# 豫构

发现软件包、解析依赖并调度编译；构云工、浏览器、节点与原生之发行物；行语言仓之仓库目标。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `yy豫构`，入口依包籍所载。

在仓库之根行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 豫构` 以验其籍。行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 豫构` 以成其器，不自行之。行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 发现 --树`，依层级（「包含包」／「包含在」）录诸包之树，以览仓中之包。

于苹果与 Linux 行仓库目标「全部」之后，又有原生豫构 `./yy豫构.exe`：其令同上（如 `./yy豫构.exe 构建 豫构`），速于 Node 之版，为常构之默具。豫构带编译器（提案 00007 合一，见编译器入口之库）：不书 `--编译器` 者以己为编译器，并行编译之工作进程亦同一程文；首参为源文、`stage`、`debug`、`--mode=…` 或 `--原生产物子进程` 者，豫构依编译器而行。原生豫构所启之 `.wasm` 子程改经 node 行之。

默认之产（提案 00007 议一）：于苹果、Linux 与豫言操作系统，编译器旁有执行器 `yy执行器.wasm`（仓库目标「全部」所生；豫言操作系统中为兼容数据盘之 `/工具/yy执行器.wasm`）者，`构建` 与 `文件` 默出本机原生可执行之文（苹果为 Mach-O，Linux 为 ELF，豫言操作系统为豫行）：豫构予编译器加 `--目标 本机 --执行器 yy执行器.wasm --降级缓存 .yybuild/降级缓存/产名.机器片`。`--输出` 以 `.wasm` 终者出 `.wasm`，以 `.树码` 终者出汇编树码；未书 `--输出` 者产名为包之程名，原生加 `.exe`（豫行不加）。编译器之参已书 `--目标` 者豫构不复加。视窗与无执行器者仍出 `.wasm`。

`豫构 发行` 构应用并其所用操作系统接口为可径行于云工、浏览器、节点或原生宿主之发行物：读包述、解依赖、依宿主择适配而绑之、书包上下文、编之、抄宿主之壳、封接口之簿，一令而毕；编译器缺省即豫构自身。`豫构 接口检查`、`豫构 接口绑定`、`豫构 装载接口` 别供其检、其绑与封簿。源在 `发行/`，用法见[发行](文档/发行.文言.md)、[接口检查](文档/接口检查.文言.md)、[接口绑定](文档/接口绑定.文言.md)、[装载接口](文档/装载接口.文言.md)。

构建诸令（构建、类型检查、文件与仓库目标）每行一次，于今目录 `.yy构建日志/运行/` 下立一运行，录其令、提交、负载及包发现、包图诸区间之时；其所启嵌套之豫构与编译器承环境之变量入同一运行，各书一事文。`YY_BUILD_LOG=0` 则止，`YY_BUILD_LOG_DIR` 易其根，`YY_BUILD_LOG_TAG` 书其签。式见[构建日志之式](../性能研究/构建性能/日志格式.文言.md)，析之以 `yy构建性能`。

`豫构 运行 径 参…` 编一脚本（或任一 `。豫` 程文）及其所依之模为装载单元（提案〇〇〇〇三），装于豫构己之进程而行之：脚本所见之程名为其径，参为径后之参（原样予脚本，不作豫构之选）。单元置于今目录 `.yybuild/单元运行/` 下依脚本绝径所列之目，目中 `印记.txt` 记豫构、执行器与诸模源文之摘要；印同则不复呼编译器，径装之，如打印探针之脚本全行约三十毫秒。须重编则编译器唯为所改之模生原生单元，余依内容取于 `.yybuild/单元缓存/`。设环境变量 `豫构运行计时` 则于标准误印构建与装行各用之毫秒。脚本首行可书 `#!/usr/bin/env -S yy豫构 运行`（`yy豫构` 在 PATH 者），编译器视首行为空白；`应用/豫构/脚本样例/首行。脚本。豫` 为例。苹果臂六十四之原生豫构装原生单元于己之进程，豫构旁须有执行器 `yy执行器.树码`（或 `yy执行器.wasm`）。诺节（`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 运行 …`）、视窗与 Linux 上编为网页汇编之单元（置于 `.yybuild/单元运行诺节/` 下，目中 `程序名.txt` 记脚本之径），由诺节宿主另起子进程装而行之，脚本之退码即命之退码；缓存中则约零点二秒。豫言操作系统中之行俟后步。`应用/豫构/脚本样例/` 为提案例一至例三之宿主之版，二法所出同。

`豫构 交互` 逐句读豫言而行之（提案〇〇〇〇三第三步）。会话之首如已书 `寻观「标准库」之书。寻观「壳命令」之书。寻「壳命令」之「文件」之书。寻「标准库」之「操作系统」之「文件系统」之书。`：[壳命令](../../库/壳命令/包说明.文言.md)（如 `「文件」之「列出」于『/』`、`「运行」于『/bin/echo』于「列」【『甲』】`）与标准库径可用之。一行之句皆闭则依次处之，行末之句号可省；未闭则印续行之示 `…> ` 而续读。`「名」乃…` 与其后同名之定合为一组。每组于豫构进程中编之（语法、名解、类检、闭包之转），生原生单元而装行之；前组之定后组可用，后定蔽前定。一组导未装之模者，先编其模为单元而装之。末句为裸式者依型印其值：整与小数印为 `「…」`，串 `『…』`，爻 `「阳」` `「阴」`，列 `「列」【…】`，元组 `（… 与 …）`，无参之函印其果；型为「有」者唯行之。编有误或有异未承，则印其诊而弃此组，会话续之；读至输入之末而止。标准输入为终端乃印 `壳> `。会话之源文书于今目录 `.yybuild/交互外部包/豫言/交互会话/` 下；首版唯苹果臂六十四之原生豫构可用，须于包所在之仓中行之。每句约五十毫秒（实测见提案〇〇〇〇三实施记录）。

所依与组成皆见[包籍](豫构。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。

值桥之标并构纯豫言文件定位共核，工具链之包置 `yy文件定位共享.wasm` 于稳定节点宿主之旁，以供正定位读取之接线。
