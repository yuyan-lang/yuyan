# 豫构

发现软件包、解析依赖并调度编译；构云工、浏览器、节点、原生与豫行之发行物；行语言仓之仓库目标。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `yy豫构`，入口依包籍所载。

在仓库之根行 `./yy豫构.exe 检查 豫构` 以验其籍。行 `./yy豫构.exe 构建 豫构` 以成其器，不自行之。行 `./yy豫构.exe 发现 --树`，依层级（「包含包」／「包含在」）录诸包之树，以览仓中之包。

于苹果与 Linux 行仓库目标「全部」之后，又有原生豫构 `./yy豫构.exe`：其令同上（如 `./yy豫构.exe 构建 豫构`），速于 Node 之版，为常构之默具。豫构带编译器（提案 00007 合一，见编译器入口之库）：不书 `--编译器` 者以己为编译器，并行编译之工作进程亦同一程文；首参为源文、`stage`、`debug`、`--mode=…` 或 `--原生产物子进程` 者，豫构依编译器而行。原生豫构所启之 `.wasm` 子程改经 node 行之。

默认之产（提案 00007 议一）：于苹果、Linux 与豫言操作系统，编译器旁有执行器 `yy执行器。树码`（仓库目标「全部」经「执行器」所生；豫言操作系统中为兼容数据盘之 `/工具/yy执行器。树码`）者，`构建` 与 `文件` 默出本机原生可执行之文（苹果为 Mach-O，Linux 为 ELF，豫言操作系统为豫行），由编译器于终链径出，不经 `.wasm`：豫构予编译器加 `--目标 本机 --执行器 yy执行器。树码 --降级缓存 .yybuild/降级缓存/产名.机器片`（所传皆绝对之径：执行器取编译器所在之目者，降级之缓置于今目录之下；编译器行于其目）。`--输出` 以 `.wasm` 终者出 `.wasm`，以 `。树码` 终者出汇编树码；未书 `--输出` 者产名为包之程名加本机系统之缀：苹果加 `。苹果。豫行`，Linux 加 `。林纳克斯。豫行`，豫言操作系统出豫行之文，不加缀。编译器之参已书 `--目标` 者豫构不复加；交叉之目标（`--目标系统`、`--目标架构`）与底层之程之书法，见[编译器包说明](../豫言编译器/包说明.文言.md)“原生之产”。视窗与无执行器者仍出 `.wasm`。

`豫构 发行` 构应用并其所用操作系统接口为可径行于云工、浏览器、节点或原生宿主之发行物：读包述、解依赖、依宿主择适配而绑之、书包上下文、编之、抄宿主之壳、封接口之簿，一令而毕；编译器缺省即豫构自身。`豫构 接口检查`、`豫构 接口绑定`、`豫构 装载接口` 别供其检、其绑与封簿。源在 `发行/`，用法见[发行](文档/发行.文言.md)、[接口检查](文档/接口检查.文言.md)、[接口绑定](文档/接口绑定.文言.md)、[装载接口](文档/装载接口.文言.md)。

构建诸令（构建、类型检查、文件与仓库目标）每行一次，于今目录 `.yy构建日志/运行/` 下立一运行，录其令、提交、负载及包发现、包图诸区间之时；其所启嵌套之豫构与编译器承环境之变量入同一运行，各书一事文。`YY_BUILD_LOG=0` 则止，`YY_BUILD_LOG_DIR` 易其根，`YY_BUILD_LOG_TAG` 书其签。式见[构建日志之式](../性能研究/构建性能/日志格式.文言.md)，析之以 `yy构建性能`。

`豫构 运行 径 参…` 编一脚本（或任一 `。豫` 程文）及其所依之模为装载单元（提案〇〇〇〇三），装于豫构己之进程而行之：脚本所见之程名为其径，参为径后之参（原样予脚本，不作豫构之选）。包与仓根依脚本所在而寻：仓根依次自脚本所在之目、今目、豫构所在之目而上寻（含 `库/标准库` 之目），次察豫构旁之 `源`（日用之发行）与 `/源`；构时切至仓根，行脚本前切回旧之今目。不属任何包之脚本拷入自生之包「脚本运行」（`.yybuild/脚本外部包/豫言/脚本运行/`，依标准库与壳命令）而编之，程名仍为原径，原文改则次行重编。单元置于今目录 `.yybuild/单元运行/` 下依脚本绝径所列之目，目中 `印记.txt` 记豫构、单元之目标、执行器与诸模源文之摘要；印同则不复呼编译器，径装之，如打印探针之脚本全行约三十毫秒。须重编则编译器唯为所改之模生原生单元，余依内容取于 `.yybuild/单元缓存/`。设环境变量 `豫构运行计时` 则于标准误印构建与装行各用之毫秒。脚本首行可书 `#!/usr/bin/env -S yy豫构 运行`（`yy豫构` 在 PATH 者），编译器视首行为空白；`应用/豫构/脚本样例/首行。脚本。豫` 为例。苹果臂六十四之原生豫构装原生单元于己之进程，豫构旁须有执行器 `yy执行器。树码`（或 `yy执行器.wasm`）。诺节（`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 运行 …`）、视窗与 Linux 上编为网页汇编之单元（置于 `.yybuild/单元运行诺节/` 下，目中 `程序名.txt` 记脚本之径），由诺节宿主另起子进程装而行之，脚本之退码即命之退码；缓存中则约零点二秒。豫言操作系统两构之机上亦装原生单元：开机之豫构与盘上之 `/工具/yy豫构` 皆可行脚本（造盘加 `--工具链`）。`应用/豫构/脚本样例/` 为提案例一至例三之宿主之版，二法所出同。

`豫构 交互` 逐句读豫言而行之（提案〇〇〇〇三第三步）。会话之首如已书 `寻观「标准库」之书。寻观「壳命令」之书。寻「壳命令」之「文件」之书。寻「壳命令」之「实现」之书。寻「标准库」之「操作系统」之「文件系统」之书。`（宿主与豫言操作系统同，并有 `寻「标准库」之「操作系统」之「命令行参数」之书。`）：[壳命令](../../库/壳命令/包说明.文言.md)（如 `「文件」之「列出」于『/』`、`「运行」于『/bin/echo』于「列」【『甲』】`）与标准库径可用之。一行之句皆闭则依次处之，行末之句号可省；未闭则印续行之示 `…> ` 而续读。`「名」乃…` 与其后同名之定合为一组。每句（壳命令亦然）皆编为组单元而行之，不设快路（十月十四日用户定）。惟用户所入者编之：会话之法于装前导之单元时登之（请求之文、编译器与异标为单元之命行参而传之），首不编；豫言操作系统中壳命之法分部按需而装，每编一句之前，句所用之部（见用户态桌面之 `部居`）则装其造盘时预编之单元而行其登脚本，开机壳、桌面终端与远程登录之会话皆同。乃依次行开头之句（开机壳予开机自启诸句；`豫构 交互 --开头句 句` 予命令行之诸句，十月十四日起桌面终端以用户所入之首行如此付新会话）。开头之句如所读之行先切为句，一行可有数句或惟注。每组于豫构进程中编之（语法、名解、类检、闭包之转），生原生单元而装行之；前组之定后组可用，后定蔽前定。一组导未装之模者，先编其模为单元而装之。命令之脚本：`「脚本」于『径.txt』` 以文之每行为交互之一句而处之，先印 `+ 行`，有误则续；唯空白与注之行略之；`「脚本」于『甲。脚本。豫』` 付 `豫构 运行`。末句为裸式者依型印其值：整与小数印为 `「…」`，串 `『…』`，爻 `「阳」` `「阴」`，列 `「列」【…】`，元组 `（… 与 …）`，无参之函印其果；型为「有」者唯行之。编有误或有异未承，则印其诊而弃此组，会话续之；读至输入之末而止，末句有误则退码为一，否则为零。标准输入为终端乃印 `壳> `；`豫构 交互 --提示` 则每行之前皆印之（桌面终端与远程登录开会话于管）。`豫构 交互 --预装` 则起即装前导之单元（不印其示），开头之句既办、初读行之前印一行 `豫构交互：备用会话已就绪`；远程登录预起一如是之备会话，exec 至则径接之。会话之源文书于仓根之 `.yybuild/交互外部包/豫言/交互会话/` 下；仓根先视豫构旁之 `源` 目（日用之发行：单文件旁置一份源树，随处而起皆用之，前导唯编一次），次自今目录上寻，不得则自豫构所在之目上寻，皆不得则诸句皆不能行（豫言操作系统中仓根为 `/源`）。首句（或预装）至乃备会话之包与前导之单元；会话之目 `会话<纳秒><随机后缀>/` 置诸组之源文、请求之文与异标。原生豫构（苹果臂六十四、Linux 兼容六十四、豫言操作系统两构）与豫行启动器（苹果、Linux 两构）中之豫构豫行上编为原生单元。单元目录之印与单元之缓之键记单元之目标系统与构，启动器中之豫构豫行与原生豫构共一仓而不相误用。每句约五十毫秒（实测见提案〇〇〇〇三实施记录）。预编前导：`豫构 预编前导 仓根 [-- 编译器参数…]` 依交互初编之法，为仓根下之交互会话备会话之包与前导之单元，单元与编译之缓存留于仓根与编译器目之 `.yybuild`；`--` 后之参接于单元之参后而付编译器。豫言系统造盘，于宿主以依盘内所布之树为虚根（客体二号之环境 `豫言根目录`）而行之，置其果于盘。

`开机。豫` 为豫言操作系统开机程序之入口（提案〇〇〇〇三第八步）：造两构之启盘时，豫言系统编之为开机程序，开机即入豫构之交互之式（其法在 `开机壳。豫`）。文件与环境之命依库 用户态桌面 之命令壳（已授“桌面”根下之径、.环境），「运行」「构建启动盘」同步行子程，「图形」入桌面，「退出」终之；逐键编辑而读行（拼音组字、候选、补全、历史，Ctrl-C 弃此行）。每句皆以盘上之 `/工具/yy豫构`、`/工具/yy执行器。树码` 与源树 `/源` 编之，编译缓存之程序标识取 `/工具/yy豫构.摘要`，与盘上之豫构共缓存；造盘缺省带工具链，盘无工具链则诸句皆不能行。开机自启诸句为会话之开头句，编而行之；「图形」书入桌面之请，读次行之前于此入桌面。造盘时已预编前导单元（单元目录之印与盘上者合）则开机即装之而后读首句，首句不复候编与装。有参而行则为常豫构。

所依与组成皆见[包籍](豫构。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。

值桥之标并构纯豫言文件定位共核，工具链之包置 `yy文件定位共享.wasm` 于稳定节点宿主之旁，以供正定位读取之接线。
