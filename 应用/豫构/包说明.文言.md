# 豫构

发现软件包、解析依赖并调度编译；构云工、浏览器、节点、原生与豫行之发行物；行语言仓之仓库目标。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `豫构`，入口依包籍所载。

在仓库之根行 `./豫构。林檎。豫行 检查 豫构` 以验其籍。行 `./豫构。林檎。豫行 构建 豫构` 以成其器，不自行之。行 `./豫构。林檎。豫行 发现 --树`，依层级（「包含包」／「包含在」）录诸包之树，以览仓中之包。

于林檎与 Linux 行仓库目标「全部」之后，又有原生豫构 `./豫构。林檎。豫行`：其令同上（如 `./豫构。林檎。豫行 构建 豫构`），速于 Node 之版，为常构之默具。豫构带编译器（提案 00007 合一，见编译器入口之库）：不书 `--编译器` 者以己为编译器，并行编译之工作进程亦同一程文；首参为源文、`stage`、`debug`、`--mode=…` 或 `--原生产物子进程` 者，豫构依编译器而行。原生豫构所启之 `.wasm` 子程改经 node 行之。

默认之产（提案 00007 议一）：于林檎、Linux 与豫言操作系统，编译器旁有执行器 `执行器。树码`（仓库目标「全部」经「执行器」所生；豫言操作系统中为兼容数据盘之 `/工具/执行器。树码`）者，`构建` 与 `文件` 默出本机原生可执行之文（林檎为 Mach-O，Linux 为 ELF，豫言操作系统为豫行），由编译器于终链径出，不经 `.wasm`：豫构予编译器加 `--目标 本机 --执行器 执行器。树码 --降级缓存 <共储>/降级/产名.机器片`（所传皆绝对之径：执行器取编译器所在之目者，降级之缓置于共储，见下；编译器行于其目）。`--输出` 以 `.wasm` 终者出 `.wasm`，以 `。树码` 终者出汇编树码；未书 `--输出` 者产名为包之程名加本机系统之缀：林檎加 `。林檎。豫行`，Linux 加 `。林纳。豫行`，豫言操作系统出豫行之文，不加缀。编译器之参已书 `--目标` 者豫构不复加目标与执行器；书 `--目标 本机` 而未书 `--降级缓存` 者补其降缓，文名带目标之系与构（如 `降级/豫构。豫行-豫言-兼容六十四.机器片`）；交叉之目标（`--目标系统`、`--目标架构`）与底层之程之书法，见[编译器包说明](../豫言编译器/包说明.文言.md)“原生之产”。轩窗与无执行器者仍出 `.wasm`。

`豫构 发行` 构应用并其所用操作系统接口为可径行于云工、浏览器、节点或原生宿主之发行物：读包述、解依赖、依宿主择适配而绑之、书包上下文、编之、抄宿主之壳、封接口之簿，一令而毕；编译器缺省即豫构自身。`豫构 接口检查`、`豫构 接口绑定`、`豫构 装载接口` 别供其检、其绑与封簿。源在 `发行/`，用法见[发行](文档/发行.文言.md)、[接口检查](文档/接口检查.文言.md)、[接口绑定](文档/接口绑定.文言.md)、[装载接口](文档/装载接口.文言.md)。

编译之缓置于共储之根（提案 00034）：环境之变量 `YY_CACHE_DIR` 所予之目，无则 `/tmp/豫构缓存-<用户名>`（豫言操作系统中为今目录之 `.豫构缓存`）。根下依编译语义号分目，号书于库 译场 之 `译料/译设/语义号。数据。豫`，编译之义变则易之（其规见 AGENTS.md）。号目之中：`引/<仓根>/` 为诸工作树自有之阶缓，依改时判新旧，每缓旁之“。记”录书时之阶键与内容之摘；`键/` 与 `物/` 为依内容而寻之共储阶缓，阶键为入单之沙二五六（编译语义号、信名、模之缓身，及源文之摘或本模前阶与所导诸模同阶之摘），键库存产摘，旁之“。料”存入单，物库依摘存产，本树之缓旧则先依阶键问此，中则径取；`产物/` 为终链之成品，键为链键单（编译语义号、产名、所出之的、执行器之摘、原生之的、诸模闭包形式与元数之摘）之沙二五六，豫行旁之“。摘要”并存并取；`降级/` 为原生之产之降缓与整产之缓，依产名（及目标之系与构）分文。模之缓身与包之缓号皆去仓根，名解以降诸阶与终链之成品，异树中同一缓；文件依赖、抽象语法与语义标记书全径，留于各树自有之阶缓。编译器之参 `--do-not-load-cache` 令诸阶与终链皆从头而算；仓库目标「全部」之三级以之冷编，二三逐字同则证语义号无漏易。

一呼豫构可构数程：`./豫构。林檎。豫行 构建 包甲 --输出 甲 --又 构建 包乙 [入口段…] --输出 乙 --又 文件 径 --输出 丙 --编参 --开机程序 -j 24 -- 公参…`。前端一次编诸程所依之并，乃各终链；`--编参` 后之一参惟授本组之终链，`--` 后之编参诸程共之。诸程之终链与原生之生，豫构别起进程而并行之，同时至多 `YY_链接并行数` 个（缺省为核数除六，介于一三之间），所依之模多者先链。造盘之开机程序与豫行诸器即如是一次编毕。加 `--链参存 文` 则惟编前端，存诸程终链之参于此文；后以 `豫构 链接 文 [--只链 前缀] [--编译器 编译器]` 续链之，`--只链` 惟链出径以前缀起者（造盘时二构之前端父进程一次编毕，二子进程各链其程）。

构建诸令（构建、类型检查、文件与仓库目标）每行一次，于今目录 `.构建日志/运行/` 下立一运行，录其令、提交、负载及包发现、包图诸区间之时；其所启嵌套之豫构与编译器承环境之变量入同一运行，各书一事文。`YY_BUILD_LOG=0` 则止，`YY_BUILD_LOG_DIR` 易其根，`YY_BUILD_LOG_TAG` 书其签。式见[构建日志之式](../性能研究/构建性能/日志格式.文言.md)，析之以 `构建性能`。

`豫构 运行 径 参…` 编一脚本（或任一 `。豫` 程文）及其所依之模为装载单元（提案〇〇〇〇三），装于豫构己之进程而行之：脚本所见之程名为其径，参为径后之参（原样予脚本，不作豫构之选）。包与仓根依脚本所在而寻：仓根依次自脚本所在之目、今目、豫构所在之目而上寻（含 `库/豫章` 之目），次察豫构旁之 `源`（日用之发行）与 `/源`；构时切至仓根，行脚本前切回旧之今目。不属任何包之脚本拷入自生之包「脚本运行」（`.豫构缓存/脚本外部包/豫言/脚本运行/`，依标准库与壳命令）而编之，程名仍为原径，原文改则次行重编。单元置于今目录 `.豫构缓存/单元运行/` 下依脚本绝径所列之目，目中 `印记.txt` 记豫构、单元之目标、执行器与诸模源文之摘要；印同则不复呼编译器，径装之，如打印探针之脚本全行约三十毫秒。须重编则编译器唯为所改之模生原生单元，余依内容取于 `.豫构缓存/单元缓存/`。设环境变量 `豫构运行计时` 则于标准误印构建与装行各用之毫秒。径以“豫行”终者作清单豫行（提案〇〇〇三八第一步，式见《豫行格式》“清单豫行”）：不复编，依段之次装诸单元于本进程而行之，程名即其径；清单豫行由 `豫构 构建 包 --清单 --输出 名。清单。豫行` 书之：先依行之法以单元之鹄编出单元之箧（今目之 `.豫构缓存/清单/<出之末名>`），乃依装之次合之；单元之鹄依 `--` 后之 `--目标系统`、`--目标架构`，未予取本机。唯能装原生单元之豫构能行之（林檎臂六十四之原生豫构与豫言操作系统中之豫构）。未装一元之先，汇诸单元所导之宿主函数，有本平台未具者（提案〇〇〇四〇）则一举列之而不行；设环境 `YY_所供=关` 则惟言不拒。脚本与单元之装亦如是核之。脚本首行可书 `#!/usr/bin/env -S 豫构 运行`（`豫构` 在 PATH 者），编译器视首行为空白；`应用/豫构/脚本样例/首行。脚本。豫` 为例。林檎臂六十四之原生豫构装原生单元于己之进程，豫构旁须有执行器 `执行器。树码`（或 `执行器.wasm`）。诺驿（`node 豫言操作系统/宿主/节点/宿主.cjs 豫构.wasm 运行 …`）、轩窗与 Linux 上编为网页汇编之单元（置于 `.豫构缓存/单元运行诺驿/` 下，目中 `程序名.txt` 记脚本之径），由诺驿宿主另起子进程装而行之，脚本之退码即命之退码；缓存中则约零点二秒。豫言操作系统两构之机上亦装原生单元：开机之豫构与盘上之 `/工具/豫构。豫行` 皆可行脚本（造盘加 `--工具链`）。`应用/豫构/脚本样例/` 为提案例一至例三之宿主之版，二法所出同。

`豫构 交互` 逐句读豫言而行之（提案〇〇〇〇三第三步）。会话之首如已书 `寻观「豫章」之书。寻观「诏令」之书。寻「诏令」之「案牍」之书。寻「诏令」之「实现」之书。寻「豫章」之「寓所」之「藏书」之书。`（宿主与豫言操作系统同，并有 `寻「豫章」之「寓所」之「号令」之书。`）：[壳命令](../../库/诏令/包说明.文言.md)（如 `「案牍」之「列目」于『/』`、`「行」于『/bin/echo』于「列」【『甲』】`）与标准库径可用之。一行之句皆闭则依次处之，行末之句号可省；未闭则印续行之示 `…> ` 而续读。`「名」乃…` 与其后同名之定合为一组。每句（壳命令亦然）皆编为组单元而行之，不设快路（十月十四日用户定）。惟用户所入者编之：会话之法于装前导之单元时登之（请求之文、编译器与异标为单元之命行参而传之），首不编；豫言操作系统中壳命之法分部按需而装，每编一句之前，句所用之部（见用户态桌面之 `部居`）则装其造盘时预编之单元而行其登脚本，开机壳、桌面终端与远程登录之会话皆同。乃依次行开头之句（开机壳予开机自启诸句；`豫构 交互 --开头句 句` 予命令行之诸句，十月十四日起桌面终端以用户所入之首行如此付新会话）。开头之句如所读之行先切为句，一行可有数句或惟注。每组于豫构进程中编之（语法、名解、类检、闭包之转），生原生单元而装行之；前组之定后组可用，后定蔽前定。一组导未装之模者，先编其模为单元而装之。命令之脚本：`「脚本」于『径.txt』` 以文之每行为交互之一句而处之，先印 `+ 行`，有误则续；唯空白与注之行略之；`「脚本」于『甲。脚本。豫』` 付 `豫构 运行`。末句为裸式者依型印其值：整与小数印为 `「…」`，串 `『…』`，爻 `「阳」` `「阴」`，列 `「列」【…】`，元组 `（… 与 …）`，无参之函印其果；型为「有」者唯行之。编有误或有异未承，则印其诊而弃此组，会话续之；读至输入之末而止，末句有误则退码为一，否则为零。入分二式，命令行可指之（十月十六日用户定）：`豫构 交互 --组字` 为交互之入，逐键而编，有输入法（拼音组字）、候选、补全与旧行，用壳核心之「闻言」，与开机壳同一编辑之器（读行时终端入原始之模，读毕复之；空行按 Ctrl+D 则终会话，Ctrl+C 弃方入之行）；`豫构 交互 --直读` 为非交互之入，依行原样而读，不经输入法与补全（豫言操作系统开机之控台以壳核心之「直闻」逐键读之，候键时照办子任务之信与「图形」之请）。皆不书则标准入为终端（且无 `--提示`）则组字，否则直读。宿主原生、豫行启动器与豫言操作系统同。`--编译器 径` 别指编译器（默为豫构自身，执行器取编译器旁之 `执行器。树码`）；`--先装前导` 则前导单元已编者起即装之（未编则不装，俟首句）。直读而标准输入为终端乃印 `壳> `；`豫构 交互 --提示` 则每行之前皆印之（桌面终端与远程登录开会话于管）。`豫构 交互 --直读 --回执 标` 则每读新句之前印一行 `标 成` 或 `标 败`（前句之成败，会话之首为成），续行印 `标 续`，以代提示，捉刀（提案〇〇〇三六）据此知一句之毕与其成败。`豫构 交互 --预装` 则起即装前导之单元（不印其示），开头之句既办、初读行之前印一行 `豫构交互：备用会话已就绪`；远程登录预起一如是之备会话，exec 至则径接之。会话之源文书于仓根之 `.豫构缓存/交互外部包/豫言/交互会话/` 下；仓根先视豫构旁之 `源` 目（日用之发行：单文件旁置一份源树，随处而起皆用之，前导唯编一次），次自今目录上寻，不得则自豫构所在之目上寻，皆不得则诸句皆不能行（豫言操作系统中仓根为 `/源`）。首句（或预装）至乃备会话之包与前导之单元；会话之目 `会话<纳秒><随机后缀>/` 置诸组之源文、请求之文与异标。原生豫构（林檎臂六十四、Linux 兼容六十四、豫言操作系统两构）与豫行启动器（林檎、Linux 两构）中之豫构豫行上编为原生单元。单元目录之印与单元之缓之键记单元之目标系统与构，启动器中之豫构豫行与原生豫构共一仓而不相误用。每句约五十毫秒（实测见提案〇〇〇〇三实施记录）。`豫构 交互 --直读 --只编译 --开头句 句…` 惟编开头之句而不装不行：每句先于标准误印 `+ 句`，不得编者随之以诊；编毕即返，不读标准入，一句未编得则退码为一。`应用/豫构/林纳对照。测试。豫` 以之核 LOCALAGENTS.md 第八节壳命与林纳命对照之例句（`豫构 目标 豫构测试` 与全树之试皆行之）。预编前导：`豫构 预编前导 仓根 [-- 编译器参数…]` 依交互初编之法，为仓根下之交互会话备会话之包与前导之单元，为豫言操作系统预编者并诸部之单元，前导与诸部一呼并编，单元与编译之缓存留于仓根与编译器目之 `.豫构缓存`；`--` 后之参接于单元之参后而付编译器。豫言系统造盘，于宿主以依盘内所布之树为虚根（客体二号之环境 `豫言根目录`）而行之，置其果于盘。

`开机。豫` 为豫言操作系统开机程序之入口（提案〇〇〇〇三第八步）：造两构之启盘时，豫言系统编之为开机程序，开机即入豫构之交互之式（其法在 `开机壳。豫`）。文件与环境之命依库 用户态桌面 之命令壳（已授“桌面”根下之径、.环境），「行」「营启盘」同步行子程，「图形」入桌面，「辞」终之。全系统惟一壳（十月十六日）：开机壳与宿主、桌面终端、远程登录同经「交互命令」入会话，入之式亦由交互之参选之：`/系统/开机。数据。豫` 之「交互参数」（如 `「交互参数」者「列」【『--直读』】也。`），无此文或此项则为 `--组字`（逐键编辑：拼音组字、候选、补全、历史，Ctrl-C 弃此行）；`--直读` 依行原样而读，串口之脚本整行而入，不经拼音。每句皆以盘上之 `/工具/豫构。豫行`、`/工具/执行器。树码` 与源树 `/源` 编之，编译缓存之程序标识取 `/工具/豫构。豫行。摘要`，与盘上之豫构共缓存；造盘缺省带工具链，盘无工具链则诸句皆不能行。开机自启诸句为会话之开头句（`--开头句`），编而行之；「图形」书入桌面之请，读次行之前与候键之隙于此入桌面。造盘时已预编前导单元（单元目录之印与盘上者合）则开机即装之而后读首句（`--先装前导`），首句不复候编与装。开机先视有无「葺寓」所暂存之 `/新版`（十月十七日）：有则行 `安装系统 换上`，今启为新系统之试启则易所暂存之 `/源` 与 `/工具`，否则删其暂存，然后读程标、寻仓根、入会话。有参而行则为常豫构。

将作者，一机一主之构建服务也（提案〇〇〇三五）：并译之始访之，无则遣之立于后台（先离调用者之会，乃迁于会所 `~/.豫构/将作`）；诸役皆交之而行，依槽数（缺省在线核数减一，`YY_将作槽数` 可改）而排，先交互、次前台、后后台（`YY_将作优先`），同等则先少者。将作依器（程文之沙二五六，系入 `~/.豫构/将作/工具链/<指纹>/`）遣代役（`<器> 将作 代役`），役行于代役：工作之役付其常驻之工（带境之帧，每役于客之所居、依客之风俗行之），同指纹之诸树共一代役、共一池常驻之工；代役闲十分则退。客门绝则撤其役；代役绝则其役归诸客自行；将作不在，则自并行如旧。门之首行皆携令牌（`~/.豫构/将作/令牌`，0600），将作唯认同主。牒皆数据子语言之一行（籍册）。始立则书门籍 `~/.豫构/将作/门。数据。豫`。`豫构 将作 代役 <门> <指纹>` 为代役之入口，将作遣之。`豫构 将作 运行` 立之于将作之门（缺省三七四一一，`YY_将作端口` 可改），唯本机则守 127.0.0.1、入盟则守 0.0.0.0；唯本机而三时无构则自休；`豫构 将作 启动` 立之于后台（已立则不动）；`豫构 将作 重启` 请其止，候其退，复立新者于后台（入盟或易程之后用之）；`豫构 将作 状态` 书其况（入盟则接同僚之列；`--数据` 则书数据子语言之况）；`豫构 将作 役` 书行中与候派之役；`豫构 将作 同僚` 书同僚之列（名、平台、核、状、负载、闲槽与槽数、排队、址与所自），首行书本机之实例、节点与所收邻籍之报数；`豫构 将作 入盟 <ssh 主机>` 本无虎符则生之，以系统之 ssh 与 scp 授之于彼之会所，乃两边各 `豫构 将作 重启`；`豫构 将作 停止` 请其退；`豫构 监工` 订其况而于屏上时时更之，`--全网` 则于本机之况后接诸在线同僚所报之况，非终端则五秒一书。`YY_将作=关`、CI 之境、Wasm 之译器，皆不用之。

将作初立即生虎符（`~/.豫构/将作/虎符`：三十二字随机数之十六进，0600），故缺省守 0.0.0.0，开邻籍（多播名籍）：服务之类 `_yuyan-build._tcp.local`，实例 `将作＠<主名>`，TXT 携节点、虎符之纹、平台、核数与约版；始立则自报而问，此后六十秒一为，止则告别。符纹同者相见，节点（会所之 `节点`）小者叩彼：两边各出随机之数，以虎符印随数与节点而互证（合符），乃结为同僚之链，链上每行附会钥印序与文之验。同僚每秒互报其况（槽数、闲槽、排队、一分之负载与况文），五秒不闻则绝之而书离，此后十秒一试。设置之籍 `~/.豫构/将作/设置。数据。豫` 之「同僚」列静同僚（每项“主”或“主:端”），多播不通者亦交之。符纹异者列于同僚之下，书为未盟：于一机行 `豫构 将作 入盟 <ssh 主机>` 授之以符，彼行 `豫构 将作 重启`，乃两相结交。有同僚之链者不以闲而休。构时设 `YY_将作=关` 则不用将作，亦不开本网。`dns-sd -B _yuyan-build._tcp`（林檎）与 `avahi-browse _yuyan-build._tcp`（林纳）皆可径见之。林檎之上，立将作之会（终端或 ssh）须常开，将作乃得出入本网（系统之本网隐私依立之之会而放之）；托于 launchd 留待后续之版。

同僚之间互借其缓、互托其役（提案〇〇〇三五第四步）：

- **邻家缓存**：托出既成、还于本机重行之役（将作派时标邻取，代役加水土 `YY_将作邻取`），译阶于共储不得其键，则请将作遍问同僚（每不中皆问则冷构迟，故唯重行时问之）；同僚答以其产（卦文，核其沙二五六），则书于本机之共储，以为中。
- **托役**：本机槽满，候派逾二百毫秒之译阶之役（验类并蜕、跨卷之精、闭包之前、ANF、全码之生），托于所报有闲之同僚（闲依其槽数、在跑之役与一分之负载算之）；彼毕则答托毕，本机还其役于候派之首而即重行，此时诸阶多可自同僚取之，重行唯取而核之。同僚败、拒或绝，则役仍行于本机，其果恒与全在本机者同。唯托语义号同者；托主之仓根须能补为同长之镜根。
- **借场**：受托者为每托主仓根于临时之目立一镜根，与托主仓根同字长，以己之器、以镜根为所居而行其役（水土 `YY_将作借场` 以识之）；所缺之阶缓、包境与源文依相对之径向托主求之，含托主仓根者依字易为镜根。受托者唯受白籍之阶，参中全径须在托主仓根之下，托主唯为己所托之仓根答请文。

- **远作**：水土 `YY_将作远作` 授云端之缓之根址，则同僚亦无之阶键复问远作：每程先探“根/号/有”一次，有乃以系统之 curl 取“根/号/键/前二/阶键”与“根/号/物/前二/摘”，核其沙二五六而书于本机之共储。今唯用本网之邻籍，云端读书之接口留待后续之版。

`豫构 将作 状态` 之首行，有托役时显托出与受托之役数、自同僚所取之缓数（邻取）与借场所取之文数（借取）。器以编译语义号认同；于同僚备器（利器）与抽验，留待后续之版。

行在者，每用户每宿主一常驻之程，为此宿主之豫言系统也（提案〇〇〇三九）：林檎、林纳之原生诸程起则来登其籍（执行器之「行在门」），籍之柄即宿主进程之号，行在自居零号；壳命「列出役」「辍役」「辍」与任务管理器所问即此籍。交互之会话不见行在则立之于后台，入行在之会话复装几席之「任务」「图形」「屏键」「电源」四部。其所在 `~/.豫言/行在/`：门书 `门。数据。豫` 记端口（缺省自三七四三一起，见占则后试，`YY_行在端口` 易其始）、进程号与启时，`钥`（〇六〇〇）为连之所示。无务无连满三时则自退。`豫构 行在 运行 [--后台]` 行之，`启动` 立之于后台，`重启` 停而复立，`状态` 印其况与诸在籍之务（壳命「行在态」同），`停止` 请其退。`YY_行在=关`、集成之境与林檎林纳以外之宿主不用，仍独行。

入行在之程依附庸之表观其文（提案〇〇〇三九第二步，其法在执行器，见客体二号说明“附庸”）：根为私根 `~/.豫言/行在/根`，系统、数据、软件居私根而可书；起程时今目所在之仓、共储之根、`~/.豫构`、`~/.豫言` 与 /tmp 依原径可书，工具链之目与系统诸目依原径惟读。`YY_附` 增其附庸（冒号所隔之宿主之径），`YY_全宿主` 透宿主之根；壳命「附庸」书本务之表。将作、行在二役依宿主之域而行。

行在之桌面（提案〇〇〇三九第三步）：壳命「图形」书 /系统/请求进入桌面 于私根，行在见之，则于私根中起行在工具之目之本机图形桌面（其目取 `YY_行在工具`，缺省为豫构所在之目之 `行在工具/`，仓库目标「行在工具」编图形桌面与桌面程序），书 /系统/桌面运行中，桌面退则删之。桌面为屏之主：画布于共之屏块 `~/.豫言/行在/物块`，诸务之「截屏」读之，「点击」「按键」诸拟入书其注环。林檎之窗尺取 `YY_行在屏尺`（缺省一千二百八十乘八百），设 `YY_行在屏后台` 则开窗于后；林纳无显，桌面亦无头而行。桌面每窗（「辟窗」所开亦然）由同目之桌面程序各以己之进程行之，入行在而登于籍。「息」「更始」请行在尽止诸务而退，更始复于后台立新行在。
