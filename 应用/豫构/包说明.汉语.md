# 豫构

发现软件包、解析依赖并调度编译和原生链接。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为可执行文件类型，不可被其他包依赖；包内模块仍可互相引用。类型典中的入口和文件名见包配置，程序产物为 `yy豫构`。

## 使用

在仓库根目录运行：

```sh
./yy豫构 检查 豫构
./yy豫构 构建 豫构
```

依赖、原生源文件及说明路径以 [包配置](豫构。包。豫) 为准。构建不会自动运行程序；有发布或服务副作用的工具应先阅读其入口源码。
