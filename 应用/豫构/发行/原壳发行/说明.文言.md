# 用户态系统发行

节点原壳桌面之成物与网页行在之成物又附 `字体.ttf` 与 `字体许可证.txt`，共仓内免费文楷源文与全许可。桌面默认择文楷；节点程序自其成物之目取之，网页行在由页依族而宣，皆共公字体接口与纯豫言之解绘。通用节点打包仍三核心文件；独立桌面成物若用文楷，亦须附此二资。仓库成物目标记字体源与许可为输入，资源文为产物。

此命令壳与用户态桌面节点发行之配置也。构建取当命令壳源，绑公控制台、文件、子程序、字体与显示诸接口。启则默认命令行，以 `「图形」` 开桌面，归则续同会话。

构建命为 `./豫构。林檎。豫行 目标 用户态系统节点发行 -j 24 --不连带`，末行正式装载之核。启动命为 `node 用户态系统节点发行/启动.mjs --授权控制台 主控制台 --授权只读目录 桌面=目录路径 --授权显示面 主窗口=900x640 --原生依赖目录 依赖路径`；依赖目录须具 SDL。欲建目录或存环境，以 `--授权目录` 授写。子程序以 `--授权子程序 名=启动文件` 授之，环境别以 `--允许环境 名`。节点宿主既支网页事件、网页文树、网页界面三接口（原壳「图形」所用平铺桌面赖之），节点发行乃复，俟后续之版。

网页行在由仓库目标 `用户态系统浏览器发行` 构之（`豫构 目标 用户态系统浏览器发行 -j 24`）：发行目录下之 `行在/` 为页与三快照，`构建/` 为浏览器构建宿主之进程表、工作线程、内存文件系统、编码、豫寓之实与边界胶水之体，`字体.ttf` 与 `字体/` 供页依族而宣。旧原壳之浏览器发行与专给其用之网页适配，今为网页行在所代（二〇二六年十月二十日）。

正式原壳建目录、存而取消环境、继子程序输入、参及环境之传皆过。正式启动器之管与实PTY二式，皆行“回显进入前 → 图形 → 实文件预览 → 归 → 回显返回后 → 退出”；归前还窗。记录器惟采实SDL之素而注其事，正式启动器犹核原程序。实画为 `原壳正式往返.png`。

环境文在已授“桌面”根之 `.环境`，逻辑径为 `/.环境`。原壳当径、切换、列与读，共图形命令之公文件服务，当径存于原壳会话；建目录、写与附随其径。写与附共授权文本之写服务。子程序输入文犹相对授权根，复制、移动、删除等余旧文件命、管之正式句式与流式输出待成。Windows/Linux与原生系统之独验及原生接口适配未成。模板以 `.txt` 避重复包之发现，构建辅助写于隐发行目录。

`node 豫言操作系统/宿主/节点/原壳文件导航验收.mjs 用户态系统节点发行` 已过：列、子目录导航与读、切换败而存原径、相对建目录、惟读拒写而存文件。

同验亦过相对当径之中文覆盖与附、短文覆盖断旧尾、附而建新文，及惟读拒覆盖与附而原文不易。
行模之启示惟说完整命令之提交与图形入口；逐键终端模示中文组字、数字择词、Esc 留英文与引号快捷键。旧浏览器原壳之逐键入，随其发行而退（二〇二六年十月二十日）。

用户态系统浏览器发行今惟生网页行在（提案〇〇〇四三）：发行目录下之 `行在/`（页 index.html、行在.mjs、秘府.mjs、终端.mjs 与快照 源.tar.gz、工具.tar.gz、桌面.tar.gz）、`构建/`（浏览器构建宿主之进程表、工作线程、内存文件系统、编码、豫寓之实与边界胶水之体）与三套之字及许可。网页行在之开机壳为豫构交互，与原生同一程序，见 `豫言操作系统/宿主/浏览器/行在/说明.文言.md`。发行时于宿主以网页汇编之豫构对源快照行 `预编前导`，置前导与行在诸部之单元、阶缓于 `源.tar.gz` 之 `tmp/豫构缓存`（`node` 须在 PATH 中），浏览器中装前导、装部径中。
