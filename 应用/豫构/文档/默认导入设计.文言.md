# 默认导入设计

库于包述「类型」中必书「默认导入」，定独书包名之导（`寻观「甲」之书。`）所展为何模。此以代昔定于包定位之「总集」，且使“诵”（重导出）退出语言。字段、义与验，见[豫构包系统](../包系统.文言.md)“默认导入”；此篇记其缘由、所在、迁移之指与待办之事。

今状：二〇二六年十月九日已切换。仓中诸库包皆明书默认导入；纯门面之总集与余转出之文已除；含实之总集改名为常模，并入默认导入；语言中无 `诵`、模别名之定义与“模名同名定义”之特则；构建之器一律书第五式包上下文。

## 缘由

- 「总集」本为二〇二三年以来目录之门面约定，二〇二六年九月五日起为解析之则：独书包名之导，取包根之 `总集。豫`。其名写死于 `库/构建基础/包定位。豫` 与接口检查之器，不属任何包之述。
- 总集以“诵”摊他模之名而转出，标准库又以 `「控制」者「控制」也` 复绑名空间为定义。如此，模若为物，而语言本无一等之模。
- 门面与实现相杂：约十三总集藏数十至数千行之实。独名之导，引总集所转之全树入依赖图，标准库总集所及凡五十四模，而常文件所用不过五前置之模（闭包十一）。

## 要点

- 字段在库之「类型」，必书。其值为目之列；列空则无默认导入，如此之包唯可导具体之模。目为包内模径（以“/”分段）或登记之子包名，子先于模，子目则递归展其子之默认导入。可执行文件之包无此字段。
- 展发于编译器之前端：一导于语法树仍为一条，`抽象语法分析` 转之为文开（`观`）、文命名（`寻`）二伪定义，文名为多文名（以制表符连诸径，首复加一制表符为记）；唯一文则与单文之导全同。`导入预测` 返诸叶文，供依赖之析。
- 名称解析视多文名为一体：`名称解析文件投影` 逐文求首有此名之义；`寻`、`观` 初遇，验目间不重名（每进程每多文名一验），报“默认导入的条目导出了同名定义「名」”。覆盖之检以 `读覆盖模块` 合诸文之义。
- 包记第六项为目之列。构建之器一律书第五式包上下文：第四式加“默认导入”一列。第二至四式无此列，读时改自包述之文取此字段（构建基础以小扫描器读 `「默认导入」者「列」【…】`），故云仓与云工作台手书之第二式上下文照常可用。
- 包名仍可为限定之前缀（`甲之名`），盖 `寻` 以甲绑一名空间，对应诸叶模。目自身之模名空间不另绑：欲书 `字典术之查`，则明 `寻「标准库」之「数据结构」之「字典术」之书。`。
- 模为静态之名域。名空间唯可为 `之` 之底，不可为参、返、类或数据，亦不可被顶层之定义复绑为名（`「甲」者「甲」也` 报“命名空间不是一等值”）。解名甲时，先查局部之绑与已开之文，末乃视名为甲之名空间；空间中有同名定义甲之特则已除。
- `观` 唯开已导之模之名，自不载文；导而兼开，用 `寻观`。

## 迁移之指

| 旧写 | 新写 |
| --- | --- |
| `观「甲」之「总集」之书。`、`寻观「甲」之「总集」之书。` | `寻观「甲」之书。`（含实之总集已改名为 `甲。豫`，欲取此模本身，书 `寻观「甲」之「甲」之书。`） |
| `总集之乙`（`寻「甲」之「总集」之书。` 所绑之名空间） | `甲之乙`（先 `寻「甲」之书。`） |
| `寻诵`、`观诵`、`寻观诵`、`诵` | 除 `诵`：包装之模唯留己码，用者依包之默认导入或径导具体之模；本文所用之名书 `寻观` 或 `观` |
| 一包之总集转出他包之名（图像处理至图像量化、深度学习框架至深度学习等） | 用者径依而导底层之包 |
| `「乙」者「乙」也`（复绑名空间为定义）、倚“名空间与同名定义”之写法 | 明 `寻` 导模，以 `乙之名` 限定 |
| 标准库：`寻观「标准库」之书。` 后书 `字典术之甲`、`数据结构之字典术之甲` | 默认导入唯开十五前置之模之名；书 `寻「标准库」之「数据结构」之「字典术」之书。`，乃书 `字典术之甲` |
| 标准库：`寻观「标准库」之「豫言标准内核」之书。` 或目录门面 `寻观「标准库」之「数据结构」之书。` | `寻观「标准库」之书。`，或逐模 `寻观「标准库」之「数据结构」之「字符串术」之书。` |
| 库包述无「默认导入」 | 于「类型」补 `「默认导入」者「列」【…】`；不须被独书包名而导之包，书空列 `【】` |

## 迁移之果

- 总集转列：包根总集一百一十四，纯门面九十七者除之，含实者十六改名为常模（如 `总集。豫` 改为 `源码排版。豫`）。
- 非总集之转出文：六十，纯门面者除之，带码者去 `诵` 而以 `寻观` 书其名。
- 标准库：门面九（总集、豫言标准内核、七目录门面）已除，默认导入为十五前置之模；用者补显 `寻` 约七百四十行，去目录层限定约一百六十处。
- 跨包转出：图像处理、深度学习、深度学习框架、静态站，用者径导底层之包。
- 数值类型昔以二十六“值别名”选转，今默认导入整批之模。

## 待办事项

- 接口检查之器（`豫言操作系统/应用/豫言操作系统接口检查`）视独名之导为单文，遇多项默认导入之接口包须改（今接口包之默认导入皆空）。
- 着色之文与底层之文导多项默认导入者，仅类型上有所支持，未有专试。
- 同一进程中，包文有改，已验之多文名不复验其重名。
- 语言服务尚未为「默认导入」之目生跳转。
- 读旧式包上下文时，包述中「默认导入」见于注释或书作他式者，扫描器不识。
