# 豫构接口绑定

以 `./豫构。林檎。豫行 接口绑定 规范包 适配包 实现模块。豫 输出目录` 行之。此豫构之令也（源在 `应用/豫构/发行/接口绑定。豫`），先于进程内以接口检查核纯约与宿主实作之包籍、版本、方向及源签；合则抄实现模块于构建目录，以规范包名造可编之绑定包，存第四式规范清单。客源码所依所导，皆公约之包籍；构建时包境方指此绑定。

绑包中之实现模块依接口模取名 `名。接口。豫`，不照适源之 `名。豫` 而抄：模文乃带接口模之名，绑适之宿主构与不绑之单元、显式文件构于同一接口模算得同一包内相对之径；阶缓以绝径易得之信标同，二境乃得共一缓，易境而还者亦常为本目下实有之接口模文（#1196）。

首版惟单模块、宿主所供之接口包。输出须在暂构目录；适配之私依随生成包，不易纯约之公依。浏览器与云工可各以异适配承同一接口；`宿主清单来源.txt` 记本次所选适配之簿径，不可但据接口名揣宿主。常编译器未能直析无体之 `。接口。豫`，故此为构时绑定。成品由装载包具集客需、宿供二簿，平台入口先核之；今 Wasm 通桥无逐术之名，故逐术之证仍在实跑。
