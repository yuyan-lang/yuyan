# 仓库包构建

于仓根行豫构。包名取 `。包。豫` 之文件名，其所在即包根。配置唯解语法，不行其文。主名与依赖之制，见[包系统](../包系统.文言.md)。

## 目录

仓根惟五目：`库/` 藏众用之库，依父库层层而置；`应用/` 藏可执行之程序，分发布、网页汇编、文档站、开发工具诸组，另有豫言编译器、豫构、性能研究、本地模型验收；`豫言操作系统接口/` 为带回收之接口；`豫言操作系统底层接口/` 为无回收之底层接口；`豫言操作系统/` 为其实现，内有宿主、适配、装载、裸机，及操作系统之工具（`应用/`）。

库之试置其库下之 `测试/`；试若须外依，则于其处别立试包（如 `库/标准库/测试` 之「标准库测试」），不登为子包。唯一应用所用之库，置其应用下之 `库/`；众用者乃入顶层 `库/`。分组与父库之目，唯物理之排，不改包名，不改导入，不登「包含在」。原生运行时之构建与产物在 `豫言操作系统/宿主/原生/运行时支持库/`，编译器成 WasmGC 时读 `豫言操作系统/宿主/网页汇编/运行时.wat`。自二〇二六年九月二十七日，种子与编译器皆用此二处，仓根不复留兼容之径。

## 包界

库有标准库、单元测试、癸象工具、网页客户端、云工宿主、浏览器宿主、构建基础、编译器核心、包配置、源码排版诸包（单元测试至浏览器宿主五者旧合为拓展库，今各自成包；旧之网页服务端无所用，简易网页服务器自具其能，故删之）；工具包唯数据库连接所用，移入其下之 `库/`。标准库无外依；构建基础司包定位、上下文与并行调度，不依编译器。编译器居 `应用/豫言编译器`，依标准库、癸象工具、构建基础。包配置用编译器之 parser；豫构复依包配置，故不可反使编译器依豫构。

工具各有目录、包籍与入口，不复立工具总包，分居 `应用/<组>/` 与 `豫言操作系统/应用/`。共享排版之术别置库/源码排版。语言之试为测试包，居 `应用/豫言编译器/测试`；文档及其例为文例包，居 `应用/豫言编译器/文档`；性能研究居 `应用/性能研究`。标准库之试居 `库/标准库/测试`（「标准库测试」），免反依成环。测试有预期失败之文，不可尽以构建成功为验。`*_v0` 不察。

## 导入

```text
寻观「标准库」之书。
寻观「标准库」之「数据结构」之「多态列」之书。
寻观「构建基础」之「包定位」之书。
```

首例独书标准库，则取 `库/标准库/总集。豫`，模块仍称标准库。众包同此法：总集须手书，缺则报，不择他书，不循当前目录。内核入标准库目录。总集非程序入口，不删诵，不易重导出之义。

库、应用及其下分组之目，皆为分类，非导入之名；各包同位。旧标准库转发书与特殊搜索之途皆除。

包可用「包含在」「包含包」二字段成组：父登记其直子，子明其父。依父，即得以 `父之子之模块` 引其子之模块；路径止于子，则取子之总集。成组乃逻辑之系，不改包名，不系于目录之相套。字段、校验与上下文，见[包系统](../包系统.文言.md)。

## 构建

```sh
make 豫构
make 类型检查 豫构测试
./yy豫构 检查 豫言编译器
./yy豫构 构建 豫言编译器 --输出 yy编译器
./yy豫构 构建 文档网站生成器 --输出 yy文档网站
./yy豫构 构建 标准库测试 数据结构 可选值。测试 --输出 yy可选值测试
./yy可选值测试
```

构建与类型检查可于包名后明言入口各段，不带扩展名，不复书包名。不言则取包文件之入口。无默认入口者仍可供依赖，亦可明择程序而建之。入口虽异，不越子包，不宽直依之禁。

## 初举

发布包同造 yy_bs_stable 与 yy豫构_stable，两种置仓根。make 自初级即由稳定豫构按包图造 yy2_bs、yy3_bs、yy4_bs，比定点，再造正式豫构；不复造单文件引导器。

文件式编译命令仍可用，然皆委豫构，非旧搜索也。行 `./yy豫构 自举包 --输出 dist/新包`，导出两种；目录须新，统一正则生 C，唯取此次编译之闭包。

依赖、位置、子包之界有变，则缓存别域，不误用旧绑定。原生经统一正则生 C，以 clang 链接；运行时循 Make。远程获取、版本求解与锁文件，皆未设。
