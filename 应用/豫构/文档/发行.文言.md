# 豫构发行

`豫构 发行` 构豫言之应用为可径行于宿主之发行物。宿主有四：云工（Cloudflare Workers）、浏览器、节点（诺驿单文之发行包）、原生（本机可执行之文）。读应用之包描述，循依赖而尽取其闭包，于所用每 `豫言操作系统XXX` 接口依宿主择适配而绑之，书包上下文，编应用，抄宿主之壳，终封接口之清单。接口检查、接口绑定、装载接口皆成于豫构之进程；编译器缺省即豫构自身。

豫构发行以豫言书之，源在 `应用/豫构/发行/`。应用编为 WasmGC；值桥依编译器核心之结构径书之；JS 外壳抄自浏览器或云工之宿主库，唯载 Wasm、传宿主之能，应用之法悉在豫言。

## 用法

```sh
豫构 发行 <云工|浏览器|节点|原生|豫行> <应用目录> <输出目录> \
  [--包根 <目录>]… [--许可 <文件>|-] [--命名入口 <名>] [--启动器 <文件>]… [--编译器 <路径>] [--类型检查]
豫构 发行 <云工|浏览器> <入口源码> <输出目录> --包上下文 <文件> \
  [--许可 <文件>|-] [--命名入口 <名>] [--编译器 <路径>]
```

`豫构` 谓仓根之 `./yy豫构.exe`；轩窗或惟有 Wasm 工具链者，书 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm`。`豫构 发行 --帮助` 陈其用法。

**构建根**：行于构建根之目录。构建根含 `库/`（标准库与内置基础库）、`豫寓榫卯/` 与 `豫言操作系统/`（`适配/`、`宿主/`、`装载/`）。语言仓根本身即构建根，云仓之 `dist/构建源码` 亦然。原生之模又用构建根之执行器 `yy执行器。树码`（「全部」生之）。诸目录可为指向语言仓之符号链接：豫构发行以规范化（解符号链接后）之实径书包上下文，盖包上下文须规范绝径，且编译缓存以径计，同一源码唯可以一径见也。

**参数**（选项可书于位置参之前、之间、之后）：

- `云工|浏览器|节点|原生|豫行|模拟`：宿主之模（豫行与模拟二模见下同名二节）。
- `应用目录`：含 `入口。豫`（或脚本 `入口。脚本。豫`，为须导入测试之验收应用）与恰一包描述之目录。
- `输出目录`：产物之目录；构建前先删之（见「产物与临时文件」之安检）。
- `--包根 <目录>`：可重复，指诸库包所在之目录（递归以寻），唯认 `<包名>。包。豫`。目录相对构建根，亦可书绝径；同一文件经数包根而重见者，只算其一。
- `--许可 <文件>|-`：云工模之许可文件；缺则取 `<应用目录>/许可.json`（有则用），否则不用；`-` 明示不用。他模不用许可文件，给之则拒。
- `--命名入口 <名>`：唯云工模用，须为 ASCII 标识符（见下「命名入口」）。
- `--入口 <文件名>`：唯模拟模用，入口之文（对应用目录），缺省 `模拟验收。脚本。豫`。
- `--编译器 <路径>`：缺省用豫构自身（原生 `yy豫构.exe` 或 `yy豫构.wasm`）；名无斜杠者补 `./`。
- `--类型检查`：唯对入口验类（编译器加 `--type-check-only --parallel -j 24`，诊断直出于终端），不出产物，不装清单。
- `--包上下文 <文件>`：依所授包上下文径构之（见「授包上下文」）。
- 编译器恒加 `--parallel -j 24`（构建并行不少于二十）。

**所行**（依次）：

1. 应用目录须恰有一 `*。包。豫`，读其名称、所有者与依赖；无之，则须恰有一 `*。包。豫.txt`（语言仓一致性验证之目录，以包描述存为 `.txt`，免为全仓库包发现误认为包）：此时复制应用目录于 `dist/.自动构建/<输出名>/应用`，并改 `.txt` 为原名，此后以副本为应用目录。
2. 循依赖而尽取其闭包：`豫章` 与内置基础库（`考课`、`结绳`、`营造`、`译场`、`网页客`、`云工东道`、`网览东道`；网页客户端之源码高亮用编译器核心之析辞，故编译器核心及其所依之构建基础亦内置）内置；`豫言操作系统XXX` 谓操作系统接口 `XXX`；余依赖，于诸 `--包根` 中寻恰一 `<名>。包。豫`，无则告，多则告（明包名、何者所依、所搜之包根或诸候选），并递归解其依赖；有环则以已访之表截之。库与应用之序：依赖在前，应用居末；接口依名之字节序，不随依赖声明之序与包根之序，故产物可复现。诸包所有者须为「豫言」，依赖须为平铺之名列，包名与接口名不得空、不得为 `.`、`..`，亦不得含斜杠、反斜杠、制表与换行。
3. 每接口 `XXX`（并接口包所依之接口，如显示依基础）：接口目录 `豫寓榫卯/XXX`（一或数 `*。接口。豫` 模块）；适配依其模之宿主支持清单 `豫言操作系统/宿主/<节点|浏览器|云工>/宿主支持清单.tsv` 择之（每行“接口名⇥适配目录⇥宿主支持清单文件”）：适配书 `-` 者应用供之，书 `宿主` 者宿主以带型之导入径供之，皆不绑，包上下文直指接口之规范包；表所不载之接口告“宿主不支持接口”。宿主径供之接口所依之接口亦须书 `宿主`，否则告之，以一类于客内惟一表故。节点之模必有表；浏览器、云工之模无表，则适配目录依宿主之模取其先存在者：云工模 `豫言操作系统/适配/XXX云工`、`XXX`，浏览器模 `XXX浏览器`、`XXX`。原生之模依次择 `XXX原生`、`XXX节点`（诺驿之适配唯用豫言之库，原生共之）与共用 `XXX`，适配之余子包可由 `--包根 豫言操作系统/适配` 得之。适配目录须有与每接口模块同名之实现模块。先删旧 `dist/.自动构建/<输出名>/操作系统绑定/XXX`，后行接口绑定（同 `豫构 接口绑定 <接口包描述> <适配包描述> <诸实现模块…> dist/.自动构建/<输出名>/操作系统绑定/XXX`）。无适配则告，并示他宿主之适配存否。适配包描述所依，非内置亦非接口者（外库，若张量适配所依之 `金属`），并其所依并入包节点，居应用之前，且书于该接口绑定包之上下文行，应用不必依之；外库先求于诸 `--包根`，不得则求于构建根之 `库/`（`--包根` 同名者先）；外库又须应用所未依之接口者，补其接口（并其接口之闭包）入集，自绑而复行一遍。
4. 书包上下文于 `dist/.自动构建/<输出名>/包上下文`（一行一包：标准库、诸内置基础库、诸接口绑定包（所依他接口与其适配所依之外库列为其依）、诸库、应用；径皆规范绝径，字段以真制表符隔之）。
5. 依包上下文构之：云工与浏览器之模编 `程序.wasm`、书 `值桥.wasm` 而抄宿主之壳（与 `--包上下文` 之式同一函）；节点之模又编文件定位、传输控制二共核，书 `启动.mjs` 与 `清单.json`；原生之模由编译器于终链径出 `<输出目录>/程序.exe`（编译器之参 `--目标 本机 --执行器 <构建根>/yy执行器。树码`，不经 `.wasm`）。原生之验类循普通客体之法。
6. 装接口之清单（同 `豫构 装载接口 <输出目录> dist/.自动构建/<输出名>/操作系统绑定/<诸接口>…`），书 `接口要求组.json` 与 `宿主提供组.json`。宿主径供之接口亦有此目，惟含接口检查所书之 `规范清单.json` 与 `宿主清单来源.txt`（取支持清单之第三栏）；应用所供之接口无目（待办事项：浏览器、云工之模未核应用所供之接口）。

**产物与临时文件**：

- `<输出目录>`：先删后建。安检：其末段不得为空、`.`、`..`；已存在者须为目录；不得在 `dist/.自动构建` 之内；不得等于构建根、应用目录、任一包根，亦不得为其上级目录。
- `dist/.自动构建/<输出名>/操作系统绑定/<接口名>/`：接口绑定包，每次构建皆重绑；依输出名而分，数应用得同时构之。置于隐目 `.自动构建` 之下者，包之发现（豫构与接口检查）不入隐目：接口相依时（如图形显示依显示与图形处理器），检查后绑之接口不兼见规范包与先绑同名之绑定包而告“包短名不唯一”，豫构亦不告“包名冲突”。节点之模之绑定在 `dist/.节点绑定/`。
- `dist/.自动构建/<输出名>/`：所书之 `包上下文`（可以复查）与 `.txt` 描述时之 `应用/` 副本。云仓与语言仓皆已忽略 `/dist/`。

**误告**：皆以中文书之，明其因，首书 `豫构 发行失败：`。含：当前目录非构建根；缺工具或文件；应用目录无包描述或有多个；包描述格式不对（带文件名与病因）；依赖包不得、候选有多、名称或所有者不符；接口无适配；接口检查不过；输出目录不安全；编译器等外部命令败（带命令行与退出码，编译败者兼附编译器之输出）。败则退出码一。

**例**：

```sh
# 云工：云工作台用户目录持久对象（云仓；于构建根中，包根书绝径）
豫构 发行 云工 $C/应用/豫言云工作台/用户目录应用 dist/云用户目录 --包根 $C/应用/豫言云工作台/库 --包根 $C/库
# 浏览器：包服务阅读页
豫构 发行 浏览器 $C/应用/包管理服务/阅读应用 dist/阅读应用 --包根 $C/应用/包管理服务/库
# 语言仓一致性验证（.txt 描述，无需包根），产物 dist/日志一致性
豫构 发行 云工 豫言操作系统/适配/日志/一致性验/应用 dist/日志一致性
# 节点发行包（一致性之驱见 豫言操作系统/宿主/节点/一致性验证/）
豫构 发行 节点 豫言操作系统/宿主/节点/一致性验证/应用 dist/节点一致性
```

**须知**：编译缓存之目以编译器 `.wasm` 文之 SHA-256 名之；字节同之编译器共其缓存。编译缓存原子而书，绑定依输出名而分，数构建得同时行之。清单之构造编号取自编译器运行时之序，接口检查每始则复其序于进程之始值，故一进程检数接口，编号与独行者同；接口检查历接口文皆按 UTF-8 字节为序，故原生与诺驿所生之清单同。已知之限：唯支持所有者为「豫言」之包；依赖须为平铺之名列；接口逐一绑之（不并行）；编译败时，编译器之全部输出原样带回，颇长。

**单元测试**（纯函数之部：包描述之解析、依赖之解析、包上下文之书、接口适配之择、命令行之析）在 `应用/豫构/发行/`，测试名依次为 `文本工具。测试`、`包描述。测试`、`依赖解析。测试`、`上下文生成。测试`、`接口适配。测试`、`自动参数。测试`、`宿主构建。测试`。于语言仓根构而行之，例如：

```sh
豫构 构建 豫构 发行 包描述。测试 --输出 yy发行包描述测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy发行包描述测试.wasm
```

## 豫行模式

`豫构 发行 豫行` 编应用为豫行之文（[提案〇〇〇二一](../../../提案/00021-豫行跨平台运行.汉语.md)）：一豫行于豫言操作系统与诸宿主之豫行启动器皆可行。适配之择同原生之模（`XXX原生`、`XXX节点`、`XXX`），显示、声出与设备之口（询设备、网卡、声卡，关机、重启）依豫言操作系统由执行器径供；编译器之参为 `--目标 本机 --目标系统 豫言 --目标架构 <构> --执行器 <构建根>/yy执行器。树码`。

- 产物：臂为 `程序臂。豫行`，兼为 `程序兼。豫行`。无 `--启动器` 则唯编本机之构；有则编诸启动器之构。
- `--启动器 <文件>`（可重，唯豫行之模用之）：豫行启动器之可行之文。依文首识其宿主（Mach-O 六十四位与 ELF 之臂、兼，PE 之兼），取同构之豫行合为单文件 `程序<宿主之名>`：`程序林檎臂`、`程序林臂`、`程序林兼`、`程序轩窗兼.exe`，加执行之权（宿主为轩窗则不加）。单文件于其宿主径行，诸参皆予豫行。

```sh
豫构 发行 豫行 <应用目录> dist/某应用 --启动器 yy豫行启动器.exe --启动器 yy豫行启动器林兼
```

## 模拟模式

`豫构 发行 模拟` 编应用并其验收之本为一工具宿主之程，行于[模拟宿主](../../../库/沙盘/包说明.文言.md)：页、事、时钟、随机与网皆纯豫言之内存所成，由测试制之，验收全以豫言书之。

```sh
./yy豫构.exe 发行 模拟 <应用目录> <输出目录> [--入口 <文件名>] [--包根 <目录>]…
node 豫言操作系统/宿主/节点/宿主.cjs <输出目录>/程序.wasm
```

- 入口：`--入口` 所授之文（对应用目录）；缺省为应用目录之 `模拟验收。脚本。豫`，无则同他模（`入口。豫`，次 `入口。脚本。豫`）。验收之本居所验应用之目（可执行之包不可被依），以 `寻「应用名」之「入口」之书。` 导应用，呼 `「入口」之「入口」`。
- 适配：依 `豫言操作系统/宿主/模拟/宿主支持清单.tsv` 择之。浏览器一侧之接口绑 `XXX模拟` 适配（其态在模拟宿主），网址、网址定位、网址查询绑本不依宿主之纯豫言适配。表所不载之接口则构败。
- 浏览器宿主：径依浏览器宿主库之应用，构时以 `库/网览东道沙盘` 代之（抄至 `dist/.自动构建/<输出名>/浏览器宿主/` 而易名为浏览器宿主），柄之反照、事、fetch 诸原语皆落于模拟宿主。
- 模拟宿主：自并入包上下文，并加于应用之所依，验收之本可径 `寻观「沙盘」之书。`；应用之包描述不须改。
- 产物：惟 `<输出目录>/程序.wasm`，常工具宿主之程，无 JS 之壳、启动之文与装载之清单；不读许可。程依验收之果设退出码（`沙盘报`：有败则一）。读页模诸相对之径，以运行时之今目录为准。
- 可与 `--类型检查` 合用，惟验验收之本之类。

## 授包上下文

适配之目得以同名普通 `.豫` 文供应用接口之纯豫言回调接线，如 `事务处理。豫` 应规范之 `事务处理。应用接口。豫`。绑时先抄接线而存应用接口之文名；余应用接口用规范之声。持久事务模拟以此径传事务之引用态于试者所登真应用回调。

手书包上下文者（如云仓构建程序）以 `--包上下文` 径构之，唯用于云工与浏览器之模。次位置参为入口之源；不读包描述、不绑接口，产物之 `接口要求组.json` 与 `宿主提供组.json` 先书为待封装（包上下文无接口绑定则书空列），用者另以 `豫构 装载接口` 封之：

```sh
豫构 发行 浏览器 应用/入口。豫 dist/浏览器 --包上下文 包上下文
豫构 发行 云工 应用/入口。豫 dist/云工 --包上下文 包上下文 --许可 许可.json --编译器 ./yy3_bs.wasm
豫构 发行 云工 应用/入口。豫 dist/云工 --包上下文 包上下文 --许可 许可.json --命名入口 CloudModel
```

许可书按 KV、R2、D1、SERVICE、DO、ASSETS、QUEUE、EMAIL 列可授之绑定；未书 `--许可` 则不用许可之文。云工之 `入口.mjs` 可作 Wrangler 主入口，同一豫言 Wasm 可受 fetch 或 queue 之事；浏览器则呼 `启动豫言浏览器应用()`。编应用时禁旧缓存，以防共享工作树旧物混入；豫构发行不立部署配置，亦不改云仓。

## 宿主之壳与产物

**命名入口**：`--命名入口` 唯云工用，以一 ASCII 标识符为命名 `WorkerEntrypoint` 之导出名。名为 `CloudModel` 者，其请以 `service-fetch` 事入豫言；公域默认请仍以 `fetch` 入。Wrangler 可以 `entrypoint: CloudModel` 指服务绑定。Wrangler 4.129.0 本地同 Worker 绑定已验二路异应；非法别名见拒。自定 RPC 法、多个别名及云上部署留待后版。详 [Cloudflare 命名入口文档](https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/rpc/#named-entrypoints)。

浏览器产物又有 `自动启动.mjs`。页载 `<script type="module" src="/产物/自动启动.mjs?标识=应用根"></script>`，无需别书调用 JS；有 `id="应用根"` 始取 Wasm 而启之。省标识则即启。真 Chrome 已验有标则行豫言、无标则略之且不取 Wasm。若欲自主持客器之寿，仍可呼 `入口.mjs` 所出之明启函数。

浏览器产物又抄 `图形.mjs`：显示、图形处理器、图形显示诸接口之宿主术，`宿主.mjs` 初用此诸能乃动态载之，不用之应用不取此篇。浏览器发行亦抄 `文件能力.mjs` 与 `控制台.mjs`，供宿主需载已授目录之文件原语与控制台之能。

云工与浏览器皆抄 `中央张量.mjs`（张量计算接口中央处理器后端之宿主之部，在浏览器宿主之目，二宿主共之；`宿主.mjs` 初用张量之原语乃动态载之），浏览器又抄 `中央张量工作线程.mjs`（跨源隔离之页之工作线程之本）。包境有张量计算之绑定包（`操作系统绑定/张量计算/`）则又编中央张量内核之模：由包境中标准库之径推 `库/` 之目，于应用包境之旁书第三版之包境（`<包上下文>.中央张量内核`：底层库、中央张量内核、中央张量内核模块，皆底层之模），以同一编译器编 `库/底层库/中枢算阵/模块/单线程。底层。豫` 为 `中央张量内核.wasm`；浏览器又编 `多线程。底层。豫` 为 `中央张量内核多线程.wasm`；云工则于 `动态资源.mjs` 之末加 `export {default as 中央张量内核模块} from './中央张量内核.wasm';`，入口之壳据之以内核之模付宿主（Workers 不得于行时编 Wasm 之字）。见[张量计算网页适配](../../../豫言操作系统/适配/张量计算/说明.文言.md)。

浏览器产物并抄 `工作线程自动启动.mjs`。工客豫言源若别于页客，宜构于页产物子目录；页客以子目录壳之相对址造工。壳于 Dedicated Worker 内载同目录二 Wasm；工客先以自身柄听主信，继以豫言回信。真 Chrome 已验页、工皆为豫言 Wasm 而初信与回信往还。

云工 `入口.mjs` 又出通用 `豫言持久对象` 类，可于 Wrangler 持久对象绑定及 SQLite `exports` 引之。类之外层分派 fetch、alarm 唯属宿主，实务之断与久态读写由同一豫言 Wasm 行之。

云工模式又出 `动态资源.mjs`，汇隔离入口、宿主与句柄之源码，兼值桥 Wasm 字节，以备动态载器；又附文件式程序之隔离运行入口 `隔离运行客.mjs` 与浏览器编器宿主 `编译宿主.mjs`（内存文件系与 `执行模块`），以供[隔离运行公约](../../../豫寓榫卯/隔离运行/规范.文言.md)之云工适配。实务唯书豫言；用 Loader 者，许可书之 `LOADER` 当列其名，Wrangler 须置 `worker_loaders`。同号 `get` 之码与限额须恒同。

云工之模又读应用目录（`入口。豫` 所在）之可选文 `执行配置.json`，析为 JSON 而规整之，书为 `动态资源.mjs` 之导出常量 `执行配置`，无文则书 `{}`（JSON 非法则构建败）。其文惟调各事类之墙钟时限（如 `{"事件时限毫秒":{"durable-alarm":900000}}`），非属 `许可.json`，亦不易许可依绑定种类之结构；产物之 `入口.mjs` 于加载时验之而用之，配置非法则 Worker 加载败。入口壳以命名空间导入读此导出，缺此导出则守默认时限。其式、默值与上限见 `豫言操作系统/宿主/云工/说明.文言.md`。

**节点发行**：节点之模之发行包有 `程序.wasm`、内联共用模之 `启动.mjs`、发行清单 `清单.json`，及纯豫言共核 `yy文件定位共享.wasm` 与 `yy传输控制共享.wasm`（以同次发行所择编译器，自客体二号底层入口构之）。启动文内联共用之 `终端输入.mjs`、控制台之能、文件定位胶水与 FFI 系统胶水；客宿主供标准库旧终端原语，清能力则复输入之制。应用依 `--允许源` 所录地址端口授网事；监听用明录之源，连接亦得用发行既有全源之配。造终端浏览器之发行包，默认通诸 HTTP(S) 源，网页、外脚、样表与转向皆毋须逐以 `--允许源` 授之；余应用循逐源之授。Node 公共控制台正式探针之构、装载及授而读写实验皆过；浏览器控制台实页之验留待后版。

**用户态系统发行**：仓库目标 `用户态系统节点发行` 抄当前命令壳之源与 `应用/豫构/发行/原壳发行/` 之包述之模于 `dist/.用户态系统节点/应用`，以 `豫构 发行 节点` 绑控制台、文件、子程序、字体、显示诸接口，出 `yy用户态系统节点发行`，复核其发行而附文楷字体与许可；`用户态系统浏览器发行` 同此，出 `yy用户态系统浏览器发行`。行 `豫构 目标 用户态系统节点发行 -j 24`；自举工具已具者可加 `--不连带`。详见 `应用/豫构/发行/原壳发行/说明.文言.md`。
