# 手写数字训练

这是用[深度学习框架](../../../库/深度学习/框架/包说明.汉语.md)在 MNIST 上训练多层感知机的路一应用：784 → 隐藏 → 10，修正线性，软最大交叉熵，默认亚当优化器。每轮打乱训练集、逐批训练，打印训练损失、训练与测试正确率和用时，最后打印最终测试正确率。`--合成` 改用合成数据（10 类、每类一个 784 维原型加均匀噪声），不读文件，用来跑通整条流程。

## 包身份

所有者：豫言。包版本：0.1.0。本包为可执行文件（入口 `入口`，产物名 `yy手写数字训练`），登记在「人工智能」分组下。它实现启动接口，经深度学习框架用张量计算、文件、压缩与张量文件接口，所以用 `yy双宿主构建` 的节点模式构建成诺节发行包。

## 构建与运行

在仓库根目录（需先有 `yy双宿主构建.wasm` 与 `yy4_bs.wasm`）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/手写数字训练 dist/手写数字训练 --包根 库/深度学习
node dist/手写数字训练/启动.mjs --授权只读目录 数据=<MNIST 目录> -- --轮数 5
node dist/手写数字训练/启动.mjs -- --合成 --轮数 3
```

数据目录须以“数据”为名只读授予，目录（或 `--子目录` 指定的子目录）里放 `train-images-idx3-ubyte`、`train-labels-idx1-ubyte`、`t10k-images-idx3-ubyte`、`t10k-labels-idx1-ubyte`；解压后的文件与 `.gz` 原件都行，先找解压后的。应用参数写在 `--` 之后：

| 参数 | 含义 |
| --- | --- |
| `--轮数 N` | 训练轮数，默认 5 |
| `--批大小 B` | 默认 100 |
| `--隐藏 H` | 隐藏层宽度，默认 256 |
| `--优化器 名` | `亚当`（默认）或 `随机梯度下降` |
| `--学习率 L` | 亚当默认 0.001，随机梯度下降默认 0.1 |
| `--动量 M`、`--权重衰减 W` | 随机梯度下降的动量（默认 0.9）；两种优化器的权重衰减（默认 0） |
| `--种子 S` | 初始化与打乱的伪随机种子，默认 0；同一种子结果可复现 |
| `--子目录 路径` | 数据文件在授权目录里的子目录，默认为授权目录本身 |
| `--训练样本数 N` | 只用训练集的前 N 个样本 |
| `--合成` | 用合成数据（训练 6000 个、测试 1000 个） |

参数不对时打印用法并以退出码 2 结束。宿主选项 `--张量线程数 N` 写在 `--` 之前。

## 结果

2026-09-30 在 macOS arm64（诺节 26.3.0，张量接口 0.3.0，中央处理器后端）上用默认参数（784→256→10，亚当，学习率 0.001，批大小 100，种子 0）训练 5 轮，测试正确率依次为 95.57%、96.82%、97.33%、97.77%、97.74%，最终 97.74%（9774/10000）；两次运行的数值逐位相同。载入四个解压后的文件约 2 至 3 秒；每轮训练 26 至 55 秒、评估约 0.5 秒，随主机负载（当时负载平均 100 以上）波动。合成数据 3 轮后测试正确率 100%。

## 已知限制

- 速度受限于诺节宿主：逐元运算与视图写入在主线程单线程计算，亚当更新约占每步用时的三分之二。
- 文件接口的路径不接受 `./` 开头，所以 `--子目录 .` 与省略相同。
