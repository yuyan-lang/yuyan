# 手写数字训练

此以[深度学习框架](../../../库/深度学习/框架/包说明.文言.md)训多层感知机于 MNIST 之路一应用也：784 → 隐 → 10，修正线性，软最大交叉熵，默以亚当为优化之器。每轮乱训练之集、逐批而训，书训练之损、训练与测试之正率及所用之时，终书最终测试之正率。`--合成` 则用合成之数据（十类，每类一 784 维之型加均匀之噪），不读文件，以通全程。

## 包之身份

主：豫言。版：0.1.0。可执行文件之包（入口 `入口`，产物名 `yy手写数字训练`），登于「人工智能」之组。实启动之接口，经深度学习框架用张量计算、文件、压缩与张量文件之接口，故以 `yy双宿主构建` 之节点式构为诺节之发行包。

## 构与行

于仓之根（须先有 `yy双宿主构建.wasm` 与 `yy4_bs.wasm`）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/手写数字训练 dist/手写数字训练 --包根 库/深度学习
node dist/手写数字训练/启动.mjs --授权只读目录 数据=<MNIST 之目> -- --轮数 5
node dist/手写数字训练/启动.mjs -- --合成 --轮数 3
```

数据之目须以“数据”之名只读授之，目中（或 `--子目录` 所指之子目中）置 `train-images-idx3-ubyte`、`train-labels-idx1-ubyte`、`t10k-images-idx3-ubyte`、`t10k-labels-idx1-ubyte`；已解之文件与 `.gz` 原件皆可，先寻已解者。应用之参书于 `--` 之后：

| 参 | 义 |
| --- | --- |
| `--轮数 N` | 训练之轮数，默五 |
| `--批大小 B` | 默一百 |
| `--隐藏 H` | 隐层之宽，默二百五十六 |
| `--优化器 名` | `亚当`（默）或 `随机梯度下降` |
| `--学习率 L` | 亚当默 0.001，随机梯度下降默 0.1 |
| `--动量 M`、`--权重衰减 W` | 随机梯度下降之动量（默 0.9）；二器之权衰（默零） |
| `--种子 S` | 初始与乱序之伪随机种，默零；同种则其果可复 |
| `--子目录 路径` | 数据文件在所授之目中之子目，默为所授之目 |
| `--训练样本数 N` | 惟用训练集之前 N 样 |
| `--合成` | 用合成之数据（训练六千、测试一千） |

参误则书用法，以退出之码二终。宿主之选项 `--张量线程数 N` 书于 `--` 之前。

## 所得

2026-09-30 于 macOS arm64（诺节 26.3.0，张量接口 0.3.0，中央处理器之后端）以默参（784→256→10，亚当，学率 0.001，批大 100，种零）训五轮，测试之正率依次为 95.57%、96.82%、97.33%、97.77%、97.74%，终为 97.74%（9774/10000）；再行之，数值逐位相同。载四已解之文件约二至三秒；每轮训练二十六至五十五秒、评估约半秒，随主机之负（时负载均值逾百）而动。合成之数据三轮后测试之正率百分之百。

同日易用张量接口 0.4.0（逐元之算入线程之池，亚当之更与就地线性组合于宿主一次而成）而再行之：测试之正率依次为 95.57%、96.77%、97.37%、97.77%、97.74%，终仍为 97.74%；每轮训练十一至二十一秒（负载均值百至百三十），每步约十二毫秒（前向约五、反向约六、更约 0.7 毫秒），前于接口 0.3.0 约三十一毫秒（更约二十一毫秒）。

## 已知之限

- 文件接口之径不受 `./` 起首者，故 `--子目录 .` 与省之同。
