# 语言模型训练

此以[深度学习框架](../../../库/深度学习/框架/包说明.文言.md)训词级语言之模于 Penn Treebank 之路一应用也（needle 作业四之 train_ptb）：嵌入 → 序列之模 → 线性之层，序列之模可择二层长短期记忆（默）、简单循环或变换之器。训用截断反传（每批之后分离隐态而常驻之）与梯之裁；每若干批书其段之均损、困惑度与每批之时，每轮书训练与验证之困惑度及所用之时，终书测试之困惑度。

## 包之身份

主：豫言。版：0.1.0。可执行文件之包（入口 `入口`，产物名 `yy语言模型训练`），登于「人工智能」之组。实启动之接口，经深度学习框架用张量计算与文件之接口，以 `yy双宿主构建` 之节点式构为诺节之发行包。

## 数据

用 Mikolov 所预处之 PTB（词表万，稀词为 `<unk>`，数为 `N`）：`ptb.train.txt`、`ptb.valid.txt`、`ptb.test.txt`，出自 https://raw.githubusercontent.com/wojzaremba/lstm/master/data/（同 needle、torchtext，MD5 依次为 f26c4b92c5fdc7b3f8c7cdcb991d8420、aa0affc06ff7c36e977d7cd49e3839bf、8b80168b89c18661a38ef683c0dc3721）。每行之末加 `<eos>`，训练 929589 词、验证 73760 词、测试 82430 词。

## 构与行

于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/语言模型训练 dist/语言模型训练 --包根 库/深度学习
node dist/语言模型训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<PTB 之目> -- --轮数 3
node dist/语言模型训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<PTB 之目> -- --模型 变换器 --轮数 5
```

数据之目须以“数据”之名只读授之；`--张量后端 金属 --允许系统库调用` 用苹果之 GPU（书于 `--` 之前）。应用之参书于 `--` 之后：

| 参 | 义 |
| --- | --- |
| `--模型 名` | `长短期记忆`（默）、`简单循环`（双曲正切）或 `变换器` |
| `--轮数 N` | 默一 |
| `--批大小 B`、`--序长 T` | 默二十、三十五（截断反传之长） |
| `--嵌入维 E`、`--隐藏 H`、`--层数 L` | 默二百、二百、二；变换之器之出维等于嵌入维 |
| `--头数`、`--头维`、`--前馈` | 变换之器之头数、每头之维与前馈之维，默四、五十、八百 |
| `--丢弃 P` | 嵌入与序出（变换之器兼各层之内）之丢弃率，默 0.2 |
| `--裁剪 C` | 梯之总范之上限，默 0.25，零则不裁 |
| `--优化器 名`、`--学习率 L` | `随机梯度下降`（学率二十，同 PyTorch 之例）或 `亚当`（学率 0.001）；不给则变换之器用亚当，余用随机梯度下降 |
| `--最多行数 N` | 每文件至多读 N 行，零则尽读 |
| `--验证批大小 B` | 默十 |
| `--报告间隔 N` | 每 N 批一书，默二百，零则不书 |
| `--种子 S`、`--子目录 路径` | 默零、所授之目 |

参误则书用法，以退出之码二终。

## 所得

2026-09-30 于 macOS arm64（苹果 M5 Pro，诺节 26.3.0，张量之接口 0.4.0，金属之后端）以全量之 PTB 训之，余皆默参。本机同时有他会话方构建、行大模，主机之负均十至百零五，GPU 亦见占，所费之时如实录之。

| 模 | 轮 | 训之困惑度 | 验之困惑度 | 训之时（秒） | 验之时（秒） |
| --- | --- | --- | --- | --- | --- |
| 长短期记忆 | 1 | 382.94 | 213.03 | 1225.8 | 21.2 |
| 长短期记忆 | 2 | 174.75 | 158.66 | 647.5 | 17.1 |
| 长短期记忆 | 3 | 132.82 | 137.31 | 663.7 | 19.1 |
| 变换器 | 1 | 649.02 | 331.10 | 294.1 | 18.7 |
| 变换器 | 2 | 297.65 | 244.76 | 217.2 | 20.8 |
| 变换器 | 3 | 220.81 | 211.34 | 1168.3 | 14.6 |
| 变换器 | 4 | 181.92 | 190.79 | 260.9 | 3.9 |
| 变换器 | 5 | 155.83 | 174.78 | 234.4 | 4.1 |

- 长短期记忆：二层，嵌入与隐皆 200，参 4653200 个，随机梯度下降（学率 20）、裁 0.25、丢弃 0.2、批大 20、序长 35，每轮 1327 批。三轮之后测之困惑度 134.38；每批约 0.45 至 0.49 秒，首轮负重时 1.1 至 1.4 秒。此三轮乃合全段之入之投为一次矩阵乘之前之版所测；改之后于 2000 行之子集相校，训每批皆约 0.39 秒，验速约增四之一。同子集上中央处理器之后端每批约 0.7 秒；金属之后端减隐维 200 为 20 亦不加速，时几尽费于召宿主。
- 变换器（`--模型 变换器`）：二层，嵌入 200，四头各 50 维，前馈 800，参 4982200 个，亚当（学率 0.001），余同上。五轮之后测之困惑度 165.14；每批约 0.12 至 0.23 秒，第三轮负与 GPU 之占最重时 0.5 至 2.3 秒。

## 已知之限

- 待办事项：长短期记忆每时前向十余、反向二三十小算，每批召宿主数千次（又释之如其数），金属之后端每召之费远大于 GPU 之算；一层全段之入之投已合为一次矩阵乘，欲更速，俟张量之接口有融合之循环单元（或全段之序）之原语、或能合派。
- 无学率之衰与早停。
- 待办事项：2026-09-30 晚张量计算节点之适配加出池与延释句柄（f4dfb2ffa）之后，长短期记忆于金属之后端训十余批则报“张量计算：改形：甲须连续，先紧致化”（改前之适配上同码无恙，上之所得即是）；中央处理器之后端与变换器不与焉，俟适配修之。
