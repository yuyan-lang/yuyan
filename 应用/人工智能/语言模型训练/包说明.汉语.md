# 语言模型训练

这是用[深度学习框架](../../../库/深度学习/框架/包说明.汉语.md)在 Penn Treebank 上训练词级语言模型的路一应用（needle 作业四的 train_ptb）：嵌入 → 序列模型 → 线性层，序列模型可选两层长短期记忆（默认）、简单循环或变换器。训练用截断反向传播（每批之后隐状态分离并常驻）与梯度裁剪；每隔若干批打印这段的平均损失、困惑度与每批用时，每轮打印训练与验证困惑度和用时，最后打印测试困惑度。

## 包身份

所有者：豫言。包版本：0.1.0。本包为可执行文件（入口 `入口`，产物名 `yy语言模型训练`），登记在「人工智能」分组下。它实现启动接口，经深度学习框架用张量计算与文件接口，用 `yy双宿主构建` 的节点模式构建成诺节发行包。

## 数据

用 Mikolov 预处理的 PTB（词表 10000，稀有词为 `<unk>`，数字为 `N`）：`ptb.train.txt`、`ptb.valid.txt`、`ptb.test.txt`，来自 https://raw.githubusercontent.com/wojzaremba/lstm/master/data/（与 needle、torchtext 相同，MD5 依次为 f26c4b92c5fdc7b3f8c7cdcb991d8420、aa0affc06ff7c36e977d7cd49e3839bf、8b80168b89c18661a38ef683c0dc3721）。每行末加 `<eos>`，训练 929589 词、验证 73760 词、测试 82430 词。

## 构建与运行

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/语言模型训练 dist/语言模型训练 --包根 库/深度学习
node dist/语言模型训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<PTB 目录> -- --轮数 3
node dist/语言模型训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<PTB 目录> -- --模型 变换器 --轮数 5
```

数据目录须以“数据”为名只读授予；`--张量后端 金属 --允许系统库调用` 用苹果设备的 GPU（写在 `--` 之前）。应用参数写在 `--` 之后：

| 参数 | 含义 |
| --- | --- |
| `--模型 名` | `长短期记忆`（默认）、`简单循环`（双曲正切）或 `变换器` |
| `--轮数 N` | 默认 1 |
| `--批大小 B`、`--序长 T` | 默认 20、35（截断反向传播的长度） |
| `--嵌入维 E`、`--隐藏 H`、`--层数 L` | 默认 200、200、2；变换器的输出维等于嵌入维 |
| `--头数`、`--头维`、`--前馈` | 变换器的头数、每头维数与前馈维数，默认 4、50、800 |
| `--丢弃 P` | 嵌入与序列输出（变换器还有各层内）的丢弃率，默认 0.2 |
| `--裁剪 C` | 梯度总范数上限，默认 0.25，0 为不裁 |
| `--优化器 名`、`--学习率 L` | `随机梯度下降`（学习率 20，同 PyTorch 例子）或 `亚当`（学习率 0.001）；不给时变换器用亚当，其余用随机梯度下降 |
| `--最多行数 N` | 每个文件至多读 N 行，0 为全读 |
| `--验证批大小 B` | 默认 10 |
| `--报告间隔 N` | 每隔 N 批打印一次，默认 200，0 为不打印 |
| `--种子 S`、`--子目录 路径` | 默认 0、授权目录本身 |

参数不对时打印用法并以退出码 2 结束。

## 结果

2026-09-30 在 macOS arm64（苹果 M5 Pro，诺节 26.3.0，张量接口 0.4.0，金属后端）上用全量 PTB 训练，其余为默认参数。本机同时有别的会话在构建、跑大模型，主机负载平均 10 至 105，GPU 也被占用，用时照实记录。

| 模型 | 轮 | 训练困惑度 | 验证困惑度 | 训练用时（秒） | 验证用时（秒） |
| --- | --- | --- | --- | --- | --- |
| 长短期记忆 | 1 | 382.94 | 213.03 | 1225.8 | 21.2 |
| 长短期记忆 | 2 | 174.75 | 158.66 | 647.5 | 17.1 |
| 长短期记忆 | 3 | 132.82 | 137.31 | 663.7 | 19.1 |
| 变换器 | 1 | 649.02 | 331.10 | 294.1 | 18.7 |
| 变换器 | 2 | 297.65 | 244.76 | 217.2 | 20.8 |
| 变换器 | 3 | 220.81 | 211.34 | 1168.3 | 14.6 |
| 变换器 | 4 | 181.92 | 190.79 | 260.9 | 3.9 |
| 变换器 | 5 | 155.83 | 174.78 | 234.4 | 4.1 |

- 长短期记忆：两层，嵌入与隐藏 200，参数 4653200 个，随机梯度下降（学习率 20）、裁剪 0.25、丢弃 0.2、批大小 20、序长 35，每轮 1327 批。3 轮后测试困惑度 134.38；每批约 0.45 至 0.49 秒，第 1 轮负载重时 1.1 至 1.4 秒。这三轮是把整段输入投影合成一次矩阵乘之前的版本测的；改写后在 2000 行的子集上对照，训练每批都约 0.39 秒，验证快约四分之一。同一子集上中央处理器后端每批约 0.7 秒；金属后端把隐维从 200 降到 20 也不变快，时间几乎全花在宿主调用上。
- 变换器（`--模型 变换器`）：两层，嵌入 200，4 头各 50 维，前馈 800，参数 4982200 个，亚当（学习率 0.001），其余同上。5 轮后测试困惑度 165.14；每批约 0.12 至 0.23 秒，第 3 轮负载与 GPU 占用最重时 0.5 至 2.3 秒。

## 已知限制

- 待办事项：长短期记忆每个时刻前向十来次、反向二三十次小算子，每批几千次宿主调用（外加同样多次释放），金属后端上每次调用的开销远大于 GPU 计算；一层整段输入的投影已合成一次矩阵乘，再快要等张量接口有融合的循环单元（或整段序列）原语、或能合并派发。
- 没有学习率衰减与早停。
- 2026-09-30 晚张量计算节点适配加了输出池与延后释放句柄（f4dfb2ffa）之后，长短期记忆在金属后端上训练十来批后曾报“张量计算：改形：甲须连续，先紧致化”（适配的可池表留下残留记号，不连续的跨步视图混进输出池；上面的结果是改动前的适配上得的）。同日修复后，`--最多行数 1000` 在金属后端上 31 批与验证、测试都跑完，每批约 160–200 毫秒（本机负载约 35），损失与中央处理器一致（训练损失 7.282491 与 7.282102）。
