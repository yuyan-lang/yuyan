# 十类小图训练

此以[深度学习框架](../../../库/深度学习/框架/包说明.文言.md)训 ResNet9（needle 作业四之模型，NHWC 之布）于 CIFAR-10 之路一应用也。每轮乱训练之集、逐批而训，每若干批书其段之均损，每轮书训练之损、训练与测试之正率、每批之时，终书最终测试之正率。默惟读训练集前二千张、测试集前一千张，以行小规模之验；`--训练样本数 0 --测试样本数 0` 则读全量，宜行于金属之后端。

## 包之身份

主：豫言。版：0.1.0。可执行文件之包（入口 `入口`，产物名 `yy十类小图训练`），登于「人工智能」之组。实启动之接口，经深度学习框架用张量计算、文件与张量文件之接口，以 `yy双宿主构建` 之节点式构为诺节之发行包。

## 数据

用 CIFAR-10 二进制版（https://www.cs.toronto.edu/~kriz/cifar-10-binary.tar.gz，MD5 c32a1d4ab5d03f1284b67883e8d87530）解后之 `cifar-10-batches-bin/`：`data_batch_1.bin` 至 `data_batch_5.bin` 为训练之集，`test_batch.bin` 为测试之集，每文件万条，每条一字标签加 3072 字像素（R、G、B 各 32×32）。读者易像素为 NHWC 之 [样数, 32, 32, 3]，缩至 [0, 1]。

## 构与行

于仓之根（须先有 `yy双宿主构建.wasm` 与 `yy4_bs.wasm`）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/十类小图训练 dist/十类小图训练 --包根 库/深度学习
node dist/十类小图训练/启动.mjs --授权只读目录 数据=<含 cifar-10-batches-bin 之目> -- --轮数 5
node dist/十类小图训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<含 cifar-10-batches-bin 之目> -- --训练样本数 0 --测试样本数 0 --轮数 10
```

数据之目须以“数据”之名只读授之；`--张量后端 金属 --允许系统库调用` 则用苹果之 GPU（书于 `--` 之前）。应用之参书于 `--` 之后：

| 参 | 义 |
| --- | --- |
| `--轮数 N` | 训练之轮数，默一 |
| `--批大小 B` | 默三十二 |
| `--训练样本数 N`、`--测试样本数 N` | 默二千、一千；零为全（五万、一万） |
| `--报告间隔 N` | 每 N 批书其段之均损，默十，零则不书 |
| `--优化器 名` | `亚当`（默）或 `随机梯度下降` |
| `--学习率 L` | 亚当默 0.001，随机梯度下降默 0.01 |
| `--动量 M`、`--权重衰减 W` | 随机梯度下降之动量（默 0.9）；二器之权衰（默 0.001，同 needle 之 train_cifar10） |
| `--种子 S` | 初始与乱序之伪随机种，默零 |
| `--子目录 路径` | 批文件在所授之目中之子目，默 `cifar-10-batches-bin` |

参误则书用法，以退出之码二终。

## 所得

2026-09-30 于 macOS arm64（诺节 26.3.0，张量接口 0.4.0，中央处理器之后端，主机负载均值约百三十）以默参（训练二千张、测试一千张，亚当 0.001，权衰 0.001，批大 32）训五轮：训练之损依次为 2.25、1.69、1.38、1.11、0.92，训练之正率 21.8%、40.1%、51.9%、61.5%、69.0%，测试之正率 25.0%、29.1%、33.4%、31.2%、33.8%（样少，已过拟）；每批百七十至二百七十毫秒，每轮约十一至十七秒，载约半秒。

## 已知之限

- 全量之图须约 740 MB 常驻之存；于中央处理器之后端以每批约 0.2 秒计，每轮约五分。
- 无数据之增与学率之衰，十轮之后测试之正率随批归一之滑动之统起伏数个百分点。
- 读者以每批文件恰万条为设。
