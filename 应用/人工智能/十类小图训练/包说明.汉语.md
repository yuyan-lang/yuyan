# 十类小图训练

这是用[深度学习框架](../../../库/深度学习/框架/包说明.汉语.md)在 CIFAR-10 上训练 ResNet9（needle 作业四的模型，NHWC 布局）的路一应用。每轮打乱训练集、逐批训练，每隔若干批打印这段的平均损失，每轮打印训练损失、训练与测试正确率、每批用时，最后打印最终测试正确率。默认只读训练集前 2000 张、测试集前 1000 张，用来做小规模验证；`--训练样本数 0 --测试样本数 0` 读全量，宜在金属后端上跑。

## 包身份

所有者：豫言。包版本：0.1.0。本包为可执行文件（入口 `入口`，产物名 `yy十类小图训练`），登记在「人工智能」分组下。它实现启动接口，经深度学习框架用张量计算、文件与张量文件接口，用 `yy双宿主构建` 的节点模式构建成诺节发行包。

## 数据

用 CIFAR-10 二进制版（https://www.cs.toronto.edu/~kriz/cifar-10-binary.tar.gz，MD5 c32a1d4ab5d03f1284b67883e8d87530）解开后的 `cifar-10-batches-bin/`：`data_batch_1.bin` 至 `data_batch_5.bin` 为训练集，`test_batch.bin` 为测试集，每个文件 10000 条，每条 1 字节标签加 3072 字节像素（R、G、B 各 32×32）。读取器把像素换成 NHWC 的 [样本数, 32, 32, 3] 并缩放到 [0, 1]。

## 构建与运行

在仓库根目录（需先有 `yy双宿主构建.wasm` 与 `yy4_bs.wasm`）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/人工智能/十类小图训练 dist/十类小图训练 --包根 库/深度学习
node dist/十类小图训练/启动.mjs --授权只读目录 数据=<含 cifar-10-batches-bin 的目录> -- --轮数 5
node dist/十类小图训练/启动.mjs --张量后端 金属 --允许系统库调用 --授权只读目录 数据=<含 cifar-10-batches-bin 的目录> -- --训练样本数 0 --测试样本数 0 --轮数 10
```

数据目录须以“数据”为名只读授予；`--张量后端 金属 --允许系统库调用` 用苹果设备的 GPU（写在 `--` 之前）。应用参数写在 `--` 之后：

| 参数 | 含义 |
| --- | --- |
| `--轮数 N` | 训练轮数，默认 1 |
| `--批大小 B` | 默认 32 |
| `--训练样本数 N`、`--测试样本数 N` | 默认 2000、1000；0 为全部（50000、10000） |
| `--报告间隔 N` | 每隔 N 批打印这段的平均损失，默认 10，0 为不打印 |
| `--优化器 名` | `亚当`（默认）或 `随机梯度下降` |
| `--学习率 L` | 亚当默认 0.001，随机梯度下降默认 0.01 |
| `--动量 M`、`--权重衰减 W` | 随机梯度下降的动量（默认 0.9）；两种优化器的权重衰减（默认 0.001，同 needle 的 train_cifar10） |
| `--种子 S` | 初始化与打乱的伪随机种子，默认 0 |
| `--子目录 路径` | 批文件在授权目录里的子目录，默认 `cifar-10-batches-bin` |

参数不对时打印用法并以退出码 2 结束。

## 结果

2026-09-30 在 macOS arm64（诺节 26.3.0，张量接口 0.4.0，中央处理器后端，主机负载平均约 130）上用默认参数（训练 2000 张、测试 1000 张，亚当 0.001，权重衰减 0.001，批大小 32）训练 5 轮：训练损失依次为 2.25、1.69、1.38、1.11、0.92，训练正确率 21.8%、40.1%、51.9%、61.5%、69.0%，测试正确率 25.0%、29.1%、33.4%、31.2%、33.8%（样本少，已过拟合）；每批 170 至 270 毫秒，每轮约 11 至 17 秒，载入约 0.5 秒。

## 已知限制

- 全量图像要约 740 MB 常驻存储；中央处理器后端上按每批约 0.2 秒估算每轮约 5 分钟。
- 没有数据增强与学习率衰减，十轮后测试正确率随批归一的滑动统计起伏几个百分点。
- 读取器假定每个批文件恰有 10000 条。
