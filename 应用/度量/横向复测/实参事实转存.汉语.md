# 实参事实转存

这是已有单层守卫内联的参数事实转存实验，不改公共 ABI、对象布局、样本字段或命令行参数。

冻结编译器函数 1205 的调用序一，原始指令依次读取局部八、局部一与局部九，再把局部九转换为 i31 并无号取值，经类型二的间接调用进入函数 1494。实际转译入口快照含局部八的类型十八事实；守卫把实参复制到块临时，再复制到被调函数参数，旧路径没有转存事实，故被调体再次执行同一类型检查。

修改仅在有样本的原函数记录最近六条原始指令，依读取器边界识别两条参数读取及函数号的读取、i31 转换和无号取值。其他形状保留未知来源；已有窥视优化若吞掉额外指令，清除该记录。复制时只转存类型及非空事实，长度、界与对象头缓存仍不转存。

备用机语义测试构建完成 421 项任务，执行退出零并输出「参数事实测试通过」。测试覆盖具体类型、i31、非空、旧目的事实删除、其他局部保留、长度与界及缓存拒绝、多字节局部号、错误参数数、有号取值、杂令、内联上下文和关闭采集。主机原生生成器完成 701 项任务、退出零。

pit-mac 冻结候选 SHA256 为 275c89a189b3def92f29cbbcb215c0ee2c3045ba004457166e160fc4436391e5，大小 26597024 字节。实际 `客:f947` 目标守卫命中后，重复判空、对象标签及类型十八比较已消失，数组越界检查仍在；整段汇编由 806 行减至 758 行。一次冷编 236.05 秒，退出零，产物与既有 Node 轮次逐字节相同。此为单次验证，尚不能与历史中位数据以宣称收益。

主机标准 WasmGC 参数转存夹具工具完成 326 项任务、退出零。已证与未知来源的正常数组路径，Node 与 AOT 均退出零，并检查同一调用点的目标命中与其他目标回退；四项错型及空引用，Node 报类型转换陷阱，AOT 退出 135 并报「类型转换失败」；两项越界，Node 报数组越界，AOT 退出 127 并报「数组索引越界」。退出码对应转译器原有致命码。无样本普通调用夹具与旧单层生成器的机器文件逐字节相同，运行退出零。正式交替测速和完整构建比较仍待完成。
