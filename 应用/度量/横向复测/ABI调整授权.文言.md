# ABI 调整授权

用户于 2026-10-05 此会话明许：「允许少量修改ABI如果这个能使AOT速度更快的话」。此许施于旧长目标：于 pit-mac 以同机、同源之冷编打印与全构基准，使原生 AOT 及或逾 Node，产物仍同；此机为备。

后可作有实性能之据之少量 ABI 更易。各更仍录实改、运行语义与产物之校，于同机基准证其益。今尚未因此许而作新 ABI 之改。

今递归候选之热点函展十八层、帧五四零八字节；旧序一冷编三零零点六一秒，末目标守卫倒序一冷编二八九点六六秒，二产物皆与旧 Node 基准同。帧尚未减，正式五轮与全构之比未始。先察静态槽与尾递归复用，乃依实瓶颈定 ABI 须易否。
