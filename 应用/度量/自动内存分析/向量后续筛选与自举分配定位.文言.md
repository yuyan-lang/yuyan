# 并填之后，察自举之费

二〇二六年九月二十日。试宽批、窄索、显式内联、读值复用、载荷对齐与循环尾检。或初测稍利而复测不定，或反增其时，皆未纳于正式生成器。窄索之体虽短，V8 先内联多层自递归，分区之体反不得入；故不可唯以文短断其速。

复以自动栈之旗编译编译器，所得与默认逐字节同，三百九十二万三千一百五十三字节；栈候选无一命中。故先前自举之速，不可归功于自动栈分配。

静察中间表示，有分配位置二万五千五百五十九，数组百五十二。其中六十三因入他对象而未明容器之寿，七十一因用途未有证明而留 GC。此乃静态位置之数，非运行分配之数；未证不逃，亦不等于实逃。

以 GC 诊断并记线程之任务，得三万九千二百二十事件。类型检查与擦除所报累计分配约占百分之五十七。此为历次分配之积，非同时存活之量；诸线程暂停相叠，不可相加作墙钟之损。

又采样统一网页汇编之类型检查任务，见名称解析及源码范围搜索费时。查其文，固定声明后缀屡拆为字符列，通用前缀比较虽首字已异，犹验其后。今改编译器内之纯比较，异则止，声明后缀直验已有字符；通用列术之求值约不改，语言服务结果不弃。差分一万〇五百一十六例及完整自举皆过，八次墙钟对照见均时省约百分之三点三，故留其术。详见 [验收之文](源码前缀分配消除.文言.md)。
