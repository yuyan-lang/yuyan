# 统一 ANF：首条自举路径

本次实现提供实验目标 `--target=wasmgc-anf`，原有 `wasmgc` 路径保留。本报告区分已实现的自举路径与完整架构审阅稿中的后续工作。

## 自举性能

2026-09-09，本机 Apple M5 Pro、48 GB 内存、macOS arm64，接交流电。Node 26.3.0，V8 14.6.202.34-node.20。Node worker 的机器栈为 128 MiB，V8 使用默认 GC 配置。

| 完整自举路线 | 墙钟秒 | 用户态秒 | 系统态秒 |
|---|---:|---:|---:|
| 旧 WasmGC → 旧 WasmGC，Node/V8 | 123.07 | 138.17 | 7.81 |
| 统一 ANF WasmGC → 统一 ANF WasmGC，Node/V8 | 115.99 | 132.30 | 7.10 |

WasmGC 本轮缩短 **5.8%**。这只是本机、当前自举负载的结果，Wasm 各只有一次正式对照；不是其他程序的性能保证。

每行从相同的编译器源码出发，输出对应路线的可执行编译器。计时对应 `自举计时源码指纹.json`。

## 已实现

- 闭包转换后的表达式直接构造成独立 ANF：函数内整数值 ID、原子操作数、有序指令、带结果的 if、动态退出域和明确的结束式。分支公共后续只构造一次。
- 前序 contify 已引入的共享尾部用词法结果块承接；只能跳出包围自己的块，不开放任意 goto，也不复制公共后续。
- 验证 ID 唯一性、定义和可见范围，以及结果块目标的词法合法性。验证失败时停止代码生成。
- 新目标调用 ANF 构造器与验证器。WasmGC 复用旧生成器的模块设施和原子原语编码，控制区域直接消费新 ANF；动态提前退出使用原有 EH 机制。

## 验证口径

主要指标是编译器从相同源码完成一次自身编译的墙钟时间，同时保留用户态与系统态 CPU 时间。计时包含前端、默认阶段导出与后端，不包含准备种子编译器的时间。计时运行串行执行，不同时启动其他验证构建。

完整自举使用同一包上下文，显式 `--do-not-load-cache`；不同源码快照、不同缓存条件的开发计时不混算加速比。

## 回归验证

- WasmGC：统一 ANF 编译器在 Node/V8 内编译自身，种子与输出 Wasm 完全相同；旧 WasmGC 对照同样达到固定点。
- ANF 构造测试：结果 if 只有一份公共后续；非法分支局部变量泄漏和重复 ID 被拒绝。

## 范围限制

- 尚未切换默认后端。
- ANF 当前在模块生成器内按函数构造，尚未成为独立序列化、缓存和导出 stage。
- 运行时类型多数仍为通用值；完整原语签名／效果登记表、类型与元数验证尚未落地。
- 显式循环节点已有格式，但验证与后端会明确拒绝；当前自举通过尾调用执行递归。循环活跃性需要另外实现固定点分析。
- 尚未统一所有程序的 FFI、调试选项及运行参数。
- 这是可自举的实验实现，不代表架构审阅稿的全部条目已经完成。
