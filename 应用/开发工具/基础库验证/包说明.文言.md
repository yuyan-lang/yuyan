# 基础库验证

版：0.1.0。

批行之令：`yy基础库验证 批模糊 目标程序 语料目录 保留样本路径 每种次数 批量 每批超时毫秒`，批量宜万。目标受 `批模糊 种子路径 起点 次数 进度路径`，读种而召设施之 `执行变异批次`，以还码退出。解析术之零与二皆受，子程全批须零退；父程见余码、陷、逾时皆判败，存今序之定变样。败序为种内之序。单例复行之令为 `yy基础库验证 重放 目标程序 种子路径 编号 样本路径 超时毫秒`；目标受一样径，书真退码。旧「模糊」之式仍可行。

每批启前，父书进度为始减一。子零退后，进度原文须严等于始加量减一之整数表示；目标循约书整数而无换行。校其全文，察空文、坏尾、错序及单输入之早退。成批则书种径、始序、次数、末序为证；全量之数据逐批严核及真实目标之术。进度有异则书种、始、预期及实文，存本批始序之定变样。非零退者存其码；进度犹为哨或逾批界，则存始样，别书实序及保留样之序。终因别表逾时。节点、原生正负实验具《批进度验证记录.汉语.md》。

此器复用「基础库测试设施」，读语料、定序变异、限时隔离子程而量中位。

模糊之试：`yy基础库验证 模糊 目标程序 语料目录 临时样本路径 次数 超时毫秒`。目标受样本路径一参；零常治、二拒非法输入、余码报崩。种取语料目录之常文。器留末样，败则书种名、变异序及样径。乙级全量至少百万次变异；循本机资源之队而行。

程序基准：`yy基础库验证 基准 目标程序 预热次数 重复次数`。书墙钟纳秒之中位，含启程之费。热点之术可径调库之 `基准中位纳秒`。

器依标准库与仓内设施，许循仓库之许。语料所出、版与许可由所试之库录之。

资源命令受目标程序、时限毫秒、常驻限字节、采间毫秒及目标诸参，分书终因、实退码、采常驻最大字节与系统峰字节，未得者明书。单例、批模糊及重放同用资源候器，常驻必守之限十六吉字节，采间二十毫秒；逾时、常驻逾限及资源未得皆别于目标退码，主动退百二十四归正常。败则循旧进度文复成留样。基准逐次书目标资源果，复汇含启子程与观测之费的墙钟中位，单次时限二十四时。进程内热点仍用库术。
