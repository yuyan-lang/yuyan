# 基础库验证

版：0.1.0。

批行之令：`yy基础库验证 批模糊 目标程序 语料目录 保留样本路径 每种次数 批量 每批超时毫秒`，批量宜万。目标受 `批模糊 种子路径 起点 次数 进度路径`，读种而召设施之 `执行变异批次`，以还码退出。解析术之零与二皆受，子程全批须零退；父程见余码、陷、逾时皆判败，存今序之定变样。败序为种内之序。单例复行之令为 `yy基础库验证 重放 目标程序 种子路径 编号 样本路径 超时毫秒`；目标受一样径，书真退码。旧「模糊」之式仍可行。

此器复用「基础库测试设施」，读语料、定序变异、限时隔离子程而量中位。

模糊之试：`yy基础库验证 模糊 目标程序 语料目录 临时样本路径 次数 超时毫秒`。目标受样本路径一参；零常治、二拒非法输入、百二十四留作逾时之码，余码报崩。种取语料目录之常文。器留末样，败则书种名、变异序及样径。乙级全量至少百万次变异；循本机资源之队而行。

程序基准：`yy基础库验证 基准 目标程序 预热次数 重复次数`。书墙钟纳秒之中位，含启程之费。热点之术可径调库之 `基准中位纳秒`。

器依标准库与仓内设施，许循仓库之许。语料所出、版与许可由所试之库录之。
