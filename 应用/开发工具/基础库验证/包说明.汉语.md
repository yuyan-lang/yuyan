# 基础库验证

版本：0.1.0。

本工具复用「基础库测试设施」读取语料、确定性变异、限时隔离子进程与测量中位数。

运行模糊测试：`yy基础库验证 模糊 目标程序 语料目录 临时样本路径 次数 超时毫秒`。目标接受一个样本路径参数；退出 0 表示正常处理，2 表示已拒绝非法输入，124 为超时保留码，其余退出码报告崩溃。种子选自语料目录的普通文件。工具保留最后一次样本，失败时打印种子名、变异序号与样本路径。乙级全量执行使用至少 1000000 次变异；全量运行按本机资源队列执行。

运行程序基准：`yy基础库验证 基准 目标程序 预热次数 重复次数`。输出墙钟纳秒中位数，包含进程启动。热点函数基准直接调用库的 `基准中位纳秒`。

工具依赖标准库与仓内设施，许可遵循仓库许可。语料的数据出处、版本与许可由被测库登记。
