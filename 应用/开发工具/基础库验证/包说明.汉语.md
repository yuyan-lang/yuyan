# 基础库验证

资源命令正常结束时以目标真实退出码退出；超时、常驻超限和资源未知返回失败，并保留分开的原因与数值输出。采样阈值表示观察到超限后的强制终止门槛，操作系统瞬时硬限额留待后续事项。

macOS 诺节资源采样使用 `node --experimental-ffi` 启动完整宿主，宿主旁包含 `yy进程资源共享.wasm`。缺少共享模块或系统调用能力时，资源结果明确为未知，正数资源门槛判定失败。

版本：0.1.0。

批量模式：`yy基础库验证 批模糊 目标程序 语料目录 保留样本路径 每种次数 批量 每批超时毫秒`，建议批量10000。目标接收 `批模糊 种子路径 起点 次数 进度路径`，读取种子后调用设施的 `执行变异批次`，并以返回码退出。目标每次解析的0与2由设施接纳，整个子程序须退出0；父程序把其余退出码、陷阱与超时判为失败，保存当前编号的确定性变异样本。失败编号是种子内部编号。单例重放命令为 `yy基础库验证 重放 目标程序 种子路径 编号 样本路径 超时毫秒`，目标接受一个样本路径，输出独立结束原因与真实退出码。原有「模糊」模式继续可用。

每批启动前，父程序将进度文件初始化为起点减一。子程序退出0后，进度文件原文必须精确等于起点加次数减一的整数表示；目标按协议写无换行整数。比较采用完整文本，以识别空文、损坏后缀、错序及单输入批早退。每批成功输出种子路径、起序、次数和末序证明行；全量计数以这些逐批硬核及真实目标实现为依据。进度不符时报种子、起点、预期与实际原文，保存本批起点的确定性样本。非零退出时保留退出码；进度仍为哨兵或超出本批时，保留起点样本并分别报告实际序号与保留样本编号。结束原因单独表示超时。正负控制的节点和原生实测见《批进度验证记录.汉语.md》。

本工具复用「基础库测试设施」读取语料、确定性变异、限时隔离子进程与测量中位数。

运行模糊测试：`yy基础库验证 模糊 目标程序 语料目录 临时样本路径 次数 超时毫秒`。目标接受一个样本路径参数；退出 0 表示正常处理，2 表示已拒绝非法输入，其余退出码报告崩溃。种子选自语料目录的普通文件。工具保留最后一次样本，失败时打印种子名、变异序号与样本路径。乙级全量执行使用至少 1000000 次变异；全量运行按本机资源队列执行。

运行程序基准：`yy基础库验证 基准 目标程序 预热次数 重复次数`。输出墙钟纳秒中位数，包含进程启动。热点函数基准直接调用库的 `基准中位纳秒`。

工具依赖标准库与仓内设施，许可遵循仓库许可。语料的数据出处、版本与许可由被测库登记。

资源命令：`yy基础库验证 资源 目标程序 超时毫秒 RSS限字节 采样毫秒 [目标参数…]`，打印结束原因、真实退出码、采样最大常驻字节与操作系统峰值字节，未知写为“未知”。单例、批模糊和重放复用同一资源等待器，默认常驻硬门槛16 GiB、采样20毫秒；超时、常驻超限和资源未知独立于目标退出码，主动退出124归入目标正常结束。失败按已有进度文件重建并保留样本。基准每次输出目标资源结果，再汇总包含子进程启动与观测成本的墙钟中位数，默认单次时限24小时。进程内热点基准继续调用库函数。
