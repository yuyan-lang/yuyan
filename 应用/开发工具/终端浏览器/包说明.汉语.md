# 终端浏览器

在现有图形界面中显示简单 HTTP 网页的实验性浏览器。

## 组成

- **终端文字**：文字节点按深度缩进、各占一行，并继承直接父元素的终端颜色、背景和粗体样式。正值 `margin-left` 与 `padding-left` 各增加一级缩进；正值上、下边距与内边距各增加一行空白。终端按行显示，右侧盒距不映射为可见宽度。
- **网页抓取**：通过宿主授权的 HTTP(S) 网页请求接口获取页面；会跟随 301、302、303、307、308 重定向，按响应网址解析相对 `Location`，转向最多一百次；POST 遇 301、302、303 时转为 GET，307 与 308 保持方法和正文。分块响应暂不支持。
- **超文本标记解析**：自造词法与建树，不用外部解析器；`script`、`style`、`textarea`、`title` 内的原始文本会保留到对应闭标签，标签名按 ASCII 大小写不敏感处理。
- **样式**：自造样式表解析、选择器匹配与层叠，解析逗号分隔的选择器组、`*`、标签、`#id`、`.class`、属性存在选择器（`[disabled]`）、属性等值选择器（`[type="text"]`）、前缀（`[href^="https"]`）、后缀（`[href$=".html"]`）、子串（`[class*="card"]`）、空白词（`[class~="card"]`）、连字符前缀（`[lang|="zh"]`）、同一元素上的复合简单选择器、空白分隔的后代选择器（如 `main p`、`.card a`、`button.primary#save`）及直接子代组合符（如 `main > p`，`>` 两侧须留空格）；属性值接受无引号、单引号或双引号并精确比较，属性名与值须连续书写，属性值暂不支持空格。声明支持大小写不敏感的 `!important`，重要声明先于普通声明；每类声明内部按 CSS specificity 与源码顺序层叠。属性大小写标志及伪类条目未列出的伪类尚未实现。路径匹配接受显式祖先列，并用于 GUI 块级与行内递归、容器、表单和列表项的样式计算。`<select>` 选项的专用渲染路径尚未传递祖先列。图形页面按文档顺序获取授权来源的外部 CSS，并结合内嵌样式；终端渲染支持八种标准色及常见三位、六位十六进制写法。GUI 元素映射 `display:none`、`color`、`background-color`、`font-size`、`font-weight`、`border` 与 `border-radius`。
- **伪类**：CSS 与 DOM 查询支持 `:first-child`、`:last-child`、`:only-child`、`:nth-child(odd)`、`:nth-child(even)`、整数参数与 An+B 参数（如 `:nth-child(3)`、`:nth-child(2n+1)`、`:nth-child(-n+3)`、`:nth-child(-2n-1)`）、`:empty`、`:checked`、`:disabled`、`:required` 与 `:optional`；结构伪类按父节点中元素子项的顺序匹配，文字与注释不计入位置；所有已支持伪类按类选择器 specificity 参与级联。`:required` 与 `:optional` 只匹配支持该属性的 `input`、`select`、`textarea` 控件，且按 `required` 属性是否存在判定；`input` 的 `hidden`、`button`、`submit`、`reset`、`image`、`range`、`color` 类型不参与匹配；不计算当前值的有效性。其他伪类与 `:nth-child` 的 `of` 子句尚未实现。
- **悬停样式**：图形页支持 CSS `:hover` 并把悬停级联转为界面自绘的悬停状态样式；样式按完整 specificity 与源码顺序重算。首版的悬停状态跟随实际被设样的目标元素；如 `section:hover a`，指针悬停在 `a` 上时规则生效，单独悬停在 `section` 其他位置时不生效。脚本的 `querySelector`、`matches` 不读取 GUI 当前悬停元素，含 `:hover` 的查询不会命中。
- **布局**：自造盒模型与块级布局；GUI 支持块级纵排、HTML 表格分组与逐行横排、`display:flex` 横排/纵排、换行、`gap`、主轴分配与交叉轴对齐；flex 子项支持整数 `flex-grow`、`flex-shrink`、像素 `flex-basis`、单值 `flex` 简写与 `align-self`，段落把文字和链接片段排在同一行内。表格单元按无前导零、无空白的正十进制 `colspan` 跨度比例分配行宽；不同列数的行不共享列宽，`rowspan` 尚未支持。
- **脚本**：支持部分 JavaScript 语法与文档对象接口；图形模式按文档顺序执行内联脚本与已授权的外链脚本，脚本后的 DOM 用于图形渲染与链接收集。`document` 支持按 id、标签、类名、`name` 属性及基础选择器查询，`getElementsByName(name)` 直接精确匹配 `name` 属性并返回静态可索引节点列，缺少参数按字符串 `"undefined"` 查询；`querySelector`、`querySelectorAll` 与元素 `matches` 共用 CSS 选择器范围：`*`、标签、`#id`、`.class`、`[name]`、`[name=value]`、`[name^=value]`、`[name$=value]`、`[name*=value]`、`[name~=word]`、`[name|=prefix]`、空白分隔的后代选择器和直接子代组合符（如 `main > p`，`>` 两侧须留空格）；属性等值支持引号值，不支持空格；`document.title` 可读写，`document.head`、`document.body` 与 `document.documentElement` 返回当前树中的对应元素；元素支持 `innerText` 读写、`innerHTML` 子树序列化读写、`matches`、`getAttribute`、`hasAttribute`，带 `id` 的元素支持 `setAttribute`、`removeAttribute`、`remove`，表单控件支持 `checked` 属性；`select.value` 可读写，设置时选中首个匹配选项并清除其他选项，未匹配时清空选择；图形界面中的块容器、段落、列表项、行内元素及按钮支持 `onclick` 冒泡；事件处理器及其祖先可调用 `event.preventDefault()` 取消普通链接导航、按钮提交/重置与文本框按 Enter 提交；禁用按钮不派发事件；文本输入的 `oninput`、下拉选项的 `onchange`、Enter 与文本框转发的其他按键的 `onkeydown` 沿祖先路径执行，`event.key` 使用常见 DOM 键名；未被文本框编辑逻辑消耗的按键会转发，文本框按 Enter 时如未阻止默认行为就提交所属 GET/POST 表单；有效表单提交前会在表单上派发可冒泡的 `submit` 事件，内联 `onsubmit` 与事件监听器都可调用 `event.preventDefault()` 取消提交；复选框/单选框先改变勾选状态，再沿祖先路径依次触发 `onclick`、`onchange`，禁用控件不派发；通过 `<label>` 激活内部控件时，控件与 label 之间的包装元素也沿祖先路径收到事件；处理器支持 `this`、`event.target`、`event.currentTarget` 与 `event.type`；复选框可点击切换，单选框按表单内 `name` 互斥；`<select multiple>` 可多选并以重复 GET 字段提交，页面保留脚本环境。GUI 聚焦变化会在目标元素上派发不冒泡的 `focus`、`blur` 事件；程序调用的 `focus()`、`blur()` 仅更新脚本可读焦点快照。元素支持 `addEventListener(type, callback)` 注册 `click`、`input`、`change`、`keydown`、`submit`、`focus`、`blur` 回调；触发时以 `event` 为参数，`this` 对应 `currentTarget`，监听器沿已支持的路径运行；内联处理器先运行，同节点监听器按注册顺序运行，同一元素与事件类型下重复注册同一回调会忽略；`removeEventListener(type, callback)` 按回调身份移除监听器。监听选项（含 `capture`）与其他事件类型尚未支持。
- **计算属性**：普通对象字典支持 `obj[key]` 读取与赋值，key 按运行器的字符串转换结果匹配自有属性名；缺失属性读作 `undefined`，赋值会新增或替换属性。稠密数组支持给已有下标赋值及向末尾追加；跨过数组长度的稀疏下标、数组 `length`、字符串下标、对象原型链尚未支持。计算属性接收器路径限变量与成员路径，下标表达式限变量或字面量。直接对象成员调用（如 `obj.method()`、`obj[key]()`）会将对象作为普通函数的 `this`；箭头函数仍取创建时的词法 `this`。闭包函数支持 `fn.call(thisArg, ...args)` 与 `fn.apply(thisArg, argsArray)`；`apply` 的实参只接受当前数组、`null` 或 `undefined`，普通 array-like 对象尚未支持。箭头函数忽略动态 `thisArg`，仍取创建时的词法 `this`。
- **Cookie**：图形页按 scheme、主机和端口保存会话级简单 `name=value` Cookie；来源依据 URL 中的 scheme 与 authority 字面值匹配，主机大小写及默认端口尚未归一。`document.cookie` 可读写当前来源的 Cookie，页面脚本运行前会取得已有值，赋值按同名覆盖。主文档 GET/POST、重定向请求与外链 CSS/脚本 GET 都会发送匹配来源的 `Cookie`，各响应中的 `Set-Cookie` 都会写回会话并供后续请求与脚本使用。`Path`、`Domain`、`Secure`、`SameSite`、`Expires` 与 `Max-Age` 等属性尚未处理。
- **DOM 节点类型**：节点只读提供 `nodeType` 与 `nodeName`，元素另有 `tagName`；元素名为 ASCII 大写，文字、注释、文档节点名分别为 `#text`、`#comment`、`#document`，节点类型值分别为 1、3、8、9。
- **DOM 连通性**：节点可读只读属性 `isConnected`；文档节点恒为 `true`，带内部身份的元素按当前文档树判断，脱树元素为 `false`。文字与注释节点因尚无内部身份，暂返回 `false`。
- **DOM 子节点**：节点可读 `childNodes`（含文字与注释的直接子节点集合）、`children`（元素子节点集合）、`firstChild`、`lastChild`、`firstElementChild`、`lastElementChild` 与 `childElementCount`。集合是每次读取时生成的可下标值列并带 `length`；不存在的首末节点返回 `null`。
- **DOM 父节点**：节点可读 `parentNode` 与 `parentElement`；前者返回直接父节点，后者返回直接元素父节点。文档根节点和脱离文档树的节点没有父节点时返回 `null`。
- **DOM 兄弟节点**：节点可读 `previousSibling`、`nextSibling`、`previousElementSibling` 与 `nextElementSibling`；元素兄弟属性会跳过文字和注释节点。内容相同的文字或注释节点若位于不同位置，查询可能命中首个结构相同节点。
- **动态 DOM**：`document.createElement(tagName)` 创建无属性、无子节点的元素；`document.createTextNode(text)` 创建文字节点；元素 `appendChild(node)` 将子节点追加到父元素末尾并返回子节点，`removeChild(node)` 移除指定的直接子节点并返回它。缺少子节点、实参非节点、目标非直接子节点或父元素脱离文档树时会抛错。脚本执行前会为树中元素分配脚本不可见的内部身份，新增元素及 `innerHTML` 生成的元素也会获唯一身份；追加与移除按目标父元素身份只重建其祖先路径，树中已有的元素追加前会先从旧位置移除。对当前环境链中直接绑定的节点，属性或文本内容改写会按身份更新所有含该节点的绑定子树；脱树父元素追加子节点也会同步其绑定子树，因此可先构建脱树子树再挂入文档。绑定在普通对象、数组等容器中的节点引用，以及其他未连入当前环境链的别名不会同步更新；向脱树父元素追加已有父节点的子节点时，不会从其原父节点移除；可能形成祖先环的追加不写回。
- **箭头函数与异常**：支持 `x => 表达式`、`() => 表达式`、`(x, y) => 表达式` 与块体。表达式体隐式返回其值；块体支持 `return`、`var`、`let`、`const`、表达式语句、`if/else`、`while`、经典 `for`、`switch/case/default`、`try { ... } catch (error) { ... }`、`throw value`、`break`、`continue`、嵌套块及命名函数声明。`throw` 抛出原值，`catch` 绑定该值；运行器产生的字符串异常也会传给 `catch`，但异常发生前未返回的环境更新可能不保留。尚未支持 `finally`、`do/while`、错误对象与堆栈。`switch` 只接受括号条件与花括号体；case 表达式按需求值，匹配使用当前支持值类型的严格相等，命中后按源码顺序贯穿，`break` 退出最近的 switch，`continue` 传至最近循环，`return` 与 `throw` 继续向外传播。对象与数组的引用相等尚未实现。`this` 取创建箭头函数时环境中的值，作为事件回调时仍保持该词法值。参数支持标识符列，默认值、剩余参数与解构参数尚待实现。
- **undefined 与 null**：全局 `undefined` 与 `null` 分别表示；两者都是假值，`typeof undefined` 返回 `"undefined"`，`typeof null` 返回 `"object"`。未传入的函数参数、无初值的 `var`/`let`、空 `return`、无返回语句的函数与 `forEach` 返回 `undefined`。普通对象缺失属性和数组负下标、越界读取均返回 `undefined`；DOM 查询无结果返回 `null`。`===` 与 `!==` 区分二者；`==` 与 `!=` 将二者视为相等，并支持布尔值与数字按 `0`/`1` 比较；其他宽松类型转换尚未实现。
- **外链脚本**：图形模式按文档顺序同步获取 `<script src>` 并与内联脚本顺序执行；相对地址按最终页面地址解析，来源须获 `--允许源` 授权，请求失败则跳过。`async`、`defer`、`type="module"` 与动态插入脚本尚未按浏览器语义处理；命令行文字管线只执行内联脚本。
- **页面载入事件**：图形模式的初始脚本执行完毕后，会在 `document` 上派发一次不可冒泡、不可取消的 `DOMContentLoaded` 事件；正常结束的事件处理器修改的 DOM 会进入首次渲染。处理器抛错时，本次派发中的环境更新可能回退，但页面仍继续显示。之后在 `window` 上按注册顺序派发不可冒泡、不可取消的 `load` 事件，最后调用 `window.onload`；`load` 监听器的 `this`、`event.target` 与 `event.currentTarget` 都是 `window`。
- **文档载入状态**：图形模式下，页面脚本与 `DOMContentLoaded` 处理器读取 `document.readyState` 得到 `interactive`；`DOMContentLoaded` 处理后变为 `complete`，随后派发 `window` 的 `load` 事件并调用已赋值的 `window.onload` 回调。`window.addEventListener('load', callback)` 与 `removeEventListener('load', callback)` 按回调身份注册和移除函数监听器；重复注册同一回调会忽略，监听选项暂不支持。派发开始时固定本轮监听器序列；事件处理中移除尚未调用的监听器不会改变当前派发。回调异常不阻断页面显示，但本次事件或回调中的环境更新可能回退。无此页面状态的纯 HTML 执行环境返回 `loading`。
- **数组回调**：数组支持同步的 `map(callback)`、`filter(callback)`、`forEach(callback)`、`some(callback)`、`every(callback)`、`find(callback)`、`findIndex(callback)` 与 `reduce(callback, initialValue?)`；普通回调依次接收元素、从零开始的索引和原数组，`reduce` 依次接收累积值、元素、索引和原数组。`map` 返回映射数组，`filter` 按回调结果的真值保留元素，`forEach` 返回 `undefined`；`some` 命中真值后短路并返回 `true`，`every` 遇到假值后短路并返回 `false`；`find` 返回首个使回调为真的元素，`findIndex` 返回其索引，均命中即短路；未命中时分别返回 `undefined` 与 `-1`，空数组也分别返回这两个值。`reduce` 有第二个参数时将其作为初值（包括显式 `undefined`），无初值时以首项作初始累积值并从第二项开始调用回调；空数组有初值时返回初值，无初值时报错。循环按源顺序执行，并保留回调对闭包变量的更新；`thisArg` 尚未支持。
- **数组方法**：数组支持 `concat(...items)`、`includes(searchElement)`、`indexOf(searchElement)`、`slice(start, end)`、`flat(depth = 1)`、`join(separator)`、`push(...items)`、`unshift(...items)`、`pop()`、`shift()`、`splice(start, deleteCount?, ...items)`、`reverse()` 与 `sort(compareFn?)`；`concat` 按源码顺序求值参数，返回包含原数组项目的新数组，数组参数只浅展开一层，其他值作为单项加入；不修改接收数组。`flat` 返回新数组，依深度递归展开其中的数组；深度缺省或为 `undefined` 时取 1，非正深度不再展开。深度使用当前引擎的简化整数转换，数字串、布尔值和空值转为整数，其他类型按零处理；无穷深度尚未支持。当前数组是稠密列，没有空槽。搜索方法按当前值类型比较且忽略 `fromIndex`，无参搜索目标为 `undefined`。`slice` 返回浅拷贝，结束索引不包含且负索引从末尾计算；索引把数字串、布尔值和空值简化转换为整数，其他类型按零处理，未定义的起止索引使用默认边界。`join` 缺少分隔符或传入 `undefined` 时用逗号，数组项为 `null` 或 `undefined` 时写为空串，其他值按引擎规则转为字符串。修改数组的方法按源码顺序求值实参，重建数组后写回简单变量或由变量名与成员访问组成的可写路径，并返回各方法规定的结果；路径可包含对象属性及数组下标，根绑定更新后数组别名不共享此次写回。修改方法包括 `push`、`unshift`、`pop`、`shift`、`splice`、`reverse` 与 `sort`；`push`、`unshift` 使用参数创建新数组，`pop`、`shift`、`reverse` 忽略额外实参，`splice` 与 `sort` 按各自规则使用参数。`push`、`unshift` 返回新长度；`pop`、`shift` 弹出并返回相应项，空数组返回 `undefined`；`reverse` 返回反转后的数组。`splice` 返回删除项组成的新数组，将第三个及之后的实参插入指定位置；`start` 按 `slice` 的整数索引规则换算并裁入数组范围，省略 `deleteCount` 时删除至末尾，显式传入 `undefined` 时删除零项，删除数量裁入剩余范围。排序使用稳定插入排序；未提供比较器或显式传入 `undefined` 时，按 `String` 转换后的 Unicode 字符序升序排列，`undefined` 排在末尾且不传给比较器；比较器接收两个已定义元素，返回值按当前简化整数转换判序，闭包变量更新会保留。接收器路径须以简单变量为根，且仅支持属性包与稠密数组；函数调用等有副作用的路径及普通 array-like 对象尚未支持。
- **字符串方法**：字符串支持 `length`、`trim()`、`trimStart()`、`trimEnd()`、`charAt(index)`、`replace(searchValue, replacement)`、`replaceAll(searchValue, replacement)`、`slice(start, end)`、`split(separator)`、`includes(searchString)`、`startsWith(searchString)`、`endsWith(searchString)`、`indexOf(searchString)`、`toLowerCase()` 与 `toUpperCase()`；大小写方法只转换 ASCII 字母，其他字符保持原样；trim 系列移除首尾 ASCII TAB 至 CR 与空格，其他 Unicode 空白尚未覆盖；`charAt` 省略索引或传入 `undefined` 时取索引零，负索引和越界索引返回空串；索引按 Unicode 字符计算。`replace` 按字面替换首个匹配，`replaceAll` 按字面替换所有非重叠匹配；空搜索串时，`replace` 在开头插入替换文，`replaceAll` 在首尾及每个 Unicode 字符边界插入替换文。正则与 `$&` 等替换标记尚未实现；`slice` 的结束索引不包含且负索引从末尾计算，`undefined` 起始与结束索引使用默认边界，索引转换与数组 `slice` 相同；`split(undefined)` 与无参 `split()` 一样不分隔；其他方法只处理首参，参数按引擎规则转为字符串，`split` 的第二个 `limit` 参数及索引方法的 `fromIndex` 尚未实现；空分隔串按 Unicode 字符拆分。长度和索引按 Unicode 字符计数，不按 JavaScript 的 UTF-16 单元计数。
- **at 索引**：数组和字符串支持 `at(index)`；缺少索引或传入 `undefined` 时取首项，负索引从末尾计算，越界返回 `undefined`。字符串按当前引擎的 Unicode 字符索引。
- **表单值**：脚本可读写 `input.value` 与 `textarea.value`。空 input 的值为空串；缺少 `value` 的 checkbox/radio 默认为 `on`；未设置 `value` 的 textarea 以其正文为初值。脚本赋值会更新控件当前值，并保存原始默认值供表单重置恢复。
- **反射属性**：元素的 `name`、`type`、`placeholder`、`alt`、`src` 可直接读写对应 HTML 属性；缺省字符串属性读作空串，未设置 `type` 的 input 读作 `text`。`disabled` 读作布尔值，赋予 truthy 值会设置该属性，赋予 falsy 值会移除该属性。checkbox/radio 的 `checked` 表示当前勾选状态，`defaultChecked` 表示表单重置所用的默认状态。
- **祖先查询**：元素支持 `closest(selector)`；从当前元素开始沿文档祖先向上返回首个匹配项，没有匹配时返回 `null`。节点支持 `contains(otherNode)`，检查参数是否为自身或后代；无参数或非节点参数返回 `false`，也可检查脱离文档树的子树。选择器范围与 `matches` 相同；脱离文档树时 `closest` 只能用不依赖祖先的选择器匹配自身。
- **元素内查询**：元素支持 `querySelector(selector)` 与 `querySelectorAll(selector)`，在其后代中按文档顺序返回首项或可索引结果列；结果不含接收元素自身。
- **类名操作**：元素可直接调用 `element.classList.add(...tokens)`、`remove(...tokens)`、`contains(token)` 与 `toggle(token, force?)`；增删支持多个词项，切换返回布尔值，空词项或含空白的词项会抛错。仅支持这些直接方法，`length` 与 `item` 尚未实现。
- **动态内联样式**：元素支持 `element.style.cssText` 读写整段内联样式，并支持 `element.style.color`、`backgroundColor`、`display` 等点属性读写单条声明；驼峰属性名转换为 CSS 连字符名，改写会替换同名声明并保留其他声明。`setProperty`、`getPropertyValue`、`removeProperty` 可操作 CSS 声明，`setProperty` 支持 `important` 优先级。自定义属性名按大小写精确匹配；CSS 值中的 `var()` 会递归替换，函数名不区分 ASCII 大小写，支持组合值、嵌套 fallback 与循环回退并保留 fallback 空白；引号内的 `var()` 不替换。`length` 与方括号属性访问尚未实现。
- **渲染**：通过仓库已有的界面自绘与显示控件在授权显示面构建可滚动 DOM 树；链接有可点击热区。地址栏支持提交导航，返回、前进与刷新按钮使用会话内历史，新导航清除前进记录；刷新按当前地址重新 GET，保持历史位置且不重放 POST 正文。

## JavaScript 全局内建

全局 `JSON.parse(text)` 只接收字符串，使用独立的严格 JSON 递归解析器，支持 `null`、布尔值、整数、双引号字符串、数组与字符串键对象；解析转义字符串并拒绝非法转义、原始控制字符、非 JSON 空白、额外尾随内容及非整数数值格式。重复对象键保留最后一个值。暂不支持 `reviver`。

全局 `JSON.stringify(value)` 紧凑序列化 `null`、布尔值、整数、字符串、数组与普通对象的自有属性。该函数值的 `typeof` 为 "function"，可保存后调用。字符串中的双引号、反斜线及控制字符会转义。暂不支持 replacer、space、循环引用及其他非 JSON 值，遇非 JSON 值会报错。

全局 `Object.keys(value)` 返回普通对象自有属性键组成的字符串数组，顺序沿用对象属性顺序；`Object.values(value)` 按同一顺序返回属性值；`Object.entries(value)` 返回相同顺序的 `[key, value]` 二项数组。数组的 `keys` 返回从 `"0"` 起的数字索引键，`values` 返回数组项列，`entries` 按索引组成二项数组。`Object.fromEntries(entries)` 接收稠密数组，要求每项也是数组；每项首个值转为字符串键，第二个值为属性值，缺失时均按 `undefined` 处理，额外项忽略。重复键更新属性值并保留首次键序，返回按输入顺序构成的普通对象；不支持 iterator 或其他输入类型。`Object.hasOwn(object, key)` 按属性名判断自有属性是否存在，即使属性值为 `undefined` 也会返回 `true`；缺少 `key` 时按字符串 `"undefined"` 查找，额外参数忽略。对象参数须为普通对象或数组。





全局 `Array.isArray(value)` 当且仅当参数是当前引擎的数组值时返回 `true`；缺少参数按 `undefined` 处理并返回 `false`。`Array.of(...items)` 按实参顺序返回包含所有实参的新稠密数组，无参数时返回空数组。`Array.from(value, mapFn)` 接收当前引擎的数组或字符串并返回新数组；数组输入浅拷贝，字符串按 Unicode 字符拆分。映射仅支持直接成员调用 `Array.from(value, mapFn)`，按输入顺序传入元素与从零开始的索引，并将回调结果放入新数组；缺少源参数、映射参数非函数且非 `undefined`、超过两个参数或其他源类型会报错。不支持 `thisArg`、普通 array-like 对象与 iterator。当前数组是稠密列，不含空槽。

数组支持 `sort(compareFn?)`，按稳定插入排序返回排序后的新数组，并写回简单变量或可写成员路径。未提供比较器或显式传入 `undefined` 时，按 `String` 转换后的 Unicode 字符序升序排列；数组中的 `undefined` 排在末尾且不传给比较器。比较器依次接收两个已定义元素，返回值按当前简化整数转换判序，闭包变量更新会保留。路径须以简单变量为根，且只支持属性包与稠密数组；普通 array-like 对象尚未支持，排序别名不会共享这次写回。

数组支持 `splice(start, deleteCount?, ...items)`，接受简单变量或可写成员路径接收器；按源码顺序求值实参，返回删除项组成的新数组，并把剩余项与第三个及之后的实参写回根变量。`start` 按 `slice` 的整数索引规则换算并裁入数组范围；省略 `deleteCount` 时删除至末尾，显式传入 `undefined` 时删除零项，删除数量裁入剩余范围。无参时返回空数组且内容不变；修改数组仍不影响别名。
数组接收器路径也支持以 `window`、`self` 或 `globalThis` 为根读取脚本全局绑定；修改后写回当前脚本环境中对应的绑定。

全局 `Math` 提供 `abs`、`sign`、`min`、`max`、`floor`、`ceil`、`trunc` 与 `round`。这些方法仅接收整数数值；`abs` 与 `sign` 取首参，`min` 与 `max` 至少需要一个实参并返回极值，其余方法取首参并原样返回。缺少所需参数或实参不是数值时会报错。数值模型目前只有整数，未实现小数、NaN、Infinity 或 `Math.random`。




## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/开发工具/终端浏览器 dist/终端浏览器 --包根 库
node dist/终端浏览器/启动.mjs --授权显示面 终端浏览器=1024x768 --允许源 http://example.com -- http://example.com/
```

入口只接受 HTTP 网址，不读取本地文件。地址栏和链接解析支持 HTTP(S) 绝对地址、协议相对地址、站点根路径和当前目录相对路径，并规范化 `.`、`..` 路径段且保留重复斜杠；仅输入域名时补 `http://`。`#fragment` 同页链接更新当前地址与访问历史，不重新请求页面；匹配元素会聚焦并滚入可视区。正文及浏览器使用的 HTML 属性解码十进制、十六进制数值字符引用（分号可省略；非法码点替换为 U+FFFD）及 `&lt;`、`&gt;`、`&quot;`、`&apos;`、`&nbsp;`、`&amp;` 等常用命名实体；完整命名实体表尚未支持。图形表单支持 `text`、`email`、`search`、`url`、`tel`、`number` 输入框、`textarea`、`hidden`、下拉框（含多选）、复选框、单选框及 GET/POST 提交；可编辑控件须有 `id` 或 `name`，仅提交带 `name` 的字段和已勾选的复选框、单选框；单选框按页面级 `name` 分组。POST 使用 UTF-8 编码的 `application/x-www-form-urlencoded` 正文；前进到 POST 历史项时按 URL 重新 GET，不重放正文。文件选择、图片资源、复杂嵌套行内样式与完整 JavaScript 事件对象尚未支持。初始 HTML 中的外链 `<link rel="stylesheet">` 与内嵌 `<style>` 按标记顺序参与级联；脚本执行或事件更新 DOM 后，新增或改写的样式源会按 DOM 遍历顺序追加规则，旧树和本批次中已出现的外链 href 不重复请求。移除或移动已加载的样式源不会撤销或重排旧规则；改写样式内容会追加新规则，旧规则暂留。所有外部样式表仍须获来源授权。`event.preventDefault()` 当前可取消链接导航、按钮提交/重置、文本框 Enter 提交和有效表单提交事件的默认导航。运行 Node 宿主时须已提供 `@kmamal/sdl`，以 `--授权显示面` 授权“终端浏览器”，并以 `--允许源` 授权网页及其外部样式表来源。浏览器会按 `Location` 跟随 HTTP 重定向，最多一百次；POST 遇 301、302、303 时转为 GET，307、308 保持方法与正文。

提交非空 `number` 字段时会检查简单十进制数值格式（可选正负号、至少一位数字、至多一个小数点）；`min`、`max` 使用相同格式约束范围，无效范围值会忽略。指数记法与 `step` 暂不校验。`date` 字段作为文本框录入，校验固定 `YYYY-MM-DD` 年月日、公历闰年及合法 `min`、`max` 范围；无效约束值会忽略，原生日期选择器尚未支持。

`<label>` 包裹 checkbox/radio 的文字以及 `for` 指向同文档控件 `id` 的标签，都可激活对应 checkbox/radio。

HTML 数值字符引用中，U+0080–U+009F 范围内由 HTML 规范列出的 27 个值会映射为对应替代字符；其余控制码保留原值。

`<img>` 会显示 `alt` 替代文字；缺少 `alt` 时显示 `[图片]`，空 `alt` 时不显示文字。替代文字继承链接热区，图片位图尚未绘制。

图形页面脚本提供共享的浏览器全局标记对象：`window`、`self`、`globalThis`、`top`、`parent` 与 `frames` 指向同一值，顶层 `this` 也指向该值。其属性读取当前脚本环境中的全局绑定；`window.foo = value` 会更新该环境绑定，后续可经别名读取。`window.Object`、`window.Math` 与 `window.Array` 可取对应内建值。`location.href` 与 `window.location.href` 可读取页面加载后的规范 URL；给这两种路径赋值会解析相对地址并发起授权的 HTTP(S) 导航，写入后页面历史会增加当前页并清除前进记录；同页 fragment 只更新地址与历史。给 `location`、`window.location` 或其他共享全局对象的 `location` 属性赋值也会按 `href` 规则导航并追加历史。`location.pathname`、`location.search`、`location.hash` 及 `window.location` 的对应属性可读写；路径不含查询串与片段，查询串和片段分别带前缀 `?`、`#`，缺失时为空串，并随导航与历史切换同步。赋 `pathname` 替换路径并保留查询串与片段；缺少开头的 `/` 时会补上，空值设为 `/`。赋 `search` 替换查询串并保留片段；赋 `hash` 替换片段并保留路径与查询串。赋查询串、片段可省略 `?`、`#` 前缀；空值移除对应部分。路径、查询串与片段赋值会按 URL 部件规则对空格、非 ASCII 字符及相应分隔符作百分号编码。赋值复用 `href` 导航流程，同页 fragment 变化复用当前文档并更新历史。通过 `self`、`globalThis`、`top`、`parent`、`frames` 的 `location.href` 赋值行为相同。直接调用 `location.assign(url)` 或上述全局别名的 `location.assign(url)` 会用同样的相对地址解析并追加历史；`location.replace(url)` 或上述全局别名的 `location.replace(url)` 会替换当前历史项并清空前进历史，同页 fragment 替换当前地址和历史项而不重新获取文档。纯 HTML 管线没有页面地址时返回空字符串。图形页面按 GUI 的聚焦与失焦事件维护只读的 `document.activeElement`，覆盖文本框、按钮、复选框、单选框、下拉选项和可点击链接；没有匹配焦点节点时返回 `document.body`。带内部身份的 DOM 节点可按身份比较。GUI 聚焦变化会在目标元素上派发不冒泡的 `focus`、`blur` 事件。已连接的常见控件、带 `href` 的链接及带 `tabindex` 或 `onclick` 的元素支持 `focus()`、`blur()` 更新脚本可读的活动元素快照；这些方法尚不驱动 GUI 原生焦点，也不派发焦点事件。数组和普通对象的引用相等、`navigator`、窗口方法与全局属性枚举尚未实现。

图形页面脚本可通过 `history` 或 `window.history` 调用 `back()`、`forward()` 与 `go(delta?)`；历史栈头为最近项，`go()` 与 `go(0)` 重新 GET 当前地址并保留历史位置。超出历史范围的移动不改变页面。历史遍历会按目标地址重新 GET，并恢复该历史项保存的控件值与勾选状态。`pushState`、`replaceState` 与 `state` 尚未支持。
HTML `autofocus` 会把初始 GUI 焦点交给文档顺序中首个带该属性且可聚焦的元素，并触发 `focus` 事件。
DOM 元素可读写 `outerHTML`，读取时按 HTML 规则序列化自身；给已连接元素赋值会解析零个或多个顶层节点，并按内部身份在文档树与当前环境中的祖先绑定里替换目标元素。脱离文档树的元素与文档根节点赋值不改文档；原元素的脚本引用仍指向被移除的节点。
`console.log`、`console.info`、`console.warn`、`console.error` 与 `console.debug` 可用；通过 `window.console` 也可调用。每个参数各输出一行到宿主标准输出，完整控制台格式化与分组尚未实现。

相对地址以 `?` 开头时，保留当前路径并替换查询串；以 `#` 开头时，保留当前查询串。

在当前支持冒泡的事件中，处理器可调用 `event.stopPropagation()` 阻止事件继续传给后续祖先；同一元素上的其余监听器仍会执行，此方法不取消默认行为。`event.stopImmediatePropagation()` 还会停止当前元素上后续的事件监听器。

动态 DOM 支持 `parent.insertBefore(newNode, referenceNode)`：参照节点须为父节点的直接子节点，传 `null` 时追加；文档树中的旧元素节点会先从原位置移走。脱树父节点可通过当前环境中的直接节点绑定更新。文字与注释节点尚无内部身份，重复内容可能选错参照；移动时旧位置也可能保留而出现重复节点。

`addEventListener` 接受内置类型与自定义事件类型。`dispatchEvent(eventLike)` 接受带非空字符串 `type` 的普通对象；先运行目标节点上的内联 `on<type>` 与监听器，再按 `bubbles` 真值沿祖先冒泡。处理器中的 `event.target` 固定为派发目标，`currentTarget` 与 `this` 随当前节点变化；`preventDefault()` 仅对 `cancelable` 为真的事件生效，取消后 `dispatchEvent` 返回 `false`。`stopPropagation()` 保留当前节点的其余监听器并停止后续祖先；`stopImmediatePropagation()` 还停止当前节点的后续监听器。`Event` 与 `CustomEvent` 全局值可读取；支持直接标识符形式 `new Event(type, options)` 与 `new CustomEvent(type, options)`，其 `bubbles`、`cancelable` 与 `CustomEvent.detail` 字段可用，直接调用构造器会报错。构造结果采用普通属性对象表示，没有原生原型与对象身份。派发为每个处理阶段构造事件视图并保留自定义字段；处理器保存的阶段视图在派发结束后仍保留其 `currentTarget`，不会清为 `null`。捕获阶段与原生默认动作尚未实现。

- **HTML 基准网址**：文档树中首个带 `href` 属性的 `<base>` 为相对网址解析设定基址；空 `href` 使用最终页面地址。锚链接、表单 `action`、外链样式表和外链脚本都按此基址解析，`#fragment` 链接也按此基址定位。图形模式脚本可只读 `document.baseURI`；它反映当前文档 URL 与有效 `<base href>`，并在初始脚本组执行后及每轮 GUI 事件处理后刷新。同一轮脚本处理过程中改动 `<base>`，新值到该轮结束后才可读到。图形模式下，`document.URL` 与 `document.documentURI` 返回已提交页面的最终地址，并随页面状态提交更新；纯 HTML 管线无页面地址时返回空串。外部资源仍须使用受支持的 HTTP(S) 地址并获来源授权。`<base target>` 尚未支持。
