# 终端浏览器

在终端中显示简单 HTTP 网页的实验性浏览器。

## 组成

- **网页抓取**：通过标准库的明文 HTTP 客户端获取页面；尚不支持 HTTPS、重定向或分块响应。
- **超文本标记解析**：自造词法与建树，不用外部解析器。
- **样式**：自造样式表解析、选择器匹配与层叠。
- **布局**：自造盒模型、块级布局与折行。
- **脚本**：支持部分 JavaScript 语法与文档对象接口，仅执行页面内脚本。
- **渲染**：终端着色输出。

## 用法

```sh
./yy豫构 构建 终端浏览器 --输出 yy终端浏览器
./yy终端浏览器 http://example.com/
```

当前入口只接受 HTTP 网址，不读取本地文件；它输出一次页面文本，尚无链接导航与交互。
