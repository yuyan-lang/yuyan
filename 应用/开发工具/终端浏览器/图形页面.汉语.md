# 图形页面

工具栏提供页内查找输入框和“查找下一个”按钮；在输入框按回车也会定位下一个匹配项。查找按 DOM 文档顺序循环定位含查询词的可见文本节点，并显示当前序号、命中总数和该文本节点的文字预览；含查询词的文本节点会整段显示浅黄色背景。每个文本节点只计一次；跨文本节点的词语、同一文本节点内的后续重复位置、字符级高亮以及将普通文本块滚动到视口中尚未支持。隐藏元素的文字和浏览器工具栏文字不参与查找。

图形页面内容区获得焦点时，Ctrl+R 刷新当前页，Alt+左箭头返回，Alt+右箭头前进。工具栏输入框位于快捷键监听区之外；页面文本输入框中的这些组合键不触发浏览器快捷键。

GET 表单字段按 UTF‑8 字节进行表单网址编码：空格写作 `+`，非安全字节写作 `%HH`，中文及其他非 ASCII 内容可正确提交。

命名的提交按钮会作为成功控件加入请求：`<button>` 未设 `value` 时提交其文字，`<input type="submit">` 未设 `value` 时提交显示标签“提交”。

页面脚本设置控件的 `value` 后，页面重绘与后续表单提交会读取 DOM 的新值；用户输入也会同步写回 DOM。

包裹 checkbox/radio 的 `<label>` 文本可以点击切换对应控件；`for` 属性也可按同一文档中的控件 `id` 激活外置 checkbox/radio。

`<select>` 会递归收集 `<optgroup>` 内的 `<option>`；带 `disabled` 的选项不可选择。单选框以首个 `selected` 项为初值，否则取首个选项；`<select multiple>` 以显式标记为初值，可独立切换多个选项，GET 提交会为每个选中项生成同名字段，`select.value` 为首个选中项的值。JavaScript 设置 `select.value` 时会选中首个匹配的选项并清除其他选项的选中状态；无匹配项时清空选择。选项的 `selected` 属性可由 JavaScript 读取和设置。

CSS `position:absolute` 按父元素内距盒定位，`top`、`right`、`bottom`、`left` 支持整数 `px` 与 `0`；`position:relative` 支持同样单位的偏移。`fixed`、`sticky` 与百分比定位值尚未支持。

表单提交会校验非空 `email`（单个 `@` 且两侧有内容）、`url`（以 `http://` 或 `https://` 开头）及 `number`（可选正负号、至少一位数字、至多一个小数点）；`min`、`max` 按相同的简单十进制格式约束范围，无效范围值会忽略。指数记法与 `step` 暂不校验。非空 `date` 值按固定 `YYYY-MM-DD` 校验年月日和公历闰年，合法 `min`、`max` 按日期范围约束，无效约束值会忽略；日期输入以文本框录入，原生日期选择器尚未支持。`required` 还会校验支持的文本输入、`textarea`、`select`、checkbox 和 radio 组。radio 同名组中任一项选中即满足必填。校验失败时禁用提交按钮并显示提示。

块级元素默认纵排；`display:flex` 默认横排，支持 `flex-direction:column` 纵排，并将整数 `px` 或 `0` 的 `gap` 映射为子项间距。`flex-wrap:wrap` 支持换行；`justify-content` 支持居中、末端、两端与均分，`align-items` 支持居中、末端、基线与拉伸。`flex-grow`、`flex-shrink` 支持非负整数，`flex-basis` 支持整数 `px` 与 `0`；`flex` 简写支持单个非负整数以及 `auto`、`none`、`initial`，`align-self` 支持起点、居中、末端、基线与拉伸。上述子项属性仅作用于直接父元素为 `display:flex` 的元素。`column-reverse`、`row-reverse` 与 `wrap-reverse` 不反转顺序；`flex-start` 等默认起点对齐由布局引擎处理；多值 `flex` 简写和其他 `display` 类型尚未映射。

HTML 表格的 `table`、`thead`、`tbody`、`tfoot` 按块级容器纵排；`tr` 横排其单元格，`td` 与 `th` 各自显示为单元格容器。同一行内按 `colspan` 跨度比例分配可用宽度，未标跨度时单元格均分；当前仅识别无前导零、无空白的正十进制整数，其余跨度值按一列处理。表格和行有少量默认间距，表头加粗。不同列数的行不会共享列宽；`rowspan` 与 `border-collapse` 尚未支持。

块级元素与表单控件应用 `width`、`height` 的整数 `px`、`0` 和百分比；`min-width`、`max-width`、`min-height`、`max-height` 支持整数 `px` 与 `0`。

HTML 标题 `h1`–`h6` 按层级显示字号并加粗；`blockquote`、`ul`、`ol` 使用默认缩进，`hr` 显示分隔线。无序列表以圆点标记；有序列表以圈码标记 1–10 项并遵循 `start`，超过 10 项暂以圆点标记。作者 CSS 会覆盖默认标题与容器样式。

HTML `<button>`、`<input type="button">` 与 `<input type="submit">` 显示为原生按钮；`<button>` 拼接后代文字，input 按钮使用 `value`，均遵循 `disabled`。表单内省略 `type` 或指定 `type="submit"` 的 `<button>`、以及 `<input type="submit">`，会提交 GET 表单；提交按钮带 `name` 时也会提交其 `value`。`<button type="reset">` 与 `<input type="reset">` 会将所属表单控件还原为页面中的 HTML 默认值。POST 表单的提交按钮禁用。按钮自身与祖先的 `onclick` 均可调用 `event.preventDefault()` 取消默认提交或重置；未取消时照按钮类型执行默认动作。禁用按钮不派发点击事件。

文本输入框与多行文本框显示 `placeholder` 并遵循 `disabled`；禁用的输入框、复选框和单选框不可操作，也不参加表单提交。

GET 表单提交会保留 action 已有的查询参数，并把新字段放在 URL 片段之前。

这是终端浏览器的图形界面版本。命令行网址仍由浏览器管线获取、解析并执行页面脚本；脚本执行后的 DOM 文字交由仓库已有的「界面自绘」和「显示控件」包显示在“终端浏览器”显示面。HTML 中的 `<a href>` 会显示为可点击文字，点击后获取并显示目标页；脚本插入的链接也会收集。`#fragment` 同页链接更新地址栏与访问历史并复用当前页面，不重新获取文档；匹配元素的 `id` 或 `<a name>` 会聚焦并滚入可视区。元素上的 `onclick` 会在原页面 JavaScript 环境中执行，输入控件当前值同步到 DOM 供处理器读取；DOM 更新后页面随之重绘。段落和标题内的文字按行内流显示；`span`、`b`、`strong`、`u`、`s`、`strike`、`del` 上匹配到的字号、颜色、背景、粗体与装饰会作用于相应文字片段，带 `onclick` 的行内文字保留点击热区。

命令行页面渲染会分别输出元素与文字节点；文字按深度缩进，并应用其直接父元素的终端颜色、背景和粗体样式。正值 `margin-left` 与 `padding-left` 各增加一级缩进；正值上、下边距与内边距各增加一行空白。终端按行显示，右侧盒距不映射为可见宽度；行内文字各占一行，复杂的多层样式继承尚未支持。

浏览器工具栏（地址栏、返回、前进、刷新与查找控件）固定在页面上方；网页元素树单独滚动，工具栏保持可见。刷新会按当前地址重新 GET 并保留当前历史位置；POST 页重载时不重放正文。块级元素建立纵排容器，段落行内片段保留文字、锚链接热区与 `<br>` 换行；`<script>`、`<style>`、`<textarea>`、`<title>` 的正文按原始文本保留，直到相应结束标签，避免把其中的 `<` 误作标记；标签名按 ASCII 大小写不敏感处理。`<img>` 显示 `alt` 替代文字，缺少 `alt` 时显示 `[图片]`，空 `alt` 不显示文字，替代文字继承链接热区。普通文本中的连续空格、制表符和换行折叠为一个空格，`<pre>` 内保留这些空白。元素按匹配到的外链与嵌入样式应用 `display:none`、`color`、`background-color`、`font-size`、`font-weight`、`margin` 与 `padding`。盒距支持 `px` 整数值、`0`，以及一至四值简写和各边长写；简写顺序遵循上、右、下、左扩展，长写边值优先。其他单位当前按零处理。`<link rel="stylesheet" href="…">` 在标签所在位置获取；外链与文内 `<style>` 按文档顺序参与层叠。样式表来源须获网络授权。链接上的 `onclick` 会冒泡，事件目标保持原触发元素，`event.currentTarget` 与 `this` 随当前处理器变化；自身或祖先处理器可调用 `event.preventDefault()` 取消普通导航，未取消时继续导航。普通链接即使自身无 `onclick`，也会先触发祖先处理器。复选框与单选框直接点击时先改变勾选状态，再依次沿祖先路径派发 `onclick`、`onchange`；经 `<label>` 转发时，控件与 label 之间的包装元素也沿真实祖先路径收到事件。`event.target` 固定为输入控件，`event.currentTarget` 与 `this` 随处理器变化，禁用控件不派发。`event.preventDefault()` 当前仅取消链接导航与按钮提交/重置；完整事件对象及其他默认行为尚未支持。编辑地址后提交即可导航，点击普通链接会同步地址栏并记录当前页；返回与前进按钮沿访问历史移动。仅输入域名时自动补 `http://`，新导航会清除前进记录。导航解析 HTTP(S) 绝对地址、协议相对地址、站点根路径和当前目录相对路径，并规范化路径中的 `.`、`..` 段且保留重复斜杠；query 与 fragment 后缀保持原样。

GUI 盒样式支持 `border: <整数>px solid <颜色>` 与 `border-radius: <整数>px` 或 `0`；颜色沿用页面支持的常见颜色名和三位、六位十六进制写法。

仅含 query 的相对地址会保留当前路径并替换旧 query；以 fragment 开头的相对地址保留当前 query。

`text`、`email`、`search`、`url`、`tel`、`number` 输入框与 `<textarea>` 带 `id` 或 `name` 时可编辑；`hidden` 字段参与提交。`<select>` 的各 `<option>` 显示为可点选项，按选中状态标记；首个 `selected` 选项为初值，否则取第一个选项。选择变化会执行 `onchange`，所选值会参与 GET 提交。复选框显示当前勾选状态，可点击切换；单选框显示所选状态，按 `name` 互斥。GET/POST 表单只提交带 `name` 且已勾选的复选框与单选框，并使用其 `value`，未指定时默认值为 `on`。表单内的单选框只与同一表单内同名控件互斥；优先用表单 `id` 或 `name` 定位，缺少时按地址、方法和字段匹配。表单外的单选框仍按整页同名分组。其他带 `name` 的 GET 字段会附到 action 查询串，POST 字段以 UTF-8 编码的 `application/x-www-form-urlencoded` 正文发送；响应按网页显示并加入历史。前进到 POST 历史项时按 URL 重新 GET，不重放正文。查询串会转义空格、`&`、`=`、`+`、`%`、`#`、`?`；其他字符保持原样。`<button>` 未写 `type` 时按提交按钮处理，`type="button"` 与 `type="reset"` 不提交表单。表单内文本框按回车会执行其 `onkeydown` 处理器；未设置时提交所属 GET/POST 表单。图片位图、文件选择与复杂嵌套行内样式尚未支持。图形显示是否可用，取决于启动宿主是否提供并授权“终端浏览器”显示面。

`<input type="date">` 作为可编辑文本框接收并提交 `YYYY-MM-DD` 值。

文本输入与多行文本输入会在键入时执行 `oninput`，处理器中的 `event.type` 为 `input`；事件沿父元素冒泡。下拉框选项变化时执行 `onchange`，处理器中的 `event.type` 为 `change`；事件沿父元素冒泡。

表单文本框按回车会沿父元素路径执行 `onkeydown`；处理器中的 `event.type` 为 `keydown`，`event.key` 为 `Enter`。若路径上的处理器均未调用 `event.preventDefault()`，就提交所属 GET/POST 表单。文本框转发的其他按键也会沿路径执行 `onkeydown`，`event.key` 使用常见 DOM 键名；文本编辑控件自行处理的按键不会转发。

块级元素支持 CSS `text-align: left/start`、`center`、`right/end` 与 `justify`。
普通纵排块容器把连续文字与常见行内元素合成同一段落；computed `display:none` 跳过，`display:inline` 纳入行内流，`block` 与 `flex` 作为分段边界并沿原有容器路径渲染。表单控件保留专用控件渲染，flex 父容器保留每个直接子项的 flex 布局。
块级文字支持无单位数字形式的 CSS `line-height`，按字号倍数参与 GUI 文本排版。
文字空白处理支持继承 CSS `white-space: pre`、`pre-wrap`，子元素可用 `normal` 取消空白保留。
HTML 元素上的 `style` 声明会并入该元素的 CSS 样式，并覆盖同属性的普通样式表值。脚本可读写 `element.style.cssText`，也可用 `element.style.color`、`element.style.backgroundColor`、`element.style.display` 等点属性读取或改写单条内联声明；驼峰属性名会转换为 CSS 连字符名。改写会替换同名内联声明并保留其他声明；`setProperty`、`getPropertyValue`、`removeProperty` 可读写 CSS 声明，`setProperty` 支持 `important` 优先级。自定义属性名按大小写精确匹配；CSS 值中的 `var()` 会递归替换，函数名不区分 ASCII 大小写，支持组合值、嵌套回退与循环回退，并保留 fallback 空白；引号内的 `var()` 不替换。`length` 与方括号属性访问尚未支持。
通配、标签、类、ID、属性存在（如 `[disabled]`）、属性等值（如 `[type="text"]`）、前缀（`[href^="https"]`）、后缀（`[href$=".html"]`）、子串（`[class*="card"]`）、空白词（`[class~="card"]`）及连字符前缀（`[lang|="zh"]`）选择器、`:first-child`、`:last-child`、`:only-child`、`:nth-child(odd/even)`、整数与 An+B（如 `:nth-child(2n+1)`、`:nth-child(-n+3)`）、`:empty`、`:checked`、`:disabled`、`:required` 与 `:optional`、同一元素上的复合简单选择子、空白分隔的后代选择子与直接子代组合符（如 `main > p`）按祖先路径匹配；`>` 两侧须留空格。结构伪类只计父节点下的元素子项，文字与注释不参与位置判断。`:required` 与 `:optional` 只匹配支持该属性的 `input`、`select`、`textarea` 控件，且按 `required` 属性是否存在判定；`input` 的 `hidden`、`button`、`submit`、`reset`、`image`、`range`、`color` 类型不参与匹配；不计算当前值有效性。逗号分隔的选择器组按每个命中分支的 specificity 参与级联。属性选择器的值须连续书写，属性值目前不支持空格。GUI 块级容器、段落、标签、表单、列表项及行内样式均应用路径匹配结果。`<select>` 的选项专用渲染路径尚未传递祖先列。复合选择子的标签、类、属性、ID 与伪类 specificity 参与级联，同优先级按源码顺序覆盖；属性大小写标志与其余伪类尚未支持。
图形页支持 CSS `:hover`；悬停样式映入自绘层的 `悬停时` 状态变体，并按常态规则与悬停规则共同级联。首版悬停状态取当前被设样元素的 GUI 悬停状态；`section:hover a` 会在指针进入 `a` 时生效，指针只在 `section` 其他位置时不会改变 `a`。脚本 `querySelector` 与 `matches` 没有 GUI 悬停元素身份，因此包含 `:hover` 的查询不会匹配。

类选择子按空白分隔后精确匹配，例如 `.btn` 不会命中 `btn-large`。
HTML 空元素（如 `img`、`input`、`br`、`meta`）会直接成为叶节点，`/>` 自闭合标记也会立即结束元素。
页面脚本按文档次序收集；带 `src` 的 `<script>` 会按当前页面解析相对地址，同步读取后与内联脚本一并执行；来源须获 `--允许源` 授权，请求失败则跳过。`async`、`defer`、`type="module"` 与动态插入脚本尚未按浏览器语义处理。
图形页的初始脚本执行完毕后，会在 `document` 上派发一次不可冒泡、不可取消的 `DOMContentLoaded` 事件；正常结束的处理器修改的 DOM 会显示在首次渲染中。处理器抛错时，本次派发中的环境更新可能回退，但页面仍继续渲染。之后按注册顺序在 `window` 上派发不可冒泡、不可取消的 `load` 事件，再调用 `window.onload`；`load` 回调的 `this`、`event.target` 和 `event.currentTarget` 都是 `window`。

初始页面脚本和 `DOMContentLoaded` 处理器读取 `document.readyState` 时得到 `interactive`；`DOMContentLoaded` 处理后值变为 `complete`，随后派发 `window` 的 `load` 事件并调用已赋值的 `window.onload` 回调。`window.addEventListener('load', callback)` 和 `removeEventListener('load', callback)` 支持按函数身份注册、移除；重复注册同一函数会忽略，监听选项暂不支持。派发开始时固定本轮监听器序列；事件处理中移除尚未调用的监听器不会改变当前派发。监听器收到含 `type`、`target`、`currentTarget`、`bubbles`、`cancelable` 与 `defaultPrevented` 的事件对象；处理器异常不会阻断页面显示，但本次事件或回调中的环境更新可能回退。

脚本可调用 `location.assign(url)`、`window.location.assign(url)`、`location.replace(url)` 或 `window.location.replace(url)` 导航；相对地址按当前页面解析。`assign` 会追加历史项；`replace` 替换当前历史项并清空前向历史。同页 fragment 导航复用当前文档；使用 `replace` 时更新当前地址和历史项，不重新获取文档。`self`、`globalThis`、`top`、`parent` 与 `frames` 上的 `location.assign(url)` 和 `location.replace(url)` 行为相同。给 `location` 或上述全局对象的 `location` 属性赋值也会按 `href` 规则导航并追加历史。

脚本可通过 `history` 或 `window.history` 调用 `back()`、`forward()` 和 `go(delta?)`。历史栈头是最近项；省略 `delta` 或传入 `0` 时按当前地址重新 GET，并保留历史位置。越界移动不改变页面。历史遍历按目标地址重新 GET，并恢复该历史项保存的控件值与勾选状态。`pushState`、`replaceState` 与 `state` 尚未支持。

图形页脚本可读写 `location.pathname`、`location.search`、`location.hash` 及对应的 `window.location` 属性；路径不含查询串与片段，查询串含前导 `?`，片段含前导 `#`，不存在时为空串。导航、同页片段变化及历史切换后，这些属性值与 `location.href` 同步。给 `pathname` 赋值替换路径并保留查询串与片段；缺少开头的 `/` 时会补上，空值设为 `/`，HTTP(S) 路径中的反斜杠按路径分隔符转为 `/`。给 `search` 赋值替换查询串并保留片段；给 `hash` 赋值替换片段并保留路径与查询串。查询串与片段赋值可省略 `?`、`#` 前缀；空值移除对应部分。路径、查询串与片段赋值会按 URL 部件规则对空格、非 ASCII 字符及相应分隔符作百分号编码。赋值沿用 `href` 导航流程，因此同页片段变化复用当前文档并更新历史。
脚本 DOM API 支持 `document.getElementById`、`getElementsByTagName`、`getElementsByClassName`、`querySelector` 与 `querySelectorAll`；节点集合可下标读取并带 `length`。这些查询与元素的 `matches(selector)` 共用 CSS 已实现的选择器范围：逗号分隔的选择器组、`*`、标签、`#id`、`.class`、`[name]`、`[name=value]`、`[name^=value]`、`[name$=value]`、`[name*=value]`、`[name~=word]`、`[name|=prefix]`、`:first-child`、`:last-child`、`:only-child`、`:nth-child(odd/even)`、整数及 An+B 参数（如 `:nth-child(2n+1)`、`:nth-child(-n+3)`）、`:empty`、`:checked`、`:disabled`、`:required`、`:optional`、同一元素上的复合简单选择器、空白分隔的后代选择器与直接子代组合符（如 `main > p`，`>` 两侧须留空格）。结构伪类只计父节点下的元素子项；`:required` 与 `:optional` 仅匹配适用的表单控件并依 `required` 属性判定，不校验当前值有效性；等值属性选择器接受成对的单引号或双引号，`~=` 按空白词匹配，`|=` 匹配精确值或连字符前缀。
元素支持 `matches(selector)`；后代选择器按元素在当前文档树中的祖先路径判断。
节点支持 `contains(otherNode)`；自身或其后代节点返回 `true`，缺少参数或参数不是节点时返回 `false`，对脱离文档的子树也按当前子树判断。
元素的 `innerText` 可读取或替换其文字内容；写入会更新 DOM 并重绘。`innerHTML` 读取子树的 HTML 序列化结果，写入时解析标记；运行器加入的私有身份属性不会泄露。DOM 节点只读提供 `nodeType` 与 `nodeName`，元素另有 `tagName`；元素名为 ASCII 大写，文字、注释、文档节点名分别为 `#text`、`#comment`、`#document`，节点类型值分别为 1、3、8、9。
DOM 节点可读取 `childNodes`（全部直接子节点，含文字与注释）、`children`（仅元素子节点）、`firstChild`、`lastChild`、`firstElementChild`、`lastElementChild` 与 `childElementCount`。两个子节点集合每次读取返回可下标访问且带 `length` 的即时快照；无首末节点时返回 `null`。
节点的 `parentNode` 返回直接父节点，`parentElement` 返回直接元素父节点；文档根节点和脱离文档树节点没有父节点时返回 `null`。
节点可读取 `previousSibling`、`nextSibling`、`previousElementSibling` 和 `nextElementSibling`；元素兄弟属性仅搜索相邻元素并跳过文字、注释节点。文字或注释节点内容相同且位于不同位置时，当前树查询可能命中首个结构相同节点。
脚本可直接读写元素的 `name`、`type`、`placeholder`、`alt`、`src` 属性；`disabled` 作为布尔属性读写，影响禁用控件交互。复选框与单选框的 `checked` 读写当前勾选状态，`defaultChecked` 读写表单重置所用的默认状态；修改 `checked` 后再改 `defaultChecked` 不会覆盖当前勾选，表单重置会回到默认状态。
`document.title` 读取 `<title>` 的文字；有 `<title>` 时，赋值会替换其文字并更新文档树。
元素的 `removeChild(node)` 会从当前元素移除指定的直接子节点并返回该节点；缺少参数、参数不是节点、目标不是直接子节点或父元素脱离文档树时会报错。带 `id` 的元素可调用 `remove()` 从文档树移除；删除后页面重绘并更新脚本中的 `document`。
`Element.replaceChild(newChild, oldChild)` 会用新节点替换当前元素的直接子节点，并返回被移除的旧节点。两个参数都必需且必须是节点，旧节点必须是直接子节点；新节点包含当前父元素时会报层级错误，父元素脱离文档树时也会报错。同一节点作为新旧参数时不修改树并返回该节点。替换会复用 `insertBefore` 的节点移动逻辑；带身份的元素可从文档树中的原位置移走。文字与注释节点尚无内部身份，内容相同的节点可能被误认。
元素可调用 `hasAttribute(name)` 检查属性是否存在；带 `id` 的元素可调用 `setAttribute(name, value)` 与 `removeAttribute(name)` 修改属性，变更会写回文档树并重绘。
元素还可调用 `toggleAttribute(name, force?)`：属性名必需；省略 `force` 时反转属性是否存在，提供时按其真值强制设置存在或移除。方法返回最终的存在状态；仅当前文档树中的元素会变更属性并重绘，脱离文档树的元素保持原状并返回原存在状态。
设置元素 `innerHTML` 时，会把新内容解析为 HTML 子节点并参与重绘。
初始 HTML 中的 `<link rel="stylesheet">` 与 `<style>` 按标记顺序参与级联。脚本或事件更新 DOM 后，新增或改写的样式源按新树遍历顺序追加规则；旧树及本批次已出现的外链 href 不会重复请求，仍受来源授权约束。移除或移动已加载样式源不会撤销或重排旧规则；改写样式内容会追加新规则，旧规则暂留。
复选框与单选框先更新勾选状态，再按序沿祖先路径触发 `onclick`、`onchange`；处理器可读取更新后的 `document`，事件目标保持输入控件，当前目标随处理器变化。禁用控件不派发事件。

文本样式支持 CSS `text-decoration-line`，以及 `text-decoration` 简写中的 `underline` 和 `line-through`。

HTML 数值字符引用中，U+0080–U+009F 范围内由 HTML 规范列出的 27 个值会映射为对应替代字符；其余控制码保留原值。

GUI 显示会解码正文和浏览器使用的 HTML 属性中的十进制及十六进制数值字符引用，分号可省略；无效码点会替换为 U+FFFD。命名实体支持 `&lt;`、`&gt;`、`&quot;`、`&apos;`、`&nbsp;`、`&amp;`、`&copy;`、`&reg;`、`&trade;`、`&ndash;`、`&mdash;`、`&hellip;`、`&lsquo;`、`&rsquo;`、`&ldquo;`、`&rdquo;`、`&bull;`、`&cent;`、`&pound;`、`&yen;`、`&euro;`、`&deg;`、`&plusmn;`、`&times;`、`&divide;`、`&middot;`、`&sect;`、`&para;`、`&frac14;`、`&frac12;`、`&frac34;`、`&laquo;`、`&raquo;`、`&iexcl;`、`&iquest;`、`&larr;`、`&uarr;`、`&rarr;`、`&darr;` 与 `&check;`；完整命名实体表尚未支持。

HTTP(S) 网页导航及 GET/POST 表单请求会跟随带 `Location` 的 301、302、303、307、308 响应，最多跟随 100 次；跳转地址支持绝对地址、协议相对地址、根路径、目录相对路径及 query/fragment 相对地址。POST 遇 301、302 或 303 时改为 GET 并清除正文与请求头；307、308 保留原请求。地址栏与历史记录使用最终响应地址。

地址栏下方显示最终 HTTP 响应状态码；普通导航、刷新与 GET/POST 表单均显示最终响应的码。返回、前进和同页 fragment 导航沿用对应历史页的状态码。

跨页面返回或前进后，浏览器会重取文档并按控件 `id` 或 `name` 恢复文本输入框、多行文本框与下拉框的当前值；复选框和单选框按唯一 DOM 节点身份恢复勾选状态。恢复后的 DOM 会写回脚本的 `document`。页面结构变化时，找不到的控件会跳过；缺少节点身份的控件不会恢复，节点身份改变时勾选状态也可能无法对应原控件。

在当前支持冒泡的事件中，处理器可调用 `event.stopPropagation()` 阻止事件继续传给后续祖先；同一元素上的其余监听器仍会执行，此方法不取消默认行为。`event.stopImmediatePropagation()` 还会停止当前元素上后续的事件监听器。

`Node.insertBefore(newNode, referenceNode)` 会在参照节点前插入并返回新节点；参照节点须为父节点的直接子节点，传 `null` 时追加。文档树中的旧元素节点会先从原位置移走；脱树父节点通过脚本环境中的直接绑定更新。文字与注释节点尚无内部身份，重复内容可能选错参照；移动时旧位置也可能保留而出现重复节点。

脚本可对 DOM 元素调用 `dispatchEvent(eventLike)` 触发事件。它接受带非空字符串 `type` 的普通对象；直接标识符形式 `new Event(type, options)` 与 `new CustomEvent(type, options)` 可构造含 `bubbles`、`cancelable` 和 `detail` 字段的事件值，构造器全局值也可读取。派发从目标到祖先，同一节点先运行内联处理器再运行注册监听器。处理器保存的事件视图是各节点阶段快照，派发结束后其 `currentTarget` 不会清为 `null`。构造结果采用普通属性对象，没有原生事件原型与对象身份；构造器属性调用、捕获阶段与原生默认动作尚未实现。

## HTML 基准网址

文档树中首个带 `href` 属性的 `<base>` 为相对网址解析设定基址；空 `href` 使用最终页面地址。锚链接、表单 `action`、外链样式表和外链脚本都按此基址解析，`#fragment` 链接也按此基址定位。图形模式脚本可只读 `document.baseURI`；它反映当前文档 URL 与有效 `<base href>`，并在初始脚本组执行后及每轮 GUI 事件处理后刷新。同一轮脚本处理过程中改动 `<base>`，新值到该轮结束后才可读到。图形模式下，`document.URL` 与 `document.documentURI` 返回已提交页面的最终地址，并随页面状态提交更新；纯 HTML 管线无页面地址时返回空串。外部资源仍须使用受支持的 HTTP(S) 地址并获来源授权。`<base target>` 尚未支持。
