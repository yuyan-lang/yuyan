# 图形之面

工具栏横列，地不足则换行；正文滚区占视口之余。地址栏既输入网址，按 Enter 则往；刷新钮复请今已载之址。请求败则示告，毋留空白页；HTTP 状态码见于工具栏。

工具列有页内查文之框与「查下处」之钮；于查框按回车，亦定位次一命中。循 DOM 文序，环寻含所求之可见文节，显今序、总数与中节文之预览；凡含所求词之文节，皆涂浅黄底。每文节惟计一命中；跨文节之词、同节后续重见、逐字高亮及令常文块滚入可视区，皆未备。隐元之文与浏览器工具列之文不入寻。

图形页之内容区得焦时，Ctrl+R 刷今页，Alt+左箭头返，Alt+右箭头进。工具列输入器在监听区外；页中文本输入器之此组合键不触发浏览器快捷键。

GET 表字段依 UTF‑8 字节作网址表编码：空白作 `+`，不安全之字节作 `%HH`，中文及余非 ASCII 文皆可正提交。

有名之提交钮亦入请求：`<button>` 无 `value` 则提交其文，`<input type="submit">` 无 `value` 则提交所显之「提交」。

页脚本易器之 `value` 后，重绘及后续表提交皆取 DOM 新值；人所输入亦回书 DOM。

包裹 checkbox/radio 之 `<label>` 文可点击而易其器；`for` 亦循同文树控件之 `id` 激活外置之复、单选器。

`<select>` 递收 `<optgroup>` 中之 `<option>`；带 `disabled` 者不可选。单选以首个 `selected` 项为初值，否则取首项；`<select multiple>` 以显式选态为初值，可各自易诸选项，GET 表每个选中项皆成同名字段，`select.value` 取首选项之值。JavaScript 设 `select.value`，则首个同值项选而余项皆除其选态；无同值项则清空之。`selected` 属可由 JavaScript 读写。

`<script>`、`<style>`、`<textarea>`、`<title>` 之文皆存为原文，直至相应之闭标记，不以其中 `<` 为标；标签名之 ASCII 大小写不敏感。

CSS `position:absolute` 依父元内距盒定位；`top`、`right`、`bottom`、`left` 受整数 `px` 与 `0`；`position:relative` 亦受其偏移。`fixed`、`sticky` 与百分定位尚未备。

表提交时校验非空 `email`（惟一 `@` 且两侧有文）、`url`（以 `http://` 或 `https://` 起）与 `number`（正负号可无，至少一数位，点至多一）；`min`、`max` 循同式约范围，无效界值则略。指数与 `step` 尚不验。非空 `date` 依定式 `YYYY-MM-DD` 验年月日与公历闰岁；合法 `min`、`max` 约日期之界，无效界值则略。日期以文本框书入，原生选日器尚未备。`required` 亦校验已受之文输入、`textarea`、`select`、复选、单选组。同名单选一项既选，即足其必；验不合则禁提交钮而示提示。

块元常纵列；`display:flex` 默认横列，受 `flex-direction:column` 纵列，并以整数 `px` 或 `0` 之 `gap` 为子距。`flex-wrap:wrap` 可折行；`justify-content` 受居中、末、两端、均分，`align-items` 受居中、末、基线、拉伸。`flex-grow`、`flex-shrink` 受非负整数，`flex-basis` 受整数 `px` 与 `0`；`flex` 简写受单一非负整数及 `auto`、`none`、`initial`，`align-self` 受起、居中、末、基线、拉伸。诸子项属性惟直父为 `display:flex` 之元乃效。`column-reverse`、`row-reverse`、`wrap-reverse` 皆不逆其序；`flex-start` 等起齐从布局擎之默认。多值 `flex` 简写及余种 `display` 尚未映。
HTML 表格之 `table`、`thead`、`tbody`、`tfoot` 依块容器而纵列；`tr` 横列其格，`td`、`th` 各为格容器。同一行循 `colspan` 跨度之比例分其可用宽；无跨度者均分。今惟识无前导零、无空白之正十进制整数，其余跨度值皆视一列。表与行略有默认间距，表头加粗。列数异之行不共列宽；`rowspan` 与 `border-collapse` 尚未备。
常纵排块容器中，连文与常行内元合为一段；计算所得 `display:none` 则略，`inline` 入行流，`block` 与 `flex` 则断段而仍循旧容器径。表器仍专径显之；flex 父元仍逐直属子项作弹性布局。

块元与表器之 `width`、`height`，受整数 `px`、`0` 与百分数；四种最小、最大宽高受整数 `px` 与 `0`。

HTML 标题 `h1`–`h6` 依级定字号且加粗；`blockquote`、`ul`、`ol` 有默认缩进，`hr` 显分隔。无序以点为记；有序以圈码记一至十项，且从 `start` 起；逾十项暂记以点。作者 CSS 可覆标题与容器之默认样。

HTML `<button>`、`<input type="button">`、`<input type="submit">` 皆化本钮而显；`<button>` 合其后代之文，input 钮取 `value`，皆承 `disabled`。表中省 `type` 或定 `type="submit"` 之 `<button>`，及 `<input type="submit">`，皆提交 GET 表；提交钮有 `name` 则其 `value` 亦纳。`<button type="reset">` 与 `<input type="reset">` 还原所属表器于 HTML 初值。POST 表之提交钮为禁。钮己与祖元之 `onclick` 皆可呼 `event.preventDefault()` 以止默认之提交或重置；不止则依钮类行其默认。禁钮不发点击事。

文输入器与多行文框显 `placeholder`，且承 `disabled`；禁用之输入、复选、单选皆不可操作，亦不入表。

GET 表提交保留 action 既有之查询参，新字段置于 URL 片段之前。

此乃终端浏览器图形之面。命令列之网址仍由浏览器之管线取之、析之、行页中之脚本；脚本后 DOM 之文，交仓中旧有「界面自绘」与「显示控件」之包，显于名「终端浏览器」之显示面。HTML 中 `<a href>` 之链，显为可点击之文；点击则取目标页而显之，脚本所增之链亦可举。`#fragment` 同页之链，易地址与阅历而仍用今页，不复取文；匹配之 `id` 或 `<a name>` 聚焦而滚入可视之区。诸元之 `onclick`，依旧页之脚境而行，输入器今值亦易于 DOM 以供处置，DOM 有变则重绘。段与标题中之文，循行内之流而显；`span`、`b`、`strong`、`u`、`s`、`strike`、`del` 上所合之字号、色、背景、粗体与饰式，施于相应文字片；行内之文带 `onclick` 者仍有可点击之区。

命令列呈页，则元与文字各自成行；文字依深度缩进，并承直父元之终端色、背景与粗体。正 `margin-left`、`padding-left` 各增一级缩进；正上下外距、内距各增一空行。终端逐行显，右侧盒距不成可见宽。行内文字各占一行，繁层样式之承袭尚未备。

浏览器工具栏（地址、返、进、刷新与查找诸器）常置页首；网页元素之树别入滚区，滚页时工具仍可见。刷新则依今址重作 GET，且守今阅历之位；POST 页重载不复发正文。块元成纵列之器；段内行片保文字、锚链热区与 `<br>` 断行；常文中连空格、制表与换行并为一空格，`<pre>` 之内仍存其白。诸元依所合之内嵌及外链样式施 `display:none`、`color`、`background-color`、`font-size`、`font-weight`、`margin`、`padding`。盒距受整数 `px` 与 `0`，简写一至四值及各边长写；简写依上、右、下、左而扩，长写边值优先。其余单位今皆作零。`<link rel="stylesheet" href="…">` 于标签处取之；外样与内嵌 `<style>` 依文序参与层叠。Node 发行包默认通诸 HTTP(S) 源。链上之 `onclick` 沿祖元上行，`event.target` 恒初发之元，`event.currentTarget` 与 `this` 随今处置元而易。自身或祖元之处置可呼 `event.preventDefault()` 止链之常导航，不止则仍往。复、单选直点时易其勾态，后循祖径先发 `onclick`、继发 `onchange`；经 `<label>` 转发，内控至签之间诸包装元亦循实祖径受事。`event.target` 恒为输入器，`event.currentTarget` 与 `this` 随处置元而易，禁器不发事。`event.preventDefault()` 今唯止链之导航及按钮之提交、重置；全事件对象与余默认事态尚未备。改址而提交则导航，普通链则地址栏亦随之，且存今页；返、进二钮循阅历而移。仅书域名则自动补 `http://`，新导航则清前进之记。导航能解 HTTP(S) 绝对之址、协议相对之址、站点根路径与今目录相对之址，并归一径中之 `.`、`..` 段，且存重复斜线；query、fragment 之尾缀仍其故。

GUI 盒样式受 `border: <整数>px solid <颜色>` 与 `border-radius: <整数>px`、`0`；颜色沿用页中所受之常名及三位、六位十六进制码。

相对址惟含 query，则存当前路径而易旧 query；惟以 fragment 起者，则存当前 query。

`text`、`email`、`search`、`url`、`tel`、`number` 诸输入框及带 `id` 或 `name` 之 `<textarea>` 可书；`hidden` 之值亦入表。`<select>` 诸 `<option>` 显为可点之项，依选态作记；首个 `selected` 为初值，否则取首项。选易则行 `onchange`，其值亦入 GET 表。复选器显其今态，可点击而易之；单选器显所选之态，同 `name` 者互斥。GET/POST 表皆惟纳带 `name` 之字段及已勾之复选、单选，取其 `value`，无则值为 `on`。表内单选惟与本表同名者互斥；先依表之 `id` 或 `name` 定之，皆无则比址、法与字段。表外单选仍以全页同名为组。余 GET 字段附于 action 查询串；POST 字段以 UTF-8 `application/x-www-form-urlencoded` 之正文发送；应答作网页显而入阅历。前进至 POST 阅历项时依 URL 重作 GET，不重发正文。查询串之空白、`&`、`=`、`+`、`%`、`#`、`?`皆作转义，余符仍其故。`<button>` 无 `type` 则作提交钮；`type="button"` 与 `type="reset"` 不提交。表内文本框按回车则行其 `onkeydown`，未阻默认乃提交所属 GET/POST 表。择档、图片与繁嵌行样尚未备。图形之显可否行，视启动之宿主有无所供且所授权之「终端浏览器」显示面。
`<input type="date">` 以文本框受书，值式为 `YYYY-MM-DD`。

文本与多行文本之控件，键入则行 `oninput`，其处置之 `event.type` 为 `input`，且沿父元而上行。下拉选项有变则行 `onchange`，其 `event.type` 为 `change`，亦沿父元而上行。

表内文本框按回车，则沿父元径行 `onkeydown`，其 `event.type` 为 `keydown`，`event.key` 为 `Enter`；径上诸处置皆不呼 `event.preventDefault()`，乃提交所属 GET/POST 表。文本框所转之余键，亦循此径行 `onkeydown`，`event.key` 用常见 DOM 键名；输入器自理之编辑键不转发。

块元之文字可依 CSS `text-align: left/start`、`center`、`right/end`、`justify` 而齐。
块文可依无单位数之 CSS `line-height`，以字号倍数入界面排文。
文之空白可承 CSS `white-space: pre`、`pre-wrap`，子元之 `normal` 可去保留而折之。
HTML 元素之 `style` 声明并入其 CSS 样，且覆样式表中同名之常规值。脚本可取易 `element.style.cssText`，亦可用 `element.style.color`、`element.style.backgroundColor`、`element.style.display` 等点属而读改单一内样；驼峰属名易为 CSS 连字符名。改则易同名旧声明而仍存余项。`setProperty`、`getPropertyValue`、`removeProperty` 可取易 CSS 声明，`setProperty` 受 `important` 优先级。自定义属依大小写精确相比；CSS 值中 `var()` 可递代，其函数名不辨 ASCII 大小写，受组合值、嵌套回退、循环回退并存回退空白；引号中之 `var()` 不代。`length` 与方括号属访问亦未备。
通配、标签、类、标识、属性存有（如 `[disabled]`）、属性等值（如 `[type="text"]`）、前缀（`[href^="https"]`）、后缀（`[href$=".html"]`）、子串（`[class*="card"]`）、空白词（`[class~="card"]`）及连字符前缀（`[lang|="zh"]`）诸选子、`:first-child`、`:last-child`、`:only-child`、`:nth-child(odd/even)`、整数与 An+B（如 `:nth-child(2n+1)`、`:nth-child(-n+3)`）、`:empty`、`:checked`、`:disabled`、`:required`、`:optional`、同元复合之简单选子、空白隔之后代选子与直接子代符（如 `main > p`，`>` 两旁须留空格），皆循祖径而合；结构伪类惟数父元之元素子项，文与注皆不入序。`:required`、`:optional` 惟施于可受此属之 `input`、`select`、`textarea`；`input` 之 `hidden`、`button`、`submit`、`reset`、`image`、`range`、`color` 类型不配；余则依 `required` 属存否而判，未校当前值之有效性。逗号所分诸选子，依各自命中者之 specificity 入级联。属性选子之值须连续书之，今不受空格。GUI 块容、段、签、表、列表项与行内样，皆用沿途之合。`<select>` 选项专径尚未传祖列。复合选子之签、类、属性、标识与伪类 specificity 皆入级联，同等则循文序；属性大小写标志与余伪类尚未备。
图形页受 CSS `:hover`；悬停样入自绘层之 `悬停时` 态变，并合常态与悬停规则而级联。首版悬停态取今被设样元之界面悬停态；`section:hover a` 于指针入 `a` 时效，惟指针止于 `section` 余处，不易 `a` 之样。脚本 `querySelector` 与 `matches` 无界面悬停元之身份，故含 `:hover` 之查询不配。

类名依空白分界而全同乃合，如 `.btn` 不合 `btn-large`。
HTML 空元（如 `img`、`input`、`br`、`meta`）径成叶，自闭之 `/>` 亦即闭之。
页中诸脚依文次而收；`script` 有 `src` 则依终页之址解相对址，同步取其文，与内脚依序行之；Node 发行包默认通诸 HTTP(S) 源，外取败则略。`async`、`defer`、`type="module"` 与动态插入之脚，尚未循浏览器之法。
图形页之初页脚既行，则于 `document` 发一次不冒泡、不可取消之 `DOMContentLoaded` 事；处置既成，其所易 DOM 于首渲可见。处置有异，则此发事间之环更新或复原，然页面仍续渲。继于 `window` 循登序发不冒泡、不可取消之 `load` 事，后呼 `window.onload`；听者之 `this`、`event.target`、`event.currentTarget` 皆 `window`。

初页脚与 `DOMContentLoaded` 处置所读 `document.readyState` 为 `interactive`；`DOMContentLoaded` 既处，则值转 `complete`，继发 `window` 之 `load` 事而呼已赋之 `window.onload` 回调。`window.addEventListener('load', callback)` 与 `removeEventListener('load', callback)` 依函身登、除；重登同函则略之，听者选项未备。发事之初定今轮听者之序；事中虽除未呼之听者，此发不改。听者得含 `type`、`target`、`currentTarget`、`bubbles`、`cancelable`、`defaultPrevented` 诸属之事值；处置有异，不阻页面显，然其事或函之环更新或复原。

脚本可呼 `location.assign(url)`、`window.location.assign(url)`、`location.replace(url)` 或 `window.location.replace(url)` 而导之；相对址循今页而解。`assign` 增阅历项；`replace` 代今阅历项且清前向之记。同页 fragment 导则仍用今文；以 `replace` 行之，则易今址与今阅历项，不复取文。`self`、`globalThis`、`top`、`parent`、`frames` 之 `location.assign(url)` 与 `location.replace(url)` 亦然。赋值于 `location` 或诸共身之 `location` 属，亦循 `href` 导页并增阅历。

脚本可循 `history` 或 `window.history` 呼 `back()`、`forward()`、`go(delta?)`。阅历栈首为最近项；略 `delta` 或传零，则依今址重作 GET，仍居原阅历位。越界遍历不改页面。阅历遍历依目标址重作 GET，并还其项所存之控件值与勾态。`pushState`、`replaceState` 与 `state` 尚未备。

图形页脚本可读写 `location.pathname`、`location.search`、`location.hash` 与对应 `window.location` 属；路径不含询与片，询、片各带前缀 `?`、`#`，无则空串。导页、同页片段之变与阅历切换后，诸属值皆随 `location.href` 更。赋 `pathname` 易径而存询与片；无前导 `/` 则补之，空值则置 `/`，HTTP(S) 径中之反斜线易为路径斜线。赋 `search` 易询而存片；赋 `hash` 易片而存径与询。赋询、片可略 `?`、`#` 前缀；空值则去其部。路径、询与片之输入，依网址部件之法，将空格、非 ASCII 字与相应分隔符百分编码。皆循 `href` 导页之程，同页片易则仍用今文而更阅历。
脚本 DOM 之法有 `document.getElementById`、`getElementsByTagName`、`getElementsByClassName`、`querySelector`、`querySelectorAll`；节点集皆可下标取且有 `length`。诸查询与元素 `matches(selector)` 共用 CSS 既有选子之域：逗号分组、`*`、标签、`#id`、`.class`、`[name]`、`[name=value]`、`[name^=value]`、`[name$=value]`、`[name*=value]`、`[name~=word]`、`[name|=prefix]`、`:first-child`、`:last-child`、`:only-child`、`:nth-child(odd/even)`、整数及 An+B 文式（如 `:nth-child(2n+1)`、`:nth-child(-n+3)`）、`:empty`、`:checked`、`:disabled`、`:required`、`:optional`、同元复合之简单选子、空白间之后代选子与直接子代符（如 `main > p`，`>` 两旁须留空格）。结构伪类惟数父元之元素子项；`:required`、`:optional` 惟用于适用表器，依 `required` 属判之，不校当前值有效性；等值属性选子受成对引号，`~=` 按空白词合，`|=` 合精确值或连字符前缀。
元素受 `matches(selector)`；后代选子循元素在今文档树之祖径而验。
节点受 `contains(otherNode)`；己与之后代皆还 `true`，缺参与非节点参还 `false`，脱树子树亦依今子树而验。
元素之 `innerText` 可取或易其文；书之则更 DOM 而重绘。`innerHTML` 可举子树之 HTML 序文；书之则析为标记，机内身份之属不显。DOM 节点只读有 `nodeType`、`nodeName`，元素另有 `tagName`；元素名为 ASCII 大写，文、注、文档之名各为 `#text`、`#comment`、`#document`，节点类型之值各为 1、3、8、9。
DOM 节点可取 `childNodes`（诸直接子，含文与注）、`children`（惟元素子）、`firstChild`、`lastChild`、`firstElementChild`、`lastElementChild`、`childElementCount`。两子集每读一回，皆还带 `length` 且可下标之即时快照；无首末则还 `null`。
节点之 `parentNode` 还其直父，`parentElement` 还其直元素父；文根与脱树节点无父，则还 `null`。
节点可取 `previousSibling`、`nextSibling`、`previousElementSibling`、`nextElementSibling`；元素兄弟法惟寻相邻元素，越文与注。文、注内容同而异位者，今树查询或中首个结构同之节点。
脚可直读写元之 `name`、`type`、`placeholder`、`alt`、`src` 属；`disabled` 依布尔属法读写，并影响禁器之交互。复选、单选之 `checked` 读写今勾态，`defaultChecked` 读写重置之本态；既改 `checked` 再改 `defaultChecked` 不覆今勾，重置则还本态。
`document.title` 读 `<title>` 之文；若有 `<title>`，赋之则易其文并更文档树。
元之 `removeChild(node)` 可自今元去其指定直子而还此节点；缺参、非节点、非直子或父元脱树，皆发事故。带 `id` 之元可呼 `remove()` 自文档树去之；既删则重绘，且更新脚本中之 `document`。
`Element.replaceChild(newChild, oldChild)` 以新元易今元之直子，且还所去之旧元。二参皆必具且皆须为节点，旧元必为直子；新元含父元则发层级之事故，父元脱树亦然。新旧同元，则树不改而还此元。替换循 `insertBefore` 之移元法；有身之元素可自文树旧处移来。文、注元尚无机内身，同文之节点或相误。
元可呼 `hasAttribute(name)` 验属存否；带 `id` 之元可呼 `setAttribute(name, value)` 与 `removeAttribute(name)` 易属，变则回书文档树并重绘。
又可呼 `toggleAttribute(name, force?)`：属名必具；无 `force` 则反转存否，有之则依其真值强定存或删。法还终存否；惟文树中之元可易属而重绘，脱树之元仍旧，且还本存否。
设元素 `innerHTML`，则析新文为 HTML 子节点而重绘。
初 HTML 之 `<link rel="stylesheet">` 与 `<style>` 依标记之序入级联。脚本或事件易 DOM 后，新添或改写之样源循新树之序追加诸规；旧树及本批已有之外链 href 不复请，Node 发行包默认通诸 HTTP(S) 源。已载之样源既除或移，则旧规不撤不移；改样文则添新规，旧规尚留。
复、单选先易勾态，后沿祖径先发 `onclick`、继发 `onchange`；处置皆可读更新后之 `document`，事件目标恒为输入器，当前目标随处置元而易；禁器不发事。

文饰可依 CSS `text-decoration-line`，亦识简写 `text-decoration` 中之 `underline`、`line-through`。

HTML 数值字符引中，U+0080–U+009F 内规范所列二十七值，各映为其对应字符；余控制码仍其本值。
GUI 正文及浏览器所用 HTML 属性皆解十进、十六进数值字符引，可省其分号；非法码点代以 U+FFFD。命名之实体受 `&lt;`、`&gt;`、`&quot;`、`&apos;`、`&nbsp;`、`&amp;`、`&copy;`、`&reg;`、`&trade;`、`&ndash;`、`&mdash;`、`&hellip;`、`&lsquo;`、`&rsquo;`、`&ldquo;`、`&rdquo;`、`&bull;`、`&cent;`、`&pound;`、`&yen;`、`&euro;`、`&deg;`、`&plusmn;`、`&times;`、`&divide;`、`&middot;`、`&sect;`、`&para;`、`&frac14;`、`&frac12;`、`&frac34;`、`&laquo;`、`&raquo;`、`&iexcl;`、`&iquest;`、`&larr;`、`&uarr;`、`&rarr;`、`&darr;`、`&check;`；全名表尚未备。

`<img>` 以 `alt` 替代文显之；无 `alt` 则显 `[图片]`，空 `alt` 则不显文字。替代文承其祖链之热区；图片位图未绘。

HTTP(S) 页之导航及 GET/POST 表请，遇含 `Location` 之 301、302、303、307、308 应答，则循其转向，至多百次。转址受绝对址、协议相对、根径、目录相对及 query/fragment 相对之形。POST 遇 301、302、303，则改 GET 且除正文与请首；307、308 则仍其本请。址栏与阅历皆记终应之址。

址栏之下显终 HTTP 应之状态码；常导、刷新、GET/POST 表请，皆显终答之码。返、进与同页 fragment 导，仍循其阅历页之码。

跨页返、进之后，重取其文，依控件 `id` 或 `name` 复文本输入、多行文本与下拉之今值；复选、单选则依唯一 DOM 元身份复其勾态。复后之 DOM 回书脚本之 `document`。文树既易，失器则略；无身份之器不复，身份既易，勾态或不应本器。

今所受冒泡之事，处置可呼 `event.stopPropagation()` 止其续传于后祖；同元余监听仍行，此法不止默认行。`event.stopImmediatePropagation()` 则兼止今元后续之监听。

`Node.insertBefore(newNode, referenceNode)` 插新元于参考之前而还新元；参考须为父之直子，传 `null` 则附于末。文树既有之元素先自旧处移；脱树父元循脚境直绑而易。文、注元尚无机内身，重文或误为参考；移动时旧位或仍留而成重元。

脚可对 DOM 元呼 `dispatchEvent(eventLike)` 发事。其受带非空字符串 `type` 之常物；直名式 `new Event(type, options)`、`new CustomEvent(type, options)` 可构含 `bubbles`、`cancelable`、`detail` 属之事值，全局构造值亦可取。派发自目标循祖，同元先行内联处置，继行所登监听。处置者所存之事视乃各元阶段快照，事竟其 `currentTarget` 尚不清为 `null`。构造结果为普通属包，无原生事之原型与物身；构造器属呼、捕获与原生默认行尚未备。

## HTML 之基准网址

文树中首个有 `href` 属之 `<base>`，定相对网址之基址；空 `href` 则用最终页面之址。锚链、表单 `action`、外链样与外链脚本，皆循此基解析；`#fragment` 链亦循之。图形脚可只读 `document.baseURI`；其依今文 URL 与有效 `<base href>`，于初脚群行毕及每轮 GUI 事处既毕重算。同轮脚处中若改 `<base>`，则轮终后始得新值。图形模式下，`document.URL` 与 `document.documentURI` 皆还已提交页面之终址，并随页面状态既成而更新；纯 HTML 管线无页面网址，则还空串。外资源仍须为所受 HTTP(S) 网址，Node 发行包默认通诸 HTTP(S) 源。`<base target>` 尚未备。
