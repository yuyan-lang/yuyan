# 终端浏览器

于终端呈简易明文网页，今为试作。

## 组成

- **取网页**：依标准库明文超文本传输协议取文；密传、转向、分块皆未备。
- **析标记**：自造词法、建树，不假外器。
- **施样式**：自造析表、配选、层叠。
- **定布局**：自造盒式、块布、折行。
- **行脚本**：行 JavaScript 部分句法及文档之器，惟取页内脚本。
- **呈色**：终端着色而出。

## 用法

```sh
./yy豫构 构建 终端浏览器 --输出 yy终端浏览器
./yy终端浏览器 http://example.com/
```

今入口惟取明文网址，不读本地文；一呈页文，未有循链接及交互之术。
