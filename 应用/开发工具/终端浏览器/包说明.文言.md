# 终端浏览器

以既有图形界面呈简易 HTTP 网页，今为试作。

## 组成

- **终端之文**：文字节点依深缩进，各占一行，承其直父之色、背景与粗体。正 `margin-left`、`padding-left` 各增一级缩进；正上下外距、内距各增一空行。终端逐行显，右侧盒距不成可见宽。
- **取网页**：依宿主所授权之 HTTP(S) 网页请求接口取文；循 301、302、303、307、308 转向，`Location` 相对答址解析，至多百跳；POST 遇 301、302、303 易为 GET，307 与 308 守法与正文。分块响应尚未备。
- **析标记**：自造词法、建树，不假外器；`script`、`style`、`textarea`、`title` 中之原文留至相应闭元，标签名依 ASCII 而不辨大小写。
- **施样式**：自析样式之表、配选、层叠，析逗号分组、`*`、标签、`#id`、`.class`、属性存有选子（`[disabled]`）、属性等值选子（`[type="text"]`）、前缀（`[href^="https"]`）、后缀（`[href$=".html"]`）、子串（`[class*="card"]`）、空白词（`[class~="card"]`）、连字符前缀（`[lang|="zh"]`）、同元复合之简单选子、空白分隔之后代选子（如 `main p`、`.card a`、`button.primary#save`）与直接子代组合符（如 `main > p`，`>` 两旁须留空格）；属性值可无引号、单引号或双引号，且精确相比；属性名与值须连续书之，属性值暂不受空格。声明受大小写不敏之 `!important`，重要者先于普通者；各类之内仍依 CSS specificity 与源码序层叠。依今有选子算 CSS specificity，同等则循源码之序。属性大小写标志与伪类条目未列者尚未备。沿途合式受显式祖先列，施于 GUI 块元与行内递归、容器、表器、列表项之样式计算。`<select>` 选项之专用绘径尚未传祖先列。图形页依文序取已授权之外 CSS，合内嵌样式；终端呈色通八正色及三位、六位十六进制常式。GUI 元素映 `display:none`、`color`、`background-color`、`font-size`、`font-weight`、`border`、`border-radius`。
- **伪类**：CSS 与 DOM 之查询皆受 `:first-child`、`:last-child`、`:only-child`、`:nth-child(odd)`、`:nth-child(even)`、整数及 An+B 文式（如 `:nth-child(3)`、`:nth-child(2n+1)`、`:nth-child(-n+3)`、`:nth-child(-2n-1)`）、`:empty`、`:checked`、`:disabled`、`:required`、`:optional`；结构伪类循父元中元素子项之序而配，文与注不入位；诸既备伪类皆按类选择器之 specificity 入级联。`:required`、`:optional` 惟施于可受此属之 `input`、`select`、`textarea`；`input` 之 `hidden`、`button`、`submit`、`reset`、`image`、`range`、`color` 类型不配；余则依 `required` 属存否而判，未校当前值之有效性。余伪类与 `:nth-child` 之 `of` 子句尚未备。
- **悬停样式**：图形页受 CSS `:hover`，以悬停级联易为界面自绘之悬停态样，并依完整 specificity 与文序重算。首版悬停之态依实被设样之目标元；如 `section:hover a`，指针悬于 `a` 时则效，惟悬于 `section` 余处则不效。脚本 `querySelector`、`matches` 不知界面今之悬停元，故含 `:hover` 之查询不合。
- **定布局**：自造盒式与块布；GUI 受块元纵列、HTML 表格分组与逐行横列、`display:flex` 横纵列、折行、`gap` 子距、主轴之分与交叉轴之齐；flex 子项受整数 `flex-grow`、`flex-shrink`、像素 `flex-basis`、单值 `flex` 简写与 `align-self`，段中文与链片同列而显。表格单元循无前导零、无空白之正十进制 `colspan` 跨度比例分行宽；异列之行不共宽，`rowspan` 尚未备。
- **行脚本**：行 JavaScript 部分句法及文档之器；图形模式循文序执行内联脚本与已授权之外链脚本，脚后 DOM 用于图形呈现与链收集。`document` 可依 id、标签、类、`name` 属及基础选子而寻；`getElementsByName(name)` 直精确相比 `name` 属，还静态可索之节点列，缺参则以串 `"undefined"` 寻；`querySelector`、`querySelectorAll` 与元 `matches` 共用 CSS 选子之域：`*`、标签、`#id`、`.class`、`[name]`、`[name=value]`、`[name^=value]`、`[name$=value]`、`[name*=value]`、`[name~=word]`、`[name|=prefix]`、空白间之后代选子与直接子代符（如 `main > p`，`>` 两旁须留空格）；属性等值可受引号，今不受空格；`~=` 按空白词合，`|=` 合精确值或连字符前缀；`document.title` 可读写；`document.head`、`document.body`、`document.documentElement` 取今树中相应之元。元可取易文（`innerText`）、读写子树标记（`innerHTML`）、验选择子（`matches`）、取属（`getAttribute`）、验属存否（`hasAttribute`）；有 `id` 之元可设属（`setAttribute`）、删属（`removeAttribute`）及除元（`remove`），表器亦受 `checked` 属；`select.value` 可读写，设之则首同值项选而余项除选，无同值则清选；图形块容、段、列表项、行内元与按钮之 `onclick` 沿父元而上行；己与祖元之处置皆可呼 `event.preventDefault()` 止普通链导、按钮提交重置与文本框回车之提交；不止则默认续行，禁钮不发点击事。文本器之 `oninput`、选项之 `onchange`、Enter 与文本框所转之余键皆沿祖径行 `onkeydown`，`event.key` 用常见 DOM 键名；编辑器自理之键不转发，回车未止默认则提交所属 GET/POST 表。有效表将提交，先于表元发可冒泡之 `submit` 事；行内 `onsubmit` 与监听皆可呼 `event.preventDefault()` 止提交。复、单选先易勾态，再沿祖径先发 `onclick`、继发 `onchange`；禁器不发事。经 `<label>` 激活内控，控与签之间诸包装元亦循祖径受事。处置可用 `this`、`event.target`、`event.currentTarget`、`event.type`；复选可点击易态，单选依表内 `name` 互斥；`<select multiple>` 可多选，GET 以重名诸字段纳之；禁器不交互亦不提交，且保页面之脚境。元亦可用 `addEventListener(type, callback)` 登 `click`、`input`、`change`、`keydown`、`submit` 回调；发事时以 `event` 为参，`this` 即 `currentTarget`，监听循旧有祖径而上；行内处置先行，同元回调依登记次序而行，同元同事重登同回调则忽之；`removeEventListener(type, callback)` 依回调身份除其监听。监听选项（含 `capture`）及余类事件尚未备。
- **计算属**：普通属性包受 `obj[key]` 取赋，`key` 依机中之文化法寻己属性；缺属取则还未定义，赋则增或易之。稠列受既有下标易值与末尾追加；跨界成疏列、列之 `length`、串之索赋、物件原型链尚未备。计算属之受者径惟许变量与成员径，索式惟许变量或常值。直呼物件成员（如 `obj.method()`、`obj[key]()`），常规函之 `this` 即此物。闭包函亦受 `fn.call(thisArg, ...args)`、`fn.apply(thisArg, argsArray)`；`apply` 次参惟受今列、`null`、`undefined`，常 array-like 物尚未备。箭函不受动态 `thisArg`，仍取生时所捕之词法 `this`。
- **未定义与无**：全局 `undefined` 与 `null` 分立，二者皆为伪；`typeof undefined` 还 `"undefined"`，`typeof null` 还 `"object"`。缺参、无初值之 `var`/`let`、空 `return`、函无回与 `forEach` 皆还未定义。属包缺名与值列负标、越界读取皆还未定义；DOM 寻无则还 `null`。`===`、`!==` 别二者；`==`、`!=` 使无与未定义相等，且爻数循零一比之；余宽松转类尚未备。
- **Cookie**：图页依 scheme、主机、端口存会简饼 `name=value`；据 URL 中 scheme 与 authority 原文比源，主机大小及默端口尚未齐一。脚行前先取今源旧值，`document.cookie` 可读写之，同名则易。主文 GET/POST、转向及外 CSS、脚本 GET 皆依源发送 `Cookie`；各响应之 `Set-Cookie` 皆入会，以供后请与脚取。`Path`、`Domain`、`Secure`、`SameSite`、`Expires`、`Max-Age` 诸属尚未理。
- **DOM 节点类型**：节点只读有 `nodeType`、`nodeName`，元素另有 `tagName`；元素名为 ASCII 大写，文、注、文档之名各为 `#text`、`#comment`、`#document`，节点类型之值各为 1、3、8、9。
- **DOM 连通性**：节点可读只读属性 `isConnected`；文档节点恒还 `true`，有机内身份之元循今文树验之，脱树元还 `false`。文、注尚无机内身份，暂皆还 `false`。
- **DOM 子节点**：节点可取 `childNodes`（直子皆含文与注）、`children`（惟元素子）、`firstChild`、`lastChild`、`firstElementChild`、`lastElementChild` 与 `childElementCount`。子集每读一回则成可下标之值列，并有 `length`；无首末者还 `null`。
- **DOM 父节点**：节点可取 `parentNode` 与 `parentElement`；前者还直父，后者还直元素父。文根及脱树节点无父者还 `null`。
- **DOM 兄弟节点**：节点可取 `previousSibling`、`nextSibling`、`previousElementSibling`、`nextElementSibling`；元素兄弟法越文与注。同文之文、注节点若异位，或中首个结构同者。
- **造元附子**：`document.createElement(tagName)` 造无属、无子且具独一机内身份之元；`document.createTextNode(text)` 造文字节点；元之 `appendChild(node)` 依目标父元之身份附子于末而还子；`removeChild(node)` 去指定之直接子而还其节点。缺参、非节点、非直子或父元脱树，皆发事故；二法皆仅重造祖径。树中已有之元先自旧处移除；若将成祖孙之环，则不改文树。行脚本前，树中诸元皆赋隐身份；`innerHTML` 所生元亦各得新身份。当前环境链中直绑之节点，改属性或文字内容，则循身份易其含该节点之绑定子树；脱树父元附子，亦同步其绑定子树，故可先成脱树子树而后挂文档。节点若藏于普通物、列等容器，或别处环境链未相连者，其别名不随易；向脱树父元附既有父之子，不自其旧父移之；若将成祖孙之环，则不改文树。
- **箭函数与异常**：受 `x => 式`、`() => 式`、`(x, y) => 式` 与块体；式体隐回其值，块体行 `return`、`var`、`let`、`const`、式句、`if/else`、`while`、经典 `for`、`switch/case/default`、`try { ... } catch (error) { ... }`、`throw value`、`break`、`continue`、嵌套块及命名函声明。`throw` 抛其原值，`catch` 以之为绑；运行器之串异亦授 catch，然异前未返之环更恐不存。`finally`、`do/while`、错误对象与堆栈尚未备。`switch` 受括件与花括体；case 式惟需时乃求，依今备之值种严格相比；既合则依源码序贯行，`break` 出最近之 switch，`continue` 传最近之循环，`return` 与 `throw` 皆外传。物、列之引用相等尚未备。其 `this` 取生时环境之值，纵为事件回调亦守此词法值。参数今止标识列，默认、余参与解构参数尚待。
- **外链脚本**：图形模式循文序同步取 `<script src>`，与内脚依序行；相对址循终页面之址，来源须得 `--允许源` 授权，请败则略。`async`、`defer`、`type="module"` 与动态插入脚本，尚未循浏览器之法；命令列文字管线惟行内脚。
- **页面载入之事**：图形模式之初页脚既行，则于 `document` 发一次不冒泡、不可取消之 `DOMContentLoaded` 事；处置既成，其所易 DOM 入首帧。处置有异，则此发事间之环更新或复原，然页面仍显。继于 `window` 循登记之序，发不冒泡、不可取消之 `load` 事，终呼 `window.onload`；其 `this`、`event.target` 与 `event.currentTarget` 皆为 `window`。
- **文档载入之态**：图形模式中，页面脚与 `DOMContentLoaded` 处置所读 `document.readyState` 为 `interactive`；`DOMContentLoaded` 既处，则转 `complete`，继发 `window` 之 `load` 事而呼已赋之 `window.onload` 回调。`window.addEventListener('load', callback)` 与 `removeEventListener('load', callback)` 依函身登记、除去函数听者；重登同函则略之，听者选项未备。发事之初定今轮听者之序；事中虽除未呼之听者，此发不改。回调有异不阻页面显，然其事或函之环更新或复原。纯 HTML 行境无此页态，则还 `loading`。
- **列之回调**：列可同步行 `map(callback)`、`filter(callback)`、`forEach(callback)`、`some(callback)`、`every(callback)`、`find(callback)`、`findIndex(callback)`、`reduce(callback, initialValue?)`；常法回调依序受项、始于零之序数、原列为参；`reduce` 受累值、项、序数、原列。`map` 还映列，`filter` 依回调之真值留项，`forEach` 还 `undefined`；`some` 中真即止而还真，`every` 遇伪则止而还伪；`find` 还首个回调为真之项，`findIndex` 还其序数，皆中即止；皆不中则各还 `undefined`、`-1`，空列亦然。`reduce` 有次参则以之为初值，纵明传 `undefined` 亦然；无初值则首项为种，自次项始呼回调。空列有初值则还之，无初值则发事故。循源码之序而行，且留回调所更之闭包变量；`thisArg` 尚未备。
- **列之方法**：列受 `concat(...items)`、`includes(searchElement)`、`indexOf(searchElement)`、`slice(start, end)`、`flat(depth = 1)`、`join(separator)`、`push(...items)`、`unshift(...items)`、`pop()`、`shift()`、`splice(start, deleteCount?, ...items)`、`reverse()` 与 `sort(compareFn?)`；`concat` 依源码序求参，还含旧项之新列；参为列者惟浅展一层，余值作单项纳入，且不改受呼列。`flat` 别还新列，循深度递展其中之列；深度缺省或为 `undefined` 则取一，非正则不展。深度循今引擎之约法化整，数值、数字串、爻、无皆转整，余类作零；无穷深度尚未备。今列为稠列，无空槽。寻值依今有值种相比，缺参所寻为 `undefined`，`fromIndex` 不理；`slice` 还浅拷贝，止位不含，负位自末计；索引之数文、爻、无约法化整，余类作零，未定义之起止取默界；`join` 无参或分隔为 `undefined` 则用逗号，列项之无与未定义皆成空串，余值循机中之法转文。列改诸法依源码序求参，重建新列后写回简名或由名与成员访问组成之可写径；径以简名为根，受属性包与稠列。改写根绑之后，数组别名不共此易；函数呼等具副效之路径与常 array-like 物尚未备。`push`、`unshift` 纳参为新项并还新长；`pop`、`shift`、`reverse` 忽额参，`splice` 与 `sort` 依各自之法用参；`pop`、`shift` 分出末首项，空列还 `undefined`；`reverse` 反列而还之；`splice` 还所删之列，并将第三参起诸项插入，索引依 `slice` 之法化之，略 `deleteCount` 则删至末，明传 `undefined` 则删零，删数裁于余界；无参则还空列而列不易。排序以稳定插入序行；无比较函或明传 `undefined`，依 `String` 所成 Unicode 字序升列，未定义者置末且不授比较函；比较函受二已定义项，其果以今约法化整判序，闭包所更之值可续。
- **串之方法**：串受 `length`、`trim()`、`trimStart()`、`trimEnd()`、`charAt(index)`、`replace(searchValue, replacement)`、`replaceAll(searchValue, replacement)`、`slice(start, end)`、`split(separator)`、`includes(searchString)`、`startsWith(searchString)`、`endsWith(searchString)`、`indexOf(searchString)`、`toLowerCase()` 与 `toUpperCase()`；大小写诸法惟易 ASCII 字母，余字符守故；trim 诸法除首尾 ASCII TAB 至 CR 与空格，余 Unicode 空白尚未尽备；`charAt` 缺索或索为 `undefined` 则取零，负索与越界皆还空串，索依 Unicode 字符计。`replace` 依字面易首个合处，`replaceAll` 易尽其不交叠之字面合处；寻串为空时，前者于首插替文，后者于首尾及每一 Unicode 字界插之。正则与 `$&` 等替换记法尚未备。`slice` 止位不含、负位自末计，起止为 `undefined` 则取默认界，其索引之化整同列 `slice`；`split(undefined)` 同无参，不分隔；余法惟理首参，参数循机中之法转串；`split` 次参 `limit`、寻索次参 `fromIndex` 尚未备；空分隔则依 Unicode 字符拆列。长与索依 Unicode 字符计，不依 JavaScript UTF-16 单元计。
- **at 索引**：列与串皆受 `at(index)`；缺参或 `undefined` 则取首项，负索自末计，越界还 `undefined`。串之索循今引擎之 Unicode 字符。
- **表器之值**：脚可读写 `input.value` 与 `textarea.value`。空 `input` 之值为空串；checkbox/radio 无 `value` 则默值 `on`；textarea 无 `value` 则以正文为初值。脚赋其值则易控件今值，并存原初值以供表器复位。
- **反射之属**：元之 `name`、`type`、`placeholder`、`alt`、`src` 可直读写其 HTML 属；字符串属缺省则读空串，input 未设 `type` 则读 `text`。`disabled` 读为布尔值；赋真值则置此属，赋假值则去之。checkbox/radio 之 `checked` 表今勾态，`defaultChecked` 表重置所用之本态。
- **寻祖元**：元受 `closest(selector)`；自今元始，沿文档祖元上行，还首合者；无合则还 `null`。节点受 `contains(otherNode)`，验参为己或后代否；缺参、非节点皆还 `false`，脱树子树亦可验。选子之域同 `matches`；离文树者 `closest` 惟以不依祖之选子验己。
- **元内查询**：元受 `querySelector(selector)` 与 `querySelectorAll(selector)`，循后代文序还首项或可索引之列；不含受呼元自身。
- **类名之操**：元可直呼 `element.classList.add(...tokens)`、`remove(...tokens)`、`contains(token)`、`toggle(token, force?)`；增删可受诸词，切换还布尔值；空词或含空白者发事故。今仅有此四直法，`length`、`item` 未备。
- **动态内样**：元受 `element.style.cssText` 读易全内样，亦受 `element.style.color`、`backgroundColor`、`display` 等点属以读易单一声明；驼峰属名易为 CSS 连字名，易则代同名旧声明而存余项。`setProperty`、`getPropertyValue`、`removeProperty` 可操作 CSS 声明，`setProperty` 受 `important` 优先级。自定义属依大小写精确相比；CSS 值中未引号之 `var()` 可递代，其函数名不辨 ASCII 大小写，受组合值、嵌套回退、循环回退并存回退空白；引号中之 `var()` 不代。`length` 与方括号属取尚未备。
- **呈色**：依仓中既有界面自绘与显示控件，于所授权之显示面成可滚之 DOM 树；链有可点击之热区。地址栏可提交导航，返、进、刷新诸钮行会话中之阅历，新导航清前进之记；刷新依今址重作 GET，守阅历之位，且不重发 POST 正文。

## JavaScript 全局内建

全局 `JSON.parse(text)` 惟受串，以别造之严解析递归法，受无、爻、整数、双引串、列及串键之物；解诸转义，并拒非法转义、原控制符、非 JSON 空白、尾余文及非整数数式。物键重者取末值。`reviver` 尚未备。

全局 `JSON.stringify(value)` 紧缩而序列化无、爻、整数、串、列及常物之己属。其函数值 `typeof` 还 "function"，可藏而后呼之。串中双引、反斜线与控制符皆转义。`replacer`、`space`、循环引用及余非 JSON 值未备；遇非 JSON 值则发事故。

全局 `Object.keys(value)` 还常物己属键之串列，循物之属性次序；`Object.values(value)` 循同序还属性值；`Object.entries(value)` 循同序还 `[key, value]` 二项列。列之 `keys` 还自 `"0"` 始之数引键，`values` 还其项列，`entries` 依索引成二项列。`Object.fromEntries(entries)` 受稠列，且各项皆须为列；取每行首值转串为键、次值为属性值，缺位各视 `undefined`，余项忽之。重键则易值而守初见之序，依输入序成常物；iterator 与余输入类尚未备。`Object.hasOwn(object, key)` 按名验自有属；值虽为 `undefined`，属存仍还 `true`；缺 `key` 则按串 `"undefined"` 寻，余参忽之。对象参须为常物或列。





全局 `Array.isArray(value)` 惟其参为今引擎之列值则还真；缺参视为未定义而还伪。`Array.of(...items)` 循实参次序成新稠列以纳诸参；无参则还空列。`Array.from(value, mapFn)` 受今引擎之列或串，别还新列；列则浅抄，串则依 Unicode 字拆。映调惟受直呼 `Array.from(value, mapFn)`，循输入次序授项与自零始之标，取其果成新列。缺源参、映参非函且非 `undefined`、参逾二或源类不受皆发事故；`thisArg`、常 array-like 物及 iterator 尚未备。今列为稠列，无空槽。

列受 `sort(compareFn?)`，以稳定插入序成新列，写回简名或可写成员径。无比较函或明传 `undefined` 时，依 `String` 所成 Unicode 字序升列；列中 `undefined` 后置，且不授比较函。比较函循次受二已定义项，其果依今简化整数法判序，且闭包所更之值可续。成员径须以简名为根，惟受属性包与稠列；常 array-like 物尚未备，别名不共此次写回。

列受 `splice(start, deleteCount?, ...items)`，器可为简名或可写成员径；实参依源码序求之，还所删除项之新列，并将余项暨第三参起诸项写回其根名。`start` 依 `slice` 整数索引之法化之，裁入列中；略 `deleteCount` 则删至末，明传 `undefined` 则删零项，删数裁于余界。无参则还空列，原列之内容不易；改列亦不及别名。
列器之径亦可自 `window`、`self`、`globalThis` 为根读取脚本全局绑；改后写回今脚境中相应之绑。

全局 `Math` 受 `abs`、`sign`、`min`、`max`、`floor`、`ceil`、`trunc` 与 `round`。诸法惟受整数数值；`abs`、`sign` 取首参，`min`、`max` 至少受一参而还极值，其余取首参而原还之。缺所需参或参非数值皆发事故。今数值惟整数，小数、NaN、Infinity 与 `Math.random` 尚未备。




## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用/开发工具/终端浏览器 dist/终端浏览器 --包根 库
node dist/终端浏览器/启动.mjs --授权显示面 终端浏览器=1024x768 --允许源 http://example.com -- http://example.com/
```

入口惟取 HTTP 网址，不读本地文。地址栏与诸链能解 HTTP(S) 绝对、协议相对、站根及今目录相对之址，并归一 `.`、`..` 径段而存重复斜线；仅书域名则补 `http://`。`#fragment` 同页之链易今址与阅历，不复请页面；匹配元聚焦而滚入可视之区。正文及浏览器所用 HTML 属性解十进、十六进数值字符引（分号可省，非法码点代以 U+FFFD），亦解 `&lt;`、`&gt;`、`&quot;`、`&apos;`、`&nbsp;`、`&amp;` 等常用名实体；全命名实体表尚未备。图形表备 `text`、`email`、`search`、`url`、`tel`、`number` 输入器、`textarea`、`hidden`、下拉（含多选）、复选、单选及 GET/POST 提交；可书之器须有 `id` 或 `name`，惟纳带 `name` 之字段及已勾之复选、单选；单选依全页 `name` 分组。POST 以 UTF-8 `application/x-www-form-urlencoded` 正文发送；前进至 POST 阅历项时依 URL 重作 GET，不重发正文。择档、图片资源、繁嵌行样与 JavaScript 全事件对象尚未备。初 HTML 之外链 `<link rel="stylesheet">` 与内嵌 `<style>` 依标记之序入级联；脚本或事件易 DOM 后，新添或改写之样源循 DOM 之序追加诸规，旧树及本批已有之外链 href 不复请。样源既除或移，则旧规不撤不移；改写样文则添新规，旧规尚留。诸外样仍须得源授权。`event.preventDefault()` 今可止链导、按钮提交重置、文本框回车提交及有效表之 submit 默认导航。行于 Node 宿主，须先具 `@kmamal/sdl`，以 `--授权显示面` 授名“终端浏览器”，复以 `--允许源` 授所访之网页与外样之源。浏览器循 `Location` 随 HTTP 转向，至多百次；POST 遇 301、302、303 易为 GET，307、308 则守法与正文。

表提交之非空 `number`，今验简十进数式（正负号可无，至少一数位，点至多一）；`min`、`max` 循同式约范围，无效界值则略。指数记法与 `step` 尚不验。`date` 字段以文本框书入，验定式 `YYYY-MM-DD` 年月日、公历闰岁与合法 `min`、`max` 界；无效界值则略，原生选日器尚未备。

`<label>` 包裹复、单选器之文，及以 `for` 指同文树控件 `id` 之签，皆可激活对应之器。

HTML 数值字符引中，U+0080–U+009F 内规范所列二十七值，各映为其对应字符；余控制码仍其本值。

`<img>` 显 `alt` 替代文；无 `alt` 则显 `[图片]`，空 `alt` 则不显文字。替代文承祖链之热区，图片位图尚未绘。

图形页脚本有共身之浏览器全局标记：`window`、`self`、`globalThis`、`top`、`parent`、`frames` 皆归一值，顶层 `this` 亦指此值。其属循今脚境之全局绑而取；`window.foo = value` 则易此境之绑，后可循别名取之。`window.Object`、`window.Math`、`window.Array` 可取相应内建值。`location.href` 与 `window.location.href` 可读页面载后之规范网址；赋此二径则解相对址并发已授权之 HTTP(S) 导航，且将今页纳史、清前行；同页 fragment 惟易址与阅历。赋值于 `location`、`window.location` 或诸共身之 `location` 属，亦循 `href` 导页并增阅历。`location.pathname`、`location.search`、`location.hash` 及 `window.location` 相应属可读写；路径不含询与片，询、片各带 `?`、`#`，无则空串，且随导页与阅历易而更。赋 `pathname` 易径并存询与片；无前导 `/` 则补之，空值则置 `/`。赋 `search` 易询并存片；赋 `hash` 易片并存径与询。赋询、片可略 `?`、`#` 前缀，空值则去其部。路径、询与片之输入，依网址部件之法，将空格、非 ASCII 字与相应分隔符百分编码。赋值循 `href` 导页之程，同页片易仍用今文而更阅历。经 `self`、`globalThis`、`top`、`parent`、`frames` 之 `location.href` 赋值亦然。直呼 `location.assign(url)` 或上述全局别名之 `location.assign(url)`，循相对址解析而增阅历；`location.replace(url)` 或上述别名之 `location.replace(url)`，则代今阅历项并清前向史；同页 fragment 用 `replace`，惟易今址与今阅历项，不复取文。纯 HTML 管线无页面网址则值为空串。图形页循 GUI 之聚、失焦事，记只读 `document.activeElement`，涵文框、钮、复选、单选、下拉选项及可点击链；无匹配焦点节则还 `document.body`。有机内身之 DOM 节今可循身相比。GUI 聚失其变，则于目标元发不冒泡之 `focus`、`blur` 事。已连之常用控件、具 `href` 之链及具 `tabindex` 或 `onclick` 之元，可呼 `focus()`、`blur()` 易脚本所见活动元之快照；此法尚不驱 GUI 原生焦点，亦不发聚失焦事。列与常物之引用相等、`navigator`、窗法与全局属之遍举尚未备。

图形页脚本可循 `history` 或 `window.history` 呼 `back()`、`forward()` 与 `go(delta?)`；阅历栈首为最近项，`go()` 与 `go(0)` 依今址重作 GET，仍居原阅历位。越界遍历则页面不改。遍历依目标址重作 GET，并还该阅历项所存控件值与勾态。`pushState`、`replaceState` 与 `state` 尚未备。
HTML `autofocus` 使文序中首具此属且可聚之元初得 GUI 焦，并发 `focus` 事。
行内 `onfocus`、`onblur` 与 `addEventListener('focus'|'blur', callback)` 皆受；GUI 聚失之事惟于目标元行，不循祖径。
DOM 元可读写 `outerHTML`，读取则依 HTML 规则序化其身；予连文之元赋值，则析零个或数个顶层元，循机内身份于文树及今环祖绑易其目标。脱树之元与文档根赋之皆不改文树；旧元之脚本所持引用仍指已去之元。
`console.log`、`console.info`、`console.warn`、`console.error`、`console.debug` 皆可用，亦可循 `window.console` 而呼。每参各出一行于宿主标准输出；完整控制台排式与分组尚未备。

相对址起于 `?` 者，存今路径而易查询；起于 `#` 者，存今查询。

今所受冒泡之事，处置可呼 `event.stopPropagation()` 止其续传于后祖；同元余监听仍行，此法不止默认行。`event.stopImmediatePropagation()` 则兼止今元后续之监听。

动态 DOM 亦受 `parent.insertBefore(newNode, referenceNode)`：参考元须为父之直子，传 `null` 则附于末；文树中既有之元素先自旧处移。脱树父元可循今境直绑而易。文、注元尚无机内身，重文或误为参考；移动时旧位或仍留而成重元。

`addEventListener` 受内置与自定之事类。`dispatchEvent(eventLike)` 受带非空字符串 `type` 之常物；先行目标元之内联 `on<type>` 与监听，`bubbles` 为真则循祖径续冒泡。处置中 `event.target` 恒为派发目标，`currentTarget` 与 `this` 随今元而易；`cancelable` 为真乃可由 `preventDefault()` 止之，既止则 `dispatchEvent` 还 `false`。`stopPropagation()` 存今元余监听而止后祖；`stopImmediatePropagation()` 兼止今元后续监听。`Event`、`CustomEvent` 全局值可取；直名式 `new Event(type, options)`、`new CustomEvent(type, options)` 可用，备 `bubbles`、`cancelable` 及 `CustomEvent.detail`，直呼构造器则发事故。所构之值为常属包，无原生原型与物身。派发每阶段各构事视，存自定之属；处置者所存之阶段视，事竟仍存其 `currentTarget`，不清为 `null`。捕获与原生默认行尚未备。

- **HTML 之基准网址**：文树中首个有 `href` 属之 `<base>`，定相对网址之基址；空 `href` 则用最终页面之址。锚链、表单 `action`、外链样与外链脚本，皆循此基解析；`#fragment` 链亦循之。图形脚可只读 `document.baseURI`；其依今文 URL 与有效 `<base href>`，于初脚群行毕及每轮 GUI 事处既毕重算。同轮脚处中若改 `<base>`，则轮终后始得新值。图形模式下，`document.URL` 与 `document.documentURI` 皆还已提交页面之终址，并随页面状态既成而更新；纯 HTML 管线无页面网址，则还空串。外资源仍须为所受 HTTP(S) 网址，且得源授权。`<base target>` 尚未备。
