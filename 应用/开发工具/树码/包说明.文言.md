# 树码

此编译中间之产之转换、统计、核对之器也，用提案00001第一版树码。

构之：`节点 yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24`。

- `转换 <文件> [--输出 <文件>] [--种类 <阶段>] [--包上下文 <文件>]`：JSON、树码、阶段中间文互转。常以 JSON 与中间文成树码，以树码成 JSON；指输出之缀以择其式。阶段常取文件名末点段，树码则依卷首。串列以「串列」为种。
- `统计 <缓存目录或文件> [--包上下文 <文件>]`：依阶段计篇数、JSON 与树码之字节及其比值，兼计 JSON 读取还原、JSON 编码、树码编码、树码解码之时。时以单进程之纳秒积之，不含树码之卷上读写。
- `核对 <缓存目录或文件> [--包上下文 <文件>]`：逐阶段 JSON 成树码而复之，比其树，复编而验字节之同；输入树码亦须与规范复编之字节同。败则报其篇，退出之值非零。

包上下文用豫构所成之篇，依包身份易结构之径；编码省之则留本机径，读有包径之树码须授本机包上下文。统计、核对兼取 JSON、树码；目录中同名之产先树码，明指篇者依所指而读。树码输入之 JSON 大小，以同树编码之量计，JSON 读取之时记零。统计、核对惟读输入，转换书所指之输出。语义标记、语言服务之 JSON 非树组，略之；目录名末 `_v0` 者亦略之。
