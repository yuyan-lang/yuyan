# 树码

这是编译器中间产物的转换、统计与核对工具，使用提案00001的第一版树码。

构建：`节点 yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24`。

- `转换 <文件> [--输出 <文件>] [--种类 <阶段>] [--包上下文 <文件>]`：JSON、树码与阶段中间文本互转。默认将 JSON 或中间文本转为树码，将树码转为 JSON；指定输出扩展名选择目标格式。阶段默认取文件名最后一个点分段；树码以文件头为准。串列用「串列」种类。
- `统计 <缓存目录或文件> [--包上下文 <文件>]`：按阶段统计文件数、JSON 和编码后的树码字节数及 JSON 与树码比值，另计 JSON 读取还原、JSON 编码、树码编码、树码解码耗时。各耗时为单进程纳秒累计，不含树码磁盘读写。
- `核对 <缓存目录或文件> [--包上下文 <文件>]`：逐个将阶段 JSON 编成树码并还原，比较树结构，再检查二次编码的字节一致性；树码输入还须与规范重新编码的字节相同。失败报出文件并以非零状态退出。

包上下文采用豫构生成的上下文文件，按其包身份替换结构化路径；编码时省略则保留本机路径，读取含包路径的树码须给本机包上下文。统计与核对覆盖 JSON 和树码；目录中同名产物优先树码，显式文件按所指输入处理。树码输入的 JSON 大小按同树的 JSON 编码计算，JSON 读取耗时记零。统计与核对只读取输入，转换写入所选输出。语义标记与语言服务 JSON 不属树组，跳过；忽略名称以 `_v0` 结尾的目录。
