# 树码

这是编译器中间产物的转换、统计与核对工具，使用提案00001的第一版树码。

构建：`节点 yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24`。

- `转换 <文件> [--输出 <文件>] [--种类 <阶段>] [--包上下文 <文件>]`：树码与阶段中间文本互转。树码默认转成同名 `。豫` 文本，文本默认转成树码；指定输出扩展名选择目标格式。阶段默认取文件名最后一个点分段；树码以文件头为准。串列用「串列」种类。
- `统计 <缓存目录或文件> [--包上下文 <文件>]`：按阶段统计文件数、树码字节、读取、编码、解码耗时和本机相关文件数。耗时为单进程纳秒累计；读取含文件读取与还原。
- `核对 <缓存目录或文件> [--包上下文 <文件>]`：解码树码，再编码并与原字节比较；另比较往返树结构与二次编码字节。失败报出文件并以非零状态退出。
- `显示 <文件> [--包上下文 <文件>]`：将豫言中间文本写到标准输出，供编辑器预览，不生成文本文件。
- `读取编辑器资料 <文件>`：由豫言解码语言服务或语义标记树码，向标准输出返回编辑器交换资料；磁盘上只保存树码。

包上下文采用豫构生成的上下文文件，按其包身份替换结构化路径；编码时省略则保留本机路径，读取含包路径的树码须给本机包上下文。统计与核对只处理阶段树码并只读取输入，转换写入所选输出；忽略名称以 `_v0` 结尾的目录。树码第二版中每个定义只含名字与表达式，第一版缓存须由编译器重建。
