# 设计验收

同一入口在原生、诺节和浏览器执行，打印三十秒动画五帧的像素散列，以及四秒有声样例全部波形字节的散列与长度。各端输出逐字比较可以复核提案 00018 前两期的一致性验收。

原生构建：`豫构 构建 设计验收 --输出 yy设计验收.exe -j 24`。诺节构建：`豫构 构建 设计验收 --输出 yy设计验收.wasm -j 24`。浏览器构建：`豫构 发行 浏览器 应用/开发工具/设计验收 yy设计浏览器 --包根 库 --包根 豫言操作系统/适配`，配合同仓宿主的 `设计。测试页.html` 收集输出。

预置以豫言字符串保存设计树码，含字形与采样素材。入口先解码同一预置，再求值、渲染、混音。更新源样例后，在仓库根构建并运行 `准备。脚本。豫`，重新生成 `动画预置。豫` 和 `声音预置。豫`；两份源数据随验收程序登记。
