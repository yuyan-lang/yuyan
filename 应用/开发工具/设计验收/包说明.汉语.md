# 设计验收

同一入口在原生、诺节和浏览器执行，打印三十秒动画按每秒三十帧求值的完整显示表、十个动画段各一帧的完整像素，以及四秒有声样例全部波形字节。输出采用可以还原的十六进制表示；小数沿用设计树码的八字节位型。各端输出逐字比较可以复核提案 00018 前两期的一致性验收。

原生构建：`豫构 构建 设计验收 --输出 yy设计验收.exe -j 24`。诺节构建：`豫构 构建 设计验收 --输出 yy设计验收.wasm -j 24`。浏览器构建：`豫构 发行 浏览器 应用/开发工具/设计验收 yy设计浏览器 --包根 库 --包根 豫言操作系统/适配`，配合同仓宿主的 `设计。测试页.html` 收集输出。

预置以豫言字符串保存设计树码，含字形与采样素材。入口先解码同一预置，再求值、渲染、混音。更新源样例后，在仓库根构建并运行 `准备。脚本。豫`，重新生成 `动画预置。豫` 和 `声音预置。豫`；两份源数据随验收程序登记。

原生实际输出保存为 `yy原生基线.txt`，复制到浏览器产物目录；`设计。测试页.html` 加载该文件，逐字符比较浏览器实际输出，显示总字符数、差异数和首个差异位置。诺节实际输出与原生基线用 `cmp` 比较。完整显示表包含几何坐标、颜料、图像字节与仿射、不透明度、图层子项、遮罩、全部效果参数及混合模式。源节点中仅供编辑的声明属性另行由树码往返测试覆盖。
