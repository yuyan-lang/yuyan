# 豫言编辑器树码接入

这是 VS Code 对编译器树码的接入说明。默认保存检查调用 Node 宿主运行 `yy4_bs.wasm`；中间产物、语言服务和语义标记缓存都使用 `.树码`。

二进制编解码、编辑器资料转换和阶段文本显示由豫言编写的 `yy树码.wasm` 执行。插件调用 `读取编辑器资料` 获取悬停和定义跳转资料，调用 `显示` 打开只读的中间文本预览；包路径由对应包上下文还原。编辑器交换资料走进程标准输出，磁盘缓存只保存树码。

在项目根目录构建工具：`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24`。

`npm run pretest` 检查插件编译、语法和资料接入；设 `YY_EDITOR_WASM_ROOT` 为已构建工具且运行「编辑器树码」测试的工作树，可进一步读取豫言生成的真实语言服务、语义标记二进制样本，验证 Wasm 与插件互操作。
