# 豫言编辑器树码之接

此 VS Code 接编译器树码之说明也。保存之常验，以 Node 宿主行 `yy4_bs.wasm`；中间之产、语言服务及语义标记缓存皆用树码。

二进制编解、编辑器资料转换及阶段豫文之显，皆由豫言所作 `yy树码.wasm` 行之。插件以 `读取编辑器资料` 取悬停、定义跳转之资，以 `显示` 开只读中间豫文；包径依其包上下文复之。编辑器交换之资循进程标准输出，卷上缓存惟存树码。

于项目根构器：`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24`。

`npm run pretest` 验插件之编、语法及资料之接；设 `YY_EDITOR_WASM_ROOT` 为已构器且行「编辑器树码」测试之工作树，则读豫言所成语言服务、语义标记之实二进制样本，验 Wasm 与插件互通。
