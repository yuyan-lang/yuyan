# 豫言工作台网页示例

豫言工作台之浏览器示例：以内存中数示例之文为文之服，经[工作台网页](../../../../库/工作台/网页/包说明.文言.md)之「运行网页工作台」于页中览、开、编而存之。此为「豫言工作台」之子包。

## 所含

- `入口。豫`：示例之文（说明、一带包述与双语说明之示例包、笔记）置于一引用；「内存列目录」「内存读文本」合为「浏览服务」，「内存写文本」「内存改名」「内存删除」改此引用。入口于 ID 为 `工作台容器` 之元素运行工作台，开 `示例/入口。豫`。
- `页面.html`：满视口之容器与浏览器宿主之启脚。

## 构建与运行

于仓根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 应用/开发工具/豫言工作台/网页示例 dist/豫言工作台网页示例 --包根 库 --编译器 ./yy4_bs.exe
cp 应用/开发工具/豫言工作台/网页示例/页面.html dist/豫言工作台网页示例/index.html
```

乃以任一静态文件之服伺 `dist/豫言工作台网页示例`，如本仓之简易网页服务器：于此目运行 `node <仓根>/豫言操作系统/宿主/节点/宿主.cjs <径>/yy简易网页服务器.wasm --本机 18731`，以支 WasmGC 与 JSPI 之浏览器开 `http://127.0.0.1:18731/`。

## 验收

二〇二六年十月十日于内置浏览器窗格验之：文树显目录与文、展目录、开文为签；源码框依语义着色，着色层与 `textarea` 之位、字体、行高逐项皆同；输入后签显改标，命令加回车存之则标去，闭签复开读得所存之正文；Markdown 阅读之视、豫言文档之视、包树（经包配置析示例包述）、构建钮之示皆如常。长文（百余行）横纵滚动及末行回车换行后两层犹齐，光标随输入滚入视野。闭前一签后，后一签仍为同一页节（依键重排）。首屏之接另以「首屏容器超文本」所生之首屏页验之：始后容器子节无变，交互如常。
