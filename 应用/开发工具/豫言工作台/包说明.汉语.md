# 豫言工作台

文档声明的签名使用与源码编辑器相同的语义着色，保留原文、空白与等宽排版。解析暂未成功的签名显示完整原文。

状态栏显示主标签记录的编辑或定位行列，行列从一开始，位置按字符计算。控件报告单点选区时同步对应栏的光标，副栏保留主栏位置，范围选区保留引用范围。完整行号栏、语法着色和原生方向键交互验收继续实施。

构建诊断按钮按文件路径保存界面身份，点击后切到对应源码。已有标签复用未保存缓冲，读取新文件失败时保留当前标签及构建输出，并显示读取错误。

包列表以浅色底标出当前文件所属的最近包，按包描述路径区分同名包。切换主标签时更新选中底色，包行保持 20 逻辑像素。

打开或切换主标签，以及进入包视图时，按包声明层级展开所属包的祖先。当前包和无关包保留折叠选择，同一标签的正文编辑保留手动折叠状态。自动滚动定位留待后续实施。

副栏首次打开从文件页初始化独立光标位置和定位序，收起重开沿用已有记录。声明定位和编辑事件更新副栏记录；正文、保存状态与撤销历史继续共享。正文缩短或历史恢复时，两栏光标保持在正文字符范围内，另一栏需要修正时增加定位序。

副栏光标记录随文件改名迁移路径，成功关闭后清理；未保存而拒绝关闭时保留记录。

模型按文件路径保存副栏光标位置与定位序，状态更新保留记录，副栏渲染投影读取该记录。

改名与移动成功后重读根规则及已缓存子目录规则；资源刷新失败显示错误并保持已完成的文件身份迁移。

刷新重读已缓存目录的 `.gitignore`，更新目录规则并保持当前标签与缓冲；目录或规则读取失败时保留旧缓存并显示路径。

删除子目录 `.gitignore` 成功后清空对应目录规则，资源行随状态更新恢复样式；失败保留已有规则。

目录展开时读取该目录的 `.gitignore`，按目录路径替换缓存；读取失败保留旧规则并显示路径，目录确认文件已移除时清空对应规则。文件编辑和标签切换保持缓存，文件树与搜索结果复用缓存显示忽略样式。

忽略匹配层按目录作用域叠加规则，深层否定规则沿用父目录约束。忽略行使用淡色并保持点击打开；刷新与删除时的子目录规则同步继续实施。

改名改变文件视图类型时，主副栏进入原始视图；同类型改名保留两栏各自的阅读选择，正文与编辑历史保持。

模型空文本回复显示明确失败，已有会话消息保持。

删除根 `.gitignore` 成功后清空忽略规则；删除待改名文件成功后收起对应输入区。删除失败保留规则与输入。

改名和移动完成后的资源刷新同步根 `.gitignore`：文件存在时重读规则，文件移走后清空规则，读取失败保留上次规则并显示错误。

改名开始、目标修正和取消操作会清除上次错误提示，修正期间保留发起文件路径。

底栏“改名”按需打开 30 像素输入行，支持确认与取消。输入绑定发起文件，切换标签后保持来源；成功后关闭输入行。执行流程先检查文件保存状态与目标标签，磁盘成功后同步标签、副栏、导航及已打开会话引用；磁盘失败时保留原缓冲与输入。

改名后引用处理更新已打开会话中的匹配路径，更新后的缓冲进入撤销历史并显示修改状态，保存基线保留。无匹配会话保留原正文，未打开会话的联动留待后续实施。

改名后同步资源行路径与名称，搜索按新路径移除失配项、加入新匹配项。跨目录移动后重读已展开目录，按真实父目录和层级展示文件，保留展开状态与编辑缓冲。刷新失败显示错误并保留已完成的文件身份迁移。

改名后的标签状态迁移保留正文、保存基线、选区、光标与撤销历史，同步主副栏路径及副栏视图选择。目标标签冲突时保留原状态。

改名磁盘逻辑在授权目录内检查目标存在性，完整写入并关闭目标后删除源。已有目标得到保留，写入失败保留源文件，源删除失败显示两份文件的状态。

会话处理提供按完整路径更新上下文引用的逻辑，保留文本快照、范围与扩展字段，供文件改名流程接入。

刷新根目录时，已有 `.gitignore` 读取失败会保留上次规则并显示错误；目录确认该文件已移除后清空规则。

这是以文件标签组织源码、文档与 AI 会话的紧凑工作台。设计依据为云仓 `提案/豫言工作台设计.汉语.md`。

首阶段提供授权目录的紧凑文件树、按需展开、文件标签与关闭、全文预览、独立视图状态和未保存缓冲区模型。文件树行高为 20 逻辑像素，上下内距为零，顶部单行导航，使用云仓纸墨朱配色。

应用通过公共文件服务读取名为“工作台”的授权目录，通过名为“主窗口”的显示面运行。文件授权失败时显示具体错误。

共用 Markdown 表格预览用于文件阅读、系统文件预览和助手回复，显示表头、单元内容与分隔线。

## 会话文件

助手消息使用共用 Markdown 预览展示标题、列表、强调与围栏代码，用户和系统消息按原文展示。会话文件继续保存消息原始正文。

模型请求的上下文包含文件路径、文本快照和引用字符区间。区间从零开始，包含起位、不包含止位；同一文件的各段引用分别传入。旧引用沿用保存的路径与快照。

会话文件的原生落盘验收入口为 `测试/会话落盘。测试。豫`。在专用临时目录授权写入后，依次创建源码、创建会话、引用源码、发送消息、磁盘读取、关闭标签和重新打开，核对正文与保存状态。此入口以无窗口方式运行。

`.会话` 文件默认显示对话，提供原始内容切换。中文 JSON 字段保存格式版本、标题、工作目录、消息、上下文引用、工具记录及修改摘要。消息追加保留其他字段；格式检查和消息展示复用同一缓冲区。文件与选区上下文已接入，真实模型执行继续验收。

对话底部提供多行输入；“保存消息”或控制／命令加回车将草稿追加为用户消息并写入会话文件。每个标签保留自己的草稿；成功后清空，失败时保留草稿与原文并显示错误。真实模型联调与工具执行继续实施。

会话顶部可引用已打开的源码文件。引用保存授权目录中的相对路径、字符区间和当前缓冲区快照，并在对话中展示。引用改变会话正文，使用保存快捷键落盘；随后保存消息也一并写入引用。原生选区引用已接入，实际拖选与浏览器联调继续验收。

`模型协议。豫` 将会话消息和引用快照转换为标准聊天请求正文，模型名由调用方指定。授权网络传输、环境配置与回复保存已接入，真实服务继续联调。

模型协议解析完整聊天回复，取得首项文字内容；HTTP 错误、服务错误、无效 JSON 和缺少文字均返回明确错误。实际模型服务继续联调。

`模型连接。豫` 通过现有授权网络接口发送完整聊天请求，网址、模型名与凭证由配置传入。凭证只进入请求标头。助手回复保存使用同一会话缓冲区；写入失败保留回复与修改标记，可用保存快捷键重试。界面配置和真实服务联调继续实施。

启动配置使用环境变量 `豫言工作台模型网址`、`豫言工作台模型名称`、`豫言工作台模型凭证`。网址填写完整聊天端点。配置地址及模型后，“请求回复”先保存草稿，调用模型，再保存助手消息；用户消息写入失败会停止请求。凭证保留在应用运行配置中。运行环境授予对应网络目标后可以发送请求。原生实际联调与异步运行状态继续验收。

源码视图打开时自动聚焦编辑框，定位请求保留指定光标位置。原生窗口已实测中文多行粘贴、命令加 S 保存及磁盘内容核对；文档定位后光标落在声明开头。

文件树顶栏的加号创建新会话，按序选择未占用的“新会话N.会话”根目录文件名，打开对话并登记文件树。新文件带修改标记，保存快捷键或保存消息写入对应文件。已保存会话关闭后保持资源行，后续新建继续避开该名称。

会话输入框铺满内容区，保存消息与请求回复同排靠右。原生实窗已验证新建会话、中文输入、消息落盘、关闭重开及应用重启后读取原消息。

## 包浏览

文件删除成功时同步移除对应搜索结果，保留搜索条件和侧栏收展状态。删除失败保留结果列表。

文件搜索失败时保留已有结果，显示读取失败的目录路径。重试成功清除错误提示，保持当前编辑标签。

文件搜索基础通过授权目录服务递归匹配相对路径，结果使用资源行的完整路径身份，包含本地会话文件。搜索跳过旧版目录与 Git 元数据目录，目录读取失败报告路径。活动栏提供搜索入口，侧栏输入文件名或相对路径后执行搜索，显示结果数量和可点击资源行。返回文件保留原目录树与编辑缓冲。异步搜索继续实施。

顶部“包”切换到授权工作目录的包树，读取包描述中的所有者、父包和子包声明，按声明顺序展示层级。行高保持 20 逻辑像素。点击包优先打开中文包说明，说明使用文件标签与编辑缓冲。切回“文件”保留未保存内容。包树折叠、源码与测试入口及所属包说明导航已接入，选中包定位继续实施。

包行左侧的加减按钮展开或收起子包，点击名称打开说明。折叠状态随文件与包视图切换保留，已打开标签和未保存文本继续保留。

包行的“目录”打开授权目录内的实际条目，源码与测试可沿文件树继续浏览；刷新返回工作目录根。底部操作栏“包说明”按当前文件的最近包目录打开包说明。路径匹配以目录分隔符为边界，嵌套包优先于父包。目录切换保留打开标签与未保存内容。

展开的包显示“源码”和“测试”子行，行高保持 20 逻辑像素。“源码”浏览包目录，“测试”浏览其 `测试/` 子目录。收起包时一并隐藏入口。读取失败显示服务错误，并保留当前文件缓冲。

## 包检查结果

诊断导航优先使用已打开文件的缓冲并切换到原始代码，保留未保存文本。尚未打开的文件由授权读取服务加载。

底部操作栏“检查”按当前文件所属包调用具名授权程序“豫构”，参数为 `检查 包名 -j 24`。授权程序在工作仓库中执行，读取已保存文件。结果区保存退出码、标准输出与标准错误，可收起；结果展示保留编辑缓冲。启动环境以现有子程序授权配置“豫构”。原生检查授权调用已验收；构建与类型检查入口、诊断文件导航已接入，异步状态、运行入口及精确行列定位继续实施。

检查前验证全部打开标签的保存状态。有修改时提示先保存，保存后再发起检查；提示期间保留原构建结果与编辑缓冲。

构建结果识别现有解析错误和类型检查错误中的文件提示，提供“打开错误文件”入口。入口切到原始代码，保留已有文件缓冲；绝对路径按应用当前工作目录转换为授权相对路径，启动时工作目录与授权工作台根保持一致。精确行列定位继续接入源码范围数据。

无窗口验收使用 `yy豫言工作台 --授权子程序 豫构=原生豫构绝对路径 -- 后台检查 包名`，输出检查退出码和两路文本。它复用界面的执行函数。macOS 原生后台联调已验证工作台包检查成功、缺少程序授权返回错误、不存在的包返回非零退出码，运行期间保持前台流程。

底部操作栏“构建”调用授权豫构的 `构建 包名 -j 24`，按豫构当前配置生成产物。构建沿用检查前的保存提示与结果面板，保留退出码及两路输出。原生后台实际构建授权联调通过，运行入口与异步状态继续实施。

“类型检查”调用授权豫构的 `类型检查 包名 -j 24`，结果进入同一输出面板，错误文件入口沿用诊断导航。执行前确认打开标签已保存。编译器使用授权豫构的既有配置。

对话输入区的“清空上下文”清除当前会话的引用列表，保留消息与其他记录，修改标记随会话缓冲更新。保存快捷键或下次保存消息将变更写入会话文件。

重复添加同一路径、同一起止范围的引用时更新文本快照；不同范围的引用分别保留。引用更新继续沿用会话缓冲与保存状态。

源码标签保存码点选区范围。原生选区事件更新当前标签；切换到会话后，文件引用按钮在有选区时显示“引用选区”，记录起止位置及选区文本快照，无选区时引用全文。中文码点截取与跨标签范围保持已通过后台回归；实际窗口拖选及浏览器选区接入继续验收。

正文改变与撤销重做清除旧选区范围，后续控件事件重新报告当前范围，引用操作读取更新后的标签状态。

会话中的文件引用行提供“包说明”按钮，按该文件的所属包读取中文说明，将说明路径和全文快照加入上下文。读取与解析沿用授权文件服务和正式包解析器。操作保留当前会话标签，保存沿用会话缓冲流程。

会话消息使用“用户”“助手”“系统”角色，正文为字符串。格式检查逐项验证消息，异常记录显示格式错误，可在原始内容视图修正后继续操作。

对话视图展示已有工具执行记录和修改摘要。工具记录显示“工具”“结果”，修改摘要显示“路径”“摘要”；空记录列表保持空白。工具记录可收起和展开，收起后显示记录数量，每个会话标签分别保留显示状态。收展保持会话正文与保存状态。工具执行继续实施，差异查看和应用修改已接入。

修改摘要包含字符串字段“路径”“原文”“新文”时提供“查看差异”。差异打开为只读标签，左右展示两份快照，保存操作显示只读提示。摘要字段继续显示简述。应用修改已接入。逐行差异复用差异比较库，删除与插入分别着色，两侧以空行对齐并显示各自行号。

差异两侧标题对非空且末行没有换行符的快照显示“末行无换行”，用于辨识仅末行换行符改变的修改。

差异标签的“应用修改”先比较目标文件当前内容与原文快照。已打开文件使用编辑缓冲，其余文件通过授权服务读取。匹配后打开目标标签并写入新文，进入未保存状态，支持撤销；保存快捷键负责落盘。内容已经改变时显示冲突提示并保留当前缓冲。

后台真实文件验收入口为 `测试/差异落盘。测试。豫`。构建生成原生验收程序后，以 `--授权目录写 工作台=独立临时目录` 运行，验证未打开文件读取、应用差异、保存和磁盘重读。全树测试对该入口执行类型检查，实际写入验收在独立目录运行。

重新查看同一路径的修改摘要时，差异标签刷新为该记录的快照，并保持单个只读标签。源码与会话标签继续保留各自缓冲。

文件作用域消息按指定标签处理编辑、保存与模型操作，处理后恢复主标签路径，并保留目标文件的缓冲更新及错误信息。这是分栏编辑的消息基础，分栏显示继续接入。

副栏文件路径独立保存，主标签切换保持副栏路径，收起副栏保留文件标签和未保存缓冲。双栏共享文件缓冲，并按文件路径处理编辑消息。副栏标签列展示已打开文件，点击标签切换副栏文件。标签显示未保存标记，悬停展示完整路径；副栏“保存”写入该栏文件。

主副栏会话均提供已打开文件、选区及所属包说明的引用入口。引用按目标会话路径派发，保留另一栏当前文件。

Markdown 引用块采用左侧细线与阅读间距，有序列表保留原文编号。

根目录加载及刷新读取 `.gitignore`，规则保存在工作台状态；资源树以次要字色标记匹配项，文件继续显示并可打开。忽略规则复用正则包路径通配，处理会话模式、目录模式、注释及按顺序生效的否定规则。目录模式按实际条目类型区分同名普通文件。规则保留前导空格，仅去除未转义的末尾空格，转义标点按字面匹配。嵌套忽略文件继续实施。

否定忽略规则逐级检查父目录。先恢复被忽略的父目录，再恢复其中的文件，资源树显示相应的忽略状态。

删除待确认时提供“取消删除”，保留文件标签和缓冲，清除确认状态；再次删除重新显示目标路径。

删除状态处理复用授权文件接口：已确认的文件删除成功后移除文件标签和资源项，并清理对应副栏；失败保留缓冲与标签，未保存文件显示保存提示。底部操作栏“删除文件”首次显示完整目标路径，再次点击“确认删除”执行；切换文件清除确认状态。原生后台临时目录验收通过首次保留、二次删除与标签副栏清理。

Markdown 行内阅读沿用标记文的可转义标点集合，反斜杠转义后的标点显示为字面文字；末尾单独反斜杠保留。

构建诊断的文件导航按路径去重，保留首次出现的顺序；完整构建输出继续保留全部错误文本。

标题、列表和引用块共用正文的行内代码展示，保持各块字号、编号和边线。

Markdown 正文的行内代码复用标记文闭合规则，以等宽字体和浅色背景显示；连续正文合并为文字片段。双星号粗体复用强调闭合规则，未闭合标记保留原文。嵌套行内格式、斜体、链接与表格继续实施。

无窗口入口提供 `后台构建 包名` 和 `后台类型检查 包名`，分别复用界面的构建、类型检查授权调用；输出包含子程序退出码及两路文本。启动时以具名子程序“豫构”授权已有工具链，并以 `--允许环境 PATH` 授权搜索路径传递。工作台显式传入当前 `PATH`，供豫构启动编译器及 Node 工具链。

`后台模型 提示文本` 以无窗口方式调用同一模型连接。配置沿用环境变量“豫言工作台模型网址”“豫言工作台模型名称”“豫言工作台模型凭证”，网络访问沿用宿主授权；成功输出模型正文，失败输出错误提示。此入口可用于后台服务联调，真实服务成功调用继续验收。

主副栏的 Markdown 视图入口统一称“阅读／原文”，会话称“对话／原始内容”，源码称“文档／原始代码”。

Markdown 文件的文档视图复用标记文库识别标题、列表、分隔线和围栏代码，正文采用阅读字号，围栏代码保持原文并使用等宽字体。阅读来自当前编辑缓冲，原始代码视图继续提供全文编辑。行内格式、表格及链接交互留待后续版本。

关闭副栏正在显示的已保存文件时收起副栏。关闭其他文件保留副栏；未保存文件继续保留标签、缓冲和副栏位置，并显示保存提示。

标签栏“右侧打开”把当前文件放入副栏，主栏可继续切到会话或其他文件。副栏提供原始文本编辑和“收起”，编辑、选区、快捷键及保存按文件路径派发。主副栏共用文件缓冲。副栏支持文档、对话与原始内容切换；声明定位、会话草稿、保存消息和请求回复按副栏文件处理。独立标签导航及真实窗口交互继续实施。
检查、类型检查与构建以后台任务运行，编辑与标签操作继续可用。运行期间底栏显示“停止”，完成后收取退出码、标准输出与错误输出，并保留文件缓冲。
# 后台模型会话入口

`后台模型会话` 从标准输入读取一行完整会话 JSON，沿用本地模型环境配置与宿主网络授权，输出单行中文 JSON，字段为“状态”和“正文”。状态为“完成”或“失败”，正文通过 JSON 转义保留换行与引号。此入口供具名后台子程序调用；界面任务接入继续实施。
后台回复按发起会话路径与请求正文核对后保存，切换标签保留当前文件。请求后的会话修改及关闭会话的回复保留在结果面板，供后续审阅。后台任务启动与计时收取继续接入。
界面“请求回复”启动具名子程序“模型请求”，参数为 `后台模型会话`，通过标准输入传递会话。运行期间可编辑与切换标签，底栏“停止”终止当前任务，计时收取结果并按发起会话保存。模型请求与构建共用单个任务槽。

启动工作台时，将“模型请求”授权为已构建工作台程序的绝对路径，并固定授予该子程序所需的网络访问参数。允许传递环境变量“豫言工作台模型网址”“豫言工作台模型名称”“豫言工作台模型凭证”；凭证由本地环境提供。真实模型服务的端到端联调继续验收。
模型请求前校验当前会话的格式与版本，格式错误时显示修正提示。模型任务收取后，结果面板显示结束状态；修改冲突时继续保留结构化回复供审阅。
原生模型子程序使用 `-- 后台模型会话` 区分宿主参数与应用参数。专用验收入口 `测试/模型子程序。测试。豫` 通过具名授权启动实际工作台产物，收取非零退出与错误输出。原生执行器的网页请求导入接通及真实模型回复列入后续实施。
未打开文件时，编辑区保留纸色空白；从资源树打开文件后显示对应内容。
主副编辑组标签共用名称规则，将超过十八个字符的文件名缩为十六个字符加省略号，完整路径通过悬停提示显示，未保存标记继续显示在末尾。
主、副编辑组按剩余宽度等比分配，正文长度保持各组宽度稳定。离屏布局回归覆盖 768、1024、1440 像素宽度，使用固定文字量具验证分配。
副编辑区标题与标签共用短名称规则，标题单行省略，保留工具按钮的布局空间。
文档与 Markdown 阅读内容采用居中的 900 像素宽度上限，窄编辑区按可用宽度展示，沿用云仓阅读页的正文宽度。
文档声明标题随可用宽度排布，定位源码按钮保留操作空间。悬停提示说明定位行为，文档过期时提示先修正源码。
搜索侧栏将搜索框与执行按钮置于同一行，标题与结果计数采用固定行高，搜索结果沿用紧凑资源行。
包树折叠、名称与目录按钮统一为 20 像素高，长包名单行省略，选中背景覆盖按钮区域。
文件标签保持单行，超出宽度时在独立区域横向滚动，视图切换操作置于滚动区域外。
源码编辑区显示从一开始的行号，行号栏宽 48 像素，与正文共用纵向滚动位置。
窗口宽度小于 900 逻辑像素时收起副编辑组，保留副栏文件与编辑状态；恢复宽窗口时重新显示副编辑组。
豫言源码的原始视图复用云仓高亮器的编译器语义范围，注释、字符串、数字、关键字、类型和内建标记按纸墨朱主题着色。解析中的残缺源码使用普通颜色，正文保持可编辑。主副栏共用这套绘制。
着色缓存按文件路径保留最新正文与范围。正文未变的重绘直接复用范围，正文变化后重新解析并替换该文件缓存。
`离屏预览` 入口使用真实工作台视图、字体接口与绘制器，以 1280×800 尺寸编码 PNG，输出 `yy工作台离屏预览.png`。运行环境提供无衬线字体与输出文件写入能力。原生运行已产出真实文件树、中文源码与文档双视图图片，交互场景留待后续验收。
副编辑组的文件标签与操作合并为一行，标签独立横向滚动，主副正文顶端对齐。布局回归覆盖 768、1024 和 1440 逻辑像素宽度。

文档场景通过应用的副栏视图切换消息生成声明数据，并在绘制前检查声明记录与解析结果。该场景的实际图片验收继续进行。
原生预览已绘出声明标题、签名卡片与定位源码入口。预览日志按目录、文档解析、字体、布局、绘制和 PNG 编码分阶段输出。
资源侧栏右缘提供 4 像素宽的全高拖动区域。拖动调整文件、包和搜索侧栏的宽度，初始宽度为 220 像素，抬起结束调整；编辑正文、标签与后台任务沿用当前状态。

主副编辑组的文件标签复用文件树的类型图标，保持 28 像素行高与完整路径提示。
离屏预览分别记录目录、声明、字体、首次布局、首次绘制及 PNG 编码的墙钟耗时，供后台性能核验。
