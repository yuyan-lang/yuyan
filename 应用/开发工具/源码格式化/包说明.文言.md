# 源码格式化

## 格式检查

以 `豫构 构建 源码格式化 检查 --输出 yy格式检查.wasm -j 24` 造只读核验之器。
借编译器析词，寻名（`「…」`）中之英文字母与下划线，复以既有排版器百二十列之果比原文。串与注中之英文字母、下划线皆可用。诸篇保持原貌。

- `node 豫言操作系统/宿主/节点/宿主.cjs yy格式检查.wasm`：核 Git 所录 `.豫` 与 `。豫` 诸篇，略 `*_v0` 之目及 `yuyan-vscode`。名或篇径含英文字母或下划线之篇，逐篇书 GitHub Actions 之误，核毕以一退。排版之失惟告警。
- `yy格式检查.wasm --只查标识符`：惟校名与径、不核排版，有犯则以一退；约十秒，云仓 CI 于云仓之根行之。
- `yy格式检查.wasm --标识符 径之前缀……`：逐处列径以此诸前缀起之篇之犯，每行“篇径：名”，末行总数；无前缀则列尽。
- `yy格式检查.wasm 篇径……`：核所指诸篇，名与排版之失皆惟告警。

提案 00013（标识符规范化）既清仓中旧犯，自此有犯皆败。析文败之篇告警，惟核其径。
CI 之 `formatting check` 作业行无参之核，有犯则作业败；造器败亦报败。

解析并格式化豫言源文件。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `yy源码格式化`，入口依包籍所载。

在仓库之根行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 源码格式化` 以验其籍。行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 源码格式化` 以成其器，不自行之。

所依与组成皆见[包籍](源码格式化。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。
