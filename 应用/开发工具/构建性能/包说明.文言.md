# 构建性能

读构建之志，列诸运行，总一运行之时，以析构建之迟速而求其速。志由豫构、构建编排与并行编译书之，其式见[构建日志格式](../../性能研究/构建性能/日志格式.文言.md)。

段之均时，由统计基础库在线累积而得；摘要依既有秒数之式书之。

## 用法

于仓根行之：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 构建性能 --输出 yy构建性能.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy构建性能.wasm 列出            # 近二十次运行，新者在前
node 豫言操作系统/宿主/节点/宿主.cjs yy构建性能.wasm 列出 50
node 豫言操作系统/宿主/节点/宿主.cjs yy构建性能.wasm 摘要            # 最近一次
node 豫言操作系统/宿主/节点/宿主.cjs yy构建性能.wasm 摘要 <运行名>
node 豫言操作系统/宿主/节点/宿主.cjs yy构建性能.wasm 清理 1000       # 惟留最新千次
```

志之根：先 `--根 目录`，次环境 `YY_BUILD_LOG_DIR`，皆无则今目录之 `.yy构建日志`。

## 摘要所载

- 运行之要：令、目录、分支、提交、有未提交之改否、系统、处理器之数、签、用时、退码，及始终之系统负载。负载高则他构争核，其时不宜与他次相较。
- 进程之树：诸进程之用时、类与参，依父子而缩；豫构之进程附诸区间（包发现、包图、包上下文、编译器调用）之时。
- 编排诸目标：各目标自“检查”之启至“完成”之毕之时，依时降序；跳过者注“已最新”。
- 每一编译（依墙钟降序）：
  - 墙钟、务数（并败者与未行者之数）、务时之和；
  - 平均并行 = 务时之和 ÷ 墙钟；利用之率 = 平均并行 ÷ 并发之限；
  - 关键之路：循所待之最长链，惟计务时，不计候时；及其占墙钟之比；
  - 候槽之和：诸务自备至启之时之和；关键之路上诸务候槽之和：槽为他务所占，关键之路所延之时；
  - 诸段之务数、时和、均时与最久；
  - 最迟之十务；关键之路上诸务（逾六十则惟列首尾各三十）。
  - 有之则录并行工之 Node 宿主计：模块备时、实例行时、宿主调用数；旧志或宿主无计者不显此项。

判之：墙钟近关键之路，则增并发无益，当缩其链；利用高而墙钟远过关键之路，是力不足，当减其工；利用低而墙钟远过关键之路，是调度或候待有失。

## 所限

待办事项：关键之路之“毕”，乃调度收其成之时，含收取之迟；缓存中否及工作进程读所依、算、书出诸步之时与字节尚未录；Windows 上 `清理` 依 `rm`。
