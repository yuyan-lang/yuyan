# 着色器翻译

把着色源（`名。着色器。豫`）译成 WGSL、MSL（金属着色语言）或 PTX（统算），或只做解析与类型检查。

## 包身份

所有者：豫言。包版本：0.1.0。本包为可执行文件类型，程序产物为 `yy着色器`，登记在「开发工具」之下。翻译器在编译器核心（`库/编译器核心/编译步骤/着色翻译/`）；本工具另用包配置发现包并启用包上下文。

## 使用

在仓库根目录运行（工具在当前目录发现包，为文件所属的包启用包上下文）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色器翻译 --输出 yy着色器.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy着色器.wasm 译 库/着色库/测试/样例/加倍。着色器。豫
node 豫言操作系统/宿主/节点/宿主.cjs yy着色器.wasm 金属 库/着色库/测试/样例/加倍。着色器。豫
node 豫言操作系统/宿主/节点/宿主.cjs yy着色器.wasm 统算 库/着色库/测试/样例/加倍。着色器。豫
node 豫言操作系统/宿主/节点/宿主.cjs yy着色器.wasm 检查 库/着色库/测试/样例/加倍。着色器。豫
node 豫言操作系统/宿主/节点/宿主.cjs yy着色器.wasm 生成 库/着色库/测试/样例/加倍。着色器。豫
```

- `译`：WGSL 打印到标准输出；入口表（每行“入口：入口项 → 函数（阶段）”）打印到标准错误。
- `金属`：同样译成 MSL，供金属在运行时编译（只支持计算入口，顶点、片元入口写成一行注释略去）。
- `统算`：同样译成 PTX，供统算驱动即时编译（只支持计算入口；入口表里是改写成 ASCII 的 PTX 入口名）。
- `检查`：只做语法分析与类型检查，通过时打印“检查通过：文件”。
- `生成`：打印高级代码导入此着色源时构建所得模块的豫言源码（导出「着色源」「金属源」「PTX源」、各入口项的函数名与 PTX 入口名）。

失败时打印“着色器翻译失败：原因”并以退出码 1 结束。应用里一般不直接调用本工具：高级代码 `寻` 着色源时，编译器在构建中完成翻译。语言规则见[着色语言](../../豫言编译器/文档/语言技术规范/着色语言.汉语.md)。依赖及说明路径以 [包配置](着色器翻译。包。豫) 为准。
