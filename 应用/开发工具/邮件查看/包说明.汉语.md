# 邮件查看

这是邮件格式库的文件查看程序。运行 `yy邮件查看 邮件文件` 显示邮件头部、MIME 嵌套层数与载荷字节数。邮件按回车换行读取，解析错误显示原因。程序自行实现，许可遵循仓库许可。

头字段显示调用 RFC 2047 解码，UTF-8 与 GBK 的 B、Q 编码字显示为文本；编码字段解析失败时显示原字段值。

私有入口 `邮件发送` 使用现有TCP连接升级STARTTLS，执行服务器证书、主机与握手签名验证。运行参数为主机、端口、招呼域名、发件人、收件人、邮件文件、当前Unix秒及可选可信根DER文件。安全连接复用安全传输及证书库的公开接口。消费者已经链接，真实互通、关闭及负例验收继续实施。测试网络目录提供纯豫言SMTP对照服务源码，以本机OpenSSL作为测试对端，按独立端口与标准流管线运行。
