# 网页设计

取本地站点之网页，依所予视口编为设计之作，藏路径、图层、遮罩与图材，可授设计播放器而观。

以 `豫构 构建 网页设计 --输出 网页设计。苹果。豫行 -j 24` 成器。行之曰 `./网页设计。苹果。豫行 站点目录 网页相对路径 输出。设计 宽 高 [语言代码]`。语言常取 `zh`，亦可于末项授 `en` 等代码，以定布局与择字。首页之径为空，目录页之径以 `/` 终。

以 `https://yuyan.local/` 为站根，循相对之址及根径取站内之材。先析其址而正其径，询文与片段存于址，读材惟循其径；遇已存之目录，则取其中 `index.html`。字用系统所藏，站内字材亦循址取之。外站之材，俟后续版本。

欲藏其动，行 `./网页设计。苹果。豫行 动画 站点目录 网页相对路径 输出。设计 宽 高 时长`。时长以毫秒计，至少一毫秒。因所载之篇、字、图及样规，以节点原信号藏为设计影卷。

遍站成卷，行 `./网页设计。苹果。豫行 整站 站点目录 输出目录 宽 高`。循站之诸箧，收 `.html` 之页，共材与字库，各编其作。输出循旧相对之径，以 `。设计` 代 `.html`，如 `文档/总纲.html` 则著于 `输出目录/文档/总纲。设计`。
