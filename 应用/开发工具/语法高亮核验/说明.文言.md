# 语法高亮核验

遍仓中豫源，以编器析其辞，定标记于原文；复以 TextMate 与 Oniguruma 分色，逐字校其可比之域。析败者别列，不阻余篇。

先以 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 语法高亮核验 --输出 yy语法高亮核验.wasm -j 24` 成器，后行 `node 豫言操作系统/宿主/节点/宿主.cjs yy语法高亮核验.wasm`。可授仓根，不授则取今径。候选出于 Git 工作树，取 `。豫`、`.yuyan`、`.yyon`，略 `_v0` 及所忽略之篇。文件表写 `yy语法高亮文件表.txt`，导入所据写 `yy语法高亮上下文.txt`，差异写 `yy语法高亮差异.json`；既析之果按源、器、上下文摘要藏于 `.yybuild/语法高亮核验/`。逐篇别起豫器（器为 `.wasm` 者托节点宿主行之），五百秒不成则记未覆，仍校余篇；时限可以 `YY_GRAMMAR_TIMEOUT_MS` 易之。析一篇必兼其所导，常费十余秒，遍仓逐篇须数时，宜先择样而校。

编器偏移按 Unicode 字，TextMate 按 UTF-16 码元，校前须转换。取 scope 所属之色类，不取随主题迁易之 RGB。惟校编器已标、两类可对应之字；无标之域不称已验。编器谓括号、方括号、逗号为常术，TextMate 谓之标点，校时同归标点；跨行之换行不妄报。每异具路径、行列、原文、二类及 scope；差异为待审之证，非独断编器必真。详见同名 `.汉语.md`。

## 删白之验

编器不视空格换行，故删之而诸非白之字不当易色。`应用/开发工具/yuyan-vscode/test/删空白核验.mjs` 以五法删白（尽删、惟删换行、惟删空格、间段而删者二），逐字较删前删后 TextMate 之类；删而成 `「：` 或 `：」` 之白则存之，盖其易注与转义之界也。此验不待编器，遍仓分十片并行，约一分而毕：

```sh
git ls-files -- '*。豫' > yy删空白文件表.txt
node 应用/开发工具/yuyan-vscode/test/删空白核验.mjs . yy删空白文件表.txt
```

可加第三参“第几片/共几片”（自零起）分为数进程并行；报写 `yy删空白差异-第几片.json`，有异则退出码为一。TextMate 逐行分辞，故 grammar 以 `。` 分句，惟于句首识声明，字段之列、括号诸域皆以语境相配，不系于行首、行尾及缩进。旧式金样之裸名紧接关键辞者，删白犹易其色：grammar 有意不于裸名之中着关键辞之色。
