# 实际终端尺寸与物理窗口接线

主循环每次重绘调用正式「读取标准终端尺寸」，同时检查成功、列大于零、行大于零；成功后消费真实宽高，失败继续原逻辑行路径。查询使用共享原生尺寸能力，应用未加入 DSR、轮询等待或默认八十列。

私有布局消费文字排版「码点断行区间」。每个扩展字素为一个数组槽，宽度由统一码计算，非换行映六十五哨码，确保末空格按终端格数折行。CRLF 映单个硬断槽，满列末尾补虚行。可见帧按真实行数裁剪，并随编辑光标移动；旧窗口缩小时相对移动限于现行高。SGR 归属后继字素并在续行恢复，清行与归标复位。高亮回调经过现有行编辑「高亮文本」进入真实应用展示路径。

新自动测试「物理窗口。测试」提供十五个固定参考，保留原六项私有布局参考。源码格式化与 git diff --check 通过；本阶段依快速合入指令未进行新编译或实际尺寸 PTY 验证，相关结果交后续验收，未登记甲乙达标。先前六真实 PTY 会话证据仍仅证明编辑输入与逻辑重绘。

已落地功能为字素与东亚光标、Emacs 按键、可存历史与 Ctrl-R、补全回调、多行编辑、高亮回调和终端物理窗口源码。第一个实际使用者为豫言终端命令壳。交互求值提案 00003、数据库和模型命令行的独立交互入口迁移另外记录；现数据库入口采用命令参数执行 SQL。本阶段未增设这些应用的交互模式。

边界：单字素宽度超过整屏列数、非 SGR 控制序列嵌入高亮结果、终端在读取按键阻塞期间单独改变尺寸仍需后续实测。尺寸在下一次输入重绘时重新读取。高亮器应保留原可见字素，只增加 SGR 样式；几何位置根据编辑原文计算。
