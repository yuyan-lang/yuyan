# 豫言终端

提供豫言交互式终端。

交互输入的末尾退格使用「行编辑」基础库，按统一码扩展字素簇删除组合字符和表情序列。

主循环保留行编辑会话，历史上下浏览与 Ctrl-R 经过会话状态机，候选确认调用补全回调并保留光标右文。逻辑行重绘通过终端相对光标控制，按提示及光标前文的东亚列宽定位。零距离归标输出空串。

命令补全复用「壳核心」的名字候选索引，提供纯豫言无调全拼与音节首字母。接线十七例与拼音补全十例通过 Node；真实终端六会话通过 Node，覆盖中文退格、历史、搜索取消、补全、多行与搜索接受。手动入口为「真实终端验收。脚本」，由真实终端逐次送键运行。

实际屏宽、软折行及本轮新增向量的原生验收继续实施。表情列宽按统一码库当前规则计算。

Ctrl-O 在光标处开新行，输入仍从原光标继续。多行输入用上下方向键按东亚列宽移到相邻逻辑行；单行输入用上下方向键浏览历史。候选重写前文后重新切分完整字素，组合标记可以与新前文合簇。

交互重绘通过「豫言操作系统控制台」读取标准输出终端的真实列数与行数，按「文字排版」的字素槽区间软折行。物理窗口跟随光标纵向滚动，候选使用剩余可见行，每次按键重绘重新取尺寸。正尺寸查询成功时启用物理窗口；查询失败时采用逻辑行重绘。

物理展示保留提示与输入的 SGR 样式，续行恢复样式，清行和归标前复位。应用私有「设置交互高亮器」接收全文高亮回调，通过行编辑「高亮文本」生成展示，编辑原文保持原值。高亮器可添加 SGR 样式。

「物理窗口。测试」为 CI 自动发现入口，包含十五项固定宽高、组合字素、末空格、CRLF、SGR、滚动与高亮参考。本阶段完成源码、格式化和差异检查；真实尺寸下的彩色软折行与新原生入口验收继续实施。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为可执行文件类型，不可被其他包依赖；包内模块仍可互相引用。类型典中的入口和文件名见包配置，程序产物为 `yysh`。

## 使用

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 豫言终端
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 豫言终端
```

依赖及说明路径以 [包配置](豫言终端。包。豫) 为准。构建不会自动运行程序；有发布或服务副作用的工具应先阅读其入口源码。
