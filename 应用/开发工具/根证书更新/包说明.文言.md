# 根证书更新

此器以豫言转 Mozilla NSS `certdata.txt`，存诸证书之 DER、TLS 服务器信任位及失信日期。标签重、无标签、八进数误、文缺及无证书者，皆报失。析成乃书根证书数据包之 `数据表。豫`。

`CKA_CLASS` 起新对象而清其标签；证书、TLS 信任及失信日期各验其标签。日期受 NSS 十三字节及十五字节之数字加 `Z`，书表前验其文形。入文为仓外所取 NSS 全篇；转换之口可治证书及另立之信任对象。

造器用 `豫构 构建 根证书更新 --输出 yy根证书更新.wasm -j 24`。行器用 `节点 yy根证书更新.wasm 仓外certdata.txt 库/基础库/密码与安全/根证书数据/数据表。豫`。

源取 [Mozilla NSS](https://raw.githubusercontent.com/nss-dev/nss/master/lib/ckfw/builtins/certdata.txt)，许可 MPL 2.0。下载置仓外，录源之提交、日期及 SHA-256；生成则整表，验根数据，并修数据包双语说明之来源与摘要，乃录其改。全树测试自察基本转换之验；Mozilla 全集及原生全验俟后。
