## 捷思脚本之行与验

- `捷思运行 脚本文件`：以一 `.mjs` 为模块置于捷思引擎而求值，印其状（求值成，或首误与所用之时）。宿主之物（`window`、`globalThis`、`self`、`document`、`navigator`、`console`、`WebAssembly` 及常见之构造器与函数名）由 `宿主桩。豫` 供最小之桩，惟使脚本顶层不因缺名而抛误，不仿其行。模块依 `import` 之关经加载器自本地文件读之：相对之径依引用者所在之目录，站绝对之径（如 `/豫言操作系统/浏览器/引导检查.mjs`）依当前目录；成品之中平铺于一目之脚本，于仓则散于数处，文不得则于 `豫言操作系统/装载`、`豫言操作系统/宿主/网页汇编`、`豫言操作系统/宿主/浏览器` 依名补求之；`node:` 为首之模块惟供空函数之桩。
- `捷思验收 脚本目录`：于目录中每一 `.mjs` 各行一次 `捷思运行`。
- `捷思分析 脚本文件`：调试之用，印模块之依赖说明符、导入之项及导出之项。

## 网平测参照试

网平测（web-platform-tests）之参照试，由本引擎自渲：试页与参照页各渲一遍（视口八百乘六百），逐素较之，容差依网平测之 `fuzzy` 元标签。网平测之数据置仓外之数据目录（`/Users/zc/repos/yuyan-worktrees/豫言数据/网页数据/wpt`，git 稀疏检出；补目录用 `git sparse-checkout add css/css-flexbox …`）。

### 用法示例

构建：`豫构 构建 网页一致性 --输出 yy网页一致性.exe -j 24`。于林纳克斯之 x86-64 机，用六十四位豫构并加 `-- --目标 本机 --执行器 yy执行器六四。树码`。运行：

### 命令

- `网平测参照 数据目录 子路径… [--输出 清单] [--并发 个数] [--时限 秒] [--内存 兆] [--深度 汇总深度] [--续] [--只列]`：批量而行。子路径为数据目录下之子目录或文（如 `css/css-flexbox`、`html/rendering`）。运行器递归寻带 `<link rel="match">` 或 `<link rel="mismatch">` 之试页（略 `support`、`resources`、`reference`、`tools` 之目录与名为 `-ref`、`-notref` 之参照页），每试各行于独立子进程（程序以 `网平测单测` 自调），并行至多“并发”个（默认四）。单试逾“时限”（默认一百二十秒）或常驻内存逾“内存”（默认八千一百九十二兆）即止之，崩溃、逾时、逾内存皆唯记为出错，余试照行。`--输出` 指果单之文，每百条刷新一次；`--续` 读已有之单，唯行单中所无之试；`--只列` 唯列将行之试。毕则依径排序书单，并印各级目录之汇总（总计，及深一至“汇总深度”之各级目录，默认三级）。
- `网平测单测 数据目录 路径`：行一试，印一行：`网平测结果`、论、异素数、说明（制表符分隔）。
- `网平测存图 数据目录 路径 输出目录`：以试页、首条参照页及差异图（异处标赤，同处淡之）存为三 PNG，以观败因；输出目录须先有。
- `网平测汇总 清单 [深度]`：于果单印各级目录之汇总。`网平测对比 旧清单 新清单`：逐径较二单，印论有变之试及退步、进步、新增、消失之数。
- `网平测字体 数据目录`：印三标准族名与 Ahem 可得字体否，以诊某机之字体。

### 果单

每行四列，制表符分隔：径、论、异素数、说明。

| 论 | 义 |
| --- | --- |
| 通过 | 得一条步步皆成之参照通路；说明书“两页皆纯色”者，二页皆为纯色（多为皆未绘出而偶同） |
| 失败 | 渲染之果与所求不合；说明书何页纯色、极道差及差异框（异素之包围盒），求不等价而等价者书“两页相同” |
| 出错 | 页读取败、子进程崩溃、逾时或逾内存 |
| 跳过 | 页含可行之脚本或须待脚本（`reftest-wait`）、分页或须人手、服务端替换（`.sub.`）、参照为图像或矢量图，或无参照；脚本一概当数据，不行 |

异素数取诸较中异素最少者。汇总之通过率 = 通过 ÷（通过 + 失败 + 出错），跳过不计；“其中皆纯色”一栏记二页皆纯色而通过之试数，“去之后”之通过率复去此类试。

### 判定之则

- 同页之数参照为“或”（任一成即可）；参照页自带参照者循链依次而成（深度优先，至深八层）。
- `match` 求二页等价，`mismatch` 求二页不等价。
- `<meta name="fuzzy" content="[参照页:]maxDifference=a-b;totalPixels=c-d">` 示容差：单数则自零至其数，带参照页之前缀者唯施于其参照页；无 `fuzzy` 则求逐素相同。
- 页中之相对址依试页之址解之，以斜杠为首之址映于数据目录之根。
- `.xht`、`.xhtml` 之页，先去 CDATA 之标记，并展自闭而非空之元素，再依超文本标记解析（近似可扩展标记之解析）。
- `font-family: Ahem` 取数据目录之 `fonts/Ahem.ttf`，余字体用系统之体；林纳克斯上之原生执行器暂无字体宿主，运行器依候选之径读 Liberation 字体。
