# 云设备代理

云设备代理是豫言编写的命令行工具。`供给` 模式连接豫言云，接收命令执行、任意 HTTP/HTTPS 请求和模型转发任务。它也能独立向本机 Ollama 或 OpenAI 兼容端点发送请求，并把往来按 session 保存在当前目录的 `AI会话` 下。

## 用法

在仓库根目录构建：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy3_bs.wasm 应用/开发工具/云设备代理/入口。豫 -o yy云设备代理.wasm --parallel
```

```text
yy云设备代理 发送 <ollama|openai> <session> <请求文件> [主机] [端口]
yy云设备代理 列出
yy云设备代理 浏览 <session>
yy云设备代理 网页 [端口]
yy云设备代理 登录 [端口]
yy云设备代理 供给 <服务商凭据文件> [本地主机]
```

协议 `ollama` 将请求送至 `/api/chat`，默认端口 `11434`；`openai` 将请求送至 OpenAI 兼容的 `/v1/chat/completions`，默认端口 `1234`。主机均默认为 `127.0.0.1`，也可显式指定。请求文件原样转发，须符合所选端点的 JSON 格式；要实时看到生成过程，请设置 `"stream": true`。每次请求的协议写在 `协议.<时间>.txt` 中，命令结束也会打印协议。

session 只能含英文字母、数字、横线和下划线。发送命令将原请求留在 `请求.<时间>.json`，上游响应正文留在 `响应.<时间>.jsonl`。同一 session 可发送多次；`浏览` 在命令行展示存档。`网页` 启动只监听本机的浏览页面，默认端口 `8765`，页面展示 session 列表、原始请求、响应与协议。

例如，请求文件为 `请求.json` 时，可运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy云设备代理.wasm 发送 ollama 示例 请求.json`；随后运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy云设备代理.wasm 网页`，在浏览器打开命令所示地址。

`登录` 的用法类似 `wrangler login`：在本机 `127.0.0.1` 上监听一个端口（默认 `8976`），打印并尝试打开本站链接 `https://yuyan-lang.org/个人?cli_port=端口&cli_state=状态码`。你在浏览器里登录本站并点“授权命令行登录”后，本站签发一个主访问令牌（`yym_` 开头，有效 90 天），用 303 改址送到本机的 `/callback`；工具核对状态码后把它存进 `~/.豫言/云凭据.json`（目录权限 700、文件权限 600）。每次授权会作废以前命令行登录得到的主令牌。十分钟内没有收到回调则退出。登录只保存凭据，不接受任何远程任务；`供给` 模式须另外在前台显式运行。`yy批量发布 --发布` 在没有设置 `YY_UPLOAD_TOKEN` 时，用这个主访问令牌换取上传令牌。

`供给` 模式使用系统 `curl` 连接云端，接收现有 `request` 模型任务，以及新增的 `exec` 与 `http` 任务。它继承启动程序的账户权限，不自行提权。云端控制事件的 JSON 形状如下：

```json
{"type":"exec","id":"任务编号","command":"可执行的 shell 命令"}
{"type":"http","id":"任务编号","url":"https://example.com/path","method":"POST","headers":["Content-Type: application/json"],"body":"{}"}
```

`exec` 由 `/bin/sh -c` 执行。`http` 的 `url` 可指向任意 HTTP 或 HTTPS 地址，包括本机、局域网和公网；`method` 默认为 `GET`，`headers` 与 `body` 可省略。HTTP 响应包含状态行、标头和正文。两类任务经现有 `/api/ai/provider/chunk` 分片通道回传一个 JSON 结果，字段为 `exitCode`、`stdout`、`stderr`；HTTP 结果的 `stdout` 包含响应原文。非零退出码仍作为任务结果返回。云端分发及界面尚需配合此协议。

`发送` 模式仍使用自带的 HTTP/1.0 连接实现，不支持 HTTPS、鉴权或 HTTP 分块传输编码；这一限制不适用于使用 `curl` 的 `供给` 模式。
