# 原生对比

较原生工具链与 Node 工具链构建之时。原生者，仓库目标「原生工具链」所生之 `yy豫构.exe` 与 `yy4_bs.exe`；Node 者，`yy豫构.wasm` 与 `yy4_bs.wasm`。原生之中位慢于 Node，则书 GitHub 之警（`::warning`）；二者产物不同或构建败，则书误（`::error`）而以一退。CI 之「Wasm 包起步」于 Linux x64、Linux arm64 与苹果行「全部」之后行之。

## 用法

先于仓根行「全部」，以生原生工具链。乃：

```sh
./yy豫构.exe 构建 原生对比 --输出 yy原生对比.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy原生对比.wasm                      # 探针三轮、全构二轮
node 豫言操作系统/宿主/节点/宿主.cjs yy原生对比.wasm --探针轮数 5 --构建轮数 3 -j 24
```

## 所量

- 冷编打印之探：`豫构 文件 应用/开发工具/原生对比/打印探针。豫`。探唯以标准库打印一行；工作之务不读缓存（`-- --do-not-load-cache`），标准库诸模皆现编。
- 全构豫言编译器：`豫构 构建 豫言编译器`，工作之务亦不读缓存。

每负载行若干轮：奇轮先 Node 后原生，偶轮反之；每轮以 `cmp -s` 核二产物逐字相同。终书 Markdown 之表，列二者之中位、原生与 Node 之比、诸轮之秒；有环境变量 `GITHUB_STEP_SUMMARY` 者，并书于其文，为作业之摘要。产物书于仓根之 `yy原生对比-*.wasm`，以 `yy` 始，Git 略之。

墙钟为机上他务所扰，CI 诸运行器亦多异，故唯书警，不令作业败。
