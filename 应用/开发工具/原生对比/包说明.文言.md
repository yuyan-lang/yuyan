# 原生对比

较原生工具链与 Node 工具链构建之时。原生者，仓库目标「原生工具链」所生之 `yy豫构.exe` 与 `yy4_bs.exe`；Node 者，`yy豫构.wasm` 与 `yy4_bs.wasm`。原生之中位慢于 Node，则书 GitHub 之警（`::warning`）；二者产物不同或构建败，则书误（`::error`）而以一退。CI 之「Wasm 包起步」于 Linux x64、Linux arm64 与苹果行「全部」之后行之。

## 用法

先于仓根行「全部」，以生原生工具链。乃：

```sh
./yy豫构.exe 构建 原生对比 --输出 yy原生对比.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy原生对比.wasm                      # 探针三轮、全构二轮
node 豫言操作系统/宿主/节点/宿主.cjs yy原生对比.wasm --探针轮数 5 --构建轮数 3 -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy原生对比.wasm --场景 全部 --轮数 5 -j 24      # 议五诸场景
```

`--场景 名` 可复，名曰 探针、构建、系统、增量、你好、测试、原生产物，或 全部；不给则行探针与全构（CI 如此）。`--轮数` 为余场景之轮数，默三。

## 所量

- 冷编打印之探：`豫构 文件 应用/开发工具/原生对比/打印探针。脚本。豫`。探唯以标准库打印一行；工作之务不读缓存（`-- --do-not-load-cache`），标准库诸模皆现编。
- 全构豫言编译器：`豫构 构建 豫言编译器`，工作之务亦不读缓存。
- 冷编豫言系统（系统）：工作之务不读缓存。
- 改一文后重构豫言系统（增量）：先各行一遍以实其缓；每轮于 `兼降级原语。豫` 末附各异之注一行，重构而复其旧。
- 小程构而行之（你好）：构打印之探而行之，所出须含“你好，豫言”。Node 出 `.wasm` 而以 Node 行之；原生径出原生可执行之文（编译器 `--目标 本机 --执行器 yy执行器.wasm`）而径行之。先各行一遍以实其缓。
- 试之子集构而行之（测试）：标准库中不涉网络与进程之试六则，逐一如上构而行之，退码须零。
- 全构编译器而出原生之产（原生产物）：同全构，原生一边径出原生编译器，行其 `--version` 以核之。

每场景行若干轮：奇轮先 Node 后原生，偶轮反之；二边皆出 `.wasm` 者（探针、全构、系统、增量）每轮以 `cmp -s` 核二产物逐字相同。终书 Markdown 之表，列二者之中位、原生与 Node 之比、诸轮之秒；有环境变量 `GITHUB_STEP_SUMMARY` 者，并书于其文，为作业之摘要。产物书于仓根之 `yy原生对比-*.wasm`，以 `yy` 始，Git 略之。

墙钟为机上他务所扰，CI 诸运行器亦多异，故唯书警，不令作业败。
