# 浏览器

页面载入时浏览器造页面接口宿主：抓取交换复用本页的资源读取器（支持 `file:`、`data:` 与 `http(s):`），本地簿按页面来源新建并复用，会话簿每页一份，持久化留待后续版本。交换目前按地址取资源、给状态二百与正文，请求方法、首部与正文的传递留待后续版本。

网络资源经过「抓取」的内部资源入口，沿统一安全链检查并保留页面渲染正文。导航响应记录内容安全策略，后续子资源沿同一策略请求；严格传输策略在安全响应后登记并升级后续地址。底层已解码的响应移除编码和长度首部后交统一抓取层。

单选列表采用最后一个已选项，展开列表保留空选择；首个直接选项的空值按占位规则参与必填校验，已选的禁用选项参与必填判定后从提交中排除。祖先自动方向按其后代文字判定。缺少媒体类型的网络响应和无扩展名本地文件按签名识别常见图像。片段中的文本指令保留锚点回退，纯文本指令保持当前滚动，锚点解码保留首个字节序标记字符。

文本输入与文本域的 `dirname` 字段附带文字方向，显式方向沿祖先继承，自动方向取首个强方向字符；隐藏的 `_charset_` 字段提交八位统一码编码名，候选列表后代从提交和校验中排除。片段导航由内向外滚动锚点所在的嵌套容器，遵守各容器滚动范围。

同站判定规范化域名、国际化主机与网络地址，拒绝空主机和非法主机，尾点域名沿公共后缀规则比较。文件网址接受本地主机，文件子资源由文件页面读取，安全网页的子资源遵守安全传输约束。

载入失败时页面区显示“无法载入 地址”与“原因：…”：读取器把顶层地址的异常消息记进 `浏览器载入错误`，没有异常而得不到页面时按网址形态补写原因（网址无法解析、不支持的网址方案、资源不存在或无法解码），页面内容无法解码时记同名原因；每次载入前清空，没有失败原因时页面区显示输入提示。网络请求的诊断照旧打印到标准输出。冒烟测试核对失败记录与方案提示。

非空输入支持数字语法、上下限及步长、邮箱基本结构、完整网址及模式整串匹配。数字步长默认一，支持 `any`，基点依次采用合法的 `min`、`value` 属性及零，运算容许微小浮点误差。文字长度适用于文本输入和文本域，模式适用于文本输入；只读豁免依输入种类适用。模式采用脚本正则的统一码集合模式，语法错误忽略该约束。日期控件和完整邮箱语法继续实施。

表单提交前检查必填与文字长度约束，点击与回车共用校验。失败时显示说明并聚焦首个无效控件，表单与提交者的跳过校验属性可用。

禁用字段集的首个直接图例子树保留控件可用性，嵌套时继续检查外层字段集。禁用选项组的选项从成功控件中排除。

多选控件逐项显示勾选状态与活动项。点击对应行或按空格切换该项，上下键移动活动项，上档方向键选择经过的范围，控制或命令加全选键选中可用项；提交保留同名多值。禁用项切换、全选及范围选择沿用禁用检查。范围回缩、禁用项的焦点跳过与细化列表主题继续实施。

输入与文本域编辑时自动显露插入符，横向超宽文字和纵向超高内容随光标移动；点击、拖选及候选区域共用移动后的行片段。手动滚动与拖到边缘自动滚动继续实施。

文本域按行显示，点击和拖选按纵坐标选择文字行，候选区域按控件或组字光标选择对应行；上下键保持当前横向位置移到相邻行，上档键继续扩选。精细字形定位、连续纵移的横向目标记忆与控件内部滚动继续实施。

候选窗区域取自聚焦控件的可见文字片，跟随控件光标或组字光标；页面画布通过原样输入区域向显示控件报告，候选窗提示包含画布在窗口内的偏移。逐字形、多行和真实输入法窗口验证继续实施。

组字更新保存预编辑文字及其光标，提交文字仍由文字输入写入控件。组字期间页面编辑键与回车由输入法处理；焦点改变、窗口失焦和提交清理预编辑状态。预编辑显示与候选区域接通；逐字形、多行及真实窗口验证继续实施。

上档点击同一文本控件保留原锚点，点击位置成为选区末端；随后拖动继续扩展该范围。跨控件点击建立新锚点。

文本控件指针按下取得焦点并定位锚点，移动更新选区，抬起保留范围。控件片段复用滚动、裁剪和样式变换，位置按行宽比例计算并收拢到字素边界；横向拖出时夹到首尾。导航和窗口失焦清理拖动状态。沿用固定度量综合冒烟核对按下定位及拖动范围；多行纵向定位、双击选词、上档点击、自动滚动和旋转局部坐标继续实施。

控件重排同步锚点与光标到文字绘制选区，焦点切换清理旧控件装饰。输入与文本域显示选区背景、选中字色或单像素插入符，绘制复用内容框裁剪和既有滚动变换。沿用综合冒烟以固定度量核对选区显示片和插入符几何；逐字形位置、多行映射、闪烁、内部滚动和组字反馈继续实施。

文本选区保存锚点与光标，上档加方向、起首或末尾扩展范围，普通方向键收拢已有选区。复制、剪切、删除、粘贴及文字输入共用范围，替换时最大长度按剩余文字计算。字素与按词移动可扩选。指针拖选、选区绘制和历史完整选区保存继续实施。

焦点顺序先按正值 `tabindex` 排序，同值保持文档顺序，再轮到默认与零值；负值通过指针或自动焦点取得焦点。制表键前进，上档加制表反向并循环。按钮、链接及显式焦点元素加入轮换，自动焦点在载入后重绘焦点环；按钮回车与空格、链接回车复用提交、复原和导航。隐藏属性、隐藏输入及禁用控件按焦点资格处理；样式可见性、惰性子树与阴影树焦点代理继续实施。

文本控件移动与删除遵循统一码扩展字素边界，命令／控制加方向键或删除键按词边界操作。命令／控制加 X 剪切全选文字，加 Z 撤销，加 Y 重做，历史按控件身份保存文字及光标；复原与跨文档导航清空历史。输入按最大长度属性限制插入并保留完整字素。撤销分组、完整选区和统一码十六位长度规则继续实施。

复原按钮按表单归属恢复默认值与选态，包含显式关联的外部控件。单行输入回车采用默认提交按钮并沿用提交者覆盖；没有提交按钮的单输入表单可直接提交。文本域回车插入换行。隐式提交的阻挡输入类型细分留待后续版本。

页面控件可取得焦点并编辑：文本输入、方向键、首尾移动、退格、删除、命令／控制全选与复制粘贴接到实时值，文本域接受多行回车。点击标签与控件切换复选、单选和下拉状态，制表键依文档顺序切换控件。重排保留文档身份、字体集合与既有计算样式，提交消费实时值；跨文档导航清理旧状态。范围选择、光标和组字绘制、下拉弹窗、多选交互、类型专用控件、约束校验及状态伪类重新级联继续实施。

最小壳复用网页载入、布局与绘制，资源读取接受文件、数据网址和明文与安全网络地址。网络请求复用超文本传输的默认网址请求、证书验证、内容解压和会话小饼；显示与输入复用界面自绘的像素图控件。载入时用「载网页」执行页面里的普通脚本，再按脚本改过的文档渲染，每个脚本（以及事件监听、定时器回调）最多五千万步。页面定时器（setTimeout、setInterval、requestAnimationFrame）在计时更新里按页面时钟执行，计时间隔取到下一个定时器到期为止；回调改了文档就重排一次。点击页面时先向命中的节点派发冒泡、可取消的 click 事件，页面脚本的监听取消时不做默认动作（跟随链接、提交、激活控件），监听改了文档就重排。按键时同样先向焦点控件（没有时向 body）派发 keydown、keyup，带 key、keyCode 与修饰键字段，监听取消时不滚动、不编辑。表单控件取得、失去焦点时派发 focus、blur（值比取得焦点时变了先派发 change），输入或删改文字后派发 input，勾选框、单选框与下拉框改变后派发 input 与 change。页面里的模块脚本（type="module"，内嵌与外部，可从相对地址导入）在普通脚本之后执行。按下、抬起鼠标左键时先向指针下的节点派发 mousedown、mouseup（带 clientX、clientY、button）；指针移动时指针下的节点换了先派发 mouseout、mouseover，再派发 mousemove。页面脚本记下的导航（location.href、assign、replace、reload）、改地址（pushState、replaceState）、走历史（back、forward、go）与滚动（scrollTo、scrollBy）请求，浏览器在处理消息与计时更新之后照办，新页面载入时又记下的（脚本重定向）接着照办，最多十轮；pushState 新加历史条目时旧地址推进后退历史。窗口尺寸写进页面的 innerWidth、innerHeight，重排后派发 resize。每次重排后把页面区尺寸与滚动位置写进模块 `观听`（媒体查询列表、大小观察器与交叉观察器），按新盒树投递大小观察与交叉观察；窗口尺寸变了重新求值媒合并派发 change。mouseenter、mouseleave、popstate、hashchange 留待后续版本。

窗口提供地址栏、回车访问、前往按钮、后退与前进按钮；地址栏一行定高 40 像素，校验说明也排在这一行，其下整块是页面区。页面视口跟随窗口大小（`页面视口`）：视图记下窗口尺寸，页面图尺寸与它不同时由计时更新按新尺寸重排，滚动位置夹回可滚范围；命中与收文字片按页面图的视口矩形。主键抬起按显示列表命中并沿祖先查找链接，滚轮更新视口位置并复用盒树重绘。页面有焦点且没有控件焦点（或焦点在链接上）时，上、下、左、右键每次滚 40 像素，上翻页、下翻页与空格每次滚页面区高减 40（上档加空格向上），起首、末尾滚到两端。导航历史保存地址，跨文档返回时重新载入。

片段导航解码百分号与统一码，优先匹配元素标识，再匹配具名锚；空片段与缺少目标的 `top` 滚到页首。首次载入可以定位片段，同文档访问与片段历史复用节点、字体集合及盒树，地址栏保存完整地址。

主键拖动可以跨文字节点选择，命中片段复用滚动、变换与裁剪路径，选区复用页面的选中字色和背景绘制。拖动选区后抑制链接导航。全选与复制按钮，以及页面焦点上的命令／控制加 A、C，可选择文字并复制到系统剪贴板；导航清除旧选区，复制失败时显示诊断并保留选中文字。

用豫构构建 `浏览器`，图形运行环境提供“主窗口”显示面、系统字体与剪贴板接口。唯一的 `冒烟。测试` 入口检查画布尺寸与像素、滚动位置、后退和前进、按窗口尺寸重排与翻页量，在改窗口尺寸与滚动后核对大小观察与交叉观察的条目，并用固定文字度量核对字符命中、反向跨节点选择、全选与清理。末尾的表情一例把浏览器的基础字体换成只含官方 `NotoColorEmoji.ttf` 的集合（文件不存在时印一行说明而跳过），载入 `👍🏽 🇨🇳 👨‍👩‍👧` 一段，核对显示项里图像图案颜料的彩字项至少三条、段落宽度在合理范围。构建 `浏览器` 的图形运行环境提供主窗口显示面、系统字体与剪贴板接口。

页面区按显示面像素比显示：运行循环把像素比交给视图，`高清页面` 先铺一层白底（网页画布没背景时透明），再按整数倍复制一倍页面图的像素放大，按版号与像素比缓存；页面区的原样输入坐标除以倍数换回 CSS 像素。滚轮只改滚动位置并记下待重画，主循环交完排队的输入后由计时更新合并成一次重画；重画复用同一页面的文字路径与图像读取器（`重绘读取器`）。只纵向滚了整数像素时平移旧画面、只画露出的条带（`舒卷重绘网页盒页`），点击与按下时按整幅补出显示列表再命中（`浏览器命中显示列表`）。欢迎页列出豫言官网与 example.com 两个链接。

macOS 应用：`构建 浏览器 --输出 浏览器臂。豫行 -- --目标 本机 --目标系统 豫言 --目标架构 臂六十四 --执行器 <绝对路径>/执行器新。树码` 编出与豫言操作系统相同的豫行，再用 macOS 豫行启动器 `--合成` 成单文件，放进应用包的 `Contents/MacOS/`，桌面字体随包放在 `Contents/Resources/豫言操作系统/裸机/字模生成/字体/原始字体.ttf`（启动器在当前目录找不到字体时改到 `../Resources`，从访达双击也能启动），再本机签名（提案 00021）。执行器与启动器取自与浏览器同一份源码（提交 4bacc9761 之后）：用稳定编译器 `构建 客体二号 --输出 执行器新。树码` 得执行器，再用它构建新的豫构（`构建 豫构 --输出 豫构新。林檎。豫行 -- --目标 本机 --执行器 …`），由新豫构构建启动器（`构建 豫言裸机 豫行启动器 --输出 豫行启动器臂。林檎。豫行 -- --目标 本机 --目标系统 林檎 --目标架构 臂六十四 --执行器 …`）与浏览器。稳定工具链包里的旧执行器遇到大于 4 KiB 的 HTTPS 响应读取会丢数据（整块代办放不下时重发读取请求，前一次读走的数据丢失），官网首页与 GitHub 首页因此载入失败。应用从含 `豫言操作系统/裸机/字模生成/字体/原始字体.ttf` 的仓库根目录启动，`--显示面后台` 让窗口留在后台；字体随应用包带上留待后续版本。

网络导航共用进程内小饼库，顶层访问与页面资源读取分别传入同站上下文和顶层安全导航标记。转向最终地址回传给页面基址与地址栏，后续样式、字体和图像按最终文档地址读取。

顶层响应按媒体类型显示：超文本标记进入文档解析，其他文本类型与结森显示字面文字并保留空白，图像生成独立图像页。文件地址按常用文本与图像后缀选择媒体类型；数据网址复用其媒体声明，网络地址复用响应内容类型。`about:blank` 生成空白页。展示文档保留原地址，子资源读取返回原始字节。

同站小饼上下文比较协议与可注册域名，公共后缀采用官方精确、通配、例外及私有域规则；四版和六版网络地址按完整主机比较。

预编辑文字拼接在当前选区，显示独立于提交值；密码控件遮蔽显示串，组字光标按预编辑位置绘制。焦点改变、提交和复原清理预编辑。组字下划线留待后续实施。

提交按钮按文档顺序收集具名成功控件，支持输入默认值、文本域、单选与复选状态、下拉选择、提交者字段及 `form` 显式归属。按钮可以覆盖动作、方法和编码类型。获取表单替换目标查询，提交表单复用正式网络客户端发送网址编码、纯文本或多段正文；换行按回车换行编码。提交导航共用会话小饼、证书验证、转向和响应展示通路。控件实时编辑、约束校验、文件选择、图像按钮坐标与目标窗口继续实施。

对话框：按 Esc 时最上层模态对话框先收 `cancel` 事件，没有被取消就关闭。模态对话框打开时，点在它外面的点击被忽略，不激活后面的内容；框内的点击照常。`<form method="dialog">` 提交先做约束校验，通过后关闭所在对话框，提交按钮的 `value` 成为 `returnValue`，不导航；提交者可以用 `formmethod=dialog` 覆盖方法。
