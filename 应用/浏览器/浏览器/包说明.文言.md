# 浏览器

最小壳复用网页载入、布局及绘制，资源之读受文件、数据网址及明文与安全网络之址。网络之请复用超文本传输之默认网址请求、证书核验、内容解压及会话小饼；显示及输入复用界面自绘之像素图控件。

窗供地址栏、回车访问、前往之钮、后退与前进之钮；页面显于 1024×720 素之画布。主键抬起，依显示之列命中，循祖先求链接；滚轮更视口之位，复用盒树重绘。导航之史存地址，返页则复载。

以豫构构建 `浏览器`，图形之运行环境供“主窗口”显示面及系统字体。惟一 `冒烟。测试` 入口用纯色数据页面及空字体来源，验画布之度、滚动之位、后退及前进。

后续施事：窗之尺寸联动、选区及复制、嵌套容器之滚、页面状态之史、异步载入、脚本及表单、导航之间小饼共用、转向最终地址之还。
