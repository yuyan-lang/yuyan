# 浏览器

上档点击同一文本控件则存旧锚，以所点之位为选区之末，继拖则续扩其范围。跨控件点击则立新锚。

文本控件指针按下取焦并定锚，移动改其选，抬起存其范围。控件之片复用滚动、裁剪及样式变换，依行宽比例定其位，收于字素之界；横向拖出则约于首尾。导航与窗口失焦清拖动态。沿定度综合冒烟核按下之位及拖动之范围；多行纵位、双击选词、上档点击、自动滚动及旋转之局部位，续为之。

控件复排以锚与标同步文字之选区，换焦清旧控件之饰。输入与文本域示选区背景、选中字色或一素宽插入符，绘制复用内容框之裁及既有滚动变换。沿综合冒烟以定度核选区显示片及插入符之形；逐字形之位、多行映射、闪烁、内滚动及组字之反馈，续为之。

文本选区存锚与标，上档合方向、起首或末尾则扩其界，常方向键收已有之选。复制、剪切、删除、粘贴及输入共此范围，替换之最大长依余文计。循字素或词移标亦可扩选。指针拖选、选区之绘及史存全选区，续为之。

焦点先依正值制表次序，同值循文档之序，继以默认与零值；负值可由指针或自动焦点得之。制表前行，上档合制表则反行，皆循环。钮、链及显式焦点元素与轮换，载入后自动取焦并重画其环；钮之回车与空格、链之回车复用提交、复原及导航。隐藏属性、隐藏输入与禁用控件依资格裁之；样式可见、惰性子树及阴影树之焦点代理，续为之。

文本控件移标与删文循统一码扩展字素之界，命令或控制合方向与删除键则循词界。合天键剪全选之文，合人键撤销，合地键重做；史依控件之身存文与标，复原与跨文档则清。输入依最大长约其插文，存全字素。撤销之分组、全选区及统一码十六位长规，续为之。

复原钮依表单之属复其默认值与选态，显式关联之外控亦与焉。单行输入回车取默认提交钮，依提交者之覆；无提交钮而惟一输入者可径提交。文本域回车入新行。隐式提交阻挡之输入类，细分留后。

页面控件可得焦而编辑：文字输入、方向键、首尾之移、退格、删除、命令／控制全选及复制粘贴接即时值，文本域受多行回车。点击标签及控件更复选、单选与下拉之态，制表键循文档之序易控件。复排存文档之身、字体集及既有计算样式，提交用即时值；跨文档导航清旧态。范围之选、光标及组字之绘、下拉浮窗、多选之交互、类型专用控件、约束之验及状态伪类复级联续施之。

最小壳复用网页载入、布局及绘制，资源之读受文件、数据网址及明文与安全网络之址。网络之请复用超文本传输之默认网址请求、证书核验、内容解压及会话小饼；显示及输入复用界面自绘之像素图控件。

窗供地址栏、回车访问、前往之钮、后退与前进之钮；页面显于 1024×720 素之画布。主键抬起，依显示之列命中，循祖先求链接；滚轮更视口之位，复用盒树重绘。导航之史存地址，跨文档而返则复载。

片段导航解百分号及统一码，先配元素标识，次配有名之锚；空片段及无目标之 `top` 滚至页首。初载可定位片段，同文档之访及片段之史复用节点、字体集及盒树，地址栏存全址。

主键拖动，可跨文字节点而选；片段之命中复用滚动、变换及裁剪之径，选区复用页面之选中字色及背景。选区既拖，则止链接导航。全选与复制之钮，及页面得焦时命令／控制加 A、C，皆可选文而置系统剪贴板；导航清旧选区，复制失则示诊而存所选之文。

以豫构构建 `浏览器`，图形之运行环境供“主窗口”显示面、系统字体及剪贴板接口。惟一 `冒烟。测试` 入口验画布之度与像素、滚动之位、后退及前进，以固定文字之度验字符命中、反向跨节点之选、全选及清理。

网络导航共用进程之小饼库，顶层访问及页面资源之读取，各传同站之境与顶层安全导航之记。转向最终之址还于页面基址及地址栏，后续样式、字体与图像循最终文档之址而读。

顶层之应依媒体之类而显：超文本标记入文档之析，余文字类与结森依字面显文而存空白，图像生成独立图像之页。文件之址依常用文字及图像后缀择媒体类；数据网址用其媒体之声明，网络之址用响应内容之类。`about:blank` 生空白页。展示之文存原址，子资源之读还原始字节。

同站小饼之境较协议及可注册域名，公共后缀用官方精确、通配、例外及私有域诸则；四版、六版网络地址较全主机。

提交之钮循文档之序收有名且成之控件，受输入默认值、文本域、单复选之态、下拉之选、提交者之字段及 `form` 明定之属。钮可覆动作、方法及编码类。获取表单易目标之查询，提交表单复用正式网络客户，以网址编码、纯文或多段正文而送；换行依回车换行编码。提交导航共用会话小饼、证书核验、转向及响应展示之路。控件即时编辑、约束之验、文件之选、图像钮之位、目标窗口及对话框提交续施之。
