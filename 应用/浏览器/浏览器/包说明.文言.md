# 浏览器

单选取末一已选之项，展开之列得存空选；首个直子空项循占位之则而校必填，禁用已选者参与有值之判，提交则除之。祖先自动之向取其后裔之辞。网络未明媒体之类与本地无缀之文件，验署而辨常见图像。片段文本之令存锚点之退路，纯令守现有滚动，解锚保首个字节序标之字。

文本输入及文本域之 `dirname` 附文字之向；明定者承祖先，自动者取首强向之字。隐字段 `_charset_` 提交八位统一码之名，候选列表之后裔免于提交及校验。片段导航循锚点之祖，从内而外滚诸容器，皆守其界。

同站之判正域名、国际主机及网络地址，空与非法之主机皆拒；尾点之域循公共后缀而较之。文件网址受本地主机，文件页乃得读文件之资，安全网页之子资守安全传输之则。

载入败则页面之区示「无法载入 址」与「原因：…」：读取器以顶层址之异文记于 `浏览器载入错误`，无异而不得页则依网址之形补书其由（网址不可解、方案不支、资不在或不可解码），页容不可解码则记同名之由；每载入前清之，无败由则页面之区示入之提示。网络请之诊仍印于标准出。冒烟之测核败之记与方案之示。

非空之输入验数字之法、上下限及步长、邮箱基本之制、完整网址及模式之全串匹配。数步默认一，受 `any`；基先取合法之 `min`，次取 `value`，终取零，容浮点之微差。文长施于文字输入及文本域，模式施于文字输入；只读免验各循其类。模式用脚本正则之统一码集合式，语法有误则略其约。日期控件及邮箱全法续施之。

表单提交之前验必填及文长之约，点击与回车共其验。失则显其说而聚焦首个无效之控件，表单及提交者之免验属性可用。

字段集有禁，其首直接图例之裔仍可用；层相嵌者，续核外层字段集。选项组有禁，其选项屏于成功控件之外。

多选控件逐项显勾选之态及活动之项。点击其行或按空格则易其选，上下键移活动项，上档方向键选所经之区，控制或命令加全选键选可用之项；提交存同名之多值。禁用项之切换、全选及范围之选循禁用之验。范围之回缩、禁用项焦点之跳及列表之精饰续施之。

输入及文本域编辑之时自显插入符，横向超宽之文与纵向超高之内容随标而移；点击、拖选及候选之区共用已移之行片。手滚及拖至边之自滚续施之。

文本域依行而显，点击及拖选依纵位择文行，候选之区依控件或组字之标择其行；上下键持今横位而移邻行，上档键续扩其选。精细字形定位、连纵移之横向目标记忆及控件内滚动续施之。

候选窗之区取焦点控件可见之文片，随控件之标或组字之标；页面画布以原样输入区域报显示控件，候选窗之示兼画布于窗内之偏位。逐字形、多行及真实输入法窗之验续施之。

组字之更存预编辑之文及其标，提交之文仍以文字输入入控件。组字间页面编辑键及回车付输入法；易焦、窗口失焦及提交清预编辑之态。预编辑之显与候选之区已接；逐字形、多行及真实窗之验续施之。

上档点击同一文本控件则存旧锚，以所点之位为选区之末，继拖则续扩其范围。跨控件点击则立新锚。

文本控件指针按下取焦并定锚，移动改其选，抬起存其范围。控件之片复用滚动、裁剪及样式变换，依行宽比例定其位，收于字素之界；横向拖出则约于首尾。导航与窗口失焦清拖动态。沿定度综合冒烟核按下之位及拖动之范围；多行纵位、双击选词、上档点击、自动滚动及旋转之局部位，续为之。

控件复排以锚与标同步文字之选区，换焦清旧控件之饰。输入与文本域示选区背景、选中字色或一素宽插入符，绘制复用内容框之裁及既有滚动变换。沿综合冒烟以定度核选区显示片及插入符之形；逐字形之位、多行映射、闪烁、内滚动及组字之反馈，续为之。

文本选区存锚与标，上档合方向、起首或末尾则扩其界，常方向键收已有之选。复制、剪切、删除、粘贴及输入共此范围，替换之最大长依余文计。循字素或词移标亦可扩选。指针拖选、选区之绘及史存全选区，续为之。

焦点先依正值制表次序，同值循文档之序，继以默认与零值；负值可由指针或自动焦点得之。制表前行，上档合制表则反行，皆循环。钮、链及显式焦点元素与轮换，载入后自动取焦并重画其环；钮之回车与空格、链之回车复用提交、复原及导航。隐藏属性、隐藏输入与禁用控件依资格裁之；样式可见、惰性子树及阴影树之焦点代理，续为之。

文本控件移标与删文循统一码扩展字素之界，命令或控制合方向与删除键则循词界。合天键剪全选之文，合人键撤销，合地键重做；史依控件之身存文与标，复原与跨文档则清。输入依最大长约其插文，存全字素。撤销之分组、全选区及统一码十六位长规，续为之。

复原钮依表单之属复其默认值与选态，显式关联之外控亦与焉。单行输入回车取默认提交钮，依提交者之覆；无提交钮而惟一输入者可径提交。文本域回车入新行。隐式提交阻挡之输入类，细分留后。

页面控件可得焦而编辑：文字输入、方向键、首尾之移、退格、删除、命令／控制全选及复制粘贴接即时值，文本域受多行回车。点击标签及控件更复选、单选与下拉之态，制表键循文档之序易控件。复排存文档之身、字体集及既有计算样式，提交用即时值；跨文档导航清旧态。范围之选、光标及组字之绘、下拉浮窗、多选之交互、类型专用控件、约束之验及状态伪类复级联续施之。

最小壳复用网页载入、布局及绘制，资源之读受文件、数据网址及明文与安全网络之址。网络之请复用超文本传输之默认网址请求、证书核验、内容解压及会话小饼；显示及输入复用界面自绘之像素图控件。载时以「载入网页」行页中之常脚本，乃依脚本所改之文档渲染，每脚本（及事件之听、定时器之回调）至多五千万步。页面定时器（setTimeout、setInterval、requestAnimationFrame）于计时之更新依页面之时钟行之，计时之间取至次一定时器之期；回调改文档则重排一次。点页时先派冒泡可取消之 click 事于所中之节，页面脚本之听取消则不行默认之动（循链接、提交、激控件），听改文档则重排。按键亦先派 keydown、keyup 于焦点之控件（无则 body），带 key、keyCode 与修饰键之项，听取消则不滚、不编。表单之控件得失焦点则派 focus、blur（值较得焦点时有易，则先派 change），输入或删改文字后派 input，勾选框、单选框与下拉框既易则派 input 与 change。页中之模块脚本（type="module"，内嵌与外部，可自相对之址导入）于常脚本之后行之。按、抬鼠标左键则先派 mousedown、mouseup 于指下之节（带 clientX、clientY、button）；指移而指下之节易，先派 mouseout、mouseover，乃派 mousemove。页面脚本所记导航（location.href、assign、replace、reload）、改址（pushState、replaceState）、行史（back、forward、go）与滚（scrollTo、scrollBy）之请，浏览器于处消息与计时之更新后行之，新页载时复记者（脚本之重定向）续行之，至多十轮；pushState 新增史之条则推旧址入后退之史。窗尺书入页之 innerWidth、innerHeight，重排后派 resize。mouseenter、mouseleave、popstate、hashchange，留待后版。

窗供地址栏、回车访问、前往之钮、后退与前进之钮；地址栏一行定高四十素，校验之说亦排于此行，其下全块为页区。页之视口随窗之大小（`页面视口`）：视记窗尺，页图之尺异之则计时之更新依新尺重排，滚位夹回可滚之围；命中及收文片依页图之视口之矩。主键抬起，依显示之列命中，循祖先求链接；滚轮更视口之位，复用盒树重绘。页得焦而无控件之焦（或焦在链）时，上下左右之键每滚四十素，上翻页、下翻页与空格每滚页区之高减四十（上档加空格则上），起首末尾滚至两端。导航之史存地址，跨文档而返则复载。

片段导航解百分号及统一码，先配元素标识，次配有名之锚；空片段及无目标之 `top` 滚至页首。初载可定位片段，同文档之访及片段之史复用节点、字体集及盒树，地址栏存全址。

主键拖动，可跨文字节点而选；片段之命中复用滚动、变换及裁剪之径，选区复用页面之选中字色及背景。选区既拖，则止链接导航。全选与复制之钮，及页面得焦时命令／控制加 A、C，皆可选文而置系统剪贴板；导航清旧选区，复制失则示诊而存所选之文。

以豫构构建 `浏览器`，图形之运行环境供“主窗口”显示面、系统字体及剪贴板接口。惟一 `冒烟。测试` 入口验画布之度与像素、滚动之位、后退及前进、依窗尺重排及翻页之量，以固定文字之度验字符命中、反向跨节点之选、全选及清理。

网络导航共用进程之小饼库，顶层访问及页面资源之读取，各传同站之境与顶层安全导航之记。转向最终之址还于页面基址及地址栏，后续样式、字体与图像循最终文档之址而读。

顶层之应依媒体之类而显：超文本标记入文档之析，余文字类与结森依字面显文而存空白，图像生成独立图像之页。文件之址依常用文字及图像后缀择媒体类；数据网址用其媒体之声明，网络之址用响应内容之类。`about:blank` 生空白页。展示之文存原址，子资源之读还原始字节。

同站小饼之境较协议及可注册域名，公共后缀用官方精确、通配、例外及私有域诸则；四版、六版网络地址较全主机。

提交之钮循文档之序收有名且成之控件，受输入默认值、文本域、单复选之态、下拉之选、提交者之字段及 `form` 明定之属。钮可覆动作、方法及编码类。获取表单易目标之查询，提交表单复用正式网络客户，以网址编码、纯文或多段正文而送；换行依回车换行编码。提交导航共用会话小饼、证书核验、转向及响应展示之路。控件即时编辑、约束之验、文件之选、图像钮之位、目标窗口及对话框提交续施之。

预编辑之文接于今选之区，所显独于提交之值；密码控件蔽所显之串，组字之标依预编辑之位而绘。焦点之变、提交及复原清预编辑。组字下线留待后施。

页面之区依显示面之素比而显：运行之循以素比予视，`高清页面` 先铺白底（网页画布无背景则透明），乃以整数倍复一倍页图之素而放之，依版号与素比而存；页面之区原样之入，坐标除以倍数复为 CSS 之素。滚轮唯改滚位而记待重画，主循交尽列候之入，乃由计时之更新并为一次重画；重画复用同页之文路读器与图读器（`重绘读取器`）。唯纵滚整数之素，则移旧画而唯画所露之条（`滚动重绘网页盒页面`），点按之时依全幅补显示列表而后命中（`浏览器命中显示列表`）。欢迎之页列豫言官网与 example.com 二链。

macOS 之应用：`构建 浏览器 --输出 yy浏览器臂。豫行 -- --目标 本机 --目标系统 豫言 --目标架构 臂六十四 --执行器 <绝对路径>/yy执行器新。树码` 编与豫言操作系统同一之豫行，乃以 macOS 豫行启动器 `--合成` 为单文，置于应用包之 `Contents/MacOS/`，桌面之字随包置于 `Contents/Resources/豫言操作系统/裸机/字模生成/字体/原始字体.ttf`（启动器于今目录不得字，则移至 `../Resources`，自访达双击亦可启），乃本机签之（提案 00021）。执行器与启动器取诸与浏览器同一之源（提交 4bacc9761 之后）：以稳定编译器 `构建 客体二号 --输出 yy执行器新。树码` 得执行器，乃以之建新豫构（`构建 豫构 --输出 yy豫构新.exe -- --目标 本机 --执行器 …`），由新豫构建启动器（`构建 豫言裸机 豫行启动器 --输出 yy豫行启动器苹果臂 -- --目标 本机 --目标系统 苹果 --目标架构 臂六十四 --执行器 …`）与浏览器。稳定工具链包中之旧执行器，读 HTTPS 之应逾四千字则失其数（整块代办不容则重发读请，前读之数遂失），官网首页与 GitHub 首页因之载入败。应用自含 `豫言操作系统/裸机/字模生成/字体/原始字体.ttf` 之仓根而启，`--显示面后台` 使窗留于后台；字体随应用包，续于后版。
