# 复制回收宿主之构建

Wasmtime 48.0.1 官方 C 接口之常本含 DRC，未含 `gc-copying`。今取同版之源码，启复制回收，初堆定为一百二十八 MiB。所改见 `复制回收器.patch`，不改回收之法；已有同版头文，则复用而免重装。

源码置 `yy_wasmtime_gc_source`，Rust 1.98.1 置 `yy_rust`，Cargo 缓存置 `yy_cargo`。此皆构建之具，非豫言编译器之术；下载与构建之时不入自举之计。

构建命令与参数详见同目录《复制回收构建.汉语.md》。Cargo 采用 release，启用 `wat,wasi,parallel-compilation,gc,gc-copying,cranelift`，而不用默认特性。既成，行 `make 网页汇编复制宿主 网页汇编宿主编译器=./yy3_bs`。

复制本别名 `yy网页汇编复制宿主`；其预编译产物不得与 DRC 本混用。二者之系统接口桥同。昔日以 `YY_WASM_GC_RESERVE_MB` 试 DRC 之容量；正式复制回收之测不设此项，直用引擎初堆。

另设 `YY_WASM_GC_INLINE=1`，则引擎启 `Inlining::Yes`；未设，则仍 `Inlining::No`。预编译与执行须同其设，子进程亦承之。此改引擎生机码之法，不改编译器源码与输入 Wasm。

须以 `wasm_engine_new_with_config(wasm_config_new())` 造引擎。若径用 `wasm_engine_new()`，则旁取默认而弃所设。设 `YY_WASM_GC_CONFIG_LOG=1`，可验已成引擎之初堆与内联；一百二十八 MiB 应示 `heap_initial=134217728 bytes`。前测误标初堆者，今皆正为默认堆，不与后测混称。

异常直调之本，Wasm 栈限六十四 MiB，异步栈额一百二十八 MiB；宿主别起一百二十八 MiB 栈之线程，主线程候之，不并行用豫言堆。初始回收堆仍一百二十八 MiB。

又须施《批量字节桥接.patch》，整段转字节，毋逐字立根。复制宿主以 `YY_WASM_GC_BULK` 编之，常宿主仍循旧法。设 `YY_WASM_GC_HEAP_MB` 可定初堆，限六十四至二千四十八 MiB，默认一百二十八；今另验五百一十二。复制之堆分两半，诸进程各有其堆。堆额有变，须重作相应 AOT，运行亦用同额。
