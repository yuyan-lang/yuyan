# 网页汇编编译宿主

器以豫言为入口，以 C 约接 Wasmtime，授 P1 模块以 `yuyan:build-host/v1.call`。此为编译宿主之扩展，非 P3 标准接口，亦非 WIT 绑定。

此器授进程、环境与当前目录读写，惟载可信构建程序。参数逐项传之，不合为 shell 文。备 Wasmtime 48.0.1 C API 于 `yy_wasmtime_c_api`，以 `make 网页汇编宿主` 构之。编客时设 `YY_WASM_HOST_BRIDGE=1`，后以 `yy网页汇编宿主` 载之；命令详见《说明.汉语.md》。预编译物惟以显式参数载入，必取可信之物。

界上传五整数，返一整数；地址皆客内偏移。字串以小端长度与 UTF-8 字节传之。进程句柄各归其客，单调编号，最多四千零九十六项。输出各限二百五十六 MiB，以已除名临时文件收之，免管道壅塞；非实时流输出之器。每毫秒候进程完成，多路等待惟候本宿主子进程，不兼网络与客文件描述符。

客终，收其直属未毕子进程。包上下文沿用原生真锁，不空废之。客器再召 Wasm worker，复由本器载之；clang 等原生器径行。授客同名绝对目录，使编译路径与宿主合。

编译桥接之栈五百一十二 MiB，初堆六十四 MiB，单堆上限五百一十二 MiB，线性内存限四 GiB；普通 WASI 守旧限。AOT 宜由本器预编译，异配置之物未必可载。本次唯验 macOS arm64。

豫构之原生清单不合 Wasm。编本仓库编译器，其构建基础已由桥接供之，可显式以空清单覆之，详见汉语本。不得据此弃他包之原生依赖；其未实现者仍当链败。自举之验与所阻，见《验证.文言.md》。
