# 标准内存指令执行

存储模块现在可以从标准 `.wasm` 加载并执行三十二位整数内存访问：四字节读取／写入、八位与十六位有符号／无符号读取、八位与十六位写入，以及 `memory.size` 和 `memory.grow`。验证器检查栈效果、偏移范围、自然对齐上限和内存索引；没有内存声明的模块不能借此绕过验证。

每个函数实例携带所属模块的内存操作上下文。普通函数调用沿用当前上下文，跨模块导入调用进入提供者的上下文，返回后仍使用调用者的上下文。内存在多次导出调用间保留，独立装配的实例不会共享内容。此内部上下文不改变标准 Wasm 函数签名。

原生版和 Wasm 版豫言执行器均通过持久读写、未对齐访问、窄读写和符号扩展、增长与零初始化、增长失败、越界陷阱、跨模块读取及实例隔离测试。缺失内存、非法对齐和错误索引在验证阶段拒绝。同一生成模块在 V8 运行对应操作，结果一致；既有整数核心和模块装配回归通过。

命令行的“执行”和“装配执行”已接入存储加载器。每个内存默认限额二百五十六页，即十六 MiB 的客体可见容量，实际宿主引用数组开销更大；函数与指令执行预算保持十万次。命令不自动授予系统宿主导入。

```sh
./yy3_bs 库/编译器核心/网页汇编核心/内存指令。测试。豫 -o yy内存指令测试 -j 1
./yy内存指令测试
./yy中文网页汇编 执行 yy内存指令.wasm 大小
./yy中文网页汇编 执行 yy内存指令.wasm 增 1
```

两条独立执行命令均输出一；每次命令会建立新实例。库内测试覆盖同一实例多次调用后的持久状态。

裸机后端尚未接入内存访问，中文存储模块文本、内存导入／导出、批量内存指令的执行接入及完整 WasmGC 也未完成。这一进展不表示默认 Shell 已经实现。

批量初始化、丢弃、复制和填充也已接入参考执行，详[批量内存](批量内存.汉语.md)。
