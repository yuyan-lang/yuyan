# 三十二位除余

中文中间式、标准字节编解、栈验、参考执行及双架构降级，今具有符号除、无符号除、有符号余、无符号余，标准码自 `0x6d` 至 `0x70`。中文仍冠“整数三十二位”。

有符号商趋零，余非零则从被除数之号。四令除数为零皆陷。有符号最小数除负一溢出，取余则合法而得零。参考执行先以绝对值求商，后复其号；机器后端先验除零，以六十四位求有符号商，再验三十二位可容，故不误陷合法余数。

二〇二六年九月二十二日，四十七正常例及五陷阱例，经原生参考执行、同源码网页目标与 V8 皆过。正例含诸符号组合、无符号高位及大小两端，亦经中文与字节往返。诸型合，双架构机器令经反汇编核验。

裸机各增正常积核、误期望、四类除零及有符号除溢出，九十八项模拟器之验皆过。原生与网页生成器所成双架构镜像逐字同，亦同于所验者。诸复验命令详汉语篇。
