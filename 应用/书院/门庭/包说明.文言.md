# 官网

通称官网，谓 `yuyan-lang.org`（主站）与 `docs.yuyan-lang.org`（docs 站）共用之页面。云仓提案 C00005《静态站与动态站分离》方行：一源之页，构时出二形——主站之页由浏览器中之豫言系统排而绘之，docs 之页乃构时所书之 HTML 与 CSS。

此 `应用/书院/门庭/` 之父包也，唯有包述与此说，无模。登网站资料生成、网站产物守卫、共用界面应用、首页应用、产品应用、问答应用、技术文档应用与编简；增其程者，必登于此包之「包含包」，新包书「包含在」。

## 目录

| 径 | 内容 |
| --- | --- |
| `内容/` | 网站之内容：页稿 `*.汉语.md` 与 `*.文言.md`、`资料/`、`共用/`、`资源/`、`产品/`、`性能/`、`条款/`、`响应头`、`转址` |
| `生成/` | 包「网站资料生成」：读页稿与语言仓之学篇、指南、技术之文，书 `dist/网站` |
| `守卫/` | 包「网站产物守卫」：核问答之数据、静文之正文、站内之链与技术之文之检索 |
| `共用界面/` | 包「共用界面应用」：全站之导航、址栏、页脚与两辞；并其 `静态渲染。脚本。豫` |
| `首页/`、`产品/`、`问答/`、`技术文档/` | 包「首页应用」「产品应用」「问答应用」「技术文档应用」：四应用及其静绘之脚本 |
| `编简/` | 包「编简」：取页稿读为匠心之文档，写整站为文档站而行其守 |

`内容/` 为网站之内容，包之发现惟取本目下之包目。页稿之名、`资料/` 中之 `问答.json` 与 `技术文档.yml`、Cloudflare 之 `响应头` 与 `转址` 皆以中文名之；网站资料生成书 `响应头`、`转址` 为产物中之 `_headers`、`_redirects`（Cloudflare 所须之名），书产品之目为产物中之 `products/`（今主站之网址）。网址皆直书中文，不作百分号之编码。

## 二产

- `dist/网站`：主站与 docs 站共用之页，仓库目标「官网」书之。
- `dist/文档站`：docs 站之 HTML 与 CSS，仓库目标「文档站」于 `dist/网站` 上依共用界面、首页、技术文档三静绘之脚本书之，不带本与网汇之文。

## 后续之版

- `资料/` 之 JSON 与 YAML 改为数据子语言 `名。数据。豫`（提案 00028）。
- 产品之页于 docs 站静绘，网址自 `/products/` 改为 `/产品/`（阶段二）。
