# 官网

通称官网，谓 `yuyan-lang.org`（主站）与 `docs.yuyan-lang.org`（docs 站）共用之页面。云仓提案 C00005《静态站与动态站分离》方行：一源之页，构时出二形——主站之页由浏览器中之豫言系统排而绘之，docs 之页乃构时所书之 HTML 与 CSS。

此 `应用/书院/门庭/` 之父包也，唯有包述与此说，无模。登网站资料生成、网站产物守卫、共用界面应用、首页应用、产品应用、问答应用、技术文档应用、编简、附表、提要、页录与问答页；增其程者，必登于此包之「包含包」，新包书「包含在」。

## 目录

| 径 | 内容 |
| --- | --- |
| `内容/` | 网站之内容：页稿 `*.汉语.md` 与 `*.文言.md`、`资料/`、`共用/`、`资源/`、`产品/`、`性能/`、`条款/`、`响应头`、`转址` |
| `生成/` | 包「网站资料生成」：读页稿与语言仓之学篇、指南、技术之文，书 `dist/网站` |
| `守卫/` | 包「网站产物守卫」：核问答之数据、静文之正文、站内之链与技术之文之检索 |
| `共用界面/` | 包「共用界面应用」：全站之导航、址栏、页脚与两辞；并其 `静态渲染。脚本。豫` 与收尾之 `静态收尾。脚本。豫` |
| `首页/`、`产品/`、`问答/`、`技术文档/` | 包「首页应用」「产品应用」「问答应用」「技术文档应用」：四应用及其静绘之脚本 |
| `编简/` | 包「编简」：取页稿读为匠心之文档，写整站为文档站而行其守 |
| `附表/` | 包「附表」：以页稿之附表记，易为所指数文之表段，使译名之页其表惟《翻译列表》一源 |
| `提要/` | 包「提要」：一页之一句提要取于其源文（题记之 `description` 或源文首行之提要记），供网站资料生成与编简共用 |
| `页录/` | 包「页录」：页面之集、题、址、对页与正文之源一处所登，官网与编简共读 |
| `问答页/` | 包「问答页」：“十万个为什么”之正文生成，官网与编简共一器，依语出可见之文 |

页稿可书一行 `<!-- 附表：径 -->`，径对仓根；网站资料生成与编简读页之时，以其所指数文之表段易之（自首行以 `### ` 起者至末尾）。译名之页，其翻译列表即取于语言仓之《翻译列表》，改名与增删惟改此一份。

页稿与规范之篇，其提要书于源文：介绍之页书题记之 `description:`，规范之篇书源文一行 `<!-- 提要：… -->`。网站资料生成与编简皆取此一份，页目与技术文档之目不复另抄。

`内容/` 为网站之内容，包之发现惟取本目下之包目。页稿之名、`资料/` 中之 `问答.json` 与 `页录。数据。豫`、Cloudflare 之 `响应头` 与 `转址` 皆以中文名之；网站资料生成书 `响应头`、`转址` 为产物中之 `_headers`、`_redirects`（Cloudflare 所须之名）。网址皆用中文目录式之净址，不作百分号之编码：页为 `<径>/index.html`，汉语页在 `/教程/启机第一/` 之属，文言页皆冠 `/文言/`（`/文言/教程/启机第一/`）；无文言稿之页由生成之程序补一份 `/文言/<径>/`。产品之页址为 `/产品/`。

## 二产

- `dist/网站`：主站与 docs 站共用之页，仓库目标「官网」书之。
- `dist/文档站`：docs 站之 HTML 与 CSS，仓库目标「文档站」于 `dist/网站` 上依共用界面、首页、技术文档、产品四静绘之脚本书之（编页应用时门庭之目亦为包根，页应用可依页录等门庭之子包），复由 `静态收尾。脚本。豫` 为每页之首挂横幅、清其除横幅一条以外凡去主站之链，并核其产，不带本与网汇之文。

docs 站之规曰“去主站之途惟此一条”：每页顶上之横幅明此为豫言之静站、请移步动站以得更佳之境，横幅之链指主站同页；此外站头、导航、页脚、诸篇总目与正文皆不留指主站之链（指主站动径之条去之，正文之句惟存其字）。此规由 `静态收尾。脚本。豫` 行之，并为「文档站」鹄末之核：不合则令鹄败。

## 社区包之页

docs 站别有社区包之页：社区包之库之 CI 于行「文档站」之先设水土 `豫言社区包目录`（社区仓 `包/` 之绝径，在语言仓之树外）与 `豫言社区包提交`，网站资料生成依之书稿根 `/包/`、`/包/<主>/`、`/包/<主>/<包名>/` 三级之页，各出汉语与文言二份（文言之页在 `/文言/包/…`）。包之述与名帖由是器以籍册（数据之库）读之，包说明中之相对之链改指社区库同处之 GitHub 源码；`/全部页面/` 与 `sitemap.xml` 随而录之。

`静态收尾。脚本。豫` 有包页者，改站头与站导中「包管理」之 `/packages/` 为站内之链（文言之页指 `/文言/包/`），并以旧 `/packages/` 之址 301 于 `/包/`（诸级用 `:splat`）。又重排 docs 站之 `_redirects`：去 200 改书之规（Pages 自为目录取 `index.html`、为无斜之目录补斜），无 `*` 亦无 `:名` 之静规居前、有 `*` 或有 `:名` 之动规移于最末；核时动规不逾百条、静规不逾二千条。主站之 `dist/网站/_redirects` 不动，Worker 须彼 200 之规。
