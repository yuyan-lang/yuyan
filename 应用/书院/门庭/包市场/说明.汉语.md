# 豫言包市场页

`入口。豫` 是主站包管理的列表页，原样搬自云仓的 `应用/包管理服务/市场应用/`：读 `/api/releases?catalog=1&offset=…`，以豫言在浏览器里画包卡片、搜索、分页、断网重试与语言切换，界面文字走 `data-han`、`data-wen`。卡片链到 `/packages/<所有者>/<包名>/`；每张卡带 `data-kind`（lib、exe、test，规则同包引擎的「包类别」：名字以“测试”“验证”结尾为测试，可执行文件为可执行程序，其余为库）。

`静态渲染。脚本。豫` 在构建时把同一份应用放进网页沙盘跑一遍，写出 docs 站的包列表页：读环境变量 `豫言社区包目录` 指向的社区包仓库（`<所有者>/<包目录>/`），按每个包的包描述算出 `/api/releases` 的答复（结绳，字段与包服务同形），登记成 `GET /api/releases?catalog=1&offset=0&q=` 的回应，让应用把全部卡片画出来（不必输入查询词），再把整页写回。写出的是 `/包/`、`/包/<所有者>/` 的汉语页与 `/文言/包/…` 的文言页；卡片链改指 `/包/<所有者>/<包名>/`（文言页指 `/文言/包/…`），卡片补上 `data-搜寻`（所有者、名称与简介，供搜索比对），删去“加载更多”按钮，挂上 `/资源/包市场.css` 与 `/资源/包搜索.js`。没设 `豫言社区包目录` 时一页不写，印一行跳过。

`市场页。豫` 把包列表页的正文与整页收成一份声明：`市场内容文` 给出汉语或文言正文，`市场页文` 在正文外补上文档头与收尾、成独立整页。静态渲染用它重写 docs 站的包列表页，模拟验收用它载入同样的页面跑真实应用，两处共用这一份结构。

`模拟验收。脚本。豫` 在模拟宿主上运行真实包市场应用，覆盖搜索与分页、三种筛选、包名与简介按文字显示、服务故障重试、认证字段缺失、断网保留搜索并重试、文言详情链接与历史恢复，共 35 项断言。在仓库根这样运行：

```sh
豫构 发行 模拟 应用/书院/门庭/包市场 输出目录 --包根 库 --包根 应用/书院/门庭 --入口 模拟验收。脚本。豫
node 豫言操作系统/宿主/节点/宿主.cjs 输出目录/程序.wasm
```

`内容/资源/包搜索.js` 是 docs 站唯一的一段脚本，手写原生 JavaScript，不经编译器、不联网：按搜索框的字比对卡片的 `data-搜寻`，三个勾选框按 `data-kind` 过滤，状态行照主站的说法报已展示几个包，没有结果时显示主站同样的提示。`内容/资源/包市场.css` 照主站包市场的样式取包市一处，使两站同貌。

docs 站本来一律不带脚本，包列表页是唯一的例外；其余页面照旧不带脚本、不带网页汇编文件。由仓库目标「文档站」在共用界面、首页、技术文档、产品四个静态渲染之后、收尾之前编译运行（`豫构 发行 模拟 应用/书院/门庭/包市场 输出目录 --入口 静态渲染。脚本。豫`）。
