# 豫言包市场页

`入口。豫` 为主站包府之列页，自云仓 `应用/包管理服务/市场应用/` 原样迁入：读 `/api/releases?catalog=1&offset=…`，以豫言于客器画卡、寻名、续页、断网复求与辞易，界面之文走 `data-han`、`data-wen`。卡链 `/packages/<主>/<名>/`；每卡带 `data-kind`（lib、exe、test，同包引擎之「包类别」：名以“测试”“验证”终者为试，可执行文件为器，余为库）。

`静态渲染。脚本。豫` 于构时以同一应用入沙盘行一遍，书 docs 之包列页：读水土 `豫言社区包目录` 所指之社区包库（`<主>/<包目>/`），依各包之述算 `/api/releases` 之答（结绳，栏与包府同形），登为 `GET /api/releases?catalog=1&offset=0&q=` 之应，令应用尽绘其卡（不待输入），乃复书全页。所书为 `/包/`、`/包/<主>/` 之汉语页与 `/文言/包/…` 之文页；卡链改指 `/包/<主>/<名>/`（文页指 `/文言/包/…`），卡补 `data-搜寻`（主、名与简介，供搜寻相较），去“续观”之钮，挂 `/资源/包市场.css` 与 `/资源/包搜索.js`。不设 `豫言社区包目录` 则一页不书，印一行而略之。

`市场页。豫` 以包列页之正文与全页收为一份之声明：`市场内容文` 出汉语或文言正文，`市场页文` 于正文外补档首与收尾、成独立之整页。静绘取以重书 docs 之包列页，模拟之验取以载同页而行真应用，二处共用此一份之结构。

`模拟验收。脚本。豫` 于模拟宿主行真包市应用，核寻与续页、三择、包名与简介依文而示、服务之故复求、认证之缺、断网存寻而复求、文详之链与史复，凡三十五断。于仓根如是行之：

```sh
豫构 发行 模拟 应用/书院/门庭/包市场 输出目录 --包根 库 --包根 应用/书院/门庭 --入口 模拟验收。脚本。豫
node 豫言操作系统/宿主/节点/宿主.cjs 输出目录/程序.wasm
```

`内容/资源/包搜索.js` 为 docs 站惟一之脚本，手写原生 JavaScript，不经编译器、不联网络：依寻框之字较卡之 `data-搜寻`，三勾框依 `data-kind` 而择，状行依主站之说报已陈几包，无得则示主站同款之提示。`内容/资源/包市场.css` 依主站包市之式取其一隅，使两站同貌。

docs 站本一律不带脚本，包列页乃其独异；余页如故，不带脚本、不带网页汇编之文。由仓库鹄「文档站」于共界、首页、技术之文、产品四静绘之后、收尾之先编而行之（豫构 发行 模拟 应用/书院/门庭/包市场 输出目录 --入口 静态渲染。脚本。豫）。
