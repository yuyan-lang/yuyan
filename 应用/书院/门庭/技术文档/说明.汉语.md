# 豫言技术文档检索

技术正文由静态页面直接提供。浏览器中的豫言程序生成页内目录，在首次检索时读取静态搜索索引，按章节、语言和关键词显示结果。

`模拟验收。脚本。豫` 使用正式生成的静态页面与搜索索引运行双语验收，覆盖页内目录、多词检索、全词大小写、空态、键盘与按钮关闭、索引缓存以及新规范检索和语言隔离。`技术文档应用构建` 通过 `模拟验收步们` 构建并运行，实际验收 50 项断言通过。

`静态渲染。脚本。豫` 在构建时给 docs 静态站 `dist/文档站` 里带页内目录的网页补上目录：每页载进网页沙盘，跑一遍真实的技术文档应用，再写回原文件。在共用界面静态渲染之后运行，由仓库目标「文档站」编译运行。
