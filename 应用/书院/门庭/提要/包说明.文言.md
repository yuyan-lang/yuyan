# 提要

一页之一句提要，取于其源文。介绍之页书于题记之 `description`，规范之篇书于源文首行之摘要记，网站资料生成与编简皆取此一份。

提要（page summary）合页之简介与其源文为一：读一页之提要，即读其源文——有页首题记者，取题记之 `description`；无题记者，取源文一行 `<!-- 提要：… -->`。提要改则源文改，所出之页随之而变，不必复抄一份。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，所依为标准库与章程（解析前言）。

## 用法

```yuyan
寻观「提要」之书。

「页之提要」于『应用/书院/门庭/内容/译名.汉语.md』
```

径对仓根，调者在仓根行。默认导入（`提要` 模块）所供：

- `「页之提要」`：读仓根下一页之源文，取其提要。
- `「文之提要」`：以一份源文之全篇取提要，供已读入内存者。
- `「前言述」`：源文题记之 `description`，无题记或无此栏则空串。
- `「标记提要」`：源文首条提要记中之一段，包于「可有」；无记者得「可无」。
- `「提要标首」`、`「提要标尾」`：提要记之首尾，书为 `<!-- 提要：` 与 ` -->`。

## 提要之源

二处择一，先题记次标记：

1. 题记之 `description:`，介绍之页之书法，与站点页面之 description 同源；
2. 源文一行 `<!-- 提要：… -->`，规范之篇之书法，标记于渲染不可见。

## 报错

二种告祸，免提要默然而空：

- 提要记无其尾 ` -->`；
- 二处皆无提要。

## 调用处

页稿皆在 `应用/书院/门庭/内容/`，规范在 `应用/豫言编译器/文档/语言技术规范/`。网站资料生成书技术之文时取提要，入页前言之 `description`，总览之卡亦取于此；编简出站时逐页取提要，为其页网页之 description。二处之书法见各自之包说明。
