# 速查之页

速查之页，官网与 docs 站共用之“速查”正文也：读 `应用/书院/门庭/内容/资料/速查。数据。豫`，依分部而出 `/速查/` 与 `/文言/速查/` 二页之分部表。

## 数据

`速查。数据。豫` 每条记六事：部、名、式（语法之形）、例（一小段能过验类之豫言）、释（汉文各一句）、出（语言技术规范之篇与节）。读之借“籍册”（数据文件）之“数据表诸行”，依签而取文；出者生指 `/文档/<篇>/` 之站内链。

## 生成

公函“速查正文”受条目之列与语（可阙，阙则双语），还整页正文之网文片段：卷首、分部之目、各部之表（式、例、释三栏）与注。例依站上码块之式而着色：包以 `<pre data-yuyan-highlight>`，官网以页本着色，docs 站以共界静绘于构时着色。释与栏名皆带 data-han、data-wen 二栏，官网随界语而易；docs 站依页之语惟出其语之可见之文。

## 防错

`速查。测试。豫` 取每条之例，书为包内 `校场/` 下之试文，一并以豫构验其类；其不能过者，报其部与名。如此则速查随语言而行，不待人记而改。
