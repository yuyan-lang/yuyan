# 速查页

速查页（速查页）是官网与 docs 站共用的“速查”正文：读 `应用/书院/门庭/内容/资料/速查。数据。豫`，按分组输出 `/速查/` 与 `/文言/速查/` 两页的分组表。

## 数据

`速查。数据。豫` 每条记六项：部（分组）、名、写法（语法的形状）、例（一小段能过类型检查的豫言）、说明（汉语与文言各一句）、出处（语言技术规范的篇与节）。读取用库「籍册」（数据文件）的「数据表诸行」，按字段名取文字；出处生成指向 `/文档/<篇>/` 的站内链接。

## 生成

公开函数「速查正文」接收条目列与语（可阙，缺省出双语），返回整页正文的网页片段：卷首、分组目录、各组的分组表（写法、例、说明三栏）与注。例照站上代码块的方式着色：包一层 `<pre data-yuyan-highlight>`，官网由页面脚本着色，docs 站由共用界面静态渲染在构建时着色。说明与栏名都带 data-han、data-wen 两栏，官网随界面语言切换；docs 站按页面的语只出那一语的可见文字。

## 防错

`速查。测试。豫` 把每条的例写成包内 `校场/` 下的测试文件，一次交给豫构做类型检查；哪条编不过就报出它的部与名。这样速查跟着语言走，不靠人记得去改。
