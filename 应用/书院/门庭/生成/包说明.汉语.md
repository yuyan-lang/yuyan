# 网站资料生成

整理官方网站需要的教程与资料，并生成整个官网静态站（取代原先的 Jekyll）。语料放在 `应用/书院/门庭/内容/`，页面稿、资料、共用资源、产品、性能、条款与 Cloudflare 的响应头、转址都在那里。

## 功能

程序在仓库根目录运行，分三步：

1. `入口。豫` 从语言仓文档生成带前言的 Markdown 页面：教程写到 `dist/网站稿/教程/`，指南写到 `dist/网站稿/指南/`，十七篇技术规范写到 `dist/网站稿/文档/`，并为旧 HTML 地址生成跳转页。中间稿只落在 `dist/网站稿/`，源码树不写。技术文档页的文稿快照取 `dist/语言来源.txt`，由仓库目标「官网」在运行前写好。
2. `整站。豫` 先把 `内容/` 抄进 `dist/网站稿/`（产品目录写成 `products/`，`响应头`、`转址` 写成 `_headers`、`_redirects`，`资料/` 与 `条款/` 不抄），再把教程各章的示例程序抄成 `/教程/示例/`，然后用静态站库（语言仓 `库/刊刻`，Markdown 由 `库/圈点` 转换）读取稿根，写出 `dist/网站`：带前言的页面按 `layout` 套用 `布局。豫` 中的布局（`default`、`技术文档`、`重定向`），其余文件原样复制；另写技术文档搜索索引 `文档/搜索.json`、`sitemap.xml` 与 `robots.txt`。条款在整站写完后抄进 `dist/网站/条款/`，全部页面扫描时才能列入。
3. `全部页面。豫` 在整站写完后扫描 `dist/网站` 的全部网页（跳过旧址跳转页；说明取第一个 h1，没有时取 title），并入包管理、控制台（`/cloud/` 下的全部固定页面：控制台、本机算力、GitHub 同步与账户级服务；项目与任务由控制台的项目列表列全）、试写间、账户等动态入口，按目录写出 `/全部页面/`：每层先列目录、再列页面。扫描到的目录没有首页时生成只列该目录的首页（如 `/指南/`、`/条款/`），使网址栏的上级目录链接都能打开；这些目录与 `/全部页面/` 的目录规则追加到 `dist/网站/_redirects`（平台不自动找 index.html）。

站点数据：`内容/资料/技术文档.yml` 是技术规范的章节目录（侧栏、翻页、总览卡片与站点导航共用），`内容/资料/问答.json` 是“十万个为什么”的问答，正文由 `问答。豫` 生成。技术文档总览中的 `<div class="技术篇目"></div>` 在生成时换成章节卡片。网址直接用中文，不做百分号编码。

后续版本：`资料/` 的 JSON 与 YAML 改成数据子语言 `名。数据。豫`（提案 00028）。

本包为可执行文件类型，不可被其他包依赖；包内模块仍可互相引用。类型典中的入口和文件名见包配置，程序产物为 `网站资料生成`。

## 使用

在仓库根目录运行仓库目标「官网」，它用正在运行的豫构编出本程序并运行：

```sh
./豫构。<系>。豫行 目标 官网
```

也可以单独检查、构建本包（`./豫构 检查 网站资料生成`、`./豫构 构建 网站资料生成`）。依赖、原生源文件及说明路径以 [包配置](网站资料生成。包。豫) 为准。构建不会自动运行程序；运行前先备好 `dist/语言来源.txt`，或者在仓库根目录用仓库目标「官网」。
