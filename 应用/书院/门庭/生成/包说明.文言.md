# 网站资料生成

整理官方网站需要的教程与资料，并成官网之全站（代昔之 Jekyll）。语料在 `应用/书院/门庭/内容/`：页稿、资料、共用之资源、产品、性能、条款与 Cloudflare 之响应头、转址皆在焉。

## 所司

此器行于仓根，其事有三：

1. `入口。豫` 取语言仓之文，书带前言之 Markdown 页：学篇入 `dist/网站稿/教程/`，指南入 `dist/网站稿/指南/`，技术规范十七篇入 `dist/网站稿/文档/`，并为旧网址书迁址之页。中间之稿惟落 `dist/网站稿/`，不书源码之树。技术之文之稿快照取 `dist/语言来源.txt`，仓库目标「官网」行前书之。
2. `整站。豫` 先抄 `内容/` 于 `dist/网站稿/`（产品之目书为 `products/`，`响应头`、`转址` 书为 `_headers`、`_redirects`，`资料/` 与 `条款/` 不抄），次抄学篇诸章之示例为 `/教程/示例/`，乃以静站之库（语言仓 `库/刊刻`，Markdown 由 `库/圈点` 转之）读稿根，书于 `dist/网站`：有前言之页依 `layout` 套 `布局。豫` 之版（`default`、`技术文档`、`重定向`），余文原样复制；又书技术之文之检索 `文档/搜索.json`、`sitemap.xml` 与 `robots.txt`。条款于全站既成之后抄入 `dist/网站/条款/`，总目乃得列之。
3. `全部页面。豫` 于全站既成之后遍览 `dist/网站` 之网页（略迁址之页；其注取首 h1，无则取 title），并包府、控制台（`/cloud/` 下诸定页：控制台、本机算力、GitHub 同步与账户之服务；项目与任务由控制台之项目列尽之）、试写间、户籍诸动态之门，依目录书 `/全部页面/`：每层先目录，后诸篇。所见之目录无首页者，为作惟列其下之首页（如 `/指南/`、`/条款/`），使址栏之上级皆可启；此等目录与 `/全部页面/` 之目录规附于 `dist/网站/_redirects` 之末（平台不自寻 index.html）。

站之数据：`内容/资料/技术文档.yml` 为技术规范诸篇之目（侧栏、翻篇、总览之卡与站之导航共用之），`内容/资料/问答.json` 为“十万个为什么”之问答，其正文由 `问答。豫` 成之。技术总览之 `<div class="技术篇目"></div>` 成站时易为诸篇之卡。网址直书中文，不作百分号之编码。

后续之版：`资料/` 之 JSON 与 YAML 改为数据子语言 `名。数据。豫`（提案 00028）。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `网站资料生成`，入口依包籍所载。

于仓根行仓库目标「官网」，以今行之豫构编此器而行之：

```sh
./豫构。<系>。豫行 目标 官网
```

亦可独验其籍、独构其器（`./豫构 检查 网站资料生成`、`./豫构 构建 网站资料生成`）。所依与原生组成皆见[包籍](网站资料生成。包。豫)。构不自行其器；行前先备 `dist/语言来源.txt`，或于仓根用仓库目标「官网」。

变接口则修说明，变身份与组成则修包籍。说明不作模块。
