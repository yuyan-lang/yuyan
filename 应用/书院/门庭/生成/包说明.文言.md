# 网站资料生成

整理官方网站需要的教程与资料，并成官网之全站（代昔之 Jekyll）。语料在 `应用/书院/门庭/内容/`：页稿、资料、共用之资源、产品、性能、条款与 Cloudflare 之响应头、转址皆在焉。

## 所司

此器行于仓根，其事有三：

1. `入口。豫` 取语言仓之文，书带前言之 Markdown 页：学篇入 `dist/网站稿/教程/`，指南入 `dist/网站稿/指南/`，技术规范十七篇入 `dist/网站稿/文档/`。页之网址为中文目录式之净址：学篇 `/教程/<名>/`、指南 `/指南/<名>/`、技术规范 `/文档/<名>/`，文言页冠 `/文言/`；文中的章链与仓内之文档链亦改为新址。技术之文之提要由库「提要」取于其源文，书于页前言 `description`，与编简同源。中间之稿惟落 `dist/网站稿/`，不书源码之树。技术之文之稿快照取 `dist/语言来源.txt`，仓库目标「官网」行前书之。
2. `整站。豫` 先抄 `内容/` 于 `dist/网站稿/`（`响应头`、`转址` 书为 `_headers`、`_redirects`，`资料/` 与 `条款/` 不抄），以条款四文依新址抄入稿根（`/条款/条款/`、`/条款/隐私/` 及其文页），次抄学篇诸章之示例为 `/教程/示例/`，就稿根之附表记补其所指数文之表段（「附表」之库；译名之页其翻译列表即取于《翻译列表》），乃以静站之库（语言仓 `库/刊刻`，Markdown 由 `库/圈点` 转之）读稿根，书于 `dist/网站`：有前言之页依 `layout` 套 `布局。豫` 之版（`default`、`技术文档`），余文原样复制；又书技术之文之检索 `文档/搜索.json`、`sitemap.xml` 与 `robots.txt`。既成，先补无文言稿之页一遍（抄为 `/文言/<径>/index.html`，易 `lang` 与对页属），乃书诸篇总目、补汉语页之对页属、复补文页一遍（总目与目录页之文版），以所补之址入 `sitemap.xml`；次改文页之站内链为文对页，终以旧网址之 301 规附于 `_redirects`（其径依平台为百分号之码，无连跳）。首页无文言稿，`/文言/` 即由此补出。
3. `全部页面。豫` 于全站既成之后遍览 `dist/网站` 之网页（其注取首 h1，无则取 title），并包府、控制台（`/cloud/` 下诸定页：控制台、本机算力、GitHub 同步与账户之服务；项目与任务由控制台之项目列尽之）、试写间、户籍诸动态之门，依目录书 `/全部页面/`：每层先目录，后诸篇。所见之目录无首页者，为作惟列其下之首页（如 `/指南/`、`/条款/`），使址栏之上级皆可启；此等目录与 `/全部页面/` 之目录规附于 `dist/网站/_redirects` 之末（平台不自寻 index.html）。

## 社区包之页

社区包之库（`yuyan-lang/yuyan-community-packages`）之 CI 于行「文档站」之先设二水土：`豫言社区包目录` 为社区仓 `包/` 之绝径，在语言仓之树外；`豫言社区包提交` 为社区仓之提交号。此器于全站书稿根之后、套版之先读此二俗，于稿根书包页：

- `/包/`：诸包，依主而分，主与包名皆依字之序；页首书一句凡几主、几包。
- `/包/<主>/`：此主之诸包。
- `/包/<主>/<包名>/`：包页，列名、主、版本、种类（可执行者于括中注界面）、许可、所依与源码，其下为简介与所渲染之 `包说明.汉语.md`；名、版本、种类、许可与一句简介取于包述，一句简介先取名帖之提要，无则取简介之首句。

三种页各出汉语与文言二份（文言之页在 `/文言/包/…`，用简介之文言稿与 `包说明.文言.md`）。

`包文件页。豫` 次为每包每文出一文档页：址为 `/包/<主>/<名>/文档/<去 source/ 之文径>/`，文言之页冠 `/文言/`；包制之文别有一页于 `/文档/`（文档之根页）。页数依主站文件页之式（`tab=files`、`view=docs`），`documentation.names` 以「阅读逻辑」之「声明」自源抽之，`references` 与 `qualifiedReferences` 以「阅读逻辑」之「引用」算之；查包、读文、析源三注入之函具于此：查包先视社区包之目，次视语言仓之包籍（「营造」之「访包」），读文于包目读其原文，析源取跨包之引。跨包之引于生成时算为址：引之的（社区包、语言包、发行）由「阅读逻辑」以变体授之，此鉴而分路，不解析字串；目标为社区包者指其站内文件页，目标为语言仓之包（豫章之属）以其的中之包名查包，指语言仓本轮提交（`dist/语言来源.txt`）于 GitHub 之源，得声明行号者书为 `#L` 之锚。包内文件径之中目（如 `文档/测试/`）亦各书一不挂脚本之目录页，免全站补目录页以带脚本之常版加之。包述与名帖以籍册（数据之库）读之，不手析；名帖有显示之名则于列中与名并列。`依赖` 中有包页者链于其包页，无者惟书其名。包页之源码链指社区仓此包之目 `https://github.com/yuyan-lang/yuyan-community-packages/tree/<社区仓提交>/包/<主>/<包目>`；包说明中之相对链改指同处之 GitHub 源码（文用 `blob`，目用 `tree`）。

不设 `豫言社区包目录`（本机出主站、云仓出主站）则一页不出，余者如故。社区仓之 `包/` 在语言仓之树外：语言仓求包时并扫 `dist/` 之下，社区仓之包与语言仓同名之包相撞。

站之数据：技术规范诸篇之目由库「页录」出（`内容/资料/页录。数据。豫` 一纸声明，侧栏、翻篇、总览之卡与站之导航共之），各篇之题、址与分组皆出于此；`内容/资料/问答.json` 为“十万个为什么”之问答，其正文由库「问答页」成之（与编简同一器）；页录以此二页为正文之源问答，又以速查之页为正文之源速查（其正文由库「速查页」成之），整站依之易其正文，不另书一判。技术总览之 `<div class="技术篇目"></div>` 成站时易为诸篇之卡，卡之题与址取于篇目，一言之要取于各篇稿件之提要（「提要」之库）。站内之链皆书中文之址，不作百分号之编码；文页之站内链指文对页。

后续之版：`资料/` 之 JSON 与 YAML 改为数据子语言 `名。数据。豫`（提案 00028）。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包不供他包所依，包内诸书仍可相引。程序名曰 `网站资料生成`，入口依包籍所载。

于仓根行仓库目标「官网」，以今行之豫构编此器而行之：

```sh
./豫构。<系>。豫行 目标 官网
```

亦可独验其籍、独构其器（`./豫构 检查 网站资料生成`、`./豫构 构建 网站资料生成`）。所依与原生组成皆见[包籍](网站资料生成。包。豫)。构不自行其器；行前先备 `dist/语言来源.txt`，或于仓根用仓库目标「官网」。

变接口则修说明，变身份与组成则修包籍。说明不作模块。
