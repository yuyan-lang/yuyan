# 页录

官网与编简共用的页面集合只有一处登记：`内容/资料/页录。数据。豫`。介绍页、数据页与规范篇各列一行，写的是源文件、数据页的正文来源与规范篇的分组；每页的标题、地址与对页地址都取自页面源文本身。编简页目、官网章目、总览卡片、站点导航与技术文档搜索索引都由这一份声明生成。

页录（page register）把页面集合收成一份声明。介绍页写一行源文件，标题取前言里的 `title`，地址取前言里的 `permalink`，对页地址取前言里的 `han_page` 与 `wen_page`；数据页同样写源文件与前言，另写一栏正文来源（现为问答或速查），正文由生成函数出、不读源文的标记文；规范篇写一行汉语源文件与分组，文言源文件由后缀换出，章名取源文件末段，标题取篇首的 `# 标题`，地址由章名推出（汉语 `/文档/章/`，文言 `/文言/文档/章/`），前言里写了 `permalink` 就以它为准。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、章程（前言解析）、籍册（数据文件）与圈点（分行）。

## 用法

```yuyan
寻观「页录」之书。

令「项们」为「读页录」于「元」而
令「篇目们」为「篇目列」于「元」而
```

两个读取函数都在仓库根运行，读申请一次核一次。默认导入（`页录` 模块）提供：

- `「读页录」`：核过声明与页源相符后，读出全部页项，次序照声明——先是介绍页，再是数据页，最后是规范篇，每页汉语、文言各一项。
- `「篇项们」`：规范篇的篇项列，一章一条，带章名、两语源文件、两边标题与地址、分组与文言分组。
- `「篇目列」`：官网用的篇目，每项是前言表（`name`、`group`、`wen_group`、`title`、`wen_title`、`url`、`wen_url`），形状与原先从 `技术文档.yml` 读出的相同。
- `「总览址」`：总览页一语的地址（汉语取 `/文档/`，文言取前言里的 `wen_page`），技术文档布局的侧栏与翻篇入口由此来。
- `「篇之章们」`：规范篇的章名，按声明次序；网站产物守卫数规范篇数用它。
- `「正文址们」`：正文来源为某一种（问答或速查）的页的地址，按页项次序；网站资料生成据此把这些页的正文换成对应生成函数出的正文。`「问答址们」` 只取问答那一种。
- `「寻址页」`：按地址找页项，找不到时得可无；网站资料生成按页面网址找页项，据此决定正文来源。
- `「核页录」`、`「核源在」`、`「核目列」`、`「核址们」`、`「核对址」`：登记的源都要在、每个页源目录里不许有未登记的页源、地址不许重复、对页地址要两边互指。读取函数都会先跑这些核对，测试也可以单独调用它们。

三个类型：`「页项」`（源文件、语、篇名、标题、地址、对页地址、正文来源）、`「正文之源」`（原稿、问答或速查）与 `「篇项」`（章名、两语源文件、两语标题与地址、分组与文言分组）。

## 声明里的六样

1. `「总览页」`：总览页的汉语源文件，技术文档布局要它的两个地址；
2. `「页源目们」`：页源目录，核未登记的页源时按目录列出文件；
3. `「别页们」`：不是站点页的页源（编译警告与云端代码高亮统一方案是仓内文档），核目录时跳过；
4. `「介绍页们」`：介绍页，汉语、文言各一行；
5. `「数据页们」`：数据页，汉语、文言各一行，写源文件与正文来源；
6. `「规范篇们」`：规范篇，一章一行，写汉语源文件、分组与文言分组。

## 报错

五种情形报错，都在读取页录时发生，免得页面集合悄悄少一页或多一页：

- 登记的页源不存在；
- 页源目录里有 `.汉语.md` 或 `.文言.md` 既没登记也不在 `别页们` 里；
- 同一页源登记了两次；
- 两个页面用同一个地址；
- 一页的对页地址指向页录里的另一页，而那一页的对页地址不指回来。

## 调用处

编简用它取页面集合、标题、地址与正文来源（`编简/页源。豫`）；网站资料生成用它取规范篇目、总览地址、按网址找页项与正文来源为问答或速查的地址（`生成/入口。豫`、`生成/整站。豫`、`生成/布局。豫`）；网站产物守卫用它数规范篇数（`守卫/模拟验收。脚本。豫`）。各处的写法见各自的包说明。

## 维护

改页面集合只改声明。修改接口时更新本说明；修改包身份、版本或依赖时同步更新包配置。说明文件不参与模块导入。
