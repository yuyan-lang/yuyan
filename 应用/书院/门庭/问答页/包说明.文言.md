# 问答页

「十万个为什么」之页，其正文惟此一份，官网与编简皆调之。数据为问答之独源：题号、义类、所据之篇、所据之则与永久之锚皆由 `内容/资料/问答.json` 而生。

问答之页，以问答之数据系于两站之“十万个为什么”之页。正文双语合一：每项汉文各一份，包于 `data-han`、`data-wen` 二栏之中，官网之页仍于页内易其语；编简为无脚本之静站，依所予之语惟出其语之可见之文。题数类数由数据计之，页中不书。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依标准库、结绳（析问答之数据）与圈点（避讳网页之文、换行）。

## 用法

```yuyan
寻观「问答页」之书。

「问答正文」于（「问答组们」于「元」）
「问答正文」于（「问答组们」于「元」）于『文言』
```

`「问答正文」` 不予语则出双语之正文（官网用之），与 `『汉语』` 或 `『文言』` 则可见之文惟出其语（编简用之）；二法皆先依数据计题数、类数与题号。默认导入（`问答页` 之模）所供：

- `「问答正文」`：问答之页全文，语可阙。
- `「问答组们」`：读仓根之问答数据，得诸类。
- `「读问答」`：以一份数据之文句析为诸类，供已读入者用之。
- `「问答文」`：问答数据之径（对仓根）。
- `「问答题」`、`「问答组」`：一题与一类之类型。

## 数据之形

一题六项：汉问、汉答、文问、文答、所据之则与题号。一类四项：汉名、文名、所据之篇与诸题。页中题号径取于数据，不另编号；类之序与题数由数据数之。

## 调用之处

网站资料生成于书整站之前读问答之数据，以本包 `「问答正文」` 易“十万个为什么”二页之正文（不予语，出双语）；编简读页录之时，正文之源为问答之页亦调本包，依页之语与 `『汉语』` 或 `『文言』`。二处之书，见各自之包说明。
