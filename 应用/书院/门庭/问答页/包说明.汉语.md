# 问答页

「十万个为什么」页面的正文只有这一份实现，官网与编简都调它。数据是问答的唯一来源：题号、主题、依据章节、规则说明与永久锚点都由 `内容/资料/问答.json` 生成。

问答页（questions page）把问答数据与两个站点的“十万个为什么”页面连在一处。正文双语合一：每一项汉语、文言各写一份，包在 `data-han`、`data-wen` 两栏里，官网的页面照样在页内切换语言；编简是没有脚本的静态站，按所予的语只出那一语的可见文字。题数与主题数从数据算，页面里不手写。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、结绳（解析问答数据）与圈点（网页文字避讳、换行）。

## 用法

```yuyan
寻观「问答页」之书。

「问答正文」于（「问答组们」于「元」）
「问答正文」于（「问答组们」于「元」）于『文言』
```

`「问答正文」` 不给语时出双语正文（官网用），给 `『汉语』` 或 `『文言』` 时可见文字只出那一语（编简用）；两种写法都先按数据算题数、主题数与题号。默认导入（`问答页` 模块）提供：

- `「问答正文」`：问答页的完整正文，语可省。
- `「问答组们」`：读仓库根下的问答数据，得各主题。
- `「读问答」`：由一份数据的文句解析出各主题，供已经读进内存的调用方使用。
- `「问答文」`：问答数据的路径（相对仓库根）。
- `「问答题」`、`「问答组」`：一道题与一个主题的类型。

## 数据的形

每道题是六项：汉语问题、汉语解答、文言问题、文言解答、规则说明与题号。每个主题是四项：汉语名、文言名、依据章节与题目列表。页面里的题号直接取自数据，不另编号；主题的序与题目数从数据数出来。

## 调用处

网站资料生成在写整站之前读问答数据，把“十万个为什么”两页的正文换成本包的 `「问答正文」`（不给语，出双语）；编简读页录时，正文来源为问答的页也调本包，按页的语给 `『汉语』` 或 `『文言』`。两处的写法见各自的包说明。

## 维护

修改接口时更新本说明；修改包身份、版本或构建组成时同步更新包配置。说明文件不参与模块导入。
