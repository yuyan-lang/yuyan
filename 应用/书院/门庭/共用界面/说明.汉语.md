# 豫言共用界面

全站导航、正文之后的本页网址栏（页面有站点导航时在站点导航之上，否则在页脚之上）、页脚、语言选择、共享 Cookie、网址参数、跨页跳转和动态文本节点由豫言浏览器程序实现。词典数据来自 `/共用/词典.json`；MutationObserver 把后续 DOM 变更送回豫言事件循环。网址栏显示本页网址路径（主机名加各级路径段，段已解码），每段都是链接：前面各段指向上级目录，末段是本页（href 为空），右端是“全部页面”入口；栏内是网址原文，切换文言时不翻译。包管理服务的包页、文档页与所有者页由服务端画同样的网址栏，产品页写在静态网页里，样式都是 `/共用/主题.css` 的 `.豫网址`。用模拟模式单独构建本包可以运行它的模拟验收。官网默认布局、技术文档、包市场、账户、试写间、云工作台和官网源码浏览页已使用此程序。源码树浏览器的独立离线生成器仍保留原入口，官网发布工具只转换官网生成页。历史缓存文档仍可请求 `/共用/界面.js`，但该资源现由构建流程生成，只负责启动豫言 Wasm，不再维护一套 JS 界面业务实现。

`模拟验收。脚本。豫` 在模拟宿主运行真实共用界面，覆盖导航、汉文切换、动态文本自动翻译与恢复、菜单、法律链接、语言偏好、真实各页面、语言对页与锚点、站点导航排序、问答翻译链接和受限页面切语，共 49 项断言（读云仓页面的四个用例在语言仓里缺文件时跳过）。共用界面应用构建运行这份模拟验收。云工作台场景使用现行算力页面。

`静态渲染。脚本。豫` 在构建时为 docs 静态站（云仓提案 C00005）渲染整站：把官网静态产物 `dist/网站` 的每个网页载进网页沙盘，跑一遍真实的共用界面，再给豫言代码块写上语法高亮、删去全部脚本元素，写到 `dist/文档站`；脚本与网页汇编文件不复制，其余文件原样复制。文言页按 `/文言/` 路径载入（界面语言由路径定）。没有脚本时，窄屏菜单换成勾选框加标签，点“菜单”就用纯 CSS 展开、收起全站导航；汉文两个按钮换成链接（有对页的指对页，没有对页的文言页指主站同页）；技术文档的搜索框藏起；问答页显示主题下拉框，按选中的选项用 CSS（`:has` 与 `option:checked`）藏起别的主题分组，文字搜索、清除按钮与计数藏起；另写 `404.html`，并在 `_redirects` 末尾补上转到主站的动态路径。由仓库目标「文档站」编译运行。

`静态收尾。脚本。豫` 在四个静态渲染都写完之后为 docs 站收尾：每个网页的 `<body>` 之首挂一条横幅，说明这是豫言静态站、请去动态站获得更佳体验（汉语页与文言页各一份文字），横幅里的链接指主站上的同一页、带 `data-主站入口` 标记，是 docs 站上唯一指向主站的链接；其余指向主站的链接按情形改写或去掉，目标在 docs 站里有的改成站内相对链接，没有的按位置整项去掉（站头、站点导航、页脚、全部页面树里的条目，按钮与示例里的“在试写间运行”）或只留文字（正文句子），相对写法而目标不在 `dist/文档站` 里的一律当指向主站处理；`_redirects` 里补转址那一段删掉，有包页（`/包/`，由网站资料生成按环境变量 `豫言社区包目录` 写出）时把站头与站点导航里的「包管理」从 `/packages/` 改成站内链接（文言页指 `/文言/包/`）、把旧的 `/packages/` 网址 301 到 `/包/`（目录与各级用 `:splat`），再把 `_redirects` 整份重排（去掉 200 改写规则，不带 `*` 也不带 `:名` 的静态规则在前、带 `*` 或 `:名` 的动态规则在最末），`sitemap.xml` 与 `robots.txt` 的网址改成 `https://docs.yuyan-lang.org`，横幅样式补进 `共用/主题.css` 末尾。改完重新读产物核对：每个网页恰好一条带标记的主站链接（就是横幅那条），此外没有 `href`、`src`、`action` 指向主站，没有指向不存在站内目标的相对链接，`_redirects` 里没有转到主站的规则、动态规则都在静态规则之后且不过一百条、静态规则不过两千条，站点地图与 `robots.txt` 的主机是 docs 站；不合就报错，让目标失败。docs 站的规矩是“只此一条去主站”。由仓库目标「文档站」在四个静态渲染之后编译运行。
