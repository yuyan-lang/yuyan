# 豫言共用界面

全站导航、正文之后的本页网址栏（页面有站点导航时在站点导航之上，否则在页脚之上）、页脚、语言选择、共享 Cookie、网址参数、跨页跳转和动态文本节点由豫言浏览器程序实现。词典数据来自 `/共用/词典.json`；MutationObserver 把后续 DOM 变更送回豫言事件循环。网址栏显示本页网址路径（主机名加各级路径段，段已解码），每段都是链接：前面各段指向上级目录，末段是本页（href 为空），右端是“全部页面”入口；栏内是网址原文，切换文言时不翻译。包管理服务的包页、文档页与所有者页由服务端画同样的网址栏，产品页写在静态网页里，样式都是 `/共用/主题.css` 的 `.豫网址`。用模拟模式单独构建本包可以运行它的模拟验收。官网默认布局、技术文档、包市场、账户、试写间、云工作台和官网源码浏览页已使用此程序。源码树浏览器的独立离线生成器仍保留原入口，官网发布工具只转换官网生成页。历史缓存文档仍可请求 `/共用/界面.js`，但该资源现由构建流程生成，只负责启动豫言 Wasm，不再维护一套 JS 界面业务实现。

`模拟验收。脚本。豫` 在模拟宿主运行真实共用界面，覆盖导航、汉文切换、动态文本自动翻译与恢复、菜单、法律链接、语言偏好、真实各页面、语言对页与锚点、站点导航排序、问答翻译链接和受限页面切语，共 66 项断言。共用界面应用构建运行这份模拟验收。云工作台场景使用现行算力页面。

`静态渲染。脚本。豫` 在构建时为 docs 静态站（云仓提案 C00005）渲染整站：把官网静态产物 `dist/网站` 的每个网页载进网页沙盘，跑一遍真实的共用界面，再给豫言代码块写上语法高亮、删去全部脚本元素，写到 `dist/文档站`；脚本与网页汇编文件不复制，其余文件原样复制。文言页带 `?lang=wen` 载入。没有脚本时，窄屏菜单换成勾选框加标签，点“菜单”就用纯 CSS 展开、收起全站导航；汉文两个按钮换成链接（有对页的指对页，其余的文言指主站同页带 `?lang=wen`）；技术文档的搜索框藏起；问答页显示主题下拉框，按选中的选项用 CSS（`:has` 与 `option:checked`）藏起别的主题分组，文字搜索、清除按钮与计数藏起；另写 `404.html`，并在 `_redirects` 末尾补上转到主站的动态路径。由仓库目标「文档站」编译运行。
