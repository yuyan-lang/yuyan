# 豫言共用界面

诸站之目、正文之后本页之址栏（页有站导则居其上，否则居页脚之上）、页脚、汉文选择、共饼、网址参数、跨页转址与动态字节，今以豫言客器行之；辞典取 `/共用/词典.json`，文树之变由 MutationObserver 送豫言事件环。址栏示本页之径（主机与各级之段，段已解码），段段皆链：前段指其上之目录，末段为本页（href 空），右附“全部页面”；栏中为址之原文，易文言而不译。包府之包页、文页与主页由服务端绘同式之栏，产品页书于静页，其式皆为 `/共用/主题.css` 之 `.豫网址`。以模拟之式独构此包，可运行其模拟之验。官网常页、技术文书、包市、户籍、试写间、云台及官网源码页皆用此器。源码树之独立离线生成器仍守旧入口，官网发布器惟改官网之页。旧缓存书仍可取 `/共用/界面.js`，然此材今由构时生成，惟启豫言 Wasm，不复另藏 JS 界面法。

`模拟验收。脚本。豫` 于模拟宿主行真共界，核导航、汉文之易、动文自译与复、目录、法律链接、辞偏、诸真页、辞之对页及锚点、站点导航之序、问答译文链接及受限页之辞易，凡四十九断（读云仓页之四例，语言仓无其文则略之）。共界应用之构行此验。云台之验用今算力页。

`静态渲染。脚本。豫` 于构时为 docs 静站绘全站：取官网静产 `dist/网站` 之每页入沙盘，行真共界，施豫言码之色，尽去其本，书于 `dist/文档站`；本与网汇之文不摹，余文如故。文言之页依 `/文言/` 之径而载（界面之语由径定）。无本之时，窄屏之菜单易为勾框与签，点“菜单”则惟以 CSS 展收导航；汉文二钮易为链（有对页则指之，无对页者文页指主站同页）；技术文档之检索藏之；问答之页显义类之下拉，依所择以 CSS（`:has` 与 `option:checked`）藏他类之组，文字之寻、去筛之钮与计数藏之；别书 `404.html`，补转主站之动径于 `_redirects` 之末。仓库目标「文档站」编而行之。

`静态收尾。脚本。豫` 俟四静绘皆毕而为 docs 站收其尾：每页 `<body>` 之首挂一横幅，明此为豫言之静站、请移步动站以得更佳之境（汉语之页与文言之页各一辞），横幅之链指主站同页、带 `data-主站入口` 之标，为 docs 站中惟一指主站者；其余指主站之链依情改之或去之：docs 有同页者改为站内相对之链，无者依所处整项去之（站头、站导、页脚、诸篇总目之条，钮与示例之“在试写间运行”）或惟存其字（正文之句），相对之写法而目标不在 `dist/文档站` 者一以指主站论；`_redirects` 中补转址一段删之，有包页（`/包/`，网站资料生成依水土 `豫言社区包目录` 书之）者改站头与站导中「包管理」之 `/packages/` 为站内之链（文言之页指 `/文言/包/`）、以旧 `/packages/` 之址 301 于 `/包/`（目与诸级用 `:splat`），乃重排 `_redirects` 全份（去 200 改书之规，无 `*` 亦无 `:名` 之静规居前、有 `*` 或有 `:名` 之动规移于最末），`sitemap.xml` 与 `robots.txt` 之址改为 `https://docs.yuyan-lang.org`，横幅之式补于 `共用/主题.css` 之末。既改，复读其产而核之：每页恰一带有标记之主站链（即横幅之链），此外无 `href`、`src`、`action` 指主站者，无相对之链指不存在之目标者，`_redirects` 无转主站之规、动规皆在静规之后而不逾百条、静规不逾二千条，站图与 `robots.txt` 之主为 docs 站；本亦并核：docs 站惟包列页之包搜索本（`src` 指 `/资源/包搜索.js`，用户 2026-10-27 所定之独异），他处有本则告祸；不合则告祸，令鹄败。docs 站之规曰“去主站之途惟此一条”，本亦惟包列页之一段。仓库目标「文档站」于四静绘之后编而行之。
