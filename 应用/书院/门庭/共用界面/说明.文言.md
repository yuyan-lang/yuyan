# 豫言共用界面

诸站之目、正文之后本页之址栏（页有站导则居其上，否则居页脚之上）、页脚、汉文选择、共饼、网址参数、跨页转址与动态字节，今以豫言客器行之；辞典取 `/共用/词典.json`，文树之变由 MutationObserver 送豫言事件环。址栏示本页之径（主机与各级之段，段已解码），段段皆链：前段指其上之目录，末段为本页（href 空），右附“全部页面”；栏中为址之原文，易文言而不译。包府之包页、文页与主页由服务端绘同式之栏，产品页书于静页，其式皆为 `/共用/主题.css` 之 `.豫网址`。以模拟之式独构此包，可运行其模拟之验。官网常页、技术文书、包市、户籍、试写间、云台及官网源码页皆用此器。源码树之独立离线生成器仍守旧入口，官网发布器惟改官网之页。旧缓存书仍可取 `/共用/界面.js`，然此材今由构时生成，惟启豫言 Wasm，不复另藏 JS 界面法。

`模拟验收。脚本。豫` 于模拟宿主行真共界，核导航、汉文之易、动文自译与复、目录、法律链接、辞偏、诸真页、辞之对页及锚点、站点导航之序、问答译文链接及受限页之辞易，凡六十六断。共界应用之构行此验。云台之验用今算力页。

`静态渲染。脚本。豫` 于构时为 docs 静站绘全站：取官网静产 `dist/网站` 之每页入沙盘，行真共界，施豫言码之色，尽去其本，书于 `dist/文档站`；本与网汇之文不摹，余文如故。文言之页带 `?lang=wen` 而载。无本之时，窄屏之菜单易为勾框与签，点“菜单”则惟以 CSS 展收导航；汉文二钮易为链（有对页则指之，余则文言指主站同页带 `?lang=wen`）；技术文档之检索藏之；问答之页显义类之下拉，依所择以 CSS（`:has` 与 `option:checked`）藏他类之组，文字之寻、去筛之钮与计数藏之；别书 `404.html`，补转主站之动径于 `_redirects` 之末。仓库目标「文档站」编而行之。
