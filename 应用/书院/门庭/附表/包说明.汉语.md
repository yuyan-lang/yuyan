# 附表

页面稿里留一行标记，构建时把另一份文档的表格部分补进来。译名页的翻译列表因此只有《翻译列表》一个来源。

附表（appended table）把页面里的表格与登记它的文档连起来：页面写一行 `<!-- 附表：路径 -->`，网站资料生成与编简读过页面后，把这一行换成该文档的表格部分，即自其第一个以 `### ` 起首的行到末尾。表格改了，各处生成的页面随之而变，不必再抄第二份。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只依赖标准库。

## 用法

```yuyan
寻观「附表」之书。

「补附表」于（「阅」于『应用/书院/门庭/内容/译名.汉语.md』）
```

页文里没有附表标记时，`「补附表」` 原样返回，所以整篇扫描、逐页补入都不必先判断。标记的路径按仓库根解析，调用程序在仓库根运行。

默认导入（`附表` 模块）提供：

- `「补附表」`：把页文里的每条附表标记换成所指文档的表格部分，可有多条，逐条补入。
- `「有附表」`：页文里有没有附表标记。
- `「表段」`：取一份文档的表格部分，即自第一个以 `### ` 起首的行到末尾。
- `「表起」`：表格部分的起点（字符序号），包在「可有」里。

## 报错

三种情形报错，免得附表悄悄空掉：

- 附表标记没有结尾 ` -->`；
- 标记里的路径读不到文件；
- 来源文档里没有以 `### ` 起首的行。

## 调用处

页面稿都在 `应用/书院/门庭/内容/`，附表标记写在页面稿里；网站资料生成在把内容抄进稿根之后，对稿根里的 Markdown 页逐页补附表；编简在读一页的源文时补附表。两处的写法见各自的包说明。
