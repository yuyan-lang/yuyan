# 豫言操作系统：使中文之程序行于诸境

**豫言为中文编程之语言；豫言操作系统为载其程序之生态。** 愿以中文书计算，亦以同一中文之约，取文件、网络、窗与诸宿主之能。程序先编为豫汇，存以树码；原生之程由是生为豫行之文，行于豫言操作系统；网页之程导为网页汇编，行于浏览器与云端。

此篇书其志与次第，诸平台今日所支之域，以[豫言操作系统总体架构](/文言/豫言操作系统架构/)为准。

## 一法而通诸宿

豫言操作系统定程序何以始、何以取所授之能、何以传值与释资源；诸平台各行此约。裸机则直治硬件，桌面则资既有之系统，浏览器与边缘之算则资其所在之接口。

| 宿主 | 程序之形 | 豫言操作系统所供 |
| --- | --- | --- |
| 豫言操作系统（ARM64、AMD64） | 豫行 | 引导、内存、驱动、调度、文件系统、网络、壳与桌面 |
| macOS、Linux、轩窗 | 编译器径出之本机程序；后此经启动器行同一豫行 | 执行器、平台之层与统一之中文接口 |
| 浏览器 | 网页汇编 | 中文能力之绑定、权限之映射、程序生灭之同义 |
| 云端 Worker | 网页汇编 | 请求、存储诸能之绑定，并明无窗之境所能 |

诸途各异，程序所见之义同。

## 中文以通宿主之能

宿主之 API 名法各异。豫言操作系统于语言侧定中文之名、类型、误与权限，再映诸宿之实法；所统者，可见之义也。能随所授而有：诸宿唯告其实有之能；有窗之宿，取文件亦须授。

同一程序，惟宿主合其**接口之版与所需之能**，乃可行。纯计算可达诸境；图形须窗；服务须受请求之能。装载之时先验其约，缺则同法告之。

图形界面亦豫言操作系统之一能。以豫言共书布局、控件与绘图之法，诸宿各供窗、输入、字形与画面提交。浏览器可作其上之应用而长；天下网页仍循 HTML、CSS 与 JavaScript 之规范。

## 成事之次

1. **一二进制而行诸境。** 同一豫行经启动器行于 macOS、Linux、轩窗；启动器可自带豫行，合为单一可执行之文（[提案〇〇〇二一](https://github.com/yuyan-lang/yuyan/blob/yybs/提案/00021-豫行跨平台运行.汉语.md)）。
2. **定其约。** 有版之接口、资源之柄、权限、误与异步之义，及豫行之式与内核服务所成之豫言内核 ABI。
3. **立诸宿同验。** 以同批豫言程序，核豫言操作系统、桌面之系统、浏览器与云端之果，记其所缺。
4. **通图形程序。** 窗、输入、字体与绘图之能，共用之中文界面库与平铺桌面。
5. **实机。** 依明定之机型，渐验驱动与安装。
6. **成生态。** 开发之器、包与应用之分发，公示兼容与性能之实数。

今豫言操作系统已能启于 QEMU、VMware Fusion 与 UTM：内核与驱动以豫言书之，数据之盘为标准 ext4，开机即豫言之壳，有平铺桌面，系统中能行豫言工具链、构程序而造启动光盘。志之所贵，在使已成之功渐归**同一个豫言操作系统**。
