# 编简

取页录所登介绍之页与规范之篇，读为匠心之文档，供两站共用。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包不供他包所依，包内诸书仍可相引。程序名曰 `编简`。

在仓库之根行：

```sh
./豫构。林檎。豫行 构建 编简 --输出 编简。林檎。豫行 -j 12
./编简。林檎。豫行 列出
./编简。林檎。豫行 全部
./编简。林檎。豫行 出站 /tmp/编简站
./编简。林檎。豫行 渲染 /译名/ 1200 1 /tmp/译名.png
./编简。林檎。豫行 切片 /译名/ 1200 1200 /tmp/译名片
```

- `列出`：书诸页之径与题。
- `全部`：各页编为文档而书其顶层块数，校其无异常。
- `出站 目录`：尽书诸页为 docs 整站（先清其根），行整站之守，书其卷数与字节。
- `渲染 路径 宽 倍 输出`：依宽排为连续之版，画为宽倍高倍之图。
- `切片 路径 宽 片高 前缀`：同版纵切之，每片画为宽乘片高之图，名以前缀接一二三。

页面之集在[页录](../内容/资料/页录。数据。豫)登记一处，题、址与对页之址由库「页录」取于源文：介绍之页取题记之 `title`、`permalink` 与 `han_page`、`wen_page`，规范之篇取篇首之 `# 题`，址由章名而推（有 `permalink` 者依之）。介绍之稿取 `应用/书院/门庭/内容/`（与网站之生成共一份），规范之篇取语言仓 `应用/豫言编译器/文档/语言技术规范/` 之原文。各页之提要由库「提要」取于其源文：介绍之页取题记之 `description`，规范之篇取源文一行 `<!-- 提要：… -->`，与网站之生成同出一源。稿中书一行 `<!-- 附表：径 -->` 者，读入之时以此行易为所指数文之表段（「附表」之库）；译名之页，其翻译列表即取于语言仓之《翻译列表》，与网站之生成同出一源。

技术之文汉语页书于 `/文档/名/`，文言页书于 `/文言/文档/名/`；文言总览之页依 `内容/文档首页.文言.md` 题记之 `permalink`，书于 `/文言/文档/总览/`，与官网同址。出站别书根上之 `_redirects`，以旧径（`/文档/名.汉语.html`、`/文档/名.文言.html`、`/豫言操作系统.汉语.html` 之属，依页源之名而推）以 301 转至新径；总览页旧之 `/文档/总览.文言.html` 别书一条。站内之链成篇时改写为净径。

## 文档之形

一页之文档三节：站头（站名与全站之导航）、网址栏（本页之径逐段为链）、正文，末为页脚。站头、网址栏、页脚皆为匠心之文档组件（「文档组件保存」），展开为一段；主站之设计树码可依组件之名存之。

正文由匠心之「标记文篇」自 markdown 编成：题、段、列、表、引、围栏之码与网页之块。围栏之码编为「码块」，豫言之码复经译场之义标裁为带 `tok-` 样式类之「码片」；段中行内之码、强调、加粗、链与式，循标记文行内之则。

## 修文

改页之集则改页面目录那一份声明（今为库「页录」之 `页录。数据。豫`）；改 markdown 转换之规则则同步 `库/匠心/篇引。豫` 与此节。说明不作模块。
