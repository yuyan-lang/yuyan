# 译名

豫言的文件名、标识符、代码与文档都用中文，外来的技术名词各有一个中文名。本页说明 JSON、Node.js、JavaScript 与密码算法 SHA、RSA 的译名及其由来，全部译名列在页末的[翻译列表](#翻译列表)。

## 起名的原则

- **短**：两三个字，方便组成复合词，如结绳文件、诺驿库。
- **能猜**：看到名字，大致猜得出来历或用途。
- **像专名**：产品与格式的名字用新组合的词。

办法按术语挑选：**音义兼译**（字音接近原名，字义贴合用途）、**意造**（按意思造新词）、**直译**（原名本身是比喻时，照字面译出）、**沿用**（已有通行的中文名）。

专有名称优先音义兼译，本土有神似之物的取本土说法，通用概念优先意译：结绳、沙二五六、李萨阿是专名；杂凑、签名、张量、汇编是通用概念。数字逐位写成汉字零至九，与豫言的数字字面量同法：标准编号、版本号、位数都这样写，如 RFC 3339 译征求意见三三三九、ext4 译扩展文件系统四；十六进制、三十二位同文这类已成词的照旧；两段数字相连会读混的，把位数写在前面加“位”，如 SHA3-256 译二五六位沙三。人名缩写取各人姓氏译名的首字，如 LZ 译莱齐、RSA 译李萨阿、Diffie–Hellman 译迪赫。

格式名用固定的字收尾，表明类别：图（图像格式）、景（三维场景格式）、档（归档）、压（压缩）、码（文本记法）、象（对象表示）、列（列式数据）、量（张量）、阵（多维数组）、浮（浮点）。

缩写、专名与接口名一律有中文名；英文原名只留在字符串、下载的数据与规范原文里。

## JSON：结绳

JSON（JavaScript Object Notation）用对象与数组层层嵌套来表示数据，是网络接口与配置文件最常用的数据格式。结绳取本土说法：

- **义**：上古结绳记事，是早先的数据记法；“结”又读近 J。出处：《易·系辞下》“上古结绳而治，后世圣人易之以书契”。
- **组词**：结绳文件、结绳解析器、结绳对象；豫言处理 JSON 的库叫“结绳”。

## Node.js：诺驿

Node.js 是在服务器与命令行上运行 JavaScript 的环境，也是豫言的后端之一，豫言的编译器与各种工具都能在它上面运行。诺驿是音义兼译：

- **音**：“诺”取 Node 的音，又是应诺之“诺”：先应下，事办完再回话，正合异步回调的路数。
- **义**：“驿”是驿站，消息一站站传递的节点；豫言把网络叫作“驿”，诺驿即网络上的节点，node 的本义“节点”尽在其中。
- **组词**：诺驿库（npm 上的包，与“系统库”相对）；平台名诺驿之林檎、诺驿之林纳、诺驿之轩窗。“诺驿”是新组合的词，一看就知道是专名。

## JavaScript：捷思

JavaScript 是网页的脚本语言，浏览器与诺驿都能运行它。捷思是音义兼译：

- **音**：捷思（jié sī）读起来接近 JS。“捷”与字母 J 的音译“杰”同音；“思”取 S 的音。
- **义**：“捷”是敏捷，“思”是思考，合起来是敏捷的思维，贴合这门语言轻量灵活、随写随跑的特点。
- **组词**：捷思文件、捷思模块、捷思引擎。
- **标准名**：ECMAScript（简称 ES）译作易思。“易”（yì）取 E 的音，“思”取 S 的音，与捷思同用“思”，表明两者是同一门语言；ES2015 叫易思二零一五，制定标准的 ECMA 译作易克玛。

## SHA 与 RSA：沙、李萨阿

SHA 是最常用的杂凑算法族，RSA 是最常用的公钥算法。两个译名分别用了专名的两种起法：取音兼取义，取人名首字。

- **沙**：SHA（Secure Hash Algorithm，安全杂凑算法）译作沙，音义兼译。沙（shā）读如 SHA；杂凑把任意长的数据磨成定长的细末，如沙。编号逐位写成汉字：沙一、沙二五六、沙五一二、沙三；SHA-3 的可扩展输出函数 SHAKE 译作沙克。
- **李萨阿**：RSA 由三位提出者 Rivest、Shamir、Adleman 的姓氏首字母组成。译名同样取三人姓氏译名李维斯特、萨莫尔、阿德曼的首字，保留三人并列的结构。Diffie–Hellman 密钥交换同例译作迪赫，压缩算法 LZ 译作莱齐。
- **组词**：沙二五六摘要、密钥杂凑码沙二五六（HMAC-SHA256）、李萨阿签名、李萨阿概率签名（RSA-PSS）、椭圆迪赫（ECDH）。
