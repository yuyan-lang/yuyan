# 译名

豫言之文件名、标识、代码与文书，皆以汉文书之；外来之术语，各有汉名。此篇述 JSON、Node.js、JavaScript 与密码算法 SHA、RSA 之译及其所由，诸译皆列于篇末之[翻译列表](#翻译列表)。

## 立名之则

- **简**：二三字，便于缀为复词，如结绳文件、诺驿库。
- **可推**：见其名，略知其所出与所用。
- **类专名**：器与格式之名，取新合之词。

其法视术语而择：**音义兼译**（字音近原名，字义合其用）、**意造**（依义造新词）、**直译**（原名本为譬喻，依字译之）、**沿用**（既有通行之汉名）。

专名先音义兼译，本土有神似之物者取本土之说，通名先意译：结绳、沙二五六、李萨阿，专名也；杂凑、签名、张量、汇编，通名也。数则逐位书以汉字零至九，与豫言数字之字面同法：标准之号、版号、位数皆然，如 RFC 3339 译征求意见三三三九，ext4 译扩展文件系统四；十六进制、三十二位同文之属已成词者仍旧；两数相连而易混者，书位数于前而加“位”，如 SHA3-256 译二五六位沙三。人名之缩写，取各人姓氏译名之首字，如 LZ 译莱齐，RSA 译李萨阿，Diffie–Hellman 译迪赫。

格式之名，以定字殿之，以明其类：图（图像格式）、景（三维场景格式）、档（归档）、压（压缩）、码（文本记法）、象（对象表示）、列（列式数据）、量（张量）、阵（多维数组）、浮（浮点）。

缩写、专名及接口之名，皆有汉名；英文原名惟存于字符串、所下载之数据及规范原文。

## JSON：结绳

JSON（JavaScript Object Notation）以对象与数组层层相嵌而表数据，网络之接口、配置之文多用之。结绳，取本土之说：

- **义**：上古结绳记事，乃早先之数据记法；“结”又读近 J。出处：《易·系辞下》“上古结绳而治，后世圣人易之以书契”。
- **缀词**：结绳文件、结绳解析器、结绳对象；豫言治 JSON 之库曰“结绳”。

## Node.js：诺驿

Node.js 者，行 JavaScript 于服务器与命令行之境也，亦豫言后端之一，豫言之编译器与诸工具皆可行于其上。诺驿，音义兼译也：

- **音**：诺取 Node 之音，又应诺之诺：先应之，事毕而后报，合异步回调之道。
- **义**：驿者传命之站，消息递相传之节点也；豫言名网络曰驿，诺驿即网络之节点，node 之本义“节点”尽在其中。
- **缀词**：诺驿库（npm 之包，与“系统库”相对）；平台名诺驿之林檎、诺驿之林纳、诺驿之轩窗。“诺驿”为新合之词，一见即知其为专名。

## JavaScript：捷思

JavaScript 者，网页之脚本语言也，浏览器与诺驿皆能行之。捷思，音义兼译也：

- **音**：捷思（jié sī），读之近 JS。捷与字母 J 之音译“杰”同音；思取 S 之音。
- **义**：捷者，敏也；思者，虑也；合言之，敏捷之思，合此语轻灵、随书随行之性。
- **缀词**：捷思文件、捷思模块、捷思引擎。
- **标准之名**：ECMAScript（省称 ES）译易思。易（yì）取 E 之音，思取 S 之音，与捷思同用“思”，明二者为一语；ES2015 曰易思二零一五，定其标准之 ECMA 译易克玛。

## SHA 与 RSA：沙、李萨阿

SHA 者，杂凑算法之最常用者也；RSA 者，公钥算法之最常用者也。二译各用专名立名之一法：一取音兼取义，一取人名之首字。

- **沙**：SHA（Secure Hash Algorithm，安全杂凑算法）译为沙，音义兼译也。沙（shā）读如 SHA；杂凑磨任意长之数据为定长之细末，若沙然。编号逐位书以汉字：沙一、沙二五六、沙五一二、沙三；SHA-3 可扩展输出之函数 SHAKE，译为沙克。
- **李萨阿**：RSA 者，立法三人 Rivest、Shamir、Adleman 姓氏之首字母也。译名亦取三人姓氏译名李维斯特、萨莫尔、阿德曼之首字，存三人并列之构。Diffie–Hellman 之密钥交换同例，译为迪赫；压缩算法 LZ 译为莱齐。
- **缀词**：沙二五六摘要、密钥杂凑码沙二五六（HMAC-SHA256）、李萨阿签名、李萨阿概率签名（RSA-PSS）、椭圆迪赫（ECDH）。
