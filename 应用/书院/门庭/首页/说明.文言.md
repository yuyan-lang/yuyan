# 官网首页应用

`入口。豫` 藏三例，裁切换与复制。客源码惟导豫言操作系统网页界面、剪贴板、网址三公约之包籍；构时先核约与浏览器实作，乃以 OS 适配绑定之。客不导旧宿主及具体适配包。其产由豫构以浏览器之宿主编之，布时置于 `dist/网站/资源/首页应用/` 下。

`静态渲染。脚本。豫` 于构时易 docs 首页三例为无本之分页：载首页于沙盘，行真首页之应用，次第点三页之钮，录各例之码、所出、所释与试写间之链，乃书代码册为三单选、三页签与三例之板，补分页之规于 `资源/首页.css` 之末：择何单选则惟显何板（惟用 CSS）。复制之钮须本，不书。仓库目标「文档站」俟共界静绘之后编而行之。
