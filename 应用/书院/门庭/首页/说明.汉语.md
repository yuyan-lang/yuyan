# 官网首页应用

`入口。豫` 持有首页三个示例及切换、复制行为。应用源码只导入豫言操作系统网页界面、剪贴板、网址三个纯接口包身份；构建时先核对接口规范与浏览器实现，再把这些身份绑定到 OS 适配包。应用不导入旧浏览器宿主或具体适配包。产物由豫构以浏览器宿主构建，发布时放在 `dist/网站/资源/首页应用/` 下。

`静态渲染。脚本。豫` 在构建时把 docs 静态站首页的三个代码示例改成不靠脚本的分页：把首页载进网页沙盘，跑真实的首页应用，依次点三个分页按钮，记下每个示例的代码、输出、解释与“在试写间运行”的链接，再把代码册写成三个单选框、三个分页标签与三块示例面板，并在 `资源/首页.css` 末尾补上分页规则：选中哪个单选框就只显示哪块面板（纯 CSS）。复制按钮要脚本，不写。由仓库目标「文档站」在共用界面静态渲染之后编译运行。
