# 官网

通称官网，指 `yuyan-lang.org`（主站）与 `docs.yuyan-lang.org`（docs 站）共用的页面。云仓提案 C00005《静态站与动态站分离》实施中：同一份页面源在构建时出两种呈现——主站的页面由浏览器里的豫言系统排版绘制，docs 站的页面是构建时写好的 HTML 与 CSS。

这是 `应用/书院/门庭/` 的父包，只有包描述与本说明，不含模块。它登记网站资料生成、网站产物守卫、共用界面应用、首页应用、产品应用、问答应用、技术文档应用与编简；新增程序时，须在本包「包含包」登记，并在新包写「包含在」。

## 目录

| 路径 | 内容 |
| --- | --- |
| `内容/` | 网站内容：页面稿 `*.汉语.md` 与 `*.文言.md`、`资料/`、`共用/`、`资源/`、`产品/`、`性能/`、`条款/`、`响应头`、`转址` |
| `生成/` | 包「网站资料生成」：读页面稿与语言仓的教程、指南、技术文档，写出 `dist/网站` |
| `守卫/` | 包「网站产物守卫」：核对问答数据、静态正文、站内链接与技术文档索引 |
| `共用界面/` | 包「共用界面应用」：全站导航、网址栏、页脚与双语文字；连同它的 `静态渲染。脚本。豫` |
| `首页/`、`产品/`、`问答/`、`技术文档/` | 包「首页应用」「产品应用」「问答应用」「技术文档应用」：四个页面应用及其静态渲染脚本 |
| `编简/` | 包「编简」：把页面稿读成匠心的文档，把整站写成文档站并跑守卫 |

`内容/` 是网站内容，包发现只认本目录下的包目录。页面稿的文件名、`资料/` 里的 `问答.json` 与 `技术文档.yml`、Cloudflare 的 `响应头` 与 `转址` 都按中文命名；网站资料生成把 `响应头`、`转址` 写成产物里的 `_headers`、`_redirects`（Cloudflare 要的文件名），产品目录写成产物里的 `products/`（现行主站的网址）。网址一律直接用中文，不做百分号编码。

## 两种产物

- `dist/网站`：主站与 docs 站共用的页面，由仓库目标「官网」写出。
- `dist/文档站`：docs 站的 HTML 与 CSS，由仓库目标「文档站」在 `dist/网站` 上依次跑共用界面、首页、技术文档三个静态渲染脚本写出，不带脚本与网页汇编文件。

## 后续版本

- `资料/` 的 JSON 与 YAML 改成数据子语言 `名。数据。豫`（提案 00028）。
- 产品页在 docs 站静态渲染，网址从 `/products/` 改成 `/产品/`（阶段二）。
