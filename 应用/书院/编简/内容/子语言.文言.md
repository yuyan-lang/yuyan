# 子语言

豫言之源文皆以 `。豫` 终，同用一法。文名于 `。豫` 之前加类段（如 `。脚本`、`。着色器`、`。底层`），则属其子语言。缀定四事：文中可书者何，无体之声谁供之，编为何代，导时得何模。此篇依缀列诸子语言；诸缀之详则与仓中之例，见技术之文《[文件后缀](/文档/文件后缀.文言.html)》。诸子语言共守之则，及其于一程序中相配之道，见技术之文《[子语言设计](/文档/子语言设计.文言.html)》。

## 豫言（有垃圾回收）

此组为高级之文：有垃圾回收，编为 WasmGC 之模。

| 缀 | 子语言 | 所载 |
| --- | --- | --- |
| `名。豫` | 豫言 | 常源，一文一模；顶层惟有定义，其值皆数据 |
| `名。脚本。豫` | 脚本 | 顶层即程序之体，依次行之；独编独行 |
| `名。测试。豫` | 试 | 单元之试，顶层即程序之体；全树之试自得而行之，构库则略之 |
| `名-编号。豫` | 金样 | 试料，顶层即程序之体；同组配一 `名。成功` 或 `名。失败` 之标文，书所期之果 |
| `名。接口。豫` | 宿主接口 | 唯书类型与 `乃` 之签，宿主或构建时所绑之适配实之；每声编为带型之 Wasm 导入 |
| `名。应用接口。豫` | 应用接口 | 唯书类型与签，应用实之；入口定同名之顶层函，则编为导出 |
| `名。内建。豫` | 内建之声 | 编译器所供之语言原语，其签依编译器之原语表校之 |

## 着色语言

着色之文以豫言常法书图形处理器之着色程序，详见技术之文《[着色语言](/文档/着色语言.文言.html)》。

| 缀 | 子语言 | 所载 |
| --- | --- | --- |
| `名。着色器。豫` | 着色语言 | 检类而后译为 WGSL、MSL 与 PTX；高级之代导之，得构时所生之模 `名。着色生成。豫` |
| `名。着色器。接口。豫` | 着色内建之声 | 着色之的所供之算与内建之函 |

## 底层豫言（无垃圾回收）

名含“。底层”者为底层之文：无垃圾回收，编为常 Wasm，用于执行器、驱动、张量内核诸系统之代。程序之入口为底层之文，则全程依底层编之。

| 缀 | 子语言 | 所载 |
| --- | --- | --- |
| `名。底层。豫` | 底层豫言 | 底层之源 |
| `名。底层。测试。豫` | 底层之试 | 底层单元之试，全树之试照常得而行之 |
| `名。底层接口。豫` | 底层接口 | 每无体之声编为一 Wasm 导入，导入之模名为文名去其缀 |
| `名。底层内建。豫` | 底层内建之声 | 底层库之原语表，其调就地编为 Wasm 之令 |

## 包述

| 缀 | 子语言 | 所载 |
| --- | --- | --- |
| `名。包。豫` | 包述 | 一包一篇：名称、所有者、版本、简介、说明、类型、依赖诸字段，豫构读之 |

## 豫汇

豫汇（豫言汇编），豫言之内与网页汇编（Wasm）一一相应之子语言也，原生、裸机、诺驿、浏览器、云工诸后端共以为执行之界。有垃圾回收之层曰豫汇，应 WasmGC；无垃圾回收之层曰底层豫汇，应常 Wasm。

| 缀 | 子语言 | 所载 |
| --- | --- | --- |
| `名.树码` | 豫汇 | 汇编树码：编译器之出径以 `.树码` 终，则书豫汇之模为此文；豫言系统可径由之生豫行之文 |

## 导入

导之路惟书模块名，编译器依导者之子语言补其缀，取首存之文：

| 导者 | 依次所求 |
| --- | --- |
| 豫言 | `名。豫`、`名。接口。豫`、`名。应用接口。豫`、`名。内建。豫`、`名。着色器。豫` |
| 着色语言 | `名。着色器。豫`、`名。着色器。接口。豫` |
| 底层豫言 | `名。底层。豫`、`名。底层接口。豫`、`名。底层内建。豫` |

试之模以全名导之（末段书 `名。测试`），以供试与脚本。
