# 林纳命令对照

豫言操作系统惟一壳：开机之壳、桌面之终端、ssh 远程登录，与 macOS、Linux 上之 `豫构 交互`，所行之句皆同。壳中所入，句句皆豫言之程，先编为机器之码而后行之；命即库函，合数库函即成新句之程。此篇列林纳常用之命于豫言壳中之书法，每句皆经豫构逐句编而核之。

## 书法要略

- 字串书为 `『…』`，整数书以汉字之数，如 `「一二」`。
- 参以 `于` 引之；签名有标签之参书为 `于「标签」曰 值`，如 `「辍役」于「号」曰「一二」`。
- 无参之命径书其名，如 `「问津」`。
- 一行可书数句，以 `。` 分之。
- 句之值为数、为文、为列，则壳印之：`「计」以「文」于（「藏书」之「列目」于『.』）` 印今目录条目之数。
- 「案牍」之「阅」之类，径印其果；欲取其果而续算，则用「藏书」之「阅」（文件之文）、「藏书」之「列目」（目录之条）、「藏书」之「所居」（今目录）诸返值之库函。
- 标 ★ 者，于豫言操作系统中用之，资系统之设备接口或远程登录之程。

## 文件与目录

| 林纳 | 豫言 | 注 |
| --- | --- | --- |
| `pwd` | `「案牍」之「所居」` | 印今目录 |
| `cd /数据` | `「案牍」之「迁」于『/数据』` | |
| `ls /数据` | `「案牍」之「列目」于『/数据』` | |
| `cat 卷.txt` | `「案牍」之「阅」于『卷.txt』` | |
| `echo 文字 > 卷.txt` | `「案牍」之「著」于『卷.txt』于『文字』` | 新建或截而书之 |
| `echo 文字 >> 卷.txt` | `「案牍」之「续著」于『卷.txt』于『文字』` | 续书于末 |
| `cp 甲 乙` | `「案牍」之「摹」于『甲』于『乙』` | |
| `mv 甲 乙` | `「案牍」之「徙」于『甲』于『乙』` | |
| `mkdir 目录` | `「案牍」之「置箧」于『目录』` | |
| `rm 卷.txt` | `「案牍」之「焚」于『卷.txt』` | 删文件或空目录 |
| `find /源 -name '*。豫'` | `「寻卷」于「模式」曰『*。豫』于「路径」曰『/源』` | 通配 `*`、`?`、`[…]`，`**` 跨目录 |
| `diff 甲 乙` | `「校勘」于「旧」曰『甲』于「新」曰『乙』` | |
| `sha256sum 卷.txt` | `「沙二五六」于『卷.txt』` | |
| `curl -o 页.html 网址` | `「索书」于「网址」曰『https://yuyan-lang.org/』于「文件」曰『页.html』` | |
| `tar xzf 包.tar.gz -C 目录` | `「解档」于「档」曰『包.tar.gz』于「目录」曰『目录』` | 识 .tar、.tar.gz、.tgz、.zip |

## 文字

| `head -n 80 卷.txt` | `「读行」于「文件」曰『卷.txt』于「起」曰「一」于「止」曰「八零」` | 附行号 |
| `sed -i 's/旧文/新文/g' 卷.txt` | `「全易」于「文件」曰『卷.txt』于「旧」曰『旧文』于「新」曰『新文』` | 「易」易其独一处 |
| `wc -c 卷.txt` | `「计文字节」于（「藏书」之「阅」于『卷.txt』）` | 印字节之数 |
| `echo 文字` | `「复述」于『文字』` | |

## 合为一句

| 林纳 | 豫言 | 注 |
| --- | --- | --- |
| `命令一; 命令二` | `「案牍」之「置箧」于『新目录』。「案牍」之「迁」于『新目录』` | 以 `。` 分之 |
| `echo "$(pwd)"` | `「复述」于（「藏书」之「所居」于「元」）` | `$(…)` 书为括中之子式 |
| `x=3; echo $((x*2))` | `令「甲」为「三」而「甲」乘「二」` | 印 `「六」` |
| `ls \| wc -l` | `「计」以「文」于（「藏书」之「列目」于『.』）` | 管道书为函之相嵌 |
| `ls \| grep 词` | `「择」以「文」于（得「名」而「文含」于『词』于「名」）于（「藏书」之「列目」于『.』）` | |
| `cat 甲 乙 > 丙` | `「案牍」之「著」于『丙』于（（「藏书」之「阅」于『甲』）接（「藏书」之「阅」于『乙』））` | |
| `[ -e 卷.txt ] && echo 有` | `若「藏书」之「实有」于『卷.txt』则「复述」于『有』否则「元」` | |
