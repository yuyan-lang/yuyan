# 源码树浏览器

发布可用“构建源码 源码目录 输出目录”，惟览所命之根，饰文取于当前目录。循词着色，不待包籍，语未成亦可阅。先收目录与书径，逐书读取而成饰页，不尽蓄诸页于内存。一书一页，首页惟载首选之书。页惟 HTML 与 CSS：成页之时即标所阅之书、展其所在之目、定其永久之链；页首二单选易汉文界面之辞，源码存其本，每页始以汉语。旧单页之锚（`index.html#源码-N`）转至其页，俟诸后版。发布者先依包界备副本，不混所依；旧“构建”之令不改。

生成可浏览的源码静态网站。
