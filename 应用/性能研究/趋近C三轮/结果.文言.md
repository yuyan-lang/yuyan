# 三察提速之余地

九月十九日，复察排序。今未可谓至极；然所得乃特定产物之试，未入编译器，不改公用入口。

同机同引擎，以倒序百万、四百万数试之。各五进程，每进程六行，首行别录，余二十五取中；次组反其先后，计时不并行构建。百万项，旧产物二十二点五九六毫秒，新试十八点三二零，C 网页七点九一八。四百万项，旧九十七点八零七，新七十八点九六七，C 三十三点七零九。新试省时约十九分之一百，然犹耗 C 之二点三四倍。不可由一术谓全语言皆然。

先分别省入口包装、索引截断前之检、大整数之解。各得小益，诸样范围相交；合之虽益显，或改负数、大索引、大整数及异常之义，故不得径用。引擎本有数组界检未除。

诸试皆补编译所得之网页汇编。私克隆填充、分区、排序诸函，使本例局部数组行其中；此非已成逃逸分析。直入者或先解枢轴，构造者但受本例合法长度，故推广须证其类型、范围、别名及异常先后，不能证则循旧途。

九变体各试一、二、一百二十八、百万项，每六行，逐一验其排序，共二百一十六行。旧版、裸值、裸联又验大整数与负整数，共一百零八行。皆通过。此限所造倒序之数，未遍随机、重值、逃逸与异常之境；验序代码不入计时产物。原始数、补丁与摘要俱存。

本轮未改编译器。复以其自举，禁编译缓存，新进程十八工并行，八百七十一事，墙钟十九点零六秒，所得与种子逐字节同，仍合三十秒之约。此单次复验，非排序试验之功；前轮三次中位十八点六九秒，不因本试更之。所谓冷者不清系统文件缓存。
