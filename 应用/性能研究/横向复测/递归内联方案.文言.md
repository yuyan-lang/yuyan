# 递归内联方案

此单层间接内联后之第二阶段实验方案也。五轮冷编之比已毕：AOT 中位数 239.53 秒，节点 193.47 秒，产物皆同，AOT 犹慢约 23.81%。节点于同冻结函数一二零五之呼序三择函数一二零五，续展自递归；今原生之作略自身，亦毋展内联体中之呼。全构之比仍在行，此方案尚未作。

仍已许之 `--内联样本` 与旧 JSON 字段，毋增公共 ABI、对象布局、命令行参或兼容层。冻结样本拟录函数一二零五呼序一至一四九四，及呼序三至一二零五；原令调查已验后者为类型三之间接尾呼，自身之型亦须复验。

各原呼者共新增展开字节预算六千，展深上限六十四。每展依被呼者原令段之字节数扣预算，预算或深尽则存旧呼。目标守卫、验空与验签仍存；首阶段拒旧异常与尝试表目标之令仍旧。内联体中合旧小函规则之直接叶呼可展，亦计同一预算。无样本者仍旧途。

以当函号、原呼序、局映基与尾态为各层展开之境：入被呼体则存呼者之态，易为被呼函号，自原呼序零始；终乃复之。新层仍旧块临、控制栈与事实栈。内联体中之尾呼，于守卫分支毕后须跳出最近内联层；唯原函之境可径返。毋仍用越过呼者后续之码之裸返。

验须及递归之合与预算尽之退、他目标、呼序之复、局映之复、内层尾呼后外层续算、多果、异常之捕、空与错签、回收存活压力。又验无样本产物与首阶段同。冻结编译器须经冷编产物之对，乃作同机更番测速与全构之比，节点仍默认策略。若码膨与寄存器之压抵其益，存实验之果而易方案，未证之候选毋合。

此扩首阶段单层之能。用户于此会话明言「允许调整」，已许循上策进。今已作共预算、逐层境之存复、内层尾呼退出最近层；尚未并参数事实转存。

备用机生成器毕七零一构建事，退出零。上下文测试毕四二一构建事，运行退出零，验二层函号、呼序、局映与深之复，预算累扣、恰足、不足与深之尽；递展之尾态恒退出最近块。标准网页汇编回收运行夹具工具毕三二六构建事，造四常呼与尾呼模块，各以零与一二八填充令触深与预算之尽。各模递归八十次，外层仍续加七，且循同呼处呼他目标；Node 与备用机 AOT 四者皆退出零。分派函之实机器码各有六四与四零个目标一之守卫，证已展而限尽乃退。主机生成器方构；异常、多果、回收与冻结编译器及正式性能犹待复验。
