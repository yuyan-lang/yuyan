# 递归内联方案

此单层间接内联后之第二阶段实验方案也。单层五轮冷编之比，AOT 中位数 239.53 秒，节点 193.47 秒，产物皆同，AOT 慢约 23.81%；单层全构 1060.42 对 821.65 秒，产物同，AOT 慢约 29.06%。节点于冻结函一二零五之呼序三择函一二零五，续展自递归。下录递归之策及所作之验。

仍已许之 `--内联样本` 与旧 JSON 字段，毋增公共 ABI、对象布局、命令行参或兼容层。冻结样本拟录函数一二零五呼序一至一四九四，及呼序三至一二零五；原令调查已验后者为类型三之间接尾呼，自身之型亦须复验。

各原呼者共新增展开字节预算六千，展深上限六十四。每展依被呼者原令段之字节数扣预算，预算或深尽则存旧呼。目标守卫、验空与验签仍存；首阶段拒旧异常与尝试表目标之令仍旧。内联体中合旧小函规则之直接叶呼可展，亦计同一预算。无样本者仍旧途。

以当函号、原呼序、局映基与尾态为各层展开之境：入被呼体则存呼者之态，易为被呼函号，自原呼序零始；终乃复之。新层仍旧块临、控制栈与事实栈。内联体中之尾呼，于守卫分支毕后须跳出最近内联层；唯原函之境可径返。毋仍用越过呼者后续之码之裸返。

验须及递归之合与预算尽之退、他目标、呼序之复、局映之复、内层尾呼后外层续算、多果、异常之捕、空与错签、回收存活压力。又验无样本产物与首阶段同。冻结编译器须经冷编产物之对，乃作同机更番测速与全构之比，节点仍默认策略。若码膨与寄存器之压抵其益，存实验之果而易方案，未证之候选毋合。

此扩首阶段单层之能。用户于此会话明言「允许调整」，已许循上策进。今已作共预算、逐层境之存复、内层尾呼退出最近层；已并参数事实转存，入各层清来路之记，出则复呼者之记，所记局号依今层而映。

三参转存已依原读器验：函一二零五之型三，参三、果一；呼序三在字节位一七五九一九，为 `return_call_indirect 3 0`，此前次读局一二、一四、一六、一三，继作 i31 转与无号取值。近七实令辨二或三参，传事实毋定写此诸局号。主机参测试与来路测试各毕四二一事、运行退出零，最终生成器毕七零一事。三参标准网页汇编回收八用例，Node 二常者退出零、六陷者退出一；AOT 常途与他目标之退退出零，错型与空引用退出一三五、越界退出一二七，皆报旧误。

最终生成器 SHA256 为 c2300c4d315724fe9c362c1135644ef05e3fd78c70aabf3cbb6ec253ad2f2aeb。冻结客体与执行器仍为 fc45ba2a…、c8ef4b7c…；二呼处之样本所造原生编译器 SHA256 为 559ac0690993c621460adedf3a2c5693faf17815275c5f6b6d38988df8e1f99d，大小二六六四六五六零字节。实 `客:f947` 有十八目标一四九四之守卫及十八自身一二零五之守卫；栈帧为 0x1520，即五四零八字节。一冻结冷编退出零，产物与旧 Node 基准逐字同，然耗三零零点六一秒，未入正式五轮及全构之比。此一退及帧之长，须先易码之序与寄存器之压，乃正式复测；未可称递归之速进。

备用机生成器毕七零一构建事，退出零。上下文测试毕四二一构建事，运行退出零，验二层函号、呼序、局映与深之复，预算累扣、恰足、不足与深之尽；递展之尾态恒退出最近块。标准网页汇编回收运行夹具工具毕三二六构建事，造四常呼与尾呼模块，各以零与一二八填充令触深与预算之尽。各模递归八十次，外层仍续加七，且循同呼处呼他目标；Node 与备用机 AOT 四者皆退出零。分派函之实机器码各有六四与四零个目标一之守卫，证已展而限尽乃退。主机生成器方构；异常、多果、回收与冻结编译器及正式性能犹待复验。
