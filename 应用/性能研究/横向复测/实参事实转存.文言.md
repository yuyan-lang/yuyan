# 实参事实转存

此为旧单层守卫内联之参数事实转存实验，毋易公共 ABI、对象布局、样本字段与命令行参。

冻结编译器函一二零五之呼序一，原令次读局八、局一与局九，乃转局九为 i31 而无号取之，经型二之间接呼入函一四九四。实转入口之快照有局八型十八之事实；守卫抄参于块临，复抄于被呼之参，旧途未传事实，故被呼体复验同型。

所改唯于有样本之原函记近六实令，依读器之界辨二参之读与函号之读、i31 转及无号取值。他形仍为未知之源；旧窥视若吞余令，则清其记。抄参唯传型与非空，长、界与对象头缓存毋传。

备用机语义测试构建毕四二一事，执行退出零而印「参数事实测试通过」。验及具体型、i31、非空、旧目的事实之删、他局之存、长界缓存之拒、多字节局号、错参数数、有号取值、杂令、内联之境与采集之闭。主机原生生成器毕七零一事，退出零。

pit-mac 冻结候选 SHA256 为 275c89a189b3def92f29cbbcb215c0ee2c3045ba004457166e160fc4436391e5，大小二六五九七零二四字节。实 `客:f947` 目标守卫合后，重复空验、对象标签及型十八之较已去，数组界验仍存；全段汇编自八零六行减为七五八行。一冷编耗二三六点零五秒，退出零，产物与旧 Node 轮逐字同。此为一验，未可据旧中位数称其益。

主机标准网页汇编回收抄参夹具工具毕三二六事，退出零。已证与未知源之常数组途，Node 与 AOT 皆退出零，且验同呼处之目标合与他目标之退；四错型与空引用，Node 报型转陷阱，AOT 退出一三五而报「类型转换失败」；二越界，Node 报数组越界，AOT 退出一二七而报「数组索引越界」。退出码合转译器旧致命码。无样本常呼夹具与旧单层生成器之机器文件逐字同，运行退出零。正式更番测速与全构之比犹待毕。
