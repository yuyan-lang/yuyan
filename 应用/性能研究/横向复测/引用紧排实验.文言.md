# 引用紧排之试

二〇二六年十月四日，用户许更堆内对象之约。别立工作树「原生引用紧排」，以结构头复用候选 5cdd23f1d 为本。执行器与 AOT 生成器须俱重造。

结构头仍八字节，惟引用字段由八缩四，余字段暂仍八；八字节字段以八对齐，对象总长亦然。三引用之结构由三十二缩为二十四。值栈与数组之约如故。

已察执行器之结构元数据，每字段记一类别字节。结构总长、字段偏址、新建与默认新建、字段读写、回收之引用扫描、宿主造结构、生成器之字段偏址与内联分配，皆须同改。八字节字段之对齐须守继承前缀，毋以父型末尾之填充为子型字段之始。

验之次序：杂引用与八字节数值、继承字段、宿主装箱、强制回收、冷编打印、全构建。终于 pit-mac 用冻结之客体编译器，禁读缓存，校产物逐字节，互易 Node 与 AOT 先后。

位图缓存候选 b6040fbc3 全构建今已毕：real 一〇八一点二〇秒，user 五六八〇点四八秒，sys 三〇二点五二秒；产物 SHA256 为 fc45ba2a749d766aed1c9dcae26a856bda40fdb5edc83bb18b625385f4bb496b。较结构头候选一〇五一点五三秒为迟，故紧排不以之为本。一轮之差，未足证独立优化之效。

今已更执行器之结构总长、对齐、字段读写与回收扫描；第二版 AOT 之内联分配、普通字段访问与变体标签窥孔亦同更。第一版 AOT 之结构读取循既有执行器 GC 之径。宿主之大整、浮点、外资皆单字段结构，其首址仍八字节，旧写址可存。

生成器入口及所依三百九十七项类型检查皆过。执行器初验见底层除法名误，改用底层库实有之「无符号除」；再验执行器入口及所依二百二十项，皆过。今重造执行器与生成器之全套。布局运行与性能未验，不得据此断其义正或其效优。

初造全套已成。pit-mac 冻结打印探针以新布局生成，出「你好，豫言」。冻结编译器亦成，然启时报导入未连：此基线早于已入上游之摘要原语。今取 c10a4894e 之主机、带型名、构建摘要及双语说明，重造执行器；沿用前已许之原语百十二、百十三。

摘要原语补齐后，执行器造毕，其 SHA256 为 c8ef4b7c6ffc625aff610fbf0fc049740be8756dd074adfba75d872d781f6120。pit-mac 以之造冻结编译器，已始冷编诊断。复察 struct.set 引用类别仍用带偏之八字节书，今易四字节书以免侵邻字段，正验并造「yy紧排生成器二.wasm」。旧生成器所造候选惟供诊断，耗时不入正式性能之证。

修正版生成器三百九十七项类型检查、六百六十一项构建皆过，其 SHA256 为 8fde63b819f7725ed8fad98b175c51275ceaa25a773d14b9d0898b13d90214c7。旧诊断候选之冷编果与冻结 Node 之果逐字同，SHA256 为 cd7cfebcf93c057b2d0207397682cdfee5d50b928299c2ec451ac73053a94e54。修正版于 pit-mac 正造原生编译器，继温机一轮、正测五轮；奇轮 AOT 先，偶轮 Node 先，每轮别目录、禁读缓存、校果。正式结果未齐，全构建亦未验。

修正版原生编译器造毕，其 SHA256 为 0c94fc3733c326887c565f2c40e2643a80888934cb44c81ad47cba4c55bf992a，六轮之试已入 AOT 温机。备用本机之引用链分配压力探针过：留五万项链，四十轮各造百万项暂链而验其和，终复读所留；原生与 Node 皆出 1249975000，逐字同。原生 peak memory footprint 为 1180730736 字节。此验分配之压下链犹正，未直接见 GC 之呼，不得断其已验强制回收。今备冻结豫构客体之原生程序，俟全构建之测。

温机轮之果逐字同，Node 一九五点三七秒、AOT 二四四点三〇秒；温机不入正式中位数，正测第一轮已始。配套原生豫构 SHA256 为 14c6d624d97658a6403692c55a648f821f7f92392e8c03b57d81e03274bf1e66，已送 pit-mac。备用本机别造标准 WasmGC 夹具：父结构一引用，子继之而添引用与宽整；新约字段之偏为八、十二、十六，总长二十四。易首引后，验邻引为九、宽整为百二十三、经父型读首引为十五。Node 与第二版 AOT 皆零退出，断言过；解释与初版 AOT 正验。

解释器与初版 AOT 亦以同夹具零退出，四执行之径皆过布局断言。正测第一轮 AOT 毕，二四三点七一秒；所配 Node 轮尚行，未计正式之差。复察源码，对象字段皆用紧排之偏，余八字节步长属值栈或数组之径。

六轮互易先后之冷编零退出，温机及正测五轮之果皆逐字同。正测 Node 一九三点八八、一九三点四六、一九三点八二、一九四点一七、一九三点五二秒，中位一九三点八二；AOT 二四三点七一、二四四点三六、二四三点六八、二四三点八九、二四三点七〇秒，中位二四三点七一，犹迟百分之二十五点七四。较前候选中位二四六点二四秒低，然异批约百分之一之差，未足独证紧排之效。追平之志未达。

今于 pit-mac 始紧排全构建：冻结源码 e7300b7910901600d2e7ed592dd838c77d10bd60，配套原生豫构与候选编译器，二十四任务并行，明禁读缓存，果置 ~/wp8-scratch/yy紧排完整，毕则与冻结 Node 之果校之。全构建之果尚待取。
