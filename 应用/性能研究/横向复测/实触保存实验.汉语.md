# 实触保存实验

这是基于相邻写入提交 3cb4690c6 的隔离优化候选。ARM64 宽函数在降级时记录经「物寄」实际访问的虚拟栈寄存器，仅保存这些寄存器。含数值码的函数保留原集合，局部寄存器保存规则保持原样；栈帧大小、局部偏移及调用约定保持原样。

虚拟栈使用 x19 至 x22，局部使用 x23、x24、x26、x27。入帧与出帧依同一保存列表生成，固定预留保存区，故删除未访问项不改变局部地址。预期减少别名优化后仍按最大栈深生成的多余保存与恢复。排版、类型检查、产物核对与性能尚待验证，未据此宣称收益。

排版与差异复核已完成，原生生成入口及依赖的 403 项类型检查、671 项构建任务均退出零。冻结编译器原生生成已启动，运行结果与性能仍待验证。
