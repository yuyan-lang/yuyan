# ABI 调整授权

用户已于 2026-10-05 在本会话明确授权：「允许少量修改ABI如果这个能使AOT速度更快的话」。此授权用于现有长期目标：在 pit-mac 以同机、同源码的冷编打印和完整构建基准，使原生 AOT 达到或超过 Node，且产物一致；本机为备用。

后续可以实施有具体性能依据的少量 ABI 调整。每项调整仍须记录实际改变、运行语义及产物对照，并在同机基准确认收益。当前尚未因此授权实施新的 ABI 改动。

当前递归候选的热点函数展开十八层、帧为 5408 字节；原排列单次冷编 300.61 秒，末目标守卫倒序单次 289.66 秒，二者产物均与既有 Node 基准相同。帧大小尚未下降，正式五轮和完整构建比较未启动。先调查静态槽位与尾递归复用，再根据实际瓶颈决定是否需要 ABI 调整。
