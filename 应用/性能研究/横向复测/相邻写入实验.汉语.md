# 相邻写入实验

候选基于常量打包提交 36a647d4a，独立于工作树「原生相邻写入」。真实汇编存在连续的「ADD x11, x源, #偏；STR w甲, [x28,x11]；ADD x11, x源, #偏加四；STR w乙, [x28,x11]」。本候选改为三条：以保留临时 x12 求物理地址，成对写入两个相邻四字节值，再重发原第二个 ADD，保持 x11 的最终值及标志寄存器。

匹配仅在 ARM64 宽函数的生成代码体中进行，四个片都必须是四字节原始指令。标号、重定位、非四字节原始片均阻止匹配；源、值不能用 x11 或 x12，源不能是 sp，偏移限四字节对齐的零至 252。原内存写入模板本身没有中间检查或调用。使用既有临时寄存器约定，不增加 ABI 或堆布局。未通过验证前不采用候选。

源码已写入并接入函数体，正在排版，类型、真实机器编码、产物与性能均未验证。pit-mac 继续独占运行常量打包六轮对照，本机只准备下一候选。

排版、差异复核通过。首次类型检查发现比较辅助函数的导入遗漏，补入降级公用后，原生生成器入口及依赖的 403 项类型检查、671 项构建任务通过。生成器 SHA256 为 4d6350bc3c43fb7d38cb8228ddd99eccce600938c329443e30c93ed497028df4。备用本机的标准 WasmGC 四引用数组夹具先在 Node 通过，再经新生成器生成的 AOT 通过；反汇编确认实际执行两条 STP w 指令，分别写入偏移 16、20 与 24、28，原 x11 最终偏移 20、28 的 ADD 保留。继承结构与相邻引用、i64 混合字段夹具也退出零。正在备用本机生成冻结编译器客体，尚未验证完整冷编产物或性能。
