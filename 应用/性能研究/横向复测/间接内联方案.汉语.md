# 间接内联方案

这是根据同一冻结客体的 Node 内联跟踪提出的原生优化方案。客体 SHA256 为 fc45ba2a749d766aed1c9dcae26a856bda40fdb5edc83bb18b625385f4bb496b。Node 在函数 1205（f947）调用序 1 的多态调用中选择函数 1494，观测相对调用频率约 97.56%，函数体 79 字节；它还展开了该函数的自递归调用。此前扩大直接内联限额没有覆盖这个间接调用目标。

第一阶段仅实现带目标守卫的单层间接调用内联，自递归展开留待单层结果确认后。拟新增生成器可选参数 `--内联样本 文件`，读取普通 JSON 数据：客体 SHA256 及调用者函数号、原始 Wasm 调用序号、被调函数号列表。函数号按原模块含导入的索引计；调用序号按原始调用指令计，须对照实际字节复核，禁止按调试名称猜索引。样本不匹配客体时跳过此优化。

生成时核对被调函数存在、签名适合调用点、函数体可用既有内联路径处理。保留原函数引用判空与签名验证。在调用点比较实际函数号：匹配已选目标时复用直接内联的参数暂存、局部映射、控制栈及结果处理；不匹配时执行现有间接调用。保留异常传播与 GC 根保存规则。公共调用 ABI、对象布局和 Wasm 编译产物语义不变。未提供样本时沿用现有生成路径。

验证须覆盖目标命中、其他目标回退、判空与签名失败、普通调用与尾调用、多个结果和异常控制；旧式异常或不能复用的函数先跳过，不增加兼容层。之后运行既有结构、存活压力、标签夹具及冻结冷编产物对照；有收益才继续完整构建同机比较。Node 基线保持默认策略，跟踪诊断耗时不纳入性能结论。

本方案包含生成器新增读取样本能力，按本仓“新增功能、ABI、兼容层前先问”的指令，已向用户说明并取得“允许调整”的授权。授权范围是本方案的单层目标守卫内联及可选样本参数；公共 ABI 与对象布局保持不变。参数、样本读取或间接内联尚未实现，后续按上述验证要求推进。

只读函数号调查 341 项构建及运行退出零，已确认函数 1494 的名字字节为 102 49 50 50 55，即 f1227；类型号 2，签名字节 96 2 109 109 1 109。其指令段长 72 字节，另有局部声明，与 Node 记录的 79 字节函数体一致。原指令包含闭包捕获数组读取、i31 或盒装 i64 索引转换、无号 32 位范围检查及数组取值，没有直接调用；适合优先评估单层展开。曾按名称数字推测的 f1236 实际是函数 1503，故实现必须使用校准后的原模块索引，禁止按名字推算。
