# 相邻写入实验

候选本于常量打包 36a647d4a，独置「原生相邻写入」工作树。实汇编有四令相继：加偏入 x11、书甲四字节、加邻偏入 x11、书乙四字节。今代以三令：借保留临寄 x12 求物理址，成对书邻四字节之二值，复发原次加，x11 末值及标志寄存器如旧。

唯于 ARM64 宽函所生之代码体合之，四片皆须四字节原令。标、重定位及异长原片皆断其合；源、值毋居 x11、x12，源毋为 sp，偏唯四字节齐之零至二五二。原书存模板无间验及呼。循既有临寄之约，不增 ABI，不易堆局。未验则不用。

源码已入而接函体，正排版；型、实机器编码、产物与速皆未验。pit-mac 独行常量打包六轮对照，本机唯备后候选。

排版及差异之校皆毕。初验型得比较辅助之导入遗漏，补降级公用后，原生生成器入口及所依之型四〇三事、构建六七一事皆成。生成器 SHA256 为 4d6350bc3c43fb7d38cb8228ddd99eccce600938c329443e30c93ed497028df4。备用本机之标准 WasmGC 四引用数组夹具先行于 Node 而成，再以新生成器造 AOT 行之亦成；反汇编得实用二 STP w，书偏一六、二〇及二四、二八，x11 末偏二〇、二八之 ADD 仍存。继承结构、邻引用与 i64 混合字段之夹具亦零退出。备用本机正造冻结编译器客体，全冷编果及速未验。

冻结编译器原生生成及启动之验已零退出，SHA256 为 7481cf9951bbfef1aacf68241d3fade6e7807b5fb057257209d0dc262ab1a135，文件二六六四六五六〇字节，较常量打包候选少四九五三六字节。大热点 f947、f933、f904 无新成对书，次热点组有一处；未可以文件之小推全速之益。已于备用本机 /private/tmp/yy相邻写入冷编 用冻结上下文、别编译器之径、禁读缓存校冷编果，事未毕。pit-mac 仍行原候选之交替基准，未并增测速。

备用本机冷编之校今零退出，果与冻结 Node 逐字同，SHA256 为 cd7cfebcf93c057b2d0207397682cdfee5d50b928299c2ec451ac73053a94e54。实耗一九五点〇九秒、用户一八六点五七秒、系统二点五八秒，唯为本机验义，毋与 pit-mac 之时混较。新成对书实居 chars 返对象之初置：偏一六、二〇书 w6、w14，后存原 x11 末偏二〇之 ADD。同步 Git 包已备，候主测试机今基准之毕而传送正测；速之益未定。

欲减生成之扫描耗，先验首令 ADD x11 之字节前缀，合者乃解后三令；合之条件及所代之果如旧。改后排版、入口及所依之型四〇三事、构建六七一事皆成，新生成器 SHA256 为 47247ca2690525cf5e6b068daccea17ee1240f05468cd809c3c43c563d1433e9。复造同一冻结编译器，与前候选逐字同，SHA256 仍为 7481cf9951bbfef1aacf68241d3fade6e7807b5fb057257209d0dc262ab1a135，故前夹具及冷编校果所验者为同一可执行文件。主机正测仍候今基准之毕。
