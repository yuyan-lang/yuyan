# 间接内联方案

此据同一冻结客体之节点内联跟踪而拟之原生优化也。客体 SHA256 为 fc45ba2a749d766aed1c9dcae26a856bda40fdb5edc83bb18b625385f4bb496b。节点于函数 1205（f947）调用序一之多态呼，择函数 1494，相对调用频率约 97.56%，体七十九字节；又展其自递归之呼。前宽直接内联之限，未及此间接之目标。

首阶段唯作带目标守卫之单层间接内联，自递归之展待首阶段之果而定。拟增生成器可选参 `--内联样本 文件`，读普通 JSON 数据：客体 SHA256 与调用者函数号、原网页汇编调用序号、被调函数号之列。函号依原模块含导入之序计；调用序依原调用之令计，须据实字节复核，毋因调试名猜其号。样本不合客体者，略此优化。

生成时验被调函实存、签名合调用处、体可循旧内联之途。函数引用之判空与验签仍旧。于调用处比实函数号，合所选目标者用旧直接内联之参数暂存、局部映射、控制栈与结果处置；不合者循旧间接呼。异常之传与 GC 根之保皆存。公共调用 ABI、对象布局及网页汇编产物之义不变。无样本者循旧生成之途。

验须及目标合、异目标之回退、空与签之败、常呼与尾呼、多结果及异常控制；旧异常及不可循旧内联者先略，毋增兼容层。继验旧结构、存活压力、标签夹具与冻结冷编产物之对；有益乃复测同机全构。节点之基仍默认策略，跟踪诊断之耗时毋入性能之论。

此方案增生成器读取样本之能，依本仓“新增功能、ABI、兼容层前先问”之令，已告用户，得“允许调整”之授权。所许为此方案之单层目标守卫内联与可选样本参；公共 ABI 与对象布局仍旧。参数、样本之读与间接内联尚未作，后循上列之验而进。

只读函号调查三百四十一项构建与运行退零，已验函数 1494 名字节为 102 49 50 50 55，即 f1227；类型号二，签名字节 96 2 109 109 1 109。其指令段七十二字节，另有局部声明，与节点所录七十九字节之体相合。原令及闭包所藏数组之读、i31 或盒装 i64 索引之转、无号三十二位之界检与数组取值，无直接呼；可先察单层之展。前依名字数字推 f1236，实为函数 1503，故实现须用校准之原模块索引，毋据名推号。

样本读取之模与测试已书于「裸机后端」，依旧「结森工具」，毋自造解析之语。数据字段曰「客体摘要」与「调用点」；每呼处含「调用者」「调用序」及「目标」之数组。摘要不合或无呼处者返空列，同名唯取首，负号与非整数之目标皆滤之。源码已排，测试之构正在行；未接命令行、算客体摘要或展机器之呼，毋据此称内联已成。

继已书生成器 `--内联样本` 之参与 SHA-256 摘要之验。每生之前清配置，有样本者唯算客体摘要一次，不合则仍空。新增之验及实 abc 摘要之合、abcd 之拒与配置之清。首构因测试误用整数表示之术败，已易逐项之比，并依令去并行而复行；今复核未毕，机器之呼之展尚未作。

串行之诊又见摘要表示误用他模私有「整数余数」，已易减与乘；新验补「字节串」之直接导入。读器与摘要之码已过类型检查之阶段，全测试之构与行犹待定。同一编译器缓存唯行一构，仍循今复核会话而察。

样本测试串行编译退零，行报「内联样本测试通过」，退零。读取、摘要之合与拒及配置之清已验；生成器入口及所依之类型检查已起，未毕。此唯证样本配置之途，目标守卫、呼之展与性能之验犹待作。

目标守卫之展开源码今已书。原呼之序于转原函时依调用令计，内联体毋改其序；间接呼循旧途验后，合样本目标者借独立块临存函号与实参，循旧局映、内联控制层与异常途而展；不合则复旧呼。目标须本模定义、同型号、非自身且旧转译器可处，样本目标体限六千字节，旧径内联仍六十字节。条件层合后处尾返，控制与事实栈同护。源码已排，型、生与语义之验未毕。
