# ANF 直生 Wasm GC 之验

已作可行原型：取既有闭包树，经既有 ANF，直书 WAT。所生模块无 memory、无 import。然未具完整编译器所需诸义，尚无此后端之自举时间，不可许全面迁移无损其速。

现有 ANF 顶层末又作 CPS，今直生绕之。常调用用 Wasm 栈，尾调用用 return_call_indirect；末虑唯还调用之值，须复其尾位。小整 i31，大整 i64 struct，诸元组与闭包境为 GC array，构造器为标签 struct 加字段 array。引擎自持 globals、locals 与参数之根。

其费有由：类型已擦，通用值须解装；构造器多一标签对象；闭包表调用尚未专化。宜留类型与对象形状，整数直为 i64，具体 ADT 直作有字段之 struct，闭包持类型化函数引用。可捕之续延仍须自明其义，不可以常调用之栈充 call/cc 之全义。

二十四验皆过，含零数组、大整、i64 最小值与非法长度拒绝。未知外调、跨模块皆明拒；百万尾循环成。模块无内存及导入，再生之文逐字节同。直生工具亦单验。原录在《记录/》，生成之文在《生成/》。此为架构之试，非自举性能已证。
