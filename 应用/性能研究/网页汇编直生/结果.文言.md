# ANF 直生 Wasm GC 之验

已作可行原型：取既有闭包树，经既有 ANF，直书 WAT，交 Wasmtime 成码。不经 LLVM，不链 C 运行时，不设豫言线性内存虚栈。所生模块无 memory、无 import。然未具完整编译器所需诸义，尚无此后端之自举时间，不可许全面迁移无损其速。

M5 Pro、macOS arm64、Wasmtime 48.0.1。各暖一回，测三回，取中数；计启动、实例化、运行与退出，不计成码准备。手书 C 另为专型参照，非同编译器之异后端。

| 题 | 手书 C | 豫言原生 | 旧 LLVM/WASI | 直生 GC，复制，总初堆一百二十八 MiB |
| --- | ---: | ---: | ---: | ---: |
| 斐波那契三十五 | 0.0173 | 0.5424 | 3.7453 | 1.0228 |
| 深二十之树，建而求和 | 0.0433 | 0.1135 | 0.5265 | 1.3179 |
| 百万元素数组，填而求和 | 0.0035 | 0.0995 | 0.5578 | 0.2068 |

直生于旧器，递归快约三点六六倍，数组快约二点七零倍，树反缓约二点五零倍。于豫言原生，皆未及。C 短例多受启动之时，不可径推纯计算之比。

收集之法与初堆甚要。复制式默认堆之数组耗七点七零七秒，显定总初堆一百二十八 MiB，乃降至零点二零七秒。DRC 系显选引用计数，非称引擎默认；旧标签已正，时数未改。出处、全数与命令详汉语本。

现有 ANF 顶层末又作 CPS，今直生绕之。常调用用 Wasm 栈，尾调用用 return_call_indirect；末虑唯还调用之值，须复其尾位。小整 i31，大整 i64 struct，诸元组与闭包境为 GC array，构造器为标签 struct 加字段 array。旧 C 根登记不复需，引擎自持 globals、locals 与参数之根。

余缓有由：类型已擦，通用值须解装；构造器多一标签对象；闭包表调用尚未专化；原 LLVM 诸优化亦不自来。宜留类型与对象形状，整数直为 i64，具体 ADT 直作有字段之 struct，闭包持类型化函数引用。可捕之续延仍须自明其义，不可因弃虚栈而弃 call/cc。

两收集器及边界共二十四验皆过，含零数组、大整、i64 最小值与非法长度拒绝。未知外调、跨模块皆明拒；百万尾循环成。正用计时皆核其果，模块无内存及导入，再生之文逐字节同。

原生三级四级自举同，完整类型检查过。旧稳定首命令不识今包布局，复跑明诊，以今器经豫构成二级，其后循规定命令成之。直生工具亦单验。原录在《记录/》，生成之文在《生成/》。此为架构之试，非自举性能已证。
