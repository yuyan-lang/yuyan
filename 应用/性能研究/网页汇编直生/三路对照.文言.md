# 三器同目标自举之较

三器皆以同源串行编为 WasmGC 器。Cranelift 预编译之器两验为 301.77、226.91 秒，均 **264.34 秒**；V8 直载 Wasm 为 81.28、75.74 秒，均 **78.51 秒**；原生同目标为 117.49、107.78 秒，均 **112.64 秒**。今 V8 最速，原生次之，Cranelift 此路最迟。V8 较原生省时约 30.3%；Cranelift 费时为原生约 2.35 倍、V8 约 3.37 倍。

Cranelift 用 copying GC、二 GiB 初堆而开内联，AOT 已备；预备另费 78.32 秒，不入表。V8 用 Node 26.3.0，每验别立进程，延迟编译与分层优化之费入执行。其堆循默认，工栈一百二十八 MiB。原生亦生成 Wasm，非生成本机码。诸器各有 GC 与桥接之费，未分其功，不谓此倍数为引擎恒性。

第一组自 20:37:56 至 20:46:17，循 Cranelift、V8、原生之序，皆先于 20:46:52 合盖。初次反验受暗唤醒、休眠所扰，中断而弃其时。再开盖充电，21:10:21 至 21:17:40 循原生、V8、Cranelift 复验，其间无休眠。逐验刷新缓存之识，不锁频率，不齐堆上限；两验有波动，故并列而不择最好。

六物逐字同，亦同先前已验自举固定点之产物。原生生成本机码之前验为 306.12 秒，后端之功异，不混入此表。命令、原时与哈希，见《三路对照.汉语.md》及 `三路验证摘要.json`。今但增记录，不改编译器及宿主。
