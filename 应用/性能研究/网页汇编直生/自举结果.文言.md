## 所成与所费

后端在 `库/编译器核心/编译步骤/代码生成/网页汇编直生。豫`，目标 `--target=wasmgc`。直生 GC 引用、数组与结构体。文串字面量启动时一造；拼文、UTF-8 与 JSON 扫描行于客。宿主唯供系统原语与组装，不代客行编译之术。

为全异常与可捕获续延之义，非尾调用之余算托于 GC 续延对象，以尾调用复之。其分配、取域与装箱解箱之费犹在。元组与构造器之布局尚可专型化；并行亦尚有空阶段进程之费，最终 GC 生码则集于一进程。
