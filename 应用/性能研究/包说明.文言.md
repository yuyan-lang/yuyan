# 性能研究

保存编译器和运行时的性能研究程序。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包为库，可供他包所依。无默认程序入口，试例须明指其书。

在仓库之根行 `./yy豫构 检查 性能研究` 以验其籍。

所依与说明之径皆见[包籍](性能研究。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。

## 构建性能

`构建性能/` 存构建性能调查之方、[构建日志之式](构建性能/日志格式.文言.md)与诸报告；构建之志由豫构书之，以开发工具 `yy构建性能` 析之。

## 列表数组段

`列表数组段/` 存提案 00002 第八步之数组段列（VList）原型、单元之试与对照之基准，实测之论见[实测](列表数组段/实测.汉语.md)：未及易换之准，「列」仍守链表之表示。

## 测数

自二〇二六年九月二十六日，此包唯存报告与实验之源。诸测之数（日志、采样、剖析、补丁、摘要 JSON、WAT 片段等，凡二千七百九十二件，约六十九兆字节）皆删于版本库，须用则重测。

报告所链之数，于工作树已亡。欲得旧数，可依原径取诸 git 史：先以 `git log --diff-filter=D --format=%h -1 -- '应用/性能研究/<路径>'` 得删之之提交，再以 `git show '<其提交>^:应用/性能研究/<路径>'` 取其文。
