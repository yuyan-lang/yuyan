# 比 OCaml 之进境

二〇二六年九月十九日，此工作区实测：冷编译缓存之 Wasm 自举三行，得十八点一六、十八点三〇、十八点六八秒，皆少于三十。种子及后三代字节皆同。此冷者禁豫言编译缓存、重启引擎，非清操作系统页缓存也。

六题各取二等规模，各法三进程，每进程六行，首行别录。八百六十四行之结果值皆同，然排序与矩阵只验既定结果值，非遍验每一元素。详数、原始记录及复现之令见同名汉语篇。

小规模六题，豫言四胜 OCaml；大规模六题，三胜。递归、排序、树事两等皆胜；大筛素数费时为 OCaml 二点四五倍，大矩阵一点二三倍，大数组一点一三倍。排序虽胜 OCaml，犹约十倍于 C/WASI。故未可曰全语言已及 OCaml，更未可曰已及 C 或商用之验已成。

今所改者：闭递归立静态满参之工；续化函数头之虑而守求值之序；纯整之工以内 i64 行，外守通值之约；混合之工裸存整数与分支之果；入口有守卫与常途，未行之支不先强验其类；尾递回环，先备诸参而后存之；数组索引仍拒负数、截位与越界；构造器字面之叶可共，有引用或载荷别名者不共。数组守卫之独益未明，不独归功于此。

稳定编译器至原生四代依令自举，三四代同。原生与 Wasm 自检皆过。十五项 Wasm 回归输出合于所期，四项兼验原生；极值、回绕、泛型、异常、尾递换参、越界及可变物隔离皆有验。

后事首在数组之表示。宜增可变字节与 i64 专用数组，泛型之旧约不易，使用者自择；此涉公开库制，已请用户裁而未施行。若欲旧代码自得其利，则须于类型擦除前留元素之类，贯通分配、别名、读写与跨工调用，不可暗易分配而失诸处之约。

既定数组之制，再验安全范围证明、跨工满参调用及叶工内联，继以字符串、映射表、解析诸实务。今仅验此机 Node/V8 与原生 OCaml，别引擎及浏览器尚待。每改仍守自举三十秒之限，并拒生成程序显著退步；进程内之快，不可充冷启动之快。
