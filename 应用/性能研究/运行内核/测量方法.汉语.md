# 运行内核对照

此组实验把程序内算法耗时与启动开销分开。目标是判断生成程序的计算性能；它不能代替冷缓存自举的墙钟验收，也不能把少量基准概括为整门语言已经商用成熟。

六项算法来自既有跨语言对照：递归斐波那契、素数筛、整数矩阵乘法、逆序数组快速排序、满二叉树构造与求和、数组填充与求和。未为豫言更换算法。每个新进程运行六轮，保留第零轮，正式统计后五轮。计时包围完整算法调用，包含算法内部的数组或树分配；不包括宿主启动、模块初始化及结果打印。不强制 GC，因而 GC 暂停是否落入计时区间会造成波动。

最终复测每项每种实现使用三个新进程，共十五个正式样本；记录中间值及每个进程的中间值，避免只挑最快一轮。所有轮次的结果值须一致。源码、原始 CSV 与工具版本共同保留。

比较对象为豫言 WasmGC 与 OCaml 原生。OCaml 不是 Wasm 版本，两者也不是完全相同的运行时。OCaml 使用安全数组访问，未使用 `-unsafe`。筛选程序的 OCaml 使用字节标记数组，豫言使用通用引用数组。整数在本组输入中不溢出；语言各自的整数语义仍不同。

机器为 Apple M5 Pro（18 核、48 GB）；Node 26.3.0，V8 14.6.202.34-node.20；OCaml 5.5.0，`flambda: false`。本轮保持引擎默认优化设置。豫言使用 Node Worker，栈上限 128 MiB。

构建命令（包上下文编号按本地环境调整）：

```sh
ocamlopt -O3 -I /opt/homebrew/lib/ocaml -o yy内核OCaml 应用/性能研究/运行内核/单调钟.c 应用/性能研究/运行内核/原生内核.ml
node 应用/网页汇编/节点网页汇编宿主/宿主.cjs yy内核最终种子.wasm 应用/性能研究/运行内核/矩阵乘法。豫 --package-context .yybuild/豫构上下文/17.上下文 --target=wasmgc -c -o yy终核矩阵乘法.wasm
./yy内核OCaml 矩阵乘法 300
node 应用/网页汇编/节点网页汇编宿主/宿主.cjs yy终核矩阵乘法.wasm 300
```

文件名未带“最终复测”的 CSV 为开发过程中的首轮记录，不能混入最终版本统计。CSV 列依次为题目、进程内轮次、秒数、结果值。最终复测文件名额外记录规模、实现和进程序号。
