# 性能研究

保存编译器和运行时的性能研究程序。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 使用

在仓库根目录运行：

```sh
./yy豫构 检查 性能研究
```

依赖及说明路径以 [包配置](性能研究。包。豫) 为准。
