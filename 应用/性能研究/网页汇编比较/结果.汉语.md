# 豫言网页汇编与组件实测结果

编译器自举作为首要指标的后续实测见[自举评估](自举评估.汉语.md)。本页小程序倍数不能外推自举时间。

2026-09-07，美东。Apple M5 Pro，Wasmtime 48.0.1。方法和限制见[复现说明](复现说明.汉语.md)，迁移判断见[迁移评估](迁移评估.汉语.md)。对应文言本见《结果.文言.md》。

当前实现存在明确性能损失：五项中，预编译组件耗时是原生的 **2.28–3.64 倍**。组件与核心模块的耗时接近，主要差距已在核心 Wasm 执行路径中出现；本实验没有证明差距的单一成因，也没有测量频繁跨语言函数调用。

## 五轮中位数

单位：秒。所有方式都是新进程墙钟时间；预编译排除了 Wasmtime 编译阶段，仍包括进程启动和模块初始化。每组预热一轮，正式五轮；最小值、最大值见《结果.json》，原始样本见本目录六份 CSV。

| 工作负载 | 原生 | 核心预编译 | 组件预编译 | 组件／原生 | 核心即时编译 | 组件即时编译 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 斐波那契（35） | 1.197536 | 3.950989 | 3.855377 | 3.22× | 3.950086 | 3.931597 |
| 素数筛（1000000） | 0.152979 | 0.447518 | 0.456900 | 2.99× | 0.490572 | 0.495132 |
| 矩阵乘法（240） | 1.823786 | 6.384264 | 6.376124 | 3.50× | 6.393861 | 6.459978 |
| 快速排序（100000） | 0.217274 | 0.786381 | 0.791037 | 3.64× | 0.830596 | 0.838180 |
| 递归回收（100000） | 0.015171 | 0.034251 | 0.034522 | 2.28× | 0.072529 | 0.076026 |

回收测试较短，启动占比更高，不能把其倍数当成纯 GC 吞吐率。四个较长计算测试的组件／原生比为 2.99–3.64 倍。组件相对核心模块的中位耗时差约在 -2.42% 至 +2.10% 之间；这不是统计置信区间，也不能称为零开销。

## 启动与封装

零输入斐波那契输出 0，用于观察加载、运行时初始化、少量逻辑和输出的基线：

| 方式 | 中位耗时（毫秒） |
| --- | ---: |
| 原生 | 3.278 |
| 核心预编译 | 4.882 |
| 组件预编译 | 5.265 |
| 核心即时编译，禁缓存 | 44.724 |
| 组件即时编译，禁缓存 | 49.582 |

长计算中前置编译影响相对小，短任务中则很显著。AOT 或常驻组件宿主值得优先采用，但此表没有测量常驻宿主。

组件封装复用了同一批 Wasm 对象。以斐波那契为例，核心模块 1,408,093 字节，组件 1,453,511 字节，增加约 44.4 KiB。文件含调试信息，不是最小发布体积；其它产物大小及 SHA-256 见《构建记录.json》。

## 正确性与验证

六个输入场景 × 五种方式 × 六轮，共 180 个样本（含 30 个预热样本），均退出成功且输出与原生参照逐字节一致。每个场景另有一次原生参照执行，不列入样本数。

| 场景 | 输出 |
| --- | --- |
| 斐波那契 35 | 9227465 |
| 素数筛 1000000 | 78498 |
| 矩阵边长 240 | 52876840 |
| 排序 100000 | 150002 |
| 递归回收 100000 | 两行：100000、5000050000 |
| 启动输入 0 | 0 |

五个组件都经组件链接器严格校验，并在 Wasmtime 中执行。额外开启回收日志后，原生与组件各发生 7 次 GC，输出仍一致；日志另存《回收验证.json》，不计入时间。新增的两份豫言源码分别通过类型检查和编译。没有修改编译器语义，所以没有重新执行三阶段自举。

## 解释边界与下一步

本结果回答“当前这条迁移路径会怎样”，不能回答“Wasm 理论上必然慢多少”。原生是 LLVM 22 的全程序 O3/LTO，Wasm 是 LLVM 23 的逐模块 O2，再由 Cranelift 编译；编译器优化程度和后端都不同。显式栈、十六字节值拆解、间接尾调用、内存检查与跨模块优化不足是待测的原因，尚未以 profile 或对照实验确定各自贡献。

应先对齐 Wasm O3/LTO 与原生编译流程，再测调用与值表示；同时开发真正的 WIT 双向绑定。公开接口采用批量操作，先测同语言内部调用、跨组件标量调用、大小字符串／列表、资源句柄、异步调用的独立成本。此次命令组件只在启动、参数、I/O 等系统边界使用组件接口，算法内部没有反复跨组件，因此不能从“组件≈核心”推导“跨语言互调免费”。

现在适合将 Component Model 作为互操作方向，并继续保留原生性能基线；现有证据不支持直接删除原生后端。
