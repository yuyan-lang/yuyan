# 递归形态与尾参省略策略

进一步拆分排序回退：五进程各六轮，轮换版本，四百万元素校验和均为 6000002。当前单扫版首轮 57.674 ms / 热轮 46.377；复原整个旧递归体 56.869 / 44.676；保留邻接消除但复原旧尾参 55.761 / 44.607；只压缩尾参及其新形成的邻接临时值 57.811 / 46.652。最后一个原型也消除了尾参压缩后紧邻的 i19 搬运，不能将其描述成绝对孤立的尾参变量实验。

据此增加通用递归形态分析：发现静态非尾自调用时，暂不执行新加入的恒等尾参省略；邻接消除仍启用。纯尾递归循环不受影响。退出域与显式循环保守保留旧传递方式。该选择是基于实测的代码生成策略，不改变语言语义，不按算法名、函数编号或字节大小硬编码。已有双步扫描的参数推进规则保持原状。

五项形态测试通过，覆盖直接尾递归、递归后计算、其他函数调用、尾分支和非尾分支。编译器类型检查通过；种子已生成，实际排序主函数归一化空白后与仅邻接原型一致。一次六轮运行首轮 57.799 ms，其余 45.678、44.814、44.327、44.354、44.175 ms，全部校验和 6000002。此为初测，完整自举和正式回归、同期性能验证仍在进行。

后续线索：分区热循环中，先读扫描位得到 i6、进行整数比较，真分支又读同一位得到 i8，中间尚无写入。这提示可研究通用的局部读取复用：由支配关系、相同数组与索引、无中间别名写入或未知调用证明可用值；不能跨循环回边复用旧值。尚未实现或验证此项收益，不提前宣称可达到 C。

完整本机自举、三四代一致性及两项类型检查已通过。Wasm 冷缓存自举 22.45、22.87 秒，二三代产物一致。38 项运行回归通过；六核产物复核显示仅排序改变，其余五项与单扫版逐字节一致。原始记录见递归形态本机验证.json、形态运行回归.json、形态六核产物.json。
