# 栈公门与后备

今增《网页汇编栈入口》，依表示之证生公用引用门。数组须为首令，初与长取自整数常量或参数。先验所用之参，后解其装；未用环境不验，私体以零代之。

容量不足、长度负、逾六十四 MiB 或增长失败，则以原参尾调 GC 后备；类型未明亦然。成功则记长，遍置初值；零用 memory.fill，余以 i64 逐项写之。每次重置，不藏旧内容。整数归原装箱法，单元归空引用。

以 ANF 造创建与读取，私体及公门皆自动生成。正常与强制增长失败两夹具，共六百二十验皆过，涵盖极值、初值、空数组、越界、类型、容量、单元及陷阱后复用。失败夹具恒为零页，皆由 GC 成之；正常夹具至多两页，超容量不增其栈。详见《栈自动入口验证.json》。验型与 Wasm 实行皆过。

默认后端未接此门。尚须合整条调用图之封闭、不逸、无重入及无子数组分配诸证，乃可从零用帧。后当合资格与签名，接统一生成，复验完整自举、冷缓存及诸基准。未有新默认性能成绩，目标未成。
