# 独址之后，先验其效

初筛手改产物以探诸术之效，唯验基准之和，未具通用证明与全语义回归，不得称已成之优化。

诸术各与独址本版配对，五进程各六轮，先后互易。热轮取后二十五值之中，不以异批之数直相比。省清零与省单元返回，热轮之变皆微；删重检、递归守界、传界与向量填充，皆未胜旧。传界并内联分区，亦未胜。故诸原型存其证，不入编译器。

采样多归排序主函，然分区可内联其中，不可据此谓分区不热。察引擎轨迹：旧主函五百六十七字节，分区守卫与快体得内联，递归调用未展；新快体二百四十三字节，引擎先展四层递归，预算既尽，分区不得内联。手内联分区则多复其速，犹未胜旧。

故指令虽少，未必更速，函体之量亦改引擎取舍。然不足以断诸退步皆由内联，亦不可妄加空文以诱引擎。继察 C/Wasm 实码，见其合扫描之递进于歧后。仿此原型热轮三十五点九七二毫秒，同批旧版三十七点二六五；乃进而作通用变换，待全验。诸数与轨迹具今语同名文及本目录记录。

通用变换既成，所生排序字节与原型同。生成器检百万余项，排序与分区检二十七万余项，皆通。然两次独立复测，热轮仅省约百分之零点零六、零点三五，诸进程互有胜负。效证不足，故撤此变，复已验之独址源码，字节相同，验型亦通。候选留补丁以备考，不入编译，未为所弃候选重行全自举。不可执初次之数称又速百分之三点五。
