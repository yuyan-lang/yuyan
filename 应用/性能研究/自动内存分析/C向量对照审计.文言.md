# C 对照与向量之审

待用户定统计容差，先独审 C。原 SDK 相对路径已失，取他 worktree 之同版工具，只读而用之。以原 C 源、O3、十六 MiB 线性栈复构，又加 SIMD 另构一版。

旧物与复构物整体哈希异，逐节察之，唯名称元数据异，诸非自定义节皆同，反汇编亦同。故旧对照可复现。新向量版有 SIMD 特性，旧者无。

各三进程、每程六轮而校，诸果同，向量 C 于数组、矩阵、排序反慢。故仍取较快之旧 C 为对照，不以慢者降其准。此未穷 C 诸优化，亦未析引擎机器码之故。

百万项排序前组稍后、今组稍先，不可择佳数称功。容差之问未答，完成之约未改。详数见 [汉语篇](C向量对照审计.汉语.md)。
