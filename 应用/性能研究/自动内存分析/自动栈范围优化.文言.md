# 自动栈之范围优化

今以有界关系接实际栈后端。旧证唯明 wasm32 之宽，新证复明索引严格小于上界，且回边不改其上。原接口仍守旧义。

私体唯一数组形参、无根分配者，先验上界不逾组长及诸参数有序，合则入快体，不合则入全检后备。唯获证之访问省检，余者如旧；不禁引擎检查。表示与闭合之证定数组不换，容量之证定地址不溢。

实际排序之填充、分区皆自得其证，非按函数名取之。旧关系诸验与新增五验皆过；循环夹具五百一十七验过。排序六千九百一十六例，分区一万零二百八十七例，含陷阱后之数组内容，皆与 GC 合。初验脚本误取无返回值之方法，修脚本重验，产物未改。

原签名与导入导出不变，其余五基准产物同旧。本机与 Wasm 所生排序同；本机三四代自举同，两途验型过。

四百万排序热轮中数：GC 四四点九六三毫秒，逐检栈六三点四六六，范围栈四四点三一二，C 三三点四九九九五八。范围栈较逐检少约三成，尚较 C 慢约三成二，首轮亦慢于 GC，故试旗仍不常启。后须续改循环、地址与初始化，目标未成。

常途完整冷缓存 Wasm 自举为 22.42、22.08 秒，皆在三十秒内，种子与二三代同，未开试旗。
