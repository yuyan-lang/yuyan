# 既有规模之补验

本轮未改编译器，核原生三四代，皆复旧哈希。按既有记录，六题各有二规模，近验大者，不足代小者。乃补七组，各五进程、每进程六轮，首轮别录，后五取中，诸果皆同。

百万项排序，豫言七点九二一毫秒，C 七点七一四六秒之千分，约慢百分之二点六八；四百万项之近齐，不可概诸规模。余题在今 C 对照前，树之构造消费已多消，亦不可谓一般分配皆如此快。

用户命关键取舍须问，今问是否以百分之二为统计容差，抑须无容差而证不慢于 C。答复未至，未改完成之约。即许百分之二，今百万项之数亦非已过；须定准则而另验。ABI、整数与数组语义、冷举三十秒之限悉如故。详数见 [汉语篇](既有规模补充复测.汉语.md)。
