# 栈址指实，单步去值

依既有诸证，合三术：址影兼八字节之头而直指元素，访影无复偏移；复索则减基与头。单步唯尾递续行，歧不必产值，赋参后自合。独址扫描诸歧皆进一，故合其递于步后；余参仍按旧值并赋，数值扫描仍在歧内递。

此赖 SSA、表示、范围、活性与进度之证，非可泛改诸函。提前返与未知调用不合单步证，仍循旧途。步内比较为假，止时为真；读写与除法不删，不越步易次。公门、组形与源码之约皆不改。

察本机热点实码，旧豫言一千四百三十二字节，C 六百六十八。指令之少不足自证其速，故诸原型皆配对实测。混合索引、对齐、右移与单改载荷皆未见稳定之益；去值、合递与载荷址并用，乃见其效。旋转循环无加益，故不取。

生成器一万八千八百一十一组，检百万余项；真排序六千九百一十九组，分区一万零二百八十七组，共检二十七万零三项。旧产物八百四十一具名函之约与导入导出皆同，唯填充、分区两私快体改变。

又检容量边与哨兵三十五项，三异帧皆抵六十四 MiB 之限；末项、末后之址及超限拒绝皆合，邻帧无损。新热点实码一千四百字节，量仅稍减，故仍以实测时证其效。

四百万项，五进程各六轮，诸版轮换。旧独址首轮四十六点六一三毫秒、热轮三十六点七四四；新首轮四十五点三三七、热轮三十五点七一零；C 热轮三十三点三零二。较旧热轮省约百分之二点八，犹慢于 C 约百分之七点二，未可谓成。实验栈仍须显式启用。诸证与原始测数见同目录今语文所列记录。

本机全自举与两项验型皆通，三四代字节同。默认模式冷缓存 Wasm 自举为二十二点九六、二十三点三零秒，种子与后二代皆同。未启实验栈，不可归此时于栈分配之效。

本机与 Wasm 所生实验排序同。余五基准及未启实验之排序，字节皆如前，故不复测。
