# 依正则生非 GC 栈体

今增《网页汇编栈表示证明》与《网页汇编栈数值生成》，皆以豫言书之，未入默认统一后端。

前者辨整、爻、元、址，验原语、调用、支流与返回；引用不得入数值数组，整数不得冒爻。此证须与不逸、封闭调用及入口守卫相合，不可独断安全。

后者依正则生私体：整用 i64，址用 i32，读写径生检查及 load/store。自尾递先备诸参，逆存而回环，故交换无失。参号不连续亦可。

根数组须居首令，入口先分帧而初始化，根自递暂拒；子体不得造数组。公门守卫、容量后备与调用图尚未合，不可遽启为默认后端。

表示二十验过。以正则造填充、求和、换参及疏号之函，算法 WAT 皆由生成器生之。夹具一百二十八验过，含百万尾递、极值、百组随机溢出求和、越界及陷阱后再用。末次收紧签名，重生成之文与已验者同。两模块验型亦过。

此轮未改默认路径，无新性能成绩。后当合诸证、生公门与 GC 后备，再接范围与地址之证，复验完整自举及冷缓存时数。目标未成。
