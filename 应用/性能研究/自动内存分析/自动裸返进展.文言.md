# 自动私门裸返

返回之证今入实生成。先施于已证单宽整组之调用链：循私参之约，证诸返皆整，别立 `$rd…` 私门。公门、公表、旧引用返回如故；字节组、双组与未证者守旧。源文无须标记。

调用者诸前提皆具，乃入新门；所得存 i64，需引用时复装。公途尾调新门，须先调后装再返，不得混其返回类型。裸门尾递仍并行赋诸参。

快体先别存原表示表，推所得之资格；后备则复旧表、清新调用之记，不借快体所知。未知结果、递中换类、混合所返、复杂退出皆拒。此省装拆与检查；小整装箱未必占堆，不可妄称等量省堆。

实产物五进程，各六轮，首轮别记。百万排序 14.335 至 12.961 毫秒；四百万 60.321 至 54.694；八百万 129.033 至 119.725。诸果同，无并发编译。四百万省约百分之九点三，犹未及此前 C 约三十四毫秒。此表为豫言前后之比。

新端到端用例验实际裸门、全宽溢出、公门动态调用、零递归透传、递中换类及后备事实隔离。完整验证另记。
