# 栈访既验，后可省检

新增重复访问之析。每段记组之局部号与索引原子，同组同索既访无事故，后访省其重检；首检、读写与其序皆存。

此赖已验之封闭栈图：头与长不变，无宿主重入、原始内存写入及子组分配，SSA 与表示皆合。调用虽可易载荷，不可易头；不合此前提者，毋用此证。诸歧各记，其证不出其歧，亦不传于邻歧。异组异索、局部与常数不混，算术等价与别名不妄推。

常私体去重，守卫之后备仍守旧检。先试诸途皆去重，虽验无误，首轮反退；故依生成路径留后备之形，不依程序之名。最终编译器所生字节与两批所测原型同。排序主私体九检减为三，八百四十一具名函之约及导入导出皆不改，分区后备亦不改。

局部证书十三试皆通；生成器检百万余项，真排序与分区检二十七万零三项，果、事故与事故后内容皆比。

五进程各六轮，诸版轮换。与 C 同批复测，旧热轮三十五点二九六毫秒，新三十四点三三二，C 三十三点零六四七九二。新较旧省约百分之二点七，五进程热轮中数皆胜；犹慢于 C 约百分之三点八，未可谓成。

新分区快体三百三十一字节，去重排序体三百五十一。引擎先内联分区，后展一层递归而复内联其分区，未重旧时预算耗尽之失。此为本机引擎实迹，非诸引擎必然之约。诸数与证据见同名今语文所列记录。

本机全自举与两项验型皆通，三四代字节同。默认模式冷缓存 Wasm 自举为二十三点九五、二十四点三四秒，种子与后二代皆同，未逾三十秒。此未启实验栈，不可归其时于栈分配之效。

本机与 Wasm 所生实验排序同。余五基准及未启实验之排序，字节皆如前，故不复测。实验栈仍须显式启用。
