# 自动省中间数组

虚拟数组今入默认网页汇编生成。新造、全填、只读消费之链，编译器自证而省其实，以长与生成式代之。源文无须标记，不留私缓冲，不用和式，消费者仍逐项行原整数运算。

公约与公表如故，原函数为表外后备。先解长验容，再无陷阱验余参之整数资格；合则入虚门，不合则仍 GC。读址之宽与界、条件之 i31 限、除法之误皆存。

首批限主体三步，不越额外闭包取域与复杂控制。须证只读、不逸、递参守约、初始化全覆。生成式唯计数、常数、加减乘，重算费不逾七节点；未证者守旧。非按程序名、编号或规模而取。

正途不分配中间数组，然大整数返回犹可装箱，不谓全无分配。诸函既成，清其模块分析上下文，不久持正则树。省分配则资源所需亦变，不保资源耗尽之时机相同。

同机五进程，各六轮，首轮别记，余取中数。二百万项，旧 1.873、今 0.711、C 2.188 毫秒；千万项，旧 15.593、今 3.578、C 10.800。千万项较旧省约百分之七十七，稳态约为此 C 三分之一。此实编译产物，非手改原型。

首轮千万项今约 22.30～23.17 毫秒，C 约 16.17～17.28；虽优于旧 50.60～53.31，尚未及 C。排序亦尚迟，不称全语言功成。

网页程序三十四项回归皆过。新例确有六虚门，验仿射、全宽回绕、公门动态调用、非整数后备，以及改写、漏填、外传之拒。八误途与旧消息同。导入、导出、公表皆同；完整自举与余题复测另记。

终验：本机三四代同，两入口验型皆过。清分析上下文后，网页冷编译缓存自举 21.68、19.92 秒，二三代同，未清系统页缓存。定稿数组产物与实测者同。

斐波那契、筛、矩阵、排序产物与前皆同；树所引库多一未用数组私门，故复测，旧 14.414、新 14.297 毫秒，诸果同，未见退。

别行六轮察 GC，运行线程事件八至四，所录区间分配约四亿零六百六十三万至六百六十七万字节；所录最大堆对象约八千五百二十八万至五百三十六万。未计末次回收后之尾段，非总分配、真峰值或 RSS；正途省数组另有生成代码为证。

数组稳态已先于此 C，首轮仍后；排序旧差亦在。整体之志未成。
