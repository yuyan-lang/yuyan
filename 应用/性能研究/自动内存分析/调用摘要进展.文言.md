# 跨函摘要进展

今增跨函来源与所逸之察，尚用于报告，未据此改物之形或复其存。此轮无新提速之数，齐 C 之志未成。

局部携其参数来源，容器合其诸域，静调依被调者之约映回实参，分支从宽，递归求不动点。分别记可外存之参、返回所可达之参、可能新造之物与未知副作用。未知写后，旧来源不得径信，以防新别名。

可达非必同一，可能新造非必独有。常量后或共用，故不得据此径许栈存及线性复用。每函八参、二百五十六局部以内精察，逾限从最宽；迭代不敛亦从宽，毋以未成之证许其安全。

八项正则回归过，含返参、载参、取域、算术、互递、未知调与写后读取。曾得写后来源漏传，已正之。树之建者不外存参数，返有新造来源；树之求和者亦不外存参数，返可达其输入。后当辨对象之形与字段路径，再察调用者之生存期。

启闭诊断，树网页产物同，六行结果合。未谓通用栈存、所有权与复用已成，亦不用久留私缓冲。

范围：新造之记只察显式元组、构造器、数组及未知调之宽源，不计整数装箱等隐式分配。“否”非谓全函不分配；后用以优化，须合表示与装箱之察。

终验：本机自举与两途类型检查过，三代四代同；网页冷编译缓存全自举为 19.32、19.43 秒，二代三代同，源码之差与产物摘要俱存。
