# 先算而后置栈

旧法惟许首令造组。今许先行整数加减乘，以其所得为长与初值，然后置不逸之组于线性栈。无须人为标记，仍验值形、调用闭合与不逸；除、读写、调用、分支及未知之术，皆不许先行。证不足、容量不容，则循原 GC 之途。

又见前导之算常生整数私门，旧法因而拒栈。今为其架桥，守原私约，复装参数而尾入公门，共验栈界；后备另有其门，不复经桥。公约未改。此但去数组载荷之 GC，参数与结果或仍装箱，非谓全函无分配。

同源排序，先以输入加一为长。百万元素，旧十点七四九毫秒，新八点一二五，约省四分之一；四百万，旧四十四点八八三，新三十四点零四九。各七进程，各行六轮，去首而取中。此新覆盖之益，非胜 C 之全证。

新门差分五千九百零四，旧门差分及单元验六千零三十三；拒绝前导四例，私门差分二千零六十五，源码初始化五百一十六，皆验其值与界。原六核及默认排序之产物如旧，字节无异。

今仍以试旗启用，未广为多对象调用栈。自举之志与实测之数另存，原生链与 Wasm 冷编译各记，不相混。大目标未竟，不言已成。

定稿 Wasm 冷自举十五点五五、十五点八七秒，种子及二代皆同。原生三步五十八点零四四、八十一点九二六、七十九点零五四秒，末二代字节相同，两式类型检查皆过。若以原生每次三十秒为约，此数未达，不以 Wasm 之数代证。
