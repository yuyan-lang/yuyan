# 析排序之费，试双步之行

今先分时观排序。豫言分配约一点零四八毫秒、填充一点四二七、排序四十六点零二八；C 排序三十一点八八四。差距多在排序，非尽在分配。此分段观测改调用之界，非无扰之精确剖析，亦不可概论他程序。

另以引擎不安全选项唯作合法输入之诊断，省数组界验约减三毫秒，未解全差；关闭循环展开反迟。此选项不入正式运行，边界测试亦不用之。字节归纳与同位交换分支皆试而无益。

观 C 机器码，见两步合行及剩余计数，乃试于已守范围之私门。奇数先行一步，余每轮依次二步，数组自身之界悉存，失约仍循旧途。四百万项稳态四十八点三六一降至四十四点三二三毫秒，首轮亦减；百万、八百万项复测皆约省百分之九。

九万四千五百组边界，返值、失败之类与文、全组及失败前所写皆同。含零轮、奇偶轮数、负数与全宽两端。

欲入编译器，须另证每回必进一、上界不变、诸支必尾递，无早返外求；退出结果与参数并赋之义皆全，第一步失败不可先作第二步。范围保持不等于必进，旧证未足，不可径用。须依指令之义，不依排序之名。

今得原型与实证，默认编译器未改，自举未重行。后当通证入生成而复验时限，远志未竟。
