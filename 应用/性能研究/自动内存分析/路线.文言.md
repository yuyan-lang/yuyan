# 自动察存与择其分配

用户已决：不用久留之私缓冲，不令作者手标所有权。编译器自察其形、所逸、别名、末用与生存之期，证足则择捷途，证未足则守 GC。公开约定与程序之义不变。

今有裸整数、整组与字节范围之证；双组之证方验。私有整组仍由 GC 收，不是久留之缓冲。旧栈优化所及甚狭；统一正则构造又以栈元组同普通元组而造，故名有“栈”不足为实。

不逸不谓无别名，独有不谓只读一回。线性与至多一用亦异。须察诸路径，合支从宽，递归求不动点；未知调用守后备。诸证可为中间表示之内约，不必先增源语言手标之制。

次第为：先验双组；次列分配之形与不化之故；再拆局部元组为局部值，消其分配；继推跨函之逸与返回别名；证独有及末用，然后许原地更新与复用；末乃试合宜之栈存。网页 GC 引用须在引擎可追踪处，不得径当整数址藏入线性内存。异常、尾调与重入皆须验。

每进一术，计其分配、回收与耗时，亦验冷缓存全自举不逾三十秒。目标仍为诸基准齐或胜同机 C/Wasm。今仅首步在验，其余尚待施行；不得以计划谓已成。

今双组已验，分配报告已立；跨函来源与外存摘要亦有八项回归。字段路径、末用及完整所有权犹待推，详调用摘要进展篇。

今已证受限造受之链，合动态标签与载荷为一 GC 物，省其载荷分配。深二十之树由 20.328 毫秒至 13.796；冷缓存自举 21.65、21.68 秒。详单对象进展篇，尚非通用栈置与完整线性推导。
