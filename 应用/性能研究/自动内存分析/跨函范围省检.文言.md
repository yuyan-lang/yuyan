# 跨函省检之验

今试直调分区快体，复试去索引三验，皆于生成之 WAT 为之，未入编译器。各验二规模，各式七新进程，进程各行六次，去首次而取中数；轮换其序，核其结果。

百万元素，原式八点一五七毫秒，直调八点三零七，省检九点四零三，C 七点八四七。四百万，原式三十四点一五一，直调三十五点八五五，省检三十九点五四九，C 三十三点三一八。少验而反缓，故不可用。

引擎志示：原式内联分区；省检式先展四层自递归，预算既尽，分区遂不得内联。此足证择内联者有变，未足尽释其缓。

复以内联分区试之，留验者于百万略速，于四百万无益；尽去验者仍缓。两组分行，不可以后组豫言之数较前组 C 而称胜。

诸原型但验正常输入，未具自动范围之证，非法输入之义亦未守，不得发布。今存数据、补丁、引擎志与产物摘要，而不改正式编译器；无源码之变，故不重行自举。后当广不逸对象之栈置，仍守公约，证不足则归 GC。未达全目标，不言功成。
