# 容器逸出之析

今以分配之处为物，以字段为边，察一函数内诸物所指。存物于局部之器，未必外逸；器既外逸，其所达亦逸。元组分字段，数组合诸元；条件合两途，写入不删旧源，务取保守。

未知调用，皆视为可留其参。已逸之器，其字段兼记外源，防外人易其所藏而漏判。既有不留之证，不可充只读之证。传播用待表，环与深链皆可达。

此证唯言不出本函，非言唯一、线性或可置非 GC 栈。输入须为合法 SSA；控制未识、局部逾二五六、字段逾六四、三二轮未定，皆不授证。今惟诊断取用，未改分配生成。

编译器诸函五千零七十三，三百六十二未授证。所析分配处一万二千三百六十，得局部元组一千零七十六，其中一千零七十在模块初设。数组一百五十三，尚无不逸之证。此皆静态之处，非运行次数。

尝于汇编原型消一千零七十二单槽盒。冷自举基线二二点零二、二三点四八秒；原型二二点六四、二二点九三秒。产物皆同，墙钟未见益，故不纳生成器。

原生与 Wasm 各验一千零二十例，含边界十九、三节点图穷举一千、四十节点逆序深链一。全程原生自举及两项类型检查皆过，三四代同。Wasm 冷自举二代二一点五七秒，三代二三点零一秒，种子与两代同；用十八工，不读编译缓存，未清系统页缓存。此验三十秒之限，非前后提速之证。

后当析跨函之留、返、写及可达别名，再察闭包、高阶调用与载荷表示。诸证由编译器自求，毋劳使用者手标。通用非 GC 栈分配及诸基准齐 C 之志，尚未竟。详数与证据见 [汉语篇](容器逃逸分析.汉语.md)。
