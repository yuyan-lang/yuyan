# 自动循环范围优化已接入

默认 Wasm 编译器现在会在既有整数数组、整数返回私有入口中自动发现循环范围关系，验证所有尾递归回边，并生成动态守卫。条件满足时进入独立快体；否则进入保留原检查的旧体。无需源码标注，没有持久私有缓冲，公开参数与返回约定、导入导出及函数表不变。

证明仅允许删除已知合法的 wasm32 索引宽度检查。整数加法仍保留原语义，数组自身边界检查仍由 GC 数组操作执行。生成快体时才把获证的操作编号加入当前事实表，之后清空，普通体和其他克隆不继承这些入口假设。

本轮由 `网页汇编差分关系`、`网页汇编循环关系` 和 `网页汇编循环入口` 实现。候选关系、分析上限与保守拒绝条件见此前的 `循环关系进展.汉语.md`；并非任意程序的完整线性类型或区间证明系统。

## 同机正式测量

Apple M5 Pro，Node 26.3.0 / V8 14.6。四百万项排序，五个独立进程交替执行改前、自动循环优化和既有 C/Wasm 对照，各六轮；首轮单列，后 25 次取中位数。计时期间没有并发构建或诊断测试。校验结果均为 6000002。

| 实现 | 稳态毫秒 | 首轮范围毫秒 |
|---|---:|---:|
| 改前 | 55.521 | 75.922～82.142 |
| 自动循环优化 | 48.785 | 70.823～74.571 |
| C/Wasm | 34.063 | 42.738～44.522 |

本组稳态时间减少约 12.1%；此前独立初测为 54.408→49.002 毫秒，减少约 9.9%，方向一致。正式新结果仍为 C 耗时的约 1.43 倍，首轮也落后，不能宣布已追平 C。

原始数据见 `自动循环正式对照.json`、`自动循环初测.json`。此前手改 WAT 原型只用于确定方向；这里的产物全部由正式编译器自动生成。

## 正确性与自举

- 34 项程序回归通过，与上一轮输出逐项一致，见 `自动循环回归.json`。
- 正式生成的旧入口与新守卫入口进行 15,972 组边界对照，比较返回值、异常类别和消息，以及完整数组内容，包括 14,248 组失败前发生的写入，全部一致。涵盖负数、全宽整数两端、UINT32_MAX 与其后继、空数组及越界索引。
- 实际分区快体删除 3 个宽度检查；旧体的 3 个检查仍在，两体各保留全部 5 次 GC 数组读写。导入、导出和公开函数表与改前一致，见 `自动循环模块边界.json`。测试导出适配器只用于观测，没有改函数体。
- 按规定完成稳定编译器串行首级、后二级并行的本机完整自举，`yy3_bs` 与 `yy4_bs` 逐字节相同；`./yy` 及 `./yy3_bs` 两种入口类型检查通过。
- 单独使用 `--do-not-load-cache` 的 Wasm 冷编译缓存自举为 20.36、20.25 秒，二代与三代逐字节相同。未清操作系统页缓存。日志见 `自动循环冷自举二代.txt`、`自动循环冷自举三代.txt`。
- 斐波那契、素数筛、矩阵、树、虚拟数组五个其他基准的重新生成产物与上一轮逐字节相同，见 `自动循环其他产物.json`。

源码差异、产物一致性与 SHA-256 见 `自动循环源码.补丁`、`自动循环产物摘要.json`。
