# 虚拟数组之试

本轮未改编译器，唯改产物以择后策，不计为语言既成之功。

先内嵌分区循环，诸检与算法皆存；四百万排序由 54.040 毫秒至 62.728，反迟，故不用。

又察局部数组：长 n，逐置第 n-1 位以 n，后循次求和。原型存长度之解码与范围检查，读时径得所置之值，去数组与填充。仍逐项加减，不用和式，不留缓冲，不缓存答案。空组、小组诸果同，负长与 2^32 仍拒。

二百万项，1.984 至 0.487 毫秒；千万项，14.599 至 2.389。各五进程六轮，首轮别记，余取中数。无并发编译，诸果同。此尚原型，非默认编译器已胜 C 之证；去分配则资源耗尽之时机亦未必如旧。

欲自动施之，当循分配点与调用图，不按程序之名：证数组及别名不逸，初始化全覆诸位，所置为计数器与常量之总整数式；副作用、未知调用、未明除法皆拒。消费者只读，读址仍验；写入、外传、身份观察守旧。容量、回绕、空组与控制皆须保全，证不足则仍用 GC，源文无须标记。

若值可安全复得，则无须另置实体，较栈置更进一步。然通用栈置、完整线性与别名之证，尚未成也。详同名汉语篇及原始数据。

已立完整初始化之证：两参，数正则置其前一位，每轮一写，原组与数减一而尾递；零支返单元。所得记组参、数参与整数生成式，不拘参数先后与函数名。调用者尚须证初数等于组长且容量合法，未可据此径删分配。

式唯计数、常数、加减乘，守整数回绕；展开费限六十四，局部值限百二十八。外调、依旧组、除法、复写、错址错步、异阈及复杂控制皆拒。独立测试与验型皆过，含变式、常填、全宽回绕、倒置参数及预算之界。尚未接默认生成，无新正式提速；次须证只读、不逸及调用相应。

已立只读与调用链之证，独立测试及验型皆过。只读者唯取所定之组而不写，递参不易，不捕获、不外传；未知调用与别名传播皆拒。其证不谓读址皆合法，类型与边界犹须检。

链证限新造、全填、消费三令，填数同组长，新组只入受者一参，填果不复用，终返消费之果。以新造及用途之限，证别参不含原组；不可唯凭受者单体断无别名。

暂接诊断于编译器，真实数组程序得一候选，名号皆报告所得，非按名匹配。其后复旧接线，重造默认编译器与前已验三代逐字节同；所造数组程序亦同。尚未于默认产物省组，无新正式提速之数。次当以长度与生成式立私门，读时检址而代入，容量、除法、条件与后备诸义皆守；亦须察重算之费。

又试逐读皆检之原型：二百万项，基线 1.908 毫秒，带检 0.512，旧原型 0.497；千万项，15.115、2.747、2.525。各五进程六轮，首轮别记。留检犹省约百分之八十二，然未入默认生成。

今有通用取值生成器，验容量与读址，而代入整数式。原引用之解码仍属调用者，勿妄假其为整。正途不造组，越界误途以空 GC 组之读得原类陷阱，无久留缓冲。豫言生独立模块，四十五次数值断言、二十一次误途对照皆过，错误类别与信息相同；巨长有效值未真造组。

默认尚不施此变。次须立完整受者私门与调用者快途，并存未合整数前提之 GC 后备；除法、条件之界、递参类型与读序皆不可废。

已立虚组整数之证与完整受者生成器。其余诸参须先守整数之约，运算、分支与递参皆维持其表示；换类者拒。以组长代数组，诸值裸存；尾递先备诸实参，再逆序并赋而回环，非尾则仍调用。比较所得可径判，其余条件仍经 box 与 i31 检查，除法之误亦存。

独立生成模块实执行，三十一次数值断言、七次误途断言皆过，含十万次递归、交换、非尾、回绕、条件与除法。验型亦过。默认调用者尚未接线，无新正式提速。

次当留原 owner 为后备，公门先解长验容，再以无陷阱之守卫验其余参；合约则调用虚门，不合则仍 GC。以长代已省之组，不读不存在之局部。公表不改，私门置表外。接线后犹须全回归、自举、时限及实测。

后记：今已接默认生成而全验，详自动虚组进展篇；上文未接者，前事也。
