# 筛环紧化

今析产物之效，未改编译器。唯省邻接写读，或唯省恒参，益皆小；二者合，首轮由四十三点零一五毫秒至三十三点九一六。改为 tee 而存其赋，不及删去，故须证单用而后删。

施于三环，同期复测：旧首轮四十四点五九八，原型三十二点五零八，C 三十一点零三四二九二；热轮旧十六点零一九，原型十六点二八一，C 三十点三二八二五。犹未及 C 之初轮，不取异轮之优数相较。

独立夹具二百六十一验皆过，正常果复以试除验之，零规模之界错亦同。此非全语义之证。

后当据正则单用之证省邻接搬运，排形参与复制之体；唯回跳同克隆，乃省恒参，余参先求后存。双步之扫描规另存，不可混改。通用实现既成，复行全验、自举及 C 对照。总目标未成。
