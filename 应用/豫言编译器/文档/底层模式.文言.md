# 底层模式（不用垃圾回收之编译模式）

底层模式者，豫言编译器之第二编译模式也。执行器、驱动、文件系统、张量内核等系统之代码，以**常豫言之语法**书之；编译之时，不用垃圾回收，亦不倚标准库之运行时，径生标准之 Wasm 模块。所生之模块可行于 Node（诺驿）诸 Wasm 引擎，亦可由豫言操作系统之寄存器降级后端译为 ARM64、x86-64 之机器码（原生之二进制与裸机；编译器 `--目标 本机` 径书原生可执行之文，不经 .wasm，异标则加 `--目标系统`、`--目标架构`；图形之程所需之宿主之授（如显示之面）以 `--缺省宿主选项 '--授权显示面 主窗口=1280x860'` 书于产，启时补命令行所缺，命令行书同项者以命令行为准，见冶铸包说明之“缺省宿主选项”）；用小数（f64）、单精度（f32）、长整数（i64）、向量（v128）与原子之令者，降前先经数值转译（见 `豫言操作系统/裸机/文档/数值降级.文言.md`）。此代前所自造括号式“低阶语言”者：语言唯一，所异者编译之模而已。

## 一、模之所在：文名

底层模块内部之符号复用常程之包模块身份：主、包名、包内径与定义名共标一定义。函数之召、顶层常量与附加函数皆用此标识，异源码之目所构之汇编树码，其内部名同。公开导出用源文所声之名。

编译之模，文之性也，以文名定之：名含「。底层」者为底层之文，余皆高级之文（有垃圾回收）。

| 后缀 | 所书 |
| --- | --- |
| `名。底层。豫` | 底层之源 |
| `名。底层。测试。豫` | 底层之试，全树测试依 `。测试。豫` 而得之 |
| `名。底层接口。豫` | 底层接口：唯书类型与 `乃` 之签，每无体之声编为一 Wasm 之导入（见第七节） |
| `名。底层内建。豫` | 底层内建之声：底层库之本术（基础原语）、规度（布局原语）与广规度（六十四位址之布局原语），径为 `库/底层库/本术。底层内建。豫`、`库/底层库/规度。底层内建。豫`、`库/底层库/广规度。底层内建。豫`（见第六节） |
| `名。底层签名。豫` | 底层模之约：与同目同名之底层源文相配，声其类之种、透明之类、值之类与具体之块，核之如常约（见[签名文件](../../../提案/00060-签名文件.汉语.md)） |

- 底层签名之种名循底层现行之书：签名之文先 `寻观「磐石」之「数值类型」之书。`，抽象之类其种书「元类型」，如 `「页号」乃「元类型」也。`。签名之文中的名循底层之导入法，先导而后用。

- 程序之模视其入口之文：入口为底层之文，则编译器行底层之管。
- 底层之文，`寻`、`观`、`寻观` 唯求 `名。底层。豫`、`名。底层接口。豫` 与 `名。底层内建。豫`，故底层之代唯依底层库诸含底层之文之包；高级之文导底层之模，则报“这是底层模块，高级代码不能导入”。
- 编译之模唯视文名，一包之中可兼置底层与高级之文，包之层级亦与模无涉。包描述书“编译模式”之字段，则报错。
- 底层可执行之包，所成者 Wasm 模块：豫构照常出 `.wasm`；`「文件名」` 以 `.wasm` 终者豫构照原名出之（如 `客体执行器.wasm`）。出径以 `。树码` 终者书汇编树码（底层豫汇），如执行器 `执行器。树码`；唯用 i32 与旧令而由旧路之模书为汇编树码，俟诸后版。
- 豫言诸文之缀（兼高级、着色之文与文书、试料），尽见[文件后缀](语言技术规范/文件后缀.文言.md)。

## 二、语言之子集

底层模式全用豫言之语法与类型检查；所异者，后端之所受也。凡不可入无垃圾回收之境者，编译之时明报其错，不退回垃圾回收。

| 所受 | 所拒（报错） |
| --- | --- |
| 整数、爻、单元 `元`、`若…则…否则`、`令`、`；`；元组布局之类、定长列（定长数组之栏）、卦（定宽无号整数）、指向（带类型地址）、下标（带列长之下标）；小变体之构与 `鉴` | 元组值、逾小变体之界之构造器 |
| 小数（f64）、单精度（f32）、长整数（i64）、向量（v128） | 字符串之值、异常、续延 |
| 整数常量之 `鉴`（成分派） | 闭包、以函数为值而传、间接调用 |
| 一阶函数：全局函数、局部函数（依其被调之情处之，见下） | 引用类、运行时之数组、字典等数据结构 |
| 自递归与尾调用（尾位之自调化为回跳） | 一函数于诸调处用异型之值（泛型函数必单态而用） |
| 底层库本术、规度与广规度之内建之声（见磐石（底层库））、接口文件之导入之声（见第七节）、类型之声 `立「元类型」`（唯作类型） | 不在底层原语表之内建名、签与原语表不合之内建之声 |

上表所谓“闭包、以函数为值而传、间接调用”与“元组之值”诸限，皆由**验类**报之。底层之文逐定义既验，证义之底限察循察后之定义而行：按名簿辨其名为常值、为局部具名之函、为顶层（自递归）之函，遇以函数为值（系之、传之、还之）、呼函数之类之参（间调）、拉姆达与递归见于值之位、元组之构，则报 `编译错误：卷:行:列：…`，并书所在定义之名与所呼参之名。其判与其辞惟于译料底限定其一，证义与底读共由之；底读于入口文之末读仍拒此诸写，常途之中乃验类既报之后之兜底耳。

值之型应 Wasm 之数值型：整数、爻、单元为 **i32**（整数按补码回绕，爻为零一，单元为零）；小数为 **f64**；单精度为 **f32**；长整数与小变体为 **i64**；向量为 **v128**。函数恒返一值。简树本无型，后端之**定型**依原语之签、字面、调用与绑定，往复推之，得诸变量与函数结果之型，推之不得者以 i32 论；一变量推得二型者，报“类型不一致”。

小变体循既有类块、`立` 声、构造之用与 `鉴…或有…则…` 之文。类本身书作 `立「元类型」`（「元类型」出「数值类型」之篇），如：

```
「签果」立「元类型」也。
　「得签」立化「整数」为「签果」者也。
　「缺签」立「签果」也。
```

一器可空，可载一物；所载惟整数、爻或至多三十二爻之卦。声时验其度，逾界之辞首书“底层小变体的载荷”。一值用六十四位整数，高三十二位存器序，低三十二位存载爻；空载则低位皆零。传参、返果、局部之系，皆依值；造器径用整数之令。鉴循共用前端验诸支之尽，乃化为较签与取载；负筹之补码、卦之无号爻象，皆存其真。

小变体入布局之栏、众载与广载之制，留待后版；今入组类布局之栏则编时告误。

## 三、函数与循环

- **顶层函数**：`「名」乃化…也。「名」者会…也。` 成 Wasm 函数；唯自导出函数（见下）沿调用图可至者乃生。
- **自递归**：豫言编译器已升满参递归为全局函数；后端以尾位之自调改为回函数起点之跳（`br`），非尾位之自调则为常调。互递归须自改写（豫言无前向引用）。
- **局部函数**（`令「f」为（得…）属（化…）而`、`复令「f」属…即…而`）依其被调之情三取其一：
  1. 未被调：弃之；
  2. 仅被调一次而不自调：展之于调处；
  3. 仅被调一次而自调皆在尾位：成**内联循环**（共用外层函数之局部变量，可读写外层之可变格）；
  4. 余者：升为全局函数，自由变量为前置形参（**不得捕获可变格**，否则报错）。
- 是以惯常之写法：“单次调用之局部递归函数 = 循环”。环之形参可为任一值型，如小数、单精度或向量之累加。

## 四、可变格

`置格`、`读格`、`写格` 供函数内之可变变量：

```
令「和」为「置格」于「零」而
令「位」为「置格」于「零」而
复令「当」属化「有」为「整数」
　即得「无」而
　　若（「读格」于「位」）小于「数」则
　　　（（「写格」于「和」于（（「读格」于「和」）加（「读格」于「位」）））而后
　　　　（「写格」于「位」于（（「读格」于「位」）加「一」））而后
　　　　「当」于「元」）
　　否则
　　　「读格」于「和」而
「当」于「元」。
```

格成 Wasm 局部变量，必直接由 `虑 名 者 新格 … 而` 所绑，且唯作 `读格`、`写格` 之首实参；不得为常值而传，亦不得为提升之函数所捕。他型之格，用 `数格` 模块之 `置小数格`、`读小数格`、`写小数格` 及单精度、长整数、向量之同形者，格之型随其初值。

## 五、内存、静态数据与声明

布局书为命名元组，亦可为循次而投之元组。栏依声之次紧列，偏移为前栏之广之积，总广为众栏之广之和。栏之起须合自然之齐，隙以明栏补之；元组之齐取众栏之最大者。

| 栏类 | 广（字节） | 自然之齐（字节） |
| --- | --- | --- |
| 卦，八、十六、三十二、六十四爻 | 一、二、四、八 | 同广 |
| 整数、单精度 | 四 | 四 |
| 长整数、小数 | 八 | 八 |
| 向量 | 十六 | 十六 |
| 指向 T | 今仓址宽，四或八 | 同广 |
| 元组 | 众栏之广之和 | 众栏之齐之最大者 |
| 定长列 于 n 于 T | T 之广乘 n | T 之齐 |

p 为指向 R，则 `p 中「栏」` 得该栏之址，重投者逐层计之；循次者自零而始。检时并存两宽之度，底层总装依今仓之声核齐而择常偏，降为址加；同一阶段之储可供三十二与六十四位二目标。

`（「定长列」于 n 于 T）`（在列度之模 `库/底层库/列度。底层内建。豫`）乃定长数组之栏：其广等 T 之广乘 n，其齐取 T 之齐。n 为编译时非负之整数，T 须可为布局之栏；元素含指向者，两宽之下元素之广各计，底层总装依今仓之宽择之。`p 中「栏」` 得数组栏之址，`「第址」于 列址 于 下标` 得元素之址。`（「下标」于 n）`（在列下标之模 `库/底层库/列下标。底层。豫`）乃带列长之下标：字面之下标，检时核零至 n 减一，越则报编译之误；运行时所得之整数，先以 `「验下标」于 整数` 换成下标，其疆即所期之类中列长 n，越则陷；亦可径为 `第址` 之次实参，如 `「第址」于 列址 于（「验下标」于 整数）`。`第址` 之次参书下标，不书裸整数；列度与下标之类用时书 `寻观「磐石」之「列度」之书。` 与 `寻观「磐石」之「列下标」之书。`。不加中缀「第」诸新写法。

`「址作指」以 T 于 地址` 存所向之类，`「指作址」于 指针` 还原址；位型皆存，广随仓制。六十四位址内存之代码，用 `「长址作指」以 T 于 地址` 与 `「指作长址」于 指针` 于长整数址与指向之间转。

- 线性内存之读写：`读四`、`读二`、`读二有号`、`读一`、`读一有号`、`写四`、`写二`、`写一`；`存页数`、`存增长`、`存摹`、`存填`。他型之读写见第六节（`读小数`、`读单精`、`读长数`、`读向量` 等）。
- 顶层值定义必为**编译时之常量**：整数常量、常量间之整数运算、他常量之引用、`静态文` 之结果。其入函数者，代以数字。小数诸型之常，书于函数之中（如 `「单」于「0.5」`）。
- **声明**乃顶层值定义：`「内存」者（「声明存」于「初始页」于「最大页」）也。`、`「数据区」者（「声明数据区」于「起」于「止」）也。` 各止一声；用 `静态文` 之前须先声数据区（编译器先求含声明之定义，故书写之序无碍）。缺数据区者由 `豫构 类型检查` 告之，诊作 `编译错误：文件:行:列：定义名：使用静态串「…」之前须先声明数据区（声明数据区 起 止）`：位取彼顶层定义之名所在之行列，引号中为其静串首六十字。
- **共享内存**：`声明共享内存 初始页 最大页`，供原子之令与多线程（Wasm 令共享内存必有最大页数）。
- **六十四位址之内存**（memory64）：`声明存六四`（或 `声明共享存六四`）。此时诸址皆长整数，用 `广仓` 模块之 `长址读四`、`长址写单精`、`长址读向量`、`长址存页数` 等；用整数之址者，编译时报型不合。一二字节之读写（`长址读二`、`长址读一有号`、`长址写二` 等）、成批之复制与填充（`长址存摹`、`长址存填`，址与长皆长整数）、原子之操作（`长址一气读四`、`长址一气加四` 等）皆有长址之版。静串仍返三十二位之址（数据区在四吉之下），以 `「无号数作长数」于（「静态文」于『…』）` 得长整数之址。原生二进制与豫言系统之线性内存可增逾四吉（macOS 与 Linux 至六十八 TiB，裸机 AMD64 与 ARM64 至一百二十七 TiB，轩窗与 macOS x86-64 至八吉，见 `豫言操作系统/裸机/文档/数值降级.文言.md`）。
- **址（址宽之整数）**：底层库 `址算` 之 `址加`、`址减`、`址乘`、`址交爻`、`址升位`、`址无号降位`、`址等于`、`址无号小于` 等，及 `数作址`（无号而扩）、`有号数作址`、`址作数`（取低三十二位）、`读址`、`写址`（依址之宽读写四或八字节）、`址宽`（四或八）。前端之型皆书整数，后端依址参推其宽：六十四位址之内存六十四位；常内存者，原生之产（`--目标 本机` 径出之可执行，或出 。树码 之汇编树码）亦六十四位，出 .wasm（浏览器、云工、诺驿）者三十二位。同源以之书址与指针之算，易内存之声即易其宽；三十二位时所生之令与常整数之算同。六十四位之构，三十二位之值（如「读四」之果）授于址参者依无号而零扩之，源文不必书 `数作址`；以六十四位之值传三十二位之参、书于四字节者，乃报“既是长整数，又是整数”。
- **原生之产默六十四位址**（十月十三日用户定）：原生之产，常内存之声皆以六十四位址之内存生之，存所声之页数；出 .wasm 者仍三十二位。编译器之参 `--三十二位地址`（经豫构书 `豫构 构建 <包> -- --三十二位地址`）改诸内存之声（含 `声明存六四`）为三十二位，最大页不逾六万五千五百三十五，唯供较速。
- **六十四位址之开关**：编译器之参 `--六十四位地址`（默关；经豫构书 `豫构 构建 <包> -- --六十四位地址`），改程序之常内存为六十四位址，最大页二十一亿余（实限依平台：林檎与 Linux 六十八太字节，裸机兼容百二十七太字节），可以编堆逾四吉之底层程序；执行器之门径以 `声明存六四` 声六十四位址之内存，构时不需此开关。六十四位址之模另有三则：整数之算与较随其操作数取三十二或六十四位，二者须同型；整数之字面随所求之型；读写内存之址参可为三十二位之整数，生成时零扩之。故址之算自推为六十四位；址之算（`址加`、`址减`、`读址`、`写址` 等）之址参亦可为三十二位之整数，生成时亦零扩之，故三十二位之读取可径为址与偏移。以六十四位之值传三十二位之参、书于四字节、或与非址之三十二位值混算者，报型之冲突：辞举两面临何术、何召而定，末附二处之源位：形参曰“函数〈丙〉之参〈名〉既某（于函数〈甲〉召〈丙〉之时定），又某（于函数〈乙〉召〈某〉之时定）”；函数之果曰“函数〈名〉之果于其体为某，于函数〈乙〉召〈某〉之时又按某用”；余变量曰“〈名〉既某（于函数〈甲〉召〈丁〉之时定），又某（于函数〈乙〉之体定）”。宽定于某术之体者，曰“于函数〈甲〉之体定”。每面临其术顶层定义之源位，如“（前者定义于 卷:行:列，后者定义于 卷:行:列）”。一次尽报，至多千条；位取正名所留定义范围，不得则省其半。此冲报于定型，故底层之程以 `豫构 类型检查` 即见之，不待构建；于此以 `址作数`、`数作址`、`读址`、`写址` 明之。编译时之折叠以三十二位算，逾三十二位之常以 `长常` 或运行时之移得之。此三则唯用于六十四位址之模（原生之产默然）；出 .wasm 之常内存之模，产物与改前逐字节同。
- `「串址」者（「静态文」于『你好』）也。`：字符串以 UTF-8 附零字节置于数据区，其值为址；文同者共一份。
- **内存之导入与导出**：`「来处」者（「声明存引」于『环境』于『内存』）也。` 令模块不自建内存，而自宿主导之（模块名、字段名为字符串之字面）；页数、共享否、六十四位址否仍依内存之声，须先声内存，唯一次。宿主依所导之限建内存，诸实例诸工作线程可共一共享之内存。`「出口」者（「声明存出」于『内存』）也。` 以其名出内存，供宿主读写，可声数次。声其一者，模块由新路。待办：导共享之内存者，每实例化则数据段复书，宜避静态串。

## 六、数值之型与原语

规度（布局内建原语，`库/底层库/规度。底层内建。豫`）供 `「卦」于「爻数」曰 n`、`「指向」于 T`、多态之「读」「写」，及三十二位整数址之「址作指」「指作址」。列度（定长列内建原语，`库/底层库/列度。底层内建。豫`）供 `「定长列」于 n 于 T`、`「第址」`、`「验下标」`（其疆取类中隐列长）；用时书 `寻观「磐石」之「列度」之书。`。`「下标」于 n` 在列下标之模（`库/底层库/列下标。底层。豫`），用时书 `寻观「磐石」之「列下标」之书。`。六十四位址内存之代码别导广规度（`库/底层库/广规度。底层内建。豫`），取长整数址之「长址作指」「指作长址」。默认所引存旧器所识之声，列度、列下标、规度与广规度由通布局之新器检之。

整字面依所期卦类核零至二之 n 次方减一。有号六十四位足容之正负筹，皆循旧节；字值异于位值者，存其十进原文至检时，上疆与负数各验。卦码循无号真值而核。常数之式与模，检毕皆归整数之节，覆盖、折常、生码共循其形。三十二爻及以下以三十二位整数表之，余以长整数表之。

「卦作长数」于诸爻数皆零扩，「长数作卦」取低 n 位，「卦作有号长数」以最高实爻为号而展至长整数。「卦作数」以三十二爻及以下之卦依位样读为三十二位之整，三十二爻之首爻为阳者读作负；「数作卦」取低 n 位，与「长数作卦」同，三十二爻者原样。二术唯许三十二爻及以下，逾则编时告误而书其源位，宽卦改用「卦作长数」「长数作卦」。

爻数用编译期整数常量；闭合数索之加减乘，循既有数学整数而规。底层本术之相应声明，主名、包名、包内径皆核，乃与标准筹算同入一门。

「读」「写」之所向为上表之标量。八、十六、三十二、六十四爻各择读一、读二、读四、读长数与其写术；整数、长整数、单精度、小数、向量各择其读写；指向择读址、写址。卦读则零扩，元组与定长列之元素皆循投影或 `第址` 之址逐项读写；`下标` 之值唯由字面之核与 `验下标` 而生，`第址` 据此计元素之步。

`寻观「磐石」之书。` 依底层库之默认导入（基础、内存、格、址运算）唯引整数之部（同于旧版，旧编译器犹能编唯用整数之程序）；数值之扩充，则按模另导：`数值类型`、`小数算`、`单精算`、`长数算`、`向量算`、`一气算`、`广仓`、`数格`、`单精术`，如 `寻观「磐石」之「小数算」之书。`。诸函皆底层库「本术」之模（`库/底层库/本术。底层内建。豫`）内建之声之包装：类型检查依底层原语表（`库/译场/分职/笔受/底/底定型。豫`）校其名、参数之数与参果之型，易其调为内名 `底层_名`（以“声明”起之名易为 `声明：` 加其余，如「声明存」易为 `声明：内存`）；编译器内联之后应一 Wasm 之令（取整、较等之义，即 Wasm 之义）。依址之宽或元素之类而多态之原语（读写内存、内存页数与增长、选择、可变之格），于「原语」书为类变。

- **小数（f64）**：字面如 `「1.5」`；`小数加`、`小数减`、`小数乘`、`小数除`、`小数小者`、`小数大者`、`小数复号`、`小数绝对值`、`小数取负`、`小数向上取`、`小数向下取`、`小数截尾`、`小数约`、`小数开方`；较之 `小数等于`、`小数不等于`、`小数小于`、`小数大于`、`小数不大于`、`小数不小于`；转之 `小数作数`（越界则陷）、`小数饱和作数`、`数作小数`、`无号数作小数`、`小数作长数`、`小数饱和作长数`、`长数作小数`、`小数作单精`、`单精作小数`；位型 `小数位`、`位作小数`；内存 `读小数`、`写小数`；`小数择`。
- **单精度（f32）**：其常书 `「单」于「0.5」`（小数就近而舍）；算、较、取整、开方与小数同名而冠以 `单精度`（`单精加` … `单精开方`、`单精等于` …）；`单精作数`、`单精饱和作数`、`数作单精`、`无号数作单精`、`单精位`、`位作单精`、`读单精`、`写单精`、`单精择`。
- **单精度之超越函数**（`单精术` 模块，常函数，以范围归约与多项式逼近，常用之域相对误差约百万分之一）：`单精指数`、`单精对数`、`单精双曲正切`、`单精逻辑斯谛`（S 形之函数）、`单精正弦`、`单精余弦`、`单精幂`。待办：非正规数、上溢为无穷、零与负数之对数、极大之三角，皆粗略处之；四道向量之版未备。
- **长整数（i64）**：`「长」于「一二三」`（整数依有符号而扩）；逾三十二位之常书 `「长常」于『123456789012』`（十进制之串，编译时解之）；`长数加`、`长数减`、`长数乘`、有符号与无符号之除与余、`长数交爻`、`兼爻`、`位变爻`、`长数升位`、`长数有号降位`、`长数无号降位`、循环之移（移位之量亦长整数）；`长数为零`、`长数等于` 及有符号、无符号之较；`长数作数`（取其低三十二位）、`数作长数`、`无号数作长数`；`读长数`、`写长数`；`长数择`。
- **向量（v128）**：同一向量，依形而解——字节十六（i8x16）、短整数八（i16x8）、整数四（i32x4）、长整数二（i64x2）、单精度四（f32x4）、小数二（f64x2）。
  - 内存：`读向量`、`写向量`；读而扩之 `读字节八扩`、`读字节八无号扩`、`读短数四扩`、`读短数四无号扩`；`读单精广播`。
  - 广播与车道：`字节十六广播` … `小数二广播`；`单精四取道`、`单精四改道` 及诸形之取道、改道（道号必为编译时之整数常量）。
  - 单精度四：`单精四加`、`减`、`乘`、`除`、`最小`、`最大`、`绝对值`、`取负`、`开方`、四种取整、六种之较（其果为掩码）、`单精四求和`、`单精四乘加`（先乘后加）、`数四作单精四`、`单精四饱和作数四`。
  - 整数：`数四加`、`减`、`乘`、`取负`、`绝对值`、`最小`、`最大`、移位、`等于`、`小于`、`大于`；`数四点积短数八`（量化之点积）；`数四扩短数八低`、`高` 及无符号者；`短数八加`、`减`、`乘`、`短数八扩字节十六低`、`高` 及无符号者、`短数八收窄数四`；`字节十六加`、`减`、`字节十六收窄短数八`。
  - 位与重排：`向量交爻`、`向量兼爻`、`向量变爻`、`向量错卦`、`向量交非`、`向量位择`、`向量有阳`；`向量洗牌`（诸道打为四整数常量）、`单精四洗牌`（四个零至七之三十二位道号）、`向量换序`；`向量常`；`向量择`。

## 七、导入与导出

- **入口**：入口之文（依赖之序之末文，如 `入口。底层。豫`；试者即 `名。底层。测试。豫` 本身）顶层之入口之函「入口」（其类 `化「有」为「有」`，与常程之入口之函同名；编译器之参 `--入口函数 名` 可易其名），编译器出之为 `启动`，无参无果：
  ```
  「入口」乃化「有」为「有」者也。
  「入口」者得「无」而「运行全部校验」于「元」也。
  ```
  入口之名、其出与参果之数，皆于 `库/译场/网汇/篇入口。豫`（模块入口之约）一处而声之，前端之总装与本机之后端皆取焉：前端依之书出，后端依之求门而核其签，两端不复各书一名。四本机之鹄（裸机、林纳、林檎、轩窗）与网汇之模，其约同名；WasmGC 一类之 `_start` 出于洒扫，别为一途。Node 之宿（`底层宿主.cjs`）与 `底层测试 --诺驿` 调 `启动` 以行其模。
- **导出**：定义名以「导出：」起者，为模块之导出函数，导出之名乃其后之部（`「导出：合计」` 导出为 `合计`）。唯导出函数（并入口之函）及其调用图乃生成。显出其名与入口之出名相同者（同程既书入口之函、又书 `「导出：启动：0：0」`），总装于「底察重名」告“导出名重复”，并举二定义之名。
- **导出之签**：导出名后可缀〈：参数数：结果数〉以定 Wasm 之签，如 `「导出：合计：0：0」`（豫言之“有→有”函数由此导出为无参无果之门）。总装时为之造包装函数：形参多于所定者补其型之零，所定结果数为零者弃其返值；无缀之导出函数则如故（形参与结果之 Wasm 型由定型所推）。入口之函依 `启动：0：0` 而出。
- **导入**：底层接口之文（后缀 `。底层接口。豫`）唯书类型与 `乃` 之签，每无体之声编为一 Wasm 之导入：模块名乃接口文件之名（去其后缀，如 `林纳。底层接口。豫` 为“林纳”），字段名乃声之名。参果之 Wasm 型依声之类而定：整数与爻为 i32，长整数为 i64，单精度为 f32，小数为 f64，向量为 v128；类为有之参不入签，果为有者无果（其值为单元零）；他类则报错。类型检查易其调为内名 `导入：模块：字段：参数：结果`（参果书型字之串，型字为 整、长、单、双、向，无则书零），后端依之生导入。如 `平台。底层接口。豫` 之 `「写字节」乃化「整数」为「有」者也。`，即导入“平台”.“写字节”，其签 (i32) → ()。接口文件置于用之之包（如 `豫言操作系统/裸机/客体二号/平台接口/`）；`豫寓底榫卯` 之接口包，构建时未绑适配之实者，亦依此编为导入。
- **系统之符号**：`林纳`、`林檎`、`轩窗` 三接口之文声系统调用与系统库之函，其声名用中文（译名见《翻译列表》“系统符号”之节，即提案 00013 之附），如 `「书」乃化「整数」又化「整数」又化「整数」为「整数」者也。` 即系统调用 write。原生之目标，裸机后端依字段名查 `豫言操作系统/裸机/库/冶铸/降级鹄。豫` 之导入对照之表：林纳之表，每行为中文名、系统调用之原名、二构之调用号、参类与果数；林檎之表为中文名、系统库之符号（如 `_write`）、参类等；轩窗之表为中文名、符号（如 `CreateFileW`）、所在之动态库、参类与果数，导入之表与动态库之解皆用其符号。系统之原名唯记于此表；增系统之符号者，于接口之文加中文之声，于对照之表加一行，并补其译名于提案 00013 之附与《翻译列表》。

## 八、分派

对整数变量之等值判断之链（含对整数常量之 `鉴`）合而为分派：至多四项则逐项较之，多则依键折半。同键取先者。

## 九、编译管线

底层模式下，每文依次行：语法分析、名称解析、类型检查、类型擦除、跨模块优化、**闭包前优化**（止于此，不作递归转换、闭包环境、全局存储、函数提升）。入口文之终阶，由底层后端读各文之闭包前优化形式：

1. **读取**：转树为无类型简树，予每绑定以全局唯一之名，平柯里化之调用，收局部函数为 `局函`，拒闭包、元组、构造器之值、异常、续延、字符串值；小数之字面转为其 IEEE-754 位型；类型之声置一占位（真以为值则报错）；
2. **顶层常量**：随用随求；先求含声明者；
3. **化简**：代入字面（整数、长整数、小数、字符串），折叠纯整数运算，静态串定其址，解 `长常`，常量引用取其值；`令 x = v 于 若 x …` 而 x 不复见者，并为 `若 v …`；
4. **提升**：如第三节；全局函数之尾自调化为回跳；等值之链成分派；
5. **定型**：于诸可达函数反复施约，至不复变而止（`底定型`）；宽之冲于此报之。编译之参 `--宽度检查`（豫构验类底层之程时授之）令总装止于此步：不生令、不书产，専为验类之时即报此冲；
6. **生成**：每式于操作数栈留一值；局部变量以名引之，形参居前，依作用域分配，同级分支复用其号，名冠型字；块之型取所定之型；分派以嵌套块加决策树；
7. **总装**：自导出函数沿调用图集可达之函数，附导入、内存、数据段。皆 i32、唯用旧令而内存不共享、非六十四位者由**旧路**：转回网页汇编核心之状态模块，编码时**验证**，字节同于前（寄存器降级后端与客体执行器如故可用）；否则由**新路**：装为通用之模块项，以通编码器书标准 Wasm 之二进制，引擎装载时验之。

## 十、验证与器用

- **回归之例** `库/底层库/测试/底层示例`：唯用整数，涵尾递归、非尾递归、分派、内联循环、可变格、位运算、多参数、无符号之较、静态串与内存。构之：`./豫构。林檎。豫行 构建 底层示例 --输出 /tmp/底层示例.wasm`。
- **扩充之回归例** `库/底层库/测试/底层扩充示例`：小数、单精度（并超越函数）、长整数、向量（并宽松之集）、原子与共享内存、控制之构；别有入口 `六四`（六十四位址之内存），二入口皆校址之算（主入口三十二位、`六四` 六十四位）、`补充`（逐一覆余下之原语）、`导入`（带型之导入，唯编而验之）、`内存导入`（自宿主导共享之内存而复出之，诸工作线程以原子之令相协）。诸项不合则陷，由所出之 `启动` 行之。
- **单精度矩阵乘** `库/底层库/测试/单精度矩阵乘`：标量、向量、寄存器分块之向量、融合乘加之分块四内核，校其果逐位相同；`标量`、`向量`、`分块`、`融合` 四入口各复一内核二十遍以计时。
- **宿主侧之校器** `应用/百工坊/底层测试`：`底层测试 模块.wasm` 读唯用整数之模块，行标准之验与二进制之往返，装成带内存与数据段之状态实例，于宿主之整数执行器逐项调其导出而核其果（二十六项）；`底层测试 --诺驿 模块.wasm` 以用扩充之型之模块交 Node 宿主行之，依退出之状定之，并报所用之时。
- **诺驿之宿**（`豫言操作系统/宿主/节点/底层宿主.cjs`）：底层之模导内存者，依导入段之限建之；导「数学」（其声书于用者之包之 `数学。底层接口。豫`，`指数`、`对数`、`正弦`、`余弦`、`正切`、`双曲正切`、`反正切`、`幂`、`以二为底对数`，皆双精）与「诺驿」（`写字节 址 长`、`写整数`、`写长数`、`写小数`、`毫秒`、`线程数`）之函者，宿主供之；模块出「工作线程」者，宿主先起数工作线程（环境变量 `豫言底层线程数`，缺则可用之处理器数减一），各以同一模块、同一共享内存实例化而调 `工作线程(序号)`（序自一起），乃于主线调 `启动`，返则终诸工作线程。
- **试验之器** `应用/百工坊/底层生成`：`底层生成 读|编译 …` 径读阶段文本，便于察简树与所生之码；开发后端不必重建编译器。
- **类型检查**：`豫构 类型检查 <包名>` 于底层之程（入口为 `。底层。豫` 之可执行包）依原生之构之址宽为一次宽度之检，报声明与实之宽不合、同一值之二宽与缺数据区之静串，如 `豫构 类型检查 客体二号`。整包之验所查正为包之本入（命令行未另给入段）者启此宽度之检：包中惟一篇则此度即行；尚有他篇则以之为 `--又程序` 并授译者，首度惟验类，既毕，豫构复使主程独行一度宽度之检。链元（入文及其所依之闭）于是于验类之时总装至定型而止。库包与另给入段之命皆不行此度。单为此检者，径授编译器 `--宽度检查 --目标 本机`。惟置底层库之模之包（如 `冶铸`）无入口之程，其验类逐模而为止于前端，宽度之检留于用此诸模之构。内核之属有入口之底层之程，依上法而检之。
- 豫构之测试 `应用/豫构/包资料。测试。豫`、`包系统。测试。豫` 涵“编译模式”字段之报错、底层之文之判、底层导入与入口之寻、高级之文导底层之模之报错，及包上下文之往返。
- 编译器之改，循 `AGENTS.md` 三轮自举以校：`编译器三` 与 `编译器` 字节全同，且过 `--type-check-only`。

## 十一、所限与待办

- 寄存器降级后端（Wasm → x86-64、arm64）经数值转译而支扩充之型，豫言系统之内核易任务时存浮点与向量之寄存器（所限见 `豫言操作系统/裸机/文档/数值降级.文言.md`）。客体执行器（客体二号）唯释 i32 之底层模块；待办：执行器释扩充之型之令。
- 泛型函数于底层模式必单态而用；向量之道号、洗牌之道、向量之常，必为编译时之整数常量（经内联与化简而为字面）。
- 块之果型取所定之型；诸支皆回跳或陷之块而为实参者，其型或推之不得（以 i32 论），甚罕，遇之则绑于有型之变量。
