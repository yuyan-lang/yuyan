# 豫言标签函数类型设计

这是豫言标签函数类型的已确认设计。函数的参数可以带标签；类型、定义、调用与构造器模式统一写作 `「标签」为 …`，按声明顺序书写，需要分组时加括号。标签属于函数类型；类型检查完成后，调用中的标签被去掉，生成的代码与按位置书写的调用相同。现行规则见[标签函数类型规范](语言技术规范/标签函数类型.汉语.md)。

本文与[文言稿](标签函数类型设计.文言.md)同步。

## 一、决定事项

| 编号 | 规则 |
| --- | --- |
| 决一 | 类型、定义、调用与构造器模式统一写 `「标签」为 …`。「为」后面：在类型里是类型，在定义里是局部名，在调用里是实参，在模式里是子模式 |
| 决二 | 标签属于函数类型。带标签与无标签的函数类型互不相等，标签文字不同也互不相等；两者之间只能显式转接 |
| 决三 | 实参按声明顺序书写，标签可重复并逐位置核对。带标签的参数必须写标签，无标签的参数照旧写 `于 实参` |
| 决四 | 普通箭头与带标签箭头各有形成、引入和消去规则；标签核对是类型检查的一部分，其他类型规则对完整函数类型照常适用 |
| 决五 | `〇为〇` 是操作符，与其他操作符不新增显式优先级关系；能按现有规则唯一解析时可以省略括号，需要分组时加括号 |
| 决六 | 首版覆盖普通值函数、匿名函数、值构造器与构造器模式、普通模式与底层模式、接口签名；类型构造器的参数与着色语言暂不支持 |
| 决七 | 删去过期的 `循□以〇` |

## 二、写法

### 类型

```yuyan
「差」乃
  化（「被减数」为「整数」）而
  化（「减数」为「整数」）而
  「整数」
也。
```

`（「被减数」为「整数」）` 是一个带标签的参数：标签为「被减数」，类型为「整数」。同一函数类型里，带标签与无标签的参数可以并存：

```yuyan
「缩放」乃化「整数」而化（「倍率」为「整数」）而「整数」也。
```

### 定义

```yuyan
「差」者会（「被减数」为「甲」）而会（「减数」为「乙」）而「减」于「甲」于「乙」也。
「缩放」者会「数」而会（「倍率」为「倍」）而「乘」于「数」于「倍」也。
```

`会（「被减数」为「甲」）而` 接收标签为「被减数」的参数，函数体以「甲」引用它。标签供调用者使用，局部名供函数体使用，两者可以同名。

有类型匿名函数沿用类型的写法：

```yuyan
「单位」者遇（「数值」为「整数」）者「物」而「物」也。
```

### 调用

```yuyan
「差」于（「被减数」为「一零」）于（「减数」为「三」）。
「缩放」于「四」于（「倍率」为「二」）。
「单位」于（「数值」为「八」）。
```

三条调用的结果依次为「七」「八」「八」。带标签的实参仍由 `于` 接入调用，与无标签实参同在一条实参序列里。

### 构造器与模式

```yuyan
「坐标类」立「元类型」也。
「坐标」立化（「横」为「整数」）而化（「纵」为「整数」）而「坐标类」也。

「原点」者「坐标」于（「横」为「零」）于（「纵」为「零」）也。

「取横」乃化「坐标类」而「整数」也。
「取横」者会「点」而
  鉴「点」而
    有（「坐标」于（「横」为「横值」）于（「纵」为「纵值」））则「横值」
也。
```

模式里「为」后面写子模式；「横值」「纵值」是本分支的新变量。

### 括号与标签记号

- 带标签的项只能出现在四处：函数类型的参数位置（包括 `化` 的定义域与 `遇` 的参数类型）、`会` 的绑定参数、`于` 的实参、构造器模式的实参。出现在其他位置时报错。
- 括号按普通表达式的分组规则使用。`〇为〇` 与其他操作符不新增显式优先级关系，沿用已有的通用默认规约；能唯一解析时可以省略括号，遇到未定义优先级关系或需要明确范围时加括号。标签项与其右侧的表达式可以分别分组，例如 `于（「回调」为（会「数」而「数」））`、`化（「回调」为（化「整数」而「整数」））而 …`。
- 标签必须是一个非空的「名称」，数字记号（如「三」）、注释与编译器内部名称不能作标签。标签不参与名称查找，与同名变量互不影响。
- 同一参数组内允许标签重复，每个标签只描述自己所在的参数位置。参数组沿用现有规则：右侧的字面箭头展平为一组，返回类型为函数类型别名时另起一组。

## 三、规则

### 箭头类型的形成 引入与消去

用 `A → B` 表示普通单参数箭头，用 `~标: A → B` 表示标签为「标」的单参数箭头。A、B 均可取任意已经形成的类型，包括带标签函数类型。两种箭头按各自的类型规则处理，源码写法见第二节。

| 规则 | 普通箭头 `A → B` | 带标签箭头 `~标: A → B` |
| --- | --- | --- |
| 形成 | A、B 均为合法类型，则形成普通箭头类型 | A、B 均为合法类型，标签合法，则形成具有该标签的箭头类型 |
| 引入 | 环境中加入局部变量「物」且其类型为 A，函数体按 B 检查；`会「物」而 体` 检查为该普通箭头 | 环境中加入局部变量「物」且其类型为 A，函数体按 B 检查；`会（「标」为「物」）而 体` 检查为该带标签箭头 |
| 消去 | 函数值具有该普通箭头类型，实参按 A 检查，则 `函数 于 实参` 的结果类型为 B | 函数值具有该带标签箭头类型，实参按 A 检查，则 `函数 于（「标」为 实参）` 的结果类型为 B；实参标签须与类型中的标签相同 |

有类型匿名函数 `遇` 按对应的引入规则合成类型：显式给出 A，在扩展后的环境中合成函数体类型 B，得到普通箭头或带标签箭头。局部变量的名字可以共同换名，箭头类型中的标签按文字比较。

表中列的是单参数组。多参数组沿用现有箭头分组与完整应用规则，引入与消去对当前组的每个参数位置使用相应规则；源码调用须一次补齐当前组的全部参数。各位置的标签可以相同。

### 逐位对照

引入规则、消去规则以及构造器模式检查，都逐个位置依据函数类型选择带标签或无标签的参数规则：

- 类型在该位置带标签「甲」：必须写 `「甲」为 …`，标签文字须完全相同，括号依解析需要添加。
- 类型在该位置无标签：直接写实参或局部名，不能写标签。

标签属于箭头类型，决定该位置使用的引入和消去规则。实参与形参仍依位置对应：第 n 个实参对应第 n 个参数。完整应用、参数组、返回函数的规则不变；隐式类型参数（`承`、`授以`）不带标签，规则也不变。

同名标签逐位置核对，各位置的参数类型也可以不同：

```yuyan
「成对」乃化（「物」为「整数」）而化（「物」为「字符串」）而（「整数」合「字符串」）也。
「成对」者会（「物」为「数」）而会（「物」为「文」）而「数」与「文」也。
「成对」于（「物」为「七」）于（「物」为『甲』）。
```

第一位置检查「物」标签与整数实参，第二位置检查「物」标签与字符串实参。标签重复不改变位置、实参次序或局部变量绑定。

### 引入规则与函数值表达式

检查 `会（「甲」为「局部名」）而` 时使用带标签箭头的引入规则，期望类型的当前参数位置须带同一标签「甲」；`会「局部名」而` 使用普通箭头的引入规则。`遇（「甲」为 类型）者「局部名」而` 按带标签箭头的引入规则合成类型。

参数声明或实参与对应参数位置的类型、标签不匹配时，类型检查报错。函数值定义则按包含标签的完整类型核对。

直接引用已有函数值作为定义是合法的。例如，沿用第二节的「差」：

```yuyan
「差类」即化（「被减数」为「整数」）而化（「减数」为「整数」）而「整数」也。
「另一个差」乃「差类」也。
「另一个差」者「差」也。
```

引用「差」时，变量规则给出它的完整函数类型；该类型与「差类」相等，因此该定义通过检查。「另一个差」的调用继续按类型中的「被减数」「减数」两个标签使用消去规则。定义体还可以是条件选择、读取函数值或一次完整调用返回的函数值；均按现有表达式规则合成或检查类型，保留其完整函数类型中的标签。

### 类型相等与组合

带标签函数类型是完整类型，可以依现有类型形成规则用于类型别名、函数参数与返回值、元组、列及其他已有类型构造，也可以作为泛型的类型实参。标签对函数参数声明与调用方式作约束，函数值的组合沿用现有类型规则。

| 比较 | 结果 |
| --- | --- |
| `化（「数值」为「整数」）而「整数」` 与它自身 | 相等 |
| 标签「数值」与标签「输入」 | 不等 |
| 带标签与无标签 | 不等 |
| 交换标签或参数类型不同的两个位置 | 不等 |
| 交换标签和参数类型均相同的两个位置 | 相等 |
| 函数体的局部名「甲」改为「乙」 | 类型不变 |

合一采用同一规则。标签项是参数描述，类型变量不能解为一个独立的标签项；类型变量可以解为包含标签参数的完整函数类型。例如「甲」可以取 `化（「底数」为「整数」）而「整数」`，泛型函数与容器可以传递或保存这种函数值，类型里的标签须完整保留。

期望 `化 甲 而 乙` 的高阶函数仍要求无标签的回调参数。带标签函数的参数描述与该位置不相等，须显式转接：

```yuyan
「平方」乃化（「底数」为「整数」）而「整数」也。
「平方」者会（「底数」为「数」）而「乘」于「数」于「数」也。

（「态射」授以「整数」授以「整数」）于「数列」于（会「数」而「平方」于（「底数」为「数」））
```

把整个带标签函数类型作为类型实参则可以直接使用：

```yuyan
「平方类」即化（「底数」为「整数」）而「整数」也。
「原样」乃承「甲」而化「甲」而「甲」也。
「原样」者受「甲」而会「物」而「物」也。

（「原样」授以「平方类」于「平方」）于（「底数」为「三」）。
```

这条调用的结果为「九」。「原样」的类型参数「甲」取完整的「平方类」，其返回函数继续要求标签「底数」。

## 四、求值与生成代码

实参按声明顺序书写，类型检查后去掉标签，得到的调用与按位置书写的调用相同。求值顺序、尾位置、顶层直接调用与去装箱都保持原样；运行时不保存标签。

## 五、编译期表示

下表是上述箭头类型及其引入、消去形式的编译器表示。共用现有箭头主节点时，参数位置的标签项记录带标签箭头的类型信息，类型形成、相等、引入与消去均依此信息处理。

| 节点 | 内容 | 位置与存续 |
| --- | --- | --- |
| 标签项节点 | 标签字符串，一个子式 | 在函数类型的参数位置时子式为类型，随检查后的类型保存，类型擦除时去掉；在调用与模式的实参位置时子式为值或子模式，检查后去掉 |
| 带标签拉姆达 | 标签字符串，一个抽象 | 由 `会（「标签」为「局部名」）而` 解析得到；检查后变为现有的带类型拉姆达，其参数类型为标签项 |

- 标签字符串不计入自由变量，不做名称解析与换名；通用遍历照常进入子式。
- 保留标签的源码范围，供诊断与悬停使用。

## 六、解析

- 新增中缀操作符 `〇为〇`。左边须为单个名称，检查方式与组值字段名相同；构造标签项节点。
- 新增 `会〇而〇`，第一个元素只接受形如 `「标签」为「局部名」` 的标签项；构造带标签拉姆达，局部名在主体中绑定。原有 `会□而〇` 继续处理无标签绑定。
- `化〇而〇`、`遇〇者□而〇`、`〇于〇` 沿用原形状，标签项就是参数，括号只负责分组。
- 优先级：与「为」有关的组合不新增显式优先级关系，使用现有通用默认规约。某组合没有优先级关系时，解析器仍报“未定义优先级关系”，由源码加括号分组；不把所有省略括号的写法统一判为错误。
- 解析用例须证明 `会〇而〇` 的标签项分支与 `会□而〇`、括号表达式之间只有一种解析结果；能省略括号的情形与必须分组的组合分别覆盖。

## 七、类型检查改动

1. 类型形成：依普通箭头与带标签箭头的形成规则检查定义域及结果类型；标签项只许出现在函数类型的参数位置与 `遇` 的参数类型，检查各位置标签合法，允许重复。
2. 类型相等与合一：标签项按标签文字与子类型比较；类型变量不得解为独立标签项，可以解为包含标签参数的完整函数类型。
3. 匿名函数检查：按第三节的引入规则处理 `会`、`遇`；变量、条件等表达式使用现有规则，所得函数类型包含其标签信息。
4. 函数调用（`函数应用隐式参数合成。豫`）：按第三节的消去规则逐位置检查标签与实参类型，成功后剥去调用标签。推定隐式参数时，实参预读看穿标签项，形参使用去掉标签的真实类型。
5. 构造器模式（`模式匹配类型检查。豫`）：同样逐位置核对。
6. 无体声明：按签名合成函数体时，生成带标签的 `会`。

## 九、诊断

| 情形 | 提示 |
| --- | --- |
| 该位置须写标签而未写 | 第 n 个参数须写（「甲」为 …） |
| 标签文字不符 | 第 n 个参数的标签应为「甲」，实际写了「乙」 |
| 该位置无标签却写了标签 | 第 n 个参数无标签，去掉（「乙」为 …）的标签 |
| 定义的标签与类型不符 | 同上三条，指向对应的 `会` 或 `遇` |
| 函数值的标签与期望类型不符 | 显示期望与实际的函数类型 |
| 标签项出现在其他位置 | 带标签的项只能作函数参数 |
| 操作符组合没有优先级关系 | 沿用解析器的未定义优先级关系诊断，提示用括号分组 |
| 类型构造器参数或着色语言使用标签 | 首版暂不支持 |

## 十、删去 `循□以〇`

`循 名 以 式` 的构造函数直接返回式，不建立任何绑定；`LOCALAGENTS.md` 也写明它“不会建立递归绑定”。仓内仍有 25 个源码文件、71 处在写：编译器网页汇编测试 17 个文件，性能研究 8 个文件。71 处都在带签名的顶层定义里，形如 `「名」者循「…」以 …`（其中 2 处前面隔着 `受「甲」而`），递归由签名提供。

删除步骤：

1. 删去这些文件中的 `循「…」以`，行为不变。
2. 删去操作符定义，以及它在文言符集、控制操作符表里的登记。
3. 更新词法与语法规范、`LOCALAGENTS.md` 与语言规范里的相关文字。

这一步与标签功能互不依赖，可以先单独提交。

## 十二、验收用例

| 类别 | 必须覆盖 |
| --- | --- |
| 基本 | 一个标签；多个标签；同组重复标签且参数类型相同或不同；带标签与无标签混合；结果正确 |
| 拒绝 | 缺标签、标签写错、无标签位置写标签、次序颠倒导致类型或标签不匹配、数字记号作标签、未分组而出现未定义优先级关系、标签项出现在其他位置 |
| 解析 | 可唯一解析的标签项允许省略括号；无优先级关系的组合加括号后可解析；嵌套表达式的标签项与右侧分别分组 |
| 形成 | 普通与带标签箭头的定义域、结果类型是否合法；各位置标签是否合法；重复标签及嵌套带标签函数类型形成 |
| 引入与消去 | `会`、`遇` 与期望箭头匹配及不匹配；实参标签和类型匹配及不匹配；函数别名、条件选择与调用返回的函数值按完整类型检查 |
| 类型 | 相等表各行；类型别名；跨文件导入与重导出；带标签的高阶参数；显式转接后交给 `态射`；直接交给 `态射` 报错 |
| 泛型 | `授以` 与推定；带标签参数的类型含类型变量；类型变量取完整带标签函数类型后传递、返回及容器保存，标签保持；独立标签项不能作类型实参 |
| 构造器 | 构造、模式、嵌套模式 |
| 运行 | 开启与关闭优化；顶层直接调用与自递归尾调用照常生成；整数、小数参数照常去装箱 |
| 接口 | 带标签的 `。接口。豫` 签名边界形不变；无体声明合成 |
| 阶段与排版 | 序列化往返；格式化幂等；注释保留 |

## 十三、暂不做

乱序书写、默认值、省略参数、标签简写、自动转换或专门的转换语法、类型构造器参数的标签、着色语言中的标签、把组值与组类的命名项改为同一写法。
