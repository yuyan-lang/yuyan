# 证明之层

此[提案〇〇〇一六](../../../../提案/00016-证明层与精化擦除.汉语.md)之证明层规范也，书今所行之实。证明之层与实层分为二文：实层照常而编，证明之层书精化之类与证，编译所出惟取于实层。证由证核（证明内核）核之，由证场（证明细化器）细为证明项。此篇与[汉语稿](证明层.汉语.md)相应，后续之版列于证九。

## 证一：二层之文与目

| 层 | 文 | 所载 | 编译所出 |
| --- | --- | --- | --- |
| 实层 | `X。豫`、`X。接口。豫` | 今之语言 | 照常而生 |
| 证明之层（人书） | `证明/…/X。证明。豫`、`证明/…/X。证明接口。豫` | 精化之类、一般依值之类与证 | 无 |
| 证明之层（证场所生） | `证明/…/X。证明项。豫`、`证明/…/X。证明项接口。豫` | 细化后之签与证明项、归纳之规 | 无 |

包之 `证明/` 子目与源码之目一一相应：`<包>/<相对之径>/X。豫` 配 `<包>/证明/<相对之径>/X。证明。豫`，`X。接口。豫` 配 `X。证明接口。豫`。所生之证明项与手书之证同目，缀易为 `。证明项。豫` 与 `。证明项接口。豫`。如 `库/豫章/形制/次第。豫` 配 `库/豫章/证明/形制/次第。证明。豫`，生 `库/豫章/证明/形制/次第。证明项。豫`。

- 证明之文依相对之径求所配之实文；配之不得，则命告证径与所期之实径。
- 实文可配证文，亦可独存；独存之定，记曰未证。
- 证明之层可读所配之实文与其导入之闭；闭中实层之定入证核之核境，所依包之证明项文依已有之文核其来源与摘要。实层之构惟读实层。
- 全 `证明/` 依目而除于实层之构，格式之检与全树之试，其得文亦依目而别。
- 证文留于本包；每包如旧一包述、一包说明，仓库根之目如旧。

四缀皆入库。手书之二为证场之入；所生之二为证核之入，证核读证明项之文；实定由译场（编译器核心）之前端经证场取而授之。证场生证明项，依次书文首、本模严格正类型之归纳规与细化后之正文。

## 证二：证明之层之语

证明之层仍用今之豫言文法，所增者惟证核所供之内建名，及四则惟行于证明之文之规。

### 内建之名

| 名 | 签或书法 | 用 |
| --- | --- | --- |
| 「辞类」 | 宇宙 | 辞之类；类属之者为辞，擦时删之。 |
| 「侔」 | `「侔」乃凡「甲」而化「甲」又化「甲」为「辞类」者也。` | 相等之辞：两边算得同类之相等成员，则恰有一成员「元」。 |
| 「自反」 | `「自反」乃凡「甲」而凡「值」属「甲」而（「侔」于「值」于「值」）者也。` | 两边算得相同即成；亦以证爻式之算得「阳」。 |
| 「代入」 | `「代入」乃凡「甲」而凡「左」属「甲」又凡「右」属「甲」而化「所证」属（化「甲」为「辞类」）又化（「侔」于「左」于「右」）又化（「所证」于「右」）为（「所证」于「左」）者也。` | 以等代等；表层之「所证」由证场补。 |

| 「待证」 | 定义体或子项书 `「待证」` | 未竟之证，算未证。 |
| 「某归纳」 | 证核为每严格正之「立」类而生，如「列归纳」 | 归纳之规；证明项之文照抄其全文。 |

### 四则

- **爻式即辞。** 类之位书爻式，即辞“其算得阳”：`「阳」` 为真，`「阴」` 为谬，`（「序数」小于「长」）` 之属与 `且`、`或`、`非` 径书为爻式。
- **辞参为交类。** 签中书为独参，如 `又化（（「计」于「列值」）大于「零」）`；在证核为交类：成员于每证皆立，证留零次之位，运行时省参位。调用以 `于` 显给其证；证场以源码所给之证入证明项，自上下境补证列于证九。「幽」之参亦为交类。
- **择类为子集之类。** `「择类」于 A 于 谓辞` 之值即 A 之值，可径当 A 用；谓辞为此子集之类之成员条件。「择证」以值与据合为一择类之值，供须显据之处。
- **精化之签谈实定。** 证明之文为实层之定所书之签 `「定义名」乃 T 者也。`，读为辞 `「隶」于「定义名」于 T`：实定属于 T。T 擦后之算分与实层之签同；证场与证核依此成员之辞核实定。证明之文同名之 `「定义名」者 … 也。` 乃写法甲之副本，读法见证六。

### 证明项

证即带依值之类之豫言项，书法仍今之语法（`得…而`、`于`、`鉴…而 或有…则`，模式中新名依〇〇〇六九书 `得「名」`）。证核对证明项验类，此步可判：相等之改须书所证，算有筹限，子集之类与交类之据皆在项中。求证明者，人也、AI 也、证场也；证核司验。

### 表层之二法

用归纳之证，表层可径书归纳之规，亦可递归而书，二者皆由证场细为同一种证明项。

- **径书归纳之规。** 证中径书 `「列归纳」` 之属，「所证」可省，证场依目标与被归纳之项推之。例如：

```yuyan
「连结合」者设「物」而得「前」曰「甲表」又得「中」曰「乙表」又得「后」曰「丙表」而
　「列归纳」
　　于「自反」
　　于（得「头」又得「尾」又得「归」而「代入」于「归」于「自反」）
　　于「甲表」
也。
```

- **递归而书。** 证中径递归呼同一定理；证场识对原形参之构造器之支，以递归之呼为归纳之假，并补其所省之证。递归须为结构递归，递归之实参为该支所拆同类之字段；互递归、嵌套递归与对类参之递归列于证九。

## 证三：义：计算之类论

**计算之统。** 证明之层之计算，即豫言之按值求值，其规见[执行与编译](执行与编译.文言.md)编一至编四。证核自以按值符号求值之器为化简与反射之算；编译所出之码，惟于被证之程以编译之形而行时入可信之基。

**类。** 类者，闭合豫言之值上之部分等价之关也：定孰为成员、孰为相等，成员之间自反、对称、传递。`a` 属于 `A`，谓 `a` 求值得 `A` 之成员；抛出之形见下。

- `「列」于「物」`：成员为有限之「缀」终以「罄」，元皆「物」之成员；二列相等，当且仅当长短同、逐项等。成员皆有限，此归纳所由立之根。
- `「侔」于 甲 于 乙`：甲乙皆算得同类之相等成员，则恰有一成员「元」；否则空。辞皆然：真则有成员，假则空。爻式之辞，算得「阳」则有「元」，否则空。
- `化「x」属 A 为 B`：成员为豫言之函数 f：于 A 中任相等之 a 与 a'，`f` 于 a 与 `f` 于 a' 皆常算毕，且于 B 相等。
- `「择类」于 A 于 P`：A 之成员中 P 立者，相等依 A；为 A 之子类。
- 交类（辞参、「幽」）：于每证皆属果类、证留零次之位之值。
- `「隶」于 t 于 T`：t 求值得 T 之成员，则恰有一成员「元」；否则空。T 为 `「必返」于 B`，则言 t 常算毕而得 B 之成员。T 为函数之类 `化「x」属 A 为 B`，等于对 A 之每成员 a 皆有 `「隶」于（t 于 a）于 B`；定义域为商类时，亦证相等之实参得相等之果。

**凡函数皆可抛。** 实层之签 `化 A 为 B`，于证明之层读为可抛之 B：于 A 之任一成员，其果或为 B 之成员，或抛、或止、或不终。每过验类之实层定义，自属其类之本解，此精化之始。

**渐次精化。** 于本解之上可逐条加：

- 必返：于前置之下必常返，前置书为辞参，果书 `「必返」`，如 `化「列值」属（「列」于「乙」）又化（（「计」于「列值」）大于「零」）为（「必返」于「乙」）`。
- 返何：果书 `「择类」`，如 `为（「必返」于（「择类」于「数」于（得「值」而（非（「值」小于「零」））且（「值」小于「二五六」））））`。
- 何时抛、抛何：所抛之信合于某谓辞；豫言之异常带字符串之信。书法随有状代码之案并定。

果书 `「必返」` 则诺常返；惟书果类则依本解可抛，欲以为证，先证 `「必返」`。`「必返」` 以资足为前提：栈尽、内存竭所致之止，由运行之境任之。

前置能书为结构谓辞者（如“列有项”书为规约谓辞「有项」），先书结构谓辞：依算与归纳可证，亦易随数据而传。书为算术时，前置穿他函数须先证等式，线性算术之判定列于证九。

**相等。** 类于求值封闭：a 算一步得 a'，则 a 与 a' 于任何类皆相等。证核核相等时行符号求值：所鉴为构造器则下算，遇变量则止。符号求值依按值之呼：实参为值，或取于全类之变量，乃代入函数之体；实参未成值时，用按值之呼下所立之等式，如实参于体中恰用一次、用之先惟有常算不抛不止之算，则可移入。如 `「接列」于「罄」于 X` 依「接列」之定算为 X，X 可为未求值之项。步依抽象之步计，附注随证明项之文而存列于证九。

相等用外延之等；函数外延与商类列于证九。

**整数。** 「数」为六十四位补码。加、减、乘以二之六十四次方回绕；除与取余向零截之，余之号随被除数；比较为六十四位有符号之比，结果为爻。除数为零、最小整除以负一，皆止；最小整余负一得零。止者，程之终也，尝试运行不能接。四宿主同此一规：网页汇编以令之陷为之；冶铸（原生后端）于 AMD64、ARM64 生同一之检，ARM64 之硬件除零不陷，冶铸先察除数而后跳陷。证明之层依此义立模，与[执行与编译](执行与编译.文言.md)编四同。

**可靠。** 证核诸规于此义皆立；擦除之定理由此而得，见证五。

## 证四：证核与证场

**二包之分。** 证核惟依豫章（标准库），检一小核心之演算，为可信之基；证场依豫章、章句（语法树）、译场（编译器核心）与证核，以 `。证明。豫` 细为证明项，不可信。证场有失，证核拒之。实层之构惟依实层。

**核项。** 证明项与实定共用核形（核心项定义）之「核项」；束变量用自零起之德氏下标，全局之名带模之身份与名，次数分零次、多次、未定次。证明项之文既读，先定其次数，乃求值。

**证核所认。** 证核之递归与终，惟经归纳之规：证中之递归由证场译为归纳之规，证核核归纳规之用。核一定时，境中惟有先核之定；定自身之名留于境外。证场漏判一非结构之递归，所译之项留其自身之名，证核告“「名」尚未定义：证明不得引用自身”。

**筹限。** 证核之求值器共一千万抽象步之筹；逾筹之算告「步数超限」而拒。证核惟收算毕之算，其检必止。步依抽象之步计，诸宿主得同一之断。

**严格正。** 严格正者，所定之类型惟见于构造器字段之正位。负位有三：函数之定义域；「匣」「匣列」之属可变容器之元；签名之文中抽象类型之参（不见其实现，第一版皆当负位）。经「列」等别之「立」类而嵌套者，察其类之参于其自之构造器中严格正。证明之层自定之「立」类须严格正；证核于判为不严格正之声明告“非严格正：证明层的立声明被拒绝”。归纳之规惟给严格正之类；实层之非严格正类型仍存，其值之性以步数归纳（步进索引）证之，列于证九。

**宇宙。** 「类」为类型之宇宙，「辞类」为辞之宇宙；二者分层，「类」不属于己。第一期之宇宙层级止于一。

**归纳规之生与照抄。** 证核为每严格正之「立」类生一归纳规与一计算规，名以类名接「归纳」，如「列归纳」。归纳规之所证落于「类」，辞亦类也，故辞与计算之类皆可证。生成之函数于一切严格正之声明行同一之构：依构造器之次生支，每直接递归之字段配一归纳之假；内建列之规别生，归其为起别名之模（豫章之形制/次第）。

证场以归纳规照抄入定此类之模之证明项文，谁定其类谁生之；下游之包惟核已有之文，所生留于本包。其模未配证文者，生一惟含归纳规之证明项文。证核依「立」声明重生签与计算规，与文中所抄逐字比之（绑定之名归一而后比），有异即拒。

**大小之论一次。** 每归纳规之计算，为一结构递归之豫言函数，如「列归纳」之「行」。「列」于「物」之成员皆有限之列，于长短一次归纳，则证「行」于每成员皆算毕、果属于所证于表。归纳规由证核中同一生成之函数依「立」声明而生，此论于生成之函数一次，于一切严格正之声明皆立。

**可信之基。** 证之立，赖此数者：按值求值之规；证核（求值器、定宽整数与帛之原语、严格正之检与归纳规之生成函数）；证核诸规于计算之类论之可靠纸证；豫言类统之安；译场前端所出之实定；宿主所供接口之约与一切「假」。证明项之文以入待：证核惟认自核之物，文中所抄归纳规由证核重生而后比。

**证场。** 证场解名、取实定、以递归之证译为归纳规、补所省之证、治手书成员之证、生证明项之文。证场之终止之检不入可信之基；证场不可信，其失惟使证核拒之。写法甲与惟书签之自证列于证九。

## 证五：精化之擦

**依类而分。** 证明之层每子项或为算，或为证。类属「辞类」者为证，余为算。行之，每绑定标其次数：零次者惟检时用，多次者运行时用。证核保零次之值惟见零次之位。二例外于算皆常：「悖」应不可达，「代入」应恒等。

**擦之规。**

| 证明之层 | 擦后 |
| --- | --- |
| 辞参：签中之 `化（命题）`、定中之 `得「据」`、呼中之 `于「据」` | 删 |
| 「幽」于 A 之参与绑定 | 删 |
| 「择类」于 A 于 谓辞 | A |
| 「必返」于 B | B |
| `「爻分」于 c 于（得「据」而 甲）于（得「反据」而 乙）` | `若 c 则 甲 否则 乙` |
| `「悖」于 证` | 不可达 |
| 「代入」「自反」与其他证 | 尽删 |
| `「某归纳」于 所证 于 各支 于 值`，所证为辞 | 尽删 |
| `「某归纳」于 所证 于 各支 于 值`，所证为计算之类 | 计算规施于值，各支代入 |
| 依值函数之类 | 常函数之类；类索引依今规擦 |

**擦之所管。** 精化之签擦后之算分即实层之签；证明之层自定之义（引理、规约所用之函数、「幽」）留于证文。可靠由证径谈实定而保（见证六）。证场依擦规核精化之签与写法甲之副本，此步列于证九。

**擦除定理。** 证核受 e 属于 T，则 e 擦后之豫言程序属于 T。此定理连证核之受与实层之程：证明之层既过，擦后之程即实层所行之程，所出惟它。

## 证六：证谈实定

**精化之签乃关于实定之辞。** 证明之文得见所配实文之实定。为实层之定所书之精化签，即辞 `「隶」于 定义 于 T`；T 为函数之类时，证核展为逐实参之形。证引实定，以归纳规、依实定展一步、「已返」「接返」之属证之。相应之关即在证中：证所谈者，实定也。

**「已返」与「接返」。** 「已返」于一值，证此值为「必返」于其类之成员；「接返」于项、续、前证与续证，证 `「隶」于（「续」于「项」）于（「必返」于「丙」）`，其中「续」为求值之境，前证言项常返，续证言境于每值常返。

**实定所自。** 证核所执之实层定义，由译场（编译器核心）之前端出，落于与编译器共用之核心项；编译器亦自此层而下编。此层项之类型出一份声明，证核与译场共之；证场惟运其原。证场之 `取实定` 以检后之定转为证核之核声明列；`按源文取实定` 为入口之常式，豫构（构建工具）之 `证明` 命先于实模行验类，乃调此入口。

**写法甲：依实而书证。** 证明之文依实层之定书一同名之副本，于所须之处夹以证。此为表层之书：证场依副本之构生关于实定之成员证，书于证明项文，交证核核之；证核读证明项之文，副本留于证文。副本与实定不合，证场告“联结不符”，指其异支。写法甲之此生列于证九；今之证场治写法乙、手书成员之证与局部函数。

**写法乙：别立定理。** 辞中径书实层之名，如「连结合」中书「连」；证核算至之，依实定展一步。

**惟书签。** 证文惟书精化之签者，交证场自求成员之证；此步列于证九。

**手书成员之证。** 精化签之成员证可手书，书于 `「定义名之隶」` 之名下（如「计之隶」），其辞由证核依签推之，此惟书证。例如：

```yuyan
「计」乃凡「乙」而化（「列」于「乙」）为（「必返」于「数」）者也。
「计之隶」者设「乙」而得「输入」而
　「其计必返」于「输入」于「零」
也。
```

**局部函数之谈。** 实中常用 `「复令」` 书局部函数，如「倒」中之倒置、「计」中带累加器之其计。证文先书一与之逐字相同之证明层定义（如「倒置式」「其计式」）：证核展实定一步，所得局部函数与之换名而同，故关于其式之引理即关于实之局部函数之引理。此定义依实层之本解为可抛，常返别证（如「倒置必返」）。径引局部函数之书法列于证九。

**二法之分。** 不变量与代码之构相缠者（如循环中所持之性），用写法甲；事后而陈之性（如往返、幂等、结合之律），用写法乙。

**余规。**

- 证明之层多出之定义（引理、规约所用之函数、幽灵之定义）留于证文。
- 骨架之生：豫构可依实层生证明层之骨架，抄其定、于类与证处留「待证」，人或 AI 补其阙。此步列于证九。
- 实定既改，依实定所展之项亦改，关于其证于证核检而败。

## 证七：`豫构 证明` 之命

**用法。** 于仓库根行 `豫构 证明 <包> [--核对]`；`<包>` 为包之短名，参惟受 `--核对`，多书则告“用法：豫构 证明 <包> [--核对]”。

**常式。** 命递归配目标包与导入图内诸包之 `证明/` 下之 `。证明。豫`、`。证明接口。豫` 与实文，先经将作（构建服务）于导入图内各配模行验类，乃经译场之文件依阶取配模及其导入之闭之实定，依深优而后序排之。次调证场细化，书证明项，复依次交证核核之；先核之报传于证核。所依包之证明项依已有之文核之，更新所依包时行其包之证明命。

目标包之模未书手证、而定严格正之类型者，命生一惟含归纳规之证明项专卷。所生与旧文同则留旧文。

**`--核对`。** 配模照常先验类；命惟读证明项之文，重立文首以核来源与摘要，乃交证核；书文之步留于常式。证文既改而证明项未重生者，告：

```
证明项过期：库/豫章/证明/形制/次第。证明项。豫 记的是旧摘要，请运行「豫构 证明」
```

**报与退码。** 命逐条印定义之状，如：

```
首项：已证
连：已证
连结合：已证
汇总：精化签名 3，已证 3，待证 0；可信基：
```

状有三：`已证`、`待证`、`假`。末总精化签之数、已证之数、待证之数与可信之基。皆过则返零；有证不立或命有失则返一。失者之文印其诊断，余文照常核之。

**证明项文首。** 文首为一豫言注释，书“证场（证明细化器）生成，不得手改”、来源之包内相对径与原文依八位同文字节所算之沙二五六（SHA-256）十六进制摘要。归纳规专卷以实包之内径识来源，正文为空，摘要为空入之摘要。证明项之文由证场生；合并有争则重行其命而生之，如旧入库。

证明项文中之实层名为全局之名，指实层之实定；文中书全证核所核：每精化签所化之成员定理与其证、别之定理与证明项、归纳规与「代入」之所证、辞参之证。评审观证明项文之辞；证文既改则摘要不合，核时告证明项过期，证明项与证文由此相保。

## 证八：报错

报错书为豫言之项，带文、行、列与所证之辞。证核核一定之报以“证明不成立”起，次定义之名与源位，下为“要证”“得到”与缘由；命之报则一行。数例：

```
证明不成立：「连罄」，列算。证明。豫 第 5 行第 25 列
要证：（「侔」于（「缀」于「头」于（「连」于「尾」于「罄」））于（「缀」于「头」于「尾」））
得到：「自反」
自反两边须正常算得相同；可抛项没有证「必返」
```

```
证明不成立：「谬」，坏证。证明。豫 第 3 行第 8 列
要证：「阴」
得到：「伪证」以「阴」于「零」
得到可抛的命题：没有证「必返」
```

```
细化不成：证明的递归不是结构递归：「连罄」调用「连罄」于「表」，实参不比形参小（列算。证明。豫 第 5 行第 40 列）
```

```
缺少成员证明：首项之隶
```

```
证明不成立：「列归纳」，次第。证明项。豫 第 1 行第 1 列
要证：（「列」于「物」的归纳规则）
得到：（文件里照抄的规则）
归纳规则与证核生成的不同
```

证明项文过期、证明前验类有失、证文配不上实文，此三类由命径告，分别示以重生、先修实模、补其配对之文。
