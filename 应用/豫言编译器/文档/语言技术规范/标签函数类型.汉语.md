# 标签函数类型

这是当前编译器在独立实现基线之上增加的语言规则。标签属于函数类型，按参数位置核对，检查后擦除。本文与[文言稿](标签函数类型.文言.md)同步。

## 签一：语法

```yuyan
「差」乃化「被减数」为「整数」而化「减数」为「整数」而「整数」也。
「差」者会「被减数」为「甲」而会「减数」为「乙」而「减」于「甲」于「乙」也。
「差」于「被减数」为「一零」于「减数」为「三」。
```

标签写在完整操作符中：`化〇为〇而〇`、`化〇为〇者□而〇`、`遇〇为〇者□而〇`、`会〇为□而〇`、`〇于〇为〇`。`会` 的标签右边须为局部名称；`遇` 仍以 `者「局部名」` 绑定函数体。独立标签项与标签项外括号无法解析。

标签须为非空名称，数字记号、注释和编译器内部名称不可作标签。标签文字独立于名称环境，局部名可以与标签相同。标签允许重复，各位置的真实参数类型可以不同。

查[规约关系表](规约关系表.汉语.md)之前，五个带标签操作符分别映射为 `化〇而〇`、`化〇者□而〇`、`遇〇者□而〇`、`会□而〇`、`〇于〇`，沿用原操作符的规约关系。调用照旧左结合。定义域可以直接写类型应用，如 `化「表」为「列」于「整数」而「整数」`；调用中的复合实参须自行括起，如 `于「值」为（「加」于「一」于「二」）`。

## 签二：类型规则

记普通箭头为 `A→B`，标签箭头为 `~签:A→B`。

| 规则 | 普通箭头 | 标签箭头 |
| --- | --- | --- |
| 形成 | A、B 均为类型 | A、B 均为类型且标签合法 |
| 引入 | 将局部名按 A 加入环境，按 B 检查体 | 将局部名按 A 加入环境，按 B 检查体；定义的标签须为签 |
| 消去 | 实参按 A 检查 | 实参标签须为签，实参值按 A 检查 |
| 相等 | 域与结果逐项相等 | 标签文字、域与结果逐项相等 |

`遇` 在验参数类型后合成函数体类型，按参数有无标签合成相应箭头。标签保持原文，局部变量依原有绑定规则换名。

两种箭头是独立的类型构造。完整标签函数类型可以作为类型别名、参数、返回值、元组项、容器元素或泛型类型实参。变量、条件选择和调用返回的函数值均按完整类型检查。

合一比较标签和子类型。待求类型变量可以解为完整标签函数类型；独立标签项是参数描述，不能作为待求类型变量的解。期望普通回调的位置须接收普通函数；可用普通匿名函数调用标签函数来显式转接。

## 签三：应用与模式

第 n 个实参对应第 n 个形参，标签与真实类型均逐位检查。带标签位须写同一标签；普通位直接写实参。标签重复时仍按位置处理。

参数组、完全应用、字面右箭头展平、返回函数类型别名另起一组、隐式 `承` 与 `授以` 均沿用原有规则。隐式参数可以是类型参数，也可以是隐式值参数（`承 A 者「x」而 B`，见[依值类型](依值类型.汉语.md)）；两者都不带标签，标签项不能作为其实参。依值箭头可以带标签：`化「签」为 A 者「x」而 B`。

隐式参数求解预读实参时穿过标签包装，按真实域类型匹配；读取类型的四种入口与一次有序推定规则见[类型与模块](类型与模块.汉语.md)类四。实参值、构造器子模式与局部变量按剥去标签后的真实类型检查。

## 签四：擦除与边界

类型检查后调用与模式中的标签包装消失。带类型抽象的域中保留标签，供阶段文件、接口类型、相等与悬停使用，随后随类型标注擦除。标签不参与自由变量、名称查找或换名。

运行时实参顺序、求值交错、尾位置、直接调用与原有整数去装箱保持原规则。构造器字段形、签名类别和宿主边界形按真实类型计算。无体声明按各参数有无标签合成相应匿名函数；宿主字段名和 Wasm 参数形照旧。

JSON 与豫言阶段源码保存标签项和未检查的标签抽象。标签项有一个子式；标签抽象有一个绑定体；检查后的阶段拒绝残留的未检查标签抽象。悬停中的标签箭头显示 `（化「标签」为 类型 而 结果类型）`。

## 签五：实现范围

普通值函数、匿名函数、值构造器与模式、GC 和底层模式、无体接口签名均适用。首版的类型构造器参数和着色语言遇标签时给出明确诊断。默认值、可变参数、乱序调用、部分应用、标签简写和自动转接均维持既有语言边界。

当前编译器已删除 `循□以〇`。顶层递归以紧邻的完整签名与定义建立；局部递归写 `递归虑`。仓内原来 `循「名」以` 的用例已改用上述签名递归。
