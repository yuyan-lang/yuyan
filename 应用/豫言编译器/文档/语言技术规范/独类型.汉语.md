# 独类型

`「独」于 T` 是恰好要用一次的 T 值，用于凭据、句柄、临时文件这类交出去或收回来都只该发生一次的值。类型构造器「独」与「作独」「去独」由豫章「独行」模块提供，`寻观「豫章」之书。` 即可直接用。编译器在类型检查时核对用法。本文与[文言稿](独类型.文言.md)同步。

## 独一：写法

```yuyan
寻观「豫章」之书。

「凭据」立「类」也。
　「造凭」立化「数」为「凭据」者也。

「凭号」乃化「凭据」为「数」者也。
「凭号」者得「凭」而
　鉴「凭」而
　　或有（「造凭」于得「号」）则「号」
也。

「登记」乃化「数」为（「独」于「凭据」）者也。
「登记」者得「号」而「作独」于（「造凭」于「号」）也。

「交付」乃化（「独」于「凭据」）为「数」者也。
「交付」者得「凭」而「凭号」于（「去独」于「凭」）也。

「书」于（「述数」于（「交付」于（「登记」于「七」）））。
```

- 「作独」把普通的值转成独值，开一笔“恰用一次”的账；它是「独」的构造器，类型是 `凡「甲」而化「甲」为（「独」于「甲」）`。
- 「去独」把独值转回普通的值，这笔账就此了结，类型是 `凡「甲」而化（「独」于「甲」）为「甲」`。得到的值照普通值用。
- 普通值与独值之间的转换都手写：要独值的地方写「作独」，要普通值的地方写「去独」。两者类型不同，混用时报类型不相等。

## 独二：恰用一次

类型是 `「独」于 T` 的参数与令绑定叫独变量，拆独鉴出的载荷（见独四）也是。每个独变量在每条控制路径上恰好用一次，下面每一种都算用一次：

- 传给类型是独的参数；
- 作函数的返回值；
- 「去独」；
- 交给另一个变量（`令「乙」为「甲」而 …`），之后由「乙」接着记账；
- 被拆独的鉴用掉。

若、鉴、且、或的各支要用掉同样的独变量；以「告祸」收尾的一支不计，它少用的独变量不报（告祸时怎样收回资源见独五）。递归函数可以把独变量当参数传给自己。匿名函数、局部函数（复令）与回调都是常函数：常函数里用的独变量只来自它自己的参数与它里面的令绑定，外面的独值当参数传进去。

违反时报编译错误，位置是出错的那个名字或式子：

| 情形 | 诊断 |
| --- | --- |
| 一条路径上用了两次以上 | 独变量「凭」用了 2 次：独值恰要用一次；要多处用就先「去独」，这里是第二次 |
| 一次也没用 | 独变量「凭」没用掉：独值恰要用一次（传给收独的参数、作返回值或「去独」） |
| 各支用数不同 | 各支用掉的独变量不同：「凭」在一支里用了 1 次、在另一支里用了 0 次；若、鉴、且、或的各支要用掉同样的独变量 |
| 常函数里提到外面的独变量 | 常函数里不许提到外面的独变量「凭」：匿名函数、局部函数与回调里要用独值，就把它当参数传进去 |
| 把独值绑到「」 | 独值不能丢（类型「…」）：独值恰要用一次，传给收独的参数、作返回值或「去独」 |

`而后` 前面的值被丢弃时照普通规则报错，独值也在其内。

## 独三：类型位置

`「独」于 T` 用作变量、参数、结果的整个类型：令绑定的类型、函数类型的参数类型与结果类型。函数类型本身是普通值，可以放进列表、记录与别的类型。编译器在下列情形报编译错误：

| 情形 | 诊断 |
| --- | --- |
| 套在类型构造器的实参、记录栏、元组、命名项里 | 「独」只能作变量、参数、结果的整个类型，不能套在别的类型里 |
| `「独」于（「独」于 T）` | 「独」不能再套「独」：独值已经是恰用一次的值 |
| 构造器字段的类型含独 | 构造器的字段不能是独值：变体的载荷与记录的栏里不许有「独」 |
| 类型别名整个是独类型 | 类型别名不能是独类型：在用到的地方直接写「独」于 类型 |
| 顶层定义的类型是独 | 顶层定义不能是独值：独值只能作变量、参数、结果的整个类型；要长存就先「去独」 |
| 泛型函数的类型参数取独值 | 「某函」的类型参数取了独值（类型「…」）：泛型函数碰不到独值，先「去独」再交给它；「作独」也不能再套独值 |
| 元组的一项是独值 | 独值不能装进元组：「独」只能作变量、参数、结果的整个类型 |

泛型函数的类型参数只在一处可以取独值：「告祸」的结果类型参数，因为告祸不返回。取独值的栏照普通规则报类型错误，先「去独」再取。

## 独四：拆独

独值的类型是变体、每个构造器至多带一栏时，可以直接鉴它，叫拆独。鉴算把被鉴的独值用掉一次；走到带一栏的支，那一栏绑定的名字仍是独变量，在这一支里恰好用一次；走到不带栏的支，这笔账就此了结。可失败的取得因此交出 `「独」于（「成否」于 T 于 缘由）`（「成否」在豫章「成亏」，另写 `寻观「豫章」之「形制」之「成亏」之书。`）：

```yuyan
「试登」乃化「数」为（「独」于（「成否」于「凭据」于「文」））者也。
「试登」者得「号」而
　若（「号」大于「零」）则「作独」于（「成」于（「造凭」于「号」））否则「作独」于（「误」于『号要大于零』）
也。

「试取」乃化「数」为「数」者也。
「试取」者得「号」而
　鉴（「试登」于「号」）而
　　或有（「成」于得「凭」）则「交付」于「凭」
　　或有（「误」于得「由」）则（「书」于（「去独」于「由」）而后「零」）
也。
```

成功一支的「凭」是 `「独」于「凭据」`，交给「交付」；失败一支的「由」是 `「独」于「文」`，「去独」以后照普通值用。「或可有」的独值同样能拆：「可有」一支鉴出独值，「可无」一支没有载荷。拆独依据的是 F 对和类型的分配律 F(A+B) ≅ FA ⊕ FB（F 是左伴随，保持余积），鉴就是 ⊕ 的消去。「独」只有一个构造器、一栏，编译器不装箱，运行时拆独就是普通的鉴。

鉴独值时每支都写出构造器。编译器在下列情形报编译错误：

| 情形 | 诊断 |
| --- | --- |
| 用变量或「其他」兜底 | 鉴独值时每支都要写出构造器：不能用变量或「其他」兜底，兜底的那支拿不到载荷，账就丢了 |
| 构造器带两栏以上 | 拆独只拆每个构造器至多一栏的变体：这个构造器有 2 栏，先「去独」再鉴 |
| 载荷位置再套模式 | 拆独只拆一层：鉴出的载荷要直接绑一个名字，不能再套模式；要细分就在这一支里再鉴它 |
| 载荷位置写「」 | 独值不能丢：拆独时鉴出的载荷要绑一个名字，在这一支里恰用一次 |
| 拆元组或记录 | 拆独只拆变体，不拆元组与记录：先「去独」，再鉴得到的值 |
| 鉴出「作独」 | 独值不能直接鉴出「作独」：要拿里面的值就「去独」；里面是变体时，直接鉴它的构造器（拆独） |

鉴出的载荷与别的独变量一样记账：用两次、没用掉、被常函数捕获都照独二的诊断报。元组与记录这类积类型先「去独」再拆：一笔善后（见独五）只管一份义务，拆积会把它分成几份。直接鉴出「作独」只在「独行」模块里写（「去独」就是这样实现的）。

## 独五：告祸出口与善后

握着独值时告祸，异常越过还没了结的账，接住它的「姑试」照常往下走。类型检查把以告祸收尾的一支当作回不来的路，少用的独变量不报，对应线性逻辑里零类型的左规则：回不来的路可以丢掉剩下的资源。告祸时也要收回的资源，由取得它的库登一笔善后（祸时收尾）：

- 「登善后」：接收收尾函数（收「元」），登进善后簿，交回一笔「善后」。取得资源时调用，把这笔「善后」存进资源的表示里。
- 「了善后」：资源正常收回或转交出去时调用，这笔善后就此销掉；对已经了结的再调用不做事。
- 「姑试」进门时记下账位；接住异常时，先倒着跑这一层登过而没销的收尾，再交给处理函数。
- 一路没人接住时，「常处祸」印完消息先「尽善后」，再退出。自己另登了顶层未捕获处理器的程序，退出前调用「尽善后」。
- 收尾自己告祸时，消息印到标准错误，其余收尾照跑，原来的异常照样交给处理函数。

善后都在豫章「祸福」（`库/豫章/本原/祸福。豫`）里，编译器不参与。例：

```yuyan
「临凭」即「组类」【「号」乃「数」也，「后」乃「善后」也】也。

「开临凭」乃化「数」为（「独」于「临凭」）者也。
「开临凭」者得「号」而
　令「后」为「登善后」于（得「无」而「书」于『祸时收回临凭』）而
　「作独」于（「组值」【「号」者「号」也，「后」者「后」也】）
也。

「收临凭」乃化（「独」于「临凭」）为「有」者也。
「收临凭」者得「独凭」而
　令「凭」为「去独」于「独凭」而
　「了善后」于（「凭」中「后」）
也。
```

正常路上「收临凭」了结这笔账；在「开临凭」与「收临凭」之间告祸时，接住异常的「姑试」替它跑收尾。先例是 Linear Haskell 的库 linear-base 里的 RIO：取得资源时一并交释放函数，保证取得的资源总会释放。

## 独六：实现

- 豫章「独行」（`库/豫章/形制/独行。豫`）：「独」是单构造器单字段的类型，运行时直接以字段本身表示，作独、去独与拆独不另花开销。
- 登记：类型检查给参数与令绑定定类型时，类型是独的，按绑定名的源码范围记进本文件的独系名单（`库/译场/分职/证义/独察。豫` 的「登独系」，由「录源系悬停」调用）；拆独鉴出的载荷由鉴验类的「拆独支」改成独并登记。
- 恰用一次：类型检查之后沿名称解析后的定义列走一遍（「察独恰用列」），按名单认出独变量，逐条路径记账，诊断带文件行列；鉴的一支模式里有独系时，把支体移一位、补一层绑定再走。名单为空的文件跳过这一遍。
- 类型位置：签名、构造器与别名在卷结构检查里查（「察顶独嵌」「察器独嵌」「察别名独」）；元组在类型检查时查（「察组无独」）；拆独的模式在鉴验类的「拆独支」里查；泛型函数的类型实参与带类型绑定在检查后的对象上查（「察独泛型列」），诊断位置取所在定义。
- 善后：豫章「祸福」的善后簿是一条新登在前的单链，「善后序」逐笔编号；「姑试」的账位就是进门时的「善后序」。

## 独七：后续版本

- 借出：不用掉独值，只看一眼或暂借出去；“交回句柄又带结果”这类要拆积的写法也由它解决。
- 独函数：捕获独值的闭包。
- 唯一、局部、共享等其余用法轴。
- 善后簿按执行栈分账（协程、多核差遣）；陷阱、辍役与断电时由行在在任务结束时代收；「辞」退出前跑善后。
