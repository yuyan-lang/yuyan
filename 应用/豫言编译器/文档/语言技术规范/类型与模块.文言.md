# 类型、名称与模块

不可预设 HM、任意依赖类或自动柯里化；其接受之集及参数之组，或异本基线。

## 类一：类型与形成

Γ 为有序绑定及文件接口。类有内建、刚性变量、`C(P,N,c,K)` 名义构造器、构造应用、连续箭头 `[A1,…,An,R]`（n≥1）、全称 `[a1,…,am].B`（m≥1）、元组（项可带名，为命名元组）。P 文件身份，N 名，c 类型内号，K 声明类。

七内建皆可成类；元类型亦可成类，不设宇宙层。环境中认作元类型之名可为类；透明别名展开，普通值不可因其名而成类。箭头各域与结果皆验，右箭头展平，域中箭头不展；全称以元类型绑定类参而验体；元组逐项验，名随项存。依值之箭（`化「x」属 A 为 B`，A 为可依之内建值类）与隐值参数（`凡「x」属 A 而 B`）之成，见[依值类型](依值类型.文言.md)依二。

类型应用首须名义构造器，沿 K 消参；显参域为元类型或已入之内建索引类，实参各验类之成或索引之值，签循参位而核；隐式位置惟授隐参。尽后 K 须元类型。计算首用名义构造器。立可成名义类型，亦可立返回某类型之值构造器。异声明同形，各守其名。构造器之果类展而为组类（命名元组）者，所造之值与按名之投、模式之鉴皆依此元组之形：造与鉴皆依栏名排其显参为元组诸栏之次。

类型构造器之显参可带签，应用循位核签，实参依去签之域而验。元类型之参验类之成，内建索引之参验其值类。

底层卦（定宽无号整数）书作 `（「卦」于「爻数」曰 n）`，具体爻数为编时整常，自一至六十四；指向（带类型地址）书作 `（「指向」于 T）`。卦之相等比爻数，指向之相等比所指之类。

底层元组可作内存之布局。p 为指向 R，R 为元组，则 `p 中 f` 循名或次取栏，还指向该栏之类之址；栏之存否、栏类与自然之齐，编者核之。广、齐与偏移见[底层模式](../底层模式.文言.md)第五节。

## 类二：类等与匹配

先依接口展开透明类，不执行普通值函数体。内建同标签，刚名同名，箭头元组同数而逐项等，命名元组并比名与序，有名无名不等，应用同首同参式而逐项等；全称同数，以同批新鲜刚名开体；名义构造器惟比 P 与 N，今分支忽略 c、K，不可另以编号或声明类加相等之限。

带类型抽象先共换绑定名；与非抽象相比时有局部 η 扩展：依参式以同一新名施非抽象而比。非任意 β 归约。对象子类型检查今惟类等，无普遍宽度子类、协变或动态兜底。

隐参另有 U，映局部待求名至未解或类型。左待求未解则记右项，已解则比旧解，余名刚性；结构递归。尝试失败保进入前映射，不带半成残解；终仍正式验实参。

## 类三：合成与检查

合成 `Γ⊢e⇒A` 得类及补后式，检查 `Γ⊢e⇐A` 得补后式。不能合成不许退动态执行。

| 式 | 合成 | 检查 |
| --- | --- | --- |
| 常量、内建 | 固有类 | 固有类等期望 |
| 名称 | 环境类及引用 | 必要时实例化隐式头而比较 |
| 会 | 无域标不能直接合成 | 期望首箭头域予绑定，验体对余类 |
| 遇 | 验域，扩境合成体，成箭头 | 域与期望首域等，验体 |
| 受 | 不任意合成 | 期望全称，以新鲜类名开体 |
| 期望全称而无受 | 非独立合成则 | 可补隐抽象而验，勿捕为值参 |
| 类型标注 | 验类验物，返所标 | 再与外期望比 |
| 元组 | 逐项合成；有名者得命名元组类，值去其名 | 同数逐项检查；名须逐项同 |
| 投影 | 合成明确元组，取项类；按名者须明确命名元组，以名得序 | 合成后比期望 |
| 条件 | 验爻，先真支合成而验假；失败反向 | 两支同一期望 |
| 顺序 | 前按有验，乃合后，取后类 | 前按有验，后检查；甲非有则报编译之误 |
| 虑 | 合成定义，扩境合成尾；递归取标 | 定义同，尾依期望；不自泛化 |
| 递归 | 不任意推断，局部特取标 | 验递归类，自身入境而验体 |
| 鉴 | 合成对象；首支合成，余支检查 | 对象仍合成，各支同一期望 |
| 调用 | 类四无期望 | 类四有期望 |

首模式支不能合成，不任换支求类；条件之反向尝试另有其则。

复令“即”之后惟许书函数字面（得…而…、设…而…，外可加括）。递归之值本不任意推、惟以标验，书之不称亦于验类之先告：`复令只绑函数字面：「名」的“即”后是…`，带卷、行列与源行（议一四四八）。故上表“验递归类，自身入境而验体”惟施于函体：函体待呼而求，其时槽已填。

## 类四：调用全法

输入头之 T、h，有序脊 S，可选期望 E。先开 T 前连续全称为待求名，袭签名隐参之名；与环境、调用头、期望诸名相犯，或签名无名，乃另取带序之新名；次拆显箭头 A1…An→R，非箭头则 n=0。

从 S 首读至多 m 个类参（以）；显参始则依次取 n 个，间插隐参拒。原 S 非空须足，少则拒；原 S 空可取裸函数实例化。余脊留后轮。已给隐参填 U，皆验为类型；既无隐亦无显而犹调用，拒之。

预读实类，其白名单有自由变量、文件定义引用、有标之式、字面与内建之常、单态满调、单态构造之书及组值。变量与定义取已知之类；标先形成类，式待正检；整字面依「数」，小字面依「小数」，串依「文」，内建依本类。单态满调首须为变量或定义之引，显参满其组，取果类；可省者循补齐之则。单态构造取首之果，组值合诸项而成组类。旧推已竟则袭其解；犹有未解，乃补读二形：其一，投影 `e 中「名」`，e 可由白名单取类，则循字段取类，可逐层而投，带类之址亦循其字段；其二，类已定之满调，首仍限变量与定义之引，隐类参以「以」尽给，或由其自身白名单诸实参尽定，则取其果。内调自推，补读惟循投影之对象与白名单之实参。其余待正检。所期之果先接地，次依实参之序匹配；有余脊则本轮不用终期，裸函数以全显函类代果类。

惟合成之时（E 空），旧推犹有未定隐类参，型参值参各据原声明而辨；诸显参之中，未定之名惟居一个匿函之果位，匿函诸域皆由余实参或已给隐参定齐，乃补标诸域，合其体类，复配果位。调用之向据原期而定；后组尚存而本组暂空所期，外检之向犹存。检查之时，匿函之旧则如故。数匿函之果俱待定者，仍告未定。未解尚存则拒，列未定隐参、形类与所期，示书属或以；全映射惟详调时陈之。推依有序匹配，已有之解仍存。尽解后施诸类型实参，逐个正检显参，补调用树；余脊非空则续，尽则还果，检查之末须等 E。 预读与函体之补推，暂借推算之境；事毕还其名序与隐值之录，正检仍循原次而命名编号。

隐参取诸白名单实类与所期之果；合成之时，另循上则补匿函之果。内调须借外期方能定者，仍须以或属明之。连化为一组，调用须足；函参亦可为函类。

依值之箭之实参验与代、隐值参数之实与推，见[依值类型](依值类型.文言.md)依三。

## 类五：模式

提案 00002 第四步：标准库 `数据结构/多态列。豫` 之「列」「罄」「缀」，乃内建列（`《《内建类型：列》》`、`《《内建列：罄》》`、`《《内建列：缀》》`）之别名。常结构之较与支内合一，仍规旧列类首（主“豫言”、包名“标准库”、包内此模）为内建列身份，以供旧存与旧接口；物类逐项较之。内建罄、缀仍用旧构造器签与字段之形。

合成所鉴 T，各支独立扩境。构造器开隐参使结果匹配 T，载荷逐项验；新名绑定 T，已识构造名不作新名。数、串、爻常量须合 T；元组须明确元组同数，命名者名须逐项同；列糖已展。模式应用必以构造器为首，不逆任意函数；首为函数则类检报“模式里不能调用函数「名」：模式只能由构造器、字面量与新名组成”，支体仍检。

绑定仅本支可见。重复绑定、重复默认依基线失败处理，不自变成相等守卫。运行擦类后按标签、常量、字段判；类检之末，可识之匹配析其穷尽：得缺、得冗、未证皆为编译之误（见[编译警告](编译警告.文言.md)）；编译之器为每匹配存缺支之运行报错之路，惟越类之值（如不安全之转所造者）乃及之。决策树可异，先后可达之行与默认限制不可异，未选支不行。

整数索引之细、“无法细化”与依值模式匹配，见[依值类型](依值类型.文言.md)依六。

### 提案 00002 之分支细化开发规

宿主之界暂拒终果特化之构造器：终果类参必为互异全称之变，不含常量、复合类与重复之变。验此类诸构造器，拒之辞曰“结果类型特化的构造器不能过宿主边界”。待办之事：实作特化构造器之宿主边界转换。

模式之约必不能合，则其支不可达；编译器于支之源码位置报编译之误“不可达的匹配分支”，略其体之类检。模中构造器所属之类非所鉴之类者，编译器于模处告误“模式的构造器「名」不属于被鉴值的类型「类」”（带文件与行列），其体仍验，验毕乃并告。空名 `「」` 为通配：不立系，仍为覆尽诸值之兜底支；`或有「」则` 遂为不系之兜底书（此条改[提案〇〇〇六九](../../../../提案/00069-模式新名写得.汉语.md)“不另设兜底写法”之句；欲用其值者仍书 `或有得「其他」则`）。模中之裸名与可见之构造同名、见以为构造而其类不合者，告误书模名自处与构造所定之处，且示欲于此立新系当书 `得「名」`（[提案〇〇〇六九](../../../../提案/00069-模式新名写得.汉语.md)首段）。合成果类取首可达支；无可达支且无期望类，则不能合成。`--no-warnings` 止警之输出，不可达之支仍报编译之误而略其体。模中之裸名（构造器而外）一立为新系而蔽其外（议题 212、222）；全局之函、本卷之类名、外层之系与模式之变皆然，内建构造器之名与常值仍依表达式验之。模中之施以函数为首、重绑模式名、强定存在参等寻常之误仍报；以函数为首者，筛可达之支时即报。模之位见正名自他卷所展之类型式者，编译器告定讯，书其卷、行列与源行：其源为裸名，则曰“模式变量「名」与类型「名」同名，换个名字”；源中书 以（…），则曰“模式里不能写类型实参，去掉 以（…）”；源文不可为裸名而模之项为元组、箭或隐式前缀之类，则曰“模式里不能写类型表达式：…”；余则循旧告“不是支持的模式匹配项：…”。前二辞末示模式惟构造、字面与新名可为（议题 #419）。

期望之类明定而诸支皆不可达，仍先求所鉴之式，继抛可捕获之“模式匹配错误，缺少分支”异常。

此段录正验之开发规，施行之状及证见[施行记](../../../../提案/00002-实施记录.文言.md)。全 GADT、存在之类及不可达支之验未毕。

构造器所返之类与分析对象之类行双向一阶合一；外境中类为元类型之局部变量，可于本支求解，求解必验其名自现。所得代换施于支之期望返类、局部绑定之类及支体之类参、标注。诸支各立状态，正常返与异常退皆复原状，余支仍用原境。

匹配有明定期望类，乃许此细化。合成匹配仍由首支合返类而检后继诸支；任一支细化外层类变，则告“需类型标注”。后继支由首支所得之类，乃合成算法内部之果，不得据此许细化。局部匹配可用类型判断明期望，如 `（（鉴……）属「文」）`。

存在之类之开发路，先由构造器结果推隐参。结果不能定之参为本支新刚类，字段与随包之函依此类检之；合成支之结果类不得含此新名，否则告“存在类型逃出模式匹配分支”。显式模式类参唯核结果已定之类，不得强定存在之参，亦不得凭其指定而细化泛型构造器之外层索引。跨参组未定之存在参，仍在实现验收之域。

存在之类于隐式模式参中一绑，使检查后支之语法树闭合；复用仍取同一类名。模式转换去其隐绑，运行时构造器字段之次如故。

跨参组之构造器模式，由终构造结果求隐参；读后全称另取新名，将见于终果之有用后继索引纳入推定，唯补今调用组之隐参。后组实绑定仍守同一终索引之约，隐藏类之绑定及逃逸之限遍及全支。

## 类六：无体之声与宿主之界

实签存约筹之宽：常约、应用约之「数」，应底层六十四位「长整数」，实类题『长』，出纳用「取客长」「还客长」；底约三十二位「整数」题『整』，出纳用「取客整」「还客整」。底约所声「长整数」亦题『长』。实约签（实现签名检查）之「实约边类」依约篇之种定其宽狭，合派循已验之类。

包述列「实现接口」，则译器阅所列约包三类接口之篇，以模名与字段共定实身。常约、应用约取包短名，底约取篇名。模 M 之声 F，于实包根下 M 箧诸篇及根下 M 同名独篇求唯一同名之实；域外诸函循常而译。惟书 `乃` 者，犹须具实。阙者告曰 `接口「营造」声明了「阅帛片」，实现包/营造/ 下没有实现`；重者列其各篇。（用户 2026-10-28 定，提案〇〇〇五八。）

实函逐参受之。整数、长整数、小数、爻、单位之类各守其本；串与字节串、列、组、资、有构造之类，各以 `指向 于 客串`、`指向 于 客列`、`指向 于 客组`、`指向 于 客资`、`指向 于 客变` 相应。客类诸标，声于磐石（底层基础库）之 `客值。底层。豫`；指向之术，声于规度（布局内建原语）。透明之别名展而后稽。译器察参之数、次与类，又察其果；不合告曰 `「营造：阅帛片」的实现与声明不合：第几个参数……`。

底层实包之入口，于包内 `.豫构缓存/实约/` 合成常底篇，引诸实卷；约包循上下文之次，约篇循已序清单之次，诸声循声明之次，自零授号。合篇先取验籍之类，再循正名、验类、底层之后端而成分派。约篇及其类依入缓存之印，底层终链收底篇。客物存形与寿命，实方自掌；所用之类各具二术：

- `取客类别 : 指向 客参 → 整数 → 对应的实现类型`，按号取客参。单位之参循边界之制省位，合篇补 `元`。
- `还客类别 : 对应的实现类型 → 指向 客果`，还其果于客；单位之果用 `还客元 : 有 → 指向 客果`。类别之字为整、长、小、爻、串、列、组、资、变。

合篇循实签补召之标签，直召其函。导出三术：`实约计` 告声数；`实约寻号` 受模名字节址与长、字段字节址与长而还号；`实约分派` 受号与 `指向 客参` 而还 `指向 客果`。求号逐字节验双名，阙则还负一；无号而入派则陷。常接口、应用接口之模取包短名，底层接口之模取去缀篇名。装入者依双名求号，继以号入派；声明有变，装入复依名而接。

实现者循底层之制声明内存与静态数据区，以藏名牒之字节。程内显引磐石（底层库）之实约（生成分派调用接口），调同名三术；参果之址各持客参、客果之类。此模经实约机（分派内部链接协议）召合成之术，底层总装内接为直召，阙实与重名皆于编时告之。总装复原入口之径，术名与导出适配皆循旧约。

后续之事：异步所还，实侧交果之约待定。

无体之声者，签名之后无同名之义之 `乃` 声，惟许见于[词法与语法](词法与语法.文言.md)语四所列之文。语法分析合其体：逐参受之之嵌函，至内为一次内原语之调，实参依次为诸层之参。类型检查依声类检之，并按声明类别改其至内之调：

- **宿主导入**（`。接口。豫`）：依诸参之类与所期之果类算边界签名（形与 Wasm 类之应见[网页汇编接口](网页汇编接口.文言.md)网五），附于内名之末，去类为“有”之实参。算形先展透明之类；整数、小数、爻、字符串、有径应；元组、命名元组依项；列于甲为列；字节串、字节缓冲为串；有构造器之类依其声次列诸支，以类之实参代构造器之类参；接口之文无构造器之类为资；果类 `异步返回 于 甲`（标准库 `语言核心/异步原语。豫`）记为异〔甲之形〕，惟许为果之最外。函数之类、全称之类、类变量、列外之递归类、动态分类值，及非接口之文无构造器之类（如引用类），皆报“不能过宿主边界”。
- **内建之声**（`。内建。豫`）：声名须在编译器之原语表，否则报“不在原语表里的内建名”。签名依粗形校之：整数、小数、爻、字符串（字节串、字节缓冲同属串）、有记为整、小、爻、串、元，余类记为任；去元参后，参数与原语表同数，表书“任”之位配诸粗形，余位须同，否则报“内建签名不符”。校通则易为原语之内名（`豫言_` 加声名），代码生成就地生令或调运行时。参之次依内原语。
- **底层内建之声**（`。底层内建。豫`）：内名为 `底层_` 加声名（声名以“声明”起者易为 `声明：` 加其余，如「声明存」易为 `声明：内存`），须在底层后端之原语表（`底层定型。豫`）、车道原语表或殊处之单，否则报“不在底层原语表里的内建名”。签名依粗形校之：整数与爻记为整，小数记为双，底层库数值类型之长整数、单精度、向量记为长、单、向，字符串记为串，有记为元，余类（类变之属）记为任；去元参后，在原语表者参数须同数，址参配整或长，任配诸类，果之元配整，余位须同，否则报“内建签名与底层原语表不符”。殊处之原语唯校其名。
- **底层导入**（`。底层接口。豫`）：模块名为接口文件之名（去其后缀），字段名为声名，改为 `导入：模块：字段：参数：结果`；参果书型字之串（整数与爻为整，长整数、单精度、小数、向量为长、单、双、向；无则书零），去类为“有”之实参，果为“有”者无果；他类则报“底层导入的参数与结果只能是整数、爻、长整数、单精度、小数、向量或有”。其义见《底层模式》七。

- **应用接口**（`。应用接口。豫`）：改为“应用接口：包名：函数名：全签名”，全签名并书类为“有”之参（代码生成以此知实现之何参为“有”），实参仍惟留非“有”者。入口定同名顶层之函则编为导出，入口未实而见调则抛可承之异，见[网页汇编接口](网页汇编接口.文言.md)网五。待办之事：未核入口定义之类与应用接口所声之类同否，今恃接口检查器于实现文件之式核之。

标准库之语言原语，皆声于 `库/豫章/本原/本术。内建。豫`；宿主之务声于 `库/豫章/东道。接口。豫` 与 `宿主带列。接口。豫`（导入模块“标准库”）；标准库之公函改调之，公名与参次不易。底层库之原语声于 `库/底层库/本术。底层内建。豫`，底层库诸模之公函改调之。

## 名一：作用域

局部绑定近者先。顶层循块之序：类块先纳诸类之名与种，乃察器签；类块之即名循声次而纳：见其前所书之类与员，器用其前之即，自引则报未定义之名。义块先察诸签，尽纳诸名与类，乃逐义察之。类块中即名以外之名与义块之员名共见于整块，块外循声次而见。独员存自递归之法，无签之者循旧境而察。当前绑定先于打开文件，打开文件先于空间；空间为值之用，由呼处验之。

空名 `「」` 为通配，不系一值。可书于 `令` 之系位（`令「」为 值 而 体`）、`得` 之参位（`得「」而 体`）与 `鉴` 之模（`或有「」则 …`，及嵌于复合之模者），一所可书数枚。于式中引 `「」` 则报编译之误“「」是通配，不能当名字引用”，带卷、行列与源行；模位之 `「」` 为通配而非引。`令` 后单书一非空之名仍为新系，`得` 后之非空名仍为参名。

`令` 所系之名于体内一无所用者，编译器发警（首段惟警，三段改为编译之误），其文书值之类，且示“要用就接住；要丢就写 令「」为”。通配 `「」`、`得` 之函数参、`复令` 与顶层之定不在警内。

无副作用之函见直召而其果又弃者，编译器发警（首段惟警，三段改为编译之误），其文如“「名」没有副作用，它的结果没被用到，这一句什么也没做；要用新值就接住它”。覆 `令「」为 召`、系名而不用与 `召 而后 …` 三书；惟认最外即召之式，值为若、鉴之类复合者不报。副作用依召而推：写匣、改列、出入、东道之接与告祸为有，读匣、造匣、算术与构值不为，经参、闭包、函值之召不可知者概以为有；递归之顶层依强连通分求其定。所推之果随模块接口而布（见名二）。

`鉴` 之模中，裸名与构造同者（含构造之值别名）为构造之模；余裸名一立为新系而蔽其外，与本卷之类名、顶层之函、常值同名者亦然（议题 212、222）。既蔽，支体中同名之引归内新系，递归之呼亦取内者（议题 434）。他卷所展之类名居模之位，则依“模之项为类型式”告定讯，模式之变另取一名即可（议题 #419）。裸名与构造同名而见以为构造者，书构造所定之处，并示同名书 `得「名」` 即立为新系。

空间者，`寻` 所立之静态名域，惟居 `之` 投影之左，不可为参、为返、为类或为数据。`空间之名` 于名称期消为所指文件中之定义引用，不运行查字段。打开文件新者前加，故后观先查；顶层定义却附于已有绑定末，重复时先项可先中，文件投影亦取首名。不可一概谓所有名称后者胜。须存其不同次序。

## 名二：导入与包

模块有同名 `名。签名。豫` 者，外引先取其签为公约；底层取 `名。底层签名。豫`。实义仍出同名常卷或底卷。签声循序而验，类可引前声及所导之类。内按实义校约：名存、种同、值类合、透明之体同；具体之块，构造俱全，类序相应。无签之卷，诸义皆出，展类循旧。

外引之正名验类待公约；有签则约待签文及所导之约。实卷私义虽易，外引之检仍可用；降级成码另待实形。实卷自检之键兼存配签之摘。模块接口别存「纯性表」之分：顶层定之名与“召之有无副作用”之爻，阳为纯、阴为有；导入方作纯召弃果之警时读之。有签之模自其实推此表，约中之类仍取于签。旧约无此分者以“纯性未知”处之，即当有副作用，不阻其编。

路径以包名、登记之子包名与包内模块名成之。包根为 `名字。包。豫` 所在；依赖与子包之登记（「包含在」「包含包」）明列。首段必为本包自身或其直依之名，是为始包；自次段起，段为当前所指包登记之子，则入其子而续，否则余段为所指包内之模块：子先于模块。路径止于包（单名，或止于子）则依其默认导入而展（详下），不聚目录；多段自所指包之根逐级。模块之文先求 `模块名。豫`，无则次求接口之文 `模块名。接口。豫`、`模块名。应用接口。豫` 与内建之声 `模块名。内建。豫`，又次求着色之源 `模块名。着色器。豫`（导之得构时所生之模）。着色之文（`。着色器。豫`、`。着色器接口。豫`）之所导，惟求 `模块名。着色器。豫` 与 `模块名。着色器接口。豫`，见[着色语言](着色语言.文言.md)着二。底层之文（名含「。底层」）之所导，惟求 `模块名。底层。豫`、`模块名。底层接口。豫` 与 `模块名。底层内建。豫`；高级之文导此三种底层之模则报错，诸缀尽见[文件后缀](文件后缀.文言.md)。未登记之嵌套包仍为界，不可经父路径越之；登记之子，可经父路径引之。源用 `。豫`，兼容输入亦识 `.yuyan`。

导入之操作有三：寻载目标之文，而立末段名之静态空间；观纳已导之文所有名于未限定查找，所观之文须已由寻或寻观导之；寻观兼二者。依赖图含所需接口，自导与环导拒，不加载半接口规避。

默认导入者，库包述中「类型」所必书之「默认导入」也：其值为列，可为空列（空列示此包之导必明书模径）。目者，以“/”分段之包内模径（不含缀），或登记之子名；子先于模，子目则递归展其子自身之默认导入；诸目所展之叶模，不许导出同名之义。展为多叶模，则寻以末段绑一空间，对应诸叶模（`包名之名` 逐叶模求之），观依目之序逐一开之，寻观兼二者；所绑之空间惟末段之一，欲得某目自身之空间者，显寻其模。字段之书与检，见[豫构包系统](../../../豫构/包系统.文言.md)“默认导入”。

包定位非值 ABI，然输出 P 入符号。模块相施必须同 P，不擅换工作目录实址。可由定位层供绝对身份、源码及有序依赖，避免类型检查暗寻路径。

## 名三：构造与定序

器序自一起，循所属类块、同果头之器次而计。剥全称、箭头，再取应用头；同块异类，各自计数。归纳之类，其器全集取诸本块，鉴之覆盖据之。取块之员，惟取立类与器；块中即名循声次而纳，以备器用。

器果之头须为本块所立之类，否则报编译之误“构造器「K」的结果类型「T」不在本块”；器之序惟依本块之次计。

义块第 i 义配第 i 签；多员之签皆以化或凡始。错序、阙义、常量互递归，察声时告之。透明之即循单项旧法。

签中 `「甲」乃「类」也` 及带参种之同类声，出为抽象之类。外籍惟存名义之身（签卷与名）及种。`甲 A₁…Aₙ` 与 `甲 B₁…Bₙ` 同，当且惟当诸参逐项皆同；与他类及实形各别。卷内循实展之；过宿主之界、生成之码，皆按实形成之。

外惟见签所列之名。抽象之值，由公函授之；欲鉴其物，经公函取其可验之果。透明之声 `「甲」即 R 也` 存其体；「立」所全出之块，诸构俱存，造拆如常。外类不合之告，注明抽象所出之签卷。

公声依签序而录。降级按模块之卷名与声明之名，系于实义表之序；径召与链接皆用实序。实卷增私义者，外引之验类缓仍可用，降级则依实义重系其引。

签有可省之参，则并生默认之隐声，类取公参，所需隐类参袭函之前缀。隐声与实卷默认之义同受签察，公约载之；跨卷省参，则据此引实卷之默认值。

卷外抽象之类，覆盖循公约，器集为空；鉴之通配支可覆其值。具体之类，读接口所存之器全集；成约时循所属块取之，存察后之类、名义之籍与块内之次。本卷覆盖取察后全义；块属之察定循果类之首所取者即本块之器。

文件接口分藏公义与具体之器全集。公义存类型、值、构造各项；透明存体，值存类与引用，构造存类与身份。器之块属与次序入约摘，全集变则外鉴之储随之更新。无签之约待察后义及原声，有签之约依签成籍。编译产物只可装配，不足验新源码。

最终定义列定全局：常源文之顶层为书作常初值之数据，试、脚本、金样别有程序之体（见[执行与编译](执行与编译.文言.md)行一）；多态类型擦除可为空占位，不可压序。匿名名有内部计数，换旧对象须携接口清单，不命他方猜之。
