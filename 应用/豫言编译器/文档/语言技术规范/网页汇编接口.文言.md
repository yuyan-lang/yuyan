# 网页汇编接口

## 网一：唯一之目标

编译器唯一目标：WasmGC。用引擎引用、类型数组、结构及 Wasm 调用栈，不赖任何“裸指针之约”。本篇节号恒定，以便引述；原第二节随旧目标而删。

## 网三：GC 值

表达式皆返 `(ref null eq)`，实际如下。

| 值 | 表示 |
| --- | --- |
| 单位、擦除类 | ref.null eq |
| -2^30…2^30-1 整 | 有符号 ref.i31 |
| 其余 i64 | `$big=struct(field i64)` |
| 爻 | i31 0/1 |
| 小数 | `$float=struct(field f64)` |
| 元组、引用、闭包、数组 | `$tuple=array(mut (ref null eq))` |
| 串、字节、字节缓冲 | `$bytes=array(mut i8)`，不附隐藏之末零；字节缓冲可改，惟以类别于字节串 |
| 构造实例 | `$variant=struct(field i32,field (ref $tuple))`，号及载荷 |
| 资源（接口之文无构造器之类） | `$外=struct(field (ref null extern))`，字段不可改，藏宿主所授之物；可空者，惟令原型全局得以 struct.new_default 造之 |
| 代码 | i31 函数表索引 |

闭包首代码，余捕获；普通源函数保擦后逐参链，内部多参数型不由源箭头数臆定。代码 ref.cast i31、i31.get_u 后按参数数目 call_indirect，不填宿主之址。

## 网四：调用、模块、异常

本基线恒生 t0 至 t16；模块之函数或动态调用参数逾十六者，依所用最大参数之数 N 续生 t17 至 tN。参数皆 eqref，结果亦然，self 入参数数。尾调用 return_call_indirect，普通合流用结果块与 br，不设续延之帧。

函数索引依闭包树组之序，全局键 `路径#定义名`，不含定义序号；输出合并一模块，非可任意拼接之约。替单函数须保表号、类型、全局，或桥接。

导出 `_start`，先 data 生串全局，再于承 `$error` 之 `try_table` 中依序调模块并弃果，后行启动文本。漏网之 `$error` 至 `_start`，以其串调 `$exception` 全局所存之顶层未承之术（闭包）；术返则 `unreachable`，术空则转型败而陷。字面按 `\hh`，不假有效文本而改字节。

串异用 `$error` 标签，载其串一 eqref。抛即 `throw $error`，模式缺支亦然。尝试调模块内之 `$try(操作, 处理)`：于 `(try_table (catch $error …))` 中以元调操作之闭包，常终径返其果；承之则出 `try_table`，以异串尾调处理之闭包。二闭包皆依公约间调（型 `$t2`，首参为闭包自身）。`$exception` 可变全局唯存顶层未承之术，标准库以 `豫言_设置当前异常处理器` 登之。

提前返用 `$escape` 标签，载标识与值两个 eqref。每入动态之域新造空 `$tuple` 为标识，以 `ref.eq` 较之，无次数之限；捕获比标，不同重抛，越动态范围不支持。二标皆模块自定；`$error` 以 `yy_错误` 之名出，宿主之导入术可以之抛尝试所能承之异，载本模之 `$bytes` 为辞（JS 宿主书 `new WebAssembly.Exception(exports.yy_错误, [辞之字节])`）；`$escape` 唯用于模内。算术、索引、cast trap 非自动可捕字符串异常。

## 网五：宿主之界

客与宿主之间有二途：带型之导入，及过渡所留之旧通调 `call`。新代惟用前者。

### 带型之导入

`。接口。豫` 之无体之声（构建时未为适配所代者）编为带型之 Wasm 函数导入。模块名为所在包之短名，字段名为声名，皆不带版本；（模块，字段）一模唯一，同导再见，签名须同。导入于函数编号先于自定之函，其序编译器定之、每次同，宿主依（模块，字段）绑之。接口之模既链入，其所声诸函皆成导入；宿主所未实者，给桩，调之乃报“接口函数未绑定：模块.字段”。

类型检查依参果之类算边界签名，书作“参形，参形→果形”。参之元不书，故签名之参与 Wasm 之参一一相当。形之文法见汉语稿。

| 豫言之类 | 形 | 顶层参果之 Wasm 类 | 嵌于元组之表 |
| --- | --- | --- | --- |
| 整数 | 整 | i64 | 规整之 i31 或 `$big` |
| 小数 | 小 | f64 | `$float` |
| 爻 | 爻 | i32，惟零一 | i31 零一 |
| 字符串、字节串、字节缓冲 | 串 | `(ref $bytes)` | `$bytes` |
| 有 | 元 | 参省，果无 | 空引 |
| 接口之文无构造器之类（资源） | 资 | `(ref extern)` | `$外` |
| 元组、命名元组（依字段之序） | 组〔…〕 | `(ref $tuple)` | `$tuple` |
| 列于甲 | 列〔甲〕 | `(ref $tuple)`，诸元依甲之嵌表 | `$tuple` |
| 有构造器之类 | 变〔支｜…〕 | `(ref $tuple)`：首为支序（构造器于类声之次，自零始）之 i31，次为载荷诸项 | `$tuple` |

顶层之引皆非空，惟元组之元可空。诸转换皆在客内：整拆装，小取装，爻转 i31，资拆装 `$外`（参拆后先断其非空）。列、变及含列变之组，以编译器依形去重所生之转换函处之；惟含整、小、爻、串、元、资之组径传，宿主惟读之，不改客所授之元组，惟写引于己所新造者。不可过界之类，类型检查时报误：函数（回调宜用应用接口）、泛型之函与类变量、列外之递归类、引用与数组引用等非接口之文无构造器之类、动态分类值。

### 自定之段「豫言边界」

凡 WasmGC 之模皆带名 `豫言边界` 之自定之段，内为 UTF-8 文，一行一项，行尾换行，字段以制表符隔之：`导入⇥模块⇥字段⇥签名`，每带型导入恰一行，序同导入段；`导出⇥导出名⇥签名` 为应用接口之出（待办事项：尚未生）。无带型导入则其内为空。读者遇不识之首字段，略其行。JS 宿主据此识豫言之程，依签名转值；原生执行器可不读之，依 Wasm 类校之。

### 原型全局与值桥

模示宿主以不可变之类原型全局 `yy_bytes`、`yy_tuple`、`yy_big`、`yy_float`、`yy_extern`，另出异常之标 `yy_错误`（见网四）。宿主取实际引擎类型造返回值，不能另造同形而不兼容之型。原型与宿主所用之引擎同配置，跨版本另验。

JS 宿主经值桥之模（与编译器同代所生，类型定义与客运行时全同）读写嵌于元组之值：`kind` 辨其类（空〇、小整一、字节二、元组三、大整四、小数五、资源六），`int`/`new_int`、`float`/`new_float`、`ext_get`/`new_ext`、`tuple_len`/`tuple_get`/`tuple_set`/`new_tuple`、`bytes_len`/`bytes_out`/`bytes_in` 读写诸值，字节经值桥之线性内存相换。三家 JS 宿主共用胶水 `豫言操作系统/宿主/网页汇编/边界.mjs`：读「豫言边界」之段，依签名互转 Wasm 值与 JS 值，无实者给桩；惟标“异步”之实乃套 JSPI。

### 旧之通调（过渡）

模中尚有 `《《外调》》`，编译器乃书导入 `yuyan:gc-host/v1` 之 `call`，型 `(eqref,eqref)→eqref`，首为原语名 bytes，次为依外调参数之序之 tuple。桥容单位、i31/i64、f64、bytes、普通 tuple；i31 授宿主为整数，宿主返爻则映为 i31。深限 512，不通传任意构造器、闭包、宿主指针。每调用设宿主侧独立临时之存，造完返回引用即尽释。复制不保任意环与共享，引用变更和闭包必须留 guest。

guest 已含引用及数组、抛异与尝试、登顶层未承之术、不安全恒等、整数加减乘除及相等、串字节拼接与比较、长度、取字节、截字节串，字节缓冲之造、一字与小端四字之读写、填、抄、转字节串，及若干 UTF-8/JSON 操作。形参次序仍须守。诸名亦为「。内建。豫」内建之声所可用之原语（见[类型与模块](类型与模块.文言.md)类六）。
