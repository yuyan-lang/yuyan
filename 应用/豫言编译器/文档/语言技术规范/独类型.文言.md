# 独类型

独于某类者，其值当恰用其一。凭据、句柄、暂文之属，交之收之皆止一回者用之。类之构造独与作独、去独，由豫章独行之篇供之，`寻观「豫章」之书。` 即可径用。编者于验类之时核其用。此文与[汉语稿](独类型.汉语.md)同步。

## 独一：书法

```yuyan
寻观「豫章」之书。

「凭据」立「类」也。
　「造凭」立化「数」为「凭据」者也。

「凭号」乃化「凭据」为「数」者也。
「凭号」者得「凭」而
　鉴「凭」而
　　或有（「造凭」于得「号」）则「号」
也。

「登记」乃化「数」为（「独」于「凭据」）者也。
「登记」者得「号」而「作独」于（「造凭」于「号」）也。

「交付」乃化（「独」于「凭据」）为「数」者也。
「交付」者得「凭」而「凭号」于（「去独」于「凭」）也。

「书」于（「述数」于（「交付」于（「登记」于「七」）））。
```

- 作独以常值为独值，开一账，恰用其一；乃独之构造器，其类为 `凡「甲」而化「甲」为（「独」于「甲」）`。
- 去独以独值还常值，账于此毕，其类为 `凡「甲」而化（「独」于「甲」）为「甲」`。所得之值如常用之。
- 常独之转皆手书：须独之处书作独，须常之处书去独。二者异类，混用则告类不相等。

## 独二：恰用一回

参与令系之类为独于某类者，谓之独名。每独名每径恰用其一，下列每一皆为一用：

- 授类为独之参；
- 为函之所还；
- 去独；
- 授他名（`令「乙」为「甲」而 …`），自此乙续其账。

若、鉴、且、或诸支所用之独名须同；以告祸终之支不计，其少用者不告。递归之函得以独名为参而自授。匿名之函、局部之函（复令）与回调皆常函也：常函所用之独名惟出其自参与其内之令系，外之独值以参授之。

违之则告编译之误，其位为误处之名或式：

| 情形 | 诊辞 |
| --- | --- |
| 一径之中再用以上 | 独变量「凭」用了 2 次：独值恰要用一次；要多处用就先「去独」，这里是第二次 |
| 一无所用 | 独变量「凭」没用掉：独值恰要用一次（传给收独的参数、作返回值或「去独」） |
| 诸支用数不同 | 各支用掉的独变量不同：「凭」在一支里用了 1 次、在另一支里用了 0 次；若、鉴、且、或的各支要用掉同样的独变量 |
| 常函及外之独名 | 常函数里不许提到外面的独变量「凭」：匿名函数、局部函数与回调里要用独值，就把它当参数传进去 |
| 以独值系于「」 | 独值不能丢（类型「…」）：独值恰要用一次，传给收独的参数、作返回值或「去独」 |

`而后` 前之值见弃者依常规告误，独值亦在其中。

## 独三：类之所居

`「独」于 T` 为名、参、果之全类：令系之类、函类之参类与果类。函类本身为常值，可入列、记与他类。编者于下列情形告编译之误：

| 情形 | 诊辞 |
| --- | --- |
| 裹于类施之实参、记之栏、元组、命名之项 | 「独」只能作变量、参数、结果的整个类型，不能套在别的类型里 |
| `「独」于（「独」于 T）` | 「独」不能再套「独」：独值已经是恰用一次的值 |
| 构造器之栏含独 | 构造器的字段不能是独值：变体的载荷与记录的栏里不许有「独」 |
| 类之别名全为独 | 类型别名不能是独类型：在用到的地方直接写「独」于 类型 |
| 顶层之定其类为独 | 顶层定义不能是独值：独值只能作变量、参数、结果的整个类型；要长存就先「去独」 |
| 泛函之类参取独 | 「某函」的类型参数取了独值（类型「…」）：泛型函数碰不到独值，先「去独」再交给它；「作独」也不能再套独值 |
| 元组之一项为独 | 独值不能装进元组：「独」只能作变量、参数、结果的整个类型 |
| 鉴独值 | 独值不能直接鉴：先「去独」，再鉴得到的值 |

泛函之类参惟一处得取独值：告祸之果类参，告祸不还故也。径鉴独值惟书于独行之篇（去独即如是实之）。取独值之栏依常规告类误，先去独而后取。

## 独四：实现

- 豫章独行（`库/豫章/形制/独行。豫`）：独为单器单栏之类，行时径以其栏为形，作独、去独不另费。
- 登：验类为参与令系定类之时，类为独者依系名之源域书于本卷独系之单（`库/译场/分职/证义/独察。豫` 之登独系，由录源系悬停召之）。
- 恰用一回：验类之后循正名后之定义列一行（察独恰用列），依单识独名，逐径记账，诊带卷与行列。单空之卷越此一行。
- 类之所居：签、构造器与别名于卷构之察中察之（察顶独嵌、察器独嵌、察别名独）；元组与鉴于验类之时察之（察组无独、察鉴独）；泛函之类实参与带类之系于察后之物察之（察独泛型列），诊位取所在之定义。

## 独五：后续之版

- 告祸之径：握独值而召或告祸之函，告祸之出口上独值何以收之。此版不察告祸之出口，以告祸终之支亦不察其少用。
- 可失败之取：可失败之操何以交出独值（成否之中裹独值）。
- 借出：不耗独值，惟一观或暂借之。
- 独函：捕独值之闭包。
- 唯一、局部、共享诸余用法之轴。
