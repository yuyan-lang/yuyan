# 独类型

独于某类者，其值当恰用其一。凭据、句柄、暂文之属，交之收之皆止一回者用之。类之构造独与作独、去独，由豫章独行之篇供之，`寻观「豫章」之书。` 即可径用。编者于验类之时核其用。此文与[汉语稿](独类型.汉语.md)同步。

## 独一：书法

```yuyan
寻观「豫章」之书。

「凭据」立「类」也。
　「造凭」立化「数」为「凭据」者也。

「凭号」乃化「凭据」为「数」者也。
「凭号」者得「凭」而
　鉴「凭」而
　　或有（「造凭」于得「号」）则「号」
也。

「登记」乃化「数」为（「独」于「凭据」）者也。
「登记」者得「号」而「作独」于（「造凭」于「号」）也。

「交付」乃化（「独」于「凭据」）为「数」者也。
「交付」者得「凭」而「凭号」于（「去独」于「凭」）也。

「书」于（「述数」于（「交付」于（「登记」于「七」）））。
```

- 作独以常值为独值，开一账，恰用其一；乃独之构造器，其类为 `凡「甲」而化「甲」为（「独」于「甲」）`。
- 去独以独值还常值，账于此毕，其类为 `凡「甲」而化（「独」于「甲」）为「甲」`。所得之值如常用之。
- 常独之转皆手书：须独之处书作独，须常之处书去独。二者异类，混用则告类不相等。

## 独二：恰用一回

参与令系之类为独于某类者，谓之独名，拆独所鉴出之载（见独四）亦然。每独名每径恰用其一，下列每一皆为一用：

- 授类为独之参；
- 为函之所还；
- 去独；
- 授他名（`令「乙」为「甲」而 …`），自此乙续其账；
- 为拆独之鉴所用。

若、鉴、且、或诸支所用之独名须同；以告祸终之支不计，其少用者不告（逢祸何以收物见独五）。递归之函得以独名为参而自授。匿名之函、局部之函（复令）与回调皆常函也：常函所用之独名惟出其自参与其内之令系，外之独值以参授之。

违之则告编译之误，其位为误处之名或式：

| 情形 | 诊辞 |
| --- | --- |
| 一径之中再用以上 | 独变量「凭」用了 2 次：独值恰要用一次；要多处用就先「去独」，这里是第二次 |
| 一无所用 | 独变量「凭」没用掉：独值恰要用一次（传给收独的参数、作返回值或「去独」） |
| 诸支用数不同 | 各支用掉的独变量不同：「凭」在一支里用了 1 次、在另一支里用了 0 次；若、鉴、且、或的各支要用掉同样的独变量 |
| 常函及外之独名 | 常函数里不许提到外面的独变量「凭」：匿名函数、局部函数与回调里要用独值，就把它当参数传进去 |
| 以独值系于「」 | 独值不能丢（类型「…」）：独值恰要用一次，传给收独的参数、作返回值或「去独」 |

`而后` 前之值见弃者依常规告误，独值亦在其中。

## 独三：类之所居

`「独」于 T` 为名、参、果之全类：令系之类、函类之参类与果类。函类本身为常值，可入列、记与他类。编者于下列情形告编译之误：

| 情形 | 诊辞 |
| --- | --- |
| 裹于类施之实参、记之栏、元组、命名之项 | 「独」只能作变量、参数、结果的整个类型，不能套在别的类型里 |
| `「独」于（「独」于 T）` | 「独」不能再套「独」：独值已经是恰用一次的值 |
| 构造器之栏含独 | 构造器的字段不能是独值：变体的载荷与记录的栏里不许有「独」 |
| 类之别名全为独 | 类型别名不能是独类型：在用到的地方直接写「独」于 类型 |
| 顶层之定其类为独 | 顶层定义不能是独值：独值只能作变量、参数、结果的整个类型；要长存就先「去独」 |
| 泛函之类参取独 | 「某函」的类型参数取了独值（类型「…」）：泛型函数碰不到独值，先「去独」再交给它；「作独」也不能再套独值 |
| 元组之一项为独 | 独值不能装进元组：「独」只能作变量、参数、结果的整个类型 |

泛函之类参惟一处得取独值：告祸之果类参，告祸不还故也。取独值之栏依常规告类误，先去独而后取。

## 独四：拆独

独值之类为变体、诸构器至多一栏者，可径鉴之，谓之拆独。鉴即用所鉴之独值一回；入带一栏之支，其栏所系之名仍为独名，于此支恰用其一；入无栏之支，账于此毕。可败之取故可交 `「独」于（「成否」于 T 于 缘由）`（成否在豫章成亏，另书 `寻观「豫章」之「形制」之「成亏」之书。`）：

```yuyan
「试登」乃化「数」为（「独」于（「成否」于「凭据」于「文」））者也。
「试登」者得「号」而
　若（「号」大于「零」）则「作独」于（「成」于（「造凭」于「号」））否则「作独」于（「误」于『号要大于零』）
也。

「试取」乃化「数」为「数」者也。
「试取」者得「号」而
　鉴（「试登」于「号」）而
　　或有（「成」于得「凭」）则「交付」于「凭」
　　或有（「误」于得「由」）则（「书」于（「去独」于「由」）而后「零」）
也。
```

成支之凭为 `「独」于「凭据」`，授之交付；误支之由为 `「独」于「文」`，去独之后如常用之。或可有之独值亦可拆：可有之支鉴出独值，可无之支无载。拆独之据，F 于和类之分配 F(A+B) ≅ FA ⊕ FB（F 为左伴，存余积），鉴即 ⊕ 之消。独惟一构器一栏，编者不装其箱，行时拆独即常鉴。

鉴独值者诸支皆书其构器。编者于下列情形告编译之误：

| 情形 | 诊辞 |
| --- | --- |
| 以名或「其他」兜底 | 鉴独值时每支都要写出构造器：不能用变量或「其他」兜底，兜底的那支拿不到载荷，账就丢了 |
| 构器二栏以上 | 拆独只拆每个构造器至多一栏的变体：这个构造器有 2 栏，先「去独」再鉴 |
| 载位复套模 | 拆独只拆一层：鉴出的载荷要直接绑一个名字，不能再套模式；要细分就在这一支里再鉴它 |
| 载位书「」 | 独值不能丢：拆独时鉴出的载荷要绑一个名字，在这一支里恰用一次 |
| 拆元组或记 | 拆独只拆变体，不拆元组与记录：先「去独」，再鉴得到的值 |
| 鉴出作独 | 独值不能直接鉴出「作独」：要拿里面的值就「去独」；里面是变体时，直接鉴它的构造器（拆独） |

所鉴出之载与他独名同记其账：再用、未尽其用、为常函所及，皆依独二之诊告之。元组与记之属积类，先去独而后拆：一笔善后（见独五）惟管一义，拆积则分之为数。径鉴出作独惟书于独行之篇（去独即如是实之）。

## 独五：告祸之出口与善后

握独值而告祸，祸越未了之账，承之之姑试照常而行。验类以告祸终之支为不返之径，少用之独名不告，当线性之逻辑零类之左则：不返之径可弃其余物。逢祸亦当收之物，取之之库登一笔善后（祸时之收）：

- 登善后：受收尾之术（受元），登于善后之簿，还一笔善后。取物之时呼之，存此笔于物之形中。
- 了善后：物常收或转付他人之时呼之，此笔于此销之；已了者再呼无为。
- 姑试入门记其账位；承祸之时，先倒行此层所登而未销之收，乃付处祸之术。
- 每笔善后记登时所行差遣役之号。诸役交错而行，姑试惟收本役所登；役终（成、败或见断），差遣以行役善后收其所余未销者。
- 祸终无承，常处祸书辞之后先尽善后，然后退。自登他顶层处祸之程，临退当自呼尽善后。
- 收尾自告祸，其辞书于误出，余收照行，原祸照付处祸之术。

善后皆在豫章祸福（`库/豫章/本原/祸福。豫`），编者不与。例：

```yuyan
「临凭」即「组类」【「号」乃「数」也，「后」乃「善后」也】也。

「开临凭」乃化「数」为（「独」于「临凭」）者也。
「开临凭」者得「号」而
　令「后」为「登善后」于（得「无」而「书」于『祸时收回临凭』）而
　「作独」于（「组值」【「号」者「号」也，「后」者「后」也】）
也。

「收临凭」乃化（「独」于「临凭」）为「有」者也。
「收临凭」者得「独凭」而
　令「凭」为「去独」于「独凭」而
　「了善后」于（「凭」中「后」）
也。
```

常径以收临凭了其账；开临凭与收临凭之间告祸，承祸之姑试代行其收。营造草牍之临时件依此而书：领临时件登善后而出 `「独」于「临时件」`，常径必恰以收临时件收之，或以交临时件付他程一次（议一千七百二十）。其先例为 Linear Haskell 之库 linear-base 之 RIO：取物之时并交释放之术，保所取之物终得释放。

## 独六：实现

- 豫章独行（`库/豫章/形制/独行。豫`）：独为单器单栏之类，行时径以其栏为形，作独、去独与拆独不另费。
- 登：验类为参与令系定类之时，类为独者依系名之源域书于本卷独系之单（`库/译场/分职/证义/独察。豫` 之登独系，由录源系悬停召之）；拆独所鉴出之载，由鉴验类之拆独支易为独而登之。
- 恰用一回：验类之后循正名后之定义列一行（察独恰用列），依单识独名，逐径记账，诊带卷与行列；鉴之一支模中有独系者，移支体一位，补一系而行。单空之卷越此一行。
- 类之所居：签、构造器与别名于卷构之察中察之（察顶独嵌、察器独嵌、察别名独）；元组于验类之时察之（察组无独）；拆独之模于鉴验类之拆独支察之；泛函之类实参与带类之系于察后之物察之（察独泛型列），诊位取所在之定义。
- 善后：豫章祸福之善后簿为新者在前之单链，善后序逐笔编号，每笔又记登时之本今役号；姑试之账位即入门时之善后序，承祸之时惟代行号大于位而役为本役者；差遣于账终、账终换回之中先以行役善后收所了之役之余善后。

## 独七：后续之版

- 借出：不耗独值，惟一观或暂借之；“还句柄又带其果”之类须拆积之书法，亦由之解。
- 独函：捕独值之闭包。
- 唯一、局部、共享诸余用法之轴。
- 多核差遣开时，善后簿依核分账或加锁；懒开就地所行之役各记其号（今皆记负二，交错则不相分）；陷阱、辍役与断电之时，由行在于任务终时代收；「辞」退之前行善后。
