# 编译警告

此为提案 00002 编译警告通道之规。今正造而验，整步之状见[施行记](../../../../提案/00002-实施记录.文言.md)。

编译之警默认启，构建仍行。警、定误、内误共书 `文件:行:列：所在定义：说明`，行列起一。匿名之句题 `顶层语句`，内误之辞冠 `内部错误：`。`--no-warnings` 止本次之警出与警录；覆盖之析、成块归属之察皆如故，其果为编译之误者仍报。并行工作进程受同参，任务虽成，其警行亦转于父进程标准错误。

验类不得其名，则报编译之误，首行书 `文件:行:列：所在定义：未定义的名字「名」`。名为标准库更名前之旧称，则别书 `「旧名」今作「今名」`；有可见之近名（本地之系、本卷顶层之名与所观之书，依编辑距离取之，至多三），则别书 `相近的名字：「甲」「乙」`。外层诸检原样传其定讯；旧调用失域者，由统一出口报内误。

验类推不出函数应用之隐参，则报编译之误，首行书 `文件:行:列：所在定义：函数「名」的隐式参数无法完全确定：未能确定 甲`，指误处之应用；继列 `函数的隐式参数：`、`形参类型：`、`期望类型：` 与 `提示：`。所期之类乃检查模式所求之果类；合成模式书 `没有期望类型（合成模式）`。外层诸检原样传其定讯。

类不相与拉姆达之验不成，亦报编译之误。物验类（按期望类型检查表达式）、物类合成（按值合成类型）遇首为 `不相等！` 或 `拉姆达只能检查为明确的函数类型：` 之误，取本式最外之域，次退今源域、今定义域，经统一出口具定义之名与原辞。外层诸检原样传之；`-vv` 亦循此式。

「告定讯」（报告定稿诊断）依所给之域、今源域、今定义域之次取首有者。今定义域乃正名所记之声明名域，匿名之句则取全句。三者俱无，立告内误“诊断缺少源位”。「报定」（构造诊断）必受源域，卷空或行列负则立告内误。诊断具起讫行列、定义之名与原辞。待报之列于登记之际成诊，存其时之域名，卷末依次并出。

译之入口以「成否」（结果类型）承诸阶之果，成则还值，误则书诊于标准误，以退出码一终。定讯传递之冠于出口去之，调度转其诊与败状。内异至此具今源域与定义名；未入树节则取任务之卷首行首列。全构与工作之程共此出口。诸子式之精域，待提案 00059 第二步补全。

语言服务之源码范围起零，左闭右开。警录含 `种类：警告`、全 `范围`、`内容`、`定义`，与定义位及悬停资料俱存。类型检查资料以阶段快照持久存之；模式展开复其资料，补警而写回，存既有定义及悬停之录。编译警告阶产亦存全域与定义名，冷编、中缓共此格式化之出口。

警告之标与覆盖之析步数之限入编译缓存身份。启、止各存语言服务产物，免止警之时仍取含警之旧物；覆盖之断为编译之误，编不成则不留验果，故其标惟系仍循警途之警。步数之限异亦各存，复旧则可复用故存。

未用匹配分支之误指该支 `有`、`或有` 字。名称解析循原源码重建其范围，略注、字串与引号名；分支类检及模式转换存之，决策树展开去其标。

重支报编译之误“未使用的匹配分支”。GADT 构造器终果与分析式之类合一而必相冲之支，报编译之误“不可达的匹配分支”；不验其支体，余类误仍报。

顺序之式（`甲 而后 乙`），甲之类当为有。甲非有则报编译之误：误指甲，其文如 `而后前面的值被丢弃（类型「爻」）：要处理就用它；不要就写 令「名」为（…）而 …`，书甲之类与二改法。甲为有时不报；前式明书 `令「名」为 甲 而 乙` 者属令之系，亦不报。

可识之匹配，支之类检后存覆盖矩阵，文件类检毕，以全定义析有用性及缺例。冗支报编译之误，指其支；缺失报编译之误“缺少匹配分支”，指 `鉴` 字，例至多三。名依匹配处原声明之前缀、已检之义及局部避名析之，导入别名存其限定之名；内建构造器（阳、阴、元，及内建列之罄、缀）无声，名未为本地定义、局部绑定所占，则用内建之名。中间形式无鉴位者暂沿首支之位。冗支不以支体惟抛错而免。此诸断于类检之末一举排为定讯而出，不于首处而止；模式展开之阶不复重报未用之支。语言服务之产仍供编辑器示悬停、跳转与警。待办事项：全诸模之转换。

覆盖之析分三果而别报，皆为编译之误。得缺则报“缺少匹配分支”，例至多三；已证有缺而今境无可书之名者，仍报“缺少匹配分支”而略其例。得冗则报“未使用的匹配分支”，唯证得乃报；未证其冗者不报。既未得缺、亦未证尽者，报“鉴的穷尽证不出”，其由有二：候选补全之步数尽，或候选回溯存未知（原语引用之字段、未定类之循环等），二者书曰“鉴的穷尽证不出：补全分支，或加一个兜底分支（可调大环境变量「豫言穷尽步数」）”；模不可化为覆盖之析、支失其域、析类非单列者，全匹配不得入证，书曰“鉴的穷尽证不出：此处的模式无法分析，请改写模式或补一个兜底分支”。已得缺者惟报缺，不复报“证不出”；未证者不据以报冗，亦不印未知候选为缺例。

无构造器之名义类（如标准库 `帛`、接口文件之资类）由原语或不安全之转造之，候选之查以无穷域处之，不得以构造器之空集证无居民，含此类字段之支不据之警冗余；有构造器而尽为 GADT 所剪者，仍为空域。标准库 `匣`、`匣列`、`杂匣列` 择列时亦以无穷域处之；全通配候选含此诸引用类，则存未知，不据之警冗余，亦不印未知候选为缺例。其身份依标准库包之主、名及包内模径核之，异包同名类仍循其自有构造器析之。待办事项：补引用字段共约之可居性析。

候选补全之步数预算，全搜索共之，候选回溯、列交换皆耗此预算，诸支不得复置；其限问环境 `豫言穷尽步数`，无或空则取缺省一万步（百万步则含递归大类之文须编逾一分），亦存递归路径之深限。每匹配各具一预算，零与负亦受，零则立证不出。编译器命令行之口启时一问而写于通设；其值入编译缓存之身份，与警告之标同法，CI 与将作皆用缺省，环境唯供本地试之。预算尽还未知，不以未知证无候选，亦不印为缺例。构造器名称之境，印缺例初求名乃备，每匹配至多备一次，存不可见之果；无求名者省其准备。

递归候选之径并录闭合类及含自由类变量之类。闭合类之重径先独证其无居，证出乃剪展开之径，证不出则记未知；未定类之重径记未知；二者皆续试余构造器，不据以证全类为空，亦不据以判支为冗。构造器之命参（标签项）取类首时去其签，依实栏之类判有限、化字面。显式子模仍逐层验。泛型递归专项已验未知之存及后终止候选可用；实大文件之正常警告验收犹行。

文件类检之末，难析之鉴亦报：模不可转、支失其域、析类非单列者，登其鉴字之域，卷末逐个报编译之误“鉴的穷尽证不出”，不复默略全匹配。文件覆盖列空则径还；警止则此二析亦如故，不清其待验项与难析之项，其断仍记为编译之误。独立类检之原声明输入今已补全，须供“抽象语法”；模式展开须供“类型检查资料”。已检分支所存诊断范围于展开时去之，独立阶循此约验之。

词法之阶，串至卷末不闭则报编译之误 `文件:行:列：所在定义：字符串未闭合（『 起于第 N 行第 M 列）`，其位指开引 `『`。串字中之原样换行，依《词法与语法》所许，故漏闭引者，其串多为后之 `』` 所收；词法记其起止之行，此后语法之误或定稿之诊落于此串起处之后者，于诊辞之后别起一行书 `前面第 N 行起的字符串跨了 K 行，是否漏了『』`，示其误或由漏闭之引而生。

正名之阶：局部之名（参、`令`、`复令`、内定与模式之名）与 `寻` 所导之书之别名同名，而其名又于系外为值用者，于“命名空间不是一等值，不能作为参数、返回值、类型或数据使用：卷”之后别起一行书 `局部名「名」（第 N 行绑定）与导入的模块「名」同名`，举其系行与同名之书。系处由正名所记，报误如常而止其编。
