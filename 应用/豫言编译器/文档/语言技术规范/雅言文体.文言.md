# 雅言之体

雅言者，豫言源文之一体也（提案〇〇〇二六），其书法从提案〇〇〇二七《关键词换字》所定，兼〇〇〇二四之首支或有。包籍书 `「文体」者『雅言』也。`，则编译器依雅言析其包之源；`豫构 转写 --文体 雅言 路径…` 则改书其源为雅言。雅言与今制所析，同一具体语法之树，展及其后诸阶皆同。其实在 `库/译场/分职/文体/雅言。豫`（析与印之入口）与 `雅言/` 之目（符集、视图、平铺、排版、编译单元）。

## 一、书法

| 构 | 今制 | 雅言 |
| --- | --- | --- |
| 函数之类 | `化「整数」而「字符串」` | `化「整数」为「字符串」` |
| 多参函数之类 | `化「甲」而化「乙」而「丙」` | `化「甲」又化「乙」为「丙」` |
| 带签之参类 | `化「起」为「整数」而……` | `化「起」曰「整数」为……` |
| 可省之参 | `可化「宽」为「整数」而……` | `化「宽」曰「整数」可阙为……` |
| 依值之参 | `化「整数」者「长」而……` | `化「长」属「整数」为……` |
| 带签之依值之参 | `化「起」为「整数」者「长」而……` | `化「起」曰「长」属「整数」为……` |
| 隐类之参 | `承「甲」而承「乙」而……` | `凡「甲」又凡「乙」而……` |
| 隐值之参 | `承「整数」者「长」而……` | `凡「长」属「整数」而……` |
| 匿名之函 | `会「甲」而会「乙」而 体` | `得「甲」又得「乙」而 体` |
| 带类之匿名之函 | `遇「整数」者「项」而 体` | `得「项」属「整数」而 体` |
| 带签之匿名之函 | `会「起」为「甲」而 体` | `得「起」曰「甲」而 体` |
| 带签又带类之匿名之函 | `遇「起」为「整数」者「甲」而 体` | `得「起」曰「甲」属「整数」而 体` |
| 带默认值之参 | `会「宽」为「宽值」默认「二六」而 体` | `得「宽」曰「宽值」阙则「二六」而 体` |
| 隐匿名之函 | `受「甲」而受「乙」而 体` | `设「甲」又设「乙」而 体` |
| 局部之名 | `虑「甲」者 值 而 体` | `令「甲」为 值 而 体` |
| 局部之递归 | `递归虑「名」其 类 者 值 而 体` | `复令「名」属 类 即 值 而 体` |
| 带签之调用 | `「截取」于「起」为「零」` | `「截取」于「起」曰「零」` |
| 类之实参 | `「态射」授以「整数」授以「字符串」` | `「态射」以「整数」又以「字符串」` |
| 类之标 | `「小数」也「零点二五」` | `「零点二五」属「小数」` |
| 先后 | `甲；乙` | `甲 而后 乙` |
| 鉴之支 | `鉴「值」而有 模式 则 甲 或有 模式 则 乙` | `鉴「值」而或有 模式 则 甲 或有 模式 则 乙` |
| 签名、构造器 | `「名」乃化……也`、`「枝」立化……也` | 类以化、凡起者 `「名」乃化……者也`、`「枝」立化……者也`，余书 `……也` |
| 算与较 | `「加」于「甲」于「乙」` | `「甲」加「乙」`（减、乘、除以、大于、小于、等于、不等于同） |
| 非 | `「非」于「甲」` | `非「甲」` |

导入、定义 `「名」者 值 也`、类之别名 `「名」即 类 也`、条件 `若……则……否则……`、调用之 `于`、`且`、`或`、`与`、`合`、`中`、`之`、`附`、列、组值、组类、构造之书、注、数与串，其书皆同今制。

次参以下以“又X”续之：类中书 `又化`、`又凡`，匿名之函书 `又得`、`又设`，类之实参书 `又以`。“又X”与其“为”“而”之书同义，惟其右须为同类之构：`化「甲」又化「乙」为「丙」` 与 `化「甲」为化「乙」为「丙」` 同一树也，印则皆书其前者。

签名、构造器加“者”否，惟视类之首一字：以化、凡起（函数之类或隐参之类，不在括号中）者以“者也”收，否则以“也”收；收误则报。组类之项亦然。

算与较之中缀，前缀调用之简也：`「甲」加「乙」` 即 `「加」于「甲」于「乙」`，依所居之域求名「加」，惟视其形，不视其类；`非「甲」` 即 `「非」于「甲」`。限定之名（如 `「小数操作」之「加」`）仍书前缀之调用。

## 二、析

雅言用今制之式析器（依符表移位规约，见[词法与语法](词法与语法.文言.md)、[规约关系表](规约关系表.文言.md)），易以雅言之符表（`雅言/符集。豫`）。诸符之阐所出之节，与今制相应之书同；书法未易者，径用今制之符。词法、切分顶层之语、注之所附与句末同行之注归前句，皆同今制。

1. **依值之参与类之标。** `化「长」属「数」为……` 读为依值之参。化、曰之后之类若为无括号之类标，则废此读；欲以类标为定义域，书于括号之中：`化（「甲」属「乙」）为……`。
2. **“又X”之约。** `化〇又〇`、`凡〇又〇`、`得〇又〇`、`设〇又〇` 之右项（去注后）须为同类之构，`〇又以〇` 之左项须为以类参终之调用，不然则废此读。
3. **者也。** 签名、构造器之类以化、凡起者须书“者也”，否则须书“也”，书误即报。
4. **可省之参必带签。** `化 类 可阙为……` 报误，示以当书 `化「签」曰 类 可阙为……`。
5. **规约之系。** 依今制规约之表，其异者如下：
   - 今制之 `〇授以〇`、`〇；〇`、`〇也〇`（类之标），雅言为 `〇以〇`、`〇而后〇`、`〇属〇`；`〇又以〇`、`〇于〇曰〇`、`〇乃〇者也`、`〇立〇者也` 各依 `〇以〇`、`〇于〇`、`〇乃〇也`、`〇立〇也` 查表。
   - 语级之中缀 `〇者〇也`、`〇即〇也`、`〇乃〇也`、`〇立〇也` 居右，则左符皆先约。
   - `〇属〇` 松于余中缀：左之中缀皆先约；右接 `于`、`之`、`以`、`合`、`中` 则右规约，类可为调用、限定之名、类之实参与元组之类。
   - `〇而后〇` 最松之中缀也：左之中缀皆先约，右之中缀皆先续。调用、附串之后接 `而后`，不必括号。
   - 算与较之中缀：`之`、`中` 先之而约；其彼此之间（同一中缀连书亦然），与调用、`与`、`合`、`附`、`且`、`或` 之间，皆无规约之系，混书须括（同提案〇〇〇二二）。
   - `非` 之后接 `于`、`以`、`与`、`合`、`附`、`且`、`或`、`而后` 或算较之中缀须括；接 `之`、`中` 则如常右规约。
   - `卦曰〇` 紧于诸中缀，对任一右符皆左规约（同今制第 1 条）。
   - 余依今制：前缀之符后接中缀则右规约，表所未授之系即报“未定义优先级关系”。

析器依符表而析，表于造时算定诸辞而拆为字（`库/译场/译料/算符/操作符表。豫`），今制与雅言各用其一。雅言之表不出语义之标。

## 三、印

印器改自今制之印器，出器（`今制打印/排版器`）共之，排版之则同者仍旧：式可平铺于今行则平铺，不容则依其形分行，括号依原印之，的体所需而原树所无之括号，印器补之。雅言之书法另有数则：

1. 呼 `「加」` 等恰二无签之显参、首无注者，印为中缀；呼 `「非」` 恰一者，印为前缀 `非`。
2. 函数之类之链分行则每节一行，次节以下以 `又` 起，末行以 `为` 起；签名之“者也”紧接链之末行。隐参之后接他类，`而` 留行末。
3. 匿名之函之首不容一行，则每首一行，同类相续者以 `又` 起；`而` 皆留行末，函体另起一行。局部之名、局部之递归，值后之 `而` 亦留值之末行之尾。
4. 局部之递归之值为匿名之函，则 `即` 另起一行深一层，函体复深一层。
5. `而后` 所连之式各居一行，`而后` 留行末。

## 四、核

- `库/译场/测试/雅言解析。测试。豫`：成对之今制与雅言之书，析得同树；数种误书报误。
- `库/译场/测试/雅言打印。测试。豫`：今制之例改书为雅言（依今制析之、依雅言印之、复依雅言析之，二树须同，括号不较），所印与所期逐字同，复印之不易。
- 全仓之核：`yy往返核对 --雅言`（见源码格式化之包说明）逐篇改书而核 Git 所录诸源。二〇二六年十月十六日核六千五百九十一篇，过者六千五百一十五，余七十六篇乃今制自不能析之旧书之例。全仓雅言之析共用十六点九秒，今制之析十七点三秒。
