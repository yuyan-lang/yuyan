# 雅言之体

雅言者，豫言源文之书法也（提案〇〇〇二六、〇〇〇二七，兼〇〇〇二四之首支或有）；编译器、格式之器与诸工具皆依雅言析之印之。析先得具体语法之树，展及其后诸阶见[词法与语法](词法与语法.文言.md)。

## 一、书法

| 构造 | 书法 |
| --- | --- |
| 函数类型 | `化「数」为「文」` |
| 多参函数类型 | `化「甲」又化「乙」为「丙」` |
| 带签之参类 | `化「起」曰「数」为……` |
| 可省之参 | `化「宽」曰「数」可阙为……` |
| 依值之参 | `化「长」属「数」为……` |
| 带签之依值之参 | `化「起」曰「长」属「数」为……` |
| 隐类之参 | `凡「甲」又凡「乙」而……` |
| 隐值之参 | `凡「长」属「数」而……` |
| 匿名之函 | `得「甲」又得「乙」而 体` |
| 带类之匿名之函 | `得「项」属「数」而 体` |
| 带签之匿名之函 | `得「起」曰「甲」而 体` |
| 带签又带类之匿名之函 | `得「起」曰「甲」属「数」而 体` |
| 带默认值之参 | `得「宽」曰「宽值」阙则「二六」而 体` |
| 隐匿名之函 | `设「甲」又设「乙」而 体` |
| 局部之名 | `令「甲」为 值 而 体` |
| 局部之递归 | `复令「名」属 类 即 值 而 体` |
| 带签之调用 | `「截取」于「起」曰「零」` |
| 类之实参 | `「遍」以「数」又以「文」` |
| 类之标 | `「零点二五」属「小数」` |
| 先后 | `甲 而后 乙` |
| 鉴之支 | `鉴「值」而或有 模式 则 甲 或有 模式 则 乙` |
| 签名、构造器 | 类以化、凡始者 `「名」乃化……者也`、`「枝」立化……者也`，余书 `……也` |
| 算与较 | `「甲」加「乙」`（减、乘、除以、大于、小于、等于、不等于同） |
| 非 | `非「甲」` |
| 串之相接 | `甲 接 乙` |

导入、定义 `「名」者 值 也`、类之别名 `「名」即 类 也`、条件 `若……则……否则……`、调用之 `于`、`且`、`或`、`与`、`合`、`中`、`之`、列、组值、组类、构造之书、注、数、卦码 `卦曰「名」`（见[词法与语法](词法与语法.文言.md)词三）与串之书，见[词法与语法](词法与语法.文言.md)。

第二以下之参以“又X”接：类中 `又化`、`又凡`，匿名之函中 `又得`、`又设`，类之实参 `又以`。“又X”与所当之“为”“而”同义，惟右须同类之构：`化「甲」又化「乙」为「丙」` 与 `化「甲」为化「乙」为「丙」` 同树，印则恒书前者。

签名与构造器加“者”否，惟视类之首字：以化、凡始（函类或隐参之类，不在括中）则以“者也”收，否则以“也”收；收误则报。组类之项同之。

算较之中缀，前缀调用之简也：`「甲」加「乙」` 即 `「加」于「甲」于「乙」`，依域寻名「加」，惟视其形，不视其类；`非「甲」` 即 `「非」于「甲」`。限定之名（如 `「分厘」之「加」`）仍书前缀之调。

## 二、析

析者以操作符之表驱之（移位规约，见[词法与语法](词法与语法.文言.md)），其表为雅言符集（`库/译场/译料/算符/本算符/雅言符集。豫`）并内建之符，规约之系见[关系表](规约关系表.文言.md)。另有数约：

1. **依值之参与类之标。** `化「长」属「数」为……` 读为依值之参。化、曰之后之类若为无括之类标，此读作废；欲以类标为定义域，书于括中：`化（「甲」属「乙」）为……`。
2. **“又X”之约。** `化〇又〇`、`凡〇又〇`、`得〇又〇`、`设〇又〇` 之右项（去注之后）须同类之构，`〇又以〇` 之左项须以类之实参终之调用，否则此读作废。
3. **者也。** 签名与构造器之类以化、凡始者须书“者也”，否则须书“也”，书误即报。
4. **可省之参必带签。** `化 类 可阙为……` 报误，示书 `化「标签」曰 类 可阙为……`。

造表之时，诸类关键之辞已算好而拆为字（`库/译场/译料/算符/操作符表。豫`）。析时并出义标：乃、立、者也之属为结构之符，化、为、又、凡、曰、属、以之属为类之符，得、而、令、复令、设、鉴、或有、若之属为控制之符，语言服务之著色与悬停依之。

## 三、印

印器在 `库/译场/分职/文体/雅言/`。一式能平铺于今行则平铺，不能则依形分行；括号原样印之，所需而原树所无之括，印器补之。书法之则数条：

1. 调用 `「加」` 之属恰有二无签之显实参、首无注者，印为中缀；调用 `「非」` 恰有一者，印为前缀 `非`。
2. 函类之链分行，则每节一行，第二节起以 `又` 始，末行以 `为` 始；签名之“者也”紧接链之末行。隐参之后接他类者，`而` 留于行尾。
3. 匿名之函之首不能容于一行，则每首一行，同类相接者以 `又` 始；`而` 恒留行尾，函体另起一行。局部之名、局部之递归，其值后之 `而` 亦留于值之末行之尾。
4. 局部之递归之值为匿名之函者，`即` 另起一行深一层，函体再深一层。
5. `而后` 所连之式各占一行，`而后` 留于行尾。
