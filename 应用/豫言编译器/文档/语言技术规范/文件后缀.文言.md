# 文件后缀

豫言以文缀别文之类。源文皆以全角句号加“豫”字终（`。豫`），模块名与类段之间亦以全角句号隔之，如 `字节串。豫`、`宿主。接口。豫`、`逐元。底层。测试。豫`。缀定四事：文中可书者何，无体之声谁供之，依何模编之，导时得何模。此篇依今之仓列诸缀，各附仓中一例：缀一言源文，缀二言导时寻文之序，缀三言文书、试料、构建所出诸他文。诸子语言共守之则及其相配之道，见[子语言设计](子语言设计.文言.md)。

诸条以“缀”编号。

## 缀一：源文

导之路惟书模块名，类段由编译器依缀二补之。如 `寻观「标准库」之「数据结构」之「字节串」之书。`，所得之文为 `库/豫章/形制/字节串。豫`。

### 高级之源

高级之源有垃圾回收，编为 WasmGC 之模。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。豫` | 常源，一文一模；顶层惟有定义，其值惟数据（见[执行与编译](执行与编译.文言.md)行一） | `库/豫章/形制/字节串。豫` |
| `名。脚本。豫` | 脚本：顶层即程序之体，依次行之；可独编独行，亦可以 `豫构 运行` 径行之（提案〇〇〇〇三）；不可导；具同名所期之出（`.期望` 或 `。成功`）者，全树之试以编而行与单元装载二法各行之 | `应用/度量/列段/基准。脚本。豫` |
| `名。测试。豫` | 单元之试：顶层即程序之体，可独编独行；构库则略之，全树之试自得而行之；惟试与脚本可导试 | `应用/豫构/包系统。测试。豫` |
| `名。接口。豫` | 宿主接口：唯书类型与 `乃` 之签，宿主或构建时所绑之适配实之；每声编为带型之 Wasm 导入，导入之模名为所在包之短名 | `库/豫章/宿主。接口。豫`，导入之模曰“标准库” |
| `名。应用接口。豫` | 应用接口：应用或库实之，入口或任一链入之常模定同名之顶层函则编为导出 | `豫寓榫卯/网页服务/网页处理。应用接口。豫` |
| `名。内建。豫` | 内建之声：编译器所供之语言原语，其签依编译器之原语表校之 | `库/豫章/本原/原语。内建。豫` |

| 缀 | 所载 | 例 |
| --- | --- | --- |

### 底层之文

名含“。底层”者为底层之文：无垃圾回收，编为整数 Wasm，用于执行器、驱动、张量内核诸系统之代。语言之子集与后端，见 `应用/豫言编译器/文档/底层模式.文言.md`。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。底层。豫` | 底层之源 | `豫言操作系统/裸机/客体二号/入口。底层。豫` |
| `名。底层。测试。豫` | 底层单元之试，全树之试照常得而行之 | `库/底层库/中枢算阵/测试/逐元。底层。测试。豫` |
| `名。底层接口。豫` | 底层接口：每无体之声编为一 Wasm 导入，导入之模名为文名去其缀 | `豫言操作系统/裸机/原生样例/你好/林纳克斯。底层接口。豫`，导入之模曰“林纳克斯” |
| `名。底层内建。豫` | 底层内建之声：底层库之原语表，其调就地编为 Wasm 之令 | `库/底层库/原语。底层内建。豫` |

### 数据之文

数据之文（数据子语言，[提案〇〇〇二八](../../../../提案/00028-数据子语言.汉语.md)）藏静数。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。数据。豫` | 数据之文：其顶惟置导入、签名与 `「名」者 值 也。`；值为字面（串、整数、小数、阳、阴、元）、`「列」【…】` 与构造之书 `「头」【「字段」者 值 也，…】`，构造之首与独书之名为值之构造器（`立`）。高级之文导之，得有类之顶层数据；惟供导，以为程之入口则报错；豫构构库、检库之时，数据之文随导者而编 | `应用/豫言编译器/校场/语法/数据文件/正确。数据。豫`，社区包仓库根之 `工具链钉。数据。豫` |

- 检类分二步：检前察其书法，值中之函、算与余呼，及以 `即`、`立` 定义者，皆报错而明其故；检后察构造之首与独书之名为值之构造器。字段之名、类与必填，由构造之书降级依首之签检之（[标签函数类型](标签函数类型.文言.md)签七），字段之名误书则报“构造「头」没有属性「名」”。
- `「列」【…】` 径用内建之列构，数据之文不必导标准库；签名书「列」「字符串」等类名者，导标准库。
- 独检一数据之文：`豫构 类型检查 <包> <模块段…>`，如 `豫构 类型检查 软件目录 测试 样例`。
- 运行时所下所读之数据之文，库「数据文件」惟析其词与语法以读书之；工具与 CI 相授之清单、软件目录（如包仓库之 `/豫/社区/软件/豫言-兼容六十四。数据。豫`）与工具链钉皆书为数据之文。
- `「典」【…】` 惟供库「数据文件」于运行时读之；编与导之时，「典」之类留待后续之版，数据之文书「典」则报错。

### 约定之文名

- `入口。豫`：可执行之包常用之入口模名，包述之「类型」书 `「入口」者『入口』也`；其定入口之函「入口」（类 `化「有」而「有」`），包述可以「入口函数」别指一名。底层可执行之包，其入口之文曰 `入口。底层。豫`。

兼容之入，亦受以 `.yuyan` 终之源文之径。

## 缀二：寻模

导之路末段为模块名。编译器依导者之类，于模块名后依次补下列诸缀，取首存之文：

| 导者 | 依次所求 |
| --- | --- |
| 高级之文 | `名。豫`、`名。接口。豫`、`名。应用接口。豫`、`名。内建。豫`、`名。着色器。豫`、`名。设计。豫`、`名。数据。豫` |
| 着色之文 | `名。着色器。豫`、`名。着色器。接口。豫` |
| 底层之文 | `名。底层。豫`、`名。底层接口。豫`、`名。底层内建。豫` |

- 导之路唯书包名（或止于子）者，先依库包述「类型」中之「默认导入」展为若干目，每目再依导者之类补上表之缀（见[豫构包系统](../../../豫构/包系统.文言.md)“默认导入”）。
- 诸项皆无则报“包内模块不存在”。高级之文所导之模唯有底层之文，则报错附“这是底层模块，高级代码不能导入”；底层之文寻模不得，则报错列其可导之三缀。
- 包之入口与 `豫构 文件` 所指之文，高级、底层皆可，所求之序为表中高级、底层二行相接。数据之文可为检类之入口；构程之时以之为入口则报错。
- 试与脚本以全名导之（末段书 `名。测试`、`名。脚本`）：试惟试与脚本可导，常模导试则报“普通模块不能导入测试”；脚本不可导，导之则报“脚本不能被导入”。
- 程序之模视其入口之文：入口为底层之文，则全程行底层之管；余者行高级之管，编为 WasmGC。

如 `豫言操作系统/裸机/原生样例/你好/入口。底层。豫` 为底层之文，其二导曰：

```
寻观「底层库」之书。
寻「原生你好」之「林纳克斯」之书。
```

前者依底层库之默认导入，展为 `基础`、`内存`、`格`、`址运算` 四底层之模（如 `库/底层库/基础。底层。豫`），后者取同包之 `林纳克斯。底层接口。豫`。

## 缀三：他文

文名除半角点外皆汉字者，其缀一以全角句号隔之（构建所出之 `yy` 前缀不计）；英文之缀（`.md`、`.html`、`.wasm` 等）以半角点接之。下表以半角点接汉字之缀者（`.输入`、`.期望`、`.预置`、`.底层库`），旧名也（汇编树码已改为 `。树码`，工具链亦识旧名 `.树码`），渐改以全角句号；CI 之 formatting check 于 Git 所录之文、名除半角点外皆汉字者书警，于本机以 `./格式检查。苹果。豫行 --文件名` 列之。

### 文书

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名.汉语.md`、`名.文言.md` | 一篇之今文稿与文言稿，并存而同修；包述之「说明」登包说之二篇 | `库/豫章/包说明.汉语.md`、`库/豫章/包说明.文言.md` |

### 试料

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名.输入` | 定试之入：喂受试之程之键入之文，可含控制之字 | `豫言操作系统/裸机/壳/测试/中断.输入` |
| `名其编号。豫` 配 `名。成功` 或 `名。失败` | 黄金之样：同组源文以编号名之，“其”后逐位书其号以汉字之数（`名其一。豫`、`名其二。豫`……`名其一零。豫`）；顶层即程序之体；标记之文书其所期。`。成功` 者须编之行之皆成，标记之文非空则标准出须与之同；`。失败` 者须编或行而败，标记之文非空则所出须含其文 | `库/豫章/测试/内建/一元积其一。豫` 配 `一元积。成功` |
