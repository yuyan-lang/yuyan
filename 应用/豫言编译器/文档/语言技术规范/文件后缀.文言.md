# 文件后缀

豫言以文缀别文之类。源文皆以全角句号加“豫”字终（`。豫`），模块名与类段之间亦以全角句号隔之，如 `字节串。豫`、`宿主。接口。豫`、`逐元。底层。测试。豫`。缀定四事：文中可书者何，无体之声谁供之，依何模编之，导时得何模。此篇依今之仓列诸缀，各附仓中一例：缀一言源文，缀二言导时寻文之序，缀三言文书、试料、构建所出诸他文。

诸条以“缀”编号。

## 缀一：源文

导之路惟书模块名，类段由编译器依缀二补之。如 `寻观「标准库」之「数据结构」之「字节串」之书。`，所得之文为 `库/标准库/数据结构/字节串。豫`。

### 高级之源

高级之源有垃圾回收，编为 WasmGC 之模。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。豫` | 常源，一文一模；顶层惟有定义，其值编译器定之（见[执行与编译](执行与编译.文言.md)行一） | `库/标准库/数据结构/字节串。豫` |
| `名。脚本。豫` | 脚本：顶层即程序之体，依次行之；可独编独行，不可导，全树之试不得之 | `应用/性能研究/列表数组段/基准。脚本。豫` |
| `名。测试。豫` | 单元之试：顶层即程序之体，可独编独行；构库则略之，全树之试自得而行之；惟试与脚本可导试 | `应用/豫构/包系统。测试。豫` |
| `名。接口。豫` | 宿主接口：唯书类型与 `乃` 之签，宿主或构建时所绑之适配实之；每声编为带型之 Wasm 导入，导入之模名为所在包之短名 | `库/标准库/宿主。接口。豫`，导入之模曰“标准库” |
| `名。应用接口。豫` | 应用接口：应用实之，入口定同名之顶层函则编为导出 | `豫言操作系统接口/网页服务/网页处理。应用接口。豫` |
| `名。内建。豫` | 内建之声：编译器所供之语言原语，其签依编译器之原语表校之 | `库/标准库/语言核心/原语。内建。豫` |

### 着色之文

着色之文以豫言常法书图形处理器之着色程序，详见[着色语言](着色语言.文言.md)。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。着色器。豫` | 着色之源：检类而后译为 WGSL、MSL 与 PTX；高级之代导之，得构时所生之模 | `库/张量内核/公用。着色器。豫` |
| `名。着色器。接口。豫` | 着色内建之声：着色之的所供之算与内建之函 | `库/着色库/着色内建。着色器。接口。豫` |
| `名。着色生成。豫` | 虚径：高级之代导着色之源所得之生模，译器构时生之，唯存于编译之中 | 导 `公用。着色器。豫`，得 `公用。着色生成。豫` |

### 底层之文

名含“。底层”者为底层之文：无垃圾回收，编为整数 Wasm，用于执行器、驱动、张量内核诸系统之代。语言之子集与后端，见 `应用/豫言编译器/文档/底层模式.文言.md`。

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。底层。豫` | 底层之源 | `豫言操作系统/裸机/客体二号/入口。底层。豫` |
| `名。底层。测试。豫` | 底层单元之试，全树之试照常得而行之 | `库/底层库/中央张量内核/测试/逐元。底层。测试。豫` |
| `名。底层接口。豫` | 底层接口：每无体之声编为一 Wasm 导入，导入之模名为文名去其缀 | `豫言操作系统/裸机/原生样例/你好/林纳克斯。底层接口。豫`，导入之模曰“林纳克斯” |
| `名。底层内建。豫` | 底层内建之声：底层库之原语表，其调就地编为 Wasm 之令 | `库/底层库/原语。底层内建。豫` |

### 包述

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名。包。豫` | 包述：名称、所有者、版本、简介、说明、类型、依赖诸字段，豫构读之；以为模而导之则报错 | `库/标准库/标准库。包。豫` |

### 约定之文名

- `总集。豫`：唯书包名之导，取包根之总集，如 `寻观「标准库」之书。` 取 `库/标准库/总集。豫`。底层之文取 `总集。底层。豫`，如 `寻观「底层库」之书。` 取 `库/底层库/总集。底层。豫`。
- `入口。豫`：可执行之包常用之入口模名，包述之「类型」书 `「入口」者『入口』也`；其定入口之函「入口」（类 `化「有」而「有」`），包述可以「入口函数」别指一名。底层可执行之包，其入口之文曰 `入口。底层。豫`。

兼容之入，亦受以 `.yuyan` 终之源文之径。

## 缀二：寻模

导之路末段为模块名。编译器依导者之类，于模块名后依次补下列诸缀，取首存之文：

| 导者 | 依次所求 |
| --- | --- |
| 高级之文 | `名。豫`、`名。接口。豫`、`名。应用接口。豫`、`名。内建。豫`、`名。着色器。豫` |
| 着色之文 | `名。着色器。豫`、`名。着色器。接口。豫` |
| 底层之文 | `名。底层。豫`、`名。底层接口。豫`、`名。底层内建。豫` |

- 诸项皆无则报“包内模块不存在”。高级之文所导之模唯有底层之文，则报错附“这是底层模块，高级代码不能导入”；底层之文寻模不得，则报错列其可导之三缀。
- 包之入口与 `豫构 文件` 所指之文，高级、底层皆可，所求之序为表中高级、底层二行相接。
- 试与脚本以全名导之（末段书 `名。测试`、`名。脚本`）：试惟试与脚本可导，常模导试则报“普通模块不能导入测试”；脚本不可导，导之则报“脚本不能被导入”。
- 程序之模视其入口之文：入口为底层之文，则全程行底层之管；余者行高级之管，编为 WasmGC。

如 `豫言操作系统/裸机/原生样例/你好/入口。底层。豫` 为底层之文，其二导曰：

```
寻观「底层库」之书。
寻「原生你好」之「林纳克斯」之书。
```

前者取 `库/底层库/总集。底层。豫`，后者取同包之 `林纳克斯。底层接口。豫`。

## 缀三：他文

文书、试料与构建所出之文名，以半角点隔其缀，间亦沿用全角句号。

### 文书

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名.汉语.md`、`名.文言.md` | 一篇之今文稿与文言稿，并存而同修；包述之「说明」登包说之二篇 | `库/标准库/包说明.汉语.md`、`库/标准库/包说明.文言.md` |

### 试料

| 缀 | 所载 | 例 |
| --- | --- | --- |
| `名-编号。豫` 配 `名。成功` 或 `名。失败` | 黄金之样：同组源文以编号名之，标记之文书其所期。`。成功` 者须编之行之皆成，标记之文非空则标准出须与之同；`。失败` 者须编或行而败，标记之文非空则所出须含其文 | `库/标准库/测试/内建/一元积-1。豫` 配 `一元积。成功` |
| `名.期望` | 所期之出：命令壳之试、原生一致之探诸器，依之校程序所出 | `豫言操作系统/裸机/WASI库/测试/WASI.期望` |
| `名。测试页.html` | 浏览器之试页，于浏览器启而行之 | `豫言操作系统/宿主/浏览器/中断。测试页.html` |
| `名。测试.mjs`、`名。测试.cjs`、`名.test.mjs`、`名.test.cjs`、`名.e2e.mjs` | 宿主之代（JS）之试，全树之试以 `node --test` 行之 | `豫言操作系统/宿主/云工/公网取。测试.mjs` |
| `名。包。豫.txt` | 包述之模板：验收所用之包述，双宿主构建之自动法抄为真 `。包。豫` 而后用之；寻包唯收 `。包。豫` | `库/基础库/存储与时间/嵌入数据库/验收/目录文件/目录文件验收。包。豫.txt` |
