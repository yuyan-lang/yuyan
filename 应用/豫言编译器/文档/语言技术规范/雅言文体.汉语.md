# 雅言文体

雅言是豫言源码的一种文体（提案 00026），写法照提案 00027《关键词换字》定下的方案，含提案 00024 的首支或有。包描述写 `「文体」者『雅言』也。` 时，编译器按雅言解析这个包的源文件；`豫构 转写 --文体 雅言 路径…` 把源码转写成雅言。雅言与今制解析出同一种具体语法树，展开及其后各阶段完全相同。实现在 `库/译场/分职/文体/雅言。豫`（解析与打印的入口）与 `雅言/` 目录（操作符集、视图、平铺、排版、编译单元）。

## 一、写法

| 构造 | 今制 | 雅言 |
| --- | --- | --- |
| 函数类型 | `化「整数」而「字符串」` | `化「整数」为「字符串」` |
| 多参函数类型 | `化「甲」而化「乙」而「丙」` | `化「甲」又化「乙」为「丙」` |
| 带标签的参数类型 | `化「起」为「整数」而……` | `化「起」曰「整数」为……` |
| 可省参数 | `可化「宽」为「整数」而……` | `化「宽」曰「整数」可阙为……` |
| 依值参数 | `化「整数」者「长」而……` | `化「长」属「整数」为……` |
| 带标签的依值参数 | `化「起」为「整数」者「长」而……` | `化「起」曰「长」属「整数」为……` |
| 隐式类型参数 | `承「甲」而承「乙」而……` | `凡「甲」又凡「乙」而……` |
| 隐式值参数 | `承「整数」者「长」而……` | `凡「长」属「整数」而……` |
| 匿名函数 | `会「甲」而会「乙」而 体` | `得「甲」又得「乙」而 体` |
| 带类型的匿名函数 | `遇「整数」者「项」而 体` | `得「项」属「整数」而 体` |
| 带标签的匿名函数 | `会「起」为「甲」而 体` | `得「起」曰「甲」而 体` |
| 带标签又带类型的匿名函数 | `遇「起」为「整数」者「甲」而 体` | `得「起」曰「甲」属「整数」而 体` |
| 带默认值的参数 | `会「宽」为「宽值」默认「二六」而 体` | `得「宽」曰「宽值」阙则「二六」而 体` |
| 隐式匿名函数 | `受「甲」而受「乙」而 体` | `设「甲」又设「乙」而 体` |
| 局部名 | `虑「甲」者 值 而 体` | `令「甲」为 值 而 体` |
| 局部递归 | `递归虑「名」其 类 者 值 而 体` | `复令「名」属 类 即 值 而 体` |
| 带标签的调用 | `「截取」于「起」为「零」` | `「截取」于「起」曰「零」` |
| 类型实参 | `「态射」授以「整数」授以「字符串」` | `「态射」以「整数」又以「字符串」` |
| 类型标注 | `「小数」也「零点二五」` | `「零点二五」属「小数」` |
| 先后 | `甲；乙` | `甲 而后 乙` |
| 鉴的分支 | `鉴「值」而有 模式 则 甲 或有 模式 则 乙` | `鉴「值」而或有 模式 则 甲 或有 模式 则 乙` |
| 签名、构造器 | `「名」乃化……也`、`「枝」立化……也` | 类型以化、凡开头时 `「名」乃化……者也`、`「枝」立化……者也`，其余写 `……也` |
| 算术与比较 | `「加」于「甲」于「乙」` | `「甲」加「乙」`（减、乘、除以、大于、小于、等于、不等于同） |
| 非 | `「非」于「甲」` | `非「甲」` |

导入、定义 `「名」者 值 也`、类型别名 `「名」即 类 也`、条件 `若……则……否则……`、调用的 `于`、`且`、`或`、`与`、`合`、`中`、`之`、`附`、列、组值、组类、构造写法、注释、数字、卦码 `卦曰「名」`（见[词法与语法](词法与语法.汉语.md)词三）与字符串，写法都与今制相同。

第二个起的参数以“又X”接：类型里 `又化`、`又凡`，匿名函数里 `又得`、`又设`，类型实参 `又以`。“又X”与对应的“为”“而”写法同义，只是右边须是同类的构造：`化「甲」又化「乙」为「丙」` 与 `化「甲」为化「乙」为「丙」` 是同一棵树，打印时一律写前者。

签名与构造器加不加“者”，只看类型的开头一字：以化、凡开头（函数类型或隐式参数类型，不在括号里）时以“者也”收，否则以“也”收；收错了报错。组类里的项同此。

算术与比较的中缀是前缀调用的简写：`「甲」加「乙」` 就是 `「加」于「甲」于「乙」`，按作用域找名字「加」，只看外形，不看类型；`非「甲」` 就是 `「非」于「甲」`。限定名（如 `「小数操作」之「加」`）照旧写前缀调用。

## 二、解析

雅言用今制的表达式解析器（操作符表驱动的移位规约，见[词法与语法](词法与语法.汉语.md)、[规约关系表](规约关系表.汉语.md)），换上雅言的操作符表（`雅言/符集。豫`）。各操作符的阐述产出与今制对应写法相同的节点；没有改动的写法直接用今制的操作符。词法、切分顶层语句、注释的附着与句末同行注释归前句都与今制相同。

1. **依值参数与类型标注。** `化「长」属「数」为……` 读作依值参数。化、曰之后的类型若是没有括号的类型标注，这一种读法作废；要以类型标注作定义域，写在括号里：`化（「甲」属「乙」）为……`。
2. **“又X”的约束。** `化〇又〇`、`凡〇又〇`、`得〇又〇`、`设〇又〇` 的右项（去掉注释后）须是同类的构造，`〇又以〇` 的左项须是以类型实参结尾的调用，否则这一种读法作废。
3. **者也。** 签名与构造器的类型以化、凡开头时须写“者也”，否则须写“也”，写错即报错。
4. **可省参数必须带标签。** `化 类 可阙为……` 报错，提示写作 `化「标签」曰 类 可阙为……`。
5. **规约关系。** 按今制的规约关系表，以下各条不同：
   - 今制的 `〇授以〇`、`〇；〇`、`〇也〇`（类型标注）在雅言里是 `〇以〇`、`〇而后〇`、`〇属〇`；`〇又以〇`、`〇于〇曰〇`、`〇乃〇者也`、`〇立〇者也` 分别按 `〇以〇`、`〇于〇`、`〇乃〇也`、`〇立〇也` 查表。
   - 语句级的中缀 `〇者〇也`、`〇即〇也`、`〇乃〇也`、`〇立〇也` 在右时，左边的操作符都先规约。
   - `〇属〇` 比其余中缀都松：左边的中缀都先规约；右边接 `于`、`之`、`以`、`合`、`中` 时右规约，类型可以是调用、限定名、类型实参与元组类型。
   - `〇而后〇` 是最松的中缀：左边的中缀都先规约，右边的中缀都先接上。调用、附串之后接 `而后` 不必加括号。
   - 算术与比较的中缀：`之`、`中` 先于它们规约；它们彼此之间（同一个中缀连写也算）、与调用、`与`、`合`、`附`、`且`、`或` 之间都没有规约关系，混写须加括号（同提案 00022）。
   - `非` 之后接 `于`、`以`、`与`、`合`、`附`、`且`、`或`、`而后` 或算术比较的中缀须加括号；接 `之`、`中` 时照常右规约。
   - `卦曰〇` 比所有中缀都紧，对任何右操作符都左规约（同今制第 1 条）。
   - 其余照今制：前缀操作符之后接中缀时右规约，表里没给出的关系即报“未定义优先级关系”。

解析器按操作符表解析，表在造表时就把各类关键词算好并拆成字（`库/译场/译料/算符/操作符表。豫`），今制与雅言各用一张。雅言的表不产出语义标记。

## 三、打印

打印器由今制打印器改写而成，输出器（`今制打印/排版器`）共用，排版规则相同之处照旧：一个式能平铺进当前行就平铺，放不下按形状分行，括号原样印出，目标文体需要而原树没有的括号由打印器补上。雅言的写法另有几条：

1. 调用 `「加」` 等恰有两个不带标签的显式实参、头上没有注释时印成中缀；调用 `「非」` 恰有一个时印成前缀 `非`。
2. 函数类型链分行时每节一行，第二节起以 `又` 开头，最后一行以 `为` 开头；签名的“者也”紧接在链的最后一行之后。隐式参数之后接别的类型时，`而` 留在行尾。
3. 匿名函数的开头放不下一行时每个开头一行，同类相接的以 `又` 开头；`而` 一律留在行尾，函数体另起一行。局部名、局部递归的值之后的 `而` 也留在值的末行之尾。
4. 局部递归的值是匿名函数时，`即` 另起一行深一层，函数体再深一层。
5. `而后` 连接的式各占一行，`而后` 留在行尾。
