# 问簿

## 一、缘起

问簿（SQL）之表与问，书为常豫言：一表为一行类（有名之组）加一表声明，问为带行之匿函。表之运行之库，芥子之「册府」也；其所受之表声明中有二值，为编译依类所补，书中不必手书：

1. **行谱**（`「行谱」于 甲`）：一行有何栏、每栏何类，及一行与问值列之编解。
2. **取径**（`取径`）：自表之何路取候行——全扫，或按键取行。

二者皆于共用之前端依类首名而认，不视类所在之模，故凡高级之文皆可用，试可用同名之替类。行谱之合与取径之补（自问之约推其按键取行之等值），本篇皆定之。

## 二、行谱之合

### 2.1 时

构造之书（[标签函类](标签函数类型.文言.md)第六节）降为带签之调时，签中类为 `（「行谱」于 甲）` 之参未见书者，编译即依甲合一行谱之值补之；书之则用其所书。

### 2.2 行类自所期之类来

甲取于构造之书之所期之类：表声明书为

```
「邮箱账户行」即「组类」【「用户编号」乃「数」也，「邮箱」乃「文」也】也。
「邮箱账户」乃（「册」于「邮箱账户行」）者也。
「邮箱账户」者「置册」【「名」者『邮箱账户』也，「主键」者『用户编号』也，「子项」者（「列」【】）也】也。
```

时，值 `「置册」【…】` 之所期类为 `（「册」于「邮箱账户行」）`，编译自其中取甲 `邮箱账户行`，展其透明之别名，行类即彼有名之组。

推不出甲则告误：`合成行谱要知道行类型：给表声明写上签名`。故表声明须书其签；不书签之表声明不能自其定推出行类，所告即此条。

甲须为有名之组（`组类` 之带名项之书），每项之类限于「数」「小数」「文」「帛」「爻」与此五类各自之 `（「或可有」于 …）`。他类告误：

```
表的行类型「坏行」里「名单」一项的类型「列 于 文」存不进表：只收数、小数、文、帛、爻与它们的或可有
```

### 2.3 所合之值

所合之值为 `（「造行谱」于「栏们」曰 … 于「编」曰 … 于「解」曰 …）`，甲由所期之类定：

- **栏们**：依有名之组之项次一项一栏，为 `栏` 之列。栏名取项名；`型` 依项之类取 `整栏`、`实栏`、`文栏`、`块栏`、`爻栏`（或可有取其中之类型）；`可空` 于或可有时为阳，余为阴。
- **编**：`（得「行」而「列」【编一，编二，…】）`，依项次编为问值之列。数作 `值整`，小数作 `值实`，文作 `值文`，帛作 `值块`，爻于阳时作 `值整` 一、于阴时作 `值整` 零；或可有的栏于可无时作 `值空`，于可有时依其中之类型编。
- **解**：`（得「列」而 …）`，依项次以问值解回诸项。数、小数、文、帛取其中之值；爻以非零为阳；或可有的栏于 `值空` 时得 `可无`，否则以其中之值裹为 `可有`。栏数不合或值之种不合者，以 `行与表结构不合：…` 告祸，书其第几栏、当为何、实得何。

所合之值惟含匿函、列与构造，为数据，故表声明犹可置诸顶层（[执行与编译](执行与编译.文言.md)第五节）。

### 2.4 所行之处

合在 `库/译场/分职/证义/构造写法降级。豫` 之「降构造写法」中，紧邻式码之段。降级之入多受一所期之类，验物之入（`物验类。豫`）以所期之类授之，合类型之入（`验类具。豫` 之物类合成）授以可无；故有签之表声明合之得出，无签之表声明于合类型之时告上之误。

## 三、取径之补

取径之补，自问之约推其按键取行之等值：书默认之「径」「右径」，约中有可推之等值者易为「键等」，推不出则守其默认。今认单表之「径」、两表之连的「右径」，等值认整数之等于与豫章之「文同」。

### 3.1 时

可省之参取默认之值之处（[标签函类](标签函数类型.文言.md)第六节），编译自同调中签为「择」之实推一按键取行之等值，插所推之键等值；推不出则如故插默认之引。时在类检之前，所插之式犹过检，故其则依未检之形而书：按名之投为命名元组投影之节，短线且为短路且之节，行书为匿函之参（于体中为绑定之变，首参为一，逐层加一）。

「择」须为字面之匿函。

### 3.2 单表

「检」「聚」「改」「删」之「择」形如 `得「行」而 体`。沿体最外之短线且（可叠）逐项观之，取首条合下列之一者，其中 X 中不见「行」（「行」指匿函之参，名依人所书）：

- `（「行」中「名」）等于 X` 或 `X 等于（「行」中「名」）`，补

```
「键等」于「栏名」曰『名』于「值」曰（「值整」于 X）
```

- `「文同」于（「行」中「名」）于 X` 或 `「文同」于 X 于（「行」中「名」）`，「文同」指豫章之彼，补

```
「键等」于「栏名」曰『名』于「值」曰（「值文」于 X）
```

实参既书「径」者用其所书，不补。短线或中之等值不补；X 中见「行」者亦不补。

### 3.3 连

两表之连，其「择」形如 `得「左行」又得「右行」而 体`，二参自外而内；「右径」自体中取首条右行一栏之等值，X 中不见「右行」：

- `（「右行」中「名」）等于 X` 或 `X 等于（「右行」中「名」）`，补

```
（得「左行」而「键等」于「栏名」曰『名』于「值」曰（「值整」于 X））
```

- `「文同」于（「右行」中「名」）于 X` 或 `「文同」于 X 于（「右行」中「名」）`，「文同」指豫章之彼，补

```
（得「左行」而「键等」于「栏名」曰『名』于「值」曰（「值文」于 X））
```

X 中可有「左行」：所补之函自以「左行」为参，体中指外之「左行」者，编译降一序移入新函。「径」依 3.2 单表之则求左行之栏，X 中「左行」「右行」皆不见。

### 3.4 后版

范围之约、或、依序取行留待后版。

### 3.5 所补之值

所补者惟候行自何而来：候行犹经「择」筛之，其果与全扫同。造值用「取径」之构造「键等」与「问值」之构造「值整」「值文」，皆依类首名而认，依默认定义所在之文与名取引。

### 3.6 所行之处

补值别为一篇 `库/译场/分职/证义/取径补值。豫`，其入「补取径」为「补齐可省参」（`术应用隐参合成。豫`）于插默认之值之处所呼，受参类、本次调用之实列与默认之引，推得则予所推之式，推不出则予默认之引。连之「右径」移「择」之体时用「取径降系」，降指「左行」之系变一序。所补之值惟含构造之调、字符串与故有之式，随后犹过类检。

## 四、二则为谁而设

二则为芥子「册府」而设：表声明中不书行谱，册府所得者即编译依行类所合之栏与编解；问中不书取径，册府所得者即编译自约中所推之取行之路（今为整数之等于、豫章之文同与连之右径）。书中不见行谱与取径之构造，表与问犹书为常豫言。
