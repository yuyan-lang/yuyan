# 豫言语法指南 — 内建操作符与关键字

本篇是语法速查；精确规则以[语言规范](语言规范.汉语.md)为准。


保持裸字（不用「」）的内建符号。其余所有标识符加「」。

## 核心语法
```
令 为 而                 -- 局部绑定
复令 属 即 而            -- 表达式级局部递归
属                      -- 类型标注（值 属 类）
也 者也                  -- 语句终止（签名、构造器的类型以化或凡开头时用者也）
于 曰                   -- 函数调用，带标签的实参写 于「签」曰 值
以 又以                 -- 类型实参
之                      -- 结构投影
而后                    -- 顺序执行
鉴 或有 则              -- 模式匹配（首支也写或有）
若 则 否则              -- 条件分支
且 或 非                -- 短路的且、或与前缀的非
加 减 乘 除以 大于 小于 等于 不等于 接  -- 算术、比较与字符串相接的中缀
```

## 类型
```
化〇为〇 化〇又化〇为〇   -- 函数类型
化「签」曰〇为〇         -- 带标签的参数
凡□而〇 凡□属〇而〇     -- 多态类型、隐式值参数
得□而〇 得□又得□而〇    -- 函数参数
设□而〇                -- 隐式类型参数
与 合 中 其实            -- 对子
```

## 声明
```
立 乃 者 即 也
术 交 无序 盖谓        -- 操作符声明
寻 观 导入 打开 并打开 之 书
```

## 内置类型/值
```
类 爻 有 数 小数 文 动态分类值
阳 阴 元
```

## 操作符声明中用到的特殊标记
```
〇 -- 操作数占位符
□ -- 绑定名占位符
```

## 字面量
```
『字符串』 《《内建类型：整数》》 《《内建爻：阳》》
「一二三四五六七八九」 「三点一四」
```

## 注释
```
「：注释：」
```
