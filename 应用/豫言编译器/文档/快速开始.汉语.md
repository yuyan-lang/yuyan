# 快速开始

以下步骤适用于 Linux 和 macOS。请确保系统已有 `clang`、LLVM 工具（`llvm-ar`）、`curl`、`tar` 与 Node.js 26 或更新版本；常见安装方式如下：

```sh
# Debian / Ubuntu（Node.js 按 https://nodejs.org 的说明另装）
sudo apt-get update
sudo apt-get install clang llvm curl tar

# macOS（Homebrew）
brew install llvm node
export PATH="$(brew --prefix llvm)/bin:$PATH"
```

## 构建工具链

在仓库根目录下载 CI 发布的 [Wasm 工具链包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-binaries)，解压到仓库根目录（豫构以编译器所在目录为工具链根），再用 Node 运行包里的构建程序、豫构与编译器：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-wasm.tar.gz \
  --output yy_wasm工具链.tar.gz
tar -xzf yy_wasm工具链.tar.gz
node yy稳定节点宿主/宿主.cjs yy仓库构建_stable.wasm 运行时
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 仓库构建 --编译器 ./yy_bs_stable.wasm --输出 yy仓库构建
./yy仓库构建
```

前两步构建原生运行时与本机构建程序 `yy仓库构建`；最后一步自举编译器（二级由 Wasm 编译器在 Node 下构建，其后各级都是本机程序），得到 `yy4_bs`，并构建包工具 `yy豫构`。Linux x86-64 也可改下载同一发布中的 `yuyan-linux-x86_64.tar.gz`（原生的 `yy_bs_stable`、`yy豫构_stable` 与运行时归档），解压到仓库根目录后运行 `./yy豫构_stable 构建 仓库构建 --编译器 ./yy_bs_stable --输出 yy仓库构建` 与 `./yy仓库构建`。垃圾回收器已经包含在运行时源码中，不需要安装 Boehm GC。构建程序的全部目标见[仓库构建](../../仓库构建/包说明.汉语.md)。

## 编写并运行程序

上一节完成后已有当前的编译器与包工具 `yy豫构`。新建 `示例/你好。包。豫`：

```yuyan
「依赖」者「列」【『标准库』】也。
「入口」者『入口』也。
```

再新建同目录的 `示例/入口。豫`：

```yuyan
寻观「标准库」之书。
「打印行」于『你好，豫言！』。
```

在仓库根目录构建并运行；包名由文件名识别，不再依赖模块搜索路径：

```sh
./yy豫构 构建 你好 --输出 yy你好
./yy你好
./yy你好 参数一 参数二
```

只做类型检查可以运行 `./yy豫构 类型检查 你好`。包根、直接依赖、多入口和启动自举详见[仓库包构建](../../豫构/文档/仓库包构建.汉语.md)。独立项目使用标准库时，也必须将标准库包纳入发现范围，见[包系统](../../豫构/包系统.汉语.md)。

查看底层编译器选项可运行 `./yy4_bs --help`。旧单文件入口保留兼容，但日常构建使用豫构。
