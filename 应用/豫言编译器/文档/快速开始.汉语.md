# 快速开始

以下步骤适用于 Linux 和 macOS。只需 Node.js 26 或更新版本、`curl` 与 `tar`；常见安装方式如下：

```sh
# Debian / Ubuntu（Node.js 按 https://nodejs.org 的说明另装）
sudo apt-get update
sudo apt-get install curl tar

# macOS（Homebrew）
brew install node
```

## 构建工具链

在仓库根目录下载 CI 发布的 [Wasm 工具链包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-binaries)，解压到仓库根目录（豫构以编译器所在目录为工具链根），再用 Node 运行包里的豫构与编译器：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-wasm.tar.gz \
  --output yy_wasm工具链.tar.gz
tar -xzf yy_wasm工具链.tar.gz
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 豫构 --编译器 ./yy_bs_stable.wasm --输出 yy豫构.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 全部 -j 24
```

解压后得到编译器 `yy_bs_stable.wasm`、豫构 `yy豫构_stable.wasm` 与 Node 宿主 `yy稳定节点宿主/`。第一步用包里的豫构与编译器以当前源码构建 `yy豫构.wasm`；第二步自举编译器（`yy_bs_stable.wasm` → `yy2_bs.wasm` → `yy3_bs.wasm` → `yy4_bs.wasm`，核对 `yy3_bs.wasm` 与 `yy4_bs.wasm` 逐字节相同），再用 `yy4_bs.wasm` 重建 `yy豫构.wasm`。工具都是 `.wasm` 模块，由 `node 豫言操作系统/宿主/节点/宿主.cjs` 运行；工具再启动的 `.wasm` 子程序，宿主按文件头自动另起 Node 执行。要与 CI 使用同一版本，可改下载 `historical-binaries` 发布中的 `yuyan-wasm-<提交号>.tar.gz`，CI 所用版本的地址与 SHA-256 见 `.github/workflows/main.yml` 的 `YY_WASM_TOOLCHAIN_URL`、`YY_WASM_TOOLCHAIN_SHA256`。仓库级构建目标写在 `应用/豫构/仓库目标。豫`，运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 目标 --列出` 可列出全部目标。

## 编写并运行程序

上一节完成后已有当前的编译器 `yy4_bs.wasm` 与包工具 `yy豫构.wasm`。新建 `示例/你好。包。豫`：

```yuyan
「依赖」者「列」【『标准库』】也。
「入口」者『入口』也。
```

再新建同目录的 `示例/入口。豫`：

```yuyan
寻观「标准库」之书。
「打印行」于『你好，豫言！』。
```

在仓库根目录构建并运行；包名由文件名识别，不再依赖模块搜索路径：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 你好 --输出 yy你好.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy你好.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy你好.wasm 参数一 参数二
```

只做类型检查可以运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 类型检查 你好`。包根、直接依赖、多入口和启动自举详见[仓库包构建](../../豫构/文档/仓库包构建.汉语.md)。独立项目使用标准库时，也必须将标准库包纳入发现范围，见[包系统](../../豫构/包系统.汉语.md)。

查看底层编译器选项可运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy4_bs.wasm --help`。旧单文件入口保留兼容，但日常构建使用豫构。
