# 豫言标签函类设计

此篇为豫言标签函类之已定设计。函之参可带标；类型、定义、调用与构造器之模式，皆书作 `「标」为 …`，依所声之序书之，须分组则加括号。标属函类；类型检查既毕，去调用中之标，所生之码与依位所书之调同。今行之则见[标签函类规范](语言技术规范/标签函数类型.文言.md)。

与[汉语稿](标签函数类型设计.汉语.md)相应。

## 一、所定之事

| 号 | 则 |
| --- | --- |
| 定一 | 类型、定义、调用与构造器之模式，皆书 `「标」为 …`。「为」之后：于类型书类，于定义书局部之名，于调用书实参，于模式书子模式 |
| 定二 | 标属函类。有标与无标之函类不相等，标文异者亦不相等；二者之间唯显式转接 |
| 定三 | 实参依所声之序书之，标可重而逐位核之。有标之参必书其标，无标之参仍书 `于 实参` |
| 定四 | 普通箭头与有标箭头各有形成、引入、消去之则；标之核为类型检查之一部，余类型之则于完整函类如常行之 |
| 定五 | `〇为〇` 为操作符，与余符不新增明定之优先级关系；循旧则惟一可解者可省括号，须分组则加之 |
| 定六 | 初版及常值函、匿名之函、值构造器与构造器之模式、常模式与底层模式、接口之签名；类型构造器之参与着色之语暂不及 |
| 定七 | 去过期之 `循□以〇` |

## 二、书法

### 类型

```yuyan
「差」乃
  化（「被减数」为「整数」）而
  化（「减数」为「整数」）而
  「整数」
也。
```

`（「被减数」为「整数」）`，一有标之参也：其标曰「被减数」，其类曰「整数」。一函类之中，有标、无标之参可并存：

```yuyan
「缩放」乃化「整数」而化（「倍率」为「整数」）而「整数」也。
```

### 定义

```yuyan
「差」者会（「被减数」为「甲」）而会（「减数」为「乙」）而「减」于「甲」于「乙」也。
「缩放」者会「数」而会（「倍率」为「倍」）而「乘」于「数」于「倍」也。
```

`会（「被减数」为「甲」）而`，受标为「被减数」之参，函体以「甲」称之。标供调者之用，局部之名供函体之用，二者可同名。

有类型之匿名函，循类型之书法：

```yuyan
「单位」者遇（「数值」为「整数」）者「物」而「物」也。
```

### 调用

```yuyan
「差」于（「被减数」为「一零」）于（「减数」为「三」）。
「缩放」于「四」于（「倍率」为「二」）。
「单位」于（「数值」为「八」）。
```

三调之果，次第为「七」「八」「八」。有标之实参仍由 `于` 入调，与无标之实参同在一实参之列。

### 构造器与模式

```yuyan
「坐标类」立「元类型」也。
「坐标」立化（「横」为「整数」）而化（「纵」为「整数」）而「坐标类」也。

「原点」者「坐标」于（「横」为「零」）于（「纵」为「零」）也。

「取横」乃化「坐标类」而「整数」也。
「取横」者会「点」而
  鉴「点」而
    有（「坐标」于（「横」为「横值」）于（「纵」为「纵值」））则「横值」
也。
```

模式之中，「为」后书子模式；「横值」「纵值」，本支之新变量也。

### 括号与标之记号

- 有标之项唯见于四所：函类之参位（含 `化` 之域与 `遇` 之参类）、`会` 之绑定参、`于` 之实参、构造器模式之实参。见于他所，则报误。
- 括号循普通表达式分组之则。`〇为〇` 与余符不新增明定之优先级，循已有通用默认规约；惟一可解则可省括号，遇未定之关系或须明其范围，则加之。标项与右式可各自分组，如 `于（「回调」为（会「数」而「数」））`、`化（「回调」为（化「整数」而「整数」））而 …`。
- 标必为一非空之「名」；数之记号（如「三」）、注释与编译器内名，皆不可为标。标不与名称之查，与同名之变量两不相涉。
- 同一参组之中，标可重，各标惟描述其所居之位。参组循旧则：右之字面箭头平为一组，返类为函类别名者另起一组。

## 三、则

### 箭头类型之形成 引入与消去

以 `A → B` 表普通单参之箭头，以 `~标: A → B` 表标为「标」之单参箭头。A、B 皆可取任一已形成之类，含有标函类。二箭头各依其类型之则行，源码书法见第二节。

| 则 | 普通箭头 `A → B` | 有标箭头 `~标: A → B` |
| --- | --- | --- |
| 形成 | A、B 皆合法之类，则成普通箭头类 | A、B 皆合法之类，标合法，则成有此标之箭头类 |
| 引入 | 环境增局部变量「物」而赋类 A，体依 B 验；`会「物」而 体` 检为此普通箭头 | 环境增局部变量「物」而赋类 A，体依 B 验；`会（「标」为「物」）而 体` 检为此有标箭头 |
| 消去 | 函值有此普通箭头类，参依 A 验，则 `函数 于 实参` 之果类为 B | 函值有此有标箭头类，参依 A 验，则 `函数 于（「标」为 实参）` 之果类为 B；参标须同类中之标 |

有类型匿名函 `遇` 依其引入之则合类：明给 A，于增后环境合体类 B，得普通或有标之箭头。局部变量之名可共易，箭头之标依文字比之。

表列单参组。多参组循旧箭头分组与全授之则，引入、消去于本组诸位各用其应则；源码之调须一次尽给本组诸参。诸位之标可同。

### 逐位相对

引入、消去及构造器模式检查，皆逐位依函类择有标或无标之参则：

- 函类此位有标「甲」：必书 `「甲」为 …`，标文必全同，括号依解析之需加之。
- 函类此位无标：径书实参或局部之名，不可书标。

标属箭头类，以定此位引入、消去之则。实参与形参仍依位相应：第 n 实参应第 n 参。全授、参组、返函之则皆如旧；隐式类参（`承`、`授以`）无标，其则亦如旧。

同名之标逐位核之，各位之参类亦可异：

```yuyan
「成对」乃化（「物」为「整数」）而化（「物」为「字符串」）而（「整数」合「字符串」）也。
「成对」者会（「物」为「数」）而会（「物」为「文」）而「数」与「文」也。
「成对」于（「物」为「七」）于（「物」为『甲』）。
```

首位验「物」标及整数参，次位验「物」标及字符串参。重标不易参位、实参之序与局部绑定。

### 引入之则与函数值表达式

检 `会（「甲」为「局部名」）而`，用有标箭头引入之则，所期函类之当前参位必有同标「甲」；`会「局部名」而` 用普通箭头引入之则。`遇（「甲」为 类）者「局部名」而` 依有标箭头引入之则合成类型。

参数声明或实参之类、标不合其所应之位，则类型检查报误。函值之定义则依含标之完整类核之。

以既有函值径作定义，亦合法。如用第二节之「差」：

```yuyan
「差类」即化（「被减数」为「整数」）而化（「减数」为「整数」）而「整数」也。
「另一个差」乃「差类」也。
「另一个差」者「差」也。
```

引「差」者，变量之则给其完整函类；此类与「差类」等，故定义验过。调「另一个差」仍依类中「被减数」「减数」二标用消去之则。定义体亦可为条件之择、函值之读、完整调用所得之函值；皆循旧表达式之则合成或检查其类，存完整函类之标。

### 类型之等与组合

有标函类为完整之类，可循旧类型形成之则用于类别名、函之参与果、元组、列及余既有类型构造，亦可为泛型之类型实参。标约参数之声与调用之法，函值之组合循已有类型之则。

| 所较 | 果 |
| --- | --- |
| `化（「数值」为「整数」）而「整数」` 与其自身 | 等 |
| 标「数值」与标「输入」 | 不等 |
| 有标与无标 | 不等 |
| 易二位而其标或参类异 | 不等 |
| 易二位而其标、参类皆同 | 等 |
| 函体局部之名「甲」易为「乙」 | 类不变 |

合一同此则。标项为参之描述，类型变量不得解为独立之标项，可解为内含标参之完整函类。如「甲」可取 `化（「底数」为「整数」）而「整数」`，泛型函与容器可授或存此函值，类中之标须全存。

所期为 `化 甲 而 乙` 之高阶函仍须无标之回调参。有标函之参描述与此位不等，必显式转接：

```yuyan
「平方」乃化（「底数」为「整数」）而「整数」也。
「平方」者会（「底数」为「数」）而「乘」于「数」于「数」也。

（「态射」授以「整数」授以「整数」）于「数列」于（会「数」而「平方」于（「底数」为「数」））
```

以整条有标之函类为类型实参，则可径用：

```yuyan
「平方类」即化（「底数」为「整数」）而「整数」也。
「原样」乃承「甲」而化「甲」而「甲」也。
「原样」者受「甲」而会「物」而「物」也。

（「原样」授以「平方类」于「平方」）于（「底数」为「三」）。
```

此调得「九」。「原样」之类参「甲」取完整「平方类」，其果函仍须标「底数」。

## 四、求值与生码

实参依所声之序书之；类型检查之后去其标，所得之调与依位所书者同。求值之序、尾位、顶层直调与去装箱皆如旧；运行之时不存标。

## 五、编译期之表

下表为上述箭头类及其引入、消去之编译器表示。共用旧箭头主节点者，以参位标项存有标箭头之类信息；形成、相等、引入与消去皆依之行。

| 节点 | 所含 | 所在与存续 |
| --- | --- | --- |
| 标项节点 | 标之字符串，一子式 | 在函类之参位者，子式为类，随检查后之类存之，类型擦除时去之；在调用与模式之实参者，子式为值或子模式，检查后去之 |
| 有标之拉姆达 | 标之字符串，一抽象 | 解 `会（「标」为「局部名」）而` 得之；检查后化为旧有之带类型拉姆达，其参类为标项 |

- 标之字符串不入自由变量，不与名称解析与换名；通遍历仍入其子式。
- 存标之源码范围，以供诊断与悬停。

## 六、解析

- 增中缀之符 `〇为〇`。其左必为单一之名，核法同组值之字段名；构标项节点。
- 增 `会〇而〇`，首元素惟受 `「标」为「局部名」` 之标项；构有标之拉姆达，局部之名绑于主体。旧 `会□而〇` 仍理无标绑定。
- `化〇而〇`、`遇〇者□而〇`、`〇于〇` 仍其旧形，标项即其参，括号惟以分组。
- 优先级：凡与「为」之组合，不新增明定关系，循已有通用默认规约。组合无优先级之关系，则仍报“未定义优先级关系”，由源码加括号以分组；不尽拒省括号之式。
- 解析之例必证 `会〇而〇` 之标项支与 `会□而〇`、括号之式之间惟一解；可省括号之式与必分组之组合各验之。

## 七、类型检查之改

1. 类型形成：依普通、有标箭头形成之则验域与果类；标项唯许见于函类之参位与 `遇` 之参类，核各位之标合法，许重标。
2. 类型相等与合一：标项依标文与子类相较；类型变量不得解为独立标项，可解为内含标参之完整函类。
3. 匿名函之检：依第三节引入之则理 `会`、`遇`；变量、条件诸式循旧则，所得函类存其标。
4. 函数调用（`函数应用隐式参数合成。豫`）：依第三节消去之则逐位验标与参类，成而后去调用之标。推隐参之时，实参之预读透标项而视其内，形参用去标之实类。
5. 构造器之模式（`模式匹配类型检查。豫`）：亦逐位核之。
6. 无体之声：依签名合函体之时，生有标之 `会`。

| 所在 | 所改 |
| --- | --- |
| 签名类别（`顶层直接调用。豫` 之「类型类别码」） | 依实类计其类别，存有标之整数、小数之参去装箱之法 |
| 构造器之形 | 依实类计之 |
| 宿主边界检查 | 边界之形依实类计之；标不易参之数、Wasm 之类与宿主之字段名 |
| 序列化、阶段节点语法、阶段形状校验 | 纳二节点 |
| 类型之表与悬停 | 示作 `（「标」为 类）` |
| 语义标记（`表达式解析。豫` 之操作符表） | 登新符 |
| 源码排版 | 「为」之两侧不断行；`于（…）` 循括号实参之则；`会（…）而` 以绑定处之 |

## 九、诊断

| 情形 | 所示 |
| --- | --- |
| 此位当书标而未书 | 第 n 参当书（「甲」为 …） |
| 标文不合 | 第 n 参之标当为「甲」，今书「乙」 |
| 此位无标而书标 | 第 n 参无标，当去（「乙」为 …）之标 |
| 定义之标与类不合 | 同上三条，指其所对之 `会` 或 `遇` |
| 函值之标与所期之类不合 | 示所期与所得之函类 |
| 标项见于他所 | 有标之项唯可为函之参 |
| 符之组合无优先级关系 | 循旧未定义优先级关系之报，提示以括号分组 |
| 类型构造器之参或着色之语用标 | 初版暂不支 |

## 十、去 `循□以〇`

`循 名 以 式` 之构造函数径返其式，不立绑定；`LOCALAGENTS.md` 亦明言其“不会建立递归绑定”。仓中尚有二十五源文、七十一处书之：编译器网页汇编之测十七文，性能研究八文。七十一处皆在有签名之顶层定义，形如 `「名」者循「…」以 …`（其二处前隔 `受「甲」而`），其递归由签名所供。

去之之步：

1. 去诸文中之 `循「…」以`，行为不变。
2. 去其操作符之定义，及其于文言符集、控制操作符表之登记。
3. 更词法与语法之规范、`LOCALAGENTS.md` 与语言规范中之相关文字。

此步与标之功两不相依，可先独提交。

## 十二、验收之例

| 类 | 必及 |
| --- | --- |
| 基本 | 一标；多标；同组重标而参类同或异；有标无标相杂；其果正 |
| 拒 | 缺标、标误、无标之位书标、易序而类或标不合、数之记号为标、未分组而有未定优先级之关系、标项见于他所 |
| 解析 | 惟一可解之标项可省括号；无优先级之组合分组后可解；嵌式之标项与右式各分组 |
| 形成 | 普通、有标箭头之域与果类合法否；各位之标合法否；重标及内嵌有标函类之形成 |
| 引入与消去 | `会`、`遇` 与所期箭头合与不合；实参之标、类合与不合；函之别名、条件之择与调用所返函值依完整类验之 |
| 类型 | 等表诸行；类型别名；跨文之导入与重导出；有标之高阶参；显式转接后授 `态射`；径授 `态射` 则报误 |
| 泛型 | 明授与推定；有标之参其类含变量；类型变量取完整有标函类而授、返或存容器，标仍存；独立标项不得作类型实参 |
| 构造器 | 构造、模式、嵌套之模式 |
| 运行 | 开、关优化；顶层直调与自递归尾调照常而生；整数、小数之参照常去装箱 |
| 接口 | 有标之 `。接口。豫` 签名，边界之形不变；无体之声之合成 |
| 阶段与排版 | 序列化往返；格式化幂等；注释存之 |

## 十三、暂不为

乱序之书、默认之值、省参、标之简书、自动之转或专门之转语、类型构造器参之标、着色语中之标、使组值组类之命名项同此书法。
