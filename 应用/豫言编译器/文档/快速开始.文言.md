# 快速开始

下列步骤，行于 Linux 与 macOS。系统须先备 `clang`、LLVM 之器（`llvm-ar`）、`curl`、`tar` 与 Node.js 二十六版以上；其常设之法如次：

```sh
# Debian / Ubuntu（Node.js 依 https://nodejs.org 之说另装）
sudo apt-get update
sudo apt-get install clang llvm curl tar

# macOS（Homebrew）
brew install llvm node
export PATH="$(brew --prefix llvm)/bin:$PATH"
```

## 构建工具链

于仓库根目录下载 CI 所发之 [Wasm 工具链包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-binaries)，解于仓根（豫构以编译器所在之目为工具链之根），乃以 Node 行包中之构建程序、豫构与编译器：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-wasm.tar.gz \
  --output yy_wasm工具链.tar.gz
tar -xzf yy_wasm工具链.tar.gz
node yy稳定节点宿主/宿主.cjs yy仓库构建_stable.wasm 运行时
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 仓库构建 --编译器 ./yy_bs_stable.wasm --输出 yy仓库构建
./yy仓库构建
```

前二步造原生运行时与本机之构建程序 `yy仓库构建`；末步自举编译器（二级由 Wasm 编译器于 Node 下造之，其后诸级皆本机之器），得 `yy4_bs`，并造包工具 `yy豫构`。Linux x86-64 亦可改取同发之 `yuyan-linux-x86_64.tar.gz`（原生之 `yy_bs_stable`、`yy豫构_stable` 与运行时之档），解于仓根，乃行 `./yy豫构_stable 构建 仓库构建 --编译器 ./yy_bs_stable --输出 yy仓库构建` 与 `./yy仓库构建`。垃圾回收器已含于运行时源码，无须另装 Boehm GC。构建程序诸目标见[仓库构建](../../仓库构建/包说明.文言.md)。

## 编写并运行程序

前节既成，则有今之编译器与包工具 `yy豫构`。新建 `示例/你好。包。豫`：

```yuyan
「依赖」者「列」【『标准库』】也。
「入口」者『入口』也。
```

复建 `示例/入口。豫`：

```yuyan
寻观「标准库」之书。
「打印行」于『你好，豫言！』。
```

于仓根行之；包依文件名而得，不复以路径猜名：

```sh
./yy豫构 构建 你好 --输出 yy你好
./yy你好
./yy你好 参数一 参数二
```

唯验类型，可行 `./yy豫构 类型检查 你好`。包根、直依、多入口与初举之制，见[仓库包构建](../../豫构/文档/仓库包构建.文言.md)。独立项目欲用标准库，须将其包纳入发现域，详见[包系统](../../豫构/包系统.文言.md)。

欲观编译器之全部选项，可行 `./yy4_bs --help`。单文件旧入口仍备兼容，常用构建则由豫构行之。
