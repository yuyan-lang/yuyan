# 快速开始

下列步骤，行于 Linux 与 macOS，唯须 `curl` 与 `tar`（macOS 自带）：

```sh
# Debian / Ubuntu
sudo apt-get update
sudo apt-get install curl tar
```

## 构建工具链

于仓库根目录下载 CI 所发本平台之[原生工具链包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-binaries)（macOS 苹果之芯取 `yuyan-native-macos-arm64.tar.gz`，Linux x86-64 取 `yuyan-native-linux-x64.tar.gz`，Linux arm64 取 `yuyan-native-linux-arm64.tar.gz`），解于仓根（豫构于己旁求执行器），乃以包中之豫构据今源构一级原生豫构，复原生自举：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-native-linux-x64.tar.gz \
  --output yy原生工具链.tar.gz
tar -xzf yy原生工具链.tar.gz
./yy豫构_stable.exe 构建 豫构 --输出 yy豫构.exe -j 24 -- --目标 本机 --执行器 yy执行器。树码
./yy豫构.exe 全部 -j 24
```

解之，得原生豫构 `yy豫构_stable.exe` 与执行器之汇编树码 `yy执行器。树码`。首步据今源构一级原生豫构；次步「全部」原生自举（二级、三级，校其产逐字相同），装本机原生之工具链 `yy豫构.exe`、`yy4_bs.exe` 与执行器，并构浏览器与云工二网页后端所用之 Wasm 编译器与豫构。此后构建与诸器皆用原生之程 `./yy豫构.exe …`。欲与 CI 同版，可改取 `historical-binaries` 所发之 `<提交之时>-yuyan-native-<平台>-<提交号>.tar.gz`（时取 UTC，若 `20260930T090727Z`），CI 起步所用之址与 SHA-256 见 `.github/workflows/main.yml` 之 `YY_NATIVE_TOOLCHAIN_URL`、`YY_NATIVE_TOOLCHAIN_SHA256`。仓库之构建目标书于 `应用/豫构/仓库目标。豫`，行 `./yy豫构.exe 目标 --列出` 可尽列之。

Windows 自 Wasm 工具链之包起步，须 Node.js 二十六版以上：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-wasm.tar.gz \
  --output yy_wasm工具链.tar.gz
tar -xzf yy_wasm工具链.tar.gz
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 豫构 --编译器 ./yy_bs_stable.wasm --输出 yy豫构.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 全部 -j 24
```

此后以 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm` 代 `./yy豫构.exe`，器与程之出名用 `.wasm`，亦由之行。Windows 之原生工具链待后版。

## 编写并运行程序

前节既成，则有原生之豫构 `yy豫构.exe`（自带编译器）。新建 `示例/你好。包。豫`：

```yuyan
「依赖」者「列」【『标准库』】也。
「入口」者『入口』也。
```

复建 `示例/入口。豫`。可行之程序，始于入口之篇中入口之函「入口」：

```yuyan
寻观「标准库」之书。

「入口」乃化「有」而「有」也。
「入口」者会「无」而「打印行」于『你好，豫言！』也。
```

于仓根行之；包依文件名而得，不复以路径猜名：

```sh
./yy豫构.exe 构建 你好 --输出 yy你好.exe -j 24
./yy你好.exe
./yy你好.exe 参数一 参数二
```

唯验类型，可行 `./yy豫构.exe 类型检查 你好`。包根、直依、多入口与初举之制，见[仓库包构建](../../豫构/文档/仓库包构建.文言.md)。独立项目欲用标准库，须将其包纳入发现域，详见[包系统](../../豫构/包系统.文言.md)。

径呼编译器，则书源文于首参：`./yy4_bs.exe <源文。豫> [编译器之参…]`（`yy4_bs.exe` 与 `yy豫构.exe` 为一程）；常用构建由豫构行之。
