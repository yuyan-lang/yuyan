# 快速开始

下列步骤，行于 Linux 与 macOS。系统唯须 Node.js 二十六版以上、`curl` 与 `tar`；其常设之法如次：

```sh
# Debian / Ubuntu（Node.js 依 https://nodejs.org 之说另装）
sudo apt-get update
sudo apt-get install curl tar

# macOS（Homebrew）
brew install node
```

## 构建工具链

于仓库根目录下载 CI 所发之 [Wasm 工具链包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-binaries)，解于仓根（豫构以编译器所在之目为工具链之根），乃以 Node 行包中之豫构与编译器：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-binaries/yuyan-wasm.tar.gz \
  --output yy_wasm工具链.tar.gz
tar -xzf yy_wasm工具链.tar.gz
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 豫构 --编译器 ./yy_bs_stable.wasm --输出 yy豫构.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 全部 -j 24
```

解之，得编译器 `yy_bs_stable.wasm`、豫构 `yy豫构_stable.wasm` 与 Node 宿主 `yy稳定节点宿主/`。首步以包中之豫构与编译器，据今源造 `yy豫构.wasm`；次步自举编译器（`yy_bs_stable.wasm` → `yy2_bs.wasm` → `yy3_bs.wasm` → `yy4_bs.wasm`，校 `yy3_bs.wasm` 与 `yy4_bs.wasm` 逐字相同），乃以 `yy4_bs.wasm` 重造 `yy豫构.wasm`。诸器皆 `.wasm` 之模，以 `node 豫言操作系统/宿主/节点/宿主.cjs` 行之；器所复启之 `.wasm` 子程，宿主据其文首自另起 Node 行之。欲与 CI 同版，可改取 `historical-binaries` 所发之 `<提交之时>-yuyan-wasm-<提交号>.tar.gz`（时取 UTC，若 `20260930T090727Z`），CI 所用之址与 SHA-256 见 `.github/workflows/main.yml` 之 `YY_WASM_TOOLCHAIN_URL`、`YY_WASM_TOOLCHAIN_SHA256`。仓库之构建目标书于 `应用/豫构/仓库目标。豫`，行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 目标 --列出` 可尽列之。

## 编写并运行程序

前节既成，则有今之编译器 `yy4_bs.wasm` 与包工具 `yy豫构.wasm`。新建 `示例/你好。包。豫`：

```yuyan
「依赖」者「列」【『标准库』】也。
「入口」者『入口』也。
```

复建 `示例/入口。豫`：

```yuyan
寻观「标准库」之书。
「打印行」于『你好，豫言！』。
```

于仓根行之；包依文件名而得，不复以路径猜名：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 你好 --输出 yy你好.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy你好.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy你好.wasm 参数一 参数二
```

唯验类型，可行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 类型检查 你好`。包根、直依、多入口与初举之制，见[仓库包构建](../../豫构/文档/仓库包构建.文言.md)。独立项目欲用标准库，须将其包纳入发现域，详见[包系统](../../豫构/包系统.文言.md)。

欲观编译器之全部选项，可行 `node 豫言操作系统/宿主/节点/宿主.cjs yy4_bs.wasm --help`。单文件旧入口仍备兼容，常用构建则由豫构行之。
