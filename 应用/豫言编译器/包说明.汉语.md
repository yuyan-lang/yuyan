# 豫言编译器

解析、检查并编译豫言程序。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为可执行文件类型，不可被其他包依赖；共享编译功能请依赖编译器核心库。类型典中的入口和文件名见包配置，程序产物为 `yy`。

## 使用

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 豫言编译器
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 豫言编译器
```

依赖及说明路径以 [包配置](豫言编译器。包。豫) 为准。构建不会自动运行程序；有发布或服务副作用的工具应先阅读其入口源码。

## 原生产物

给编译器参数 `--目标 本机 --执行器 yy执行器.wasm` 时，最终链接直接写出本机原生可执行文件（macOS 为 Mach-O，Linux 为 ELF），不经 `.wasm` 文件：豫汇模块在同一进程里交给裸机后端的「原生产物」，经预编二与寄存器降级生成（提案 00007 第 3 步）。`--降级缓存 路径` 指定执行器函数的降级缓存。经豫构构建时，这些参数写在 `--` 之后，例如：

```sh
./yy豫构.exe 构建 某包 --输出 yy某包 -j 24 -- --目标 本机 --执行器 yy执行器.wasm
```

编译器因此依赖裸机后端。
