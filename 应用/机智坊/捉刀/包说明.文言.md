# 捉刀

捉刀者，编程之智能体也（提案〇〇〇三六）：使大模型居豫言之壳中，代人书码办事。名取《世说新语·容止》“床头捉刀人，此乃英雄也”，后世以捉刀称代人执笔。

## 用法

```text
捉刀 [篇径] [--模型 名] [--接口 址] [--轮流] [--深思] [--限时 秒] [--整收] [--豫构 径]
捉刀 篇径 --嘱 文     追一条用户之言，办至此轮之终而退（未竟而止则退码为一）
捉刀 续 篇径          依篇末续办之（误止之后以此自篇末复请）
捉刀 核 篇径          于新子会话重办篇中之句，与所录之回执逐句相核
```

- 篇径默为今目录之 `会话。会话。豫`。
- 默之接口为钩深之 `https://api.deepseek.com/beta`，模 `deepseek-flash`，用对话前缀之续书；钥取诸环境变量 `DEEPSEEK_API_KEY`，未设则读 `/数据/钩深密钥`（去末之换行与空格；宿主行在中为私根下同名之文；桌面揽辔台所起之捉刀不得终端之俗，赖此取钥，十月二十三日）。`--模型 名` 为他接口易模；用钩深则惟用最新之 flash 模（用户二〇二六年十月十八日定）。
- `--接口` 易为他开放机智式之址，则用轮流之映，须以 `--模型` 指模，钥取 `OPENAI_API_KEY`（可不设）。如本机之驼铃：`捉刀 --接口 http://localhost:11434/v1 --模型 qwen3-coder:30b`。`--轮流` 使钩深亦用轮流。
- `--深思` 开思考：接口所返之思录为 `「：模型思考：」` 之块。
- `--限时 秒` 为每句之限，默一时；逾时先止其句，不能止则召回子会话而另起，重放其定。
- 默以流收（邸报）：模型所书随收随印，一句既毕而多收四百字节犹未止则断之；`--整收` 易为全应并收。
- 不带 `--嘱` 则入对话：先印篇末二十行，读用户一行（空行越之），追为用户之块，办至此轮之终，复读次行；读尽（Ctrl+D）则退。
- 标准入为终端，则一轮之中终端在原始之模：按 Ctrl+C 惟止方行之一句（豫言操作系统惟止其句，宿主则召回子会话而另起、重放其定，回执录 `「：错误：」`）或模型方书之出（断之，此回所书不录），此轮随止，复至“用户> ”。于“用户> ”按 Ctrl+C 则捉刀退，篇已存，以 `捉刀 续` 续办。
- 每请之后于标准误印一行用量（入、命中与其率、出、此回与本场之费：依钩深中文官网之人民币忙闲之价，书为元，留小数六位），且于篇旁之用量之账（`会话用量。数据。豫`，数据子语，顶层一列「用量」）追一行，记时、模、命中、未中、所出与「纳元」（其费，元之十亿分之一）。

## 篇

一场之谈录为一篇会话之文（`名。会话。豫`）：

- 块头独居一行：`「：用户：」`、`「：模型思考：」`、`「：模型：」`、`「：稿：名：」`、`「：结果：」`、`「：错误：」`。块之内容为其后以「｜」起之诸行，「｜」之后照录原文。
- 模型欲有为则书一句豫言壳句（以 `。` 终），捉刀付之豫构交互之子会话而行之，回执随录于篇：成则录 `「：结果：」`，不成（编误、异未承、逾时、子会话退）则录 `「：错误：」`。签名与其后同名之定合为一句。
- 稿块收原文：捉刀先付子会话 `「名」乃「文」也。「名」者『…』也。`（值为诸行去「｜」之原文，行各带换行），后句以「名」引之。
- 系统之示（篇式之说与例、今目与日、仓根之 LOCALAGENTS.md、上寻所得之 AGENTS.md）别置于每请之首。请即系统之示加全篇，篇但增不改，故钩深之缓存几尽中。
- 回执逾二十万字则留首尾各十万字；回执去终端转义之序与回车，不合法之八位同文易为 �。
- 篇式之误（模型书用户、结果、错误之块，「｜」行前无块头，句未毕而见「｜」行，无名无串之一行言，全行之尖括标签（钩深时吐 `<clarification>`、`</｜｜DSML｜｜ parameter>` 之类），句未收，签名之后无定，不书句亦不书 `「：模型：」` 之块以交代）：此书全不录，稿亦不定，于标准误印其故（整收则并原文），此轮止。不揣其意、不代其补（漏「｜」之行为码，无角引之 `：模型：` 不为块头），亦不使重书：模型所书不合理则报误而退，听上级统理（用户 2026-10-18 定）。书首接上回执而续编之「｜」行弃而不录（续书时常有），一书唯此者亦为篇式之误。止串为三回执块头本身与换行接块头。
- 模型书 `「：模型：」` 之块以交代而无句，此轮乃终；句未成（编误、异未承等）照录其报，使模型改之。一轮至多千步，连八句未成亦止。不合篇式、请败、满千步或连八未成而止，则 `--嘱` 与 `续` 以退码一退。
- 篇逾二百万字节则易为续篇（`会话续一。会话。豫`……）：续篇以一用户之块起，说前篇之径而附前篇末二百行；子会话如故，其定不失。

## 子会话

捉刀起 `豫构 交互 --直读 --回执 标`（标每次随机而生）。宿主（林檎、林纳）之原生程序惟能起以 `--授权子程序` 所授之子程，惟能传以 `--允许环境` 所授之环境，故捉刀初行则带此诸选（子会话所用之豫构，与 PATH、HOME 等今有之环境）复行己身。子会话所用之豫构依次寻之：`--豫构` 所指者，捉刀之旁者，今目上寻之仓中者，PATH 中者；豫言操作系统中为 `/工具/豫构。豫行`。读文（「读行」）、搜索（「寻」）诸壳命须用开发之器 `开发。林檎。豫行`，子会话依次寻豫构之旁、仓根与 PATH 中者；书码则以「营」（行豫构）营而行之、试之，篇式之说载其书法。

开旧篇则先以篇中之稿块与已成之定句付子会话重放之（弃其报）；`捉刀 续` 复视篇末：末为一句而无回执则行之而办一轮；末为 `「：模型：」` 之块（已交代）则不办；余（用户之块、回执之块）则办一轮，自篇末复请。上级统理误止之捉刀，即用此。`捉刀 核` 径于新子会话依次重办其句（改文、构建之句亦重办，宜于工作目录之副本行之）。

## 模块

| 模块 | 所司 |
| --- | --- |
| 叩问 | 合对话之请（钩深前缀续书与思考之枢、止串）、致请（尺素，HTTPS 与 HTTP）、全收与流收（邸报）、解答书与用量、依忙闲计费 |
| 壳使 | 起子会话、送句、读回执与标、逾时而止、召回另起、阖之 |
| 入口 | 命行、宿主授权复行、系统之示、对话与嘱、一轮、续办、重放、重放核对、用量之账、续篇 |

篇式已别为一库 `库/篇式`（`寻观「篇式」之书。`），捉刀与揽辔共之；其单元试在 `库/篇式/测试/篇式。测试。豫`。

## 观测台之后台（--台）

`捉刀 篇径 --台` 不读标准入，供揽辔台居后而行：

- 事书为 `<篇>。观。<行号>。<序号>。会话。豫` 小卷，循会话篇之块与竖行；今行号书于 `<篇>。观。今`。要事（就绪、篇改、句始、句终、句出、用量、错误、轮始、轮终、打断、停止）至即书；流片积八片或四千零九十六字节书一批。
- 嘱咐、打断、停止为 `<篇>。令。嘱咐`、`<篇>。令。打断`、`<篇>。令。停止` 三标；嘱咐之文即用户之言。后台初起则先焚前番所遗之断止二标（未取之嘱留之），此后每轮先察断止，次取一嘱；有则录用户之块、书轮始、办一轮、书轮终。
- 事与制标之径、析法与栏数在库「揽辔」之「台」篇；观测台共用之。
- 壳中亦可发此三标：`「嘱捉刀」于「篇」曰『会话。会话。豫』于「话」曰『接着改』`、`「辍捉刀」于「篇」曰『会话。会话。豫』`、`「罢捉刀」于「篇」曰『会话。会话。豫』`（库「诏令」），与观测台之钮同效。
