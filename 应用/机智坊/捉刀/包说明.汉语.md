# 捉刀

捉刀是编程智能体（提案 00036）：让大模型在豫言的壳里替人写代码、办事。名字取《世说新语·容止》“床头捉刀人，此乃英雄也”，后世以捉刀称代人执笔。

## 用法

```text
捉刀 [篇路径] [--模型 名] [--接口 网址] [--轮流] [--深思] [--限时 秒] [--整收] [--豫构 路径]
捉刀 篇路径 --嘱 文字     追加一条用户的话，办到这一轮结束就退出（没办成而停下时退出码是一）
捉刀 续 篇路径            照篇末接着办（出错停下后用它从篇末重新请求）
捉刀 核 篇路径            在新的子会话里把篇里的句子重办一遍，与记下的回执逐句比对
```

- 篇路径缺省为当前目录的 `会话。会话。豫`。
- 缺省接口是钩深（DeepSeek）的 `https://api.deepseek.com/beta`，模型 `deepseek-flash`，用对话前缀续写；密钥只从环境变量 `DEEPSEEK_API_KEY` 读取。`--模型 名` 给别的接口换模型；用钩深时只用最新的 flash 模型（用户 2026-10-18 定）。
- `--接口` 换成别的开放机智（OpenAI）式地址时用轮流映射，要用 `--模型` 指定模型，密钥取 `OPENAI_API_KEY`（可以不设）。如本机驼铃（Ollama）：`捉刀 --接口 http://localhost:11434/v1 --模型 qwen3-coder:30b`。`--轮流` 让钩深也用轮流映射。
- `--深思` 开思考模式：接口返回的思考记成 `「：模型思考：」` 块。
- `--限时 秒` 是每句的限时，缺省一小时；超时先只打断这一句，打断不了就召回子会话另起，重放定义。
- 缺省流式接收（邸报）：模型写的随收随印，一句写完、又多收四百字节还没停就断开；`--整收` 改为整段应答一起收。
- 不带 `--嘱` 时进入对话：先印篇末二十行，读用户的一行（空行跳过），追加成用户块，办到这一轮结束，再读下一行；读到卷终（Ctrl+D）退出。
- 标准输入是终端时，一轮里终端在原始输入模式：按 Ctrl+C 只打断正在执行的一句（豫言操作系统里只打断这一句，宿主上召回子会话另起并重放定义，回执记 `「：错误：」`）或模型正在写的输出（断开，这次写的不记进篇），这一轮随即停下，回到“用户> ”。在“用户> ”处按 Ctrl+C 结束捉刀，篇已存盘，用 `捉刀 续` 接着办。
- 每次请求后在标准错误印一行用量（输入、命中与命中率、输出、本次与本场的费用，按钩深的忙闲时价算），并在篇旁的用量账（`会话用量。数据。豫`，数据子语言，顶层一个列「用量」）里追加一行。

## 篇

一场会话记成一篇会话文件（`名。会话。豫`）：

- 块头单独一行：`「：用户：」`、`「：模型思考：」`、`「：模型：」`、`「：稿：名：」`、`「：结果：」`、`「：错误：」`。块的内容是其后以「｜」起头的各行，「｜」之后照原样写。
- 模型要做事就写一句豫言壳句（以 `。` 结尾），捉刀把它交给豫构交互子会话执行，回执紧接着记进篇里：办成记 `「：结果：」`，没办成（编译出错、异常没接住、超时、子会话退出）记 `「：错误：」`。签名句与紧随的同名定义合成一句。
- 稿块收原样文字：捉刀先给子会话送 `「名」乃「文」也。「名」者『…』也。`（值是各行去掉「｜」的原文，每行带换行），后面的句子用「名」引用。
- 系统提示（篇式说明与示例、当前目录与日期、仓根的 LOCALAGENTS.md、往上找到的 AGENTS.md）单独放在每次请求的开头。请求就是系统提示加整篇，篇只增不改，钩深的上下文缓存几乎全中。
- 回执超过二十万字时留开头、结尾各十万字；回执去掉终端转义序列与回车，不合法的八位同文换成 �。
- 篇式错误（模型写出用户、结果或错误块，「｜」行前面没有块头，句子没写完就出现「｜」行，没有名称也没有字符串的一行话，整行的尖括号标签（钩深偶尔吐出 `<clarification>`、`</｜｜DSML｜｜ parameter>` 之类），句子没收尾，签名句后面没有定义，既没写句子也没写 `「：模型：」` 块交代）：这次输出整个不记进篇、稿也不定义，在标准错误印出原因（整收时连同原文），这一轮停下。不猜模型的意思、不替它补写（漏了「｜」的行当代码，不带角引号的 `：模型：` 不算块头），也不让模型重写：模型输出不合理就报错退出，由上级统一处理（用户 2026-10-18 定）。输出开头接着上一块回执往下编的「｜」行丢掉不记（续写时常有），整次只有这些时也是篇式错误。停止串是三个回执块头本身与换行接块头。
- 模型写了 `「：模型：」` 块交代、没写句子，这一轮就结束；句子没办成（编译出错、异常没接住等）照旧把回执记进篇里让模型改。一轮至多一千步，连着八次句子没办成也停下。不合篇式、请求失败、满一千步或连着八次没办成而停下时，`--嘱` 与 `续` 以退出码一退出。
- 篇超过二百万字节时换到续篇（`会话续一。会话。豫`……）：续篇以一块用户块起头，说明前篇路径并附上前篇末尾二百行；子会话照旧，定义不丢。

## 子会话

捉刀起 `豫构 交互 --直读 --回执 标记`（标记每次随机生成）。宿主（林檎、林纳）上的原生程序只能起宿主用 `--授权子程序` 授权的子程序、只能传 `--允许环境` 授权的环境变量，所以捉刀第一次运行时带上这些宿主选项（子会话用的豫构，与 PATH、HOME 等现有的环境变量）重新运行自己。子会话用的豫构依次找：`--豫构` 指定的，捉刀旁边的，从当前目录往上的仓库里的，PATH 里的；豫言操作系统里是 `/工具/豫构。豫行`。读文件（「读行」）、搜索（「寻」）等壳命令要用开发工具 `开发。林檎。豫行`，子会话依次找豫构旁边、仓根与 PATH 里的；写了代码用「营」（运行豫构）构建运行、跑测试，篇式说明里有写法。

打开已有的篇时，先把篇里的稿块与办成了的定义句交给子会话重放一遍（回执丢弃）；`捉刀 续` 再看篇末：末尾是一句还没有回执就执行它再办一轮；末尾是 `「：模型：」` 块（已经交代）就不办；其余（用户块、回执块）就办一轮，从篇末重新请求。上级统一处理出错停下的捉刀时就用它。`捉刀 核` 直接在新的子会话里把句子依次重办（会重办改文件、构建的句子，宜在工作目录的副本里做）。

## 模块

| 模块 | 内容 |
| --- | --- |
| 叩问 | 拼对话请求（钩深前缀续写与思考开关、停止串）、发请求（尺素，HTTPS 与 HTTP）、整段与流式（邸报）接收、解出答书与用量、按忙闲时计费 |
| 壳使 | 起子会话、送句、读回执与标记、超时打断、召回另起、关闭 |
| 入口 | 命令行、宿主授权重起、系统提示、对话与嘱咐、一轮、接着办、重放、重放核对、用量账、续篇 |

篇式已抽成独立库 `库/篇式`（`寻观「篇式」之书。`），捉刀与揽辔共用；其单元测试在 `库/篇式/测试/篇式。测试。豫`。
