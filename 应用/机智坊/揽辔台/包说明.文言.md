# 揽辔台

通称揽辔观测台。于豫言操作系统或宿主之窗，实时观一场捉刀之谈：状态与用量居上，会话卡片居中，输入居下，可致嘱、可止、可断。

后台为 `捉刀 --台 <篇>`：事书为 `<篇>。观。<行号>。<序号>。会话。豫` 小卷，台依行号与序号而读；旧篇以共篇式自析；嘱咐、打断、停止为 `<篇>。令。嘱咐` 等三标。

## 用法

```text
揽辔台 [篇路径]
```

篇径缺省为今目之 `会话。会话。豫`。先于终端起后台，再开此台。

发、断、止三钮各有同效之壳命（库「诏令」），于壳下命与按钮无异：

```text
「嘱捉刀」于「篇」曰『会话。会话。豫』于「话」曰『接着改』
「辍捉刀」于「篇」曰『会话。会话。豫』
「罢捉刀」于「篇」曰『会话。会话。豫』
```

## 组成

- `模`：态、篇析、事收、定时复读、制标。
- `视`：门面之界。
- `入口`：窗之主环与参。

## 构建与运行

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。林檎。豫行 -j 24
./揽辔台。林檎。豫行 会话。会话。豫
```

后台别开一终端：

```sh
DEEPSEEK_API_KEY=... ./捉刀。林檎。豫行 会话。会话。豫 --台
```

观测台每百毫秒读 `<篇>。观。今` 之针与新事，依行号与序号而收；旧篇以篇式析之。输入之“发送”书 `<篇>。令。嘱咐`，“打断”书 `<篇>。令。打断`，“停止”书 `<篇>。令。停止`；后台见标而办。

## 观测内容

- 用户、模型、思考、命令、回执、错误六卡；模型之信循共用标记文预览，命令与回执等宽。
- 状、模名、今句、本场命中/未中/所出词元与纳美元。
- 误以朱色标之；后台之四零一、篇式之误、逾时皆入误卡。
- 卡新在前：最新之流与回执居首，不待滚动。

## 测试

```sh
./豫构。林檎。豫行 运行 应用/机智坊/揽辔台/测试/状态。测试。豫
```

## 在豫言操作系统里

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。豫行 -j 24 -- --目标系统 豫言
```

以 `揽辔台。豫行` 置桌面授根（如 `/工具` 或造盘时之工具目），于文件浏览选中而行，则于一外程序格开窗；后台仍于终端行 `捉刀 篇径 --台`。窗所需之显示面由外程序格转授，输入与尺寸亦由之转交。
