# 揽辔台

通称揽辔观测台。于豫言操作系统或宿主之窗，实时观一场捉刀之谈：状态与用量居上，会话卡片居中，输入居下，可致嘱、可止、可断。系统之卡缺省隐藏，顶上状态区之钮“显示系统提示”“隐藏系统提示”惟改本窗之示。

后台为 `捉刀 --台 <篇>`：事书为 `<篇>。观。<行号>。<序号>。会话。豫` 小卷，台依行号与序号而读；旧篇以共篇式自析；嘱咐、打断、停止为 `<篇>。令。嘱咐` 等三标，别有一柝（心跳）之卷 `<篇>。令。柝`，台之窗开时约每秒重书，后台见其绝则自退。

## 用法

揽辔台为预装之器（十月二十三日）：豫言操作系统与宿主行在之桌面中，于启台点“揽辔台”，或于壳下此二句即开（林檎双击“豫言.app”即入桌面）：

```text
「图形」
「辟窗」于「种类」曰『揽辔台』
```

自桌面开之，则篇为 `/数据/揽辔/会话。会话。豫`，揽辔台自起捉刀之后台（宿主则付行在起之，见豫构包说明“预装之揽辔台”），窗开时约每秒击一柝，窗闭则后台数秒内见柝声绝而自退。`DEEPSEEK_API_KEY` 未设则捉刀读 `/数据/钩深密钥`，于壳书之一次即可：

```text
「案牍」之「著」于『/数据/钩深密钥』于『这里换成密钥』
```

揽辔台登会话之文（名帖之“所开”为“会话。豫”，十月二十三日）：于桌面文件浏览点一 `名。会话。豫` 之文，即以揽辔台开之；副击之“打开方式”中有揽辔台与“文本编辑”，后者于编辑格以文开之。壳中同效之命：

```text
「开卷」于「卷」曰『数据/揽辔/会话。会话。豫』于「用」曰『揽辔台』
「开卷」于「卷」曰『数据/揽辔/会话。会话。豫』于「用」曰『编辑』
```

于终端直行之：

```text
揽辔台 [篇路径]
```

未予篇径则用今目之 `会话。会话。豫`；予篇径则观此篇（相对之径依今目补为全径）。二者皆自起捉刀之后台，窗开时约每秒击一柝，窗闭则后台数秒内自退；加 `--只看` 则不起后台而惟观篇（后台别起：`捉刀 篇路径 --台`）。

桌面行时，可于壳携篇径径开此台（揽辔台预装于 /工具）：

```text
「辟窗」于「种类」曰『揽辔台』于「参数」曰「列」【『/数据/揽辔/会话。会话。豫』】
```

省「参数」则观今目（桌面所起之程缺为程序所在之 `/工具`）之 `会话。会话。豫`；`于「目录」曰『/数据/揽辔』` 可别定当径。

发、断、止三钮各有同效之壳命（库「诏令」），于壳下命与按钮无异：

```text
「嘱捉刀」于「篇」曰『会话。会话。豫』于「话」曰『接着改』
「辍捉刀」于「篇」曰『会话。会话。豫』
「罢捉刀」于「篇」曰『会话。会话。豫』
```

## 组成

- `模`：态、篇析、事收、定时复读、制标。
- `视`：门面之界。
- `入口`：窗之主环与参。

## 构建与运行

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。林檎。豫行 -j 24
./揽辔台。林檎。豫行 会话。会话。豫
```

揽辔台自起其旁之 `捉刀。林檎。豫行` 为后台；欲自别开终端行后台，则加 `--只看` 于揽辔台：

```sh
DEEPSEEK_API_KEY=... ./捉刀。林檎。豫行 会话。会话。豫 --台
```

观测台每百毫秒读 `<篇>。观。今` 之针与新事，依行号与序号而收；旧篇以篇式析之。输入之“发送”书 `<篇>。令。嘱咐`，“打断”书 `<篇>。令。打断`，“停止”书 `<篇>。令。停止`；后台见标而办。台自起后台时，每百毫秒之计时中又约每秒重书 `<篇>。令。柝`（其文为单调钟之纳秒）：窗闭则其程径终，柝不复更，后台隔一秒一查、见其逾四秒不更则自止而退。同篇复开一窗起后台，则 `观。今` 易为新行号，旧后台见针易亦退。

## 观测内容

- 用户、模型、思考、系统、命令、回执、错误七卡；模型之信循共用标记文预览，命令与回执等宽；系统之卡等宽，至多示首四十行，逾四十行则注全文若干字。
- 系统之卡缺省隐藏；顶上状态区之钮在“显示系统提示”与“隐藏系统提示”之间易，惟改本窗之示，不改后台与篇。
- 状、模名、今句、本场命中/未中/所出词元与费（人民币，书为元，留小数六位）。
- 误以朱色标之；后台之四零一、篇式之误、逾时皆入误卡。
- 卡依时正序：旧者居上，新者居下；卡区随末（跟随末尾），新流与回执至则自滚至下。

## 名帖与图标

`名帖。数据。豫` 供启动台与市肆：显示名“揽辔观测台”、类别“开发”、提要一句，所开“会话。豫”（开会话之文），图标指 `图标。设计。豫`。图标依徽识之法：二十四格视框，圆角画框以纸填、以墨描，中画两弯之辔，右上朱点一轮。


## 待办事项

- 旧篇每“篇已改”全析；篇大时可只析新增。
- 卡暂不可折；长回执占屏。云台折叠命令卡留待后续。
- 窗闭至后台自退之间数秒：此数秒内复开同篇，暂有二后台，旧者见 `观。今` 易行号则退。
- 揽辔既起后台、后台未书就绪而见杀者，后台不闻柝之新旧，久留不去。欲收之，于壳下 `「罢捉刀」于「篇」曰『会话。会话。豫』`。

## 在豫言操作系统里

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。豫行 -j 24 -- --目标系统 豫言
```

以 `揽辔台。豫行` 置桌面授根（如 `/工具` 或造盘时之工具目），于文件浏览选中而行，则于一外程序格开窗，而自起 `/工具/捉刀。豫行` 为后台。窗所需之显示面由外程序格转授，输入与尺寸亦由之转交。
