# 揽辔台

通称揽辔观测台（agent observability console）。在豫言操作系统或宿主窗口里实时看一场捉刀（编程智能体）会话：状态与用量在上，中间是会话卡片（用户、模型、思考、系统、命令、回执、错误），下面输入区可发嘱咐、打断与停止。系统提示卡缺省隐藏，顶部状态区的按钮“显示系统提示”“隐藏系统提示”只改本窗口的显示。

后台是 `捉刀 --台 <篇>`：事件写成 `<篇>。观。<运行号>。<序号>。会话。豫` 小卷，观测台按运行号与序号读；旧篇用共用的 `篇式` 解析；嘱咐、打断、停止是 `<篇>。令。嘱咐` 等三个标记。

## 用法

揽辔台是预装的（2026-10-23）：豫言操作系统与宿主行在的桌面里，从启动台点“揽辔台”，或在壳里下这两句就打开（林檎上双击“豫言.app”即进桌面）：

```text
「图形」
「辟窗」于「种类」曰『揽辔台』
```

从桌面打开时篇是 `/数据/揽辔/会话。会话。豫`，揽辔台自己起捉刀后台（宿主上交行在起，见豫构包说明“预装的揽辔台”），窗口关掉时请后台停止。环境变量 `DEEPSEEK_API_KEY` 没设时捉刀读 `/数据/钩深密钥`，在壳里写一次即可：

```text
「案牍」之「著」于『/数据/钩深密钥』于『这里换成密钥』
```

揽辔台登记了会话文件（名帖的“所开”是“会话。豫”，2026-10-23）：在桌面的文件浏览里点一个 `名。会话。豫` 文件就用揽辔台打开；右键的“打开方式”里有揽辔台与“文本编辑”，后者在编辑格里当文本打开。壳里的等价命令：

```text
「开卷」于「卷」曰『数据/揽辔/会话。会话。豫』于「用」曰『揽辔台』
「开卷」于「卷」曰『数据/揽辔/会话。会话。豫』于「用」曰『编辑』
```

在终端里直接运行：

```text
揽辔台 [篇路径]
```

没给篇路径就用当前目录的 `会话。会话。豫`；给了篇路径就看这一篇（相对路径按当前目录补成绝对路径）。两种都自己起捉刀后台，窗口关掉时请后台停止；加 `--只看` 就不起后台，只看篇（后台另行起：`捉刀 篇路径 --台`）。窗口里可输入嘱咐、点“打断”或“停止”；后台见到标记后照办。

桌面在运行时，可以在壳里带篇路径直接开窗（揽辔台预装在 /工具）：

```text
「辟窗」于「种类」曰『揽辔台』于「参数」曰「列」【『/数据/揽辔/会话。会话。豫』】
```

省「参数」时看当前目录（桌面起的程序缺省为程序所在的 `/工具`）的 `会话。会话。豫`；`于「目录」曰『/数据/揽辔』` 可以另定当前目录。

这三个按钮各有等价的壳命令（库「诏令」），在壳里下命令与点按钮效果相同：

```text
「嘱捉刀」于「篇」曰『会话。会话。豫』于「话」曰『接着改』
「辍捉刀」于「篇」曰『会话。会话。豫』
「罢捉刀」于「篇」曰『会话。会话。豫』
```

## 组成

- `模`：状态、会话解析、事件收取、定时重读、控制标记。
- `视`：门面界面。
- `入口`：窗口主循环与参数。

## 构建与运行

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。林檎。豫行 -j 24
./揽辔台。林檎。豫行 会话。会话。豫
```

揽辔台自己起旁边的 `捉刀。林檎。豫行` 作后台；要自己另开终端跑后台，就给揽辔台加 `--只看`：

```sh
DEEPSEEK_API_KEY=... ./捉刀。林檎。豫行 会话。会话。豫 --台
```

观测台每 100 毫秒读一次 `<篇>。观。今` 指针与新事件，按运行号与序号收；旧篇用 `篇式` 解析。输入区的“发送”写 `<篇>。令。嘱咐`，“打断”写 `<篇>。令。打断`，“停止”写 `<篇>。令。停止`；后台见到标记后照办。

## 观测内容

- 用户、模型、思考、系统、命令、回执、错误七种卡片；模型消息走共用的 Markdown 预览，命令与回执等宽；系统卡等宽，最多显示开头四十行，超过四十行时注明全文多少字。
- 系统提示卡缺省隐藏；顶部状态区的按钮在“显示系统提示”与“隐藏系统提示”之间切换，只改本窗口的显示，不改后台与篇。
- 状态、模型名、当前命令、本场命中/未中/输出词元与费用（人民币，印成元，保留六位小数，如“0.002978 元”）。
- 错误用朱色标出；后台的 401、篇式错误、超时都会进错误卡。
- 卡片按时间正序：最早的在上，最新的在下；卡片区跟随末尾，新的流与回执出现时自动滚到最下面。

## 名帖与图标

`名帖。数据。豫` 给启动台与市肆用：显示名“揽辔观测台”、类别“开发”、提要“实时看捉刀（编程智能体）会话，可嘱咐、打断与停止。”，所开“会话。豫”（打开会话文件），图标指向 `图标。设计。豫`。图标照徽识的画法：二十四格视框，圆角画框填纸色、描墨色，框里一道两弯的缰绳，右上角一轮朱色小点。

## 测试

```sh
./豫构。林檎。豫行 运行 应用/机智坊/揽辔台/测试/状态。测试。豫
```

覆盖旧篇解析、系统块成卡与显示开关、事件收取（就绪、模型片、用量、篇改）、视图生成与控制标记。

## 待办事项

- 旧篇解析在每次“篇已改”时重析全篇；篇很大时可改为只析新增段。
- 卡片暂不能折叠；命令回执很长时占屏。云平台的折叠命令卡留待后续版本。
- 同一篇已有后台在跑时（如上次窗口没关就被杀），再打开会再起一个后台。

## 在豫言操作系统里

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。豫行 -j 24 -- --目标系统 豫言
```

把 `揽辔台。豫行` 放进桌面的授权根（如 `/工具` 或造盘时的工具目录），在文件浏览器里选中运行，它就在一个外部程序格里开窗，并自己起 `/工具/捉刀。豫行` 作后台。窗口要的显示面由外部程序格转授，输入与尺寸也由它转交。
