# 揽辔台

通称揽辔观测台（agent observability console）。在豫言操作系统或宿主窗口里实时看一场捉刀（编程智能体）会话：状态与用量在上，中间是会话卡片（用户、模型、思考、命令、回执、错误），下面输入区可发嘱咐、打断与停止。

后台是 `捉刀 --台 <篇>`：事件写成 `<篇>。观。<运行号>。<序号>。会话。豫` 小卷，观测台按运行号与序号读；旧篇用共用的 `篇式` 解析；嘱咐、打断、停止是 `<篇>。令。嘱咐` 等三个标记。

## 用法

```text
揽辔台 [篇路径]
```

篇路径缺省为当前目录的 `会话。会话。豫`。先在终端里起后台：

```text
捉刀 会话。会话。豫 --台
```

再开观测台窗口。窗口里可输入嘱咐、点“打断”或“停止”；后台见到标记后照办。

这三个按钮各有等价的壳命令（库「诏令」），在壳里下命令与点按钮效果相同：

```text
「嘱捉刀」于「篇」曰『会话。会话。豫』于「话」曰『接着改』
「辍捉刀」于「篇」曰『会话。会话。豫』
「罢捉刀」于「篇」曰『会话。会话。豫』
```

## 组成

- `模`：状态、会话解析、事件收取、定时重读、控制标记。
- `视`：门面界面。
- `入口`：窗口主循环与参数。

## 构建与运行

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。林檎。豫行 -j 24
./揽辔台。林檎。豫行 会话。会话。豫
```

后台另开一个终端：

```sh
DEEPSEEK_API_KEY=... ./捉刀。林檎。豫行 会话。会话。豫 --台
```

观测台每 100 毫秒读一次 `<篇>。观。今` 指针与新事件，按运行号与序号收；旧篇用 `篇式` 解析。输入区的“发送”写 `<篇>。令。嘱咐`，“打断”写 `<篇>。令。打断`，“停止”写 `<篇>。令。停止`；后台见到标记后照办。

## 观测内容

- 用户、模型、思考、命令、回执、错误六种卡片；模型消息走共用的 Markdown 预览，命令与回执等宽。
- 状态、模型名、当前命令、本场命中/未中/输出词元与纳美元。
- 错误用朱色标出；后台的 401、篇式错误、超时都会进错误卡。
- 卡片新在前：最新的流与回执在最上面，不必等滚动。

## 名帖与图标

`名帖。数据。豫` 给启动台与市肆用：显示名“揽辔观测台”、类别“开发”、提要“实时看捉刀（编程智能体）会话，可嘱咐、打断与停止。”，图标指向 `图标。设计。豫`。图标照徽识的画法：二十四格视框，圆角画框填纸色、描墨色，框里一道两弯的缰绳，右上角一轮朱色小点。

## 测试

```sh
./豫构。林檎。豫行 运行 应用/机智坊/揽辔台/测试/状态。测试。豫
```

覆盖旧篇解析、事件收取（就绪、模型片、用量、篇改）、视图生成与控制标记。

## 待办事项

- 旧篇解析在每次“篇已改”时重析全篇；篇很大时可改为只析新增段。
- 卡片暂不能折叠；命令回执很长时占屏。云平台的折叠命令卡留待后续版本。
- 自动滚到末：现在用“新在前”绕开；要正序阅读时，需在 `门面` 的滚动区加“跟随末尾”属性（提案 00018 的缺口）。

## 在豫言操作系统里

```sh
./豫构。林檎。豫行 构建 揽辔台 --输出 揽辔台。豫行 -j 24 -- --目标系统 豫言
```

把 `揽辔台。豫行` 放进桌面的授权根（如 `/工具` 或造盘时的工具目录），在文件浏览器里选中运行，它就在一个外部程序格里开窗；后台仍在终端里跑 `捉刀 篇路径 --台`。窗口要的显示面由外部程序格转授，输入与尺寸也由它转交。
