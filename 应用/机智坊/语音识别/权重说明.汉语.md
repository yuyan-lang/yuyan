# 语音权重

`权重。豫` 读取 GGUF 二版、三版容器，要求 `general.architecture` 为 `whisper`。前端将模型文件字节串交给 `解析语音模型头` 与 `读取语音权重`。后者返回按字符串名字取得小数数组的缓存函数。

张量名沿用 [Whisper 原版模型](https://github.com/openai/whisper/blob/main/whisper/model.py) 与 [whisper.cpp 张量名表](https://github.com/ggml-org/whisper.cpp/blob/master/src/whisper-arch.h)：卷积为 `encoder.conv1.weight`、`encoder.conv2.weight`，位置为 `encoder.positional_embedding`，层权重为 `encoder.blocks.N.attn.*`、`encoder.blocks.N.attn_ln.*`、`encoder.blocks.N.mlp_ln.*`、`encoder.blocks.N.mlp.0.*`、`encoder.blocks.N.mlp.2.*`。解码器沿用对应 `decoder.*`、`cross_attn.*` 与 `token_embedding.weight`。

`语音权重形状` 返回最外维在前的整数列表；GGUF 文件里的 `ne` 已由张量格式库倒序。卷积形状为 `[输出道,输入道,核宽]`，线性权重为 `[输出维,输入维]`，位置为 `[上下文,状态维]`。展开数组最内维连续。偏置可按元素总数读取。每个名字首次取得时解码，随后返回同一数组。

载荷类型支持 F32、F16、BF16、Q4_0、Q4_1、Q5_0、Q5_1、Q8_0；量化解码复用数值类型库。头部、名字与载荷边界均由实际 GGUF 信息读取。其他 GGML 类型列为后续事项。whisper.cpp 官方转换工具产生的 GGML 文件列为后续格式事项；当前消费者输入为按上述名字与架构标记保存的 GGUF。
