# 比部（对象存储长跑核账程序）

通称对象存储长跑核账程序（object store long-run auditor）。此比部者，提案〇〇〇五四《九府》完成判据所用之核账程序也：于第四台机上恒对存储写、读、删、改，以每一已确认之事书于续书之账，末乃逐条勾之，量其可用之率与最长中断。事皆经九府守藏（库术）而行，故内府、邸阁（S3 之议）与金匮三库皆可试。

名取《唐六典》卷六“比部郎中、员外郎掌句诸司百寮俸料、公廨、赃赎、调敛、徒役课程、逋悬数物，以周知内外之经费而总勾之”：比部者，唐勾覆内外经费之司也；此程勾覆藏中之一物一事。二子命：长跑写核曰巡，末之逐条勾对曰总勾。

## 构建与起法

```
豫构 构建 比部 --输出 比部。林檎。豫行
./比部。林檎。豫行 总勾 --配置 … --前缀 … --账 …
```

（林纳之上以 `比部。林纳。豫行` 为输出之名。）

## 配置

配置为一纸数据之文 `比部。数据。豫`，与九府台同形：顶为「九府」一节，中有 `库`（`类`、`桶`、`凭据`）与 `数据目录`。数据目录即金匮之根：内府适配之 `内府。数据。豫` 与虎符皆在其下；凭据书相对之径，按数据目录而算。数据目录阙则取府署之默目（豫言之土为 `/系统/九府`，宿主为家下之 `.豫言/九府`）。

样例（包中之 `比部。数据。豫`）用金匮：

```yuyan
「九府」者「典」
　【「库」者「典」
　　　【「类」者『金匮』也，「桶」者『jiufu』也，「凭据」者『对象存储。数据。豫』也】也
　】
也。
```

试内府则改「类」为『内府』，并于数据目录之下备 `内府。数据。豫`（地址们、虎符、超时）与虎符之卷；试邸阁则改为『邸阁』而备 S3 之凭据。库类、桶与凭据皆径用九府之府署、择库，比部不别立一套。

## 巡（长跑写核）

```
比部。林檎。豫行 巡 --配置 <径> --前缀 <键前缀> --账 <账径> --时长 <秒> [--间隔 <毫>] [--小 <字节>] [--大 <字节>]
```

- 单线程循环，至时长尽而止。
- **写**：键为 `<前缀><序>`，序自一而进，接旧账已用最大之序而下；正文按（前缀、序）定造：长由序于小大之间取，正文为沙二五六之链展，书为小写十六进之文。写物之选携 `sha256`，令内府台核其摘；答成之后乃书此笔于账。
- **读**：自已确认未删之键中随机抽一读回，按（前缀、序、读回之长）重算而校；不合记误。
- **删**：每十轮删最旧之已确认键。先书将删于账而强刷于盘，乃发删；答成乃书已删。如此则比部自崩于中道，总勾亦不以删而未记为失。
- **计**：计数之物为 `<前缀>计数`，其文为十进之数。读其值与摘，以 `ifMatch` 写加一；物不在则以 `ifNoneMatch` 写一。成则书新值于账；超时、误或屡冲算疑，书一疑，次轮重读而续。
- **列**：每一百轮且最大序未满万，列前缀下之键，条数少于应有则记疑。
- **中断与可用率**：每事记起止单调之毫与成败；中断自一成之后首败之起，至次成之止。可用率为一减中断之总除总时。
- 每分钟印摘要一行（轮数、成败、读误、疑数、延迟中位与九十九分位、今之最长中断），终印总表。

阙省之 `--间隔` 一千毫、`--小` 六十四、`--大` 二百五十六。

## 账之格式

账为续书之二进卷：一条先书八字节小端之长，次以籍册数据值之帛，分帧之法与内府载段同（长头与解长帛径用 `库/内府/载段` 之实现）。其类有六：

| 类 | 栏 | 义 |
| --- | --- | --- |
| 写成 | 键、序、长、起、止、摘 | 写成，摘为写后之本之摘要 |
| 将删 | 键、序、起、止 | 删前先书，并强刷于盘 |
| 已删 | 键、序、起、止 | 删成 |
| 计成 | 键、值、起、止、摘 | 计数写至之新值 |
| 疑 | 键、序、起、止、成、缘由 | 写败、计误或列不全等不决之事 |
| 起止 | 段、起、止、附 | 段为起或止，附栏携参数或统计 |

写成、将删、已删、计成、疑皆携起止单调之毫；写败亦书一疑（序大于零），故旧账知诸序之未尝写成者，续时视为空洞而跳之。记录先积于内存，每秒一刷；将删与起始之记别加强刷。开账之际末条若半，先截而去之乃续。账可跨巡而续，同前缀接序而下。

## 总勾（逐条勾对）

```
比部。林檎。豫行 总勾 --配置 <径> --前缀 <键前缀> --账 <账径>
```

读账而依前缀分其类，乃：

- 写成而未删（亦无将删）之键必读得出，正文按（前缀、序、长）重算而合；读不得记失，不合记文误。
- 已删之键必不在；犹在记删后仍在。
- 惟有将删、未有已删者，在否皆算对。
- 计数：已确认之值（计成记中之值）互不重、严相增；自藏读末值，末值不得小于已确认之最大，亦不得大于最大加疑之数。

印账中之笔数、失、文误、删后仍在与计数之违之清单（各列前二十）与总数；皆合则退码零，否则一。

## 长跑之建议设法

- 间隔取一千毫（二十四时约八万六千轮）；欲速见其病可取一百至二百毫。
- 正文小取六十四、大取四千零九十六；一轮所写在二者之间。
- 内府适配之「超时」于 `内府。数据。豫` 设五千毫；长跑之际余裕足，而一次超时亦不至久卡。
- 账置于与对象存储异盘或异机之处；账径之盘按每轮百余字节估之（八万六千轮约十兆）。
- 三台节点依完成判据每十分钟随机杀、重起或断网一台；此时巡记其败与疑，可用率与最长中断照实印之，跑毕总勾当零失、零文误、零删后仍在、零计数之违。

## 故障时之行为

- 对象存储一时不通：写败记疑而进序、以序入空洞；读败记读误；删败记疑而进删游（惟有待删之键，总勾算对）；计败记疑，次轮重读而续。皆不中断巡，中断之数照实积之。
- 比部自崩：账中至多失最后一秒之记，其为「未记之成」，不致误报；末条半截于次开账时截之。
- 起不得（配置不读、库类不认、凭据或内府配置不在）：印一行其由而退码一。
