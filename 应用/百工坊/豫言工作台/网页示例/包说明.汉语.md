# 豫言工作台网页示例

豫言工作台的浏览器示例：几份内存里的示例文件当文件服务，经[工作台网页](../../../../库/书斋/网页/包说明.汉语.md)的「运行网页工作台」在页面里浏览、打开、编辑与保存。它是「豫言工作台」的子包。

## 内容

- `入口。豫`：示例文件（说明、一个带包描述与双语说明的示例包、笔记）放在一个引用里；「内存列目录」「内存读文本」组成「浏览服务」，「内存写文本」「内存改名」「内存删除」改这个引用。入口在 ID 为 `工作台容器` 的元素里运行工作台，打开 `示例/入口。豫`。
- `页面.html`：撑满视口的容器与浏览器宿主的启动脚本。

## 构建与运行

在仓库根目录：

```sh
./yy豫构.exe 发行 浏览器 应用/百工坊/豫言工作台/网页示例 dist/豫言工作台网页示例 --包根 库 --编译器 ./yy4_bs.exe
cp 应用/百工坊/豫言工作台/网页示例/页面.html dist/豫言工作台网页示例/index.html
```

再用任一静态文件服务伺服 `dist/豫言工作台网页示例`，例如本仓的简易网页服务器：在该目录运行 `node <仓库根>/豫言操作系统/宿主/节点/宿主.cjs <路径>/yy简易网页服务器.wasm --本机 18731`，用支持 WasmGC 与 JSPI 的浏览器打开 `http://127.0.0.1:18731/`。
