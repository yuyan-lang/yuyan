# 装帧工具

装帧方面由表生文之诸具。今有属性常量之生：读 `装帧谱/属性词表。豫` 之词元与例外、`装帧谱/属表。豫` 之层叠属表与 `装帧/属性号。豫` 之号，一举出 `装帧/属性常量。豫` 与 `装帧谱/属性常名。豫` 二篇。

## 用法

于仓根行之：

```
豫构 构建 装帧工具 --输出 属性常量生成。林檎。豫行
./属性常量生成。林檎。豫行 .
```

其参为仓根。器依仓根与各产物所在之包，分书二篇于 `库/群书/网页部/装帧/属性常量。豫` 与 `库/群书/网页部/装帧谱/属性常名。豫`，一举而二篇各得其所；仓根之下不得属性词表或属性号，则告祸而退。生成之物入库；词表、属表有改则重跑一次。
