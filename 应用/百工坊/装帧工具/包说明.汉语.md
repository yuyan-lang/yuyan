# 装帧工具

装帧方面由表生代码的诸工具。眼下有属性常量生成器：读 `装帧谱/属性词表。豫` 的词元与例外、`装帧谱/属表。豫` 的层叠属表与 `装帧/属性号。豫` 的号，一次产出 `装帧/属性常量。豫` 与 `装帧谱/属性常名。豫` 两篇。

## 怎么用

在仓库根目录运行：

```
豫构 构建 装帧工具 --输出 属性常量生成。林檎。豫行
./属性常量生成。林檎。豫行 .
```

参数是仓库根（`仓根`）。工具按仓根与各产物所在的包，把两篇分别写到 `库/群书/网页部/装帧/属性常量。豫` 与 `库/群书/网页部/装帧谱/属性常名。豫`；仓根下找不到属性词表或属性号时报错退出。生成物入库；改了词表或属表就重跑一次。
