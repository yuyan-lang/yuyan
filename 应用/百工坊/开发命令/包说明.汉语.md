# 开发命令

程序「开发」：经 ssh 在豫言操作系统里开发豫言时用的文本与文件工具。豫言操作系统里装在 `/工具/开发。豫行`；系统壳里有同名的壳命令（「寻」「寻文字」「寻卷」「读行」「替换」「全易」「差异」「文件信息」「沙二五六」「索书」「解档」），带标签的参数照壳命令的写法，由它们运行本程序。

## 子命令

| 子命令 | 参数 | 作用 |
| --- | --- | --- |
| 搜索 | 正则 路径 [上限] | 逐行按正则搜索文件或目录，印“路径:行号:行” |
| 搜索文字 | 文字 路径 [上限] | 同上，按字面文字搜索 |
| 找文件 | 通配 路径 [上限] | 按名字通配找普通文件；模式含 `/` 时按相对路径匹配，`**` 跨目录 |
| 读行 | 文件 起 止 | 印第 起 到 止 行，带右对齐的行号；止为 0 时印到末尾 |
| 替换 | 文件 旧 新 | 把唯一的一处 旧 换成 新；找不到或出现多次就报错，文件不动 |
| 全部替换 | 文件 旧 新 | 把每一处 旧 换成 新 |
| 差异 | 旧文件 新文件 | 统一格式差异，上下文三行；两份相同时印“无差异” |
| 文件信息 | 路径… | 目录的项数；普通文件的大小、文本或二进制、行数；修改时间（协调世界时） |
| 沙二五六 | 文件… | 沙256 散列，格式同 sha256sum |
| 下载 | 网址 文件 | 经 HTTP 或 HTTPS 下载（跟随转向） |
| 解档 | 档 目录 | 解开 `.tar`、`.tar.gz`、`.tgz`、`.zip` |
| 后台运行 | 程序 参数… | 把程序交给远程登录进程在后台运行（不随 ssh 会话结束），印作业编号 |
| 作业列表 | | 每个作业一行：编号、状态、命令、开始时刻 |
| 作业输出 | 号 | 作业到目前为止的全部输出 |
| 等待作业 | 号 [超时秒] | 边等边印新输出，作业结束后以它的退出码退出；超时退出码 124 |
| 终止作业 | 号 | 打断作业（豫言操作系统里连同子孙） |

遍历目录时跳过以点开头的名字（`.git`、`.豫构缓存` 等），目录项按字节序排列，输出次序固定；前八千字节有零字节的文件当二进制文件，搜索时跳过。搜索与找文件缺省至多印 5000 处，第三个参数可以改。出错时错误信息印到标准错误，退出码 1；参数不够时印用法，退出码 2。

## 后台作业

作业目录在豫言操作系统里是 `/系统/作业`，宿主上是 `~/.豫言作业`。每个作业一个十进制编号的子目录：`请求。数据。豫`（程序、参数们、目录、提交时刻，由本程序写）、`状态。数据。豫`（状态、任务号、开始、结束、退出码，由远程登录写）、`日志/` 下按序号命名的输出段与 `待终止` 标记。远程登录进程每半秒扫一次作业目录，起作业时切到请求里的目录、环境取 `.环境`，输出攒满 64 KiB 或每隔一秒写一段。远程登录重启时，上一个进程留下的“运行中”作业标成“中断”。等待用的小睡是在一个空闲的本机端口上带超时等待。

## 构建

`豫构 构建 开发命令 -j 24` 出本机程序；`豫构 构建 开发命令 --输出 开发。豫行 -j 24 -- --目标 本机 --目标系统 豫言 --执行器 执行器。树码` 出豫行文件。造盘时随工具链放进 `/工具/开发。豫行`。

## 后续版本的事项

解档还不保留可执行位、符号链接与空目录；文件信息为了取大小会读整个文件；正则搜索逐行把字节转成字符串再匹配。
