# 开发命令

程序「开发」：经 ssh 在豫言操作系统里开发豫言时用的文本与文件工具。豫言操作系统里装在 `/工具/开发。豫行`；系统壳里有同名的壳命令（「寻」「寻文字」「寻详」「寻文字详」「寻卷」「读行」「读行宽」「计行」「读字节」「替换」「全易」「依律易」「取栏」「依隔取栏」「筛行取栏」「差异」「文件信息」「沙二五六」「索书」「解档」「打包」），带标签的参数照壳命令的写法，由它们运行本程序。

## 子命令

| 子命令 | 参数 | 作用 |
| --- | --- | --- |
| 搜索 | 正则 路径 [上限] [方式] [宽] [限…] | 逐行按正则搜索文件或目录，印“路径:行号:行” |
| 搜索文字 | 文字 路径 [上限] [方式] [宽] [限…] | 同上，按字面文字搜索 |
| 找文件 | 通配 路径 [上限] [至多] [至少] [改于后] [改于前] | 按名字通配找普通文件；模式含 `/` 时按相对路径匹配，`**` 跨目录；至多至少按字节数筛（大小取自文件状态，不读正文），改于后前按修改时刻筛（协调世界时，写法同年-月-日 [时:分[:秒]]），空串为不限，四个条件可同时用 |
| 读行 | 文件 起 止 [宽] | 印第 起 到 止 行，带右对齐的行号；止为 0 时印到末尾 |
| 计行 | 文件… | 每个文件一行：行数与路径，同 `wc -l`；按六十四千字节一块流式数到卷末，大文件也照数，内存不随文件大小增长 |
| 读字节 | 文件 起 长 | 从 起 处取 长 个字节，按十进制印成一行，同 `od -An -tu1` |
| 替换 | 文件 旧 新 | 把唯一的一处 旧 换成 新；找不到或出现多次就报错，文件不动 |
| 全部替换 | 文件 旧 新 | 把每一处 旧 换成 新 |
| 正则替换 | 文件 式 模 | 按正则把每一处匹配换成模板；模板可写 `$&`、`$1` 至 `$99` 与 `$<名>` 引用捕获，`$$` 是一个 `$`；整篇当作一段，`.` 不跨行，跨行写 `[\s\S]`；印替换了几处，没有匹配不算错 |
| 取栏 | 文件 栏 分隔符 筛栏 筛文 | 逐行按分隔符取栏：栏如 `1,3`，分隔符写空为制表符，筛栏为 0 时不筛，栏号超出该行的栏时印空串 |
| 差异 | 旧文件 新文件 | 统一格式差异，上下文三行；两份相同时印“无差异” |
| 文件信息 | 路径… | 目录的项数；普通文件的大小、文本或二进制、行数；修改时间（协调世界时）。大小与修改时间取自文件状态，只读开头八千字节判文本还是二进制，文本按六十四千字节一块数行；超过六十四兆字节的文本文件不数行，行数印“—” |
| 沙二五六 | 文件… | 沙256 散列，格式同 sha256sum；按一兆字节一块读，边读边算，内存不随文件大小增长 |
| 下载 | 网址 文件 | 经 HTTP 或 HTTPS 下载（跟随转向） |
| 解档 | 档 目录 | 解开 `.tar`、`.tar.gz`、`.tgz`、`.zip`；目录不存在时先建出；前三种边解边写盘，内存不随成员大小增长，`.zip` 仍整份读入，超出解压上限时报“文件太大” |
| 打包 | 档 目录 | 把目录的整棵子树打成 `.tar`、`.tar.gz`、`.tgz`，条目路径相对目录（同 `tar -C 目录 .`）；目录按类型 5 写入，普通文件按类型 0，可执行文件权限 493、其余 420；符号链接与特殊文件跳过并计数，以点开头的名字不入档 |
| 后台运行 | 程序 参数… | 把程序交给远程登录进程（宿主上是行在）在后台运行（不随会话结束），印作业编号；请求里带上本进程的环境（壳经「行」起开发时已并进「设」的变量），宿主的行在照它起作业 |
| 作业列表 | | 每个作业一行：编号、状态、命令、开始时刻 |
| 作业输出 | 号 | 作业到目前为止的全部输出 |
| 等待作业 | 号 [超时秒] | 边等边印新输出，作业结束后以它的退出码退出；超时退出码 124；“没有作业”“（作业 N 结束，退出码 X）”“（等了 N 秒……还在运行）”印到标准错误，标准输出只有作业自己的输出 |
| 终止作业 | 号 | 打断作业（豫言操作系统里连同子孙），等它真正结束（至多十秒）再印“已终止作业 N（退出码 X）”；已经结束的作业只印退出码；十秒后仍在运行时退出码 1 |

搜索与搜索文字的方式是 `行`（默认，印“路径:行号:行”）、`只列`（每个含匹配的文件印一行路径，同 `grep -l`）、`计数`（每个含匹配的文件印一行“次数<TAB>路径”，次数多的在前，同 `grep -c` 再按次数排）、`反向`（印不匹配的行，同 `grep -v`）、`只取`（每条匹配印一行“路径:行号:匹配”，同 `grep -o`）、`当文`（把二进制文件也当文本搜，匹配行照 `行` 印，控制字节（制表除外）与一百二十七写成 `\xNN`，同 `grep -a`）。`宽` 大于零时把每行（或每条匹配）截到前若干字，按字数不按字节，同 `cut -c`。`限` 是文件基名的通配，可给多个，任一相合就算（如 `*。豫`、`*.mjs`），同 `grep --include`。读行的 `宽` 同样截每行。

遍历目录时跳过以点开头的名字（`.git`、`.豫构缓存` 等），目录项按字节序排列，输出次序固定；前八千字节有零字节的文件当二进制文件：不用 `当文` 时，有匹配只印一行“二进制文件 路径 有匹配”（同 `grep`），`计数` 照常计数、`只列` 照常列名。搜索与找文件缺省至多印 5000 处（计数的上限缺省不限），第三个参数可以改。出错时错误信息印到标准错误，退出码 1；参数不够时印用法，退出码 2。要求路径存在而它不在附庸表（挂载表）里时，报“不在附庸表里”并提示环境变量 `豫言附`、`豫言全宿主`（2026-10-20，议题 150）。

## 后台作业

作业目录在豫言操作系统里是 `/系统/作业`。宿主上加入了行在的会话里也是 `/系统/作业`（附庸表把它对到私有根，行在在那里扫；2026-10-23，议题 445），没加入行在时是 `~/.豫言作业`（照旧写下请求，没有谁来起）。每个作业一个十进制编号的子目录：`请求。数据。豫`（程序、参数们、目录、环境、提交时刻，由本程序写；环境是本进程的“名=值”列）、`状态。数据。豫`（状态、任务号、开始、结束、退出码，由起作业的一方写）、`日志/` 下按序号命名的输出段与 `待终止` 标记。远程登录进程每半秒扫一次作业目录，起作业时切到请求里的目录、环境取 `.环境`，输出攒满 64 KiB 或每隔一秒写一段。远程登录重启时，上一个进程留下的“运行中”作业标成“中断”。宿主上的行在照同一套目录与协议办：每半秒扫一次私有根的 `/系统/作业`，起作业时切到请求里的目录，环境取请求里带来的环境（旧请求没带时取行在的；都去掉附庸表、另设 `豫言行在目录`，议题 541），输出按同样的段数写，行在重启时同样标“中断”（见 豫构 的 行在作业，宿主后台作业）。等待用的小睡是在一个空闲的本机端口上带超时等待。

## 构建

`豫构 构建 开发命令 -j 24` 出本机程序；`豫构 构建 开发命令 --输出 开发。豫行 -j 24 -- --目标 本机 --目标系统 豫言 --执行器 执行器。树码` 出豫行文件。造盘时随工具链放进 `/工具/开发。豫行`。

## 后续版本的事项

解档还不保留可执行位与符号链接，zip 的流式解压留待后续版本；打包不保留修改时间、属主与符号链接（权限只分可执行与不可执行两种）；正则搜索逐行把字节转成字符串再匹配。
