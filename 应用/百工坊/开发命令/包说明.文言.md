# 开发命令

「开发」之程：经 ssh 于豫言操作系统中开发豫言所用之文与文件诸器。豫言操作系统中装于 `/工具/开发。豫行`；系统壳有同名之壳命（「寻」「寻文字」「寻详」「寻文字详」「寻卷」「读行」「读行宽」「替换」「全易」「依律易」「取栏」「依隔取栏」「筛行取栏」「差异」「文件信息」「沙二五六」「索书」「解档」），带签之参依壳命之书法，由之行此程。

## 子命

| 子命 | 参 | 用 |
| --- | --- | --- |
| 搜索 | 正则 径 [上限] [式] [宽] [限…] | 逐行依正则搜文或目，印“径:行号:行” |
| 搜索文字 | 文 径 [上限] [式] [宽] [限…] | 同上，依字面之文 |
| 找文件 | 通配 径 [上限] | 依名通配求常文；模式含 `/` 则依相对之径，`**` 跨目 |
| 读行 | 文件 起 止 [宽] | 印第起至止行，带右齐之行号；止为零则至末 |
| 替换 | 文件 旧 新 | 易唯一之旧为新；不得或多现则告误，文不动 |
| 全部替换 | 文件 旧 新 | 尽易诸旧为新 |
| 正则替换 | 文件 式 模 | 依正则尽易合式之处为模；模可书 `$&`、`$1` 至 `$99`、`$<名>` 引其捕获，`$$` 为一 `$`；全篇为一段，点不越行，欲越行则书 `[\s\S]`；印所易之数，无合不为误 |
| 取栏 | 文件 栏 分隔符 筛栏 筛文 | 逐行依分隔取栏：栏如 `1,3`，分隔空为制表，筛栏零则不筛，号逾该行之栏则印空 |
| 差异 | 旧文 新文 | 统一式之差异，上下文三行；同则印“无差异” |
| 文件信息 | 径… | 目之项数；常文之大小、文本或二进制、行数；改时（协调世界时） |
| 沙二五六 | 文件… | 沙256 散列，式同 sha256sum |
| 下载 | 网址 文件 | 经 HTTP 或 HTTPS 下载（随转向） |
| 解档 | 档 目 | 解 `.tar`、`.tar.gz`、`.tgz`、`.zip` |
| 后台运行 | 程序 参… | 付程序于远程登录之程于后台行之（不随 ssh 会话而终），印作业之号 |
| 作业列表 | | 每作业一行：号、状、命、始时 |
| 作业输出 | 号 | 作业至今之全出 |
| 等待作业 | 号 [超时秒] | 且候且印新出，作业终则以其退码退；逾时退码一二四 |
| 终止作业 | 号 | 断作业（豫言操作系统中并其子孙） |

搜索与搜索文字之式为 `行`（默，印“径:行号:行”）、`只列`（凡含配之卷各印其径一行，同 `grep -l`）、`计数`（凡含配之卷各印“次数<TAB>径”一行，多者先，同 `grep -c` 复依次数排）、`反向`（印不配之行，同 `grep -v`）、`只取`（每配印“径:行号:配”一行，同 `grep -o`）。`宽` 大于零则每行（或每配）截其前若干字，依字数不依字节，同 `cut -c`。`限` 为卷名之通配，可多，任一合则可（如 `*。豫`、`*.mjs`），同 `grep --include`。读行之 `宽` 亦截每行。

遍目则略以点起之名（`.git`、`.豫构缓存` 等），目项依字节之序，所出之次有定；首八千字节有零字节者以为二进制，搜则略之。搜索与找文件默至多印五千处（计数之限默不限），第三参可易之。有误则书其辞于标准误，退码一；参不足则印用法，退码二。

## 后台作业

作业之目于豫言操作系统中为 `/系统/作业`，宿主上为 `~/.豫言作业`。每作业一以十进之号为名之子目：`请求。数据。豫`（程序、参数们、目录、提交时刻，此程书之）、`状态。数据。豫`（状态、任务号、开始、结束、退出码，远程登录书之）、`日志/` 下依序号为名之出段与 `待终止` 之标。远程登录之程每半秒一察作业之目，起作业则切至请中之目、环境取 `.环境`，出满六十四千字节或每一秒书一段。远程登录重启，前程所遗“运行中”之作业标为“中断”。候所用之小寐，乃于一闲本机端口带时限候之。

## 构建

`豫构 构建 开发命令 -j 24` 出本机之程；`豫构 构建 开发命令 --输出 开发。豫行 -j 24 -- --目标 本机 --目标系统 豫言 --执行器 执行器。树码` 出豫行之文。造盘时随工具链置于 `/工具/开发。豫行`。

## 后续版本之事

解档尚不存可执行之位、符号链接与空目；文件信息取大小则尽读其文；正则搜索逐行以字节易串而配之。
