# 驿启（网启服务）

驿启是一台林纳或林檎机上的网络启动服务：同一局域网里的真机按 PXE 开机，先由路由器经动态主机配置（DHCP）发出地址，再由驿启补上引导服务器地址与引导文件名；固件随后经简单文件传送（TFTP）取引导文件，并按块取整份启动盘映像，拼成内存盘交给豫言内核。

## 用法

```
驿启 --目录 <启动介质> --本址 <本机 IPv4>
```

`--目录` 指向造盘产出的 `启动介质` 目录。`--本址` 是本机在局域网里的 IPv4 地址，写进代理答复的服务器地址与引导文件名字段。

另有一项只给测试用的 `--口移 <数>`：动态主机配置的两个口（六十七与四千零一十一）与文件传送的口（六十九）各加这个数，免得测试要管理员权限。

## 代理动态主机配置

听六十七与四千零一十一两个口，只答带 `PXEClient` 厂商标识的请求。按客户机架构选项给引导文件名：零给 `网启。零`，七与九给 `EFI/BOOT/BOOTX64.EFI`，其余架构不答。答复里不发地址（`yiaddr` 为零），服务器地址填 `--本址`，并给出引导服务器名、引导文件名、厂商标识与 `PXE_DISCOVERY_CONTROL` 为八的厂商选项。六十七口上的答复发广播，四千零一十一口上的答复单播回来源。

## 文件传送

听六十九口，每个传送另开一个临时口。文件名只认三种：

- `网启。零` 与 `EFI/BOOT/BOOTX64.EFI`，取自 `--目录/网启/` 下的同名文件；
- `豫言启动。块<序号>`，按序号从 `--目录/豫言启动.iso` 里现切十六兆字节一块，序号逐位写汉字数字，如 `豫言启动。块九二`；末块可以不满，序号越界答“文件不存在”。

支持块长（`blksize`，以太网上至一千四百六十八字节）、传送总长（`tsize`）与窗口大小（`windowsize`）三项选项，读操作为主，超时重传。别的文件名答“文件不存在”。

## 约定

每答一次代理动态主机配置、每传完一个文件，都在标准输出印一行。
