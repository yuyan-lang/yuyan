# 驿启（网启服务）

驿启者，林纳、林檎之上代客问津之驿也。同局之真机以网启（PXE）开机，先受址于路由之籍，驿启乃补告引导之服务器与引导之文名；固件次以简文传送（TFTP）取引导之文，复按块取整盘之影像，拼为内存之盘而授于豫言之核。

## 用法

```
驿启 --目录 <启动介质> --本址 <本机 IPv4>
```

`--目录` 指造盘所出 `启动介质` 之目。`--本址` 为本机在局中之四版址，书于代答之服务器址与引导文名之栏。

别有 `--口移 <数>` 一项，惟测试用之：籍问之二口（六十七与四千零一十一）与传文之口（六十九）各加此数，俾测试不必请于有司。

## 代答籍问

听六十七与四千零一十一之二口，惟答携 `PXEClient` 厂商标识之请。依客机架构之选项授引导文名：零则 `网启。零`，七与九则 `EFI/BOOT/BOOTX64.EFI`，余者不答。答中不发址（`yiaddr` 为零），服务器之址填 `--本址`，并授引导服务器之名、引导文之名、厂商标识与 `PXE_DISCOVERY_CONTROL` 为八之厂商选项。六十七口之答发为广播，四千零一十一口之答单播还于来所。

## 传文

听六十九口，每传另开一口。文名惟认三种：

- `网启。零` 与 `EFI/BOOT/BOOTX64.EFI`，取于 `--目录/网启/` 下同名之文；
- `豫言启动。块<序>`，依序自 `--目录/豫言启动.iso` 现切十六兆为一块，序逐位书汉字之数，如 `豫言启动。块九二`；末块可不满，序越界则答“文件不存在”。

所助者三：块长（`blksize`，以太之上至千四百六十八字节）、传送之总长（`tsize`）与窗之大小（`windowsize`）；所行皆读，逾时则重传。他名皆答“文件不存在”。

## 约

每答一籍问、每传毕一文，皆书一行于常出。
