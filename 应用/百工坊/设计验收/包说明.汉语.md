# 设计验收

`声音公共探针。豫` 直接导入公共声音输出接口，排入零点一秒静音，检查设备播放位置、延迟与关闭后失效。林纳与轩窗的原生发行保留执行器提供的公共接口，林檎原生发行使用林檎声音适配。探针构建时使用当前源码生成的执行器树码。

同一入口在原生、诺驿和浏览器执行，打印三十秒动画按每秒三十帧求值的完整显示表、十个动画段各一帧的完整像素，以及四秒有声样例全部波形字节。输出采用可以还原的十六进制表示；小数沿用设计树码的八字节位型。各端输出逐字比较可以复核提案 00018 前两期的一致性验收。

原生构建：`豫构 构建 设计验收 --输出 设计验收。林檎。豫行 -j 24`。诺驿构建：`豫构 构建 设计验收 --输出 设计验收.wasm -j 24`。浏览器构建：`豫构 发行 浏览器 应用/百工坊/设计验收 设计浏览器 --包根 库 --包根 豫言操作系统/适配`，配合同仓宿主的 `设计。测试页.html` 收集输出。

预置以豫言字符串保存设计树码，含字形与采样素材。入口先解码同一预置，再求值、渲染、混音。更新源样例后，在仓库根构建并运行 `准备。脚本。豫`，重新生成 `动画预置。豫` 和 `声音预置。豫`；两份源数据随验收程序登记。

原生实际输出保存为 `原生基线.txt`，复制到浏览器产物目录；`设计。测试页.html` 加载该文件，逐字符比较浏览器实际输出，显示总字符数、差异数和首个差异位置。诺驿实际输出与原生基线用 `cmp` 比较。完整显示表包含几何坐标、颜料、图像字节与仿射、不透明度、图层子项、遮罩、全部效果参数及混合模式。源节点中仅供编辑的声明属性另行由树码往返测试覆盖。

`官网。豫` 是提案 00018 第三期“官网静态页编成设计作品后排版一致”的验收入口：把镜像在本地的官网页面（地址前缀 `https://yuyan-lang.org` 映射到镜像目录，目录地址取 `index.html`）经网页载入与系统字体排版，编成设计作品，设计树码往返后由设计引擎重绘，与网页引擎的页面图比较。通道差大于 64 的像素（错位）不超过 0.1% 记为排版一致，通道差大于 2 的像素（两边展平曲线份数不同带来的抗锯齿差）另列；设计文件、重绘图与页面图写进输出目录。构建：`豫构 构建 设计验收 官网 --输出 官网验收。林檎。豫行 -j 24`；运行：`./官网验收。林檎。豫行 镜像目录 输出目录 [单页路径]`。三十二位程序的堆是四吉字节，整页文字多时一页一个进程。
