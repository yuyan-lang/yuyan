# 差遣差分

提案 00073 第七节第 3 条、进度 1-19 的差分与浸泡驱动。只编不跑；实跑在 pit-mac 合验里做。

## 差分

```
差遣差分
```

按批次跑 `库/豫章/测试/异步/` 下的差遣测试：单核懒关为基线，逐项再跑多核懒关、单核懒开、多核懒开，比对退出码、标准输出、标准错误。每项印“同”或“不同”；有一项不同，退出码为一。

配置：

- 单核懒关：删 `豫言多核差遣`、`豫言差遣懒开`；
- 多核懒关：叠 `豫言多核差遣=开`；
- 单核懒开：叠 `豫言差遣懒开=开`；
- 多核懒开：两者都叠。

批次现为 `均输队`、`均输睡签`、`差遣多核`、`差遣子役`、`差遣懒开`；改批次改 `批径们`。

## 浸泡

```
差遣差分 --轮数 10
差遣差分 --时长 600
```

带轮数或时长时反复跑同一批，每轮印轮次、用时与不同数；出错即停。常驻内存目前印“待接”，子进程峰值常驻已在每子进程收跑时用 `使者` 问，尚未汇总成每轮一行；`观役` 口径的直接读数待接。

## 待办

- 每轮常驻内存汇总待接；子进程峰值已有，尚未并成每轮一行。
- 批次测试若在单核基线本就失败，差分仍会逐项印“同/不同”，失败原因看子进程输出。
