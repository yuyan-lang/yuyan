# 差遣差分

议〇〇〇七三第七节第三条、进度一一九之差分与浸之驱。惟编不行；实跑于 pit-mac 合验。

## 差分

```
差遣差分
```

依批跑 `库/豫章/测试/异步/` 下之差遣诸试：单核懒关为基，逐项再跑多核懒关、单核懒开、多核懒开，较其退码、常出、误出。每项书“同”或“不同”；有一不同，退码一。

配置：

- 单核懒关：删 `豫言多核差遣`、`豫言差遣懒开`；
- 多核懒关：叠 `豫言多核差遣=开`；
- 单核懒开：叠 `豫言差遣懒开=开`；
- 多核懒开：二者皆叠。

批今为 `均输队`、`均输睡签`、`差遣多核`、`差遣子役`、`差遣懒开`；改批改 `批径们`。

## 浸

```
差遣差分 --轮数 10
差遣差分 --时长 600
```

带轮数或时长则反复跑同批，每轮书轮次、用时与不同数；有误即止。常驻内存今书“待接”，子程峰值常驻已于每子程收跑时以使者问，尚未汇为每轮一行；观役口径之直读待接。
