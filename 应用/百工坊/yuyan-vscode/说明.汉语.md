# 豫言编辑器树码接入

这是 VS Code 对编译器树码的接入说明。默认保存检查调用 Node 宿主运行 `编译器.wasm`；中间产物、语言服务和语义标记缓存都使用 `。树码`。

二进制编解码、编辑器资料转换和阶段文本显示由豫言编写的 `树码.wasm` 执行。插件调用 `显示` 打开只读的中间文本预览；包路径由对应包上下文还原。编辑器交换资料走进程标准输出，磁盘缓存只保存树码。

悬停与跳转定义的资料由 `豫构 语言服务 <源文件>` 取：豫构按所属包的包上下文调用译场的「讯储读径」，按旁记找到物库或本树缓存里的「语言服务」树码，读出后按编辑器树码解成结绳，印到标准输出；插件直接解析这一行。设置 `yuyan.buildToolCommand` 指定豫构程序，留空时依次找工作区根下的 `豫构。林檎。豫行`、`豫构。林纳。豫行`、`豫构。轩窗。豫行`，再退到 PATH 上的 `豫构`。

在项目根目录构建工具：`./豫构。林檎。豫行 构建 树码 --输出 树码.wasm -j 24`。

`npm run pretest` 检查插件编译、语法和资料接入；设 `豫言编辑器网汇根目录` 为已构建工具且运行「编辑器树码」测试的工作树，可进一步读取豫言生成的真实语言服务、语义标记二进制样本，验证 Wasm 与插件互操作。
