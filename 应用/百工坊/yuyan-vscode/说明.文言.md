# 豫言编辑器树码之接

此 VS Code 接编译器树码之说明也。保存之常验，以 Node 宿主行 `编译器.wasm`；中间之产、语言服务及语义标记缓存皆用树码。

二进制编解、编辑器资料转换及阶段豫文之显，皆由豫言所作 `树码.wasm` 行之。插件以 `显示` 开只读中间豫文；包径依其包上下文复之。编辑器交换之资循进程标准输出，卷上缓存惟存树码。

悬停与定义跳转之资由 `豫构 语言服务 <源文>` 取：豫构依所属包之包境呼译场之「讯储读径」，依旁记求物库或本树缓中之「语言服务」树码，读毕依编辑器树码解为结绳，印于标准出；插件径析此行。设 `yuyan.buildToolCommand` 指豫构之程，空则依次求工作区根下之 `豫构。林檎。豫行`、`豫构。林纳。豫行`、`豫构。轩窗。豫行`，次退于 PATH 之 `豫构`。

于项目根构器：`./豫构。林檎。豫行 构建 树码 --输出 树码.wasm -j 24`。

`npm run pretest` 验插件之编、语法及资料之接；设 `豫言编辑器网汇根目录` 为已构器且行「编辑器树码」测试之工作树，则读豫言所成语言服务、语义标记之实二进制样本，验 Wasm 与插件互通。
