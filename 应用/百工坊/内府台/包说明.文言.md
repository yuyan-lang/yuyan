# 内府台（己之藏物之台）

雅称内府台（通称自己的对象存储服务程序）。此篇为提案 00064《内府》第一步之服务程：读配置、起服务、受请、回话。

## 起法

```
内府台。林檎。豫行 [配置之径]
```

配置之径省则取台之默径：豫言之土为 `/系统/内府/内府台。数据。豫`，宿主为家下之 `.豫言/内府/内府台。数据。豫`。

数据之目须按名授于程，写乃于回话之前同步于盘。**未授目录则内府台不得起**：告以中文之误（辞中书授权之法）而以退码一退——提案六四议五欲写必落盘而后回话，未授目则不能。

宿主上如此起之：

```
内府台。林檎。豫行 --授权目录写 内府=<数据目录> -- <配置之径>
```

豫言之土作常役而起（`--授权目录写` 一对与宿主同形，书于常役之参，执行器启时自认而去之）：

```
「登记常役」于「名」曰『内府』于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「重起」曰『常』
「起常役」于「名」曰『内府』
「常役态」于「名」曰『内府』
```

临时于前台一起（调试）用「行」，授权之写法同：

```
「行」于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「授权」曰「列」【（『内府=/系统/内府』）】
```

（壳之「行」若尚无授权之栏，则如常役书 `--授权目录写 内府=/系统/内府` 于参列；二法执行器皆认。）

## 配置

```yuyan
「内府台」者 「典」
　【「数据目录」者『/系统/内府』也
　，「地址」者『127.0.0.1』也
　，「端口」者「九零九一」也
　，「虎符」者『虎符』也
　，「桶们」者「列」【『jiufu』】也
　，「授权目录」者『内府』也
　】
也。
```

- `数据目录`：金匮之根与台之配置所在；缺则豫言之土为 `/系统/内府`，宿主为家下之 `.豫言/内府`。
- `地址`、`端口`：所听；端缺 9091。
- `虎符`：虎符牍之径；相对之径依数据之目算。其文惟自牍读，志不载之。
- `桶们`：所许之桶名单；不在名单者答“桶不在内府台的桶名单里”。
- `授权目录`：启时 `--授权目录写` 所用之名，缺缺 `内府`。

## 三副本

配置中更加一节「盟」，则此台按三副本而起；不书此节则仍为独台：

```yuyan
「盟」者 「典」
　【「本员号」者『甲』也
　，「员们」者「列」【
　　　「典」【「员号」者『甲』也，「地址」者『127.0.0.1』也，「端口」者「二一零零一」也】，
　　　「典」【「员号」者『乙』也，「地址」者『127.0.0.1』也，「端口」者「二一零零二」也】，
　　　「典」【「员号」者『丙』也，「地址」者『127.0.0.1』也，「端口」者「二一零零三」也】
　　】
　】
也。
```

- 本员依本员址之址与端听客与诸盟；`内府台` 一节之 `地址`、`端口` 于独台用之，三副本时以「盟」中本员那一条为准。
- 客与盟共一门。其故：配置中每员惟书一端，一台之上惟一门；门成先行合符，认后以首封之顶名别「请」与「信」，二路不相扰。另起一端则每员之配置多书一项、多开一门，又多守一听，不如共一门之省。
- 三台共一虎符（各台之 `虎符` 指同一牍或文同之牍）。
- 数据目下之 `盟态`、`载书` 为共识之固存：每发信之前先书二卷而同步于盘；重起则自此二卷复之。不可手改。

```yuyan
「登记常役」于「名」曰『内府甲』于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/数据/内府甲』），（『/数据/内府甲/内府台。数据。豫』）】于「重起」曰『常』
「起常役」于「名」曰『内府甲』
```

三台之常役各起一架，配置中数据之目与端各各不同。

## 故障时之行

- 客连非主之台：答非主而附所知主之址；适者改连（见「豫寓府库内府榫」）。
- 主之程被杀或断网：余台于选举超时（三百至六百毫）之后选新主；其间所至之写或改连新主，或于重试之限内重发。已答成之写皆过半落盘，不失。
- 一台重起：自其 `盟态` 与 `载书` 追上；未追上前非主，读答非主；追上之后如常与盟。重起用同一数据目、同一端。
- 二员并断、不足过半：写不成盟、读确认亦数不过半，客候至超时或重试之限，服务候余员归而后复；此过半之本分也。
- 载书或盟态坏、已行逾载书之数：起台时告中文之误而以退码一退，不带坏盘而行。
- 同步于盘不成：此步不往下行，程告误而退（不落之步不配发信、不配回话）。

## 停止

- 受「息」之请：答成而后止受新请，毕其手书、同步，收场而退。
- SIGTERM：执行器不接此信，程径终。每写皆于回话之前同步于盘、其书整份原子，故已回之写不亡，亦不留半写之状。

## 志

书为人读之文行，端曰 `内府台｜`：起时之址、桶之名单与落盘已授目录否；收场一行。虎符之文不入志。
