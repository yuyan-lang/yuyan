# 内府台（己之藏物之台）

雅称内府台（通称自己的对象存储服务程序）。此篇为提案 00064《内府》第一步之服务程：读配置、起服务、受请、回话。

## 起法

```
内府台。林檎。豫行 [配置之径]
```

配置之径省则取台之默径：豫言之土为 `/系统/内府/内府台。数据。豫`，宿主为家下之 `.豫言/内府/内府台。数据。豫`。

数据之目须按名授于程，写乃于回话之前同步于盘。**未授目录则内府台不得起**：告以中文之误（辞中书授权之法）而以退码一退——提案六四议五欲写必落盘而后回话，未授目则不能。

宿主上如此起之：

```
内府台。林檎。豫行 --授权目录写 内府=<数据目录> -- <配置之径>
```

豫言之土作常役而起（`--授权目录写` 一对与宿主同形，书于常役之参，执行器启时自认而去之）：

```
「登记常役」于「名」曰『内府』于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「重起」曰『常』
「起常役」于「名」曰『内府』
「常役态」于「名」曰『内府』
```

临时于前台一起（调试）用「行」，授权之写法同：

```
「行」于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「授权」曰「列」【（『内府=/系统/内府』）】
```

（壳之「行」若尚无授权之栏，则如常役书 `--授权目录写 内府=/系统/内府` 于参列；二法执行器皆认。）

## 配置

```yuyan
「内府台」者 「典」
　【「数据目录」者『/系统/内府』也
　，「地址」者『127.0.0.1』也
　，「端口」者「九零九一」也
　，「虎符」者『虎符』也
　，「桶们」者「列」【『jiufu』】也
　，「授权目录」者『内府』也
　】
也。
```

- `数据目录`：金匮之根与台之配置所在；缺则豫言之土为 `/系统/内府`，宿主为家下之 `.豫言/内府`。
- `地址`、`端口`：所听；端缺 9091。
- `虎符`：虎符牍之径；相对之径依数据之目算。其文惟自牍读，志不载之。
- `桶们`：所许之桶名单；不在名单者答“桶不在内府台的桶名单里”。
- `授权目录`：启时 `--授权目录写` 所用之名，缺缺 `内府`。

## 停止

- 受「息」之请：答成而后止受新请，毕其手书、同步，收场而退。
- SIGTERM：执行器不接此信，程径终。每写皆于回话之前同步于盘、其书整份原子，故已回之写不亡，亦不留半写之状。

## 志

书为人读之文行，端曰 `内府台｜`：起时之址、桶之名单与落盘已授目录否；收场一行。虎符之文不入志。
