# 内府台（自己的对象存储服务程序）

通称内府服务程序（own object storage service）。这是提案 00064《内府》第一步的服务程序：读配置、起服务、收请求、回话。

## 起法

```
内府台。林檎。豫行 [配置路径]
```

配置路径省略时取台默认径：豫言操作系统上是 `/系统/内府/内府台。数据。豫`，宿主上是家目录下的 `.豫言/内府/内府台。数据。豫`。

数据目录要按名授给程序，写才在回话之前同步到盘。**没授目录时内府台起不来**：报中文错误（写明授权办法）并以退出码一退出——提案 00064 议五要求写入落盘才回话，不授目录就做不到。

宿主上这样起：

```
内府台。林檎。豫行 --授权目录写 内府=<数据目录> -- <配置路径>
```

豫言操作系统上作常役起（`--授权目录写` 这一对与宿主上同形，写在常役的参数里，执行器启动时自行认去）：

```
「登记常役」于「名」曰『内府』于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「重起」曰『常』
「起常役」于「名」曰『内府』
「常役态」于「名」曰『内府』
```

临时在前台起一次（调试用）用「行」，授权写法相同：

```
「行」于「程序」曰『/系统/内府/内府台。豫行』于「参」曰「列」【『--授权目录写』，（『内府=/系统/内府』）】于「授权」曰「列」【（『内府=/系统/内府』）】
```

（壳的「行」若还没有单独的授权栏，就照常役那样把 `--授权目录写 内府=/系统/内府` 直接写进参数列；两种写法执行器都认。）

## 配置

```yuyan
「内府台」者 「典」
　【「数据目录」者『/系统/内府』也
　，「地址」者『127.0.0.1』也
　，「端口」者「九零九一」也
　，「虎符」者『虎符』也
　，「桶们」者「列」【『jiufu』】也
　，「授权目录」者『内府』也
　】
也。
```

- `数据目录`：金匮根与内府台配置所在；缺省豫言操作系统上 `/系统/内府`，宿主上家目录下的 `.豫言/内府`。
- `地址`、`端口`：监听；端口缺省 9091。
- `虎符`：虎符文件的路径；相对路径按数据目录算。虎符的内容只从文件读，日志不写。
- `桶们`：许用的桶名单；不在名单里的桶答“桶不在内府台的桶名单里”。
- `授权目录`：启动时 `--授权目录写` 用的名，缺省 `内府`。

## 停止

- 收到请求「息」：答成后停收新请求，办完手头的写、同步，收场退出。
- SIGTERM：执行器不接这个信号，进程直接结束。每次写都在回话之前同步到盘、写入本身整份原子，所以已回话的写不会丢，也不留半写的状态。

## 日志

写成人看的文字行，前缀 `内府台｜`：起时的地址、桶名单与落盘是否授了目录；收场一行。虎符的内容不进日志。
