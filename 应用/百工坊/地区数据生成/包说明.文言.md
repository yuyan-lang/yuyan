# 地区数据生成

通称地区数据生成（locale data generation）。此包者，化 CLDR 之结绳为随俗地区数据之器也。

用法：

```
地区数据生成 源根 出径 [类别]
```

`源根` 者，CLDR 数据之根也，其下有 `main/<地区>/` 与 `supplemental/`；`出径` 者，随俗之目也；`类别` 今有 `全部` 与 `复数`，不书则 `全部`。

此器惟取库所用之栏，书为数据子语言之篇 `名。数据。豫`，径入随俗。其生成有定：同一 CLDR 重行则得同一之篇，可随时重生，不必手改。

今之类别：

- 复数：读 `supplemental/plurals.json` 与 `supplemental/ordinals.json`，收零至六类之规，键书 `基数/one`、`序数/few`，值取 `@` 前之条件。

后续类别（数字、日期、相对时间、列表、语言与地区名、时区、地区协商）随随俗之模块而增。此器惟读任务书所定之 CLDR 目，不取于网。
