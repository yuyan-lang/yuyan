# 地区数据生成

字符串写出共用述文（字符串转义），统一保存换行、制表、结束引号与注释开头。

通称地区数据生成（locale data generation）。本包是把 CLDR 结绳（JSON）抽成随俗（本地化库）地区数据的可执行工具。

用法：

```
地区数据生成 源根 出径 [类别]
```

`源根` 是 CLDR 数据根目录，下面有 `main/<地区>/` 与 `supplemental/`；`出径` 是随俗包目录；`类别` 现在有 `全部`、`复数`、`协商`、`数字`、`日历`、`相对`、`列表`、`单位`、`译名`、`时区`、`时区偏移`、`字段名`、`诊断`，缺省为 `全部`。

工具只取库用到的字段，写成数据子语言文件 `名。数据。豫`，直接写进随俗包。数据文件先以 `数据形制` 的构造写法建条目，再由本工具排版成 `「列」【「条目」【…】…】` 的形式；生成是确定的，同一份 CLDR 重跑得到同一份文件，可以随时重生成而不必手改。

现在的类别：

- 复数：读 `supplemental/plurals.json` 与 `supplemental/ordinals.json`，收零至六类规则，键写 `基数/one`、`序数/few`，值取 `@` 之前的条件文本。

类别随随俗的模块陆续加入；`时区` 写时区别名表，`时区偏移` 读时宪的 TZif 数据树并写时区偏移表与时区缩写表，`字段名` 读 dateFields.json 写字段名表。工具只读任务书中给定的 CLDR 目录与时宪数据树，不从网络取数据，也不调用仓外脚本。
