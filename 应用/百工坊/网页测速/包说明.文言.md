# 网页测速

离线可复之浏览器性能之准也。一页及诸子资先录于「浏览久存」之资目，此后回放惟读其册、不涉于网，所量之数不随网速与机负而摇。分段报单调之微秒、CPU 之时（用户与内核分）、所配之字、读资之数与耗、常驻之峰，及豫言回收统计之分配总字与峰堆；别有滚动之准、一页一行之总命与二果逐段相较之具。

## 录

先联网录一页：

```
豫构 构建 网页测速 --输出 网页测速。林檎。豫行
./网页测速。林檎。豫行 录 github https://github.com/ 1280 800
```

录时采资之换为尺素之同步取驿址：主文、衣样、脚本、图像与字体皆经之取回，凡二零零之 GET 应连状、首部与解压后之正文录于资目（册为 `缓存。数据。豫`，体为 `缓存体/` 下之帛，与览者磁盘之藏同册）。录毕即以放之法复载一过而核：主文不成者、有资未录者皆报之而非零出，先补而后量。

录好之页居测速页根下，一页一目：

- 常根为 `/Users/zc/repos/yuyan-worktrees/豫言数据/网页数据/测速页`，环境 `豫言测速页` 可易；易机之时设此或同步此目。
- 每目别有 `页。数据。豫`，记名字、网址、视口之宽高、录时（纪元秒）、资数与总字。

`列` 印已录之页与其资数、总字。

## 量

```
./网页测速。林檎。豫行 量 github 3 0
```

`量` 起三子程，各载一页一过（放法，不网），取每段之小书为 `结果/github。数据。豫`；第四参为存名，可书 `量 github 3 0 改前` 而存为 `结果/改前。数据。豫`。子程所印段表十二：解析、预取、脚本、读样、样源、读记、盒树、量树、布局、成组、映列、栅格。每行六栏：段名、单调微秒、CPU 用户微秒、CPU 内核微秒、所配之字。别有 `测速误	脚本	<N>` 一行：此页脚本报诊断之处数（载、译、行被接者各算一处，脚本载里「网页脚本：地址：诊断」那条即之）。误出之页，其脚本段之微秒虽美，不足表脚本之果行——故别为一行，不与十二段混比。另有总量与读资（读回几件、合计几何）。父程别收子程常驻之峰，并自标准之误取豫言回收统计一行之分配总字与峰堆——欲此二数则带环境：

```
env 豫言回收统计=1 ./网页测速。林檎。豫行 量 github 3 0
```

回放为纯算（无网候，惟读册读体），故取三轮之小即可比其快慢。欲见进程处理器之时，用本机之时间具：

- 林檎：`/usr/bin/time -l ./网页测速。林檎。豫行 量 github 3 0`
- 林纳：`/usr/bin/time -v ./网页测速。林纳。豫行 量 github 3 0`

滚动之准：

```
./网页测速。林檎。豫行 滚 github 30
```

载一页而后连滚三十帧，每帧四十素，一帧一行 `测速滚`、帧号与微秒。所循为览者滚动重绘之一路（舒卷重绘网页盒页）：移上帧之图、惟重画所露之条、右栏与上卷之底条，不整页重排重栅。

## 一页一行

```
./网页测速。林檎。豫行 总 github 30
```

载一页、滚三十帧（次参缺省三零），以首屏、载完、峰存、CPU 之用户与内核、所配之字、滚帧之数、中位与最慢压为一行而印，例如：

```
github｜首屏 1234567 微秒｜载完 4469144 微秒｜峰值内存 3428 MiB｜CPU 用 4900000 系 630000 微秒｜分配 1431013720 字节｜滚动 30 帧 中位 265619 最慢 451994 微秒
```

欲与他路一页一行之命者，即用此条，抄之报告，无须再算。

## 比

```
./网页测速。林檎。豫行 比 结果/改前。数据。豫 结果/改后。数据。豫
```

逐段书旧、新与变化之百分，复书总时、峰存、分配、峰堆与读资之变。同机新旧交替各三过取小，一命可也：

```
for i in 1 2 3; do ./网页测速。林檎。豫行 量 github 1 0 改前; ./网页测速。林檎。豫行 量 github 1 0 改后; done
```

## 录放之开关

采资交换之录放开关在「抓取」之「录放」一处：环境 `豫言录放` 取 `录` 或 `放`，`设录放` 亦可直设；空文为关（如故经磁盘之藏与网）。览者之资读与量具共此一关，故览者亦可整页录放：

```
env "豫言录放=录" ./浏览器。林檎。豫行 https://example.com/
```

## 诸段之义

- 解析：读主文、嗅码、解篇、套应首，至篇成。
- 预取：扫脚本、衣样、图像之外链，依源取回（回放则读册读体），复展样式之 url() 与字体之源再取一过。
- 脚本：依序行常脚本、延后与模块，每项后过微务之检。
- 读样：读衣样、解码，至样式之资成。
- 样源：合用户代理之样与篇中之样为样源。
- 读记：建样式读者（择器之记与级联之门）。
- 盒树：依篇与样式读者生盒树（含样式之配与级联）。
- 量树：以每盒所选之体之升降距写入算样。
- 布局：块流、行盒与定位。
- 成组：生绘制之组（裁剪、图层、内容图）。
- 映列：生显示之列表。
- 栅格：以绘制之组栅为页图。

样式之配与级联在盒树一段，尚未细分；欲细分须由样式之引擎自记段刻。

## 量法之限

- 所量为接引之整页载入（脚本一过、排终版），非览者异步载入之首屏与分批重绘；异步之载须窗与显示之面，此具不须窗。
- 回放时字体取于录：@font-face 之外链字体于录时已取回而存于册。
- 果中之分配字与峰堆出于豫言回收统计，为执行器回收堆之口径，非进程常驻；常驻看峰值内存。
