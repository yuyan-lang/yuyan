# 司民（代码行数统计）

司民者，计仓中 git 所录诸 `。豫` 之篇之行数，依种类、顶层之目录与二级之目录而分之，书报告以 Markdown。CI 之工作流「代码行数」（`.github/workflows/代码行数.yml`）每推 `yybs`、每有拉取之请，辄行之，书报告于作业之摘要；推 `yybs` 者，又登今数于版籍，并报告发于发行之版 [code-line-stats](https://github.com/yuyan-lang/yuyan/releases/tag/code-line-stats)，其说明即最新之报告也。

名取《周礼·秋官》之司民：“掌登万民之数，自生齿以上皆书于版，辨其国中与其都鄙及其郊野，异其男女，岁登下其死生。”以篇为户，以行为口。

## 用法

于仓之根行之：

```sh
豫构 构建 司民 --输出 司民。林檎。豫行 -j 24
./司民。林檎。豫行                          # 书报告
./司民。林檎。豫行 --版 版籍。数据。豫      # 读书版籍，报告多增减与近来诸次
```

## 计法

- 所计：`git ls-files -- '*。豫'` 所列而实有之篇。
- 每行归一类：有码之行为码，惟注之行为注，惟空（空格、全角之空、制表、回车）之行为空。末行无换行者，亦计一行。
- 依词法逐格而巡：外遇注之起符则入注，注以深计，可相套；名读至右角括；文读至未转之右书名号，文中之转义全越之。名与文跨行者，续行为码。
- 种类者，篇名自首句号以后之缀也，如 `。测试。豫`、`。底层。豫`、`。包。豫`；常篇为 `。豫`。
- 目录取篇所在之目录前一层（顶层）与前二层（二级）；径居顶层者，归顶层本身。

## 报告

次第为：总数（篇数、总行、码、注、空）；依种类、顶层、二级之三表，各依码之行数自多而少。有 `--版` 者，总数之下多一句较前次之增减，三表多一栏码之增减，末多近来三十次之表（新者居前）。

## 版籍

`--版` 所指，一数据之文也（`名。数据。豫`，以库「籍册」读书之），有二表：

- 「历次」：每次一「次」，其栏为 提交、时（提交之时）、篇（篇数）、码、注、空。
- 「近况」：最近一次依类之户口，每类一「目」，其栏为 组（种类、顶层、二级）、名、篇、码、注、空。

文不存则自此次始记；同一提交再记者，易其旧登。总数之增减较历次之前一，诸类码之增减较近况；前次所无之类，视为自零而增。

## 局限

- 历次惟增不删，每次全篇读书之。记至数万次而读书迟，乃依时疏其旧登（码中留待办之注）。
