# 司民（代码行数统计）

司民者，计仓中 git 所录诸 `。豫` 之篇之行数，依种类、顶层之目录与二级之目录而分之，书报告以 Markdown。CI 之工作流「代码行数」（`.github/workflows/代码行数.yml`）每推 `yybs`、每有拉取之请，辄行之，书报告于作业之摘要；推 `yybs` 者，又登今数于版籍，并报告发于发行之版 [code-line-stats](https://github.com/yuyan-lang/yuyan/releases/tag/code-line-stats)，其说明即最新之报告也。推 `yybs` 者，又绘近三十日之折线图，推于分支 [代码行数图](https://github.com/yuyan-lang/yuyan/tree/代码行数图)，嵌于报告。

名取《周礼·秋官》之司民：“掌登万民之数，自生齿以上皆书于版，辨其国中与其都鄙及其郊野，异其男女，岁登下其死生。”以篇为户，以行为口。

## 用法

于仓之根行之：

```sh
豫构 构建 司民 --输出 司民。林檎。豫行 -j 24
./司民。林檎。豫行                                                  # 书报告
./司民。林檎。豫行 --版 版籍。数据。豫                              # 读书版籍，报告多增减与近来诸次
./司民。林檎。豫行 --版 版籍。数据。豫 --图 近三十天.svg            # 又绘近三十日之折线图
./司民。林檎。豫行 --版 版籍。数据。豫 --图 近三十天.svg --图址 网址  # 报告又依网址嵌图
```

## 计法

- 所计：`git ls-files -- '*。豫'` 所列而实有之篇。
- 每行归一类：有码之行为码，惟注之行为注，惟空（空格、全角之空、制表、回车）之行为空。末行无换行者，亦计一行。
- 依词法逐格而巡：外遇注之起符则入注，注以深计，可相套；名读至右角括；文读至未转之右书名号，文中之转义全越之。名与文跨行者，续行为码。
- 种类者，篇名自首句号以后之缀也，如 `。测试。豫`、`。底层。豫`、`。包。豫`；常篇为 `。豫`。
- 目录取篇所在之目录前一层（顶层）与前二层（二级）；径居顶层者，归顶层本身。

## 报告

次第为：总数（篇数、总行、码、注、空）；依种类、顶层、二级之三表，各依码之行数自多而少。有 `--版` 者，总数之下多一句较前次之增减，三表多一栏码之增减，末多近来三十次之表（新者居前）。有 `--图址` 者，总数之后多一节“近三十天”，依网址嵌其图。

## 折线之图

`--图 径` 取版籍中最近一次以前三十日之诸次（今次在焉），绘为白描（SVG）之折线图，书于其径：

- 五色之线，依次为篇、总行、码、注、空，皆取其总。
- 横为提交之时。每日零时（依最近一次之时区）画一竖格，下标“月-日”；日多则间数日而标之，全图所标十许。
- 纵为读数，等分而自零始。每线依最近一次之数取十之幂为倍，故最近一次之读数在一与十之间；图惟画读数，倍书于例，如“总行数 ×10⁶”，读数乘倍即实数。纵轴之顶，取诸点读数之极，至少为十。
- 一列之像，惟画其最后之次；末点加圆。副题书起讫之时与次数。
- 色依系统之浅深二模（`prefers-color-scheme`）各取一套。

`--图址 网址` 令报告依此网址嵌图。CI 推图于分支 `代码行数图`：每次一孤立之提交，惟含此图，强推以易其旧；报告中之网址，raw.githubusercontent.com 上此图之址也，后缀 `?提交=<提交号>`，每次之图各有其址。稽府（GitHub）发行之资产皆以 `application/octet-stream` 下之，raw.githubusercontent.com 以 `image/svg+xml` 伺之，图乃得见于页。

## 版籍

`--版` 所指，一数据之文也（`名。数据。豫`，以库「籍册」读书之），有二表：

- 「历次」：每次一「次」，其栏为 提交、时（提交之时）、篇（篇数）、码、注、空。
- 「近况」：最近一次依类之户口，每类一「目」，其栏为 组（种类、顶层、二级）、名、篇、码、注、空。

文不存则自此次始记；同一提交再记者，易其旧登。总数之增减较历次之前一，诸类码之增减较近况；前次所无之类，视为自零而增。

## 局限

- 历次惟增不删，每次全篇读书之。记至数万次而读书迟，乃依时疏其旧登（码中留待办之注）。
- 三十日之登皆在一日之内者，横轴依时而标，俟诸后版（码中留待办之注）。
