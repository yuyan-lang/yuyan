# 济津（原生中继服务）

济津取渡津之意，为合成名。程序接收两个命令行参数：监听端口与配置路径。配置为籍册（数据文件），字段如下：

- `令牌摘要`：六十四字符十六进制沙二五六（SHA-256）摘要的列。
- `来源`：允许的 Origin 字符串列。Origin 缺席的客户端按令牌核验。
- `证书`、`私钥`：可选的证书链与私钥路径，采用网页服务内核已有的证书格式与签名支持。

明文入口使用 `ws://`。同时给出证书与私钥时，公开入口使用封缄（TLS 库）的服务端传输；解密后的字节转交本进程绑定在回环地址的明文笔谈（WebSocket）入口，鉴权、目标校验与转发共用津梁（中继库）。

请求路径为 `/中继?主机=<目标>&端口=<目标端口>`，其余路径答四零四。协议与关闭码见底层网络规范“浏览器”。每条连接的摘要前缀、目标、双向字节数与毫秒时长写到标准输出。

配置只保存令牌摘要。可用津梁的求令印（令牌摘要计算）生成摘要，再经铸令印（配置摘要校验）核对其格式。

`样例。数据。豫` 给出配置结构。林纳版的启动命令为 `./济津。林纳。豫行 8443 配置。数据。豫`。证书链采用 PEM，私钥采用椭圆密码标准一或公钥典第八号封套，签名使用二五六位椭圆曲线，具体证书格式沿用网页服务内核。
