# 浸泡

为提案〇〇〇七三《均输》作久试之器：依方案循环行构建与壳句，按时采「观役」之役表与「析役存」之存明细，书其原文于样本之卷，终则较首末而陈其总。

## 用法

于仓根构而运行之：

```sh
豫构 构建 浸泡 --输出 浸泡。林檎。豫行 -j 8
./浸泡。林檎。豫行 --时长 86400 --采样 60 --样本 浸泡样本。数据。豫
```

其参：

- `--时长 秒`：浸泡之久，常为 `86400`（一昼夜）；`0` 则惟行方案一遍（冒烟之用）。
- `--采样 秒`：每几秒一采，常为 `60`；至少一秒。
- `--样本 路径`：样本之卷，常为 `浸泡样本。数据。豫`。
- `--只 名前缀`：惟行名以此起之方案项（可作冒烟，如 `--只 发现`）。

退码：诸项皆零退则 `0`；有一项非零则 `1`（总中逐项书之）。配置有误、样本之卷不能书、采术抛异者，以本器之误而退。

## 方案

常方案在 `浸泡方案。数据。豫`，构时导入；改之而后重构本器乃效。顶层为「浸泡方案」，每项一「浸泡役」：

```豫言
「浸泡役值」于「名」曰『发现』
　于「程序」曰『豫构』
　于「参数」曰（「列」【『发现』】）
　于「环境」曰（「列」【（『豫言多核差遣』与『开』）】）
　于「时限秒」曰「600」
```

「环境」者，叠加于父俗之名值对；差分多核与折磨之开关皆由此授予子程。「时限秒」零则无限。构建与壳句无异，皆一命也；所行之程与参照实书，不由宿主之 shell，故通配、管、重定向皆不支持，须之者别作豫言程序。

常方案次第为：`豫构 发现`、`豫构 文件 应用/百工坊/全树测试/入口。豫 -- --type-check-only`、构全树测试、行全树测试 `--列出`、单篇类检浸泡入口；皆带 `豫言多核差遣=开`。此乃第一期验收之骨，正式浸泡时依所验之包与壳句改之。

注意：子程依 PATH 求 `豫构`。本机 PATH 之 `豫构` 若为薄启之链（惟转「文件」「类型检查」二命），案中构建之项须书真豫构（本机作 `豫构。林檎。豫行`），否则所编之程不可径行。

## 采样与样本之卷

每隔 `--采样` 秒调几席之「令列出役」（壳命「列出役」「观役」共用之役表）与「令析役存」（壳命「析役存」之存明细）——此二术即「诏令」之壳命「列出役」「观役」「析役存」所指之实——取其文，加序号与单调毫秒之时，书为一「采样」。样本之卷为数据子语（`名。数据。豫`），其形如：

```豫言
「采样们」者
「列」
【「采样值」【「序」者「1」也，「时」者「1234」也，「任务表」者『…』也，「役存表」者『…』也】
，「采样值」【…】
】。
```

二表依原文而存，换行与引经「述文」转写，可复析。子程行时亦采：主环候子程之际以「限时让」候采之间，时至则采一采，复候之。

## 总

终时（末采之后）较首末二采：

- 每任务一行，书常驻自几兆至几兆、涨降平与差；首无者书“新见”，末无者书“已不见”；
- 合计常驻与合计窖各一行；
- 「停世界时长」：自二表诸含“停世界”之行取“数毫秒”之数，具其数、最小、平均、最大与四档之布。

「析役存」不得存明细时（如宿主之任务监测不供），自退依「观役」役表较常驻，而于总中注明窖不可得。停世界一项今犹未备，总中明书“待第一期既成自采”；执行器一旦以停世界时长书于二表，不待改本器而自得之。

## 与提案〇〇〇七三之关系

提案第七节求差分、折磨与一昼夜之浸泡。差分多核与折磨在「全树测试」之 `--差分多核` 与 `--回收折磨 N`、`--调度折磨`、`--候折磨`、`--堆核对`；本器司其三：以一组构建与壳句连行不已，续采「观役」「析役存」，观内存、窖与停世界时长之涨否。境开关由各实例启时读之，故本器纳之子宫子程之境。

## 维护

采与总之纯算在 `核心。豫`（析二表、较首末、算四档之布），行与书卷在 `入口。豫`；改判定或总之式者，并改本说与汉语之版。勿于此起宿主之命：子程经「使者」「差遣」而起，采经几席之现术，卷经「藏书」而读写。
