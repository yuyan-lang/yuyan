# 浸泡

为提案 00073《均输》做长期可靠性验证的浸泡工具：按方案循环运行一组构建与壳句，定时采「观役」的任务表与「析役存」的内存明细，把原文写进样本数据文件，结束时比对首末并印出摘要。

## 用法

在仓库根目录构建并运行：

```sh
豫构 构建 浸泡 --输出 浸泡。林檎。豫行 -j 8
./浸泡。林檎。豫行 --时长 86400 --采样 60 --样本 浸泡样本。数据。豫
```

参数：

- `--时长 秒`：浸泡时长，缺省 `86400`（二十四小时）；`0` 表示只把方案跑一遍（冒烟用）。
- `--采样 秒`：每隔多少秒采一次，缺省 `60`；至少一秒。
- `--样本 路径`：样本文件路径，缺省 `浸泡样本。数据。豫`。
- `--只 名字前缀`：只跑名字以此开头的方案项（可用来冒烟，如 `--只 发现`）。

退出码：全部方案项零退出为 `0`；有任何一项非零退出为 `1`（摘要里逐项印出）。配置错、样本文件写不了、采样函数抛异常时以工具自身的错误退出。

## 方案

默认方案是 `浸泡方案。数据。豫`，编译时导入，改完重新构建本工具即生效。顶层是「浸泡方案」，每项一个「浸泡役」：

```豫言
「浸泡役值」于「名」曰『发现』
　于「程序」曰『豫构』
　于「参数」曰（「列」【『发现』】）
　于「环境」曰（「列」【（『豫言多核差遣』与『开』）】）
　于「时限秒」曰「600」
```

「环境」是追加到父进程环境上的名值对；差分多核与折磨开关都按这一路传给子进程。「时限秒」为零表示不限时。构建与壳句没有分别，都是一条命令；要跑的程序与参数照实写，不经过宿主 shell，故通配、管道、重定向都不支持，需要时另写一个豫言程序。

默认方案依次是：`豫构 发现`、`豫构 文件 应用/百工坊/全树测试/入口。豫 -- --type-check-only`、构建全树测试、运行全树测试 `--列出`、单篇类检浸泡入口；都带 `豫言多核差遣=开`。这是给第一期验收用的骨架，正式浸泡时按要验的包与壳句改写。

注意：子进程照 PATH 找 `豫构`。本机 PATH 上的 `豫构` 若是指向薄启的链接（只转发「文件」「类型检查」两种命令），方案里的构建项要写真豫构（本机写作 `豫构。林檎。豫行`），否则编出的程序不能直接运行。

## 采样与样本文件

每隔 `--采样` 秒调一次几席的「令列出役」（壳命令「列出役」「观役」共用的任务表实现）与「令析役存」（壳命令「析役存」的内存明细实现）——这两个函数正是「诏令」的壳命令「列出役」「观役」「析役存」所指向的实现——取它们的文字，加上序号与单调毫秒时刻，写成一项「采样」。样本文件是数据子语言（`名。数据。豫`），形如：

```豫言
「采样们」者
「列」
【「采样值」【「序」者「1」也，「时」者「1234」也，「任务表」者『…』也，「役存表」者『…』也】
，「采样值」【…】
】。
```

两张表按原文存，换行与引号经「述文」转义，可重新解析。子进程运行期间也在采样：主循环在等子进程时用「限时让」等采样间隔，时间到了就采一次，再接着等。

## 摘要

结束时（最后一采之后）比对首次与末次采样：

- 每个任务一行，写常驻从多少兆到多少兆、涨降平与差额；首次没有的写“新见”，末次没有的写“已不见”；
- 合计常驻与合计窖各一行；
- 「停世界时长」：从两张表里所有含“停世界”的行中取“数毫秒”的数，给出个数、最小、平均、最大与四档分布。

「析役存」取不到内存明细时（如宿主上的任务监测不提供）自动退回按「观役」任务表比常驻，并在摘要里注明窖不可得。停世界一项眼下还没有实现，摘要会写明“等第一期实现后自动采到”；执行器一旦把停世界时长写进这两张表，无需改本工具即可采到。

## 与提案 00073 的关系

提案第七节要求差分测试、折磨测试与二十四小时浸泡。差分多核与折磨模式在「全树测试」的 `--差分多核` 与 `--回收折磨 N`、`--调度折磨`、`--候折磨`、`--堆核对` 里；本工具负责第三样：把一组构建与壳句连续跑起来，持续采「观役」「析役存」，看内存、窖与停世界时长有没有涨。环境开关由各实例启动时读，故本工具把它们放进子进程环境。

## 维护

采样与摘要的纯计算在 `核心。豫`（解析两张表、比首末、算四档分布），运行与写文件在 `入口。豫`；改判定或摘要格式时同步改本说明与文言版。不要在这里起宿主命令：子进程经「使者」「差遣」起，采样经几席的现成函数取，文件经「藏书」读写。
