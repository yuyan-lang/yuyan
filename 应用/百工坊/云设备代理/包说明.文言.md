# 云设备代理

受云府之命，或行程，或请远近网页，或达本机模型。亦可自主上送模型之请；以会话为函，存请辞及原应，可列可览。

`发送 <ollama|openai> <会话> <请辞文件> [主机] [端口]` 以请辞原文上送；前者达 `/api/chat`，后者达 `/v1/chat/completions`，协议明书于档。`列出` 枚举诸会话；`浏览 <会话>` 陈其往来；`网页 [端口]` 开本机览页。会话之名唯许英文字母、数字、横线、下划线。欲逐字见答，当于请辞置 `"stream": true`。默认主机 `127.0.0.1`，两协议默认端口各为 `11434`、`1234`。

`登录 [端口]` 如 wrangler login：听本机 `127.0.0.1` 之端（默认 `8976`），印本站之链 `https://yuyan-lang.org/个人?cli_port=端口&cli_state=状态码` 而试开浏览器。人于浏览器登入本站而许之，本站立主访问令牌（`yym_` 为首，九十日），以三零三送至本机 `/callback`；核其状态码而存于 `~/.豫言/云凭据.json`（目七百、文六百）。每许一次，前此命令行所得之主令牌皆废。十分之内无回调则止。登录惟存凭据，不受远程之令；`供给` 须另于前台显式行之。`yy批量发布 --发布` 未设 `YY_UPLOAD_TOKEN` 时，径以此主令牌上传。

`供给 <凭据文件> [本地主机]` 出连云府，承旧 `request` 模型之命，亦承 `exec` 行程之命与 `http` 请网页之命。`exec` 载 `id`、`command`，以 `/bin/sh -c` 行之；`http` 载 `id`、`url`，可载 `method`、`headers`、`body`。网址凡 HTTP、HTTPS 皆可，本机、邻网、远域无别。二命之果皆循 `/api/ai/provider/chunk` 返，以 JSON 书 `exitCode`、`stdout`、`stderr`；网页之状态行、首与体俱在 `stdout`。非零退码亦以果返。此器循启者之权，无自提权之术；云府之派令与界面，待彼端续成。
