# 全树测试

遍求全仓之试而行之，以一律断其成败，可分片并行；CI 之「全树测试」矩阵，逐片召此器。

## 用法

于仓根行之（先备原生豫构 `yy豫构.exe`，亦可以 `./yy豫构.exe 目标 全树测试工具 -j 24` 造此器）。仓根有原生豫构 `yy豫构.exe` 则诸试皆由之编为本机原生之程而径行；无则（Windows 之原生工具链待后版）退用 `yy豫构.wasm`，试编为 `.wasm` 交诺节宿主行之：

```sh
./yy豫构.exe 构建 全树测试 --输出 yy全树测试.exe -j 24
./yy全树测试.exe                      # 尽行之
./yy全树测试.exe --列出               # 但列将行者
./yy全树测试.exe --分片 3/16          # 行第三片（凡十六片）
./yy全树测试.exe --只 库/标准库/      # 但行径首合此者
```

`--分片` 与 `--只` 皆可更加 `--列出`。有不虞之败则退码一，否则零。

## 试之类与其断

试之清单出于 `git ls-files`，略 `_v0` 之目：

- **单元之试**（`X。测试。豫`）：以 `./yy豫构.exe 文件 <径> --输出 …` 构而行之。退码非零，或所出有非零之“当前失败数：N”（单元测试之库每断必书），则为败。
- **但检**：规则表记为 `只检查` 之单元试（云工宿主、浏览器宿主须于其宿主行之），唯核其型，即 `./yy豫构.exe 文件 <径> -- --type-check-only`。
- **金样**（`名其一。豫`、`名其二。豫`……配 `名。成功` 或 `名。失败`；号逐位书以汉字，如 `名其一零。豫`）：同组之中，不为他篇以“名其N之书”所引者，及 `名其一`，各为一试：
  - `。成功`：须构成、行成；标记非空，则常出去首尾之空后须与之同。
  - `。失败`：构或行须败；标记非空，则所出须含其文。
- **脚本之试**（`名。脚本。豫` 配同名之 `名.期望` 或 `名。成功`）：依二法各行一遍，皆须零退，常出去首尾之空后须与所期同（所期空则不校）：编译而行（如单元之试构而行之）；单元装载（`./yy豫构.exe 运行 <径>`，装单元于豫构之身而行之，见提案〇〇〇〇三；Linux 之原生豫构暂编单元为 `.wasm` 交诺节行之，原生装载待后版；用 `yy豫构.wasm` 则书为单元之目，以 `node 豫言操作系统/宿主/节点/宿主.cjs <目>` 装而行之）。无所期之文之脚本非试。
- **JS 之试**（`.test.mjs`、`.test.cjs`、`。测试.mjs`、`。测试.cjs`、`.e2e.mjs`）：`node --test --test-timeout=1800000 <径>`。
- **试页**（`。测试页.html`）今不自行，报为略。

每试行时以三十分为限：有 `timeout` 令则以之强制，并以所用之时断其逾限；构不限时。构成之物置 `dist/全树测试/`，行毕即删。

## 规则表

`测试规则.tsv` 每行三栏，以制表为界：类、径、注。径以 `/` 终者为前缀。空行及 `#` 起首者略之。其类：

- `跳过`：不行，注书其故（如须云仓、miniflare、QEMU）。
- `只检查`：单元试唯核其型。
- `参数`：行单元试时所加之参，以空格为界（相对仓根）。
- `已知失败`：已登之败。败则报“已知失败”，不令 CI 败；若已成则报“意外通过”，促其出表。
- `只编译执行`：脚本之试唯编译而行，不行单元装载，注书其故（如探以己之程名为子程而复起）。

## 分片

`--分片 序/总` 依径序切为相连之段，同片之试多属一包，可共编译之缓存；诸片合之无重无漏。

## 维护

新增之试无须登记，自能寻得；唯须略、但检、加参、只编译执行或暂列已知之败，乃改规则表。改断之律，则同改此文与汉语之篇。
