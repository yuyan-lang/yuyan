# 吉特

吉特者，以豫言所书之吉特（Git）命令行之程也。克隆、提交、合并、推送诸事皆自为之，不召外之 git。其仓之式与 git 同：松散之物、包文与二版包索引、二版索引之文、引用与打包引用、配置之文、链接工作树，皆依 git 之式读书之，一仓可迭用 git 与吉特。其能书于库「版本库」，此包解命令行而召之。

## 用法

    吉特 [--仓库 目录] [--凭据 文件] 子命令 [选项…] [参数…]

`--仓库` 缺则为今目录，可为工作树中任一子目录，亦可为链接工作树。令成则退出码为零；败则非零，并书其故于标准错误。`吉特 帮助` 印全用法。

| 子命令 | 所为 |
| --- | --- |
| `状态 [--不含未跟踪]` | 较 HEAD、暂存区、工作区三方，式同 `git status --short`，首行书今枝 |
| `差异 [--暂存] [修订 [修订]] [-- 路径…]` | 统一式之差：不予修订则较暂存区与工作区，`--暂存` 较 HEAD 与暂存区，一修订则较之与工作区，二修订则较二树 |
| `暂存 路径…` | 暂存改动、新文与删除；`.` 或 `-A` 谓全 |
| `撤销暂存 [路径…]` | 复暂存区为 HEAD 之容，工作区仍旧 |
| `提交 -m 消息 [-a] [--允许空]` | 提交暂存区；`-a` 先暂存诸已跟踪文之改 |
| `历史 [修订] [-n 条数] [--单行]` | 依提交之时逆列其史 |
| `查看 [修订 或 修订:路径]` | 提交之说与差，或某版中之文 |
| `分支 [名 [起点]]`、`分支 -d 名`、`分支 -D 名` | 列、新建、删枝；`-d` 惟删已并入今 HEAD 之枝，`-D` 强删之 |
| `合并基 甲 乙` | 二提交最近之共祖 |
| `切换 分支`、`切换 -c 新分支 [起点]`、`切换 --分离 修订` | 切换其枝，将覆本地之改则止，`--强制` 弃其改；本地无而 `origin` 有同名之枝，则自建随之之本地枝 |
| `合并 分支 [--不快进] [-m 消息]`、`合并 --放弃` | 可快进则快进，否则三方合并；`--不快进` 必生合并之提交 |
| `变基 上游`、`变基 --继续`、`变基 --跳过`、`变基 --放弃` | 以今枝所独有之提交逐一重放于上游之上 |
| `工作树 新增 路径 [分支] [-b 新分支] [--起点 修订] [--分离]`、`工作树 删除 路径 [--强制]`、`工作树 列出` | 治链接工作树，与 `git worktree` 互通 |
| `克隆 网址 [目录]` | 经 HTTPS 克隆 |
| `拉取 [远端] [--只取]` | 取远端之新物，更远端跟踪之枝，乃合并上游；`--只取` 惟更远端跟踪之枝 |
| `推送 [远端] [规格…] [--强制]` | 推送其枝；规格书 `名`、`本地:远端`，或 `:远端` 以删远端之枝 |

提交之作者与提交者取环境变量 `GIT_AUTHOR_NAME`、`GIT_AUTHOR_EMAIL`、`GIT_COMMITTER_NAME`、`GIT_COMMITTER_EMAIL`，无则取配置 `user.name` 与 `user.email`。时区取环境变量 `时区`（如 `+8`、`+05:30`），次取 `TZ` 中 `UTC+8` 之类，皆无则书 `+0000`。

## 冲突

合并遇冲突，吉特书冲突之文为带 `<<<<<<<`、`=======`、`>>>>>>>` 之标者，于 `.git` 书 `MERGE_HEAD` 与 `MERGE_MSG`，列冲突之文而止。改毕，以 `吉特 暂存 文件…` 标其已解，乃 `吉特 提交`（不予 `-m` 则以合并之说为消息）；`吉特 合并 --放弃` 复于合并之前。

变基遇冲突亦止。改毕而暂存，乃 `吉特 变基 --继续`；`--跳过` 舍今之提交；`--放弃` 复于变基前之枝与提交。变基之进记于 `.git/吉特变基`，其间 HEAD 离枝。

## 克隆、拉取与推送

网址书 `https://主机/路径`，如 `https://github.com/yuyan-lang/yuyan.git`。克隆与拉取行智能 HTTP 第二版之约：克隆取诸枝与诸标签，书包文与包索引于 `.git/objects/pack`，立远端 `origin` 与远端跟踪之枝，检出远端之缺省枝；拉取告远端以本地已有之提交，惟收所缺之物。推送行 receive-pack：算远端所缺之物，束为包而发之，乃依远端之报逐条印引用更新之果。远端之枝不可快进则推送止，`--强制` 则仍更之。

## 令牌

推送须令牌，克隆、拉取私仓亦须之。吉特依次求之：

1. 环境变量 `吉特令牌`；
2. 凭据之文：`--凭据 文件` 所指之文，缺则 `/系统/吉特/凭据`（豫言操作系统中之位）。文每行书一令牌，或书“主机 令牌”（如 `github.com 令牌内容`）；带主机之行先，用于网址主机相同之仓；空行与 `#` 始之行略之。

令牌以 HTTP 基本认证发之（用户名 `x-access-token`，密为令牌），GitHub 之个人访问令牌可径用。吉特诸出皆不含令牌。

## 构建

    豫构 构建 吉特 --输出 吉特。林檎。豫行 -j 24

欲行于豫言操作系统，则编为豫行：

    豫构 构建 吉特 --输出 吉特。豫行 -j 24 -- --目标 本机 --目标系统 豫言 --目标架构 兼容六十四 --执行器 <仓根>/yy执行器。树码

## 性能

于本仓（约一万一千五百文、十三万物、一亿八千万字节之包），林檎臂六十四原生实测：工作区净时 `状态` 约 0.5 秒；经 HTTPS 克隆全仓约 193 秒，时多费于 HTTPS 之传。索引为每文记其改时，改时同且先于索引书时者，径用所记之散列。克隆时吉特自生包索引，与 `git index-pack` 所生者逐字节同。
