## 捷思脚本之行与验

- `捷思运行 脚本文件`：以一 `.mjs` 为模块置于捷思引擎而求值，印其状（求值成，或首误与所用之时）。宿主之物（`window`、`self`、`document`、`navigator`、`console`、`WebAssembly` 及常见之构造器与函数名）由 `宿主桩。豫` 置于引擎之全局物 `globalThis` 上（`window`、`self` 与之同为一物），惟供最小之桩，惟使脚本顶层不因缺名而抛误，不仿其行。模块依 `import` 之关经加载器自本地文件读之：相对之径依引用者所在之目录，站绝对之径（如 `/豫言操作系统/浏览器/引导检查.mjs`）依当前目录；成品之中平铺于一目之脚本，于仓则散于数处，文不得则于 `豫言操作系统/宿主/装载`、`豫言操作系统/宿主/网页汇编`、`豫言操作系统/宿主/浏览器` 依名补求之；`node:` 为首之模块由 `节点模块桩。豫` 以合成模块供之（见下）。宿主桩中之 `setTimeout`、`setInterval`、`setImmediate`、`requestAnimationFrame` 等，录其回调于虚时之定时器表，唯模块顶层 await 或测试有所待而作业之队空，方进虚时、行最早到期者一（燃料十万次，尽则止）。
- `捷思验收 脚本目录`：于目录（含子目录）中每一 `.mjs` 各起本程之子程而行 `捷思运行`，逐文印其状。引擎之登记表乃一程之公，同程所行愈多愈缓；分程则互不相累，崩亦止于己。每文有二分钟之时限，逾则止子程而记「逾时」，故某文之死循环不滞全目录（引擎之物性乃线表，成千上万项之类型化数组等顶层之初始化缓至逾时）。待办事项：并行。
- `捷思分析 脚本文件`：调试之用，印模块之依赖说明符、导入之项及导出之项。
- `捷思编译检查 脚本文件`：不行其脚本，将模块中每函数之体、类字段之初始化及静态块皆编一过，列所不能编之语法（「待接入」）及其行。
- `捷思编译汇总 脚本目录`：于目录（含子目录）中每一 `.mjs` 作编译之检，依误之辞分组而计其数及首见之文，以供依频而补引擎之特性。今 `豫言操作系统` 下诸 `.mjs` 皆能全编。

宿主桩于全局之名外，复供：元素之桩（`document.getElementById` 等所返之物，常法皆无所为）、`URL` 之桩，及带法表之构造器桩（`TextEncoder`、`Uint8Array`、`Blob`、`Worker` 等之例带对应之空法）。`node:path` 与 `node:url` 之常用函数、`node:fs` 之读文、判存、列目为真，`node:http` 为无所为之桩。

### 节点测试桩

`node:test` 与 `node:assert`（`node:assert/strict` 同）由 `节点测试桩。豫` 实之，使验收脚本中之 Node 测试文真可运行：

- `test`/`it`（含 `skip`、`todo`、`only` 及选项中之 `skip`、`todo`）、`describe`、`before`/`after`/`beforeEach`/`afterEach` 惟录之，待模块求值毕而空作业之队，依次行之。每测以空作业之队（队空则进虚时之定时器）待其所返之期约落定：兑现为通，拒绝为败，始终不落定为悬。败与悬者各印一行，状行之末加 `；测试 通过 N 失败 M 悬挂 K 跳过 S`。
- 断言皆依严格之义：`ok`、`equal`/`strictEqual`、`notEqual`、`deepEqual`/`deepStrictEqual`（较原型、自有可枚举之键及其值，映射集合依所迭之项而较）、`throws`（所期者可为正则、构造器、验证之函数或属性之物）、`doesNotThrow`、`rejects`（返期约）、`match`/`doesNotMatch`、`fail`、`ifError`。
- 自试见 `节点测试桩。测试。豫`。待办事项：钩子不分层、子测、测试之时限、日期与正则之深较。

### 果单

每行四列，制表符分隔：径、论、异素数、说明。

| 论 | 义 |
| --- | --- |
| 通过 | 得一条步步皆成之参照通路；说明书“两页皆纯色”者，二页皆为纯色（多为皆未绘出而偶同） |
| 失败 | 渲染之果与所求不合；说明书何页纯色、极道差及差异框（异素之包围盒），求不等价而等价者书“两页相同” |
| 出错 | 页读取败、子进程崩溃、逾时或逾内存 |
| 跳过 | 页含可行之脚本或须待脚本（`reftest-wait`）、分页或须人手、服务端替换（`.sub.`）、参照为图像或矢量图，或无参照；脚本一概当数据，不行 |

异素数取诸较中异素最少者。汇总之通过率 = 通过 ÷（通过 + 失败 + 出错），跳过不计；“其中皆纯色”一栏记二页皆纯色而通过之试数，“去之后”之通过率复去此类试。

### 判定之则

- 同页之数参照为“或”（任一成即可）；参照页自带参照者循链依次而成（深度优先，至深八层）。
- `match` 求二页等价，`mismatch` 求二页不等价。
- 逐像素较前，先合二页之素于白底（页图为未预乘之红绿蓝透明，浏览器截图之底为白），透明与白同；“异”谓合后任一道不同。
- `<meta name="fuzzy" content="[参照页:]maxDifference=a-b;totalPixels=c-d">` 示容差：单数则自零至其数，带参照页之前缀者唯施于其参照页；无 `fuzzy` 则求逐素相同。
- 页中之相对址依试页之址解之，以斜杠为首之址映于数据目录之根。
- `.xht`、`.xhtml` 之页，先去 CDATA 之标记，并展自闭而非空之元素，再依超文本标记解析（近似可扩展标记之解析）。
- `font-family: Ahem` 取数据目录之 `fonts/Ahem.ttf`，余字体用系统之体；林纳上之原生执行器暂无字体宿主，运行器依候选之径读 Liberation 字体。
