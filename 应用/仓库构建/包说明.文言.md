# 仓库构建

语言仓之构建程序：原生运行时、编译器自举之链、豫构、核型、豫构之试、全树之试与网页汇编宿主，皆以寻常豫言书之，由 [构建编排](../../库/构建编排/包说明.文言.md) 并行调度而缓存。代旧根 Makefile 与运行时 Makefile。

## 用法

于仓根行之。稳定之器有二源，构建程序自择：仓根有原生之 `yy_bs_stable`、`yy豫构_stable` 则用之；无则用 Wasm 工具链之包（见下节）之 `yy_bs_stable.wasm`、`yy豫构_stable.wasm`，以 Node 行之。有原生稳定之器时：

```sh
./yy豫构_stable 构建 仓库构建 --编译器 ./yy_bs_stable --输出 yy仓库构建 -j 24
./yy仓库构建 --列出                  # 列诸目标
./yy仓库构建                         # 默目标“全部”：自举而造豫构
./yy仓库构建 类型检查 豫构测试 -j 24
./yy仓库构建 全树测试 --不连带       # 但行其试，不重造所依
```

## 自 Wasm 工具链之包起步

CI 每轮发跨平台之 Wasm 工具链包 `yuyan-wasm.tar.gz`（GitHub 发布 `continuous-binaries`；`historical-binaries` 按提交之号存之）：编译器、豫构与本构建程序之 WasmGC 模块（`yy_bs_stable.wasm`、`yy豫构_stable.wasm`、`yy仓库构建_stable.wasm`），及 Node 宿主与值桥（`yy稳定节点宿主/`）。凡有 Node 与 clang 之平台，皆可以之自无而造本机之工具链。包必解于仓根：豫构以编译器所在之目为工具链之根（运行时之头文件与档皆依之）：

```sh
tar -xzf yuyan-wasm.tar.gz
node yy稳定节点宿主/宿主.cjs yy仓库构建_stable.wasm 运行时 -j 24
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 仓库构建 --编译器 ./yy_bs_stable.wasm --输出 yy仓库构建 -j 24
./yy仓库构建 -j 24
```

首步以包中之构建程序造原生运行时（运行时之源按目录列之，包中旧程序亦能容新增之源）；次步以包中豫构与编译器造今源之构建程序；其后悉委之。编译器二级由 Wasm 编译器于 Node 下造之，三级、四级与豫构仍由稳定豫构调度。

## 目标

| 目标 | 所为 |
| --- | --- |
| 运行时调试、运行时优化 | 于 `豫言操作系统/宿主/原生/运行时支持库/构建/<变体>` 编 `运行时/` 下诸 C 与 LLVM 之源，归为 `lib豫言运行时<变体><版本>.a`（先书临时之档，成乃移入）。macOS 之优化加 `-flto` 而用 `llvm-ar`，Linux 用 `ar`。 |
| 运行时 | 复出包链接所用 `包调试`、`包优化` 二档。 |
| 编译器二级、三级、四级 | 各以稳定编译器（`yy_bs_stable` 或 `yy_bs_stable.wasm`）、`yy2_bs`、`yy3_bs` 造豫言编译器，得 `yy2_bs`、`yy3_bs`、`yy4_bs`；其输入为编译器之源（三目录下之豫、C 与头文件，除试与文档）。 |
| 自举 | 核 `yy3_bs` 与 `yy4_bs` 逐字相同。 |
| 豫构、类型检查、豫构测试 | 以 `yy4_bs` 造 `yy豫构`、核豫言编译器之型、行包配置与豫构之八试。 |
| 全树测试工具、全树测试 | 造 `yy全树测试` 而行全仓之试。 |
| 网页汇编宿主、网页汇编复制宿主 | C 桥接 Wasmtime C API（仓根 `yy_wasmtime_c_api` 等），由豫构链之。 |
| 网页汇编工具链 | 以 `yy4_bs` 编编译器、豫构与本构建程序为 WasmGC 模块，并值桥与 Node 宿主置于 `yy网页汇编工具链/`（其布局即解于仓根之布局）；赖网页汇编宿主组装 WAT。 |
| 清理 | 除缓存、构建之物（含 `yy网页汇编工具链/`）与运行时之档。 |
| 全部 | 自举与豫构。 |

凡调豫构之步皆入一独占之组，逐一而行，保同一编译缓存同时唯一构建；原生运行时二变体可并行。

## 维护

增构建之步，于 `入口。豫` 增改目标；改目标则同改此文与汉语之篇。
