# 批量发布

发行之 ZIP 与 tar.gz，以纯豫言「归档」「压缩」之库成之；复用 ZIP，压档之解器验诸项而读包述。构建合档，常文可行者权为 755，余为 644，目为 755；链接仍略。

新档附包信息.json 记所依与说明，接口之模块映射.json 记文件与篇之属。门户分包籍、文档、文件树；内容域自成阅读页，同次文与源可互易，不复嵌窗。旧档不擅改，更新材料须重新打包。

此器以豫言作。常行惟列诸包，加“--打包”乃成档，加“--发布”乃上传。源码取 Git 所录及未忽略之新文，子包有界；拒敏感名，略符号链接（发行之档不载链接之文）。

构建之档备所依、Wasm 工具链（编译器 yy4_bs.wasm、豫构 yy豫构.wasm）及 Node 宿主（`豫言操作系统/宿主/节点/` 下三 .cjs 与同代之值桥）；重建唯须 Node.js。可执行之包，其程序为 .wasm 之模，以 Node 宿主行之。独立构建之树唯载所依之闭包，其中包述去「包含在」「包含包」，又去有「。包。豫.txt」包述之模之子目（双宿主构建另建之一致性应用），发行之源码存其原文；发行之材展开之总以 6400 MiB 为限，同于包府；纯接口之包（唯有 。接口。豫／。应用接口。豫）独立构建时略其类型检查。

上传之符藏于私有暂文，不列于命令；用毕即删。已成 ZIP 留以再传。异文可加“--重新打包”，版名不易而上传序增；同档重试仍归原序，旧籍可下载。

先行“yy豫构 构建 批量发布”，后行“yy批量发布 --所有者 豫言”观其计划。加“--打包”制档，加“--发布”上传；上传之符取 YY_UPLOAD_TOKEN；未设则读“yy云设备代理 登录”所存之 ~/.豫言/云凭据.json，径以其主访问令牌上传，符惟入私有暂文，不换符亦不废他符，诸程可并传。可用“--包”择一包。默认成档于 .yybuild/发布，工作副本不改。

文档以“构建包”成接口，以“构建源码”览本包，不纳所依及子包，不复立导入索引。首页列包籍、双语说明及成败，接口与源码互通；生成状态.json 各记其果。说明转义而陈，不行其 HTML。

接口败则明记之，残篇不入发行；源码不合语法者以纯文示之。源码站败则不成档。可读非谓可构建，库仍须验型，可执行之包仍须成器。重新打包者，新档既成乃备其旧于“旧档.XXXXXX/发布.zip”；败则原档不动。重传旧档不进其序，各次材料不相杂。

器之运行包惟附当前平台之程序，外部数据与动态库仍依其说明而备。敏感名之检非能尽察秘密，发布者须先审其文。测试惟传于本机，不入公府。

真档验收见内服取摘要时误析全档，今改惟取首六十四字节，并备一百二十八 MiB 之堆。公府须先部署此修复，乃可批量上传；此器不擅部署。
