# 豫言试写间

编辑、编译和运行均在浏览器 Web Worker 中完成。编译器本身为 WasmGC，生成 WAT 后由 Binaryen.js 在本地组装，再用独立 Wasm 实例运行。手动运行不请求服务器、不计服务器编译额度；AI 助写通过 Cloudflare Worker 调用 DeepSeek，密钥始终留在服务端。

## 构建

在应用目录运行 `npm ci`。从仓库根准备当前原生编译器、Wasmtime C API 编译宿主及资源：

```sh
make 浏览器编译资源
cd 应用/豫言体验
npm test
npm run 检查配置
npm run 开发
```

Wasmtime 仅用于发布前生成种子，浏览器不需要 Wasmtime、LLVM 或原生进程。宿主构建要求见 `../../工具/网页汇编宿主/说明.汉语.md`。已有当前版本 WAT 时，可直接构建并运行 `yy浏览器编译资源 yy浏览器种子.wasm.wat`，见资源工具说明。

`网页/编译/资源` 是可再生静态产物，不进入 Git。包括约 1.8 MB 的优化编译器、GC 值桥、约 2.7 MB 的压缩标准库源码与预编译缓存，以及 Binaryen.js。Binaryen 132.0.0 的发布模块未压缩约 14.8 MB，实际网络传输量取决于服务器压缩。首次使用下载，后续复用模块。资源清单保存 SHA-256，发布前测试验证资源及源码一致性。

## 执行与能力边界

每次编译新建内存文件系统，装入标准库和固定包上下文；只复用标准库派生缓存，不保留访客源码与程序输出。运行程序另用空文件系统。用户程序没有网络、原生进程、服务器文件、模型密钥或交互输入；不支持第三方原生包，未实现的原语明确报错。

加载及编译最多 90 秒，运行最多 5 秒，stdout/stderr 合计最多 64 KB。组装阶段为编译器和程序加入低频执行检查，每 1024 次函数进入检查期限并提供引擎中断机会，避免纯尾调用死循环拖延 V8 线程终止。主线程通过 `Worker.terminate()` 实现停止和超时。内存文件及交换缓冲区各限 128 MiB；这是应用缓冲区限制，不是浏览器 GC 堆的硬配额。需要支持 WasmGC、JSPI、尾调用、异常处理和 DecompressionStream 的现代浏览器，不满足时显示错误，不回退到容器。

编译器的合流主体正常返回会跳过合并体，因此必须继承尾位置；此次修复避免 JSON 解析器尾递归变成深调用栈。GC 值通过独立、同形类型的 Wasm 桥接模块读写，JS 不直接访问 GC 结构字段。Binaryen 文本入口显式转换 UTF-8 字节串，只启用使用的稳定特性。

## AI 助写

`/api/assist` 使用同源 WebSocket。范围判断、标准库查询、模型消息、最多六轮生成、六次编译运行、十二次工具调用及八分钟总时限由服务器掌握。服务端发出带编号的编译请求，浏览器执行并返回诊断；服务器只接受当前编号的限长结果。断开连接中止模型请求及后续轮次。

浏览器回传的验证结果用于该访客的助写体验，不作为服务器执行代码、授予权限或可信认证的依据。模型密钥仍为 `DEEPSEEK_API_KEY` secret；仅当 `ENABLED=true` 且有密钥时开放助写，手动编译不受此开关影响。原有每日全站及访客 AI 额度保留。

编译日志显示本地阶段和输出；对话日志保留模型往返及工具结果。未通过编译的源码不会自动替换编辑器。`/api/run` 对旧页面返回 410，提示刷新。

## 发布

```sh
npx wrangler deploy --config 发布配置.jsonc
```

部署前须完成资源生成及所有检查。新配置移除 RUNNER、Container 镜像和出站模型代理，保留 Quota。首次切换不删除旧 Durable Object 数据：保留 `YuyanContainer` 类名，旧入口只返回 410，不再提供编译或执行能力。旧容器源码和测试暂留作回退参考，不参与当前执行路径或 npm 依赖。

若上线异常，停止新流量切换，恢复切换前的 Worker 版本及其静态资源；若平台不能直接回退，则从 Git 基线 `4cdeca11` 恢复原入口、依赖和发布配置后部署，复用原配置记录的已验证容器镜像及保留的对象命名空间。此方案没有删除旧对象类的迁移。旧容器应用的最终清理应在新版本线上确认后另行进行。

## 真实浏览器验收（2026-09-09）

在 Codex 内置浏览器的本地页面实测：你好输出正确、算术输出 8、函数输出 4、模式匹配输出 3；未定义变量显示具体中文诊断；死循环五秒超时、手动停止及停止后重新运行均通过。此前 Node 测试的就绪缓冲掩盖了首个任务丢失，现已使用生产与测试共用的显式就绪握手，Binaryen 改为动态导入。

真实浏览器的小栈还要求使用 JSPI 的独立 Wasm 栈；发布时预编译可信标准库，避免在客户端重新解析大型库源码。浏览器适配层安装顶层字符串异常处理器，未捕捉异常能返回原始诊断，而非空处理器导致的 illegal cast。普通退出状态 0 不再写成错误日志。

此次没有验证付费 AI 调用：本地 AI 未配置密钥，线上状态显示 AI 可用，但尚未实测模型调用。其他浏览器尚未逐一验收。
