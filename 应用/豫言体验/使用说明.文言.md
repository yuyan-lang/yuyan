# 豫言试写间

客于网页书豫言，或述其欲，使助者成文；编之，验之，而后行之。

今已发布于 [豫言试写间](https://playground.yuyan-lang.org)。Pro 用器之版已过本地单测十九、器中联测四，并云配置与编译器类型之验。云端九九乘表一次编行即成；六之阶乘先查官书，纠其模块名，再行而得七百二十。实答之型号为 `deepseek-v4-pro`，往来与诊断皆随至随示。

## 往来之录

结果之侧别置“编译器日志”，初隐，可按“隐藏／显示”而开阖。编译之进度与输出随至随示，新请求则另起计数；页下全录仍留前后诸事。

页下置“对话与调试日志”，初阖而可开。客之所发、模型所答、编译诊断与运行输出，随至随示；修复之辞亦全记之。记录惟当事客可见，同页前后之事皆留，刷新乃去，不别存于服务器与浏览器久藏之处。

钥与认证标头不入录；上游若回显实钥，外桥先抹之。编译输出仍限六十四 KB。断流不去已得之录，慢客积压过限则明告省略。预算尽而仍败，则示其诊断与末稿，不自开录；未验之稿不径易客文。

## 制

外桥司网页、验请求、计日额；容器司助写与编行。每事别辟一室，断其网，清其境，不见前客之稿，亦不得见钥。钥藏于 Worker，容器惟由 `model.internal` 请 DeepSeek 官方之术，不于器中置模型权重。

官书预编而封之，每客取缓存副本；客之新缓存，事毕即弃，不传后客。运行库既成，惟验其在，不复开炉。

先审客志，非豫言编修之事则辞之；既许，则成 JSON 源码，验其可编，而后还客。今用 `deepseek-v4-pro`，启 high 思考。全载官书四十八模块、六百五十一公开签名与四篇已验之例，授查询、读例、编译、运行四器。往复至多六轮，编行至多六次，工具至多十二用，总时八分钟；末稿改则复验。累计 token 逾二十五万即止后呼，此为软限，非账单之硬限。然审志亦可误，能编不即合约，不得谓绝无越界之患。

## 验与用

于此目录行 `npm ci`、`npm test`、`npm run 检查配置`。镜像之构建与试行命令，见同目录《使用说明.汉语.md》。Bubblewrap 别室若不成，服务必止，不得去其禁而径行客文。Docker 之验不代 Cloudflare 之验。

`云端配置.jsonc` 以 `ENABLED=false` 备源码之改。以 Wrangler 交互置 `DEEPSEEK_API_KEY`，勿载钥于源码与谈话。凡后改，先验云端编行及隔离，后开放之。

今以 `发布配置.jsonc` 记所用账户与镜像之印，置 `ENABLED=true`。源码配置仍闭其门，以备后改之验。镜像既改，须复构、复验、复上传，而后更其印。上传用 `linux/amd64` 单架构清单；置钥与再发布之命令见汉语说明。

室二，闲一分钟而眠。一室一事，满则辞后来者。编限三十秒，行限五秒；每段输出六十四 KB，地址空间二 GiB，单文件三十二 MiB，进程三十二。事毕去其稿与缓存。

全站每日助写百次、手动运行千次；一 IP 每日助写十次、运行五十次，每分钟共六次。日界从 UTC。失败亦计数，助写内之验改不另计点击。IP 同者共其额，散众之滥用不可尽止，然总额不变。提示与源码须传模型商，不主动藏于此站。

## 价

二〇二六年九月五日所核，美元每百万 token：DeepSeek Flash 高峰未缓存输入 0.44、缓存输入 0.014、输出 1.32；非高峰各半。Cloudflare 同型号价与官方高峰同。Kimi K2.7 Code 官方及 CF 未缓存输入 0.95、缓存输入 0.19、输出 4.00。故初用 DeepSeek 官方，Kimi 尚未接入。

模型之费，与容器、Worker、Durable Object 之费各计。详价、出处及例算，俱见《使用说明.汉语.md》。价格或变，部署时复核之。

## 官书之录

以《标准库签名导出。豫》读编译器所验之类，遍录标准库公开名，兼及别名与推导者。官书改则复导，诸例复验，而后构器。命令见汉语篇。今用 Pro，旧 Flash 价不可移算；所用 token 见接收之录。

容器池以 `RUNNER_RELEASE` 别其版。旧室未易则更新其名，总室仍限二。新室初启或须稍候；须见载书四十八、签名六百五十一及 Pro 用器之录，始可谓新版已行。
