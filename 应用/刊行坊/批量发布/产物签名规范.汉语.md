# 包产物签名

正式消费者为 `yy批量发布`。它在 `制作归档` 返回后、`上传归档` 前调用 `产物发布签名门`，处理新建与复用的真实 `发布.zip`。`YY_PACKAGE_VERIFY_SPKI` 为独立固定信任的 Ed25519 DER SPKI 文件路径；配置后每个产物必须通过同名旁签核验，错误终止该包上传并计入失败。`YY_PACKAGE_SIGN_SEED` 为安全保存的32字节 Ed25519 原始种子文件路径，配置时先签名再以独立公钥回验。种子文件保存在源码扫描范围之外。空配置路径按错误处理。

离线消费者入口：

```
yy批量发布 --签名产物 发布.zip 原始种子文件 DER公钥文件
yy批量发布 --验签产物 发布.zip DER公钥文件
```

签名入口先核对生成的签名与指定信任公钥，随后写 `发布.zip.签名.der`。验签入口读取完整当前产物、旁签与独立公钥，成功退出零，失败按固定错误退出非零；可以作为发布或安装前的显式校验步骤。信任公钥由分发者的独立信任渠道确定。

旁签采用 DER：外层为声明、Ed25519 算法标识、按整字节排列的64字节签名。声明是版本整数1、协议域八位字节串“豫言包产物签名一”、产物完整字节数与32字节SHA256摘要的序列。声明DER是待签正文。核验按当前产物重建声明并逐字节比较，严格核对算法、字段数、签名字节数和比特串首字节，再用正式证书SPKI及Ed25519验签。旁签提供签名字节，调用者提供固定信任公钥。

生产实现复用正式密码散列、爱德签名及证书DER与公钥核验。两个环境变量均未配置时，执行既有发布模式。旁签位于发行ZIP同目录，可随产物分发；现有上传协议继续提交ZIP，旁签云端公开下载和安装器自动拉取列后续事项。包描述继续使用已有依赖字段，工具链包 schema 保持既有形式。

默认CI入口 `测试/产物签名。测试` 创建小型真实ZIP，测试签名与固定信任SPKI、改变产物、旁签尾部垃圾、缺公钥、坏种子及正式命令的文件读写与错误拒绝。基本运行与跨端实证分阶段记录，用户延期的长批、性能与机器恒时继续留后续。
