# 豫言语言语法规范

本文描述当前编译器源码采用的核心语法。

## 文件

豫言源文件通常使用 `.yuyan` 或 `。豫` 后缀。一个文件是一组声明，声明之间用中文句号 `。` 分隔。大多数声明自身以 `也` 收束，因此常见结尾是 `也。`

空白和换行主要用于排版。表达式需要明确分组时使用全角圆括号 `（...）`。

## 词法

标识符使用书名号式引号：

```yuyan
「整数」
「表达式」
「进行类型检查」
```

标识符引号只用于标识符。函数名、类型名、构造器名、模块名和绑定名都按这个规则书写。

字符串使用 `『』`：

```yuyan
『你好』
『可以包含中文标点。』
```

注释使用 `「：...：」`，可以单独成行，也可以夹在类型或表达式附近：

```yuyan
「：这里是注释：」
```

数字使用汉字数字和 `点`：

```yuyan
零
一
一二三
三点一四
```

数字不是标识符，不使用标识符引号。

## 导入与导出

模块路径由 `之` 串联，每一段是一个标识符。

```yuyan
寻「标准库」之书。
观「标准库」之书。
寻观「标准库」之「数据结构」之书。
诵「数据结构」之书。
```

`寻` 导入模块，`观` 打开模块，`寻观` 导入并打开模块，`诵` 导出模块内容。

## 声明

类型声明：

```yuyan
「翻倍」乃化「整数」而「整数」也。
```

定义声明：

```yuyan
「翻倍」者会「数」而「加」于「数」于「数」也。
```

透明声明使用 `号` 和 `即`：

```yuyan
「别名」号「元类型」也。
「别名」即「整数」也。
```

构造器声明使用 `立`：

```yuyan
「选项」立化「元类型」而「元类型」也。
「可无」立承「甲」而「选项」于「甲」也。
「可有」立承「甲」而化「甲」而「选项」于「甲」也。
```

文件中也可以直接放一个表达式作为声明：

```yuyan
「打印行」于『完成』。
```

## 类型

显式函数类型：

```yuyan
化「整数」而「字符串」
```

带名的依赖函数类型：

```yuyan
化「整数」者「数」而「结果类型」
```

隐式函数类型：

```yuyan
承「甲」而「甲」
承「元类型」者「甲」而化「甲」而「甲」
```

类型函数也用 `于` 应用：

```yuyan
「或可有」于「整数」
```

对子类型使用 `合`，列类型使用后缀 `列`：

```yuyan
「字符串」合「整数」
「表达式」列
```

类型标注表达式使用 `也`：

```yuyan
「值」也「整数」
```

## 表达式

标识符表达式就是一个带引号的名字：

```yuyan
「翻倍」
```

显式函数调用使用 `于`，多参数调用连续书写：

```yuyan
「翻倍」于一二
「加」于一于二
```

隐式参数调用使用 `授以`：

```yuyan
「读取」授以「整数」于「引用」
```

显式函数使用 `会...而...`：

```yuyan
会「数」而「加」于「数」于「数」
```

带参数类型的函数使用 `遇...者...而...`：

```yuyan
遇「整数」者「数」而「加」于「数」于「数」
```

隐式函数使用 `受...而...`：

```yuyan
受「甲」而会「物」而「物」
```

局部绑定使用 `虑...者...而...`：

```yuyan
虑「结果」者「加」于一于二而
    「整数表示」于「结果」
```

表达式级递归绑定使用 `递归虑...其...者...而...`。`其` 后写递归值的类型，`者` 后写递归值定义，最后的 `而` 后写使用该递归值的表达式：

```yuyan
递归虑「求零」其化「整数」而「整数」者
    会「数」而
        若「等于」于「数」于零
        则零
        否则（「求零」于（「减」于「数」于一））
而
    「求零」于三
```

`递归虑` 适合在表达式内部构造局部递归函数或递归值。绑定名在定义体和后续表达式中都可见。编译器会先把它降为显式递归单元，再进行闭包转换，因此递归函数可以安全捕获自身。

递归函数使用 `循...以...`：

```yuyan
「长度」者循「长度」以会「列」而
    鉴「列」而
        有【】则零
        或有「头」衔「尾」则「加」于一于（「长度」于「尾」）也。
```

条件表达式：

```yuyan
若「条件」则「真值」否则「假值」
```

顺序执行使用 `；`：

```yuyan
（「写引用」于「引用」于「值」；「读取引用」于「引用」）
```

模块或结构投影使用 `之`：

```yuyan
「标准库」之「数据结构」
```

对子或元组投影使用 `中`：

```yuyan
「对子」中零
「三元组」中二
```

## 数据构造

对子值使用 `与`：

```yuyan
「名字」与「类型」
```

列值使用 `【】` 和 `衔`：

```yuyan
【】
「头」衔「尾」
【「甲」，「乙」，「丙」】
```

结构表达式使用多行 `（...）` 包住一组声明：

```yuyan
（
    「项目」乃「整数」也。
    「项目」者一也。
）
```

## 模式匹配

模式匹配使用 `鉴...而...`。第一个分支用 `有`，后续分支用 `或有`：

```yuyan
鉴「可」而
    有（「可有」于「物」）则「物」
    或有「可无」则「默认」也
```

空参构造器或绑定名直接写在 `有`、`或有` 后面，不额外加一层括号：

```yuyan
或有「可无」则「默认」
```

带参数构造器模式用普通应用形式：

```yuyan
有（「可有」于「物」）则「物」
```

列模式可以匹配空列或头尾：

```yuyan
有【】则零
或有「头」衔「尾」则「加」于一于（「长度」于「尾」）
```

对子模式使用 `与`：

```yuyan
有（「左」与「右」）则「左」
```

## 外部调用

外部调用保留给运行时和编译器内部使用：

```yuyan
《《C调用》》名『yyIntAdd』传「甲」与「乙」
```

## 完整示例

```yuyan
寻观「标准库」之书。

「取默认」乃承「甲」而化（「或可有」于「甲」）而化「甲」而「甲」也。
「取默认」者受「甲」而会「可」而会「默认」而
    鉴「可」而
        有（「可有」于「物」）则「物」
        或有「可无」则「默认」也。

「翻倍」乃化「整数」而「整数」也。
「翻倍」者会「数」而「加」于「数」于「数」也。
```
