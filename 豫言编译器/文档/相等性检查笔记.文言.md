# 相等检查

以下录相等检查之推演规则，供类型检查之参。

## 一、自由变量

```
bool : {type | [] -> [bool] } |- bool : {type | [] -> [bool]}
--------------------------------------------------------------
bool : {type | [] -> [bool] } |- bool = [bool] : type
```

## 二、静态外延强制转换

```
 bool : {type | [] -> [bool] }, false : { <| [bool] |> | [] -> [false]} |-


 |-  false : { <| bool |> | [] -> [false]}
-----------------------------------------------------------------------------------------------------
 |- out([false], false) : <| bool |>
```
