# 豫言操作系统底层显示 0.1.0

状态：草案，可选能力，2026-10-01 随底层接口 0.2 加入。文言本见[文言版](规范.文言.md)。通用规则见[调用约定](../调用约定.汉语.md)，状态码表见[底层基础](../底层基础/规范.汉语.md)，初始句柄表与类别见[底层句柄](../底层句柄/规范.汉语.md)。设计缘由见[原生窗口方案](../../豫言操作系统/文档/原生窗口方案.汉语.md)。

## 范围

显示面（窗口或屏幕上的一块画面）的尺寸、像素比、整幅画面的提交、指针与键盘等输入事件、输入法候选框的位置。语义与 GC 接口的[显示接口](../../豫言操作系统接口/显示/规范.汉语.md) 0.2.0 一一对应，GC 垫层把它们直接接过去。绘制（方框、文字、控件）、命中测试与焦点都在上层，不在本包。平台没有窗口系统时所有函数返回 58。

## 授权

显示面照“句柄即能力”授予：启动方把授予的显示面放进初始句柄表，类别为 **8（显示面）**，名字就是显示面名；程序用底层句柄的 `取初始句柄` 列举，按名字找到句柄。窗口在第一次用这个句柄时才建出来，标题为显示面名。

原生宿主用命令行选项授予（写在程序参数之前，与诺节宿主同名同义）：

- `--授权显示面 名=宽x高`：宽、高是逻辑尺寸（点），可重复；
- `--显示面后台`：窗口不激活、放在其他窗口之后（不抢前台），供自动验收。

关闭显示面用底层句柄的 `关闭`。

## 函数（`显示。接口。豫`）

| 函数 | 参数 | 作用 |
| --- | --- | --- |
| 显示面尺寸 | 句柄, 出 | （宽，高）共 8 字节写入出址，物理像素；随窗口缩放、换屏改变 |
| 显示面像素比 | 句柄, 出 | （物理数，逻辑数）共 8 字节写入出址；比 = 物理数 ÷ 逻辑数，Retina 屏为（2，1） |
| 提交画面 | 句柄, 宽, 高, 址, 长 | 像素为 RGBA8、直通透明度、逐行自上而下；长 ≠ 宽×高×4 返回 28；宽高与当前尺寸不符返回 6 |
| 取显示事件 | 句柄, 址, 长, 出 | 阻塞到有事件，把一条事件记录写入（址，长），记录字节数写入出址；缓冲不足返回 61，出址写所需长度，事件留在队列里 |
| 设输入区域 | 句柄, 横, 纵, 宽, 高 | 提示输入法把候选框放在这个矩形旁，物理像素，原点在左上；做不到照常返回 0 |

常见状态码：句柄无效或类别不符 8；显示面已被用户关闭 72；窗口系统暂时不可用（如没有图形会话）6；平台没有显示 58。

## 平台

- **macOS**：AppKit 窗口（运行时载入框架），画面设给内容视图的图层，事件取自应用的事件队列，输入法经一个透明的文本视图；详见[原生窗口方案](../../豫言操作系统/文档/原生窗口方案.汉语.md)第七节。
- **Linux、Windows、裸机**：暂无，返回 58。

## 未决

- 显示面句柄还不能放进底层句柄的 `等待`；程序同时等显示事件与其他句柄时只能轮流取。
- 没有尺寸改变事件：窗口缩放后，程序在下一条事件后重读尺寸（与 GC 显示接口相同）。
- 窗口标题、图标、可否改尺寸都由平台定，本包不设函数。
