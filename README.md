# 豫言

专为中文编程设计的高级函数式通用编程语言。

当前仓库使用自托管编译器，并通过连续自举包保持可重复构建。

[网站](https://yuyan-lang.github.io/yuyan/) · [快速开始](文档/快速开始.md) · [语言规范](文档/语言规范.md) · [设计动机](文档/设计动机.md)

## 综述

本科研性质的项目旨在解决如下问题：

1. 一个中文编程语言可以以何种形式存在？
2. 编程中的概念应当如何在中文语境中表达？
3. 中文语法和语义可以在何种程度上帮助程序写作？
4. 编程语言在全中文环境下会遇到哪些技术问题，应当如何解决？
5. 中文的概念和表达又会给编程语言本身带来哪些新的发展？

作者相信，编程语言的设计本身并非完全是一个科学问题，也是一个艺术问题。本项目若可以为朋友们提供一些设计中文编程语言技术与艺术方面的思路，也就实现了本项目的初衷。感谢大家一路支持与陪伴！

更多背景见[设计动机](文档/设计动机.md)。安装、编译和运行方法见[快速开始](文档/快速开始.md)。
