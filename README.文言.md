# 豫言

夫豫言者，函数式之语言，兼高级而通用；为中文编程而作，本函数之道以成。

此仓今以自托管之器而成，复赖连续自举之包而可复。

[网站](https://yuyan-lang.github.io/yuyan/) · [豫言赋](文档/豫言赋/总目.md) · [快速开始](文档/快速开始.文言.md) · [语言规范](文档/语言规范.文言.md) · [设计动机](文档/设计动机.文言.md)

## 综述

斯业为科研而兴，所求解者五端：

1. 中文编程之语，当以何形而立？
2. 编程之概念，当以何辞而表？
3. 中文之语法与语义，助程序之写作几何？
4. 全中文之境，将遇何技术之难，当何以解之？
5. 中文之概念与表达，予编程语言以何新进？

盖编程语言之设，非独科学之题，亦艺术之业也。科学求其真，艺术求其美。此业若能以技术之思、艺术之心，稍裨中文编程之设计，则初衷遂矣。诸君相扶，谨致谢忱。

欲详其背景，见[设计动机](文档/设计动机.文言.md)；欲知安装、编译、运行之法，见[快速开始](文档/快速开始.文言.md)。
