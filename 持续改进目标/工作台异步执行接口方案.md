# 工作台异步执行接口方案

日期：2026-10-08。状态：用户已批准实施，并授权为既定任务自行扩展豫言操作系统接口。对应《豫言工作台设计》会话任务状态、构建运行与停止需求。

## 现有依据

`豫言操作系统接口/子程序/子程序。接口。豫` 已有具名授权的同步运行接口、带退出码和两路输出的结果类型，以及终止接口。宿主已有标准库异步子进程启动、尝试收取与终止桥接。实施复用原生进程能力及现有具名授权检查。

## 拟扩展接口

| 操作 | 输入 | 返回 |
| --- | --- | --- |
| 启动具名授权子程序 | 授权名称、参数列表、输入字节、环境列表 | 已启动的整数句柄，或系统错误 |
| 尝试收取具名授权子程序 | 本实例获得的整数句柄 | 运行中、已结束的退出码及标准输出与标准错误，或系统错误 |
| 终止子程序 | 本实例获得的整数句柄 | 沿用现有返回码；终止后继续收取退出结果 |

启动沿用同步接口的程序解析、参数及环境授权、工作目录和输入方式。句柄由当前实例持有；收取立即返回当前状态。完成结果沿用现有字节输出表示，首次成功收取完成结果后释放句柄。

第一阶段按完成结果展示两路输出。增量输出作为后续扩展；会话任务状态可在启动、运行中、停止请求及完成节点保存。

## 工作台接入

1. 检查、类型检查和构建从同步调用改为启动任务。保存任务来源文件、包、命令与句柄，结果仍进入现有构建面板。
2. 会话文件保存任务身份与可展示状态。句柄保存在应用内任务表，标签关闭及重开通过任务身份重新绑定；应用退出后的恢复按提案留待后续。
3. 界面事件循环调用非阻塞收取，完成时记录退出状态、输出及诊断。刷新调度复用现有能力；所需的操作系统接口缺口按最新仓库授权补齐。
4. 停止按钮复用现有终止接口，并继续收取，最终记录实际退出结果。
5. 模型执行采用相同任务状态流程；实际模型服务配置与模型网络执行方式单独核验。

## 实施与验证

实施时同步更新双语规范、接口清单及各适配声明。原生实现优先，诺节复用相同原生能力；现有诺节桥接仅作行为核对依据。

后台验收使用专用授权程序和临时目录：启动后立即得到运行中状态、完成收取两路输出、非零退出、启动失败、无效句柄、停止后收取、完成句柄释放。工作台验证执行期间继续编辑、关闭重开会话恢复任务、完成后打开诊断且保持脏缓冲。全部测试不抢占前台窗口。
