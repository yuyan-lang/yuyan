# 浏览器正式版（1.0）与一体引擎

目标：发布浏览器 1.0，并把网页引擎与系统界面、设计引擎合成一套（提案 00052《浏览器即系统》）。

用户 2026-10-24 定：尽一切所需让浏览器接近 1.0，加库、加接口都准；避免重复代码、做到统一体验——浏览器就是系统，系统就是浏览器，只是系统吃 `设计。豫`，浏览器吃 HTML、CSS 与 JS。

完成判据见提案 00052 第四节（拿得到、外壳齐、载入与性能、画得对、记得住、够标准、是一体）。一致性各方向的通过率仍记在 `网页与设计引擎.md`。
