# 设计语言前三期

目标：实施提案 00018《设计语言与引擎》的第一、二、三期（提案第二十一节），做到各期验收。用户 2026-10-13 布置，同日要求立为长期目标，做完前三期再停。

由本目标的会话负责；用户在接手时授权派子代理，各子任务使用独立工作树。每一步（或几步一组）用自己的工作树 `~/repos/yuyan-worktrees/<名>`，做完跑最便宜而有用的检查，提交、合入 yybs、`git push origin yybs`，再删工作树与分支；推送后不等 CI。

## 步骤

第一期「矢量动画」：基础实现与动画验收已完成；组件定义与实例的数据保留、去重已实现，普通用户组件调用的自动捕获与还原继续补齐（见“进度”）。

第二期「声音与文字」：

1. 声轨：采样片段（用现有解码器）、合成图、乐谱、事件；确定性混音器（48 千赫，各端逐样本一致）。
2. 接口「豫言操作系统声音输出」0.1.0（打开流、写样本块、已播放样本数与延迟、关闭；授权同显示面）与各平台实现；同步规范、实现与接口清单。诺节只当胶水，不引第三方库。
3. 文字轨：字幕、说明字幕、章节、口述影像；烧入绑定；检索与复制（壳命令）。
4. 字体子集嵌入；边下边播与跳转（跳转索引、素材块按首次用到的时刻排列）。
5. 导入 SVG、Lottie、WebVTT、SRT。
6. 图形处理器二维渲染器（着色语言、接口「图形处理器」「图形显示」）。
7. 精排基础：最优断行、连字符、中文排版规则、数学排版；字幕与正文共用。

第三期「交互、界面与文档」：

1. 输入能力、状态机、过渡混合、快照、输入日志与录屏。
2. 界面并入第一步：设计语言覆盖界面的全部元素、样式与事件（不动界面内部实现）。
3. 与提案 00009 对接：网页绘制输出引擎二维显示表；合成层动画交给引擎。动 `库/基础库/网页` 的网页绘制前先与 codex 协调。
4. 网页到设计语言的静态编译与快照编译。
5. 文档：文档组件、页面模板与分页、浮动体、脚注、编号与交叉引用、目录、索引、参考文献；PDF 导出；.tex 导入；豫言官网与文档由标记文直接生成设计作品。

## 验收

- 第二期：有声样例三端逐样本一致；边下边播的首帧时间有记录；图形处理器与参考渲染器的像素差在容差内。
- 第三期：设计语言重写界面示例（待办清单）行为一致；官网静态页编成设计作品后排版一致；交互样例按输入日志重放逐帧一致；含公式、定理、交叉引用与参考文献的中文论文样例导出 PDF，与 LaTeX 排版并排比较版面接近；同一作品分页显示与“转连续”显示都正确。

## 规矩

- 能凑合着用就行：每步只做最小可用的实现，边角情形留“待办事项”注释。
- 提案里的未决问题一律按第二十节“默认办法”做；语言详案第十八节的待确认写法先按推荐写法实现，不为这些停下来问用户。
- 图形程序守 AGENTS.md「图形程序」：每个可操作项先有壳命令（库「壳命令」，豫言操作系统的做法登记在 `库/用户态桌面/命令壳。豫`，候选在 `库/壳核心/命令登记。豫`），播放器只当监视器。
- 测试数据只写豫言，不新增结森或二进制测试文件；合入前的冒烟测试不超过 5 分钟；三端核对等重活合入后再跑或交 CI。
- 节省用量：长构建放后台、不频繁轮询，大文件只读需要的段落。
- 每期做完：在提案 00018 末节进度表记状态与提交号，并向用户简报做了什么、还差哪些验收。
- 用户叫停即停。
