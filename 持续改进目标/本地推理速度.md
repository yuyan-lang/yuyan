# 本地推理速度

目标：纯豫言深度学习推理的预填充与单路解码（批量为一）都达到或超过 Ollama。比较条件是同一台机器、同一个 GGUF 模型、同样的量化、提示与生成长度，并核对输出相同。先在 pit-mac（金属）追平，pit-pc 的统算放在之后。用户已授权深度学习快速推理所需的后续 ABI 拓展。

## 现状（2026-10-05，暂停）

用户要求暂停，目标未达成。设备为 pit-mac（M2 Max，30 核 GPU），Ollama 0.34.4。模型 Qwen3-0.6B Q8_0，SHA-256 `31db9797248620627b127c47c75caa76ec2ce9b7de9dc0f2faca02ba59615818`；30b 为 qwen3-coder:30b 的同一 GGUF。

单位词元/秒。长提示预填充约为 Ollama 的 74%，解码约 55%；短提示预填充约 25%，解码约 54%；30b 解码约 38%。

口径：
- 豫言解码计预填充首词之后的 63 次前向，Ollama 计 64 个生成词元；各自沿用自报的词元/秒。
- 长提示长度换过多次（641 → 653 → 505 → 1984；1984 为 505 词元提示重复四次），跨日数字不可直接比；短提示前后口径相同。
- Ollama 请求设 `keep_alive:0`、关提示缓存，测前测后核对无驻留模型；Ollama 解码在 171–207 间波动。

### 瓶颈判断

- **解码卡在 GPU 执行**：短提示每词元 GPU 约 7.6 毫秒、墙钟 8.1 毫秒，命令段之间的空档只有 11–19 微秒，时间花在 GPU 执行本身。1984 上下文时注意力约占 41%、Q8 投影约占 42%（之后注意力已压缩）。同样的权重分 28 次派发比 1 次慢约 50%；小矩阵派发太碎是主因，核内微调已近饱和。
- **预填充**：1984 词元已到 Ollama 的 74%，没有新的耗时分解。短提示预填充仍差约 4 倍；30b 预填充时每个（词元，专家）都重读一遍专家矩阵。
- 矩阵向量乘曾只用到约四分之一的显存带宽（10-01：27b 约 90 GB/s 对 Ollama 约 270 GB/s）；此后双行核与分段提交改善了解码，带宽利用率没有重测。
