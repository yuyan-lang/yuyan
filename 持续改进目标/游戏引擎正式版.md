# 游戏引擎正式版（1.0）

目标：发布游戏引擎 1.0，把实时三维（界画）、设计语言引擎（匠心）与九州游戏里自写的运行时接成一套游戏引擎，与浏览器 1.0 并行推进、同守提案 00052《浏览器即系统》的一体方向（避免重复、体验统一）。

## 第一款游戏（用户 2026-10-24 定）

GTA 式写实城市游戏，细节要细，只画线（lines only）。九州会话管城市线稿内容与游戏程序（私仓），本目标管引擎库。由此先后改为：界画三维线渲染器（消隐线、按类样式、虚线、抗锯齿，整城几十万段六十帧，图形处理器走图枢、中央处理器后备）→ 相机（Blender 式环绕、GTA 式第三人称跟车与步行）→ 按块流式加载与远近分级；贴图、半透明、物理材质往后放。线稿交给渲染器用界画里新立的公共类型（暂名「线景」），九州在边界上把私仓的「笔」转过来。

## 完成判据

1. 九州同一份源码在林檎与林纳上用图形处理器跑满六十帧（1920×1080），带纹理与半透明。
2. 手柄与键鼠都能玩（动作映射），有存档，有屏上界面（HUD）。
3. 游场、游环、质测、操纵、动作、声图各库有测试，九州改用它们，私仓里自写的循环、相机、碰撞与 HUD 退役。
4. 屏上界面与菜单走匠心映元（与浏览器、系统界面同一张显示表）。

## 定论（据 2026-10-24 普查，报告在 `/Users/zc/repos/yuyan-worktrees/豫言数据/任务书/钩深/游戏引擎普查.汉语.md`）

- 实时三维以界画为主干（已有图形处理器、实例化、三级级联阴影，九州在用）；匠心三维退为参考与离线，材质、光照、阴影抽成两边共用的篇。
- 相机以界画的「景镜」为唯一，设计求值时转换。
- 主循环抽成游环（固定步长、插值、事件泵、暂停与重放）；碰撞、射线、角色与载具抽成质测；九州改用。
- 屏上界面以映元为唯一；粒子、布料、溯光路径追踪、骨骼、空间声音留在匠心，迁入实时道时共用同一份。
- 新库放 `库/群书/游艺部/`（游戏引擎诸库父包），各库自己登记进它的「包含包」。

## 做法

- 与浏览器 1.0 相同：钩深（DeepSeek）各路做，Claude 写任务书、审查、逐路合入；先出功能、只做针对功能的冒烟，退步以后集中处理；优先派构建小的活（库测试与探针）。
- 九州会话（中国全景开放世界项目）10-24 回信：它那边各路眼下都在私仓路稿，不碰界画，界画第二期由本目标派；抽库要守：热循环整数定点、只用整数散列随机不读时间、拍照无窗口走中央处理器且林纳能跑、库接口只收通用数据（占用格、碰撞体、网格）不依赖私仓类型、九州入口先不动，库稳了九州自己换。
