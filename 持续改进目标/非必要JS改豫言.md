# 非必要 JS 改豫言

2026-10-10 立项（用户：“把非必要的 JS 代码，比如云端验证，全部换成豫言写作”）。10-11 晚由 Claude 接手（原执行者为 codex 代理），先纠正了前段的过度移植与非豫言夹具，再按下文“剩余清单”继续。

## 目标与完成判据

- 语言仓与云仓里，除“保留清单”外，不再有项目自写的 JS：验收、测试、一致性验证、工具脚本、页面脚本都改成豫言，或确认无用后删除。
- 云仓 npm 依赖只剩 wrangler。
- 改写后的测试在本机实跑通过；云仓构建程序或 CI 能跑的都接上（语言仓 CI 没有 wrangler，真 workerd 测试在 `应用/开发工具/全树测试/测试规则.tsv` 登记“只检查”）。

## 用户的决定

- 10-10：方案照办、不先写提案。三层：①删死的与无人调用的；②工具宿主上的豫言验收驱动（`库/验收驱动`）替“起本机 wrangler dev 再经 HTTP 检查”的测试；③宿主模式「模拟」（各接口绑纯豫言内存实现）替 jsdom 类与“云工宿主加假 env”类。差分回放退役；宿主白盒单测随宿主留 JS；模拟宿主的关系数据库是 SQLite 兼容的嵌入数据库。
- 10-11：不得新增测试用的 JSON、SQL 等非豫言文件。测试数据、固定期望、数据库种子与生成器都写成豫言；已有的正式数据库迁移照常通过原接口执行。

## 写法约定（10-11 纠偏后定）

- 只搬核心场景：每个旧 JS 测试改写时保留它验证的主要行为与关键边界，搬完即删旧 JS。不逐条照搬断言，不加旧 JS 没有的检查，不搬随机语料与穷举组合（AGENTS.md“测试从简”“能凑合着用就行”）。
- 测试数据写在豫言里：小的直接写成豫言值（字符串、结森构造、列表）；大的（大文件、大批记录、压缩流）在测试运行时用豫言生成，不把生成结果入库。数据库种子写成“插入语句 + 各行参数”的豫言值，逐行绑定参数插入。
- 不往正式适配或库里加只为测试服务的钩子（故障注入、调用记录等）。只有 JS 假对象才能做的故障注入用例直接去掉。
- 进度只在完成一项时记一句；不为每一小段单独开分支、提交、合入。
