写启动 U 盘（在本机执行，盘号每次重新认）：

```bash
diskutil list external physical
```

```bash
diskutil unmountDisk /dev/diskN
```

```bash
sudo dd if=/Users/zc/repos/yuyan-worktrees/baremetal-hardware/yy实测镜像/yy裸机实测-a86fdf58a.iso of=/dev/rdiskN bs=4m
```

```bash
diskutil eject /dev/diskN
```

壳默认是中文组字：敲拼音出候选，空格或回车选第一项，数字键选第几项；`}` 是 Shift+]。下面“→”后是这一步做完时命令行应显示的样子。

1. **启动**：关机状态插好启动 U 盘与数据 U 盘（苹果再接外接键盘）。苹果开机按住 Option 选“EFI Boot”；E40 开机按 F12 选 USB 启动项。先出现“USB插拔”与一组 USB 诊断行，约三十秒后出现“命令壳已就绪”与 `壳>`。拍一张整屏。
2. **中文输入**：`h` `x` 空格 → `「回显」于`；`n` `i` `h` `a` `o` 空格 → `「回显」于「你好」`；回车 → 下一行显示“你好”。苹果上内置键盘、外接键盘各做一遍。
3. **写入**（只在数据盘上第一次做；若第 4 步已能读出“你好”，说明写过了，跳到第 4、5 步）：`w` `j` 空格 → `「文件」之`；`x` `r` 空格 → `「文件」之「写入」于`；`c` `e` `s` `h` `i` 空格 → `…于「测试」`（这个右引号是自动补的提示，光标还在引号里）；按 `}` 越过它；`y` `u` 后按 `3`（选“于”）→ `…「测试」于`；`n` `i` `h` `a` `o` 空格 → `…于「你好」`；按 `}`；回车 → “已写入 6 字节”。
4. **读取**：`w` `j` 空格；`d` `q` 后按 `2`（选“读取”）→ `「文件」之「读取」于`；`c` 后空格（选已有文件名“测试”）→ `…于「测试」`；回车 → “你好”。
5. **重启回读**：长按电源关机，再按第 1 步启动，做第 4 步，应仍得“你好”。拍照。
6. **苹果热插拔**：进壳后拔掉外接键盘，等两秒插回，再等约十秒，屏幕会追加一组 `USB HOT`…`USB P05` 诊断行，拍下；然后用外接键盘做第 2 步，记下能否输入。
7. **E40 的 USB 键盘**（若有外接 USB 键盘）：开机前接好，做第 2 步；再试拔插（EHCI 没做热插拔，预期失败，记下现象即可）。

先不要用「文件」之「列出」与「追加」（见已知问题）。每台记下：机型、启动方式、第 2–6 步结果与照片；苹果与 E40 分开记，不互相代替。
