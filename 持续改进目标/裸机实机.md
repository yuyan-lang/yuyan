# 裸机实机

目标：豫言裸机系统在真实笔记本上日常可用——启动、显示、中文输入、USB 键盘（含热插拔）与 USB 存储持久化。实机是苹果 MacBookPro11,1（2013）与 ThinkPad E40。

这条线 10-03 至 10-05 由 codex/baremetal-hardware、codex/苹果USB诊断、codex/苹果实测镜像基线（工作树 苹果二零一三启动）、codex/baremetal-terminal-edit 几个分支推进，全部已合入 yybs。本文件是汇总入口，细节在 `豫言操作系统/裸机/文档/` 下各篇。

## 现状（2026-10-06）

- **启动盘超限已解决**：AMD64 把嵌入壳的大被动段移到虚拟、物理都从 0x400000 起的 2 MiB 大段区（存储镜像、兼容核心；见 `文档/元数据布局.汉语.md`「AMD64 大段区」）。未改前 yybs 报代码 726515 字节、可用 181392 字节；改后 yybs 直接生成启动盘。QEMU（Q35、Haswell、TCG、512 MiB）从 xHCI USB 启动：SeaBIOS 与 OVMF 都进壳，拼音 `hx`、`nihao` 回显“你好”；关 PS/2 只接 USB 键盘时，进壳后拔插键盘，壳阶段追加 USB HOT 快照，新键盘输入可用。`yy裸机验证` 380 项双架构全过（顺带修了「控制台行原子」把开机诊断行误计为坏行的旧问题）。
- **壳的文件命令卡在客体二号**：10-05 起原壳改走用户态桌面的公共文件服务。图形界面线已合入写入原语与裸机“桌面”授权（bca15e060），但 QEMU 里「文件」之「列出」/「写入」仍报“目录未获授权”：授权在 `挂载磁盘` 之前打开根目录，查不到“/”。已把根因与改法告知图形界面会话（客体二号归他们改），等其修好再验写入、读取与重启回读。壳里「运行」子程序在裸机上明确返回未获授权（图形界面线不做裸机子程序）。
- **ARM64**：嵌入当前壳仍超限（`构建`、`运行 --架构 臂六十四` 和普通豫言验证的臂六十四壳项都受影响），待办。
- **苹果 MacBookPro11,1**：启动、显示、内置与外接键盘、开机前同时接两把键盘都已实测通过（fbeac0d13、04b6cadfa）。进命令壳后插拔外接键盘失败：启动后三十秒观察窗口内拔插能恢复，窗口结束后不能；内置键盘始终可用。动态热接诊断镜像已备：`苹果二零一三启动/yy苹果动态热接诊断.iso`（SHA-256 `3ab154b0033102bbf85cd9ff726e1a8911d11e79ec44d36fff3a8388c1090c57`），待用户实测。
- **ThinkPad E40**（EHCI 加集线器）：只有旧版英文壳与内置键盘经用户确认；EHCI 只在 QEMU 验过，新版中文镜像没上过真机。
- **USB 存储**：双超级块选盘镜像 `苹果二零一三启动/yy超级块选盘.iso`（SHA-256 前缀 cf82c2）在 QEMU 经 SeaBIOS 与 OVMF 的持久化回归通过；实体数据 U 盘已备好并只读回读校验（5806ed385）。两台真机的实体写读都还没做。
- **终端**：默认中文组字、花括号输入角引号、按未闭合层级选引号（c804c741c）、中文显示与基础拼音输入（56967f6dc）已合入；分词、词频、字体选择只有方案。
