# 网页界面之约 0.1.0

有标识元素与事件队列之宿主，乃可具此包。浏览器以文树行之；他宿主能守同约，方得自称具之。客依此包，四术皆须备，阙一则拒装。

读页面语言，取根界之 BCP 47 语标；未设则空文。设置节点文字，以标识求既有元素，纯文代其文，不析 HTML。设置节点属性，惟许 `data-`、`aria-` 之首或 `href`；名限 ASCII 小写、数与横线，`href` 值限 `http://`、`https://`、`/` 或 `#` 起首。元素阙、名或址非法，皆报调用失，不可伪称已成；毋因设值而行事件之码。

等待界面事件，依宿主接收之序取一事，返“事名、目标标识”二文；无标识则后文空。此术可候，客不得因之得原生文树之柄。队列既闭，返“关闭”与空文，其后亦然。首版未定捕获、冒泡、默认动作、定时、造节点及任意选择符。

诸术惟及此界面实例；标识不得越界。文皆豫言字符串，失调用从[共同执行契约](../执行契约.文言.md)。
