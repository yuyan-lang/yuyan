# 网页界面接口规范 0.1.0

本包适用于提供带标识元素和事件队列的宿主。浏览器可用 DOM 实现；其他宿主只有在能提供相同语义时才声明此包。应用依赖本包后，四个函数都必须实现，缺少任何一个函数时不得装载。

`读取页面语言` 返回根界面当前的 BCP 47 语言标签，未设置时返回空字符串。`设置节点文字` 按 ID 查找一个已经存在的元素，用纯文本替换其文字内容，不解释 HTML。`设置节点属性` 只接受 `data-` 或 `aria-` 开头的属性名，以及 `href`；名称须为 ASCII 小写字母、数字和短横线组成，`href` 的值须以 `http://`、`https://`、`/` 或 `#` 开头。标识不存在、属性或地址不合规时报告调用失败，不得把失败当作成功。名称和值按原文保存，宿主不得隐式执行事件处理代码。

`等待界面事件` 按宿主接收顺序取一个事件，返回“事件名称、目标元素 ID”二元组；目标没有 ID 时第二项为空字符串。调用可挂起，应用只能从已授权的界面事件队列读取，不得由此取得原生 DOM 对象。宿主关闭队列时返回名称“关闭”、空 ID；之后的调用继续返回相同关闭标记。首版不规定事件捕获、冒泡、默认动作控制、定时器、节点创建或任意 CSS 选择器，它们须由后续能力包或本包下一版本定义。

所有操作只作用于当前界面实例。宿主必须按界面实例隔离元素和事件；应用不能凭另一个实例的 ID 操作其元素。输入和返回的字符串均为豫言字符串，调用出错遵循[共同执行契约](../执行契约.汉语.md)。
