# 公共控制台

此为具名授权之行入与原文输出接口。客常用“主控制台”，宿主明供其能，未供则还未获授权。接口不析命令，不求显示面，不依内核之物。

`读取控制台行` 候次行，还无 CR/LF 之原文；空行犹为行已得，流尽或页闭则还输入结束。一台同时惟许一读之候，重候则还输入无效。宿主闭必终已有之候。适配层宿主原语读之果必标异步返回，许浏览器悬而候页事；客层之果犹为寻常代数型，由既有异步边界之制复行。

`写控制台文本` 写全原文，不附新行，成则还已写，败则还系统错误。写不司逐行编辑、拼音、历史及 GUI 切换；此皆由既有壳与桌面程序治。

首版不定逐键输入与单候之取消，犹待适配实后验。Node 接实标准入出，浏览器接明授之页行入出；平台无能须明报，不可以空入伪输入结束。
