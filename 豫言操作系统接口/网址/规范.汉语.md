# 网址接口规范 0.2.0

`编码网址成分` 接受一条豫言字符串，按 UTF-8 字节进行百分号编码。ASCII 字母、数字及 `-_.!~*'()` 原样保留，其余字节写成大写十六进制的 `%HH`；例如 `a/b` 得 `a%2Fb`，`函数` 得 `%E5%87%BD%E6%95%B0`。结果只是一段成分文字，不含查询键、等号或完整网址。输入中有不能表示为有效 Unicode 标量的内容时报告调用失败，不做有损替换。

`解码网址成分` 把 `%HH` 序列按严格 UTF-8 解为文字；不完整的百分号、非十六进制数字和非法 UTF-8 均报告失败。`+` 保持加号，`%2F` 解为斜线，调用方在使用路径段前仍须自行验证解码后的斜线、反斜线和控制字符。它不解析完整网址。

两函数无权限要求、无外部副作用。浏览器、Node.js、CF Worker 和原生宿主均可实现；即使某宿主用本地纯豫言代码实现，公开签名与结果也须一致。本版不含完整 URL 解析及 IDNA 域名处理。
