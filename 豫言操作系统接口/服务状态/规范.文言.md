# 服务状态公约 0.1.0

`读取授权服务状态` 受获授服务名、绝对 `https:` 址与请求诸头，行一次 GET，惟返 HTTP 状态。宿主依资源许可核服务名；未授、坏址、坏头或服务失，则调用败。适配不暗转原请诸头，惟送所授之列；改址不自随。

此包不以响应之文、头或流授客，亦不授任意外网之权。头至多十六项，名与值由平台 HTTP 验之，UTF-8 合量不逾八 KiB。鉴权、康检仅需状态者可依之；欲读文或转原流者，别依相应能力。

补（路由代理之修）：服务绑定之 `fetch` 抛出或返被拒之 Promise，`读取授权服务状态` 不复使宿主之异越 Wasm 之界而败全事，乃告可捕之豫言异常，辞以 `服务状态请求失败：` 起，继以 `名称: 消息`。此与“服务异则调用败”相合，惟败今可为应用所捕而改答五百零三。不改术之型，不升版。
