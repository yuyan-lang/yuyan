# 服务状态接口规范 0.1.0

`读取授权服务状态` 接受已授权的服务绑定名、绝对 `https:` 网址和请求标头列表，发送一次 GET，返回 HTTP 状态码。绑定名由宿主资源许可核对；未授权、网址无效、标头无效、服务异常时调用失败。适配不转发原请求的任何标头，只发送参数列表指定的标头；重定向不自动跟随。

本包不提供响应正文、标头或流给应用，也不授予任意外网访问。允许的标头最多 16 项，每项名称和值由平台 HTTP 实现验证，名称和值的 UTF-8 总量不超过 8 KiB。此能力适合权限、健康等只需状态的内部检查；需要读取内容或原流转发的应用须另依相应能力包。

补充（路由代理修订）：服务绑定的 `fetch` 抛出或返回被拒绝的 Promise 时，`读取授权服务状态` 不再让宿主异常穿过 Wasm 边界使事件失败，而是抛出可捕获的豫言异常，消息以 `服务状态请求失败：` 起首，其后是 `名称: 消息`。这与“服务异常时调用失败”一致，只是失败现在可被应用捕获并改答 503。不改函数签名，不升版本。
