# 持久事务之约 0.1.0

此包惟供获授之当前久仓。`执行持久事务` 以有效 JSON 文为参，于同仓调用客之事务入口，成则返其所定 JSON 果文。入口以 `读取持久事务参数` 取参，以 `读取持久事务键值`、`写入持久事务键值` 行键之读写。读返有无之爻与值文：缺键为阴与空文，已存 JSON null 为阳与 `null`。`完成持久事务` 每事必且惟一成功。输入 JSON 宿主必析验，输出非 JSON 则败。

诸读写属同一原子事务；客抛错、无果或仓败，则诸写皆撤。同仓并事须串行，或得等价可串行之果。键与值由客定；宿主不得露异仓或异事之态。离事务入口而取参、读写、定果，皆败。初版借标准库字符串载 JSON 值，客可用豫言 `癸象` 自析自造；此文界为 `_start` 重入之过渡，不许二进制与宿主物柄。

今编译入口犹为 `_start`，云工适配借事务事类重入豫言；客循[网页入站之约](../网页入站/规范.文言.md)辨事。此重入乃适配之术，他日可换类型化回调，原子与值义须存。
