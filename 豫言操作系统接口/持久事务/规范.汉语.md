# 持久事务接口规范 0.1.0

本包只用于已授权的当前持久仓。`执行持久事务` 接受有效 JSON 文字，在同一仓内调用应用的事务处理入口，成功时返回入口设定的 JSON 结果文字。事务处理入口通过 `读取持久事务参数` 取得本次参数；通过 `读取持久事务键值` 与 `写入持久事务键值` 操作当前事务的键。读取返回存在标记和值的 JSON 文字，缺键返回阴与空字符串，已存储的 JSON null 返回阳与 `null`。`完成持久事务` 每次事务必须且只能成功调用一次。输入 JSON 由宿主解析验证，输出须为有效 JSON；无效文字调用失败。

所有读写属于同一个原子事务：处理入口抛错、缺少结果或存储失败时，已写入的键不得提交。一个仓内并发事务须串行化或提供等价的可串行化结果。键名和存储值由应用定义；宿主不得把另一个仓或另一次事务的状态暴露给调用方。事务处理入口之外调用参数、键值或结果函数须失败。首版以标准库字符串承载 JSON 兼容值，应用可用豫言 `癸象` 在自身逻辑中解析与构造；此文字边界是 `_start` 重入期间的过渡，不承诺二进制或任意宿主对象。

当前编译入口仍是 `_start`，云工适配通过事务事件重新进入豫言程序；应用据[网页入站接口](../网页入站/规范.汉语.md)的事件种类选择处理入口。此重入方式是适配实现，后续可以换成直接调用类型化回调，应用所见的原子性与值语义不变。
