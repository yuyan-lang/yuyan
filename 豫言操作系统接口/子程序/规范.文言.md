# 子程序接口 0.3.0

零点三版增 `终止子程序(异步句柄)`，柄由今宿主实例之标准库异步启服所得。请强止而留其记与二出，呼者续收退果。码零成、八柄无效、二十九宿主败、五十八今平台未支持；已毕而未收者亦成。柄惟识今实例所录之子程。

工具节点与原生执行器共用标准库异步柄及底层进程之止。浏览器还五十八。后续之事：裸机动态任务之止、应用宿主之异步启止。

零点二版增 `运行继承输入子程序(名称, 参数列, 环境)`，标准入继调用者，标准出与误犹捕而终乃还。同具名程序之授、环境之授、退出之果与交换之限；不继父进程环境。节点宿主继己标准入之文件描述符，其间暂止宿主原始编辑之制，终或启败则复；宿主行读不先取下一行。浏览器无此能则明返暂不可用。待办事项：原壳全输入会话之接、异步输出与取消。

此为具名所授用户态发行程序执行之接口。`运行子程序` 以名、参列、标准输入字节及环境名值对行宿主预授之程序。客不得指任意宿主之令，不得以参易宿主选项。环境名别须授，调间不留环境，不自继父环境。复环境名、零字及非法名返 `输入无效`；未授程序或环境返 `未获授权`。

常终返 `子程序已结束`，依次载退出码、标准输出与标准错误字节。非零退出亦为终果。启动、信号终止、逾时诸败返 `子程序未执行` 而载系统错误；此名谓未得常终之果，程序或已启而生副作用。交换逾限返 `资源配额已尽`。输出为原字节，客自解其文。

节点以今 Node 行预授发行之启动文，客参置 `--` 后，不调宿主壳。节点装载选项之环境不得为客所易。浏览器犹无子程序执行之实，当明返不可用。待办事项：异步取消、流式输出、余环境适配与原壳迁调。
