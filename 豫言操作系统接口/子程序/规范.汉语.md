# 子程序接口 0.6.0

0.6.0 增加 `取子程序输出(句柄)`：取出该句柄自上次取出以来新产生的标准输出与标准错误字节，取后清空；之后 `尝试收取子程序` 的完成结果只交出其余部分。桌面命令行用它在程序运行时随时显示进度。原生执行器先把管道里现有的数据读进异步表，再取出清空；裸机执行器取出子任务表里该项已收到的输出。节点与浏览器适配返回两段空字节，全部输出在收取完成时交出；节点的增量输出留待后续版本。无效句柄返回两段空字节。

裸机执行器支持 `启动子程序` 与 `尝试收取子程序`：程序名按文件系统路径解析（相对执行器的当前目录），子任务的两路输出由父任务捕获，给出的环境写成子任务的环境块。父任务在显示面的等待里同样收取子任务的输出与文件代办请求，所以桌面等键时子程序照常运行。输入字节传给子任务、裸机上的 `终止子程序` 留待后续版本。

`查询子程序资源(句柄)` 查询本实例尚未收取的子程序，保留句柄供最终收取。结果依次为状态、当前常驻字节可用爻、当前常驻字节、操作系统峰常驻字节可用爻、操作系统峰常驻字节，单位字节。状态零为成功、八为句柄无效、二十九为宿主失败、五十八为资源观测暂不可用。数值只在对应可用爻为阳时有意义；采样最大值由调用方另行累计并标为采样最大值。操作系统峰与采样最大值分别记录。

macOS 当前常驻字节通过单目标进程查询取得，原生回收时保存该目标的系统峰值。诺节工具宿主调用同一纯豫言底层查询模块，胶水调用操作系统自带系统库；具名应用查询转交原生子程序服务。查询已结束子程序时当前值可以不可用。浏览器返回资源观测暂不可用。Linux、Windows 与裸机资源后端列为后续事项。

调用方可以按采样间隔比较常驻字节与资源阈值，超限后调用 `终止子程序` 并收取结果。采样阈值是在实际观测超限时强制终止的门槛，操作系统瞬时硬限额列为后续事项。查询失败、超时与资源超限各自记录原因。

0.4.0 增加 `启动子程序(名称, 参数列, 输入字节, 环境)` 与 `尝试收取子程序(句柄)`。启动成功返回当前实例登记的整数句柄，启动失败返回系统错误。程序和环境沿用同步接口的具名授权，输入属于本次调用。

收取立即返回“子程序运行中”“子程序收取完成”或“子程序收取失败”。完成结果携带退出码、标准输出和标准错误原始字节，非零退出保留为完成结果；成功收取完成结果后释放句柄，后续查询返回资源已失效。停止复用 `终止子程序`，停止后继续收取最终结果。

原生执行器复用标准库异步表和管道收取，节点应用宿主通过原生子程序服务共用这份实现。当前输入沿用同步入口的 16384 字节交换范围。浏览器沿用资源暂不可用结果。后续事项：大输入分段写入和运行中增量输出。

0.3.0 新增 `终止子程序(异步句柄)`，句柄由当前宿主实例的标准库异步启动服务取得。它请求强制终止，保留记录与两路输出，调用方随后收取退出结果。结果码为 0 成功、8 句柄无效、29 宿主失败、58 当前平台暂不支持；已经结束而尚未收取的进程返回成功。句柄只标识本实例登记的子进程。

工具节点与原生执行器共用标准库的异步句柄及底层进程终止能力。浏览器返回 58。后续事项：裸机动态任务终止、应用宿主的异步启动与终止。

0.2.0 新增 `运行继承输入子程序(名称, 参数列, 环境)`，标准输入继承调用方，标准输出与标准错误仍捕获并在结束后返回。它沿用同一具名程序授权、环境授权、退出结果与交换上限；不继承父进程环境。节点宿主继承自身的标准输入文件描述符，期间暂停宿主原始编辑模式，结束或启动失败后恢复；宿主行读取不预取下一行。浏览器缺少该能力时明确返回暂不可用。待办事项：原壳完整输入会话接入、异步输出与取消。

这是具名授权的用户态发行程序执行接口。`运行子程序` 以名称、参数列、标准输入字节、环境名值对运行宿主预授的程序。应用不能指定任意宿主命令或通过参数修改宿主选项。环境名称须另获授权，调用间不保留环境，不自动继承父进程环境。重复环境名、零字及非法名称返回 `输入无效`；未授程序或环境返回 `未获授权`。

正常结束返回 `子程序已结束`，依次携带退出码、标准输出和标准错误字节。非零退出仍是结束结果。启动、信号终止、超时等失败返回 `子程序未执行` 携带系统错误；此名称表示未取得正常结束结果，程序可能已经启动并产生副作用。资源交换超过限额返回 `资源配额已尽`。输出为原始字节，文本解码由调用方负责。

节点以当前 Node 执行预授发行的启动文件，应用参数置于 `--` 后，不调用宿主 shell。节点装载选项环境不得由客体改变。浏览器尚无子程序执行实现，应明确返回不可用。待办事项：异步取消、流式输出、其他运行环境适配与原壳迁移。
