# 张量计算接口规范 0.1.0

本包声明宿主持有的张量与整块数值算子。应用依赖本包即要求宿主实现它。用哪种设备（CPU、GPU 或其他加速器）计算、宿主内部是否并行，由宿主决定，不改变本规范的结果语义。与文件、图形处理器互通的函数不在本包，放在桥接包里（如[张量文件](../张量文件/规范.汉语.md)）；本包只依赖基础包。

## 资源与寿命

- 张量上下文与张量都是资源，只能由本包函数创建；应用不能用整数、字符串或别的运行实例的句柄伪造。每个张量属于创建它的上下文，一个算子的全部张量参数须属于同一上下文。
- `释放张量` 使该张量失效；`释放张量上下文` 使上下文与其中全部张量失效；运行实例结束时一律失效。失效后再用：带错误分支的函数返回 `资源已失效`，其余函数属于非法资源使用，宿主终止本次运行并报告。
- 张量存储计入所属上下文的存储上限（`读取张量存储上限`，单位字节）。建立函数超限返回 `资源配额已尽`；算子的结果超限时宿主终止本次运行，应用应在大规模分配前核对上限。

## 形状与元素类型

形状是一至八个正整数组成的列表，第一项是最外层维度；元素按行优先存放，最后一维连续。各类型的存储布局如下，多字节量一律小端：

| 类型 | 单位 | 布局 |
| --- | --- | --- |
| 单精度 | 每元素 4 字节 | IEEE 754 binary32 |
| 半精度 | 每元素 2 字节 | IEEE 754 binary16 |
| 脑浮点 | 每元素 2 字节 | binary32 的高 16 位 |
| 八位整数 | 每元素 1 字节 | 二补码 |
| 三十二位整数 | 每元素 4 字节 | 二补码 |
| 块量化八位 | 每 32 元素一块，34 字节 | 与 GGUF 的 Q8_0 逐字节相同：binary16 缩放 d，随后 32 个八位整数 q；元素值为 d×q |
| 超块量化四位 | 每 256 元素一块，144 字节 | 与 GGUF 的 Q4_K 逐字节相同：binary16 的 d 与 dmin、12 字节打包的 6 位子块缩放与偏移、128 字节 4 位量化值；元素值按 GGML 的 `dequantize_row_q4_K` 定义 |
| 超块量化六位 | 每 256 元素一块，210 字节 | 与 GGUF 的 Q6_K 逐字节相同：128 字节低 4 位、64 字节高 2 位、16 个八位整数子块缩放、binary16 的 d；元素值按 GGML 的 `dequantize_row_q6_K` 定义 |

三种块量化类型的最后一维须是块长（32 或 256）的整数倍，块沿最后一维连续排列。

## 数值语义

- 除特别说明，算子的输入与结果都是单精度。计算至少以单精度进行；运算次序、是否融合乘加、并行归约如何划分，均由宿主决定。
- 合规容差：对有限输入，浮点结果与按定义以双精度求得的参考值 r 相比，须满足 |结果 − r| ≤ 1e-5 + 1e-3 × s，其中逐元素运算的 s 为 |r|，归约、矩阵乘与注意力的 s 为各被加项绝对值之和。整数结果、形状、序号须精确。
- 非有限值（NaN、正负无穷）按 IEEE 754 传播，不报错。
- 一致性验收按上述容差比较浮点结果，不要求不同宿主逐字相同。

## 挂起与执行

- 所有函数都可能挂起。宿主可以推迟执行算子，但读出类函数（`读出张量字节`、`读出张量小数`、`取最大下标`、`按概率抽样`）返回的值须反映此前全部调用的结果。
- 应用在单一线程里调用本包；宿主内部可以多线程或使用加速器。
- 就地修改只有 `写入张量字节` 与 `写入行`。其余算子返回新张量，不改变输入。`改形` 的结果与原张量共享存储，此后对任一方的就地写入另一方都可见；其余算子的结果不与输入共享存储。

## 上下文

- `取得张量上下文` 取得一个新上下文。宿主此刻不能提供时返回 `资源暂不可用`。
- `读取张量存储上限` 返回该上下文全部张量存储的字节数上限，是正整数。
- `读取单次交换上限` 返回单次交换的字节数上限，至少 1 MiB；受此限的函数有 `由字节建张量`、`由小数建张量`、`写入张量字节`、`读出张量字节`、`读出张量小数`，其中小数每个按 8 字节计。超限时，带错误分支的函数返回 `输入无效`，其余函数终止本次运行。
- `释放张量上下文` 使上下文及其全部张量失效。

## 建立与读写

- `新建张量`：元素全为零。形状不合法（空列表、含非正数、超过八维、块量化类型最后一维不合块长）返回 `输入无效`；超过存储上限返回 `资源配额已尽`。
- `新建常数张量`：单精度，每个元素都是给定小数按“就近取偶”舍入到单精度的值。
- `由字节建张量`：字节数须恰好等于该类型与形状的存储大小，否则返回 `输入无效`。
- `由小数建张量`：单精度，小数个数须等于元素总数，否则返回 `输入无效`；每个值就近取偶舍入。
- `写入张量字节`：从字节偏移起覆写存储。偏移非负且偏移加长度不超过存储大小，否则终止本次运行；量化类型写入的是原始块字节。
- `读出张量字节`：返回从字节偏移起恰好给定长度的存储字节。偏移、长度非负且在存储范围内，否则返回 `输入无效`。
- `读出张量小数`：返回从元素序号起给定个数的元素值。浮点与整数类型转换为小数时精确；量化类型按上表定义以单精度求值后再转为小数。范围不合返回 `输入无效`。
- `张量形状`、`张量元素类型` 返回建立时确定的形状与类型，不必等待算子执行完毕。
- `释放张量` 使该张量失效；经 `改形` 与它共享存储的其他张量不受影响。

## 算子

算子都返回新张量（`写入行` 除外）。参数不合下列规则时，宿主终止本次运行并报告。批维广播按 NumPy 规则：形状右对齐，缺的维当作 1，对应维相等或其一为 1。

| 函数 | 规则与定义 |
| --- | --- |
| `矩阵乘 甲 乙` | 甲为单精度，形状 […, m, k]；乙为单精度、半精度、脑浮点或三种块量化之一，形状 […, n, k]；批维广播。结果 […, m, n]：结果[…, i, j] = Σ_t 甲[…, i, t] × 乙[…, j, t]。乙按“行是输出、列是输入”存放，与 GGUF 权重的布局一致 |
| `逐元二元 运算 甲 乙` | 两者都是单精度，形状按广播对齐。`相加` a+b，`相减` a−b，`相乘` a×b，`相除` a÷b，`取较大`、`取较小` 取两者中较大或较小者；任一为 NaN 时结果为 NaN |
| `逐元一元 运算 甲` | `取指数` eˣ，`取对数` ln x，`取平方根` √x，`取倒数` 1/x，`取负值` −x，`取绝对值` \|x\|，`双曲正切` tanh x，`反曲` 1/(1+e⁻ˣ)，`反曲加权` x/(1+e⁻ˣ)，`高斯误差线性` 0.5x(1+tanh(√(2/π)(x+0.044715x³))) |
| `数乘 甲 c`、`数加 甲 c` | 逐元素乘以 c、加上 c；c 先舍入到单精度 |
| `均方根归一 甲 权 ε` | 甲形状 […, d]；权形状 [d]，可为单精度、半精度或脑浮点。y = x ÷ √(Σx²/d + ε) × w |
| `层归一 甲 权 偏 ε` | 甲形状 […, d]；权、偏形状 [d]，可为单精度、半精度或脑浮点。μ 为均值，σ² 为总体方差，y = (x − μ) ÷ √(σ² + ε) × w + b |
| `旋转位置编码 甲 起位 旋维 基数 方式` | 甲为单精度，形状 [n, h, d]；起位 ≥ 0；旋维 r 为偶数且 2 ≤ r ≤ d；基数 > 0。第 i 个词元的位置 p = 起位 + i，第 t 对（0 ≤ t < r/2）的角 θ = p × 基数^(−2t/r)。`相邻成对` 的配对为（2t，2t+1），`前后半成对` 为（t，t + r/2）；每对 (x₀, x₁) 变为 (x₀cosθ − x₁sinθ, x₀sinθ + x₁cosθ)；不小于 r 的维不变 |
| `软最大 甲` | 沿最后一维：eˣ⁻ᵐ ÷ Σeˣ⁻ᵐ，m 为该行最大值 |
| `注意力 问 键 值 有效长 起位 缩放` | 问为单精度，形状 [n, hq, d]；键 [L, hk, d]、值 [L, hk, dv] 为单精度或半精度；hq 是 hk 的整数倍 g，第 j 个问头使用第 ⌊j/g⌋ 个键头；1 ≤ 有效长 ≤ L；起位 ≥ 0。第 i 个问词元只看位置 s 满足 s < 有效长且 s ≤ 起位 + i 的键；权重为这些位置上 缩放 × (问·键) 的 softmax；结果形状 [n, hq, dv]，为各位置值的加权和 |
| `取行 表 行号` | 表形状 [R, d]，可为任一类型；行号列表非空，每项在 [0, R) 内。结果为单精度 [行号个数, d] |
| `写入行 目标 起行 源` | 目标为单精度或半精度，形状 [R, …]；源为单精度，形状 [r, …]，其余各维与目标相同；0 ≤ 起行且起行 + r ≤ R。就地把源舍入到目标类型后写入第 起行 至 起行 + r − 1 行 |
| `改形 甲 形状` | 元素总数不变；块量化类型的新形状最后一维仍须合块长。结果与甲共享存储 |
| `切片 甲 轴 起 长` | 0 ≤ 轴 < 维数，0 ≤ 起，长 ≥ 1，起 + 长 ≤ 该维长度；结果类型同甲。块量化类型沿最后一维切片时，起与长须是块长的整数倍 |
| `转置 甲 轴一 轴二` | 交换两维；甲不能是块量化类型 |
| `拼接 甲 乙 轴` | 同类型、非块量化，除该轴外形状相同 |
| `类型转换 甲 类型` | 转为浮点类型按就近取偶；转为整数类型先就近取偶再饱和到该类型范围，NaN 转为 0。转为块量化八位与 GGML 的 `quantize_row_q8_0_ref` 逐字节相同：全程单精度，d = 块内最大绝对值 ÷ 127，id 在 d 非零时为 1 ÷ d、否则为 0，q = round(x × id)（半数远离零），d 以 binary16 存放；块内含 NaN 或无穷时该块内容由宿主决定。0.1.0 不支持转为两种超块量化类型 |
| `末维求和 甲`、`末维最大 甲` | 形状 […, d] 变为 […, 1] |
| `取最大下标 甲` | 甲为单精度，按行优先展平后返回最大值的序号；NaN 视为小于一切数，并列时取序号最小者，全为 NaN 时返回 0 |
| `按概率抽样 甲 温度 前k 累积p 随机数` | 甲为单精度，展平后长度 V。温度 ≤ 0 时同 `取最大下标`。否则 zᵢ = xᵢ ÷ 温度，按 z 从大到小排序（NaN 视为负无穷，相等按序号从小到大）；前k ≥ 1 时只留前 min(前k, V) 个；在留下者上做 softmax；0 < 累积p < 1 时只留累积概率首次不小于累积p 的最短前缀（至少一个）并重新归一；u = (随机数 对 2²⁴ 取非负余数) ÷ 2²⁴；返回累积概率首次大于 u 的候选的原序号，舍入使无候选满足时返回最后一个 |

## 适用范围

首批实现为 Node.js（路一）。浏览器可以在 Worker 或 WebGPU 上实现同一语义。CF Worker 内存约 128 MiB、没有线程，不宣称实现本包。路二与裸机待执行器具备浮点与向量指令后实现。

## 规范样例

须覆盖：上限为正数；新建张量全零；字节写入后读出逐字相同；块量化八位一块的解量化值；二乘三与三乘二的矩阵乘；批维广播的逐元相加；softmax 每行之和为 1；均方根归一与旋转位置编码的已知值；有因果遮挡的注意力与逐项手算一致；取行、写入行后读出；改形后就地写入对两者可见；取最大下标的并列规则；温度为零的抽样等于取最大下标；形状不合法返回 `输入无效`；超过存储上限返回 `资源配额已尽`；释放后再读返回 `资源已失效`。
