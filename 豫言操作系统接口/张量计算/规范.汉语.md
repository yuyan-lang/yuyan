# 张量计算接口规范 0.7.0

本包声明宿主持有的张量与整块数值算子。应用依赖本包即要求宿主实现它。应用取得上下文时给出功耗偏好与加速要求，宿主据此选定后端（中央处理器或某种加速器）；用哪个设备、宿主内部是否并行，都不改变本规范的结果语义。与文件、图形处理器互通的函数不在本包，放在桥接包里（如[张量文件](../张量文件/规范.汉语.md)）；本包只依赖基础包。

## 资源与寿命

- 张量上下文与张量都是资源，只能由本包函数创建；应用不能用整数、字符串或别的运行实例的句柄伪造。每个张量属于创建它的上下文，一个算子的全部张量参数须属于同一上下文。
- `释放张量` 使该张量失效；`释放张量上下文` 使上下文与其中全部张量失效；运行实例结束时一律失效。失效后再用：带错误分支的函数返回 `资源已失效`，其余函数属于非法资源使用，宿主终止本次运行并报告。
- 张量存储计入所属上下文的存储上限（`读取张量存储上限`，单位字节）。建立函数超限返回 `资源配额已尽`；算子的结果超限时宿主终止本次运行，应用应在大规模分配前核对上限。

## 形状与元素类型

形状是一至八个正整数组成的列表，第一项是最外层维度；元素按行优先存放，最后一维连续。各类型的存储布局如下，多字节量一律小端：

| 类型 | 单位 | 布局 |
| --- | --- | --- |
| 单精度 | 每元素 4 字节 | IEEE 754 binary32 |
| 半精度 | 每元素 2 字节 | IEEE 754 binary16 |
| 脑浮点 | 每元素 2 字节 | binary32 的高 16 位 |
| 八位整数 | 每元素 1 字节 | 二补码 |
| 三十二位整数 | 每元素 4 字节 | 二补码 |
| 块量化八位 | 每 32 元素一块，34 字节 | 与 GGUF 的 Q8_0 逐字节相同：binary16 缩放 d，随后 32 个八位整数 q；元素值为 d×q |
| 超块量化四位 | 每 256 元素一块，144 字节 | 与 GGUF 的 Q4_K 逐字节相同：binary16 的 d 与 dmin、12 字节打包的 6 位子块缩放与偏移、128 字节 4 位量化值；元素值按 GGML 的 `dequantize_row_q4_K` 定义 |
| 超块量化六位 | 每 256 元素一块，210 字节 | 与 GGUF 的 Q6_K 逐字节相同：128 字节低 4 位、64 字节高 2 位、16 个八位整数子块缩放、binary16 的 d；元素值按 GGML 的 `dequantize_row_q6_K` 定义 |

三种块量化类型的最后一维须是块长（32 或 256）的整数倍，块沿最后一维连续排列。

## 视图与连续性

- 每个张量都是其存储上的一个跨步视图：元素 [i₀, …, iₙ₋₁] 位于存储第 起点 + Σ iₖ × 步长ₖ 个元素，步长以元素计，可以为零或负。新建的张量与算子的结果都是连续的：步长为行优先步长（最后一维为 1），起点为 0。除长为 1 的维外，各维步长都等于行优先步长的张量是连续的；块量化类型的张量总是连续的。
- `跨步视图 甲 形状 步长 偏移` 得到与甲共享存储的视图：结果元素 [i₀, …] 是从甲的第一个元素（甲[0, …, 0]）往后数 偏移 + Σ iₖ × 步长ₖ 个存储位置上的元素。形状须合法，步长个数与形状维数相同，所寻址的每个位置都须落在甲的存储之内；甲不能是块量化类型。视图不占新的存储，类型同甲；释放视图不影响共享同一存储的其他张量。
- `张量步长` 返回各维步长（以元素计）；`紧致化` 按逻辑次序（行优先）把张量复制成连续的新张量，总是新存储。
- 除下面的例外，函数都接受任意视图作参数，按逻辑次序读取，如同先紧致化；`读出张量字节`、`读出张量小数` 读出的也是逻辑次序的内容。
- 就地写入：`写入视图`、`填充常数` 与三种随机填充的目标可以是任意视图，写进共享的存储；`写入张量字节`、`写入行`、`按行累加`、`就地线性组合` 的目标、`亚当更新` 的参数与两个矩，以及 `改形` 的甲须是连续的，否则终止本次运行（可先紧致化）。写入目标的不同元素若指向同一存储位置（如步长为零），留下哪个值由宿主决定。

## 数值语义

- 除特别说明，算子的输入与结果都是单精度。计算至少以单精度进行；运算次序、是否融合乘加、并行归约如何划分，均由宿主决定。
- 合规容差：对有限输入，浮点结果与按定义以双精度求得的参考值 r 相比，须满足 |结果 − r| ≤ 1e-5 + 1e-3 × s，其中逐元素运算的 s 为 |r|，归约、矩阵乘与注意力的 s 为各被加项绝对值之和。整数结果、形状、序号须精确。
- 非有限值（NaN、正负无穷）按 IEEE 754 传播，不报错。
- 一致性验收按上述容差比较浮点结果，不要求不同宿主逐字相同。

## 挂起与执行

- 所有函数都可能挂起。宿主可以推迟执行算子，但读出类函数（`读出张量字节`、`读出张量小数`、`取最大下标`、`按概率抽样`）返回的值须反映此前全部调用的结果。
- 应用在单一线程里调用本包；宿主内部可以多线程或使用加速器。
- 就地修改只有 `写入张量字节`、`写入行`、`写入视图`、`填充常数`、`按行累加`、三种随机填充、`就地线性组合`、`亚当更新`，以及 `因果卷积` 与 `门控递推` 对状态参数的更新，与 `问键旋转写缓存` 对两个缓存的写入。其余算子返回新张量，不改变输入。`改形` 与 `跨步视图` 的结果与原张量共享存储，此后对任一方的就地写入另一方都可见；其余算子的结果不与输入共享存储。

## 上下文

- `取得张量上下文 功耗偏好 加速要求` 取得一个新上下文，宿主按两个选项为它选定一个后端，上下文存续期间后端不变。宿主此刻不能提供时返回 `资源暂不可用`。
- 后端名称共四个：`中央处理器`、`网页图算`（WebGPU）、`金属`（Metal）、`统算`（CUDA）。中央处理器以外的后端都是加速后端。宿主实现其中哪些由宿主决定。
- 加速要求：`不限加速` 由宿主自定；`偏好加速` 有可用的加速后端时用它，否则用中央处理器；`必须加速` 只用加速后端，没有可用的加速后端时返回 `资源暂不可用`。
- 功耗偏好：`不限功耗`、`低功耗`、`高性能`。宿主在几个后端或设备之间选择时参考它（如低功耗时选集成显卡），也可以不理会。
- `上下文已加速吗` 返回该上下文的后端是否为加速后端；`读取后端名称` 返回上面四个名称之一。两者都与取得时选定的后端一致。
- 宿主可以另设测试用的选项强制指定后端；指定的后端此刻不可用、或加速要求为 `必须加速` 而它不是加速后端时，`取得张量上下文` 返回 `资源暂不可用`。
- `读取张量存储上限` 返回该上下文全部张量存储的字节数上限，是正整数。
- `读取单次交换上限` 返回单次交换的字节数上限，至少 1 MiB；受此限的函数有 `由字节建张量`、`由小数建张量`、`写入张量字节`、`读出张量字节`、`读出张量小数`，其中小数每个按 8 字节计。超限时，带错误分支的函数返回 `输入无效`，其余函数终止本次运行。
- `释放张量上下文` 使上下文及其全部张量失效。

## 建立与读写

- `新建张量`：元素全为零。形状不合法（空列表、含非正数、超过八维、块量化类型最后一维不合块长）返回 `输入无效`；超过存储上限返回 `资源配额已尽`。
- `新建常数张量`：单精度，每个元素都是给定小数按“就近取偶”舍入到单精度的值。
- `由字节建张量`：字节数须恰好等于该类型与形状的存储大小，否则返回 `输入无效`。
- `由小数建张量`：单精度，小数个数须等于元素总数，否则返回 `输入无效`；每个值就近取偶舍入。
- `写入张量字节`：从字节偏移起覆写存储。偏移非负且偏移加长度不超过存储大小，否则终止本次运行；量化类型写入的是原始块字节。
- `读出张量字节`：返回从字节偏移起恰好给定长度的存储字节。偏移、长度非负且在存储范围内，否则返回 `输入无效`。
- `读出张量小数`：返回从元素序号起给定个数的元素值。浮点与整数类型转换为小数时精确；量化类型按上表定义以单精度求值后再转为小数。范围不合返回 `输入无效`。
- `张量形状`、`张量元素类型` 返回建立时确定的形状与类型，不必等待算子执行完毕。
- `释放张量` 使该张量失效；经 `改形` 与它共享存储的其他张量不受影响。

## 算子

算子都返回新张量（`写入行`、`写入视图`、`填充常数`、`按行累加`、三种随机填充、`就地线性组合` 与 `亚当更新` 就地修改目标，`因果卷积`、`门控递推` 另就地更新状态参数，`问键旋转写缓存` 另就地写两个缓存，`跨步视图` 与原张量共享存储）。参数不合下列规则时，宿主终止本次运行并报告。批维广播按 NumPy 规则：形状右对齐，缺的维当作 1，对应维相等或其一为 1。

| 函数 | 规则与定义 |
| --- | --- |
| `矩阵乘 甲 乙` | 甲为单精度，形状 […, m, k]；乙为单精度、半精度、脑浮点或三种块量化之一，形状 […, n, k]；批维广播。结果 […, m, n]：结果[…, i, j] = Σ_t 甲[…, i, t] × 乙[…, j, t]。乙按“行是输出、列是输入”存放，与 GGUF 权重的布局一致 |
| `逐元二元 运算 甲 乙` | 两者都是单精度，形状按广播对齐。`相加` a+b，`相减` a−b，`相乘` a×b，`相除` a÷b，`取较大`、`取较小` 取两者中较大或较小者，任一为 NaN 时结果为 NaN；`乘方` aᵇ（同 C 的 pow）；`是否相等`、`是否大于`、`是否大于等于` 成立时为 1、否则为 0，与 NaN 比较都不成立 |
| `逐元一元 运算 甲` | `取指数` eˣ，`取对数` ln x，`取平方根` √x，`取倒数` 1/x，`取负值` −x，`取绝对值` \|x\|，`双曲正切` tanh x，`反曲` 1/(1+e⁻ˣ)，`反曲加权` x/(1+e⁻ˣ)，`高斯误差线性` 0.5x(1+tanh(√(2/π)(x+0.044715x³)))，`修正线性` max(x, 0)（NaN 仍为 NaN），`软加` ln(1 + eˣ) |
| `数乘 甲 c`、`数加 甲 c` | 逐元素乘以 c、加上 c；c 先舍入到单精度 |
| `逐元标量 运算 甲 c` | 甲为单精度；c 先舍入到单精度；结果[…] = 运算(甲[…], c)，各运算的定义同 `逐元二元`（c 在右边） |
| `均方根归一 甲 权 ε` | 甲形状 […, d]；权形状 [d]，可为单精度、半精度或脑浮点。y = x ÷ √(Σx²/d + ε) × w |
| `层归一 甲 权 偏 ε` | 甲形状 […, d]；权、偏形状 [d]，可为单精度、半精度或脑浮点。μ 为均值，σ² 为总体方差，y = (x − μ) ÷ √(σ² + ε) × w + b |
| `旋转位置编码 甲 起位 旋维 基数 方式` | 甲为单精度，形状 [n, h, d]；起位 ≥ 0；旋维 r 为偶数且 2 ≤ r ≤ d；基数 > 0。第 i 个词元的位置 p = 起位 + i，第 t 对（0 ≤ t < r/2）的角 θ = p × 基数^(−2t/r)。`相邻成对` 的配对为（2t，2t+1），`前后半成对` 为（t，t + r/2）；每对 (x₀, x₁) 变为 (x₀cosθ − x₁sinθ, x₀sinθ + x₁cosθ)；不小于 r 的维不变 |
| `软最大 甲` | 沿最后一维：eˣ⁻ᵐ ÷ Σeˣ⁻ᵐ，m 为该行最大值 |
| `注意力 问 键 值 有效长 起位 缩放` | 问为单精度，形状 [n, hq, d]；键 [L, hk, d]、值 [L, hk, dv] 为单精度或半精度；hq 是 hk 的整数倍 g，第 j 个问头使用第 ⌊j/g⌋ 个键头；1 ≤ 有效长 ≤ L；起位 ≥ 0。第 i 个问词元只看位置 s 满足 s < 有效长且 s ≤ 起位 + i 的键；权重为这些位置上 缩放 × (问·键) 的 softmax；结果形状 [n, hq, dv]，为各位置值的加权和 |
| `取行 表 行号` | 表形状 [R, d]，可为任一类型；行号列表非空，每项在 [0, R) 内。结果为单精度 [行号个数, d] |
| `按下标取行 表 下标` | 表同 `取行`；下标为三十二位整数张量，按行优先展平后有 n ≥ 1 个元素，每项在 [0, R) 内。结果为单精度 [n, d]，第 i 行等于 `取行` 取表第 下标[i] 行（0.6.0） |
| `写入行 目标 起行 源` | 目标为单精度或半精度，形状 [R, …]；源为单精度，形状 [r, …]，其余各维与目标相同；0 ≤ 起行且起行 + r ≤ R。就地把源舍入到目标类型后写入第 起行 至 起行 + r − 1 行 |
| `改形 甲 形状` | 元素总数不变；块量化类型的新形状最后一维仍须合块长。结果与甲共享存储 |
| `切片 甲 轴 起 长` | 0 ≤ 轴 < 维数，0 ≤ 起，长 ≥ 1，起 + 长 ≤ 该维长度；结果类型同甲。块量化类型沿最后一维切片时，起与长须是块长的整数倍 |
| `转置 甲 轴一 轴二` | 交换两维；甲不能是块量化类型 |
| `拼接 甲 乙 轴` | 同类型、非块量化，除该轴外形状相同 |
| `类型转换 甲 类型` | 转为浮点类型按就近取偶；转为整数类型先就近取偶再饱和到该类型范围，NaN 转为 0。转为块量化八位与 GGML 的 `quantize_row_q8_0_ref` 逐字节相同：全程单精度，d = 块内最大绝对值 ÷ 127，id 在 d 非零时为 1 ÷ d、否则为 0，q = round(x × id)（半数远离零），d 以 binary16 存放；块内含 NaN 或无穷时该块内容由宿主决定。不支持转为两种超块量化类型 |
| `末维求和 甲`、`末维最大 甲` | 形状 […, d] 变为 […, 1] |
| `取最大下标 甲` | 甲为单精度，按行优先展平后返回最大值的序号；NaN 视为小于一切数，并列时取序号最小者，全为 NaN 时返回 0 |
| `按概率抽样 甲 温度 前k 累积p 随机数` | 甲为单精度，展平后长度 V。温度 ≤ 0 时同 `取最大下标`。否则 zᵢ = xᵢ ÷ 温度，按 z 从大到小排序（NaN 视为负无穷，相等按序号从小到大）；前k ≥ 1 时只留前 min(前k, V) 个；在留下者上做 softmax；0 < 累积p < 1 时只留累积概率首次不小于累积p 的最短前缀（至少一个）并重新归一；u = (随机数 对 2²⁴ 取非负余数) ÷ 2²⁴；返回累积概率首次大于 u 的候选的原序号，舍入使无候选满足时返回最后一个 |
| `跨步视图 甲 形状 步长 偏移`、`张量步长 甲`、`紧致化 甲` | 见“视图与连续性” |
| `写入视图 目标 源` | 目标与源都不是块量化类型，形状相同；源的值按 `类型转换` 的规则转成目标类型，就地写进目标（可为视图）；两者共享存储时，如同先把源完整读出再写 |
| `填充常数 目标 c` | 目标不是块量化类型，可为视图；每个元素设为 c 按 `类型转换` 规则转成目标类型的值 |
| `按行累加 目标 行号 源` | 目标为单精度、连续，形状 [R, …]；源为单精度，形状 [行号个数, …]，其余各维与目标相同；行号列表非空，每项在 [0, R) 内，可以重复。按 i 从小到大，目标[行号ᵢ, …] 加上 源[i, …]，就地修改 |
| `填充均匀随机 目标 下界 上界 种子`、`填充正态随机 目标 均值 标准差 种子`、`填充伯努利 目标 概率 种子` | 目标不是块量化类型，可为视图，就地填充。逻辑序号为 j 的元素取 Philox4x32-10（与 Random123 的 philox4x32 相同）第 ⌊j/4⌋ 块输出的第 j mod 4 个 32 位数 x：密钥为种子按 64 位二补码的低 32 位与高 32 位，计数器为（块号低 32 位，块号高 32 位，0，0）。u = ⌊x ÷ 2⁸⌋ × 2⁻²⁴。均匀：下界 + (上界 − 下界) × u。正态：每块第 0、1 个数与第 2、3 个数各成一对，u₁ = (⌊x₀ ÷ 2⁸⌋ + 1) × 2⁻²⁴，u₂ 由 x₁ 按 u 的取法得出，r = √(−2 ln u₁)，θ = 2πu₂，前者为 均值 + 标准差 × r cos θ，后者为 均值 + 标准差 × r sin θ。伯努利：u < 概率 时为 1，否则为 0。结果按 `类型转换` 规则转成目标类型。32 位数的位型由上述定义唯一确定，由它得出的浮点值按容差验收 |

## 融合算子（0.5.0）

`归一矩阵乘`、`归一门控矩阵乘`、`矩阵乘加`、`问键旋转写缓存`、`按专家门控矩阵乘` 是变换器推理常用的几组小算子的融合：每个的结果都按上表定义为对应小算子的组合。宿主可以用一个内核算完（省去中间张量与多次派发），也可以退回小算子逐个算；两种做法对应用的语义相同。

- 参数：与对应的小算子一样接受任意视图，按逻辑次序读取（`问键旋转写缓存` 的两个缓存须连续）；参数不合规则时终止本次运行。结果都是连续的新张量，不与输入共享存储，`归一矩阵乘` 返回的各结果也互不共享存储。
- 数值：中间结果（如归一后的 h、两个矩阵乘的结果）可以不舍入到单精度、不写进存储。合规容差的参考值 r 按定义以双精度求得，中间结果也不舍入；s 的取法：`归一矩阵乘` 为各被加项 \|hₜ × 乙ⱼₜ\| 之和（h 以双精度求）；`矩阵乘加` 为矩阵乘的被加项绝对值之和加 \|丙\|；`归一门控矩阵乘` 与 `按专家门控矩阵乘` 为 \|激活(g)\| × s_u + \|u\| × s_g，其中 g、u 是两个矩阵乘的参考值，s_g、s_u 是它们的被加项绝对值之和；`问键旋转写缓存` 的问′、键′ 为 \|x₀ cos θ\| + \|x₁ sin θ\|（x 为归一后的值，不旋转的维取 \|r\|），写进半精度缓存的值是在此容差内的键′、值再就近取偶舍入成半精度。
- 归一方式的权、偏与 `均方根归一`、`层归一` 的权、偏相同；`问键旋转写缓存` 对问、键各头分别归一（沿最后一维 d）。分组查询注意力的问头数 hq 与键头数 hk 由形状给出，本算子不要求 hq 是 hk 的倍数（`注意力` 要求）。
- 用途举例（千问三一层的解码约为 6 次派发）：`归一矩阵乘 甲 (均方根归一法 注意力归一 ε) 【问投影，键投影，值投影】` → `问键旋转写缓存`（问、键按头均方根归一，前后半成对旋转，写键值缓存）→ `注意力` → `矩阵乘加 注意力输出 输出投影 甲` → `归一门控矩阵乘 乙 (均方根归一法 前馈归一 ε) 门 升 反曲加权` → `矩阵乘加 积 降投影 乙`。

## 按下标取行（0.6.0）

`按下标取行` 的行号来自张量，常接在 `按行最大下标` 之后：贪心解码时，上一步的下标留在宿主（如 GPU）上，直接用作下一步的词嵌入行号。应用可以先记下下一步的算子，再读出这一步的下标；宿主读出时只须等到这个下标算完，下一步的计算可以与应用的记录、读出重叠。读出的结果仍须见此前各次调用的效果。

## 录制与重放（0.7.0）

`开始录制 量` 在 量 所属的上下文里开始录制：此后这个上下文里的张量运算照常执行、照常返回结果，宿主同时记下它们派发的计算。`结束录制 量` 结束录制，得到一个录制（资源）。

- `重放录制 录 位移 替换们` 按录制的次序再做一遍录下的计算，结果写回录制期间得到的那些张量（录制期间新建的结果张量与就地写入的缓存）。与位置有关的参数——`注意力` 的有效长与起位、`问键旋转写缓存` 与 `旋转位置编码` 的起位——都加上位移，其他参数照录制时。
- 替换们是（旧，新）张量对的列：录制时读写旧张量存储的计算，重放时改为读写新张量的存储；旧、新两个张量的元素类型、形状与步长相同，各对按录制时的张量对照、同时生效。
- 重放得阳表示全部计算都已记下，之后读出结果照常可见；得阴表示这个录制不能重放（录制期间有交给宿主计算或按行号写入的运算，或宿主不支持录制），这时宿主可能已做了其中一部分（只写录制所用的张量与缓存里位移后的位置），应用照常计算这一步即可。
- 录制期间新建的张量归录制所有：应用释放它们时，宿主推迟到 `释放录制` 再释放，录制里的计算因此一直能用这些存储。`释放录制` 后录制失效。
- 用途：贪心解码的每一步除位置外完全相同。录下一步（`按下标取行` 起的一次前向，再 `按行最大下标`）之后，各步用 `重放录制` 代替逐层重建运算，位移为与录制那步的位置差；下标与几率各用两块轮流，替换们把录制里的输入下标、输出下标与几率换成本步用的那几块，应用就可以先记下下一步、再读出这一步的下标（见上节）。

## 适用范围

首批实现为诺节（路一），后来加了金属与统算后端（见 `豫言操作系统/适配/张量计算节点`）。浏览器与云工由 `豫言操作系统/适配/张量计算` 实现，只有中央处理器后端（中央张量内核，底层豫言写的 Wasm）：浏览器页面跨源隔离时用 Web Worker 多线程；云工单线程，存储上限只取 64 MiB（CF Worker 每个隔离环境内存约 128 MiB）。网页图算（WebGPU）后端尚未接入。路二与裸机待执行器具备浮点与向量指令后实现。分段旋转位置编码（多模态位置）尚未提供：纯文字输入时各段位置相同，等同于普通旋转位置编码。融合算子（0.5.0）在诺节的金属、统算后端有融合内核时用一个内核算，否则与中央处理器、浏览器、云工一样退回小算子的组合。录制与重放（0.7.0）在诺节的金属、统算后端实现；中央处理器后端、浏览器与云工上 `重放录制` 得阴，应用照常计算。

## 规范样例

须覆盖：后端名称是四者之一且与是否加速一致；没有可用的加速后端（或强制指定中央处理器）时要求必须加速返回 `资源暂不可用`；上限为正数；新建张量全零；字节写入后读出逐字相同；块量化八位一块的解量化值；二乘三与三乘二的矩阵乘；批维广播的逐元相加；softmax 每行之和为 1；均方根归一与旋转位置编码的已知值；有因果遮挡的注意力与逐项手算一致；取行、写入行后读出；改形后就地写入对两者可见；取最大下标的并列规则；温度为零的抽样等于取最大下标；形状不合法返回 `输入无效`；超过存储上限返回 `资源配额已尽`；释放后再读返回 `资源已失效`。0.3.0 另须覆盖：跨步视图的转置、零步长广播与负步长翻转，视图参与逐元运算与矩阵乘，非连续视图读出的字节与紧致化后相同；经视图的写入视图与填充常数；紧致化后的步长；乘方、三种比较、修正线性与逐元标量；按行累加的行号重复；种子 0 第一块与 Philox4x32-10 已知答案 6627e8d5 e169c58d bc57ac4c 9b00dbd8 一致，同种子可复现，均匀、正态与伯努利的样本均值与方差合理。 0.4.0 另须覆盖：取前 k 的次序与并列；按专家矩阵乘的手算值、与对单个专家做矩阵乘逐元相同、输入共用与各用两种形状；因果卷积的手算值与分两次调用经状态衔接；二范数归一与软加的已知值；门控递推的手算值（衰减、写入强度、按 u 修正、缩放），分段与整段相同。按轴求和与按轴最大保留维度；按行最大下标的并列规则与结果类型；就地线性组合；亚当更新一步的已知值（含权重衰减）。 0.5.0 另须覆盖：各融合算子与对应小算子组合的结果在容差内相同——归一矩阵乘的三种归一方式、多个乙且类型不同（含块量化）、甲有批维；归一门控矩阵乘的激活取反曲加权与高斯误差线性；矩阵乘加的丙为残差形与偏置形；问键旋转写缓存的单精度与半精度缓存、两种旋转方式、不归一与均方根归一、旋维小于维、键头少于问头，写入的缓存行与写入行的结果相同、其余行不变；按专家门控矩阵乘的输入共用与各用两种形状。 0.6.0 另须覆盖：按下标取行与按同样行号的取行结果逐元相同，下标来自按行最大下标（形状 [n, 1]）。0.7.0 另须覆盖：录下一段运算后以位移零、空替换重放，结果与重新计算逐元相同；以非零位移重放时注意力与问键旋转写缓存按位移后的位置计算，与直接在该位置计算的结果相同；替换们使重放读写新张量；录制期间新建的张量在释放录制之前一直可用；不支持录制的后端重放得阴。
