# 张量计算接口规范

此包约宿主所持之张量与整块之算。客依此包，则宿主须行之；以何器算、内并行与否，宿主自择，其果之义不易。与文件、图形处理器相通之术别入桥接之包，此包惟依基础。

张量之境与张量皆资源，惟此包之术造之，客不得以数、文或他实例之柄伪之；一算之诸张量须同境。释张量则其失效，释境则境与其中诸张量皆失效，实例终则尽失效。失效而复用：有误支者返资源已失效，余者宿主止此行而告之。张量之存计入境之上限，建而逾限返资源配额已尽，算而逾限则止行。

形为一至八正整数之列，首为最外之维，元以行为先而末维相连，多字之数皆小端。单精度四字，半精度二字，脑浮点取单精度之高十六位，八位整数一字，三十二位整数四字，皆二补码。块量化八位三十二元一块三十四字，同 GGUF 之 Q8_0；超块量化四位、六位二百五十六元一块，各一百四十四字、二百一十字，同 GGUF 之 Q4_K、Q6_K，解之从 GGML 之法。块类末维须为块长之倍。

算之入出，除别言者，皆单精度；次序、融乘加、并行之分，宿主自择。合规之度：于有限之入，与以双精度按义所求者较，差不逾十万分之一加千分之一倍其量；归约与矩阵乘，其量取诸加项绝对值之和。整数、形、序皆须精确；非有限之值依 IEEE 传之。故一致之验以此度较浮点，不责诸宿主逐字皆同。

诸术皆可挂起；宿主可缓行其算，惟读出之术所返须见此前诸调之果。客单线而调，宿主内可多线或用加速之器。就地之改惟写入张量字节与写入行；改形与原共存，其后就地之写两者皆见；余算皆得新张量，不易其入。

诸算之规：矩阵乘甲形末为行、深，乙形末为列、深，得行、列，前诸维广播，乙可量化；逐元二元、一元之算依广播；均方根归一、层归一于末维；旋转位置编码形为词、头、维，配对或相邻或前后半；软最大于末维；注意力问头为键头之倍，因果遮其后，惟用有效长以内之键；取行按行号取表；写入行就地覆目标；改形、切片、转置、拼接、类型转换、末维求和、末维最大各如其名；取最大下标同者取其前；按概率抽样依温度、前 k、累积概率与客所给之随机整数，温度非正则取最大。层归一之权与偏可为单精度、半精度或脑浮点。化为块量化八位从 GGML 之法：全程单精度，以 d 之倒数乘之而舍（半远零），与之逐字同。NaN 者，于取最大下标视为最小，尽为 NaN 则返零；于抽样视为负无穷。

首行于 Node.js；浏览器可以 Worker 或 WebGPU 行之；云工无线且存小，不称行此包；路二与裸机待执行器具浮点与向量之令而后行。详约、诸算之式与验例见[汉语稿](规范.汉语.md)。
