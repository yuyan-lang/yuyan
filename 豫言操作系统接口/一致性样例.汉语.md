# 接口一致性样例 0.1

本清单是未来宿主实现与接口检查器的共同验收输入说明，尚无可执行测试器。所有样例在相同接口包版本下检查**可观察语义**；终端、浏览器开发者工具、Worker 日志和系统窗口的外观无需一致。

| 包 | 输入或情境 | 必须观察到 |
| --- | --- | --- |
| 基础 | 依次读两次单调微秒 | 第二值不小于第一值；不得把值解释为日历时间 |
| 基础 | 记录含换行及零字符的诊断字符串 | 调用正常返回；不要求宿主保留原样显示 |
| 包装载 | 应用依赖的完整版本缺失 | 入口运行前失败并指出包身份与版本 |
| 包装载 | 同名依赖解析到两个所有者，或传递依赖要求同包两个版本 | 构建失败；不得任选一个候选包或自动升级 |
| 包装载 | 包名与版本相同而公开签名摘要不同 | 入口运行前失败；不得以结构近似或本地文件路径代替核对 |
| 包装载 | 宿主实现文件包但未授目录 | `取得已授目录` 返回 `未获授权`，不得读取宿主当前目录 |
| 文件 | 向已授权目录传入 `../秘密`、绝对路径或零字节路径 | 返回 `输入无效`；不得越过目录权 |
| 文件 | 读取含 `00` 字节的文件直至末尾 | 字节逐位保持；末尾使用 `文件读尽`，与零上限的空串有别 |
| 文件 | 只读句柄写入、关闭后再读取 | 前者拒绝写入；后者返回 `资源已失效` |
| 文件 | 以非空字节串写入而宿主暂时不能写 | 返回 `资源暂不可用` 或实际写入一至给定长度的字节数，不得成功返回零 |
| 文件 | 关闭文件报告失败后再次读取 | 旧句柄仍返回 `资源已失效` |
| 网络 | 请求测试服务返回 HTTP 404 和正文 | 取得成功响应，状态为 404，正文正确；不当作传输失败 |
| 网络 | 初始目标获授权，但返回 HTTP 302（无论是否带 Location） | 返回 `宿主操作失败`，不得向下一跳发送请求 |
| 网络 | 响应正文超过所公布上限 | 返回 `资源配额已尽`，不得截断后报告成功 |
| 显示 | 提交宽一、高一、恰四字节的 RGBA8 画面 | 接收画面；在相同坐标与颜色规则下显示或可读回核验 |
| 显示 | 画面字节数与宽高不合 | 返回 `输入无效`，不得越界读取 |
| 显示 | 读取尺寸后显示面改变，再按旧尺寸提交 | 返回 `资源暂不可用`；不得暗中缩放或裁切后报告成功 |
| 显示 | 宿主关闭显示面后再次等待输入 | 先取得一次 `显示面已关闭`，此后返回 `资源已失效`，不得永久挂起 |
| 显示 | 中文输入法一次提交“豫言” | 一个 `文字输入` 事件携带完整字符串；按键事件不能代替已提交文本 |
| 启动 | 一次运行实例执行 `启动程序` 后正常返回 | 入口只调用一次；返回后没有悬挂的同实例重入 |
| 网页服务 | POST 正文含零字节，应用回传状态 201 与二进制正文 | 入站正文和出站正文逐位保持；恰有一次入口调用与一个响应 |
| 网页服务 | 输入正文超出所公布上限 | 入口不被调用；宿主拒绝该请求，不把截断正文交给应用 |
| 网页服务 | 两次独立请求 | 应用不需要依赖同一 Wasm 实例或前次句柄仍有效 |
| 网页服务 | 应用保存前次请求句柄并在另一实例使用 | 宿主拒绝该句柄；不能读取到前次请求数据 |
| 入口装载 | 缺少应用应导出的 `处理入站网页请求` | 在处理首个请求前装载失败，并指出缺少的包、模块与函数 |
| 入口装载 | 同名函数的参数或结果类型不同 | 在入口运行前拒绝，不靠宿主包装层的动态转换蒙混通过 |
| 入口调用 | 一个入口在宿主函数上挂起时，宿主尝试在同一实例重入入口 | 宿主拒绝重入或排队至前次入口结束；不得并发运行两个入口 |

接口包的元数据检查已可使用现有 `豫构 检查`。纯声明文件的语法和类型一致性测试须由未来接口检查器读取这些样例及 `接口文件规则.汉语.md` 实施；当前不能把普通编译器的“缺少函数定义”报错算作规范失败。
