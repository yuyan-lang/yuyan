# 显示接口规范 0.7.0

零点七版增「设置指针形状」与输入之事「组字更新」。「设置指针形状」设指于此面之形为常箭、文字（I 形）或手形，惟示意耳：宿主不能则如常而返；指出面复入，其形犹存；归还显示面则失。「组字更新」载输入法组字中之预编文与其中光标之码位（自零至文之码数）；空文为组字毕（或弃或交）。预编之文非已交之文，客惟绘之于光标处，不入正文；组字所交之文仍以 `文字输入` 授之，或先于毕告，或后之。宿主不能预编则可终不授此事，用户惟于交后见文。浏览器用组字始、更、毕之事，节点（SDL）暂不授。

零点六版增无参数之事 `显示尺寸变化`。宿主于面尺或像素比易时授之，唤无期候之客；客复读今尺与比而重绘，毋用告发时之旧尺。相邻之告可并，不越余输入之事。此事不易客态、输入之焦或计时之期；宿主观察之资随显示会话归还而清。浏览器用布局观察与视口易尺之告，节点用SDL窗尺及显示器变更之告。

零点五版增 `等待输入事件限时(面, 毫秒)` 与 `显示计时` 之事。正毫秒数内先授旧事或新输入，无事而时尽则还计时；非正则无期。候成皆清计时与候者，面闭或归亦撤计时。计时不易输入之列与焦点。今时自每候起算；输入相续可推迟更新，定期调度待后成。

零点四版增语义键名 `功能二`，当键盘 F2，以旧按下与抬起之事授之；事之构与函之签如故。客自定其行，图形命令行以之易中英文输入之式。

零点三版增 `归还显示面` 与其结果之类。归还止此显示之会，清事件之听、输入与关联绘图之资源；Node 闭此窗，浏览器归画布之会而存宿主之画布。授权不撤，同名复取则生新有效之面；旧号恒失效。旧等待者受关闭之事，重复归还则报资源已失效。客持共享面，当由掌其会者归还，普通控件入口循旧宿主管理之行。

零点二版于零点一版惟增不改：输入之事增「滚轮」；键名增编辑与修饰之键；增「读取显示面像素比」「设置文字输入区域」二术。零点一版之签与义皆不变。

显示面须宿主所授；云工无面，不得称行此包。尺寸先宽后高，以像素计，可随时变。所交画面须宽高皆正，字数恰宽乘高乘四；宿主可限一帧之字数，限不下十六兆字，逾则返资源配额已尽；提交尺寸异于面之现尺寸，则返暂不可用，客当重读重绘，不得暗缩裁而称成。逐行自左上，像素红绿蓝透各一字；红绿蓝循 sRGB，透值未预乘。实屏与窗外背景之合成不属可移之约，欲外观同则透值取二百五十五。宿主既受画面，可返已交；非谓已扫屏。

输入坐标以左上为原点，向右为横正，向下为纵正。键名首版定左、右、上、下、回车、退格、空格，零点二版增删除、起首、末尾、上翻页、下翻页、制表、退出与修饰之键上档、控制、交替、命令，亦可单通字符。修饰之键亦以按下、抬起交之，客自记其按住；面失焦，宿主补其抬起。长按可复交按下。宿主宜止制表之默认，免焦点离面；修饰之键及之与否由宿主定，求确文则据文字之事。输入法成文以「文字输入」事交，其文可兼多通字符；键事与文字事可同次皆有，客改文本惟据文字事，不得拼键以成汉字。滚轮之事（零点二版）带指之横纵与横纵之滚量，皆以物理之素计，右下为正；以行或页计者宿主折为素（一行约四十八逻辑像素乘像素比，一页为面之高），自然滚动之向亦统之；相接二事可并。像素比（零点二版）为物理之素与逻辑之素之比，恒正，可随时变，客依之缩放界面。文字输入区域（零点二版）示宿主置输入法之候选于所示之矩旁，惟为提示，宿主不能亦照常返之。候事可挂起；同面之事依所见序而交。面闭先告一度，后用则报失效；以同名再取，宿主或予新面，或返未获授权、资源暂不可用；同面首版惟一候者。详约与验例见[汉语稿](规范.汉语.md)。
