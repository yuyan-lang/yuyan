# 显示接口规范 0.7.0

0.7.0 新增「设置指针形状」与输入事件「组字更新」。「设置指针形状」把指针在本显示面上的形状设为默认箭头、文字（I 形）或手形，只是提示：宿主做不到时照常返回，形状在指针离开再回到显示面后仍然有效，归还显示面后失效。「组字更新」带输入法组字中的预编辑文字和其中光标的码点位置（零至文字的码点数）；空文字表示组字结束（取消或已提交）。预编辑文字不是已提交的内容，应用只把它画在光标处、不写入文本；组字提交的文字仍以 `文字输入` 交付，可在结束通知之前或之后到达。宿主不支持预编辑时可以从不交付此事件，用户只在提交后看到文字。浏览器用组字开始、更新、结束事件，节点（SDL）暂不交付。

0.6.0 新增无参数事件 `显示尺寸变化`。宿主在显示面尺寸或像素比变化时交付，唤醒无限等待的应用；应用重新读取当前尺寸及像素比并重绘，不依赖通知发出时的旧尺寸。相邻通知可合并，不越过其他输入事件。事件本身不改变应用状态、输入焦点或计时到期时点；宿主观察资源随显示会话归还而清理。浏览器用布局观察与视口变化通知，节点用SDL窗口尺寸及显示器变化通知。

0.5.0 新增 `等待输入事件限时(面, 毫秒)` 和 `显示计时` 事件。正毫秒数内先交付已有或新到的输入，无输入到期则返回计时事件；非正数无限等待。每次等待结束均清除计时与候者，关闭或归还也撤销计时。计时不修改输入队列，也不改变焦点。当前计时从每次等待开始计算；连续输入可以推迟计时更新，固定周期调度留待后续。

0.4.0 新增语义键名 `功能二`，对应键盘 F2，以既有按键按下和抬起事件交付；事件结构与函数签名不变。应用自行决定其行为，图形命令行用它切换中英文输入模式。

0.3.0 新增 `归还显示面` 与归还结果类型。归还结束本次显示会话，清理事件监听、输入资源及关联绘图资源；Node 关闭本次窗口，浏览器归还画布会话并保留宿主拥有的画布。授权不撤销，同名再次取得会生成新的有效显示面；旧面号保持失效。已有等待者收到关闭事件，重复归还返回资源已失效。应用持有共享面时应由管理该会话的调用方归还，普通控件入口保持原来由宿主管理的行为。

0.2.0 相对 0.1.0 只增不改：输入事件新增「滚轮」；键名新增编辑键与修饰键；新增函数「读取显示面像素比」「设置文字输入区域」。0.1.0 的签名与语义不变。

本包仅用于有可见显示面的宿主。CF Worker 无显示面时不得宣称实现本包；它仍可用普通豫言库在 CPU 上生成图像字节。应用依赖本包即要求宿主实现它，具体显示面还须由宿主授予。

- `取得已授显示面` 按本次运行授予的名称取得显示面。名称未获授权返回 `未获授权`，已授权但暂时无显示面返回 `资源暂不可用`。
- 尺寸以物理像素数返回，先宽后高；暂时无法提供正尺寸时，`读取显示面尺寸` 返回 `资源暂不可用`，不得成功返回零尺寸。尺寸可在两次调用间变化。提交宽高必须为正，字节数必须精确等于宽×高×4；乘法溢出、零尺寸或字节长度不合返回 `输入无效`。宿主可以限制单帧字节数，上限至少 16 MiB；超过时返回 `资源配额已尽`。提交时的宽高若与显示面当时的尺寸不同，返回 `资源暂不可用`，调用者应重新读取尺寸并绘制；宿主不得暗中缩放或裁切后报告成功。
- 画面像素按行优先、左上起点、每像素 RGBA8 四字节排列，通道范围零至二百五十五；RGB 使用 sRGB 编码，透明度为直通未预乘值。宿主可转换到自身显示格式，但不得改变应用提交的逻辑画面。物理显示与周围窗口背景的合成方式不属此包的可移植结果；需要一致外观的应用应提交透明度 255 的不透明像素。`画面已提交` 表示宿主已接收画面，不保证扫描输出或刷新完成。
- 输入坐标以同一显示面的左上角为原点，整数像素，向右为 x 正、向下为 y 正。指针事件的第三个整数为按钮编号：零主键、一辅助键、二次要键；其他编号由以后版本定义。按键名使用语义键名：0.1.0 固定 `左`、`右`、`上`、`下`、`回车`、`退格`、`空格`；0.2.0 增加 `删除`、`起首`、`末尾`、`上翻页`、`下翻页`、`制表`、`退出` 与修饰键 `上档`（Shift）、`控制`（Ctrl）、`交替`（Alt、Option）、`命令`（⌘、Win、Super）；并允许单个 Unicode 标量值。修饰键照样以按键按下、抬起交付，由应用记下按住的状态；显示面失去焦点时，宿主为仍按着的修饰键补发按键抬起。长按时按键按下可以重复交付。宿主应阻止 `制表` 的默认动作，免得焦点离开显示面；单字符键名是否反映 Shift 等修饰键由宿主决定，需要确切文字时以 `文字输入` 为准；应用不得靠按键事件拼接中文输入法的文字。已提交的文本以 `文字输入` 事件交付，字符串可含多个 Unicode 标量值；按键事件和文字输入事件可以针对同一次用户操作分别出现，应用应只以 `文字输入` 更新文本内容。预编辑组合态由 0.7.0 的 `组字更新` 交付。
- `等待输入事件` 可以挂起。同一显示面的事件按宿主观察顺序交付；不同显示面之间不承诺全局顺序。显示面关闭后先返回一次 `显示面已关闭`，再调用返回 `资源已失效`。以同一名称再次 `取得已授显示面` 时，宿主可以提供新的显示面，也可以返回 `未获授权` 或 `资源暂不可用`。首版同一显示面只允许一个等候者；第二个并发等候调用返回 `输入无效`，不夺走第一个等候者的事件。

- **滚轮**（0.2.0）：「滚轮」事件带指针的横、纵坐标与横向、纵向滚动量，都以物理像素计；滚动量向右、向下为正（内容向上移、视野向下）。宿主把以行或页计的滚动量折成像素（一行约 48 个逻辑像素乘像素比，一页为显示面高度），并统一自然滚动的方向；相邻的两次滚轮事件可以合并为一次（量相加、坐标取新）。宿主应阻止页面随滚轮滚动。
- **像素比**（0.2.0）：「读取显示面像素比」返回物理像素与逻辑像素（CSS 像素、窗口点）之比，大于零，可在两次调用间变化（如窗口移到另一块屏幕）；应用据此按比例放大界面。显示面失效时返回 `资源已失效`。
- **文字输入区域**（0.2.0）：「设置文字输入区域」提示宿主把输入法候选框放在给定矩形附近（横、纵、宽、高，物理像素，以显示面左上角为原点），通常是光标所在的矩形。它只是提示：宿主做不到时照常返回，应用不必检查结果。

规范样例须覆盖：错误尺寸、嵌零像素、透明通道、坐标方向、按键事件（含 0.2.0 的编辑键、修饰键与失焦补发抬起）、滚轮的方向与换算、像素比、文字输入区域、指针形状、组字更新、关闭后使用及未授权显示面。GPU 加速不属于本包的先决条件。
