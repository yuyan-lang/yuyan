# 网址定位接口规范 0.1.0

`解析绝对网址部件` 接受绝对 `http:` 或 `https:` URL；`根据根址解析网址部件` 接受待解析文字和绝对 HTTP(S) 根网址。两者按 WHATWG URL 规则解析、规范化路径和来源，返回 JSON 对象文字，字段固定为 `href`、`origin`、`pathname`、`search`，均为字符串。`search` 不含片段，有查询时含开头 `?`，无查询时为空。无效 URL、非 HTTP(S) 方案或非绝对根网址调用失败。

此包只做解析，不授予访问所得网址的网络权；调用方在使用解析结果前仍须核对来源、路径根和业务标识。当前 `_start` 边界用 JSON 文字传递部件；后续可用豫言记录类型替换，不改变 URL 语义。
