# 接口规范未决事项

今有十包可供审议，未可谓全备。旧编译器求「乃」后有体，寻模块惟查「名称。豫」；独立检查器今已读纯声明，核包版、方向、名源与源型，并生 JSON 清单。然型构造之全义、导入之环、所依闭包与摘要、载入时核实导入导出，犹未具。基础二术虽已于浏览器、云工、节点验行，其余接口未悉依同一签名验之。GPU、持久键值、字体、流、队列、定时、邮件亦未成公共包；网页界面包仅备既有元素之文、受限属性及基本事件，造节点与选择符犹未定；GPU 设备、缓冲、队列、着色与失效之约未定。

欲称可执行且已验证之标准，尚须补静态型义、机器可读之闭包锁定与装载核对，并以共验遍诸适用宿主。规范树仍惟载接口之约，适配与检查各居他目录。详见[汉语稿](未决事项.汉语.md)。
