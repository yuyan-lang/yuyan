# 接口规范未决事项

今诸接口包已成源级之约，未可谓全备。普通编译器今可导纯声明而依签名检其类（无体之签补占位，未绑定而调则报）；独立检查器读纯声明，核包版、直依、方向、名源与源型，且生载完整依闭、规范摘要之 JSON 清单，拒依环与版冲。Node 发行包于启动前核程序摘要、接口之版与规范摘要、Wasm 导入导出之形。其一致驱动八十八事，于 macOS arm64 与 Linux 二架构皆过；Windows 犹待验。类型构造之全义、诸宿主同域之装载核对、跨宿主共验，犹待成。GPU 与字体亦未成公共包（持久键值、流、队列、定时、邮件已各成持久事务、网页上游与命名持久服务之渐读、消息队列、定时事件、邮件发送诸包）；网页界面包仅备既有元素之文、受限属性及基本事件，造节点与选择符犹未定；GPU 设备、缓冲、队列、着色与失效之约未定。

欲称可执行且已验证之标准，尚须补类型之全义、诸宿主同域之装载核对，并以公共接口共验遍诸适用宿主。规范树仍惟载接口之约，适配与检查各居他目录。详见[汉语稿](未决事项.汉语.md)。
