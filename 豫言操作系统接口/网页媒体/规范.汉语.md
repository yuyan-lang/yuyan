# 网页媒体接口规范 0.1.0

本包给浏览器里的豫言程序读取 HTML 音频时钟并驱动播放动画，也提供用户手势发起的标签页录制。它只适用于能提供等义 Web Media API 的浏览器；应用依赖本包后，宿主须实现所有函数。

## 音频

- `读取网页音频状态 id`：`id` 必须指向页面已有的 `audio` 元素。返回 JSON `{ "时刻":整数, "时长":整数, "暂停":爻, "结束":爻, "静音":爻, "音量":整数, "错误":字符串 }`。时间单位为毫秒，读取时四舍五入；`duration` 尚未知或无限时长时取 -1；音量是 `round(volume × 1000)`。最近一次 `play()` Promise 拒绝的错误写在 `错误`，正常播放或成功暂停后清空。
- `绑定网页音频按钮 音频ID 按钮ID`：注册一个原生点击监听器。点击时在同步的用户手势调用栈内执行 `audio.play()` 或 `audio.pause()`，以满足浏览器播放策略。重复绑定同一音频/按钮对不得重复切换。播放 Promise 拒绝时，状态读回的错误字段记录简短中文原因；不让未处理 Promise 拒绝逃逸。
- `设置网页音频时刻 id 毫秒`：仅接受非负整数；audio 元素须已取得元数据，时刻须不大于有限时长。时刻精度按浏览器实际 seek 能力处理。
- `暂停网页音频 id`：等同调用 `pause()`，可重复调用。

所有音频函数在元素不存在、元素标签不是 `audio`、参数越界或能力不可用时抛可捕获的豫言事故。

## 屏幕录制

`绑定网页屏幕录制 开始按钮ID 停止按钮ID 下载链接ID 配置JSON` 在调用时解析并检查参数，然后把原生 click 处理器直接装到两个按钮。配置只接受以下字段：

| 字段 | 类型 | 默认值与限制 |
| --- | --- | --- |
| `宽`、`高` | 正整数 | 默认 3840、2160；1 至 16384，作为理想捕获尺寸 |
| `帧率` | 正整数 | 默认 30；1 至 120，作为理想帧率且最高请求值 |
| `码率` | 正整数 | 默认 20000000；1 至 100000000，比特每秒 |
| `文件名` | 字符串 | 默认“网页录制”；1 至 128 个字符，不含路径分隔符与控制字符 |

开始按钮的点击回调**必须直接调用** `navigator.mediaDevices.getDisplayMedia`，浏览器权限提示由浏览器呈现。请求 `video` 与 `audio`，并以 ideal 方式请求宽、高及帧率。`preferCurrentTab` 与 `selfBrowserSurface=include` 只是偏好，不可绕过浏览器的选择器或用户授权。调用者不自动选定显示来源。请求获准后，若流没有音轨则停止所有轨道并转为失败；否则启动 `MediaRecorder`，优先 `video/webm;codecs=vp9,opus`，再试 VP8/Opus，再试浏览器支持的其他录制格式。编码器实际可用的码率与捕获尺寸可低于请求值，状态须报告轨道 `getSettings()` 与 `MediaRecorder` 实际 MIME/码率。

录制数据先存在内存。停止按钮调用当前录制器的 `stop()`；`stop` 事件到达后合并媒体块为 Blob，给下载链接设置 `href`、`download` 并显示链接。应用不得通过脚本代替用户点击下载。再次开始前释放上次 Object URL；宿主关闭或重绑时停止所有媒体轨道并撤销 Object URL。

开始期间状态依次为 `请求中`、`录制中`；停止时为 `停止中`；生成下载对象后为 `可下载`。用户取消权限提示时为 `已取消`，权限拒绝、缺少音轨、捕获/录制异常为 `失败`。`读取网页录制状态 下载链接ID` 返回 JSON，字段至少含 `状态`、`宽`、`高`、`帧率`、`码率`、`类型`、`音轨数`、`错误`。开始、停止、下载元素 ID 须指向已存在的按钮、按钮、`a` 元素；元素与参数无效时接口调用抛事故。异步权限/录制失败放入状态而非异步抛过 Wasm 边界。

调用者必须先调用绑定函数，再让用户点击开始。接口不得自行合成用户手势、静音录制提示、绕开用户选择或偷偷启动捕获。页面捕获时音频是否可分享还受浏览器 UI 与安全上下文控制。
