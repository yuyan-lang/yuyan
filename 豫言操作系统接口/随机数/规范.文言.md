# 随机数公约 0.1.0

随机者，一取诸宿主密码学安全之源（如 Web Crypto 之 `getRandomValues`），不设种子，亦不供可复现之序；需可复现之伪随机者，当自为之，不得借此包冒充。

`生成随机十六进制` 取所定字节数之随机字节，书为小写十六进制文，其长恰倍字节数，无前缀。字节数限一至一零二四，越界则调用败而抛豫言之异。

`生成随机通用标识` 返小写 UUID 第四版之文，式为八、四、四、四、十二位十六进制，共三十六字，版位与变位合 RFC 9562。

此包不察随机文已否为账户名、令牌或会话所用；唯一之检与冲突之重试，属客所为。用为令牌者，当使字节数足（通常不少于三十二），且惟存其摘要。
