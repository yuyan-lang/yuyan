# 命名持久服务之约 0.1.0

`请求命名持久服务文字` 受获授绑定名、对象名、内部绝对址、法、查询键值列、请求头列与正文。宿主先循当前程序 `DO` 许可核绑定，乃以 `getByName` 定其内对象；不得因对象名越至异绑定或外网。对象名非空，至多一百二十八字，惟 ASCII 字母、数字、下划线、连字符。内部址惟许 `https://asset/` 或 `https://internal/`，其径拒反斜线、控字、`?`、`#`，毋自带查询片段。法限 GET、HEAD、POST。查询至多十六项，由宿主编码；请头惟许精确 `Origin`、`Content-Type`、`Cookie`，至多八项且毋重名；GET/HEAD 正文必空，POST 正文不逾二 MiB。

宿主返有效 JSON 物文：`status` 为上游整数号，`body` 为全 UTF-8 文，`headers` 惟载上游现有之 `content-type`、`location`、`set-cookie`、`x-yuyan-revision` 四小写名及值。正文不逾二 MiB，逾则败；HTTP 错号仍属得答。不得露异头、句柄或异程序之对象。今 `_start` 以 JSON 文传果，后可易豫言记录与字节流。
