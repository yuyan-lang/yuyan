# 启动接口规范 0.1.0

本包是**应用提供的入口契约**。应用声明依赖本包，就须导出逻辑接口模块 `程序入口` 中的 `启动程序 : 有 → 有`；宿主负责调用，不能以同名宿主导入代替。其 `乃` 是待应用定义的签名，接口文件本身没有函数体。应用的 `。包。豫` 仍选取待编译的源文件；该源文件可叫 `入口。豫` 等任意合法名称，绑定工具把其中实现的 `启动程序` 映射到本包的逻辑接口模块，并检查类型与唯一性。不能仅凭同名的宿主包装函数宣称应用已实现入口。

宿主在完成包版本核对、导入连接及授权配置后调用此入口。每个运行实例恰调用一次；入口可使用其依赖的宿主能力，并按共同效果规则挂起。入口正常返回表示此轮程序执行结束，返回值不充当进程退出码；异常终止由宿主报告为运行失败。浏览器宿主可由页面触发启动，Node.js 宿主可由进程启动触发。它们只改变触发时机，不改变入口签名。

本包不承诺应用返回后继续收到事件。需要持续处理输入的应用在入口内通过显示等能力等待事件；需要由宿主逐次调用的 HTTP 服务依赖独立的网页服务入口包。宿主必须避免对同一实例并发调用本入口。
