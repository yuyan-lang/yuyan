# 网页入站公约 0.6.0

诸术惟读当前 HTTP 请，离此请不可用。`读取入站方法` 返所受之法；`读取入站原路径` 返未析百分号之径，无查询与片段；`读取入站解码路径` 严析一次百分号与 UTF-8，坏码则败；`读取入站标头值` 依 ASCII 不辨大小写之名取头，无则空文。客若以径为档名或包名，仍须验解后斜线、控字符及己业务之规。

读头不自授凭据使用或向外转请之权；网络、服务与久存另须能力及资源授权。无当前 HTTP 请而调用则败。今适配借 Worker Request；俟类型化网页服务入口接通，可自请求值授同义资料。

`读取入站事件种类` 返 `fetch` 或 `durable-fetch`；客可据之辨同一 Worker 中所留久物入口。宿主若无一类，惟返其所具者。一次请求中其值恒定。

`读取入站查询参数` 循浏览器 URL 查询之法，取首个同名之值，已析百分号；无则空文。`入站查询参数存在` 察同名之参有无，值空亦为有。`读取入站来源` 返 URL 所定之协议、主机与非默认端口，可供同源之比，不自授跨站之权。`构造入站同源网址` 受新绝对径、待设键值列与待删键列；空径守原。宿主复制当前请之网址，先删后设，余参皆留，返同源绝对址，不发请。新径须单一 `/` 起首，拒 `//`、反斜线、控字符、`?`、`#`；键值由宿主编码。设与删各至多十六项，逾限则败。

`读取入站主机名` 取当前请之主机名，循 URL 之规归小写，不含端口。`读取入站原查询` 取原查询文，有则含首 `?`，无则空；不析参数，可供改址保留原查询。

`读取入站癸象正文文` 一次读析当前请之 JSON 正文，返可复以豫言 `癸象解析` 析之规范文。正文逾二 MiB、非 JSON、已为他读取所耗，或无当前请，则败。俟类型化网页入口通，当以请求值代此过渡文界。
