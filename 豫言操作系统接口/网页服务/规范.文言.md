# 网页服务接口规范 0.1.0

此包定客所具之入站网页入口，与客向外发请之网络包分。「入站网页。接口。豫」定宿主所具之读请术及请答之型；「网页处理。应用接口。豫」引其型而定客所具之「处理入站网页请求」。客依之，必导出逻辑接口模块「网页处理」之此术；绑定者于客包所定入口源文件中惟一求得同名同型之实现，映于此模块，源文件名可异。每一入站请，宿主造请而调用客术；云工与节点宿主可承之，浏览器页面不必承之。

请之法为 HTTP 法名，址为绝对 HTTP 或 HTTPS 址。标头名以 ASCII 大小写同视，重值列返，其序不许客跨宿主凭恃。正文为全字节；逾宿主所告之限者，宿主先拒之，不得截短而交。请求之效期止于此轮调用。

客返状态、标头、正文所成之答；状态须百至五百九十九，字段须合法。逾响应限或得非法答，宿主报败，不得伪称成功。每请一答，术可候；同一实例不得并召之。异请可异实例，客不得凭恃实例内存跨请常存。流、升级连接、队列、定时与邮件皆另立约。
