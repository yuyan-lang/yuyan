# 持久独占之约 0.3.0

此包使客于持久对象（Durable Object）中开一**并发独占之区**：区内客可候外物之出入（呼他服务、读上游、行较长之算），而其间投于此对象之他事（HTTP 请、告警、套接字之信）**皆排队以候**，不与区内之读写交错。其当平台之 `blockConcurrencyWhile`；典型之用，乃“读、改、外呼、写”须整体串行之请，如同一站同一时惟理一动态之请。

## 模

独占之区以**类型化之回调**成之（提案 C0001，与[持久事务](../持久事务/规范.文言.md)相对）：客具入口 `执行持久独占回调`（`独占处理。应用接口。豫`）。客于持久对象中调 `执行持久独占 久仓 操作名 参数`（久仓乃[持久事务](../持久事务/规范.文言.md)之 `持久仓`，三版起明传之），宿主止投他事于此对象，于平台独占之回调中呼此入口（外层之调是时悬停），授以 `持久独占区`、操作名与参文；入口所返之果文即 `执行持久独占` 之返，宿主乃复投他事。`持久独占区` 惟此次回调之内有效；区内以 `独占区持久仓` 取所属对象之久仓。

## 义

操作名为一至一百二十八字节之文，由客所约，以于回调中择所为之事；参与果皆为有效 JSON 文，各不逾八 MiB，宿主验之（JSON 非法则调用败）。回调**不见外层之 HTTP 请**，外层欲授之请之资（法、径、体、头等）当纳于参之 JSON，果再由外层据以造应。

区内客可以 `独占区持久仓` 读写久仓（含[持久事务](../持久事务/规范.文言.md)之直读写术）、启事务、读写[持久告警](../持久告警/规范.文言.md)、候任意外物之出入；不得复开独占之区（以取自 `独占区持久仓` 之仓开之，则报 `独占区内不可再启动独占区`），事务回调之内亦不得开之（以取自 `事务持久仓` 之仓开之，则报 `持久事务回调内不可启动独占区`）。诸区依次而行，不相叠；区行之际所至之他事，区毕乃投。区行之际此对象之吞吐尽为所占，故区内耗时愈短愈善。宿主可于同一实例依次或交错呼入口，客不倚两调之间之内存。

区内之败——回调抛未捕之异、果非有效 JSON 或逾八 MiB——不传于平台：宿主以败为值授外层，`执行持久独占` 抛可以「尝试运行」捕之豫言异，辞以 `持久独占失败：` 起而存其因（如 `持久独占失败：独占区结果不是有效 JSON`）；**对象不被重置**。此乃有意之设：平台原生 `blockConcurrencyWhile` 之回调一抛错，则重置整个持久对象（弃内存之态、使方行之请败，本地 workerd 已验），而客中独占区之败乃常见之业务情形。回调自抛而未捕之豫言异，标准库之默处书之于标准错误，以退出码一终此回调，辞为 `持久独占失败：豫言程序退出：1`；欲告外层以确因，回调当自以「尝试运行」捕之，而书其因于所返之果。

平台于独占区回调逾三十秒则重置对象（本地 workerd 已验：逾三十秒则对象被重置，请败），客当为区内之外呼设更短之时限。

## 术

`执行持久独占 久仓 操作名 参数`：返果 JSON 文。`独占区持久仓 独占区`：返独占区所属对象之久仓。应用接口 `执行持久独占回调`：参为 `持久独占区`、带标签 `名称` 之操作名与带标签 `参数` 之参文（同调者所授），返果 JSON 文。

## 败之情形

| 情形 | 类 |
| --- | --- |
| 操作名非一至一百二十八字节；参非有效 JSON 或逾八 MiB | 违约：`执行持久独占` 抛可捕之异，辞曰 `持久独占失败：…` |
| 回调败、果非有效 JSON 或逾八 MiB | 抛可捕之异，辞曰 `持久独占失败：…`，对象不重置 |
| 以取自 `事务持久仓` 或 `独占区持久仓` 之仓调 `执行持久独占` | 违约：抛可捕之异，辞曰 `持久独占失败：…` |
| 平台之故、独占区逾平台三十秒 | 平台之故：此调败（逾三十秒则对象被重置） |

## 跨宿主之一致

诸实现须守：区内不与他事交错、区内所至之事区后乃投；区内之败以可捕之异告之而不重置对象；不可嵌套；参与果依 JSON 文原样而传（果不必与回调所返文字节相同，然 JSON 意义相等）；上述诸限与败类。

## 一致性样例

对象中键 `n` 初为 0，`仓` 为其久仓。五并发之请各 `执行持久独占 仓 "counter" 参`，回调读 `n`、候外物三十毫秒、写回 `n+1` 而返新值，则五果恰为一至五之一排列，终 `n` 为 5，外候之区间两两不叠；同此读、候、写若不入独占区，五并发之请所得皆为 1、终 `n` 为 1（更新遗失）。独占区行中所至之 `durable-fetch` 请，区毕乃理。`执行持久独占 仓 "fail" "{}"` 而回调未捕其异，则抛以 `持久独占失败：` 起之异，其后对象如常而实例不易。`执行持久独占 仓 "" "{}"`、`执行持久独占 仓 "x" "不是JSON"` 抛异。区内 `执行持久独占（独占区持久仓 区）…` 抛 `持久独占失败：独占区内不可再启动独占区`。

## 界

此包不供带优先之队、逾时自弃之独占区、跨对象之分布式锁，亦不携外层 HTTP 请入区。惟用于获授之持久对象，对象之名与授由宿主及部署之配置定之。独占区不易平台于存储读写之输入门规则，惟于区内更挡他事之投。

后续诸版之事：独占区回调之宿主墙钟时限（短于平台三十秒之重置线，使逾时显为可捕之异）；以外层之请所取之仓携入区内复开独占之察。
