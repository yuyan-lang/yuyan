# 关系查询接口规范 0.2.0

`查询关系库首行` 接受授权数据库名和一条预备 SQL，返回首行的 UTF-8 JSON 文字；无行时返回字面量 `null`。数据库名由宿主许可核对，未授权、数据库错误或结果无法序列化为 JSON 时调用失败。SQL 在指定数据库上执行，本包不声称 SQL 只读；授予此能力等于允许应用向该数据库提交 SQL。应用可在自己的类型系统中解析返回值；接口包本身只依赖标准库。

`查询关系库首行带文字参数` 还接受文字参数列表，逐项绑定到 SQL 占位符，不通过字符串拼接生成 SQL。空列表与不带参数的函数等价；参数数量或类型不匹配由数据库报告失败。首版只提供文字参数，不提供整数、二进制参数、事务或流式结果。当前云工适配把授权名映射到 D1；其他平台可以接同等关系数据库。此包只提供查询能力，HTTP 响应须由独立能力包处理。
