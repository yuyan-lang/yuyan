# 豫言操作系统公共接口总纲

此树在仓根，惟载接口之约，不载宿主之术。每能自成一包，以 `。包。豫` 定名、版、所依；以 `。接口。豫` 定宿主所具之术，以 `。应用接口。豫` 定客所具之术，二缀兼载型与函数。所依之包，悉为必需。宿主虽能行其术，资源仍须另授。

接口之文惟有导入、以 `立` 定型、以 `乃` 定函数签名及双语注，不得置 `者` 函数之体、`C调用` 与各地私物。`者` 仍为包之元数据所用。今普通编译器求签名后即有定义，模块亦寻 `名称。豫`，故纯声明今不得当普通程序编之；接口检查器与构时绑定器已成，装载器亦可核客需与宿供之簿，惟编器未直析纯声明。

今定基础、文件、网络、显示四包，以供客取宿主之能；又定[网页界面](网页界面/规范.文言.md)之首批元素与事件四术、[网页文树](网页文树/规范.文言.md)之节点构合与同源取文、[网页消息](网页消息/规范.文言.md)之当前页带值通事、[剪贴板](剪贴板/规范.文言.md)之写文、[网址](网址/规范.文言.md)之成分编码、[网页转发](网页转发/规范.文言.md)之授权转请；另定[启动](启动/规范.文言.md)与[网页服务](网页服务/规范.文言.md)二包，以定宿主召客之入口。网页服务包之读请诸术属宿主，处理请之入口属客，不得但以「乃」断其向。无界面程序于浏览器或节点，须依基础与启动；像素画面交互程序更须依显示，惟有显示面之宿主可行；入站网页服务于云工或节点，须依基础与网页服务。文件与出站网络依客实需而增，不因平台有其物便暗授之。图像可由 CPU 以豫言常库绘之；显示与 GPU 计算各为一能，驱动归宿主下层。图形处理器之细约未定，不得谓已备。诸包今为源级草案，非诸宿主皆合约之证。凡函数之义、误、挂起与资源寿命，各见其包汉语与文言之规范。文件之法与共验之目，见[接口规则](接口文件规则.文言.md)及[一致性样例](一致性样例.文言.md)；详见[汉语总纲](总纲.汉语.md)。

今又立[关系查询](关系查询/规范.文言.md)与[网页答复](网页答复/规范.文言.md)二能：前者于获授关系库取预备句之首行，后者于当前入站请答 JSON。二者以 JSON 文越今 `_start` 之界；俟[网页服务](网页服务/规范.文言.md)之类型化入口可载，乃去此过渡。应用所依之能仍各为必需，不因同为云工平台而暗授。

[网页入站](网页入站/规范.文言.md) 今读 `_start` 当前请之法、原径与头；[网址](网址/规范.文言.md) 之二版兼严解码；关系查询之二版增文字参数缚定。诸术分包，所依者悉须显列。

[服务状态](服务状态/规范.文言.md) 则向获授内服行 GET，惟返状态，不使响应正文出宿主。网页答复二版又可作无体之答；运维鉴权客可据此止泄上游之文。

[网页入站](网页入站/规范.文言.md) 二版又辨事类、严解路径；[网页转发](网页转发/规范.文言.md) 二版以受限安头覆原答而不读正文流。[环境文字](环境文字/规范.文言.md) 则按资源许可读配置之文，毋暗授密钥。

网页入站三版又取查询参，能守余参而构同源新址；网页答复三版增文字与同源改址之答。包地址客可据此以豫言辨径、问库、定新址，宿主不藏其业务。

网页入站五版又读当前请 JSON 正文；[时间](时间/规范.文言.md) 同刻取 UTC 日与 Unix 分，[持久事务](持久事务/规范.文言.md) 于获授仓原子读写键值。试写额度客依此以豫言裁日、分及总额，宿主惟给时、仓与入站之请。今 `_start` 犹以 JSON 文载值并以事务事类重入；类型化入口既通，当易此过渡之术。

[秘密文字](秘密文字/规范.文言.md) 循资源许可读 Secret，辨缺与空；[网页上游](网页上游/规范.文言.md) 先核获授 HTTPS 来源，禁自动改向，许客先验状态而后择 JSON 读或原流入站答。试写模型客以豫言定上游请与模型规，宿主惟守密、授权、时限与流。今 `_start` 以本次事内不透明文号指上游答；类型化入口既通，当易名义资源型。

[网址定位](网址定位/规范.文言.md) 循 URL 之规析绝对、相对址；[命名持久服务](命名持久服务/规范.文言.md) 先核 `DO` 绑定许可，乃向其内命名对象发有限文字请；[授权服务](授权服务/规范.文言.md) 依 `SERVICE` 许可择白头、守原流而请内部服务。云台业务之径与结果投影仍归豫言。

[密码摘要](密码摘要/规范.文言.md) 以 UTF-8 原字节求 SHA-256 小写十六进制文。密码原语归适配；凭据格式、时限与户籍之验归豫言应用。
