# 子程序显示接口 〇点一

此包为桥接之包，连[子程序](../子程序/规范.文言.md)与[显示](../显示/规范.文言.md)二接口：父程序启子程序时转授一显示面，子程序如常召显示接口，宿主以其所交之画授父程序，以父程序所送之输入之事与尺寸授子程序。平铺桌面（提案 〇〇〇一四）之外程序格以之纳图形程序之画于格中，子程序不必改书。

## 诸术

| 术 | 用 |
| --- | --- |
| `启动带显示面的子程序(程序, 参数, 输入, 环境, 显示面名, 宽, 高, 像素比)` | 前四参同子程序接口之 `启动子程序`；另以名为“显示面名”之一面转授子程序，初尺为宽高（物理之素），像素比如所予。果同 `启动子程序`：`子程序已启动` 载其柄，或 `子程序启动失败` 载系统错误 |
| `取子程序画面(句柄)` | 交子程序最新之全画布与自前次所取以来之变区，见下 |
| `送子程序输入事件(句柄, 事件)` | 以显示接口之一输入之事入子程序之事列 |
| `设置子程序显示面尺寸(句柄, 宽, 高, 像素比)` | 易子程序显示面之尺与像素比 |

柄与子程序接口共之：`尝试收取子程序`、`取子程序输出`、`终止子程序`、`查询子程序资源` 皆如故。收毕则柄失效，本包诸术返柄无效。

返整数之二术：零成、八柄无效、二十九宿主败、五十八未支持。

## 子程序之侧

子程序如常用显示接口：

- 以所转授之名 `取得已授显示面` 则成，余名返 `未获授权`。
- `读取显示面尺寸` 与 `读取显示面像素比` 交父程序最近所设之值。
- `提交像素画面` 与 `提交像素画面区域` 以画布交宿主存之；宽高异于今尺则返 `资源暂不可用`，同显示之规。
- `等待输入事件` 与 `等待输入事件限时` 依序交父程序所送之事。父程序易尺，则先交 `显示尺寸变化`，子程序复读其尺而重画全帧。
- 父程序止子程序、闭其所居之格、或归父程序己之显示面，方候之子程序受 `显示面已关闭`。
- `设置指针形状` 与 `设置文字输入区域` 如常而返。
- `归还显示面` 止此显示之会，其后父程序取画得 `子程序未取显示面`。

## 父程序之侧

- `取子程序画面`：子程序未取面则得 `子程序未取显示面`；既取而无新画则得 `子程序画面未变`；有新画则得 `子程序画面已更新`，载画布之宽高、全画布之字（RGBA8，同显示之规）与自前次所取以来变区之左、上、宽、高（数交则取外包之矩）。子程序既终而未收，犹可取其末帧。败则得 `子程序画面失败` 载系统错误，柄无效则为 `资源已失效`。
- `送子程序输入事件`：坐标为子程序显示面上之物理之素，父程序自其坐标换算之。事依送达之序而列；列满则弃最早之事，相邻二指移并为一。
- `设置子程序显示面尺寸`：宽高须正，否则返二十八（输入无效）；子程序随后受 `显示尺寸变化`，未以新尺交全帧之前，`取子程序画面` 所交犹为旧尺之画布。

## 平台

- **诺节、浏览器**：适配返未支持：`启动带显示面的子程序` 得 `子程序启动失败` 载 `资源暂不可用`，`取子程序画面` 得 `子程序画面失败` 载 `资源暂不可用`，余二术返五十八。
- **裸机与原生执行器**：客体二号以带型之导入径行之（原语百八十二启、百八十三取画、百八十四送事、百八十五设尺）。

## 后版之事

- 指形与输入法候选之位之转交（〇点二）。
- 一子程序转授数面。
- 孙任务（子程序复起之程）取显示面。
- 诺节与浏览器之显示代办。
