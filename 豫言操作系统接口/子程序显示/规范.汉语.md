# 子程序显示接口 0.1.0

本包是桥接包，连接[子程序](../子程序/规范.汉语.md)与[显示](../显示/规范.汉语.md)两个接口：父程序启动子程序时转授一块显示面，子程序照常调用显示接口，宿主把它提交的画面交给父程序，把父程序送来的输入事件与尺寸交给它。平铺桌面（提案 00014）的外部程序格用它把图形程序的画面放进格子，子程序本身不必改写。

## 函数

| 函数 | 作用 |
| --- | --- |
| `启动带显示面的子程序(程序, 参数, 输入, 环境, 显示面名, 宽, 高, 像素比)` | 前四个参数同子程序接口的 `启动子程序`；另把名为“显示面名”的一块显示面转授给子程序，初始尺寸为宽、高（物理像素），像素比如给。结果同 `启动子程序`：`子程序已启动` 携带句柄，或 `子程序启动失败` 携带系统错误 |
| `取子程序画面(句柄)` | 交出子程序最新的整块画布与自上次取出以来的变化区域，见下文 |
| `送子程序输入事件(句柄, 事件)` | 把一个显示接口的输入事件排进子程序的事件队列 |
| `设置子程序显示面尺寸(句柄, 宽, 高, 像素比)` | 改子程序显示面的尺寸与像素比 |

句柄与子程序接口共用：`尝试收取子程序`、`取子程序输出`、`终止子程序`、`查询子程序资源` 照旧可用。收取完成后句柄失效，本包各函数返回句柄无效。

两个整数结果的函数：零成功、八句柄无效、二十九宿主失败、五十八暂不支持。

## 子程序一侧

子程序照常使用显示接口：

- 以转授的名字 `取得已授显示面` 成功，其他名字返回 `未获授权`。
- `读取显示面尺寸` 与 `读取显示面像素比` 交出父程序最近设的值。
- `提交像素画面` 与 `提交像素画面区域` 把画布交给宿主保存；宽高与当前尺寸不符时返回 `资源暂不可用`，同显示规范。
- `等待输入事件` 与 `等待输入事件限时` 按顺序交付父程序送来的事件。父程序改了尺寸，先交付 `显示尺寸变化`，子程序重读尺寸后重画整帧。
- 父程序终止子程序、关闭它所在的格子或归还父程序自己的显示面时，正在等待的子程序收到 `显示面已关闭`。
- `设置指针形状` 与 `设置文字输入区域` 照常返回。
- `归还显示面` 结束本次显示会话，父程序随后取画面得 `子程序未取显示面`。

## 父程序一侧

- `取子程序画面`：子程序还没取得显示面时得 `子程序未取显示面`；取得后没有新画面得 `子程序画面未变`；有新画面得 `子程序画面已更新`，携带画布宽、画布高、整块画布字节（RGBA8，同显示规范）与自上次取出以来变化区域的左、上、宽、高（几次提交取外包矩形）。子程序结束后、收取完成之前仍可取它的最后一帧。失败得 `子程序画面失败` 携带系统错误，句柄无效时为 `资源已失效`。
- `送子程序输入事件`：坐标是子程序显示面上的物理像素，由父程序从自己的坐标换算。事件按送达顺序排队；队列满时丢掉最早的事件，相邻的两次指针移动合并为一次。
- `设置子程序显示面尺寸`：宽高须为正，否则返回二十八（输入无效）；子程序随后收到 `显示尺寸变化`，在它按新尺寸提交整帧之前，`取子程序画面` 交出的仍是旧尺寸的画布。

## 平台

- **诺节、浏览器**：适配返回暂不支持：`启动带显示面的子程序` 得 `子程序启动失败` 携带 `资源暂不可用`，`取子程序画面` 得 `子程序画面失败` 携带 `资源暂不可用`，另两个函数返回五十八。
- **裸机与原生执行器**：客体二号经带类型导入直接实现（原语 182 启动、183 取画面、184 送事件、185 设尺寸）。
