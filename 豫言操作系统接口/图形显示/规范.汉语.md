# 图形显示接口规范 0.1.0

本包是桥接包：它依赖[显示](../显示/规范.汉语.md)与[图形处理器](../图形处理器/规范.汉语.md)两个包，只有同时实现这两个包的宿主才实现它；那两个包都不依赖本包。它让应用把 GPU 渲染的画面直接呈现到已授显示面，像素不经过应用的字节串。

- `读取显示面纹理格式 显示面 设备` 返回该显示面适合的纹理格式（常见为 `蓝绿红透八位` 或 `红绿蓝透八位`）。要渲染到显示面的管线，其颜色目标格式应与它相同。
- `取得显示面纹理 显示面 设备` 返回当前帧的纹理：尺寸等于显示面此刻的尺寸，格式同上，含 `渲染目标用途`。一个显示面第一次调用时即与该设备绑定，此后只能与同一设备配合；在 `呈现显示面` 之前重复调用，返回同一个纹理。显示面失效、已与别的设备绑定或已用于 `提交像素画面` 时，返回 `纹理未建`，附 `图形系统错误`（分别为 `资源已失效`、`输入无效`、`资源暂不可用`）。
- `呈现显示面 显示面` 把当前帧交给宿主显示，再等宿主可以接受下一帧时返回 `画面已提交`（例如下一次屏幕刷新之前）。当前帧的纹理随即失效。本帧还没有取得纹理时返回 `画面提交失败 输入无效`；显示面失效返回 `画面提交失败 资源已失效`。
- 同一显示面在一次运行中要么经本包呈现，要么经显示包的 `提交像素画面` 提交：一经本包取得纹理，此后 `提交像素画面` 返回 `资源暂不可用`；反之亦然。
- 显示面尺寸变化后，下一帧取得的纹理随之改变尺寸；应用应在每帧按纹理实际尺寸渲染。
- 所有函数都可能挂起。

规范样例须覆盖：纹理格式与管线目标一致时清屏呈现成功；每帧取得的纹理尺寸等于显示面尺寸；呈现前重复取得是同一纹理；呈现后使用旧纹理的命令返回 `命令未提交`；未取纹理即呈现返回 `画面提交失败 输入无效`；同一显示面混用两种提交方式返回 `资源暂不可用`。
