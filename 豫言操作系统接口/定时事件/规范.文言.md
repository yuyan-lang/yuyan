# 定时事件公约 0.2.0

此包使客处定时之事（cron 所发）：客具入口 `处理定时事件`（`定时处理。应用接口。豫`），cron 每发，宿主呼之一次，以此事为 `定时事件` 授之（提案 C0001）。`读取定时事件文` 以此事为参，读其所由发之 cron 与计划之刻，返 JSON 文，式如 `{"cron":"*/10 * * * *","scheduledTime":1758801600000}`。`cron` 乃发此调用之 cron 原文；`scheduledTime` 乃平台所约当发之刻，以 Unix 毫秒整数记之（自 1970-01-01T00:00:00Z 起），或早于程序实起之时；手动或试发者，平台可授其发之一瞬。整数以十进原文授客，不经浮点。计划之刻或 cron 无效，则抛可以「尝试运行」捕之豫言异（`定时事件的计划时刻无效`、`定时事件的 cron 不是字符串`）。

## 事之寿

定时之事，其寿等于入口之一调：宿主使平台之定时调用待入口返乃止（其待兼授 `waitUntil`），客于入口所成之诸事，含待外请、书存储，皆在同一定时调用之内；入口返则此调用终，平台得收未毕之后台事。入口抛未捕之豫言异，则此调用为平台记败，重试与否由平台定时之策决之，此约不设 `noRetry`。宿主可于同一实例依次呼入口，客不倚两调之间之内存。客不当设同一计划之刻仅投一次，欲幂等者自守之。

## 一致之例

| 情境 | 必见 |
| --- | --- |
| cron 为 `*/10 * * * *`，计划之刻 1758801600000 | 所返 JSON 析之，`cron` 相等，`scheduledTime` 为整数 1758801600000 |
| 计划之刻为 0 或 8640000000000000 | 整数原样而返，无小数点与指数 |
| cron 含双引号、反斜线 | JSON 转义之后可无损析还原文 |
| 计划之刻为负一、一点五或字符串 | 抛可捕之豫言异 `定时事件的计划时刻无效` |
| 入口于定时事中待一异步之书而后返 | 定时调用待书毕乃终 |
| 入口抛未捕之异 | 定时调用败，宿主不吞其异 |

## 界

此包不析 cron，不列所部署之 cron，不承计划之刻与实行之刻相隔几何，亦不设 `noRetry`、重试之数与同一计划刻之去重。云工宿主以 `scheduled` 事之控制器为 `定时事件` 授入口；他平台可以等价之定时器承之，惟 `cron` 与 `scheduledTime` 之义及事之寿须同。
