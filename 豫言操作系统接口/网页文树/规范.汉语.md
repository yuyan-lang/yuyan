# 网页文树接口

这个能力组供在浏览器里运行的豫言应用构建当前页面。应用以 ID 获取已有节点，或按允许的标签创建新节点，再写纯文本、受限属性并添加子节点。句柄目前投影为字符串，语义上是当前应用实例内的资源编号；应用不得自行构造或跨实例保存。适配层必须拒绝未知标签、未知属性、可执行链接和无效句柄。

同组提供当前 URL 的查询参数和同源只读文字资源，便于静态页面根据公开数据渲染。读取资源只接受以单斜杠开头的站内路径，不得含反斜杠；宿主核对解析后的 origin，禁止重定向，仅接受 HTTP 200，并逐块限制正文为 2 MiB。正文按严格 UTF-8 解码，网络、编码及大小错误均报告给应用。本组是浏览器能力；没有文树的平台不提供这个包。
