# 设备接口 0.1.0

此为宿主列硬件设备及其驱动之接口。`查询设备` 返 `设备已列` 而载设备之列，或 `设备未得` 而载系统错误。豫言操作系统（裸机）列开机所录之诸外设互连（PCI）功能与 USB 设备，其数由核之设备表经服务六十五、六十六得之；无硬件设备可列之宿主（浏览器、诺节、macOS 与 Linux 原生）返 `资源暂不可用`。

`设备信息值` 依次存：

1. 总线：一为外设互连，二为通用串行（USB）。
2. 位置：外设互连为配码，即线左移十六、设左移十一、功左移八之和；通用串行之编法见豫言内核之包说明。
3. 厂商号、产品号：各十六位。
4. 类码：外设互连为二十四位之类码；通用串行为类、子类、协议各八位。
5. 驱动号：零谓无驱动认之；余号见持续改进目标《开放硬件驱动》之编号分段。
6. 状态：零无驱动，一已驱动，二驱动初置败。

壳命「设备列表」以此接口印设备之表；桌面之设备管理器每二秒询此接口一次，示同一表。

## 网卡（十月十三日）

`查询网卡` 返 `网卡已列` 而载网卡之列与网络之址设，或 `网卡未得` 而载系统错误。豫言操作系统（裸机）之网卡数由核之网卡表经服务七十五逐块得之，址设取诸初任务执行器网络栈之态；问时网卡初备，则网络栈先以 DHCP 取址。无网卡可列之宿主（浏览器、诺节、macOS 与 Linux 原生）返 `资源暂不可用`。

`网卡信息值` 依次存：驱号（十为虚拟网卡、十一为英特尔千兆等，号见《开放硬件驱动》；零为驱动客体所交之卡）、链路（一通、零断）、以太址（低四十八位，首字居低）、收帧数、发帧数、发败数、在用否（一为网络栈所用者）。

`网络地址值` 依次存：取址之态（零网卡未备、一 DHCP 得之、二 DHCP 未成而用 QEMU 用户网络之默值、三方取、负一本任务不见网络栈）、本机址、掩码、网关、域名服务之址。址为四版网际之三十二位整数，首段居最高字。

壳命「网络状态」以此接口印诸网卡与址设。

## 声卡（十月十三日）

`查询声卡` 返 `声卡已得` 而载系统所用声卡（声出接口所开者即此）之 `声卡信息值`，或 `声卡未得` 而载系统错误：豫言操作系统无声卡则返 `资源不存在`，其数由核之声卡表经服务八十四得之；浏览器、诺节、macOS 与 Linux 原生返 `资源暂不可用`。`声卡信息值` 依次存驱动号、位置（外设互连之配码）、厂商号、产品号、编解码器（高清音频为编解码器之厂号左移十六加设备号，无则零）、出口（高清音频为出引脚之节点号，无则负一）、出通道（高清音频为数模转换器之节点号，虚拟声卡为出流号）、口类（引脚默认配置之设备类：零线路出、一扬声器、二耳机等，无则负一）、今流号（零谓无方开之流）、采率、声道之数、已播之帧（今流开流以来设备放毕之帧）与已书之帧。USB 声卡（驱动号三十三）之位置为通用串行之位置码（根端口号左移二十加路由串，同设备表），厂号、品号取 USB 设备者；编解码器位置 USB 音频类之版本（一或二），出口位置输出终端号，出通道位置音频流口号左移八加备用设置，口类依输出终端之类易为上述设备类（无对应者负一）。壳命「声音设备」以之印声卡之况。
