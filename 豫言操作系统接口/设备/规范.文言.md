# 设备接口 0.1.0

此为宿主列硬件设备及其驱动之接口。`查询设备` 返 `设备已列` 而载设备之列，或 `设备未得` 而载系统错误。豫言操作系统（裸机）列开机所录之诸外设互连（PCI）功能与 USB 设备，其数由核之设备表经服务六十五、六十六得之；无硬件设备可列之宿主（浏览器、诺节、macOS 与 Linux 原生）返 `资源暂不可用`。

`设备信息值` 依次存：

1. 总线：一为外设互连，二为通用串行（USB）。
2. 位置：外设互连为配码，即线左移十六、设左移十一、功左移八之和；通用串行之编法见豫言内核之包说明。
3. 厂商号、产品号：各十六位。
4. 类码：外设互连为二十四位之类码；通用串行为类、子类、协议各八位。
5. 驱动号：零谓无驱动认之；余号见持续改进目标《开放硬件驱动》之编号分段。
6. 状态：零无驱动，一已驱动，二驱动初置败。

壳命「设备列表」以此接口逐行印设备之表。
