# 网页编译接口规范 0.2.0

本包让浏览器里的豫言应用**在本机编译一组豫言源文件**：源文件由应用给出，编译在后台工作线程里由浏览器版豫言编译器（WasmGC＋JSPI）完成，输出、诊断和阶段进度作为事件进入统一事件队列（见[网页事件接口规范](../网页事件/规范.汉语.md)），最终结果以“完成”事件报告。用途是云控制台的“本地编译”：源码在云端，编译在用户浏览器，结果与日志回传云端。0.2.0 起另有**本地构建**（见“本地构建”一节）：在浏览器里展开一份仓库源码快照，用豫构等豫言工具运行检查、类型检查、构建与测试，供网页临时算力执行云端排队的构建作业。应用依赖本包后，全部函数都必须实现。

本包只规定**编译**（源文件 → 编译是否通过、标准输出与标准错误、产物摘要），不规定运行编译产物、也不规定编译器资源的发布方式。

## 编译客户端

宿主通过一个“编译客户端”模块执行编译，默认从**页面基址目录下的 `编译/客户端.mjs`** 动态加载（例如页面 `/cloud/` 加载 `/cloud/编译/客户端.mjs`）；创建宿主时可用选项 `编译客户端` 换成别的模块地址或已加载的对象（测试用）。模块须导出两个函数：

- `浏览器编译(输入, 仅编译, 报告)`：`输入` 是 `{"files":{路径:内容}}`；返回 Promise，解析为结果对象 `{ok, stdout, stderr, error, phase, artifact:{sha256}}`；过程中用 `报告(事件)` 回报 `{type:"stage",phase,label}`、`{type:"output",stream,text}`、`{type:"diagnostic",text}`。
- `停止编译()`：终止当前编译（客户端负责让上面的 Promise 以 `{ok:false,error:"已停止"}` 结束）。

语言仓的 `宿主/浏览器/编译器/` 是这两个函数的参考实现（主线程计时器、Worker、90 秒编译时限、5 秒运行时限均由它负责）。

## 函数

### `本地编译可用 : 有 → 爻`

浏览器同时具备 `WebAssembly.promising`（JSPI）、`Worker`、`DecompressionStream` 时返回阳，否则返回阴。它只查浏览器能力，**不检查编译客户端与编译资源是否能加载**；加载失败在启动之后以“完成”事件报告。可用来决定界面上是否提供“本地编译”选项。

### `启动本地编译 : 字符串(文件 JSON) → 整数`

参数是 JSON 对象，键是文件路径，值是文件内容（字符串）：`{"入口。豫":"…","库/甲。豫":"…"}`。至多 4096 个文件；路径 1 至 512 个 UTF-16 码元，不含 NUL；内容总量至多 32 MiB（UTF-8 字节）。返回**编译号**（正整数，实例内递增，不复用），编译在后台进行。**同一时刻只允许一个编译**：已有编译在运行时抛事故；参数不合规或超限同样抛事故。

### `停止本地编译 : 有 → 爻`

停止正在运行的编译。确有编译在运行时返回阳，随后会投递一个“完成”事件（`成` 为假，`错误` 为 `已停止`）；没有编译在运行时返回阴。

## 事件

类型 `编译`，`订阅号` ＝ 编译号，同一编译的事件保持先后，最后一个总是“完成”。

### 名称 `进度`

```json
{"批":[{"类":"阶段","阶段":"load","标签":"正在加载浏览器编译器与标准库"},
       {"类":"输出","流":"stderr","文字":"正在编译：/库/标准库.豫\n"},
       {"类":"诊断","文字":"错误：…"}]}
```

宿主把 50 毫秒内到达的进度合成一批（1 至 64 项，一批总量至多约 1 MiB，更大的单项自成一批）。`类` 为 `阶段`（只带 `阶段` 与 `标签` 字段）、`输出`（只带 `流` 与 `文字`，`流` 为 `stdout` 或 `stderr`）、`诊断`（只带 `文字`）；客户端没给的值为空文字；客户端报告的其他类型被忽略。**编译器把正常的编译进度也写到标准错误**，应用不能凭 `流` 为 `stderr` 判断失败，应看 `完成` 的 `成`。进度事件不会丢失：宿主在队列里该编译的进度积压过多时暂缓合批的投递，直到应用取走（编译线程本身不受影响，时限由客户端负责）。

### 名称 `完成`

```json
{"成":true,"标准输出":"…","标准错误":"…","错误":"","阶段":"compile","产物摘要":"e3b0…"}
```

`成` 为编译是否通过；`标准输出`、`标准错误` 是完整输出（宿主**不截断**，应用上报云端时自行限长）；`错误` 是失败说明（例如 `已停止`、`加载或编译超过九十秒时限`、`编译客户端不可用：…`），成功时为空文字；`阶段` 是失败发生的阶段（`load`、`compile`、`run`），可为空；`产物摘要` 是编译产物的 SHA-256 十六进制，没有产物为空文字。“完成”之前，该编译所有已收到的进度先投递完。

## 限额与失败分类

| 项 | 限额 |
| --- | --- |
| 同时运行的编译 | 1 |
| 文件数 | 4096 |
| 路径 | 512 个 UTF-16 码元 |
| 内容总量 | 32 MiB（UTF-8） |
| 一批进度 | 64 项且约 1 MiB |

违规调用（文件 JSON 不合规、超限、已有编译在运行、宿主已关闭）抛豫言事故；编译失败、超时、客户端加载失败都通过“完成”事件（`成` 为假）报告，不抛事故。浏览器不具备所需能力时，`启动本地编译` 仍可调用，随即以 `完成`（`成` 为假，`错误` 说明缺少的能力）结束。

## 一致性样例

1. 对一个简单源文件 `启动本地编译`：依次收到若干 `进度` 事件（含 `阶段` 项）和一个 `完成`，`成` 为真，`产物摘要` 是 64 位十六进制文字。
2. 源文件含语法错误：`完成` 的 `成` 为假，`标准错误` 或 `错误` 含诊断，`进度` 里出现 `诊断` 项或标准错误输出。
3. 编译中途 `停止本地编译`：返回阳；收到 `完成`，`成` 为假，`错误` 为 `已停止`；随后可以再 `启动本地编译`。
4. 编译在运行时再次 `启动本地编译`：抛事故。
5. 编译客户端模块不存在：`启动本地编译` 返回编译号，随后 `完成` 的 `成` 为假，`错误` 以 `编译客户端不可用` 开头。
6. 客户端报告 100 条输出：应用收到的所有 `进度` 批里按顺序恰好 100 条 `输出` 项。

## 本地构建（0.2.0 起）

本地构建在浏览器里运行**一串命令**（豫构、编译器、测试程序等豫言 Wasm 工具），命令可以再启动子进程（豫构启动编译器，编译器并行时启动工作进程）。源码与工具链由宿主从同源网址取来，展开在内存文件系统里，结束后全部丢弃；云端只拿到进度与结果。

### 构建客户端

宿主通过“构建客户端”模块执行构建，默认从**页面基址目录下的 `构建/客户端.mjs`** 动态加载；创建宿主时可用选项 `构建客户端` 换成别的模块地址或已加载的对象。模块须导出：

- `浏览器构建(作业, 报告)`：返回 Promise，解析为 `{ok, results:[{argv, exitCode, ms}], error, phase, ms}`；过程中用 `报告(事件)` 回报 `{type:"stage",phase,label}`、`{type:"command",index,argv}`、`{type:"output",stream,text}`、`{type:"command-done",index,exitCode,ms}`。
- `停止构建()`：终止当前构建（客户端负责让上面的 Promise 以 `{ok:false,error:"已停止"}` 结束）。

语言仓的 `宿主/浏览器/构建/` 是参考实现（内存文件系统、进程表、每个进程一个 Web Worker，客体经共享内存同步问答；见其说明）。

### 函数

- `本地构建可用 : 有 → 爻`：本地编译所需的三者齐备，且页面跨源隔离（`crossOriginIsolated`，有 `SharedArrayBuffer`）时返回阳。只查浏览器能力，不检查客户端、快照与工具链能否加载。页面须带 `Cross-Origin-Opener-Policy: same-origin` 与 `Cross-Origin-Embedder-Policy: require-corp`（或 `credentialless`）。
- `启动本地构建 : 字符串(作业 JSON) → 整数`：返回**构建号**（正整数，实例内递增，不复用）。同一时刻只允许一个构建；已有构建在运行、作业不合规或超限时抛事故。
- `停止本地构建 : 有 → 爻`：确有构建在运行时返回阳，随后投递“完成”（`成` 为假，`错误` 为 `已停止`）；否则返回阴。

### 作业

```json
{"快照":{"网址":"/cloud/api/…/快照.tar.gz","剥离层数":1,"缓存":true},
 "工具链":{"网址":"/cloud/api/…/工具链.tar.gz","缓存":true},
 "改动":{"库/甲/甲。豫":"…","旧文件。豫":null},
 "命令":[["yy豫构.wasm","检查","甲"],["yy豫构.wasm","类型检查","甲"]],
 "环境":{},"继续":false,"处理器数":8}
```

- `快照.网址`、`工具链.网址`：同源网址（站内路径或同源绝对网址），内容是 gzip 压缩的 tar（ustar、pax 扩展头与 GNU 长名都认）。快照展开到 `/仓库`，去掉每个路径开头的 `剥离层数` 段（缺省 1，GitHub 的 tarball 外面包一层目录）；符号链接与特殊文件略过。`缓存` 为真时客户端把取到的归档存进浏览器的 Cache Storage，同一网址再取时直接用（只在网址里带提交号等不变标识时设为真）。
- 工具链是 Wasm 工具链包（CI 发布的 `yuyan-wasm` 包）：其中的编译器（缺省 `yy_bs_stable.wasm`，可用 `工具链.编译器` 指定）放到 `/仓库/yy4_bs.wasm`，豫构（缺省 `yy豫构_stable.wasm`，`工具链.豫构`）放到 `/仓库/yy豫构.wasm`，值桥（缺省 `yy稳定节点宿主/yy节点值桥接.wasm`，`工具链.值桥`）用于全部进程。
- `改动`：相对 `/仓库` 的路径到新内容（文字），`null` 表示删除；不得越出仓库。
- `命令`：依次运行，工作目录 `/仓库`；程序名是仓库里的 Wasm 文件（相对 `/仓库`）。某条失败（退出码非零）时停止，`继续` 为真则接着运行其余命令。
- `环境`：命令看到的环境变量（只有这些）。`处理器数`：标准库“在线处理器数量”的值，缺省 `navigator.hardwareConcurrency`。
- 作业 JSON 至多 64 MiB；命令 1 至 25600 条，每条 1 至 25600 个字符串。

### 进程与文件

- 每个豫言程序是一个进程，占一个 Web Worker；客体的文件、子进程与摘要请求经共享内存同步交给主线程处理。标准库的宿主服务按 Node 工具宿主的语义提供：文件读写删、列目录、路径判断、修改时间、当前目录（每个进程自有）、环境变量、异步子进程（启动、收取、多路等待）与同步子进程；构建基础提供存放包上下文、当前程序与指定文件的 SHA-256。没有标准输入与终端，`运行于Windows` 等三者都为阴，没有 TCP。
- 不是 Wasm 的程序只认内建命令 `mkdir`、`rm`、`cp`、`mv`、`true`、`false`；`env 变量=值… 程序` 与 `timeout [-k 秒] 秒数 程序` 两种包装由宿主拆开。其余程序启动失败（标准库得到退出码 127）。
- 子进程输出各至多 256 MiB。

### 事件

类型 `构建`，`订阅号` ＝ 构建号，最后一个总是“完成”。

- 名称 `进度`：`{"批":[…]}`，合批规则与编译相同；项的 `类` 为 `阶段`（`阶段`、`标签`）、`命令`（`序`、`参数`）、`输出`（`流`、`文字`）、`命令完成`（`序`、`退出码`、`毫秒`）。
- 名称 `完成`：`{"成":true,"错误":"","阶段":"build","毫秒":8330,"结果":[{"参数":["yy豫构.wasm","检查","甲"],"退出码":0,"毫秒":358}]}`。`成` 为全部命令都以 0 退出；`错误` 是失败说明（`已停止`、`命令失败`、`构建客户端不可用：…`、取归档失败等）；`阶段` 为 `load`（取快照与工具链）或 `build`（运行命令）。

## 边界

本包不规定：运行编译产物、增量编译与缓存、编译器资源（编译器 Wasm、标准库资料、Binaryen）的发布与版本核对、多编译并行、`仅编译` 以外的模式、把产物写入文件。本地构建不规定：构建缓存的保存、产物取回、工具链与源码版本的核对、多构建并行。
