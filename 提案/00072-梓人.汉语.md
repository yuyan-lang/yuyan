## 一、拟定事项

- 议一：新立库梓人，作设计语言的通用三维建模核心库，目标是能建模世界上出现的一切三维物品。
- 议二：不另立文件种类。模型写在设计源 `。设计。豫` 里，用标准豫言语法；梓人是普通库。
- 议三：照参数化 CAD（计算机辅助设计）的路子做：模型是参数的函数，记着尺寸、特征与配合；网格只是显示与交换用的产出。
- 议四：装配与尺寸上的错在编译期报出。构件是函数，端口是带类型的值，拼合是函数调用；离散量进类型下标，连续量按量纲分类型。
- 议五：多种表示并存，同受一套端口、量纲与核验管辖：精确实体、自由曲面、细分曲面、网格、距离场、体素与点云、曲线。
- 议六：核验在设计编译时跑。设计源编译时本来就运行顶层；「成品」收齐构件与核验，核验不过，设计编译即失败。
- 议七：一份模型多种产出：入景（交匠心成三维场景）、出图（交规矩出工程图）、导出（交换格式）与核对表。
- 议八：开源与私有分界。让通用建模成为可能的全部基础设施都开源，包括各种表示与操作、装配与机构、材料、核验、导入导出，以及程序化建模的通用设施。具体物品的建模代码与具体的程序化生成代码，放在使用它们的项目里。
- 议九：一条语言补充交审：只能用一次的值（第九节）。量纲不改语言。
- 议十：名字取梓人（第四节之一）。
- 议十一：分六期实施（第八节），每期都能单独合入、单独验收。

## 二、动机

### 现状

- 设计源（提案 00018）已能写文档、幻灯片、动画与二维图。三维部分由匠心（设计引擎）导入传景（glTF 三维模型格式）网格，再加光照与关键帧。
- 几块三维能力已经有了，分在几处：
  - 勾股（计算几何库）：三维基本体（圆柱、圆台与圆锥、球、长方体、正棱柱、回转体），第一角画法的三视图（分可见与不可见轮廓），两形体的相贯线，形体的三角网格；
  - 规矩（工程制图库，提案 00049）：按国标出图纸，有视图、尺寸注法、公差与剖面；
  - 质测（碰撞库）：球、盒、胶囊与三角网格的求交与穿透深度，层次包围盒，射线；
  - 匠心里的匠石（程序几何，提案 00018 第五期）：按参数生成三角网格，有圆柱、圆锥、圆环、胶囊，挤出（可带洞与倒角）、旋转体、沿折线或贝塞尔曲线扫掠、卢氏细分、噪声位移、合并与变换，同参逐位相同；
  - 匠心里的动作与牵骨（反向动力学）：骨骼姿态、状态机、混合空间；
  - 界画（实时三维光栅化库）：把三角网格画成像素；
  - 豫章（标准库）的「量」（带单位的量）：一个数与一个单位类型合成，同单位才能加减。
- 缺的是中间那一层：从参数造出形体，把形体拼成装配，并在编译期核对拼得对不对。

### 问题

只用网格、折线这类“一堆点”描述三维物体，什么样的错都写得出来：两段接不上、错位、数目对不上、单位混用。模型里没有尺寸、端口与配合，错只能等渲染出来、看图才发现，修好一类又冒出下一类。

### 为什么照 CAD，不照 Blender

| | 参数化 CAD | Blender |
| --- | --- | --- |
| 给谁用 | 工厂、工地，照着造出来 | 眼睛：影视、游戏、动画 |
| 模型里存什么 | 精确实体：平面、圆柱面、曲面，各有确切尺寸 | 多边形网格：顶点与三角形、四边形 |
| 一个直径一百毫米的孔 | 存成“圆柱孔，直径一百，轴线在此”，能问直径，能与配件比对 | 一圈几十个顶点；是不是孔、直径多少，模型自己不知道 |
| 怎么建 | 草图加尺寸约束，再拉伸、回转、开孔；改一个尺寸整体重算 | 直接拖点、雕刻、加修改器；几何节点能程序化 |
| 零件之间 | 装配约束（同轴、贴合）、干涉检查、公差 | 父子层级，物体可以互相穿插 |

- 能静态检查的前提，是模型里有可查的东西：尺寸、孔、配合。
- 参数化建模本来就是“模型等于参数的函数”，正好对应豫言函数；OpenSCAD、CadQuery 就是用代码写 CAD。
- 精确表示能转成网格，网格转不回精确表示（只能近似拟合）。拿 CAD 打底，Blender 要的网格照样出得来。
- Blender 擅长的有机形体，由本提案的细分曲面、距离场与骨骼绑定补上（第三节），仍受同一套端口与核验管辖。

### 静态保证

| 错 | 怎么挡 | 哪一步报 |
| --- | --- | --- |
| 数目对不上（股数、齿数、孔数） | 依值类型下标 | 类型检查 |
| 量纲混用（长度当角度、毫米当兆帕） | 「量」的单位类型 | 类型检查 |
| 截面接错（圆管口接到方管口） | 端口的截面类型 | 类型检查 |
| 位置、朝向断开或错位 | 位姿由前一个端口推出 | 写不出来 |
| 漏接、重复接 | 「成品」按身份数端口；有了第九节的补充，由类型挡住 | 设计编译；补充后在类型检查 |
| 尺寸不合要求（最小弯曲半径、壁厚、间隙） | 核验 | 设计编译 |
| 两件互相穿插 | 干涉核验（质测求交） | 设计编译 |
| 运行时数据自相矛盾（从外部数据批量造模型时） | 程序只能经类型化的构造函数造模型，矛盾处由鉴穷尽地处理 | 程序本身在编译期查；数据在运行时进核对表 |

## 四、设计

写法照语言技术规范《依值类型》《标签函数类型》两篇，签名照提案 00065 带标签；下面是草样，细节以编译器为准。

### 之一：定位与取名

梓人取柳宗元《梓人传》：梓人“画宫于堵，盈尺而曲尽其制，计其毫厘而构大厦，无进退焉”。先在墙上画出全图，按毫厘算定，再造大厦，没有一处要返工；正合本库“先在类型里核对，再造出形体”的意思。

梓人不另写网格生成：转成三角网格沿用匠石，精确的量与出图用勾股。勾股的形体网格与匠石重叠的部分，统筹时并成一处。

梓人放在 `库/梓人/`，登记在「库」父包下；依赖豫章、大衍（任意精度整数库）、勾股、匠心、规矩与质测。

### 之二：设计原则

1. 构件就是函数，端口是带类型的值，拼合就是函数调用：类型对不上就编不过。
2. 后一个构件的位置由前一个端口推出，不另写坐标：位置与朝向的连续由构造保证。
3. 离散量进类型下标，由依值类型在编译期核对。
4. 连续量按量纲分类型；常量约束在设计编译时核验。
5. 表示与端口、核验分开：换一种表示，端口、量纲与核验照用。
6. 结果各宿主一致：同一模型在林纳、轩窗、林檎与豫言操作系统上求出逐位相同的几何（之十五）。

### 之三：量纲

复用豫章「量」（`形制/量`）。它现在是一个整数与一个单位空类型的合成：同单位才能加减，换算只在明写的一处做。扩两处，都只改库：

- 加小数版本，与整数版本并列，原有接口不变；
- 量纲代数：单位类型带长、质、时三个整数指数作下标，相乘时指数相加，相除时相减。现有的整数多项式规范化就能核对，如曲率是长度的负一次方，压强乘面积得力。

```yuyan
「长」立「类」也。
「角」立「类」也。
「长度」即（「小量」于「长」）也。
「角度」即（「小量」于「角」）也。
「米」乃化「小数」为「长度」者也。
「毫米」乃化「小数」为「长度」者也。
「度」乃化「小数」为「角度」者也。
```

内部统一存毫米与弧度，「米」「毫米」「度」只是造量的函数。「小量」是「量」的小数版本，名字实施时定。

### 之四：位姿与参考系

- 位姿是一个原点加三根正交的轴（右手系），由平移与旋转合成；
- 每个构件在自己的局部参考系里造，拼合时由端口的位姿摆到位；
- 「相对」把一个位姿放进另一个位姿的参考系，装配树逐级相乘。

```yuyan
「位姿」立「类」也。
「原位」乃「位姿」也。
「相对」乃化「基」曰「位姿」又化「局部」曰「位姿」为「位姿」者也。
```

### 之五：表示

| 表示 | 用于 | 怎么转成三角网格 |
| --- | --- | --- |
| 精确实体 | 工程件 | 按面剖分 |
| 自由曲面（NURBS，非均匀有理样条） | 流线外形 | 按弦高误差剖分 |
| 细分曲面 | 有机形体 | 逐级细分 |
| 网格 | 外来件、显示 | 本身 |
| 距离场 | 自然物、光滑融合 | 对偶轮廓法 |
| 体素与点云 | 扫描件、地质体 | 曲面重建 |
| 曲线 | 线缆、头发、路径 | 沿曲线扫出截面 |

- 每种表示都给出同一组能力：包围盒，按精度求三角网格，点在内外，到表面的有向距离，体积、面积与质心，出图用的轮廓。
- 相互转换：任何表示都能转成网格；网格、精确实体、曲面都能转成距离场，供光滑融合；点云能重建成网格。
- 精确的量（尺寸、体积、质心）尽量在原表示上算，不经网格。

### 之六：端口与拼合

```yuyan
「口」立化「类」为「类」者也。
「件」立「类」也。
「口位」乃凡「截」而化（「口」于「截」）为「位姿」者也。
「立口」乃凡「截」而化「于件」曰「件」又化「位」曰「位姿」又化「截面」曰「截」为（「件」合（「口」于「截」））者也。
「封」乃凡「截」而化（「口」于「截」）为「件」者也。
```

- 端口是带截面类型的值，记着位姿、截面参数与身份（哪个件的哪个口）。
- 截面类型由库或项目自己立，如圆管口、方管口、螺纹口、握持口。两个口截面类型相同才能接。
- 每个口要恰好用一次：接下一个构件，或用「封」（封口）收掉。「成品」按身份数出漏接与重复接；第九节的补充能让类型检查直接挡住。
- 装配约束（同轴、贴合、相距）写成端口上的拼合函数，由端口的位姿直接算出后一件的位姿，不解方程组。成环的装配（四连杆这类闭链）要解约束，列入第六期。

### 之七：股束

股束是 n 股并排的东西，如线缆、管束、轨道；股数是类型下标。

```yuyan
「束」立化「数」又化「类」为「类」者也。
「分束」乃凡「股」而化「留」为「数」者「甲」而化「出」为「数」者「乙」而化（「口」于（「束」于（「甲」加「乙」）于「股」））为（（「口」于（「束」于「甲」于「股」））合（「口」于（「束」于「乙」于「股」）））者也。
「合束」乃凡「甲」属「数」又凡「乙」属「数」又凡「股」而化（（「口」于（「束」于「甲」于「股」））合（「口」于（「束」于「乙」于「股」）））为（「口」于（「束」于（「甲」加「乙」）于「股」））者也。
```

- 「分束」的两个数目只出现在复合式里，推不出来，所以显式带标签写：`于「留」曰「三」于「出」曰「二」`。「合束」的数目在实参类型里单独出现，能推出来。
- 「增束」「减束」同理。
- 分出的那一支，端口位姿在原束最外一股的外缘。

### 之八：参考线与路径

```yuyan
「途段」立「类」也。
「途」立「类」也。
「直行」乃化「长度」为「途段」者也。
「弯行」乃化「长」曰「长度」又化「半径」曰「长度」为「途段」者也。
「缓和」乃化「长」曰「长度」又化「起曲率」曰「曲率」又化「止曲率」曰「曲率」为「途段」者也。
「接龙」乃化（「列」于「途段」）为「途」者也。
```

- 每段从上一段末端的位置与朝向接着走，所以位置与朝向连续由构造保证；缓和曲线（回旋线）还让曲率连续。
- 另有竖向的坡段与竖曲线、螺旋线、过给定点的样条。

### 之九：成形操作

```yuyan
「拉伸」乃化「截面」曰「面域」又化「位」曰「位姿」又化「高」曰「长度」为「件」者也。
「回转」乃化「截面」曰「面域」又化「轴」曰「轴线」又化「角」曰「角度」为「件」者也。
「扫掠」乃化「截面」曰「面域」又化「途」曰「途」为「件」者也。
「顺行」乃凡「截」而化「始」曰（「口」于「截」）又化「途」曰「途」为（「组类」【「形体」乃「件」也，「末口」乃（「口」于「截」）也】）者也。
「过渡」乃凡「甲截」又凡「乙截」而化「始」曰（「口」于「甲截」）又化「止」曰「乙截」又化「长」曰「长度」为（「件」合（「口」于「乙截」））者也。
```

- 基本造形：勾股已有的基本体，加上拉伸、回转、扫掠、放样，截面取勾股的二维面域。
- 从口出发：「顺行」沿路径扫出口的截面，交回形体与同一截面类型的末口，下一段只能接同一种截面；「过渡」在两种截面之间放样，交回新截面的口。
- 修形：布尔（并、差、交），圆角与倒角，抽壳，偏置与加厚，阵列与镜像，开孔（差加立口）。
- 有机形：细分，变形器（弯曲、扭转、晶格、骨骼蒙皮）。

### 之十：程序化设施

- 可复现的随机：一切随机都从显式的种子来，同一种子在各宿主上得逐位相同的结果。
- 噪声（梯度噪声与分形叠加）、侵蚀、生长规则（重写规则，即 L 系统）、散布（在面上按密度撒点并互相避让）。
- 这些是通用设施，开源；用它们生成某一类具体物品的规则，放在各自的项目里。

### 之十一：装配、关节与机构

- 关节：转动、移动、球铰与固定，各带运动范围（角度或行程）。
- 机构：关节连成的树，给定各关节变量求各件位姿（正运动学）；与匠心的动作、牵骨衔接，绑了骨骼的人物也是一种机构。
- 运动中的干涉：在运动范围内取样核验。

### 之十二：材料

- 材料是附在件上的值：物性（密度、弹性模量、强度）与外观（颜色、纹理、粗糙度、金属度）。
- 由物性算质量与质心；外观交匠心渲染。
- 本库只立材料的类型与计算；具体的材料牌号表放在各项目里。

### 之十三：核验与成品

- 「验」：一条核验，求值时算，交回成否（结果类型）。
- 通用核验：干涉、最小间隙、最小壁厚、最小弯曲半径、尺寸在公差之内、端口全接、实体封闭（无破面）。
- 「成品」：收齐构件与核验，组成作品。核验不过，或还有没接也没封的口，就告祸，设计编译随即失败，报出核验名、实际值与源位置。核验结果不会被丢掉。
- 运行时造出的模型照样交「成品」；失败时交回成否，由调用方用鉴分开成败处理。

### 之十四：产出与导入

- 入景：件转成匠心的三维场景节点（三角网格，带材料外观）。
- 出图：件交规矩出视图、剖面与尺寸标注。精确实体的轮廓与相贯线用勾股的解析投影，不经网格。
- 导出：传景（显示与交换）；三维打印用的三角网格格式；精确实体的交换格式见第七节。
- 导入：传景网格与点云。

### 之十五：数值与各宿主一致

- 几何计算用双精度小数。稳健判定（方向、相交、内外）先用带误差界的双精度，判不准时退到大衍的有理数精确计算，与勾股现行做法一致。
- 剖分、布尔、细分等算法的结果只取决于输入：不依赖散列遍历的先后；要求各宿主逐位相同的数学函数（三角函数等）由库自己实现。

### 之十六：样例

样例一，线缆束分岔：

```yuyan
「线缆」立「类」也。
「线缆口」乃化「位」曰「位姿」又化「股数」为「数」者「甲」而化「径」曰「长度」为（「口」于（「束」于「甲」于「线缆」））者也。

「布线样」者
　令「始」为「线缆口」于「位」曰「原位」于「股数」曰「五」于「径」曰（「毫米」于「八」）而
　令「干」为「顺行」于「始」曰「始」于「途」曰（「接龙」于（「列」【「直行」于（「米」于「二」）】））而
　令「岔」为「分束」于「留」曰「三」于「出」曰「二」于（「干」中「末口」）而
　令「左支」为「顺行」于「始」曰（「岔」中「零」）于「途」曰（「接龙」于（「列」【「直行」于（「米」于「一」）】））而
　令「右支」为
　　「顺行」于「始」曰（「岔」中「一」）于「途」曰（「接龙」于（「列」【「弯行」于「长」曰（「毫米」于「三零零」）于「半径」曰（「毫米」于「二零零」）】））而
　「成品」
　　于「件们」曰（「列」【「干」中「形体」，「左支」中「形体」，「右支」中「形体」，「封」于（「左支」中「末口」），「封」于（「右支」中「末口」）】）
　　于「核验」曰（「列」【「弯径不小于」于「件」曰（「右支」中「形体」）于「限」曰（「毫米」于「四八」）】）
也。
```

- 把「分束」写成留三、出三，编译报 `「束」于「五」` 与 `「束」于（「三」加「三」）` 不合。
- 漏写一个「封」，设计编译报“口没接也没封”，并指出是哪个件的哪一端。
- 弯曲半径小于线缆允许的最小值，设计编译报核验失败与实际半径。

样例二，齿轮啮合：

```yuyan
「齿轮」立化「数」又化「数」为「类」者也。
「造齿轮」乃化「模数」为「数」者「模」而化「齿数」为「数」者「齿」而化「宽」曰「长度」为（「齿轮」于「模」于「齿」）者也。
「啮合」乃凡「模」属「数」又凡「甲」属「数」又凡「乙」属「数」而化（「齿轮」于「模」于「甲」）又化（「齿轮」于「模」于「乙」）为「件」者也。

「齿轮样」者
　令「主动」为「造齿轮」于「模数」曰「二五零」于「齿数」曰「二零」于「宽」曰（「毫米」于「二零」）而
　令「从动」为「造齿轮」于「模数」曰「二五零」于「齿数」曰「四零」于「宽」曰（「毫米」于「二零」）而
　「成品」于「件们」曰（「列」【「啮合」于「主动」于「从动」】）于「核验」曰（「罄」以「核项」）
也。
```

- 模数以百分之一毫米为单位作类型下标（二五零即二点五毫米）。两个齿轮模数不同，「啮合」编不过。
- 中心距由模数与两个齿数算出，从动轮自动摆到位。

样例三，带挂点的人物：人物的手上各立一个握持口；「持」只接截面类型为握持口的东西，杯子接不到脚上。骨骼动起来，手里的东西随手走。

## 五、兼容与迁移

- 新库，不改现有接口。豫章「量」只加小数版本与量纲指数，原整数版本照旧；勾股只加模块。
- 设计源写法不变，也不加新的文件后缀。
- 现有用传景导入网格的设计源照旧可用；以后可以改由梓人摆放并核验。

## 六、备选方案

- **另立文件种类（如只管某一领域的子语言）**：建模既不换后端，也不需要另一套写法限制；静态保证来自类型，放在哪种文件里都管用。另立种类只多出一个前端模式，不取。
- **以网格为本（照 Blender）**：网格里没有尺寸、端口与配合，无从静态检查，也转不回精确表示。不取。
- **只用距离场一种表示**：布尔与融合简单稳健，但尺寸不精确，出不了精确的工程图。只作表示之一。
- **接外部几何内核**：豫言只写豫言（AGENTS.md），不接其他语言写的内核。不取。

## 七、未决问题

1. 精确实体的内部表示。（甲）特征树按需求值：存参数化的特征树，量度从参数算，显示与干涉经网格。（乙）完整的边界表示：面、边、顶点的拓扑加精确曲面。建议第一期取（甲），第二期做布尔与圆角时再定要不要（乙）。
2. 「量」小数版本的名字与放处。
3. 导出精确实体用哪种交换格式。
4. 常量核验要不要提前到类型检查（编辑时就标红）。设计编译已能报出这类错，本提案暂不提这项语言改动。
5. 名字：梓人。

## 九、语言补充（交审）：只能用一次的值

- 端口要恰好用一次。设计源里，「成品」能在设计编译时数出漏接与重复接；运行时造模型的程序（如从外部数据批量造模型）只能在运行时数，编译器保证不了它对任何输入都不漏口。
- 建议：线性类型，即只能用一次的值。端口类型标成只能用一次，编译器核对它在每条路径上恰好被用一次，漏用、重用都是编译错误。
- 这与议题 #1446「必须且只能消费一次的凭据」是同一种建议（那边管登记的句柄、预留的槽），写法照那边议定的办，不另加关键词。本提案的案例见议题 #1504，登在语言设计建议表同一条下。
- 不做这一条，梓人照样能用：漏接由「成品」在设计编译时报。
