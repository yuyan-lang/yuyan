## 一、缘起

00029 把标准库的名字改雅，00031 把翻译列表的译名改雅。用户 2026-10-14 要再推一步：为语言仓里所有包的公开接口找古雅的名字。

## 二、盘点

豫言没有私有名，模块的顶层定义都对外可见，所以“公开名字”按库包里各模块的顶层定义（「名」乃、者、立）计；测试文件、脚本与示例不计。全仓 541 个包，其中库包 425 个、模块 2,831 个、公开名字 35,455 个。可执行包没有对外接口，第一版只改库包；可执行包的包名留待后续版本。

## 三、原则

沿用《取名规范》与提案 00029、00031：先看它是什么、做什么，再找中国本有的事物、制度、典故里与之神似的名字，注明出处；一事一字，同族成套；不计实施代价，原定的名字也再求更好的。包名另守以下几条：

1. **包名取能概括全包的古名。** 书名、官署、器物、技艺都可取：编译器核心作**译场**（唐宋译经的译场），构建基础作**营造**，构建编排作**法式**（宋《营造法式》），线性代数作**方程**（《九章算术·方程》），证书作**告身**（唐代授官的凭证），根证书数据作**印谱**，壳命令作**诏令**，壳核心作**中书**（中书省草拟、发布诏令），分词器作**庖丁**（依天然关节下刀）。
2. **随已定的译名与库名。** 00029、00031 已定的名字照用：标准库作豫章，超文本传输作书札，安全传输作封缄，统一码作同文，正则作格律，结森工具作结绳，嵌入数据库作芥子，时区数据作时宪。
3. **宿主作东道。** 出自《左传·僖公三十年》“若舍郑以为东道主”：浏览器宿主作网览东道，诺节宿主作诺驿东道；模拟作沙盘（沙盘推演）。
4. **分组父包。** 基础库总称**群书**，其下各组作“某部”，取经史子集四部之“部”（仓颉部、括囊部、乐府部……）；应用分组作“某坊”（百工坊、刊行坊……）；库/ 根作**百家**。
5. **测试包随主名。** 测试作“试”（同豫章试），全量测试作“全试”，变异与模糊测试作“变试”，性能测试与验证作“速验”，与系统库对照、核验作“对勘”，全量核验作“全验”，云端复验作“云验”。
6. **操作系统一族成套。** 豫言操作系统作**豫寓**（00029 操作系统作寓所）。接口包作“豫寓＋词干”，如文件作豫寓藏书、时间作豫寓时辰、网络作豫寓驿；适配包作“豫寓＋词干＋平台＋榫”（适配即榫，与 00031 接口作榫卯相应）。平台：原生作本土，浏览器作网览，节点与诺节作诺驿，模拟作沙盘，通用与共用作通，云工照旧，没写平台的（云工上的默认实现）只作“榫”。如豫言操作系统文件节点适配作豫寓藏书诺驿榫。
7. **模块名与公开名字先换通用用字，再逐名覆核。** 第九节是全仓通用的用字表（随 00029、00031 已定的字，加本提案新定的），长词先换；各包另有本包用字与规则，最后逐名看过，读错、撞名、叠字的另拟。不改的名字逐个写明理由，分类见第十节。
8. **一部之内成套取喻。** 如译场（编译器核心）的各编译步骤照宋代译经院的九职取名（《佛祖统纪》卷四十三）：总领全程作译主，验类作证义，语法分析作缀文，生成代码作笔受，优化作刊定，排版打印作润文，名称解析作正名（《论语·子路》“必也正名乎”）。

## 五、模块名与公开名字的分批

公开名字逐包拟定，分十一批写进附表（各批见第七节，进度见第八节）。每包列出全部模块名与公开名字：现名、用量、拟名、依据。做法：

1. **先换通用用字**（第九节），长词先换；再依各包本包用字、本包规则与通例改写；最后逐名覆核，读错、撞名、叠字的另拟，依据栏写明。
2. **随包取喻**：译场的编译各步照宋代译经院九职取名；法式照《营造法式》（制度、施工、料）；诏令的文件命令随 00029 书卷一族（所居、迁、列目、阅、著、焚）；封缄以宾主喻两端（服务端作主，客户端作客）；书札里服务器事件作邸报、首部作抬头。
3. **依语境保留原义**：同一个今语词在不同包里意思不同的，按包另定。作图里的“混合”指合成，不作“杂”；排版与作图里的“定位”指排布，不作“定”；语法与约束里的“原子”指原子单元，不作“一气”；文献与标记文里的“引用”指引文，作“引”；环境变量一族的“环境”作水土，其余“环境”作境；诺驿适配里的“节点”指诺节。
4. **豫章照搬 00029**：标准库 600 个名字全依 00029 改名表（含并名与“其余不变”的三十一个）。

**第二遍（2026-10-15）。** 用户问：拟名为何多不如「列」雅？原因是第一遍以用字表逐词替换为主，换出来的多是今语的压缩，依据栏又笼统写“现名已切”。第二遍改为逐名看签名与注释，按它做什么取古名：

1. **跨包用到的名字逐个复看**（七千余个），并补了一批取喻：快照作存照（契约“立此存照”），缩进作低格（旧式书写敬语抬头、正文低格，与抬头同族），转义作避讳、解转义作回改（陈垣《史讳举例》），取前几大作拔萃（《孟子》“拔乎其萃”），旋转位置编码作斗转（《鹖冠子》“斗柄东指，天下皆春”），斜边作弦（《周髀算经》勾股弦），立方根作开立方（《九章算术·少广》），书后索引作引得（洪业《引得说》），急就的内建对象一部作“某典”，诏令的关机作息、重启作更始、帮助作问津、回显作复述、安装系统作安寓、更新系统作葺寓、下载作索书。
2. **补齐 00029、00031 已定而未用上的名**：响应一律作回书，关系库作问簿，HTTPS 作缄札，画布作画绢，网格作界格，控制台作案头，历史作史，差异作校勘，回调作回音，聚焦作凝神，滚动作舒卷，换行作提行、回车作回首，舍入作约，两数取大取小作大者、小者，小于等于作不大于；名中带阿拉伯数字的译名（阿氏三二、提要五、口令衍二、氩二混、多式一三零五）一并换上；以人名命名的照 00031 取姓氏首字加“氏”（高氏、贝氏、伯氏、霍氏、泰氏、汉氏等）。
3. **清扫误读**：用结巴词频表扫出替换时拼出的今语词（“行使者”“生态”“千手术”“正体操作”“急就集合法”“名列”“诸多边形”等百余处），逐个另拟；谓词去“吗”而无判断字的一律加“为”，名中的“们”一律作“诸”。
4. **不改的名字逐个写明理由**，分类、检验与存留词表见第十节；依据栏不再写“现名已切”。

每一批只改名字，不改行为；用量按 `git grep` 计全仓出现次数。

## 六、迁移

1. **包改名。** 改包描述的「名称」、包所在目录、父包的「包含包」与子包的「包含在」、各包「依赖」、每句导入的路径与默认导入清单；云仓同步。豫构里写死的包名与路径（如认仓根用的 `库/标准库`）要换钉两步走：豫构先认新旧两名，CI 发布新工具链、改钉之后再删旧名。
2. **与 00027、00029、00031 同批。** 关键词、标准库、译名与本提案的名字一起改，一次切换。
3. **不计实施代价。** 包名、目录名的改动面大，照改；迁移时逐包核对撞名。

## 十、不改之名

「列」是雅名的样子：一个古字，义与所指之物恰合。第二遍逐个看过不改的名字，依据栏按下列各类写明理由；名字由词与单字组成的，按词切开，逐类标出。

| 类 | 说明 | 例 |
| --- | --- | --- |
| 单字 | 一字取其本义 | 「乘」「段」「辍」 |
| 古词 | 古已有之、义与今同的成词，见下面的存留词表 | 「约束」（《史记》“约束既布”）「定位」（《易》“天地定位”） |
| 算学旧名 | 明清以来算学的旧译，与 00029 的中缀本名 | 「矩阵」「函数」「等于」 |
| 00031 定名 | 00031 审过的译名 | 「网页」「像素」「二维码」 |
| 今通行术语 | 古无其物、今已通行的术语，用得最多的二十个见下面的检验 | 「字节」「后端」「脚本」 |
| 专名 | 音译的专名、文种名与外来的专门术语 | 「赛尔特」「丝路」「印度」 |
| 豫言类名 | 随 00027 不改的类名 | 「小数」 |
| 本提案用字 | 第九节换出的字，原名恰已如此 | 「有号」「单精」 |
| 常词 | 今人常用、字面即义的词 | 「暂停」「补零」「预览」 |
| 单字连缀 | 由单字连缀成的精简名，各字取本义 | 磐石的「读四」（读四个字节） |

全部 36,251 个名字里改了 23,715 个，不改 12,536 个：单字 108 个；单字连缀 2,376 个；只含古词、算学旧名、定名、术语与专名的 5,769 个；含常词的 4,283 个。常词共 1,883 个，第二遍逐个过目：能找到更切的古名的已经换掉（如诏令的关机作息、重启作更始、帮助作问津、回显作复述，见诏令附表），其余字面即义，照留。
