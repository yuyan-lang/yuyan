## 摘要

1. **今制文采之失在文法与句读；关键字的平仄影响甚小。** 今制十五篇共 42 读，36 读不成文言（违例率 86%），平均读长 17.9 字，平收率 7%，关键词与核心名中有今语 12 个，没有主文体。按实际用量，今制关键字的平声比是 43%，反而高于 wenyan（36%），提案 00025 的“结构关键词几乎都是仄声”按词表成立、按用量不成立；读来短促的主因是一句到底、以“也”收束。
2. **研究给出两套完整方案，方向不同：**
   - **甲案「正名」（简劲）：** 以经学训诂为体。签名 `「平方和」，化二数为数也`，定义 `「平方和」者，受「甲」「乙」，……也`，局部名 `「甲」乘「甲」，谓之「甲方」`，局部递归 `所谓「乘至」者，……也`，匹配 `罄则零；「首」缀「余」，则……`。十五篇共 581 字，比今制少 23%。
   - **乙案「算经」（铺陈）：** 以《九章算术》为体。签名是一道题 `今有二数，问「平方和」几何？`，定义是一段术文 `「平方和」术曰：命之曰「甲」「乙」；「甲」自乘，名曰「甲方」；……并「甲方」「乙方」，即得所求。`，调用 `以「求和」术入「余」`，匹配 `视之：其罄者，得零；其「首」缀「余」者，……`。十五篇共 735 字。
3. **两案共同的改动：** 虚词一律回到本义（“于……于……”改为“以”统领实参，“化……而”改为“化……为”，“授以”改为施受得当的写法，“中零”改为“之一”“之二”）；每句加句读，读长四至五字；数字用古法计数；核心名雅化（书、呜呼、罄、缀、可有、可无、或有之数），类型名改为数、量、言、爻、类；今语清零。阴、阳、爻、元、鉴、罄、缀、可有、可无、“者……也”等今制的佳处都保留。
4. **评分（满分一百）：** 今制 30，wenyan 69，甲案 76，乙案 78。两案的文法违例率都是 0%（wenyan 3.5%）。甲案胜在文法、用字与简省；乙案胜在节奏（四字六字读 44%）、平声收束（41%）、情味与题术呼应。两案分差在评分误差之内，取舍主要看方向：要简劲、与今制一脉相承，取甲案；要文采与叙述之美，取乙案。
5. **需要用户定夺的问题**见第七节第 5 小节：方向、“之”的统一用法、核心名是否裸写、古法计数、类型名“量”、“附”与“属”、乙案的“当前之数”、繁体竖排。

同一篇程序（B5 求和）的四种写法：

```
今制：
「求和」乃化（「列」于「整数」）而「整数」也。
「求和」者会「数列」而
　鉴「数列」而
　　有「罄」则「零」
　　或有（「缀」于「首」于「余」）则「加」于「首」于（「求和」于「余」）也。

wenyan：
吾有一術。名之曰「求和」。欲行是術。必先得一列。曰「數列」。乃行是術曰。
　若「數列」之長等於零者。乃得零也。
　夫「數列」之一。名之曰「首」。
　夫「數列」之其餘。名之曰「餘」。
　施「求和」於「餘」。加其以「首」。乃得矣。
是謂「求和」之術也。

甲案「正名」：
「求和」，化数之列为数也。
「求和」者，受「数列」而鉴之：罄则零；「首」缀「余」，则「首」加「余」之「求和」也。

乙案「算经」：
今有数之列，问「求和」几何？
「求和」术曰：命之曰「数列」，视之：其罄者，得零；其「首」缀「余」者，以「求和」术入「余」，并「首」，即得所求。
```

## 一、方法

### 1. 定调

- **字调依《广韵》。** 用 nk2028 整理的《广韵》数据（`tshet-uinh-data` 的 `韻書/廣韻.csv`，25,337 条，每条带音韵地位，末字即平、上、去、入），上、去、入归仄。
- **简体到繁体。** 源码是简体，《广韵》是繁体。用 OpenCC 的简繁字表（`STCharacters.txt`）把每个简体字映到它的全部繁体字形，连同简体字本身一起查《广韵》，取各读声调之并。全为平声的记“平”，全为上去入的记“仄”，平仄兼有的记“两读”。
- **两读按义定调。** 四套写法共用到 216 个汉字，其中 36 字两读或《广韵》未收，另有“样”字《广韵》所收为别义，共 37 字按义定调。这些字逐一按所取之义定调，写进《定调表》（第八节），例如“乘”取相乘义（食陵切，平）、“中”取内中义（陟弓切，平）、“观”取观看义（古丸切，平）、“量”作类型名取容量义（力让切，去）、“几何”之“几”（居狶切，上）、“疏”取注疏义（所去切，去）。“样”字《广韵》只收训“槌”的平声“样”，与式样无涉，依《集韵》余亮切归去声，标“待核”。
- **记号。** ○ 平，● 仄，◐ 两读未定（本研究定调后已无），－ 停顿（字符串、注释）。

### 2. 句读与停顿

- **读界。** 源码里的 。，；：？！ 为读界。
- **列举之隔不断读。** 顿号“、”与今制【】内的逗号都是列举项之间的短顿，算符号，不断读。
- **停顿。** 『』字符串与注释的内容不计字、不计调，在记谱中记作一个停顿“－”；停顿把读内分成若干段，音步与平仄连串不跨停顿。名字「」中的字照字计拍、计调（协议第五节记谱法）。

### 3. 定步法

协议要求“二字为步，允许一个三字超音步”，但没有规定怎样划步。为了用同一把尺子量四套写法，本研究用一个确定的算法划步：

1. 读内每段先切词：名字是一个词；裸写的关键词按各方案的词表取最长匹配（如“之书”“谓之”“不然”“是为”“欲行是術”）；其余单字各自成词。
2. 二至三字的词不可拆；四字以上的名字与关键词只能在偶数位拆（「尝试运行」只能拆成 尝试｜运行）。
3. 在不拆词的前提下求代价最小的划分：二字步代价 0，三字步 1，单字步 10；同价时把三字步放在后面（五言二三、七言四三之例）。

例：wenyan 的“吾有一數。曰三。名之曰「甲」。書之。”划为 吾有｜一數‖曰三‖名之｜曰「甲」‖書之，与协议例一相同。

### 4. 度量

协议第五节各维度的度量，在本研究中的具体算法如下。

| 度量 | 算法 |
| --- | --- |
| 交替率 | 段内相邻两步，末字都有定调者，平仄相反的比例 |
| 平收率 | 以平声字收束的读，占末字有定调之读的比例 |
| 平声比 | 平声字占平仄字的比例 |
| 违律数 | 段内同调连续三字以上的串数（三平、三仄各算一次，五仄连用也只算一次） |
| 读长 | 每读的字数；报告平均读长、三至七字读所占比例、四字六字读所占比例、超过九字的长读比例、单字读比例 |
| 音步完整率 | 读内没有单字步、三字步不超过一个的读所占比例 |
| 符号密度 | 字符串与注释内容以外的非汉字符号（「」『』（）【】、。，；：？！等）每百字的个数；另报不含 。，；：？！ 的“除句读符号” |
| 简繁 | 每篇总字数与关键字数（裸写的汉字）；每个意思所用关键字数见第六节 |

以上都由一个用豫言写成的脚本计算（约千行，读《广韵》与繁简字表、切读、定步、出记谱与度量表，以 `yy豫构 运行` 执行；属草稿工具，未入库）。附录中的记谱与度量表都是它的直接输出。

### 6. 语料与引文

- 引文出处在殆知阁古籍语料（GitHub `garychowcmu/daizhigev20`，简体为主，约 7 GB）里逐条核对原文与篇名。正文以“引某”指向第八节《引文表》，表中录核定的原文、篇名与语料位置；语料中找不到或篇名未定者注“待核”。

### 7. wenyan 对照写法

wenyan 的十五篇按其源码 `src/keywords.ts` 与 `documentation/wenyan.g4` 的语法写成，保留繁体。wenyan 没有类型签名、代数类型、可选类型、元组与匿名函数，这些地方用它的惯用写法近似：参数类型写在“必先得……”里；树与对子用列表示；可选值用零或一项的列表示；匿名函数改为内嵌的具名之术。附录逐篇注明。

## 二、假设检验

协议第二节列出提案 00025 的初步品评，要求“当作假设检验，可证实也可推翻”。逐条结论如下（频次指第一节第 6 小节所列先秦十九种、两汉九种文献中的出现次数）。

### 1. 豫言的长处

| 观察 | 结论 | 证据 |
| --- | --- | --- |
| `「名」者……也` 是判断句正体 | 证实 | “陈胜者，阳城人也”（《史记·陈涉世家》）；“者”“也”在先秦文献中各出现一万七千余、三万七千余次，“X者，Y也”是最常见的判断式。甲案原样保留 |
| `乃`、`即` 作系词得体 | 部分证实 | “乃”“即”作系词都有据（“乃”先秦 2721 见，“即”两汉 2027 见）。但今制签名 `「平方和」乃化「整数」而化「整数」而「整数」也` 中，“乃”后接一串“化……而……”，判断句的谓语失了名词性，读来失衡；甲案改用《说文》式 `「平方和」，化二数为数也`，“即”改作相等判断（`若「余」即零`） |
| `寻观……之书` 雅 | 部分证实 | 以读书喻导入雅，有据：“余读孔氏书”（《史记·孔子世家》），“之书”先秦 49 见。但“寻观”二字连用在语料中零见；甲案简作 `观……之书` |
| `鉴` 雅 | 证实 | “我心匪鉴，不可以茹”（《诗·邶风·柏舟》）；先秦 68 见 |
| `或有` 雅 | 证实 | 先秦 22 见、两汉 29 见，义为“或许有”。用作可选类型时，甲乙两案改为定语 `或有之数`（“或许存在的数”），比今制 `「或可有」于「整数」` 更合文法 |
| `阳`、`阴`、`爻`、`元` 意象好 | 证实 | “一阴一阳之谓道”“爻者，言乎变者也”（《周易·系辞上》）；“元者，善之长也”（《乾·文言》）。两案保留 |
| `罄`、`缀` 意象好 | 证实 | “瓶之罄矣，维罍之耻”（《诗·小雅·蓼莪》）；“缀”训连缀（《说文》）。两案保留，“缀”改为中缀 `「首」缀「余」` |
| `可有`、`可无` 合成“可有可无” | 证实其意，出处晚 | “可有”先秦仅 6 见、“可无”37 见；四字连用最早见唐末杜希遁文（义为忽有忽无），作“无关紧要”义始见北宋孔武仲《代上执政书》（引七四）。意趣好，两案保留 |

### 2. 豫言的短处

| 观察 | 结论 | 证据 |
| --- | --- | --- |
| 虚词多作分隔符而不按文言本义 | 证实 | 今制十五篇共 42 读，逐读判定，36 读不成文言（违例率 86%），其中绝大多数因“于……于……”“会……而”“化……而”。详见第六节 |
| `于……于……` 复沓 | 证实 | 今制 B13 一句之中“于”五见。wenyan 也有同病：`施「截取」於零於三於「文」` |
| 行末悬“而” | 证实 | 今制 B2、B3、B5、B7 的定义行均以“而”收尾 |
| `化 甲 而 乙` 缺“为” | 证实 | 古人说“化而为鸟”（《庄子·逍遥游》）、“化为神奇”（《庄子·知北游》）；“化而为”先秦两汉 11 见，“化为”100 见，“化……而……”作“由甲变乙”解者未见 |
| `类型 也 值` 判断次序颠倒 | 证实 | “X，Y也”中 Y 为谓语。今制 `「小数」也「零点二五」` 把谓语放在前面 |
| `授以` 施受倒置 | 证实 | “授以”本身是古语（先秦 6 见，如“授之以政”），施予者在前、受者在后；今制 `「罄」授以「整数」` 让受者居前 |
| `中零` 不辞 | 证实 | 语料中零见；古人取项说“其一”“之二” |
| 没有句读与节奏 | 证实 | 今制平均读长 17.9 字，超过九字的长读占 76%，三至七字读仅占 12%（wenyan 分别为 4.5 字、1%、78%） |
| 符号多 | 证实 | 今制除句读外每百字 72.8 个符号，wenyan 32.5 |
| 今语混入 | 证实 | 今制关键词与常用核心名中有今语 12 个：递归、打印行、发生事故、尝试运行、整数、小数、字符串、元类型、整数表示、取余、除以、等于 |
| 没有统一的文体与口吻 | 证实 | 今制关键词出处分属史（鉴）、易（阴阳爻元）、读书笔记（寻观之书）、判断句（者也）与今语，无主文体（第六节） |
| 少情味 | 证实 | 出错写“发生事故”，捕获写“尝试运行” |
| 数字逐位 | 证实 | `「一二三」`、`「三点一四一五九」` |
| 结构关键词几乎都是仄声，读来短促 | 按词表证实，按用量推翻；短促另有原因 | 按词表（每词计一次），今制结构关键词 34 个中仄声 23 个（68%）。但按基准程序中的实际出现次数计，今制关键字的平声比为 43%，反而高于 wenyan（36%）与甲乙两案（33%、36%），因为最常用的“而”“于”都是平声。今制“声律偏促”的主要原因是没有句读：整篇只有 42 读，读末多是“也”，平收率仅 7%（wenyan 19%，甲案 20%，乙案 41%） |

### 3. 文体线索

| 观察 | 结论 | 证据与处理 |
| --- | --- | --- |
| “豫”是《易》第十六卦之名 | 证实，宜用于名物，不宜作文体 | 《豫·象》：“雷出地奋，豫。先王以作乐崇德。”《易》的卦爻辞是占辞，体例为“初九：潜龙勿用”，不合定义与算法的叙述。两案都只取《易》的名物：阴、阳、爻、元、类 |
| “鉴”是史书之名 | 证实，宜用于匹配 | 甲案以“鉴”起匹配；史书的叙事体不合定义体，未作主文体 |
| 《豫言赋》已用赋体 | 证实，宜用于文档 | 赋以“铺采摛文”为本（《文心雕龙·诠赋》），要靠“兮”与铺陈之辞成韵，用于源码则多可删之字。赋体留给《豫言赋》一类文档 |
| （新线索）经学训诂 | 采为甲案主文体 | 豫言是声明式语言，程序就是一条条“名”与“实”的对应；字书与传注的“X，Y也”“X犹Y也”“V谓之X”正是为名下定义的文体。豫言赋已有“正名”一篇 |

## 三、逐意研究

每个意思先列古人的现成说法，再列三至五个候选写法，按第七节的九个维度各打一至五分，并算加权分（满分一百）。表头缩写：法＝文法（权二十）、体＝文体与口吻（十五）、声＝声律（十五）、拍＝节奏（十五）、字＝用字（十）、情＝情味（十）、对＝对仗与呼应（五）、简＝简繁（五）、视＝视觉（五）。加权分＝4×法＋3×（体＋声＋拍）＋2×（字＋情）＋对＋简＋视。

出处一栏的“引某”指第八节《引文表》的编号，表中录有核定的原文与篇名。平仄只标关键字（名字以“名”代之）。打分针对“写法本身”：文体一栏按它所属文体是否典型、是否与所在方案的主文体相合来评。wenyan 无此功能者注“缺”，不参与取舍。

## 四、甲案「正名」：简劲之体

### 1. 风格总纲

- **主文体：经学训诂。** 以字书、传注、名辩的定义体为骨：“X，Y也”（《说文》释字）、“X者，Y也”（判断句正体）、“X犹Y也”（传注训释）、“V，谓之X”（《周易·系辞》）、“所谓X者，……也”（《大学》）、“凡……”（《说文》凡例）。辅以《易》（阴、阳、爻、元、类）、《九章算术》（“实如法而一”）、《孙子》（“十则围之”式的则字排比）。豫言的“正名”一篇、《荀子·正名》“制名以指实”都是这条线索。
- **口吻：无人称。** 像字书释字、经说释名，通篇是下定义的口吻。
- **一句一事。** 导入、签名、定义、别名、类型各为一句，签名与定义以“也”收束，合判断句之体。
- **虚词守本义。** 之（领属）、者（提顿）、也（判断）、而（连接两个谓词）、以（凭借）、为（作为、成为）、曰（称谓）、即（就是）、犹（同于）、若（假设）、则（后果）、谓之（叫作）。
- **句读规则。** 被定义之名后加逗号；“受”的参数后加逗号；“谓之”前加逗号，绑定之后用分号；“若……则……”短者连写，长者于“则”前断；“不然则”连写；“鉴”后用冒号，各支以分号相隔。每读以三至七字为宜。读号除结束列表之外只关节奏（见第 4 小节）。
- **声律。** 成对的关键词取平仄相反者：化●／为○、加○／减●、先○／后●、可有●●／可无●○、受●／而○。签名“化二数为数也”的步末字为 二●、为○、也●，二四分明。

### 4. 文法大要与读法唯一

**令牌。** 名字在「」中，字符串在『』中，二者以外的汉字裸写。裸写的汉字分为数字与关键词两类：数字是古法数字字（零至九、十、百、千、万、亿、又、分、厘、毫、丝、忽、负）的最长连串；其余汉字按固定词表取最长匹配，每个汉字必须属于某个关键词。关键词内部不含数字字，“而一”“之二”“一曰”“二数”“其体二”都是关键词与数字两个令牌相接。

**句读。** 句号结束一句。顿号只分列举项。逗号、分号、冒号结束尚未闭合的列表（“受”的参数表、“以”的实参表、“列”的项表、“化”的参数表），其余位置可加可不加，不改变结构。所以作者可以依节奏加读号，而不会改变读法。

**没有并置。** 两个名字相邻不构成表达式，只在“受”的参数表里出现。一个表达式遇到不能接续它的令牌就结束，下一支、下一子句由此开始。

**“受”的两种体。** `受「甲」而 式`：“而”连接两个谓词，体只是一个式（式中的若、鉴等结构可以跨读号，如 `受「数列」而鉴之：罄则零；……`）。`受「甲」「乙」，体`：参数表以读号结束，体由若干 `值，谓之「名」；` 子句加一个式组成，延伸到所在结构之末。所以 `受「数列」，受「数」而「数」乘二，谓之「倍」；乃……也` 只有一种读法：内层以“而”起，体止于“「数」乘二”，“谓之「倍」”绑定的是这个匿名函数，属外层之体。

**起首关键词与优先级。** 每个结构都有专属的起首词：观、藏、习（导入）；受、凡（函数）；若（条件）；鉴（匹配）；姑试（捕获）；先（先后）；书、呜呼（打印、抛出）；列、可有、可无（构造）；化（函数类型）；所谓（局部递归）。中缀与后缀的结合由下表决定，自上而下由紧到松：

**句类由名后标记区分。** `「X」，……也` 为签名；`「X」者，……也` 为定义；`「X」犹……也` 为别名；`「X」，类也` 为类型。

**“之”只有一种读法。** “甲之乙”在语法上一律是领属（乙属甲）。它表示调用（「余」之「求和」）、限定名（「小数操作」之「乘」）、取字段（「点」之「横」）、取第几项（「对」之二）还是类型应用（数之列），由两侧名字的类别决定：模块名由导入引入，类型名由类型声明或类型关键词引入，字段由类型定义引入。今制以同一个“于”兼表值的调用与类型的应用（`「求和」于「余」`、`「列」于「整数」`），也靠名字类别区分，二者同理。

**嵌套。** 内层“若”“鉴”位于外层非末支时，须加括号，与今制同。

## 五、乙案「算经」：铺陈之体

### 1. 风格总纲

- **主文体：算书。** 以《九章算术》《孙子算经》为本：函数之签名是一道题，“今有……，问……几何？”；函数之定义是一段术文，“某术曰：……”；步骤用算书的动词：置、自乘、以甲乘乙、以甲减乙、以甲除乙、并、名曰、以某术入之、即得所求。评注用刘徽注、李淳风注的“按”。豫言之名本于《易》，阴、阳、爻、元、类诸名沿用。
- **口吻：设问作答的算家。** 无人称；题设“今有”，问以“几何”“何言”，答以术文，术终于“即得所求”，前后呼应。
- **步步相承。** 术文由一步一步组成，步间以逗号、分号相次。算书有“当前之数”：`置` 某数于算筹，其后的 `自乘`、`以二乘之`、`并某`、`若大于零` 都施于当前之数，`名曰` 给当前之数命名，`即得所求` 交出当前之数。嵌套的式子化为先后之步，层层“名曰”，读来如解题。
- **题术呼应。** 题以“问”起、术以“所求”终；局部之术以“立……之术”起、以“是为……之术”终（首尾呼应，协议维度五）。
- **句读规则。** 每步一读；题的“今有……”与“问……”各为一读，四六相间（“今有二数，问「平方和」几何”即四、六）；判断与分支用分号。
- **声律。** 常用收束取平声：几何（●○）、何言（○○）、何为（○○）、即得所求（●●●○，《九章》《数书九章》有“即得所求”）、视之（●○）、得零（●○）。

### 4. 文法大要与读法唯一

**令牌与数字。** 同甲案。

**步与读号。** 题、术、值句各以句号结束。术内的步以逗号、分号相隔，读号在乙案中是步的界线（算书一步一读）。每步以专属的动词起首：命、置、并、以、取、名曰、得、即得所求、若、视、试、先立、是为、书、呜呼；或以式起首而以“自乘”等后缀收束。以“以”起首的步，看第一个式之后的词定其类：乘、减、除为算步，为为标签（`以零为「起」`）或类型实参（`以数、数为类`），术入为调用。

**当前之数。** `置`、算步、调用步、`取` 都产生一个值，成为当前之数；`名曰` 为它命名；`即得所求` 交出它。省去主语的比较（`若大于零`）与 `以二乘之`、`以「函」术入之` 都取当前之数。这条规则是“前一步之值”的简写：每步之值都可以写成以前一步为参数的式子，仍是函数式语言的写法。

**块的边界。** `若` 块由 `若……则……；若……则……；不然，……` 组成；`视` 块由若干 `其……者，……` 组成；`试` 块到 `其不尽者` 为止；局部之术由 `先立「名」之术` 起、`是为「名」之术` 止。一个块在遇到不属于它的起首词时结束。内层的 `视`、`若` 位于外层非末支时须加括号，或改为局部之术。作实参的“一术”只能是最后一步的最后一个实参，其体延伸到句末；别处要用的匿名函数先以“先立……之术”立名。

**题与值句。** 二者都以 `今有` 起首：其后若是类型、继以 `问`，是题；若是类型、继以值与 `名曰`，是值句；若直接是值（如 `今有负一与阳与元`），继以 `名曰`，亦是值句。

**“之”的读法。** 同甲案。

### 5. 示例

基准程序 B5（求和）：

```
今有数之列，问「求和」几何？
「求和」术曰：命之曰「数列」，视之：其罄者，得零；其「首」缀「余」者，以「求和」术入「余」，并「首」，即得所求。
```

```
今有｜数之列‖问「求和」｜几何‖「求和」｜术曰‖命之｜曰「数列」‖视之‖其罄者‖得零‖其「首」｜缀「余」者‖以「求和」｜术入「余」‖并「首」‖即得｜所求‖
○●｜●○●‖●○○｜●○‖○○｜●●‖●○｜●●●‖●○‖○●●‖●○‖○●｜●○●‖●○○｜●●○‖○●‖●●｜●○‖
```

句式：题为“今有……，问……几何？”；术文为“术曰：命之……，视之：其……者，……”，终于“即得所求”，与题之“问”相应。

## 七、自审

### 1. 甲案的弱点

- **签名与定义只差一个“者”。** `「平方和」，化二数为数也` 与 `「平方和」者，……也` 同属判断句，只靠“者”分开。这合《说文》与传注之体，但初读者可能把签名误读为定义。
- **“之”一字多职。** 调用（「余」之「求和」）、限定名（「小数操作」之「乘」）、取项（「对」之二）、取字段、类型应用（数之列）都写“之”。语法上只有领属一种读法，具体含义要看两侧名字的类别。
- **长读。** 实参表中不能加逗号（逗号会结束实参表），长路径、长式子也无处可断：B7、B10、B12、B13 的调用，B8 的“「左」之「叶数」加「右」之「叶数」”，B12 的导入路径，B13 的签名，共九读超过九字（长读 7%）。
- **平收率低。** 判断句以“也”收，平收率只有 20%；关键字平声比 33%，四套中最低。
- **情味淡。** 训诂体本是冷静的定义口吻，只在抛出、捕获处有“呜呼”“不虞”。
- **符号密。** 字省而名字多，除句读外每百字 53.9 个符号。
- **嵌套。** 内层“鉴”“若”位于外层非末支时仍须加括号，与今制相同。

### 2. 乙案的弱点

- **篇幅。** 735 字，与今制相当；每个函数都要一题一术，局部递归要“先立……之术……是为……之术”。
- **当前之数。** “置”“以二乘之”“以某术入之”“若大于零”都作用于上一步之值，读者要随步追踪；多参的嵌套式子须层层“名曰”。
- **题的“何 T”遇复杂类型生硬。** “问「交换」何言与数？”“问「倍之」何数之列？”不如“几何”自然。
- **交替率低。** 46%，在两案中较低；“即得所求”的“即得所”三仄连用，使违律数从 70 增至 80（这一取舍是为了用有出处的说法，见第五节）。
- **标签实参须先行。** `以零为「起」，以三为「止」，以「截取」术入「文」` 合算书“以……为实，以……为法”之体，但标签的先后必须与签名一致。
- **“今有”兼作题与值句。** 要看其后是“问”还是“名曰”才能分辨。

### 3. 两案共同未解决之处

- **名字的平仄不可控。** 名字约占总字数的四成，声律、交替、违律等度量受名字影响很大；关键字只能在名字之间做有限的调和。
- **古法计数冗长。** 圆周率要写十二字（三又一分四厘一毫五丝九忽）。
- **类型实参不够自然。** 甲案 `数、数之「态射」`、乙案 `以数、数为类` 都能读通，但不如其他部分顺口。
- **度量的操作化是本研究自定的。** 定步法、读号的放法、评分门槛换一种定法，分数会有出入。附录给出全部记谱，便于复核与改用其他标准。

### 4. 仍有争议的选择

| 选择 | 两案的做法 | 争议 |
| --- | --- | --- |
| 核心名改为裸写关键词 | 书、呜呼、罄、缀、可有、可无、加减乘除、大于小于，以及类型名数、量、言、爻、类，都不再写在「」中 | 名字自由不受影响（名字仍在「」中），但这些名字成了保留字，不能再作函数值传递，须另设同义的名字（如「加」） |
| 类型名 | 整数→数，小数→量，字符串→言，元类型→类 | “量”作小数（取“度量”之义，读去声）最费解；也可取“分”“率” |
| 字符串相接 | 附 | “属”（属辞）更雅、加权分更高，但今人易读作“属于” |
| 取项从一数起 | 「对」之一、之二 | 豫言内部仍从零计；写法与内部序号差一 |
| 相等判断 | 甲“即”，乙“为” | 甲案“为”已用于“化……为……”与标签，故取训“就是”的“即” |
| 条件收束 | 不然 | “否则”同样有据（《左传》），“不然”取其平收 |
| 甲案签名 | “X，T也” | 也可回到今制的“乃”，以与定义拉开距离 |

### 5. 需要用户定夺的问题

1. **方向：** 采甲案（简劲、与今制的判断句一脉相承）、乙案（铺陈、题术相配、读如算经），还是两案并存为两种写法？
2. **“之”的统一：** 是否接受一个“之”兼表调用、限定、取项、取字段与类型应用？
3. **核心名裸写：** 是否把打印、抛出、空列、接头、可选值、算术、比较与常用类型名改为关键词？
4. **数字：** 是否改用古法计数，数字不再写在「」中？
5. **类型名：** “数、量、言、类”是否可用，“量”是否另择？
6. **串接：** “附”还是“属”？
7. **乙案的当前之数：** 是否接受“置……以二乘之……即得所求”式的隐含前值？
8. **显示：** 是否另评繁体与竖排（协议第四节第四条允许）。乙案用繁体竖排时，最接近算经的版面。

几条需要说明的核对结果：

- 引七：常用本《史记》缺陈涉世家正文，取殆知阁的三家注本。
- 引四三：测圆海镜、数书九章正文中“设”无假设义（数书九章只有清人补题），改取九章刘徽注“设有四分之二者”；宋人例见《梦溪笔谈·艺文一》。
- 引四七：“否则”更早见《尚书·益稷》“格则承之庸之，否则威之”。
- 引五三：“或若”作“或者如果”义最早见陈徐陵《谏仁山深法师罢道书》（《广弘明集》卷二十四）；东汉《论衡》的“或若”是“或者像”义。
- 引五五：《新唐书·魏徵传》作“以铜为鉴，可正衣冠”，《旧唐书·魏徵传》作“以铜为镜，可以正衣冠”。
- 引七四：“可有可无”语料最早见唐末杜希遁文（义为忽有忽无），“无关紧要”义始见北宋孔武仲《代上执政书》。
- 引八三：“嗟夫”在先秦两汉常用典籍中未见，取《文心雕龙·诸子》。
- 引九〇（修正）：拟引“事之不济，命也”不见于左传、国语，只见于明清之际的书；“事之不济”最早见《管子·大匡》。
