# 提案

此为豫言演进之提案目录：语言、编译器、工具链与平台之要改，先书为提案，议定而后施行。

与[汉语稿](说明.汉语.md)相应。

## 文件

- 每提案一对文件：`<号>-<题>.汉语.md` 与 `<号>-<题>.文言.md`，二者同改。
- 号五位，自 `00001` 依次而增；号既授之，不改，亦不再用。
- 题用中文，简言其事，如 `00001-统一二进制表示`。

## 状

| 状 | 义 |
| --- | --- |
| 草案 | 方书之，其文随时可改 |
| 讨论中 | 书毕，待议 |
| 已接受 | 定行之，可以动手 |
| 已实现 | 已入主线，文中注其提交 |
| 已否决 | 定不为，文中注其由 |
| 已取代 | 为后之提案所代，文中注代者之号 |

状书于每篇首之表；改状则二份同改，并同改下之目。

## 书法

首一表：号、状、提出之日、所及。正文依次书：所议之事（议一、议二……）、所以然、所求与所及、设计、兼容与迁、他途、未决、施行之序。数必注于何处、何时所测。
