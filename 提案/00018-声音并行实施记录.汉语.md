# 声音并行实施记录

本轮十名子代理在独立工作树上实施声音功能，由声音统筹合入用户指定的 `codex/fast-merge` 汇集流程。

| 子代理 | 模块 | 功能 |
| --- | --- | --- |
| audio_research | 逐响 | 逐帧函数生成、逐样本变换 |
| reverb | 回声 | 延迟反馈、乒乓回声、指定尾音 |
| audio_filter | 清浊 | 二阶低通、高通、带通、跨块状态 |
| audio_dynamics | 敛幅 | 动态压缩、起释状态、联动限幅 |
| audio_envelope | 起伏 | 通用包络、提前释音、原地施加 |
| audio_normalize | 齐幅 | 峰值、均方根、增益与归一 |
| audio_decode | 声轨 | 波形、音频交换、弗拉克、沃比斯、第三层素材解码 |
| audio_layout | 列位 | 自定扬声器布局、对象声音分配 |
| audio_binaural | 双耳 | 方位响应选择、左右耳卷积、尾音 |
| audio_synth | 和鸣 | 有序合成图、振荡、增益、加和、调频 |

统筹将「音符起伏」接入现有「混入乐谱」，修复音符在起音或衰减期间结束时的释音起始电平，双语包说明同步列出模块入口。现有音频处理库已核对，素材解码复用音频编解码库，数学与波形复用设计现有模块；新增模块均采用普通豫言类型和函数。

依用户要求，本轮无测试。本地并行负载较高，类型检查由根任务统一送远端处理。

后续事项：设计声明、树码序列化及场景物体名称绑定与本轮普通函数接口的接线；奥普斯文件封装；声音效果图的统一声明。当前离线接口可由豫言调用者直接串联。

2026-10-20：奥普斯编码侧开工并完成主体。新增七个模块：区间编码器（记符号、前演、后演、放值、排字节、素位）、脉冲向量索引与整化、能量编码（拉氏反解、三档与一位退路、精位与末级）、位拨镜像（档位二分、插值求权、跳带写零、摊余、精位与优先）、递归分带（角码选取、三角频数、单带脉冲）、整帧组装、奥格封装。区间编码器与包内既有解码器逐位对齐（一千三百二十项全过），脉冲、能量、位拨、分带各有往返测试，奥格封装经 `读奥格包` 往返核对包内容。整帧编码产出可解码的单声道 CELT 包，两次编码逐字节相同。

预加重与解码器去加重的互逆关系经最小对照定死：编码侧须以**前一原样本**作状态（`x[n] = s[n] - 0.85 s[n-1]`），修正后端到端信噪比（信号平方和与误差平方和之比）自零点零七升至零点五。端到端正弦信噪比门限、码率三档、双声道、静音标志与编码速度记录列为后续事项，详见包内《奥普斯编码实施记录》。
