## 内容安全策略的违规事件与上报（2026-10-23，钩深内容安全）

- 网页安全新增「违规报告」：违规记录（违反指令、生效指令、被阻地址、原始策略、处置、源文件、行列、样本、状态码、文档地址、来源页）、违规桥（宿主装派事与上报）、违规境（只报不拦的策略、文档地址、来源页）、同一违规只报一次、按违约的那一份策略取 `report-uri` 并按文档地址补成绝对地址、`csp-report` 结绳报文体。`report-to` 的 Reporting API 投递留待后续版本。
- 抓取主算法在内容策略拦下时记一条处置 enforce 的违规；许可后再核只报不拦的策略记一条处置 report 的违规；目的为 `report` 的报告请求不受策略约束，免得报告自身再触发报告。
- 网页榫卯新增「内容安全事」：`SecurityPolicyViolationEvent` 构造器（缺文字字段给空串、缺数值字段给零、缺处置给 `enforce`、没有事件类型抛类型错误）与冒泡派发的 `securitypolicyviolation` 事件，十二个字段经「篇系」的事件包装交给脚本；页面接口装配时装上构造器。
- `fetch` 读初值的模式、凭据、缓存与转向，并把页面内容安全策略交给抓取主算法；`XMLHttpRequest` 改走主算法（来源取页面地址、凭据随 `withCredentials`），跨源预检与响应许可随之生效。
- WebSocket 在构造前按 `connect-src` 拦下时先记违规、派事并按 `report-uri` 上报，再抛安全错误。
- 浏览器资源读取按导航响应记只报不拦的策略、文档地址与来源页；违规桥在文档上派事件并按 `report-uri` 投报告，报告请求走抓取主算法、目的记 `report`；入口换页时清已报违规并重设违规境。
- 测试：网页安全「违规报告」、抓取「内容策略违规」、网页榫卯「内容安全事」三篇新测通过；页面接口、网页笔谈与浏览器综合冒烟不退回。

## 边框图像的宽度、外扩与切片取值分类（2026-10-24，钩深图像）

- 起因：`border-image-width` 的八项、`outset` 两项、`slice`/`fill` 五项长期不过；查下发现原解析只认“数字”与“百分比”，`50px 10px` 这类长度与 `auto` 都被当成缺省，边框图像区因此画小，露出背景红。
- 改法：组件收集器「边图数件」改收（值、类）两列，类分数字、百分比、长度（长度取文字里的数值前缀）；新增「四文展」把一至四个类展成四个。宽度按「边图宽一」逐边算：数字乘对应边框宽、百分比按区宽高折、长度直取、缺类（auto）取边框宽；外扩按「边图扩一」：数字乘边框宽、长度直取、其余作零；切片按类逐边折：百分比按图宽高、数字与长度按像素。`四文展` 的空列给「空」类，免得 auto 被当成零号数字。
- 「边图边片」：目标宽或高不大于零的边段不画（四角照画），修回 007 与 width-008；片内仍交「边图铺项」铺排，未改「边图铺项」「边图铺走」。
- 数字（新底 d0fc05c4e，pit-pc 林纳，`--并发 1 --内存 2048`、内存上限 8G、构建前置 `env 豫言将作托出=关`）：基线 950 通过 → 改后 956 通过；进步 6（`border-image-006`、`007`、`slice-006`、`width-008`、`css3-border-image-source`、`image-rendering-border-image`），退步 0，其他变化 0。
- 改了 `设色/边框图。豫`（取值分类与三处算法）与 `设色/映列。豫`（切片调用补环境参数、新增「边图边片」）。

## 图像重采样按方向取法（2026-10-24，钩深图像）

- 由来：object-fit 的 svg 系列成组不过（contain/cover/fill/scale-down 各 24 项）。取 contain 的 001e 图与参照逐像素比，差异集中在斜边（最大差 142），是缩小后边缘发糊、参照是浏览器按目标尺寸直出的清晰边缘。
