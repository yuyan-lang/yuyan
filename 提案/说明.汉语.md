# 提案

这是豫言演进的提案目录：语言、编译器、工具链与平台的重要改动，先写成提案，讨论定下后再实施。

旧的[文言稿](说明.文言.md)保留，以本文为准。

## 文件

- 每篇提案一个文件 `<编号>-<标题>.汉语.md`，只写现代汉语（AGENTS.md，用户 2026-10-06 定）。00001 至 00003 已有的文言稿 `<编号>-<标题>.文言.md` 保留，以汉语稿为准，不再同步。
- 编号五位，从 `00001` 起依次递增；编号一经分配，不再改动，也不再重用。
- 标题用中文，简短说明提案的内容，如 `00001-统一二进制表示`。

## 状态

| 状态 | 含义 |
| --- | --- |
| 草案 | 正在写，内容随时会改 |
| 讨论中 | 已写完，等待评议 |
| 已接受 | 决定实施，可以动手 |
| 暂缓实施 | 内容保留，决定暂不实施，文中注明原因与恢复条件 |
| 已实现 | 已合进主线，文中注明对应的提交 |
| 已否决 | 决定不做，文中注明理由 |
| 已取代 | 由后来的提案取代，文中注明取代它的编号 |

状态写在每篇开头的表格里；改状态时同步下面的目录。

## 写法

开头一张表：编号、状态、提出日期、范围。正文依次写：拟定事项（议一、议二……）、动机、目标与范围、设计、兼容与迁移、备选方案、未决问题、实施步骤。数据要注明在哪里、什么时候测得。
