## 摘要

1. **交付了什么。** 协议第九节五项交付物都在本文：研究报告（第三、四、六章）、两套完整方案（第四章）、B1–B15 全部改写与记谱（第五章）、今制与 wenyan-lang 与两套方案的度量与评分对比（第六章）、自审与待定（第七、八章）。
2. **结论。** 甲「易简体」（守今制骨架、正文法、补句读）得 **70.0**；乙「算经体」（改为算书叙事体）得 **85.0**；今制 **38.0**；wenyan-lang 在它能表达的七篇上得 **90.0**，但按协议第四节第一条「意思齐全」，它写不出意二（类型签名）、意四（自定义类型与构造器）、意五（函数类型）、意十一（模式匹配），故在整门语言上不适用。**建议走乙**，见 8.1。
3. **六处必改。** ① 调用的「于」（`「加」于「甲」于「乙」`）改为受事式 `f 受 a`（甲）或 `施 f 於 a`（乙）；② 函数类型的「化 A 而 B」改为 `化 A 成 B`（《礼记·学记》「化民成俗」），补回丢掉的「为／成」；③ 类型标注 `T 也 V` 次序倒装，改为 `V 属 T`（甲，《左传》「忠之属也」）或 `V，T 也`（乙）；④ 局部名的「虑」改为 `令「甲」为 a，而 b`（甲）或后置的 `a，名之曰「甲」，乃 b`（乙，《孟子·离娄上》「名之曰幽、厉」）；⑤ 局部递归的「递归虑」改为 `复令`（甲，取《汉书·礼乐志》「周而复始」）或 `周行`（乙，取《老子》「周行而不殆」）；⑥ 核心名的今语（打印行、发生事故、尝试运行、整数表示、除以、取余）改为 `书之`、`呜呼`／`嗟夫`、`试之`／`姑试`、`文之`／`属文`、`除`、`余`。
4. **今制的佳处经检验全部成立，两套方案都原样保留**：`「名」者……也`、`乃`、`即`、`寻观……之书`、`鉴`、`阳`／`阴`／`爻`／`元`、`罄`／`缀`、`可有`／`可无`／`或可有`、`与`／`合`、`且`／`或`、`附`、`「模块」之「名」`。
5. **量化结果。** 同一批十五篇基准程序：今制的读七成六超过九字、平收率只有 7.1%；甲的长读降到 17.8%、平收升到 20.3%，但违律反而升高（每百字 29.3）；乙长读 16.8%、平收 22.4%、违律 19.0%、交替率 47.6%，四项都优于今制与甲。**「守骨架」修不了声律**（骨架里的受、者、也、即、立全是仄声），而「铺陈」并不更冗长（乙 750 字对今制 771 字）。
6. **三处反直觉的发现。** ① 平声比高不等于声律好（甲、乙都低于今制，读来反而不更促）；② 「符号满页」的病根是每个名字都要「」，不是括号与方括号（今制的括号引号密度 66.3／百字，与甲 62.5、乙 60.2 相差很小）；③ 评分表缺一条「数字用古法还是逐位」，而它正是甲乙最大的体例分歧（B12 一处差五字）。
7. **须用户定夺者七条**（第八章），最重的三条是：方向（甲还是乙）、「名」与「签」是否合为一物（B13）、「字符串」是否改「文」（须动《翻译列表》）。

## 一、方法与口径

### 1.1 语料

度量与评比都在同一份语料上做，不用抽取的片段：

- **基准程序 B1–B15**：协议第八节全文。这是唯一的程序语料，共十五篇。
- **关键词表**：协议的今制表、wenyan-lang 的 `src/keywords.ts`、以及本报告的两套新方案。用字、文体、对仗、简繁四个维度在这里评。
- **核心名表**：今制的常用核心名、wenyan-lang 的術名（書之、乃得、噫等）、以及新方案。

程序语料里，字符串『』内容不计拍，按协议记作一个停顿；「」中的名字照字计拍与声调。

### 1.2 读的界定与记谱

协议规定「一字一拍」「音步界｜」「句读界‖」。为了让四套写法可比较，本报告把「读」定成**停顿单位**，并只用一条规则划读：

> 一句读完处（句号）、句读处（逗号、冒号）、以及承接词之前，都是读界 ‖。其余相邻二字成一步，步界 ｜。

由此：

- 今制源码几乎只有句号，一篇定义就是**一读到底**；括号与嵌套不产生停顿。这正是提案 00025 第四节所说「没有句读与节奏」的可计算形式。
- 新方案把停顿写进源码（逗号、以及居读首的承接词），于是读长可控、可复算。
- wenyan-lang 以句号「。」密集断句，读短而多。

这条规则对四套写法同样施加，不偏袒任何一套；但它在**设计之内**给新方案留了余地（新方案可以自行规定何处放句读），这不是作弊：协议第二节把「有没有句读」列为要评的东西，句读的有无本身就是被评对象。

声调记号照协议：`○` 平声，`●` 仄声，`◐` 两读（附录甲注明依据）。中古四声为准：平为平，上、去、入为仄；入声一律归仄，不依现代普通话。

### 1.3 声调依据

每个用字的声调与平水韵韵部列在附录甲，取自《广韵》与平水韵。多音字按所取之义定调并在附录里分列，例如：

- 「为」：作「作为、成为」是平声支韵，作「因为、为了」是去声寘韵。本报告的方案一律取平声义（系词），只有极少数处取去声。
- 「与」：作连词「和」是上声语韵，作动词「给予」是上声语韵（同），作语气词同「欤」是平声鱼韵。「甲 与 乙」取上声。
- 「数」：作名词「数目」是去声遇韵，作动词「计算」是上声麌韵。类型名「数」取去声（名词）。
- 「中」：作方位「之中」是平声东韵，作动词「射中」是去声送韵。取项与「其中」取平声。
- 「长」：作「长短」是平声阳韵，作「长幼」是上声养韵。

附录甲里标「待核」的，是本报告不敢断定的少数读音与出处；它们不承担论证，只影响个位数字的度量。

### 1.4 度量算法

协议第五节的九组度量，本报告按下列口径计算，全部可从本报告给出的记谱串复算：

| 维度 | 度量 | 口径 |
| --- | --- | --- |
| 声 | 交替率 | 相邻音步末字平仄不同的步对数 ÷ 步对总数 |
| 声 | 平收率 | 以平声字收束的读 ÷ 读总数 |
| 声 | 平声比 | 平声字 ÷ 全字数 |
| 声 | 违律数 | 同读内连续三字同声（三平、三仄）的次数 |
| 拍 | 读长分布 | 每读字数；三至七字读所占比例；四、六字读所占比例 |
| 拍 | 音步完整率 | 能切成二字步（允许一个三字超音步）的读 ÷ 读总数 |
| 拍 | 单字读比例 | 一字读 ÷ 读总数（有意的顿笔如「噫」另计） |
| 拍 | 长读比例 | 超过九字的读 ÷ 读总数 |
| 文 | 违例数 | 逐读判定是否通顺文言；不通顺即违例（人工判定，见 3.0 节判例） |
| 用 | 有出处比例 | 关键词中有可靠出处者 ÷ 关键词总数 |
| 用 | 今语数 | 关键词与核心名中的近现代术语个数 |
| 对 | 对仗分 | 成对关键词按词性、平仄、意义各记一分 |
| 体 | 主文体比 | 归入主文体的关键词 ÷ 关键词总数 |
| 情 | 情味处数 | 带叹词、问句、语气处数（定性） |
| 视 | 符号密度 | 非汉字符号 ÷ 全文字数 × 100 |
| 简 | 每意思字数 | 关键词表与 B1–B15 里，表达每个意思所用的汉字数 |

计数由一段临时脚本从记谱串机械统计（记谱串本身写在第五章），不靠目测。

### 1.5 文献核验

出处分三级：**成立**（查到原文，注篇名）、**待核**（只有二手转述或记忆，不能引原文）、**无**（本报告自铸，不假托古人）。自铸不扣分，伪托才扣分（协议第十节）。核验结果见附录乙。

### 1.6 本报告的边界

1. 只设计普通源码的写法。底层模式、着色语言、宏（`「头」【…】`）、`循` 兼容形式不评。
2. 只按月日可查的文献与韵书判平仄；不确定处标「待核」。
3. 文言有歧义处，宁可承认两读，不强行判一。
4. 评分表用协议第七节的权重为**主分**；另给一组「重简」权重作敏感性检验（6.3 节），因为协议允许改权重但须说明理由。

## 二、今制与 wenyan-lang 的定性评估

定量结果见第六章；本章先记两份定性判断，作为第三章取舍的背景。

### 2.1 今制：骨架好，虚词坏

今制最经得起文学眼光的是**判断句骨架**：`「名」者……也` 是《史记》列传的正体，「乃」「即」都是古人的系词，`「模块」之「名」` 是领属的正体。骨架之外的虚词几乎都不按本义：

1. `于` 作唯一的分隔符。文言里 `于` 是介词（在、向、对、比、被），不能把一个动词的两个宾语都挂在它后面；`「加」于「甲」于「乙」` 逐字读不成话。算书说「并甲乙」「以乙加甲」，wenyan 说「加「甲」以「乙」」。
2. 行末悬 `而`。文言的 `而` 居两谓词之间；`会「甲」而` ＋换行，读来气不收。这是**书写规则**的问题，不是 `而` 字的问题：让 `而` 居下一读之首即可救活。
3. `化「甲」而「乙」` 丢掉了成语的「为」字。文言有「化干戈为玉帛」「化民成俗」，没有「化甲而乙」。
4. `「整数」也「一」` 把判断句的次序倒装了。古人说「一，整数也」。
5. `「罄」授以「整数」` 施受倒置。古人说「以「整数」授「罄」」。
6. `「对」中「零」` 不成话。古人说「其一」「之首」。
7. `虑「甲」者 值 而 体` 用「虑」（思虑）当 let，不成判断；`递归虑` 又夹一个今语「递归」。
8. `若……则……否则` 的 `否则` 近世；`否则若` 三字叠，声促。
9. 数字逐位，如电报码；`，`、`；`、`【】`、`（）` 遍纸。
10. 结构关键词几乎尽仄（若、则、鉴、有、或、乃、者、也、即、立、会、化、虑、与、合、附、受、遇），句尾多收在仄上。

### 2.2 今制：确实好、应当保留的

逐字品评（提案 00025 第五节）里的赞赏，经协议九维度检验**全部成立**，本报告两套方案都原样保留：

| 写法 | 用得其所的根据 |
| --- | --- |
| `「名」者……也` | 判断句正体；《史记·陈涉世家》「陈胜者，阳城人也」 |
| `「名」乃……」也`、`即` | 系词；《孟子·梁惠王上》「是乃仁术也」；《史记》「即」多作「就是」 |
| `「模块」之「名」` | 领属正体 |
| `寻观……之书` | 以读书喻导入；「寻」《桃花源记》「寻向所志」，「观」《论语·为政》「观其所由」 |
| `鉴` | 《诗经·大雅·荡》「殷鉴不远」，《资治通鉴》书名 |
| `阳`、`阴`、`爻`、`元` | 出于《易》 |
| `罄` | 《诗经·小雅·蓼莪》「瓶之罄矣」 |
| `缀` | 连缀；《礼记·大传》「缀之以食而弗殊」 |
| `可有`、`可无`、`或可有` | 合成语「可有可无」，全表最妙者 |
| `甲 且 乙`、`甲 或 乙` | 《易·系辞上》第八章「或出或处，或默或语」 |
| `甲 与 乙`、`甲 合 乙` | 与、合皆本义 |
| `甲 附 乙` | 附为附着，意象合 |

### 2.3 wenyan-lang：一体一声，但语域窄

wenyan 的文采来自三件事：一体的算书文体（作者自谓「偶追《十书》之笔意」）、一律的第一人称口吻（吾、余）、以及**虚词各守本义**。它的代价有三条，本报告如实记下：

1. 冗长。一个 `var a = 3` 要十个汉字。
2. 语域窄。它只像一篇算书，写不出史笔的沉着，也没有《易》的庄重。
3. **表达力不及格**。协议第三节的意四（自定义类型与构造器）、意五（函数类型）、意十一（模式匹配）wenyan 都没有对应写法，只能用「物」与分支去模拟；意二（类型签名）根本没有。若把「意思齐全」当硬约束（协议第四节第一条），wenyan 在**最低约束**上就出局，它的高分只在能表达的那几篇里成立。本报告在第六章给它两栏分数：「能表达篇上的分」与「全语料的分」。

## 三、逐意思候选与取舍

约定：`○` 平、`●` 仄、`◐` 两读；平仄串只记**关键词本身**，名字按实际字数另计。出处有把握的直书，把握不足的加「待核」，本报告自铸的写「自铸」。每意思末行列两套方案的取法（甲＝易简体，乙＝算经体，见第四章）。

### 意一 导入模块

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| `寻 P 之书`／`观 P 之书`／`寻观 P 之书` | 寻《桃花源记》「寻向所志」；观《论语·为政》「视其所以，观其所由」；书《史记·太史公自序》「紬史记石室金匮之书」 | 寻○○；观○；寻观○○；之书○○ | 领属 | 今制最佳处；读音全平，收束舒展 |
| `取 P 之书`／`启 P 之名` | 取《孟子》「取之」；启《尚书·金縢》「以启金縢之书」 | 取●○；启●○；之名○○ | 述宾 | 「启其名」把「打开其中的名字」说实了，比「观」更准 |
| `读 P 之书` | 《五柳先生传》「好读书，不求甚解」 | 读●●○ | 述宾 | 读为入声，短促；且书是拿来读的，导入是「取用」，隔一层 |
| `受 P 之书` | 《孟子》「受」 | 受● | 述宾 | 「受书」可通，但「受」已让给函数应用，宜避 |

**取**：甲＝`寻／观／寻观 P 之书`（保留今制，全平收束）；乙＝`取 P 之书`（名字空间）、`启 P 之名`（打开其中名字）、`取 P 之书，启其名`（兼取）。

### 意二 类型签名

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| `「名」乃 T 也` | 《孟子·梁惠王上》「是乃仁术也」 | 乃● 也● | 判断 | 系词得体，今制即此，无懈可击 |
| `「名」，T 也` | 判断句不用系词的常式（《史记》「陈胜者，阳城人也」之省） | 也● | 判断 | 少一字，读来更简；与「者……也」以「者」的有无相别 |
| `「名」为 T 也` | 《尔雅·释天》「春为青阳，夏为朱明」 | 为○ | 判断 | 更雅，但「为」已让给构造器，且与「化 A 成 B」相混 |
| `「名」者，T 也` | 同判断句正体 | 者● 也● | 判断 | 与意三定义撞形，读法唯一要打折扣，弃 |
| `「名」属 T 也` | 《左传·庄公十年》「忠之属也」 | 属● | 判断 | 「属」宜作类型标注（意十七），此处不用 |

**取**：甲＝`「名」乃 T 也`；乙＝`「名」，T 也`（函数另有「术」式，见意五）。

### 意三 定义与类型别名

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| `「名」者 V 也`／`「名」即 T 也` | 判断正体；即《史记》多作「就是」 | 者●也●；即● | 判断 | 定义与别名用两个系词分得很干净，全表最好的一对 |
| `「名」为 V 也` | 《尔雅》「春为青阳」 | 为○ | 判断 | 与构造器争「为」 |
| `「名」者，V 之谓也` | 《孟子·离娄上》「此之谓也」 | 之谓○○ | 定义 | 「……之谓也」是定义句式（《孟子》「……之谓也」），但每处多三字，且尾巴收在仄 |
| `「名」曰 V 也` | 《尚书》「曰若稽古」 | 曰● | 命名 | 「曰」宜作引述与命名，不宜作定义 |

**取**：甲、乙同取 `「名」者 V 也` 与 `「名」即 T 也`。「即」为入声，短促，但作系词恰是「就是」的语气，不必改。

### 意四 自定义类型与构造器

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| 类型 `「树」乃「元类型」也`；构造器 `「枝」立化…而…也` | 今制 | 立● | 判断／述宾 | 「叶立树也」主宾不顺：「立」的主语应是造物者，不是叶 |
| 类型 `「树」，太极也`；构造器 `「叶」为「树」也` | 《易·系辞上》「易有太极，是生两仪」；《尔雅》「春为青阳」 | 太极●●；为○ | 判断／判断 | 类型是「太极」（众类之始），构造器是「为」（叶为树），两句都读得通 |
| 类型 `「树」乃「元类型」也`；构造器 `「叶」属「树」也` | 属《左传》「忠之属也」 | 属● | 判断 | 「属」作构造器比作标注更合（叶属于树），但「属」宜留作标注 |
| 类型 `「树」乃「元」也`；构造器 `「叶」生「树」也` | 生《易·系辞上》「易有太极，是生两仪」（原文如此，后世节缩作「太极生两仪」） | 生○ | 判断／述宾 | 「元」与单位值「元」撞名；「叶生树」方向恰好对（构造器生出类型的值），可作备选 |

**取**：甲＝类型 `「树」乃「太极」也`，构造器 `「叶」为「树」也`／`「枝」为化「树」成化「树」成「树」也`；乙同，唯类型写作 `「树」，太极也`（乙的签名本无系词）。**「太极」是要用户定夺的一处**（见 8.3）：它雅、有出处、与「元」「爻」「阳」「阴」同出一经，但离「类型」的语义最远。

### 意五 函数类型

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| `化 A 而 B` | 今制 | 化● 而○ | 自铸 | 缺「为」，读不成话 |
| `化 A 成 B` | 《礼记·学记》「化民成俗」；《庄子》「化而为鸟」 | 化● 成○ | 述补 | 「化甲成乙」合成语法；收平声，一层套一层仍读得通 |
| `化 A 为 B` | 《淮南子·原道训》「执玉帛者万国」（「化干戈为玉帛」是后世据此定型的六字语，篇内无此连文） | 为○ | 述补 | 最熟，但「为」要与构造器共用，且与构造器连写时三个「为」叠字 |
| `受 A 者 B` | 《孟子》「受……者」 | 受● 者● | 判断 | 「受甲者乙」= 受甲者是乙，雅；但「受」已让给函数应用 |
| `自 A 至 B` | 《左传》「自……至……」 | 至● | 介宾 | 像范围不像函数 |
| `具名参数`：`化 A 者「x」成 B` | 《孟子》「……者，……也」之提顿 | 者● | 提顿 | 「者」把参数名带出，与今制同形，改「而」为「成」即通 |
| `隐式类型参数`：`承「甲」成 B` | 《易》「承天而时行」 | 承○ | 述宾 | 「承」为平声，起读舒展；保留今制 |
| `标签`：`化「签」为 A 成 B` | 《战国策·魏策四》「以君为长者」 | 为○ | 「以……为……」之省 | 「化（签为 A）成 B」可读为「把签当作 A」，是标签的准确意思 |
| `名签合一`：`化 A 者「名」成 B` | 《论语·学而》「其为人也孝弟」之提顿 | 者● | 提顿 | 今制的依值参数名与标签本是同一种东西（这个参数叫什么）；合为一式之后，「名」出现在 B 里就是依值参数，不出现就是标签，省去一式 |
| `可省`：`可化 A 者「名」成 B` | 可，《论语》「可也」 | 可● | 助动 | 与今制同 |

**取**：甲、乙同取 `化 A 成 B`；具名／标签 `化 A 者「名」成 B`；隐式类型 `承「甲」成 B`；隐式值 `承 A 者「名」成 B`；可省 `可化 A 者「名」成 B`。**「成」取代「而」是本报告改动最大、收益也最大的一处**；**「名签合一」是第二处**：它把今制的两式并成一式，空出「以……为……」给调用一侧。协议第三节只要求「参数可带名、可带标签」两种写法齐全，合一之后依然齐全（合一式在 B 提及该名时即依值参数）。

### 意七 调用

| 候选 | 出处 | 平仄 | 句式 | 评 |
| --- | --- | --- | --- | --- |
| `f 于 a 于 b` | 今制 | 于○ | 介词 | 介词不按本义，复沓，读来口吃 |
| `f 受 a 受 b` | 受《孟子》；今制已用「受」作隐式参数 | 受● | 述宾 | 「加受甲受乙」= 加接受甲、接受乙；头在前，顺序同今制；「受」为上声，多字连用略促 |
| `f 取 a 取 b` | 取《孟子》「取之」 | 取● | 述宾 | 同上，但「取」已让给元组取项 |
| `施 f 於 a 於 b` | 施《论语》「己所不欲，勿施于人」；於同于 | 施● 於○ | 述宾＋介宾 | 「施「加」於「甲」於「乙」」= 施（用）加于甲、于乙；这是最深得文言之体的一式，但每调用加一字，且「於」仍复沓 |

| `f 授以 T`（类型实参） | 今制 | 授● 以● | 双宾 | 「授以」可读作「以 T 授之」，施受尚可自圆 |

**理由**：甲要最小改动，「受」只换一字而读法全变（`「加」受「甲」受「乙」` 逐字可读）；乙要叙事，「施……於……」是文言调用式的正体。甲的类型实参保留 `授以` 是本报告对今制唯一的让步，自审（7.1）已记。

## 四、两套完整方案

两套方案对应协议第一节所说的「两种方向」：甲守今制的骨架（短、简、判断句），乙改用算书的叙事体（长、铺陈、术曰）。二者共用一套**类型表达式**（化……成……、合、之列、承），因为这几处文言里本有最佳式，没有第二种更好的写法；差别在**声明体、控制流、命名与调用**上，也就是文气所在处。

两套方案都做了一件今制没做的事：**把「名」与「签」合为一物**。今制里 `化 A 者「x」而 B`（依值参数名）与 `化「签」为 A 而 B`（标签）是两种写法，其实都是「这个参数叫什么」；合成 `化 A 者「名」成 B` 之后，名字出现在类型里就是依值参数，没出现就是标签。这是协议允许的（第三节只要求「参数可带名、可带标签」，不要求二者分行），且让「以……为……」这一式空出来给调用一侧使用。

| `元类型` | `太极` | 《易·系辞上》 |

**读法唯一的论证（甲）**

1. **三类记号不相犯**：名字必在「」，字符串必在『』，数字裸写且首字为「零一二三四五六七八九」或「负」。关键词是固定的汉字词。故 `「打印」` 是名字，`打印`（若有人写）不是关键词，`一二三` 是数字，`「一二三」` 是名字。
2. **声明与表达式之分**：声明以名字开头，其后必是 `乃`／`者`／`即`／`为` 之一；表达式的开头可以是名字、数字、『』、`凡`、`承`、`若`、`鉴`、`取`、`令`、`复令`、`（`。两者不重叠。
3. **中缀都有定解**：`化 A 成 B` 右结合（照今制「而」的展平规则）；`f 受 a` 左结合；`与`、`合` 右侧字面元组展平；`且`、`或` 只与彼此有关系，混写须加括号（全照今制）。`之列` 是后缀，只出现在表达式末尾；`之` 作领属，`取……之……` 是一式；`属` 只作中缀。
4. **「，」是句读**，可出现在任意两词之间，不改变读法；它只在列字面 `A、B、C 之列` 与声明头之间有分组意味。
5. **「为」的四种位置各有定读**：声明头 `「名」为 T 也`（构造器）、`令「名」为 a`（局部名）、`f 受 a 为「名」`（具名实参）、`化 A 者「名」成 B` 里的 `者`（参数名）。四处的前后词类不同，位置定读法。

**读法唯一的论证（乙）**

与甲同，另有四处要说明：

1. **`「名」，T 也`（签名）与 `「名」者，V 也`（定义）之别在「者」**：有「者」是定义，无「者」是签名。表达式位置不出现「者＋也」的判断句，故不与声明相混。
2. **`a，名之曰「名」，乃 b`（后置命名）**：`名之曰` 之后必跟一个名字与一个句读；再遇 `乃` 即进入体。读法与「先写值、后命名」一一对应。
3. **`施 f 於 a 於 b`（调用）与 `取 x 於 y`（取项）同用「於」，但头的词性不同**：`施`、`取` 是固定的关键词，其后第一式必是函数或序数；两者的位置与后续式（`於 a` 连绵对 `於「对」` 单出）足以分辨。若嫌险，可把取项写成 `取「对」之「零」`（同甲）。
4. **古法数字**：`一百二十三` 是数词连写，`负` 只作数字前缀，`又` 只作整数与小数之界；三者都不与关键词同形，也不与「」中的名字相犯。`一百三` 写作 `一百三十`，`一百零三` 写作 `一百零三`，不省略「零」。

### 5.16 wenyan-lang 的改写

wenyan-lang 没有类型、没有自定义类型与模式匹配，协议第三节的意二、意四、意五、意九（局部递归可勉强用循环模拟）、意十一它都没有对应写法。可对照者只有七篇，本报告依其关键词表与官方示例（协议第二节）拼出，作为度量的样本：

「总字」是记谱的字数（不含『』内容）；「汉字总数」含『』内容，二者之差即字符串。音步完整率与单字读率互补（本口径下任何二字以上的读都能切成二字步），故只列单字读率。第五章每份记谱的每一行都注了该读的字数，故逐篇、逐读的度量都可据此直接复算；下表只是按方案汇总。

**这些数字说明了什么。**

1. **今制的两处品评被数据坐实。** 长读七成六（一读三十余字）、平收七点一个百分点。前者是「没有句读」，后者是「收束多促」。
2. **甲把节奏修好了，没把声律修好。** 长读从 76.2% 降到 17.8%，三至七字读从 11.9% 升到 55.9%；可是违律从每百字 26.2 升到 29.3，平声比从 32.7% 降到 27.6%，交替率也从 43.7% 降到 40.4%。原因是句读把长读切成短读，而短读常常整读皆仄（「「大者」者」●●●、「受「乙」」●）。**守今制的骨架救不了声律**，因为骨架里的「受」「者」「也」「即」「立」与基准程序里的「甲」「乙」「整数」都是仄声。
3. **乙在声律上胜甲。** 违律 19.0（比今制低四分之一）、交替率 47.6%（全场最高）、平收 22.4%。一半靠「施」是平声（今制的「于」是平声，甲的「受」是仄声），一半靠读长与四六相间。这是「铺陈」胜「简劲」的量化证据。
4. **「符号满页」的病根是引号，不是括号。** 今制的括号引号每百字 66.3，甲 62.5，乙 60.2（去掉了【】），wenyan 只有 17.6。三套豫言写法的引号密度是 wenyan 的三倍半，因为每个名字都要「」；括号的增减只是小头。要真减符号，只能减少名字的引号（本报告不敢动，见 7.3）。句读方面，甲、乙的句读密度（16.9、17.3）是今制（6.1）的近三倍，正是「四六相间」的来源。
5. **字数的账。** 同一批程序，今制 771 字，甲 728 字（少 5.6%），乙 750 字（少 2.7%）。乙的古法数字与「施……於……」多花了字，靠「「名」，T 也」省下的「乃」与几处合并抵了回来。**「铺陈」并不等于冗长**——真正的冗长是 wenyan 那种（一个赋值十个字）。

| 文体与口吻 | 15 | 2 | 4 | 5 | 5 |

**给分依据。** 今制的文法只能给二分：`「加」于「甲」于「乙」`、`「罄」授以「整数」`、`「对」中「零」`、`「整数」也「一」` 逐读不成话，且 `虑「甲」者……而` 行末悬「而」；节奏一分，长读七成六、三至七字读只有一成二；情味一分，抛出异常写「发生事故」。用字二分起于五个今语（递归、打印行、发生事故、尝试运行、整数表示）。对仗能得四分，因为「寻／观」「可有／可无」「罄／缀」「者／也」「乃／即」这些成对的好词是今制挣来的。

甲、乙的分差主要在声律（2 对 3）、节奏（4 对 5）、情味（3 对 4）、文体（4 对 5）、对仗（4 对 5）五项，共差 15 分；甲在简繁上多一分，抵回 1 分。甲的自铸多（「之列」「素」「令……为」的用法）、来源杂（寻观之书是读书笔记体，小数操作是今语库名），故文体与用字各扣一分。

wenyan 的 90 分只算它能表达的七篇。按协议第四节第一条「意思齐全」这把硬尺，它在**全语料**上不适用（意二、意四、意五、意十一无法写出），因此不能作为整门语言的方案。它的分数说明另一件事：**文学性的上限由小语言换来**；wenyan 之所以读来最像文章，一部分原因是它不做类型、不做模式匹配、不做模块。

### 6.3 权重敏感性

协议允许改权重但须说明理由。做两组替换，检验名次是否稳：

| 权重方案 | 今制 | 甲 | 乙 | 名次 |
| --- | --- | --- | --- | --- |
| 协议原表 | 38.0 | 70.0 | 85.0 | 乙＞甲＞今制 |
| 重简：简繁 10、情味 5 | 38.0 | 71.0 | 84.0 | 不变 |
| 重声：声律 25、文体 10 | 38.0 | 70.0 | 86.0 | 不变 |

名次对权重不敏感，因为三项的分差同向。**本报告主张给评分表补一条**：协议没有为「数字用古法还是逐位」设维度，而它正是两套方案最大的体例分歧之一（B12 一处就差五个字），且与情味、文体直接相关。补法有两条，任取其一：

- 在「用字」维度下加一问：「数字与量词是否用本语言的古法」；
- 在「简繁」维度下注明：「数字拉长的字数照样计入」。

### 6.4 评分表之外的三条观察

1. **「意思齐全」是硬门槛，评分只对过门槛者有效。** 协议第四节四条最低约束中，「读法唯一」与「名字自由」两套方案都过，见第四章各自的论证；「意思齐全」wenyan 不过。
2. **声律不必求「平声多」。** 甲、乙的平声比（27.6%、33.2%）都低于或近于今制（32.7%），但读来并不更促：促不促取决于**收束与交替**，不取决于平声总量。协议把「平声比」列为度量是对的（它是描述），评分时却不宜把「平声比高」当成好。
3. **同一批名字让四套写法可比。** 基准程序里的「甲」「乙」「整数」「入口」「平方和」都以仄声居多，四套写法背同样的包袱，故差值来自关键词，不来自名字。

## 七、自审

### 7.1 方案甲的弱点

1. **声律没修好。** 违律每百字 29.3，比今制还高。根子在「受」（仄）替下了「于」（平），以及短读常整读皆仄。若把「受」换成平声的「施」或另找一个平声的应用词，这一项能立刻好转——那就等于采用乙的调用式了。
2. **「授以」没改。** 类型实参仍写 `「态射」授以「整数」`，施受倒置的批评对甲仍成立。保留它只是因为「已用过、改不动」。
3. **两种类型应用并存。** `「整数」之列` 与 `「或可有」于「整数」` 同表两式，甲没有给出统一规则，只靠「之列是类于『之书』的结合式」打圆场。
4. **「者」两用。** 甲的「化 A 者「名」成 B」把参数名挂在「者」上，而「者……也」又是定义句；虽说位置能分，读法唯一的论证从此多一层。
5. **数字去「」改了词法。** 名字在「」、数字裸写，界线从标点移到字表；`「一二三」`（名字）与 `一二三`（数）并存，须在词法里写死，且「负」「点」「又」这些数字用字不能再作裸名字。
6. **「素」作默认值。** 「素」有「平素」「预先」义，但「素 值」作「预设值」是自铸，读来仍隔一层；「豫」更贴（《礼记·中庸》「凡事豫则立」），但与本语言同名。

### 7.2 方案乙的弱点

1. **长。** 「施……於……」每次调用多一字，古法数字更长；B12 一行就多五个字。简繁只给三分。
2. **三处「也」结尾的官样尾音。** 「「名」，T 也」「「名」者……是为所求也」「……乃……也」连读，容易像公牍。
3. **「得」两用。** 「得 A 者「x」，乃」是绑定，「得」同时又是算书的「结果」（「得三」），同一字在同一篇里两义，靠位置分。
4. **「名之曰」的后置作用域。** 先写值再起名，作用域向后延伸；这与今制「虑 x 者 值 而 体」的次序相反，人与编译器都要重新学。
5. **「取「零」於「对」」与「施 f 於 a」同用「於」。** 两式的头词不同（取／施），能分，但不如甲清楚。
6. **出处已二次核验，乙的那几条都立住了。** 「属文」「微数」「一百二十三」「多几何」四条原标「待核」，第三批核验已全部取得原文（见附录乙）；仍未立的只有「少几何」（乙的「少」作「小于」是常语，非算书成句）与「分厘毫丝忽作小数位名」（乙的数字写法据此为自铸）。

### 7.3 两套方案的共同未决

1. **「太极」的风险。** 它最雅、有出处，但离「类型」的语义最远；读代码的人第一眼不会想到类型。备选是保留「元类型」。
2. **「整数」「小数」留作今语。** 二者是常用类型名，出现频率极高，却正是今语术词中最伤文气者。改用「数」「微数」会与常用变量名「数」相撞（基准程序 B4 就有一个变量叫「数」）。
3. **「文」与《翻译列表》冲突。** 列表里 String 译作「字符串」；改成「文」须在列表里另立条目并说明「豫言类型名取意象名」。同理「太极」「之列」也要进列表或规范。
4. **「之列」的结合式到汉代才有确证。** 《汉书·司马迁传》「仆亦尝厕下大夫之列」为其据；更早的先秦用例仍未得，故它比「化」「成」「名之曰」这一类要薄。
5. **句读自由会不会冲淡「读法唯一」。** 「，」可插在任意两词之间，它在列字面里又是分项符。本报告的论证是「，只表示停顿，不参与语法」，但这条得在规范里写死。
6. **「名签合一」改变了语义。** 今制的标签与依值参数是两种东西（一个擦除、一个参与类型）；合一之后，一个参数是否依值要看类型里有没有提到它。这在文学上省了一式，在语义上是一次合并，须用户定夺。

## 附录丙 记谱与度量的复算

1. **切读**：遇「。」「：」「；」即断；遇「，」也断，但在「【】」之内不断（今制列表里的逗号是分项符，不是句读）；「、」不断。「『』」及其内容整体略去，不计字（故记谱行里字符串位置是空的）。
2. **计字**：跳过「」『』（）【】、，。：；与空白，其余每字一拍。名字照字计拍与声调，字符串记作停顿。
3. **交替率**：把每读的二、四、六……字作为音步末（读长为奇数时末字也算一个单字步的末字），相邻音步末平仄不同者计一次「异」，除以总对数。
4. **违律**：读内连续三字同声即计一次。
5. **平收**：读末字为平声即计一次。
6. 全部计数由一段一次性脚本从第五章的记谱串机械统计（脚本在仓外临时目录，不入库）。复算按上四条即可；第五章每份记谱都写全了读与平仄串。
