本文只写现代汉语（AGENTS.md）。

用户 2026-10-21 问：“我们豫言距离实现工程制图软件还差哪些功能（施工图纸，要求精确尺寸的那种），比如 AutoCAD 的那种。”2026-10-22 定：工程图样用设计语言写，沿用 `。设计。豫`；通用的制图能力开源，放在本仓；行业专用的构件、数据与模板由各行业库在各自的仓库里提供。

## 一、拟定事项

- **议一：图样是设计作品。** 能力格（00018 第四节）加一条轴“实尺”和一个常用点「图样」。源码仍是 `名。设计。豫`，二进制仍是 `名。设计`；编译、渲染帧、导出刻本、播放器、还原与壳命令照用。
- **议二：两套尺寸。** 几何按模型毫米画，放进带比例的视图；线宽、字高、箭头、剖面线间距、表格按图纸毫米定，与视图比例无关。
- **议三：新库「勾股」。** 二维计算几何：图元、量算、求交、偏移、修剪、面域布尔、边界识别、空间索引、稳健判定，另含回转体与圆柱的解析投影。名取《九章算术》第九章“句股”（今作勾股），专讲直角三角形与测望，是中国古代几何之学。
- **议四：新库「规矩」。** 工程制图的国标画法：图纸幅面与格式、比例、字体、图线、视图、剖视与断面、尺寸注法、剖面符号、序号、标题栏与明细栏、焊缝符号、技术要求。名取《孟子·离娄上》“不以规矩，不能成方员”：规是圆规，矩是曲尺，正是制图的两件工具；规矩又是法度，制图处处照标准。行业构件与表格模板由行业库在「规矩」之上定义。
- **议五：输出与交换。** 刻本（PDF）按实际纸张尺寸输出，线条、剖面线与文字都是矢量，文字可检索。新库「抄书」读写 DXF。DXF 译作“抄本”，DWG 译作“底本”，与刻本（PDF）同用书本之喻：底本是原图，抄本是逐行明文的传抄本，刻本是版式固定的印本（补进《翻译列表》）。库名「抄书」与「刻书」（刻本的写出库）成对。现成的图框模板与图档多是底本：「抄书」先做读，第一期就能读入抄本当图框模板（底本在过渡期经外部工具转成抄本）；交付常要底本源文件，底本读写列为第六期。
- **议六：查询命令。** 加「图样信息」「量距」等只读命令，编辑仍是写源码（00018 第十五节）。交互绘图列为后续版本事项；程序出的图要细化时，过渡期交给现有制图软件改。
- **议七：形字体。** 制图软件的图框与图样多用形字体（SHX，主字体配大字体，如 gbenor.shx 配 gbcbig.shx）。「字模」加读形字体，把字形画成笔画路径；字体文件由使用方提供，不随仓分发。SHX 译作“形字体”，沿用通行译名（补进《翻译列表》）。

## 二、动机

1. 设计语言已有工程图样要的大半：
   - 坐标与设计树码一律双精度（《设计树码格式》：小数按八字节 IEEE 754 双精度写出，坐标是两个小数，仿射是六个小数）。
   - 路径有直线、二次与三次曲线、圆弧，可填充、描边、画虚线。
   - 文档组件有精排、表格、分页、编号与交叉引用。
   - 刻本输出纯色几何与字形轮廓都是矢量。
   - 能力格、还原、壳命令、渲染帧供 AI 看图核对。
2. 缺的是制图本身：
   - 画幅以抽象的“设计单位”计，没有毫米、比例、图纸与模型之分。
   - 绘事（二维绘图库）能画虚线，国标线型的规则还没有。
   - 视图、剖视、局部放大、尺寸标注、剖面线、标题栏、明细栏都还没有。
   - 求交、偏移、修剪、面域布尔还没有，剖面线边界与相贯线都靠它们。
   - 刻本输出把渐变与图案采样成裁剪位图，文字转成轮廓、检索不到（`库/匠心/篇出。豫` 篇首注释的待办）。
   - 与别的制图软件交换文件的格式还没有。
3. 精度由双精度、容差与稳健判定保证。双精度约有十六位有效数字：十万毫米（百米）处相邻可表示数之差约 1.5×10⁻¹¹ 毫米，大地坐标 3.5×10⁹ 毫米处约 0.5 纳米，远小于施工与加工的公差。十进制只用在两头：输入时读成双精度，标注时把量出的值按标注精度舍入成文字。单精度只用于图形处理器显示，显示前先减去视口原点。
4. 豫言的一切动作都有壳命令（AGENTS.md「图形程序」），这与 AutoCAD 的命令行同理：作图、出图、查询都能由命令与脚本完成，AI 写源码就能作图。
5. 实际图档的情形（2026-10-22 看过一份通用图框模板与三套设备图）：
   - 图框模板与样图都是 2018 版底本；模板里约有四千七百个单行文字、七百个多行文字、六百个尺寸、三百个图块参照，原样读入当模板、程序往格子里填值最省事。
   - 文字多用形字体，另有 Arial、宋体等 TrueType 字体；字高按模板定（3、3.5、4、5 毫米），不全在国标字高系列里。
   - 表格栏目中英双语。
   - 签署栏有两至四级。
   - 机加工面要注表面粗糙度与几何公差。
   - 交付常要刻本加底本源文件，抄本用得少。
   - 程序出的图常要在现有制图软件里再细化。

## 三、目标与范围

本提案做：

1. 能力格的“实尺”轴、「图样」点、推断与检查，降格映射“去实尺”。
2. 「勾股」库。
3. 「规矩」库，覆盖第五节所列的国标画法。
4. 刻本输出的实尺、矢量剖面线与可检索文字。
5. 「抄书」库与导出、导入命令；读入抄本当图框模板。
6. 图样的查询命令与 AI 写图样的检查命令。
7. 「字模」读形字体。
8. 底本读写（过渡期经外部转换）。

后续版本事项：

- 交互绘图：对象捕捉、正交与极轴追踪、夹点编辑、动态输入。
- 参数化约束求解（几何约束与尺寸约束）。
- 精确实体（边界表示）三维建模，以及由实体生成二维视图。
- 打印机与绘图仪输出。
- 螺纹与齿轮的画法。
- 第六节的「图样信息」「量距」「导出抄本」三个壳命令：先要在设计树码里留住规矩一级的信息（图纸、视图与比例、图层、尺寸与序号），再做查询与导出；本批只做了实尺页与实尺刻本。

## 四、设计：实尺与图样

### 能力格

| 轴 | 链（由低到高） | 说明 |
| --- | --- | --- |
| 实尺 | 无 < 实尺 | 实尺：长度有物理单位（毫米），视图带比例，输出按实际纸张尺寸 |

常用点「图样」：时间无、空间二维、声音无、文字轨无、输入无、计算为有界纯表达式（由参数生成几何的图样升到有界程序）、素材为内嵌素材（字体）、分页为分页、精排为基础、文档结构为有（图号、序号与明细栏互相引用）、实尺为实尺。

降格映射“去实尺”：按指定的显示比例把毫米换成设计单位，实尺降为无，供图样嵌进文档、幻灯或界面。

### 单位

- 长度一律毫米，双精度；角度在源码里写度。
- 模型：构件几何按实际毫米。
- 图纸：幅面按 GB/T 14689（A0 841×1189 至 A4 210×297，另有加长幅面），图框分留装订边与不留装订边两种，带对中符号与方向符号。
- 视图：图纸上的一块区域，带比例、在模型中的原点、可选的裁剪框与断开段。比例照 GB/T 14690 优先系列：1:1，缩小 1:2、1:5、1:10 及其 10ⁿ 倍，放大 2:1、5:1 及其 10ⁿ 倍；允许系列（1:1.5、1:2.5、1:3、1:4、1:6 等）也可用。
- 注释（尺寸、文字、符号、剖面线间距、线宽）一律按图纸毫米：写进视图时，位置随视图比例换算，大小保持图纸毫米。

### 数值与容差

- 默认长度容差 10⁻⁶ 毫米、角度容差 10⁻⁹ 弧度，图样里可改。点重合、线相交、轮廓闭合都按容差判断。
- 方向判定（点在线的哪一侧）与线段相交判定用自适应精度算法，退化时改用「大衍」（任意精度整数库）的有理数精确算。
- 正交角度（0°、90°、180°、270°）的正弦、余弦直接取精确值；捕捉到的点直接引用原图元的坐标。
- 标注值由几何算出，按标注精度（默认整毫米，可设小数位）就近舍入，用「记数」（数值格式库）排成文字。

## 五、设计：库

### 「勾股」（二维计算几何）

放在 `库/群书/算学部/勾股`，与「方程」「大衍」同部。

| 类 | 内容 |
| --- | --- |
| 图元 | 点、线段、射线、直线、圆、圆弧、椭、椭弧、多段线（段可带凸度成弧）、三次贝塞尔曲线、样条 |
| 量算 | 长度、距离、最近点、垂足、切点、面积、形心、包围盒 |
| 求交 | 任两图元求交：直线与圆锥曲线用解析解，样条用细分加牛顿迭代 |
| 变换 | 平移、旋转、镜像、缩放、仿射 |
| 偏移 | 等距线：圆弧偏移仍是圆弧，多段线逐段偏移后补连接 |
| 编辑 | 修剪、延伸、打断、圆角、倒角 |
| 面域 | 由闭合轮廓建面域（外环与孤岛），并、交、差，点在面域内的判定 |
| 边界识别 | 从一组图元里找出包住给定点的最小闭合轮廓，间隙容差可设（剖面线用） |
| 空间索引 | 四叉树，供拾取、框选、视口裁剪与大量求交 |
| 解析投影 | 圆柱、圆锥、球、回转体、平面体沿主轴方向的投影轮廓与转向轮廓线，两圆柱、圆柱与圆锥、圆柱与回转面的相贯线；同一份参数生成三角网格，供匠心（设计引擎）的三维视口预览 |

### 「规矩」（工程制图）

放在 `库/规矩`，依赖匠心、勾股、字模（字体库）与记数。图样的元素都是设计语言的构造（00018 议十九），类型检查后降为场景节点。

| 类 | 依据 | 内容 |
| --- | --- | --- |
| 图纸 | GB/T 14689、GB/T 10609.1、GB/T 10609.2 | 幅面、图框、对中与方向符号；标题栏、明细栏（自标题栏向上排）、签署栏（两至四级可配）、修订栏；表格按图纸毫米定列宽与线宽，栏目可中英双语，排版复用匠心的表格；也可读入抄本当图框模板，程序往格子里填值 |
| 视图 | GB/T 14692、GB/T 4458.1、GB/T 4458.6、GB/T 16675.1 | 第一角画法的基本视图与向视图；全剖、半剖、局部剖、断面；局部放大（罗马数字编号与比例）；断开画法；对称与重复结构的简化表示；视图标注（“A—A”“A 向”“Ⅰ 5:1”） |
| 图线 | GB/T 17450、GB/T 4457.4 | 粗实线、细实线、波浪线、双折线、细虚线、粗虚线、细点画线、粗点画线、细双点画线；线宽组 d 取 0.25、0.35、0.5、0.7、1、1.4、2 毫米，细线为 d/2；点画线与双点画线两端是长画、相交处落在长画上，中心线超出轮廓线 2–5 毫米 |
| 字体 | GB/T 14691 | 汉字用长仿宋体或形字体；国标字高系列 1.8、2.5、3.5、5、7、10、14、20 毫米作缺省，实际字高以图框模板为准；汉字高不小于 3.5 毫米，字宽约为字高的 1/√2；数字与字母分 A 型、B 型，直体与 75° 斜体 |
| 尺寸注法 | GB/T 4458.4 | 线性、对齐、直径 φ、半径 R、球径 Sφ 与 SR、角度、弧长、厚度 t、45° 倒角 C、斜度与锥度；链式、基准式与坐标式；尺寸界线、尺寸线与终端（实心箭头或斜线）；数字的位置与方向；不按比例画的尺寸在数字下加粗实线；尺寸值由几何算出，也可由参数给出并与几何核对 |

行业库在「规矩」之上定义自己的构件构造（由参数生成视图里的几何、标注与明细栏行）、表格模板、图框与签署栏模板、技术要求模板。国家标准的原文留在仓外，库里只实现画法规则。

### 「抄书」（抄本读写）

放在 `库/群书/丹青部/抄书`，与「刻书」同部，只管格式：段、表、图块与图元的读写。

- **先读**（第一期）：段、表（图层、线型、文字样式、标注样式、图块记录）、常用图元（直线、圆、圆弧、多段线、单行与多行文字、尺寸、图块参照）。文字里的控制码照常换算，如 `%%c` 换成 φ、`%%d` 换成 °、`%%p` 换成 ±。「规矩」把读入的图元原样放进图纸当模板。
- **后写**（第五期）：2007 版以后的文本抄本（文字是 UTF-8，中文直接写），覆盖图层、线型、线宽、颜色、文字样式、标注样式、图块与常用图元。

「规矩」负责图样与抄本之间的换算：导出时一张图纸成一个布局，导入的抄本可作底图或模板，也可反编译成设计源码。

**底本。** 过渡期用外部工具转换：LibreDWG 的 `dwg2dxf` 已验证能把 2018 版底本转成抄本；程序出的抄本由现有制图软件另存为底本。第六期自写底本读写，依据开放设计联盟公开的底本格式规范。

## 六、设计：输出与命令

- **刻本。** 页面大小即幅面，毫米按 1 毫米 = 72/25.4 点换算；线宽与线型照图纸毫米；剖面线与图案在图样里一律输出矢量；文字嵌入字体子集，可检索（同时补上 `篇出。豫` 的待办）；多张图纸出成一份多页刻本，书签按图号。
- **渲染帧。** 照旧出位图，供 AI 看图核对。
- **壳命令**（名字暂定，照 AGENTS.md「图形程序」加在库「诏令」）：
  - 「图样信息」于「文件」曰…：列出图纸、视图与比例、图层、尺寸与序号的个数。
  - 「量距」于「文件」曰…于「起」曰…于「止」曰…：两点的模型距离，点可写坐标或“图元名.端点”一类的引用。
  - 「导出抄本」于「文件」曰…于「输出」曰…：把图样导出成抄本。
  - 导出刻本沿用 00018 的「导出便携文档」。
- **预览。** 设计播放器显示图纸，缩放、平移只改视图。

## 七、兼容与迁移

- 已有作品的实尺取“无”，行为不变。
- 设计树码加实尺、视图比例与新节点，格式版本加一；旧版本的文件照旧能读。
- 刻本输出的矢量剖面线与可检索文字对已有作品同样生效，画面不变。

## 八、备选方案

- **另起扩展名 `。图样。豫`。** 图样的编译规则与设计源相同，能力格已能区分图样与动画；另起后缀只多一套工具分支。取沿用 `。设计。豫`。
- **由三维模型投影出全部二维视图。** 要精确实体内核，工作量大；各行业图样又有大量约定画法（把不在投影面上的结构旋转到投影面上画、薄壁夸大画），本来就不是投影。取直接生成二维加常见形体的解析投影，精确实体列为后续版本事项。
- **十进制定点存坐标。** 圆弧、旋转、开方的结果多是无理数，十进制同样要舍入，又要软件模拟、慢几十倍。取双精度加容差。
- **整数纳米网格。** 适合以多边形为主的图（电路板、芯片版图）；圆弧与任意角度旋转会离开网格。取双精度。

## 九、未决问题

1. **字体。** 形字体文件随各家制图软件分发，库只读使用方提供的文件。随仓分发的仿宋字体要一款许可允许的（候选：开源的朱雀仿宋，许可待核），按字宽系数约 0.7 压成长仿宋。
2. **交互绘图。** 00018 定的是 AI 写源码；工程师在预览里至少要能量距、查坐标、圈注审图意见。程序出的图常要再细化，过渡期交给现有制图软件改；豫言里要不要做交互绘图、何时做，待用户定。
3. **库名。** 「勾股」「规矩」「抄书」与译名“抄本”“底本”待用户定。
4. **默认容差。** 长度 10⁻⁶ 毫米、角度 10⁻⁹ 弧度是否合适。
5. **原生小数运算速度。** 2026-10-12 本机实测：同一段代码栅格化十三个图标，诺驿二十毫秒、原生一点八秒。10-22 查明主因是林檎、林纳上没开硬件浮点开关（yuyan-lang/yuyan#271 已关）；余下 #272（宽浮点运算在整数与浮点寄存器间来回搬，林檎 ARM64 仍比诺驿慢一倍左右）。几何与出图全程用双精度，开工前先看 #272。
6. **抄本版本。** 先写 2007 版以后的文本格式是否够用；二进制抄本何时读。
7. **底本。** 第六期自写底本读写，还是长期靠外部转换。

## 十、实施步骤

每一步一棵工作树，可拆的分路并行。

1. **第一期「图纸与图线」：** 实尺轴与「图样」点；单位、视图与比例；幅面、图框、标题栏、明细栏与签署栏；图线与线宽组；字体；刻本实尺输出（矢量、可检索文字）；「图样信息」。另有两路可并行：「抄书」的读（读入抄本当图框模板）与「字模」读形字体。验收：一张 A3 样张，含两个比例不同的视图与填好的标题栏、明细栏；读回刻本里的路径坐标换算成毫米，与源码一致；读入一份抄本图框模板，画出的刻本与原图逐项对得上。
2. **第二期「勾股」：** 图元、量算、求交、偏移、修剪、圆角、面域布尔、边界识别、四叉树、稳健判定。验收：随机图元求交与「大衍」有理数精确解对拍；退化情形（相切、重合、共线）有专门测试。
3. **第三期「标注与剖面」：** 尺寸注法全套、剖面线、序号、焊缝符号、表面结构、几何公差、技术要求；剖视、断面、局部放大、断开画法、简化表示；「量距」。验收：照 GB/T 4458.4、GB/T 4457.5、GB/T 131、GB/T 1182 的示例图逐个复现。
4. **第四期「投影与预览」：** 常见形体的解析投影（含虚线）与相贯线；同一份参数生成三维网格预览。
5. **第五期「交换」：** 「抄书」的写与「导出抄本」。验收：导出的抄本在常见制图软件里打开，图层、线型、线宽、尺寸与中文都对；再读回比较图元。
6. **第六期「底本」：** 读写底本。在此之前，读靠外部工具转成抄本，写靠制图软件把抄本另存为底本。验收：2018 版底本读入后与转换出的抄本逐图元一致；写出的底本在常见制图软件里打开能改。
