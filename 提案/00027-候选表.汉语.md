# 提案 00027 候选表（第二版）

[提案 00027](00027-关键词换字.汉语.md) 的整句候选。第一版逐字换同义字，用户评“文学性不够”；本版每条都是一段完整的小程序，按读感挑选。★ 为第二版方案所取。未特别写出的部分照第二版方案。

每条后注“手段”：多写法（同一操作符另加写法）、换字、加符（新增中缀或前缀）、库改名；“注意”写可能的冲突。不合用户约束（倒序、跨句指代）的不列。

## 一、函数体与参数（B2 平方和）

### 1 ★ 得、又得、令、乃

```
「平方和」者，得「甲」，又得「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　乃「甲方」加「乙方」也。
```

读如：平方和者，得甲，又得乙，令甲方为甲乘甲，令乙方为乙乘乙，乃甲方加乙方也。
手段：多写法（得、又得；“，”“，乃”），算术中缀。

### 2 既得、又得、遂（史笔）

```
「平方和」者，既得「甲」，又得「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　遂「甲方」加「乙方」也。
```

读如：平方和者，既得甲，又得乙，……遂甲方加乙方也。
手段：多写法（既得、又得、“，遂”）。

### 3 一次得二参

```
「平方和」者，得「甲」「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　乃「甲方」加「乙方」也。
```

读如：平方和者，得甲乙，……
手段：加符（“得”后连列几个名字，展开成逐个匿名函数）。注意：两个名字相邻只在“得”后成立。

### 4 不避复，最整齐

```
「平方和」者，得「甲」，得「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　而「甲方」加「乙方」也。
```

读如：平方和者，得甲，得乙，……而甲方加乙方也。
手段：多写法（“，而”）。

### 5 设、则（算书与今数学口吻）

```
「平方和」者，设「甲」，设「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　则「甲方」加「乙方」也。
```

读如：平方和者，设甲，设乙，……则甲方加乙方也。
手段：换字、多写法。注意：末项的“则”与条件的“，则”同字，靠位置区分。

### 6 受、又受

```
「平方和」者，受「甲」，又受「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　乃「甲方」加「乙方」也。
```

读如：平方和者，受甲，又受乙，……
手段：换字。注意：隐式匿名函数的“受”须另换一字（见第九节）。

## 二、签名（函数类型）

### 1 ★ 化……为……，顿号列参

```
「平方和」乃化「数」、「数」为「数」也。
```

读如：平方和乃化数、数为数也。手段：换字、加符（顿号）。

### 2 以数计参

```
「平方和」乃化二「数」为「数」也。
```

读如：平方和乃化二数为数也。手段：加符（类型里的数词，同类多参）。

### 3 之为术

```
「平方和」之为术，化「数」、「数」为「数」也。
```

读如：平方和之为术，化数、数为数也（“道之为物”式）。手段：多写法（签名另写“之为术，”）。

### 4 逐参一化

```
「平方和」乃化「数」，化「数」，为「数」也。
```

读如：平方和乃化数，化数，为数也。手段：多写法（“，”断读）。

### 5 受……而成……

```
「平方和」乃受「数」、「数」而成「数」者也。
```

读如：平方和，乃受数、数而成数者也（GPT 式）。手段：换字。注意：“受”与隐式匿名函数同字。

### 6 自……至……

```
「平方和」乃自「数」、「数」至「数」也。
```

读如：平方和乃自数、数至数也。手段：换字。

## 三、条件（B4 符号）

### 1 ★ 若、则、否则

```
「符号」者，得「数」，
　若「数」大于「零」，则『正』，
　否则若「数」小于「零」，则『负』，
　否则『零』也。
```

手段：多写法（“，则”“，否则”）。

### 2 不然

```
「符号」者，得「数」，
　若「数」大于「零」，则『正』；
　不然，若「数」小于「零」，则『负』；
　不然，『零』也。
```

读如：……；不然，若数小于零，则负；不然，零也。手段：多写法（“；不然，”）。“不然”平声收。

### 3 或若、若非（wenyan）

```
「符号」者，得「数」，
　若「数」大于「零」，则『正』，
　或若「数」小于「零」，则『负』，
　若非，『零』也。
```

手段：加符（“或若”另立一符，同“或有”），多写法（“若非，”）。

### 4 苟

```
「符号」者，得「数」，
　苟「数」大于「零」，则『正』，
　否则苟「数」小于「零」，则『负』，
　否则『零』也。
```

手段：换字（苟＝假如）。

### 5 使

```
「符号」者，得「数」，
　使「数」大于「零」，则『正』，
　否则使「数」小于「零」，则『负』，
　否则『零』也。
```

手段：换字（使＝假使）。

## 四、模式匹配（B5 求和）

### 1 ★ 鉴、有、或有

```
「求和」者，得「数列」，鉴「数列」：
　有「罄」，则「零」；
　或有「首」缀「余」，则「首」加（「求和」于「余」）也。
```

读如：求和者，得数列，鉴数列：有罄，则零；或有首缀余，则首加求和于余也。
手段：多写法（“：”“，则”“；或有”），加符（中缀“缀”）。

### 2 其为（GPT）

```
「求和」者，得「数列」，鉴「数列」：
　其为「罄」，则「零」；
　其为「首」缀「余」，则「首」加（「求和」于「余」）也。
```

手段：换字（“其为”起支，诸支同形）。

### 3 遇

```
「求和」者，得「数列」，鉴「数列」：
　遇「罄」，则「零」；
　或遇「首」缀「余」，则「首」加（「求和」于「余」）也。
```

读如：遇罄，则零；或遇首缀余，则……。手段：换字。

### 4 诸支皆“或有”（提案 00024）

```
「求和」者，得「数列」，鉴「数列」：
　或有「罄」，则「零」；
　或有「首」缀「余」，则「首」加（「求和」于「余」）也。
```

手段：换字。

### 5 者代则

```
「求和」者，得「数列」，鉴「数列」：
　有「罄」者，「零」；
　或有「首」缀「余」者，「首」加（「求和」于「余」）也。
```

读如：有罄者，零；或有首缀余者，……。手段：多写法（“者，”代“，则”）。

### 6 可选结束词“云云”（嵌套鉴不再吞外层分支）

```
「读值」者，得「可选」，鉴「可选」：
　有「可有」于「值」，则鉴「值」：有「零」，则『零』；或有「其他」，则『非零』云云；
　或有「可无」，则『无』也。
```

手段：加符（“云云”收住内层）。今制此处须加括号。

## 五、局部递归（B7 阶乘）

### 1 ★ 复令

```
「阶乘」者，得「数」，
　复令「乘至」其化「数」、「数」为「数」
　　为得「余」，又得「积」，
　　　若「余」等于「零」，则「积」，否则「乘至」于（「余」减「一」）于（「积」乘「余」），
　乃「乘至」于「数」于「一」也。
```

读如：阶乘者，得数，复令乘至其化数、数为数，为得余，又得积，若余等于零，则积，否则乘至于余减一于积乘余，乃乘至于数于一也。

“复令”的别选（其余照上）：

| 写法 | 说明 |
| --- | --- |
| 周令 | “周而复始”之周 |
| 自令 | 点出自引用 |
| 反令 | “反者道之动”（《老子》四十章） |
| 循令 | 循＝循环 |
| 递令 | 留“递归”之“递” |

“其”的别选：`乃`（`复令「乘至」乃化……为……`）、`属`。

## 六、标签与介词（B13 开头三字）

### 1 ★ 介词标签

```
「截取」乃化「文」，自「数」，至「数」，为「文」也。
「截取」者，得「文」，自「起」，至「止」，乃「获取子字符串」于「起」于「止」于「文」也。
「开头三字」者，得「文」，乃「截取」于「文」自「零」至「三」也。
```

读如：截取乃化文，自数，至数，为文也。……开头三字者，得文，乃截取于文自零至三也。
手段：加符（介词作标签：类型里 `，自 类`，匿名函数里 `自「名」，`，调用里 `自 值`）。

### 2 名字标签（曰、为）

```
「截取」乃化「文」、「数」曰「起」、「数」曰「止」为「文」也。
「截取」者，得「文」，得「起」为「甲」，得「止」为「乙」，乃「获取子字符串」于「甲」于「乙」于「文」也。
「开头三字」者，得「文」，乃「截取」于「文」于「起」为「零」于「止」为「三」也。
```

读如：截取乃化文、数曰起、数曰止为文也。手段：换字、少量调序（类型里“类 曰 名”）。不宜用介词的参数（如「宽」「高」）照此写。

### 3 介词集

| 介词 | 例 | 适用 |
| --- | --- | --- |
| 自、至 | `自「零」至「三」` | 起止 |
| 从、向 | `从「甲」向「乙」` | 来去 |
| 在 | `在「目录」` | 处所 |
| 依、按 | `依「格式」`、`按「次序」` | 依据 |

不收：以（类型实参）、与（对子）、为（结果与名字标签）、于（首个实参）。

### 4 默认值

```
「排版」者，得「文」，得「宽」为「宽值」阙则「八十」，乃……也。
```

“阙则”的别选：默认、素、本、常。

## 七、异常（B11 安全除）

### 1 ★ 姑试、如有不虞、呜呼

```
「安全除」者，得「甲」，又得「乙」，
　姑试：若「乙」等于「零」，则呜呼『除数为零』，否则「甲」除以「乙」；
　如有不虞，则「零」也。
```

读如：安全除者，得甲，又得乙，姑试：若乙等于零，则呜呼“除数为零”，否则甲除以乙；如有不虞，则零也。
手段：加符（“姑试：……；如有不虞，则……”展开成「尝试运行」，“呜呼”展开成「发生事故」）。

### 2 wenyan 语

```
「安全除」者，得「甲」，又得「乙」，
　姑妄行此：若「乙」等于「零」，则呜呼『除数为零』，否则「甲」除以「乙」；
　如事不谐，则「零」也。
```

手段：加符。“姑妄行此”“如事不谐”取自 wenyan。

### 3 取出错误

```
「安全除」者，得「甲」，又得「乙」，
　姑试：若「乙」等于「零」，则呜呼『除数为零』，否则「甲」除以「乙」；
　如有不虞「误」，则（书「误」；「零」）也。
```

手段：加符（“如有不虞”后可接一个名字，绑定错误文字）。

### 4 抛出的叹词

`呜呼『……』`（★）、`嗟夫『……』`、`噫『……』`、`惜哉『……』`。

## 八、输出与先后（B14 问安）

### 1 ★ 书、；

```
「问安」者，得「名」，书『问』附「名」附『安。』；书『豫言谨识。』也。
```

读如：问安者，得名，书“问”附名附“安。”；书“豫言谨识。”也。手段：加符（前缀“书”展开成「打印行」）。

### 2 而后

```
「问安」者，得「名」，书『问』附「名」附『安。』，而后书『豫言谨识。』也。
```

手段：加符（中缀“，而后”同“；”）。

### 3 先、次

```
「问安」者，得「名」，先书『问』附「名」附『安。』，次书『豫言谨识。』也。
```

手段：加符（“先……，次……”）。

### 4 遂

```
「问安」者，得「名」，书『问』附「名」附『安。』，遂书『豫言谨识。』也。
```

手段：加符（“，遂”同“；”）。

输出词的别选：书（★）、记、录、示、告。

## 九、标注、构造器、导入、隐式参数

| 构造 | ★ | 别选 |
| --- | --- | --- |
| 类型标注 | `「零点二五」属「小数」` | `「零点二五」，「小数」也`；`「零点二五」者「小数」也`；`「零点二五」是「小数」` |
| 构造器 | `「叶」立「树」也`（不变） | `「叶」属「树」也`；`「叶」者，「树」之形也`；`「树」……一曰「叶」，二曰「枝」……` |
| 导入 | `寻`、`观`、`寻观……之书`（不变） | `藏`、`习`、`观……之书`；`求`、`观`、`求观……之书`；`寻……之籍` |
