# 提案 00043 实施记录

本文只写现代汉语（AGENTS.md）。提案见[网页行在](00043-网页行在.汉语.md)。

## 第一步：豫构交互在网页汇编上运行（2026-10-20）

做法：

- 构建宿主接口（营东道，`库/营造/营东道。接口。豫`）新增「装网汇单元」：把一个网页汇编单元装进本进程，与先装的单元共用零号表、两个异常标签与已装导出（后装的同名导出遮住先装的），暂以给定的命令行参数与程序名运行它的 _start，返回后恢复。原生执行器不供这一项：执行器遇到不认得的带型导入只是不链接（`客体二号/模块。底层。豫` 的装导入），原生上又不会调到它，所以不必分两次合入。
- 诺驿宿主（`豫言操作系统/宿主/节点/宿主.cjs`）与浏览器构建宿主的工作线程（`豫言操作系统/宿主/浏览器/构建/工作线程.mjs`）实现它；原来按“顺序.txt”装单元目录的代码改成共用同一个单元环境。程序名与命令行参数改为可临时替换。
- 豫构（`应用/豫构/入口。豫`）：新函数「本进程装原生单元」（原「运行」里的判断）。交互会话在网页汇编上：前导单元只编网页汇编单元（不给执行器与降级缓存），放在 `.豫构缓存/单元运行诺驿/` 下；前导经「装网汇单元箧」按“顺序.txt”装入；每组的豫汇模块用「洒扫篇编带名」编成网页汇编字节后经「装网汇单元字」装入；装新模块、装部改读 `.wasm`；原生的装入态与执行器状态改为第一次用到时才建；网页汇编的会话暂不加入行在；执行器取豫构自己（同「运行」）。

验收（pit-mac，诺驿）：`node 豫言操作系统/宿主/节点/宿主.cjs 豫构.wasm 交互 --直读 --回执 回执` 依次跑「复述」于『试』、「加」于「一二」于「三零」（印「42」）、「甲」者「五」也、「甲」乘「二」（印「10」，前一组的定义后一组可用）、「案牍」之「列目」于『提案』（壳命令），全部成功；含编前导共约 4 秒（前端阶段缓存与原生共用）。新原生豫构的交互照常（「乙」者「七」也、「乙」加「一」印「8」）。

## 第二步：网页开机进豫构交互（2026-10-20）

做法：

- 新页面 `豫言操作系统/宿主/浏览器/行在/`：`行在.html` 只当屏幕与键盘（显示开机壳的输出，输入框的一行送进开机壳的标准输入）；`行在.mjs` 取两个快照展开到内存文件系统，沿用浏览器构建宿主的进程表起开机壳 `/工具/豫构.wasm 交互 --直读 --提示`（当前目录 /，共享缓存根 /tmp/豫构缓存，不起将作与行在）。
- 浏览器构建宿主：进程表加标准输入（开入、读行、送入、关入）与召回、分页摘要；工作线程的「闻」向主线程读行，补齐东道其余函数（闲块数 −1、风俗为环境块、召回、问使与网络类回暂不可用 −58）与构建基础的「帛页杂凑沙二五六」（浏览器只有异步摘要，交主线程算）。
- 豫构交互找仓根：别处都没有时用 /源（原先只在豫言操作系统里这样找）。
- 快照：`源.tar.gz`（git archive HEAD：豫章、诏令两包的源码加 `库/` 下全部包描述与说明，父包「百家」登记的子包都要在，压缩后约 1.3 MB）展成 /源；`工具.tar.gz`（网页汇编的豫构与诺驿值桥，约 8.6 MB）展成 /工具。前导只有三十多个模块，开机后第一句在浏览器里现编，不在发布时预编。
- 仓库目标「用户态系统浏览器发行」另出 `行在/`（index.html、行在.mjs、两个快照）与 `构建/`（宿主模块与边界胶水本体）；云仓把发行目录发布到 /操作系统/，官网路由给 /操作系统/行在/ 与 /操作系统/构建/ 加 COOP、COEP、CORP 头（云仓同日改动）。

验收（本机内置浏览器，经 `构建。测试服务.mjs` 伺服，跨源隔离）：开场即出提示符；第一句「复述」于『浏览器里的豫言』在浏览器里编前导并运行（十秒内，窗格在后台）；随后「甲」者「五」也、「甲」乘「二」（印「10」）、「计」以「文」于（「藏书」之「列目」于『/源/库』）（印「53」）、「案牍」之「列目」于『/工具』、「取」以「文」于「三」于（「藏书」之「列目」于『/源/库/诏令』）都与原生同法编译运行，每句毫秒级。旧原壳对后三种组合句只报“这里只运行壳命令”。

已知差别：「列目」的次序原生按文件系统（林檎 APFS、裸机 ext4），浏览器按内存文件系统的插入次序；两边都带 “.” 与 “..”。

## 第三步（前半）：「图形」、桌面与终端会话（2026-10-20）

做法：

- 豫构交互：网页汇编会话在环境变量 豫言行在=网页 时就是行在会话，照宿主行在会话装「任务」「图形」「屏键」「电源」四部；前导与各部的单元目录统一放在 `.豫构缓存/单元运行诺驿/` 下（「交互单元根」）。四部只多用到 中书/令行 与几席的壳索、役令、计帐等，源快照带上 库/几席、库/中书、豫寓榫卯 的源码与全仓包描述（压缩后约 2.4 MB），第一次用到时在浏览器里编。
- 浏览器：新文件 `构建/豫寓.mjs` 在工作线程里实现图形桌面要的十个豫寓接口（照「豫言边界」签名的取值形状）；显示面、字体、剪贴板、读屏与合成输入在主线程办，显示面表与画布后端沿用 `../图形.mjs`（画布后端改为导出，好截下屏幕的事件入口）。进程表：字节缓冲的标准输入（读行、读键、原始模式、是否终端，读键照诺驿终端输入取整段转义序列）、交互子程序、增量取出、候收、按区读写文件、带类型列目、系统环境缺省、父进程结束时关闭交互子程序的标准输入；工作线程的提问可移交缓冲（像素帧免拷贝）。
- 行在（主线程）：截下对 /系统/请求进入桌面 的写入，删去请求、写下 /系统/桌面运行中，页面只留“主窗口”画布，起 /工具/图形桌面。豫行；桌面退出后撤标志、回到命令行。豫构在 /工具 下改名 豫构。豫行，与豫言操作系统的 /工具 同名；「本进程装原生单元」照「单元现况」（浏览器全零）判断。
- 发行：工具快照另带网页汇编的图形桌面（工具.tar.gz 压缩后约 17.9 MB）。

验收（本机内置浏览器，测试服务）：开机壳里「图形」在浏览器里编「图形」部、写下请求，行在起图形桌面，画出与裸机同一份桌面（文件浏览列出 /源 /工具 /数据 /系统 /软件 /tmp）；点终端图标、按键后起 /工具/豫构。豫行 交互 --组字 子会话，「复述」于『桌面终端』照常编译运行；终端里「列出役」在浏览器里编「任务」部，经豫寓察役列出开机壳、图形桌面与终端会话三个任务；点“返回命令行”后图形桌面以 0 退出，终端会话随之读到输入结束以 0 退出，页面回到命令行。

留待后续：桌面程序独立成任务（豫寓使者映，每窗一个任务）、声音、「辍」只打断一句（浏览器工作线程中止不了正在运行的一句）、亲行继承标准输入。

## 第三步（后半）：桌面程序独立成任务（2026-10-20）

做法：

- 浏览器：`构建/豫寓.mjs` 的豫寓使者映（子程序显示的八个函数）改为真实现，经同步提问交主线程；输入事件从「豫言边界」的变体形状换成 `../图形.mjs` 的事件记录。
- 行在（主线程）代管显示面：每个带显示面起的子程序一张显示面表（沿用 `../图形.mjs` 的队列与校验），后端把提交的画面存成整块画布与变化区域（几次提交取外包矩形），「取使者画面」交出后清空；「送使者入事」推进子程序的事件队列；「设使者映面尺寸」改尺寸并送「显示尺寸变化」；外壳请求与来信各存一个队列。父程序结束时子程序的显示面随之关闭，正在等待的收到「显示面已关闭」，同 macOS 事件管读到尾。
- 桌面的环境另加 豫言桌面程序=/工具/桌面程序。豫行，九宫（平铺桌面库）就照裸机把每个窗口起成一个任务。
- 发行：图形桌面与桌面程序另成 `桌面.tar.gz`（压缩后约 18.6 MB），第一次进桌面时才取；`工具.tar.gz` 只剩豫构与值桥（约 8.5 MB），开机少等。
- 匠心（矢量绘图库）：折线的「诸明显拐点」改成尾递归。原先的逐点扫描不是尾递归，长折线在浏览器工作线程约 1 MB 的栈上溢出（Maximum call stack size exceeded），原生与诺驿的栈大，没有现出来；按报错里的函数号用 `wasm-tools print` 对回源码找到它。

验收（本机内置浏览器，测试服务）：「图形」后取桌面快照、起图形桌面；点终端图标起 /工具/桌面程序。豫行 终端 任务，按键后它再起 豫构交互 --组字 会话，「列出役」列出开机壳、图形桌面、桌面程序、终端会话四个任务；点任务管理器图标再起一个桌面程序任务，任务管理器列出五个任务与窗口标题；关掉任务管理器的格子后它的任务退出；终端里「辟窗」于「种类」曰『文件浏览』经外壳请求开出文件浏览窗口（又一个任务）；点“返回命令行”后图形桌面、各窗口任务与终端会话都以 0 退出，壳里「列出役」只剩开机壳。

另见：桌面设置库照授权根“桌面”=/ 写在 /桌面设置.数据库，第四步定文件树与持久化时一并安排。

留待后续：声音、「辍」只打断一句、亲行继承标准输入；没人收取的已结束任务的记录还留在进程表里。
