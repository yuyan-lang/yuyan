本文只写现代汉语（AGENTS.md）。

## 一、约束

用户 2026-10-14 定：

1. **解析器照旧。** 仍用操作符表驱动的解析；各操作符的结构基本不变。
2. **允许少量调整参数次序，允许新增中缀与前缀写法。**
3. **避免跨句指代与颠倒参数次序。** 不用“当前之数”“先算后名之曰”一类指代前文的写法，也不写“以乙除甲”这类读序与语义相反的式子。
4. **名字仍在「」，字符串仍在『』。**
5. **以文学性为准。** 第一版逐字换同义字，用户评“文学性不够”；第二版改从整句着手：句读、避复、介词、雅名。

## 二、五条手段

1. **以句读代虚词。** 标点成为连接词的另一种写法：“，”同“而”（函数体、局部名、局部递归之后）；“：”用在“鉴”“姑试”之后；“，则”“，否则”连接条件；“；或有”连接分支。源码因此一读一顿。
2. **一义多字，按位避复。** 同一连接允许几种写法，解析器一视同仁，格式化器按位置轮换：首个参数“得”、其后“又得”；局部名之间用“，”，最后一项之前用“，乃”。古文忌同一虚词复沓，作者不必操心。
3. **介词作标签。** 标签可以取一组固定的介词（自、至、从、向、在、依），签名写 `化「文」，自「数」，至「数」，为「文」`，调用写 `「截取」于「文」自「零」至「三」`，读如句子。名字标签照留：类型里写 `化「数」曰「宽」……`（类型在前、“曰”接名），调用与匿名函数里仍写 `「宽」为 值`。
4. **核心名雅化。** 名字约占全文四成。库里改名，不动解析器：整数→数，字符串→文；打印、抛出、捕获改为前缀写法（见下一条）。
5. **常用结构给中缀、前缀写法。** 算术与比较中缀；列的接头中缀“缀”；打印前缀“书”；抛出前缀“呜呼”；捕获“姑试：……；如有不虞，则……”；类型标注中缀“属”。这些都展开成现有的函数调用或节点。

## 三、第二版方案

| 构造 | 今制 | 第二版 | 手段 |
| --- | --- | --- | --- |
| 签名 | `「名」乃 类 也` | 不变 | — |
| 定义 | `「名」者 值 也` | `「名」者，值 也`（“者，”为另一写法） | 多写法 |
| 类型别名、构造器、导入 | `即`、`立`、`寻观……之书` | 不变 | — |
| 函数类型 | `化 甲 而 乙` | `化 甲 为 乙`；多参 `化 甲、乙 为 丙` | 换字、加符 |
| 标签（类型里） | `化「起」为 类 而 ……` | 介词 `化「文」，自「数」，至「数」，为「文」`；名字 `化「数」曰「宽」，……为……` | 加符、少量调序 |
| 匿名函数 | `会「甲」而 体` | `得「甲」，体`；其后的参数 `又得「乙」，体` | 换字、多写法 |
| 带标签的匿名函数 | `会「起」为「甲」而 体` | 介词 `自「起」，体`；名字 `得「宽」为「甲」，体` | 加符、换字 |
| 默认值 | `默认` | `阙则` | 换字 |
| 局部名 | `虑「甲」者 值 而 体` | `令「甲」为 值，体`；末项前 `，乃 体` | 换字、多写法 |
| 局部递归 | `递归虑「名」其 类 者 值 而 体` | `复令「名」其 类 为 值，乃 体` | 换字、多写法 |
| 调用 | `函 于 甲 于 乙` | 不变；介词标签 `函 于 甲 自 乙 至 丙` | 加符 |
| 类型实参 | `函 授以 类` | `函 以 类` | 换字 |
| 算术与比较 | `「加」于「甲」于「乙」` 等 | `「甲」加「乙」`、减、乘、除以、大于、小于、等于；`非「甲」` | 加符 |
| 列的接头 | `「缀」于「首」于「余」` | `「首」缀「余」`（值与模式都可用） | 加符 |
| 条件 | `若 甲 则 乙 否则 丙` | `若 甲，则 乙，否则 丙`；再分支 `，否则若` | 多写法 |
| 模式匹配 | `鉴 值 而 有 模式 则 甲 或有 模式 则 乙` | `鉴 值：有 模式，则 甲；或有 模式，则 乙` | 多写法 |
| 类型标注 | `类 也 值` | `值 属 类` | 加符 |
| 打印 | `「打印行」于 文` | `书 文` | 加符 |
| 抛出 | `「发生事故」授以 类 于 文` | `呜呼 文` | 加符 |
| 捕获 | `「尝试运行」授以 类 于（会「无」而 甲）于（会「误」而 乙）` | `姑试：甲；如有不虞，则 乙`；取错误 `如有不虞「误」，则 乙` | 加符 |
| 类型名 | `整数`、`字符串` | `数`、`文` | 库改名 |

不变的：`乃`、`即`、`立`、`寻`、`观`、`寻观……之书`、`于`、`且`、`或`、`与`、`合`、`中`、`附`、`之`、`；`、`「列」【……】`、`承`、`受`、`遇`；注释、数字的写法；“否则”（见《左传·襄公二十六年》“义则进，否则奉身而退”）。

格式化器的避复规则：参数首个“得”、其后“又得”；局部名之间“，”、最后一项之前“，乃”；匹配“鉴……：”“；或有”；条件“，则”“，否则”；保留“而”的地方，“而”居行首。

## 四、整篇样例

```
寻观「标准库」之书。
「入口」乃化「有」为「有」也。
「入口」者，得「无」，书『问天地好在。』也。

「平方和」乃化「数」、「数」为「数」也。
「平方和」者，得「甲」，又得「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　乃「甲方」加「乙方」也。

「符号」乃化「数」为「文」也。
「符号」者，得「数」，
　若「数」大于「零」，则『正』，
　否则若「数」小于「零」，则『负』，
　否则『零』也。

「求和」乃化（「列」于「数」）为「数」也。
「求和」者，得「数列」，鉴「数列」：
　有「罄」，则「零」；
　或有「首」缀「余」，则「首」加（「求和」于「余」）也。

「阶乘」乃化「数」为「数」也。
「阶乘」者，得「数」，
　复令「乘至」其化「数」、「数」为「数」
　　为得「余」，又得「积」，
　　　若「余」等于「零」，则「积」，否则「乘至」于（「余」减「一」）于（「积」乘「余」），
　乃「乘至」于「数」于「一」也。

「截取」乃化「文」，自「数」，至「数」，为「文」也。
「截取」者，得「文」，自「起」，至「止」，乃「获取子字符串」于「起」于「止」于「文」也。
「开头三字」乃化「文」为「文」也。
「开头三字」者，得「文」，乃「截取」于「文」自「零」至「三」也。

「安全除」乃化「数」、「数」为「数」也。
「安全除」者，得「甲」，又得「乙」，
　姑试：若「乙」等于「零」，则呜呼『除数为零』，否则「甲」除以「乙」；
　如有不虞，则「零」也。

「问安」乃化「文」为「有」也。
「问安」者，得「名」，书『问』附「名」附『安。』；书『豫言谨识。』也。

「样本小数」乃「小数」也。
「样本小数」者，「零点二五」属「小数」也。
```

读如：“平方和者，得甲，又得乙，令甲方为甲乘甲，令乙方为乙乘乙，乃甲方加乙方也。”“安全除者，得甲，又得乙，姑试：若乙等于零，则呜呼‘除数为零’，否则甲除以乙；如有不虞，则零也。”

## 五、机制与风险

- **多写法**：给现有操作符另加组件字面不同、构造同一节点的操作符（如“得”与“又得”，“而”与“，”与“，乃”）。规约关系表按操作符名查，新写法要补对应条目。
- **“，”的两种身份。** 在【】里仍是列的分隔。列的元素若含局部名、匿名函数，会有两种读法，须加括号；写进 `LOCALAGENTS.md`。
- **“为”的几处用法。** 函数类型的结果、`令……为`、`复令……为`、名字标签 `「宽」为 值`、`得「宽」为「甲」`，靠位置区分，须原型实测。
- **介词与其他关键词。** 介词集不含“以”（类型实参）、“与”（对子）、“为”；“自”“至”等目前不是关键词。
- **“如有不虞”** 以“如”起首，避开匹配首支的“有”。
- **新算术词与 `于` 混写不定优先级，须加括号**（同 00022 的且、或）。
- **类型名改名**（数、文）牵动面最大，可在库里先加别名，分步迁移。

## 六、本约束下仍做不到的

- 普通函数的调用仍以“于”引出首个实参。
- 括号仍在，名字仍要「」。
- 数字逐位、注释写法不变（要改词法）。
- 取项仍写“中零”。

## 七、实现与迁移要点

1. **原型。** 在临时工作树里改 `库/编译器核心/编译数据/操作符/内建操作符/`（内建操作符对象定义、文言符集、标签操作符）与规约关系表，用钉点工具链编一级豫构，按新写法改写若干文件，用新编的格式化器逐个解析，核对无歧义（00024 的原型就是这样做的）。
2. **格式化器。** `库/源码排版/源码排版。豫` 写死了“而”“会”“虑”等关键词，须同步，并加上避复规则。
3. **迁移。** 会→得、授以→以、`虑「甲」者`→`令「甲」为`、递归虑→复令可按字替换；“化……而”的“而”、局部递归里的“者”、换成句读的“而”，要按语法定位。若提案 00026 能按文体重印源码，迁移即重印。中缀、前缀与“属”是新增写法，旧代码可不改。
4. **换钉。** 编译器先两种写法都认，CI 发布新工具链后改钉，再整仓迁移、删旧写法。
