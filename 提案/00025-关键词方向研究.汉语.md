# 提案 00025：关键词方向研究

日期：2026-10-14。研究基线：豫言提交 `fcbb600d15a9208c96848edbd6d20c1e5f45ac70`。研究范围依据本次确认的计划：先比较文体与核心句式，完整关键词体系及十五篇全部改写留待后续。

## 一、结论

建议继续展开两条方向：**简劲论说体**与**算书述术体**。前者以「者……也」安放名称和定义，以短句承接局部计算；后者以「术曰」「名之曰」「得」组织过程，适合逐步讲明算法。史传叙事体作为第三条对照，在输出、异常等有事件先后的段落中有优势，在纯计算中容易增加套语。

本轮最有价值的调整是让句法关系读得出来：谁接受什么、什么命名为什么、何处给出结果。关键词的古籍出处可以支持字义；文学性还取决于这些字组成的整句话。任意现代名称和任意嵌套都参与成句，故单字的雅、某个卦名的联想、平声结尾的数量，各自只说明一部分。

五种文体的试写与三条入围方向共用明确的表达边界。由此得出的推荐限于本报告所列样本、拟写和阅读标准，属于方向选择。拟写的程序语义在本文中约定，编译器实现与全语法唯一解析证明属于下一阶段。

## 三、协议前提的核查

| 原判断 | 核查结果 | 对设计的影响 |
| --- | --- | --- |
| 「者……也」适合定义 | 有强句式依据。《论语·颜渊》“政者，正也”是简洁判断实例。[原文](https://ctext.org/analects/yan-yuan) | 保留为优先候选；复杂函数体仍须表达接受参数和结果的关系 |
| 「乃」「即」作系词得体 | 判断用法有据。《史记·魏公子列传》“嬴乃夷门抱关者也”；《项羽本纪》“梁父即楚将项燕”。“判断用法”是本报告所需的结论，语法学词类归属可以进一步讨论。[魏公子列传](https://zh.wikisource.org/wiki/史記/卷077)、[项羽本纪](https://zh.wikisource.org/wiki/史記/卷007) | 今制两字有保留资格；类型签名与类型别名的技术分工仍由语言另行约定 |
| 「否则」属于近世语 | 《左传·襄公二十六年》已有“义则进，否则奉身而退”。否可理解为前项条件的否定，接则引出后果。[原文，检索义则进](https://zh.wikisource.org/wiki/春秋左氏傳/襄公) | 取消其“今语”扣分；“否则”“不然”“若非”按具体句子比较 |
| 行末的「而」构成句末违例 | 仓内词法规定外层忽略换行，表达式可以跨行；排版行尾与句法句末须分开。[词法与语法](../应用/豫言编译器/文档/语言技术规范/词法与语法.汉语.md) | 调整换行即可修复的一部分问题，归入排版与朗读；真正的关联对象欠缺才归入文法 |
| 「授以」必然施受倒置 | 按“函数”为主语来读，会出现受者与施者的冲突；按被说明的话题加省略施者来读，则仍有解释空间。《师说》“授之书而习其句读者”明确展示授予者、受者、所授物的区别。[原文](https://ctext.org/wiki.pl?chapter=959513&if=en&remap=gb) | 比较「以类型授函数」等更显式写法；类型实例化的语义属于新拟，古句只能支持其施受结构 |
| 「化甲而乙」缺少「为」 | 以“改变甲使成乙”为释义时，补足结果词能清楚表达；现制也可被解释为已约定的箭头记号 | 比较「化甲为乙」「受甲而成乙之术」「自甲至乙之术」，分别检验是否会暗示把输入对象破坏性地改成输出 |
| 「罄」适合空列 | 《说文·缶部》直接释“器中空也”，与容器空状态相近；这一依据比“罄竹难书”的联想更直接。[字条及广韵页码](https://ctext.org/dictionary.pl?char=罄&if=en&remap=gb) | 保留为优先候选；技术义为“空列构造器” |
| 「可有可无」能证明可有、可无雅且义合 | 成语所说的是有无皆可，和一个值当前具有或缺少内容之间有语义距离；时代也须另核 | 分别比较「有值／无值」「有／无」「可有／可无」；保留现名时说明“可”在类型与构造器中的不同理解 |
| 多用《易》字就能统一文体 | 卦爻辞的占断、象传的解释、系辞的论说各有组织方式 | 分开取样；“谓之”带来的论说感也能归入简劲路线 |
| wenyan 仅用「」 | 官方词法器还识别『』字符串，并忽略句号、顿号、空白等。[词法器](https://raw.githubusercontent.com/wenyan-lang/wenyan/master/src/parser.ts) | 比较实际样例的符号量，避免据印象判定 |
| 原表能确定绝对最佳 | 名称自由、朗读习惯、文体偏好和候选范围都会改变结果 | 结论表述为在这些条件与样例中的推荐方向 |

另有三项语义补充会影响关键词设计：隐式参数包括类型和值；默认参数目前属于顶层函数的特定能力；当前语言允许引用等可观察副作用。因此，改写按顺序保存原有调用和分支行为。[依值类型](../应用/豫言编译器/文档/语言技术规范/依值类型.汉语.md)、[标签与默认参数](../应用/豫言编译器/文档/语言技术规范/标签函数类型.汉语.md)、[执行与编译](../应用/豫言编译器/文档/语言技术规范/执行与编译.汉语.md)

## 五、比较所用的最小语义框架

### 边界与共同约定

以下拟写用于比较文学方向，统一放在文本代码块中。名字、数字和字符串继续采用现有界符；现有「整数」「字符串」「有」「乘」等核心名先保留，以隔开句式变化和核心改名的效果。

- 签名用 `「名」之类，受（参数类型……）而成结果类型之术也。`。参数类型之间的顿号列出同组不同参数；一个元组参数须整体成组。参数分组与完全应用要求沿用现制，实参按顺序处理。[调用规则](../应用/豫言编译器/文档/语言技术规范/类型与模块.汉语.md)
- 甲案定义用 `「名」者，术（……）也。`；乙案用 `「名」术曰（……）。`；丙案用 `「名」之术曰（……）。`。三者都是函数值的定义。
- `受「甲」、「乙」` 或 `始受「甲」，次受「乙」` 引入同一组两个实参。匿名函数统一用 `术（受……；得……）`。`得` 只标记当前术体末项的结果。
- 调用统一用 `施函数于实参于实参`。复合函数头、复合实参各用括号。`施` 明示“施行一术”，连续「于」的复沓仍记作共同弱点。
- 局部名分别用 `以值为「名」`、`置值，名之曰「名」`、`既得值，名之曰「名」`。丙案的后续局部名也用 `又得值，名之曰「名」`。值只求一次，名字作用于当前术体后续部分。
- 匹配统一用 `（鉴值：其为模式，则结果；其为模式，则结果）`。复杂模式和分支结果加括号。构造器模式仍写 `「缀」于「首」于「余」`；模式里的新名只在本分支可见。
- 条件保留 `若条件则甲否则乙`，嵌套时整式成组。先后求值保留分号；分号在当前术体中从左到右连接各句。
- `以实参授函数` 表示依次给出隐式实参，涵盖类型和值；复合头加括号。标签暂保留 `受「起」为「甲」`、`于「起」为值`，以便直接核对位置与绑定。
- `立「树」为类` 建立名义类型，`立「叶」为「树」` 及函数形的 `立「枝」……` 建立构造器；“立”的声明身份由本研究约定。

这组约定给本轮样例及组合试写提供统一解释。各片段共用已引入标准库核心名的前置环境。完整的词法优先级、错误恢复、全体表达式组合及唯一解析证明，是进入完整方案时的验收事项。句尾“也”、标点与括号共同承担边界，全语言唯一解析须经完整语法核验。

### 核心句式的候选与取舍

| 意思 | 候选 | 本轮取舍 |
| --- | --- | --- |
| 定义 | 名者值也；所谓名者值也；名之曰名 | 前者用于完整定义；第二式多“所谓”而无额外指向时偏重；第三式适合先算后命名 |
| 函数类型 | 化甲为乙；受甲而成乙之术；自甲至乙之术 | 采用第二式作共同类型框架；保留“化……为……”供更简方案再试 |
| 调用 | 原式；施术于甲于乙；以甲与乙施术 | 第二式明示施行对象；第三式中“与”的参数边界和元组含义需进一步区分 |
| 局部名 | 以值为名；置值名之曰名；既得值名之曰名 | 分别构成甲乙丙三种口吻 |
| 条件 | 若则否则；若则不然；若则若非 | 三者均可参评；本轮保留第一式，古今判定据第三节修正 |
| 匹配 | 鉴而有；鉴其为则；观其形而有 | 第二式点出“某种形状”；模式分支的技术义仍属新拟 |
| 隐式实参 | 函数授以值；以值授函数；授函数以值 | 第二式施受较明确；长的类型实参会推迟读者看到函数名 |
| 标签 | 于起为零；以零为起；名起者零 | 文法试读偏好第二式；统一方向样本保留原标记，后续须同签名、绑定一起设计 |
| 注释 | 双语框；注曰与疏曰；按曰 | 本轮保持双语内容，以 `注曰『……』` 划定边界，注释内容退出求值；“注/疏”与汉语/文言是不同分类，映射须显式说明 |

## 六、五路同题初筛：B2 平方和

共同输入为甲三、乙四，结果二五。各稿保留「平方和」「甲」「乙」「甲方」「乙方」及全部核心函数名。三条深入方向在本节与第七节合计各六篇。

### 今制

```text
「平方和」乃化「整数」而化「整数」而「整数」也。
「平方和」者会「甲」而会「乙」而
　虑「甲方」者「乘」于「甲」于「甲」而
　虑「乙方」者「乘」于「乙」于「乙」而
　「加」于「甲方」于「乙方」也。
```

### 甲：简劲论说

```text
「平方和」之类，受（「整数」、「整数」）而成「整数」之术也。
「平方和」者，术（
　受「甲」、「乙」；
　以（施「乘」于「甲」于「甲」）为「甲方」；
　以（施「乘」于「乙」于「乙」）为「乙方」；
　得（施「加」于「甲方」于「乙方」））也。
```

### 乙：算书述术

```text
「平方和」之类，受（「整数」、「整数」）而成「整数」之术也。

　受「甲」、「乙」；
　置（施「乘」于「甲」于「甲」），名之曰「甲方」；
```

```text

「平方和」之术曰（
```

### 丁：《易》释象试笔

```text
「平方和」之类，受（「整数」、「整数」）而成「整数」之术也。
「平方和」之象曰（
　受「甲」、「乙」；
　（施「乘」于「甲」于「甲」），谓之「甲方」；
　（施「乘」于「乙」于「乙」），谓之「乙方」；
　得（施「加」于「甲方」于「乙方」））。
```

这里将“之象曰”暂约为函数定义，技术义须另立。稿中真正起作用的是“谓之”的释名句；平方和缺少自然的卦象与占断内容。因此该稿显示《易传》论说可借，而以占断为全语言主调的依据仍薄。将真假写成吉凶还会引入额外价值色彩。

### 戊：辞赋试笔

```text
「平方和」之类，受（「整数」、「整数」）而成「整数」之术也。
「平方和」之术曰（
　受「甲」兮，受「乙」；
　以（施「乘」于「甲」于「甲」）为「甲方」兮；
　以（施「乘」于「乙」于「乙」）为「乙方」兮；
　乃得（施「加」于「甲方」于「乙方」））。
```

本稿以兮作为无求值效果的风格标记，只有骚体的一项表面特征；全篇声韵和比兴仍须另作。另作一项对照：删除三处“兮”，保留两句“以……为……”的平行铺陈，文气更平顺，也更接近甲案。这个对照说明，赋的优点可以来自对偶与章法；本轮搁置的是强制套兮的路线，辞赋作为更大篇章的写作方向仍有空间。


这一稿与甲案共享平行章法；逗号分隔的两个“受”仍引入同一参数组。三案入围代表本轮深入取样的选择，完整文赋路线可凭更有代表性的整篇文本再次参评。

## 八、名称、嵌套与求值的压力样例

本节逐项人工核对作用范围和对应行为。三案共用表达式核，故以甲案的术体作代表；出现保留的今制结构时明确标出。结果是纸面语义审查，执行验证待相应语法实现后进行。

### 一：匹配中再匹配

```text
（鉴「甲列」：
　其为（「缀」于「甲首」于「甲余」），则
　　（鉴「乙列」：
　　　其为「罄」，则「甲首」；
　　　其为（「缀」于「乙首」于「乙余」），则「乙首」）；
　其为「罄」，则「零」）
```

内层右括号先闭合，最后一支属于外层；「甲首」在外层第一支可见，「乙首」仅在内层第二支可见。甲列五六、乙列九时得九；甲列五六、乙列空时得五；甲列空时得零。长分支结束处的成组边界承担必要辨识工作。

### 二：匿名函数作实参、显式给出隐式类型

```text
施（以「整数」授（以「整数」授「态射」））
　于「数列」
　于（术（受「数」；得（施「乘」于「数」于「二」）））
```

两个“授”按由内到外的顺序供给隐式参数；匿名函数由最外一对术体括号界定。数列一二三映为二四六。共同缺点是函数名读到较后的位置；可并列试读“授态射以整数以整数”，后续再决定固定次序。

### 三：局部递归

本轮保留今制的 `递归虑……其……者……而……`，仅将其中函数类型、函数值和调用换成共同拟写。这样可以核对作用域，并把递归关键词的雅化留作独立问题。

```text
（递归虑「乘至」其（受（「整数」、「整数」）而成「整数」之术）者
　术（受「余」、「积」；
　　得（若（施「等于」于「余」于「零」）则「积」
　　　否则（施「乘至」于（施「减」于「余」于「一」）于（施「乘」于「积」于「余」））））
　而（施「乘至」于「数」于「一」））
```

「乘至」在自己的术体和后续调用中可见，签名仍是两个整数参数；「数」为外层非负整数。零得一，五得一二零。候选“复”“自用之术”可提示再次调用，但“复”也可能读作重复执行当前整个表达式，文法与绑定规则需要配套设计。

### 四：标签与默认值

默认参数暂保留现制的完整片段作语义锚点，避免把文学试写当成新能力：

```text
「框」乃可化「宽」为「整数」而化「名」为「字符串」而「字符串」也。
「框」者会「宽」为「宽值」默认「二六」而会「名」为「名值」而
　「名值」附（「整数表示」于「宽值」）也。
「框」于「名」为『甲』
「框」于「宽」为「三六」于「名」为『甲』
```

最后两行分别是独立调用表达式，预期为甲26、甲36。调用标签「宽」与绑定变量「宽值」分别保留；默认值是数据；省略在调用位置补齐。候选“阙则用……”适合说明省略规则，却容易被读成运行期条件分支，因此需要未来完整设计给出声明层边界。匿名函数、高阶函数、顶层可省参数三者的现行范围照语言规范核对。

### 五：隐式值参数与依值结果

下面是现制已有的类型片段与调用片段；它约束“授”的候选义必须同时容纳类型和值：

```text

化（「定长表」于「长」于「甲」）而化（「下标」于「长」）而「甲」

「读定长表」授以「三」授以「整数」于「表值」于「位置」
```

共同拟写的实参部分是：

```text
施（以「整数」授（以「三」授「读定长表」））于「表值」于「位置」
```

先三后整数的顺序保持；长度与下标约束仍属于类型。此处「三」是隐式值实参，体现将“授”解释为“供给被省略的参数”比解释为“只给类型”覆盖更全。

### 六：短路与异常边界

```text
「阴」且（施（以「爻」授「发生事故」）于『不应求值』）
「阳」或（施（以「爻」授「发生事故」）于『不应求值』）
```

两行分别得到阴、阳，右式均保持未求值。为让文字顺口而先给右式命名，会引起可观察的语义变化；所有候选必须保留这种延迟关系。B11 的“术（受无……）”同样是待执行的函数，创建函数与执行函数应分别叙述。

### 七：现代长名与记谱

统一把 B2 的「甲」「乙」依次替换为「长」「宽」、再替换为「初值」「次值」、再替换为「用户输入数」「默认比较数」。其余定义名、局部名和核心名都保持。

「甲」在 B2 各稿出现三次，「乙」也出现三次：从一字名换成二字名，整段增加六字；换成五字名，增加二十四字。各案同时承受这项增长。甲案的“以……为……”和乙案的“名之曰……”仍能维持关系，丁戊的整齐对句需要重新安排停顿；按单字平仄凑成的固定格式更容易被替换打破。

“平方和”作为名称整体读一组，重音按意义而定；五字现代词也按词义分成“用户／输入数”。保持名称原样的阅读效果，是此研究必要的一部分。

## 九、关键句读、声调与计量

### 句读与声调注释

记号沿协议：`｜`为意群内音步提示，`‖`为自然句读，`○`为中古平声，`●`为中古仄声。下表给出核过调类的短骨架；完整程序的逐字韵书查核留待确定关键词后开展。名称用〔名〕占位时，声调行也留同位占位；它不参与这行短骨架的平仄推断。

| 场景 | 关键读法 | 中古调类骨架与今音观察 |
| --- | --- | --- |
| B2，甲的定义 | 〔名〕者‖术……也 | 〔名〕●‖●……●；者、也为上声，术为入声。也在普通话中可轻缓收句，仄声身份本身说明不了实际促迫 |
| B2，乙的命名 | 名之｜曰〔名〕 | ○○｜●〔名〕；名、之平，曰入。今音“名之／曰甲方”可自然分两组 |
| B2，丙的推进 | 既得｜〔值〕‖乃得｜〔值〕 | ●●｜〔值〕‖●●｜〔值〕；得为入声，既去、乃上。连续仄声对应推进感，也可能显得重复 |
| B5，空列分支 | 其为｜罄‖则零 | ○○｜●‖●○；为取判断义，普通话 wéi；罄去、则入、零平。“其为罄”按完整条件读，单字罄保留重音 |
| B8，构造声明 | 立〔叶〕｜为〔树〕 | ●〔叶〕｜○〔树〕；立入声。名内叶入、树去；音调连仄与结构语义须分项评议 |
| B11，条件衔接 | 若……｜则……‖否则…… | 若、则入，否上；普通话 ruò、zé、fǒu zé。条件内容决定自然停顿，不能只给连词排名 |
| B13，标签试读 | 以零｜为起 | ●○｜○●；以、起上，零、为平。两组关系明白，配套类型声明还需再试 |

### B2 平方和

```text
吾有一術。名之曰「平方和」。
欲行是術。必先得二數。曰「甲」。曰「乙」。
乃行是術曰。
　乘「甲」以「甲」。名之曰「甲方」。
　乘「乙」以「乙」。名之曰「乙方」。
　加「甲方」以「乙方」。乃得矣。

```

函数程式参照[阶乘示例](https://raw.githubusercontent.com/wenyan-lang/wenyan/97f0a4b8c5a815467c5c2cac08215d722efde208/examples/factorial.wy)。共同输入三、四得到二五；`數`与豫言整数的完整数值契约分别记录。这里无需新增临时名字。

### B5 求和

```text
吾有一術。名之曰「求和」。
欲行是術。必先得一列。曰「数列」。
乃行是術曰。
　若「数列」之長等於零者。乃得零。也。
　夫「数列」之一。名之曰「首」。
　夫「数列」之其餘。名之曰「余」。
　施「求和」於「余」。名之曰「余和」。
　加「首」以「余和」。乃得矣。
是謂「求和」之術也。
```

空列、首项与尾列用数组长度、索引和切片表达；参照[归并排序示例](https://raw.githubusercontent.com/wenyan-lang/wenyan/97f0a4b8c5a815467c5c2cac08215d722efde208/examples/mergesort.wy)。相较基准新增一个临时名「余和」。该编码保留共同输入的求和行为；封闭构造器及模式检查属于另一层类型能力。

### B8 树的叶数

```text

　　物之「「右」」者。物曰「右」。

　乃得「枝值」。

乃行是術曰。
　若「树值」之「「类」」等於「「叶」」者。乃得一。也。
　夫「树值」之「「左」」。名之曰「左」。
　夫「树值」之「「右」」。名之曰「右」。
　施「叶数」於「左」。名之曰「左数」。
　施「叶数」於「右」。名之曰「右数」。
　加「左数」以「右数」。乃得矣。
是謂「叶数」之術也。
```

参照[对象示例](https://raw.githubusercontent.com/wenyan-lang/wenyan/97f0a4b8c5a815467c5c2cac08215d722efde208/examples/obj.wy)。对象编码新增标记字段「类」，新增中间结果「枝值」「左数」「右数」。对合法树保留叶数行为；名义类型、两个构造器的封闭范围和模式覆盖检查作为语义差异单列。

### B11 安全除

```text
吾有一術。名之曰「安全除」。
欲行是術。必先得二數。曰「甲」。曰「乙」。
乃行是術曰。
　姑妄行此。
　　若「乙」等於零者。
　　　嗚呼。「「除零」」之禍。曰「「除数为零」」。
　　也。
　　除「甲」以「乙」。所餘幾何。名之曰「余」。
　　減「甲」以「余」。名之曰「整除数」。
　　若「整除数」等於零者。乃得零。也。
　　除「整除数」以「乙」。乃得矣。
　如事不諧。
　　不知何禍歟。乃得零。
　乃作罷。
是謂「安全除」之術也。
```

参照[异常示例](https://raw.githubusercontent.com/wenyan-lang/wenyan/97f0a4b8c5a815467c5c2cac08215d722efde208/examples/try.wy)及后端。默认后端将除译为浮点除法；这里先求余，再用甲减余，最后除乙，编码向零截断整数商。新增「余」「整除数」两个临时名。共同检查七除三为二、负七除三为负二、七除负三为负二、一除负三为零、除零为零，限小整数。错误对象与豫言的异常载荷分别记录。

### B13 开头三字

```text
吾有一術。名之曰「截取」。
欲行是術。必先得二數。曰「起」。曰「止」。
一言。曰「文」。
乃行是術曰。
　吾有一言。曰「「」」。名之曰「果」。
　吾有一數。曰零。名之曰「位」。
　凡「文」中之「字」。
　　若「位」不小於「止」者。乃止。也。
　　若「位」不小於「起」者。
　　　加「果」以「字」。
　　　昔之「果」者。今其是矣。
　　也。
　　加「位」以一。
　　昔之「位」者。今其是矣。
　云云。
　乃得「果」。
是謂「截取」之術也。

吾有一術。名之曰「开头三字」。
欲行是術。必先得一言。曰「文」。
乃行是術曰。
　施「截取」於零。於三。於「文」。乃得矣。
是謂「开头三字」之術也。
```

该稿借默认捷思后端的 `for…of` 字符串遍历按码点计数，新增「果」「位」「字」。参数按位置传入，调用标签在该对照中单列为缺少直接对应的能力。共同输入约束为起止非负且起不大于止，起在串内；止超出末尾时截至末尾。直接用字符串索引及长度会按宿主码元处理，故选择上述编码。官方可选严格检查器对“凡”的容器另有限制，本稿的适用路径为默认后端，严格检查通过情况待验。

### B14 问安

```text
注曰。「「汉语：先问安，再署名。文言：先问安，后署名。」」。

吾有一術。名之曰「问安」。
欲行是術。必先得一言。曰「名」。
乃行是術曰。
　加「「问」」以「名」。名之曰「前」。
　加「前」以「「安。」」。書之。
　吾有一言。曰「「豫言谨识。」」。書之。
　乃歸空無。
是謂「问安」之術也。
```

字符串加法与书之按官方检查器和后端核对。中间串命名为「前」，使随后输出只针对组合完成的结果。对照核两行文字和先后顺序；无返回值与豫言单位值的表示差异单列。
