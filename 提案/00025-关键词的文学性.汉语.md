## 一、缘起

wenyan-lang 读来像一篇古文，豫言读来像算式里嵌着文言字。两者都以文言为关键词，文采却有高下。本文把豫言源码当作文章来读：合不合文言的文法，有没有句读与节奏，声音是否和谐，有没有统一的文体与说话的人；再对照 wenyan-lang，找出差距与可走的路。

## 二、wenyan-lang 的文采从何而来

1. **一体一声。** 它摹仿古代算书的文体，作者自谓“偶追《十书》之笔意”（《算经十书》），又用第一人称书生的口吻：`吾有一數。曰三。名之曰「甲」。`、`書之。`。函数是一门“术”：`欲行是術。必先得二數。曰「甲」。曰「乙」。乃行是術曰。……是謂「翻倍」之術也。`。通篇是同一个人在同一种文体里说话。
2. **虚词各守本义。** `以`、`於` 分别标出两个运算数：`加一以二`、`加一於二`。`者`、`也`、`矣` 都在本来的位置：`若三大於二者。……也。`、`昔之「甲」者。今「大衍」是矣。`。逻辑运算写成问句：`夫「甲」「乙」中有陽乎`（或）、`中無陰乎`（且）。
3. **句短而有节。** 三字、四字一顿：吾有一數／曰三／名之曰「甲」／書之。一句只做一件事，靠句读断开层次；嵌套调用用 `夫`、`其`、`取二以施` 层层承接，不用括号。
4. **有情味，带幽默。** 抛出异常是 `嗚呼。「「……」」之禍。`；捕获写成 `姑妄行此。……如事不諧。豈「「……」」之禍歟。……不知何禍歟。……乃作罷。`；丢弃一个值是 `噫`；删除是 `不復存矣`；无返回是 `乃歸空無`。程序出错时，字里有一声叹息。
5. **承注疏之体。** 注释分 `注曰`、`疏曰`、`批曰`，正是古籍的注、疏与评点；宏写作 `或云……蓋謂……`。
6. **数用古法。** 计数从十、百、千、萬、億直到兆、京、垓、秭、穰、溝、澗、正、載、極，小数用分、釐、毫、絲、忽、微、纖、沙、塵、埃、渺、漠，数字本身就是一段古雅的度量衡。
7. **字净。** 只用繁体字与「」，句读可省，全篇没有括号。

它的代价是冗长：`var a = 3` 要写十个汉字。这是它的风格选择。

## 三、豫言已有的佳处

- **判断句。** 定义写 `「名」者……也`，正是“陈胜者，阳城人也”的句式；签名用 `乃`，透明定义用 `即`，都是古人的系词。这是豫言最得文言之体的地方，比 wenyan 的“吾有一術……是謂……之術也”简劲。
- **以读书喻导入。** `寻观「标准库」之书`，雅。
- **以鉴喻匹配。** `鉴` 取“以铜为鉴，可以正衣冠”之义；`有……则……或有……则……` 合古人列举之体。
- **核心名称多有意象。** 爻值为 `阳`、`阴`，其类为 `爻`，单位为 `元`，都出于《易》；空列为 `罄`（罄竹难书），连缀为 `缀`；可选值为 `可有`、`可无`，合起来正是成语“可有可无”，`或可有` 也妙。
- **简古。** 一句一定义，有《论语》《老子》式的简劲，这是 wenyan 没有的长处。
- **文档有文采。** 《豫言赋》以赋体讲语言，篇目“启机、正名、术数、决疑、制器、鉴形、列阵、通术、归藏、府库、弦歌、持变、成章”有古书气象；小引“以 `化` 述所变，以 `而` 接所成；以 `鉴` 察万形，以 `承` 贯众类”已道出用字的立意；代码注释也配文言。

## 四、豫言的不足

1. **虚词当作分隔符，不成文法。** 这是最大的差距。`于`、`而`、`者`、`也` 多半只起切分作用，按文言读不通：
   - `「加」于「甲」于「乙」`：“于”本是介词（在、向、比），“加于甲于乙”不成话；`于……于……于……` 连缀，读来口吃。算书说“以甲乘乙”“并甲乙”，wenyan 说“加「甲」以「乙」”。
   - 行末悬“而”：`会「甲」而`、`虑……而` 常独占行尾。文言的“而”居句中，承上启下，悬在句末则气不收。
   - `化「整数」而「整数」`：成语是“化 A 为 B”（化干戈为玉帛、化腐朽为神奇），豫言却把“为”给了标签。
   - `「整数」也「一」`（类型标注）：判断句次序颠倒，古人说“一，整数也”。
   - `「罄」授以「整数」`：“授之以”是施予者在前，这里受者在前，施受倒置。
   - `虑「甲」者 值 而 体`：“虑”是思虑，不与“者”成判断。
   - `「对」中「零」`：古人不说“中零”，说“其一”“之首”。
   - `于「起」为「零」`（标签）：不辞，古人说“以零为起”。
2. **没有句读与节奏。** 一个定义往往是一整句，层层括号代替了停顿。读者无从断句，也就没有抑扬。
3. **符号压过文字。** 名字、数字都在「」里，再加（）【】，；，满页是框。古籍除句读外几乎没有符号，wenyan 也只有「」。
4. **古今语混杂。** 关键词里有“递归”，常用名里有“打印行”“整数表示”“发生事故”“尝试运行”“字符串”“元类型”。今语术词夹在古语中间，像古文里插进说明书。
5. **没有统一的文体与口吻。** “寻观之书”像读书笔记，“鉴”像史家，“爻”“阴阳”出于《易》，“会”“化”“授以”“遇”各有来处，拼不成一种文章，也没有一个说话的人。
6. **少情味。** 出错用“发生事故”，是公文腔；wenyan 在这里有“嗚呼”“豈……之禍歟”“乃作罷”。
7. **数字逐位。** `「一二三」`、`「一点五」` 像电报码；古法说“一百二十三”“一又二分”“一分五厘”。
8. **声律偏促。** 结构关键词几乎都是仄声：若、则、鉴、有、或、乃、者、也、即、立、会、化、虑、与、合、附、受、遇；平声只有而、于、之、中、寻、观、承。句子多收在仄声上，读来短促；wenyan 常以“書之”“云云”这样的平声收束，余音较长。

## 六、可取的文体

要有文采，先要有一种文体、一个说话的人。wenyan 取了算书；豫言不必再走算书，名字里已有两条现成的路：

- **《易》。** “豫”本是卦名，第十六卦，象曰：“雷出地奋，豫。先王以作乐崇德。”豫言已用了爻、阳、阴、元。注释可用“彖曰”“象曰”，断语可用“吉”“凶”“悔”“吝”，全篇有筮辞的庄重。
- **史。** “鉴”是史书之名（《资治通鉴》）。定义如列传，模块如纪、志、表；评注可仿“太史公曰”“臣光曰”，叙事可用“初，……”“是岁……”起笔，有史笔的沉着。
- **赋。** 《豫言赋》已开其端：“赋曰”铺陈，“乱曰”收束（《离骚》以“乱曰”作结），“乱曰”可作一段的结尾词。

三者可择一为主，或以《易》为体（核心名与断语）、以史为用（定义与评注）。

## 七、试笔（示意，非定稿）

同一段程序：两数平方和、列之求和。

今制：

```
「平方和」乃化「整数」而化「整数」而「整数」也。
「平方和」者会「甲」而会「乙」而
　虑「甲方」者「乘」于「甲」于「甲」而
　虑「乙方」者「乘」于「乙」于「乙」而
　「加」于「甲方」于「乙方」也。

「求和」者会「数列」而
　鉴「数列」而
　　有「罄」则「零」
　　或有（「缀」于「首」于「余」）则「加」于「首」于（「求和」于「余」）也。
```

甲稿，守豫言的简劲，只让虚词回到本义：

```
「平方和」乃化二「整数」为「整数」也。
「平方和」者，受「甲」「乙」，
　令「甲方」为「甲」乘「甲」，
　令「乙方」为「乙」乘「乙」，
　乃「甲方」并「乙方」也。

「求和」者，受「数列」而鉴之：
　有「罄」，则零；
　或有「首」缀「余」，则「首」并「余」之「求和」也。
```

乙稿，叙事体，取算书与史笔之声：

```
「平方和」之术：得「甲」「乙」二数。
　以「甲」自乘，名之曰「甲方」；
　以「乙」自乘，名之曰「乙方」；
　并之，是为所求。
是谓「平方和」。

「求和」之术：得「数列」，鉴之。
　其为「罄」也，得零；
　其为「首」缀「余」也，求「余」之和，并「首」，是为所求。
是谓「求和」。
```

甲稿与今制一一对应，已能成句；乙稿更近 wenyan，文气足而篇幅长。

## 八、待定

1. 方向：守简劲、只正文法（甲稿），还是改为叙事体（乙稿），或在两者之间。
2. 文体：以《易》、以史、以赋，或兼取。
3. 情味的分寸：叹词（呜呼、噫、惜哉）与问句（乎、欤）用多少。
4. 数字是否改用古法（十百千万，分厘毫丝）。
5. 符号：括号、方括号、分号、逗号留多少；数字是否出「」。
6. 常用核心名（打印行、发生事故、尝试运行、字符串等）是否一并雅化。
7. 繁体与竖排是否作为另一种显示方式。
