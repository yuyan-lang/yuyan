# 提案 00010：文本子语言

| 项 | 内容 |
| --- | --- |
| 编号 | 00010 |
| 状态 | 草案 |
| 提出 | 2026-10-09 |
| 范围 | 语言：自定义列宏（`「头」【…】` 的头可以是用户函数）；新库「文本」（文档结构与标准组件）。渲染器、论文网站、投稿系统不在本提案内 |

本提案给豫言加一个描述结构化文档（尤其是中文学术论文）的子语言，下称文本子语言（`text`）。它不加新语法：文档用现有的序列写法 `「头」【项，项，…】` 书写，当前语法分析器直接能解析。语言只放开一条：序列的头可以是用户定义的函数，即自定义列宏。

本文只写现代汉语（AGENTS.md）。

## 一、拟定事项

- **议一：自定义列宏。** `「头」【项一，…，项n】` 的头不是内建的「列」「典」「组值」「组类」时，展开为 `「头」于（「列」【项一′，…，项n′】）`。头是普通函数，类型为 `化（「列」于 T）而 R`。
- **议二：两种项的展开。** 字符串字面量项 `『…』` 展开为 `「文字」于『…』`；命名项 `「名」者 值 也` 展开为 `「名」于 值`；其余项不变。「文字」与各名字按当前作用域查找，与「列」查找「缀」「罄」同理。
- **议三：库「文本」。** 定义文档结构「文节点」、「文字」与标准组件（论文、节、定理、证明、公式、引用等）。组件都是普通函数，用户自己写函数即可新增组件。
- **议四：结构与渲染分离。** 列宏只产生「文节点」树；网页、LaTeX、PDF 等渲染器各自遍历这棵树，另行实现。

## 二、动机

论文要求结构（章节、定理、公式、引用）能被程序检查、生成和变换。豫言的序列写法本来就是“头加一串项”，正好写树形文档；现在只认四个内建的头。放开头的限制，文档就能用现有语法书写，类型、模块、导入全部沿用。

## 三、展开规则

| 写法 | 展开成 |
| --- | --- |
| `「节」【甲，乙】` | `「节」于（「列」【甲，乙】）` |
| 项 `『正文』` | `「文字」于『正文』` |
| 项 `「标题」者『引言』也` | `「标题」于『引言』` |
| 项 `「定理」【…】` | 递归展开 |
| 空序列 `「节」【】` | `「节」于「罄」` |

展开在序列阐述时做（`库/编译器核心/编译数据/操作符/内建操作符/内建操作符对象定义。豫` 的「阐述通用序列」，现在对未知的头返回「可无」）。展开之后照常做名称解析与类型检查。

## 四、库「文本」

```yuyan
「属性」即「字符串」合「字符串」也。

「文节点」立「元类型」也。
  「文字」立化「字符串」而「文节点」也。
  「块」立化「字符串」而化（「列」于「属性」）而化（「列」于「文节点」）而「文节点」也。
  「行内」立化「字符串」而化（「列」于「属性」）而化（「列」于「文节点」）而「文节点」也。
```

「块」「行内」的参数依次是种类名（如 `『定理』`）、属性、子节点。标准组件都是构造这两种节点的小函数：

| 种类 | 组件 |
| --- | --- |
| 文档 | 论文、标题、作者、模型（版式模板名）、摘要、关键词 |
| 章节 | 节（首项是题目；节套节即小节）、段 |
| 数学 | 公式、行内公式、定理、引理、定义、证明 |
| 引用 | 引用（键）、参考文献、文献、标签（名）、参见（名） |
| 行内 | 强调、代码 |

块里直接出现的字符串是一个段落；段内要混排强调、引用时用「段」【…】。组件只构造节点、不做计算，所以文档可以直接写成顶层定义（提案 00006 的可定值）。

新增组件就是写一个函数，例如：

```yuyan
「猜想」乃化（「列」于「文节点」）而「文节点」也。
「猜想」者会「正文」而「块」于『猜想』于「罄」于「正文」也。
```

之后即可写 `「猜想」【『……』】`。

## 五、示例

```yuyan
寻观「文本」之书。

「本文」乃「文节点」也。
「本文」者「论文」【
  「标题」者『豫言的文本子语言』也，
  「作者」者『张三』也，
  「作者」者『李四』也，
  「模型」者『期刊论文』也，
  「摘要」【『本文给出豫言的文本子语言：文档用列宏书写，结构与渲染分离。』】，
  「节」【
    『引言』，
    『学术论文既要便于书写，又要便于程序处理。』，
  】，
  「节」【
    『方法』，
    「定理」【「标签」者『求和』也，『对任意正整数 n，前 n 个正整数之和为 n(n+1)/2。』】，
    「证明」【『对 n 归纳即得。』】，
    「公式」者『\sum_{k=1}^{n} k = \frac{n(n+1)}{2}』也，
    「段」【『由』，「参见」者『求和』也，『及』，「引用」者『王二〇二五』也，『可知……』】，
  】，
  「参考文献」【
    「文献」【「标签」者『王二〇二五』也，『王五：《豫言程序设计》，二〇二五。』】，
  】，
】也。
```

程序生成内容用普通豫言函数，结果作为项放回列宏：

```yuyan
「运行记录」乃化「整数」而「文节点」也。
「运行记录」者会「次数」而「段」【『共运行』，「文字」于（「整数表示」于「次数」），『次。』】也。
```

## 六、备选方案

- 新增文本模式的字面写法（如 `｛…｝`）：正文可以不加引号，但要改词法、排版器与高亮；本提案只用现有语法。
- 另起 Markdown 或 LaTeX 式的独立语言：类型、模块、函数都要另做一套。
