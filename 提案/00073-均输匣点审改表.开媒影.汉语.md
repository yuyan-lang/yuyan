# 开媒影匣点审改表（1-10 第五批，24 处，2026-11-08 复核）

开媒影是图像解码。解码在页面所需的那条任务里做（网络取回后交同循环）；图解匣由解码任务独占，不与另一任务并发读写。

**合计**：派生前写定 0 处，单任务独用 24 处，加锁 0 处，原子匣 0 处，每实例一份 0 处。代码 0 处改动。

**2026-11-10 复核（1-10 余项第五批，均输一十，只定案不改码）**：结论“单任务独用”照旧，依据改写如下。一、派生普查加按模块解析的调用图：网页部（连急就、篇象、网页榫卯、装帧、装帧谱、接引等子包）与开媒影共 577 个顶层可变格，从全仓二十三篇派生处的任务根出发一个也够不到。二、这一族里真派生任务的只有浏览器的异步载入（「浏览器开取」解不出址时遣一个立即失败的任务）与接引静态载的预取（「预取一批」每项遣一个任务调传进来的读取器）；预取任务调的是函数值参数「读资」，调用图跟不到它的实现，所以这一条不能单靠调用图。三、真正的保证是：浏览器与桌面所在的实例没有标多核（1-11 只标了译场主与将作运行），差遣按单核跑，预取任务与主流程协作交错，读写这些格的一步之内不让出。边界：浏览器实例要标多核（或全局开关 豫言多核差遣=开 跑差分）之前，这一族要按任务重核，先看预取经读资碰到的缓存（接引的缓存、浏览久存）与页面状态格（参照策、笔谈、违规境等），再看异步载入的阶段格。
