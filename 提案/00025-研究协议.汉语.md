## 一、任务

豫言是一种以文言为关键词的编程语言。请为它设计一套文学性最高的关键词与常用核心名称，并用证据说明它为什么最好。

“最好”指：在第四节的最低约束之内，按第七节评分表得分最高。若两种方向各有所长（如简劲与铺陈），分别给出各自的最优方案，并说明取舍。

## 二、背景

### 豫言是什么样的语言

- 函数式语言：值不可变，没有循环与赋值，重复靠递归。程序由一条条声明组成：导入、类型签名、定义。表达式可以任意嵌套。
- 名字（变量、函数、类型、模块）一律写在「」里，如「平方和」；字符串写在『』里；关键词裸写；声明以句号结束。名字由程序员任取，常是现代汉语词。
- 代码注释用汉语与文言两种文字对照书写。

### 待验证的观察（来自提案 00025）

以下是初步品评的结论，请当作假设检验，可证实也可推翻：

1. 豫言的长处：`「名」者……也` 是判断句正体；`乃`、`即` 作系词得体；`寻观……之书`、`鉴`、`或有` 雅；`阳`、`阴`、`爻`、`元`、`罄`、`缀`、`可有`、`可无` 意象好。
2. 豫言的短处：虚词多作分隔符而不按文言本义（`于……于……`、行末悬“而”、`化 甲 而 乙` 缺“为”、`类型 也 值` 判断次序颠倒、`授以` 施受倒置、`中零`）；没有句读与节奏；符号多；“递归”“打印”“事故”等今语混入；没有统一的文体与口吻；少情味；数字逐位；结构关键词几乎都是仄声。
3. 可取的文体线索：“豫”是《易》第十六卦之名，“鉴”是史书之名，《豫言赋》已用赋体。

## 四、最低约束

只有这四条；其余一切（关键词的字数、是否用叹词、是否保留现有写法）都由文学性决定。

1. **意思齐全。** 第三节每个意思都有写法，各写法可以任意嵌套组合。
2. **读法唯一。** 一段源码只能有一种读法；关键词与名字、字符串、数字可区分。可以保留「」『』，也可以提出更雅的区分法，但要说明为什么仍然只有一种读法。
3. **名字自由。** 名字由程序员任取，多为现代汉语词；设计不能指望名字本身合文言。
4. **简体为准。** 以简体字书写；可另评繁体或竖排作为显示方式。

## 五、文学性的客观描述

以下各维度都给出记谱法与可计算的度量，像乐理描述音乐那样描述文言。

### 记谱法

- 一字一拍。「」中的名字照字计拍与声调；『』中的字符串内容不计，记作一个停顿。
- 声调记号：`○` 平声，`●` 仄声（上、去、入），`◐` 可平可仄或两读（须注明依据）。
- 音步界 `｜`，句读界 `‖`。

例一，wenyan-lang：

```
吾有｜一數‖曰三‖名之｜曰「甲」‖書之
○●｜●●‖●○‖○○｜●●‖○○
```

全是二字一步，读长四、二、四、二，句尾平仄相间。

例二，《论语·学而》：

```
学而｜时习之‖不亦｜说乎
●○｜○●○‖●●｜●○
```

两读都以平声语气词收束。

例三，杜甫《春望》：

```
国破｜山河｜在‖城春｜草木｜深
●●｜○○｜●‖○○｜●●｜○
```

上下句第二、四字平仄相反（破／春，河／木），出句仄收，对句平收押韵。

例四，豫言今制（基准程序 B2 的第二、三行，到句号前没有句读）：

```
「平方和」者｜会「甲」而｜会「乙」而｜虑「甲方」者｜「乘」于「甲」于「甲」而……
○○○●｜●●○｜●●○｜●●○●｜○○●○●○……
```

### 维度一：声调（声）

- **调类。** 以中古四声为准：平、上、去、入；上、去、入合称仄。查字依《广韵》或平水韵，现代普通话只作参考（入声已派入他调，须按中古归仄）。多音字按所取之义定调，并注明。
- **调性的传统描述。** 旧说“平声哀而安，上声厉而举，去声清而远，入声直而促”（相传出唐《元和韵谱》）。可作乐理式的类比：平声舒长、可延，似长音；仄声有起伏或顿挫，入声以塞音收尾、最短，似断奏。
- **交替律。** 以二字音步为单位，相邻音步的第二字平仄相反，听来有起伏（近体诗所谓“二四六分明”）。同句连续三字同声（三平、三仄）显得板滞。
- **对与粘。** 成对的两句，对应位置的音步末字平仄相反（对）；成串的句子，后一组的首句与前一组的末句在第二字上同声（粘）。可用于成对的关键词与成对的分支。
- **收束。** 一读的末字决定余音：平声收舒展、可延；仄声收顿挫，入声收最促。
- **度量：**
  - 交替率：相邻音步末字平仄不同的比例；
  - 平收率：以平声字结束的读所占比例；
  - 平声比：平声字占全部字的比例；
  - 违律数：三平、三仄连用的次数。

### 维度二：节奏（拍）

- **音步。** 汉语的标准韵律词是二音节；三音节为超音步（一加二或二加一）；单字不足一步，须靠停顿或拖长补足（参冯胜利《汉语韵律句法学》）。
- **读长。** 古文的读多为三至七字；骈文、赋以四字、六字相间（“四六”）；诗句五言多为二加三、七言为四加三。
- **语气词即休止与终止。** 句末的也、矣、焉、哉、乎、欤、耳形成休止并定下语调：也似陈述的终止，矣表完成，乎、欤为开放的问句，哉为感叹。句中的之、而、以、于是连接，不宜居读末。
- **度量：**
  - 读长分布：每读字数的分布，三至七字所占比例，四、六字所占比例；
  - 音步完整率：能分成二字步（允许一个三字超音步）的读所占比例；
  - 单字读比例：有意的顿笔（如“曰”“噫”）除外；
  - 长读比例：超过九字的读所占比例。

### 维度三：文法（句法合度）

- 每个虚词按文言本义、在本来的位置使用。主要虚词的规范用法（以王力《古代汉语》、杨伯峻《古汉语虚词》为准）：

| 字 | 本义与位置 |
| --- | --- |
| 之 | 领属（甲之乙）；代词（它）；宾语提前的标记；往 |
| 者 | 提顿、名词化（……者，……也；……的人或事） |
| 也 | 判断、提顿、肯定语气；居句末或提顿处 |
| 矣 | 已然、变化完成 |
| 焉 | 于此；句末语气 |
| 乎、欤、耶、哉 | 疑问、反诘、感叹 |
| 而 | 连接两个谓词（顺承、转折），居其间，不居句末 |
| 以 | 用、凭、因；“以……为……”（把……当作……） |
| 于 | 在、向、对、比、被 |
| 为 | 是、作为、成为；替；“为……所……” |
| 则 | 就、那么；条件的后果 |
| 乃 | 于是、才；是（系词） |
| 即 | 就是、便 |
| 其 | 他的、那；大概、岂 |
| 所 | 名词化（所……者） |
| 若、如、苟 | 如果 |
| 或 | 有人、或许、或者；“或……或……”列举 |
| 且 | 并且、将、尚且 |
| 夫 | 发语词；那 |
| 曰 | 说；叫作 |

- 可借用的成熟句式：判断（……者，……也；……乃……也）、命名（名之曰……、谓之……）、定义（所谓……者，……也；……之谓也）、条件（若……则……；苟……则……）、列举（或……或……；其一……其二……；有……有……）、过程（先……后……；既……乃……；……然后……）、引述（……曰：……）、使令与处置（使……；以……为……）、感叹（呜呼、嗟夫、噫）、疑问（……乎、……欤、何……）。
- **度量：** 基准程序逐读判定是否为通顺的文言，并注明所属句式；不通顺的读计为违例。目标零违例。

### 维度四：用字

- **出处。** 每个关键词给出先秦两汉至唐宋古文中的用例，注明书名与篇名（可用中国哲学书电子化计划 ctext.org 检索）。
- **今古。** 关键词与常用核心名中的近现代术语（递归、字符串、类型、函数、打印、异常、事故等）计为今语；目标零，确需保留的说明理由。
- **意象与色彩。** 写出每个字的常见搭配与情感色彩（如“鉴”有明镜、借鉴之意，“罄”有竭尽之意），检查是否与所表达的意思相合。
- **字形。** 笔画与结构在版面上的疏密；繁简两体的观感。
- **度量：** 有可靠出处的关键词比例；今语数；可选：用字在古籍语料中的频次。

### 维度五：对仗与呼应

- 成对出现的关键词（开与合、问与答、若与则、有与无、阴与阳、寻与观）宜词性相对、平仄相反、意义相反或相关。
- 一段的起首词与收束词首尾呼应（如 wenyan“欲行是術……是謂……之術也”）。
- **度量：** 每对关键词按词性、平仄、意义三项各记一分。

### 维度六：文体与口吻

- **文体。** 各类文献各有程式：
  - 算书：今有……问……几何？答曰……术曰……（《九章算术》）；
  - 史：初，……；是岁，……；太史公曰……；臣光曰……；
  - 易：初九、九二……；彖曰、象曰；吉、凶、悔、吝、无咎；
  - 赋：……兮……；乱曰（《离骚》以“乱曰”作结）；
  - 注疏：注曰、疏曰、按、某某曰；
  - 字书：……，……也（《说文》：从某，某声）；
  - 诸子、公牍、兵书、医书各有其体。
- **口吻。** 第一人称（吾、余）、第三人称叙述、无人称；可谦可敬。
- **统一。** 一套设计宜以一种文体为主，其余为辅，忌拼凑。豫言的现成线索：《易》（豫卦、爻、阴阳、元）、史（鉴）、赋（《豫言赋》）；可用，不限于此。
- **度量：** 全部关键词按出处文体归类，主文体所占比例。

### 维度七：情味

- 叹词与语气：呜呼、噫、嗟夫、惜哉、善哉、岂……欤、何……哉。适合错误、异常、失败、意外等处。
- 雅趣与幽默的分寸：用多了显得轻佻，全无则枯。
- **度量：** 定性。每处带情味的写法给出出处与所用语境。

### 维度八：视觉

- 古籍除句读外几乎没有符号；wenyan-lang 只用「」。
- **度量：** 每百字的非汉字符号数（「」『』（）【】，；：等）。

### 维度九：简与繁

- 文言贵简（“辞达而已矣”，《论语·卫灵公》），赋与骈文尚铺陈；两者都可以美。
- **度量：** 每个意思所用的汉字数，与今制、wenyan-lang 对比。

### 乐理对照

| 文言 | 乐理类比 |
| --- | --- |
| 字 | 音符，一字一拍 |
| 平、仄 | 长音与短音（入声似断奏） |
| 二字音步 | 小节 |
| 句读 | 乐句 |
| 句末语气词 | 终止式：也似完全终止，乎、欤似开放终止 |
| 平仄交替 | 强弱、长短的律动 |
| 对仗 | 对位与模进 |
| 押韵 | 回到主音 |
| 双声叠韵 | 头韵与谐元音 |
| 虚词 | 连接音 |
| 文体 | 曲式与体裁 |
| 叹词 | 表情记号 |

## 六、研究步骤

1. **研读。** 按第五节维度六的各文体取代表作，为第三节每个意思找出古人的现成说法（定义、命名、条件、列举、过程、引述、感叹等），附出处。
2. **列候选。** 每个意思列三至五个候选写法，各注出处、平仄、音步与句式。
3. **打分。** 按第七节评分表逐项打分。
4. **成体。** 选定主文体与口吻，组成完整的关键词与核心名系统；检查成对词的对仗与声律、全体的统一、读法唯一。
5. **试作。** 用第八节全部基准程序改写，每篇附记谱（平仄串、音步与句读）。
6. **评比。** 用同一评分表给今制、wenyan-lang 与新设计打分，计算第五节的全部度量。
7. **自审。** 写出每套方案的弱点与未解决之处。

## 七、评分表

各维度一至五分，乘权重后合计，满分一百。权重可以调整，但须说明理由。

| 维度 | 权重 | 一分 | 三分 | 五分 |
| --- | --- | --- | --- | --- |
| 文法 | 20 | 多处不成文言 | 大体通顺，偶有生造 | 每读都是通顺的文言，句式有据 |
| 文体与口吻 | 15 | 各处来源杂乱 | 有主调而有杂音 | 通篇一种文体、一个声音 |
| 声律 | 15 | 平仄板滞，收束多促 | 有交替，收束平常 | 交替分明，收束舒展有致 |
| 节奏 | 15 | 长读多，音步零乱 | 读长适中，偶有零乱 | 读长匀称，四六相间，音步整齐 |
| 用字 | 10 | 今语多，出处不明 | 少量今语 | 全有出处，无今语，意象相合 |
| 情味 | 10 | 公文腔 | 偶有情致 | 处处有情而不过 |
| 对仗与呼应 | 5 | 成对词不成对 | 部分成对 | 词性、平仄、意义俱对，首尾呼应 |
| 简繁 | 5 | 冗赘或过简以致晦涩 | 适中 | 繁简合度，无一字可删、无一处费解 |
| 视觉 | 5 | 符号满页 | 符号较少 | 近于古籍 |

## 八、基准程序

请把每篇改写成新设计，并与今制、wenyan-lang 写法并列。括号内为所涉意思。

B1 问候（意一、意二、意三、意七、意二十一）：

```

「入口」乃化「有」而「有」也。
「入口」者会「无」而「打印行」于『问天地好在。』也。
```

B2 平方和（意二、意三、意五、意六、意七、意八）：

```
「平方和」乃化「整数」而化「整数」而「整数」也。

　虑「甲方」者「乘」于「甲」于「甲」而

　「加」于「甲方」于「乙方」也。
```

B3 大者（意十）：

```
「大者」乃化「整数」而化「整数」而「整数」也。
「大者」者会「甲」而会「乙」而
　若「大于」于「甲」于「乙」则「甲」否则「乙」也。
```

B4 符号（意十，多路）：

```
「符号」乃化「整数」而「字符串」也。

　若「大于」于「数」于「零」则『正』
　否则若「小于」于「数」于「零」则『负』

B5 求和（意十一、意十四）：

```

「求和」者会「数列」而
　鉴「数列」而

　　或有（「缀」于「首」于「余」）则「加」于「首」于（「求和」于「余」）也。

B6 取值或零（意十一、意二十一）：

```

「取值或零」者会「可选」而
　鉴「可选」而
　　有（「可有」于「数」）则「数」
　　或有「可无」则「零」也。
```

B7 阶乘（意九）：

```
「阶乘」乃化「整数」而「整数」也。
「阶乘」者会「数」而
　递归虑「乘至」其化「整数」而化「整数」而「整数」者
　　会「余」而会「积」而
　　若「等于」于「余」于「零」则「积」否则「乘至」于（「减」于「余」于「一」）于（「乘」于「积」于「余」）

B8 树的叶数（意四、意十一）：

「枝」立化「树」而化「树」而「树」也。
「叶数」乃化「树」而「整数」也。
「叶数」者会「树值」而
　鉴「树值」而
　　有「叶」则「一」
　　或有（「枝」于「左」于「右」）则「加」于（「叶数」于「左」）于（「叶数」于「右」）也。

B9 交换（意十三）：

「倍之」乃化（「列」于「整数」）而（「列」于「整数」）也。

　（「态射」授以「整数」授以「整数」）于「数列」于（会「数」而「乘」于「数」于「二」）也。

B11 安全除（意十、意二十一：抛出与捕获）：

```

「安全除」者会「甲」而会「乙」而
　「尝试运行」授以「整数」
　　于（会「无」而
　　　若「等于」于「乙」于「零」则「发生事故」授以「整数」于『除数为零』否则「除以」于「甲」于「乙」）
