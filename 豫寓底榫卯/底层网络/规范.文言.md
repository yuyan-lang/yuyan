# 豫言操作系统底层网络〇点二点〇

状：草案，可选之能。汉语本见[汉语版](规范.汉语.md)。通用之规，见[调用约定](../调用约定.文言.md)；状态之码表，见[底层基础](../底层基础/规范.文言.md)；数据之收发与等待，见[底层句柄](../底层句柄/规范.文言.md)。

## 范围

TCP 之监听、连接与接受，UDP 数据报之建、连、发、收，及取套接字本端与对端之址。TCP 数据之收发、等待、关闭，皆用底层句柄之 `读`、`写`、`等待`、`关闭`；数据报以本包之 `投书`、`得书` 收发之，等待与关闭亦用底层句柄之函数。套接字乃柄（类别 6）。平台无网络，则本包诸函数皆返 58。TLS、域名解析之接口与套接字之选项（唯 `设勿滞` 除外）不在本包；HTTP 与 TLS，由垫层于 TCP 之上以豫言为之。

## 流程

**服务端。** `开门` 得监听之柄；以 `等待`（可读）知有待接之连；`迎` 得连接之柄。

**客户端。** `叩门` 立返一非阻塞之连接柄（域名解析或于其间阻塞，首版容之）；以 `等待`（可写）候其连成；`入门` 取其果：状态之码零，谓已连；否则为败之因（14 连被拒、73 超时、……）。

**收发。** 连接之柄用 `读`、`写`：读得零，谓对端有序而闭；对端重置则返 15；书于已闭之连接则返 64。`缄口` 唯闭写之向，对端读至文件尾，本端仍可读。`关闭` 释其柄。

新所接之连接柄，默认阻塞；须非阻塞者，以 `设非阻塞` 置之。

**数据报（〇点二点〇）。** `置雁` 建一系于（主机，端口）之 UDP 柄（主机为空串谓任意之址，端口零则平台择之）；`投书` 以一报全发于（主机，端口）；`得书` 收一报，并得其源之址。`连雁` 为柄设对端：此后 `投书` 主机长为零者发于对端，`得书` 唯收对端之报。以 `等待`（可读）候报之至。新建之数据报柄默认阻塞，无报则 `得书` 候至有之；须非阻塞者，以 `设非阻塞` 置之，是时无报则返 6。

## 函数（`网络。底层接口。豫`）

| 函数 | 参 | 用 |
| --- | --- | --- |
| 监听 | 主机址, 主机长, 端口, 队列长, 出 | 于（主机，端口）监听；主机为空串谓任意之址；解析不得则返 44；监听之柄四字节书于出址；址已用则返 3 |
| 连接开始 | 主机址, 主机长, 端口, 出 | 始连，非阻塞；主机可为名或数字之址；解析不得则返 44；柄四字节书于出址 |
| 连接完成 | 句柄 | 取连接之果，状态之码即其果；连尚未成则返 6 |
| 接受 | 监听句柄, 出 | 新连接之柄四字节书于出址；非阻塞而无待接之连则返 6 |
| 关闭写 | 句柄 | 半闭 |
| 取本地端口 | 句柄, 出 | 本地端口，四字节（监听而端口为零者，以此取其实端口） |
| 设无延迟 | 句柄, 开关 | 开关 1 置无延迟（闭 Nagle），0 除之 |
| 建数据报 | 主机址, 主机长, 端口, 出 | 建 UDP 柄而系于（主机，端口）；柄四字节书于出址；址已用则返 3 |
| 连数据报 | 句柄, 主机址, 主机长, 端口 | 设对端；主机可为名或数字之址；不得其解则返 44 |
| 发数据报 | 句柄, 缓冲址, 缓冲长, 主机址, 主机长, 端口 | 以缓冲为一报发于（主机，端口）；主机长为零则发于对端，未设对端返 53；报过长返 28 |
| 收数据报 | 句柄, 缓冲址, 缓冲长, 来源址, 出 | 收一报：报长于缓冲则弃其余；所收之字数四字节书于出址；来源址非零则书其源为址块（见下）；非阻塞而无报则返 6 |
| 取套接字地址 | 句柄, 对端, 出 | 对端为零取本端之址、为一取对端之址，书为址块；流套接字与数据报套接字皆可用；无对端返 53 |

后增之函数（〇点二点〇）列于扩展之号，服务之号见调用约定“服务号与转送”：建数据报百六十五，连数据报百六十六，发数据报百六十七，收数据报百六十八，取套接字地址百六十九。

## 址块

二十四字节，小端：

| 偏移 | 宽 | 字段 |
| --- | --- | --- |
| 0 | 4 | 址族：4 为 IPv4，6 为 IPv6 |
| 4 | 4 | 端口 |
| 8 | 16 | 址，网络字节之序（IPv4 用前四字节，余为零） |

## 平台之注

- 桌面：BSD 套接字（Linux、macOS）与 ws2_32（Windows）；IPv4 与 IPv6，平台裁之；`开门` 与 `置雁` 之主机串为空，则监听双栈或任意之址。数据报之四函与 `问主址`，于 Linux、macOS 用 `bind`、`connect`、`sendto`、`recvfrom`、`getsockname`、`getpeername`；于 Windows 留待后版，今返 58。
- 裸机：网络栈在初始任务之执行器中（以太网、ARP、IPv4、IPv6、ICMPv6、邻之发现、UDP、TCP、环回）。子任务之呼经底层转送由初始任务办之（见调用约定“服务号与转送”）；初始任务不阻，套接字与数据报之柄皆以非阻塞办之，无数据则返 6，子任务以 `等待` 候其就绪。主机之名，依数字之址（点分十进或六版字面，字面可加方括）、`localhost` 与问域名之服而解之；解域名以启连者，既配全局六版之址则先问 AAAA、先试六版，不成乃回落四版（RFC 8305 之最简）。六版之链址依以太址以 EUI-64 生之，全局之址与缺省之路取路由之通告，重址之检惟一次；开机发路由之请一次即行，通告至则于轮询中配其址，未至则每三秒补发、至多五次，不碍开机；`::1` 由环回。
- 与标准库今有之传输控制协议原语（十四，`豫言_传输控制协议_*`），皆可由本包加底层句柄行之：监听、开始连接、完成连接、接受、读取、写入、等待、获取本地端口、设置无延迟、关闭写入、关闭。标准库之数据报交换（原语百七十六），以 `置雁`、`连雁`、`投书`、`等待`、`得书` 与 `关闭` 行之。
