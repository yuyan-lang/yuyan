# 安全外壳公钥文本验证

以已知 Ed25519 零私种及独立所造 OpenSSH 公钥文，验所得 SSH 钥载物与三十二字节公钥皆合。兼验可选注、CRLF，非法 Base64 字、第二行、尾填号、前置选项及断文皆拒。已知主机之验，涵逐字主机、异端口、逗号别名、OpenSSH `ssh-keygen -H` 所造隐名、误名误钥，及 `@revoked` 无论先后皆拒；通配、否名不授信。`authorized_keys` 惟纳可行其限之部分选项。

授权文之验，涵多行二异 Ed25519 钥、注行、他算法行、`no-pty` 与 `restrict` 禁 PTY、同钥多行取严者及未知选项拒授；兼验自署签报与未签探问取候选钥时仍系用户与服务。
