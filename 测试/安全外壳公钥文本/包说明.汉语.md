# 安全外壳公钥文本验证

用已知 Ed25519 零种子与独立生成的 OpenSSH 公钥文本，验证解码后的 SSH key blob 和 32 字节公钥完全匹配。还验证可选注释、CRLF，以及对非法 Base64 字符、第二行、尾随填充符、前置选项和截断文本的拒绝。已知主机验证覆盖精确主机名、非标准端口、逗号别名、OpenSSH `ssh-keygen -H` 生成的哈希主机名、错误主机名与密钥，以及 `@revoked` 的顺序无关否决；通配和否定模式不授信。`authorized_keys` 仅支持可执行约束的部分选项。

授权文件测试覆盖多行中的两把不同 Ed25519 密钥、注释、其他算法、`no-pty` 与 `restrict` 禁止 PTY、同钥多行取较严约束及未知选项拒绝，并验证从签名请求和未签名试探中提取候选密钥时仍绑定用户名与服务。
