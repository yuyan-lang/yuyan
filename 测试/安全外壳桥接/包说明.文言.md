# 安全外壳桥接验证

无 PTY 标准流之验，起真 `/bin/sh`，别取 stdout 之 `OUT` 与 stderr 之 `ERR`，核二者各封常数据、扩展数据，且同耗彼窗，自十减至四；继别验二出 EOF 及子进程退。另以真 `/bin/cat` 验 stdin 待写冲刷之实写数、余尾，及原字封通道数据。

微窗之验，子进程吐 `ABC`；彼窗二字先送 `AB`，窗尽不读，增窗后复送 `C`。

以原生 PTY 验 SSH channel 数据入端转交、出端依窗裁读及窗尽暂停。模拟写败，验待写原字俱留；又置从端原始模式，使满缓冲而候可写逾时，验已写数与余尾长度之和恰为原文长度。以主从端各验多路等待之可读、可写、单路关注及非法关注位；加密缓冲试半报不进 IV，二报相连则逐报解之而存余字。另启 `/usr/bin/tty`，验其控制终端之出经 PTY 封为可析之 CHANNEL_DATA。验证不赖网络连接或后台服务者。

会话传输控制分类之验，核合法 `IGNORE`、`UNIMPLEMENTED`、`DEBUG`、`DISCONNECT`；尾有余字之坏报与空载物皆拒，常通道报则交通道术。
