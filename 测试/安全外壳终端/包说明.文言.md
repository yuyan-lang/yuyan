# 安全外壳终端验证

标准流之验，以真 `/bin/cat` 核 stdin 至 stdout 原字与 EOF，以 `/bin/sh` 核 stderr 与 stdout 分流，复以 `/usr/bin/true` 核子进程退后向闭入再写惟返误，不触 SIGPIPE。又以 `/bin/sleep` 验 TERM、信号退及重收拒绝，并核绝对径之限。

开原生伪终端，设而读字符及像素尺寸，自从端传原字节至主端，验非阻塞空读、候可写与越界尺寸。又置原始模式，验无换行之字得径达从端；独禁回显，验规范行之文仍达从端而主端不回之。继启 `/usr/bin/tty`，验子进程得控制终端且已回收；复启 `/bin/sleep`，验进程组终止、信号退出及重收拒绝。相对径程序不得启。惟施于原生 macOS/Linux。
