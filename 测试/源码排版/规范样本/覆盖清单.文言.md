# 规范排版覆盖之籍

文言：所试者记其据，未试者记其阙。汉语：这里列出 canonical formatter 样本的覆盖范围和剩余边界。

## 已试之类

| 类 | 文言 | 现代汉语 |
| --- | --- | --- |
| 篇章 | 空篇、独注篇、寻观诵诸合、长导入、型别名、构造器成组。 | 覆盖文件边界、导入与再导出、模块路径、类型别名和构造器分组。 |
| 类型 | 乃化、其化、承受、授以、〇也〇、列类、函数类及复合类相交。 | 覆盖泛型声明、类型判断、显式类型参数、列表、函数和复合类型。 |
| 函数 | 会相累，虑相续，递归虑相叠，长名与长参并见。 | 覆盖多层匿名函数、连续与递归局部绑定、超长名称。 |
| 条件与匹配 | 若入若，鉴入若，若入鉴；真否诸支各有所属。 | 覆盖交错嵌套的条件与模式匹配。 |
| 调用与集合 | 多参异形，列项繁复，末亦可逗；对子可析，亦见中、附、与、分号。 | 覆盖复杂调用、尾逗号、对子解构、列表、索引、连接和顺序表达式。 |
| 注串 | 注可重入，串可跨行，字可异宽，其内皆不动。 | 覆盖嵌套注释、多行字符串、长原子与 Unicode。 |
| 宿主与规模 | 宿主之调用、列映及逾二百行之合篇皆在。 | 覆盖原生调用与完整模块规模样本。 |

## 验法

文言：目录自读，无须手籍诸篇名。定本自排须仍定本；运行时另造零格、七格缩进之本，无注者复造断行之本。先验同词可析，再排而逐字比定本。诸异本不落盘。汉语：测试自动扫描标准目录，运行时生成空白扰动，核对词法和解析，再检查逐字节归一。

文言：三十五定本皆经类型之验。败文四例，皆为旧器所拒；异行尾之验，旧器尚败。汉语：35 个标准文件通过类型检查；四种非法输入被拒绝，CRLF 归一化目标目前失败。

## 未竟之端

文言：群篇写回之全否；字节序标及异行宽；巨篇巨串之时空；有注之篇新增断行而不移所附。此四端须别为验，不可以定本代之。汉语：仍需单独测试批量写回、BOM 与多行宽、性能极限，以及带注释源码的等价断行生成；非法输入和 CRLF 已有测试。
