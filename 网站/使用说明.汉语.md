# 官网与共用界面

主站由 Jekyll 构建，接口文档与源码浏览器由豫言生成器构建。共用资源唯一来源为 `网站/共用/`：`主题.css`、`界面.js`、`示例.mjs`。试写间和包管理站在检查配置、开发或部署前执行 `npm run 准备界面`，将资源复制到各自静态目录；这些副本不提交。

导航的「豫言」链接到主站，站点名称链接到各自首页。默认汉语，顶部可切换文言。URL 的 `lang=han|wen` 优先，其次是 `yuyan_lang` cookie，最后为汉语。线上 cookie 使用 `Domain=yuyan-lang.org; Path=/; Secure; SameSite=Lax`，因此子域共享偏好；本地预览使用当前主机 cookie。偏好只有语言值，不含身份信息。移动端导航可展开，切换按钮反映当前状态。

主站内容使用 `data-han` / `data-wen` 对应文案。已存在双语原文的教程与指南切换到同一篇的另一版本；代码、类型签名、源码注释和原始日志保持原文。原文区用 `data-原文` 标注，自动翻译只匹配可信界面词典；缺少译文的内容保留原文，不伪造译本。

`工具/网站资料生成。豫` 从文档生成教程与指南页面，正文不另行维护。运行：

```sh
./yy_bs_stable 工具/网站资料生成。豫 -o /tmp/yy网站资料
/tmp/yy网站资料
mkdir -p 网站/教程/示例
cp 文档/豫言赋/示例/* 网站/教程/示例/
jekyll build --source 网站 --destination /tmp/yy网站预览
```

共用界面测试：执行 `npm ci --prefix 网站 && npm test --prefix 网站`；临时依赖可通过 `YY_DOM_MODULE` 指定模块入口。测试覆盖默认语言、切换回原文、跨子域 cookie、动态状态和原始日志保护。首页三例须实际编译运行。发布继续使用 `.github/workflows/部署官方网站.yml`，先生成双语正文，再生成接口文档和源码树。

包管理首页只在浏览器请求 HTML 时呈现；根路径的 JSON 请求、`/health`、下载和发布接口仍按原协议工作。首页不宣称提供尚未实现的包搜索或上传表单。

主域名由 `入口/云桥.mjs` 固定代理 GitHub Pages 的 `/yuyan/` 产物，使用 Cloudflare Custom Domain 管理 DNS 与 HTTPS。GitHub Pages 保留原地址，不配置 CNAME，以免上游跳回主域形成循环。入口不转发 cookie、Authorization 或任意上游；仅接受 GET/HEAD。构建与发布仍由 GitHub Actions 完成。
