# 官网与共用界面

主站以 Jekyll 构之，接口与源码之页以豫言成之。诸站共用之材，惟取 `网站/共用/`，试写间与包府于构建前复制，不另藏副稿。

「豫言」返主站，站名返本站。初用汉语，亦可易为文言。网址 `lang` 先于 cookie，cookie 先于默认；线上以主域之 cookie 通诸子域，惟记语言，不记身份。行于小屏，目录可开阖。

两辞之文以 `data-han`、`data-wen` 相应。学篇与指南有两本者，易辞仍在同篇。源码、类型签名、原注与原录皆存其本，不以辞典妄改。未译者示其原文，不伪称文言之本。

《网站资料生成。豫》取既有文档而成网页，正文不两处维护。构建与验证之令见汉语篇；须验语言初值、诸域共好、异步状态与原文不易，且实编首页诸例而验其所出。

包府首页惟供浏览器观之；旧 JSON、健康检查、取包与发布之接口皆仍通。未设搜索与上传之表，则不称其有。

主域之门以 Cloudflare 接之，所往恒为 GitHub Pages 之 `/yuyan/`，不改旧构建。Pages 不置 CNAME，免往复成环。惟受 GET、HEAD，不传客之 cookie 与认证之符。

## 此次之验

二零二六年九月六日，Jekyll 构建、站内链接、首页三例实编实行、共用界面三试、包府九试、生成器编译与编译器串行类型检查皆成。浏览器复验大小屏、同篇易辞、诸域共好、示例往来与原录不易。

试写间旧有目录覆盖之试，因同步 yybs 后官书添模块，而云器与签名册仍为旧版，故不相齐。此改惟及界面，未易云器及其签名册；余十八试皆成。
