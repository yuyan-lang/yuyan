# 官网与共用界面

主站以 Jekyll 构之，接口与源码之页以豫言成之。诸站共用之材，惟取 `网站/共用/`，试写间与包府于构建前复制，不另藏副稿。

「豫言」返主站，站名返本站。初用汉语，亦可易为文言。网址 `lang` 先于 cookie，cookie 先于默认；线上以主域之 cookie 通诸子域，惟记语言，不记身份。行于小屏，目录可开阖。

两辞之文以 `data-han`、`data-wen` 相应。学篇与指南有两本者，易辞仍在同篇。源码、类型签名、原注与原录皆存其本，不以辞典妄改。未译者示其原文，不伪称文言之本。

《网站资料生成。豫》取既有文档而成网页，正文不两处维护。构建与验证之令见汉语篇；须验语言初值、诸域共好、异步状态与原文不易，且实编首页诸例而验其所出。

包府首页惟供浏览器观之；旧 JSON、健康检查、取包与发布之接口皆仍通。未设搜索与上传之表，则不称其有。

主域今以 Cloudflare Workers Static Assets 直供 `dist/网站` 诸页，不复转求 GitHub Pages。配置无代理之术，仍系旧域；`.html` 之径不改，目录之首以 `_redirects` 通之，响应之头以 `_headers` 定之。网站不以 GitHub Actions 构建或发布，亦无需仓库发布密钥。

## 此次之验

二零二六年九月六日，Jekyll 构建、站内链接、首页三例实编实行、共用界面三试、包府九试、生成器编译与编译器串行类型检查皆成。浏览器复验大小屏、同篇易辞、诸域共好、示例往来与原录不易。

试写间旧有目录覆盖之试，因同步 yybs 后官书添模块，而云器与签名册仍为旧版，故不相齐。此改惟及界面，未易云器及其签名册；余十八试皆成。

## 文档之名与旧径

文档之名，以 `.汉语.md` 或 `.文言.md` 终；同篇两辞，共其中文本名。《豫言赋》不复用 `.现代汉语.md`，文言亦明署其辞。`AGENTS.md` 为工具所识，故存旧名；`yuyan-vscode` 与 `*_v0` 依仓库旧例。网站之试兼验已录与新置之文，毋使旧名复入。

生成器取新名之本，联同篇两辞，存旧网页之径而导之新址。重建之前，先清 `网站/教程/`、`网站/指南/` 之旧副本；此二处不藏手写正文。编译流程与相等性检查旧记，皆明其为往昔之说；今制以规范与实现为准。

## 手动构建与发布

先备稳定编译器、Node.js、make、clang 与 Jekyll 诸依赖，详见汉语篇。在仓库之根，以 `./yy豫构_stable 构建 网站发布 --编译器 ./yy_bs_stable --输出 yy网站发布` 成其器。

行 `./yy网站发布 构建`，则验界面、造生成器、清旧副本而成全站；行 `./yy网站发布 检查`，则验所成。观其页而后行 `./yy网站发布 发布`，始传于 Cloudflare。无参数则示用法；一事不成即止。构建时勿并行他编。

初用以 `npx --yes wrangler@4.129.0 login` 登录，此后用本机所存之凭据；亦可于本地环境置令牌，不入源码。发布惟传既有产物，不复构建；源码有改，须先重构。推送分支不发布网站。
