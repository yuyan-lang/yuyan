# 设备接口 0.1.0

这是宿主列出硬件设备及其驱动的接口。`问器` 返回 `设备已列` 携带设备列表，或 `设备未得` 携带系统错误。豫言操作系统（裸机）列出开机时登记的全部外设互连（PCI）功能与 USB 设备，数据由内核设备表经服务 65、66 取得；没有硬件设备可列的宿主（浏览器、诺驿、macOS 与 Linux 原生）返回 `资源暂不可用`。

`设备信息值` 依次保存：

1. 总线：1 为外设互连，2 为通用串行（USB）。
2. 位置：外设互连为配码，即总线左移 16、设备左移 11、功能左移 8 之和；通用串行的编法见豫言内核包说明。
3. 厂商号、产品号：各 16 位。
4. 类码：外设互连为 24 位类码（基类、子类、编程接口）；通用串行为类、子类、协议各 8 位。
5. 驱动号：0 为没有驱动认领；其余编号见持续改进目标《开放硬件驱动》的编号分段。
6. 状态：0 无驱动，1 已驱动，2 驱动初置失败。

壳命令「器列」用本接口印出设备表；桌面的设备管理器每两秒查一次本接口，显示同一张表。

## 网卡（2026-10-13）

`问网卡` 返回 `网卡已列` 携带网卡列表与网络地址设定，或 `网卡未得` 携带系统错误。豫言操作系统（裸机）的网卡数据由内核网卡表经服务 75 逐块取得，地址设定取自初始任务里执行器网络栈的状态，子任务（桌面终端与远程登录的壳会话等）经执行器向初始任务要（2026-10-14）；查询时网卡刚就绪，网络栈先做一次 DHCP 取址。没有网卡可列的宿主（浏览器、诺驿、macOS 与 Linux 原生）返回 `资源暂不可用`。

`网卡信息值` 依次保存：驱动号（10 虚拟网卡、11 英特尔千兆等，编号见《开放硬件驱动》；0 为驱动客体交来的网卡）、链路（1 通、0 断）、以太地址（低 48 位，第一个字节在最低位）、收帧数、发帧数、发失败数、是否在用（1 为网络栈正在用的那块）。

`网络地址值` 依次保存：取址状态（0 网卡未就绪、1 DHCP 取得、2 DHCP 未成而用 QEMU 用户网络的默认值、3 正在取、−1 本任务看不到网络栈）、本机地址、掩码、网关、域名服务器。地址是 IPv4 的 32 位整数，第一段在最高字节。

壳命令「网络态」用本接口印出各网卡与地址设定。

## 声卡（2026-10-13）

`问声卡` 返回 `声卡已得` 携带系统所用声卡（声音输出接口打开的就是它）的 `声卡信息值`，或 `声卡未得` 携带系统错误：豫言操作系统没有声卡时返回 `资源不存在`，数据由内核声卡表经服务 84 取得；浏览器、诺驿、macOS 与 Linux 原生返回 `资源暂不可用`。`声卡信息值` 依次保存驱动号、位置（外设互连配码）、厂商号、产品号、编解码器（高清音频为编解码器的厂商号左移 16 加设备号，没有为 0）、输出端口（高清音频为输出引脚的节点号，没有为 −1）、输出通道（高清音频为数模转换器的节点号，虚拟声卡为输出流号）、端口类别（引脚默认配置里的设备类别：0 线路输出、1 扬声器、2 耳机等，没有为 −1）、当前流号（0 为没有开着的流）、采样率、声道数、已播帧数（当前流开流以来设备放完的帧数）与已写帧数。USB 声卡（驱动号 33）的位置是通用串行的位置码（根端口号左移 20 加路由串，同设备表），厂商号、产品号取 USB 设备的；编解码器放 USB 音频类版本（1 或 2），输出端口放输出终端号，输出通道放音频流接口号左移 8 加备用设置，端口类别按输出终端的类型换成上面的设备类别（没有对应的为 −1）。壳命令「声器」用它印出声卡的情况。

## 电源（2026-10-13）

`息` 与 `更始` 请求宿主关闭或重启这台机器，返回 `息果`（`关机已发`、`关机失败` 携带系统错误）与 `更始果`（`重启已发`、`重启失败` 携带系统错误）。豫言操作系统（裸机）的内核只做硬件动作：AMD64 读 ACPI 表，关机写 PM1 控制寄存器的休眠类型与 SLP_EN（休眠类型取自 DSDT 里的 `_S5_`），重启依次用 FADT 的重置寄存器、端口 0xCF9 与键盘控制器；ARM64 经 PSCI 的 SYSTEM_OFF、SYSTEM_RESET。成功时机器断电或复位而不再返回，所以实际能返回的只有失败，这台机器做不到时返回 `资源暂不可用`；`关机已发`、`重启已发` 留给内核万一返回非负值的情形。用户数据（如文件系统）由调用者先刷盘，内核不替它刷。没有硬件可控的宿主（浏览器、诺驿、macOS 与 Linux 原生）返回 `资源暂不可用`，不真的关本机。壳命令「息」「更始」用它们。

## 屏幕与输入（2026-10-17）

`观屏` 读回屏幕上现在显示的整幅画面，返回 `屏照已得` 携带宽、高（像素）与像素字节串，或 `屏照未得` 携带系统错误。像素紧排为 RGBA，每像素 4 字节、透明度 255，自上而下逐行，长为宽×高×4。豫言操作系统（裸机）经内核服务 103（读帧）直接读帧缓冲，开机壳的控制台文字与桌面提交的画面（连指针）都在其中；没有帧缓冲时返回 `资源暂不可用`，读的过程中屏幕尺寸变了返回 `资源已失效`。浏览器、诺驿、macOS 与 Linux 原生返回 `资源暂不可用`。壳命令「截屏」用它，把画面编成 PNG 写进文件。

`拟键`、`拟指`、`拟钮` 合成键盘与鼠标事件，返回 `拟成`，或 `拟败` 携带系统错误。豫言操作系统经内核服务 104（拟入）把事件放进真键盘、鼠标事件的同一去处，读输入的程序分不出来：

- `拟键` 依次接收 HID 用法（键码，如 40 回车、4 为字母 a）、按下（非零为按下，零为抬起）与修饰位（HID 修饰字节：位 0 左 Ctrl、1 左 Shift、2 左 Alt、3 左 Win，4–7 为右边的）。桌面开着时事件进按键事件环（与服务 54 读到的同格式）；开机壳的文字模式下按美式键位出字节进控制台输入环。一次出一个事件，按下与抬起各调一次。
- `拟指` 接收屏幕像素的横、纵（夹在 0 至 32767），作为指针的绝对位置交给内核；桌面下一次取指针位置（服务 47）时把指针放到那里，与 VMware 绝对坐标鼠标同一条路。
- `拟钮` 接收键位（低三位：1 左、2 右、4 中，按住的为一）与滚（滚轮格数，向下为正，取低 8 位作有符号数），出一个不带位移的四字节鼠标包放进鼠标环；桌面按它与上一包的键位差出按下、抬起，滚不为零时出滚动事件。

浏览器、诺驿、macOS 与 Linux 原生返回 `资源暂不可用`。壳命令「击键」「移指」「点击」「滚轮」用它们：经 ssh 在豫言操作系统里下这些命令，再用「截屏」与 scp 取回画面，就能远程调试实机界面。读屏与合成输入的权限控制留待后续版本。

## 内核日志（2026-10-17）

`观起居注` 读回内核开机以来记下的诊断（林纳的 dmesg），返回 `注记已得` 携带字节串（UTF-8 文字，按先后排），或 `注记未得` 携带系统错误。豫言操作系统（裸机）经内核服务 105（读起居注）读内核的 2 MiB 日志环：通用串行与各类驱动（触控板的模式切换、头几帧与头几个鼠标包）、网卡、电源、任务陷阱等内核诊断都在里面，环写满以后最早的被覆盖；环里只收内核自己的诊断。旧内核与豫行启动器返回 `资源暂不可用`；浏览器、诺驿、macOS 与 Linux 原生也返回 `资源暂不可用`。壳命令「起居」用它：实机上控制台的诊断一闪而过，桌面占屏时又被盖住，经 ssh 下这句就能读到。日志每约 10 秒存进数据盘的 /系统/起居注/本次。文本，本次开机第一次存之前先把它改名为 /系统/起居注/上次。文本，死机、强行重启之后读 上次。文本 即得上一次开机的日志。读取权限留待后续版本。
