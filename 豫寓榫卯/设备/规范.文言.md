# 设备接口 0.1.0

此为宿主列硬件设备及其驱动之接口。`问器` 返 `设备已列` 而载设备之列，或 `设备未得` 而载系统错误。豫言操作系统（裸机）列开机所录之诸外设互连（PCI）功能与 USB 设备，其数由核之设备表经服务六十五、六十六得之；无硬件设备可列之宿主（浏览器、诺驿、macOS 与 Linux 原生）返 `资源暂不可用`。

`设备信息值` 依次存：

1. 总线：一为外设互连，二为通用串行（USB）。
2. 位置：外设互连为配码，即线左移十六、设左移十一、功左移八之和；通用串行之编法见豫言内核之包说明。
3. 厂商号、产品号：各十六位。
4. 类码：外设互连为二十四位之类码；通用串行为类、子类、协议各八位。
5. 驱动号：零谓无驱动认之；余号见持续改进目标《开放硬件驱动》之编号分段。
6. 状态：零无驱动，一已驱动，二驱动初置败。

壳命「器列」以此接口印设备之表；桌面之设备管理器每二秒询此接口一次，示同一表。

## 网卡（十月十三日）

`问网卡` 返 `网卡已列` 而载网卡之列与网络之址设，或 `网卡未得` 而载系统错误。豫言操作系统（裸机）之网卡数由核之网卡表经服务七十五逐块得之，址设取诸初任务执行器网络栈之态，子任务（桌面终端与远程登录之壳会话等）经执行器求诸初任务（十月十四日）；问时网卡初备，则网络栈先以 DHCP 取址。无网卡可列之宿主（浏览器、诺驿、macOS 与 Linux 原生）返 `资源暂不可用`。

`网卡信息值` 依次存：驱号（十为虚拟网卡、十一为英特尔千兆等，号见《开放硬件驱动》；零为驱动客体所交之卡）、链路（一通、零断）、以太址（低四十八位，首字居低）、收帧数、发帧数、发败数、在用否（一为网络栈所用者）。

`网络地址值` 依次存：取址之态（零网卡未备、一 DHCP 得之、二 DHCP 未成而用 QEMU 用户网络之默值、三方取、负一本任务不见网络栈）、本机址、掩码、网关、域名服务之址。址为四版网际之三十二位整数，首段居最高字。

壳命「网络态」以此接口印诸网卡与址设。

## 声卡（十月十三日）

`问声卡` 返 `声卡已得` 而载系统所用声卡（声出接口所开者即此）之 `声卡信息值`，或 `声卡未得` 而载系统错误：豫言操作系统无声卡则返 `资源不存在`，其数由核之声卡表经服务八十四得之；浏览器、诺驿、macOS 与 Linux 原生返 `资源暂不可用`。`声卡信息值` 依次存驱动号、位置（外设互连之配码）、厂商号、产品号、编解码器（高清音频为编解码器之厂号左移十六加设备号，无则零）、出口（高清音频为出引脚之节点号，无则负一）、出通道（高清音频为数模转换器之节点号，虚拟声卡为出流号）、口类（引脚默认配置之设备类：零线路出、一扬声器、二耳机等，无则负一）、今流号（零谓无方开之流）、采率、声道之数、已播之帧（今流开流以来设备放毕之帧）与已书之帧。USB 声卡（驱动号三十三）之位置为通用串行之位置码（根端口号左移二十加路由串，同设备表），厂号、品号取 USB 设备者；编解码器位置 USB 音频类之版本（一或二），出口位置输出终端号，出通道位置音频流口号左移八加备用设置，口类依输出终端之类易为上述设备类（无对应者负一）。壳命「声器」以之印声卡之况。

## 电源（十月十三日）

`息` 与 `更始` 请宿主关或重启此机，返 `息果`（`关机已发`、`关机失败` 而载系统错误）与 `更始果`（`重启已发`、`重启失败` 而载系统错误）。豫言操作系统（裸机）之核唯行硬件之事：兼读 ACPI 之表，关机则书 PM1 控制寄存器之休眠类与 SLP_EN（休眠类取诸 DSDT 之 `_S5_`），重启则依次用 FADT 之重置寄存器、端口 0xCF9 与键盘控制器；臂由 PSCI 之 SYSTEM_OFF、SYSTEM_RESET。成则机断电或复位而不复返，故所返者唯败，机不能则返 `资源暂不可用`；`关机已发`、`重启已发` 留于核万一返非负之时。用户之数据（如文件系统）先由呼者刷盘，核不代刷。无硬件可控之宿主（浏览器、诺驿、macOS 与 Linux 原生）返 `资源暂不可用`，不真关本机。壳命「息」「更始」用之。

## 屏与入（十月十七日）

`观屏` 读回屏上今所显之全幅，返 `屏照已得` 而载宽、高（像素）与素之字串，或 `屏照未得` 而载系统错误。素紧排为 RGBA，每素四字、透明二百五十五，自上而下逐行，长为宽高乘四。豫言操作系统（裸机）经核务百零三（读帧）径读帧缓，开机壳控台之字与桌面所交之画（并指针）皆在焉；无帧缓则返 `资源暂不可用`，读时屏尺有易则返 `资源已失效`。浏览器、诺驿、macOS 与 Linux 原生返 `资源暂不可用`。壳命「截屏」用之，编其画为完璧图而书于文。

`拟键`、`拟指`、`拟钮` 合成键鼠之事，返 `拟成`，或 `拟败` 而载系统错误。豫言操作系统经核务百零四（拟入）置其事于真键鼠同归之处，读入之程不能辨：

- `拟键` 依次受 HID 之用（键码，如四十回车、四为字母 a）、按下（非零为按，零为抬）与修饰之位（HID 修饰之字：位零左 Ctrl、一左 Shift、二左 Alt、三左 Win，四至七为右）。桌面开则入按键事环（与务五十四所读同式）；开机壳文字之模则依美式键位出字入控台之环。一呼一事，按与抬各一呼。
- `拟指` 受屏之像素横纵（夹于零至三万二千七百六十七），以为指针之绝对位付核；桌面次取指位（务四十七）则置指于彼，与 VMware 绝对坐标之鼠同途。
- `拟钮` 受键位（低三位：一左、二右、四中，按者为一）与滚（滚轮格数，下为正，取低八位为有号之数），出一无移之四字鼠包入鼠环；桌面依前后键位之差出按与抬，滚非零则出滚动之事。

浏览器、诺驿、macOS 与 Linux 原生返 `资源暂不可用`。壳命「击键」「移指」「点击」「滚轮」用之：经 ssh 于豫言操作系统下此诸命，复以「截屏」与 scp 取回其画，则可远调实机之界面。读屏与合成之权限，俟诸后版。

## 内核之注（十月十七日）

`观起居注` 读回内核开机以来所书之诊（林纳之 dmesg），返 `注记已得` 而载字节之串（UTF-8 之文，依先后），或 `注记未得` 而载系统错误。豫言操作系统（裸机）经核务百零五（读起居注）读内核二兆之注环：通用串行与诸类驱（触控板之切模、始数帧与始数鼠包）、网卡、电源、任务之陷等内核之诊皆在焉，环满则最先者覆；环惟收内核之诊。旧核与豫行之启动器返 `资源暂不可用`；浏览器、诺驿、macOS 与 Linux 原生亦返 `资源暂不可用`。壳命「起居」用之：实机控台之诊一闪即逝，桌面占屏则复掩之，经 ssh 下此句即可读之。注每约十秒存于数据盘之 /系统/起居注/本次。文本，此次初存之前先易其名为 /系统/起居注/上次。文本，死机强启之后读 上次。文本 即得前次开机之注。读之权限留待后续版本。
