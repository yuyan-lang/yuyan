# 蓝牙主机接口规范

此包主 USB 蓝牙控车之机枢报文通道，供协议栈用之。报文以帛载，首字别种：一命、二异步之连、四事；后为报文之身。

- `蓝牙态` 无参。控车在则返有器，携收、发二数；不在则返无器，载资源暂不可用。
- `蓝牙收` 无参，依至之次序取一全报。无报则无报，未接则未接。一报一取，不析不合。
- `蓝牙发` 受帛一封。命经控制之端而出，以完成为成，返零；异步之连经批量之端，返零谓已入发列。未接、种不合或不得出，返负一。
- `蓝牙键报` 受种与报。种一为键盘引导之报，八字节；种二为鼠标引导之报，四字节；交入通用串行键鼠之环，案头与壳不动。成返零，败返负一。

传输之细则依蓝牙核心规范第四卷 B 部（USB 传输）。此包惟主 BR/EDR，低功耗待后续版本。

## 宿主

- **豫言操作系统（裸机）**：核之通用串行蓝牙之驱（`豫言操作系统/裸机/内核/通用串行蓝牙。底层。豫`）接 USB 蓝牙之适，执行器经机枢之口收发报文，并以人机之报交于键鼠之环。
- **林纳、林檎（原生）**：执行器径供其接口，眼下无控车，接宿主之控车俟后版。
- **模拟、网览、云工**：由 `豫言操作系统/适配/蓝牙` 之空榫供之，壳命如常；网览接 Web Bluetooth 俟后版。

未接控车之时，诸宿主之行事相同：态返无器而载暂不可用，收返未接，发与键报皆返负一。壳命「蓝牙态」印“没有蓝牙控制器”，「蓝牙寻」印空器之列，与裸机未接适配器时同。
