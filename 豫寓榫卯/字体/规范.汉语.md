# 字体接口规范 0.1.0

桌面发行可额外提供“文楷”族，使用随发行的同一免费字体文件及许可。节点从程序发行目录读取该单个资源，浏览器由页面授予同名字体；应用仍只按族名取得并分段读取，不依赖资源路径。未附资源的宿主可返回资源不存在，三个标准族名保持原有含义。

macOS独立原生执行器的“文楷”读取可执行文件所在目录的固定 `字体.ttf`，使用只读且不跟随末级符号链接的打开方式；工作目录中的同名文件不能替代它。发行时须同时携带字体许可，应用仍经本包取得资源。

本包让应用按族名取得宿主的字体文件，并按偏移分段读取它的字节。解析、栅格化、文字测量与断行由应用侧的纯豫言字体库完成，所以各宿主画出的文字一致，没有字体引擎的宿主（例如豫言系统）也能照样实现。应用依赖本包即要求宿主实现它。

- **族名**：标准族名为 `无衬线`、`衬线`、`等宽`，宿主须识别。宿主有比例西文的 `无衬线` 字面时优先给出这种字体；有覆盖常用汉字的字体时一并提供 `汉字` 族，缺字的码点由应用回退到它。`等宽` 至少覆盖拉丁字母。其他通用族名包括 `手写`、`装饰`、`圆体`、`数学`、`仿宋`、`符号`、`表情`，宿主有对应字体时提供。常见具体族名由宿主按最相近的字面解析，例如 `Arial`、`Helvetica`、`黑体`、`微软雅黑` 归 `无衬线`，`Times New Roman`、`Times`、`宋体` 归 `衬线`，`Courier New`、`Courier`、`Menlo`、`Consolas` 归 `等宽`，`楷体` 归 `手写`。层叠样式的通用族名 `serif`、`sans-serif`、`monospace`、`system-ui`、`ui-serif`、`ui-sans-serif`、`ui-monospace`、`ui-rounded`、`math`、`fangsong`、`cursive`、`fantasy` 由字体选取库折成对应的中文族名，宿主直接收到这些英文名时也照样解析。没有对应字体时 `取字样` 返回 `资源不存在`；宿主暂时无法提供时返回 `资源暂不可用`。
- **粗体族名**：`无衬线粗体`、`衬线粗体`、`等宽粗体` 是对应标准族的粗体字面，宿主可选地提供；宿主没有这个粗体字面时返回 `资源不存在`，应用回到常规族并把轮廓错开重描来仿粗。应用在请求字重为 600 以上时先取粗体族名，取得且含所需字符就用它，否则退回常规族。宿主交出常规字面充当粗体时，应用会把字形当成已粗而不再仿粗，所以粗体族名只对应真正的粗体字面。
- **缺字回退**：应用按码点选字，链序为 首选族、同类通用族、`汉字`、`符号`。应用对每个候选族取字体、查字体库的码表，取第一个有该码点字形的字体；链上没有字形时画首个字体的 `.notdef`。宿主为 `汉字` 与 `符号` 给出覆盖相应码域的字体文件，`无衬线`、`衬线` 可以给比例西文字体而把汉字留给 `汉字` 族。回退由应用侧的字体库判定，接口只交字体字节，不另设“此字有没有”的查询。
- **文件**：字体是只读的 sfnt 文件（TrueType、OpenType）或字体集（TTC）。`字样集序号` 指明字体集中的第几个字面，单个字体文件为零。宿主应优先给出 TrueType 轮廓（glyf）的字体，也接受紧凑轮廓（CFF、CFF2）。同一次运行中，同一字体的内容保持不变。
- **读取**：`读取字体文件(字体, 偏移, 长度)` 的偏移与长度须非负，且偏移加长度不超过 `字样卷长度`，否则返回 `输入无效`；长度为零时返回空字节串。单次读取长度的上限由宿主定，至少 4 MiB，超过时返回 `资源配额已尽`。中文字体文件常有 20 至 80 MB，应用应只读所需的表与字形。读取出错返回 `宿主操作失败` 并附宿主消息。
- **授权与资源**：字体属于公开的只读资源，本包免授权；宿主只开放其字体目录与发行包的字体目录，不得借本包读取其他文件。字体句柄在本次运行内一直有效，无须释放。
- **系统字体与发行字体**：宿主先在系统的字体目录里按族名找字体：林檎为 `/System/Library/Fonts`、`/Library/Fonts` 与用户字体目录，林纳为 `/usr/share/fonts`、`/usr/local/share/fonts` 与用户字体目录，轩窗为系统字体目录与用户字体目录。系统里没有该族时，改用发行包随附的字体；发行包把字体放在程序旁的 `字体/` 目录。当前发行带 `思源黑体.otf`（比例西文与汉字，归 `无衬线`、`汉字`、`符号`、`圆体`、`数学`）、`原始字体.ttf`（文楷，归 `衬线`、`手写`、`装饰`、`仿宋`；西文衬线字面留待后续版本补入）、`默认等宽黑体.otf`（等宽）。三套字体与各自许可随发行包分发。
- **宿主实现**：诺驿按内置的族名表在各系统的字体目录里查找，再退到程序旁 `字体/` 与 `字体.ttf`（见 `豫言操作系统/适配/字体诺驿`）；浏览器取页面用 `<link data-yy-字体="族名" href="…">` 声明的字体文件，可另写 `data-yy-字体序号`，页面按族名分别声明（见 `豫言操作系统/适配/字体浏览器`）；原生执行器按同一套族名在林檎、林纳的系统字体与发行包 `字体/` 里找（见 `豫言操作系统/裸机/客体二号/显示原语。底层。豫` 的「字体按族开」）。

规范样例须覆盖：三个标准族名、汉字与符号回退族名、常见具体族名与通用族名、文件头魔数（`00010000`、`true`、`OTTO`、`ttcf`）、字体集序号、越界与负数读取、长度为零的读取、未知族名。字体族验收按无衬线、衬线、等宽三族核对取得的字体不同、无衬线的 `i` 与 `m` 前进宽度不同、衬线缺汉字时回退到汉字族（见 `豫言操作系统/适配/字体诺驿/测试/字样族验收`）。
