# 内容摘要接口规范 0.3.0（文言）

本包为豫言操作系统之内容摘要接口，立内容之摘、成批之摘、目录之摘、文件系统版本之号与自版本变更之法。接口惟有类型与签名，分为二篇：「籍摘型」惟收四记录之类（籍摘详情、籍摘索引状、籍摘变更果、籍摘索引目），「籍摘」声九函而导「籍摘型」；惟用其型之库与壳命导「籍摘型」即足，不连接口诸函之宿主导入（议一千六百七十八）。其术见库「籍摘」（目 `库/籍摘`）：原生之土、豫言操作系统与壳命、试皆径用此一份纯豫言之实，不别设适包。

## 摘要之法

内容之摘一律用**稽古之物号**（与 Git 同）：以卷之内容编为 `blob <字节数>\0<内容>`，以沙一磨之，出四十字，皆小写十六进制。即 `git hash-object` 对同卷所出之物号。摘惟系于卷中内容之字节：文同则摘同，不系于径、时、权与文号。空卷之摘为 `e69de29bb2d1d6434b8b29ae775ad8c2e48c5391`。

目录之摘用**稽古之树物号**（与 Git 同之 tree 物）：以目录下之常文依仓之暂存区建树，逐层编为树物：每项为模式、名、二十字节之物号；以沙一磨其编码，出四十位小写十六进制。空目录之树号为 `4b825dc642cb6eb9a060e54bf8d69288fbee4904`。仓中惟计暂存区所跟踪之常文（与 `git write-tree` 同）；工作区已改之卷依今文重算物号而后建树。仓外之目录递归扫常文，同此物号与树编码而建树，深至多六十四层。

径之解与「豫章」之「阅」同：相对之径依东道所记之今目而解，绝对之径如故。无其卷、非普通之文或读之不得，则摘为空文。无其目录或非目录，则目录之摘为空文。

## 成批之摘

`取内容摘要们` 依所给之次还同长之摘列，每项与 `取内容摘要` 同形同义；重出之径各答一次，空组还空组。此组之径同入一请而办：册一读一写；中者径答旧物号，未中者依今文重算。执行器之成批读术留待后版。

## 构建索引

库「籍摘」不书仓之 `.git/index`。仓中所跟踪之卷用**稽古暂存区之式**（`目卷` 之读写）别存一份「构建索引」于共储之目：`<宿根>/豫构缓存-<户名>/籍摘/仓/<仓键>/index`。初可从仓之 `.git/index` 只读而取种；读写皆复稽古之索引术，经 `index.lock` 易名而易之。仓外之卷别存一份同式之索引，径记绝对而去其首斜：`<宿根>/豫构缓存-<户名>/籍摘/仓外/index`。

索引每项记径、物号、模式、大小与改时；取摘先较索引之签：大小与改时未变则径取旧物号（中），变则读文重算（未中）。同秒改过之边角循稽古之判：改时同且先于索引书出之时则以为未变；否则读文算物号而较之。

## 版本与计数

`问版本号` 还自零起之整数，有进而无退。版本与命中、未中之数存于 `<宿根>/豫构缓存-<户名>/籍摘/全局/计。数据。豫`，跨程与重启而存。壳命之书、续、焚、更名既成，呼 `记写入`（带径）使号加一并记一变更；摘要未中重算、目录建树时签核见所记之径变亦加一并记变更。新径初入册不加。号惟增无减。

## 自版本之变

`自版本变更` 受一版之号，还自该版以来增、改、更名、删之径，依径而序、去重。变更之录依（版本、径）记于 `<宿根>/豫构缓存-<户名>/籍摘/全局/变更。数据。豫`：壳命之写入、摘要未中重算、目录建树时之签核皆记一条。录惟留近四千零九十六条；截短后所问之版早于首条所留之版则答 `须全量重扫`，呼者不得以为空表。

## 诸东道

原生之东道（林檎、林纳、轩窗）与豫言操作系统（裸机）共库「籍摘」此一份纯豫言之实，读文、算物号与建树皆同一组文件之接口，所算逐字节同。浏览器之东道无可久存之真文件系统，此版还空文与零号；浏览器之支持留待后版。诺驿与云工非所支之的。

## 一致性样例

| 情境 | 必见 |
| --- | --- |
| 卷 `甲` 之文为 `abc` | 物号为 `f2ba8f84ab5c1bce84a7b441cb1959cfc7093b7f`，二问相同 |
| 同文别写一径 | 物号与 `甲` 同 |
| 无其卷 | 摘空文，`在` 为阴 |
| 惟改其时、不改其文（以同文覆书） | 物号同 |
| 目录中增删一卷 | 树号变；名、模式、子树物号皆同则树号不变 |
| 空目录 | 树号为 `4b825dc642cb6eb9a060e54bf8d69288fbee4904` |
| 同组之径二问 | 次问尽中，`未中` 不增，物号与首问同 |
| 书一所记之卷而后问号 | 号至少加一 |
| 索引书盘后清其程中之索引、复读于盘 | 版本、条目、命中与未中之数皆在 |
| `自版本变更` 于任意之版 | 得 `变更未备`，不得以为空列 |

## 边界

本包不立构建索引之并发写锁；同份索引之并发写留待后版（今以末书者胜，读者或得上一版）。不供删索引、缩索引与按径失效之单命。不保外人之写入于其时不加号，惟保下次核算之时计入。不为内容之加密、去重与按内容寻址之藏。目录之摘惟计暂存区所跟踪之常文，不计未跟踪之卷与子模；仓外之目录递归扫常文。
