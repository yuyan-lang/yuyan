# 网络接口规范

此包主出站网页之请，不主原生套接、入站监听与各地私绑。法名用大写，址须绝对之 HTTP 或 HTTPS；标头列可重名。发送可挂起，成功之答由宿主造之，应用循具名之术取状态、标头与全正文；四百、五百之状态亦为已得响应，非传输之误。

宿主按本次所授之目的地核每请。首版遇三百一、三百二、三百三、三百七、三百八之转址状态，即返宿主操作失败，不向次址发请；三百四等他态可如常交客。错误之文不得为客跨宿主分支之据。传输败、未授权、额尽各别告之。首版取全正文，宿主明示请与答之字数上限，不许以无穷之大小为常，流、取消与可验权之转址待别包。网址与标头之细约、验例俱见[汉语稿](规范.汉语.md)。
