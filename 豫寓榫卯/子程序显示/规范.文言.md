# 子程序显示接口 〇点二

此包为桥接之包，连[子程序](../子程序/规范.文言.md)与[显示](../显示/规范.文言.md)二接口：父程序启子程序时转授一显示面，子程序如常召显示接口，宿主以其所交之画授父程序，以父程序所送之输入之事与尺寸授子程序。平铺桌面（提案 〇〇〇一四）之外程序格以之纳图形程序之画于格中，子程序不必改书。

## 诸术

| 术 | 用 |
| --- | --- |
| `启动带显示面的子程序(程序, 参数, 输入, 环境, 显示面名, 宽, 高, 像素比)` | 前四参同子程序接口之 `启动子程序`；另以名为“显示面名”之一面转授子程序，初尺为宽高（物理之素），像素比如所予。果同 `启动子程序`：`子程序已启动` 载其柄，或 `子程序启动失败` 载系统错误 |
| `取子程序画面(句柄)` | 交子程序最新之全画布与自前次所取以来之变区，见下 |
| `送子程序输入事件(句柄, 事件)` | 以显示接口之一输入之事入子程序之事列 |
| `设置子程序显示面尺寸(句柄, 宽, 高, 像素比)` | 易子程序显示面之尺与像素比 |

柄与子程序接口共之：`尝试收取子程序`、`取子程序输出`、`终止子程序`、`查询子程序资源` 皆如故。收毕则柄失效，本包诸术返柄无效。

返整数之二术：零成、八柄无效、二十九宿主败、五十八未支持。

## 子程序之侧

子程序如常用显示接口：

- 以所转授之名 `取得已授显示面` 则成，余名返 `未获授权`。
- `读取显示面尺寸` 与 `读取显示面像素比` 交父程序最近所设之值。
- `提交像素画面` 与 `提交像素画面区域` 以画布交宿主存之；宽高异于今尺则返 `资源暂不可用`，同显示之规。
- `等待输入事件` 与 `等待输入事件限时` 依序交父程序所送之事。父程序易尺，则先交 `显示尺寸变化`，子程序复读其尺而重画全帧。
- 父程序止子程序、闭其所居之格、或归父程序己之显示面，方候之子程序受 `显示面已关闭`。
- `设置指针形状` 与 `设置文字输入区域` 如常而返。
- `归还显示面` 止此显示之会，其后父程序取画得 `子程序未取显示面`。

## 父程序之侧

- `取子程序画面`：子程序未取面则得 `子程序未取显示面`；既取而无新画则得 `子程序画面未变`；有新画则得 `子程序画面已更新`，载画布之宽高、全画布之字（RGBA8，同显示之规）与自前次所取以来变区之左、上、宽、高（数交则取外包之矩）。子程序既终而未收，犹可取其末帧。败则得 `子程序画面失败` 载系统错误，柄无效则为 `资源已失效`。
- `送子程序输入事件`：坐标为子程序显示面上之物理之素，父程序自其坐标换算之。事依送达之序而列；列满则弃最早之事，相邻二指移并为一。
- `设置子程序显示面尺寸`：宽高须正，否则返二十八（输入无效）；子程序随后受 `显示尺寸变化`，未以新尺交全帧之前，`取子程序画面` 所交犹为旧尺之画布。

## 平台

- **裸机（兼容六十四、臂六十四）**：客体二号以带型之导入径行之（原语百八十二启、百八十三取画、百八十四送事、百八十五设尺）。父程序须为初始任务（惟彼能读写他任务之内存，故平铺桌面行于开机壳之任务）；子程序为装载任务所起之动态任务，兼容内存不及二百五十六兆则起不成，返 `资源不存在`。子程序之显示之请经内核邮箱交初始任务，画惟传所变之区所在之行；像素比于子程序一侧恒为一。`终止子程序` 于带面而起者为闭其面：方候者立受 `显示面已关闭`，后候亦然，程随后自退。其约见 `豫言操作系统/裸机/文档/客体二号.文言.md` 之“子程序显示代办”。
- **原生林檎**：执行器内之管道代办（原语百八十二至百八十五）。父执行器起子进程时多建二管（子书画、父书事），于应用之参前加宿主之选 `--显示面代办 名=宽x高@画号,事号,比`（比为像素比乘六十四）与 `--`；子程序之执行器依之改显示原语行于管：交画则书区所在之整行于画管，候事则自事管读事录（同底层显示之事录，尺变载新宽高与像素比），尺与像素比于本地答父所新设者。父程序取画则不塞而读画管，所交之行径读入常驻画布。事管满则弃新送之事；`终止子程序` 径终子进程；事管读至尾则子程序先受 `显示面已关闭` 一次。其约见 `豫言操作系统/裸机/文档/客体二号.文言.md` 之“子程序显示代办”。
- **原生林纳**：返未支持，同下。
- **诺驿、浏览器**：适配返未支持：`启动带显示面的子程序` 得 `子程序启动失败` 载 `资源暂不可用`，`取子程序画面` 得 `子程序画面失败` 载 `资源暂不可用`，余二术返五十八。

## 后版之事

- 指形与输入法候选之位之转交（〇点二）。
- 一子程序转授数面。
- 原生林檎之事管满时依裸机之法弃最早之事、并相邻之指移；原生林纳之代办。
- 孙任务（子程序复起之程）取显示面。
- 诺驿与浏览器之显示代办。

## 外壳之请与来信（〇点二）

〇点二增子程序与父程序（外壳）之间之短信，以供[提案〇〇〇一五](../../提案/00015-桌面程序独立成任务.汉语.md)：桌面每窗为一独立之任务，开文、行程序、设签题之类须外壳为之者，经请付外壳；外壳经来信令程跳至某行或闭之。信为字节串，其容二方约之。

- `请外壳办(请)`：子之侧，以一请付转授其面之父；果零为成，五十八为未支（非带面而起或宿主不支）。
- `取外壳来信()`：子之侧，取父所送之次信；无信则得空字节串。
- `取外壳请求(柄)`：父之侧，取此子程序之次请；无请则得空字节串。
- `送程序来信(柄, 信)`：父之侧，送一信于此子程序；果零为成，八为柄无效或非带面而起，五十八为未支。

裸机由初始任务于子表项中为每带面而起之子程序存其请与来信（显示代办之操作八交请、九取来信）。其所启交互之孙之入亦经显示代办（操作十至十二）由初始任务转交（见子程序〇点八）。林檎、节点与浏览器返五十八与空字节串，此诸宿主上之桌面程序以嵌入之式行于外壳之中。
