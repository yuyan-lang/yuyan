# 网址之约 0.2.0

编码网址成分，取豫言一文，以 UTF-8 逐字节作百分号编码。ASCII 字母、数及 `-_.!~*'()` 不易；余字节皆成大写十六进制 `%HH`。如 `a/b` 成 `a%2Fb`，`函数` 成 `%E5%87%BD%E6%95%B0`。所返惟成分，不兼键、等号或全址。若输入非有效 Unicode 标量，须报失，不得损文而代之。

解码网址成分，严格验 `%HH` 与 UTF-8；百分号残缺、非十六进制或坏字码皆报失。`+` 不易，`%2F` 解为斜线；用于路径段者，客仍须别验斜线、反斜线与控字符。此术不析全址。

二术皆无授权与外效。浏览器、节点、云工、原生皆可具之；虽以豫言纯码行，签名及结果亦须同。本版未定全址解析及 IDNA。
