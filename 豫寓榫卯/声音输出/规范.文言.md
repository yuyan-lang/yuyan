# 声音输出接口之规 0.1.0

此包为已授之声音输出之流，供设计作品播放器诸程序播混成之样（提案〇〇〇一八第十节“新接口「豫寓鸣」”）。应用依此包即求宿主实之，开流又须宿主授“声音输出”。

- `辟声出` 依采率、声道之数与块之大开一输出之流。采率与声道须正（宿主至少支四万八千赫与一二声道），块之大为每书所宜之帧数，宿主可略之。未授则返 `未获授权`；暂无输出之器则返 `资源暂不可用`；参不合则返 `输入无效`。宿主可依其器之采率重采，`已播帧数` 仍依开时之采率计。
- `写声样本` 排一块之样于播放之列：交错十六位有符小端之整，每帧次为诸声道各一样，字节之数须为“声道×2”之整倍，否则返 `输入无效`。宿主可限排列之总量，逾则返 `资源配额已尽`，应用俟 `已播帧数` 增乃复书。流已闭则返 `资源已失效`。
- `已播帧数` 为播放之主时钟：自开以来已送于器之帧数，单调不减。画依此时钟取帧，跳时应用闭旧流（或续书新位之样）而复计时。流失效则返负一。
- `声出延迟` 为已书未播之帧数加器之延，以帧计。流失效则返负一。
- `阖声出` 止播、弃未播之样，流即失效；再闭则返 `资源已失效`。

授：宿主之选 `--授权声音输出` 授此次运行开声音输出之权，书法同显示面之授，书于程序参数之前。

实：浏览器用 Web Audio，依书之先后排每块之样于前块之后而播；模拟宿主（`豫言操作系统/适配/声音输出模拟`）不发声，书即算播，试可令其拒授；诺驿暂用模拟宿主之实。豫言操作系统（裸机）由执行器径实之（十月十三日，原语二百五十至二百五十四，经核之声卡表交声卡之驱，今有虚拟声卡、高清音频、通用串行声卡即 USB 音频类）：全系一出流，复开则顶旧流；支四万八千赫、一或二声道，书时不容则全退（资源配额已尽），缓约三秒；声卡之况以设备接口之 `问声卡` 询之。macOS（Core Audio 或 AVAudioEngine）、Linux（ALSA）、诺驿（呼豫言自为之原生库）之实，裸机之英特尔高清音频、授之核与重采，列为后续版之事。

网页行在（浏览器中之系统，提案〇〇〇四三）之中，工作线程（行豫言之程者）书样于共享之环形缓，音之线程之 AudioWorklet 工作件读而奏之：缓空则工作件补静音，不容一整块则整块退之（资源配额已尽）；采率、声道依开时之请，浏览器之采率异者则于工作件以线性插值重采之，`已播帧数` 仍依开时之采率计。控制之字（写位、读位、器之延）在同一共享之存，`已播帧数` 与 `声出延迟` 径读之。浏览器之自动播禁须先有手势，页于初按键或点复其 AudioContext。浏览器构建宿主无声之外务，其 `辟声出` 得 `资源暂不可用`。
