# 子程序接口 0.9.0

〇点九增 `使者入素(柄)`（十月十七日）：交互之子程入原始之模（呼九四「入终端原始之入模」而未呼九五）则阳。壳行子程据之分二：阴则以壳己之读行编辑（回显、编辑、拼音组字、旧行）收一整行，并换行书于子程；阳则每键原样书之，由子程自理（文本编辑、嵌套之壳）。开机壳、桌面终端之会话与远程登录之会话皆如是。裸机上子程呼九四、九五则告初始任务，初始任务记于其输入通道；无面之任务（如远程登录之会话）所起交互之子程亦经初始任务登而转入，〇点九起亦可用 `启动交互子程序`。林檎、林纳与网页恒阴。

〇点八增 `启动交互子程序(名, 参列, 环境)`、`写子程序输入(柄, 字节)` 与 `关闭子程序输入(柄)`。交互子程序之标准入常开：调用者随时书字，子程读则予之，无则候之；既闭，所书读尽，子程乃得文末。桌面终端以之送程序行时所入之每行（并换行）于程，安装程序之类须答问者乃可行于桌面终端。授、环境与二出同 `遣使`。裸机由启之之初始任务存待读之字：子任务读入则求于初始任务，无则候至书或闭；林檎与林纳为子进程留一标准入之管，书即书管，闭即闭其写端。节点与浏览器返启败（资源暂不可用）与五十八，调用者改用 `遣使`。裸机上带面之子程序（如独立成任务之桌面终端，提案〇〇〇一五）亦可启交互子程序：经显示代办请初始任务登此孙任务，书与闭亦经显示代办转交初始任务存之；余任务启之则返启败（资源暂不可用），调用者改用 `遣使`。书之果零为成，八为柄无效或非交互，二十九为宿主败，五十八为未支。

〇点七增 `子程序任务号(柄)` 与 `打断任务(号)`。桌面终端与远程登录按 Ctrl+C 则用之以惟断壳会话方行之一句（十月十四日起，壳命令 `「辍」于「号」曰「N」` 之法）：先以柄得会话之任务号，乃以负之任务号呼 `辍役`。

`使者役号` 返其柄所对任务之号，即任务监测之接口所列之任务标识：裸机为核之任务柄，林檎与林纳为子进程之进程号。柄无效则返负一；网页行在返进程表之任务号（同其柄）；节点、浏览器原壳与轩窗返负一。

`辍役` 之效同终端之 Ctrl-C。裸机经核务六十四断此任务及其诸子孙，退码皆百三十；方行于他核者，俟其次呼核务或其核次轮之时而终。林檎与林纳于本实例所启之子程序中寻此进程号，发 SIGINT。网页行在由主线程之进程表毁此任务及其诸子孙之工作线程，退码皆百三十。果零为成，八为无此任务，二十九为宿主败，五十八为未支持（节点、浏览器原壳与轩窗）。断后如常以 `姑收使` 收其退果。轩窗之断、子进程之孙并断，俟后版。

号负（十月十四日）则惟断任务 负号 之子孙，己则存焉，犹终端之 Ctrl-C 断前台之作业而壳自存：裸机断其核中之子任务与其经底层进程所起之诸程（并其子孙），退码百三十；网页行在毁其诸子孙之工作线程，退码百三十。果零为断其一以上，一为无子孙可断，八为号误，五十八为未支持（林檎、林纳、节点、浏览器原壳、轩窗与豫行启动器）。壳会话据之惟断当句；无子孙可断（此句于会话己之进程中算），呼者可复以正之任务号断全会话。

〇点六增 `取子程序输出(句柄)`：取其柄自前次所取以来新生之标准出与标准误字节，取则清之；其后 `姑收使` 之毕果惟交其余。桌面命令行用之，以随时示行中之进。原生执行器先读管中现有之数入异步表，乃取而清之；裸机执行器取子任务表中其项已收之出。节点与浏览器之适配返二空字节，全出于收毕时交之；节点之增量出留待后版。柄无效亦返二空。

裸机执行器支 `遣使` 与 `姑收使`：程序之名依文件系统之径解之（相对执行器之当前目录），子任务之二出由父任务捕之，所给环境书为子任务之环境块。父任务于显示面之候亦收子任务之出与文件代办之请，故桌面候键时子程序照行。输入字节传于子任务、裸机之 `召回` 留待后版。

`查询子程序资源(句柄)` 询今实例未收之子程，存其柄以待终收。果依次为状态、今常驻可用爻与字节、系统峰常驻可用爻与字节，单位字节。零成、八柄无效、二十九宿主败、五十八资源未可观。爻阳其数乃有义；采样最大由呼者别计，名为采样最大。系统峰与采样最大别录。

林檎之今常驻取自单程之询，原生收毕时存该程系统峰。诺驿工具召同纯豫言底层查询模块，胶水惟召系统自有之库；具名应用之询转原生子程服。程已终，今值或不可用。浏览器返资源未可观。林纳、轩窗与裸机之后端留后。

呼者得循采样之期比常驻字节与阈值，逾则召 `召回` 而收其果。采样阈值为实见逾限即强止之门槛，系统瞬时硬限留后。询败、逾时与资源逾限各录其因。

〇点四增 `启动子程序(名称, 参数列, 输入字节, 环境)` 与 `尝试收取子程序(句柄)`。启成则返今实例所登整数柄，启败则返系统之错。程序及环境循同步之具名授权，输入惟属此调。

收取即返“子程序运行中”“子程序收取完成”或“子程序收取失败”。毕果载退码、标准出及标准误之原始字节，退码非零亦为毕果；收取毕果既成则释柄，再询返资源已失效。止之复用 `召回`，止后续收终果。

原生执行器复用标准库异步表与管道之收，节点客宿主经原生子程序服务共用此实现。今输入循同步入口之一万六千三百八十四字节交换域。浏览器循资源暂不可用之果。后续：大入分段书及运行中增量之出。

零点三版增 `终止子程序(异步句柄)`，柄由今宿主实例之标准库异步启服所得。请强止而留其记与二出，呼者续收退果。码零成、八柄无效、二十九宿主败、五十八今平台未支持；已毕而未收者亦成。柄惟识今实例所录之子程。

工具节点与原生执行器共用标准库异步柄及底层进程之止。浏览器还五十八。后续之事：裸机动态任务之止、应用宿主之异步启止。

零点二版增 `运行继承输入子程序(名称, 参数列, 环境)`，标准入继调用者，标准出与误犹捕而终乃还。同具名程序之授、环境之授、退出之果与交换之限；不继父进程环境。节点宿主继己标准入之文件描述符，其间暂止宿主原始编辑之制，终或启败则复；宿主行读不先取下一行。浏览器无此能则明返暂不可用。待办事项：原壳全输入会话之接、异步输出与取消。

此为具名所授用户态发行程序执行之接口。`遣使候报` 以名、参列、标准输入字节及环境名值对行宿主预授之程序。客不得指任意宿主之令，不得以参易宿主选项。环境名别须授，调间不留环境，不自继父环境。复环境名、零字及非法名返 `输入无效`；未授程序或环境返 `未获授权`。

常终返 `子程序已结束`，依次载退出码、标准输出与标准错误字节。非零退出亦为终果。启动、信号终止、逾时诸败返 `子程序未执行` 而载系统错误；此名谓未得常终之果，程序或已启而生副作用。交换逾限返 `资源配额已尽`。输出为原字节，客自解其文。

节点以今 Node 行预授发行之启动文，客参置 `--` 后，不调宿主壳。节点装载选项之环境不得为客所易。浏览器犹无子程序执行之实，当明返不可用。待办事项：异步取消、流式输出、余环境适配与原壳迁调。
