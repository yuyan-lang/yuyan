# 子程序接口 0.11.0

0.11.0 增加 `辍宿主役(号)`（2026-10-23，议题 440）：按宿主进程号结束任意宿主进程，不查行在的任务表。macOS 与 Linux 先发 SIGTERM（15，程序可以收拾了再退），三百毫秒还没退再补 SIGKILL（9）；结果零为已发信号（进程随后结束），八为没有这个进程，二十九为宿主失败（如没有权限），五十八为暂不支持。豫言操作系统里没有宿主进程，诺驿、浏览器原壳与轩窗也返回五十八；要结束任务表里的任务仍用 `辍役`。壳命令 `「辍宿主役」于「号」曰「N」` 建在它之上。

0.10.0 增加 `辍役` 的结果码二（2026-10-20）：网页行在里号为负、又没有子孙可打断时，主线程给这个任务的共享内存置打断标志并返回二，任务本身留着。句子单元里的检查点见到标志就抛出专用异常，壳会话在句子边界接住、印“已打断”，接着读下一句，会话里的定义都在。`辍其句`（桌面终端与远程登录的 Ctrl+C、壳命令 `「辍」`）认得二，只见二就回提示符，不再退一步打断整个会话。其余平台仍返回一，调用方可以再以正的任务号打断整个会话。

0.9.0 增加 `使者入素(句柄)`（2026-10-17）：交互子程序进入了原始输入模式（调了原语 94「进入终端原始输入模式」还没调 95）时得阳。壳运行子程序时据此分两种：阴时由壳自己的读行编辑（回显、编辑、拼音组字、历史）收一整行，再连同换行写进子程序；阳时把每个键原样写进去，由子程序自己处理（文本编辑器、嵌套的壳）。开机壳、桌面终端里的会话与远程登录会话都这样办。裸机上子程序调 94、95 时告诉初始任务，初始任务在它的输入通道上记下；没有显示面的任务（如远程登录会话）起的交互子程序也经初始任务登记与转交输入，0.9.0 起它们同样能用 `启动交互子程序`。macOS、Linux 与网页平台恒为阴。

0.8.0 增加 `启动交互子程序(名称, 参数列, 环境)`、`写子程序输入(句柄, 字节)` 与 `关闭子程序输入(句柄)`。交互子程序的标准输入保持打开：调用方随时写入字节，子程序读到就交给它，没有就等；关闭之后，已写的字节读完，子程序读到文件结束。桌面终端用它把程序运行时输入的每一行（连同换行）送给程序，安装程序这类要回答提问的程序因此能在桌面终端里运行。授权、环境与两路输出同 `遣使`。裸机由启动它的初始任务存放待读的字节：子任务读输入时向初始任务要，没有就等到写入或关闭；macOS 与 Linux 给子进程留一条标准输入管道，写入即写管道，关闭即关写端。节点与浏览器返回启动失败（资源暂不可用）与五十八，调用方改用 `遣使`。裸机上带显示面的子程序（如独立成任务的桌面终端，提案 00015）也能启动交互子程序：它经显示代办请初始任务登记这个孙任务，写入与关闭也经显示代办转交初始任务存放；其余任务启动时返回启动失败（资源暂不可用），调用方改用 `遣使`。写入的结果零为成功，八为句柄无效或不是交互子程序，二十九为宿主失败，五十八为暂不支持。

0.7.0 增加 `子程序任务号(句柄)` 与 `打断任务(号)`。桌面终端与远程登录按 Ctrl+C 时用它们只打断壳会话正在运行的一句（2026-10-14 起，壳命令 `「辍」于「号」曰「N」` 的做法）：先由句柄取得会话的任务号，再以负的任务号调用 `辍役`。

`使者役号` 返回句柄对应任务的任务号，即任务监测接口列出的任务标识：裸机为内核任务句柄，macOS 与 Linux 为子进程的进程号。句柄无效时返回负一；网页行在返回进程表里的任务号（与句柄相同）；节点、浏览器原壳与轩窗返回负一。

`辍役` 的效果与终端里的 Ctrl-C 相同。裸机经内核服务 64 打断这个任务与它的全部子孙，退出码都是 130；正在别的处理器核上运行的任务在它下一次系统调用或那个核下一次时钟轮转时结束。macOS 与 Linux 在本实例启动的子程序里找这个进程号，给它发 SIGINT。网页行在由主线程的进程表销毁这个任务与它全部子孙的工作线程，退出码都是 130。结果零为成功，八为没有这个任务，二十九为宿主失败，五十八为暂不支持（节点、浏览器原壳与轩窗）。打断之后照常用 `姑收使` 收取退出结果。轩窗的打断、子进程的孙进程一并打断留待后续版本。

号为负（2026-10-14）时只打断任务 −号 的子孙，它自己留着，同终端里 Ctrl-C 打断前台作业而壳本身留着：裸机打断它在内核里的子任务与它经底层进程起的全部程序（连同这些程序的子孙），退出码 130；网页行在销毁它全部子孙的工作线程，退出码 130。结果零为打断了至少一个，一为没有可打断的子孙，二为已给任务 −号 置上打断标志（网页行在，任务留着，见 0.10.0），八为任务号不对，五十八为暂不支持（macOS、Linux、节点、浏览器原壳、轩窗与豫行启动器）。壳会话据此只打断当前句；没有可打断的子孙（这一句在会话自己的进程里计算）时，网页行在由检查点打断这一句，其余平台调用方可以再以正的任务号打断整个会话。

0.6.0 增加 `取子程序输出(句柄)`：取出该句柄自上次取出以来新产生的标准输出与标准错误字节，取后清空；之后 `姑收使` 的完成结果只交出其余部分。桌面命令行用它在程序运行时随时显示进度。原生执行器先把管道里现有的数据读进异步表，再取出清空；裸机执行器取出子任务表里该项已收到的输出。节点与浏览器适配返回两段空字节，全部输出在收取完成时交出；节点的增量输出留待后续版本。无效句柄返回两段空字节。

裸机执行器支持 `遣使` 与 `姑收使`：程序名按文件系统路径解析（相对执行器的当前目录），子任务的两路输出由父任务捕获，给出的环境写成子任务的环境块。父任务在显示面的等待里同样收取子任务的输出与文件代办请求，所以桌面等键时子程序照常运行。输入字节传给子任务、裸机上的 `召回` 留待后续版本。

`查询子程序资源(句柄)` 查询本实例尚未收取的子程序，保留句柄供最终收取。结果依次为状态、当前常驻字节可用爻、当前常驻字节、操作系统峰常驻字节可用爻、操作系统峰常驻字节，单位字节。状态零为成功、八为句柄无效、二十九为宿主失败、五十八为资源观测暂不可用。数值只在对应可用爻为阳时有意义；采样最大值由调用方另行累计并标为采样最大值。操作系统峰与采样最大值分别记录。

macOS 当前常驻字节通过单目标进程查询取得，原生回收时保存该目标的系统峰值。诺驿工具宿主调用同一纯豫言底层查询模块，胶水调用操作系统自带系统库；具名应用查询转交原生子程序服务。查询已结束子程序时当前值可以不可用。浏览器返回资源观测暂不可用。Linux、Windows 与裸机资源后端列为后续事项。

调用方可以按采样间隔比较常驻字节与资源阈值，超限后调用 `召回` 并收取结果。采样阈值是在实际观测超限时强制终止的门槛，操作系统瞬时硬限额列为后续事项。查询失败、超时与资源超限各自记录原因。

0.4.0 增加 `启动子程序(名称, 参数列, 输入字节, 环境)` 与 `尝试收取子程序(句柄)`。启动成功返回当前实例登记的整数句柄，启动失败返回系统错误。程序和环境沿用同步接口的具名授权，输入属于本次调用。

收取立即返回“子程序运行中”“子程序收取完成”或“子程序收取失败”。完成结果携带退出码、标准输出和标准错误原始字节，非零退出保留为完成结果；成功收取完成结果后释放句柄，后续查询返回资源已失效。停止复用 `召回`，停止后继续收取最终结果。

原生执行器复用标准库异步表和管道收取，节点应用宿主通过原生子程序服务共用这份实现。当前输入沿用同步入口的 16384 字节交换范围。浏览器沿用资源暂不可用结果。后续事项：大输入分段写入和运行中增量输出。

0.3.0 新增 `终止子程序(异步句柄)`，句柄由当前宿主实例的标准库异步启动服务取得。它请求强制终止，保留记录与两路输出，调用方随后收取退出结果。结果码为 0 成功、8 句柄无效、29 宿主失败、58 当前平台暂不支持；已经结束而尚未收取的进程返回成功。句柄只标识本实例登记的子进程。

工具节点与原生执行器共用标准库的异步句柄及底层进程终止能力。浏览器返回 58。后续事项：裸机动态任务终止、应用宿主的异步启动与终止。

0.2.0 新增 `运行继承输入子程序(名称, 参数列, 环境)`，标准输入继承调用方，标准输出与标准错误仍捕获并在结束后返回。它沿用同一具名程序授权、环境授权、退出结果与交换上限；不继承父进程环境。节点宿主继承自身的标准输入文件描述符，期间暂停宿主原始编辑模式，结束或启动失败后恢复；宿主行读取不预取下一行。浏览器缺少该能力时明确返回暂不可用。待办事项：原壳完整输入会话接入、异步输出与取消。

这是具名授权的用户态发行程序执行接口。`遣使候报` 以名称、参数列、标准输入字节、环境名值对运行宿主预授的程序。应用不能指定任意宿主命令或通过参数修改宿主选项。环境名称须另获授权，调用间不保留环境，不自动继承父进程环境。重复环境名、零字及非法名称返回 `输入无效`；未授程序或环境返回 `未获授权`。

正常结束返回 `子程序已结束`，依次携带退出码、标准输出和标准错误字节。非零退出仍是结束结果。启动、信号终止、超时等失败返回 `子程序未执行` 携带系统错误；此名称表示未取得正常结束结果，程序可能已经启动并产生副作用。资源交换超过限额返回 `资源配额已尽`。输出为原始字节，文本解码由调用方负责。

节点以当前 Node 执行预授发行的启动文件，应用参数置于 `--` 后，不调用宿主 shell。节点装载选项环境不得由客体改变。浏览器尚无子程序执行实现，应明确返回不可用。待办事项：异步取消、流式输出、其他运行环境适配与原壳迁移。
