# 随机数接口规范 0.1.0

随机数一律来自宿主的密码学安全随机源（例如 Web Crypto 的 `getRandomValues`），不提供种子，也不提供可复现序列；需要可复现伪随机序列的程序应自行实现，不得用本包冒充。

`生成随机十六进制` 读取指定字节数的随机字节并写成小写十六进制文字，结果长度恰为字节数的两倍，不含前缀。字节数须在 1 到 1024 之间，越界时调用失败并抛出豫言异常。

`生成随机通用标识` 返回小写的 UUID 第四版文字，格式为 8-4-4-4-12 个十六进制字符，共 36 个字符，版本位和变体位符合 RFC 9562。

本包不判断随机文字是否已被用作账户名、令牌或会话；唯一性检查和冲突重试属于使用者。用作令牌时，应保证字节数足够（一般至少 32 字节），并只保存其摘要。
