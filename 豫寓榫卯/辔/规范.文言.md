# 手柄接口规范 0.1.0

本包定东道授手柄之事：列柄、问钮枢之状、候接拔之事、振之（或备），及依常式问钮枢之名。应用径依此包，则求宿主实之；宿主无其能者，诸函依本规范答 `资源暂不可用`，载入不以之败。

## 常式

状中钮枢依次编号，诸宿主如一。钮们十七整，零至一千：常钮按则一千，释则零；弩机左弩、右弩为渐量（零至一千）。枢们四整，以千分计，负为左为上，正为右为下，满偏正负一千。

## 义

- **列柄**：`列辔` 无参，列此刻所接之诸柄。空列为成，示宿主有其能而眼下无器。不能列者答 `资源暂不可用`。
- **问状**：`问辔` 受一柄，还一快照。钮们恰十七，枢们恰四；宿主当以器之实轴实钮归之常式。柄已拔则答 `资源已失效`。一柄两问之间可变，状不保其常。
- **接拔**：`候辔` 受毫秒之数。数正而候：期内有接拔则交其事（一期数事者依其序，一一而交，余俟下次），期尽未改则答 `辔无变`；数非正则无期而候。接事携新柄，拔事携故柄；拔后复问则失效。客亦可逐帧列柄而较前后，不赖于候。
- **振**：`振辔` 受柄、强（零至一千，标签强）与毫（标签毫，零则宿主自定其短）。强零则止。宿主无其能者答 `资源暂不可用`；`振已发` 惟示请已交，不谓振已始或已终。振为可选之能，零点一版之宿主可一概答 `资源暂不可用`。
- **名**：`辔钮名` 受柄与钮之序，还汉字之名；序越十七或柄无此钮则还空文。`辔枢名` 同，序在四之内。名随器变，客以之示人，不以之分支。

## 宿主

- **林纳（原生）**：执行器读 `/dev/input/event*` 之 evdev 器（以 O_NONBLOCK 开之，ioctl 取其名与其能），依其能而识手柄，键码与绝对之轴依标准之布而归一；接拔则复扫输入之目而较其事号。适配在 `豫言操作系统/适配/辔原生`。无读输入器之权则答 `资源暂不可用`；振用 evdev 之 FF_RUMBLE。
- **林檎（原生）**：执行器经 Objective-C 之运行时用系统自带之 GameController：以 `[GCController controllers]` 列柄，以 `GCExtendedGamepad` 之 `pressed` 读钮、`value` 读弩与枢，依标准之布归一；接拔则每二十毫秒复扫控制器之组而较其 `vendorName`；振于此版答 `资源暂不可用`（GCHaptics 俟之后版）。适配亦在 `豫言操作系统/适配/辔原生`。
- **豫言操作系统（裸机）**：核之通用串行 HID 手柄之驱（`豫言操作系统/裸机/内核/通用串行手柄。底层。豫`）接于键鼠之通用 HID 口：报告描述符首集合之页一而用四、五、六，或表中有十字、Z、Rz、Rx、Ry 者，则按手柄收报。页九之钮一至十一依次映为甲、乙、天、地、左肩、右肩、择、启、左按、右按、徽；X、Y 为左枢之横纵，Z、Rz 为右枢之横纵，Rx、Ry 为左右弩（零至一千）；十字八向折为四钮。至多四柄，槽名依次为『手柄甲』『手柄乙』『手柄丙』『手柄丁』；接拔以较槽名得之。无柄则 `列辔` 给空列。振答 `资源暂不可用`（出报俟后版）。
- **浏览器**：用页面之 Gamepad 接口，脚本之胶置于 `豫言操作系统/宿主/浏览器/操纵.mjs`；页面可见而得柄后乃有状，拔后依规范答 `资源已失效`。其适配为 `豫言操作系统/适配/操纵浏览器`。
- **模拟宿主**：由 `豫言操作系统/适配/操纵模拟` 供之，试者以 `辔` 篇之拟置柄、拟置态、拟推事、拟取振、拟清预置柄、状与事，便于无器之机验动作之映射。

裸机与林檎之振，列于后版（议题 #557）：林檎拟用 GCHaptics（须 GCHapticEngine 与 AHAP 模式之数）。此二处眼下无振之能，`振辔` 答 `资源暂不可用`；轩窗无手柄之能，诸函答 `资源暂不可用`。

## 误

| 事 | 误 |
| --- | --- |
| 宿主无手柄之能 | `资源暂不可用` |
| 柄拔后问状或振 | `资源已失效` |
| 柄无振之能 | `资源暂不可用` |
| 参之序越界 | `输入无效`（问名还空文，不报） |

## 验收

规范之样须覆：空列、接与拔、拔后问状、钮与弩机之值、四轴之向、振成与不成、钮枢之名（含越界），及无手柄之能时诸函答 `资源暂不可用`。动作之映射见游艺部之 `御术` 库。
