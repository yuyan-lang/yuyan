# 剪贴板之约 0.2.0

零点二版增「读剪贴板文字」：读今用户系统剪贴板之纯文，此术可候。剪贴板无文（空，或惟图像等他式）则返 `剪贴板文字已得` 与空串；权、焦点或用户动作不备返 `未获授权`，剪贴板暂不可达返 `资源暂不可用`，他败返 `宿主操作失败`。读不易剪贴板之物。宿主可于读前问诸用户。

此包独立而必备：客既依之，宿主须全行其术。写剪贴板文字，以豫言一文置用户剪贴板，惟纯文，不析 HTML，不行命；成而返，谓此次写毕，不保其后不为他物所易。此术可候。

系统之剪贴，于一系统诸务共之：一务书之，他务得读。林檎（原生与行在）用系统之剪贴；林纳（原生与无头之行在）书于 `$HOME/.豫言/夹袋。文本`（目阙则建，先书临文而后易名），同一用户之诸进程共之；豫言系统（裸机）由核守一份，诸务读写同一份，容二百五十六 KiB，逾则截之；浏览之台用 `navigator.clipboard`，诺驿用 SDL 之系统剪贴。宿主之剪贴读写不成，则执行器退用本进程内之一块常驻区，约之语义如故（此时惟本进程见之）。

浏览器可求安全境、焦点、用户动作；他宿主可依本机授权。权阙、物不可用或写败，须报调用失，毋伪称成，败时毋动他持久数据。宿主无能则毋称具此包。首版未定图像、多格式与变化监听（读由零点二版增）。
