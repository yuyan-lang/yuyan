# 网页媒体接口规范 0.1.0

此包使浏览器中豫言程序可读 HTML 音频之时钟，以驱画面；亦供用户手势发起页签录制。惟能行 Web Media API 之浏览器适用；用者依之，宿主须尽行诸函。

## 音频

- `读取网页音频状态 id`：标识必为既有 `audio`。还结森文，含时刻、时长（毫秒整数）、暂停、终了、静音、音量（千分之一）与错误文字。时刻四舍五入；元数未载或无穷则时长为负一；最近 `play()` 拒绝之因记于错误，播成或止成则清之。
- `绑定网页音频按钮 音频ID 按钮ID`：立原生点击听者，于同步用户手势内调用 `play()` 或 `pause()`，合浏览器之播放律。重绑同对不重演。播 Promise 拒则记中文因于状态，不遗未处理之拒。
- `设置网页音频时刻`：毫秒非负，元数须已载，且时刻不得逾有限时长；精度从浏览器。
- `暂停网页音频`：等同 `pause()`，可重行。

元素阙、非 `audio`、参数越界或能不足，皆为可捕获之豫言事故。

## 屏幕录制

`绑定网页屏幕录制 始钮 止钮 下载链 配置` 于调用时解析与验参，后置原生点击听者于二钮。配置仅受字段：宽、高为正整数，默认 3840、2160，限一至 16384；帧率默认为 30，限一至 120；码率默认为二千万，限一至一亿比特每秒；文件名默认“网页录制”，限一至一百二十八字，不得含路径分隔与控制符。

始钮之回调，必径调 `getDisplayMedia`，由浏览器显权问；请图与声，以 ideal 请其宽、高、帧率。当前页与此标签之选择皆为愿，不能越过浏览器选择及用户授权。获准而无音轨，则止诸轨并记败；否则启 `MediaRecorder`，先试 VP9/Opus，其次 VP8/Opus，再试浏览器所能之格式。实码率与尺寸或下于所请，须据 `getSettings()`、实际 MIME 与码率报之。

录段暂存内存。止钮止录；`stop` 事至，合 Blob，置下载链之地址、文件名并示之。用户须亲点下载。复录前撤旧对象网址；重绑或宿主终则止媒体轨、撤网址。

录制状态依次为请求中、录制中、停止中、可下载；用户撤权请则已取消；权拒、无音轨、捕获或录制之异则失败。`读取网页录制状态` 还结森文，至少含状态、宽、高、帧率、码率、类型、音轨数、错误。三元素须已在文树中，且为按钮、按钮、`a`；若阙或无效则接口调用即事故。异步权请与录制之败记入状态，不越 Wasm 边界。

用者先绑定，后使用户点击始录。接口不得伪造手势、暗启捕获、屏蔽提示或代用户选择来源。是否可分享页音亦受浏览器界面与安全上下文所制。
