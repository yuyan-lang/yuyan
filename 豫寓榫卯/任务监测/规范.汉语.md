# 任务监测接口 0.10.0

0.10.0 增加「问子役（查询差遣子任务）」（2026-11-02，提案 00073 第零期）：受任务标识「任务」（与「问行役」列表的标识同域），返回「子役果」：成功为「子役已列」，携带这个任务在执行器差遣账表里登了账的差遣子任务，「子役讯」按行号排；失败为「子役未得」携带「寓误」。每条「子役讯」带十四栏：所属（任务标识）、号（账表任务号，代乘四千零九十六加行；零主流程、负一调度空等、负二没登账）、父（派生时在跑的任务号）、名（派生时给的名字，空文为无名）、态（零空、一就绪、二在跑、三搁置、四等门、五等役、六已终）、等因（等门时是描述符乘六万五千五百三十六加关注事件，等役时是所等任务的号）、等起与开时（周期计数）、累计（在核周期累计）、切入（切入次数）、分配与存活（字节）、栈峰（最深栈字节）、采周（宿主读这一行时此刻的周期计数，用来算两次采样之间的处理器占用）。豫言虚机由启动器服务三百二十提供（游标逐个扫各任务的账表），执行器原语号为 344；裸机内核也提供；原生执行器直接读本进程账表；浏览器与诺驿返回「资源暂不可用」。壳命令「列出役」「析役」「观役」据此印树。

0.9.0 在「役存值」末位加一栏「栈用」（栈留里真用到的那部分字节：线程栈深加栈复制缓冲与栈缓存写到的最高字节），计入「自账」与常驻；旧栏的位次不变。

0.9.0 在「役存值」末位加一栏「栈用」（栈留里真用到的那部分字节：线程栈深加栈复制缓冲与栈缓存写到的最高字节），计入「自账」与常驻；旧栏的位次不变。

0.8.0 增加「问区域（查询任务区域分项）」，参数为「有」，返回「区域果」：成功为「区域已列」，每个任务一条「区用讯」，把「问役存」里的区域一栏按用途拆开——每条「区用讯」带标识、二十八项「区用项」（每项有用途名、切走字节数与预留字节数）与合计；切走是该用途累计从动态区域切走的字节（含预留），预留是其中经「留区域」切出、只碰开头一截的字节（也记在切走里）；合计等于各项切走之和，正常情况下等于「问役存」的区域一栏（大程序的模块字节在「始区」按模块补记）。豫言虚机由启动器服务三百零八提供，执行器原语号为 331；裸机内核也提供；原生执行器答本进程一条；浏览器与诺驿返回「资源暂不可用」。壳命令「析区域」据此印账。

0.7.0 增加「问役存（查询任务内存明细）」，参数为「有」，返回「役存果」：成功为「役存已列」，每个任务一条「役存讯」，把「问行役」里的常驻内存拆成固占（固定段折成二兆块）、住占（动态部分的自账折成二兆块再减已换出）、换出，以及代码、固用、低址、区域、栈留、模块、映像、栈图、堆活、堆配、堆游、自账与栈用各项，均为字节，另有装时（装入毫秒，虚机自身一条记累计）；栈用（2026-11-02 加在末位，旧栏位次不变）是栈留里真用到的那部分——线程栈深加栈复制缓冲写到的最高字节加栈缓存写到的最高字节；映像是链接期排好的全局对象，从包着它的那一块（区域或低址）里扣出来单列；固占加住占等于「问行役」的常驻。豫言虚机由启动器服务三百零五提供，执行器原语号为 330；裸机内核也提供（2026-11-01 起：固定段取自内核的固定块记账，动态部分取自内核已提交块记账与执行器状态格），裸机上的代码、换出与装时三项留待后续版本；原生宿主、浏览器与诺驿返回「资源暂不可用」，补齐留待后续版本。

任务列表逐条读取服务游标直至结束，记录区与处理器采样表随任务数增长。「问本役（查询当前任务标识）」与列表的本任务记录采用相同号域；执行器据此为本任务填入本地计算的已用堆。原生行在的籍号协议以籍号匹配，旧协议以宿主进程号匹配。

0.6.0 增加「问本役（查询当前任务标识）」，参数为「有」，返回与「问行役（查询任务列表）」标识同域的整数。YXZ3 户籍登记且持有本籍时答本进程籍号；YXZ1、YXZ2、独行与轩窗答本进程宿主进程号；豫言操作系统答当前内核任务句柄；诺驿、浏览器答负一。原生执行器原语号为 310。任务号域用于任务列表、子进程任务标识及打断任务；宿主进程号域用于列宿主进程、结束宿主进程及按宿主进程号发信号。

这是宿主提供真实运行任务采样的接口。`问行役` 返回 `任务已列` 携带任务列表，或 `任务未得` 携带系统错误。列表覆盖宿主当前实现的监测范围；首版节点只覆盖当前应用宿主进程，浏览器明确返回 `资源暂不可用`；豫言操作系统（裸机）列出系统里的全部任务（统计范围为“豫言操作系统任务”，经内核服务 46 取得）。只覆盖本进程的宿主不得把范围说成全系统任务列表。

`任务信息值` 依次保存标识、名称、统计范围、单调采样时间（微秒）、CPU 万分比、常驻内存字节和已用堆字节。CPU 按两次采样间实际用户与系统处理器时间之和除以墙时计算，一个核心满载为一万，多核可超过一万。负一表示该指标不可用；不得用零伪装未知指标。采样时间只用于同一宿主的差量比较。

同进程窗口共享进程统计，不能将进程占用分别归给每个窗口。常驻内存包括宿主与客体；堆内存是宿主运行时口径，不能声称只是客体或某个窗口内存。豫言操作系统（裸机）上每个任务各有一份执行器，已用堆是该任务执行器上次回收后存活字节、此后分配字节与当前游程已切出的字节之和，由内核代读（见客体二号平台接口规范的 `役讯`）。节点当前返回一条宿主进程记录。后续需补运行子任务登记、各平台监测及实时更新事件，界面必须显示范围。

0.2.0 起增加 `问寓概况`，返回 `概况已得` 携带 `系统概况值`（处理器核数、内存总字节、内存可用字节），或 `概况未得` 携带系统错误。豫言操作系统（裸机）的核数取内核服务 39，内存总量是内核开机时池里的空闲块数（服务 100），可用量是此刻的空闲块数（服务 45），都以 2 MiB 一块换成字节。处理器总占用由调用者把 `问行役` 各任务的 CPU 万分比相加得出，满载是核数乘一万。林檎（macOS）、林纳（Linux）原生已实现：林纳读 /proc/meminfo 的 MemTotal 与 MemAvailable；林檎取 hw.memsize 与 vm 页计数，可用量是空闲、预读、可清除与可换出的文件页之和乘页大小，与 MemAvailable 同义，不含要压缩才腾得出的匿名页。诺驿（节点）、浏览器与轩窗（Windows）暂返回 `资源暂不可用`。

0.3.0 起增加 `问虚存概况` 与 `设交换区`（[提案 00023](../../提案/00023-虚拟内存.汉语.md)）。`问虚存概况` 返回 `虚存已得` 携带 `虚存概况值`（页缓存字节、页缓存里有程序映着的字节、交换区总字节、交换区已用字节、开机以来的换出次数与换入次数），或 `虚存未得` 携带系统错误。`设交换区` 的参数是字节数，返回 `交换区已设` 携带设好后的交换区字节数（关掉为零），或 `交换区未设` 携带系统错误。豫言操作系统（裸机）的页缓存与交换区统计取内核服务 102；设置交换区由初始任务在数据盘上删掉旧的 `/交换区`、按大小（向下取整到 2 MiB，至多 2046 MiB）预分配新的并经内核服务 101 登记，零为关掉交换区，交换区里还有换出的块时报 `资源暂不可用`，数据盘空间不够报 `资源配额已尽`。节点、浏览器与原生系统没有页缓存与交换区，两者都返回 `资源暂不可用`。

0.4.0 起增加 `问数据盘` 与 `扩数据盘`（2026-10-14）；0.5.0（2026-10-24，议题 581）给 `数据盘概况值` 加「可用块数」。`问数据盘` 返回 `数据盘已查` 携带 `数据盘概况值`（设备字节、块字节、总块数、空闲块数、可用块数、节点总数、空闲节点数），或 `数据盘未查` 携带系统错误。设备字节是数据盘所在设备上数据区的字节数（2 TiB 以上只算前 2 TiB）；文件系统的总量由总块数乘块字节得出，已用以总块数减空闲块数为准，可用以可用块数乘块字节为准，用量的百分比按已用除以已用加可用（同 df）。`扩数据盘` 把数据盘的文件系统就地扩到设备末尾，返回 `数据盘已扩` 携带扩展后的总块数（已经用满设备时照常返回原来的块数），或 `数据盘未扩` 携带系统错误。豫言操作系统（裸机）的数据盘是初始任务挂载的 ext4，子任务的调用经远程原语转给初始任务；扩展时旧的组与文件不动，在末尾加整组，组描述块不够时打开 META_BG，最后在一个日志事务里改超级块（见 `豫言操作系统/裸机/文档/客体文件系统.汉语.md` 的“扩容”）。没有挂载数据盘报 `资源暂不可用`，文件系统只读报 `未获授权`，盘面格式不合报 `输入无效`，读写失败报 `宿主操作失败`。浏览器与没有 statfs 的宿主两者都返回 `资源暂不可用`。

原生系统（林纳、林檎）在宿主上量当前工作目录所在的卷（2026-10-24，议题 581）：林纳发 statfs 系统调用，林檎调 libSystem 的 statfs，路径都写“.”，所以壳所在目录在哪个卷就量哪个卷；设备字节报文件系统的总字节数（总块数乘块字节），空闲块数取 f_bfree，可用块数取 f_bavail，节点数取 f_files 与 f_ffree。诺驿（节点）用 fs.statfsSync 量同一卷，字段与原生相同，可用块数取 bavail。`扩数据盘` 在宿主上没有做法，返回 `资源暂不可用`。
