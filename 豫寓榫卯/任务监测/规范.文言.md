# 任务监测接口 0.13.0

〇点一三于陷阱账值增坏调一栏：坏系统调用 SIGSYS（林檎十二、林纳三十一），客就地入内核而号不合，宿主发之；虚机接之作客陷，惟终所陷之役。依信号之项由五为六（段错、总线错、非法指令、断点、算术、坏调），客陷之合等于六项之和；务三百零九之录由九十六字为百零四字。

〇点一二增「查陷阱账（查询核陷阱账）」，受「有」而还「陷阱账果」：得则「陷阱账已列」，一虚核一「陷阱账讯」，记核号、抢占、续行、客陷之合、依信号之五项（段错、总线错、非法指令、断点、算术）、最近客陷之任务号、信号号与出事之码偏；信号号零则此核未陷客，五项之和即客陷之合。虚机由启动器务三百零九供之，执行器原语号三百三十四；裸核与原生之宿无按核之陷阱账，还「资源暂不可用」；浏览器与诺驿亦还「资源暂不可用」。壳命「析陷阱」据此印账。

0.10.0 增「问子役（问差遣之子役）」（十一月二日，提案〇〇〇七三第零期）：受任务（与问行役之标识同域），以子役果还：成则子役已列，携此役于执行器差遣账表所登之差遣子役，子役讯依行号而排；败则子役未得，携寓误。每讯十四栏：所属、号（账表之号，代乘四千零九十六加行；零主流、负一空等、负二未登）、父、名（空文无名）、态（零空、一就绪、二在跑、三搁置、四等门、五等役、六已终）、等因（等门为描述符乘六万五千五百三十六加所关之事，等役为所候之号）、等起、开时（周期计）、累计（在核之累）、切入（次）、分配、存活（字）、栈峰（最深之栈字）、采周（宿主读此行时此刻之周期计）。虚机由启动器务三百二十供之，执行器原语号三百四十四；裸核亦供之；原生执行器径读本程账表；浏览器与诺驿告资源暂不可用。壳令「列出役」「析役」「观役」据之书树。

〇点九于「役存值」之末增一栏「栈用」（栈留中实触之分：线栈之深加栈复之缓与栈缓所书至深），入「自账」与常驻；旧栏之位不改。

〇点八增「问区域（查询任务区域分项）」，受「有」而还「区域果」：得则「区域已列」，一役一「区用讯」，分「问役存」之区栏依用途而列——每讯带标识、二十八「区用项」（项有用途之名、切走之字节与预留之字节）与合计；切走者，此用自区所切之累计（含预留）；预留者，其中以「留区域」所切、惟触其首之字节（亦在切走之中）；合计为诸项切走之和，常与「问役存」之区栏相等（大程之模字于「始区」依模补记）。虚机由启动器务三百零八供之，执行器原语号三百三十一；裸核亦供之；原生之执行器答本程一条；浏览器与诺驿还「资源暂不可用」。壳命「析区域」据此印账。

〇点七增「问役存（查询任务内存明细）」，受「有」而还「役存果」：得则「役存已列」，一役一「役存讯」，分「问行役」之常驻为固占、住占、换出，及代码、固用、低址、区域、栈留、模块、映像、栈图、堆活、堆配、堆游、自账、栈用诸项，皆以字节计，又有装时（装入之毫秒，虚机自录书其累）；栈用（十一月二日加于末位，旧栏之位不改）乃栈留中实触之分——线栈之深加栈复之缓所书至深加栈缓所书至深；映像者链时所排全局之物，自所包之块（区或低址）扣出而单列；固占加住占即「问行役」之常驻。虚机由启动器务三百零五供之，执行器原语号三百三十；裸核亦供之（十一月一日起：定段取内核定块之记，动者取内核已提交块之记与执行器之状态格），代码、换出、装时三项于裸核俟后版；原生之宿、浏览器与诺驿还「资源暂不可用」，补之俟后版。

役录循服务之游标，至尽乃止；录区与功采之表，随役数而增。「问本役（查询当前任务标识）」与录中己牌同域，执行器因而书己堆之实量。原生行在之新籍以籍相认，旧牒以宿主程号相认。

〇点六增「问本役（查询当前任务标识）」，受「有」而答整数，与「问行役（查询任务列表）」之标识同域。YXZ3 户籍既登且持己籍，答本程籍号；YXZ1、YXZ2、独行与轩窗答本程宿主号；豫言之土答当前内核任务柄；诺驿网览皆负一。原生执行器以三百一十为其原语号。任务之号用于行役之表、子程之牌与辍役；宿主之号用于列宿程、止宿役与循宿牌传信。

此为宿主供实运行任务之采之接口。`问行役` 返 `任务已列` 而载任务列，或 `任务未得` 而载系统错误。列含宿主今所实监测之界；首版节点惟含今客之宿主进程，浏览器明返 `资源暂不可用`；豫言操作系统（裸机）列系统中诸任务（统计之界为“豫言操作系统任务”，以核之服务四十六得之）。惟及本进程之宿主不得谓其界为全系统任务列。

`任务信息值` 依次存标识、名、统计之界、单调采时（微秒）、CPU万分比、常驻内存字节与堆已用字节。CPU 以两采间实用户与系统处理器时之和除墙时，一核全用为万，多核可逾万。负一谓指标不可用，不得以零伪未知。采时惟供同宿主之差量比。

同进程诸窗共其统计，不得将进程之用别归诸窗。常驻内存含宿主与客体；堆内存为宿主运行时之界，不得谓惟客体或单窗之存。豫言操作系统（裸机）上每任务各有执行器，已用之堆为其前次回收后存活之字、此后所分之字与今游程已切之字之和，由核代读（见客体二号平台接口规范之 `役讯`）。节点今返一宿主进程之录。后须补运行子任务之籍、诸平台监测与实时更新之事，界面必示其界。

〇点二起增 `问寓概况`，返 `概况已得` 而载 `系统概况值`（核数、内存总字节、内存可用字节），或 `概况未得` 而载系统错误。豫言操作系统（裸机）之核数取核之服务三十九，内存之总为核开机时池中空块之数（服务一百），可用为此时空块之数（服务四十五），皆以每块二兆易为字节。处理器之总用，呼者合 `问行役` 诸任务之万分比得之，全用为核数乘万。林檎、林纳之原生已具：林纳读 /proc/meminfo 之 MemTotal、MemAvailable；林檎取 hw.memsize 与 vm 页计，可用者空闲、预读、可清除与可换出之文件页之和乘页大小，与 MemAvailable 同义，不含须压缩乃出之匿名页。诺驿（节点）、浏览器与轩窗（Windows）暂返 `资源暂不可用`。

〇点三起增 `问虚存概况` 与 `设交换区`（[提案〇〇〇二三](../../提案/00023-虚拟内存.汉语.md)）。`问虚存概况` 返 `虚存已得` 携 `虚存概况值`（页缓存之字数、页缓存中有程所映者、交换区之总与已用、开机以来换出换入之次），或 `虚存未得` 携系统之误。`设交换区` 之参为字数，返 `交换区已设` 携设后交换区之字数（关则零），或 `交换区未设` 携系统之误。豫言操作系统（裸机）之页缓存与交换区之计取核务一百零二；设交换区由初始任务于数据盘删旧 `/交换区`，依其大（下取至二兆，至多二千零四十六兆）预分新者而经核务一百零一登之，零则关之；交换区中犹有换出之块则报 `资源暂不可用`，数据盘不足则报 `资源配额已尽`。节点、浏览器与原生之系统无页缓存与交换区，皆返 `资源暂不可用`。

〇点四起增 `问数据盘` 与 `扩数据盘`（十月十四日）；〇点五（十月二十四日，议五百八十一）给 `数据盘概况值` 加「可用块数」。`问数据盘` 返 `数据盘已查` 携 `数据盘概况值`（器之字数、块长、总块、空块、可用块、节点之总与空），或 `数据盘未查` 携系统之误。器之字数为数据盘所在器上数据区之字数（二 TiB 以上惟计其前）；文系统之总以总块乘块长，已用以总块减空块为准，可用以可用块乘块长，用量之百分依已用除已用加可用（同 df）。`扩数据盘` 就地扩数据盘之文件系统至器末，返 `数据盘已扩` 携扩后之总块数（已尽则返旧数），或 `数据盘未扩` 携系统之误。豫言操作系统（裸机）之数据盘为初始任务所挂之 ext4，子任务之呼经远程原语转初始任务；扩时旧组与文件不动，于末增整组，组描述块不足则开 META_BG，终于一日志事务改超级块。未挂数据盘报 `资源暂不可用`，文件系统唯读报 `未获授权`，盘面之式不合报 `输入无效`，读书败报 `宿主操作失败`。浏览器与无 statfs 之宿皆返 `资源暂不可用`。

原生之系统（林纳、林檎）于宿上量今所居之卷（十月二十四日，议五百八十一）：林纳发 statfs 之系统调用，林檎调 libSystem 之 statfs，径皆书“.”，故壳所在之目在何卷则量何卷；器之字报文系统之总字（总块乘块长），空块取 f_bfree，可用块取 f_bavail，节点取 f_files 与 f_ffree。诺驿以 fs.statfsSync 量同卷，其域同原生，可用块取 bavail。`扩数据盘` 于宿上无其实，返 `资源暂不可用`。
