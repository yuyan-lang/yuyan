# 满参递归优化初验

今实作递归完整调用之去柯里化。连受诸参之函数，若自用皆恰足其参，则立多参内工，外仍存原包装。递归步一并传参，省逐层闭包与间接调用。少参、过施、逸出为值者，皆守旧；夹有施术之抽象不越而合之。

原算法不改，新旧 Wasm 更番测五轮，各起 Node，含启动与即时编译。矩阵三百阶由五百一十五点三九三毫秒至二百六十二点三六四，省百分之四十九点一；百万数排序省百分之三十二点六；二百万数筛省百分之二十点四；数组填和省百分之五点七。单参斐波那契增百分之零点七，树增百分之二，未据此断为显著退步，原样本俱存。

冷缓存自举三代，费二十一点零八、二十一点一五、二十一点一二秒，皆未逾三十。种子与三代字节同；原生依规自举至四代，三、四代亦同。类型检查及诸回归皆过，验施术顺序、异常中止、捕获、逃逸、非尾递归与五万次尾递归。

此为首阶段，非诸函数之去柯里化皆成。常规非递归入口、已知调用直化、数值与数组专用表示，尚待后续。未可谓已至 C 之速。命令、数值、哈希与所限，详《满参优化结果.汉语.md》。
