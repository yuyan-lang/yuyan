# 诸语言较速与提速之议

今取六题：递归斐波那契、素数筛、矩阵乘、快速排序、满树、数组填和。以今本豫言原生与 WasmGC，较 OCaml 原生、C 原生及 C 入同一 V8。各先温一轮，复测五轮，验其退出及所印之值。编译不计，启动、即时编译与执行皆计。

递归、矩阵、排序三题，豫言 Wasm 耗时约为同引擎 C/Wasm 之五点七至九点八倍，为 OCaml 原生之四点四至十八点四倍。短题多费于宿主启动；豫言宿主约七十毫秒，不可据总时直言其内算迟若干倍。原生树题近 OCaml，优于此 C 实现；诸题之差不一，不可一数蔽之。

察矩阵之热处，见闭包反复造，间接调用相承，整数反复拆装。六百阶采样，热点约占百分之九十三点八，GC 约五点二；此为采样命中，非精确分时。全程宿主调用唯五，故非 JS 往返为其主患。又察源码，去柯里化与函数参数优化二入口，皆径还原式，未施其功。

乃作小试：矩阵算法不变，不变之参数外置，内惟递序与和。三百阶由零点五零九九二二秒至零点三一七三八三秒，省百分之三十七点八；六百阶由三点六七七八二五秒至二点零四五三二四秒，省百分之四十四点四。各为五轮中数，值皆同 C。此证其路可行，非谓编译器已自动施之。

先行之事：实作去柯里化，满参调用直达多参入口，部分应用仍留包装；外提循环不变参，明定调用直化，自尾递归化循环。次存数值表示，确定整数以 i64 行，惟多态边界装箱；数组按数值、布尔专用，守索引与别名之义。再次专闭包与构造器布局，省不逃逸之物；短任务别设常驻宿主，冷、热各记。原生堆之高峰另察，未可遽断为泄漏。

不改六十四位整数语义，不以失去边界检查换速。每次编译器语义相关之改，依仓规自举、验字节、查类型。冷自举三十秒以内之限仍守，并防他题显著退步。长计算入同引擎 C 两倍以内，可为后续目标，未可称今已至。

C 树逐物分配而释放，GC 语言不强迫临退出回收全堆；叶亦或共享，故非纯回收之比。OCaml 此次为原生且未启 Flambda；未测其 Wasm。诸题算法同，而对象表示异，所测为现有实现，非语言之天限。全数、命令、工具版本、原始记录与边界，详同目录《调查与提速方案.汉语.md》。
