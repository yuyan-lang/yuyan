# 首阶段：递归完整调用去柯里化

本阶段把已验证的参数/闭包优化方向落实到编译器。改动位于 `库/编译器核心/编译步骤/优化/跨文件优化/去柯里化。豫`，沿用既有默认开启的 `执行去柯里化优化` 开关；`-fno-func-uncurry` 可禁用。未修改用户基准程序的算法。

## 实测结果

单位：毫秒，五轮交替运行的墙钟中位数，包含新 Node/Worker 启动及 JIT。

| 程序 | 优化前 | 优化后 | 墙钟变化 |
| --- | ---: | ---: | ---: |
| 矩阵乘法 300×300 | 515.393 | 262.364 | **减少 49.1%** |
| 快速排序 1,000,000 | 504.663 | 339.935 | **减少 32.6%** |
| 素数筛 2,000,000 | 111.958 | 89.173 | **减少 20.4%** |
| 数组填和 2,000,000 | 89.673 | 84.521 | 减少 5.7% |
| 斐波那契 38 | 1096.358 | 1104.092 | 增加 0.7% |
| 满树深度 18 | 90.004 | 91.813 | 增加 2.0% |
| 启动基线 | 66.099 | 65.549 | 减少 0.8% |

本轮未观察到明显退步；斐波那契和树的主要递归函数只有一个参数，不属于本阶段加速目标，其小幅变化不作性能改善或统计显著回归的结论。树任务样本范围重叠且启动占比高。原始样本和范围保存在《满参优化汇总.json》及 CSV，不以首次试跑代替正式结果。

**完整冷缓存自举连续三代：21.08、21.15、21.12 秒，中位数 21.12 秒。** 均满足 30 秒门槛；与上轮 21.45 秒接近，不把这种跨批次小差异宣称为确定的自举加速。种子及三代输出逐字节一致，SHA-256 为 `74dd5a1f07a7fd889f3b7bd73fa7dd21c56ff1f53bcaff320d6c7883e67fc4da`。

此次收益来自编译器自动变换，矩阵源文件未替换为上一轮手工外提版本。它尚不足以宣称达到 C 性能；下一阶段应继续消除已知调用的间接调度，以及数值表示中的装拆箱。

## 变换与范围

对连续的单参数抽象，若递归变量的每次使用都是恰好提供全部参数的自调用，则生成一个多参数递归内工和保留原调用形式的外部包装。递归步一次传齐参数，减少逐参生成的临时闭包和间接调用链。外部包装仅在调用入口使用。

只有相邻 lambda 可以合并，中间有副作用或其他求值的表达式不会跨越。自调用参数仍按原有求值顺序转换；遇到内部部分应用、过量应用或把函数作为值传递，整个候选函数保持原实现。参数和捕获变量通过现有抽象绑定树操作重建，避免变量捕获。

当前前端不允许缺少显式参数的部分应用，但中间树和包装仍可能包含分步调用，因此这些边界依旧需要保护。新增《去柯里化边界》直接检查中间树的完整应用及回退行为；《满参递归》检查副作用、异常、外部包装、函数逃逸、捕获、非尾递归及五万次尾递归。

这不是全面的去柯里化：普通非递归函数的完整调用、跨模块直接入口、循环不变参数自动外提以及数值/数组表示专门化仍待后续实现。内工递归仍可能经一次间接调用，本阶段消除的是逐参数的调用链。

## 复现与验证口径

对照输入仍为前一轮六个未改写的基准程序。使用 `满参优化计时。豫` 交替运行前后 Wasm，每次新建 Node，零轮预热、五轮正式，逐次与 C 校验输出，包含启动及 JIT。原始数据以 `满参` 开头的 CSV 和 `记录/满参-*.txt` 保存。先前的参数外提源码实验没有用于本轮性能结果。

原生验证严格依次执行稳定编译器 → `yy2_bs` → `yy3_bs` → `yy4_bs`，第三、四代逐字节一致。`./yy` 及最终 `yy3_bs` 的编译器类型检查通过。最终编译器重新构建并通过满参递归、去柯里化边界、整数文本、短列态射、替换共享、癸象转义、进程等待七组 Wasm 回归。

最终 `yy3_bs` 禁用缓存重新生成矩阵 Wasm，与计时所用产物逐字节一致；同一编译器生成并运行原生《满参递归》回归也通过，覆盖参数副作用与异常顺序。

Wasm 冷自举继续使用独立 Node 进程、18 工、`--do-not-load-cache -c`，包含 JIT 和最终组装，未利用跨轮机器码预热。自举输出逐代比较字节。

```sh
./yy3_bs 性能研究/横向复测/满参优化计时。豫 --parallel -c -o yy满参计时
./yy满参计时 矩阵乘法 300
/usr/bin/time -p node 工具/节点网页汇编宿主/宿主.cjs yy满参自举种子.wasm 豫言编译器/入口。豫 --package-context .yybuild/豫构上下文/11.上下文 --target=wasmgc --parallel -j 18 --do-not-load-cache -c -o yy满参自举二代.wasm
```

基准新产物命名为 `yy满参斐波那契.wasm`、`yy满参素数筛.wasm`、`yy满参矩阵乘法.wasm`、`yy满参快速排序.wasm`、`yy满参结构.wasm`；旧产物为上一轮 `yy横比*.wasm`。上下文编号因工作区而异。
