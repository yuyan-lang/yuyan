# 前端任务合分实测

二〇二六年九月九日，以同一本机编译器、同源、同包上下文，开十八客，禁读阶段旧藏而仍导出中间物。所测为生编译器之时，非比 V8 与 Wasmtime 之执行。计时逐事行，无并行验证相扰。

生 WasmGC：合卷二试二十三点一七、二十二点三五秒，均二十二点七六；分阶二试十八点九三、十八点一六秒，均十八点五五，减约百分之十八点五。生 shadow 本机物：合七十三点六五秒，分六十八点七三秒，减约百分之六点七，此各唯一次，含 clang 与链接。

分阶多耗累计 CPU，而少耗墙钟。盖合卷须待依赖之前端皆毕，分阶则依赖之对应阶既毕，下卷即可进；并行所得胜启客与读藏之费。不可推为诸项目、诸并发数及逐客重启 Wasm 实例之定率。两式皆用新优先序，故此数不独表优先级之功。

今整卷三目标默认分阶，与旧本机共前端之途，至闭包而分。百八十二卷，合为三百六十五事，分为九百一十一事；不为新后端添旧 CPS 与逐卷机器码。`--frontend-tasks=combined` 仍可明选合卷，`--frontend-tasks=split` 明选分阶。

先收毕事而展新依赖，再于就绪者中依阶段择先：依赖、解析、检查并擦除、跨卷优化、闭包、正则、代码生成。同级守加入序，不夺在途客，不为未就绪者虚留槽。旧构建任务接口皆零级，新优先构建任务乃可显授其级。

同式两轮 Wasm 各同物。异式惟二百六十四条模式匹配诊辞及十六处字节长度异，其余 WAT 同；旧新鲜名计数受进程界影响，诊辞之异仍可见，不隐而称全同。两式产物各自编译全编译器，下一代 Wasm 同。shadow 之帮助同，C 去诊辞及其长度后同。优先级以单槽动态图实测，兼验同级、动态高位、受阻高位、依赖、限额、失败收拢。

旧 stable 不识当前包布局，重试亦败，乃以可信旧器经豫构备 yy2。默认值既改，增量固定点曾异，遂 touch 种子隔离旧藏重验，不以败为成。详命令、指纹、哈希与最终验证，见汉语篇及《验证摘要.json》。

隔离缓存后，最终 yy3、yy4 实物同，类型检查过。不授粒度而编全卷 WasmGC，依赖、解析、检查并擦除、跨卷优化、闭包各启百八十二事，终生成一事，默认分阶确已行。
