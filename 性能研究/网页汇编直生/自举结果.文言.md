# 正则直生回收式网页汇编之自举

自举已成：回收式网页汇编编译器读《豫言编译器/入口。豫》及所依诸卷，实生后器。串行之种子、二代与显式大堆产物，字节皆同。今唯测编译器自举，不取旧日斐波那契、数组与树之微测为据。

## 所测

源码既定，共一百七十模块。原生路线生本机编译器，回收路线生 Wasm GC 编译器。计时自进程起，包依赖分析、语法分析、类型检查、优化、闭包转换与成器。原生含 LLVM/Clang 编译链接；回收路线含客内 ANF/WAT 生成与宿主组装。

机为 Apple M5 Pro，arm64、macOS。引擎用 Wasmtime 48.0.1、Cranelift、copying。客器先预编译为本机 AOT，每测另起进程；引擎构建、下载与 AOT 编译之时不入此计。各配置各取一完整样本，编译缓存皆新，文件页缓存或已热。本任务诸编译测试不相并行，不锁核心与频率，故不以一机一例概诸境。

## 所得

| 路线与配置 | 串行 | 四进程 |
|---|---:|---:|
| 原生 LLVM | 185.11 秒 | 68.71 秒 |
| GC copying，默认堆，不内联 | 866.28 秒 | 596.36 秒 |
| GC copying，128 MiB，不内联 | 809.59 秒 | 未测 |
| GC copying，128 MiB，内联 | 未测 | 346.54 秒 |

显式大堆串行，耗时为原生之 **4.37 倍**；已测最快之 GC 四进程配置，耗时为原生之 **5.04 倍**。能自举矣，然尚未达迁移而无性能之损。内联四进程较默认对照兼改堆量与内联，不独以其所省归于内联。

两路线成器之末事不同，此测乃迁移后实用之全程，非独比回收或单条指令。原生守其运行时默认设置，GC 堆量如表，未强定二者同一硬限。

## 验证

串行固定点 SHA-256 为 `890a79a282a9f055dce69134ba9ac309de43d5a2b646bd3177956b8662e08740`。

二代客器实以四进程自举，一千一百九十一个任务皆成。同一二代输入，以默认配置及大堆内联配置生成之并行产物，字节亦同，SHA-256 为 `db4f9bf6ef038902511848dfa2e2a3e1832c858fdace34a945462e7b33949b21`。后者旧日志名 `yy回收四代.wasm`，乃异配置之产物，非另一次代际相生之测。串行固定点与并行配置一致性，各记其证。

并行所生之 Wasm 已验型，径行 `--help` 亦正常退出；独立直生工具已依今本重建。

原生二至四代与类型检查已验，三、四代相同。旧 `yy_bs_stable` 不识今之包布局，首级以豫构与已有编译器代行，其后依规自举。

初测 `time -lp` 于客毕后取附加资源统计，为沙箱所拒；墙钟、用户及系统时间已得，客产物无误。后测悉用 `-p` 并验成功退出。又初宿主旁取默认引擎，未用配置对象；早期 copying 成绩已正为默认堆。后以已成引擎之 getter 验一百二十八 MiB 与内联，不再徒记所设。凡中止与缺原生链接清单之败测，皆不入表。

## 所成与所费

后端在 `库/编译器核心/编译步骤/代码生成/网页汇编直生。豫`，目标 `--target=wasmgc`。直生 GC 引用、数组与结构体，不经 LLVM 生 Wasm，不用旧 C 虚栈。文串字面量启动时一造；拼文、UTF-8 与 JSON 扫描行于客。宿主唯供系统原语与组装，不代客行编译之术。

为全异常与可捕获续延之义，非尾调用之余算托于 GC 续延对象，以尾调用复之。其分配、取域与装箱解箱之费犹在；去 C 虚栈，非诸费俱亡。元组与构造器之布局尚可专型化；并行亦尚有空阶段进程之费，最终 GC 生码则集于一进程。

诊断版采样见 DRC 空闲块维护为热点，故取 copying 对照。默认堆串行之秒级日志，约有五百三十四秒在语法分析阶段，内含词法与缓存写入；此乃阶段估计，非函数级精确剖析。其后宜仍以完整自举验优化，不以此一实现断诸 Wasm GC 皆慢于 C。
