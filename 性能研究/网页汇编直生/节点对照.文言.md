# 节点引擎自举之较

以 Node 26.3.0、V8 14.6.202.34-node.20 行当前回收式网页汇编编译器，无须 Cranelift 或 `.cwasm`。串行首验 104.812 秒，复用模块而新立实例之次验 104.670 秒；原生行同源、同目标费 155.55 秒，网页汇编约省 32.6%。原生输出本机编译器另费 306.12 秒，此含异后端之功，不可皆归为引擎之差。

首二验计模块准备与执行，两验全进程共 209.97 秒。又以节点所生之器独立复自举，全进程 104.79 秒。两次节点输出、原生同目标输出、节点下一代输出，四物逐字同，固定点成。哈希与原时见 `节点验证摘要.json`。

V8 仍编本机码，非逐指令解释。其默认延迟编译、分层优化之费皆入执行之时；首轮模块准备六毫秒，非谓全编止此。次验更新输入文件时识，使豫言缓存各立，不强回收。节点桥唯行系统之务与转客值，编译诸术皆在客中。入口以豫言作，WAT 组装沿原宿主解析，不以 Cranelift 编执行码。

今验止串行，未备并行及诸程序全部接口。栈一百二十八 MiB，堆循 V8 默认；原生诸目标各一验，未锁频率与同等内存上限。开盖，系统示交流电而电池放电，无休眠之事。旧同步前之时数不可混入此验。详《节点对照.汉语.md》。
