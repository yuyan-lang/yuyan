# Wasm EH 直接调用版本的自举比较

ANF → WasmGC 已改为普通调用直接使用 Wasm 调用栈，非尾调用不再生成堆续延或恢复函数；尾调用使用 `return_call_indirect`，局部合并点使用 `block/br`。动态范围内的提前返回通过 `try_table/throw` 实现，用单调递增且不复用的 i31 标记区分不同入口。

这里的“无续延分配”指普通调用与局部合并点不再分配续延对象。数据、闭包和字符串仍使用 GC；实际抛出的异常也可能由引擎分配。此后端支持自举使用的动态范围内提前退出，不支持在捕获入口已经退出后恢复调用栈，也不支持完整的多次恢复续延。标记到达 i31 正数上限时陷阱退出，避免回绕后误认旧入口。

## 测量结果

同一份冻结后的编译器源码，170 个模块，每种配置一个完整自举样本，分别建立新的编译缓存身份；文件系统页缓存可能已热。计时期间没有同时运行本任务的其他编译。环境为 Apple M5 Pro、arm64、macOS，Wasmtime 48.0.1 / Cranelift / copying，初始 GC 堆 128 MiB，启用内联。未锁定 CPU 核心或频率。

| 后端 | 串行 | 四进程 |
|---|---:|---:|
| 原生 LLVM | 184.51 秒 | 72.24 秒 |
| WasmGC + EH 直接调用 | 435.36 秒 | 237.27 秒 |
| Wasm / 原生耗时 | 2.36 倍 | 3.28 倍 |

这是端到端迁移比较：原生生成原生编译器，包含 LLVM/Clang 和链接；Wasm 生成 Wasm 编译器，包含客体内的 ANF/WAT 生成及宿主 WAT 组装。Wasm 输入预先 AOT 编译，AOT 准备和引擎构建不计时；进程启动、加载、实例化和初始化计时。宿主没有替代客体运行编译算法。两条路线没有使用相同的硬内存上限。

旧堆续延四进程的历史样本为 346.54 秒，同样使用 128 MiB 初始堆和内联；本轮 237.27 秒，减少 31.5%。历史串行大堆样本为 809.59 秒，但未开启内联，不能把本轮串行的全部改善归因于 EH。历史样本的编译器源码和调用栈配置也不同，这些是实现前后的比较，不是只切换一个选项的严格消融实验。旧记录保留在 `自举结果.汉语.md`。

## 正确性

- 原生生成并行种子 `yy异常种子.wasm`。
- 种子在 Wasm 中完整串行自举，生成 `yy异常串行二代.wasm`，正常退出，435.36 秒。
- 将第二代 AOT 编译后，用其完成四进程自举，1191 个任务成功，生成 `yy异常并行三代.wasm`，正常退出，237.27 秒。
- 第三代与原生生成的并行种子逐字节一致，SHA-256 为 `4969ad596a6b3acc0c9c3f468a2322021050a7b31a9396592c30591a2a14a73e`。这形成了经串行、并行两次自举返回同一产物的闭环。
- 串行第二代与并行产物字节不同，分别保留摘要，不把不同调度下的产物混称为字节一致。
- 原生 `yy3_bs`、`yy4_bs`、本轮原生四进程产物逐字节一致，编译器类型检查通过。旧 `yy_bs_stable` 首级命令仍因当前包布局无法找到标准库失败；诊断后使用 `yy豫构` 与已有 `yy3_bs` 生成 `yy2_bs`，随后执行规定的二至三代、三至四代命令。

## 调用栈与诊断

第一次尝试在 Wasmtime 默认 512 KiB 栈限额下出现 `call stack exhausted`。直接调用仍需要容纳编译器的非尾递归。复制宿主现配置 64 MiB Wasm 栈限额与 128 MiB `async_stack_size`，实际执行放在 128 MiB 栈的独立 pthread 中，主线程等待，不并发执行原生豫言运行时。初始 GC 堆仍为 128 MiB。

只提高 `max_wasm_stack` 的中间尝试被引擎配置约束拒绝；随后同步提高 `async_stack_size`。两次失败记录单独保存，不纳入有效耗时。

## 仍然存在的成本

完整串行日志按秒级标记累计：EH 语法分析约 278 秒，原生约 49 秒；跨模块优化约 23 / 6 秒；闭包转换约 20 / 4 秒。这是阶段定位，不是精确的函数级采样。Wasm 的 ANF 和最终生成集中在最后一个阶段，因此不能用前面标记中的零秒解释为没有执行这些工作。

逐字符字符串对象、链表与构造器包装、通用 eqref 值表示和间接调用仍在。并行仍调度旧 ANF/代码生成的空任务，最终生成仍单进程。本次没有同时改动这些部分。当前仍不满足迁移后无性能损失的条件。

## 复现

宿主构建见 `../../工具/网页汇编宿主/复制回收构建.汉语.md`。上下文编号和链接清单为本机路径，换环境时使用对应的豫构产物。

```sh
# 当前原生编译器生成种子；准备步骤不计入 Wasm 自举耗时。
./yy3_bs 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc --parallel -j 4 -o yy异常种子.wasm
YY_WASM_GC_INLINE=1 ./yy网页汇编复制宿主 \
  --预编译 yy异常种子.wasm yy异常种子.cwasm

# touch 建立新编译缓存身份，保留 AOT 字节。
touch yy异常种子.cwasm
YY_WASM_GC_INLINE=1 /usr/bin/time -p ./yy网页汇编复制宿主 \
  --运行预编译 yy异常种子.cwasm 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy异常串行二代.wasm

YY_WASM_GC_INLINE=1 ./yy网页汇编复制宿主 \
  --预编译 yy异常串行二代.wasm yy异常串行二代.cwasm
YY_WASM_GC_INLINE=1 /usr/bin/time -p ./yy网页汇编复制宿主 \
  --运行预编译 yy异常串行二代.cwasm 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc --parallel -j 4 -o yy异常并行三代.wasm
cmp yy异常种子.wasm yy异常并行三代.wasm

cp yy3_bs yy异常原生基线
/usr/bin/time -p ./yy异常原生基线 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --native-link-inputs "$PWD/yy自举原生链接清单" \
  --target=llvm -o yy异常原生串行
touch yy异常原生基线
/usr/bin/time -p ./yy异常原生基线 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --native-link-inputs "$PWD/yy自举原生链接清单" \
  --target=llvm --parallel -j 4 -o yy异常原生并行
```

原始输出及时间、失败诊断、阶段估计、构建与产物摘要均在 `异常自举记录/`。部分进度写入 stderr，故相应的“时间”文件也包含阶段日志；末尾的 `real/user/sys` 为完整计时。
