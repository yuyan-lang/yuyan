# Cranelift、V8 与 native 的同目标自举对照

**本次当前实现的排序为：V8 最快，native 其次，Cranelift/cwasm 最慢。** 三者均串行编译同一份源码、生成相同的 WasmGC 编译器，计时包含完整进程启动、加载、前端、代码生成及 WAT 组装。Cranelift 输入已提前 AOT；V8 每轮使用独立进程，其延迟编译和分层优化时间计入执行。

| 执行路线 | 第一轮 | 反向复测 | 两轮均值 |
|---|---:|---:|---:|
| Wasmtime / Cranelift，`.cwasm` | 301.77 秒 | 226.91 秒 | **264.34 秒** |
| Node / V8，直接加载 `.wasm` | 81.28 秒 | 75.74 秒 | **78.51 秒** |
| native，`--target=wasmgc` | 117.49 秒 | 107.78 秒 | **112.64 秒** |

按两轮均值，V8 比 native 少用约 **30.3%** 时间，速度约 **1.43 倍**；Cranelift 耗时约为 native 的 **2.35 倍**、V8 的 **3.37 倍**。这里包含各自的 GC 和宿主桥接成本，未分别归因到机器码、GC 或跨宿主调用，不能把倍数推广成引擎固有差距。

## 配置与验证

- 源码提交 `8860c57b`，三条路线使用相同包上下文及同一份编译器源码，不启用 `--parallel`；每次通过输入可执行文件或模块的 mtime 刷新编译缓存身份。
- Cranelift：Wasmtime 48.0.1，copying GC，**2048 MiB 初始堆**，`YY_WASM_GC_INLINE=1`，使用文件映射加载 AOT。AOT 从与 V8 相同的 Wasm 文件生成。
- V8：Node 26.3.0 / V8 14.6.202.34-node.20，默认延迟编译、分层优化及 GC，128 MiB worker 栈；`YY_NODE_REPEAT=1`，没有同进程模块复用。串行不排除 V8 内部的后台编译或 GC 工作。
- native：当前原生编译器副本 `yy三路原生`，生成目标同为 Wasm。没有人为统一三者的内存上限，也没有锁定 CPU 频率或清空文件页缓存。

六次输出均逐字节一致，SHA-256 为 `415099fde18db7e5bef1866a07bf4f1a5ea3cbb72df7e277db993a23a7dfc0c0`，也与先前已验证可继续自举的 Node 串行产物一致。

AOT 准备另耗时 **78.32 秒**，不计入表中的 `.cwasm` 执行时间。不能据此表把 AOT 冷准备视为免费；本次没有使用它的时间与其他轮次随意拼成“平均冷启动”。

## 运行顺序与休眠审计

第一组顺序为 Cranelift、V8、native，区间为 **20:37:56–20:46:17**。系统于 **20:46:52** 首次进入合盖休眠，所以第一组三项均在休眠前完成。

最初的反向复测受到 Sleep/DarkWake 及长休眠污染，native 未完成即被中断，退出 130；其 1154.68 秒不参与比较。经已有执行会话中断后，检测到重新开盖及充电，再从新的编译缓存身份开始。有效反向顺序为 native、V8、Cranelift，区间为 **21:10:21–21:17:40**，未检测到休眠事件。

本机为 Apple M5 Pro、48 GiB、macOS arm64。开始系统报告 AC Power、63% 电量且 discharging；有效复测结束为 AC Power、54% 且 charging。期间没有本任务其他构建或采样与正式运行并发。第一轮与复测的绝对耗时差异明显，尤其是 Cranelift，因此保留范围，不只挑最好成绩。两次观测不足以给出稳定统计置信区间；结论仅代表当前实现和配置。

## native 普通自举是另一种工作量

前一组试验中，native 生成本机编译器为 **306.12 秒**，见 [Node 对照](节点对照.汉语.md)。它还执行原生路线的后续变换、LLVM 编译和链接，与本表统一输出 Wasm 的任务不同，故不混入本表或据此计算引擎倍数。同步 yybs 前的其他成绩也不混入本次均值。

## 复现与原始数据

先按 [Cranelift 宿主构建](../../工具/网页汇编宿主/复制回收构建.汉语.md) 和 [Node 宿主说明](../../工具/节点网页汇编宿主/说明.汉语.md) 准备运行器。三条命令使用同一个入口、上下文和目标；每轮更新对应输入文件 mtime。上下文编号为本机示例。

```sh
# 单独准备，计时不纳入 .cwasm 执行。
YY_WASM_GC_HEAP_MB=2048 YY_WASM_GC_INLINE=1 \
  ./yy网页汇编复制宿主 --预编译 yy三路种子.wasm yy三路种子.cwasm

touch yy三路种子.cwasm
YY_WASM_GC_HEAP_MB=2048 YY_WASM_GC_INLINE=1 caffeinate -i /usr/bin/time -p \
  ./yy网页汇编复制宿主 --运行预编译 yy三路种子.cwasm \
  豫言编译器/入口。豫 --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy三路克兰.wasm

touch yy三路种子.wasm
YY_NODE_REPEAT=1 caffeinate -i /usr/bin/time -p \
  ./yy节点网页汇编宿主 yy三路种子.wasm \
  豫言编译器/入口。豫 --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy三路节点.wasm

touch yy三路原生
caffeinate -i /usr/bin/time -p ./yy三路原生 \
  豫言编译器/入口。豫 --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy三路原生.wasm
```

机器可读耗时、配置和产物校验和见 [三路验证摘要](三路验证摘要.json)。原始本机记录为根目录 `yy三路*时间.txt`、`yy三路休眠事件.txt` 和 `yy三路复测休眠事件.txt`，按生成物忽略。本次仅新增测量记录，没有修改编译器或宿主实现。
