# 本次改动的审阅顺序

先看通用原生优化，再看 WasmGC 后端及宿主，最后核对性能结论。清理仅整理审阅材料和忽略生成记录，没有修改已验证的编译器实现。

## 1. 通用优化

以下路径均相对于仓库根目录。

| 文件 | 重点 |
|---|---|
| `库/编译器核心/编译数据/抽象绑定树结构/抽象语法树/抽象语法树基础操作。豫` | 叶节点共享：已有绑定变量、无子表达式的普通节点直接返回原节点。 |
| `库/编译器核心/编译步骤/总体过程/编译文件缓存工具。豫` | 删除中间树内存缓存根的接口；磁盘缓存保留。 |
| `库/编译器核心/编译步骤/总体过程/分布编译步骤。豫` | 缓存释放时机，以及原语内联索引写入；其中 Wasm 阶段裁剪属于下一组。 |
| `库/编译器核心/编译步骤/优化/跨文件优化/常量内联。豫` | 小型非递归原语包装只在调用位置内联。 |
| `库/标准库/数据结构/多态列。豫` | 线性反转；当前 yybs 已有同一优化，本分支 diff 仍含此项。 |
| `库/标准库/数据结构/字符串术。豫` | 字节级前后缀判断与 UTF-8 边界。 |

## 2. WasmGC 生成

- `库/编译器核心/编译步骤/求值正则变换/无类型正则变换。豫`：延后闭合的有名 ANF 策略；原生入口仍选择原策略。
- `库/编译器核心/编译步骤/代码生成/网页汇编直生。豫`：GC 类型、局部变量、名字索引、EH、尾调用及 WAT 输出。
- `工具/网页汇编直生/运行时.wat`：客体运行时。
- 命令行与主程序生成入口的 `--target=wasmgc` 接入，以及 `库/构建基础/并行编译。豫`、`单一编译工作。豫` 的 Wasm 模块阶段合并。

动态提前退出使用 Wasm EH；不支持捕获入口退出后恢复或多次恢复执行栈。具体边界见 `工具/网页汇编直生/说明.汉语.md`。

## 3. 宿主与原有 WASI 路线

`工具/网页汇编宿主/` 包含宿主、GC 引用与原语桥接、Wasmtime 构建补丁。`运行时支持库/网页汇编/`、C 栈检查及 LLVM 网页汇编目标中的改动属于原有线性内存路线的自举修复，不能与直接 WasmGC 的性能改动混为一谈。`测试/网页汇编/` 的 `.成功` 文件是期望输出，应保留；`宿主边界.wat` 是手写测试，不是生成物。

构建步骤见 `工具/网页汇编宿主/说明.汉语.md` 和 `复制回收构建.汉语.md`，入口目标在根 `Makefile`。

## 4. 验证与记录

- [最新 Wasm 对照](优化结果.汉语.md)：已缓存输入 AOT 的自举口径及限制。
- [最新原生对照](原生主线对照.汉语.md)：相同源码与当前 yybs 比较。

`.gitignore` 仅对指定实验目录排除原始日志、采样、生成 WAT 和逐轮样本。这些文件仍在本机原位置，报告中的原始记录路径仍可用于本地复查；克隆代码后不会自动获得这些原始文件。实现、回归测试、复现源码、构建补丁及报告均保留在审阅范围。历史报告按原实验时间保留，最终结论以上面两份最新报告为准。

## 同步 yybs 后的验证

同步保留主线独立编译阶段和阶段缓存格式，将缓存释放及 Wasm 阶段入口接入新流程。宿主补齐小数精确表示、源码字符串表示、源码数字名及源码可用名四个原语；独立生成器改用阶段缓存解码。冲突解决后，原生三代、四代一致，类型检查通过；Wasm 自举产物与同步后的种子一致，宿主及独立生成器构建通过。首级仍因旧稳定器不识别包布局而使用已有工作编译器引导。性能报告记录的是同步前的实测，未重新测量合并后的性能；新验证哈希见 `验证摘要.json`。
