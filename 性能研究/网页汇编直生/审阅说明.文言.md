# 此改之阅序

先阅通法，次阅网页汇编与宿主，终核其验。今惟整其阅材、别其生成物，不改已验之编译器。

通法六处：抽象语法树基础操作共其不变叶；编译文件缓存工具去无用根；分布编译步骤定其释放之时；常量内联展薄原语之调用；多态列以首缀反转；字符串术按字节察前后缀而守字符界。反转今主线已有，勿重计其功。

网页汇编之法：无类型正则变换留名至生成局部；网页汇编直生作 GC 类型、名索引、EH、尾调用与文串；运行时.wat 行客体原语。动态提前退出可行，捕获入口已退而复其栈、或复之再三，今不支持。

宿主、回收桥接、原语及 Wasmtime 补丁在 `工具/网页汇编宿主/`。旧 WASI 线性内存之自举修复在原运行时与 LLVM 网页汇编路线，勿混为直生之优化。测试之 `.成功` 为所期输出，`宿主边界.wat` 为手写测试，皆存之。

新验见《优化结果.汉语.md》《原生主线对照.汉语.md》，原时与产物哈希简存 `验证摘要.json`。巨录、采样与生成物以指定忽略规则留本地，不删除；克隆代码则无此原录。法、测试、构建与报告皆入阅。诸旧报告存其时义，新结论以前二篇为准。逐文件之阅序见《审阅说明.汉语.md》。

同步主线后，独立诸阶段与新缓存之制皆存，去根之法与网页汇编入口接之。宿主补四种源码格式化原语，独立生成器循阶段解码。原生三、四代同而类型检查过，网页汇编自举亦同新种子；宿主与独立生成器皆成。旧稳定器不识包布局，首级仍以已验之器引之。诸性能数字为同步前之验，不谓合并后已复测；新哈希见 `验证摘要.json`。
