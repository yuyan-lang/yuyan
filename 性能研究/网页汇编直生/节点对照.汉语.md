# Node/V8 编译器自举对照

**Node/V8 能直接运行当前 WasmGC 编译器，并完成自举，不需要 Cranelift 或 `.cwasm`。** 本机串行同目标对照中，V8 约 104.8 秒，native 155.55 秒，V8 耗时减少约 32.6%。这不是解释器结果：V8 仍会生成机器码，默认延迟编译和分层优化的成本计入执行阶段。

## 结果与口径

| 运行方式 | 生成目标 | 耗时 |
|---|---|---:|
| Node/V8，首轮新模块 | WasmGC 编译器 | 104.812 秒 |
| Node/V8，同 worker 复用模块、新实例 | WasmGC 编译器 | 104.670 秒 |
| native，同源码同目标 | WasmGC 编译器 | 155.55 秒 |
| native，通常的原生自举 | 本机编译器 | 306.12 秒 |
| Node 运行自己生成的下一代，独立进程 | WasmGC 编译器 | 104.79 秒 |

前两项为模块准备加实例化及执行的轮内时间。两轮由同一个豫言入口启动 Node worker，整个进程总计 209.97 秒，轮内合计约 209.48 秒；约 0.49 秒差额包括入口、worker 启动和轮间处理。其余三项由外部 `time -p` 测完整进程。下一代独立进程结果与前两轮一致地落在约 105 秒。

V8 首轮模块准备约 6.45 毫秒，但这不代表全部机器码只需几毫秒：本机 V8 默认开启 `wasm-lazy-compilation`、`wasm-tier-up` 和 `wasm-dynamic-tiering`，后续编译与优化发生在约 104.8 秒执行期间。第二轮保留模块和引擎状态，重新实例化，刷新输入 Wasm 的 mtime，使豫言模块编译缓存独立；没有强制 GC。两轮各有 8,228,097 次宿主接口调用。

比较引擎应优先看同目标的 155.55 秒，而不能把原生输出 LLVM/本机代码的 306.12 秒差额全部归给 V8。这里使用同步 yybs 后的当前源码；先前 112 秒的原生串行结果属于同步前版本，不能混用。

## 功能验证

下列四个文件逐字节一致，SHA-256 均为 `415099fde18db7e5bef1866a07bf4f1a5ea3cbb72df7e277db993a23a7dfc0c0`：

- V8 首轮输出 `yy节点正式一.wasm`。
- V8 复用模块的第二轮输出 `yy节点正式一.wasm.第2.wasm`。
- native 生成的同目标输出 `yy节点原生同目标.wasm`。
- 将 V8 首轮产物作为编译器重新自举得到的 `yy节点下一代.wasm`。

这同时验证了跨引擎输出一致性，以及 Node 生成的编译器能在 Node 中继续自举到固定点。此次没有修改编译器核心；新增豫言命令行入口、Node 宿主适配和 GC 值桥接模块，入口构建及 JavaScript 语法检查均通过。

## 实现与限制

`工具/节点网页汇编宿主/入口。豫` 是命令行入口；`宿主.cjs` 使用 Node 文件和子进程 API；`值桥接.wat` 通过同形 GC 类型转换 V8 不透明对象。桥接模块的线性内存只用于复制宿主字节，编译器对象仍在 WasmGC 堆上。源程序解析、类型检查、优化、ANF 和 WAT 生成均由 Wasm 编译器执行。最终 WAT 组装沿用 `yy网页汇编宿主 --组装` 的解析入口，它不为编译器生成 Cranelift 机器码。

当前适配覆盖本次串行自举所需接口，不支持并行调度，也不代表所有程序的运行时接口已经齐全。包上下文须先由豫构生成，Node 只复用内容相同的既有上下文。V8 worker 栈为 128 MiB，GC 堆使用 V8 默认配置，未与原生强制相同内存上限。

环境：Apple M5 Pro、48 GiB、macOS arm64；Node 26.3.0，V8 14.6.202.34-node.20。源码提交为 `8860c57b`，两个输入编译器均对应同步后源码。测试全程开盖，开始和结束系统均报告 AC Power，同时电池状态为 discharging；未锁定频率。自 20:11:21 起的审计未发现 Sleep/DarkWake/Wake 事件。本任务没有其他构建或采样与正式计时并发。native 每种目标各一个样本，结果不提供统计置信区间或跨机器保证。

机器可读记录见 [节点验证摘要](节点验证摘要.json)。原始本机记录位于仓库根目录的 `yy节点*时间.txt`、`yy节点引擎配置.txt` 与 `yy节点休眠事件.txt`，按生成物忽略。

## 复现

先按 [宿主说明](../../工具/节点网页汇编宿主/说明.汉语.md) 构建。下列上下文编号为本机示例。

```sh
cp yy同步种子.wasm yy节点测量种子.wasm
YY_NODE_REPEAT=2 caffeinate -i /usr/bin/time -p \
  ./yy节点网页汇编宿主 yy节点测量种子.wasm 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy节点正式一.wasm

cp yy3_bs yy节点对照原生
touch yy节点对照原生
caffeinate -i /usr/bin/time -p ./yy节点对照原生 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy节点原生同目标.wasm

cmp yy节点正式一.wasm yy节点原生同目标.wasm
```

V8 的编译与优化机制可参阅 [V8 官方说明](https://v8.dev/blog/wasm-speculative-optimizations)；子进程适配使用 [Node 的 child_process API](https://nodejs.org/api/child_process.html)。本报告速度结论来自本机实测。
