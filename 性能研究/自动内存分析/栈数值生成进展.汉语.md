# 从 ANF 自动生成非 GC 栈私有函数

本轮新增两个豫言模块，尚未导入默认统一后端：

- `网页汇编栈表示证明。豫`：对合法 SSA 区分完整整数、布尔、单元和数组地址，验证原语实参、返回值、分支合流、数组元素及静态调用签名。引用不能写入数值数组，整数不能直接假定为布尔。签名和封闭调用图须由上层组合验证，单独通过表示检查不等于分配安全。
- `网页汇编栈数值生成。豫`：消费上述证明，自动生成 i64 数值、i32 数组地址的私有函数。数组读写内联生成范围检查和线性内存 load/store；分支、普通调用、尾调用和自尾递归由 ANF 生成。自递归先准备全部参数，再逆序赋值，保留交叉依赖。支持非连续参数编号。

根数组必须是函数第一条指令，使用入口预先初始化的帧参数。根函数自递归暂时拒绝，防止重新分配和初始化被错误消除。私有子函数不能创建数组。公开入口、运行时类型守卫、容量失败时的 GC 后备和完整调用图资格尚未连接；此时不能把生成器直接作为安全的默认后端启用。

`栈表示证明。测试。豫` 的 20 项正反例通过。`栈数值生成。测试。豫` 从 ANF 构造填充、求和、尾递归参数交换及非连续参数函数，算法 WAT 全部由新增生成器产生；仅测试入口分配、清零和导出手写。

生成夹具通过 128 项执行检查，包括百万次尾递归、奇偶次数的参数交换、i64 极值、100 组确定性随机数组的模 2^64 求和、负索引、超 wasm32 索引、数组越界及陷阱后再次执行。原始记录见 `栈数值自动生成验证.json`。两个新模块的类型检查通过；最后一轮收紧调用签名后重新编译，生成 WAT 与已验证夹具逐字节一致。

本轮没有修改默认代码生成路径，未更新性能成绩，也不把此前原型成绩当作自动后端成绩。上轮完整自举结果仍适用于上轮默认编译器；新增生成器启用后必须重新完成完整自举、回归和冷缓存性能验收。下一步连接组合证书、公开包装入口、初始化和 GC 后备，再把范围证明与地址归纳接入自动生成。
