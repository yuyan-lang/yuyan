# 自动非 GC 栈的封闭调用证明

用户已明确允许自动 stack allocated non gc memory。保持自动推断、原公开 ABI 和 GC 后备，不要求源代码添加所有权或局部性标记。

新增 `网页汇编栈封闭证明。豫`。它用函数名散列表、参数数量、反向调用边和工作列表证明调用链封闭：未知原语、动态调用、宿主调用、额外数组分配及尚未建模的控制形式均拒绝；允许封闭的互递归，不声称函数终止或无陷阱。拒绝结果沿反向调用边传播，每个函数最多由可用转为拒绝一次。每个函数限制 256 个局部值，超过限制保守拒绝。

根函数只允许指定 SSA 数组创建点，子函数不允许创建数组。该证明必须与现有不逃逸、整数元素证明组合，不能独立推出栈分配安全。整数装箱等 GC 分配并未被这层证明排除；它限制的是额外数组分配和可重入效果。

新增 20 项测试，覆盖封闭递归、污染递归、未知目标、动态调用、间接宿主调用、实参数量、重复函数名、分配点和额外分配。特别检查了数组没有传给宿主时仍拒绝宿主调用。Wasm 测试已通过。

分配诊断通过 `--debug-print-add 内存分配` 输出组合证明结果。实际快速排序的分配点通过不逃逸、整数元素和封闭调用检查。该诊断仍明确写出“仍为 GC，栈代码生成尚未接入”；没有把资格证明伪装成自动栈分配已完成。

地址递增排序原型进一步通过 6,916 组逐元素对照，共比较 156,712 个元素：长度 0..7 的全排列、500 组确定性随机数组及其子区间、重复值、完整 i64 极值和边界调用。与原 GC 实现及独立 JS 排序参考一致。原始结果见 `非GC栈逐元素验证.json`，测试夹具 `yy栈逐元素夹具.wat` 的额外导出只用于验证。

仍待完成：把组合证明接入栈入口与 GC 后备生成，自动传递栈顶，验证宿主边界及完整自举性能。当前性能证据仍属于人工 WAT 原型，不代表默认编译器已自动生成该优化。

## 验证与冷自举

按仓库规定完成稳定编译器→二代→三代→四代本机自举；三、四代逐字节一致。`./yy` 类型检查和 `./yy3_bs --type-check-only --parallel` 均通过。Wasm 种子、二代、三代和再次复测产物逐字节一致。

启用 `--do-not-load-cache`、18 个工作线程，完整 Wasm 自举墙钟时间依次为 36.37、27.09、26.18 秒。首轮超过 30 秒，不删除该样本，不能声称已稳定达标。旧递归形态编译器对同一份新源码的对照为 24.94 秒；它也生成相同产物。这几次测量不足以把差异归因于某个具体优化或系统因素。历史 22 秒成绩不能替代当前源码的验收。

## 初始化优化复测

五个新进程，各六轮，轮换版本顺序，输入四百万元素。全部校验和 6000002。首轮中位数与其余二十五个样本的中位数分开记录。计时包含排序测试内部的数组分配、清零/填充及排序，排除程序启动和结果打印。

| 原型 | 首轮 ms | 热轮 ms |
|---|---:|---:|
| 原 GC |56.515|44.514|
| 非 GC 栈＋地址递增 |48.590|36.431|
| 再省去冗余初始化 |47.698|36.009|
| 再向量化填充 |47.748|35.825|
| C/Wasm |43.700167|33.812750|

最快原型热轮较 GC 减少约 19.5%，仍比 C 慢约 6.0%。省去清零以完整覆盖初始化为前提，向量填充只针对满足守卫的入口；不能推广到未经证明的数组。原始记录见 `非GC栈初始化复测.json`。这些改动仍是人工 WAT 原型，尚未成为自动代码生成规则。
