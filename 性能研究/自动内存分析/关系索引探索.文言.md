# 循环关系与索引之界

今探排序之迟，未改默认编译器。所试乃生成之网页汇编，不可谓豫言已得其利。无久留私缓冲，不改数组之形、公约及排序之法。

尾递之参，有值不变者。试省其读写三十二对，四百万项旧五十三点八九九毫秒，新五十四点二三五，稳态无益，故暂不入。

另设私门，先验零不大于存放序数，存放序数不大于扫描序数，扫描序数不大于上界，上界不大于二之三十二次方减一。不合者仍入旧门。扫描至上界即止；未至而进一，必不逾界。存放或止或进一，亦不逾新扫描之数。故循环所用索引皆可纳于无符号三十二位。

据此唯省三处宽度之验，数组自身之界悉存。门前之验不读数组、不生陷阱；旧门及零轮之义仍全。枢轴仍许全宽整数。

百万项旧十三点零零三毫秒，新十一点七二五；四百万项旧五十四点一六八，新四十八点四五七；八百万项旧一百一十八点八七一，新一百零六点五六八。主试五进程交替，各六轮，首轮别录，余取中数。规模复测三进程，其间曾另行边界之验，未录是否同时，故唯为旁证，正式入编译器后须独占复测。四百万项约省百分之十点五，仍未及前试 C 之三十三点三四毫秒；今未复测 C，不立新比例。

常值数组七千九百八十六例，返值与失败消息皆同。异值数组一万五千九百七十二例，兼验全组及失败前所写，亦皆同。长度取零、一、四，诸参兼及负数、全宽两端及三十二位之界。原始数据、补丁与摘要具存。

欲入编译器，须于正则中推诸参关系，逐支逐回边验其保持，不可以函数名或排序之形代证明。先证不溢，再论加一；尾参须同时代入。所省之验唯属于守卫私门，事实不可漏入旧门。亦须限分析与克隆之量，复验自举时限及程序之义。今得方向与实证，未成通用规则，远志未竟。
