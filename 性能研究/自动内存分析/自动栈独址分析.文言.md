# 栈索独址之析

既有址影，今析数值之用。索唯供寻址与可推之尾递，则存其址而省其数；若以索算所写之值，则数仍存。源码毋须手注，诸函之约不改。

此析唯施于已证必进之单步。先取诸址参为候，自条件、写值、须存之术及递归实参追其数用；有用者去之，再析至定。唯无用加减乘与比较可删，读写与除法皆存，事故之次如故。止时以址减组基，复其索；扫描之终预为址。此术赖既有非负界证与六十四 MiB 容量之限，不可泛施于任意整数。

新数新址皆先求，后逆次赋之，以守尾参并赋之义。求和可省数索，填充以长度减索，故不可省。仿射未知则重算址，所需之数术亦存。

## 验与效

生成器差分一万零四百二十六组，检二十八万一千三百九十四项；真排序六千九百一十九组，分区一万零二百八十七组，共检二十七万零三项。异帧、交索、负偏移、整数溢出与事故后写入皆验。原八百二十八函之约及导入导出皆如故。

四百万项排序，五进程各六轮，诸版轮换。旧址影首轮中数五十一点八四三毫秒，热轮三十九点一八九；独址首轮四十五点七一九，热轮三十六点七零七；C 热轮三十二点九七一七九二。独址热轮较旧省约百分之六点三，然尚慢于 C 约百分之十一点三，未可谓成。实验栈仍须显式启用。原始记录与今语详解具于同目录。

本机全自举与两项验型皆通，三四代字节相同。Wasm 两次冷缓存自举为二十三点零四、二十二点九七秒，种子与后二代皆同。此用默认模式，未启实验栈，故不可归其速于栈分配。

本机与 Wasm 所生实验排序亦同。余五基准及未启实验之排序，字节皆如前，故不复测其速。旧注误谓初始化不计时，今正其辞，未改其行。
