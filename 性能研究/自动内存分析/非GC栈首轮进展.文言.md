# 非 GC 栈初行

用户已许，依每实例六十四 MiB 初限探索。顶以值授，不置可变全局栈顶；调用者存旧标记，子调用得新标记，退或陷阱不留全局顶之残态。容量可留，内容每调用重置。唯原生数值入栈，GC 引用不入。

四百万数，同期五进程各六轮：GC 首轮五十七点一九、热轮四十四点七四一毫秒；逐项检之栈为六十点一五五、四十七点一八三；加范围证为五十三点五八二、四十一点一六四；再以地址递增为四十七点七六一、三十六点二六七；C 为四十二点七七九五四一、三十三点七二一一六六。渐近而未及，未可称成。

运行时十九验、排序对照四百零二验皆过；豫言基础模块与生成器既立，其独立夹具十五验皆过。此仍封闭调用图之原型，宿主重入与通用自动资格未备，默认编译器未启。后须接非逸与活跃期之证，复行全自举、回归、接口与诸程序之验。
