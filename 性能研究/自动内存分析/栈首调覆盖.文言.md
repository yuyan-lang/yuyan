# 栈组首调全写之证

新组既成，首调若自零遍写至长，且不读旧值、不召外工、不使组外逸，则先填可免。须先验 SSA、表示、封闭调用图及不逸；其组、上界与起点逐一对应。无证仍遍填，容量不足仍归 GC，整数解码如故。此非内容缓存，亦非完整线性之证。

六核复测，五者热轮先于当前 C 对照，排序三三点三零五对三三点二六九毫秒，差在波动之内。树已消构造消费之功，不可谓一般分配皆如此快。再试省清零，七进程各六轮，旧三三点八二九，新三三点三五九，C 三三点一六三毫秒，尚非稳定胜 C。

首调之证十一例皆过；实际根入口二千零五十一例、逐元校验一百零四万九千六百次皆同，复用之前特污其存。另验非零初值五百一十五项及容量两界。候选全程自举既成，原生三四代同；Wasm 冷举二一点八五、二三点六六秒，诸代同。

然自动生成版九进程热轮三四点一一九毫秒，旧三三点零四七；再验新三三点一九二，旧三二点九三七，皆未胜。原型之微利不稳，故撤生成接线，复其先填，独留证明与诸验。此轮未得可保留之提速，目标未竟。详数见 [汉语篇](栈首调覆盖.汉语.md)。
