# 自动非 GC 栈：授权后的首轮实现

用户已明确允许 stack allocated non gc memory，接受先前说明的通用栈容量高水位。探索上限每实例 64 MiB，超过容量或增长失败时回退原 GC 实现。没有缓存数组内容，每次调用重新初始化；内存不导出，原入口签名保留。

## 栈约定

采用按值传递的栈顶标记，reserve(sp,n) 只确保容量并返回下一标记，不修改全局栈顶。调用者保留自己的旧标记，将新标记交给子调用；子调用返回或陷阱不会遗留全局 bump pointer。数组头 8 字节，长度占前 4 字节，元素为完整 i64；不把 GC 引用写入线性内存。

当前排序原型只覆盖封闭且无宿主重入的调用图，顶层帧从零开始，递归排序不再分配数组。任意宿主回调、未知调用、对象逃逸及自动跨调用传递栈顶尚未实现，不能声称已完成通用栈后端。默认编译器仍未启用这条路径。

## 实测

四百万元素，五进程各六轮，版本轮换，首轮与后续二十五轮分别取中位数。全部校验和 6000002，原始记录为非GC栈首次对照.json。

| 版本 | 首轮 ms | 热轮 ms |
|---|---:|---:|
| GC 形态版 |57.190|44.741|
| 栈内存直接访问，逐项检查 |60.155|47.183|
| 栈内存＋分区范围守卫 |53.582|41.164|
| 上述范围证明＋地址递增 |47.761|36.267|
| C/Wasm |42.779541|33.721166|

地址递增原型较 GC 热轮减少约 18.9%，但仍比 C 慢约 7.6%，目标未完成。最初把每次访问做成辅助函数调用的原型热轮约 245 ms，已否决；有收益的是直接生成访问、范围证明及地址归纳的组合，而非仅换内存。

快分区入口增加 upper < array_length，并保留原 0 <= store <= scan <= upper <= u32 条件；失败走完整逐项检查的后备。快循环只访问 scan、store，按现有进度不变量，两者在每次访问时均落在帧内。该原型在这一前提下去掉重复数组长度检查，保留 Wasm 线性内存边界保护，不使用关闭检查的引擎选项。地址按 8 字节递增，帧总量不超过 64 MiB，避免地址算术溢出。

另有跳过冗余清零、向量化完整初始化的原型，尚未正式配对复测，不纳入上表，也未加入编译器。现有主结果仍保留清零和完整填充。

## 验证与源码

19 项独立运行时检查通过：负长度、未对齐、容量上限、嵌套帧不重叠、子帧陷阱后外层仍可读、标记复用及重新初始化、增长失败等。越界错误以原 GC 排序产物为参照；第一次手写期望消息不准确，改为真实参照后验证通过，未修改运行时错误行为。

GC、地址栈、向量栈、强制增长失败后备模块做 402 项排序对照，含负值、零、完整 i64 极值及 1..128、257、1024 的长度，结果和异常类型/消息一致。测试检查校验和，尚未完成复杂数据分布的逐元素排序与完整通用语义验证。

已新增豫言模块 网页汇编线性栈基础。豫 和豫言测试生成器 线性栈运行时生成。豫。它们生成的独立 Wasm 夹具另通过 15 项检查。基础模块尚未接入统一生成器，现有默认编译器语义没有改变；不能把上一轮冷自举成绩当作未来自动栈后端的验收。

下一步：把非逃逸、仅数值存储、封闭调用及活跃期条件变成实际编译器资格，生成栈入口和 GC 后备；让范围证明驱动直接访问和地址归纳。接入后必须复跑完整自举、全套回归、ABI 核查和多程序实测。任何未知宿主重入首先保守回退 GC。
