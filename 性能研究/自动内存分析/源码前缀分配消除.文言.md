# 省源码前缀之分配

二〇二六年九月二十日。名称定位之术，字符相比无旁效，异则即止；十种声明后缀，直验源码既有字符，不复屡造新列。通用列术之求值约不改，语言服务及源码范围不弃。

同机、同源码、十八工，禁编译缓存，先以旧新新旧，复以新旧旧新，凡八次完整自举。旧者四次二十三、二十三点四八、二十二点八四、二十三点六六秒；新者二十一点八六、二十三点三二、二十一点七一、二十三点〇五秒。旧均二十三点二四五，新均二十二点四八五，省〇点七六秒，约百分之三点二七。八份产物与新种子逐字节同，皆不逾三十秒。

此益出于编译器内部算法，非自动栈已用于编译器。单验统一网页汇编之类型检查任务，累计所报分配自十四点八〇五 GiB 降至十点八八六 GiB，约省百分之二十六点五；此非驻留之量，亦非全程降幅。

新旧前缀之术，差分验一万〇五百一十六例、十二万六千一百九十二比，皆同。六内核之产物、语言服务信息及语义标记如故，默认 GC 排序亦同。原生四级自举及两项类型检查毕，三、四代逐字节同。初有缓存诊断临时名之异，另立缓存而独行末级，C 文及程序皆复同。

本术留之。容器寿命之自动证明、运行内核恒及 C 之志，犹须续进。实数、方法与证据，见 [汉语报告](源码前缀分配消除.汉语.md)。
