# 自动察形省分配

今以所证用于生成，源文无须标记，公用接口如故，亦不用久留私缓冲。所得对象仍属网页汇编之 GC；通用栈置与完整线性推导，尚未成也。

旧树一节，标签与载荷各占一物。今察造者之形，验受者之用，证调用之界，而合标签与诸字段为一物。载荷不复别造，取字段少一重间接。公用函数仍受旧形。

所验者，分常值、新造之物、虚载荷三类；循支路辨标签与字段，验递归与所返。子树可共，载荷须独用。共载荷、异形同标签、物之外传、未知调用及未能证者，皆守旧法。常量共用之物不改；公私杂处则验形，形定则直取。

此证与先前诊断摘要各立，非谓凡不逸之物皆可知也。造者至多四参，函数至多百二十八局部值，载荷至多四字段；调用处须相邻而静定。过其限则不变。

同机五进程，各六轮，首轮别记，余取中数。树深二十，旧为 20.328 毫秒，今为 13.796，C 为 18.0395；较旧省时约三成二，较此 C 省约二成四。此一程序之效，非全语言胜 C 之证。详见同名汉语篇与正式数据。

网页汇编三十一项、编译器内部四组皆过；共子树、外传、全宽整数、公私同标签诸界皆验。公开导入、导出、函数表无异。本机自举三四代相同，两入口验型皆过。网页汇编冷缓存自举为 21.65、21.68 秒，二三代相同。C 计时兼释树，豫言之回收时机属引擎，非逐轮强使等量回收也；省时之率不可冒称省存之率。

后当察值域、字段、别名与末用，证成而后省物、紧形、复用。勿以不逸为独有，勿强源文以繁标记。

全组复测，斐波那契、筛、矩阵、树之稳态皆先于此 C；排序用时犹为其约 1.87 倍，数组约 1.34 倍。数组与筛之首轮亦慢，故未可称全成。各数及原始样本见汉语篇。

深二十之树，内节凡 1,048,575，每节省一载荷，叶常量仍共。别行六轮察 GC，事件由三十七至二十三；记录区间分配之和由约 460 百万字节至 250 百万。此单次诊断，未含末次回收以后之分配，亦非进程峰值，不可过言。

又手改产物试窄整组：数组由 14.646 至 11.761 毫秒，排序却由 62.337 至 66.858。故形小未必速，不径施通用窄化。此试未具自动值域之证，仅适既有数据，未入编译器。
