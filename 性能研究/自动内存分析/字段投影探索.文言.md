# 字段投影之试

察类型阶段，名称定位与 GC 尚费时。源码状态三域之取，犹经间接调用。乃试独参直取一域者入内联候选，借旧替换之术，守求值次序与别名。识别十例及副作用、异常、动态调用之验皆过。

冷自举依旧、新、新、旧而行，十八工，不读编译缓存，未清系统页缓存。旧二二点七九、二三点一六秒，新二三点六九、二三点零一秒；均值旧二二点九七五，新二三点三五零。间接调用虽少，墙钟未见益，故撤其七行规则。两组各自输出相同，组间优化异，产物亦异。

六核各唯字典取键辅助工有变，计算之体如故；未据此称速度不变。源码复本轮前，原有改动悉存，类型检查通过。试验与证据存 [汉语篇](字段投影探索.汉语.md)。后当直析跨函之留、返、写与可达别名，自动求其寿，毋以普通内联代生命周期之证。目标未竟。
