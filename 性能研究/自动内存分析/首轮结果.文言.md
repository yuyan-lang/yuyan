# 自动察存首绩

不用久留私缓冲，今以自动之证择 GC 布局，并立分配诊断。完整线性之推、通用栈存与对象复用，尚未成。

双组沿调用图并验其初、其写、其传；不逸且值皆整者，用私有 i64 GC 数组。公开约定、回绕与索引之验不改，作者无须标注。六百方阵，旧耗二百一十点七六〇毫秒，今一百五十六点四〇五，C 网页一百八十九点二五九；三百方阵亦胜。五进程各六行，首行别录，余取中，原始数俱存。

双组阶段本机自举及类型检查皆过，三代四代同；网页回归三十项过。冷编译缓存全自举两行十八点八九、十八点九二秒，二代三代同。

以 `--debug-print-add 内存分配` 可见分配之形、词法使用数、所逸与所有权之证、所择之途及未化之故。一见不谓线性，多次借读不害局部独有。七项正则级回归皆过，启闭报告所得矩阵产物同。报告为静态候选，含库及未行之支，非动态对象之数；隐式装箱与宿主分配亦未逐点尽列。

本批未得仅局部借读而可消之元组，故不妄加无益之术。树之载荷入构造器，构造器返调用者；逸出创建之函，不等于永须堆存。后当察返回别名、容器之图、调用者与消费者之期，再许拆除、改形或栈存。旧栈标记入统一正则后与普通元组同，须辨名实。

GC 追踪中，树工见三十六次收集，大组八次；含初始化且追踪扰其时，不以此时当正常基准。其证足以优先究树之分配回收，未足逐字节归于源码对象。

今斐波那契、筛与矩阵有胜 C 之例；排序、大树、大组犹未齐，目标未成，须续究。

终验：加分配报告后，本机自举及两途类型检查皆过，三代四代同；网页冷编译缓存自举十九点三三、十九点〇七秒，二代三代同。今源码之差与产物摘要俱存。
