# 筛选循环紧化拆分

本轮继续定位上一轮条件累加候选的首轮开销。未改编译器源码，也未把手改产物当作最终成果。所有原型保留数组索引宽度与边界检查，使用同一字节数组算法和六轮测量程序，没有预热或持久缓冲。

五进程各六轮，轮换版本次序。拆分实验的首轮中位数：条件累加基线 43.015 ms；只消除相邻局部写读 41.344；只省恒等尾参 39.130；两者结合 33.916；进一步展开增量及累加临时值 33.019。各版本热轮约 16 ms。

相邻写读改成 local.tee 保留赋值的独立对照：基线 44.424，删除写读 33.890，保留 tee 40.458 ms。说明不能仅依靠等价 tee 替换取得同样收益，需要证明赋值无其他读取后才能删除。

扩展到标记、外层筛选和计数三个循环后，一轮实验从 44.387 降到 30.802 ms。另一次包含 C 的同期复测为：

| 版本 | 首轮 ms | 热轮 ms |
|---|---:|---:|
| 当前条件累加候选 |44.598|16.019|
| 三循环原型 |32.508|16.281|
| 既有 C/Wasm |31.034292|30.328250|

首轮减少 27.1%，但仍比 C 慢约 4.7%；热轮变化约 1.6%，不能称严格不回退。不能选取另一轮的 30.802 与这里的 C 跨组比较。全部原始数据及差分补丁同目录保留。

抽取原型与基线的三个完整循环，构造每次重新分配的独立 Wasm 夹具，验证 0..256 及 997、1024、10000、100000，共 261 项。正常结果另与独立试除法比较，规模 0 的原有边界错误按类型和消息比较，均通过。该测试未覆盖全部任意参数、类型、共享和异常组合，不能替代通用编译器变换的正式回归。

## 下一步实现约束

1. 从 ANF 使用计数证明局部值只有一次读取，排除形参及重复展开的区域。仅当实际生成代码中的 local.set 与同名 local.get 紧邻时删除；不得匹配编号前缀，不得跨指令、注释或控制流删改。保留未证明的赋值，尤其是多次使用的值。SSA 合法性与代码复制后的使用次数必须一致。
2. 只有已确定回跳当前克隆的尾调用，才省去相同形参的恒等传递。普通调用、不同克隆及其他函数仍传完整实参。其余实参先全部求值，再逆序写回；不以不变尾参优化破坏交换或交叉依赖。
3. 已有双步循环单步模式另有扫描参数推进规则，不能误把它与一般尾递归合并。必须复跑排序等现有内核和交换参数测试。
4. 完成通用生成后再做模块差分、全部回归、规定的本机完整自举、Wasm 冷缓存自举和同期 C 对照。当前首轮及自举稳定性目标仍未完成。
