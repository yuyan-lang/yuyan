# 自动栈地址镜像

已有表示、范围、进度之证，乃为参数索引另持 i32 地址镜像。镜像为数组基址加索引八倍，头之八字节仍由存取指令加之。原 i64 索引不废，诸参数签名如旧。

小偏可递，限负十六至十六；未知则依新索引重算。诸新数、诸新址先备而逆存，故交叉取旧值不乱。唯双步快体用镜像，全检后备如旧，不以此另删边界检查。

独立模拟验一万零八十六组、二十八万零八百九十四项，含异址复制、负十七重算、非零帧址、分帧哨兵与 i64 溢出和。实际排序六千九百一十六例、分区一万零二百八十七例皆合，含陷阱后内容。

四百万排序，首轮、热轮中数：GC 五四点三六〇、四五点〇二五毫秒；双步索引五二点三三七、四一点五二六；地址镜像五二点四〇四、三九点四四八；C 四二点一四五七〇八、三二点八六五五四二。热轮少约百分之五，首轮未显变；较 C 尚慢约二成。后当研究去双份状态及改初始化，试旗仍不常启，目标未成。

本机三四代同，两途验型过；余五基准及无试旗之排序皆同旧，公门签名如故。常途冷缓存 Wasm 自举为 22.94、22.47 秒，种子与二三代同，未开试旗。
