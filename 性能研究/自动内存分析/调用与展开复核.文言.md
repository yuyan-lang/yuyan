# 复核调用与展开

今守已验证之双步编译器，试六途而不径入。空区间之递归可省其调用，然初测基线亦迟，须复验。核其产物摘要与引擎皆未变，整机负载未能独立察明，遂七进程轮换，并置 C 于同期。

四百万项稳态，基线四十四点六八六毫秒，省空递四十四点零五五，C 三十三点五一四，利约百分之一点四，暂不入。另试四步，反迟；兼省空递亦未及双步。依剩余次数择单步双步，阈八、三十二、百二十八皆未速，故六途皆不取。

复以降序、全宽随机、短块逆序及全同之数验既有双步。备数不入计时，逐轮验全组有序及和、异或不变。各分布稳态皆未退，约省百分之三至十五。全同取小规模，因原算法于此工作量为平方级，未改其法。

此为排序部分之测，不可与四百万项全程之数混比，亦不足言已及 C。源码未改，完整自举未重行；今得验证与舍取之证，远志未竟。
