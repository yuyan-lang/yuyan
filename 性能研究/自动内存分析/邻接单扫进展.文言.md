# 邻接扫描之省

旧法为诸槽反复拆文重组，种子生成历一百四十九点三四七秒而主动止之，尚未行 Wasm 冷自举。虽运行有益，此费不可受。

今先选单用非参之槽，文仅拆一次，词与空白各聚而存原序，乃扫邻接存取。含分号引号者不改，避注释与引文。余指令、验型及诸参并赋如故。

旧七验皆过，增四验待复。新种子既成，冷自举方行，周验与全效尚待。

Wasm 冷自举二十二点一二、二十二点六零秒，二三代同物。十一验皆过。六基准已复编，连空行之处得再省单用搬运，非去运算与界验。本机全自举与三十八回归犹行，后须测效。

全本机自举、同物与验型皆过，三十八回归及十一专项皆过。六项同测：筛首轮约与 C 同，斐波、矩阵、树、数组胜既有 C；树与数组皆有消物之变，不可泛称分配器胜。排序热轮四十六点七零二毫秒，C 三十三点四八五六六七，且较前版退约百分之五。独复旧递归主体，可复旧速，故当察其调用与内联。去内部返回值之原型无益，不取。正确性与冷自举既过，排序回退未解，总目标未成。
