# 循环范围之证入生成

今默认网页汇编编译器自察循环之约，逐验尾递，立有守卫之私门。合约者入快体，不合者循旧体。作者无须标记，不置久留私缓冲，公开诸约及函数表皆存。

所得之证唯省索引宽度之验，数组自身之界不废。快体生成时暂授事实，事毕即清，不流于普通体。此有限关系分析，非任意程序之全线性类型系统。

四百万项排序，五进程交替，各六轮，首轮别录，余二十五次取中。改前五十五点五二一毫秒，今四十八点七八五，C 三十四点零六三，约省百分之十二点一。前独立初测约省百分之九点九，方向相同。今仍为 C 耗时约一点四三倍，首轮亦未及，不可言功毕。

三十四项回归皆过。一万五千九百七十二组边界，返值、失败之类与文、全组及失败前所写皆同。快体省宽度验三处，旧体悉存；两体各五次数组存取不减。公表、导入导出皆同。

规定之本机自举已成，三代四代逐字节同，两入口类型检查皆过。网页汇编冷编译缓存自举二十点三六、二十点二五秒，二代三代亦同，未清操作系统页缓存。余五基准产物与前轮逐字节同。

后当续探排序及首轮之迟。可据范围之证试窄索引及循环之变，仍须实测，不预许其必速。远志未竟。
