# 素数筛首轮定位

本轮只做产物原型与诊断，未修改编译器或基准源码，未将原型纳入默认实现。基线为上一轮已通过完整自举的 yy单用素数筛.wasm。没有启动私有持久缓冲、预热或省略数组检查。

每次配对实验均为五个进程、每进程六轮，版本轮换；首轮与其余二十五轮分别取中位数。输入一千万，全部结果 664579。下面各行来自各自同期对照，不跨实验相减。

| 原型 | 旧首轮 ms | 新首轮 ms | 旧热轮 ms | 新热轮 ms |
|---|---:|---:|---:|---:|
| 删除不变尾参及已知数组转换 |43.752|42.853|19.410|19.466|
| 布尔常量直接整数化 |43.301|44.390|19.471|19.250|
| 计数循环整体紧化 |43.527|36.919|19.799|16.756|
| 只将条件加一变为非零归一化后累加 |43.038|43.739|19.244|16.161|

前两项没有稳定收益，不值得单独据此加入编译器。条件累加对热轮有效，但未改善首轮；完整紧化同时改善两者，支持继续研究混合整数循环的单用表达式展开、无效搬运消除与受限条件累加。

独立分段诊断原样抽取 db749、db754、db758 及装解箱函数，用局部数组每轮重新分配，在调用边界读宿主时间。五进程结果：分配首轮 3.031 ms / 热轮 2.529 ms；标记 20.347 / 10.325；计数 20.533 / 6.612。独立模块改变了编译上下文，分段中位数也不能严格加总为原程序中位数；它仅用于定位，不替代完整程序验收。

整体紧化保留 i64 索引宽度检查、GC 数组边界检查、完整 i64 加法及返回装箱。将字节条件先归一化为零或一，再累加，不能直接加字节值。通用实现必须证明累加基值是裸整数，分支内只有无陷阱运算；未知类型、除法、读取和调用不可提前执行。尾参更新必须保持同时赋值语义。现阶段只验证了基准校验和，原型没有通过全面语义验证，不能发布或用于自举。

差分补丁、原始测量及诊断 WAT 同目录保存。下一步先在混合整数生成路径中实现可独立验证的证明与变换，再跑完整回归、自举及同期 C 对照。素数筛首轮与排序尚未达到目标，目标保持进行中。
