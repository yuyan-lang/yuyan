# 初检记长，后检复用

新增按需长度之析。同段同组有数次实检，乃记首检之号，于旧读头之处存其长，后检用之。首索之六十四位范围检仍先于读头，读不前移至函首，亦不移入未行之歧。

此赖封闭栈图、SSA、表示与头不可变之证。调用可易载荷，不可易长。诸歧各取其源，不出其证；已省之检非源，仅余一检则不设槽。后备仍守旧形。根与排序两私函各由三读头减为一，三检皆存；诸函之约及导入导出不变。

来源十三试皆通。旧循环夹具未触此术，字节如前，不可独以其百万检自证新术。故新造先读、跨函改数、再读之夹具，五千七百九十九组，检一万二千二百零一项，果与事故后内容皆比。真排序与分区又检二十七万零三项，根函验千余长度。

原型之益较大，最终产物则小，故复以九进程配对。旧热轮三十三点九六三毫秒，新三十三点五三六，九组七胜，省约百分之一点三。另五进程与 C 同批，新热轮三十三点九四四，C 三十三点零二八三三四，犹慢约百分之二点八。不可取异批相较，亦不可执初次原型之益为终论。诸证与测数见同名今语文所列记录。

本机全自举与两项验型皆通，三四代字节同。默认模式冷缓存 Wasm 自举为二十三点零八、二十三点二一秒，种子与后二代皆同。未启实验栈，不可归此时于长度复用之效。后可试合正常路径之范围判断，而败途仍辨其事故；尚未作，不计其功。

本机与 Wasm 所生实验排序同。余五基准及未启实验之排序，字节皆如前，故不复测。实验栈仍须显式启用。
