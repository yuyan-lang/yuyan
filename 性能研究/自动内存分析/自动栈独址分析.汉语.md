# 自动栈的索引标量活性分析

在地址镜像基础上，新增 `网页汇编栈标量活性。豫`。它自动判断循环参数是否还需要整数表示：只参与已获证寻址和可归纳尾递归更新的索引，只维护 i32 地址；参与存储值计算等数值用途的索引，继续维护 i64 数值。源码不增加标记，函数参数签名保持不变。

分析仅适用于进度证明批准的单步区域。先假定地址参数可省略数值状态，再从条件、数组写入值、保留操作及尾调用实参传播数值活性；移除有数值用途的候选并迭代到稳定。只删除无用的加减乘和比较，保留数组读取、写入和除法及其异常。索引退出时按地址与数组基址之差恢复；扫描终点预先转换为地址。这个恢复依赖已有非负范围和 64 MiB 栈容量限制，不能直接用于任意整数或任意地址。

新旧地址和数值参数先全部求出，再逆序写回，保持尾递归的并行赋值语义。求和循环可省略索引数值写回；填充循环的索引参与“长度减索引”，仍保留。超出仿射分析范围的地址更新继续重算，不能据此删除所需的数值计算。

## 验证记录

- `栈独址生成验证.json`：10,426 组、281,394 项差分检查，覆盖跨索引赋值、负偏移重算、不同帧起点、完整 i64 溢出求和、越界异常及异常后的数组内容。
- `栈独址代码选择验证.json`：确认求和实际采用独址，而填充及将索引写入数组的迁移循环保留数值状态。
- `栈独址排序差分验证.json`：真实编译器产物的 6,919 组排序和 10,287 组分区，合计 270,003 项结果、异常和内容检查。
- 另对小数组所有起点的交替写入及尾参数交换完成 715,649 项检查，百万项求和返回 500000500000。
- `栈独址接口审计.json`：原有 828 个函数签名不变，导入导出不变；原函数中仅分配根入口 f766 的函数体改变。

## 配对性能

四百万元素；每版五个新进程，每进程六轮，轮换版本顺序。计时包含分配、填充、排序和校验和计算，排除命令行解析及打印。所有校验和均为 6000002。首轮取五个样本中位数，热轮取其余二十五个样本中位数。

| 版本 | 首轮 ms | 热轮 ms |
|---|---:|---:|
| 地址镜像，保留整数状态 | 51.843 | 39.189 |
| 自动独址 | 45.719 | 36.707 |
| C/Wasm | 41.493541 | 32.971792 |

相对地址镜像，首轮减少 11.8%，热轮减少 6.3%；五个进程的热轮中位数均改善。热轮仍比 C 慢 11.3%，目标尚未达成。原始逐轮数据见 `栈独址排序实测.json`。实验栈开关仍默认关闭。

完整本机自举与两项类型检查通过，`yy3_bs` 与 `yy4_bs` 逐字节一致。默认模式使用 `--do-not-load-cache --parallel -j 18` 的完整冷缓存 Wasm 自举分别为 23.04、22.97 秒；种子与二、三代 Wasm 产物一致。该时间未开启实验栈分配，不能理解为栈分配使自举提速。记录见 `栈独址本机验证.json` 与 `自动栈独址冷自举.json`。

本机与 Wasm 编译器生成的实验排序产物一致。关闭实验开关的排序及其余五个基准产物与上一版逐字节相同，故不重复运行未变化的基准。详见 `栈独址六核产物.json`。另外修正了排序基准原注释中“初始化不计入”的描述，计时边界和程序行为未改。
