# 排序调用边界与机器码调查

本轮未改编译器源码。使用当前单扫版实际产物生成可复现 WAT 原型，保留原范围守卫、宽整数比较、数组检查和异常后备；每版本五进程各六轮，顺序轮换，输入四百万，全部校验和为 6000002。原型只做基准校验，尚未通过全面语义验证，均未进入默认编译器。

第一组：基线首轮 58.250 ms / 热轮 46.360；只显式内联范围守卫 56.677 / 45.124；同时内联分区循环 61.675 / 44.541。全体内联使热轮接近旧条件版，但首轮变差，远未达到 C 热轮约 33.5 ms 的既有记录，不据此投入通用实现。

第二组：基线 58.688 / 46.618；全体内联 61.965 / 44.753；借用调用者已有只读数组、上界及枢轴局部值，避免三项参数复制，得到 61.027 / 44.945。未有热轮增益。

第三组：基线 58.554 / 46.924；全体内联 61.959 / 44.849；在原 u32 范围守卫内令扫描、存放位置和上界使用 i32，保留枢轴与数组元素 i64，得到 61.072 / 44.819。仍无明显收益。此实验与早期未显式内联的 i32 索引实验上下文不同。最初原型漏删已变 i32 索引后的 wrap_i64，被引擎验证拒绝；修正后重新组装、验证及完整复测，失败版本未用于统计。
