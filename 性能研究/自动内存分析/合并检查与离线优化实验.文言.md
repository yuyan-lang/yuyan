# 合检与离线优化之试

此轮未改编译器源码与默认流程。先试合已有长度之检查，败途仍辨旧事故；复测仅省约百分之零点三，故不取。

又取 Binaryen 官方一百三十二版于临时目录，验其下载摘要。O2、O3 可生当前引擎所验之模块；O4 于本模块触内部断言，故止其试。未用无陷阱、低址不用或封闭世界等额外假定。

五进程各六轮，诸版轮换。O3 使豫言与 C 热轮皆退；O2 首轮有益，热轮之益不定。限内联之规模，亦未胜。排序仍未及 C，故不入默认途。

O2 后编译器由三百八十四万余字节减为二百二十三万余，处理约零点四八秒。两次全冷缓存自举并后处理，外钟实测二十二点八二、二十二点三一秒。优化种子与后二代字节同，后处理前之原始输出亦与旧编译器同。

导入导出之名与类同，自举可行；专用夹具千余组，果、事故与事故后内容皆合。然未遍验诸 ABI、语言特性与余基准，不可谓尽成。此为离线发布之研究，未引入新依赖。诸源、摘要、测数与限度见同名今语文。次仍究递归之界与循环内联，目标未毕。
