# 自动栈双步

范围既定，复验诸续恰进一、上界不移、无提前返回及未知调用，乃先去奇数一步，余者两步一判。异常仍循旧序。

步内比较置假，终则置真。诸新参先备而逆存，恒等者可省，交换不乱。步文逾四〇九六字符则守单步；全检后备亦不合步，试旗仍不常启。

夹具验奇偶、零及百万步，比较九万八千四百二十六项。又以独立公式验换参与交替数组九万八千零二十一项，二百组 i64 溢出求和亦合。除零及陷阱后复用皆验。实际排序六千九百一十六例，分区一万零二百八十七例皆合。

其余五基准、无试旗之排序皆同旧；公用签名及导入导出不变。本机与 Wasm 所生排序同。完整本机自举三四代同，两途验型过。

四百万排序，首轮、热轮中数：GC 五七点三七六、四四点八〇五毫秒；单步栈六六点五一八、四四点一五五；双步栈五三点九一六、四二点四一五；C 四三点一一七八三三、三三点六四九二〇九。双步较单步首轮少约一成九，热轮少约百分之四；较 C 仍慢，不谓功成。后当续改地址与初始化。

常途完整冷缓存 Wasm 自举为 22.34、22.12 秒，皆在三十秒内，种子与二三代同，未开试旗。
