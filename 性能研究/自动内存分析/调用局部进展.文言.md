# 调用局部之证

今以跨函数逃逸摘要接分配之报，不烦作者加标，不改公开约定，不蓄私有缓冲。此轮增证，未改分配，亦未称运行加速。

元组传于已知函数，逐参察之：外不存其物，返不达其源，且无未知副作用，乃许调用不留。诸用有一未证，仍从宽拒之。外返、容器捕获、动态调用及复杂控制，皆不妄许。

如造对而付消费，消费惟取整数域而算之，可证不留；若返原物、载物而返、付未知函数，则不可。返值虽弃，此轮亦未据最后使用而放行。

惟局部借读者，仍列可消元组；经调用而不留者，别列调用局部候选，不谓独有，不谓线性。同物传二参，亦可不逸，然活别名未尽知，不可据以复用。今用 Wasm GC 引用，线性内存栈址不可径代之，须另证表示与消费者之约。

新十验及旧七验皆过。继当察字段路径、返回别名、最后使用与容器寿命。先求免造，次求简形，证全而实测有益，乃议区域存储与原位复用；不以手工标记累作者。

实察树、排序、矩阵，静态分配点各一七一三、一六八四、一六八九；新调用局部候选皆无。此数兼库与未行分支，非动态分配之数。三产物与前定稿逐字节同。故宜细察字段与返回来源，不以狭证称提速。

Node 宿主长报有截，未据缺文计数；终以自举原生 yy3_bs 取全报。宿主未改，证据另存。

定验：原生自举与二入口类型检查皆过，三四代同。Wasm 禁编译缓存自举二一点零四、二一点八六秒，二三代同；未清系统页缓存。新十验、旧分配七验与调用摘要八验皆过。产物摘要另存。
