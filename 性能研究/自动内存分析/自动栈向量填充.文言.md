# 栈组并填

二〇二六年九月二十日，纳八项并填之术于编译器。栈组不入 GC，须启 `--wasm-stack`；公用调用之约不改。

凡单组之循环，每步一写，索进一，余参不移，等上界则止，返单元；无读、无除、无他调用，值由加减乘成，索之系数为常数且在负十六至十六之间，式树不逾六十四节点，乃可并填。入口先验零不逾索、索不逾上、上不逾组长；既验，以四向量并写八项，余者逐写。失验则循旧检查体。整数仍依模二之六十四次方而算，根之初置不省，组中旧值不藏以供后用。

同机排序四百万项，五进程各六轮，热时中位：旧术三十四点三八八毫秒，新术三十三点九〇一，C 三十三点九七九七〇九。复以九进程，各六轮：旧术三十五点三五四，新术三十四点三〇二，C 三十四点一〇一六六七。新术较旧减时约百分之一点四至三；与 C 相近，未可谓恒胜之。

证明之试十六项皆过。常号填充之差分一十一万五千三百四十六例，疏号四万八千二百一十六例；复验真排序六千九百一十九例、分区一万〇二百八十七例、根入口与六十四 MiB 容量之界，皆合。八百四十一函数中，仅填充快体有改；诸签名、导入、导出如故。余五内核及默认 GC 排序之产物，与旧逐字节相同。

原生四级自举毕，三、四代同，类型检查皆过。禁编译缓存，以十八工行默认 GC 之 Wasm 自举，两代墙钟二十二点三七秒、二十二点八八秒，种子与二、三代同，皆不逾三十秒。

此术可留。后当省生成之冗，广不逃逸之证；未谓诸程序皆及 C，亦未谓商用之志已毕。详数、原始记录与复验之令，见 [汉语报告](自动栈向量填充.汉语.md)。
