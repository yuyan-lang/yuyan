# 栈封闭之证

用户许自动非 GC 栈矣。无须手注所有权，公用 ABI 如故，不可证者仍归 GC。

今增《网页汇编栈封闭证明》。以散列表记函数，以逆边传不闭之证。宿主、动调、未知术、额外数组及未明控制，皆拒；互递闭合者可，不谓必终，亦不谓无陷阱。诸函各限二五六局部，逾者从旧。

根体唯许指定数组创建点，子体不得再造数组。此证须合不逸与整数元素之证，不可独断栈之安全。整数装箱之 GC 分配非此所禁。

二十验皆过。数组虽未授宿主，宿主能重入，故仍拒之。实际排序分配点已合诸证；诊断明言仍用 GC，自动栈生成未接。

地址递增原型又验六千九百一十六例，比十五万六千七百一十二元素，与 GC 及独立排序皆合。含全排列、随机、重复、整数极值、子区间及边界。详见《非GC栈逐元素验证.json》。夹具之导出唯供验，不入公用接口。

后须以证生栈入口及 GC 后备，自动传栈顶，再验自举与性能。今有资格证明及人工原型，未可称默认后端已成。

## 验证与时数

遵仓库之法，本机四代既成，三四代相同；两途验型皆过。Wasm 种子、二代、三代及复测产物亦同。

禁编译缓存，十八工，自举墙钟三次为三六点三七、二七点〇九、二六点一八秒。首试逾三十，不隐其数，未可称稳定达标。旧编译器编新源码，为二四点九四秒，产物同。证尚不足，不妄归因。

又以五进程各六轮验排序，规模四百万，校验和皆六百万零二。热轮中数：GC 四四点五一四毫秒；栈地址递增三六点四三一；去冗余初始化三六点〇〇九；向量填充三五点八二五；C 三三点八一二七五。最快原型较 GC 少约一成九，较 C 尚慢约百分之六。计时含测试内数组分配、初始化与排序。

去清零须证全覆盖，向量填充须守入口之约。今皆人工 WAT 原型，自动后端未接，不谓功成。
