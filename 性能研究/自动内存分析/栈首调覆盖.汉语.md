# 栈数组首调用覆盖

结论：保留独立证明与测试，**撤回生成接线**。完整自举和正确性验证均通过，但自动生成版在两组独立热运行测量中均未超过基线；原型的小幅收益未能稳定复现。下文的省略行为、产物审计及冷自举数据属于已撤回的候选版本，不是当前默认或实验栈生成器的行为。

新增自动跨函数覆盖证明：根数组创建后的第一条指令必须直接调用一个已证明的填充函数；其数组实参必须为新数组，上界必须为创建长度的同一原子，扫描实参必须为整数零。填充函数每步恰写一个元素，扫描加一，其他参数不变，退出为单元；只能使用已知整数上的加减乘，不能读取数组、调用其他函数或暴露数组。

该规则仅在已有 SSA、整数表示、封闭调用图和非逃逸证明之后使用。栈容量与参数守卫不变，容量失败仍执行原 GC 后备。成功快路径保留初始值的解码，省略随后必被完整覆盖的初始化写入；没有缓存内容或改变数组的可观察语义。未获覆盖证书的函数仍执行完整初始化。实验栈开关仍为 `--wasm-stack`。

源码为 `网页汇编栈覆盖证明。豫`。试验曾在 `网页汇编栈调用图。豫` 组合证明，并由 `网页汇编栈入口。豫` 生成入口；这两处接线现已撤回。独立证明只证明这次调用完整写入，不等同于通用跨函数逃逸摘要、唯一所有权或完整线性类型推导。

## 决策依据

本轮首先对当前六个内核与 C/Wasm 做同机复测：各三个新进程，每进程六轮，首轮单列，后五轮合并取中位数，顺序交替，无并发构建。

| 程序及规模 | 豫言热轮 ms | C/Wasm 热轮 ms |
|---|---:|---:|
| 斐波那契 40 | 102.383 | 128.365 |
| 素数筛 10,000,000 | 15.842 | 30.253 |
| 矩阵乘法 600 | 156.257 | 187.362 |
| 树基准 22 | 0.001 | 69.705 |
| 数组基准 10,000,000 | 2.551 | 10.807 |
| 快速排序 4,000,000 | 33.305 | 33.269 |

结果均一致。树程序已由通用造消融合等优化消除了大量工作，微秒级计时不能代表一般树分配性能。排序差距约 0.1%，小于进程间波动，不能认定稳定超过 C。原始信息、二进制哈希及逐进程数据见 [原始复测](容器后六核复测原始.json) 和 [摘要](容器后六核复测摘要.json)。

随后对 SIMD 填充之后的排序产物做省略重复清零原型：七个新进程各六轮，轮换三版本顺序，基线热轮 33.829 ms，原型 33.359 ms，C 33.162791 ms。原型改善约 1.4%，仍慢于同期 C；这组只用于选择实现方向，正式生成产物须另行复测。见 [原型数据](向量后省清零原型实测.json)。

## 已完成验证

- 11 项调用处证明测试，覆盖完整覆盖、插入读取、非零起点、不同上界、不同数组、未知目标、动态调用、常量长度、空数组和参数数量错误。
- 实际生成的排序根入口与之前版本比较：2,051 个案例，1,049,600 次逐元素检查。长度 1..1024 递增及递减，复用前将内存写成 i64 最小值，确认填充不依赖旧内容。空数组、负长度和超宽长度的异常相同。见 [根入口差分](栈首调覆盖根差分.json)。
- [精确 WAT 审计](栈首调覆盖产物审计.json) 确认除根入口初始化片段替换为解码后 `drop` 外，整个排序模块文本完全相同，私有算法和 GC 后备保持原样。

候选版本还通过了以下验证：

- 515 项初始化运行检查，完整覆盖以非零初值创建，部分覆盖保留另一个非零初值。确认两个函数都实际生成栈入口，且仅完整覆盖入口省略初始化。GC 与栈模式输出一致。见 [回归及生成命中记录](栈首调覆盖初始化回归.json)。此命中记录对应撤回前候选，当前生成器会为两者保留初始化。
- 8,388,607 项栈容量边界与 8,388,608 项 GC 后备各六轮，两版均结果一致。见 [容量验证](栈首调覆盖容量验证.json)。
- stable → 二代 → 三代 → 四代原生自举完成，三四代相同；两项类型检查通过。Wasm 两代冷自举 **21.85、23.66 秒**，种子与两代相同。见 [候选验收摘要](栈首调覆盖验收摘要.json)。
- 其余五个内核及默认 GC 排序与之前版本逐字节相同；自动生成排序与之前验证的候选相同。见 [六核验证](栈首调覆盖六核验证.json)。

## 性能否决

九个新进程各六轮，轮换顺序，无并发构建：[自动生成版实测](栈首调覆盖定稿实测.json) 的基线热轮为 **33.047 ms**，候选 **34.119 ms**，C **32.753709 ms**。候选首轮为 41.059 ms，基线 42.244 ms；首轮更快不足以抵消热运行回退。

再独立测量基线、原型及自动生成版，各九个新进程六轮：[差异复测](栈首调覆盖差异复测.json) 为 **32.937 / 32.854 / 33.192 ms**。原型相对基线只快约 0.25%，自动生成版仍慢约 0.77%。原型与自动生成版的入口仅多出被丢弃的初始常量，但没有足够证据把进程波动归因于该差异；不以选择较好样本保留优化。

因此撤回两处生成接线，恢复完整初始化。保留证明模块、回归源和所有正反数据。当前性能目标仍未完成；下一步应优先寻找能消除整个热路径对象、而不只减少一次内存遍历的跨函数分析机会。

撤回后重新生成原生第三代和第四代，两者均与本轮前编译器哈希 `d388568e49f86da0100a81145f1ea78bd645a657738cb526b8d3c4c400c1b1d4` 相同，随后两项类型检查通过。见 [恢复验证](栈首调覆盖撤回验证.json)。当前运行基线继续采用本轮六核复测的产物，候选版计时不冒充当前版本成绩。
