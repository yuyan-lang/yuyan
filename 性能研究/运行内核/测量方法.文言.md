# 内功比试之法

此试计算法之功，别于启进程、入模块之费；冷缓存自举仍另验其墙钟。六题之胜负，不足以断全语言之商用。

取递归斐波那契、筛素数、乘矩阵、逆序快排、造树求和、填数组求和六事，不易其算法。各进程六行，首行别录，后五取中；终验各法三进程，共十五正样。分配若在算法内，亦入其时；打印在计时外。不强令回收，故回收之迟速可动其数。各行之果须同。

豫言用 WasmGC，OCaml 用原生，C 分原生与 WASI；运行时各异。OCaml 留边界检查，C 无同等检查。筛之标记，C 与 OCaml 用字节，豫言用通用引用。树试之 C 显式释放全树，余者听回收器；不可据此独论分配器。此诸数不溢出，非谓诸语言整数之约皆同。

机为 Apple M5 Pro，十八核、四十八 GB；Node 26.3.0，V8 14.6.202.34-node.20；clang 原生 22.1.7，WASI 23.1.0；OCaml 5.5.0，无 flambda，未启 unsafe。复现之令见同名汉语篇。

旧录与终验分存。CSV 依次记题、轮、秒、果；终验文件名兼记规模、法与进程序号。不得择最快者而弃其余。
