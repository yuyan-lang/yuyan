# 第四轮今绩与待决之事

> 后决：用户不用久留私缓冲，转而自察所逸、生存之期与线性之用。下文缓冲乃旧试之记，非待决之事。

至二〇二六年九月十九日，诸优化已入编译器，公开约定如故，自举及回归皆验。然未尽齐 C，亦未可谓已穷其速。

同机同 V8，较 C 之 WASI 产物。斐波那契四十，豫言耗一百一十点二七〇毫秒，C 一百三十一点二四七；千万筛，豫言十八点九〇九，C 三十点四一七。矩阵、排序、大树、大组之耗时，犹分别为 C 之一点一三、一点九一、一点一五、一点三九倍。详数与取样之法见同题汉语篇，不以数例之胜谓全语言皆胜。

纯整递归今先验而后行，行毕复验；其参并换，其和守回绕，不减原算法之功，亦不藏前果。斐波那契四十较前省时约二成三分。私有整组、字节之证、裸爻、跨函直入与薄造组之展，亦已施行。未知及外逸者守旧途，索引之验不废。

验中得一旧失：巨整作爻，本当陷而竟判真。今须证其值合 i31 之约，方许纯整之化；合法非法之界皆验。

本机三代四代同；两途类型检查过；网页回归二十七项皆合。禁编译缓存之完整网页自举，两行分别十九点八一、二十点五一秒，二代三代同。此禁编译缓存，非尽清操作系统页缓存。源码之差、产物之摘要及原始计时俱存。

另有覆写全组而复用缓冲之试作，未入编译器。千万项热后耗五点六九二毫秒，同策 C 八点九八二；首行则四十八点〇一二，C 十五点八三一，仍未及。组虽缩小，其约八十兆字节之内存犹留，须待实例销毁。拟限每实例一百二十八 MiB，逾限或无安全之证者归 GC，然通用证明与回退尚待成。

此留存之策，请用户择其常开、显式开启，或不用；未决不擅设常开。其余仍可究双数组私有参数之证、排序访问之费与树之分配回收。双组之化尚未施行，后须验别名、换参、第三组及未知值，毋以类型之名代运行之实。
