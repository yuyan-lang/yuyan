# 第四轮阶段记录

此为在途之记，未谓功成。私有整组、字节范围之证、裸爻及造组薄壳之展，皆已入编译器；纯整循环旋转未计入同题汉语篇之表。

各题三进程，各六行，首行别录，余十五取中；次组反其先后，计时不并编译。诸结果同。千万筛耗十八点八四五毫秒，C 网页三十点四零九；四百万排序耗六十四点零零九，C 三十三点七八八。矩阵、大组、大树仍有未及，故不得谓全语言已齐 C。

原生三四代同，类型检查及二十六项网页回归皆过。禁编译缓存自举十八点七八、十九点一六秒，网页诸代同；未清系统文件缓存。公约不易，私组唯取不逸而用途皆明者；字节须证初值与诸写皆在界内，索引之检不废。

单展循环未获恒益，故不入。线性内存唯试，其去检者不可发布。详数、源码补丁、摘要与复现证据见同题汉语篇及本目录数据。仍循目标续行。
