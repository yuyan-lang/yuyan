# 保持 ABI 的第二轮 C 性能追赶

2026-09-19，基于 `e55c39dc` 的工作区改动。本轮明显缩小了排序和整数递归的差距，但没有全面达到 C。主对照是同一 Node/V8 引擎下的 C/WASI，另保留 C 原生数据；两端的数组表示、边界检查及内存回收方式仍有区别。

C 原生仍在多项任务上明显更快。例如大矩阵为 54.565 毫秒，大数组为 1.755 毫秒；不能将“接近 C/WASI 的某些内核”说成“整体达到 C 原生”。完整数值、首轮、范围及各进程中位数均在 `最终汇总.json`。

硬件和工具沿用前轮：Apple M5 Pro、18 核、48 GB；Node 26.3.0 / V8 14.6.202.34-node.20；原生 clang 22.1.7，WASI SDK clang 23.1.0，均 `-O3`。没有为豫言更换基准算法或移除边界检查。C 使用线性内存，豫言使用 WasmGC；C 的树实验包含显式释放，GC 语言按运行时策略回收。

## 保留的改动

1. **多参数小型直线函数内联。** 在原有薄原语包装规则之外，只接受至少两层参数、复杂度小于 64、无分支和递归节点的受限表达式。原有展开次数限制继续生效。`交换(数组, 左, 右)` 不再为一次调用连续创建部分应用闭包。实际分区函数由三处间接调用变为零处，直接包含两次数组写入；前后代码片段与指令计数已保存。
2. **发布静态递归入口的轻量包装。** 函数体仍留在定义模块，仅将无捕获包装放入索引。后续完整调用可直接到达已有静态入口，不复制递归体。同模块逐定义发布到内存索引，每个模块重置，并以文件路径区分；跨文件使用原有持久索引。普通函数值和通用闭包入口保留。
3. **除法结果保留为 i64。** 消除除法与后续算术之间的重复装拆箱；不把除法加入入口类型推断，保持除零与溢出陷阱的执行位置。
4. **纯整数递归的尾部加法累加器。** 只匹配区域末尾“自调用结果加另一个已计算的整数，并直接返回”的形式。利用 i64 模加结合律累积待加值，先计算全部新参数再逆序写回，跳回内部循环。递归结果同时出现在两个加数中时不变换；非尾分支中的加法也不变换。显式返回补入待加值。代码片段用列表线性拼接，避免长函数文本的反复复制。

实际斐波那契私有整数函数中，自调用指令由两处变为一处，另一路变成累加循环。`整数递归优化前.wat` 与 `整数递归优化后.wat` 是实际产物片段。

以上均不修改现有通用值表示、泛型数组布局、宿主协议和外部入口签名；六份基准的导入导出边界已核对一致。没有新增专用数组 API。

## 发现并处理的回退

最初将小型单参数函数也纳入新内联规则，树基准出现稳定回退。消融测量中，深度 18 的旧版中位数为 4.006 毫秒，只扩大内联为 5.680 毫秒，再加静态包装为 5.542 毫秒。最终把新增规则收窄到至少两个参数，专门针对部分应用成本。独立复测中新旧均为 3.901 毫秒，最终全套测量也没有复现该明显回退。消融原始数据没有删除。

动态回调的第一次最终测量中，加一回调从 5.326 到 6.533 毫秒，不能忽略。因此又交替运行五个新进程，并增加两千万次调用：

| 调用次数、回调 | 旧版毫秒 | 新版毫秒 |
|---|---:|---:|
| 四百万、加一 | 5.957 | 6.199 |
| 四百万、乘三 | 5.980 | 5.887 |
| 两千万、加一 | 29.858 | 27.361 |
| 两千万、乘三 | 28.740 | 31.006 |

复核中差异方向不一致、进程间范围明显重叠。热循环和加一回调的指令在归一化函数编号后完全相同，文本与摘要存于 `高阶复核/`。目前既不能据此宣称动态调用提速，也不能确认有稳定回退；第一次不利结果也完整保留，而不是用复核结果覆盖。该负载仍需在更稳定的测量环境中跟踪。

## 自举与正确性

最终源码完成 AGENTS.md 规定的稳定编译器 → `yy2_bs` → `yy3_bs` → `yy4_bs` 流程，三代四代逐字节一致。`./yy` 类型检查、最终原生并行类型检查、最终 Wasm 自身并行类型检查均通过。

完整 871 个任务、18 路并行、新 Node 进程、`--do-not-load-cache` 的最终自举：

| 轮次 | 墙钟秒 |
|---|---:|
| 种子 → 二代 | 18.21 |
| 二代 → 三代 | 18.69 |
| 三代 → 四代 | 19.32 |

中位数 **18.69 秒**，仍满足 30 秒目标。前轮中位数为 18.30 秒，本轮没有宣称自举提速。“冷”指禁用豫言编译缓存并重新启动引擎，不指清空系统文件页缓存；同次构建仍使用既有的 Wasm 模块共享机制。最终种子及后三代字节一致。

20 项 Wasm 回归输出与 `.成功` 文件一致；直线内联、排序逐项、递归累加和私有入口四项另经原生运行。名单在 `最终复测/回归输出.json`。新增检查包括跨文件调用、局部同名变量、数组别名、异常和参数求值次序、负数除法及两类陷阱、排序全部元素、递归结果重复使用、非尾分支、参数交换和 i64 回绕。正式横测 972 次算法调用及高阶复核 240 次调用均完成，各组结果值一致。常规矩阵/排序基准仍只校验既有结果值；逐项排序正确性由独立回归补充。
