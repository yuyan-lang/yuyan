# 守旧约而趋 C

二〇二六年九月十九日，基于 `e55c39dc`。今排序与纯整递归大进，然未可曰全语言已及 C。主比同引擎之 C/WASI，原生 C 另录。

四百万数排序，由三百五十四点五二七毫秒减至一百点九一九，C/WASI 为三十三点五三八；豫言虽快约三点五倍，犹费 C 三倍之时。斐波四十，由一百八十点〇六四减至一百四十点七九二，C/WASI 为一百三十二点七五八，差约六分于百。大筛素数、矩阵、数组仍有差，不掩之。
