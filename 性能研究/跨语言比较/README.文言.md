# 豫言跨语言性能比较

此目录以四种算法，较豫言、C、Python、OCaml、Java、JavaScript 六者之性能：

- 递归斐波那契：测递归调用与整数运算。
- 埃拉托斯特尼素数筛：测数组访问、分支与循环。
- 整数矩阵乘法：测密集算术与内存访问。
- 原地快速排序：测递归、交换与不规则分支。

运行之：

```sh
python3 性能研究/跨语言比较/运行.py
```

默认每项预热一次、正式测量五次。欲改次数，可用 `--预热次数` 与 `--次数`。脚本所行如次：

1. 自提交 `40aa7a16` 提取与 `yy_bs_stable` 配套之标准库、运行时，置于 `.yybuild.nosync`。
2. 惟以 `./yy_bs_stable` 编译豫言实现，并开 `--optimize --whole-program-opt`。
3. 以 `-O3` 编译 C 与 OCaml，复编译 Java，并用本机 Python 与 Node.js。
4. 计时之前，先校验六种实现之结果完全一致。
5. 生成 `结果.md`，及含原始样本之 `结果.json`。

编译时间不计，进程启动时间计入。每次正式测量皆启新进程，故 Java、JavaScript 之结果含单次运行中即时编译预热之成本。此套件惟见诸具体算法与实现，不可释为语言之单一总分。

除语言关键字、标准库接口与语言名称外，自定义文件名、标识符、参数、说明与结果字段，皆用中文。OCaml 5.5 之词法器不纳汉字标识符，故 OCaml 实现中函数名、变量名保留拉丁字母，而以中文注释明其义。
