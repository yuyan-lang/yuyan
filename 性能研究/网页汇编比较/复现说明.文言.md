# 网页汇编较速复验法

取豫言实程序，较原生、核心模块、命令组件。此验封装与执行，非异言频繁互调之验也。详数、命令、工具版本及其参数，见《复现说明.汉语.md》与《构建记录.json》。

机为 Apple M5 Pro，arm64，Darwin 25.5.0。用本地既有 `yy编译器`，库取 `1a1bb90f`。原生 LLVM 22.1.7，以全程序优化及 LTO 行之；网页汇编用 WASI SDK 34、Clang 23.1.0，今后端实为逐模块 `-O2`。两者优化之法未齐，不可尽以差值归罪于 Wasm 指令。

两端豫言栈皆十六 MiB，单堆上限皆六十四 MiB；初堆四 MiB，筛百万数则三十二 MiB。原生栈参数以槽计，故设一；网页汇编以 MiB 计，故设十六。

先取原生之输出为参照，再暖机一轮，更番测五轮，取其中数。轮轮验其退出与输出；矩阵、排序仅验原程序所出摘要。以单调钟记子进程前后之时，含启动、加载、初始化、运算、回收、收取输出，不含前置编译。轮次零为暖机，不入定数。次序固定，未锁核频；运行间不并行编译。

核心模块仍用 P1。取 Clang 最后链接命令，以 `-###` 察底层参数，更链接器为 `wasm-component-ld`，以 command 适配器成组件，启严格校验。其对象、运行时及内存限额皆不更。预编译者先以 Wasmtime compile 制本机码，后启新进程载之；即时编译者每次禁磁盘编译缓存。二者皆非常驻实例之纯计算时。

本次上下文为 `.yybuild/豫构上下文/16.上下文`；重建则当取新上下文。豫构所传原生清单与 WASI 不合，故径调编译器；旧 yy 不识今库布局，故用 yy编译器。筛百万数，原生小堆亦败，故两端同增初堆。败者不入样本。

积列初试二十万，原生于十六 MiB 栈报溢出，故正式改十万。额外回收日志与类型检查，皆在计时既毕而行。

五题为斐波那契三十五、筛百万数、矩阵边长二百四十、排序十万数、积列十万数；另以斐波那契零察启动。CSV 五列为题名、输入、轮次、方式、秒数。AOT 产物系于本机，不可当通用发行之物。[预编译之法](https://docs.wasmtime.dev/examples-pre-compiling-wasm.html)。
