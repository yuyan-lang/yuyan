# 以自举之时考网页汇编

今验（二〇二六年九月八日）：Wasm 连续自举既成，同名三级四级逐字节同。具栈检之自举三百六十九点一一秒，同版原生直接入口六十二点七二秒，约五点八九倍；各一验，四工。详《../../工具/网页汇编宿主/验证.文言.md》。下文尽存桥接前之历史，未成之说非今况。

考于二〇二六年九月七日，美东。详数、命令与所限见《自举评估.汉语.md》。今取编译器自身为题，不复以小程序之速推其自举。

原生可自编，Wasm 编译器则败于终链，未得可运行之器。故 Wasm 自举时间尚不可测，比例未得，非零亦非超时。前验小题二至四倍之数，不可以移用于自举。

自举之正验，当使 Wasm 编译器编同版自身，成下一代，再验固定点。原生生成 Wasm 编译器，乃交叉编译之备，非 Wasm 自举。

旧原生器制二级，墙钟 106.74 秒，成之；新二级自编为三级，119.77 秒，亦成，且二、三级逐字节同，cmp 返零。故今有效基线为每级 119.77 秒。两时各属一代一验，不可谓多次重复之统计。二级再制 Wasm，74.31 秒而败；不可称较原生为速。真 Wasm 自举时间未得。

原生两次用户态累计为 291.85、309.50 秒，内核态为 82.98、90.81 秒；四并发行之，累计可逾墙钟。命令、摘要与日志俱存《自举记录》。此循今包构建入口行两代自编，未更原有 yy2_bs、yy3_bs、yy4_bs，非重行旧单文件三阶段之法。

机为 Apple M5 Pro，系统 Darwin 25.5.0。源码 `1a1bb90f`，原生 LLVM 22.1.7，网页汇编 SDK 34、Clang 23.1.0。用豫构，四并发，禁豫言缓存读取，优化从默认；原生运行时及包 C 缓存仍可复用，文件页未清。诸编译先后行，不锁核频。每阶段一验，非多次中数。

以新成原生二级编译器制 Wasm 编译器，历 74.31 秒，终链而败，退出一。其缺为在线处理器数量、启动与收取异步子进程、字符串按字节在前、存放包上下文。前四者今同居子进程 C 文件，Wasm 构建排之；字符比较虽不需子进程，亦连坐而失。包上下文另属包原生扩展，未入 Wasm 链接。

遂以原源码编包上下文 C 为 Wasm 对象，成之，补入终链，又缺 flock；余四符号仍缺。今 P1 libc 无此文件锁定义。未以空桩、假成功或忽略未定义符号掩之。

初误用性能研究之包上下文，直依赖不合；已令豫构生成编译器之新上下文，再行正验。此快败不入自举时间。

纵补链接，尚须包文件系统、子进程调度与 LLVM 工具调用。可许原生宿主，则以明定构建接口召相同 LLVM 工具，用多个 Wasm 实例比四并发；此可测编译器居 Wasm 之损益，然 LLVM 尚原生。若工具链亦尽求标准 Wasm，则当移植之，或自为生成、链接。

后验当同源码、同优化、同并发、同堆栈，分别记编译器、宿主工具、通信启动、内存峰值与缓存，并验新器固定点。今惟增记录与文书，编译器、运行时未改。

## 复考第三版接口

前验为 P1，不足谓 P3 无异步。今核[正式说明](https://wasi.dev/releases/wasi-p3)，P3 有异步函数、流、future，亦有网络、HTTP 与异步文件之用。command 导出 run，供宿主调用；非使 guest 任意按路径召原生程序之 spawn。其 [run 定义](https://raw.githubusercontent.com/WebAssembly/WASI/main/proposals/cli/wit/run.wit)可证。

[0.3.1 文件系统 WIT](https://raw.githubusercontent.com/WebAssembly/WASI/v0.3.1/proposals/filesystem/wit/types.wit)未列文件锁操作；no-lock 乃错误枚举，非锁术。

本机以 P3 编包上下文，成；编旧子进程 C，缺 spawn.h，亦告信号须仿真。再以 P3 重编核心运行时，独立归档，不混 P1，补包上下文而链，惟缺 flock。P3 libc 有 sysconf，未见 flock、fork、posix_spawn、execve、waitpid 定义；未验 sysconf 返真实核数。日志俱存《自举记录》。此为接口探针，非 P3 完整自举时间。

故宜以 P3 异步组件任务代现有进程协议，非必永守 POSIX 之形。多核并行尚须宿主与实例调度，异步非即多核。缓存可归宿主一处写入，或分目录隔离，然须明定其约，不得空废锁而称成功。[WASIX proc_spawn](https://wasix.org/docs/api-reference/wasix/proc_spawn)另有扩展，非 WASI 0.3 标准接口。
