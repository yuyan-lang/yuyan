# 性能研究

保存编译器和运行时的性能研究程序。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包为库，可供他包所依。无默认程序入口，试例须明指其书。

在仓库之根行 `./yy豫构 检查 性能研究` 以验其籍。

所依与原生组成皆见[包籍](性能研究。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。

## 测数

自二〇二六年九月二十六日，此包唯存报告与实验之源。诸测之数（日志、采样、剖析、补丁、摘要 JSON、WAT 片段等，凡二千七百九十二件，约六十九兆字节）皆删于版本库，须用则重测。

报告所链之数，于工作树已亡。欲得旧数，可依原径取诸 git 史：先以 `git log --diff-filter=D --format=%h -1 -- '性能研究/<路径>'` 得删之之提交，再以 `git show '<其提交>^:性能研究/<路径>'` 取其文。
