# 统一正则与影子根栈

今置 `shadow`、`wasmgc-anf` 二试验目标，旧途仍为默认。闭包之树直成正则，值以函数内整数为号，运算之参皆原子，if 有果，后续不复写。前序已有之合流以词法结果块承之，毋任意跳转。

本机函数用真栈，C 为 LLVM 之编码，不复承 CPS 与虚栈。迁堆之根别列影栈，不用 Boehm。跨回收而存者乃入槽，回收毕复读。无根者不立帧，有根者临需始立。动态退出以栈上激活、唯一号及 setjmp/longjmp 行之，先复根链而后退栈；令既失效则报错，不许保存 continuation。网页汇编以 EH 行之。

初行十六参，今从模块最大元数。普通值各居局部，根槽稠密编之；无回边区域以引用计数保守求其活者。回收验界内联，回收本体别置冷路。尾调用常路直传值，唯临回收始存其函数与参；本函数有活动退出域则不尾跳。含 setjmp 者以 volatile 护其值，回收亦依此读写。

验自举以同源、同包上下文、同链接清单，禁读缓存，逐次计时，含前端、阶段导出、后端与链接，不含制种子之时。异源异缓存之旧计时不得相除言其速。链接之缓存基名固定，而两代实物仍须逐字节比较。

此乃首条自举路径，非全案毕。独立正则阶段及序列化、完整原语签名与效果、细类验证、循环降低尚待行之；显式循环今报未支持，不默生错码。FFI、调试及全运行参数亦未尽统。本机语言线程今一，真栈百二十八 MiB；并行编译另验多进程。详实数与复现之令，见《实现与自举.汉语.md》。

本机实测：旧本机自举二百八十五点六七秒，新者二试为二百五十点八八、二百五十一点一六秒，均值减约百分之十二点一。旧网页汇编于 V8 自举一百二十三点零七秒，新者一百一十五点九九秒，减约百分之五点八。皆同源而禁读缓存，然旧途及网页汇编各唯一次，不可推为诸程序之定率。本机与网页汇编所生之物异，不以两时直判执行器之速。

计时之后，唯补链接 `-Wl,-S`，去 LTO 临时对象之调试籍而定复现；正常符号、展开资料与签名仍存。初两代代码与数据虽同，临时路径、时间戳使 UUID 与签名异，故另验全文件，不混并行验证之时于性能表。

旧默认途之 yy3、yy4 实物同，类型检查过。旧 stable 不识今包布局，重试仍报文件夹未找到，故以可信旧本机所生之编译器为 yy2 种，非谓旧 stable 已过。新旧网页汇编于 V8 自举皆得同物。正则越域与重号皆拒；根栈迁移、别名、嵌套退出及小堆深尾递归、异常皆验。增量缓存或存旧诊断之新鲜名号，故本机最终固定点必用连续全量自举。

最终本机再行全量自举，二试为二百五十九点四八、二百五十八点四七秒，均值二百五十八点九八秒，较旧约减百分之九点三。其时无并行构建相扰，惟源码较前表多链接定名之修，故另列，不择最速者冒为最终数。末两代 C 与可执行实物皆同，确以上代所生编译器生下代。小堆试验实经十一次迁堆而过。
