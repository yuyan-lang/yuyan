# 统一 ANF 与影子根栈：首条自举路径

本次实现提供两个实验目标：`--target=shadow` 和 `--target=wasmgc-anf`。默认 `llvm`、原有 `wasmgc` 路径保留。本报告区分已实现的自举路径与完整架构审阅稿中的后续工作。

## 自举性能

2026-09-09，本机 Apple M5 Pro、48 GB 内存、macOS arm64，接交流电。Node 26.3.0，V8 14.6.202.34-node.20。两种 native 运行时默认初始堆为 256 MiB；新 native 语言线程和 Node worker 的机器栈均为 128 MiB，V8 使用默认 GC 配置。

| 完整自举路线 | 墙钟秒 | 用户态秒 | 系统态秒 |
|---|---:|---:|---:|
| 旧 native → 旧 native 后端 | 285.67 | 265.85 | 17.88 |
| 新 native → shadow，首次 | 250.88 | 244.39 | 5.66 |
| 新 native → shadow，下一代复测 | 251.16 | 245.67 | 4.94 |
| 旧 WasmGC → 旧 WasmGC，Node/V8 | 123.07 | 138.17 | 7.81 |
| 统一 ANF WasmGC → 统一 ANF WasmGC，Node/V8 | 115.99 | 132.30 | 7.10 |

新 native 两次平均 **251.02 秒，较旧路线缩短 12.1%**；WasmGC 本轮缩短 **5.8%**。这只是本机、当前自举负载的结果，旧路线及 Wasm 各只有一次正式对照；不是其他程序的性能保证。

每行从相同的编译器源码出发，输出对应路线的可执行编译器。native 与 Wasm 生成不同产物、调用不同最终工具，不能拿两行墙钟时间直接判断机器指令执行器的速度。native 总收益也不能全归因于影子栈：新路线同时去掉旧 CPS／虚拟栈准备，以及逐模块 native 后端工作；系统态耗时下降与这项结构变化相符，但本实验没有逐项消融来分配各优化的贡献。

五次计时对应 `自举计时源码指纹.json`。之后唯一的编译器源码修正是为实验 native 链接增加 `-Wl,-S`，去除 LTO 随机临时对象的调试记录；最终固定点另外验证，不将并行回归期间的耗时混入上表。

最终修正后的 native 又执行了两次独立的全量自举，分别为 **259.48 秒**（user 253.11、sys 5.02）和 **258.47 秒**（user 251.92、sys 5.22），平均 **258.98 秒**。这两次没有并行构建干扰；与旧路线 285.67 秒相比，最终版本约缩短 **9.3%**。其源码较上表仅增加上述链接选项及说明注释，因此单列报告，不把它混入原来严格同源的两次均值，也不只选最快的开发结果作为最终数字。

## 已实现

- 闭包转换后的表达式直接构造成独立 ANF：函数内整数值 ID、原子操作数、有序指令、带结果的 if、动态退出域和明确的结束式。分支公共后续只构造一次。
- 前序 contify 已引入的共享尾部用词法结果块承接；只能跳出包围自己的块，不开放任意 goto，也不复制公共后续。
- 验证 ID 唯一性、定义和可见范围，以及结果块目标的词法合法性。验证失败时停止代码生成。
- native 使用普通本机函数和真实机器栈；C 只是交给 clang/LLVM 的临时编码，不含旧 CPS 或调用虚拟栈。编译参数为 `-O3 -flto -DNDEBUG`。
- native 沿用移动式复制 GC，以影子根帧提供精确根槽，不使用 Boehm。GC 更新槽后，生成代码重新读取仍存活的值。
- 动态提前退出使用机器栈上的激活记录、唯一激活号和 `setjmp/longjmp`；展开前恢复影子根链。失效令牌报错，不支持保存 continuation。WasmGC 使用原有 EH 机制。
- 两个新目标调用同一个 ANF 构造器与验证器。WasmGC 复用旧生成器的模块设施和原子原语编码，控制区域直接消费新 ANF。

## 为降低运行开销所做的修改

1. 调用 ABI 的参数个数取模块实际最大元数，最低为二，不再一律传十六个通用值。
2. 普通值保留独立局部变量。只有跨 GC 调用仍需要的值进入根槽，调用后重读并清空槽；根槽按实际保存的 ID 紧凑编号。
3. 无活根的函数不登记根帧。其余函数首次需要时才登记；在自己的 `setjmp` 之前完成登记，遵守 C 对非局部跳转的规则。
4. GC 阈值检查强制内联，完整回收函数标记为冷路径且禁止内联。此前 LTO 将回收器并入安全点，导致未触发 GC 的调用也保存大量寄存器。
5. 合法尾调用生成 `musttail`；存在本函数活动退出域时保留普通调用。尾调用的常见路径直接传局部值，仅在需要 GC 时保存函数引用和实参。
6. 只在存在 `setjmp` 的函数中使用 volatile 局部值；GC 通过 volatile 根槽读写，避免移动回收与非局部跳转组合造成未定义行为。

活跃性统计在无回边的结构化区域上进行，分支间采取保守计数。针对同一份旧编译器闭包输入，开发阶段的紧凑根槽版本把静态根槽总量从 117,653 降到 40,308；5,791 个函数中有 4,106 个无需根槽。这些是静态规模，不能直接当作动态运行次数或最终加速比。

## 验证口径

主要指标是编译器从相同源码完成一次自身编译的墙钟时间，同时保留用户态与系统态 CPU 时间。计时包含前端、默认阶段导出、后端及本机链接，不包含准备种子编译器的时间。计时运行串行执行，不同时启动其他验证构建。

完整自举使用同一包上下文与原生链接清单，显式 `--do-not-load-cache`。另用相同 Wasm 输出区分运行时开销与后端工作量；不同源码快照、不同缓存条件的开发计时不混算加速比。

本机链接先输出到固定基名的缓存文件，再复制到指定 `-o` 路径；优化实验产物使用 `-Wl,-S` 去除 LTO 临时对象路径和时间戳的调试记录，保留普通符号、展开信息和代码签名。仅固定基名还不够：最初两代 C、机器代码和数据区域一致，但调试记录、UUID 与签名不同，不能据此声称整个文件已经一致。

## 回归验证

- 最终 native：连续两次全量自举生成的 C 和完整可执行文件均相同。可执行文件 SHA-256 为 `7aa1647f5ebefb3b9bab1cf78365a13badf81b11abbe61dbd74c649970fbf80e`。最后一次执行的是上一代生成的编译器，不是仅把同一份 C 重复交给 clang。
- 旧默认路线：执行规定的 `yy2_bs → yy3_bs --parallel → yy4_bs --parallel`，`yy3_bs` 与 `yy4_bs` 字节相同；随后并行类型检查通过。原定首级 `yy_bs_stable` 命令及不隐藏诊断的重跑均因当前包布局报“文件夹未找到”，实际使用可信旧 native 编译器完整生成的产物作为 `yy2_bs` 种子。没有把旧 stable 的失败记为成功。
- WasmGC：统一 ANF 编译器在 Node/V8 内编译自身，种子与输出 Wasm 完全相同；旧 WasmGC 对照同样达到固定点。
- ANF 构造测试：结果 if 只有一份公共后续；非法分支局部变量泄漏和重复 ID 被拒绝。
- C 运行时测试：移动更新、共享别名、嵌套提前退出和退出后根释放通过；开发阶段也执行过 AddressSanitizer 检查。
- 语言测试：在 1 MiB 初始堆下，跨分配与提前退出保留两个十万节点列表，并验证深尾递归和异常捕获；启用 `YY_GC_DEBUG_FLAG=1` 确认执行了 11 次移动回收。

增量重编的诊断文字中带有旧前端的全局新鲜名编号，可能与全量重编不同。因此最终 native 固定点使用连续全量自举，不用增量种子的诊断字符串差异代替语义结论。

## 范围限制

- 尚未切换默认后端，也未删除旧 LLVM/WASI 路线。
- ANF 当前在模块生成器内按函数构造，尚未成为独立序列化、缓存和导出 stage。
- 运行时类型多数仍为通用值；完整原语签名／效果登记表、类型与元数验证尚未落地。
- 显式循环节点已有格式，但验证与后端会明确拒绝；当前自举通过尾调用执行递归。循环活跃性需要另外实现固定点分析。
- 尚未统一所有程序的 FFI、调试选项及运行参数；native 当前为一个语言执行线程配置 128 MiB 机器栈，GC 协议仍是单执行线程。并行编译属于多进程能力，需单独验证。
- 这是可自举的实验实现，不代表架构审阅稿的全部条目已经完成。

## 复现入口

先构建运行时和包含新 target 的编译器；仓库已有的 `yy3_bs` 未必包含当前未提交修改。

```sh
make yy_runtime_lib
./yy豫构 构建 豫言编译器 --编译器 ./yy3_bs --输出 yy统一驱动 -- --do-not-load-cache
./yy统一驱动 豫言编译器/入口。豫 --target=shadow -c -o yy影子种子
./yy影子种子 豫言编译器/入口。豫 --target=shadow --do-not-load-cache -c -o yy影子二代
./yy影子二代 豫言编译器/入口。豫 --target=shadow --do-not-load-cache -c -o yy影子三代
cmp yy影子二代 yy影子三代
```

性能实验显式传入已准备的 `--package-context` 和 `--native-link-inputs`，排除包准备差异。上述便捷入口的包准备时间不应与实验结果混比。
