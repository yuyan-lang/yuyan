# 豫言版本管理

本工具以豫言编写，将中文命令和选项转换为 Git 参数。它直接启动系统中的 `git`，继承标准输入、标准输出与标准错误，并返回 Git 的退出码。因此认证、编辑提交消息等交互仍可正常使用。

从仓库根目录构建：

```sh
./yy 工具/豫言版本管理/入口。豫 -o yy版本管理
```

例如：

```sh
./yy版本管理 状态 --简短
./yy版本管理 暂存 --路径 文档/说明.汉语.md
./yy版本管理 提交 --消息 更新说明
./yy版本管理 历史 --单行 --条数 5
./yy版本管理 --仓库 其他目录 分支 --全部
```

可用命令：`初始化`、`克隆`、`状态`、`暂存`、`提交`、`历史`、`差异`、`分支`、`切换`、`合并`、`获取`、`拉取`、`推送`、`远端`、`查看`、`撤销暂存`、`还原`。命令后的仓库名、分支名、修订号、路径、远端名及远端地址保持原样。`--路径` 将后续参数作为路径交给 Git，适用于名称以 `-` 开头的文件。使用 `帮助` 查看选项；不支持的选项会报错。

`远端` 支持 `列表`、`新增 名称 地址`、`删除 名称`、`重命名 旧名 新名`。`撤销暂存 --路径 文件` 只从暂存区撤销，保留工作区修改；`还原 --路径 文件` 恢复工作区文件，请按需使用。

此客户端调用已安装的 Git，不自行实现 Git 仓库格式或网络协议。SSH 仅在远端地址使用 SSH 传输时由 Git 调用。
