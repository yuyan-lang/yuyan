# 豫言版本管理

此器以豫言成，译汉语令辞为 Git 之参。径启 `git`，承其输入、常出、误出，返其退码。故认证及成章之交互皆可行。

在库根编之：

```sh
./yy 工具/豫言版本管理/入口。豫 -o yy版本管理
```

用例如下：

```sh
./yy版本管理 状态 --简短
./yy版本管理 暂存 --路径 文档/说明.汉语.md
./yy版本管理 提交 --消息 更新说明
```

诸令有初始化、克隆、状态、暂存、提交、历史、差异、分支、切换、合并、获取、拉取、推送、远端、查看、撤销暂存、还原。库名、枝名、版本名、径名、远端名及址皆原样传之。`--路径` 之后诸参为径；`帮助` 可观选项。不识之选项则告误。

远端令可用列表、新增、删除、重命名。撤销暂存唯去暂存之文，工作区仍存；还原则复工作区之文，宜审而后行。

此器藉已装之 Git，不另造仓簿及传输法。惟远端用 SSH 时，Git 乃召 SSH。
