# 豫言操作系统接口检查

此工具以豫言读仓中接口包纯声明之文（仓根「豫言操作系统接口」与「豫言操作系统底层接口」下之包），借编译器词法与抽象语法之术，而止于合声明定义之前，故无体之「乃」可存。又读同目录包之描述，验主、名、全版及直接所依，拒同包重名、越依与函数之体。「。接口。豫」之术宿主具，「。应用接口。豫」之术客具；实现之主、名、版、向从「实现接口。豫」核之，再比源级术型。凡当实现之术，须有「者」之体，徒有「乃」不可充数。定位诸包，须于仓根行之：所导之包与清单所依之包，皆按短名查包索引，索引循构建基础之包发现（同豫构，略 `.git`、`.yybuild`、`_v0` 及符号链接）自当前目录建之，首用乃建而复用，故标准库、底层库、他接口包皆可解，不复写死其所；昔唯识自身、标准库与以「豫言操作系统」起首之包，故不得底层库。所导者须为本包或直接所依；索引无其名或有二同名，皆拒；所有者由清单生成时之身份核对定之。所导模块之文，循后缀「。接口。豫」「。应用接口。豫」「。豫」（普通库之模块，如标准库、底层库之类型别名）而求；接口文与应用接口文同名，或接口文与源码同名，皆拒。跨文型之名源与先后已核，可生第四版 JSON 清单，尽录公开声明、所析依赖闭包及规范文之 SHA-256 摘要；依赖成环或同名异版者拒之。算摘要须构建机有 `shasum -a 256`；名循逻辑文件，毋取物理径。以「--核对清单」可复生而逐字节较之，察规范与既存清单之异。型构造之全义与逐术投影核对，犹待成之。详见[汉语稿](说明.汉语.md)。
