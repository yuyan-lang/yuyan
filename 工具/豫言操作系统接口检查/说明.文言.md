# 豫言操作系统接口检查

此工具以豫言读仓根纯声明之文，借编译器词法与抽象语法之术，而止于合声明定义之前，故无体之「乃」可存。又读同目录包之描述，验主、名、全版及直接所依，拒同包重名、越依与函数之体。「。接口。豫」之术宿主具，「。应用接口。豫」之术客具；实现之主、名、版、向从「实现接口。豫」核之，再比源级术型。凡当实现之术，须有「者」之体，徒有「乃」不可充数。跨文型之名源与先后已核，可生第四版 JSON 清单，尽录公开声明、所析依赖闭包及规范文之 SHA-256 摘要；依赖成环或同名异版者拒之。算摘要须构建机有 `shasum -a 256`；名循逻辑文件，毋取物理径。以「--核对清单」可复生而逐字节较之，察规范与既存清单之异。型构造之全义与逐术投影核对，犹待成之。详见[汉语稿](说明.汉语.md)。
