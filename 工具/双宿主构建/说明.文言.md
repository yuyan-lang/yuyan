# 双宿主构建

云工模式又出 `动态资源.mjs`，汇隔离入口、宿主与句柄之源码，兼值桥 Wasm 字节，以备动态载器。实务唯书豫言；用 Loader 者，许可书之 `LOADER` 当列其名，Wrangler 须置 `worker_loaders`。同号 `get` 之码与限额须恒同。

此器以豫言书之。取应用豫言稿，编为 WasmGC，组值桥，抄浏览器或云工库中固定 JS 外壳。外壳唯载器、传能，应用之法悉在豫言。

先成 `yy双宿主构建` 与 `yy网页汇编宿主`，于仓根以六参行之：模式、源码、产物目录、编译器、包上下文、许可文件；第七参可命云工服务入口。模式称「浏览器」或「云工」；浏览器许可传 `-`。云工许可书按 KV、R2、D1、SERVICE、DO、ASSETS、QUEUE、EMAIL 列可授绑定。云工之 `入口.mjs` 可作 Wrangler 主入口，同一豫言 Wasm 可受 fetch 或 queue 之事；浏览器则呼 `启动豫言浏览器应用()`。编应用时禁旧缓存，以防共享工作树旧物混入；此器不立部署配置，亦不改云仓。

云工第七参若为 `CloudModel`，构建器出同名 `WorkerEntrypoint`，其请以 `service-fetch` 事入豫言；公域默认请仍以 `fetch` 入。Wrangler 可以 `entrypoint: CloudModel` 指服务绑定。Wrangler 4.129.0 本地同 Worker 绑定已验二路异应；非法别名见拒。自定 RPC 法、多个别名及云上部署待补。详 [Cloudflare 命名入口文档](https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/rpc/#named-entrypoints)。

浏览器产物又有 `自动启动.mjs`。页载 `<script type="module" src="/产物/自动启动.mjs?标识=应用根"></script>`，无需别书调用 JS；有 `id="应用根"` 始取 Wasm 而启之。省标识则即启。真 Chrome 已验有标则行豫言、无标则略之且不取 Wasm。若欲自主持客器之寿，仍可呼 `入口.mjs` 所出之明启函数。

浏览器产物并抄 `工作线程自动启动.mjs`。工客豫言源若别于页客，宜构于页产物子目录；页客以子目录壳之相对址造工。壳于 Dedicated Worker 内载同目录二 Wasm；工客先以自身柄听主信，继以豫言回信。真 Chrome 已验页、工皆为豫言 Wasm 而初信与回信往还。

云工 `入口.mjs` 又出通用 `豫言持久对象` 类，可于 Wrangler 持久对象绑定及 SQLite `exports` 引之。类之外层分派 fetch、alarm 唯属宿主，实务之断与久态读写由同一豫言 Wasm 行之；构建器仍不代应用立 Wrangler 配置。
