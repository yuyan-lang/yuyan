# 低阶语言

## 为什么需要

裸机上的客体执行器要跑普通豫言编译出的 WasmGC 模块（800 个函数、近五万条指令），执行器本身只能是整数 Wasm 函数，再由寄存器降级变成两种架构的机器码。此前执行器是用豫言逐条拼 `网页指令` 的扁平列表（约 727 KB 源码），每加一个操作码都要手算标签深度和栈形状，规模上去以后无法维护。低阶语言是一个刻意很小的括号语言：只有一种类型（三十二位整数）、显式的内存读写和结构化控制，编译器一遍分词、一遍成树、一遍成码，直接产出与手写列表等价的 `网页状态模块`，再经现有的验证、二进制生成和降级路径进入 ARM64／AMD64 镜像，也可以生成标准 `.wasm` 交给 Node 等宿主调试。

## 语法

源文件是 S 表达式，行注释以分号起，字符串字面量以双引号括起（不能含引号，只用于数据段）。

顶层形式：

|形式|含义|
|---|---|
|`(常量 名 表达式)`|编译期整数常量；表达式只含数字、已定义常量和 `+ - * / & \| ^ << >> >>u ~ !`|
|`(宏 名 (参…) 模板)`|文本宏。使用处 `(名 实参…)` 被展开成模板（参数原样代入，可嵌套，展开深度上限 64）；实参在模板里出现几次就求值几次|
|`(导入 名 "模块" "字段" 参数数 结果数)`|导入函数（先于定义的函数编号）|
|`(函数 名 (参…) 语句…)`|函数。含 `(返回 表达式)` 的函数有一个结果，否则无结果；结果函数末尾自动补 `unreachable`|
|`(导出 "外名" 函数名)`|导出|
|`(内存 初始页 最大页)`|线性内存声明（至多一个）|
|`(数据 偏移 项…)`|主动数据段；项可以是字符串（UTF-8）、数字（一个字节）、`(字 值…)`（小端四字节）、`(半 值…)`（小端两字节）、`(零 长度)`|

表达式：数字（十进制、`0x` 十六进制、可带负号，按三十二位取模）、局部变量名、常量名、`(op a b)`（`+ - * / /u % %u & \| ^ << >> >>u rotl rotr == != < > <= >= <u >u <=u >=u`，其中 `+ - * & \| ^` 可有多个参数，`-` 单参数为取负）、`(! a)`、`(~ a)`、`(&& a b…)`、`(\|\| a b…)`（短路，结果为 0 或 1）、`(读4 址 [偏移])`、`(读2 …)`、`(读2有 …)`、`(读1 …)`、`(读1有 …)`（无符号或有符号扩展；偏移须为常量）、`(选 条件 甲 乙)`（两边都求值）、`(内存页数)`、`(内存增长 页数)`、`(函数名 实参…)`。所有能在编译期算出的表达式都折叠为常量。

语句：`(局 名…)` 声明局部变量（整个函数内有效，初值为零）、`(令 名 表达式)` 声明并赋值、`(置 名 表达式)`、`(存4 址 值 [偏移])`、`(存2 …)`、`(存1 …)`、`(若 条件 语句…)`、`(若否 条件 (语句…) (语句…))`、`(当 条件 语句…)`、`(中断 [层数])`、`(继续 [层数])`、`(返回 [表达式])`、`(陷阱)`、`(弃 表达式)`、`(内存复制 目的 来源 长度)`、`(内存填充 目的 字节 长度)`、`(块 语句…)`、函数调用语句（有结果的调用自动丢弃结果）、分派：

```
(分派 表达式
  (情形 (值 值…) 语句…)
  (情形 (值) 语句…)
  (否则 语句…))
```

`分派` 把各情形的值排序后编译成二分决策树，每个情形体只生成一份，用嵌套 `block` 加 `br` 到达，没有贯穿；重复的值在编译期报错。

## 输出与约束

- 每个值都是 `i32`，函数至多一个结果；宽整数（`i64`）由使用者按高低字自己拼。
- 局部变量按参数、`局`/`令` 出现的先后编号；局部变量不能与常量同名；参数不能重名。
- 输出是 `网页状态模块`（无全局），可经 `生成状态二进制` 写成标准二进制。
- 编译错误是异常，信息带出错的表达式文本。

## 工具与验收

`工具/豫言裸机/低阶编译。豫`：`yy低阶编译 输入源 输出模块`，读一个低阶源文件，写标准 Wasm 二进制。用 Node 的 `WebAssembly` 运行同一模块（提供平台导入）可以在宿主上调试；`库/编译器核心/裸机后端/低阶语言。测试。豫` 编译一份覆盖全部形式的源，先过标准验证，再用整数执行器运行二十个用例核对结果，检查带内存与数据段的模块经二进制往返仍通过验证，并要求十一个恶例（未定义名字、参数个数不符、重复分派值、赋值给未声明变量、参数重名、常量引用未定义名字、循环外中断、单参数加法、非常量偏移、括号未闭合、只有函数名的调用）在编译期被拒绝。
