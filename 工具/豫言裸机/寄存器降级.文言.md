# 寄存器降级

## 何以重写

旧降以内存之栈为本：每压一值，先读栈指，较其上限，写值，进一槽；每弹一值，退槽而读。比较、择一、除余，各展十余令，一操作平均约三十三字节。ARM64 命令壳因是几满一兆之预算（详[臂常量装载](臂常量装载.文言.md)），欲增执行器之能，必溢，而行亦迟。

今以寄存器为栈：虚拟栈项居于寄存器，而又并其常量与比较于后令。ARM64 命令壳自约九百七十八千字节减至十六万二千九百字节，AMD64 自七十九万八千八百七十三减至十八万四千。

## 制

- **栈槽即寄存器**：虚拟栈第 d 项恒居一物理寄存器，多于寄存器者溢于帧槽。ARM64 用 x19 至 x24、x26、x27 凡八，AMD64 用 rbx、r12 至 r15、rbp 凡六；皆由被调者保存，函数但存其所用。栈深编译时已定，故“弃栈顶数项”“分支时改栈高”皆不生码。
- **基寄存器**：ARM64 之 x28 为线性内存基址，x18 为今字节数（页数左移十六位），x25 为全局起址；AMD64 相应为 r9、r8、r10。入口一立，不复存。
- **内部借用**：ARM64 借 x9 至 x13；AMD64 借 rax、rcx、rdx、r11 于原语内，rsi、rdi 供溢出之操作数暂居。
- **局部居帧槽**：参数自 x0 至 x7（AMD64 为 edi、esi、edx、ecx）入，序言写之于局部槽；逾者经共用暂存传之（ARM64 自 `0x40380000`，AMD64 自 `0x380000`，每四字节）。此址旧为内存操作数栈，今已空。
- **帧**：ARM64 自 sp 而上：x30（十六字节）、被调者所存寄存器对（恒留六十四字节，使局部之偏不随所用寄存器之数而变）、局部槽、溢出槽，总数按十六字节对齐；AMD64 先 push 所存之寄存器，后 `sub rsp`，局部与溢出自 rsp 起。序言以 sp 较调用栈之下界（ARM64 `0x403D0000`，AMD64 `0x3D0000`），低则陷。
- **待发**：`i32.const` 与比较令不即发码，先记为“待发常量”“待发比较”，视后令而融之：
  - 常量后之加减、与或异或、乘、移位、比较，改用立即数式；
  - 比较后之 `br_if`、`if`，径发条件跳，不先 `cset` 为零一而后测；
  - `i32.eqz` 加于待发比较则反其条件，加于待发常量则折为新常量；
  - 余令之前，先落待发者为真寄存器之值。
- **控制帧**：每 `block`、`loop`、`if` 记其类、基深、果数、分支标、终标、否则标。跳至某帧，则自栈顶取其果数之值，依次搬于该帧基深之槽，所弃中间槽不必理。`br`、`return`、`unreachable` 以后，至相配之 `else`、`end` 之前，皆死码，惟以嵌套之数略过。
- **多果**：函数与块可返数值，函数之果走结果寄存器（ARM64 为 x0 至 x3，AMD64 为 eax、edx、ecx），调者旋搬入新栈槽。
- **整批内存**：`memory.copy`、`memory.fill`、`memory.init`、`memory.grow` 各一助手，全模块共用；越界皆陷，重叠而复者按地址之势择其向；数据段之描述先四字节有效长，后接原字节，`data.drop` 则写长为零。
- **入口存根**：立基寄存器，读页数之描述，呼启动函数，探测之式再读一内核私有之址（必缺页，以证隔离），终以退出码零请求完成。

两架构共此一遍历，异者唯在“令原语”一层：`指移`、`指二元`、`指载内存` 诸包装，依首参分派于[臂降级原语](../../库/编译器核心/裸机后端/臂降级原语。豫)或[兼降级原语](../../库/编译器核心/裸机后端/兼降级原语。豫)，而原语复由[臂汇编](../../库/编译器核心/裸机后端/臂汇编。豫)、[兼汇编](../../库/编译器核心/裸机后端/兼汇编。豫)编码。二汇编之编码器皆对 llvm-mc 之出而试之（ARM64 六十余例，AMD64 四百六十例）。

## 余波与所踩

- 用户码快逾二十倍：多任务用例中百万次之“长循环”，不复跨一时钟周期，验抢占之 `双任务`、`定时中断` 诸景遂败。新增[长算常量。豫](../../库/编译器核心/裸机后端/长算常量。豫)，改为二千万次，每任务约百毫秒，跨数十周期。
- 探测之读必在启动函数**返回之后**：`设备缺页退出` 诸景正赖父任务返回后之一读以致缺页。
- AMD64 之载入种类编号异于 ARM64（零扩、符扩之次），初移植时字节与半字之有符号读错位，由 `固定访存` 一景所发。
- 验证器所生之 C 近六十兆字节，编译器末链因发布版之分配器不查所余之堆而崩；构建前设 `YY_GC_INITIAL_HEAP_SIZE_MB=1024` 可避之，根治当改运行时之分配器。

## 界

- 局部尚未分寄存器，每读写皆一栈访；无内联、公共子式与逃逸分析。
- 局部与操作数栈槽合逾三千五百之函数，入口即陷（与旧降“栈越界即陷”同）；果数逾寄存器数者拒之。
- 全局值至多四千零九十六（ARM64 单载偏移之限）。
- 旧内存操作数栈之降、内存编码及其试皆已除；[访存编码](访存编码.文言.md)、[结构控制](结构控制.文言.md)、[固定内存](固定内存.文言.md)、[批量复制](批量复制.文言.md)、[批量填充](批量填充.文言.md)所述行为之规与验收不易，其实现以此篇为准。
