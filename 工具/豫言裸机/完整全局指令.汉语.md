# 完整全局声明与指令验证

指令验证现按模块读取定义全局的完整值类型、可变标记和初始化表达式，再向每个函数传递同一份全局类型列表。global.get 按声明类型压栈；global.set 要求全局可变并检查值类型；索引和全局导出边界均检查。

初始化表达式支持 i32/i64/f32/f64 常量、空引用，以及 i32/i64 加减乘扩展常量。最终恰有一个值且符合全局声明类型。常量编码读取与函数体共用边界及溢出规则，禁止用任意函数指令代替常量表达式。引用可空性和具体堆类型作用域仍按完整类型关系检查。

当前模块接口仍拒绝非函数导入，因此尚未支持导入全局；初始化中的 global.get、ref.func 也尚未接入。拒绝这些形式属于未支持，不是断言其全部不合法。

20 个完整标准模块分类与 Node 一致，库测试通过。覆盖宽整、小数、引用子类型、非空约束、可变性、错误初值、扩展常量、索引及导出越界。命令构建及真实产物复验结果另录。此为静态验证，不执行全局初始化或对象分配，默认裸机镜像不变。

新增允许的结构体、数组及 i31 常量构造；读取常量子操作码后先检查白名单，再复用对象类型规则。字段读取、写入和任意对象操作不因此成为合法常量。20 个全局模块与 20 个结构对象回归通过。

真实产物复验：`yy优化器三代.wasm` 与 `yy栈默认回归GC重复索引边界.wasm` 已越过全局读取和 GC 常量初始化，停在尚未接入的操作码 19（间接尾调用）；`yy栈向量排序.wasm` 停在操作码 40（i32.load）。这些结果只定位下一个未支持项，不证明完整模块有效或已能在客体执行。下一步须建立完整表与内存上下文，验证资源索引、地址类型及调用签名。
