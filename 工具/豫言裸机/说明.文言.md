# 豫言双架构裸机之始

标准网页汇编整数模块经豫言提前编译，成两机启动镜像。机器字节、标号、重定位、首部与页表皆以豫言作之，无英文汇编源，不借外汇编及链接之器。

臂机于一级异常层立页与向量，返零级以行客；兼容机自保护模式入长模式，立页、描述符、任务状态及中断门，转第三环以行客。核心验硬件所存用户态，授串口、核验、用户态、时钟与任务查询诸服务。旧验收须四次核验；常规程序可径退，不受此测试约束。

初版两机各六试：正常、隔离、错果、释页权、操作数栈溢、调用栈溢。前二须成，后四须拒；退码与串口文字并验，不以印字独为证。验证器亦豫言所作，限时候之，超时终本轮所生进程，产物及日志藏新建临时目录。命令详汉语稿。

用户两栈分区而有界，函数诸参及局部合计至多一百二十八，代码至多一兆字节。今单核、静态大页，两客分域轮行之实现详[双任务调度](双任务调度.文言.md)，实测另载。今二槽可动态生灭、等待、终止、回收与传消息；[用户命令壳](用户命令壳.文言.md)初具，未授输入模块者默认载之。通用多任务、文件、持久化、完整命令壳、客中动态加载及完整垃圾回收犹未备。用户代码与栈未细分写行之权，不以此冒生产沙箱。旧普通豫言仍循原 WasmGC 后端。

串口由客体访设备，模拟退出惟为止试。生成器不先算客体之果；其自身尚由旧编译器构建，以 Wasm 行之亦借既有宿主。客体无旧库依赖，非整个自举工具链已独立。此为微内核引导原型，非完备操作系统。

用户态结构控制已通，两架构二十试皆过，详[结构控制](结构控制.文言.md)。后续时钟与轮行之进展，见[双任务调度](双任务调度.文言.md)。

增非阻塞读字节，双架构二十四试皆过，详[控制台输入](控制台输入.文言.md)。

今增客故障独退与退出码之问，两机一三八试俱成，详[故障隔离](故障隔离.文言.md)，并载避旧编译缓存误验之法。

今增阻塞待客与退出唤醒，两架构一四八试俱成，详[阻塞等待](阻塞等待.文言.md)。

今增有权止客之术，两架构一五四试俱成，详[主动终止](主动终止.文言.md)，动态创建及回收未毕。

今增行中复制任务，两机一六〇试俱成，详[运行时创建](运行时创建.文言.md)。今单槽静态池，动态加载及资源复用未成。

今固定池之生、待、止、收与再用皆通，两机一七二试成，详[任务回收](任务回收.文言.md)。通用多客分配、通信、动态加载、命令壳及持久文件犹待。

今增受所属与世次句柄约束之双向信函，两机一八〇试成，详[任务通信](任务通信.文言.md)。接收暂不阻塞，客态服务所需犹续进。

今待信、唤醒与彼止之处置皆通，两机一九二试成，详[阻塞通信](阻塞通信.文言.md)。通用调度、长字节与客态服务犹续进。

今造镜像默认常规运行，省方式或言“运行”皆可；旧正常、隔离仍守验收之义。详[常规运行](常规运行.文言.md)，两机二一〇试成。非谓完整高级豫言及 WasmGC 已能行。
今设备地址隔离已及用户线性区，首末、上界、只读与用户可见性皆验，两机共二六二试成。详[用户设备内存](用户设备内存.文言.md)。默认用户命令壳可交互治任务；虚拟磁盘驱动、文件持久化、动态执行器与 WasmGC 尚未成。
今接用户设备寄存器与“设备驱动”造镜方式，两机二六八试成，详[用户设备寄存器](用户设备寄存器.文言.md)。核主初置与授页，用户可协商特性、定队列；磁盘传输、退出清理及文件持久化尚待续作。
今用户态虚拟磁盘可读写、刷新，另启模拟器而数据仍在；两机二八〇试成，详[用户磁盘读写](用户磁盘读写.文言.md)。文件目录、命令壳文件术及设备服务分进程，犹待续作。
用户文件系统提交日志已验复启、缺尾、坏记与满盘，两机二九四试成，详[文件系统提交日志](文件系统提交日志.文言.md)。目录、文件名、删除、空间回收与命令壳文件术犹未成。
今用户文件目录可建、寻、枚举、替换、分段读与删，复启仍守柄之世次，两机三〇八试成。详[用户文件目录](用户文件目录.文言.md)。命令壳文件术、独立文件服务与日志盘占回收犹待作。
默认用户壳今兼文件、目录、路径及显式格式化，旧任务与输入术皆存，两机三一四试成。详[命令壳文件操作](命令壳文件操作.文言.md)。日志盘占回收、独立文件服务、动态加载与 WasmGC 犹待完成。
设备主自然毕、显式退出、陷阱及硬件缺页，今皆由核夺权、复位而清设备映射；子毕不夺父权。两机三二六试成，详[设备退出清理](设备退出清理.文言.md)。随机在途压力、通用资源池、盘占回收、动态加载与 WasmGC 犹待完成。

客体取字及三十二位变长数之读，已验两架构，诸试共三百二十八项皆成；复以独立网页汇编执行器验其模块并行其试。详[客体取字](客体字节读取.文言.md)。此仅载入之基，未入默认命令壳；模块全验、动态执行与垃圾收集尚待续成。

客体模块之头、段序、段界、名字与选段之限，皆验于两架构，诸试共三百三十项而成。详[客体模块分段](客体模块区段.文言.md)。录目仅知段址；段内全验、指令与实例化待续，未可载行外来程序。

客体整数函数之目，今验类型、导入、定义、局部、导出与启动签名，诸试共三百三十二项而成。详[客体函数之目](客体函数索引.文言.md)。代码全验与其余资源之读待续，录目成不授执行。

客体内存、全局、数据段之读与独立工作区初置，皆验两架构，诸试共三百三十四项而成。详[客体资源初置](客体资源初置.文言.md)。先遍验主动段，乃复制其字；尚不行函数，全验、实例化与动态执行待续。

客体整数函数体今可解而录指令，验形与立即数，回填条件出口，诸试共三百三十六项而成。详[客体解指令](客体指令解码.文言.md)。操作数栈之验与执行待续，解成不授行。

客体整数函数之操作数与控制栈皆验两架构，诸试共三百三十八项而成。详[客体栈之验](客体操作数栈.文言.md)。四十四例与标准验证同；执行、运行陷阱、模块全验与动态运行待续。

用户态整数解释器今实行标准模块之控制、算术与调用，求和、阶乘皆客体自算，诸试共三百四十项而成。详[客体整数之行](客体整数执行.文言.md)。内存令、导入、命令壳载行、跨模块互调与垃圾收集待续。

用户态解释器今可行内存读写、增长、复制、填充、段初置与弃，诸试共三百四十二项而成。详[客体内存令](客体内存执行.文言.md)。回绕、空界与失败不半写皆验；导入、命令壳载行、链接与垃圾收集待续。

客体解释器今连定平台之术，按名寻导出，启动一度，并受默认空表；独立 C 模块之原字实跑，四次回调皆成，诸试共三百四十八项。详[客体导入与启动](客体导入与启动.文言.md)。命令壳载行、通用互连、WASI、间接调用与垃圾收集待续。

默认用户态壳今可自盘载行模块为子，候其归、终其行、示其码；复启仍可载，独立 C 模块亦成。子行时父仍可读写。诸试三百五十二项，四默认镜像已新，详[命令壳载行](命令壳程序运行.文言.md)。通用任务内存池、互连、WASI、间接调用、磁盘空间回收与垃圾收集待续。

二〇二六年九月二十五日：独立宽除之函使臂之命令壳码逾一兆之限，凡以文件命令壳为基之试皆将败。臂之常量装今唯高十六位非零方发 `MOVK`，文件命令壳减约七万字节，余地复正；新设[代码量诊断。豫](代码量诊断。豫)可随时核两架构之余。两架构无外部模块共三百六十项皆成；带外部模块之三百六十八项，行时见父子二任务同写串口而字节交错之间歇败，详[臂常量装载](臂常量装载.文言.md)。

控制台之出，今由内核以行蓄之：每任务于内核私页蓄一行，遇换行、缓满、读入、任务退出或被终止，乃一并书于串口，一行不复为他任务之字所断。二任务各书三千行之 `控制台行原子` 景及 `--只验 名` 之选皆已入验证器，两架构共三百六十二试皆成，带外部模块之三百七十试连成，详[控制台以行为单](控制台行缓冲.文言.md)。

二〇二六年九月二十五日：降之后端改以寄存器为栈：虚拟栈项居于寄存器，常量与比较并于后令，入函一并核调用栈。ARM64 命令壳自九百七十八千字节减至十六万二千九百字节，AMD64 自七十九万八千八百七十三减至十八万四千，预算得宽，可续增执行器之能；两机共三百六十二项（并外部模块三百七十项）QEMU 之验悉过。详[寄存器降级](寄存器降级.文言.md)。

二〇二六年九月二十五日：内核增内存块之管：ARM64、AMD64 各有三十二块、每块二兆字节之物理池，服务二二 `内存块(n)` 为任务按需增块，服务二三返块数；`memory.grow` 逾八页，则迁线性内存于动态块而续增，任务毕、败、被终止皆归还，复制任务尽复其块，池尽则干净而败。增四景，两机共三百七十八项（并外部模块）QEMU 之验悉过。详[内存块管理](内存块管理.文言.md)。
