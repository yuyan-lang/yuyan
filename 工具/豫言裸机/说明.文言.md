# 豫言双架构裸机之始

## 今之全系（先阅此）

豫言操作系统今为可启、可交互、有持久文件系统之单核系统，ARM64 与 AMD64 皆于 QEMU 通过自动验收：

| 层 | 所载 | 文 |
|---|---|---|
| 内核 | 手编机器码（豫言源所生）：页权限之隔离、定时之抢占、二任务槽之创建、等待、终止、回收、复制，单条整数消息之邮箱与阻塞接收，动态内存块（线性内存可增），设备窗口与 IOMMU 之隔离，Virtio 设备之用户态访问 | 本目录诸专题 |
| 用户态执行器 | `客体二号`：以底层模式之常豫言所书 WasmGC 解释器（栈机、保守标记清扫、异常、尾调用、软浮点），于用户态行普通豫言程序 | [客体二号](客体二号.文言.md) |
| 文件系统 | 用户态 Virtio 块驱动加双区追加日志之持久文件系统（多层目录、崩溃安全之提交扇区、紧缩），离线造盘之器 `yy造盘` | [客体二号](客体二号.文言.md)、[文件系统提交日志](文件系统提交日志.文言.md) |
| 壳 | 普通豫言所书之默认命令壳（`壳/壳。豫`）：目录、切换、列、读、写、追加、复制、移动、建、删、运行、脚本、加、回显；命令之出可以 `>`、`>>` 导入文件；子进程中亦可读写文件（由壳代办）| [客体二号](客体二号.文言.md) 验收一节 |
| 进程 | 同步子进程：复制任务，子任务以盘上之程序易己，父任务候其退出码 | 同上“子进程”一节 |
| 动态装载 | 多实例：运行中自盘装载 Wasm 模块，跨模块导入导出与双向回调（含延迟之链） | 同上“多实例”一节 |
| 数值 | 小数运算走 IEEE 754 软浮点（加减乘除、诸转、定点六位转文、文转小数）；Wasm 之 f32、f64 诸指令（较、算、取整、开方、转、饱和截断）亦以软浮点行之，逐位与 V8 相校 | 同上“软浮点”“Wasm 浮点指令”二节 |

**构与行**（于仓库根目录、已装 QEMU）：

```sh
./yy豫构 文件 工具/豫言裸机/豫言系统。豫 --编译器 ./yy4_bs --输出 yy豫言系统
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy豫言系统 运行 --架构 兼容六十四      # 交互；壳中书“退出”以终
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy豫言系统 构建 --预置 某目录树       # 唯造镜像与盘，并印 QEMU 之令
```

`--预置` 所指之目录树，全入于盘；树中以 `。豫` 终者先编为程序（`/程序/你好。豫` 成 `/程序/你好.wasm`），以 `.低阶库` 终之标记文件构同名之底层包（`/库/库甲.低阶库` 成 `/库/库甲.wasm`），壳中以 `运行 /程序/你好.wasm 参…` 启之，普通豫言程序可用 `豫言_加载模块`、`豫言_调用导出` 装载而调库。用法见 `工具/豫言裸机/豫言系统。豫`。

**验**：

```sh
./yy豫构 文件 工具/豫言裸机/普通豫言验证。豫 --编译器 ./yy4_bs --输出 yy普通豫言验证
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy普通豫言验证                       # 三十七项乘双架构，约十二分；--只验 普通-壳- 可只行一类
```

涵：普通豫言程序（打印、列表、闭包、异常、回收之压、小数、浮点指令、表指令）、壳（基本、文件命令、运行子进程、子进程之文件、输出重定向、子程序崩溃之隔、盘上之大程序）、语言测试集 `测试/网页汇编` 之十二例、磁盘（跨重启读写、离线造盘）、动态装载（含回收之压）、内核服务之探针。内核本身别有 `yy裸机验证`（下文，三百余项）。

**今之界**：内核唯二任务槽，故一时唯一子进程、子进程不得再起子进程；子进程之文件事由初始任务经邮箱代办（每信三字节，量大甚缓）；无实时时钟；小数精确表示未作；跨实例唯传数值；无 SIMD。

标准网页汇编整数模块经豫言提前编译，成两机启动镜像。机器字节、标号、重定位、首部与页表皆以豫言作之，无英文汇编源，不借外汇编及链接之器。

臂机于一级异常层立页与向量，返零级以行客；兼容机自保护模式入长模式，立页、描述符、任务状态及中断门，转第三环以行客。核心验硬件所存用户态，授串口、核验、用户态、时钟与任务查询诸服务。旧验收须四次核验；常规程序可径退，不受此测试约束。

初版两机各六试：正常、隔离、错果、释页权、操作数栈溢、调用栈溢。前二须成，后四须拒；退码与串口文字并验，不以印字独为证。验证器亦豫言所作，限时候之，超时终本轮所生进程，产物及日志藏新建临时目录。命令详汉语稿。

用户两栈分区而有界，函数诸参及局部合计至多一百二十八，代码至多一兆字节。今单核、静态大页，两客分域轮行之实现详[双任务调度](双任务调度.文言.md)，实测另载。今二槽可动态生灭、等待、终止、回收与传消息；[用户命令壳](用户命令壳.文言.md)初具，未授输入模块者默认载之。通用多任务、文件、持久化、完整命令壳、客中动态加载及完整垃圾回收犹未备。用户代码与栈未细分写行之权，不以此冒生产沙箱。旧普通豫言仍循原 WasmGC 后端。

串口由客体访设备，模拟退出惟为止试。生成器不先算客体之果；其自身尚由旧编译器构建，以 Wasm 行之亦借既有宿主。客体无旧库依赖，非整个自举工具链已独立。此为微内核引导原型，非完备操作系统。

用户态结构控制已通，两架构二十试皆过，详[结构控制](结构控制.文言.md)。后续时钟与轮行之进展，见[双任务调度](双任务调度.文言.md)。

二〇二六年九月二十五日：独立宽除之函使臂之命令壳码逾一兆之限，凡以文件命令壳为基之试皆将败。臂之常量装今唯高十六位非零方发 `MOVK`，文件命令壳减约七万字节，余地复正；新设[代码量诊断。豫](代码量诊断。豫)可随时核两架构之余。两架构无外部模块共三百六十项皆成；带外部模块之三百六十八项，行时见父子二任务同写串口而字节交错之间歇败，详[臂常量装载](臂常量装载.文言.md)。

控制台之出，今由内核以行蓄之：每任务于内核私页蓄一行，遇换行、缓满、读入、任务退出或被终止，乃一并书于串口，一行不复为他任务之字所断。二任务各书三千行之 `控制台行原子` 景及 `--只验 名` 之选皆已入验证器，两架构共三百六十二试皆成，带外部模块之三百七十试连成，详[控制台以行为单](控制台行缓冲.文言.md)。

二〇二六年九月二十五日：降之后端改以寄存器为栈：虚拟栈项居于寄存器，常量与比较并于后令，入函一并核调用栈。ARM64 命令壳自九百七十八千字节减至十六万二千九百字节，AMD64 自七十九万八千八百七十三减至十八万四千，预算得宽，可续增执行器之能；两机共三百六十二项（并外部模块三百七十项）QEMU 之验悉过。详[寄存器降级](寄存器降级.文言.md)。

二〇二六年九月二十五日：内核增内存块之管：ARM64、AMD64 各有三十二块、每块二兆字节之物理池，服务二二 `内存块(n)` 为任务按需增块，服务二三返块数；`memory.grow` 逾八页，则迁线性内存于动态块而续增，任务毕、败、被终止皆归还，复制任务尽复其块，池尽则干净而败。增四景，两机共三百七十八项（并外部模块）QEMU 之验悉过。详[内存块管理](内存块管理.文言.md)。
