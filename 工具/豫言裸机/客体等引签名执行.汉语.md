# 客体 `eqref` 函数签名

客体解释器现在接受以 `eqref` 为参数或单一返回值的函数签名。类型索引把参数记录在签名位图的高十六位；操作数栈验证调用实参、函数返回值以及参数的 `local.get`、`local.set`、`local.tee`。运行时沿用现有的引用值表示和调用帧，不改变宿主平台的整数接口。

`等引签名正.wasm` 是可执行验收模块：在原有外部模块的启动函数中加入 `(param eqref) (result eqref)` 恒等函数调用，让非空 `i31` 与空 `eqref` 都经过同一调用路径，然后继续原有平台回调。该模块已经通过 Node 的 `WebAssembly.Module` 标准验证。双架构裸机回归使用：

```sh
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy设备配置编译器 工具/豫言裸机/验证。豫 -o yy等引签名验证
./yy等引签名验证 --外部模块 yy外部C模块.wasm yy外部C错误.wasm --客体模块 工具/豫言裸机/等引签名正.wasm
```

此步只开放函数签名中的 `eqref`。局部变量声明中的 `eqref`、其他宽数值类型和普通豫言最小模块所需的更多 GC 指令仍需逐项实现与验收。
