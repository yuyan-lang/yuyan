# 完整型之结构控制

今实令验者受块、循环、条件、否则、终结及无条件条件跳转。帧存父栈、初子栈、全签名与局部赋值记。块与条件以果为标签，循环以参为标签，函数自为最外标签。

条件先取三十二位判断，再取块参。否则先验前支果，后复初栈及赋值记；无否则则另验隐式空支，参能供果乃可。出块复初赋值记，不使支内非空局部之赋值冒出其域。条件跳转验而留标签值，无条件则断流。

二十一完整模块验宽果、多果、隐支传参、循环参、跳深错型、重否则、帧界与赋值域，与 Node 分类同。验型构建运行皆成，四百零八标量回归亦成。日志存 `/tmp/yy结构指令检查日志`、`/tmp/yy结构指令构建日志`、`/tmp/yy结构指令运行日志`、`/tmp/yy结构标量回归运行日志`。

分支表、异常、尾调、回收对象及模块资源全验尚待，未能据此运行普通豫言全程序，未接裸机，默认镜像不变。
