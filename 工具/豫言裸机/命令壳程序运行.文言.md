# 命令壳载行程序

默认用户态壳今以“运行 路径 [导出名]”读磁盘标准模块，于独立子任务验而行之。所用为生产执行组件，不携单元验例。可继以“等待”“终止”治其任务。

未明导出，则次寻“启动”、`_start`、`main`；明之则唯寻所指。今入口无参，返零或一整数。路径循既有相对、绝对与目录之法，带空白之引号语法未具。

父先析路、验文件与长，尽读而后复制任务。文件八至十三万一千零七十二字节。父保文件系统、设备权与输入，仍理诸命；子独占其执行工作区，读模块、解指令、验栈、初置、寻导出而行。未验者不得行，访存不入父域与执行器之目，平台只授既有合型接口。

子未等待回收，不复生子，沿今两槽之限。等待、终止、察任务与退出清理皆循旧核；内置与文件程序共一柄，不漏相管。子正常、陷阱、验败或被终止，父仍可读写与再起。

返整数则显示并为完整退出码，无返则零。结果与退出码皆以有符号十进制示之。读、解、验、初置与查导出败，子示其阶段而以一百二十六退；运行败以一百二十五退，附执行器之过码。强制终止之码循旧核。

每次至多百万步，调用与工作区之限仍存。子之终止由核收之，不撤父之块设备权。

执行组件按函数与类型基号装配，控制台由壳供之；程序壳治解析与子入口，文件壳合为默认模块。二四六零零存子柄，后每四字节存程序长、导出名长与显式记。程序字始六五五三六，查名始六三零零零。子录模块会覆盖旧文件工作区，故必复制之后始录；父自有副本。

唯测试播种入口格式化新临时盘，写算术、陷阱、损坏、循环、后备导出及可选独立 C 模块，再入同一默认壳。产品启动不自格式化，不自写验例。

试先起循环，候实入执行，父创写读文件，继而终止回收；再验导出、后备、陷阱、坏字、缺名、坏路与坏命。若有 C 夹具，必自文件系统读而行。第二次模拟启动用默认壳，沿旧盘不播种，复读备注与程序而行，以验持久。旧隔离、任务、通信、文件与输入诸试仍行。

完整执行环境未成。通用互连、WASI、间接调用、任务与内存池、磁盘空间回收、完整垃圾收集，皆当续成。
