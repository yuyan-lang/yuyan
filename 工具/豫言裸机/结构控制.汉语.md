# 双架构用户态结构控制

ARM64 与 AMD64 提前编译后端现已接入标准整数 Wasm 的块、循环、条件、否则、结束、跳转、条件跳转、返回和陷阱。控制标签由豫言机器码连接器解析；代码仍直接输出机器字节，没有汇编源文件或外部汇编器。

编译阶段维护控制帧和静态操作数高度。循环标签落在循环体入口，其余块标签落在块末尾；函数返回跳到共同收尾代码。条件分支先弹出条件再判断，非零为真。不可达代码仍由模块验证器检查，降级时可以省去不可达的基本指令。

跳转需要丢弃中间栈值时，先把要保留的结果复制到目标栈位置，再下移操作数栈指针。复制按地址从低到高进行，支持源、目标重叠和多个函数结果。不增加私有缓冲区，不改变原有函数调用接口。已有调用栈与操作数栈容量检查继续保留。

## 验证

裸机验证器增加“结构控制”和“控制错误”，两种架构合计二十项。结构控制程序在真正用户态完成四次核验：

- 循环累加一至一万，结果 `50005000`；条件跳转退出外层块。
- 保留外层值七，跨块跳转丢弃中间值九，留下四十二，随后相加得到四十九。
- 子函数保留两个返回值一、二并丢弃前面的九十九，调用方相减得到负一。
- 嵌套真假条件只执行被选择的路径，跳过另一侧陷阱并返回四十二。

错误对照把循环预期值改为 `50005001`，必须由内核报告失败并以失败状态退出。测试同时保留权限隔离、放开权限的负对照、栈越界及原有整数比较验证。标准模块另可交给 V8，通过同样的四次核验。

```sh
./yy3_bs 工具/豫言裸机/验证。豫 -o yy裸机验证 -j 1
./yy裸机验证
```

这仍是单用户域裸机原型。参考解释器的执行预算不自动适用于提前编译的机器码；裸机尚无定时抢占和故障任务回收，死循环仍可能独占处理器。默认用户态 Shell、控制台输入、文件系统及完整 WasmGC 仍待实现。
