# 完整类型之读取

新读器循有界游标，读标准编码为完整型。备数值、向量、抽象具体引用及可空性、窄字段、可变标记、函数、结构、数组、子型与递归组。又增异常引用及其空底，不归聚合之系。

具体号以非负 s33 读，合法非最短正编码可受；逾五字节、截断、负号及超过无符号三十二位者拒。抽象堆依规范一字节，可变标记唯零一；尾余亦可验。每向量仍限六万五千五百三十六项，此乃实现之额。

读成非即模块合法。父型数量、号之作用域、递归等价、终型、字段子型皆待上下文。尚未接裸机解码，未增对象执行与回收。

对照 Node 26.3.0，类型段 `01 60 01 63 f0 7f 00` 可受，视多字节负值为函数堆；今规范抽象堆一字节，非负具体号乃 s33，故此读器拒之，存异不称尽同。递归组正例于 Node 亦成。

所据：[三版类型编码](https://webassembly.github.io/spec/core/binary/types.html)。诸试验编号之极、非最短正码、宽数、可空、递归字段，并截断、溢出、错型与错标记。
