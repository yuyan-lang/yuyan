# 限权读设备配置

块设备先循现代 Virtio PCI，两机共其用户协议。今仅辨设备、循能力链；未协商特性、立队列、启 DMA、读写扇区，非持久化已成。

平台十九号服务曰设备配置读，一参一果。参为字节偏移，四字节齐，限零至二百五十二。固定总线零、第四设备、功能零，惟初始任务得读；子不承权。不得自选物理地址或端口，亦不得写配置。参谬或无权者返全一，设备缺席亦可同果，今未细分败因。

用户核厂商与块设备标识，循能力链以求通用、通知、中断状态、设备配置四类。验对齐、边界、长度，至多四十八步；通知须容其乘数。未以所得 BAR 地址径访存。

臂机用低址 ECAM，验时关高址 ECAM；内核以设备属性映射所需块，仅核可访，且不可执行。兼容机于异常处理中循配置端口，用户无端口权。机器字节皆豫言所造。

实挂独立临时盘，验标识、类别、能力、坏参及子无权；不挂则验缺席，错期望须败。另以同解析函数验十种能力表。初始任务之权为引导约，非完整设备能力制。BAR、队列、DMA 生命周期与缓存一致、完成通知、恢复、刷新、块服务、文件持久化，皆仍待成。无 IOMMU 而可任意编程 DMA 者，虽居用户，仍须可信。

所据为 [Virtio 1.2](https://docs.oasis-open.org/virtio/virtio/v1.2/virtio-v1.2.html)、[QEMU virt 文档](https://www.qemu.org/docs/master/system/arm/virt.html) 与其平台内存表；固定平台不代通用枚举。
