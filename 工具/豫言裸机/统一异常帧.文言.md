# 系统调用与缺页同帧

臂同步异常、兼容系统调用与缺页，今与定时中断共整数帧之局。臂二百七十二字节，兼容一百六十字节，诸字段详任务上下文篇，以备后续阻塞、退出共用恢复之基。

臂保存时借零号寄存器取系统状态，分派前复原其参数；返客前先置服务结果于帧零号槽，核返址与客栈，乃复诸寄而返。

兼容系统调用于硬件返帧前存十五寄，服务结果置于偏移一百一十二之累加槽，然后共验共复，余寄皆还原。

兼容缺页另有硬件错误码，先验来者为用户，保全原累加寄而移错误码至内核私处 `0x103328`，去栈中其项，乃成同帧。旧缺页之验改取此码。今仅单处理器且内核屏蔽中断，多处理器与嵌套故障尚未具。

二〇二六年九月二十二日，双架构一百一十八验皆过。新增递归系统调用之正负例，二十层、四十层诸计算核服务返值及存活栈值，亦验空输入负一。相同模块经 V8，四核皆合，误期望则败。旧定时、屏蔽负例、隔离、栈界与独立 C 模块皆过。诸型合，新指令经反汇编核对。

复验命令详汉语篇。产物在 `/tmp/yy裸机验证.EgUuS0`，诸证录于 `验证记录.json` 之“统一异常帧扩展验证”。缺页仍止测试客体，未复故障任务或续他任务；创建、调度、阻塞与全进程状态未成，余未具异常亦未化为可恢复任务事件。

原生与网页生成器所成双架构系统调用镜像逐字同，亦同于本轮所验者。

后进已成两客轮行、易帧易页，详[双任务调度](双任务调度.文言.md)。本篇所载一一八试，乃统一帧阶段之旧证。
