# 用户态文件与目录

2026-09-22：两架构共 308 项 QEMU 自动验收通过，含十四项新文件目录用例。类型检查及十四个标准 Wasm 模块的独立验证通过；另行解析八份磁盘并重放目录语义，四组对应磁盘跨架构完全一致。

文件目录层建立在已验证的提交日志和 Virtio 块驱动之上。它支持根目录、嵌套目录、空文件、名称查找、枚举、内容替换、分段读取和删除；每次变更提交完成后才更新内存索引。格式当前仍是内部实验格式。

## 接口行为

根目录句柄固定为零。创建指定父目录、名称和种类，种类一是文件，二是目录；成功返回完整句柄。查找不存在的名称返回零，枚举结束也返回零。文件内容替换和删除成功返回零；读取返回实际字节数，超过文件尾返回零。

| 操作 | 参数 |
| --- | --- |
| 创建 | 父目录句柄、名称地址、字节长度、种类 |
| 查找 | 父目录句柄、名称地址、字节长度 |
| 替换内容 | 文件句柄、数据地址、字节长度 |
| 分段读取 | 文件句柄、文件内偏移、输出地址、请求长度 |
| 删除 | 文件或目录句柄 |
| 信息 | 句柄、字段号；零种类、一内容长度、二父句柄、三名称字节数 |
| 枚举 | 父目录句柄、起始槽号、48 字节名称输出缓冲 |

枚举从指定槽号开始，返回一个完整句柄并复制名称。下一槽号为返回句柄的低六位加一，名称有效长度通过信息接口取得。空名称、超过 48 字节、包含零字节或斜线、单独的点和双点都被拒绝。名称按字节比较，支持 UTF-8 中文名称，但不实施 Unicode 归一化。

错误码：负一表示未挂载或句柄无效；负二表示对象种类或操作错误；负三表示名称、缓冲或字段参数不合法；负四表示同名对象已存在；负五表示槽或日志空间不足；负六表示块 I/O 错误；负七表示目录非空；负八表示格式或目录记录无效。

## 目录与句柄

索引共有 64 槽，其中一槽用于根目录。句柄包含槽号与代际。删除后释放槽并推进代际，旧句柄不会指向后来创建的对象；代际无法继续增长时永久退休该槽。该状态从日志重放恢复，跨重启保持一致。

父对象必须是有效目录，名称在同一父目录内唯一。父关系在建立时确定，目前没有重命名或移动接口。删除根目录被拒绝；非空目录必须先删除子对象。内容替换只接受文件，不接受目录。

删除回收目录槽和逻辑名称，尚未回收追加日志占用的磁盘空间；日志压缩与磁盘空间复用仍待实现。

## 持久化与重放

每次变更的日志载荷包含 128 字节元数据，以及内容替换时的文件字节。元数据记录标识、版本、操作、句柄、父句柄、名称长度、内容长度和名称。操作分为建立文件、建立目录、替换文件和删除对象。

挂载先清空目录索引，再由提交日志校验并重放记录。除底层校验外，目录层还检查父目录存在、句柄代际、名称唯一、对象类型及删除时无子项。即使日志校验正确，语义无效的目录记录也会使文件系统挂载失败。只有整个挂载成功后才开放文件接口。

块 I/O 错误导致底层日志失效时，文件接口同时失效；空间不足而没有写入时，现有索引保留。格式化必须显式调用，不对未知磁盘自动格式化。

## 当前内存约束

组件要求固定八页 Wasm 线性内存。目录索引位于偏移 16384 起，外部名称和数据缓冲限定在 `[32768, 262144)`，记录暂存使用上半部内存。内容替换需要连续缓冲，因此当前单文件写入上限为 229376 字节；读取支持片段，不要求一次读取整个文件。

组件目前运行在持有设备的用户任务内。默认 Shell 已接入路径解析和文件命令，详[命令壳文件操作](命令壳文件操作.汉语.md)。独立文件服务进程、多用户文件权限、动态程序加载和 WasmGC 尚未实现。

## 验收范围

- 中文文件名、嵌套目录、空文件、4097 字节内容及跨扇区片段读取。
- 独立 QEMU 启动之间恢复原目录，以及恢复内容替换、删除和新句柄。
- 同名创建拒绝，非空目录与根目录拒删，文件与目录类型检查。
- 删除句柄二后槽复用为句柄六十六，旧句柄持续无效。
- 填满 63 个可用槽，拒绝额外创建；删除后复用并重新挂载。
- 名称和缓冲边界检查。
- 直接提交校验正确但父目录不存在的记录，挂载必须失败，后续信息查询不可用。

构建与完整验收沿用裸机验证器，实际结果见验证记录。

## 函数组装约定

`文件目录函数组` 接受块传输、日志格式化、日志挂载、日志追加、日志读取的函数编号，以及函数组起始编号和类型起始编号。类型依次为：零参一结果、单参一结果、双参一结果、三参一结果、三参无结果、四参一结果。

组内相对编号依次为：零重置索引、一解析句柄、二检查缓冲、三检查名称、四内部查找、五日志重放、六挂载、七提交暂存记录、八公开查找、九创建、十替换内容、十一删除、十二分段读取、十三信息、十四枚举、十五格式化。日志挂载的重放回调须绑定组内编号五。内部辅助函数不应作为客户端文件接口开放。
