# 客体数组长度指令

用户态执行器现在解码并执行标准 WasmGC `array.len`（`0xfb 0x0f`），该指令没有类型号立即数。静态验证读取操作数栈顶的精确引用类型，确认它指向数组类型；不可达控制流沿用栈多态规则。运行时核验活句柄与数组类型，再从对象头读取元素数量并压入 `i32` 结果。结构体引用和整数都不能冒充数组。

标准有效的独立模块创建三个元素的数组，`array.len` 返回 3；以结构体引用调用 `array.len` 的独立模块在标准引擎中无效，也在豫言静态验证阶段被拒绝。数组长度仍受现有每对象最多 32 个槽位的限制。ARM64、AMD64 QEMU 连同既有场景共 368 项全过，产物与日志在 `/tmp/yy裸机验证.BbCKYn`；三级自举产物一致，编译器入口类型检查通过。

宿主构建提示：当前原生代码生成器对大型生产 Shell 工具会构造约 174 MiB 的单个临时字符串，默认 256 MiB 宿主 GC 堆不足。使用 `YY_GC_INITIAL_HEAP_SIZE_MB=1024` 编译该工具与裸机验证程序；此配置只影响构建宿主，不改变裸机客体堆。降低宿主代码生成峰值内存仍是后续工作。
