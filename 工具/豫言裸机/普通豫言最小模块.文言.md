# 普通豫言小模块接入之实测

二〇二六年九月二十三日，用当下编译器之 `--target=wasmgc`，自包内常语生二模块：一唯言「一」，一召标准库打印中文。非手书网页汇编，亦未改所得模块。

整数模块三千一百八十六字节，三十三型、一导入、二十八定义函数、七全局及一标签；打印模块三十三万四千零八十四字节，三十八型、一导入、八百定义函数、一千三百五十七全局及一标签，兼有数据计数五百二十二。二者皆为标准引擎所许，亦过今静态指令之检。宿主整数执行器装载时皆报段未支持；此报非 QEMU 客体所出，不得移称其故障。后将小模块经 QEMU 命令壳文件途径装入，客体以负二拒之；初裁类型段，知旧法不通 `eqref`、`struct`。今客体已于 QEMU 读尽其二百九十七字、三十三型之类型段，且可行纯 `i32` 字段结构与 `i31` 一隅；然真模块尚有 `i64`、数组与引用签名，故其体仍不行。详《程序镜像主动数据》《客体复合类型索引》及《客体结构执行》。

无打印之小模块，亦具 GC 型、函数表、引用全局、元素与标签；徒添 i31 一令不足行常语。打印模块八百定义函数，已逾现客体一百二十八函数之限。验收须兼试小模块与标准库模块，勿以其一冒全部。

今客体值槽、调用帧局部槽各四字节，函数引用以负一为空。i31 全域与函数引用、空值若同藏无标四字，必有相撞。低位有记之 i31 内码今已接客体令、验型和值栈，两架构 QEMU 亦验之；然此仅无堆对象之小整一隅。次当全验类型，备宽值与独立引用标记，重算帧、栈、全局、表及宿主暂存诸根；整数不得伪成引用。其后纳标签与引用段、结构数组对象及真回收。

二〇二六年九月二十四日复试：等引函数之署既经双架构验行，小模块循命令壳装入犹报负二。审其原字型段，零至十六型皆为等引参果函数；**第十七型乃含六十四位整数字段之结构**，今索引以四字节字段为限，首拒在此。其后尚有六十四位浮点结构、等引数组、八位及六十四位整数数组、具体引字段与宽值函数。故须先建有型宽值之槽与对象布局，重核诸根，再按宽行读写调用；不可徒去拒绝而误许未实现之体。直生运行时所用数组复制，今已行同型可变八位与整数组，并经双架构重叠复制之验；余元素型犹待续治。

二模块及编译、静态检查记录存 `/tmp/yy普通整数探针.wasm`、`/tmp/yy普通客体探针.wasm` 等；临时源已移除。新镜像构造经两架构三百六十八场景之验，产物在 `/tmp/yy裸机验证.Jr5w13`；常语探针串口记录在 `/tmp/yy裸机验证.zRvscx`。

二〇二六年九月二十四日续：客体索引已记结构宽字段位图；常语最小模块第十七型有一 `i64` 字段，其图当为一。独立混合字段与旧单宽字段模块，于双架构裸机三百六十八试核其录。对象槽、造物及取宽字段未通，原常语模块犹不可行。详见[客体复合类型索引](客体复合类型索引.文言.md)。

又察独立规范模块，其局部值型 `(ref null 0)` 为 Node 所许，而客体函数索引以负二拒之，未及回收。`i64.eq` 亦未入客体指令。二缺非仅改结构载荷可解。现有 `--客体模块` 路循外部 C 例，求其导出并核其果；常语任意模块在此非零退出，不足以断其确切败处，宜另设通用逐阶段诊断。

宽结构行后续：第十七型之单 `i64` 字段及混合 `i32/i64` 结构，今可造而取，独立规范模块于双架构已验。此补原模块首个结构执行之缺；真实三千一百八十六字节常语模块仍含 `f64`、引用字段、数组及余令，未全体于客体行之，须续逐型验。

今已通 `(ref null 结构类型号)` 增局部：独立模块于双架构裸机存宽字段物之引于局部，经回收而复取四十二；错型写入及越界型号亦各依阶段拒，详[客体引用传递](客体引用传递.文言.md)。前述“犹拒”乃未通时之诊断。常语全模块尚含余未受类型与指令，未曾整体行之；`i64.eq`、引用字段、数组、`f64` 尚须续核。

`i64.eq` 及余九规范宽整数比较令，今经独立模块于双架构验，详[客体宽值执行](客体宽值执行.文言.md)。前述 `i64.eq` 之缺已补；三千一百八十六字节常语原模块犹未全行，引用字段、数组、`f64` 及余型令待究。

再以原字模块试所生客体执行器：第十九型 `struct(f64)` 今可索，其宽位、小数位皆一；然全模块索引仍返负二，不支持记为一。循次裁原模块类型段为规范前缀模块，前十八型可索；加**第十八型等引数组**，始置不支持记。其后第二十一型又具 `i32` 与指向第十八型之具体引字段，亦待治。不可因 `f64` 型已扫，便谓全模块可行。双架构三百六十八试皆过，产物在 `/tmp/yy裸机验证.fTx2Uq`；原模块 QEMU 装载犹报根任务非零退出，日志在 `/tmp/yy裸机验证.21dYJZ`。

后通引字段之**声明扫描**，复循型裁原段而试：零至二十八型之各前缀，皆无不支持记；添第二十九型，始返负二。其型乃受指向第二十型之具号引及二 `i32`，而还同型具号引之函数署。全模块犹未行；引字段之行、具号引函数署与调用，待次第治之。新增声明之双架构三百六十八试产物在 `/tmp/yy裸机验证.YPhS5R`，原模块复试串口日志在 `/tmp/yy裸机验证.8PR1rd`。

具号引函数署之声明有界扫描既成，原三千一百八十六字模块三十三型皆录，不支持记为零。客体乃入代码段，于第七个定义函数之局部声明返负二：其局部组为二 `i64`、三 `i32`、一 `(ref 20)`；读堆号二十而止，游标在原模块偏移六百六十四。今仅通可空之具体结构引局部；非空具体引局部及确定赋值、数组引局部犹待治。标准 Node 许原模块，不可谓其字坏。函数署声明模块之双架构三百六十八试皆过，产物在 `/tmp/yy裸机验证.dm74fc`；原模块复试在 `/tmp/yy裸机验证.A0oBA6`。

函数索引今能循界读原模块之非空具号数组引与 `eqref` 局部声明；双架构三百六十八试皆过，产物在 `/tmp/yy裸机验证.SXfU9k`。复试原模块，首拒已非代码段，而在全局段首个 `eqref` 全局型字之后（原模块偏移三百七十五）；客体索引返负二，不支持记仍零，日志在 `/tmp/yy裸机验证.oPRTaP`。此唯局部**索引**之缺已补；非空局部确定赋值验型、数组引确型与 GC 根、`eqref` 全局初值及全模块行，皆未备。

客体今可录、初置而行可变 `eqref` 全局之 `ref.null eq` 初值及 `i31` 读写；独立正反模块于双架构三百六十八试皆过，产物在 `/tmp/yy裸机验证.kxIjEs`。真三千一百八十六字常语模块，已越首个等引全局；次负二在第二全局之非空具号数组引型字之后（原模块偏移三百八十），日志在 `/tmp/yy裸机验证.Znq0MA`。其型兼有 `array.new_default` 初值；不可徒许型字，而略造物、GC 根及静态验型。
