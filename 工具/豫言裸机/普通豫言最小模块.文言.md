# 普通豫言小模块接入之实测

二〇二六年九月二十三日，用当下编译器之 `--target=wasmgc`，自包内常语生二模块：一唯言「一」，一召标准库打印中文。非手书网页汇编，亦未改所得模块。

整数模块三千一百八十六字节，三十三型、一导入、二十八定义函数、七全局及一标签；打印模块三十三万四千零八十四字节，三十八型、一导入、八百定义函数、一千三百五十七全局及一标签，兼有数据计数五百二十二。二者皆为标准引擎所许，亦过今静态指令之检。宿主整数执行器装载时皆报段未支持；此报非 QEMU 客体所出，不得移称其故障。后将小模块经 QEMU 命令壳文件途径装入，客体以负二拒之；初裁类型段，知旧法不通 `eqref`、`struct`。今客体已于 QEMU 读尽其二百九十七字、三十三型之类型段，且可行纯 `i32` 字段结构与 `i31` 一隅；然真模块尚有 `i64`、数组与引用签名，故其体仍不行。详《程序镜像主动数据》《客体复合类型索引》及《客体结构执行》。

无打印之小模块，亦具 GC 型、函数表、引用全局、元素与标签；徒添 i31 一令不足行常语。打印模块八百定义函数，已逾现客体一百二十八函数之限。验收须兼试小模块与标准库模块，勿以其一冒全部。

今客体值槽、调用帧局部槽各四字节，函数引用以负一为空。i31 全域与函数引用、空值若同藏无标四字，必有相撞。低位有记之 i31 内码今已接客体令、验型和值栈，两架构 QEMU 亦验之；然此仅无堆对象之小整一隅。次当全验类型，备宽值与独立引用标记，重算帧、栈、全局、表及宿主暂存诸根；整数不得伪成引用。其后纳标签与引用段、结构数组对象及真回收。

二〇二六年九月二十四日复试：等引函数之署既经双架构验行，小模块循命令壳装入犹报负二。审其原字型段，零至十六型皆为等引参果函数；**第十七型乃含六十四位整数字段之结构**，今索引以四字节字段为限，首拒在此。其后尚有六十四位浮点结构、等引数组、八位及六十四位整数数组、具体引字段与宽值函数。故须先建有型宽值之槽与对象布局，重核诸根，再按宽行读写调用；不可徒去拒绝而误许未实现之体。直生运行时所用数组复制，今已行同型可变八位与整数组，并经双架构重叠复制之验；余元素型犹待续治。

二模块及编译、静态检查记录存 `/tmp/yy普通整数探针.wasm`、`/tmp/yy普通客体探针.wasm` 等；临时源已移除。新镜像构造经两架构三百六十八场景之验，产物在 `/tmp/yy裸机验证.Jr5w13`；常语探针串口记录在 `/tmp/yy裸机验证.zRvscx`。

二〇二六年九月二十四日续：客体索引已记结构宽字段位图；常语最小模块第十七型有一 `i64` 字段，其图当为一。独立混合字段与旧单宽字段模块，于双架构裸机三百六十八试核其录。对象槽、造物及取宽字段未通，原常语模块犹不可行。详见[客体复合类型索引](客体复合类型索引.文言.md)。

宽结构行后续：第十七型之单 `i64` 字段及混合 `i32/i64` 结构，今可造而取，独立规范模块于双架构已验。此补原模块首个结构执行之缺；真实三千一百八十六字节常语模块仍含 `f64`、引用字段、数组及余令，未全体于客体行之，须续逐型验。
