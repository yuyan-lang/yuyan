# 客体函数引用全局

定义全局今可用默认函数引用，与整数共存。初值可为空或函数引用；函数号须有，且入模块已声明引用之集。

型与可变性各记。型标签在 `[29504,29632)`，一全局一字节；旧记录仍记可变标志及初值，运行值仍始四五零五六。不以引用型之非零误授写权。

取全局则按声明添型，赋全局则验栈顶相合；不可变仍于解码时验。整数与引用不得相冒。实例化复制已验初值，复实例化还其原值。

今受整数常量、函数引用及默认空函数引用初值，亦受合法非最短空型编码。已知型不合、可变标志非法及函数号越界皆拒。导入全局、取全局初值、通用堆型及扩展常式尚待续。

新增二十试，十九静态判定同标准引擎，九试执行及全局值亦同。含不可变、赋值、清空、混合型、仅以全局初值声明函数、异型、复初置及取全局置表而间接调用。另以合法外部引用型验未支持之拒绝。

此为后续辨全局引用留型，尚未成堆对象与垃圾收集。

所据：[官方全局测试](https://github.com/WebAssembly/spec/blob/main/test/core/global.wast)。

二零二六年九月二十三日，两架构三百六十六项裸机回归皆过。产物在 `/tmp/yy裸机验证.yXM6uc`，日志在 `/tmp/yy引用全局验证日志`。二十份相关模块经标准验证，四份默认命令壳镜像已更新，与实测逐字节同。元数据布局及独立读盘复核亦过。详见[验证记录](验证记录.json)之“客体引用全局扩展验证”。

## `eqref` 全局及空引初值

定义之可变 `eqref` 全局，今许相符之 `ref.null eq` 初值，实例化存客体空引值零；静态验型循等引标签核 `global.get/set`，运行仍用独立全局槽。五十三字规范 WasmGC 模块，以 `i31` 入全局，复取而与同值新造 `i31` 比，Node 与臂六十四、兼容六十四 QEMU 皆得一。若唯改初值为 `ref.null func`，五十三字模块为 Node 所拒，客体资源索引返负二。并旧试三百六十八项皆过，产物在 `/tmp/yy裸机验证.kxIjEs`。全局值已入从宽 GC 寻根，详[客体自动根回收](客体自动根回收.文言.md)；非空具号引全局、造物常式、堆确型及完整常语模块犹未备。

## 复合引全局有界索引

非空具号结构、数组引之全局，今录堆型号与常式始址。有界读 `array.new_default`、零元 `array.new_fixed`，及携一数值域之 `struct.new`；型、参不符或越界，则报误。五十一字默认数组、五十字定长零元数组规范模块，Node 均许之；两架构三百六十八试皆过，产物在 `/tmp/yy裸机验证.QeeB0b`。此唯声明、常式之索引；客体实例化犹拒复合引全局，未分配对象，常语模块犹未能行。
