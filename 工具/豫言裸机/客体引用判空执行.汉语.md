# 客体引用判空

用户态 Wasm 执行器把 `ref.is_null` 扩展到已支持的 GC 引用和函数引用。静态验型读取操作数的精确引用标签，拒绝普通 `i32`；对具体引用再核对类型表，区分函数、结构和数组。验证器把函数域或 GC 域写进该指令的私有记录，运行时据此选择空值编码，不需要猜测四字节运行值的类型。

这一域标记是必要的：函数空引用当前编码为 `-1`，GC 空引用为 `0`，但 `i31.new(-1)` 也会得到位形 `-1`，它不是空引用。运行时按指令记录选择比较对象，因此不会把这个非空小整数误判为空。具体数组空引用、新分配数组、通用 `eqref` 空引用和函数空引用均按各自域处理。

六个独立标准模块覆盖上述边界及整数误用反例，并与标准 WebAssembly 引擎核对。未支持的引用类型和普通豫言完整模块仍待接入。

ARM64、AMD64 的完整 QEMU 回归共 368 项全部通过，产物和串口日志在 `/tmp/yy裸机验证.SnfC5E`；旧具体函数引用用例亦在两架构通过。编译器入口类型检查通过。静态验证对错误操作数继续返回类型错误码 `-1`，不把标准无效模块误报为“未支持”。
