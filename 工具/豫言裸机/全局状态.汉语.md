# 裸机用户态全局变量

布局更新：固定半兆分割及固定全局基址已取消；当前按元数据实际长度布局，见[元数据布局](元数据布局.汉语.md)。下文涉及旧固定地址和容量的段落仅记录早期实现，当前以新布局为准。

镜像生成入口现读取完整状态模块，并在验证索引、类型和可变性后，为自有三十二位全局变量生成用户态读写指令。普通执行不经过系统调用。只读声明的写入在生成机器码前拒绝。

全局值按四字节连续放在模块元数据区起始处，随后是数据段描述符及载荷。ARM64 基址为 `0x40280000`，AMD64 为 `0x280000`。数据段地址整体后移全局区长度；合计仍受 524284 字节限制，不能侵入页数描述符。存在全局或数据段时，代码上限为 512 KiB。全局值不属于 Wasm 线性地址空间，普通客体访存指令不能以线性地址读取该区。

无内存模块也可持有全局变量；有内存时，全局、主动数据初置、被动数据运行时初始化共用状态镜像生成链。旧存储镜像接口保留，并继续拒绝缺少全局声明上下文的指令。

2026-09-22，ARM64 与 AMD64 合计 106 项 QEMU 验证全部通过。新增两类正常模块及各自错误期望值负对照：仅有全局的模块、全局与内存及数据共存的模块。客体核对初值、跨函数连续更新、只读负数初值、写入负一后递增回零，以及用全局值作为地址执行数据初始化。共存用例同时核对主动段和被动段，防止元数据布局变化破坏数据地址。

相同标准模块在 V8 中通过四次正常核验，两个错误期望值模块均在最后一次核验失败。状态镜像入口与验证入口类型检查通过，关键读写机器指令经反汇编核对。

```sh
./yy3_bs 工具/豫言裸机/验证。豫 -o yy裸机验证 -j 1
./yy裸机验证
./yy3_bs 工具/豫言裸机/入口。豫 -o yy豫言裸机 -j 1
./yy豫言裸机 臂六十四 输入.wasm yy全局.elf 正常
```

产物目录 `/tmp/yy裸机验证.s0xi5i`，完整散列、退出码和串口日志见 `验证记录.json` 的“裸机全局扩展验证”。本轮仍是单模块静态镜像；全局导入导出、动态装载、多进程地址域、调度、文件系统、默认用户态 Shell 和完整 WasmGC 尚未完成。只读约束在 Wasm 验证层实施，不是单独的硬件只读页。

原生生成器与同源码的 WasmGC 生成器产出逐字节相同的双架构共存镜像，且与 QEMU 受测镜像一致。网页生成仍使用现有宿主，不代表客体已有 WasmGC 执行器。
