# 客体结构体指令执行

今客体执行器读纯 `i32` 字段、至多三十二字段之结构型，识标准 WasmGC `struct.new`（`0xfb 0x00`）及 `struct.get`（`0xfb 0x02`）。解码记型号与字段号；静态验栈以型号别结构引用，造物逐取所宣字段，取字段则拒整数伪引、异型与越界。运行时由受检对象堆造物、存字段；读取先核柄确指活物且型号相符。

首结构令依模块生期初置对象堆；重载模块则清初置记，同模后召不妄重置。今堆用客体线性内存原预留之 `[393216,524288)`；客体若自宣内存，则运行前遍扫指令记录，拒其中结构令，以免域相侵，亦免有副效而后知限。容不足则辨活动值栈与局部帧之活柄，标扫复试；异型字段与递归型组仍未成。纯 `i32` 数组之初成子集别见《客体数组执行》，回收界限见《客体自动根回收》。

标准有效之独立 WasmGC 验具含一字段结构，实行 `i32.const 42 → struct.new 0 → struct.get 0 0`，所得四十二。又以整数径作 `struct.get` 之无效具，客体静态验栈已拒；自带内存之标准有效结构模块，客体运行前返不支持。诸字码皆与独立标准引擎对勘。另以双 `i32` 字段之模块验造物逆取栈值、取第二字段，标准引擎所得亦四十二。臂六十四、兼容六十四 QEMU 并旧试共三百六十八项皆过，产物在 `/tmp/yy裸机验证.oD3tvN`；壳程序运行与重启亦过。

## 宽整结构字段

`struct.new` 与 `struct.get` 今可行已录之 `i64` 字段，亦可杂 `i32`。对象仍以四字节为实体槽：第 `i` 字段首槽，为 `i` 加其前宽位之数；宽整占邻二槽，分配先核总槽不逾三十二。造物逆取字段，宽值先高后下；取字段以下、高次第还值栈，且记高字非 GC 引根。字段号仍按逻辑数核界，物头记实体槽数。

独立规范模块六十字节者有单宽字段，六十八字节者有 `(i32,i64,i32)` 混合字段；Node 及双架构 QEMU 皆得四十二。又有四十九字节错型模块，以 `i32` 充 `i64` 字段；Node 判其非法，客体验栈亦拒之。三模块原字于两客体执行镜像各现一次，裸机三百六十八试皆过，产物存 `/tmp/yy裸机验证.Z50aSm`。前次 AMD64 壳串口偶失一 UTF‑8 字，程序及后续任务仍成；同产物再行全试皆过，今次新产物首行全过。

引用字段、`f64` 字段、`struct.set` 及宽字段对象受 GC 压力之专验犹未备；常语最小模块亦含余未受类型与指令，不可谓全体已行。
