# 客体整数之行

资源已录，指令已解，栈已验，乃于用户态解释标准模块整数函数。入口今按函数号行无参函数，返零或一整数；内调用可有整数参数与返回。默认命令壳尚未接之。

今可行常量、比较、算术、除余、位运算、移位、旋转、计数、符号扩展，局部与全局读写，选择、块、循环、条件、诸分支、返回与直接调用。求和与递归阶乘皆实算，期望数仅为验据。

内存令已续成，详[客体内存令](客体内存执行.文言.md)；定平台导入、启动与默认空表已续成，详[客体导入与启动](客体导入与启动.文言.md)；元素、标签与间接调用待续。行前遍察指令，未受者先拒，毋行至半途乃知不能。故意带未连导入而函数欲改全局之例，须在写前拒之。未调用之函数有未受令，今亦拒其模块。

资源先初置，访存仍必验独立之界。先尽连定平台导入，初次调用前行启动；未知或错型则拒，不以空函数充之。

值栈始二六二一四四，终于三二七六八零，至多一万六千三百八十四值。调用帧始三二七六八零，终于三九三二一六，至多十六，各四千零九十六字节。前一千零二十四存参数与局部，后置至多一百二十八控制帧，各十六字节，存种类、入栈高、目标与返回数。

入函数，参数自值栈移入新局部，余局部清零；保留调用者之前缀，归时交还结果。解释函数递归以行调用，先验十六帧之界。

分支存所需结果，截余值与内层控制帧，乃往其处；循环留其帧而返体首。未选之条件路不行。否则与结束依块返数收帧。分支表以无符号下标择路，过其目标数则择默认。

步数由调用者给，一至一百万，每令扣一，循环递归共用。计数运算内迭至多三十二；参数复制与帧清零亦有界。值栈与调用帧各验容量。

不可达、除零、最小有符号整数除负一，皆返陷阱状态，不使原生异常坠执行器；最小整数余负一则零。

零为成，负一为入口或准备错，负二为未受形式，负四为陷阱，负五为步数尽，负六为栈限或重入。零步返负五，过百万返负一。

成败皆清值栈高、调用深度、运行记与本次许可，败后可复行。陷阱前全局之改不自动复原；重载与资源初置另行。此同普通网页汇编陷阱之状态义。

须备外层八页且资源初置、栈验皆成。二九一四零记值栈高，二九一四四记调用深，二九一四八记余步，二九一五二记过，二九一五六记运行中，二九一六零存结果，二九一六四记有无结果。败不发布结果，合法零与负一须以状态辨之。

二八七零四仅在本次受限检查成而行时置一，归则清；非完整标准支持之诺。重入拒而不毁外调用。定域今仅一实例，无链接与并发实例分配。

三十一原模块于客体读、解、验、初置而行，验算术、条件、变量、分支表、求和、阶乘、陷阱、限额、无返、先拒与恢复，复核结果及清理。诸模块皆经独立标准验证，其中二十八实跑以比返回或陷阱；仅增测试导出，不改函数体。限额及未受形式依本器之策别验。

通用导入、命令壳载行、跨模块互调、通用实例与完整垃圾收集，皆当续成。今为可行之受限整数解释器，未谓目标操作系统执行环境已全。
