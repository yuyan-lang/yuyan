# 客体数组指令执行

今用户态客体执行器识标准 WasmGC 纯 `i32` 元素数组之 `array.new`、`array.get`、`array.set`，长至多三十二。类型索引记元素可变否；静态验栈须精确数组型引用，`array.set` 又须元素可变。运行时以受检对象堆造数组，读写皆核活柄、型号及下标界。

数组堆仍据 `[393216,524288)`；客体若自宣线性内存而含此诸数组令，则入口未有副效先拒之。重载模块则清堆初置记。分配不成，则辨活动值栈与局部帧之活柄，标扫而复试；界限别见《客体自动根回收》。`array.len` 后续成事见《客体数组长度执行》；异型元素、局部变量中具体引用，今仍未成。

标准有效之独立 WasmGC 模块行 `array.new → array.get`，所得四十二；别模块行 `array.new → array.set`，于客体堆留值四十二。越界 `array.get` 之标准有效模块返受控陷阱；以整数伪数组引用之标准无效模块，为客体静态验栈所拒。诸模块各与标准引擎之验或运行结果对勘。臂六十四、兼容六十四 QEMU 并旧试共三百六十八项皆过，产物与日志在 `/tmp/yy裸机验证.2uJxYR`；三级自举产物同，编译器入口验型亦过。
