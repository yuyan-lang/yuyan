# 客体元素段与函数指针

后续：以段置表、弃段、复制表已接，见[客体表批量](客体表批量.文言.md)。下存元素段初验之范围。

资源层读标准元素段，运行时以主动段初置函数表。间接调用守已验之型，字节格式与公用接口不改。此途行于用户态，非宿主先算其果。

今受零至七八种编码，含主动、被动、声明式及编号列、引用表达式列。型限默认函数引用；式限函数引用与以单字节内置堆类型所记之空函数引用，偏移限既有整数常式。主动段验表号，诸函数引用验函数号；被动与声明式虽无表亦可存。

初置先尽验主动数据段与元素段。空段之偏移亦不得逾表界。任一越界，返负三，内存、全局、函数表旧值皆不动，实例就绪仍零。诸验皆过，乃清表而依次复制，后段覆前段。主动及声明式标为已弃，被动留存；复初置可还原其表。

二九二零八记段数，二九二一二记引用数。`[46080,47104)` 容六十四段，每段十六字节，依次记模式、偏移、引用起点与数量；`[47104,49152)` 容五百一十二引用，负一为空；`[51256,51512)` 记丢弃标志。表仍限一千零二十四项。逾容量返负二，乃实现之限，非断模块违规范。

改表、长表、多表、导入表、通用引用、扩展常式及完整垃圾收集尚未成。被动元素虽存，其后续初始化表令待续。

[函数指针夹具.c](函数指针夹具.c) 为独立 C 输入，以易变函数指针数组保间接调用。启动验两目标及改指针，“指针验收”导出以两次间接调用得八十四。此乃兼容性夹具，非内核或执行器改用 C；客体不连 C 运行库。重建命令见[汉语说明](客体元素段.汉语.md)。

标准引擎对照二十五模块之有效性、十五次执行之果；另二试验未受引用型或表达式之拒绝。裸机新场景含二十七试。命令壳试盘存同一 C 模块于“指针.wasm”，初启及复启皆须从盘载行“指针验收”，得八十四。

所据：[WebAssembly 元素段编码](https://webassembly.github.io/spec/core/binary/modules.html#element-section)。
