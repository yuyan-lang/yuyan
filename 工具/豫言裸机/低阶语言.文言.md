# 低阶语言

## 何以有此

裸机客体执行器所欲行者，乃普通豫言所编之 WasmGC 模块（八百函数、近五万条指令）；执行器自身惟整数 Wasm 函数，由寄存器降级化为两机之机器码。昔者执行器以豫言逐条拼「网页指令」之扁平列，约七百二十七千字节之源，每增一操作码，必手算标签之深、栈之形，其大则不可维。低阶语言者，刻意至小之括号语：惟一类（三十二位整数），显式读写内存，控制成结构；一遍分词、一遍成树、一遍成码，径出与手写列等价之「网页状态模块」，复经既有之验证、二进制生成与降级而入 ARM64、AMD64 之镜像，亦可出标准 `.wasm` 付 Node 诸宿主调试之。

## 文法

源为 S 表达式；分号起行注；字符串字面量以双引号括之（不含引号，惟用于数据段）。

顶层：

|式|义|
|---|---|
|`(常量 名 表达式)`|编译期整数常量；表达式惟含数、已定之常量及 `+ - * / & \| ^ << >> >>u ~ !`|
|`(宏 名 (参…) 模板)`|文本宏；用处 `(名 实参…)` 展为模板（参数原样代入，可嵌套，展开至深六十四）；实参于模板中出现几次则求值几次|
|`(导入 名 "模块" "字段" 参数数 结果数)`|导入函数（编号先于定义者）|
|`(函数 名 (参…) 语句…)`|函数；含 `(返回 表达式)` 者有一结果，否则无；有结果者末尾自补 `unreachable`|
|`(导出 "外名" 函数名)`|导出|
|`(内存 初始页 最大页)`|线性内存声明（至多一）|
|`(数据 偏移 项…)`|主动数据段；项为字符串（UTF-8）、数（一字节）、`(字 值…)`（小端四字节）、`(半 值…)`（小端二字节）、`(零 长度)`|

表达式：数（十进制、`0x` 十六进制、可带负号，模二之三十二次）、局部名、常量名、`(op a b)`（`+ - * / /u % %u & \| ^ << >> >>u rotl rotr == != < > <= >= <u >u <=u >=u`，其中 `+ - * & \| ^` 可多参，`-` 单参为取负）、`(! a)`、`(~ a)`、`(&& a b…)`、`(\|\| a b…)`（短路，得零或一）、`(读4 址 [偏移])`、`(读2 …)`、`(读2有 …)`、`(读1 …)`、`(读1有 …)`（无符号或有符号扩展；偏移须为常量）、`(选 条件 甲 乙)`（两侧皆求值）、`(内存页数)`、`(内存增长 页数)`、`(函数名 实参…)`。凡编译期可算者皆折为常量。

语句：`(局 名…)` 声明局部（通函数有效，初为零）、`(令 名 表达式)` 声明兼赋值、`(置 名 表达式)`、`(存4 址 值 [偏移])`、`(存2 …)`、`(存1 …)`、`(若 条件 语句…)`、`(若否 条件 (语句…) (语句…))`、`(当 条件 语句…)`、`(中断 [层数])`、`(继续 [层数])`、`(返回 [表达式])`、`(陷阱)`、`(弃 表达式)`、`(内存复制 目的 来源 长度)`、`(内存填充 目的 字节 长度)`、`(块 语句…)`、调用语句（有结果者自弃其结果）、分派：

```
(分派 表达式
  (情形 (值 值…) 语句…)
  (情形 (值) 语句…)
  (否则 语句…))
```

分派者，排诸情形之值而成二分决策树，每情形体唯一份，以嵌套 `block` 与 `br` 达之，无贯穿；值重则编译时拒之。

## 出与约

- 每值皆 `i32`，函数至多一结果；宽整数（`i64`）由用者按高低字自拼。
- 局部按参数、`局`／`令` 先后编号；局部不得与常量同名；参数不得重名。
- 出为「网页状态模块」（无全局），可经「生成状态二进制」书为标准二进制。
- 编译之误为异常，其文含出错之表达式。

## 具与验

`工具/豫言裸机/低阶编译。豫`：`yy低阶编译 输入源 输出模块`，读一低阶源，写标准 Wasm 二进制。以 Node 之 `WebAssembly` 运同一模块（供平台导入）可于宿主调试；`库/编译器核心/裸机后端/低阶语言。测试。豫` 编一份遍涉诸式之源，先过标准验证，复以整数执行器行二十例核其果，验带内存与数据段之模块经二进制往返仍通过，并使十一恶例（未定之名、参数个数不符、分派值重、赋值于未声明之变量、参数重名、常量引用未定之名、循环外中断、单参数加法、非常量偏移、括号未闭、仅函数名之调用）皆于编译时被拒。
