# 标量数值指令验证

顺序指令验证器现接入 128 个标准标量数值操作码（0x45–0xc4）及 8 个饱和截断转换（0xfc 的 0–7）。覆盖整数和浮点比较、算术、整数位操作、浮点单目运算、数值转换、重解释和符号扩展。类型规则区分 i32、i64、f32、f64；比较结果为 i32，转换的输入和结果类型分别检查。

每个操作码有三个完整二进制模块：类型正确、输入类型错误、结果类型错误，共 408 个。所有模块已用 Node 标准引擎独立核对分类。测试不执行算术，因此不能用这些结果证明除零陷阱、数值精度或浮点运行语义正确。

本次仍属指令类型验证，不是裸机执行器的算术支持扩展。结构控制和 GC 对象指令尚待；0xfc 其他子操作码仍明确拒绝。默认镜像不变。

豫言验证器的 408 个模块测试、原有 18 个顺序指令回归均已通过，类型检查和构建成功。日志为 `/tmp/yy标量指令检查日志`、`/tmp/yy标量指令构建日志`、`/tmp/yy标量指令运行日志`、`/tmp/yy标量回归运行日志`。
