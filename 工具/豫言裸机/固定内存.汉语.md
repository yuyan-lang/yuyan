# 裸机固定线性内存

后续已支持预留容量内的增长，现行布局和限制见[内存增长](内存增长.汉语.md)。以下保留该阶段实现与验证记录。

标准 Wasm 的单个自有内存现可直接降级到 ARM64 与 AMD64 用户态镜像。当前要求声明的初始页数与最大页数相等，最多八页，每页 65536 字节。未给最大值或允许增长的声明会明确拒绝。

用户代码上限一兆字节，随后为独立线性区，再后为操作数栈和调用栈。ARM64 线性区基址为 `0x40300000`，AMD64 为 `0x300000`。这些是客体的直接非 GC 内存；生成器中的参考内存仅用于按顺序应用主动数据段、生成初始镜像字节。

支持三十二位、八位、十六位标量读写和窄值符号扩展，允许非对齐及跨 Wasm 页访问。先以六十四位运算检查地址、静态偏移和完整访问宽度，验证后才访问线性区。`memory.size` 返回固定页数；`memory.grow 0` 返回原页数，其他增长返回负一，符合当前固定声明的语义。后续已接入批量填充，详[批量填充验证](批量填充.汉语.md)；复制亦已接入，详[批量复制验证](批量复制.汉语.md)；运行时初始化与数据丢弃也已接入，详[数据段验证](数据段.汉语.md)。有数据段时的代码上限及布局以该文为准。

2026-09-22，双架构共 32 项 QEMU 验证通过，新增八项：各架构的正常访存、读越界、写越界和地址加偏移回绕。正常项包含主动数据小端读取、跨页四字节读写、有符号及无符号窄读，以及大小和增长返回值。相同标准模块在 V8 中通过四次核验，三类负例在任何核验之前触发陷阱。命令行生成器输出与受测镜像逐字节相同，生成和验证入口类型检查通过。

```sh
./yy3_bs 工具/豫言裸机/验证。豫 -o yy裸机验证 -j 1
./yy裸机验证
./yy3_bs 工具/豫言裸机/入口。豫 -o yy豫言裸机 -j 1
./yy豫言裸机 臂六十四 输入.wasm yy臂内存.elf 正常
./yy豫言裸机 兼容六十四 输入.wasm yy兼容内存.img 正常
```

本次产物目录为 `/tmp/yy裸机验证.JCfQzH`；完整退出码、串口日志及散列记录在 `验证记录.json` 的“固定访存扩展验证”。临时目录可能被清理，可用上述验证器重建。

这一步没有实现动态页分配、多进程地址空间、调度、文件系统、用户态 Shell 或完整 WasmGC。当前非法访问仍终止整个测试客体；故障任务退出而系统继续运行的隔离验收尚待实现。客体及镜像生成过程不调用 LLVM、libc 或外部汇编器；生成器自身仍由现有宿主工具链引导。

同一镜像生成器经 WasmGC 目标编译后，在既有网页宿主中生成双架构固定访存镜像，均与原生生成结果逐字节一致。此项验证生成链一致性，不表示客体已具有 WasmGC 执行器。
