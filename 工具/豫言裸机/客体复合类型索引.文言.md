# 客体复合类型索引

常语最小 Wasm 模块之类型段有三十三型：首十七为 `eqref` 函数签名，其后有结构、数组、`i64`、`f64` 签名及具编号之堆引。旧客体索引遇首结构即返不支持，后型之位无从记。

今用户态索引器循界扫结构、数组字段。原类型表居 `[32768,33792)`，函数表始于 `34816`，中隙 `[33792,34816)` 每型十六字，记其类、原字段或签名始末。宽数及具号引用之续字亦有界读之；原字仍在执行器独见之模块输入区。旧 `i32`、`funcref` 快径与表址不迁。

此初仅有界扫描、留其信息，非完备 WasmGC 验型。结构数组字段之存型字限规范数型、引型、`i8`、`i16`；可变记限零一，截断与非法存型皆报坏。后已许至多三十二纯 `i32` 字段之结构型入受限执行，详《客体结构体指令执行》。今又许闲置 `i64` 结构字段之声明，仍记原字位；若以 `struct.new` 或 `struct.get` 及含非 `i32` 字段之结构，静态验型即返负二。此唯声明之进，非四字值槽及对象布局已容宽数。`f64` 字段、余未行之字段、具体堆号 s33 全域、递归组及子型仍未备。

验具含标准有效之结构数组、具号字段、`i64` 与 `f64` 函数签名，并验坏字段与截断。又取今常语编译器生成物之二百九十七字完整类型段，标准 Wasm 引擎许之；臂六十四、兼容六十四 QEMU 皆实读至段末，计三十三型，核关键表项与末型终游标。后增标准有效 `i8` 结构、`i16` 数组及无效 `0x79` 字段，独立引擎之断同之。今复以十五字独立模块验闲置 `i64` 结构可索；三十三字独立模块于不可达函数置 `struct.new`，标准引擎许其体，客体静态验之返负二。两具原字皆见于所生镜像。两架构三百六十八项 QEMU 回归皆过，今产物在 `/tmp/yy裸机验证.9XbwkH`。常语模块之体尚未行，完备 WasmGC 回收未备。

## 宽字段之记

结构类型索引，今于辅录偏移十二记前三十二字段之 `i64` 位。函数类型同址记宽参；依类型种类辨之，不可混读。单一宽字段之图为一；独立规范三字段 `(i32, i64, i32)` 之图为二。重录先清旧图。Node 验新十九字节模块为合法；ARM64、AMD64 裸机三百六十八试皆过，新原字于两索引镜像各现一次，产物存 `/tmp/yy裸机验证.EKb6Kx`。

后续执行拟以四字节为一实体槽：第 `i` 字段首槽，为 `i` 加其前宽位之数；宽字段占相邻二槽，总槽数为字段数加宽字段数。分配前核不逾堆之三十二槽；下高二字别存，高字不得作 GC 引根。今仅成索引，含宽字段之 `struct.new`、`struct.get` 犹明拒，不可谓常语模块已行。

后续之行：辅录偏移十二之宽位图，今供 `struct.new/get` 验栈与四字节实体槽布局。单宽与混合字段规范模块于双架构 QEMU 皆还四十二；详[客体结构执行](客体结构执行.文言.md)。前文拒宽结构令之说，属昔日录型阶段。
