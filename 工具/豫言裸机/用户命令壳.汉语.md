# 用户态命令壳

现行默认版本已扩展文件与路径命令，参见[命令壳文件操作](命令壳文件操作.汉语.md)。本篇保留基础输入循环和任务交互的说明。

不指定输入模块时，镜像生成器默认装入命令壳：

```sh
./yy命令壳编译器 工具/豫言裸机/入口。豫 -o yy豫言裸机 -j 1
./yy豫言裸机 臂六十四 yy命令壳臂.elf
./yy豫言裸机 兼容六十四 yy命令壳兼容.img
```

在终端交互运行：

```sh
qemu-system-aarch64 -machine virt,gic-version=2,virtualization=off,secure=off -cpu cortex-a53 -accel tcg -m 128M -smp 1 -display none -monitor none -serial stdio -no-reboot -semihosting-config enable=on,target=native -kernel yy命令壳臂.elf
qemu-system-x86_64 -machine pc -accel tcg -m 128M -smp 1 -display none -monitor none -serial stdio -no-reboot -device isa-debug-exit,iobase=0xf4,iosize=0x04 -kernel yy命令壳兼容.img
```

每次运行其中一条命令即可。正常输入退出后，ARM64 的模拟器退出码为 0，AMD64 的调试退出设备返回 33；后者不是命令壳故障。

原有“架构、输入模块、输出镜像”用法继续运行指定模块。命令壳由豫言代码构造中文 Wasm IR，经过同一个标准 Wasm 子集后端生成用户态机器码，运行时不依赖 LLVM 或 libc。它目前使用低层整数、显式线性内存和平台导入，尚未经过普通高层豫言的完整编译链，也不证明客体 WasmGC 或动态执行器已经完成。宿主构建仍使用已有的原生豫言编译器及其宿主依赖。

启动时核对用户态身份，随后轮询串口，回显输入，并实际解析命令。命令与行为如下：

| 命令 | 行为 |
| --- | --- |
| 帮助 | 显示当前支持的命令和限制 |
| 任务 | 查询并显示前台任务编号、已保存的子任务句柄及内核状态值 |
| 启动 | 复制出一个内置短任务，等待三个时钟滴答后以 7 退出 |
| 忙碌 | 复制出一个持续计算的内置任务，供终止和抢占操作使用 |
| 等待 | 等待子任务，打印真实退出码，然后回收任务槽 |
| 终止 | 请求内核终止子任务，之后可用等待取得退出码并回收 |
| 退出 | 终止、等待并回收现有子任务，再结束命令壳 |

当前只保存一个子任务，未回收时拒绝再次启动。任务结束与任务槽回收是不同步骤，已结束的任务仍需等待回收。任务句柄带代际，连续启动会出现 1、3 等句柄。忙碌任务不自行结束，对它执行等待会阻塞命令壳；目前没有前台中断键或取消等待。

输入上限为 255 字节。超长后丢弃整行，直到换行才恢复，绝不执行截断后的命令或后缀。支持换行、回车和回车换行；退格与删除键按 UTF-8 字节边界删除前一字符。终端回显暂按 ASCII 一列、非 ASCII 两列处理，未实现通用 Unicode 显示宽度、历史记录、光标移动或控制序列解析。未知命令会报告错误并继续接受输入。

这是真实交互和任务管理的第一版，启动命令仅运行内置任务，不冒充外部程序加载。文件系统、目录命令、块设备、持久化、管道、重定向、多服务调度、普通豫言运行时及 WasmGC 仍属于未完成的总目标。

验收使用 QEMU 串口管道发送命令，检查任务创建、代际更新、退出码 7 与 143、终止与回收、输入错误恢复，以及有忙碌任务时退出能够结束系统。详细结果载于验证记录。
