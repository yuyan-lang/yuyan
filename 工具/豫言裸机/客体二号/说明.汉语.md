# 客体二号

用户态豫言客体执行器二号，以**底层模式**的普通豫言编写（旧的括号式 `.低阶` 源码由此取代）。它解释执行普通豫言编译得到的 WasmGC 模块：栈机解释器、分配与标记清扫回收、异常、结构与数组、宿主原语（输出、文件、命令行、同步子进程）、持久文件系统与 Virtio 块设备驱动。

## 构建

```sh
./yy豫构 构建 客体二号 --输出 /tmp/yy客体二号.wasm
```

产物是标准 Wasm 模块（导出 `启动`），由验证工具 `工具/豫言裸机/普通豫言验证。豫` 读入后追加客体模块与标志数据段，生成裸机镜像。内存布局常量（`布局`）的地址与验证工具约定一致，不得随意改动。

## 模块

`布局` 内存布局与状态格常量；`基础` 输出、变长整数、内存与宽整数助手；其余模块依依赖顺序排列。语言约定见 `文档/底层模式.汉语.md`。
