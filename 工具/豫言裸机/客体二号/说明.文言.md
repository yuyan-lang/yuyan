# 客体二号

用户态豫言客体执行器二号，以**底层模式**之常豫言书之（旧括号式 `.低阶` 源码由此代之）。其所行者，普通豫言所编之 WasmGC 模块：栈机之解释、分配与标记清扫之回收、异常、结构与数组、宿主之原语（输出、文件、命令行、同步子进程）、持久之文件系统与 Virtio 块设备之驱动。

## 构建

```sh
./yy豫构 构建 客体二号 --输出 /tmp/yy客体二号.wasm
```

所成者标准 Wasm 模块（导出 `启动`），由验证之器 `工具/豫言裸机/普通豫言验证。豫` 读入，附客体模块与标志之数据段，生裸机之镜像。内存布局之常量（`布局`）其址与验证之器相约，不可妄改。

## 模块

`布局` 记内存布局与状态格之常量；`基础` 记输出、变长整数、内存与宽整数之助手；余者依依赖之序。语言之约见 `文档/底层模式.文言.md`。
