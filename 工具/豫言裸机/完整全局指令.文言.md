# 完整全局验令

按模块一读定义全局之型、变记与初值，诸函数共用其型列。读取压声明型，写入须可变且值合；号与导出界皆验。

初值受四数型常量、空引用及两整型加减乘，终须恰一合声明之值。编码与函数体共用界及溢出规则，不以任意指令充常量。引用可空与具体号仍守全型之约。

接口未受非函数导入，故导入全局未备；初值之 global.get、ref.func 亦未接。其拒为未备，不谓皆非法。

二十标准模块与 Node 分类同，库试皆成。含宽整、小数、引用、非空、变记、错初值、扩展常量与越界。命令与实产物复验后录。此不运行初始化与分配，默认裸机镜像不变。

又受结构、数组、i31 之合法常量构造，先验子码白名单，后循对象型规；字段读写及余操作不因此可充常量。二十全局与二十结构回归皆过。
