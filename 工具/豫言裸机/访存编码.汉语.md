# 带边界检查的访存机器片

新增 ARM64 与 AMD64 标量访存编码器，接受可信的线性区基址、长度、指令偏移、访问宽度及读写方式。它们生成直接操作内存的机器指令，不调用 C 或 LLVM，也不使用私有缓冲区。

客体地址从操作数栈按三十二位位模式零扩展。地址、偏移和访问宽度在六十四位寄存器中相加，比较完整访问的末端与线性区长度。只有检查通过才加上基址并访问；失败进入现有裸机陷阱路径。这样不会把三十二位加法溢出误当成低地址访问。

支持一、二、四字节写入，以及对应读取和八／十六位符号扩展。读写后沿用既有操作数栈接口与压栈容量检查。线性区映射、生命周期和增长仍由后续接入层负责。
