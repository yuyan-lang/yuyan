# 客体等值引用比较

用户态 WasmGC 执行器新增 `ref.null eq` 与 `ref.eq`。解码器把 `ref.null eq` 标记为可空 `eqref`，运行值采用零；原有函数引用空值仍使用独立的 `-1` 表示。静态验证允许 `i31ref`、`eqref` 以及实际类型为结构体或数组的具体引用参与 `ref.eq`，拒绝普通 `i32` 和函数引用。运行时比较两个受检引用值的身份或小整数值，结果为 `i32`。

独立标准模块覆盖相等的两个 `i31`、两个空 `eqref`、空引用与 `i31` 不相等、两个新分配数组不相等、具体数组空引用与通用 `eqref` 空引用相等，以及把整数或函数引用交给 `ref.eq` 的无效模块。具体数组和结构的空引用也使用 GC 空值零；具体函数空引用保留原函数引用空值。它们分别由标准 WebAssembly 引擎核对。

这仍是受限执行路径：`eqref` 函数参数、返回值、类型化局部、全局及数组引用元素尚未接入，`ref.is_null` 对 `eqref` 的完整类型规则亦待补。当前测试不能证明普通豫言模块已可运行。

后续已接通当前引用子集的 `ref.is_null`，见[客体引用判空执行](客体引用判空执行.汉语.md)；其他列出的缺口仍在。

七个独立模块的标准引擎判定与豫言执行器一致。ARM64、AMD64 完整 QEMU 回归共 368 项全部通过；产物与串口日志在 `/tmp/yy裸机验证.AHdhq3`。生产 Shell 的外层 Wasm 模块已通过结构检查和标准引擎验证，编译器入口类型检查通过。
