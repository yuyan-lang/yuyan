# 示例：于豫言操作系统中行程序

`工具/豫言裸机/示例/` 乃一树，可径置于磁盘：`程序/` 下为数则普通豫言之程序，`数据/` 下为其所读之文件。壳之试 `示例` 以符号链接为其预置之树，故此中诸程序，皆于二架构之 QEMU 逐字验其出。

## 行

```sh
./yy豫构 文件 工具/豫言裸机/豫言系统。豫 --编译器 ./yy4_bs --输出 yy豫言系统
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy豫言系统 运行 --预置 工具/豫言裸机/示例
```

`--预置` 所指之树，整置于磁盘（缺省八千一百九十二扇区即四兆字节，每程序编为 `.wasm` 约三百四十千字节起，程序多则以 `--盘容量 32768` 增之）；树中以 `。豫` 终之源，先以普通豫言之编译器编为 `.wasm`（`程序/你好。豫` 成 `/程序/你好.wasm`）。启动之后，于壳中以 `运行 路径 参数…` 起程序，以 `退出` 闭系统：

```
壳> 运行 /程序/你好.wasm 豫言 操作系统
你好，豫言、操作系统！
壳> 运行 /程序/统计.wasm /数据/文本.txt
文件：/数据/文本.txt
字节：132
行数：5
词数：8
壳> 运行 /程序/质数.wasm 30 > /质数.txt
壳> 读 /质数.txt
```

## 诸程序

| 程序 | 所为 | 所示之能 |
|---|---|---|
| `你好` | 向每参问好，无参则问候“世界” | 命令行参数、标准输出 |
| `回声` | 每参各印一行 | 命令行参数 |
| `质数 [N]` | 列不逾 N（缺省五十）之质数 | 递归与整数运算 |
| `斐波那契 [N]` | 印前 N（缺省十）项 | 尾递归（栈不增） |
| `统计 [文件]` | 印文件之字节、行、词之数（缺省 `/数据/文本.txt`） | **子进程读文件**（由初始任务代办） |
| `复制文件 源 目标` | 依字节复制文件，二进制亦不损 | 子进程读写文件、错误之处 |

壳之诸令亦可与之相配：`运行 … > 文件` 以子程序之标准输出写入文件，`追加`、`复制`、`移动`、`读`、`列` 治文件，`脚本 路径` 逐行行文件中之令。

## 自作程序

1. 于预置树之 `程序/` 下置一普通豫言之源程序（以 `寻观「标准库」之书。` 起，可参此中诸例）。
2. 命令行参数用 `「命令行参数」之「获取参数」于「元」`，文件用 `「文件系统」之「读文件」`、`「写文件」`、`「读文件字节串」` 等，退出码用 `「进程」之「退出」`。
3. 复行 `yy豫言系统 运行 --预置 汝之目录`；程序编为 `.wasm` 后，至多四兆字节者皆可自磁盘而行。

## 已知之限

- 子程序中之文件事，由壳所在之初始任务经内核邮箱代办，每信唯三字节，读写兆字节级之文件甚缓。
- 子程序不得再起子进程（内核唯二任务槽）。
- 线性内存至多三十二兆字节，一次物化数十万项之列则堆尽；递归数千层之内无妨。
- 无实时时钟、管道与环境变量；详见 [说明](说明.文言.md) 之“今之界”。
