# 数组对象验型

今受数组创建、默认创建、定长创建、普通及扩展读、写、长度、填充与复制。索引长度皆 i32，元素依具体声明；非空引用不得默认造，窄域读法分明，写填须可变。

复制别取源目型，目须可变，源可只读，源存储型须可赋目。窄宽不同不可因展开同为 i32 而混同。诸操作数依序验，空引用型可受，行时陷阱尚须按指令之义实现。

定长创建不先展巨型列；实值验毕而至断流帧底，余未知可径处。可达缺值仍拒。此为验时优化，非谓运行数组容量无界。

二十模块与 Node 分类同，豫言验者皆成；二十结构及 i31 回归亦成，验型构建皆成。日志存 `/tmp/yy数组对象检查日志`、`/tmp/yy数组对象构建日志`、`/tmp/yy数组对象运行日志`、`/tmp/yy数组结构回归运行日志`。

段式创建初始化、对象执行、分配回收尚待，默认裸机镜像不变。
