# 独立 C 编译器生成模块的互操作验证

本轮输入由独立 Clang 编译 C 夹具产生，不由豫言手工构造 Wasm 函数体。模块通过标准导入 `平台/核验` 双向传递计算结果，导出 `启动` 与线性内存 `memory`。程序包含栈数组循环、整数公约数、移位组合及持久变量更新，正常运行完成四次核验；另编译错误期望值版本，必须报告失败。

实际输入带有一个未初始化、未导出的函数表，以及内存导出。新增外部模块读取层保留这些声明，检查表界、导出重名和内存索引；规范化写出仍保留表和完整导出列表。当前还不支持元素段、表操作、间接调用、表导出或全局导入导出，遇到这些形式仍明确拒绝。没有把未知段静默丢弃。

2026-09-22：原生豫言参考执行器、同源码 WasmGC 参考执行器均完成独立双实例执行及错误期望拒绝。原始及规范化模块在 V8 中各完成四次核验，内存导出仍为两页。ARM64 与 AMD64 分别完成正常和负对照裸机运行，连同既有测试共 110 项全部通过。完整验证工具运行的产物目录为 `/tmp/yy裸机验证.LgvrTT`。

夹具使用 Clang `23.1.0-wasi-sdk`，LLVM 提交 `895aa2c896ada719451be2e3673c83da8ddf1141`。本机只读使用 `/Users/zc/repos/yuyan-worktrees/yuyan-wktree-4/yy_wasi_sdk/bin/clang`。该工具仅制作外部测试输入；豫言机器后端直接生成双架构客体镜像，客体不链接 libc。

```sh
./yy3_bs 工具/豫言裸机/验证。豫 -o yy裸机验证 -j 1
./yy3_bs 库/编译器核心/网页汇编核心/外部模块。测试。豫 -o yy外部模块测试 -j 1
./yy3_bs 工具/豫言裸机/外部模块验证。豫 -o yy外部模块验证 -j 1
./yy外部模块验证 /你的SDK/bin/clang
```

豫言验证工具使用 `-O1 -fno-builtin -nostdlib`、`--target=wasm32-unknown-unknown`、无默认入口、去符号，以及两页初始／四页最大内存。源码在 `外部模块夹具.c`；它是外部语言兼容性夹具，内核、机器编码器和验证驱动均仍以豫言实现。

此证据覆盖该独立编译模块及当前支持的指令和模块形式，不能推出任意 C／Wasm 程序均已兼容。本次裸机路径在宿主预先读取模块并生成机器码，尚未证明客体内动态加载器或用户态解释器已经完成。调度、文件系统、默认用户态 Shell、完整 WasmGC 及故障任务独立退出仍待实现。

补充验证：原生及 WasmGC 参考测试均拒绝非法内存导出索引、表上下限错误与重名导出。命令行装配平台和外部模块执行通过。两条生成器路径产生的镜像与上述 QEMU 受测镜像逐字节一致；完整记录见 `验证记录.json` 的“独立C模块扩展验证”。
