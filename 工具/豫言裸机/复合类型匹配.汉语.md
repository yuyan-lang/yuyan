# 复合类型匹配

新增匹配层接受一个由类型上下文提供的堆类型匹配器。它不直接比较具体类型编号，负责引用可空性、数值类型一致性、存储字段、结构体字段前缀、数组元素以及完整函数参数/结果的匹配。

只读字段协变；可写字段要求存储类型双向相容，且父子可变标记必须一致。打包 i8/i16 字段必须同种，不能因为读取结果为 i32 就把不同存储类型视为相容。结构体可以在保留父字段前缀的基础上增加字段；数组逐元素匹配。函数参数逆变、结果协变，两边参数和结果数量分别必须相同。引用允许非空向可空拓宽，不能反向缩窄。

20 条运行断言通过，类型检查与构建通过。另用 8 个完整继承模块在 Node 标准引擎验证只读/可写字段、数组和函数方差的正反例，分类符合预期。日志为 `/tmp/yy复合匹配检查日志`、`/tmp/yy复合匹配构建日志`、`/tmp/yy复合匹配运行日志`。

本层不建立具体堆类型关系，不做递归类型规范化，也不独立授予模块执行许可。下一步需要把作用域检查、递归类型身份及父类型关系与本层组合；随后才能迁移客体类型段验证。默认裸机镜像未改变。
