# 默认命令壳加载运行程序

默认用户态 Shell 已接入文件系统和解释器，可用 `运行 路径 [导出名]` 从磁盘读取标准 Wasm 文件，在独立子任务中验证、初始化并运行。此功能使用生产执行组件，不携带解释器单元测试模块。

例如：

```text
运行 /外部.wasm
等待
运行 /算术.wasm 启动
等待
运行 /循环.wasm
终止
等待
```

不指定导出名时，依次查找“启动”、`_start`、`main`；指定名称时只查该名称。当前运行入口要求无参数、零或一个 i32 返回值。路径支持已有文件系统的相对路径、绝对路径及目录处理；命令的路径和导出名暂不支持包含空白的引号语法。

## 父子任务边界

父 Shell 先解析路径、确认文件类型和长度，完整读取程序到输入缓冲，然后调用内核复制任务。文件长度须在八至十三万一千零七十二字节之间。父任务保留文件系统、设备授权及命令输入状态，继续处理命令；子任务独占复制得到的解释器工作区。

子任务完成模块解析、解码、栈验证和资源初置，再查找导出并执行。未通过验证的程序不会进入运行入口。程序不能通过线性内存指令访问父任务或解释器元数据，平台导入仍只开放已实现且签名匹配的接口。

已有子任务尚未等待回收时，拒绝创建另一个程序任务，沿用当前两个任务槽的内核限制。`等待`、`终止`、`任务` 和 Shell 退出清理沿用已有内核操作；程序和内置任务共用同一任务句柄状态，不会互相漏管。正常退出、陷阱、验证失败和显式终止之后，父 Shell 仍可继续读写文件及启动后续程序。

## 返回与错误

有 i32 返回值时打印“程序返回”，并把该值作为完整任务退出码；无返回值时打印“程序执行完成”，退出码为零。结果与任务退出码使用有符号十进制显示。

模块读取、解码、验证、初置或导出查找失败时，子任务打印对应阶段并以一百二十六退出。运行陷阱、步数耗尽、未连接接口或其他运行失败以一百二十五退出，同时打印解释器错误码。显式终止的任务退出码由已有内核终止语义决定。

每次解释执行最多一百万步，函数调用深度、工作区及当前 Wasm 子集限制保持不变。被终止的任务由内核回收，父任务的块设备不会因子任务结束而撤权。

## 组装与状态

`客体执行组件。豫` 根据函数基号、类型基号和控制台提供者组装生产解释器。`程序命令壳。豫` 负责命令解析和子任务入口，`文件命令壳。豫` 将其加入默认模块。

Shell 子任务句柄存于线性内存 24600。24604、24608、24612 分别保存待运行程序长度、导出名长度及是否显式指定名称。程序字节位于 65536，导出查询名位于 63000。子任务的模块索引会覆盖部分原文件命令工作区，因此必须在复制任务后进行；父任务始终保留自己的副本。

## 磁盘验收

仅验收用的播种入口会格式化全新的临时测试磁盘，写入算术、陷阱、损坏、循环和后备导出模块，以及可选的独立 C 编译 Wasm。然后停止测试驱动会话，进入同一个默认 Shell。正常产品启动不格式化，也不自动写入这些程序。

测试先启动循环模块，等待它实际进入执行，再让父 Shell 创建、写入和读取文件，随后终止并回收程序。继续测试显式导出、默认后备导出、陷阱、损坏输入、找不到导出、错误路径与错误命令。若提供 C 夹具，必须从文件系统读取并正常完成其运行。

第二次 QEMU 启动使用默认 Shell 镜像，沿用同一磁盘，不再播种；重新读取备注和程序文件并执行，以检查真实持久化。原设备隔离、任务、IPC、文件系统及 Shell 输入回归仍保留。

这仍不是完整语言执行环境。任意模块链接、WASI、间接调用、通用任务与内存池、磁盘空间回收及完整 WasmGC 仍待完成。
