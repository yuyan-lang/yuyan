# 复合类型相容

匹配器受上下文所裁堆型之关系，不径比具体编号；本层检可空、数型、字段、结构前缀、数组及函数参数结果。

只读域可协变，可写域须双向相容，变记亦同。八位、十六位存储各守其类，不以读出皆三十二位整数而混同。结构可增域而守父前缀；数组按元素；函数受参逆变、返果协变，参数与结果数量各同。非空可拓为空，不可反向冒充。

二十运行断言、验型、构建皆成。另以八完整继承模块于 Node 验字段、数组及函数方差正反例，皆合。日志存 `/tmp/yy复合匹配检查日志`、`/tmp/yy复合匹配构建日志`、`/tmp/yy复合匹配运行日志`。

具体堆关系、递归型规范化未由此立，亦不独授模块执行权。后须合以作用域、递归型身份及父型关系，再迁客体验型。默认裸机镜像不变。
