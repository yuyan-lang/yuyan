# 类型段组合验证

`类型段验证。豫` 将作用域检查、共享递归类型身份和复合类型方差组合为类型段验证入口。入口接受共享类型表与已读取的递归组，验证后返回扩展后的共享表及包含声明和身份的上下文。原表采用值传递，验证失败不会向调用者返回扩展结果。

具体引用相容先检查身份等价，再沿显式父链查找目标类型。父编号必须严格递减，因此继承链遍历不会陷入循环。结构相似本身不建立未声明的继承关系。具体函数、结构、数组分别匹配其抽象类别；空聚合底类型可匹配具体结构和数组，空函数底类型可匹配具体函数，类别间不能混用。

每个有父类型的声明都检查复合类型关系，包括结构字段前缀、可变字段不变、只读字段协变、数组字段规则、函数参数逆变与结果协变。上下文关系由身份和已检查结构前提的父链提供，不使用模块局部编号相等代替递归类型等价。

23 个二进制类型段读取后执行组合验证，结果与 Node 标准引擎一致；另有 7 条上下文断言覆盖继承方向、底类型及类别隔离。类型检查、构建及运行通过，日志为 `/tmp/yy类型段检查日志`、`/tmp/yy类型段构建日志`、`/tmp/yy类型段运行日志`。

当前验证范围仅为类型段，不包含指令、导入导出、实例链接与 GC 运行。跨模块引用关系还需要携带各自已验证上下文并共享类型表；不能直接在一个模块的上下文中使用另一模块的局部编号。尚未接入裸机加载器，默认镜像不变。
