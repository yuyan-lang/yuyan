# 客体宽数读取

用户态客体读取器新增完整的有符号 64 位 LEB 读取函数。它通过原有受界字节读取器取得最多十字节，把结果分为低 32 位返回值和存于线性内存偏移 29476 的高 32 位。输入截断、超过十字节，以及第十字节的无效高位或续字标记都会设置原有粘滞错误；读取函数不会把溢出的编码截成可执行整数。

独立裸机用例实际检查 `0`、`-1`、`2^32`、`2^63-1`、`-2^63`、非法第十字节和截断输入，同时保留原有 32 位 LEB 边界回归。ARM64 与 AMD64 的“客体读数边界”场景均通过，完整 368 项 QEMU 回归也通过；产物与串口日志在 `/tmp/yy裸机验证.keUWXN`。主编译器入口类型检查通过。

这个独立读取函数仍只供读数用例调用；客体解码器已经按同一高低字规则处理 `i64.const`，并接通受限执行路径，见[客体宽值执行](客体宽值执行.汉语.md)。调用帧和对象字段仍按四字节值实现，普通豫言完整模块尚不可用。后续需让两处编码规则共享实现，并扩展局部、调用及结构字段。
