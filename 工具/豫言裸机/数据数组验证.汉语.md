# 数据段与数组数据初始化验证

按模块核对数据计数段与实际数据段数量，检查被动数据段的字节载荷边界。没有数据指令的模块允许省略计数段；使用数组数据构造或初始化时必须有计数段且索引有效。读取器跳过载荷，不按载荷长度构造整数列表。

array.new_data 要求数组元素为数值、向量或打包整数，弹出两个三十二位整数并产生非空具体数组引用。array.init_data 另要求目标可变，检查可空具体数组引用与三个三十二位整数。创建只读数组合法；将数据写入已有只读数组非法。引用元素不能由原始数据字节初始化。动态范围与空引用陷阱留给执行器。

20 个标准模块分类已核对，覆盖打包、宽整、向量、只读、引用错型、截断、段号越界、计数缺失或不一致、不可达路径及动态范围边界。实际库运行和回归结果见验证记录。

当前只接入被动数据段。主动数据段需完整内存和偏移常量上下文，暂明确拒绝；元素段与对应数组指令未在本阶段接入。静态验证不分配数组、不执行复制或 GC，不改变默认裸机镜像。

依据：[WebAssembly 数组指令验证](https://webassembly.github.io/spec/core/valid/instructions.html)。

本轮 20 个数据数组测试、20 个捕获回归均运行通过。现有真实产物 `yy优化器三代.wasm` 与 `yy栈默认回归GC重复索引边界.wasm` 的当前范围内全部函数指令验证通过。模块没有执行，其他资源未全验，不据此宣称普通豫言或 GC 已在裸机运行。
