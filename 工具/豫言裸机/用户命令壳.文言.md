# 用户命令壳

造镜像而不授输入模块者，默认置命令壳。用法为架构、输出镜像；旧三参之式仍行所授模块。

壳以豫言造中文网页汇编整数令，由既有后端降为用户机器码。客体不用 LLVM 与 libc；宿主仍借既有编译器。此低层显式存储之壳，非普通高层豫言全链已成，亦非客体执行器与垃圾回收规范已备。

入则验用户权限，读串口，回显而析命。帮助列其能；任务问真编号与状态；启动生短任务，过三滴答以七退；忙碌生不自退之任务；等待取其退出码而回收；终止令其退；退出则先清理子任务，再毕其身。

今限一子，未收不复生。结束非回收，句柄随代际而更。忙碌者不自毕，待之则壳亦候；未备中断键与取消。

一行限二百五十五字节，逾则尽弃至换行，不行残命。容回车、换行及其相连；退格循通字符字节之界。回显宽度暂以 ASCII 一列、余二列，未备通用字宽、历史、光标与控制序列。未知命令报错而续行。

此交互与任务之初成也。启动只行内置任务，不谓外部装载已具。文件、目录、块设备、持久化、管道、重定向、多服务、普通豫言运行时及垃圾回收规范，皆仍待成。双架构以串口实授命，核其任务与错误恢复；实录另载。
现行默认壳已增文件与路径之术，详[命令壳文件操作](命令壳文件操作.文言.md)。本篇仍记基础输入与任务交互。
