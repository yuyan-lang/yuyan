# 默认 Shell 的文件命令

2026-09-22：两架构共 314 项 QEMU 验收通过。新增三组文件交互和原有三组任务/输入交互均通过；独立解析磁盘确认重启后的文件内容和临时文件删除。命令行生成的有盘、无盘四个默认镜像与验收产物逐字节一致。

默认命令壳现在包含文件命令，同时保留任务交互、UTF-8 退格、超长行丢弃和退出时的子任务清理。Shell 仍在用户态运行。

没有设备授权时，Shell 可以继续使用任务命令，并提示文件命令不可用。采用“设备驱动”方式构建、挂接项目支持的 Virtio 磁盘和 IOMMU 后，Shell 会初始化块驱动并尝试挂载文件系统。未知格式不会自动格式化。

## 使用

```sh
./yy豫言裸机 臂六十四 '' yy文件系统臂.elf 设备驱动
./yy豫言裸机 兼容六十四 '' yy文件系统兼容.img 设备驱动
```

空输入表示使用内置默认 Shell；仍可提供其他固定内存的用户模块。QEMU 运行参数沿用项目的设备隔离平台与现代 Virtio 磁盘配置。两参数构建方式继续支持没有磁盘的运行环境。

在新磁盘上输入以下命令：

```text
格式化 确认
建目录 /文档
新建 /文档/样本
写入 /文档/样本 豫言文件，重启仍在
切换 /文档
当前
列出
读取 ./样本
退出
```

“格式化 确认”会重建挂接磁盘上的文件系统。仅输入“格式化”会显示用法，不会修改磁盘。

## 命令

| 命令 | 行为 |
| --- | --- |
| 挂载 | 重新挂载并切回根目录 |
| 格式化 确认 | 显式重建文件系统并切回根目录 |
| 建目录 路径 | 创建目录，父目录须已存在 |
| 新建 路径 | 创建空文件 |
| 写入 路径 文本 | 替换已有文件的内容；省略文本可写成空文件 |
| 读取 路径 | 分段读取并输出文件内容 |
| 列出 [路径] | 枚举指定目录，省略路径使用当前目录 |
| 切换 [路径] | 切换当前目录，省略路径回到根目录 |
| 当前 | 显示当前完整路径 |
| 删除 路径 | 删除文件或空目录，拒绝删除当前目录 |
| 帮助 | 显示文件命令和原有任务命令 |

路径支持绝对路径、相对路径、点、双点和重复斜线；根目录的上级仍是根目录。文件后面附带斜线会被当作目录要求检查。当前按空白分隔命令和路径，不支持带空格路径的引号或转义；写入文本使用路径后余下的行内容。输入仍最多 255 字节，超过后丢弃整行。

失败会显示具体中文原因，例如路径不存在、目录非空、对象类型不符、同名对象已存在或参数不合法。错误后 Shell 继续接收命令。文件命令不自动创建缺失的父目录，也不递归删除目录。

## 实现与验证边界

扩展模块复用原有 Shell 的输入循环和任务处理，将输入缓冲移至线性内存偏移 32768，避开块驱动、日志和目录状态。有磁盘时，退出命令会在已完成的同步请求之后停用设备，再继续原有子任务清理。文件系统和 Shell 暂时位于同一个用户任务，独立文件服务进程仍待实现。

自动验收通过串口实际输入命令，分三次 QEMU 启动验证格式化、创建写入、重启读取、临时文件删除和错误恢复；原有三组 Shell 交互与输入恢复也使用扩展后的默认模块。具体结果见验证记录。

“启动”目前仍启动内置任务，尚不能加载磁盘中的外部程序。日志磁盘空间回收、动态执行器、普通豫言运行与 WasmGC 仍在完整 OS 目标内，尚未完成。
