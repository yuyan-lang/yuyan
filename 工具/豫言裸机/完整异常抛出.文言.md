# 异常标签与抛出验型

逐模块读定义标签，属性须零，型号须指无果之函数型，参列即异常载荷。导出号亦验。接口未受标签导入，故此列无导入项，不谓已备全导入号域。

抛出先验标签，依参列取载荷，遂断当前帧之流。引用抛出须可空异常引用，空异常底型亦受；实值为空之陷阱属执行之事。不可达可借未知值，不免实栈错型、错号与非法声明。

二十完整模块已与标准执行器分类核对，含载荷数序、宽整、引用、属性、非函数型、有果之禁、导出越界及引用抛出。构建、验型与运行之果另录。

今仅备静态标签与抛出之规。捕获、退栈、异常对象分配及回收根未备；裸机镜像不改，不谓普通豫言已能全行于客体。后须验捕获分支及标签型，继行传播与回收。

据[指令验型规范](https://webassembly.github.io/spec/core/valid/instructions.html)及[标签编码](https://webassembly.github.io/spec/core/binary/types.html#tag-types)。

今二十异常试、二十四表调用回归皆过。实优化器模块已过抛出，止于未备之码三十一，即捕获表控制块。此为下一验型缺项，非异常执行已成之证。
