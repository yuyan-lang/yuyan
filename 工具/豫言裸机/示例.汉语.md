# 示例：在豫言操作系统里运行程序

`工具/豫言裸机/示例/` 是一棵可以直接放进磁盘的目录树：`程序/` 下是几个普通豫言程序，`数据/` 下是它们要读的文件。壳测试 `示例` 用符号链接把它当作预置树，所以这里的每个程序都在两个架构的 QEMU 里逐字验证过输出。

## 运行

```sh
./yy豫构 文件 工具/豫言裸机/豫言系统。豫 --编译器 ./yy4_bs --输出 yy豫言系统
YY_GC_INITIAL_HEAP_SIZE_MB=1024 ./yy豫言系统 运行 --预置 工具/豫言裸机/示例
```

`--预置` 指向的目录树整棵放进磁盘（默认 8192 个扇区即 4 MiB，每个程序编成 `.wasm` 约 340 KB 起，程序多了用 `--盘容量 32768` 加大）；树里以 `。豫` 结尾的源文件会先用普通豫言编译器编成 `.wasm`（`程序/你好。豫` 成 `/程序/你好.wasm`）。启动后在壳里用 `运行 路径 参数…` 启动程序，用 `退出` 关掉系统：

```
壳> 运行 /程序/你好.wasm 豫言 操作系统
你好，豫言、操作系统！
壳> 运行 /程序/统计.wasm /数据/文本.txt
文件：/数据/文本.txt
字节：132
行数：5
词数：8
壳> 运行 /程序/质数.wasm 30 > /质数.txt
壳> 读 /质数.txt
```

## 程序

| 程序 | 作用 | 展示的能力 |
|---|---|---|
| `你好` | 向每个参数问好，没有参数则问候“世界” | 命令行参数、标准输出 |
| `回声` | 每个参数打印一行 | 命令行参数 |
| `质数 [N]` | 列出不超过 N（默认 50）的质数 | 递归与整数运算 |
| `斐波那契 [N]` | 打印前 N（默认 10）项 | 尾递归（栈不增长） |
| `统计 [文件]` | 打印文件的字节数、行数、词数（默认 `/数据/文本.txt`） | **子进程读文件**（由初始任务代办） |
| `复制文件 源 目标` | 按字节复制文件，二进制也不损坏 | 子进程读写文件、错误处理 |
| `行数` | 从标准输入逐行读到结束，打印每行的序号与内容和总行数 | **标准输入重定向**（`运行 … < 文件` 或管道），`尝试读取标准输入行` 遇文件结束返回阴 |
| `环境变量 名…` | 打印每个参数名对应的环境变量的值（没设置则说明未设置） | **环境变量**（壳的 `设` 命令给出），`获取环境变量` |
| `死循环` | 打印 “死循环开始” 后永远空转（尾递归循环） | **Ctrl-C**：运行后按 Ctrl-C，执行器以退出码 130 结束它 |
| `日期检查` | 读实时钟，检查 `当前日期时间表示` 形如 `YYYY-MM-DD hh:mm:ss`，打印年月日与小时 | **实时钟**（内核墙钟服务，UTC）；壳的 `日期` 命令打印完整的当前日期时间 |

壳命令也能配合它们：`运行 … < 文件` 让程序的标准输入取自文件（如 `运行 /程序/行数.wasm < /数据/文本.txt`），`运行 甲 … | 乙 …` 把前一个程序的输出送给后一个（顺序管道），`设 名 值`、`取消 名`、`环境` 维护环境变量（存在 `/.环境`），`日期` 打印当前的 UTC 日期时间，`运行 … > 文件` 把子程序的标准输出写进文件，`追加`、`复制`、`移动`、`读`、`列` 处理文件，`脚本 路径` 逐行执行文件里的命令。

## 写自己的程序

1. 在预置树的 `程序/` 下放一个普通豫言源程序（`寻观「标准库」之书。` 起头，参见这里的例子）。
2. 命令行参数用 `「命令行参数」之「获取参数」于「元」`，文件用 `「文件系统」之「读文件」`／`「写文件」`／`「读文件字节串」` 等，退出码用 `「进程」之「退出」`。
3. 重新运行 `yy豫言系统 运行 --预置 你的目录`；程序编成 `.wasm` 后至多 4 MiB 都能从磁盘运行。

## 已知限制

- 子程序里的文件操作由壳所在的初始任务经内核邮箱代办，每条消息只带三个字节，读写兆字节级文件会很慢。
- 子程序不能再起子进程（内核只有两个任务槽）。
- 线性内存至多 32 MiB，一次物化几十万项的列表会用尽堆；递归深度几千层以内没有问题。
- 实时钟只有秒的精度、只有 UTC；管道是顺序的（各段一个接一个运行，前一段必须自己结束）；详见 [说明](说明.汉语.md) 的“当前限制”。
