# 客体间接调用

后续：标准元素段之验证与初置已接，见[客体元素段](客体元素段.文言.md)。下存间接调用初验之范围。

今行标准间接调用令，所受之型皆三十二位整数。字节码及公用接口仍旧。

解码先验类型号与表号；验栈先取表下标，继按签名取参添果。运行复验界限、空引用与目标之型，然后循直接调用之途。型以结构相合为准，不以编号同异为断；今所受子集，参数与结果之数相同即合。

越界、空引用、异型皆返负四。入口收栈、复调用深度、撤执行之权，不令执行器陷于机器异常。资源初置，表项皆空。

元素段、改表诸令及完整引用类型尚未成。成功调用之试，由验收代码于初置后填表；此乃测试设施，非程序接口，不可据此谓任意 C 函数指针已通。后须接元素段之验证与初置，再验全程。

新增九试：空引用、正负越界、异号同型、异型、无表、误表号、误类型号、缺参。九试之有效性、其中五试之运行结果，皆与标准执行器相合。标准执行器之试，经导出表置同一函数引用。

所据：[WebAssembly 间接调用验证规则](https://webassembly.github.io/spec/core/valid/instructions.html)。今仅承诺上述子集。
