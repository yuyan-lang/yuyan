# 用户线性内存的设备映射

内核现在可以为固定设备建立一至一百二十八个连续硬件页的映射，每页 4096 字节。设备地址从 `0x1000` 开始，物理起点由内核镜像构建者指定。内部接口拒绝空区间、非页对齐地址、超过 128 页及越过 32 位物理地址空间的区间；它不接受用户程序提交的任意物理地址。

这一步复用既有的 SMMUv3 / VT-d 上下文、页表发布和失效同步。授权只覆盖指定区间，没有打开直通。调用者必须证明区间属于被授权任务；参数范围检查本身不构成所有权证明。旧的单页写保护、撤销及漏刷负对照继续使用同一实现。

自动验收为根任务配置固定八页 Wasm 内存，即 512 KiB。ARM64 物理起点为 `0x40300000`，AMD64 为 `0x300000`。设备地址区间为 `[0x1000, 0x81000)`。

| 用例 | 设备地址 | 要求 |
| --- | --- | --- |
| 用户设备区首部 | 0x1000 | 四字节真实 DMA 写入成功，相邻四字节不变 |
| 用户设备区末部 | 0x80ff8 | 最后一个硬件页的末端写入成功，相邻四字节不变 |
| 用户设备区上界 | 0x81000 | 写入被拒绝，哨兵不变，记录对应设备和地址的翻译故障 |
| 用户设备区只读 | 0x80ff8 | 写入被拒绝，哨兵不变，记录写权限故障 |

VT-d 故障地址按硬件页记录，核对时清除低十二位；SMMUv3 事件核对请求的设备地址。不能把其他初始化失败算作隔离成功。

这些用例仍由内核诊断钩子驱动 EDU 发起传输，并在之后进入用户态程序。它们证明用户物理区间可以受 IOMMU 约束地承接 DMA，尚未证明用户态 Virtio 块驱动完成磁盘读写。后续仍须接入受限设备寄存器访问、队列协议、在途请求取消与撤销、资源生命周期及持久化。该内部初始化接口也不能用于重置正在运行的设备地址空间。

用户程序会再次确认当前运行于用户态。首部、末部和只读用例还通过标准 Wasm 线性内存读取指令核对目标值及相邻哨兵，确认设备操作后的物理内存就是该任务实际可见的内存。上界位于 Wasm 内存之外，只由内核诊断核对，用户程序不能越界读取。保存的 `.wasm` 与镜像中的用户模块一致；它依赖镜像启动钩子准备诊断数据，不能脱离该环境单独当作普通计算样例运行。

构建与完整回归：

```sh
./yy设备配置编译器 工具/豫言裸机/验证。豫 --type-check-only --parallel
./yy设备配置编译器 工具/豫言裸机/验证。豫 -o yy裸机验证 -j 1
./yy裸机验证 --外部模块 yy外部C模块.wasm yy外部C错误.wasm
```
