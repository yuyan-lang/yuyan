# 跨模块函数类型匹配

新增跨模块函数匹配使用提供方与使用方各自已验证的类型上下文。先检查两边共享类型表的共同前缀一致，再确认所指类型均为函数，最后比较共享身份并沿提供方显式父链查找使用方要求的类型。不会把使用方局部编号用于索引提供方的类型列表。

共享表可以是同一条扩展链中的不同快照；独立表若出现同号不同结构，则拒绝。发生分叉且公共部分之后不一致的表也拒绝，调用者应重新在同一共享表中登记模块。身份比较与实例函数绑定分开，此层还没有捕获函数实现或运行跨模块调用。

7 条测试覆盖等价类型编号平移、提供子类型满足父接口、反向继承拒绝、不同签名、非函数类型、独立表碰撞及旧快照复用。类型检查、构建及运行全部通过。另用 Node 实际实例化提供者和消费者模块，验证子类型绑定成功、i64/i32 参数不匹配产生链接错误；这只是规范对照，不是豫言裸机链接验收。
