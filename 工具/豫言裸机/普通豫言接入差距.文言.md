# 普通豫言接入裸机之未备

据二〇二六年九月二十三日源码，三百六十八裸机试仅证既有系统服务及所受网页汇编子集，不证普通豫言与垃圾收集皆成。今默认壳由豫言构整数指令而降用户态机器码，未由普通语法循完整正则中间式、垃圾收集网页汇编之路而来。

直生说明载今 `--target=wasmgc`；编译器核心旧后端使用说明载 LLVM/WASI，二者不可混。直生运行时以 i64 字段装巨整，以可变 eq 引用数组存元组、引用，兼有 i31、型转换、型测试、引用相等、结构读取、数组造读写复制及异常标签。通用宿主入口 `yuyan:gc-host/v1.call` 受两可空 eq 引用而返一。

统一生成器又出引用全局、参数、结果、代数结构、i64 与 i8 数组及专门结构；编码基础出 f64 常量而装箱。尾调用、提前退出亦各有义。独成结构分配，不足言普通豫言可行。

当先备完整值型、字段型、递归型组与子型，验宽数传递、同型、可空及可变字段之约；复核元数据、值栈、调用帧与客体存储诸域，不相侵，竭则报错。次备对象及回收，验环、共享、死物复用、界外、空值与错型。根须及操作数、局部、全局、表、宿主暂存与异常载荷；活者留，死者可去。又备尾调不积帧、异常展开与宿主权限边界。

终验须由普通编译器造程序，动态载入，分配逾堆额而实际回收，返壳后仍可操作文件，两架构皆过。可先以非移动标记清扫实现回收，此乃次序，不减递归类型、规范与普通程序之终求；对象地址不得作为可伪造整数授模块。

所据：[垃圾收集类型](https://webassembly.github.io/gc/core/syntax/types.html)、[运行时结构](https://webassembly.github.io/gc/core/exec/runtime.html)。函数、聚合与外部引用各有其类；i31 非通常堆分配物。内存与回收之法可择，模块可见之义不可改。
