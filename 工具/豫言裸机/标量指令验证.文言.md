# 标量数值验型

顺序验令今受标准标量码百二十八（0x45–0xc4），及饱和截断八码（0xfc 之 0–7）。含整浮比较算术、位术、浮点单目、转换、重解释与符号扩展。四数型各别，比较返三十二位整数，转换参果各验。

每码造三完整模块：正型、错参、错果，合四百零八，皆以 Node 独核分类。试不行算术，故不证除零、数值精度与浮点运行之义。

此仍验型，非裸机算术执行之扩展。结构控制、回收对象指令尚待，0xfc 余码仍拒，默认镜像不变。

豫言验者之四百零八模块试及旧十八顺序试皆成，验型构建亦成。日志存 `/tmp/yy标量指令检查日志`、`/tmp/yy标量指令构建日志`、`/tmp/yy标量指令运行日志`、`/tmp/yy标量回归运行日志`。
