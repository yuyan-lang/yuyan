# 客体执行器二号（普通豫言 WasmGC）

## 何以有此

一号执行器（手写扁平指令列，约七百二十七千字节之源）唯能行整数之子集，模块窗口一百二十八千字节、函数百二十八、值槽四字节，不足以承普通豫言所编之 WasmGC 模块：带标准库打印之最小者，函数八百、全局一千三百五十七、被动数据段五百二十二、类型三十八，用 i64、引用、结构与数组、具体类型转换、异常及尾调用。二号执行器以**底层模式**之常豫言书之（详见 `文档/底层模式.文言.md`；此代昔所自造之括号式低阶语言），约四千五百行，源在 `工具/豫言裸机/客体二号/`，乃一包，书 `「编译模式」者『底层』也。`，唯依 `底层库`。译为 Wasm 模块，读成「网页状态模块」，经既有之寄存器降级入 ARM64、AMD64 用户镜像，于用户态行之。

## 值与对象

- **值槽**：操作数、局部、全局皆八字节槽 `[低字, 高字]`；i32、引用唯用低字，i64、f64 占满。
- **引用字**：零为空；奇数为 i31（`(值<<1)|1`）；低三位 010 为函数引用（`(函数号<<3)|2`）；八字节对齐之堆址为对象。
- **堆对象**：头八字节 `[类型号|种类<<24|标记位, 总字节数]`。结构 = 头 + 每字段八字节槽（压缩字段存低字）；数组 = 头 + `[长度][填充]` + 元素（按宽度一、二、四、八字节）；异常对象（种类四）存标签与载荷。
- **类型表**：每型三十二字节，记种类、参数／字段／元素之情、超类；字段类别零为四字节数值、一为八字节数值、二为引用、三为 i8、四为 i16。类型相涉以超类链断之，函数类型逐字节较其参数与结果之编码。

## 行

- **直解字节码**：每函数初次被召时扫其体，立边表（每字节偏移八字节：块起→end 之后、if→else 之后）；其后 `block/loop/if/br` 由运行时**标签栈**（每项 `[目标, 栈基, 元数, 种类]`）司之，`try_table` 之标签兼理**处理器栈**。
- **寄存器为循环之参**：主循环 `解释循环(指令针, 帧针, 边基, 栈针)` 乃自尾递归之函数，译为回跳；简单指令径续，控制转移类（throw、end、br 系、return、调用系、GC 前缀）经状态格 `新指令针／新帧针／边偏` 交回新现场，`新指令针` 为零则最外层函数已返。
- **显式调用帧**：帧栈项 `[返回址, 召者 fp, 召者函数, 标签栈顶, 处理器栈顶]`；尾调用（`return_call`、`return_call_indirect`、`return_call_ref`）复用当前帧；函数返回则复标签栈与处理器栈。
- 值栈、标签栈、帧栈、处理器栈、标记栈、边表池、堆皆在线性内存，大小由常量定；初逾八页则由寄存器降级之增长助手迁入内核动态块。
- 陷阱径印其因，以专属退出码（一二〇至一三七）退任务。

## 回收

非移动标记清扫：分配先取自由链（小块按八字节分类，大块首次适应而分之），次自堆顶划出，不足则先回收、再向内存请增。对象起始位图（每八字节一位）以辨候选之指针；根为值栈（保守，两字皆扫）、全局、表及异常载荷；堆内对象按类型精扫诸字段。每回收毕，阈值取存活字节与二兆字节之较大者。宿主原语执行时禁回收，免多次分配间之中间对象丢失。

## 宿主原语

`yuyan:gc-host/v1.call(名字节数组, 参数元组)` 按名分派：打印行、打印字符串、标准错误打印行、打印通用值、退出进程、命令行程序名与参数、工作目录、环境变量（恒空）、平台之判、读标准输入行、字节转字符串、字节串之空／长度／取字节／从字符串／单字节／拼接、整数加／乘／除、整数转字符串、字符串转整数，及文件与目录之原语（读写删、建目录、列目录、路径之判、切换目录、格式化与挂载）。整数依运行时之约装箱（i31 或 `$big`），对象类型号取自模块所导出之原型 `yy_bytes`、`yy_tuple`、`yy_big`、`yy_float`。**未实现**：小数运算（须浮点）、进程之原语。

## 持久文件系统与块设备

Virtio 块设备（现代之协议、单队列、一次一请求）之驱动行于用户态：初置时协商特性、核 PCI 能力链、配队列而读容量；队列、请求头与数据之缓冲皆在内核所授之静态窗内，用户态唯经 `搬入静态／搬出静态` 二内核服务存取。文件系统乃双区追加日志：超级块加两等长之记录区，记录由头扇区、数据扇区、提交扇区合成，挂载时顺次验之，遇无效之头或缺提交扇区即为日志之尾；空间不足则紧缩存活之条目入他区而换超级块。

## 构、调与验

```text
./yy豫构 构建 客体二号 --输出 /tmp/yy客体二号.wasm
```

所成者标准 Wasm 模块（导出 `启动`，签为 `() → ()`）。验证之器 `工具/豫言裸机/普通豫言验证。豫` 读之，附客体模块（0x10000 起，至多四百四十八千字节）、模块之长（0x408）及标志数据段，生 ARM64 与 AMD64 镜像。`启动` 缺省召导出 `_start`，试验时可于 0x2400 置导出名、0x2440 置参数个数、0x2444 起置 i32 参数。同一 wasm 可于 Node 调试：宿主供 `平台` 模块之 `写字节`、`退出任务`、`读字节` 及设备诸函数，先写客体入内存再召 `启动`。

验：`yy普通豫言验证` 编 `普通探针/` 下诸 `.豫` 源（`./yy豫构 … --target=wasmgc`），嵌模块入执行器，生 ARM64 与 AMD64 镜像于 QEMU 行之，要求串口输出恰为「豫言核心启动」、与 `.期望`（宿主 Node 行同一模块之出）逐字同之程序输出、「用户任务全部退出」；磁盘之探针别带持久盘，涵跨重启之文件读写。

## 界

- 仅搬运 f64 常量，**无浮点运算**（遇之即陷阱）；无 SIMD；多内存、导入内存／表／全局、外部引用未作。
- 不验模块，信编译器之产物；`ref.cast` 用超类链，不作跨递归组之结构等价。
- 文件系统之外，进程、时间等宿主原语待接。
