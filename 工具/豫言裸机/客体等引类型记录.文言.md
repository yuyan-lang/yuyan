# 客体等引类型记录

旧索引惟纳 `i32`（`0x7f`）与 `funcref`（`0x70`）。常语最小 Wasm 模块首函型即用 `eqref`（`0x6d`），故旧法不能存其签名。

今索引器识函数之等引参数与单结果。每型十六字，仍记参数数、结果数及结果型；参数位图低十六位记函数引，高十六位记等引，故不混为整数或函数引。结果字段存 `0x6d`。见等引则读尽类型段后返不支持之负二；客体未备 GC 验型和值栈，未可放行。

裸机验具用二函型之标准 Wasm 字流：一以等引为参，一以等引为果。直验位图六万五千五百三十六、结果型一百零九、拒码及错误状态；复载普通整数模块，验状态归零。臂六十四与兼容六十四三百六十八 QEMU 场景皆过，产物在 `/tmp/yy裸机验证.hhWnqo`。真实常语小模块经壳之文件途径，犹以负二拒，未行其体。

次当使客体类型表纳结构、数组、递归组、具体引用与子型，复传等引之型记于操作数、局部、全局及 GC 堆。小整内码虽另验，尚未接诸途；今不谓已能行 WasmGC。
