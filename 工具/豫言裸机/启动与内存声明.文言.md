# 启动与内存声明之验

二〇二六年九月二十三日，复治裸机之事。今于遍验函数体之前，先验启动段及内存声明；虽无定义函数体，亦不得逸其检。此为用户态执行器纳外部模块之静态关隘。

启动段或阙；若有，独载一无符号三十二位函数号。所指函数兼计导入与定义，参、果俱空。验而不行。段重、段空、余字、越界、编码不正，皆拒之。

三十二位内存之下界不得逾上界，亦不得逾六万五千五百三十六页；共享者必具上界。导出内存之号，须在已定义者之内。普通读写及页数、增长诸令，今验内存之有无、编号、对齐及整数浮数之型。多内存读写扩展立即数明拒，其动态语义尚待成。六十四位内存今明拒，乃实现所限，非谓规范不许。主动数据与批量内存令，犹未尽系于声明，故未可称模块全验。

新增启动十三例、内存声明十四例、内存指令十二例，验合法与非法诸形，复验旧异常。大部分类与标准执行器合；六十四位内存之拒为特例。新建验收器于臂、兼容两架构 QEMU 共过三百六十八场景，含外部 Wasm 模块；两真实大模块亦过新静态入口之检，未于客体尽行之。裸机镜像生成路径未改。后宜联主动数据与批量内存令，继而实作普通豫言 WasmGC 对象与回收，终以双架构 QEMU 自 Shell 装载、运行、退出、再用资源为证。
