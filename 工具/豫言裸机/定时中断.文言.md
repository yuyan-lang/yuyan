# 用户行时之定时中断

后续改用全整数帧，详[任务上下文](任务上下文.文言.md)。下存初验之界。

双架构今默认开周期钟，许用户态受硬中断。钟至入核，增滴答，确认设备，复还原任务。增“平台／时钟滴答”导入，无参而返三十二位整数，计已处理之钟，满宽则回绕。

臂用 virt 之第二版中断控制器与非安全物理定时器，号三十。映设备而独许内核，设分发、接口与优先级，以频率寄存器除百为期。存所改四寄存器，核来号，计数、重载，复写确认号，还寄存器而返。所据平台与架构规范详汉语篇。

兼容架构用传统中断控制器与定时器，移钟至向量三十二，蔽余外设，分频一万一千九百三十二，约每秒百次。门核来者为用户，存所改寄存器，计数并告中断毕，复而还客。返客时许中断，内核处理时仍蔽之。今验于单处理器 pc 模拟平台。

未行任务切换。滴答只计已处理之中断，非精确墙钟；久蔽、模拟器暂停等不可据以推实历时。多处理器路由、他平台设备发现与全上下文保存尚待之。

二〇二六年九月二十二日，双架构用户各行两段百万次累加，中无系统调用，后核算术与新增滴答，以验异步入核、原程续行及钟之再至。负例只蔽返客状态之中断位，模块与硬件如故，则进展核验败。补丁位置须唯一。

默认一百一十验、含独立 C 模块一百一十四验皆过。后者产物在 `/tmp/yy裸机验证.RZ3ePo`，诸证录于 `验证记录.json` 之“定时中断扩展验证”。实码经反汇编核验，非法设备偏移皆拒，诸型合。复验命令详汉语篇。

调度、故障任务独退、内核通信、文件系统、用户默认壳、客体动态执行器与完整垃圾回收未成。此为抢占之基，非抢占调度已验。
