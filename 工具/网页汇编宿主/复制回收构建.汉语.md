# 复制式 GC 宿主构建

官方 Wasmtime 48.0.1 C API 默认构建包含 DRC，却不包含 `gc-copying`。本地实验使用同版本源码，显式启用复制式 GC，并将初始 GC 堆设置为 128 MiB。修改保存在 `复制回收器.patch`；不更改 GC 算法。该补丁还允许复用已下载的同版本官方 C 头文件，免于通过 CMake 再次安装。

源码目录为 `yy_wasmtime_gc_source`，本地 Rust 1.98.1 位于 `yy_rust`，Cargo 缓存为 `yy_cargo`。这些是可重建依赖，不是豫言编译器的一部分；正式自举计时不包含下载和构建这些依赖的时间。

```sh
# 在 Wasmtime 48.0.1 源码根目录应用补丁之后构建。
YY_WASMTIME_PREBUILT_HEADERS="$PWD/../yy_wasmtime_c_api/include" \
CARGO_HOME="$PWD/../yy_cargo" RUSTC="$PWD/../yy_rust/bin/rustc" \
../yy_rust/bin/cargo build --release -p wasmtime-c-api \
  --no-default-features \
  --features wat,wasi,parallel-compilation,gc,gc-copying,cranelift -j 8

# 回到豫言仓库根目录。
make 网页汇编复制宿主 网页汇编宿主编译器=./yy3_bs
./yy网页汇编复制宿主 --预编译 yy回收编译器.wasm yy回收编译器复制.cwasm
./yy网页汇编复制宿主 --运行预编译 yy回收编译器复制.cwasm <编译器参数>
```

DRC 与 copying 的 AOT 文件不可混用。复制宿主与原宿主采用相同的系统接口桥接。`YY_WASM_GC_RESERVE_MB` 是早期 DRC 诊断使用的容量预留方式，正式 copying 测试不设置它，直接采用引擎的初始堆配置。

补充内联配置：设置 `YY_WASM_GC_INLINE=1` 时，宿主调用引擎的 `compiler_inlining(Inlining::Yes)`；不设置时保留默认的 `Inlining::No`。预编译与运行使用同一设置。子进程继承该环境变量，因此并行工作进程也使用一致配置。该设置只影响引擎生成机器码，不改变编译器源码或输入 Wasm。

宿主必须通过 `wasm_engine_new_with_config(wasm_config_new())` 构造引擎。`wasm_engine_new()` 会直接使用 `Engine::default()`，绕过上述设置。使用 `YY_WASM_GC_CONFIG_LOG=1` 可输出构造完成的实际初始堆与内联模式；有效的 128 MiB 配置应显示 `heap_initial=134217728 bytes`。早期成绩中误标为 128 MiB 的运行已重新标记为默认堆，不能与修正后的配置混淆。

EH 直调版本将 Wasm 调用栈限额设为 64 MiB，并将引擎 async_stack_size 设为 128 MiB 以满足配置约束。C 宿主使用 128 MiB 的独立 pthread 栈，主线程等待其结束；这不是并行执行豫言运行时。该配置不改变 128 MiB 初始 GC 堆。

批量字节桥接需同时应用 `批量字节桥接.patch`，它将引擎已有的 `ArrayRef::new_from_i8_slice` 与 `copy_to_i8_slice` 暴露给 C 桥接，避免逐字节建立根及检查类型。复制宿主以 `YY_WASM_GC_BULK` 编译；普通宿主保留逐元素兼容实现。

`YY_WASM_GC_HEAP_MB` 可设置初始 GC 堆为 64–2048 MiB，默认保留 128 MiB；性能对照另测 512 MiB。复制收集器使用两个半区，因此总容量 128 MiB 时活动区约为 64 MiB。每个并行进程独立持有堆。改变容量必须重新生成对应 AOT 文件，并在运行时使用相同设置，引擎会拒绝不匹配的产物。

自举计时应保持开盖、接交流电。`caffeinate -i` 可在命令期间防止空闲休眠，但本机合盖后仍发生 DarkWake/休眠，不能仅凭该命令认定测试有效。最终对照需检查电源日志，剔除休眠干扰；详见 `../../性能研究/网页汇编直生/优化结果.汉语.md`。优化后的测量配置使用每进程 1024 MiB（四进程）或 2048 MiB（串行），宿主默认值仍未改变；AOT 准备成本需与自举运行计时分开说明。
