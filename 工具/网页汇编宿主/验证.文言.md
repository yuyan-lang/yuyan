# Wasm 编译器自举之验

复由完整入口以同名生成四级，与三级逐字节尽同，cmp 得零，固定点已成。

二〇二六年九月八日，于 Apple M5 Pro、macOS arm64，Wasm 二级生三级，三级生四级，皆全程编译链接而成。两代原物唯 name 节中“三级／四级”三字节异，其代码、数据与余字节尽同。摘要、差异及原录见《验证记录.json》《../../性能研究/网页汇编比较/宿主自举记录/》。

二级生三级耗二百三十点零六秒；具独立栈检之三级生四级耗三百六十九点一一秒；同版原生生后继耗六十二点七二秒。正式 Wasm 成绩约原生五点八九倍。各取一验，四工并行，新编译器缓存而禁读旧缓存，系统文件缓存未清。Wasm 自载 AOT 至链成后继计之，预编译另耗零点四零秒。内含宿主、子进程、LLVM 与链接，非独量指令之速。原生 LLVM 22.1.7，WASI SDK 34 内 LLVM 23.1.0。

二级未具新生成之栈检，三级有之；然两验非严格隔离，不尽以时差归之于检查。旧一百一十九点七七秒别属前验，今以同版直接入口为对照。原生首两验或漏库、或清单失标，皆败于链接，其时不入成绩。清单首行须“豫构原生链接二”，次列豫构原生归档绝对路径；现代命令详汉语本。

旧栈先写后验，越而损堆；今先验写界，扩编译宿主之栈至五百一十二 MiB，线性内存限四 GiB，初堆六十四 MiB，单堆限五百一十二 MiB。动态堆分配亦先验余量。六项内存回归、宿主边界皆过；详《自举修复.文言.md》。

原生三级四级逐字节同，完整类型检查过。旧 yy_bs_stable 首命令不识今包布局，去重定向复验同败，故以今编译器经豫构成二级，其后循规定命令而成。旧 yy 同有此碍，新 yy3_bs 则过。性能对照用显式上下文，不以其物与异上下文之原生三级强比。

前验之参数、异步子进程、普通 WASI 与无宿主拒执行皆过；故障原录仍存，非谓今尚败。新 C 路径语法检查与 diff 检查亦过。今 Wasm 编译器可自举，然 clang、wasm-ld 仍在原生宿主，非全工具链皆迁，亦非 WIT 已成。

第四代 Wasm 全类型检查五百零八步皆过。两新增常例以普通 Wasmtime 行之，未启桥接，得 500500 与 42；验后复桥接运行时归档。
