# 网页汇编编译宿主

本工具用豫言提供入口，经 C API 嵌入 Wasmtime，向 WASI P1 核心模块提供 `yuyan:build-host/v1.call`。它是为编译器自举准备的显式宿主扩展，不是 WASI 0.3 标准接口，也不是 Component Model WIT 绑定。

该宿主允许程序启动原生进程、继承环境并读写当前工作目录，因此只加载可信构建程序。宿主原样传递参数向量，不使用 shell 拼接；执行能力由选择本宿主显式授予。

准备[官方 Wasmtime 48.0.1 C API](https://github.com/bytecodealliance/wasmtime/releases/tag/v48.0.1) 到仓库根的 `yy_wasmtime_c_api`，包含 `include/wasmtime.h` 和 `lib/libwasmtime.a`。运行 `make 网页汇编宿主` 构建。可用 `网页汇编宿主编译器` 指定配套的原生豫言编译器。本次验证平台是 macOS arm64；其他平台的链接依赖尚未验证。

```sh
make 网页汇编宿主
YY_WASM_HOST_BRIDGE=1 ./yy编译器 程序。豫 --package-context 包上下文 --target=wasm -o yy程序.wasm
./yy网页汇编宿主 yy程序.wasm 参数
./yy网页汇编宿主 --预编译 yy程序.wasm yy程序.cwasm
./yy网页汇编宿主 --运行预编译 yy程序.cwasm 参数
```

只有显式的 `--运行预编译` 会反序列化本机码；输入必须来自可信的 Wasmtime 预编译。普通模块不使用此路径。切换桥接选项后重新链接产物；该选项改变运行时导入，不改变 LLVM 模块代码。宿主在启动原生编译工具时继承桥接选项，使下一代仍链接桥接运行时。

协议只有五个 i32 输入和一个 i32 返回，内存地址是 guest 偏移。启动请求为小端字符串计数及每项的长度、UTF-8 字节。操作涵盖启动、等待、结果长度、分段读取、释放、CPU 数、保存包上下文和等待进程事件。不存在 guest 指针直接转成 host 指针的路径。

每实例有独立、单调递增的句柄，最多保留 4096 项；输出最多每流 256 MiB。捕获输出使用已 unlink 的临时文件，避免管道塞满死锁；不适合作为需要实时流式输出的通用进程服务。等待阶段以 1 ms 间隔检查子进程；当前多路等待只支持本宿主进程的可读完成事件，不支持任意 guest 文件描述符或网络套接字。进程回收后关闭临时文件，实例退出时终止并回收尚未完成的直属子进程。

桥接模式默认豫言栈 512 MiB、初始堆 64 MiB、单堆上限 512 MiB、线性内存上限 4 GiB。原来普通 WASI 的 4 MiB 初始堆和 64 MiB 单堆上限不足以运行编译器；普通模式的预算没有改变。Wasmtime C API 和 CLI 可能使用不同的编译配置，AOT 应使用本工具的 `--预编译` 生成，不承诺其他配置生成的 cwasm 可以加载。

包上下文复用原生实现的真实文件锁，不使用空锁桩。编译器派生自己的 Wasm worker 时，宿主自动再次调用本工具；原生 clang 等程序仍直接执行。工作目录以同名绝对路径授予 guest，保证传给原生工具的构建路径一致。

当前豫构默认提供的原生包清单不能用于 Wasm。编译本仓库编译器时，其构建基础扩展已经由本桥接覆盖，可以显式清空该清单：

```sh
YY_WASM_HOST_BRIDGE=1 ./yy豫构 构建 豫言编译器 \
  --编译器 ./yy3_bs --输出 yy宿主编译器.wasm -j 4 \
  -- --target=wasm --native-link-inputs ''
./yy网页汇编宿主 --预编译 yy宿主编译器.wasm yy宿主编译器.cwasm
```

这不是通用第三方 C 包迁移功能；其它包需要各自的 Wasm 实现，未实现符号仍须链接失败。自举尝试与已知阻断见《验证.汉语.md》。
