# 浏览器编译资源

从仓库根运行。先安装 `应用/豫言体验` 的 npm 依赖，再用当前原生编译器生成完整编译器的 WasmGC WAT。构建本工具后执行：

```sh
./yy豫构 构建 浏览器编译资源 --编译器 ./yy3_bs --输出 yy浏览器编译资源
./yy浏览器编译资源 yy浏览器种子.wasm.wat
```

工具用豫言打包标准库源码与固定内存路径；JavaScript 适配层调用 Binaryen 组装、优化发布编译器并生成 gzip 资源和校验清单。不包含原生进程能力、工作区绝对路径或 AI 密钥。产物写入应用的 `网页/编译/资源`，由静态资源发布，不进入 Git。

必须使用包含合流尾位置修复的编译器生成 WAT。发布前运行应用测试；测试在 V8 默认栈下编译并执行真实页面示例。
