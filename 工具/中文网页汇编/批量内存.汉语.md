# 批量内存指令执行

标准二进制加载和参考执行器已接通 `memory.init`、`data.drop`、`memory.copy`、`memory.fill`。初始化和丢弃使用所属实例的数据状态，复制和填充使用所属实例的线性内存。当前仍限单内存，不支持跨不同内存复制。

验证器检查操作数、内存索引和数据索引。二进制包含数据索引指令时，必须有相符的数据计数段；缺失或计数不符均拒绝。旧函数核心入口不会绕过存储上下文验证接受这些指令。

操作会先检查完整范围，再修改目标。重叠复制保留原始源内容，填充值取低八位。重复丢弃合法，丢弃后数据段为空，零长度初始化仍须满足源和目标边界。其他实例的数据状态不受影响。

2026-09-22：原生与 WasmGC 目标的批量测试均通过。同一生成模块在 V8 执行初始化、重叠复制、填充、丢弃、零长度边界及越界负例，结果一致。类型检查与标量内存回归通过。

```sh
./yy3_bs 库/编译器核心/网页汇编核心/批量内存。测试。豫 -o yy批量内存测试 -j 1
./yy批量内存测试
./yy3_bs 库/编译器核心/网页汇编核心/批量内存。测试。豫 --target=wasmgc -o yy批量内存测试.wasm -j 1
./yy网页汇编宿主 yy批量内存测试.wasm
```

这些结果来自参考执行器。裸机内存后端、默认用户态 Shell、调度和完整 WasmGC 仍未完成。批量操作计为一条指令，执行预算不等于逐字节的时间预算。
