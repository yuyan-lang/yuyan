# 检查标准模块类型段

命令 `yy中文网页汇编 检查类型段 模块.wasm` 读取标准核心模块，检查头部、段次序、重复段及长度边界，读取自定义段名称，并对类型段执行作用域、递归身份与继承方差检查。非类型段的内容仅按边界跳过，成功信息明确指出其余模块内容尚未验证。

实现位于 `库/编译器核心/网页汇编核心/模块类型检查。豫`，已接入现有命令入口。本接口不会运行输入，也不会授予宿主权限。不存在类型段时得到空类型上下文；类型段内多余或缺失字节均拒绝，不从后续段借字节完成读取。

类型检查、构建及 12 个模块边界测试通过。对三个工作区现有 WasmGC 产物运行命令：`yy优化器三代.wasm` 含 42 型，`yy栈向量排序.wasm` 含 51 型，`yy栈默认回归GC重复索引边界.wasm` 含 37 型，均通过。三个文件亦经 Node 标准引擎验证，散列记录在裸机验证记录中；本轮没有重新编译这些输入。

此结果证明完整类型处理链能够处理实际产物，不证明裸机执行器支持其指令、宿主接口或垃圾回收。默认启动镜像未改变。
