# 结构控制：表示、验证与参考执行

中文整数 IR 增加块、循环、条件、否则、结束、跳转、条件跳转、返回和陷阱，直接对应标准 Wasm 控制指令。指令以平坦序列保存，嵌套由开始／结束标记确定。函数最外层结束由二进制写出器补齐，不写入 IR 指令列。

块、循环、条件各带一个结果数量，当前只支持零或一个三十二位整数结果，没有块参数；二进制块类型因此是空类型或 `i32`。跳转参数是标签深度，零表示当前控制帧，最外层函数也有标签。循环跳转使用入口参数数量（当前为零），其他跳转使用目标结果数量。类型索引形式的块类型、多值块参数和 `br_table` 尚未支持，读取时明确拒绝。

例如，下面的指令片段返回四十二：

```text
「《《整数三十二位常量》》」【「一」】，
「《《条件》》」【「一」】，
「《《整数三十二位常量》》」【「四二」】，
「《《否则》》」【】，
「《《整数三十二位常量》》」【「七」】，
「《《结束》》」【】
```

验证器分别追踪操作数高度和控制帧。每帧保存种类、入口高度、结果数量、不可达状态；内层块不能消费外层栈值。无条件跳转、返回和陷阱之后允许栈多态，但仍检查局部／函数／标签索引，仍拒绝剩余具体值与块结果不符的程序。进入新块或 `else` 重置其不可达状态。当前限制最多一千零二十四层控制嵌套，属于实现资源上限。

豫言参考执行器与实例装配器现已接通结构控制。运行帧保存块入口栈、循环入口和块后指令；跳转保留目标结果并恢复目标入口栈，循环回边复用同一帧，以尾调用继续。每条实际执行的指令扣减共享预算，无限循环会以预算耗尽中止。未选择的分支不执行，返回及函数标签跳转支持原有多结果签名。

ARM64 与 AMD64 裸机后端现已接通这些控制指令，并通过用户态实际执行验证，详[双架构用户态结构控制](../豫言裸机/结构控制.汉语.md)。参考执行预算尚不适用于裸机提前编译代码，定时抢占仍待实现。

## 验证

2026-09-22：八项合法模块的中文／二进制往返，以及十二项非法结构拒绝，在原生和 WasmGC 测试目标均通过。V8 实际执行八项合法模块，核对七项返回值和一项陷阱。另以独立字节构造非法标准模块核对拒绝行为；其中块结果数量超出当前子集的拒绝属于实现限制，不能当成标准禁止多值块的证据。

```sh
./yy3_bs 库/编译器核心/网页汇编核心/结构控制。测试。豫 -o yy结构控制测试 -j 1
./yy结构控制测试
./yy3_bs 库/编译器核心/网页汇编核心/结构控制。测试。豫 --target=wasmgc -o yy结构控制测试.wasm -j 1
./yy网页汇编宿主 yy结构控制测试.wasm
```

生成的 `yy结构控制0.wasm` 至 `yy结构控制7.wasm` 是可交给标准引擎执行的独立模块。类型检查与已有整数核心回归通过。此次尚不证明客体系统能够执行循环或运行交互 Shell。

依据：[Wasm 验证算法](https://webassembly.github.io/spec/core/appendix/algorithm.html)。

双架构十六项已有裸机回归通过，日志目录 `/tmp/yy裸机验证.RwC6oq`；此回归仅覆盖原有直线程序，该项为此前回归记录，后续裸机控制执行结果见上述专篇。

## 执行器验证

一万次累加得到 `50005000`，与 V8 独立执行同一模块一致。分支跳过陷阱、无条件与条件跳转、跨层丢弃中间值、条件跳转未发生时保留结果、函数返回和无限循环预算测试，在原生与 Wasm 版参考执行器均通过。循环通过尾调用执行，没有用宿主递归表示每次迭代。运行时仍是整数子集，尚无线性内存和 WasmGC。

跨模块重导出调用同一万次循环，以及 `return`／函数标签跳转的双结果顺序也已通过原生和 Wasm 两种测试。命令行可直接执行 `./yy中文网页汇编 执行 yy结构控制0.wasm 值`，结果为 `42`。已有整数核心与实例装配回归通过。
