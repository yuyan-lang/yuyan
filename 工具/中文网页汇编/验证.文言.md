# 中文网页汇编整数核心之验

二〇二六年九月二十一日，于 macOS ARM64 验之。今惟整数子集，不以此许完整回收引擎、裸机或性能目标已成。

原生测试及同程序经 Wasm 后之测试皆过。中文、二进制可往返，验手书与注、常量之界、回绕、多返、局部、宿主调用、预算、递归、恶段、含零之名及万令之列。

以标准引擎验六导出。外部模块独立以字节构之，导入豫言求和而导出翻倍；豫言复调用之，成往返之链。千组输入皆合预期。以宿主桥装配，不冒循环实例化已成。外部模块经中文重编后仍可调用。

求和模块四十七字节，各易零及二百五十五，共九十四例；新读取器许十一、拒八十三，所许皆过标准验证。此有限差分，非完备之证。失败不覆既有输出。

三阶段自举毕，第三、第四代同字节，原入口类型亦过。散列、命令详同名汉语稿。节点宿主尚缺单字节串原语，整套 Wasm 测试用现有 Wasmtime 宿主而过；所生成整数模块则可行于 V8。余类型、控制、内存、回收、装配及机器后端待续，不言已去 LLVM/libc。
