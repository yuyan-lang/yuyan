# 模块全局状态

后续已接入双架构裸机后端，详[裸机全局状态](../豫言裸机/全局状态.汉语.md)。以下保留最初参考执行阶段的验证范围。

新增状态模块层，在既有函数、内存、数据声明之外附加自有三十二位全局变量，记录可变性和常量初值。标准二进制支持全局段及 `global.get`、`global.set`。验证器检查初值范围、索引、操作数栈和只读写入；没有全局上下文的旧模块入口明确拒绝这些指令。

每次装配创建独立的全局引用，函数调用期间更新会保留。跨模块导入函数捕获提供者实例，因此调用者的同号全局不会取代提供者状态。全局操作与线性内存、数据段共用同一个实例执行接口。

命令行的“执行”和“装配执行”已接入状态模块读取与装配。原来的无全局模块仍可使用这些入口。中文文本入口目前仍是函数核心格式，没有加入完整状态模块的文本声明。

```sh
./yy3_bs 库/编译器核心/网页汇编核心/状态模块。测试。豫 -o yy全局状态测试 -j 1
./yy全局状态测试
./yy3_bs 库/编译器核心/网页汇编核心/状态模块。测试。豫 --target=wasmgc -o yy全局状态测试.wasm -j 1
./yy网页汇编宿主 yy全局状态测试.wasm
./yy3_bs 工具/中文网页汇编/入口。豫 -o yy中文网页汇编 -j 1
./yy中文网页汇编 执行 yy全局状态.wasm 增
./yy中文网页汇编 装配执行 提供者 yy全局状态.wasm 包装 yy全局包装.wasm 调用 包装 算
```

最后两个命令分别输出 `11`、`1011`。2026-09-22，持续更新、独立实例、只读值、跨模块归属、与内存共存及二进制往返已在原生参考执行器和 V8 中通过。状态模块、二进制入口及命令行入口类型检查通过。旧内存模块的命令行执行也通过。

既有九十八项双架构 QEMU 回归全部通过，产物目录为 `/tmp/yy裸机验证.sOqjsT`。**全局变量尚未接入裸机后端，此回归不代表其裸机执行已通过。** 当前只支持自有三十二位全局及整数常量初值，不支持全局导入导出、引用全局和其他初始化表达式。用户态执行器的裸机集成、完整 WasmGC、调度、文件系统及默认 Shell 仍未完成。

补充验证：同源码的 WasmGC 参考执行测试通过；原生与网页目标均拒绝非法可变标志、错误数值类型、错误初始化形式和段内尾随字节四类畸形段。散列及验收范围见 `全局状态验证记录.json`。
