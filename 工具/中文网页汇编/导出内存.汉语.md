# 导出内存的实例绑定

新增 `网页外部实例`，将模块声明与装配后的状态绑定。`装配网页外部实例` 创建绑定；`调用外部实例` 调用导出函数；`外部实例内存` 按导出名返回该实例真正持有的线性内存。调用者无需分别传递模块和实例，接口也不复制内存或重新实例化模块。

返回的对象可供宿主使用已有的有界读写和增长接口。重复取得同一导出会访问相同状态；增长后旧的引用仍能观察新页数和新增字节。函数名误作内存名、或名称不存在时明确报错。

2026-09-22，独立 C 夹具增加“取字节”和“置字节”导出。豫言原生参考执行器与同源码的 WasmGC 参考执行器均通过以下验证，V8 对同一标准模块得到相同结果：

- 宿主写入后，客体导出函数读到相同字节。
- 客体导出函数写入后，宿主通过再次取得的导出内存读到更新。
- 另一个实例的同址字节保持为零。
- 宿主增长一页后，客体可读取新增的零字节并写入，旧内存引用能读到该更新。
- 另一个实例的内存仍为两页。

这些测试还覆盖错误导出类别与不存在名称的拒绝，类型检查通过。运行 `库/编译器核心/网页汇编核心/外部模块。测试。豫` 可复验；独立编译夹具的完整流程见[外部模块验证](../豫言裸机/外部模块.汉语.md)。

本接口目前属于宿主参考执行器。它没有新增内存导入、跨进程共享内存或内核 IPC，也不意味着客体内动态加载已完成；这些仍属于完整 OS 目标的后续工作。
