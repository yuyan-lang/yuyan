# 豫言并行编译

编译器受 `--parallel`，则以豫言之任务图调度诸工作进程，不假 Python。其书置于 `工具/豫构`，以备独立构建工具取用。

`-j N`、`--num-cpu N` 皆限在途进程之数；未言其数，则取在线之核数。`--very-parallel`、`--yuyan-parallel` 亦行此法。

一文件之事，次为察依赖、解析、类型检查并擦除、跨模块优化、闭包转换、求值正则变换、代码生成。解析至跨模块优化，必候所依文件之同阶段皆毕；其后唯候自身前阶段。察得新依赖，则增文件与任务。终以有序候选反复拓扑扫描，定链接之序，不以进程毕时为序。

诸工作仍受 `--mode=worker`，缓存之约如故。唯检查类型者，止于检查并擦除。依赖以换行分，参数各为一串，故路径有空格亦可。事败或启事有误，则止启新事，候在途者毕而收之，返非零码；所待成环或缺失，则报未毕之事。

`yy_parallel_log.txt` 记进程号、退出码及两路输出，`yy_parallel_deps.txt` 记文件依赖。任务图毕与链接毕时存之；中途骤止，未必得存。诸构建不可同时写同一缓存与日志。

## 异步子进程

`标准库/操作系统/异步子进程` 有 `异步获取输出`，受程序名与参数列，即启进程，返 `异步任务于子进程结果`。结果四者：进程号、退出码、标准输出、标准错误也。同一任务，可再候之。

启而不成，进程号为零，退出码为 127，并告系统错误。信号致止，则码为 128 加信号号；收集或回收有误，则为 125。已启之任务，调用者当候之，以释记录与描述符。此术收文本，尚无取消、超时之法。

豫言之调度仍在一线程。每子进程别设原生收集线程，排空两管，待 `waitpid` 毕，以通知管唤豫言任务。别线程唯治原生存储，不涉豫言堆；多核之用，在诸工作进程。

## 自举与验

旧 `yy_bs_stable` 尚含 Python 调度入口，故首级串行，后级并行：

```sh
./yy_bs_stable 豫言编译器/入口。豫 -o yy2_bs
./yy2_bs 豫言编译器/入口。豫 -o yy3_bs --parallel
./yy3_bs 豫言编译器/入口。豫 -o yy4_bs --parallel
cmp yy3_bs yy4_bs
```

`make 连续自举` 从此序。验书在 `测试/标准库/异步/子进程-1。豫` 与 `工具/豫构/调度器。测试。豫`，验众输出、信号、错误码、再候、回收、并发之限、依赖之序、动态增事及败后收拢。验子进程，可先行 `ulimit -n 64`。
