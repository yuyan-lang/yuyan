# 源码树浏览器

生成可浏览的源码静态网站。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为可执行文件类型，不可被其他包依赖；包内模块仍可互相引用。类型典中的入口和文件名见包配置，程序产物为 `yy源码树浏览器`。

## 使用

在仓库根目录运行：

```sh
./yy豫构 检查 源码树浏览器
./yy豫构 构建 源码树浏览器
```

依赖、原生源文件及说明路径以 [包配置](源码树浏览器。包。豫) 为准。构建不会自动运行程序；有发布或服务副作用的工具应先阅读其入口源码。

## 维护

发布工具使用 `./yy源码树浏览器 构建源码 源码目录 输出目录`：只扫描指定源码目录，界面资源从当前工作目录读取。语法解析失败时保留转义后的纯文本阅读。发布流程传入已经按包边界过滤的暂存副本，不扫描整棵依赖树。原有 `构建 [输出目录]` 命令保持兼容。

修改接口时更新本说明；修改包身份、版本或构建组成时同步更新包配置。说明文件不参与模块导入。
