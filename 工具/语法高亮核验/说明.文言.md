# 语法高亮核验

遍仓中豫源，以编器析其辞，定标记于原文；复以 TextMate 与 Oniguruma 分色，逐字校其可比之域。析败者别列，不阻余篇。

先以 `./yy3_bs 工具/语法高亮核验/入口。豫 -o yy语法高亮核验 --parallel` 成器，后行 `./yy语法高亮核验`。可授仓根，不授则取今径。候选出于 Git 工作树，取 `。豫`、`.yuyan`、`.yyon`，略 `_v0` 及所忽略之篇。文件表写 `yy语法高亮文件表.txt`，导入所据写 `yy语法高亮上下文.txt`，差异写 `yy语法高亮差异.json`；既析之果按源、器、上下文摘要藏于 `.yybuild/语法高亮核验/`。逐篇别起豫器，五秒不成则记未覆，仍校余篇；欲宽限可设 `YY_GRAMMAR_TIMEOUT_MS=20000`。

编器偏移按 Unicode 字，TextMate 按 UTF-16 码元，校前须转换。取 scope 所属之色类，不取随主题迁易之 RGB。惟校编器已标、两类可对应之字；无标之域不称已验。编器谓括号、方括号、逗号为常术，TextMate 谓之标点，校时同归标点；跨行之换行不妄报。每异具路径、行列、原文、二类及 scope；差异为待审之证，非独断编器必真。详见同名 `.汉语.md`。
