# 源码排版规则

本文记录 `yy格式化` 的排版约定。修改格式化行为时，应同步更新本文、[文言版本](源码排版规则.文言.md)与测试。

## 行宽与缩进

- 每层缩进使用两个 ASCII 空格。
- 默认行宽为 120 格；ASCII 字符计一格，中文及其他非 ASCII 字符计两格。
- 标识符、字符串、注释等不可拆分的内容可以适当超宽，不在内部断开。
- 限制深层表达式的缩进，避免文本不断向右移动。

## 括号与续行

- 左括号紧跟首项，避免单独留下 `（`；首项为独行注释时除外。
- `于（` 可以留在同一行。需要断行时，在 `于` 之前断开，不拆开 `于` 与 `（`。
- 同一调用的续项比首项多缩进一层，不沿用原文件中偶然过深的缩进。

## 分支与条件

同一个 `鉴` 的 `有`、`或有` 分支对齐，分支体缩进一层。分支头和较短的分支体可以共用一行。

括号分支体若放不进 `则` 或 `否则` 后，但能放进下一行，则整体移到下一层：

```yuyan
或有「式」则
  （「计算」于「式」）
```

如果下一行仍然放不下，就按括号与调用结构分行，不额外增加无意义的缩进。短条件式可以单行书写；多行条件式的 `若`、`则`、`否则` 对齐，后两者独占一行，分支正文各缩进一层。

## 绑定、类型与顺序

- 短的 `虑…者…而…` 可以单行书写。
- 多行绑定中，`者` 后的值缩进一层；结束绑定的 `而` 与 `虑` 对齐，后续正文保持同层。
- 连续绑定保持相同层级，不形成阶梯状缩进。
- `递归虑` 是复合关键字，不从中间断开。
- 函数类型中的 `化…而` 尽量连续排列；换行后的 `化` 缩进一层。
- 类型声明之后的所有构造器统一缩进一层。
- 以分号连接的同级表达式保持同一缩进。

## 注释与稳定性

前置注释跟随其后的声明或表达式，后置注释跟随其前面的表达式；顶层声明之间的前置注释属于下一条声明。

写回之前必须完成所有输入文件的带注释语法解析；任一文件解析失败，就不写回任何文件。格式化必须幂等：对同一文件再次格式化，字节内容不变。
