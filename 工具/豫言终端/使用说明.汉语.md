# 豫言终端

本地终端统一提供编译、包管理和离线文档工具。帮助可用 `help 包`，单次执行可用 `./yysh -c '包 列表'`。拼音只用于补全，执行使用完整中文名称。

## 构建与启动

```console
./yy豫构 构建 豫言终端 --编译器 ./yy4_bs --输出 yysh
./yysh
./yysh help
```

## 智能补全

| 输入中的当前词 | 候选及填入结果 |
| --- | --- |
| `工具 构建 wd` | 填入 `工具 构建 文档网站生成器 ` |
| `编译 yyzd` | 填入 `编译 豫言终端 ` |
| `类型检查 bz` | 填入 `类型检查 标准库 ` |
| `包 检查 bz` | 填入 `包 检查 标准库 ` |

Tab 显示或切换候选，Ctrl-E 或右方向键填入选中项；Enter 始终执行当前文字。空行按 Tab 列主命令，命令后的空格处按 Tab 列出该位置的候选。最多显示五项，超过五项分页。路径参数保留原有中文文件、目录、相对路径、绝对路径和 `~/` 路径补全。普通外部程序同样须按正式名称或路径执行。

包名候选出现在 `编译`、`类型检查`、`包 检查` 后，复用豫构的包发现规则，跳过符号链接和 `*_v0` 目录。仓库子目录自动向上定位项目；`--项目 路径` 可改变发现范围。同一行内缓存包候选，下一次输入命令时刷新。包名只填入，不转换已输入的参数；同名包仍按豫构规则用 `--所有者` 区分。

## 常用操作

```console
./yysh 工具 构建
./yysh 编译 豫言终端 --输出 yysh
./yysh 类型检查 豫言终端
./yysh 文档 生成
```

## 工具与项目

工具默认位于 `yysh` 旁边，命名为 `yy工具名`。`工具 构建` 用豫构构建整套常用工具，先写临时产物，成功再替换。编译器优先取同目录 `yy编译器`，否则取 `yy4_bs`。`YYSH_TOOL_DIR` 可指定工具目录，`YYSH_COMPILER` 可指定编译器；相对环境路径按启动目录解释。

命令前可加 `--项目 路径`、`--预演`。除网页服务外，管理命令的相对路径按项目根解释。预演列出程序、独立参数和工作目录，不执行子工具。编译命令的 `--` 后按原顺序和参数边界传给编译器。

## 验证

```console
./yy豫构 构建 豫言终端 终端。测试 --输出 yy终端测试
./yy终端测试
./yy豫构 构建 豫言终端 管理。测试 --输出 yy终端管理测试
./yy终端管理测试 ./yysh
```

测试覆盖命令及包名补全、拒绝拼音直接执行、参数边界、工作目录、预演及本地工具失败退出。

官网、在线体验和云端包管理服务已迁入相邻的 `yuyan-cloud` 仓库。本仓库保留编译器、标准库、豫构、本地批量发布及离线文档工具。网站运营命令由云仓库提供。
