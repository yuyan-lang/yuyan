# 豫言终端

豫言终端用豫言编写，统一提供编译、文档和网站工具。拼音仅用于智能补全：先选择候选并填入正式名称，再按 Enter 执行。命令行本身不把拼音、首字母或前缀翻译成命令、工具名或包名。

## 构建与启动

```console
./yy豫构 构建 豫言终端 --编译器 ./yy4_bs --输出 yysh
./yysh
./yysh help
./yysh help 网站
./yysh -c '网站 检查'
```

`help`、`帮助`、`--help` 列出所有已接入操作，每条一行。`help 网站 上传` 查看具体用法。帮助不要求工具已安装。保留明确的英文别名 `cd`、`pwd`、`clear`、`exit`；不接受 `qiehuan`、`mulu` 等拼音别名。

## 智能补全

| 输入中的当前词 | 候选及填入结果 |
| --- | --- |
| `wz` | 选择“网站”，填入 `网站 ` |
| `网站 yl` | 选择“预览”，填入 `网站 预览 ` |
| `工具 构建 wd` | 填入 `工具 构建 文档网站生成器 ` |
| `编译 yyzd` | 填入 `编译 豫言终端 ` |
| `类型检查 bz` | 填入 `类型检查 标准库 ` |
| `包 检查 bz` | 填入 `包 检查 标准库 ` |

主命令、子命令、工具名和包名均加入候选，使用中文、无调全拼、首字母及模糊子序列筛选。已完成的前置词应为正式名称，例如先把 `wz` 补全成“网站”，再输入 `yl`。直接按 Enter 执行 `wz yl` 会失败，不会自动翻译。

Tab 显示或切换候选，Ctrl-E 或右方向键填入选中项；Enter 始终执行当前文字。空行按 Tab 列主命令，命令后的空格处按 Tab 列出该位置的候选。最多显示五项，超过五项分页。路径参数保留原有中文文件、目录、相对路径、绝对路径和 `~/` 路径补全。普通外部程序同样须按正式名称或路径执行。

包名候选出现在 `编译`、`类型检查`、`包 检查` 后，复用豫构的包发现规则，跳过符号链接和 `*_v0` 目录。仓库子目录自动向上定位项目；`--项目 路径` 可改变发现范围。同一行内缓存包候选，下一次输入命令时刷新。包名只填入，不转换已输入的参数；同名包仍按豫构规则用 `--所有者` 区分。

## 常用操作

```console
./yysh 工具 构建
./yysh 编译 豫言终端 --输出 yysh
./yysh 类型检查 豫言终端
./yysh 文档 生成
./yysh 网站 构建
./yysh 网站 预览 8000
./yysh 网站 上传
./yysh --预演 网站 发布
```

已接入包发现与检查、编译文件、格式化、接口文档、源码网站、教程资料、官网构建检查上传、本地网页服务及自举包导出发布。`网站 上传` 检查并上传现有产物，期间会复制本机条款；`网站 发布` 先构建再上传，失败即停。`网站 检查` 只检查必要文件，不替代内容预览。自举包发布沿用原工具的 yybs 分支及远端一致性校验。

`网站 预览 [端口]` 服务 `dist/网站`；`网页服务 <目录> [端口]` 服务当前目录下的指定目录。默认端口 8000，监听 `127.0.0.1`，前台运行，Ctrl-C 停止。正常结束后还原工作目录。尚无后台任务、管道、重定向、shell 脚本或网页操作台。

## 工具与项目

工具默认位于 `yysh` 旁边，命名为 `yy工具名`。`工具 构建` 用豫构构建整套常用工具，先写临时产物，成功再替换。编译器优先取同目录 `yy编译器`，否则取 `yy4_bs`。`YYSH_TOOL_DIR` 可指定工具目录，`YYSH_COMPILER` 可指定编译器；相对环境路径按启动目录解释。

命令前可加 `--项目 路径`、`--预演`。除网页服务外，管理命令的相对路径按项目根解释。预演列出程序、独立参数和工作目录，不执行子工具。编译命令的 `--` 后按原顺序和参数边界传给编译器。

`状态` 显示工具路径；`环境 检查` 检查文件和依赖是否存在，不自动安装或登录。现有网站构建仍需稳定双种子、原生构建工具、Node.js/npm、Ruby/Jekyll、Wrangler 与本机条款配置，详见网站使用说明。
