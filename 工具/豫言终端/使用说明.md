# 豫言终端

豫言终端是一个用豫言编写的交互式命令终端。它提供类似 fish 的友好默认行为：无须学习一套脚本语法即可启动程序，不会在命令名有歧义时暗自猜测，并将中文程序名作为一等公民。

## 构建

```console
./yy_bs_stable 工具/豫言终端/入口。豫 -o yysh
```

## 使用

```console
./yysh
./yysh -c 'mulu'
```

命令名的解析顺序如下：

1. 当前目录中的精确文件名。
2. `PATH` 中的精确文件名。
3. 无调全拼或拼音首字母的完整匹配。
4. 无调全拼或拼音首字母的唯一前缀匹配。

例如，当可执行文件名为 `简易网页服务器` 时，可使用 `jianyiwangyefuwuqi` 或 `jywyfwq` 启动。若前缀匹配到多个程序，终端会列出候选并拒绝执行。

在交互终端中，输入命令名或任意参数时都会实时显示至多五个匹配项。命令位置会把当前目录中的所有非 ASCII 文件和文件夹以及 `PATH` 中的非 ASCII 可执行程序作为候选；参数位置补全当前目录中的非 ASCII 文件和文件夹。纯 ASCII 名称不会出现在候选区，但仍然可以直接输入和执行。所有命令使用相同的文件与目录候选规则，`cd`、`切换` 和 `qiehuan` 也不会过滤普通文件。带 `/` 的相对路径、绝对路径和 `~/` 路径可以逐段补全；空格后按 `Tab` 会列出当前目录候选。

匹配采用原名、无调全拼和拼音首字母的模糊子序列。例如 `cge` 可以匹配 `藏书阁`，`abcxyz` 可以匹配 `abc你好xyz`，查询没有写出的中文或拉丁字符都可以跳过。当前项以反色标出；按 `Tab` 显示候选或移动选中项，不改变候选顺序，超过五项时按页继续浏览。路径以 `/` 结尾时会列出该目录内全部符合规则的子项。按 `Ctrl-E` 或右方向键将当前候选填入命令行；`Enter` 始终立即执行当前命令，不参与补全。

在命令位置执行一个文件夹名等同于 `cd 文件夹名`。当前目录中的可执行文件可以直接按名称运行，不需要添加 `./`。

支持单引号、双引号、反斜杠转义和空引号参数。前台子进程继承标准输入、标准输出与标准错误。

当前版本专注于单个前台命令，尚不实现管道、重定向、后台作业和 shell 脚本语法。
