# 豫言终端

终端总编译、包制与离线文档。`help 包` 可问其法，`./yysh -c '包 列表'` 可一行而行。拼音惟补全，用命须实名。

## 构建与启动

## 智能补全

输入 `b`，候选有“包”，填之乃成 `包 `。继输 `jc`，选“检查”，乃成 `包 检查 `。直行 `b jc` 则不得执行。`工具 构建 wd` 可填文档网站生成器；`编译 yyzd` 可填豫言终端；`类型检查 bz` 与 `包 检查 bz` 可填标准库。

主命、子命、器名、包名，皆入候选；以中文、无调全拼、首字母、模糊子序列筛之。Tab 陈列或择项，Ctrl-E 或右向键填入；Enter 唯行当前之文。空行按 Tab 列主命，命后空格按 Tab 列其位之候选。每页至多五项。文件与目录之路径补全仍存；外器亦唯以实名或路径行之。

编译、类型检查、包检查之后，列发现之包名。循豫构之发现法，不入符号链接及旧版目录。仓库内循父求根，`--项目 路径` 可明定范围；一行之内缓存包名，下命始刷新。不改已输之包名；同名者仍以 `--所有者` 辨之。

## 位置与依赖

诸器默认在 `yysh` 之旁，以 `yy工具名` 名之。构建先成临时之器，再易旧者。编译器先取 `yy编译器`，未备则取 `yy4_bs`。`YYSH_TOOL_DIR` 定器之处，`YYSH_COMPILER` 定编译器；相对环境路径据启动目录。

命前可加 `--项目 路径`、`--预演`。除网页服务外，相对路径据项目根。预演列器、参量与所在，不实执行。编译之 `--` 后悉授编译器，不改其序与界。

## 验证

以豫构构建本包之 `终端。测试` 与 `管理。测试` 两入口，分别输出 `yy终端测试` 与 `yy终端管理测试`。于仓库根行前者，行后者则授 `./yysh` 为参。验命令及包名之补全、拒拼音径行、参数边界、工作目录、预演及败则止。本地之器以豫言替身验之。
