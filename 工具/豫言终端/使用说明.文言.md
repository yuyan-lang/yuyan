# 豫言终端

夫终端者，人机相接之门，命令所出、程序所行之处也。豫言终端，以豫言书成；取 fish 之善以为默。故不习脚本之语法，而可径启程序；命令之名有歧，则弗加臆测；中文程序之名，与诸名同列，无少异焉。

## 构建

欲成其器，于仓库根目录行：

```console
./yy_bs_stable 工具/豫言终端/入口。豫 -o yysh
```

## 使用

既已构成，则以下列之令启之：

```console
./yysh
./yysh -c 'mulu'
```

### 辨名之序

命令之名，其解析有序，凡四：

1. 当前目录中之精确文件名。
2. `PATH` 中之精确文件名。
3. 无调全拼或拼音首字母之完整匹配。
4. 无调全拼或拼音首字母之唯一前缀匹配。

如可执行文件名 `简易网页服务器`，则以 `jianyiwangyefuwuqi` 或 `jywyfwq` 启之。若前缀匹配多个程序，则终端列其候选，拒绝执行，不以臆测代选择。

### 候选之陈

于交互之时，输入命令名或任一参数，皆实时显示匹配项，至多五项。处命令之位，则以当前目录中所有非 ASCII 文件与目录，及 `PATH` 中非 ASCII 可执行程序为候选；处参数之位，则仅补全当前目录中非 ASCII 文件与目录。纯 ASCII 之名，虽不列于候选，仍可径输而执行。凡诸命令，其文件与目录之候选规则皆同；`cd`、`切换`、`qiehuan`，亦不过滤普通文件。带 `/` 之相对路径、绝对路径与 `~/` 路径，皆可逐段补全；空格之后按 `Tab`，则列当前目录之候选。

### 匹配之法

匹配以原名、无调全拼、拼音首字母之模糊子序列求之。如 `cge` 可匹配 `藏书阁`，`abcxyz` 可匹配 `abc你好xyz`；查询未写之中文或拉丁字符，皆可跳过。当前项以反色标出。按 `Tab`，则显示候选或移动选中项，而不改候选之序；候选逾五项，则分页续览。路径以 `/` 结尾，则列该目录内凡合规则之子项。按 `Ctrl-E` 或右方向键，则以当前候选填入命令行；按 `Enter`，则即时执行当前命令，不参与补全。

### 命令之行

于命令之位执行一目录名，等同 `cd 目录名`。当前目录中之可执行文件，可径按其名运行，无须加 `./`。

单引号、双引号、反斜杠转义与空引号参数，皆可用。前台子进程，继承标准输入、标准输出与标准错误。
