# 豫言终端运营平台设计

本文记录完整设计目标。第一期统一入口、帮助、拼音补全与现有工具适配已实现，实际命令及参数以《使用说明.汉语.md》和 `yysh help` 为准；下列清单仍包含后续阶段目标。以现有 `yysh` 为入口，用豫言整合开发、文档、网站和发布工具；交互模式和单次命令共用同一套执行逻辑。首版面向本地仓库维护者，后续可增加本地网页操作台。

## 使用方式

启动 `./yysh` 后输入中文命令，继续支持中文全名、拼音和首字母补全。新增 `./yysh 网站 构建` 这类直接调用，保留 `./yysh -c '网站 构建'`。帮助同时接受 `help`、`帮助`、`--help`，其余新增命令以中文为准。

`help` 显示全部常用命令，每个完整操作一行，不把多个操作挤在一行。`help 网站` 按组筛选，`help 网站 上传` 给出参数、默认路径、实例和执行影响。帮助不启动构建、不扫描远端、不要求工具已安装。未就绪的命令仍显示，并标注缺失依赖；尚未实现的命令只出现在设计文档中，不冒充可执行功能。

以下为目标帮助内容；尖括号为必填参数，方括号为可选参数。

```text
帮助 [命令…]                       查看常用命令或某条命令的详细用法
状态                               查看项目、工具版本、产物及运行中的任务
环境 检查                          检查编译器、工具和网站构建依赖
工具 构建 [工具名]                 构建指定工具或整套工具
包 列表                            列出当前可发现的豫言包
包 检查 <包名>                     检查包配置和依赖
编译 <包名> [--输出 路径]          按包配置编译程序
编译文件 <路径> [--输出 路径]      按源文件所属包编译程序
类型检查 <包名>                    只运行类型检查
运行 <包名> [-- 程序参数…]        编译成功后运行程序
测试 <包名>                        执行该包登记的测试入口
格式化 <文件>                      格式化指定源码文件
文档 生成 [入口] [--输出 目录]    生成接口文档网站
源码 生成 [--输出 目录]            生成源码浏览网站
资料 生成                          从双语文档生成教程与指南
网站 构建                          构建官网、文档、源码页并检查产物
网站 检查                          检查已有网站产物
网站 预览 [--端口 8000]            在本机预览已构建的网站
网页服务 <目录> [--端口 8000]      在本机提供指定目录的静态网页
网站 上传                          检查并上传现有网站产物
网站 发布                          依次构建、检查并上传网站
自举包 导出 <目录>                 导出编译器与豫构双种子包
自举包 发布                        验证并发布连续自举包
任务 列表                          查看运行中及最近结束的任务
任务 日志 <编号>                   查看指定任务的输出
任务 停止 <编号>                   停止本终端启动的指定任务
切换 [目录]                        切换当前目录，也可用 cd
目录                               显示当前目录，也可用 pwd
清屏                               清空终端显示，也可用 clear
退出 [状态码]                      退出终端，也可用 exit
```

日常最短流程为 `网站 构建` → `网站 预览` → `网站 上传`；自动化可用 `./yysh 网站 发布`。上传只处理已经生成的产物，发布明确包含重新构建。`上传` 单独输入时列出可上传对象，不猜测网站、包或自举包。包上传及试写间部署待其客户端契约整理完成后扩展。

## 现有工具怎样接入

| 统一入口 | 现有实现 | 需要补充 |
| --- | --- | --- |
| 包、编译、类型检查、自举包导出 | `yy豫构` 的发现、检查、构建、文件、类型检查、自举包 | 参数适配及产物路径获取 |
| 文档生成 | 文档网站生成器 | 默认入口和输出目录 |
| 源码生成、资料生成、格式化 | 对应独立工具包 | 明确各工具的输入输出契约 |
| 网站构建、检查、上传 | `yy网站发布 构建/检查/发布` | 将底层“发布”映射为上层“上传” |
| 网站发布 | 串联现有网站构建与上传 | 任务步骤、失败中止和产物记录 |
| 网页服务、网站预览 | 简易网页服务器，以当前目录为服务根、位置参数为端口 | 子进程工作目录、后台生命周期与监听地址控制 |
| 自举包发布 | `yy发布连续自举包 --publish` | 保留已有 yybs 分支和远端一致性校验 |
| 运行、测试、环境、状态、任务 | 部分底层能力可复用 | 新增统一编排与状态管理 |

网站当前仍依赖 Node.js/npm、Ruby/Jekyll、Wrangler 和原生构建工具。整套分发应说明这些依赖，不能宣称一个二进制即可完成所有构建发布。现有网站“检查”只检查必要文件存在，不等于完整链接检查或线上验收。现有上传步骤还会复制本机私有条款，产物记录须在这一步完成之后生成。

## 实现结构

在豫言终端包内增加命令目录、工具适配、项目上下文、任务管理四个模块，均用豫言实现。保留已有命令解析和交互编辑。用一份命令登记表生成分派、帮助及补全；每条记录包含命令路径、别名、摘要、参数、默认值、依赖、执行入口和影响类型，避免帮助与实际参数各自维护。

工具调用使用原生子进程和参数列，不拼接 shell 字符串。执行只接受正式命令名、工具名、包名和明确别名；拼音、首字母和模糊匹配仅用于候选筛选，必须先补全填入再执行。外部程序也只按精确名称或路径执行。包名候选复用豫构的项目包发现规则。编译器附加参数在 `--` 后原样传递，不改变空格、空参数或参数顺序。

向上查找仓库或包配置定位项目，支持 `--项目 路径`；工具路径从分发清单或显式配置取得，不随当前目录任意选用同名可执行文件。启动子工具时使用其约定工作目录，不能为了预览改变交互终端的当前目录。配置、输出目录和日志路径均相对明确的项目根解析。

首版的编译和生成任务前台执行，保留实时输出与退出状态。静态服务可作为受管任务运行；退出终端时默认停止本次启动的服务。任务记录编号、命令参数、工作目录、步骤、起止时间、状态、日志及产物；停止只作用于本工具拥有的进程。并行任务使用豫言异步调度和原生子进程；同一输出目录的构建与上传互斥。

提供 `--预演` 展示实际程序、参数、工作目录、生成路径及上传目的地。网站上传记录最终文件摘要、源码提交和脏状态，成功后记录部署结果；失败保留日志，不自动重复上传。若使用产物新旧校验，需覆盖未提交文件和外部条款，不能只比较 Git 提交号。预览默认限制为本机访问，现有服务器是否支持指定监听地址应在接入时验证并按需扩展。

“打包一份”采用一个分发目录：`yysh`、按系统架构编译的工具、必要资源及版本清单。整套工具统一版本、统一查找路径；编译器可随包提供或明确指定。优先复用独立工具，不把所有生成器源码直接并入终端。仓库开发模式可用 `工具 构建` 更新产物，依赖缺失时给出具体修复命令。

## 分期及验收

第一期实现统一命令登记和一行帮助，接入豫构、文档、源码、资料、格式化、网站构建检查上传及前台预览。暂不显示未实现的测试和任务命令。第二期增加运行与测试适配、受管服务、日志、产物清单和整套分发。第三期按需要增加本地网页操作台，直接调用同一命令登记及任务服务，展示快捷操作、执行日志、产物和部署记录；远程多人管理另行设计身份与权限。

测试包必须登记明确测试入口，不推测任意文件都可执行。网站构建沿用现有验证流程；编译器语义相关修改执行仓库要求的完整自举验证。

验收覆盖：帮助每个命令一行且与登记表一致；中文及拼音补全；交互与单次调用结果一致；带空格路径和 `--` 参数透传；缺少工具时可读报错；任一步失败不继续；预览目录与端口正确；退出和停止不会误杀其他服务。上传适配先使用替身子进程验证参数及失败处理，实际部署另按明确发布请求执行。
