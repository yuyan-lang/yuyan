# AI Gateway

AI Gateway 是豫言编写的命令行工具。它将请求文件原样提交到本机 Ollama 或 OpenAI 兼容端点，边接收边打印模型正文，并把原始请求和响应按 session 保存在当前目录的 `AI会话` 下。

## 用法

在仓库根目录构建：

```sh
./yy3_bs 工具/AI网关/入口。豫 -o yyAI网关 --parallel
```

```text
yyAI网关 发送 <ollama|openai> <session> <请求文件> [主机] [端口]
yyAI网关 列出
yyAI网关 浏览 <session>
yyAI网关 网页 [端口]
```

协议 `ollama` 将请求送至 `/api/chat`，默认端口 `11434`；`openai` 将请求送至 OpenAI 兼容的 `/v1/chat/completions`，默认端口 `1234`。主机均默认为 `127.0.0.1`，也可显式指定。请求文件原样转发，须符合所选端点的 JSON 格式；要实时看到生成过程，请设置 `"stream": true`。每次请求的协议写在 `协议.<时间>.txt` 中，命令结束也会打印协议。

session 只能含英文字母、数字、横线和下划线。发送命令将原请求留在 `请求.<时间>.json`，上游响应正文留在 `响应.<时间>.jsonl`。同一 session 可发送多次；`浏览` 在命令行展示存档。`网页` 启动只监听本机的浏览页面，默认端口 `8765`，页面展示 session 列表、原始请求、响应与协议。

例如，请求文件为 `请求.json` 时，可运行 `./yyAI网关 发送 ollama 示例 请求.json`；随后运行 `./yyAI网关 网页`，在浏览器打开命令所示地址。

本工具以 HTTP/1.0 请求关闭连接后的流式响应。不支持 HTTPS、鉴权或 HTTP 分块传输编码。OpenAI 兼容端点应提供标准 SSE 数据行。
