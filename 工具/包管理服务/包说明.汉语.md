# 包管理服务

## 包阅读页面

`/release/:id` 只展示包信息、说明、依赖摘要、下载和修订历史；`/release/:id/docs` 展示 API 模块目录；`/release/:id/files` 展示该修订的完整文件树。源码文件默认进入对应文档，可切换源码；其他发行材料提供下载。没有生成文档时明确提示，不把无关模块当作该文件文档。

文档与源码在主站 `/release/:id/files?path=source/包内路径&view=docs` 的统一代码浏览器内展示，复用现有浏览器布局、文件树样式、行号和语义配色。右侧开关使用 `view=source` 切换源码，保持当前文件；全部发行文件均进入同一浏览器，二进制或超过 1 MiB 的文件提供下载。门户不再跳转内容域阅读文档，也不使用 iframe。

`GET /api/releases/:id/file?path=存储相对路径` 返回源码字符串、语义标记及结构化文档字段。生成器新增 `模块-N.json`；旧 HTML 只提取名称、类型和说明文本，不作为 HTML 插入主站。客户端只创建受控 DOM 和文本节点，语义标记验证范围与种类后使用既有配色，无效标记退回纯文本。内容域旧阅读地址继续兼容，但上传的任意 HTML 仍不能在登录站点执行。

`GET /api/releases/:id/reading` 返回包内源码与 API 页映射。新文档使用 `接口/模块映射.json`；已有修订缺少映射时，受限读取现有接口页的源码路径标签，最多 256 页，超过限制须重新生成。无接口页的旧修订仍可查看原文档首页。新 ZIP 的 `文档/包信息.json` 提供依赖和说明路径；旧修订缺少此元数据时不猜测依赖，保留包配置入口。

生成仍在发布者本地通过标准工具完成，服务器不执行上传源码或构建脚本。生成器部署在云端也不会自动使第三方输入可信；云端编译执行需另行设计受限工作进程，当前未启用源码直接上传生成。

## 同版本上传修订

包声明版本不变时可上传不同 ZIP。服务器在“所有者、包名、版本”范围内从 1 分配递增的 `revision`（上传序数），每次使用新的发布 ID 和 R2 目录；不删除旧 ZIP、源码、文档或运行材料。完全相同的 ZIP 按 SHA-256 去重复用原 ID/序数，旧 ZIP 重试不成为最新修订。

默认列表仅展示每个包版本的最新修订；市场再按包筛选最近发布的版本。`GET /api/releases/:id` 始终返回该次修订，并给出 `latestId` 和 `historyUrl`。`GET /api/releases/:id/history?offset=0` 按序数倒序分页，每页最多 50 条，返回 `revisions`、`nextOffset`，每条含固定 `downloadUrl`。页面可查看历史及下载旧 ZIP。最新修订登记后立即可见，缺失文件不回退混用旧修订。

上线必须执行 `0007_上传修订.sql`。旧数据保留原 ID，上传序数设为 1；上线迁移和新版容器须协调进行，旧容器不支持新表唯一约束。部署前备份 D1。该迁移不删除 R2 对象，不允许客户端指定序数，也不改变所有者身份验证。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为可执行文件类型，不可被其他包依赖；包内模块仍可互相引用。类型典中的入口和文件名见包配置，程序产物为 `yy包管理服务`。

## 使用

在仓库根目录运行：

```sh
./yy豫构 检查 包管理服务
./yy豫构 构建 包管理服务
```

依赖、原生源文件及说明路径以 [包配置](包管理服务。包。豫) 为准。构建不会自动运行程序；有发布或服务副作用的工具应先阅读其入口源码。

## 维护

修改接口时更新本说明；修改包身份、版本或构建组成时同步更新包配置。说明文件不参与模块导入。
