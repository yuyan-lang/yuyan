# 包府略

外设工役一，以接域名、D1、R2 与容器；内设豫言之服一，以断名、版、令、验、颁之法。工役截内服所叩虚主机之请求，乃代用 D1、R2 之绑定。故内服不直通 D1，亦不以 SQLite 之术问 D1。

器惟一 production 桶。上传者先陈文件之名、印、量；内服验令与旧版，工役乃授同域 PUT 之路。上传者复执令投之，工役先请内服验其记，乃以 R2 绑定流写 `pending/`，不藏 S3 密钥。复请验证或完成。完成之时，内服取实物，验 SHA-256、ZIP、路径、数目与解压总量；善则于同桶复制为 `sha256/` 正式物，再以 D1 批次记版。`pending/` 之物可俟一日生命周期同除。

下载者无须执令。工役先问 D1，继取正式桶之物，以不可变缓存与摘要应之。

包名与版本皆不可阙，文件式为 `<包名>-<版本>.zip`。以末一连字符为界；名可华可夷，版为点分数字。既颁之同名同版，不可覆也。

今支持邮箱密码立户，不发验证信；旧“豫言”用户仍存。令之明文不入源码，D1 惟存其 SHA-256。R2 绑定之权由 Cloudflare 自授，无须 S3 密钥。是以源码可公，而账户凭据、明令、`.dev.vars` 皆不可公。

云端所须创者：D1 `yuyan-package-registry` 与 R2 production 桶 `yuyan-user-packages`。又须将 D1 真标识填入 `wrangler.jsonc`，乃可迁移而部署。详命与接口，见[白话说明](使用说明.汉语.md)。

器用 `lite`，室仅二百五十六兆。豫言旧制之栈先占五百一十二兆，故器中刻令：栈三十二兆、初堆四兆、极堆六十四兆。此令须兼存镜像 `ENV` 与外桥之设；若删镜像之令，云端直启 OCI 时可不受外桥之令，遂以一三九号夭。

## 邮箱立户与发布

首页可立户、登入、退出、生符与废符。惟需邮箱密码，不发验证信，不设邮件寻回或第三方登录。邮箱去首尾空白而以小写比，非已验所有权；密码十五至一百二十八字符，不裁剪。公开之名随机生，不用邮箱。立户须受当前条款与隐私说明。

密码加随机盐，以 PBKDF2-SHA256 十万次派生而藏，不存明文。会话持随机符，库藏摘要，Cookie 设 Secure、HttpOnly、SameSite=Strict，七日到期；复登入则废旧会话。上传符仅生时示之，不入浏览器久库；新符出则本人旧符尽废，退出不废 CLI 之符。

账户接口、字段与命令详汉语篇。同源 JSON 写请求限四千零九十六字节，按 IP 与邮箱摘要限流，注册每来源十分钟至多五试。过期记录因后续写请求而清，不诺定时删除。

初次准备成功即保留包名，后惟其主可布新版。上传、验证与完成皆审发布者，数据库约束亦防并发越权。未发布之保留名不自动释，内测可人工受理。

上线先备份迁移 D1，保旧籍而立多用户之表。须更新豫言容器及 Worker，不可以 `--containers-rollout none` 独更新外桥；旧器恒记发布者为一，不合今制。工具链须识今包元数据，旧种子不识者先更新验摘要之种，不绕过校验。测试与发布命令见汉语篇，本次不自动布站。

注册开放前，另修仓库外隐私说明，明邮箱、密码派生值、随机名、受约记录、七日会话与限流；去注册未开之旧辞。注销删除循既有隐私邮箱，不使条款正文入公库。

## 发布者验证之记

迁移 `0003_发布者验证.sql` 立验证字段，新户皆 `unverified`；惟旧编号一且名“豫言”之官户初记 `verified`。不因邮箱、客传字段或包名授之，今无自助验证之门。此记非邮箱验证，立户仍不发验证信。

账户面板示己之记，循 ZIP 全名查包则示实际发布者与其记，不公邮箱。包随该版发布者当前状态而变，非谓程序、安全或许可证已经审验。查询不缓存，旧 ZIP 下载之约不变。

上传 Access Token 之权定为 `packages:upload`，惟供本人有权之包准备、上传、校验与发布，不可登入、读账户私录或治令牌。生符须持登录会话；所回 `scope` 仅明服务端既授之权，客端不得扩之。
