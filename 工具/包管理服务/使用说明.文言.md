# 包府略

文先于本地成之：于仓库根行 `./yy文档网站生成器 构建包 包文件 发布目录/文档`，合全目录入 ZIP。生成器与豫构同辨包主、寻所依，而惟录本包；包府不召生成器。详见[生成器之说](../文档网站生成器/包说明.文言.md)。

外设工役一，以接域名、D1、R2 与容器；内设豫言之服一，以断名、版、令、验、颁之法。工役截内服所叩虚主机之请求，乃代用 D1、R2 之绑定。故内服不直通 D1，亦不以 SQLite 之术问 D1。

器惟一 production 桶。上传者先陈文件之名、印、量；内服验令与旧版，工役乃授同域 PUT 之路。上传者复执令投之，工役先请内服验其记，乃以 R2 绑定流写 `pending/`，不藏 S3 密钥。复请验证或完成。完成之时，内服取实物，验 SHA-256、ZIP、路径、数目与解压总量；善则于同桶复制为 `sha256/` 正式物，再以 D1 批次记版。`pending/` 之物可俟一日生命周期同除。

下载者无须执令。工役先问 D1，继取正式桶之物，以不可变缓存与摘要应之。

包名与版本皆不可阙，文件式为 `<包名>-<版本>.zip`。以末一连字符为界；名可华可夷，版为点分数字。既颁之同名同版，不可覆也。

今支持邮箱密码立户，验邮箱而后上传；旧“豫言”用户仍存。令之明文不入源码，D1 惟存其 SHA-256。R2 绑定之权由 Cloudflare 自授，无须 S3 密钥。是以源码可公，而账户凭据、明令、`.dev.vars` 皆不可公。

云端所须创者：D1 `yuyan-package-registry` 与 R2 production 桶 `yuyan-user-packages`。又须将 D1 真标识填入 `wrangler.jsonc`，乃可迁移而部署。详命与接口，见[白话说明](使用说明.汉语.md)。

析篇之器用 `standard-1`，室四 GiB；栈三十二 MiB、初堆一百二十八 MiB、极堆一千零二十四 MiB，留双半区之余。旧极堆过狭，析长篇则屡收而不进。其限兼刻镜像与外桥；闲十分钟则寝，取已成之页不惊其器。纳包一器，析篇三器，总数不过四；队列并行不过六，原生请求逾六十秒则重试。

## 邮箱立户与发布

首页可立户、登入、退出、生符与废符。以邮箱密码立户，发验信，可由邮件更密，不设第三方登录。邮箱去首尾空白而以小写比，非已验所有权；密码十五至一百二十八字符，不裁剪。公开之名随机生，不用邮箱。立户须受当前条款与隐私说明。

密码加随机盐，以 PBKDF2-SHA256 十万次派生而藏，不存明文。会话持随机符，库藏摘要，Cookie 设 Secure、HttpOnly、SameSite=Strict，七日到期；复登入则废旧会话。上传符仅生时示之，不入浏览器久库；新符出则本人旧符尽废，退出不废 CLI 之符。

账户接口、字段与命令详汉语篇。同源 JSON 写请求限四千零九十六字节，按 IP 与邮箱摘要限流，注册每来源十分钟至多五试。过期记录因后续写请求而清，不诺定时删除。

初次准备成功即保留包名，后惟其主可布新版。上传、验证与完成皆审发布者，数据库约束亦防并发越权。未发布之保留名不自动释，内测可人工受理。

上线先备份迁移 D1，保旧籍而立多用户之表。须更新豫言容器及 Worker，不可以 `--containers-rollout none` 独更新外桥；旧器恒记发布者为一，不合今制。工具链须识今包元数据，旧种子不识者先更新验摘要之种，不绕过校验。测试与发布命令见汉语篇，本次不自动布站。

注册开放前，另修仓库外隐私说明，明邮箱、密码派生值、随机名、受约记录、七日会话与限流；去注册未开之旧辞。注销删除循既有隐私邮箱，不使条款正文入公库。

## 发布者验证之记

迁移 `0003_发布者验证.sql` 立验证字段，新户皆 `unverified`；惟旧编号一且名“豫言”之官户初记 `verified`。不因邮箱、客传字段或包名授之，今无自助验证之门。此记非邮箱验证，立户发邮箱验信，验邮箱不授身份之记。

账户面板示己之记，循 ZIP 全名查包则示实际发布者与其记，不公邮箱。包随该版发布者当前状态而变，非谓程序、安全或许可证已经审验。查询不缓存，旧 ZIP 下载之约不变。

上传 Access Token 之权定为 `packages:upload`，惟供本人有权之包准备、上传、校验与发布，不可登入、读账户私录或治令牌。生符须持登录会话；所回 `scope` 仅明服务端既授之权，客端不得扩之。

## 验邮箱与更密

先施迁移 `0004_邮箱验证与密码重置.sql`，再部署外桥与新器。未验邮箱，不得生上传之符，旧符亦不得准备、上传、校验或发布。迁移废未验诸符，官户未系邮箱者亦然；身份之记不能代邮箱之验。旧官户须由维护者系真实所控邮箱账户，亲验而后生符。

于 Cloudflare 开 Email Sending，验 yuyan-lang.org 之 DNS。EMAIL 绑定惟许 noreply@yuyan-lang.org 发信；收信转递非此发信之能。

POST 诸门：resend-verification 须登入，verify-email 惟需邮件 token，无须登入；forgot-password 取 email，reset-password 取 token 与 password。立户即试发验信，未发者可登入再请。验信一时有效，更密信半时有效；循验信之址即自动验之，无须登入复按；更密仍须输入新密而提交。券惟藏摘要，前端取 fragment 即去地址栏之券。异器亦可循址直验，不生会话，不验旁户。

更密既成，邮箱亦验，旧会话、上传之符及邮件诸券同废，其事同一事务而成，不可重用。邮箱无户亦应同辞。每邮箱十分钟三信，全站十分钟百信，另受来源限流；投递未成亦计之。

emailVerified 惟示户主。verified 与 unverified 别记真实身份之审验，如已审企业；验邮箱不得之，亦非包之安全之证。

## 即时发布

门户曰 packages.yuyan-lang.org，客文居 usercontent.yuyan-lang.org。登录之符惟属门户，不设父域。旧中文门户转至新域，须再登入。

一举发布，先立版本之籍，页面即见；源码、构建包、说明、文档与运行包各自上传，不候诸物俱至。缺者明告未得，败者可补，成者不覆。同摘要重传不另立物。文档以所选目录为根，须有 index.html；不解压归档，不行客代码。

新籍以所有者、包名、版本为唯一，所有者取认证，不信客自称。今信上传之材，不验源码全否、文档生成之法或重建成否，亦不审恶意；仍验权限、路径、大小与摘要。旧 ZIP 诸接口仍通，不混新籍。

客域先行分流，无账户接口。框与响应皆施沙箱，许脚本而不许同源、表单、弹窗与上层导航。缺物之应不缓存，补传后可再观。单文件默认限百 MiB，不等于账户总配额。

先备份而迁 0005_即时发布.sql，再俱部署桥与容器；此版未行线上迁移与部署。协议及测试之详见汉语篇。

## 定主而传档

邮箱既验，乃定所有者之名；一户一名，全站无重，既定不易。名用一至三十二汉字、小写字母、数字、下划线或短横线，不始于“用户-”。官名豫言仍存。

发布惟传一 ZIP。其内设源码、文档、构建，器可执行者更备运行。源码之首层惟一包书，主、名、版、类与说明皆取其书；只析不行。主须合户籍，双语说明及文档入口须在。压档限十六 MiB，展开限六十四 MiB，条目不逾二千零四十八；拒越界、重径、链接与异物，验其 CRC。

验毕立籍即公，诸物次第入藏。败者重传同档补之，异档不得易同版。客文仍居隔域沙箱，未行恶意审验。旧写门闭，旧下载仍通。先迁 0006_所有者绑定.sql，再部署桥与器。详法以汉语篇新章为准，前述逐物上传之法废。

## 包市与己户

首页 `/` 为公开包市，循主名包名各示近颁之版，可寻可续观；`/release/<编号>` 示版本之详，文与源码皆于主站共览。`/个人` 集登入、验邮箱、符、主名与 ZIP 发布。“吾包”用 `GET /api/releases?mine=1`，服务端依会话主号筛之，无会话则应 401。包市用 `catalog=1`，以 `q` 寻之。旧首页验信更密之址携原 fragment 转至己户。

## 豫言成阅读之页

版本概览、文档之目与源码之页，今由内服 `页面渲染。豫` 成之。云桥惟取公开之籍与物，传于内服；内门不许外客直入。

文件之树惟陈源码中 `。豫`，包书亦在，不陈存储之前缀。文与源码共树，以寻常链接相易。说明由 `安全文档。豫` 饰其段、题、列与代码；客之 HTML 悉转义，链接之法有界，不使客文借主站之权。

成页依修订、路径、模式与语言暂藏，旧文之图亦暂藏，失败不藏。无须迁库，亦不改 ZIP；发布须并更新内服、云桥与样式，不可独更其桥。

## 阅读之制

包页惟二签：概览、文与源码。旧 `/docs` 亦入共器，不复别列目录。文与源码可互易，移篇不改其所观之制。目录次序不移，小屏初收之。声明与行号皆可定址。未指篇则始于总集，无总集则请择篇；已指而不存则报四零四，不以他篇代之。所寻载于址中之 `q`，语言以合法 `lang` 为先，否则循旧好。

旧修订未载依赖之录，则静析其包配置；不行源码，不改归档与库中之籍。配置阙失或不合法，明告未得，不妄称无依赖。

## 成页久存

诸材既存，乃记其成，付修订于持久之列，不候诸页尽成。失于入列者，十分钟一补；生成败者重试，终败入别列，不废其包。豫言定诸页之目，仍以豫言成篇，存于 R2 之 `rendered/`，与原档各居其所。

启 `PERSISTENT_PAGES=true`，先取边缘副本，次取 R2；新包未成则暂应二零二，不藏其提示。迁移之旧篇未藏，则仍即时成而示之，并藏于 R2。概览逾五分钟则后台新之，新修订亦新旧概览。客之 Cookie 不入成页。`/api/releases/<编号>/pages` 可观所计与已成之数；易渲染之代，则别其存径。

旧文补注，复用编译器之词元扫描，倒缀而终反之，不逐词重抄前文；惟文档服务用之，不易编译器，不行客之源码。
