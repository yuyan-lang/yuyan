# 正则直生回收式网页汇编

目标曰 `--target=wasmgc`。取闭包之树，降为统一正则而直写，不经 LLVM，亦不用 C 虚栈。整数、小数、文串、元组、构造器、引用、数组与闭包，皆以回收引用存之。



拼文、取字节、分通字符、解 JSON 文串，皆行于客。文件、进程与环境之务，托 `yuyan:gc-host/v1.call` 于宿主。编译与生码仍行于客；宿主唯供原语与组装。今须居仓库根径而行，并读本目录 `运行时.wat`。

编译之令为 `./yy3_bs 豫言编译器/入口。豫 --package-context <包上下文路径> --target=wasmgc -o yy回收编译器.wasm`。缓存别以 `.wasmgc-anf-v2`，正则与生码合诸模块而行。

独立器 `yy网页汇编直生`，首参为依赖次序之闭包 JSON 路径数组，次参为输出 WAT 路径。旧一参整数原型已更为 `_start` 全模块入口。旧微测仅记昔日之本；今唯测编译器自举。

能启动、能验型，未足谓自举成；须客器实生后器，乃据产物与记时论之。

异常直调之自举数与复现之法，见 `../../性能研究/网页汇编直生/异常自举结果.文言.md`。旧堆续延之数，存于同处 `自举结果.文言.md`。

今常调用托于 Wasm 栈，尾调用径归，合流用块与分支，皆不造堆续体。提前返者以异常投其尚存之归处，号用 i31，递增而不复用；至限则陷。归处既退而欲复入者，此途不支持。异常之物及寻常数据，仍或有分配。

后又以有名正则式延后虑之闭合，共享不变之叶，去旧树无用之根；名入桶，长文积片一合，字节转义查预造之表，同卷诸前端步合为一工。并行、串行自举固定点皆验。今开盖接电，四工两验均时为网页汇编 50.35 秒、原生 47.12 秒，差 6.9%；串行一验为 96.91、111.74 秒。此以已备 AOT 之器为始，不计其预备之费，不可谓全面迁移皆无损。详见 `../../性能研究/网页汇编直生/优化结果.文言.md`。
