# ANF 直接生成 Wasm GC

编译器目标 `--target=wasmgc` 将闭包转换结果降为统一 ANF，再生成 Wasm GC。它跳过 LLVM 与原有 C 虚拟栈，不使用线性内存保存豫言对象。跨模块全局值、完整整数、小数、字符串、元组、代数构造器、引用、数组和闭包采用 GC 引用表示。

函数调用直接使用 Wasm 调用栈，尾调用使用 `return_call_indirect`，局部合并点使用 `block/br`，均不创建堆续延。动态范围内的提前返回使用 Wasm EH，入口通过单调递增的 i31 标记区分；标记达到上限时 trap，防止复用失效标记。此路线支持自举使用的提前退出语义，不支持在捕获入口退出后恢复或重复恢复执行栈。异常抛出本身仍可能由引擎分配异常对象，闭包及程序数据也仍使用 GC。

字符串拼接、字节扫描、UTF-8 拆分、JSON 字符串解码等频繁操作在客体内执行。文件、进程、环境变量等通过 `yuyan:gc-host/v1.call` 调用宿主原语。宿主只提供运行时接口与 WAT 组装，编译器算法和代码生成在客体内执行。当前构建需从仓库根目录运行，并读取本目录的 `运行时.wat`。

```sh
./yy3_bs 豫言编译器/入口。豫 \
  --package-context .yybuild/豫构上下文/24.上下文 \
  --target=wasmgc -o yy回收编译器.wasm
```

上下文编号为本机示例，应使用豫构为当前包生成的上下文。该目标单独使用 `.wasmgc-anf-v2` 缓存，ANF 与最终代码生成在完整模块链接阶段执行。

独立生成器 `yy网页汇编直生` 调用同一编译器核心实现：第一个参数为按依赖顺序列出的闭包 JSON 文件路径数组，第二个参数为输出 WAT 路径。旧的一元整数 `run` 原型接口已由完整模块入口 `_start` 替代。历史微基准记录仅描述当时原型；本次性能验证仅测完整编译器自举。

自举通过与耗时结论以实际产物和自举报告为准，启动成功或模块验证成功不等于自举成功。

EH 直调版本的完整自举结果与复现步骤见 `../../性能研究/网页汇编直生/异常自举结果.汉语.md`。旧堆续延路线的历史结果保存在同目录 `自举结果.汉语.md`。

后续性能优化包括有名 ANF（临时及原有 let 延后闭合）、语法树叶共享与缓存生命周期、i31 和原语内联、名字分桶索引、WAT 片段一次拼接、256 项字节转义表与模块工作进程合并。最新实现已通过并行及串行自举固定点验证；开盖接电复测，四进程两轮均值为 Wasm 50.35 秒、原生 47.12 秒，差 6.9%；串行单轮为 96.91 / 111.74 秒。此口径使用已缓存的输入 AOT，其准备成本不计入，不能宣称全面迁移零损耗。详见 `../../性能研究/网页汇编直生/优化结果.汉语.md`，完整过程见同目录 `优化过程.汉语.md`。
