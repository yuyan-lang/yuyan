# 客器接口装载之核

装载先校应用所需与宿主所供之接口簿、签名及规范摘要，继核 Wasm 惟一函数导入 `yuyan:gc-host/v1.call`，且有 `_start` 导出。

部分 Safari 能编模块，而 `WebAssembly.Module.imports` 或 `exports` 取表则报错。今浏览器入口以编模块之原字节并授装载；惟模块表 API 抛错，乃直析同一字节之导入、导出节，行等价之核。表可读而形不合者不得退求字节。实例化惟供定名导入，并复核 `_start` 可行。

真 Safari 上线复载，旧 `Module.imports unable to produce import descriptors` 错已无；今共界犹因该客器无 JSPI、请求文字之术还 Promise 而不得启。静导航仍见。全异步界面须另建无 JSPI 续行之途。
