# 客器接口装载之核

装载先校应用所需与宿主所供之接口簿（身份、所依、向与签名），继核 Wasm 之导入导出：诸导入皆函，或为过渡之 `yuyan:gc-host/v1.call`，或为自定段「豫言边界」录其签名、导入模块为标准库、构建基础或应用所需接口包之带型导入（宿主未实者给桩，调乃报错），不合者一并列报；且有 `_start` 导出。

部分 Safari 能编模块，而 `WebAssembly.Module.imports` 或 `exports` 取表则报错。今浏览器入口以编模块之原字节并授装载；惟模块表 API 抛错，乃直析同一字节之导入、导出节与「豫言边界」段，行等价之核。表可读而形不合者不得退求字节。实例化惟供定名导入，并复核 `_start` 可行。

真 Safari 上线复载，旧 `Module.imports unable to produce import descriptors` 错已无；今共界犹因该客器无 JSPI、请求文字之术还 Promise 而不得启。静导航仍见。全异步界面须另建无 JSPI 续行之途。
