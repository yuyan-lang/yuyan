# 桌面程序

桌面之一窗（提案〇〇〇一五）。平铺桌面行于豫言操作系统，则终端、文件浏览、任务管理器、设备管理器、设置、搜索与编辑器皆为此程之一任务，任务管理器中各占一行；一窗崩而不累全桌面。

用法：`/工具/桌面程序。豫行 种 [参…]`，平铺桌面起之为外程序之格，常不手行之。

- `终端 [脚本之径]`：终端；予脚本之径则开场行之。
- `文件浏览`、`役管理器`、`器管理器`、`设置`、`寻`：其窗。
- `编辑 径 行号`：编此文，行号大于零则移标于其行。

窗须外壳为之事（开文、右侧开之、行程序、行脚本、设签题、复读设置、求窗列、依种名开窗）经「豫寓使者映」〇点二之外壳之请付桌面；桌面经外壳之来信令其跳行或闭。浏览器、诺驿与原生 macOS 上之平铺桌面如故于本进程示此诸窗。
