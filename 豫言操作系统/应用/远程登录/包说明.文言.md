# 远程登录

豫言操作系统之远程登录程序（SSH 服务端），造盘时装为 `/工具/yy远程登录`，开机自启（开机壳行 `/系统/开机自启`，无此文则作「开启远程登录」一行）。协议之部在 `库/安全外壳/安全外壳服务端`。

## 登录

- 端口二十二，主机钥为 Ed25519，初启乃生，存于 `/系统/远程登录/主机私种`；「远程登录状态」印其纹与可置于 known_hosts 之公钥行。
- 口令：于本机之壳以 `「设置登录口令」于「口令」为『…』` 设之（加盐之 PBKDF2-HMAC-SHA256 散存于 `/系统/远程登录/口令`），乃 `ssh -p 22 任意用户名@机址`。
- 公钥：书 OpenSSH 之 `ssh-ed25519` 公钥行于 `/系统/远程登录/授权公钥`（authorized_keys 之式）。
- 用户名不限：豫言操作系统无多用户。

## 会话

- 交互之会（`ssh 主机`）：会即一 `/工具/yy豫构` 交互子会话（十月十四日起，与开机壳、桌面终端同为一壳，每句皆编而行，所能行之句皆同）。有终端（十月十六日起）则起 `交互 --组字`：字原样转之，回显、行编、拼音组字、补全与旧行皆壳核心之逐键编辑为之，同开机壳、桌面终端；Ctrl+C 于会话停于提示则原样转之（壳弃方入之行），于会话方行一句则经「辍其句」惟断此句；空行按 Ctrl+D 则终会话；出之换行易为回车换行。无终端则起 `交互 --提示`，依行读之。
- 「运行」诸命于子会话中同步行之，子程之出随转，行中所入之行付之；Ctrl+C（十月十四日）于子会话方行一句则惟断此句（壳命「辍」之法：惟终此句所起之程，会话印退码与提示，定义皆存；此句于会话之进程中算而不可断，乃断全子会话而复起之），子会话停于提示则惟弃方入之行；Ctrl+D 闭子会话之标准入。
- 「脚本」由子会话逐行行之；「退出」或空行之 Ctrl+D 终子会话，远程登录之会亦终；「图形」于本机之屏入桌面（开机壳候键时即入之），「打开窗口」于本机所行之桌面开窗（见库 用户态桌面 之壳请求）。
- 一次之行（`ssh 主机 '「远程登录状态」'`）：起一不印提示之子会话行此句，退码为子会话之退码（此句有误为一）。远程登录预起一前导已装之备会话（`/工具/yy豫构 交互 --预装`），一次之行径接之，每条约零点四秒；备会话犹装前导亦接之，候其装毕（约二三秒），即补起新备，数会话可并装单元（十月十六日起，见豫言内核之「唤闲核」）。

## 多连与后台作业（二〇二六年十月十四日）

- 并服诸连，每连可开多会话通道，诸通道之会话之态不相干。客于 `~/.ssh/config` 开 ControlMaster（如 `ControlMaster auto`、`ControlPath ~/.ssh/yy-%C`、`ControlPersist 10m`），惟首命握手，其后每命惟开一新通道（宿主上首命约零点三至零点五秒，其后每命约零点零五至零点一五秒），并行之命亦不复排队。新连之握手与认证犹于主环中同步为之，其间他连暂停约一秒。
- 后台作业：壳命「后台运行」付程序于远程登录之程行之（其父为初任务，作业不随 ssh 会话而终），印作业之号；「作业列表」「作业输出」「等待作业」（且候且印新出，以作业之退码终）「限时等待作业」「终止作业」。会话之端为「开发」同名之子命，作业之目在 `/系统/作业`（见 应用/开发工具/开发命令 之说明）；此之「作业管理」每半秒一察作业之目，起作业、依段书其出、记其退码，远程登录重启则以前程所遗“运行中”之作业标为“中断”。

## 文件传输（SFTP）

`sftp` 与 `scp`（OpenSSH 九版起默循 SFTP）得以上下文件，认证与会同（口令或公钥，用户名不限）。协议之部在 `库/安全外壳/安全外壳文件传输`。

- 径乃已授“桌面”目中之绝径：于豫言操作系统乃整个数据盘之根 `/`（含 `/工具`、`/输出`、`/系统`），可用中文之名；`REALPATH .` 之起始为壳之今径（默 `/`）。
- 读写依块流式而行（READ 读一块，WRITE 依所请之偏书一块），数百 MiB 之系统镜像唯占一块之存。可行 `put`、`get`、`reput` 与 `reget` 续传、`ls -l`（真长与修改之时）、`mkdir`、`rm`、`rmdir`、`rename`（文与目录，可跨目录；OpenSSH 之 `sftp` 用 posix-rename，目已存则代之）及 `scp -r`；乱序与多路并传之 WRITE 亦各书其偏（文件接口零点七之定位书）。远程登录久驻，文件柄之表复用其序，传文多少皆不必重启。
- 于宿主（苹果臂原生）百 MiB 之 `sftp put`、`sftp get`、`scp` 上下各约十二至十四秒，约每秒七至八 MiB，所耗多在 AES-256-GCM。

## 管理

- 「开启远程登录」：书于开机自启，未行则于后台启之。
- 「关闭远程登录」：去之于开机自启，断方行之远程登录（于远程之会行之则自断）。
- 「远程登录状态」：开机自启、行否、端口、口令、授权公钥与主机钥。

## 于宿主试行

参为 `[端口 [设之目录]]`，如 `yy远程登录 22222 /tmp/远程登录设置`，设之目录置 `口令`、`授权公钥` 诸文。试行文件传输则授程以一“桌面”之目，授权之选书于端口之前：`yy远程登录 --授权目录写 桌面=/某/目录 22222 /tmp/远程登录设置`，乃 `sftp -P 22222 用户@127.0.0.1`。

后续版本之事：新连之握手与认证改为逐步行之、重换钥、端口转发、登录之志、标准误走扩展之数。
