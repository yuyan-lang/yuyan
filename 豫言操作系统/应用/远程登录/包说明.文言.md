# 远程登录

豫言操作系统之远程登录程序（SSH 服务端），造盘时装为 `/工具/远程登录。豫行`，开机自启（开机壳行 `/系统/开机自启`，无此文则作「启远程登录」一行）。协议之部在 `库/密壳/密壳主`。

## 登录

- 端口二十二，主机钥为 Ed25519，初启乃生，存于 `/系统/远程登录/主机私种`；「远程登录态」印其纹与可置于 known_hosts 之公钥行。其生在「密抽帛」：处理器有 RDRAND、RNDR 则用硬件随机之令，无则用执行器之熵池（盘上之种文、计时之抖、小睡与收包之刻），无人按键亦足。
- 口令：于本机之壳以 `「设登录口令」于「口令」曰『…』` 设之（加盐之 PBKDF2-HMAC-SHA256 散存于 `/系统/远程登录/口令`），乃 `ssh -p 22 任意用户名@机址`。此亦通系统惟一之口令：桌面锁屏、闲置锁屏与开机问口令皆用此散（见库 用户态桌面 之「重门」），设口令乃效，未设则如故。
- 公钥：书 OpenSSH 之 `ssh-ed25519` 公钥行于 `/系统/远程登录/授权公钥`（authorized_keys 之式）。
- 用户名不限：豫言操作系统无多用户。

## 会话

- 交互之会（`ssh 主机`）：会即一 `/工具/豫构。豫行` 交互子会话（十月十四日起，与开机壳、桌面终端同为一壳，每句皆编而行，所能行之句皆同）。有终端（十月十六日起）则起 `交互 --组字`：字原样转之，回显、行编、拼音组字、补全与旧行皆壳核心之逐键编辑为之，同开机壳、桌面终端；Ctrl+C 于会话停于提示则原样转之（壳弃方入之行），于会话方行一句则经「辍其句」惟断此句；空行按 Ctrl+D 则终会话；出之换行易为回车换行。无终端则起 `交互 --提示`，依行读之。
- 「行」诸命于子会话中同步行之，子程之出随转，行中由子会话之读行编辑代收其入（回显、编辑、组字，回车并换行付子程；子程入原始之模则逐键径传，十月十七日）；Ctrl+C（十月十四日）于子会话方行一句则惟断此句（壳命「辍」之法：惟终此句所起之程，会话印退码与提示，定义皆存；此句于会话之进程中算而不可断，乃断全子会话而复起之），子会话停于提示或在原始之模（「使者入素」，十月十七日）则以 Ctrl+C 原样付会话（停于提示则弃方入之行）；Ctrl+D 闭子会话之标准入。
- 「脚本」由子会话逐行行之；「辞」或空行之 Ctrl+D 终子会话，远程登录之会亦终；「图形」于本机之屏入桌面（开机壳候键时即入之），「辟窗」于本机所行之桌面开窗（见库 用户态桌面 之壳请求）。
- 客中道而断：会话收尾断壳会话而收尽之（进程之转柄随之而闭），初始任务即收其内核之务，任务之表不复留零兆之“任务”（二〇二六年十月二十日，议题百二十）。
- 一次之行（`ssh 主机 '「远程登录态」'`）：起一不印提示之子会话行此句，退码为子会话之退码（此句有误为一）。远程登录预起一前导已装之备会话（`/工具/豫构。豫行 交互 --预装`），一次之行径接之，每条约零点四秒；备会话犹装前导则不接（议题三百四十二：装前导时书行于其入、即闭其入，行失于通道未登之前，初 ssh 无所出而退码零），改起一新子会话行此句，随后复补备会话；数会话可并装单元（十月十六日起，见豫言内核之「唤闲核」）。行不入会话则印“错误：会话的输入没有写进去（码 …）”，退码遂非零。

## 多连与后台作业（二〇二六年十月十四日）

- 并服诸连，每连可开多会话通道，诸通道之会话之态不相干。客于 `~/.ssh/config` 开 ControlMaster（如 `ControlMaster auto`、`ControlPath ~/.ssh/yy-%C`、`ControlPersist 10m`），惟首命握手，其后每命惟开一新通道（宿主上首命约零点三至零点五秒，其后每命约零点零五至零点一五秒），并行之命亦不复排队。新连之握手与认证分步而行，每轮惟行一步，与已立之连同轮：默客自滞于其身，握手逾六十秒、认证逾五分则惟断此连。主环闲则依退避而候（自二十毫秒起每轮倍之，至多二百毫秒；有活连则候于最近有进之连，字至则醒，sftp 上传不因退避而缓），子程方行而无新出者不计为进：构建之际无出之闲会话几不耗处理器。
- 后台作业：壳命「后台行」付程序于远程登录之程行之（其父为初任务，作业不随 ssh 会话而终），印作业之号；「作业列」「作业出」「待作业」（且候且印新出，以作业之退码终）「限时待作业」「罢作业」。会话之端为「开发」同名之子命，作业之目在 `/系统/作业`（见 应用/百工坊/开发命令 之说明）；此之「作业管理」每半秒一察作业之目，起作业、依段书其出、记其退码，远程登录重启则以前程所遗“运行中”之作业标为“中断”。

## 文件传输（SFTP）

`sftp` 与 `scp`（OpenSSH 九版起默循 SFTP）得以上下文件，认证与会同（口令或公钥，用户名不限）。协议之部在 `库/密壳/密壳文件传输`。

- 径乃已授“桌面”目中之绝径：于豫言操作系统乃整个数据盘之根 `/`（含 `/工具`、`/输出`、`/系统`），可用中文之名；`REALPATH .` 之起始为壳之今径（默 `/`）。
- 读写依块流式而行（READ 读一块，WRITE 依所请之偏书一块），数百 MiB 之系统镜像唯占一块之存。可行 `put`、`get`、`reput` 与 `reget` 续传、`ls -l`（真长与修改之时）、`mkdir`、`rm`、`rmdir`、`rename`（文与目录，可跨目录；OpenSSH 之 `sftp` 用 posix-rename，目已存则代之）及 `scp -r`；乱序与多路并传之 WRITE 亦各书其偏（文件接口零点七之定位书）。远程登录久驻，文件柄之表复用其序，传文多少皆不必重启。
- 于宿主（林檎臂原生）今支恰恰封、`aes128-gcm@openssh.com` 与 `aes256-gcm@openssh.com`：百 MiB 之 `sftp get` 不加 `-c` 则议 AES-128-GCM，约七点八秒（约每秒十三兆）；`put -a`（远端先置源文一小段）约七点七秒（约每秒十三兆）。`-c aes256-gcm@openssh.com` 则 get 约十点零秒、put 约九点五秒（约每秒十兆）。`-c chacha20-poly1305@openssh.com` 则 get 约一点九秒（约每秒五十三兆）、put 约二点一秒（约每秒四十七兆）。三法之沙256 皆与原文合。加密之法依 SSH 之规，取客所陈两皆能之首；本机 OpenSSH 十版首列 `aes128-gcm@openssh.com`，故不加 `-c` 议 AES-128-GCM。AES-GCM 之时主要耗于纯豫言之按字 T 表 AES；八位表 GHASH 与加密合流后不复为瓶颈。

## 管理

- 「启远程登录」：书于开机自启，未行则于后台启之。
- 「阖远程登录」：去之于开机自启，断方行之远程登录（于远程之会行之则自断）。
- 「远程登录态」：开机自启、行否、端口、口令、授权公钥与主机钥。
- 启动之诊（2026-10-23，议题三百八十五）：凡启与服皆在顶上「姑试」中；取主机之种而败则书一行诊，候一秒复试，至多四回，四回不成则不带空壳守关，书一行而退，由看护隔三秒重起。主机之种为已有、现生，及启之误由，书于 `/系统/远程登录/启动诊断`，开机壳之看护每秒一读、以「远屏记」印于串口而删之——子之「书」入其出管，不至串口，惟初任务（看护）能印。开机后串口遂有「主机私种：盘上没有，现生成；主机钥指纹 SHA256:…」一行之录；起居注亦书一份。
- 看护（议题三百一十五，十月二十二日）：一会有误（读写逾时、包验之败、sftp 之书写败等）惟终此会、诸连如故；服务真要退时，其由先书于起居注（内核之日志；#344 未合之前起居注中用户所书之行犹读不回，开机壳中看护之要步并印于串口；宿主无注则印于标准出）。开机自启之服务由初任务看护：开机壳候键之隙与桌面方行之环（议三一五、十月二十二日：九宫每帧一呼，看护自限为每秒至多一次）每秒一察，服务不在则候其退满三秒重起一次，并书一行于起居注（开机壳中又印一行于串口）；连起三次不立则止一分而记之，免于死环，满一分则清连败而复试（议题四百二十）（见 几席 之 远程令 之「远程登录看护」）。「阖远程登录」之后无自启之行，故不重起。

## 于宿主试行

参为 `[端口 [设之目录]]`，如 `远程登录 22222 /tmp/远程登录设置`，设之目录置 `口令`、`授权公钥` 诸文。试行文件传输则授程以一“桌面”之目，授权之选书于端口之前：`远程登录 --授权目录写 桌面=/某/目录 22222 /tmp/远程登录设置`，乃 `sftp -P 22222 用户@127.0.0.1`。
