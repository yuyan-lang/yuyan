# 远程登录

豫言操作系统之远程登录程序（SSH 服务端），造盘时装为 `/工具/yy远程登录`，开机自启（开机壳行 `/系统/开机自启`，无此文则作「开启远程登录」一行）。协议之部在 `库/安全外壳/安全外壳服务端`。

## 登录

- 端口二十二，主机钥为 Ed25519，初启乃生，存于 `/系统/远程登录/主机私种`；「远程登录状态」印其纹与可置于 known_hosts 之公钥行。
- 口令：于本机之壳以 `「设置登录口令」于「口令」为『…』` 设之（加盐之 PBKDF2-HMAC-SHA256 散存于 `/系统/远程登录/口令`），乃 `ssh -p 22 任意用户名@机址`。
- 公钥：书 OpenSSH 之 `ssh-ed25519` 公钥行于 `/系统/远程登录/授权公钥`（authorized_keys 之式）。
- 用户名不限：豫言操作系统无多用户。

## 会话

- 交互之会（`ssh 主机`）：每行付系统壳行之，与开机壳、桌面终端同一快路、同一壳命与其法，出发回客；有终端则程自回显、理退格、回车与方向键（方向键弃之），出之换行易为回车换行。
- 「运行」异步启子程：其出随转，行中所入之行书于其标准入，Ctrl+C 断之，Ctrl+D 闭其标准入；子程终则非零退码另起一行。
- 「脚本」逐行行之；「退出」或空行之 Ctrl+D 终会话；「图形」「打开窗口」告远程登录不能为之。
- 一次之行（`ssh 主机 '「远程登录状态」'`）：行一句壳命，退码为子程之退码，壳命有误为一。

## 文件传输（SFTP）

`sftp` 与 `scp`（OpenSSH 九版起默循 SFTP）得以上下文件，认证与会同（口令或公钥，用户名不限）。协议之部在 `库/安全外壳/安全外壳文件传输`。

- 径乃已授“桌面”目中之绝径：于豫言操作系统乃整个数据盘之根 `/`（含 `/工具`、`/输出`、`/系统`），可用中文之名；`REALPATH .` 之起始为壳之今径（默 `/`）。
- 读写依块流式而行（READ 读一块，WRITE 依所请之偏书一块），数百 MiB 之系统镜像唯占一块之存。可行 `put`、`get`、`reput` 与 `reget` 续传、`ls -l`（真长与修改之时）、`mkdir`、`rm`、`rmdir`、`rename`（文与目录，可跨目录；OpenSSH 之 `sftp` 用 posix-rename，目已存则代之）及 `scp -r`；乱序与多路并传之 WRITE 亦各书其偏（文件接口零点七之定位书）。远程登录久驻，文件柄之表复用其序，传文多少皆不必重启。
- 于宿主（苹果臂原生）百 MiB 之 `sftp put`、`sftp get`、`scp` 上下各约十二至十四秒，约每秒七至八 MiB，所耗多在 AES-256-GCM。

## 管理

- 「开启远程登录」：书于开机自启，未行则于后台启之。
- 「关闭远程登录」：去之于开机自启，断方行之远程登录（于远程之会行之则自断）。
- 「远程登录状态」：开机自启、行否、端口、口令、授权公钥与主机钥。

## 于宿主试行

参为 `[端口 [设之目录]]`，如 `yy远程登录 22222 /tmp/远程登录设置`，设之目录置 `口令`、`授权公钥` 诸文。试行文件传输则授程以一“桌面”之目，授权之选书于端口之前：`yy远程登录 --授权目录写 桌面=/某/目录 22222 /tmp/远程登录设置`，乃 `sftp -P 22222 用户@127.0.0.1`。

后续版本之事：并服多连、重换钥、端口转发、登录之志；文件传输之续传与目录改名；一程约十万次开文之后须重启（文件接口之资源表不复用表序）。
