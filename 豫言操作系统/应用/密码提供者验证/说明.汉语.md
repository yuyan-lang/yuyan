# 密码提供者验证

这是通过正式系统接口调用密码能力的普通GC客体。应用直接依赖标准库、密码摘要0.2.0和口令派生0.1.0，入口调用SHA256文字与字节摘要、同长文字比较、PBKDF2SHA256一轮与二轮。期望值写在入口，错误直接抛出异常，成功打印“密码提供者基本向量通过”。

原生路径：双宿主构建的原生模式依次选择“接口名原生”和“接口名”目录。本任务两个接口选现有 `豫言操作系统/适配/密码摘要/摘要。豫` 与 `豫言操作系统/适配/口令派生/派生。豫`，经既有 `豫言操作系统绑定` 工具将适配源码以纯规范包身份写入生成包，包上下文指向生成包。普通编译器将正式密码库及字节编码库一同链接入客体；原生生成器与执行器复用该客体。实现由主树9a984及原生构建代理的模式接线共同闭合。

裸机路径：使用相同已绑定普通GC客体，经现有客体二号的装载、GC运行时与原语执行。密码算法已经链接为客体函数；字节、数组和整数走共用运行时。裸机镜像预置和装载接线由基础设施负责。两个密码接口的提供者身份来自现有独立宿主提供.json，清单格式沿用现三列模式及既有接口清单。

生成链通过普通原生模式调用 `yy双宿主构建 --自动 原生 豫言操作系统/应用/密码提供者验证 输出目录`；工具参数与原生生成器配置以双宿主构建说明为准。本包入口是该链的廉价基本验证载荷。完整原生、裸机实跑、类型及性能核验按用户要求延期，本说明记录实际源码路径与入口。
