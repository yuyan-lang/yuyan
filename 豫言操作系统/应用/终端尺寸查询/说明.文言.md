# 终端尺寸查询

此为节点宿主、原生应用共用之终端查询服务。程召公共控制台之 `读取标准终端尺寸`，原生执行器用底层终端之能，取常出之实列、行数。常出承所查终端，果以空格隔二整数，书于常误。失则还 `0 0`。

以 `豫构 构建 终端尺寸查询 --输出 yy终端尺寸查询.wasm -j 24` 构之，再以原生镜像生成器预编为 `yy终端尺寸查询.exe`。节点宿主循 `YY_TERMINAL_SIZE_SERVICE`、宿主之旁、今目录求此原生服务。

以 `豫构 目标 原生终端尺寸服务 -j 24` 构同源执行器与原生服务；`全部` 连带之。以 `node 豫言操作系统/宿主/节点/终端尺寸。测试.mjs 验收 ./yy终端尺寸查询.exe` 验实伪终端之百九列三十七行、七十三列十九行、零尺寸与管出，并书节点每递之耗时。节点每查即启原生服务，后版可用常驻之服。
