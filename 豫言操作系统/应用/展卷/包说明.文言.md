# 文档阅读

文档阅读（展卷）读刻本（便携文档，PDF），于宿主已授“主窗口”显示面陈之。其界面以设计之语言书之：上为工具之栏，司翻页、缩放、适宽适页、目录与寻；左为目录之侧，列大纲；中为像素之图，陈渲染之页，所寻之中与拖选之文于图上画半透之框；下为状态之行，书径、页序与总数、缩放之百分与讯。

解析与渲染付披卷之库：尾与交叉之引、物之流与增益之改、六漉之法、页树与承属、内容之图形之态、径之填描与裁、色、图像与文字；表单与内联之像由披卷画。嵌入之真型交字模，十四常体以宿主系统之字代之。加密之文于状行告“不支持加密文档”。

命令为 `展卷 <刻本文件>`。文件之径循标准库文件系统今目录；显示面由运行环境授予。无参则印用法。

## 交互

- 翻页：`PageDown`、`PageUp`、空格与退格；工具栏之“上一页”“下一页”；轮一屏翻一页（页内之滚留待后续版本）。
- 缩放：`+`、`-` 以一点二五与零点八倍缩，`0` 适页，`1` 原尺；工具栏之“缩小”“放大”“适宽”“适页”。比例夹于零点一至八倍。
- 目录：工具栏“目录”开合其侧，点大纲之条跳于所至之页。
- 寻：工具栏之文框入文，页内所中之文画朱色半透之框；“下一处”仍用同一之寻。
- 选：于页上按主键而拖，与拖矩相交之文画青色半透之框；工具之栏“复制”以所选之文置系统剪贴，状行书字数或误。壳命「纳袋」调同一剪贴之接口以书任意之文。
- 闭窗、按 Escape 或 q 则毕，归显示之会。

翻页、缩夹、选交与页文之拼在 `模型。豫`，为不接显示之纯术；`测试/模型。测试。豫` 核之。页之渲染与高亮在 `视图。豫`，依页与缩放藏于一匣；`测试/截图。脚本。豫` 以刻书造样张，画开局、寻中、目录三态为便图。

## 图标

图标 `图标。设计。豫` 循徽识之法：二十四格之视框，纸色纸卷、墨色描边，右上折角，中三道横线，左下朱签一枚。
