# 文档阅读

文档阅读（展卷）读刻本（便携文档，PDF），在宿主已授予的“主窗口”显示面里显示。界面用设计语言写成：上面工具栏管翻页、缩放、适宽适页、目录与查找；左边目录侧栏列大纲；中间像素图显示渲染后的页面，页内查找的命中与拖动选中的文字在图上画半透明框；下面状态行写文件路径、页序与总数、缩放百分数与讯息。

解析与渲染交给披卷库：文件尾与交叉引用、对象流与增量更新、六种过滤器、页树与继承属性、内容流的图形状态、路径填描与裁剪、颜色、图像与文字；嵌入的 TrueType 字体交给字模，标准十四字体用宿主系统字体顶替。表单对象与内联图像由披卷画。加密文档在状态行报“不支持加密文档”。

命令为 `展卷 <刻本文件>`。文件路径遵循标准库文件系统的当前工作目录；显示面由运行环境授予。没有参数时打印用法。

## 交互

- 翻页：`PageDown`、`PageUp`、空格与退格；工具栏的“上一页”“下一页”；滚轮一屏翻一页（页内滚动留待后续版本）。
- 缩放：`+` 或 `=`、`-` 以 1.25 与 0.8 倍缩放，`0` 适页，`1` 原始大小；工具栏的“缩小”“放大”“适宽”“适页”。比例夹在 0.1 到 8 倍。
- 目录：工具栏“目录”开合侧栏，点大纲条目跳到目标页。
- 查找：工具栏文本框输入文字，页内命中的文字画朱色半透明框；“下一处”沿用同一查找。
- 选中：在页面上按住主键拖动，与拖动矩形相交的文字画青色半透明框；工具栏“复制”把选中的文字写进系统剪贴板，状态行报字数或错误。壳命令「纳袋」调同一个剪贴板接口写任意文字。
- 关闭窗口、按 Escape 或 q 结束并归还显示会话。

翻页、缩放夹取、选中相交与页文拼接写在 `模型。豫` 里，是不碰显示的纯函数；`测试/模型。测试。豫` 核对它们。页面渲染与高亮在 `视图。豫`，按页与缩放缓存在一个匣里。`测试/截图。脚本。豫` 用刻书现造样张，把开局、查寻命中、目录侧栏三态画成便图，供审查目验。

## 图标

图标 `图标。设计。豫` 照徽识的画法：二十四格视框，纸色纸卷、墨色描边，右上折角，中间三道横线，左下角一枚朱色书签。
