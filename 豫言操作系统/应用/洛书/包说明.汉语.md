# 洛书

洛书是数独游戏，取《易·系辞上》“河出图，洛出书”为名。程序在桌面上开成窗口，窗口标题与启动台里显示“数独”，类别为游戏。

## 玩法

- 出题分易、中、难三档。每道题都由回溯求解器核对唯一解；难度按挖去的格数与单解（只用“某格只剩一个候选”推填）能否推满分档。
- 点一格即选中。点侧栏的数字键盘或按键盘 1–9 填数，按 0、退格或删除清除，方向键移动选中格。
- 点「笔记」进入笔记模式，此时填的是该格九宫格里的候选小字；再点一次退出。
- 填数与同行、同列或同宫已有的数相重时即时标红。点「提示」在选中格（为空时取第一个空格）填一个正确的数；点「核对」把与解答不合的格标红。
- 点「撤销」退回上一步，「重做」回到刚撤销的一步。
- 盘面填满且无冲突即完成，状态行显示“完成”与用时，计时停住。
- 点「新局」按当前难度另出一题；点「易」「中」「难」按该档另出一题。

## 界面

界面用设计语言写成：`视图。豫` 的「控件视图」把模型写成匠心门面（设计界面构造）的控件树，`入口。豫` 经「作门面」换入门面元素，交门面自绘的计时会话显示。改状态的动作都走模型的「更新」，按钮与键盘产生的是同一种「洛书消息」。

配色与桌面、工作台一致：纸色 `#F8F6F0`、内容底 `#FFFEFA`、墨色 `#272B27`、朱色 `#A33C2C`、线色 `#DCDED3`、浅色 `#EEEEE5`。选中格为暖色底，同行、同列、同宫为浅色底，与选中格同数的格加深；冲突与核对标出的错格为淡红底。

## 模块

| 模块 | 内容 |
| --- | --- |
| `模型` | 盘面、格位、题解、存照与模型类型；出题、补满、挖格、求解、数解、唯一、候选、单解、冲突表、完成判断、提示、撤销重做与更新 |
| `视图` | 颜色与样式，格、行、棋盘、数键、侧栏与整窗的控件树，键盘消息映射 |
| `入口` | 取当前毫秒为种子，造初始全局，在主窗口运行计时会话 |

## 名帖与图标

`名帖。数据。豫` 给出显示名“数独”、类别“游戏”与提要。`图标。设计。豫` 是二十四格视框的九宫点阵图标，按洛书之数布点，中点用朱色。用「豫构 设计 编译」可单独编出图标。

## 测试

- `测试/盘面。测试。豫`：求解一道已知题、空盘判为非唯一、三档各出一题都唯一、冲突检测、提示、撤销重做与核对。
- `测试/截图。测试。豫`：用「写真」把开局、带笔记与有冲突三个状态画成便图，写到 `/tmp`，供审查打开查看。
