# 洛书

洛书者，数独之戏也，取《易·系辞上》“河出图，洛出书”之义。其程启于桌面之窗，窗题与启动台中曰“数独”，类别曰游戏。

## 玩法

- 出题分易、中、难三档。每题皆以回溯求解之器核其独解；难度依所挖之格数与单解（惟凭“一格独一候”推填）能否推满分档。
- 点一格即选。点侧栏之数键，或按键盘一至九填数，按零、退格或删除清除，方向键移所选。
- 点「笔记」入笔记之模，所填者为此格九宫中之候数小字；再点则出。
- 所填与同行、同列或同宫之数相重者即时标赤。点「提示」于所选（空则取首空）填一正数；点「核对」则与解不合者标赤。
- 点「撤销」退上一步，「重做」复所撤之步。
- 盘满而无冲突则完成，状态行书“完成”与用时，计时乃止。
- 点「新局」依今难度另出一题；点「易」「中」「难」依其档另出一题。

## 界面

界面以设计语言成之：`视图。豫` 之「控件视图」以模型为匠心门面之控件树，`入口。豫` 经「作门面」易为门面之元，交门面自绘之计时会话而显。改状之事皆归模型之「更新」，键与钮所生者同一种「洛书消息」。

色与桌面、工作台同：纸色 `#F8F6F0`、内容之底 `#FFFEFA`、墨 `#272B27`、朱 `#A33C2C`、线 `#DCDED3`、浅 `#EEEEE5`。所选之格暖底，同行、同列、同宫浅底，与所选同数者加深；冲突与核对所标之误格淡红为底。

## 模块

| 模块 | 内容 |
| --- | --- |
| `模型` | 盘面、格位、题解、存照与模型之型；出题、补满、挖格、求解、数解、唯一、候选、单解、冲突表、完成之判、提示、撤销重做与更新 |
| `视图` | 色与式，格、行、棋盘、数键、侧栏与整窗之控件树，键盘之信 |
| `入口` | 取今毫为种，造初局，于主窗行计时之会 |

## 名帖与图标

`名帖。数据。豫` 书显示名“数独”、类别“游戏”与提要。`图标。设计。豫` 为二十四格视框之九宫点阵，依洛书之数布点，中点用朱。以「豫构 设计 编译」可单编其图。

## 测试

- `测试/盘面。测试。豫`：解一已知之题、空盘判为非独、三档各出一题皆独、冲突之验、提示、撤销重做与核对。
- `测试/截图。脚本。豫`：以「写真」画开局、带笔记与有冲突三状为便图，书于 `/tmp`，以供审查。
