# 便笺

图形之程「便笺」（名取唐薛涛所制彩笺“薛涛笺”，亦曰花笺）。界面以设计语言书：`视图。豫` 以匠心门面之「控件」构造排为控件之树，「作门面」易为门面之元，付门面自绘而显；模、信与更为常豫言，纯理之存取在库「笺谱」之 `笺籍。豫`。

## 界面

- 左栏：新建之钮、搜索之框与便笺之列。列中每行有色条、置顶之朱点、题（取正文首行）与改时；置顶者居前，同顶则新者居前；点一行则开之。
- 右栏：顶栏有题、顶钮、五色之钮、字号“字小”“字大”与删钮；下为多行编辑之区，铺今笺之浅底，空则示占位之文；底书字号、字数与存盘之状。
- 删先出确认之栏，点“删除”乃删，点“取消”则退。
- 编辑之区可组字、可剪贴，按控制或命令加 Z 则撤销近一步（八百毫秒内之连编为一步，至多百步）；停笔一秒则自存。
- 五浅色之底：纸白、浅黄、浅绿、浅蓝、浅粉；字号在十一至二十六之间增减。

## 数据

- 一笺之正文书为 `/数据/花笺/<号>。文本`，号以逐位汉字之数书；题取首行，去其首尾之白，空则“无题”。
- 其目书于 `/数据/花笺/目录。数据。豫`，记号、置顶与色号；式见库「笺谱」之包说明。
- 目文不在时，依目中 `。文本` 之文扫其号。
- 编止一秒则自存正文；目于新建、删、置顶、改色时书。
- 程序每半秒读目文与诸条之改时：壳命于他处改目则全册复读，改某条之正文则惟读其一；方编而未存之条不复读。

## 壳命

| 命 | 说 |
| --- | --- |
| `「记笺」于「文」曰『…』` | 新记一条，印新号 |
| `「笺列」` | 逐条印号、题与改时 |
| `「读笺」于「号」曰「三」` | 印正文 |
| `「删笺」于「号」曰「三」` | 去正文与目项 |
| `「改笺」于「号」曰「三」于「文」曰『…』` | 全篇易其正文 |
| `「置笺」于「号」曰「三」` | 置顶之状反之 |
| `「色笺」于「号」曰「三」于「色」曰「二」` | 易色号 |

图形界面之新建、删、置顶、改色与存盘径呼库「笺谱」之同批函；命改之后，开窗于次轮刷新而随。

## 文

- `花笺。包。豫`：包述。
- `入口。豫`：主窗之计时显会。
- `模型。豫`：模、信、更、自存与外改之察。
- `视图。豫`：色、式与控件之树。
- `名帖。数据。豫`：桌面与市肆所用之名、类与提。
- `图标。设计。豫`：二十四格视框之便笺徽识。
- `测试/便笺。测试。豫`：模之纯理之断。
- `测试/截图。脚本。豫`：三关键态之便图。

## 测试

`便笺。测试。豫` 核：择笺换正文与已存，改文更题与待存之标，撤销退一步而定于文末，字号增减之上下限，按号择笺不得则不动。存取与排、搜、题、目之往还之断在库「笺谱」之 `测试/笺籍。测试。豫`。

## 待办之事

- 真窗之组字入框与长文之卷由界面后端司之，手感受验于实机。
- 编辑之区惟示文，不作语法之染与行号。
- 便笺无改名之命，题随首行而变。
