# 便笺

图形程序「便笺」（名取唐代薛涛所制彩笺“薛涛笺”，亦称花笺）。界面用设计语言写：`视图。豫` 用匠心门面的「控件」构造排成控件树，「作门面」换成门面元素，交门面自绘显示；模型、消息与更新是普通豫言，纯逻辑的存取在库「笺谱」的 `笺籍。豫`。

## 界面

- 左栏：新建按钮、搜索框与便笺列表。列表每行有颜色条、置顶的朱点、标题（取正文首行）与修改时刻；置顶的排在前面，同置顶时新的在前；点一行就打开它。
- 右栏：顶栏有标题、置顶按钮、五个颜色钮、字号“字小”“字大”与删除按钮；下面是多行编辑区，铺当前便笺的浅色底，空时显示占位文字；底部写字号、字数与保存状态。
- 删除先出确认栏，点“删除”才删，点“取消”退回。
- 编辑区支持组字输入、复制粘贴，按控制或命令加 Z 撤销最近一步（八百毫秒内的连续输入算一步，最多一百步）；停笔一秒自动保存。
- 五种浅色底：纸白、浅黄、浅绿、浅蓝、浅粉；字号在十一至二十六之间增减。

## 数据

- 每条便笺的正文存成 `/数据/花笺/<编号>。文本`，编号逐位写成汉字数字；标题取首行，去掉首尾空白，空的写“无题”。
- 元数据存 `/数据/花笺/目录。数据。豫`，记编号、置顶与颜色号；格式见库「笺谱」的包说明。
- 目录文件不存在时，按目录里的 `。文本` 文件扫出编号。
- 编辑停一秒自动存正文；目录在新建、删除、置顶、改色时写。
- 程序每半秒读一次目录文字与各条的修改时刻：壳命令在别处改了目录就整册重读，改了某条正文就只重读那一条；正在编辑且有未存改动的那一条不重读。

## 壳命令

| 命令 | 说明 |
| --- | --- |
| `「记笺」于「文」曰『…』` | 新建一条，印出新编号 |
| `「笺列」` | 逐条印编号、标题与修改时刻 |
| `「读笺」于「号」曰「三」` | 印出正文 |
| `「删笺」于「号」曰「三」` | 删去正文与目录项 |
| `「改笺」于「号」曰「三」于「文」曰『…』` | 整篇换掉正文 |
| `「置笺」于「号」曰「三」` | 置顶状态取反 |
| `「色笺」于「号」曰「三」于「色」曰「二」` | 改颜色号 |

图形界面的新建、删除、置顶、改色与保存直接调用库「笺谱」的同一批函数；命令改了以后，开着的窗口在下一轮刷新时跟上。

## 文件

- `花笺。包。豫`：包描述。
- `入口。豫`：主窗口的计时显示会话。
- `模型。豫`：模型、消息、更新、自动存盘与外部改动的检查。
- `视图。豫`：颜色、样式与控件树。
- `名帖。数据。豫`：桌面与市肆用的名字、类别与提要。
- `图标。设计。豫`：二十四格视框的花笺徽识。
- `测试/便笺。测试。豫`：模型纯逻辑的断言。
- `测试/截图。脚本。豫`：三张关键状态的便图。

## 测试

`便笺。测试。豫` 核对：择笺换正文与已存，改文更新标题与待存标记，撤销回退一步并定位到文末，字号增减的上下限，按号择笺找不到时不动。存取与排序、搜索、标题、目录往返的断言在库「笺谱」的 `测试/笺籍。测试。豫`。
