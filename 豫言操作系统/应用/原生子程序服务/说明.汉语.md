# 原生子程序服务

服务以标准输入每行一个 JSON 请求、标准输出每行一个 JSON 结果复用原生具名授权子程序接口。节点宿主作为消息胶水，原生服务持有授权检查、句柄表、停止及输出收取能力。

请求动作包含启动、收取与终止。启动传名称、参数、输入字节数组及环境名值对；收取和终止传句柄。完成结果包含退出码及两路原始字节数组，保持零字节与任意字节值。服务进程通过现有宿主参数预授程序和环境。

声音动作包含声音打开、声音写入、声音已播、声音延迟及声音关闭，使用公共声音输出接口。声音打开传采样率、声道及块大小，返回句柄；声音写入传句柄与输入字节数组；其他动作传句柄，时钟动作返回帧数。声音流由豫言原生服务持有，林檎设备操作复用声音输出原生适配。节点宿主同步转递这些消息，正式节点发行自动附带原生服务。

构建：`豫构 发行 原生 豫言操作系统/应用/原生子程序服务 yy原生服务 --包根 库 --包根 豫言操作系统/适配`。设备验收入口位于声音输出原生适配的验收包。关闭后的流记录回收列为后续事项。
