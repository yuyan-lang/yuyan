# 原生子程序服务

服务以标准入每行一 JSON 请、标准出每行一 JSON 果，复用原生具名授权子程序接口。节点宿主为消息之胶，原生服务持授权之验、句柄表、终止及二出收取之能。

请之动作有启动、收取及终止。启动传名、参数、输入字节数组及环境名值对；收取及终止传柄。毕果载退码及二路原始字节数组，存零字节及诸字节值。服务进程循已有宿主参数预授程序与环境。

声音之动作有声音打开、声音写入、声音已播、声音延迟及声音关闭，循公共声音输出之接口。开传采率、声道及块之大，返柄；书传柄与输入之字节数组；余动作传柄，器钟之调返帧数。声流由豫言原生之服持之，林檎器之事复用声音输出原生适配。节点宿主同步递此诸请，正式节点发行自动附原生之服。

构建：`豫构 发行 原生 豫言操作系统/应用/原生子程序服务 原生服务 --包根 库 --包根 豫言操作系统/适配`。验器之入口在声音输出原生适配之验收包。闭后之流记之收，列为后续之事。
