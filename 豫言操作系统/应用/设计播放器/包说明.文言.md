# 设计播放器

设计作品（`名。设计`，[提案〇〇〇一八](../../../提案/00018-设计语言与引擎.汉语.md)）之图之播放器。播放器为监视之器：播、停、跳、音量、字幕皆由壳命易之（库「壳命令」之「播放」「暂停」「继续」「跳到」「设音量」「选字幕」「播放状态」），命书播放之状于用户家目之 `.豫言设计播放状态`；播放器每帧读之，依同一墙钟算今时，以库「设计」之中央处理器参考渲染器画此帧，交于所授之显示面。

## 用法

```
yy设计播放器 [文件。设计]
```

带文则先行与壳命「播放」同之库函（自首播此文），乃始显之；不带文则显今播放之状所记之文。闭窗、Escape 或 q 则止播放器，播放之状不易。于平铺桌面之终端运之，则画经子程序显示之代而现于桌面之格。
