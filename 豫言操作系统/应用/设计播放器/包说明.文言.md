# 设计播放器

设计作品（`名。设计`，[提案〇〇〇一八](../../../提案/00018-设计语言与引擎.汉语.md)）之图之播放器。器依壳命所书之状显画而播声轨。播放、暂停、继续、跳到、设音量、选字幕、播放状态同用设计库之法。作品之声先混为十六位双声道之样缓存，再以四千零九十六帧补块，列之目标为八千一百九十二帧；画以声器已播之样数为主钟。器布设备时钟之快照，壳问与暂停读同一时。无声之作与不可用之声器取状之墙钟。

「设渲染后端」于「后端」曰『自动』得择自动、中央处理器、图形处理器，以「渲染后端」问其配。自动优先图形处理器，器不可用则取中央处理器。图形器可用时，两后端之布同由图形显示帧纹理呈之；配易而窗即时显之。

## 用法

```
设计播放器 [文件。设计]
```

带文则先行与壳命「播放」同之库函（自首播此文），乃始显之；不带文则显今播放之状所记之文。闭窗、Escape 或 q 则止播放器，播放之状不易。于平铺桌面之终端运之，则画经子程序显示之代而现于桌面之格。

## 后续之版

## 验

`测试/输出。测试。豫` 于林檎真声器与后台窗验设备时钟、壳问快照、图形之呈、中央处理器之易与闭流。原生发行后，以 `--授权显示面 主窗口=64x64 --显示面后台` 授测试之窗。
