# 设计播放器

设计作品（`名。设计`，[提案 00018](../../../提案/00018-设计语言与引擎.汉语.md)）的图形播放器。播放器是监视器：播放、暂停、跳到、音量、字幕都由壳命令改变（库「壳命令」里的「播放」「暂停」「继续」「跳到」「设音量」「选字幕」「播放状态」），命令把播放状态写进用户主目录下的 `.豫言设计播放状态`；播放器每帧读这份状态，按同一墙钟算出当前时刻，用库「设计」的中央处理器参考渲染器画出这一帧，提交到已授的显示面。

## 用法

```
yy设计播放器 [文件。设计]
```

带文件时先执行与壳命令「播放」相同的库函数（从头播放该文件），再开始显示；不带文件时显示当前播放状态里的文件。关窗、Escape 或 q 结束播放器，播放状态保持不变。在平铺桌面的终端里运行时，画面经子程序显示代办出现在桌面格子里。
