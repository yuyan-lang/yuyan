# 设计播放器

设计作品（`名。设计`，[提案 00018](../../../提案/00018-设计语言与引擎.汉语.md)）的图形播放器。播放器按壳命令写下的状态显示画面、播放声轨。「播放」「暂停」「继续」「跳到」「设音量」「选字幕」「播放状态」共用设计库做法。作品的声音先混为十六位双声道样本缓存，再按 4096 帧补块，播放队列目标为 8192 帧；画面以声音设备的已播样本数为主时钟。播放器写出设备时钟快照，壳查询与暂停读取同一时刻。无声作品及不可用声音设备采用状态墙钟。

「设置渲染后端」于「后端」曰『自动』可选『自动』『中央处理器』『图形处理器』，以「渲染后端」查询配置。自动模式优先图形处理器，设备不可用时采用中央处理器。图形处理器可用时，两种渲染后端的画布共用图形显示帧纹理呈现；窗口马上显示后端配置的改变。

## 用法

```
yy设计播放器 [文件。设计]
```

带文件时先执行与壳命令「播放」相同的库函数（从头播放该文件），再开始显示；不带文件时显示当前播放状态里的文件。关窗、Escape 或 q 结束播放器，播放状态保持不变。在平铺桌面的终端里运行时，画面经子程序显示代办出现在桌面格子里。

## 后续版本

- 增量渲染与缩小渲染（现在每帧整幅重画）。
- 长作品边读取边混音、低延迟队列与声音设备恢复。

## 验证

`测试/输出。测试。豫` 在真实林檎声音设备与后台窗口验证设备时钟、壳查询快照、图形呈现、中央处理器切换及关闭流。原生发行后使用 `--授权显示面 主窗口=64x64 --显示面后台` 授予测试窗口。
