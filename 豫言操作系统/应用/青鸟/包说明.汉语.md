# 青鸟

青鸟是收信与发信的图形程序，显示名“邮件”，类别“网络”。取《山海经》西王母的信使青鸟，后世以青鸟喻传信。

## 收信

收信由尺牍的 IMAP 客户端（RFC 9051，兼容 RFC 3501）做成。按账户开 TCP 连接：安全方式为隐式时直接做 TLS 握手（端口九九三），为开始时先明文招呼再以 STARTTLS 升级（端口一四三），为无时全程明文（只宜本机测试）。登录先试 LOGIN；服务器不接受时改用 AUTHENTICATE PLAIN（RFC 4616）。

登录后列信箱、选信箱、按 UID 取自下一个号往前五十封的信头；每条信头有 UID、旗标（\Seen 判未读）、内时、大小、发件人、主题与时刻，发件人与主题按 RFC 2047 解码。取整封邮件用 BODY.PEEK[]，正文与附件交给信式解析：text/plain 依 Content-Type 的 charset 与 Content-Transfer-Encoding 解码，text/html 去掉标签与实体字符后只留文字；带附件名的叶部件解 base64 或 quoted-printable 后按名收集。标已读发 UID STORE +FLAGS (\Seen)；删除先加 \Deleted 再 EXPUNGE；移动先发 UID MOVE，服务器不支持时退回 UID COPY 加 \Deleted 与 EXPUNGE。

收信连接在一次界面会话内复用；换了账户或协议出错时断开重连。窗口关闭时发 LOGOUT 与 close_notify。IDLE 留待后续版本。

## 发信

发信用尺牍现有的 SMTP 报文与投递：安全方式为隐式时先在四六五端口做 TLS 握手，为开始时在五八七端口交给投递代码做 STARTTLS；报文为七位字节与回车换行，正文与附件用 base64，主题含高位字节时按 RFC 2047 编码，附件名按 RFC 2231 写成 `filename*=UTF-8''…`。收件人与抄送都从界面或壳命令的地址列来，地址间用逗号分隔。

## 账户

账户存于 `/系统/青鸟/账户。数据。豫`，顶层「账户」记五栏：服务器、端口、用户名、口令与安全方式（隐式、开始或无）。发信端口由安全方式推出：隐式四六五，其余五八七。口令现在明文存盘；将来放进钩正加密的数据区或钥匙圈。

## 界面

窗口按屏幕切换三种视图。信屏：左栏信箱，中栏信首列（发件人、主题、时刻，未读加粗，当前信浅底），右栏选中信的正文与附件，每个附件有“存到下载”的按钮（写到 `/数据/下载/`）。写信屏：收件人、抄送、主题、正文、附件路径，发送与取消。设置屏：服务器、端口、用户名、口令、安全方式，保存与返回。改系统状态的按钮在控件事件里写等价的壳命令，点击时交同一条消息，更新调用与壳命令同一批库函数。

## 壳命令

- `「收信」`：取收件箱，印未读封数与最近五封的发件人和主题。
- `「信列」于「箱」曰『收件箱』`：选该箱，印每封的 UID、未读标记、发件人、主题与时刻。
- `「寄信」于「收件人」曰「列」【…】于「主题」曰…于「正文」曰…`：以账户发一封纯文本信。
- `「设邮箱」于「服务器」曰…于「端口」曰…于「用户名」曰…于「口令」曰…于「安全」曰…`：写账户文件并印概况。

## 测试

`测试/模型。测试。豫` 测纯逻辑与信式：地址列拆分、置已读、附件存盘、MIME 正文与附件提取、HTML 只留文字、中文主题的 RFC 2047 编码、附件 base64 与 RFC 2231 名的往返。

`测试/收发。测试。豫` 用内存中的字节通道起最小的 IMAP 与 SMTP 服务端：IMAP 覆盖问候、LOGIN、AUTHENTICATE PLAIN、LIST、SELECT、UID FETCH 信头与正文、STORE 标读、STORE 删除加 EXPUNGE、MOVE 与 LOGOUT；SMTP 覆盖问候、EHLO、MAIL FROM、RCPT TO、DATA 与点转义，核对生成报文的主题编码、base64 正文与附件名。

`测试/截图。脚本。豫` 用匠心门面的写真把信屏、写信屏与设置屏画成便图，供人工核对。

## 依据

[RFC 9051](https://www.rfc-editor.org/rfc/rfc9051.html)（IMAP4rev2）、[RFC 3501](https://www.rfc-editor.org/rfc/rfc3501.html)（IMAP4rev1）、[RFC 5321](https://www.rfc-editor.org/rfc/rfc5321.html)（SMTP）、[RFC 6409](https://www.rfc-editor.org/rfc/rfc6409.html)（提交）、[RFC 3207](https://www.rfc-editor.org/rfc/rfc3207.html)（STARTTLS）、[RFC 8314](https://www.rfc-editor.org/rfc/rfc8314.html)（隐式 TLS）、[RFC 2045](https://www.rfc-editor.org/rfc/rfc2045.html) 至 [RFC 2049](https://www.rfc-editor.org/rfc/rfc2049.html) 与 [RFC 2047](https://www.rfc-editor.org/rfc/rfc2047.html)、[RFC 2231](https://www.rfc-editor.org/rfc/rfc2231.html)（MIME 与参数）、[RFC 4616](https://www.rfc-editor.org/rfc/rfc4616.html)（PLAIN）。
