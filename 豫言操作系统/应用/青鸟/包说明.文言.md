# 青鸟

青鸟者，收信发信之图形程序也，显示名“邮件”，类别“网络”。名取《山海经》西王母之信使青鸟，后世以青鸟喻传信。

## 收信

收信以尺牍之收信（IMAP，就正五四五一，兼就正三五零一）为之。依户开 TCP：安全之法为隐式则径行 TLS（端口九九三），为开始则先明文招呼而以 STARTTLS 升之（一四三），为无则终始明文（惟宜本机试之）。登录先试 LOGIN；服务器不受，则改 AUTHENTICATE PLAIN（就正四六一六）。

登录而后列箱、择箱、依 UID 自下号前五十内取信首；首有 UID、旗标（\Seen 判未读）、内时、大小、发者、题与时刻，发者与题依 RFC 2047 解之。取整封以 BODY.PEEK[]，正文与附付信式解析：text/plain 依 charset 与传输编码解之，text/html 去签与实体而留其字；带附名之叶部解 base64 或可印码而后依名收之。标读发 UID STORE +FLAGS (\Seen)；删则先加 \Deleted 而后 EXPUNGE；移则先发 UID MOVE，服务器不受则退为 UID COPY 加 \Deleted 与 EXPUNGE。

收信之连一会之内复用之；换户或协议有误则断而重连。窗闭则发 LOGOUT 与 close_notify。IDLE 待后。

## 发信

发信以尺牍之邮传与投递：安全之法为隐式则先于四六五端口行 TLS，为开始则于五八七付投递以 STARTTLS；报文七位、回车换行，正文与附用 base64，题含高位则依 RFC 2047 编码，附名依 RFC 2231 书为 `filename*=UTF-8''…`。收者与抄者皆自界面或壳命之址列，以逗号间之。

## 账户

户存于 `/系统/青鸟/账户。数据。豫`，顶名「账户」记五栏：服务器、端口、用户名、口令与安全之法（隐式、开始或无）。发信端口由安全之法推之：隐式四六五，余五八七。口令今以明文存盘；他日入钩正加密之数据区或钥匙圈。

## 界面

窗依屏易三视。信屏：左箱，中首列（发者、题、时刻，未读加粗，今信浅底），右所选之正文与附，每附有“存到下载”之钮（书于 `/数据/下载/`）。写信屏：收、抄、题、正文、附径，发送与取消。设置屏：服务器、端口、用户名、口令、安全之法，保存与返回。改状之钮于控件之事书等价之壳命，点则交同一之信，更新呼与壳命同批之库函。

## 壳命令

- `「收信」`：取收件箱，印未读之数与近五封之发者及题。
- `「信列」于「箱」曰『收件箱』`：择其箱，印每封之 UID、未读之记、发者、题与时刻。
- `「寄信」于「收件人」曰「列」【…】于「主题」曰…于「正文」曰…`：以户发纯文之信。
- `「设邮箱」于「服务器」曰…于「端口」曰…于「用户名」曰…于「口令」曰…于「安全」曰…`：书户文而印其概。

## 试

`测试/模型。测试。豫` 试纯术与信式：分址、置已读、存附、MIME 正文与附之取、HTML 去签、中文题之 RFC 2047、附之 base64 与 RFC 2231 名之往返。

`测试/收发。测试。豫` 以内存之字节通道起最小之 IMAP 与 SMTP：IMAP 覆问候、LOGIN、AUTHENTICATE PLAIN、LIST、SELECT、UID FETCH 首与腹、STORE 标读、STORE 删加 EXPUNGE、MOVE 与 LOGOUT；SMTP 覆问候、EHLO、MAIL FROM、RCPT TO、DATA 与点转义，核所生报文之题码、base64 正文与附名。

`测试/截图。脚本。豫` 以匠心门面之写真画信屏、写信屏与设置屏为便图，供人核对。

## 依据

就正五四五一（IMAP4rev2）、就正三五零一（IMAP4rev1）、就正五三二一（SMTP）、就正六四零九（提交）、就正三二零七（STARTTLS）、就正八三一四（隐式 TLS）、就正二零四五至二零四九与二零四七、就正二二三一（MIME 与参数）、就正四六一六（PLAIN）。
