# 版筑

版筑是方块（落块消行），显示名“方块”，类别“游戏”。界面用设计语言的控件构造写成控件树，经「作门面」交自绘后端显示。

井十列二十行，七种四格块：长条、方形、丁形、两种斜形、两种曲尺。出块用“七块一袋”：每袋七种各一，由卜筮（随机数）带种子打乱，同种子出同序。

键盘：← → 左右移，↑ 顺时针旋转（转不开时依次试左右挪一格、两格），↓ 软降，空格硬降，P 暂停；右侧有新局与暂停按钮。

计时下落：一级八百毫秒，每升一级减一成，最低一百毫秒；每消十行升一级。

计分：一行一百、两行三百、三行五百、四行八百，乘等级；软降每格一分、硬降每格二分。右侧显示下一块、分数、行数、等级。

新块一出就碰到已有方块即为终局，显示“终局”与新局按钮。

规则、袋、计分与更新都是不碰显示的纯函数，测试见 `测试/方块。测试。豫`。关键状态的离屏截图见 `测试/截图。脚本。豫`，写到 `/tmp/方块-*.png`。

窗口按 800×600 逻辑像素排版：左边二百六十乘五百二十的井，右边二百宽的信息栏。井的像素图按显示的像素比生成，屏幕为一倍时二百六十乘五百二十像素，二倍时加倍。
