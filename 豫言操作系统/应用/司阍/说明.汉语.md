# 司阍（本土网页服务程序）

以网页服务本土适配在豫言系统与原生宿主上监听端口，接一个最小的示范应用。运行：

```text
./司阍。林檎。豫行 八零八零
./司阍。林檎。豫行 八零八零 证书.pem 私钥.pem
```

第一个命令行参数是端口，缺省八零八零；第二、三个参数给出时做安全传输（P-256 证书与私钥，PEM）。演示路径：

- `/`、`/你好`：纯文字问候。
- `/回显`：POST 正文原样回成文字，至多一六 MiB，超出回四一三。
- `/上传`：逐块读完正文并回字节数，不积存全文；已用一二百 MB 正文实测。
- `/头`：回方法、网址、原径、原问与抬头数的结绳。
- `/分块`：分块响应，分三次写后正常结束。
- `/事件`：事件流，写三条 `data:` 帧后结束。
- 其余路径回四零四纯文字。

## 验证

- 安全传输已与 OpenSSL 4.0.3 的 `s_client -tls1_3` 完成握手（TLS 1.3、TLS_AES_128_GCM_SHA256），`curl -k https://127.0.0.1:<端口>/你好` 得 200 与正文，同一连接连发两次请求照常应答。
