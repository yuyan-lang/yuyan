# 用户态系统发行

此正式原壳与用户态桌面之 Node、浏览器发行配置也。构建取当原壳源，绑公控制台、文件、子程序、字体与显示诸接口。启则默认命令行，以 `「图形」` 开桌面，归则续同会话。

构建命为 `节点 yy豫构.wasm 目标 用户态系统节点发行 -j 24 --不连带`，末行正式装载之核。启动命为 `node yy用户态系统节点发行/启动.mjs --授权控制台 主控制台 --授权只读目录 桌面=目录路径 --授权显示面 主窗口=900x640 --原生依赖目录 依赖路径`；依赖目录须具 SDL。欲建目录或存环境，以 `--授权目录` 授写。子程序以 `--授权子程序 名=启动文件` 授之，环境别以 `--允许环境 名`。

浏览器构建目标为 `节点 yy豫构.wasm 目标 用户态系统浏览器发行 -j 24`，共节点目标所构原壳发行之器，乃择浏览器适配。页以授权控制台映射授“主控制台”，以授权目录授“桌面”；原壳。测试页.html 惟承入出与画布，正式命令犹原壳释之。实浏览器默认命令行、图形命令、文件预览、归原会话、续回显与退出皆过，控台无误。

正式原壳建目录、存而取消环境、继子程序输入、参及环境之传皆过。正式启动器之管与实PTY二式，皆行“回显进入前 → 图形 → 实文件预览 → 归 → 回显返回后 → 退出”；归前还窗。记录器惟采实SDL之素而注其事，正式启动器犹核原程序。实画为 `yy原壳正式往返.png`。

环境文在已授“桌面”根之 `.环境`，逻辑径为 `/.环境`。原壳当径、切换、列与读，共图形命令之公文件服务，当径存于原壳会话；建目录、写与附随其径。写与附共授权文本之写服务。子程序输入文犹相对授权根，复制、移动、删除等余旧文件命、管之正式句式与流式输出待成。Windows/Linux与原生系统之独验及原生接口适配未成。模板以 `.txt` 避重复包之发现，构建辅助写于隐发行目录。

`node 豫言操作系统/宿主/节点/原壳文件导航验收.mjs yy用户态系统节点发行` 已过：列、子目录导航与读、切换败而存原径、相对建目录、惟读拒写而存文件。

同验亦过相对当径之中文覆盖与附、短文覆盖断旧尾、附而建新文，及惟读拒覆盖与附而原文不易。
