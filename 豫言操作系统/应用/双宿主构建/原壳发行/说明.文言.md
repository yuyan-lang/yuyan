# 用户态系统节点发行

此正式原壳与用户态桌面之节点发行配置也。构建取当原壳源，绑公文件、子程序、字体、显示诸接口。原壳已去裸机专属宿主之导；启时示全中文而默认命令行，以 `「图形」` 开桌面，归则续同会话。

构建命为 `节点 yy豫构.wasm 目标 用户态系统节点发行 -j 24 --不连带`，末行正式装载之核。启动命为 `node yy用户态系统节点发行/启动.mjs --授权只读目录 桌面=目录路径 --授权显示面 主窗口=900x640 --原生依赖目录 依赖路径`；依赖目录须具 SDL。欲建目录或存环境，以 `--授权目录` 授写。子程序以 `--授权子程序 名=启动文件` 授之，环境别以 `--允许环境 名`。

正式原壳建目录、存而取消环境、继子程序输入、参及环境之传皆过。正式启动器之管与实PTY二式，皆行“回显进入前 → 图形 → 实文件预览 → 归 → 回显返回后 → 退出”；归前还窗。记录器惟采实SDL之素而注其事，正式启动器犹核原程序。实画为 `yy原壳正式往返.png`。

环境文在已授“桌面”根之 `.环境`，逻辑径为 `/.环境`。原壳当径、切换、列与读，共图形命令之公文件服务，当径存于原壳会话；建目录随其径。子程序输入文犹相对授权根，写、附等余旧文件命、管之正式句式与流式输出待成。浏览器原壳、Windows/Linux与原生系统之独验及原生接口适配未成。模板以 `.txt` 避重复包之发现，构建辅助写于隐发行目录。
