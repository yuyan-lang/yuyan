# 用户态系统发行

两端原壳桌面发行附加 `字体.ttf` 与 `字体许可证.txt`，复用仓内免费文楷源文件和完整许可。桌面默认选择文楷；节点程序从自身发行目录取得，浏览器由页面声明同名族，均复用公共字体接口与纯豫言解析绘制。通用节点打包仍为三个核心文件；独立桌面发行若使用文楷，也须随附这两个资源文件。仓库发行目标登记字体源与许可为输入，资源文件为产物。

这是正式原壳与用户态桌面的 Node 和浏览器发行配置。构建复制当前原壳源码，绑定公共控制台、文件、子程序、字体和显示接口。启动默认命令行，以 `「图形」` 打开桌面，返回后继续同一会话。

构建命令是 `节点 yy豫构.wasm 目标 用户态系统节点发行 -j 24 --不连带`，构建末尾执行正式装载核对。启动命令是 `node yy用户态系统节点发行/启动.mjs --授权控制台 主控制台 --授权只读目录 桌面=目录路径 --授权显示面 主窗口=900x640 --原生依赖目录 依赖路径`；依赖目录须提供 SDL。需要建目录或保存环境时，以 `--授权目录` 授写权限。子程序以 `--授权子程序 名=启动文件` 授权，环境另用 `--允许环境 名`。

浏览器构建目标为 `节点 yy豫构.wasm 目标 用户态系统浏览器发行 -j 24`，复用节点目标所构建的原壳发行工具，随后选择浏览器适配。页面以授权控制台映射授予“主控制台”，以授权目录授予“桌面”；原壳。测试页.html 只承接输入输出与画布，正式命令仍由原壳解释。实际浏览器的默认命令行、图形指令、文件预览、返回原会话、继续回显与退出已通过，控制台无错误。

正式原壳目录创建、环境保存取消、继承子程序输入、参数及环境传递通过验收。正式启动器的管道与真实PTY两种输入均完成“回显进入前 → 图形 → 实际文件预览 → 返回 → 回显返回后 → 退出”；窗口在返回前归还。记录器只采集真实SDL像素并注入事件，正式启动器仍核对原程序。实际画面为 `yy原壳正式往返.png`。

环境文件位于已授“桌面”根的 `.环境`，逻辑路径为 `/.环境`。原壳当前目录、切换、列表、读取复用图形命令行的公共文件服务，当前路径保存在原壳会话中；创建目录、写入和追加跟随该路径。写入与追加复用共享授权文本写服务。子程序输入文件仍相对于授权根，复制、移动、删除等其余旧文件命令、管道正式句式和流式输出仍待完成。Windows/Linux及原生系统的独立验证和原生接口适配尚未完成。模板用 `.txt` 后缀避免重复包发现，构建辅助程序写入隐藏发行目录。

`node 豫言操作系统/宿主/节点/原壳文件导航验收.mjs yy用户态系统节点发行` 已通过：列表、子目录导航及读取、切换失败保留原路径、相对建目录、只读拒写并保留文件。

同一验收也已通过相对当前目录的中文覆盖与追加、短文覆盖截断旧尾部、追加创建新文件，以及只读拒绝覆盖和追加后原内容保持不变。
行模式的启动提示只说明完整命令提交和图形入口；逐键终端模式显示中文组字、数字选词、F2 与引号快捷键。浏览器原壳逐键输入仍待接入，界面不宣称该模式已经具备这些能力。
