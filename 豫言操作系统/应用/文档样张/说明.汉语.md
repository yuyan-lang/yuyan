# 文档样张

将图表库的数据坐标模型导出为一页中文便携文档：中文标题、横纵轴标签与蓝色折线。坐标映射复用图表库，路径复用二维绘图，中文字形与度量复用字体库，字体子集与 PDF 输出复用便携文档库。

从仓库根目录构建 `豫构 构建 文档样张 --输出 yy文档样张.wasm -j 24`，运行 `节点 yy文档样张.wasm [输出路径] [TrueType字体路径]`。默认输出 `yy文档样张.pdf`，默认字体为仓内 `豫言操作系统/裸机/字模生成/字体/原始字体.ttf`。可以传入支持中文的单字体 TrueType 文件。

样张消费既有图表模型，图表库保持 PNG 与 SVG 的公开输出范围。

`测试/紧凑样张。测试。豫` 生成 CID CFF 的真实字样 `A中あ한`，复用字体库的 cmap 格式 4/12 查码，并按 charset 格式 0/1/2 把 GID 转为 CID。测试包含不同编号的合成映射向量。实际字形号与同机 HarfBuzz 的 34、9569、1466、58207 核对，生成文件供 qpdf 与系统 PDF 阅读器检查。
