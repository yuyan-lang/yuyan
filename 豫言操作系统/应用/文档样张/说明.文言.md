# 文档样张

以图表之数据坐标模造一页中文便携文档：中文题、横纵轴之标与蓝色折线。坐标之映用图表库，径用二维绘图，中文字形与度用字体库，字体子集与 PDF 之出用便携文档库。

自仓根构之：`豫构 构建 文档样张 --输出 yy文档样张.wasm -j 24`；运行 `节点 yy文档样张.wasm [输出路径] [TrueType字体路径]`。默认出 `yy文档样张.pdf`，用仓内 `豫言操作系统/裸机/字模生成/字体/原始字体.ttf`。可授支持中文之单体 TrueType 卷。

样张用既有图表之模，图表库仍以 PNG 与 SVG 为公开之出。

`测试/紧凑样张。测试。豫` 造 CID CFF 之真字样 `A中あ한`，用字体库之 cmap 格式四、十二查字，并依 charset 格式零、一、二将 GID 化 CID。试含异号之合成映射向量。真形号与同机 HarfBuzz 之三十四、九千五百六十九、一千四百六十六、五万八千二百七核对，所造卷授 qpdf 及系统 PDF 阅读器验之。
