# 浏览器编译资源

此工具的豫言源码以语言仓为唯一维护位置。先在语言仓编译工具：

```sh
./yy豫构 构建 浏览器编译资源 --输出 yy浏览器编译资源 -j 24
```

再于云仓先执行 `./yy云仓构建 准备源码 准备种子`，再执行 `./yy云仓构建 浏览器编译资源`。构建过程把本工具及浏览器编译宿主复制到云仓暂存构建树，在暂存树里把豫言编译器编成 WasmGC 二进制（编译器直接写出），再由本工具打包标准库源码与固定内存路径，并按编译器核心的结构化表示直接写出值桥 Wasm（不经 WAT）。宿主 JavaScript 调用 Binaryen 处理、优化发布编译器并生成 gzip 资源和校验清单，值桥原样发布；这些平台源码归在 `豫言操作系统/宿主/浏览器/编译器/`，云仓网页目录仅保留生成副本。资源产物写入应用的 `网页/编译/资源`，不进入 Git。

必须使用包含合流尾位置修复的编译器。发布前在云仓暂存构建树运行 `node --test 应用/豫言体验/测试/浏览器编译测试.mjs 应用/豫言体验/测试/浏览器线程测试.mjs`；测试在 V8 默认栈下编译并执行真实页面示例。
