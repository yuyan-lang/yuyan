# 图形桌面

这是跨运行环境的全中文用户态桌面。桌面拥有自己的窗口系统、文件浏览器和图形命令行，通过系统接口取得平台能力。

## 实施边界

复用界面、界面自绘、显示控件、字体和现有文件系统。桌面代码不访问内核内存、寄存器或设备驱动。宿主提供一个显示面，桌面在其中管理自己的窗口。

当前已实现窗口身份登记、去重置顶、活动窗口查询、轮换与关闭的纯状态操作，以及复用界面自绘的双窗口入口。窗口内容仅显示接入进度，文件与壳服务尚未接入，本包当前不能作为完整桌面运行。

## 分阶段目标

1. 用现有中文界面语言实现两窗口桌面，接层级、裁剪与焦点；保留两个应用状态。
2. 文件浏览器接目录列表、路径导航、上级、刷新、文本预览，失败显示具体错误。
3. 抽出壳的命令执行与编辑状态，图形命令行复用命令语义、拼音候选、历史、引号规则及输出滚动。壳的可执行包不能直接被依赖，共用逻辑应移入库。
4. 系统仍默认启动命令行，通过正式命令启动桌面；退出恢复原壳。桌面也能由宿主独立启动。
5. 按浏览器、Node、Windows、macOS、Linux、原生豫言系统分别核实适配与运行结果。缺失能力按接口错误显示，不假定各平台均已支持。

现有自绘主循环只在显示面关闭或出错时返回，需补应用主动结束的返回路径；优先采用库内控制，不增公共系统ABI。原生执行器底层显示当前主要接macOS，其他平台适配仍须逐项核实。

## 验证

窗口状态测试覆盖双窗口轮换、关闭活动和非活动窗口、重复置顶、空窗口及全部关闭。后续需补实际布局遮挡、焦点路由、文件读取、壳一致性、图形退出与各平台验收。模拟器结果与真机结果分别记录。

## 文件浏览接入

`文件浏览。豫` 已实现浏览状态与中文视图，以注入的列目录、读文本服务执行操作。窗口身份与浏览状态分别保存，切换层级不应重新读取目录。导航失败保留旧目录、条目与预览，路径草稿保留失败目标，错误单独显示；刷新使用已成功进入的当前路径。

受控服务测试已构建运行通过，覆盖打开目录、文本预览、上级导航、刷新、失败保留状态及根路径。此验证未访问实际平台目录，实际服务与桌面状态集成尚待接入。

用户已授权新增公共文件 ABI。文件接口 0.2.0 增加“列出目录”和“查询文件信息”，沿用目录权、相对路径与系统错误，目录条目区分目录、普通文件及其他项。Node 适配类型检查、宿主文件边界测试与接口清单生成通过；GUI 服务接入及其他平台适配尚待完成，不在 GUI 中绕过授权目录边界。

壳复用审计：`命令位置`、`命令登记` 为文字及登记逻辑；`拼音输入`、`智能候选` 与字库需归共用壳库。`交互输入` 混合编辑状态、全局引用及控制台重画，须拆开状态转换与显示；`壳。豫` 的命令处理依赖旧文件、进程服务，须经服务入口复用。抽取时同步原壳及测试，保留原有正式句式与中文输入行为。

## 公共文件服务接入

桌面使用名为“桌面”的授权目录；Node 启动时可用 `--授权只读目录 桌面=路径` 授予。入口取得目录服务并加载授权根，文件窗口使用实际的浏览视图。浏览状态独立于窗口层级，切换、关闭重开和退出都保留状态。

文件服务只通过公共文件接口列目录、打开只读文件、分块读取及关闭；未授权或失败以浏览错误显示。文本在完整字节读取后视为 UTF-8 字符串，避免分块边界拆断汉字。待办事项：二进制识别、无效 UTF-8 与大文件预览截断。

桌面包类型检查、退出与浏览状态保留测试通过；实际 Node 发行启动、Wasm 文件服务调用及图形画面尚待验收，不能据此声称跨平台运行完成。
