# 图形桌面

此全中文用户态之桌面也，可行于诸运行之境。自具窗制、文件浏览与图形命令行，以系统接口取平台之能。

## 施作之界

用界面、界面自绘、显示控件、字体及旧文件系统。桌面不取内核之存、不问寄存之器、不涉设备之驱动。宿主授一显示面，桌面于其中治诸窗。

今已成窗名登记、去重置顶、当事窗之查、轮换与关闭之纯态术，及用界面自绘之双窗入口。窗中惟示接入之进度，文件与壳服务尚未接，此包今未可为全桌面而行。

## 分步之志

1. 以旧中文界面之语成双窗桌面，接层次、裁剪与焦点，存两客之态。
2. 文件浏览接目录之列、径之导航、上级、刷新与文本预览；败则示其误。
3. 析壳之命令执行与编辑之态，图形命令行共用命令之义、拼音之候选、历史、引号之法与输出之滚动。壳之可执行包不可为依赖，共用之术当徙于库。
4. 系统初启仍入命令行，以正式命令启桌面；退则还旧壳。宿主亦可独启桌面。
5. 浏览器、Node、Windows、macOS、Linux及原生豫言系统，各核其适配与运行。缺能则循接口示误，不谓诸平台皆已支持。

旧自绘主循环惟面闭或有误乃还，须补客自止之归路；先用库内之控，不增公共系统ABI。原生执行器底层显示今主要接macOS，余平台适配尚须逐项核之。

## 验证

窗态之试含双窗轮换、闭当事与非当事窗、重置顶、空窗及全闭。后当补实排之遮挡、焦点之分发、文件读取、壳义一致、图形退出与诸平台验收。模拟之果与真机之果别录。

2026-10-04：窗态之试已构建而行，皆过，桌面包类型之查亦过；图形之画尚未验。

## 文件浏览之接

`文件浏览。豫` 已成浏览之态与中文视图，以所授列目录、读文本之服务行事。窗名与浏览之态别存，易层次勿重读目录。导航败则存旧目录、条目与预览，路径草稿存败之所往，误别示之；刷新用已入之当前径。

受控服务之试已构建而行，皆过，含开目录、文本预览、上级导航、刷新、败而存态及根径。此试未读实平台之目录，实服务与桌面态之接尚待成。

用户已允增公共文件 ABI。文件接口 0.2.0 增“列出目录”与“查询文件信息”，循目录权、相对径与系统错误，条目分目录、普通文件与他物。Node 适配类型之查、宿主文件边界之试与接口清单之生成皆过；GUI 服务之接与余平台适配尚待成，GUI 不越目录授权之界。

壳之复用审计：`命令位置`、`命令登记` 为文字与登记之术；`拼音输入`、`智能候选` 及字库当归共用壳库。`交互输入` 杂编辑之态、全局之引与控制台重画，当析态变与显示；`壳。豫` 之命令处理依旧文件、进程服务，当经服务之入口共用。析时并改旧壳与试，存正式句式及中文输入之法。

## 桌面退出之接

桌面入口已用库内可止主循环，“返回命令行”之钮置终态，使调用还。窗名与层次存之。此不改公共系统 ABI；壳之图形启动命令尚未接，独启则归宿主调用者。库入口初模早终之试与桌面包类型之查皆过，实按钮而主循环还尚待图形之验。

## 共用壳库之徙

命令位置、命令登记、命令补全、智能候选、拼音输入与字库已徙 `库/壳核心`，旧控制台壳与桌面径依同库。并改旧壳导入、字库生成与字模读取之径，三核心之试亦徙库之测试目录。迁移回归皆过；编辑态与控制台输出之析、命令服务之授与图形终端之接尚未成。

## 公共文件服务之接

桌面用名“桌面”之授权目录；Node 启时可以 `--授权只读目录 桌面=路径` 授之。入口取目录服务而载根，文件窗用实浏览视图。浏览态与窗之层次别，切换、关闭重开及退出皆存其态。

文件服务惟循公共文件接口列目录、开只读文、分块读与闭；未授或败则以浏览之误示之。字节尽读而后视为 UTF-8 字符串，免块界断汉字。待办事项：二进制之辨、无效 UTF-8 与大文预览之截。

桌面包类型之查、退出与浏览存态之试皆过；实 Node 发行之启、Wasm 文件服务之调及图形之画尚待验，不据此谓跨平台运行已成。

循今源码重构双宿主构建、接口检查、绑定与装载诸具，复以同代检查器生文件清单而核之。实文件服务之探针以 `文件服务。测试。豫` 构为 Node 发行入口，授只读验收目录，列目录、普通文之类与二十四字节之数、中文正文及未授之误皆过。

桌面之 Node 发行包亦成。用 Node 26.3.0、SDL 0.11.13、九百乘六百四十逻辑尺寸之真隐窗；`宿主/节点/桌面后台验收.mjs` 录所交之素，注 SDL 鼠标事，点文件项而生实预览，复点“返回命令行”使主循环归零。共交六帧，末绘之录可见“豫言文件预览验证”。此证今 Node/macOS 自绘、文件与按钮之实链，不代物理输入、他系统及图形命令行之验。

验图与日志存此任务工作树之 `yy桌面后台预览.png`、`yy桌面后台按钮验收.log`。原生依赖置临时目录，验脚本须明授发行目录、原生依赖目录、资源目录及PPM输出径，守后台之式。

命令行窗已接共用正式执行，可行帮助、回显、加法与退出，存命令历史与草稿，输出授旧滚动控件。上下历史键用显示接口之中文键名。余登记之术今由暂不可用服务明报其误，全文件、进程与环境命令服务尚待接；拼音、引号之键与共用控制台编辑会话尚待施。

共用执行、图形历史草稿与退出、桌面态诸试皆过，旧控制台壳构建亦过。于 Node/macOS真隐窗注正式加法之文、回车、上键与滚轮，复点返回之钮。实绘之录有两次“加于12于3”之正式句与果15，初由输入而行，次由历史复而行。初验误点输入框之右，未行命；已正坐标重行，不独以帧数谓命成。

今录为 `yy图形命令行后台.png` 与 `yy图形命令行后台验收.log`。宿主后台验脚本于四径之后加“命令行”，乃行此事之程；命之果必复核实像素，不代物理键盘之验。
