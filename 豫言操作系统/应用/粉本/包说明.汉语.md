# 画板（粉本）

粉本是画图与改图的图形程序，通称画板。名取古代画稿“粉本”：古人作画先有稿本，依样落墨上色。

## 画布

- 新建：按侧栏里填的宽高造一块白底画布，缺省一千二百八十乘八百。
- 打开：读一个完璧图（PNG）或捷图（JPEG），换成一块同尺寸的画布；透明处与白底合成。
- 保存：把画布编成完璧图写盘。路径取路径框里的文；框里空着时用上次的路径。
- 缩放：适合窗口、百分之百、放大、缩小；滚轮以指针为准缩放。
- 平移：按住右键或中键拖动；方向键一格移六十四像素。

## 工具

- 笔：按粗细与颜色画线；粗细从一到六十四。
- 橡皮：同笔，颜色是白纸色。
- 线：起末两点画一条粗线。
- 矩、椭：起末两点围出的矩形或椭圆，描边或填充由侧栏的描边/填充按钮定。
- 桶：四邻填充，容差三十二。
- 取色：把画布上一点的颜色设为当前颜色。
- 文：在点处按基线落一段文字，字体与字号照侧栏。
- 选：拖出矩形选区，再用复制、剪切、粘贴、删除四个按钮，或控制键加 C、X、V 与删除键。

## 颜色与粗细

侧栏有十六个常用色格、最近用过的颜色（至多八个）、色码输入与粗细滑杆。

## 撤销与重做

每一步画笔、每一段线、每一个填充都记进撤销栈，至多五十步，重做栈随新的改动截断。

## 键盘

| 键 | 作用 |
| --- | --- |
| 控制加 Z、控制加 Y | 撤销、重做 |
| 控制加 C、X、V | 复制、剪切、粘贴选区 |
| 控制加 S | 保存 |
| 控制加零、控制加一 | 适合窗口、百分之百 |
| B、E、L、R、O、G、I、T | 笔、橡皮、线、矩、椭、桶、取色、文 |
| 删除、退格 | 删除选区 |
| Escape | 取消选区 |
| 左右上下 | 平移 |
| 加、减 | 放大、缩小 |

## 壳命令

- 「粉本存」于「路径」曰……：把当前打开的画存到路径。
- 「粉本开」于「路径」曰……：在画板里打开这个文件；画板没开时请桌面开一个窗。

两条命令在家目录下的状态文件 `豫言粉本。文本` 里写下请求，画板的计时器每二百毫秒读一次并办；办完把号码与一句讯写回，命令行再执行「粉本存」或「粉本开」即可看到结果。

## 依赖

画图部分（画布、光栅化、填充、撤销补丁、剪贴）都在「画布」里，是不碰显示的纯函数，测试只测这些；开图存图、状态文件与文字落笔在「文书」；状态与更新在「模型」；界面与屏幕合成在「视图」。
