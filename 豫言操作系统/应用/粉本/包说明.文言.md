# 粉本（画板）

粉本者，画图改图之器，通称画板。名取古之画稿：先有粉本，乃依样落墨上色。

## 画布

- 新建：依侧栏所填宽高造白底之布，缺省一千二百八十乘八百。
- 开：读便图或捷图，易为同尺之布；透处与白底合。
- 存：编布为便图书于卷。径取径框之文；空则用旧径。
- 缩：适合、百分之百、放大、缩小；轮以指为准而缩。
- 移：按副钮或中钮而拖；方向之键一格移六十四素。

## 器

- 笔：依粗细与色画线；粗细自一至六十四。
- 擦：同笔，色为白纸。
- 线：起末二点画一粗线。
- 矩、椭：起末二点之矩或椭，描填由侧栏之钮。
- 桶：四邻而填，容差三十二。
- 取色：以布上一点之色为今色。
- 文：于点依基线落一段文，体与字号依侧栏。
- 选：拖出方选，乃以复制、剪切、粘贴、删除四钮，或控制加丙、叉、维与删除之键。

## 色与粗细

侧栏有十六常色、近用之色（至多八）、色码之入与粗细之杆。

## 撤销与重做

每一笔、每一段线、每一次填皆入撤销之栈，至多五十步；重做之栈随新改而截。

## 键

| 键 | 用 |
| --- | --- |
| 控制加 Z、控制加 Y | 撤销、重做 |
| 控制加 C、X、V | 复制、剪切、粘贴选区 |
| 控制加 S | 存 |
| 控制加零、控制加一 | 适合、百分之百 |
| B、E、L、R、O、G、I、T | 笔、擦、线、矩、椭、桶、取色、文 |
| 删除、退格 | 删选区 |
| Escape | 消选 |
| 左右上下 | 平移 |
| 加、减 | 放大、缩小 |

## 壳命

- 「粉本存」于「路径」曰……：以今所开之画存于径。
- 「粉本开」于「路径」曰……：于画板开此卷；画板未开则请桌面开一窗。

二命以家主之下 `豫言粉本。文本` 状文为请，画板之计时每二百毫秒一读而办；办毕书号与一讯，命令行再行即可见其果。

## 所依

画之部（布、栅、填、补丁、剪贴）皆在不涉显示之纯函，试惟试此；开存、状文与文字落笔在「文书」；状与更在「模型」；界面与合屏在「视图」。
