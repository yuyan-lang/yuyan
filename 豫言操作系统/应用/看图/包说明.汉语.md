# 看图

看图读取一个图片文件，在宿主已授予的“主窗口”显示面里显示。界面用设计语言写成：一个像素图控件放按比例缩放、平移后的图，下面一行文字控件写文件名、序号与总数、原始宽高与当前比例。视图由匠心门面（设计界面构造）的「控件」写成一棵竖排控件树，「作门面」转成门面元素，交自绘后端门面自绘显示；窗口尺寸变化时像素图按新尺寸重合成。

命令为 `看图 <图片文件>`。文件路径遵循标准库文件系统的当前工作目录；显示面由运行环境授予。静态图像和动画首帧使用正式 `解图像` 入口。`.svg` 与 `.SVG` 文件走白描入口，原始宽高先取 `viewBox` 的第三、四数，再取 `width`、`height` 属性，都读不出时用 800×600。

## 交互

- 缩放：滚轮与 `+`、`-` 以指针或图区中心为准缩放；`0` 适应图区，`1` 原始大小。比例夹在 1/16 到 32 倍之间。
- 平移：按住主键拖动，或用方向键各移 64 素。图比图区小时居中，大时夹在图区内。
- 翻页：`PageDown`、`PageUp` 与空格、退格在同一目录里按文件名顺序换下一张、上一张；只认所开里的后缀（大小写不论），到头停住。
- 关闭窗口、按 Escape 或 q 结束并归还显示会话。

缩放、平移、翻页与同目录过滤、排序都写在 `视图。豫` 里，是不碰显示的纯函数；`测试/视图。测试。豫` 核对缩放后指针下的图上那一点不动、比例上下限、适应与原始的比例和居中、同目录排序与过滤、翻页到头停住。

## 格式与图标

支持的格式是 PNG、JPEG、GIF、BMP、WebP、QOI、TGA、PPM、PAM、PBM、PGM 与 SVG，名帖 `名帖。数据。豫` 的「所开」与 `视图。豫` 的「看图后缀」一致。图标 `图标。设计。豫` 照徽识的画法：二十四格视框，圆角画框填纸色、描墨色，框内两峰山脊，右上角一轮朱色小日。
