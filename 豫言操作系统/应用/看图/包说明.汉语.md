# 看图

看图读取一个图片文件，在宿主已授予的“主窗口”显示面里显示。界面用设计语言写成：一个像素图控件放按比例缩放、平移后的图，下面一行文字控件写文件名、序号与总数、原始宽高与当前比例。视图由匠心门面（设计界面构造）的「控件」写成一棵竖排控件树，「作门面」转成门面元素，交自绘后端门面自绘显示；窗口尺寸变化时像素图按新尺寸重合成。

命令为 `看图 <图片文件>`，文件路径遵循标准库文件系统的当前工作目录；显示面由运行环境授予。不带文件起时同样开主窗口，显示空态：标题“没有打开的图片”，一句点图说明与一句在壳里用「开卷」打开图的说明，下面列出当前目录或「图片」目录里能看的图，点一行即在同一窗口打开那张图。空态取图目录的次序是：当前目录里有能看的图就用当前目录，否则「图片」目录里有能看的图就用它，两处都没有图时列表为空并写明“这里没有能看的图”。静态图像和动画首帧使用正式 `解图像` 入口。`.svg` 与 `.SVG` 文件走白描入口，原始宽高先取 `viewBox` 的第三、四数，再取 `width`、`height` 属性，都读不出时用 800×600。

## 交互

- 缩放：滚轮与 `+`、`-` 以指针或图区中心为准缩放；`0` 适应图区，`1` 原始大小。比例夹在 1/16 到 32 倍之间。
- 平移：按住主键拖动，或用方向键各移 64 素。图比图区小时居中，大时夹在图区内。
- 翻页：`PageDown`、`PageUp` 与空格、退格在同一目录里按文件名顺序换下一张、上一张；只认所开里的后缀（大小写不论），到头停住。空态里按空格或 `PageDown` 打开列表中的第一张。
- 空态：点列表里的一行即在本窗口打开那张图，标题与信息行随图更新；点图与桌面终端的壳命令「开卷」做同一件事。让已开的看图窗口换图的壳命令留待后续版本，换图时用「开卷」另开一窗。
- 关闭窗口、按 Escape 或 q 结束并归还显示会话。

缩放、平移、翻页与同目录过滤、排序都写在 `视图。豫` 里，是不碰显示的纯函数；空态里位为负一、按名开图与空态信息文写在 `入口。豫`。空态顶端另放一枚一乘一的纸色像素图，带原样输入与自动聚焦，按键因此照旧交给「释入」：Escape 与 q 关窗，空格与 `PageDown` 打开列表第一张。`测试/视图。测试。豫` 核对缩放后指针下的图上那一点不动、比例上下限、适应与原始的比例和居中、同目录排序与过滤、目录图列与空态翻页；`测试/空态。测试。豫` 在 `/tmp` 写一个小 PPM，核对空态信息文的文字与可看张数、图行数、按名开图后的位、图版、内容宽高与适应复位、名字找不到时原样返回；`测试/画面。测试。豫` 核对空内容的画面按窗口大小填深灰。`测试/截图。脚本。豫` 用「写真」把空态与开图后的界面画成两倍便图。

## 格式与图标

支持的格式是 PNG、JPEG、GIF、BMP、WebP、QOI、TGA、PPM、PAM、PBM、PGM 与 SVG，名帖 `名帖。数据。豫` 的「所开」与 `视图。豫` 的「看图后缀」一致。图标 `图标。设计。豫` 照徽识的画法：二十四格视框，圆角画框填纸色、描墨色，框内两峰山脊，右上角一轮朱色小日。空态的纸色面板、标题、图名行与列表卡取桌面共用的纸墨朱主题，颜色与字号照月令、市肆等图形软件。
