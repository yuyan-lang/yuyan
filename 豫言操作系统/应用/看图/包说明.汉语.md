# 看图

看图读取一个图片文件，调用共用图像编解码和图像处理库，在宿主已授予的“主窗口”显示面显示。窗口尺寸变化时重新等比缩小并居中，透明图片覆盖深灰背景。关闭窗口、按 Escape 或 q 结束并归还显示会话。

命令为 `yy看图 <图片文件>`。文件路径遵循标准库文件系统的当前工作目录；显示面由运行环境授予。静态图像和动画首帧使用正式 `解码图像` 入口。`.svg` 与 `.SVG` 文件复用正式矢量图入口，按当前窗口尺寸光栅化。

本工具作为提案 00004 的图片文件实际使用者与公测看图示例。完整类型检查通过，PPM 像素及真实 PNG、SVG 文件的解码、缩图、底色合成消费链已在诺节与同一客体的硬浮原生程序通过。真实显示、尺寸变化与关闭及镜像预置仍待窗口验证；动画连续播放、浏览器资源选择与窗口内缩放交互列为后续事项。
