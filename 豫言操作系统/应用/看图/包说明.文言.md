# 看图

看图读一图文，用共用图像编解码及图像处理之库，于宿主已授“主窗口”显示面陈之。窗尺易则等比缩小而居中；透明图覆深灰之底。闭窗、按 Escape 或 q 则毕，归此显示之会。

命令为 `yy看图 <图片文件>`。文件之径循标准库文件系统今目录；显示面由运行环境授予。静图及动画首帧皆用正式 `解码图像` 之口。`.svg` 及 `.SVG` 之文循正式矢量图之口，依今窗尺成栅。

此器为提案 00004 之图文实用者及公测看图之例。全类型之核验已过；PPM 之素及真 PNG、SVG 文件，经解码、缩图、合底之用，诺节与同客体硬浮原生皆验而过。真显示、窗尺变化、闭窗及镜像预置，皆候窗验；动画连续播放、浏览器资源选择及窗内缩放交互，列于后续。
