# 看图

看图读一图文，于宿主已授“主窗口”显示面陈之。其界面以设计之语言书之：像素之器一，陈依比例缩、依指而移之图；文字之器一，书其名、其序与总数、其原尺与今比。视图以匠心门面之「控件」造为竖排之树，付「作门面」易为门面之元，交门面自绘而显；窗尺易则像素之器依新尺复成。

命令为 `看图 <图片文件>`。文件之径循标准库文件系统今目录；显示面由运行环境授予。静图及动画首帧皆用正式 `解图像` 之口。`.svg` 及 `.SVG` 之文循白描之口，其原尺先取 `viewBox` 之第三、四数，次取 `width`、`height` 之属，皆不得则用八百乘六百。

## 交互

- 缩放：滚轮与 `+`、`-`，以指或图区之心为准；`0` 适图区，`1` 守原尺。比例夹于十六分之一至三十二倍。
- 平移：按主钮而拖，或以方向之键各移六十四素。图小于图区则居中，大则夹于区内。
- 翻页：`PageDown`、`PageUp` 与空格、退格，于同目之图中依文件名之次前后而易；惟认所开之尾，大小写不论；至头则止。
- 闭窗、按 Escape 或 q 则毕，归此显示之会。

缩放、平移、翻页与同目之择、排，皆在 `视图。豫`，为不接显示之纯术；`测试/视图。测试。豫` 核指缩而指下图点不动、比例之上下、适应与原始之比例及居中、同目之排与择、翻页至头而止。

## 格式与图标

所解之格式：PNG、JPEG、GIF、BMP、WebP、QOI、TGA、PPM、PAM、PBM、PGM 与 SVG。名帖 `名帖。数据。豫` 之「所开」与 `视图。豫` 之「看图后缀」相合。图标 `图标。设计。豫` 循徽识之法：二十四格之视框，圆角画框以纸填之、以墨描之，中起两峰之脊，右上朱日一轮。
