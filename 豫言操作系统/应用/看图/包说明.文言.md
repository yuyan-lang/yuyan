# 看图

看图读一图文，于宿主已授“主窗口”显示面陈之。其界面以设计之语言书之：像素之器一，陈依比例缩、依指而移之图；文字之器一，书其名、其序与总数、其原尺与今比。视图以匠心门面之「控件」造为竖排之树，付「作门面」易为门面之元，交门面自绘而显；窗尺易则像素之器依新尺复成。

命令为 `看图 <图片文件>`，其径循标准库文件系统今目录；显示面由运行环境授予。无文而起则亦开主窗，陈空态：题“没有打开的图片”，一句示点图、一句示壳中用「开卷」开图，下列今目或「图片」之目中可看之图，点一行则于同窗开之。取图之目有序：今目有可看之图则用今目，否则「图片」之目有可看之图则用之，两处皆无则列空而书“这里没有能看的图”。静图及动画首帧皆用正式 `解图像` 之口。`.svg` 及 `.SVG` 之文循白描之口，其原尺先取 `viewBox` 之第三、四数，次取 `width`、`height` 之属，皆不得则用八百乘六百。

## 交互

- 缩放：滚轮与 `+`、`-`，以指或图区之心为准；`0` 适图区，`1` 守原尺。比例夹于十六分之一至三十二倍。
- 平移：按主钮而拖，或以方向之键各移六十四素。图小于图区则居中，大则夹于区内。
- 翻页：`PageDown`、`PageUp` 与空格、退格，于同目之图中依文件名之次前后而易；惟认所开之尾，大小写不论；至头则止。空态中按空格或 `PageDown` 则开列中第一张。
- 空态：点列中一行则于本窗开之，题与信息随图而更；点图与桌面终端之壳命「开卷」同为一事。使已开之窗换图之壳命留待后续版本，换图则用「开卷」别开一窗。
- 闭窗、按 Escape 或 q 则毕，归此显示之会。

缩放、平移、翻页与同目之择、排，皆在 `视图。豫`，为不接显示之纯术；空态之负位、依名开图与空态信息之文在 `入口。豫`。空态顶端别置一乘一之纸色像素图，带原样入与自动聚焦，故键仍交「释入」：Escape 与 q 闭窗，空格与 `PageDown` 开列中首张。`测试/视图。测试。豫` 核指缩而指下图点不动、比例之上下、适应与原始之比例及居中、同目之排与择、目录图列与空态翻页；`测试/空态。测试。豫` 于暂处书一小 PPM，核空态信息之文与可看之数、图行之数、依名开图后之位、图版、内容宽高与适应复位、名不得则还旧模；`测试/画面。测试。豫` 核空内容之画依窗尺填深灰。`测试/截图。脚本。豫` 以「写真」画空态与开图后之界面为二倍便图。

## 格式与图标

所解之格式：PNG、JPEG、GIF、BMP、WebP、QOI、TGA、PPM、PAM、PBM、PGM 与 SVG。名帖 `名帖。数据。豫` 之「所开」与 `视图。豫` 之「看图后缀」相合。图标 `图标。设计。豫` 循徽识之法：二十四格之视框，圆角画框以纸填之、以墨描之，中起两峰之脊，右上朱日一轮。空态之纸色板、题、图名行与列卡取桌面共用之纸墨朱主题，色与字号依月令、市肆诸图形之程。
