# 豫言操作系统实现目录

根目录的 `豫言操作系统接口/` 是独立的接口规范，只用豫言声明公共能力；本目录保存平台实现。`宿主/浏览器/` 与 `宿主/云工/` 保存 JavaScript 装载、对象桥和浏览器验收页，`适配/基础/` 保存基础接口到现有宿主的过渡实现及装载核对。`工具/双宿主构建/入口。豫` 从本目录复制平台外壳到构建产物。

非豫言实现代码须逐步归入本目录。当前已搬入浏览器与云工宿主外壳，共 48 个 `.mjs`/`.html` 文件；原生运行时和网页汇编宿主的 C 源码已搬入 `宿主/原生/`，原 `运行时支持库/` 只保留构建规则与产物。Node/V8 的三个 `.cjs` 宿主文件及值桥 WAT 已搬入 `宿主/节点/`，网页汇编直生所需的运行时 WAT 已搬入 `宿主/网页汇编/`。其他工具外壳、性能研究夹具与云仓业务 JavaScript 仍在迁移中。搬迁须同时更新构建路径并用真实 Wasm 与宿主验收，不能仅更改文件位置。

旧 `yy_bs_stable` 二进制内嵌旧原生头文件路径，旧编译器成品内嵌旧 WAT 路径。`运行时支持库/原生` 与 `工具/网页汇编直生/运行时.wat` 暂保留指向本目录的符号链接，只有一个实现副本。已从旧种子依次生成 `yy2_bs`、`yy3_bs`、`yy4_bs`，后两者字节相同；新编译器不依赖旧路径完成类型检查。云仓重新准备源码并生成官网及站点请求 Worker 通过。

`适配/网页界面/`、`适配/网页文树/`、`适配/剪贴板/`、`适配/网址/` 与 `适配/网页转发/` 分别对照根目录纯接口规范，把已有元素交互、受限节点构建、剪贴板、编码和云工授权转发封成中文豫言调用。云仓官网首页、产品页和路由 Worker 的源码现依赖纯接口包名；构建器先核对接口身份、版本和签名，再在临时目录把该身份绑定到适配实现。`装载/接口核对.mjs` 在浏览器与云工入口启动应用前，核对应用要求和独立保存的宿主支持清单、规范摘要、方向与签名，以及 Wasm 通用导入和 `_start` 导出。当前通用导入表不包含逐个豫言函数名，逐函数连通仍靠真实运行验收。普通编译器还不能直接解析无函数体的纯 `。接口。豫`。

`适配/网页消息/` 另提供带 JSON 详情的当前页事件通道；云仓豫言语法高亮应用依赖这一纯接口，源码高亮规则仍由豫言库实现。它的两份浏览器装载壳维护在 `宿主/浏览器/语法高亮/`，构建时分别复制到云工作台和包服务静态资源目录。

`宿主/浏览器/编译器/` 保存试写间的浏览器编译平台实现；`宿主/节点/值桥接.wat` 是浏览器试写间与其他宿主共用的值桥来源。云仓编译网页路径由构建复制，不维护第二份 JavaScript 或 WAT。资源构建工具本身用豫言实现，现位于 `工具/浏览器编译资源/`，由语言仓编译后交给云仓运行。

`宿主/云工/项目核心/` 保存云项目核心 WasmGC 的隔离值桥。云仓 `make 准备宿主` 从本目录生成忽略版本控制的操作系统副本；工作台与测试直接导入该副本，不再维护工具目录下的项目核心宿主源码。

`适配/关系查询/` 与 `适配/网页答复/` 分别把获授权 D1 首行查询和当前请求的 JSON 答复接到两个独立纯接口包。云仓金额单位应用只依赖包身份，构建时绑定并在装载前核对；JSON 文字只是 `_start` 入口尚无类型化入参时的过渡边界。

关系查询 0.2.0 增加预备 SQL 的文字参数绑定；网址 0.2.0 增加严格百分号解码，并由 `适配/网址/` 和 `适配/网址云工/` 分别实现。`适配/网页入站/` 读取当前 Worker 请求的方法、原路径及标头。公开包应用以这四组能力读取并验证文件名、查询 D1、返回 JSON。绑定器将实际适配的宿主清单来源写入构建目录，装载包工具据此重新核对，避免同一接口在不同宿主上误用另一适配的清单。

`适配/服务状态/` 只向获授权的 Worker 服务发送 GET 并返回状态码，不向应用交付上游正文。网页答复 0.2.0 增加空正文响应。云工作台的运维鉴权应用以服务状态、网页入站和网页答复三组接口实现；Cookie 仅由应用显式放进固定服务请求。

网页入站 0.2.0 统一读取事件种类、原路径和严格解码路径；网页转发 0.2.0 只负责改址与原流转发，还能覆盖三种受限安全标头。`适配/环境文字/` 读取获授权的配置文字。官网路由分别依赖网页入站与网页转发；试写器路由另依赖网页答复与环境文字，静态资源仍沿原请求流转发并保留响应状态与正文。

网页入站 0.3.0 又提供查询参数读取与同源 URL 路径、查询改写；网页答复 0.3.0 增加文字和同源重定向响应。包地址应用在豫言中解析路由、验证名称、绑定 SQL 参数并决定 204、错误文字、改写计划或 302；操作系统适配只执行当前请求 URL 和响应操作。

网页入站 0.4.0 增加主机名和原查询串读取；网页答复 0.4.0 增加应用指定 HTTPS 外站重定向。网页转发 0.3.0 允许应用在授权资源流响应上覆写 `Content-Type` 与 `Content-Disposition`。包服务静态应用以豫言决定资源白名单、门户跳转和下载标头，操作系统适配读取 Assets 并保持响应流。

网页入站 0.5.0 增加 JSON 正文读取；`适配/时间/` 从同一平台时点产生 UTC 日与 Unix 分钟；`适配/持久事务/` 把当前授权持久仓的参数、键值和结果接到纯接口。试写器额度应用只依赖网页入站、网页答复、环境文字、时间、持久事务五个接口包，在豫言中继续执行日额与分钟额判定；原有两键数据格式及原子扣减保持不变。

`适配/秘密文字/` 按 Worker 的 Secret 许可读取密钥；`适配/网页上游/` 对每次 HTTPS 上游请求核对 `OUTBOUND_ORIGINS` 来源许可，禁止自动重定向，在本次请求中提供状态、有限 JSON 读取和原流入站回应。试写模型应用只依赖网页入站、网页答复、环境文字、秘密文字、网页上游五组纯接口；豫言继续构造模型请求和 SSE 响应标头，平台适配只处理获授权的网络与流。

云工宿主的旧出站请求原语在程序声明 `OUTBOUND_ORIGINS` 时同样执行来源检查并强制 `redirect: error`，防止这一许可被旧调用路径绕开。未声明该许可的旧程序暂按原行为运行，待迁移时逐一收紧。

`适配/网址定位/` 返回 URL 标准解析后的 `href`、`origin`、`pathname`、`search`；`适配/命名持久服务/` 按 `DO` 许可访问本次程序的命名对象、编码查询并返回有限正文和响应头。云工作台站点请求应用以这两组能力及网页入站、网页答复、网址接口完成目标站点选择、路径边界、令牌格式和结果投影；适配不包含站点业务规则。

`适配/关系数据库/` 在 `云工宿主` 的句柄桥上实现关系数据库 0.1.0：`prepare` 预备语句，`bind` 绑定已校验的类型参数，`first`、`all`、`run` 与 `batch` 分别对应首行、多行、执行结果和原子批。平台错误经新增的 `云工调用方法安全` 读到原文，再转为豫言异常，应用可用「尝试运行」按唯一约束冲突等原因恢复；未获许可的库名仍直接中止请求。该接口是把包管理服务中依赖 D1 多行读写的 JS（账户、云用量、AI 市场等）迁入豫言的前提。

`适配/口令派生/` 与 `适配/随机数/` 直接调用云工宿主的 Web Crypto：前者是 PBKDF2-HMAC-SHA-256（迭代次数 1 至 100000，输出 64 位小写十六进制），后者是 `getRandomValues` 与 `randomUUID`。两者的十六进制转换共用 `拓展库` 云工宿主 `字节。豫` 中的 `字节串转小写十六进制`。它们是把账户口令、会话令牌、上传令牌等密码学逻辑迁入豫言的前提。

`宿主/网页汇编/运行时.wat` 的 `$json_string` 与 `宿主/原生/运行时/字符串.c` 现支持 `\uXXXX`（代理对合并，孤代理替换为 U+FFFD，`\u0000` 得字节 0），畸形转义仍中止；癸象编码器把无短式的控制字符写成 `\u00xx`。规则见 `库/拓展库/癸象工具/癸象转义.汉语.md`，对拍见 `宿主/网页汇编/一致性验证/`。此前遇到 Python、Go 的 JSON 输出或宿主对控制字符的 `\u00XX` 转义，解码会在 Wasm 里 `unreachable`，是计费流式中断、公开接口被畸形数据拖垮的根因。

`适配/对象存储/` 在 `云工宿主` 句柄桥上实现对象存储 0.1.0，映射到 R2 绑定：`head` 取元数据，`get` 加严格 UTF-8 的 `TextDecoder` 读文字（上限 2 MiB：JSON 转义最坏六倍须低于值桥的 16 MiB），`put` 用真正的 `Headers` 表达条件写并交平台校验 `sha256`（返回 null 即 `{"written":false}`），另有 `delete`、`list`，以及把 `body` 流交给 `Response` 的直通（正文不进 Wasm 内存，HEAD 只用 `head`，对象不存在返回阴且不占用最终响应）。`适配/压缩/` 用 Blob、`pipeThrough` 与 `DecompressionStream` 逐块读取输出，累计超限立即取消（压缩炸弹不会被整体解出），并把 ZIP 条目包成 gzip 容器让平台原生校验 CRC-32 与大小（存储方法先包成 deflate 存储块）。`适配/密码摘要/` 增加字节摘要和尽力恒时的 `恒时相等文字`。三者的真实 Wasm 测试在 Node（R2 为类实例模拟）与本地 workerd（真实 R2）中都通过；它们是把包服务发布、下载与阅读链的 JS 迁入豫言的前提。

`适配/授权服务/`、`适配/网页上游/`、`适配/命名持久服务/` 用豫言写在云工宿主库上（不增宿主 JavaScript）。读取状态表存在 Wasm 实例内，经带信号的 `pipeThrough`、流式 TextDecoder 与码点边界切块提供增量文字块读取、有限整读和取消；授权服务增带正文请求，网页上游增严格校验的动态公网 HTTPS 上游，命名持久服务增流式请求、原答与入站请求转发。这些是把 AI 市场调用、服务商连接、云工作台模型流与编译流的 JS 迁入豫言的前提。

`适配/网页事件浏览器/` 与升级后的 `适配/网页界面/`、`适配/网页文树/`、`适配/网页消息/`，把浏览器宿主的统一事件队列、界面订阅器（委托、同步键规则）与页面控制（白册、一次建树、句柄回收）封成中文调用；三个纯 JS 工厂在 `宿主/浏览器/宿主.mjs`，可脱离 Wasm 单测，验收材料在 `适配/网页事件浏览器/一致性验证/`。这是把云控制台等前端 JS 迁成豫言浏览器应用的接口基础。

云工宿主壳新增事件种类 `durable-block`（`blockConcurrencyWhile` 内重入）；事件墙钟时限默认 30 秒（独占与事务 25 秒），可由应用目录里可选的 `执行配置.json` 按事件种类调整，告警至多 15 分钟；`yy双宿主构建` 校验后把它写成产物 `动态资源.mjs` 的导出 `执行配置`（新旧壳与新旧构建器可混用）。`适配/持久事务/`、`适配/持久告警/`、`适配/持久独占/` 用它们把持久仓的事务内外读写、告警和并发独占封成中文调用。本地 workerd 实测：事务内的告警变更与直接 storage 写入随回滚一起撤销，事务回调期间其他事件排队，回调超 30 秒平台会重置对象——规范据此措辞，云端行为待验证清单见 `宿主/云工/说明.汉语.md`。这是把云工作台的三个 Durable Object（用户目录、云端项目、公开站点）迁成豫言的接口基础。

`适配/消息队列/`、`适配/定时事件/`、`适配/邮件发送/`、`适配/文字规整/` 与 `适配/日志/` 分别把云工的 Queue 绑定与 queue 事件、scheduled 事件、Send Email 绑定、String 对象和 console 接成纯接口，全部用豫言写在 `拓展库` 云工宿主的句柄桥之上，没有新增宿主 JS（邮件发送用宿主已有的 `豫言_云工_授权绑定存在` 判断绑定是否配置）。消息体由宿主的 JSON.parse/stringify 规范化并拒绝伪造宿主句柄的记号，批量数组由豫言在规范文字上拆分；文字规整经 TextDecoder/TextEncoder 传递 UTF-8 字节，不经 JSON，控制字符与 BOM 精确往返，输入上限 1 MiB；邮件先在豫言里校验地址、主题、正文再交给 send，失败以（阴，固定原因）返回且不含地址；日志按 UTF-8 字节在码点边界截断到 8 KiB。`消息队列/一致性验证/` 与各适配的 `一致性验证/` 含 75 项真实 Wasm 的 Node 测试，以及 14 个真实本地 workerd 场景（`attempts` 与延迟重试、毫秒计划时刻、邮件内容、日志级别）；实测本地 Miniflare 在处理失败时会把已确认的消息也整批重投，消费处理须幂等。这些接口是把包管理服务里的页面任务队列、定时补发、账户邮件、邮箱规范化与日志迁入豫言的前提。

`适配/网页事件流/` 与 `适配/持久频道/` 用豫言写在云工宿主库上，不增宿主 JS。事件流适配以 `TransformStream` 可读端作 `Response` 正文并立即提交响应头，写入与请求 `AbortSignal`（须开 `enable_request_signal`）派生的“断开等待”竞速，故客户端断开后写入返回 1、应用仍可结算；持久频道适配把宿主具名广播包成保序订阅，以 0xFF 起首控制帧承载探测与带因关闭，`Promise.race` 加 `scheduler.wait` 实现限时等待而不丢消息。两包各有真实 Wasm 的 Node 验证与本地 workerd 复验，并附复现 AI 服务商连接持久对象的组合范例。已知限制：当前宿主在事件结束或超时时不收尾响应流与订阅，适配说明给出已验补丁。这是迁移云工作台 `/events` 与 AI 市场 `/connect`、`/dispatch`、`/chunk` 的接口基础。

`适配/隔离运行/` 实现隔离运行 0.1.0：豫言写在云工宿主库上校验参数、重算程序摘要、调用 `LOADER.get(范围:摘要, …)` 取得子 Worker 并 POST 输入；子 Worker 的模块（`隔离运行客.mjs` 与浏览器编译器宿主 `编译宿主.mjs`）由 `yy双宿主构建` 写进产物 `动态资源.mjs`，宿主只多一个通用原语 `豫言_云工_隔离运行客按号取`。云工作台的用户站点程序经它运行，见 `适配/隔离运行/说明.汉语.md`。

HTTP 接口簇（网页入站 0.7、网页答复 0.5、网页转发 0.4、环境文字 0.2、网址定位 0.2、网址查询 0.1）在云工宿主库上全用豫言实现，把包管理服务与云工作台里散落的请求/响应胶水收成统一接口：入站可读有限字节、严格 UTF-8 文字、宿主校验后的 JSON 正文与合法名校验的标头，答复可带标头、多个 Set-Cookie、字节与流，转发支持筛标头与静态资源并拒绝点段路径。独立审查发现的缺陷已修：JSON 经宿主 `JSON.parse` 校验与规范化而不再经癸象往返（畸形字符串不再陷阱、大整数不回绕、万项数组不栈溢出），旧标头读取/改址/内容类型遇非法输入抛可捕获异常，转发拒绝 `.`/`..`/`%2e` 段，网址文字限 64 KiB，表单限 1024 项，文首 BOM 不再被丢弃；各接口的一致性验证共 33+21+17+10+5+3 项 Node 测试通过。
