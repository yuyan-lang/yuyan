# 标准库宿主服务：各 JS 宿主的接线与统一语义

子程序接口另有原语 309「遣信宿主役（按宿主进程号发信号）」：林檎、林纳按宿主号发一次信号；轩窗没有能送达脱开控制台进程的温和通道，九与十五都按进程句柄硬止，退出码一百三十七、一百四十三（一百二十八加信号号），其他有效信号、豫言操作系统、诺驿与浏览器答五十八。信号限一至一百二十七，越界答二十二；成功答零，无进程答八，发送失败答二十九。信号范围先于平台与进程号核对。它始终取宿主号域，归使者（子进程能力）节。

终止异步子进程按当前实例登记的句柄强制终止，记录保留到收取；结果码为 0 成功、8 句柄无效、29 宿主失败、58 暂不支持。工具节点与原生执行器复用各自的进程记录和底层终止能力；应用节点与浏览器的异步启动及终止留待后续版本。

节点应用宿主的行读取只读取当前行所需字节，避免预取下一行并夺走子程序输入；仍去掉行尾换行与回车。终端原始输入逐字节组成完整字符或连续可读的转义按键，不批量预取后续命令。继承输入的子程序启动前暂停本次原始编辑模式，结束或启动失败后恢复。真实管道验证父命令、子一行、父续行依次消费输入；真实PTY验证换行前子端未读，结束后父端无换行读键。长行效率、延迟到达的转义序列尾部和完整原壳调用迁移仍待完成。

这是标准库与构建基础的宿主服务在各 JS 宿主上的规范。标准库的 `东道。接口。豫` 与 `东道带列。接口。豫` 编成导入模块“豫章”的一百一十六个带类型导入，营造的 `营东道。接口。豫` 编成导入模块“营造”的十五个；导入形状（签名、Wasm 类型、自定义段「豫言边界」）见[网页汇编接口](../../应用/豫言编译器/文档/语言技术规范/网页汇编接口.汉语.md)网五。本篇规定各宿主提供哪些、怎样接线，以及各宿主一致的语义。2026-10-21 加的三个网络对时接口（`读墙钟秒毫`、`设墙钟偏移`、`注起居`）只在豫言操作系统的执行器里有实现（前两者在原生执行器上按宿主时钟与「不支持」回答）；2026-10-22 加的 `读墙钟偏移` 同样只在豫言操作系统的执行器里有实现，原生执行器给（0，0）；这些接口在 Node 工具宿主与浏览器构建工作线程（网页行在）上按宿主时钟或「不支持」作答（编译器写编译缓存时要读墙钟），其余 JS 宿主不提供；网络对时只在豫言操作系统里做。2026-10-23 加的 `提句柄上限` 在豫言操作系统的执行器里按平台提高本进程的文件句柄软上限：macOS 提到硬上限与 `kern.maxfilesperproc` 的较小者，Linux 提到硬上限，返回提后的软上限；Windows、裸机与 JS 宿主返回 −1。同日加的 `辞行在` 在豫言操作系统的原生执行器上把本进程从宿主行在里辞出（见[客体二号说明](../裸机/客体二号/说明.汉语.md)的“辞去行在”），其余平台没有行在：Node 工具宿主与浏览器构建工作线程返回阳，其他 JS 宿主不提供、由边界胶水给桩。同日加的 `附帛` 追加写文件字节串，原生执行器、Node 工具宿主、浏览器编译宿主与浏览器构建工作线程都有实现，其余宿主给桩。同日加的 `置箧` 建目录（缺的上级一并建，已存在算成功）与 `改权` 改权限位，原生执行器、Node 工具宿主、裸机与浏览器构建工作线程都有实现（浏览器构建工作线程的内存文件系统同裸机没有权限位，改权对已有的路径答零），其余宿主给桩。同日加的 `删箧` 删空目录在原生执行器（含轩窗）、Node 工具宿主、裸机与浏览器构建工作线程都有实现，其余宿主给桩；`问负载`、`问开机秒` 与 `问主机名` 在原生执行器（林檎、林纳）与 Node 工具宿主上有实现，浏览器构建工作线程答网页行在开机以来的秒数、负载与主机名答空串，裸机与轩窗返回空串或负一，其余宿主给桩。2026-10-26 加的 `置影` 造符号链接（路径与所指两个标签参数，返回零或底层错误码）：原生执行器经底层文件接口的 `建链` 在根句柄 3 下建（路径先经附庸表改写，所指照原样记下），裸机经文件系统建快速符号链接（所指不到六十字节，更长的返回参数无效），Node 工具宿主用 `fs.symlinkSync`（所指照原样记下，相对的仍相对）；轩窗、Node 应用宿主、浏览器与云工没有造符号链接的能力，返回 58（不支持）。程序与测试造符号链接用它，不必起 `ln` 宿主命令（议题 850）。2026-10-27 与「共身」一并补齐：置影在轩窗用 `CreateSymbolicLinkW`，裸机补上数据块符号链接（所指不短于六十字节）；共身是宿主服务里的新一员，给已有文件再添一个同实的名字，供程序与测试造硬链接而不必起 `ln`（议题 858、870）。

## 接线

- 三家 JS 宿主共用胶水 `网页汇编/边界.mjs`：它读「豫言边界」段，按签名把 Wasm 值与 JS 值互转。宿主给出按（模块，字段）分组的实现表；表里没有的导入给桩，调用时报“接口函数未绑定：模块.字段”。签名表与导入表按模块缓存。Safari（JavaScriptCore）的 `WebAssembly.Module.imports` 遇到 WasmGC 引用类型会整张表报错，这时胶水改用「豫言边界」段的导入行作导入表（编译器按同一张登记表写出导入项与段行，二者一一对应）。
- 同步的实现直接调用；只有标了“异步”的实现才套 JSPI。没标“异步”却返回 Promise 的，胶水当场报错。下面各宿主给出的标准库函数都是同步的，所以带类型导入在没有 JSPI 的浏览器里也能用。
- 平铺发布：`浏览器/`、`云工/`、`浏览器/编译器/` 下的 `边界.mjs` 在仓库里只是转出 `../网页汇编/边界.mjs`（编译器目录是 `../../`）的一行。豫构发行把胶水本体写成产物里的 `边界.mjs`，云工动态子 Worker 的模块源码也带上它；Node 发行启动文件把胶水内联进来。浏览器编译宿主只在模块有带类型导入时才动态载入胶水（读不出导入表时，看模块有没有「豫言边界」段）。
- 云工每个事件新建一个实例，带类型导入的闭包也每个事件一套，不共用“当前事件”的状态。带类型导入在每次调用时检查该事件的墙钟时限。
- 装载核对：程序须带「豫言边界」段，Wasm 的导入只能是在该段里有签名、导入模块为标准库、构建基础、平台接口包或应用要求的接口包的带类型导入；不合的一次列全报出。

## 统一语义

- **附庸径外**（附庸挂载表外查询，原语三百一十七）：接收路径文，返回爻。执行器统一计算私有根的真路径，按当前挂载表选择最长路径前缀，同长时沿用路径改写的可写优先规则；绝对路径长于根路径且匹配私有影子根挂载时答阳。空挂载表、根路径、相对路径与其他挂载答阴。查询保留上次路径改写的表外标记。豫章（标准库）直接调用此服务。原生与裸机共用执行器实现；诺驿（Node）、浏览器与云工六处宿主的挂载命名空间为空，显式接线答阴。根径推导与挂载匹配由执行器维护。

以标准库注释为准，各宿主一致：

- **退出进程**：按退出码结束本次运行，0 表示成功。浏览器与云工上退出码 0 的运行正常完成，非零以“豫言程序退出：码”失败；项目核心退出码 0 时照常读取输出，非零为失败。
- **标准错误打印行**：写宿主的错误流。Node 写文件描述符 2；编译宿主收进运行结果的 stderr；浏览器与云工没有独立的错误流，缺省写日志的错误级（`console.error`），调用者可以传 `错误输出` 改去向；项目核心先收集起来，运行失败时作错误消息交给调用方，不再借它抛错。
- **获取当前工作目录**：归实例所有。Node 工具宿主可以切换；Node 应用宿主不支持切换，恒返回实例创建时的进程目录；编译宿主、浏览器与云工恒为“/”。
- **在线处理器数量**：宿主可用的并行数，不知道时为 1。编译宿主恒为 1。
- **同步改名文件**：把旧路径的文件改名为新路径，新路径已有文件时整体替换，修改时间随文件不变。Node 工具宿主用 `fs.renameSync`，原生执行器用 renameat（Windows 用许覆盖的 MoveFileExW），同时读新路径的进程只会读到替换前或替换后的完整文件；内存文件系统把条目挪到新路径；裸机以读出、写入、删除旧文件代替。标准库的原子写文件、原子写文件字节串先写同目录临时文件再用它改名，编译缓存靠它让几个构建进程共用同一缓存目录。
- **空路径**（2026-10-26 加，议题 658）：长度为零的路径一律指“不存在”，与 POSIX 的 ENOENT 一致。原生执行器的 `规范路径` 遇空路径返回专用负码「空路径码」（−2），别的失败（路径过长）照旧返回 −1，各文件原语据码分办：空路径报不存在，过长的路径报参数无效。空路径的答复：`实有`、`为箧`、`为卷` 答阴，改时得零，卷大小、卷大小长、问权、卷号与改时纳各得负一，卷占得负三，列目录得空列，读文件抛出“读文件失败：路径：错误码 44”；写文件与附帛抛出“写文件失败：路径：不存在”；焚与更名抛出“……错误码 44”，都可以「姑试」接住；置箧、改权、删箧与切换目录返回非零错误码。裸机初始任务走同一份 `规范路径`，整文件读写抛出可接的豫言异常。Node 工具宿主用 `fs` 的同名函数，空路径同样报 ENOENT。豫寓藏书（文件接口）另以空路径指授权根，属另一套接口。
- **读文件、删除、改名与写文件失败**（2026-10-26 加，议题 723）：整读文件（`阅`、`阅帛`，原语 28、29，以及 `阅帛片` 的读文件一段）、删除（32）、改名（180）与写文件（`著`、`著帛` 30、31、`附帛` 258）失败时，各宿主都报成可接的豫言异常，消息与原生执行器同文：读文件为“读文件失败：路径：错误码 码”，删除为“删除文件失败：路径：错误码 码”，改名为“改名失败：旧路径 → 新路径：错误码 码”，写文件与附帛为“写文件失败：路径：原因”，原因取底层状态码的说明文字（如“是目录”“无空间（磁盘已满或文件个数已达上限）”“无权限”，见边界胶水的 `底码说明`）。原生执行器、裸机初始任务（写文件由「本地写文件或祸」查码）、Node 工具宿主、浏览器编译宿主与浏览器构建工作线程一致，客体的「姑试」接得住；没被接住时由顶层未捕获处理器印“未捕捉的豫言异常：”加消息并以一退出（2026-10-26 前原生、诺驿、浏览器三处把读、删、改名、写文件的失败直接抛出边界或印字后退出，豫言接不住）。Node 工具宿主按错误的符号名（ENOENT 等）换成底层状态码，与平台无关；浏览器编译宿主按内存文件系统的错误码（不存在 44）换算；浏览器构建工作线程把主线程答复里带来的底层状态码原样成文。
- **设执行位**：把文件的权限设成所有者可读写执行、其余可读执行（0o755）。Node 工具宿主用 `fs.chmodSync`；原生执行器在 macOS 与 Linux 上都先受界打开父目录再用 `fchmodat`；裸机与浏览器编译宿主的内存文件系统里文件一律可执行，直接成功；其余 JS 宿主给桩。

- **问主机名**（2026-10-23 加）：返回主机全名，不截域名，调用者自己截到第一个点；取不到为空串。Linux 上原生执行器读 `/proc/sys/kernel/hostname` 并去掉行尾换行；macOS 上经 `sysctlbyname` 取 `kern.hostname` 并去掉末尾的零字节；Node 工具宿主用 `os.hostname()`。轩窗与裸机返回空串（待办事项：轩窗改用 GetComputerNameExW，裸机由内核记主机名），其余宿主给桩。
- **问号实占**（2026-10-25 加，提案 00056）：给一个进程号，返回这个进程的实占字节数（六十四位，装箱）；进程不存在、不是同一用户、平台不支持时返回负一。Linux 上原生执行器读 `/proc/<号>/status` 的 `VmRSS` 加 `VmSwap`（千字节乘 1024，原语 291）；macOS 上取 `proc_pid_rusage` 的 `ri_phys_footprint`（偏移 72 的八字节，与活动监视器“内存”列同口径）。裸机、轩窗与各 JS 宿主返回负一。行在用它在门口按进程号量本机各豫言进程，不再起 `ps`。
- **问号父**（2026-10-25 加，提案 00056）：给一个进程号，返回父进程号；进程不存在或平台不支持时返回负一。Linux 上原生执行器读 `/proc/<号>/stat` 第四栏（第二栏程序名在括号里、可能含空格与右括号，从最后一个右括号往后数，原语 292）；macOS 上取 `kinfo_proc` 偏移 560 的 `e_ppid`。裸机、轩窗与各 JS 宿主返回负一。行在按它把子孙归到最上层的登记任务上。
- **问己时**（2026-10-28 加）：读本进程从启动到此刻累计用掉的处理器时间，用户态与内核态分开，各以微秒计，返回（用户微秒，内核微秒）。原生执行器发 `getrusage(RUSAGE_SELF, 暂存)`（原语 313）：Linux 第 98 号系统调用（x86-64）、第 165 号（ARM64），macOS 经 libSystem 的 `getrusage`；结构前两段 `ru_utime`、`ru_stime` 各是「八字节秒 + 微秒」，秒在偏移 0 与 16、微秒在偏移 8 与 24。诺驿宿主用 Node 的 `process.cpuUsage()`（微秒）。裸机、轩窗、浏览器与云工没有这个数，返回（−1，−1）。这个数只增不减，量具拿两刻相减给每段报 CPU 时间。
- **问己配**（2026-10-28 加）：读本进程从启动到此刻累计分配的字节数（原语 314）。口径是执行器回收堆：每次回收把这一轮的分配计并进累计，所以只增不减；原生（六十四位与三十二位）与裸机都有。诺驿、浏览器与云工的程序不经执行器跑，返回 −1。量具拿两刻相减给每段报分配字节。
- **辞附庸**（2026-10-25 加，提案 00056）：撤掉本进程的附庸、仍留在行在里：当前目录与程序名换回宿主路径，环境块里去掉 `豫言附庸`、改设 `豫言全宿主=1`，此后起的子程序照常加入行在、看到的是宿主路径；行在的连接不关。原生执行器上成功返回阳，没开附庸也没加入行在返回阴，设了虚根（`豫言根目录`）时不做、返回阴；裸机、轩窗与各 JS 宿主返回阴。构建类命令据此登记不附庸，受司阍与仓管。
- **辞附庸由**（2026-10-26 加，议题 #802）：同「辞附庸」撤掉本进程的附庸、仍留在行在里，返回缘由码而不是阳阴：0 成；1 不认（不是林檎、林纳原生）；2 设了虚根（豫言根目录），不撤；3 没加入行在（行在态三）；4 连不上行在（态二时先再试一次加入，仍不成）；5 撤了附庸，但环境块放不下“豫言全宿主=1”。调用方据此分办：只有“不认”才辞出行在，未入、连断只说明缘由。诺驿、浏览器与云工的宿主答 1（不认）。
- **定缺存**（2026-10-25 加，提案 00056 第三期）：给本程序选缺存的办法——零窖、一候、二止，记进执行器的状态格，此后按块向行在领内存时用（见[客体二号说明](../裸机/客体二号/说明.汉语.md)的“仓与领存”）。林檎与林纳原生返回阳，法不在零至二之间返回阴；裸机、轩窗与各 JS 宿主没有仓，返回阴。
- **遣使于境离**（2026-10-26 加，议题 #654）：参数与返回同「遣使于境」（程序名、参数列、工作目录、环境块），子进程在新会话中运行：林檎与林纳原生上执行器在子进程执行程序之前调 setsid，子进程自成会话与进程组。不走常驻工作者；裸机、轩窗、诺驿、浏览器与云工返回负五十八（原语 297）。构建服务（将作）用它起代役：代役自成一组，此后起的常驻工作者、原生产物子进程与它们的分片工作者都继承这个组。
- **散组**（2026-10-26 加，议题 #654）：以本进程的进程号为组号，向那个进程组发 SIGTERM，把本进程与它起的常驻工作者、原生产物子进程、分片工作者一并召回。代役由将作以「遣使于境离」起，组号就是它的进程号，这一发正好带走整棵树；本进程不是组长时那个组不存在，信号什么也杀不到，返回二十九；只有林檎与林纳原生实现（原语 298），裸机、轩窗、诺驿、浏览器与云工返回负五十八。代役退出前召回在跑的子进程、关连接，再调它，忙着的常驻工作者与分片工作者不再等手上的任务做完。
- **遣信**（2026-10-27 加，议题 #1024）：按本实例登记的异步子进程句柄发一个信号，返回（结果码，进程号）：零为已发出或子进程早已退出，八句柄无效（含常驻工作进程），二十九信号发不出去，五十八这个宿主没有这种信号；进程号取不到时为负一。十五是 SIGTERM、九是 SIGKILL，林檎与林纳原生按号发一至一百二十七号信号，子进程已经不在（系统调用答 ESRCH）也算零。轩窗没有 SIGTERM，执行器也不装控制台事件处理函数，后台服务又带 DETACHED_PROCESS 脱开控制台、收不到 GenerateConsoleCtrlEvent，九与十五都按进程句柄硬止（原语 307），退出码一百三十七、一百四十三（一百二十八加信号号），其余答五十八；豫言操作系统按子表项取内核任务号，九与十五都经内核服务 11「终止」结束这个任务（内核没有“请求结束”的通道，退出码一百四十三），其余答五十八；诺驿、浏览器与云工答五十八。将作（构建服务）用它收掉过了截止还不退的代役：先发 SIGTERM，五秒后还不退再发 SIGKILL（见[豫构包说明](../../应用/豫构/包说明.汉语.md)的将作一节）。
- **获取随机整数**：上界不大于零时中止；取 64 位安全随机数对上界取余，不保证均匀。裸机执行器读处理器随机指令（RDRAND、RNDR），处理器没有时（QEMU 默认的 qemu64、较老的实机）退用任务号、时钟与调用计数混合的散列（获取随机小数同此，2026-10-11 起）；安全随机字节串先用处理器随机指令，没有时（2026-10-14 起）改用执行器的熵池：混进计时抖动、中断与按键收包的时刻、实时钟与数据盘上的种子文件 /系统/随机种子，经沙256 导出（见 裸机/客体二号/说明.汉语.md“后备熵源”）。
- **获取环境变量**：只见已授权的名字。Node 工具宿主视为全部授权；Node 应用宿主按 `--允许环境`；编译宿主、浏览器与云工不向标准库授予任何名字，一律当作不存在。
- **小数转字符串**（小数表示）：同 C 的 `%f`，六位小数；-0 写作 `-0.000000`，绝对值不小于 1e21 的展开成整数，非数写 `nan`，无穷写 `inf`、`-inf`。
- **小数精确表示**：同 C 的 `%.17g`，17 位有效数字、去掉尾随的零；-0 写作 `-0`，非有限值同上。编译器的中间产物序列化依赖它。
- **字符串转小数**（理解小数）：同 C 的 `strtod`：跳过开头空白，取最长的可转前缀，认 `inf`、`infinity`、`nan`（不分大小写，可带符号），没有可转的得 0，超出范围得无穷。
- **云工通用句柄桥**：全局句柄、构造对象、调用全局及其安全版只许取白名单里的全局，与 Node 应用宿主相同，另加 Request、Promise、Error、caches、scheduler；fetch、WebSocket、EventSource、Function、WebAssembly、globalThis 等不在表内，不能借它绕过外发来源许可与绑定授权；网页上游的动态公网 HTTPS 另用专用原语 云工公网请求发起：许可 OUTBOUND_ORIGINS 含 https://* 时才放行，宿主核对 https、无凭据并强制 redirect 为 manual（见云工宿主说明）。

理解整数、字节转字符串、字节串单字节与字节串空已改为编译器内建，语义见[执行与编译](../../应用/豫言编译器/文档/语言技术规范/执行与编译.汉语.md)编四。
