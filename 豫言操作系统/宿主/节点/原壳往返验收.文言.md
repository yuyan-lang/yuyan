# 原壳与桌面往返验收

此为实Node原壳入用户态桌面而归原会话之验录。验存正式原壳源码，构建时复制为临时包入口，绑定旧基础、字体、文件与显示适配；程序犹先入命令行，桌面以正式指令启之。临时包惟供验收，正式裸机入口未改。

临时目录为 `/private/tmp/yy原壳绑定草稿`。包名循“豫言裸机”，零点一版，可执行入口“入口”，依标准库、壳核心与用户态桌面，具双语说明。复制 `豫言操作系统/裸机/壳/壳。豫` 为入口，复制 `壳/交互输入。豫` 与 `宿主服务。接口。豫` 于同名之处；三源逐字节相比皆同。

以 `yy双宿主构建.wasm --自动 节点 /private/tmp/yy原壳绑定草稿 yy原壳绑定节点发行 --包根 库 --编译器 ./yy4_bs.wasm` 构建，四公接口之绑定与装载核对皆过。旧后台验收脚本以此发行行于实PTY，参依次为发行目录、原生依赖目录、授权资源目录、`yy原壳完整往返.ppm` 与“原壳”，用实SDL隐窗，不夺前台。

同一PTY会话入 `「回显」于「进入前」`，出“进入前”；复入 `「图形」`，实桌面得授目录而绘之。后台之验点文件钮，览实说明文，复点返回钮。原壳复显“壳>”；入 `「回显」于「返回后」`，出“返回后”，复入 `「退出」`，出“壳已退出”。全进程退出码零，实文件服务之调与窗归还之断言皆过，六次提交画面。`yy原壳完整往返.png` 存说明正文之预览。

此证验Node、实PTY与SDL之事注入。待办事项：正式发行入口、逐键边界与历史状态专验、浏览器原壳往返、Windows/Linux与原生系统各验、旧壳平台命令再析。临时包未足代正式入口与长久内核弱绑定之设计。
