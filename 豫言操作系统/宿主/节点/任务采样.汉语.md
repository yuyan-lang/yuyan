# 任务采样

这是任务管理器所需的节点宿主真实采样能力。`创建任务采样` 为当前宿主进程建立采样器，`采样` 返回进程标识、应用名称、统计范围、单调采样时间、处理器万分比、常驻内存字节及已用堆字节。CPU 占用按两次采样之间的用户与系统 CPU 时间之和除以墙时计算，一个核心满载为一万，多核可超过一万。

统计范围是当前宿主进程，同进程中的窗口共享该范围；这些数字不能归给单个窗口。零采样间隔用负一表示处理器指标不可用。真实忙碌进程测试验证了采样时间递增、处理器活动和内存数据。公共豫言任务监测接口及节点适配已接入，并内联到正式发行启动文件。实时更新事件、任务管理器窗口及其他平台实际采样仍未接入。
