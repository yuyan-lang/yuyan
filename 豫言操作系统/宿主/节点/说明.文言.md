# 节点应用宿主

## 设计之旨（必守）

二〇二六年十月六日用户定之，凡改此宿主者皆须守（AGENTS.md「诺节（Node）后端」亦列为必守）：

1. **诺节惟为胶**：诺节乃豫言诸后端之一（尚有原生、浏览器、云工、裸机）。诺节所需系统之能（显示、剪贴板、图形处理器之属），皆调我以豫言所书之原生之库，与原生执行器共一实；毋新增诺节专用之适配（`豫言操作系统/适配/*节点`）及诺节独有之能。
2. **毋引第三方之库**：毋用 npm 之包、SDL、Dawn 之属；惟用诺节内置之模（若 `node:ffi`）、操作系统自带之系统库，及豫言自有之库。
3. **原生之速为先**：性能之优以原生为先，V8 惟为对照之基，毋为诺节之速而损原生。
4. **以诺节为准**：原生与诺节所行不一，是原生犹未善也；以诺节为参照察原生之失，令原生齐之。
5. **诸端同能**：惟用豫言自有之库，则诺节与原生之能自同；毋于诺节为原生所无之能。

今况与迁：下文“显示与图形”犹赖 npm 之包 `@kmamal/sdl`、`@kmamal/gpu`，今诺节诸适配亦旧法也；皆惟修而不扩，渐改为调我原生之库（若原生显示之库）。原生生成器当能出可为 `node:ffi` 所载之动态库，此为待办之事。

## 旧有之说

字体之能又识资名 `字体.ttf`，惟读程序成物之目所附此一文，拒符号之链，不授同目余文。原壳桌面之成物附免费文楷与 `字体许可证.txt`；客以“文楷”族名用旧公字体接口。三标准族犹用旧系统字体候选。

终端浏览器之发行包默认通诸 HTTP(S) 源，行时毋须 `--允许源`。余应用仍循逐源之授；显示面仍以 `--授权显示面` 授之。

此为路一行于桌面与服务器之宿主。`yy双宿主构建 --自动 节点` 编客为 `程序.wasm`，又出独文 `启动.mjs` 与 `清单.json`。所用 Node 须二十六版或更新，且能行 WebAssembly JSPI。

于仓根造发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 惟授读；`--授权文件 路径` 可自文载所授。宿主之选在 `--` 前，其后诸参归客。目录、源、环境变量未授者皆闭。启时先验程序摘要、Wasm 出入、接口之版与签名，乃行客。宿主所能见 `宿主支持清单.tsv`；基础、文件、网络、张量计算、张量文件、显示、图形处理器、图形显示、字体诸适配各见 `../../适配/基础节点/说明.文言.md`、`../../适配/文件节点/说明.文言.md`、`../../适配/网络节点/说明.文言.md`、`../../适配/张量计算节点/说明.文言.md`、`../../适配/张量文件节点/说明.文言.md`、`../../适配/显示节点/说明.文言.md`、`../../适配/图形处理器节点/说明.文言.md`、`../../适配/图形显示节点/说明.文言.md`、`../../适配/字体诺节/说明.文言.md`。张量之原语书于此目之 `张量.mjs`，显示、图形与字体之原语书于此目之 `图形.mjs`（与浏览器宿主共用 `../浏览器/图形.mjs` 之显示面表与图形之能），构建器并三共用之模内联于 `启动.mjs`；工作线程之源亦以其中诸函之文拼之，发行包不别带文件。

`--张量线程数 N` 定张量计算所用之线程数（兼主线）：缺省取 `os.availableParallelism()`，上限二百五十六（逾则以二百五十六计），一则不起工作线程。工作线程初须并行乃起，不留进程；矩阵乘与注意力依工之多寡定实用之线，工少则惟主线。主机别有重负之时，线满诸核或反迟（被夺之线执已领之块，拖住其算），可减此数，如 `--张量线程数 12`。

`--张量后端 名` 为验用之选，强令张量计算之适配惟用此后端，名为 `中央处理器`、`网页图算`、`金属`、`统算` 之一（余名则载败）。缺则适配依客加速之求自择。今有中央处理器、金属与统算三后端：金属惟于苹果之系统、统算惟于装英伟达驱动（libcuda.so.1）之林纳克斯，且皆须予 `--允许系统库调用` 乃可用；指不可用者则 `取得张量上下文` 返 `资源暂不可用`。一致之验默以之定于中央处理器，令诸台之出同；验加速之后端则驱动另予 `--张量后端 金属` 或 `--张量后端 统算`，予 `--张量后端 自动` 则不指后端而惟予 `--允许系统库调用`，以验自择（见 `一致性验证/说明.文言.md`）。

[一致性之验](一致性验证/说明.文言.md)及发行包装载、授权、文件、网络、张量计算、张量文件与拒载诸事。

标准库与构建基础之带型导入，经共用胶水 `../网页汇编/边界.mjs` 接之：此宿主供标准库二十四，及构建基础之存包上下文、问面板可用、今程序与指定文 SHA-256，皆同步之实，不套 JSPI，余皆为桩。装载之核惟放标准库、构建基础、平台接口包、应用所需接口包之带型导入，不合者一并列报。`_start` 之后，客实「启动程序」者（导出 `豫言操作系统启动/启动程序`，见网五），此宿主经 JSPI 调之一次；旧产物无此导出，惟行 `_start`。诸宿主各供何者与同一之义见[标准库之宿主服务](../标准库宿主.文言.md)。

平台接口之包之带型导入亦经此胶水接之：此宿主供「诺节宿主」（`库/诺节宿主`）六十九尽——张量原语五十九、文件原语五、网络原语二，及显示、图形、字体三依操作名分派之原语；「系统库调用」十八；「云工宿主」中时、随机、志、摘要、网址、规整、压缩诸适配所需之通用原语四十六；「安全外壳密码」之求SHA256。余平台之函（云工宿主之余、浏览器宿主、中央张量宿主等）给桩。此诸实由以旧原语名为键之能表派生（`应用宿主.mjs` 之 `派生平台实现`，函名与旧原语名之对照取 `../云工/值桥.mjs` 之 `平台导入旧名`）：小数之果去其 `{小数}` 之壳，系统库调用三调原语之外部值列展为数列；惟网络发送、显示、图形与十三异步之云工通用原语套 JSPI，张量、文件诸原语同步径调。

**显示与图形**（显示、图形处理器、图形显示三接口）：

- `--授权显示面 名=宽x高`（可重书）授显示面，宽高为 SDL 窗之点数（正整数，不逾六万五千五百三十六）；应用初 `取得已授显示面 名` 乃开窗。名未授者返 `未获授权`。
- `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）：载 SDL 之前设 `SDL_MAC_BACKGROUND_APP=1`（于 macOS 为后台之应用，无 Dock 之标，不激），窗隐而建，不夺前台。隐窗之上像素之交与 WebGPU 之呈照常而返，自动之验用之；惟人工验输入之事乃开可见之窗。SDL 二点三二点八无“显而不激”之窗提示（`SDL_WINDOW_ACTIVATE_WHEN_SHOWN` 乃 SDL 三之提示）。
- 显示须 npm 包 `@kmamal/sdl`，图形处理器须 `@kmamal/gpu`（Dawn），图形显示二者皆须。二者不随发行包而分，应用初用乃载，依次自启动文件之目、当前之目、`--原生依赖目录 目`（或环境变量 `YY_NODE_NATIVE_DIR`，二者并给则从其选）依 Node 之 require 之法寻之，目指含 `node_modules` 之层。不得则 `取得已授显示面`、`取得图形设备` 返 `资源暂不可用`，并于标准误一告之；余能不受其扰。安之：`npm install --prefix 目 @kmamal/sdl @kmamal/gpu`（npm 十一缺省不行安装之本：macOS arm64 径用包中自带之二进制，他台须先 `npm approve-scripts @kmamal/sdl @kmamal/gpu` 而重安，乃下本台预编之文）。
- 应用既终，宿主闭诸窗、释诸设备、销 Dawn 之例，进程随即而退。

```sh
node dist/应用名/启动.mjs --授权显示面 主画面=640x480 --原生依赖目录 ~/豫言原生依赖 -- 应用参数
```

待办事项：@kmamal/gpu 零点二点一每约百毫秒乃理异步之回调一次，每 `提交图形命令`、建物与读回至少候此（弹误域），交互之渲染每秒约十帧而已；须改 Dawn 之轮询或易他构。

**系统库调用**（惟供适配与系统库，不入公共之接口）：

- `外部库.mjs` 本诺节之 `node:ffi`（实验之能，须带 `--experimental-ffi`）供系统库调用之原语（导入模块「系统库调用」之十八带型导入，能表之旧名冠 `豫言_节点_外部库`）：开动态之库、取符号之址、依签名而调、原生之存之分释、读写与抄、C 文，及取张量之存（SharedArrayBuffer）之原生址与视图（元类之号、起、形、步，起与步以元计；视图惟读，不须许）。豫言之封装为 `库/系统库调用`，金属之算之封装为 `库/金属`，统算（CUDA）驱动之口之封装为 `库/统算`。构建器亦内联 `外部库.mjs` 于 `启动.mjs`。
- 应用宿主默不开：系统库之调能行任意原生之码，越目录、网络诸授，故须予宿主之选 `--允许系统库调用`。予此选、程序用系统库之调（导「系统库调用」）而诺节未带 `--experimental-ffi`，宿主带此旗以同参自重启（承三流，退码取子进程者）。未予此选或诺节不具 `node:ffi`，则「外部库可用原语」（旧名 `豫言_节点_外部库可用`）为假，适配当退就他法。此为定规，张量计算之金属与统算后端循之：未予此选则二者皆视为不可用，张量自择后端时退就中央处理器；予此选而有可用之加速后端，则不限、偏好与必须加速皆择之（苹果则金属，林纳克斯则统算）；予 `--张量后端 金属` 或 `--张量后端 统算` 而未予此选，取张量之境则返资源暂不可用，宿主启时于标准错误示须加 `--允许系统库调用`。
- `底层宿主.cjs` 行底层（无回收）之模：模导内存者，依导入段之限建之（可共享、可六十四位址），导「数学」「诺节」之函者由之供，出「工作线程」者先起数工作线程共一共享之内存（环境变量 `YY_底层线程数`，缺则可用之处理器数减一），乃调 `_start`；`宿主.cjs` 遇此等模则交之，Wasm 工具链之包无此文则照旧行之。详见 `应用/豫言编译器/文档/底层模式.文言.md`。
- 带型之宿主导入（见 `应用/豫言编译器/文档/语言技术规范/网页汇编接口.文言.md` 网五）：`宿主.cjs` 经共用胶水 `../网页汇编/边界.mjs`（工具链之包置于宿主之旁）依模之「豫言边界」段转值。实导入模块「标准库」之六十五函与「构建基础」之五函（存包上下文、问面板可用、绘面板、今程序与指定文 SHA-256）（袭旧原语：串参转为 Buffer，列果惟返数组），惟读取终端按键、出入终端原始输入之式、二拼音之转与绘监视面板未实；又实平台接口之包「系统库调用」之十八与「安全外壳密码」之九（亦袭旧原语，小数之果去其 `{小数}` 之壳，三调原语之外部值列展为数列；工具链之包无 `外部库.mjs` 则系统库调用惟给桩）；又有边界回环测试之夹具 `边界回环.cjs`（导入模块「测试」，惟仓中有之）。未实之带型导入给桩，调之乃报“接口函数未绑定：模块.字段”。旧之通调 `yuyan:gc-host/v1.call` 已删，第二步以前所编、犹导之之旧 `.wasm` 工具，须以今编译器重建。`_start` 之后有 `豫言操作系统启动/启动程序` 之导出，则同步调之（经胶水之 `造边界导出`）。WasmGC 之程（出 `yy_tuple` 或带「豫言边界」之段）不交 `底层宿主.cjs`。
- 工具宿主 `宿主.cjs` 恒开：为客之工作线程另带 `--experimental-ffi`（V8 引擎之旗通于全进程，不传于工作线程）；Wasm 工具链包之宿主无 `外部库.mjs` 则惟供报不可用之 `豫言_节点_外部库可用`；旧版 yy双宿主构建 所生、未内联 `外部库.mjs` 之 `启动.mjs` 亦然。
- 签名之文：返类一字、全角冒号、诸参之字，若 `址：址址长`。类字：无（惟用于返）、爻、字（八位无号）、整（三十二位有号）、长（六十四位有号）、址（指针）、单、双。函之物依“址＋签名”存之；`node:ffi` 一库之物同名惟许一签，故每（库，签名）各开一库之物。惟认经“取符号”所登之址。整数与指针于豫言皆六十四位有号之整数。布尔之返惟取返值最低之字，返 int 之 C 函当书“整”（glibc 之 `isalpha` 返千零二十四之类，其低字为零）。macOS arm64（诺节 26.3.0）与林纳克斯 x86-64（诺节 26.10.0）皆已验，林纳克斯亦自进程之主象取 C 库之函。
- 诺节载 `node:ffi` 时之“实验之能”之警，宿主拦之，不书于标准误。
- 待办事项：结构按值而传（arm64 上逾十六字之结构，调者传指副本之址，书为“址”即可；余未支）；回调（`node:ffi` 之回调惟可于造之之线程调之）；可变参之函；任意函指；视窗。
