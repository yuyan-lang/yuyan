# 节点应用宿主

此为路一行于桌面与服务器之宿主。`yy双宿主构建 --自动 节点` 编客为 `程序.wasm`，又出独文 `启动.mjs` 与 `清单.json`。所用 Node 须二十六版或更新，且能行 WebAssembly JSPI。

于仓根造发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 惟授读；`--授权文件 路径` 可自文载所授。宿主之选在 `--` 前，其后诸参归客。目录、源、环境变量未授者皆闭。启时先验程序摘要、Wasm 出入、接口之版与规范摘要，乃行客。宿主所能见 `宿主支持清单.tsv`；基础、文件、网络诸适配各见 `../../适配/基础节点/说明.文言.md`、`../../适配/文件节点/说明.文言.md`、`../../适配/网络节点/说明.文言.md`。
