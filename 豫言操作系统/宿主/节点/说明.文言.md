# 节点应用宿主

此为路一行于桌面与服务器之宿主。`yy双宿主构建 --自动 节点` 编客为 `程序.wasm`，又出独文 `启动.mjs` 与 `清单.json`。所用 Node 须二十六版或更新，且能行 WebAssembly JSPI。

于仓根造发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 惟授读；`--授权文件 路径` 可自文载所授。宿主之选在 `--` 前，其后诸参归客。目录、源、环境变量未授者皆闭。启时先验程序摘要、Wasm 出入、接口之版与签名，乃行客。宿主所能见 `宿主支持清单.tsv`；基础、文件、网络、张量计算、张量文件、显示、图形处理器、图形显示诸适配各见 `../../适配/基础节点/说明.文言.md`、`../../适配/文件节点/说明.文言.md`、`../../适配/网络节点/说明.文言.md`、`../../适配/张量计算节点/说明.文言.md`、`../../适配/张量文件节点/说明.文言.md`、`../../适配/显示节点/说明.文言.md`、`../../适配/图形处理器节点/说明.文言.md`、`../../适配/图形显示节点/说明.文言.md`。张量之原语书于此目之 `张量.mjs`，显示与图形之原语书于此目之 `图形.mjs`（与浏览器宿主共用 `../浏览器/图形.mjs` 之显示面表与图形之能），构建器并三共用之模内联于 `启动.mjs`；工作线程之源亦以其中诸函之文拼之，发行包不别带文件。

`--张量线程数 N` 定张量计算所用之线程数（兼主线）：缺省取 `os.availableParallelism()`，上限二百五十六（逾则以二百五十六计），一则不起工作线程。工作线程初须并行乃起，不留进程；矩阵乘与注意力依工之多寡定实用之线，工少则惟主线。主机别有重负之时，线满诸核或反迟（被夺之线执已领之块，拖住其算），可减此数，如 `--张量线程数 12`。

`--张量后端 名` 为验用之选，强令张量计算之适配惟用此后端，名为 `中央处理器`、`网页图算`、`金属`、`统算` 之一（余名则载败）。缺则适配依客加速之求自择。今惟中央处理器，指余三者则 `取得张量上下文` 返 `资源暂不可用`；一致之验以之定于中央处理器，令诸台之出同。

[一致性之验](一致性验证/说明.文言.md)及发行包装载、授权、文件、网络、张量计算、张量文件与拒载诸事。

**显示与图形**（显示、图形处理器、图形显示三接口）：

- `--授权显示面 名=宽x高`（可重书）授显示面，宽高为 SDL 窗之点数（正整数，不逾六万五千五百三十六）；应用初 `取得已授显示面 名` 乃开窗。名未授者返 `未获授权`。
- `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）：载 SDL 之前设 `SDL_MAC_BACKGROUND_APP=1`（于 macOS 为后台之应用，无 Dock 之标，不激），窗隐而建，不夺前台。隐窗之上像素之交与 WebGPU 之呈照常而返，自动之验用之；惟人工验输入之事乃开可见之窗。SDL 二点三二点八无“显而不激”之窗提示（`SDL_WINDOW_ACTIVATE_WHEN_SHOWN` 乃 SDL 三之提示）。
- 显示须 npm 包 `@kmamal/sdl`，图形处理器须 `@kmamal/gpu`（Dawn），图形显示二者皆须。二者不随发行包而分，应用初用乃载，依次自启动文件之目、当前之目、`--原生依赖目录 目`（或环境变量 `YY_NODE_NATIVE_DIR`，二者并给则从其选）依 Node 之 require 之法寻之，目指含 `node_modules` 之层。不得则 `取得已授显示面`、`取得图形设备` 返 `资源暂不可用`，并于标准误一告之；余能不受其扰。安之：`npm install --prefix 目 @kmamal/sdl @kmamal/gpu`（npm 十一缺省不行安装之本：macOS arm64 径用包中自带之二进制，他台须先 `npm approve-scripts @kmamal/sdl @kmamal/gpu` 而重安，乃下本台预编之文）。
- 应用既终，宿主闭诸窗、释诸设备、销 Dawn 之例，进程随即而退。

```sh
node dist/应用名/启动.mjs --授权显示面 主画面=640x480 --原生依赖目录 ~/豫言原生依赖 -- 应用参数
```

待办事项：@kmamal/gpu 零点二点一每约百毫秒乃理异步之回调一次，每 `提交图形命令`、建物与读回至少候此（弹误域），交互之渲染每秒约十帧而已；须改 Dawn 之轮询或易他构。

**系统库调用**（惟供适配与系统库，不入公共之接口）：

- `外部库.mjs` 本诺节之 `node:ffi`（实验之能，须带 `--experimental-ffi`）供系统库调用之原语，外调名冠 `豫言_节点_外部库`：开动态之库、取符号之址、依签名而调、原生之存之分释、读写与抄、C 文，及取张量之存（SharedArrayBuffer）之原生址。豫言之封装为 `库/系统库调用`，金属之算之封装为 `库/金属`。构建器亦内联 `外部库.mjs` 于 `启动.mjs`。
- 应用宿主默不开：系统库之调能行任意原生之码，越目录、网络诸授，故须予宿主之选 `--允许系统库调用`。予此选、程序有此诸外调名而诺节未带 `--experimental-ffi`，宿主带此旗以同参自重启（承三流，退码取子进程者）。未予此选或诺节不具 `node:ffi`，则 `豫言_节点_外部库可用` 为假，适配当退就他法。
- 工具宿主 `宿主.cjs` 恒开：为客之工作线程另带 `--experimental-ffi`（V8 引擎之旗通于全进程，不传于工作线程）；Wasm 工具链包之宿主无 `外部库.mjs` 则不供此诸原语。
- 签名之文：返类一字、全角冒号、诸参之字，若 `址：址址长`。类字：无（惟用于返）、爻、字（八位无号）、整（三十二位有号）、长（六十四位有号）、址（指针）、单、双。函之物依“址＋签名”存之；`node:ffi` 一库之物同名惟许一签，故每（库，签名）各开一库之物。惟认经“取符号”所登之址。整数与指针于豫言皆六十四位有号之整数。
- 诺节载 `node:ffi` 时之“实验之能”之警，宿主拦之，不书于标准误。
- 待办事项：结构按值而传（arm64 上逾十六字之结构，调者传指副本之址，书为“址”即可；余未支）；回调（`node:ffi` 之回调惟可于造之之线程调之）；可变参之函；任意函指；视窗。

```sh
node dist/应用名/启动.mjs --允许系统库调用 -- 应用参数
```
