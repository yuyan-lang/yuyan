# Node 宿主一致性验证

这是路一 Node 发行包的本机验收。先在仓库根目录构建 `yy双宿主构建.wasm`，再构建验证应用并运行驱动：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/宿主/节点/一致性验证/应用 dist/节点一致性
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性
```

驱动在本机启动 HTTP 服务并创建临时文件夹具，故运行环境须允许本机回环监听。它逐行比较标准输出和标准错误，检查文件写入及七项装载拒绝情形。张量计算用例在豫言里按规范容差判定浮点结果，只打印“通过/失败”或精确的整数结果；张量文件用例读取夹具 `甲/张量.bin`（100 字节）。期望输出分别存于 `期望输出.txt`、`期望错误.txt`；确认行为变更后才以 `--记录` 更新期望。2026-09-29 重建同一发行包后，macOS arm64（Node 26.3.0）、Linux arm64 与 x86-64（均为 Node 26.10.0）各通过 88/88 项；Linux 两架构在只读挂载仓库的容器内运行。同日加入张量计算与张量文件用例后共 121 项，macOS arm64（Node 26.3.0）通过 121/121；新版在 Linux 与 Windows 仍待验收。9 月 30 日张量计算接口升到 0.2.0，加入后端用例（驱动以宿主选项 `--张量后端 中央处理器` 运行，各平台输出因此相同）后共 122 项，macOS arm64（Node 26.3.0）通过 122/122；同日升到 0.3.0，加入跨步视图、新增逐元运算、按行累加与随机填充用例后共 130 项，通过 130/130；升到 0.4.0，加入混合专家与线性注意力用例后共 135 项，通过 135/135；再加训练提速（按轴归约、按行最大下标、就地线性组合、亚当更新）用例后共 138 项，通过 138/138。

验收加速后端时给驱动加 `--张量后端 名`：驱动改用该后端运行应用（不是中央处理器时同时给 `--允许系统库调用`）。这时「张量·后端」一行按设计与期望不同，其余各行应当相同。

```sh
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性 --张量后端 金属
```

2026-09-30 张量计算接入金属后端后，macOS arm64（Apple M5 Pro，Node 26.3.0）上缺省运行通过 138/138；以 `--张量后端 金属` 运行通过 137/138，唯一不同的是「张量·后端」一行（金属/阳/已得金属/已得金属）。临时打点确认各张量用例里矩阵乘（单精度与块量化八位）、逐元二元、逐元一元、逐元标量、软最大、末维求和、末维最大、均方根归一、旋转位置编码、取行、按行累加、按轴求和、按轴最大、填充常数、紧致化、写入视图、切片、转置、拼接都在 GPU 上执行；超块量化（Q4_K、Q6_K）的取行与矩阵乘、半精度权重的均方根归一交给中央处理器。

同日晚加「张量·输出池与跨步视图」用例：加速上下文把 GPU 结果的存储留给后来的结果（输出池），宿主新建张量的不连续跨步视图不能混进池里；用例反复制造入池失败的 GPU 结果、同字节数的宿主张量与其转置视图，旧版适配在本机三次运行都因地址复用报“张量计算：改形：甲须连续，先紧致化”而终止。修复后缺省运行通过 139/139，以 `--张量后端 金属` 运行通过 138/139（唯「张量·后端」一行不同）。

同日夜加「异常·挂起前后」用例：字符串异常改用 Wasm 原生异常后，验证 JSPI 挂起点（密码摘要是异步能力）前后的抛出与捕获——挂起后抛出、处理函数里先挂起再返回、内层处理函数挂起后再抛而由外层接住。共 140 项，macOS arm64（Node 26.3.0）缺省运行通过 140/140。

驱动另可给 `--张量后端 自动`：不指定后端、只给 `--允许系统库调用`，验收适配的自动选择——有加速后端时不限加速也用它，所以同样只有「张量·后端」一行不同。

```sh
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性 --张量后端 统算
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性 --张量后端 自动
```

2026-09-30 接入统算后端后，Linux x86-64（NVIDIA GeForce RTX 5090，Node 26.10.0）上缺省运行通过 138/138；`--张量后端 统算` 与 `--张量后端 自动` 都通过 137/138，唯一不同的是「张量·后端」一行（统算/阳/已得统算/已得统算）。同日 macOS arm64（Node 26.3.0）上缺省 138/138，`--张量后端 金属` 与 `--张量后端 自动` 都是 137/138（金属/阳/已得金属/已得金属）。
