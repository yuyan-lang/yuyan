# Node 宿主一致性验证

这是路一 Node 发行包的本机验收。先在仓库根目录构建 `yy双宿主构建.wasm`，再构建验证应用并运行驱动：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/宿主/节点/一致性验证/应用 dist/节点一致性
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性
```

驱动在本机启动 HTTP 服务并创建临时文件夹具，故运行环境须允许本机回环监听。它逐行比较标准输出和标准错误，检查文件写入及七项装载拒绝情形。期望输出分别存于 `期望输出.txt`、`期望错误.txt`；确认行为变更后才以 `--记录` 更新期望。2026-09-28 在 macOS arm64、Node 26.3.0 上通过 88/88 项；其他平台仍须各自运行同一发行包验收。
