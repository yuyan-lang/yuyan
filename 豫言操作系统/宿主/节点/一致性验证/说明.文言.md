# 节点宿主一致性之验

此为路一节点发行包之本机验收。先于仓根造 `yy双宿主构建.wasm`，次造验客而行驱动：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/宿主/节点/一致性验证/应用 dist/节点一致性
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性
```

驱动于本机起 HTTP 之服，造临时文件，故须许本机回环监听。逐行较标准出、标准误，验文件之写及七事之拒载。所期之出在 `期望输出.txt`、`期望错误.txt`；行为确改，乃以 `--记录` 更新。二〇二六年九月二十九日，重建同一发行包，而 macOS arm64（Node 26.3.0）、Linux arm64 与 x86-64（皆 Node 26.10.0）各八十八验皆过；Linux 二架构于仓库只读挂载之容器内行。Windows 犹待验收。
