# 节点宿主一致性之验

此为路一节点发行包之本机验收。先于仓根造 `yy双宿主构建.wasm`，次造验客而行驱动：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/宿主/节点/一致性验证/应用 dist/节点一致性
node 豫言操作系统/宿主/节点/一致性验证/运行.mjs dist/节点一致性
```

驱动于本机起 HTTP 之服，造临时文件，故须许本机回环监听。逐行较标准出、标准误，验文件之写及七事之拒载。张量计算之例于豫言中依规范之容差判浮点之果，惟书“通过/失败”或确然之整数；张量文件之例读夹具 `甲/张量.bin`（百字）。所期之出在 `期望输出.txt`、`期望错误.txt`；行为确改，乃以 `--记录` 更新。二〇二六年九月二十九日，重建同一发行包，而 macOS arm64（Node 26.3.0）、Linux arm64 与 x86-64（皆 Node 26.10.0）各八十八验皆过；Linux 二架构于仓库只读挂载之容器内行。同日增张量计算与张量文件之例，凡百二十一验，macOS arm64（Node 26.3.0）皆过；新版于 Linux 与 Windows 犹待验收。三十日张量计算之接口升至 0.2.0，增后端之例（驱动以宿主之选 `--张量后端 中央处理器` 行之，故诸台之出同），凡百二十二验，macOS arm64（Node 26.3.0）皆过。
