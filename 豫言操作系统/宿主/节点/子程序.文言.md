# 节点用户态子程序之能

此为公进程接口所需之节点宿主执行之能，在 `子程序.mjs`。今独立实现已过实节点子进程之验，犹未绑公豫言接口、启动诸参与原壳，不得据此谓原壳运行之令可用。

宿主以名预授节点发行入口、工作目录及定宿主参。客惟传程序名、参列、标准输入字节与环境名值对。入口以今节点程序行之，客参置 `--` 后；不调宿主壳。每调别造环境，不继父环境，不留前调之环境；环境名别须授，节点装载选项之环境拒之。

还状码、退出码、标准输出字节、标准错误字节与误辞。状零谓常终，退出码非零亦存输出；授权、输入、配额与启动之败分别报之。交换之限默认 16 MiB，时限出于宿主所授之配置，默认二分钟。待办事项：公接口、节点授权选项、浏览器不可用之适配、原壳迁调及异步取消。

验含中文标准输入、有空格之参、标准错误、环境逐调之隔、未授程序与环境、复环境名、非零退出与不存之工作目录。实 Wasm 子程序与图形往返，待公接口接后验之。
