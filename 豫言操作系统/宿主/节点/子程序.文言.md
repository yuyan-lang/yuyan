# 节点用户态子程序之能

此为公子程序接口之节点宿主执行之能，在 `子程序.mjs`。公接口与节点适配已接，以 `--授权子程序 名=启动文件路径` 授程序，以 `--允许环境 名` 授可传环境；犹未迁原壳，不得据此谓原壳运行之令可用。

宿主以名预授节点发行入口、工作目录及定宿主参。客惟传程序名、参列、标准输入字节与环境名值对。入口以今节点程序行之，客参置 `--` 后；不调宿主壳。每调别造环境，不继父环境，不留前调之环境；环境名别须授，节点装载选项之环境拒之。

还状码、退出码、标准输出字节、标准错误字节与误辞。状零谓常终，退出码非零亦存输出；授权、输入、配额与启动之败分别报之。交换之限默认 16 MiB，时限出于宿主所授之配置，默认二分钟。此调传入之环境名亦以宿主参授子程序，余目录、网络与程序之授不继。待办事项：浏览器不可用之适配、原壳迁调及异步取消。

验含中文标准输入、有空格之参、标准错误、环境逐调之隔、未授程序与环境、复环境名、非零退出与不存之工作目录。又以双宿主构建造父子两实 Wasm 发行：父循正式启动器调公接口，得子输出“甲 乙，丙”与“环境甲”，父发行装载之核亦过。此验不含子 Wasm 读标准输入；字节输入以实节点子进程验之。原壳迁调与图形往返犹待验。
