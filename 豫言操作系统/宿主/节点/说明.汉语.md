# Node 应用宿主

这是路一在桌面与服务器上的宿主。`yy双宿主构建 --自动 节点` 将应用编成 `程序.wasm`，并生成单文件 `启动.mjs` 与 `清单.json`。运行环境须为 Node 26 或更新版本，且须支持 WebAssembly JSPI。

在仓库根目录构建发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

运行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 只授读取；`--授权文件 路径` 可从文件载入授权。宿主选项写在 `--` 前，后续参数交给应用。未授的目录、来源与环境变量均不开放。启动时先核对程序摘要、Wasm 导入与导出、接口版本和签名，再运行应用。宿主支持范围见 `宿主支持清单.tsv`；基础、文件、网络、张量计算、张量文件、显示、图形处理器、图形显示、字体适配分别见 `../../适配/基础节点/说明.汉语.md`、`../../适配/文件节点/说明.汉语.md`、`../../适配/网络节点/说明.汉语.md`、`../../适配/张量计算节点/说明.汉语.md`、`../../适配/张量文件节点/说明.汉语.md`、`../../适配/显示节点/说明.汉语.md`、`../../适配/图形处理器节点/说明.汉语.md`、`../../适配/图形显示节点/说明.汉语.md`、`../../适配/字体诺节/说明.汉语.md`。张量原语写在本目录的 `张量.mjs`，显示、图形与字体原语写在本目录的 `图形.mjs`（与浏览器宿主共用 `../浏览器/图形.mjs` 的显示面表与图形能力），构建器把它们与三个共用模块一起内联进 `启动.mjs`；工作线程的源码也由其中的函数文本拼成，发行包不另带文件。

`--张量线程数 N` 设张量计算所用的线程数（含主线程）：缺省取 `os.availableParallelism()`，上限 256（超过按 256 计），取 1 时不创建工作线程。工作线程在第一次需要并行时才创建，不拖住进程退出；矩阵乘与注意力按工作量决定实际用几个线程，量小时只用主线程。主机上另有重负载时，线程占满全部核心反而可能变慢（被抢占的线程手握已领的块会拖住整次计算），可把此值调小，例如 `--张量线程数 12`。

`--张量后端 名` 是测试用选项，强制张量计算适配只用该后端，名为 `中央处理器`、`网页图算`、`金属`、`统算` 之一（其余名字装载失败）。缺省由适配按应用的加速要求自动选择。现在有中央处理器、金属与统算三个后端：金属只在苹果系统上、统算只在装有英伟达驱动（libcuda.so.1）的林纳克斯上，且都要给了 `--允许系统库调用` 才可用；指定不可用的后端时 `取得张量上下文` 返回 `资源暂不可用`。一致性验证缺省用它固定为中央处理器，使各平台输出相同；验收加速后端时驱动另给 `--张量后端 金属` 或 `--张量后端 统算`，给 `--张量后端 自动` 时不指定后端、只给 `--允许系统库调用`，验收自动选择（见 `一致性验证/说明.汉语.md`）。

[一致性验证](一致性验证/说明.汉语.md)覆盖发行包装载、授权、文件、网络、张量计算、张量文件与装载拒绝情形。

标准库与构建基础的带类型导入经共用胶水 `../网页汇编/边界.mjs` 接入：本宿主提供标准库二十四个与构建基础的可绘监视面板，都是同步实现、不套 JSPI，其余给桩；旧产物照旧经 `yuyan:gc-host/v1.call`，旧原语由同一份实现派生。装载核对放行过渡期的 call 与标准库、构建基础、平台接口包、应用要求的接口包的带类型导入，不合的一次列全。`_start` 之后，应用若实现了「启动程序」（导出 `豫言操作系统启动/启动程序`，见网五），本宿主经 JSPI 调用它一次；旧产物没有这个导出，只跑 `_start`。各宿主提供哪些与统一语义见[标准库宿主服务](../标准库宿主.汉语.md)。

**显示与图形**（显示、图形处理器、图形显示三个接口）：

- `--授权显示面 名称=宽x高`（可重复）授予显示面，宽高是 SDL 窗口的逻辑尺寸（点，正整数，不超过 65536）；应用第一次 `取得已授显示面 名称` 时开窗。未授予的名称返回 `未获授权`。
- `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）：载入 SDL 前设 `SDL_MAC_BACKGROUND_APP=1`（macOS 上成为后台应用，无 Dock 图标、不激活），窗口以隐藏方式创建，不抢前台焦点。隐藏窗口上像素提交与 WebGPU 呈现照常返回，自动验收用它；只有人工验收输入事件时才开可见窗口。SDL 2.32.8 没有“显示时不激活”一类的窗口提示（`SDL_WINDOW_ACTIVATE_WHEN_SHOWN` 是 SDL 3 的提示）。
- 显示需要 npm 包 `@kmamal/sdl`，图形处理器需要 `@kmamal/gpu`（Dawn），图形显示两者都要。它们不随发行包分发，应用第一次用到时才载入，依次从启动文件所在目录、当前目录、`--原生依赖目录 目录`（或环境变量 `YY_NODE_NATIVE_DIR`，两者都给时以选项为准）按 Node 的 require 规则查找，目录指含 `node_modules` 的那一层。找不到时 `取得已授显示面`、`取得图形设备` 返回 `资源暂不可用`，并在标准错误提示一次；其余能力不受影响。安装：`npm install --prefix 目录 @kmamal/sdl @kmamal/gpu`（npm 11 默认不运行安装脚本：macOS arm64 直接用包里自带的二进制，其他平台须先 `npm approve-scripts @kmamal/sdl @kmamal/gpu` 再重装，才会下载本平台的预编译文件）。
- 应用结束后宿主关闭全部窗口、释放全部设备并销毁 Dawn 实例，进程随即退出。

```sh
node dist/应用名/启动.mjs --授权显示面 主画面=640x480 --原生依赖目录 ~/豫言原生依赖 -- 应用参数
```

待办事项：@kmamal/gpu 0.2.1 每约 100 毫秒才处理一次异步回调，每次 `提交图形命令`、创建对象与读回至少等这么久（弹出错误域），交互渲染只有每秒约十帧；须改 Dawn 的轮询或换用别的构建。

**系统库调用**（只供适配与系统库使用，不进公共接口）：

- `外部库.mjs` 基于诺节的 `node:ffi`（实验特性，须带 `--experimental-ffi`）提供系统库调用原语，外调名以 `豫言_节点_外部库` 开头：打开动态库、取符号地址、按签名调用、原生内存的分配与释放、读写与复制、C 字符串，以及取张量存储（SharedArrayBuffer）的原生地址与视图信息（元素类型号、起点、形状、步长，起点与步长以元素计；视图信息只读，不需要允许）。豫言侧的封装是 `库/系统库调用`，金属计算的封装是 `库/金属`，统算（CUDA）驱动接口的封装是 `库/统算`。构建器同样把 `外部库.mjs` 内联进 `启动.mjs`。
- 应用宿主缺省不开放：系统库调用能执行任意原生代码、绕过目录与网络等授权，所以须给宿主选项 `--允许系统库调用`。给了此选项、程序里有这些外调名而诺节没带 `--experimental-ffi` 时，宿主带上此旗以同样的参数重启自身（继承标准流，退出码取子进程的）。没给此选项或诺节不支持 `node:ffi` 时，`豫言_节点_外部库可用` 为假，适配应退回别的实现。这是定规，张量计算的金属与统算后端照此办理：没给此选项时两者都视为不可用，张量自动选择后端时退回中央处理器；给了此选项且有可用的加速后端时，不限加速、偏好加速与必须加速都选它（苹果上是金属，林纳克斯上是统算）；给了 `--张量后端 金属` 或 `--张量后端 统算` 而没给此选项时，取得张量上下文返回资源暂不可用，宿主启动时在标准错误提示须加 `--允许系统库调用`。
- `底层宿主.cjs` 运行底层（无垃圾回收）模块：模块导入内存时按导入段的限制建内存（可共享、可六十四位地址），导入「数学」「诺节」的函数由它提供，导出「工作线程」时先起若干工作线程共用同一块共享内存（环境变量 `YY_底层线程数`，缺省为可用处理器数减一），再调用 `_start`；`宿主.cjs` 遇到这样的模块就交给它，Wasm 工具链包没带这个文件时照旧运行。详见 `应用/豫言编译器/文档/底层模式.汉语.md`。
- 带类型的宿主导入（见 `应用/豫言编译器/文档/语言技术规范/网页汇编接口.汉语.md` 网五）：`宿主.cjs` 经共用胶水 `../网页汇编/边界.mjs`（Wasm 工具链包里与宿主同目录）按模块的「豫言边界」段转换值。实现了导入模块「标准库」的六十五个函数与「构建基础」的三个函数（照搬旧原语：串参数转成 Buffer，列结果只返回数组），只有读取终端按键、进入与退出终端原始输入模式、两个拼音转换与绘监视面板没有实现；另有边界回环测试的夹具 `边界回环.cjs`（导入模块「测试」，只在仓库里有）。没有实现的带类型导入给桩，调用时报“接口函数未绑定：模块.字段”。旧的 `yuyan:gc-host/v1.call` 照旧提供，给稳定工具链与仍有外调的程序用。`_start` 之后有 `豫言操作系统启动/启动程序` 导出就同步调用它（经胶水 `造边界导出`）。WasmGC 程序（导出 `yy_tuple` 或带「豫言边界」段）不交给 `底层宿主.cjs`。
- 工具宿主 `宿主.cjs` 总是开放：给客体工作线程另带 `--experimental-ffi`（V8 引擎旗对整个进程生效，不传给工作线程）；Wasm 工具链包里的宿主没带 `外部库.mjs` 时只提供报告不可用的 `豫言_节点_外部库可用`；用旧版 yy双宿主构建 生成、没有内联 `外部库.mjs` 的 `启动.mjs` 也是如此。
- 签名文字：返回类型字、全角冒号、各参数类型字，如 `址：址址长`。类型字：无（只用于返回）、爻、字（八位无符号）、整（三十二位有符号）、长（六十四位有符号）、址（指针）、单、双。函数对象按“地址＋签名”缓存；`node:ffi` 的同一个库对象里同一符号只能取一种签名，所以每种（库，签名）各开一个库对象。只认经“取符号”登记过的地址。整数与指针在豫言里都是六十四位有符号整数。布尔返回只取返回值的最低字节，返回 int 的 C 函数要按“整”声明（glibc 的 `isalpha` 返回 1024 之类，最低字节为零）。macOS arm64（诺节 26.3.0）与林纳克斯 x86-64（诺节 26.10.0）上都已验证，林纳克斯上同样从进程主映像取 C 库函数。
- 诺节载入 `node:ffi` 时的“实验特性”警告由宿主拦下，不写到标准错误。
- 待办事项：结构体按值传递（arm64 上大于 16 字节的结构体由调用者传指向副本的指针，写作“址”即可；其余未支持）；回调（`node:ffi` 的回调只能在创建它的线程上调用）；可变参数函数；任意函数指针；视窗。
