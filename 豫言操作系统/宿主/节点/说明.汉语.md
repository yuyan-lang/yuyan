# Node 应用宿主

这是路一在桌面与服务器上的宿主。`yy双宿主构建 --自动 节点` 将应用编成 `程序.wasm`，并生成单文件 `启动.mjs` 与 `清单.json`。运行环境须为 Node 26 或更新版本，且须支持 WebAssembly JSPI。

在仓库根目录构建发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

运行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 只授读取；`--授权文件 路径` 可从文件载入授权。宿主选项写在 `--` 前，后续参数交给应用。未授的目录、来源与环境变量均不开放。启动时先核对程序摘要、Wasm 导入与导出、接口版本和签名，再运行应用。宿主支持范围见 `宿主支持清单.tsv`；基础、文件、网络、张量计算、张量文件、显示、图形处理器、图形显示适配分别见 `../../适配/基础节点/说明.汉语.md`、`../../适配/文件节点/说明.汉语.md`、`../../适配/网络节点/说明.汉语.md`、`../../适配/张量计算节点/说明.汉语.md`、`../../适配/张量文件节点/说明.汉语.md`、`../../适配/显示节点/说明.汉语.md`、`../../适配/图形处理器节点/说明.汉语.md`、`../../适配/图形显示节点/说明.汉语.md`。张量原语写在本目录的 `张量.mjs`，显示与图形原语写在本目录的 `图形.mjs`（与浏览器宿主共用 `../浏览器/图形.mjs` 的显示面表与图形能力），构建器把它们与三个共用模块一起内联进 `启动.mjs`；工作线程的源码也由其中的函数文本拼成，发行包不另带文件。

`--张量线程数 N` 设张量计算所用的线程数（含主线程）：缺省取 `os.availableParallelism()`，上限 256（超过按 256 计），取 1 时不创建工作线程。工作线程在第一次需要并行时才创建，不拖住进程退出；矩阵乘与注意力按工作量决定实际用几个线程，量小时只用主线程。主机上另有重负载时，线程占满全部核心反而可能变慢（被抢占的线程手握已领的块会拖住整次计算），可把此值调小，例如 `--张量线程数 12`。

`--张量后端 名` 是测试用选项，强制张量计算适配只用该后端，名为 `中央处理器`、`网页图算`、`金属`、`统算` 之一（其余名字装载失败）。缺省由适配按应用的加速要求自动选择。现在只有中央处理器后端，指定其余三个时 `取得张量上下文` 返回 `资源暂不可用`；一致性验证用它固定为中央处理器，使各平台输出相同。

[一致性验证](一致性验证/说明.汉语.md)覆盖发行包装载、授权、文件、网络、张量计算、张量文件与装载拒绝情形。

**显示与图形**（显示、图形处理器、图形显示三个接口）：

- `--授权显示面 名称=宽x高`（可重复）授予显示面，宽高是 SDL 窗口的逻辑尺寸（点，正整数，不超过 65536）；应用第一次 `取得已授显示面 名称` 时开窗。未授予的名称返回 `未获授权`。
- `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）：载入 SDL 前设 `SDL_MAC_BACKGROUND_APP=1`（macOS 上成为后台应用，无 Dock 图标、不激活），窗口以隐藏方式创建，不抢前台焦点。隐藏窗口上像素提交与 WebGPU 呈现照常返回，自动验收用它；只有人工验收输入事件时才开可见窗口。SDL 2.32.8 没有“显示时不激活”一类的窗口提示（`SDL_WINDOW_ACTIVATE_WHEN_SHOWN` 是 SDL 3 的提示）。
- 显示需要 npm 包 `@kmamal/sdl`，图形处理器需要 `@kmamal/gpu`（Dawn），图形显示两者都要。它们不随发行包分发，应用第一次用到时才载入，依次从启动文件所在目录、当前目录、`--原生依赖目录 目录`（或环境变量 `YY_NODE_NATIVE_DIR`，两者都给时以选项为准）按 Node 的 require 规则查找，目录指含 `node_modules` 的那一层。找不到时 `取得已授显示面`、`取得图形设备` 返回 `资源暂不可用`，并在标准错误提示一次；其余能力不受影响。安装：`npm install --prefix 目录 @kmamal/sdl @kmamal/gpu`（npm 11 默认不运行安装脚本：macOS arm64 直接用包里自带的二进制，其他平台须先 `npm approve-scripts @kmamal/sdl @kmamal/gpu` 再重装，才会下载本平台的预编译文件）。
- 应用结束后宿主关闭全部窗口、释放全部设备并销毁 Dawn 实例，进程随即退出。

```sh
node dist/应用名/启动.mjs --授权显示面 主画面=640x480 --原生依赖目录 ~/豫言原生依赖 -- 应用参数
```

**系统库调用**（只供适配与系统库使用，不进公共接口）：

- `外部库.mjs` 基于诺节的 `node:ffi`（实验特性，须带 `--experimental-ffi`）提供系统库调用原语，外调名以 `豫言_节点_外部库` 开头：打开动态库、取符号地址、按签名调用、原生内存的分配与释放、读写与复制、C 字符串，以及取张量存储（SharedArrayBuffer）的原生地址。豫言侧的封装是 `库/系统库调用`，金属计算的封装是 `库/金属`。构建器同样把 `外部库.mjs` 内联进 `启动.mjs`。
- 应用宿主缺省不开放：系统库调用能执行任意原生代码、绕过目录与网络等授权，所以须给宿主选项 `--允许系统库调用`。给了此选项、程序里有这些外调名而诺节没带 `--experimental-ffi` 时，宿主带上此旗以同样的参数重启自身（继承标准流，退出码取子进程的）。没给此选项或诺节不支持 `node:ffi` 时，`豫言_节点_外部库可用` 为假，适配应退回别的实现。
- 工具宿主 `宿主.cjs` 总是开放：给客体工作线程另带 `--experimental-ffi`（V8 引擎旗对整个进程生效，不传给工作线程）；Wasm 工具链包里的宿主没带 `外部库.mjs` 时不提供这些原语。
- 签名文字：返回类型字、全角冒号、各参数类型字，如 `址：址址长`。类型字：无（只用于返回）、爻、字（八位无符号）、整（三十二位有符号）、长（六十四位有符号）、址（指针）、单、双。函数对象按“地址＋签名”缓存；`node:ffi` 的同一个库对象里同一符号只能取一种签名，所以每种（库，签名）各开一个库对象。只认经“取符号”登记过的地址。整数与指针在豫言里都是六十四位有符号整数。
- 诺节载入 `node:ffi` 时的“实验特性”警告由宿主拦下，不写到标准错误。
- 待办事项：结构体按值传递（arm64 上大于 16 字节的结构体由调用者传指向副本的指针，写作“址”即可；其余未支持）；回调（`node:ffi` 的回调只能在创建它的线程上调用）；可变参数函数；任意函数指针；视窗。

```sh
node dist/应用名/启动.mjs --允许系统库调用 -- 应用参数
```
