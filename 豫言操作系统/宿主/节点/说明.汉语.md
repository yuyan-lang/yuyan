# Node 应用宿主

这是路一在桌面与服务器上的宿主。`yy双宿主构建 --自动 节点` 将应用编成 `程序.wasm`，并生成单文件 `启动.mjs` 与 `清单.json`。运行环境须为 Node 26 或更新版本，且须支持 WebAssembly JSPI。

在仓库根目录构建发行包：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 应用目录 dist/应用名
```

运行发行包：

```sh
node dist/应用名/启动.mjs --授权目录 名=路径 --允许源 https://example.com --允许环境 变量名 -- 应用参数
```

`--授权只读目录 名=路径` 只授读取；`--授权文件 路径` 可从文件载入授权。宿主选项写在 `--` 前，后续参数交给应用。未授的目录、来源与环境变量均不开放。启动时先核对程序摘要、Wasm 导入与导出、接口版本和规范摘要，再运行应用。宿主支持范围见 `宿主支持清单.tsv`；基础、文件、网络适配分别见 `../../适配/基础节点/说明.汉语.md`、`../../适配/文件节点/说明.汉语.md`、`../../适配/网络节点/说明.汉语.md`。

[一致性验证](一致性验证/说明.汉语.md)覆盖发行包装载、授权、文件、网络与装载拒绝情形。
