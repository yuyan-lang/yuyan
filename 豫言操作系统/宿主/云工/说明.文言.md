# 云工宿主壳说

云工宿主为薄宿主：惟译名与值。豫言以资「云工物」径执 JS 之物，以通用原语读写属性、呼法、造物、候 Promise；平台之义（D1、R2、持久之物、队列、网页之请与答等）皆书于 `豫言操作系统/适配/` 之云工适配，豫言一侧之通用原语见 `库/云工宿主`。

## 诸文

- `入口.mjs`：Worker 之入口壳。出默认之处（fetch、queue、scheduled）、命名服务入口之类 `豫言服务入口` 与通用持久之物之类 `豫言持久对象`（fetch、alarm）。
- `宿主.mjs`：造宿主、建实例、分平台之事、白名单、许可与宿主之物。
- `物桥.mjs`：通用原语之实与值之转，Node 应用宿主共之。
- `值桥.mjs`：造豫言实例（标准库宿主之服、带型导入之接）与值桥。
- `平台资料.mjs`、`中央张量.mjs`：用之乃动载。
- `隔离入口.mjs`、`隔离运行客.mjs`：动态子 Worker 之入口（豫言客器与文件式客器）。

## 实例与事

- 每宿主（一隔离体一；持久之物每物一）于首事至时建一 Wasm 实例，行 `_start` 一次，后诸事皆于此实例呼应用接口之出。诸事交错于 JSPI 挂起之点。
- 入口抛异出 Wasm（程序之疵）者，宿主废其实例，后事另建，在途之事照常毕之。
- 宿主不存按事之态。平台之事与类型化入口之对如下，请与上下文以参授之：

| 平台之事 | 应用接口之出 | 参 |
|---|---|---|
| fetch、服务之绑、持久之物 fetch | 豫言操作系统网页服务/处理入站网页请求 | 〔0, Request, 上下文, 事类〕；归〔0, Response 或 Promise〕 |
| queue | 豫言操作系统消息队列/处理队列批次 | 〔0, MessageBatch, 上下文〕 |
| scheduled | 豫言操作系统定时事件/处理定时事件 | 〔0, ScheduledController, 上下文〕 |
| 持久之物 alarm | 豫言操作系统持久告警/处理持久告警 | 〔0, 告警之信, DurableObjectState〕 |

上下文为 ExecutionContext，持久之物中为 DurableObjectState。事类为 fetch、service-fetch 或 durable-fetch。

## 物桥

- 「云工值」之序：空 0、未定义 1、爻 2、整 3（安全整数之 number）、数 4（余 number）、大整数 5、文 6、字节 7（Uint8Array；宿主所归之 Uint8Array 与 ArrayBuffer 皆复为字节值）、物 8（余皆是）。
- 「云工果」：〔0, 值〕为成，〔1, 错名, 辞〕为败。或败之原语皆归云工果，宿主不抛于 Wasm。
- 属性之名不得为 `__proto__`、`prototype`、`constructor`、`eval`、`Function` 之属。
- 「云工造回调」所造之 JS 函被呼，宿主以应用接口之出 `云工宿主/执行云工回调` 入 Wasm；成则归值，败则抛 Error。回调入口云工宿主库供之。

## 白名单、许可与宿主之物

- 「云工全局」惟认白名单（`宿主.mjs` 之 `可用全局`）之全局。`fetch`、`WebSocket`、`EventSource`、`Function`、`WebAssembly`、`globalThis` 不在其列，外发惟由平台之绑或宿主之物 豫言公网取。
- 「云工绑定」依许可清单（产物 `许可.json`，键为 KV、R2、D1、SERVICE、DO、ASSETS、QUEUE、EMAIL、LOADER、RATE_LIMIT、ENV、SECRET、SECRETS_STORE、VERSION、ANALYTICS、WORKFLOW）核其绑名。
- 宿主之物：
  - 豫言公网取：动态公网 HTTPS 之请，许可 `OUTBOUND_ORIGINS` 含 `https://*` 乃许，址须 https、无用户名与口令，转址一律 manual。
  - 豫言子工：依 LOADER 许可之绑载子 Worker，子 Worker 惟行所授之 Wasm，env 空、globalOutbound 为 null。
  - 豫言平台资料：取平台资料之物。
  - 豫言应用导出：此实例之应用接口出表，持久事务与持久独占之适配以之于平台回调中呼应用所定之入口。

## 中央张量

导入模块「中央张量宿主」每宿主一份：「启用」时动载 `中央张量.mjs` 而载其内核（产物 `动态资源.mjs` 之 `中央张量内核模块`），余调同步行之。

## 试

- `宿主支持清单。测试.mjs`（无须构建之产，全树测试自觅之）：宿主支持清单之式与适配之依；云工宿主包之声皆由物桥实之；中央张量宿主之声与 `值桥.mjs` 对照表相合；物桥之值转与成败之果；无类型化入口之程序报误。
- `公网取。测试.mjs`：豫言公网取之许可与址之核。
- `一致性验证/`：持久之物之拟、试验应用与 Node 之试，说见其目。

## 后续之版
