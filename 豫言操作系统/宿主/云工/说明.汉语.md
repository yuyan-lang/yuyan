# 云工宿主壳说明

云工宿主是薄宿主：只翻译名字和值。豫言用资源「云工物」直接持有 JS 对象，经通用原语读写属性、调用方法、构造对象、等待 Promise；平台语义（D1、R2、持久对象、队列、网页请求与响应等）都写在 `豫言操作系统/适配/` 的云工适配里，豫言一侧的通用原语见 `库/云工宿主`。

## 文件

- `入口.mjs`：Worker 入口壳。导出默认处理器（fetch、queue、scheduled）、命名服务入口类 `豫言服务入口` 与通用持久对象类 `豫言持久对象`（fetch、alarm）。
- `宿主.mjs`：创建宿主、建实例、分派平台事件、白名单、许可与宿主对象。
- `物桥.mjs`：通用原语的实现与值转换，Node 应用宿主共用这一份。
- `值桥.mjs`：创建豫言实例（标准库宿主服务、带类型导入的接线）与值桥。
- `平台资料.mjs`、`中央张量.mjs`：用到时才动态导入。
- `隔离入口.mjs`、`隔离运行客.mjs`：动态子 Worker 的入口（豫言客器与文件式客器）。

## 实例与事件

- 每个宿主（一个隔离体一个；持久对象每个对象一个）在第一个事件到来时建一个 Wasm 实例，跑一次 `_start`，以后所有事件都在这个实例上调用应用接口导出。多个事件在 JSPI 挂起点交错执行。
- 入口把异常抛出 Wasm（程序缺陷）时，宿主作废这个实例，后来的事件另建新实例，在途的事件照常跑完。
- 宿主不保存任何按事件的状态。平台事件与类型化入口的对应如下，请求、上下文（网页事件还有先交函数）作为参数传入：

| 平台事件 | 应用接口导出 | 参数 |
|---|---|---|
| fetch、服务绑定、持久对象 fetch | 豫言操作系统网页服务/处理入站网页请求 | 〔0, Request, 上下文, 种类, 先交〕；返回〔0, Response 或 Promise〕 |
| queue | 豫言操作系统消息队列/处理队列批次 | 〔0, MessageBatch, 上下文〕 |
| scheduled | 豫言操作系统定时事件/处理定时事件 | 〔0, ScheduledController, 上下文〕 |
| 持久对象 alarm | 豫言操作系统持久告警/处理持久告警 | 〔0, 告警信息, DurableObjectState〕 |

上下文是 ExecutionContext，持久对象里是 DurableObjectState。种类是 fetch、service-fetch 或 durable-fetch。

先交是宿主为每次网页事件调用新造的函数 先交(响应) → Promise（网页事件流适配用它立即提交响应头）：入口返回之前以 Response 调用它，宿主立即以这个 Response 作答，入口继续运行，入口的返回值随之忽略；有 `waitUntil` 的上下文等入口跑完，此后入口抛出只写错误输出。它只认第一次（入口返回之后或第二次调用都报错），返回入口运行完毕的 Promise（入口正常返回得 true，抛出得 false），适配据此在事件结束时收尾。先交与请求、上下文一样只是本次调用的参数。

## 物桥

- 「云工值」的支序：空 0、未定义 1、爻 2、整 3（安全整数范围的 number）、数 4（其余 number）、大整数 5（bigint）、文 6（string）、字节 7（Uint8Array；宿主送回的 Uint8Array 与 ArrayBuffer 复制成字节值）、物 8（其余一切）。
- 「云工果」：〔0, 值〕为成功，〔1, 错误名, 消息〕为失败。可能失败的原语都返回云工果，宿主不向 Wasm 抛异常。
- 属性名不许是 `__proto__`、`prototype`、`constructor`、`eval`、`Function` 等。
- 「云工造回调」造出的 JS 函数被调用时，宿主以应用接口导出 `云工宿主/执行云工回调` 进入 Wasm；成功返回值，失败抛 Error。回调入口由云工宿主库提供。

## 白名单、许可与宿主对象

- 「云工全局」只认白名单（`宿主.mjs` 的 `可用全局`）里的全局。`fetch`、`WebSocket`、`EventSource`、`Function`、`WebAssembly`、`globalThis` 不在表内，外发请求只能走平台绑定或宿主对象 豫言公网取、豫言授权取。
- 「云工绑定」按许可清单（产物的 `许可.json`，键为 KV、R2、D1、SERVICE、DO、ASSETS、QUEUE、EMAIL、LOADER、RATE_LIMIT、ENV、SECRET、SECRETS_STORE、VERSION、ANALYTICS、WORKFLOW）核对绑定名：未授权是部署错误，宿主直接中止本次事件（豫言接不住）；已授权而平台没有配置时得 undefined，可选的绑定由适配当作“没有配置”，必需的绑定由「绑定」便利函数用「云工中止」中止本次事件。
- 宿主对象：
  - 豫言公网取：动态公网 HTTPS 请求，许可 `OUTBOUND_ORIGINS` 含 `https://*` 时放行，网址须是 https、不带用户名或密码，redirect 一律改为 manual。
  - 豫言授权取：许可来源的外发请求（网页上游适配的静态来源用），网址须是 https、不带用户名或密码，来源须列在许可 `OUTBOUND_ORIGINS` 里（通配 `https://*` 不放行真实来源），redirect 一律改为 manual；函数属性 `已授权(网址)` 只核对、不发请求。
  - 豫言子工：按 LOADER 许可的绑定加载子 Worker，子 Worker 只运行传入的 Wasm，env 为空、globalOutbound 为 null。
  - 豫言平台资料：取平台资料对象。
  - 豫言应用导出：本实例的应用接口导出表，持久事务与持久独占的适配用它在平台回调里调应用定义的入口。

## 中央张量

导入模块「中央张量宿主」每个宿主一份：「启用」时动态导入 `中央张量.mjs` 并载入内核（产物 `动态资源.mjs` 的 `中央张量内核模块`），其余调用同步执行。

## 测试

- `宿主支持清单。测试.mjs`（不需要构建产物，全树测试自动发现）：宿主支持清单格式与适配依赖；云工宿主包的声明都由物桥实现；中央张量宿主的声明与 `值桥.mjs` 的对照表一致；物桥的值转换与成败结果；没有类型化入口的程序报错。
- `公网取。测试.mjs`：豫言公网取的许可与网址核对。
- `一致性验证/`：持久对象模拟、试验应用与 Node 测试，说明见该目录。
