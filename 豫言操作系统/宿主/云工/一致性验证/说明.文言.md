# 宿主壳一致性验证

此目录验云工宿主壳（`../宿主.mjs`、`../入口.mjs`）与三接口——[持久事务](../../../../豫言操作系统接口/持久事务/规范.文言.md)二版、[持久告警](../../../../豫言操作系统接口/持久告警/规范.文言.md)初版、[持久独占](../../../../豫言操作系统接口/持久独占/规范.文言.md)初版——及每事时限之配、`durableFetch` 先应与 `waitUntil`。皆用**真豫言 Wasm**，持久对象由此目录之模拟供之，另有一套验于本地 workerd。

## 文件

| 文件 | 内容 |
| --- | --- |
| `模拟持久对象.mjs` | 可复用之 Durable Object 模拟：`storage`（get/put/delete/list/deleteAll/告警/事务）、输入闸、`blockConcurrencyWhile`、`waitUntil`、`id`，及使 `fetch`/`alarm` 经输入闸授宿主之 `模拟持久对象`（`触发告警` 仿平台送告警与败而重试） |
| `模拟慢网络.mjs` | 候 `ms` 毫秒而应之模拟上游，记请之区间，以断并发或独占 |
| `持久对象壳.test.mjs` | 三十六 Node 测试：直读写久仓、事务、告警、独占区、时限配置、先应、大值与桥之限 |
| `额度回归.test.mjs` | 云仓额度应用之原验收断言（以旧接口构建，须仍过） |
| `应用/持久对象壳一致性应用/` | 试验应用源码（包描述存为 `.txt`，免为 `yy豫构` 全仓包发现所析） |
| `本地工作者验证/` | 可选：验于本地 workerd 之真实脚本与差分比对 |

## 复跑（私有暂存）

一、建私有暂存，令暂存中之 `豫言操作系统`、`豫言操作系统接口`、`工具` 指向待验之语言仓（默即语言仓自身）。
二、以暂存中**同版**重编之 `yy双宿主构建`（工具源 `工具/双宿主构建/入口。豫`）构建二应用：试验应用（此目录 `应用/持久对象壳一致性应用`）与云仓 `应用/豫言体验/额度应用`。草稿区 `建应用.sh <暂存> 云工 <应用目录> <输出名>` 成“绑所依之 OS 接口、写包上下文、`yy双宿主构建`、`yy豫言操作系统装载包`”四步，亦可循云仓 Makefile 同序手为之。云仓额度应用之包描述未列 `豫言操作系统*` 之依赖（云仓 Makefile 由包上下文供之），以草稿脚本构建者，须先抄应用目录而于「依赖」补网页入站、网页答复、环境文字、时间、持久事务五接口包。
三、行：`env "持久对象壳产物=<暂存>/dist/持久对象壳一致性应用" "额度应用产物=<暂存>/dist/额度应用" node --test 持久对象壳.test.mjs 额度回归.test.mjs`（Node 须支持 JSPI，如 v26）。测试所需 `执行配置`，由试验应用目录中之 `执行配置.json` 经构建器书入 `动态资源.mjs`，个别用例另向宿主径传配置对象。
四、云仓迁毕，当以二 `*.test.mjs` 入云仓之验收，产物之径易为云仓构建目录。

## 模拟与本地 workerd 之关系

`模拟持久对象.mjs` 之行，依 Wrangler 4.129.0 本地 workerd（兼容日期 2026-09-05，SQLite 存）实测校之：`list` 依 UTF-8 字节序；事务回调行时输入闸闭、他事排队；事务回调内之告警变更与径写 `storage` 者随事务回滚；回滚后复用事务对象则报 `Cannot put() on rolled back transaction`；`blockConcurrencyWhile` 回调抛错或逾三十秒，记为对象重置；告警之处理始，告警视为已清，败后视为已设以待重试。`本地工作者验证/` 中差分比对，以八十二项操作分送模拟与本地 workerd，输出全同。与真器犹异者：模拟无输入门对存取之细粒保护、无真实之对象休眠与驱逐、`waitUntil` 惟记而不延寿、告警不自按时而触（以 `触发告警` 手送）。此诸端与他云端之行，见 `../说明.文言.md` 之“云端待验之目”。

## 试验应用之协议

请体 `{"op":…}`，应为纯文本：`OK`；`K|事类`；`E|值 JSON`（有）与 `M|`（缺键）；`D|1`/`D|0`；`L|列 JSON`；`T|事务之果`；`B|独占之果`；`A|1|时`/`A|0|0`；`R|重试数`；`N|长度`；`X|误辞`。主要之操作：`put`/`get`/`del`/`list`/`clear`（直读写久仓），`tx`（`args` 为事务参 JSON，`name` 择用例）、`tx-outside`，`alarm-get`/`alarm-set`/`alarm-del`/`retry`，`block`（`name`、`args`）、`block-big`、`block-len`、`tx-big`，`counter-plain`（不入独占之读、候、写）、`sleep`、`early`、`early-fail`、`boom`、`put-big`、`getlen`。请头 `x-op: body-len` 则径读原请体而返其长。
