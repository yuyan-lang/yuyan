# 持久对象壳一致性应用

惟为验宿主壳而设之试验应用，无业务之义。其具四类型化之入口（提案 C0001），无「入口」之函：`处理入站网页请求`（`durable-fetch`，及非持久对象之 `fetch`）读 JSON 请体 `{"op":…}`，行久仓、事务、告警、独占区、长候诸事，以纯文本之协议而应（`OK`、`K|事类`、`E|值`、`M|`、`D|1`、`L|列`、`T|事务之果`、`B|独占之果`、`A|已设|时`、`X|误`）；`执行持久事务回调`、`执行持久独占回调` 依名择例而返其果；`处理持久告警` 依久仓 `alarm-mode` 而行。久仓依持久事务四版明取之：网页之请以 `入站请求持久仓`（非持久对象之请不得取，诸事得 `X|当前事件不属于持久对象`），事务回调以 `事务持久仓`，独占区回调以 `独占区持久仓`，告警入口以 `告警持久仓`。候外物之事，经宿主之物 `豫言公网取` 向久仓 `upstream` 键所给之基址（缺则 `https://slow.test`）发请，许可 `OUTBOUND_ORIGINS` 为 `https://*`。测试见 `../../持久对象壳.test.mjs`，复跑之法见 `../../说明.文言.md`。
