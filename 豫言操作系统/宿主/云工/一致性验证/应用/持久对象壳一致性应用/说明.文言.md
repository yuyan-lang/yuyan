# 持久对象壳一致性应用

惟为验宿主壳而设之试验应用，无业务之义。其依 `读取入站事件种类` 分派：`durable-fetch`（及非持久对象之 `fetch`）读 JSON 请体 `{"op":…}`，行久仓、事务、告警、独占区、长候、先应诸事，以纯文本之协议而应（`OK`、`K|事类`、`E|值`、`M|`、`D|1`、`L|列`、`T|事务之果`、`B|独占之果`、`A|已设|时`、`R|重试数`、`X|误`）；`durable-transaction`、`durable-block`、`durable-alarm` 各有入口。候外物之事，经久仓 `upstream` 键所给之基址（缺则 `https://slow.test`，许可惟授此址）向模拟上游发请。测试见 `../../持久对象壳.test.mjs`，复跑之法见 `../../说明.文言.md`。`执行配置.json` 随应用抄入产物，以验构建器之抄入。
