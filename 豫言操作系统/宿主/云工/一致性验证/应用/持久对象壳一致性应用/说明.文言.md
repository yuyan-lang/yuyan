# 持久对象壳一致性应用

惟为验宿主壳而设之试验应用，无业务之义。其具四类型化之入口（提案 C0001），无「入口」之函：`处理入站网页请求`（`durable-fetch`，及非持久对象之 `fetch`）读 JSON 请体 `{"op":…}`，行久仓、事务、告警、独占区、长候诸事，以纯文本之协议而应（`OK`、`K|事类`、`E|值`、`M|`、`D|1`、`L|列`、`T|事务之果`、`B|独占之果`、`A|已设|时`、`X|误`）；`执行持久事务回调`、`执行持久独占回调` 依名择例而返其果；`处理持久告警` 依久仓 `alarm-mode` 而行。候外物之事，经久仓 `upstream` 键所给之基址（缺则 `https://slow.test`，许可惟授此址）向模拟上游发请。测试见 `../../持久对象壳.test.mjs`，复跑之法见 `../../说明.文言.md`。`执行配置.json` 随应用抄入产物，以验构建器之抄入。
