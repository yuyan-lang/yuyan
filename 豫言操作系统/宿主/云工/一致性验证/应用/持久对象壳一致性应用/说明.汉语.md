# 持久对象壳一致性应用

只用于验证宿主壳的试验应用，没有业务含义。它按 `读取入站事件种类` 分派：`durable-fetch`（以及非持久对象的 `fetch`）读 JSON 请求体 `{"op":…}` 执行持久仓、事务、告警、独占区、长等待、响应先返等操作，用纯文本协议应答（`OK`、`K|事件种类`、`E|值`、`M|`、`D|1`、`L|列表`、`T|事务结果`、`B|独占结果`、`A|已设|时刻`、`R|重试数`、`X|错误`）；`durable-transaction`、`durable-block`、`durable-alarm` 各有处理入口。等待外部输入输出的操作通过持久仓 `upstream` 键给出的基址（缺省 `https://slow.test`，许可只授权它）向模拟上游发请求。测试见 `../../持久对象壳.test.mjs`，复跑方法见 `../../说明.汉语.md`。`执行配置.json` 随应用复制到产物，用来验证构建器的抄入。
