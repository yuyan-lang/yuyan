# 持久对象壳一致性应用

只用于验证宿主壳的试验应用，没有业务含义。它实现四个类型化入口（提案 C0001），没有「入口」函数：`处理入站网页请求`（`durable-fetch`，以及非持久对象的 `fetch`）读 JSON 请求体 `{"op":…}` 执行持久仓、事务、告警、独占区、长等待等操作，用纯文本协议应答（`OK`、`K|事件种类`、`E|值`、`M|`、`D|1`、`L|列表`、`T|事务结果`、`B|独占结果`、`A|已设|时刻`、`X|错误`）；`执行持久事务回调`、`执行持久独占回调` 按名称选用例并返回结果文字；`处理持久告警` 按持久仓里的 `alarm-mode` 行事。持久仓按持久事务 0.4.0 显式取得：网页请求用 `入站请求持久仓`（非持久对象的请求取不到，操作得 `X|当前事件不属于持久对象`），事务回调用 `事务持久仓`，独占区回调用 `独占区持久仓`，告警入口用 `告警持久仓`。等待外部输入输出的操作经宿主对象 `豫言公网取` 向持久仓 `upstream` 键给出的基址（缺省 `https://slow.test`）发请求，许可 `OUTBOUND_ORIGINS` 为 `https://*`。测试见 `../../持久对象壳.test.mjs`，复跑方法见 `../../说明.汉语.md`。
