# 持久对象壳一致性应用

只用于验证宿主壳的试验应用，没有业务含义。它实现四个类型化入口（提案 C0001），没有「入口」函数：`处理入站网页请求`（`durable-fetch`，以及非持久对象的 `fetch`）读 JSON 请求体 `{"op":…}` 执行持久仓、事务、告警、独占区、长等待等操作，用纯文本协议应答（`OK`、`K|事件种类`、`E|值`、`M|`、`D|1`、`L|列表`、`T|事务结果`、`B|独占结果`、`A|已设|时刻`、`X|错误`）；`执行持久事务回调`、`执行持久独占回调` 按名称选用例并返回结果文字；`处理持久告警` 按持久仓里的 `alarm-mode` 行事。等待外部输入输出的操作通过持久仓 `upstream` 键给出的基址（缺省 `https://slow.test`，许可只授权它）向模拟上游发请求。测试见 `../../持久对象壳.test.mjs`，复跑方法见 `../../说明.汉语.md`。`执行配置.json` 随应用复制到产物，用来验证构建器的抄入。
