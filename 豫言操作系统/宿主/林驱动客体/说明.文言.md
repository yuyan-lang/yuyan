# 固定 Linux 客体构建配置

## 共享页内核

`共享内核配置` 循串口内核之配，启 DEVMEM，关 STRICT_DEVMEM，供客中代理访豫言所授之共享物页。客物址域由宿主 EPT 授之，共享页之留及双向设备环之接继行。

以豫言之器统配构：`节点 林内核构建.wasm 源码绝对目录 输出绝对目录 配置绝对路径 解包依赖根绝对目录 [附加驱动源码目录]`。器复制所给之配至输出之域，呼 Linux 自有配器与 make，两路成 bzImage；首文、库、m4 及 bison 数据皆指别解依赖根。根备 flex、bison、m4、libelf、OpenSSL、zlib、zstd 之开发及运行诸篇。源码及下载诸物在仓外，系统软件包之安装存其旧。

十月十二日，于 pit-mbp13 `/home/zc/yy-guest-kernel` 构成，豫言之器实跑亦过。新核九十五万九千四百八十八字节，沙256 `a2e6d16a2544094a958c0cd9d7019a0ebf6c0af0df3e27c174f9ec9d7a319e41`；配置沙256 `58c35ae286195905f6b3c87e3a8b97dd62eb357304dccd383cceae459dc4a4d4`。单核 KVM、二 GiB 之豫言宿主嵌套启至 `/init`，读物址零起十六字节成，串口六项往返过；四十五秒 timeout 终常驻宿主，退码一二四。日志取回 `/private/tmp/共享内核.串`。此验覆共享物页访问之前置之能，设备环交回及受管启动继行。

此乃 Linux 6.12.112 客体之实构配置。`内核配置` 为 Linux 自生之产物，存外部组件旧式；此目未增 C、shell 或 JS 程序。源码与成品留开发机临时目录，二进制不入库。

## 网卡内核

豫言构器于所给网卡配启 PACKET、DEVMEM，关 STRICT_DEVMEM，循 olddefconfig 核其依赖。所成客核供原始以太帧套接字及授权共享页之访，备网卡代理接设备环；报文之路与受管启动继行。用串口配时，网络依赖由 olddefconfig 裁之。

2026-10-04 增 `网卡内核配置`，由同版 Linux 之 `scripts/config`、`olddefconfig` 成之。启 PCI、NET、INET、NETDEVICES、ETHERNET、NET_VENDOR_INTEL、E1000，留单核、禁 ACPI 之启式，禁 PCI_MSI、E1000E、客体 IOMMU。网卡用既有 e1000 驱动及传统 INTx，宿主掌 DMA 隔离。

别置源码 `/tmp/林网卡源码/linux-6.12.112`，出于 `/tmp/林网卡构建`，录于 `/tmp/林网卡内核构建.log`。用旧临时依赖根，`M4` 明指其 `usr/bin/m4`，`BISON_PKGDATADIR` 指 `usr/share/bison`；主机头文件、链接库亦指此根。以 Linux 旧 make、GCC 15.2.0、Binutils 2.46 及 `-j 24 bzImage` 构之，留旧串口内核。

Q35/KVM 直启对照已识 `00:04.0 [8086:100e]`，e1000 成 `eth0`，报 IRQ 10、BAR 0 `0xfeb80000`、BAR 1 `0xc000`；备 COM2 后，豫言 PID 1 服务就绪，六项串口往返皆过。此对照证固定内核、驱动及原生应用可行，网卡实网络收发仍待验。

同核入豫言 VMM，首未支持者为四字节 PCI 配置址写：VMX 出因 `0x1e`，限定 `0x0cf80003`，客体 RIP 低位 `0x812884e9`。VMM 常收而续宿主；PCI 配置、BAR、DMA 及中断转交仍待接。见[林设备分配](../../裸机/文档/林设备分配.文言.md)。

## 原串口内核

授第五参（如 broadcom-sta 之源码目录）则器复开模块、cfg80211（去规则库之签之求）与 UNIX 套接字，编 bzImage 及诸模之后，抄该目录于产出目录之 `附加驱动` 下而编为外部之模（如 `wl.ko`）。

2026-10-03 于 pit-pc-ubuntu 构，以 GCC、Linux 自备 make 及配置器行之。构建依赖自其发行版仓库取，解于 `/tmp/林客体依赖/根`，未装系统。flex、bison、m4 用此根之器，bison 数据、主机头文件及链接库亦指此根。源码在 `/tmp/林客体源码/linux-6.12.112`，日志在 `/tmp/林内核构建.log`。

禁 SMP、ACPI、PCI、模块及 KASLR，留六十四位可移内核、ELF、initramfs、8250 控台、proc/sysfs/tmpfs；x86-64 选入本地 APIC 及 IOAPIC。内核未内置 init，后由装载器偕 initramfs 供之。
