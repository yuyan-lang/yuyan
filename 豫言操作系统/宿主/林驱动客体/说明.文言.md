# 固定 Linux 客体构建配置

此乃 Linux 6.12.112 客体之实构配置。`内核配置` 为 Linux 自生之产物，存外部组件旧式；此目未增 C、shell 或 JS 程序。源码与成品留开发机临时目录，二进制不入库。

## 网卡内核

2026-10-04 增 `网卡内核配置`，由同版 Linux 之 `scripts/config`、`olddefconfig` 成之。启 PCI、NET、INET、NETDEVICES、ETHERNET、NET_VENDOR_INTEL、E1000，留单核、禁 ACPI 之启式，禁 PCI_MSI、E1000E、客体 IOMMU。网卡用既有 e1000 驱动及传统 INTx，宿主掌 DMA 隔离。

别置源码 `/tmp/yy林网卡源码/linux-6.12.112`，出于 `/tmp/yy林网卡构建`，录于 `/tmp/yy林网卡内核构建.log`。用旧临时依赖根，`M4` 明指其 `usr/bin/m4`，`BISON_PKGDATADIR` 指 `usr/share/bison`；主机头文件、链接库亦指此根。以 Linux 旧 make、GCC 15.2.0、Binutils 2.46 及 `-j 24 bzImage` 构之，留旧串口内核。

Q35/KVM 直启对照已识 `00:04.0 [8086:100e]`，e1000 成 `eth0`，报 IRQ 10、BAR 0 `0xfeb80000`、BAR 1 `0xc000`；备 COM2 后，豫言 PID 1 服务就绪，六项串口往返皆过。此对照证固定内核、驱动及原生应用可行，网卡实网络收发仍待验。

同核入豫言 VMM，首未支持者为四字节 PCI 配置址写：VMX 出因 `0x1e`，限定 `0x0cf80003`，客体 RIP 低位 `0x812884e9`。VMM 常收而续宿主；PCI 配置、BAR、DMA 及中断转交仍待接。见[林设备分配](../../裸机/文档/林设备分配.文言.md)。

## 原串口内核

2026-10-03 于 pit-pc-ubuntu 构，以 GCC、Linux 自备 make 及配置器行之。构建依赖自其发行版仓库取，解于 `/tmp/yy林客体依赖/根`，未装系统。flex、bison、m4 用此根之器，bison 数据、主机头文件及链接库亦指此根。源码在 `/tmp/yy林客体源码/linux-6.12.112`，日志在 `/tmp/yy林内核构建.log`。

禁 SMP、ACPI、PCI、模块及 KASLR，留六十四位可移内核、ELF、initramfs、8250 控台、proc/sysfs/tmpfs；x86-64 选入本地 APIC 及 IOAPIC。内核未内置 init，后由装载器偕 initramfs 供之。

本地镜像为独立工作树之 `yy林内核6.12.112`，已由豫言装载器析之而成启动诸片，未于豫言内置虚拟机行之。分工及议见[林驱动客体](../../裸机/文档/林驱动客体.文言.md)。

外部 initramfs 已由 `林初盘准备` 成之；`yy林初盘.cpio` 含底层豫言之 `/init` 及控台、服务串口器。QEMU pc/TCG 已行至 init 就绪而过串口服务基线，诸果见上文所引之议；嵌套启动仍未成。

QEMU microvm/TCG、qemu64、单核、512 MiB 径启基线已书 `Linux version 6.12.112`，初置时钟并挂 devtmpfs，末以未供 initramfs/init 书 `No working init found`，循 `panic=1 reboot=t` 退出。日志为独立工作树之 `yy林内核基线.log`。此证固定镜像可行及串口可书，未证豫言内置虚拟机或服务往返。编译器 GCC 15.2.0，链接器 Binutils 2.46。
