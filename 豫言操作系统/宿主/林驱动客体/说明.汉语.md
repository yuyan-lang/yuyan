# 固定 Linux 客体构建配置

这是 Linux 6.12.112 客体的实际构建配置。`内核配置` 是 Linux 自身生成的配置产物，保留外部组件原有格式；本目录没有新增 C、shell 或 JS 程序。源码与构建产物保留在开发机临时目录，二进制文件不入库。

2026-10-03 于 pit-pc-ubuntu 构建，使用 GCC、Linux 自带 make 与配置工具。构建依赖从该机发行版仓库下载，解包到 `/tmp/yy林客体依赖/根`，未安装到系统。flex、bison 与 m4 使用该根下可执行文件；bison 数据目录、主机编译头文件和链接库也指向该根。源码位于 `/tmp/yy林客体源码/linux-6.12.112`，日志为 `/tmp/yy林内核构建.log`。

配置关闭 SMP、ACPI、PCI、模块与 KASLR，保留六十四位可重定位内核、ELF、initramfs、8250 串口控制台、proc/sysfs/tmpfs；x86-64 会选入本地 APIC 和 IOAPIC。内核尚未内置 init 程序，后续由装载器配合 initramfs 提供。
