# 固定 Linux 客体构建配置

这是 Linux 6.12.112 客体的实际构建配置。`内核配置` 是 Linux 自身生成的配置产物，保留外部组件原有格式；本目录没有新增 C、shell 或 JS 程序。源码与构建产物保留在开发机临时目录，二进制文件不入库。

## 网卡内核

2026-10-04 新增 `网卡内核配置`，由同一版本 Linux 的 `scripts/config` 和 `olddefconfig` 生成。开启 PCI、NET、INET、NETDEVICES、ETHERNET、NET_VENDOR_INTEL、E1000，保留单核、关闭 ACPI 的启动方式，关闭 PCI_MSI、E1000E 和客体 IOMMU。网卡使用 e1000 现成驱动与传统 INTx，宿主负责 DMA 隔离。

独立源码为 `/tmp/yy林网卡源码/linux-6.12.112`，输出目录为 `/tmp/yy林网卡构建`，日志为 `/tmp/yy林网卡内核构建.log`。使用原临时依赖根，`M4` 明确指向该根的 `usr/bin/m4`，`BISON_PKGDATADIR` 指向 `usr/share/bison`；主机头文件与链接库也指向此根。以 Linux 原有 make、GCC 15.2.0、Binutils 2.46 和 `-j 24 bzImage` 构建，保留原串口内核。

Q35/KVM 直接启动对照已识别 `00:04.0 [8086:100e]`，e1000 创建 `eth0`，报告 IRQ 10、BAR 0 `0xfeb80000`、BAR 1 `0xc000`；提供 COM2 后，豫言 PID 1 服务就绪，六项串口往返验收通过。此对照证明固定内核、驱动与原生应用运行，网卡实际网络收发仍须验证。

同一内核进入豫言 VMM 后，首个未支持的访问为四字节 PCI 配置地址写入：VMX 退出原因 `0x1e`，退出限定 `0x0cf80003`，客体 RIP 低位 `0x812884e9`。VMM 正常回收并继续宿主；PCI 配置、BAR、DMA 与中断转交尚待接入。记录见[林设备分配](../../裸机/文档/林设备分配.汉语.md)。

## 原串口内核

2026-10-03 于 pit-pc-ubuntu 构建，使用 GCC、Linux 自带 make 与配置工具。构建依赖从该机发行版仓库下载，解包到 `/tmp/yy林客体依赖/根`，未安装到系统。flex、bison 与 m4 使用该根下可执行文件；bison 数据目录、主机编译头文件和链接库也指向该根。源码位于 `/tmp/yy林客体源码/linux-6.12.112`，日志为 `/tmp/yy林内核构建.log`。

配置关闭 SMP、ACPI、PCI、模块与 KASLR，保留六十四位可重定位内核、ELF、initramfs、8250 串口控制台、proc/sysfs/tmpfs；x86-64 会选入本地 APIC 和 IOAPIC。内核尚未内置 init 程序，后续由装载器配合 initramfs 提供。
