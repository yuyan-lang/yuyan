# 标准库之宿主服务：诸 JS 宿主之接线与同一之义

子程序接口别有原语三百零九「遣信宿主役（按宿主进程号发信号）」：林檎林纳循宿号传一信；轩窗惟九强止，余正信、豫言之土、诺驿与浏览器答五十八。信限一至百二十七，越界答二十二；成答零，程亡答八，发败答二十九。先验信界，后察平台与程号。恒取宿号之域，属使者（子进程能力）节。

止异步子进程循今实例所录之柄强止，记留至收；码零成、八柄无效、二十九宿主败、五十八未支持。工具节点与原生执行器复用各自之程记及底层之止；客节点与浏览器之异步启止留待后版。

节点客宿主之行读惟取当行所需字，毋预取下一行而夺子程序之入；犹去行尾换行与回车。终端原始入逐字节成全字符或连可读之转义键，不批取后命。继输入之子程序启前暂止本会原始编辑之制，终或启败则复之。实管验父命令、子一行、父续行次取其入；实PTY验换行前子未读，终后父无换行读键。长行之效、迟至之转义序尾与全原壳调用之迁犹待成。

此标准库与构建基础之宿主服务行于诸 JS 宿主之规。标准库之 `宿主。接口。豫` 与 `宿主带列。接口。豫` 编为导入模块“标准库”之带型导入八十一，构建基础之 `构建宿主。接口。豫` 编为导入模块“构建基础”之三；导入之形（签名、Wasm 之类、自定段「豫言边界」）见[网页汇编接口](../../应用/豫言编译器/文档/语言技术规范/网页汇编接口.文言.md)网五。本篇定诸宿主各供何者、如何接线，及诸宿主同一之义。十月二十一日所加三网络对时之接口（`读墙钟秒毫`、`设墙钟偏移`、`注起居`）惟于豫言操作系统之执行器有其实（前二者于原生执行器依宿主之钟与“不支持”答之）；十月二十二日所加 `读墙钟偏移` 亦惟于豫言操作系统之执行器有其实，原生执行器给（零，零）；此诸接口于诺驿工具宿主以宿钟或“不支持”垫之，三家 JS 宿主为诺驿上之豫构与试，不供之，网络对时惟行于豫言操作系统。十月二十三日所加 `提句柄上限` 于豫言操作系统之执行器依平台提本进程文件句柄之软限：林檎提至硬限与 `kern.maxfilesperproc` 之小者，林纳提至硬限，返提后之软限；轩窗、裸机与 JS 宿主返负一。同日所加 `辞行在` 于豫言操作系统之原生执行器辞本程于宿主之行在（见[客体二号说明](../裸机/客体二号/说明.文言.md)之“辞行在”），余平台无行在：诺驿工具宿主返阳，余 JS 宿主不供之，边界胶水给桩。同日所加 `置箧` 立目（缺之上级并立，已有则为成）与 `改权` 易其权位，原生执行器、诺驿工具宿主与裸机皆有其实，余宿主给桩。同日所加 `删箧` 去空目，于原生执行器（含轩窗）、诺驿工具宿主与裸机皆有其实，余宿主给桩；`问负载`、`问开机秒` 与 `问主机名` 于原生执行器（林檎、林纳）与诺驿工具宿主有其实，裸机与轩窗还空文或负一，余宿主给桩。同日所加 `问使众` 量子程连同子孙之常驻和，于原生执行器（林檎、林纳）有其实，裸机与轩窗还负一，诺驿工具宿主还 −1（诺驿无现成之子孙枚举），余宿主给桩。十月二十六日所加 `置影` 立符号之链（径与所指二标参，还零或底码）：原生执行器经底层文件之 `建链` 于根柄三下立之（径先经附庸之表改写，所指原样记之），裸机以文件系统立速链（所指不及六十字，长者还参误），诺驿工具宿主以 `fs.symlinkSync`（所指原样记之，相对者仍相对）；轩窗、诺驿应用宿主、浏览与云工无立影之能，还五十八（不支持）。程与试造影，不必起 `ln` 之宿主命（议八百五十）。十月二十七日与「共身」并补：置影于轩窗以 `CreateSymbolicLinkW`，裸机补数据块之符号链接（所指不短于六十字）；共身为宿主服之新列，为已有之文复添一同实之名，供程与试立硬链而不必起 `ln`（议八百五十八、八百七十）。十月二十四日所加 `遣离使`（议五四五）于新会之中启子程，原生执行器于子行之前调 setsid（林檎依 posix_spawn 之 POSIX_SPAWN_SETSID 标，林纳于 clone 之后、execve 之前调 setsid），裸机由核起一务（父亡而后由初任务收养），诺驿工具宿主依 `child_process` 之 `detached` 而 unref 其柄与二管，应用宿主、浏览器与云工给桩。

## 接线

- 三 JS 宿主共用胶水 `网页汇编/边界.mjs`：读「豫言边界」段，依签名互转 Wasm 之值与 JS 之值。宿主授依（模块，字段）分组之实现表；表所无之导入给桩，调之则报“接口函数未绑定：模块.字段”。签名表与导入表依模块而存。Safari（JavaScriptCore）之 `WebAssembly.Module.imports` 遇 WasmGC 引用之型，则全表报错；胶水乃以「豫言边界」段之导入行为导入之表（编译器以同一登记书导入之项与段之行，一一相应）。
- 同步之实径调之；惟标“异步”者乃套 JSPI。未标“异步”而返 Promise 者，胶水当即报错。下列诸宿主所供标准库之函皆同步，故带型导入于无 JSPI 之浏览器亦可行。
- 平铺之发布：`浏览器/`、`云工/`、`浏览器/编译器/` 下之 `边界.mjs`，于仓中惟一行，转出 `../网页汇编/边界.mjs`（编译器目为 `../../`）。豫构发行书胶水本体为产物之 `边界.mjs`，云工动态子 Worker 之模块源码亦附之；节点发行启动文件内联胶水。浏览器编译宿主惟模有带型导入乃动态载胶水（导入之表不可读，则视模有「豫言边界」段否）。
- 云工每事新立一实例，带型导入之闭包亦每事一套，不共“当前事件”之态。带型导入每调验其事之墙钟时限。
- 装载之核：程须有「豫言边界」段，Wasm 之导入惟其段录签、导入模块为标准库、构建基础、平台接口包或应用所需接口包之带型导入；不合者一并列报。

## 同一之义

以标准库之注为准，诸宿主同：

- **退出进程**：依退出码终此运行，零为成。浏览器与云工，码零之运行正常而毕，非零则以“豫言程序退出：码”败；项目核心码零则照取所出，非零为败。
- **标准错误打印行**：书于宿主之误流。Node 书于文件描述符二；编译宿主收入运行结果之 stderr；浏览器与云工无独立之误流，默书于日志之误级（`console.error`），调者可授 `错误输出` 以易其所往；项目核心先收之，运行败则以为错误之辞交调者，不复借之抛错。
- **获取当前工作目录**：属实例。Node 工具宿主可迁；Node 应用宿主不可迁，恒返实例立时之进程目录；编译宿主、浏览器与云工恒为“/”。
- **在线处理器数量**：宿主可用之并行数，不知则一。编译宿主恒一。
- **同步改名文件**：易旧径之文为新径，新径有文则代之，改时随文不变。Node 工具宿主用 `fs.renameSync`，原生执行器用 renameat（Windows 用许覆盖之 MoveFileExW），同时读新径者惟见易前或易后之全文；内存文件系统移其条目于新径；裸机以读、写、删旧代之。标准库之原子写文件、原子写文件字节串先书同目录之暂文，后以此易名；编译缓存赖之，数构建进程得共一缓存之目录。
- **空路径**（十月二十六日加，议六百五十八）：长零之径，皆指“不存在”，同 POSIX 之 ENOENT。原生执行器之 `规范路径` 遇空径而还专负码「空路径码」（负二），余败（径过长）仍还负一，诸文件原语据码分办：空径报不存，过长之径报参误。空径之答：`实有`、`为箧`、`为卷` 答阴，改时得零，卷大小、卷大小长、问权、卷号与改时纳各得负一，卷占得负三，列目得空列，读文告祸曰“读文件失败：径：误码 四十四”；书文与附帛告祸曰“写文件失败：径：不存在”；焚与更名告祸曰“……误码 四十四”，皆可以「姑试」承之；置箧、改权、删箧与迁还非零之码。裸机初始任务同一 `规范路径`，整文读写告可承之异。诺驿工具宿主以 `fs` 之同名函数，空径亦报 ENOENT。豫寓藏书（文件接口）别以空径指授权之根，属另一套接口。
- **读文、删、易名与书文之败**（十月二十六日加，议七百二十三）：整文之读（`阅`、`阅帛`，原语二十八、二十九，及 `阅帛片` 之读文一段）、删（三十二）、易名（百八十）与书文（`著`、`著帛` 三十、三十一、`附帛` 二百五十八）而败，诸东道皆告可承之祸，辞与原生执行器同文：读曰“读文件失败：径：误码 码”，删曰“删除文件失败：径：误码 码”，易名曰“改名失败：旧径 → 新径：误码 码”，书文与附帛曰“写文件失败：径：因”，因取底码之说明（若是目录、无空间（盘满或文数已尽）、无权限，见边界胶水之底码说明）。原生执行器、裸机初始任务（书文由「本地写文件或祸」察码）、诺驿工具宿主、浏览器编译宿主与浏览器构建工作线程一致，客之「姑试」可承；无承者顶层之处书“未捕捉的豫言异常：”并其辞而以一退（十月二十六日前原生、诺驿、浏览器三处直抛越界或印而退，豫言不能承）。诺驿工具宿主依误之符号名（ENOENT 之类）易为底码，与平台无涉；浏览器编译宿主依内存文系统之误码（不存四十四）换算，浏览器构建工作线程依主线程之答所携之底码成文。
- **设执行位**：以所有者可读书行、余者可读可行之位（〇七五五）易文之权。Node 工具宿主用 `fs.chmodSync`；原生执行器于林檎、林纳皆先受界开其父箧，而后用 `fchmodat`；裸机与浏览器编译宿主之内存文件系统，文皆可执行，径还成；余 JS 宿主给桩。
- **卷大小**（十月二十二日加，议三百五十一）：按径还其卷之字节数，不读正文；无其卷或非常文则还负一。原生执行器读状块之长度（原语七十二，裸机与原生共用），惟取低四字，四吉字节以上之卷则环绕；诺驿工具宿主以 `fs.statSync` 取其长，浏览器编译宿主之内存文件系统径给条目之长，余宿主给桩。十月二十四日次段起标准库「藏书」之「卷大小」改行「卷大小长」，此处留予径调宿主接口者。
- **卷大小长**（十月二十四日加，议四百六十七）：按径还其卷之字节数（六十四位），不读正文；无其卷或非常文则还负一。原生执行器读状块 +32 之八字（原语二百六十九，裸机与原生共用），诺驿工具宿主以 `fs.statSync` 取其长，浏览器编译宿主与构建工作线程取内存文件系统条目之长，诺驿应用宿主、浏览器与云工之运行时宿主无按径问长之能、还负一。裸机之文件系统合 inode 之 i_size_lo 与 i_size_high 为六十四位，「项长度」与状块皆取全八字，豫言系统之初始任务与子任务亦答得出四吉字节以上之真长。次段起「藏书」之「卷大小」转行此路，还六十四位之长。
- **遣离使**（十月二十四日加，议五四五）：于新会之中异步启子程，参与收取同 `遣使`，惟子程别为一会与群，不随主人之终端、会与群杀而亡。原生执行器于子行之前调 setsid（林檎依 posix_spawn 之 POSIX_SPAWN_SETSID 标，林纳于 clone 之后、execve 之前调 setsid），裸机由核起一务（父亡而后由初任务收养），诺驿工具宿主依 `child_process` 之 `detached` 而 unref 其柄与二管，应用宿主、浏览器与云工给桩。将作与行在之后台者用之，不复循 PATH 求宿主之 setsid 程。
- **遣离使于卷**（十月二十六日加，议六五九）：于新会之中异步启子程，而其二出尽续于卷末（缺之上级并建），参与收取同 `遣离使`；二出皆在卷中，收之皆空。原生执行器依今目录规卷径为绝径、开以续，以此柄兼授子程为标准出与误，复于子行之前调 setsid（原语二百九十九，裸机与原生共一实：裸机由初任务替子任务起务、柄经底层转送）；诺驿工具宿主以 `fs.openSync` 取续书之柄、经 `child_process` 之 `stdio` 授于子程，`detached` 而 unref。应用宿主、浏览器与云工给桩（应用宿主本不供异步之启）。将作与行在之后台者用之，其出各入会所下之 `将作.输出`、`行在.输出`：起之者既退，服所印之误与执行器硬中止之报犹存于卷（议六五八之崩乃见其因）。
- **阅帛片**（十月二十二日加，议三百五十一）：按径、始偏与字限读出一段，一次至多一兆；卷短于所求则依实而还，限零则空数组。原生执行器开以只读、定位读入中转之缓而拷成恰长之数组（原语二二六，裸机与原生共用），诺驿工具宿主以 `fs.openSync`、`fs.readSync` 带位而读，浏览器编译宿主自内存文系统取其一段（败则同读文，告可承之祸），浏览器构建工作线程以「读片」之请交主线程自同一内存文系统取其一段（一次至多一兆，卷短依实，限零则空，偏负或限负报参误，败则同读文而告可承之祸，十月二十六日，议七百八十六），余宿主给桩。标准库「藏书」之「阅帛片」裹之；简易网页服务器据之分块发大文，不尽载其卷。
- **著与著帛**（十月二十四日补记，议五百八十八）：按径以文书或以帛书，同步书之，旧文尽覆，无卷则新立；上级不在则先逐级立之而后书，诸宿主同法。原生执行器先径开之，报不存乃以底层文件之「建目录」逐一立其缺之祖而再开（原语三十、三十一，其法在客体二号之写打开，裸机与原生共用文件原语；他开之误则径返，不立目）；诺驿工具宿主先以 `fs.mkdirSync` 之 `recursive` 立其父而后 `fs.writeFileSync`；浏览器编译宿主书于内存文系统（目为的、逾其限者各带底码三十一、五十一）；余宿主给桩。书败之辞见「读文、删、易名与书文之败」一条。标准库「藏书」之「著」「著帛」裹之；欲原子书则用同篇之「定稿」「定稿帛」。

- **置箧**（十月二十三日加）：立目，缺之上级并立，目已有则为成；成还零，败还宿主之误码。原生执行器经底层文件之「建目录」逐级立其祖（原语三十九，裸机与原生共用），诺驿工具宿主以 `fs.mkdirSync` 之 `recursive`，余宿主给桩。呼者径用「东道」之「置箧」；壳中同名者乃案牍之命。
- **置影**（十月二十六日加，议八百五十）：立符号之链，所指原样记之（相对者仍相对），成还零、败还宿主之误码。原生执行器经底层文件之「建链」于根柄三下立之（原语三百零二，径先经附庸之表改写；裸机与原生共用，裸机所指不及六十字则立速链、不短者用一数据块，轩窗以 `CreateSymbolicLinkW` 立之、所指为绝径而系目则加目之标），诺驿工具宿主以 `fs.symlinkSync`；诺驿应用宿主、浏览、云工与项目之核无按径立影之能，还五十八（不支持）。「藏书」之置影裹之。
- **共身**（十月二十七日加，议八百七十）：立硬链，令新名与旧径指其一物（一节点、一内容），链数加一，成还零、败还宿主之误码。原生执行器经底层文件之「共身」于根柄三下加名（原语三百零三，二径皆先经附庸之表改写；林纳、林檎以 `linkat`，轩窗以 `CreateHardLinkW`），裸机以文件系统于目中增项而加节点之链数，诺驿工具宿主以 `fs.linkSync`；诺驿应用宿主、浏览、云工与项目之核还五十八（不支持）。「藏书」之共身裹之。
- **改权**（十月二十三日加）：受径与模，易其权位（若八进之七〇〇、六〇〇，即十进之四四八、三八四），成还零，败还宿主之误码。原生执行器于林檎、林纳皆先受界开其父而后 `fchmodat`，循末段之链（原语二百五十九，裸机与原生共用），诺驿工具宿主以 `fs.chmodSync`，裸机无权限之位、径还零，余宿主给桩。标准库「藏书」之「改权」裹之。
- **卷占**（十月二十四日加，议五百八十一）：受径而取卷实占之盘字（六十四位），不读正文，亦不随末影；常文为块数乘五百一十二，目还负一，影与余类还负二，不存或取不得还负三。原生执行器以原语二百九十取一状（林纳读 statx 之缓四十八处之 stx_blocks，林檎读 struct stat 一百零四处之 st_blocks），裸机依四基之块向上取整，轩窗无块数、还负三；诺驿工具宿主以 `fs.lstatSync`，轩窗之块数不可靠，亦还负三；浏览器编译宿主、构建工作线程、诺驿应用宿主、浏览器与云工还负三。「藏书」之「卷占」裹之，量箧遍历时每条只问一次，真值还负三则退依类与字节累加。
- **问权**（十月二十四日加，议五百四十四）：受径而取其权位（八进低十二位，若〇七五五还四九三），径不存或取不得则还负一。原生读状块二十处之 st_mode 低十二位（林檎、林纳取〇七七七七，轩窗依只读与目折算），诺驿之工具宿主以 `fs.statSync().mode & 0o7777`，裸机无权位而还零，余宿给桩。「藏书」之问权裹之；「详目」经开发工具之文件信息印 ls -l 首栏即赖之，不必起 stat 或 ls 之宿主命。
- **卷号**（十月二十七日加，议九百三十五）：受径而取文系统所以别其文之号（inode），不读其文：同文虽由诸径（含硬系）观之其号惟一，径上之文既易（删而重构、抄新文而易名覆之）则其号亦易；径不存或取不得则还负一。原生读状块八处之八字（原语三百零五：林纳取 statx 之 stx_ino，林檎取 struct stat 之 st_ino），裸机取索引之号；诺驿之工具宿主以 `fs.statSync(…, {bigint: true}).ino`（轩窗上或零）；浏览器编译宿主与构建工作线程之内存文系统每书一文予一号、改名则随之；诺驿应用宿主、浏览器与云工无按径问文号之能，还负一。「藏书」之卷号裹之；器之指纹依（径、号、字数、改时）而存，赖此识同径之易文。
- **改时纳**（十月二十七日加，议九百三十五）：受径而取文之末改之时，以纪元以来之纳秒计（低高二半装箱），不读其文；同秒之内原地覆写亦分得之，指纹之缓赖以识“同秒曾改”。原生读状块四十八处之八字（原语三百零六；林纳 statx 之 stx_mtime_sec/nsec、林檎 struct stat 之 st_mtimespec 皆合为纪元以来之纳秒），裸机依秒乘十亿；诺驿之工具宿主以 `fs.statSync(…, {bigint: true}).mtimeNs`；浏览器编译宿主与构建工作线程以内存文系统条目之时钟乘十亿；诺驿应用宿主、浏览器与云工无按径问改时之能，还负一，呼者退依整秒乘十亿（「藏书」之「改时纳」即依此退路）。径不存或取不得亦还负一。
- **删箧**（十月二十三日加）：去空目，成还零，败还宿主之误码（不存、非目、目中有物之类）。原生执行器经底层文件之「删目录」去根柄三下之径：林檎、林纳以 `unlinkat` 之 `AT_REMOVEDIR`，轩窗以 `RemoveDirectoryW`（原语二百六十，裸机与原生共用）；裸机初始任务循「文件系统删除」，先察目空否，非空还「底码目录非空」，子任务经底层转送交初始任务；诺驿工具宿主以 `fs.rmdirSync`，余宿主给桩。
- **问负载**（十月二十三日加）：还一、五、十五分均负，书如 `/proc/loadavg` 首三事（每事二位小数，空格间之），不得则空文。林纳上原生执行器读 `/proc/loadavg`，取首三字段原样还之；林檎上以 `sysctlbyname` 取 `vm.loadavg`（struct loadavg：三 uint32 定点数 ldavg，后随八字对齐之一 long fscale，共二十四字节，回写之长须二十四），每事依 ldavg×100÷fscale 取整而书为“整数.两位”（原语二百六十一，裸机与原生共用）；诺驿工具宿主以 `os.loadavg()` 各取 `toFixed(2)` 而连之。轩窗与裸机还空文（待办：轩窗以 GetSystemTimes 自算，裸机由核补负载之计），余宿主给桩。

- **遣使于境离**（十月二十六日加，议题六五四）：参与返同「遣使于境」（程名、参列、所居、环境块），子程在新会之中行：林檎、林纳之原生执行器于子行之前调 setsid，子程自为新会新群。不由常驻之工；裸机、轩窗、诺驿、浏览与云工还负五十八（原语 297）。将作以之起代役：代役自为一群，此后所起常驻之工、原生之产子程与其分片之工皆承此群。
- **散组**（十月二十六日加，议题六五四）：以本程之程号为群号，朝其群发 SIGTERM，收本程与其所起常驻之工、原生之产子程、分片之工而尽召之。代役由将作以「遣使于境离」起，群号即其程号，一信适尽全树；本程非群之长则其群不存，信无所杀，还二十九；惟林檎、林纳之原生实之（原语 298），裸机、轩窗、诺驿、浏览与云工还负五十八。代役退前召在行之子、掩门，乃调之，忙时之常驻工与分片之工不复俟其务毕。
- **遣信**（十月二十七日加，议一千零二十四）：依今实例所籍之异步子程之柄发一信，还（码，程号）：零为信已出或子程早退，八柄无效（常驻之工亦在焉），二十九信不得出，五十八此土无此信；程号不得则负一。十五为 SIGTERM、九为 SIGKILL，林檎、林纳之原生依号发一至一百二十七之信，子程已不在（系统之调答 ESRCH）亦为零；轩窗无 SIGTERM，惟九依程柄硬止（原语三百零七），余答五十八；裸机、诺驿、浏览与云工答五十八。将作以之收逾截止不退之代役：先发 SIGTERM，五秒犹不退则发 SIGKILL（见[豫构包说明](../../应用/豫构/包说明.文言.md)之将作一节）。
- **获取随机整数**：上界不大于零则止；取六十四位之安全随机数对上界取余，不保均布。裸机之执行器读处理器之随机令（RDRAND、RNDR），无之（QEMU 默认之 qemu64、旧之实机）则退用任务号、时钟与调用之计相混之散（获取随机小数同，二〇二六年十月十一日起）；安全随机字节串先用处理器之随机令，无之（二〇二六年十月十四日起）则改用执行器之熵池：混计时之抖、中断与按键收包之时、实时之钟与数据盘之种子文件 /系统/随机种子，以沙256 导出（见 裸机/客体二号/说明.文言.md“后备熵源”）。
- **获取环境变量**：惟见已授之名。Node 工具宿主视为尽授；Node 应用宿主依 `--允许环境`；编译宿主、浏览器与云工不授标准库以任何名，皆如不存。
- **小数转字符串**（小数表示）：同 C 之 `%f`，六位小数；-0 书为 `-0.000000`，绝对值不小于 1e21 者展为整数，非数书 `nan`，无穷书 `inf`、`-inf`。
- **小数精确表示**：同 C 之 `%.17g`，十七位有效数字，去尾零；-0 书 `-0`，非有限者同上。编译器中间产物之序列化恃之。
- **字符串转小数**（理解小数）：同 C 之 `strtod`：越首之空白，取最长可转之前缀，识 `inf`、`infinity`、`nan`（不分大小写，可带正负），无可转者得零，逾范围得无穷。
- **云工通用句柄桥**：全局句柄、构造对象、调用全局及其安全之版，惟许取白名单之全局，同 Node 应用宿主，另加 Request、Promise、Error、caches、scheduler；fetch、WebSocket、EventSource、Function、WebAssembly、globalThis 等不在表，不得借以越外发来源之许与绑定之授；网页上游之动态公网 HTTPS 别用专术 云工公网请求发起：许之 OUTBOUND_ORIGINS 含 https://* 乃许，宿主验 https、无凭据而强转址为 manual（见云工宿主说明）。

理解整数、字节转字符串、字节串单字节与字节串空，今为编译器内建，其义见[执行与编译](../../应用/豫言编译器/文档/语言技术规范/执行与编译.文言.md)编四。
