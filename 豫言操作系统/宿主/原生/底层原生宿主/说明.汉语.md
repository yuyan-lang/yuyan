# 底层原生宿主

C 程序，用 Wasmtime C API 加载 [豫言操作系统底层原生后端](../底层原生后端/说明.汉语.md) 编出的 Wasm 模块，实现它唯一的宿主导入 `底宿主.call(术码, 块址)`，把每个术码翻成真实的 POSIX 系统调用（`clock_gettime`、`open/read/write/close`、`openat` 一族等）。

**现状：写完、能编译、能启动，但因为对方模块拿不到自己的线性内存而实际调不通**——不是这个宿主的问题，是底层模式编译器现在不会导出 Wasm 内存段。完整说明、复现步骤、修法建议见 [底层原生后端的说明](../底层原生后端/说明.汉语.md#状态设计与骨架已完成被一处编译器缺口挡住未跑通)。

## 构建（手动，尚未接入仓库构建系统）

```sh
clang -O2 -I yy_wasmtime_c_api/include \
  豫言操作系统/宿主/原生/底层原生宿主/底层原生宿主.c \
  yy_wasmtime_c_api/lib/libwasmtime.a \
  -o yy底层原生宿主 -lpthread -ldl -lm
```

## 运行

```sh
./yy底层原生宿主 yy底层原生后端.wasm
YY_底层宿主_跟踪=1 ./yy底层原生宿主 yy底层原生后端.wasm   # 打印每次 底宿主.call 的术码、块址与返回码
```
