# 豫言操作系统底层原生后端

[豫言操作系统底层接口](../../../../豫言操作系统底层接口/总纲.文言.md)于 macOS／Linux 之后端。底层模式之豫言包，编为标准整数 Wasm 模块（`yy底层原生后端.wasm`），设计上唯一之宿主导入乃统一调度之点 `底宿主:call(术码, 块址) → 状态之码`；由[底层原生宿主](../底层原生宿主/说明.文言.md)（C，用 Wasmtime C API）载入而实之。

## 状态：已通，端到端自检皆过

**结论：此路（以底层模式编为标准 Wasm，配一以 Wasmtime 为本之原生宿主）今已通。** 前阻之之编译器缺——底层后端所编 Wasm 模块不导出其线性内存，致 Wasmtime 宿主不得取 guest 内存——今已补；自检之例端到端而行，退出之码零，印「OK」。

### 所补者何

- **编译器**：`库/编译器核心/网页汇编核心/存储二进制。豫` 之 `生成内存数据二进制`，于重拼导出段（第七段）时，若模块声明内存（`模` 中内存之列非空），即于既有导出之后，追加一条〈"memory"，种类二，索引零〉之内存导出项——唯读旧导出段之 LEB128 计数、加一、余字节原样留之、后缀以新项，不解每一既有导出项。故意不动共享之 `网页导出` 型（`模块结构。豫`）与共享之 `生成网页函数二进制`（`二进制生成。豫`）——此二者高级／WasmGC 之路亦用之。已以 `库/癸象工具/癸象转义。测试。豫` 于 `--target=wasmgc` 下，分以修前修后之编译器编之，两皆洁过，证高级之路未受其扰（WasmGC 之码从不用底层模式之「声明内存」，此新逻辑于其乃纯然空操作）。改后已过完整自举（`yy_bs_stable`→`yy2_bs`→`yy3_bs`→`yy4_bs`），`yy3_bs` 与 `yy4_bs` 逐字节相同。
- **宿主**：[底层原生宿主](../底层原生宿主/底层原生宿主.c) 之 `术_取初始句柄`，先前直书柄为三，不应真开之文件描述符；今改真 `open(".", O_RDONLY)`，以所得真 fd 报 guest。
- **自检**：本包 `入口。豫` 之 `导出：启动`，先前直书目录之柄为「三」，未尝呼 `取初始句柄`；今先呼之以取真柄，后续 `打开`／`删文件` 皆用此柄，不复赖某数恰可用之幸。

行之（macOS，已验；Linux 未于真机行之，码以 `#ifdef __APPLE__`／`__linux__` 覆两边，理当同成立）：

```sh
./yy豫构 构建 豫言操作系统底层原生后端 --输出 yy底层原生后端.wasm -j 24
./yy底层原生宿主 yy底层原生后端.wasm   # 印 hello from native backend 与 OK，退出之码零
```

### 已成、可用之部分

- **`术码。豫` 加 `入口。豫`**：四十五接口函数中，基础（十一）、句柄（十三）、文件（九）共三十三，已书真实调用侧之码（参数写入共用之二百五十六字节 `块`，呼 `底宿主_调用`，读回其果）；终端／网络／进程依裸机后端同法占位，返不支持。自检之例试时钟／平台／处理器数／标准输出／取初始句柄／文件之建-写-闭-开-读-较-删，端到端而通。
- **[底层原生宿主](../底层原生宿主/底层原生宿主.c)**：C 程序，Wasmtime 载模块，`底宿主.call` 之调度实现（应三十三术码，真呼 POSIX：`clock_gettime`、`open/read/write/close`、`openat` 一族等），状态之码依 WASI errno 之子集映之，`clang -Wall -Wextra` 无警。

### 未为之事

- `读目录`（术码二七）：须宿主持"柄→目录流"之状态表，今仍返"未实现"（五二）。
- Windows 之版（Win32 API，另需一份宿主，此 C 文件不适用）。
- 唯于此 macOS 机上行之；Linux 之支（`#ifdef __linux__`）未于真 Linux 验之。

## 设计（供接手之参）

- **术码**（`术码。豫`）逐一应接口之函数，宿主据此分派至真实之系统调用。
- **块**为二百五十六字节之共用暂存（址零），按接口函数原参之序，每参四字节；有 `出` 参之函数，其果由宿主径写 guest 之内存对应之址，不经调用之返值。
- 本包单线程，每呼皆同步而成方返，共用一暂存是安全的。
- `取平台` 亦经宿主：宿主以 `#ifdef __APPLE__`／`__linux__` 自报其为何平台（三／二），一份 `.wasm` 两处可用。

## 构建

```sh
./yy豫构 构建 豫言操作系统底层原生后端 --输出 /tmp/yy底层原生后端.wasm
```

配[底层原生宿主](../底层原生宿主/说明.文言.md)构建、行之；`YY_底层宿主_跟踪=1` 环境变量启逐次调用之调试输出。
