# 浏览器构建之客户端

此乃[网页编译之约](../../../../豫言操作系统接口/网页编译/规范.文言.md) 0.2“本地构建”之构建客户端参考之实现：于浏览器中展仓库源码之快照与 Wasm 工具链，以豫构等豫言之器行检查、类型检查、构建与测试。云工作台之网页临时算力用之以行云端所排之构建作业；源码与产物惟在内存，毕则尽弃。

## 所成

- `客户端.mjs`：入口，出 `浏览器构建(作业, 报告)`、`停止构建()`、`构建可用()`。取快照与工具链（gzip 之 tar，可存于 Cache Storage），展于内存文件系统之 `/仓库`，施改动，置工具链之编译器与豫构于 `/仓库/yy4_bs.wasm`、`/仓库/yy豫构.wasm`，乃依次行诸令。
- `文件系统.mjs`：内存之文件系统（文与目录，修改之时以秒计）与 tar 之展（ustar、pax 扩展之头、GNU 长名；符号链接略之）。
- `进程.mjs`：主线程之进程表。一豫言之程为一进程，占一 Web Worker；进程之出与退码存于此，候父收之。其义同 Node 工具宿主之进程桥接。非 Wasm 之程惟认 mkdir、rm、cp、mv、true、false；env、timeout 之包装于此拆之。
- `工作线程.mjs`：客之工作线程。标准库与构建基础之带型导入经共用胶水 `边界.mjs` 接之；文件、子进程、摘要之请，经共享之存同步问于主线程（`Atomics.wait` 塞至答至，答逾一 MiB 则分块续取），故页必跨源隔离。有 JSPI 则 `_start` 行于独立之 Wasm 栈，免编译器深递归而溢线程之栈。
- `编码.mjs`：主线程答值之二进制编码。
- `边界.mjs`：仓中转出 `../../网页汇编/边界.mjs`；平铺发布时构建以本体代之。

## 本机之验

浏览器宿主受每一构建作业至多二万五千六百令，每令至多二万五千六百字符串之参，供多包合入前之验依次行之。

`../构建。测试服务.mjs` 以 `豫言操作系统/宿主/` 为根供静文，`/资料/…` 取所给目录中之快照与工具链，诸应皆附 COOP、COEP 之头。试页 `../构建。测试页.html` 由网址之参取快照、工具链与令，书出与果于 `#结果`，毕则 `<html>` 带 `data-构建="完成"`。行法见汉语稿。

**记**：二〇二六年十月六日，于 Apple M5 Pro（十八硬件线程）、无头 Chrome 154，用 CI 之 Wasm 工具链包（d883137fe）与 yybs 之快照（约五千文）：`检查 结森工具` 零点四秒，`类型检查 结森工具` 冷缓存五点八秒（编译子进程百七十五，并行至多十八；同机 Node 冷缓存五点六秒），`构建 结森工具 结森访问。测试` 一点九秒，行测试十八项皆过；并取快照与展之，共八点三秒。

待办事项：构建之缓存（`.yybuild/sha256_*.nosync`）每次自零始，可存于 IndexedDB 而复用；并写同文不加锁；无标准输入、终端与 TCP。
