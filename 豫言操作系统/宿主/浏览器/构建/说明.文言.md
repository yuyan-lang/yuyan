# 浏览器构建之客户端

此乃[网页编译之约](../../../../豫寓榫卯/网页编译/规范.文言.md) 0.2“本地构建”之构建客户端参考之实现：于浏览器中展仓库源码之快照与 Wasm 工具链，以豫构等豫言之器行检查、类型检查、构建与测试。云工作台之网页临时算力用之以行云端所排之构建作业；源码与产物惟在内存，毕则尽弃。

## 所成

- `客户端.mjs`：入口，出 `浏览器构建(作业, 报告)`、`停止构建()`、`构建可用()`。取快照与工具链（gzip 之 tar，可存于 Cache Storage），展于内存文件系统之 `/仓库`，施改动，置工具链之编译器与豫构于 `/仓库/编译器.wasm`、`/仓库/豫构.wasm`，乃依次行诸令。
- `文件系统.mjs`：内存之文件系统（文与目录，修改之时以秒计）与 tar 之展（ustar、pax 扩展之头、GNU 长名；符号链接略之）。
- `进程.mjs`：主线程之进程表。一豫言之程为一进程，JSPI 制共处理器工池，旧制各占一 Web Worker；进程之出与退码存于此，候父收之。其义同 Node 工具宿主之进程桥接。非 Wasm 之程惟认 mkdir、rm、cp、mv、true、false；env、timeout 之包装于此拆之。父终则收拾其无人收取之子务之录：已毕者除之，犹行者改录于初始之务（首立之录），其毕而后亦不留（提案〇〇〇四三之六）。「亲行」（承标准入之同步行）令子读父之标准入，入尽之标与原始之制皆在父之入上，子毕不阖之；父有出之观察者则子之出随出而转付之（同原生之承标准流，提案〇〇〇四三之五）。断务号正则并其诸子孙，号负则惟断子孙，退码百三十；号负而无子孙可断者，为其务之工线程置断标而返二，务存焉（提案〇〇〇四三第六步）。
- `工作线程.mjs`：客之工作线程。标准库与构建基础之带型导入经共用胶水 `边界.mjs` 接之；文件、子进程、摘要之请，经共享之存问于主线程（JSPI 制以 `Atomics.waitAsync` 悬其役，旧制以 `Atomics.wait` 塞其工；答逾一 MiB 则分块续取），故页必跨源隔离。问答素以结构化之克隆传请、以 `编码.mjs` 之二进制编码传答，不经文字。答为误时，控制字之四携其码（文系统予底码，如不存四十四、是目三十一、无地五十一）；工线程依之，以读、删、易名、书文之败抛为可承之祸（辞与执行器同文：读、删、易名带误码，书文带底码之说明，十月二十六日，议七百二十三）。「阅帛片」以径、偏与字限入“读片”之请，交主线程自内存文系统取此段而答：帛原样传而不经文；一次至多一兆，卷短则依实，限零则空，偏负或限负则报参误（误码二十八），文不在则报不存（四十四），败皆告可承之祸（十月二十六日，议七百八十六）。有 JSPI 则 `_start` 行于独立之 Wasm 栈，免编译器深递归而溢线程之栈。构建基础之「装网汇单元」同诺驿宿主：装单元于本线程之进程（共零号表、异常之标与已装之出），暂以所予之参与程名行其 _start（提案〇〇〇四三）。各役又自有一断字与一断例（提案〇〇〇四三第六步）：网页行在现编之句子之卷入 `yuyan:browser/v1` 之 `interrupt`，每入函、诸跳之前呼之；例读断字，置则抛专异。「装网汇单元」行前清标，承此异则返二，会话据之印“已打断”而续读次句。断字之缓冲与主线程共之，进程表据之置标。
- `编码.mjs`：主线程答值之二进制编码。
- `豫寓.mjs`：网页行在（提案〇〇〇四三）所用豫寓（豫言操作系统接口）十接口之工作线程之实：显示、字体、剪贴、设备、任务、子程序与子程序之显、时、声、文件；须共享者以同步之问付主线程（进程表之外务）。声则每流一环形之缓，与音之线程之工作件（`../行在/声音工作件.mjs`）共之：工作线程径书其样，开与阖以同步之问付主线程；缓不容一整块则整块退之。进程表又有字缓之标准入（读行、读键、原始之制、终端否）、交互之子程序、增量之取、依区读写文件与断务（号正并其诸子孙，号负惟断子孙，退码百三十；号负无子孙则置标而返二，见〇点十子程序之规）；系统之环境为诸进程环境之缺省；父终则阖其交互之子之入。
- `边界.mjs`：仓中转出 `../../网页汇编/边界.mjs`；平铺发布时构建以本体代之。

## 本机之验

旧制之构建工与诺驿宿主同其回收之时：四事而换一工，闲二百五十毫秒亦释之，以回收累事之Wasm堆高水位。子程之出、退码与父程收取之柄，存至收取毕。

浏览器宿主受每一构建作业至多二万五千六百令，每令至多二万五千六百字符串之参，供多包合入前之验依次行之。

`../构建。测试服务.mjs` 以 `豫言操作系统/宿主/` 为根供静文，`/资料/…` 取所给目录中之快照与工具链，诸应皆附 COOP、COEP 之头。试页 `../构建。测试页.html` 由网址之参取快照、工具链与令，书出与果于 `#结果`，毕则 `<html>` 带 `data-构建="完成"`。行法见汉语稿。

**记**：二〇二六年十月六日，于 Apple M5 Pro（十八硬件线程）、无头 Chrome 154，用 CI 之 Wasm 工具链包（d883137fe）与 yybs 之快照（约五千文）：`检查 结绳工具` 零点四秒，`类型检查 结绳工具` 冷缓存五点八秒（编译子进程百七十五，并行至多十八；同机 Node 冷缓存五点六秒），`构建 结绳工具 结绳访问。测试` 一点九秒，行测试十八项皆过；并取快照与展之，共八点三秒。

待办事项：构建之缓存（`.豫构缓存/sha256_*.nosync`）可存于 IndexedDB 而复用；同卷并写之互斥，留待后版。

## TCP 中继与套接之验

发行之配套：`应用/豫构/仓库目标。豫` 中网页行在、主站精简开机之摹卷籍与产物籍，同纳 `构建/中继客.mjs`。此役所改限浏览器宿主之目，发行之掌者配而成之。

群候（多路等待）之 TCP 事信接线，由[议题一四六二](https://github.com/yuyan-lang/yuyan/issues/1462) 继之。此页之例循单连守候，径验中继收发与闭状。

致帛循原生中转之分书，一次至多一兆；主依所得字数进其序，继致余札。

`中继客.mjs` 居主工，一连各掌一 WebSocket。进程表受 `中继: {地址, 令牌}`，如 `{地址: 'ws://127.0.0.1:18792', 令牌: 'test'}`，亦可取 `wss://主机`。径定 `/中继?主机=…&端口=…`，查询诸辞循 URL 编之。各役自持连籍，役终尽撤其舟。`行在/行在.mjs` 与 `行在/单应用.mjs` 自页参 `中继`、`中继令牌` 立其设；设阙则客之 TCP 术还负五十八。待办事项：后自登录或秘府（浏览器持久存储）之设取凭。

叩门（发起连接）即还一与柄；先致文字 `凭 <令牌>`，得 `连上` 则通，守候（等待事件）之可写位二，入门（连接确认）还零。听与听帛（接收文字与字节）循帛队取字，暂阙还一；客有序归，则尽取所藏，乃还二与空帛，形同原生。续告与续告帛（部分发送）依字节之序致二进制帧，还此次交东道之字数。缄口（半关闭）致文字 `缄口` 而留听路，别（关闭连接）阖舟释柄。勿滞（无延迟设置）受设报成，发时归浏览器掌之。守候依事信而待，期尽还零事；悬栈 JSPI 与同步之候共循问答。

闭码 `4000 + N` 化为原语负码 `−N`，四零七六得负七十六，四零零二得负二；一千为有序之终，异常断舟得负十五。误由（错误说明）依码陈中文之因。开门、迎、门号（监听、接受连接、本地端口查询）与数据报诸术仍还负五十八，监听与数据报之能留待后版。

本机逐令经将作而编，前毕乃后起；先以 `豫构 行在 状态` 核行在之号与端口。PATH 之链补齐问连址（套接字地址查询）前，先编执行器，继授济津（原生中继服务）之构建：

```sh
豫构 行在 状态
豫构 构建 客体二号 --输出 执行器新。树码
豫构 构建 济津 --输出 济津。林檎。豫行 -- --执行器 执行器新。树码
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/取页。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/取页.wasm
```

值桥用上节所生 `构建/值桥.wasm`。依 `应用/百工坊/济津/样例。数据。豫` 存 `济津配置。数据。豫` 于工作树；令牌摘要为凭之沙二五六（SHA-256），来源籍纳 `http://localhost:18791`。下印应本机试凭 `test`，并录回环数址，供二种页址：

```text
「令牌摘要」者「列」【『9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08』】也。
「来源」者「列」【『http://localhost:18791』，『http://127.0.0.1:18791』】也。
「证书」者『』也。
「私钥」者『』也。
```

二终端各行一令。济津受本机行在之管，内存限二千零四十八兆；静态服务具跨源隔离之首：

```sh
env 豫言内存上限=2048 ./济津。林檎。豫行 18792 济津配置。数据。豫
```

```sh
node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs 豫言操作系统/宿主/浏览器/构建 18791
```

启 `http://localhost:18791/浏览器/构建/套接。测试.html?自动&中继=ws%3A%2F%2F127.0.0.1%3A18792&中继令牌=test`。页次第行取页之例：`example.com:80` 得首辞以 `HTTP/1.` 起而含二百之码，端口二十五得底码七十六，伪凭得底码二。后二验原语负七十六、负二与非零退码。页示“通过”或“失败”，`html` 之 `data-测试` 同录其果；逾时终役撤舟。全网页行在与单应用页亦可附此二参。

## 处理器池独立验收

处理器之池、各役之态、悬候、让行与终役之约，见[网页行在之说明](../行在/说明.文言.md#处理器之池与让行)。JSPI 制复用定数之处理器工池，旧制仍一役一工。`编码.mjs` 又供宿主步骤之同步、异步续行及浏览器系统调用之边界转换，发行旧有之文目并携其实现。声流之表随本役接口而立。

`多任务。测试.html` 径取同目之 `值桥.wasm`、`回声.wasm`、`运算.wasm`、`受参.wasm`。三程之源在 `测试样例/`，包述在本目 `处理器池试。包。豫`，共本目之双语说明，所有者曰“构建”，包曰“处理器池试”，所依明指“豫言”之“豫章（标准库）”。仓根逐条下令，PATH 之豫构循缺省本机将作（构建服务），一命既毕乃行后命。先以 `豫构 行在 状态` 核其进程号与端口。

```sh
豫构 行在 状态
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/回声。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/回声.wasm
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/运算。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/运算.wasm
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/受参。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/受参.wasm
豫构 构建 值桥接生成 --输出 豫言操作系统/宿主/浏览器/构建/值桥接生成。林檎。豫行
env 豫言内存上限=2048 ./豫言操作系统/宿主/浏览器/构建/值桥接生成。林檎。豫行 豫言操作系统/宿主/浏览器/构建/值桥.wasm
node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs 豫言操作系统/宿主/浏览器/构建 18791
```

出名以 `.wasm` 结则用网页汇编后端。先验类者，以同样 `文件`、`--外部包目录` 之参，续 `-- --type-check-only`。乙路察点之选入工具链后，三编译之命续 `-- --让行检查点`，并核纯算役之分时。值桥生成之程经本机行在保护而行，林纳者名 `值桥接生成。林纳。豫行`。

浏览器启 `http://127.0.0.1:18791/浏览器/构建/多任务。测试.html?自动`。页先编三模，乃二工并派十二役，各六：四受字而回声，四积筹约一秒，四陈独有之参；逐核零退码与所期之声；其一中文之入逾一 MiB，并核“续”之分块答复。复派三待读役，终其一，核退码百三十、工存、同工邻役仍回声而善终。页逐条示“通过”或“失败”，`html` 之 `data-测试` 终记其果；逾时告败，并清进程表。按“开始测试”可复试。

`让行。测试.html` 验让行之察点：径取同目之 `值桥.wasm`、`长算.wasm`、`回声.wasm`，二样须以识 `--让行检查点` 之豫构编之（yybs 85060da544 以后），编令同上，末续 `-- --让行检查点`；`长算` 之源在 `测试样例/长算。豫`，书“开算”而后无尽累加，不问东道。页先核 `长算.wasm` 入 `yuyan:browser/v1` 之 `让行`，乃派三役于二工：长算与一回声同工，余一回声别工。长算既开，送一行于同工之回声，须三秒内毕（让行之察点依十毫秒之片让出事环）；乃终长算，须三秒内得退码一百三十，工存。浏览器启 `http://127.0.0.1:18791/浏览器/构建/让行。测试.html?自动`，果亦书于 `html` 之 `data-测试`。
