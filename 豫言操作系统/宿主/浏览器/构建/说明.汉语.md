# 浏览器构建客户端

这是[网页编译接口](../../../../豫寓榫卯/网页编译/规范.汉语.md) 0.2 “本地构建”的构建客户端参考实现：在浏览器里展开仓库源码快照与 Wasm 工具链，用豫构等豫言工具运行检查、类型检查、构建与测试。云工作台的网页临时算力用它执行云端排队的构建作业；源码与产物都只在内存里，结束后丢弃。

## 组成

- `客户端.mjs`：入口，导出 `浏览器构建(作业, 报告)`、`停止构建()`、`构建可用()`。取快照与工具链（gzip 的 tar，可存进 Cache Storage），展开到内存文件系统的 `/仓库`，应用改动，把工具链里的编译器与豫构放到 `/仓库/编译器.wasm`、`/仓库/豫构.wasm`，再依次运行命令。
- `文件系统.mjs`：内存文件系统（文件与目录，修改时间以秒计）与 tar 展开（ustar、pax 扩展头、GNU 长名；符号链接略过）。
- `进程.mjs`：主线程的进程表。每个豫言程序是一个进程，JSPI 模式下共享处理器 Worker 池，旧模式下各占一个 Web Worker；进程的输出与退出码存在这里等父进程收取。语义照 Node 工具宿主的进程桥接：启动返回句柄（负数为错误码），收取返回五项，多路等待只认子进程句柄。不是 Wasm 的程序只认 `mkdir`、`rm`、`cp`、`mv`、`true`、`false`；`env`、`timeout` 包装在这里拆开。父进程结束时收拾它没人收取的子任务记录：已结束的删去，运行中的改挂给初始任务（第一个建的记录），它们结束之后也不再留存（提案 00043 第六条）。「亲行」（继承标准输入的同步运行）让子进程读父进程的标准输入，输入结束标志与原始模式都在父进程的输入上，子进程结束不关闭它；父进程有输出观察者时，子进程的输出随出随转给它（同原生继承标准流，提案 00043 第五条）。打断任务正号连同全部子孙、负号只打断子孙，退出码 130；负号没有子孙可断时给这个任务的工作线程置打断标志并返回二，任务留着（提案 00043 第六步）。
- `工作线程.mjs`：客体工作线程。标准库与构建基础的带类型导入经共用胶水 `边界.mjs` 接入；文件、子进程、摘要请求经共享内存向主线程提问（JSPI 模式以 `Atomics.waitAsync` 挂起任务，旧模式以 `Atomics.wait` 阻塞线程；答复长于 1 MiB 时分块续取），所以页面必须跨源隔离。问答一直用结构化克隆传请求、按 `编码.mjs` 的二进制编码传答复，不走文字。答复是错误时，控制字第 4 格带错误的码（文件系统给底层状态码，如不存在 44、是目录 31、无空间 51）；工作线程据它把读、删除、改名、写文件的失败抛成可接的豫言异常（消息与执行器同文：读、删、改名带“错误码 码”，写文件带底码的说明文字，2026-10-26，议题 723）。「阅帛片」把路径、偏移与字节数放进「读片」请求交主线程，主线程从内存文件系统取这一段答复：帛原样传、不经文字；单次至多一兆字节，卷比所要的短时按实有的返回，字节数为零得空帛，负的偏移或字节数报参数无效（错误码 28），文件不存在报不存在（44），失败都抛成可接的豫言异常（2026-10-26，议题 786）。有 JSPI 时 `_start` 在独立的 Wasm 栈上运行，避免编译器深递归撑破工作线程的栈。构建基础的「装网汇单元」同诺驿宿主：把单元装进本线程的进程（共用零号表、异常标签与已装导出），暂以给定的参数与程序名运行它的 _start（提案 00043）。各任务另有自己的打断标志字与打断例程（提案 00043 第六步）：网页行在里现编的句子单元导入 `yuyan:browser/v1` 的 `interrupt`，每进函数、每个跳转之前调用它；例程读标志字，置位就抛专用异常。「装网汇单元」运行前清标，接住这个异常时返回二，会话据此印“已打断”后接着读下一句。标志字的缓冲由任务与主线程共享，由进程表置标。
- `编码.mjs`：主线程答复值的二进制编码（无、爻、小数、大整数、文字、字节、数组）。
- `豫寓.mjs`：网页行在（提案 00043）用的豫寓（豫言操作系统接口）十个接口的工作线程侧实现：显示、字体、剪贴板、设备、任务、子程序与子程序显示、时间、声音、文件；要共享的经同步提问交主线程（进程表的外务）。声音每条流一条环形缓冲，与音频线程里的工作件（`../行在/声音工作件.mjs`）共用：工作线程直接写样本，打开与关闭经同步提问交主线程；缓冲放不下一整块时整块退回。进程表另有字节缓冲的标准输入（读行、读键、原始模式、是否终端）、交互子程序、增量取出、按区读写文件与打断任务（正号连同全部子孙、负号只打断子孙，退出码 130；负号没有子孙时置标并返回二，见 0.10.0 子程序规范）；系统环境作每个进程环境的缺省；父进程结束时关闭它的交互子程序的标准输入。
- `边界.mjs`：仓库里转出 `../../网页汇编/边界.mjs`；平铺发布时由构建步骤换成胶水本体。

## 本机验证

旧模式下构建工作线程与诺驿宿主采用相同的回收时机：每四次任务换一个线程，空闲250毫秒后释放线程，回收跨任务累积的Wasm堆高水位。子进程输出、退出码和父进程收取句柄保留至收取完成。

浏览器宿主接受每个构建作业至多 25600 条命令，每条至多 25600 个字符串参数，供多包合入前检查依次执行。

`../构建。测试服务.mjs` 以 `豫言操作系统/宿主/` 为根提供静态文件，`/资料/…` 取给定目录里的快照与工具链，每个响应都带 COOP、COEP 头。测试页 `../构建。测试页.html` 从网址参数取快照、工具链与命令，把输出与结果写进 `#结果`，结束时 `<html>` 带 `data-构建="完成"`。

```sh
mkdir -p 构建资料
git archive --format=tar.gz --prefix=yuyan-快照/ HEAD > 构建资料/快照.tar.gz
cp <Wasm 工具链包.tar.gz> 构建资料/工具链.tar.gz
node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs 构建资料 18790
# 浏览器打开（命令是 encodeURIComponent 过的 JSON）：
# http://127.0.0.1:18790/浏览器/构建。测试页.html?快照=/资料/快照.tar.gz&工具链=/资料/工具链.tar.gz&命令=[["豫构.wasm","类型检查","结绳工具"]]
```

**记录**：2026-10-06 在 Apple M5 Pro（18 个硬件线程）、无头 Chrome 154 上，用 CI 的 Wasm 工具链包（d883137fe）与 yybs 快照（约 5000 个文件）：`检查 结绳工具` 0.4 秒，`类型检查 结绳工具` 冷缓存 5.8 秒（175 个编译子进程，最多 18 个并行；同机 Node 冷缓存 5.6 秒），`构建 结绳工具 结绳访问。测试` 1.9 秒，运行测试 18 项全过；连同取快照与展开共 8.3 秒。

待办事项：构建缓存（`.豫构缓存/sha256_*.nosync`）可存进 IndexedDB 复用；同卷并发写入的互斥与 TCP 中继接线留待后续版本。

## 处理器池独立验收

处理器池、任务状态、挂起调用、让行与结束任务的规则见[网页行在说明](../行在/说明.汉语.md#处理器池与让行)。JSPI 模式复用固定数目的处理器 Worker 池，旧模式沿用每任务一个 Worker。`编码.mjs` 另提供宿主步骤的同步及异步续行、浏览器系统调用边界转换；发行流程原有的文件清单携带这些实现。声音流表随各任务的接口实现建立。

`多任务。测试.html` 直接从同目录取 `值桥.wasm`、`回声.wasm`、`运算.wasm`、`受参.wasm`。三个程序的源码位于 `测试样例/`，包配置为本目录的 `处理器池试。包。豫`，复用本目录双语说明，以“构建”为所有者、以“处理器池试”为包名，依赖显式指向“豫言”的“豫章（标准库）”。从仓库根按以下顺序逐条执行；PATH 上的豫构使用缺省的本机将作（构建服务），每次等待当前命令完成后再执行下一条。开始前 `豫构 行在 状态` 应显示进程号与端口。

```sh
豫构 行在 状态
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/回声。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/回声.wasm
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/运算。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/运算.wasm
豫构 文件 豫言操作系统/宿主/浏览器/构建/测试样例/受参。豫 --外部包目录 豫言操作系统/宿主/浏览器 --输出 豫言操作系统/宿主/浏览器/构建/受参.wasm
豫构 构建 值桥接生成 --输出 豫言操作系统/宿主/浏览器/构建/值桥接生成。林檎。豫行
env 豫言内存上限=2048 ./豫言操作系统/宿主/浏览器/构建/值桥接生成。林檎。豫行 豫言操作系统/宿主/浏览器/构建/值桥.wasm
node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs 豫言操作系统/宿主/浏览器/构建 18791
```

`.wasm` 输出名选择网页汇编后端。样例可先以同样的 `文件`、`--外部包目录` 参数，追加 `-- --type-check-only` 做类型检查。乙路的编译器选项合入工具链后，三个编译命令追加 `-- --让行检查点`，可同时核查纯计算任务的分时。值桥生成程序在本机行在保护下运行，林纳宿主的生成程序名使用 `值桥接生成。林纳。豫行`。

浏览器打开 `http://127.0.0.1:18791/浏览器/构建/多任务。测试.html?自动`。页面预编译三个模块后同时派十二个任务到两个 Worker，各六个：四个读行回显、四个计算约一秒、四个打印独有参数，逐项核零退出码与精确输出；一条中文输入超过一 MiB，用来核对“续”的分块答复。随后派三个待读任务，结束其中一个，核退出码一百三十、Worker 保留、同 Worker 的另一个任务继续回显并正常退出。页上逐项显示“通过”或“失败”，`html` 的 `data-测试` 最终为同名结果；超时按失败报告并统一清理进程表。点击“开始测试”可重复执行。
