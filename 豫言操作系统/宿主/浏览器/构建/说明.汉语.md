# 浏览器构建客户端

这是[网页编译接口](../../../../豫言操作系统接口/网页编译/规范.汉语.md) 0.2 “本地构建”的构建客户端参考实现：在浏览器里展开仓库源码快照与 Wasm 工具链，用豫构等豫言工具运行检查、类型检查、构建与测试。云工作台的网页临时算力用它执行云端排队的构建作业；源码与产物都只在内存里，结束后丢弃。

## 组成

- `客户端.mjs`：入口，导出 `浏览器构建(作业, 报告)`、`停止构建()`、`构建可用()`。取快照与工具链（gzip 的 tar，可存进 Cache Storage），展开到内存文件系统的 `/仓库`，应用改动，把工具链里的编译器与豫构放到 `/仓库/yy4_bs.wasm`、`/仓库/yy豫构.wasm`，再依次运行命令。
- `文件系统.mjs`：内存文件系统（文件与目录，修改时间以秒计）与 tar 展开（ustar、pax 扩展头、GNU 长名；符号链接略过）。
- `进程.mjs`：主线程的进程表。每个豫言程序是一个进程，占一个 Web Worker；进程的输出与退出码存在这里等父进程收取。语义照 Node 工具宿主的进程桥接：启动返回句柄（负数为错误码），收取返回五项，多路等待只认子进程句柄。不是 Wasm 的程序只认 `mkdir`、`rm`、`cp`、`mv`、`true`、`false`；`env`、`timeout` 包装在这里拆开。
- `工作线程.mjs`：客体工作线程。标准库与构建基础的带类型导入经共用胶水 `边界.mjs` 接入；文件、子进程、摘要请求经共享内存向主线程同步提问（`Atomics.wait` 阻塞到答复，答复长于 1 MiB 时分块续取），所以页面必须跨源隔离。有 JSPI 时 `_start` 在独立的 Wasm 栈上运行，避免编译器深递归撑破工作线程的栈。
- `编码.mjs`：主线程答复值的二进制编码（无、爻、小数、大整数、文字、字节、数组）。
- `边界.mjs`：仓库里转出 `../../网页汇编/边界.mjs`；平铺发布时由构建步骤换成胶水本体。

## 本机验证

`../构建。测试服务.mjs` 以 `豫言操作系统/宿主/` 为根提供静态文件，`/资料/…` 取给定目录里的快照与工具链，每个响应都带 COOP、COEP 头。测试页 `../构建。测试页.html` 从网址参数取快照、工具链与命令，把输出与结果写进 `#结果`，结束时 `<html>` 带 `data-构建="完成"`。

```sh
mkdir -p yy构建资料
git archive --format=tar.gz --prefix=yuyan-快照/ HEAD > yy构建资料/快照.tar.gz
cp <Wasm 工具链包.tar.gz> yy构建资料/工具链.tar.gz
node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs yy构建资料 18790
# 浏览器打开（命令是 encodeURIComponent 过的 JSON）：
# http://127.0.0.1:18790/浏览器/构建。测试页.html?快照=/资料/快照.tar.gz&工具链=/资料/工具链.tar.gz&命令=[["yy豫构.wasm","类型检查","结森工具"]]
```

**记录**：2026-10-06 在 Apple M5 Pro（18 个硬件线程）、无头 Chrome 154 上，用 CI 的 Wasm 工具链包（d883137fe）与 yybs 快照（约 5000 个文件）：`检查 结森工具` 0.4 秒，`类型检查 结森工具` 冷缓存 5.8 秒（175 个编译子进程，最多 18 个并行；同机 Node 冷缓存 5.6 秒），`构建 结森工具 结森访问。测试` 1.9 秒，运行测试 18 项全过；连同取快照与展开共 8.3 秒。

待办事项：构建缓存（`.yybuild/sha256_*.nosync`）每次从零开始，可存进 IndexedDB 复用；并发写同一文件不加锁；没有标准输入、终端与 TCP。
