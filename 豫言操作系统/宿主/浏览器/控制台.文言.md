# 控制台宿主之实

此为 Node 与浏览器可共用之具名控制台能力之治。`创建控制台能力` 受授权映射，各项供 `读取行`、`写文本` 及可有之 `关闭`；读回调还“有行否、原文”，许 Promise。宿主内果为“状态码、正文、错误文字”：零为成，一为未授，三为闭后失效，四为输入尽，七为输入无效或重候，八为宿主败。适配原语须用异步返回之签。

各具名台惟一读候，异台各立。闭先终诸候，乃清提供者，后至之果不入次读。空行与输入尽别，惟去行尾，不析命令。写存原文而候提供者成。

Node 之 `../节点/控制台.mjs` 供实文件描述符后端，逐字读至一行，受 UTF-8、CRLF、空行及无新行之末行，不先夺后行。写治部分之写。今 Node 读用同步文件描述符之术；下层挂住，不可由同线程主动取消，异步取消待后成。

行 `node --test 豫言操作系统/宿主/浏览器/控制台。测试.mjs 豫言操作系统/宿主/节点/控制台。测试.mjs`，五验皆过，其中 Node 用实子进程标准入出之管。此阶段未接原语映射、适配包与原壳，不可以此称公共 Wasm 控制台或浏览器原壳可用。
