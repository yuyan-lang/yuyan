# 网页行在

网页行在（提案〇〇〇四三）者，浏览器中之豫言操作系统也：标签即行在（宿主常驻之系统，提案〇〇〇三九），开机之壳为豫构交互，与裸机、宿主之行在同一程序。壳中每句豫言皆于浏览器编为网页汇编之单元，装于开机壳所在之进程而行之。

## 所成

- `行在.html`：页。示开机壳之出，送输入之框一行于开机壳之标准入；上下键翻本页旧行。发布时易名为 `行在/index.html`。
- `行在.mjs`：取二快照展于内存之文件系统，立进程表，起开机壳 `/工具/豫构.wasm 交互 --直读 --提示`（今目 /，共缓存之根 `/tmp/豫构缓存`，不起将作与行在）。
- 进程表、工作线程与内存之文件系统承浏览器构建宿主（`../构建/`）：一任务一 Web Worker，文件、子进程、标准入经共享之存同步问于主线程，故页须跨源隔离。

## 快照

- `源.tar.gz` 展为 /源：豫章（标准库）与诏令（壳命令库）二包之源，并 `库/` 下诸包之述与说明。开机壳初编句时先编前导（三十余模），此后每句惟编其句。
- `工具.tar.gz` 展为 /工具：网页汇编之豫构 `豫构.wasm` 与诺驿值桥 `节点值桥接.wasm`。
- 仓库目标「用户态系统浏览器发行」生二快照与页（发行目录下之 `行在/` 与 `构建/`），云仓布发行目录于站之 `/操作系统/`，官网路由于 `/操作系统/行在/` 与 `/操作系统/构建/` 加跨源隔离之头。

## 本机之验

置二快照于一资料之目，行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`，浏览器开 `http://127.0.0.1:18791/浏览器/行在/行在.html?源=/资料/源.tar.gz&工具=/资料/工具.tar.gz`。
