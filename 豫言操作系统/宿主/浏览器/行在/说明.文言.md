# 网页行在

网页行在（提案〇〇〇四三）者，浏览器中之豫言操作系统也：标签即行在（宿主常驻之系统，提案〇〇〇三九），开机之壳为豫构交互，与裸机、宿主之行在同一程序。壳中每句豫言皆于浏览器编为网页汇编之单元，装于开机壳所在之进程而行之。

## 所成

- `行在.html`：页。页之终端示开机壳之出，键原样付开机壳之标准入；点屏即可书。页脚书语言仓之提交号（站布时书于 `/操作系统/来源提交`），报误则知其版。发布时易名为 `行在/index.html`。
- `行在.mjs`：取快照展于内存之文件系统，接秘府，立进程表，起开机壳 `/工具/豫构。豫行 交互`（交互之参取 /系统/开机。数据。豫 之「交互参数」，默 --组字，同裸机开机壳；标准入以终端视之；今目 /，共缓存之根 `/tmp/豫构缓存`，不起将作与行在；/系统/开机自启 每行一句为开头之句）。
- `秘府.mjs`：秘府（站之私有文件系统）之读入与书回，见下“秘府”。
- `终端.mjs`：页之终端。惟识回车、换行、退格、制表与常用之 CSI 序（移标、擦行、清屏），非 ASCII 之字占二格（同组字之「输入格宽」）；开机壳入原始之制（组字）则每键径送，否则页自回显、自理退格，至回车乃送一行（同终端之规范之制）。中文输入法所上之字亦送之。
- 进程表、工作线程与内存之文件系统承浏览器构建宿主（`../构建/`）：一任务一 Web Worker，文件、子进程、标准入经共享之存同步问于主线程，故页须跨源隔离。

## 快照

- `源.tar.gz` 展为 /源：前导与行在四部所编之源（豫章（标准库）、诏令（壳命令库）、几席、中书与豫寓榫卯，又屏键之部截屏所需画谱、勘合、括囊三包顶层之源），并全仓诸包之述与说明。开机壳初编句时先编前导（三十余模），此后每句惟编其句。
- `工具.tar.gz` 展为 /工具：网页汇编之豫构 `豫构。豫行` 与诺驿值桥 `节点值桥接.wasm`。
- `桌面.tar.gz` 亦展于 /工具：图形桌面 `图形桌面。豫行` 与桌面程序 `桌面程序。豫行`（压后约十八点六兆），初入桌面乃取。/工具 之名同豫言操作系统之 /工具。
- 仓库目标「用户态系统浏览器发行」生三快照与页（发行目录下之 `行在/` 与 `构建/`），云仓布发行目录于站之 `/操作系统/`，官网路由于 `/操作系统/行在/` 与 `/操作系统/构建/` 加跨源隔离之头。

## 秘府

盘之余，除快照所来之 /源、/工具 与暂用之 /tmp（/数据、/系统、/软件 与根下之文，如桌面设置之库 /桌面设置.数据库），皆存于秘府（站之私有文件系统）之 `网页行在` 目，重载犹在。

- 开机则举秘府之树读入内存之文件系统，乃撤 /系统/桌面运行中（同裸机“开机时标阴”）。/系统/开机自启 每行一句，为开机壳之开头句，行于首提示之前，同裸机之开机壳；所留 /系统/请求进入桌面 开机则办之。
- 其后内存文件系统于此诸径之书、删、易名与建目皆记之，三百毫秒而整篇书回秘府（一径屡改惟书一次），阖页则并书所积。
- 一时惟一标签书回（网页之锁 `网页行在秘府`）；余标签如常读入，所改惟存本页之内存，开机时状态栏言之。
- 浏览器之“清除网站数据”尽去秘府。

## 双端之对

「原生对比」（`应用/百工坊/原生对比`）之「交互」场以同一组句（定而后用、裸式印值、组合之句、编译之误、未承之异）分付原生之豫构交互与 Node 上 `豫构.wasm` 之交互，所出须逐字同；网页行在所行即 Node 一边之同一网页汇编之程。CI 抽样之轮“原生与 Node 性能对比”一步默行之，二边异则败。

## 字体

发行目录之 `字体/` 携思源黑体、原始字体、默认等宽黑体三套与许可，`字体.ttf` 为文楷。页依族名各宣之：`文楷` 用 `../字体.ttf`，`无衬线`、`汉字`、`符号`、`圆体`、`数学` 用 `../字体/思源黑体.otf`，`衬线`、`手写`、`装饰`、`仿宋` 用 `../字体/原始字体.ttf`，`等宽` 用 `../字体/默认等宽黑体.otf`；`Arial`、`Helvetica`、`黑体`、`Times New Roman`、`宋体`、`Courier New`、`Menlo` 等具体之名与 `serif`、`sans-serif`、`monospace`、`system-ui` 等通用之名亦各宣一条。粗体之名不宣，字体选取取不到真粗面则返常规而仿之。`字体基` 网址之参另指字体之目，`字体` 之参以诸族共指一文。

## 本机之验

置三快照于一资料之目，行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`，浏览器开 `http://127.0.0.1:18791/浏览器/行在/行在.html?源=/资料/源.tar.gz&工具=/资料/工具.tar.gz&桌面=/资料/桌面.tar.gz`。字体依族名取于 `字体基`（默为站之 `/操作系统/字体/`）；本机开发以 `字体基` 指仓内 `豫言操作系统/裸机/字模生成/字体/` 之网址，`字体=` 犹可令诸族共指一文。

## 桌面

开机壳之环境 豫言行在=网页，壳乃依宿主行在之会话装「任务」「图形」「屏键」「电源」四部（部之源在 /源，初用乃于浏览器编之）。「图形」书 /系统/请求进入桌面，行在（主线程）删之、书 /系统/桌面运行中，令页惟留名“主窗口”之画布，起 /工具/图形桌面。豫行，环境另加 豫言桌面程序=/工具/桌面程序。豫行；桌面退则撤标、复命令行。

图形桌面与壳之部以带型之导入径呼豫寓之接口（同原生执行器之“路二”），工作线程中之实见 `../构建/豫寓.mjs`：显示面、字体、剪贴、读屏与拟入办于主线程（显示面表与画布后端承 `../图形.mjs`），文件依授权之根“桌面”=/ 读写内存之文件系统，子程序经进程表起（交互之子以终端视之，可入原始之制），任务表列进程表中方行之务，「辍役」毁其务及诸子孙之工作线程（退码百三十）。桌面终端所起者即 /工具/豫构。豫行 交互 --组字 之会话，与开机壳同一壳。

一窗一务（提案〇〇〇一五）：九宫（平铺桌面库）见 豫言桌面程序，乃如裸机以「遣使附映面」起每窗（终端、文件浏览、任务管理器等）为一 /工具/桌面程序。豫行 之务，而转授一显示面。行在为之代管其面：窗务所交之画存为整画布与所变之区，桌面以「取使者画面」取之；桌面所送之入事排于窗务之事列；尺与像素比由桌面设之。窗务须外壳办者（如终端中「辟窗」开新窗）以「请外壳办」交桌面，桌面之来信以「送程序来信」还之。终端之窗务又起 /工具/豫构。豫行 交互 --组字 之会话。桌面退则诸窗务之面随闭，窗务自退，终端会话读尽亦退。

宫（工作区）各有一面：主画布带 `data-yy-显示面前缀="宫"`，桌面取“宫二”“宫三”……之面，行在（主线程）于浏览器开同源之小窗，内置带 `data-yy-显示面="宫二"` 之画布与隐 input，尺、像素比与入事皆依小窗算。浏览器以弹窗之许或用户之手势拦之，则此面不得，桌面令其宫共用主画布；用户阖小窗即此面「显示面已关闭」，还此面则小窗随之闭。「题映面」设小窗之题，九宫以每宫焦点窗口之题题之。桌面之多面会话以「待诸面入事限时」并候数宫：还至事面之序（自零起），漏尽则序负一而事为「显示计时」；只候一面则同「待入事限时」。

后续版本：声、「辍」惟断一句（提案〇〇〇四三第五步）、秘府依块书回大文。
