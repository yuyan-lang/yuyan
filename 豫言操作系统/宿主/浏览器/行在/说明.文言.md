# 网页行在

网页行在（提案〇〇〇四三）者，浏览器中之豫言操作系统也：标签即行在（宿主常驻之系统，提案〇〇〇三九），开机之壳为豫构交互，与裸机、宿主之行在同一程序。壳中每句豫言皆于浏览器编为网页汇编之单元，装于开机壳所在之进程而行之。

## 所成

- `行在.html`：页。页之终端示开机壳之出，键原样付开机壳之标准入；点屏即可书。页脚书语言仓之提交号（站布时书于 `/操作系统/来源提交`），报误则知其版。发布时易名为 `行在/index.html`。
- `行在.mjs`：取快照展于内存之文件系统，接秘府，立进程表，起开机壳 `/工具/豫构。豫行 交互`（交互之参取 /系统/开机。数据。豫 之「交互参数」，默 --组字，同裸机开机壳；标准入以终端视之；今目 /，共缓存之根 `/tmp/豫构缓存`，不起将作与行在；/系统/开机自启 每行一句为开头之句）。
- `秘府.mjs`：秘府（站之私有文件系统）之读入与按区之书回，见下“秘府”。
- `终端.mjs`：页之终端。惟识回车、换行、退格、制表与常用之 CSI 序（移标、擦行、清屏），非 ASCII 之字占二格（同组字之「输入格宽」）；开机壳入原始之制（组字）则每键径送，否则页自回显、自理退格，至回车乃送一行（同终端之规范之制）。中文输入法所上之字亦送之。
- `声音.mjs`：主线程之声出。持一声境与声之工作件；每流一环形之缓，与工作线程共之，工作件于音之线程读而奏之。初按键或点则复其声境（浏览器之自动播禁须先有手势）。
- `声音工作件.mjs`：音之线程之工作件（AudioWorklet 之处理器，`registerProcessor('豫寓鸣', …)`）。自环形之缓读交错十六位之样，缓空则补静音；浏览器之采率异于开时所请者，则于此侧以线性插值重采之。已播之帧即其读位。
- 进程表、工作线程与内存之文件系统承浏览器构建宿主（`../构建/`）：一任务一 Web Worker，文件、子进程、标准入经共享之存同步问于主线程，故页须跨源隔离。

## 单应用之启与主站外壳

`单应用.mjs` 者，网页行在之别启法也（云仓提案〇〇〇〇五）：不起开机之壳、不装诸部、不现编句，径以构时预编之应用（豫行，网页汇编之模）为初始之任而全窗行之，以地址栏之径为第一命令行之参授之（径先解其百分号之编而复汉字，问参原样附焉）。惟展一工具之档（`工具.tar.gz`：应用与值桥），不携桌面、工具、源与字。`起单应用` 先示全窗之面而后启应用：面未示则布局之尺为零，应用量面即得“资源暂不可用”。

外务有六：显示面；网页导航（豫寓向导：前往、替换当前、重载、压入史、易史、移史）；网页文树之「读页驿址」；网页请求（豫寓网索：阻塞之「索网页文字」、发起之「发起网页索」与「罢网页索」）；网页事件（豫寓网事：「待网页事」与窗口之 popstate、hashchange 订阅，请求之果亦投同列）；剪贴板（豫寓夹袋：写则页中记一份而试写系统之夹袋，读则取此份）。皆在 `行在/网页外务.mjs`：工作线程同步而问，主线程以延后之答应之（`fetch`、夹袋、历史之事皆然），故豫言视之如阻塞之调（同「待入事限时」之法）。字体、声出与子程序代办无之，应用问之则报“接口函数未绑定”。

`../外壳/` 者，主站之页壳也：极小之载器（`外壳.html` 与 `外壳.mjs`），主站每径皆回此页。先依 `../引导检查.mjs` 之「检查浏览器支持」验 WasmGC 与 JSPI，复验跨源隔离（SharedArrayBuffer）、Worker 与 DecompressionStream；不具则惟书一行，附 `https://docs.yuyan-lang.org<同径>` 之链；具则载 `单应用.mjs`，取 `../工具.tar.gz`（网址之参 `快照=` 可另指）与 `/工具/问好。豫行`（网址之参 `应用=` 可另指），以 `location.pathname + location.search` 授之。应用之画满铺于窗，应用退则页书退码与文档站同径之链。

跨源隔离三头书于 `../外壳/_headers`（Cloudflare Pages 之应头规）：`Cross-Origin-Opener-Policy: same-origin`、`Cross-Origin-Embedder-Policy: require-corp`、`Cross-Origin-Resource-Policy: same-origin`，照线上 `/操作系统/行在/` 之法。服务器或过渡之 Worker 回此壳时，于同处书此三头。

精简之开机包由仓库之目标编出：`豫构 目标 主站精简开机`，产物在仓根之 `主站精简开机/`：`外壳/`（index.html、外壳.mjs）、`行在/单应用.mjs`、`构建/`（进程表、工作线程、豫寓之口、内存之文件系统、编码与其边界胶水之体）、`显示.mjs`、`工具.tar.gz`（工具/问好。豫行 与 工具/节点值桥接.wasm）与 `_headers`，共约二百六十千字节。示例之应用曰 `问好`（`豫言操作系统/应用/问好`）。其步不起宿主之令：摹卷以「摹卷步」，打 `工具.tar.gz` 以新立之「吉合步」——于构建之程径呼典藏之「套打」，书为 ustar 之合档而六级吉缩之；应用与值桥皆以今行此豫构（「自豫构步」之「本程序径」）编之，免仓根之链仍旧而产物出于旧译（议四二五）。显示面之一部自 `../图形.mjs` 拆入 `../显示.mjs`（状码、事种、显示面之表、画布之后端、键名之译），简包惟带之；图形处理器、图形显示之桥与字体留于 `../图形.mjs`，其 `export *` 转出显示面诸术，行在与诺驿宿主取用如故。目标每先删发行之目而后陈之，免旧文之留。

本机之试：以 `主站精简开机/` 全置一资料之目，行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`（诸应皆加 COOP 与 COEP 之头），浏览器启 `http://127.0.0.1:18791/资料/主站精简开机/外壳/index.html`。当整屏见白地墨色之“你好”，点之则易朱，按 Escape 则见“应用已退出”与文档站之链；控制台依次见应用所印者：所受之参（地址栏之径，汉字原样）、“当前地址”、“订阅 popstate 得号”、取本页之响应结绳（`成` 为真、`状态` 二百、`字节数` 非零）；点一下后又有“压入 /甲/ 之前/之后，地址”、“已写剪贴板”与请按后退键之语，按浏览器后退键乃印所受网页事件之全结绳（`类型` 为 `历史`、`名称` 为 `popstate`、`详情.网址` 是原址）。

## 快照

- `源.tar.gz` 展为 /源：前导与行在诸部所编之源（豫章（标准库）、诏令（壳命令库）、几席、中书与豫寓榫卯，又屏键之部截屏所需画谱、勘合、括囊三包顶层之源），并全仓诸包之述与说明；又带 `tmp/豫构缓存`：发行时于宿主以网页汇编之豫构对同一份源行「预编前导」（豫言缓存目录设为同布局，豫言行在=网页），以前导与行在诸部之单元、阶缓依浏览器之径预编，单元中源文之径已易为 `/源`。开机壳初编句时先视前导之单元已备（单元目之印同于今所算者、且诸模之阶缓俱在今所算之处，乃为已备），备则径装之，不复于页面编前导（三十余模）；诸部初用时亦然，径装预编之单元，不复现编籍册、章句诸包。语义号、摘要或阶缓之号不合则如常现编：前导之阶缓一有不在，则视前导为未备，于页面重编，不告“阶缓不存”。
- `工具.tar.gz` 展为 /工具：网页汇编之豫构 `豫构。豫行` 与诺驿值桥 `节点值桥接.wasm`。
- `桌面.tar.gz` 亦展于 /工具：图形桌面 `图形桌面。豫行` 与桌面程序 `桌面程序。豫行`（压后约十八点六兆），初入桌面乃取。/工具 之名同豫言操作系统之 /工具。
- 仓库目标「用户态系统浏览器发行」惟生网页行在：三快照与页（发行目录下之 `行在/` 与 `构建/`）及三套之字与许可。云仓布发行目录于站之 `/操作系统/`，官网路由于 `/操作系统/行在/` 与 `/操作系统/构建/` 加跨源隔离之头。

## 秘府

盘之余，除快照所来之 /源、/工具（/数据、/系统、/软件 与根下之文，如桌面设置之库 /桌面设置.数据库），皆存于秘府（站之私有文件系统）之 `网页行在` 目，重载犹在。共编译之缓根 `/tmp/豫构缓存` 亦存于秘府；余之 /tmp 为暂用，不留。

- 开机则举秘府之树读入内存之文件系统，乃撤 /系统/桌面运行中（同裸机“开机时标阴”）。/系统/开机自启 每行一句，为开机壳之开头句，行于首提示之前，同裸机之开机壳；所留 /系统/请求进入桌面 开机则办之。
- 其后内存文件系统于此诸径之书、删、易名与建目皆记之，三百毫秒而书回秘府（一径屡改惟书一次），阖页则并书所积。书回按区而增：每书先较其旧文，惟按位书所改之区，末截至今长；有同步之访问句柄 `createSyncAccessHandle` 则用之，无则以可写之流按位书之。大文小改不须整篇重书。
- 缓根下之目依编译语义号而分（`/tmp/豫构缓存/<语义号>/`），开机读 /源 中 库/译场/译料/译设/语义号。数据。豫 之编译语义号，惟留今号之目，旧号之目则删；惟删 UUID 形之名，`交互缓存/` 之属留之。交互会话前导与诸部单元之目在缓根之 `交互缓存/网页行在/` 下（豫构之「交互缓存根」于网页行在为定处，议一四七、二二五），故重载而后前导之单元与阶缓俱在，首句不须复编前导。
- 一时惟一标签书回（网页之锁 `网页行在秘府`）；余标签如常读入，所改惟存本页之内存，开机时状态栏言之。
- 浏览器之“清除网站数据”尽去秘府。

## 任务与标准入

- 二「亲行」皆承调用者之标准入：子务所读者即页之终端入于会话之字，子务既退则还之，会话续读其余。豫章 使者 之「亲行」三流皆承（同原生），子务之出随出随示；豫寓 子程序接口之「亲行」惟承标准入，出与误仍收于宿主，随使报付于调用者（同原生）。
- 父务先退，则其无人收取之子务之录并收拾之：已毕者径除，犹行者改录于初始之务（开机壳），其毕而后亦不留于进程表。

## 双端之对

「原生对比」（`应用/百工坊/原生对比`）之「交互」场以同一组句（定而后用、裸式印值、组合之句、编译之误、未承之异）分付原生之豫构交互与 Node 上 `豫构.wasm` 之交互，所出须逐字同；网页行在所行即 Node 一边之同一网页汇编之程。CI 抽样之轮“原生与 Node 性能对比”一步默行之，二边异则败。

## 字体

发行目录之 `字体/` 携思源黑体、原始字体、默认等宽黑体三套与许可，`字体.ttf` 为文楷。页依族名各宣之：`文楷` 用 `../字体.ttf`，`无衬线`、`汉字`、`符号`、`圆体`、`数学` 用 `../字体/思源黑体.otf`，`衬线`、`手写`、`装饰`、`仿宋` 用 `../字体/原始字体.ttf`，`等宽` 用 `../字体/默认等宽黑体.otf`；`Arial`、`Helvetica`、`黑体`、`Times New Roman`、`宋体`、`Courier New`、`Menlo` 等具体之名与 `serif`、`sans-serif`、`monospace`、`system-ui` 等通用之名亦各宣一条。粗体之名不宣，字体选取取不到真粗面则返常规而仿之。`字体基` 网址之参另指字体之目，`字体` 之参以诸族共指一文。

## 本机之验

置三快照于一资料之目，行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`，浏览器开 `http://127.0.0.1:18791/浏览器/行在/行在.html?源=/资料/源.tar.gz&工具=/资料/工具.tar.gz&桌面=/资料/桌面.tar.gz`。字体依族名取于 `字体基`（默为站之 `/操作系统/字体/`）；本机开发以 `字体基` 指仓内 `豫言操作系统/裸机/字模生成/字体/` 之网址，`字体=` 犹可令诸族共指一文。

## 桌面

开机壳之环境 豫言行在=网页，壳乃依宿主行在之会话装「行在诸部名」中网页行在之数部（任务、图形、屏键、声音、电源、剪贴；部之源在 /源，单元随快照预编，初用径装之；单元目之印不合乃于浏览器编之）。「软件」部留待浏览器中装软件之版。「图形」书 /系统/请求进入桌面，行在（主线程）删之、书 /系统/桌面运行中，令页惟留名“主窗口”之画布，起 /工具/图形桌面。豫行，环境另加 豫言桌面程序=/工具/桌面程序。豫行；桌面退则撤标、复命令行。

图形桌面与壳之部以带型之导入径呼豫寓之接口（同原生执行器之“路二”），工作线程中之实见 `../构建/豫寓.mjs`：显示面、字体、剪贴、读屏与拟入办于主线程（显示面表与画布后端承 `../显示.mjs`（`../图形.mjs` 转其导出，并带图形处理器、图形显示桥与字体）），文件依授权之根“桌面”=/ 读写内存之文件系统，子程序经进程表起（交互之子以终端视之，可入原始之制），任务表列进程表中方行之务，「辍役」毁其务及诸子孙之工作线程（退码百三十）；号负而无子孙可断者，为会话之共享存置断标而返二，句子之卷中之察点见标抛专异，会话于句子之界印“已打断”而续读次句（提案〇〇〇四三第六步）。桌面终端所起者即 /工具/豫构。豫行 交互 --组字 之会话，与开机壳同一壳。

一窗一务（提案〇〇〇一五）：九宫（平铺桌面库）见 豫言桌面程序，乃如裸机以「遣使附映面」起每窗（终端、文件浏览、任务管理器等）为一 /工具/桌面程序。豫行 之务，而转授一显示面。行在为之代管其面：窗务所交之画存为整画布与所变之区，桌面以「取使者画面」取之；桌面所送之入事排于窗务之事列；尺与像素比由桌面设之。窗务须外壳办者（如终端中「辟窗」开新窗）以「请外壳办」交桌面，桌面之来信以「送程序来信」还之。终端之窗务又起 /工具/豫构。豫行 交互 --组字 之会话。桌面退则诸窗务之面随闭，窗务自退，终端会话读尽亦退。

宫（工作区）各有一面：主画布带 `data-yy-显示面前缀="宫"`，桌面取“宫二”“宫三”……之面，行在（主线程）于浏览器开同源之小窗，内置带 `data-yy-显示面="宫二"` 之画布与隐 input，尺、像素比与入事皆依小窗算。浏览器以弹窗之许或用户之手势拦之，则此面不得，桌面令其宫共用主画布；用户阖小窗即此面「显示面已关闭」，还此面则小窗随之闭。「题映面」设小窗之题，九宫以每宫焦点窗口之题题之。桌面之多面会话以「待诸面入事限时」并候数宫：还至事面之序（自零起），漏尽则序负一而事为「显示计时」；只候一面则同「待入事限时」。

## 声

声出之接口（豫寓鸣）于网页行在以 AudioWorklet 接浏览器之 Web Audio：

- 工作线程行豫言之程，`辟声出` 时造环形之缓（SharedArrayBuffer，容至少六万五千五百三十六帧，块大者依二之幂增之），经同步之问以缓交主线程，得其流号；主线程造 AudioWorkletNode，置缓于处理器之选项，工作件乃于音之线程读之。
- 控制之字八，皆三十二位之整：写帧位（工作线程书）、读帧位（工作件书，即已播之数）、设备延迟帧（主线程书），余待用；样自第三十二字节起，交错十六位小端。
- 缓不容一整块则整块退之，得「资源配额已尽」（同接口规范宿主限其队列之量）；缓空则工作件补静音。已播之帧与声出之延皆读共享之控制字，不复问主线程。
- 浏览器之采率异于开时所请者，工作件以线性插值重采之，已播之帧仍依开时之率计。
- 浏览器之自动播禁须先有手势：`声音.mjs` 于初按键或点（document 捕获之际）复其声境，此后之流随开随奏。开机自启所放之音，须待用户一按乃出。
- 程毕则行在阖其所开之流（进程表之「结务」），声境留以待后程。
- 壳中「试声」（放一秒七百五十赫之试音）所行即此途，由声之一部之做法（`库/几席/声令。豫`）调豫寓鸣；放毕印已播之帧，实机以耳验之。
- 同一工作线程之实，于浏览器构建宿主亦用之；彼无主线程之声外务，`辟声出` 仍得「资源暂不可用」。

## 终端与打断

页之终端按 Ctrl+C 时，除送控字三于开机壳，复经进程表以负之任务号呼「辍役」（提案〇〇〇四三第六步）：壳方行一句则置断标，句中之察点抛专异，壳会话印“已打断”而续读次句；方行子程序则终其子程；停于提示则惟弃方入之行，所置断标随下句之始而清。
