# 网页行在

网页行在（提案 00043）是浏览器里的豫言操作系统实例：标签页就是行在（宿主常驻系统实例，提案 00039），开机壳是豫构交互，与裸机、宿主上的行在同一份程序。壳里每句豫言都在浏览器里编成网页汇编单元，再装进开机壳所在的进程运行。

## 组成

- `行在.html`：页面。显示开机壳的输出，把输入框里的一行送进开机壳的标准输入；上下键翻本页输入过的行。发布时改名为 `行在/index.html`。
- `行在.mjs`：取两个快照展开到内存文件系统，建进程表，起开机壳 `/工具/豫构。豫行 交互 --直读 --提示`（当前目录 /，共享缓存根 `/tmp/豫构缓存`，不起将作与行在）。
- 进程表、工作线程与内存文件系统沿用浏览器构建宿主（`../构建/`）：每个任务一个 Web Worker，文件、子进程、标准输入经共享内存向主线程同步提问，所以页面要跨源隔离。

## 快照

- `源.tar.gz` 展成 /源：豫章（标准库）与诏令（壳命令库）两包的源码，加 `库/` 下全部包描述与说明。开机壳第一次编句时先编前导（三十多个模块），之后每句只编这一句。
- `工具.tar.gz` 展成 /工具：网页汇编的豫构 `豫构。豫行`、图形桌面 `图形桌面。豫行` 与诺驿值桥 `节点值桥接.wasm`，名字与豫言操作系统 /工具 里的相同。
- 仓库目标「用户态系统浏览器发行」生成两个快照与页面（发行目录下的 `行在/` 与 `构建/`），云仓把发行目录发布到站点的 `/操作系统/`，官网路由给 `/操作系统/行在/` 与 `/操作系统/构建/` 加跨源隔离头。

## 本机验证

把两个快照放进一个资料目录，运行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`，浏览器打开 `http://127.0.0.1:18791/浏览器/行在/行在.html?源=/资料/源.tar.gz&工具=/资料/工具.tar.gz`。

## 桌面

开机壳的环境里 豫言行在=网页，壳就按宿主行在会话装「任务」「图形」「屏键」「电源」四部（部的源码在 /源，第一次用到时在浏览器里编）。「图形」写下 /系统/请求进入桌面，行在（主线程）删去它、写下 /系统/桌面运行中，让页面只留名为“主窗口”的画布，起 /工具/图形桌面。豫行；桌面退出后撤下标志、回到命令行，它起的终端会话随之读到输入结束而退出。

图形桌面与壳的部用带类型导入直接调豫寓接口（同原生执行器的“路二”），工作线程里的实现见 `../构建/豫寓.mjs`：显示面、字体、剪贴板、读屏与合成输入在主线程办（显示面表与画布后端沿用 `../图形.mjs`），文件按授权根“桌面”=/ 读写内存文件系统，子程序经进程表起（交互子程序当终端，可入原始模式），任务表列进程表里运行着的任务。桌面终端起的就是 /工具/豫构。豫行 交互 --组字 会话，与开机壳同一个壳。

后续版本：桌面程序独立成任务（豫寓使者映）、声音、/数据与/系统存进站点私有存储、开机壳逐键组字、「辍」只打断一句（提案 00043 第三至五步）。
