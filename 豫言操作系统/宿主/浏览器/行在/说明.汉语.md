# 网页行在

网页行在（提案 00043）是浏览器里的豫言操作系统实例：标签页就是行在（宿主常驻系统实例，提案 00039），开机壳是豫构交互，与裸机、宿主上的行在同一份程序。壳里每句豫言都在浏览器里编成网页汇编单元，再装进开机壳所在的进程运行。

## 组成

- `行在.html`：页面。页面终端显示开机壳的输出，按键原样送进开机壳的标准输入；点屏幕即可打字。页脚写语言仓提交号（站点发布时写在 `/操作系统/来源提交`），报问题时对得上版本。发布时改名为 `行在/index.html`。
- `行在.mjs`：取快照展开到内存文件系统，接上秘府，建进程表，起开机壳 `/工具/豫构。豫行 交互`（交互参数取 /系统/开机。数据。豫 的「交互参数」，缺省 --组字，同裸机开机壳；标准输入当终端；当前目录 /，共享缓存根 `/tmp/豫构缓存`，不起将作与行在；/系统/开机自启 每行一句作开头句）。
- `秘府.mjs`：秘府（站点私有文件系统，OPFS）的读入与写回，见下文“秘府”。
- `终端.mjs`：页面终端。只认回车、换行、退格、制表与常用的 CSI 序列（移光标、擦行、清屏），非 ASCII 的字占两格（同组字编辑器的「输入格宽」）；开机壳进了原始模式（组字）时每个键直接送，否则页面自己回显、处理退格，按回车才送一行（同终端的规范模式）。中文输入法上屏的字照送。
- 进程表、工作线程与内存文件系统沿用浏览器构建宿主（`../构建/`）：每个任务一个 Web Worker，文件、子进程、标准输入经共享内存向主线程同步提问，所以页面要跨源隔离。

## 快照

- `源.tar.gz` 展成 /源：前导与行在四部要编的源码（豫章（标准库）、诏令（壳命令库）、几席、中书与豫寓榫卯，加屏键部截屏要的画谱、勘合、括囊三包的顶层源码），加全仓的包描述与说明。开机壳第一次编句时先编前导（三十多个模块），之后每句只编这一句。
- `工具.tar.gz` 展成 /工具：网页汇编的豫构 `豫构。豫行` 与诺驿值桥 `节点值桥接.wasm`。
- `桌面.tar.gz` 也展到 /工具：图形桌面 `图形桌面。豫行` 与桌面程序 `桌面程序。豫行`（压缩后约 18.6 MB），第一次进桌面时才取。/工具 里的名字与豫言操作系统 /工具 里的相同。
- 仓库目标「用户态系统浏览器发行」生成三个快照与页面（发行目录下的 `行在/` 与 `构建/`），云仓把发行目录发布到站点的 `/操作系统/`，官网路由给 `/操作系统/行在/` 与 `/操作系统/构建/` 加跨源隔离头。

## 秘府

盘上除了快照带来的 /源、/工具 与临时的 /tmp，其余部分（/数据、/系统、/软件 与根目录下的文件，如桌面设置库 /桌面设置.数据库）存在秘府（站点私有文件系统，OPFS）的 `网页行在` 目录里，重新载入页面后还在。

- 开机时把秘府里的整棵树读进内存文件系统，再撤下 /系统/桌面运行中（同裸机“开机时标阴”）。/系统/开机自启 每行一句，作开机壳的开头句，在第一个提示符之前执行，同裸机开机壳；留着的 /系统/请求进入桌面 开机后照办。
- 之后内存文件系统里这些路径的写、删、改名与建目录都记下，三百毫秒后整篇写回秘府（同一路径连改几次只写一次），关页面时把积下的一并写回。
- 同一时刻由一个标签页写回（网页锁 `网页行在秘府`）；别的标签页照常读入，改动只留在本页内存里，开机时状态栏说明。
- 浏览器的“清除网站数据”清掉秘府。

## 双端对照

「原生对比」（`应用/百工坊/原生对比`）的「交互」场景把同一组句子（定义后再用、裸式印值、组合句、编译错误、没接住的运行时异常）分别交给原生豫构交互与 Node 上的 `豫构.wasm` 交互，输出须逐字相同；网页行在跑的就是 Node 这一边的同一份网页汇编程序。CI 抽样轮次的“原生与 Node 性能对比”一步缺省就跑它，两边不同即失败。

## 字体

发行目录的 `字体/` 带思源黑体、原始字体与默认等宽黑体三套字体及许可，`字体.ttf` 是文楷。页面按族名分别声明：`文楷` 用 `../字体.ttf`，`无衬线`、`汉字`、`符号`、`圆体`、`数学` 用 `../字体/思源黑体.otf`，`衬线`、`手写`、`装饰`、`仿宋` 用 `../字体/原始字体.ttf`，`等宽` 用 `../字体/默认等宽黑体.otf`；`Arial`、`Helvetica`、`黑体`、`Times New Roman`、`宋体`、`Courier New`、`Menlo` 等具体族名与 `serif`、`sans-serif`、`monospace`、`system-ui` 等通用族名也各声明一条。粗体族名不声明，字体选取取不到真粗面时回到常规面仿粗。`字体基` 网址参数另指字体目录，`字体` 参数把全部族名指到同一个文件。

## 本机验证

把三个快照放进一个资料目录，运行 `node 豫言操作系统/宿主/浏览器/构建。测试服务.mjs <资料目录> 18791`，浏览器打开 `http://127.0.0.1:18791/浏览器/行在/行在.html?源=/资料/源.tar.gz&工具=/资料/工具.tar.gz&桌面=/资料/桌面.tar.gz`。字体按族名取自 `字体基`（缺省是站点的 `/操作系统/字体/`）；本机开发时让 `字体基` 指向仓内 `豫言操作系统/裸机/字模生成/字体/` 的网址，`字体=` 仍可把全部族名指到同一个字体文件。

## 桌面

开机壳的环境里 豫言行在=网页，壳就按宿主行在会话装「任务」「图形」「屏键」「电源」四部（部的源码在 /源，第一次用到时在浏览器里编）。「图形」写下 /系统/请求进入桌面，行在（主线程）删去它、写下 /系统/桌面运行中，让页面只留名为“主窗口”的画布，起 /工具/图形桌面。豫行，环境另加 豫言桌面程序=/工具/桌面程序。豫行；桌面退出后撤下标志、回到命令行。

图形桌面与壳的部用带类型导入直接调豫寓接口（同原生执行器的“路二”），工作线程里的实现见 `../构建/豫寓.mjs`：显示面、字体、剪贴板、读屏与合成输入在主线程办（显示面表与画布后端沿用 `../图形.mjs`），文件按授权根“桌面”=/ 读写内存文件系统，子程序经进程表起（交互子程序当终端，可入原始模式），任务表列进程表里运行着的任务，「辍役」销毁任务与它全部子孙的工作线程（退出码 130）。桌面终端起的就是 /工具/豫构。豫行 交互 --组字 会话，与开机壳同一个壳。

每个窗口一个任务（提案 00015）：九宫（平铺桌面库）见到 豫言桌面程序，就照裸机用「遣使附映面」把每个窗口（终端、文件浏览、任务管理器等）起成一个 /工具/桌面程序。豫行 任务并转授一块显示面。行在替它代管这块显示面：窗口任务提交的画面存成整块画布与变化区域，桌面用「取使者画面」取走；桌面送的输入事件排进窗口任务的事件队列；尺寸与像素比由桌面设。窗口任务要外壳办的事（如终端里「辟窗」开新窗口）经「请外壳办」交给桌面，桌面的来信经「送程序来信」交回。终端窗口任务再起 /工具/豫构。豫行 交互 --组字 会话。桌面退出时各窗口任务的显示面随之关闭，窗口任务自行退出，终端会话读到输入结束也退出。

后续版本：声音、「辍」只打断一句（提案 00043 第五步）、秘府按块写回大文件。
