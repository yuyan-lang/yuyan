# 浏览器文件能力接入

2026-10-05 正式浏览器之成物已于实站点私有存储验：原壳造目录、中文写与附、复制、移动、删除及重载读回皆过；GUI 写“界面中文写入”而归原壳读回，误录为空。说明文惟不存乃始造，用户存空说明文，重载犹空。画面 `/private/tmp/yy浏览器真实写入.jpg` 已核，线上之易犹待成。

宿主今可明授可写目录：名表之值为 `{目录: FileSystemDirectoryHandle, 可写: true}`；径给目录柄犹默认惟读。循公文件接口零点五，可造、覆盖、追加、依游标写文、造单层目录及删文或空目录。每写闭原生写流乃还成，使余文柄即见新文；闭公柄释游标之资，不存原生写流。并写之调犹待成。

四组宿主协议之验皆过，含即截、续写中文与追加、造目录与已有之冲、存非空目录、存惟读文、越界、缺父与失效柄。此证用目录柄之代与实物字；实浏览器储存与公Wasm调用犹待验，已布网页今犹惟授读。后文惟读与三组之验为早期之录。

此为公文件接口之浏览器宿主原语模块 `文件能力.mjs`。宿主以名至原生 `FileSystemDirectoryHandle` 之表明授目录，模块复用旧 `句柄.mjs`，以不透明柄号授调用者。目录或为已授本地目录，或为宿主所得站点私有文件系统；模块不启授权框，不自取余目录。

列目录、取文件信息、只读开文、物字分块读取、读尽与关闭，循节点原语之结果元组约。路径自授权根逐段解之，不造文件；空径指根目录，开文件则径不得空。绝对径、空段、点与双点段皆归输入无效。目录未授、原生权限拒绝、资源不存与柄已闭，各归相应公状态。今惟读，写则明归未获授权。

原生之术依 [WHATWG File System 标准](https://fs.spec.whatwg.org/)。`文件能力。测试.mjs` 用目录柄之代与实物字，验目录树、信息、UTF-8跨块读取、读尽、关闭、清理与误态，三组皆过。

待办事项：原语之声明接入浏览器宿主与支持清单，增普通豫言文件浏览器适配而录于父包，绑定公文件零点二接口；构建器复制此模块后，构建实桌面发行，于实浏览器目录验之。网页云资源名表为资源地址与元数据，后循旧云服务接同一公能，毋直以名表充本地目录柄。同柄并读与写权限后治，今桌面顺次读文。
