# 控制台宿主实现

这是 Node 与浏览器可共用的具名控制台能力管理。`创建控制台能力` 接收授权映射，每项提供 `读取行`、`写文本` 及可选 `关闭`；读取回调返回“是否有行、原文”，允许 Promise。宿主内部结果为“状态码、正文、错误文字”：零为成功，一为未授权，三为关闭后失效，四为输入结束，七为输入无效或重叠等待，八为宿主失败。适配原语须使用异步返回签名。

每个具名控制台只有一个读取等待；不同控制台独立。关闭先结束所有等待，再清理提供者，晚到结果不会传给下一读取。空行与输入结束分开；只移除行尾，不解析命令。写入保留原文并等待提供者完成。

Node 的 `../节点/控制台.mjs` 提供真实文件描述符后端，逐字节读取至一行，支持 UTF-8、CRLF、空行及无换行末行，不预读后续行。写入处理部分写。当前 Node 读取使用同步文件描述符操作；底层操作挂住时不能靠同一线程主动取消，异步取消是待办事项。

执行 `node --test 豫言操作系统/宿主/浏览器/控制台。测试.mjs 豫言操作系统/宿主/节点/控制台。测试.mjs`，五项测试通过，其中 Node 使用真实子进程标准输入输出管道。此阶段尚未接入原语映射、适配包及原壳，不能据此宣称公共 Wasm 控制台或浏览器原壳可用。
