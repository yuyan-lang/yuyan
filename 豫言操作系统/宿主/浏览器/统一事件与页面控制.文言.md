# 浏览器宿主：统一事列、界面订阅器与页面控制

`宿主.mjs` 于原有“文树、事与网求之术”外，增**纯厂函数**三而导出（可离 Wasm，惟以 JSDOM 独测），`创建浏览器宿主` 惟接其于豫言之术。其所服者，网页事件、网页界面、网页文树、网页消息四接口包之浏览器适配也。

## 一、统一事列 `创建事件队列`

- 诸源之事共一先进先出之列；每事有类（界面、消息、定时、事件流、请求、编译、可见性、联机、历史、关闭、宿主）与宿主所予单调之序。`推事件(事件, 附加)` 仍为原始入口：旧式事（无 `类型` 字段）依名归类——`click/input/change/submit`（无 `来源句柄`）归界面，`定时` 归定时，余归宿主；新式事自带合法 `类型` 字段，即归其类。
- 每类各有其限（默认一千零二十四，`创建浏览器宿主({队列上限:{界面:2048}})` 或 `豫言_浏览器_设置事件队列上限` 可调）；满则弃该类最旧之事而计之（宿主类为例外：满则报错，守旧行）。合并之键：紧接列尾、同类同键之高频事就地代之。
- 取法有三：**原始**（`豫言_浏览器_等待事件`，取任意类之下一事，返原始癸象，其行与旧宿主全同——旧事之癸象形不变）、**统一**（`豫言_浏览器_等待网页事件`，任意类，返统一癸象）、**依类**（`豫言_浏览器_等待界面事件`、`豫言_浏览器_等待网页消息`，惟取己类，返元组）。待者所不受之类，其事留于列，绝不被吞。
- 宿主闭后，统一与依类之等待每呼皆异步返“关闭”之标记（免不察关闭之环占线程）；原始之等待守旧行（闭后不复返）。
- **他事源之接入**（事件流、请求、编译及将来之批事）：宿主中凡术欲向豫言投新类之事，呼 `推事件({类型:'事件流', 订阅号:整数, 名称:文, 详情:癸象, …余字段}, {合并键})` 即可；不必增列或等待之术，客以等待网页事件即可收之。批事（同一订阅号之多事合为 `详情.批`）可由该事源于投前自成之。

## 二、界面订阅器 `创建界面订阅器`

订阅界面事件之宿主实现：于目标（元素、文档、窗口）安原生之听，**同步**成键律之匹、`preventDefault`、`stopPropagation`、`stopImmediatePropagation`，再以不含原生物之载荷投于列。要点：

- 委托：任一后代触发皆投；标识为触发元素之标识，操作键取最近之 `data-yy`（止于订阅之界）；不冒泡之事一律于捕获相听。
- 策与键规则于订时严验（未识之字段、类型之误、相悖之组合皆报错）；键规则默认不匹输入法组字间之键。
- 载荷不含 `password` 输入框之值；`值` 逾六万五千五百三十六码元则省而标之；消息订阅之详情于原生回调即序列化而验一 MiB 之限。
- 旧式隐听（惟报有标识之元素）遇已被订阅所覆之同名事则让之，免重。

## 三、页面控制 `创建页面控制`

按元素标识之读写（值、显隐、焦点、光标、滚动、模态框、页面之状）与柄型文树之术（建树、组合、释放、追加文、iframe 之址、模板之装入）。**签、属性、链接、类名之白册与诸限额惟于此写一处**，四适配皆经其验；宿主于其上仍留底层原语之旧防（`豫言_浏览器_设置属性` 拒 `on*`、`srcdoc` 与 `javascript:` 之址）。柄表上限仍四千零九十六（`句柄.mjs`，增 `条目()` 与 `上限`，供整树释放与报错之用）；号单调而增，永不复用。

## 测验与察

- 单元测试与一致性测试见 `适配/网页事件浏览器/一致性验证/`。
- `创建浏览器宿主` 所返之对象增 `状态()`：`{积压, 各类积压, 丢弃, 各类丢弃, 等待者, 序, 句柄数, 界面订阅数, 消息订阅数}`，惟供测验与察。
- 构建器固定所抄之宿主文件仍为 `值桥.mjs`、`句柄.mjs`、`宿主.mjs`、`入口.mjs`、`自动启动.mjs`、`工作线程自动启动.mjs`；此次改动未增一文，故不必改构建器。
