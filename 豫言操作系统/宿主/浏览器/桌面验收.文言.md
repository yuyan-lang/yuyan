先构建浏览器图形桌面发行，于产物目录置本机可解之中文字体，名曰 `yy验收字体.ttf`（字体不入库）。行 `node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs yy图形桌面浏览器发行 50692 --桌面验收`，开所印地址之 `桌面。测试页.html`。服务惟听本机；明授桌面标则启恒名PNG保存端点，至多八兆，不受文件路径。

此番实浏览器验根目录之列、说明中文预览、子目录之入与子文中文预览；图形命令行行 `「文件」之「读取」于「子目录/子.txt」` 及读说明文，皆见其正文。存验收画面之后，产物之 `yy浏览器桌面实际.png` 见文件浏览与命令行同读说明正文；返回钮后页见“桌面已返回调用方”，显示面之输入框已去，误录为空。

# 原壳浏览器入口之接口缺

2026-10-05 同一原壳源构浏览器绑定发行，实浏览器见二缺：标准库宿主无原始终端模式之判；补为阴则原壳正择行模，然候页提交之 Promise 为边界所拒，诊断曰“标准库.尝试读取标准输入行 返回了 Promise，但它的边界签名结果没有标异”。同步边界不得承浏览器事之候，不可径覆宿主回调以成原壳会话。败接已撤，不以此称浏览器原壳可用。

次当增公共控制台包：读行以异步结果还“行已得、输入尽或系统错误”，出由具名控制台之能；Node 接实终端或管，浏览器接页之行入与出区。原壳命令之行存既有豫言代码，行模改调公接口；GUI 同步入而归原会话。宿主闭则输入之候必终，未授控制台则明报，独立 GUI 无须控制台。用户已允增 ABI，实之须并适配声明与装载清单，别验 Node 与实浏览器之往返。
## 公共控制台原壳之往返

原壳行入已接公控制台“主控制台”，未授则明报；逐键模仍用旧编辑器。Node 行模启动须传 --授权控制台 主控制台。正式文件命、子程序继承之入、参与环境、实 SDL 图形归返之复验皆过。

浏览器用同一原壳源与适配接口，于原壳。测试页.html 明授控制台回调。实验行默认命令行回显“进入前” → 「图形」 → 实站点文件预览 → 归同原壳 → 回显“返回后” → 退出；GUI 输入控件还、画布隐、原壳输入复，控台无误。画为 yy浏览器同壳往返.png。浏览器行模今用页之文字输入，原壳逐键拼音与快捷键未接页；GUI 旧输入法犹别行。余平台与原生适配之验待成。
## 系统设置字体之验

原壳试页增衬线字体之宣，字面序六。惟于本机临发行目录供系统字体资源：Arial Unicode 存为 `yy验收字体.ttf`，宋体存为 `yy验收宋体.ttc`。实浏览器已验自无衬线易宋体而桌面字形变、设置闭而复开存其择，及归原壳而退出。控台无误；输出之素为 `yy浏览器默认字体.png` 与 `yy浏览器字体设置.png`。字体文件为本机验资，不入库。
