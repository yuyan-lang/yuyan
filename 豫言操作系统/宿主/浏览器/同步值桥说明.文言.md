# 客器同步值桥

客器若无 `WebAssembly.Suspending` 或 `WebAssembly.promising`，值桥直行 Wasm `_start` 与启动之导出 `豫言操作系统启动/启动程序`（有则行），纯同步宿主之能仍可供豫言客器。宿主之术若还 Promise，值桥即言其名，不以异步物伪充豫言值。

有 JSPI 者仍循悬栈复行之旧途。同步之途不能续异步之行，故候网络、文树事件、流者不得用；亦不能代客器补 WasmGC 等模块之能。

`同步值桥。测试.mjs` 以真豫言 Wasm 验无 JSPI 之同步运行及异步拒绝；`装载/浏览器入口。测试.mjs` 验旧 JSPI 入途。Safari 全界面犹须另解异步续行及模块兼容。

## 败时页面之示

`自动启动.mjs` 于客器不能启（如缺 WasmGC）或中道而败（如界面之程于无 JSPI 之客器叩异步之能），则加 `<html>` 以属性 `data-yuyan-app-error`（值乃败因，至多三百字），仍于控制台报其错。静页不必书脚本，唯置一默隐之示，以 CSS 属性选择器显之，如：

```css
.需要现代浏览器 { display: none; }
html[data-yuyan-app-error] .需要现代浏览器 { display: block; }
```

云工作台之 `首页.html` 与 `控制台.css` 即以此示“须支持 WasmGC 与 JSPI 之客器”。

## 平台接口之带型导入

自取消外调第三步，浏览器宿主库（`库/浏览器宿主`）与中央张量宿主库（`库/中央张量宿主`）之函编为带型之导入：导入之模为包名“浏览器宿主”“中央张量宿主”，字段为接口之篇所声之函名。`宿主.mjs` 出对照之表 `浏览器平台导入`，以每字段对能表之旧原语名（旧名惟内键）。

- 惟真或返 Promise 之六十二术套 JSPI：书为 async 者、候事列之四术、读同源之文、显示图形字体三术（初用乃动载 `图形.mjs`），及中央张量之启用与运行。余皆同步而调，不复每调而悬。
- 无 JSPI 者，`创建豫言实例` 改标异步之术为同步而调：果返 Promise 乃报“此浏览器缺少 JSPI，程序调用了异步宿主能力：模.字段”，故惟调同步之能之新产物照行。
- 中央张量于带型之路，惟启用、运行或异；余者内核未启则报“中央张量：尚未启用”（适配恒先取境）。读单精与数学之原实返 `{小数}`，带型之路取其裸数。
- `宿主支持清单.tsv` 列浏览器所供之接口及其适配，式同 `节点/宿主支持清单.tsv`；构建器于浏览器之式依之择适配，表所不载者浏览器不供。`宿主支持清单。测试.mjs` 核清单之式、适配不依浏览器所不供之平台包、平台包之所声与对照之表一一相同，并以最小之 Wasm 客器于有无 JSPI 二境造宿主。
