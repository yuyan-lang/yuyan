# 浏览器编译宿主

此目录藏试写间浏览器编译与隔离行客之 JavaScript 平台术：内存虚籍、WasmGC 值桥、Binaryen 组装、工作线程与页事桥。豫言源码裁试写界面及程序之义；此诸模块惟接浏览器 Worker、Wasm 与字节之能。

编译器直书 Wasm 二进制，不经 WAT，亦不召外部组装之进程。编译毕，`编译核心.mjs` 以 `组装.mjs` 读其二进制（Binaryen 132），装顶层字符串承异者（凭名段寻 `_start` 与 `exception`）与时限之检，乃行之。

组装之器依自定段「豫言边界」（或旧之 `yuyan:gc-host/v1.call` 导入）识豫言之程，惟有带型导入、不导 call 之程（第二步以后之编译器与多数用户之程）亦装此二者。`执行模块` 依（模块，字段）供标准库与构建基础之带型导入，无者为桩，旧 call 之原语由同一实现派生；模有带型导入乃动态载同目之 `边界.mjs`。仓中之 `边界.mjs` 惟一行，转出 `../../网页汇编/边界.mjs`；平铺抄此目于他处（试写网页、云工动态子 Worker 之模块表）时，须易以胶水本体。诸函之义见[标准库之宿主服务](../../标准库宿主.文言.md)。

云仓 `准备源码` 与 `浏览器编译资源` 抄此处 `.mjs` 于试写网页构境，复置同文于静态资源。值桥由 `yy浏览器编译资源` 依 `库/编译器核心/编译步骤/代码生成/回收值桥接。豫` 之结构径书，不立二维护源。云仓旧径惟生成副本，不为实作之本。

`资源组装/组装资源.mjs` 乃构建时之脚本，不入网页静态资源：由 `yy浏览器编译资源` 召之，参依次为编译器 Wasm、标准库资料 JSON、Binaryen 之目、资源出目；以 Binaryen 读编译器之二进制，装浏览器之处置而优化之，由 WAT 组值桥 Wasm，预编标准库，书 gzip 之料与校验之单。原在云仓 `应用/豫言体验/源码/`，本属平台组装之宿，今与诸编译宿主同守于此。

## Safari 27 栈误之诊（2026-09-25）

试写间“函数与类型”之例，Safari 27 曾报 `Maximum call stack size exceeded`；旧页惟示误文，未明组装何段。今编译宿主告入 WAT 组装之段与文长，组装器于解析、函数处理、成二进制之败各附段名。同材 Node 真编十验皆通。线上重刊全编译资源与装载产物，Safari 27 复载行此例得 `4`。旧栈误之独一根因，现证未足定之。
