# 浏览器编译宿主

这里保存试写间浏览器编译与隔离运行的 JavaScript 平台实现：内存文件系统、WasmGC 值桥、Binaryen 组装、工作线程及页面事件桥。豫言源码决定试写间界面和程序语义；这些模块负责调用浏览器提供的 Worker、Wasm 和字节 API。

编译器直接写出 Wasm 二进制，不经过 WAT，也不再调用外部组装进程。编译完成后，`编译核心.mjs` 用 `组装.mjs` 读入二进制（Binaryen 132），装入顶层字符串异常处理器（依靠名字段找到 `_start` 与 `exception`）和时限检查，然后运行。

`yuyan-cloud` 的 `准备源码` 与 `浏览器编译资源` 目标把本目录的 `.mjs` 复制到试写间网页构建目录，再把同一份文件放入网页静态资源。值桥由 `yy浏览器编译资源` 按 `库/编译器核心/编译步骤/代码生成/回收值桥接。豫` 的结构化表示直接写出，没有第二份维护源码。云仓对应路径是生成副本，不作为实现来源。

`资源组装/组装资源.mjs` 是构建期脚本，不进入网页静态资源：由 `yy浏览器编译资源` 调用，参数依次为编译器 Wasm、标准库资料 JSON、Binaryen 目录、资源输出目录；它用 Binaryen 读入编译器二进制、装入浏览器处理并优化，由 WAT 组装值桥 Wasm，预编译标准库，写出 gzip 资料与校验清单。它原在云仓 `应用/豫言体验/源码/`，属于平台组装宿主，现与其他编译宿主一起维护在这里。

## Safari 27 栈错误诊断（2026-09-25）

试写间的“函数与类型”示例曾在 Safari 27 报 `Maximum call stack size exceeded`，旧页面只显示错误文字，不能定位组装步骤。编译器宿主现在报告进入 WAT 组装的阶段和文本长度；组装器在解析、函数处理和二进制生成失败时附阶段名称。使用同一编译资源的 Node 真实编译测试 10/10 通过。线上重新发布完整编译资源和装载产物后，Safari 27 刷新运行该示例输出 `4`。现有证据不足以确认此前栈溢出的单一根因。
