# 浏览器编译宿主

这里保存试写间浏览器编译与隔离运行的 JavaScript 平台实现：内存文件系统、WasmGC 值桥、Binaryen 组装、工作线程及页面事件桥。豫言源码决定试写间界面和程序语义；这些模块负责调用浏览器提供的 Worker、Wasm 和字节 API。

`yuyan-cloud` 的 `准备源码` 与 `浏览器编译资源` 目标把本目录的 `.mjs` 复制到试写间网页构建目录，再把同一份文件放入网页静态资源。`值桥接.wat` 复用操作系统 `宿主/节点/值桥接.wat`，没有第二份维护源码。云仓对应路径是生成副本，不作为实现来源。

## Safari 27 栈错误诊断（2026-09-25）

试写间的“函数与类型”示例曾在 Safari 27 报 `Maximum call stack size exceeded`，旧页面只显示错误文字，不能定位组装步骤。编译器宿主现在报告进入 WAT 组装的阶段和文本长度；组装器在解析、函数处理和二进制生成失败时附阶段名称。使用同一编译资源的 Node 真实编译测试 10/10 通过。线上重新发布完整编译资源和装载产物后，Safari 27 刷新运行该示例输出 `4`。现有证据不足以确认此前栈溢出的单一根因。
