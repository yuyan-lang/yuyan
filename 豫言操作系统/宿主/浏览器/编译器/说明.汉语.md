# 浏览器编译宿主

这里保存试写间浏览器编译与隔离运行的 JavaScript 平台实现：内存文件系统、WasmGC 值桥、工作线程及页面事件桥。豫言源码决定试写间界面和程序语义；这些模块负责调用浏览器提供的 Worker、Wasm 和字节 API。

编译器直接写出 Wasm 二进制，不经过 WAT，也不调用外部组装进程。`编译核心.mjs` 给编译器加参数 `--浏览器检查点`，编译器在最终模块里直接写出浏览器的顶层字符串异常处理器（导入 `yuyan:browser/v1` 的 `fail`）和时限检查点（导入 `yuyan:browser/v1` 的 `check`，每 1024 次函数进入调用一次），实现见编译器核心的 `编译步骤/代码生成/网页汇编浏览器检查点。豫`。宿主拿到 `/程序.wasm` 后直接运行，不再做二进制处理。

`执行模块` 按（模块，字段）提供标准库与构建基础的带类型导入，没有的给桩；`yuyan:browser/v1` 的 `check` 在超过时限时抛出“Wasm 执行超过时限”，`fail` 以“未捕捉的豫言异常”报出程序没有接住的异常。模块有带类型导入时才动态载入同目录的 `边界.mjs`。仓库里的 `边界.mjs` 只是转出 `../../网页汇编/边界.mjs` 的一行，把本目录平铺复制到别处（试写间网页、云工动态子 Worker 的模块表）时，要换成胶水本体。各函数的语义见[标准库宿主服务](../../标准库宿主.汉语.md)。

`yuyan-cloud` 的 `准备源码` 与 `浏览器编译资源` 目标把本目录的 `.mjs` 复制到试写间网页构建目录，再把同一份文件放入网页静态资源。值桥由 `yy浏览器编译资源` 按 `库/译场/分职/笔受/回收值桥接。豫` 的结构化表示直接写出，没有第二份维护源码。云仓对应路径是生成副本，不作为实现来源。

`资源组装/组装资源.mjs` 是构建期脚本，不进入网页静态资源：由 `yy浏览器编译资源` 调用，参数依次为编译器 Wasm、标准库资料 JSON、值桥 Wasm、资源输出目录。编译器 Wasm 由云仓构建时带编译器参数 `--浏览器检查点` 编出，自带检查点；脚本原样发布编译器与值桥，预编译标准库，写出 gzip 资料与校验清单；编译器没有检查点时打印警告。它原在云仓 `应用/豫言体验/源码/`，属于平台组装宿主，现与其他编译宿主一起维护在这里。

## Safari 27 栈错误诊断（2026-09-25）

试写间的“函数与类型”示例曾在 Safari 27 报 `Maximum call stack size exceeded`，旧页面只显示错误文字，不能定位组装步骤。当时编译器宿主报告进入 WAT 组装的阶段和文本长度，组装器在解析、函数处理和二进制生成失败时附阶段名称。使用同一编译资源的 Node 真实编译测试 10/10 通过。线上重新发布完整编译资源和装载产物后，Safari 27 刷新运行该示例输出 `4`。现有证据不足以确认此前栈溢出的单一根因。
