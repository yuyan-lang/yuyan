# 桌面浏览器验收

这是实际浏览器桌面发行的验收页。`桌面。测试页.html` 在当前站点私有文件系统的 `yy桌面验收` 下创建说明文件和子目录夹具，以“桌面”名称授给运行实例。界面与文件行为由实际豫言Wasm执行，页面只负责准备原生能力和报告返回结果。

先构建浏览器图形桌面发行，在产物目录放入本机可解析的中文字体，名为 `yy验收字体.ttf`（字体不入库）。运行 `node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs yy图形桌面浏览器发行 50692 --桌面验收`，打开打印地址中的 `桌面。测试页.html`。服务只监听本机；显式桌面标记启用固定PNG保存端点，最多8MiB，不接受文件路径。

本次实际浏览器验证根目录列举、说明中文预览、子目录导航与子文件中文预览；图形命令行执行 `「文件」之「读取」于「子目录/子.txt」` 和读取说明文件，均显示对应正文。保存验收画面后，产物中的 `yy浏览器桌面实际.png` 显示文件浏览与命令行读取同一说明正文；返回按钮后页面显示“桌面已返回调用方”，显示面的输入框已移除，错误日志为空。

待办事项：浏览器完整原壳启动GUI与恢复原会话、F2和逐字拼音、物理键鼠、本地目录选择、云资源目录、其他浏览器逐项验收。本页单独启动GUI，不能据此证明操作系统已默认命令行启动。夹具写入仅发生于测试目录；应用文件能力目前只读。
# 原壳浏览器入口的接口缺口

2026-10-05 同一原壳源码完成浏览器绑定构建，实际浏览器暴露两个问题：浏览器标准库宿主缺少原始终端模式判定；补为阴后原壳正确选择行模式，但等待页面提交的 Promise 被边界拒绝，诊断为“标准库.尝试读取标准输入行 返回了 Promise，但它的边界签名结果没有标异”。同步边界不能承载浏览器事件等待，不能用宿主回调覆盖来实现完整原壳会话。该失败接入已撤回，未据此宣称浏览器原壳可用。

下一步新增公共控制台包：读取行以异步结果返回“行已得、输入结束或系统错误”，输出通过具名控制台能力；Node 接真实终端或管道，浏览器接页面行输入及输出区。原壳命令执行保持现有豫言代码，行模式改调公共接口；GUI 同步进入并返回原会话。输入等待在宿主关闭时必须结束，未授控制台时明确报告，保持独立 GUI 不需要控制台。用户已允许新增 ABI，实施时同步适配声明和装载清单，并分别验证 Node 与实际浏览器往返。
