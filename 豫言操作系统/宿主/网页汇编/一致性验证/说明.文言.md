# 网页汇编运行时 JSON 串一致性验证

验 `豫言操作系统/宿主/网页汇编/运行时.wat` 之 `$json_string`（`癸象解析` 解串之术）能识 `\uXXXX`，及 `库/拓展库/癸象工具/癸象数据结构。豫` 之编码器于控制字符之书。其则详 `库/拓展库/癸象工具/癸象转义.文言.md`。

## 所含

| 文件 | 用 |
| --- | --- |
| `运行时JSON字符串.test.mjs` 与 `运行时JSON字符串试验壳.wat` | 低层：合 `运行时.wat` 与试验壳为一模块，直呼 `$json_string`。穷举六万五千五百三十六个 `\uXXXX`（大小写二式）与一百零四万八千五百七十六个高低代理对，兼验孤代理项、短转义、非零起点、畸形转义（必陷）、随机 `JSON.stringify` 往还及超长串。唯须仓根与 `yy网页汇编宿主`。 |
| `应用/` 与 `癸象转义验证.test.mjs` | 端到端：云工应用开 `/round`、`/raw`、`/enc`、`/host`、`/q`、`/h`，Node 以真 Wasm 对拍：`JSON.stringify` 而豫言解之、豫言编之、`JSON.parse` 还之，涵中文、表情符、孤代理项、大小写十六进制、ESC、NUL、DEL、U+2028、`\/`、混合转义、嵌套与超长串；畸形转义则断其请求败；并及宿主所授查询参数、标头与 `request.json()` 之生产路。 |

应用之包描述存为 `应用/癸象转义验证应用。包。豫.txt`，免为 `yy豫构` 全仓库发现所误认；构建时抄入暂存内临时目录，复其原名 `。包。豫`。

## 复跑（私有暂存，不动共享构建）

于暂存目录（有符号链接 `库`、`豫言操作系统`、`豫言操作系统接口`、`运行时支持库`、`工具`，及编译器、`yy网页汇编宿主`、`yy双宿主构建`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`）：

1. 低层：`node --test 豫言操作系统/宿主/网页汇编/一致性验证/运行时JSON字符串.test.mjs`。
2. 绑接口：于 `网页入站`（适配模块 `请求`）与 `网页答复`（适配模块 `响应`）各行一次 `./yy豫言操作系统绑定 豫言操作系统接口/<能力>/豫言操作系统<能力>。包。豫 豫言操作系统/适配/<能力>/豫言操作系统<能力>适配。包。豫 豫言操作系统/适配/<能力>/<模块>。豫 dist/操作系统绑定/<能力>`。
3. 书包上下文（`豫构包上下文二`，列 `标准库`、`拓展库`、二绑定包与应用包；应用包依 `标准库`、`拓展库`、二绑定包）。
4. `./yy双宿主构建 云工 <应用>/入口。豫 dist/癸象转义验证 ./yy3_bs <包上下文> <应用>/许可.json`，继以 `./yy豫言操作系统装载包 dist/癸象转义验证 dist/操作系统绑定/网页入站 dist/操作系统绑定/网页答复`。
5. `node --test 豫言操作系统/宿主/网页汇编/一致性验证/癸象转义验证.test.mjs`。

另有网页汇编侧之豫言测试 `库/拓展库/癸象工具/癸象转义。测试。豫`（以 `--target=wasmgc` 编之，由 `yy网页汇编宿主` 行之；当前工作目录之路若含非 ASCII 字，则 `yy网页汇编宿主` 之行模式因读环境变量而崩（组装模式无碍），宜于路径纯 ASCII 之目录行之，如语言仓根目录）。原生运行时库重建（`make 运行时`）之后，此测试亦可原生而行。

## 所期
