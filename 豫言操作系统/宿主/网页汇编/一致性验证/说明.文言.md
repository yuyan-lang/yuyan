# 网页汇编运行时 JSON 串一致性验证

验 WasmGC 客体运行时（编译器内之 `库/编译器核心/编译步骤/代码生成/回收运行时。豫`）之 `$json_string`（`结森解析` 解串之术）能识 `\uXXXX`，及 `库/结森工具/结森数据结构。豫` 之编码器于控制字符之书。其则详 `库/结森工具/结森转义.文言.md`。

## 所含

| 文件 | 用 |
| --- | --- |
| `应用/` 与 `结森转义验证.test.mjs` | 端到端：云工应用开 `/round`、`/raw`、`/enc`、`/host`、`/q`、`/h`，Node 以真 Wasm 对拍：`JSON.stringify` 而豫言解之、豫言编之、`JSON.parse` 还之，涵中文、表情符、孤代理项、大小写十六进制、ESC、NUL、DEL、U+2028、`\/`、混合转义、嵌套与超长串；畸形转义则 `结森解析` 严校其文而抛可捕之事故，断应用答四百；并及宿主所授查询参数、标头与 `request.json()` 之生产路。应用具网页服务之处理入口 `处理入站网页请求`。 |

应用之包描述存为 `应用/结森转义验证应用。包。豫.txt`，免为 `yy豫构` 全仓库发现所误认；构建时抄入暂存内临时目录，复其原名 `。包。豫`。
