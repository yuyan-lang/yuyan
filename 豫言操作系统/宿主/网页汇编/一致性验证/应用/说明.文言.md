# 癸象转义验证应用

云工之应用，验真 Wasm 上 `癸象解析` 解 `\uXXXX`、`癸象表示` 编控制字符之行，与 `../癸象转义验证.test.mjs` 相配。

径与行：

| 径 | 行 |
| --- | --- |
| `POST /round` | 正文（JSON 文）由宿主 `text()` 取之，`癸象解析` 而后 `癸象表示`，原样归之 |
| `POST /raw` | 正文乃一 JSON 串；归其所解之串原字节 |
| `POST /enc` | 正文视为任意串，归其 `癸象表示`（当与 `JSON.stringify` 逐字节同） |
| `POST /host` | 由 `读取入站癸象正文文`（宿主 `request.json()` 之生产路） |
| `GET /q?p=…` | 回显查询参数 `p`（宿主以 JSON 授之，控制字符书为 `\u00xx`） |
| `GET /h` | 回显请求头 `x-t` |

正文若含畸形转义，豫言运行时即止，壳界见 `WebAssembly.RuntimeError`；应用不捕，测试以请求败断之。

构建与复跑见 `../说明.文言.md`。
