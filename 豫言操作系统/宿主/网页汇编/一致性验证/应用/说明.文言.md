# 结森转义验证应用

云工之应用，验真 Wasm 上 `结森解析` 解 `\uXXXX`、`结森表示` 编控制字符之行，与 `../结森转义验证.test.mjs` 相配。应用具网页服务（`豫言操作系统网页服务`）之处理入口 `处理入站网页请求`：请以参授之，答以返值还之。

径与行：

| 径 | 行 |
| --- | --- |
| `POST /round` | 正文（JSON 文）由 `读取入站有限正文文字` 取之（宽解 UTF-8，去首 BOM，同 `text()`），`结森解析` 而后 `结森表示`，原样归之 |
| `POST /raw` | 正文乃一 JSON 串；归其所解之串原字节 |
| `POST /enc` | 正文视为任意串，归其 `结森表示`（当与 `JSON.stringify` 逐字节同） |
| `POST /host` | 由 `读取入站结森正文文`（宿主 `request.json()` 之生产路），所得规范之 JSON 复经 `结森解析` 与 `结森表示` |
| `GET /q?p=…` | 回显查询参数 `p`（宿主以 JSON 授之，控制字符书为 `\u00xx`） |
| `GET /h` | 回显请求头 `x-t` |

正文若含畸形转义，`结森解析` 严校其文，抛可捕之事故“结森语法不合规”，应用答四百，体为“错误：”与其辞。

构建与复跑见 `../说明.文言.md`。
