# 结森转义验证应用

云工应用，用来在真实 Wasm 上验证 `结森解析` 对 `\uXXXX` 的解码与 `结森表示` 对控制字符的编码，配合 `../结森转义验证.test.mjs`。应用实现网页服务（`豫言操作系统网页服务`）的处理入口 `处理入站网页请求`：请求作参数传入，响应作返回值交回。

路径与行为：

| 路径 | 行为 |
| --- | --- |
| `POST /round` | 正文（JSON 文本）经 `读取入站有限正文文字` 取得（宽松 UTF-8，去开头 BOM，同 `text()`），`结森解析` 后再 `结森表示`，原样返回 |
| `POST /raw` | 正文是一个 JSON 字符串；返回解码出的字符串原字节 |
| `POST /enc` | 正文当作任意字符串，返回它的 `结森表示`（应逐字节等于 `JSON.stringify`） |
| `POST /host` | 走 `读取入站结森正文文`（宿主 `request.json()` 的生产路径），所得规范化 JSON 再经 `结森解析` 与 `结森表示` |
| `GET /q?p=…` | 回显查询参数 `p`（宿主以 JSON 传来，控制字符为 `\u00xx`） |
| `GET /h` | 回显请求头 `x-t` |

正文含畸形转义时，`结森解析` 的严格语法校验抛出可捕获的异常“结森语法不合规”，应用答 400，正文为“错误：”加消息。

构建与复跑见 `../说明.汉语.md`。
