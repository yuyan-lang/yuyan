# 癸象转义验证应用

云工应用，用来在真实 Wasm 上验证 `癸象解析` 对 `\uXXXX` 的解码与 `癸象表示` 对控制字符的编码，配合 `../癸象转义验证.test.mjs`。

路径与行为：

| 路径 | 行为 |
| --- | --- |
| `POST /round` | 正文（JSON 文本）经宿主 `text()` 取得，`癸象解析` 后再 `癸象表示`，原样返回 |
| `POST /raw` | 正文是一个 JSON 字符串；返回解码出的字符串原字节 |
| `POST /enc` | 正文当作任意字符串，返回它的 `癸象表示`（应逐字节等于 `JSON.stringify`） |
| `POST /host` | 走 `读取入站癸象正文文`（宿主 `request.json()` 的生产路径） |
| `GET /q?p=…` | 回显查询参数 `p`（宿主以 JSON 传来，控制字符为 `\u00xx`） |
| `GET /h` | 回显请求头 `x-t` |

正文含畸形转义时豫言运行时中止，壳边界表现为 `WebAssembly.RuntimeError`；应用不捕获，测试以请求失败断言。

构建与复跑见 `../说明.汉语.md`。
