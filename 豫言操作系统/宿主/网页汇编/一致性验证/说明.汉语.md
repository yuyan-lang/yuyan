# 网页汇编运行时 JSON 字符串一致性验证

验证 WasmGC 客体运行时（编译器内的 `库/编译器核心/编译步骤/代码生成/回收运行时。豫`）的 `$json_string`（`结森解析` 的字符串解码）支持 `\uXXXX`，以及 `库/结森工具/结森数据结构。豫` 的编码器对控制字符的输出。规则本身见 `库/结森工具/结森转义.汉语.md`。

## 内容

| 文件 | 作用 |
| --- | --- |
| `运行时JSON字符串.test.mjs` + `运行时JSON字符串试验壳.wat` | 低层：用 `yy回收运行时生成` 把客体运行时打印成 WAT 模块项，与试验壳组装成一个模块，直接调用 `$json_string`。穷举全部 65536 个 `\uXXXX`（大小写两式）与全部 1048576 个高低代理对，并验孤立代理项、短转义、非零起点、畸形转义（必须陷阱）、随机 `JSON.stringify` 往返与超长串。组装模块原用 `yy网页汇编宿主`（Wasmtime）；该工具已随单一 Wasm 后端删除，本测试暂被全树测试跳过，`应用/开发工具/全树测试/测试规则.tsv` 已登记待办（改在 Node 上运行）。 |
| `应用/` + `结森转义验证.test.mjs` | 端到端：云工应用暴露 `/round`、`/raw`、`/enc`、`/host`、`/q`、`/h`，Node 用真实 Wasm 对拍：`JSON.stringify` → 豫言解析 → 豫言编码 → `JSON.parse`，含中文、emoji、孤立代理项、大小写十六进制、ESC/NUL/DEL、U+2028、`\/`、混合转义、嵌套、超长串；畸形转义由 `结森解析` 的严格语法校验抛出可捕获的异常，断言应用答 400；并覆盖宿主传来的查询参数、标头与 `request.json()` 生产路径。应用实现网页服务的处理入口 `处理入站网页请求`。 |

应用的包描述保存为 `应用/结森转义验证应用。包。豫.txt`，以免被 `yy豫构` 的全仓库包发现当作包；构建时复制到暂存内的临时目录并改回 `。包。豫`。

## 复跑（私有暂存，不动共享构建）

在暂存目录（含符号链接 `库`、`豫言操作系统`、`豫言操作系统接口`，以及编译器 `yy4_bs.wasm` 与 `yy双宿主构建`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`）里：

1. 低层：`node --test 豫言操作系统/宿主/网页汇编/一致性验证/运行时JSON字符串.test.mjs`（暂不可运行，见上表）。
2. 构建应用：`node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 云工 豫言操作系统/宿主/网页汇编/一致性验证/应用 dist/结森转义验证`。自动模式按包描述绑定 `基础` 与 `网页服务`（适配模块 `入站网页`）两个接口，生成包上下文，构建应用并装载接口清单；用法见[双宿主构建说明](../../../应用/双宿主构建/说明.汉语.md)。
3. `node --test 豫言操作系统/宿主/网页汇编/一致性验证/结森转义验证.test.mjs`（产物目录默认 `dist/结森转义验证`，可用环境变量 `YY_ESCAPE_DIST` 指定）。

另有 WasmGC 侧的豫言测试 `库/结森工具/结森转义。测试。豫`：用 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 文件 库/结森工具/结森转义。测试。豫 --输出 yy结森转义测试.wasm` 编译，再用 `node 豫言操作系统/宿主/节点/宿主.cjs yy结森转义测试.wasm` 在 Node 上运行；全树测试也这样构建并运行它。

## 期望结果

低层 8 项、端到端 11 项全部通过。对旧运行时（无 `\u` 支持）构建同一应用，端到端 11 项全部失败；对旧编码器则 9 项失败。
