# 网页汇编运行时 JSON 字符串一致性验证

验证 `豫言操作系统/宿主/网页汇编/运行时.wat` 的 `$json_string`（`癸象解析` 的字符串解码）支持 `\uXXXX`，以及 `库/拓展库/癸象工具/癸象数据结构。豫` 的编码器对控制字符的输出。规则本身见 `库/拓展库/癸象工具/癸象转义.汉语.md`。

## 内容

| 文件 | 作用 |
| --- | --- |
| `运行时JSON字符串.test.mjs` + `运行时JSON字符串试验壳.wat` | 低层：把 `运行时.wat` 与试验壳组装成一个模块，直接调用 `$json_string`。穷举全部 65536 个 `\uXXXX`（大小写两式）与全部 1048576 个高低代理对，并验孤立代理项、短转义、非零起点、畸形转义（必须陷阱）、随机 `JSON.stringify` 往返与超长串。只需仓根与 `yy网页汇编宿主`。 |
| `应用/` + `癸象转义验证.test.mjs` | 端到端：云工应用暴露 `/round`、`/raw`、`/enc`、`/host`、`/q`、`/h`，Node 用真实 Wasm 对拍：`JSON.stringify` → 豫言解析 → 豫言编码 → `JSON.parse`，含中文、emoji、孤立代理项、大小写十六进制、ESC/NUL/DEL、U+2028、`\/`、混合转义、嵌套、超长串；畸形转义断言请求失败；并覆盖宿主传来的查询参数、标头与 `request.json()` 生产路径。 |

应用的包描述保存为 `应用/癸象转义验证应用。包。豫.txt`，以免被 `yy豫构` 的全仓库包发现当作包；构建时复制到暂存内的临时目录并改回 `。包。豫`。

## 复跑（私有暂存，不动共享构建）

在暂存目录（含符号链接 `库`、`豫言操作系统`、`豫言操作系统接口`、`运行时支持库`、`工具`，以及编译器与 `yy网页汇编宿主`、`yy双宿主构建`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`）里：

1. 低层：`node --test 豫言操作系统/宿主/网页汇编/一致性验证/运行时JSON字符串.test.mjs`。
2. 绑定接口：对 `网页入站`（适配模块 `请求`）与 `网页答复`（适配模块 `响应`）各运行一次 `./yy豫言操作系统绑定 豫言操作系统接口/<能力>/豫言操作系统<能力>。包。豫 豫言操作系统/适配/<能力>/豫言操作系统<能力>适配。包。豫 豫言操作系统/适配/<能力>/<模块>。豫 dist/操作系统绑定/<能力>`。
3. 写包上下文（`豫构包上下文二`，含 `标准库`、`拓展库`、两个绑定包与应用包，应用包依赖 `标准库`、`拓展库`、两个绑定包）。
4. `./yy双宿主构建 云工 <应用>/入口。豫 dist/癸象转义验证 ./yy3_bs <包上下文> <应用>/许可.json`，再 `./yy豫言操作系统装载包 dist/癸象转义验证 dist/操作系统绑定/网页入站 dist/操作系统绑定/网页答复`。
5. `node --test 豫言操作系统/宿主/网页汇编/一致性验证/癸象转义验证.test.mjs`。

另有 WasmGC 侧的豫言测试 `库/拓展库/癸象工具/癸象转义。测试。豫`（用 `--target=wasmgc` 编译后由 `yy网页汇编宿主` 运行；当前工作目录路径含非 ASCII 字符时，`yy网页汇编宿主` 的运行模式会因读取环境变量失败而崩溃（组装模式不受影响），请在 ASCII 路径的目录下运行，例如语言仓根目录）。原生运行时库重建（`make 运行时`）后，同一份测试也可原生运行。

## 期望结果

低层 8 项、端到端 11 项全部通过。对旧运行时（无 `\u` 支持）构建同一应用，端到端 11 项全部失败；对旧编码器则 9 项失败。
