# 豫言操作系统实作之目

根之 `豫言操作系统接口/` 专定公约，惟以豫言述之；此目录藏诸平台之实作。`宿主/浏览器/`、`宿主/云工/` 收装载、物桥及验收页；`适配/基础/` 承基础公约，接旧宿主之术。双宿主构建器由此取壳，置于成品。

非豫言之实作，宜次第归此。今浏览器与云工之外壳四十八档已归，原生运行时及网页汇编宿主之 C 源亦入 `宿主/原生/`；旧运行时目录惟存构建法与成品。节点宿主三 CJS 档及值桥 WAT 亦入 `宿主/节点/`；直生所需运行时 WAT 入 `宿主/网页汇编/`。余工具之壳、性能研究之样具、云仓旧 JavaScript 尚待迁。迁一处，当改构建之径，以真 Wasm 与宿主验之，毋徒徙其档。

旧稳种之器固记旧头径，旧客器亦固记 WAT 旧径；故旧两径暂留符号连结，皆指此目录，无复本。由稳种自举二、三、四级，三四字节尽同；新器核型不赖旧径。云仓复备源码，官网与站点请求之云工成品皆成。

`适配/网页界面/`、`适配/网页文树/`、`适配/剪贴板/`、`适配/网址/` 与 `适配/网页转发/`，各循根之纯接口公约，藏旧节交互、受限造节、剪贴、编码与云工授权转请，而出中文豫言术。云仓首页、产品页及官网路由源码今依公约包名；构器先核包籍、版本与签，乃于暂目录以公约身份绑定适配。`装载/接口核对.mjs` 于客启前比客需、宿供二簿，验规范摘、向、签及 Wasm 通桥与 `_start`。通桥之表无逐术之名，故逐术贯通仍俟实跑证之。常编译器犹不能直析无体之纯 `。接口。豫`。

`适配/网页消息/` 又承当前页带癸象详情之事；云仓豫言语法高亮客依此纯约，其辨辞着色仍由豫言库行。二薄载壳藏 `宿主/浏览器/语法高亮/`，构时抄至云台与包府静态资源。

`宿主/浏览器/编译器/` 藏试写间浏览器编译之平台术；`宿主/节点/值桥接.wat` 为诸宿主共用之值桥源。云仓网页旧径惟构时副本，不维护二份 JavaScript 或 WAT。资源构器以豫言成之，今居 `工具/浏览器编译资源/`，语言仓编后授云仓行。

`宿主/云工/项目核心/` 藏云项目核心 WasmGC 隔离值桥。云仓行 `make 准备宿主`，由此生成不入籍之操作系统副本；工作台与验收径取之，工具目录不复维护此宿主源。

`适配/关系查询/` 与 `适配/网页答复/` 各接纯公约：前者取获授 D1 首行，后者答当前请之 JSON。云仓金额单位客惟依包籍，构时绑之，载前核之。JSON 文为 `_start` 无类型化入参时之过渡界。

关系查询二版增预备 SQL 文参缚定；网址二版增严析百分号，浏览器与云工各有适配。`适配/网页入站/` 读当前请之法、原径与头。公开包客凭四组能验名、问 D1、答 JSON。绑定器记实际适配之宿主簿径，装载包据之再核，毋以同名公约错取异宿之簿。

`适配/服务状态/` 惟向获授 Worker 内服行 GET，返状态而不授上游正文。网页答复二版可作空体之答。云台运维鉴权客依服务状态、网页入站、网页答复三约；饼惟由客显授固定服务之请。

网页入站二版统取事类、原径与严解径；网页转发二版惟司改址、原流转请，亦可覆三种受限安头。`适配/环境文字/` 读获授配置文。官网路由各依入站与转发；试写路由又依答复与环境文字，静资仍循原请之流，存上游状态与正文。

网页入站三版又取查询参，能改同源径与所指诸参；网页答复三版增文字与同源改址之答。包地址客于豫言析路、验名、缚 SQL 文参，定空答、错文、改写计划或三零二；操作系统适配惟行当前请之网址与答术。

网页入站四版增主机名、原查询之读；网页答复四版增应用所定 HTTPS 外站改址。网页转发三版许客覆授权资源答之 `Content-Type` 与 `Content-Disposition`。包府静态客以豫言定资源白册、门户改址及下载头；操作系统适配读 Assets 而存答流。

网页入站五版增 JSON 正文之读；`适配/时间/` 自同一时点取 UTC 日与 Unix 分；`适配/持久事务/` 将当前获授久仓之参、键值与果接纯约。试写额度客惟依入站、答复、环境文字、时间、持久事务五包，仍以豫言裁日额与分钟额；旧双键之形及原子扣减皆存。

`适配/秘密文字/` 循 Worker Secret 许可读密；`适配/网页上游/` 每请核 `OUTBOUND_ORIGINS` 之 HTTPS 来源，禁自动改向，于本请供状态、有界 JSON 读与原流入站答。试写模型客惟依入站、答复、环境文字、秘密文字、网页上游五约；豫言仍造模型请与 SSE 答头，适配惟司获授网络与流。

旧云工出站请原语于程序列 `OUTBOUND_ORIGINS` 时亦核来源，强置 `redirect: error`，毋使旧径越此许可。未列许可之旧客暂守原行，俟迁移逐一收紧。

`适配/网址定位/` 返 URL 标准所析之 `href`、`origin`、`pathname`、`search`；`适配/命名持久服务/` 循 `DO` 许可访当前程序之命名对象、编码查询，返有界正文与答头。云台站点请求客凭此二约及入站、答复、网址三约，定目标站、径界、令式与结果投影；适配不藏站之业务规。

`适配/关系数据库/` 于 `云工宿主` 句柄桥上承关系数据库首版：`prepare` 备句，`bind` 缚已校之型参，`first`、`all`、`run`、`batch` 各当首行、诸行、执行之果与原子批。平台之误经新增之 `云工调用方法安全` 得其原文，转为豫言之异，客可以「尝试运行」依唯一约之冲等因而复；库名未获许者仍径止其请。此约乃包管理服务中赖 D1 多行读写之 JS（账户、云用量、AI 市场诸端）迁入豫言之前提。

`适配/口令派生/` 与 `适配/随机数/` 径用云工宿主之 Web Crypto：前者为 PBKDF2-HMAC-SHA-256（迭代一至十万，出六十四位小写十六进制），后者为 `getRandomValues` 与 `randomUUID`。二者书十六进制皆共用 `拓展库` 云工宿主 `字节。豫` 之 `字节串转小写十六进制`。此乃账户口令、会话令牌、上传令牌诸密码之事迁入豫言之前提。

`宿主/网页汇编/运行时.wat` 之 `$json_string` 与 `宿主/原生/运行时/字符串.c` 今识 `\uXXXX`（代理成对合一，孤代理代以 U+FFFD，`\u0000` 得字节零），畸形转义仍止；癸象编码器于无短式之控制字书为 `\u00xx`。其则见 `库/拓展库/癸象工具/癸象转义.文言.md`，对拍见 `宿主/网页汇编/一致性验证/`。昔遇 Python、Go 之 JSON 或宿主对控制字之 `\u00XX`，解码必陷于 Wasm 之 `unreachable`，此乃流计费中断、公接口为畸形所困之根。

`适配/对象存储/` 于 `云工宿主` 句柄桥上承对象存储首版，映于 R2 绑定：`head` 取元，`get` 配严解 UTF-8 之 `TextDecoder` 以读文（限二 MiB：JSON 转义最坏六倍，须低于值桥十六 MiB），`put` 以真 `Headers` 表条件写而使平台验 `sha256`（返 `null` 即 `{"written":false}`），复有 `delete`、`list`，及以 `body` 流授 `Response` 之直通（正文不入 Wasm 内存，HEAD 惟用 `head`，对象无则返阴而不占终答）。`适配/压缩/` 以 Blob、`pipeThrough` 与 `DecompressionStream` 逐块读出，累计逾限即止（压缩之炸不得整解），并包 ZIP 条目为 gzip 容器，使平台原生验 CRC-32 与实数（存之法先包为 deflate 存储块）。`适配/密码摘要/` 增字节之摘要与尽力恒时之 `恒时相等文字`。三者之真 Wasm 试验，于 Node（R2 为类实例仿造）与本地 workerd（真 R2）皆过；此乃包府发布、下载与阅读诸链之 JS 迁入豫言之前提。

此三适配悉以豫言书于云工宿主库，不增宿主 JavaScript：读势之表存于 Wasm 实例内，循带信号之 `pipeThrough`、流式 TextDecoder 与码点界之裁，供渐读、有限整读与止；授权服务增带正文之请，网页上游增严验之动态公网 HTTPS，命名持久服务增流请、终答与转入站请。此乃 AI 市场调用、服务商连接、云台模型流与编译流诸 JS 迁入豫言之前提。

`适配/网页事件浏览器/` 及升级之网页界面、网页文树、网页消息三适配，以宿主之统一事列、界面订阅器（委托、同步键律）与页面控制（白册、一次建树、柄之回收）出中文诸术；三纯厂函在 `宿主/浏览器/宿主.mjs`，可离 Wasm 独测，验收之材在 `适配/网页事件浏览器/一致性验证/`。此乃云控制台诸前端 JS 迁为豫言浏览器应用之接口基础。

云工宿主壳增事类 `durable-block`（`blockConcurrencyWhile` 内重入）；事之墙钟默三十秒（独占、事务二十五秒），可由应用目录之可选 `执行配置.json` 依事类调之，告警至多十五分；`yy双宿主构建` 验之而写为产物 `动态资源.mjs` 所出之 `执行配置`（新旧壳与新旧构建器可混用）。`适配/持久事务/`、`适配/持久告警/`、`适配/持久独占/` 以之封持久仓事务内外之读写、告警与并发独占为中文诸术。本地 workerd 所验：事务内告警之变与直写 storage 皆随回滚而撤，事务回调之间他事排队，回调逾三十秒则平台重置其对象——规范循此而书，云端之验目见 `宿主/云工/说明.文言.md`。此乃云台三持久对象（用户目录、云端项目、公开站点）迁入豫言之接口基础。

`适配/消息队列/`、`适配/定时事件/`、`适配/邮件发送/`、`适配/文字规整/` 与 `适配/日志/`，分以云工之 Queue 绑定与 queue 事、scheduled 事、Send Email 绑定、String 对象及 console，接为纯约，皆以豫言书于 `拓展库` 云工宿主句柄桥之上，未增宿主 JS（邮件发送用宿主所有之 `豫言_云工_授权绑定存在`，以断绑定之置否）。消息体由宿主之 JSON.parse/stringify 规范之，并拒其伪造宿主句柄之记，批量之数组则由豫言于规范文上拆之；文字规整经 TextDecoder、TextEncoder 传 UTF-8 字节，不经 JSON，控制之字与 BOM 皆精确往返，入文以一 MiB 为限；邮件先于豫言校址、主题、正文而后授 send，败则以（阴，定因）返而因不含址；日志依 UTF-8 字节于码点之界截至八 KiB。`消息队列/一致性验证/` 与诸适配之 `一致性验证/`，含七十五项真 Wasm 之 Node 测试，及十四个真本地 workerd 之场（`attempts` 与延迟重试、毫秒计划之刻、邮件之内容、日志之级）；实测本地 Miniflare 于处败之时，连已确认之书亦整批重投，消费之处必幂等。此诸约乃包管理服务中页面任务之队列、定时之补发、账户之邮件、邮箱之规范与日志迁入豫言之前提。

`适配/网页事件流/` 与 `适配/持久频道/` 以豫言书于云工宿主库之上，不增宿主 JS。事件流适配以 `TransformStream` 之可读端为 `Response` 之体而即提头，书与请求 `AbortSignal`（须开 `enable_request_signal`）所生“断开候”相竞，故客断后书返一而应用犹可结算；持久频道适配以宿主具名广播为质，字节 0xFF 起首之控制帧载探测与带因之闭，`Promise.race` 合 `scheduler.wait` 而限时候讯不遗。二包各有实 Wasm 之 Node 验与本地 workerd 之复验，并附复 AI 服务商连接持久对象之组合范例。已知之限：今宿主于事毕或逾时不收尾响应流与订阅，适配说明载已验之补丁。此乃云工作台 `/events` 与 AI 市场 `/connect`、`/dispatch`、`/chunk` 迁入豫言之接口基础。

`适配/隔离运行/` 实隔离运行 0.1.0：豫言书于云工宿主库之上，验参、重算程之摘、以 `LOADER.get(范围:摘要, …)` 得子工而 POST 其入；子工之模块（`隔离运行客.mjs` 与浏览器编器宿主 `编译宿主.mjs`）由 `yy双宿主构建` 书入产物 `动态资源.mjs`，宿主惟增一通用原语 `豫言_云工_隔离运行客按号取`。云工作台用户站点之程序由是而运，详见 `适配/隔离运行/说明.文言.md`。

HTTP 之簇（网页入站〇点七、网页答复〇点五、网页转发〇点四、环境文字〇点二、网址定位〇点二、网址查询〇点一）悉以豫言书于云工宿主库之上，收包管理与云工作台散落之请求答复胶水为一统之接口：入站可读有限字节、严格 UTF-8 之文、宿主所验之 JSON 体与验名之头；答复可带头、诸 Set-Cookie、字节与流；转发有筛头与静资，而拒点段之径。独立审所得之弊已修：JSON 改由宿主 `JSON.parse` 验而规范之，不复经癸象往返（畸串不陷、大整不回绕、万项之组不溢栈）；旧读头、改址、内容类型遇非法之入皆抛可捕之异；转发拒 `.`、`..`、`%2e` 之段；网址文限六万五千五百三十六字节；表单限千二十四项；文首 BOM 不复见弃。诸接口之一致验共三十三、二十一、十七、十、五、三项 Node 测试皆通。
