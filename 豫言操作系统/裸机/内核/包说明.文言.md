# 豫言内核

连八字节之项由子包「底层地址表」生成，经导出「填连续表」供旧呼桥用；跳表之新项附于末。宿主及硬件客体页表初置共用之，呼者择架构之旗、首项及步长，授可写之域并刷映射。

豫言操作系统内核之不系于架构者：任务、调度与内存之管。以底层豫言书之，编为无回收之 Wasm 模块，复由裸机后端降级者之内核态目标，为兼容六十四与臂六十四各生机器码，与手书之入口（开机、异常与中断之出入、系统调用之分派）连为内核之镜像。

- `内核。底层接口。豫`：特权之操作（依内核虚址读写四字八字、清零、复制、逐字复制、刷快表、刷一页、屏障、架构之号，及兼之 I/O 端口之读写，臂读得 0xFF），编为导入模块「内核」之导入；惟内核态目标供之（出线之小桩）。
- `架构。底层。豫`：二构之异聚于此——核之数据之址、页表项之式、槽之容、页表根与记账之址，及核访物理内存之法（臂皆恒等；兼低区恒等，余者经任务窗之临窗）。
- `内存。底层。豫`：物理块（二兆）之配与释、四级页表之行与补、动区（用户虚址一 TiB 起）之按需提交、任务内存之清（兼清本槽所占桌面占屏之标与按键之事模）与复、服务二十二、二十四、二十五、四十四（归还内存块）、四十五（空闲内存块数）与开机之初置。
- `任务。底层。豫`：动槽（三十二起）之配与收、句柄、调度之环、调度（存帧、择槽、载帧、换页表与浮点）、空闲（「转空闲」「空闲选」：多核本核无可行者，或单核而有小睡者）、服务五十小睡（睡至次滴答，有信或子终则早醒）、用处理器之账、退出而唤其主、消息与句柄之服；旧二槽之字段依定址，同视之。
- `装载。底层。豫`：服务二十八至三十一持久块之务、三十七装载任务、三十八读启动块、三十九核数、四十一四十二读写他任务、四十六任务之信、四十七鼠标之位、五十小睡、五十三按键之模与五十四读按键、六十代码块之映，及开机留模与动态系统调用之分派。豫行之文由服务四十三按段建任务装之，两架构共其装载之理。
- `按段。底层。豫`：服务四十三按段建任务（[提案〇〇〇〇五](../../../提案/00005-自有可执行格式.汉语.md)第三步，惟兼容）：执行器于用户态拆豫行之段表而交之，核依段请块、拷入或清之，用户区之段拷入用户区块，余段以二兆大页映之，带启动块，自文首之入口起；段块记于槽区 +0x1000 起，「放资源」还之。入口之模转四十三于此。
- `平台。底层。豫`：臂之平台初置（开机最先由手书之核呼之）：平台号一（依 ACPI 寻设备之 UEFI 之机，如 VMware），则读 SPCR、MADT、MCFG 定串口、GIC 与 PCIe 配置空间，预置页表中指内核区之项加物理之偏，映 GIC、配置空间、串口于设备之二级表；平台号零（QEMU virt）则无为。见[臂六十四之平台](../文档/臂平台.文言.md)。
- `帧控台。底层。豫`：臂之帧缓控台：有 GOP 帧缓则依 UTF-8 解控台之字，以启盘所带之控台字模（虚址 0x56000000）白字黑底绘于屏，屏满上移半屏；手书之串口出字例程经导出「帧控台字节」呼之，开机内存初置之后启之。见[臂六十四之平台](../文档/臂平台.文言.md)。 并供核务三十二至三十五（交帧、帧缓之信、读字体之模、字体之模之长），桌面遂可行于臂。
- `扩展主控。底层。豫`：二构共用之扩展主控（xHCI）之驱（十月十日起臂用之，十一日起兼亦用之，以代手书者）：于 PCI 配置空间寻首扩展主控，自固件受之，复位而以命令环、事件环巡而编址根端口（及一层 USB 2 集线器之下）之设备（败则三试），配 HID 引导协议键鼠、VMware 虚拟鼠之中断端点与 U 盘之二 bulk 端点；U 盘依 ext4 超级块寻数据区，服务二十八至三十一以 bulk-only 之传读写之（一命至多一兆）。手书之『控台收入』经「扩展主控轮询」呼之（兼返零则仍行手书之 EHCI 后备），键报交按键之模，鼠包入鼠环，根端口之变则于巡中复编址或释槽。兼开机经「扩展主控开机」初置之。
- `按键。底层。豫`：两构共用之键盘解码（十月十一日）：兼之 PS/2 键盘（手书之『控台收入』收串口毕，经导出「键盘收入」呼之，以端口之原语读 i8042，辅口之鼠字入鼠环）与 USB 引导键盘之报（兼手书之 xHCI、EHCI 报告之片经导出「键盘报告」呼之，臂之「键鼠」径呼之）易为 HID 之用之按、抬与修饰之位。文字之模依美式键位出字节入控台之环（方向出 ESC 之序，Ctrl 加字母出控制之码，Ctrl-C 置中断之标）；事件之模（服务五十三开之，执行器取显示面时开）入按键之事环，服务五十四逐一读之。鼠（十月十一日起）：入鼠环者皆四字之包（首字、横移、纵移、滚轮）；PS/2 之鼠初收则开 IntelliMouse 滚轮之模，辅口之字于此成包；USB 引导协议鼠之报由「鼠标报告」换包（兼手书之 xHCI 报告之片经同名之导出呼之，臂之「键鼠」径呼之）。见[控台输入](../文档/控台输入.文言.md)。
- `存储。底层。豫`：两构共用之大容量存储验窗、搬文、备命及发布环项。窗长为五百一十二字节之正倍，整批扇在设备容量内，文经设备任务所授静窗及核之私缓转运。读写之命依扇数书数据长、大端扇区字段，同步之命数据为空；环项先书设备缓址及长，经屏障而发布控制字。标签由呼者存之，门铃及完事之候由呼者办之。
- `入口。底层。豫`：导出手书之核经跳表所呼之函，其序见裸机后端「内核模块」之「内核导出名们」。

模不声线性内存、数据段与全局，核之数据以原语依绝址读写；函之参不逾四（兼之寄存器参数之数）。诸函之参、果与呼之约，见各模之注。
