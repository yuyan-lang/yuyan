# 豫言内核

豫言操作系统内核里与架构无关的部分：任务、调度与内存管理。用底层豫言写成，经编译器得到不带回收的 Wasm 模块，再由裸机后端降级器的内核态目标为 AMD64 与 ARM64 各生成一份机器码，与手写的入口部分（开机、异常与中断的进出、系统调用分派）连接成内核镜像。

特权操作（任意地址读写、系统寄存器、快表刷新、页表根切换、屏障、开关中断）声明在 `内核。底层接口。豫`，编成导入模块「内核」的导入；只有内核态目标提供它们，并就地展开成指令。模块自己的数据放在线性内存里，基址是内核给它的数据区。

手写部分经入口模块导出的函数调用本包。各函数的参数、结果与调用约定见入口模块的注释。
