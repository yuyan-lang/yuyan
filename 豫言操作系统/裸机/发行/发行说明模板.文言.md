## 何物

豫言操作系统者，以豫言所书之单核微内核操作系统也：内核之机器码、启动之首与页表，皆豫言所生；用户之程序行于用户态执行器「客体二号」之上；命令壳与桌面亦以豫言书之，且预编为 x86-64 之机器码，随 ISO 附焉。

此版为 x86-64 之 BIOS/UEFI 混合启动 ISO，以 Limine 引之：

- 开机入中文命令壳：默以拼音组字，按 1–9 选字，F2 易为英文；入「帮助」以观诸令。
- 于命令壳入「图形」，乃入图形桌面。桌面有四窗：文件浏览器、命令行、系统设置、任务管理器，惟以键盘即可开之、易之、闭之，亦可以 PS/2 鼠标点之；出桌面则还命令壳。

## 于 QEMU 启之

须 QEMU 之 `qemu-system-x86_64`，内存予 512 MiB 或逾之。下二令皆以 ISO 为 USB 大容量存储之器，接于 xHCI 控制器；QEMU 之窗示系统之画而受键盘之入，终端并接系统之串口。串口见「命令壳已就绪。」，则启毕。

传统 BIOS（QEMU 自带之 SeaBIOS）：

```sh
qemu-system-x86_64 -machine q35 -accel tcg -m 512M -smp 1 -serial stdio -no-reboot \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1 -boot order=c
```

UEFI（OVMF 固件）。下为 macOS 上 Homebrew 所装 QEMU 自带固件之路；先复一可写之变量文件：

```sh
cp /opt/homebrew/share/qemu/edk2-i386-vars.fd ovmf-vars.fd
qemu-system-x86_64 -machine q35 -accel tcg -m 512M -smp 1 -serial stdio -no-reboot \
  -drive if=pflash,format=raw,unit=0,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd \
  -drive if=pflash,format=raw,unit=1,file=ovmf-vars.fd \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1
```

他系统 OVMF 固件之所在，随其装法而异（如 Debian 与 Ubuntu 之 `ovmf` 软件包装于 `/usr/share/OVMF/`），易上二固件之路即可。须闭 Secure Boot：此版之引导器未署名。

## 于 UTM 启之（macOS）

已验于 UTM 4.7.5。UTM 默接键盘于 USB 2.0 之控制器（EHCI/UHCI），此版惟驱 PS/2 键盘与 xHCI 上之 USB 键盘，故须易设置二事：

1. 新立虚拟之机，择「模拟」（Emulate）→「其他」（Other），启动之映像（Boot ISO Image）择此 ISO；架构择 x86_64，系统仍其默之 Q35；内存予 1024 MiB（至少 512 MiB）。
2. 开虚拟机之设置：于「输入」（Input）页，置「USB 支持」（USB Support）为「关」（Off）；于「QEMU」页，勾「PS/2 控制器」（PS/2 controller）。UEFI 之启仍开。
3. 启虚拟之机，见「壳>」，入「图形」乃入桌面。若画全黑，易「显示」（Display）之显卡为 `VGA` 而复试。

## 已知之限

此版惟求能启、有图形之界。下列诸事，俟诸后版：

- 于系统中书豫言之程序而行之，兼直解其源而行之；
- 网络与声音；
- 装于内置硬盘（AHCI、NVMe）：今惟能自 ISO 或 U 盘启；
- 多核：系统惟用一核；
- 设置之久存：复启则还其默认；
- 实体之机：此版惟验于虚拟之机。ISO 可写于 U 盘而试于实机，然固件与器因机而殊，未必能启，或键盘不可用；于苹果之机热插拔 USB 键盘，尚未支持；
- 他架构：此版惟有 x86-64。

又有今状如下：

- 鼠标：PS/2 鼠标可用（QEMU 默有之，于其窗点之以捕鼠，Ctrl+Alt+G 释之；UTM 依上节设置亦为 PS/2，须于 UTM 捕鼠）。USB 鼠（含 usb-tablet）犹无驱，亦无滚轮。
- 键盘：PS/2 键盘与接于 xHCI（USB 3）控制器之 USB 键盘可用；接于 EHCI/UHCI（USB 2.0/1.1）控制器者，犹不可用。
- 文件浏览器所读者，数据盘上之桌面目录也；惟自 ISO 启而无数据盘，则示“桌面目录不可用：本版要接 USB 数据盘”。
- 显示：用固件所供之线性帧缓；宽逾千九百二十或高逾千二百之高分屏，桌面倍之（二千五百六十乘千六百之屏，桌面为千二百八十乘八百）。
- 资源：同时可行之任务与可用之内存，其限皆紧。
- 诊断之信（键盘与 USB 之初置）惟出于串口，不示于屏；报问题，请附串口之出。
- 虚拟之机：已验于 QEMU（q35，SeaBIOS 与 OVMF）与 UTM 4.7.5（依上节易设置二事）；VirtualBox、VMware 未验，愿闻其果。
