## 何物

豫言操作系统者，以豫言所书之双架构微内核操作系统也：内核之机器码、启动之首与页表，皆豫言所生；用户之程序行于用户态执行器「客体二号」之上；命令壳、桌面与工具亦以豫言书之，且预编为光盘目标架构之机器码，随 ISO 附焉。

此版有兼容六十四与臂六十四二构之 BIOS/UEFI 混合启动 ISO，其引导之程亦豫言所生：

- 开机入中文命令壳（豫构之交互之式）：命书为豫言句，字符串书于『』，如 `「复述」于『你好』`、`「案牍」之「列目」于『/』`；拼音径书于输入之行，按 1–9 选字，? 为通配，Esc 留拼音为英文；入「问津」以观诸令。
- 于命令壳入「图形」，乃入图形桌面。桌面为平铺之窗：活动栏启文件浏览、终端、任务管理器、设备管理器、设置、搜索、启动台与市肆，每窗各为一独立之任务；惟以键盘即可开之、易之、闭之，亦可以鼠点之（PS/2 之鼠、USB 之鼠，或绝对坐标之数位板）。
- 令「寓版」印系统之版、提交号之前九位与架构。
- 内核开机启诸处理器核，任务分于诸核而并行。
- 启盘带系统内之工具链（`/工具` 中之豫构、编译器、豫言系统与格式化）：于命令壳或桌面之终端，可构建而行豫言之程序、行 `。脚本。豫` 之脚本，亦可自源码造己之启盘。
- 网卡与声卡以豫言所书之原生驱动驱之：虚拟网卡、英特尔千兆网卡、瑞昱 PCIe 网卡与 USB 网卡；虚拟声卡、英特尔高清音频与 USB 声卡。
- 令「安寓」以装系统于内置 NVMe 或 AHCI 之盘；令「葺寓」以新镜就地更之。所装之内盘有二系统槽，新系统未确而重启，则引导程序自归旧系统。
- 远程登录（SSH 与 SFTP）与市肆（软件之安装、更新、卸载）随盘而具。
- 同一源码以 `豫言系统 启动盘 --架构 臂六十四` 造臂六十四之 UEFI 启盘（`豫言启动臂.iso`），可启于林檎芯片 Mac 之 QEMU 或 VMware Fusion。

## 于 QEMU 启之

内存予二吉或逾之，处理器核予四。下数令皆以 ISO 为 USB 大容量存储之器，接于 xHCI 控制器；QEMU 之窗示系统之画而受键盘之入，终端并接系统之串口。串口见「命令壳已就绪。」，则启毕。

### 兼容六十四

须 `qemu-system-x86_64`。传统 BIOS（QEMU 自带之 SeaBIOS）：

```sh
qemu-system-x86_64 -machine q35 -accel tcg -m 4G -smp 4 -serial stdio -no-reboot \
  -drive if=none,id=yy_iso,format=raw,file={{兼容光盘}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1 -boot order=c
```

UEFI（OVMF 固件）。下为 macOS 上 Homebrew 所装 QEMU 自带固件之路；先复一可写之变量文件：

```sh
cp /opt/homebrew/share/qemu/edk2-i386-vars.fd ovmf-vars.fd
qemu-system-x86_64 -machine q35 -accel tcg -m 4G -smp 4 -serial stdio -no-reboot \
  -drive if=pflash,format=raw,unit=0,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd \
  -drive if=pflash,format=raw,unit=1,file=ovmf-vars.fd \
  -drive if=none,id=yy_iso,format=raw,file={{兼容光盘}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1
```

他系统 OVMF 固件之所在，随其装法而异（如 Debian 与 Ubuntu 之 `ovmf` 软件包装于 `/usr/share/OVMF/`），易上二固件之路即可。须闭 Secure Boot：此版之引导器未署名。

### 臂六十四

须 `qemu-system-aarch64`。林檎芯片之 Mac 上用 HVF 硬虚，处理器取 host：

```sh
qemu-system-aarch64 -machine virt,gic-version=3,virtualization=off,secure=off,highmem-ecam=off,iommu=smmuv3,default-bus-bypass-iommu=off \
  -accel hvf -cpu host -m 2G -smp 4 -serial stdio -no-reboot \
  -bios /opt/homebrew/share/qemu/edk2-aarch64-code.fd \
  -drive if=none,id=yy_iso,format=raw,file={{臂光盘}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1
```

他机器上以 `-accel tcg -cpu max` 易 `-accel hvf -cpu host`，固件易为林纳上 UEFI 之固件（如 `/usr/share/AAVMF/AAVMF_CODE.fd`）。`-machine` 后之 `gic-version=3…default-bus-bypass-iommu=off` 诸项不可省：少之则内核之裸机核验不过。

## 于 UTM 启之（macOS）

### 臂六十四（林檎芯片之 Mac，虚拟化）

1. 新立虚拟之机，择「虚拟化」（Virtualize）→「其他」（Other），启动之映像（Boot ISO Image）择臂六十四之光盘；架构臂六十四，内存予 2048 MiB 或逾之，UEFI 之启仍开。
2. 启虚拟之机，见「壳>」，入「图形」乃入桌面。

### 兼容六十四（模拟）

已验于 UTM 4.7.5。UTM 默接键盘于 USB 2.0 之控制器（EHCI/UHCI），此版驱 PS/2 键盘与 xHCI、EHCI 上之高速 USB 键盘，UTM 默认之全速键盘经 UHCI 伴随控制器而接，俟后版，故须易设置二事：

1. 新立虚拟之机，择「模拟」（Emulate）→「其他」（Other），启动之映像（Boot ISO Image）择兼容六十四之光盘；架构择 x86_64，系统仍其默之 Q35；内存予 4096 MiB（至少二吉）。
2. 开虚拟机之设置：于「输入」（Input）页，置「USB 支持」（USB Support）为「关」（Off）；于「QEMU」页，勾「PS/2 控制器」（PS/2 controller）。UEFI 之启仍开。
3. 启虚拟之机，见「壳>」，入「图形」乃入桌面。若画全黑，易「显示」（Display）之显卡为 `VGA` 而复试。

## 于系统中

- 装于内盘：于命令壳或桌面之终端入「安寓」，循示择盘而再确之；既装，拔 U 盘或光盘而复启。SATA 之盘须于固件之设择 AHCI 之式。
- 更新：置 `豫言系统` 所造之新镜于数据区之 `/更新`，于命令壳或远程登录行 `「葺寓」于「目录」曰『/更新』`，乃行「更始」而重启。新系统之初启为试启，开机壳确认而后为主槽；未确而重启，则引导程序归旧系统。
- 远程登录：造盘时以 `--预置` 置 `系统/远程登录/授权公钥`（OpenSSH 之 ssh-ed25519 公钥行），装成之系统开机即可以此公钥 ssh 登录；亦可于壳中以「设登录口令」设口令。文件之传用 sftp 与 scp。
- 市肆：桌面活动栏之“软件”自 yuyan-lang.org 之社区软件目录取软件，可安装、更新、卸载；壳命令「安装软件」「更新软件」「卸软件」与界面同用一批库函数。

## 功之今状

- 鼠标：PS/2 之鼠、xHCI 上之 USB 鼠与绝对坐标之数位板（usb-tablet），滚轮可用；QEMU 之窗点之以捕鼠，Ctrl+Alt+G 释之。
- 键盘：PS/2 键盘、xHCI 上之 USB 键盘与 EHCI 上之高速 USB 键盘。
- 显示：用固件所供之线性帧缓；宽逾千九百二十或高逾千二百之屏，桌面按有效像素比二绘之，系统设置具八种缩放而存之。
- 资源：内存按需而提交，任务按需而立；执行器用六十四位之址，回收之堆可至六十四 TiB 以上。
- 实体电脑：已启于二〇一三年出之 MacBook Pro 与 ThinkPad E40；前者验显示与键盘，后者验 AHCI 硬盘、瑞昱网卡、高清音频与 EHCI 之安装。
- 虚拟之机：已验于 QEMU（q35，SeaBIOS 与 OVMF；臂六十四用 virt）、UTM 4.7.5（依上节设置）与 VMware Fusion（臂六十四）。
