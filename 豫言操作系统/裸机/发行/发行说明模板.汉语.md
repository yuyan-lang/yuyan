## 这是什么

豫言操作系统是用豫言写成的双架构微内核操作系统：内核的机器码、启动头与页表都由豫言生成；用户程序在用户态执行器「客体二号」上运行；命令壳、桌面与工具也用豫言写成，并预先编译成 x86-64 机器码随 ISO 附带。

本版是 x86-64 的 BIOS/UEFI 混合启动 ISO，引导程序也由豫言生成：

- 开机进入中文命令壳（豫构的交互模式）：命令写成豫言句，字符串写在『』里，如 `「复述」于『你好』`、`「案牍」之「列目」于『/』`；拼音直接写进输入行，按 1–9 选字，? 是通配符，Esc 把拼音当英文留下；输入「问津」查看命令。
- 在命令壳输入「图形」进入图形桌面。桌面是平铺窗口：活动栏打开文件浏览、终端、任务管理器、设备管理器、设置、搜索、启动台与市肆，每个窗口各是一个独立任务；只用键盘就能打开、切换和关闭，也可以用鼠标点按（PS/2 鼠标、USB 鼠标或绝对坐标数位板）。
- 内核开机启动全部处理器核，任务分到各核上同时运行。
- 启动盘带系统内工具链（`/工具` 里的豫构、编译器、豫言系统与格式化）：在命令壳或桌面终端里可以构建并运行豫言程序、运行 `。脚本。豫` 脚本，也可以从源码造出自己的启动盘。
- 网卡与声卡用豫言写的原生驱动：虚拟网卡、英特尔千兆网卡、瑞昱 PCIe 网卡与 USB 网卡；虚拟声卡、英特尔高清音频与 USB 声卡。
- 命令「安寓」把系统装进内部 NVMe 或 AHCI 硬盘；命令「葺寓」从新镜像就地更新。安装出的内部盘有两个系统槽，新系统没有确认就重启时，引导程序自动回到原来的系统。
- 远程登录（SSH 与 SFTP）与市肆（软件安装、更新、卸载）随盘提供。
- 同一份源码用 `豫言系统 启动盘 --架构 臂六十四` 另造 ARM64 UEFI 启动光盘（`豫言启动臂.iso`），可在 Apple 芯片 Mac 的 QEMU 或 VMware Fusion 中启动。

## 在 QEMU 中启动

需要 QEMU 的 `qemu-system-x86_64`，内存给 4 GiB 或更多，处理器核给 4 个。下面两条命令都把 ISO 当作 USB 大容量存储设备，接在 xHCI 控制器上；QEMU 窗口显示系统画面并接收键盘输入，终端同时接着系统串口。串口出现「命令壳已就绪。」即启动完成。

传统 BIOS（QEMU 自带的 SeaBIOS）：

```sh
qemu-system-x86_64 -machine q35 -accel tcg -m 4G -smp 4 -serial stdio -no-reboot \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1 -boot order=c
```

UEFI（OVMF 固件）。下面是 macOS 上 Homebrew 版 QEMU 自带的固件路径；先复制一份可写的变量文件：

```sh
cp /opt/homebrew/share/qemu/edk2-i386-vars.fd ovmf-vars.fd
qemu-system-x86_64 -machine q35 -accel tcg -m 4G -smp 4 -serial stdio -no-reboot \
  -drive if=pflash,format=raw,unit=0,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd \
  -drive if=pflash,format=raw,unit=1,file=ovmf-vars.fd \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1
```

其他系统上 OVMF 固件的位置随安装方式而定（例如 Debian 与 Ubuntu 的 `ovmf` 软件包装在 `/usr/share/OVMF/`），替换上面两个固件路径即可。须关闭 Secure Boot：本版的引导器没有签名。

## 在 UTM 中启动（macOS）

已在 UTM 4.7.5 上验证。UTM 默认把键盘接在 USB 2.0 控制器（EHCI/UHCI）上，本版驱动 PS/2 键盘与 xHCI、EHCI 上的高速 USB 键盘，UTM 默认的全速键盘经 UHCI 伴随控制器连接，留待后续版本，所以要改两项设置：

1. 新建虚拟机，选「模拟」（Emulate）→「其他」（Other），启动映像（Boot ISO Image）选本 ISO；架构选 x86_64，系统保持默认的 Q35；内存给 4096 MiB（至少 4 GiB）。
2. 打开虚拟机设置：在「输入」（Input）页把「USB 支持」（USB Support）设为「关」（Off）；在「QEMU」页勾选「PS/2 控制器」（PS/2 controller）。UEFI 启动保持开启。
3. 启动虚拟机，出现「壳>」后输入「图形」进入桌面。若画面全黑，把「显示」（Display）的显示卡改成 `VGA` 再试。

## 在系统里

- 安装到内部盘：在命令壳或桌面终端输入「安寓」，按提示选盘并确认两次；装好后取出 U 盘或光盘再重启。SATA 硬盘要在固件设置里选 AHCI 模式。
- 更新：把 `豫言系统` 造出的新镜像放进数据区的 `/更新`，在命令壳或远程登录里执行 `「葺寓」于「目录」曰『/更新』`，再执行「更始」重启。新系统第一次启动是试启，开机壳确认后成为主槽；没有确认就重启时，引导程序回到原来的系统。
- 远程登录：造盘时用 `--预置` 放入 `系统/远程登录/授权公钥`（OpenSSH 的 ssh-ed25519 公钥行），装好的系统开机即可用这把公钥 ssh 登录；也可以在壳里用「设登录口令」设置口令。文件传输用 sftp 与 scp。
- 市肆：桌面活动栏的“软件”从 yuyan-lang.org 的社区软件目录取软件，可以安装、更新、卸载；壳命令「安装软件」「更新软件」「卸软件」与界面走同一批库函数。

## 功能现状

- 鼠标：PS/2 鼠标、xHCI 上的 USB 鼠标与绝对坐标数位板（usb-tablet），滚轮可用；QEMU 窗口里点一下捕获鼠标，Ctrl+Alt+G 释放。
- 键盘：PS/2 键盘、xHCI 上的 USB 键盘与 EHCI 上的高速 USB 键盘。
- 显示：用固件提供的线性帧缓冲；宽超过 1920 或高超过 1200 的屏上桌面按有效像素比 2 绘制，系统设置提供八种缩放并保存。
- 资源：内存按需提交，任务按需创建；执行器使用六十四位地址，回收堆可到 64 TiB 以上。
- 实体电脑：已在 2013 年的 MacBook Pro 与 ThinkPad E40 上启动；前者验过显示与键盘，后者验过 AHCI 硬盘、瑞昱网卡、高清音频与 EHCI 安装。
- 虚拟机：已在 QEMU（q35，SeaBIOS 与 OVMF）、UTM 4.7.5（按上节设置）与 VMware Fusion（ARM64）上验证。
