这是豫言操作系统的第一个公开测试版 {{版本}}（文件名与标签中记作 {{文件名版本}}），供试用与反馈。本版是预发行版本，可能还有缺陷；请先在虚拟机里试用，也请勿用它保存重要数据。

## 这是什么

豫言操作系统是用豫言写成的单核微内核操作系统：内核的机器码、启动头与页表都由豫言生成；用户程序在用户态执行器「客体二号」上运行；命令壳与桌面也用豫言写成，并预先编译成 x86-64 机器码随 ISO 附带。

本版是 x86-64 的 BIOS/UEFI 混合启动 ISO，由 Limine 引导：

- 开机进入中文命令壳：默认拼音组字，按 1–9 选字，F2 切换英文；输入「帮助」查看命令。
- 在命令壳输入「图形」进入图形桌面。桌面有文件浏览器、命令行、系统设置、任务管理器四个窗口，只用键盘就能打开、切换和关闭，也可以用鼠标点按（PS/2 鼠标，或接在 xHCI 上的 USB 鼠标）；退出桌面后回到命令壳。

## 在 QEMU 中启动

需要 QEMU 的 `qemu-system-x86_64`，内存给 512 MiB 或更多。下面两条命令都把 ISO 当作 USB 大容量存储设备，接在 xHCI 控制器上；QEMU 窗口显示系统画面并接收键盘输入，终端同时接着系统串口。串口出现「命令壳已就绪。」即启动完成。

传统 BIOS（QEMU 自带的 SeaBIOS）：

```sh
qemu-system-x86_64 -machine q35 -accel tcg -m 512M -smp 1 -serial stdio -no-reboot \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1 -boot order=c
```

UEFI（OVMF 固件）。下面是 macOS 上 Homebrew 版 QEMU 自带的固件路径；先复制一份可写的变量文件：

```sh
cp /opt/homebrew/share/qemu/edk2-i386-vars.fd ovmf-vars.fd
qemu-system-x86_64 -machine q35 -accel tcg -m 512M -smp 1 -serial stdio -no-reboot \
  -drive if=pflash,format=raw,unit=0,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd \
  -drive if=pflash,format=raw,unit=1,file=ovmf-vars.fd \
  -drive if=none,id=yy_iso,format=raw,file={{ISO文件}} \
  -device qemu-xhci,id=xhci -device usb-storage,drive=yy_iso,bootindex=1
```

其他系统上 OVMF 固件的位置随安装方式而定（例如 Debian 与 Ubuntu 的 `ovmf` 软件包装在 `/usr/share/OVMF/`），替换上面两个固件路径即可。须关闭 Secure Boot：本版的引导器没有签名。

## 在 UTM 中启动（macOS）

已在 UTM 4.7.5 上验证。UTM 默认把键盘接在 USB 2.0 控制器（EHCI/UHCI）上，本版只驱动 PS/2 键盘与 xHCI 上的 USB 键盘，所以要改两项设置：

1. 新建虚拟机，选「模拟」（Emulate）→「其他」（Other），启动映像（Boot ISO Image）选本 ISO；架构选 x86_64，系统保持默认的 Q35；内存给 1024 MiB（至少 512 MiB）。
2. 打开虚拟机设置：在「输入」（Input）页把「USB 支持」（USB Support）设为「关」（Off）；在「QEMU」页勾选「PS/2 控制器」（PS/2 controller）。UEFI 启动保持开启。
3. 启动虚拟机，出现「壳>」后输入「图形」进入桌面。若画面全黑，把「显示」（Display）的显示卡改成 `VGA` 再试。

## 已知限制

本版只求能启动、有图形界面。以下各项留待后续版本：

- 在系统里编写和运行豫言程序，包括直接解释执行源码；
- 网络与声音；
- 装进内置硬盘（AHCI、NVMe）：目前只能从 ISO 或 U 盘启动；
- 多核：系统只用一个处理器核；
- 设置的持久保存：重启后恢复默认；
- 实体电脑：本版只在虚拟机里验收。ISO 可以写进 U 盘在实机上试，但固件与设备因机而异，未必能启动或使用键盘；苹果电脑上热插拔 USB 键盘尚未支持；
- 其他架构：本版只有 x86-64。

此外还有这些现状：

- 鼠标：支持 PS/2 鼠标与接在 xHCI（USB 3）控制器上的 USB 鼠标（HID 启动协议，可以热插拔）。QEMU 默认带 PS/2 鼠标，在 QEMU 窗口里点一下捕获鼠标，Ctrl+Alt+G 释放；UTM 按上节设置后也是 PS/2，要在 UTM 里捕获鼠标。滚轮与 usb-tablet 的绝对坐标留待后续版本。
- 键盘：支持 PS/2 键盘与接在 xHCI（USB 3）控制器上的 USB 键盘；接在 EHCI/UHCI（USB 2.0/1.1）控制器上的键盘还不能用。
- 文件浏览器读的是数据盘上的桌面目录；只从 ISO 启动、没有数据盘时显示“桌面目录不可用：本版要接 USB 数据盘”。
- 显示：用固件提供的线性帧缓冲；宽超过 1920 或高超过 1200 的高分屏上，桌面按两倍放大（2560×1600 的屏上桌面是 1280×800）。
- 资源：同时运行的任务数与可用内存都有较紧的限额。
- 诊断信息（键盘与 USB 初始化）只输出到串口，不显示在屏幕上；报告问题时请附串口输出。
- 虚拟机：已在 QEMU（q35，SeaBIOS 与 OVMF）与 UTM 4.7.5（按上节改两项设置）上验证；VirtualBox、VMware 尚未验证，欢迎反馈结果。
