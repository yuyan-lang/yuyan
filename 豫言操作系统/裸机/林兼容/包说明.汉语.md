# 林兼容

林兼容层（[提案 00012](../../../提案/00012-兼容林纳克斯程序与驱动.汉语.md)）：在豫言操作系统上原样运行林纳克斯（Linux）程序。

- 兼容层是底层模式的普通豫言程序，编成豫行文件（AMD64 用 `yy豫言系统 底层豫行 yy林兼容.wasm 输出`，ARM64 用 `底层臂豫行`），作为普通的子程序由命令壳启动：`「运行」于『/林/林兼容』于「列」【[『--根』，『林根目录』，][『--跟踪』，]『林程序路径』，『参数』…】`。`--根` 给出林根（林程序看到的 `/`）在豫言文件系统里的位置；`--跟踪` 让每个系统调用打印一行（线程号、号、参数与结果，带路径的调用还印出路径），林程序的异常也打印出来（向量、错误码、故障址、程序计数），用来与 strace 对照。
- 林程序的机器码直接在处理器上运行：兼容层用内核的通用机制「受限模式」（服务 48 进入受限）运行它，林程序执行系统调用指令或出故障时，内核把它的寄存器交回兼容层；兼容层按 Linux 的语义办完，再进入受限。内核不认识 Linux 的系统调用号。
- Linux 的语义（系统调用号、errno、文件描述符号、fork、信号、`/proc` 等）只写在本包里；豫言内核、接口包与标准库都不依赖本包。
- 林程序的文件由豫言的文件服务提供（初始任务代办，节点原语 210–219），兼容层只做翻译：路径解析（当前目录、`.`、`..`、符号链接）、文件描述符表、stat/statx、getdents64、readlink，以及建、写、截断、删除、建目录、改名（普通文件）、建符号链接（symlink、symlinkat）、改模式（chmod、fchmodat；mkdir 的模式位去掉掩码 022 后写进去）。flock 照收不管。连续的写先攒在 64 MiB 的待写缓冲里（同一描述符、位置相接），别的系统调用开始前先写出去。
- 进程与管道：fork/vfork/clone（不带 CLONE_THREAD）用内核服务 49 克隆任务，execve 在原任务里换程序（含 `#!` 脚本；路径 /proc/self/exe 换成当前程序；参数与环境拷好后把旧程序的内存块交还内核），wait4 查子任务状态；管道放在线性内存 3 GiB 起的共享区（内核服务 51 共享区段，兼容层一启动就建好），fork 出的进程映同一批物理块。
- 内存：林程序的地址空间就是兼容层线性内存平移 1 TiB；mmap 可映文件（读入内容，私有映射）。链接在 0x400000 的非位置无关程序（如 Debian 的 python3.11）放进低区：内核服务 52 低区映射把兼容层动态区的 14 块另映到 0x400000–0x1FFFFFF，兼容层经动态区那一处读写。
- 文件请求：初始任务的邮箱只存一条消息，几个林进程同时读文件时请求可能被拒，兼容层小睡后重发。
- 线程：clone 带 CLONE_THREAD 建线程，同一进程的各线程在一个豫言任务里轮流运行（多对一）；futex（等、醒、移、醒兼运算）在兼容层里办，会阻塞的系统调用返回“需等”由主循环换线程、稍后重办；内核在时钟轮转时让受限执行退出（原因 3），兼容层借此在线程间轮换。
- 信号：sigaction、sigprocmask、sigaltstack、kill（自己与子进程）、tgkill、alarm、setitimer、POSIX 计时器（一个）、sigsuspend、pause、sigtimedwait、rt_sigreturn；线程运行前投能投的信号，在线程栈（或备用栈）上建与 Linux 同布局的信号帧（x86-64、ARM64），阻塞中的系统调用按 SA_RESTART 重做或得 EINTR；子进程结束时给父进程记 SIGCHLD；林程序的异常有处理函数时转成 SIGSEGV 等信号。
- /proc 与 /sys：兼容层按字面生成，不经文件服务：meminfo、cpuinfo、stat、uptime、mounts、self 下的 stat、status、maps、cmdline、environ、comm、fd、task（task/线程号只在线程活着时存在，task 目录的链接数是 2 加线程数）、exe、cwd，sys/kernel 与 sys/vm 的常见项，/sys 的处理器在线表等。
- 共享映射：MAP_SHARED 从线性 64 GiB 起的共享区分（内核服务 51 标共享），fork 出的进程看到同一块内存。
- 内存文件（memfd_create，描述符种类 16）：对象表在管道共享区，一棵进程树共见；内容在物理块里（内核服务 55 区段物块要块、56 映物块映块），描述符经套接字传给别的进程后两边读写同一份；每次 mmap(MAP_SHARED) 映到新地址。memfd_create 与 eventfd2 遇到不认识的标志位返回 EINVAL（Chromium 用它探测内核）。
- 内存保护与退还：mprotect 去掉写权限的区间记进不可写区段表，prlimit 往这里写返回 EFAULT（Chromium 的 ProtectedMemory 这样验证只读）；madvise 的 MADV_DONTNEED、MADV_REMOVE 把私有区间清零，整 2 MiB 的块交还内核（PartitionAlloc 与 glibc 退还内存后认定再读到的是零）。
- futex 的优先级继承锁（LOCK_PI、UNLOCK_PI、TRYLOCK_PI）：锁字记持有者的线程号，抢不到时置“有等者”位、稍后重办。
- 多路等待与事件描述符：poll、ppoll、select、pselect6、epoll（水平触发）、eventfd、timerfd；等不到时返回“需等”，由主循环稍后重办。
- Unix 套接字：socketpair、socket、bind、listen、connect、accept、accept4、shutdown、send、recv、sendto、recvfrom、sendmsg、recvmsg（SCM_RIGHTS 传描述符）、getsockname、getpeername、getsockopt、setsockopt；连上的流套接字是共享区里的一对管道，监听者记在共享区的登记表里（路径与抽象名都可以），fork 出的进程也连得上。写到没有读端的管道或套接字时发 SIGPIPE（MSG_NOSIGNAL 不发）。
- mremap：缩小原地办，变大时（MREMAP_MAYMOVE）新分一块并拷过去。
- IPv4 套接字（描述符种类 15）：TCP 与 UDP 的 socket、bind、listen、connect（非阻塞得 EINPROGRESS，阻塞的等连好）、accept、send/recv、sendto/recvfrom、sendmsg/recvmsg、sendmmsg/recvmmsg、shutdown、getsockname/getpeername、getsockopt（SO_ERROR 等），poll/epoll 可等；协议栈在初始任务的执行器里（网卡 virtio-net，见客体二号），兼容层经远程原语 220–229 请它办，同一套接字被 fork 后几个进程共持时按引用数关闭。地址按 QEMU 用户网络静态配置（本机 10.0.2.15，网关 10.0.2.2，域名服务 10.0.2.3），127.0.0.1 走环回。AF_INET6 返回 EAFNOSUPPORT（程序退回 IPv4）。
- kill 给子进程：SIGKILL 直接终止任务，其余信号投进共享区的信箱，子进程在信号收集里取走、按处置办；ioctl 的 FIONBIO、FIOCLEX、FIONCLEX 对任何描述符都行；开机的 0、1、2 以读写方式打开（libuv 按 F_GETFL 判断能不能写）。
- 子包「林根工具」（`yy林根 解包 林根目录 档案…`）把林纳克斯根文件系统的 tar 档（可以是 Docker 镜像的几层）解成林根目录，`yy豫言系统 启动盘 --林根 盘内目录=林根目录` 把它造进数据盘。
