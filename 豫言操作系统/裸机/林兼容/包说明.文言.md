# 林兼容

域中候退依所存成员之记译已退之号，至父收内核之柄。信号目标反查惟合活成员。

`窗口沙箱` 为第八步实浏览器之验门：初用户与组号千，默认参留 Wayland、软件绘画及验页，Chrome 用默认沙箱。辅向量之真效用户、组号取今身份。`窗口验收盘 架构 林根目录 输出目录 沙箱` 选此门，三参之法循第六步。沙箱之验须核实页及隔离之行。

用户与组之易，先验旧号，尽过而书；常程惟选已有真、效、存号。`setuid`、`setgid` 有权时并易三号，降权后惟易效号；`setreuid`、`setregid` 依真效之易同步存号。零号尽弃而复之，返 EPERM。独立之能、用户命名空间之映及文件权限之验续行。

第八步经典过滤器见 `过滤。底层。豫`。`过滤校验` 受兼容私存之八字节令列、令数及工作区，零为有效、二十二为无效；令数一至四〇九六，工作区至少令数乘四字节。验令码、数据偏及跳址，交诸前驱暂存初置之掩，拒分支绕书而读。末令须返，跳向前而在列内。

`过滤执行` 受已验且不变之程、令数、六十四字节调用快照及六十四字节暂存，返全三十二位动作。快照循程序架构载原调号、审计架构、令址及六个六十四位参。可行三十二位绝对载、即数、十六字暂存、长度、算术、条件跳、返回及累加器与索引寄存器互转；动态除零返杀线动作。呼者保址有效、容足及诸缓不重叠。

`沙箱。底层。豫` 接 `seccomp` 与 `prctl`：禁提权之标惟增，装前抄且验滤程；克隆线、分叉及换程留策。同步先验诸活线之滤链，继而一并布之；歧则返线号，有同步错误旗则返 ESRCH。调用先以原号行滤链，后译架构之号；叠加取最严动作，同级取最新数据。支错误返、允行、跟踪缺席、杀线、杀程及具调用元数据之 SIGSYS；严模式惟允读、写、线退及信号返。

线表尾偏四十八、五十六、六十，各存私滤链、禁提权标及模式。滤程抄后不变。两架构 QEMU 自验装、私抄、承继、同步、调用截及信号元数据。真实 Linux ELF、命名空间及去 `--no-sandbox` 之 Chrome 验收续行；滤结回收、映射权限细验及信号终止之候状态编码留后补。

KVM 桌面之验，置启动盘、志、截图于磁盘别目，以 `TMPDIR` 指其下暂目，QEMU 快照循此环境。依宿主余量预留暂存之地。

前表面尽卸则清显示面之旧像；跟踪记前表面号与映射之数。复后窗之像留后补。

顶层之窗依首次带缓提交之序映于一豫言显示面，最新映者得键盘之焦。重画守前窗及焦；毁或卸前面，则复次已映之窗。多窗之布、鼠标择窗及对象号复用之代，留后续。跟踪书窗名及已交缓之尺，以验实程而定位。

启动块沿通用客体八兆参区之布，其后为六十四千字程名区；环境、当前目录及显示之授，皆依程名区中所定之偏读之。兼容层藏启动块于六十四至八十米，避描述之径及窗口服缓。键盘每十滴答察一回，以次滴答为今察之止期。

桌面验收有林终端、林浏览器二门，共「运行」之启程、装载及受限线程之理。空参而获显面者，终端行 foot，浏览器行 Chromium，以 Wayland、软件绘画及本地验页；明参循旧命令行之法。第六步浏览器用 `--no-sandbox`，第八步启沙箱而验。

管道共区容七百六十八米；内存文件之块表居共区二百五十六米起，每对象容六五五二〇块之号，足以受 foot 原样之五百一十二米画存。伪终端之主从循双管传字，终端式、尺寸及前台程组共存于两端。

Wayland 之服由兼容层启动之程轮询，听于 `/tmp/wayland-0`，循既有 Unix 管与林程通信。服办全局之询、同步、共存之缓及窗口表面之配置与提交。桌面以空参启兼容层，则行 `/林/根` 中之 foot。ARM64、AMD64 皆已验 foot 输入命令及 Chromium 窗显本地之页。林根工具之 `窗口验收盘 架构 林根目录 输出目录`，合构原生预置及图形启动盘。

伪终端主从循双向共管，`/dev/ptmx` 建主端，`/dev/pts/终端号` 开从端；两端共存终端式、尺寸及前台程组，描述之复与闭循管端引用。XKB 映经共存文件传于 Wayland 客户端，桌面基本按键译为键事。规范行编、修饰掩及输入法留待后补。

桌面指针之移、按、释，传于前表面 Wayland 指针对象；坐易为八位小数，键号易为左、中、右钮。易表面则先传离，后传入。轮与跨客之离事留后补。

窗口显示之桥，复用提案〇〇〇一四之子程序显示代办之约。豫言桌面授显示面，兼容之层经初始任务交画，取尺与输入之事。`窗口自检` 入口可构为两架构之豫行程序，以验桌面中之画与按键回传。

消息式套接字之队，各管容五百十二条，逐条记发者之进程号；收则随其消息授凭据。队满，阻塞之书候之，非阻塞者返 EAGAIN。

消息式套接字之发缓诸段合为一条，收缓诸段依次取同条之文。转缓由本程复用。截断之旗留待后版。

授控制消息，以今次读管之发者与止位为据。锁内存之于收程己区，以守今次所读之界。

发控制描述与消息之文共一锁，先察容文之余；候而重办者留其未授之控制。部分授后有误之撤留待后版。

林兼容之层（[提案〇〇〇一二](../../../提案/00012-兼容林纳克斯程序与驱动.汉语.md)）：于豫言操作系统原样行林纳之程。

- 兼容之层以底层模式之豫言书之，由编译器径出豫行之文（以 `豫构 构建 林兼容 --输出 林兼容 -j 24 -- --目标 本机 --目标系统 豫言 --目标架构 兼容六十四`，臂易末项为 `臂六十四`；不书 `--目标架构` 则依构之机之架构，于臂机造兼之盘须明书之；编译器之 `--符号表 文件` 别书函数之符号表），命令之壳以常子程序起之：`「行」于『/林/林兼容』于「列」【[『--根』，『林根目录』，][『--跟踪』，]『林程序路径』，『参数』…】`。`--根` 示林根（林程所见之 `/`）于豫言文件系统中之所在；`--跟踪` 使每系统调用印一行（线号、号、参与果，带径之调用并印其径），林程之异常亦印之（向量、误码、故障之址、程之计），以对照 strace。
- 林程之机器码径行于处理器：兼容之层以内核通用之「受限之式」行之；林程行系统调用之令或有故障，核以其寄存器还兼容之层，层依 Linux 之义办之，复入受限。核不识 Linux 系统调用之号。
- Linux 之义（调用之号、错误之号、文件描述之号、分叉、信号、`/proc` 等）惟书于本包；豫言之核、接口之包与标准之库皆不依之。
- 林程之文件由豫言底层文件之接口供之（经底层转送请初始任务办之，见 `转送`；提案〇〇〇二一第十一步），层惟译之：解路（当前目录、`.`、`..`、符号链接）、文件描述之表、stat/statx、getdents64、readlink，及建、书、截、删、建目录、易名（常文）、建符号链接、改式（chmod、fchmodat；mkdir 之式去其掩〇二二而书之）。flock 受而不理。连书先积于六十四兆之待书之缓（同描述而位相接），他系统调用将行先书出之。
- 进程与管道：分叉以服务四十九克隆之，execve 于原任务中易其程（含 `#!` 之脚本；径为 /proc/self/exe 则易为今程；参与环境既拷，还旧程之块于内核），wait4 察子任务之状；waitid 得候全体或指定之子，得不候或留其终状，依今进程号域书其号，用户号取分叉时之真号。止续、群组、进程描述、用量及子易身份后之用户号待后补之。管道置于线性内存三吉起之共享区（服务五十一，层起即建之），分叉之程映同块。
- 管道共区二百五十六兆；每管有八百格待传控制描述，供铬启动之时集中传句柄。
- 内存：林程之址空即兼容层线性内存移一 TiB；mmap 得映文件（读其容，私映）。链接于 0x400000 之非位置无关之程（如 Debian 之 python3.11）置于低区：内核服务五十二低区映射以兼容层动区之十四块别映于 0x400000 至 0x1FFFFFF，层经动区读写之。
- 底层之请：初始任务之函惟容一信，诸林程并请则信或见拒，层小睡而复发。
- 线程：clone 带 CLONE_THREAD 则建线程，一进程之诸线程同在一豫言任务中迭行（多对一）；futex（候、醒、移、醒兼运算）办于层中，将阻之系统调用返“需等”，主环易线而后重办；时钟轮转之际核令受限之行退出（故三），层借此轮诸线程。
- 信号：sigaction、sigprocmask、备栈、kill（己与子）、tgkill、alarm、setitimer、POSIX 计时器（一）、sigsuspend、pause、sigtimedwait、rt_sigreturn；线将行则投可投之信，于线栈（或备栈）建同 Linux 之信号帧，阻中之系统调用依 SA_RESTART 重之或得 EINTR；子终则为父记 SIGCHLD；林程之异常有处理之函则转为信号。
- /proc 与 /sys：层依字面生之，不经文件之服；task/线号惟线存乃有，task 目录之链接数为二加线数。
  内存文件可由 `/proc/self/fd/N` 重开，同一对象依新旗而别记偏移，使 Chromium 得只读之共存描述。
- 共映：MAP_SHARED 自线性六十四吉起之共区分之（服务五十一标共享），分叉之程见同块。
- 内存文件（memfd_create，描述之种十六）：对象之表居管道共区，一树之程共见；其容在物理之块（服务五十五要之、五十六映之），描述经套接字传于他程，二者所读写者同；每共映一次则映于新址。memfd_create、eventfd2 遇不识之旗返 EINVAL（Chromium 以之探核）。/dev/shm 为兼容层中之内存文件系统（同林纳之 tmpfs）：其文即内存文件之对象，依名登记于管道共区，同名再开得同一对象，unlink 惟去其名；Chromium 之共享内存建于此。fallocate 于内存文件有效。
- 大程只读段之共享：逾三十二兆之位置无关主程（如二百七十九兆之 Chromium）装毕，只读段之整二兆块标为共享（服务五十五），块号记于共区之映像缓存；分叉则映而不复，他程装同文则改映之（服务五十六，逐字比对）。十余 Chromium 之程共一份程序之内存。
- 内存之护与退：mprotect 去书权之区记于不可书之段表，prlimit 书于此则返 EFAULT（Chromium 之 ProtectedMemory 以此验只读）；madvise 之 MADV_DONTNEED、MADV_REMOVE 清私区为零，整二兆之块交还内核。
- futex 继优之锁（LOCK_PI、UNLOCK_PI、TRYLOCK_PI）：锁字记持者之线号，不得则置候位而稍后复办。
- 多路之候与事件之描述：poll、ppoll、select、pselect6、epoll（水平触发）、eventfd（计数居管道共区，分叉或传于他程则共之）、timerfd；不得则返“需等”，主环稍后重办。
- Unix 套接字：socketpair、socket、bind、listen、connect、accept、shutdown、send、recv、sendmsg、recvmsg（SCM_RIGHTS 传描述）、取名与选项诸调用；连上之流套接字即共区之一对管道，SOCK_SEQPACKET 亦然，惟守消息之界（一书一整条，一读一条，读之不尽则截）；设 SO_PASSCRED 之端，recvmsg 附 SCM_CREDENTIALS（发者之进程号，用户与组皆零；Chromium 之 zygote 赖之以识子程）；监听者记于共区之登记表（径与抽象之名皆可），分叉之程亦得连之。书于无读端之管或套接字则发 SIGPIPE（MSG_NOSIGNAL 则否）。
- mremap：缩则原处办之，长（MREMAP_MAYMOVE）则新分一块而拷之。
- IPv4 套接字（描述之种十五）：TCP 与 UDP 之建、系、听、连、受、收发、半闭、取名与选项，poll、epoll 得候之；栈在初始任务之执行器（网卡经核务六十一至六十三，核先用原生网卡之驱，见客体二号），层经底层转送请之（底层网络之听、连、受、数据报与套接之址，底层柄之读书、候与闭）；分叉共持者依引用之数而闭。分叉之子用父所建之套接（初始任务依主而核其柄），留待后续之版。址依 QEMU 用户网络静设，127.0.0.1 走环回。AF_INET6 返 EAFNOSUPPORT。
- 杀子：SIGKILL 径终其任务，余信投于共区之信箱，子于收信时取之而依其处置办之；ioctl 之 FIONBIO、FIOCLEX、FIONCLEX 诸描述皆可；开机之零一二以读写开之。
- 子包「林根工具」（`林根 解包 林根目录 档案…`）解林纳根文件系统之 tar 档（得为 Docker 镜像之数层）为林根目录，`豫言系统 启动盘 --林根 盘内目录=林根目录` 造之于数据盘。
用户之域，以兼容层存其身份之映与能力。新域之号先为溢出号；一写自身一号之映，乃转为域内号。组号之映，先禁附加组；重写则返 EPERM。能力可弃，弃而复取则返 EPERM。嵌套之域承禁附组之约。多项之映、同域多程共记与余域之隔离，留待后续。

`/proc/self/ns/user` 为今用户域之身份链，读之得 `user:[域号]`。新域得新号，分叉承旧号，察状得其节点号。惟读而开，则存当时之域身份，后建新域而旧描述身份存。域描述之读写返 EINVAL。进程树共区首偏八，存域号之原子计数。他程之域径、域描述之复接及设备号细化，留待后续。

进程号域，以兼容层共表记其属及祖域之号。`clone` 建域，其首程号一；`unshare` 之域施于下次分叉，今程存旧域。己、父、线、候退、信号目标及消息凭据之程号，皆依观者之域译之；域外目标返 ESRCH。首程退则域失活，并终止表中后代；复分叉返 ENOMEM。父子重布同分叉之项，存其退态。`/proc/self/ns/pid` 供域身份链及惟读描述符。孤儿之收养、程组、同域诸程之信号权及域描述之复接，俟后续。

## 分叉之文件态

带共文件态之旗而克隆者共根及今目录，常分叉者得私副。易目录、依今目录解径、取今目录及进程目录之链接共用此态。态置兼容既有共区，别锁守之；内核仍供通用任务克隆及共内存之机。

`chroot` 须有今用户域易根之能。绝径及绝链接自新根起，`..` 至新根而止；今目录及先开目录之描述存旧径之锚。`getcwd` 返依新根之径，今目录在根外则返 ENOENT。`/proc/self/fdinfo` 列在用描述之常文项；为新根则系原进程之物理任务号及生代，主退或任务号复用后开返 ESRCH、读旧目录描述返 ENOENT。虚进程目录之状由所开之物供之。

后续：造文之掩、余进程目录之根、常根改名后节点之锚、进程描述链接依物而随、fdinfo 文，以及实 Chrome 封文件树与二构沙箱窗口之验。
