# 林兼容

林兼容之层（[提案〇〇〇一二](../../../提案/00012-兼容林纳克斯程序与驱动.汉语.md)）：于豫言操作系统原样行林纳克斯之程。

- 兼容之层以底层模式之豫言书之，编为豫行之文（兼以 `yy豫言系统 底层豫行`，臂以 `底层臂豫行`），命令之壳以常子程序起之：`「运行」于「/林/林兼容」于[「--根」于「林根目录」于][「--跟踪」于]「林程序路径」于「参数」…`。`--根` 示林根（林程所见之 `/`）于豫言文件系统中之所在；`--跟踪` 使每系统调用印一行（号、参与果），以对照 strace。
- 林程之机器码径行于处理器：兼容之层以内核通用之「受限之式」行之；林程行系统调用之令或有故障，核以其寄存器还兼容之层，层依 Linux 之义办之，复入受限。核不识 Linux 系统调用之号。
- Linux 之义（调用之号、错误之号、文件描述之号、分叉、信号、`/proc` 等）惟书于本包；豫言之核、接口之包与标准之库皆不依之。
- 林程之文件由豫言之文件之服供之（初始任务代办，节点原语二百一十至二百一十七），层惟译之：解路（当前目录、`.`、`..`、符号链接）、文件描述之表、stat/statx、getdents64、readlink，及建、书、截、删、建目录、易名（常文）。连书先积于六十四兆之待书之缓（同描述而位相接），他系统调用将行先书出之。
- 进程与管道：分叉以服务四十九克隆之，execve 于原任务中易其程（含 `#!` 之脚本），wait4 察子任务之状；管道置于线性内存三吉起之共享区（服务五十一），分叉之程映同块。
- 内存：林程之址空即兼容层线性内存移一 TiB；mmap 得映文件（读其容，私映）。链接于 0x400000 之非位置无关之程（如 Debian 之 python3.11）置于低区：内核服务五十二低区映射以兼容层动区之十四块别映于 0x400000 至 0x1FFFFFF，层经动区读写之。
- 文件之请：初始任务之函惟容一信，诸林程并读文件则请或见拒，层小睡而复发。
- 子包「林根工具」（`yy林根 解包 林根目录 档案…`）解林纳克斯根文件系统之 tar 档（得为 Docker 镜像之数层）为林根目录，`yy豫言系统 启动盘 --林根 盘内目录=林根目录` 造之于数据盘。
