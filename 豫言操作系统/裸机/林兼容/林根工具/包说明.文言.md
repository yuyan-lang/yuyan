# 林根工具

林根工具（提案〇〇〇一二）解林纳克斯根文件系统之档为“林根目录”，以供启盘造全林根于数据盘。

用法：`yy林根 解包 林根目录 档案…`。档为 tar，得经 gzip、xz、zstd 压之（依首之魔数辨之），亦得为 RPM 之包（取其压过之 cpio 负载，依 newc 读之）；予多档则依次叠之，同 Docker 镜像之层：后档为上层，同路取最上层之项，`.wh.名` 删下层同名之项（并其下之路），`.wh..wh..opq` 删下层于此目录之所有。

林根目录有二物：

- `内容/序号`：诸常文之内容，依所见之序编号（〇、一、二……）。宿主之文件系统或不辨大小写、不许设备之文，故内容惟依序号而藏。
- `清单`：一项一行，字段以制表符分之：种（`目`、`文`、`链`）、式（十进之权位，含 setuid 之属）、路（无首斜杠）、附（`文` 为内容之号，`链` 为链接之的，`目` 为空）。

档中之硬链接书为指同一内容号之 `文`；设备之文、命名之管等特文略之而计其数；路首之 `./` 与 `/` 去之，含 `..` 段之路略之。

启盘以 `--林根 盘内目录=林根目录` 读之：目录成盘内之目录，常文带其式，符号链接依原的书为 ext4 之符号链接（短于六十字节者藏于节点）。

后版之事：为上层所覆所删之文不书其容、硬链接共节点、设备之文、目录之式与属主。
