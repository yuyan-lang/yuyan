# 林根工具

窗口验盘先依今源码制其造盘之器，乃制相配之开机程序、执行器与内核。开机之式易则先自举今编译器；造盘之器与诸模同源码之版。

QEMU 验前扩盘之非零首段为疏文：臂构数据盘二 GiB，兼构启盘合数据盘四 GiB。ext4 所声明之容量由全设备之空间承之，目录及文件可续分空块。

桌面验收之出目惟含 ASCII 字，器于启前核之。两构之数据盘皆由 USB 接今启动内核。诊断得以 `林桌面验收.wasm 监视器管道 原样命令` 送 QEMU 监视之令；截 PNG 之令可书 `screendump /private/tmp/豫言window.png -f png`，实图径亦惟含 ASCII 字。

桌面验收之程序参数可取「浏览器长验」，以于合入后候 Chromium 首次交画，询期十分钟。常用「浏览器」询期二分钟，宜短轮定位。初设确认之窗逐以实回车认之，窗及页仍以图验明。

窗口验收盘沿用「壳」入口，两架构皆以同壳入豫言桌面。桌面交互之器以 `豫构 构建 豫言裸机 林桌面验收 --输出 林桌面验收.wasm -j 24` 制之，以 `林桌面验收.wasm 架构 镜像目录 独立输出目录 终端或浏览器` 行之。臂六十四用 HVF，兼容六十四用 KVM；器送 USB 键鼠之入，终端书 `echo 42`，留串口及图。各轮用独立输出之目及暂写之影，终由人核提示、命令之果或浏览器之页。

窗口验盘之门自补运行之目及页面：`dev/shm`、`dev/pts`、`tmp`、`run`，并 `usr/share/林测/页.html`。预置林终端、林浏览器、窗口自检三原生之程，终端及浏览器共林兼容之运行理。浏览器用 Wayland 及软件绘画，显验页及脚本之果四十二；今依第六步用 `--no-sandbox`，第八步启沙箱而验。

林根工具（提案〇〇〇一二）解林纳根文件系统之档为“林根目录”，以供启盘造全林根于数据盘。

用法：`林根 解包 林根目录 档案…`。档为 tar，得经 gzip、xz、zstd 压之（依首之魔数辨之），亦得为 RPM 之包（取其压过之 cpio 负载，依 newc 读之），或 deb 之包（取 ar 档中名始于 data.tar 之员，解压而依 tar 读之）；予多档则依次叠之，同 Docker 镜像之层：后档为上层，同路取最上层之项，`.wh.名` 删下层同名之项（并其下之路），`.wh..wh..opq` 删下层于此目录之所有。

林根目录有二物：

- `内容/序号`：诸常文之内容，依所见之序编号（〇、一、二……）。宿主之文件系统或不辨大小写、不许设备之文，故内容惟依序号而藏。
- `清单`：一项一行，字段以制表符分之：种（`目`、`文`、`链`）、式（十进之权位，含 setuid 之属）、路（无首斜杠）、附（`文` 为内容之号，`链` 为链接之的，`目` 为空）。

档中之硬链接书为指原文之绝对符号链接（`链`，附为 `/` 加原路），造盘时内容惟书一份；基层之 `bin`、`sbin`、`lib`、`lib32`、`lib64`、`libx32` 为指 `usr/` 下同名目录之符号链接者（如 Debian 十二），后诸层此诸目录下之项徙于 `usr/` 下，同名之目录项去之（usrmerge，同 dpkg 循链而置）；设备之文、命名之管等特文略之而计其数；路首之 `./` 与 `/` 去之，含 `..` 段之路略之。

启盘以 `--林根 盘内目录=林根目录` 读之：目录成盘内之目录，常文带其式，符号链接依原的书为 ext4 之符号链接（短于六十字节者藏于节点）。

后版之事：为上层所覆所删之文不书其容、硬链接共节点、设备之文、目录之式与属主。

# 缓存清理后之恢复

`恢复软件 软件索引.gz 下载目录 镜站地址 软件名…` 读 Debian 软件索引，递取所依软件，以宿主 `curl` 下载其档，写「软件档案清单」于下载目录。`林根 清单解包 林根目录 软件档案清单` 循清单叠解其档。以 `豫构 构建 林根工具 恢复软件 --输出 恢复软件.wasm -j 24` 构入口。今依赖取首候选；版本约束、虚拟软件、损档重试，列为后事。
