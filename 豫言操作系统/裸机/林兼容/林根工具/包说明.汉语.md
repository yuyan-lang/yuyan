# 林根工具

窗口验收盘先由当前源码构建造盘工具，再生成配套开机程序、执行器和内核。开机格式更新后，先自举当前编译器；造盘工具与模块使用同一源码版本。

QEMU 验收前把只含非零前段的盘扩为稀疏文件：ARM64 数据盘为两 GiB，AMD64 启动数据合盘为四 GiB。ext4 的声明容量由完整设备空间承载，目录和文件可以继续分配空闲块。

桌面验收的输出目录只含 ASCII 字符，工具在启动前检查路径。两架构的数据盘均经 USB 接入当前启动内核。诊断时可用 `yy林桌面验收.wasm 监视器管道 原样命令` 发送 QEMU 监视器命令；截图命令例如 `screendump /private/tmp/yywindow.png -f png`，实际截图路径也只含 ASCII 字符。

桌面验收的程序参数可取「浏览器长验」，用于合入后等待 Chromium 首次交画，轮询期限为十分钟。默认「浏览器」使用两分钟期限，适合短轮定位。初次配置确认窗经真实回车逐个确认，窗口和页面仍由截图验明。

窗口验收盘沿用「壳」入口，供两架构以同一命令壳进入豫言桌面。桌面交互工具由 `豫构 构建 豫言裸机 林桌面验收 --输出 yy林桌面验收.wasm -j 24` 构建，运行 `yy林桌面验收.wasm 架构 镜像目录 独立输出目录 终端或浏览器`。ARM64 使用 HVF，AMD64 使用 KVM；工具发送 USB 键鼠输入，终端输入 `echo 42`，并保留串口与截图。各轮使用独立输出目录和临时写入快照，最后人工核对提示符、命令结果或浏览器页面。

窗口验收盘入口自动补齐运行目录和页面：`dev/shm`、`dev/pts`、`tmp`、`run`，以及 `usr/share/林测/页.html`。它预置「林终端」「林浏览器」「窗口自检」三个原生程序，终端和浏览器共用林兼容运行逻辑。浏览器入口使用 Wayland 与软件绘制，显示验收页面及脚本结果 42；当前沿第六步使用 `--no-sandbox`，第八步验收启用沙箱。

林根工具（提案 00012）把林纳根文件系统的档案解成“林根目录”，供启动盘把整棵林根造进数据盘。

用法：`yy林根 解包 林根目录 档案…`。档案是 tar，可以经 gzip、xz 或 zstd 压缩（按开头的魔数识别），也可以是 RPM 包（取出压缩过的 cpio 负载，按 newc 格式读）或 deb 包（ar 档里名字以 data.tar 开头的成员，解压后按 tar 读）；给多个档案时按次序叠加，同 Docker 镜像的层：后面的档案是上一层，同一路径取最上层的项，`.wh.名字` 删去下面各层的同名项（连同它下面的路径），`.wh..wh..opq` 删去下面各层在这个目录里的全部内容。

缓存清理后的恢复入口：`yy恢复软件 软件索引.gz 下载目录 镜站地址 软件名…`。入口读取 Debian 软件索引，递归取得依赖并调用宿主 `curl` 下载软件档案，在下载目录写入「软件档案清单」。用 `yy林根 清单解包 林根目录 软件档案清单` 按清单叠加解包。恢复入口由 `豫构 构建 林根工具 恢复软件 --输出 yy恢复软件.wasm -j 24` 构建。当前依赖取首个候选，版本约束、虚拟软件与损坏下载的重试列为后续事项。

林根目录里有两样东西：

- `内容/序号`：每个普通文件的内容，按出现次序编号（0、1、2……）。宿主的文件系统可能不分大小写、不许建设备文件，所以内容只按序号存放。
- `清单`：每项一行，字段以制表符分隔：种（`目`、`文`、`链`）、模式（十进制的权限位，含 setuid 等）、路径（不带开头的斜杠）、附（`文` 为内容序号，`链` 为链接目标，`目` 为空）。

档案里的硬链接写成指向原文件的绝对符号链接（`链`，附为 `/` 加原路径），造盘时内容只写一份；基础层的 `bin`、`sbin`、`lib`、`lib32`、`lib64`、`libx32` 是指向 `usr/` 下同名目录的符号链接时（如 Debian 12），后面各层这些目录下的项改挂到 `usr/` 下、同名目录项去掉（usrmerge，与 dpkg 顺着链接放文件的结果相同）；设备文件、命名管道等特殊文件略去并计数；路径开头的 `./` 与 `/` 去掉，含 `..` 段的路径略去。

启动盘用 `--林根 盘内目录=林根目录` 读林根目录：目录建成盘内目录，普通文件带上模式，符号链接照原目标写成 ext4 的符号链接（短于 60 字节的存进节点）。

后续版本的事项：被上层覆盖或删去的文件内容不写出、硬链接共用节点、设备文件、目录模式与属主。
