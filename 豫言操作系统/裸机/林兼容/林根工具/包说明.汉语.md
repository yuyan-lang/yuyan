# 林根工具

林根工具（提案 00012）把林纳克斯根文件系统的档案解成“林根目录”，供启动盘把整棵林根造进数据盘。

用法：`yy林根 解包 林根目录 档案…`。档案是 tar，可以经 gzip、xz 或 zstd 压缩（按开头的魔数识别），也可以是 RPM 包（取出压缩过的 cpio 负载，按 newc 格式读）或 deb 包（ar 档里名字以 data.tar 开头的成员，解压后按 tar 读）；给多个档案时按次序叠加，同 Docker 镜像的层：后面的档案是上一层，同一路径取最上层的项，`.wh.名字` 删去下面各层的同名项（连同它下面的路径），`.wh..wh..opq` 删去下面各层在这个目录里的全部内容。

林根目录里有两样东西：

- `内容/序号`：每个普通文件的内容，按出现次序编号（0、1、2……）。宿主的文件系统可能不分大小写、不许建设备文件，所以内容只按序号存放。
- `清单`：每项一行，字段以制表符分隔：种（`目`、`文`、`链`）、模式（十进制的权限位，含 setuid 等）、路径（不带开头的斜杠）、附（`文` 为内容序号，`链` 为链接目标，`目` 为空）。

档案里的硬链接写成指向同一内容序号的 `文`；设备文件、命名管道等特殊文件略去并计数；路径开头的 `./` 与 `/` 去掉，含 `..` 段的路径略去。

启动盘用 `--林根 盘内目录=林根目录` 读林根目录：目录建成盘内目录，普通文件带上模式，符号链接照原目标写成 ext4 的符号链接（短于 60 字节的存进节点）。

后续版本的事项：被上层覆盖或删去的文件内容不写出、硬链接共用节点、设备文件、目录模式与属主。
