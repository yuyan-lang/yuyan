# 独立外编译模块之验

以独立 Clang 编 C 夹具成标准模块，非豫言手造其函数体。由标准导入“平台／核验”通计算结果，导出“启动”与内存。程序行栈数组循环、公约数、移位合值及持久变量更新，正例四核皆合，误期望版必须败。

实得模块有未初置、未导出之函数表，亦导出内存。外部模块层保留其声明，验表界、导出重名及内存号；规范化复出，表与导出仍存。元素段、表令、间接调用、表导出及全局导入导出尚拒，不默弃未知段。

二〇二六年九月二十二日，原生与同源码网页参考执行皆过双实例与负例；原始及规范化模块经 V8，各四核皆合，内存仍二页。双架构裸机正负皆过，合旧验共一百一十项。完整驱动之产物在 `/tmp/yy裸机验证.LgvrTT`。

外编译器为 Clang `23.1.0-wasi-sdk`，提交号、宿主路径及复验诸令详汉语篇。其用仅造外来试件，豫言后端直成客体机器码，客体不链 libc。夹具为 C，核心、机器编码及验证驱动仍为豫言。

此验仅及所试模块与已具之指令、模块形式，未能谓任意外来程序皆可行。裸机今由宿主预读而成码，客体动态装载与用户解释器尚未验成。调度、文件系统、用户默认壳、完整垃圾回收及故障任务独退亦待之。

补验非法内存号、误表界与重名导出，原生与网页皆拒。命令装配执行亦过。两途成像皆逐字同于模拟器所验，诸证见 `验证记录.json` 之“独立C模块扩展验证”。
