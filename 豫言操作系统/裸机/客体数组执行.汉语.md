# 客体数组指令执行

用户态客体执行器现支持标准 WasmGC 中纯 `i32` 元素数组的 `array.new`、`array.get`、`array.set`，长度上限为 32。类型索引保存元素可变性；静态验栈要求精确的数组类型引用，`array.set` 还要求元素可变。运行时通过受检对象堆分配数组，读取和写入均核对活句柄、类型号和下标边界。

数组对象堆沿用 `[393216,524288)`；客体声明自己的线性内存且含这些数组指令时，执行入口在产生副作用前拒绝该模块。模块重新装载时重置堆初始化标志。分配失败时会扫描活动值栈和局部帧中的活句柄，标记清扫后重试；其范围与限制见《客体自动根回收》。`array.len` 的后续实现见《客体数组长度执行》。其他元素类型和局部变量中的具体引用类型尚未实现。

标准有效的独立 WasmGC 模块执行 `array.new → array.get` 得到 42；另一模块执行 `array.new → array.set`，并在客体对象堆中留下值 42。越界 `array.get` 的标准有效模块返回受控陷阱；把整数当数组引用的标准无效模块在客体静态验栈被拒绝。上述模块分别与标准引擎的验证或运行结果核对。ARM64、AMD64 QEMU 连同既有场景共 368 项全过，产物与日志在 `/tmp/yy裸机验证.2uJxYR`；三级自举产物一致，编译器入口类型检查通过。
