# 客体对象堆之始

常语最小 WasmGC 模块已需结构数组；独有 `i31` 之码，不足行之。今置可迁之用户态对象堆分配法，俟接 `struct.new`、`array.new` 与自回收。调用者授基址与长，初置先验八字齐、最小容及**实际 Wasm 线性内存**之上界，复于堆首记游标与终。无恒定物理址，后迁栈增容可易其域。

每物首十六字：型号、四字节槽数、标记、引用槽位图。载荷八字齐，分配则清零；引用取载荷址，乃非零偶数，与奇数 `i31`、零空引有别。今限一物至多三十二四字节槽；先验游标、终界及实存之容，容竭返零而游标不迁。此限出于今之位图，非 WasmGC 规范之限。

柄须正指活物载荷之首。标记者略空引与奇数小整，先记物，继循首中引用位以追其子，故环图可止；整数槽虽值似物址，亦不留其物。扫者释未记之物，清活物之记，重建自由链。分配先取等容自由块，重署其首并清载荷；异容块尚不拆并。图深逾今一百二十八层之限则报错，标记败后不得清扫。

《客体堆测试》生标准有效 Wasm 模块，豫言解释器与 Node 皆验界限、环图、断边回收、旧柄失效、精确位图及等容复用。同组件已入裸机用户态验收主程序；后生产客体解释器之纯 `i32` `struct.new`、`struct.get` 一隅，亦接受检分配与核柄。臂六十四、兼容六十四 QEMU 并旧试共三百六十八项皆过，今产物在 `/tmp/yy裸机验证.oD3tvN`。然**回收之根犹由验具明授**，生产解释器未遍追值栈、局部、全局、表与平台暂存诸根，容竭亦不自扫。故不得谓数组或完备自回收已行。增内存时须并迁两栈与任务复制之域。
