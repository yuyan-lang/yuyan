# 顺序指令验型

自完整模块读取之果，循函数指令界验类型栈。今受不可达、空令、返回、弃值、四数型常量、局部读写暂存、直调、空引用与判空。余令明拒，不因界合而赦。

宽整常量验长度与末位，不截为窄整；浮点依字节数读，此时唯验型，不解数值。直调依全签名验参果。非空参数初已定，非空局部先赋乃读，不可达亦守之。返回先验果后断流，终结不得余实值。

十八完整标准模块试皆成，与 Node 分类同。含溢出、过长、错果、错参、未赋与断流后实型之错。日志存 `/tmp/yy顺序指令检查日志`、`/tmp/yy顺序指令构建日志`、`/tmp/yy顺序指令运行日志`。

结构控制、算术、回收对象、异常、尾调及全局表内存尚待，未可验普通豫言全程序。余段未全验，不授整模块执行权，未接裸机，默认镜像不变。
