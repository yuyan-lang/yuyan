# 控制台字模生成

这是在构建时用豫言的「字体」库生成灰度字模的库（2026-10-07 起不再用 FreeType，宿主与豫言操作系统里都能运行）。默认 Noto Sans Mono CJK SC Regular，另生成思源黑体 Regular，版本与校验值见《中文支持》。完整许可在 `字体/Noto许可证.txt`、`字体/思源许可证.txt`，须随字体与字模分发。文楷原体仍保留，默认字体已改为 Noto。

栅格化不做微调，字形按整像素定位（见「字体」库的 `栅格化`）。裸机只读点阵。生成物名为“豫言控制台字模”，保留上游来源声明。

用法：`寻观「控制台字模生成」之「字模」之书。` 后调用 `「生成控制台字模们」于「元」`（拼音字库与 Noto 字模），路径都相对仓库根目录。豫言系统的「启动盘」在构建壳之前调用它。对照字形用的思源字模另由 `「生成思源字模」于「元」` 生成，启动盘不用。

先将规范汉字拼音转换为 `库/壳核心/yy拼音字库。豫`。字集收集默认壳、生成字库、输入法源码与预览中的完整 Unicode 字符，另含可打印 ASCII 与替代字符。字号二十四像素、行高三十二像素，ASCII 宽十二，其他字宽二十四。输出 Noto 的 `yy控制台字模.bin` 与 `yy中文字体预览.ppm`（另可生成思源的 `yy思源控制台字模.bin`）。字模头十六字节为四个小端整数：标记、字形数、半宽、行高；每项七百七十六字节为码点、宽度及二十四乘三十二灰度像素。缺字时报错，像素越格则裁去。待办事项：任意文件字集、长行预览。
