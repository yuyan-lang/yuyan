# 控制台字模生成

此器以豫言系统库调用，于构时调 FreeType 而生灰度字模。默认 Noto Sans Mono CJK SC Regular，兼生思源黑体 Regular，版本与校验见《中文支持》。许可全辞在 `字体/Noto许可证.txt`、`字体/思源许可证.txt`，须随原体与字模同发。文楷原体仍存，默认已易 Noto。

构机须具 FreeType：macOS 今取 `/opt/homebrew/lib/libfreetype.dylib`，Linux 取 `libfreetype.so.6`。裸机惟读点阵，无须 FreeType。今依公开 LP64 结构取位，Windows LLP64 之支持待办。生成物曰“豫言控制台字模”，仍记原体之源。

构之：`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 控制台字模生成 --输出 yy控制台字模生成.wasm -j 24`。行之：`node 豫言操作系统/宿主/节点/宿主.cjs yy控制台字模生成.wasm`。

先转规范汉字之拼音为 `壳/yy拼音字库。豫`。字集取默认壳、所生字库、输入法源及预览中完整 Unicode 之字，兼可印 ASCII 与替代字。字号二十四像素，行高三十二；ASCII 宽十二，余字宽二十四。出 Noto 之 `yy控制台字模.bin`、思源之 `yy思源控制台字模.bin` 与 Noto 之 `yy中文字体预览.ppm`。头十六字节为四小端整数：标记、形数、半宽、行高；每项七百七十六字节，为码点、宽度及二十四乘三十二灰度像素。缺字则报，像素越格则裁之。待办事项：任意文件之字集、长行预览及构程将退前释 FreeType 字面。
