# 控制台字模生成

此库于构时以豫言之「字体」库生灰度字模（二〇二六年十月七日起不复用 FreeType，宿主与豫言操作系统中皆可行）。默认 Noto Sans Mono CJK SC Regular，兼生思源黑体 Regular，版本与校验见《中文支持》。许可全辞在 `字体/Noto许可证.txt`、`字体/思源许可证.txt`，须随原体与字模同发。文楷原体仍存，默认已易 Noto。

栅格不微调，字形依整像素而定（见「字体」库之 `栅格化`）。裸机惟读点阵。生成物曰“豫言控制台字模”，仍记原体之源。

用之：`寻观「控制台字模生成」之「字模」之书。` 乃呼 `「生成控制台字模们」于「元」`（拼音字库与 Noto 之字模），诸路皆对仓根。豫言系统之「启动盘」于构壳之前呼之。对照所用思源之字模，另以 `「生成思源字模」于「元」` 生之，启盘不用。

先转规范汉字之拼音为 `库/壳核心/yy拼音字库。豫`。字集取默认壳、所生字库、输入法源及预览中完整 Unicode 之字，兼可印 ASCII 与替代字。字号二十四像素，行高三十二；ASCII 宽十二，余字宽二十四。出 Noto 之 `yy控制台字模.bin` 与 `yy中文字体预览.ppm`（亦可生思源之 `yy思源控制台字模.bin`）。头十六字节为四小端整数：标记、形数、半宽、行高；每项七百七十六字节，为码点、宽度及二十四乘三十二灰度像素。缺字则报，像素越格则裁之。待办事项：任意文件之字集、长行预览。
