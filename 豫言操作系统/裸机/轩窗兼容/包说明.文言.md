# 轩窗兼容

轩窗兼容之层，于豫言操作系统原样行轩窗之程，与林兼容同为蕃坊之蕃长。

- 兼容之层以底层豫言书之，编为静态之豫行：`「构建」于「包」曰『轩窗兼容』于「输出」曰『轩窗兼容。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】`。
- 行之：`「行」于『/轩窗/轩窗兼容。豫行』于「列」【[『--根』，『轩窗根目录』，][『--跟踪』，]『程序路径』，『参数』…】`。既置轩窗之坊，「行」一 PE 可执行之文，蕃坊即付本层。`--跟踪` 每呼接口书一行。
- 装：尽读 PE32+ 之文，核 DOS 之首、PE 之签、可选之首与机器之号；像置于线性之偏四吉，逐节拷之，须则依重定位之表改之；像后排栈、线程之块与进程之块、堆。
- 呼接口经蕃门：导入之表每项各指一门，门居虚址二之三十九次方，其处无所映；客一呼即取指而误，归于兼容之层，层以址求门序，查表得号而办之，书果于首寄，返其呼处。兼容之层不生机器之码。
- 所识之接口（kernel32.dll）：退出进程、分配虚存、添异常之处、取标准之柄、书文、读文、取设末误、关柄、取进程线程之号、取模块之柄。标准入、出、误之柄为四、八、十二；书文逐字付内核之写字节，读文逐字取控台之入，遇换行或文尾而止。呼不识之接口则书“DLL!函数名”而以百二十七终。
- 线性内存之布：全局之格居百二十八千之上，避执行器实例之格与零号核块；底层请块之址书于零号核块之请块格；受限之状区居六十四千；蕃门之表居一至二兆；启动之块居六十四至八十兆；读缓居二百五十六兆之上；轩窗程之像、栈、线程之块与堆居四吉之上。
- 受限之异：程计适在蕃门者为呼接口；断则续行；余异书其向量、误码、故址与程计，以访问违例终。

后版之事：

- 命令行与环境之块。
- 文件、目录、时间、堆与线程本地之存等常用接口；接口集之名之映。
- 线程、结构化之异与向量化异常处理之投。
- AMD64 程之线程块（gs 之基）与裸机 AMD64 之验。
- 用户之界（user32、gdi32）经显示代办接于豫言之桌面。
