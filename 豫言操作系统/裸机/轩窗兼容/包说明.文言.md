# 轩窗兼容

轩窗兼容之层，于豫言操作系统原样行轩窗之程，与林兼容同为蕃坊之蕃长。

- 兼容之层以底层豫言书之，编为静态之豫行：`「构建」于「包」曰『轩窗兼容』于「输出」曰『轩窗兼容。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】`。
- 行之：`「行」于『/轩窗/轩窗兼容。豫行』于「列」【[『--根』，『轩窗根目录』，][『--跟踪』，][『--兼译』，『译码目录』，[『--兼译服』，『端口』，][『--兼级』，『2』，]]『程序路径』，『参数』…】`。既置轩窗之坊，「行」一 PE 可执行之文，蕃坊即付本层。`--跟踪` 每呼接口书一行。
- 装：尽读 PE32+ 之文，核 DOS 之首、PE 之签、可选之首与机器之号；像置于线性之偏四吉，逐节拷之，须则依重定位之表改之；像后排栈、进程之区（一兆）与堆。
- 兼译：以 `--兼译 译码目录` 起，程与库为兼之 PE，于臂上行象胥所译之码：码依文之散与长名之，「行」时蕃坊自备其程与程目所引之库之码（亦可先于壳中「传译」之）。整译（十一月二十七日）：加 `--兼译服 口`（蕃坊自备而加之），装无码之 PE 则奉其径于象胥服，彼全译之入藏而还其码之径，此读而登之（兼译篇之兼整译；请之布在兼核之即约，收发在即客之篇）；异常之报书整译成败之数。装节、改址、解引如常，依散寻码，置码与表于堆，登于兼模之册（兼核之册，与林兼容共之）。参与返依兼之约，寄号同象胥之映；间接之转与返经 SVC #0x87 归此层：标为门则办接口，否则查册改程计与 x23；处理器识别与时戳经 SVC #0x88、#0x89 答之；x87、串比、位散聚与 XSAVE 经 SVC #0x8A 至 #0x8F 付兼核之浮办、串比与宽办，与林兼容同。线程之指为线程块，x24 指 ymm 之高半。问特性、取系统之信与共页之特性皆依兼答之。
- 模：程与所载之库皆籍于模表。依名寻库：先寻已载，次读程目同名之文，得则映于堆游而改其址；不得则为系统之库，籍为伪模，所引之函皆登蕃门。真像依导出之表求函，转发者依“库.函”再求。有线程本地存储之目录者，分序依模板分块，书其址于线程块所指之数组。
- 回调：进程初起，依所依之序先行诸库之回调与主函，次行程之回调，乃入其口；载库、一次之执亦然。不递归于本栈，排待调之列，压帧存状，函返叩回调之门则续其次，毕则弹帧书果。
- 仿：零级读当前级与识别之寄答零；读共页之数依模取之。
- 进程之区：线程块（栈界、自指、进程线程之号、进程块、末误、线程本地存储之槽与扩槽）、进程块（像基、进程参块、进程堆、处理器之数、系统之版）、进程参块（标准之柄、当前目录、像路、命令行、环境），及宽窄命令行、宽窄像路、宽当前目录、宽环境。命令行首项为像路，余参依 MSVC 之规加引号；环境取诸启块之环区；当前目录取诸启块之所居。
- 径：C 盘当轩窗之根（无根则当豫言之根），Z 盘恒当豫言之根，惟此二盘；反斜与斜皆为分，去“\\?\”之首，点与双点由此层规之，相对之径自当前目录始；CONOUT$、CONIN$、NUL 为器。
- 代码页：ANSI、OEM 与控台之页皆为八位同文，与豫言同；他页依拉丁一逐字对之。
- 址与结构：此层之址有二：客所见之虚址曰客址，此层之线偏曰本址。「址型」以签名藏之为二抽象之类，惟经窗址、窗虚互易，读写之原语惟受本址；寄存与客存之裸值于边界一易为客址，布局之常与静串之址经数作本址而易。PE 之诸首、节表、导入之描、导出与线程本地存储之录，线程块、进程块、进程参块与统串，皆书为「结构」之具名布局；柄表之项、模表之项、回调之帧与待调之项、门表之项、堆块之首、共页之模，及客所予之出参诸结构，亦皆书为具名之布局，按名取栏。
- 呼接口经蕃门：导入之表每项各指一门，门居虚址二之三十九次方，其处无所映；客一呼即取指而误，归于兼容之层，层以址求门序，查表得号而办之，书果于首寄，返其呼处。兼容之层惟解门号，程之机器之码原样而行。
- 所识之 DLL：kernel32、kernelbase、api-ms-win-core- 诸接口集（皆映于 kernel32 之名）、shlwapi、ntdll 与 bcryptprimitives。所识之接口登于接口表（每接口立一构，名与办皆依构鉴尽），凡二百三十六，分为进程与模块、环境与误、内存、线程本地存储与同步、文件与控台、时、本地化与径、版本与系统之信、杂项诸类；详见汉语之稿。呼不识之接口则书“DLL!函数名”而以百二十七终。
- 线性内存之布：十六千以下为执行器实例之约，此层之数皆置其上；数据之区十六至六十四千；受限之状区居六十四千；全局之格居百二十八千之上；柄表、纤存之表、私之当前目录居百四十四至二百千；底层请块之址书于零号核块之请块格；蕃门之表居一至二兆；易文之暂存居二至三兆；模表、名池、回调之帧、待调之列、程目、依边、号门、共页之模与兼译之册、码径、码目、ymm 之高半居三至四兆；启动之块居六十四至八十兆；读缓居二百五十六兆之上；轩窗程之像、栈、进程之区与堆居四吉之上。
- 受限之异：程计适在蕃门者为呼接口；断则续行；余异书其向量、误码、故址与程计，以访问违例终。
- 验：MSVC 静连之 distlib 启动器行毕其 C 运行库之启，开而读其己文，书“Fatal error in launcher: Unable to find an appended archive.”，以码一终；其末续以 shebang 之行与 zip 之尾，则析其 shebang，拼带引号之命令行，呼建进程而得“不支”；原生你好之轩窗入口与轩窗文件入口各验控台之读书与文之建、书、读、删。兼译：同启动器之 x64 版经象胥之码行之，二果皆同；手拼之 x86-64 控台之像书二行而以零终。谷歌浏览器视窗臂六十四之版：载 chrome_elf，行其回调与主函，入 wWinMain，chrome_elf 初其分区之配，呼接口千七百余次，止于延载 ADVAPI32 之 InitializeAcl。

- 线程、子进程、结构化之异与向量化异常处理之投，纤存之回调。
- 目录之列、移文、取柄之信诸文件接口；设环境之变而改其块。
- AMD64 程之线程块（gs 之基）与裸机 AMD64 之验。
- 兼译：查表不得之片段即译（林兼容有之，此层未接）与程自生之码、多线、码节中为 DIR64 所改之 imm64、兼之结构化异常之展。
- 用户之界（user32、gdi32）经显示代办接于豫言之桌面。
