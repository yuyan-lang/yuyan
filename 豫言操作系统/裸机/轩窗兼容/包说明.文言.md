# 轩窗兼容

轩窗兼容之层，于豫言操作系统原样行轩窗之程，与林兼容同为蕃坊之蕃长。

- 兼容之层以底层豫言书之，编为静态之豫行：`「构建」于「包」曰『轩窗兼容』于「输出」曰『轩窗兼容。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】`。
- 行之：`「行」于『/轩窗/轩窗兼容。豫行』于「列」【[『--根』，『轩窗根目录』，][『--跟踪』，]『程序路径』，『参数』…】`。既置轩窗之坊，「行」一 PE 可执行之文，蕃坊即付本层。`--跟踪` 每呼接口书一行。
- 装：尽读 PE32+ 之文，核 DOS 之首、PE 之签、可选之首与机器之号；像置于线性之偏四吉，逐节拷之，须则依重定位之表改之；像后排栈、进程之区（一兆）与堆。
- 进程之区：线程块（栈界、自指、进程线程之号、进程块、末误、线程本地存储之槽与扩槽）、进程块（像基、进程参块、进程堆、处理器之数、系统之版）、进程参块（标准之柄、当前目录、像路、命令行、环境），及宽窄命令行、宽窄像路、宽当前目录、宽环境。命令行首项为像路，余参依 MSVC 之规加引号；环境取诸启块之环区；当前目录取诸启块之所居。
- 径：C 盘当轩窗之根（无根则当豫言之根），Z 盘恒当豫言之根，惟此二盘；反斜与斜皆为分，去“\\?\”之首，点与双点由此层规之，相对之径自当前目录始；CONOUT$、CONIN$、NUL 为器。
- 代码页：ANSI、OEM 与控台之页皆为八位同文，与豫言同；他页依拉丁一逐字对之。
- 呼接口经蕃门：导入之表每项各指一门，门居虚址二之三十九次方，其处无所映；客一呼即取指而误，归于兼容之层，层以址求门序，查表得号而办之，书果于首寄，返其呼处。兼容之层惟解门号，程之机器之码原样而行。
- 所识之 DLL：kernel32、kernelbase、api-ms-win-core- 诸接口集（皆映于 kernel32 之名）与 shlwapi。所识之接口登于接口表（每接口立一构，名与办皆依构鉴尽），凡百四十，分为进程与模块、环境与误、内存、线程本地存储与同步、文件与控台、时、本地化与径诸类；详见汉语之稿。呼不识之接口则书“DLL!函数名”而以百二十七终。
- 线性内存之布：十六千以下为执行器实例之约，此层之数皆置其上；数据之区十六至六十四千；受限之状区居六十四千；全局之格居百二十八千之上；柄表、纤存之表、私之当前目录居百四十四至二百千；底层请块之址书于零号核块之请块格；蕃门之表居一至二兆；易文之暂存居二至三兆；启动之块居六十四至八十兆；读缓居二百五十六兆之上；轩窗程之像、栈、进程之区与堆居四吉之上。
- 受限之异：程计适在蕃门者为呼接口；断则续行；余异书其向量、误码、故址与程计，以访问违例终。
- 验：MSVC 静连之 distlib 启动器行毕其 C 运行库之启，开而读其己文，书“Fatal error in launcher: Unable to find an appended archive.”，以码一终；其末续以 shebang 之行与 zip 之尾，则析其 shebang，拼带引号之命令行，呼建进程而得“不支”；原生你好之轩窗入口与轩窗文件入口各验控台之读书与文之建、书、读、删。

后版之事：

- C 运行库之动态库（ucrtbase、api-ms-win-crt-*、vcruntime140）：动态连 C 运行库之程，须此层自实其函。
- 线程、子进程、结构化之异与向量化异常处理之投，纤存之回调，线程本地存储之目录与回调。
- 目录之列、移文、取柄之信诸文件接口；设环境之变而改其块。
- AMD64 程之线程块（gs 之基）与裸机 AMD64 之验。
- 用户之界（user32、gdi32）经显示代办接于豫言之桌面。
