# 轩窗兼容

轩窗兼容之层，于豫言操作系统原样行轩窗之程，与林兼容同为蕃坊之蕃长。

- 兼容之层以底层豫言书之，编为静态之豫行：`「构建」于「包」曰『轩窗兼容』于「输出」曰『轩窗兼容。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】`。
- 行之：`「行」于『/轩窗/轩窗兼容。豫行』于「列」【[『--根』，『轩窗根目录』，][『--跟踪』，][『--兼译』，『译码目录』，[『--兼译服』，『端口』，][『--兼级』，『2』，]]『程序路径』，『参数』…】`。既置轩窗之坊，「行」一 PE 可执行之文，蕃坊即付本层。`--跟踪` 每呼接口书一行。
- 装：尽读 PE32+ 之文，核 DOS 之首、PE 之签、可选之首与机器之号；像置于线性之偏四吉，逐节拷之，须则依重定位之表改之；像后排栈、进程之区（一兆）与堆。
- 兼译：以 `--兼译 译码目录` 起，程与库为兼之 PE，于臂上行象胥所译之码：码依文之散与长名之，「行」时蕃坊自备其程与程目所引之库之码（亦可先于壳中「传译」之）。整译（十一月二十七日）：加 `--兼译服 口`（蕃坊自备而加之），装无码之 PE 则奉其径于象胥服，彼全译之入藏而还其码之径，此读而登之（兼译篇之兼整译；请之布在兼核之即约，收发在即客之篇）；异常之报书整译成败之数。片段即译（十一月二十七日）：间转或返之标查册不得，落某模则以其基、落堆中则以堆首为基（客 VirtualAlloc 而自生之码；此层之虚存皆自堆游分之），奉标前后各至多百二十八千之码于象胥服即译之，登所受之片于兼模之册（兼核之片位记之），复以受限护页（务四百二十一）设其源窗为零级只读；客改之则撞权故，兼写护故废其页上之片、开其写而重为之，后入则重译。异常之报书所护、所开与护败之数。装节、改址、解引如常，依散寻码，置码与表于堆，登于兼模之册（兼核之册，与林兼容共之）。参与返依兼之约，寄号同象胥之映；间接之转与返先寻 x25 所指之查缓，得则径往；不得乃经 SVC #0x90（旧码 #0x87）归此层：标为门则办接口（门不入缓），否则查册改程计与 x23，复依 x17 书于缓（册有废条则尽清之；异常之报书填、清、误之数）；处理器识别与时戳经 SVC #0x88、#0x89 答之；x87、串比、位散聚与 XSAVE 经 SVC #0x8A 至 #0x8F 付兼核之浮办、串比与宽办，与林兼容同。线程之指为线程块，x24 指 ymm 之高半，x25 指查缓。问特性、取系统之信与共页之特性皆依兼答之。
- 模：程与所载之库皆籍于模表。依名寻库：先寻已载，次读程目同名之文，得则映于堆游而改其址；不得则为系统之库，籍为伪模，所引之函皆登蕃门。真像依导出之表求函，转发者依“库.函”再求。有线程本地存储之目录者，分序依模板分块，书其址于线程块所指之数组。
- 回调：进程初起，依所依之序先行诸库之回调与主函，次行程之回调，乃入其口；载库、一次之执亦然。不递归于本栈，排待调之列，压帧存状，函返叩回调之门则续其次，毕则弹帧书果。
- 仿：零级读当前级与识别之寄答零；读共页之数依模取之。
- 进程之区：线程块（栈界、自指、进程线程之号、进程块、末误、线程本地存储之槽与扩槽）、进程块（像基、进程参块、进程堆、处理器之数、系统之版）、进程参块（标准之柄、当前目录、像路、命令行、环境），及宽窄命令行、宽窄像路、宽当前目录、宽环境。命令行首项为像路，余参依 MSVC 之规加引号；环境取诸启块之环区；当前目录取诸启块之所居。
- 径：C 盘当轩窗之根（无根则当豫言之根），Z 盘恒当豫言之根，惟此二盘；反斜与斜皆为分，去“\\?\”之首，点与双点由此层规之，相对之径自当前目录始；CONOUT$、CONIN$、NUL 为器。
- 代码页：ANSI、OEM 与控台之页皆为八位同文，与豫言同；他页依拉丁一逐字对之。
- 址与结构：此层之址有二：客所见之虚址曰客址，此层之线偏曰本址。「址型」以签名藏之为二抽象之类，惟经窗址、窗虚互易，读写之原语惟受本址；寄存与客存之裸值于边界一易为客址，布局之常与静串之址经数作本址而易。PE 之诸首、节表、导入之描、导出与线程本地存储之录，线程块、进程块、进程参块与统串，皆书为「结构」之具名布局；柄表之项、模表之项、回调之帧与待调之项、门表之项、堆块之首、共页之模，及客所予之出参诸结构，亦皆书为具名之布局，按名取栏。
- 呼接口经蕃门：导入之表每项各指一门，门居虚址二之三十九次方，其处无所映；客一呼即取指而误，归于兼容之层，层以址求门序，查表得号而办之，书果于首寄，返其呼处。兼容之层惟解门号，程之机器之码原样而行。
- 所识之 DLL：kernel32、kernelbase、api-ms-win-core- 诸接口集（皆映于 kernel32 之名）、shlwapi、ntdll 与 bcryptprimitives，及 C 运行库之 ucrtbase、api-ms-win-crt- 诸接口集、msvcrt 与 vcruntime140。所识之接口登于接口表（每接口立一构，名与办皆依构鉴尽），凡四百八十三，分为进程与模块、环境与误、内存、线程本地存储与同步、文件与控台、时、本地化与径、版本与系统之信、杂项诸类；详见汉语之稿。呼不识之接口则书“DLL!函数名”而以百二十七终。
- 线性内存之布：十六千以下为执行器实例之约，此层之数皆置其上；数据之区十六至六十四千；受限之状区居六十四千；全局之格居百二十八千之上；柄表、纤存之表、私之当前目录居百四十四至二百千；底层请块之址书于零号核块之请块格；蕃门之表居一至二兆；易文之暂存居二至三兆；模表、名池、回调之帧、待调之列、程目、依边、号门、共页之模、C 运行库之态与暂与兼译之册、码径、码目、ymm 之高半居三至四兆；启动之块居六十四至八十兆；读缓居二百五十六兆之上；轩窗程之像、栈、进程之区与堆居四吉之上。
- 受限之异：程计适在蕃门者为呼接口；断则续行；余异书其向量、误码、故址与程计，以访问违例终。
- C 运行库（运行库、格式、运行库文件、运行库跳、运行库浮转、运行库时间、运行库杂项、运行库数学八篇，十一月二十八日）：mingw 与 MSVC 所编之 C 程所动连之 UCRT 一隅，百六十四函：启动之参列（依轩窗之规切之）、初项（经回调逐一行之）、终表与收尾、退出；堆之分释；串与内存之术；标准之三流与 printf 之族（整、字、串、指、浮皆依 UCRT 之样；浮以大数精化为十进之位，五成双而舍；snprintf 依选项截之）。文流之表六十四项：开、读、行、字、退字、定位、关、改名、删、临文，误则书 errno。设跳与远跳依兼臂之 jmp_buf 存复其寄。串转浮识十进、十六进、无穷与非数，位少者以双精直算，多者以扩精乘除十幂而舍。时：取时、钟、世时地时、合时、差时、式时（地时依协调世时）。杂：字类、串与宽串、串转整（轩窗之 long 三十二位）、区域（惟 C）、宽窄之易、取环境、FormatMessageA。数学二十七函，中以兼核六十四位之扩精算之，终舍为双精；双精之参与返经状态之浮参位、浮返位。态居库态之区与其后诸篇之暂。验：兼译 mingw 之 x64 程，hello 书其参而以三终；printf 之对照百余式、文流之对照与 glibc 原生逐字同；lua 五点四点七之 x64 版行四十九行之综合之本，与原生之 lua 逐行同，惟 os.date 之 %c 依 UCRT 之样异。
- 同步之物（同步篇，十一月二十八日）：事件、互斥、信号量记其状于柄表，候之则依状而答，候不得则答超时。
- 结构化之异（异常展、异常派二篇，十一月二十八日，x64 之程）：查函项于异常之目，依 UNWIND_INFO 虚展其帧；抛则逐帧而派，有处者借回调行之，续则依原境，尽则交滤；展回逐帧而展，至目帧则易其返值与程计。派展皆可续，层记于六兆之异区；处中再抛再展则别开一位，至外位之返门，外为派则自其原境续之，外为展则接其所办之帧。展毕而撤诸位。着陆之处与处者多惟见于数据，故设程而无码者先即译之。验：mingw g++ 所编之 x64 程，静连与动连二版，四层之析构与五次之接皆如 C++ 之义。
- 兼译之时程计当设于蕃门者，设客程照设其门址，再入则取指而误，运行之环依门办之。
- 验：MSVC 静连之 distlib 启动器行毕其 C 运行库之启，开而读其己文，书“Fatal error in launcher: Unable to find an appended archive.”，以码一终；其末续以 shebang 之行与 zip 之尾，则析其 shebang，拼带引号之命令行，呼建进程而得“不支”；原生你好之轩窗入口与轩窗文件入口各验控台之读书与文之建、书、读、删。兼译：同启动器之 x64 版经象胥之码行之，二果皆同；手拼之 x86-64 控台之像书二行而以零终。谷歌浏览器视窗臂六十四之版：载 chrome_elf，行其回调与主函，入 wWinMain，chrome_elf 初其分区之配，呼接口千七百余次，止于延载 ADVAPI32 之 InitializeAcl。
