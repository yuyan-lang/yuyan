# 引用测试、转换和相等验证

新增 ref.test、ref.test_null、ref.cast、ref.cast_null 的完整类型检查。先验证目标堆类型，再按该类型所属层次的可空顶类型检查输入；聚合、函数、外部和异常四类不能跨层次混用。同层次中的不同结构或数组类别仍可测试，不能只因静态类型不同就拒绝，因为运行时结果可以为假或陷阱。

测试产生 i32，转换产生声明的目标引用类型，可空标记不会丢失。ref.as_non_null 保留原堆类型并去除可空性，不可达未知值仍保持未知。ref.eq 只接受可空 eq 子类型，不能直接比较通用 any、函数或外部引用。

20 个完整标准模块与 Node 分类一致，豫言验证器测试通过；20 个数组回归通过。覆盖非空转换后局部赋值、可空引用不能冒充非空、不可达未知值、跨类别拒绝及相等操作限制。类型检查、构建和运行日志为 `/tmp/yy引用转换检查日志`、`/tmp/yy引用转换构建日志`、`/tmp/yy引用转换运行日志`、`/tmp/yy引用数组回归运行日志`。

本次不执行动态转换，不证明运行时对象身份、转换陷阱或 GC 回收已经实现。外部引用与聚合的显式转换、转换分支以及完整实例资源验证仍待，默认裸机镜像不变。
