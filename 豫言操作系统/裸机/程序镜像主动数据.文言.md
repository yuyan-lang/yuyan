# 程序镜像主动数据

昔播种之验具，以待入盘之每字化为写内存诸令。三千一百八十六字之豫言模块，令臂六十四用户代码长一百三十五万一千六百六十字，越可用之一百零四万八千五百七十二字，未及启机。此乃验具代码滋蔓，非盘与模块之限。

今以 Wasm 主动数据段载其字。镜像构造已有主动段初置之法，置字于用户线性内存；命令壳仍循文件接口写盘、读盘。省逐字写令，则程序字数不复等比增机器令。

以外来 C Wasm 行双架构 QEMU 验收，三百六十八项悉过，日志在 `/tmp/yy裸机验证.Jr5w13`。以三千一百八十六字之普通豫言模块试之，镜像成而机启，壳见 `/外部.wasm`；运行则报“程序读取失败，代码 -2”，不复报镜像越界。其故在客体执行器未解 `eqref` 与 `struct`，未可称普通豫言既能运行。串口日志在 `/tmp/yy裸机验证.zRvscx/臂六十四-壳程序运行.日志`。

裁类型段而试：唯 `i32` 返回之单类型可过装载；同形之 `eqref` 则拒。最小豫言模块前十七函数类型改为 `i32` 而可过，后继 `struct` 犹拒。故当立辨型之 GC 复合类型表、宽而有记之值槽、可追根之堆；不可混 `eqref` 为 `funcref`。
