# 客体导入、导出与启动

后续：命令壳载行已成，见[命令壳程序运行](命令壳程序运行.文言.md)；间接调用之子集与元素段未竟之事，见[客体间接调用](客体间接调用.文言.md)。下存本阶段所验。

今可按导出名寻函数，连豫言平台之定函数，首次调用前行模块启动。名字与签名皆核，诸绑定尽成乃行。循标准网页汇编导入导出之制，不改模块二进制与公共调用约定。

平台今授三术：“写字节”取一整数而无返，写其低八位；“核验”取二整数而无返，不等则客体陷阱；“用户态”无参返一整数，实问平台权限。名字逐字合，参数返回数皆须合。未知或签名不符返负二，后项未连不得先行前项而生输出。

核验在执行器内比较，不以原生核验陷阱坠其任务。导入取放解释值栈，不以客体整数作原生函数址。任意导入、WASI 与设备接口待续。

查导出取外层名字始址与长，先验域；函数返号，缺返负一，非函数返负二，坏域或未成之目返负三。调用者必察而后行。中文与其余合法名字同用标准导出表。

资源初置为内部准备。运行入口连诸导入，初次请求时先行无参无返之启动，再行所请函数，共用步额。启动成记一，后请不复启动；启动败或步尽记二，不许直接重试导出，须重新初置为新实例，以免悄然重作外部副作用。无启动段亦成其准备记。

导入另扣一步，不能以宿主调用逃限。写字节与核验次数每次尝试重计，仅为试据，非授权之据。

为受常见 C 所生模块，今验默认空函数引用表之声明：至多一表，初始至多一千零二十四，最大不得少于初始。初置皆空引用，导出核实其数。此非间接调用之成；元素、表令、其余表型与标签待续。仅有未用合法空表之整数模块可行。

二九一七六、二九一八零、二九一八四存表数、初始与最大。表域五八三六八至六二四六四，空记负一；导入绑定域六二四六四至六二九七六，各四字节存内部服务号，唯定分派可用。二九一九二记连成，二九一九六记写次数，二九二零零记成功核验数；二九二零四记启动零待、一成、二行中或败。重扫与初置皆废旧记，今仍定域单实例。

十四例验导出导入、写字、核验、错名错型、全连后输出、启动一次、启动互调、败后初置、空表与表号。有效者复与标准引擎比，宿主以真正网页汇编函数供之，免动态参数掩其签名差。

复以独立 C 编译模块之原字入客体，经读、解、验栈、初置、按名寻导出而解释行之，C 以平台核验回调豫言执行器。正例须四验皆成，错例首失即客体陷阱，而承载任务正常终止。

此为标准模块与固定平台之双向调用；独立模块通用互连、命令壳载行、WASI、间接调用、通用实例与完整垃圾收集，皆待续成。
