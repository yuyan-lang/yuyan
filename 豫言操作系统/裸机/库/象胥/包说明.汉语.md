# 象胥

象胥（二进制翻译器）把兼容六十四（x86-64）机器码翻译成臂六十四（ARM64）机器码，让臂六十四的豫言系统原样跑兼容六十四的林纳与轩窗程序。名字取自《周礼·秋官》的象胥：掌管四方使者、传译言语的官。

## 做法

- 装程序时整体翻译：把程序的代码段按控制流解成指令，提升成带类型的操作，由象胥自带的臂六十四编码器直接出机器码，缓存在盘上。译出的码钉住兼容六十四的寄存器、用客体自己的栈，所以不经冶铸（原生后端）的降级。
- 运行时才生成的代码（即时编译器、自修改代码）另走即时翻译，按基本块翻译并缓存。
- 寄存器固定对应：兼容六十四的十六个通用寄存器各占一个臂六十四寄存器。
- 标志位按需计算，臂六十四有 FlagM、FlagM2 扩展时直接用。
- 内存次序：多线程程序的访存用 LDAPR、STLR 保持兼容六十四的强序，单线程程序用普通访存；林檎芯片的硬件强序开关作为可选的加速。
- 向量指令：SSE 译成 NEON；处理器识别（CPUID）报的向量特性到 SSE4.2 为止。
- 翻译后的程序在林兼容与轩窗兼容（蕃坊）里跑，系统调用照原样交兼容层。

## 已有

- **兼式**：兼容六十四指令的带类型表示。寄存器、操作宽、寻址的基与比例、存储元、前缀、拓展前缀、编码种类与码表各有自己的类型；解码失败的缘由是「辨误」（截断、过长、无此令）。
- **码读**：按字节读机器码的游标，记着段首令址；签名把码流、指令起点与读到的位置藏起来，模块外只拿得到字节、令址与指令长度。一条指令读满十五字节报过长，码流读完报截断。
- **令址**：兼容六十四指令虚拟地址的抽象类型，整数只在边界进出。
- **兼辨**：指令解码器。`「辨兼令」于 码读` 得 `「成否」于（「兼令」合「码读」）于「辨误」`。认旧式前缀、拓展前缀（REX）、单字节与二三字节码表、向量扩展（VEX）与广向量扩展（EVEX），解 ModRM、SIB、位移与立即数，算操作宽与长度。
- **流式、兼流**：控制流发现。`「寻块」` 从入口按直接转移与调用找全可达指令，切成基本块：调用与条件转移的下一条也是块首，解不出的地址成空块，转到段外的目标另记。
- **兼作、兼义**：语义提升。`「义于令」` 把整数子集的指令提升成带类型的操作「兼作」，暂不译的带缘由。
- **标集、兼标**：标志活性。`「义图于」` 在流图上求出每条操作之后还要用的标志；调用、间接转移、返回与停按调用约定当标志全死。
- **臂式、臂编**：带类型的臂六十四编码器，抽象的「臂字」只能由编码函数造出；立即数放不进时返回可无。
- **译式、兼译**：直译。`「译图」` 把义图逐块逐条译成臂六十四机器码，交出机器码、各块入口的偏移与没能翻译的指令。约定：通用寄存器按编码号放在 x0 至 x15；标志在 NZCV，块边界上 C 等于进位之反，只算之后要用的；syscall 译成 SVC #0x86；间接转移与返回把目标放进 x16，经 SVC #0x87 请林兼容查表转去。
- **兼程**：整个程序的翻译。`「译精灵」` 析兼容六十四的固定地址静态精灵（程序头、符号表），以入口、函数符号、数据段里指向代码段的指针为根找块，再补上指令里程计相对取址与立即数落在代码段里的根找一遍，逐段直译后首尾相接，写成译码文件：文件头五个八字节（魔数“XIANGXU1”、版本一、入口的译码偏移、码长、入口项数），接着是臂六十四码，再是按地址排好的入口表（兼容六十四地址、译码偏移各八字节）。同时交出段数、码长、入口项数与没能翻译的指令（「兼程译果」）。位置无关与动态链接的程序暂不译。

## 接入林兼容

- 林兼容以 `--兼译 译码文件` 起动时认兼容六十四精灵：各段照常装到原址只当数据，译码与入口表映进林程序的地址空间，程序起点换成入口的译码；SVC #0x86 按兼容六十四的林纳系统调用号办，SVC #0x87 按 x16 在入口表里二分查到译码再接着跑，查不到就当异常报出。
- 蕃坊在臂六十四主机上遇到兼容六十四的林纳程序时，先备好译码（缓存在 `/tmp/象胥译码/`，名字由程序路径散列、大小与修改时间拼成，删了下次重译），再交林兼容加 `--兼译` 运行。
- 壳命令 `「传译」于「路径」曰『程序』` 重新翻译一个程序，印出译码路径、段数、码长、入口项数，以及没能翻译的指令按缘由归并的明细。

## 后续版本

- 跑通静态的 busybox 与 Debian 的 /bin/true；fs 段（线程指针）、处理器识别。
- 八位与十六位操作、带进位的加减、乘除、循环移位、奇偶与辅助进位标志。
- 即时翻译、内存次序、查表改成客体里的散列表、SSE 转 NEON。
- 广向量扩展的压缩位移、码表四（APX）与 REX2，控制寄存器传送的特殊长度。

## 测试

- `测试/兼辨。测试。豫`：llvm-mc 生成的编码逐条核对长度与各字段，并核对三种报错。
- `测试/兼流。测试。豫`：两段代码的基本块、块尾与段外目标。
- `测试/兼义。测试。豫`：三十条指令的提升与两段代码的活标志。
- `测试/臂编。测试。豫`：一百零四条臂六十四指令字与 llvm-mc 比较，另核放不进的情形。
- `测试/兼译。测试。豫`：两段代码的译码，期望值经 llvm-objdump 反汇编逐条核过。
- `测试/兼程。测试。豫`：一个兼容六十四小程序整个翻译，核对文件头、码长与项数、入口偏移与入口表。

```
豫言系统 '「构建」于「包」曰『象胥』于「入口」曰「列」【『测试』，『兼辨。测试』】于「输出」曰『兼辨测试』'
豫言系统 '「行」于『./兼辨测试』于（「罄」以「文」）'
```
