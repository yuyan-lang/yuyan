# 裸机后端

双超级块识别之模拟验已过：BIOS 择零号有效块、UEFI 择唯一号块有效之第三盘，皆越前之启动 ISO、校验坏盘；BIOS 正式读 final.txt，返 ExternalABI512。全类验、系统构、介质造皆过，确界见硬件里程碑；实体读写犹未验。

数据盘识别候选：唯读核零或一扇区之豫言超级块魔数、版一、代非零、前二十八字节 FNV 校验；一块有效即留候选，挂载犹由旧文件系统取最高有效代、巡记录。两块皆无效则使后器代，免五百一十二字节扇区之启动 ISO 阻数据盘。不自格式，空盘须先以旧离线造盘工具备之；今不增格式入口。类验已过，运行犹待验。

内联体存复己之等长守卫表；长异则返之无否则条件，唯于真支已返后之假支记等长，用映后局号。早返入边仍原入之实，外层求交则去单边假定；书相关局仍去其事实。公开 ABI、对象布局及展境之签仍旧。

旧内联样明列径呼实目标者，此呼可用样体长限六千；仍验共预算、深及异常之形。不合之呼仍旧径展之判，径自展仍限二层。样之 JSON 式及公开 ABI 仍旧。

有热点样之函，径自呼亦可展前二层，仍守六千字节共预算及深护；无样之函仍旧途，余径呼限仍旧。今候选之语义验与测速犹待毕。

豫言裸机（`豫言操作系统/裸机/`）之后端库：臂（AArch64）与兼容（x86-64）二构之机器编码与汇编，寄存器与整数之降级（依目标之述生入口、导入之桩与内存增长之助，目标有裸机、Linux、macOS 与 Windows；macOS 与 Windows ARM64 位置无关），内核之任务、内存、设备与控台，系统镜像与持久盘之造，商用平台可执行文件之写（Linux 之链接格式静态可执行；苹果之马赫格式可执行、dyld 导入之槽之绑及其特设签名所用之散列二五六；视窗之 PE32+ 可执行与 kernel32 之导入表），数值之降（数值读取、数值转译与数值之钩：底层新路所产之 i64、f32、f64、v128 与原子之令，转为宽函数与数值内在码，于二构展为浮点、NEON／SSE 与原子之令，见 `豫言操作系统/裸机/文档/数值降级.文言.md`），核之浮点与向量之境（浮点上下文），及裸机验证器所用诸例。旧为编译器核心之子目 `库/编译器核心/裸机后端`，二〇二六年九月二十七日别为独包；编译器不用之，改之不必重举。

## 籍与用

初客之嵌入，由 `系统构造` 共理：不逾 448 KiB 者置旧模块窗，逾者末段暂藏旧窗、余前段藏于被动段。启动之包先以标准 Wasm 令长内存，循序合抄两段于动态区始 `0xC0000`，乃呼旧启动，循 `状态_主程序大` 之标。静态八页、栈、传参区与应用 ABI 守旧约。`测试/初始大客体。测试。豫` 已实装而调用包装入口，验窗界、先抄后呼旧入口、尾字、模块长与大程序标；新壳旧基线与固定合并基线 36aa076c4 之 BIOS/UEFI USB 输入之验已成，所及见《智能命令》。

所有者曰豫言，版本暂定 0.1.0。此包为库，依标准库、编译器核心（网页汇编之核）与结森工具。用之者，豫言裸机之主包「豫言裸机」也。

内联样本之读器解普通 JSON 之客体摘要与原模呼处，摘要须合客体 SHA-256 乃用；不合者配置空。生成器可选参曰 `--内联样本 文件`，须与 `--预编二` 同用。转译器存表界与空引之验；有本模定义、同型号且可展之目标者，迟验签于守卫之退，合目标则由模块声明证其同型。无可用目标仍旧验序，引用呼仍旧途。

有样本之原呼者共六千原令字节之展预算，通深之护为六四；自呼取前二层而展，旧径内联之限仍旧。各层存复函、呼序与局映；全尾链返原函，有常呼续体之内尾呼出最近展层。二层展与尾链基线已有运行之验；免重验签候选之验与速犹待毕。

以模块导入，如 `寻观「裸机后端」之「机器编码」之书。`。此包无总集。

## 维护

原令可证二引用参出于读局，则传已知型与非空；长界与对象头缓存毋传，未知之源存其验。递归内联依今层映局号，各层存、清与复来路之记，毋误用外层之源事实。

预编二闭控制层，仍实入边之可达。环唯有回边者，其末仍不可达；外块唯合实出分支之事实，遂存不变数组之长与型，供后验之省。

宽函降前，简恒零之非参局及宽整加减零，省宽较果紧随之无号扩。零或单果块、无回跳环，体无控流者可展；直段记近书之三十一位界，普通块入口存其实，控流合处及未知令清之，据以去复验之转换及相邻同局宽较相等。含数值隐帧之访者审而略之。

实测及验录见[原生追平记录](../../../../应用/性能研究/横向复测/原生追平记录.文言.md)。

AMD64 xHCI 逐枚已接之根端，候各自异步 Enable Slot 完事，依槽号别置输出上下文及 EP0 环；Address Device 事件回收写控器运行寄存器，待数别存，USB 地址与槽态各取。诸合式键盘依槽别存态、报文缓冲、旧键及中断环，端配置成即请报；累计报数、Caps 态共用。回收事件后每百毫秒察根端连接，新连候稳定而枚，断器则停其记、释其槽，复用先清全槽。禁 PS/2 之 QEMU BIOS、UEFI 已验直连全速两键盘别入、去重不相覆、热接、换端及同端复插，BIOS 别验中断环周回；Mac 多键盘、热插拔犹待实测，EHCI 多键盘、集线器下游热插拔未于此轮作。范围及诊断地址见 [USB 硬件里程碑](../../文档/通用串行总线硬件里程碑.文言.md)、[苹果键盘诊断](../../文档/苹果键盘诊断.文言.md)。

寻址既成，由 EP0 之 Setup、IN Data、OUT Status 三段请设备描述符前八字节，验其类而记 EP0 包长；继以 Evaluate Context 更包长，取全十八字节设备描述符、九字节配置首及全配置。求零备用之 HID boot 键盘接口及中断 IN 端点，向合者发 SET_CONFIGURATION、SET_PROTOCOL，以择 boot 协议；继以别置输入上下文配置中断端点，置八字节报文之请，续排而接既有字符收入。

改接口则更此说明；变身份、版本或所依则修包籍。

AMD64 USB 存储枚举择 SCSI/BOT 接口及其 bulk 入、出两端，别存槽号及端点之参，设配置而启两端。启程之探行 INQUIRY、READ CAPACITY(10) 及 LBA 零单块之读；已枚之根端入口治内核内部单块读、写、同步之请，维护两环周回，候存储时治合式键盘报文。QEMU 已验容量、块内容、专用盘写入同步、周回及重启回读；其请未接应用 ABI、调度及持久文件系统，实体机未验，确切范围见 USB 硬件里程碑。

择盘改为逐器配置成即行唯读启探；探败，后器枚举清内态、共用传输环而复试。欲使空介质读卡器等败候选让位，未自格式诸介质。类验及 BIOS/UEFI 模拟之验皆过：空介质居前、有效数据盘居后，择次盘，容量与首块之读皆成。五百一十二字节扇区而无豫言文件系统之盘，犹或先选；探逾后端点之复犹待作。实体读写、文件系统挂载未验。

AMD64 键盘报告片外置 `0x1F7000`，已接旧 xHCI 之巡，择合之事、去重、化键码而续排，仍用字符收入环，Ctrl-C 写旧中断之记。片存寄存器及标志，其事仍由旧巡统收。关 PS/2 之 QEMU BIOS、UEFI 已验正式回显、中文组字及连续收入，且越环周回；范围及实体机未验之录，见控台输入与硬件里程碑。

闭包融合之候选，唯合冻结客体已验之纯构造、纯取用及定呼窗，且临局后无读取。首实目标与后函表项皆合，乃传所捕值及右参，径呼取用体之尾目标；不合者尽行旧径。旧表界、空验及退径验签皆存，公开 ABI 与对象布局不易。生成器之构建及八标准客体之合、退、陷阱皆验成；速仍在测。

静序候选先证单函表、单活动元素段，无表之导入导出，诸定义函皆不书表，并验取用函之定项；乃求构造函之实槽。合槽则径传所捕参，省两查表及临闭包。不合则复首呼之位及参；未能证者仍两实目标之守。公开 ABI 如故。十五标准客体之合、退、书表、导出表、越界及签误皆验成；冻结编译器候选仍在测速。

融合既合，预算及签许可则展取用体之比较包装函；复用已尽之参存段，去旧实而存真捕值及右参，乃循旧展法。预算不及仍径呼。旧十五标准客体及新未捕异常之例皆验成，公开 ABI 如故；速仍在筛。
