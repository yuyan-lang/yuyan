# 裸机后端

豫言裸机（`豫言操作系统/裸机/`）之后端库：臂（AArch64）与兼容（x86-64）二构之机器编码与汇编，寄存器与整数之降级（依目标之述生入口、导入之桩与内存增长之助，目标有裸机、Linux、macOS 与 Windows；macOS 与 Windows ARM64 位置无关），内核之任务、内存、设备与控台，系统镜像与持久盘之造，商用平台可执行文件之写（Linux 之链接格式静态可执行；苹果之马赫格式可执行、dyld 导入之槽之绑及其特设签名所用之散列二五六；视窗之 PE32+ 可执行与 kernel32 之导入表），数值之降（数值读取、数值转译与数值之钩：底层新路所产之 i64、f32、f64、v128 与原子之令，转为宽函数与数值内在码，于二构展为浮点、NEON／SSE 与原子之令，见 `豫言操作系统/裸机/文档/数值降级.文言.md`），核之浮点与向量之境（浮点上下文），及裸机验证器所用诸例。旧为编译器核心之子目 `库/编译器核心/裸机后端`，二〇二六年九月二十七日别为独包；编译器不用之，改之不必重举。

## 籍与用

初客之嵌入，由 `系统构造` 共理：不逾 448 KiB 者置旧模块窗，逾者末段暂藏旧窗、余前段藏于被动段。启动之包先以标准 Wasm 令长内存，循序合抄两段于动态区始 `0xC0000`，乃呼旧启动，循 `状态_主程序大` 之标。静态八页、栈、传参区与应用 ABI 守旧约。`测试/初始大客体。测试。豫` 已实装而调用包装入口，验窗界、先抄后呼旧入口、尾字、模块长与大程序标；新壳旧基线与固定合并基线 36aa076c4 之 BIOS/UEFI USB 输入之验已成，所及见《智能命令》。

所有者曰豫言，版本暂定 0.1.0。此包为库，依标准库与编译器核心（网页汇编之核）。用之者，豫言裸机之主包「豫言裸机」也。

## 维护

宽函降前，简恒零之非参局及宽整加减零，省宽较果紧随之无号扩。零或单果块、无回跳环，体无控流者可展；直段记近书之三十一位界，普通块入口存其实，控流合处及未知令清之，据以去复验之转换及相邻同局宽较相等。含数值隐帧之访者审而略之。

实测及验录见[原生追平记录](../../../../应用/性能研究/横向复测/原生追平记录.文言.md)。

AMD64 xHCI 逐枚已接之根端，候各自异步 Enable Slot 完事，依槽号别置输出上下文及 EP0 环；Address Device 事件回收写控器运行寄存器，待数别存，USB 地址与槽态各取。首个合式键盘之态留存，诸端巡毕乃请报文。关 PS/2 之 QEMU 已验 BIOS、UEFI USB 启动盘并接键盘，亦验键盘先枚之序；范围及诊断地址见 [USB 硬件里程碑](../../文档/通用串行总线硬件里程碑.文言.md)。

寻址既成，由 EP0 之 Setup、IN Data、OUT Status 三段请设备描述符前八字节，验其类而记 EP0 包长；继以 Evaluate Context 更包长，取全十八字节设备描述符、九字节配置首及全配置。求零备用之 HID boot 键盘接口及中断 IN 端点，向合者发 SET_CONFIGURATION、SET_PROTOCOL，以择 boot 协议；继以别置输入上下文配置中断端点，置八字节报文之请，续排而接既有字符收入。

改接口则更此说明；变身份、版本或所依则修包籍。

AMD64 USB 存储枚举择 SCSI/BOT 接口及其 bulk 入、出两端，别存槽号及端点之参，设配置而启两端。启程时由 CBW、数据、CSW 三段行 LUN 零之 INQUIRY、READ CAPACITY(10) 及 LBA 零单块 READ(10)，核其合事及状态。QEMU 已验高速、超高速存储模型之容量及首扇区全内容，并复验并接键盘；运行时块请、写入、同步及持久文件系统接入尚待，确切范围见 USB 硬件里程碑。

AMD64 键盘报告片外置 `0x1F7000`，已接旧 xHCI 之巡，择合之事、去重、化键码而续排，仍用字符收入环，Ctrl-C 写旧中断之记。片存寄存器及标志，其事仍由旧巡统收。关 PS/2 之 QEMU BIOS、UEFI 已验正式回显、中文组字及连续收入，且越环周回；范围及实体机未验之录，见控台输入与硬件里程碑。
