# 裸机后端

豫言裸机（`豫言操作系统/裸机/`）的后端库：臂（AArch64）与兼容（x86-64）架构的机器编码与汇编、寄存器与整数降级（按目标描述生成入口、导入桩与内存增长助手，目标有裸机、Linux、macOS 与 Windows；macOS 与 Windows ARM64 位置无关）、内核的任务、内存、设备与控制台，系统镜像与持久盘的构造，商用平台可执行文件的写出（Linux 的 ELF64 静态可执行文件；macOS 的 Mach-O 可执行文件、dyld 导入槽绑定及其特设代码签名所用的 SHA-256；Windows 的 PE32+ 可执行文件与 kernel32 导入表），数值降级（数值读取、数值转译与数值挂钩：底层模式新路径产出的 i64、f32、f64、v128 与原子指令转成宽函数与数值内在码，在两种架构上展开成浮点、NEON／SSE 与原子指令，见 `豫言操作系统/裸机/文档/数值降级.汉语.md`），内核的浮点与向量上下文（浮点上下文），以及裸机验证器所用的各项用例。原为编译器核心的子目录 `库/编译器核心/裸机后端`，2026-09-27 起独立成包；编译器本身不用它，改动它不必重新自举。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库与编译器核心（网页汇编核心）。使用者是豫言裸机主包「豫言裸机」。

## 使用

按模块导入，如 `寻观「裸机后端」之「机器编码」之书。`。本包没有总集。

## 维护

宽函数降级先简化恒零非参数局部和宽整数加减零，并省去宽比较结果的紧邻无号扩展。无控制流的零或单结果块、无回跳循环可展开；直线段内记录最近局部写入的三十一位范围，普通块入口保留事实，控制合流与未知指令清空事实，据此消除重复范围转换和相邻同局宽相等比较。含数值隐式帧访问的函数保守处理。

实测及验证记录见[原生追平记录](../../../../应用/性能研究/横向复测/原生追平记录.汉语.md)。

AMD64 xHCI 的首个根端口设备寻址会等待异步 Enable Slot 完成；Address Device 事件回收写入控制器运行寄存器，等待预算独立保存，USB 地址与槽状态分别读取。范围与诊断地址见 [USB 硬件里程碑](../../文档/通用串行总线硬件里程碑.汉语.md)。

成功寻址后，以 EP0 的 Setup、IN Data、OUT Status 三阶段请求设备描述符前 8 字节，校验描述符类型并记录 EP0 包大小；随后以 Evaluate Context 更新包大小，读取完整 18 字节设备描述符、9 字节配置头及完整配置。扫描零备用设置的 HID boot 键盘接口与中断 IN 端点，向匹配设备发送 SET_CONFIGURATION 与 SET_PROTOCOL，选用 boot 协议；HID 中断端点配置与报告收入另行推进。

修改接口时更新本说明；修改包身份、版本或依赖时同步更新包配置。
