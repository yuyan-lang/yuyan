# 任务探针

底层模式的用户态探针，直接作为初始任务装进内核镜像（不经执行器），验证 2026-10-09 新增的三个内核服务与任务处理器记账：

- 服务 45 `空闲内存块数`：池里有空块；
- 服务 46 `任务信息`：从游标 0 取到初始任务的记录（句柄 0、状态非零），游标能一直走到 -1；
- 处理器记账：忙等五个全局滴答后，本任务记录里的累计滴答随之增长；
- 服务 44 `归还内存块`：线性内存增长后写两个动态块，归还后空闲块数正好多两块；再读其中一块得零（缺页重新提交、整块清零），空闲块数少一块；超出容量的归还返回零。

全部通过输出 `OK`；任一步失败输出 `FAIL` 加步号并陷阱。运行：`yy普通豫言验证 --只验 底层-任务`（两种架构）。
