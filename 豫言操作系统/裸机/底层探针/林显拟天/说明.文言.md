# 林显拟天

通称假 X 服务器。林纳显示后端之协议替身，用于无可用显示服务器之开发机。

听于 `/tmp/.X11-unix/X9`，待一客；依 X11 之协议应建立、建窗、取键图、查原子与贴素之请。一帧既满，乃依次送按键之按抬（键码八，首级 `a`、次级 `A`）、文字、指移、主键之按抬、轮上下各一格、尺变与 `WM_DELETE_WINDOW` 闭窗。窗号取自建窗之请，事中仍以原号报还，以供冒烟核其事之配面；又可回选请一次，以核客之剪贴之服；亦可为别家之选主，以核客之 ConvertSelection 与 GetProperty。

## 行法

先清旧套接之文（程序亦自删一次），而后于后起之：

```sh
rm -f /tmp/.X11-unix/X9
./林显拟天。林纳。豫行 &
DISPLAY=:9 ./林显输入探针。林纳。豫行 --授权显示面 主窗口=320x240
```

拟天只事一客、一验；客既闭，程序乃退。其系固定之号九，径为 `/tmp/.X11-unix/X9`，不读授权之文，不校授权。

## 界

| 请 | 答 |
| --- | --- |
| 建立（108） | 循真 Xwayland 之形，八千二百七十六字（起于四零九六零）：厂商之串二十字、七像素格、一屏一二八零×七六二（根窗 0x381、默示 colormap 0x4c、默示 visual 0x4d、根深二十四）、七深共三百三十六视（深二十四有三百，末为真彩二十四位；余六深各六）、最大之请六五五三五、键码八至二五五 |
| 建窗（1） | 记窗号与宽高，余不校 |
| 查原子（16） | 皆答七一 |
| 取键图（101） | 二百四十八键，每键二级；键码八为 `a`、`A` |
| 贴素（72） | 读弃其素；纵加高及窗高则发诸事一次 |
| 置选之主（22） | 记选主之窗，发选请（求者窗 0x300，选、目、属皆七一） |
| 改属（18）、送事（25） | 读弃其体，常出印 `C`／`S`，以核客已答属与选告 |
| 求选（24） | 答选告（求者、选、目、属依所请），印 `Q` |
| 取属（20） | 答格式八、类七一之文“别家剪贴”，印 `P`；可为别家之选主 |
| 余请 | 读弃其体，不应 |
