# 林显拟天

通称假 X 服务器（fake X server）。林纳显示后端的协议替身，用于没有可用显示服务器的开发机。

在 `/tmp/.X11-unix/X9` 上听一个连接，按 X11 协议应答执行器的建立、建窗、取键图、查原子与贴像素请求；一帧贴满后依次送按键按下与抬起（键码八，键图第一级为 `a`、第二级为 `A`）、文字、指针移动、主键按下与抬起、滚轮上下各一格、改尺寸与 `WM_DELETE_WINDOW` 关窗。窗口号从建窗请求的窗口字段取，事件里原样带回，供冒烟程序核对事件是否配到显示面；另可回一次选区请求，核对客户端的剪贴板服务。

## 跑法

先清掉旧套接字（程序自己也会删一次），再在后台起：

```sh
rm -f /tmp/.X11-unix/X9
./林显拟天。林纳。豫行 &
DISPLAY=:9 ./林显输入探针。林纳。豫行 --授权显示面 主窗口=320x240
```

假 X 只服务一个连接、一次冒烟；连接关掉后程序退出。它绑定固定的显示号九，路径是 `/tmp/.X11-unix/X9`，不读授权文件，不校验授权。

## 边界

| 请求 | 应答 |
| --- | --- |
| 建立（108） | 二十六字附加数据：一个屏、真彩二十四位视、最大请求六五五三五、键码八至二五五 |
| 建窗（1） | 记窗口号与宽高，不校验其余字段 |
| 查原子（16） | 一律回原子号七一 |
| 取键图（101） | 二百四十八键、每键两级；键码八为 `a`、`A` |
| 贴像素（72） | 读掉像素；纵加高达到窗高时发一次全部事件 |
| 置选区主（22） | 记下选主窗口，向它发一个 SelectionRequest（求者窗 0x300，选区、目标与属性都七一） |
| 改属性（18）、送事件（25） | 读掉体，标准输出印 `C`／`S`，供核对客户端已回属性与 SelectionNotify |
| 其余请求 | 读掉体，不应答 |
