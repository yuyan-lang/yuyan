# 两客轮行

两客居同虚址，各有实存。钟至，核存旧客诸整数寄与返态，择可行之客，复其帧，易其页表，清旧译址而还。核域、核栈与设备之映，两表同之，客不得入。今限一核，处异常时不受钟扰。

臂之客域自〇x40200000至〇x40400000，次客实存自〇x40600000至〇x40800000；兼容之客域自〇x200000至〇x400000，次客实存自〇x600000至〇x800000。臂帧二七二字节，兼容帧一六零字节。

平台有“任务编号”“任务状态”二问。状态之一位为可行，二位为已行，四位为已毕；号越界则返负一。此为今试之约，未立恒久接口。七号服务仍为致命陷阱。

两客各持异值，同址长算，算中不入核。毕验己值未乱、和数无误、彼已得行。首客毕而彼未行者，不得称抢占。又禁首客之中断为反证，令次客期值有误为反证；二客各四验俱成，始报全成。实测另载验证记录。

今仅静态两客。动态生灭、等待、故障独退、页之分还、通信、持久文件、用户态豫言命令壳及客中执行器，皆未毕；浮点、向量、线程局部状态与多核亦未备。不得以此称全系统已成。

二〇二六年九月二十二日，两机共一二四试皆过，两客正例及错果、禁抢占反例俱验；旧单客与外来 C 模块亦无退失。类型检查与实码覆核皆成。标准模块另以 V8 验其算，不以之证抢占。产物藏于 `/tmp/yy裸机验证.Lbni9C`，散列与范围见验证记录之“双任务抢占扩展验证”。

后进已使访存失界及生成陷阱独止其客，余客续行，详[故障隔离](故障隔离.文言.md)。本篇一二四试为旧阶段之证，全生灭之制犹未毕。
