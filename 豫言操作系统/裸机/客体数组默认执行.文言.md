# 客体数组默认构造

用户态客体执行器今识标准 WasmGC `array.new_default`（`0xfb 0x07`）之纯 `i32` 数组。解码取数组型号；验型必数组且元素为 `i32`，仅取一 `i32` 长而产其具体引。运行时于受检物堆分配，长至三十二，诸元素初为零。堆不足则循活动根寻扫而复试。

验模造三元素数组，取首元素而得零；标准网页汇编引擎亦验而行之。臂六十四、兼容六十四 QEMU 旧试共三百六十八项皆过，产物与日志在 `/tmp/yy裸机验证.TdOmRE`。异类元素、引用默认值及普通豫言所需完备 WasmGC 尚待续作。

后续已接 `i8` 元素之默认造，详[客体字节数组执行](客体字节数组执行.文言.md)；引用元素仍未具。
