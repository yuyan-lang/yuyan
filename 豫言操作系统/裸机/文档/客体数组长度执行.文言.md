# 客体数组长度指令

用户态执行器今识并行标准 WasmGC `array.len`（`0xfb 0x0f`），此令无型号随字。静态验栈察栈顶精确引用型，必为数组；不可达支仍循栈多态之则。运行时核活柄及数组型，取物首之元素数，入 `i32` 栈。结构引与整数不得伪数组。

标准有效独立模块造三元素数组，`array.len` 得三；以结构引用行此令之独立模块于标准引擎无效，豫言亦于静态验型拒之。数组长仍限每物至多三十二槽。臂六十四、兼容六十四 QEMU 并旧试共三百六十八项皆过，产物与日志在 `/tmp/yy裸机验证.BbCKYn`；三级自举产物同，编译器入口验型亦过。

宿主构建之限：今原生代码生成器为大型生产壳工具或造约百七十四兆字节之单个暂串，默认二百五十六兆字节宿主 GC 堆不足。编此工具及裸机验具须设 `YY_GC_INITIAL_HEAP_SIZE_MB=1024`；此仅及构建宿主，不改裸机客体堆。降低宿主生成峰值内存，尚须续治。
