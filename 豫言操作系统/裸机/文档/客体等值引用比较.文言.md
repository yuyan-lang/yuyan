# 客体等值引用比较

用户态 WasmGC 执行器今识 `ref.null eq` 与 `ref.eq`。解码记空等引为可空 `eqref`，运行值用零；函数空引仍别用 `-1`。静态验型许 `i31ref`、`eqref` 及实际为结构或数组之具体引入 `ref.eq`，拒凡整数与函数引。运行时比两受检引之身份或小整数值，返 `i32`。

独立标准模验两小整同、两空引同、空引与小整异、两新数组异、具体数组空引与通用等引空值同，并以整数或函数引误入此令为反例。具体数组与结构之空引亦用 GC 空值零，具体函数空引仍循函数域。诸模皆以标准网页汇编引擎复核。

此尚受限行路：`eqref` 函数参、返回、类型局部、全局、数组引元素未接，`ref.is_null` 对等引之完备型则亦待续。不得据此谓普通豫言模块已可行。

后续已接今受引用子集之 `ref.is_null`，详[客体引用判空执行](客体引用判空执行.文言.md)；余缺口仍存。
