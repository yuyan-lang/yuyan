# 结构体与 i31 指令类型验证

指令验证器现支持 struct.new、struct.new_default、struct.get、struct.get_s、struct.get_u、struct.set，以及 ref.i31、i31.get_s、i31.get_u。结构体类型必须由已验证上下文确认，字段编号必须在界内；创建时按字段展开类型弹出初值，并产生对应具体非空结构引用。

默认创建要求所有字段可默认初始化，非空引用字段会拒绝。字段写入要求可变且值类型相容。打包字段必须使用有符号或无符号扩展读取，普通字段不能使用这两种读法。i31 创建接收 i32，提取接收可空 i31 引用并产生 i32；空引用在类型上合法，但具体执行必须陷阱。

20 个完整模块测试与 Node 标准引擎分类一致，豫言验证器测试也全部通过；18 个原顺序指令回归通过。类型检查和构建通过，日志为 `/tmp/yy结构对象检查日志`、`/tmp/yy结构对象构建日志`、`/tmp/yy结构对象运行日志`、`/tmp/yy结构对象回归运行日志`。

这是 GC 指令的静态验证，尚未分配结构对象、执行字段访问或回收内存。数组、引用转换、异常及运行时根扫描仍待接入；默认裸机镜像不变。
