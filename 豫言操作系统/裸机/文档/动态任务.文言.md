# 动态任务（兼容）

兼容之核于旧二静槽（槽零、槽一）之外，供任意多之动态任务。动态任务由服务三十七“装载任务”自开机所留用户区之模，起一全新之任务，不复制父任务；命令壳之“运行”经执行器之子进程途用之。

## 句柄与限

- 动态任务之句柄为槽号之倍：偶数，不下六十四。旧句柄惟零与奇数（槽一每复用加二），二者不相犯。
- 动态槽号自三十二至四百一十八万六千一百一十一，任务号（句柄）可至八百三十七万二千二百二十二；能并存之动态任务之数，由内存定之。
- 分槽以游标自小至大轮转，所回收之槽待游标一周乃复用，旧句柄不即指新任务。

## 槽区与内核任务之窗

每动态槽有百二十八 KiB 之槽区，映于内核任务之窗 0x8000000000（PML4 第一项，惟内核可访）加槽号乘百二十八 KiB。十六槽共一二兆物理块（组），组块于首分此组之槽时求于内存之管而清之。

| 槽区之偏 | 所载 |
| --- | --- |
| 0x00 | 状态（位义同旧槽：一可行，二曾行，四已毕，八故障，0x10 候任务，0x20 被止，0x40 候消息） |
| 0x04 | 退出码 |
| 0x08 | 主人句柄 |
| 0x0C | 所候之句柄 |
| 0x10 | 本句柄 |
| 0x14 | 内存块数 |
| 0x18 | 页表之根（物址，八字节） |
| 0x20–0x30 | 用户区块号、原生栈二块、启动块之块号与长 |
| 0x34、0x38 | 调度环之后、前 |
| 0x40 | 邮箱（十六字节，式同旧槽） |
| 0x200 | 保存之帧（百六十字节） |
| 0x400 | 浮点之区（fxsave，五百一十二字节） |
| 0x600 | 控台行缓（0x7FC 处为字数） |
| 0x1000 | 内存块号表（二千四十八项） |
| 0x4000 起 | PML4、低区 PDPT、低区页目、动区 PDPT 与四张动区页目 |

窗之元数据居窗末一 GiB（0xFFC0000000 起）：M0 块载窗之 PDPT、第五百一十一张页目（其第零、一项映 M0、M1，第二、三项为二 2 MiB 暂窗）与槽位图；M1 块载余五百一十一张页目。窗于首次装载任务时建；旧二槽 PML4 第一项并指窗之 PDPT，动态任务之页表拷自槽零，故诸地址空间所见之窗同一。

全局之量居 0x121F08 起：动态槽数（已装未收者之数）、窗已建否、M0、M1、模之块号、分槽游标、调度环首。

## 装载任务与启动块

- 开机初置于高区内存初置之后，若机有百二十八兆以上之内存，则求一块，原样复用户区 0x200000 起二兆为模（时大码初置已书预编二之跳板）。惟百二十八兆之机不留模，装载任务返负一，行为与旧版全同。
- 服务三十七装载任务（启动块之线性址、长，至多二兆）：建窗、分槽；求用户区一块（拷模），预编二启盘复求原生栈二块（清之，映于 0x1C00000 起），有启动块复求一块（自呼者线性内存拷入）；页表拷自槽零而改其用户区、原生栈与动区；首帧 rip 0x200000、rsp 0x3F0000、rflags 0x202；浮点区置控制字 0x37F 与 MXCSR 0x1F80；主人为呼者；入调度环，动态槽数加一，返新句柄。
- 服务三十八读启动块（目之线性址、块内之偏）：偏为负一则返启动块之总长；否则每次拷至多六十四 KiB，返所拷之数；旧槽与无启动块者返零。
- 执行器所约之启动块：送参数区六十四 KiB、送程序名区六十四 KiB、程序之字节，末十六字为魔数、程序长与子任务之式。子任务开机先问总长，识魔数则取之，依“子任务改装”拷为己之参数、程序名、当前目录、输入路径与环境，乃备重启，其后启动之循环径行新程序。程序长于模块之窗（四百四十八 KiB）者置于区域之起，由重启之备落位。

## 调度

有动态槽时，定时之中断、阻塞之服务与退出后之调度，皆转外置之模统一轮转：次为槽零、槽一（旧槽数为二时）、调度环中之动态槽，复归槽零。切换时整帧存于旧任务之保存帧，取新任务之帧而易页表之根；浮点即时切换，主人记于 0x124400，故系统调用返处之惰性切换恒见“主人即当前槽”。动态槽数复零，则旧调度器如故接之。

## 服务

- 动态任务之系统调用由外置之模分派：写字节（本槽行缓）、核验、完成与退出任务、任务编号、陷阱、句柄之服务（状态、退出码、候、止、收、发）、收、来源、候消息、内存块（与旧槽同一，依槽取址）、装载任务、读启动块；时钟、读字节、墙钟、中断查询、设备与持久块之服务归原分派（后二者惟许槽零）；帧缓之信与字体模块之长返零，余帧之服务返负一。
- 旧槽呼三十七、三十八亦转外置之模；旧槽对动态句柄呼状态、退出码、候、止、收、发，于句柄解码处转外置之模。
- 消息之义同旧槽：邮箱一格，收者方候消息则即交付；候消息惟有“活伴”（主人可行，或有可行之子任务）时阻塞。动态任务可致消息于句柄零（初始任务，文件之代办者）；子任务毕，若主人方候之或方候消息，依旧义醒之（候消息者来源为负一）。

## 主核之转接

外置之模（内存之管与动态任务合一）链于 0x1A0000，首为跳表：+0 内存之服务、+8 动态系统调用、+16 调度、+24 动态故障、+32 句柄之服务、+40 旧槽候消息、+48 开机留模。主核惟加数处转接：系统调用之入（当前槽不下二或服务号不下三十七则转外置分派）、调度之入与退出后之调度（有动态槽则转外置调度）、句柄之解（偶数非零者转外置句柄之服务）、故障之退（动态槽之故障转外置）、候消息（有动态槽则转外置），皆经主核之跳桩。外置之模呼主核之“返回用户”“调度复原”“串口字节”“系统调用分派”“接收消息”“失败”，用链接时所生之跳桩。

## 后续之版之事

- 动态任务退时，其子任务成孤：不收，不易其主。
- 动态任务于旧句柄惟能致消息（致于己之主人或句柄零）；状态、候、止、收旧句柄者返负一。
- 动态任务暂不用帧之服务与块设备；块设备之文件由初始任务代办（远程文件，依旧约逐信传之）。
- 无可行之任务时无空闲之态，依失败停机。
- 分槽之时位图最坏须扫四百万位。
- 惟作兼容，臂仍二静槽；臂之核于三十七返负一、于三十八返零，执行器据之退用复制任务。
- 执行器之页限为六万五千五百三十五页，回收之位图与卡表依限预留，每任务先占约百四十四兆；执行器六十四位、按需提交之后乃减。
