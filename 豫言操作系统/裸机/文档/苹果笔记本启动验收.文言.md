# 苹果笔记本启动验收

目标：用户欲支持 MacBook Pro（Retina，十三英寸，二零一三年末）。用户言已装 Linux，可试 U 盘启动。独立树居 `~/repos/yuyan-worktrees/苹果二零一三启动`，yybs 基线 `9246bc0be`。此阶段循现通用 EFI 介质，先验 U 盘载核、图形命令壳、USB 输入；内置键盘、触控板、内存储及余设备，别据实体之证接之。

[Apple 官方规格](https://support.apple.com/en-us/111946) 载 Intel Core i5/i7、Intel Iris Graphics、2560×1600 屏、二 USB 3 接口。[Apple 启动按键说明](https://support.apple.com/en-us/102603) 载 Intel Mac 启时持 Option，可入启动管理器。USB 拓扑、设备身份，俟用户 Linux `lsusb -t` 或实体启日志。

## 候选介质

产物 `yy苹果启动.iso`，循已构混合镜，SHA256 为 `49e320f7db513678ab90aa6a1635c9bccb7bcf8b7522733befc49dc07aec05d9`。xorriso 核 MBR 有 `0xEF` EFI 分区、`0xAF` 分区；源介质有 `EFI/BOOT/BOOTX64.EFI`，file 验为 x86-64 PE32+ EFI 程序。Limine 配置以 multiboot1 载核及默认字模；此阶段未添系统 ABI、苹果专用兼容层。

## 模拟器证据

Q35、Haswell、TCG、五百一十二 MiB、单核、禁 PS/2、OVMF、qemu-xhci。镜为唯读 USB 磁盘，接次 USB 端，首端接高速 USB 键盘，未附光盘。OVMF 志明载、启“UEFI QEMU USB HARDDRIVE”；继显豫言核、命令壳已备。帧缓核为 1280×800、三十二位、行距 5120，截图证图形中文壳已显；F2、H、Shift-H 入 `hH`，正常退。TCG 报 Haswell 部分 CPU 特性不受，此验未模拟完整 Mac 硬件、Apple 固件。

## 实体机验收仍待

选定测试 U 盘而写候选镜，关机接 Mac，启而持 Option，择 EFI 项；记内核、壳、图形是否现，继验键盘。写盘前须定测试盘身份，毋误写今 Linux、E40 数据盘。此文不以模拟之果断言 Mac 已合；Apple 固件识别、实际显示模式、内置输入、内存储，皆未获实测之证。
