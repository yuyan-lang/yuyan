# 中文启动与输入验收

这是完整中文交互镜像的验收步骤。最终镜像已构建；BIOS 128 MiB、UEFI 512 MiB 的有无 COM1 启动与键盘补全均已实测。以下步骤供真机复验，不表示每项已在每种配置上逐一验证。

## 启动介质

最终 ISO 的 SHA-256：`f75263da45955e7b609f63ab63f8505f8107c55056b482a64222fb8e45b55f8d`。BIOS 无串口复验已执行 `bz`、Tab、回车并输出完整帮助，截图 `/private/tmp/yy-final-bios-none.png`。

在仓库根目录运行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫言系统.wasm 启动盘 --输出 yy完整中文启动介质 --预置 无`。构建机会用 FreeType 生成 Noto、思源完整字模，再构建客体与壳。ISO 为 `yy完整中文启动介质/yy豫言启动.iso`，包含 BIOS/MBR 与 x86-64 UEFI 入口。

## 模拟机

依次检查 BIOS、UEFI；每种方式检查有 COM1 与无 COM1。无串口参数为 `-serial none`；有串口使用文件日志，避免串口与键盘同时注入字符。UEFI 使用只读 pflash 加载固件，不用 `-bios` 加载该闪存文件。

1. 出现中文加载信息、欢迎文字、输入说明及 `壳>` 提示符，英文小写清楚。
2. 输入 `bz`、Tab、回车；应补成“帮助”并输出中文命令说明。
3. 输入 `huixian`、Tab、空格、`abc`、回车；应补成“回显”，输出 `abc`。
4. 输入 `j`、Tab，再按 Tab；候选应轮选“加”和“建”。Esc 清除候选状态，不自动执行。
5. 输入 `hx`、Tab、空格，按 F2，输入 `nihao`、数字 1，按 F2、回车；应执行“回显 你好”，输出“你好”。
6. 中文模式输入 `ni`，空格选首项“你”；输入 `hao`，空格选首项“好”。Tab 可翻页，数字对应当前页 1～9。
7. 组字中按退格删除拼音末字，Esc 清组字；中文上屏后退格删除末字。
8. 连续输出多行中文，屏底上移并清空最后一行；长中文行换行，不在行末写出屏幕。
9. `tmp-echo ok` 仍可执行；回到英文模式后“退出”或 `tmp-exit` 结束壳。

## E40

使用最终交付镜像的唯一文件名与 SHA-256，避免误写旧镜像。先确认 U 盘当前设备编号，再卸载整盘并把 ISO 写到原始设备；历史 `disk6` 编号不能证明当前设备身份。选择 USB 启动，按上述 Tab、F2 与选字步骤检查。记录 BIOS 设置、屏幕照片、是否使用内置键盘及具体输入。当前只有先前英文壳与内置键盘已由用户确认；新版完整中文镜像尚无 E40 实测结果。

## 已知范围

当前只接受三十二位直接 RGB 帧缓，输入法只有简单双模式全拼、规范字候选与手录常用词，无词频学习。启动盘默认不挂持久数据盘，文件命令可能报告不可用。尚未验证的项目不能因编译成功而标记通过。
