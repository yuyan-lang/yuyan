# 苹果键盘实机诊断

用户实测 MacBookPro11,1：旧候选 ISO 显示常，内键盘、后接之外键盘皆不能入。承许 SSH pit-mbp13 读 Linux：Intel xHCI 8086:9c31，BAR B0A00000、六十四 KiB，HCCPARAMS 200077C1，用三十二字节上下文。外 SONiX 413d:2114 直连 USB 2 根二端，低速，接口零 boot 键盘、IN 81、最大包八、间隔十；内 Apple 05ac:0259 直连根五端，全速，接口零 boot 键盘、IN 83、最大包十、间隔八。二者不经蓝牙集线器。

诊断用旧实测镜源码 00dc0cb1b，加 USB 启屏快照。今 yybs 550386101 启盘构报用户码 701684 字节、可用 263592 字节，此布局阻碍已告终端会话；此事不旁改其界面、输入法、字体、用户布局。诊断镜、正式候选别存，不以旧基线之验称今上游全过。

## 使用

定测试 U 盘而写诊断 ISO；外键盘先接乃开机。Mac 持 Option 启而择 EFI Boot。拍全 USB 诊断行，不待键盘可入；唯见“USB诊断开始”亦拍其画。实体键盘未修成。

## 字段

诸数皆八位十六进制。核内端口表据 0x12B000 至 0x12CFFF，各端三十二字节；存寄存器与标志，循旧串口、帧缓出之，不增应用 ABI。

| 行 | 诸列之义 |
| --- | --- |
| USB PCI | PCI 配置址、类码、BAR 低高字 |
| USB CTRL | 控器阶段、末寻址态、操作寄存器虚址、scratchpad 数 |
| USB ENUM | 最大端数、寻址成数、完整描述成数、巡态 |
| USB KEY | 键盘配置态、端点初置态、端点命令完码、所择槽 |
| USB EP | IN 端址、最大包长、间隔、累计报数 |
| USB P02、P05 | 初 PORTSC、寻址态、寻址完码、首描述态、全枚举态、枚举步、其时全局键盘配置态、VID/PID 双字 |

末字高十六位为 PID、低为 VID；完整描述成，乃据以识器。键盘态为全局所择者之态，不以此称各端皆配置成。

## 验证

格式、全构、启介质、终稿核心类验、差异检皆过。诊断表先于 USB 初置清零，免启程既枚而抹其记。Q35、Haswell、TCG、五百一十二 MiB、单核、禁 PS/2、OVMF、qemu-xhci（USB 2 九端、USB 3 四端），从 USB 存储模型启诊断 ISO；屏上七行 USB 字段皆可读，P02、P05 八字之记，与模拟器物理内存逐项同。壳备，F2、H、Shift-H 得 hH，正常退。截图 yyUSBDebug.png 已人观。ISO SHA256：b9ebf3288d86e25b894410c1a1b9b08a02ae5cbc4fed797fefee35ed1d4195cc。此唯证诊断之出正、模拟输入仍存；Mac 实体之败，俟此镜之照片，尚未修成。
