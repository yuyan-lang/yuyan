# 结构对象与小整验型

今验结构新建、默认新建、普通及有符号无符号读、写，兼 i31 创建与提取。先确认具体结构型，次验字段界；造时依字段展开型取初值，返具体非空引用。

默认造须诸域可默认，非空引用域则拒。写须可变且型合；窄域读须明符号扩展，普通域不得冒用。小整以 i32 造，提取受可空 i31 而返 i32；空引用型可受，行时须陷阱。

二十完整模块与 Node 分类同，豫言验者皆过；旧十八顺序回归亦过，验型构建皆成。日志存 `/tmp/yy结构对象检查日志`、`/tmp/yy结构对象构建日志`、`/tmp/yy结构对象运行日志`、`/tmp/yy结构对象回归运行日志`。

此为静态验型，未造运行对象，未行字段访问，未回收内存。数组、转换、异常及根扫描尚待，默认裸机镜像不变。
