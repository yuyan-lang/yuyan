# 帧之务：用户态以画书于帧缓

## 今之行（2026-10-11）

核务32、33逐物理像素交画、报物理宽高。臂由豫言内核帧控台行之；兼沿外置帧务，帧求倍定一。执行器于宽逾1920或高逾1200时报自动比2，余为1；显示控件依有效比栅格化字、求逻辑尺、换指位、交脏区。设置具自动、100%、125%、150%、175%、200%、250%、300%而持久存之。外部图形之程得父桌面有效比，比变则并设显示面。

光标依自动比绘，相对鼠移同比增；绝对坐标依今物理宽高折之。鼠态区8192字，光标缓自+2048起。影帧至少容2560×1600×4字，指移续补交新旧光标之区。

两构共用 `内核/显示模式。底层。豫`，务57读模式数、58依自0起之下标读宽乘65536加高、59依宽高设模式。QEMU标准显卡由迪斯派寄，臂内存帧由固件配置 `etc/ramfb`，威睿三代由BAR0寄及BAR2帧；二代由端口及BAR1帧。固件无帧缓而有 virtio-gpu 者，驱动开机时由虚拟显卡取连续八块为像素区、依同一帧录建帧缓，调度及空闲选约每三十毫秒传整帧于显卡（见内核包说明「虚拟显卡」）。列具今模及1280×800、1920×1080、2560×1600。换模更新帧录、行距及映射，执行器清光标态、截鼠位而交一次尺变；还面复开机模式而清屏。

十月二十一日始，虚拟显卡兼多出（至多四屏；独屏则尽十六兆之素区，多屏则每屏一槽，四、一七七、九二零字）：驱动开机读设备配置之 num_scanouts 与显示之信，得 EDID 之特性则读其首尺（不容于槽则退一二八〇乘八零零）；诸出各建其资、各设扫描、各冲其帧。新增核务百三十屏信（屏序、目之偏 → 宽高行距接否；屏序为负则返屏数）、百三十一屏交帧（屏序包于宽高字之高八位，宽高各十二位，区之义同三十二）、百三十二屏设模、百三十三屏变（屏之世代）。执行器依面取屏：主窗口、屏一、宫一为第零，屏二、宫二为第一，至多第四；帧信、交帧、易模皆依面。热插由百三十三之世代见之：拔者下次取事交显示面已关闭，接者交显示尺寸变化。核之控台惟画第零屏；壳命「屏列」列诸屏，「设屏」改其一，「设置分辨率」仍惟改第一屏与桌面之设。设备配置之 events_read 约每三十毫秒一读，见显示之事则重读显示之信而重配屏表。QEMU `-device virtio-vga,max_outputs=2` 即二出二屏之验机。

2026-10-11独立Fusion臂探针实测1920×1080、2560×1600直书帧可用，自动200%及150%切换重排、鼠点皆正。后续之事：兼帧务迁为共用底层豫言、逾16兆字之模式、依高级配置电源接口寻固件配置设备、分辨率确认倒计时、威睿二代实机之验、逾四屏与独屏槽限外之模式。

## 昔之实现与测量（2026-10-06至2026-10-10）

下存当时接口、实现之居及测量；今之尺及缩放依上节。

核务三十二「提交帧」与三十三「帧缓冲信息」（平台导入 `平台.提交帧`、`平台.帧缓冲信息`），使用户态之程以全帧之画交核，书于 Multiboot 之帧缓。惟兼容核心行之；臂无帧缓，二务皆按未知之务返一，呼者视为无显示。执行器「客体二号」据此于裸机行公共显示之约（见 `客体二号/裸显示。底层。豫`）：一面即全帧缓，输入惟键盘。

| 务 | 参 | 果 |
|---|---|---|
| 三十三 帧缓之信 | 无 | 宽乘六万五千五百三十六加高（逻辑之素：高分之屏倍之，则半于物理之素，余即物理之素）；无可用之三十二位直接 RGB 帧缓则零 |
| 三十二 交帧 | 像素于客线性内存之址（为零则不读像素，涂 宽×高 之区为黑，倍则涂二宽乘二高；十月六日始执行器还显示面以之清屏）；宽乘六万五千五百三十六加高（逻辑之素）；区左乘六万五千五百三十六加区上；区宽乘之加区高（区，逻辑之素；零则全帧，十月十日始） | 成零，败负一 |
| 三十四 读字体模块 | 目于客线性内存之址；模内之偏 | 所拷之数（至多六万五千五百三十六）；偏至末为零；无模或目越界为负一 |
| 三十五 字体模块长度 | 无 | 模之字数；无则零 |
| 三十六 读鼠标字节 | 无 | 鼠环之一字；无则负一。环中皆四字之包：首字、横移、纵移、滚轮（二〇二六年十月十一日起，见[控台输入](控台输入.文言.md)之“鼠包与滚轮”）。初呼则清鼠标之环，向鼠标发 D4 F4 以开数据之报（二〇二六年十月六日） |

- **素之式**：画为 RGBA8，行优先，无行距。核读帧缓之录之红位：红位十六（QEMU 标准显卡之 BGRX）则易红蓝，红位零则如故，余式败之。Multiboot 1 之约置色彩之信于信息结构偏移百一十（自有之引导依之），昔 Limine 四字节对齐而置于百十二，故录之红位或在 0x103926，或在 0x103928；核视 0x103927 是否红宽八以辨之。
- **验**：宽高须正而不逾逻辑之度（三十三所返之宽高）；像素须全在客可用之线性内存，界同“块搬入静态”（线性基址为三 MiB 则五百一十二 KiB，否则动态块数乘二 MiB），像素之址另有一 GiB 之粗界（旧为三十二兆；裸机页限既增，帧缓或居其上）。画书于帧缓左上，逐行依行距而进。
- **字体模块**（三十四、三十五，二〇二六年十月六日）：启盘所带第二模块，桌面所用之 TrueType 字体（文楷）。设备初置之时「兼文楷篇初置」映之于核窗一 GiB 加三十二兆起（页目 0x125000 第十六项起），虚址、物理址、长度存于 0x103A00、0x103A04、0x103A08；三十四自核窗拷于 r9 加目之址，目之界同交帧。执行器于裸机诸族名皆取此体（`显示原语。底层。豫` 之「字体裸开」「字体裸定读」）。自有之引导，BIOS 下置模紧随内核（八兆起），UEFI 下居固件所予之高址；若落块池，亦如首模标池图。
- **代码之居**：务体居 0x1F5000 起之外置区（帧缓映射代码所在八 KiB 之后半），依 eax 分三十二、三十三、三十四、三十五；主核分派表惟一区间之判（务号三十二至三十五皆至同一以 r11 呼外置区之呼口，主核近一万二千六百零八字之限）；构建时核两半各不逾四 KiB。
- **验收**（二〇二六年十月六日）：以 `豫言系统 启动盘 --壳 库/器物/测试/原生显示提交探针。脚本。豫` 所造混合 ISO，经 QEMU q35、SeaBIOS、xHCI U 盘而启，探针串口出“尺寸：1280×800、像素比乘六十四：64、提交：成功、等待：显示计时、归还：成功”，QEMU 监视器 screendump 得全屏 RGB(32,96,160)；`裸机验证` 三百八十项皆过。

待办：惟认红位零与十六之三十二位式；三倍以上之放大与写合并之映（以速高分之屏书帧）俟诸后版；书帧之际不闭中断；执行器之候为忙候；鼠可用 PS/2 与 xHCI 上 USB 启动之约者（相对之移与滚轮，滚轮自十月十一日），usb-tablet 之绝对坐标俟诸后版。

**PS/2 鼠标**（二〇二六年十月六日）：键盘初置之配置字改为 or 0x40、and 0xCC，开辅口之钟（二路中断犹闭）；主核「键盘收入」读状态见辅口之位 0x20，则跃至外置区 0x1F5C00 之「鼠标字节入」，存字于 0x103B10 起之六十四字之环（0x103B00 魔数“MOUS”、0x103B04 写计、0x103B08 读计）；务三十六读一字，初呼则清之而向鼠标发 D4 F4。外置区之布改为：帧务主体居 0x1F5000，补零至三千七十二字，后接「鼠标字节入」。执行器（`客体二号/裸显示。底层。豫`）成三字之包、交指之事，交画时叠绘十二乘十九之箭头光标，指移则重交末帧。十月十一日起读 i8042 者为两构共用之豫言内核「键盘收入」（见[控台输入](控台输入.文言.md)），外置区惟置帧务主体，「鼠标字节入」与主核之『鼠标字节』跳板已删；同日起「键盘收入」初呼则开 IntelliMouse 滚轮之模，辅口之字由豫言内核成四字之包（首字、横移、纵移、滚轮，三字之鼠补零）乃入此环，执行器依四字之包解之而交滚轮之事。

**帧缓改为写合并**（二〇二六年十月六日）：核旧映帧缓为强不可缓存（页目项 PCD|PWT）。实机每书一素、每读一字，皆一往返于总线：二千五百六十乘千六百之林檎笔记本，桌面一帧须书十六兆，迟滞可见；控台卷屏逐字而复全屏，每卷一行约十秒，目见其画如 CRT 自上而下扫。今帧缓映射先设 PAT 第四项为写合并（WC），页目项改为 P|RW|PS 加 PAT 位（0x1083），书则处理器合为整行之突发；控台至底一举上移半屏，八字一复，读显存之数减数十倍。QEMU 之帧缓本为常内存，此二者之异，惟实机乃见。

**USB 之鼠**（二〇二六年十月六日）：xHCI 之驱于全枚举时，键盘之后复寻 HID 启动之约之鼠接口（类三、子类一、约二，零备用）。键盘之途未为此器设配置，则先设之，次设启动之约，乃以 Configure Endpoint 惟加此接口之中断入端（槽上下文之条目数取旧值与此端号之大者）。三十二项之中断环、报告缓冲与鼠之诸字，皆居此槽键盘记录之后（记录偏百二十八起为鼠之字，三百二十起为报告缓冲，五百一十二起为环）。林檎笔记本内置键盘与触控板同为一 USB 器者，二接口各配一端。报告片依事之端号分流，以启动之报（键位、横移、纵移）转为 PS/2 三字之包（纵移反之），书于同一鼠环，执行器仍依 PS/2 之包解之。PS/2 之途（十月十一日起为豫言内核之「键盘收入」）与务三十六之初置先读状态之口，得 0xFF（无 PS/2 控器）则略之，鼠环惟有真字。QEMU 实试：`-device usb-mouse,bus=xhci.0` 与默认 PS/2 之鼠并存，USB 鼠点开“系统设置”；`-machine i8042=off` 惟接 usb-kbd 与 usb-mouse（如林檎笔记本，无 PS/2），USB 键盘打字入桌面，USB 鼠点“返回命令行”还壳、复入桌面点“任务管理器”皆正，鼠环之字数恰为报数之三倍；开机后 `device_add usb-mouse` 热插之鼠得新槽，亦可用。十月十一日起报告片惟验与重排，换包交豫言内核之「鼠标报告」（经跳表）：出四字之包，所收不下四字则第四字为滚轮（HID 前滚为正，反之乃同 PS/2）。非启动子类之鼠、usb-tablet 之绝对坐标与触控板之手势，俟诸后版。

**高分之屏倍之**（二〇二六年十月六日）：实机所试之屏二千五百六十乘千六百，一帧十六兆，执行器之堆不能容，入桌面则报“堆内存不足”（堆诊断：请求 16384016，页数 762/1024）。今核依帧缓之录现求倍数（外置区之「帧求倍」，果置于 r13）：宽逾千九百二十或高逾千二百则二，余则一。三十三返物理宽高除以倍；三十二之宽高上限随之减半，倍则每素书为二乘二：素既转，复为二份，以八字之存一书之，每行之素书二遍；涂黑之区亦乘二。执行器、桌面、光标与鼠标之坐标皆用逻辑之素，二千五百六十乘千六百之屏，桌面为千二百八十乘八百，一帧四兆。QEMU 用 OVMF 加 `-vga none -device VGA,xres=2560,yres=1600`，昔 Limine 择二千五百六十乘千六百，实测二秒入桌面，画满全屏，红蓝不误。

**桌面占屏**（二〇二六年十月十日）：交帧之式既合，像素之址非零则核书交者槽号加一于 `0x103A0C`，址零（还面而涂黑）则书零。此格非零，核控台之绘字（0x1F6000）解码之后径终：串口如故，屏不绘字、游标不移；故桌面占屏之际，核之诊（“任务陷阱…”“内存耗尽…”）、执行器之诊与子程径书控台之字惟入串口，不覆桌面。任务之终（退、陷、故障、见终皆经豫言内核之「清理任务」），此格为其槽所占则零之：图形之程未还面而终，壳之出犹上屏。桌面行于开机之壳，语言之异越显示控件之主循环，则主循环先还其面（清屏、清标）乃抛之，壳承其异而示如故。臂之开机参数 +2136 用同约（见[臂之平台](臂平台.文言.md)）。

**交区**（二〇二六年十月十日，提案 00011 第四步）：三十二号为四参之务（第三、四参经 edx、ecx，臂经 x2、x3），书画之一矩于帧缓。第四参零则全帧；否则区之宽高须正、全在画内，不然返负一。源自画之 (区左, 区上) 起，每行跨 宽乘四字；目自帧缓之 (区左, 区上) 起，倍则坐标乘二。兼容外置区入则先存 edx、ecx 于 r15、ebp（ecx 继为移位之数与红位），越界既验，依区移源、目之起，行数列数易为区高、区宽，源之行跨置于 r13（分一倍二倍之后，r13 即行跨）。臂之「提交帧服务」自帧取第三、四参，依区逐行拷之。像素之址为零（涂黑）则惟问宽高。执行器之裸机显示以之行显示接口零点八之「呈像素画面区域」：叠绘光标而先交其区，乃补交光标所在十二乘十九之小矩与前次交光标之位；指移则惟交此二小矩。六十四位址之构之执行器为画别开第三中转之缓，惟拷区所在之行；常构之执行器开机依帧缓之尺取影帧一块，每交之后拷区所在之行于其中，指移则以影帧补交光标（二〇二六年十月十一日起：应用所交之字常为每帧暂复者，见收之后其存或还于核或他用，旧则补交光标之旧位绘为黑块）。
