# USB 硬件里程碑

这是硬件支持方向的最小实施路线。现有 xHCI 已有 PCI 发现、固件交接、控制器启动、DMA 环、根端口复位、Enable Slot 与 Address Device 代码。现有持久文件系统使用 Virtio 块设备；裸机源码中尚未发现 AHCI、NVMe 驱动。

本次先验收首个直连根端口设备寻址：等待异步 Enable Slot 完成事件，避免只扫描一遍就判定失败；修正 Address Device 等待的事件回收目标，使 ERDP 写入运行寄存器基址加 `0x38`；独立保存等待预算，避免槽号与完成标记覆盖计数；从输出槽上下文原始双字读取槽状态，保留 USB 地址。实现仍使用现有诊断区，不新增 ABI。

集成位置是裸机后端的 `兼汇编。豫` 中 `兼容根端口扫描`。`0x1039B0` 为寻址状态（0 未尝试、1 等待、2 成功、3 失败），`0x1039B4` 为命令完成码，`0x1039B8` 为完成槽号，`0x1039BC` 为 USB 地址，`0x1039C0` 为槽状态，`0x1039C4` 为 EP0 状态。控制器运行寄存器基址保存在 `0x10395C`，事件环软件出队指针保存在 `0x10399C`，二者必须分开。

`兼容核心。豫` 的 BAR 映射检查忽略共享 PDPT 项的已访问位：帧缓冲先访问该目录后，硬件会置此位，目录仍然有效。原有逐位比较会跳过 BAR 映射，使后续控制器启动访问未映射地址。

控制器复位保留“内存位图已初始化”检查，去掉以位图第零位为退出条件的旧检查；第零位是内核保留块，正常启动恒置位。旧检查使控制器未复位就换用内核 DMA 环，固件的设备槽仍占据端口，Address Device 返回 TRB Error。

64 位 BAR 的高地址校验从 PCI 记录 `0x103948` 读取 BAR0 高双字；原代码误读 `0x103940` 的设备类码，导致正常的 64 位 BAR 也跳过复位。上述两个复位条件须一并修正。

后续顺序：配置直连 HID boot 键盘并接入现有字符收入；再在存储方向选择 AHCI 或 USB 大容量存储，将读写接入现有文件系统。新增接口或 ABI 须先另行确认。

EP0 控制传输先取设备描述符前 8 字节：在 `0x07C01000` 放置 Setup、IN Data、OUT Status 三个 TRB，数据写入 `0x07C02000`，仅 Status 请求完成事件。它验证描述符头的长度与类型，记录 USB 版本、设备类码和 EP0 包大小；随后需按包大小更新上下文，再读取完整设备描述符与配置。内部状态 `0x1039C8` 取 0 未试、1 等待、2 成功、3 失败；`0x1039CC` 为完成码、`0x1039D0` 为前四字节、`0x1039D8` 为读取字节数、`0x1039DC` 为第 4～7 字节。该状态区止于中文解码状态 `0x1039E0` 之前，并避开 PS/2 初置标记 `0x1039F8`。

本次未实施鼠标、显示模式切换、网络、音频、ACPI、多核、AHCI、NVMe、USB 大容量传输或完整 HID 输入。待办事项：64 字节上下文、多设备与集线器拓扑、热插拔须另行实现。QEMU 验证不能代替 ThinkPad E40 与其他实体机实测。

寻址与事件回收依据 [Intel xHCI 1.2 规范](https://cdrdv2-public.intel.com/625472/625472_xHCI_Rev1_2b.pdf) §4.6.5、§4.9.4、§5.5.2.3.3。

## 报告处理片与接入约定

报告处理片位于 `0x1F7000`，镜像偏移 `0xF7000`，保留 8 KiB，字体从 `0x1F9000` 起。实际连接测得报告片 993 字节、前方绘字片 1571 字节；镜像生成时检查报告与绘字区间，避免相互覆盖。该入口无参数、无返回值，保存标志及 RAX、RCX、RDX、RBX、RSI、RDI、R9、R10。它只处理当前出队位置上周回位、Transfer 类型、槽号、端点号、请求地址均匹配，且成功传完八字节的报告；非匹配事件不改变状态，出队指针、周回位及 ERDP 仍由原轮询维护。键盘实际槽号在端点初始化时从寻址诊断复制到独立 DMA `0x07C08070`，避免旧命令状态字段的用途冲突。

处理片比较前后六个 usage，仅将新按下的键写入既有字符收入环；支持字母、数字、常用标点、Shift/Caps、Ctrl 字母、Enter、Esc、退格、Tab、F2、方向、Home、End、Delete，并重排下一报告。DMA 偏移 100、104、108 分别保存报告数、最后报告完成码、Caps 状态；前一报告在 `0x07C02810`。事件确认前的调用由终端会话接入：外层保存 RAX，以 RAX 调用 `0x1F7000` 后恢复，原有事件逻辑继续执行。本阶段已通过机器片连接与布局测量，轮询调用及实际连续输入尚待验收。待办事项：自动重复、LED、错误恢复、多设备与热插拔另行实现。

EHCI 根端口复位：异步调度启动后，从 HCSPARAMS 取端口数，复位首个已连接端口。加电等待 800 微帧（100 毫秒），复位保持 400 微帧（50 毫秒），释放后等待 80 微帧（10 毫秒）；FRINDEX 差值按 14 位周回计算，PORTSC 写入清 W1C 与 PE 位。私有记录 `0x07C02000` 保存端口号，下一字保存最终 PORTSC。

沿用 Q35、Penryn、512 MiB、单核、TCG、关闭 PS/2、光驱启动，挂单个 `ich9-usb-ehci1` 和只读高速 USB 存储。BIOS 与 OVMF UEFI 均入壳；两路诊断为 17，记录端口 1、PORTSC=`0x1005`，确认 CCS=1、PE=1、PR=0。此项尚未读取设备描述符，不计 USB 数据传输、文件读写或实体机成功。ISO SHA256 为 `228de198f5d7214b059d22ddb0c74612f3d78bb8c25fa67ae1988952b45a46ae`；低全速伴随控制器、多端口与集线器仍待。

EHCI 异步空队列：预留物理块 30、31，清零私有 DMA 区，在 `0x07C00000` 建立无 qTD 的自环 QH，启用 PCI Memory Space、Bus Master 与异步调度。Q35、Penryn、512 MiB、单核、TCG、关闭 PS/2、仅 `ich9-usb-ehci1`，同一光驱 ISO 经 BIOS 与 OVMF UEFI 均入壳并正常退出。两路诊断为 15，USBCMD=`0x00080021`、USBSTS=`0x00008008`，ASS=1、HCHalted=0、Host System Error=0，ASYNCLISTADDR=`0x07C00000`；QH 为 `07C00002 4040E000 40000000 00000000 00000001 00000001 00000000 00000000`。初置及调度类型检查通过，ISO SHA256 为 `efc5f7efc1bfdf49e5ad7f8550e4f08738847ba10631c203b6c34a6c55a180f8`。此验无设备请求；EP0、周期调度、双控制器、集线器、键盘及块设备传输仍待。

鼠标可在键盘报告链完成后复用 HID 枚举和中断传输，但要另行处理鼠标协议、坐标与按键。显示已有引导器选择的直接 RGB、32 位帧缓冲映射和绘字，尚未实现运行时模式切换。`客体二号/裸机底层网络。豫` 在裸机路径返回不支持；网络需要网卡驱动和网络栈。音频模型只用于 EP0 枚举验收，音频流未实施。裸机后端源码尚未发现 ACPI 表解析与多核启动实现，现有硬件验收均为单核。这些项目仅作评估，未在本轮新增功能。
