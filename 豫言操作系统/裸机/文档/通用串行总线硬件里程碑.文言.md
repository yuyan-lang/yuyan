## 二构共用之扩展主控之驱（二〇二六年十月十一日）

兼之扩展主控（xHCI）改用豫言内核中二构共用之驱 `内核/扩展主控。底层。豫`（原臂之 `键鼠。底层。豫`），以代手书者；键盘、鼠标（含滚轮之字）、U 盘皆归之。开机初置 USB，手书之核先经「扩展主控开机」呼之：得扩展主控而初置成，则略手书之根端入口与开机之诊，`『控台收入』` 经「扩展主控轮询」理其事；无扩展主控（惟 EHCI）则由增强主控之驱接管（见下文“二构共用之增强主控驱”）。驱之要：兼以端口之原语「端口读四」「端口写四」读书 PCI 配置空间；寄存器映于共享页目录 `0x11F000` 第五百一十一项（虚址 `0xBFE00000` 起，不可缓存）；环、上下文与 U 盘之缓置于旧池二块（物址 `0x7C00000` 起，诸址空间恒等）；受固件之 USB 遗留支持而关其 SMI；根端口编址败则候百毫秒复试，至多三次；根端口之连接有变，则于巡中复编址或释槽；候命令与传输之际，键鼠之报照理之。U 盘行 bulk-only：TEST UNIT READY、READ CAPACITY(10)，依 ext4 超级块于盘首或六十四兆之一至十六倍处寻数据区，READ(10)、WRITE(10) 一命至多二千零四十八扇（超速之器；余二百四十），SYNCHRONIZE CACHE(10) 报命败亦视为成。服务二十九、三十改为三参（扇、线性之址、长为五百一十二之倍），核径与呼者线性内存相拷，见客体二号平台接口规范“持久块服务”。兼之内核之模之址自 `0x1C0000` 移于 `0x1A4000`（容二百八十八 KiB，驱加 U 盘后约百五十八 KiB）。

此役先验首个直连根端设备寻址：候异步 Enable Slot 完事，免一巡即判其败；正 Address Device 待命之事件回收目标，使 ERDP 写于运行寄存器基址加 `0x38`；别存待命之数，免槽号与完毕标志覆之；槽态取自输出槽上下文原始双字，USB 地址仍存。循既有诊断区，不增 ABI。

集成在裸机后端 `兼汇编。豫` 之 `兼容根端口扫描`。`0x1039B0` 为寻址态（0 未试、1 待命、2 成、3 败），`0x1039B4` 为完码，`0x1039B8` 为完成槽号，`0x1039BC` 为 USB 地址，`0x1039C0` 为槽态，`0x1039C4` 为 EP0 态。控器运行寄存器基址存于 `0x10395C`，事件环软件出队指针存于 `0x10399C`，二者须别。

`兼容核心。豫` 验 BAR 映射，略共享 PDPT 项已访问位：帧缓冲先访其目录，硬件置此位，目录犹有效。旧逐位之验略过 BAR 映射，使后启控器访未映之址。

控器复位仍验内存位图已初置，去以首位为退出之旧验；首位属内核保留块，正常启时恒置。旧验使控器未复位而易内核 DMA 环，固件设备槽犹占其端，Address Device 回 TRB Error。

六十四位 BAR 高址之验，从 PCI 记录 `0x103948` 取 BAR0 高双字；旧码误读 `0x103940` 设备类码，使正常六十四位 BAR 亦略复位。前述二条件须俱正。

后续之序：置直连 HID boot 键盘，接既有字符收入；继于 AHCI 与 USB 大容量存储中择其一路，接读写于既有文件系统。欲增接口或 ABI，须先别请。

EP0 控制传输先取设备描述符前八字节：于 `0x07C01000` 置 Setup、IN Data、OUT Status 三 TRB，数据入 `0x07C02000`，唯 Status 请完事。验描述符首之长与类，记 USB 版本、设备类码及 EP0 包长；继须循包长更上下文，乃取全设备描述符与配置。内部态 `0x1039C8` 以零为未试、一为待、二为成、三为败；`0x1039CC` 记完码、`0x1039D0` 记前四字节、`0x1039D8` 记所取字节数、`0x1039DC` 记第四至第七字节。此区止于中文解码态 `0x1039E0` 之前，亦避 PS/2 初置之记 `0x1039F8`。

此役未作鼠标、显示模式切换、网络、音频、ACPI、多核、AHCI、NVMe、USB 大容量传输及完整 HID 收入。待办事项：六十四字节上下文、多器与集线器拓扑、热插拔，皆须别作。QEMU 之验，不代 ThinkPad E40 及他实体机之验。

## 二构共用之增强主控驱（二〇二六年十月十三日）

EHCI（USB 二点零）主控改用豫言内核中二构共用之驱 `内核/增强主控。底层。豫`（驱号五，「设备列表」称“增强主控”），以代惟兼有之手书机器码者（`裸机后端` 之二十四 `增强*。豫` 与 `兼容核心。豫` 中之呼处皆已删，其昔日之验录存于 git 之史，末含手书 EHCI 之提交为 `c95e1d8a9`）。

USB 设备之层 `通用串行` 与键鼠、存储、集线器诸类驱不分主控：类驱仍书命令为 xHCI 式之 TRB 环与端点上下文，薄分派层 `内核/主控分派。底层。豫` 于增强主控在用时，以控传、编址、释放槽、配端点、按铃、发令、取事件等转授增强主控；增强主控化环中新书之 TRB 为 qTD 链，挂于异步调度之队列头，成则书为与 xHCI 同构之传输事，类驱之源不必易。

- 启：无 xHCI 则设备之层启之；依外设互连之序，寻类码 0x0C0320 之主控，至多启二实例（ThinkPad E40 有二 EHCI），诸实例之根端口依次连编为设备层所见之逻辑口（实例零之口自一起），共用块甲、块乙（与扩展主控同，二兆，四 GiB 之下）与设备槽（槽态记其所属之实例）。
- 启之法：开访存与主控，经「设备控块授权」授之（臂之 SMMU 所需），循 HCCPARAMS 之 EECP 链自 BIOS 受 USB 之所有（USBLEGSUP），停之、复位之，设异步环（自环之头队列头加一哨兵 qTD）而行之（惟开异步调度，不开中断），置 CONFIGFLAG 使诸口路由于增强主控，诸口上电。
- 传：控制与批量走异步调度之队列头与 qTD，中断端点于设备层巡时当异步传输为之；数据翻位由软件记之；高速集线器后之全速、低速设备带集线器之址与口号，由集线器之事务转换器行分割事务。
- 热插拔：口态之变于巡中察之，继而复编址或释槽。
- 屏上之诊：开机时每实例印一行“增强主控 序 位置 标 栏 口”（成）或“增强主控 败 步 位置”（败，步一至五见源注），每有设备之根端口印“增强主控 口 果”（果一为高速设备，二为交伴随控制器，全一为败）；诸行经控台字节上屏亦入串口，其后乃通用串行层所印之集线器行、设备行与存储行。
- 待办事项：伴随控制器（UHCI/OHCI，全速、低速设备直接接根端口者赖之），周期调度与中断，一端点同时多提交，六十四位址，逾二增强主控，二主控并存，网卡类驱于增强主控。

验（二〇二六年十月十三日，QEMU 十一点一点一，惟接 `usb-ehci` 而不接 xHCI，U 盘与 `usb-kbd` 接于 EHCI）：

- 兼（pit-pc-ubuntu，KVM，q35、SeaBIOS）与臂（hvf，UEFI，SMMU v3）开机皆入命令壳；键盘（监视器 sendkey）入壳；「设备列表」列增强主控、大容量存储与键盘，皆为已驱；`「文件」之「写入」`、`「读取」` 经 EHCI 上之数据区（一百九十二兆处）往返无误；`usb-kbd` 之 `device_add`、`device_del` 能增减设备；同一 EHCI 再接 `usb-mouse`、`usb-tablet`，键盘、鼠标可用（数位板无类驱）。
- 二 `usb-ehci`：U 盘、键盘分居二控制器，两种排布（U 盘在前或在后）于二构皆能开机、输入、读写文件；设备列表中二增强主控各一行，逻辑口自一与自七起。
- 有 xHCI 之原途如常：`qemu-xhci` 加 U 盘与键盘，二构之设备列表为扩展主控，文件读写与键盘输入无误；兼 BIOS 与 UEFI（OVMF）冒烟过。
- 集线器：QEMU 之 `usb-hub` 惟有全速之描述，不能接 EHCI 之根端口（报 speed mismatch），QEMU 之 EHCI 亦不拟分割事务，故集线器后之设备（ThinkPad E40 诸外部设备皆在速率匹配集线器后）与事务转换惟实机可验；集线器之枚举、诸口上电与复位，走设备层中与 xHCI 共用之码。

## E40 实体资料

Lenovo [旧机型 PSREF](https://psrefstuff.lenovo.com/syspool/Sys/PDF/withdrawnbook/lslwbook.pdf)中，Edge 14 之 Intel 0578 配置列 HM55、USB 2.0 及 SATA 磁盘；[Intel 五系列/3400 系列数据手册](https://www.intel.com/content/dam/www/public/us/en/documents/datasheets/5-chipset-3400-chipset-datasheet.pdf)列 EHCI 控器及集成 SATA/AHCI。用户所供 Windows 十照片，证 Type 0579-4PC 之 E40 有 Intel USB Enhanced Host Controller 二（3B34、3B3C），SATA AHCI 为 `8086:3B29`，Generic USB Hub 为 `8087:0020`（速率匹配集线器）。实机所测（二〇二六年十月十三日）：3b34 在 `00:1d.0`、3b3c 在 `00:1a.0`，皆惟经各自之速率匹配集线器（USB 二之集线器，接于根端口一）接外器，无伴随控制器，故 U 盘与键盘必在此集线器之后；高速 U 盘在其后不须事务转换，全速、低速键盘则须。E40 实机之验收见 `持续改进目标/裸机实机.md`。
