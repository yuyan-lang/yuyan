# 终端编辑与输入法

此中文交互壳之逐字编辑也。常入、退字、取史，皆于原提示行重绘；游标之左右各存 UTF-8 字，汉字择定则入于标处。Tab 于标在末且不组字时循正式句式之位补全；十月二十二日起行内组字惟列此串拼音之普通字词，不复先筛当位已知名（独打 `?` 展全选如故），所择之字词原样插于标处，详《智能命令》。候选去重，存初见之位，重字不占易页之位。

## 键之约

嵌套引号镜像为 `嵌套引号验收/豫言启动.iso`，SHA-256 为 `397984df6eb0d409a4457cdc3a8f02447ebc093cb095e3cc031d027e3c84998b`，壳长四十六万六千四百一十三字节；循 `36aa076c4` 基线之系统工具。源码逐键回归验外未闭、内闭、外闭后复开、第三层交替，及越两种既有闭引。QEMU Penryn、Q35、xHCI、512 MiB、禁 PS/2，BIOS USB 键盘入 `hx`、`1` 后，连按 Shift+[、Shift+[、Shift+]、Shift+]，成 `「回显」于「『』」`；复按 Shift+[ 得新 `「`，退字去之而回车出 `『』`。正式退后虚拟机以三十三退，日志为同目录 `嵌套引号USB.log`。今轮未复验 UEFI。

默认中文镜像为 `默认中文验收/豫言启动.iso`，SHA-256 为 `27f306e0b895eff80660b2c58d2f93e34b3b534d3aa9d5eccbae96152b814ef6`，壳长四十六万一千一百六十七字节；复用固定 `36aa076c4` 基线之系统工具。QEMU Penryn、Q35、xHCI、512 MiB，禁 PS/2，串口惟书日志，由全速 USB 键盘实验 `hx`、`1`、Shift+[、`ni`、`2`、Shift+]、回车，出“呢”；Shift+] 越右侧既有闭引，参遂正闭。又验 `j`、`1`、`12`、Tab、`3`、Tab、回车出 `15`，证择词后数字复为实参；`tc`、`1`、回车正式退，虚拟机以三十三退。日志为同目录 `默认中文USB.log`。今轮未复验 UEFI。

恒以中文组字（十月十日起罢中英之易，F2 与 Ctrl-R 不复易之）：字母径书于输入之行，标前相续之 ASCII 字母即拼音，每打一字母则依此串重算候选，有候选则别起一行印候选之行。有候选者，候选每页标一至九，数键直择当页，以所择之字词代此串字母；空格或回车择首，Tab 或 = 翻次页，- 翻前页（首尾相循，候选逾一页则行末示“=/- 翻页 今页/总页”，十月六日起）。无候选则数键、空格、= 与 - 如常入，回车行此行。退格如常删字，拼音随短。Esc 留此拼音为英文于行，不复出候选，后打之字母别起一段拼音（壳记拼音起点，惟计起点之后之字母；移标、取史、补全与择字亦移起点于标处）。`?` 如字母书于行、计于拼音，为通配，合任一段（可空）：独打 `?` 则展当位诸已知之选，候选行书“当前位置全部选项”，择、翻页同上；`tu?` 之属依通配给候选；按 Esc 则此串（含 `?`）亦作英文留之，欲入 `?` 本字，打 `?` 而按 Esc；独打 `?` 而当位无已知之选则示一行，`?` 留于行（十月十一日起，见《智能命令》）。Shift+[ 循标左未闭之引而易：外用 `「`，其未闭则内用 `『`，外既闭则复用 `「`；更深者交替。Shift+] 闭当层；右已有同闭引则越之；未择之拼音作英文留于引前；方入之 `{ }` 后紧按 Esc，则易回 ASCII 之 `{` 或 `}`（十月十一日起）。嵌套引号之源码逐键回归已成，镜像之验见本节。

固定合并基线 yybs `36aa076c4` 之 BIOS/UEFI USB 键盘之验已成：禁 PS/2，串口惟书日志，两路验参之定与行、游标之移、删除、历史草稿之复及当时之 F2 续组（十月十日起无 F2 之易）。镜像校验值、逐键所及与日志所在，见[智能命令](智能命令.文言.md)。长句分词、词频与字体选择犹循下策，待择施行之次。

终端取键之接口如故。输入环依序送字节，壳识串口常序：上、下、右、左各为 `ESC [ A`、`ESC [ B`、`ESC [ C`、`ESC [ D`；首、尾为 `ESC [ H`、`ESC [ F`。亦受 Ctrl-P/N/F/B/A/E；Ctrl-D 去标右一字，退格去左一字。Esc 留标前之拼音为英文而收候选；紧于 `{ }` 之后则易角引回 ASCII 之 `{ }`（逐字而至之方向键以 ESC 起，紧于 `{ }` 后按方向键亦如是，留待后版）。不识之全转义键（如独按修饰之键）皆不理；F2 与 Ctrl-R（码十八）亦不理。硬件之事主扩展扫描码转此序；报告处理片由旧轮询中九字节调用接入，取键之接口与应用 ABI 皆循旧约。

史惟存于当会，至多 10001 行；上取前命，下取后命，归最新之位则复始取史时之草稿。空行不录。择字、易页、退字如故；方组字，先由输入法处之，方向诸键付编辑而留拼音为英文。

## 今之范围与后议

原行重绘以旧回车输出及空格覆余字，宽依今字模：ASCII 一格，余字二格。待办事项：越屏宽之跨行编辑待补。末重写左文以定标位；十月二十二日（议题三百五十六）起重绘入行之后与印提示之后书一 NUL 之字为记，帧缓控台见之则于今标处绘二素宽、三十二素高之白竖线，桌面终端与串口由终端自示光标。

长句分词：后先以旧拼音字籍与常用词作最长匹配，不得者留组音供择，不增词籍格式。

分词之源码前提已核：`库/中书/拼音入。豫` 之常用词今为查询术之分支，字籍则列音节与字串。施前先整旧常用词为可枚举之豫言列，仍用旧词与字籍，不增外部词籍格式。惟已知名无匹配，乃入分词之回退；段段先取最长词，余拼音存待次一择字。同音词犹须择，回车惟定当候选，不径行命。预期之例：回显参 `nihaozhongguo` 分“你好”“中国”；`nihaoyuyan` 于“豫言”“语言”处待择；不识之尾音犹存其组。此皆待施之验例，未有分词实现与已过之果。

联想频度：后先于当会录择词之数，同数循旧序；久存之法另议。

频度惟于当位已筛候选中列序，不混他位之名与不匹配之词。先去重，再依本会确认之数列序，同数循旧序；惟确认乃计，易页、取消与提交命令不重计。名字索引缓存犹惟存名字与拼音，不存排序后之候选。预期之验有同音词复查、取消不计、已知候选与字词回退之先后、同数之序及新会清零。此为方案，未施频度学习。

择字体：两字体已随盘而载；行时易字模，须先察旧载入接口可复用否。若须增 ABI，先陈其缺与法而问之。

字体接口之可行已核：`字模生成/入口。豫` 以同一生成术出默认与思源字模，`豫言系统。豫` 载二者于介质，今启盘惟带默认字模。`库/裸机后端/字体模块。豫` 初置取首 Multiboot 模块，未循模块名择之。`宿主服务。接口。豫` 无控制台易字体之声明；旧可移植字体接口供只读字体之文，`客体二号/显示原语。底层。豫` 之字体路径向 macOS 系统字体文件，不可据此谓控制台可易字体。

最小候选之法为启时择默认或思源字模，复用首模块装载之约，先不增应用 ABI。用户既择，乃造相应启动配置，核字模之长、字形之备与 BIOS/UEFI 之显。壳内行时之易，别须议控制台服务与授权，不径写内核字体状态地址以代接口。今轮惟核源码而定候选之法，未行字体选择。

此三者后议也，今未施。E40 新中文编辑须用户亲验于实机。

## 所验

壳之类型检查与链接皆成；交互编辑测试于节点宿主运行而成，验汉字左右与首尾移动、右字之删、命史之界与草稿之复、候选之序与真拼音候选去重、方位键序及字格宽。所改豫言之篇皆已排版。

借基础中文会话之系统工具造持久盘镜像，报“镜像片段重叠”；无盘混合 ISO 成，而 QEMU Penryn、Q35、xHCI、BIOS USB 启动报“裸机核验失败”，未入壳。客体执行器与基础中文验收版逐字节同。今源系统工具之重构，因先提交与同步之命而止；启动之败因未明，此 ISO 不得列为已验之版。未行全仓测试，未验 E40 实机。

同步 yybs 之冲突已逐项合之，存 Shift/Caps、xHCI 巡事、E40 初置与无 COM1 之 FF 验；初置之记徙于 `0x1039F8`，修饰之态仍居 `0x10392C`。同步后壳之构与交互编辑测试皆成，所涉控台及依赖类型检查亦成；全后端逐篇之检查因久而止，不记全成。实机器片测试成，普通核心长 10686、隔离核心长 11093 字节，皆未及 GDT 前 12608 字节之界。

硬件会话已明首次启动之败出于 PDPT Accessed 位之验，并于独立修复版证 QEMU 启动复成；此修复由硬件之事提交验之，本事不重录，亦未称整套新镜像已验。

## 合并镜像交互之验

2026-10-03，据终端编辑与硬件修复俱存之 `479672fc1` 基线，重构系统工具、客体执行器与壳，成 `终端合并验收/豫言启动.iso`。SHA-256 为 `3b75aa2fa56ca0b6a7e4076cbabc287eab865c4cfabb24893cb7f0a7009bb349`。今轮新命令位置之篇未接入壳，故此验惟证今编辑之能。

QEMU Penryn、Q35、xHCI、512 MiB、USB 盘，循 SeaBIOS 与 OVMF UEFI 两路，皆入壳。串口逐键而入，核其果：

| 所行 | BIOS 与 UEFI 之果 |
| --- | --- |
| 入 `echo ab`，左移，间入 `x`，回车 | `axb` |
| 上键取前命，回车 | 复出 `axb` |
| 入草稿 `echo draft`，上取史，下复草，回车 | `draft` |
| F2 入 `ni` 择“你”，左移入 `hao` 择“好”，F2 易英文，End，回车 | `好你`，候选“你”惟见一次 |
| 入 `echo abc`，左移二次，Ctrl-D 删右字，退格删左字，入 `x`，End，回车 | `xc` |
| 入 `exit` | “壳已退出”“用户任务全部退出” |

UEFI 别验 `echo ab` 左移入 `x`、右移入 `y`，得 `axby`；`echo home` 经 Home、End，仍得 `home`。逐键串口之出可见原行回车重绘，候选犹别行而示。此验串口之入与执行之果，未增 PS/2 扩展键映射，未验帧缓闪烁之标。无盘启路未验文件久存，全仓与 E40 实机犹未验。旧失败之 ISO，不列今轮候选。

## 正式句式与当位组字镜像验收

二〇二六年十月三日，自含硬件全描述符之修与正式句式入口之源码重构系统工具、启动介质，兼今轮 F2 组字之合。镜像为 `正式命令验收/豫言启动.iso`，SHA-256 为 `4d9fd25413ce3ea365832d5799416b912277d4be589151cba84ceda5252dadf9`。

QEMU Penryn、Q35、xHCI、512 MiB、USB 盘，由 SeaBIOS 与 OVMF UEFI 两路皆入正式壳。两路逐键验：英文 `hx` 按 Tab 成 `「回显」于`，`nihao` 按 Tab 退为“你好”，回车出“你好”；F2 之 `hx` 惟列已知“回显”，择后 `ni`、`hao` 两次组字，终出“你好”；上取命史，再出“你好”；正式退出皆示“壳已退出”“用户任务全部退出”。BIOS 别验 `nihao` 一次组词；正式回显中插字得 `axb`；文件成员 `dq` 列“当前”“读取”二项，以数二择成 `「案牍」之「阅」于`，缺参提交则告错。

UEFI 别验 `「回显」于「正文 于 甲 | >」`，原文悉出，引内符号不作连接词与管道；`abc` 自行末左移二次、Ctrl-D、退格、插 `x`、End，出 `ax`。此证新镜像串口之编辑、候选与正式执行，未证文件久存、实键盘扩展键、帧缓闪烁之标及 E40 实机。两验收虚拟机皆已退出。
