# 终端编辑与输入法

此中文交互壳之逐字编辑也。常入、退字、取史，皆于原提示行重绘；游标之左右各存 UTF-8 字，汉字择定则入于标处。Tab 补命仍限未带参且标在末之命。拼音候选合而去重，存初见之位，常用词字仍先，重字不占易页之位。

## 键之约

终端取键之接口如故。输入环依序送字节，壳识串口常序：上、下、右、左各为 `ESC [ A`、`ESC [ B`、`ESC [ C`、`ESC [ D`；首、尾为 `ESC [ H`、`ESC [ F`。亦受 Ctrl-P/N/F/B/A/E；Ctrl-D 去标右一字，退格去左一字。Esc 即取消候选或组音。硬件之事主扩展扫描码转此序，本事不改控台驱动，不增 ABI。

史惟存于当会，至多 10001 行；上取前命，下取后命，归最新之位则复始取史时之草稿。空行不录。F2、择字、易页、组音退字如故；组音未定，先由输入法处之。

## 今之范围与后议

原行重绘以旧回车输出及空格覆余字，宽依今字模：ASCII 一格，余字二格。待办事项：越屏宽之跨行编辑待补。末重写左文以定标位，今帧缓未有闪烁之标。

长句分词：后先以旧拼音字籍与常用词作最长匹配，不得者留组音供择，不增词籍格式。

联想频度：后先于当会录择词之数，同数循旧序；久存之法另议。

择字体：两字体已随盘而载；行时易字模，须先察旧载入接口可复用否。若须增 ABI，先陈其缺与法而问之。

此三者后议也，今未施。E40 新中文编辑须用户亲验于实机。

## 所验

壳之类型检查与链接皆成；交互编辑测试于节点宿主运行而成，验汉字左右与首尾移动、右字之删、命史之界与草稿之复、候选之序与真拼音候选去重、方位键序及字格宽。所改豫言之篇皆已排版。

借基础中文会话之系统工具造持久盘镜像，报“镜像片段重叠”；无盘混合 ISO 成，而 QEMU Penryn、Q35、xHCI、BIOS USB 启动报“裸机核验失败”，未入壳。客体执行器与基础中文验收版逐字节同。今源系统工具之重构，因先提交与同步之命而止；启动之败因未明，此 ISO 不得列为已验之版。未行全仓测试，未验 E40 实机。

同步 yybs 之冲突已逐项合之，存 Shift/Caps、xHCI 巡事、E40 初置与无 COM1 之 FF 验；初置之记徙于 `0x1039F8`，修饰之态仍居 `0x10392C`。同步后壳之构与交互编辑测试皆成，所涉控台及依赖类型检查亦成；全后端逐篇之检查因久而止，不记全成。实机器片测试成，普通核心长 10686、隔离核心长 11093 字节，皆未及 GDT 前 12608 字节之界。

硬件会话已明首次启动之败出于 PDPT Accessed 位之验，并于独立修复版证 QEMU 启动复成；此修复由硬件之事提交验之，本事不重录，亦未称整套新镜像已验。

## 合并镜像交互之验

2026-10-03，据终端编辑与硬件修复俱存之 `479672fc1` 基线，重构系统工具、客体执行器与壳，成 `yy终端合并验收/yy豫言启动.iso`。SHA-256 为 `3b75aa2fa56ca0b6a7e4076cbabc287eab865c4cfabb24893cb7f0a7009bb349`。今轮新命令位置之篇未接入壳，故此验惟证今编辑之能。

QEMU Penryn、Q35、xHCI、512 MiB、USB 盘，循 SeaBIOS 与 OVMF UEFI 两路，皆入壳。串口逐键而入，核其果：

| 所行 | BIOS 与 UEFI 之果 |
| --- | --- |
| 入 `echo ab`，左移，间入 `x`，回车 | `axb` |
| 上键取前命，回车 | 复出 `axb` |
| 入草稿 `echo draft`，上取史，下复草，回车 | `draft` |
| F2 入 `ni` 择“你”，左移入 `hao` 择“好”，F2 易英文，End，回车 | `好你`，候选“你”惟见一次 |
| 入 `echo abc`，左移二次，Ctrl-D 删右字，退格删左字，入 `x`，End，回车 | `xc` |
| 入 `exit` | “壳已退出”“用户任务全部退出” |

UEFI 别验 `echo ab` 左移入 `x`、右移入 `y`，得 `axby`；`echo home` 经 Home、End，仍得 `home`。逐键串口之出可见原行回车重绘，候选犹别行而示。此验串口之入与执行之果，未增 PS/2 扩展键映射，未验帧缓闪烁之标。无盘启路未验文件久存，全仓与 E40 实机犹未验。旧失败之 ISO，不列今轮候选。
