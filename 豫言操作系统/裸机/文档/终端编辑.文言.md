# 终端编辑与输入法

此中文交互壳之逐字编辑也。常入、退字、取史，皆于原提示行重绘；游标之左右各存 UTF-8 字，汉字择定则入于标处。Tab 补命仍限未带参且标在末之命。拼音候选合而去重，存初见之位，常用词字仍先，重字不占易页之位。

## 键之约

终端取键之接口如故。输入环依序送字节，壳识串口常序：上、下、右、左各为 `ESC [ A`、`ESC [ B`、`ESC [ C`、`ESC [ D`；首、尾为 `ESC [ H`、`ESC [ F`。亦受 Ctrl-P/N/F/B/A/E；Ctrl-D 去标右一字，退格去左一字。Esc 即取消候选或组音。硬件之事主扩展扫描码转此序，本事不改控台驱动，不增 ABI。

史惟存于当会，至多 10001 行；上取前命，下取后命，归最新之位则复始取史时之草稿。空行不录。F2、择字、易页、组音退字如故；组音未定，先由输入法处之。

## 今之范围与后议

原行重绘以旧回车输出及空格覆余字，宽依今字模：ASCII 一格，余字二格。待办事项：越屏宽之跨行编辑待补。末重写左文以定标位，今帧缓未有闪烁之标。

长句分词：后先以旧拼音字籍与常用词作最长匹配，不得者留组音供择，不增词籍格式。

联想频度：后先于当会录择词之数，同数循旧序；久存之法另议。

择字体：两字体已随盘而载；行时易字模，须先察旧载入接口可复用否。若须增 ABI，先陈其缺与法而问之。

此三者后议也，今未施。E40 新中文编辑须用户亲验于实机。

## 所验

壳之类型检查与链接皆成；交互编辑测试于节点宿主运行而成，验汉字左右与首尾移动、右字之删、命史之界与草稿之复、候选之序与真拼音候选去重、方位键序及字格宽。所改豫言之篇皆已排版。

借基础中文会话之系统工具造持久盘镜像，报“镜像片段重叠”；无盘混合 ISO 成，而 QEMU Penryn、Q35、xHCI、BIOS USB 启动报“裸机核验失败”，未入壳。客体执行器与基础中文验收版逐字节同。今源系统工具之重构，因先提交与同步之命而止；启动之败因未明，此 ISO 不得列为已验之版。未行全仓测试，未验 E40 实机。
