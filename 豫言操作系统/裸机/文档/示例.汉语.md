# 示例：在豫言操作系统里运行程序

下列原生示例输出保留此前验证基线。当前共用壳在Node已使用全中文用户态启动提示，并通过公共子程序接口运行具名授权程序；原生对应公共接口仍待绑定，完整原生示例复验尚未完成。

`豫言操作系统/裸机/示例/` 是一棵可以直接放进磁盘的目录树：`程序/` 下是几个普通豫言程序，`数据/` 下是它们要读的文件。壳测试 `示例` 用符号链接把它当作预置树，所以这里的每个程序都在两个架构的 QEMU 里逐字验证过输出。

## 运行

```sh
./豫构。林檎。豫行 目标 造盘工具 -j 24
./豫言系统。林檎。豫行 运行 --预置 豫言操作系统/裸机/示例
```

`--预置` 指向的目录树整棵放进磁盘（缺省就是本目录 `豫言操作系统/裸机/示例`，写 `--预置 无` 得空盘（一块空的 ext4）；盘缺省 65536 个扇区即 32 MiB，ext4 扣去元数据与 4 MiB 日志后能存约 27 MiB，程序多了用 `--盘容量` 加大）；树里以 `。豫` 结尾的源文件由编译器直出成豫行文件（没有后缀：`程序/你好。豫` 成 `/程序/你好`，脚本 `程序/回声。脚本。豫` 成 `/程序/回声`）。系统由「运行」造好启动盘后在 QEMU 里从 U 盘引导。启动后在壳里用 `运行 路径 参数…` 启动程序，用 `退出` 关掉系统：

```
正在启动豫言命令壳 / Starting Yuyan shell...
内核与基本设备已就绪 / Kernel and base devices are ready.
命令壳已就绪 / Shell ready.
Welcome to Yuyan Operation system
壳就绪
壳> 运行 /程序/你好 豫言 操作系统
你好，豫言、操作系统！
壳> 运行 /程序/统计 /数据/文本.txt
文件：/数据/文本.txt
字节：132
行数：5
词数：8
壳> 运行 /程序/质数 30 > /质数.txt
壳> 读 /质数.txt
```

启动信息的中文全文从串口输出；帧缓目前只画 ASCII，因此图形屏幕显示对应英文提示。临时键盘验收命令为 `tmp-help`、`tmp-echo 文字`、`tmp-exit`，后续可单独删除。

## 程序

| 程序 | 作用 | 展示的能力 |
|---|---|---|
| `你好` | 向每个参数问好，没有参数则问候“世界” | 命令行参数、标准输出 |
| `回声` | 每个参数打印一行 | 命令行参数 |
| `质数 [N]` | 列出不超过 N（默认 50）的质数 | 递归与整数运算 |
| `斐波那契 [N]` | 打印前 N（默认 10）项 | 尾递归（栈不增长） |
| `统计 [文件]` | 打印文件的字节数、行数、词数（默认 `/数据/文本.txt`） | **子进程读文件**（由初始任务代办） |
| `复制文件 源 目标` | 按字节复制文件，二进制也不损坏 | 子进程读写文件、错误处理 |
| `行数` | 从标准输入逐行读到结束，打印每行的序号与内容和总行数 | **标准输入重定向**（`运行 … < 文件` 或管道），`闻` 遇文件结束返回阴 |
| `环境变量 名…` | 打印每个参数名对应的环境变量的值（没设置则说明未设置） | **环境变量**（壳的 `设` 命令给出），`问俗` |
| `死循环` | 打印 “死循环开始” 后永远空转（尾递归循环） | **Ctrl-C**：运行后按 Ctrl-C，执行器以退出码 130 结束它 |
| `日期检查` | 读实时钟，检查 `今时` 形如 `YYYY-MM-DD hh:mm:ss`，打印年月日与小时 | **实时钟**（内核墙钟服务，UTC）；壳的 `日期` 命令打印完整的当前日期时间 |

壳命令也能配合它们：`运行 … < 文件` 让程序的标准输入取自文件（如 `运行 /程序/行数 < /数据/文本.txt`），`运行 甲 … | 乙 …` 把前一个程序的输出送给后一个（顺序管道），`设 名 值`、`取消 名`、`环境` 维护环境变量（存在 `/.环境`），`日期` 打印当前的 UTC 日期时间，`运行 … > 文件` 把子程序的标准输出写进文件，`追加`、`复制`、`移动`、`读`、`列` 处理文件，`脚本 路径` 逐行执行文件里的命令。

## 写自己的程序

1. 在预置树的 `程序/` 下放一个普通豫言源程序（`寻观「豫章」之书。` 起头，参见这里的例子）。文件名取 `名。脚本。豫` 时顶层就是程序体（如 `程序/回声。脚本。豫`）；取 `名。豫` 时把要做的事写进入口函数 `「入口」乃化「有」为「有」者也。「入口」者得「无」而 … 也。`（如 `程序/你好。豫`）。
2. 命令行参数用 `「号令」之「受命」于「元」`，文件用 `「藏书」之「阅」`／`「著」`／`「阅帛」` 等，退出码用 `「进退」之「辞」`。
3. 重新运行 `./豫言系统。林檎。豫行 运行 --预置 你的目录`；程序编成豫行文件放在盘上运行。

## 已知限制

- 子程序里的文件操作由壳所在的初始任务经内核邮箱代办，每条消息只带三个字节，读写兆字节级文件会很慢。
- 子程序不能再起子进程（内核只有两个任务槽）。
- 线性内存至多 32 MiB，一次物化几十万项的列表会用尽堆；递归深度几千层以内没有问题。
- 实时钟只有秒的精度、只有 UTC；管道是顺序的（各段一个接一个运行，前一段必须自己结束）；详见 [说明](../说明.汉语.md) 的“当前限制”。
