# 终端编辑与输入法

这是中文交互壳的字符编辑实现。普通输入、退格和历史回取在原提示行重画；光标左右两侧按 UTF-8 字符保存，中文选字插入光标处。Tab 命令补全仍只用于没有参数且光标在末尾的命令。拼音候选合并后保留首次出现位置，常用词字仍优先，重复字不再占据翻页位置。

## 按键契约

现有读取终端按键接口不变。输入环按顺序送入字节，壳解释常见串口方向键序列：上、下、右、左分别为 `ESC [ A`、`ESC [ B`、`ESC [ C`、`ESC [ D`；Home、End 为 `ESC [ H`、`ESC [ F`。也接受 Ctrl-P/N/F/B/A/E；Ctrl-D 删除光标右边一字，退格删除左边一字。Esc 立即取消候选或组音。硬件方向负责扩展扫描码到这些字节的转换，本方向不修改控台驱动或新增 ABI。

历史只在当前壳会话保存，最多 10001 行；上键取上一命令，下键取下一命令，到最新位置恢复开始翻阅时的草稿。空行不记。F2、选字、翻页、组音退格保持现有行为；组音中先由输入法处理按键。

## 本轮范围与后续

原行重画使用已有回车输出与空格覆盖残字，宽度遵循当前字体的 ASCII 一格、其他字符两格。待办事项：超过屏宽后的跨行编辑另补。屏幕中的游标位置由最后重写的左文决定，当前帧缓没有闪烁游标。

自动分词长句：后续先以现有拼音字库与常用词表作最长匹配，失败处保留组音让用户选字，不新增词典格式。

联想词频：后续先在当前会话记录已选词次数，同次数沿用原顺序；持久化方案另议。

字体选择：现有两份字体已经随盘分发；运行时切换需要确认现有字模加载接口能否复用。若需新增 ABI，先说明并询问。

上述三项为后续方案，本轮未实现。E40 新版中文编辑须由用户真机验收。

## 验证记录

壳的类型检查与链接通过；交互编辑测试在节点宿主运行通过，覆盖中文字符左右移动、首尾移动、右字删除、历史边界与草稿恢复、候选顺序及真实拼音候选去重、方向键序列和字格宽度。修改的豫言文件已格式化。

借用基础中文会话的系统工具生成带持久盘镜像时，报“镜像片段重叠”；无盘混合 ISO 生成成功，但 QEMU Penryn、Q35、xHCI、BIOS USB 启动报“裸机核验失败”，未进入壳。客体执行器与基础中文验收版本逐字节一致。当前源码系统工具的重建因先提交与同步的要求而停止，启动失败原因尚未确认，不能将此 ISO 作为已验收版本。未跑全仓测试，未作 E40 真机测试。

同步 yybs 的冲突已逐项合并，保留 Shift/Caps、xHCI 轮询、E40 初置与无 COM1 的 FF 检查；初置标记改在 `0x1039F8`，修饰状态仍在 `0x10392C`。同步后的壳构建和交互编辑回归通过，受影响控台及依赖类型检查通过；完整后端逐文件检查因耗时停止，未计为完整通过。实际机器片回归通过，普通核心长 10686、隔离核心长 11093 字节，均低于 GDT 前 12608 字节空间。

硬件会话已将首次启动失败定位到 PDPT Accessed 位检查，并在其独立修复版中确认恢复 QEMU 启动；该修复由硬件方向提交与验收，本方向不重复合入或宣称整套新镜像已验收。

| --- | --- |
