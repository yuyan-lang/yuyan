# 终端编辑与输入法

这是中文交互壳的字符编辑实现。普通输入、退格和历史回取在原提示行重画；光标左右两侧按 UTF-8 字符保存，中文选字插入光标处。Tab 在光标位于末尾时按正式句式位置补全；F2 组字先筛上下文已知名称，无匹配才给普通字词，详见《智能命令》。候选去重保留首次出现位置，重复字不再占据翻页位置。

## 按键契约

嵌套引号镜像为 `yy嵌套引号验收/yy豫言启动.iso`，SHA-256 为 `397984df6eb0d409a4457cdc3a8f02447ebc093cb095e3cc031d027e3c84998b`，壳长 466413 字节；沿用 `36aa076c4` 基线的系统工具。源码逐键回归覆盖外层未闭、内层闭合、外层闭合后再开、第三层交替，以及越过两种已有闭引号。QEMU Penryn、Q35、xHCI、512 MiB、关闭 PS/2，BIOS USB 键盘输入 `hx`、`1` 后，连续按 Shift+[、Shift+[、Shift+]、Shift+] 得到 `「回显」于「『』」`；再按 Shift+[ 得到新的 `「`，退格移除后回车输出 `『』`。正式退出后虚拟机以 33 退出，日志为同目录 `yy嵌套引号USB.log`。本轮未重验 UEFI。

默认中文镜像为 `yy默认中文验收/yy豫言启动.iso`，SHA-256 为 `27f306e0b895eff80660b2c58d2f93e34b3b534d3aa9d5eccbae96152b814ef6`，壳长 461167 字节；复用固定 `36aa076c4` 基线的系统工具。QEMU Penryn、Q35、xHCI、512 MiB，关闭 PS/2，串口只写日志，由全速 USB 键盘实测 `hx`、`1`、Shift+[、`ni`、`2`、Shift+]、回车，输出“呢”；按 Shift+] 时已有右侧闭引号被越过，参数正确闭合。另验 `j`、`1`、`12`、Tab、`3`、Tab、回车输出 `15`，证明选词后数字恢复为字面参数；`tc`、`1`、回车正式退出，虚拟机以 33 退出。日志为同目录 `yy默认中文USB.log`。本轮未重验 UEFI。

中文组字现为默认模式，F2 切换中文与英文。有待选拼音时，候选每页标为 1–9，数字直接选当前页；空格或回车选首项，Tab 翻页。没有待选拼音时数字照常输入。中文模式中，Shift+[ 根据光标左侧未闭合的引号切换：外层用 `「`，其未闭合时内层用 `『`，外层闭合后再用 `「`；更深层交替。Shift+] 对应闭合当前层；右侧已有相同闭引号时越过它。选词后可直接输入，英文模式保留原花括号。嵌套引号的源码逐键回归已通过，镜像实测记录见本节。

固定合并基线 yybs `36aa076c4` 的 BIOS/UEFI USB 键盘验收已完成：关闭 PS/2，串口只写日志，两路验证参数确认与执行、光标移动、删除、历史草稿恢复及 F2 连续组字。镜像校验值、逐键范围和日志位置见[智能命令](智能命令.汉语.md)。长句分词、词频与字体选择仍按下文方案待选实施阶段。

现有读取终端按键接口不变。输入环按顺序送入字节，壳解释常见串口方向键序列：上、下、右、左分别为 `ESC [ A`、`ESC [ B`、`ESC [ C`、`ESC [ D`；Home、End 为 `ESC [ H`、`ESC [ F`。也接受 Ctrl-P/N/F/B/A/E；Ctrl-D 删除光标右边一字，退格删除左边一字。Esc 立即取消候选或组音。硬件方向负责扩展扫描码到这些字节的转换；报告处理片通过现有轮询中的九字节调用接入，按键接口与应用 ABI 沿用现有约定。

历史只在当前壳会话保存，最多 10001 行；上键取上一命令，下键取下一命令，到最新位置恢复开始翻阅时的草稿。空行不记。F2、选字、翻页、组音退格保持现有行为；组音中先由输入法处理按键。

## 本轮范围与后续

原行重画使用已有回车输出与空格覆盖残字，宽度遵循当前字体的 ASCII 一格、其他字符两格。待办事项：超过屏宽后的跨行编辑另补。屏幕中的游标位置由最后重写的左文决定，当前帧缓没有闪烁游标。

自动分词长句：后续先以现有拼音字库与常用词表作最长匹配，失败处保留组音让用户选字，不新增词典格式。

分词的源码前提已核对：`壳/拼音输入。豫` 的常用词目前是查询函数分支，字库则是音节到字串的列表。实施前先把已有常用词整理为可枚举的豫言列表，仍使用现有词和字库，不增加外部词典格式。分词仅进入已知名称没有匹配的回退路径；每段先取最长词，剩余拼音保留到下一次选字。同音词仍须选择，回车只确认当前候选，不能直接执行命令。预期案例：回显参数 `nihaozhongguo` 分为“你好”与“中国”；`nihaoyuyan` 在“豫言”“语言”处等待选择；不能识别的末尾继续保留组音。这些是待实现的验收案例，尚无分词实现或通过结果。

联想词频：后续先在当前会话记录已选词次数，同次数沿用原顺序；持久化方案另议。

词频只在当前位置已经筛出的候选内排序，不能把其他位置的名称或不匹配词混入。先去重，再按本会话确认次数排序，同次数保留原顺序；确认才计数，翻页、取消和提交命令不重复计数。名字索引缓存继续只缓存名字与拼音，不缓存排序后的候选。预期验证包括同音词再次查询、取消不计数、已知候选与字词回退的优先级、同次数顺序及新会话清零。此为方案，尚未实现词频学习。

字体选择：现有两份字体已经随盘分发；运行时切换需要确认现有字模加载接口能否复用。若需新增 ABI，先说明并询问。

字体接口可行性已核对：`字模生成/入口。豫` 用同一生成函数输出默认与思源字模，`豫言系统。豫` 将两份复制到介质，当前 Limine 配置只指定默认字模。`库/裸机后端/字体模块。豫` 初置时读取首个 Multiboot 模块，未按模块名称选择。`宿主服务。接口。豫` 没有控制台字体切换声明；已有可移植字体接口提供只读字体文件，`客体二号/显示原语。豫` 的字体路径面向 macOS 系统字体文件，不能据此宣称控制台可切换。

最小候选方案为启动时选择默认或思源字模，复用首模块加载约定，先不新增应用 ABI。用户选定后再制作对应启动配置，核对字模大小、字形覆盖和 BIOS/UEFI 显示。壳内运行时切换另需设计控制台服务与授权，不用直接写内核字体状态地址来代替接口。本轮只完成源码核对与方案，没有实现字体选择。

上述三项为后续方案，本轮未实现。E40 新版中文编辑须由用户真机验收。

## 验证记录

壳的类型检查与链接通过；交互编辑测试在节点宿主运行通过，覆盖中文字符左右移动、首尾移动、右字删除、历史边界与草稿恢复、候选顺序及真实拼音候选去重、方向键序列和字格宽度。修改的豫言文件已格式化。

借用基础中文会话的系统工具生成带持久盘镜像时，报“镜像片段重叠”；无盘混合 ISO 生成成功，但 QEMU Penryn、Q35、xHCI、BIOS USB 启动报“裸机核验失败”，未进入壳。客体执行器与基础中文验收版本逐字节一致。当前源码系统工具的重建因先提交与同步的要求而停止，启动失败原因尚未确认，不能将此 ISO 作为已验收版本。未跑全仓测试，未作 E40 真机测试。

同步 yybs 的冲突已逐项合并，保留 Shift/Caps、xHCI 轮询、E40 初置与无 COM1 的 FF 检查；初置标记改在 `0x1039F8`，修饰状态仍在 `0x10392C`。同步后的壳构建和交互编辑回归通过，受影响控台及依赖类型检查通过；完整后端逐文件检查因耗时停止，未计为完整通过。实际机器片回归通过，普通核心长 10686、隔离核心长 11093 字节，均低于 GDT 前 12608 字节空间。

硬件会话已将首次启动失败定位到 PDPT Accessed 位检查，并在其独立修复版中确认恢复 QEMU 启动；该修复由硬件方向提交与验收，本方向不重复合入或宣称整套新镜像已验收。

## 合并镜像交互验收

2026-10-03，从含终端编辑与硬件修复的 `479672fc1` 基线源码重建系统工具、客体执行器和壳，生成 `yy终端合并验收/yy豫言启动.iso`。SHA-256 为 `3b75aa2fa56ca0b6a7e4076cbabc287eab865c4cfabb24893cb7f0a7009bb349`。本轮新命令位置模块未接入壳，因此这些结果证明当前编辑功能。

| --- | --- |
| 输入 `echo ab`，左移，在中间输入 `x`，回车 | `axb` |
| 上键取上一命令，回车 | 再次输出 `axb` |
| 输入草稿 `echo draft`，上键取历史，下键回草稿，回车 | `draft` |
