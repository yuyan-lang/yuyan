# 客体数组默认构造

用户态 WasmGC 执行器支持 `array.new_default`（`0xfb 0x07`）的纯 `i32` 数组子集。解码器读取数组类型号；静态验证确认类型表中是数组且元素为 `i32`，只消费一个 `i32` 长度并产生该数组的具体引用。运行时用现有受检对象堆分配至多 32 个元素，把每个元素初始化为零。分配不足时沿用活动根扫描和回收重试。

验收模块通过 `array.new_default` 创建三元素数组，再以 `array.get` 读取首元素，预期为零。该模块也由标准 WebAssembly 引擎验证和执行。ARM64、AMD64 的完整 QEMU 回归共 368 项全部通过，产物与日志在 `/tmp/yy裸机验证.TdOmRE`。其他元素类型、引用元素的默认值以及普通豫言模块所需的完整 WasmGC 仍待实现。

后续已接入 `i8` 元素的默认构造，见[客体字节数组执行](客体字节数组执行.汉语.md)；引用元素仍未实现。
