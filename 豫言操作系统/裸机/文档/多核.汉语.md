# 多核（AMD64）

AMD64 内核开机时启动全部处理器核，任务分到各核上同时运行。内核用一把大内核锁：同一时刻只有一个核在内核里，各核在用户态同时运行。

## 开机

- 外置模块的“多核开机”在开机初置里由主核调用（此时中断关着）。xAPIC 模式下，本地 APIC 映到两个旧槽低区页目录第 29 项（虚址 0x3A00000，不可缓存；动态任务的页表从槽 0 拷来，所以也有这一项）。PIT 通道 0 设成模式 2、100 Hz，用来计时。
- 主核向内存管理要两块 2 MiB 作其余核的“各核区”，映到两个旧槽低区页目录第 16、17 项（虚址 0x2000000 起，仅内核可访问），每块容纳 128 个核。
- 实模式跳板拷到物理 0x7000（GDTR 放在 0x7FE0），向量 0x30（其余核的定时器）与 0xFF（伪中断）装上中断门，主核拿住大内核锁，再广播 INIT、等 10 ms、广播两次 SIPI（向量 0x07）、等 100 ms。其余核各自原子地取一个序号；等候结束后主核给序号计数加 0x10000 把它封住，得到其余核数。
- 其余核数为零时，主核还掉两块、放锁，此后与单核完全一样。否则串口与屏幕印“处理器核：N”，用 PIT 校准本地 APIC 定时器（÷16，100 ms 的计数除以十作 10 ms 的初值），还掉用不到的第二块，设主核的各核区，记下槽 0 正在主核上运行，动态槽数加一（多核时调度一律由外置模块做），把向量 0x20 改成“多核时钟”，最后置多核标志。主核拿着的锁到第一次进用户态时由出口钩放开。
- 其余核的跳板：关中断，载 GDTR，开 PAE 与 SSE（CR4 0x620），CR3 用槽 0 的 0x110000，EFER 置 LME，CR0 清 CD、NW、EM、TS 并置 PG、PE，远跳到 0x08:0x7048 进长模式，再跳到“多核核入”。多核核入取序号（超出容量就停机），在本核区建 GDT（拷主核的，TSS 描述符改指本核的 TSS）与 TSS（RSP0 为区顶），重载段寄存器与 TR，载共用的 IDT，执行 fninit，开本地 APIC（SVR 0x1FF），等主核写好定时器初值后开周期定时（向量 0x30），进入空闲。

## 各核区与全局量

| 位置 | 内容 |
| --- | --- |
| 0x121F28 | 其余核数 |
| 0x121F2C | 多核标志（第 0 位） |
| 0x121F30 | 大内核锁 |
| 0x121F34 | TLB 代数 |
| 0x121F38、0x121F3C | 槽 0、槽 1 正在某核上运行（动态槽记在槽区 +0x3C） |
| 0x121F40 | 其余核的序号计数 |
| 0x121F44 | 本地 APIC 定时器初值 |
| 0x121F48 | 本地 APIC 虚址（八字节） |
| 0x121F50 | 各核区容量 |
| 0x121F54、0x121F58 | 两块各核区的块号 |

每核一个 16 KiB 对齐的各核区，区顶是这个核的内核栈顶（TSS 的 RSP0）：

| 偏移 | 内容 |
| --- | --- |
| +0x00 | 本核的当前槽 |
| +0x04 | 本核的浮点主人 |
| +0x08 | 本核见过的 TLB 代数 |
| +0x0C | 核号 |
| +0x30 | GDTR（其余核） |
| +0x40 | GDT（其余核） |
| +0x100 | TSS（其余核） |
| 到 +0x4000 | 内核栈 |

内核里把 rsp 向下取整到 16 KiB 就得到本核的区（进空闲时按 rsp−8 取整，栈指针恰在区顶时也落在本核）。主核的区在 0x1EC000（栈顶 0x1F0000），其余核的区从虚址 0x2000000 起每核 16 KiB。

## 大内核锁

- 主核心的三个入口（系统调用、时钟中断、缺页）在保存现场之后有入口钩，两个出口（返回用户、调度复原）在恢复现场之前、开机第一次进用户态之前有出口钩。多核标志没置时，钩子只做一次测试就跳过。
- 入口钩呼外置模块跳转表 +64“多核入”：自旋取锁，把本核区的当前槽与浮点主人换入 0x103340 与 0x124400；TLB 代数变了就重载 CR3 冲刷。出口钩呼 +72“多核出”：把这两个量换出到本核区，再放锁。主核心里读写 0x103340、0x124400 的旧代码因此照旧可用。
- 拆下内核窗口里的组块时 TLB 代数加一，其余核下次取锁时冲刷。

## 调度与空闲

- 多核时动态槽数多计一，定时中断、阻塞服务与退出后的调度都转到外置模块统一轮转。每个任务有“正在运行”标记：调度时先清掉当前任务的标记，只挑可运行且不在别核上运行的任务，挑中就置上标记。
- 主核仍由 PIT（向量 0x20，100 Hz）计时并查控台输入；其余核用本地 APIC 定时器（向量 0x30，约 100 Hz）轮转。
- 没有可运行的任务时，这个核存好当前任务的浮点状态，当前槽与浮点主人记 -1，页表根换回槽 0 的，放锁，在内核里开中断停机。定时中断把它从空闲里叫醒：栈放回区顶下 160 字节，取锁（主核还要滴答加一、查控台输入），从槽 0 起按调度次序找可运行且不在别核上运行的任务，找到就取它的帧返回用户态，找不到就放锁回到空闲。
- 任务可以在任一核上运行，下次调度可能换到别的核；浮点状态在切走时存起、切入时取出。

## 验证

- QEMU q35，SeaBIOS 与 OVMF，`-smp 1`、`2`、`4`：开机印“处理器核：N”；命令壳连续运行 40 个子程序，输出与退出码全对，子任务全部回收。
- 一个异步子任务加一个同步子任务同时数 20000 以内的质数：单核总用时约 4760 ms，双核与四核约 2430 ms。
- 单核行为与以前一样：380 项裸机验证与普通豫言验证的壳测试照旧通过。

## 后续版本的事项

- x2APIC 模式的机器（IA32_APIC_BASE 第 10 位）只用一个核。
- 至多用 257 个核。
- 内核由一把大锁串行；没有核间中断，空闲的核最迟 10 ms 后接手新任务。
- 终止正在别核上运行的任务返回 -1，以后改为延后终止。
- ARM64 只用一个核。
- 用 ACPI MADT 找核、逐个唤醒。
