# 完整类型选择指令

已接入无注解 select 与带注解 select。无注解选择只允许同一种数值或向量类型，拒绝引用；已知值与未知值混合时保留已知类型，两者均未知则保留未知。带注解形式要求恰好一个有效值类型，并分别检查两个候选值，结果按该声明类型拓宽。两种形式均要求条件为 i32。

14 个完整模块测试与 Node 分类一致，豫言测试通过，20 个引用转换回归通过。覆盖 i64、引用子类型、非空约束、不可达未知、错误条件类型、注解数量及类型编号越界。日志为 `/tmp/yy选择指令检查日志`、`/tmp/yy选择指令构建日志`、`/tmp/yy选择指令运行日志`、`/tmp/yy选择引用回归运行日志`。

新增命令 `yy中文网页汇编 检查函数指令 模块.wasm`，从完整模块读取类型和代码后验证当前支持的指令。它明确拒绝尚不支持的指令，且成功不表示其他模块资源已全验，也不会执行模块。真实产物检查结果另录，默认裸机镜像不变。

命令构建及正例验证已通过。对现有 `yy优化器三代.wasm` 检查时，首次遇到未支持操作码 35（global.get），退出 1；这表明下一步需要完整全局声明和初始化验证，不说明输入模块非法。日志为 `/tmp/yy函数指令命令正例日志`、`/tmp/yy真实函数指令检查日志`。
