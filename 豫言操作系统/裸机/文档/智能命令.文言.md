# 智能命令体验改进

此裸机壳循网页壳输入之规而施之实现与计划也。正式句式已接壳之输入与执行循环，位置之析、候选之择与逐键组字皆过回归；BIOS 与 UEFI 新镜像串口之交互已验，详《终端编辑》。

## 所据

网页壳今之说明在云仓 `应用/豫言云工作台/智能命令.汉语.md`。输入之位、候选与回退，分别见 `库/云台前端输入/位置。豫`、`候选。豫`、`刷新。豫`；页面之术见 `工作台应用/智能输入。豫`。

正式输入以角引号围名，成员以 `之` 联，参数以 `于` 引，如：

```text
「文件」之「列出」
「文件」之「读取」于「入口。豫」
「文件」之「写入」于「新文件。豫」于「正文」
```

择候选而定，则自补角引号与连接词。先据当下命、成员或参之位，筛已知之名，通中文前缀、全拼与首字母；已知无合者，乃示普通拼音字词。同音须择，择之惟入行，再提交乃行其命。组字未定，不行命。空入、`之` 后、`于` 后，各示当位之候选；`?` 或 Tab 可展当位诸项。

角引号内空格、`之`、`于` 与换行皆存原文。正文可成对嵌角引号，缺闭者报错。游标与输入之位，循网页旧义。

云文件系统所据为 `库/云文件系统/地址。豫` 与 `地址。测试。豫`：名之引用与名链，以角引号与 `之` 书；所有者、摘要、调用者之起点各治之。包说明犹有旧方括号之辞，施之须据今源与测试核定之规。裸机今轮复用旧文件之术，不增云端名表、内容库及所有者服务。

## 施之次序

1. 别核角引号之深、成员与参之位，兼验引内连接词与嵌套正文。
2. 裸机已通之术，录为相应正式句式；候选随位而择其范围。
3. 合已知名之候选与普通拼音回退，用旧字籍，去重而存其序。
4. 接原行编辑、游标与命史，择入与提交各行之；构实壳而验合并后之镜像。

旧空白分词短令存否，已问用户；未定之前，不增双语法兼容之路。长句分词、词频与择字体，后各循《终端编辑》之议而进。若增 ABI 或云端之能，另陈而问之。

## 正式句式之接入

`壳/命令登记。豫` 共录成员路、内术名与参数数，行命之析与当位候选皆用之。文件之成员有当前、切换、列出、读取、写入、追加、复制、移动、建目录、删除；余旧术录于根级。析命须段段角引号闭合，成员先于参，参之数合籍；引内正文不复拆词。

交互与脚本入口已用正式句式。Tab 随位筛中文、全拼与首字母，无合乃退字词，空查询则展全部；再按 Tab 可轮择，填角引号并据籍补之或于，回车乃行命。路径参之候选取当前目录；无盘仍可回退拼音。析候选有错则示之而还编辑。

F2 已与 Tab 共用当位候选：字母组字先筛已知名，无合乃取普通字词；通大写、数键之择、分页与取消。空格或回车定候选惟填入，组字既毕，再回车乃提交。普通字词留游标于外引之内，可续组，亦可于旧右文前插字。待择拼音无候选，回车则存其组，Esc 可取消；组字未定，移动键不易输入之位。

`壳/上下文输入。测试。豫` 直调交互入口之逐键术，已构而运行皆成：拼音择回显与文件成员、首字母同音两项而择其次、大写 NI、续组“你好”、择字回车与提交回车之别、存右文、无候选存组与取消。命令登记与交互候选回归之试已成，今组字改后之实壳已构，且验《终端编辑》所列 BIOS 与 UEFI 镜像操作。带目录前缀之路径补全、旧管道与重定向之正式表达待施；今未增短令兼容之支与云端之能。

## 初大壳与自由参之验

镜像 `yy自由参数验收/yy豫言启动.iso`（独立验证树）之 SHA-256 为 `9a0c3ed48580f721dfdc11737d1dbeb7a1bdbc0e7c51a3b2bf615ea06e9896a1`，壳长四十六万三千七百七十二字节。初壳逾旧窗，执行器启动之包以标准 Wasm 令长内存，循序合抄被动前段与窗末段于动态区，乃入旧启动；静态八页、栈与应用 ABI 不易。初大客之试实装而调用，首尾异字、窗界、有界最大页数、模块长与大程序标皆成。

QEMU Penryn、Q35、xHCI、512 MiB，以串口入字，BIOS 与 UEFI 两路皆由 USB 镜像而启：`hx`、Tab、`AbC`、回车先成 `「回显」于「AbC」`，再回车乃出 `AbC`；`j`、Tab、`12`、Tab、`3`、Tab、回车出 `15`；`ab` 中左移入 `x`，定而行则出 `axb`，历史复行亦成。F2 之 `hx` 先择已知回显，复以 `ni`、`hao` 续组而出“你好”；BIOS 别验整词 `nihao` 与大写 `NI`。正式退出皆成，两虚拟机皆退。此镜像硬件源码本于 `ea8cb2735`，不证后继 yybs 多端口与存储之改；最新合并镜像待别验，亦未证文件落盘与 E40 真机。

## 固定合并基线 USB 键盘之验

合并镜像 `yy分段合并验收/yy豫言启动.iso` 之 SHA-256 为 `a611ef218894087a2bece8b12f32c77ece3f6cd5bc53afb216f41e23fc8dd3ec`，硬件与壳源码定于 yybs `36aa076c4`（任务提交 `60a8abdf7`）。系统工具与镜像之构皆成，裸机后端包类型检查已成；初大客之试别按独立入口构而行之。

QEMU 11.1.1、Penryn、Q35、512 MiB，设 `i8042=off`，串口惟书日志；自端口一 USB 镜像而启，端口二为 USB 键盘，BIOS 用全速，UEFI 用高速。诸入皆由 QEMU `sendkey` 进实 HID 报告之路。两路皆验：`AbC` 初回车惟定带引参，再回车出 `AbC`；Tab 定两参加法而出 `15`；Home/End、左移入字、Delete 与退格后出 `ab`；历史取回、左右移、入 `x` 后出 `axb`；上下历史复 `h` 草稿；F2 先择已知回显，`ni`、`hao` 续组而出“你好”，所见候选行无复项。正式退后两虚拟机皆以三十三退。日志为同目录 `yyBIOSUSB输入.log`、`yyUEFIUSB输入.log`。

今证固定合并基线之输入路，不含后继容量与扇区读取之提交，未证文件落盘、跨行编辑、闪烁游标与 E40 真机。长句分词、会内词频与字体选择犹为《终端编辑》中之策，待用户择其施行之次。

## 普通参后之连接词

自由参可直入英文、数与正文。已有正式成员而末参未加角引者，回车先围其参，循登记补所缺必需参之连接词；是回车惟定文字，再回车乃行。无候选时 Tab 亦定自由参。原文之大小写与内空皆存；未闭引、未知命与裸书成员，不自动改写。登记与参连接之试已成；镜像之验所及见上节。

普通字词回退可续组，择字后游标留于外引之内。参文既成，按 End 至闭引之外，再按 Tab，壳循登记补所缺必需参之“于”。末必需参、未闭引与错成员序皆不多补；此惟改输入行。例：`「文件」之「写入」于「新文件。豫」` 后按 Tab，可续入正文参。

登记之试已验新名、次参原文、末参、未闭引与错序。镜像 `yy参数连接验收/yy豫言启动.iso` 之 SHA-256 为 `308bb996022476d4562071923e44ffc51c764c1e27d4ee5ae77f4756aae561f5`，壳长四十五万五千六百五十三字节；复用前轮系统工具，QEMU Penryn、Q35、xHCI、512 MiB USB 盘由 BIOS 与 UEFI 两路皆入壳。两路逐键行 F2、`wj`、空格、`xr`、空格、`ni`、空格、End、Tab、`nihao`、空格、回车，成 `「文件」之「写入」于「你」于「你好」`，入写术而告写入失败。无盘之路未证文件落盘。两路别验回显“你好”成后 End、Tab、回车，不多补“于”，犹出“你好”；正式退出亦成，虚拟机已退。今轮不证他项新硬件之改。

## 独立分析所成

名之拼音索引已于会内复用。旧手录命索引供同名之查，余名初扫字籍而后存之；每查候选，犹循当位登记重择名字之范围，故目录与命位有变，不引旧候选。此免逐键复扫同名之字籍。智能候选与实逐键上下文之试已重构而运行皆成；裸机响应之验另录。

索引复用之验收镜像为 `yy索引复用验收/yy豫言启动.iso`，SHA-256 为 `ea9301e1545ec6ba7a8579e3c041dc3d56ae4af46f925eb564920054d2b22170`，壳长四十五万五千零八字节。今轮复用前轮系统工具，QEMU BIOS、Penryn、Q35、xHCI、512 MiB USB 启而入壳；一次送 F2、`hx`、`nihao`、择与提交，首个一千毫秒观测窗已还全候选与“你好”之出。文件成员初次犹补算索引，后续复以 `wj`、`dq` 择“当前”而提交，于首个同窗出 `/`；“当前”“读取”同音候选犹为二项。英文 Tab 回显与字词回退、正式退出亦成，虚拟机已退。此为一次交互之观，非精确延迟与吞吐之基准；今轮未复验 UEFI 与他项新硬件之改。

`壳/智能候选。豫` 已按中文前缀、全拼与首字母筛已知名；无所匹配，乃以末尾拼音求字词，而存前文。展全部者，惟列已知候选。去重而存首见之序；择后补角引号与调用者所定连接词，惟生文字。名之音取字籍基础读音，多音之辨尚未施。

`壳/智能候选。测试。豫` 已构而运行皆成，验已知优先、字词回退、大写、存前文、展全部、去重、参之填入、连接词与越界之择。共享拼音查询改后，终端编辑之试亦成。此篇已接壳之交互，登记后之文授正式句式入口以行之；此等模块之试惟证所列术之行为。

`壳/命令位置。豫` 还已写成员、参之序、原文前缀与查询词；惟引深为零则循连接词分段，去段外空白与一层外引。未闭之引可续析以供编辑，行命前之闭合校验则告其缺起或缺闭。
