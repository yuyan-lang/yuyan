# 多核

核开机时启诸处理器核，任务分于诸核而并行。核内一大锁：同时惟一核在核内，诸核于用户态并行。下先言兼容，臂见[臂](#臂)一节。

## 开机

- 外置之模之“多核开机”，开机初置时主核呼之（中断方关）。xAPIC 之式，映本地 APIC 于旧二槽低区页目第二十九项（虚址 0x3A00000，不缓存；动态任务之页表拷自槽零，故亦有之）。PIT 通道零设为式二、百赫，以计时。
- 主核求内存之管二块二兆，为余核之“各核区”，映于旧二槽低区页目第十六、十七项（虚址 0x2000000 起，惟内核可访），每块容百二十八核。
- 实模式之跳板拷于物理 0x7000（GDTR 置 0x7FE0），向量 0x30（余核之定时）与 0xFF（伪中断）装其门，主核执大锁，乃广播 INIT，候十毫秒，广播 SIPI 二次（向量 0x07），候百毫秒。余核各以原子取一序；候毕，主核加序之计 0x10000 以封之，得余核之数。
- 余核之数为零，则主核还二块、放锁，此后一如单核。否则印“处理器核：N”，以 PIT 校本地 APIC 之定时（十六分之，百毫秒之计除以十为十毫秒之初值），还所不用之第二块，设主核之区，记槽零方行于主核，动态槽数加一，改向量 0x20 为“多核时钟”，终置多核之标。主核所执之锁，至首入用户态时由出口之钩放之。
- 余核之跳板：关中断，载 GDTR，开 PAE 与 SSE（CR4 0x620），CR3 用槽零之 0x110000，EFER 置 LME，CR0 去 CD、NW、EM、TS 而置 PG、PE，远跳于 0x08:0x7048 入长模式，乃跳于“多核核入”。多核核入取其序（逾容则止），于本核之区建 GDT（拷主核者，TSS 之描述改指本核之 TSS）与 TSS（RSP0 为区顶），重载段寄存器与 TR，载共用之 IDT，行 fninit，开本地 APIC（SVR 0x1FF），候主核书定时之初值，乃开周期定时（向量 0x30），入空闲。

## 各核区与全局之量

| 位 | 所载 |
| --- | --- |
| 0x121F28 | 余核之数 |
| 0x121F2C | 多核之标（第零位） |
| 0x121F30 | 大锁 |
| 0x121F34 | TLB 之代 |
| 0x121F38、0x121F3C | 槽零、槽一方行于某核（动态槽记于槽区 +0x3C） |
| 0x121F40 | 余核之序之计 |
| 0x121F44 | 本地 APIC 定时之初值 |
| 0x121F48 | 本地 APIC 之虚址（八字节） |
| 0x121F50 | 各核区之容 |
| 0x121F54、0x121F58 | 二块各核区之块号 |
| 0x121F5C、0x121F60 | 旧槽零、一之“子毕”之粘（见[动态任务](动态任务.文言.md)之消息） |

每核一各核区，十六 KiB 对齐，区顶为此核内核栈之顶（TSS 之 RSP0）：

| 偏 | 所载 |
| --- | --- |
| +0x00 | 本核之当前槽 |
| +0x04 | 本核之浮点之主 |
| +0x08 | 本核所见 TLB 之代 |
| +0x0C | 核号 |
| +0x30 | GDTR（余核） |
| +0x40 | GDT（余核） |
| +0x100 | TSS（余核） |
| 至 +0x4000 | 内核之栈 |

核内取 rsp 下整于十六 KiB，即得本核之区（入空闲时以 rsp 减八取整，栈指恰在区顶亦落本核）。主核之区在 0x1EC000（栈顶 0x1F0000），余核之区自虚址 0x2000000 起，每核十六 KiB。

## 大锁

- 主核心三入口（系统调用、时钟中断、缺页）于存现场之后有入口之钩；二出口（返回用户、调度复原）于复现场之前、开机首入用户态之前有出口之钩。多核之标未置，则钩惟一试而越之。
- 入口之钩呼外置之模跳表 +64“多核入”：旋而取锁，换入本核区之当前槽与浮点之主于 0x103340 与 0x124400；TLB 之代变则重载 CR3 以冲刷。出口之钩呼 +72“多核出”：换出二量于本核之区，乃放锁。故主核心读写 0x103340、0x124400 之旧码如故可用。
- 拆内核窗中之组块，TLB 之代加一，余核下次取锁时冲刷。

## 调度与空闲

- 调度一律由豫言内核之「调度」为之（外置之模之小呼口转之）；多核时动态槽数多计一。每任务有“方行”之记：调度先去当前任务之记，惟取可行而不行于他核者，取之则置其记。
- 主核仍以 PIT（向量 0x20，百赫）计时而察控台之输入；余核以本地 APIC 之定时（向量 0x30，约百赫）轮转。
- 无可行之任务，则此核存当前任务之浮点，当前槽与浮点之主记负一，页表之根换为槽零者，放锁，于核内开中断而止。定时之中断自空闲醒之：栈置于区顶下百六十字节，取锁（主核复加滴答、察控台之输入），自槽零起依调度之次寻可行而不行于他核者，得则取其帧还用户态，不得则放锁复归空闲。
- 任务可行于任一核，下次调度或易其核；浮点之态切出时存之，切入时取之。

## 验证

- QEMU q35，SeaBIOS 与 OVMF，`-smp 1`、`2`、`4`：开机印“处理器核：N”；命令壳连行四十子程序，输出与退出码皆合，子任务尽收。
- 一异步子任务与一同步子任务同数二万以内之质数：单核共用约四千七百六十毫秒，双核与四核约二千四百三十毫秒。
- 单核之行如旧：三百八十项裸机验证与普通豫言验证之壳测试皆过。

## 臂

调度与空闲之理在豫言内核（「调度」「空闲选」「转空闲」，见[动态任务](动态任务.文言.md)之“豫言内核”一节），其义同兼容；手书者在裸机后端之「臂多核」之模。

- 开机：主核首入用户态之前呼『多核开机』：建核零之区（0x400B5100），置 TPIDR_EL1，清取号之区而执锁，置多核之标，记槽零方行，乃以 PSCI CPU_ON（HVC，函号 0xC4000003）次第醒核一至七（所指 MPIDR 即核号，入口『核入』，上下文为核号）。一无所起，则撤多核之标与锁，此后一如单核；否则记余核之数，动态槽数加一（多核时调度皆在豫言内核）。主核经出口之钩放锁，乃入用户态。
- 余核自『核入』入（一级、MMU 关）：建本核之区与栈，开浮点，设 VBAR、MAIR、TCR、TTBR0（槽零之零级表 0x400A5000）而开 MMU，醒本核之 GIC 再分发器（0x080A0000 加核号乘百二十八 KiB），SGI 之帧设组一、优先而使二十七号虚钟之断，开系统寄存器之接，以主核之初值起虚钟，入空闲。
- 各核区：核零在 0x400B5100，核 n（一至七）在 0x401F0000 加 (n−1) 乘八 KiB，区顶为其内核栈之顶。+0 本核当前槽，+4 本核浮点之主，+12 核号，+16 栈顶（八字节）。TPIDR_EL1 指本核之区。
- 大锁：Lamport 面包肆之锁，惟用常读常写与 dmb sy（数据之缓存未开，则内存以不可缓存访之；苹果芯片之硬虚惟于可缓存之内存行独占之访 ldaxr／stxr）。第 j 核之“方取号”在 0x400B5200 加八 j，号在其后四字节；取号而依（号，核号）列次。
- 入口之钩：零级同步、零级 IRQ 与空闲之钟，存现场后取锁，换入本核区之当前槽与浮点之主于 0x400B0030 与 0x400B4800（零级同步继而自帧复 x12 至 x17 与 x30）；出口之钩：返回用户（惰性浮点切换之后）、调度复原与开机首入用户态之前换出之，乃清本核之号以放锁。多核之标未置，则钩惟一试而越之。
- 空闲：内核返三，则内核已存浮点，当前槽与浮点之主记负一，页表换为槽零者；手书之口放锁，栈归区顶，开 IRQ，wfi。空闲时虚钟之断循向量第五项（当前层 IRQ）『核闲时钟』：取锁、应之（核零乃加滴答、察控台之输入），呼内核「空闲选」自槽零寻可行而不行于他核者，得则经『调度复原』还用户态，否则放锁复归空闲。
- 多核时根任务退后诸核入空闲；测试之脚本见“设备退出清理完成”即止 QEMU。

### 验证（臂）

- QEMU virt（GICv3），纯拟 `-cpu cortex-a53 -accel tcg` 与苹果芯片硬虚 `-cpu host -accel hvf`，`-smp 1`、`2`、`4`：命令壳行子程序、读写数据盘之文，所出同单核。
- 一异步子任务数六十万以内之质数、一同步子任务数五十万以内之质数（惟印其数）：硬虚之下单核共用一万零八百九十毫秒，双核五千五百三十毫秒，四核五千五百七十毫秒。
- 三百八十项裸机验证（单核）皆过。

## 后续之版之事

- x2APIC 之机（IA32_APIC_BASE 第十位）惟用一核。
- 至多用二百五十七核。
- 核内以一大锁串行；无核间中断，空闲之核至迟十毫秒乃接新任务。
- 止方行于他核之任务返负一，后改为延止。
- 臂至多用八核（设备之映盖前十一核之再分发器），余核之内核栈八 KiB。
- 臂开数据与指令之缓存后，改用独占之令之锁。
- 多核时根任务退后自关机。
- 以 ACPI MADT 寻核，逐一唤之。
