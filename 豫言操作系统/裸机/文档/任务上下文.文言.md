# 中断所存整数任务之境

后续系统调用与缺页亦共此局，详[统一异常帧](统一异常帧.文言.md)。下存初接定时之界。

定时中断今存全部整数通用寄与返客之据，毕则由同帧复之。存、验、复之码列于“任务上下文”，以备后续调度；恢复末即返用户，非寻常子程序之返。

臂帧二百七十二字节，十六字节齐。自零至二百四十，每八字节存一寄，凡零至三十号；二百四十八存客栈，二百五十六存返址，二百六十四存状态。

兼容帧一百六十字节。先存十五非栈通用寄，共一百二十字节，后接硬件返帧：返址、代码段、标志、客栈与栈段，各八字节。细目详汉语篇。

恢复前核返址与客栈是否在今静态用户域。核验借额外暂寄，后由帧复之，不再赖旧计时处理所改寄少。此仍单域之界，非多进程地址策略。

二〇二六年九月二十二日，存验复俱接之后，含百万次循环、蔽中断负例及独立 C 模块之一百一十四项双架构验皆过。实码经反汇编核寄存覆盖、偏移、状态复写及次序，诸型合。复验诸令详汉语篇。

产物在 `/tmp/yy裸机验证.CVKv5h`，诸证录于 `验证记录.json` 之“整数上下文扩展验证”。今仍返原任务，未造多任务而迁其境。浮点、向量、线程基址、页表标识未入此帧，故不得谓完整进程之境、抢占调度与隔离已成；系统调用与余异常亦未尽改用此帧。
