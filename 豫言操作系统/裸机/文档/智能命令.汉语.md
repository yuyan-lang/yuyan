# 智能命令体验改进

这是裸机壳沿用网页壳输入规则的实现与实施计划。正式句式已接入壳的输入与执行循环，位置分析、候选决策及逐键组字已通过回归；BIOS 与 UEFI 新镜像的串口交互已验收，详见《终端编辑》。

## 已确认的依据

网页壳的现行说明在云仓库 `应用/豫言云工作台/智能命令.汉语.md`。输入位置、候选和回退决策分别由 `库/云台前端输入/位置。豫`、`候选。豫`、`刷新。豫` 实现，页面层为 `工作台应用/智能输入。豫`。

正式输入使用角引号包围名称，成员之间用 `之`，参数之前用 `于`，例如：

```text
「文件」之「列出」
「文件」之「读取」于「入口。豫」
「文件」之「写入」于「新文件。豫」于「正文」
```

候选确认后自动补入角引号和连接词。先按当前命令、成员或参数位置筛选已知名称，支持中文前缀、全拼与首字母；只有没有已知匹配时，才显示普通拼音字词候选。同音候选须确认，确认只填入输入行，再次提交才执行。组字期间不执行命令。空输入、`之` 后、`于` 后各显示相应范围的候选，`?` 或 Tab 可展开当前位置选项。

角引号里的空格、`之`、`于` 和换行属于原文。正文允许成对嵌套角引号，缺少闭合引号须报错。光标与输入位置分析遵循网页现有语义。

云文件系统的依据为 `库/云文件系统/地址。豫` 及 `地址。测试。豫`：名字引用和名字链使用角引号与 `之`，所有者、摘要、调用者起点分别处理。包说明仍有旧的方括号措辞，实施须以当前源码与测试核对后的规则为准。裸机本轮复用既有文件操作，不增加云端名表、内容库或所有者服务。

## 最小实施顺序

1. 独立核对并复用角引号深度、成员与参数位置规则，覆盖引号内连接词及嵌套正文。
2. 将裸机已支持操作登记为对应的正式句式，候选根据当前位置选择范围。
3. 统一已知名称候选与普通拼音回退，使用现有字库；保持去重和稳定顺序。
4. 接入原行编辑、光标与历史，确认填入和提交分开；构建实际壳并验收合并后的镜像。

是否保留现有空白分词短令已询问用户；在确认前不增加双语法兼容路径。后续长句分词、词频与字体选择仍按《终端编辑》的方案分别推进。任何新增 ABI 或云端能力另行说明并询问。

## 正式句式接入

`壳/命令登记。豫` 共用成员路径、内部操作名和参数数目表，供执行解析和位置候选使用。文件成员为当前、切换、列出、读取、写入、追加、复制、移动、建目录、删除；其余现有操作在根级登记。解析要求各段角引号闭合，成员在参数之前，参数数目符合登记；引号内正文不再次拆词。

交互及脚本入口已改用正式句式。Tab 按当前位置匹配中文、全拼和首字母，无匹配回退字词，空查询展开全部；再次 Tab 可轮换候选，填入角引号并按登记补之或于，回车才执行。路径参数候选取当前目录；无盘时可以继续拼音回退。候选分析错误会显示后返回编辑。

F2 已与 Tab 共用当前位置候选：字母组字时先匹配已知名称，无匹配才给普通字词；支持大写、数字选择、分页和取消。空格或回车确认候选只填入，组字结束后再次回车才提交。普通字词留光标在外引号内，既可连续组字，也可在已有右文前插字。待选拼音没有候选时，回车保留组字，Esc 可取消；组字期间移动键不改变输入位置。

`壳/上下文输入。测试。豫` 直接调用交互入口的逐键处理，已构建运行通过：拼音选择回显与文件成员、首字母同音两项并选择第二项、大写 NI、连续“你好”、选字回车与提交回车的区分、右文保留、无候选保留与取消。命令登记及交互候选回归测试已通过，本轮组字修改后的实际壳已构建，并完成《终端编辑》所列 BIOS 与 UEFI 镜像操作。带目录前缀的路径补全、旧管道与重定向的正式表达尚待处理；本轮没有新增短令兼容分支或云端能力。

## 已完成的独立分析

`壳/智能候选。豫` 已实现中文前缀、全拼、首字母的已知名称过滤；无匹配时按末尾拼音回退到字词，并保留前文。展开全部只列已知候选。候选去重且保留首次顺序；选择后补入角引号及调用方给定的连接词，只生成文本。名字拼音采用字库中的基础读音，尚未处理多音消歧。

`壳/智能候选。测试。豫` 已构建并运行通过，覆盖已知优先、普通字词回退、大写、前文保留、全部展开、去重、参数填入、连接词与越界选择。共享拼音查询改动后的终端编辑测试也已通过。模块已接入壳交互，登记后的文本交由正式句式执行入口处理；这些模块测试只证明所列函数行为。

`壳/命令位置。测试。豫` 已构建并运行通过，覆盖空输入、成员拼音、参数拼音、引号内连接词与空格、嵌套豫言正文、未闭引号编辑及非法引号拒绝。此验证只证明分析模块，未证明新句式的整条执行路径。
