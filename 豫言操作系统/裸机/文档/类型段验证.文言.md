# 类型段合验

今合作用域、共享递归身份与复合方差为类型段入口，受共享表与已读诸组，验成返新表及声明身份之境。旧表按值传，败则不返扩展结果。

具体引用先比身份，次循显式父链。父号递减，故链不循环；形似不自生未声明之继承。函数、结构、数组各归其抽象类；空聚合可入具体结构数组，空函数可入具体函数，不越其系。

凡有父型皆验复合关系：结构前缀、可写不变、只读协变、数组域、函数受参逆变返果协变。关系据身份与已验结构前提之父链，不以模块同号冒递归等价。

二十三二进制类型段合验，与 Node 分类同；另七断言验继承方向、空底与类别隔离。验型、构建、运行皆成，日志存 `/tmp/yy类型段检查日志`、`/tmp/yy类型段构建日志`、`/tmp/yy类型段运行日志`。

今唯验类型段，未含指令、接口、链接与回收运行。跨模块须携各自合法上下文而共享身份表，不得混其局部号。未接裸机加载，默认镜像不变。
