# 守界访存编码

增双架构标量访存编码，受可信基址、区长、偏移、宽度与取舍之别，直生机器指令，不借外编译器与私缓冲。

客址以三十二位零扩之，偏移与末端以六十四位相加，先验全界，后加基址而访问；败则入旧陷阱。不可因窄数回绕而误入低址。

可取舍一二四字节，窄读可扩符号，仍守旧操作数栈之约。原生十二组机器片及非法参数之试已过，反汇编核其运算、分支、陷阱与寄存器。

后续已接模块降级与镜像数据初置，双架构定区访存及三类陷阱皆验。详[定区内存之验](固定内存.文言.md)。动态授页与默认壳未成。命令详汉语篇。

同源码经网页目标运行，十二组机器片与原生逐字同，诸型亦合；实机执行之验仍待之。

二〇二六年九月二十五日：本文所述以内存栈为本之降，已为[寄存器降级](寄存器降级.文言.md)所代；旧之内存编码及其试皆已除。所述行为之规与 QEMU 之验不易，两机共三百六十二项（并外部模块三百七十项）悉过。
