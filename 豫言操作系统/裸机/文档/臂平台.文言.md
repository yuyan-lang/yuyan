# 臂六十四之平台：QEMU 与 VMware

臂六十四之豫言操作系统可启于二平台：QEMU 之 virt 机型（平台号零），与依 ACPI 之表寻设备之 UEFI 之机（平台号一）；今所实验者，苹果芯片 Mac 上 VMware Fusion 之臂虚拟机也（二〇二六年十月九日）。二者同用一启盘 `yy豫言启动臂.iso`，引导程序开机时辨之。

## 二平台之异

| | QEMU virt | VMware Fusion（臂） |
|---|---|---|
| 内存 | 自实址 0x40000000 起 | 自实址 0x80000000 起，0x100000000 以上续之 |
| 实址 0x40000000 | 内存 | PCIe 配置空间（二百五十六兆） |
| 串口 | PL011，0x09000000 | 类 16550，逐字访之，0x3FFF03F8（虚拟机配串口乃有） |
| GIC 分发器、重分发器 | 0x08000000、0x080A0000 | 0x2C010000、0x2C100000 |
| 实时之钟 | PL031，0x09010000 | 引导程序取时于 UEFI |
| 寻设备 | 址固定 | ACPI：SPCR、MADT、MCFG |

内核之虚址布局，二平台同：内核区为虚址 0x40000000 至 0x7FFFFFFF。VMware 上此段映于实址 0x80000000 至 0xBFFFFFFF，二者之差曰物理之偏（QEMU 为零，VMware 为 0x40000000）。手书之核之址常数皆不改，惟书于页表与 TTBR0 之实址加物理之偏。

## 开机参数之区

开机参数之区居内核区之首（虚址 0x40000000，即实址 0x40000000 加物理之偏）。QEMU 径装内核时，惟首二项由 QEMU 之 loader 书之，余为零；UEFI 引导时，引导程序先零六十四 KiB 而后书之。

## 引导程序（BOOTAA64.EFI）

启盘之内核分四段：0x40080000 起之内核、0x50000000 起之大段区、0x56000000 起之控台字模、0x57000000 起之字体之模（桌面之 TrueType 字体，首十六字为魔数“YYFONT01”与长）。

其于 QEMU 之法见[说明](../说明.文言.md)臂六十四启盘之节，此惟书为平台号一所增之步：

1. 读毕内核诸段，复取 UEFI 内存表；可用内存（类一至四、七）之最低起址，依一吉下取整而减 0x40000000，即物理之偏；内核目标区间随之移于 0x40000000 加偏起。
2. 退启动之务前，取 GOP 之帧缓、配置表中 ACPI 二之根，呼运行时之务 GetTime 取时（依 UTC 折之）。
3. 退启动之务后，依缓存之行洗而废内存表之缓冲与 ACPI 之区（类九、十），关 MMU 与缓存。
4. 零开机参数之区，书上表诸项；自内存表抄保留区段：类非一至四、七，且小于十一者（固件所留、运行时之务、ACPI 等）。平台号取“物理之偏非零”。
5. 拷诸段于载址加物理之偏。
6. 物理之偏非零，则于引导程序自栈之底建暂页表：虚址零至一吉设备内存恒等映之，一至二吉映于实址 0x40000000 加偏，二吉以上以一吉大块恒等映至内存之末；MAIR、TCR 同内核，开 MMU（缓存仍关），乃跳入内核之口虚址 0x40080000。

## 内核

- **平台初置**：手书之核设栈之后，先呼底层豫言内核之「平台初置」（`内核/平台。底层。豫`）。平台号一，则读 SPCR 定串口之类与址，读 MADT 定 GIC 分发器与重分发器，读 MCFG 定 PCIe 配置空间；预置页表（虚址 0x400A0000 起七页）中指内核区之项加物理之偏；设备二级表中 GIC 之项改指 0x400A7000 之三级表，使虚址 0x08000000、0x080A0000 落于实之分发器与重分发器；映 PCIe 配置空间于虚址 0x3F000000，恒等映串口所居之二兆之块。手书之核继而设 TTBR0 为预置零级表之实址（虚址加物理之偏），自是用内核自之页表。
- **串口**：出入依串口之类，循 PL011 或 16550 之寄存器；类一则出者弃之，无入。
- **内存池**：自实址二吉加物理之偏起（VMware 上自 0xC0000000 起，避内核区），保留区段所覆之块置为已占。
- **页表之根**：旧槽零、一之零级表之实址，虚址加物理之偏；内核依实址读写页表，经二吉以上之恒等大块（VMware 上虚址二至三吉正为内核区之别映）。
- **墙钟**：平台号一，则墙钟之秒为开机墙钟之秒加（今之虚拟计数减开机之计数）除以计数之频。
- **单核**：平台号一，惟用开机之核。
- **帧控台**：有 GOP 帧缓（像素之式零、一，址在二吉以上），则「平台初置」恒等映帧缓所在之一吉，映启盘所带之控台字模（同兼之 `yy控制台字模.bin`，装于虚址 0x56000000）于内核区；开机内存初置之后清屏而启之。手书之串口出字之例程每出一字，呼底层豫言内核之「帧控台字节」（`内核/帧控台。底层。豫`）：依 UTF-8 积码点，白字黑底绘二十四乘三十二之字形（ASCII 宽十二），行换、回车、退格皆处之，行满自换，至屏底一举上移半屏。VMware 之 GOP 与 QEMU 之 `-device ramfb` 皆可。
- **USB 键鼠**：开机内存初置之后，有 ACPI 之根则「键鼠初置」（`内核/键鼠。底层。豫`）于 PCIe 配置空间（「平台初置」映其首三十二总线于虚址 0x30000000）寻首 xHCI 之主控，映其寄存器（BAR 在二至五百一十二吉则恒等映之，否则映于虚址 0x32000000），要二兆之块以置环与上下文，复位之，以命令环、事件环（巡之，不开断）编址根端口之设备，读描述符，配 HID 键鼠之中断端点。根端口上之 USB 2 集线器，待根端口毕乃理之：读其描述，以配端点之令标其槽为集线器，诸口上电、复位，其下之设备依路由（口号）与 TT（高速集线器后之全速、低速者）编址。VMware 默带之虚拟键盘为引导协议；虚拟鼠标无引导协议，依其报之式识相对（接口一）、绝对（接口零）二端点。手书之『控台收入』（时钟每十毫秒、读字之务每次）先呼「键鼠轮询」：新按之键依美式键位换为字节入控台之环（回车十三、退格八、Esc 二十七、F2 为十八、Ctrl 加字母为控制之码，方向、起首、末尾、删除、翻页出 ESC [ 之序），鼠标之报换为 PS/2 三字之包入鼠标之环（绝对之坐依帧缓宽高折为位移）。
- **桌面之务**：核务三十二至三十六皆付豫言内核（旧槽亦然）。有帧缓则：三十三返宽乘六万五千五百三十六加高；三十二逐行拷任务线性内存之 RGBA 画于帧缓（式一则易红蓝），址零则清屏而还屏于控台；三十五、三十四返、读字体之模；三十六取鼠标环之一字。执行器裸机之显示后端遂于臂行桌面（「图形」）如故。

## 行于 VMware Fusion

1. 新建虚拟机：择“创建自定虚拟机”，操作系统择“其他 → 其他 64 位 Arm”，固件为 UEFI；内存二吉以上（四吉较裕）。
2. 光驱接 `yy豫言启动臂.iso`，开机固件自光盘启之。屏上显命令壳之出（中文用控台字模）。点入虚机之窗即可以 VMware 之 USB 键盘打字；入「图形」进桌面，鼠标可用。
3. 串口可别接，便于录或自宿主打字：于 `.vmx` 书

   ```
   serial0.present = "TRUE"
   serial0.fileType = "pipe"
   serial0.fileName = "/tmp/yy串口.sock"
   serial0.pipe.endPoint = "server"
   efi.serialconsole.enabled = "TRUE"
   ```

   开机后以 `nc -U /tmp/yy串口.sock` 连之，乃可于命令壳中打字。

实验（二〇二六年十月九日，VMware Fusion，四吉、二虚拟处理器）：开机至“壳>”；于串口入「日期」，得正之本地时；连入「日期」八次，屏满而上移无误。QEMU 加 `-device ramfb`，屏之截图与串口所出同。

USB 键鼠之验（二〇二六年十月十日）：QEMU（qemu-xhci 加 usb-kbd、usb-mouse，edk2 与 ramfb）中以监视器注键行命令、进桌面，鼠标移而点「任务管理器」开其窗；VMware Fusion 中识 xHCI 与键鼠之设备而配其端点，经串口进桌面而虚机运行如常。仿 VMware 默认 USB 之配（键盘在根端口七之集线器后）所造之虚机，集线器七口上电复位而识键盘、配其端点；QEMU 中键鼠接于 usb-hub 之后，注键如常。

## 后续版本之事

- 数据盘：VMware 之 NVMe、SATA 之驱动，与 PCIe 设备配置空间之读写。
- 多核：依 MADT 诸核之 MPIDR 唤余核（VMware 第二核为 0x10000）。
- 鼠标滚轮、按键重复、大写锁定、多层与 USB 3 集线器后之设备、热插拔。
- 惟识 ACPI 二之 XSDT；UEFI 之时依 UTC 解之（VMware 所给乃宿主本地之时，系统时区默认零时，所显正为本地之时）。
