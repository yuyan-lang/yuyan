# 内置 Linux 驱动客体

此乃豫言内核为宿主，内置 Linux 虚拟机以载既有驱动及用户态组件之实施议。所记为拟分工及验成之准；虚拟机入行与 Linux 嵌套启动皆未成。

## 开发机之验

用户许随时用 pit-mac；pit-pc-ubuntu 连接不稳，继明许用之测试。开发先用今机及 pit-mac，x86 KVM 之验用 pit-pc-ubuntu。其机今备 QEMU 10.2.1，用户 zc 入 kvm 组，`/dev/kvm` 可读写，嵌套 KVM 为 Y。

`林虚拟化探测。豫` 循既有豫言核长模式启码，成专用 Multiboot 镜像；初置片实行 CPUID 叶一，验 ECX 第五位，书结果而停机。镜像 SHA-256 为 `96f42f123e8a8fde3bf322aebe1f2cbfc97f26f34aed2a2e12a80bb83415590f`。同镜于 pit-pc-ubuntu 以 `-machine pc,accel=kvm -cpu host,+vmx,enforce` 启，串口实得“豫言核心启动”“客体可见VMX”；以 `-machine pc,accel=tcg -cpu qemu64` 启，实得“客体不支持VMX”。二验皆书探毕之标记，继由十秒 timeout 终止。此证第一层豫言核可见 VMX；未读其 MSR，未行 VMXON，未建 EPT，未入第二层客体。

2026-10-03 唯读核实：今机为 ARM64 macOS；受信之 pit-mac 为 Apple M2 Max、ARM64。二者不能供此役原生 x86 VMX 之验。

pit-pc-ubuntu 为 x86-64、Intel Core i9-14900K，CPU 报 VMX、EPT，`/dev/kvm` 在，`/sys/module/kvm_intel/parameters/nested` 为 `Y`。SSH 用户 zc 之组未含 kvm，验 `/dev/kvm` 可读写未过。标准 `/usr/bin`、`/usr/local/bin` 未见 qemu-system-x86_64。须备 QEMU 及 KVM 使用权，乃以豫言内核自探并实入虚拟机，验第一层客体所见之能。宿主有标志，尚不能称嵌套已成。

外层用 QEMU/KVM、`-cpu host`；普通 TCG 不作 VMX/SVM 验成之替。开发机 Linux 惟承外层模拟器，产品仍由豫言内核载 Linux 客体。

## 三阶

### VMX 根操作入行之验

继验 VMCS：专镜于物理 0x06002000 备一页，抄 VMX_BASIC 版本号，VMCLEAR 后 VMPTRLD；以 VMWRITE 书 1048576 于 GUEST_RIP（0x681E），以 VMREAD 读还而比。诸 VMX 指令即验 CF/ZF；毕则复 VMCLEAR 而验，继 VMXOFF。KVM 实录有“VMCS清空装入及字段读写已验证”“VMCS回收已执行”，继根操作出及探毕；十秒 timeout 终止。今镜 SHA-256 为 `ecb8616aff970b6238939e00d511f0bae7786f1a88299252b203ec22454d4986`。构建及独立类型检查过。VMCS 基本操作已有实行之证；诸字段全备、EPT、VMLAUNCH、第二层客体之行皆未成。

探能首版之后，专用器已加 VMXON/VMXOFF。先验 IA32_FEATURE_CONTROL 锁位及 SMX 外允许位；未锁则惟于此验客体置允许而锁之。验 IA32_VMX_BASIC 所需区不逾一页、内存类为 WB，循 CR0/CR4 固定位正寄存器。专镜于物理 0x06000000 清一页而书版本，于 0x06001000 存其物理指针，须至少 128 MiB 内存。VMXON 后即验 CF/ZF，成则 VMXOFF，二返回路皆还原 CR4、CR0。通行之动态分配与 MSR 异常之复，留待办事项。

2026-10-03 于同一受许验机、同 QEMU 参数，KVM 串口实得“VMXON及VMXOFF已执行”，继得探毕标记；TCG 实得不支持及探毕标记，未行 VMX 指令。二验由十秒 timeout 终止。镜像 SHA-256 为 `f2c3f6cb15700497ac0cb523e8eeac189c2498117d07f085e0ab2638446db34f`。此惟证豫言核入出 VMX 根操作；VMCS、EPT、第二层极小客体之入及退出分派皆未验。所据为 [Intel 系统手册](https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html) 与固定 Linux 源码之 MSR 定义。

极小客体备器为 `林极小客体准备。豫`，构建入口为 `豫言裸机 林极小客体准备`。行 `yy林极小客体准备.wasm yy极小客体.bin`，成九十八字节长模式指令，拟载入口一零四八五七六。先书三于 COM1 之 LCR（0x3FB），定八位；继书 UTF-8 标记“豫言极小客体已执行”及换行于 0x3F8，末 HLT。不用栈及中断；宿主须备长模式与客体可执行映射，每次 I/O 出后依指令长进 RIP，遇 HLT 出而续行宿主。

今机以 LLVM 独立反汇编，核一次配置输出、二十八次数据输出及末 HLT；器之类型检查过。产物 SHA-256 为 `47aba03543b8d23c49da8414627f8886b041d99450b8ab2d82d39ec77e9b2d46`。此惟证所备指令合意，客体实行、VMX 出及宿主续行皆未得证。

| 阶 | 此向所任 | 所待于硬件向 | 验成 |
|---|---|---|---|
| 极小客体 | 定 RAM、入口、串口与日志，备书串口而停机之指令字节 | 探能、VMXON/VMCS、寄存器、EPT、入出与败诊 | 分明无能、入败及客体实书之标记；HLT 出而宿主续行 |
| Linux 启动 | 定内核、装载参数、最小设备与日志 | 客体内存、CPU/MSR、中断注入与时钟推进 | 先见 Linux banner，后见 init 标记；外层 QEMU 直启 Linux 不计成 |
| 服务往返 | 以第二串口传请求响应，豫言书客体服务，先通回声 | 串口读出、响应注入、续行与回收 | 豫言送编号，Linux 服务还同编号及文；客体止而宿主可用 |

硬件会话尚未受此架构新令，不假定其已作 VMX，不复改其内核代码。下文为待合验之内部约定，明分工后定代码接口。

## 首客体

固定 Linux 6.12.112，乃 2026-10-03 官方长期维护版。源码已得，置 `/private/tmp/yyLinux-6.12.112.tar.xz`，SHA-256 为 `164dc9d1f6c93c61a15e1f071c48379b467f2b17c469cce7223471968208ed03`，与官方清单合；于 pit-pc-ubuntu 用临时目录之依赖构成。旧 `/boot/vmlinuz-7.0.0-34-generic` 不许读，未以之验解析。Linux 为外部客体，存其旧语言、配置之式及构建法；仓中新装载器、设备模型、验证器及客体服务皆以豫言书，不转写 Linux 驱动。实配置存 `豫言操作系统/宿主/林驱动客体/内核配置`，构建诸事见其双语说明。

初设一 vCPU、512 MiB 独占 RAM，径载 x86-64 bzImage 与 initramfs，不增客体 BIOS、UEFI、图形、PCI 枚举及真器直通。initramfs 惟备 `/init`、控制台与验收服务；可循仓中既有 Linux 原生执行之路，先验其成品可独立为 init。

装载器验 boot flag、HdrS、协议版、六十四位入口、setup_sects、syssize、kernel_alignment、pref_address、init_size、命令行容量及 initrd 上界。依头部求压缩主体之位，不以全 bzImage 为代码入口。清零 boot_params，复制 setup header，填命令行、initrd 及 E820。六十四位入口在所载主体加 0x200；RSI 指参数页，依协议定段寄存器、禁中断，恒等映射解压所需之域、参数及命令行。依实有 init_size 与 initrd 求布局，毋重叠。

## 设备及 CPU 约

拟以 16550 COM1（0x3F8）记日志，COM2（0x2F8）通服务。豫言截客体端口 I/O，模拟收发、线路状态及初置寄存器；日志归宿主，不放任客体直访真串口。

早期日志可轮询，Linux 全启仍需时钟及中断。已验固定版 `arch/x86/Kconfig`：X86_64 选 X86_LOCAL_APIC，继选 X86_IO_APIC，禁 SMP 不能于构建中去之。初议单处理器、禁 ACPI 与 PCI，`noapic` 禁 IOAPIC 路，`nox2apic` 禁 x2APIC，留 LAPIC 及 PIC/PIT；仍待实启，不称惟 UART 即足。CPUID、控制寄存器、MSR、异常及 EPT 出因，须与 Linux 所见之能合；未成之 kvmclock 等勿宣。

先见早期 banner，再成时钟、中断及 init；逐阶存全日志及首未处置之退出。参 QEMU microvm 之设备范围，不称豫言已有其实现。

## 首服务

求速往返，先以专串口传可打印单行：请求 `编号 回声 内容`，响应 `编号 成功 内容`。日志与服务异道，一时惟一请求在途。单行预算初取 65536 字节，逾则报败；UTF-8 编码，初验文无换行。此为内部验收之约，未立公开应用 ABI。

Linux 服务先还原文，豫言验编号及文，乃停客体而验宿主可续行。后由 Linux 客体办无线网络及 CUDA，专服务受任务而还果。真 DMA 设备分配、中断隔离、IOMMU、复位及 CUDA 版本匹配属后阶。E40 CPU、无线网卡 ID 与 VT-d 未明，不据此许其直通。

## 装载准备代码

`林客体装载。豫` 已成 bzImage 校验、主体截取、四 GiB 下载址及 initrd 布局、4096 字节 boot_params、三项 E820 与零终令文。参数页在 0x9000，令文在 0x20000。初版惟受协议不下二点一二、六十四位可移之高位载镜；初置区与 initrd 重叠则拒。

`林客体准备。豫` 成内核、参数页、令文及 initrd 四片原始二进制，印客体址，待虚拟机装载端接之：

```text
节点 yy豫构.wasm 构建 豫言裸机 林客体准备 --输出 yy林客体准备.wasm -j 24
节点 yy林客体准备.wasm 内核bzImage 初盘或无 yy林客体
```

`林客体装载。测试。豫` 于节点宿主过十六项产物核对及十四项恶损、不支持输入之拒验，含主体首末、initrd 址与长、空 initrd、令文、E820、sentinel 清零、坏头、主体截断、错对齐、高址及区重叠。真 Linux 6.12.112 bzImage 亦已解析而成各片；VMX 客体行及嵌套 Linux 启动未得验果。

## 串口模型之进

`林客体串口。豫` 已成内部双口之态、DLAB 除数闩、IER/LCR/MCR/SCR、轮询线路状态、六五五三六字节接收环、回环探测、收发中断原因及发送确认。书发送寄存器还待输出之字，待 VMX 出端转传日志或服务；余书还负一，不访真串口。OUT2 使能中断线路；读接收寄存器消队列，读 IIR 确认发送中断。FIFO 今惟拟开关及接收清空；门槛、超时、线路之败、调制变化中断及波特率计时待 Linux 合验。

`林客体串口。测试。豫` 于节点宿主过初置、除数、UTF-8 输出、零字节接收、双口隔离、回环及中断确认等二十八验，模型类型检查亦过。未接 VMX I/O 出端，未证真 Linux 驱动行成。

2026-10-03：于 pit-pc-ubuntu `/tmp/yy林客体依赖/根` 解发行版 flex、bison、m4、libelf、OpenSSL、zlib 及 zstd 构建依赖与运行库，不易系统包；固定内核源置其 `/tmp/yy林客体源码/linux-6.12.112`，循 Linux 旧构法成最小 x86-64 配置并构 bzImage。已核六十四位、可移、ELF、initramfs 及 8250 控台皆启，APIC/IOAPIC 仍入。镜像长九五九四八八字节，SHA-256 为 `44a9b83d29f842a85eb99c8c9b853c53c00053275c29b0afc589539750c23b01`；装载器所得载址一六七七七二一六、入口一六七七七七二八，参数页长四零九六字节。惟验构镜及备载，KVM 权未易。

固定镜像已于外层 QEMU microvm/TCG 径启，串口见版本、时钟初置及 devtmpfs 挂载；未供 init，末报 `No working init found`。此基线惟辨镜像自身之败，未计三层嵌套之阶为成。

## 初进程及服务基线

`原生样例/林初进程` 为新增底层豫言包「原生林初进程」，循旧原生生成器成静态 x86-64 ELF。惟用既有 read、write、openat、ioctl、ppoll 绑定；PID 1 不依动态库及 WasmGC 执行器，先书启动标记，继以原始 termios 开 `/dev/ttyS1` 而供服务。

`林初盘格式。豫` 及 `林初盘准备。豫` 成标准 newc initramfs，含可行之 `/init`、`/dev/console`（5:1）、`/dev/ttyS0`（4:64）、`/dev/ttyS1`（4:65）。径、权及器号经系统 cpio 与 Linux 自解之验。

```text
节点 yy豫构.wasm 构建 原生林初进程 --输出 yy林初进程.wasm -j 24
节点 yy豫构.wasm 构建 豫言裸机 原生生成 --输出 yy原生生成.wasm -j 24
节点 yy原生生成.wasm Linux 兼容六十四 yy林初进程.wasm yy林初进程
节点 yy豫构.wasm 构建 豫言裸机 林初盘准备 --输出 yy林初盘准备.wasm -j 24
节点 yy林初盘准备.wasm yy林初进程 yy林初盘.cpio
节点 yy林客体准备.wasm yy林内核6.12.112 yy林初盘.cpio yy林含初盘客体
```

2026-10-03 于 QEMU `pc`/TCG、qemu64、单核、512 MiB 径载固定 Linux 与此初盘。COM1 记日志，COM2（0x2F8、IRQ3）循本机 TCP 端口 42791 转传。日志见 `Run /init as init process`、`豫言Linux客体init已启动`、`豫言Linux客体服务就绪`。`林服务验收。豫` 以标准库 TCP 逐字节验编号、UTF-8、空白、未知令后续行、空文及逾六五五三六字节之行拒后续行，皆过。客户端退而服务常驻，验毕止此役 QEMU 基线之进程。
