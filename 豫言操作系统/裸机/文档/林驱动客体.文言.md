# 内置 Linux 驱动客体

此乃豫言内核为宿主，内置 Linux 虚拟机以载既有驱动及用户态组件之实施议。已于外层 QEMU/KVM 内，以豫言核入极小客体，成串口 I/O 出、VMRESUME、HLT 出及宿主续行；Linux 嵌套启与嵌套服务往返未成。下文分阶存早验之录。

## 首次真实嵌套之验

继广内存至固定 Linux 所需 512 MiB。专用宿主页表以零至二 GiB 成 supervisor-only 恒等映射；客体 EPT 惟以 GPA `[0, 0x20000000)` 映宿主物理 `[0x40000000, 0x60000000)`，VMX、VMCS、EPT、寄存器上下文及宿主新 PD 皆居低址留区。客体初页亦覆零至 512 MiB。夹具书 0x44332211 于 GPA 0x1FFFF000，宿主自物理 0x5FFFF000 读还核之，证末页实可达。常核分配及页权之法未易，恒等映射惟用于不行常用户任务之专镜。

2026-10-03 以外层 `-m 2G` 实验，KVM 录有“五百一十二MiB客体末页写入已验证”，复有 CPUID、寄存器、客体输出、HLT 续行与回收标记。镜 `yy林虚拟化大内存.bin` SHA-256 为 `ddaf619198e60338153f71cdf05f8cf76523f9ab44078653a5337d90a8b564d9`。KVM 验十五秒后由 timeout 终，TCG 同布局之不支持路亦过；构建与类型检查过。今专镜须至少二 GiB 内存。此惟证所述行访，Linux 尚未于内置客体启；继须抄其装载片而易入口。

继备退出通用寄存器上下文及 CPUID 分派。RSP 归 VMCS 管，内部片以六十四位尽存余十五寄存器于宿主物理 0x06007000 起之别区；分派惟改返回值，VMRESUME 前尽复。今惟供一客体一处理器。CPUID 普通叶至一，扩展叶至 0x80000001，宣单处理器，存宿主厂商及处理器签名，隐 VMX、hypervisor、XSAVE/AVX、半虚拟化叶；未知叶还零。最低指令之能据固定 Linux `required-features.h` 复核，仍待真 Linux 启验。

第二版夹具先置 R8 全六十四位标记、R9 标记，行 CPUID 叶零与一，以 R10/R11 存结果，继书原二十八字节而 HLT。宿主验诸值、输出计数与出因；初验见核验读取目标之误，正后复验过。2026-10-03 KVM 实录有“CPUID及跨退出寄存器保存已验证”，继 HLT 续行及回收标记。镜像 `yy林虚拟化上下文.bin` 之 SHA-256 为 `923e483ebc96e39e0b9656e45a0dc758171470794f251852c456921ef40650eb`；构建与独立类型检查过。此证及所列寄存器标记、CPUID 二叶，不能称 Linux 全态、CPUID 诸叶及中断皆备；Linux 嵌套启仍未成。

`林虚拟化运行。豫` 为专镜内部片。循能力 MSR 定执行控制，用独立两 MiB 客体物理区、客体分页根及长模式段态；读宿主今控制寄存器、EFER、FS/GS 基址、描述符表基址，定 VM-exit 宿主 RIP/RSP。客体初禁中断，行与极小夹具同之九十八字节指令。初诊见 CR 掩码字段换算之误，已据固定 Linux vmx.h 正之；FS/GS MSR 号亦据源复核。书字段败则记末字段号，入败及异常出则书十六进制错误号或出因。

运行无条件截 I/O 及 HLT。惟受此夹具 COM1 单字节输出：LCR 配置写予确认，数据写转宿主串口；每出依 VM-exit 指令长进 GUEST_RIP，继 VMRESUME。HLT 出则核二十八 UTF-8 字节皆转传，书宿主续行之标记，收 VMCS 而 VMXOFF。此乃极小客体内部桥，完整串口模型及中断注入仍待 Linux 合验。

## 三阶

### EPT 备表与指针之验

专镜已读 IA32_VMX_EPT_VPID_CAP，须有四级遍历、WB 及二 MiB 大页。三表页居宿主物理 0x06003000、0x06004000、0x06005000；以可读、可写、可执行之 WB 大页，将客体物理零至二 MiB 映于宿主物理 0x04000000 起，余项清零。EPT_POINTER（0x201A）置 0x0600301E，VMWRITE/VMREAD 实读相合。KVM 录有“EPT能力及指针读回已验证；映射尚未执行”，继 VMCS 回收、VMXOFF 及探毕。

探片增长，固定核码区重叠之验拒旧布局。今以极小跳转片，自核初置入口入物理六 MiB 专用码区；先验旧区皆零乃书，串口输出用本片别函数。常核布局及 ABI 未易。正后 KVM、TCG 入口皆实过，构建及类型检查亦过；今镜 SHA-256 为 `a99bdc7b30b4f62647633e72d588fdae1c764cf128c4c71ef92b6c83235556a4`。EPT 执行控制、宿主与客体全态及 VMLAUNCH 未成；今证惟及探能、备表与指针书读。

### VMX 根操作入行之验

继验 VMCS：专镜于物理 0x06002000 备一页，抄 VMX_BASIC 版本号，VMCLEAR 后 VMPTRLD；以 VMWRITE 书 1048576 于 GUEST_RIP（0x681E），以 VMREAD 读还而比。诸 VMX 指令即验 CF/ZF；毕则复 VMCLEAR 而验，继 VMXOFF。KVM 实录有“VMCS清空装入及字段读写已验证”“VMCS回收已执行”，继根操作出及探毕；十秒 timeout 终止。今镜 SHA-256 为 `ecb8616aff970b6238939e00d511f0bae7786f1a88299252b203ec22454d4986`。构建及独立类型检查过。VMCS 基本操作已有实行之证；诸字段全备、EPT、VMLAUNCH、第二层客体之行皆未成。

探能首版之后，专用器已加 VMXON/VMXOFF。先验 IA32_FEATURE_CONTROL 锁位及 SMX 外允许位；未锁则惟于此验客体置允许而锁之。验 IA32_VMX_BASIC 所需区不逾一页、内存类为 WB，循 CR0/CR4 固定位正寄存器。专镜于物理 0x06000000 清一页而书版本，于 0x06001000 存其物理指针，须至少 128 MiB 内存。VMXON 后即验 CF/ZF，成则 VMXOFF，二返回路皆还原 CR4、CR0。通行之动态分配与 MSR 异常之复，留待办事项。

2026-10-03 于同一受许验机、同 QEMU 参数，KVM 串口实得“VMXON及VMXOFF已执行”，继得探毕标记；TCG 实得不支持及探毕标记，未行 VMX 指令。二验由十秒 timeout 终止。镜像 SHA-256 为 `f2c3f6cb15700497ac0cb523e8eeac189c2498117d07f085e0ab2638446db34f`。此惟证豫言核入出 VMX 根操作；VMCS、EPT、第二层极小客体之入及退出分派皆未验。所据为 [Intel 系统手册](https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html) 与固定 Linux 源码之 MSR 定义。

极小客体备器为 `林极小客体准备。豫`，构建入口为 `豫言裸机 林极小客体准备`。行 `yy林极小客体准备.wasm yy极小客体.bin`，成九十八字节长模式指令，拟载入口一零四八五七六。先书三于 COM1 之 LCR（0x3FB），定八位；继书 UTF-8 标记“豫言极小客体已执行”及换行于 0x3F8，末 HLT。不用栈及中断；宿主须备长模式与客体可执行映射，每次 I/O 出后依指令长进 RIP，遇 HLT 出而续行宿主。

今机以 LLVM 独立反汇编，核一次配置输出、二十八次数据输出及末 HLT；器之类型检查过。产物 SHA-256 为 `47aba03543b8d23c49da8414627f8886b041d99450b8ab2d82d39ec77e9b2d46`。此惟证所备指令合意，客体实行、VMX 出及宿主续行皆未得证。

## 设备及 CPU 约

拟以 16550 COM1（0x3F8）记日志，COM2（0x2F8）通服务。豫言截客体端口 I/O，模拟收发、线路状态及初置寄存器；日志归宿主，不放任客体直访真串口。

早期日志可轮询，Linux 全启仍需时钟及中断。已验固定版 `arch/x86/Kconfig`：X86_64 选 X86_LOCAL_APIC，继选 X86_IO_APIC，禁 SMP 不能于构建中去之。初议单处理器、禁 ACPI 与 PCI，`noapic` 禁 IOAPIC 路，`nox2apic` 禁 x2APIC，留 LAPIC 及 PIC/PIT；仍待实启，不称惟 UART 即足。CPUID、控制寄存器、MSR、异常及 EPT 出因，须与 Linux 所见之能合；未成之 kvmclock 等勿宣。

先见早期 banner，再成时钟、中断及 init；逐阶存全日志及首未处置之退出。参 QEMU microvm 之设备范围，不称豫言已有其实现。

## 首服务

求速往返，先以专串口传可打印单行：请求 `编号 回声 内容`，响应 `编号 成功 内容`。日志与服务异道，一时惟一请求在途。单行预算初取 65536 字节，逾则报败；UTF-8 编码，初验文无换行。此为内部验收之约，未立公开应用 ABI。

Linux 服务先还原文，豫言验编号及文，乃停客体而验宿主可续行。后由 Linux 客体办无线网络及 CUDA，专服务受任务而还果。真 DMA 设备分配、中断隔离、IOMMU、复位及 CUDA 版本匹配属后阶。E40 CPU、无线网卡 ID 与 VT-d 未明，不据此许其直通。
