# 客体二号

用户态豫言客体执行器二号，以**底层模式**的普通豫言编写（旧的括号式 `.低阶` 源码由此取代）。它解释执行普通豫言编译得到的 WasmGC 模块：栈机解释器、分配与标记清扫回收、异常、结构与数组、宿主原语（输出、文件、命令行、同步子进程）、持久文件系统与 Virtio 块设备驱动。

## 构建

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 客体二号 --输出 /tmp/yy客体二号.wasm
```

产物是标准 Wasm 模块（导出 `启动`），由验证工具 `豫言操作系统/裸机/普通豫言验证。豫` 读入后追加客体模块与标志数据段，生成裸机镜像。内存布局常量（`布局`）的地址与验证工具约定一致，不得随意改动。

## 模块

`布局` 内存布局与状态格常量；`基础` 输出、变长整数、内存与宽整数助手；其余模块依依赖顺序排列。语言约定见 `应用/豫言编译器/文档/底层模式.汉语.md`。

## 豫言操作系统底层接口：裸机后端

`裸机底层状态码`、`裸机底层基础`、`裸机底层句柄`、`裸机底层文件`、`裸机底层终端`、`裸机底层网络`、`裸机底层进程` 七个模块，是[豫言操作系统底层接口](../../../豫言操作系统底层接口/总纲.汉语.md)在裸机上的实现（45 个函数，方案见[底层接口方案](../../../文档/豫言操作系统底层接口方案.汉语.md)）。它们是**新增、独立**的模块：直接复用既有的文件系统（`fs读文件`、`fs写文件`、`fs建目录`、`fs删除`等）、控制台（`读字节`、`读行`、`打印串`）与时钟（`时钟滴答`、`墙钟秒`）原语，不改动这些既有实现；入口只在启动时新增一次 `底柄_初始化` 调用（借用「暂存缓冲」头 8 字节存句柄表基址与终端模式，经 `取区域` 动态分配句柄表、路径缓冲与内容缓冲，不与既有状态格冲突）。

- **句柄模型**：句柄 0/1/2 是标准三流；句柄 3 恒为根目录（唯一的预开目录）；4 起的 13 个槽按需分配给已打开的文件与目录，每槽有独立的路径缓冲（224 字节）与内容缓冲（4096 字节，整文件缓存）。
- **路径解析**：相对目录句柄解析，不含当前目录，`..` 越出目录句柄子树报错，与既有 `主机文件` 里依赖“当前目录”状态的路径规范化是两套独立的逻辑。
- **已知限制**（均已在各文件的双语注释里逐条注明）：`底层网络`、`底层进程` 全部返回“不支持”（网络因裸机无网络栈；进程因桥接既有的 GC 对象参数子进程机制不在本轮范围）；`建管道`、`取终端尺寸` 返回“不支持”；`填随机字节` 返回“不支持”（裸机熵源未定）；文件与目录内容缓存上限 4096 字节，超过则相应操作返回“溢出”；单调时钟精度 10 毫秒（内核滴答），墙钟精度 1 秒（RTC）。
- **GC shim 的改接**：控制台输出原语（1–4 号）经本接口的 `写`；Linux 上的文件原语经本接口的 Linux 后端（见下节）。裸机上的文件原语仍直接用执行器内的文件系统（待办事项：放大整文件缓存的上限后改经本接口）。

## 多平台：同一份执行器在 Linux 与 macOS 上运行

执行器是同一份整数 Wasm 模块，由寄存器降级按目标生成裸机镜像、Linux 可执行文件或 macOS 可执行文件。运行时靠目标内建导入 `导入：目标：平台号`（降级时绑定为常量：裸机 1、Linux 2、macOS 3）选择平台实现；其他目标的导入降级为陷阱桩，不会被执行。

- `林系统`、`苹系统`：Linux 系统调用包装（导入模块名 Linux）与 macOS libSystem 包装（导入模块名“苹果”，返回 -1 时导入桩已换成 -errno），以及 `是林`、`是苹` 与各自的 errno 转换表（两个系统的 errno 编号不同）。`原生系统` 在两者之间分派写、读、退出、时钟与终端判断。
- `平台`：写字节、读字节、退出、时钟滴答、墙钟、中断查询在原生系统上改走系统调用或 libSystem；任务与邮箱服务在原生系统上尚未实现，按失败返回（待办事项）。
- `林启动`、`苹启动`：启动时写程序名区、参数区与环境块。Linux 读 `/proc/self/exe`、`cmdline`、`environ`；macOS 用 `sysctl` 的 `KERN_PROCARGS2`（缓冲是启动时新增长的两页）。之后的宿主原语不必区分平台。
- `林底层`、`苹底层`：底层接口 45 个函数的 Linux 与 macOS 后端，`原生底层` 按平台号在两者之间分派（函数名加前缀“原底_”）；裸机后端各函数开头在原生系统上转到这里。句柄就是文件描述符，3 号是根目录“/”。Linux 打开用 `openat2` 加 `RESOLVE_BENEATH`（越界返回 76），`ENOSYS` 时退回 `openat`；macOS 没有等价标志，目前只拒绝绝对路径与“..”段（待办事项：逐段检查符号链接）。状态分别取自 `statx` 与 `fstatat`，目录分别取自 `getdents64` 与 `__getdirentries64`。网络、进程、等待与终端模式暂返回 58。
- `原生文件原语`：原生系统上的文件宿主原语，路径仍由 `规范参数` 规范成绝对路径，再经底层接口访问宿主文件系统；启动时当前目录取自 `/proc/self/cwd` 或 `getcwd`。
- 生成与验证：`yy原生生成 Linux|苹果 臂六十四|兼容六十四 执行器.wasm 输出 客体.wasm` 把客体模块嵌进执行器，得到独立可执行文件（macOS 目前只有 arm64）；`yy原生一致性`（`豫言操作系统/裸机/原生一致性。豫`）把普通探针与文件探针在 Linux（两种架构；非 Linux 系统上加 `--经 docker`）或 macOS（`--系统 苹果`，本机运行）上运行，与裸机验证所用的期望输出逐字比较。
