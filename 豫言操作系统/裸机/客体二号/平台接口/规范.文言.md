# 持久块服务

此为 AMD64 裸机初始任务取用内核 USB bulk-only 块设备之接口。服务号二十八至三十一，各应容量、读取、写入、同步。容量报可用五百一十二字节扇区数，无设备或未获授权则报零；读写与同步，零为成，一为设备之请败，负一为拒。ARM64 容量报零，余报负一。

读写之参为无符号扇区号及静态窗编码 `静偏 | (长度 << 20)`。长必五百一十二，窗末不得逾镜像所授任务零之静态域，扇区号必小于容量。内存固定则授初始页，可增长则授八页；子任务不得其权。同步不访静态窗。未授权或设备未探成，则拒其请。

写时核先自 `0x300000 + 静偏` 抄入私有 `0x07C0B000` 缓冲，读成乃自此抄还静态窗。应用不献物理址。每请唯传一扇区，复用 READ(10)、WRITE(10) 及 SYNCHRONIZE CACHE(10)。

主体居 `0x007DF000` 起之外置四 KiB 码页，主核唯存呼口。根端扫描码限于 `0x007D0000` 起之前五十二 KiB。设备初置使主核逾描述符表之界，则移至 `0x007DD000` 起之八 KiB 域，失败与串口之呼如旧；其后接服务页，复接 `0x007E0000` 之控制器码。构器验各域之长，免覆描述符表及邻码。

今唯用首个相合之 USB 大容量存储接口，未有择盘与分区之口。验时自光盘介质启，别接专用 USB 数据盘；若以启载 ISO 为首个 USB 存储器，亦探之，未知之式不自格式化。

帧缓页目录独据 `0x11F000`，IOMMU 初置用 `0x11A000` 至 `0x11EFFF`，二者不共。USB 验路未启 IOMMU，所验为服务访问之权及设备传输；旧 Virtio 之路仍用 IOMMU。

执行器先择 Virtio，其初置败乃试 USB。文件系统仍用块容量、块读、块写、块刷新，盘式不变。AMD64 启盘授初始执行器静态转运之窗，正式镜不自格式化未知之盘。非裸机目标不呼此服务。

待办事项：非五百一十二字节块、UAS、热插拔、错误之复、EHCI 及 AHCI，皆未作；实体机未验。

## 目标内建导入：页容量

`目标` 导入模块之 `页容量`，返本目标线性内存之页数上限，降级者依目标生其常数（裸机后端「目标页容量上限」）：兼容裸机六万五千五百三十五页（约四 GiB），臂裸机千二十四页（六十四兆），视窗一万六千三百八十四页，苹果与 Linux 六万五千五百三十五页。执行器起时记之为堆之页限，回收之位图与卡表依之预留；启动镜像线性内存之容，取模块所声最大页与此限之小者。

## 装载任务与读启动块

`平台` 导入模块之 `装载任务`（启动块之线性址、长）为兼容裸机之核之服务三十七：自开机所留用户区之模起一全新之子任务，返其句柄（不下六十四之偶数），败则返负一；启动块至多二兆，原样授子任务。`读启动块`（目之线性址、块内之偏）为服务三十八：偏为负一则返启动块之总长，否则每次拷至多六十四 KiB 而返所拷之数；非装载而起者返零。臂之核于三十七返负一、于三十八返零；原生之系统由执行器径返负一与零。执行器所约启动块之式见 [动态任务](../../文档/动态任务.文言.md)。装载任务之长参，第二十四至三十一位为工具映像之号（零为常装），依映像所起之子任务径行预编之码。

## 处理器核数与映像信息

`平台` 导入模块之 `处理器核数`（服务三十九）返核所启处理器核之数（余核之数加一），`在线处理器数量`（宿主原语六十五）用之。`映像信息`（映像号、目之线性偏；服务四十）拷第 k 工具映像之头（百二十八字节：客体之字节数与三处之样等）于呼者之线性内存，返零；无此号返负一。执行器据之识工具之 wasm，见 [动态任务](../../文档/动态任务.文言.md) 之“工具之映像”。臂之核于三十九返一、于四十返负一；原生之系统由执行器径返一与负一。
