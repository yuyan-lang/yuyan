# 原生跨平台声音输出实施记录

2026-10-13，提案 00018 第二期声音输出的平台补齐。

林纳克斯复用既有 `openat`、`ioctl`、`write` 与 `close` 系统原语，直接连接内核 PCM 接口。参数块按目标机 `/usr/include/sound/asound.h` 核对：硬件参数 608 字节，区间起点 260，请求掩码偏移 512，硬件参数控制值 3261088017，延迟控制值 2148024609。格式是交错十六位有符号小端整数；每块完整写入后返回。设备延迟来自内核，已播帧数按累计写入帧减待播帧计算。欠载后重新准备设备，关闭丢弃待播样本。

视窗复用系统 `winmm.dll` 的波形输出 API，固定入口登记七个函数。句柄采用现有长整数类型与参数类别六，完整保存用户态指针。AMD64 的固定导入桩对类别六省去三十二位自拷贝，后续转参使用既有六十四位转移；ARM64 已有类别六保持寄存器全宽的路径。所有新增驱动逻辑为普通底层豫言，调用头和样本存放在非回收区域，播放完的块复用，关闭时先复位设备、再解除所有头。已播帧数由系统播放位置取得。

声音接口身份与公开声明保持现有 0.1.0，原语 250–254 按平台选实现。新增的是执行器私有平台入口，宿主提供清单沿用原声音输出声明。

## 验证

- 声音原语与两平台底层模块的类型检查通过。
- 视窗长参数后端编码测试通过；检查长整数入口省去截断，保留高三十二位。
- 林纳克斯声音探针交叉编译为静态 x86-64 ELF 通过。远端头文件及声卡设备清单已读取；其后传送探针时 SSH 超时，探针尚未在远端运行。
- 公共声音探针 `应用/百工坊/设计验收/声音公共探针。豫` 直接导入声音输出规范接口，以当前源码构建的执行器树码交叉编译为林纳克斯静态 x86-64 ELF，通过类型、闭包与最终链接；苹果本机目标也构建通过。此入口排入零点一秒静音，查询设备时钟与延迟，关闭后核对流失效。发行路由的苹果声音适配选择由原生规划统一处理。
- 新增标识符检查为零。整文件标签检查中的警告来自既有接口和降级模块的旧签名，新声明均带标签。
