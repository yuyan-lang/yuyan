# 客体引用判空

用户态执行器今使 `ref.is_null` 通于已受之 GC 引与函数引。静态验栈取操作数精确引型，拒凡 `i32`；具体引更察型表，辨函数、结构、数组。验者记函数域或 GC 域于此令私录，运行时据之择空值码，不以四字节值形妄猜其类。

此域记不可省：函数空引今码 `-1`，GC 空引为 `0`，而 `i31.new(-1)` 亦得位形 `-1`，实非空引。运行时循已验之域比空值，故不误判。具体数组空引、新造数组、通用等引空值与函数空引，各循其域。

六独立标准模验诸界与整数误用反例，皆以标准网页汇编引擎复核。余引用型及普通豫言全模尚待续作。
