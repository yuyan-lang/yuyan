# 完整类型二进制读取

新增读取器复用有界字节游标，将标准类型编码读为完整类型模型。覆盖数值与向量、抽象/具体引用及可空性、打包字段与可变标记、函数参数结果、结构、数组、子类型声明和递归类型组。模型同时补入 Wasm 3.0 的异常引用与空异常底类型，它们不属于聚合引用层次。

具体堆编号按非负 s33 读取，允许合法的非最短正编号，拒绝五字节以外编码、截断、负编号及超过无符号三十二位的值。抽象堆类型按规范单字节读取；字段可变标记必须为零或一。读取结束可检查尾部多余字节。读取器沿用每向量 65536 项的资源上限，此上限属于当前实现限制。

二进制读取不等于模块验证：父类型数量、索引作用域、递归组类型等价、final 约束及字段子类型仍需上下文验证。本模块尚未接入裸机客体解码器，亦未增加 GC 对象执行或回收。

对照发现：Node 26.3.0 接受类型段 `01 60 01 63 f0 7f 00`，将其中多字节负值视为函数堆类型。当前规范却将抽象堆类型列为单字节，具体编号才允许非负 s33。因此本读取器拒绝该编码，保留差异记录，不宣称所有分类与 Node 相同。标准递归组正例在 Node 中有效。

依据：[Wasm 3.0 类型编码](https://webassembly.github.io/spec/core/binary/types.html)。测试涵盖最大编号、非最短正编号、宽数值、引用可空性、递归组字段保留，以及截断、越界、非法类型和非法字段标记。

当前构建和运行验证通过：类型模型 30 条断言、读取器 20 条断言。构建日志为 `/tmp/yy完整类型读取构建日志`，运行日志为 `/tmp/yy完整类型读取运行日志`。
