# 原生 Linux 客体初进程

设备环之口并询显示环；显示驱动可用则问 `/dev/fb0` 实几何，循共用显示块之规核之，以定位写逐行更新显存。显示环居留域偏二百五十六基、二槽各六十四基；首部留偏三十二记成功件数、三十六记末错误码。色道之约、多显示输出留后补。

此乃内置 Linux 客体之豫言 PID 1 与串口回声服务。以底层模式编之，编译器径出静态 Linux x86-64 ELF，initramfs 置于 `/init`。标准输出书启动及就绪标记，COM2 之 `/dev/ttyS1` 载服务，日志与服务异道。

启动先探 `/dev/mem` 之开及物址零起十六字节读之能，报节点缺、驱动缺或权拒，继映客物四百八十兆保留域首四页，核宿主所书设备环标识、槽数及槽长。映址为用户绝对址 `0x31C000`，占代理线性存末四页，避静数据及串口缓冲；两向环相距八吉字节，各六十四槽、槽长六十四字节。代理用六十四位共享线性存，旧整数址访存显转为长址，两端径共底层设备环之法。启动之验自首环取全事，核类、长、调用之序、旗与二载荷整数，易载荷为八十四、八十五后向他环投应，复行串口之服。初盘之器供权限 `0600`、主号一、次号一之字符设备节点。网、显、算之设备事路由列于后续之事。

接口用 Linux 系统调用之中文声名（读、写、相对打开、设备控制、带信号掩码轮询、映射内存，即 read、write、openat、ioctl、ppoll、mmap），由原生降级入口表及旧导入桩绑之。实现与文件名皆中文。termios 循 Linux x86 内核之式，定原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号为非空首项，原样还之，初版由调用者用十进制编号。文可含空白及 UTF-8。未知命令还 `0 错误 请求格式`；单行至多六五五三六字节，不计换行，逾则弃至换行而还 `0 错误 请求过长`。一时办一请求。PID 1 常驻，无字或读败则候一秒复试。

构建：`./豫构。林檎。豫行 构建 原生林初进程 --输出 林初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`（编译器径降底层之模为 ELF）。所得由 `林初盘准备` 置 newc initramfs，后供内置虚拟机；QEMU 基线之验不代嵌套。

2026-10-03：固定 Linux 6.12.112 于 QEMU pc/TCG 启至此器，启动及就绪标记皆见。豫言 TCP 客户端循 COM2 转传，验编号、中文、空白、未知令、空文、过长行拒及续后恢复，皆成。独立类型检查亦过。实 ELF 长一二四六五零四字节，SHA-256 为 `8a9995e134dc33f3938036ffcff95761ae55d6bcbb43ee53cc424e4859e70ed8`。

## 网卡 TCP 入口

实网帧验台于两环之间之末十二字，存原始套接字描述符、近书入之果、请之长，相对址各为 196596、196600、196604，供宿主核发送是否入林之队。此诊域与两环之首、槽各立。

代理开网卡，循旧设备控制问运行旗，候实链运行乃告就绪。验台于宿主用户壳初启时先连网络流，前台任务退出乃发核验之文。久断链之时限告报留于后续。

`设备环入口。底层。豫` 为原始网帧桥之口。启时初盘有 `/wl.ko` 则先以 finit_module 载之（博通 BCM4360 之闭源 wl 驱）；有 `/etc/wpa_supplicant.conf` 则分子程行 `/sbin/wpa_supplicant -i wlan0 -c /etc/wpa_supplicant.conf -D nl80211`。网卡先试 `wlan0`（wl 之接口名），无则用 `eth0`。链既备，以 SIOCGIFHWADDR 取网卡之以太址，书于设备发豫言之环（相对址十九万六千六百零八）首四十起六字，复书一于四十八；豫言之网络栈经核务六十三读之，以卡本址收发，代理不开混杂之模。代理惟启 `eth0`，以原生套接字接口开而缚非阻塞 AF_PACKET 原始套接字，搬全以太帧；网卡地址解析由豫言共用底层处之。代理四页六十四位共享线性存中，物共享域映于用户绝对址 `0x320000`，长一百二十八吉字节；收发环相对址各为 131072、196608，十六槽各二吉字节，各容三万二千八百三十二。私收发事缓相对址各为 98304、100352，环满或网卡暂未可书则留而复试，轮询候二十毫秒。定原生基址、多设备之配列于后续之事。构用 `./豫构。林檎。豫行 构建 原生林初进程 设备环入口 --输出 林网帧初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`。

`网卡入口。底层。豫` 备独立网络入口，循前述行协议。PID 1 用旧 Linux 系统调用表 socket、bind、listen、accept4、close，定 `eth0` 为 `10.0.2.15/24`，听 TCP `42794`；连接毕则闭之，复受客户端。标准输出书网络启动、就绪，服务数据循 Linux 网卡驱动收发。请求缓冲区仍六五五三六字节，监听队列一零二四。初版惟适固定 x86-64 ifreq 式及测试地址。

构建：`./豫构。林檎。豫行 构建 原生林初进程 网卡入口 --输出 林网络初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`；初盘：`节点 林初盘准备.wasm 林网络初进程 林网络初盘.cpio`。ELF SHA-256 为 `be73e651b82b76d2107664b59bc232d2b9bcbcc21135f7f63372a6ba6e5633ed`，初盘为 `142a4aeb98e81af4e21d19daedebdbc51c2a6d562188fbaf73c936fb50d14e8b`。宿主设备全路及验限见[林设备分配](../../文档/林设备分配.文言.md)。
