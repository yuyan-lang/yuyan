# 原生 Linux 客体初进程

此乃内置 Linux 客体之豫言 PID 1 与串口回声服务。以底层模式编之，循旧原生生成器成静态 Linux x86-64 ELF，initramfs 置于 `/init`。标准输出书启动及就绪标记，COM2 之 `/dev/ttyS1` 载服务，日志与服务异道。

接口存既有 Linux 系统调用英语协议字段，用旧 read、write、openat、ioctl、ppoll 降级表，不增 ABI。实现与文件名皆中文。termios 循 Linux x86 内核之式，定原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号为非空首项，原样还之，初版由调用者用十进制编号。文可含空白及 UTF-8。未知命令还 `0 错误 请求格式`；单行至多六五五三六字节，不计换行，逾则弃至换行而还 `0 错误 请求过长`。一时办一请求。PID 1 常驻，无字或读败则候一秒复试。

构建：`节点 yy豫构.wasm 构建 原生林初进程 --输出 yy林初进程.wasm -j 24`；生成：`节点 yy原生生成.wasm Linux 兼容六十四 yy林初进程.wasm yy林初进程`。所得由 `林初盘准备` 置 newc initramfs，后供内置虚拟机；QEMU 基线之验不代嵌套。

2026-10-03：固定 Linux 6.12.112 于 QEMU pc/TCG 启至此器，启动及就绪标记皆见。豫言 TCP 客户端循 COM2 转传，验编号、中文、空白、未知令、空文、过长行拒及续后恢复，皆成。独立类型检查亦过。实 ELF 长一二四六五零四字节，SHA-256 为 `8a9995e134dc33f3938036ffcff95761ae55d6bcbb43ee53cc424e4859e70ed8`。
