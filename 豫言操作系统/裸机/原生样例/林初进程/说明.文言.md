# 原生 Linux 客体初进程

此乃内置 Linux 客体之豫言 PID 1 与串口回声服务。以底层模式编之，编译器径出静态 Linux x86-64 ELF，initramfs 置于 `/init`。标准输出书启动及就绪标记，COM2 之 `/dev/ttyS1` 载服务，日志与服务异道。

启动先探 `/dev/mem` 之开及物址零起十六字节读之能，报节点缺、驱动缺或权拒，继映客物四百八十兆保留域首四页，核宿主所书设备环标识、槽数及槽长。映址为用户绝对址 `0x31C000`，占代理线性存末四页，避静数据及串口缓冲；两向环相距八吉字节，各六十四槽、槽长六十四字节。代理用六十四位共享线性存，旧整数址访存显转为长址，两端径共底层设备环之法。启动之验自首环取全事，核类、长、调用之序、旗与二载荷整数，易载荷为八十四、八十五后向他环投应，复行串口之服。初盘之器供权限 `0600`、主号一、次号一之字符设备节点。网、显、算之设备事路由列于后续之事。

接口用 Linux 系统调用之中文声名（读、写、相对打开、设备控制、带信号掩码轮询、映射内存，即 read、write、openat、ioctl、ppoll、mmap），由原生降级入口表及旧导入桩绑之。实现与文件名皆中文。termios 循 Linux x86 内核之式，定原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号为非空首项，原样还之，初版由调用者用十进制编号。文可含空白及 UTF-8。未知命令还 `0 错误 请求格式`；单行至多六五五三六字节，不计换行，逾则弃至换行而还 `0 错误 请求过长`。一时办一请求。PID 1 常驻，无字或读败则候一秒复试。

构建：`./yy豫构.exe 构建 原生林初进程 --输出 yy林初进程 -j 24 -- --目标 本机 --目标系统 林纳克斯 --目标架构 兼容六十四`（编译器径降底层之模为 ELF）。所得由 `林初盘准备` 置 newc initramfs，后供内置虚拟机；QEMU 基线之验不代嵌套。

2026-10-03：固定 Linux 6.12.112 于 QEMU pc/TCG 启至此器，启动及就绪标记皆见。豫言 TCP 客户端循 COM2 转传，验编号、中文、空白、未知令、空文、过长行拒及续后恢复，皆成。独立类型检查亦过。实 ELF 长一二四六五零四字节，SHA-256 为 `8a9995e134dc33f3938036ffcff95761ae55d6bcbb43ee53cc424e4859e70ed8`。

## 网卡 TCP 入口

`网卡入口。底层。豫` 备独立网络入口，循前述行协议。PID 1 用旧 Linux 系统调用表 socket、bind、listen、accept4、close，定 `eth0` 为 `10.0.2.15/24`，听 TCP `42794`；连接毕则闭之，复受客户端。标准输出书网络启动、就绪，服务数据循 Linux 网卡驱动收发。请求缓冲区仍六五五三六字节，监听队列一零二四。初版惟适固定 x86-64 ifreq 式及测试地址。

构建：`./yy豫构.exe 构建 原生林初进程 网卡入口 --输出 yy林网络初进程 -j 24 -- --目标 本机 --目标系统 林纳克斯 --目标架构 兼容六十四`；初盘：`节点 yy林初盘准备.wasm yy林网络初进程 yy林网络初盘.cpio`。ELF SHA-256 为 `be73e651b82b76d2107664b59bc232d2b9bcbcc21135f7f63372a6ba6e5633ed`，初盘为 `142a4aeb98e81af4e21d19daedebdbc51c2a6d562188fbaf73c936fb50d14e8b`。宿主设备全路及验限见[林设备分配](../../文档/林设备分配.文言.md)。
