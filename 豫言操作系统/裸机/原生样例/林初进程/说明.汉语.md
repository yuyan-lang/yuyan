# 原生 Linux 客体初进程

这是内置 Linux 客体的豫言 PID 1 与串口回声服务。以底层模式编译并通过已有原生生成器输出静态 Linux x86-64 ELF；initramfs 将其放在 `/init`。标准输出打印启动与就绪标记，COM2 的 `/dev/ttyS1` 承载服务，日志与服务分开。

接口文件保留既有 Linux 系统调用的英语协议字段，使用已有 read、write、openat、ioctl、ppoll 降级表，不增加 ABI。实现与文件名采用中文。termios 按 Linux x86 内核布局设置原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号作为非空首项原样返回，首版由调用者使用十进制编号。内容可以包含空白与 UTF-8。未知命令返回 `0 错误 请求格式`；单行最多 65536 字节（不含换行），超出时丢弃至换行并返回 `0 错误 请求过长`。一次处理一条请求。PID 1 常驻，读不到数据或读失败时等待一秒重试。

构建：`节点 yy豫构.wasm 构建 原生林初进程 --输出 yy林初进程.wasm -j 24`；生成：`节点 yy原生生成.wasm Linux 兼容六十四 yy林初进程.wasm yy林初进程`。生成物通过 `林初盘准备` 装入 newc initramfs，后由内置虚拟机使用；基线 QEMU 验证不能代替嵌套验收。
