# 原生 Linux 客体初进程

设备环入口同时轮询显示环；显示驱动可用时查询 `/dev/fb0` 的实际几何，经共用显示块规则核验后采用定位写逐行更新实际显存。显示环使用保留区偏移二百五十六 KiB、两个六十四 KiB 槽；首部保留偏移 32 为成功件数、36 为最后错误码。颜色通道协商与多个显示输出列为后续事项。

这是内置 Linux 客体的豫言 PID 1 与串口回声服务。以底层模式编译，由编译器直接输出静态 Linux x86-64 ELF；initramfs 将其放在 `/init`。标准输出打印启动与就绪标记，COM2 的 `/dev/ttyS1` 承载服务，日志与服务分开。

启动时探测 `/dev/mem` 的打开与物理零起十六字节读取能力，报告节点缺失、驱动缺失或权限拒绝，随后映射客体物理 480 MiB 保留区的首四页，核对宿主写入的设备环标识、槽数与槽长。映射地址为用户绝对地址 `0x31C000`，占代理线性内存末四页，避开静态数据与串口缓冲；两方向环相隔八 KiB，各六十四槽、槽长六十四字节。代理使用六十四位共享线性内存，既有整数地址访存显式转换成长地址，两端直接复用底层设备环算法。启动核验从首环取完整消息，核对类别、长度、调用序号、标志与两个载荷整数，将载荷改为八十四与八十五后向另一环投递回应，再继续串口服务。初盘准备器提供权限 `0600` 的字符设备节点，主号一、次号一。网卡、显示和计算的设备消息路由列为后续事项。

接口文件使用 Linux 系统调用的中文声明名（读、写、相对打开、设备控制、带信号掩码轮询、映射内存，即 read、write、openat、ioctl、ppoll、mmap；译名见提案 00013 附录），由原生降级入口表与已有导入桩绑定。实现与文件名采用中文。termios 按 Linux x86 内核布局设置原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号作为非空首项原样返回，首版由调用者使用十进制编号。内容可以包含空白与 UTF-8。未知命令返回 `0 错误 请求格式`；单行最多 65536 字节（不含换行），超出时丢弃至换行并返回 `0 错误 请求过长`。一次处理一条请求。PID 1 常驻，读不到数据或读失败时等待一秒重试。

构建：`./yy豫构.exe 构建 原生林初进程 --输出 yy林初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`（编译器把底层模块直接降级成 ELF）。生成物通过 `林初盘准备` 装入 newc initramfs，后由内置虚拟机使用；基线 QEMU 验证不能代替嵌套验收。

2026-10-03：固定 Linux 6.12.112 在 QEMU pc/TCG 启动到本程序，启动与就绪标记均出现；豫言 TCP 客户端经 COM2 转发核验编号、中文、空白、未知命令、空内容、超长行拒绝及随后恢复，全部通过。程序独立类型检查通过。实际 ELF 为 1246504 字节，SHA-256 为 `8a9995e134dc33f3938036ffcff95761ae55d6bcbb43ee53cc424e4859e70ed8`。

## 网卡 TCP 入口

原始网帧验台在两环之间的末十二字节保存原始套接字描述符、最近写入结果和请求长度，相对地址分别为 196596、196600、196604，供宿主核对发送是否进入 Linux 队列。该诊断区与两个环的头、槽独立。

代理置网卡为开启后，按现有设备控制查询运行旗，待实际链路运行才发布就绪标记。验台在宿主用户壳启动时先连接网络流，前台任务退出后再发送核验报文。永久断链的限时报告列为后续事项。

`设备环入口。底层。豫` 是原始网帧桥入口。启动时若初盘里有 `/wl.ko`，先用 finit_module 加载（博通 BCM4360 的闭源 wl 驱动）；若有 `/etc/wpa_supplicant.conf`，再分出子进程执行 `/sbin/wpa_supplicant -i wlan0 -c /etc/wpa_supplicant.conf -D nl80211`。网卡先试 `wlan0`（wl 的接口名），没有再用 `eth0`。链路就绪后经 SIOCGIFHWADDR 取网卡的以太地址，写到设备发往豫言之环（相对地址 196608）首部 +40 起六字节，并在 +48 写 1；豫言网络栈经内核服务 63 读取，以网卡自己的地址收发，代理不开混杂模式。代理只启用 `eth0`，以原生套接字接口打开、绑定非阻塞 AF_PACKET 原始套接字，搬运完整以太帧；网卡地址解析由豫言共用底层处理。代理的四页六十四位共享线性内存中，物理共享区映到用户绝对地址 `0x320000`，长度 128 KiB；收、发环相对地址分别为 131072、196608，十六个二 KiB 槽，各容量 32832 字节。私有收发消息缓冲相对地址分别为 98304、100352，环满或网卡暂不可写时留待重试，轮询等待二十毫秒。固定原生基址和多设备配置列为后续事项。构建使用 `./yy豫构.exe 构建 原生林初进程 设备环入口 --输出 yy林网帧初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`。

`网卡入口。底层。豫` 提供独立网络入口，沿用上述行协议。PID 1 用已有 Linux 系统调用表中的 socket、bind、listen、accept4、close 配置 `eth0` 为 `10.0.2.15/24`，监听 TCP `42794`；连接结束后关闭连接并继续接受客户端。标准输出报告网络启动与就绪，服务数据经 Linux 网卡驱动收发。请求缓冲区仍为 65536 字节，监听队列为 1024。首版只适配固定 x86-64 ifreq 布局与测试地址。

构建：`./yy豫构.exe 构建 原生林初进程 网卡入口 --输出 yy林网络初进程 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四`；初盘：`节点 yy林初盘准备.wasm yy林网络初进程 yy林网络初盘.cpio`。ELF SHA-256 为 `be73e651b82b76d2107664b59bc232d2b9bcbcc21135f7f63372a6ba6e5633ed`，初盘为 `142a4aeb98e81af4e21d19daedebdbc51c2a6d562188fbaf73c936fb50d14e8b`。完整宿主设备路径与验收限制见[林设备分配](../../文档/林设备分配.汉语.md)。
