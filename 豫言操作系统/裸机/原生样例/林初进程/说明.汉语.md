# 原生 Linux 客体初进程

这是内置 Linux 客体的豫言 PID 1 与串口回声服务。以底层模式编译，由编译器直接输出静态 Linux x86-64 ELF；initramfs 将其放在 `/init`。标准输出打印启动与就绪标记，COM2 的 `/dev/ttyS1` 承载服务，日志与服务分开。

启动时探测 `/dev/mem` 的打开与物理零起十六字节读取能力，报告节点缺失、驱动缺失或权限拒绝，随后映射客体物理 480 MiB 处的保留页，核对宿主写入的设备环标识、槽数与槽长，再继续串口服务。映射地址为用户绝对地址 `0x31F000`，占代理线性内存末页，避开静态数据与串口缓冲。初盘准备器提供权限 `0600` 的字符设备节点，主号一、次号一。跨客体双向环收发列为后续事项。

接口文件使用 Linux 系统调用的中文声明名（读、写、相对打开、设备控制、带信号掩码轮询、映射内存，即 read、write、openat、ioctl、ppoll、mmap；译名见提案 00013 附录），由原生降级入口表与已有导入桩绑定。实现与文件名采用中文。termios 按 Linux x86 内核布局设置原始八位、115200、无回显及非规范输入。

请求一行 `编号 回声 内容`，响应 `编号 成功 内容`；编号作为非空首项原样返回，首版由调用者使用十进制编号。内容可以包含空白与 UTF-8。未知命令返回 `0 错误 请求格式`；单行最多 65536 字节（不含换行），超出时丢弃至换行并返回 `0 错误 请求过长`。一次处理一条请求。PID 1 常驻，读不到数据或读失败时等待一秒重试。

构建：`./yy豫构.exe 构建 原生林初进程 --输出 yy林初进程 -j 24 -- --目标 本机 --目标系统 林纳克斯 --目标架构 兼容六十四`（编译器把底层模块直接降级成 ELF）。生成物通过 `林初盘准备` 装入 newc initramfs，后由内置虚拟机使用；基线 QEMU 验证不能代替嵌套验收。

2026-10-03：固定 Linux 6.12.112 在 QEMU pc/TCG 启动到本程序，启动与就绪标记均出现；豫言 TCP 客户端经 COM2 转发核验编号、中文、空白、未知命令、空内容、超长行拒绝及随后恢复，全部通过。程序独立类型检查通过。实际 ELF 为 1246504 字节，SHA-256 为 `8a9995e134dc33f3938036ffcff95761ae55d6bcbb43ee53cc424e4859e70ed8`。

## 网卡 TCP 入口

`网卡入口。底层。豫` 提供独立网络入口，沿用上述行协议。PID 1 用已有 Linux 系统调用表中的 socket、bind、listen、accept4、close 配置 `eth0` 为 `10.0.2.15/24`，监听 TCP `42794`；连接结束后关闭连接并继续接受客户端。标准输出报告网络启动与就绪，服务数据经 Linux 网卡驱动收发。请求缓冲区仍为 65536 字节，监听队列为 1024。首版只适配固定 x86-64 ifreq 布局与测试地址。

构建：`./yy豫构.exe 构建 原生林初进程 网卡入口 --输出 yy林网络初进程 -j 24 -- --目标 本机 --目标系统 林纳克斯 --目标架构 兼容六十四`；初盘：`节点 yy林初盘准备.wasm yy林网络初进程 yy林网络初盘.cpio`。ELF SHA-256 为 `be73e651b82b76d2107664b59bc232d2b9bcbcc21135f7f63372a6ba6e5633ed`，初盘为 `142a4aeb98e81af4e21d19daedebdbc51c2a6d562188fbaf73c936fb50d14e8b`。完整宿主设备路径与验收限制见[林设备分配](../../文档/林设备分配.汉语.md)。
