# 原生长址

路二（径生原生之二进制）之六十四位址内存（memory64）样例，底层之模。程序声六十四位址内存（最多一十亿七千三百七十四万一千八百二十四页，即六十四 TiB），增线性内存自一页至八万二千页（约五吉），于四吉上下读写四字节整数、长整数、小数与一二字节（并有号之读），读写线性内存末四字节，填四吉之上之一段，复制跨四吉之一段于四吉之上，复核逾最多页之增长返负一而页数不改。皆合则书“长址原生：通过”而以零退，否则书首不合之序而以一退。

核验书于 `核验。豫`，诸址皆长整数，读写用底层库 `内存六四` 之 `长址…` 诸函。`入口。豫` 为 Linux 之版（径发系统调用），`苹果入口。豫` 为 macOS 之版（经 libSystem）。

构与生（于仓库之根）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 原生长址 苹果入口 --输出 yy原生长址苹果.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 文件 豫言操作系统/裸机/原生生成。豫 --输出 yy原生生成.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm 苹果 臂六十四 yy原生长址苹果.wasm yy原生长址苹果
./yy原生长址苹果
```

x86-64 之版易 `臂六十四` 为 `兼容六十四`。Linux 之版：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 原生长址 --输出 yy原生长址.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm Linux 臂六十四 yy原生长址.wasm yy原生长址臂
node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm Linux 兼容六十四 yy原生长址.wasm yy原生长址兼
```

Linux 之版可于 macOS 以 Docker 行之（`FROM scratch` 之镜像，唯含此一文件，见 `原生样例/你好/说明.文言.md`）。

线性内存唯所用之页占物理内存：macOS 与 Linux 之动态区以 MAP_NORESERVE 映六十四 TiB（x86-64 之 macOS 为数据段之零填），此样唯触数页。
