# 原生你好

路二（直接生成原生二进制）在 Linux 上的最小闭环样例，底层模式。程序写一行“你好”，从标准输入读至多 64 字节并原样写出，最后以退出码 7 结束。写、读、退出直接发 Linux 系统调用：导入声明在 `林纳。底层接口。豫` 里，导入模块名就是接口文件名“林纳”，导入名是中文名（`写`、`读`、`退出进程`，即系统调用 `write`、`read`、`exit_group`；原名只记在裸机后端 `降级目标。豫` 的入口表里），寄存器降级按入口表生成系统调用桩，地址类参数在进入系统前加上线性内存基址。

构建（在仓库根目录）：编译器参数 `--目标 本机` 让编译器把底层模块直接降级成原生可执行文件（底层程序不带执行器），`--目标系统`、`--目标架构` 指定目标。

```sh
./yy豫构.exe 构建 原生你好 --输出 yy原生你好臂 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 臂六十四
./yy豫构.exe 构建 原生你好 --输出 yy原生你好兼 -j 24 -- --目标 本机 --目标系统 林纳 --目标架构 兼容六十四
```

产物是静态 ELF64 可执行文件，在 Linux arm64 与 x86-64 上直接运行，不依赖任何动态库。

在 macOS 上可用 Docker 验证（`FROM scratch` 镜像，只含这一个文件）：

```sh
printf 'FROM scratch\nCOPY --chmod=755 yy原生你好臂 /hello\nENTRYPOINT ["/hello"]\n' > Dockerfile
docker build --platform linux/arm64 -t yy-hello .
printf '回声\n' | docker run --rm -i --platform linux/arm64 yy-hello; echo $?
```

应输出“你好”与“回声”两行，退出码 7。x86-64 换成 `yy原生你好兼` 与 `linux/amd64`。

## macOS 版

`林檎入口。底层。豫` 是同一程序的 macOS 版：写、读、退出经 libSystem 的 `write`、`read`、`exit`（导入模块名为“林檎”，导入名是 `写`、`读`、`退出`），生成的 Mach-O 位置无关、由 dyld 绑定导入槽、带特设代码签名，可在本机（arm64）直接运行：

```sh
./yy豫构.exe 构建 原生你好 林檎入口 --输出 yy原生你好林檎 -j 24 -- --目标 本机 --目标系统 林檎 --目标架构 臂六十四
printf '回声\n' | ./yy原生你好林檎; echo $?
```

Linux 版的编译器参数相应为 `--目标系统 林纳`，不写入口段（见上文）。

## Windows 版

`轩窗入口。底层。豫` 是同一程序的 Windows 版：经 kernel32 的 `GetStdHandle`、`WriteFile`、`ReadFile`、`ExitProcess`（导入模块名为“轩窗”，导入名是 `取标准句柄`、`写文件`、`读文件`、`退出进程`）。编译器参数写 `--目标系统 轩窗`，产物是 PE32+ 可执行文件：AMD64 版用固定基址（名义地址与 Linux 相同），ARM64 版位置无关（布局同 macOS），导入表只列 kernel32 的函数。

```sh
./yy豫构.exe 构建 原生你好 轩窗入口 --输出 hello-x64.exe -j 24 -- --目标 本机 --目标系统 轩窗 --目标架构 兼容六十四
./yy豫构.exe 构建 原生你好 轩窗入口 --输出 hello-arm64.exe -j 24 -- --目标 本机 --目标系统 轩窗 --目标架构 臂六十四
```

在 Windows 上运行 `hello-x64.exe`（或 ARM64 机器上的 `hello-arm64.exe`）应输出“你好”与回显，退出码 7。CI 的“轩窗原生样例”两个作业在 Linux 上生成这两个文件，再到 Windows x64 与 ARM64 运行器上执行核对。

## 豫行版

`豫行入口。底层。豫` 经平台导入（`平台。底层接口。豫`：写字节、退出任务，即内核服务 0 与 18）逐字节写一行“你好”，以退出码 7 结束。编出的豫行文件在豫言操作系统上运行，服务调用经代码段开头的服务门（[提案 00021](../../../../提案/00021-豫行跨平台运行.汉语.md)）；宿主启动器也用它验收。

```sh
./yy豫构.exe 构建 原生你好 豫行入口 --输出 yy原生你好豫行臂 -j 24 -- --目标 本机 --目标系统 豫言 --目标架构 臂六十四
```
