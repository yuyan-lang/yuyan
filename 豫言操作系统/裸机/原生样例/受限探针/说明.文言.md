# 受限探针

受限之式（提案〇〇〇一二服务四十八「进入受限」）之至简验程，底层之式，编为豫行而行于豫言操作系统（虚机与裸机皆用之）。十一月二十五日为虚机之受限（议一九四五第四步，林檎经 Hypervisor.framework）而作。

程于己之线性内存置：

- 偏 0x1000 起臂六十四之六令：`mov x8,#64`、`mov x0,#7`、`svc #0`、`mov x0,#9`、`svc #1`、`b .`；
- 偏 0x2000 起受限之状区（千零八十八字），程计为一 TiB 加 0x1000（受限之虚址为线性之偏加一 TiB，同林兼容），栈针为一 TiB 加 0x4000。

乃二入受限，逐项验之：

1. 初回答原因一（系统之呼之令），向量零，x8 为六十四、x0 为七，程计止于初 svc 之后。
2. 次回答原因四（内核之服之呼），向量一，x0 为九，程计止于次 svc 之后。

每项印一行“受限探针：项 成”或“受限探针：项 败 得 N”，皆过则以退码零终，一项不过则以一终。

构与行（于仓之根，壳中）：

```
「构建」于「包」曰『受限探针』于「输出」曰『受限探针。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】
「行」于『./受限探针。豫行』于（「罄」以「文」）
```

产物之名须以“豫行”终：虚机依名认静态之豫行，无此缀者作清单而寻其单元，报“不存在”（系统误码四十四）。此数令惟属臂六十四，兼容六十四另书一份。

十一月二十五日于 pit-mac 之测试虚机（d55606a5bc，林檎经 Hypervisor.framework）实行，九项皆过。

## 停候探针

同包另一入口「停候探针」，为行在虚机停世挂候之回归之验：纯底层之豫行不依执行器实例之约用线性偏一三七二，探于其处书奇数二七一，乃逐字书一行“停候探针 成”而以零退。虚机惟于多核之役行停世挂候，单核之役自务门如常而归，一行皆出。

```
「构建」于「包」曰『受限探针』于「入口」曰「列」【『停候探针』】于「输出」曰『停候探针。豫行』于「编参」曰「列」【『--目标』，『本机』，『--目标系统』，『豫言』，『--目标架构』，『臂六十四』】
「行」于『./停候探针。豫行』于（「罄」以「文」）
```
