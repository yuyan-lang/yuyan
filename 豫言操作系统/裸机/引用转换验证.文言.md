# 引用测试转换验型

今受可空非空之引用测试与转换。先验目标堆型，再依其系之可空顶型验输入；聚合、函数、外部、异常不得相混。同系异结构数组可测试，静态型异不径拒，其行时可假可陷。

测试返 i32，转换返目标引用，存可空记。非空断言守原堆而除可空，断流未知仍未知。引用相等唯受 eq 子型，不径比 any、函数或外部。

二十完整模块与 Node 分类同，豫言验者皆成，二十数组回归亦成。含转换后赋值、可空不得冒非空、未知、异系及相等之限。日志存 `/tmp/yy引用转换检查日志`、`/tmp/yy引用转换构建日志`、`/tmp/yy引用转换运行日志`、`/tmp/yy引用数组回归运行日志`。

此不行动态转换，不证运行对象身份、陷阱与回收已成。外部聚合显式转换、转换分支及实例资源全验尚待，默认镜像不变。
