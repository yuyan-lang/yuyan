# 完整型选择

无注解选择唯受同数型或向量，拒引用；实型与未知合则守实型，皆未知则仍未知。有注解者须恰一合法值型，二候选各验，果依声明拓宽。条件皆须 i32。

十四完整模块与 Node 分类同，豫言验者皆成，二十引用转换回归亦成。含宽整、子型、非空、未知、错条件、注解数量与越界。日志存 `/tmp/yy选择指令检查日志`、`/tmp/yy选择指令构建日志`、`/tmp/yy选择指令运行日志`、`/tmp/yy选择引用回归运行日志`。

增命令 `yy中文网页汇编 检查函数指令 模块.wasm`，读完整模块之型与体，验今所受指令，未备者明拒。成功不证余资源全验，亦不执行。实产物之检后录，默认裸机镜像不变。

命令既成，正例过。验既有优化器三代，首遇未备码三十五（global.get）而退出一；当先备完整全局及初始化之验，非谓输入非法。日志存 `/tmp/yy函数指令命令正例日志`、`/tmp/yy真实函数指令检查日志`。
