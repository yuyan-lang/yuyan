**UTM 与键盘（二〇二六年十月六日）**：于 UTM 4.7.5（QEMU 10.0.2，UEFI，IDE 光驱）实试，入桌面。UTM 默闭 i8042，接 usb-kbd、usb-tablet 于 `-usb` 之 ICH9 EHCI/UHCI（别有一 qemu-xhci，惟供 USB 之转），内核惟驱 PS/2 与 xHCI 上之 HID 键盘，故须于「QEMU」页勾「PS/2 控制器」，于「输入」页置「USB 支持」为「关」；惟开 PS/2 而不闭 USB，则 QEMU 送键于 USB 键盘，犹不得。显卡 virtio-vga 与 VGA 于 OVMF 皆有帧缓。QEMU 中接 `usb-kbd` 于 xHCI，亦入桌面。键盘与 USB 启时之诊（`PS2 STAGE=`、`USB PCI=` 等）惟书串口（主核之「串口裸字节」），不复绘于屏。开机不复候三十秒之 USB 热插拔观察（为苹果实机之察而设），开机至命令壳约三点四秒；PS/2 键盘之入环，正其写计逾二百五十六则尽以键为环满而弃之之误；出桌面之清屏改由内核涂黑（交帧像素址予零），不复于客堆新建四兆之数组。桌面通 PS/2 鼠标（核开辅口，务三十六读字；执行器成包交指事，叠绘光标），QEMU 默机自带 PS/2 鼠标，监视器 `mouse_move`、`mouse_button` 可试；USB 鼠与 usb-tablet 犹无驱。

**高分之屏（二〇二六年十月六日）**：帧缓宽逾千九百二十或高逾千二百，核倍之：桌面所得半其宽高（二千五百六十乘千六百之屏为千二百八十乘八百，一帧四兆），交帧则每素书为二乘二（见 `文档/帧服务.文言.md`）。实机所试二千五百六十乘千六百之屏，旧入桌面即须一帧十六兆，执行器之堆不能容。QEMU 加 `-vga none -device VGA,xres=2560,yres=1600`，OVMF 与 SeaBIOS 下 Limine 皆择二千五百六十乘千六百，可以复现。

**USB 之鼠（二〇二六年十月六日）**：核之 xHCI 之驱识 HID 启动之约之鼠（类三、子类一、约二），开机前接好或开机后热插皆可；与键盘同器之鼠接口（如苹果笔记本内置键盘与触控板）亦各配一端。其报转为 PS/2 三字之包，书于与 PS/2 鼠同一之鼠环，执行器无须改。无 PS/2 控器（状态之口得 0xFF）则核略 PS/2 鼠之读与初置。QEMU 可以 `-device usb-mouse,bus=xhci.0` 接 USB 鼠，加 `-machine i8042=off` 去 PS/2，以拟惟有 USB 输入之机。详见 `文档/帧服务.文言.md`。

**书屏与卷屏（二〇二六年十月六日）**：帧缓映为写合并（PAT 第四项设为 WC），控台至底一举上移半屏，八字一复。实机读写显存皆经总线，旧以强不可缓存之映，逐字逐行而卷，于二千五百六十乘千六百之苹果笔记本，每卷一行约十秒。详见 `文档/帧服务.文言.md`。

所生 `yy启动介质/yy豫言启动.iso` 可写入 U 盘，是 BIOS/UEFI 兼载之 ISO：传统 BIOS/MBR 与 x86-64 UEFI 皆由 Limine 启之，并循 Multiboot 一载现有无盘内核。今唯 x86-64；可不待 Virtio 数据盘而先入壳，已接 xHCI USB bulk-only 数据盘之持久文件之术，未知盘不自格式化；EHCI、AHCI 及实体机尚未验。QEMU 之 BIOS 验，以 ISO 为 USB 大容量存储器：

二〇二六年十月二日 xHCI BAR 映射、唯读探测与 DMA 区复验：QEMU 11.1.1 之 Q35 默认 CPU 与 `-cpu Penryn`，各循 SeaBIOS BIOS/MBR、OVMF UEFI，以同一 qemu-xhci USB ISO 起至 `壳>`。四组皆立 PDE[511] BAR0 映并唯读探 capability；SeaBIOS 二 CPU 模型之页表值皆为 `0x00000000fea000bb`，OVMF 默认 CPU 为 `0x000000c0000000bb`，OVMF Penryn 为 `0x00000008000000bb`。核置第三十一块之位，`0x121000` 位图为 `0x800003ff`，并清 `[0x07E00000, 0x08000000)`；同轮 `yy裸机验证` 三百八十项全验皆成。PCI Memory Space 已启，Bus Master 与控制器未启；USB HID 与存储传输未成，实体机器尚未实测。
二〇二六年十月二日 xHCI 停机复位复验：QEMU 11.1.1 Q35 + qemu-xhci 用同一 BIOS/UEFI 混合 USB 镜，默认 CPU 与 `-cpu Penryn`，分循 SeaBIOS BIOS/MBR、OVMF UEFI，共四式皆启至 `壳>`。SeaBIOS BAR0 为 `0xFEBD4000`；OVMF 默认 CPU 为 `0xC000000000`，Penryn 为 `0x800000000`。四式操作寄存器皆读 USBCMD=0、USBSTS=1（HCH=1、CNR=0），控制器复位既成，止而未启。核未启 PCI Bus Master，未置 DMA 环，未复启控制器；`yy裸机验证` 三百八十项皆过。此为 QEMU 仿验；ThinkPad E40 与诸实体电脑待验；USB HID 与 USB 存储传输驱动未具。
二〇二六年十月二日 QEMU EHCI 固件启验：QEMU 11.1.1 Q35 挂 `usb-ehci` 与同一混合 USB ISO，由 EHCI USB 大容量盘启。默认 CPU 经 SeaBIOS BIOS/MBR、OVMF UEFI 两式皆入 `壳>`；`-cpu Penryn` 经二固件亦皆入 `壳>`。默认 CPU 下 PCI 器号为 `8086:24CD`，BAR0 各为 `0xFEBD5000`、`0x81085000`；CAPLENGTH/HCIVERSION 为 `0x01000020`，HCSPARAMS1 为 `0x00000006`，HCSPARAMS2 为 `0x00006880`。SeaBIOS 读 USBCMD=`0x00080031`、USBSTS=`0x0000C00C`；OVMF 读 USBCMD=`0x00080000`、USBSTS=`0x00001004`。此唯验固件启路。PCI 寻器源码兼识 EHCI、xHCI，留 EHCI 为后备而先选 xHCI；QEMU 双控制器拓扑已验 EHCI 居 `00:03.0`、xHCI 居 `00:04.0`，配置偏移 `0x08` 原始双字各为 `0x0C032010`、`0x0C033001`，清 revision 低字节后类码相合。新优先逻辑已构并核内复验，详下条。扫描记录仍唯有一控制器；EHCI 交权、双控制器驱动、USB 键盘输入与存储传输未成，ThinkPad E40 实机尚待验。

二〇二六年十月二日 当前核之混合 USB ISO 仿验：QEMU 11.1.1 Q35 下，EHCI 单控 USB 盘循 SeaBIOS BIOS/MBR、OVMF UEFI 皆启至 `壳>`，入「回显」「退出」皆成。复以 EHCI `00:03.0`、xHCI `00:04.0` 并置，USB 盘挂 xHCI；SeaBIOS 与 OVMF 两路皆启至壳。二式 PCI 记录 `0x103938` 所见 BDF 索引 `0x20`（`00:04.0`）、器号 `1b36:000d`、类码 `0x0C033000`；BAR0 SeaBIOS 低字为 `0xFEBD4004`，OVMF 低字 `0x00000004`、高字 `0x000000C0`。是验扫描先记 EHCI、继续寻器，后以 xHCI 易其录。双构 `yy裸机验证` 三百八十项皆过。USB 盘由固件授 Limine 而启；核尚未成 EHCI 交权、USB HID 与 USB 数据传输驱动，ThinkPad E40 及诸实体机仍待验。

EHCI 固件交权之据：[Intel EHCI 1.0 规范](https://www.intel.com/content/dam/www/public/us/en/documents/technical-specifications/ehci-specification-for-usb.pdf) §2.2.4、§5.1。驱动由 BAR0+`0x08` 之 HCCPARAMS[15:8] 取 EECP，循 PCI 配置空间之扩展能力链求 ID `0x01`；若有 USBLEGSUP，置 OS Owned 第 24 位，候 BIOS Owned 第 16 位清而后操作控制器。宜循链而定位，不可倚芯片组固定位址 `0x68`。

QEMU 11.1.1 Q35 EHCI 唯读基线（PCI `00:03.0`，`8086:24CD`）：SeaBIOS BAR0=`0xFEBD5000`，OVMF BAR0=`0x81085000`；二者 HCCPARAMS 皆 `0x00006880`，故 EECP=`0x68`。PCI 配置 `0x68` 之 USBLEGSUP 皆 `0x00000001`（ID=1，OS、BIOS 交权位皆零），`0x6C` 之 USBLEGCTLSTS 皆 `0xC0000000`。SeaBIOS 操作寄存器 USBCMD=`0x00080031`、USBSTS=`0x0000C00C`；OVMF 为 USBCMD=`0x00080000`、USBSTS=`0x00001004`。数由 QEMU monitor 读取，核未求 EHCI 之权。

ThinkPad E40 Pentium 之 MTM 与芯片组尚待实机或固件信息核定。若其用 Intel 5 Series/HM55，芯片组资料列 EHCI 二功能 `D29:F0`、`D26:F0`；今启扫之录唯容一主控，尚不足以驱动两控制器所辖诸 USB 端口。[Intel 5 Series/3400 Series 芯片组资料](https://www.intel.com/content/dam/www/public/us/en/documents/datasheets/5-chipset-3400-chipset-datasheet.pdf)

二〇二六年十月二日 QEMU xHCI 能力之基：以 QEMU monitor 直读 PCIe 根端口后之 xHCI BAR0，SeaBIOS 之址为 `0xFE800000`，OVMF UEFI 之址为 `0x81000000`；二者寄存器同：`CAPLENGTH/HCIVERSION=0x01000040`、`HCSPARAMS1=0x08001040`、`HCSPARAMS2=0x0000000F`、`HCSPARAMS3=0`、`HCCPARAMS1=0x00087001`、`DBOFF=0x2000`、`RTSOFF=0x1000`。此乃 QEMU 设备模型之只读基线；核尚未映而读之，亦未复位或启控制器与 DMA。

二〇二六年十月二日 xHCI 映射试验隔离复验：未成之核 MMIO 映与读寄存器，暂屏于启镜之外，以零机片留待办；PCI xHCI 之寻仍启。重造同一混合 ISO 后，以 QEMU Penryn + Q35、PCIe 根端口后之 xHCI 与 USB 启动盘，分由 SeaBIOS BIOS/MBR、OVMF UEFI 起至壳；行 `回显` 后皆复见 `壳>`；臂六十四与兼容六十四裸机共三百八十验皆过。此复验证启路与寻器未受此试验所损；xHCI 控制器、USB HID 与 DMA 驱动尚未成。

二〇二六年十月二日 xHCI BAR 唯读探复验：兼容六十四核循 PCI 记录，验共用页目录与空闲 PDE[511]；仅启 PCI 内存空间，不启 Bus Master；以不可缓存二兆页映 BAR0 于 `0xBFE00000 + (BAR0低字 & 0x1FF000)`，读验能力区八双字。QEMU Q35 + Penryn + PCIe 根端口后之 xHCI，经 SeaBIOS BIOS/MBR 与 OVMF UEFI 由同一 USB ISO 起至 `壳>`；`回显`、`退出` 皆成；所读与前述 monitor 基线同，三百八十项裸机验皆过。控制器未复位未启，DMA、USB HID 与可读写 USB 存储未成；ThinkPad E40 与实体机待验。

二〇二六年十月二日 PS/2 修饰键复验：QEMU Penryn + Q35 + xHCI 之同一混合 USB 镜，以 SeaBIOS BIOS/MBR 与 OVMF UEFI 皆入 `壳>`。监视器注入左 Shift+`a`、Caps Lock+`a`，皆得 `A`；Caps Lock+Shift+`a` 得 `a`；Shift+`1`、`2`、`-` 得 `!`、`@`、`_`；右 Shift+`b` 得 `B`。此唯验 QEMU 仿 PS/2，ThinkPad E40 实机与实体键盘待验。

二〇二六年十月二日 QEMU USB 键盘缺口复验：QEMU 11.1.1 Q35 + Penryn + xHCI 挂同一混合镜与 `usb-kbd`（接 `xhci.0`）；SeaBIOS、OVMF 皆启至 `壳>`。QEMU `info usb` 示 USB Keyboard 已挂于端口，然此设备配置下，监视器所注 `help` 未达壳。去 `usb-kbd` 后，同 SeaBIOS 配置之 PS/2 注入能读 `help`。此为模拟器设备配置之对照；核尚无 xHCI 启动、DMA 环与 USB HID 寻举之驱动。

二〇二六年十月二日 旧式 CPU 仿验：今核混合 USB 镜以 QEMU `-cpu Penryn`、Q35 与 EHCI USB 盘，分经 SeaBIOS BIOS/MBR、OVMF UEFI，皆启至 `壳>`；「回显」「退出」皆成。Penryn 乃旧式 x86-64 CPU 模型，此仿验不能代 ThinkPad E40 实机之验。

二〇二六年十月二日 xHCI 控制器启行复验：核先行 BIOS 交权、停机复位，乃立四 GiB 以下之 DCBAA、命令环、事件环与 ERST；循控制器所报，置至多五百七 scratchpad 页；后启 PCI Memory Space 与 Bus Master，而运行控制器。QEMU 11.1.1 Q35 + qemu-xhci 用同一混合 USB 镜；默认 CPU 与 `-cpu Penryn`，各经 SeaBIOS BIOS/MBR、OVMF UEFI，四式皆至 `壳>`。监视器所读启动态 `0x103964=1`、USBCMD=`1`、USBSTS=`8`（HCH 位已清）。臂、兼容两架裸机三百八十验皆过。今唯成控制器之初置与启行；USB 器之枚举、事件之治、HID 输入与 USB 大容量储存之传输，皆待作。此唯验 QEMU，ThinkPad E40 与诸实体机未试。

二〇二六年十月二日 xHCI 根端口连记复验：QEMU 11.1.1 Q35 + Penryn + qemu-xhci 用同一混合 USB 镜，SeaBIOS BIOS/MBR 与 OVMF UEFI 皆由 USB 启至 `壳>`。核启控后取 HCSPARAMS1.MaxPorts，自操作寄存器基址 `+0x400` 起，每端口增 `0x10`，唯读 PORTSC.CCS。两固件路皆记 `0x103964=1`、根端口数 `0x103970=8`、已连数 `0x103974=1`、首个已连端口 `0x103978=1`；QEMU `info usb` 示 USB 大容量器在 Port 1。臂、兼容两架三百八十项裸机验全过。此唯验 QEMU 根端口连态；设备枚举、USB 事件、HID 与存储传输尚未成，ThinkPad E40 及诸实体机待试。

二〇二六年十月二日 QEMU VMware SVGA II 模型复验：同一混合镜加 `-vga vmware`，于 Q35 + Penryn + qemu-xhci 下，分经 SeaBIOS BIOS/MBR 与 OVMF UEFI 起机，皆入 `壳>`；xHCI 启态、八根端口、Port 1 已连之记，与前验同。此验 QEMU 之 VMware SVGA II 设备模型；VMware Fusion x86-64 hypervisor 路尚未验。

二〇二六年十月二日 QEMU 基础 x86-64 CPU 仿验：同一混合镜以 `-cpu qemu64`、Q35 + qemu-xhci 作 SeaBIOS BIOS/MBR 与 OVMF UEFI USB 启机，两路皆入 `壳>`，并得 xHCI 启态 `1`、根端口数 `8`、已连数 `1`、首端口 `1`。此验 QEMU 通用 x86-64 CPU 模型，ThinkPad E40 与实体 CPU 尚待验。
