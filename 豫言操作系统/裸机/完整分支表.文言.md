# 完整型之分支表

分支表读诸目标及默认深度，验索引三十二位整数，诸标签皆验，不因常量索引未选而免。目标值数须同默认，实分支值须各合其型。

标签不必字面同型：可空 none 可供 eq 与 any；断流栈底之未知亦可供异数型。已有实错值不赦，标签数异亦拒。诸目标皆验而后断流，不择一目标代静态全验。

十二完整模块试与 Node 分类同，二十一结构回归亦成，验型构建皆成。日志存 `/tmp/yy分支表检查日志`、`/tmp/yy分支表构建日志`、`/tmp/yy分支表运行日志`、`/tmp/yy分支表结构回归运行日志`。

此扩完整型验令，未改裸机执行器。异常、尾调、回收对象与余资源全验尚待，默认镜像不变。
