# 字体诺驿适配

“文楷”用单字体文件序号零，候选路径为 `字体.ttf`。节点宿主以此资源名为程序发行目录所附唯一字体，拒符链与旁文。发行又置三文于程序旁 `字体/` 之目：思源黑体、原始字体、默认等宽黑体。

`字样。豫` 于诺驿宿主行[字体接口](../../../豫寓榫卯/字体/规范.文言.md) 零点一点零。`实现榫卯。豫` 定公约之身份与版；豫构发行于节点之式依 `宿主/节点/宿主支持清单。数据。豫` 取此目。包描述以「平台」明此适配唯用于诺驿；不须诺驿库。

**族名何从得文**：族名与候之表在数据文 `字样族表。数据。豫`，类与纯术在 `字样族。豫`。每项书族名、类别、发行之文、集序、诸系统之候与粗否；别名之项（若 `Arial`、`serif`、`宋体`）发行之文空，类别指通用之名，查时循类别而归其本。候先系统字体之目、次发行 `字体/`，次第试之，先开者用；三系统之径同列，无者自略，故不必先判系统。

别名：`sans-serif`、`system-ui`、`ui-sans-serif`、`Arial`、`Helvetica`、`黑体`、`微软雅黑` 归无衬线；`serif`、`ui-serif`、`Times New Roman`、`Times`、`宋体` 归衬线；`monospace`、`ui-monospace`、`Courier New`、`Courier`、`Menlo`、`Consolas` 归等宽；`cursive`、`楷体` 归手写；`fantasy` 归装饰；`ui-rounded` 归圆体；`math` 归数学；`fangsong` 归仿宋。余族名返 `资源不存在`。

三粗体之名惟系统之真粗面，发行不携粗文；宿主无其面则返 `资源不存在`，客返常规而错廓重描以仿粗。字体库受 TrueType（glyf）与紧凑（CFF、CFF2）之廓，思源黑体与 Noto CJK 之 CFF 中文可径析。

**缺字之退**：`字样回退链` 依首选之族出 `首选 → 同类通用 → 汉字 → 符号` 之序；客于诸候取字体、查码表，取首有是码者。诺驿之 `汉字` 与 `符号` 各授一份覆盖其码之系统字或发行字；`无衬线` 于有思源黑体之林纳先授思源黑体（比例西文兼汉字）；惟有 DejaVu 时授 DejaVu，汉字由 `汉字` 族补之。

**宿主原语**：`豫言_诺节_字体(操作, 路径, 号, 偏移, 长度)`，返（码、号、长、字、文），实于 `宿主/节点/图形.mjs`（发行启动文件内联之）。`打开` 受三处：字体目白册之文（依真径判之，防符链越目：林檎 `/System/Library/Fonts`、`/Library/Fonts`、`~/Library/Fonts`；林纳 `/usr/share/fonts`、`/usr/local/share/fonts`、`~/.local/share/fonts`、`~/.fonts`；轩窗 `%WINDIR%\Fonts` 与 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`）、发行所附 `字体.ttf`、程序旁 `字体/` 目之文（`字体/…` 对程序目录而解，越目之相对径不授）。同文再开得同号。`读取` 依号与偏移取一段，不动文之位；一次之限十六兆，同值桥。应用终则尽闭之。

**校验**：适配先查读取之域（偏移、长为负或越文末则返 `输入无效`）、一次之限（`资源配额已尽`）与零长（径返空字节串），乃交宿主。

**验收**：宿主之单元试在 `宿主/节点/图形。测试.mjs`（以临时之目为字体目，验白册、同号、依偏移读、越界、清理、程序旁 `字体/` 目之许与越界之拒）。字体族之验收在 `测试/字样族验收`：于诺驿依族名取三族而析之，核三族之体不同、无衬线 `i` 与 `m` 之进宽不同、衬线缺汉字则退于汉字族、回退之链序；逐项书“通过”或“失败”，末书其总。

```sh
# 于语言仓根发行而行（远端林纳实测通过四项、失败零项）
./豫构。林纳。豫行 发行 节点 豫言操作系统/适配/字体诺驿/测试/字样族验收 dist/字样族验收 \
  --包根 库 --包根 豫言操作系统/适配 --包根 豫寓榫卯 --包根 豫寓底榫卯 -j 8
node dist/字样族验收/启动.mjs
```

**平台接口**：本适配之裹函转调平台接口包之无体声明，编为带型之宿主导入（界签见《网页汇编接口》网五）：「诺驿宿主」之「字样本术」之「诺驿字体操作」（旧外调名 `豫言_诺节_字体`）。宿主之实与旧原语同。
