# 字体族验收

此诺驿字体适配之验收程式，验[字体接口](../../../../../豫寓榫卯/字体/规范.文言.md)之族名映射与缺字之退：

1. 依 `无衬线`、`衬线`、`等宽` 三族各取字体，读全文而以字体库析之；以「字形数、`i` 与 `m` 之进宽」为签，核三族所得之体不同。
2. 核 `无衬线` 之体 `i` 与 `m` 之进宽不同（比例西文）。
3. 核衬线缺汉字则退于 `汉字` 族：衬线之体无常用汉字 `汉`，则 `汉字` 族必有之；已有 `汉`，则改以生僻 `𪚩`（U+2A6A9）再验；本机二族皆覆盖生僻之字，则记通过而注之。
4. 核 `字样回退链` 之序为 `首选、同类通用、汉字、符号`。

逐项书“通过”或“失败”，末行书“字样族验收：通过 N 项，失败 M 项”；有败则异常而终，退码非零。字体之文经 `读字样卷` 以六十四 KiB 为段读全，乃交字体库析之，故所验者宿主所实授之字节。

## 构与行

于语言仓根：

```sh
./豫构。林纳。豫行 发行 节点 豫言操作系统/适配/字体诺驿/测试/字样族验收 dist/字样族验收 \
  --包根 库 --包根 豫言操作系统/适配 --包根 豫寓榫卯 --包根 豫寓底榫卯 -j 8
node dist/字样族验收/启动.mjs
```

远端林纳（字为 DejaVu Sans、DejaVu Serif、DejaVu Sans Mono 与 Droid Sans Fallback）实测通过四项、失败零项。族表与系统之候见[字体诺驿说明](../说明.文言.md)。
