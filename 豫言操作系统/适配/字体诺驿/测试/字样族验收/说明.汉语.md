# 字体族验收

这是诺驿字体适配的验收程序，验证[字体接口](../../../../../豫寓榫卯/字体/规范.汉语.md)的族名映射与缺字回退：

1. 按 `无衬线`、`衬线`、`等宽` 三族各取字体，读全文件并用字体库解析；以「字形数、`i` 与 `m` 的前进宽度」作签名，核对三族得到不同的字体。
2. 核对 `无衬线` 字体里 `i` 与 `m` 的前进宽度不同（比例西文）。
3. 核对衬线缺汉字时回退到 `汉字` 族：衬线字体没有常用汉字 `汉` 时，`汉字` 族必须有它；衬线字体已有 `汉` 时，改用生僻汉字 `𪚩`（U+2A6A9）再验；本机两族都覆盖生僻字时记通过并注明。
4. 核对 `字样回退链` 的次序为 `首选、同类通用、汉字、符号`。

逐项打印“通过：…”或“失败：…”，末行打印“字样族验收：通过 N 项，失败 M 项”；有失败项时以异常结束，退出码非零。字体文件经 `读字样卷` 按六十四 KiB 一段读全，再交字体库解析，所以验的是宿主真正交出的字节。

## 构建与运行

在语言仓根目录：

```sh
./豫构。林纳。豫行 发行 节点 豫言操作系统/适配/字体诺驿/测试/字样族验收 dist/字样族验收 \
  --包根 库 --包根 豫言操作系统/适配 --包根 豫寓榫卯 --包根 豫寓底榫卯 -j 8
node dist/字样族验收/启动.mjs
```

远端林纳（字体为 DejaVu Sans、DejaVu Serif、DejaVu Sans Mono 与 Droid Sans Fallback）实测通过 4 项、失败 0 项。字体族表与系统候选见[字体诺驿说明](../说明.汉语.md)。
