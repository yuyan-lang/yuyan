# 字体诺驿适配

“文楷”使用单字体文件序号零，候选路径为 `字体.ttf`。节点宿主将这个资源名解释为程序发行目录随附的唯一字体资产，拒绝符号链接及旁文件。发行包另把三套字体放在程序旁 `字体/` 目录：思源黑体、原始字体与默认等宽黑体。

`字样。豫` 在诺驿宿主上实现[字体接口](../../../豫寓榫卯/字体/规范.汉语.md) 0.1.0。`实现榫卯。豫` 固定公共包身份与版本；豫构发行的节点模式按 `宿主/节点/宿主支持清单。数据。豫` 选用本目录。包描述用「平台」声明本适配只用于诺驿；它不需要诺驿库。

**族名怎样找到文件**：族名与候选的对照表写在数据文件 `字样族表。数据。豫`，类型与纯函数在 `字样族。豫`。每一项写族名、通用类别、发行包里的字体文件、字体集序号、各系统候选与是否粗体；别名项（如 `Arial`、`serif`、`宋体`）的发行文件留空，类别指向通用族名，查表时顺着类别归到通用族。候选先系统字体目录、后发行包 `字体/`，依次尝试，第一个能打开的即用；三个系统的路径写在同一张表里，不存在的文件自然跳过，所以不必先判断系统。

别名：`sans-serif`、`system-ui`、`ui-sans-serif`、`Arial`、`Helvetica`、`黑体`、`微软雅黑` 归无衬线；`serif`、`ui-serif`、`Times New Roman`、`Times`、`宋体` 归衬线；`monospace`、`ui-monospace`、`Courier New`、`Courier`、`Menlo`、`Consolas` 归等宽；`cursive`、`楷体` 归手写；`fantasy` 归装饰；`ui-rounded` 归圆体；`math` 归数学；`fangsong` 归仿宋。其他族名返回 `资源不存在`。

`无衬线`、`衬线`、`等宽` 三个粗体族名只对应系统里的真粗面，发行包不带粗体文件；宿主没有这个字面时返回 `资源不存在`，应用回到常规族并把轮廓错开重描来仿粗。字体库支持 TrueType（glyf）与紧凑（CFF、CFF2）轮廓，思源黑体与 Noto CJK 的 CFF 中文字形可以直接解析。

**缺字回退**：`字样回退链` 按首选族给出 `首选 → 同类通用族 → 汉字 → 符号` 的次序，应用对每个候选族取字体、查字体库码表，取第一个有该码点的字体。诺驿的 `汉字` 与 `符号` 族各给一份覆盖相应码域的系统字体或发行字体；`无衬线` 在有思源黑体的林纳上先给思源黑体（比例西文兼汉字）；只有 DejaVu 时给 DejaVu，汉字由 `汉字` 族补上。

**宿主原语**：`豫言_诺节_字体(操作, 路径, 号, 偏移, 长度)`，返回（状态码, 号, 长度, 字节, 文字），实现在 `宿主/节点/图形.mjs`（发行启动文件内联它）。`打开` 接受三处：字体目录白名单下的文件（按真实路径判断，防符号链接越出目录：林檎 `/System/Library/Fonts`、`/Library/Fonts`、`~/Library/Fonts`；林纳 `/usr/share/fonts`、`/usr/local/share/fonts`、`~/.local/share/fonts`、`~/.fonts`；轩窗 `%WINDIR%\Fonts` 与 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`）、发行随附的 `字体.ttf`、程序旁 `字体/` 目录下的文件（`字体/…` 相对程序目录解析，越出该目录的相对路径不授）。同一文件重复打开得同一个号。`读取` 按号与偏移读一段，不改变文件位置；单次上限 16 MiB（同值桥上限）。应用结束时关闭全部文件。

**校验**：适配先查读取范围（偏移、长度为负或越过文件末尾返回 `输入无效`）、单次上限（`资源配额已尽`）与零长度（直接返回空字节串），再交宿主。

**验收**：宿主单元测试在 `宿主/节点/图形。测试.mjs`（临时目录当字体目录，核对白名单、同号、按偏移读取、越界、清理、程序旁 `字体/` 目录的允许与越界拒绝）。字体族验收在 `测试/字样族验收`：在诺驿宿主上按族名取三族并解析字体，核对三族字体不同、无衬线 `i` 与 `m` 前进宽度不同、衬线缺汉字时回退到汉字族、回退链次序；逐项打印“通过”或“失败”，末行汇总。

```sh
# 在语言仓根目录发行并运行（远端林纳实测通过 4 项、失败 0 项）
./豫构。林纳。豫行 发行 节点 豫言操作系统/适配/字体诺驿/测试/字样族验收 dist/字样族验收 \
  --包根 库 --包根 豫言操作系统/适配 --包根 豫寓榫卯 --包根 豫寓底榫卯 -j 8
node dist/字样族验收/启动.mjs
```

**平台接口**：本适配的包装函数转调平台接口包里的无体声明，编成带类型的宿主导入（边界签名见《网页汇编接口》网五）：「诺驿宿主」之「字样本术」的「诺驿字体操作」（旧外调名 `豫言_诺节_字体`）。宿主对这些导入的实现与旧原语相同。
