# 前端接口探针应用

一致性验收所用之探针应用：订“豫言测试命令”之消息，依 `{"号":n,"操作":"函数名","参":[…]}` 而调网页定时、储存、导航、环境、请求、事件源、编译、应用八接口包，与时间、随机数、网址定位、网址查询、日志、文字规整六既有接口（浏览器适配）之诸函数，以“豫言测试回复”之消息返 `{"号":n,"成":爻,"果":字符串}`。另露等待网页事件、订阅界面事件、取消订阅界面事件、读取网页事件丢弃数、读取网页事件类型丢弃数、设置网页事件队列上限、订阅网页消息、发布网页消息，供测者取事与造事。返“有无”之函数以 `1|值` 与 `0|` 示之。**惟用于测验，不部署。**说明见 `../../说明.文言.md`。
