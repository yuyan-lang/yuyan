# 网页定时浏览器适配

`定时。豫` 实现[网页定时接口](../../../豫言操作系统接口/网页定时/规范.汉语.md)的全部函数：`启动一次定时`、`启动重复定时`、`取消定时`。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（需要等待的操作）两个原语，操作名为 `定时.一次`、`定时.重复`、`定时.取消`；失败以（阴，错误文）返回，再由本适配转成豫言事故，不让 JavaScript 异常越过 Wasm 边界。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`。`创建网页能力` 的定时部分校验参数（周期定时间隔至少 10 毫秒，标记至多 1024 码元），再调用宿主已有的 `造定时`（`setTimeout`/`setInterval`，同时至多 64 个）；到期事件经统一事件队列，类型“定时”，订阅号为定时号；周期定时器在上一个事件被取走前不重复投递。取消时连同队列里尚未取走的该定时号事件一并移除。

**运行要求**：等待类函数挂起豫言栈，浏览器须支持 JSPI；八个新包与网页事件包共用同一个统一事件队列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用 `前端接口探针`、宿主单元测试与 JSDOM＋真实 Wasm 的一致性测试，说明见其中的 `说明.汉语.md`）。
