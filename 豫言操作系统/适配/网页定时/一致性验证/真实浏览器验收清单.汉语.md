# 真实浏览器验收清单（网页定时等八包、网页事件 0.2.0、网页界面 0.3.0）

JSDOM 不能覆盖下列行为，须在真实浏览器（Chromium，带 JSPI）里验证。**测试页**：把探针应用产物（`自动启动.mjs`、`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`接口要求组.json`……）与 `测试页.html` 放在同一个目录，用静态服务器（`.mjs` 须以 `text/javascript`、`.wasm` 以 `application/wasm`、`text/event-stream` 接口须真实流式）打开；在控制台或自动化工具里用 `window.__发(操作, ...参)` 调用接口，`await window.__宿主` 取宿主对象，`.状态()` 读队列状态。验证结果记在下面“已验”一节。

**已验（真实浏览器）**：见文末“验证记录”。

**须在真实浏览器验证的项**：

1. **定时**：标签页在后台时定时被降频（约每秒一次）、事件仍按序；一次定时到期后可再启动；`取消定时` 之后没有该号事件。
2. **储存**：真实 `sessionStorage`/`localStorage`；隐私模式或站点数据被禁时 `写入网页储存` 返回阴、`读取网页储存` 返回（阴，空）；配额（约 5 MB）写满时返回阴而不抛。
3. **导航**：`压入历史`、`替换历史` 只改地址栏；真实前进后退产生 `历史` 事件；`前往网址` 到同源其他页面与到他源；`替换当前网址` 后退不回旧页；`javascript:` 地址被拒。
4. **环境**：真实时区偏移与 `new Date().getTimezoneOffset()` 相反；夏令时切换日前后；真实 `document.cookie` 中含 `HttpOnly` 的饼不可见。
5. **请求**：真实 `fetch`：同源 JSON 的 GET/POST；`缓存:不缓存` 实际带 `Cache-Control: no-cache`；同时 32 个请求；重定向到别的来源被 `mode:same-origin` 视为网络错误；超时与取消；服务器返回非 UTF-8 正文。
6. **事件源**：真实 `fetch` 流读取 `text/event-stream`：跟随服务器的 `retry:`；服务端每 20 秒轮换连接时的“重连中→打开”；一次回放几千条历史时页面仍响应点击（背压不冻结界面）；后台标签页里的行为。
7. **编译**：`本地编译可用` 在无 Worker 或无 JSPI 的浏览器上为阴；真实编译客户端（`编译/客户端.mjs`）端到端：进度成批、完成事件、停止（Worker 被终止后可再启动）。
8. **应用**：真实 `import()` 加载另一个豫言浏览器应用，子应用在父应用事件循环之外独立响应点击；子应用加载失败的错误提示。
9. **网页事件 0.2.0 选择器**：真实点击导航链接与语言钮：`阻止默认` 让链接不跳转（`dispatchEvent` 一返回即已阻止）；`停止同处` 让页面上其他监听者收不到；`带矩形` 的数值与开发者工具中元素的位置一致；悬停事件 `mouseover` 的选择器过滤在快速移动下不丢事件。
10. **网页界面 0.3.0**：`点击节点` 触发 `<a href="#锚">` 真实滚动到锚点；`设置节点位置` 在 `position:absolute` 浮层上真实移动，并与 `读取节点矩形` 一致；`读取节点属性("文档根", ...)`。
11. **兼容**：Firefox（JSPI 可用性）、Safari 27；无 JSPI 的浏览器上，等待类函数应给出明确的降级提示。

## 验证记录

**2026-09-26，Chromium 152（Claude 内置浏览器，JSPI 可用），本机 `node 测试/真浏览器服务.mjs` 提供静态页与 `/api/*`；均通过**

| 项 | 结果 |
| --- | --- |
| 1 定时 | 一次定时到期事件的种类、标记、定时号正确且耗时不少于设定；周期定时不积压（应用不取事件 250 毫秒，积压恰为 1）；取走后继续投递；取消返回阳、再取消返回阴 |
| 2 储存 | 真 `localStorage`/`sessionStorage` 往返（含 `😀`）；会话与本地隔离；空值是“存在” |
| 3 导航 | `压入历史`/`替换历史` 只改地址栏；`移动历史(-1)` 收到类型 `历史` 的 `popstate` 事件且地址回到起点；跨源历史与 `javascript:` 地址被拒 |
| 4 环境 | 美东时区偏移 −300（冬）与 −240（夏）与 `getTimezoneOffset()` 相反一致；`读取页面饼` 读到 `yuyan_lang=wen`、原样返回 `abc%20d`，`HttpOnly` 的饼不可见 |
| 5 请求 | GET/POST JSON、`缓存:不缓存` 实带 `Cache-Control: no-cache`，请求带上本站饼；404 仍是“完成”；非 UTF-8 → 失败；重定向到别的来源 → 网络错误；超时、正文过大；三个并发请求按到达顺序入队，取消一个后无残留事件；阻塞变体等待期间到期的定时事件仍在队列里 |
| 6 事件源 | 真 `fetch` 流：服务端每 150 毫秒关闭连接并 `retry:100` 时稳定重连 8 秒（`重连中`→`打开`，事件号连续）；**五千事件回放：积压恒为 8 批、丢弃 0、页面主线程延迟正常（50 毫秒计时误差 2 毫秒），五千条无一丢失无一重复**；404 与 `text/html` 为致命错误 |
| 7 编译 | `本地编译可用` 为真（Worker、JSPI、DecompressionStream 齐备）；假编译客户端经**真实动态 `import()`** 从页面基址目录的 `编译/客户端.mjs` 加载：31 条进度（含 30 条输出）与完成事件正确，停止后收到“已停止”。**真实的编译客户端与编译器资源也验过**（`编译目录` 指向云仓 `应用/豫言体验/网页/编译`，含 Worker 与 15 MB 编译资源）：语法正确的项目 0.5 秒编译通过，249 条真实进度（阶段与标准错误输出），完成事件 `成` 为真、`产物摘要` 为 64 位十六进制；语法错误的项目 `成` 为假、`错误` 为“未关闭的字符串”；编译中 `停止本地编译` 得“已停止”（Worker 被终止），之后可再编译；项目须含 `入口。豫` 与 `云项目。包。豫`（客户端的约定） |
| 8 应用 | 真实 `import('/子应用/入口.mjs')`：子应用写入 DOM 并响应真实点击；重复启动与不存在的模块抛事故 |
| 9 选择器 | 真实鼠标悬停、点击带 `title` 的链接：`带属性`、`带矩形`（与元素真实位置一致）正确；`阻止默认`＋`停止同处` 使链接不跳转、页面上别的监听者收不到；点击 `.文件目录` 内部没有事件（`排除选择器`），点击页面空白处有事件 |
| 10 界面 0.3.0 | `点击节点` 触发 `<a href="#锚">` 真实滚动（scrollY 721）；拦截订阅存在时点击被同步阻止（与规范一致，须先撤订阅）；`设置节点位置` 后 `读取节点矩形` 与真实 `getBoundingClientRect` 一致；`读取节点属性("文档根","data-lang")` |
| 文树 0.3.0 | 真页面里查询、`template` 内容查询（文档查询看不到）、导出树重建、超文本清洗（`<img onerror>` 被拒）、替换包一层均符合规范 |

**尚未在真实浏览器验证**：后台标签页的定时降频；隐私模式与配额满时的储存失败；Firefox 与 Safari；服务端每 20 秒轮换事件流的长时间行为；输入法组字与焦点细节（沿用旧清单）。（真实编译客户端已于同日补验，见第 7 项。）
