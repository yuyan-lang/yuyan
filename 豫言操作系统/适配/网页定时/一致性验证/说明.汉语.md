# 网页定时、储存、导航、环境、请求、事件源、编译、应用：浏览器一致性验证

八个新包，加上时间、随机数、网址定位、网址查询、日志、文字规整六个既有接口的**浏览器适配**（`适配/<能力>浏览器/`），共用一个探针应用 `前端接口探针`，所以验证材料集中放在这里。

**内容**

- `应用/前端接口探针/`：探针应用源码（包描述文件名带 `.txt` 后缀，避免被 `yy豫构 发现` 当成包）。它订阅“豫言测试命令”消息，按 `{"号":n,"操作":"函数名","参":[…]}` 调用八个接口包的**全部**函数（另含 `等待网页事件`、订阅、发布消息等取事件所需的调用），用“豫言测试回复”消息返回 `{"号":n,"成":爻,"果":字符串}`；函数失败的事故消息原样在 `果` 里。有无返回值的函数，元组以 `1|值`/`0|` 表示（存在与否）。
- `测试/网页能力单元.test.mjs`：不含 Wasm，用 JSDOM 直接测宿主的 `创建SSE解析器`（字节级：分块、CRLF、BOM、多字节、注释、`retry`、超限）与 `创建网页能力`（不能经探针传递的大载荷限额、关闭后行为、背压管线）。
- `测试/前端接口一致性.test.mjs`：JSDOM＋**真实 Wasm**：定时（不积压、取消保证、名额）、储存（区域隔离、配额失败返回阴）、环境（时区、饼）、导航（历史与 popstate）、请求（本机 `node:http` 服务器与 Node 真实 `fetch`：完成／失败／取消／并发上限／阻塞变体）、事件源（成批、重连与 `Last-Event-ID`、致命错误、**五千事件背压不丢**）、编译（注入假编译客户端：成批进度、停止、单例）、应用（注入假模块加载器）、六个浏览器适配（规范里的一致性样例逐条验证）；另有一条检查探针覆盖了八个接口文件里的每个函数。
- `测试/夹具.mjs`：启动探针的公共代码（选项：`网络`、`编译客户端`、`导入模块`、`页面应用超时`、`窗扩展`）。
- `真实浏览器验收清单.汉语.md`：JSDOM 不能覆盖、须在真实浏览器里验证的项目与已验结果。

**复跑**（在构建根，即语言仓根目录；需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`，用法见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)；编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发；`<构建根>` 指构建根的绝对路径）

```sh
./yy双宿主构建 --自动 浏览器 <语言仓>/豫言操作系统/适配/网页定时/一致性验证/应用/前端接口探针 dist/前端接口探针
env "前端探针产物目录=<构建根>/dist/前端接口探针/" \
    "JSDOM路径=<云仓>/网站/node_modules/jsdom/lib/api.js" \
    node --test --test-timeout=25000 \
      <语言仓>/豫言操作系统/适配/网页定时/一致性验证/测试/网页能力单元.test.mjs \
      <语言仓>/豫言操作系统/适配/网页定时/一致性验证/测试/前端接口一致性.test.mjs
```

- 环境变量都有默认值：`前端探针产物目录` 默认 `一致性验证/产物/`；`JSDOM路径` 默认按仓库布局指向云仓；`接口根`、`探针源` 供“覆盖全部函数”一条使用。
- **不要给探针传超过 1 MiB 的载荷**（网页消息的限额会让探针本身中止）；限额类断言放在 `网页能力单元.test.mjs`。
- 服务器路径请用 ASCII（`node:http` 收到的路径是百分号编码的）。
- 全部测试几秒跑完；测试里的网络都是本机回环，不访问外网。

**相关的既有验收**：`网页事件浏览器/一致性验证/`（事件、界面、文树、消息四包，含 0.2.0 选择器与 0.3.0 新函数的用例）。
