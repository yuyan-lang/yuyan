# 真实浏览器验收清单（网页定时等八包、网页事件零点二点零、网页界面零点三点零）

JSDOM 所不能及者，当于真实浏览器（Chromium，备 JSPI）验之。**测试页**：置探针应用之产物（`自动启动.mjs`、`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`接口要求组.json`……）与 `测试页.html` 于同一目录，以静态服务器（`.mjs` 当以 `text/javascript`、`.wasm` 以 `application/wasm`，`text/event-stream` 之接口须真流式）启之；于控制台或自动化之具，以 `window.__发(操作, ...参)` 调接口，`await window.__宿主` 取宿主之物，`.状态()` 读列之状。所验之果，记于下“验证记录”。

**已验（真实浏览器）**：见末“验证记录”。

**当于真实浏览器验之项**：

1. **定时**：标签页处后台则定时降频（约每秒一次），事仍依序；一次之期毕后可再启；取消定时之后无此号之事。
2. **储存**：真 sessionStorage 与 localStorage；隐私模式或站点数据被禁，则写入网页储存返阴、读取网页储存返（阴，空）；配额（约五 MB）满则返阴而不发事故。
3. **导航**：压入历史、替换历史惟改地址栏；真前进后退生“历史”之事；前往网址至同源他页与他源；替换当前网址后退不复至旧页；`javascript:` 之址见拒。
4. **环境**：真时区之偏与 `new Date().getTimezoneOffset()` 之号相反；夏令时切换日前后；真 document.cookie 中带 HttpOnly 之饼不可见。
5. **请求**：真 fetch：同源癸象之 GET 与 POST；“缓存:不缓存”实带 `Cache-Control: no-cache`；同时三十二请求；重定向至他来源，为 `mode:same-origin` 视作网络之错；超时与撤；服务器返非 UTF-8 之正文。
6. **事件源**：真 fetch 流读 `text/event-stream`：从服务器之 `retry:`；服务端每二十秒轮换连接时“重连中→打开”；一回放数千条旧事而页仍应点击（背压不使界面冻）；后台标签页中之行。
7. **编译**：本地编译可用于无 Worker 或无 JSPI 之浏览器为阴；真编译客户端（`编译/客户端.mjs`）端至端：进度成批、完成之事、停止（Worker 终止后可再启）。
8. **应用**：真 `import()` 载另一豫言浏览器应用，子应用于父应用事环之外独立应点击；子应用载败之错示。
9. **网页事件零点二点零选择器**：真点导航之链与语言之钮：阻止默认使链不跳（dispatchEvent 一返即已阻止）；停止同处使页上他监听者不得见；带矩形之数与开发者工具所见元素之位相符；悬停之 mouseover 于疾移下选择器之滤不失事。
10. **网页界面零点三点零**：点击节点触发 `<a href="#锚">` 真滚至锚；设置节点位置于 `position:absolute` 之浮层真移，且与读取节点矩形相符；读取节点属性（“文档根”，…）。
11. **兼容**：Firefox（JSPI 之可用）、Safari 二十七；无 JSPI 之浏览器上，候事之函数当明示降级之告。

## 验证记录

**二〇二六年九月二十六日，Chromium 一百五十二（Claude 内置浏览器，备 JSPI），本机 `node 测试/真浏览器服务.mjs` 供静态页与 `/api/*`；皆通过**

| 项 | 果 |
| --- | --- |
| 一 定时 | 一次之期至，事之种类、标记、定时号皆正，耗时不少于所设；周期之期不积压（客不取事二百五十毫秒，积压恰一）；取后续投；取消返阳、再取消返阴 |
| 二 储存 | 真 localStorage 与 sessionStorage 往返（含 😀）；会话与本地相隔；空值乃“存在” |
| 三 导航 | 压入历史、替换历史惟改地址栏；移动历史（负一）收类曰历史之 popstate 事而址归其始；跨源之历史与 `javascript:` 之址见拒 |
| 四 环境 | 美东时区之偏，冬负三百、夏负二百四十，与 getTimezoneOffset 之号相反而相合；读取页面饼得 `yuyan_lang=wen`，`abc%20d` 原样而返，HttpOnly 之饼不可见 |
| 五 请求 | GET 与 POST 癸象、“缓存:不缓存”实带 `Cache-Control: no-cache`，请求带本站之饼；四百零四仍为“完成”；非 UTF-8 → 败；重定向至他来源 → 网络之错；超时、正文过大；三并发之请求依到达之序入列，撤其一而无残事；阻塞之变体候时所到之定时事仍在列 |
| 六 事件源 | 真 fetch 流：服务端每一百五十毫秒闭联而 retry:100，稳定重连八秒（“重连中”→“打开”，事件号相连）；**五千事回放：积压恒八批、弃零、页面主线程之迟如常（五十毫秒之计时差二毫秒），五千条无失无重**；四百零四与 text/html 为致命之错 |
| 七 编译 | 本地编译可用为真（Worker、JSPI、DecompressionStream 皆备）；假编译客户端经**真动态 import()** 自页面基址目录之 `编译/客户端.mjs` 载入：三十一条进度（含三十条输出）与完成之事皆正，止后收“已停止”。**真编译客户端加编译器资源，本轮未验** |
| 八 应用 | 真 `import('/子应用/入口.mjs')`：子应用书于文树，应真点击；重启与不存之模块发事故 |
| 九 选择器 | 真鼠标悬、点带 title 之链：带属性、带矩形（与元素之真位相合）皆正；阻止默认加停止同处使链不跳、页上他监听者不得见；点 `.文件目录` 之内无事（排除选择器），点页之空白处有事 |
| 十 界面零点三点零 | 点击节点触发 `<a href="#锚">` 真滚（scrollY 七百二十一）；拦截之订阅在则点被同步阻止（合于约，须先撤订阅）；设置节点位置后读取节点矩形与真 getBoundingClientRect 相合；读取节点属性（“文档根”，“data-lang”） |
| 文树零点三点零 | 真页中查询、template 内容之查询（文档查询不见之）、导出树重建、超文本之清洗（`<img onerror>` 见拒）、替换包一层，皆合于约 |

**尚未于真实浏览器验之项**：后台标签页定时之降频；隐私模式与配额满时储存之败；Firefox 与 Safari；真编译客户端与编译资源；服务端每二十秒轮换事件流之久行；输入法组字与焦点之细（沿旧清单）。
