# 网页定时、储存、导航、环境、请求、事件源、编译、应用：浏览器一致性验证

八新包，及时间、随机数、网址定位、网址查询、日志、文字规整六既有接口之**浏览器适配**（`适配/<能力>浏览器/`），共一探针之应用“前端接口探针”，故验之材料聚于此。

**内容**

- `应用/前端接口探针/`：探针应用之源（包描述之文件名带 `.txt` 后缀，免为 `yy豫构 发现` 所当作包）。其订“豫言测试命令”之消息，依 `{"号":n,"操作":"函数名","参":[…]}` 而调八包之**诸**函数（另含等待网页事件、订阅、发布消息等取事所需之调），以“豫言测试回复”之消息返 `{"号":n,"成":爻,"果":字符串}`；函数败，则事故之辞原样在“果”。返有无之函数，其元组以 `1|值` 与 `0|` 示其存否。
- `测试/网页能力单元.test.mjs`：不涉 Wasm，以 JSDOM 直测宿主之 `创建SSE解析器`（逐字节：分块、CRLF、BOM、多字节、注释、retry、逾限）与 `创建网页能力`（不能经探针传递之大载荷限额、关闭后之行、背压之管线）。
- `测试/前端接口一致性.test.mjs`：JSDOM 加**真实 Wasm**：定时（不积压、取消之保、名额）、储存（区之隔、配额败返阴）、环境（时区、饼）、导航（历史与 popstate）、请求（本机 node:http 服务器与 Node 真实 fetch：成／败／撤／并发之限／阻塞之变体）、事件源（成批、重连与 Last-Event-ID、致命之错、**五千事背压而不失**）、编译（注入假编译客户端：成批之进度、止、单例）、应用（注入假模块加载器）、六浏览器适配（约中之一致性之例逐条验之）；又一条察探针已覆八接口文件中之每一函数。
- `测试/夹具.mjs`：启探针之公共代码（选项：网络、编译客户端、导入模块、页面应用超时、窗扩展）。
- `真实浏览器验收清单.文言.md`：JSDOM 所不能及、须于真实浏览器验之项与已验之果。

**以私有暂存复跑**（于语言仓根，`$SP` 为己之草稿区）

```sh
$SP/工具箱/建暂存.sh $SP/我的暂存
$SP/工具箱/建应用.sh $SP/我的暂存 浏览器 <语言仓>/豫言操作系统/适配/网页定时/一致性验证/应用/前端接口探针 前端接口探针
env "前端探针产物目录=$SP/我的暂存/dist/前端接口探针/" \
    "JSDOM路径=<云仓>/网站/node_modules/jsdom/lib/api.js" \
    node --test --test-timeout=25000 \
      <语言仓>/豫言操作系统/适配/网页定时/一致性验证/测试/网页能力单元.test.mjs \
      <语言仓>/豫言操作系统/适配/网页定时/一致性验证/测试/前端接口一致性.test.mjs
```

- 环境变量皆有默认：前端探针产物目录默认 `一致性验证/产物/`；JSDOM路径默认依仓库之布局指云仓；接口根、探针源供“覆全函数”一条用。
- **勿传逾一 MiB 之载荷于探针**（网页消息之限使探针自止）；限额类之断言置于 `网页能力单元.test.mjs`。
- 服务器之径当用 ASCII（node:http 所收之径为百分号编码）。
- 诸测数秒即毕；测中之网络皆本机回环，不访外网。

**相关之既有验收**：`网页事件浏览器/一致性验证/`（事件、界面、文树、消息四包，含零点二点零选择器与零点三点零新函数之例）。
