# 网页定时浏览器适配

`定时。豫` 行[网页定时之约](../../../豫言操作系统接口/网页定时/规范.文言.md)之诸函数：`启动一次定时`、`启动重复定时`、`取消定时`。`实现接口。豫` 定公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（须候者）二原语，操作名为 `定时.一次`、`定时.重复`、`定时.取消`；败则以（阴，错误文）返，本适配转为豫言事故，不使 JavaScript 之异常越 Wasm 之界。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`。`创建网页能力` 之定时部，验其参（周期之间至少十毫秒，标记至多一千零二十四码元），乃调宿主已有之 `造定时`（setTimeout 与 setInterval，同时至多六十四）；期至之事入统一事列，类曰“定时”，订阅号即定时号；周期之期，前事未取则不复投。撤时并去列中此号未取之事。

**运行之要**：候事之函数挂豫言之栈，浏览器须支持 JSPI；八新包与网页事件包共一统一事列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用“前端接口探针”、宿主单元测试与 JSDOM 加真实 Wasm 之一致性测试，说明见其中之 `说明.文言.md`）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「浏览器宿主」之「网页能力原语」之「浏览器网页能力」（旧外调名 `豫言_浏览器_网页能力`）。宿主实此诸导入，与旧原语同。
