# 显示节点适配

`画面。豫`、`输入。豫` 在路一 Node 宿主上实现[显示接口](../../../豫言操作系统接口/显示/规范.汉语.md) 0.1.0 的两个模块。`实现接口。豫` 固定公共包身份与版本；双宿主构建的节点模式按 `宿主/节点/宿主支持清单.tsv` 选用本目录，并连带绑定 `../基础节点/`。两个模块与[显示浏览器适配](../显示浏览器/说明.汉语.md)的同名模块逐句相同，只有外调名（`豫言_节点_显示`）与私有构造器名（`节点显示面`）不同，改动时两边同步。

**依赖**：宿主运行时需要 npm 包 `@kmamal/sdl`（SDL 2 的 Node 绑定），第一次取得显示面时才载入；查找顺序与宿主选项见[节点宿主说明](../../宿主/节点/说明.汉语.md)。找不到时 `取得已授显示面` 返回 `资源暂不可用`，并在标准错误提示一次。包描述用「平台」声明本适配只用于诺节，并在「诺节库」里登记 `@kmamal/sdl`。

**显示面怎样授予**：运行发行包时用宿主选项 `--授权显示面 名称=宽x高`（可重复，写在 `--` 前）授予，宽高是窗口的逻辑尺寸（点）。`取得已授显示面 名称` 第一次调用时开一个标题为该名称的 SDL 窗口；名称没有授予返回 `未获授权`；同名再取得返回同一个显示面。用户关闭窗口或应用结束时显示面关闭。宿主选项 `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）让窗口隐藏且不激活，自动验收用它。

```sh
node dist/应用/启动.mjs --授权显示面 主画面=640x480 -- 应用参数
```

- **尺寸**：物理像素，即 SDL 窗口的 `pixelWidth`、`pixelHeight`（Retina 屏上是逻辑尺寸的两倍）。窗口不可拖动改尺寸；移到像素比不同的屏幕时尺寸随之改变。
- **像素画面**：先按规范核对宽高与字节数（`输入无效`）与当前尺寸（`资源暂不可用`），再用 SDL 的 `window.render(宽, 高, 宽×4, 'rgba32', 字节)` 原样覆盖窗口（不混合）。已用于图形显示呈现的显示面返回 `资源暂不可用`。超过 16 MiB 的画面返回 `资源配额已尽`（待办事项：分块传递）。
- **输入事件**：SDL 的 `keyDown`、`keyUp` 转成按键事件：`left right up down return enter backspace space` 依次译为 `左 右 上 下 回车 回车 退格 空格`，单个字符原样交付（字母按 Shift 与大写锁定定大小写），其余键不交付；`textInput`（含输入法提交的文字）转成 `文字输入`；`mouseMove`、`mouseButtonDown`、`mouseButtonUp` 转成指针事件，坐标乘以像素比后取整，按钮号为 SDL 按钮号减一（左 0、中 1、右 2）；相邻的指针移动合并。每个显示面有独立事件队列（上限 65536，满时丢最旧的），同一显示面第二个并发等候者得 `输入无效`；关闭后先交付一次 `显示面已关闭`，再等待返回 `资源已失效`。待办事项：组字期间的按键也会交付（@kmamal/sdl 不给组字事件）；随 Shift 变化的符号键（如 Shift+1）交付未变化的字符。

**宿主原语**：`豫言_节点_显示(操作, 显示面号, 甲, 乙, 字节)`，操作与返回值同浏览器的 `豫言_浏览器_显示`。显示面表（取得结果、事件队列、等候、提交校验、关闭流程）与浏览器共用 `宿主/浏览器/图形.mjs` 的 `创建显示面表`；SDL 窗口后端在 `宿主/节点/图形.mjs`，发行启动文件内联这两个模块。`等待输入事件` 挂起豫言栈（JSPI）。

**验收**：`../图形显示节点/一致性验证/`（探针、后台窗口的自动验收与输入事件的人工验收）；宿主单元测试在 `宿主/节点/图形。测试.mjs`（伪 SDL，不开窗口）。
