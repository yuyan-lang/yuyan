# 显示节点适配

0.7.0 新增 `设置指针形状`（原语操作 `指针形状`，宿主用 SDL 系统光标 arrow、ibeam、hand；SDL 光标为全局，多个显示面以最后一次为准）与输入事件 `组字更新` 的转换；@kmamal/sdl 不给组字事件，Node 宿主暂不交付它。共用显示核心另有 `剪贴板读`、`剪贴板写` 两个操作，供[节点剪贴板适配](../剪贴板节点/说明.汉语.md)使用。

0.6.0 将宿主事件种类10译为 `显示尺寸变化`。SDL窗口尺寸或所在显示器变化时唤醒同一豫言主循环，重读当前尺寸及像素比；旧窗口在图形模式替换后的通知不影响新窗口。

0.5.0 接入限时等待，原语操作 `等待限时` 以甲为毫秒，事件种类9译为 `显示计时`；输入到达、到期与归还均撤销候者和计时器。显示面表仍与浏览器共用。

显示0.4.0新增 F2 的语义键名“功能二”，按下和抬起沿用既有事件交付。

现实现显示接口0.3.0，新增归还结果及 `归还显示面`，委托共用宿主关闭本次SDL窗口；旧面号失效，授权保留供同名再取。下文0.2.0的像素比与输入区域规则保持适用。

`画面。豫`、`输入。豫` 在路一 Node 宿主上实现[显示接口](../../../豫言操作系统接口/显示/规范.汉语.md) 0.2.0 的两个模块。`实现接口。豫` 固定公共包身份与版本；双宿主构建的节点模式按 `宿主/节点/宿主支持清单.tsv` 选用本目录，并连带绑定 `../基础节点/`。两个模块与[显示浏览器适配](../显示浏览器/说明.汉语.md)的同名模块逐句相同，只有外调名（`豫言_节点_显示`）与私有构造器名（`节点显示面`）不同，改动时两边同步。

**依赖**：宿主运行时需要 npm 包 `@kmamal/sdl`（SDL 2 的 Node 绑定），第一次取得显示面时才载入；查找顺序与宿主选项见[节点宿主说明](../../宿主/节点/说明.汉语.md)。找不到时 `取得已授显示面` 返回 `资源暂不可用`，并在标准错误提示一次。包描述用「平台」声明本适配只用于诺节，并在「诺节库」里登记 `@kmamal/sdl`。

**显示面怎样授予**：运行发行包时用宿主选项 `--授权显示面 名称=宽x高`（可重复，写在 `--` 前）授予，宽高是窗口的逻辑尺寸（点）。`取得已授显示面 名称` 第一次调用时开一个标题为该名称的 SDL 窗口；名称没有授予返回 `未获授权`；同名再取得返回同一个显示面。用户关闭窗口或应用结束时显示面关闭。宿主选项 `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）让窗口隐藏且不激活，自动验收用它。

```sh
node dist/应用/启动.mjs --授权显示面 主画面=640x480 -- 应用参数
```

- **尺寸**：物理像素，即 SDL 窗口的 `pixelWidth`、`pixelHeight`（Retina 屏上是逻辑尺寸的两倍）。窗口不可拖动改尺寸；移到像素比不同的屏幕时尺寸随之改变。
- **像素画面**：先按规范核对宽高与字节数（`输入无效`）与当前尺寸（`资源暂不可用`），再用 SDL 的 `window.render(宽, 高, 宽×4, 'rgba32', 字节)` 原样覆盖窗口（不混合）。已用于图形显示呈现的显示面返回 `资源暂不可用`。单帧上限是 16 MiB 的一百倍（1600 MiB），高像素比屏幕上的大窗口画面可以整帧提交；超过上限返回 `资源配额已尽`。
- **输入事件**：SDL 的 `keyDown`、`keyUp` 转成按键事件：`left right up down return enter backspace space` 依次译为 `左 右 上 下 回车 回车 退格 空格`；0.2.0 增 `delete home end pageUp pageDown tab escape` 译为 `删除 起首 末尾 上翻页 下翻页 制表 退出`，修饰键 `shift ctrl alt gui` 译为 `上档 控制 交替 命令`（@kmamal/sdl 把右 GUI 键拼成 `gUI`，一并收下），窗口 `blur` 时为按着的修饰键补发按键抬起；单个字符原样交付（字母按 Shift 与大写锁定定大小写），其余键不交付；`mouseWheel` 转成 `滚轮`：格数乘 48 个逻辑像素与像素比，纵向取反（SDL 向上为正），`flipped` 时再反，相邻两次合并；`textInput`（含输入法提交的文字）转成 `文字输入`；`mouseMove`、`mouseButtonDown`、`mouseButtonUp` 转成指针事件，坐标乘以像素比后取整，按钮号为 SDL 按钮号减一（左 0、中 1、右 2）；相邻的指针移动合并。每个显示面有独立事件队列（上限 65536，满时丢最旧的），同一显示面第二个并发等候者得 `输入无效`；关闭后先交付一次 `显示面已关闭`，再等待返回 `资源已失效`。待办事项：组字期间的按键也会交付（@kmamal/sdl 不给组字事件）；随 Shift 变化的符号键（如 Shift+1）交付未变化的字符。

**宿主原语**：`豫言_节点_显示(操作, 显示面号, 甲, 乙, 字节, 丙, 丁)`，操作与返回值同浏览器的 `豫言_浏览器_显示`。`读取显示面像素比` 为窗口 `pixelWidth / width`；`设置文字输入区域` 照常返回但不起作用（待办事项：@kmamal/sdl 没有 `SDL_SetTextInputRect`，候选框位置由系统定；以后可考虑经 node:ffi 调同一个 libSDL2）。显示面表（取得结果、事件队列、等候、提交校验、关闭流程）与浏览器共用 `宿主/浏览器/图形.mjs` 的 `创建显示面表`；SDL 窗口后端在 `宿主/节点/图形.mjs`，发行启动文件内联这两个模块。`等待输入事件` 挂起豫言栈（JSPI）。

**验收**：`../图形显示节点/一致性验证/`（探针、后台窗口的自动验收与输入事件的人工验收）；宿主单元测试在 `宿主/节点/图形。测试.mjs`（伪 SDL，不开窗口）。

**平台接口**：本适配的包装函数转调平台接口包里的无体声明，编成带类型的宿主导入（边界签名见《网页汇编接口》网五）：「诺节宿主」之「显示原语」的「诺节显示操作」（旧外调名 `豫言_节点_显示`）。宿主对这些导入的实现与旧原语相同。
