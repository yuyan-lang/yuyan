# 显示节点适配

显示零点四版增 F2 之语义键名“功能二”，按下与抬起循旧事授之。

今行显示零点三版，增归还结果与 `归还显示面`，授共用宿主闭此SDL窗；旧号失效，存授权以供同名复取。下文零点二版像素比与输入区域之约犹用。

`画面。豫`、`输入。豫` 于路一节点宿主行[显示接口](../../../豫言操作系统接口/显示/规范.文言.md) 零点二点零之二模。`实现接口。豫` 定公约之身份与版；双宿主构建于节点之式依 `宿主/节点/宿主支持清单.tsv` 取此目，并连绑 `../基础节点/`。二模与[显示浏览器适配](../显示浏览器/说明.文言.md)同名之模逐句相同，惟外调之名（`豫言_节点_显示`）与私构之名（`节点显示面`）异；改之则两处同改。

**所依**：宿主行之须 npm 包 `@kmamal/sdl`（SDL 二之节点绑定），初取显示面乃载之；寻之之序与宿主之选见[节点宿主之说](../../宿主/节点/说明.文言.md)。不得则 `取得已授显示面` 返 `资源暂不可用`，并于标准误一告之。包描述以「平台」明此适配唯用于诺节，而登 `@kmamal/sdl` 于「诺节库」。

**显示面何以授**：行发行之包时，以宿主之选 `--授权显示面 名=宽x高` 授之（可重书，书于 `--` 之前），宽高为窗之点数。`取得已授显示面 名` 初调则开一 SDL 之窗，以名为题；名未授则返 `未获授权`；同名再取，得同一显示面。用者闭窗或应用终，则面闭。宿主之选 `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）令窗隐而不激，自动之验用之。

```sh
node dist/应用/启动.mjs --授权显示面 主画面=640x480 -- 应用参数
```

- **尺寸**：以物理之素计，即 SDL 窗之 `pixelWidth`、`pixelHeight`（Retina 之屏为点数之倍）。窗不可拖而易其尺；移至像素比异之屏则尺随之易。
- **像素画面**：先依规范核宽高与字数（`输入无效`）及现尺（`资源暂不可用`），乃以 SDL 之 `window.render(宽, 高, 宽×4, 'rgba32', 字节)` 原样覆其窗（不混合）。已用于图形显示之呈现之面返 `资源暂不可用`。逾十六兆之画面返 `资源配额已尽`（待办事项：分块而交）。
- **输入之事**：SDL 之 `keyDown`、`keyUp` 化为按键之事：`left right up down return enter backspace space` 依次译为 `左 右 上 下 回车 回车 退格 空格`，单一之字原样交之（字母依 Shift 与大写锁定定其大小），余键不交；`textInput`（兼输入法所成之文）化为 `文字输入`；`mouseMove`、`mouseButtonDown`、`mouseButtonUp` 化为指针之事，坐标乘像素比而取整，钮号为 SDL 钮号减一（左零、中一、右二）；相接之移合一。每面各有事列（限六万五千五百三十六，满则去其最旧），同面并候之第二者得 `输入无效`；闭后先交 `显示面已关闭` 一次，再候返 `资源已失效`。待办事项：组字之中之键亦交（@kmamal/sdl 不供组字之事）；随 Shift 而变之符号键（如 Shift+1）交其未变之字。

**宿主原语**：`豫言_节点_显示(操作, 显示面号, 甲, 乙, 字节, 丙, 丁)`，其操作与所返同浏览器之 `豫言_浏览器_显示`。零点二版：`delete home end pageUp pageDown tab escape` 译为 `删除 起首 末尾 上翻页 下翻页 制表 退出`，`shift ctrl alt gui` 译为 `上档 控制 交替 命令`，窗失焦则补修饰之抬起；`mouseWheel` 化为 `滚轮`（格乘四十八逻辑像素与像素比，纵反之，flipped 则再反）；像素比为窗之 `pixelWidth / width`；`设置文字输入区域` 照返而无效（待办事项：@kmamal/sdl 无 `SDL_SetTextInputRect`）。显示面之表（取之果、事列、候者、提交之验、面闭之序）与浏览器共用 `宿主/浏览器/图形.mjs` 之 `创建显示面表`；SDL 窗之后端在 `宿主/节点/图形.mjs`，发行之启动文件内联此二模。`等待输入事件` 挂起豫言之栈（JSPI）。

**验收**：`../图形显示节点/一致性验证/`（探针、后台之窗之自动验收、输入之事之人工验收）；宿主之单元测试在 `宿主/节点/图形。测试.mjs`（伪 SDL，不开窗）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「诺节宿主」之「显示原语」之「诺节显示操作」（旧外调名 `豫言_节点_显示`）。宿主实此诸导入，与旧原语同。
