# 显示节点适配

`画面。豫`、`输入。豫` 于路一节点宿主行[显示接口](../../../豫言操作系统接口/显示/规范.文言.md) 零点一点零之二模。`实现接口。豫` 定公约之身份与版；双宿主构建于节点之式依 `宿主/节点/宿主支持清单.tsv` 取此目，并连绑 `../基础节点/`。二模与[显示浏览器适配](../显示浏览器/说明.文言.md)同名之模逐句相同，惟外调之名（`豫言_节点_显示`）与私构之名（`节点显示面`）异；改之则两处同改。

**所依**：宿主行之须 npm 包 `@kmamal/sdl`（SDL 二之节点绑定），初取显示面乃载之；寻之之序与宿主之选见[节点宿主之说](../../宿主/节点/说明.文言.md)。不得则 `取得已授显示面` 返 `资源暂不可用`，并于标准误一告之。待办事项：本欲书 `@kmamal/sdl` 于包描述「原生」之「系统依赖」，然包配置惟许以 ASCII 字母、数字及 `_ + - .` 为系统库名，书之则全仓之包发现皆败，故暂记于包描述之注。

**显示面何以授**：行发行之包时，以宿主之选 `--授权显示面 名=宽x高` 授之（可重书，书于 `--` 之前），宽高为窗之点数。`取得已授显示面 名` 初调则开一 SDL 之窗，以名为题；名未授则返 `未获授权`；同名再取，得同一显示面。用者闭窗或应用终，则面闭。宿主之选 `--显示面后台`（或环境变量 `YY_NODE_DISPLAY_BACKGROUND=1`）令窗隐而不激，自动之验用之。

```sh
node dist/应用/启动.mjs --授权显示面 主画面=640x480 -- 应用参数
```

- **尺寸**：以物理之素计，即 SDL 窗之 `pixelWidth`、`pixelHeight`（Retina 之屏为点数之倍）。窗不可拖而易其尺；移至像素比异之屏则尺随之易。
- **像素画面**：先依规范核宽高与字数（`输入无效`）及现尺（`资源暂不可用`），乃以 SDL 之 `window.render(宽, 高, 宽×4, 'rgba32', 字节)` 原样覆其窗（不混合）。已用于图形显示之呈现之面返 `资源暂不可用`。逾十六兆之画面返 `资源配额已尽`（待办事项：分块而交）。
- **输入之事**：SDL 之 `keyDown`、`keyUp` 化为按键之事：`left right up down return enter backspace space` 依次译为 `左 右 上 下 回车 回车 退格 空格`，单一之字原样交之（字母依 Shift 与大写锁定定其大小），余键不交；`textInput`（兼输入法所成之文）化为 `文字输入`；`mouseMove`、`mouseButtonDown`、`mouseButtonUp` 化为指针之事，坐标乘像素比而取整，钮号为 SDL 钮号减一（左零、中一、右二）；相接之移合一。每面各有事列（限六万五千五百三十六，满则去其最旧），同面并候之第二者得 `输入无效`；闭后先交 `显示面已关闭` 一次，再候返 `资源已失效`。待办事项：组字之中之键亦交（@kmamal/sdl 不供组字之事）；随 Shift 而变之符号键（如 Shift+1）交其未变之字。

**宿主原语**：`豫言_节点_显示(操作, 显示面号, 甲, 乙, 字节)`，其操作与所返同浏览器之 `豫言_浏览器_显示`。显示面之表（取之果、事列、候者、提交之验、面闭之序）与浏览器共用 `宿主/浏览器/图形.mjs` 之 `创建显示面表`；SDL 窗之后端在 `宿主/节点/图形.mjs`，发行之启动文件内联此二模。`等待输入事件` 挂起豫言之栈（JSPI）。

**验收**：`../图形显示节点/一致性验证/`（探针、后台之窗之自动验收、输入之事之人工验收）；宿主之单元测试在 `宿主/节点/图形。测试.mjs`（伪 SDL，不开窗）。
