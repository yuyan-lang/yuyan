# 声音原生验收

公共声音接口打开 48000 赫兹双声道设备，写入两块样本并核对设备时钟与关闭后的资源失效。节点发行通过豫言原生子程序服务执行设备操作，系统库调用仅供测试等待。

`声音宿主探针。豫` 是包里另一个单独构建的入口文件：经公共声音接口与设备接口的「问声卡」检查声音流的开、写、写满、查已播、重开、整帧、放干后再写、空等后写与关闭，每项印“通过”或“不符”，只写静音，不出声。编成豫行（`豫构 文件 … -- --目标 本机 --目标系统 豫言 --目标架构 臂六十四 --执行器 执行器。树码`）在豫行启动器下运行时，检查内核声音服务 80–84（启动器在 macOS 上用音频队列办理，提案 00021 第 8 步）；编成 macOS 原生程序时检查声音输出原生适配，两边逐行对照，原生适配收 44100 赫、待播不设上限、可以多流、查询声卡得“资源暂不可用”，对应的几项不同是预期的。

`声图放声。豫` 是第三个单独构建的入口文件：用匠心的声图混出四百四十赫的正弦加噪声（每块四千零九十六帧，共二十四块，约两秒），经公共声音接口逐块编成十六位小端样本写入林檎的声音播放队列。写完后按设备时钟等它播完，每二百五十毫秒印已播帧数与待播延迟；核对时钟推进、待播非负、关流后流失效，末行印“声图放声通过”。听不到声音时，看这两个数即知缓冲是否按四万八千赫被设备消耗。编成 macOS 原生程序：`豫构 构建 声音原生验收 声图放声 --输出 声图放声。林檎。豫行`（构建给本机程序接上声音输出原生适配），运行时须宿主选项 `--授权声音输出`，即 `./声图放声。林檎。豫行 --授权声音输出`。
