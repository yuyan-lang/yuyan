# 字体：诺节与浏览器一致性之验

诺节与浏览器共用字体探针 `应用/字体探针/`。诺节于本机系统之字体目录寻之；浏览器之试页 `豫言操作系统/宿主/浏览器/字体。测试页.html` 以三标准族名皆声为一份试字体 `字体/测试字体.ttf`。试字体不入库：本机置于仓外 `豫言数据/字体/`（Droid Sans Fallback，Apache 二版，见其目之 来源.txt），凡 TrueType 字体皆可代之。

**复行**：一、诺节：以双宿主构建之节点式建探针而行之，当终于“探针完成：通过 19 项，失败 0 项”。二、浏览器：以浏览器式建之，置试页与试字体于产物之目，以本机之服供之。三、无头 Chrome 导其页，`<pre id="结果">` 当终于同言，`<html>` 带 `data-探针="完成"`。四、宿主之单元测试（不须真字体与浏览器）。命令详见[汉语稿](说明.汉语.md)。

**验记（2026-09-30，macOS arm64，Node 26.3.0，Chrome 154 无头）**：诺节探针过十九事，无败；无衬线得 `STHeiti Medium.ttc` 第一面（黑体-简 中等），衬线得 `Songti.ttc` 第六面（宋体-简 常规），等宽得 `Menlo.ttc` 第零面。浏览器探针过十九事，无败。宿主之单元测试，诺节十一、浏览器十五，皆过。林纳克斯与视窗之路径表未于真机验之。
