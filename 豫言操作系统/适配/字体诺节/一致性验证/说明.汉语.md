# 字体：诺节与浏览器一致性验证

诺节与浏览器共用字体探针 `应用/字体探针/`。诺节在本机的系统字体目录里找字体；浏览器测试页 `豫言操作系统/宿主/浏览器/字体。测试页.html` 把三个标准族名都声明成同一份测试字体 `字体/测试字体.ttf`。测试字体不入库：本机放在仓外 `豫言数据/字体/`（Droid Sans Fallback，Apache 2.0，见该目录的 来源.txt），任何 TrueType 字体都可代替。

**复跑**（在语言仓根目录；需已构建 `yy双宿主构建`、`yy4_bs`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；勿与别的构建并发）

```sh
# 1. 诺节：构建并运行探针，应以“探针完成：通过 19 项，失败 0 项”结束
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/适配/字体诺节/一致性验证/应用/字体探针 dist/字体探针
node dist/字体探针/启动.mjs
# 2. 浏览器：构建，放入测试页与测试字体，用本机服务提供
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 豫言操作系统/适配/字体诺节/一致性验证/应用/字体探针 dist/字体探针浏览器
mkdir -p dist/字体探针浏览器/字体
cp 豫言操作系统/宿主/浏览器/字体。测试页.html dist/字体探针浏览器/
cp ../豫言数据/字体/DroidSansFallbackFull.ttf dist/字体探针浏览器/字体/测试字体.ttf
node 豫言操作系统/适配/网页定时/一致性验证/测试/真浏览器服务.mjs dist/字体探针浏览器 18777 &
# 3. 无头 Chrome 导出页面：<pre id="结果"> 应以“探针完成：通过 19 项，失败 0 项”结束，<html> 带 data-探针="完成"
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --user-data-dir=/tmp/豫言字体探针 \
  --dump-dom "http://127.0.0.1:18777/字体。测试页.html?等待=6000" > 字体探针输出.html
# 4. 宿主单元测试（不需要真字体与浏览器）
node --test 豫言操作系统/宿主/节点/图形。测试.mjs 豫言操作系统/宿主/浏览器/图形。测试.mjs
```

Chrome 导出页面后进程可能不退出：输出文件出现 `</html>` 后结束它即可。
