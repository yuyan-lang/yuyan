# 日志浏览器适配

`日志。豫` 在浏览器里实现[日志接口](../../../豫言操作系统接口/日志/规范.汉语.md)（0.1.0）：按错误、警告、信息三级写单条日志。语义与云工适配（`../日志/`）逐字相同，接口包本身不变。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `日志.错误`、`日志.警告`、`日志.信息`；失败以（阴，错误文）返回，再转成豫言事故。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`：写入页面的 `console.error/warn/info`；单条超过 8192 个 UTF-8 字节时在字符边界截断并附“…（已截断）”。

**选用规则**：构建器在浏览器模式下优先选用 `适配/<能力>浏览器`，云工模式选 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用 `前端接口探针` 含本接口；JSDOM＋真实 Wasm）。
