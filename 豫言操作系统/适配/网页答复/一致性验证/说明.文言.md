# 网页答复一致性验证（0.5.0）

此目录以真 Wasm 与节点宿主验《豫言操作系统网页答复》0.5.0 之云工适配：

- `应用/网页答复一致性应用/`：试验之应用。包描述存为 `网页答复一致性应用。包。豫.txt`，以免为 `yy豫构` 之全仓包发现误析为包；构建脚本 `建应用.sh` 复之于暂存内之临目录而改回原名。
- `网页答复一致性.test.mjs`：节点之测，载构建之产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑（用私暂存）

一、建暂存（一次）：`建暂存.sh <暂存目录>`，符号链接语言仓只读之材，并复编译器与构建之器。
二、构建：`建应用.sh <暂存目录> 云工 <本目录>/应用/网页答复一致性应用 网页答复一致性`，产物在 `<暂存目录>/dist/网页答复一致性/`。
三、测试：`cd <暂存目录> && node --test <本目录>/网页答复一致性.test.mjs`。产物根默认为当前目录之 `dist`，可以环境变量 `产物根` 改之。

## 所覆

- 五带头之术：同名之头守序而多 `Set-Cookie`、不暗增一头、正文原样（含二百五十六字节值与零字节）；
- 状二百至五百九十九与二零四、二零五、三零四之正文相冲；头名、值、数、禁名（不辨大小写）、`Set-Cookie` 之长、内容种类之正反例，含 CRLF 注入、非 ASCII、控字符；
- 正文之限（八 MiB、二 MiB、十六 MiB 及各加一）；改址之五状与二十余种目标之正反例；HEAD 不特为处；重复答复惟首者生效；旧术回归（含旧术仍自增 no-store 与 nosniff）。

每测皆断言真 Wasm 之可察之行；期望之值凡能由平台标准之实现给出者（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`），皆取自同一标准之实现，不手抄。
