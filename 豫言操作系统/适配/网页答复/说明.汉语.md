# 网页答复云工适配

把公共答复调用投影为当前 Worker 的 Response。旧函数（癸象文、空答、文字、同源改址、外址改址）保持 0.4.0 的行为，包括自动添加 `Cache-Control: no-store` 与 `X-Content-Type-Options: nosniff`。

带头系列（0.5.0：文字、癸象文、空答、字节、改址）在豫言里先做全部校验：状态范围与无正文状态、标头名的令牌字符与长度、标头值的字符集与长度、数量、禁用名、内容类型格式、`Set-Cookie` 长度、`Location` 目标（绝对网址经 `URL.parse` 检查方案、用户信息与主机）以及正文大小；通过后才用 `Response` 构造器创建响应，标头以 `[["名","值"],…]` 序列初始化，从而保持顺序并允许同名多项。文字与字节正文经宿主字节句柄交给 Response，任意字节与控制字符都不经过 JSON 转义；适配不添加任何标头，平台自行处理的正文长度标头不在此列。宿主本身限制每次请求只设置一次响应。

不需要新的宿主原语。带头系列的校验全部发生在响应产生之前，失败时应用仍可回应错误。
