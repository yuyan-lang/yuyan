# 网页答复云工适配

以当前 Worker 之 Response 承公共答术。旧术（癸象文、空答、文字、同源改址、外址改址）守 0.4.0 之行，含自增 `Cache-Control: no-store` 与 `X-Content-Type-Options: nosniff`。

带头诸术（0.5.0：文字、癸象文、空答、字节、改址）于豫言中先尽验之：状之范围与无正文之状、头名之令牌字与长、头值之字集与长、头数、禁名、内容种类之式、`Set-Cookie` 之长、`Location` 之目标（绝对址以 `URL.parse` 察其方案、用户信息与主机）及正文之大；验毕，方以 `Response` 造答，头以 `[["名","值"],…]` 序列而初，以守其序并许同名多项。文字与字节之正文经宿主字节柄授 Response，任意字节与控字符皆不经 JSON 转义；适配不暗增一头，平台自理之正文长度头不在此列。宿主自限每请惟设一答。

无须新宿主原语。带头诸术之验皆在造答之前，败则客仍可答以误。
