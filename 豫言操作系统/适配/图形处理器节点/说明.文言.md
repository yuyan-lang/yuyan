# 图形处理器节点适配

`图形。豫` 于路一节点宿主以 Dawn（npm 包 `@kmamal/gpu`，Google Dawn 之 WebGPU）行[图形处理器接口](../../../豫言操作系统接口/图形处理器/规范.文言.md) 零点一点零。`实现接口。豫` 定公约之身份与版。此模与[图形处理器浏览器适配](../图形处理器浏览器/说明.文言.md)之 `图形。豫` 逐句相同，惟外调之名（`豫言_节点_图形`）与私构之名（`节点图形设备`、`节点图形纹理` 等）异；改之则两处同改。宿主之侧亦共用浏览器宿主 `宿主/浏览器/图形.mjs` 之 `创建图形能力`：惟易 `navigator.gpu` 为 Dawn 之例，设备、缓冲、纹理、采样器、着色模块、管线、绑定组、命令与读回之术，与浏览器同一其码，其详见图形处理器浏览器适配之说。

**所依**：`@kmamal/gpu` 初 `取得图形设备` 乃载之（寻之之序见[节点宿主之说](../../宿主/节点/说明.文言.md)）；不得或无适配器（如无 GPU 之 CI 机）则返 `资源暂不可用`，不得者又于标准误一告之。不用图形之应用不载之。包描述以「平台」明此适配唯用于诺节，而登 `@kmamal/gpu` 于「诺节库」。

- **限额**：依适配器之极而求；二〇二六年九月三十日于 macOS arm64（苹果之芯，Metal）依次为 30150672384、30150672384、16384、65535、1024 与 16777216（第六项为值桥单次交换之限十六兆）。
- **误**：Dawn 以未为误域所接之误径书于标准出，故宿主以误域包其建、录、交与读回；读回之复校验不过（如纹理无复制源之用）则返 `图形校验错误`。
- **退**：应用既终，宿主释诸设备而销 Dawn 之例，否则 Dawn 之计时拖住其进程。

**宿主原语**：`豫言_节点_图形(操作, 参数, 字节)`，其操作、参数之 JSON 与所返同浏览器之 `豫言_浏览器_图形`；行于 `宿主/浏览器/图形.mjs`（共用）与 `宿主/节点/图形.mjs`（载 Dawn 与窗之呈现器），发行之启动文件内联此二模。诸术皆可挂起（JSPI）。

**验收**：`../图形显示节点/一致性验证/`；宿主之单元测试在 `宿主/节点/图形。测试.mjs`（伪 GPU）与 `宿主/浏览器/图形。测试.mjs`（共用之分）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「诺节宿主」之「图形原语」之「诺节图形操作」（旧外调名 `豫言_节点_图形`）。宿主实此诸导入，与旧原语同。
