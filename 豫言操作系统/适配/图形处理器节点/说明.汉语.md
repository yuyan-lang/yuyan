# 图形处理器节点适配

`图形。豫` 在路一 Node 宿主上用 Dawn（npm 包 `@kmamal/gpu`，Google Dawn 的 WebGPU）实现[图形处理器接口](../../../豫言操作系统接口/图形处理器/规范.汉语.md) 0.1.0。`实现接口。豫` 固定公共包身份与版本。模块与[图形处理器浏览器适配](../图形处理器浏览器/说明.汉语.md)的 `图形。豫` 逐句相同，只有外调名（`豫言_节点_图形`）与私有构造器名（`节点图形设备`、`节点图形纹理` 等）不同，改动时两边同步。宿主一侧也共用浏览器宿主 `宿主/浏览器/图形.mjs` 的 `创建图形能力`：只把 `navigator.gpu` 换成 Dawn 的实例，设备、缓冲、纹理、采样器、着色模块、管线、绑定组、命令与读回的逻辑与浏览器是同一份代码，行为细节见图形处理器浏览器适配的说明。

**依赖**：`@kmamal/gpu` 在第一次 `取得图形设备` 时才载入（查找顺序见[节点宿主说明](../../宿主/节点/说明.汉语.md)）；找不到或没有适配器（如没有 GPU 的 CI 机器）时返回 `资源暂不可用`，找不到时还在标准错误提示一次。不用图形的应用不载入它。包描述用「平台」声明本适配只用于诺节，并在「诺节库」里登记 `@kmamal/gpu`。

- **限额**：按适配器的最大值申请；2026-09-30 在 macOS arm64（Apple 芯片，Metal）上依次为 30150672384、30150672384、16384、65535、1024 与 16777216（第六项是值桥单次交换上限 16 MiB）。
- **错误**：Dawn 把没有被错误域接住的错误直接打印到标准输出，所以宿主把创建、录制、提交与读回都包在错误域里；读回时复制的校验不通过（如纹理没有复制源用途）返回 `图形校验错误`。
- **退出**：应用结束后宿主释放全部设备并销毁 Dawn 实例，否则 Dawn 的计时器会拖住进程。

**宿主原语**：`豫言_节点_图形(操作, 参数, 字节)`，操作、参数 JSON 与返回值同浏览器的 `豫言_浏览器_图形`；实现在 `宿主/浏览器/图形.mjs`（共用）与 `宿主/节点/图形.mjs`（Dawn 载入与窗口呈现器），发行启动文件内联这两个模块。所有函数都可能挂起（JSPI）。

**验收**：`../图形显示节点/一致性验证/`；宿主单元测试在 `宿主/节点/图形。测试.mjs`（伪 GPU）与 `宿主/浏览器/图形。测试.mjs`（共用部分）。
