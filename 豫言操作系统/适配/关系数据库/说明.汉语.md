# 关系数据库云工适配

把公共[关系数据库接口](../../../豫言操作系统接口/关系数据库/规范.汉语.md)映射到当前 Worker 许可中的 D1 绑定：`prepare` 预备语句，`bind` 绑定已校验的 JSON 参数，`first`、`all`、`run` 取首行、全部行和变更信息，`batch` 提供原子批。适配在自己的豫言代码里校验参数类型（字符串、安全整数、布尔、null）、SQL 与结果大小上限，并把 D1 报告的错误原文交给应用；它不解释应用的 SQL，也不保存查询结果。整数经 JSON 传值，绝对值超过 2^53−1 的整数须由应用改用字符串表达。

适配用云工薄宿主的通用原语写成：「云工绑定」取 D1，「云工调」调用 `prepare` 与 `bind`（参数逐项转成云工值直接传入），「云工调候」等待 `first`、`all`、`run`、`batch`；结果行由 JS 的 `JSON.stringify` 写成 JSON 文字，`meta` 的 `changes` 与 `last_row_id` 逐项读取。D1 的错误得到「云工败」，适配以它的消息原文抛出可捕获的豫言异常。库名未获许可时「云工绑定」同样得到失败结果，适配把它转成豫言异常（消息为 `未授权的D1绑定：库名`）；规范要求的“宿主直接中止当前请求”留待后续版本。适配没有顶层可变格。
