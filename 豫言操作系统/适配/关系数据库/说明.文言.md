# 关系数据库云工适配

以当前 Worker 许可之 D1 绑定承公共[关系数据库公约](../../../豫言操作系统接口/关系数据库/规范.文言.md)：`prepare` 备句，`bind` 缚已校之 JSON 参，`first`、`all`、`run` 取首行、诸行与变更之讯，`batch` 供原子批。适配自以豫言校参之型（字符串、安全整数、布尔、null）、SQL 与果之大小，而以 D1 所报之误原文授客；不释客之 SQL，亦不藏所得。整数经 JSON 传值，绝对值逾 2^53−1 者，客当改以字符串表之。

适配书于云工薄宿主之通用原语：「云工绑定」取 D1，「云工调」呼 `prepare` 与 `bind`（参逐一化为云工值径授之），「云工调候」候 `first`、`all`、`run`、`batch`；诸行以 JS 之 `JSON.stringify` 书为 JSON 文，`meta` 之 `changes` 与 `last_row_id` 逐一读之。D1 之误得「云工败」，适配以其辞原文抛可承之豫言异。库名未许，「云工绑定」亦得败果，适配化之为豫言之异（辞为 `未授权的D1绑定：库名`）；规范所求“宿主径止此请”，留待后版。适配无顶层可变格。
