# 时间浏览器适配

`时点。豫` 于浏览器中承[时间之约](../../../豫言操作系统接口/时间/规范.文言.md)（0.2.0）：读取当前 UTC 日与 Unix 分钟、Unix 毫秒与毫秒转 ISO 文字。其义与云工适配（`../时间/`）逐字相同，接口包自身不变。`实现接口。豫` 固公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `时间.UTC日与分`、`时间.当前毫秒`、`时间.转ISO`；败则返（阴，错文），转为豫言事故。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`：以 Date.now() 与 toISOString()；毫秒之绝对值逾八点六四乘十之十五次方则发事故；UTC 之日取 ISO 文前十字，与同一毫秒所算之分钟取自同一刻。

**选用之规**：构建器于浏览器模式，先取 `适配/<能力>浏览器`；云工模式，取 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用“前端接口探针”含此接口；JSDOM 加真实 Wasm）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「浏览器宿主」之「网页能力原语」之「浏览器网页能力」（旧外调名 `豫言_浏览器_网页能力`）。宿主实此诸导入，与旧原语同。
