# 隔离运行云工适配

把公共[隔离运行接口](../../../豫言操作系统接口/隔离运行/规范.汉语.md)映射到 Cloudflare Dynamic Worker Loader。全部逻辑用豫言写在 `拓展库` 云工宿主的句柄桥之上，宿主只多一个通用原语 `豫言_云工_隔离运行客按号取`（等同已有的 `云工动态按号取`，只是子 Worker 的模块换成文件式程序的入口）。

- **参数与摘要**：豫言先检查运行器名、范围（1 至 128 字节、无控制字符）、摘要格式、程序 Base64 文字与输入的大小，用宿主的 `云工解Base64安全`（`atob`）解码程序，再用 `云工密码摘要` 重算它的 SHA-256 与传入的摘要比较，不符抛出「运行产物摘要不匹配」，Base64 非法或解码后越限抛出「运行产物无效」。
- **隔离体**：`LOADER.get(范围:摘要, …)`：同一范围与摘要的运行复用已编译的子 Worker，不同范围永不共用。子 Worker 由构建器写入 `动态资源.mjs` 的两个模块组成：`隔离运行客.mjs`（入口）与 `编译宿主.mjs`（浏览器编译器宿主的内存文件系统和 `执行模块`），外加程序 Wasm 与值桥 Wasm。无网络出站、无绑定、CPU 1000 毫秒、子请求 0。旧构建器产物缺这两个模块时，原语抛出「缺少动态 Worker 模块源码」。
- **调用**：输入的 UTF-8 字节经 `云工字节成句柄` 成为 Request 的请求体（不经 JSON 转义），向子 Worker 入口 POST；子入口解析并检查 `args` 与 `files`，运行程序，只收集 `/数据/` 与 `/响应/` 的文件（严格 UTF-8，至多 256 个、合计 1 MiB），返回 `{ok,stdout,stderr,exitCode,files}`。状态 200 时豫言原样返回响应文字；400（输入无效）与其他状态转成豫言异常「隔离运行输入无效」「隔离运行失败」；宿主拒绝也转「隔离运行失败」。用毕释放所有宿主句柄。
- **不做的事**：不编译、不保存状态、不提供网络；持久数据由调用者放进输入 `files`，再从输出 `files` 取回。

验证：云仓库的公开站点验收（`应用/豫言云工作台/验收/公开站点豫言验收.mjs`）在真实本地 workerd（Miniflare 的 `workerLoaders`）里用真实的编译产物（项目核心 Wasm）运行：摘要不符、越限、程序失败、输出文件筛选与超限、同范围复用与异范围隔离。
