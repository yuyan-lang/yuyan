# 隔离运行一致性应用

隔离运行公约之试验应用。请求体为 JSON：`{runner,scope,digest,program,input,repeat,tolerant}`（前五项为字符串，`repeat` 为整数，`tolerant` 为爻；缺则 `runner` 为 `LOADER`、`repeat` 为一、`tolerant` 为假），应用调 `运行隔离程序` 凡 `repeat` 次，而以 JSON 答：成则 `{ok:true,result,failures,lastError}`（`result` 乃末次成功之果文），首异而不容错则 `{ok:false,error,failures}`。`许可.json` 授 `LOADER` 与 `MISSING_LOADER` 二绑定之名（后者于环境中无之，以验绑定不存在之异）。构建与测试见上一级目录之说明。
