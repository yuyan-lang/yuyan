# 隔离运行一致性应用

隔离运行接口的试验应用。请求体是 JSON：`{runner,scope,digest,program,input,repeat,tolerant}`（前五项是字符串，`repeat` 是整数，`tolerant` 是爻；缺省 `runner` 为 `LOADER`、`repeat` 为 1、`tolerant` 为假），应用调用 `运行隔离程序` 共 `repeat` 次，并以 JSON 回应：成功为 `{ok:true,result,failures,lastError}`（`result` 是最后一次成功的结果文字），首个异常且未容错时为 `{ok:false,error,failures}`。`许可.json` 授权 `LOADER` 与 `MISSING_LOADER` 两个绑定名（后者不存在于环境，用来验证绑定不存在的异常）。构建与测试见上一级目录的说明。
