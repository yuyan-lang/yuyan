# 隔离运行一致性验证

于真本地 workerd 与真豫言 Wasm 验[隔离运行公约](../../../../豫言操作系统接口/隔离运行/规范.文言.md)之云工适配。

- `应用/`：试验应用 `隔离运行一致性应用`（包描述存为 `.包。豫.txt`，免为 `yy豫构` 全仓库之包发现所误；构建之本复应用之目录于暂存内之临时目录而改回原名）。以请求体之 `{runner,scope,digest,program,input,repeat,tolerant}` 付 `运行隔离程序`，报其果或异之消息；`repeat` 使同一事之内重复而运，`tolerant` 使败而不断，以验宿主句柄不漏。
- `探针/`：文件式探针程序 `隔离运行探针`，以 `yy3_bs --target=wasmgc` 现编（包描述亦存为 `.txt`）。依首命令行参数择其所为：回显请求之文而书数据、响应、他目录之文；书 N 件或 N 字节之数据文；退出码；未捕之异；标准误；出逾限；非法 UTF-8；死循环（**仅存为探针，测试不运之**，本地 workerd 不执算时之限）。
- `隔离运行.test.mjs`：Node 之测（`node:test`）十二项：文之回与筛、径之规整、程序自败乃返值、文之件数字节数与 UTF-8 之限、参违规、未授与不存在之运行器、入违规与非 Wasm、Base64 之宽容、一事之内连运千次不竭句柄（含成功与四类败）、范围之隔与并发、第二真程序（云端项目核心 Wasm）、假加载器核隔离体之标识、模块之集、算时与子请求之限、请求体逐字节相等。约九秒。

## 复验

1. 建私有暂存（符号链接语言仓之只读材料，复制编器与工具，独立编译缓存）：主代理草稿区之 `建暂存.sh <暂存目录>`。
2. 于暂存目录构建试验应用，出名 `隔离运行一致性`：`建应用.sh <暂存目录> 云工 <本目录>/应用 隔离运行一致性`。产物在 `<暂存目录>/dist/隔离运行一致性/`，其 `动态资源.mjs` 含 `隔离运行客.mjs` 与 `编译宿主.mjs`。
3. 于暂存目录运行：`node --test <本目录>/隔离运行.test.mjs`。测试以暂存中之 `yy3_bs` 现编探针（亦可以 `YY_PROBE_WASM` 指已编之探针）；Miniflare 默认取相邻云仓 `工具/包管理服务/node_modules`（`E2E_MINIFLARE` 可改）；产物根默认 `./dist`（`YY_DIST_ROOT` 可改）。第二真程序需云仓 `工具/云端项目核心/产物/yy项目核心.wasm`，无则略之。

## 实测所得平台之事

- 本地 workerd 之 Worker Loader 子工不执 `limits.cpuMs`：死循环之探针运行数分钟仍占尽算力而不返（曾因是而挂起，须依进程号止之）。云端由平台执之；本地之测故不含死循环。
- 由 `--target=wasmgc` 所编之文件式程序无宿主检点，宿主执行器之五秒墙钟限于其不行。
- 未捕之豫言异于文件式宿主表为 `illegal cast`（`ok` 为假、`exitCode` 为一）。
- 子工之出文逾限或非有效 UTF-8 者回五百，母适配转为「隔离运行失败：500：…」。
- 单事之内连运一千次（每次至少造六句柄）而成，一千次尽败亦成，可知诸途皆释句柄。
