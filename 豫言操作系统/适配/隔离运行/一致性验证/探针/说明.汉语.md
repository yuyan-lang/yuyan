# 隔离运行探针

隔离运行一致性验证用的文件式程序（`--target=wasmgc`，读写内存文件系统、标准输出与退出码）。第一个命令行参数选择行为：`echo` 读 `/请求/路径.txt` 与 `/请求/状态.txt`，写 `/数据/记录.txt`、`/响应/正文.txt`、`/响应/状态.txt`、`/其他/密.txt`、`/请求/篡改.txt` 并打印一行；`many:256`、`many:257`、`many:300` 写相应个数的数据文件；`big:1048576`、`big:1048577` 写恰这么多字节的一个数据文件；`bigout` 向标准输出打印 65537 字节；`fail` 以退出码 3 结束；`trap` 触发未捕获的豫言异常；`stderr` 写标准错误；`badutf8` 写不合法 UTF-8 的文件；`loop` 死循环（测试不运行它，本地 workerd 不强制 CPU 限额）；其他参数打印“未知命令”。包描述存为 `隔离运行探针。包。豫.txt`，测试会把本目录复制到临时目录并改回原名后编译。
