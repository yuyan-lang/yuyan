# 隔离运行云工适配

此适配以 Cloudflare Dynamic Worker Loader 实公约之[隔离运行](../../../豫言操作系统接口/隔离运行/规范.文言.md)。诸术悉以豫言书于 `拓展库` 云工宿主句柄桥之上，宿主惟增一通用原语 `豫言_云工_隔离运行客按号取`（同旧之 `云工动态按号取`，惟子工之模块易为文件式程序之入口）。

- **参与摘**：豫言先验运行器名、范围（一至一百二十八字节、无控制之字）、摘要之式、程之 Base64 文与入之大，以宿主之 `云工解Base64安全`（`atob`）解程，复以 `云工密码摘要` 重算其 SHA-256 而较传入之摘，不符则抛「运行产物摘要不匹配」，Base64 非法或解后逾限则抛「运行产物无效」。
- **隔离体**：`LOADER.get(范围:摘要, …)`：同范围同摘之运，共已编之子工；异范围永不共。子工由构建器书入 `动态资源.mjs` 之二模块成之：`隔离运行客.mjs`（入口）与 `编译宿主.mjs`（浏览器编器宿主之内存文件系与 `执行模块`），并程序 Wasm 与值桥 Wasm。无外发之网、无绑定、算时一千毫秒、子请求为零。旧构建器之产物缺此二模块者，原语抛「缺少动态 Worker 模块源码」。
- **调**：入之 UTF-8 字节经 `云工字节成句柄` 为 Request 之体（不经 JSON 转义），POST 于子工入口；子入口析而验 `args` 与 `files`，运程序，惟收 `/数据/` 与 `/响应/` 之文（严格 UTF-8，至多二百五十六件、合一 MiB），返 `{ok,stdout,stderr,exitCode,files}`。状态二百则豫言原样返其文；四百（入无效）与他状态转为豫言异「隔离运行输入无效」「隔离运行失败」；宿主拒亦转「隔离运行失败」。用毕悉释宿主句柄。
- **所不为**：不编、不存状、不供网；久存之数，客置于入之 `files`，复自出之 `files` 取之。

验：云仓之公开站点验收（`应用/豫言云工作台/验收/公开站点豫言验收.mjs`）于真本地 workerd（Miniflare 之 `workerLoaders`）以真编译之产物（项目核心 Wasm）运行：摘要不符、越限、程序败、出文之筛与逾限、同范围共用与异范围相隔。
