# 云工网页上游适配

实现网页上游接口 0.4.0（云工薄宿主）。全部用豫言写在云工薄宿主的通用原语（`库/云工宿主` 的物宿主与物）之上：请求、读取、解码、取消都直接操作平台对象（`Request`、`Response`、`ReadableStream` 的读取器、`TextDecoder`、`AbortSignal`、`TransformStream`、`URL`、`Headers`），宿主只翻译名字和值。

- 静态来源请求：先用宿主对象 `豫言授权取` 的 `已授权` 核对来源（程序许可 `OUTBOUND_ORIGINS`），未授权得失败且不发请求；再校验方法、标头、正文与时限，经 `豫言授权取` 发出（`redirect` 一律 `manual`，3xx 视为失败并取消其正文），`AbortSignal.timeout` 覆盖整次交换。方法为 GET、HEAD、POST、PATCH、PUT、DELETE；允许 GitHub API 所需的 `User-Agent` 与 `X-GitHub-Api-Version`；超时上限 18000000 毫秒；PATCH、PUT、POST 都传正文。
- 动态公网 HTTPS：`豫言授权取` 的 `已授权('https://*')` 表示程序许可是否声明了通配来源；网址逐条严格校验（可见 ASCII、`https://`、无用户信息与查询片段、主机名规则、端口白名单），以 `URL` 规范化后经宿主对象 `豫言公网取` 发出，正文按字节发送。
- 响应：`网页上游响应` 包着 Response、本次请求的中断信号与读取状态格。读取状态随响应传递，同一实例里交错执行的请求各用各的响应，互不相干。
- 增量读取：首次读取时才创建读取器；有信号时经恒等 `TransformStream` 的 `pipeThrough(…, {signal})` 接上，期满后读取失败且上游被取消。每次读一块原始字节（过大的块余部留作余字），交给流式 `TextDecoder`（去掉 BOM，非法序列成 U+FFFD，跨块拼接），再按码点边界切出不超过最大字节的文字，余文留作待出文字。有限整读先看 `Content-Length`，再循环累计，超限即取消。
- `上游转为出站响应`：以上游正文流与允许的响应头造状态 200 的 Response，用网页服务适配的 `物出站响应` 包成出站网页响应，由处理入口返回。

一致性验证见 `一致性验证/`。
