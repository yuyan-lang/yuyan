# 网页上游云端复验

上游流三适配（网页上游、授权服务、命名持久服务）于本机 wrangler dev（真 workerd）之黑盒复验，以[验收驱动](../../../../../库/考成/包说明.文言.md)书之。此包含三者共用之接线与器，及网页上游之用例；授权服务、命名持久服务之用例各在其 `一致性验证/云端复验/`，皆依此包。

- `上游流外壳.mjs`：Worker 一侧接线之壳，与产物之 `入口.mjs` 同目录。应用所发之请——全局 fetch（网页上游之静源与公网上游）、服务绑定 SVC（授权服务）、持久对象 DOS（命名持久服务）——皆转于测试所起之本机假服务（径之前缀 `/out/主机`、`/svc`、`/do`），并附原址、转址之式、有信否、对象之名诸观察之头；测试经 `/__yy/fake?base=` 以假服务之基址告外壳。外发、服务绑定、持久对象皆平台之物，以此 JavaScript 之壳接之，行为与记皆在豫言之测试。持久对象之 `/upload` 由外壳自读其请流，报块数、总字节与首末块之间隔，以核请体之为流。
- `wrangler.jsonc`：SVC 绑于本 Worker 之命名入口 `假服务`，DOS 绑于持久对象类 `假对象`；兼容之标 `enable_request_signal` 必开，中止与逾时乃达上游。
- `上游流共用。豫`：上游之记（去处、主机、对象之名、方法、路径、查询、原址、转址之式、有信否、标头、正文）；今之行为（`设上游行为` 并清其记）；断开之记（`等到上游断开`：中止或逾时达上游，假服务觉其连被闭）；`试行`、`试行成`、`跑应败`（以 POST /run 请试验应用）；报之解析（`诸报段`、`段值`、`诸块于`、`终于`、`断终于`、`断终态`）；`分块流回应`（每块之前候之，其尾 close 正终、error 中途断之、hang 不复出块）。
- `网页上游云端复验。测试。豫`：十三用例——静源之渐读、请求编号与头值之验、未授之源与旧术、逾时与读误与中止与有限之读、公网上游之合规之请、网址之规整、约七十恶意或越界之址、参违、三〇〇类不随、公网之逾时与中止、上游流转为出站之答，及云工宿主静态授权上游之写法与转址（原 `豫言操作系统/宿主/云工/一致性验证/上游请求`）。

于仓根行之：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/网页上游/一致性验/云端复验/网页上游云端复验。测试。豫 --输出 网页上游云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 网页上游云端复验.wasm
```

wrangler 次第取环境变量 `云工命令行路径`、仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；皆无则书“跳过”而以零退。产物 `dist/网页上游一致性/` 不存（或环境变量 `重建云工应用=1`），则以 `豫构 发行` 构之。CI 无 wrangler，全树测试于此目录惟验其类。
