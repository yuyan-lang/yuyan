# 网页上游云端复验

上游流三个适配（网页上游、授权服务、命名持久服务）在本机 wrangler dev（真 workerd）里的黑盒复验，用[验收驱动](../../../../../库/考成/包说明.汉语.md)写成。本包含三者共用的接线与工具，以及网页上游的用例；授权服务与命名持久服务的用例在各自的 `一致性验证/云端复验/`，依赖本包。

- `上游流外壳.mjs`：Worker 侧的接线外壳，与产物的 `入口.mjs` 放在同一目录。应用发出的请求——全局 fetch（网页上游的静态来源与公网上游）、服务绑定 SVC（授权服务）、持久对象 DOS（命名持久服务）——都转给测试起的本机假服务（路径前缀 `/out/主机`、`/svc`、`/do`），并附上原网址、转址方式、有无信号、对象名等观察用的标头；测试经 `/__yy/fake?base=` 把假服务基址告诉外壳。外发、服务绑定与持久对象都是平台对象，由这个 JavaScript 外壳接线，行为与记录都在豫言测试里。持久对象的 `/upload` 由外壳自己读请求流，回报块数、总字节与首末块的间隔，用来核对请求体是流。
- `wrangler.jsonc`：SVC 绑到本 Worker 的命名入口 `假服务`，DOS 绑到持久对象类 `假对象`；兼容标志 `enable_request_signal` 必须开启，取消与超时才能传到上游。
- `上游流共用。豫`：上游记录（去处、主机、对象名、方法、路径、查询、原网址、转址方式、有无信号、标头、正文）；当前行为（`设上游行为` 同时清空记录）；断开记录（`等到上游断开`：取消或超时传到上游时，假服务察觉连接被关）；`试行`、`试行成`、`跑应败`（向试验应用 POST /run）；报告解析（`诸报段`、`段值`、`诸块于`、`终于`、`断终于`、`断终态`）；`分块流回应`（每块前等待，末尾 close 正常结束、error 中途断开、hang 不再出块）。
- `网页上游云端复验。测试。豫`：十三个用例——静态来源的增量读取、请求编号与标头值校验、未授权来源与旧函数、超时与读取错误与取消与有限读取、公网上游的合规请求、网址规范化、约七十个恶意或越界网址、参数违规、3xx 不跟随、公网超时与取消、上游流转为出站响应，以及云工宿主静态授权上游的写入方法与重定向（原 `豫言操作系统/宿主/云工/一致性验证/上游请求`）。

在仓库根目录运行：

```sh
./yy豫构.exe 文件 豫言操作系统/适配/网页上游/一致性验/云端复验/网页上游云端复验。测试。豫 --输出 yy网页上游云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy网页上游云端复验.wasm
```

wrangler 依次取环境变量 `云工命令行路径`、仓库旁云仓的 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；没有就打印“跳过”并以零退出。产物 `dist/网页上游一致性/` 不存在（或环境变量 `重建云工应用=1`）时用 `豫构 发行` 构建。CI 没有 wrangler，全树测试对本目录只做类型检查。
