# 上游流一致性应用

试验之应用，验授权服务〇点五、网页上游〇点四、命名持久服务〇点五之带正文请、渐读、止、有限整读、动态公网 HTTPS 上游与入站请转发。惟供一致性测试。

应用以网页服务〇点二之处理入口 `处理入站网页请求` 受请（提案 C0001）：入站之请以参授之，诸径各造一出站之答，以为返值还宿主。

## 径

- `POST /run`，正文为 JSON 之述。`op`：`svc`（授权服务带正文之请）、`svcold`（旧授权服务之请，验旧柄可读）、`up`（静态来源之网页上游）、`upjson`（旧之整读 JSON）、`pub`（公网 HTTPS 上游）、`do`（命名持久服务流）、`dotext`（命名持久服务文字，返摘要）、`multi`（`mode` 取 `many`、`interleave`、`guard`、`argcheck`）。
- 通用字段：`binding`、`object`、`url`、`method`、`headers`（二元数组列）、`query`、`body`、`bodyPow`（二之幂个 a）、`bodyExtra`、`timeout`、`read`（`chunks`、`limited`、`limitedtwice`、`mixed`、`sse`、`cancel`、`gated`、`none`）、`max`、`limit`、`header`。
- `/fwd`：由请头 `x-cfg`（JSON）予转发之述，以 `转发网页请求至命名持久服务` 转入站之请于持久对象，对象之答为所返出站之答。`/svcpass`：以 `请求授权服务` 转入站之体，乃以 `授权服务原答转为出站响应` 原样返服务之答。`/uppass`：以 `上游转为出站响应` 以网页上游之体流为所返之答。`/dopass`：先流式请对象，验状态，乃以 `命名持久服务原答转为出站响应` 原样返对象之答。
