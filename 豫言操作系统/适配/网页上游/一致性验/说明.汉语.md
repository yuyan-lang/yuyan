# 上游流一致性验证（网页上游 0.4.0）

本目录验证授权服务 0.5.0、网页上游 0.4.0、命名持久服务 0.5.0 的带正文请求、增量读取与转发。三个能力包的一致性验证目录各存一份试验应用副本，便于各自独立复跑；本目录的用例侧重 `网页上游`。

## 内容

- `应用/`：试验应用 `上游流一致性应用`，依赖三个能力包与网页服务，以网页服务的处理入口 `理来书` 接收请求（提案 C0001）。`POST /run` 接受 JSON 描述（`op` 取 `svc`、`svcold`、`up`、`upjson`、`pub`、`do`、`dotext`、`multi`），`/fwd`、`/svcpass`、`/uppass`、`/dopass` 走转发与原答，各返回一个出站响应；读取结果写成不含控制字符的报告（块用 `〔〕` 括起、段用 `‖` 分隔）。内含仿 `AI市场应用/流式答复。豫` 的 SSE 增量解析（仅测试用），演示“读一个 5 帧 SSE，边读边累计字节”。应用包描述存为 `上游流一致性应用。包。豫.txt`，避免被 `豫构` 的全仓库包发现解析；`豫构 发行` 会自动改回原名再构建。
- `云端复验/`：本机 wrangler dev（真 workerd）里的黑盒复验（豫言测试包 `豫寓网溯云验`），也是三个适配共用的接线外壳、假服务与报告解析所在；网页上游的十三个用例见其[包说明](云端复验/包说明.汉语.md)。

## 复跑

在仓库根目录运行（需已构建 `豫构`；wrangler 取自仓库旁云仓的 `应用/包管理服务/node_modules`，或环境变量 `云工命令行路径`）：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/网页上游/一致性验/云端复验/网页上游云端复验。测试。豫 --输出 网页上游云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 网页上游云端复验.wasm
```

测试按需把试验应用构建到 `dist/网页上游一致性/`（环境变量 `重建云工应用=1` 时重建），在临时工作目录里起 wrangler dev，跑完即停。

## 需要注意

- 构建需要最新的接口与适配（含网页服务）；他人改动共享文档后，须先重生成各适配的 `宿主提供.json`。
- 静态来源与公网请求都经宿主对象（`豫言授权取`、`豫言公网取`）走全局 `fetch`，外壳把它们转给本机假服务；程序许可 `OUTBOUND_ORIGINS` 须含通配来源 `https://*` 才能使用公网函数。
- 云工薄宿主不设事件墙钟时限，由平台的 CPU 限额兜底。
