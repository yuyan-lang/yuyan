# 上游流一致性验证（网页上游 0.4.0）

此目录验授权服务〇点五、网页上游〇点四、命名持久服务〇点五之带正文请、渐读与转发。三能力包之一致性验证目录各存试验应用之副本，以便各自独立复行；此目录之用例重在 `网页上游`。

## 内容

- `应用/`：试验应用 `上游流一致性应用`，依三能力包及网页服务，以网页服务之处理入口 `理来书` 受请（提案 C0001）。`POST /run` 受 JSON 之述（`op` 取 `svc`、`svcold`、`up`、`upjson`、`pub`、`do`、`dotext`、`multi`），`/fwd`、`/svcpass`、`/uppass`、`/dopass` 行转发与原答，各返一出站之答；读果书为无控字之报（块以 `〔〕` 括之，段以 `‖` 分之）。内含仿 `AI市场应用/流式答复。豫` 之 SSE 渐析（惟测试用），示“读一五帧 SSE，边读边累计字节”。应用包描述存为 `上游流一致性应用。包。豫.txt`，以免被 `豫构` 之全仓库包发现所析；`豫构 发行` 自还原名而后构建。
- `云端复验/`：本机 wrangler dev（真 workerd）之黑盒复验（豫言测试包 `豫寓网溯云验`），亦三适配共用之接线外壳、假服务与报之解析所在；网页上游之十三用例见其[包说明](云端复验/包说明.文言.md)。

## 复行

于仓根行之（须已成 `豫构`；wrangler 取自仓旁云仓之 `应用/包管理服务/node_modules`，或环境变量 `云工命令行路径`）：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/网页上游/一致性验证/云端复验/网页上游云端复验。测试。豫 --输出 网页上游云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 网页上游云端复验.wasm
```

测试随需构试验应用于 `dist/网页上游一致性/`（环境变量 `重建云工应用=1` 则重构），于暂存之工作目录起 wrangler dev，毕即止之。

## 须知

- 构建须最新之接口与适配（含网页服务）；他人改共享文档后，须先重生各适配之 `宿主提供.json`。
- 静源与公网之请皆经宿主之物（`豫言授权取`、`豫言公网取`）行于全局 `fetch`，外壳转之于本机假服务；程序许可 `OUTBOUND_ORIGINS` 必含通配来源 `https://*` 方可用公网术。
- 云工薄宿主不设事之墙钟时限，以平台之 CPU 限额为底。
