# 文字规整云工适配

四术皆以薄宿主之通用原语（`库/云工宿主` 之「物宿主」与「物」）呼 JS：入文为文值授宿主，宿主以 `TextDecoder`（`ignoreBOM: true`，文首之 U+FEFF 不失）还为 JS 字符串，复以全局 `String` 造其包装之物，于其上呼 `trim`、`toLowerCase`，读 `length`；`全为字母或数字吗`（二版新增）另以全局 `RegExp` 造 `/^[\p{L}\p{N}]+$/u` 而呼 `test`。果文由宿主以 `TextEncoder` 编为 UTF-8 而交回，全程不经 JSON，故控制之字、引号、反斜线、U+2028 及 BOM 皆精确往返。宿主之物付诸回收，单事之内可屡呼。入文一 MiB 之限，由适配于授宿主之前验之。云工宿主与诺节应用宿主同以物桥行此诸原语，故此适配两处皆可行。

真本地 workerd 实测：`去首尾空白`、`转小写`、`UTF16长度` 之果与 Node 同（皆 V8 也）。综合之场见 `../消息队列/一致性验证/真实工作者/`。
