# 文字规整云工适配

四个函数都经薄宿主的通用原语（`库/云工宿主` 的「物宿主」与「物」）调用 JS：输入字符串作为文值交给宿主，宿主用 `TextDecoder`（`ignoreBOM: true`，文首的 U+FEFF 不丢）还原成 JS 字符串，再以全局 `String` 造包装对象，在它上面调 `trim`、`toLowerCase`，读 `length`；`全为字母或数字吗`（0.2.0 新增）另以全局 `RegExp` 造 `/^[\p{L}\p{N}]+$/u` 并调用 `test`。结果字符串由宿主用 `TextEncoder` 编成 UTF-8 交回，全程不经 JSON，所以控制字符、引号、反斜线、U+2028 与 BOM 都精确往返。宿主对象由垃圾回收释放，单个事件内可以调用任意多次。输入上限 1 MiB 由适配在交给宿主之前检查。云工宿主与诺节应用宿主用同一份物桥实现这些原语，所以本适配在两边都能运行。

真实本地 workerd 实测：`去首尾空白`、`转小写`、`UTF16长度` 的结果与 Node 一致（同为 V8）。综合场景见 `../消息队列/一致性验证/真实工作者/`。

`一致性验证/` 里有试验应用、真实 Wasm 的 Node 测试（含全部 Unicode 码点分块对拍）和复跑说明。
