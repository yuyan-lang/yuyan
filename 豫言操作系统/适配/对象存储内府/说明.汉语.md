# 豫寓府库内府榫（对象存储内府适配）

通称对象存储内府适配（own object storage adapter）。这是豫寓榫卯「豫寓府库」（对象存储接口 0.5.0）的一套实现：把接口的调用转成对内府台（自己的对象存储服务）的请求。

## 已接上的函数

- `取物元数据`：对象不存在返回 `null`，存在返回元数据的结绳文字。
- `读物文字`：对象不存在返回 `null`；对象比上限大返回 `{"tooLarge":true,"size":n}`；否则严格按 UTF-8 解码，返回 `{"text":…,"size":…,"httpEtag":…,"customMetadata":…}`。
- `读物字节`：不存在得（阴，空帛）；超上限抛异常。
- `写物`、`写物文字`：支持无条件、唯无（`ifNoneMatch`）与符同（`ifMatch`）三种条件，以及 `sha256` 摘要校验（由内府台核，不符报 `did not match` 且不留对象）；返回 `written`、`size`、`etag`、`httpEtag` 或 `{"written":false}`。
- `删物`：一批至多一千个键，一个不合规就整批报错、一个也不删。
- `列举物`：前缀、一页条数、续标、分隔与 `include`（只接受 `["customMetadata"]`）。

## 暂不支持的函数

直通出站响应（`物藏物作回书`）、入站正文写入（`来正文写物`）与分段写物四步这一步报中文事故「内府适配暂不支持：…」，留待提案 00064 第三步。

## 配置

连接设置从金匮根下的 `内府。数据。豫` 读（九府的择库把它设在九府的数据目录下）：

```yuyan
「内府」者 「典」
　【「地址」者『127.0.0.1:9091』也
　，「虎符」者『虎符』也
　，「超时」者「三零零零零」也
　】
也。
```

- `地址们`（可选）：内府台的 `主机:端口` 列，三副本时写三台的地址。给了它多于一條时，适配逐个试；拿到「非主」就改连所附盟主的地址；连不上、等不到答复，或答「非主」而不知盟主（正在选举），就轮下一个。每次重试前按退避歇一下（一百毫秒起翻倍，至多两秒），至多十二次，超过报“内府台没有可用的盟主”。同一地址上连接还在就复用，只有换地址时才重开连接。
- `地址`（单机必填）：内府台的 `主机:端口`；没写 `地址们` 时用它。
- `虎符`（必填）：虎符文件的路径；相对路径按金匮根算。虎符的内容只从文件读，不进配置与日志。
- `超时`（可选）：一次等待的毫秒上限，缺省三万。

改了这份文件，下一次调用就按新设置重连。多台时改连之后会把盟主的地址挪到列首并记住，下一次先找它。

### 非主与重试

连到不是盟主的台时，内府台答「非主」并附所知盟主的地址。适配收到之后改连那个地址，同一个请求重发；连不上就轮下一个地址。选举期间各台都不知盟主，答「非主」而不附地址，适配照样退避着轮下去，等新盟主选出。重试有上限（十二次，合计约十七秒），超过就把末一次的缘由抛成中文事故。

一条写如果已经可能生效（例如上次等待超时、其实已经成了），重发这一条条件写会得到“冲突”：这是诚实的答，按接口约定重试条件写本来就会这样。适配不做去重。

## 与别处的关系

内府台在 `应用/百工坊/内府台`，库在 `库/内府`（券、客、合符）。九府的择库多认一个库类「内府」，用 `库/九府/内府库。豫` 把这五个函数扎成守藏的库术。

## 限额

- 桶名是 `桶名` 抽象类型，由 `验桶名` 从文字构造（一至六十四字节，首字半角字母或下划线，其余半角字母、数字或下划线）；适配用 `桶名之文` 取回原文字。
- 键一至一千零二十四字节，不含控制字符，不以斜杠开头。
- 写入正文至多十六兆字节；读文字的字节上限一至二兆；读字节的上限一至十六兆。
- 删物一批至多一千键；列举一页至多一千项。
