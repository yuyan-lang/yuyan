# 网址定位浏览器适配

`定位。豫` 在浏览器里实现[网址定位接口](../../../豫言操作系统接口/网址定位/规范.汉语.md)（0.2.0）：按 URL 标准解析绝对与相对网址的部件。语义与云工适配（`../网址定位/`）逐字相同，接口包本身不变。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `定位.绝对`、`定位.根`；失败以（阴，错误文）返回，再转成豫言事故。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`：`new URL`：输入超过 64 KiB 视为无效；失败消息与云工适配相同（“网址不是有效的绝对网址”等）。

**选用规则**：构建器在浏览器模式下优先选用 `适配/<能力>浏览器`，云工模式选 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用 `前端接口探针` 含本接口；JSDOM＋真实 Wasm）。
