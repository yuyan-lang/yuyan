# 网址定位浏览器适配

`定位。豫` 于浏览器中承[网址定位之约](../../../豫言操作系统接口/网址定位/规范.文言.md)（0.2.0）：按 URL 标准解析绝对与相对网址的部件。其义与云工适配（`../网址定位/`）逐字相同，接口包自身不变。`实现接口。豫` 固公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `定位.绝对`、`定位.根`；败则返（阴，错文），转为豫言事故。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`：以 new URL：输入逾六十四 KiB 视为无效；败辞与云工适配相同（“网址不是有效的绝对网址”等）。

**选用之规**：构建器于浏览器模式，先取 `适配/<能力>浏览器`；云工模式，取 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用“前端接口探针”含此接口；JSDOM 加真实 Wasm）。
