# 张量计算网页适配一致性验证

此目验[张量计算接口](../../../../豫言操作系统接口/张量计算/规范.文言.md)之浏览器与云工之适配（`../`）。

**所含**

- `应用/张量探针/`：探针之应用，独立之验收之包「张量探针应用」（可执行之类，登于父包「豫言操作系统适配」之下，惟依接口之包；自有包述，故不为适配包「豫言操作系统张量计算适配」之源，适配包可独检、独验其类）。诸例抄自诺节一致之应用（`豫言操作系统/宿主/节点/一致性验证/应用`）之张量之部，除张量文件；每例书一行“类·项：果”，终书“张量探针完成”。`期望输出.txt` 即诺节期望中张量诸行加此一行，故网页宿主与诺节宿主之果逐字同。
- 探针又终书一行“张量·多线程校验：……”：较大之矩阵乘（分块与矩阵乘向量）、软最大、按轴求和、解码式之注意（行分段注意与合并，含问头倍于键头之一例）与正态随机之填，诸果之字之散列。其随中央张量内核之数值之实而变，不入期望；单线与多线、浏览器与云工所得此行当逐字同。
- 测试之页：`豫言操作系统/宿主/浏览器/张量。测试页.html`（非豫言之码依规置于宿主之目），书探针所出于 `#结果`，毕又书一行“跨源隔离：是/否，工作线程 N 个，……”，`<html>` 带 `data-探针="完成"`。本机之服：`豫言操作系统/宿主/浏览器/张量。测试服务.mjs`，带 `--隔离` 则诸应皆附 COOP/COEP 之头，页遂跨源隔离，中央张量之宿主用共享之存与 Web Worker 多线。
- `张量云工.test.mjs`：诺节之测，载云工构建之产物 `宿主.mjs`、`程序.wasm`、`值桥.wasm` 与 `中央张量内核.wasm`，以定时之事行探针，至“张量探针完成”与期望逐行同，并书多线之校一行；又测产物无内核之模则取境返资源暂不可用。全树之测登为略（须先构建产物）。

**复行**（于构建之根，即语言仓之根；须已构建 `yy双宿主构建`、`yy4_bs`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；勿与他构并行）

```sh
# 1. 构建二产物（自动之式为张量计算取 适配/张量计算，基础取 适配/基础浏览器 或 适配/基础云工；适配所依之库 张量后端、张量内核 自并入；中央张量内核之模由构建器另编）
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 豫言操作系统/适配/张量计算/一致性验证/应用/张量探针 dist/张量探针
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 云工 豫言操作系统/适配/张量计算/一致性验证/应用/张量探针 dist/张量探针云工
# 2. 云工：诺节所拟之云工宿主
node --test 豫言操作系统/适配/张量计算/一致性验证/张量云工.test.mjs
# 3. 浏览器：二本机之服（常与跨源隔离），无头 Chrome 各行一遍；?等待=15000 令页插一迟十五秒之图以止 load 之事，--dump-dom 俟探针毕乃出
node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs dist/张量探针 18771 &
node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs dist/张量探针 18772 --隔离 &
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --user-data-dir=/tmp/豫言张量单 \
  --dump-dom "http://127.0.0.1:18771/张量。测试页.html?等待=15000" > 张量探针单线程.html
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --user-data-dir=/tmp/豫言张量隔 \
  --dump-dom "http://127.0.0.1:18772/张量。测试页.html?等待=15000" > 张量探针多线程.html
```

- 二页之 `<pre id="结果">` 至“张量探针完成”皆当与 `应用/张量探针/期望输出.txt` 逐行同；“张量·多线程校验”一行，二页与云工之测所书当逐字同；末行单线之页为“跨源隔离：否，工作线程 0 个”，多线之页为“跨源隔离：是，工作线程 N 个”（N 为硬件线程数减一，至多十五）。
- 此 Chrome 出页之后或不自退：输出之文见 `</html>` 则止之可也。

**所记**：2026-09-30 于 Apple M5 Pro（十八硬件线程）、Chrome 154 与诺节 26.3：二页与云工之测前四十四行皆与期望逐行同，多线之校一行三者同（多线之页起十五工作线程）；探针全程单线约零点二秒、多线亦约零点二秒（诸例甚小，多线不省时）。
