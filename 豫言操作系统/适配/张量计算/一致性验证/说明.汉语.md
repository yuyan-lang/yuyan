# 张量计算网页适配一致性验证

本目录验证[张量计算接口](../../../../豫寓榫卯/张量计算/规范.汉语.md)的浏览器与云工适配（`../`）。

**内容**

- `应用/张量探针/`：探针应用，独立的验收程序包「张量探针应用」（可执行文件类型，登记在父包「豫寓榫榫」之下，只依赖接口包；它有自己的包描述，所以不会被当成适配包「豫寓算阵榫」的源码，适配包可以单独检查与类型检查）。用例抄自诺驿一致性应用（`豫言操作系统/宿主/节点/一致性验证/应用`）的张量部分，不含张量文件；每个用例打印一行“类·项：结果”，然后打印“张量探针完成”。`期望输出.txt` 就是诺驿期望输出里的张量各行加上这一行，所以网页宿主与诺驿宿主的结果逐字相同。
- 探针最后还打印一行“张量·多线程校验：……”：较大的矩阵乘（分块与矩阵乘向量）、软最大、按轴求和、解码式注意力（走分段注意力与合并，含问头数是键头数两倍的一例）与正态随机填充，各结果字节的散列。它随中央张量内核的数值实现而变，不写进期望输出；单线程与多线程、浏览器与云工运行得到的这一行应逐字相同。
- 测试页：`豫言操作系统/宿主/浏览器/张量。测试页.html`（非豫言代码按规定放在宿主目录），把探针的输出写进 `#结果`，结束后再写一行“跨源隔离：是/否，工作线程 N 个，……”，`<html>` 带 `data-探针="完成"`。本机服务：`豫言操作系统/宿主/浏览器/张量。测试服务.mjs`，带 `--隔离` 时每个响应都带 COOP/COEP 头，页面因而跨源隔离，中央张量宿主用共享内存与 Web Worker 多线程。

**复跑**（在构建根，即语言仓根目录；需已构建 `豫构`；勿与别的构建并发）

```sh
# 1. 构建产物（自动模式为张量计算选用 适配/张量计算，基础选用 适配/基础浏览器 或 适配/基础云工；适配依赖的库 张量后端、张量内核 自动并入；中央张量内核模块由构建器另编）
./豫构。林檎。豫行 发行 浏览器 豫言操作系统/适配/张量计算/一致性验证/应用/张量探针 dist/张量探针
# 2. 浏览器：两个本机服务（普通与跨源隔离），无头 Chrome 各跑一遍；?等待=15000 让测试页插入一张延迟 15 秒的图片拖住 load 事件，--dump-dom 在探针结束后才导出
node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs dist/张量探针 18771 &
node 豫言操作系统/宿主/浏览器/张量。测试服务.mjs dist/张量探针 18772 --隔离 &
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --user-data-dir=/tmp/豫言张量单 \
  --dump-dom "http://127.0.0.1:18771/张量。测试页.html?等待=15000" > 张量探针单线程.html
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --user-data-dir=/tmp/豫言张量隔 \
  --dump-dom "http://127.0.0.1:18772/张量。测试页.html?等待=15000" > 张量探针多线程.html
```

- 两份页面的 `<pre id="结果">` 到“张量探针完成”为止都应与 `应用/张量探针/期望输出.txt` 逐行相同；“张量·多线程校验”一行两份页面应逐字相同；最后一行单线程页面为“跨源隔离：否，工作线程 0 个”，多线程页面为“跨源隔离：是，工作线程 N 个”（N 为硬件线程数减一，至多 15）。
- 这台 Chrome 导出页面后进程可能不退出：输出文件出现 `</html>` 后结束它即可。

**记录**：2026-09-30 在 Apple M5 Pro（18 个硬件线程）、Chrome 154 与诺驿 26.3 上：两份页面与云工测试的前 44 行都与期望输出逐行相同，多线程校验一行三者相同（多线程页面起了 15 个工作线程）；探针全程单线程约 0.2 秒、多线程约 0.2 秒（用例很小，多线程省不下时间）。
