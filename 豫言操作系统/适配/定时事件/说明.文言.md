# 定时事件云工适配

云工宿主以〔0，控制器，上下文〕呼入口 `处理定时事件`：`定时事件` 之构造器 `云工定时事件` 裹 `scheduled` 事之控制器与上下文，皆资「云工物」。`读取定时事件文` 读控制器之 `cron` 与 `scheduledTime`：`cron` 须为串；`scheduledTime` 须为非负之安全整数（余若负数、小数、非数、逾安全整数之数、串、undefined，皆无效之刻）；合则造 `{cron, scheduledTime}` 之物，由平台 `JSON.stringify` 书之，整数之刻不经豫言之浮点。适配惟用云工薄宿主之通用原语，不露控制器，亦不行 `noRetry`，不存任何态，无顶层可变之格。

事之寿，云工宿主保之：`scheduled` 处理器所返 Promise 待入口返乃成，故客之异步书写皆在此一调用之内；入口抛未捕之异，则其 Promise 被拒，平台记为败。

真本地 workerd 实测：经 `/cdn-cgi/handler/scheduled?cron=…&time=毫秒` 而发，`cron` 与 `scheduledTime`（毫秒整数）原样达于豫言；不带 `time` 则 `scheduledTime` 为当下之毫秒；事内 KV 之异步书写，于调用终前已成。综合之场见 `../消息队列/一致性验证/真实工作者/`。
