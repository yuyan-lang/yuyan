# 持久告警落盘适配

持久对象的告警：每个对象至多一个，落在它持久仓的保留键 `::告警` 里，重启后仍在。供豫言系统与原生宿主上的服务程序使用。

## 语义

- `读恒告警 仓`：键不存在或值为 `null` 时（阴，零）；否则（阳，绝对毫秒）。
- `设恒告警 仓 毫秒`：时刻须在 0 至 8640000000000000 之间，越界报 `持久告警时刻须在 0 至 8640000000000000 之间`；已有告警被替换。
- `删恒告警 仓`：把键写成 `null`（视为未设置）；本来没有也无事。
- 告警事件由服务程序在到点时用 `造恒告警事 仓 已重试次数` 造出；应用入口里用 `告警恒仓 事` 取仓、`读告警重试次数 事` 取次数。
- 入参的 `仓` 可以是对象的持久仓，也可以是事务里的 `事务恒仓`：那时告警的设置与删除随事务提交或回滚（持久事务适配的草稿机制管这些写入）。

## 用法

```yuyan
寻观「豫寓恒警金匮榫」之「告警」之书。

「设恒告警」于「仓」于「一七五八八零一六零零零零零」。
「读恒告警」于「仓」。
```

## 待办事项

- 告警到点的调度、失败重试与退避由服务程序的定时器负责；适配只读写那颗键。
- 单对象多告警、周期告警都不提供（规范如此）。
