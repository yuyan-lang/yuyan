# 持久告警落盘适配

持久之户之告警：一物至多一警，落于其仓之留键 `::告警`，重启而在。供豫言系统与本土之宿主用。

## 语义

- `读恒告警 仓`：键不存或值为 `null` 则（阴，零）；否则（阳，绝对毫秒）。
- `设恒告警 仓 毫`：刻须在零至八兆六千四百亿之间，越度者告祸；旧警见代。
- `删恒告警 仓`：书键为 `null`（视为未设）；本无亦无事。
- 告警之事由服务之程于到点时以 `造恒告警事 仓 已试之次` 造之；应用之口以 `告警恒仓 事` 取仓、`读告警重试次数 事` 取次。
- 所授之 `仓` 可为物之仓，亦可为契中之 `事务恒仓`：其时设删随契成撤。

## 用法

```yuyan
寻观「豫寓恒警金匮榫」之「告警」之书。

「设恒告警」于「仓」于「一七五八八零一六零零零零零」。
「读恒告警」于「仓」。
```

## 后续之事项

- 到点之调、败而重试与退避由服务之程之漏刻任之；此适惟读写其一键。
- 一物多警、周期之警皆不为（规如此）。
