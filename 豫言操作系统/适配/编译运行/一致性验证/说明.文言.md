# 编译运行一致性验证

于真豫言 Wasm、真宿主运行器、真豫言编器与标准库之资，分别于 Node 进程内与本地 workerd（Miniflare）验[编译运行公约](../../../../豫言操作系统接口/编译运行/规范.文言.md)之云工适配。

- `应用/`：试验应用 `编译运行一致性应用`（包描述存为 `.包。豫.txt`，以免为 `yy豫构` 之全仓包发现误认为包；`yy双宿主构建 --自动` 复应用目录于构建根内之临时目录（`dist/.自动构建/<输出名>/应用`）而改回原名）。其于**同一事之内**依脚本逐步调公约之五术，返各步之果（详见 `应用/入口。豫` 之注）：一 HTTP 请求一段脚本，盖运行号惟启之之事有效，Worker 亦不许一请求所启之编续于他请求也。
- `编译运行一致性.test.mjs`：`node:test`，凡三十二项：
  - **两境各行同一组十二景**：全流程（事序与标、终止之事恰一、`artifact` 之式与摘、产物字节与 Base64 一致、出之逐字拼接、取尽后状态二、结束后失效与重复结束）、产物可行（以浏览器编器宿主隔离而行，出“你好，多文件”）、编败乃返值（`finished` 而 `ok` 为假、无 `artifact`、有 `diagnostic`、读产物抛异）、请求违规十四类与超大请求文与编译器名三类、运与运之间不遗用户之文、同一项目两次编译产物逐字节同、指定入口与 `entry` 为 null、近单文件限额之源、两运交错而读、等待毫秒与运行号之验、运行号跨事无效、多事并发各编各的。
  - **Node 进程内专属二项**：未授与不存之绑定使事失败（宿主之误）、尽结束后无残留之运。
  - **运行器级六项（Node 内，径调运行器）**：同一运至多一候者而结束使候者得状态二、候满得状态一后仍能取后续之事、未终之运并发上限八、既结束未始之运不复编、既终之运不占并发之额而至多留三十二、宿主之故乃 `failed` 事。
  约二十一秒。

## 复行

于构建根行之（语言仓根本身即可，须已成 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖之解见[双宿主构建说明](../../../../工具/双宿主构建/说明.文言.md)）。编译缓存以编译器可执行文件之修改时间为准，数构建同用一编译器则共其缓存，勿并行。

1. 构建试验应用，输出名 `编译运行一致性`：`./yy双宿主构建 --自动 云工 <本目录>/应用 dist/编译运行一致性`。若接口目录根下之公共 `.md` 有变而宿主提供清单未重生成，须先重生成相关清单。
2. 于构建根行：`node --test --test-force-exit <本目录>/编译运行一致性.test.mjs`（Node 二十六以上，需 JSPI）。所需资源默认取邻云仓 `../yuyan-cloud`：`工具/云端编译服务/` 之 `资源/编译器.wasm`、`资源/值桥接.wasm`、`资源/标准库.json.gz`、`组装器.mjs`（及其 `资源/组装器.wasm`），`应用/豫言体验/node_modules/binaryen`（Node 进程内用），`工具/包管理服务/node_modules/miniflare`（workerd 用）。环境变量 `YY_DIST_ROOT`（产物之根，默认 `./dist`）、`YY_CLOUD_ROOT`、`YY_BINARYEN`、`E2E_MINIFLARE` 可改其径；缺任一项则测试立报而指之。
3. workerd 之部自装一与云仓 `编译外壳.mjs` 同构之外壳（产物、运行器、编资置于临时目录树），标准库之资经服务绑定之替身以供。

## 实测所得之平台事实

- Worker 运行时不许一请求所启之异步工作（定时器）续于他请求：此乃“运行号惟启之之事有效”之所由来，亦本验证置每景于同一事内之故。
- 同一编（同一项目、同一编器与标准库）于 Node 与本地 workerd 中产物逐字节同（确定）。
- 编器 Wasm 同步而行，独占 isolate；宿主不让出事件循环，故事待编毕方能送出（旧云桥之“流式”亦然）。
