# 对象存储云工适配

以当前 Worker 许可中之 R2 绑定承公共[对象存储公约](../../../豫言操作系统接口/对象存储/规范.文言.md)（`许可.json` 例：`{"R2":["PACKAGES"]}`，桶名由客授），悉以豫言书于云工薄宿主通用原语之上：`云工绑定('R2', 桶名)` 取桶之物，`云工调候` 呼 R2 之法而候之，`云工取` 读其属，`全局造` 造 `Headers`、`TextDecoder`、`Response`。R2 所返之物，以资「云工物」径执之，存亡付垃圾回收。

| 公约之术 | R2 之召 |
| --- | --- |
| `取对象元数据` | `head(键)`，读 `size`、`etag`、`httpEtag`、`uploaded`（Date 以 `getTime` 取之）、`httpMetadata`、`customMetadata` |
| `读取对象文字` | `get(键)`；`size` 逾上限则不读正文；否则 `arrayBuffer()` 后以 `new TextDecoder('utf-8', {fatal: true, ignoreBOM: true})` 严解 |
| `读取对象字节` | `get(键)`；`size` 逾上限则不读正文而抛异；否则 `arrayBuffer()` 之果由宿主径复为字节串（不经 JSON） |
| `写入对象`、`写入对象文字` | `put(键, Uint8Array, {onlyIf: Headers, sha256, httpMetadata, customMetadata})`；返 `null` 即前提不合 |
| `删除对象` | `delete([键…])` |
| `列举对象` | `list({limit, prefix, cursor, delimiter, include})` |
| `对象存储对象转为出站响应` | 依入站请之法择之：GET 诸法用 `get(键)`，以 `body` 流置 `new Response(body, {status, headers})`；入站之 Request 以网页服务适配之 `入站请求物` 取之，答以 `物出站响应` 裹为出站之答而返；HEAD 用 `head(键)` 与无体之 Response；对象无则返阴与 `new Response(null, {status: 404})` |

要点：

- **JSON 字面由 JS 书之**：对象之键、`etag`、`httpEtag`、`customMetadata`、正文文字、列举之续标与 `delimitedPrefixes`，皆以 JS 之 `JSON.stringify` 书为字面，控制字符之转义与大文之速皆由 JS 保之；整数（大小、毫秒）与 `httpMetadata` 之五字符串字段逐一读之。`读取对象文字` 之限取二 MiB：控制字符最坏膨胀六倍，约十二 MiB。
- **条件写用真 `Headers`**：本地 workerd 探之，`onlyIf` 必为 `Headers` 乃效（纯对象则 R2 静默忽之而照覆），故适配以 `全局造('Headers')` 造 `If-None-Match: *` 或 `If-Match: "etag"`，设于 `put` 选项物之 `onlyIf`；余选项书为 JSON，经 `JSON.parse` 成常物。
- **`list` 之果为纯对象，其 `objects` 之元乃 `R2Object` 类实例**；未截断时 `cursor` 键在而值为 `undefined`，适配惟于 `truncated` 为真时取续标。含 `include` 时本地 R2 每页约百项，客当循 `cursor` 续列。
- **校在豫言**：桶名、键、选项 JSON（未知字段、型、互斥、长、保留名）、标头名与值、状；违者抛豫言之异。平台之故得「云工败」，适配以其辞原文抛豫言之异（如 R2 错码之文）。
- **直通之体留于 JS**：GET 之径惟读 `size`、`httpEtag`、`body`，正文流径授 Response；试验于六十四 MiB 之对象断言 `arrayBuffer/text/bytes/json/blob` 一次未召。
- **部署之误**：桶名不在许可，或许而未绑，「云工绑定」得败果，适配化之为豫言之异（辞为 `未授权的R2绑定：桶名` 或 `绑定不存在：桶名`）。规范所求“宿主径止此运行”，留待后版。
- **诸请无共态**：适配无顶层可变格，同一实例中交错之诸请不相扰。

验：同一试验于 Node（云工薄宿主，R2 为形取自真 workerd 之类实例仿造）与 `wrangler 4.129.0` 之本地 workerd（真 R2 绑定，本地存储）皆过，见 `一致性验证/`。平台所察：`sha256` 不合之辞含 `(10037)`；键逾一零二四字节为 `(10020)`；`list` 之 `limit` 逾一千为 `(10022)`；本地 R2 先验摘要而后判前提；可压缩之类而客户端受 gzip 时，workerd 改用分块传输而不存 `Content-Length`。
