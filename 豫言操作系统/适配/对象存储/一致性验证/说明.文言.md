# 对象存储一致性验证

此目录验[对象存储公约](../../../../豫言操作系统接口/对象存储/规范.文言.md)之云工适配：试验客在 `应用/`（免为全库所发现，包描述存为 `对象存储一致性应用。包。豫.txt`，构建时复其原名 `对象存储一致性应用。包。豫`；`许可.json` 授 `{"R2":["PACKAGES","SPARE"]}`），Node 试验为 `对象存储一致性.test.mjs`，R2 仿造器为 `模拟R2.mjs`。

仿造器乃 R2 绑定之**类实例**（宿主桥惟于非纯对象发柄）：`head` 与 `put` 返 `HeadResult`，`get` 返带 `body` 流之 `GetResult`，`uploaded` 为 `Date`，`checksums` 有 `toJSON`，`list` 返纯对象（未截断时 `cursor` 键在而值为 `undefined`），`put` 之 `onlyIf` 惟认真 `Headers`（纯对象静默忽之）、先验摘要而后判条件，错辞与错码（10037、10020、10022）取自真 workerd 之探；另有故障之注与召用之记，以断言“直通不整读正文”“tooLarge 不读正文”“非法键不召平台”。

试验所覆：元；读文（多字节、BOM、非法 UTF-8、二 MiB 之边、控制字符最坏之膨胀）；写（条件写四果、sha256 合与不合、选项之校、十六 MiB 之边）；删（一千之限、列空、非法键则整批拒）；列（前缀、分页、`delimiter`、`include`、一千零一对象）；直通（GET、HEAD、无对象、六十四 MiB 之大对象、附加标头与状之校）；桶之隔；许可外之桶名；同一事内六千次取元之柄释。

## 以私有暂存复跑

一、建私有暂存：`建暂存.sh <暂存目录>`。
二、构建试验客：`cd <暂存目录> && 建应用.sh <暂存目录> 云工 <此目录>/应用 对象存储一致性`，产物在 `<暂存目录>/dist/对象存储一致性/`。
三、行试验（Node 载真 Wasm，桶为仿造器）：`env 产物目录=<暂存目录>/dist/对象存储一致性 node --test 对象存储一致性.test.mjs`。

## 于本地 workerd（真 R2 绑定）复跑

复 `dist/对象存储一致性/` 于空目录，去 `程序.wasm.wat`，补内容为 `{}` 之 `执行配置.json`，另置 `wrangler.jsonc`：`{"name":"对象存储检查","main":"入口.mjs","compatibility_date":"2026-09-04","r2_buckets":[{"binding":"PACKAGES","bucket_name":"pk"},{"binding":"SPARE","bucket_name":"spare"}]}`；`wrangler dev --local --port <端口>` 起后：`env 远端地址=http://localhost:<端口> node --test 对象存储一致性.test.mjs`。此时桶为真本地 R2，赖仿造器之用例（故障注入、召用记录、控制字符键、六十四 MiB 直通）自跳，余者于 wrangler 4.129.0 全过。试验以运行号为键之前缀，且于每例末清理，可复行。
