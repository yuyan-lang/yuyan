# 随机数浏览器适配

`生成。豫` 于浏览器中承[随机数之约](../../../豫言操作系统接口/随机数/规范.文言.md)（0.1.0）：随机十六进制文字与 UUID v4。其义与云工适配（`../随机数/`）逐字相同，接口包自身不变。`实现接口。豫` 固公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `随机.十六进制`、`随机.通用标识`；败则返（阴，错文），转为豫言事故。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`：以 crypto.getRandomValues 与 crypto.randomUUID；非安全上下文（如 http 之非 localhost 页）无 randomUUID，则宿主依 RFC 4122 以随机字节自组之。

**选用之规**：构建器于浏览器模式，先取 `适配/<能力>浏览器`；云工模式，取 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用“前端接口探针”含此接口；JSDOM 加真实 Wasm）。
