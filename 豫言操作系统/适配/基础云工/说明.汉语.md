# 基础接口云工适配

云工宿主（`豫言操作系统/宿主/云工/`）的[基础接口](../../../豫言操作系统接口/基础/规范.汉语.md)适配。基础接口有诊断、时钟、错误三个模块，本适配按模块分成三个同名文件，由 `yy豫言操作系统绑定` 一次绑定三个模块。依赖基础的接口（如张量计算）在云工上用本适配取得同一个 `系统错误` 类型；双宿主构建在云工模式下遇到依赖基础的接口时选用本目录（目录 `../基础/` 是早先的过渡适配包，没有这三个模块）。

- `诊断。豫`：`记录诊断` 交给宿主的标准错误输出；云工宿主把它交给创建宿主时传入的输出函数。
- `时钟。豫`：`读取单调微秒` 由宿主的单调纳秒读数（`performance.now()`）换算为整数微秒，同一事件内不倒退，起点不代表日历时刻（Workers 的时钟只在 I/O 之后前进）。
- `错误。豫`：`系统错误` 及其构造器逐字照抄规范。

三个文件与浏览器适配 `../基础浏览器/` 逐字相同，只用值桥内建的宿主原语 `豫言_标准错误打印行` 与 `豫言_获取当前纳秒时间`，没有新增宿主原语。宿主支持清单是 `宿主提供.json`，由接口检查器从规范生成，接口规范改动后须重新生成。验收随张量探针进行，见 `../张量计算/一致性验证/`。
