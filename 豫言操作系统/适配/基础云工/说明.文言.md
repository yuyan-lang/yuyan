# 基础接口云工适配

此为云工宿主（`豫言操作系统/宿主/云工/`）之[基础接口](../../../豫言操作系统接口/基础/规范.文言.md)适配。基础有诊断、时钟、错误三模，此适配分为三文，名与模同，`yy豫言操作系统绑定` 一次并绑之。依基础之接口（若张量计算）于云工以此取同一 `系统错误` 之类；双宿主构建于云工之式，遇依基础之接口则取此目（`../基础/` 乃昔之过渡适配，无此三模）。

- `诊断。豫`：`记录诊断` 交宿主之标准误；云工宿主付之于建宿主时所授之输出函数。
- `时钟。豫`：`读取单调微秒` 取宿主单调之纳秒（`performance.now()`），化为整微秒；同事件不倒退，原点不作历日（Workers 之钟惟于 I/O 之后乃进）。
- `错误。豫`：`系统错误` 及其构造，一依规范之文。

三文与浏览器之适配 `../基础浏览器/` 逐字同，惟用值桥内建之宿主原语 `豫言_标准错误打印行` 与 `豫言_获取当前纳秒时间`，不增新原语。宿主支持之簿为 `宿主提供.json`，接口检查器自规范生之；规范有改，须复生之。验收随张量探针而行，见 `../张量计算/一致性验证/`。
