# 网页服务云工之适配

于云工薄宿主成 `豫言操作系统网页服务` 〇点二（提案 C0001），含原网页入站、网页答复、网页转发三包所并之诸术。适配惟用云工宿主库之通用原语（`物宿主`、`物`、`回调` 三模）：入站之请包平台之 Request、此事之上下文（ExecutionContext，持久对象则为对象之状）与事类，出站之答包 Response 或终为 Response 之 Promise，皆以资「云工物」径执 JS 之物。宿主呼客之入口 `处理入站网页请求` 则授〔0，请，上下文，事类〕，入口返〔0，答〕，宿主取其答（Promise 则候其成）为此 HTTP 之答。

- 读：以「物取」「物调」读 Request、URL、Headers 之属与法；`读取入站事件种类` 返其事类。有限之正文以流读器逐块而计、逾限则废；宽解严解 UTF-8 用宿主之 `TextDecoder`，JSON 以宿主 `JSON.parse` 验之、`JSON.stringify` 正之，嵌套逾三十三层视为无效。或败之调皆取「云工果」，宿主之异不越 Wasm 之界。
- 造答：以全局构造器 `Response` 造答；带头之答先于豫言严验其状、头与内容种类。
- 转：`转发网页请求` 以请（或易其径）授所许之 ASSETS 或 SERVICE 之绑，出站之答即绑 `fetch` 所返之 Promise，入口即返。`转发网页请求并加标头` 与 `造静态资源响应` 亦不候于入口：以「登记云工回调」接 then 之回调于 `fetch` 之 Promise（成、败各一，任一被呼则并注销之），资源或上游之答既至，乃于回调易其状、头而造新 Response，出站之答为 then 所得之 Promise；回调败则此请败。`转发网页请求并筛标头` 候上游，上游败则为可捕之豫言异。
- 入站请求物、入站请求上下文、入站请求种类（请 → Request、上下文、事类）与 物出站响应、出站响应物（Response 或 Promise ↔ 出站之答），供网页事件流、网页上游、授权服务、命名持久服务、对象存储诸适配经绑后之 `豫言操作系统网页服务` 包导入而用之。

此适配无顶层可变之格，此请之中间态皆在参与局部；回调之登记表在云工宿主库。所需宿主之能：通用原语（全局 `URL`、`Request`、`Response`、`Headers`、`TextDecoder`、`JSON`、`decodeURIComponent`、`Promise` 之回调）与 SERVICE、ASSETS 之绑。一致之验见 `一致性验证/` 下网页入站（读请）、网页答复（造答）、网页转发（转请与改址）三组。
