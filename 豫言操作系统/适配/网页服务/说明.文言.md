# 网页服务云工之适配

于云工宿主成 `豫言操作系统网页服务` 〇点二（提案 C0001），含原网页入站、网页答复、网页转发三包所并之诸术。入站之请与出站之答各裹此调句柄表之一柄：请为宿主所登之 Request，答为 Response 或宿主待成之 Promise。宿主呼客之入口 `处理入站网页请求` 则授〔0，请之柄〕，入口返同形之答，宿主取其柄所指之物（Promise 则候其成）为此 HTTP 之答。

- 读：由通用句柄桥读 Request 之属；有限之正文以流读器逐块而计、逾限则废，宽解严解 UTF-8 与 JSON 之规整皆成于宿主之 `TextDecoder`、`Response.json`、`JSON.parse`，宿主之异不越 Wasm 之界。
- 造答：于宿主造 Response；带头之答先于豫言严验其状、头与内容种类。
- 转：`转发网页请求` 以请（或易其径）授所许之 ASSETS 或 SERVICE 之绑，不候上游，答柄指在途之 fetch Promise；`转发网页请求并加标头`、`转发网页请求并筛标头` 与 `造静态资源响应` 候上游而后造答，败则为可捕之豫言异。
- `入站请求句柄`（请→宿主柄号）、`句柄出站响应`（柄号→出站之答）与 `出站响应句柄`，供网页事件流、网页上游、授权服务、命名持久服务、对象存储诸适配经绑后之 `豫言操作系统网页服务` 包导入而用之。

所需宿主之能：通用句柄桥、Request 与 Response 之造、流读器、文之解码器、URL 编解码、服务之绑与静资之绑。一致之验见 `一致性验证/` 下网页入站（读请）、网页答复（造答）、网页转发（转请与改址）三组。
