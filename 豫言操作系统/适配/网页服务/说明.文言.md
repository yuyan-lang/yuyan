# 网页服务云工之适配

于云工宿主成 `豫言操作系统网页服务`（提案 C0001）。入站之请与出站之答各裹此调句柄表之一柄：请为宿主所登之 Request，答为 Response 或宿主待成之 Promise。宿主呼客之入口 `处理入站网页请求` 则授〔0，请之柄〕，入口返同形之答，宿主取其柄所指之物为此 HTTP 之答。

诸读术由通用句柄桥读 Request 之属；造答诸术于宿主造 Response；`转发网页请求` 以请（或易其径）授所许之 ASSETS 或 SERVICE 之绑，绑之答原样为果。`入站请求句柄`、`句柄出站响应` 供网页事件流、网页上游诸适配取请之柄、裹上游之果为答。

所需宿主之能：通用句柄桥、Request 与 Response 之造、服务之绑与静资之绑。
