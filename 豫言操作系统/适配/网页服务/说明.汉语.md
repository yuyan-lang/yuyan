# 网页服务云工适配

在云工宿主上实现 `豫言操作系统网页服务` 0.2.0（提案 C0001），包括原网页入站、网页答复、网页转发三个包并入的全部函数。入站请求与出站响应各包着本次调用句柄表里的一个句柄：请求是宿主登记的 Request，响应是 Response 或宿主待完成的 Promise。宿主调用应用的入口 `处理入站网页请求` 时传入〔0, 请求句柄〕，入口返回同形的响应，宿主取出句柄所指的对象（Promise 则等它完成）作为本次 HTTP 响应。

- 读取：经通用句柄桥读 Request 的属性；有限正文读取用流读取器逐块累计、按上限取消，宽松与严格 UTF-8 解码、JSON 规范化都在宿主的 `TextDecoder`、`Response.json`、`JSON.parse` 里完成，宿主异常不越过 Wasm 边界。
- 造响应：在宿主里构造 Response；带标头的响应先在豫言里严格校验状态、标头与内容类型。
- 转发：`转发网页请求` 把请求（必要时改路径）交给获授权的 ASSETS 或 SERVICE 绑定，不等待上游，响应句柄指向在途的 fetch Promise；`转发网页请求并加标头`、`转发网页请求并筛标头` 与 `造静态资源响应` 等待上游后再构造响应，失败转为可捕获的豫言异常。
- `入站请求句柄`（请求 → 宿主句柄号）、`句柄出站响应`（句柄号 → 出站响应）与 `出站响应句柄` 供网页事件流、网页上游、授权服务、命名持久服务、对象存储等适配经绑定后的 `豫言操作系统网页服务` 包导入使用。

所需宿主能力：通用句柄桥、Request 与 Response 的构造、流读取器、文本解码器、URL 编解码、服务绑定与静态资源绑定。一致性验证见 `一致性验证/` 下的网页入站（请求读取）、网页答复（造响应）、网页转发（转发与改址）三组。
