# 网页服务云工适配

在云工宿主上实现 `豫言操作系统网页服务`（提案 C0001）。入站请求与出站响应各包着本次调用句柄表里的一个句柄：请求是宿主登记的 Request，响应是 Response 或宿主待完成的 Promise。宿主调用应用的入口 `处理入站网页请求` 时传入〔0, 请求句柄〕，入口返回同形的响应，宿主取出句柄所指的对象作为本次 HTTP 响应。

读取函数经通用句柄桥读 Request 的属性；造响应的函数在宿主里构造 Response；`转发网页请求` 把请求（必要时改路径）交给获授权的 ASSETS 或 SERVICE 绑定，绑定的响应原样作为结果。`入站请求句柄`、`句柄出站响应` 供网页事件流、网页上游等适配取请求句柄、把上游结果包成响应。

所需宿主能力：通用句柄桥、Request 与 Response 的构造、服务绑定与静态资源绑定。
