# 网页服务云工适配

在云工薄宿主上实现 `豫言操作系统网页服务` 0.2.0（提案 C0001），包括原网页入站、网页答复、网页转发三个包并入的全部函数。适配只用云工宿主库的通用原语（`物宿主`、`物`、`回调` 三个模块）：入站请求包着平台给的 Request 对象、本次事件的上下文（ExecutionContext，持久对象为对象状态）与事件种类，出站响应包着 Response 或终将得到 Response 的 Promise，都以资源「云工物」直接持有 JS 对象。宿主调用应用的入口 `处理入站网页请求` 时传入〔0, 请求, 上下文, 种类〕，入口返回〔0, 响应〕，宿主取出响应（Promise 则等它完成）作为本次 HTTP 响应。

- 读取：用「物取」「物调」读 Request、URL、Headers 的属性与方法；`读取入站事件种类` 返回事件种类。有限正文读取用流读取器逐块累计、按上限取消；宽松与严格 UTF-8 解码用宿主的 `TextDecoder`，JSON 用宿主的 `JSON.parse` 校验、`JSON.stringify` 规范化，嵌套超过 33 层按无效 JSON 处理。可能失败的调用都取「云工果」，宿主异常不越过 Wasm 边界。
- 造响应：用全局构造器 `Response` 造响应；带标头的响应先在豫言里严格校验状态、标头与内容类型。
- 转发：`转发网页请求` 把请求（必要时改路径）交给获授权的 ASSETS 或 SERVICE 绑定，出站响应就是绑定 `fetch` 返回的 Promise，入口立即返回。`转发网页请求并加标头` 与 `造静态资源响应` 也不在入口里等待：它们用「登记云工回调」给 `fetch` 的 Promise 接上 then 回调（成功、失败各一个，任一被调用时两者一起注销），资源或上游响应到达后在回调里改写状态、标头并造新的 Response，出站响应是 then 得到的 Promise；回调失败时本次请求失败。`转发网页请求并筛标头` 等待上游，上游失败转为可捕获的豫言异常。
- 入站请求物、入站请求上下文、入站请求种类（请求 → Request、上下文、种类）与 物出站响应、出站响应物（Response 或 Promise ↔ 出站响应）供网页事件流、网页上游、授权服务、命名持久服务、对象存储等适配经绑定后的 `豫言操作系统网页服务` 包导入使用。

本适配没有顶层可变格，本次请求的中间状态都在参数与局部变量里；回调登记表在云工宿主库里。所需宿主能力：通用原语（全局 `URL`、`Request`、`Response`、`Headers`、`TextDecoder`、`JSON`、`decodeURIComponent`、`Promise` 回调）与 SERVICE、ASSETS 绑定。一致性验证见 `一致性验证/` 下的网页入站（请求读取）、网页答复（造响应）、网页转发（转发与改址）三组。
