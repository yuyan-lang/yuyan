# 网页服务造答之一致性验证

此目录以真 Wasm 与节点宿主验《豫言操作系统网页服务》0.2.0 云工适配之造答诸术（原网页答复包之十回应之术并入网页服务，易为“造…响应”，返 `回书`，由处理入口还宿主）：

- `应用/网页答复一致性应用/`：试验之应用，具网页服务之处理入口 `理来书`（提案 C0001）。包描述存为 `网页答复一致性应用。包。豫.txt`，以免为 `yy豫构` 之全仓包发现误析为包；`豫构 发行` 复之于构建根内之临目录（`dist/.自动构建/<输出名>/应用`）而改回原名。
- `网页答复一致性.test.mjs`：节点之测，载构建之产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。宿主复用一实例以处诸请。

## 复跑

于构建根行之（语言仓根本身即可，须已成 `yy豫构`；用法与依赖之解见[豫构发行说明](../../../../../应用/豫构/文档/发行.文言.md)）。同一编译缓存同时惟行一构建。

一、构建：`./yy豫构.exe 发行 云工 <本目录>/应用/网页答复一致性应用 dist/网页答复一致性`，产物在 `dist/网页答复一致性/`。
二、测试：`node --test <本目录>/网页答复一致性.test.mjs`。产物根默认为当前目录之 `dist`，可以环境变量 `产物根` 改之。

## 所覆

- 五带头之术（`造带头文字回书`、`造带头结绳回书`、`造带头空回书`、`造带头字节回书`、`造带头改址回书`）：同名之头守序而多 `Set-Cookie`、不暗增一头、正文原样（含二百五十六字节值与零字节）；
- 状二百至五百九十九与二零四、二零五、三零四之正文相冲；头名、值、数、禁名（不辨大小写）、`Set-Cookie` 之长、内容种类之正反例，含 CRLF 注入、非 ASCII、控字符；
- 正文之限（八 MiB、二 MiB、十六 MiB 及各加一）；改址之五状与二十余种目标之正反例；HEAD 不特为处；造数答者惟入口所返者生效；`造结绳回书`、`造空回书`、`造文字回书`、`造同源改址回书`、`造外址改址回书`（含自增 no-store 与 nosniff）。

每测皆断言真 Wasm 之可察之行；期望之值凡能由平台标准之实现给出者（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`），皆取自同一标准之实现，不手抄。
