# 网页事件流一致性验证

此目录验[网页事件流公约](../../../../豫寓榫卯/网页事件流/规范.文言.md)之云工适配：试验应用在 `应用/`（为免全仓库发现包时误析，包描述存为 `事件流一致性应用。包。豫.txt`，构建时改回 `事件流一致性应用。包。豫`），Node 之测为 `事件流一致性.test.mjs`，于真实 workerd（持久对象内 `durable-fetch`、真实 HTTP、真实 D1）复验者为豫言之测 `云端复验/事件流云端复验。测试。豫`。试验应用具网页服务之处理入口 `理来书`（提案 C0001，一实例理诸请）；始事件流以请为参，惟于 HTTP 之事调之。Node 之测所涵：响应头与帧序、固定内容种类与默认无缓存、UTF-8；响应头先于程序毕而至；二千小块与一百二十个六十四 KiB 之块；六十四 KiB 之界（六万五千五百三十六通、六万五千五百三十七抛异、多字节按字节计）；背压（读者不读则书不越读者）；客断之二法——读端取消与请求信号中止（书正阻于背压、读者仍读，二时机）——其后书返一、应用续毕收尾而书于 D1；惟轮询“已断开”亦能察空闲联之断；止使读者见误、其后书返二；终后书返二、再终与止幂等；无效流柄、已毕之事之流柄、同请重开皆抛可捕之豫言异；多流并发不相扰；`durable-fetch` 与 `service-fetch` 事亦可用，慢读者惟阻其自事；附加标头诸校验之支（合法之界：六十四字节名、八千一百九十二字节值、三十二项、制表、引号与反斜杠、覆 `Cache-Control`；非法：越界与二零四、二零五之状态、九禁名与 `Set-Cookie`、非令牌名、CR、LF、NUL、DEL、ESC、高位字节、`豫`、八千一百九十三字节值、三十三项、重复）。“收尾流”一则验程序返而流未终者，适配之收尾回调随入口之毕而终之（见[适配说明](../说明.文言.md)）。同实例中他事方行而用其柄当败，此则记为待办（薄宿主下交错之请无由辨之）。

## 复行

于构建根行之（语言仓根本身即可，须已依今之源码成 `豫构`（云工之式复制 `物桥.mjs`）；用法与依赖之解见[豫构发行说明](../../../../应用/豫构/文档/发行.文言.md)）。试验应用又用网页服务与关系数据库二云工适配。编译缓存以编译器可执行文件之修改时间为准，数构建同用一编译器则共其缓存（缓存原子而书，可并行）。

一、构建试验应用：`./豫构。林檎。豫行 发行 云工 <本目录>/应用 dist/事件流一致性`，产物在 `dist/事件流一致性/`。
二、行测（Node 二十六以上：实 Wasm 须 JSPI，以 `node:sqlite` 拟 D1）：`env 产物目录=<构建根>/dist/事件流一致性 node --test --test-force-exit 事件流一致性.test.mjs`（于此目录行之；`<构建根>` 谓构建根之绝径）。预期通二十、待办一。Workers 之全局 `scheduler.wait` 于 Node 无之，`工具.mjs` 之 `造全局` 以 `node:timers/promises` 之 `scheduler` 垫片，经 `创建云工宿主({全局})` 授之。

## 于本地 workerd 复行

`云端复验/` 者，以[验收驱动](../../../../库/考成/包说明.文言.md)书之豫言测包，见[其说明](云端复验/包说明.文言.md)。一令毕之：求 wrangler（环境变量 `云工命令行路径`，或仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；皆无则书“跳过”而以零退）→ 产物 `dist/事件流一致性/` 不存则以 `双宿主构建.wasm` 构之（环境变量 `重建云工应用=1` 则强重构）→ 于新暂存之工作目录纳产物、`云端复验/rig.mjs`（转诸请于持久对象之包装）与 `wrangler.jsonc`（**必**含兼容标志 `enable_request_signal`，见适配说明），依 `应用/建表.sql` 建 D1 表 → 于空端口起 `wrangler dev --local`（Wrangler 4.129.0）→ 逐一行用例 → 止 wrangler（并 workerd 之子进程）。于构建根行之：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/网页事件流/一致性验/云端复验/事件流云端复验。测试。豫 --输出 事件流云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 事件流云端复验.wasm
```

同一持久对象之 D1 日志跨例累积，例惟观各自新增者；每行皆用新 `.state`。“中止”一则置于末：Wrangler 4.129.0 之 dev 代理或视被中止之响应流为致命之误而退出（本地开发工具之行，直接运行 workerd 不受此累）。有败则以退码一终，而存工作目录与 `wrangler.log`。CI 无 wrangler，全树测试于 `云端复验/` 惟验其类。

薄宿主上已于 Wrangler 4.129.0 尽通过（九项），并录所观（背压缓冲之量、断之察时、中止于 HTTP/1.1 之所见），见[适配说明](../说明.文言.md)。云端（Cloudflare 边缘）之行留待验之。
