# 网页事件流一致性验证

本目录验证[网页事件流接口](../../../../豫言操作系统接口/网页事件流/规范.汉语.md)的云工适配：试验应用在 `应用/`（为免被全仓库包发现，包描述存为 `事件流一致性应用。包。豫.txt`，构建时改回 `事件流一致性应用。包。豫`），Node 测试是 `事件流一致性.test.mjs`，在真实 workerd（持久对象内 `durable-fetch`、真实 HTTP、真实 D1）里复验的是 `事件流云端复验.test.mjs`。Node 测试覆盖：响应头与帧序、固定内容类型与默认无缓存、UTF-8；响应头先于程序结束到达；2000 个小块与 120 个 64 KiB 块；64 KiB 边界（65536 通过、65537 抛异常、多字节按字节计）；背压（读者不读则写入不越过读者）；两种客户端断开——读端取消与请求信号中止（写入正阻塞在背压上、读者仍在读两种时机）——之后写入返回 1、应用继续完成收尾并写入 D1；只轮询“已断开”也能发现空闲连接的断开；中止使读者见到错误、之后写入返回 2；结束后写入返回 2、重复结束与中止幂等；无效流柄、他事流柄（含句柄号相同）、重复开始、非 HTTP 事件（`scheduled`）都抛可捕获的豫言异常；多流并发互不串扰；`durable-fetch` 与 `service-fetch` 事件也可用，慢读者只阻塞它自己的事件；附加标头的全部校验分支（合法边界：64 字节名、8192 字节值、32 项、制表、引号与反斜杠、覆盖 `Cache-Control`；非法：越界与 204/205 状态、九个禁用名与 `Set-Cookie`、非 token 名、CR/LF/NUL/DEL/ESC/高位字节/`豫`、8193 字节值、33 项、重复）。另有两条“收尾流”测试：事件结束（程序返回而流未结束）与超过墙钟时限时，宿主收尾未结束的响应流，不让它悬挂（宿主已并入 `收尾流`，见[适配说明](../说明.汉语.md)）。

## 复跑

在构建根里运行（语言仓根目录本身即可，需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖解析规则见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)）。编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发。

1. 构建试验应用：`./yy双宿主构建 --自动 云工 <本目录>/应用 dist/事件流一致性`，产物在 `dist/事件流一致性/`。
2. 跑测试（Node 26 以上：真实 Wasm 需要 JSPI，`node:sqlite` 模拟 D1）：`env 产物目录=<构建根>/dist/事件流一致性 node --test --test-force-exit 事件流一致性.test.mjs`（在本目录里运行；`<构建根>` 指构建根的绝对路径）。预期 22 通过、0 待办。Workers 的全局 `scheduler.wait` 在 Node 里没有，`工具.mjs` 的 `造全局` 用 `node:timers/promises` 的 `scheduler` 垫片，经 `创建云工宿主({全局})` 传入。

## 在本地 workerd 里复跑

1. 把 `dist/事件流一致性/` 复制到一个空目录，去掉 `程序.wasm.wat`，再放入本目录 `云端复验/` 里的 `rig.mjs`（转发到持久对象的包装）和 `wrangler.jsonc`（**必须**含兼容标志 `enable_request_signal`，见适配说明）。
2. 建 D1 表：`wrangler d1 execute DB --local --persist-to <工作目录>/.state --file <本目录>/应用/建表.sql`。
3. 起服务：`wrangler dev --local --port <端口> --persist-to <工作目录>/.state`（Wrangler 4.129.0）。
4. 复验：`env 远端地址=http://localhost:<端口> node --test --test-force-exit 事件流云端复验.test.mjs`。同一个持久对象的 D1 日志跨测试累积，测试只看各自新增的记录；每次复验前重建 `.state`。“中止”那条放在文件末尾：Wrangler 4.129.0 的 dev 代理会把被中止的响应流当成致命错误而退出（本地开发工具行为，直接运行 workerd 不受影响）。

已在 Wrangler 4.129.0 上全部通过，含观察记录（背压缓冲量、断开的发现时机、中止在 HTTP/1.1 上的可见形态），见[适配说明](../说明.汉语.md)。云端（Cloudflare 边缘）行为待验证。
