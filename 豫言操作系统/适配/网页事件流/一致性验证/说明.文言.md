# 网页事件流一致性验证

此目录验[网页事件流公约](../../../../豫言操作系统接口/网页事件流/规范.文言.md)之云工适配：试验应用在 `应用/`（为免全仓库发现包时误析，包描述存为 `事件流一致性应用。包。豫.txt`，构建时改回 `事件流一致性应用。包。豫`），Node 之测为 `事件流一致性.test.mjs`，于真实 workerd（持久对象内 `durable-fetch`、真实 HTTP、真实 D1）复验者为 `事件流云端复验.test.mjs`。Node 之测所涵：响应头与帧序、固定内容种类与默认无缓存、UTF-8；响应头先于程序毕而至；二千小块与一百二十个六十四 KiB 之块；六十四 KiB 之界（六万五千五百三十六通、六万五千五百三十七抛异、多字节按字节计）；背压（读者不读则书不越读者）；客断之二法——读端取消与请求信号中止（书正阻于背压、读者仍读，二时机）——其后书返一、应用续毕收尾而书于 D1；惟轮询“已断开”亦能察空闲联之断；止使读者见误、其后书返二；终后书返二、再终与止幂等；无效流柄、他事流柄（句柄号纵同）、重开、非 HTTP 事（`scheduled`）皆抛可捕之豫言异；多流并发不相扰；`durable-fetch` 与 `service-fetch` 事亦可用，慢读者惟阻其自事；附加标头诸校验之支（合法之界：六十四字节名、八千一百九十二字节值、三十二项、制表、引号与反斜杠、覆 `Cache-Control`；非法：越界与二零四、二零五之状态、九禁名与 `Set-Cookie`、非令牌名、CR、LF、NUL、DEL、ESC、高位字节、`豫`、八千一百九十三字节值、三十三项、重复）。别有二则“收尾流”之测：事毕（程序返而流未终）与逾墙钟之限，宿主收尾未终之响应流，不使其悬挂（宿主已并 `收尾流`，见[适配说明](../说明.文言.md)）。

## 复行

于构建根行之（语言仓根本身即可，须已成 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖之解见[双宿主构建说明](../../../../工具/双宿主构建/说明.文言.md)）。编译缓存以编译器可执行文件之修改时间为准，数构建同用一编译器则共其缓存，勿并行。

一、构建试验应用：`./yy双宿主构建 --自动 云工 <本目录>/应用 dist/事件流一致性`，产物在 `dist/事件流一致性/`。
二、行测（Node 二十六以上：实 Wasm 须 JSPI，以 `node:sqlite` 拟 D1）：`env 产物目录=<构建根>/dist/事件流一致性 node --test --test-force-exit 事件流一致性.test.mjs`（于此目录行之；`<构建根>` 谓构建根之绝径）。预期通二十二、待办零。Workers 之全局 `scheduler.wait` 于 Node 无之，`工具.mjs` 之 `造全局` 以 `node:timers/promises` 之 `scheduler` 垫片，经 `创建云工宿主({全局})` 授之。

## 于本地 workerd 复行

一、取 `dist/事件流一致性/` 复制于空目录，去 `程序.wasm.wat`，纳此目录 `云端复验/` 中之 `rig.mjs`（转诸请于持久对象之包装）与 `wrangler.jsonc`（**必**含兼容标志 `enable_request_signal`，见适配说明）。
二、建 D1 表：`wrangler d1 execute DB --local --persist-to <工作目录>/.state --file <本目录>/应用/建表.sql`。
三、起服务：`wrangler dev --local --port <端口> --persist-to <工作目录>/.state`（Wrangler 4.129.0）。
四、复验：`env 远端地址=http://localhost:<端口> node --test --test-force-exit 事件流云端复验.test.mjs`。同一持久对象之 D1 日志跨测累积，测惟观各自新增者；每次复验前重建 `.state`。“中止”一则置于文末：Wrangler 4.129.0 之 dev 代理视被中止之响应流为致命之误而退出（本地开发工具之行，直接运行 workerd 不受此累）。

已于 Wrangler 4.129.0 上尽通过，并录所观（背压缓冲之量、断之察时、中止于 HTTP/1.1 之所见），见[适配说明](../说明.文言.md)。云端（Cloudflare 边缘）之行待验。
