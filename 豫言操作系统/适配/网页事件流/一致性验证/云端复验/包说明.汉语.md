# 网页事件流云端复验

网页事件流在本机 wrangler dev（真 workerd，持久对象内 `durable-fetch`，真实 HTTP 与 D1）里的黑盒复验，用[验收驱动](../../../../../库/考成/包说明.汉语.md)写成，一条命令完成“按需构建试验应用 → 起 wrangler → 跑全部用例 → 停 wrangler（含 workerd 子进程）”。

- `事件流云端复验。测试。豫`：九个用例——响应头与帧序、程序返回后未结束的流由适配收尾、64 KiB 块边界与大量块、背压、客户端中止后应用继续收尾、结束后语义、附加标头与 Content-Type 不可覆盖、十二个流并发、中止之后客户端所见（放在最后：wrangler 的 dev 代理可能因此退出）。
- `wrangler.jsonc`：本机复验用的 wrangler 配置，必须含兼容标志 `enable_request_signal`。
- `rig.mjs`：Worker 侧的转发外壳，与产物的 `入口.mjs` 放在同一目录，按请求头 `x-do` 把请求转给持久对象实例（缺省 main）；带正文的请求先读完正文再转发，免得持久对象没读正文就作答时，转发在响应之后再读请求流，wrangler dev 把这当成致命错误而退出。

在仓库根目录运行：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/网页事件流/一致性验/云端复验/事件流云端复验。测试。豫 --输出 事件流云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 事件流云端复验.wasm
```

wrangler 依次取环境变量 `云工命令行路径`、仓库旁云仓的 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；没有就打印“跳过”并以零退出。产物 `dist/事件流一致性/` 不存在（或环境变量 `重建云工应用=1`）时用 `双宿主构建.wasm` 构建。每次运行用新的临时工作目录，D1 状态从空开始；同一个持久对象的日志跨用例累积，用例只看各自新增的记录。CI 没有 wrangler，全树测试对本目录只做类型检查。
