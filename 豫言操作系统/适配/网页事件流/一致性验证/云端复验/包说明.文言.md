# 网页事件流云端复验

网页事件流于本机 wrangler dev（真 workerd，持久对象内 `durable-fetch`，真 HTTP 与 D1）之黑盒复验，以[验收驱动](../../../../../库/考成/包说明.文言.md)书之，一令毕“随需构试验之应用 → 起 wrangler → 行诸用例 → 止 wrangler（并 workerd 之子进程）”。

- `事件流云端复验。测试。豫`：九例——响应头与帧序、程序返而流未终者适配收之、六十四 KiB 之块界与大量之块、背压、客止之后应用续而收尾、终后之义、附加标头与 Content-Type 不可覆、十二流并行、止之后客之所见（置于末：wrangler 之 dev 代理或因此而退）。
- `wrangler.jsonc`：本机复验之 wrangler 配置，必含兼容之标 `enable_request_signal`。
- `rig.mjs`：Worker 一侧之转发外壳，与产物之 `入口.mjs` 同置一目录，依请求头 `x-do` 转请于持久对象实例（缺则 main）；有正文之请先尽读其正文乃转，免持久对象未读正文而先答时，转送于答后复读请流，wrangler dev 视为致命之误而退。

于仓根行之：

```sh
./yy豫构.exe 文件 豫言操作系统/适配/网页事件流/一致性验/云端复验/事件流云端复验。测试。豫 --输出 yy事件流云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy事件流云端复验.wasm
```

wrangler 次第取环境变量 `云工命令行路径`、仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；皆无则书“跳过”而以零退。产物 `dist/事件流一致性/` 不存（或环境变量 `重建云工应用=1`）则以 `yy双宿主构建.wasm` 构之。每行用新暂存之工作目录，D1 之态自空始；同一持久对象之日志跨用例而积，用例惟观各自新增之记。CI 无 wrangler，全树测试于此目录惟验其类。
