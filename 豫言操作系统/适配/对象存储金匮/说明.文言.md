# 对象存储落盘适配

桶、键、体与元皆落于本机之盘，重启而在。供豫言系统与本土之宿主用。

## 目与卷

```
<金匮根>/对象/<桶>/索引         JSON 之物：键 → 元之 JSON 文
<金匮根>/对象/<桶>/物/<沙二五六>.物   体之字节（依内容之沙而名）
<金匮根>/对象/<桶>/段/<上传号>/段<段号>.片   分传暂存之段
```

元为 JSON 之文，栏曰 `size`、`etag`（体之沙）、`uploaded`（Unix 毫秒）、`httpMetadata`（`contentType`、`cacheControl`）、`customMetadata`。桶名经 `遁名` 转写而为目名。

## 写与读

- `写物 桶 键 选项 帛`、`写物文字 桶 键 选项 文`：书体与元，还 `{"written":true,"size":…,"etag":"…","httpEtag":"\"…\""}`；条件不立者还 `{"written":false}` 而仓不改。选项为 JSON 之文，认 `contentType`、`cacheControl`、`customMetadata`、`ifNoneMatch`、`ifMatch`。
- `取物元数据 桶 键`：元之 JSON 文；物不存则 `null`。
- `读物文字 桶 键 限`：`{text,size,httpEtag,customMetadata}`；不存则 `null`，逾限则 `{tooLarge,size}`。
- `读物字节 桶 键 限`：（阳，体）或（阴，空帛）；限越度或体逾限者告祸。
- `删物 桶 键列`：去索引之项与体之卷。
- `列举物 桶 选项`：认 `prefix`、`startAfter`、`limit`，还 `{"objects":[{key,size,etag,uploaded}…],"truncated":false}`，依字节之序。

## 分传

`始分段写物 桶 键 选项` 还 `{"上传号":"…"}`；`来正文写段 请求 桶 键 上传号 段号` 书其体于段目；`终分段写物 桶 键 上传号 段们 选项` 依段号升序合之、核选项之 `摘要`、写物而删段目；`弃分段写物 桶 键 上传号` 弃其段目。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓府库金匮榫」之「对象」之书。

「设匮根」于『/某处的数据盘/豫言』。
「写物文字」于『站内』于『配置/甲』于『{"contentType":"application/json"}』于『{"ok":true}』。
「读物文字」于『站内』于『配置/甲』于「一零四八五七六」。
```

## 后续之事项

- `物藏物作回书` 未具，呼之则告祸。
- 键长之限、桶名之合法、列之 `delimiter` 与 `include`、`truncated` 之真、所留字段未核。
- 索引整表重写，键多则写物之费与键数俱增，宜改追加之记。
- `读物文字` 不为严 UTF-8 之验。
