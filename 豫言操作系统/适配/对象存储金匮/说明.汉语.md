# 对象存储落盘适配

桶、键、正文与元数据都落在本机盘上，重启后仍在。供豫言系统与原生宿主上的服务程序使用。

## 目录与卷

```
<金匮根>/对象/<桶>/索引         JSON 对象：键 → 元数据的 JSON 文字
<金匮根>/对象/<桶>/物/<沙二五六>.物   正文字节（按内容摘要命名）
<金匮根>/对象/<桶>/段/<上传号>/段<段号>.片   分段上传的暂存段
```

元数据是 JSON 文字，字段为 `size`、`etag`（正文的沙二五六）、`uploaded`（Unix 毫秒）、`httpMetadata`（`contentType`、`cacheControl`）、`customMetadata`。桶名经 `遁名` 转写后作目录名。

## 写与读

- `写物 桶 键 选项 帛`、`写物文字 桶 键 选项 文字`：写正文与元数据，返回 `{"written":true,"size":…,"etag":"…","httpEtag":"\"…\""}`；条件不成立时返回 `{"written":false}` 且仓不改。选项是 JSON 文字，认 `contentType`、`cacheControl`、`customMetadata`、`ifNoneMatch`、`ifMatch`。
- `取物元数据 桶 键`：元数据 JSON 文字；对象不存在返回 `null`。
- `读物文字 桶 键 上限`：`{text,size,httpEtag,customMetadata}`；不存在返回 `null`，超过上限返回 `{tooLarge,size}`。
- `读物字节 桶 键 上限`：存在且不超上限时（阳，正文），否则（阴，空帛）；上限不在 1 至 16777216 之间或正文超过上限时报中文事故。
- `删物 桶 键列`：删索引项与正文卷。
- `列举物 桶 选项`：选项 JSON 认 `prefix`、`startAfter`、`limit`，返回 `{"objects":[{key,size,etag,uploaded}…],"truncated":false}`，按键的字节序排列。

## 分段写物

`始分段写物 桶 键 选项` 返回 `{"上传号":"…"}`；`来正文写段 请求 桶 键 上传号 段号` 把请求正文写进段目；`终分段写物 桶 键 上传号 段们 选项` 按段号升序拼合、核对选项里的 `摘要`（沙二五六的十六进制）、写物并删段目；`弃分段写物 桶 键 上传号` 删段目。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓府库金匮榫」之「对象」之书。

「设匮根」于『/某处的数据盘/豫言』。
「写物文字」于『站内』于『配置/甲』于『{"contentType":"application/json"}』于『{"ok":true}』。
「读物文字」于『站内』于『配置/甲』于「一零四八五七六」。
```
