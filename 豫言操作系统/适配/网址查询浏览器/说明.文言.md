# 网址查询浏览器适配

`查询。豫` 于浏览器中承[网址查询之约](../../../豫言操作系统接口/网址查询/规范.文言.md)（0.1.0）：按表单规则编码与解析查询串、设置网址查询参数。其义与云工适配（`../网址查询/`）逐字相同，接口包自身不变。`实现接口。豫` 固公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `查询.编码`、`查询.解析`、`查询.设参`；败则返（阴，错文），转为豫言事故。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`：以 URLSearchParams 与 URL；适配以 [(名,值)] 之列序列化为癸象数组授宿主，宿主验一千零二十四项与一 MiB 之限。

**选用之规**：构建器于浏览器模式，先取 `适配/<能力>浏览器`；云工模式，取 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用“前端接口探针”含此接口；JSDOM 加真实 Wasm）。
