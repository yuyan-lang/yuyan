# 网址查询浏览器适配

`查询。豫` 在浏览器里实现[网址查询接口](../../../豫言操作系统接口/网址查询/规范.汉语.md)（0.1.0）：按表单规则编码与解析查询串、设置网址查询参数。语义与云工适配（`../网址查询/`）逐字相同，接口包本身不变。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `查询.编码`、`查询.解析`、`查询.设参`；失败以（阴，错误文）返回，再转成豫言事故。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`：`URLSearchParams` 与 `URL`；适配把 [(名称,值)] 列表序列化成 JSON 数组交给宿主，宿主校验 1024 项与 1 MiB 的限额。

**选用规则**：构建器在浏览器模式下优先选用 `适配/<能力>浏览器`，云工模式选 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用 `前端接口探针` 含本接口；JSDOM＋真实 Wasm）。
