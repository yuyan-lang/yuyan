# 云工持久告警适配

`告警。豫` 借当前 Durable Object 之存储告警，以承[持久告警之约](../../../豫言操作系统接口/持久告警/规范.文言.md)：`读取持久告警` 呼 `storage.getAlarm`（宿主以十进文传毫秒，适配转为整数），`设置持久告警` 呼 `storage.setAlarm`，`删除持久告警` 呼 `storage.deleteAlarm`。告警既至，云工宿主登平台授于 `alarm(info)` 之告警信息（不予则为空物）于此调之句柄表，以 `持久告警事件`（构造器 `云工持久告警事件` 裹其柄）授入口 `处理持久告警`（提案 C0001）；`读取告警重试次数` 经句柄桥读其 `retryCount`，缺或非非负整数则为零。适配惟察时之范围（0 至 8640000000000000），不存任何态；于持久对象之外调前三术，宿主报“当前事件不属于持久对象”而止此调。

告警之调用径施于 `storage`，于事务回调内之变，与其事务同命（本地 workerd 4.129.0 实测：事务回滚则事务内所设之告警并撤、所删者复；云端待验）。重试之次、败后待试之际告警视为已设、告警之事始告警视为已清，此诸行由平台所供，已于本地 workerd 验之，云端待验。事时之限（`durable-alarm` 默三十秒，可配至十五分）由宿主 `执行配置.json` 定之，见 `豫言操作系统/宿主/云工/说明.文言.md`。
