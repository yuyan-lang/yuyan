# 云工持久告警适配

`告警。豫` 借 Durable Object 之告警，以承[持久告警之约](../../../豫寓榫卯/持久告警/规范.文言.md)三版，惟用云工薄宿主之通用原语。告警既至，云工宿主以〔0，告警信息，对象之态〕呼入口 `理恒告警`：`恒告警事` 之构造器 `云工持久告警事件` 裹平台授于 `alarm(info)` 之告警信息（不予则为空物）与对象之态，皆资「云工物」。

- `告警恒仓` 以对象之态与其 `storage` 造久仓（持久事务适配之 `造恒仓`），告警入口中读写久仓与告警皆用之。
- `读恒告警`、`设恒告警`、`删恒告警` 呼久仓之仓之 `getAlarm`、`setAlarm`、`deleteAlarm`：仓取自网页之请、告警之事或独占之区，则为对象之 `storage`；取自 `事务恒仓`，则为事务，告警之变遂与本事务同命。`getAlarm` 得 null，则返阴与零。适配惟察时之范围（0 至 8640000000000000）。
- `读告警重试次数` 读告警信息之 `retryCount`，为非负整数则取之，否则为零。
- 适配不存其态，无顶层可变之格。

重试之次、败后待试之际告警视为已设、告警之事始告警视为已清，此诸行由平台所供，已于本地 workerd 验之，云端待验。后续诸版之事：旧宿主依事类所设之墙钟时限（`执行配置.json`）随薄宿主而去，告警入口之时限由平台定之。
