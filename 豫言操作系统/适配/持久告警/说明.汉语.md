# 云工持久告警适配

`告警。豫` 用 Durable Object 的告警实现[持久告警接口](../../../豫言操作系统接口/持久告警/规范.汉语.md) 0.3.0，只用云工薄宿主的通用原语。告警到时，云工宿主以〔0, 告警信息, 对象状态〕调用入口 `处理持久告警`：`持久告警事件` 的构造器 `云工持久告警事件` 包着平台传给 `alarm(info)` 的告警信息（没给时为空对象）与对象状态，都是资源「云工物」。

- `告警持久仓` 用对象状态与它的 `storage` 造出持久仓（持久事务适配的 `造持久仓`），告警入口里读写持久仓、告警都用它。
- `读取持久告警`、`设置持久告警`、`删除持久告警` 调持久仓的仓的 `getAlarm`、`setAlarm`、`deleteAlarm`：持久仓取自网页请求、告警事件或独占区时是对象的 `storage`，取自 `事务持久仓` 时是事务对象，告警变更因而与本事务同命运。`getAlarm` 得 null 时返回阴与零。适配只检查时刻范围（0 至 8640000000000000）。
- `读取告警重试次数` 读告警信息的 `retryCount`，是非负整数时取其值，否则为零。
- 适配不保存状态，没有顶层可变格。

重试次数、失败后重试期间告警视为已设置、告警事件开始时告警视为已清除，这些行为由平台提供，已在本地 workerd 验证，云端待验证。后续版本的事项：旧宿主按事件种类设的墙钟时限（`执行配置.json`）随薄宿主去掉，告警入口的时限由平台决定。
