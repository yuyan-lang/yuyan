# 基础接口浏览器适配

浏览器宿主（`豫言操作系统/宿主/浏览器/`）的[基础接口](../../../豫言操作系统接口/基础/规范.汉语.md)适配。基础接口有诊断、时钟、错误三个模块，本适配按模块分成三个同名文件，由 `yy豫言操作系统绑定` 一次绑定三个模块；显示、图形处理器、图形显示等依赖基础的浏览器适配用 `寻观「豫言操作系统基础」之「错误」之书` 取得同一个 `系统错误` 类型。双宿主构建在浏览器模式下遇到依赖基础的接口时选用本目录。

- `诊断。豫`：`记录诊断` 交给宿主的标准错误输出；浏览器宿主把它交给 `启动豫言浏览器应用({输出})` 传入的输出函数，缺省丢弃。
- `时钟。豫`：`读取单调微秒` 由宿主的单调纳秒读数（`performance.now()`）换算为整数微秒，同一实例内不倒退，起点不代表日历时刻。
- `错误。豫`：`系统错误` 及其构造器逐字照抄规范。

三个文件与 Node 适配 `../基础节点/` 相同，只用值桥内建的宿主原语 `豫言_标准错误打印行` 与 `豫言_获取当前纳秒时间`，没有新增宿主原语。宿主支持清单是 `宿主提供.json`，由接口检查器从规范生成，接口规范改动后须重新生成。验收随图形探针进行，见 `../图形显示浏览器/一致性验证/`。
