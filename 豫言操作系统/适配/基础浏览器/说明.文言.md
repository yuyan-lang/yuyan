# 基础接口浏览器适配

此为浏览器宿主（`豫言操作系统/宿主/浏览器/`）之[基础接口](../../../豫言操作系统接口/基础/规范.文言.md)适配。基础有诊断、时钟、错误三模，此适配分为三文，名与模同，`yy豫言操作系统绑定` 一次并绑之；显示、图形处理器、图形显示诸依基础之浏览器适配，以 `寻观「豫言操作系统基础」之「错误」之书` 取同一 `系统错误` 之类。双宿主构建于浏览器之式，遇依基础之接口则取此目。

- `诊断。豫`：`记录诊断` 交宿主之标准误；浏览器宿主付之于 `启动豫言浏览器应用({输出})` 所授之输出函数，不授则弃。
- `时钟。豫`：`读取单调微秒` 取宿主单调之纳秒（`performance.now()`），化为整微秒；同实例不倒退，原点不作历日。
- `错误。豫`：`系统错误` 及其构造，一依规范之文。

三文与节点之适配 `../基础节点/` 同，惟用值桥内建之宿主原语 `豫言_标准错误打印行` 与 `豫言_获取当前纳秒时间`，不增新原语。宿主支持之簿为 `宿主提供.json`，接口检查器自规范生之；规范有改，须复生之。验收随图形探针而行，见 `../图形显示浏览器/一致性验证/`。
