# 显示浏览器适配

今行显示零点三版，增归还结果与 `归还显示面`，清此画布会话之事件听与输入框；存宿主画布与授权，同名复取则生新号。下文零点二版像素比与输入区域之约犹用。

`画面。豫`、`输入。豫` 于浏览器宿主行[显示接口](../../../豫言操作系统接口/显示/规范.文言.md) 零点二点零之二模。`实现接口。豫` 定公约之身份与版，`yy豫言操作系统绑定` 一次并绑二模（双宿主构建于浏览器之式取此目，并连绑 `../基础浏览器/`）。[显示节点适配](../显示节点/说明.文言.md)同名之模与此逐句相同（惟外调与私构之名异），改则两处同改。

**显示面何以授**：页中带 `data-yy-显示面="名"` 之 `<canvas>`，即以其名授此次之行；授否在作页者，应用不得自造。`取得已授显示面 名` 于文档中寻属性值等名之 canvas：无则返 `未获授权`；浏览器宿主已闭则返 `资源暂不可用`；同一 canvas 再取，得同一显示面。canvas 离文档或宿主闭，则面闭。

```html
<canvas data-yy-显示面="主画面" style="width:640px;height:480px"></canvas>
```

- **尺寸**：物理之素 = canvas 之 CSS 布局宽高 × `devicePixelRatio`（四舍五入）；为零则 `读取显示面尺寸` 返 `资源暂不可用`。页宜以 CSS 定 canvas 之宽高；未定者，宿主首取时书当时布局之尺于内联之式，免依像素比改其素数而布局随之自涨。canvas 勿带边框与内距（待办事项：改用 `devicePixelContentBoxSize`）。
- **像素画面**：`提交像素画面` 先依规范核宽高与字数（`输入无效`），次核与面之现尺同（`资源暂不可用`），乃设 canvas 之素数为此尺，以 2d 上下文之 `putImageData` 书 RGBA8 直通透明之素。同面已用于图形显示之呈现，则返 `资源暂不可用`。值桥一值之限十六兆，逾之之画面（如高像素比之全屏）返 `资源配额已尽`（待办事项：分块而交）。
- **输入之事**：宿主于 canvas 后插一透明之 `<input data-yy-显示面输入="名">` 以受键盘与输入法，点 canvas 则聚焦之。`pointerdown`/`pointermove`/`pointerup` 化为指针之事（坐标以面之左上为原，依物理之素取整；钮号即 DOM 之 `button`；按下则捕其指针；相接之移合一）；`keydown`/`keyup` 化为按键之事，键名为 `左 右 上 下 回车 退格 空格`，零点二版增 `删除 起首 末尾 上翻页 下翻页 制表 退出` 与修饰之 `上档 控制 交替 命令`，或单一 Unicode 标量，余键不交，组字之中之键不交；`制表` 止其默认，免焦点离面；输入框失焦则补修饰之键之抬起；`input`（非组字）与 `compositionend` 以输入框中已定之文为 `文字输入` 交之而清其框。canvas 之右键菜单阻之。`wheel`（非被动之听，止页之滚）化为 `滚轮`：像素之式乘像素比，行之式每行折四十八逻辑像素，页之式折画布之高，相接二事合一。每面各有事列（限六万五千五百三十六，满则去其最旧），同面并候之第二者得 `输入无效`；闭后先交 `显示面已关闭` 一次，再候返 `资源已失效`。`设置文字输入区域` 移隐 input 于所示之矩（依 canvas 之位与像素比换算），输入法之候选随之。`读取显示面像素比` 取 `devicePixelRatio`。

**宿主原语**：`豫言_浏览器_显示(操作, 显示面号, 甲, 乙, 字节, 丙, 丁)`，操作为 `取得 尺寸 提交 等待`，零点二版增 `像素比` 与 `输入区域`；返（码、四整数、文、第五整数）。新参新返皆附于末，旧位不变；码一至七依次为未获授权、资源暂不可用、资源已失效、资源不存在、资源已存在、资源配额已尽、输入无效，余为宿主操作失败。其行在 `宿主/浏览器/图形.mjs` 之纯工厂 `创建显示能力`（宿主初用乃动态载 `图形.mjs`）。`等待输入事件` 挂起豫言之栈，浏览器须具 JSPI。

**验收**：`../图形显示浏览器/一致性验证/`（探针应用、真 Chrome 之行法与验收之单）；宿主之单元测试在 `宿主/浏览器/图形。测试.mjs`。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「浏览器宿主」之「显示原语」之「浏览器显示操作」（旧外调名 `豫言_浏览器_显示`）。宿主实此诸导入，与旧原语同。
