# 显示浏览器适配

`画面。豫`、`输入。豫` 在浏览器宿主上实现[显示接口](../../../豫言操作系统接口/显示/规范.汉语.md) 0.1.0 的两个模块。`实现接口。豫` 固定公共包身份与版本，`yy豫言操作系统绑定` 一次绑定两个模块（双宿主构建在浏览器模式下选用本目录，并连带绑定 `../基础浏览器/`）。

**显示面怎样授予**：页面里带 `data-yy-显示面="名称"` 属性的 `<canvas>` 就以该名称授予本次运行，由写页面的人决定，应用不能自己创造显示面。`取得已授显示面 名称` 在文档中找属性值等于名称的 canvas：找不到返回 `未获授权`；浏览器宿主已关闭时返回 `资源暂不可用`；同一个 canvas 重复取得返回同一个显示面。canvas 被移出文档或宿主关闭时，显示面关闭。

```html
<canvas data-yy-显示面="主画面" style="width:640px;height:480px"></canvas>
```

- **尺寸**：物理像素 = canvas 的 CSS 布局宽高 × `devicePixelRatio`（四舍五入）；为零时 `读取显示面尺寸` 返回 `资源暂不可用`。页面应用 CSS 给 canvas 定宽高；没定时，宿主首次取得时把当时的布局尺寸写进内联样式，免得按像素比改 canvas 的像素数后布局尺寸跟着变大。canvas 不要带边框或内边距（待办事项：改用 `devicePixelContentBoxSize`）。
- **像素画面**：`提交像素画面` 先按规范核对宽高与字节数（`输入无效`），再核对与显示面当时尺寸相同（`资源暂不可用`），然后把 canvas 的像素数设成该尺寸，用 2d 上下文的 `putImageData` 写入 RGBA8 直通透明度的像素。同一显示面已用于图形显示呈现时返回 `资源暂不可用`。值桥单值上限是 16 MiB，超过的画面（如高像素比下的全屏）返回 `资源配额已尽`（待办事项：分块传递）。
- **输入事件**：宿主在 canvas 后插入一个透明的 `<input data-yy-显示面输入="名称">` 接收键盘与输入法，点击 canvas 时聚焦它。`pointerdown`/`pointermove`/`pointerup` 转成指针事件（坐标以显示面左上角为原点、按物理像素取整，按钮号即 DOM 的 `button`；按下时捕获指针；相邻的指针移动合并）；`keydown`/`keyup` 转成按键事件，键名为 `左 右 上 下 回车 退格 空格` 或单个 Unicode 标量值，其余键不交付，组字期间的按键不交付；`input`（非组字）与 `compositionend` 把输入框里已提交的文字作为 `文字输入` 交付后清空输入框。canvas 的右键菜单被阻止。每个显示面有独立事件队列（上限 65536，满时丢最旧的），同一显示面第二个并发等候者得 `输入无效`；关闭后先交付一次 `显示面已关闭`，再等待返回 `资源已失效`。待办事项：输入法候选框固定在视口左上角，应跟随应用的光标。

**宿主原语**：`豫言_浏览器_显示(操作, 显示面号, 甲, 乙, 字节)`，操作为 `取得 尺寸 提交 等待`，返回（状态码, 四个整数, 文字）；状态码 1 至 7 依次为未获授权、资源暂不可用、资源已失效、资源不存在、资源已存在、资源配额已尽、输入无效，其余为宿主操作失败。实现在 `宿主/浏览器/图形.mjs` 的纯工厂 `创建显示能力`（宿主第一次调用时才动态导入 `图形.mjs`）。`等待输入事件` 挂起豫言栈，浏览器须支持 JSPI。

**验收**：`../图形显示浏览器/一致性验证/`（探针应用、真实 Chrome 运行步骤与验收清单）；宿主单元测试在 `宿主/浏览器/图形。测试.mjs`。
