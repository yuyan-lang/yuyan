# 云工网址定位适配

使用当前云工宿主的 URL 对象解析绝对及相对地址，向应用交付 `href`、`origin`、`pathname`、`search`、`protocol`、`hostname`、`host`、`port`、`username`、`password`、`hash` 十一项 JSON 文字，字段值全部取自宿主 URL 对象。输入文字先交给宿主自己的 `TextDecoder` 序列化成 JSON 字面量再拼进 `URL.parse` 的参数，因此控制字符与任意 UTF-8 都不会破坏参数；无法解析时 `URL.parse` 返回 null，适配把它转成可捕获的豫言异常，不让宿主异常越过 Wasm 边界。适配不发起网络请求，也不替应用决定哪些来源或路径可以访问。

不需要新的宿主原语；需要平台支持 `URL.parse`（云工的兼容日期已满足）。
