# 云工网址定位适配

借云工宿主之 URL 物析绝对与相对址，以 JSON 文授 `href`、`origin`、`pathname`、`search`、`protocol`、`hostname`、`host`、`port`、`username`、`password`、`hash` 十一项，诸字段皆取自宿主之 URL 物。所入之文先交宿主自身之 `TextDecoder` 书为 JSON 字面，而后并入 `URL.parse` 之参，故控字符及任意 UTF-8 不伤参；不可析则 `URL.parse` 返空，适配转之为可捕之事故，不令宿主之异越过 Wasm 之界。适配不发网，不代客定可访之源与径。

无须新宿主原语；平台须支持 `URL.parse`（云工之兼容日期已足）。
