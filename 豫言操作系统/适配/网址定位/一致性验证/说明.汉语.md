# 网址定位一致性验证（0.2.0）

本目录用真实的 Wasm 与 Node 宿主验证 `豫言操作系统网址定位` 0.2.0 的云工适配：

- `应用/网址定位一致性应用/`：试验应用。包描述存为 `网址定位一致性应用。包。豫.txt`，避免被 `yy豫构` 的全仓库包发现当成包解析；构建脚本 `建应用.sh` 会把它复制到暂存内的临时目录并改回原名。
- `网址定位一致性.test.mjs`：Node 测试，加载构建产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑（用私有暂存）

1. 建暂存（一次）：`建暂存.sh <暂存目录>`，它把语言仓的只读材料符号链接进来并复制编译器与构建工具。
2. 构建：`建应用.sh <暂存目录> 云工 <本目录>/应用/网址定位一致性应用 网址定位一致性`，产物在 `<暂存目录>/dist/网址定位一致性/`。
3. 测试：`cd <暂存目录> && node --test <本目录>/网址定位一致性.test.mjs`。产物根默认为当前目录下的 `dist`，可用环境变量 `产物根` 改写。

## 覆盖

- 十一个字段与 WHATWG URL 逐字相同、键序固定，覆盖默认端口、国际化域名、凭据、点段、编码、控制字符与制表换行、超长路径（60000 字节）；
- 无效网址、非 HTTP(S) 方案、非绝对根网址、结果方案不合规，都是可捕获的失败；相对引用（`..`、`?q`、`#h`、空串、协议相对）。

每个测试都断言真实 Wasm 的可观察行为；期望值凡能由平台标准实现给出的（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`）都取自同一标准实现，不手抄。
