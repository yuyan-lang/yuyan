# 网址定位一致性验证（0.2.0）

此目录以真 Wasm 与节点宿主验《豫言操作系统网址定位》0.2.0 之云工适配：

- `应用/网址定位一致性应用/`：试验之应用。包描述存为 `网址定位一致性应用。包。豫.txt`，以免为 `yy豫构` 之全仓包发现误析为包；构建脚本 `建应用.sh` 复之于暂存内之临目录而改回原名。
- `网址定位一致性.test.mjs`：节点之测，载构建之产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑（用私暂存）

一、建暂存（一次）：`建暂存.sh <暂存目录>`，符号链接语言仓只读之材，并复编译器与构建之器。
二、构建：`建应用.sh <暂存目录> 云工 <本目录>/应用/网址定位一致性应用 网址定位一致性`，产物在 `<暂存目录>/dist/网址定位一致性/`。
三、测试：`cd <暂存目录> && node --test <本目录>/网址定位一致性.test.mjs`。产物根默认为当前目录之 `dist`，可以环境变量 `产物根` 改之。

## 所覆

- 十一字段与 WHATWG URL 逐字相同、键序固定，含默认端口、国际化域名、凭据、点段、编码、控字符与制表换行、超长之径（六万字节）；
- 坏址、非 HTTP(S) 之方案、非绝对之根址、结果方案不合，皆为可捕之败；相对之引（`..`、`?q`、`#h`、空文、协议相对）。

每测皆断言真 Wasm 之可察之行；期望之值凡能由平台标准之实现给出者（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`），皆取自同一标准之实现，不手抄。
