# 云工持久独占适配

`独占。豫` 用对象状态的 `blockConcurrencyWhile` 与登记的回调实现[持久独占接口](../../../豫言操作系统接口/持久独占/规范.汉语.md) 0.3.0，只用云工薄宿主的通用原语。

- `执行持久独占` 以持久仓（持久事务的 `持久仓`）为第一个参数：持久仓取自 `事务持久仓` 时报“持久事务回调内不可启动独占区”，取自 `独占区持久仓` 时报“独占区内不可再启动独占区”；操作名须 1 至 128 字节，参数须是平台 `JSON.parse` 接受的 JSON 且不超过 8 MiB。核对通过后登记一个回调（`登记云工回调`），交给对象状态的 `blockConcurrencyWhile`。
- 平台调用回调时，回调经宿主对象 `豫言应用导出` 调用应用入口 `执行持久独占回调`，参数是 `持久独占区`（JS 数组〔0, 对象状态〕）、操作名与参数文字；入口返回的文字须是有效 JSON 且不超过 8 MiB。回调**总是成功返回** JS 数组〔成否, 结果或原因〕，区内的失败（入口抛出未捕获异常、结果无效、回调里的豫言异常）都作为原因返回，**不抛给平台回调**（平台会因此重置整个对象）；`执行持久独占` 再把失败转成可捕获的豫言异常（消息 `持久独占失败：…`）。回调用完即注销。
- `独占区持久仓` 用对象状态与它的 `storage` 造出所在为独占的持久仓，区内读写持久仓、开启事务、读写告警都用它。
- 适配不保存状态，没有顶层可变格。

本地 workerd 已验：区内等待外部输入输出时其他事件排队、多个区依次执行、区内失败不重置对象。后续版本的事项：旧宿主为独占区回调设的 25 秒墙钟时限随薄宿主去掉，回调超过平台 30 秒时对象被重置；从外层请求取得的持久仓带进区内再开独占区，适配查不出来。
