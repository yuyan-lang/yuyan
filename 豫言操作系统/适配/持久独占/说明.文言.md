# 云工持久独占适配

`独占。豫` 借对象之态之 `blockConcurrencyWhile` 与所登之回调，以承[持久独占之约](../../../豫言操作系统接口/持久独占/规范.文言.md)三版，惟用云工薄宿主之通用原语。

- `执行持久独占` 以久仓（持久事务之 `持久仓`）为首参：仓取自 `事务持久仓` 则报“持久事务回调内不可启动独占区”，取自 `独占区持久仓` 则报“独占区内不可再启动独占区”；操作名须一至一百二十八字节，参须为平台 `JSON.parse` 所受之 JSON 且不逾八 MiB。核既过，乃登一回调（`登记云工回调`），授对象之态之 `blockConcurrencyWhile`。
- 平台呼回调，则回调经宿主之物 `豫言应用导出` 呼客之入口 `执行持久独占回调`，参为 `持久独占区`（JS 数组〔0，对象之态〕）、操作名与参文；入口所返之文须为有效 JSON 且不逾八 MiB。回调**恒成而返** JS 数组〔成否，果或因〕，区内之败（入口抛未捕之异、果无效、回调中之豫言异）皆以为因而返，**不抛于平台之回调**（平台必因此重置整个对象）；`执行持久独占` 复转其败为可捕之豫言异（辞曰 `持久独占失败：…`）。回调用毕即注销。
- `独占区持久仓` 以对象之态与其 `storage` 造所在为独占之久仓，区内读写久仓、启事务、读写告警皆用之。
- 适配不存其态，无顶层可变之格。

本地 workerd 已验：区内候外物之出入则他事排队、诸区依次而行、区内败不重置对象。后续诸版之事：旧宿主独占回调二十五秒之墙钟时限随薄宿主而去，回调逾平台三十秒则对象被重置；以外层之请所取之仓携入区内复开独占，适配不能察之。
