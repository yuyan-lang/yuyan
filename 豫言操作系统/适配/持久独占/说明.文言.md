# 云工持久独占适配

`独占。豫` 借 `ctx.blockConcurrencyWhile` 与事重入，以承[持久独占之约](../../../豫言操作系统接口/持久独占/规范.文言.md)：`执行持久独占` 呼宿主 `云工持久独占执行安全`，宿主于 `blockConcurrencyWhile` 之回调中以 `durable-block` 之事重入 `_start`，入口以 `读取持久独占名`、`读取持久独占参数` 取入参，以 `完成持久独占` 定其果（宿主以原生 `JSON.parse` 验参与果，各不逾八 MiB）。区内之败，于回调内捕之而以为值返，**不抛于平台之回调**（平台必因此重置整个对象），适配复转为可捕之豫言异。适配察事类：惟持久对象之 `durable-*` 事（除 `durable-transaction`、`durable-block`）可开区。

`durable-block` 之事默墙钟二十五秒（平台三十秒重置线之内），可由宿主 `执行配置.json` 调至多三十秒。本地 workerd 4.129.0 已验：区内候外物之出入则他事排队、诸区依次而行、区内败不重置对象、逾三十秒则平台重置对象；云端待验，见 `豫言操作系统/宿主/云工/说明.文言.md` 之清单。
