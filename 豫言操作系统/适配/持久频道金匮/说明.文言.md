# 持久频道落盘适配

一程之内、跨事之具名文字之道：订阅得柄，发布依先后而达，待可限时，阖则先送已排之书而后告其因。其态在内存，随服务之程而生，不入于盘（规如此）。供豫言系统与本土之宿主用。

## 语义

- `订阅恒频道 频名`：核其名（一至六十四字节，字母、数或 `.` `_` `:` `-`），新订而授柄。
- `发布恒频道文字 频名 文`：文零至六万多字节；依先后续于其频诸活订，还所达之数；无其频则零。
- `待恒频道信 柄 时限`：时限零至三百六十万毫。有书则取首而还（零，文）；已终则（二，因）；至时限则（一，空）。待时以墙钟之毫自旋。
- `罢订阅恒频道 柄`：置为已终、因曰“订阅已取消”；幂等。
- `阖恒频道 频名 因`：举其频诸活订置为已终，还所阖之数；已排之书先交。
- `读恒频道订阅数 频名`：活订之数。

订阅之前所发不补；一订之内保序。名或文越限、时限越界、柄不存在者依规告祸或出态。

## 用法

```yuyan
寻观「豫寓恒道金匮榫」之「频道」之书。

「柄」者「订阅恒频道」于『页面事件』也。
「发布恒频道文字」于『页面事件』于『甲』。
「果」者「待恒频道信」于「柄」于「三六零零零零零」也。
「罢订阅恒频道」于「柄」。
```

## 后续之事项

- 待以自旋，耗算；服务之程有事件之环后宜改为挂起之待。
- 积压逾 1 MiB 而断、每实例六十四频、每频二百五十六订之上限、柄惟在本事内有效，皆未核。
- 不入盘：重启即失，与规合。
