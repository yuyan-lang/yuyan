# 环境文字云工适配

以薄宿主之通用原语「云工绑定」（`库/云工宿主` 之「物宿主」）承公共环境读文与绑定在否之断。宿主依许可核其类与名：未授则败曰“未授权的<种类>绑定：<名>”，已授而环境无之则败曰“绑定不存在：<名>”，余得绑之值。

- `读取授权环境文字` 以类 `ENV` 取值：值为文则原样而返；已授而阙（宿主告“绑定不存在”），或值空、`null`、`undefined`、`0`、`false` 诸伪者，返空文；未授之名与非文之真值（如物、数五），抛豫言之异“未授权的ENV绑定：<名>”“环境变量不是文字”。
- `授权绑定存在` 以类与名授同一原语：已授而在者依 JavaScript 之真伪答之（物型之绑为阳，文型之环境变量须非空），已授而阙为阴，未授抛豫言之异；类或名空者，抛可捕之“绑定种类为空”“绑定名称为空”。

公约以未授为部署之误，客不可恃而捕之；薄宿主之败皆为值，故此为豫言之异，客不接则标准库默认之处止当前之事。适配不缓存，亦不授环境之物于客。诺节应用宿主同以物桥行「云工绑定」，惟认 `ENV`（`--允许环境` 所授之环境变量），故此适配两处皆可行。
