# 环境文字云工适配

经薄宿主的通用原语「云工绑定」（`库/云工宿主` 的「物宿主」）实现公共环境文字读取与绑定存在判断。宿主按许可核对种类与名称：未授权时得失败“未授权的<种类>绑定：<名>”，已授权而环境里没有时得失败“绑定不存在：<名>”，其余得绑定的值。

- `读取授权环境文字` 以种类 `ENV` 取值：值是字符串时原样返回；已授权而缺失（宿主报“绑定不存在”）或值为空、`null`、`undefined`、`0`、`false` 等假值时返回空字符串；未授权的名称与非文字的真值（例如对象、数字 5）抛出豫言异常“未授权的ENV绑定：<名>”“环境变量不是文字”。
- `授权绑定存在` 把种类与名称交给同一原语：已授权且存在时按 JavaScript 真值回答（对象型绑定为阳，文字型环境变量须非空），已授权而缺失得阴，未授权抛出豫言异常；种类或名称为空抛出可捕获的“绑定种类为空”“绑定名称为空”。

规范把未授权归为部署错误，应用不能依赖捕获它；薄宿主的失败都是值，所以这里表现为豫言异常，应用不接住时由标准库的默认处理中止当前事件。适配不缓存，也不把环境对象交给应用。诺节应用宿主用同一份物桥实现「云工绑定」，只认 `ENV`（`--允许环境` 授权的环境变量），所以本适配在两边都能运行。
