# 环境文字一致性验证（0.2.0）

此目录以真 Wasm 与节点宿主验《豫言操作系统环境文字》0.2.0 之云工适配：

- `应用/环境文字一致性应用/`：试验之应用。包描述存为 `环境文字一致性应用。包。豫.txt`，以免为 `yy豫构` 之全仓包发现误析为包；构建脚本 `建应用.sh` 复之于暂存内之临目录而改回原名。
- `环境文字一致性.test.mjs`：节点之测，载构建之产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑（用私暂存）

一、建暂存（一次）：`建暂存.sh <暂存目录>`，符号链接语言仓只读之材，并复编译器与构建之器。
二、构建：`建应用.sh <暂存目录> 云工 <本目录>/应用/环境文字一致性应用 环境文字一致性`，产物在 `<暂存目录>/dist/环境文字一致性/`。
三、测试：`cd <暂存目录> && node --test <本目录>/环境文字一致性.test.mjs`。产物根默认为当前目录之 `dist`，可以环境变量 `产物根` 改之。

## 所覆

- `读取授权环境文字`：已授而有值、已授而阙（返空文）、为空、假值；未授之名与非文之值仍败；
- `授权绑定存在`：D1、SERVICE、ASSETS、R2、ENV 之有与无，空文之环境变量得阴，未授则败，空类或空名报可捕之事故。

每测皆断言真 Wasm 之可察之行；期望之值凡能由平台标准之实现给出者（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`），皆取自同一标准之实现，不手抄。

**须宿主补丁**：此测要求宿主具原语 `豫言_云工_授权绑定存在`（阙之则测径报错）。补丁加于 `豫言操作系统/宿主/云工/宿主.mjs` 中 `豫言_云工_绑定句柄` 一行之后：

```js
        // 文言：察绑定之在否；未授权者仍败，已授而阙者归阴，真值与 JavaScript 同。汉语：按种类与名称检查已授权绑定是否存在；未授权是部署错误仍抛出，已授权但缺失（undefined、null、空字符串等假值）返回 false。
        豫言_云工_授权绑定存在: (种类值, 名) => {
          const 种类 = 文字(种类值), 名称 = 文字(名);
          if (!许可[种类]?.includes(名称)) throw Error('未授权的' + 种类 + '绑定：' + 名称);
          return Boolean(环境?.[名称]);
        },
```
