# 显示、图形处理器、图形显示：节点一致性之验

节点与浏览器共一图形探针之应用：`../../图形显示浏览器/一致性验证/应用/图形探针/`。节点之式为显示、图形处理器、图形显示各取 `适配/显示节点/`、`适配/图形处理器节点/`、`适配/图形显示节点/`。

**自动之验皆用后台之窗**（`--显示面后台`：隐而不激，不夺前台），应用之参 `跳过输入` 略输入之组；输入之事惟人工验之，乃开可见之窗。宿主之术（授、依赖之缺、后台之窗、SDL 事之译、易窗、搬运而呈、清理）别有不开窗之单元测试 `豫言操作系统/宿主/节点/图形。测试.mjs`（伪 SDL 与伪 GPU），全树测试自行之。

**复行**（于语言仓之根；须先造 `yy双宿主构建`、`yy4_bs`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；勿与他构并行）

```sh
# 一、造探针
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 豫言操作系统/适配/图形显示浏览器/一致性验证/应用/图形探针 dist/节点图形探针
# 二、依赖安于仓外之目（下称 依赖目录）
npm install --prefix 依赖目录 @kmamal/sdl @kmamal/gpu
# 三、自动之验：后台之窗，略输入；当终以“探针完成：通过 35 项，失败 0 项”，退码零
node dist/节点图形探针/启动.mjs --授权显示面 像素画面=64x48 --授权显示面 图形画面=64x48 --显示面后台 --原生依赖目录 依赖目录 -- 跳过输入
# 四、依赖之缺：不给依赖之目；显示与取设备二组败于“资源暂不可用”，标准误各一告，不崩，退码零
node dist/节点图形探针/启动.mjs --授权显示面 像素画面=64x48 --授权显示面 图形画面=64x48 --显示面后台 -- 跳过输入
# 五、人工验输入（开可见之窗）：探针书“等待输入：…”后，于“输入画面”之窗点按、移指、按键、书文（可用输入法），终闭其窗
node dist/节点图形探针/启动.mjs --授权显示面 像素画面=64x48 --授权显示面 图形画面=64x48 --授权显示面 输入画面=320x240 --原生依赖目录 依赖目录 -- 人工输入
# 六、宿主之单元测试（不开窗）
node --test 豫言操作系统/宿主/节点/图形。测试.mjs
```

人工验时逐行核所书之“输入事件：…”：点按得 `指针按下 x,y,0` 与 `指针抬起 x,y,0`（坐标以窗之左上为原，物理之素；右键钮号二）；移指得 `指针移动`；方向、回车、退格、空格诸键得 `按键按下 左` 等语义之名；字母之键得单一之字（Shift 下为大写）；输入法所成之文得 `文字输入 …`；闭窗得 `显示面已关闭`，其后一行报“通过：人工输入…”。此行所开者可见之窗，并目验之：“像素画面”与“图形画面”二窗皆纯蓝（像素所交之一帧、GPU 所呈三帧之末帧）；后台之窗隐，自动之验不见窗中之画，惟读回离屏之帧纹理。

## 验证之录

**二〇二六年九月三十日，macOS arm64（苹果之芯，Metal），Node 26.3.0，@kmamal/sdl 0.11.13（SDL 2.32.8），@kmamal/gpu 0.2.1（Dawn）。**

| 项 | 果 |
| --- | --- |
| 自动之验（第三步） | 过三十五项，败零项，退码零，约五点四秒；连行三次皆同。以环境变量 `YY_NODE_NATIVE_DIR`、`YY_NODE_DISPLAY_BACKGROUND=1` 代二选，果同 |
| 显示 | 未授之名返 `未获授权`；六十四乘四十八点之窗，尺为一百二十八乘九十六（Retina）；字数不合、零宽返 `输入无效`；宽多一返 `资源暂不可用`；一帧不透之蓝素返 `画面已提交` |
| 图形处理器 | 限额 30150672384、30150672384、16384、65535、1024、16777216；缓冲写读、计算着色倍之、不合之 WGSL 逐条之诊、清屏读回、三角形中绿角黑、坏命令全列不行、毁后而用皆过 |
| 图形显示 | 纹理之式 `蓝绿红透八位`；未取即呈返 `输入无效`；三帧各再取得同一纹理、帧纹理读回四万九千一百五十二字即一百二十八乘九十六乘四、清屏而呈返 `画面已提交`、旧帧之命令返 `命令未提交`；二交互斥 |
| 后台之窗 | 行时每零点二秒采前台之应用（`lsappinfo front`），恒为原前台之应用，此进程之类为 BackgroundOnly；隐窗之上像素之交十次约一百四十六毫秒，WebGPU 呈十帧约九十六毫秒，不滞于候刷新，故不改用屏外之窗 |
| 依赖之缺（第四步） | `取得已授显示面`、`取得图形设备` 返 `资源暂不可用`，标准误各一行之告，退码零 |
| 输入之事与窗中之画 | 待人工之验（第五步）；SDL 之事之译与搬运而呈，单元测试覆之，搬运之着色于 Dawn 另验其逐字皆同。@kmamal/sdl 无注事之术，不能自合 |

**已知之病**：@kmamal/gpu 零点二点一每约百毫秒乃理异步之回调一次（弹误域约百毫秒，`mapAsync` 约二百毫秒），探针每帧（读回、交命令、呈现）约零点三秒，多耗于此；交互之渲染每帧至少候提交命令之误域一次，每秒约十帧。
