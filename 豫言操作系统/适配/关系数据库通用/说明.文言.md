# 关系数据库通用适配

本包以纯豫言行关系数据库接口四术，模块曰 `语句`。用者先立嵌入数据库查询会话，以 `嵌入数据库/关系查询/接口适配` 之 `登记关系库` 将所授名登于会话。读写共其内存关系库。

JSON 参数于 SQL 分词既成后缚于词元，以之存取数据。依 CREATE TABLE 之 INTEGER/INT/BIGINT、BOOLEAN/BOOL 及文字列声明，还整数、爻、串或空值。批量之术依内存快照循序而行，败则复诸行、列类及行号。

后续事项：接文件页树、验原生与裸机装载、增 SQL 诸法、自动养护索引、跨用者事务隔离。验收之记随嵌入数据库关系查询之说明而存。

`宿主提供.json` 因现有关系数据库适配之同一接口公开清单。接口所有者、名、版本、模块及四声明之签名，逐项皆同。实现之签名与平台装载，列入后续验收。

`测试/语句。测试。豫` 由本包 `语句` 召首行、诸行、执行及批执行四公开术。新版全链型验已过，Node 与 Mach-O arm64 预编二硬原生皆成，所书 `{"值":"甲","数":9}` 及成验之言，逐字节同。此验及普通包调用与内存会话；系统宿主正式绑定、装载、文件久存之接及裸机实机运行，列入后续验收。

节点宿主之支持表以关系数据库接口择此共用适配。`测试/规范绑定/` 客依并寻纯规范之名，由既有双宿主自动构建器尽验签名、绑定并造装载之簿；正式 `启动.mjs` 核装载而行四术，皆过。同一 `程序.wasm` 预编为硬原生而行，输出逐字同。今由调用者登记所授内存会话；裸机之行及持久关系会话，列入后续之事。

持久授权之门为嵌入数据库「登记关系存储」：调用者授目标名、已开键值库与快照键。四公约之签名仍旧，执行与批行成则经共用纯豫文存其会话，首行与全行之查读同会话。`测试/规范持久/` 由正式文件目录权于异进程存复，Node 正式发行已验。此文件节点绑定之客体，其硬原生平台文件导入之接仍在施作；纯快照核心与正式内存规范绑定已有两端之证。

原生正式文件之路循宿主直供之法，接公共文件与基础公约，关系接口仍绑定此共用实现。同一规范持久测试源，于 Node 与硬原生各自正式文件上下文中，异进程存复皆成，结果同；原生可写目录以 `--授权目录写` 授之。裸机与断电耐久仍施作。
