# 关系数据库规范持久测试

客体导入纯规范关系数据库与文件接口。调用者从宿主取得「关系持久」目录权，打开追加日志键值库，并将目标关系会话绑定到指定快照键。写入进程经共用适配执行 SQL 和批修改后自动保存；另一个进程以「恢复」参数读回快照，核对类型和插入号。两次运行均保留单独登记的旁会话。

运行时传入 `--授权目录 关系持久=专属测试目录`，恢复进程再传 `-- 恢复`。Node 与硬原生分别使用自己的目录。

原生构建临时选择文件与基础为宿主直接提供，关系接口仍绑定共用纯豫适配；运行使用 `--授权目录写 关系持久=专属目录`。两端文件绑定上下文各循既有路径，同一测试源码的写入和跨进程恢复结果一致。
