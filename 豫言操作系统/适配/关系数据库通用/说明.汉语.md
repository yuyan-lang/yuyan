# 关系数据库通用适配

本包以纯豫言实现关系数据库接口的四个函数，逻辑模块为 `语句`。调用者先建立嵌入数据库查询会话，并通过 `嵌入数据库/关系查询/接口适配` 的 `登记关系库` 将授权名登记到会话。读取和写入使用同一份内存关系库。

JSON 参数在 SQL 分词后绑定到词元；参数值参与数据存取。结果按 CREATE TABLE 的 INTEGER/INT/BIGINT、BOOLEAN/BOOL 与文字列声明返回整数、布尔、字符串或空值。批量函数在同一内存快照上依序执行，失败时恢复行、列类型和行号。

后续事项：文件页树接入、原生及裸机装载验收、更多 SQL 语法、自动维护索引、跨调用者事务隔离。当前验收记录随嵌入数据库的关系查询说明维护。

`宿主提供.json` 复用现有关系数据库适配的同一接口公开清单。接口所有者、名称、版本、逻辑模块与四个声明签名逐项相同。实际实现签名检查与平台装载列入后续验收。

`测试/语句。测试。豫` 从本包 `语句` 模块调用首行、全部行、执行和批执行四个公开函数。新版完整链类型检查通过，Node 与 Mach-O arm64 预编二硬原生实跑均通过，输出 `{"值":"甲","数":9}` 与通过提示逐字节一致。该用例覆盖普通包调用和内存会话；系统宿主正式绑定、装载、文件持久接入及裸机实际运行列入后续验收。
