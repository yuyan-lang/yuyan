# 关系数据库通用适配

本包以纯豫言实现关系数据库接口的四个函数，逻辑模块为 `语句`。调用者先用嵌入数据库 `结构化查询/库态` 的「新问会话」建立查询会话，再通过 `芥子/关系问/榫合` 的 `登问簿` 将授权名登记到会话。读取和写入使用同一份会话；宿主可用同一模块的 `行问簿脚本` 执行迁移等多语句文字。

SQL 由嵌入数据库的结构化查询按 SQLite 语义执行（触发器、约束、外键、UPSERT、RETURNING 等，见嵌入数据库《结构化查询/SQLite兼容实施记录.md》）。JSON 参数按语句里的参数号绑定为值：字符串、整数、布尔（整数一、零）与空值；结果按值的类型返回整数、实数、字符串、空值或字节数组。批量函数整批原子执行，失败时恢复批前的数据与事务状态。

后续事项：文件页树接入、原生及裸机装载验收、跨调用者事务隔离。当前验收记录随嵌入数据库的关系查询说明维护。

`宿主提供.json` 复用现有关系数据库适配的同一接口公开清单。接口所有者、名称、版本、逻辑模块与四个声明签名逐项相同。实际实现签名检查与平台装载列入后续验收。

`测试/语句。测试。豫` 从本包 `语句` 模块调用首行、全部行、执行和批执行四个公开函数。新版完整链类型检查通过，Node 与 Mach-O arm64 预编二硬原生实跑均通过，输出 `{"值":"甲","数":9}` 与通过提示逐字节一致。该用例覆盖普通包调用和内存会话；系统宿主正式绑定、装载、文件持久接入及裸机实际运行列入后续验收。

节点宿主支持表将关系数据库接口映到本共用适配。`测试/规范绑定/` 客体依赖并导入纯规范身份，通过既有豫构发行构建执行完整签名检查、绑定与装载清单生成；正式 `启动.mjs` 的装载核对及四接口实跑已通过。同一 `程序.wasm` 经硬原生预编二实跑，输出逐字相同。当前授权模型由调用者登记内存会话；裸机运行与持久关系会话列入后续事项。

持久授权入口为嵌入数据库的「登关系藏」：调用者给出目标授权名、已开启的键值库和快照键。四个公开规范签名沿用原声明，执行和批执行成功后经共用纯豫模块保存该会话，首行与全部行查询读取同一会话。`测试/规范持久/` 用正式文件目录权在独立进程保存及恢复，Node 正式发行已验。该文件节点绑定客体的硬原生平台文件导入连接继续实施；纯快照核心与正式内存规范绑定已有双端证据。

原生正式文件路径通过既有宿主直供规则连接公共文件与基础接口，关系接口继续绑定本共用实现。同一规范持久测试源码在 Node 与硬原生各自正式文件上下文中完成独立进程保存和恢复，结果一致；原生可写目录选项为 `--授权目录写`。裸机与断电耐久继续实施。
