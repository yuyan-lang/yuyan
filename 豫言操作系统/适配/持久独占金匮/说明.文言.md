# 持久独占落盘适配

持久之户之并发独占之区：区中之读写与外调不与诸事交错。其态惟在进程（服务之程次第办理），不须入盘。供豫言系统与本土之宿主用。

## 语义

- `行恒独占 仓 操作名 参数`：名一至百二十八字节，参须为有效 JSON 而不逾八兆；核而后呼 `登恒独占回音` 所登之回音（受区、名、参），还果之 JSON 文。
- 区中再启则告 `持久独占失败：独占区内不可再启动独占区`；回音抛祸或果非法者告 `持久独占失败：…`，不重置其物。
- `独占区恒仓 区`：回音之中取其所属之仓。

## 用法

```yuyan
寻观「豫寓恒专金匮榫」之「独占」之书。

「登恒独占回音」于「我的回音」。
「行恒独占」于「仓」于『计数』于『{}』。
```

## 后续之事项

- 区内诸事之候与三十秒之限由服务之程之事件环任之；此适惟守“次第与不叠”。
- 以 `事务恒仓` 开独占之区当告祸，须知其仓之从来（今 `恒仓` 不带来历），俟与持久事务之适共改。
