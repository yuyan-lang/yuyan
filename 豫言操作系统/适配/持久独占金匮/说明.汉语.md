# 持久独占落盘适配

持久对象的并发独占区：区内的读写与外调不与其他事件交错。状态只在进程里（服务程序串行办理），不需要落盘。供豫言系统与原生宿主上的服务程序使用。

## 语义

- `行恒独占 仓 操作名 参数`：操作名 1 至 128 字节，参数须是有效 JSON 且不超过 8 MiB；核对后调用 `登恒独占回音` 登记的回音（收独占区、操作名、参数），返回结果 JSON 文字。
- 区内再开独占区报 `持久独占失败：独占区内不可再启动独占区`；回音抛错或结果不是有效 JSON 时报 `持久独占失败：…`，不重置对象。
- `独占区恒仓 区`：回音里取所属对象的持久仓。

## 用法

```yuyan
寻观「豫寓恒专金匮榫」之「独占」之书。

「登恒独占回音」于「我的回音」。
「行恒独占」于「仓」于『计数』于『{}』。
```
