# 网页储存浏览器适配

`储存。豫` 行[网页储存之约](../../../豫言操作系统接口/网页储存/规范.文言.md)之诸函数：`读取网页储存`、`写入网页储存`、`删除网页储存`。`实现接口。豫` 定公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（须候者）二原语，操作名为 `储存.读取`、`储存.写入`、`储存.删除`；败则以（阴，错误文）返，本适配转为豫言事故，不使 JavaScript 之异常越 Wasm 之界。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`。区惟认“会话”（sessionStorage）与“本地”（localStorage，测试可由 `创建浏览器宿主({储存})` 注入）；键至多五百一十二、值至多一百零四万八千五百七十六 UTF-16 码元。读之果以首字标其有无（“1”加值，或“0”），适配拆为（爻，字符串）；写遇配额或被禁则返 `0`，适配转为阴，不发事故。

**运行之要**：候事之函数挂豫言之栈，浏览器须支持 JSPI；八新包与网页事件包共一统一事列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用“前端接口探针”、宿主单元测试与 JSDOM 加真实 Wasm 之一致性测试，说明见其中之 `说明.文言.md`）。
