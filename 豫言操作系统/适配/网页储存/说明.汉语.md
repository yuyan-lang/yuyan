# 网页储存浏览器适配

`储存。豫` 实现[网页储存接口](../../../豫言操作系统接口/网页储存/规范.汉语.md)的全部函数：`读取网页储存`、`写入网页储存`、`删除网页储存`。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（需要等待的操作）两个原语，操作名为 `储存.读取`、`储存.写入`、`储存.删除`；失败以（阴，错误文）返回，再由本适配转成豫言事故，不让 JavaScript 异常越过 Wasm 边界。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`。区域只认“会话”（`sessionStorage`）与“本地”（`localStorage`，测试可经 `创建浏览器宿主({储存})` 注入）；键至多 512、值至多 1048576 个 UTF-16 码元。读取的结果以首字符标示存在（“1”加值，或“0”），适配拆成（爻，字符串）；写入遇配额或禁用返回 `0`，适配转成阴，不抛事故。

**运行要求**：等待类函数挂起豫言栈，浏览器须支持 JSPI；八个新包与网页事件包共用同一个统一事件队列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用 `前端接口探针`、宿主单元测试与 JSDOM＋真实 Wasm 的一致性测试，说明见其中的 `说明.汉语.md`）。
