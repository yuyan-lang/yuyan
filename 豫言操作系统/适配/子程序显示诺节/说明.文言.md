# 子程序显示诺节适配

`子程序显示。豫` 于诺节宿主行[子程序显示接口](../../../豫言操作系统接口/子程序显示/规范.文言.md) 〇点一，`实现接口。豫` 定公包之身份与版本；节点宿主支持之表（`豫言操作系统/宿主/节点/宿主支持清单.tsv`）为诺节之式择此目录。

诸术皆返未支持：`启动带显示面的子程序` 得 `子程序启动失败` 载 `资源暂不可用`，`取子程序画面` 得 `子程序画面失败` 载 `资源暂不可用`，`送子程序输入事件` 与 `设置子程序显示面尺寸` 返五十八。适配惟用豫言之码，皆成于客内。

目录名用“诺节”：双宿主构建之原生之式依 `子程序显示原生`、`子程序显示节点`、`子程序显示` 之序寻适配，三者皆无，此接口留原生执行器以带型之导入径行之（原语百八十二至百八十五）。

后版：诺节改经 `node:ffi` 召原生显示之库，则径承原生执行器之管道代办。
