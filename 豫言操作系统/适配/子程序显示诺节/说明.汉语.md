# 子程序显示诺节适配

`子程序显示。豫` 在诺节宿主上实现[子程序显示接口](../../../豫言操作系统接口/子程序显示/规范.汉语.md) 0.1.0，`实现接口。豫` 固定公共包身份与版本；节点宿主支持清单（`豫言操作系统/宿主/节点/宿主支持清单.tsv`）为诺节模式选用本目录。

各函数返回暂不支持：`启动带显示面的子程序` 得 `子程序启动失败` 携带 `资源暂不可用`，`取子程序画面` 得 `子程序画面失败` 携带 `资源暂不可用`，`送子程序输入事件` 与 `设置子程序显示面尺寸` 返回五十八。适配只用豫言代码，全部在客体内完成。

目录名用“诺节”：双宿主构建的原生模式按 `子程序显示原生`、`子程序显示节点`、`子程序显示` 的次序找适配，三者都没有，本接口留给原生执行器经带类型导入直接实现（原语 182–185）。

后续版本：诺节改经 `node:ffi` 调原生显示库后，直接继承原生执行器的管道代办。
