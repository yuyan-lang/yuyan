# 豫言操作系统适配

此 `豫言操作系统/适配/` 之父包也，唯有包述与此说，无模。登诸接口之适配包，其序从[接口总纲](../../豫言操作系统接口/总纲.文言.md)能力组之表（表见汉语本），同一接口之诸宿主变体（节点、浏览器、云工）相次；末为 `基础/测试/` 下二验收之程，其依基础适配，依制登于此包。

- 适配之包述不入接口清单之摘要，改之不必重生 `宿主提供.json`。
- 绑定之具复适配之包述以为绑定之包，「包含在」亦随之；绑定之包唯于构建之目经手书之包上下文而用，豫构不校其层级。
- 增适配者，依前序登于此包之「包含包」，新包书「包含在」。
- 桥接之包（如张量文件）之适配，与所桥接口之同宿主适配同构：自动之式依传递之闭而绑应用所用诸接口，包上下文中桥接包之绑定包依所桥接口之绑定包，即其适配之源；故桥接之适配可径引所桥之接口之模，解其适配之私构（如文件节点之 `节点文件柄`、张量计算节点之 `节点张量上下文`）以取宿主之号，并用其辅助之函。是以桥接之适配惟配同宿主之变体（节点配节点），包述依所桥之接口包；接口检查器惟较其签名，不析实现之模之引，绑定之具无须改。
