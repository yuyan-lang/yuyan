# 原生立方演示

于林檎原生之窗逐帧以图形处理器画一带深测与光照之旋立方，以验图形处理器之接口二版之绘管、深道与图映交换之链之呈。

- 着色之源 `立方。着色器。豫`（同「点染试」之样例「立方」）：顶点以合矩（透视、观、模之积）移其位，以模之转矩转其法，环境三分、漫射七分以施底色；片元出其色。豫言编译器译之为 MSL 而授金属。
- 每帧：取图映之帧纹（跨帧沿用，所存不自动清零），窗大易则复建深纹，书此帧之均匀（模绕纵轴转帧序之千分二十一，绕横轴转千分十三），交一深道（清屏深灰、清深为一、依三十二位之索画立方，比法小于通过），乃呈之；一毫秒问其入，窗闭则止。
- 终书每帧之均时：取帧纹、渲染提交（编、交而候图形处理器毕）、呈（读回帧纹而授像素之显）三段，每四帧另测独读回，及并候入之墙钟。

## 构与行

于 macOS（若 pit-mac）发行原生之程，乃于本机后行之：

```sh
豫构 发行 原生 豫言操作系统/适配/图形显示原生/立方演示 dist/立方演示 --包根 库 --包根 豫言操作系统/适配
dist/立方演示/程序。林檎。豫行 --授权显示面 主窗口=800x600 --显示面后台 600
```

末参为帧数，缺则六百。每帧之时之测见[图形显示原生适配](../说明.文言.md)“每帧之时”一节（pit-mac），本机早先之截图在仓外 `豫言数据/九州/图枢截图/`。
