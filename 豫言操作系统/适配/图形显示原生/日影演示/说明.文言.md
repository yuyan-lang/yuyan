# 原生日影演示

于林檎原生之窗，逐帧以图形处理器画带纹之地与四十九例化之立方，有日之平行光之影、高动态之绘与调色、四重采样，以验图形处理器接口五版之纹与渐远、可采之深纹与比较采样、逐例之布、半精之鹄与多采。

- 着色之源 `日影。着色器。豫`：方影之顶点移立方入日之光空；方、地之顶点出光空之位（先循法向外推约二影图之纹素，以免掠面生竖条之自影）；受光量于影图依比而采（偏随坡增，线滤之比较采器为二乘二之渐近之滤）；照明为“天光加日光乘漫乘受光”之高动态之色；调色之片元乘曝光，行 ACES 之调与伽马之正。豫言编译器译为 MSL 授金属。
- 资：二百五十六见方棋噪之地纹（九层渐远，以 `衍多级纹理` 衍之，线滤、复寻）；二千零四十八见方之影图（深度单精度，兼采样之用）；随窗之大复建之四采半精之色纹、四采之深纹与合入之半精之纹；立方之顶与索、每例三十二字（偏、高、色）之例缓、地之顶与索。
- 管（皆以 `置全述渲染管线`）：惟书深之影管（片元之口空）、例化立方之管（剔背）、地管、调色之管；主道之二管采数为四。
- 每帧：向显示面之交换之链取今可绘之纹，依窗之大备纹，书均匀（镜在半径三十、高十六之圆上徐转，日仰约四十二度、方位缓移）；影道（`全述渲染通道`，惟深附）、主道（多采色附合入半精之纹，加多采之深附）、调色之道（全屏三角画于可绘之纹）分三交而各计其时；每四帧一帧合三道于一交，以较分交之费；乃以 presentDrawable 呈之。窗闭或帧满则止，书诸段之均时。

## 构与行

于 macOS（如 pit-mac）以具四版着色内建之豫构构之，乃于本机后台行之：

```sh
豫构 构建 原生日影演示 --输出 日影演示。林檎。豫行 -j 12
./日影演示。林檎。豫行 --授权显示面 主窗口=1600x900 --显示面后台 600 /tmp/日影.png
```

首参为帧数，缺省六百；次参有便图之径，则终前别建常纹，画一帧（三道合一交，不呈），读回而以蓝红二道易为红绿蓝之序，著为便图（交换之链可绘之纹私存，不可读回）。每帧之时见[图形显示原生适配](../说明.文言.md)“每帧之时”一节，截图在仓外 `豫言数据/九州/图枢截图/`。
