# 原生日影演示

林檎原生窗口里逐帧用图形处理器画一片带纹理的地面与四十九个实例化的立方体，有太阳平行光的阴影、高动态范围渲染加色调映射与四倍多重采样，验收图形处理器接口 0.4.0 的纹理与渐远层、可采样的深度纹理与比较采样、逐实例布局、半精度目标与多重采样。

- 着色源 `日影。着色器。豫`：方影顶点把立方体变到太阳的光空间；方顶点、地顶点带出光空间位置（先把世界位置沿法向外推约两个阴影图纹素，免得掠射的面起竖条状的自影纹）；受光量在阴影图上按比较采样取受光（偏移随坡度变大，线性过滤的比较采样器做二乘二百分比渐近过滤）；照明是“天光加太阳光乘漫射乘受光”的高动态范围颜色；调色片元乘曝光、做 ACES 色调映射与伽马校正。豫言编译器把它译成 MSL 交给金属。
- 资源：二百五十六见方的棋盘噪声地面纹理（九层渐远，由 `衍多级纹理` 生成，线性过滤、重复寻址）；二千零四十八见方的阴影图（深度单精度，兼采样用途）；随窗口尺寸重建的四倍多重采样半精度颜色纹理、四倍多重采样深度纹理与合入用的半精度纹理；立方体顶点与索引、每实例三十二字节（偏移、高度、颜色）的实例缓冲、地面顶点与索引。
- 管线（都用 `置全述渲染管线`）：只写深度的阴影管线（片元入口为空）、实例化立方体管线（剔除背面）、地面管线、色调映射管线，后两条之前的主通道采样数为四。
- 每帧：取图映帧纹理，按窗口尺寸备纹理，写均匀缓冲（相机在半径三十、高十六的圆上慢转，太阳仰角约四十二度、方位缓移）；阴影通道（`全述渲染通道`，只有深度附件）、主通道（多重采样颜色附件合入半精度纹理，加多重采样深度附件）、色调映射通道（全屏三角形画进帧纹理）分三次提交并各自计时；每四帧有一帧把三个通道合在一次提交里，用来比较分次提交的开销；再呈现。窗口关闭或画满帧数就停，印出各段平均耗时。

## 构建与运行

在 macOS 上（如 pit-mac）用含 0.4.0 着色内建的豫构构建，再在本机后台运行：

```sh
豫构 构建 原生日影演示 --输出 日影演示。林檎。豫行 -j 12
./日影演示。林檎。豫行 --授权显示面 主窗口=1600x900 --显示面后台 600 /tmp/日影.png
```

第一个参数是帧数，缺省六百；第二个参数给了便图路径时，退出前再画一帧（三个通道合一提交，不呈现）写成便图。每帧耗时的实测见[图形显示原生适配](../说明.汉语.md)“每帧耗时”一节，截图在仓外 `豫言数据/九州/图枢截图/`。
