# 持久频道云端复验

持久频道与组合范例“服务商连接缩影”于本机 wrangler dev（真 workerd、真持久对象与 D1）之黑盒复验，以[验收驱动](../../../../../库/考成/包说明.文言.md)书之，一令毕“随需构试验之应用 → 起 wrangler → 行诸用例 → 止 wrangler（并 workerd 之子进程）”。

- `持久频道云端复验。测试。豫`：九例——跨请订与发、逾时之精、闭、六十四 KiB 与零长之讯、订限二百五十六与积压之断、一订之内三千条之讯、频道限六十四、真 D1 上先订后放之去重、客断后为频道之讯所唤而收尾。
- `服务商连接云端复验。测试。豫`：组合范例端到端一例——连之首帧与心跳、派发与分片、调用方止而服务商受 cancel、新连代旧连、服务商断而见察。
- `wrangler.jsonc`：本机复验之 wrangler 配置，含兼容之标 `enable_request_signal`（请求信号止乃能察客断）。
- `rig.mjs`：Worker 一侧之转发外壳，与产物之 `入口.mjs` 同置一目录，依请求头 `x-do` 转请于异持久对象实例（缺则 main）；有正文之请先尽读其正文乃转，免持久对象未读正文而先答时，转送于答后复读请流，wrangler dev 视为致命之误而退。

于仓根行之：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/持久频道/一致性验证/云端复验/持久频道云端复验。测试。豫 --输出 持久频道云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 持久频道云端复验.wasm
./豫构。林檎。豫行 文件 豫言操作系统/适配/持久频道/一致性验证/云端复验/服务商连接云端复验。测试。豫 --输出 服务商连接云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 服务商连接云端复验.wasm
```

wrangler 次第取环境变量 `云工命令行路径`、仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；皆无则书“跳过”而以零退。产物 `dist/持久频道一致性/`、`dist/服务商连接缩影/` 不存（或环境变量 `重建云工应用=1`）则以 `双宿主构建.wasm` 构之。CI 无 wrangler，全树测试于此目录惟验其类。
