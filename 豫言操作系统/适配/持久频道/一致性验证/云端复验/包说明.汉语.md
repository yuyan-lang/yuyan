# 持久频道云端复验

持久频道与组合范例“服务商连接缩影”在本机 wrangler dev（真 workerd、真实持久对象与 D1）里的黑盒复验，用[验收驱动](../../../../../库/考成/包说明.汉语.md)写成，一条命令完成“按需构建试验应用 → 起 wrangler → 跑全部用例 → 停 wrangler（含 workerd 子进程）”。

- `持久频道云端复验。测试。豫`：九个用例——跨请求订阅与发布、超时精度、关闭、64 KiB 与零长消息、订阅上限 256 与积压断开、一个订阅内三千条消息、频道上限 64、真实 D1 上先订阅再回放的去重、客户端断开后被频道消息唤醒并收尾。
- `服务商连接云端复验。测试。豫`：组合范例端到端一例——连接首帧与心跳、派发与分片、调用方取消后服务商收到 cancel、新连接替换旧连接、服务商断开后被察觉。
- `wrangler.jsonc`：本机复验用的 wrangler 配置，含兼容标志 `enable_request_signal`（请求信号中止才能发现客户端断开）。
- `rig.mjs`：Worker 侧的转发外壳，与产物的 `入口.mjs` 放在同一目录，按请求头 `x-do` 把请求转给不同的持久对象实例（缺省 main）；带正文的请求先读完正文再转发，免得持久对象没读正文就作答时，转发在响应之后再读请求流，wrangler dev 把这当成致命错误而退出。

在仓库根目录运行：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/持久频道/一致性验/云端复验/持久频道云端复验。测试。豫 --输出 持久频道云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 持久频道云端复验.wasm
./豫构。林檎。豫行 文件 豫言操作系统/适配/持久频道/一致性验/云端复验/服务商连接云端复验。测试。豫 --输出 服务商连接云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 服务商连接云端复验.wasm
```

wrangler 依次取环境变量 `云工命令行路径`、仓库旁云仓的 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；没有就打印“跳过”并以零退出。产物 `dist/持久频道一致性/`、`dist/服务商连接缩影/` 不存在（或环境变量 `重建云工应用=1`）时用 `双宿主构建.wasm` 构建。CI 没有 wrangler，全树测试对本目录只做类型检查。
