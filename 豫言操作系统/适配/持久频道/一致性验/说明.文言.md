# 持久频道一致性验证

此目录验[持久频道公约](../../../../豫寓榫卯/持久频道/规范.文言.md)之云工适配。试验应用在 `应用/`（为免全仓库发现包时误析，包描述存为 `持久频道一致性应用。包。豫.txt`，构建时改回 `持久频道一致性应用。包。豫`），Node 之测为 `持久频道一致性.test.mjs`：**同一宿主对象上并发诸 `durable-fetch`**，以拟同一持久对象实例之诸事（一宿主对象一程序实例，频道表在实例之顶层可变之格，其域与真实 Durable Object 合；`新宿主` 每造新宿主对象，即新持久对象实例）。所涵：跨事订与发（订后必达、订前不补、事毕后订数归零）；三订者按序各得其一；诸发者并发则每订之内同一发者保序而无失；候之逾时（不为订数之探所增减）、零超时轮询、越界之时抛异；闭（已排之讯先交，再得状态二与因，同名可复订）；撤幂等而撤后再候得状态二；无效之柄抛异，订阅柄为随机 UUID；订限二百五十六（第二百五十七抛可捕之异）与频道限六十四（第六十五抛可捕之异）；积压逾一 MiB 而被断（因文、其后不复达）；一订之内收发五千条；文字之则（零与六万五千五百三十六字节可发，六万五千五百三十七与字节 0xFF 起首者拒，多字节按字节计）；频道名之则；常 `fetch` 之事不依事类而拒（频道名照常而核）；异宿主对象不相通；讯按字节原样往返（NUL、控制字节、换行、增补平面之字）；**先订、后放、再并即时**之范（含凭 `Last-Event-ID` 重联，订与读首之间窗内所来之事恰现一次，自中序号续读，四追加者并发加三于异时起之流，每流恰各见每事一次）。二则记为待办（薄宿主不知事之何时毕，见[适配说明](../说明.文言.md)之待办之事）：他事所得之订阅柄当失效；事毕当自撤本事所遗之订。

`组合范例/` 乃以二包实现之“服务商连接”缩影，见[组合范例说明](组合范例/说明.文言.md)。

## 复行

于构建根行之（语言仓根本身即可，须已依今之源码成 `豫构`（云工之式复制 `物桥.mjs`）；用法与依赖之解见[豫构发行说明](../../../../应用/豫构/文档/发行.文言.md)）。试验应用又用网页服务、网页事件流与关系数据库三云工适配，组合范例另用时间适配。编译缓存以编译器可执行文件之修改时间为准，数构建同用一编译器则共其缓存（缓存原子而书，可并行）。

一、构建试验应用：`./豫构。林檎。豫行 发行 云工 <本目录>/应用 dist/持久频道一致性`，产物在 `dist/持久频道一致性/`。
二、行测（Node 二十六以上）：`env 产物目录=<构建根>/dist/持久频道一致性 node --test --test-force-exit 持久频道一致性.test.mjs`（于此目录行之；`<构建根>` 谓构建根之绝径）。预期通二十二、待办二。`scheduler.wait` 之垫片见 `工具.mjs` 之 `造全局`。

## 于本地 workerd 复行

`云端复验/` 者，以[验收驱动](../../../../库/考成/包说明.文言.md)书之豫言测包，见[其说明](云端复验/包说明.文言.md)。一令毕之：求 wrangler（环境变量 `云工命令行路径`，或仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；皆无则书“跳过”而以零退）→ 产物 `dist/持久频道一致性/` 不存则以 `双宿主构建.wasm` 构之（环境变量 `重建云工应用=1` 则强重构）→ 于暂存之工作目录纳产物、`云端复验/wrangler.jsonc`（含兼容标志 `enable_request_signal`；事件流转发须请求信号方能察客断）与 `rig.mjs`，依 `应用/建表.sql` 建 D1 表 → 于空端口起 `wrangler dev --local` → 逐一行用例 → 止 wrangler（并 workerd 之子进程）。于构建根行之：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/持久频道/一致性验证/云端复验/持久频道云端复验。测试。豫 --输出 持久频道云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 持久频道云端复验.wasm
```

每例用己之频道名；“频道限六十四”一则以 `x-do` 请求头指向专属持久对象实例，盖订不随事毕而收，会尽主实例六十四频道之额。有败则以退码一终，而存工作目录与 `wrangler.log`。CI 无 wrangler，全树测试于 `云端复验/` 惟验其类。

薄宿主上已于 Wrangler 4.129.0 尽通过（九项）：跨请求订与发、逾时之精、闭、六十四 KiB 与零长之讯、二百五十六与积压、三千条之讯、六十四频道之限（第六十五抛豫言之异，试验应用答 HTTP 500）、真实 D1 上之放回去重、客断后事为讯所唤而撤订（断后复发三条而后察）。云端之行留待验之。
