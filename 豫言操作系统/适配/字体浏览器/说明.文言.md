# 字体浏览器适配

`字样。豫` 于浏览器宿主行[字体接口](../../../豫寓榫卯/字体/规范.文言.md) 零点一点零。`实现榫卯。豫` 定公约之身份与版；豫构发行于浏览器之式先取此目（`字体浏览器`）。

**字体何以声明**：页以 `<link data-yy-字体="族名" href="字体文件之址">` 声明各族名之字体文件，字体集可加 `data-yy-字体序号`（缺则为零）；此元素亦可兼书 `rel="preload" as="font" crossorigin`，令浏览器先取之。未声明之族名，取得则返 `资源不存在`。族名以正斜起者，按径取字体：浏览器宿主无可列之系统字体目，此支返 `资源不存在`，字谱之属在浏览器中惟列页面所宣之体。通用之族名与常见之具体族名各书一条；粗体之族名惟页有真粗文乃书，不书则客取不到真粗面，退常规而仿之。例：

```html
<link rel="preload" as="font" crossorigin href="字体/自由无衬线常规.ttf" data-yy-字体="无衬线">
<link rel="preload" as="font" crossorigin href="字体/自由无衬线常规.ttf" data-yy-字体="sans-serif">
<link rel="preload" as="font" crossorigin href="字体/自由衬线常规.ttf" data-yy-字体="serif">
<link rel="preload" as="font" crossorigin href="字体/自由衬线常规.ttf" data-yy-字体="衬线">
<link rel="preload" as="font" crossorigin href="字体/自由等宽常规.ttf" data-yy-字体="monospace">
<link rel="preload" as="font" crossorigin href="字体/自由等宽常规.ttf" data-yy-字体="等宽">
<link rel="preload" as="font" crossorigin href="字体/自由衬线粗体.ttf" data-yy-字体="自由衬线粗体">
<link rel="preload" as="font" crossorigin href="字体/思源黑体.otf" data-yy-字体="汉字">
<link rel="preload" as="font" crossorigin href="字体/思源黑体.otf" data-yy-字体="符号">
```

网页行在之页 `宿主/浏览器/行在/行在.html` 依此式宣之：文楷用 `../字体.ttf`，无衬线、汉字、符号、圆体、数学用 `../字体/思源黑体.otf`，手写、装饰、仿宋用 `../字体/原始字体.ttf`，等宽用 `../字体/默认等宽黑体.otf`；衬线、无衬线与等宽中度量相合之名（`serif`、`sans-serif`、`monospace`、`Arial`、`Helvetica`、`Times New Roman`、`Times`、`Courier New`、`Courier`）与 `自由衬线`、`自由无衬线`、`自由等宽` 三族各分之常、粗、斜、粗斜皆用 `../字体/自由*.ttf`；`黑体`、微软雅黑、`宋体`、`Menlo` 等具体之名与 `system-ui`、`ui-*` 等通用之名亦各书一条。`字体基` 网址之参另指字体之目，`字体` 之参以诸族共指一文（旧试之用）。

**缺字之退**：浏览器之适配惟依页所宣之族名授文。字体选取之库依码于族链上逐字查码表，链末加 `sans-serif`、`汉字`、`emoji`、`符号`，对应页所宣之 `自由无衬线`、`汉字`、`表情`、`符号`；`汉字` 族供自由衬线等比例西文缺汉字时退之。今发行不携表情之字，页不宣 `表情`，表情之码落于 `汉字` 或 `符号` 之字或 `.notdef`。

**宿主原语**：`豫言_浏览器_字体(操作, 族名, 号, 偏移, 长度)`，返（码、号、长、集序、字、文），实于 `宿主/浏览器/图形.mjs` 之 `创建字体能力`（`宿主.mjs` 初用乃动态载 `图形.mjs`）。初取依 `href` 取全文件而存之（挂起豫言之栈，须 JSPI），后同名得同号；取之败则返 `宿主操作失败` 而附 HTTP 之状。读依偏移切之，一次之限十六兆。待办事项：大字体全取占内存，后可依 HTTP Range 分段取之。

**校验**：同诺驿之适配，先验读之范围、一次之限与零长，乃交宿主。

**验收**：宿主之单元测试在 `宿主/浏览器/图形。测试.mjs`（伪文档与伪 fetch）；真浏览器与字体探针之验见 `../字体诺驿/一致性验/`。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「网览东道」之「字样本术」之「网览字样操作」（旧外调名 `豫言_浏览器_字体`）。宿主实此诸导入，与旧原语同。
