# 字体浏览器适配

`字体。豫` 于浏览器宿主行[字体接口](../../../豫言操作系统接口/字体/规范.文言.md) 零点一点零。`实现接口。豫` 定公约之身份与版；双宿主构建于浏览器之式先取此目（`字体浏览器`）。

**字体何以声明**：页以 `<link data-yy-字体="族名" href="字体文件之址">` 声明各族名之字体文件，字体集可加 `data-yy-字体序号`（缺则为零）；此元素亦可兼书 `rel="preload" as="font" crossorigin`，令浏览器先取之。未声明之族名，取得则返 `资源不存在`。

**宿主原语**：`豫言_浏览器_字体(操作, 族名, 号, 偏移, 长度)`，返（码、号、长、集序、字、文），实于 `宿主/浏览器/图形.mjs` 之 `创建字体能力`（`宿主.mjs` 初用乃动态载 `图形.mjs`）。初取依 `href` 取全文件而存之（挂起豫言之栈，须 JSPI），后同名得同号；取之败则返 `宿主操作失败` 而附 HTTP 之状。读依偏移切之，一次之限十六兆。待办事项：大字体全取占内存，后可依 HTTP Range 分段取之。

**校验**：同诺节之适配，先验读之范围、一次之限与零长，乃交宿主。

**验收**：宿主之单元测试在 `宿主/浏览器/图形。测试.mjs`（伪文档与伪 fetch）；真浏览器与字体探针之验见 `../字体诺节/一致性验证/`。
