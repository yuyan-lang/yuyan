# 字体浏览器适配

`字体。豫` 在浏览器宿主上实现[字体接口](../../../豫言操作系统接口/字体/规范.汉语.md) 0.1.0。`实现接口。豫` 固定公共包身份与版本；双宿主构建的浏览器模式优先选用本目录（`字体浏览器`）。

**字体怎样声明**：页面用 `<link data-yy-字体="族名" href="字体文件网址">` 声明每个族名的字体文件，字体集可加 `data-yy-字体序号="序号"`（缺省为零）；这个元素也可以同时写 `rel="preload" as="font" crossorigin`，让浏览器提前下载。没有声明的族名 `取得字体` 返回 `资源不存在`。例：

```html
<link rel="preload" as="font" crossorigin href="字体/NotoSansSC.ttf" data-yy-字体="无衬线">
```

**宿主原语**：`豫言_浏览器_字体(操作, 族名, 号, 偏移, 长度)`，返回（状态码, 号, 长度, 字体集序号, 字节, 文字），实现在 `宿主/浏览器/图形.mjs` 的 `创建字体能力`（`宿主.mjs` 第一次用到时动态导入 `图形.mjs`）。`取得` 第一次按 `href` 取回整个文件并缓存（挂起豫言栈，需 JSPI），之后同一族名得同一个号；取回失败返回 `宿主操作失败` 并附 HTTP 状态。`读取` 按偏移切片，单次上限 16 MiB。待办事项：大字体整取占内存，以后可按 HTTP Range 分段取。

**校验**：与诺节适配相同，适配先查读取范围、单次上限与零长度，再交宿主。

**验收**：宿主单元测试在 `宿主/浏览器/图形。测试.mjs`（伪文档与伪 fetch）；真实浏览器与字体探针的验收见 `../字体诺节/一致性验证/`。
