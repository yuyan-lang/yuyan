# 字体浏览器适配

`字样。豫` 在浏览器宿主上实现[字体接口](../../../豫寓榫卯/字体/规范.汉语.md) 0.1.0。`实现榫卯。豫` 固定公共包身份与版本；豫构发行的浏览器模式优先选用本目录（`字体浏览器`）。

**字体怎样声明**：页面用 `<link data-yy-字体="族名" href="字体文件网址">` 声明每个族名的字体文件，字体集可加 `data-yy-字体序号="序号"`（缺省为零）；这个元素也可以同时写 `rel="preload" as="font" crossorigin`，让浏览器提前下载。没有声明的族名 `取字样` 返回 `资源不存在`。`取字样` 的族名以正斜线 `/` 起头时按路径取字体：浏览器宿主没有可列的系统字体目录，这一支返回 `资源不存在`，字体查看一类的程序在浏览器里只列页面声明过的字体。通用族名与常见具体族名各写一条；粗体族名只在页面确有真粗体文件时声明，没有声明时应用取不到真粗面，回到常规面仿粗。例：

```html
<link rel="preload" as="font" crossorigin href="字体/自由无衬线常规.ttf" data-yy-字体="无衬线">
<link rel="preload" as="font" crossorigin href="字体/自由无衬线常规.ttf" data-yy-字体="sans-serif">
<link rel="preload" as="font" crossorigin href="字体/自由衬线常规.ttf" data-yy-字体="serif">
<link rel="preload" as="font" crossorigin href="字体/自由衬线常规.ttf" data-yy-字体="衬线">
<link rel="preload" as="font" crossorigin href="字体/自由等宽常规.ttf" data-yy-字体="monospace">
<link rel="preload" as="font" crossorigin href="字体/自由等宽常规.ttf" data-yy-字体="等宽">
<link rel="preload" as="font" crossorigin href="字体/自由衬线粗体.ttf" data-yy-字体="自由衬线粗体">
<link rel="preload" as="font" crossorigin href="字体/思源黑体.otf" data-yy-字体="汉字">
<link rel="preload" as="font" crossorigin href="字体/思源黑体.otf" data-yy-字体="符号">
```

网页行在的页面 `宿主/浏览器/行在/行在.html` 按这套写法声明：文楷用 `../字体.ttf`，无衬线、汉字、符号、圆体、数学用 `../字体/思源黑体.otf`，手写、装饰、仿宋用 `../字体/原始字体.ttf`，等宽用 `../字体/默认等宽黑体.otf`；衬线、无衬线与等宽中的度量兼容之名（`serif`、`sans-serif`、`monospace`、`Arial`、`Helvetica`、`Times New Roman`、`Times`、`Courier New`、`Courier`）与 `自由衬线`、`自由无衬线`、`自由等宽` 三族各分量的常规、粗体、斜体、粗斜体用 `../字体/自由*.ttf`；`黑体`、微软雅黑、`宋体`、`Menlo` 等具体族名与 `system-ui`、`ui-*` 等通用族名也各写一条。`字体基` 网址参数另指字体目录，`字体` 参数把全部族名指到同一个文件（旧测试用法）。

**缺字回退**：浏览器适配只按页面声明的族名交文件。字体选取库按码点在族链上逐字查码表，链末追加 `sans-serif`、`汉字`、`emoji`、`符号`，对应到页面声明的 `自由无衬线`、`汉字`、`表情`、`符号`；`汉字` 族供自由衬线等比例西文字体缺汉字时回退。当前发行不带表情字体，页面不声明 `表情`，表情码点落到 `汉字` 或 `符号` 的字体或 `.notdef`。

**宿主原语**：`豫言_浏览器_字体(操作, 族名, 号, 偏移, 长度)`，返回（状态码, 号, 长度, 字体集序号, 字节, 文字），实现在 `宿主/浏览器/图形.mjs` 的 `创建字体能力`（`宿主.mjs` 第一次用到时动态导入 `图形.mjs`）。`取得` 第一次按 `href` 取回整个文件并缓存（挂起豫言栈，需 JSPI），之后同一族名得同一个号；取回失败返回 `宿主操作失败` 并附 HTTP 状态。`读取` 按偏移切片，单次上限 16 MiB。待办事项：大字体整取占内存，以后可按 HTTP Range 分段取。

**校验**：与诺驿适配相同，适配先查读取范围、单次上限与零长度，再交宿主。

**验收**：宿主单元测试在 `宿主/浏览器/图形。测试.mjs`（伪文档与伪 fetch）；真实浏览器与字体探针的验收见 `../字体诺驿/一致性验/`。

**平台接口**：本适配的包装函数转调平台接口包里的无体声明，编成带类型的宿主导入（边界签名见《网页汇编接口》网五）：「网览东道」之「字样本术」的「网览字样操作」（旧外调名 `豫言_浏览器_字体`）。宿主对这些导入的实现与旧原语相同。
