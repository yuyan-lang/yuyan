# 网页环境浏览器适配

`环境。豫` 行[网页环境之约](../../../豫言操作系统接口/网页环境/规范.文言.md)之诸函数：`读取本地时区偏移分钟`、`读取页面饼`。`实现接口。豫` 定公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（须候者）二原语，操作名为 `环境.时区偏移`、`环境.饼`；败则以（阴，错误文）返，本适配转为豫言事故，不使 JavaScript 之异常越 Wasm 之界。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`。时区之偏取 `-new Date(毫秒).getTimezoneOffset()`（东正，四舍五入为整分）；饼自 document.cookie 依名精取其值，原样返之而不解码，被禁或发错则视为无。

**运行之要**：候事之函数挂豫言之栈，浏览器须支持 JSPI；八新包与网页事件包共一统一事列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用“前端接口探针”、宿主单元测试与 JSDOM 加真实 Wasm 之一致性测试，说明见其中之 `说明.文言.md`）。
