# 网页环境浏览器适配

`环境。豫` 实现[网页环境接口](../../../豫言操作系统接口/网页环境/规范.汉语.md)的全部函数：`读取本地时区偏移分钟`、`读取页面饼`。`实现接口。豫` 固定公共包身份与版本，接口检查器须在构建前核对签名。

**宿主原语**：适配只调用 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（需要等待的操作）两个原语，操作名为 `环境.时区偏移`、`环境.饼`；失败以（阴，错误文）返回，再由本适配转成豫言事故，不让 JavaScript 异常越过 Wasm 边界。

**宿主实现**：`宿主/浏览器/宿主.mjs` 的 `创建网页能力`。时区偏移取 `-new Date(毫秒).getTimezoneOffset()`（东为正，四舍五入为整分钟）；饼从 `document.cookie` 按名精确取值，原样返回不解码，禁用或抛错时视为不存在。

**运行要求**：等待类函数挂起豫言栈，浏览器须支持 JSPI；八个新包与网页事件包共用同一个统一事件队列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用 `前端接口探针`、宿主单元测试与 JSDOM＋真实 Wasm 的一致性测试，说明见其中的 `说明.汉语.md`）。
