# 网页消息浏览器适配

此适配在 `豫言操作系统/` 内调用宿主的统一事件队列，向应用提供名称和 JSON 详情，不暴露原生 Event 句柄。消息名称限定为“豫言”前缀，详情限制为 1 MiB。构建前按纯接口核签，装载时用独立宿主清单核对。

**0.2.0 结构**：`订阅网页消息` 与 `取消订阅网页消息` 走宿主入口 `豫言_浏览器_订阅网页消息`、`豫言_浏览器_取消订阅网页消息`（在文档上监听，事件以“消息”类型进入统一队列，详情在事件到达的原生回调里就序列化并检查大小）；`等待网页消息` 走类型化入口 `豫言_浏览器_等待网页消息`，只取消息类型，返回（名称，详情文，错误文），错误文非空时转成事故。`发布网页消息` 沿用通用句柄桥构造并派发 `CustomEvent`。旧版基于通用句柄桥“订阅事件”与“等待浏览器事件”的实现不再使用；仍用旧原语的老应用不受影响，因为宿主保留了旧原语的原样行为。

**验收**：见 `网页事件浏览器/一致性验证/`；语法高亮应用的既有验收（`应用/豫言语法高亮/测试/浏览器高亮.test.mjs`）应在重建后继续通过。
