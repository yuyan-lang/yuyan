# 张量计算原生适配

林檎 ARM64 原生执行器通过既有系统库调用桥运行纯豫言金属设备与张量后端。必要链路包含取得金属上下文、页对齐清零的单精度存储、从字节或小数上传、矩阵乘法、读回小数及释放。算子复用 `金算阵后端` 和 `算阵后端` 的同一实现。

每块存储登记地址、字节数、类型、起点、形状与步长。既有原语 171 与 172 查询登记；174 创建登记、175 解除登记。设备同步并释放缓冲后，适配解除登记并归还原生内存。上下文释放收回其全部存储。

本包提供张量计算 0.7.0 的完整公共声明实现，复用公共适配的类型、视图与算子。原生张量存储、原生张量转换和原生张量抽样三个纯豫言子包提供存储账、数值转换、跨步复制与抽样。每个共享视图分别登记并解除，存储引用计数由公共实现管理。

豫构发行的 `--自动 原生` 选择本适配并生成公共接口绑定，由编译器连同同配的执行器 `执行器。树码` 直出 `程序。林檎。豫行`。基本 CI 运行原生登记生命周期回归，以及通过正式接口自动绑定的二阶矩阵乘回归；取得设备时运行 GPU 链路。GPU 实机结果留待验收记录。
