# 张量计算原生适配

苹果臂六十四之原生执行器，由既有系统库调用桥行纯豫言金属之器与张量后端。必需之链有取金属境、齐页清零之单精存、由字与小数上传、矩阵乘、读回小数及释之。算复用金属张量后端、张量后端之同一实现。

每存登址、字数、类、起、形与步。既有原语百七十一、百七十二查之；百七十四登之，百七十五解之。器同步而释缓后，适配解登且还原生之存。释境则还其诸存。

本包备张量计算零点七版诸公共声明之体，复用公共适配之类、视与算。原生张量存储、原生张量转换、原生张量抽样三纯豫言子包，供存账、数值之转、跨步之抄与抽样。共享诸视各登而解，存之引用数由公共实现治之。

双宿主构建以 `--自动 原生` 择本适配，成公共接口之绑定，复用同配原生生成器与执行器，出 `程序.exe`。基本 CI 行原生登记生终之试，复由正式接口自动绑定而试二阶矩阵乘；得器则行 GPU 之链。实机 GPU 之果待验收之记。
