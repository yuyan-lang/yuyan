# 原生张量抽样

此包以常豫言行跨步之抄与依率之抽，径用系统库调用之原生存术。

`中央张量跨步抄` 受元宽一、二、四字节；两起与诸步皆以元计，形与步以逗号隔整数之文。循行优先之序，尽读源元于暂字节串而后写目，故步可正负，源目可同存而叠。

`中央张量抽样` 读址上连续单精之分。温度不大于零，则弃非数，取最大者，等则取小序。温度正，则以温度除分，稳定降序而取前 k，以系统 C `exp` 算减最大分之指数，归一为率；循累积 p 取前缀，含首过界者，复归一。随机整数取模 16777216，化为零至一而不及一；累积率严格大于随值则取之，终项兜底。空则还零。

父适配验址、形与元宽。指数符号取自进程主象。余系统之符号装载留待后续。
