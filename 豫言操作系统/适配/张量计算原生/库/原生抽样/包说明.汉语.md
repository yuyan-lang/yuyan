# 原生张量抽样

此包以普通豫言提供跨步复制与概率抽样，复用系统库调用的原生内存操作。

`中央张量跨步抄` 的宽度取 1、2、4 字节；源起点、目标起点和各维步长以元素计，形状与步长采用逗号分隔整数文字。按逻辑行优先顺序先读取全部源元素到临时字节串，再写目标，支持正负步长和同存储重叠。

`中央张量抽样` 从地址读取连续单精度 logits。温度不大于零时忽略非数，最大值并列取小序号。正温度时稳定降序排列温度缩放值，保留前 k，以系统 C `exp` 计算最大值平移后的概率，再按累积 p 保留包含过界第一项的前缀并归一。随机整数模 16777216 映射到零至一的半开区间，以严格大于随机值的累计概率选择，末项兜底。空输入返回零。

父适配负责有效地址、形状和元素宽度的检查。指数符号从进程主映像取得。其他系统平台的指数符号装载列入后续事项。
