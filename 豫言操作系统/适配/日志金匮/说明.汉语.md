# 日志落盘适配

把日志接口的三个函数（`录误`、`录戒`、`告`）写进本机盘上的按日卷册，重启后仍在，供豫言系统与原生宿主上的服务程序使用。

## 位置与格式

卷册放在当前金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下的 `日志/` 目录里，一卷一日，名字是本地日期 `年-月-日.log`（按宿主的本地日期，格式 `%Y-%m-%d`）。每调用一次追加一行 JSON 对象：

```
{"级别":"error","时刻":"12:34:56","文字":"……"}
```

字段固定三个：`级别` 为 `error`、`warn`、`info`；`时刻` 是本地时刻 `%H:%M:%S`；`文字` 是应用给的日志文字（超过上限时先截断）。写成 JSON 而不是裸文本，换行、引号与控制字符都不必另设转义规则，按行读出即可还原。

## 上限与截断

单条文字按 UTF-8 字节计至多 8192 字节；更长的先减去省略标记 `…（已截断）` 的字节数得到余量，在字节串里从该位置向前退到不是 UTF-8 续字节的位置，取出前缀还原成文字，再附上标记，总长仍不超过 8192 字节，不会把一个码点切成两半。不超过上限的文字原样写出。空字符串是合法的一条日志。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓日录金匮榫」之「日录」之书。

「设匮根」于『/某处的数据盘/豫言』。
「录误」于『读盘失败』。
```

写日志卷的路径由「今日录位」按当天日期算出，「录位」按给定日期算出，测试读回时用后者。适配不脱敏、不采样，也不把日志另送别处；敏感信息不得写入日志是应用的责任。

后续版本的事项：卷册轮转与大小上限、把时刻写成完整日期时间、依级别分卷。
