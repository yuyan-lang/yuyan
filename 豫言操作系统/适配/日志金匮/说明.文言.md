# 日志落盘适配

日志三口（`录误`、`录戒`、`告`）书于本机之盘，按日成卷；重启而卷犹在，供豫言系统与本土之宿主用。

## 所在与形制

卷在当今金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下之 `日志/` 目，一卷一日，名以本地日期 `年-月-日.log`（依宿主本地之历，式 `%Y-%m-%d`）。每用一次，续一行 JSON 之物：

```
{"级别":"error","时刻":"12:34:56","文字":"……"}
```

栏凡三：`级别` 为 `error`、`warn`、`info`；`时刻` 为本地之时 `%H:%M:%S`；`文字` 为应用所授之文（逾限先截）。书为 JSON 而不用裸文，则换行、引号与控字不必别设其避，按行读之即可还其原。

## 上限与截

单条之文依 UTF-8 字节计，至多八千一百九十二字节；逾者先减省略之标 `…（已截断）` 之字节而得余量，于字节串中自其位前退至非续字节之处，取前段还为文字，乃附其标；总长仍不过八千一百九十二，不使一码中裂。未逾者原样书之。空文亦为一记。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓日录金匮榫」之「日录」之书。

「设匮根」于『/某处的数据盘/豫言』。
「录误」于『读盘失败』。
```

卷径由「今日录位」按当日之历而得，「录位」按所授之日而得，试者读回则用后者。适配不脱敏、不采样，亦不别送他处；秘事不得入日志，乃应用之责。

后续之事项：卷册轮转与大小之限、时刻书为全日、依级别分卷。
