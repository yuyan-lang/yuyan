# 云工持久事务适配

`键值。豫` 借当前 Durable Object 之存，以承[持久事务之约](../../../豫言操作系统接口/持久事务/规范.文言.md)三版。

- **事务**：`执行持久事务` 先于豫言中规整参 JSON，复经宿主 `云工持久事务执行安全` 启 `storage.transaction`；宿主于回调中自实例之池另取一实例（外层之调所用之实例犹被占），登平台之事务对象于此调之句柄表，以 `持久事务`（构造器 `云工持久事务` 裹其柄）与参文呼客之入口 `执行持久事务回调`，回调所返之文（宿主验其为有效 JSON）即其果（提案 C0001）。宿主以回调或平台之败为值而返，适配转为可捕之豫言异（辞曰 `持久事务失败：…`）。事务内之读、写、删、列经宿主之原语，宿主依此调取仓，故施于此事务；`回滚持久事务` 经句柄桥呼事务对象之 `rollback()`。
- **直读写**：`读取持久仓键值` 等五术，呼 `storage.get/put/delete/list/deleteAll`，施于持久对象本身：宿主依此调取仓，于事务回调中用之则读写亦归本事务；于持久对象之外用之则宿主报误（书与列经安全之原语转为可捕之异，余者止此调）。
- **值之理**：书则经宿主原生 `JSON.parse` 验之而以结构化值存（`云工持久写入值安全`：键一至二千零四十八字节、值不逾二 MiB、嵌套不逾三十二层、拒宿主所留之单键对象，败则归为值而转为可捕之异）；读则径返宿主所书之 JSON 文，不于豫言中析而复书（故控制字符与增补平面字皆不为豫言 JSON 编解码之器所扰）；列举经 `云工持久列举值安全` 规整其选（空串视同未指），而限果不逾八 MiB。事务内与直取之读写同循此径。
- **不为**：适配不存其态，不释客之键与业务之规；不露 `allowConcurrency`、`noCache`、`allowUnconfirmed`，亦不供 SQL 与同步事务（另见`云工宿主`）。

一致性验证之例，见 `豫言操作系统/宿主/云工/一致性验证/`（含持久事务、持久告警、持久独占三接口与宿主壳之 Node 测试及试验应用）。
