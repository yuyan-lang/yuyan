# 节点剪贴板适配

`文字。豫` 于路一节点宿主行[剪贴板之约](../../../豫言操作系统接口/剪贴板/规范.文言.md)零点二版之读与写。无自有之宿主原语，借[显示节点适配](../显示节点/说明.文言.md)所用显示原语 `豫言_节点_显示` 之二术：`剪贴板读` 于文位返剪贴之纯文，`剪贴板写` 以字节之参为 UTF-8 之文而置之。二术由共用显示之核转于节点之后端，以 `@kmamal/sdl` 之 `clipboard`（于 macOS 即 NSPasteboard）成之，不必先取显示面。

宿主行时须 npm 包 `@kmamal/sdl`；不得则读返 `资源暂不可用`，写报调用之失。包描述以「平台」明此适配惟用于诺节。
