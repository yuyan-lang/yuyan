# 节点剪贴板适配

`文字。豫` 在路一 Node 宿主上实现[剪贴板接口](../../../豫言操作系统接口/剪贴板/规范.汉语.md) 0.2.0 的读与写。它没有自己的宿主原语，借[显示节点适配](../显示节点/说明.汉语.md)所用的显示原语 `豫言_节点_显示` 的两个操作：`剪贴板读` 在文字位返回剪贴板里的纯文本，`剪贴板写` 把字节参数当 UTF-8 文字写入。两者由共用显示核心转给 Node 后端，用 `@kmamal/sdl` 的 `clipboard`（macOS 上即 NSPasteboard）完成，不需要先取得显示面。

宿主运行时需要 npm 包 `@kmamal/sdl`；找不到时读取返回 `资源暂不可用`，写入报告调用失败。包描述用「平台」声明本适配只用于诺节。
