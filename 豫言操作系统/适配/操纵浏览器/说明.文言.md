# 手柄浏览器适配

浏览器宿主所用手柄接口之适配，依常式行 `豫寓辔`。柄由页面 Gamepad 之接口供之，其读在宿主之胶 `豫言操作系统/宿主/浏览器/操纵.mjs`。

## 对应

- `列辔` 调宿主原语 `网览手柄数` 取柄数，再依枚举之序以 `网览手柄号` 与 `网览手柄名` 造柄；页无 Gamepad 接口（`网览手柄数` 为负一）则答 `资源暂不可用`。
- `问辔` 以 `网览手柄连` 视其犹接，接则以 `网览手柄钮` 与 `网览手柄枢` 逐项取十七钮四枢；不在则答 `资源已失效`。
- `候辔` 以 `网览手柄候` 取页所记之接拔；无变则答 `辔无变`。
- `振辔` 以 `网览手柄振` 调其振动之器；无其能则答 `资源暂不可用`，柄不在则答 `资源已失效`。
- `辔钮名` 与 `辔枢名` 取常式十七与四之汉字名，不经宿主。

## 界

浏览器之 Gamepad 接口惟页面可见时更新其状，拔后 getGamepads 不复返其柄。接拔之事由页面之 gamepadconnected 与 gamepaddisconnected 通知记之；宿主既建之前已接之柄无事，客可逐帧列辔而较前后。

## 验收

`豫言操作系统/宿主/浏览器/操纵。测试.mjs` 以伪导航验胶水之数、号、名、钮、枢、连、候、振；真浏览器之验留待后版。
