# 手柄浏览器适配

浏览器宿主用的手柄接口适配，按标准布局实现 `豫寓辔`。手柄由页面的 Gamepad 接口提供，读取放在宿主胶水 `豫言操作系统/宿主/浏览器/操纵.mjs`。

## 对应关系

- `列辔` 调宿主原语 `网览手柄数` 取手柄数，再按枚举次序用 `网览手柄号` 与 `网览手柄名` 造手柄；宿主没有 Gamepad 接口时（`网览手柄数` 为负一）答 `资源暂不可用`。
- `问辔` 用 `网览手柄连` 看手柄是否接着，接着时用 `网览手柄钮` 与 `网览手柄枢` 逐项取十七个按钮与四个轴；不在答 `资源已失效`。
- `候辔` 用 `网览手柄候` 取浏览器记下的接入与拔出事件；没有变化答 `辔无变`。
- `振辔` 用 `网览手柄振` 调手柄的振动执行器；没有振动能力答 `资源暂不可用`，手柄不在答 `资源已失效`。
- `辔钮名` 与 `辔枢名` 取标准布局的十七与四个汉字名，不经过宿主。

## 边界

浏览器的 Gamepad 接口只在页面可见时更新状态，拔出后 `getGamepads` 不再返回该手柄。接入与拔出事件由页面的 `gamepadconnected` 与 `gamepaddisconnected` 通知记下；宿主建立之前已接上的手柄没有事件，应用可以每帧 `列辔` 比较前后两份列表。

## 验收

`豫言操作系统/宿主/浏览器/操纵。测试.mjs` 用假的导航对象验证胶水的数、号、名、钮、枢、连、候、振；真正的浏览器页面验证留待后续版本。
