# 文件接口 Node 适配

文件接口 0.5.0 的 `删除路径` 接节点删除原语，只删除可写目录内的普通文件或空目录。真实宿主测试覆盖删除成功、只读拒绝、非空目录保留、符号链接拒绝、越界拒绝和失效目录权；公共 Wasm 调用与壳接入仍待验收。

文件接口 0.4.0 增加覆盖和追加打开：可写目录权下创建普通文件，覆盖立即截断，追加每次写在末尾。宿主测试验证创建、覆盖、追加及只读拒绝，并确认越界符号链接目标未被截断。父路径检查与打开之间的竞态仍待处理。

真实 Wasm 发行通过正式启动器调用公共接口：创建后写入“甲乙”，追加“丙”并读回“甲乙丙”，覆盖为“丁”后读回“丁”；发行装载核对通过。该证据不代表原壳环境文件调用已迁移。

文件接口 0.3.0 增加 `创建目录`：须可写授权，仅创建一层，核对父目录真实路径。已有目录、缺失父目录、只读授权及越界符号链接均有宿主回归验证。

路一 Node 宿主的[文件接口](../../../豫言操作系统接口/文件/规范.汉语.md)适配。目录权只来自启动时的宿主选项：`--授权目录 名=路径`（可读可写）或 `--授权只读目录 名=路径`；`取得已授目录` 按名称取目录权，未授权的名称返回 `未获授权`。

- 路径规则：`/` 分隔的相对路径；空串、以 `/` 开头、空段、`.`、`..`、零字节与无效 UTF-8 返回 `输入无效`；Windows 上段内的 `\` 与 `:` 也返回 `输入无效`（待办事项：是否在所有平台都拒绝，以求三平台完全一致）。
- 越界防护：宿主先求目标的真实路径，确认仍在授权目录内（符号链接指向目录外时返回 `输入无效`），再打开。求真实路径与打开之间仍有竞态，待办事项：逐段 `O_NOFOLLOW` 打开。
- `打开只读文件` 以只读打开，`打开可写文件` 以只写打开已存在的文件，都不创建、不截断；目标不存在返回 `资源不存在`，不是普通文件返回 `输入无效`，只读目录上打开可写文件返回 `未获授权`。
- `读取文件` 读至多上限字节（单次不超过值桥交换上限 16 MiB）；读到末尾返回 `文件读尽`，上限为零返回空字节串，上限为负返回 `输入无效`。`写入文件` 返回实际写入字节数，空输入返回零，暂时写不进返回 `资源暂不可用`。
- 读写方向分离：只读柄写入、可写柄读取都返回 `未获授权`。`关闭文件` 之后（无论成败）句柄失效，再用返回 `资源已失效`；伪造的句柄号同样得到 `资源已失效`。

新增宿主原语（外调名）：`豫言_节点_文件取得目录`、`豫言_节点_文件打开`、`豫言_节点_文件读取`、`豫言_节点_文件写入`、`豫言_节点_文件关闭`，实现在 `豫言操作系统/宿主/节点/应用宿主.mjs`，返回（状态码，…）：0 成功，1 至 7 依次对应未获授权、资源暂不可用、资源已失效、资源不存在、资源已存在、资源配额已尽、输入无效，8 为宿主操作失败（附消息），读取时 9 表示读尽。本适配依赖基础接口的 `错误` 模块，由节点模式的构建器一并绑定。

**平台接口**：本适配的包装函数转调平台接口包里的无体声明，编成带类型的宿主导入（边界签名见《网页汇编接口》网五）：「诺节宿主」之「文件原语」的「诺节文件取得目录」（旧外调名 `豫言_节点_文件取得目录`）、「诺节文件打开」（旧外调名 `豫言_节点_文件打开`）、「诺节文件读取」（旧外调名 `豫言_节点_文件读取`）、「诺节文件写入」（旧外调名 `豫言_节点_文件写入`）、「诺节文件关闭」（旧外调名 `豫言_节点_文件关闭`）。宿主对这些导入的实现与旧原语相同。

## 文件接口 0.2.0

新增目录列举与文件信息查询。空路径只在这两个查询中表示授权根；真实路径仍须位于授权目录内。目录列举直接子项并区分普通文件、目录与其他对象，符号链接列为其他。信息查询返回种类及普通文件字节数，目录与其他对象返回零。

Node 平台原语为 `诺节文件列目录` 与 `诺节文件查询信息`。真实文件边界测试在宿主的 `文件浏览。测试.mjs`，已通过授权根、子目录、文件字节数、非目录、缺失目标、上溯、绝对路径、空段、零字节、外部符号链接、伪目录权及未授权名称。此结果只证明当前 Node 平台，未替代 Windows、Linux、浏览器或原生系统验收。
