# 文件接口节点适配

文件接口零点五之 `删除路径` 接节点删文原语，惟删可写目录内之普通文或空目录。实宿主之验含删成、惟读拒、存非空目录、拒链、拒越界及失效目录权；公 Wasm 调用与壳之接犹待验。

文件接口 0.4.0 增覆盖与追加之开：写权下造普通文，覆盖即截，追加每写在末。宿主之验含创建、覆盖、追加与只读之拒，并核越界链之目标不被截。查父与开之间竞态犹待治。

实 Wasm 发行循正式启动器调公接口：造而写“甲乙”，追加“丙”而读得“甲乙丙”，覆盖为“丁”而读得“丁”；发行装载之核已过。此证不谓原壳环境文件之调已迁。

文件接口 0.3.0 增 `创建目录`：须授写，仅造一层，核父之真径。已有目录、父不存、只读之授与越界之链，皆经宿主回归之验。

此为路一节点宿主之[文件接口](../../../豫言操作系统接口/文件/规范.文言.md)适配。目录权惟出于启时之宿主选项：`--授权目录 名=路径`（可读可写）、`--授权只读目录 名=路径`；`取得已授目录` 以名取之，未授之名得 `未获授权`。

- 路之式：以 `/` 分之相对路；空、首斜、空段、`.`、`..`、零字节、非 UTF-8 者皆 `输入无效`；于 Windows，段中有 `\` 或 `:` 者亦然（待办事项：诸平台是否并拒，以求三台全同）。
- 防越界：宿主先求其真径，验其仍在所授目录之内（符号链指外则 `输入无效`），而后开之。求径与开文之间犹有隙，待办事项：逐段以 `O_NOFOLLOW` 开之。
- `打开只读文件` 以读开，`打开可写文件` 以写开已存之文，皆不造不截；不存者 `资源不存在`，非常文者 `输入无效`，只读之目录求写者 `未获授权`。
- `读取文件` 读至多上限之字（每次不逾值桥之限十六兆字节）；尽则 `文件读尽`，上限为零得空字，为负得 `输入无效`。`写入文件` 返实写之数，空入返零，暂不可写则 `资源暂不可用`。
- 读写分向：只读之柄求写、可写之柄求读，皆 `未获授权`。`关闭文件` 之后无论成败柄皆失效，再用得 `资源已失效`；伪号亦然。

新增宿主原语（外调名）：`豫言_节点_文件取得目录`、`豫言_节点_文件打开`、`豫言_节点_文件读取`、`豫言_节点_文件写入`、`豫言_节点_文件关闭`，实于 `豫言操作系统/宿主/节点/应用宿主.mjs`，返（码，…）：零成；一至七依次为未获授权、资源暂不可用、资源已失效、资源不存在、资源已存在、资源配额已尽、输入无效；八为宿主操作失败而附辞；读时九为读尽。此适配依基础接口之 `错误` 模，节点模式之构建器并绑之。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「诺节宿主」之「文件原语」之「诺节文件取得目录」（旧外调名 `豫言_节点_文件取得目录`）、「诺节文件打开」（旧外调名 `豫言_节点_文件打开`）、「诺节文件读取」（旧外调名 `豫言_节点_文件读取`）、「诺节文件写入」（旧外调名 `豫言_节点_文件写入`）、「诺节文件关闭」（旧外调名 `豫言_节点_文件关闭`）。宿主实此诸导入，与旧原语同。

## 文件接口 0.2.0

增目录之列与文件信息之查。空径惟此二查为授权根；真径仍必在已授目录内。列直下诸项，分普通文、目录与其他，符号链接为其他。信息还类与普通文之字节数，目录及他物为零。

Node 平台之术为 `诺节文件列目录` 与 `诺节文件查询信息`。实文件之边界试在宿主 `文件浏览。测试.mjs`，已验授权根、子目录、文件字节数、非目录、不存之目、上溯、绝对径、空段、零字、外链、伪权与未授之名，皆过。此惟证今 Node 平台，不代 Windows、Linux、浏览器及原生系统之验。
