# 图形处理器原生适配

`图形。豫` 于林檎原生之执行器行[图形处理器之接口](../../../豫寓榫卯/图形处理器/规范.文言.md)零点三点零：设备、缓冲、八位四色之纹与深纹、MSL 着色模块、算绘之管线（并深测与剔法）、绑定组、计算派发、渲染通道与深度渲染通道、依点、依三十二位索引与带首索基顶之绘，皆经[金属库](../../../库/金/包说明.文言.md)（Objective-C 运行时与 Metal 框架，悉书于豫言；绘之部在金属库之 `绘事` 篇）而成，无他人之库。`实现接口。豫` 定公包之身份与版，`宿主提供。数据。豫` 为接口之清单（同节点、浏览器之适配）。

## 行

- **设备**：`取图枢` 取默认之金属器而建一命令之队；无金属（非林檎、宿主不能调系统库、无默认之器）则返资源暂不可用。`读器点染鹄` 恒为金属目标，`译点染篇` 之源文为 MSL（豫言编译器之「金属源」，算、顶点、片元之入口皆可译）。
- **缓冲**：金属共享之存，CPU 与 GPU 共一存。`写图形缓冲` 与 `读回图形缓冲` 径读写缓冲所容之址，一次不逾十六兆；`销毁图形缓冲` 释缓冲。字数须为正之四倍，不逾一吉。
- **纹理**：红绿蓝透与蓝绿红透八位纹理（含标准色空间之式）用金属共享之存，初清零，依行密书而读回，可为绘之鹄；储纹之用惟配红绿蓝透八位。`深度单精度` 为私存之 Depth32Float 纹理，其用惟深度目标，写之则止行，读回则返校验之误。
- **着色模块与管线**：`译点染篇` 以 MSL 授金属编之，误以图形校验错误附金属之辞而返；`置算管线` 依入口之名建管线，并读其每线程组之线数。`置渲染管线`、`置深度渲染管线`、`置剔除渲染管线` 与 `置剔除深度渲染管线` 依名取顶点、片元之术而立绘管：顶点之述第 i 布用金之槽三十减 i，属依位号对着色之 `[[attribute(N)]]`；色鹄惟八位四色之式；混法从规范；带深测之管，深鹄之格为 Depth32Float，另立深度之规（比法从规范，写深与否）；剔法录于管，绘时依之设金绘编之器，正面恒逆时。
- **绑定组**：`置算系组` 与 `置渲染系组` 受缓冲之绑（纹理、采样器留于后版），第 g 组绑号 b 之缓系于金之槽 g × 16 + b；绘之组之缓并系于顶点与片元二术。
- **命令**：`呈图形令` 先验全列，一有不过则全列不行，返命令未提交附校验之误。所验：绘道之色鹄须为具绘鹄之用之色纹；深道之深纹须为深度单精度、与色鹄同大；管之有无深测须合其道，色格须同其鹄，顶点之缓不少于布数，依点而绘则诸缓足其点数，依索而绘则索缓足其索数，索段之绘则索缓足首索与索数；复制之偏与长须合规范。既过，相续之派发与绘道录于一命令之缓（相续之派共一算编，每绘道一绘编，正面设为逆时针，每绘依管设剔法），交而同步候之；`复制图形缓冲` 于二段之间在 CPU 一侧抄之。故 `呈图形令` 返时命令皆毕，`待图形毕` 无事。
- **试**：`测试/纹理。测试。豫` 验八位四色纹之建、书与逐字读回；`测试/渲染。测试。豫` 以光照立方之着色源（`测试/立方。着色器。豫`）验：无深则后画者掩先画者，有深则先画之近三角掩后画之远三角，三十二位索引所画之立方中心为正面之色，同缓二段以首索基顶分画左右，不剔则正背皆画而剔背惟余正、剔正惟余背，深纹读回报校验之误，管与道之深不合则全列不呈；皆逐字较读回之素。二〇二六年十月二十一日于 pit-mac（Apple M2 Max）二试皆过。

## 构与用

`豫构 发行 原生` 依次择 `XXX原生`、`XXX节点` 与 `XXX`，故应用依 `豫寓图枢` 则自择此适配（`--包根 豫言操作系统/适配 --包根 库`）。试于仓根构而行之：`豫构 构建 豫寓图枢本土榫 测试 渲染。测试 --输出 渲染测试。林檎。豫行 -j 24`，乃行 `./渲染测试。林檎。豫行`。

## 待办事项

向设备问缓冲之上限；半精与红单精之纹、采样器与纹理资源之绑；画点须顶点之术书点之大（着色之语未有此内建之出）；依索而绘不核索值是否逾顶点之缓；设备失与释后之失效检查；显示之呈今每帧读回共享之纹而授像素之显，改为金属交换之链（CAMetalLayer）可省读回与复制（其时见[图形显示原生适配](../图形显示原生/说明.文言.md)）。
