# 日志云工适配

以三术映 Worker 之 `console.error`、`console.warn`、`console.info`。适配先于豫言按 UTF-8 字节核其限，未逾八千一百九十二字节者，原样授云工宿主之控制台原语；逾则先减标 `…（已截断）` 之字节以得余量，复于字节串中向前退至 UTF-8 之字界（不裂一码点），以整段字节授宿主，用 `Uint8Array.slice` 取其前缀，以 `TextDecoder` 还为字符串（其费与入文之大小几无关）；逾一千六百万字节之巨文，超宿主桥单次之交换，则改于豫言逐字节拼前缀，每次约十毫秒，仍与入文之大小无关，且不拆整串为字符之列而竭内存。日志之文不经 JSON，控制之字与换行原样达平台；宿主桥授字符串于宿主原语之时，去其首之 U+FEFF（宿主桥之缺，详一致性测试之待办）。适配不存日志，不脱敏，亦不分请求；敏感之讯不得书入日志，乃客之责。

真本地 workerd 实测：三级于 workerd 日志中，分显为 `[ERROR]`、`[WARNING]` 与常行；逾长之文被截而以 `…（已截断）` 终，单条不逾八千一百九十二字节。综合之场见 `../消息队列/一致性验证/真实工作者/`。

`一致性验证/` 有试应用、真 Wasm 之 Node 测试及复行之说明。
