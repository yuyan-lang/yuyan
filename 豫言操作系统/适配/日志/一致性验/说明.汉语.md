# 日志一致性验证

本目录在本机 workerd 里用真实 Wasm 验证[日志接口](../../../../豫寓榫卯/日志/规范.汉语.md)的云工适配：

- `应用/`：试验应用 `日志一致性应用`。包描述存为 `应用/日志一致性应用。包。豫.txt`，避免被 `豫构` 的全仓库包发现当成包；`豫构 发行` 会把应用目录复制到构建根内的临时目录（`dist/.自动构建/<输出名>/应用`）并改回 `。包。豫`。
- `云端复验/`：用[验收驱动](../../../../库/考成/包说明.汉语.md)写的豫言测试包，在本机 wrangler dev（真 workerd）里经真实 HTTP 写日志，再从 wrangler 的本机观测接口读回这次请求的控制台日志，核对级别、参数个数与文字，共 11 项，见[其说明](云端复验/包说明.汉语.md)。

## 复跑

在构建根（语言仓根目录）运行：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/日志/一致性验证/云端复验/日志云端复验。测试。豫 --输出 日志云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 日志云端复验.wasm
```

产物 `dist/日志一致性/` 不存在（或环境变量 `重建云工应用=1`）时，测试先用 `./豫构。林檎。豫行 发行 云工 <本目录>/应用 dist/日志一致性` 构建（用法与依赖解析规则见[豫构发行说明](../../../../应用/豫构/文档/发行.汉语.md)）。找不到 wrangler 时打印“跳过”并以零退出；CI 没有 wrangler，全树测试对 `云端复验/` 只做类型检查。

2026-10-11 在 wrangler 4.129.0 上 11 项全部通过。
