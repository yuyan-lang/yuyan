# 日志一致性验证

此目录于本机 workerd 以真 Wasm 验[日志公约](../../../../豫寓榫卯/日志/规范.文言.md)之云工适配：

- `应用/`：试应用 `日志一致性应用`。包描述存为 `应用/日志一致性应用。包。豫.txt`，免为 `豫构` 全仓库之包发现误作一包；`豫构 发行` 复应用之目录于构建根内之临时目录（`dist/.自动构建/<输出名>/应用`），而改回 `。包。豫`。
- `云端复验/`：以[验收驱动](../../../../库/考成/包说明.文言.md)所书之豫言测试包，于本机 wrangler dev（真 workerd）以真 HTTP 书日志，复自 wrangler 本机观测之口读回此请之控制台日志，核其级、参数之数与其文，凡十一项，见[其说明](云端复验/包说明.文言.md)。

## 复行

于构建根（语言仓之根）行之：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/日志/一致性验/云端复验/日志云端复验。测试。豫 --输出 日志云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 日志云端复验.wasm
```

产物 `dist/日志一致性/` 不存（或环境变量 `重建云工应用=1`）则测先以 `./豫构。林檎。豫行 发行 云工 <本目录>/应用 dist/日志一致性` 构之（用法与依赖之解见[豫构发行说明](../../../../应用/豫构/文档/发行.文言.md)）。不得 wrangler 则书“跳过”而以零退；CI 无 wrangler，全树测试于 `云端复验/` 惟验其类。
