# 日志云端复验

日志适配于本机 wrangler dev（真 workerd）之黑盒复验，以[验收驱动](../../../../../库/考成/包说明.文言.md)书之，一令而毕“随需构试验之应用 → 起 wrangler → 行诸用例 → 止 wrangler（并 workerd 之子进程）”。试验之应用以请之正文授所对之级之日志函；测以真 HTTP 发请，复自 wrangler 本机观测之口（`/cdn-cgi/local/explorer/api/local/observability/query` 之 `logs` 表）读此请所在之事之控制台日志，核其级（`error`、`warn`、`info`）、参数之数与其文。

- `日志云端复验。测试。豫`：十一用例——装载时之接口核对（应用之要求与宿主之所供皆含日志接口 0.1.0）、三级、不逾八一九二字节者如原而书（空串、换行、引号、反斜线、控制之字、文中 BOM、表情、恰八一九二字节）、文首 BOM、八一九二与八一九三字节之截断边界、多字节之字惟于字间截而尽充、一 MiB 之文、一八十五 MiB 之大入与豫言内所造十七、四十 MiB 之巨串、二字节之字、连呼、未知之径不书日志。
- `wrangler.jsonc`：本机复验所用 wrangler 之配置，无绑定。

于仓根行之：

```sh
./yy豫构.exe 文件 豫言操作系统/适配/日志/一致性验/云端复验/日志云端复验。测试。豫 --输出 yy日志云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy日志云端复验.wasm
```

wrangler 次第取环境变量 `云工命令行路径`、仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；无则书“跳过”而以零退。产物 `dist/日志一致性/` 不存（或环境变量 `重建云工应用=1`）则以 `yy豫构.wasm 发行 云工` 构之。每行用新暂存之工作目录。CI 无 wrangler，全树测试于此目录惟验其类。
