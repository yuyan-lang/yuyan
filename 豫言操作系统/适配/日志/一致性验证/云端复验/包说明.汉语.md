# 日志云端复验

日志适配在本机 wrangler dev（真 workerd）里的黑盒复验，用[验收驱动](../../../../../库/考成/包说明.汉语.md)写成，一条命令完成“按需构建试验应用 → 起 wrangler → 跑全部用例 → 停 wrangler（含 workerd 子进程）”。试验应用把请求正文交给对应级别的日志函数；测试经真实 HTTP 发请求，再从 wrangler 的本机观测接口（`/cdn-cgi/local/explorer/api/local/observability/query` 的 `logs` 表）读出这次请求所在事件的控制台日志，核对级别（`error`、`warn`、`info`）、参数个数与文字。

- `日志云端复验。测试。豫`：十一个用例——装载时的接口核对（应用要求与宿主提供都含日志接口 0.1.0）、三个级别、不超过 8192 字节者原样写出（空串、换行、引号、反斜线、控制字符、文中 BOM、表情、恰 8192 字节）、文首 BOM、8192 与 8193 字节的截断边界、多字节字符只在字符之间截断且尽量填满、1 MiB 文字、1/8/15 MiB 大输入与豫言内生成的 17/40 MiB 巨串、两字节字符、连续调用、未知路径不写日志。
- `wrangler.jsonc`：本机复验用的 wrangler 配置，不需要绑定。

在仓库根目录运行：

```sh
./豫构。林檎。豫行 文件 豫言操作系统/适配/日志/一致性验证/云端复验/日志云端复验。测试。豫 --输出 日志云端复验.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs 日志云端复验.wasm
```

wrangler 依次取环境变量 `云工命令行路径`、仓库旁云仓的 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`；没有就打印“跳过”并以零退出。产物 `dist/日志一致性/` 不存在（或环境变量 `重建云工应用=1`）时用 `豫构.wasm 发行 云工` 构建。每次运行用新的临时工作目录。CI 没有 wrangler，全树测试对本目录只做类型检查。
