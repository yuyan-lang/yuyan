# 环境文字落盘适配

自一唯读之数据文件读授权之境绑，不占宿主之境，重启如故。供豫言系统与本土之宿主用。

## 配置

文件在当今金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下，名曰 `配置。数据。豫`：

```yuyan
「环境」者「典」【「主机名」者『豫言测试』也、「空格占位」者『』也】也。
「授权」者「列」【「组值」【「种类」者『ENV』也，「名称」者『主机名』也】】也。
```

顶之「环境」为记，栏名即境名，栏值即其文；顶之「授权」为绑定之列，每有一条，有 `种类` 与 `名称` 二字段（种类如 `ENV`、`D1`、`R2`）。每用重读，改之即见；无其卷则视为无绑。

## 语义

- `读授权境文字`：名在「授权」中而种类为 `ENV` 者还其值；授而未在「环境」中置（或值为空串）得空串；未授者报可捕之中文事故 `环境文字未授权：` 接其名。
- `授权系存在`：种类与名俱登于「授权」者得阳；种类为 `ENV` 者，境中须有非空之值，空串算阴；未授者报 `绑定未授权：种类/名称`；种类或名空者分别报 `绑定种类为空`、`绑定名称为空`。
- 非 `ENV` 之种类惟答“登否”，不交一物。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓水土金匮榫」之「文字」之书。

「设匮根」于『/某处的数据盘/豫言』。
「读授权境文字」于「名」曰『主机名』。
「授权系存在」于『ENV』于『主机名』。
```

## 试

`测试/文字。测试。豫` 造暂根、书配置，核已授之值、空值、未授之名、非 ENV 种类之有无，又重设其根（拟重启）而读回，终清之。
