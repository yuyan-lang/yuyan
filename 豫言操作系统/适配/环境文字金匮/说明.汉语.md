# 环境文字落盘适配

从一个只读的数据文件读授权环境绑定，不占宿主环境，重启后照旧。供豫言系统与原生宿主上的服务程序使用。

## 配置

文件在当前金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下，名 `配置。数据。豫`：

```yuyan
「环境」者「典」【「主机名」者『豫言测试』也、「空格占位」者『』也】也。
「授权」者「列」【「组值」【「种类」者『ENV』也，「名称」者『主机名』也】】也。
```

顶层「环境」是记录，栏名即环境名、栏值是文字；顶层「授权」是绑定记录列，每条有 `种类` 与 `名称` 两个字段（种类如 `ENV`、`D1`、`R2`）。每次调用时重读，改了文件立刻生效；文件不存在时视为没有任何绑定。

## 语义

- `读授权境文字`：名字在「授权」里且种类是 `ENV` 时返回值；授权而未在「环境」里配置（或值为空串）得空串；未授权报可捕获的中文事故 `环境文字未授权：` 接名字。
- `授权系存在`：种类与名称都登记在「授权」里得阳；种类为 `ENV` 时还要「环境」里确有非空的值，空串算阴；未授权报 `绑定未授权：种类/名称`；种类或名称为空分别报 `绑定种类为空`、`绑定名称为空`。
- 非 `ENV` 的种类只答“登记与否”，不交出任何对象。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓水土金匮榫」之「文字」之书。

「设匮根」于『/某处的数据盘/豫言』。
「读授权境文字」于「名」曰『主机名』。
「授权系存在」于『ENV』于『主机名』。
```

## 测试

`测试/文字。测试。豫` 造临时金匮根、写配置文件，核对已授权值、空值、未授权名字、非 ENV 种类的存在判断，再重设根（模拟重启）读回，最后清理。
