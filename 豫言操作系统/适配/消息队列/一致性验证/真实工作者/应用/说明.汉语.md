# 平台综合一致性应用

在真实本地 workerd 上综合验证五个接口的试验应用，由 `../真实工作者.e2e.mjs` 驱动。它实现三个类型化入口（提案 C0001），没有「入口」函数。网页入口 `处理入站网页请求` 的路由：`/send?d=`、`/batch`（投递到 `E2E_QUEUE`）、`/mail?from=&to=&subject=`（请求正文为邮件正文）、`/log/error|warn|info`、`/norm/trim|lower|len`、`/kv`；队列入口 `处理队列批次` 按消息 `body.op`（ack、retry、boom，其他不处理）处理并写日志；定时入口 `处理定时事件` 把 `读取定时事件文` 的结果写入日志和 KV。
