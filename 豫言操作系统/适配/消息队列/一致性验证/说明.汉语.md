# 消息队列一致性验证

本目录用真实 Wasm 验证[消息队列接口](../../../../豫言操作系统接口/消息队列/规范.汉语.md)的云工适配：

- `应用/`：试验应用 `消息队列一致性应用`。包描述存为 `应用/消息队列一致性应用。包。豫.txt`，避免被 `yy豫构` 的全仓库包发现当成包；构建脚本会把应用目录复制到暂存内的临时目录并改回 `。包。豫`。
- `消息队列.test.mjs`：Node 测试（`node:test`），加载构建产物的 `宿主.mjs`、`程序.wasm`、`值桥.wasm`，用类实例做模拟对象（宿主桥只对非纯对象发句柄），共 28 项（含按包管理服务页面任务消费者原型组合日志接口的场景）。

## 复跑

1. 建私有暂存（符号链接语言仓的只读材料，复制编译器与工具，独立编译缓存）：主代理草稿区的 `建暂存.sh <暂存目录>`。
2. 在暂存目录构建试验应用，输出名 `消息队列一致性`：`建应用.sh <暂存目录> 云工 <本目录>/应用 消息队列一致性`。它先用 `yy豫言操作系统绑定` 把接口包与适配绑定成可编译包，再生成包上下文，调用 `yy双宿主构建` 与 `yy豫言操作系统装载包`，产物在 `<暂存目录>/dist/消息队列一致性/`。
3. 在暂存目录里运行：`node --test <本目录>/消息队列.test.mjs`。产物根目录默认取当前目录下的 `dist`，也可用环境变量 `YY_DIST_ROOT` 指定。预期 28 项全部通过。

另有在真实本地 workerd 上综合验证五个新接口的场景，见 `真实工作者/`（约 50 秒，14 个场景）。
