# 平台资料云工适配

以公共[平台资料公约](../../../豫言操作系统接口/平台资料/规范.文言.md)映于云工宿主。适配甚薄：验参（集名一至六十四字节而无控制之字、前缀至多五百一十二字节、键一至五百一十二字节，违者抛「平台资料参数无效」）与整形其果；真取资料、解压、筛键、排序与缓存，皆在宿主 JS `豫言操作系统/宿主/云工/平台资料.mjs`。

适配以薄宿主之通用原语（`库/云工宿主` 之「物宿主」与「物」）用宿主之物 `豫言平台资料`：呼其 `取()` 得资料器（`创建平台资料` 之果），乃呼资料器之 `列键(环境, 许可, 集名, 前缀)` 与 `读文字(环境, 许可, 集名, 键)`。

- **资料器惟取一次**：资料器依器缓其所解之资料，而每 `取()` 皆造新器，故适配存器于实例之格，同实例交错之诸请共之（惟为跨请之缓存）。
- **环境与许可由适配予之**：资料器惟视其参，不视平台之 env。适配依资料集取其所倚之服务绑定（`标准库` 对 `BROWSER_COMPILER`，同宿主之 `默认资料集`），以「云工绑定」于 `SERVICE` 核之：已授而在，则环境有之、许可列之；已授而阙，许可列之而环境无之，资料器告「标准库资料不可用」；未授，许可不列，资料器告「未授权的平台资料集：标准库」；不识之集名，交资料器告「未知的平台资料集：<集名>」。
- **败**：资料器之败（未知之集、未授、资料不可用、参数无效）皆化为以其辞为文之可捕豫言之异；资料不可用之后，下回重取。
- **何以置于宿主**：云工作台之资料集 `标准库`，乃约二兆七之 gzip（解之约五十七兆之 JSON，凡一千八百七十九条，其中惟五十一条为豫言标准库之源）。豫言之 JSON 解析器不能吞五十七兆，亦不当每事一解；宿主以 `DecompressionStream` 解而析之，惟留键以 `/库/标准库/` 起首之字符串条，应用每回但得所需之键列或某键之文。
- **授权**：`标准库` 映于许可所授服务绑定 `BROWSER_COMPILER`（`许可.json` 之 `SERVICE` 须有之），网址固定为 `https://playground.yuyan-lang.org/编译/资源/标准库.json.gz`，客不得自择其源。

验见 `一致性验证/`。
