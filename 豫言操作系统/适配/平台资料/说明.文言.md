# 平台资料云工适配

以公共[平台资料公约](../../../豫言操作系统接口/平台资料/规范.文言.md)映于云工宿主。适配甚薄：验参（集名一至六十四字节而无控制之字、前缀至多五百一十二字节、键一至五百一十二字节，违者抛「平台资料参数无效」）与整形其果；真取资料、解压、筛键、排序与缓存，皆在宿主 JS `豫言操作系统/宿主/云工/平台资料.mjs`，经二新宿主原语：

- `豫言_云工_平台资料列键安全(集, 前缀)`：返（成否，JSON 字符串数组文或错误文）；
- `豫言_云工_平台资料读文字安全(集, 键)`：返（状，文或错误文），状零键在、一键不在、二败。

二原语皆“安全之变体”：宿主之败以值返之，适配复转为可捕之豫言异，不令 JS 异越 Wasm 之界。

- **何以置于宿主**：云工作台之资料集 `标准库`，乃约二兆七之 gzip（解之约五十七兆之 JSON，凡一千八百七十九条，其中惟五十一条为豫言标准库之源）。豫言之 JSON 解析器不能吞五十七兆，亦不当每事一解；宿主以 `DecompressionStream` 解而析之，惟留键以 `/库/标准库/` 起首之字符串条，依宿主实例而缓之，应用每回但得所需之键列或某键之文。
- **授权**：`标准库` 映于许可所授服务绑定 `BROWSER_COMPILER`（`许可.json` 之 `SERVICE` 须有之），网址固定为 `https://playground.yuyan-lang.org/编译/资源/标准库.json.gz`，客不得自择其源。
- **接入宿主之改（主代理任之，本目录不改共享之 `宿主.mjs`）**：`宿主.mjs` 首 `import {创建平台资料} from './平台资料.mjs'`；`创建云工宿主` 中 `const 平台资料 = 创建平台资料({全局})`；能力表登记上二原语；`工具/双宿主构建/入口。豫` 复制宿主文件之清单添 `平台资料.mjs`。改动之片段见 `平台资料.mjs` 文末之注。

验见 `一致性验证/`。
