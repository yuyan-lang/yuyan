# 图形处理器浏览器适配

`图形。豫` 以浏览器之 WebGPU 行[图形处理器接口](../../../豫寓榫卯/图形处理器/规范.文言.md) 零点三点零（并深度、剔法与分段索绘）。凡 WebGPU 之调皆在宿主 `宿主/浏览器/图形.mjs` 之纯工厂 `创建图形能力`；适配编豫言之枚举与列为 JSON 之文（物以宿主之号），由唯一之原语 `豫言_浏览器_图形(操作, 参数, 字节)` 交宿主，写入之字与 WGSL 之源另以字节传之，返（码、物号、文、读回之字）。`实现接口。豫` 定公约之身份与版。[图形处理器节点适配](../图形处理器节点/说明.文言.md)之 `图形。豫` 与此大略相同（外调与私构之名异，深度、剔法与分段索绘依诺驿只修不扩之法返校验之误），宿主之 `创建图形能力` 亦为节点所共，改则两处同改。

- **设备与限额**：`取图枢` 调 `navigator.gpu.requestAdapter()`，缓冲、存储绑定、二维纹理之边、工作组诸限皆依适配器之极而求之（求之不得则退用默认）；浏览器无 WebGPU 或无适配器则返 `资源暂不可用`。首版于浏览器恒许，不返 `未获授权`。`读器限额` 之第六项恒为十六兆，即值桥一值之限。设备之 `lost` 既兑，`读器态` 返 `设备已丢失` 而附其因；`释图枢` 调 `destroy()`，其后状态为 `设备已丢失 设备已释放`。
- **物与失效**：物各有号于宿主之表，单调而增，不复用，并记所属之设备。有错支之术遇已毁之物或设备已释、已失者，返 `图形系统错误 资源已失效`；`呈图形令` 返 `命令未提交`；无错支之写与毁，遇已毁之物或已释之设备则终止此行，设备已失则默然略之（设备之失异步而至，应用不能先避）。
- **校验**：诸建之调皆以 `pushErrorScope('validation')` 与 `pushErrorScope('out-of-memory')` 包之，校验之误返 `图形校验错误` 附 WebGPU 之辞，存储不足返 `资源配额已尽`；管线用 `create…PipelineAsync`，`GPUPipelineError` 亦为校验之误。`译点染篇` 取 `getCompilationInfo()` 之误，逐条书为“第几行第几列：辞”。宿主先依规范核字数须为四之倍、纹理宽高之域、`存储纹理用途` 惟许三格式等，乃交 WebGPU。
- **读回**：宿主新建 `MAP_READ | COPY_DST` 之暂存缓冲，复之而 `mapAsync`，自候此前所交诸命令毕；纹理读回每行齐于二百五十六字，读毕去其衬而紧排之。逾十六兆返 `图形校验错误`；暂存之复与交亦包于误域，复之校验不过亦返 `图形校验错误`。
- **命令**：`呈图形令` 先解列中诸号（有失效者全列不行而返资源已失效，异设备者返校验之误），乃录全列于一编码器，一 `queue.submit` 而已：有一不过，WebGPU 使全命令缓冲无效，全列皆不行；其误由误域返之。渲染通道之每绘，依次设管线、绑定组（序即组号）、顶点缓冲（序即槽号）；`索引绘制` 用 `uint32` 之索引；`三角形带` 之管线带 `stripIndexFormat: uint32`。
- **深度（二版）**：`深度单精度` 译作 `depth32float`，`深度目标用途` 译作渲染附件之用（深纹惟此一用，不带复制）；宿主先核深格与深用相配，深纹写之则终止此行，读回则返 `图形校验错误`。`置深度渲染管线` 之参多带 `深度`（比法之名从 WebGPU、写深与否），宿主加之以 `depthStencil`；`深度渲染通道` 之参多带 `深度`（深纹之号、清深之值或空），宿主录为 `depthStencilAttachment`。管与道配否，由 WebGPU 校之，不配则全列不交。
- **剔法与分段索绘（三版）**：`不剔除`、`剔背面`、`剔正面` 译作 `none`、`back`、`front`，`置剔除渲染管线` 与 `置剔除深度渲染管线` 之参多带 `剔除`，宿主书于 `primitive.cullMode`（正面用 WebGPU 缺省之逆时）。`索引段绘制` 之索字段编为录（缓号、首索、基顶），宿主 `setIndexBuffer` 后以 `drawIndexed(索数, 实例数, 首索, 基顶)` 绘之；`索引绘制` 仍以缓号与 `drawIndexed(索数, 实例数)`。
- **混合**：`透明混合` 色以 `src-alpha / one-minus-src-alpha`，透明度以 `one / one-minus-src-alpha`；`相加混合` 皆 `one / one`。
- **限先于豫言核之**：值桥一值逾十六兆则抛不可捕之 JS 异，故写入之字、着色之源与参数之 JSON 先于适配核其长：写逾限则终止此行，源与参逾限返 `图形校验错误`。

私构（`浏览器图形设备`、`浏览器图形纹理` 等）不在公约，应用勿用；图形显示之桥接适配赖之以取物号。诸术皆可挂起（JSPI）。宿主初用乃动态载 `图形.mjs`，不用图形之应用不取之。

**验收**：`../图形显示浏览器/一致性验证/`（探针应用、真 Chrome 之行法与验收之单）；宿主之单元测试在 `宿主/浏览器/图形。测试.mjs`（伪 GPU）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「网览东道」之「图形本术」之「网览图形操作」（旧外调名 `豫言_浏览器_图形`）。宿主实此诸导入，与旧原语同。
