# 图形处理器浏览器适配一致性验证

本目录在真实浏览器里验证[图形处理器接口](../../../../../豫寓榫卯/图形处理器/规范.汉语.md) 0.4.0 的网页适配（`../`）。适配的宿主单元测试在 `豫言操作系统/宿主/浏览器/图形。测试.mjs`，只用手写伪 GPU 核对传给 WebGPU 的描述；这里的探针在真 WebGPU 上画图并读回数值，与金属适配的同名验收比对。

**内容**

- `应用/纹采探针/`：探针应用，包「纹采探针应用」，包描述存成 `.txt`，免得被包发现当成包。它把 `图形处理器原生/测试/纹采。测试。豫` 的九项在网页平台重跑一遍：采样纹理、渐远层、比较采样的阴影、逐实例布局、半精度相加混合、红单八位、四倍多重采样（带多重采样深度附件）合入、双颜色目标，以及各项校验。每项通过时打印一行读数，读回数值须与金属一致。
- 测试页：`豫言操作系统/宿主/浏览器/纹采。测试页.html`（非豫言代码按规定放在宿主目录），用 `启动豫言浏览器应用({输出})` 把探针输出写进 `#结果`，结束后给 `<html>` 加 `data-探针="完成"`。地址带 `?等待=毫秒` 时插入一张由服务延迟响应的图片，拖住 load 事件，供无头 Chrome 的 `--dump-dom` 在探针结束后导出页面。
- 本机服务：`豫言操作系统/宿主/浏览器/真浏览器服务.mjs`，静态提供产物目录与测试页，另设 `/api/slow`。

**复跑**（在构建根，即语言仓根目录；需已构建 `豫构`，工具链须含点染（着色翻译）的 0.4.0 着色内建，纹采着色源用到比较采样等；勿与别的构建并发）

```sh
# 1. 构建探针；浏览器模式按宿主支持清单绑定 适配/图形处理器浏览器
./豫构。林纳。豫行 发行 浏览器 豫言操作系统/适配/图形处理器浏览器/一致性验证/应用/纹采探针 dist/纹采探针 --包根 库/点染
# 2. 起本机服务
node 豫言操作系统/宿主/浏览器/真浏览器服务.mjs dist/纹采探针 18768 &
# 3. 有头浏览器打开，肉眼核对输出
open "http://127.0.0.1:18768/纹采。测试页.html"
# 4. 无头 Chrome 导出页面（本机无 WebGPU 时去掉 --enable-unsafe-webgpu 会取不到设备）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言纹采探针 --dump-dom "http://127.0.0.1:18768/纹采。测试页.html?等待=8000" > 纹采探针输出.html
```

- `纹采探针输出.html` 的 `<pre id="结果">` 应依次出现“一、采样纹理：通过；左上 255,0,0,255，右下 255,255,0,255”等九行读数，最后是“纹采九项通过：采样纹理、渐远层、比较采样的阴影、逐实例布局、半精度相加混合、红单八位、四倍多重采样合入、双颜色目标与各项校验都与金属一致”，`<html>` 带 `data-探针="完成"`。
- 任何一项不符时，页面打印“失败：”和事由、像素坐标、期望与实得，供比对金属的同名测试输出。
- 无头 Chrome 不支持 WebGPU 时 `取图枢` 返回 `资源暂不可用`，页面打印“失败：取图枢返回 资源暂不可用”；这时改用有头浏览器。
- 这台 Chrome 导出页面后进程可能不退出：输出文件出现 `</html>` 后结束它即可。
- 无头 Chrome 的 `--dump-dom` 在探针跑完之前就可能导出（页面顶层的 await 不挡它）；无头验收时让测试页把每行读数 POST 给服务，或直接用有头浏览器看页面。

## 验证记录

**2026-10-21，pit-mac（Apple M2 Max），Chrome 154.0.8037.98，`--headless=new --enable-unsafe-webgpu`（WebGPU 走 Metal），本机静态服务。** 纹采探针九项全部通过，读回数值与金属一致：

- 一、采样纹理：左上 `255,0,0,255`，右下 `255,255,0,255`。
- 二、渐远层：第一层左红右蓝，第二层 `128,0,128,255`（金属为 127 或 128，都在中值附近）。
- 三、比较采样的阴影：左 `0,0,0,255`，右 `255,255,255,255`。
- 四、逐实例布局：四个象限依次红、绿、蓝、白。
- 五、半精度相加混合：`16384,14336,13312,16384`。
- 六、红单八位：画 0.2 读回 `51`。
- 七、四倍多重采样（带多重采样深度）：对角 `128,0,0,255`，内侧 `255,0,0,255`。
- 八、双颜色目标：八位 `0,255,0,255`，半精度 `14336,13312,16384,15360`。
- 九、校验：格式不配整列不提交、采样数二不建、深度纹理不衍生渐远层、无采样用途不能绑组、多重采样不能读回。

无头验收让测试页把每行读数 POST 给本机服务，免得 `--dump-dom` 在 GPU 跑完之前导出页面；有头浏览器直接看页面即可。
