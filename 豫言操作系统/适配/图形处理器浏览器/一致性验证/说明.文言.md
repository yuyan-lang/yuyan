# 图形处理器浏览器适配一致性验证

此目录以真浏览器验[图形处理器接口](../../../../../豫寓榫卯/图形处理器/规范.汉语.md)四版之网页适配（`../`）。适配之宿主单元试在 `豫言操作系统/宿主/浏览器/图形。测试.mjs`，惟以手写伪 GPU 核其所授 WebGPU 之述；此之探针于真 WebGPU 上绘图而读回其数，与金属适配同名之验相较。

**所容**

- `应用/纹采探针/`：探针之应用，包「纹采探针应用」，其包述存为 `.txt`，以免为包发现所收。取 `图形处理器原生/测试/纹采。测试。豫` 之九验于网页之平台重行：采纹、渐远、比较采影、逐例之布、半精相加、红单八位、四采（带多采之深附）合入、双鹄，及诸校验。每项过则书一行所读，所读须与金一致。
- 试页：`豫言操作系统/宿主/浏览器/纹采。测试页.html`（非豫言之码依规置于宿主之目），以 `启动豫言浏览器应用({输出})` 收探针之出于 `#结果`，毕则给 `<html>` 加 `data-探针="完成"`。地址带 `?等待=毫秒` 者，插一延迟之图以拖 load 之事，供无头 Chrome 之 `--dump-dom` 候探针之毕。
- 本机之服：`豫言操作系统/宿主/浏览器/真浏览器服务.mjs`，静供产物之目与试页，另设 `/api/slow`。

**复跑**（于构根，即语言仓之根；须已构 `豫构`，其工具链须含点染四版之着色内建，纹采之着色用比较采等；勿与别构并发）

```sh
# 1. 构探针；浏览器之式按宿主支持之簿绑 适配/图形处理器浏览器
./豫构。林纳。豫行 发行 浏览器 豫言操作系统/适配/图形处理器浏览器/一致性验证/应用/纹采探针 dist/纹采探针 --包根 库/点染
# 2. 起本机之服
node 豫言操作系统/宿主/浏览器/真浏览器服务.mjs dist/纹采探针 18768 &
# 3. 有头之浏览开之，目核其出
open "http://127.0.0.1:18768/纹采。测试页.html"
# 4. 无头 Chrome 导出其页（本机无 WebGPU 者去 --enable-unsafe-webgpu 则不得其器）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言纹采探针 --dump-dom "http://127.0.0.1:18768/纹采。测试页.html?等待=8000" > 纹采探针输出.html
```

- `纹采探针输出.html` 之 `<pre id="结果">` 当次第见“一、采样纹理：通过；左上 255,0,0,255，右下 255,255,0,255”等九行所读，终以“纹采九项通过：采样纹理、渐远层、比较采样的阴影、逐实例布局、半精度相加混合、红单八位、四倍多重采样合入、双颜色目标与各项校验都与金属一致”，`<html>` 带 `data-探针="完成"`。
- 一有不合，页书“失败：”与其事、位、所期与所得，以供较金属同名之试。
- 无头 Chrome 不支 WebGPU 者，`取图枢` 返 `资源暂不可用`，页书“失败：取图枢返回 资源暂不可用”；此时改有头之浏览。
- 此 Chrome 导出其页后或不去：出文见 `</html>` 而后止之。
- 无头 Chrome 之 `--dump-dom` 或于探针未毕而先出（页顶之 await 不阻之）；无头之验，令试页以每行所读 POST 于服，或径用有头之浏览观之。

## 验证之记

**二〇二六年十月二十一日，pit-mac（Apple M2 Max），Chrome 154.0.8037.98，`--headless=new --enable-unsafe-webgpu`（WebGPU 走金属），本机静服。** 纹采之探九验皆过，所读与金一致：

- 一、采纹：左上 `255,0,0,255`，右下 `255,255,0,255`。
- 二、渐远：一层左红右蓝，二层 `128,0,128,255`（金为百二十七或百二十八，皆近中）。
- 三、比较采影：左 `0,0,0,255`，右 `255,255,255,255`。
- 四、逐例之布：四象次第红、绿、蓝、白。
- 五、半精相加：`16384,14336,13312,16384`。
- 六、红单八位：画零点二读得 `51`。
- 七、四采（带多采之深附）：对角 `128,0,0,255`，内侧 `255,0,0,255`。
- 八、双鹄：八位 `0,255,0,255`，半精 `14336,13312,16384,15360`。
- 九、校验：格不合不呈、采数二不建、深纹不衍层、无采样之用不入组、多采不可读。
