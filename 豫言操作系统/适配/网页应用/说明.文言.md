# 网页应用浏览器适配

`应用。豫` 行[网页应用之约](../../../豫言操作系统接口/网页应用/规范.文言.md)之诸函数：`启动页面应用`。`实现接口。豫` 定公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（须候者）二原语，操作名为 `应用.启动`（异步，经 `豫言_浏览器_网页能力异步`）；败则以（阴，错误文）返，本适配转为豫言事故，不使 JavaScript 之异常越 Wasm 之界。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`。宿主验入口之径（同源、以“/入口.mjs”终、无“..”与查询、片段），以 `import()`（可由 `创建浏览器宿主({导入模块})` 注入）载其模块，调其 `启动豫言浏览器应用()`，候子应用就绪（三十秒为限）；同径惟启一次，至多八个；宿主闭则子应用一并闭。

**运行之要**：候事之函数挂豫言之栈，浏览器须支持 JSPI；八新包与网页事件包共一统一事列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用“前端接口探针”、宿主单元测试与 JSDOM 加真实 Wasm 之一致性测试，说明见其中之 `说明.文言.md`）。
