# 网页事件源浏览器适配

`事件源。豫` 行[网页事件源之约](../../../豫言操作系统接口/网页事件源/规范.文言.md)之诸函数：`打开事件源`、`关闭事件源`。`实现接口。豫` 定公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力`（同步）与 `豫言_浏览器_网页能力异步`（须候者）二原语，操作名为 `事件源.打开`、`事件源.关闭`；败则以（阴，错误文）返，本适配转为豫言事故，不使 JavaScript 之异常越 Wasm 之界。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`。宿主以 fetch 流行 SSE（不用原生 EventSource，盖原生之物无背压）：`创建SSE解析器` 依 WHATWG 之规切事，宿主成批投之，类曰“事件流”；每事件源于列中未取之批达八则止读其流，客取后复续，故不失事。断则自带 Last-Event-ID 而重连，重连之间可由服务器之 retry: 调之；HTTP 非二百、类型不合或事过大为致命之错。

**运行之要**：候事之函数挂豫言之栈，浏览器须支持 JSPI；八新包与网页事件包共一统一事列。

**验收**：一致性验证见 `../网页定时/一致性验证/`（探针应用“前端接口探针”、宿主单元测试与 JSDOM 加真实 Wasm 之一致性测试，说明见其中之 `说明.文言.md`）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「浏览器宿主」之「网页能力原语」之「浏览器网页能力」（旧外调名 `豫言_浏览器_网页能力`）。宿主实此诸导入，与旧原语同。
