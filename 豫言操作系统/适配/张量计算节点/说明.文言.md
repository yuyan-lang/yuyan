# 张量计算接口节点适配

此为路一节点宿主之[张量计算接口](../../../豫言操作系统接口/张量计算/规范.文言.md)适配。张量之存为宿主之 `SharedArrayBuffer`，不受 Wasm 内存之限，宿主之工作线程可径读写；客惟持随机之号，宿主每用必核其类与存亡，与文件之柄共一资源之表。

- 后端：此适配有中央处理器（宿主以 JS 算之）、金属与统算三后端。`取得张量上下文` 先视宿主之选 `--张量后端`（验用，书于 `--` 之前）：有所指则惟用之，不可用或不合必须加速者返 `资源暂不可用`；无所指则依加速之求自择：必须者取首一可用之加速后端，偏好者与不限者皆先求加速之后端（苹果则金属，林纳克斯则统算），无则用中央处理器。加速之后端惟宿主予 `--允许系统库调用` 乃可用，故未予此选则不限者犹用中央处理器。金属可用之条：苹果之系统、予此选、能取默认之金属器；统算可用之条：林纳克斯、予此选、有 libcuda.so.1 与卡（用第零卡）。功耗之好今无所为。`读取后端名称` 与 `上下文已加速吗` 依境之后端答之。网页图算后当接之：改可用之探与「节点张量取得后端上下文」，器表见 `库/张量后端`。
- 金属：金属之境乃宿主之境加一张量后端（`库/张量后端`：存缓之存、管线之存、命令合批、延释；诸境共 `库/金属张量后端` 之一金属器）。张量犹存于宿主，金属之缓零抄裹宿主之存所在之整页（小存系时带页内之偏）；金属张量存其视之信（存址、类、起、形、步），GPU 之果与视之信径推之，余张量初用乃问宿主（由 `系统库调用` 之张量存与视之原语）。有「张量内核」之核而类与布合用之算，于 GPU 算之，惟记于今命令之缓：矩阵乘（甲单精；乙为单精、半精、脑浮点、Q8_0、Q4_K 或 Q6_K；块量化之乙依「量化宜分块」择矩阵向量乘或分块矩阵乘；单精之边行不连续则先于 GPU 紧致之，临时者俟下次同而还）、逐元二元、逐元一元、逐元与数（兼数乘、数加）、软最大、末维求和、末维最大、均方根归一与层归一（权、偏为浮点）、二范数归一、旋转位置编码（角表由 C 数学之库以双精求之复舍为单精，依（起位，词数，旋维，基数）存最近一表，诸层共之）、注意（键值单精或半精；解码等「注意力宜分段」为真则分段而后合，暂存之张量依境存之、诸层共之，不足则易新）、写入行（目单精或半精）、取行（表为浮点或块量化）、按轴求和、按轴最大、三十二位之类之紧致与切片、转置、拼接、写视（同类而不共存）、填常（单精）、按行累加、就地线性组合、亚当更新（1 − βᵗ 由 C 数学之库以双精求之）、取前 k、按行最大下标、类型转换（转单精，或由单精转半精、脑浮点）；软最大与取前 k 于长行依「软最大宜分段」「取前k宜分段」析为二派，暂存之张量俟下次同而还。余者（随机之填、因果卷积、门控递推、按专家矩阵乘、三十二位整数之填、不连续或类不合之入等）付宿主：付之前先同（交而候已记之派），宿主就地所改之张量又调「节点张量主机已改」（金属存统一，无为）。读字、读小数、取最大下标、依概率抽样亦先同；形、类、步及改形、跨步视图不读写其数，不同。释张量时，若未交之派犹用其存，先建一共存之视以存之，即释原号（后用之犹报资源已失效），视与缓俟下次同而释；释境之前先同而尽释其缓。待办事项：随机之填、因果卷积、门控递推、按专家矩阵乘接已有之核；解码每词元犹编约五百派，每派经系统库之调十余次，其费过 GPU 之算，可并派或减其调。
- 统算：统算之境同金属，乃宿主之境加一张量后端，诸境共 `库/统算张量后端` 之一统算器（第零卡之主上下文）；于 GPU 所算之算、付宿主前之同、宿主已改与延释皆同金属（段长与阈依「后端种类」取统算之值）。所异者，显卡自有显存：张量犹存于宿主，初于 GPU 用之则上传一副于显存而常驻（权惟传一次）；宿主就地改之而调「节点张量主机已改」者，次用乃重传；同时下本批 GPU 所写之存回宿主。派于交时连发，参数之区与参指之组一次书之。二〇二六年九月三十日于 NVIDIA GeForce RTX 5090（其时显卡并为他程所占）：节点一致性百三十七/百三十八（惟「张量·后端」一行异），深度学习框架之试五十六/五十六，qwen3:0.6b-q8_0 贪心六十四词元与中央处理器逐号同，其速见本地推理与手写数字训练之说。待办事项：同时整块下本批所写之存（可改为宿主将读乃下）；新建之果张量亦先上传宿主之全零。
- 上限：`读取张量存储上限` 为本机之物理内存（`os.totalmem()`）；`读取单次交换上限` 为十六兆字节（值桥单次交换之限），适配先于豫言核其字数。
- 形与行号等整数之列，书为逗号所隔之十进制文以过值桥；元之类、算、旋转之式，皆化为号（元之类零至七，依次为单精度、半精度、脑浮点、八位整数、三十二位整数、块量化八位、超块量化四位、超块量化六位）。
- `由小数建张量` 先由宿主核之而建全零之张量，后逐元置之；`读出张量小数` 先核其范，后逐元取之。每元一召宿主，大块之数宜用字节之函。
- 算：JS，先以双精求之，后舍为单精。乙为块量化之矩阵乘，皆逐块随解而求点积（Q8_0 一次算甲一行乘乙二行，或甲二行乘乙二行，乙块一读而供多行），每元之算次同逐行之点积，故预填与解码于同一行之果一致；乙为单精、半精者径求点积，脑浮点者逐行化为单精。量化之式一依 GGML：Q8_0 之解与 `quantize_row_q8_0_ref` 之量，Q4_K、Q6_K 之 `dequantize_row_q4_K`、`dequantize_row_q6_K`。
- 参数不合（类、形、轴、范不合，或张量异境）者，宿主抛异而终其行；算子之果逾存储之限亦终之。有误支之函遇已释之张量或境，返 `资源已失效`。
- `改形` 之果与原张量共一存（以引用之数计入存储之限一次），释其一不害其二。
- 视（0.3.0）：宿主为每张量记其步与起（以元计）；`跨步视图` 惟登新步与起，与原共存（亦以引用之数计）。算子遇非连续之入，先紧致于临时之共享缓（不计入存储之限，待办事项），逐元二元与逐元标量则依步径读；`写入视图`、`填充常数` 与三随机之填依步写回共存。`改形`、`写入张量字节`、`写入行`、`按行累加` 遇非连续者止其行。
- 随机（0.3.0）：Philox4x32-10 于宿主以三十二位整数之算为之（积之高三十二位，析为十六位二半而求），已以 Random123 三组已知之答核之；正态用 Box–Muller。新增之原语皆主线独算。
- 混合专家与线性注意（0.4.0）：`按专家矩阵乘` 聚择同一专家之行为一入阵，以其专家之阵一乘之（与 `矩阵乘` 同分块并行与融合量化之点积，与单专家之矩阵乘逐位同），后散回原位；`门控递推` 依头分块付线程之池，状态以单精存回，中间以双精；`取前k` 逐次择其最大（O(k × 行长)），`因果卷积`、`二范数归一` 主线独算。待办事项：诸专家之矩阵乘各派，解码时每层三派八专家，可合为一派；门控递推之预填犹逐词，可改分块之法。
- 训练之速（0.4.0）：逐元二元、逐元标量、逐元一元（兼数乘、数加）、紧致化、同类之写入视图与填充常数，皆付线程之池依元分块而算（块可起于行中，依步径读写其视，不必先紧致；加减乘除、比较与抄，每元以半工计）；新增就地线性组合、亚当更新（依元分块并行）、按轴求和与按轴最大（入视为 [外, 轴长, 内]，依（外，内段）分块并行，和依轴序以双精累之）、按行最大下标（同取前 k 之取一）。每出之元惟一线依定序求之，多线之果与单线逐位同。
- 并行：矩阵乘依出而分块，注意依（词，问头）而分块，工多则宿主之工作线程共为之；线程之数所取与所调，见[节点宿主之说](../../宿主/节点/说明.文言.md)。诸线竞领其块，每元惟一线依单线之序求之，故果与单线逐位同；于客犹为同步之调。

新增宿主原语（外调名冠 `豫言_节点_张量`，凡五十八），实于 `豫言操作系统/宿主/节点/张量.mjs`，由 `应用宿主.mjs` 并入能之表；发行之启动文件内联此模。码同文件适配。待办事项：Q4_K、Q6_K 多行之矩阵乘犹逐行求点积；前 k 抽样改用部分之择；三十二位整数化脑浮点，绝对值逾 2^24 者二舍。
