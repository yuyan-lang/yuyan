# 定时事件落盘适配

给服务程序的定时器用的两件事：把一次 cron 触发写成 JSON 交给应用，从盘上的数据文件读出要安排的定时表。供豫言系统与原生宿主上的服务程序使用。

## 定时事

`定时事` 携带 cron 表达式原文与计划触发时刻（Unix 毫秒）。宿主在定时器到点时用 `盘定时事` 造出（先核对时刻在 0 至 8640000000000000 之间，越界报 `定时事件的计划时刻无效`），交给应用入口 `理定时事`；应用用 `读定时事文` 取回 JSON 文字：

```json
{"cron":"*/10 * * * *","scheduledTime":1758801600000}
```

字段顺序固定为 `cron` 在前、`scheduledTime` 在后；时刻是整数，不经浮点。适配不解析 cron、不枚举部署清单、不承诺准点，也不去重。

## 定时表

定时器按 `<金匮根>/定时。数据。豫` 里登记的表达式排周期：

```yuyan
「定时」者「列」【「组值」【「式」者『*/10 * * * *』也】】也。
```

`读定时表` 返回其中各条的 `式` 文字组成的列；文件不存在时得空列。每次调用重读，改了文件立刻生效。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓更鼓金匮榫」之「事件」之书。

「设匮根」于『/某处的数据盘/豫言』。
「表」者「读定时表」于「元」也。
「事」者「盘定时事」于「式」曰（「第」于「零」于「表」）于「刻」曰「一七五八八零一六零零零零零」也。
「读定时事文」于「事」。
```

## 测试

`测试/事件。测试。豫` 核对序列化文本、越界时刻报错、定时表读取与重读。
