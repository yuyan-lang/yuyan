# 定时事件落盘适配

为服务之程之漏刻二事：述一次 cron 之触发为 JSON 以授应用，自盘上之数据文件读所排之定时表。供豫言系统与本土之宿主用。

## 定时之事

`定时事` 携 cron 之原文与计划之刻（Unix 毫秒）。宿主于漏尽时以 `盘定时事` 造之（先核其刻在零至八千六百四十兆之间，越度者告 `定时事件的计划时刻无效`），授应用之口 `理定时事`；应用以 `读定时事文` 取其 JSON 之文：

```json
{"cron":"*/10 * * * *","scheduledTime":1758801600000}
```

栏序定 cron 在先、scheduledTime 在后；刻为整数，不经浮点。适配不析 cron、不枚举部署之册、不诺准点，亦不去重。

## 定时之表

漏刻依 `<金匮根>/定时。数据。豫` 所登之式而排：

```yuyan
「定时」者「列」【「组值」【「式」者『*/10 * * * *』也】】也。
```

`读定时表` 还其中诸条之 `式` 所成之列；无其卷则空列。每用重读，改之即见。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓更鼓金匮榫」之「事件」之书。

「设匮根」于『/某处的数据盘/豫言』。
「表」者「读定时表」于「元」也。
「事」者「盘定时事」于「式」曰（「第」于「零」于「表」）于「刻」曰「一七五八八零一六零零零零零」也。
「读定时事文」于「事」。
```

## 试

`测试/事件。测试。豫` 核述文、越度之刻告祸、定时表之读与重读。
