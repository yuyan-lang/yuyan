# 网址查询一致性验证（0.1.0）

本目录用真实的 Wasm 与 Node 宿主验证 `豫言操作系统网址查询` 0.1.0 的云工适配：

- `应用/网址查询一致性应用/`：试验应用。包描述存为 `网址查询一致性应用。包。豫.txt`，避免被 `yy豫构` 的全仓库包发现当成包解析；构建脚本 `建应用.sh` 会把它复制到暂存内的临时目录并改回原名。
- `网址查询一致性.test.mjs`：Node 测试，加载构建产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑（用私有暂存）

1. 建暂存（一次）：`建暂存.sh <暂存目录>`，它把语言仓的只读材料符号链接进来并复制编译器与构建工具。
2. 构建：`建应用.sh <暂存目录> 云工 <本目录>/应用/网址查询一致性应用 网址查询一致性`，产物在 `<暂存目录>/dist/网址查询一致性/`。
3. 测试：`cd <暂存目录> && node --test <本目录>/网址查询一致性.test.mjs`。产物根默认为当前目录下的 `dist`，可用环境变量 `产物根` 改写。

## 覆盖

- `编码查询串`：与 `URLSearchParams` 序列化逐字相同，覆盖空格、保留符号 `!'()~`、UTF-8、控制字符、同名项、空键值、1024 项与 1 MiB 边界；
- `解析表单键值`：与 `URLSearchParams` 的解析结果相同（保序、加号、百分号、非法 UTF-8、开头问号、控制字符、1 MiB 边界）；
- `设置网址查询参数`：绝对与相对网址与 `URL` + `searchParams.set` 的结果相同；来源改变、非 HTTP(S)、无效网址与 64 KiB 限额的失败。

每个测试都断言真实 Wasm 的可观察行为；期望值凡能由平台标准实现给出的（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`）都取自同一标准实现，不手抄。
