# 基础接口适配

此包处独立目录，以旧标准宿主之输出与单调钟，行根目录[基础接口之约](../../../豫言操作系统接口/基础/规范.文言.md)二术。诊断循旧输出，纳秒化整数微秒；浏览器、云工、节点各守其底层实现，此包不抄之。

今普通编译器未能以纯「。接口。豫」为所依，故此包为可编之过渡适配。签名与行为须循接口检查与共验样例核之；绑定器既成，客当直依规范包。此包不载各地私物。

「实现接口。豫」静载所行公约之主、名、全版与宿主之任，检查器先核其身份，再核术型。

「装载核对.mjs」可通用于三种 JS 宿主。受已编之 Wasm 客器、应用所需与宿主所供之第四版清单，先核基础包全身份、传递所依、规范 SHA-256 摘要及二术之向与型，再核今编译投影之通桥导入及 `_start` 导出；若有启动清单，亦核「启动程序」之向与型。基础构建包装已于浏览器、云工成品之默认入口召之；节点于造客实例前亦可召之。

三端首轮所验及余缺，见[验证记录](验证.文言.md)。
