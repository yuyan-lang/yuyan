# 基础接口适配

本包在独立目录中把根目录[基础接口规范](../../../豫言操作系统接口/基础/规范.汉语.md)的两项公共函数接到已有标准库宿主调用。`记录诊断` 复用现有输出，`读取单调微秒` 把现有单调纳秒读数换算为整数微秒。浏览器、CF Worker 和 Node.js 的底层时钟与输出由现有宿主提供；本包不复制它们的实现。

现阶段普通编译器不能以 `。接口。豫` 为依赖，因此这是可编译的过渡适配包。公共签名必须由接口检查和共同样例与规范核对；待纯接口绑定进入编译链后，应用应直接依赖规范包。此包不包含宿主专有对象。

`实现接口。豫` 用静态豫言配置声明所实现的公共接口身份、完整版本和宿主角色；接口检查器在签名比对前核对它。

`装载核对.mjs` 是三种 JS 宿主可共用的首批成品预检：接收已编译的 Wasm 模块、应用要求和宿主提供的版本 4 接口清单，在调用应用入口前核对完整基础包及传递依赖身份、规范 SHA-256 摘要、两项公共函数的方向与签名，以及当前编译器的通用 Wasm 导入和 `_start` 导出。若应用提供启动清单，也核对 `启动程序` 的方向与签名。[基础构建包装](../../../工具/豫言操作系统基础构建/说明.汉语.md)会把它接到浏览器与 Worker 成品的默认入口；Node/V8 运行者在创建实例前调用同一函数。

三端首轮运行证据和剩余检查边界见[验证记录](验证.汉语.md)。
