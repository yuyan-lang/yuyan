# 基础接口适配

本包在独立目录中把根目录[基础接口规范](../../../豫寓榫卯/基础/规范.汉语.md)的两项公共函数接到已有标准库宿主调用。`记录诊断` 复用现有输出，`读取单调微秒` 把现有单调纳秒读数换算为整数微秒。浏览器、CF Worker 和 Node.js 的底层时钟与输出由现有宿主提供；本包不复制它们的实现。

普通编译器已能导入 `。接口。豫` 并按签名做类型检查，但未经绑定运行时调用接口函数会报“接口函数未绑定”，因此这是可运行的过渡适配包。公共签名必须由接口检查和共同样例与规范核对；待纯接口绑定进入编译链后，应用应直接依赖规范包。此包不包含宿主专有对象。

`实现接口。豫` 用静态豫言配置声明所实现的公共接口身份、完整版本和宿主角色；接口检查器在签名比对前核对它。

三端首轮运行证据和剩余检查边界见[验证记录](验证.汉语.md)。
