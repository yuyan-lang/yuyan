# 基础接口节点适配

此为路一节点宿主（`豫言操作系统/宿主/节点/`）之[基础接口](../../../豫言操作系统接口/基础/规范.文言.md)适配。基础有诊断、时钟、错误三模，此适配分为三文，名与模同，`yy豫言操作系统绑定` 一次并绑之；他节点适配（文件、网络）以 `寻观「豫言操作系统基础」之「错误」之书` 取同一 `系统错误` 之类。

- `诊断。豫`：`记录诊断` 书其文于标准误，每条附换行，不混于程序之标准出。
- `时钟。豫`：`读取单调微秒` 取宿主单调之纳秒（节点之 `performance.now()`），化为整微秒；同实例不倒退，原点不作历日。
- `错误。豫`：`系统错误` 及其构造，一依规范之文。

惟用标准库之宿主原语 `豫言_标准错误打印行` 与 `豫言_获取当前纳秒时间`，不增新原语。宿主支持之簿为 `宿主提供.json`，接口检查器自规范生之；规范有改，须复生之。验收见 `豫言操作系统/宿主/节点/一致性验证/`。
