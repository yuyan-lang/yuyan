# 图形探针应用

显示、图形处理器与图形显示三个接口的一致性验收用的豫言应用，浏览器与 Node 共用：依次调用三个接口包的函数，每项打印一行“通过：…”或“失败：…（详情）”，最后打印“探针完成：通过 N 项，失败 M 项”。

- **浏览器**：页面须授予 `像素画面`、`图形画面`、`输入画面` 三个显示面；打印“等待输入：开始”后，它连续等待十个输入事件，与测试页合成的事件逐一核对。测试页是 `豫言操作系统/宿主/浏览器/图形。测试页.html`，运行步骤见 `../../说明.汉语.md`。
- **Node**：宿主选项授予 `像素画面`、`图形画面`（人工验收另授 `输入画面`）。应用参数 `跳过输入` 跳过输入一组，供后台窗口的自动验收；`人工输入` 改为逐个打印输入画面收到的事件，直到窗口关闭，再核对关闭后等待返回资源已失效。运行步骤见 `../../../../图形显示节点/一致性验证/说明.汉语.md`。

为了核对“呈现前重复取得是同一纹理”，探针用适配里的 `纹理号` 取纹理的宿主对象号；图形处理器的浏览器与节点两个适配都有这个函数，所以探针适用于这两种绑定。
