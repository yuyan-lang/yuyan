# 显示、图形处理器、图形显示：浏览器一致性验证

三个接口共用一个探针应用，验证材料集中放在这里。同一个探针也在 Node 上运行，步骤与记录见 `../../图形显示节点/一致性验证/说明.汉语.md`。

**内容**

- `应用/图形探针/`：探针应用源码（包描述存成 `.txt`，免得被包发现当成包）。它依次验证显示（未授权名称、尺寸、字节数与尺寸不符、提交一帧）、图形处理器（设备与限额、缓冲写读、计算着色加倍、不合法 WGSL、清屏读回、三角形中心与角落、坏命令整列不执行、销毁后使用）、图形显示（纹理格式、未取即呈现、三帧取纹理清屏呈现、重复取得同一纹理、帧尺寸、旧帧失效、两种提交互斥）与输入事件，每项打印一行“通过：…”或“失败：…（详情）”，最后打印“探针完成：通过 N 项，失败 M 项”。
- 计算着色加倍与三角形两段 WGSL 由探针目录里的着色源 `加倍着色。着色器。豫`、`三角着色。着色器。豫` 在构建时生成（见 `应用/豫言编译器/文档/语言技术规范/着色语言.汉语.md`）；探针依赖「着色库」，所以构建命令带 `--包根 库/着色库`。
- 测试页：`豫言操作系统/宿主/浏览器/图形。测试页.html`（非豫言代码按规定放在宿主目录）。它授予三个显示面 `像素画面`、`图形画面`、`输入画面`，用 `启动豫言浏览器应用({输出})` 把探针的输出写进 `#结果`；探针打印“等待输入：开始”后，测试页向输入画面合成指针、按键、文字与输入法事件，再移除该 canvas；探针结束后再核对像素画面中心确为蓝色。
- 宿主单元测试：`豫言操作系统/宿主/浏览器/图形。测试.mjs`，用手写的伪文档、伪 canvas 与伪 WebGPU 测 `创建显示能力`、`创建图形能力` 的授权、错误路径、事件转换、命令解码、整列不执行、纹理读回的行对齐与帧纹理呈现，不需要 Wasm 与 JSDOM，全树测试会自动运行。
- `真实浏览器验收清单.汉语.md`：已在真实 Chrome 验过的项与仍须人工验证的项。

**复跑**（在构建根，即语言仓根目录；需已构建 `yy双宿主构建`、`yy4_bs`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；勿与别的构建并发）

```sh
# 1. 构建探针（自动模式为图形处理器、图形显示、显示及它们依赖的基础分别选用 适配/X浏览器/）
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 豫言操作系统/适配/图形显示浏览器/一致性验证/应用/图形探针 dist/图形探针 --包根 库/着色库
# 2. 把测试页放进产物目录，用仓里已有的本机服务提供（.mjs 为 text/javascript，.wasm 为 application/wasm，另有 /api/slow）
cp 豫言操作系统/宿主/浏览器/图形。测试页.html dist/图形探针/
node 豫言操作系统/适配/网页定时/一致性验证/测试/真浏览器服务.mjs dist/图形探针 18766 &
# 3. 无头 Chrome 运行并导出页面；?等待=8000 让测试页插入一张延迟 8 秒的图片，拖住 load 事件，--dump-dom 在探针结束后才导出
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言图形探针 --dump-dom "http://127.0.0.1:18766/图形。测试页.html?等待=8000" > 探针输出.html
# 4. 截图核对 GPU 呈现（WebGPU 画布呈现后不保留图像，页面脚本读不到，只能截图）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言图形探针 --window-size=420,260 --screenshot=探针截图.png "http://127.0.0.1:18766/图形。测试页.html?等待=8000"
# 5. 宿主单元测试
node --test 豫言操作系统/宿主/浏览器/图形。测试.mjs
```

- `探针输出.html` 的 `<pre id="结果">` 应以“探针完成：通过 36 项，失败 0 项”与“通过：页面核对像素画面中心像素为蓝”结束，`<html>` 带 `data-探针="完成"`。截图里前两个 canvas 都应是纯蓝（像素画面提交的一帧、图形画面三帧中的最后一帧），第三个 canvas 已被移除。
- 这台 Chrome（154，macOS）导出页面或截图后进程可能不退出：输出文件出现 `</html>` 或截图文件写出后结束它即可。不要加 `--virtual-time-budget`：虚拟时间下 `requestDevice()` 一直不返回。
- `yy简易网页服务器` 目前把 `.mjs` 当 `application/octet-stream`，模块脚本加载失败，所以这里用网页定时一致性验证里的 `真浏览器服务.mjs`。
- 有头浏览器里人工验证时，去掉 `?等待=…` 直接打开测试页即可；想亲手试输入，先在页面上点输入画面（点击会聚焦宿主插入的隐形输入框），但测试页会在探针进入输入阶段后自动合成事件并移除该画布，人工输入须另写页面或改用网页事件探针的方式。
