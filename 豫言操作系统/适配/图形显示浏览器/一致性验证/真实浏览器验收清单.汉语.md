## 仍须在真实浏览器验证的项

- **真实输入**：真实鼠标与键盘（可信事件、指针捕获在画布外抬起、右键菜单被阻止）；真实中文输入法的组字与提交，候选框位置（现固定在视口左上角）；Safari 里 `compositionend` 与 `keydown` 的先后。
- **高像素比**：Retina 屏上 `devicePixelRatio` 为 2 时尺寸、坐标与 canvas 像素数；缩放页面时的尺寸变化；带边框或内边距的 canvas（现按布局矩形计，会多算）。
- **尺寸变化**：两帧之间改 canvas 的 CSS 尺寸，下一帧取得的纹理随之改变；像素提交在尺寸变化后返回 `资源暂不可用`，重新读取尺寸再提交。
- **大画面**：物理像素超过 2048×2048（RGBA 超过 16 MiB）时 `提交像素画面` 返回 `资源配额已尽`（待办事项：分块传递）。
- **后台与丢失**：标签页在后台时 `呈现显示面` 一直等待；`chrome://gpucrash` 造成设备丢失后 `读取设备状态` 为 `设备已丢失`，带错误分支的函数返回 `资源已失效`。
- **索引绘制、采样器与纹理绑定、三角形带、透明与相加混合、渲染绑定组**：探针未覆盖，宿主单元测试只验了参数编码。
- **兼容**：Firefox 与 Safari 的 WebGPU 与 JSPI；没有 WebGPU 的浏览器上 `取得图形设备` 返回 `资源暂不可用`。
