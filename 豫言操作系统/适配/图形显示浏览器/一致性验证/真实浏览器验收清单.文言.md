## 犹须于真浏览器验者

- **真之输入**：真鼠与键（可信之事、指针捕获而抬于画布之外、右键菜单之阻）；真中文输入法之组字与提交，候选框之位（今定于视口左上）；Safari 中 `compositionend` 与 `keydown` 之先后。
- **高像素比**：Retina 屏 `devicePixelRatio` 为二时之尺、坐标与 canvas 素数；缩页时尺之变；带边框与内距之 canvas（今依布局之矩计之，则多算）。
- **尺寸之变**：两帧之间改 canvas 之 CSS 尺，下帧所取纹理随之而变；像素之交于尺变后返 `资源暂不可用`，重读尺而再交。
- **大画面**：物理之素逾二千零四十八见方（RGBA 逾十六兆）时 `提交像素画面` 返 `资源配额已尽`（待办事项：分块而交）。
- **在后与丢失**：标签页在后时 `呈现显示面` 久候；`chrome://gpucrash` 致设备之失后 `读取设备状态` 为 `设备已丢失`，有错支之术返 `资源已失效`。
- **索引绘制、采样器与纹理之绑、三角形带、透明与相加之混、渲染绑定组**：探针未及，宿主之单元测试惟验参数之编。
- **兼容**：Firefox 与 Safari 之 WebGPU 与 JSPI；无 WebGPU 之浏览器 `取得图形设备` 返 `资源暂不可用`。
