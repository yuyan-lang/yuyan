# 显示、图形处理器、图形显示：浏览器一致性之验

三接口共一探针应用，验材聚于此。

**所含**

- `应用/图形探针/`：探针应用之源（包描述存为 `.txt`，免被包之发现视为包）。依次验显示（未授之名、尺寸、字数与尺寸不合、交一帧）、图形处理器（设备与限额、缓冲写读、计算着色倍之、不合法之 WGSL、清屏而读回、三角之中与角、坏令全列不行、毁后而用）、图形显示（纹理格式、未取而呈、三帧取纹理清屏而呈、再取同一纹理、帧尺、旧帧失效、二提交互斥）与输入之事，每项书一行“通过：…”或“失败：…（详）”，终书“探针完成：通过 N 项，失败 M 项”。
- 测试页：`豫言操作系统/宿主/浏览器/图形。测试页.html`（非豫言之码依规置于宿主之目）。授三显示面 `像素画面`、`图形画面`、`输入画面`，以 `启动豫言浏览器应用({输出})` 书探针之出于 `#结果`；探针书“等待输入：开始”，页乃于输入画面合成指针、按键、文字与输入法之事，而后移其 canvas；探针既毕，页复核像素画面之中确为蓝。
- 宿主之单元测试：`豫言操作系统/宿主/浏览器/图形。测试.mjs`，以手书之伪文档、伪 canvas、伪 WebGPU 测 `创建显示能力`、`创建图形能力` 之授权、错路、事之转、命令之解、全列不行、纹理读回之行齐与帧纹理之呈，不须 Wasm 与 JSDOM，全树测试自行之。
- `真实浏览器验收清单.文言.md`：已于真 Chrome 验者与犹须人验者。

**复行**（于构建根，即语言仓之根；须已成 `yy双宿主构建`、`yy4_bs`、`yy豫言操作系统接口检查`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；勿与他构建并行）

```sh
# 1. 构探针（自动之式为图形处理器、图形显示、显示及其所依之基础各取 适配/X浏览器/）
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 豫言操作系统/适配/图形显示浏览器/一致性验证/应用/图形探针 dist/图形探针
# 2. 置测试页于产物之目，以仓中既有之本机服务供之（.mjs 为 text/javascript，.wasm 为 application/wasm，又有 /api/slow）
cp 豫言操作系统/宿主/浏览器/图形。测试页.html dist/图形探针/
node 豫言操作系统/适配/网页定时/一致性验证/测试/真浏览器服务.mjs dist/图形探针 18766 &
# 3. 无头 Chrome 行之而出其页；?等待=8000 使页插一迟八秒之图，拖其 load 之事，--dump-dom 乃于探针既毕而出
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言图形探针 --dump-dom "http://127.0.0.1:18766/图形。测试页.html?等待=8000" > 探针输出.html
# 4. 截图以核 GPU 之呈（WebGPU 画布既呈则不存其像，页之脚本不得读，惟截图可验）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --enable-unsafe-webgpu \
  --user-data-dir=/tmp/豫言图形探针 --window-size=420,260 --screenshot=探针截图.png "http://127.0.0.1:18766/图形。测试页.html?等待=8000"
# 5. 宿主之单元测试
node --test 豫言操作系统/宿主/浏览器/图形。测试.mjs
```

- `探针输出.html` 之 `<pre id="结果">` 当终于“探针完成：通过 36 项，失败 0 项”与“通过：页面核对像素画面中心像素为蓝”，`<html>` 带 `data-探针="完成"`。截图中前二 canvas 皆当纯蓝（像素画面所交之一帧、图形画面三帧之末），第三者已移。
- 此 Chrome（一百五十四，macOS）出页或截图后其程或不退：出文见 `</html>` 或截图既书，则止之。勿加 `--virtual-time-budget`：虚拟之时下 `requestDevice()` 永不返。
- `yy简易网页服务器` 今以 `.mjs` 为 `application/octet-stream`，模块之脚本载而败，故此用网页定时一致性之验中之 `真浏览器服务.mjs`。
- 于有头之浏览器人验，去 `?等待=…` 径开测试页即可；欲亲试输入，先点页上之输入画面（点之则聚焦宿主所插之隐输入框），然测试页于探针入输入之段即自合成诸事而移其画布，人之输入须别书页，或仿网页事件探针之法。
