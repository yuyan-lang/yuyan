# 张量文件接口 Node 适配

路一 Node 宿主的[张量文件接口](../../../豫言操作系统接口/张量文件/规范.汉语.md)适配。宿主用 `fs.readSync` 按位置（pread）把文件区段直接读进新张量的 `SharedArrayBuffer`，数据不经值桥，也不改变文件柄的顺序读取位置；大张量每次最多读 256 MiB，直至读满。

- 桥接构建：节点模式构建应用时，本适配所桥接的豫言操作系统文件与豫言操作系统张量计算都绑定到各自的 Node 适配（文件节点、张量计算节点）源码，包上下文里桥接包的依赖指向这两个绑定包；所以本适配可以解开文件适配的私有构造器 `节点文件柄` 取出宿主句柄号，并复用张量计算适配的编码函数（取上下文句柄号、按上下文包装结果：金属上下文里载入的是金属张量）。宿主侧两种资源在同一张资源表里，可按号互查。
- 错误：上下文已释放、文件柄已关闭或无效返回 `资源已失效`；可写文件柄返回 `未获授权`；偏移为负、形状不合法、文件在偏移之后不足所需字节返回 `输入无效`；超过上下文存储上限返回 `资源配额已尽`；读取出错返回 `宿主操作失败` 并附宿主消息。

新增宿主原语（外调名）：`豫言_节点_张量由文件载入`，返回（状态码，句柄号或错误消息），实现在 `豫言操作系统/宿主/节点/张量.mjs`；状态码同文件适配。

**平台接口**：本适配的包装函数转调平台接口包里的无体声明，编成带类型的宿主导入（边界签名见《网页汇编接口》网五）：「诺节宿主」之「张量原语」的「诺节张量由文件载入」（旧外调名 `豫言_节点_张量由文件载入`）。宿主对这些导入的实现与旧原语相同。
