# 授权服务云工适配

实现授权服务接口 0.5.0（云工薄宿主），全部用豫言写在云工薄宿主的通用原语（`库/云工宿主` 的物宿主与物）之上，宿主只翻译名字和值。

- `请求授权服务`：入站请求作参数传入（提案 C0001），以网页服务适配的 `入站请求物` 取其 Request；按白名单逐个复制入站标头、加固定标头；转发正文时把入站 `body` 流原样交给新 `Request`（`duplex: half`，`redirect: manual`），经 `SERVICE` 绑定的 `fetch` 发出。发请求失败抛可捕获的豫言异常（`授权服务请求失败：名称: 消息`）。
- `请求授权服务带正文`：正文按字节交给 `Request`（不经 JSON 转义），`AbortSignal.timeout` 挂在 `Request` 上，覆盖整次交换；失败或超时得 `授权服务请求失败` 与原因。3xx 原样作为成功响应。
- 响应：`授权服务响应` 包着 Response、中断信号与读取状态格；读取状态随响应传递，同一实例里交错执行的请求互不相干。增量读取、有限整读与取消与网页上游适配是同一套机制（读取器、带信号的 `pipeThrough`、流式 `TextDecoder`、码点边界切块）。
- `读取授权服务结森正文文` 克隆响应后读 JSON，原响应流仍可由 `授权服务原答转为出站响应`（网页服务适配的 `物出站响应`）原样返回。
- 服务绑定未授权或不存在时，取绑定抛可捕获的豫言异常，不发请求。

一致性验证见 `一致性验证/`（试验应用、Node 测试与真 workerd 冒烟）。平台前提：`pipeThrough` 的 `signal` 选项与 `AbortSignal.timeout` 为宿主运行时所支持（Node 与 workerd 均支持）。
