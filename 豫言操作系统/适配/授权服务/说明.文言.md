# 授权服务云工适配

实授权服务之约〇点五（云工薄宿主），悉以豫言书于云工薄宿主之通用原语（`库/云工宿主` 之物宿主与物）之上，宿主惟译名与值。

- `请求授权服务`：入站之请以参授之（提案 C0001），以网页服务适配之 `入站请求物` 取其 Request；依白名逐一复入站之头，增定头；转正文则以入站 `body` 之流原样授新 `Request`（`duplex: half`，`redirect: manual`），经 `SERVICE` 之绑之 `fetch` 发之。发请败则告可承之豫言异常（`授权服务请求失败：名: 辞`）。
- `请求授权服务带正文`：正文以字节授 `Request`（不经 JSON 转义），`AbortSignal.timeout` 系于 `Request`，贯全程；败或期满得 `授权服务请求失败` 与因。三百号原样为成之答。
- 答：`授权服务响应` 包 Response、断信与读态之格；读态随答而行，一实例中交错之诸请不相涉。渐读、有限整读与止，与网页上游适配同一机（读器、带信之 `pipeThrough`、流式 `TextDecoder`、依码点之界裁块）。
- `读取授权服务结森正文文` 以答之副本读 JSON，原流仍可由 `授权服务原答转为出站响应`（网页服务适配之 `物出站响应`）原样返之。
- 服务之绑未授或无之，取绑则告可承之豫言异常，不发请。

一致之验见 `一致性验证/`（试验应用、Node 之测与真 workerd 之烟试）。平台之前提：`pipeThrough` 之 `signal` 选项与 `AbortSignal.timeout` 为宿主运行时所支（Node 与 workerd 皆支）。
