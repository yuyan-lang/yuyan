# 上游流一致性应用

试验应用，验证授权服务 0.3.0、网页上游 0.2.0、命名持久服务 0.2.0 的带正文请求、增量读取、取消、有限整读、动态公网 HTTPS 上游与入站请求转发。只供一致性测试使用，不是业务应用。

## 路由

- `POST /run`，正文为 JSON 描述。`op`：`svc`（授权服务带正文请求）、`svcold`（旧的授权服务请求，验证旧柄可读）、`up`（静态来源的网页上游）、`upjson`（旧的整体 JSON 读取）、`pub`（公网 HTTPS 上游）、`do`（命名持久服务流）、`dotext`（命名持久服务文字，返回摘要）、`multi`（`mode` 取 `many`、`interleave`、`guard`、`argcheck`）、`badhandle`（无效柄）。
- 通用字段：`binding`、`object`、`url`、`method`、`headers`（二元数组列表）、`query`、`body`、`bodyPow`（2 的幂个 a）、`bodyExtra`、`timeout`、`read`（`chunks`、`limited`、`limitedtwice`、`mixed`、`sse`、`cancel`、`gated`、`none`）、`max`、`limit`、`header`。
- `/fwd`：由请求头 `x-cfg`（JSON）给出转发描述，把当前入站请求转给持久对象。`/svcpass`：旧的授权服务原流直通。`/uppass`：旧的网页上游流回应。`/dopass`：先流式请求对象，检查状态，再把对象响应作为最终响应。

报告不含控制字符：块用 `〔〕` 括起，段用 `‖` 分隔。SSE 增量解析仿 `AI市场应用/流式答复。豫`，仅测试用。
