# 上游流一致性验证（授权服务 0.3.0）

此目录验授权服务〇点三、网页上游〇点二、命名持久服务〇点二之带正文请、渐读与转发。三能力包之一致性验证目录各存同一试验应用之副本，以便各自独立复行；此目录之测试文件重在 `授权服务`。

## 内容

- `应用/`：试验应用 `上游流一致性应用`，依三能力包及网页入站、网页答复。`POST /run` 受 JSON 之述（`op` 取 `svc`、`svcold`、`up`、`upjson`、`pub`、`do`、`dotext`、`multi`、`badhandle`），`/fwd`、`/svcpass`、`/uppass`、`/dopass` 行转发与原答；读果书为无控字之报（块以 `〔〕` 括之，段以 `‖` 分之）。内含仿 `AI市场应用/流式答复。豫` 之 SSE 渐析（惟测试用），示“读一五帧 SSE，边读边累计字节”。应用包描述存为 `上游流一致性应用。包。豫.txt`，以免被 `yy豫构` 之全仓库包发现所析；草稿区 `建应用.sh` 自还原名而后构建。
- `测试/`：Node 测试，以类实例作服务绑定桩与持久对象桩（宿主桥惟对非纯物发句柄），皆连真 Wasm。`桩.mjs` 供慢速分块流、桩与宿主之装配。测试文件：`授权服务.test.mjs`（二十三例：渐读之序、UTF-8 跨块与坏字节、最大字节之切、期满、误、止、有限读、请之形、参违、柄验、旧术之容）、`多态.test.mjs`（五例：同一事内千二百请而柄不竭、六千小块、错综读、旧术之守、参验）、`模糊.test.mjs`（三百例随机较验：任意字节、任意切块、任意最大字节，文必等于 TextDecoder 之整体解码，且每块不逾限、无半字）。
- `平台/`：真 workerd 冒烟（Miniflare 加真 workerd，须有云仓 `工具/包管理服务/node_modules/miniflare`，可以环境变量 `迷你路径` 指之）：置同一 Wasm 产物于 workerd，配另一 Worker（服务绑定）、持久对象类与外发拦截 Worker，验 SSE、UTF-8、期满、止、请之形、公网上游（通配来源之许、外发拦截、三〇二）、持久对象与转发。`基线.mjs` 与 `取消传播.test.mjs` 以纯 JavaScript 为对照，明本地 workerd 不向服务绑定之被调 Worker 回调流之 cancel，纯 JavaScript 亦然。

## 复行（私有暂存）

```
SP=<草稿区>                                   # 含 工具箱/建暂存.sh、建应用.sh
$SP/工具箱/建暂存.sh <暂存>
cd <暂存> && $SP/工具箱/建应用.sh <暂存> 云工 <语言仓>/豫言操作系统/适配/授权服务/一致性验证/应用 上游流一致性
cd <语言仓>/豫言操作系统/适配/授权服务/一致性验证/测试
env "产物目录=<暂存>/dist/上游流一致性" node --test --test-timeout=200000 *.test.mjs
env "产物目录=<暂存>/dist/上游流一致性" node --test --test-timeout=200000 ../平台/冒烟.test.mjs   # 真 workerd
```

环境变量 `产物目录` 指所构 `dist/上游流一致性`（缺省为当前目录下 `./dist/上游流一致性`）。测试之间须以有引用之定时器保活（测试文件已处），以 `AbortSignal.timeout` 之定时器不占 Node 事件循环也。

## 须知

- 构建须最新之接口与适配（含网页入站、网页答复）；他人改共享文档后，须先重生各适配之 `宿主提供.json`。
- 公网 HTTPS 上游经全局 `fetch` 而发：Node 测试以 `创建云工宿主({全局})` 注假 `fetch`，静态来源之术以 `网络` 注之；程序许可 `OUTBOUND_ORIGINS` 必含通配来源 `https://*` 方可用公网术。
- 宿主执行一事之默认时限为三十秒（`创建豫言实例`），流读逾此者，须宿主使时限可配。
- 真 workerd 冒烟会于当前目录生成 `.wrangler/` 之缓存，宜于语言仓之外之目录行之（如草稿区），毋留其缓存于仓中。
