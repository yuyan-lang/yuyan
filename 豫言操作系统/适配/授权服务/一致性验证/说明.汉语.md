# 上游流一致性验证（授权服务 0.3.0）

本目录验证授权服务 0.3.0、网页上游 0.2.0、命名持久服务 0.2.0 的带正文请求、增量读取与转发。三个能力包的一致性验证目录各存一份相同的试验应用副本，便于各自独立复跑；本目录的测试文件侧重 `授权服务`。

## 内容

- `应用/`：试验应用 `上游流一致性应用`，依赖三个能力包与网页入站、网页答复。`POST /run` 接受 JSON 描述（`op` 取 `svc`、`svcold`、`up`、`upjson`、`pub`、`do`、`dotext`、`multi`、`badhandle`），`/fwd`、`/svcpass`、`/uppass`、`/dopass` 走转发与原答；读取结果写成不含控制字符的报告（块用 `〔〕` 括起、段用 `‖` 分隔）。内含仿 `AI市场应用/流式答复。豫` 的 SSE 增量解析（仅测试用），演示“读一个 5 帧 SSE，边读边累计字节”。应用包描述存为 `上游流一致性应用。包。豫.txt`，避免被 `yy豫构` 的全仓库包发现解析；`yy双宿主构建 --自动` 会自动改回原名再构建。
- `测试/`：Node 测试，用类实例作服务绑定桩与持久对象桩（宿主桥只对非纯对象发句柄），全部连真实 Wasm。`桩.mjs` 提供慢速分块流、桩与宿主装配。测试文件：`授权服务.test.mjs`（23 例：增量读取顺序、UTF-8 跨块与坏字节、最大字节切块、超时、错误、取消、有限读取、请求形态、参数违规、句柄校验、旧函数兼容）、`多态.test.mjs`（5 例：同一事件内 1200 次请求句柄不竭、6000 个小块、交错读取、旧函数守卫、参数校验）、`模糊.test.mjs`（300 例随机差分：任意字节、任意切块、任意最大字节，文字须等于 TextDecoder 的整体解码，且每块不超限、不含半个字符）。
- `平台/`：真 workerd 冒烟（Miniflare 加真 workerd，需要云仓 `工具/包管理服务/node_modules/miniflare`，可用环境变量 `迷你路径` 指定）：把同一份 Wasm 产物放进 workerd，配合另一个 Worker（服务绑定）、持久对象类与外发拦截 Worker，验证 SSE、UTF-8、期满、取消、请求形态、公网上游（通配来源许可、外发拦截、302）、持久对象与转发。`基线.mjs` 与 `取消传播.test.mjs` 用纯 JavaScript 对照说明：本地 workerd 不向服务绑定的被调 Worker 回调流的 cancel，纯 JavaScript 亦然。

## 复跑

在构建根里运行（语言仓根目录本身即可，需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖解析规则见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)）。编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发。`<构建根>` 指构建根的绝对路径。

```
./yy双宿主构建 --自动 云工 <语言仓>/豫言操作系统/适配/授权服务/一致性验证/应用 dist/上游流一致性
cd <语言仓>/豫言操作系统/适配/授权服务/一致性验证/测试
env "产物目录=<构建根>/dist/上游流一致性" node --test --test-timeout=200000 *.test.mjs
env "产物目录=<构建根>/dist/上游流一致性" node --test --test-timeout=200000 ../平台/冒烟.test.mjs   # 真 workerd
```

产物目录环境变量 `产物目录` 指向构建出的 `dist/上游流一致性`（缺省为当前目录下的 `./dist/上游流一致性`）。测试期间需要 ref 定时器保活（测试文件已处理），因为 `AbortSignal.timeout` 的定时器不占 Node 事件循环。

## 需要注意

- 构建需要最新的接口与适配（含网页入站、网页答复）；他人改动共享文档后，须先重生成各适配的 `宿主提供.json`。
- 公网 HTTPS 上游经全局 `fetch` 发出：Node 测试通过 `创建云工宿主({全局})` 注入假 `fetch`，静态来源函数通过 `网络` 注入；程序许可 `OUTBOUND_ORIGINS` 须含通配来源 `https://*` 才能使用公网函数。
- 宿主执行一个事件的默认时限为 30 秒（`创建豫言实例`），更长的流读取需要宿主使时限可配。
- 真 workerd 冒烟会在当前目录生成 `.wrangler/` 缓存，请在语言仓之外的目录运行（例如系统临时目录），不要把该缓存留在仓库里。
