# 真实浏览器验收清单

JSDOM 所不能盖者，须于真浏览器验之。**试页**：以探针客之产物（`自动启动.mjs`、`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`接口要求组.json` 等）与本目录之 `测试页.html`、`模板.html` 置于同一目录，以任一静态服务开之（`.mjs` 须以 `text/javascript`、`.wasm` 以 `application/wasm` 供之）；于控制台或自动化之具中以 `window.__发(操作, ...参)` 呼接口，`await window.__宿主` 取宿主之对象，`.状态()` 读事列与柄之状。

**开发时已于 Chromium（具 JSPI）验过者**（果皆合于约）：

1. 客经 `自动启动.mjs` 装载，过接口清单之核；读取页面语言等基本之呼。
2. 打开模态框：真 `showModal()`，`:modal` 相合，焦点入对话框中；**Esc**：未得用户激活，则 `cancel` 不可取消（事之载带 `可取消:false`、`已阻止默认:false`，对话框闭）；经一次真实点击得用户激活后，`订阅界面事件("创建弹窗","cancel",{"阻止默认":true})` 使 Esc 被同步拦下，对话框仍开。
3. 真键盘：订阅 `keydown` 之键规则（无 Shift 之 Enter、候选框未 hidden 时之 Tab、无选区时之 Ctrl+C、Ctrl+L），逐一按之：命中者已阻止默认为真；候选框隐藏则 Tab 不拦，焦点依浏览器默认而移；显现则 Tab 被拦，焦点留于输入框。
4. 真点动态之钮：以构建页面节点树建无标识而带 `data-yy` 之钮，容器订 `click`，真点之得标识空、操作键正之事。
5. 码点与码元之互换：含 😀 之输入框，`设置输入光标(1,3)`，真选区为 UTF-16 之一至四，读取选区文字为“😀b”。
6. 真布局：读取滚动度量与设置滚动顶合于真之 scrollTop、scrollHeight、clientHeight；读取节点可见依真 CSS 而判；宽三百七十五像素（具 viewport meta）时读取页面状态之窄屏为真。
7. 装入页面模板（同源 fetch）：脚本不行、`on*` 被去、`target=_blank` 之链带 `rel=noopener noreferrer`；设置页面框架地址：页所声明之源可设，他源被拒。

**仍须于真浏览器补验者**：

- **输入法组字**：以真中文输入法入之，察 `compositionstart/update/end`、`input` 之组字中与其序；Chrome 中组字提交之 Enter 有 `isComposing`，Safari 中 `compositionend` 先于 `keydown` 而 `keyCode` 为 229，确认键规则于二者下皆不误中。
- **焦点之细**：聚焦节点于不可聚焦、隐藏、`inert` 区之表现；iframe 内之焦点；标签页在后台时读取页面状态之可见。
- **选区**：Chrome、Firefox、Safari 于输入框内选区之 `getSelection().toString()` 各异，确认读取选区文字与仅选区为空于三者皆正（宿主于输入框内选区另有处理）。
- **`online`/`offline`、`visibilitychange`、`popstate`**：以浏览器之离线开关、切换标签、真前进后退触发，察类与详情。
- **`beforeunload`、页面关闭**：宿主闭后等待返“关闭”，客退。
- **高频与压力**：真滚动下 `scroll` 之并合、一次建二千节之耗时、一万次建树释放后之内存与柄数、`data-yy` 委托于大列之开销。
- **CSP 与沙箱**：站点之 `frame-src`、`sandbox` 与设置页面框架地址之配合；`usercontent` 源之预览。
- **浏览器之兼容**：Firefox（JSPI 可用否）、Safari 27 之行；无 JSPI 之浏览器，客当明示降级（宿主于异步宿主之能力报“此浏览器缺少 JSPI”）。
