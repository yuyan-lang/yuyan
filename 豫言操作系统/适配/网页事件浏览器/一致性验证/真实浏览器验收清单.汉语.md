# 真实浏览器验收清单

JSDOM 不能覆盖下列行为，须在真实浏览器里验证。**测试页**：把探针应用产物（`自动启动.mjs`、`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`接口要求组.json`……）与本目录的 `测试页.html`、`模板.html` 放在同一个目录，用任意静态服务器（`.mjs` 须以 `text/javascript`、`.wasm` 以 `application/wasm` 提供）打开测试页；在控制台或自动化工具里用 `window.__发(操作, ...参)` 调用接口，`await window.__宿主` 取宿主对象，`.状态()` 读队列与句柄状态。

**开发时已在 Chromium（带 JSPI）里验过的项**（结果均符合规范）：

1. 应用经 `自动启动.mjs` 装载并通过接口清单核对；`读取页面语言` 等基本调用。
2. `打开模态框`：真实 `showModal()`，`:modal` 匹配，焦点在对话框内；**Esc**：未经用户激活时 `cancel` 事件不可取消（事件载荷带 `可取消:false`、`已阻止默认:false`，对话框关闭）；经一次真实点击获得用户激活后，`订阅界面事件("创建弹窗","cancel",{"阻止默认":true})` 使 Esc 被同步拦下，对话框保持打开。
3. 真实键盘：订阅 `keydown` 的键规则（Enter 且无 Shift、候选框未 hidden 时的 Tab、无选区时的 Ctrl+C、Ctrl+L），逐个按下：命中的按键 `已阻止默认` 为真，候选框隐藏时 Tab 不被拦截、焦点按浏览器默认移动，显示后 Tab 被拦截、焦点留在输入框。
4. 真实点击动态按钮：用 `构建页面节点树` 建出无 ID、带 `data-yy` 的按钮，容器订阅 `click`，真实点击得到 `标识` 为空、`操作键` 正确的事件。
5. 码点与码元换算：含 😀 的输入框里 `设置输入光标(1,3)`，真实选区为 UTF-16 的 1 至 4，`读取选区文字` 为“😀b”。
6. 真实布局：`读取滚动度量`/`设置滚动顶` 与真实 `scrollTop/scrollHeight/clientHeight` 一致；`读取节点可见` 按真实 CSS 判定；375 像素宽（含 viewport meta）时 `读取页面状态` 的 `窄屏` 为真。
7. `装入页面模板`（同源 fetch）：脚本不执行、`on*` 被剔除、`target=_blank` 链接带 `rel=noopener noreferrer`；`设置页面框架地址`：页面声明的来源可设、其他来源被拒。

**仍须在真实浏览器补验的项**：

- **输入法组字**：用真实中文输入法输入，检查 `compositionstart/update/end`、`input` 的 `组字中` 与顺序；Chrome 里组字提交的 Enter 有 `isComposing`，Safari 里 `compositionend` 先于 `keydown` 且 `keyCode` 为 229，确认键规则在两者下都不误命中。
- **焦点细节**：`聚焦节点` 对不可聚焦元素、隐藏元素、`inert` 区域的表现；iframe 内焦点；标签页在后台时 `读取页面状态` 的 `可见`。
- **选区**：Chrome、Firefox、Safari 对输入框内选区的 `getSelection().toString()` 不同，确认 `读取选区文字` 与 `仅选区为空` 在三者下都正确（宿主对输入框内选区有单独处理）。
- **`online`/`offline`、`visibilitychange`、`popstate`**：用浏览器的离线开关、切换标签页、真实前进后退触发，检查类型与详情。
- **`beforeunload`、页面关闭**：宿主关闭后等待返回“关闭”，应用退出。
- **高频与压力**：真实滚动下 `scroll` 事件合并、一次建 2000 个节点的耗时、一万次建树释放后的内存与句柄数、`data-yy` 委托在大列表上的开销。
- **CSP 与沙箱**：站点的 `frame-src`、`sandbox` 与 `设置页面框架地址` 的配合；`usercontent` 来源的预览。
- **浏览器兼容**：Firefox（JSPI 可用性）、Safari 27 的行为；无 JSPI 的浏览器上应用应给出明确的降级提示（宿主会对异步宿主能力报“此浏览器缺少 JSPI”）。
