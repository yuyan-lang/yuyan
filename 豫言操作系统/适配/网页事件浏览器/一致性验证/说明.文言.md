# 网页事件、网页界面、网页文树、网页消息：浏览器一致性验证

四包共一探针客，故验之材尽置于此。

**所含**

- `应用/接口探针/`：探针客之源（包描述之名缀 `.txt`，免为 `yy豫构 发现` 视作包）。其订“豫言测试命令”之信，依 `{"号":n,"操作":"术名","参":[…]}` 呼四包之**诸术**，而以“豫言测试回复”之信返 `{"号":n,"成":爻,"果":文}`；术败之事故辞原样在 `果` 中。
- `测试/宿主单元.test.mjs`：不涉 Wasm，以 JSDOM 直测宿主三厂函——事列（依类取、背压与弃数、并合、关闭）、界面订阅器（委托、操作键、同步键律、组字、策验、消息订阅）、页面控制（属性白册全表、建树之限、柄之回收、iframe、模板之清洗）。
- `测试/接口一致性.test.mjs`：JSDOM 加**真 Wasm**，经探针逐项验适配层与宿主之接线：新旧事件术不互吞、委托与操作键、键律同步 `preventDefault`、组字、读回与控制、白册、一次建树与限额、柄不泄（一万次建释）、事列背压、消息、定时之归类、关闭之义；又有一例察探针已覆四接口文件中每术。
- `测试页.html`、`模板.html`：真浏览器冒烟之页与同源模板，见 `真实浏览器验收清单.文言.md`。

**复跑**（于构建根，即语言仓根；须已成 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`，用法与适配之择见[双宿主构建说明](../../../../工具/双宿主构建/说明.文言.md)；编译缓存以编译器可执行文件之修改时间为准，数构建同用一编译器则共其缓存，勿并行；`<构建根>` 谓构建根之绝径）

```sh
# 构探针（浏览器模式；自动模式为“网页事件”择 适配/网页事件浏览器/，见下）
./yy双宿主构建 --自动 浏览器 <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/应用/接口探针 dist/接口探针
# 跑测试（jsdom 在云仓 网站/node_modules；变量名为华文，以 env 传之）
env "探针产物目录=<构建根>/dist/接口探针/" \
    "JSDOM路径=<云仓>/网站/node_modules/jsdom/lib/api.js" \
    node --test <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/测试/宿主单元.test.mjs \
                <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/测试/接口一致性.test.mjs
```

- 自动模式于浏览器模，每能力先取 `适配/<能力>浏览器/`，无则取 `适配/<能力>/`：“网页事件”因取 `适配/网页事件浏览器/`（余三能力依能力名对 `适配/网页界面`、`适配/网页文树`、`适配/网页消息`），不须符号链接。欲手绑者，其令等同：`./yy豫言操作系统绑定 豫言操作系统接口/网页事件/豫言操作系统网页事件。包。豫 豫言操作系统/适配/网页事件浏览器/豫言操作系统网页事件浏览器适配。包。豫 豫言操作系统/适配/网页事件浏览器/事件。豫 dist/操作系统绑定/网页事件`。
- 环境变量皆有默认：`探针产物目录` 默认 `一致性验证/产物/`；`JSDOM路径` 依仓布局指向云仓；`接口根` 默认语言仓之 `豫言操作系统接口/`，`探针源` 默认 `应用/接口探针/入口。豫`。
- 诸测约九十例，数秒而毕；单跑 `node --test` 时勿予探针逾一 MiB 之载（限额之断言置于宿主单元测试）。

**重建既有应用后当重跑之既有验收**（宿主与三适配皆为其所绑）：官网首页（`网站/验收/首页豫言验收.mjs`）、产品页、问答、技术文档、共用界面（六例）、语法高亮（`应用/豫言语法高亮/测试/浏览器高亮.test.mjs`）、运维（`应用/豫言云工作台/验收/运维豫言验收.mjs`）。开发时已以重建之产物逐一跑过，皆通过。
