# 网页事件、网页界面、网页文树、网页消息：浏览器一致性验证

四个包共用一个探针应用，所以验证材料集中放在这里。

**内容**

- `应用/接口探针/`：探针应用源码（包描述文件名带 `.txt` 后缀，避免被 `yy豫构 发现` 当成包）。它订阅“豫言测试命令”消息，按 `{"号":n,"操作":"函数名","参":[…]}` 调用四个接口包的**全部**函数，并用“豫言测试回复”消息返回 `{"号":n,"成":爻,"果":字符串}`；函数失败的事故消息原样在 `果` 里。
- `测试/宿主单元.test.mjs`：不含 Wasm，用 JSDOM 直接测宿主的三个工厂函数——事件队列（按类型取、背压与丢弃计数、合并、关闭）、界面订阅器（委托、操作键、同步键规则、组字、策略校验、消息订阅）、页面控制（属性白册全表、建树限额、句柄回收、iframe、模板清洗）。
- `测试/接口一致性.test.mjs`：JSDOM＋**真实 Wasm**，经探针逐项验证适配层与宿主的接线：新旧事件 API 不互吞、委托与操作键、键规则同步 `preventDefault`、组字、读回与控制、白册、一次建树与限额、句柄不泄漏（一万次建树释放）、队列背压、消息、定时归类、关闭语义；另有一条检查探针覆盖了四个接口文件里的每个函数。
- `测试页.html`、`模板.html`：真实浏览器冒烟页与同源模板，见 `真实浏览器验收清单.汉语.md`。

**复跑**（在构建根，即语言仓根目录；需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`，用法与适配选择规则见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)；编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发；`<构建根>` 指构建根的绝对路径）

```sh
# 构建探针（浏览器模式；自动模式会为 网页事件 选用 适配/网页事件浏览器/，见下）
./yy双宿主构建 --自动 浏览器 <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/应用/接口探针 dist/接口探针
# 跑测试（jsdom 在云仓 网站/node_modules；变量名是中文，用 env 传）
env "探针产物目录=<构建根>/dist/接口探针/" \
    "JSDOM路径=<云仓>/网站/node_modules/jsdom/lib/api.js" \
    node --test <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/测试/宿主单元.test.mjs \
                <语言仓>/豫言操作系统/适配/网页事件浏览器/一致性验证/测试/接口一致性.test.mjs
```

- 自动模式在浏览器模式下对每个能力优先取 `适配/<能力>浏览器/`，没有再取 `适配/<能力>/`：`网页事件` 因此用 `适配/网页事件浏览器/`（其余三个能力按能力名对应 `适配/网页界面`、`适配/网页文树`、`适配/网页消息`），无需符号链接。想手工绑定时的等价命令：`./yy豫言操作系统绑定 豫言操作系统接口/网页事件/豫言操作系统网页事件。包。豫 豫言操作系统/适配/网页事件浏览器/豫言操作系统网页事件浏览器适配。包。豫 豫言操作系统/适配/网页事件浏览器/事件。豫 dist/操作系统绑定/网页事件`。
- 环境变量都有默认值：`探针产物目录` 默认 `一致性验证/产物/`；`JSDOM路径` 默认按仓库布局指向云仓；`接口根` 默认语言仓的 `豫言操作系统接口/`，`探针源` 默认 `应用/接口探针/入口。豫`。
- 全部测试约 90 例，几秒跑完；`node --test` 单跑时不要给探针传超过 1 MiB 的载荷（限额类断言放在宿主单元测试里）。
