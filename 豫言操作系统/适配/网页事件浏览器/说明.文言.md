# 浏览器网页事件适配

`事件。豫` 承[网页事件之约](../../../豫言操作系统接口/网页事件/规范.文言.md)，以浏览器宿主 `宿主.mjs` 中之统一事列与界面订阅器，出六项中文公术。客惟见癸象文与整数订阅号，不得原生事对象或柄。`实现接口。豫` 固其包籍与版本；构前当核六术之签名。

**宿主之术**（皆在 `宿主/浏览器/宿主.mjs`，败则返（阴，错文），再由此适配化为豫言事故，不使 JS 之异常越 Wasm 之界）：`豫言_浏览器_等待网页事件`、`豫言_浏览器_订阅界面事件`、`豫言_浏览器_取消订阅界面事件`、`豫言_浏览器_事件丢弃数`、`豫言_浏览器_事件类型丢弃数`、`豫言_浏览器_设置事件队列上限`。

**宿主 JS 何以必改**：键之律、止默认、止传播须于原生事回调中同步而成，豫言惟能事后处之；统一事列（依类取事、每类之背压与弃数、并合）与事之委托，亦须宿主于事至时即成。此诸逻辑写为三可独测之厂函（`创建事件队列`、`创建界面订阅器`、`创建页面控制`），`创建浏览器宿主` 惟接其于豫言之术；`宿主.mjs` 乃构建器固定所抄之一，增逻辑不必增外壳之文。

**列之约**：「宿主」类（低层宿主库之原始事）满则拒新事而报错，余类满则弃该类最旧之事；`创建浏览器宿主({队列上限:{界面:2048}})` 可于启动时传初限；宿主对象另有 `状态()`（积压、弃数、柄数、订阅数），供测试与察，业务不得倚之。

**运行之要**：候事诸术悬豫言之栈，浏览器须支 JSPI（`WebAssembly.Suspending`）。**验收**：`一致性验证/` 有探针客、宿主单元测试（JSDOM，不含 Wasm）与 JSDOM 加真 Wasm 之一致性测试，说明见其中之 `说明.文言.md`；键律之时序、dialog 之 Esc、输入法组字、焦点之细节等 JSDOM 所不能盖者，须于真浏览器验之，清单见该说明。
