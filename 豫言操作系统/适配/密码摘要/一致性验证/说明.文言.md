# 密码摘要一致性验证

此目录验[密码摘要公约](../../../../豫言操作系统接口/密码摘要/规范.文言.md)二版之云工适配：试验客在 `应用/`（包描述存为 `密码摘要一致性应用。包。豫.txt`，构建时复其原名），Node 试验为 `摘要一致性.test.mjs`。所覆：文字摘要与字节摘要，与 Node `crypto` 对拍（入空、标准之向量、汉字、零字节与 0xFF、二百五十六个字节值之全、一 MiB 与十六 MiB 之边）；入逾十六 MiB 则适配自抛异（于 Wasm 内造零字节串以试之）；`恒时相等文字` 之等、不等、长异、空文、汉字、字节数同而内容异；以六十四 KiB 之串较首字节相异与末字节相异之耗时，以证循环不早退。

## 以私有暂存复跑

一、建私有暂存：`建暂存.sh <暂存目录>`。
二、构建试验客：`cd <暂存目录> && 建应用.sh <暂存目录> 云工 <此目录>/应用 摘要一致性`，产物在 `<暂存目录>/dist/摘要一致性/`。
三、行试验：`env 产物目录=<暂存目录>/dist/摘要一致性 node --test 摘要一致性.test.mjs`。
