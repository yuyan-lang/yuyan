# 密码摘要一致性验证

本目录验证[密码摘要接口](../../../../豫言操作系统接口/密码摘要/规范.汉语.md) 0.2.0 的云工适配：试验应用在 `应用/`（包描述存为 `密码摘要一致性应用。包。豫.txt`，构建时改回原名），Node 测试是 `摘要一致性.test.mjs`。测试覆盖：文字摘要与字节摘要与 Node `crypto` 对拍（空输入、标准向量、汉字、零字节与 0xFF、全部 256 个字节值、1 MiB 与 16 MiB 边界）；输入超过 16 MiB 时适配自己抛出异常（在 Wasm 内构造零字节串测试）；`恒时相等文字` 的相等、不等、长度不同、空文、汉字、字节数相同而内容不同；用 64 KiB 字符串比较首字节相异与末字节相异的耗时，证明循环不提前退出。

## 复跑

在构建根里运行（语言仓根目录本身即可，需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖解析规则见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)）。编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发。

1. 构建试验应用：`./yy双宿主构建 --自动 云工 <本目录>/应用 dist/摘要一致性`，产物在 `dist/摘要一致性/`。
2. 跑测试：`env 产物目录=<构建根>/dist/摘要一致性 node --test 摘要一致性.test.mjs`（在本目录里运行；`<构建根>` 指构建根的绝对路径）。
