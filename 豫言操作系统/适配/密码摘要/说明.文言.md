# 密码摘要云工适配

以 UTF-8 字符串或字节串授云工 SHA-256 原语（Web Crypto `digest`），逐字节书为小写十六进制，其转换共用 `拓展库` 云工宿主 `字节。豫` 之 `字节串转小写十六进制`；文字之摘要即其原字节授字节之摘要，二者之果恒同。入逾宿主值桥十六 MiB 之限，则先于豫言抛异，免宿主 JS 之错穿出 Wasm。客惟受摘要文，不受宿主密码物。

`恒时相等文字` 全以豫言书成，不赖宿主：长同之二串，逐字节取整数之差，积其差之平方，终较所积是否为零；循环之体无系于数据之分支，亦不早退。Node 试验以六十四 KiB 之二串，较首字节相异与末字节相异之耗时，二者同量级（早退之实现相去数百倍）。
