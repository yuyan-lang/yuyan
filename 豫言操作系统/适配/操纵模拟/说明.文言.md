# 手柄模拟适配

模拟宿主所用手柄接口之适配。依常式行 `豫寓辔`：`列辔` 陈其柄表，`问辔` 按号还预置之钮枢，`候辔` 依次交预置之接拔，`振辔` 记其请而答已发，`辔钮名` 与 `辔枢名` 给十七与四之汉字名。

## 预置之境

试者或用例寻观本包之「辔」篇，用其拟置柄、拟置态、拟推事、拟取振、拟清五术：

- `拟清` 清柄表、状表、事表与振录；
- `拟置柄` 整份易所接之柄（各以 `辔柄值` 造之，如 `「辔柄值」于「号」曰「一」于「名」曰『甲柄』`）；
- `拟置态` 受柄、钮们与枢们，换同号之状（钮十七项，枢四项）；
- `拟推事` 纳一 `辔接` 或 `辔拔`，下次 `候辔` 交之；
- `拟取振` 取且清其振录。

`候辔` 于模拟不候：无预置之事则径答 `辔无变`。须候之境由呼者自反复试之。

## 界

模拟不校钮枢之列长短与取值，试者可故予越界之值。真器之上，长短与归一出诸宿主之实。
