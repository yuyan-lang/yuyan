# 手柄模拟适配

模拟宿主用的手柄接口适配。它按标准布局实现 `豫寓辔`：`列辔` 交出手柄表，`问辔` 按号交出预置的按钮与摇杆值，`候辔` 依次交出预置的接入与拔出事件，`振辔` 记下请求并答已发，`辔钮名` 与 `辔枢名` 给出十七与四个汉字名。

## 预置场景

测试或用例导入本包的「辔」篇，调用其「拟置柄」「拟置态」「拟推事」「拟取振」「拟清」五个函数：

- `拟清` 清空手柄表、状态表、事件表与振动记录；
- `拟置柄` 整份替换接着的手柄（每个手柄用 `辔柄值` 造，如 `「辔柄值」于「号」曰「一」于「名」曰『甲柄』`）；
- `拟置态` 依次接收柄、钮们与枢们，换掉同一号的状态（钮们十七项，枢们四项）；
- `拟推事` 推入一件 `辔接` 或 `辔拔`，下一次 `候辔` 交出；
- `拟取振` 取出并清空振动记录。

`候辔` 在模拟里不等待：没有预置事件时立刻答 `辔无变`。需要等待的场景由调用方自己重试。

## 边界

模拟不校验钮们与枢们列的长度与取值范围，测试可以故意给越界的值。真设备上的长度与归一由各宿主的实现负责。
