# 文字规整浏览器适配

`规整。豫` 于浏览器中承[文字规整之约](../../../豫言操作系统接口/文字规整/规范.文言.md)（0.2.0）：与 ECMAScript trim、toLowerCase、length 及 /^[\p{L}\p{N}]+$/u 逐字符相同的文字运算。其义与云工适配（`../文字规整/`）逐字相同，接口包自身不变。`实现接口。豫` 固公共包之身与版，接口检查器当于构建前核其签。

**宿主原语**：适配惟调 `豫言_浏览器_网页能力(操作名, 一, 二, 三)`，操作名 `规整.去空白`、`规整.转小写`、`规整.UTF16长度`、`规整.全字母数字`；败则返（阴，错文），转为豫言事故。

**宿主之行**：`宿主/浏览器/宿主.mjs` 之 `创建网页能力`：于宿主字符串直调 trim、toLowerCase、length 与正则；输入逾一 MiB 则发事故。

**选用之规**：构建器于浏览器模式，先取 `适配/<能力>浏览器`；云工模式，取 `适配/<能力>云工` 或 `适配/<能力>`。

**验收**：`../网页定时/一致性验证/`（探针应用“前端接口探针”含此接口；JSDOM 加真实 Wasm）。

**平台接口**：此适配之包之函转调平台接口之包中无体之声，编为带型之宿主导入（边界之签见《网页汇编接口》网五）：「浏览器宿主」之「网页能力原语」之「浏览器网页能力」（旧外调名 `豫言_浏览器_网页能力`）。宿主实此诸导入，与旧原语同。
