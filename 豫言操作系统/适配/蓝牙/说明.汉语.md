# 蓝牙空适配

模拟、浏览器与云工三种宿主没有蓝牙主机控制器。蓝牙接口由本适配实现：`蓝牙态` 返回 `蓝牙无器` 并携带 `资源暂不可用`，`蓝牙收` 返回 `蓝牙未接`，`蓝牙发` 与 `蓝牙键报` 返回负一。适配不取任何宿主能力，也不伪造控制器。

壳命令照常回话：「蓝牙态」印“没有蓝牙控制器”，「蓝牙寻」印“找到 0 个设备”，「蓝牙断」印“已断开”，「蓝牙配」「蓝牙忘」「蓝牙回连」按同一退路回话，与原生没有接控制器时相同。

原生执行器与豫言操作系统（裸机）的控制器由执行器直接提供，裸机经内核的通用串行蓝牙驱动接 USB 蓝牙适配器。浏览器接入 Web Bluetooth 留待后续版本。
