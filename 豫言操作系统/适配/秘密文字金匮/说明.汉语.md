# 秘密文字落盘适配

从一个只读的数据文件读授权秘密，不占宿主环境，重启后照旧。供豫言系统与原生宿主上的服务程序使用。

## 配置

文件在当前金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下，名 `配置。数据。豫`：

```yuyan
「秘密」者「典」【「数据库口令」者『某处得来的口令』也、「空占位」者『』也】也。
```

顶层「秘密」是一个记录，栏名即秘密名，栏值是文字。头一次调用时读，之后每次调用重读，改了文件立刻生效。文件不存在时视为没有任何秘密，读任何名字都报未授权。

## 语义

- 名字在「秘密」里：返回（阳，文字）；值为空串时返回（阳，空串），与“不存在”分清。
- 名字不在「秘密」里：报可捕获的中文事故，消息是 `秘密未授权：` 接名字。
- 值是文字以外的数据（整数、爻、记录等）时按空串处理；这一处留待后续版本改成报错。

适配不脱敏、不写日志、也不枚举授权名字；秘密流出到外部请求与响应由应用负责。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓密语金匮榫」之「文字」之书。

「设匮根」于『/某处的数据盘/豫言』。
「读授权秘密文字」于「名」曰『数据库口令』。
```

## 测试

`测试/文字。测试。豫` 造一个临时金匮根，写配置文件，核对已授权名字、空值、未授权名字三种情形，再换一个根（模拟重启）读回，最后清理。
