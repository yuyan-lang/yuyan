# 秘密文字落盘适配

自一唯读之数据文件读授权之秘，不占宿主之境，重启如故。供豫言系统与本土之宿主用。

## 配置

文件在当今金匮根（`金匮` 之「路」的「设匮根」「匮根」，缺省 `.豫言金匮`）下，名曰 `配置。数据。豫`：

```yuyan
「秘密」者「典」【「数据库口令」者『某处得来的口令』也、「空占位」者『』也】也。
```

顶之「秘密」为一记，栏名即秘名，栏值即其文。首用之时读之，其后每用重读，改之即见。无其卷则视为无秘，读何名皆报未授。

## 语义

- 名在「秘密」中：还（阳，文）；值为空串则还（阳，空串），与“不存”相分。
- 名不在「秘密」中：报可捕之中文事故，辞曰 `秘密未授权：` 接其名。
- 值为文以外之物（整数、爻、记等）者，作空串论；此处于后续之版改为告祸。

适配不脱敏、不入日志，亦不枚举授权之名；秘之流出外请与回书，乃应用之责。

## 用法

```yuyan
寻观「金匮」之「路」之书。
寻观「豫寓密语金匮榫」之「文字」之书。

「设匮根」于『/某处的数据盘/豫言』。
「读授权秘密文字」于「名」曰『数据库口令』。
```

## 试

`测试/文字。测试。豫` 造暂根，书配置之文，核已授、空值、未授三事，又易其根（拟重启）而读回，终清之。
