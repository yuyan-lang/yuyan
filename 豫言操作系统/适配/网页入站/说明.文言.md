# 网页入站云工适配

自当前 Worker Request 取法、未解码之径、来源、主机名、原查询、查询参、所指头值及有界之正文。适配惟以文、爻、整数与字节串授客，不以 Request、Headers 或 ReadableStream 之柄授客；资源之权另由宿主核之。

有限读正文（0.7.0）行通用句柄桥：得 `request.body` 之读器，逐块调 `云工读取流块安全`；每块先由句柄读其 `byteLength` 而较之于限，逾限之块永不抄入 Wasm，是时以安全调用废读器（上游取消纵败亦吞之）。字节片两两并之，总抄为 O(n log k)，十六 MiB 之正文（每块六十四 KiB）约需〇点一五秒。文字诸术借宿主之 `TextDecoder`：宽解者流式而解，去其 BOM；严解者先以 `fatal: true` 之解码器逐片验之；单块逾 1 MiB 者，先于宿主以 `subarray` 分片，使每次越值桥之数远小于桥之十六 MiB 交换之限。`读取入站癸象正文文` 先以二 MiB 为限而读，复以字节造 `Response`，用 `云工调用方法安全` 调 `json`，故坏 JSON、逾限、无正文、已被读，皆为可捕之事故；合法之入，其果不易。

所需宿主之能：通用句柄桥、流读（`云工读取流块安全`、`云工取消流读取器` 之类）、字节句柄与流式解码，无须新宿主原语；所需平台：Web Streams、支持 fatal 之 `TextDecoder`、`Response.json`、`Headers.has`。此适配为旧编译器可载之过渡包；构前当以接口检查器核其签。
