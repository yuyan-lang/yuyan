# 网页入站一致性验证（0.8.0）

本目录用真实的 Wasm 与 Node 宿主验证 `豫言操作系统网页入站` 0.8.0 的云工适配：

- `应用/网页入站一致性应用/`：试验应用。包描述存为 `网页入站一致性应用。包。豫.txt`，避免被 `yy豫构` 的全仓库包发现当成包解析；`yy双宿主构建 --自动` 会把它复制到构建根内的临时目录（`dist/.自动构建/<输出名>/应用`）并改回原名。
- `网页入站一致性.test.mjs`：Node 测试，加载构建产物（`程序.wasm`、`值桥.wasm`、`宿主.mjs`、`许可.json`）逐项断言。

## 复跑

在构建根里运行（语言仓根目录本身即可，需已构建 `yy双宿主构建`、`yy3_bs`、`yy豫言操作系统绑定`、`yy豫言操作系统装载包`；用法与依赖解析规则见[双宿主构建说明](../../../../工具/双宿主构建/说明.汉语.md)）。编译缓存由编译器可执行文件的修改时间决定，多个构建同时用同一编译器会共享缓存，勿并发。

1. 构建：`./yy双宿主构建 --自动 云工 <本目录>/应用/网页入站一致性应用 dist/网页入站一致性`，产物在 `dist/网页入站一致性/`。
2. 测试：`node --test <本目录>/网页入站一致性.test.mjs`。产物根默认为当前目录下的 `dist`，可用环境变量 `产物根` 改写。

## 覆盖

- 状态 0 至 4 的全部划分：分块成功、恰好上限、超一字节、流式取消（读到越界块即停）、声明长度预判（不读流）、不可解析的声明长度、无正文（GET、HEAD、POST 无体、DELETE 无体）、已被读取与已被锁定、空流；
- 上限参数越界（0、−1、16777217、非数字）、上限 1 与 16 MiB 边界；十六兆字节整块与分块、超一字节、24 MiB 巨块超限（不得整块拷入 Wasm）、4096 个小块（句柄不泄漏）、带偏移的视图；
- 宽松与严格 UTF-8：多字节跨块、BOM、孤立字节、代理对、过长编码、越界码点、末尾残缺、NUL；宽松解码膨胀上限；流故障与取消故障；
- `读取入站有限癸象正文文`（0.8.0）：规范化（重复键、整数样式键、`\u` 与 `\/`、`1e21`、BOM、多字节跨块）、状态 1 至 5 全部不抛异常（含畸形转义、嵌套过深、坏 UTF-8、无正文、已读取、恰好上限与超一字节、声明长度预判、取消读取流、上限 0 与 8388609、8 MiB 边界）；`读取入站癸象正文文`：合法输入规范化、坏 JSON、空正文、无正文、嵌套过深、2 MiB 边界、读取次序；`入站标头存在`；事件种类（fetch、service-fetch、durable-fetch）；全部旧函数回归。

每个测试都断言真实 Wasm 的可观察行为；期望值凡能由平台标准实现给出的（`URL`、`URLSearchParams`、`TextDecoder`、`Headers`）都取自同一标准实现，不手抄。
