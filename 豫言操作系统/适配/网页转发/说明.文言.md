# 云工网页转发适配

`转发。豫` 承[网页转发之约](../../../豫言操作系统接口/网页转发/规范.文言.md)。由当前云工之请取二径，限同源改址，循许可择静资或服务，传原请之头、法与正文流，以上游答归平台。客惟传获授名及可无之新径，不得 URL、Request、Response 与服务之柄。宿主一请惟许一终答。

0.4.0 增二术：`转发入站请求并筛标头` 于豫言中验径、法、保留名与固定头（令牌字、长、数、重名、宿主所管之名、值之字集、入站值中之控字符、请体已否被读），复以 `Headers` 柄依「先复而后覆」造头，造带 `duplex: "half"` 与 `redirect: "manual"` 之 `Request`，交 `SERVICE` 绑定之 `fetch`（用安全调用，败则转为可捕之事故），上游 Response 原样而归，不读正文。`回应入站以静态资源` 以 `ASSETS.fetch(网址)` 取资源，复其 `Headers`，依「名初见则先去而后加」施附加头，以原正文流与终状造新 Response（HEAD 与无正文之状不带正文，并废资源之正文流）。

无须新宿主原语。今为旧编译器可载之过渡包；构前当以接口检查器核其签；他宿主欲称具此能，须另成同义适配。
