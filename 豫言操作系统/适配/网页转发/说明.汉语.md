# 云工网页转发适配

`转发。豫` 实现[网页转发接口](../../../豫言操作系统接口/网页转发/规范.汉语.md)。它从当前 Worker 请求提取两种路径，限制同源改址，按许可表选择 `ASSETS` 或服务绑定，转发原请求的标头、方法和正文流，并把上游响应交回平台。应用只传授权绑定名及可选新路径，不接触 URL、Request、Response 和服务句柄。宿主本身限制每次请求只设置一次响应。

0.4.0 新增两个函数：`转发入站请求并筛标头` 在豫言里校验路径、方法、保留名与固定头（令牌字符、长度、数量、重名、宿主管理的名称、值的字符集、入站值中的控制字符、请求体是否已被读取），再用 `Headers` 句柄按“先复制、后覆盖”构造标头，创建带 `duplex: "half"` 与 `redirect: "manual"` 的 `Request` 并交给 `SERVICE` 绑定的 `fetch`（用安全调用，失败转为可捕获异常），把上游 Response 原样交回，不读取正文。`回应入站以静态资源` 用 `ASSETS.fetch(网址)` 取资源，复制其 `Headers` 后按“名称首次出现先删除再追加”应用附加标头，以原正文流和最终状态构造新 Response（HEAD 与无正文状态不带正文，并取消资源正文流）。

不需要新的宿主原语。当前为普通编译器可加载的过渡包；构建前用接口检查器核对签名；其他宿主须提供同义适配，才能声称实现本能力包。
