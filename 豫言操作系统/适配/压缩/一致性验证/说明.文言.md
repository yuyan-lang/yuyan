# 压缩一致性验证

此目录验[压缩公约](../../../../豫言操作系统接口/压缩/规范.文言.md)之云工适配：试验客在 `应用/`（免为全库所发现，包描述存为 `压缩一致性应用。包。豫.txt`，构建时复其原名 `压缩一致性应用。包。豫`），Node 试验为 `压缩一致性.test.mjs`。试验所覆：与 `zlib.inflateRawSync`、`zlib.deflateRawSync`、`zlib.crc32` 逐字节对拍；入空、流空、坏、截、末有余字节；出限之边；压缩之炸（二百 MiB 之出，于一 MiB 之限取消）；存储块之边（六万五千五百三十五、六万五千五百三十六、十三万零七十字节等）；改一字节之数据、改所期 CRC-32 与所期实数；参数越界；随机扰动之对拍。

## 以私有暂存复跑

一、建私有暂存（符号链接语言仓之只读材料，复制编译器，编译缓存自成一家）：`建暂存.sh <暂存目录>`。
二、构建试验客：`cd <暂存目录> && 建应用.sh <暂存目录> 云工 <此目录>/应用 压缩一致性`，产物在 `<暂存目录>/dist/压缩一致性/`。
三、行试验（Node 径载真 Wasm）：`env 产物目录=<暂存目录>/dist/压缩一致性 node --test 压缩一致性.test.mjs`。

## 于本地 workerd 复跑

复 `dist/压缩一致性/` 于空目录，去 `程序.wasm.wat`，补内容为 `{}` 之 `执行配置.json`（构建器缺省时当写入），另置 `wrangler.jsonc`：`{"name":"压缩检查","main":"入口.mjs","compatibility_date":"2026-09-04"}`；`wrangler dev --local --port <端口>` 起后：`env 远端地址=http://localhost:<端口> node --test 压缩一致性.test.mjs`。同一试验经 HTTP 召真 workerd，已于 wrangler 4.129.0 全过。
