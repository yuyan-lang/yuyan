# 压缩一致性验证

本目录验证[压缩接口](../../../../豫言操作系统接口/压缩/规范.汉语.md)的云工适配：试验应用在 `应用/`（为免被全仓库包发现，包描述存为 `压缩一致性应用。包。豫.txt`，构建时改回 `压缩一致性应用。包。豫`），Node 测试是 `压缩一致性.test.mjs`。测试覆盖：与 `zlib.inflateRawSync`、`zlib.deflateRawSync`、`zlib.crc32` 逐字节对拍；空输入、空流、损坏、截断、尾随字节；输出上限的边界；压缩炸弹（200 MiB 输出在 1 MiB 上限取消）；存储块边界（65535、65536、131070 字节等）；改一字节数据、改预期 CRC-32 与预期大小；参数越界；随机扰动对拍。

## 用私有暂存复跑

1. 建私有暂存（符号链接语言仓的只读材料，复制编译器，编译缓存独立）：`建暂存.sh <暂存目录>`。
2. 构建试验应用：`cd <暂存目录> && 建应用.sh <暂存目录> 云工 <本目录>/应用 压缩一致性`，产物在 `<暂存目录>/dist/压缩一致性/`。
3. 跑测试（Node 直接装载真实 Wasm）：`env 产物目录=<暂存目录>/dist/压缩一致性 node --test 压缩一致性.test.mjs`。

## 在本地 workerd 里复跑

把 `dist/压缩一致性/` 复制到一个空目录，去掉 `程序.wasm.wat`，补一个内容为 `{}` 的 `执行配置.json`（构建器缺省时应写入），再放 `wrangler.jsonc`：`{"name":"压缩检查","main":"入口.mjs","compatibility_date":"2026-09-04"}`；`wrangler dev --local --port <端口>` 起来后：`env 远端地址=http://localhost:<端口> node --test 压缩一致性.test.mjs`。同一份测试经 HTTP 调用真实 workerd，已在 wrangler 4.129.0 上全部通过。
