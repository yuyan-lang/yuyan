# 云工命名持久服务适配

实命名持久服务之约〇点五（云工薄宿主），悉以豫言书于云工薄宿主之通用原语（`库/云工宿主` 之物宿主与物）之上。先循 `DO` 之许取绑，乃以 `getByName` 依对象名取其物；径、查询（以 `URLSearchParams` 编之）、法与有限之头由豫言值授之，POST 正文以字节授 `Request`，`redirect: manual`。

- `请求命名持久服务文字`：发请后于此术之内有限整读（读态惟在术内），返状态、正文与所许四头之 JSON（上限八 MiB）；对象抛错、逾限、读败皆告豫言异常。
- `请求命名持久服务流`：`AbortSignal.timeout` 系于 `Request`，贯全程，得 `命名持久服务请求结果`。`命名持久服务响应` 包 Response、断信与读态之格；读态随答而行，一实例中交错之诸请不相涉；渐读、有限整读与止，与网页上游适配同一机。
- `转发网页请求至命名持久服务`：以网页服务适配之 `入站请求物` 取入站之 Request，以 `new Headers(入站 headers)` 复之，依白名删余头，增定头；POST 则以入站 `body` 之流授新 `Request`（`duplex: half`）；对象之答以 `物出站响应` 原样为出站之答。入站正文已读或已锁则告豫言异常。
- `命名持久服务原答转为出站响应`：已渐读之答告豫言异常；转出之后读得状态三。
- 对象名以 ASCII 字母、数字、下划线、短横与斜线成之（〇点三起许斜线，以承“户号/项目号”之名），惟授 `getByName`。
- 持久对象之绑未授或无之，取绑则告可承之豫言异常，不发请。

一致之验见 `一致性验证/`。
