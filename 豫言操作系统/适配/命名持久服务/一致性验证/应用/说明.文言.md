# 上游流一致性应用

试验之应用，验授权服务〇点三、网页上游〇点二、命名持久服务〇点二之带正文请、渐读、止、有限整读、动态公网 HTTPS 上游与入站请转发。惟供一致性测试，非业务之应用。

## 径

- `POST /run`，正文为 JSON 之述。`op`：`svc`（授权服务带正文之请）、`svcold`（旧授权服务之请，验旧柄可读）、`up`（静态来源之网页上游）、`upjson`（旧之整读 JSON）、`pub`（公网 HTTPS 上游）、`do`（命名持久服务流）、`dotext`（命名持久服务文字，返摘要）、`multi`（`mode` 取 `many`、`interleave`、`guard`、`argcheck`）、`badhandle`（无效柄）。
- 通用字段：`binding`、`object`、`url`、`method`、`headers`（二元数组列）、`query`、`body`、`bodyPow`（二之幂个 a）、`bodyExtra`、`timeout`、`read`（`chunks`、`limited`、`limitedtwice`、`mixed`、`sse`、`cancel`、`gated`、`none`）、`max`、`limit`、`header`。
- `/fwd`：由请头 `x-cfg`（JSON）予转发之述，以当前入站请转于持久对象。`/svcpass`：旧授权服务之原流直通。`/uppass`：旧网页上游之流答。`/dopass`：先流式请对象，验状态，乃以对象之答为终答。

报无控字：块以 `〔〕` 括之，段以 `‖` 分之。SSE 渐析仿 `AI市场应用/流式答复。豫`，惟测试用。
