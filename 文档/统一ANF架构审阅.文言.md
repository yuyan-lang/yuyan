# 统一 ANF 架构审阅稿

议已入工。今定结果 if、原生真栈与影子根栈，续延不得保存，默认导出仍旧。下文兼载全案，非谓诸项皆成；实验目标为 `shadow` 与 `wasmgc-anf`。

首途自举、计时及未竟之事，见[实现与自举](../性能研究/统一正则/实现与自举.文言.md)。

## 所议十事

一、分支与标签分派皆交结果，不复造续延函数以合流。
二、正则式另立数据之类，函数内以唯一序号名值，诸 let 有序而存。
三、循环有参、有果，续行与退出各明其目标。
四、普通调用、尾调、异常与提前退出各立其义，不混广义续延。
五、以运行时类型为度，未知者明为通用值，不复推源语言全类。
六、原语之签名、效果、错误与后端能力共一表。
七、各变换受验证之约，共享优化循此一式。
八、阶段之义独立，落盘依缓存与跨工之需，仍存 stage 与文本往返之能。
九、两后端共受一式，旧 WASI 路线待替代之能备而后去。
十、原生真栈与影子根栈同入此工，不取 Boehm；机器码仍托 LLVM。

## 式之纲

模块存版本、依赖、形状、常量、全局、函数与初始化之序。函数存参数、返回类、效果与体。体为有序绑定及结束式。普通算术、调用、读写诸参皆原子；惟 if、分派、循环、捕获与退出域内有子体。

```text
%果 = 如果 %条件 {
  %甲 = 直调 @甲函数(%输入)
  产出 %甲
} 否则 {
  %乙 = 直调 @乙函数(%输入)
  产出 %乙
}
%终 = 整数加(%果, 1)
返回 %终
```

产出者，归最近可交果之区域；返回者，离全函数。分支私名不出其域，惟结果可出。一支抛出则另一支供果；两支皆转出则不造假值，其后无可达之式。

循环之参于续行时同时易之，毋逐槽覆而失旧值。退出循环交其果。目标唯可为词法外层，毋入兄弟域、处理体或别函数。不置通用 goto。

## 构造与控制

今原生先作 ANF，复作续延传递与栈准备；网页汇编另在生成器中正则化。宜于闭包转换、函数提升之后，续延传递之前立共同边界。新器直接造结果分支，不先造旧合并点再拆，不复制共同后续。

函数内唯一值号与显示名分存。旧绑定序数于边界解一次，后用值号。构造用局部积累而终定，勿逐虑闭合复抄后树。内联必另名其复制值。前序函数名若仍有全局计数，先作归一化比较，不遽言全程确定。

普通调用交果，环境显作参数；代码引用不露本机地址与 Wasm 表号。尾调须核活动处理范围，不能但见“调用而即返”便弃当前 catch。循环、返回、异常转出皆结束所离之范围。

提前退出以每次激活之令牌为凭，异于静态标签。用户已定续延不得保存，不得越其动态之域。故以提前退出行之，激活之号不复用；网页汇编托 EH，原生托栈上跳返记录，转移前复影子根链。

## 类、效果与运行时

先备单元、爻、整数64、小数64、对象引用、代码引用与通用值。闭包转换今已无类型，故不能凭空补全；字面、原语与已知构造给其类，余循通用 ABI，后自擦除前留小型表示资料而渐精之。字段逻辑形状共用，物头、标签、指针压缩与写屏障归后端。

读、写、I/O、分配及 GC、抛出、陷阱、控制转移、不终止、回调皆须辨之。果不用不必可删；未知调用从慎。整数边界、浮点、字节串及越界之既有差异须核，不在格式之议中擅改其义。

原语共表，诸宿主依之查所缺；系统之锁与错误仍须各验。公共 ANF 不自行完成栈映射，真栈原生仍须保活 GC 引用并处置安全点。

## 验证、缓存与迁移

验值号唯一、先定义后使用、原子参数、分支产出、返回类、循环目标、字段可变性、处理域与原语能力。效果不可任输入自称无害。阶段读入必验版本与索引。

同工阶段传其值，跨工或缓存所需乃落盘；由消费者之数定释放，不使旧树皆存至终。默认文本导出仍旧，勿因统一正则而省之。缓存含 ANF 与原语版本，旧格式转换或失效，不与 CPS 后“求值正则形式”混写。先用现有 JSON 与文本框架，勿并造新二进制容器。

先立数据、读写与验证，次旁路造式，再切网页汇编消费者，再接原生真栈与影子根链；默认导出不改，旧后端留作比较。性能以同源同目标自举为重，分记构造、优化、生成、导出与总时。原生验三四代与类型，网页汇编验下一代；同后端查字节固定点，跨后端先较规范式与行为。
