# 快速开始

下列步骤，行于 Linux 与 macOS。系统须先备 `clang`、`curl`、`tar`；其常设之法如次：

```sh
# Debian / Ubuntu
sudo apt-get update
sudo apt-get install clang curl tar

# macOS（Homebrew）
brew install llvm
```

## 构建稳定自举编译器

于仓库根目录下载[连续自举包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-bootstrap)，构其中之编译器，名之曰本仓库约定之 `yy_bs_stable`：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-bootstrap/yuyan-bootstrap-bundle.tar.gz \
  --output 豫言自举包.tar.gz
mkdir -p 豫言自举包
tar -xzf 豫言自举包.tar.gz -C 豫言自举包 --strip-components=1
./豫言自举包/构建.sh
cp 豫言自举包/豫言自举编译器 ./yy_bs_stable
chmod +x ./yy_bs_stable
./yy_bs_stable --version
```

自举包须以 `clang` 自 LLVM 中间表示重链；垃圾回收器已含于运行时源码，无须另装 Boehm GC。

## 编写并运行程序

新建 `你好。豫`：

```yuyan
寻观「标准库」之书。

「打印行」于『你好，豫言！』。
```

于仓库根目录运行之；编译器默认自 `./藏书阁` 寻标准库：

```sh
./yy_bs_stable 你好。豫
```

惟编译而不运行：

```sh
./yy_bs_stable 你好。豫 --compile-only -o 你好
```

欲传命令行参数于编译后之程序，则于参数前加 `--`：

```sh
./yy_bs_stable 你好。豫 -- 参数一 参数二
```

欲观编译器之全部选项：

```sh
./yy_bs_stable --help
```
