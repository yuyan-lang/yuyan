# 直立设备地址隔离

用户已决以 IOMMU 限 DMA。核掌设备地址空间、映射、撤销与故障，用户驱动掌 Virtio。浏览器 I/O 由宿主供之。此为实施次第，非谓已成。

臂机试 SMMUv3，关总线旁路；兼容机试 Q35 与 Intel VT-d，启其 DMA 翻译模型。AMD64 此处为指令集，不谓已支持 AMD 厂商之 IOMMU。初未赖中断重映射，不以 DMA 隔离冒中断隔离。Virtio 明启平台翻译，关 ATS，旧平台仍作回归。

先据可信平台描述辨设备与寄存器，勿任探未知地址。再立核专有之表、命令与故障队列，未授权者无 DMA 映射。设初态而待硬件确认，非写一次寄存器便谓已成。驱动得独立设备地址空间，仅映其获授 CPU 缓冲，不受任意物理址。协商不合则拒，勿退回旁路。

撤销须令缓存失效并待完成；停新请求、处在途 DMA，而后收页。驱动终止与设备复位亦守此序。故障设备止其访问，余任务续行。核自用队列不得交驱动改。

始限一设备、一空间、一在途请求，非减隔离之约。必实试授权访问、未映射与只读拒绝、撤销后拒绝、页回收无旧写；另故放权限，使保护区变化而测试败，以证实有 DMA。隔离既验，再读写磁盘、刷新、重启复读，继作文件持久化。

先验两模拟平台兼容，继立空表而候硬件开启确认；均不代实 DMA 拒绝与映射撤销之验。规范与来源详汉语稿。
