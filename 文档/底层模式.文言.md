# 底层模式（不用垃圾回收之编译模式）

底层模式者，豫言编译器之第二编译模式也。执行器、驱动、文件系统等系统之代码，以**常豫言之语法**书之；编译之时，不用垃圾回收，亦不倚标准库之运行时，径生仅含整数指令之标准 Wasm 模块，可由豫言操作系统之寄存器降级后端译为裸机机器码。此代前所自造括号式“低阶语言”者：语言唯一，所异者编译之模而已。

## 一、模之所在：包描述

编译之模，包之性也，书于 `包名。包。豫` 之可选字段，不视文件之后缀，源文仍皆 `。豫`：

```
「编译模式」者『底层』也。
```

- 其值唯二：`高级`（缺省，有垃圾回收）、`底层`。
- 同一依赖之闭包，诸包必同其模。豫构解包图时校之，不合则报错；故底层之包不得依标准库，唯得依底层之包（如 `底层库`）。
- 豫构读此字段，以“底层诸包之文件列”授于编译器之包上下文（第三式，唯有底层包时乃见；无则与旧式字节全同，缓存不失）。编译器依入口文所属之包择其管线。
- 底层可执行之包，所成者 Wasm 模块，非原生程序：豫构不作原生链接；`「文件名」` 仍须以 `yy` 起或以 `.exe` 终（如 `yy客体执行器.wasm`）。

## 二、语言之子集

底层模式全用豫言之语法与类型检查；所异者，后端之所受也。凡不可入无垃圾回收之境者，编译之时明报其错，不退回垃圾回收。

| 所受 | 所拒（报错） |
| --- | --- |
| 整数、爻、单元 `元`、`若…则…否则`、`虑`、`；` | 元组、构造器（枚举）、构造器之 `鉴` |
| 整数常量之 `鉴`（成分派） | 字符串之值、小数、异常、续延 |
| 一阶函数：全局函数、局部函数（依其被调之情处之，见下） | 闭包、以函数为值而传、间接调用 |
| 自递归与尾调用（尾位之自调化为回跳） | 引用类、数组、字典等运行时之数据结构 |
| 外部调用之原语（见 `底层库`） | 不在 `底层库` 之外部调用名 |

诸值皆**三十二位整数**（`i32`）：整数按补码回绕，爻为零一，单元为零；函数恒返一整数。

## 三、函数与循环

- **顶层函数**：`「名」乃化…也。「名」者会…也。` 成 Wasm 函数；唯自导出函数（见下）沿调用图可至者乃生。
- **自递归**：豫言编译器已升满参递归为全局函数；后端以尾位之自调改为回函数起点之跳（`br`），非尾位之自调则为常调。互递归须自改写（豫言无前向引用）。
- **局部函数**（`虑「f」者（化…）也（会…）而`、`递归虑「f」其…者…而`）依其被调之情三取其一：
  1. 未被调：弃之；
  2. 仅被调一次而不自调：展之于调处；
  3. 仅被调一次而自调皆在尾位：成**内联循环**（共用外层函数之局部变量，可读写外层之可变格）；
  4. 余者：升为全局函数，自由变量为前置形参（**不得捕获可变格**，否则报错）。
- 是以惯常之写法：“单次调用之局部递归函数 = 循环”。

## 四、可变格

`新格`、`读格`、`写格` 供函数内之可变变量：

```
虑「和」者「新格」于「零」而
虑「位」者「新格」于「零」而
递归虑「当」其化「有」而「整数」者会「无」而
  若「小于」于（「读格」于「位」）于「数」
  则（（「写格」于「和」于（「加」于（「读格」于「和」）于（「读格」于「位」）））；（「写格」于「位」于（「加」于（「读格」于「位」）于「一」））；「当」于「元」）
  否则「读格」于「和」
而「当」于「元」
```

格成 Wasm 局部变量，必直接由 `虑 名 者 新格 … 而` 所绑，且唯作 `读格`、`写格` 之首实参；不得为常值而传，亦不得为提升之函数所捕。

## 五、内存、静态数据与声明

- 线性内存之读写：`读四`、`读二`、`读二有符号`、`读一`、`读一有符号`、`写四`、`写二`、`写一`；`内存页数`、`内存增长`、`内存复制`、`内存填充`。
- 顶层值定义必为**编译时之常量**：整数常量、常量间之整数运算、他常量之引用、`静态串` 之结果。其入函数者，代以数字。
- **声明**乃顶层值定义：`「内存」者（「声明内存」于「初始页」于「最大页」）也。`、`「数据区」者（「声明数据区」于「起」于「止」）也。` 各止一声；用 `静态串` 之前须先声数据区（编译器先求含声明之定义，故书写之序无碍）。
- `「串址」者（「静态串」于『你好』）也。`：字符串以 UTF-8 附零字节置于数据区，其值为址；文同者共一份。

## 六、导入与导出

- **导出**：定义名以 `导出：` 起者，为模块之导出函数，导出之名乃其后之部（`「导出：启动」` 导出为 `启动`）。唯导出函数及其调用图乃生成。
- **导入**：外部调用名 `导入：模块：字段：参数数：结果数` 为宿主函数之导入，如 `《《C调用》》名『导入：平台：写字节：1：0』传「字节」`。结果数为零者，其值为单元零。

## 七、分派

对整数变量之等值判断之链（含对整数常量之 `鉴`）合而为分派：至多四项则逐项较之，多则依键折半。同键取先者。

## 八、编译管线

底层模式下，每文依次行：语法分析、名称解析、类型检查、类型擦除、跨模块优化、**闭包前优化**（止于此，不作递归转换、闭包环境、全局存储、函数提升）。入口文之终阶，由底层后端读各文之闭包前优化形式：

1. **读取**：转树为无类型简树，予每绑定以全局唯一之名，平柯里化之调用，收局部函数为 `局函`，拒闭包、元组、构造器、异常、续延、字符串值；
2. **顶层常量**：随用随求；先求含声明者；
3. **化简**：代入字面，折叠纯整数运算，静态串定其址，常量引用取其值；`令 x = v 于 若 x …` 而 x 不复见者，并为 `若 v …`；
4. **提升**：如第三节；全局函数之尾自调化为回跳；等值之链成分派；
5. **生成**：每式于操作数栈留一 i32；局部下标形参居前，依作用域分配，同级分支复用；分派以嵌套块加决策树；
6. **总装**：自导出函数沿调用图集可达之函数，附导入、内存、数据段，编码并**验证**为标准 Wasm 二进制。

## 九、验证与器用

- **回归之例** `测试/底层示例`：底层之包，唯依 `底层库`，涵尾递归、非尾递归、分派、内联循环、可变格、位运算、多参数、无符号之较、静态串与内存。构之：`./yy豫构 构建 底层示例 --输出 /tmp/yy底层示例.wasm`。
- **宿主侧之校器** `工具/底层测试`：`yy底层测试 模块.wasm` 读其模块，行标准之验与二进制之往返，装成带内存与数据段之状态实例，于宿主之整数执行器逐项调其导出而核其果（二十五项）。
- **试验之器** `工具/底层生成`：`yy底层生成 读|编译 …` 径读阶段文本，便于察简树与所生之码；开发后端不必重建编译器。
- 豫构之测试 `工具/豫构/包资料。测试。豫`、`包系统。测试。豫` 涵编译模式之字段、依赖闭包同模之检与第三式包上下文之往返。
