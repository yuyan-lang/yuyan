# 中间阶段性能

二零二六年九月八日，本机 arm64，以十八工作进程度之。遵所嘱，各取数次之**最短完成时间**，不以均值断退进；他事并行，慢样本存而不据之立论。

终版冷构建三试：

| 样本 | 次序 | 癸象单书秒 | 双书秒 |
| --- | --- | ---: | ---: |
| 甲 | 单而双 | 57.03 | 88.45 |
| 乙 | 双而单 | 43.43 | 53.71 |
| 丙 | 单而双 | 45.59 | 45.16 |
| **各取最短** |  | **43.43** | **45.16** |

双书多一又七三秒，约百分之四。暖缓存三试，单书五点一二、五点零零、五点零七秒；双书五点五八、五点四八、五点九三秒。各取最短，差零点四八秒。旧有八成至九成之大退已不复见，然今尚有小费，不谓全无回退。

所用编译器同，分名使编译缓存各空；源码、选项、并发数亦同。共享原生缓存与系统页缓存不清。两式内读皆癸象，存内存者径取其树，不读豫文。六次所得编译器皆同于自举固定点：

`86077f42941802fe3272c7577ba9244e4412c99bab6921740f5b69c4a0262c22`

同树三度，各项取最短，单位毫秒：

| 样本 | 癸象编码 | 源码编码 | 写源码 | 复解源码 |
| --- | ---: | ---: | ---: | ---: |
| 多态列词法 | 14.847 | 0.008 | 0.281 | 2.352 |
| 表达式解析闭包 | 54.626 | 3.995 | 0.250 | 742.859 |
| 表达式解析代码生成前 | 357.324 | 19.321 | 0.557 | 4,339.199 |

各列最短未必出于同次，不可相加作总时。初读文件及解癸象不计入编码。九次复树再书癸象，与原树之规范文皆同。源码复解用共同语法，非日常双书之内读路径。

词法之文即原书，加阶段注于首；去此注而复词，原空白、注与源域不易。昔以长元组载令牌，同一例复解约八十四秒，今废之，约二点三五毫秒。独立输入须验源与词相符；常读癸象不重词法。

终版有三千八百五十三对阶段文件。癸象六二三九九一四八六字节，源码三五九五一二零八七字节，合九八三五零三五七三字节，约单份之一点五七六倍。LLVM、对象及共享原生缓存不入此数。

今直取树之有型字段书源码，不先造癸象；可用旧语法者循之，无旧文者以 `「《《扩展名》》」【…】` 申之。以显栈积片，串与名直扫字节。书文件先直开，缺父径乃建，不反复逐层 mkdir/stat。缓存之效以癸象为准，缺豫文则补书，不重行阶段，不易癸象时刻。

往返、手书作用域、词法一致性、建径覆写、逐阶新进程至 LLVM、三举固定点及类型检查皆验。独立对象终链而行，得“捕获值”。

旧 AST 包装之八成至九成增幅，属已废之制。重做途中尚有较慢样本，亦不删；其快照、原始计时、日志位置与复现命令详见[汉语篇](中间阶段性能.汉语.md)，不得与终版混取最短。
