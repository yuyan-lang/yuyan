# 中间诸言与编译分阶

编译每至一阶，常并书癸象与豫文。内读以癸象为常；豫文可复解，不待执行。诸言共词法、括号、引号与序列。定义以者、即、乃，函数以会、受、遇；调用、虑、分支、元组与函数类型，皆循源码。其降级之义无旧文可书者，以 `「《《扩展名》》」【参数…】` 申之；列头仍自由名，不改词法。语法同，而各阶所许之式有别。

常用绑定以名书之；名有遮蔽、无名或不可直书者，乃用扩展，索引自一始。词法之文直存原书，首加阶段之注；读则去此注而复词，原空白与源域不易。词与源须相符，独立输入验之；常读癸象不再词法。余阶篇首记版本二、阶段、公开性与声明类别，正文可改而复解。诸参直取于树，不先造癸象，不复以“中间节点”包万物。癸象以有序数组存定义，不托典键之序。小数存十七有效位，原十进字面亦存。源域与注释俱可复得。

诸阶之次：词法、抽象语法、名称解析、类型检查、模式展开、类型擦除、续延调用展开、隐参擦除、跨模块优化、闭包前优化、递归转换、闭包环境、全局存储、函数提升、求值正则、消冗、续延传递、代码生成准备。全局存储暂汇为一初始化式，提升后复为函数组。检查后定义与对象并存，名称解析所得跳转资料亦存。优化内部之递归重写，不各立文件。

独行一阶，命曰：

```sh
./yy2_bs stage 输入阶段 输出阶段 输入文件 输出前缀 源文件身份 \
  [依赖源身份 依赖阶段 依赖文件]… [-- 编译器选项…]
```

源文件身份定其模块，未必尚存原书。所依模块、阶段、产物须明授；若须源文，以“源码”阶段授其快照。词法产物本含源文。依赖不备则告缺，不暗取旧缓存。输入输出同阶，则但换其表示。语义标记与编辑器协议非中间程序；LLVM 与机器产物亦各循旧制。

验之，以复解后同于原式为本，以独行诸阶同于连行为继。常写两式，读癸象；度其费，可用 `--intermediate-json-only` 作单写之对照，以 `--read-intermediate-text` 度豫文之读。性能程序名“中间语言性能”，以豫言作之，读文、预热、复解、编码分别计时。冷暖缓存与磁盘之量，须各记之，不先断其快慢。

书文以显栈积片，终乃合之；串之转义与名之辨直扫字节，毋逐字造列。书文件先直开之，缺父径乃建，不逐阶反复建同径。扩展与调用之参，加括号以明其界。缓存之效以癸象为准，唯缺豫文则补书之，不重行其阶，不改癸象时刻。

代码既成，当验类型，继以三举，比较 `yy3_bs` 与 `yy4_bs`，同乃成其固定点。

后端亦可独行：由“代码生成前形式”至“代码生成形式”，LLVM、位码、对象文件皆从所授输出前缀；并书完成标记。多模块之序，仍以 `--override-add-file-dependency` 明授；终链归构建系统。

回归兼验：中间语言往返，阶段非法输入与长列反转，逐阶新进程至 LLVM 之集成，暨建径、覆写、空文与零字节。以“阶段样例。测试”验捕获及打印；独立文本所得对象终链，输出“捕获值”，与新旧编译器连行同。旧注释与语义标记之试亦过。性能实测另载同名性能篇。
