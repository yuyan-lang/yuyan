# 前端补全计划：让云控制台前端用豫言浏览器应用重写

状态：2026-09-26 起草，由“前端接口”代理（F1）维护；“前端应用”代理（F2）据此写代码。本文分七部分：一、范围与结论；二、缺口表（前端用到的每一个浏览器能力，对照现有 OS 接口）；三、新增与升级的接口一览（签名速查）；四、进度表（F2 只使用“规范已提交”的接口；能构建、能验收的以“适配已提交／验证通过”为准）；五、F2 使用须知；六、登记文本（交主代理）；七、需求留言（F2 在文末追加）。

## 一、范围与结论

**范围**：云仓 `应用/豫言云工作台/网页/{工作台,控制台,智能输入,命令总线,本地编译,行差异}.mjs` 与 `工具/包管理服务/网页/阅读状态.js`。代码浏览器（`应用/豫言代码浏览`）已从云仓删除，不在范围内。

**审计结论**（逐文件通读并对照当前的 `豫言操作系统接口/`、`豫言操作系统/适配/`、`库/拓展库/浏览器宿主/`、`宿主/浏览器/宿主.mjs`）：

1. 调研 `浏览器前端.md` 里最重的四个结构性阻塞——统一事件队列、句柄表压力、无 id 元素的事件委托、同步 `preventDefault`——**已由 `网页事件` 0.1.0、`网页界面` 0.2.0、`网页文树` 0.2.0、`网页消息` 0.2.0 解决**（含键规则 `仅选区为空/仅目标标识/仅当属性`、`data-yy` 操作键、一次建树、整树释放、每类型背压）；浏览器宿主实现已落库（提交 8aafbddb），92 例一致性验证通过。**不重做。**
2. 仍缺的是三类：**(甲)** 统一事件队列里“预留”的四类事件源——定时、事件流（SSE）、请求（非阻塞 fetch）、编译——还没有对应的 OS 接口包；另有储存、导航与历史、页面环境（时区、饼）、启动另一个豫言应用。**(乙)** 已有的通用 OS 接口（时间、随机数、网址定位、网址查询、日志、文字规整）只有“云工”适配，浏览器构建绑定不到。**(丙)** 现有接口的几处小缺口：按选择器过滤的同步拦截、事件载荷带目标属性与矩形、程序性点击、属性移除与读回、节点矩形与位置、选择器查询与节点读回、受限超文本装入（阅读状态与源码高亮用）。
3. 处置：新增 8 个接口包（网页定时、网页储存、网页导航、网页环境、网页请求、网页事件源、网页编译、网页应用），升级 3 个（网页事件 0.2.0、网页界面 0.3.0、网页文树 0.3.0），补 6 个浏览器适配（时间、随机数、网址定位、网址查询、日志、文字规整，目录名带“浏览器”，构建器在浏览器模式下优先选它）。宿主 JS 只在 `豫言操作系统/宿主/浏览器/宿主.mjs`；新增逻辑写成可脱离 Wasm 单测的工厂函数，业务规则一处写成、多处校验。
4. **批次**：第一批（控制台 `工作台/控制台/智能输入/命令总线/本地编译`）＝定时、储存、导航、环境、请求、事件源、编译、应用、网页事件 0.2.0、网页界面 0.3.0、四个浏览器适配（时间、随机数、网址定位、网址查询）；第二批（阅读状态）＝网页文树 0.3.0 与日志、文字规整的浏览器适配。

## 三、新增与升级的接口一览（签名速查）

完整语义、限额、失败与一致性样例以各包 `规范.汉语.md` 为准；此处只列签名与要点。类型记法同规范：`有`＝单位值；`爻`＝布尔；`（甲 合 乙）`＝二元组；JSON 文字都是 UTF-8 字符串。**所有新事件源都进同一个统一事件队列，用 `等待网页事件` 取（见网页事件规范）**，事件 JSON 里 `类型` 与 `订阅号` 区分来源。

### 网页定时 0.1.0（`定时。接口。豫`）

- `启动一次定时 : 整数(毫秒) → 字符串(标记) → 整数(定时号)`
- `启动重复定时 : 整数(间隔毫秒) → 字符串(标记) → 整数(定时号)`
- `取消定时 : 整数 → 爻`（曾存在且未到期为阳；同时清掉该定时号尚未取走的事件）

事件：类型 `定时`，`订阅号`＝定时号，`名称` 为“定时”，`详情` 为 `{"种类":"一次"或"重复","标记":文字,"时刻":Unix毫秒}`。同时至多 64 个定时器；周期定时器在上一个事件被取走前不重复投递。

### 网页储存 0.1.0（`储存。接口。豫`）

- `读取网页储存 : 字符串(区域) → 字符串(键) → （爻 合 字符串）`（存在与否，值）
- `写入网页储存 : 字符串(区域) → 字符串(键) → 字符串(值) → 爻`（配额满、隐私模式等失败返回阴，不抛事故）
- `删除网页储存 : 字符串(区域) → 字符串(键) → 有`

区域只有 `会话`（sessionStorage）与 `本地`（localStorage）；键不加前缀，原样使用；键至多 512、值至多 1 MiB（UTF-16 码元）。

### 网页导航 0.1.0（`导航。接口。豫`）

- `前往网址 : 字符串 → 有`（`location.assign`，解析后只允许 http/https）
- `替换当前网址 : 字符串 → 有`（`location.replace`）
- `重载页面 : 有 → 有`
- `压入历史 : 字符串 → 有`、`替换历史 : 字符串 → 有`（`pushState/replaceState(null,'',url)`，只允许同源）
- `移动历史 : 整数 → 有`（`history.go`）

回退与前进产生的 `popstate`、`hashchange` 用网页事件包订阅“窗口”取得（类型 `历史`）。

### 网页环境 0.1.0（`环境。接口。豫`）

- `读取本地时区偏移分钟 : 整数(Unix毫秒) → 整数`（东为正：北京时间为 480；按该时刻的夏令时计）
- `读取页面饼 : 字符串(名) → （爻 合 字符串）`（只读当前页面可见的饼，原样返回）

### 网页请求 0.1.0（`请求。接口。豫`）

- `发起网页请求 : 字符串(请求 JSON) → 整数(请求号)`：非阻塞；结果作为类型 `请求` 的事件投递，`订阅号`＝请求号，`名称` 为“完成”或“失败”，`详情` 为响应对象。
- `取消网页请求 : 整数 → 爻`：取消后保证不再收到该请求号的事件。
- `请求网页文字 : 字符串(请求 JSON) → 字符串(响应 JSON)`：阻塞变体（挂起当前调用，其余事件照常排队）。

请求 JSON：`{"方法":"GET","网址":"/cloud/api/session","标头":{"Content-Type":"application/json"},"正文":文字,"缓存":"不缓存","超时毫秒":60000,"正文上限":8388608,"标记":文字}`（除网址外皆可省）。只允许同源。响应对象：成功 `{"成":true,"状态":200,"状态文":"OK","标头":{小写名:值},"正文":文字,"标记":文字}`；失败 `{"成":false,"原因":"网络错误|超时|正文过大|正文不是有效UTF-8","说明":文字,"标记":文字}`。任何 HTTP 状态码（含 4xx、5xx）都算“完成”。并发至多 32。

### 网页事件源 0.1.0（`事件源。接口。豫`）

- `打开事件源 : 字符串(网址) → 字符串(选项 JSON) → 整数(事件源号)`
- `关闭事件源 : 整数 → 爻`

选项 JSON：`{"起始事件号":"…","重连毫秒":3000}`（可省）。事件：类型 `事件流`，`订阅号`＝事件源号，`名称`：`打开`；`消息`（详情 `{"批":[{"事件号":"12","事件名":"message","数据":"…"},…]}`，一批 1 至 256 项，宿主在队列有积压时不再读流，**不丢事件**）；`错误`（详情 `{"状态":"重连中"或"已关闭","原因":文字}`）。断线自动带 `Last-Event-ID` 重连（`重连中` 之后可再收到 `打开`）；HTTP 非 200、内容类型不对属致命，`已关闭` 后不再有事件。仅同源；同时至多 8 个。

### 网页编译 0.1.0（`编译。接口。豫`）

- `本地编译可用 : 有 → 爻`（JSPI、Worker、DecompressionStream 齐备）

## 五、F2 使用须知

**事件循环形态**：应用只有一个阻塞点 `等待网页事件`，返回的 JSON 里 `类型` 取 界面／消息／定时／事件流／请求／编译／可见性／联机／历史／关闭。请求号、定时号、事件源号、编译号、界面订阅号都出现在 `订阅号` 字段；应用自己保存“号 → 处理”的对应表。旧的 `等待界面事件`、`等待网页消息` 可与它混用，但同一个事件只被取走一次。

**限额速记**：句柄表 4096（用一次建树后立即释放）；界面订阅 ≤256；定时 ≤64；并发请求 ≤32；事件源 ≤8；每类型事件队列默认 1024（`设置网页事件队列上限` 可调到 65536）。

**同步决定必须预先声明**：阻止默认与停止传播只能在订阅时写进策略；要按运行状态改变，请取消并重新订阅，或用键规则的 `仅当属性`。程序性 `点击节点` 会经过页面上的所有订阅：回放被拦截的点击时，须先 `取消订阅界面事件` 再 `点击节点`，随后重订。

**时间与区域**：`读取当前Unix毫秒`（时间接口）加 `读取本地时区偏移分钟` 得本地时间，格式化固定为 zh-CN 数字样式，用纯豫言写；旧代码的 `toLocaleString` 输出会有细微差异，需在报告里说明。


**与旧 JavaScript 行为的已知差异与限制**（迁移时逐条核对）：

- 属性白册：动态节点**不能设 `style`、`name`、`src`、`rel`（`target=_blank` 时自动带 `rel`）、`contenteditable`、`on*`**；`tabindex` 只有 `-1`/`0`；`data-*` 名称只能是小写字母、数字与短横线（`dataset.taskId` 对应 `data-task-id`）；单选框分组需要的 `name` 只能由页面静态 HTML 提供。
- 元素 ID 不含空白、引号、`<>&` 与反斜杠，至多 128 个字符；同一文档内不得重复。
- 储存的键不加前缀、原样使用；配额失败返回阴。
- 请求只能同源；带本站的饼；`AbortController` 由 `取消网页请求` 代替；`Response.json()` 由豫言 `癸象解析` 代替（HTML 错误页仍会作为正文文字返回，不会抛错）。
- 事件流以**批**到达，`事件号` 是服务端 `id:` 原文；重连后可能重放已见过的事件，应用自己按业务编号去重（旧代码已如此）。
- 没有 `pagehide` 时的同步写；没有 `beforeunload`；页面卸载后应用立即终止。
- 被自己拦截的点击要回放，须先取消订阅、`点击节点`、再重订；`阻止默认`／`停止同处` 只能在订阅时声明。
- 本地时间格式化用 `读取本地时区偏移分钟` 自算，输出固定 zh-CN 数字样式（`toLocaleString` 的细微差异需在报告里说明）。
- 应用测试可复用 `豫言操作系统/适配/网页定时/一致性验证/测试/夹具.mjs` 的 `启动探针`（选项：`网络`、`储存`、`窗扩展`、`编译客户端`、`导入模块`、`页面应用超时`），网络类用本机 `node:http`；路径请用 ASCII。
