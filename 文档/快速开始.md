# 快速开始

以下步骤适用于 Linux 和 macOS。请确保系统已有 `clang`、`curl` 和 `tar`；常见安装方式如下：

```sh
# Debian / Ubuntu
sudo apt-get update
sudo apt-get install clang curl tar

# macOS（Homebrew）
brew install llvm
```

## 构建稳定自举编译器

在仓库根目录下载[连续自举包](https://github.com/yuyan-lang/yuyan/releases/tag/continuous-bootstrap)，构建其中的编译器，并将它安装为本仓库约定的 `yy_bs_stable`：

```sh
curl --fail --location \
  https://github.com/yuyan-lang/yuyan/releases/download/continuous-bootstrap/yuyan-bootstrap-bundle.tar.gz \
  --output 豫言自举包.tar.gz
mkdir -p 豫言自举包
tar -xzf 豫言自举包.tar.gz -C 豫言自举包 --strip-components=1
./豫言自举包/构建.sh
cp 豫言自举包/豫言自举编译器 ./yy_bs_stable
chmod +x ./yy_bs_stable
./yy_bs_stable --version
```

自举包需要使用 `clang` 从 LLVM 中间表示重新链接；垃圾回收器已经包含在运行时源码中，不需要安装 Boehm GC。

## 编写并运行程序

新建 `你好。豫`：

```yuyan
寻观「标准库」之书。

「打印行」于『你好，豫言！』。
```

在仓库根目录运行它；编译器默认从 `./藏书阁` 查找标准库：

```sh
./yy_bs_stable 你好。豫
```

只编译而不运行：

```sh
./yy_bs_stable 你好。豫 --compile-only -o 你好
```

向编译后的程序传递命令行参数时，在参数前使用 `--`：

```sh
./yy_bs_stable 你好。豫 -- 参数一 参数二
```

显示编译器的全部选项：

```sh
./yy_bs_stable --help
```
