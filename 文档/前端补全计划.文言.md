# 前端补全计划：使云控制台之前端以豫言浏览器应用重写

此文乃[汉语本](前端补全计划.汉语.md)之文言节本，二者并行而维；缺口之细表、诸术之签及登记之文，以汉语本为准。“前端接口”之代理（F1）维之，“前端应用”之代理（F2）据之作代码。

## 一、范围与断语

**范围**：云仓 `应用/豫言云工作台/网页/` 之工作台、控制台、智能输入、命令总线、本地编译、行差异六文件，及 `工具/包管理服务/网页/阅读状态.js`。代码浏览器已自云仓除去，不在此列。

**审计之断**（逐文件通读，而对照今之接口、适配、浏览器宿主库与宿主）：

1. 调研所谓四大结构之阻——统一事列、柄表之压、无标识元素之委托、同步之止默认——**已由网页事件、网页界面、网页文树、网页消息四包解之**（含键律之“仅选区为空、仅目标标识、仅当属性”、`data-yy` 操作键、一次建树、整树之释、每类之背压）；宿主之实早已入库，九十二例一致性之验皆通。**不重作。**
2. 所缺者三类：**其一**，统一事列中“预留”之四类事源——定时、事件流、请求、编译——尚无其接口之包；又缺储存、导航与历史、页境（时区、饼）、启另一豫言应用。**其二**，已有之通用接口（时间、随机数、网址定位、网址查询、日志、文字规整）惟有“云工”之适配，浏览器构建无从绑定。**其三**，现有接口之小缺：按选择器之同步拦截、事载之带目标属性与矩形、程序之点、属性之去与读、节点之矩形与位、选择器之查询与节点读回、受限超文本之装入（阅读状态与源码高亮用之）。
3. 处置：新立八包（网页定时、网页储存、网页导航、网页环境、网页请求、网页事件源、网页编译、网页应用），升三包（网页事件零点二点零、网页界面零点三点零、网页文树零点三点零），补六浏览器适配（时间、随机数、网址定位、网址查询、日志、文字规整；目录名带“浏览器”，构建器于浏览器模式先取之）。宿主 JS 惟在 `豫言操作系统/宿主/浏览器/宿主.mjs`；新增之理写为可离 Wasm 而单测之工厂，业务之律一处成之而多处受验。
4. **批次**：第一批（控制台）＝定时、储存、导航、环境、请求、事件源、编译、应用、网页事件零点二点零、网页界面零点三点零、四浏览器适配；第二批（阅读状态）＝网页文树零点三点零与日志、文字规整之浏览器适配。

## 二、缺口之表（要）

- **事与输入**：click、input、change、submit 之委托与 `data-yy` 操作键、keydown 之同步拦截（Ctrl+L、无选区之 Ctrl+C、目标为命令框之上下键、候选可见时之诸键）、组字，皆**已备**；文档捕获相之 click 拦截（惟拦导航之链与语言钮，且读所点之 href）与悬停提示之 `closest`，**缺**，以网页事件零点二点零之选择器、排除选择器、带属性、带矩形补之；程序之 `.click()`，缺，以网页界面之点击节点补之；`pagehide` 时同步书储，凡 Wasm 应用皆不能，不供（阅读状态每 toggle 已即记）。
- **界面之读写与节点树**：属性、hidden、类名、data-、aria-、value、焦点、光标、选区、滚动、显隐、iframe 之址、一次建树、插入、替换、移除、释放、模板之装，皆已备；缺者：removeAttribute、读回属性与文、根元素之 data-lang、getBoundingClientRect 与 style.left/top（以设置节点位置、读取节点矩形补，不开放 style）、innerHTML（以设置页面节点超文本补，白册清洗）、querySelector/closest/matches/父/子/TreeWalker/Range（以选择器之查询、读取页面节点树补）、动态 `import()` 他 Wasm 应用（以网页应用补）。
- **定时、储存、导航、网络、事件源**：setTimeout/setInterval（网页定时）、sessionStorage 与 localStorage（网页储存）、location 与 history（网页导航）、document.cookie（网页环境）、本地时间（网页环境之时区偏）、Date.now 与 randomUUID 与 URL 与 URLSearchParams（四浏览器适配）、fetch 之并发与取消（网页请求）、EventSource 之重连与回放洪峰（网页事件源，宿主依列之余量缓读而不失事）、Worker 加 Wasm 之本地编译（网页编译）。
- **不属操作系统者**（F2 以纯豫言写之）：正则（约五十五处，须手书扫描器）、Markdown 之子集、命令预览之未闭合癸象扫描、行差异、命令总线之状态机、ISO 时间之析、UTF-16 长度与 UTF-8 字节数、拼音字表之反查。

## 三、新增与升级之接口（要）

签名与义以各包之约为准；今仅列其名与要。凡新事源，皆入同一统一事列，以“等待网页事件”取之。

- **网页定时** 零点一点零：启动一次定时、启动重复定时（间隔十毫秒起）、取消定时；事类“定时”，订阅号即定时号；周期不积压；取消保不复收；至多六十四期。
- **网页储存** 零点一点零：读取、写入、删除；区曰“会话”或“本地”；写败（配额、被禁）返阴而不发事故。
- **网页导航** 零点一点零：前往网址、替换当前网址、重载页面、压入历史、替换历史、移动历史；址限 http 与 https，历史限同源。
- **网页环境** 零点一点零：读取本地时区偏移分钟（东正）、读取页面饼（只读，原样，HttpOnly 不见）。
- **网页请求** 零点一点零：发起网页请求（不候，果入列）、取消网页请求、请求网页文字（阻塞之变体）；限同源，并发三十二（含果未取者），正文严格 UTF-8 而有上限。
- **网页事件源** 零点一点零：打开事件源、关闭事件源；事类“事件流”，名曰打开、消息（成批）、错误；断则带 Last-Event-ID 自重连；宿主于列中未取逾八批则止读，不失事。
- **网页编译** 零点一点零：本地编译可用、启动本地编译、停止本地编译；事类“编译”，进度成批，终以“完成”。
- **网页应用** 零点一点零：启动页面应用（同源入口之径，候子应用就绪，随父应用而闭）。
- **网页事件** 零点二点零：订阅策略增选择器（最近合者）、排除选择器（点于某域之外）、带属性、带矩形。
- **网页界面** 零点三点零：读取节点属性（保留字“文档根”“页体”）、移除节点属性、读取节点文字、点击节点、设置节点位置、读取节点矩形。
- **网页文树** 零点三点零：查询页面节点（含 template 内容）、读取页面节点标签、属性、文字、父级、查找最近页面祖先、页面节点匹配选择器、读取页面节点树（导出之形同构建页面节点树之入）、替换页面节点、移除页面节点属性、设置页面节点超文本；签之白册增 em、i、kbd、sup、sub、blockquote、hr、dl、dt、dd。
- **浏览器适配**：时间浏览器、随机数浏览器、网址定位浏览器、网址查询浏览器、日志浏览器、文字规整浏览器。

## 四、进度

诸项皆**验证通过**：八新包、网页事件零点二点零、网页界面零点三点零、网页文树零点三点零、六浏览器适配。验收共一百五十三例（JSDOM 加真实 Wasm，网络类用本机 node:http），并于 Chromium 一百五十二（JSPI）之真浏览器逐项验之；真编译客户端、Firefox、Safari 及后台标签页等列于 `豫言操作系统/适配/网页定时/一致性验证/真实浏览器验收清单.文言.md` 之待验。F2 以 `建应用.sh <暂存> 浏览器 <应用目录> <输出名>` 构建，依赖 `豫言操作系统网页定时` 等者自动绑定其适配。详表见汉语本第四部分。

## 五、F2 用之须知

- **事环之形**：应用惟一阻塞点乃等待网页事件，其癸象之“类型”取界面、消息、定时、事件流、请求、编译、可见性、联机、历史、关闭；请求号、定时号、事件源号、编译号、界面订阅号皆见于“订阅号”，应用自存“号至处理”之对应。
- **限额速记**：柄表四千零九十六（一次建树后即释）；界面订阅二百五十六；定时六十四；并发请求三十二；事件源八；每类事列默认一千零二十四（可调至六万五千五百三十六）。
- **同步之断须预先声明**：止默认与止传播惟能订阅时书于策略；欲依运行之状而变，当撤而重订，或用键律之“仅当属性”。程序之点击节点经页上诸订阅：回放己所拦之点，须先撤订阅，再点，而后重订。
- **勿于接口目录根下增 `.md`**：接口检查器以接口目录根下所有语言之文摘要写入每适配之宿主提供簿；增之则诸应用之装载包核对尽败。工作文档置于 `文档/`。
