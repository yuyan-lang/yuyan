# 统一正则后端迁移

二〇二六年九月九日。默认 native，经统一正则生 C，以 clang 成器，根存影栈；llvm、shadow 皆其别名。wasmgc 同取统一正则，wasm、wasmgc-anf 皆其别名。旧 LLVM/WASI 手栈生码、续延传递变换与机器栈准备皆去，wasi-sdk 不复受。

前端默认分依赖、解析、检查擦除、优化、闭包诸阶，依序择就绪者先行；其后合卷构正则而生码。combined 留以对照。昔日速率见[合并与拆分](../性能研究/前端调度/合并与拆分.文言.md)，今验证不另称测时。

原生默认 O3 与 LTO；不优化则 O0、调试库。双种子各载 C 与运行时，弃旧入口之链接。运行时留旧种 ABI，以续引导，非复设旧后端。纯正则查看诸阶尚存，不参生码；循环与原语效果诸限亦如前。

二级生三级，三级生四级，末两器字节同，摘要为 `7a1772bbf77494ffcceef8693e0c5084757fb33adadb77d65d48a45fcdc0483a`，并行类型检查亦过。旧 stable 初举仍报文件夹未找到，重行诊断亦然；乃以可信现器经豫构备二级，不以初举之败冒成功。

WasmGC 以 V8 自举亦过，与原生所生同串行目标字节同，摘要为 `152a254d358978cd8a262ef3179ba6ab5ee6c6b3fc10608ee3a988a361ce86b2`。双种 C 包自其脚本成器，移种于仓根，可编 llvm 别名之不优化目标；调试与优化产物皆过一 MiB 堆之根保活、尾递归与异常试。种未移而直用于导出子目录，则头文件定位败；依自述移于仓根乃通。

移植种重制调度试，动态优先、同级次序、并发上限及败后收拢皆过。
