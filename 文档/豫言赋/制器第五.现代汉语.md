# 制器第五·现代汉语译文

[文言原文](制器第五.md)

## 本章导读

程序中的数据不只有数字和字符串。书籍、人物、树、成功和失败都有自己的结构。如果把它们都表示成零散的普通值，程序就无法准确区分哪些形状合法。豫言可以用 `立` 创建新类型，再用构造器列出这种类型允许的不同形状。

## 自定义类型

先声明类型本身：

```yuyan
「来客」立「元类型」也。
```

然后声明构造器：

```yuyan
「无客」立「来客」也。
「有客」立化「字符串」而「来客」也。
```

`「无客」` 是不携带数据的 `「来客」` 值。`「有客」` 则是一个函数：它接收字符串并构造一个 `「来客」`。所以 `「有客」于『子衿』` 的类型是 `「来客」`。

完整例程使用 `鉴` 处理两种形状：

```yuyan
寻观「标准库」之书。

「来客」立「元类型」也。
「无客」立「来客」也。
「有客」立化「字符串」而「来客」也。

「致辞」乃化「来客」而「字符串」也。
「致辞」者会「客」而
    鉴「客」而
        有「无客」则『虚席以待。』
        或有（「有客」于「姓名」）则
            「字符串拼接」于『有朋自远方来：』于「姓名」也。

「打印行」于（「致辞」于（「有客」于『子衿』））。
```

输出为：

```text
有朋自远方来：子衿
```

配套源码见[制器。豫](示例/制器。豫)。下一篇会详细解释模式匹配。

## 新类型与类型别名

`立` 创建真正的新类型；`即` 只为现有类型建立别名：

```yuyan
「计数」即「整数」也。
```

`「计数」` 与 `「整数」` 在类型检查时是同一个类型。`「来客」` 则是独立类型，不能直接拿字符串冒充。需要严格限制合法数据形状时，应使用 `立` 和构造器；只想缩短一个较长的类型名称时，可以使用 `即`。
