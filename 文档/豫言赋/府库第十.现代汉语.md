# 府库第十·现代汉语译文

[文言原文](府库第十.md)

## 本章导读

大型程序不可能把所有定义放在一个文件中，也没有必要重复实现前人已经完成的功能。模块把定义组织进不同文件和目录，并控制哪些名称进入当前作用域。

## 导入、打开与导出

三个基本动作是：

- `寻`：导入模块并保留模块名称。
- `观`：打开模块，使其中的名称可以直接使用。
- `诵`：把模块内容继续导出给下游模块。

它们可以组合为 `寻观`、`寻诵`、`观诵` 和 `寻观诵`。最常见的初学写法是：

```yuyan
寻观「标准库」之书。
```

大型程序如果担心名称冲突，可以只导入特定模块，再用 `之` 投影成员：

```yuyan
寻「标准库」之「输入输出」之「笔」之书。
寻「标准库」之「数据结构」之「整数操作」之书。

「笔」之「打印行」于
    （「整数操作」之「整数表示」于
        （「整数操作」之「乘」于「六」于「七」））。
```

输出为 `42`。配套源码见[府库。豫](示例/府库。豫)。

## 创建自己的模块

假设目录中有 `示例。包。豫`，声明 `「依赖」者「列」【『标准库』】也。`，并有同目录模块 `礼数。豫`：

```yuyan
寻观「标准库」之书。

「加倍」乃化「整数」而「整数」也。
「加倍」者会「数」而「乘」于「数」于「二」也。
```

另一个文件可以导入它并保留模块名称：

```yuyan
寻观「标准库」之书。
寻「示例」之「礼数」之书。

「打印行」于（「整数表示」于（「礼数」之「加倍」于「二一」））。
```

第一段是包名，其余段对应包根目录内的文件路径；即使是同包模块，也要显式写包名。包只能导入自身及声明的直接依赖，不能穿过子包边界。标准库包位于 `藏书阁/标准库`。构建方法见[仓库包构建](../仓库包构建.汉语.md)。一个模块应该围绕清楚的职责组织，而不应只为缩短文件而随意拆分。

## 是否打开模块

模块名称少而清楚，或者它本来就是当前文件的基础词汇时，可以打开。两个模块可能导出同名函数、需要标明函数来源，或者当前文件只使用大型 API 的少量成员时，保留模块前缀会更清楚。

## 练习

新建 `圆术。豫`，再从另一个文件分别使用“导入后投影”和“导入并打开”两种方式调用它。比较哪种写法更容易看出名称来源。
