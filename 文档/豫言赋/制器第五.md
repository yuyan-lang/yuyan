# 制器第五

[今译](制器第五.现代汉语.md)

## 赋曰

工欲象物，必先制器。或铸一鼎而有三足，或开一匣而纳百珍；器定其疆，形别其用。程序所见，亦非独数与辞：书有卷帙，人有姓名，树有枝叶，事有成败。若尽以散值记之，则同异无纪，取舍无门。故立其类型以总名，立其构造以分形；无所载者，独标一象；有所载者，挟值而来。

于是 `立` 字一出，先辟元类型之域；继立诸构造器，如陶范既陈，注物成形。构造器非注释之号，乃真函数也：无参者自成一值，有参者纳其所载而返新器。器既成，后文但持其值，不得混入异类；类型守其疆，构造明其形。

## 解章

欲自制一代数数据之类，先立其类型：

```yuyan
「来客」立「元类型」也。
```

复立其诸形：

```yuyan
「无客」立「来客」也。
「有客」立化「字符串」而「来客」也。
```

`「无客」` 者，不载物而自为来客之一形也。`「有客」` 者，实一术也；受字符串而构来客。故 `「有客」于『子衿』` 之类为 `「来客」`。

全篇以 `鉴` 分其二形：

```yuyan
寻观「标准库」之书。

「来客」立「元类型」也。
「无客」立「来客」也。
「有客」立化「字符串」而「来客」也。

「致辞」乃化「来客」而「字符串」也。
「致辞」者会「客」而
    鉴「客」而
        有「无客」则『虚席以待。』
        或有（「有客」于「姓名」）则
            「字符串拼接」于『有朋自远方来：』于「姓名」也。

「打印行」于（「致辞」于（「有客」于『子衿』））。
```

其出曰：

```text
有朋自远方来：子衿
```

同例见[制器。豫](示例/制器。豫)。至于鉴形之细，具于次篇。

## 新类与别名

`立` 者，辟一新类也；`即` 者，但为旧类更名也。例曰：

```yuyan
「计数」即「整数」也。
```

`「计数」` 与 `「整数」`，验类之时同归一体。`「来客」` 则为独立新类，字符串不得冒之。概念自有合法诸形者，宜以 `立` 与构造器制之；长类但欲约其名者，宜以 `即` 别号之。

构造器亦可受多参，如树之枝，可纳左树、所值、右树。豫言以相续之函数类型表多参，故制器之法，仍不出函数一途。

## 试策

自立 `「节气」`，置 `「春」`、`「夏」`、`「秋」`、`「冬」` 四无参构造器；复作一术，以四者各化一辞。故漏一形，试思有值至而无枝可入，将何以处之。
