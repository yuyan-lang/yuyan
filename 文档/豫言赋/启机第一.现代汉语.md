# 启机第一·现代汉语译文

[文言原文](启机第一.md)

## 本章导读

计算机放在桌面上时只是沉默的机器；只有得到准确的指令，它才能快速而持续地工作。程序负责表达人的意图，编译器负责把这种表达转换成机器能够执行的形式。豫言使用中文命名，以函数组织计算，并通过类型检查保持程序各部分的一致。

本章先完成最小的一步：导入标准库，调用打印函数，让第一个豫言程序发出声音。

## 编写并运行

豫言源文件通常以 `.yuyan` 或 `。豫` 结尾。编译器会依次解析语法、解析名称、检查类型，然后生成可执行程序。如果还没有 `yy_bs_stable`，请先按照[快速开始](../快速开始.md)构建它。

新建 `问候。豫`：

```yuyan
寻观「标准库」之书。

「打印行」于『问天地好在，豫言初鸣。』。
```

`寻观` 同时完成两件事：`寻` 导入模块，`观` 打开模块。打开标准库后，就可以直接使用其中的 `「打印行」`。`于` 表示函数调用，左边是函数，右边是参数；`『』` 中是字符串。

在仓库根目录运行：

```sh
./yy_bs_stable 问候。豫
```

输出为：

```text
问天地好在，豫言初鸣。
```

如果只检查源码而不运行副作用：

```sh
./yy_bs_stable 问候。豫 --type-check-only
```

配套源码见[启机。豫](示例/启机。豫)。

## 声明边界

一个豫言文件由若干声明组成，中文句号 `。` 用来分隔声明。换行和缩进主要帮助人阅读，不能代替句号。因此下面两条声明即使放在同一行，含义仍然相同：

```yuyan
寻观「标准库」之书。「打印行」于『问天地好在，豫言初鸣。』。
```

不过，代码和文章一样，应当优先保持清楚。结构复杂时，应该用换行表现层次，用缩进说明从属关系。

## 练习

修改字符串后重新运行。然后故意删除最后一个中文句号，观察编译器如何报告未完成的声明。这样可以区分“源码能够解析”和“程序能够运行”这两个阶段。
