## 本章导读

字符串保存一组字符，可以表示短名称，也可以表示长篇文本。字符串能够拆分、拼接、搜索和输出。纯函数只根据输入决定输出；打印、读取等函数还会影响程序外部，因此执行次序也成为程序含义的一部分。

## 字符串与打印

字符串字面量写在 `『』` 中。标准库的 `「字符串拼接」` 接收两个字符串并返回一个新字符串：

```yuyan
「字符串拼接」于『幸会，』于『豫客』
```

`「打印行」` 的类型大致是：

```yuyan
化「字符串」而「有」
```

`「有」` 是单元类型，`「元」` 是它唯一有意义的值。打印函数的返回值不携带计算结果；调用它的目的，是在标准输出中产生一行文字。

完整例程：

```yuyan
寻观「标准库」之书。

「问候」乃化「字符串」而「字符串」也。
「问候」者会「姓名」而
    「字符串拼接」于『幸会，』于「姓名」也。

（「打印行」于（「问候」于『豫客』）；
 「打印行」于『愿与君共究函数之道。』）。
```

输出为：

```text
幸会，豫客
愿与君共究函数之道。
```

配套源码见[弦歌。豫](示例/弦歌。豫)。

## 顺序执行与纯计算

`甲；乙` 先求值甲，再求值乙，并把乙的结果作为整个表达式的结果。它适合串接打印、写文件和修改引用等有外部效果的计算。

如果两个表达式都是纯计算，通常应该通过函数调用和局部绑定表达数据依赖：

```yuyan
虑「总数」者「加」于「甲」于「乙」而
    「整数表示」于「总数」
```

这里的“先加后表示”由数据依赖自然确定，不需要 `；`。

标准输入可以通过 `「尝试读取标准输入行」` 等函数取得。读取可能遇到输入结束，所以结果同时包含字符串和表示是否成功的爻值。与外部环境交互时，应当同时考虑失败和执行次序。

## 练习

定义 `「落款」`，把姓名与 `『谨上』` 拼接。先打印正文，再打印落款；随后交换 `；` 两边，观察输出次序如何变化。
