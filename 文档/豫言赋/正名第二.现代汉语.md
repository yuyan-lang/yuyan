# 正名第二·现代汉语译文

[文言原文](正名第二.md)

## 本章导读

程序需要用名称指向数据，也需要用类型说明数据可以怎样使用。名称像前后相合的凭证，类型像阻止不同事物混杂的边界。豫言通常先用 `乃` 声明名称的类型，再用 `者` 给出具体定义。

## 声明与定义

```yuyan
「年岁」乃「整数」也。
「年岁」者「二零二六」也。
```

第一行说明 `「年岁」` 是整数，第二行给它具体的值。`乃` 后面是类型，`者` 后面是表达式，`也` 结束一条声明。

字符串写在 `『』` 中：

```yuyan
「篇名」乃「字符串」也。
「篇名」者『豫言赋』也。
```

数字字面量虽然也写在 `「」` 中，却会在名称解析前被识别。汉字数字按十进制数位连续书写：`「一三」` 是十三，`「二零二六」` 是二千零二十六。古典数词 `「十三」` 会被当成普通名称，而不是数字。

完整例程如下：

```yuyan
寻观「标准库」之书。

「年岁」乃「整数」也。
「年岁」者「二零二六」也。

「篇名」乃「字符串」也。
「篇名」者『豫言赋』也。

「打印行」于（「字符串拼接」于「篇名」于
    （「字符串拼接」于『，纪年：』于（「整数表示」于「年岁」）））。
```

输出为：

```text
豫言赋，纪年：2026
```

## 四种写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `「名字」` | 标识符 | `「年岁」` |
| `『文字』` | 字符串 | `『豫言赋』` |
| `「一二三」` | 整数一百二十三 | `「加」于「一二三」于「一」` |
| `「：说明：」` | 注释 | `「：此处不运行：」` |

普通定义更接近不可变的“绑定”，并不表示一个可以随时改写的盒子。需要可变状态时，应使用第十二篇介绍的引用。

## 练习

把 `「年岁」` 的类型改成 `「字符串」`，仍然给它整数值，再运行类型检查。编译器会拒绝这个名实不符的定义。
