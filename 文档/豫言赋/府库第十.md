# 府库第十

[今译](府库第十.现代汉语.md)

## 赋曰

一室之藏，简牍有限；天下之书，府库相联。若百工皆自炼铁、伐木、制墨，而后始作一器，则岁月先穷，功业未起。故前人之术，分卷而著；后人之用，按名而求。门有层次，卷有署号；欲但执其书，则 `寻` 之；欲陈其名于案，则 `观` 之；欲使后来者由我而得，则 `诵` 之。

然尽开群库，异卷同名，宾主或乱。故有时不 `观`，但保模块之号；用时循 `之` 而取，如入府、过廊、启阁、展卷。路径虽长，来处昭然。小篇可开以求便，大业宜分以守界；或显或藏，视其规模而制宜。

## 解章

模块者，分诸定义于异文件、异目录，而统其名称之界也。其基本之事有三：`寻` 者导入而存模块之名，`观` 者开之而使其中诸名可径用，`诵` 者复传其内容于后来之模块。

三者可相合，曰 `寻观`、`寻诵`、`观诵`、`寻观诵`。初学最常书：

```yuyan
寻观「标准库」之书。
```

大篇恐诸名相冲者，但寻一卷而以 `之` 取其成员：

```yuyan
寻「标准库」之「输入输出」之「笔」之书。
寻「标准库」之「数据结构」之「整数操作」之书。

「笔」之「打印行」于
    （「整数操作」之「整数表示」于
        （「整数操作」之「乘」于「六」于「七」））。
```

其出四十二。同例见[府库。豫](示例/府库。豫)。

## 自著一卷

若同目录有 `礼数。豫`，其文曰：

```yuyan
寻观「标准库」之书。

「加倍」乃化「整数」而「整数」也。
「加倍」者会「数」而「乘」于「数」于「二」也。
```

他篇可寻之而不观，以存其卷名：

```yuyan
寻观「标准库」之书。
寻「礼数」之书。

「打印行」于（「整数表示」于（「礼数」之「加倍」于「二一」））。
```

文件之目录，因成模块之路。标准库藏于仓库之 `藏书阁`；自有模块，则由源文件之结构与编译器所设寻路而得。分卷当各主一义，不可但为缩篇而漫裂之。

## 开与不开

模块之名少而明，或本为通篇之基础辞者，宜观之。二库或有同名、读者须知术之所自、库大而篇中但取少数者，宜留其前缀。模块之界，亦协作之界也；名明、所赖单向之诸卷，较一卷包举万端者易验、易改、易传。

## 试策

新作 `圆术。豫`，著一整数之术；复于他篇，一以“寻而投影”，一以“寻观而径用”召之。两文相较，察何者更能显其来处。
