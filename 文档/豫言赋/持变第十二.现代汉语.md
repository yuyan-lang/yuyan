# 持变第十二·现代汉语译文

[文言原文](持变第十二.md)

## 本章导读

程序不应假设每件事都会成功：搜索可能没有结果，输入可能结束，除数可能为零。预期内的缺失可以用可选值明确表达；无法在当前层处理的严重失败可以使用异常；确实需要随时间变化的共享状态时，则可以使用引用。

## 可选值

标准库的可选值类型是 `「或可有」于「甲」`，有两个构造器：

- `「可有」于「值」`：成功取得一个值。
- `「可无」`：没有值。

安全整数除法可以把除数为零表示为 `「可无」`：

```yuyan
「安除」乃化「整数」而化「整数」而（「或可有」于「整数」）也。
「安除」者会「被除数」而会「除数」而
    若「等」于「除数」于「零」
    则「可无」
    否则「可有」于（「除以」于「被除数」于「除数」）也。
```

完整例程：

```yuyan
寻观「标准库」之书。

「安除」乃化「整数」而化「整数」而（「或可有」于「整数」）也。
「安除」者会「被除数」而会「除数」而
    若「等」于「除数」于「零」
    则「可无」
    否则「可有」于（「除以」于「被除数」于「除数」）也。

「打印可选整数」乃化（「或可有」于「整数」）而「有」也。
「打印可选整数」者会「可」而
    「打印行」于（「可选值表示」授以「整数」于「整数表示」于「可」）也。

「打印可选整数」于（「安除」于「八」于「二」）。
「打印可选整数」于（「安除」于「八」于「零」）。
```

输出为：

```text
可有（4）
可无
```

配套源码见[持变。豫](示例/持变。豫)。真实程序通常会用 `鉴` 分别处理两种形状。

## 异常

调用契约被破坏，而当前层无法合理恢复时，可以使用：

```yuyan
「发生事故」于『除数不得为零』
```

标准库也提供 `「尝试运行」`，接收待执行函数和异常处理函数。异常可以跨越多层调用，使用方便，但也会隐藏普通返回路径。像“未找到”“输入结束”“解析失败”这样的预期情况，通常更适合使用可选值或专门的结果类型。

## 引用

普通绑定不会随时间改写。需要可变状态时，可以建立引用：

```yuyan
「匣」乃「引用类」于「整数」也。
「匣」者「新引用」授以「整数」于「零」也。

「写引用」授以「整数」于「匣」于「一」。
「读引用」授以「整数」于「匣」
```

引用会让同一名称在不同时刻读出不同值，因此应限制在明确边界内。能够通过参数和返回值传递状态时，纯函数通常更容易测试和推理。

## 练习

为 `「安除」` 定义 `「取零为默认」`：有结果时返回结果，没有结果时返回零。然后思考：这样会不会混淆“真正的商为零”和“除法失败”？
