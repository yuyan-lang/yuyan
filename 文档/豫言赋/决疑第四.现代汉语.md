# 决疑第四·现代汉语译文

[文言原文](决疑第四.md)

## 本章导读

程序经常需要根据条件选择不同路径。豫言用 `「爻」` 表示布尔类型，`「阳」` 和 `「阴」` 分别表示真与假。比较函数产生爻值，`若……则……否则……` 根据这个值选择一个分支。

## 条件表达式

整数比较函数包括 `「等」`、`「大于」` 和 `「小于」`。条件表达式写成：

```yuyan
若「条件」则「真值」否则「假值」
```

条件表达式本身会返回值，因此两个分支都必须产生与上下文相容的类型。以下函数返回两个整数中较大的一个：

```yuyan
「较大者」乃化「整数」而化「整数」而「整数」也。
「较大者」者会「甲」而会「乙」而
    若「大于」于「甲」于「乙」
    则「甲」
    否则「乙」也。
```

完整例程：

```yuyan
寻观「标准库」之书。

「较大者」乃化「整数」而化「整数」而「整数」也。
「较大者」者会「甲」而会「乙」而
    若「大于」于「甲」于「乙」
    则「甲」
    否则「乙」也。

「打印行」于（「整数表示」于（「较大者」于「八」于「一三」））。
```

输出为 `13`。配套源码见[决疑。豫](示例/决疑。豫)。

## 组合布尔值

标准库中常用的三个爻值函数是：

```yuyan
「且」于「甲爻」于「乙爻」
「或者」于「甲爻」于「乙爻」
「非」于「甲爻」
```

例如，判断一个数是否严格位于一与十之间：

```yuyan
「且」于（「大于」于「数」于「一」）于（「小于」于「数」于「一零」）
```

条件可以嵌套，但嵌套太深会变得难读。如果分支取决于数据的构造形状，例如一个值可能为空、也可能带有数据，就应该使用第六篇介绍的模式匹配。

## 练习

定义 `「绝对值」`：输入非负时返回自身，否则用 `「减」于「零」于「数」` 取反。检查两个分支是否都返回整数。
