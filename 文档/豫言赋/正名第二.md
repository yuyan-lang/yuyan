# 正名第二

[今译](正名第二.现代汉语.md)

## 赋曰

天地繁而可纪者，以其有名；万物殊而可用者，以其有类。山川列号，草木分科；鼎有款识，剑有干将。程序之中亦然：无名，则后文无所指；无类，则诸术无所施。名若符节，前后相合；类若关津，异物不杂。故先书其所是，曰 `乃`；继书其所有，曰 `者`。声明悬衡于前，定义实载于后；名实既副，然后可行。

豫言之名，以双角护之；豫言之辞，以方括藏之。`「山」` 者，名也；`『山』` 者，字符串也。一画之差，名实遂判。数字虽为常量，亦寓 `「」` 之中；注释虽入正文，乃以 `「：` 与 `：」` 为藩，不参与运行。其貌相近，其职各殊，此正名之始也。

## 解章

豫言之定义，常先悬其类型，后实其所值：

```yuyan
「年岁」乃「整数」也。
「年岁」者「二零二六」也。
```

首句言 `「年岁」` 为整数；次句命之以值。`乃` 后列其类，`者` 后陈其式，`也` 收一义而成一声明。

字符串以 `『』` 藏之：

```yuyan
「篇名」乃「字符串」也。
「篇名」者『豫言赋』也。
```

数字字面量，貌亦在 `「」` 中，然先于名称而辨。汉字之数，当逐位连书：`「一三」` 为十三，`「二零二六」` 为二千零二十六。若古法书 `「十三」`，则编译器视之为常名，不视为数也。

合而书之：

```yuyan
寻观「标准库」之书。

「年岁」乃「整数」也。
「年岁」者「二零二六」也。

「篇名」乃「字符串」也。
「篇名」者『豫言赋』也。

「打印行」于（「字符串拼接」于「篇名」于
    （「字符串拼接」于『，纪年：』于（「整数表示」于「年岁」）））。
```

其出曰：

```text
豫言赋，纪年：2026
```

同例见[正名。豫](示例/正名。豫)。

## 四辨

凡书代码，当辨四者：

| 书法 | 其义 | 其例 |
| --- | --- | --- |
| `「名字」` | 名也 | `「年岁」` |
| `『文字』` | 字符串也 | `『豫言赋』` |
| `「一二三」` | 数一百二十三也 | `「加」于「一二三」于「一」` |
| `「：说明：」` | 注也 | `「：此处不运行：」` |

世俗所谓变量，于纯函数之域，多实为绑定：一名在其域中，恒指一值，非可随意改易之匣。欲持可变之态，当用第十二篇之引用，不可以普通定义混之。

## 试策

易 `「年岁」` 之声明为 `「字符串」`，而仍赋以整数，复验其类。编译器必拒之。盖斗不可以量布，尺不可以称粟；名实不副，强合则乱。
