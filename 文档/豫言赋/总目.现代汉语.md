## 前言

人类先后用结绳、文字、竹帛和金石记录思想。进入计算机时代以后，我们要让机器按照人的意图工作，同样需要一套准确的表达方式。西方语言能够描述程序，中文也可以探索自己的编程表达。豫言以中文命名，以函数组织计算，以类型约束接口：`化` 描述类型变换，`而` 连接输入与输出，`鉴` 分析数据形状，`承` 引入多态类型。

本教程以函数为主线、类型为结构，先介绍值与类型，再学习函数、参数、构造器、模式匹配、递归和多态，最后讨论模块、副作用、可选值、异常及组合式设计。所有完整示例都已经通过仓库中的稳定自举编译器进行类型检查和实际运行。

全书采用十三篇的渐进结构，写作体例受到[《文言阴符》](https://github.com/wenyan-lang/book)启发；章节安排、解释、比喻及豫言示例则根据豫言当前的语言设计重新编写。精确语法以[语言规范](../语言规范.md)为准，构建步骤见[快速开始](../快速开始.md)。

## 阅读方法

初学者适合按照篇次阅读；已经熟悉函数式编程的读者，可以从第五篇开始，重点了解豫言的构造器、模式匹配和隐式参数。每一篇都包含完整示例，可以在仓库根目录直接运行：

```sh
./yy_bs_stable 文档/豫言赋/示例/启机。豫
```

如果只想检查类型而不运行程序：

```sh
./yy_bs_stable 文档/豫言赋/示例/启机。豫 --type-check-only
```

## 基本约定

1. 内建关键字不加引号，例如 `乃`、`者`、`会`、`而`、`于`、`鉴`；自定义名称使用 `「」`。
2. 字符串使用 `『』`；数字字面量也写在 `「」` 中。
3. 声明之间用中文句号 `。` 分隔；需要明确分组时使用全角括号 `（）`。
4. 教程为了便于理解，会较多地使用显式写法；熟悉语言后可以酌情使用简写。

类型规则并不是对作者的束缚，而是帮助程序保持一致的工具。先守住接口边界，才能放心组合和扩展程序。
