# 鉴形第六·现代汉语译文

[文言原文](鉴形第六.md)

## 本章导读

同一类型可能有不同构造形状，一个组合值也可能包含多个部分。模式匹配像一面镜子：它既能判断值具有哪种形状，也能同时取出其中携带的数据。

## 模式匹配

基本形式是：

```yuyan
鉴「待察值」而
    有「第一模式」则「第一结果」
    或有「第二模式」则「第二结果」
```

条件表达式只检查爻值；模式匹配检查构造器。例如：

```yuyan
或有（「有客」于「姓名」）则「姓名」
```

这条模式既确认输入由 `「有客」` 构造，也把内部字符串绑定为 `「姓名」`。

## 对子

对子值用 `与` 构造，对子类型用 `合` 表示：

```yuyan
「五」与「八」
「整数」合「整数」
```

完整例程：

```yuyan
寻观「标准库」之书。

「对子求和」乃化（「整数」合「整数」）而「整数」也。
「对子求和」者会「对子」而
    鉴「对子」而
        有（「左」与「右」）则「加」于「左」于「右」也。

「打印行」于（「整数表示」于（「对子求和」于（「五」与「八」）））。
```

输出为 `13`。配套源码见[鉴形。豫](示例/鉴形。豫)。

对子也可以按序号投影：

```yuyan
「对子」中「零」
「对子」中「一」
```

只取一个已知位置时，投影比较简洁；需要同时命名多个部分或区分构造器时，模式匹配更清楚。

## 剩余分支

一个类型有多个构造器时，模式通常应该覆盖所有可能。确实想统一处理剩余形状时，可以用普通绑定接住它们：

```yuyan
或有「其他」则「默认值」
```

不过，如果将来增加新构造器时理应有新行为，显式列出每个分支会更安全。

## 练习

定义 `「交换」`，把 `甲合乙` 的对子变成 `乙合甲`。先用模式取得左右两个值，再用 `与` 反序构造。
