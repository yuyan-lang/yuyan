# 启机第一

[今译](启机第一.现代汉语.md)

## 赋曰

粤有机焉，伏处案隅，缄默若石；既受人命，迅疾如风。加减千万而不疲，往复终日而无怨。然其所短者，不知人欲；其所待者，惟在明文。辞差一字，则南辕而北辙；义定一端，则百器如臂指。故程序者，人意之契；编译者，古今之驿。上承作者之思，下译机器之令；析其名，验其类，排其序，乃使静者动、默者鸣。

夫豫言之为言也，以中文立名，以函数为经，以类型为纬。观其一行，或只问候；穷其所至，可自举编译，可驱网络，可成百工。初登高台，不必先测云汉；姑击一石，以闻其声。

## 解章

程序者，授机器以确令也。豫言之源，常以 `.yuyan` 或 `。豫` 终其名。编译之器，先析其辞，次辨其名，复验其类，终乃生可行之物。今但行三事：寻标准之库，取打印之术，发问候之声。

未得 `yy_bs_stable` 者，宜先循[快速开始](../快速开始.文言.md)而构之。新作 `问候。豫`，书曰：

```yuyan
寻观「标准库」之书。

「打印行」于『问天地好在，豫言初鸣。』。
```

`寻观` 者，合 `寻`、`观` 二事也。寻者，引其库；观者，开其名。既观标准库，则 `「打印行」` 可径用之。`于` 者，施术于参也；左为术，右为所受。`『』` 所括者，字符串也。

立于仓库之根，行曰：

```sh
./yy_bs_stable 问候。豫
```

其出曰：

```text
问天地好在，豫言初鸣。
```

但欲验其类，不欲发其效者，行曰：

```sh
./yy_bs_stable 问候。豫 --type-check-only
```

本书同例，见[启机。豫](示例/启机。豫)。

## 辨微

一篇之内，声明若干，以中文句号 `。` 隔之。换行、缩进者，助人观文；句号者，实断其界。故下文虽并为一行，其义无异：

```yuyan
寻观「标准库」之书。「打印行」于『问天地好在，豫言初鸣。』。
```

然程序亦文章也。辞短者可并，义繁者宜分；以换行示脉，以缩进明属，使人一览而知其宾主。

## 试策

易其字符串而复行之。又可故去末一中文句号，观编译器何以告其声明未竟。正反相参，则解析与运行之二门可辨矣。

古之鼓瑟，先调一弦；今之编程，先通一行。一行既通，百篇可继。
