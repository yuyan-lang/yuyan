# 列阵第七·现代汉语译文

[文言原文](列阵第七.md)

## 本章导读

一个值只能表示一个对象，一列值则可以保存任意数量的同类元素。豫言标准库的列只有两种形状：空列 `「罄」`，以及由一个头元素和一条尾列组成的 `「缀」`。处理列时，也只需要分别处理这两种形状。

## 构造列表

`「缀」于「头」于「尾」` 在旧列前加入一个元素。因此 `[2, 3, 5]` 可以显式写成：

```yuyan
「缀」于「二」于（「缀」于「三」于（「缀」于「五」于「罄」））
```

它的类型是 `「列」于「整数」`。`「列」` 是类型构造器，接收元素类型后形成具体的列类型。整数列和字符串列是不同类型，不能混放元素。

求和函数按照列的结构递归：

```yuyan
「列求和」乃化（「列」于「整数」）而「整数」也。
「列求和」者会「数列」而
    鉴「数列」而
        有「罄」则「零」
        或有（「缀」于「头」于「尾」）则
            「加」于「头」于（「列求和」于「尾」）也。
```

完整例程：

```yuyan
寻观「标准库」之书。

「列求和」乃化（「列」于「整数」）而「整数」也。
「列求和」者会「数列」而
    鉴「数列」而
        有「罄」则「零」
        或有（「缀」于「头」于「尾」）则
            「加」于「头」于（「列求和」于「尾」）也。

「数列」乃「列」于「整数」也。
「数列」者「缀」于「二」于
    （「缀」于「三」于（「缀」于「五」于「罄」））也。

「打印行」于（「整数表示」于（「列求和」于「数列」））。
```

输出为 `10`。配套源码见[列阵。豫](示例/列阵。豫)。

## 函数式循环

命令式语言常用可变计数器循环，函数式语言则常按数据结构递归。`「列求和」` 每次处理一个头元素，把更短的尾列交给自身，直到遇到空列。

标准库已经提供 `「长度」`、`「态射」`、`「滤」`、`「从左折叠」` 和 `「从右折叠」` 等函数。初学者仍然应该亲自写一次结构递归，因为这些高阶函数正是从重复出现的递归结构中抽象出来的。

## 练习

仿照 `「列求和」` 写 `「列长度」`：空列长度为零，非空列长度为一加尾列长度。再写 `「列乘积」`，比较两个函数中相同的结构和变化的部分。
