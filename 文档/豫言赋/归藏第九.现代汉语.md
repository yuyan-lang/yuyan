# 归藏第九·现代汉语译文

## 本章导读

递归函数会调用自身，但每次调用都应该让问题更接近终点。一个正确的递归通常包含基准情况和规模缩小步骤：基准情况负责停止，递归步骤负责把问题变小。

## 顶层递归

顶层递归函数需要先声明类型，使编译器在检查函数体时已经知道递归名称的类型。阶乘可以写成：

```yuyan
「阶乘」乃化「整数」而「整数」也。
「阶乘」者会「数」而
    若「等」于「数」于「零」
    则「一」
    否则「乘」于「数」于（「阶乘」于（「减」于「数」于「一」））也。
```

输入为零时返回一，这是基准情况；否则把问题转换成规模更小的 `数 - 1`。

完整例程：

```yuyan
寻观「标准库」之书。

「阶乘」乃化「整数」而「整数」也。
「阶乘」者会「数」而
    若「等」于「数」于「零」
    则「一」
    否则「乘」于「数」于（「阶乘」于（「减」于「数」于「一」））也。

「打印行」于（「整数表示」于（「阶乘」于「六」））。
```

输出为 `720`。配套源码见[归藏。豫](示例/归藏。豫)。

## 局部递归

只在一个表达式内部使用的递归函数，可以写成：

```yuyan
递归虑「求零」其化「整数」而「整数」者
    会「数」而
        若「等」于「数」于「零」
        则「零」
        否则「求零」于（「减」于「数」于「一」）
而
    「求零」于「三」
```

`其` 后面是递归值的类型，`者` 后面是定义，最后一个 `而` 后面是使用该值的表达式。局部递归可以捕获外层绑定，适合实现只服务于一个函数的辅助过程。

## 终止条件

类型正确不代表递归一定终止。编译器可以检查参数与结果类型，却不一定能证明每次调用都更接近基准情况。写递归时应该明确回答：基准输入是什么？每次调用缩小了什么？所有合法输入是否一定能到达基准情况？

例如，阶乘如果接收负数，就会不断远离零。因此还需要明确合法输入范围，或者在入口检查，或者设计一个只能表示非负数的类型。

## 练习

定义 `「幂」`：指数为零时返回一，否则返回底数乘以指数减一时的结果。然后再用局部递归改写。
