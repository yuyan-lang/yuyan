# 弦歌第十一

[今译](弦歌第十一.现代汉语.md)

## 赋曰

辞本无形，因字成章；弦各有声，比次成歌。字符串者，群字所居也。或短如名号，或长如典册；可断，可合，可寻，可示。合二辞者，如续断弦，前声既发，后韵相承。然值藏机内，人目未闻；必假笔墨之术，出之于屏，乃使沉思化为可见。

纯术只因所入而定所出，如镜照物，不改外境；打印之术则动屏幕，读取之术则候人言，是为效用。效用既有先后，不可乱其节拍，故以 `；` 连之。先声既毕，后声乃作；如钟鼓有序，宫商不杂。其结果虽只 `元`，其影响已留于世。

## 解章

字符串之实，以 `『』` 括之。标准库有 `「字符串拼接」`，受二字符串而返其合者：

```yuyan
「字符串拼接」于『幸会，』于『豫客』
```

`「打印行」` 之类，大略曰：

```yuyan
化「字符串」而「有」
```

`「有」` 者，单元之类也；`「元」` 者，其惟一有义之值也。打印所返不载算果，盖调用之意在使标准输出生一行辞耳。

全篇曰：

```yuyan
寻观「标准库」之书。

「问候」乃化「字符串」而「字符串」也。
「问候」者会「姓名」而
    「字符串拼接」于『幸会，』于「姓名」也。

（「打印行」于（「问候」于『豫客』）；
 「打印行」于『愿与君共究函数之道。』）。
```

其出曰：

```text
幸会，豫客
愿与君共究函数之道。
```

同例见[弦歌。豫](示例/弦歌。豫)。

## 顺序与纯算

`甲；乙` 者，先求甲，次求乙，而以乙之果为全式之果也。打印、写文件、改引用诸有效于外者，尤须以此定其先后。若二式皆纯算，则宜以函数调用或局部绑定表其值之所赖，不必强立时序。

例曰：

```yuyan
虑「总数」者「加」于「甲」于「乙」而
    「整数表示」于「总数」
```

先加后表示，自其值之所赖而定，无须 `；` 也。

标准输入可由 `「尝试读取标准输入行」` 等术取得。读取或逢输入已尽，故其果兼有字符串与成否之爻。凡与外境交接者，失败与时序皆当入其谋，不可恒以万事顺遂为断。

## 试策

作 `「落款」`，合姓名与 `『谨上』`；先打印正文，后打印落款。复易 `；` 左右之序，观其声何以倒置。由是可辨“所返之值同”与“外效之次同”，非一事也。
