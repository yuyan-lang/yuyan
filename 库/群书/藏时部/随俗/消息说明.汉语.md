# gettext 消息目录

`读取便携消息 文本` 读取 PO 字符串，`读取编译消息 字节串` 读取 MO 二进制，均返回消息目录。`查消息 目录 标识` 查询普通译文，未译项返回原标识。

`查上下文消息 目录 上下文 标识` 查询 msgctxt 对应条目。`查复数形消息 目录 上下文 单数 复数 形下标` 查询 msgstr[n] 对应译文，形下标从零起。调用者依据地区复数规则计算形下标。缺少译文时，零下标返回单数，其余下标返回复数。

`查数量复数消息 目录 地区 上下文 单数 复数 数量` 使用目录头 `Plural-Forms` 的 `nplurals` 和 `plural` 计算形下标，结果落在零至形数减一之间。`消息头字段` 读取目录头，`消息目录字符集` 读取 Content-Type 的 charset，默认 UTF-8。无有效复数头时调用本地化数据包的 CLDR 规则：英语 one 对应零，其余对应一；简繁中文、日文、韩文采用单形零。缺译时数量一返回原单数，其余返回原复数。

按数量查询先校验 nplurals，再校验实际连续译文形数；高位形下标保留无符号位模式，越界回退原文。缺头英语只有数量位模式等于一时采用 one，UINT64_MAX 的负载体采用 other。

表达式支持数量变量 n、十进制常数、括号、一元 `!`、`+`、`-`，乘除取余、加减、比较、`&&`、`||` 与 `?:`。正式目录头规则采用 GNU gettext 在 64 位 unsigned long 平台上的语义：数量和结果由豫言整数承载无符号位模式，加减乘以模 `2^64` 回绕，比较和除余采用无符号操作。负的豫言载体表示其对应的高位无符号数；`复数无符表示` 输出无符号十进制。十进制常数最大为 `18446744073709551615`。逻辑和条件分支惰性求值；未选分支检查语法，选中分支除零使规则回退到 CLDR 默认。nplurals 与形下标按无符号范围比较。表达式最多百万字节、百万解析步、万层嵌套。语义依据 [GNU gettext 官方复数求值源码](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-runtime/intl/eval-plural.h)。

PO 读取器支持上下文、复数条目、连续引文、多行标识与译文，以及 `\n`、`\t`、`\r`、`\b`、`\f`、`\v`、`\a`、引号、反斜线、八进制和十六进制转义。`\t` 生成字节 9。带 fuzzy 标志的条目保留为待译，查询返回原文。MO 读取器支持大小端、主修订零与一的普通表，次修订一及其后通过系统消息模块展开系统相关字符串表。普通表与展开后的原译字节对统一交给编码转换包严格解码，再拆上下文和复数形；未知系统宏略过整对。UTF-8 BOM、UTF-16/32 大小端 BOM 与目录头起始零字节排列引导头文本解码，ASCII 可读头采用 Latin1 引导字段识别，再依据 charset 严格解码。无效表、未知编码或非法字段返回空目录。

PO 输入字符串承载原文件字节。读取器先依据目录头 charset 严格解码完整源文，保护 GBK 等编码的字符边界；普通引文字符编码回源字符集，八进制与十六进制转义直接写字节。相邻引用与续行合并为完整字段后，字段按目录字符集严格解码，再构造上下文及复数形键。UTF-8 的 `\303\251` 得到 `é`，Latin1 的 `\351` 得到 `é`。同声明的相邻引用与行尾注释采用转义感知的引号扫描。无效控制序列、无效字段编码、零字节及 EOT 字段略过该项。八进制最多三位，十六进制扫描限额保持一亿位。顺序依据 [GNU PO 官方词法器](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-tools/src/read-po-lex.c)。

显式空 msgctxt 与无上下文分别保存。`查上下文消息` 的空字符串参数查询显式空上下文，`查消息` 查询无上下文。复数查询的空上下文参数沿用无上下文约定；空上下文复数查询消歧留待后续接口事项。

PO 词法归一支持同物理行多个声明和紧贴引号的字段名，引用及注释内容保持原文。查询以条目存在性和空译文判定回退，译文等于完整查询键时仍返回译文。系统消息字节对沿同一字符集解码、上下文构键和复数拆形路径进入目录。复数方括号序号周围的空格及制表符按词法空白归一，引文空白保持原文。

`读取编译消息带系统替换 数据 替换字典` 返回错误文和目录；替换字典为系统段名与原始字节串的列表。错误文为空表示读取成功。原 `读取编译消息` 入口使用空替换字典。扩展结果保留内部零字节，去除末尾终止零，随后采用目录头 charset。

格式依据 [GNU gettext PO 文件](https://www.gnu.org/software/gettext/manual/html_node/PO-Files.html) 与 [MO 文件](https://www.gnu.org/software/gettext/manual/html_node/MO-Files.html)。
