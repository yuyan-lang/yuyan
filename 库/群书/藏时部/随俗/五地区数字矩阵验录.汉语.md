# 五地区数字矩阵准备记录

2026 年 10 月 8 日，以已提交 yybs `1aca19050f4f39e5d7e69b9d08e9f29b87e39a0d` 为基线，只读审计当前数字、货币、复数实现。五地区拉丁数字快照的标准小数模式均为 `#,##0.###`，百分比模式均为 `#,##0%`，标准货币模式均为 `¤#,##0.00`；小数点为点号、分组为逗号、负号为连字符。现公开接口的整数、定点及最小单位货币输入约定与这些符号、分组及位置规则一致。

`测试/五地区数字。测试。豫` 使用公开函数为 zh-Hans、zh-Hant、en、ja、ko 各设置 27 项断言，共 135 项。边界含零、负数、三位分组、小数补零、百万分率正负半点及半点前一单位、TWD／USD 符号、零／三／四位货币、文字符号的不换行空格、普通币码回退与复数整数／可见小数位区别。全部 75 项 fractions 另按官方 `_digits` 逐项核对：47 项零位、20 项二位、6 项三位、2 项四位。预计共 210 项断言，实际成功计数由运行后的标准输出确定。

数据来源为本地化数据包保存的 Unicode CLDR JSON 48.0.0 官方快照：

| 检查维度 | 官方源 |
| --- | --- |
| 分组、小数、负号、百分号、标准数字／货币模式与 currencySpacing | cldr-numbers-full/main/zh-Hans、zh-Hant、en、ja、ko/numbers.json |
| USD、TWD 与普通符号，缺项使用币码 | 相同五地区 currencies.json；私表修正已在基线合入 |
| 货币位数全表 | cldr-core/supplemental/currencyData.json 的 currencyData.fractions._digits |
| 基数复数 | cldr-core/supplemental/plurals.json：en 的 one 为 i=1 且 v=0；zh、ja、ko 为 other |

官方仓库为 [Unicode CLDR JSON 48.0.0](https://github.com/unicode-org/cldr-json/tree/48.0.0/cldr-json)，快照来源及 Unicode License V3 见数据包双语《数据来源》。标准币间距取非符号且非分隔字符与数字相邻时插入 U+00A0；现金舍入、窄符号及其他编号系统留待后续选项。百万分率半点远离零取整数百分比，沿用既有公开约定。
