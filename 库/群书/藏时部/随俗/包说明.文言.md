# 本地化

此包为简繁英日韩地区书整数、定点小数、百分、货币、复数、日期时刻、列表及相对时间。整数三位一组；百分受整数百分值，比率受百万分率而取整百分；货币受最小单位整数，位从 CLDR 四十八之货币补充全表。列表之序不易。

公开诸术在默认导入诸篇。货币用五地区官定普通币符及最小单位位数，尽纳快照中异于币码之符；普通符缺则用币码，文字符依 currencySpacing 分隔，详见《货币符号》。日期时刻具 CLDR 四式，星期由调用者授周一至周日之一至七，时区之名亦由调用者授之；相对时间具年月季周日时分秒；英文复数分 one、other，中日韩皆 other。数据定于 CLDR 48.0.0，所出及许可见本地化数据包。

gettext PO/MO 读取在消息篇，具字集解码、上下文、复数诸形及 GNU 无符复数式之求值；系统消息表受调用者所授宏之字节。查消息，缺则返原文。默认导入兼含地区排序之篇；汉文拼音、笔画之剪裁，用 CLDR 四十八之 Unicode 十七根排序、组合类及规范分解数据。地区格式命令器、中文姓名排序之例已用此库。

四项格式之修，已于 pit-mac 过包检、类检及五十短验：基础格式十八、数字货币二十一、日期十一；诺驿与同客体硬原生皆以零退，三组标准输出逐字相同。日期之数据源码，标准输出曰“日期格式测试通过”。消息百五十六、排序七十一短断言，皆过同客体双后端；官方根全档验至原末行 206309。定姓名之性能入口，实求四万完整排序键、比较两万次。消息二口，各于诺驿父、原生父成百万隔离变异，每批万次；原生父以公共运行术启 Wasm 子程，子程行于诺驿。详见《格式修正双后端验录》《消息验证记录》及本地化数据《根模型》。后验之事：五地区全功能矩阵、Intl 对照、裸机运行、逐入分配与公共峰值观测、消息 domain 及空上下文复数查询之接口约定。

此包又有一路依 CLDR 数据表之通用术，遍二十要区（en、zh、zh-Hant、ja、ko、fr、de、es、pt、ru、ar、it、hi、tr、vi、id、th、nl、pl、uk）；其数据由 `应用/百工坊/地区数据生成` 取 CLDR 四十六之结森而生，置于同目之 `名。数据。豫`：

- 地区协商：按补全表补语言文字地域，按父地区与隐规求父与回退之链，按别名易其旧名，任意之标归于二十之一。
- 复数之规：析 CLDR 之语法，含 n、i、v、w、f、t、e 七操作数、取余、范围与逗列，基数序数皆具。
- 数字之式：小数、百分、货币与紧式短长；分组有首末二档；数系可别指 latn、arab、deva、thai；币按币位收其最小；紧式依复数而择形。
- 日历之式：公历之月、星期、纪元、上下与时段；日期、时与日期时各四档；骨架依可用之式而选；时区有偏移与地式之名，常用者又有本地之名。
- 相对之时：八单位之未过二式依类别取形，又及近二日之型与单位之名。
- 列表：与、或、单三类，二、首、中、末四式。
- 译名：常用语言与地区之本地名。

数据表以 `数据形制` 之条目构造，按键线性而索；二十之外归英文。生成之器惟读任务书所定之 CLDR 目，表可重行而生。日历之式又予 `排式分段`（按段还字段字、宽与其文，供捷思分段之出）与 `上下午文`（AM、PM 之名）；数字之紧式按键改用十之幂值（与表之 `紧/短/1000/…` 合），整数无组分符时次档取首。捷思之 `Intl` 已接此通用之口。后事：补全与别名之全表、紧式之 e 操作数、时区之夏令规则，俟后补之。
