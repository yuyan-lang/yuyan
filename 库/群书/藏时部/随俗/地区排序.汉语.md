# 地区排序

固定 CLDR 48 中文剪裁的官方快照、生成器、接口、测试、示例与性能程序已经执行验证。正式中文表包含拼音 44470 项、笔画 102037 项与规则 977 项；根表、组合类与规范分解固定于 Unicode 17。地区、规则、非连续收缩及规范分解共 71 项短断言通过 Node 与同客体硬原生；完整官方根核验运行到原文件末行 206309。分项来源、哈希与运行记录见本地化数据《根模型》《中文排序》。

中文排序使用 Unicode CLDR 48 官方 `common/collation/zh.xml`。豫言生成器提取 `PINYIN LONG` 与 `STROKE LONG` 两个自动生成段的全部 `<*` 单码点主序行，保存逐码点的先后次序。数据按每 256 个码点分桶，桶分派采用平衡分支。覆盖数量由生成器打印并记入数据说明。

`地区排序键 地区 方式 码点列` 生成整数排序键。地区以 `zh` 开头时，方式取 `拼音` 或 `笔画`。源码先消费最长中文规则，再用实际 CLDR48/UCA17 根匹配及十七版隐式权重处理其余输入，统一提取三层。其他地区使用相同的十七版根元素。输入先做同版 NFD。

`比较地区码点 地区 方式 甲码点列 乙码点列` 返回负一、零或一。`比较地区排序键 甲键 乙键` 比较预计算的键。`使用地区排序表 权重函数 码点列` 是调用者自定优先主序接口，正数先于默认主权，零使用 DUCET 最长匹配，弱层沿用完整 DUCET 元素；官方地区规则通过 `地区排序键` 调用。

`中文主序权重 方式 码点` 位于本地化数据包的中文排序模块，返回官方主序号，表外返回零。示例 `中文姓名排序。豫` 通过本地化的默认导入展示张三和李四在拼音、笔画下的顺序。性能程序使用八个固定姓名，拼音与笔画各运行一万轮，每轮计算两份完整三级键并比较一次，总计四万份键与两万次比较；实际校验输出在 Node 与同客体硬原生间逐字节相同。

默认入口已接实际 CLDR48／UCA17／UCD17 根闭包，沿用公开签名；自定表默认及弱层同样使用真实根。根桶和组合类来自同一生成物，隐式类型由固定十七版官方范围提供。拉丁前特殊组保留原序，Hani 接其后，笔画再重排 Bopo。来源、SHA、最小串验链见双语根模型说明。

生成器保存 `private-pinyin`、两种 LONG 内的 reset 及拼音段尾词组规则；规则目标、锚点与斜杠扩展先做同版 NFD，保留关系强度和定义序号，按定义时间引用更早规则。固定规则使用预留插入间隔。关系修改最后具足该强度的元素并截去其后的弱元素；十九项逐元素及固定令和、株式会社回归已在 Node 与同客体硬原生执行通过，原算法同一输入的失败记录见《固定关系末元》。通用任意规则的动态权重分配留待后续。

组合类阻挡和非连续收缩返回消费跨度与原序跳过点，保持三层元素次序；固定 LONG 的 FDD0 拉丁及盲文笔画索引已生成。十七版提供器与 NFD 已自动接入并执行核验。固定官方 XML 的导入与重排选项由生成器精确核对。后续规则范围为更广前缀上下文、大小写位及选项、通用动态插入分配与全层级一致性核对。

独立测试 `中文排序规则。测试。豫` 的 33 项断言覆盖空白、标点、符号、货币、数字、Hani、Bopo 与拉丁的相对位置，NFD 声调与大小写，官方三个词组 reset、三级别名、重复锚点插入与多字锚点展开，以及根数据的 `l·` 收缩。向量依据 [CLDR 特殊重置与展开规则](https://unicode.org/reports/tr35/tr35-collation.html#Special_Reset_Positions) 和 [ICU 文字重排说明](https://unicode-org.github.io/icu/userguide/collation/concepts/#script-reordering)；源码列出直接码点与明确预期，33 项已在同客体双后端执行通过。
