# 地区之序

定 CLDR 四十八中文剪裁之官档、生成器、接口、测试、示例及性能篇，已实核之。中文表具拼音 44470 项、笔画 102037 项、规则 977 项；根表、组合类、规范分解定于 Unicode 十七。地区、规则、非连续收缩、规范分解合七十一短断言，皆过诺节及同客体硬原生；官根全验行至原档末行 206309。来源、哈希、实录见本地化数据《根模型》《中文排序》。

中文排序取诸 Unicode CLDR 四十八版官定 `common/collation/zh.xml`。豫言生成器取 `PINYIN LONG`、`STROKE LONG` 两段所生之全部 `<*` 单码主序行，循其逐码之次第。每二百五十六码为一桶，以平衡分支择桶。所收之数由生成器印出，载于数据说明。

地区排序键成整数之键，中文先取最长本地则，余用四十八版官根及十七版隐式重，合元素而分三层；余地区用同一十七版根元素。入码先为同版 NFD。

`比较地区码点 地区 方式 甲码点列 乙码点列` 还负一、零、一。`比较地区排序键 甲键 乙键` 校已成之键。`使用地区排序表 权重函数 码点列` 为调用者自定优先主序之术，正重先于默认，零取 DUCET 最长匹配，弱层循完整元素；官定地区规则由地区排序键行之。

`中文主序权重 方式 码点` 在本地化数据包之中文排序篇，还官定主序号，表外还零。姓名示例循本地化之默认导入，以张三、李四示拼音、笔画之异序。性能篇取八定姓名，拼音、笔画各行万轮，每轮成二完整三级键、比较一次，合四万键、两万比较；诺节及同客体硬原生之校验输出逐字相同。

默认入口已接四十八版官根及 UCA、UCD 十七版闭包，公开签名如旧；自定表默认及弱层亦用官根。桶及组合类同一生成物，隐式取十七版官定范围。拉丁之前特殊组循旧序，Hani 接其后，笔画又重排 Bopo。来源、SHA、串验见根模型双语篇。

生成器存私拼音、两长式之重置及拼音篇末词组之则，目标锚点及斜杠所扩先为同版 NFD，存强度、定义之序，引用惟取先则。所定规则用预留插入间隔。关系改末一具足其强度之元，截其后弱元；十九逐元及定令和、株式会社回归，已过诺节、同客体硬原生，旧算法同入之败见《固定关系末元》。通用任意规则之动态分重俟后版。

组合类阻挡、非连续收缩还跨度与原序越点，存三层元素之序；所定长式 FDD0 拉丁、盲文笔画索引已成表。十七版提供器、NFD 已自动接入而实核；生成器精核官定 XML 之导入、重排诸选。更广前缀上下文、大小写位诸选、通用分重、全层一致性俟后版。

独立测试篇列三十三项断言，察空白、标点、符号、货币、数字、Hani、Bopo、拉丁之相对序，NFD 声调及大小写、三词组重置、三级别名、重复锚点插入、多字锚点展开、根数据连续收缩。向量依 [CLDR 特殊重置及展开之则](https://unicode.org/reports/tr35/tr35-collation.html#Special_Reset_Positions) 与 [ICU 文字重排之说](https://unicode-org.github.io/icu/userguide/collation/concepts/#script-reordering)，径列码点、预期；三十三项已过同客体双后端。
