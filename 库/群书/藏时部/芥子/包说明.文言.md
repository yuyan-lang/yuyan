# 嵌入数据库

SQLite 唯读表名之查，循编码转换篇，依档编码取八位、十六位小端或大端。记录字段存序列之型及原字节。

结构化查询在 `问簿/` 诸篇，循 SQLite 之义行 SQL 之文。值分空、整、实、文与字节之块，列依所宣之类取亲和，较前依两边亲和而化；备建表之约（主键与行号之别名、UNIQUE、NOT NULL、CHECK、DEFAULT、外键及 ON DELETE 之动）、唯一与部分索引、触发器（BEFORE、AFTER、UPDATE OF、WHEN、RAISE）、视图、ALTER TABLE 之改名与增列、INSERT OR、UPSERT、RETURNING、子查、连接、分组聚合、复合之查、WITH、事务与 defer_foreign_keys。公门为 `问簿/库态` 之「新问会话」「设定会话时钟」及 `问簿/执行` 之「行问句」「行问脚本」「一气行」「果集文」。诸法、诸函、其义与其验，见《问簿/SQLite兼容实施记录.md》。

键与值皆字节串，循字节序。读事务执不变页树之本，叶与枝各容三十二项。写事务独执一库之锁，录成则布新本，弃则释锁；持久之败亦释锁而存旧本。批量写删以「事务写删批」一次归并乱序之（键，可有之值）批，值可无则删；「事务删界」一趟去起（含）止（不含）间之键；「前缀游标」依键序逐批取某前缀下之项，惟交一批，不交全列。

文件库之默认提交书脏页之录：每三十二项为一逻辑页，惟录本务所改之页与目标页数；帧首为魔数、载长与页验，载荷以十六进之码录，值内之帧与外帧之界各辨。基校与果校以「项列验」逐项续算，与整串页验同值，不必为校而重编全库。复原循成帧，越截断、坏帧与基不合者，逐帧而复；残尾后可续录。每千二十四次提交或日志满六十四兆则行检查点：全库书为第二版主数据卷于临径，同步而原子改名代主，乃截日志至零。范围取左闭右开，前缀取同首之键，皆循键序。

`卷恒` 之「辟卷数据库」为文件库之默认口：主数据径存检查点，旁挂「.日志」脏页之录；空库、第一版与第二版主数据皆循增量之路，旧式整卷录库仍循旧路。提交惟增变页，以「同步卷」落盘成而后布新本；检查点定期并录入主而清日志，败则旧主与日志如故、次提交续之。`分页恒` 之「辟分页卷数据库」为同路之显式双径口；「辟旧分页卷数据库」与「辟旧全帧卷数据库」惟为旧库与旧验收而存。初查解叶，再查循缓存，「淘汰页树储」释解码之项。主数据全幅读入，库大于内存须后按页惰读而解。

用户态桌面之字体设置首用此库。桌面于已授目录开 桌面设置.数据库，启动复字体，选择则录事务；惟读之会存会内设置。包索引迁移列于后补。

设置持久之验已核默认、提交、复启与未授之退；实图形复验列于后补。今全包类型之核、主数据页诺驿与硬原生之验皆过，嵌帧尽截断与实目录权故障之验续行。甲乙尚在施作。

关系查询之门在 `关系问/引擎`（以串为行之内存关系表）及 `关系问/榫合`（四 JSON 关系之术与多句脚本之行，立于结构化查询之上，依结森工具）。参为串、整、爻（依整数一、零缚之）及空，所得依 SQLite 值类书为 JSON。详见《关系查询/说明.文言.md》。

`测试/结构化查询/对照。测试。豫` 以本引擎行对照之例（含云仓诸迁移及账本、计费、身份、限流之句），逐步较于系统 sqlite3 所生之期望；期望由 `测试/结构化查询/生成对照期望。脚本。豫` 生之。`测试/结构化查询/逻辑子集。测试。豫` 取 SQLite 官方 sqllogictest `select1.test` 首建表、三十插句及 e、b、d 三列排序之查。

`关系问/存照` 以 JSON（第二版）存查询之会：模式之物记立句原文，行值带类之标，并存末插行号；复原先尽解而验，乃以调用者所定授名布之。`关系问/持久` 纳快照于所定键值键，复用事务提交与日志复原。共用关系适配以「登关系藏」系保存之处，语句与批行成则存已提交之态，SQL 事务待结束而存。持久提交败时内存已改；闭文败或令提交未定，调用者可重开验日志。落盘同步与断电耐久之验，列入后续之事。

主数据页循偏移惰读之口，见《惰读页.文言.md》。「辟惰读主数据页树」用于使用时守内容之文件；缓存未中，则以正定位读术取其页，逾容淘汰而释解码条目。

测试依基础库测试设施，日志批变异之口备录序、单例复行及百万隔离驱动；全树默认行二次小验。召法见 `测试/日志批变异.文言.md`。

默认文件日志与分页数据库已接五字段构页之术，提交成则用独版文件惰读页树，旧读存其原文件。读写或定位之能败，则退内存页树。构造之兼容与明文件径，见《文件页策略.文言.md》。
