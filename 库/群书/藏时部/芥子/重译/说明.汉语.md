# 重译

重译把问簿（SQL）的文字译成调册府的豫言源文字。导入 D1 转储、运维时的临时查询与迁移期间的旧代码走这一路：SQL 文字经重译成豫言，再与别的代码一样编成单元执行。

## 两个入口

- `重译句`：接收一条 SQL 语句的文字（SELECT、INSERT、UPDATE、DELETE）与所涉各表的建表语句文字（CREATE TABLE、CREATE INDEX），返回一段豫言源文字。源文字里有所涉各表的行类型与表声明，查询另有结果行类型「问句果」与函数「问句」。
- `重译建表`：接收建表语句文字，返回各表的行类型与表声明。导入 D1 的表结构用它。

查询函数「问句」的签名是 `化「库」曰「问库」又化「参一」曰 类型 …为 结果类型者也`：第一个参数是芥子的库句柄，此后每个 `?` 一个带标签参数，标签依次是「参一」「参二」……。函数体调册府：SELECT 单表作「检」，两表内连接作「检二」，分组作「聚」；INSERT 作「登」，UPDATE 作「改」，DELETE 作「删」。「检」「检二」「聚」的必填参数（择、次、右径、留）照册府签名的次序逐一写出，缺省值取册府定的全收、不排、全扫与全留。

## 名字

表名作表的名字，表名后面加「行」作行类型名，例如表 `邮箱账户` 得 `「邮箱账户」` 与 `「邮箱账户行」`。栏名照 SQL 的列名。名字里有英文字母、阿拉伯数字或下划线时以“名字「…」不是豫言名字”报错；结果列的别名同样按豫言名字核对。

## 类型

栏的类型照芥子「声明亲和」：整数亲和作「数」，实数亲和作「小数」，文字亲和作「文」，无亲和（BLOB）作「帛」，NUMERIC 作「数」。没有 NOT NULL 又不是主键的栏作 `（「或可有」于 …）`。

参数的类型照它所比、所赋的栏推定：比较里的参数取栏里面的类型，插入与更新里的参数取栏的类型（可空栏即「或可有」）。LIMIT 与 OFFSET 的参数作「数」。同一个参数号前后类型不同时报错。

## 表声明

每张表一条行类型、一条表声明：

```
「邮箱账户」乃（「册」于「邮箱账户行」）也。
「邮箱账户」者「置册」【「名」者『邮箱账户』也，「主键」者『用户编号』也，（「唯一」于（「列」【『邮箱』】））】也。
```

唯一与唯一索引作「唯一」，普通索引作「索引」，FOREIGN KEY 作「外系」。行谱不写，由编译器合成；表没有主键时「主键」写空串。

## 支持的语句

- SELECT：单表；两表内连接（INNER JOIN 与 CROSS JOIN，ON 与 WHERE 并进「择」，栏按表名或别名分到左行、右行）；WHERE；ORDER BY（升序、降序、NULLS FIRST、NULLS LAST）；LIMIT 与 OFFSET。
- 聚合：COUNT、SUM、MIN、MAX、AVG，带 GROUP BY 与 HAVING，或单独作聚合查询。没有 GROUP BY 的聚合先「检」出全部行，再在生成的代码里算，空表也得一行。聚合结果列没写别名时用固定的名字：计数、求和、最小、最大、平均。
- INSERT（VALUES）、UPDATE、DELETE。
- CREATE TABLE 与 CREATE INDEX。
- 条件：比较（=、<>、<、<=、>、>=）、AND、OR、NOT、IS NULL、IS NOT NULL、IN 列表、LIKE 前缀（`'abc%'`）。

## 空值

每个条件译成两个豫言爻式：真（确为真）与假（确为假）。比较的真、假都要求两边有值；IS NULL 的真是「可无」、假是「可有」；NOT 互换真假；AND 的真取且、假取或；OR 的真取或、假取且。WHERE、ON、HAVING 只取真。于是可空栏参与比较时遇空为假，外面再套 NOT 也照 SQL 的结果。

排序里的可空栏写成能处理「或可有」的比较函数：升序时「可无」排在前面，降序时排在后面，NULLS FIRST 与 NULLS LAST 照写。

## 报错

译不了的写法以祸抛出，写明哪一处、为什么。例如：名字含英文字母；聚合函数不认识；LIKE 的模式不是以「%」结尾的前缀；INSERT 缺必填栏；参数前后类型不一；建表语句里的表找不到。
