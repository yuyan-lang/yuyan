# 重译（文言）

重译者，以问簿（SQL）之文译作调册府之豫言源也。D1 之转储、临时之问、迁移之旧文，皆由是路：SQL 之文经重译而成豫言，与百文同编为单元而行。

## 二门

- `重译句`：受一句之文（SELECT、INSERT、UPDATE、DELETE）与所涉诸表建表之文（CREATE TABLE、CREATE INDEX），还一段豫言源。源中有诸表之行类与表宣；查询另有结果行类「问句果」与函「问句」。
- `重译建表`：受建表之文，还诸表之行类与表宣。D1 之表结构由是译之。

问句之签为 `化「库」曰「问库」又化「参一」曰 型 …为 结果之型者也`：首参为芥子之库柄，此后每一 `?` 一签参，签次为「参一」「参二」……。其体调册府：SELECT 单表曰检，两表内连曰检二，分组曰聚；INSERT 曰登，UPDATE 曰改，DELETE 曰删。「检」「检二」「聚」之必填参（择、次、右径、留）依册府签次逐一书之，常值取册府所定之全收、不排、全扫与全留。

## 名

表名即表之名，表名后加行即行类之名，如 `邮箱账户` 得 `「邮箱账户」` 与 `「邮箱账户行」`。栏名循 SQL 之列名。名中有西字、数码或下画线者，以“名字「…」不是豫言名字”告祸；结果列之别名亦以豫言名核之。

## 型

栏之型循芥子之声明亲：整亲为数，实亲为小，文亲为文，无亲（BLOB）为帛，NUMERIC 为数。未非空且非主键之栏作 `（「或可有」于 …）`。

参之型循所比、所赋之栏而定：较中之参取栏内之型，插入与更新之参取栏之型（可空之栏即或可有）。LIMIT 与 OFFSET 之参作数。同一参号前后异型则告祸。

## 表宣

每表一则行类、一则表宣：

```
「邮箱账户」乃（「册」于「邮箱账户行」）也。
「邮箱账户」者「置册」【「名」者『邮箱账户』也，「主键」者『用户编号』也，（「唯一」于（「列」【『邮箱』】））】也。
```

唯一与唯一之索作「唯一」，常索作「索引」，外键作「外系」。行谱不书，编译器合成之；无主键之表，「主键」书空串。

## 所收之句

- SELECT：单表；两表内连（INNER JOIN 与 CROSS JOIN，ON 与 WHERE 并入择，栏依表名或别名分于左行、右行）；WHERE；ORDER BY（升降、NULLS FIRST、NULLS LAST）；LIMIT 与 OFFSET。
- 聚合：COUNT、SUM、MIN、MAX、AVG，带 GROUP BY 与 HAVING，或独为一聚。无 GROUP BY 之聚先检出全行，再于生成之文中算之，空表亦得一行。聚合之果未书别名者用定名：计数、求和、最小、最大、平均。
- INSERT（VALUES）、UPDATE、DELETE。
- CREATE TABLE 与 CREATE INDEX。
- 条件：较（=、<>、<、<=、>、>=）、AND、OR、NOT、IS NULL、IS NOT NULL、IN 之列、LIKE 之前缀（`'abc%'`）。

## 空值

每一条件译作二爻：真者确真，假者确假。较之真假皆须两边有值；IS NULL 之真为可无、假为可有；NOT 换其真假；AND 之真以且、假以或；OR 之真以或、假以且。WHERE、ON、HAVING 惟取真。故可空之栏入较遇空为假，外复套 NOT 亦循 SQL 之果。

排序中可空之栏作能处或可有之较：升则可无居前，降则居后，NULLS FIRST 与 NULLS LAST 照书。

## 告祸

不可译者告祸，明其处与其故。如：名含西字；聚合不识；LIKE 之式非以「%」终之前缀；INSERT 缺必填之栏；参前后异型；建表之语中无其表。
