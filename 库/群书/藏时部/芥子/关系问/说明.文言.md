# 关系查询

`引擎。豫` 治以串为行之内存关系表：`关系立表` 立表，`关系插` 验列数，`关系问` 受行谓词，`关系更新`、`关系删` 还所及行数；又有排序、分页、连接、分组、整数聚合、索引快照、维护索引及事务快照诸术。维护索引与写版在包内私篇 `维护目`、`变更版`。

SQL 之文由 `../结构化查询/` 行之，其义同 SQLite，诸法诸函见《../结构化查询/SQLite兼容实施记录.md》。

`接口适配。豫` 立于结构化查询之上，供关系数据库接口四 JSON 之术：`取问簿首行`、`取问簿全行`、`行问簿句`、`批量行问簿语句`，又供宿主行多句之文（如迁移）之 `行问簿脚本`。用者先以 `问簿/库态` 之「新问会话」立会，复以「登问簿」登于所授之名。参为 JSON 数组：串、整数（绝对值不逾 2^53−1）、爻（依整数一、零缚之）及 null；参数之数须等句中所用最大之参号。所得之行依列序书为 JSON 对象，列名重则存首见之位、取末见之值；整、实、文、空与字节之块（字节数组）各保其类。`行问簿句` 还本句所变之行数（触发器所改不计）及会之末插行号。批行皆原子：无显事务则隐始之，终则提交而验延迟外键；一句有失，则复批前之数、事务之态与延迟外键之态。

`快照。豫` 以 JSON（第二版）存会：模式之物依立序记名、所属之表与立句原文，复时重析之；行值带类之标；又存末插行号。复原先尽析之，乃依授名布之，坏快照不扰旧会；事务未竟则拒存。`持久。豫` 纳快照于所定键值之键，复用键值事务之提交与日志之复原；「登关系藏」系存处之后，语句与批行成则存之，显事务待其终而存。持久提交败时内存已改；闭文之败或令提交未定，用者可重开验日志。

测试在 `../测试/关系查询/`：`引擎。测试。豫` 验以串为行之术；`接口适配。测试。豫` 验四 JSON 之术、参之校、UPSERT 之 RETURNING、原子之批及批中事务之复；`持久。测试。豫` 验经键值日志存而复之（表、唯一索引、检查之约、触发器、视图、诸类之值及行号之续）。
