# 关系查询

`引擎。豫` 治以串为行之内存关系表：`关系立表` 立表，`关系插` 验列数，`关系问` 受行谓词，`关系更新`、`关系删` 还所及行数；又有排序、分页、连接、分组、整数聚合、索引快照、维护索引及事务快照诸术。维护索引与写版在包内私篇 `维护目`、`变更版`。

SQL 之文由 `../问簿/` 行之，其义同 SQLite，诸法诸函见《../问簿/SQLite兼容实施记录.md》。

`接口适配。豫` 立于问簿之上，供关系数据库接口四 JSON 之术：`取问簿首行`、`取问簿全行`、`行问簿句`、`批量行问簿语句`，又供宿主行多句之文（如迁移）之 `行问簿脚本`。用者先以 `问簿/库态` 之「新问会话」立会，复以「登问簿」登于所授之名。参为 JSON 数组：串、整数（绝对值不逾 2^53−1）、爻（依整数一、零缚之）及 null；参数之数须等句中所用最大之参号。所得之行依列序书为 JSON 对象，列名重则存首见之位、取末见之值；整、实、文、空与字节之块（字节数组）各保其类。`行问簿句` 还本句所变之行数（触发器所改不计）及会之末插行号。`导关系转储` 行 D1 风格之多句转储（PRAGMA、BEGIN/COMMIT、建表、建索引、成批之插），还一行之说，所不识之 PRAGMA 名列于末；诸句仍依次而行，遇误即止。批行皆原子：无显事务则隐始之，终则提交而验延迟外键；一句有失，则复批前之数、事务之态与延迟外键之态。

`存照。豫` 以 JSON（第二版）存全会：模式之物依立序记名、所属之表与立句原文，复时重析之；行值带类之标；又存末插行号。复原先尽析之，乃依授名布之，坏快照不扰旧会；事务未竟则拒存。

`藏库。豫` 纳会之表与索引于芥子页式之键值库。键以零字节分段：授键之下，「模式」一键藏书模式之文，「元」一键藏末插之号；每表于「表」、表名、「行」三段之下以行号占一键，行号书为八字节大端，字节之序即行号之序，循前缀而遍则得全表；行记以结绳书之，首列行号，次列诸值之标。藏时与已藏之库底逐表逐行按号相较：新有旧无则书，两有而异则书，旧有新无则删；模式之文异则重书模式键，末号异则重书元键，删表则清其旧行。复时按模式键重造空表、索引、触发器与视图，乃循表前缀灌行，重造其会而登于授名，并记库底；模式键无则取旧纸一束，入而即改新藏。行键之转以「藏库号帛」与「藏库帛号」互易，表前缀由「藏库表前缀」得之。

`藏目。豫` 定目项保序之编码：空先，数次，文又次，块最后；数书为八字节保序双精（负者位型尽反，非负者翻其首爻），文与块之零字节转义而以双零收。目之键：前缀、编码之值、八字节行号。惟有单表而无条件之目入键值库，带校与偏目仍循表扫。等值之查以编码前缀一次尽取，范围之查同前缀下游标而早止；改行、删行、删表则与行并理其项，新增之目整表建项，删目整表清项。

`游标。豫` 者，只读影上之薄游标也：按前缀一取其项，其后惟移其位，不复筛全列。藏库扫表、藏目扫目皆藉之。底犹用今之列举，待键值库之前缀游标至则易其底，其面不变。

`持久。豫` 以「藏库录」与「藏库复」存复授名之下会话；「登关系藏」系存处之后，语句与批行成则存之，显事务待其终而存。持久提交败时内存已改；闭文之败或令提交未定，用者可重开验日志。

测试在 `../测试/关系查询/`：`引擎。测试。豫` 验以串为行之术；`接口适配。测试。豫` 验四 JSON 之术、参之校、UPSERT 之 RETURNING、原子之批及批中事务之复；`持久。测试。豫` 验经键值日志存而复之（表、唯一索引、检查之约、触发器、视图、诸类之值及行号之续）；`藏库。测试。豫` 验新藏之键、重开而复原、增量惟改所动之行键、旧纸读入即成新藏，及 D1 风格 SQL 转储之导入与重开之问；`藏目。测试。豫` 验编码之序、项数、等值取号、范围取号、改删后之增量维护、重开后目仍在。
