# 关系查询

`引擎。豫` 提供按字符串行操作的内存关系表：`关系立表` 创建表，`关系插` 校验列数，`关系问` 接收行谓词，`关系更新` 和 `关系删` 返回受影响行数；另有排序、分页、连接、分组、整数聚合、索引快照、维护索引与事务快照等函数。维护索引与写版本位于包内私模块 `维护目`、`变更版`。

SQL 文字由 `../结构化查询/` 执行，语义与 SQLite 相同，语法与函数清单见《../结构化查询/SQLite兼容实施记录.md》。

`接口适配。豫` 在结构化查询之上提供关系数据库接口的四个 JSON 函数：`取问簿首行`、`取问簿全行`、`行问簿句`、`批量行问簿语句`，以及宿主执行多语句文字（如迁移文件）用的 `行问簿脚本`。调用者先用 `问簿/库态` 的「新问会话」建立会话，再用「登问簿」登记到授权名下。参数是 JSON 数组：字符串、整数（绝对值不超过 2^53−1）、布尔（按整数一、零绑定）与 null；参数个数须等于语句里用到的最大参数号。结果行按列序写成 JSON 对象，列名重复时保留首次的位置、取最后的值；整数、实数、文字、空值与字节块（字节数组）各保其类。`行问簿句` 返回本句的变更行数（不含触发器所改）与会话的最后插入行号。批量函数整批原子执行：没有显式事务时隐式开始，结束时提交并检查延迟外键；任一条失败则恢复批前的数据、事务状态与延迟外键状态。

`快照。豫` 以 JSON（第二版）保存会话：模式对象按建立次序记名字、所属表与建立语句原文，恢复时重新解析；行值带类型标记；另存最后插入行号。恢复先完整解析，再按授权名发布，坏快照不影响现有会话；有未结束的事务时拒绝保存。`持久。豫` 把快照放进调用者指定的键值键，复用键值事务提交与日志恢复；「登关系藏」绑定保存目标后，语句与批执行成功即保存，显式事务在结束后保存。持久提交失败时内存已更新；文件关闭失败可能使提交结果不确定，调用者可以重开核对日志。

测试在 `../测试/关系查询/`：`引擎。测试。豫` 覆盖字符串行接口；`接口适配。测试。豫` 覆盖四个 JSON 函数、参数校验、UPSERT 的 RETURNING、原子批与批内事务语句的恢复；`持久。测试。豫` 覆盖经键值日志保存与恢复（表、唯一索引、检查约束、触发器、视图、各类型的值与行号接续）。
