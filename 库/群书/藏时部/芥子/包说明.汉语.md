# 嵌入数据库

SQLite 只读表名查询复用编码转换包，按文件编码选择 UTF-8、UTF-16 小端或大端。记录字段保持序列类型与原始字节。

结构化查询在 `问簿/` 模块组里按 SQLite 的语义执行 SQL 文字。值分空、整数、实数、文字与字节块，列按声明类型取亲和，比较前按两边亲和转换；支持建表约束（主键与行号别名、UNIQUE、NOT NULL、CHECK、DEFAULT、外键及 ON DELETE 动作）、唯一索引与部分索引、触发器（BEFORE、AFTER、UPDATE OF、WHEN、RAISE）、视图、ALTER TABLE 改名与加列、INSERT OR、UPSERT、RETURNING、子查询、连接、分组聚合、复合查询、WITH、事务与 defer_foreign_keys。公开入口为 `问簿/库态` 的「新问会话」「设定会话时钟」与 `问簿/执行` 的「行问句」「行问脚本」「一气行」「果集文」。语法、函数、语义与验证见《问簿/SQLite兼容实施记录.md》。

键值存储以字节串为键和值，按字节序排列。只读事务持有不可变页树快照，叶页与分支页各容纳 32 项。写事务在同一数据库实例中独占写锁，提交后发布新快照；提交的持久化失败时也释放写锁并保留旧快照，回滚释放写锁。批量写删用「事务写删批」一次归并任意乱序的（键，可选值）批，值为「可无」表示删除；「事务删界」一趟删去起（含）止（不含）之间的键；「前缀游标」按键序逐批取出某前缀下的项，只交一批，不交整份项列。

文件库的默认提交写脏页日志：每 32 项为一逻辑页，只记本事务改动的页与目标页数，帧首是魔数、负载长度与「页验」，负载用十六进位数码编码，值中的帧内容与外层帧边界保持区分。基线校验与结果校验用「项列验」逐项续算，与整串「页验」同值，不必为校验重编全库。恢复扫描完整帧，跳过截断、坏帧与基线不合的帧，逐帧重放；残尾后可以继续追加。每 1024 次提交或日志满 64 MiB 做一次检查点：整库写成第二版主数据卷到临时路径，同步后原子改名替换主卷，再把日志截到零。范围遍历使用左闭右开边界；前缀遍历保留按键排序。

`卷恒` 的「辟卷数据库」是文件库默认入口：主数据路径存检查点，旁挂「.日志」脏页日志；空库、第一版与第二版主数据都走增量路径，旧式整卷日志库仍按旧路打开。提交只追加改动页，用「同步卷」落盘成功后才发布新快照；检查点定期把日志并进主数据并清空日志，失败时旧主卷与日志保持原样、下次提交继续。`分页恒` 的「辟分页卷数据库」是同一条增量路径的显式双路径入口；「辟旧分页卷数据库」与「辟旧全帧卷数据库」只为旧库与旧验收保留。页树按首次查询解码叶页，重复查询使用缓存，「淘汰页树储」释放解码条目。主数据整幅读入，库比内存大需要后续按页惰读解码。

用户态桌面的字体设置是第一个使用者。桌面在已授“桌面”目录中打开 `桌面设置.数据库`，启动时恢复字体，选择字体时提交事务；只读会话保留会话内设置。包索引迁移列为后续事项。

设置持久测试已核对默认值、提交、重开恢复与未授权回退；真实图形回归列为后续事项。当前整包类型检查及主数据页的 Node、硬原生测试通过，内嵌帧全截断与真实目录权故障验收继续执行。甲乙级保持实施状态。

关系查询入口在 `关系问/引擎`（字符串行的内存关系表）与 `关系问/榫合`（四个 JSON 关系函数与多语句脚本执行，建在结构化查询之上，依赖结绳工具）。参数为字符串、整数、布尔（按整数一、零绑定）与空值，结果按 SQLite 的值类型写成 JSON。详见《关系查询/说明.汉语.md》。

册府（表的运行库）把表与查询写成普通豫言。一张表是一个行类型（命名元组）加一条表声明：

```
「邮箱账户行」即
　「组类」
　【「用户编号」乃「数」也
　，「邮箱」乃「文」也
　，「昵称」乃（「或可有」于「文」）也
　】
也。

「邮箱账户」乃（「册」于「邮箱账户行」）者也。
「邮箱账户」者「置册」【「名」者『邮箱账户』也，「主键」者『用户编号』也，（「唯一」于（「列」【『邮箱』】））】也。

「按邮箱取编号」乃化「库」曰「问库」又化「邮箱」曰「文」为（「列」于「数」）者也。
「按邮箱取编号」者得「库」曰「甲」又得「邮箱」曰「址」而
　「检」
　　于「库」曰「甲」
　　于「自」曰「邮箱账户」
　　于「择」曰（得「行」而「文同」于（「行」中「邮箱」）于「址」）
　　于「遍」曰（得「行」而「行」中「用户编号」）
也。
```

查询、写入与事务由「检」「检二」「聚」「登」「改」「删」「同办」等函数完成；条件、投影、排序、分组与连接都是以行为参数的匿名函数，随程序一起编成机器码。「辟问库」按路径打开文件背书的问库，「新问库」只在内存。存储沿用问簿的库状态，经关系问的藏库写进键值库落盘。「建册」按册生成规范的建表语句，经现有解析器得表定义后登进库状态，SQL 文字入口因此看得见同一批表；结构摘要用建表语句原文，原文相同直接过，只在末尾加可空栏、只加索引时自动补上，其余变化报错。登、改、删各自一个事务，核非空、唯一与外系约束，删除还被外系引用的行报错；同办把几件事并在一个事务里，出祸整体回滚。第一版的取径只认整数主键的行号别名，其余栏全表扫再比。索引取行、外连接、UPSERT、显式迁移步骤与服务程序里的动态 SQL 列后续版本。芥子收到的 SQL 文字由「重译」（`重译。豫`）译成调用册府的豫言源，写法与支持面见 `重译/说明.汉语.md`。

`测试/结构化查询/对照。测试。豫` 用本引擎执行对照用例（含云仓全部迁移与账本、计费、身份、限流语句），逐步与系统 sqlite3 生成的期望比较；期望由 `测试/结构化查询/生成对照期望。脚本。豫` 生成。`测试/结构化查询/逻辑子集。测试。豫` 固定 SQLite 官方 sqllogictest `select1.test` 的首个建表、三十条插入以及 e、b、d 三列的排序查询。

`关系问/存照` 以 JSON（第二版）保存查询会话：模式对象记建立语句原文，行值带类型标记，并存最后插入行号；恢复先完整解析，再按调用者给定的授权名发布。`关系问/持久` 将快照放进调用者指定的键值键，复用键值事务提交与日志恢复。共用关系适配通过「登关系藏」绑定保存目标，语句和批执行成功后保存已提交状态，活动 SQL 事务在结束后保存。持久提交失败时内存已更新；文件关闭失败可能产生提交不确定，调用者可以重开核对日志。落盘同步与断电耐久验收列入后续事项。

主数据页按偏移惰读入口见《惰读页.汉语.md》。「辟惰读主数据页树」面向使用期间保持内容的文件，缓存未命中通过正式定位读取接口获取目标页，容量淘汰释放解码条目。

测试依赖基础库测试设施，日志批变异入口提供编号持久化、单例重放与百万隔离驱动；全树默认运行2次冒烟。调用约定见 `测试/日志批变异.汉语.md`。

默认文件WAL及分页数据库已接五字段页树构建回调，成功提交后用独版本文件惰读页树；旧只读事务保持原文件。I/O或定位能力失败回退内存页树。构造兼容与明示文件路径见《文件页策略.汉语.md》。
