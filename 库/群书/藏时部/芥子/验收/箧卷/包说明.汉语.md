# 目录文件验收

这个程序通过现有目录权文件接口验收数据库追加日志、二进制值重开、所有字节截断点及内嵌帧恢复，以及主文件检查点、损坏主图像后的日志重放。启动器授予本次新建空目录，名称为“数据库验收”；程序在该目录操作 `真实文件恢复.数据库`、`分页主数据.数据库`、`分页事务.日志`、`增量主.数据库` 与 `增量日志.日志`，以缺失父目录触发检查点写入失败。目录里须预置测试样本「关系库官方工具样本。数据库」。

包描述使用 `。包。豫.txt` 模板，交给已有豫构发行自动模式复制为实际验收包，复用已有文件适配与宿主支持清单。源码为纯豫言。

目录中另预置测试样本「关系库官方工具样本。数据库」，程序通过正式只读目录权入口查询其80行、负整数及溢出链。日志、分页故障及只读样本验收已经 Node 和硬原生实际运行通过，记录见《双端验收记录》。落盘同步与实机断电验收列为后续事项。

入口另含独立快照文件与增量 WAL 的正式目录验收。快照用两个路径保存前后版本，缓存淘汰后核对旧值，路径冲突拒绝覆盖。增量默认路径核对两次提交后的真实文件重开与删除重放，连续提交一千零二十四次触发检查点并核对日志被清空，再把日志逐字节截断重开，核对每次都回到最后完整提交；夹具在覆盖主文件时一并清掉旁的增量日志。大库测量另见同目录的 `大库/入口。豫`。
