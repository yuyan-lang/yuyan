# 中文排序数据

源数据为 Unicode CLDR release-48 的中文排序规则，官方地址为 https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/collation/zh.xml 。快照保存在 `数据/中文排序.xml`，SHA-256 为 `55890bb4b1f8779b9868f8afb805a1db3af0da8f9d6456f756cc25de85e3bb1e`。版权与授权信息保留在 XML 开头，适用 Unicode 数据许可。

`排序生成。脚本。豫` 读取官方快照，提取两种 LONG 段的 `<*` 主序行，生成 `中文排序表。豫`。主序行中的额外 ASCII 规则字符会使生成失败，以便发现数据形式变化。输出采用码点高位分桶，每行记录十进制码点及主序号。

本轮生成器源码调用 `排序规则生成。豫` 解析 `private-pinyin` 与两种 LONG 的 reset 行，包括段尾重庆、沈阳、藏文规则。生成物再加入拼音与笔画规则桶，记录 NFD 目标码点列、关系强度、before 2 标志、定义序号、NFD 锚点及扩展。私拼音记录同时加入两种方式，短版与注音方式各自保留为后续范围。

中文生成器使用统一码的码点和 NFD 操作处理固定规则中既已赋码的锚点和声调；运行时默认根已接真实 CLDR48／Unicode17 根桶、组合类与隐式闭包。根生成器只复用版本无关文本解析，直接读取官方 UnicodeData17 组合类，先成根表再成中文表以闭合依赖。

重生成命令：豫构构建本地化数据的排序生成入口，再用节点宿主运行产物，传入快照路径及中文排序表输出路径。

当前阶段为静态补实现候稿，`中文排序表。豫` 待生成，覆盖数量待运行后记录。生成器新增固定 FDD0 索引直接主序位置；规则查找新增按组合类的非连续匹配与跳过点，关系解释器保留消费跨度。既有 33 项规则向量及新增 15 项非连续、索引向量均待执行。后续范围为同版提供器接入、前缀上下文、大小写位、通用动态权重插入与全层一致性。
