# 本地化数据

本包收录共同地区数据 CLDR 的简体中文、繁体中文、英文、日文与韩文剪裁，供本地化使用。地区标识采用 zh、zh-Hant、zh-TW、en、ja、ko。

接口包含地区判断、列表分隔文本、基数复数类别、四种日期时间模式、八种相对时间单位与货币默认小数位。英文整数部为正一或负一且无可见小数位得到 one，其余得到 other；中文、日文与韩文得到 other。基数类别按源数绝对值求取，依据 [Unicode 复数规则](https://www.unicode.org/reports/tr35/tr35-numbers.html#Language_Plural_Rules)。货币默认小数位逐项取自补充表 fractions._digits，默认采用两位。数据目录保存 CLDR 48.0.0 五地区完整数字、货币、公历、列表与日期字段快照，以及补充复数与货币规则。

数据出处为 Unicode CLDR，采用 Unicode License v3：[数据仓库](https://github.com/unicode-org/cldr-json)、[许可](https://www.unicode.org/license.txt)。本包固定拉丁数字及三位分组，其他编号系统留待后续版本。

中文排序数据固定于 CLDR release-48 与 Unicode 17.0.0。官方根排序、分数边界、字符表与中文排序 XML 保存于数据目录；纯豫言根排序生成器先生成根桶、组合类及规范分解桶，中文排序生成器随后生成拼音、笔画与规则桶。生成产物已格式化并保存，来源、许可、哈希及完整官方核验见《中文排序》和《根模型》。本包直接依赖统一码排序数据与统一码；规范分解、组合类及隐式权重使用同版十七数据。
