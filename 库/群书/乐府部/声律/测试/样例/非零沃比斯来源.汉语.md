# 非零沃比斯参考

样例由本机 ffmpeg 9.0.2 内置 Vorbis 编码器生成，输入为 440 Hz 正弦，48000 Hz、双声道、4800 帧。本机 ffmpeg 未编入 libvorbis，因此生成时启用内置 Vorbis 编码器的实验选项。

生成命令：

```text
ffmpeg -hide_banner -loglevel error -f lavfi -i sine=frequency=440:sample_rate=48000:duration=0.1 -ac 2 -c:a vorbis -strict experimental -q:a 4 非零沃比斯.ogg
ffmpeg -hide_banner -loglevel error -i 非零沃比斯.ogg -af atrim=end_sample=4800 -c:a pcm_f64le -f f64le 非零沃比斯参考.pcm
```

参考文件由 ffmpeg 独立解码，依容器终 granule 4800 显式裁尾。ffmpeg 未裁尾的原始解码返回 5120 帧，裁尾后保存 4800 帧、9600 个交错双精度样本，共 76800 字节。参考期望读取原始小端 IEEE 754 双精度 PCM，逐样本比较误差阈值 0.00003，并要求实际及参考具有绝对值超过 0.01 的非零样本。
