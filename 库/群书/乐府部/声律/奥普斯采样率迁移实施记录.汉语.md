# 奥普斯采样率迁移实施记录

私核依据官方 Opus v1.1 [silk/decoder_set_fs.c](https://github.com/xiph/opus/blob/v1.1/silk/decoder_set_fs.c) 实施 8、12、16 千赫内部采样率变化。新率重新建立 48 千赫重采样桥，清预测输出环、残差环与短预测史，设置首复位帧标 1、前音高 100、末增益索引 10、前信号 0。前增益 Q16 与前 NLSF 从上一个实际使用的预测态保存；十阶和十六阶之间保存共同的线谱槽，首复位帧使用新帧完整预测。

正式 PLC 与舒适噪声按新率初始化。双声分别保存中声、侧声前增益和前 NLSF，解码器级中侧预测、末样和独中声标继续保存。相同采样率返回原状态。

`丝路改单声采样率` 和 `丝路改双声采样率` 接受实际旧跟踪态与新千赫值，返回新跟踪态。`丝路改单声完整率` 和 `丝路改双声完整率` 接受完整态，保存高声引用及负载元数据，返回新完整态。主调度在旧、新 SILK 内部率不同的包开始前，使用实际上一率的完整态调用，并把返回值写入目标率槽。混合低声属于 16 千赫。声道与内部率同时变化时，可先在旧率完成声道迁移，再把新声道的真实状态传入率迁移私核。

前一批声道迁移随主线新增舒适噪声私有槽同步扩大完整 PLC 复制：参数 33、短史 32、激励 640 项，保留舒适噪声增益、随机种、线谱、合成史与激励缓冲。

使用完整 25a843 发布工具链，在 pit-mac 独立声道核验工作树、独立缓存构建运行六个有向率切换的单双声字段向量：177 项通过、0 项失败。检查独立预置前增益和线谱、真实预测环及短史复位、官方参数、双声中侧历史和新增 CNG 数组末槽完整复制。源码均排版 120。统一调度接线由母代理继续，逐 PCM 精度与长连续率切换验收继续后续实施。
