# 图表

图表提供不可变的图、坐标轴与数据系列。造图、造坐标轴、设轴标签、设对数轴、添系列、添坐标轴组成面向对象风格的调用流程，输出矢量图得到 SVG 文本。系列种类支持折线、散点与柱状；中文标题、轴标签与图例经 SVG 文本元素写出。轴范围由调用者指定，坐标轴按垂直方向排列，每轴使用 600×400 的绘图区。

直方图数据按半开箱区间生成计数；柱状绘制这些计数。热力图采用完整 256 色翠紫色图（viridis），另有灰度色图。显示图像接受图片资源 URI，SVG 写出 image 元素。误差线接受各点相同的纵向绝对误差。输出子图网格按列数排列固定 600×400 子图。刻度按 1、2、5 倍十的幂选择步长，数值格式包输出五位有效数字。

翠紫原表来自 [Matplotlib v3.10.7 官方色表](https://raw.githubusercontent.com/matplotlib/matplotlib/v3.10.7/lib/matplotlib/_cm_listed.py)，使用其 [许可](https://raw.githubusercontent.com/matplotlib/matplotlib/v3.10.7/LICENSE/LICENSE)。源码保留六位小数，纯豫言初始化时乘 255 四舍五入生成八位通道；归一值乘 256 取索引，端点夹至首尾。
