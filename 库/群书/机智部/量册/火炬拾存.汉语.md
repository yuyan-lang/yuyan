# 火炬拾存

`解析火炬拾存` 接受 PyTorch ZIP 存档中的 `data.pkl` 字节串，返回 `火炬张量说明` 列表。调用方负责读取 ZIP 的 `data/<存储键>` 条目，并按说明装配张量。

一条说明按顺序包含：张量名字、存储键、安量数据类型、存储元素偏移、形状、按元素计的步长、存储元素总数。根数据可以是权重字典，也可以是含 `state_dict` 字段的检查点字典。字典的字段顺序参与结果顺序；memo 的字典、列表与张量别名保留共享关系。

支持协议二至五的常用数据指令：PROTO、FRAME、MARK、整数、Unicode 字符串、旧式字节字符串、None、布尔、元组、列表、字典、memo、REDUCE、BINPERSID、BUILD、POP 与 DUP。解析结束核对 STOP、栈及末尾位置。字段长度与存储布局经过界限检查。空张量、零维标量、非零存储偏移、非连续步长可用。

GLOBAL 与 STACK_GLOBAL 的符号白名单为 `collections.OrderedDict`、`torch._utils._rebuild_tensor_v2`，以及 torch 的 DoubleStorage、FloatStorage、HalfStorage、BFloat16Storage、LongStorage、IntStorage、ShortStorage、CharStorage、ByteStorage、BoolStorage。对应安量类型为 F64、F32、F16、BF16、I64、I32、I16、I8、U8、BOOL。

REDUCE 将 OrderedDict 与张量重建符号解释为本模块的数据操作。持久标识取 storage 类型、键与元素数；设备字段保留类型校验。BUILD 接纳字典附属属性状态，丢弃附属 metadata。其余符号或指令以字符串异常报告，可由 `尝试运行` 捕捉。

测试以纯豫言拼装固定协议二与四的字节向量，覆盖权重字典、外包 state_dict、OrderedDict 附属状态、memo 张量别名、偏移与非连续步长、恶意 GLOBAL/STACK_GLOBAL、缺失 memo、存储越界与截断数据。当前源码已排版，类型检查与运行验证等待统筹分配构建时段。

后续事项：协议零与一的文本整数指令、浮点元数据、非空 OrderedDict 构造参数、新版无类型存储与 `_rebuild_tensor_v3`、Parameter 重建、FRAME 内指令边界的严格核对、真实 PyTorch 生成的外部对照向量。

协议依据：[CPython pickletools 操作码文档](https://github.com/python/cpython/blob/main/Lib/pickletools.py)。张量字段依据：[PyTorch 重建函数](https://github.com/pytorch/pytorch/blob/main/torch/_utils.py)。
