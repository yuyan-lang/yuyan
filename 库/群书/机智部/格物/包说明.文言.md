# 机器学习

向量用双精小数列。缩放器存偏与度，先取训练之列而定之，再同施于训练与预测。标准化用总体之方差，恒值之度取一。最小最大缩放以零一为界。具逆缩放、独热编码、依词表定标签与轮转折号。

一元岭回归返截距与斜率，惟罚斜率；零罚则为普通最小二乘。评价具均方误差、平均绝对误差、决定系数、准确率、二类之精确率、召回率、调和分数及混淆计数。二类以零一为号；分母零则精确率、召回率取零。

相配之列须等长，折数须正，误差及准确率之列须有项。标签无于表则返负一。类别之表、样本之序皆由调用者供之。

接收者曲线面积以正负样本两两较而得，同分计半胜，独具一类则取零。训练测试划分返循样本之序而分之索引；折索引以轮转之号定训练或测试。

指标别具全混淆矩阵、合并同分之精确召回曲线梯形积及二类对数损失。矩阵预处理具训练之缩放器、逆变换、选样本行及循定随机源之训练测试划分。

后续验收之事：生命周期峰值资源、超限之判、同机系统实现之效、浏览器与裸机之核，依别阶段行之。

逻辑回归用数值优化之有限记忆极小，求二类含L2罚之目标；截距别存一项，免罚。有名F64矩阵以安量存，结森元数据存于字符串；保存模型、载入模型可用于实文件。逻辑多元与存取之试具独立系数界、解析梯度、手书F64载荷与精确结森元数据之核。

多元普通及岭回归、Lasso坐标下降、主成分、近邻、二贝叶斯、均值聚类、DBSCAN、CART、森林及梯度提升皆受矩阵之例。树与提升之浮点位型以十进字符串存，复还整数诸位；主成分、贝叶斯及树具安量往返。三类九例二维逻辑之试，逐类核解析梯度、目标下降及别定之号。

模型向量循共同批模糊五参，每变异次行严格与可恢复之析，以核接纳相合；败例由共同隔离器存之。线性与树之二合法安量，豫言生成器可复成；全批之证见模型模糊验收之记。

列之均值及标准化之总体方差，复用正式统计之在线汇总。教学例以三组长价拟合普通回归，以别定九之期望核新长四之价，及安量复模之预测。

性能入口复用共同基准，例之种既定，先热二轮，再取九轮中位并印结果之校验。任务可取线性、逻辑、聚类、主成分、决策树、森林、提升、密度、存取及预处理；次参定样本行数。

七普通短验合为一体，以系统time量其全程一次：诺节零点四七秒，最大常驻七四八五八四九六字；同体原生零点一七秒，最大常驻一零七六四二八八字，皆零退。所量兼运行器，所验及二内存计法见《整组资源测量记录》。百万各批之峰与硬超限之判，续验之。
七普通验口于pit-mac各启Node进程，皆零退；系统time所量全时合一点二三秒，兼七次宿主之启，编译别计。诸口客体摘要、实出及资源之录，见《普通入口计时记录》。
