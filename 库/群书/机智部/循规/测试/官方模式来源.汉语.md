# 官方模式测试来源

`官方模式。测试。豫` 收录 JSON Schema Test Suite 的五十项 Draft 2020-12 数据，逐项使用官方 `valid` 真值核对 `校验结森模式`。上游固定提交为 `5b0ee1613e45fcc2bddac00e07c19cd49b00d8a8`，采集日期为 2026-10-08。

[官方测试目录](https://github.com/json-schema-org/JSON-Schema-Test-Suite/tree/5b0ee1613e45fcc2bddac00e07c19cd49b00d8a8/tests/draft2020-12)提供原始模式、输入与真值。源码中的定位采用“文件名加 JSON Pointer”，例如 `type.json#/0/tests/1` 指向文件第零组的第一项测试。中文名用于本地诊断，模式和输入保留官方判义字段与数据。方言声明统一固定为 Draft 2020-12，源码中的模式文本省略重复的 `$schema` 声明。

| 官方文件 | 组号及项号 | 项数 |
|---|---|---:|
| type.json | 0 的 0、1、2；5 的 1、7、8 | 6 |
| properties.json | 0 的 0 至 5 | 6 |
| required.json | 0 的 0 至 3 | 4 |
| items.json | 0 的 0、1；2 的 0、1 | 4 |
| enum.json | 0 的 0、1；5 的 1；9 的 2 | 4 |
| const.json | 0 的 0、1；1 的 1；4 的 1 | 4 |
| anyOf.json | 0 的 0 至 3 | 4 |
| oneOf.json | 0 的 0 至 3；8 的 1、3 | 6 |
| pattern.json | 0 的 0、1；1 的 0 | 3 |
| minimum.json | 0 的 0 至 2 | 3 |
| maximum.json | 0 的 0 至 2 | 3 |
| boolean_schema.json | 0 的 0；1 的 0、4 | 3 |

正则用例使用内置搜索回调，覆盖简单锚定与子串搜索。有限掩码对照采用枚举 `[1,2,3]` 显式生成的三种规范文本和七个词元，逐项穷举前缀可达性，并核对生成完成值符合官方枚举模式。该对照的穷尽域为有限文法规定的文本集合。

后续版本事项：平台整数范围外的纯整数向量随大整数表示接入；其他 JSON Schema 关键词及完整 ECMA 正则合同分别扩充来源向量。上述事项另行统计。当前五十项仅记录选定子集，验证结果由 CI 报告。
