# 网页安全

网页资源的来源、跨源访问、传输和内容策略由纯豫言模块处理，网络交换复用超文本传输，密码摘要复用密码库。

「源」统一来源序列化与同源比较，网络来源规范化默认端口，不透明来源序列化为 `null`。「跨源共享」检查简单方法和字段、来源许可、凭据与预检响应，预检缓存按 `Access-Control-Max-Age` 记期限，计时许可核 `Timing-Allow-Origin`。「内容策略」解析指令首项、用途回退和多策略交集，匹配来源、协议、主机、路径及内联凭据，`'self'` 按 CSP3 的方案族比较（http 与 ws、https 与 wss 同族，主机与有效端口须相同）；报告只记日志，`upgrade-insecure-requests`、`sandbox`、`unsafe-eval`、`wasm-unsafe-eval` 与 `frame-ancestors` 各有查询。

「完整性」按最强摘要算法校验子资源，复用密码库的三种散列。「混合内容」检查可信来源与回环例外并提供安全地址升级。「来源页」实现八种来源页策略，移除凭据和片段，并从响应头解析策略。「严格传输」维护动态期限与子域继承，安全响应登记后升级后续请求；「必缄预载」把预载数据包的两张主机表解析成定长表并二分查找，「必缄须升」合并预载与动态两项，返回主机该不该升级为 https。

「隔离」检查跨源资源策略与页面隔离首部。「沙盒权限」检查沙盒能力与框架嵌入限制。「媒体防嗅探」按目的和响应媒体类型执行脚本与样式的禁止嗅探要求。网页载入中的外部脚本复用完整性校验，抓取主算法调用资源访问检查。

后续事项：`report-uri` 与 `report-to` 的报告投递、`strict-dynamic` 的信任传播、权限策略、完整跨源隔离环境与分区存储。
