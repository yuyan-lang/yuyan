# 网页安全

网页资源的来源、跨源访问、传输和内容策略由纯豫言模块处理，网络交换复用超文本传输，密码摘要复用密码库。

「源」统一来源序列化与同源比较，网络来源规范化默认端口，不透明来源序列化为 `null`。「跨源共享」检查简单方法和字段、来源许可、凭据与预检响应，预检缓存按 `Access-Control-Max-Age` 记期限，计时许可核 `Timing-Allow-Origin`。「内容策略」解析指令首项、用途回退和多策略交集，匹配来源、协议、主机、路径及内联凭据，`'self'` 按 CSP3 的方案族比较（http 与 ws、https 与 wss 同族，主机与有效端口须相同）；`upgrade-insecure-requests`、`sandbox`、`unsafe-eval`、`wasm-unsafe-eval` 与 `frame-ancestors` 各有查询。来源列表同时带 `'strict-dynamic'` 与 nonce／摘要时，外链脚本只认元素的 nonce 或正文摘要，主机白名单不再生效（`网页外链许可`）；解析器插入的外链脚本由 `网页外链拦` 在取回正文后核一次，先按只报不拦的策略记一条 report 违规，再按守策拦截。

「违规报告」把每次拦截写成违规记录：违反指令、生效指令、被阻地址、原始策略、处置、源文件、行列、样本、状态码、文档地址与来源页；多份策略取违约的那一份，同一违规只报一次。外链脚本的违规由 `网页外链违规` 造：被阻地址记目标地址、生效指令记 `script-src-elem`，事件派在该 `script` 元素上。宿主经「置网页违规桥」装上派发事件与上报的实现，库本身不碰文档与网络；报告体按 `csp-report` 形制写成结绳文本，`report-uri` 的地址从违约策略里取出并按文档地址补全。「违规境」保存当前文档只报不拦的策略、文档地址与来源页，抓取主算法与 WebSocket 构造前据此记只报不拦的违规。

「完整性」按最强摘要算法校验子资源，复用密码库的三种散列。「混合内容」检查可信来源与回环例外并提供安全地址升级。「来源页」实现八种来源页策略，移除凭据和片段，并从响应头解析策略。「严格传输」维护动态期限与子域继承，安全响应登记后升级后续请求；「必缄预载」把预载数据包的两张主机表解析成定长表并二分查找，「必缄须升」合并预载与动态两项，返回主机该不该升级为 https。

「隔离」检查跨源资源策略与页面隔离首部。「沙盒权限」检查沙盒能力与框架嵌入限制，并按基本拉丁小写列出 iframe 的 `sandbox` 词元列表所支持的能力词（`沙盒许可词列`），供 `supports` 判定。`析沙盒旗` 把属性值解析成十五项开关（有沙盒、脚本、同源、表单、弹窗、顶层、顶层用户、逃逸、情态、下载、存储、指针、呈现、取向、协议），`并沙盒旗` 让嵌套框继承外层限制；`沙盒当旗` 记正在载入的子文档的旗，`沙盒禁脚本`、`沙盒禁情态`、`沙盒禁同源` 三个判定供脚本执行、情态框与文档 cookie 使用。「媒体防嗅探」按目的和响应媒体类型执行脚本与样式的禁止嗅探要求。网页载入中的外部脚本复用完整性校验，抓取主算法调用资源访问检查。

后续事项：`report-to` 的 Reporting API 投递、报告按文档分区、报告请求携带凭据、`strict-dynamic` 的信任传播、权限策略、完整跨源隔离环境与分区存储。
