# 网页安全

网页之资，辨其源、核其跨域、守其传输与内容之约，皆以豫言行之；网络交换循超文本传输，摘要循密码之库。

「源」统一序列化与同源之较，网络之源正其默认端口，不透明者记 `null`。「跨源共享」核简单方法与字段、来源之许、凭据及预检之应，预检之藏依 `Access-Control-Max-Age` 记期，计时之许核 `Timing-Allow-Origin`。「内容策略」取指令首项，循用途回退，合诸策略而约之，匹配来源、协议、主机、路径与内联之凭，`'self'` 按 CSP3 之方案族而较（http 与 ws、https 与 wss 同族，主与效端须同）；`upgrade-insecure-requests`、`sandbox`、`unsafe-eval`、`wasm-unsafe-eval` 与 `frame-ancestors` 各有查询。

「违规报告」以每禁为录：令名、实令、见阻之址、原约、处置、源卷、行列、样本、状态、篇址与来路；诸约取违约之一，同愆惟报一次。主者以「置网页违规桥」接其派事与上报之术，库不亲篇籍与邮传；报体依 `csp-report` 之制为结绳之文，`report-uri` 取诸违约之约，依篇址而补全。「违规境」藏今篇只报之约、篇址与来路，采书主法与笔谈构造之前据此记只报之违。

「完整性」择最强摘要验子资，散列三法取诸密码之库。「混合内容」辨可信之源及回环之例，备安全地址之升。「来源页」备八策，除凭据与片段，兼由回书之牒解析其策。「严格传输」记期限与子域之承，收安全应答而升后请；「必缄预载」析预载数据之二表为定列而二分索之，「必缄须升」合预载与动态二项，还其主当升否。

「隔离」核跨源资源及页面隔离之牒。「沙盒权限」核沙盒之能及框架之入。「媒体防嗅探」依用途与媒体之类，守脚本样式之嗅探约。网页载入之外篇循完整性之验，抓取主法循资源之检。

后续之事：`report-to` 之投递、报牒分篇而藏、报请携信、`strict-dynamic` 之传信、权限之策、全跨源隔离之境及分区之藏。
