# 浏览久存

浏览器持久资料（提案 00052 第一期“记得住”）：给浏览器开一个资料目录，把 cookie、本地存储、严格传输策略、历史、书签与磁盘缓存的索引写成籍册数据文件（提案 00028），缓存的响应体按文件存在 `缓存体/` 下。

## 资料目录

- 豫言操作系统：数据盘的 `/系统/浏览器`。
- 宿主（林檎、林纳）：`$HOME/.豫言/浏览器`；行在里 `~/.豫言` 经附庸可写，与壳的剪贴、行在的私有根同一处。
- 环境变量 `豫言浏览资料` 或「设浏览资料」可以改，测试用它隔开目录。

目录里的表一律是 `名。数据。豫`：

| 表 | 顶层名 | 内容 |
| --- | --- | --- |
| `小饼。数据。豫` | 小饼们 | 持久 cookie（名称、值、域、路径、到期、仅主机、安全、仅超文本、同站、创建序、来源安全） |
| `本地存储。数据。豫` | 诸源 | 每个来源一条记：源、项列（名与值） |
| `严格传输。数据。豫` | 记录们 | 学到的严格传输安全记录（域、期限、兼及子域） |
| `历史。数据。豫` | 历史们 | 地址、标题、时刻（纪元秒），新的在前，留一万条 |
| `书签。数据。豫` | 书签们 | 地址、标题、时刻，新的在前 |
| `缓存。数据。豫` | 缓存们 | 磁盘缓存的索引（地址、状态、首部、体名、存入、用、到期、标签、改时、长度） |

读表容错：表不在、读不出或有语法错时用缺省。写表先写同目录临时文件再改名，读一半的读者只会见到旧的或新的整表；写不出时静默作罢，只读的宿主不挡浏览。

## 模块

- `资料`：资料目录、表的读写、缓体文件、取栏。
- `历史书签`：历史的记与取、清历史、书签的增删与读。
- `本地久存`：本地存储按来源读回与写回，每源限额五十兆字节。
- `缓存册`：磁盘缓存索引的登记、按地址取、使用时刻、五吉字节上限的淘汰与清缓存。

响应体的存取与命中判定在「抓取」的 `久存缓存` 里；小饼、严格传输策略与本地存储的类型转换在浏览器应用的 `存续` 模块里。

## 后续版本事项

- 缓存按来源分区；缓存索引的并发写合并。
- IndexedDB 已在网页榫卯里以内存版实现（`索引库`），数据是急就值；急就值还没有可逆的落盘编码，IndexedDB 落盘留待后续版本。
- 本地存储的配额按跨源总量再分。
