# 浏览久存

浏览之久存（提案〇〇〇五二第一期“记得住”）：为览者立资目，以小饼、本地之储、必缄之策、史、签与磁盘缓存之册书为籍册之文（提案〇〇〇二八），缓体别为一文而居 `缓存体/` 之下。

## 资目

- 豫言操作系统之数据盘：`/系统/浏览器`。
- 宿主（林檎、林纳）：`$HOME/.豫言/浏览器`；行在之中 `~/.豫言` 经附庸而可书，与壳之剪贴、行在之私根同处。
- 俗 `豫言浏览资料` 或「设浏览资料」可易之，试者以之相隔。

目中之表皆 `名。数据。豫`：

| 表 | 顶名 | 所藏 |
| --- | --- | --- |
| `小饼。数据。豫` | 小饼们 | 久存之饼（名称、值、域、径、期、仅主机、安、仅超文本、同站、创建之序、来源之安） |
| `本地存储。数据。豫` | 诸源 | 一源一记：源、项列（名与值） |
| `严格传输。数据。豫` | 记录们 | 所学必缄之记（域、期、兼及子域） |
| `历史。数据。豫` | 历史们 | 地址、标题、时刻（纪元之秒），新者居前，留万条 |
| `书签。数据。豫` | 书签们 | 地址、标题、时刻，新者居前 |
| `缓存。数据。豫` | 缓存们 | 磁盘缓存之册（地址、状态、首部、体名、存入、用、期、标签、改时、长度） |

读表不败：不在、不读或式误则用其默。写表先书同目之草文而后易名，读者惟见新旧之全；不能书则默罢，只读之宿不碍浏览。

## 诸模

- `资料`：资目、表之读写、缓体之文、取栏。
- `历史书签`：史之记取、清史、签之增删与读。
- `本地久存`：本地之储依源而读写，一源之限五十兆字。
- `缓存册`：缓存之册之登记、按址而取、用之刻、五吉字上限之汰与清缓存。

体之存取与中之判在「抓取」之 `久存缓存`；饼、必缄之策与本地之储之类转在浏览器应用之 `存续` 模。

## 后续版本事项

- 缓存依源分区；缓存之册之并写相合。
- IndexedDB 已在网页榫卯中以内存之版行（`索引库`），其数为急就之值；急就之值尚无逆书之编码，IndexedDB 之落盘留待后版。
- 本地之储之额，按跨源总量再分。
