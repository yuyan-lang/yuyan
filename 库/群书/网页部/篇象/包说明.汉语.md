# 文档对象

「文基」（CharacterData，字符数据节点：文段、白文段、批示、批注四种）是抽象类型，只能经「作文基」按节点种类检查后得到；「文基文」读它自身的字符数据，「设文基文」（树操作）改写并记文字变更。元素、文档与片段不是文基，取整棵子树的文字用「文内容」（textContent）；属性节点的值用「属节值」「设属节值」（议题 1260）。

构树接线保存「篇式」（文档模式）：正篇为标准模式，近正篇为近标准模式，异篇为怪异模式。「节篇式」（读取所属文档模式）按节点归籍查询，文档克隆保留模式；独立片段采用标准模式。

「界域裁撰」支持跨子树的文字序列化、内容克隆、提取、删除、节点插入与包裹，文字插入时同步当前范围终点。「选区」复用范围边界保存锚点、焦点与方向，支持范围增删、折叠、延展、包含判断和文字输出。「属域」按节点身份维护属性命名空间资料，并同步普通属性表。变更观察器对移除子树保留至投递前的临时订阅，投递、断开及重新观察时清理。

默认导入「归籍」「比勘」「界域」「游历」「影树」。「节点属文档」「编籍」「收养节点」「引入节点」按稳定身份维护跨文档归属，树插入与克隆同步归籍。「节点形同」比较节点资料、无序属性和按序子树；「节点位次」给出标准文档位置位图。子列变更记录保留操作时的前后兄弟节点。

「界域」保存可变起讫边界，提供边界比较、设置、前后定位、折叠、节点及内容选取、克隆、静态快照与公共祖先。「游历」提供树遍历器、节点迭代器、节点种类掩码和三态筛选，支持前后、父子与兄弟导航。「影树」登记开放或封闭根及宿主，按当前属性和树顺序计算插槽分配、回退内容与递归展平。范围及迭代器在树变更时的位置修正、影子事件与样式继续实施。
选择器状态另接 `:valid`、`:invalid`（控件按「网页校验态」，表单按「网页表单校验」）、`:user-valid`／`:user-invalid`（后者另要「用户改过」，`标控件改过` 由界面动作置位，脚本设值不算）与勾选框的 `:indeterminate`。选择器状态接通字段集禁用继承和首图例子树豁免，选项沿选项组承接禁用。只读与可写状态结合文本控件、只读属性、禁用和可编辑继承；占位提示读取即时空值，默认态读取选项及勾选控件的默认属性，未定态识别缺值的进度元素。空节点判定计入字符数据段。

「表单控件活动序」与「设表单控件活动序」保存选择控件的活动项序号，复原回到零。多选控件逐项显示活动标记、勾选标记与文字，即时选态继续供提交使用。

复原与文档清理删除同一节点的全部即时记录，恢复默认属性及默认文本内容。

「设控件预编辑」保存可选的显示覆盖，「表单控件编辑映值」读取覆盖或实时值；提交仍读取「表单控件值」。复原清理显示覆盖，密码遮蔽在显示值上进行。

「校验」默认导入，收约束校验一族：`校验态` 的十一项（值缺、类不合、式不合、过严、过短、不及、逾、步不合、坏输、自误、合）由「网页校验态」按 HTML 规范逐项算出——值取已按类型消毒的 `表单控件值`，required 看选态（单选按同名同根一组查），`pattern` 编成 `^(?:模式)$` 用 `v` 旗寻（编不成按忽略），min/max 在 number、range 上按数比、在 date、time、month、week、datetime-local 上按定宽串比，maxlength/minlength 按码点数，step 只在 number、range 上校；「网页校验文」给第一条合用的话，「网页校验乎」不合时派不冒泡可取消的 `invalid` 事件，「网页报校验」同它（移焦由界面层做），「网页设自误」「网页自误文」按节点身份存自定错误，「网页标号们」给 `label[for]` 与祖先 label，「网页表单控件们」「网页表单成员们」「网页表单校验」供提交前判（前者收 input、select、textarea；成员们另收 button、fieldset、output、object，`form.elements` 用它）：全合得阳，否则逐个派 `invalid` 得阴。阀门由宿主在真正提交前调用。`表单控件半选` 存勾选框的 indeterminate。`表单控件选区` 与 `设表单控件选区` 按节点身份存文本控件的起讫（码点下标，左闭右开，没记过时折在值的末尾），供脚本的 `selectionStart`、`selectionEnd`、`selectionDirection`、`setSelectionRange` 与 `select()` 读写；`网页所有权表单`（`form` 属性指的 id，或祖先 form）、`网页列号节`（`list` 属性指的 id）、`网页按号寻节` 与 `网页祖形` 是查表单与列表的两件小工具。类型专用规整、`form.submit()` 的直接提交入口、ValidityState 的活对象形态继续实施。

表单控件实时值与选中状态按节点身份保存，输入默认属性和文本域默认内容保留。`表单控件值`、`设表单控件值`、`表单控件已选`、`设表单控件已选` 供显示、交互与提交共同读取；复原与文档清理删除即时覆盖，`:checked` 消费即时选态。用户代理样式提供输入、文本域、选择及按钮的边框与背景，固有尺寸由章法的替代元素自然尺寸给出，隐藏输入按显示规则处理。类型专用规整、完整脏标记、精细控件主题及自定义表单元素继续实施。

「篇用户代理样式」提供默认块元素（含 `details`、`address`、`legend` 等）、隐藏元数据（含 `noscript`，按已启用脚本的浏览器处理）、标题、列表及表格显示规则。「篇求样式」与「载篇节样式」先加入该来源，再加入页面来源，页面声明按级联覆盖默认值。级联之前按元素求值 `attr()`：候选声明里的 `attr(名[ type(…)][, 备用])` 换成元素属性文（依类型校验，缺或不合作备用），慢路径与快读器两条都换。显式来源计算入口由调用者选择是否加入该来源。`a[href]` 取蓝色并加下划线，`summary` 是内标记的列表项（`details[open]` 里为向下箭头，否则为向右箭头）。输入、文本域、选择与按钮只给显示方式、颜色、边框与内距，固有宽高由章法的替代元素自然尺寸给出：输入框与单行下拉框宽二百、高一行文字，文本域宽二百、高八十，勾选框与单选钮十六见方，列表式选择框按可见行数取高。`[popover]` 的弹出层默认隐藏（照浏览器关闭态的 `display:none`；`:popover-open` 留待后续）。`input[type=image]` 另外清零边框与内距、底色透明，按图像自然宽高作替代元素排版。控件主题、链接状态与其余默认样式随后补齐。

版本：0.1.0。

「样式载」默认导入。「载样式源」接读取器、条件环境、样式基址与正文，展开外部导入。「载篇样式」按文档顺序读取样式元素及样式链接，筛选节点的媒体条件，跳过禁用链接，并以外部资源最终地址作为嵌套导入基址；外链取回后在链接节点上派发 `load`，取不到则派发 `error`。「载篇节样式」将这些来源接入节点的级联和继承计算。替代样式表选择、链接关系的完整空白分词与内容类型随后补齐。

呈现提示（presentational hints）：表格一族的 HTML 呈现属性按 HTML 规范「渲染」一章映射成层叠候选，来源同作者样式，排序在所有作者规则之前：`table` 的 `border`、`cellspacing`、`cellpadding`、`width`、`height`、`align`、`bgcolor`，`td` 与 `th` 的 `width`、`height`、`nowrap`、`valign`、`align`、`bgcolor`（`cellpadding` 沿祖先取所属表的属性），`tr` 与行组的 `valign`、`align`、`bgcolor`，`col` 与 `colgroup` 的 `width`、`align`、`bgcolor`。`dir` 属性对所有元素生效（2026-10-28）：值为 `ltr`、`rtl` 时折成 `direction:ltr`／`direction:rtl` 声明，与浏览器默认样式里的 `dir` 一致，作者样式仍压得住它；`auto` 折成 `unicode-bidi:plaintext`，段落方向由随行（块容器）或文字排版（表单控件）按 UAX #9 的 P2、P3 由首强字符定，整行 `start`／`end` 也按这个段基级解析。`table` 的 `rules` 为 `none`、`groups`、`rows`、`cols`、`all` 时按规范给表 `border-style:hidden` 与折叠边框；`rules=groups` 还让行组（`thead`、`tbody`、`tfoot`）带上下的 1 像素实线，组与组之间因此露出组线，表外缘由表的隐藏边压住。

「样式引擎」默认导入。「篇样式读者」接条件环境、文档根节点与样式来源，一次建好这份文档的样式表，返回读取记录；记录里的「读取」按节点给出计算样式。「篇常样式读者」使用与「篇求样式」同一套来源（用户代理样式加页面里的样式元素）。建表时来源只装配一次，每条规则的选择器分支预先拆好段、算好特异性，再按最右复合选择器的标识、类、标签建索引，树视图建一次；读取节点样式时只检验索引命中的分支，元素的计算样式按文档序缓存，子元素直接取缓存里的父样式。每个元素的结果与「带条件算节样式」逐属性相同；表外的节点（非元素或不在建表子树里）转交「带条件算节样式」。文档变动后由调用者重新建表。「渲染网页篇」与「载静态网页」使用这个读取器。「篇样式树观」一次遍历把整棵树登记进数组（下标是节点身份减最小身份），父、子、前元素兄弟、种类、名称、命名空间在登记时算好，之后每次查询是常数时间；「前序节」用显式的待访栈，线性时间。

样式装配先展开嵌套规则，再筛选条件和登记层顺序。嵌套规则前后的声明保持源码次序，媒体与支持块里的声明继续匹配其父选择器。

「带条件算节样式」接受条件环境、节点与样式来源。在装配层块时递归筛选 `@media` 和 `@supports`；「篇算节样式」采用默认屏幕环境。调用者在视口或用户偏好改变后传入新环境重新计算，取得更新的样式。

本包提供带稳定身份的可变文档节点。节点的内容、属性、父子关系及脏位用豫言引用保存。使用者持有节点后，可观察后续修改。

默认导入「样式接线」。「节随行样式」解析 `style` 属性，「篇样式规则」按前序收集样式元素的规则，「篇外链样式」收集样式链接地址，交由加载器获取后解析。

默认导入「择器接线」。「篇样式树观」以节点身份提供抽象查询；「节合择器」「近择器」「问择器」「问择器全」对应 `matches`、`closest`、`querySelector`、`querySelectorAll`。查询按前序返回稳定节点，范围根参与 `:scope` 匹配。初始控件状态取自属性，交互状态接线留待页面事件循环。

默认导入「计算样式」。「新样式源」登记来源、层与规则；「篇算节样式」将匹配规则与行内声明级联，递归继承父样式并替换变量。「篇求样式」使用本页样式元素。「装配样式诸源」接受环境并展开条件、层声明与层块，同名层共享首次登记的顺序，嵌套层按限定名称登记。级联之前先滤候选：颜色属性在解析期解不出的颜色值、`image-set()` 没有可用选项的图像声明都丢掉，让级联退回前一条声明。当前计算入口返回指定值字符串，后续接单位、颜色换算及缓存；层组的完整树序优先级与匿名层独立身份随后补齐。

「节伪件候选」对每条规则里以伪元素结尾的选择器分支，去掉伪元素后匹配这个元素，匹配上就产生带伪元素名的层叠候选。计算元素样式时（祖先只作继承，不算伪元素），对 `before`、`after`、`marker` 各自把胜出的声明连成「名:值;」，以「::名」为键并进元素的计算样式；它不是继承属性，子元素不带。盒树生成时再解析回来，对元素样式层叠出伪元素的样式。

节点种类采用网页文档对象的编号。元素、文本、注释、属性、处理指令、字符数据段、文档与片段由相应构造函数创建。节点身份在移动、修改和重新插入后保持。

默认导入「节点」「树操作」「节操作」「标记析」「序列化」「遍历」。父子操作同步更新引用，片段插入依次移动其子节点；插入检查祖先关系以维持树结构。属性修改与树修改把祖先链标为脏。文字规范化移除空文字，并将相邻文字合入首节点。

「析篇」「析片段」调用超文本标记的标准树构造（经「构树接线」把树建造器接到本包的节点，句柄是登记表里的序号，零表示空位置）：整页补出全文、头与身元素，片段按 body 元素的上下文解析；「设内标记」以节点自身为上下文元素解析。模板元素的内容就是它的子节点。「外标记」「内标记」进行标记序列化与转义；原始文本直接写出。查询按文档前序遍历，深克隆创建新的身份与可变引用。

「事件」「中止」「微役」「观察」一并默认导入。事件沿固定父链依次捕获、到达目标、冒泡；监听支持捕获、一次、被动和中止信号，回调对象的身份用于去重与移除。自定义事件保存任意豫言值的详情。回调异常写入任务诊断；微任务检查点按入队顺序执行。

中止控制器保存首个理由，同步通知善后；组合信号采用首先中止的信号。事件循环用「推进中止时刻」提供毫秒时间，驱动超时信号。变更观察器支持子节点、属性、文字、子树、属性筛选和旧值；记录在微任务检查点批量投递，也可主动取走或断开。每记一条变更「篇变更计数」加一，浏览器据此判断脚本改没改文档。

# 选择控件实时映射

单行单选控件首次读取时，已有选态保留；没有选项选中时选择首个可用项，跳过禁用选项与禁用组中的选项。多选与多行保持原选态。显式值和下标赋值登记已初始化状态，清空后保持空选择。复原选择控件同时复原其选项并重置初始化状态。

「择控件下标」「择控件值」读取首个已选项，「设择控件下标」按位置更新各项选态，「设择控件值」选中首个值匹配项。未匹配值和越界下标清除选择，默认属性保留；显示与提交沿已有选项状态读取。默认首项选择和选项增删修复留待后续版本。
# 对话框

「对话态」按节点身份保存对话框的返回值与模态标志，提供「对话返回」「设对话返回」「对话模态吗」「设对话模态」「最上模态对话」「对话关闭」「对话请求取消」。「对话关闭」去掉 `open` 属性、清模态标志，并把不冒泡、不可取消的 `close` 事件排进微任务队列异步派发；「对话请求取消」同步派发可取消、不冒泡的 `cancel` 事件，未被取消时关闭。「最上模态对话」按文档前序取最后一个模态对话框，供浏览器壳处理 Esc 与阻挡框外点击。

选择器匹配新增 `:modal` 伪类，模态对话框匹配。用户代理样式新增 `dialog` 的默认显示、定位、收缩尺寸、自动外边距、边框、内边距与画布色，`dialog:not([open])` 隐藏，`dialog:modal` 改为固定定位、滚动溢出并按 `calc(100% - 6px - 2em)` 限制最大宽高。逻辑 inset 属性、`::backdrop` 与完整的顶层次序留待后续版本。


「画布态」按元素身份保存画布元素的位图：宽、高与红绿蓝透明八的字节。「设画布位图」写入或替换位图，「取画布位图」按节点读取，「标画布变更」递增篇章变更计数。网页榫卯的画布上下文每次绘制后写入本篇，设色从本篇取图并按盒尺寸绘制，浏览器据变更计数重排重画。

「媒体态」按元素身份保存 `audio` 与 `video` 的加载与播放状态：网络态、就绪态、暂停、结束、寻位、当前时、时长、播放率、音量、静音、当前源、缓冲、已播与可寻范围、媒体错误，以及视频解码器与当前帧画面。载入按 `src` 或子元素 `source` 选源，经宿主给的取资、解声、开影与开声四术取音、解画与放声：`video` 元素先开影，开得成时按视频解码器给的时长与尺寸载入并解出首帧，否则退回解声取音。成功时依次派发 `loadstart`、`durationchange`、`loadedmetadata`、`loadeddata`、`canplay` 与 `canplaythrough`；播放、暂停、寻位、推进、回绕与结束各自派发规范所列事件。带放声器时当前时取音频时钟（放声器所报已播帧数除采样率），无放声器时由宿主传入页面毫秒推进；约每二百五十毫秒派发一次 `timeupdate`；有视频在播时浏览器每十六毫秒推进一帧，按当前时解出应显之帧写进画面。播到末尾时按 `loop` 属性回绕，或依次派发 `timeupdate`、`pause` 与 `ended`。放声器由宿主在载入时开出，播放、暂停、寻位、音量与静音都转到它；暂停与停末按声钟把当前时补到最新，跳转与回绕把放声器挪到目标，故暂停与跳转都不丢样本。没有音轨或声音输出打不开时退回页面时钟。
# XPath

「径求」按 XPath 1.0 在文档树上求值：先把节点树按先序摊成带下标的表（下标即文档序），再按「轴＋名测试＋谓词」逐段选节点。轴有子、后代、后代或自身、自身、父、祖先、祖先或自身、属性、前兄弟、后兄弟、前、后十二条，另有一条命名空间轴按元素上的 `xmlns` 声明匹配；名测试收名、`*`、`text()`、`node()`、`comment()`；谓词收位置、`last()`、`position()` 比较、属性有无与等值、文字等值与包含。函数库收 `count`、`string`、`number`、`boolean`、`not`、`true`、`false`、`name`、`local-name`、`text`、`normalize-space`、`contains`、`starts-with`、`concat`、`floor`、`ceiling`、`round`。节点集按身份去重、按文档序排序；数值按豫言的整数收。

「径线」把这一套接到文档对象上：文档物有 `evaluate`、`createExpression`、`createNSResolver` 三个方法；全局物有 `XPathResult` 与 `XPathEvaluator` 两个名字，`XPathResult` 带 `ANY_TYPE` 起十个类型常量。结果对象带 `resultType`、`snapshotLength`、`snapshotItem`、`iterateNext`、`singleNodeValue`、`numberValue`、`stringValue`、`booleanValue`、`invalidIteratorState` 九个成员。

| 网页接口 | 豫言入口 |
| --- | --- |
| `document.evaluate` | `安装路径`（径线） |
| `document.createExpression` | `径编式`、`径表达式求` |
| `XPathResult` 常量 | `安装结果常量`（径线） |
| `XPathExpression`、`XPathEvaluator` | `径表达式`、`径求值器` |

样式引擎的容器重算入口（2026-10-31）：新增「重算容器子树」按给定容器宽高与容器名把一棵元素子树的样式全量重算一遍（环境里放 `容宽`、`容高`、`容名`，逐元素走「带条件算节样式」，不做缓存与精确失效），返回（节点, 计算样式）对之列；「样式表储」与「设样式表」「取样式表」把最近建成的文档样式表存进进程级一格（「篇样式读者」建表后自会写入），供块流排到查询容器时取用。计算样式模块的装配阶段新增 `@container` 分支：按环境里由「容器链入」收好的 `容器:*`／`容器:名字` 容器尺寸与名字筛规则，环境里没有容器尺寸时整块不配。`@layer` 的层号改在装配前按层树前序预填（见「装帧」包说明），匿名层仍按首次遇到登记。

`@scope`（2026-10-31）：样式规则的记录带上「域起」「域止」两格（默认可无）。装配阶段遇 `@scope (起) [to (止)] { … }` 时，从 `@scope` 前奏里取括号内的选择器（`括号们` 按次序取全部括号文，`首括文` 是起、`次括文` 是止），把块内每条普通规则盖上这两格（`盖域规则`），再按普通规则装配，选择器本身不改写。匹配元素时（`择器` 篇的 `域内合`）从元素自己起沿父链往上走，第一个匹配起选择器的祖先（或元素自己）就是作用域根，路上（根之下到元素之间）若有元素匹配止选择器就算出界；`:scope` 由起选择器本身承担。隐式作用域（`<style>` 里不带前奏的 `@scope`）由「记隐式域」在解析样式表时补上：把 `<style>` 的父元素（没有就用它自己）记成规则的「域根」，块内普通规则只盖域根、不盖起选择器；匹配时 `域内由根` 沿父链找到这个根即算在内，路上遇止选择器仍判出界。块里再套 `@media`/`@layer` 一类的，内层规则经装配展开后再由「盖域来源们」统一补上「域起」「域止」「域根」，不会逃出作用域。
