# 门面之宿

界面文树后端（门面篇）在自家网页引擎上之宿也。网页文树、网页界面、网页事件三约，皆由本包实于篇象之文档：建改循其文术，择器依装帧，样规入页中之式，排绘归章法、设色、匠心。门面篇不改一字，界面遂由自家引擎排之、绘之、处其入。

## 诸篇

- `状态`：三约共用之可变之态：文档、视口、近帧与显示列表、事列、订阅、焦点、文框今值与光标、卷位、待注之点、柄表、事序与弃数、画素、题、模式、字源与字集之藏。
- `文档`：网页文树之文术：取节、造件、读文属、增删移换其子、择器而问、依深而导、装超文、纳样规、画绢之素、文框今值与光标。柄为节籍之文；险签（脚本、样式、嵌框之属）不与柄。
- `出图`：依页中样式之节排而光栅一帧（篇常样式读者 → 章法 → 设色 → 匠心）。字集先问东道之字体，不得则退取仓中随带之字体（`豫言操作系统/裸机/字模生成/字体/` 下之思源黑体、原始字体与默认等宽黑体），使无字体之东道亦能出字。又供显示列表之命、节之矩、帧耗与存图（塔加图）。
- `事理`：订阅与事列、焦点、命中之派、按键与文字之入、卷位，及网页界面依识之读写。
- `启`：示与试之数门：启一体、注点、注键、存图、帧数与帧耗、一体文字与一体属性、设模式。

## 用法

先 `「一体启」于「宽」曰「八零零」于「高」曰「六四零」于「页范」曰…` 设视口与页范（页范中须有界面之器），乃调门面篇之 `「行门面」`；门面篇经三约之适读写本包。离屏之图用 `「一体存图」于「路径」曰『草稿/图。塔图』`；试则先 `「一体注点」` 排一点，乃行门面篇，末以 `「一体文字」` 与 `「一体帧数」` 断之。塔加图由外具转为网便之图或捷图而观。

## 待办事项

- 惟行单帧（离屏）之式：画一帧、派尽待注之点则答闭。常驻之式须接显示之画面与入（器物像素图面与原样之入），林纳无头之执行器无显示之后端，俟之后版。
- 出图不画画绢之素，页中亦无图像之资（读图恒答可无）。
- 卷位惟记而不效，舒卷之度恒为零；文框惟于末增删其文，无选区、组字与光标之闪。
- 派事无捕获之阶，亦不合高频之事；策惟认择器、排除择器、止默、一次、合并与捕获。
- 键事惟携键名与四修饰；组字中填阴（非组字中也）。
- 柄表惟增不减；超文之装不验签与白册；样规不拒 at 之规与外引。
- 随带字体之径写死为仓根之下，他处安装须别授。
