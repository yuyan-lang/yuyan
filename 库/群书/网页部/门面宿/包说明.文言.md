# 门面之宿

界面文树后端（门面篇）在自家网页引擎上之宿也。网页文树、网页界面、网页事件三约，皆由本包实于篇象之文档：建改循其文术，择器依装帧，样规入页中之式，排绘归章法、设色、匠心。门面篇不改一字，界面遂由自家引擎排之、绘之、处其入。

## 诸篇

- `状态`：三约共用之可变之态。一次会话之界面全状在 `界面态` 一录（文档、视口、近帧与显示列表、事列、订阅、焦点、文框今值与光标、卷位、待注之点、柄表、事序与弃数、画素、题、收场之由、字源与字集之藏，及文档样式版号与读样之器之藏）；「一体启」全份易以新造之 `界面初态`。不随会话重置之映面、映比、模式与限额别立于录外。候事之果用 `待事果` 变体：得事，或收场而携其由（单帧已尽、面关闭、面失效）。模式用 `界面模式` 变体（单帧／常驻）。
- `文档`：网页文树之文术：取节、造件、读文属、增删移换其子、择器而问、依深而导、装超文、纳样规、画绢之素、文框今值与光标。柄为节籍之文；险签（脚本、样式、嵌框之属）不与柄。
- `出图`：依页中样式之节排而光栅一帧（篇常样式读者 → 章法 → 设色 → 匠心）。字集先问东道之字体，不得则退取仓中随带之字体（`豫言操作系统/裸机/字模生成/字体/` 下之思源黑体、原始字体与默认等宽黑体），使无字体之东道亦能出字。读样之器依文档之版号而藏：样式未变、惟标脏重画（易焦、强令重画）则循前帧之旧，不复建其表。又供显示列表之命、节之矩、帧耗与存图（塔加图）。
- `事理`：订阅与事列、焦点、命中之派、按键与文字之入、光标与选区（键与指改之，推于设色而画）、卷位、指按与悬停之态，及网页界面依识之读写。按下与悬停之态入篇象之择器态，式里 `:active`、`:hover` 之规由是而行。指按、指移、指抬三处别挂页面内拖放之钩：按下认可拖之源，移逾五虚素则派 dragstart 与 drag，依今所中之节派 dragenter、dragover、dragleave，抬起则派 drop 与 dragend；拖放之事携类、据、许效、投效与文数，初版惟 text/plain 一种。剪贴之文经系统夹袋读写：控制或命令加 c、x、v 各为复制、剪切、粘贴，copy、cut、paste 之事携 clipboardData 之类与据，粘贴之常动以文接于可编文框之末。无焦之键派于按键之订所之之节（页根之器），不复默弃；「待网页事」答 `待事果`：得事，或收场而携其由；单帧之式空列收场（单帧已尽），常驻之式向面阻塞而候，面阖或失效乃收场（面关闭／面失效）。
- `启`：示与试之数门：启一体、启一体常驻（取面而依其尺与比启视口）、一体视宽与视高与视比、注点、注键、按下与抬起、悬停、重画、存图、帧数与帧耗、一体文字与一体属性、设模式。

## 用法

先 `「一体启」于「宽」曰「八零零」于「高」曰「六四零」于「页范」曰…` 设视口与页范（页范中须有界面之器），乃调门面篇之 `「行门面」`；门面篇经三约之适读写本包。欲真窗则以 `「一体常驻启」于「面名」曰『主窗口』于「页范」曰…` 代「一体启」：取于面、依实尺与比定视口、置常驻；此后同一「行门面」每帧呈于面、候面之入，窗阖则还；面名须行在或桌面所授。离屏之图用 `「一体存图」于「路径」曰『草稿/图。塔图』`；试则先 `「一体注点」` 排一点，乃行门面篇，末以 `「一体文字」` 与 `「一体帧数」` 断之。塔加图由外具转为网便之图或捷图而观。

今有可跑之例：`库/门面/示例/一体`（待办之单离屏出一帧，且与门面自绘之端对照字体、间、色），不书死后端，依下之包图而落于本包。（书斋网页入口之例已成，然上游判包之属有误、类检不过，暂存 `.草稿/存档/库/门面/示例/书斋/`，俟上游修之而复。）

## 构之如何择其适

本包者，「网页文树」「网页界面」「网页事件」三约之适之一也（别有 `网页文树模拟` 以供沙盘与云仓之静态渲、`网页文树` 以行真浏览器）。常构依包图自绑：`库/门面/示例/一体` 之属不书死后端，构时三约绑于 `豫言操作系统/适配/` 下 `网页文树原生`、`网页界面原生`、`网页事件原生`，门面篇遂经三适而落于本包。命如常：

```sh
豫构 构建 界面一体示例 入口 --输出 界面一体示例。林纳。豫行 -- --目标系统 林纳 --目标架构 兼容六十四
```

欲易其后端（如令同例行真浏览器），以包图中三约之绑易为 `网页文树`、`网页界面浏览器`、`网页事件浏览器` 一组即可；本包不改一字。

本包又依剪贴之介 `豫寓夹袋`（`事理` 之复制、剪切、粘贴经其读写系统夹袋）；构时亦依宿主而绑：浏览器由 `豫言操作系统/适配/剪贴板`，诺驿由 `剪贴板节点`，原生则东道自供。本包与示例皆不书死适名。

## 待办事项

- 画布之像素经篇象之「画布态」交设色常绘（与图像同预遮挡、随卷与裁）；`画页画绢像素` 别存之旧记犹在。页中无图像之资（读图恒答可无）。
- 文框之光标与选区：方向、起首、末尾移光标，按上档而扩选；指按与按而拖改光标与选区，上档按而一点自选锚扩至按处，打字与粘贴代选区，退格、删除依光标删一字；文档光标之表为独真之源，改则推于设色画底、线与插符（未聚之框不画）。组字之预稿已入出图，然无下画之饰。
- 事派已分捕获与冒泡二路（先捕后冒，同路依注册之序，尚未依节点之深浅而序）；犹不合高频之事。
- 键事惟携键名与四修饰之键（修饰之按住由面之修饰按抬而记），「组字中」依面之组字状而填；显示之介不携 code、repeat、location，欲填须扩其介。
- 拖放惟行于页面之内、text/plain 一种：拖文入页与东道之拖放须扩显示输入之介，俟后版；粘贴惟以整段之文接于文框之末，光标处之插与选区之切皆待选区，而文框尚无选区；复制、剪切、粘贴之捷径径走常动，不先派 keydown，页面不能改 clipboardData（类与据皆宿所填）。
- 柄表有增无减；装超文不校标签与属性之白册；样规不拒 at 之规与外来之引。
- 随带字体之路依名取于字模之字体清单之仓径，清单无其名乃退写死之仓径。
- 窗名须行在或桌面所授；直起其程而取映面，则得「未获授权」，此宿主之防，非阙也。
