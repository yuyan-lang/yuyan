# 门面之宿

界面文树后端（门面篇）在自家网页引擎上之宿也。网页文树、网页界面、网页事件三约，皆由本包实于篇象之文档：建改循其文术，择器依装帧，样规入页中之式，排绘归章法、设色、匠心。门面篇不改一字，界面遂由自家引擎排之、绘之、处其入。

## 诸篇

- `状态`：三约共用之可变之态。一次会话之界面全状在 `界面态` 一录（文档、视口、近帧与显示列表、事列、订阅、焦点、文框今值与光标、卷位、待注之点、柄表、事序与弃数、画素、题、收场之由、字源与字集之藏，及文档样式版号与读样之器之藏）；「一体启」全份易以新造之 `界面初态`。不随会话重置之映面、映比、模式与限额别立于录外。候事之果用 `待事果` 变体：得事，或收场而携其由（单帧已尽、面关闭、面失效）。模式用 `界面模式` 变体（单帧／常驻）。
- `文档`：网页文树之文术：取节、造件、读文属、增删移换其子、择器而问、依深而导、装超文、纳样规、画绢之素、文框今值与光标。柄为节籍之文；险签（脚本、样式、嵌框之属）不与柄。
- `出图`：依页中样式之节排而光栅一帧（篇常样式读者 → 章法 → 设色 → 匠心）。字集先问东道之字体，不得则退取仓中随带之字体（`豫言操作系统/裸机/字模生成/字体/` 下之思源黑体、原始字体与默认等宽黑体），使无字体之东道亦能出字。读样之器依文档之版号而藏：样式未变、惟标脏重画（易焦、强令重画）则循前帧之旧，不复建其表。又供显示列表之命、节之矩、帧耗与存图（塔加图）。
- `事理`：订阅与事列、焦点、命中之派、按键与文字之入、卷位、指按与悬停之态，及网页界面依识之读写。按下与悬停之态入篇象之择器态，式里 `:active`、`:hover` 之规由是而行。无焦之键派于按键之订所之之节（页根之器），不复默弃；「待网页事」答 `待事果`：得事，或收场而携其由；单帧之式空列收场（单帧已尽），常驻之式向面阻塞而候，面阖或失效乃收场（面关闭／面失效）。
- `启`：示与试之数门：启一体、启一体常驻（取面而依其尺与比启视口）、一体视宽与视高与视比、注点、注键、按下与抬起、悬停、重画、存图、帧数与帧耗、一体文字与一体属性、设模式。

## 用法

先 `「一体启」于「宽」曰「八零零」于「高」曰「六四零」于「页范」曰…` 设视口与页范（页范中须有界面之器），乃调门面篇之 `「行门面」`；门面篇经三约之适读写本包。欲真窗则以 `「一体常驻启」于「面名」曰『主窗口』于「页范」曰…` 代「一体启」：取于面、依实尺与比定视口、置常驻；此后同一「行门面」每帧呈于面、候面之入，窗阖则还；面名须行在或桌面所授。离屏之图用 `「一体存图」于「路径」曰『草稿/图。塔图』`；试则先 `「一体注点」` 排一点，乃行门面篇，末以 `「一体文字」` 与 `「一体帧数」` 断之。塔加图由外具转为网便之图或捷图而观。

## 待办事项

- 出图二式：单帧（离屏）画一帧、派尽待注之点则答闭；常驻以「一体常驻启」依名取面（豫寓映之画面与输入），依面之实尺与比定视口，出图每帧依比放大为实素而后呈；事列空则向面候入，指针移、主键按抬、键、文入、轮、组字、尺易、计与阖各翻为悬、按、点、键、改值、卷串（章法「网页舒卷链滚」，与浏览器同路）、预稿之状、重定视口、标脏重画与收场；面失效或阖则答闭而还面。轮所卷者即网页引擎之卷位表（界面卷量、界面设卷依之答话，不复别存）。组字惟记其状与定稿，预稿之绘留待办。「一体计时」设候事毫秒之限，至则重画一帧（供动与闪之周期刷新），零则无期而候。窗名须行在或桌面所授，径起其程则得「未获授权」。
- 出图不画画绢之素，页中亦无图像之资（读图恒答可无）。
- 卷位惟记而不效，舒卷之度恒为零；文框惟于末增删其文，无选区、组字与光标之闪。
- 派事无捕获之阶，亦不合高频之事；策惟认择器、排除择器、止默、一次、合并与捕获。
- 键事惟携键名与四修饰；组字中填阴（非组字中也）。
- 柄表惟增不减；超文之装不验签与白册；样规不拒 at 之规与外引。
- 随带字体之径写死为仓根之下，他处安装须别授。
