# 门面宿主

界面文树后端（门面篇）在自家网页引擎上的一份宿主。网页文树、网页界面、网页事件三个宿主接口都由本包实现在篇象文档上：建树改树走篇象的文档操作，择器用装帧的匹配，样式规则进页里的样式元素，排版与绘制走章法、设色、匠心。门面篇一行不改，界面就由自家引擎排版、绘制与处理输入。

## 模块

- `状态`：三接口共用的可变状态：文档、视口、最近一帧与显示列表、事件列、订阅、焦点、文本框现值与光标、滚动位置、待注入的点击、句柄表、事件序号与丢弃数、画布像素、标题、模式、字体源与字体集缓存。
- `文档`：网页文树接口的文档操作：取节点、建元素、读写文字与属性、增删移换子节点、选择器查询、深度导出、超文本装入、样式规则、画布像素、文本框现值与光标。句柄是节点身份号的文字；危险元素（脚本、样式、嵌框等）不给句柄。
- `出图`：按页里的样式元素排版与光栅出一帧（篇常样式读者 → 章法 → 设色 → 匠心）。字体集先问宿主的字体接口，问不到时退回仓里的随带字体文件（`豫言操作系统/裸机/字模生成/字体/` 下的思源黑体、原始字体与默认等宽黑体），使没有字体接口的宿主也能出字。另提供显示列表命中、元素矩形、帧耗时与存图（塔加图，即 TGA）。
- `事理`：界面订阅与事件列、焦点、命中与点击派发、按键与文字输入、滚动位置，以及网页界面包按元素标识的读写。
- `启`：给示例与测试用的入口：启一体、注一体点、注一体键、一体存图、一体帧数与帧耗、一体文字与一体属性、设一体模式。

## 用法

程序里先 `「一体启」于「宽」曰「八零零」于「高」曰「六四零」于「页范」曰…` 设视口与页范（页范里须有界面容器），再调门面篇的 `「行门面」`；门面篇经三接口的适配读写本包。离屏出图用 `「一体存图」于「路径」曰『草稿/图。塔图』`；测试先用 `「一体注点」` 排一次点击，再跑门面篇，最后用 `「一体文字」` 与 `「一体帧数」` 断言。塔加图由外部工具转成 PNG 或 JPEG 观看。

## 待办事项

- 只实现单帧（离屏）模式：画过一帧、派完待注的点击之后答关闭事件。常驻模式要接显示接口的画面与输入（器物像素图面与原样输入），林纳无头执行器没有显示后端，留待后续版本。
- 出图不画画布像素（`画页画绢像素` 的像素只存着），页面里也没有图像资源（读图恒答可无）。
- 滚动位置只记不生效，舒卷度量恒为零；文本框只支持在末尾增删文字，没有选区、组字与光标闪烁。
- 事件派发没有捕获阶段，也不合并高频事件；订阅策略只认择器、排除选择器、阻止默认、一次、合并与捕获。
- 键事件只带键名与四个修饰键；组字中填阴（不是输入法组字中）。
- 句柄表只增不减；超文本装入不校验标签与属性白册；样式规则不拒绝 at 规则与外部引用。
- 随带字体路径写死为仓库根下的位置，装到别处时要另给。
