# 门面宿主

界面文树后端（门面篇）在自家网页引擎上的一份宿主。网页文树、网页界面、网页事件三个宿主接口都由本包实现在篇象文档上：建树改树走篇象的文档操作，择器用装帧的匹配，样式规则进页里的样式元素，排版与绘制走章法、设色、匠心。门面篇一行不改，界面就由自家引擎排版、绘制与处理输入。

## 模块

- `状态`：三接口共用的可变状态。一次会话的界面状态全在 `界面态` 一个记录里（文档、视口、最近一帧与显示列表、事件列、订阅、焦点、文本框现值与光标、滚动位置、待注入的点击、句柄表、事件序号与丢弃数、画布像素、标题、收场缘由、字体源与字体集缓存，以及文档样式版号与样式读取器缓存）；「一体启」整份换成新造的 `界面初态`。不随会话重置的显示面、像素比、模式与限额单独立在记录之外。等待结果用 `待事果` 变体：得事，或收场并带缘由（单帧已尽、面关闭、面失效）。模式用 `界面模式` 变体（单帧／常驻）。
- `文档`：网页文树接口的文档操作：取节点、建元素、读写文字与属性、增删移换子节点、选择器查询、深度导出、超文本装入、样式规则、画布像素、文本框现值与光标。句柄是节点身份号的文字；危险元素（脚本、样式、嵌框等）不给句柄。文档一改就把样式版号加一，出图据此决定样式读取器能不能沿用。
- `出图`：按页里的样式元素排版与光栅出一帧（篇常样式读者 → 章法 → 设色 → 匠心）。字体集先问宿主的字体接口，问不到时退回仓里的随带字体文件（`豫言操作系统/裸机/字模生成/字体/` 下的思源黑体、原始字体与默认等宽黑体），使没有字体接口的宿主也能出字。样式读取器按文档版号缓存：页面样式没变而只是标脏重画（换焦点、强制重画）时沿用上一帧那份，不重建样式表。另提供显示列表命中、元素矩形、帧耗时与存图（塔加图，即 TGA）。
- `事理`：界面订阅与事件列、焦点、命中与点击派发、按键与文字输入、光标与选区（键盘与指针改，推给设色画）、滚动位置、指针按下与悬停态，以及网页界面包按元素标识的读写。按下与悬停态写进篇象的择器状态，层叠样式里的 `:active`、`:hover` 规则因此生效。指针按下、移动、抬起三处另挂页面内拖放的钩子：按下时认下可拖的源，移过五逻辑像素派 dragstart 与 drag，按当前命中的节派 dragenter、dragover、dragleave，抬起时派 drop 与 dragend；拖放事件带种类、文据、允许效、投放效与文件数，首版只有 text/plain 一种。剪贴板文字走系统剪贴板适配的读写文字：控制或命令加 c、x、v 分别复制、剪切、粘贴，copy、cut、paste 事件带 clipboardData 的种类与文据，粘贴的默认动作把文字接到可编辑文本框末尾。没有焦点时按键派给按键订阅的目标元素（页根容器），不再静默丢掉；「待网页事」答 `待事果`：得事，或收场并带缘由；单帧模式空列收场（单帧已尽），常驻模式向显示面阻塞候入，面关闭或失效才收场（面关闭／面失效）。
- `启`：给示例与测试用的入口：启一体、启一体常驻（取显示面并按它的尺寸与像素比启视口）、一体视宽与视高与视比、注一体点、注一体键、按下一体与抬起一体、悬停一体、一体重画、一体存图、一体帧数与帧耗、一体文字与一体属性、设一体模式。显示接口里 `呈像素画面`、`待入事`、`设指形状`、`设文字入区域`、`归还映面` 五处都已接上：指针移动时按命中元素的标签设光标形状（文本框为文字指针，链接、按钮、摘要、标签为手形），文字输入与组字更新时把焦点文本框的光标矩按像素比折成实素提示给输入法候选框，窗口关闭时先归还显示面再清掉映面。

## 用法

程序里先 `「一体启」于「宽」曰「八零零」于「高」曰「六四零」于「页范」曰…` 设视口与页范（页范里须有界面容器），再调门面篇的 `「行门面」`；门面篇经三接口的适配读写本包。要真窗口就用 `「一体常驻启」于「面名」曰『主窗口』于「页范」曰…` 取代「一体启」：它取自显示面、按物理尺寸与像素比定视口、把模式置为常驻，随后同一个「行门面」每帧呈上屏、等显示面的输入，窗口关闭时返回；面名须由行在或桌面授予。离屏出图用 `「一体存图」于「路径」曰『草稿/图。塔图』`；测试先用 `「一体注点」` 排一次点击，再跑门面篇，最后用 `「一体文字」` 与 `「一体帧数」` 断言。塔加图由外部工具转成 PNG 或 JPEG 观看。

现成的可跑示例：`库/门面/示例/一体`（待办清单离屏出一帧，并与门面自绘版对照字体、间距与颜色），不写死后端，靠下面的包图绑定落到本包。（书斋网页版入口的示例已写就，但上游判包归属有误、类检过不去，暂存 `.草稿/存档/库/门面/示例/书斋/`，等上游修好再放回。）

## 构建：接口绑到哪个适配

门面宿本身是被「网页文树」「网页界面」「网页事件」三个接口的适配选中的实现之一（另有 `网页文树模拟` 给沙盘与云仓的静态渲染用、`网页文树` 走真浏览器）。普通构建时按包图自动绑定：`库/门面/示例/一体` 这类程序不写死后端，构建时三个接口绑到 `豫言操作系统/适配/` 下的 `网页文树原生`、`网页界面原生`、`网页事件原生`，于是门面篇经这三份适配落到本包。命令照常：

```sh
豫构 构建 界面一体示例 入口 --输出 界面一体示例。林纳。豫行 -- --目标系统 林纳 --目标架构 兼容六十四
```

要换后端（例如让同一个示例走真浏览器），把包图里这三个接口的绑定换成 `网页文树`、`网页界面浏览器`、`网页事件浏览器` 那一组即可；本包不需要改一行。

本包还依赖剪贴板接口 `豫寓夹袋`（`事理` 的复制、剪切、粘贴经它读写系统剪贴板）；构建时同样按宿主绑定：浏览器走 `豫言操作系统/适配/剪贴板`，诺驿走 `剪贴板节点`，原生由宿主提供。本包与示例都不写死适配名。

## 待办事项

- 画布像素经篇象的「画布态」交给设色照常绘制（与图像一样参与遮挡、随滚动与裁剪）；`画页画绢像素` 另存的那份旧记录仍在。页面里没有图像资源（读图恒答可无）。
- 文本框的光标与选区：方向键、起首、末尾移光标，按住上档扩展选区，指针按下与按着拖动改光标与选区，上档按着点一下从选锚扩到按处，打字与粘贴替换选区、退格与删除按光标删一个字；文档里的光标表是唯一的真源，改动后推给设色画底色、竖线与插入符（未聚焦的框不画）。组字的预编辑文字已参与出图，但没有下划线装饰。
- 事件派发已分出捕获与冒泡两路（先捕获后冒泡，同路按注册次序，尚未按节点深度排序）；还不合并高频事件。
- 键事件只带键名与四个修饰键（修饰键的按住态由显示面的修饰键按下、抬起记下），「组字中」按显示面的组字状态填；显示接口不带 code、repeat、location，要填须扩接口。
- 拖放只做页面内、text/plain 一种：拖文件进页面与宿主拖放要扩显示输入接口，留待后续版本；粘贴只把整段文字接到文本框末尾，光标处插入与选区剪切依赖选区，而文本框还没有选区；复制、剪切、粘贴的快捷键直接走默认动作，不先派 keydown，页面改不了 clipboardData（种类与文据由宿主填好）。
- 句柄表只增不减；超文本装入不校验标签与属性白册；样式规则不拒绝 at 规则与外部引用。
- 随带字体路径按名字取自「字模」之「字体清单」的仓库径，清单里没有的名字才退回写死的仓内路径。
- 窗口名须由行在或桌面授予；直接起进程取映面会得「未获授权」，这是宿主的安全前提，不是缺陷。
