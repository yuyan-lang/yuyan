# 严格传输安全预载数据

本包保存铬（Chromium）严格传输安全预载表（HSTS preload list）的快照，分两张主机表：兼及子域者与仅本域者。条目按主机名的字节次序排好，每片若干整行，行以换行分隔。

## 出处与许可

- 原表：铬源码树的 `net/http/transport_security_state_static.json`，取用二〇二六年十月二十日的文件（一零五七一四零四字节）。
- 条目：九五一四七条 `mode` 为 `force-https` 的主机名，其中九四八九七条带 `include_subdomains`，二五零条仅本域。
- 版权归 The Chromium Authors，按 BSD 三条款式许可发布；原文件开头的注释载明 BSD-style license。
- 转换工具：《测试》里的「必缄预载数据生成」。它跳过 `//` 注释行，用结绳解析原表，只取 `force-https`，按主机名排序后分片写出。

## 接口

「预载表」模块提供两个顶层常量：「必缄预载兼域分片」与「必缄预载独域分片」，各是字符串片组成的列。每片含若干整行主机名，行以换行分隔，片的边界由本包与解析方约定。解析由「网页安全」的「必缄预载」负责。

## 更新

原表更新时重跑转换工具，覆盖本包的数据文件：

```
豫构 运行 库/群书/网页部/必缄预载数据/测试/必缄预载数据生成。脚本。豫 <原表.json> <数据文件路径>
```
