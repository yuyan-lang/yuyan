# 浏览器接口

`页面接口` 把抓取、`Headers`、`URL` 与 `URLSearchParams`、`FormData`、`Blob` 与 `File`、`localStorage` 与 `sessionStorage`、`TextEncoder` 与 `TextDecoder` 和 `XMLHttpRequest` 一次装进页面环境。网络交换、本地簿与会话簿、持久回调由页面接口宿主给出。`XMLHttpRequest` 只做异步请求，提供 `open`、`send`、`abort`、`setRequestHeader`、`getResponseHeader`、`getAllResponseHeaders` 与 `overrideMimeType`；状态从 `UNSENT` 到 `DONE`，事件走 `onreadystatechange`、`onloadstart`、`onprogress`、`onload`、`onerror`、`onabort`、`ontimeout`、`onloadend` 属性；`responseType` 支持空、`text`、`json`、`arraybuffer` 与 `blob`。`send` 在建好 `loadstart` 之后同步走完抓取交换，后续事件之间不再检查中止状态。同步请求、上传进度、超时计时与 `overrideMimeType` 对正文类型的影响留待后续版本。

页面提供 `MutationObserver`，支持 `observe`、`disconnect`、`takeRecords`。观察器复用文档变更记录与微任务队列，回调以观察器为接收者，同时接收记录数组和观察器原对象。观察选项支持子节点、属性、字符数据、子树、旧值及属性名筛选；省略属性或字符数据开关时按相关选项推导，矛盾选项抛出类型错误，空属性筛选观察零个属性。记录提供类型、目标、新增节点、移除节点、前后兄弟、属性名、属性命名空间和旧值。移除子树的临时订阅保留至投递前，投递、断开和重新观察时清理。完整原型品牌留待后续版本。

`performance` 提供页面毫秒时钟、时间原点、标记、度量、分类查询与清除，标记详情保存原捷思值；度量可引用起止标记或指定时刻，缺失标记抛出语法错误。

节点接通 `before`、`after`、`replaceWith`、`isEqualNode`、`compareDocumentPosition`、`importNode` 和 `adoptNode`，节点移动保留身份，收养、导入、创建和克隆维护所属文档。`childNodes`、`children` 和 `dataset` 保留对象身份；节点集合提供动态下标、`item`、`forEach`、键值迭代及命名取项，`querySelectorAll` 和变更记录节点列采用静态集合。元素标签、类名和名称集合按当前文档树查询。附签任意键的读写、删除和枚举即时映射数据属性。

范围接通文字输出、内容克隆、提取、删除、插入及包裹；`Selection` 保存锚点、焦点、方向和活动范围，文档与窗口的 `getSelection` 共用包装。元素接通 `outerHTML`、`insertAdjacentText`、`insertAdjacentElement`，位置忽略基本拉丁大小写。`classList` 提供逐项回调、键值迭代及默认迭代。

文档提供稳定的 `implementation`，创建超文本文档、文档类型和带命名空间的文档；文档工厂提供属性、命名空间属性、处理指令与字符数据段。元素接通属性节点的读取、附着、移除和存在查询，属性节点读写联动元素的内容属性。四种命名空间属性方法以命名空间与本地名寻址。`AbortSignal.timeout` 复用页面定时器，在到期任务中以 `TimeoutError` 中止信号，零延迟排入后续任务。

页面提供 `DOMParser` 的超文本解析、`XMLSerializer` 的节点标记序列化、六类界面与输入事件构造器、`Range`、`StaticRange` 与 `NodeFilter` 常量；文档提供范围、树遍历器和节点迭代器创建方法。范围维护起讫、折叠、选取、比较和快照，树遍历器按节点种类与三态筛选导航。树变更自动修正范围及遍历器位置、完整扩展标记解析和事件品牌留待后续版本。

元素接通开放及封闭的影子根、宿主、插槽分配与递归展平查询；影子根样式、事件重定向与插槽变更事件留待后续版本。文档标题读写原树，表单、图像、链接、脚本等分类属性返回当前快照，字符集和内容类型提供页面常量。元素的标题、名称、类型、链接及替代文字等属性映射内容属性，网址解析留待后续版本。
「样式声明」提供元素的实时行内样式对象，包含 `cssText`、`length`、`item()`、属性值与重要性读写、移除和驼峰属性名；读写直接作用于文档节点的样式属性。「装求定样式」安装只读 `getComputedStyle()`，复用文档层叠计算并接受伪元素参数。外链样式来源及布局求定值接入留待后续。


`getAttributeNames` 返回当前属性名数组；`toggleAttribute` 按可选强制参数添加或移除布尔属性，返回修改后的存在状态，原有属性值随保留操作一起保留。`createElementNS` 按给定命名空间和名称建立元素，空值命名空间采用空命名空间。名称校验及带前缀名称拆分留待后续版本。

信号提供 `throwIfAborted`，待中止时返回未定义，已中止时抛出原理由值；脚本可通过 `catch` 获取同一对象或基础值。

页面提供 `AbortSignal.abort` 与 `AbortSignal.any`。前者创建已中止信号，保留显式理由与缺省文档异常；后者接受当前支持的可迭代信号列，组合信号采用首个中止输入的理由，完成监听善后并派发中止事件。空列返回待中止信号，已中止输入按列顺序选取。超时静态方法、自定义迭代器和依赖登记回收继续实施。

中止信号提供 `addEventListener`、`removeEventListener`、`dispatchEvent` 和实时 `onabort`。控制器首次中止先移除受信号约束的监听，再同步派发 `abort`；事件的目标、接收者和路径指向信号，冒泡、取消与越界标志为假。监听去重、一次监听、移除、对象监听和选项共用节点事件入口。`onabort` 更新保持注册位置，清空移除处理器，再赋函数重新注册。完整信号原型与抛中止理由继续实施。

页面提供 `AbortController`，`signal` 保持包装身份，`aborted` 与 `reason` 实时读取。`abort` 保留首次捷思理由并执行原文档中止善后；监听选项的 `signal` 接通原信号，支持中止移除和已中止信号跳过注册。缺省理由为名称 `AbortError`、旧式编号 20 的文档异常对象，显式空值保留为空值。

页面提供 `DOMException` 构造器，接收消息与名称，缺省消息为空文字、名称为 `Error`。对象提供只读 `name`、`message`、`code`，已登记异常名称映射旧式编号，其余名称编号为零。错误原型、异常抛出、栈、常量及构造品牌继续实施。

页面环境提供 `queueMicrotask`，将脚本函数排入文档对象的微任务队列，执行时复用原闭包环境。宿主通过原有微任务检查点按入队次序执行，嵌套排队接在后面，异常记入任务诊断并继续。

页面环境提供 `setTimeout`、`setInterval`、`requestAnimationFrame` 及 `clearTimeout`、`clearInterval`、`cancelAnimationFrame`（模块 `定时器`）。定时器按页面时钟（毫秒，绑定文档时从零起）到期；宿主调「行到期网页定时器」推进时钟，按到期先后（同时到期按编号）执行回调，每个回调之后过一次「网页微役察点」（捷思期约作业与文档微任务），回调的故障打印后继续。重复定时器的间隔至少一毫秒；动画帧回调十六毫秒后到期，实参是页面时钟。「网页定时器下次到期」给出最早的到期时刻，宿主据此定计时间隔。字符串回调、嵌套最小延迟与后台节流留待后续版本。

元素包装有 `onclick`、`onkeydown`、`oninput` 等事件处理器属性（click、dblclick、close、cancel、input、change、submit、reset、keydown、keyup、keypress、mousedown、mouseup、mouseover、mouseout、mousemove、focus、blur、load、scroll）。每个节点每种事件一个槽，元素的 on 开头属性在绑定文档时编成以 `event` 为参数的函数放进槽，脚本赋值替换槽里的函数；第一次赋值时登记一个监听，派发时以元素为接收者调用当前函数，返回假时取消事件。事件参数从事件数据读出 `key`、`code`（文字）、`keyCode`、`which`、`button`、`clientX`、`clientY`（数）与 `ctrlKey`、`shiftKey`、`altKey`、`metaKey`、`repeat`（真假）。内联处理器的元素、表单、文档作用域链与窗口、文档上的处理器留待后续版本。

页面环境有 `window` 与 `self`，就是全局对象；`document`、`navigator`、定时器、`queueMicrotask`、`AbortController`、`DOMException`、`Event`、`CustomEvent` 也是它的属性。`window.addEventListener`、`removeEventListener`、`dispatchEvent` 转给 `document`（窗口事件挂在文档节点上），`window.onload` 与 `<body onload>` 用文档节点的 load 处理器槽。模块 `窗位` 给页面装上 `location`（与 `document.location` 同一对象：`href`、`protocol`、`host`、`hostname`、`port`、`pathname`、`search`、`hash`、`origin`，`assign`、`replace`、`reload`）、`history`（`length`、`state`、`pushState`、`replaceState`、`back`、`forward`、`go`）与窗口的 `innerWidth`、`innerHeight`、`devicePixelRatio`、`scrollX`、`scrollY`、`scrollTo`、`scrollBy`。页面地址、视口尺寸、滚动位置与历史长度由宿主写入；脚本导航、改地址、走历史与滚动时记下请求，宿主用「取网页页索」取走照办。popstate、hashchange 与窗口、文档事件分开留待后续版本。

事件监听接受函数和带 `handleEvent` 方法的对象。对象监听每次派发读取当前方法，以监听对象作为接收者；注册去重和移除沿用监听对象身份。

页面提供 `CustomEvent` 构造器，共用事件选项与包装；`detail` 保留原捷思值，缺省为空值。对象详情在派发前后保持身份，监听可通过详情修改原对象。

页面环境提供 `Event` 构造器，接收事件类型及 `bubbles`、`cancelable`、`composed` 选项。构造与监听共用事件包装入口，构造后即可交给节点的 `dispatchEvent`。构造品牌、原型和派生事件类型继续实施。

节点的 `dispatchEvent` 接受已登记的浏览器事件对象，派发原事件并返回默认动作是否继续执行。重新派发复用同一事件包装，沿用原事件的捕获、目标、冒泡和取消行为。

同一原事件通过内部编号复用浏览器事件包装，捕获、目标和冒泡监听共享参数身份与实时状态。包装登记随页面释放留待后续版本。

事件参数的 `target`、`currentTarget` 读取原事件的实时节点，复用浏览器节点包装。`composedPath()` 返回当前派发路径的节点数组。派发结束后当前目标为空值、阶段归零、路径清空，目标保留原派发节点。

事件参数提供 `preventDefault`、`stopPropagation`、`stopImmediatePropagation`，直接控制原事件；实时属性提供 `defaultPrevented`、`cancelBubble`、`eventPhase`，并公开 `bubbles`、`cancelable`、`composed`。设置真值 `cancelBubble` 可停止传播。事件包装身份和完整品牌检查留待后续版本。

`addEventListener`、`removeEventListener` 接通脚本函数监听，按节点与函数身份复用原事件回调，支持布尔捕获参数和选项对象的 `capture`、`once`、`passive`。原文档派发事件时，以监听节点为接收者调用脚本闭包，事件参数提供 `type`。事件属性的剩余扩展留待后续版本。

文字节点接通 `splitText`，按捷思码元拆成前后两段；原节点保留前段，新节点返回后段，并在原节点有父节点时紧随其后插入。脱离节点的拆分结果保留所属文档。拆开代理对的存储和范围位置同步留待后续版本。

字符数据接通 `substringData`、`appendData`、`insertData`、`deleteData`、`replaceData`，按捷思码元计算起点与数量，数量截到剩余长度，修改复用原文档文字变更记录。无配对代理码元存储和完整无符号参数转换留待后续版本。

节点公开 `nodeName` 和 `ownerDocument`，元素公开 `tagName`、`localName`、`namespaceURI`。超文本元素标签名按基本拉丁字母转大写，所属文档采用稳定包装；脱离与克隆节点保留所属文档，跨文档收养同步子树归属。带前缀元素名称的拆分留待后续版本。

文字、注释、字符数据段与处理指令节点的 `data`、`nodeValue` 读取和修改原节点内容，`length` 按十六位统一码码元计数。`textContent` 对字符节点共用原内容，文档与文档类型节点读取为空值；字符节点空值赋值清空内容。修改复用文档观察记录与脏标记。完整可空文字转换和字符数据方法留待后续版本。

`getRootNode()` 返回当前树的根节点并复用包装身份，`isConnected` 根据当前根是否为文档实时读取连接状态，`hasChildNodes()` 查询当前子节点。插入与移除后立即反映新状态；影子树与跨影子树根查询留待后续版本。

输入的 `defaultValue`、`defaultChecked` 与选项的 `defaultSelected` 反映默认内容属性，文本域的 `defaultValue` 读取和修改原始文字。已有即时编辑状态保留，复原控件后采用更新的默认值和选态。默认属性变化的完整组联动与类型专用规则留待后续版本。

`disabled`、`required`、`readOnly`、`multiple` 反映对应布尔内容属性，属性存在时读取为真，赋值按捷思真值添加或移除属性。`readOnly` 映射 `readonly`，修改沿用文档脏标记与选择器状态；控件编辑、校验、提交继续读取这些文档属性。节点品牌与类型专用限定留待后续版本。

选择控件的首次读取接入单行单选默认状态，显式清除后保持空选态；表单复原重置选项即时状态和默认选择。动态选项增删后的修复与完整大小解析留待后续版本。

选择控件的 `value`、`selectedIndex` 直接映射选项实时状态。值赋值取首个匹配项，下标赋值只选指定项，未匹配值或越界下标清除选态；默认 `selected` 属性保留。默认首项选择、动态选项修复、多选完整规则与整数转换边界留待后续版本。

输入与文本域的 `value`、输入的 `checked`、选项的 `value` 与 `selected` 绑定文档对象的实时控件状态。脚本赋值保留默认属性和文本域原始内容，浏览器显示与表单提交读取同一状态。选择控件值映射、选项值反映规则、单选组联动与类型专用规则留待后续版本。

`append`、`prepend`、`replaceChildren` 接收多个节点与文字实参，按实参顺序装入文档片段，再追加、前插或替换当前子节点。已有节点保留身份并移动到新位置，空参数替换清空子节点。完整对象文字转换、层级预验证与失败恢复留待后续版本。

`classList.replace` 校验两个词元，按原位置替换并合并重复类名，旧词元缺失时返回假。`item` 按下标取得词元，越界返回 `null`；`toString` 返回当前类名属性，`value` 赋值直接更新该属性。下标属性、迭代器与完整无符号转换留待后续版本。

`classList` 保存稳定对象身份，`length`、`value` 读取当前类名属性，重复词元保留首个位置。支持多词元 `add`、`remove`、`contains` 和带可选强制参数的 `toggle`，更新直接作用于 `class`。空词元与含空白词元在修改前报错。下标、迭代器与完整品牌检查留待后续版本。

`parentElement` 返回元素父节点，`previousElementSibling`、`nextElementSibling` 跳过文字与注释取得相邻元素；`firstElementChild`、`lastElementChild` 与 `childElementCount` 读取当前直接子元素。空关系返回 `null`，树修改后这些只读属性即时更新。

`matches` 对当前节点运行已有层叠选择器匹配，`closest` 从当前节点开始沿父链寻找首个匹配节点。返回包装复用节点身份，未找到时返回 `null`；脱离文档树的节点仍可匹配自身。完整选择器错误与范围伪类规则留待后续版本。

`nodeType` 返回文档对象的节点类型编号。`documentElement` 取得文档的首个直接子元素，`head`、`body` 从根元素的直接子节点取得对应结构，`body` 同时识别框架集。缺失结构返回 `null`，所得节点共用包装身份。命名空间与节点品牌的完整限定留待后续版本。

`innerHTML` 实时序列化当前子节点，赋值复用文档片段解析并替换子节点。标记实体与注释沿已有解析和序列化处理，移出的节点保留包装身份。模板内容与完整转换规则留待后续版本。

`insertAdjacentHTML` 在 body 上下文里解析标记文字，按 `beforebegin`、`afterbegin`、`beforeend`、`afterend` 插入；`children` 返回实时元素集合；`lang`、`dir` 反映同名属性。全局 `navigator` 提供 `language`、`languages`（简体中文优先）与 `userAgent`。按系统区域设置取语言留待后续版本。

`parentNode`、`previousSibling`、`nextSibling`、`firstChild` 与 `lastChild` 每次读取当前文档树，返回共用身份的节点包装，空关系返回 `null`。这些只读属性在节点插入、移动与移除后立即反映新关系。

`id` 与 `className` 实时映射节点的 `id`、`class` 属性，缺失属性读为空字符串。属性赋值与 `setAttribute`、`removeAttribute` 共用原文档状态，标识查询和选择器读取更新后的属性。

节点 `textContent` 使用宿主读写访问器。读取取得当前文档的文字内容，赋值调用文档对象的文本更新；后续树操作即时反映到下一次读取。节点种类对应的空值规则与完整文字转换留待后续版本。

`createDocumentFragment` 创建文档片段，片段追加到父节点时依次移动其子节点；`createComment` 创建注释。`normalize` 递归移除空文字，并将相邻文字合并到首个节点，复用文档对象的树更新与脏标记。

节点方法支持 `hasAttribute`、`contains`、`isSameNode`、`cloneNode`、`insertBefore` 和 `replaceChild`。克隆按实参决定是否复制后代并取得独立节点身份；插入复用文档的父子关系检查，替换返回原节点。包含与身份检查对空节点返回假。

`querySelectorAll` 返回按文档顺序保存的静态节点集合，提供只读下标、长度、取项、逐项回调和迭代，节点包装与单节点查询共用身份。`removeChild` 校验直接父子关系并返回被移除节点；`remove` 从原文档移除当前节点。完整原型和集合品牌留待后续实施。

浏览器接口将豫言文档对象绑定到捷思页面环境，按网页标准的文档方法名称提供调用。节点包装按文档节点身份缓存，脚本对属性和树的修改直接作用于原文档。

`新网览篇系` 建立包装缓存，`封装网览节` 包装节点，`系网览篇` 在指定捷思环境绑定 `document`。支持元素查询、选择器查询、元素与文字创建、属性读取与设置、属性移除和节点追加。

`dialog` 元素包装提供 `open`（与 `open` 内容属性互相反映）、`returnValue`、`show()`、`showModal()` 与 `close(返回值?)`。`show()` 打开非模态对话框，对已打开的非模态对话框抛 `InvalidStateError`，对已打开的模态对话框改为非模态；`showModal()` 打开模态对话框，对已打开的对话框抛 `InvalidStateError`；`close()` 只在打开时动作，返回值缺省时保留原值，`close` 事件由文档对象异步派发。`onclose`、`oncancel` 与既有事件处理器属性共用处理器槽。`::backdrop` 与完整品牌检查留待后续版本。

跟随 DOM Living Standard 的节点、元素和文档方法。属性访问器、事件、窗口能力、节点集合完整行为、品牌检查与安全策略留待后续实施。

「网页流」提供 `ReadableStream`、`WritableStream` 与 `TransformStream`：可读流有默认读取者、取消、分茶（`tee`）、管道（`pipeTo`、`pipeThrough`）、`locked`、异步迭代与 `ReadableStream.from`，可写流有默认写入者与背压，变换流把可写一侧的块变换后交给可读一侧。控制器提供 `enqueue`、`close`、`error` 与实时 `desiredSize`，排队策略提供 `CountQueuingStrategy` 与 `ByteLengthQueuingStrategy`。期约按作业队列的次序兑现，腔量为正时调用底层源的 `pull`，读完、出错与取消各按规范兑现或拒绝关闭期约。字节流以 `Uint8Array` 出入；BYOB 读取留待后续版本。

`TextEncoderStream` 与 `TextDecoderStream` 复用文帛编码的编码器与增量解码状态，跨块的残字留在解码器里。`CompressionStream` 与 `DecompressionStream` 复用括囊的素收缩（DEFLATE）、泽缩库（zlib）与吉缩（gzip），支持 gzip、deflate 与 deflate-raw，关闭时一次压缩或解压。抓取的响应提供 `body` 取值器，首次读取时把整段正文做成一枚一次读完的可读流；请求的 `body` 接受可读流对象。

`EventSource` 用页面抓取取 `text/event-stream`，解析 `data`、`event`、`id`、`retry` 与注释行，向监听者派发 `open`、`message`、自定义事件与 `error`，连接结束后按重试毫秒数用页面定时器重连，`close()` 之后不再重连。整段正文一次读完，按块增量读取留待后续版本。
