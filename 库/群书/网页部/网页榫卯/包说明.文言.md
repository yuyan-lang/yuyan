# 浏览器接口

`页面接口` 一次装采书、提封、驿址与询参、表单之录、卷帛、籍册、文帛之编及驿书于页面之境。网之交换、本地与会话之簿、持久之诺，由主录授之。驿书惟行异步，具 `open`、`send`、`abort`、`setRequestHeader`、`getResponseHeader`、`getAllResponseHeaders` 及 `overrideMimeType`；就绪自 `UNSENT` 至 `DONE`，事以 `onreadystatechange`、`onloadstart`、`onprogress`、`onload`、`onerror`、`onabort`、`ontimeout`、`onloadend` 诸性行之；`responseType` 容空、`text`、`json`、`arraybuffer` 与 `blob`。发请告始之后，一顿而走邮传，后事之间不复察止。同步之请、上传之进、超时之计时及 `overrideMimeType` 之改体，留待后修。

页面有 `crypto`：`getRandomValues` 以系统安全之随机写整数类型数组，浮点与逾六五五三六字节者分别告类型不匹配与配额之错；`randomUUID` 还版本四、变体十之编号。`crypto.subtle` 有 `digest`（沙一二五六三八四五一四）、`generateKey`、`importKey` 与 `exportKey`（raw、spki、pkcs8、jwk）、`sign` 与 `verify`（密钥杂凑码、椭圆签、李萨阿或然签、第一版签、爱德二五五一九）、`encrypt` 与 `decrypt`（伽氏计数、连环、计数、最优填）、`deriveBits` 与 `deriveKey`（椭迪赫、交换二五五一九、杂凑衍、口令衍二）及 `wrapKey` 与 `unwrapKey`（钥裹与诸加密之术）。诸术皆还期约，钥材藏于内档，客手所见为 `CryptoKey` 之凭。待办：李萨阿私钥未存素因子与 CRT 之数，私钥之结与 PKCS#8 惟带模、公指、私指；结格式之裹拆留后；计数模式之宽按低位字节递加。


页面供 `MutationObserver`，具 `observe`、`disconnect`、`takeRecords`。器承文档变更之录与微役之队，告时以原器为主，并授诸录之列及原器。其约可观子节、属性、字辞、子树，留旧辞而筛属性之名；属性、字辞之开关省之，则据其相关之约推之，相违则报类型之误，筛名为空则属性皆舍。录具其种、所向、新入、移去、前后之邻、属性名、属性之域与旧辞。已移子树之暂约，留至投递前；投递、断约及重订则清之。原型之制，后续行之。

`performance` 供页面毫秒之钟、时原、标记、度量、分类之询与清除，标记之详存原捷思值；度量可引起讫之标或指定时刻，失标则报语法之误。

节点具 `before`、`after`、`replaceWith`、`isEqualNode`、`compareDocumentPosition`、`importNode`、`adoptNode`；枝迁而符存，收养、引入、造节、摹本皆守其籍。`childNodes`、`children`、`dataset` 守其物身；群籍具动态下标、按序取项、逐项回调、键值迭代与依名求项，选择诸节与变更之列存静影。标签、类名与名称之集随今树而求。附签诸键之读写、著焚、列举，皆即时归于数据属性。

界域可述辞、摹容、取容、删容、插枝、裹容；`Selection` 藏锚点、焦点、方向及活动之界，文档与窗口之 `getSelection` 共其物身。元素具 `outerHTML`、`insertAdjacentText`、`insertAdjacentElement`，所授位置忽略基本拉丁大小写。`classList` 具逐项回调、键值迭代与默认迭代。

文档之 `implementation` 守其身，可造超文本之卷、文档之型及带域之卷；工厂可造属性、带域属性、处理指令及字符数据段。元素可询、附、去属性节点并问其存，属性节点之读写与元素饰辞相应。四种带域属性之术，凭域及本名求之。`AbortSignal.timeout` 承页面之定时，至期以 `TimeoutError` 中止其信，零延迟亦排后役。

页面供 `DOMParser` 析超文本、`XMLSerializer` 述节点标记，六类界面输入之事、`Range`、`StaticRange` 及 `NodeFilter` 常数；文档可造范围、树游与节点迭代。界域守起讫，能敛、能选、能比、能留影；树游依种类与三态之筛而行。树变随护界位与游位、扩展标记之全析及事件品牌，后续行之。

元素可植开阖之影根，询宿主，依名授席而重席展平。影根之样、事件之重定向及席变之事，后续行之。文档之题读写本树，表单、图像、链接、脚本诸属还今时静影，字符集与内容类型列为常数。元素之题、名、种、链及替代之辞皆映内容属性，网址之析俟后续成。
「样式声明」供元素行内之式，随节点而即读即改；具 `cssText`、`length`、`item()`、属性值、重要性之读写、移除及驼峰诸名。「装求定样式」置只读 `getComputedStyle()`，循文档层叠之算而受伪元素。外链来源与布局求定之值，留俟后续。


`getAttributeNames` 列今属性之名；`toggleAttribute` 据可省之强令置焚布尔属性，还其存否，留属性者亦留其旧辞。`createElementNS` 据所授之域与名造元素，域为空值则用空域。名之校验与前缀之析，后续行之。

信号供 `throwIfAborted`，待中止则还未定义，已中止则抛原理由值；脚本可以 `catch` 得同一对象或基础值。

页面供 `AbortSignal.abort` 及 `AbortSignal.any`。前者建已中止信号，存显赋之理由及缺省文档异常；后者受今所支持之可迭代信号列，合信号取首个中止输入之理由，毕监听善后而派发中止事件。空列还待中止信号，已中止输入依列序取之。超时静态方法、自定义迭代器及依赖之录回收续施之。

中止信号供 `addEventListener`、`removeEventListener`、`dispatchEvent` 及实时 `onabort`。控制器首次中止，先移受信号所约之监听，乃同步派发 `abort`；事件之目标、接收者及路径皆指信号，冒泡、取消及越界之标皆阴。监听去重、一次监听、移除、对象监听及选项共节点事件入口。`onabort` 更新存注册之位，清空则移处理器，复赋函数则重录。全信号原型及抛中止理由续施之。

页面供 `AbortController`，`signal` 存包装身份，`aborted`、`reason` 实时取之。`abort` 存首次捷思理由而行原文档中止善后；监听之选 `signal` 接原信号，中止则移除，已中止则略注册。缺省理由为名 `AbortError`、旧式号二零之文档异常对象，显赋空值则存空值。

页面供 `DOMException` 构造器，受消息及名，缺省消息为空文、名为 `Error`。对象供只读 `name`、`message`、`code`，已录异常之名映旧式号，余名之号为零。错误之原型、异常之抛出、栈、常量及构造之品牌续施之。

页面之境供 `queueMicrotask`，排脚本函数于文档对象之微任务队列，行时共原闭包之境。宿主由原检查点循入队次序行，嵌套排者续后，异则录任务诊断而续。

页面之境供 `setTimeout`、`setInterval`、`requestAnimationFrame` 及 `clearTimeout`、`clearInterval`、`cancelAnimationFrame`（模块 `定时器`）。定时器依页面之时钟（毫秒，绑文档时自零起）而至期；宿主呼「行到期网页定时器」进其时钟，依至期之先后（同时则依号）行回调，每回调之后过「网页微役察点」一次（捷思期约之作业与文档之微任务），回调之故印之而续。重复之定时器间隔至少一毫秒；动画帧之回调十六毫秒后至期，实参为页面之时钟。「网页定时器下次到期」予最早之期，宿主据之定计时之间。字符串之回调、嵌套之最小延迟与后台之节流，留待后续之版。

元素之包装有 `onclick`、`onkeydown`、`oninput` 等事件处理器之属（click、dblclick、close、cancel、input、change、submit、reset、keydown、keyup、keypress、mousedown、mouseup、mouseover、mouseout、mousemove、focus、blur、load、scroll）。每节每种事一槽，元素以 on 起之属于绑文档时编为以 `event` 为参之函而置于槽，脚本所赋则易槽中之函；初赋则录一听，派时以元素为受者呼今函，还假则取消其事。事之参自事之数据读 `key`、`code`（文）、`keyCode`、`which`、`button`、`clientX`、`clientY`（数）与 `ctrlKey`、`shiftKey`、`altKey`、`metaKey`、`repeat`（真假）。内联处理器之元素、表单、文档之作用域链与窗、文档上之处理器，留待后续之版。

页面之境有 `window` 与 `self`，即全局之物；`document`、`navigator`、定时器、`queueMicrotask`、`AbortController`、`DOMException`、`Event`、`CustomEvent` 亦为其性。`window.addEventListener`、`removeEventListener`、`dispatchEvent` 转于 `document`（窗之事挂于文档之节），`window.onload` 与 `<body onload>` 用文档之节之 load 处理器之槽。模块 `窗位` 予页装 `location`（与 `document.location` 为一物：`href`、`protocol`、`host`、`hostname`、`port`、`pathname`、`search`、`hash`、`origin`，`assign`、`replace`、`reload`）、`history`（`length`、`state`、`pushState`、`replaceState`、`back`、`forward`、`go`）与窗之 `innerWidth`、`innerHeight`、`devicePixelRatio`、`scrollX`、`scrollY`、`scrollTo`、`scrollBy`。页之址、视口之尺、滚之位与史之长由宿主书之；脚本导航、改址、行史与滚，则记其请，宿主以「取网页页索」取而行之。popstate、hashchange 与窗、文档之事之分，留待后续之版。

页面之境供 `matchMedia`、`ResizeObserver` 与 `IntersectionObserver`（模块 `观听`）。`matchMedia` 还媒合之列，具 `media`、实时之 `matches`、`onchange` 及 `addEventListener`、`removeEventListener`、旧式 `addListener`、`removeListener`。其问复用装帧之条件求值，依今观察之视口与浅色之好而判；宿主重排之后呼「网页投递重排观察」，合否既易则派 `change`，事带 `media` 与 `matches`。`ResizeObserver` 具 `observe`、`unobserve`、`disconnect`，`observe` 之选取 `box`（`content-box` 或 `border-box`）；重排之后依布局之盒投 `target`、`contentRect`、`contentBoxSize`、`borderBoxSize`，初观必报，尺易再报。`IntersectionObserver` 具 `observe`、`unobserve`、`disconnect`、`takeRecords`；根取视口，`rootMargin` 受像素与百分，`threshold` 受数与列，重排、滚动之后依布局之盒与滚之位投 `target`、`isIntersecting`、`intersectionRatio`、`boundingClientRect`、`intersectionRect`、`rootBounds` 与 `time`。宿主以「设网页观察视口」「设网页观察卷位」书页区之尺与滚之位，重排后呼「网页投递重排观察」，滚动后呼「网页投递滚动观察」，并以按节求盒之术授之。元素为根、待报之队与真实之时戳，留待后续之版。

事件监听受函数及有 `handleEvent` 之对象。对象监听每派发取今方法，以监听对象为接收者；注册去重及移除循其对象身份。

页面供 `CustomEvent` 构造器，共事件之选与包装；`detail` 存原捷思值，缺省为空值。对象详情于派发前后存其身份，监听可由详情改原对象。

页面之境供 `Event` 构造器，受事件类型及 `bubbles`、`cancelable`、`composed` 之选。构造与监听共事件包装入口，既成可授节点之 `dispatchEvent`。构造品牌、原型及派生事件类型续施之。

节点之 `dispatchEvent` 受已登记之浏览器事件对象，派发原事件，返默认动作可续行之爻。再派发共原包装，循原事件之捕获、目标、冒泡及取消之行。

同一原事件循内部之号，共浏览器事件包装；捕获、目标及冒泡之监听，共参数身份与实时状态。包装登记随页面释放，留待后版。

事件参数之 `target`、`currentTarget` 取原事件实时节点，共浏览器节点包装。`composedPath()` 返今派发路径之节点数组。派发既终，当前目标为空值，阶段归零，路径清空，目标存原派发节点。

事件参数供 `preventDefault`、`stopPropagation`、`stopImmediatePropagation`，径控原事件；实时属性供 `defaultPrevented`、`cancelBubble`、`eventPhase`，并公开 `bubbles`、`cancelable`、`composed`。设 `cancelBubble` 为真，可止传播。事件包装身份及全品牌之检，留待后版。

`addEventListener`、`removeEventListener` 接通脚本函数之监听，依节点及函数身份共原事件回调，受爻捕获参数及选项对象之 `capture`、`once`、`passive`。原文档派发事件，以监听节点为接收者行闭包，事件参数供 `type`。事件属性之余扩展，留待后版。

文字节点接通 `splitText`，循捷思码元分为前后；原节点存前段，新节点载后段而返之，有父则插于原节点之后。离树之节点拆分，存所属文档。拆代理对之存储及范围位置同改，留待后版。

字符数据接通 `substringData`、`appendData`、`insertData`、`deleteData`、`replaceData`。起点与数循捷思码元，数约于余长；改文共原文档文字变更之录。无配对代理码元之存储及全无符号参数转换，留待后版。

节点公开 `nodeName`、`ownerDocument`；元素公开 `tagName`、`localName`、`namespaceURI`。超文本元素之标签名，基本拉丁字转大写；所属文档守其包装。节点虽离树或复制，存其旧属；跨文档收养则举族更籍。有前缀元素之名拆分，留待后版。

文字、注释、字符数据段及处理指令节点之 `data`、`nodeValue` 读改原节点内容，`length` 依十六位统一码码元计数。`textContent` 于字符节点共用原文，文档及文档类型节点读为空值；字符节点赋空值则清内容。修改复用文档观察之录及脏标。全可空文字转换及字符数据诸法留待后版。

`getRootNode()` 还当前树之根节点而复用包装身份，`isConnected` 依当前根是否为文档实时读连接之态，`hasChildNodes()` 查当前子节点。插及除后即见新态；影子树及跨影子树之根查询留待后版。

输入之 `defaultValue`、`defaultChecked` 及选项之 `defaultSelected` 反映默认内容属性，文本域之 `defaultValue` 读改原始文字。既有即时编辑之态存焉，复原控件则取更新后默认值及选态。默认属性变化之全组联动及类型专规留待后版。

`disabled`、`required`、`readOnly`、`multiple` 反映各布尔内容属性，有属性则读为阳，赋值依捷思真值添或除之。`readOnly` 映 `readonly`，修改循文档脏标及选择器之态；控件编辑、校验及提交仍读诸文档属性。节点品牌及类型专限定留待后版。

选择控件初读接入单行单选默认之态，显式清除后存空选态；表单复原重置选项即时之态及默认选择。动态选项增删后之修与全大小解析留待后版。

选择控件之 `value`、`selectedIndex` 径映选项实时之态。值赋取首个相合者，下标赋唯选指定项，值未合或下标越界则清选态；默认 `selected` 属性存焉。默认首项选择、动态选项之修、多选全规及整数转换之界留待后版。

输入及文本域之 `value`、输入之 `checked`、选项之 `value` 及 `selected` 系于文档对象实时控件之态。脚本赋值存默认属性及文本域原文，浏览器显示与表单提交共读此态。选择控件值映、选项值反映之规、单选组联动及类型专规留待后版。

`append`、`prepend`、`replaceChildren` 受多节点及文字实参，依实参之序装于文档片段，乃追加、前插或替换当前诸子。既有节点存身份而移至新位，空参替换则清诸子。全对象文字转换、层级预验及败后之复留待后版。

`classList.replace` 验二词元，依原位替换而合重复类名，旧词元缺则还阴。`item` 依下标取词元，越界还 `null`；`toString` 还当前类名属性，`value` 赋值径更新之。下标属性、迭代器及全无符号转换留待后版。

`classList` 存稳定对象身份，`length`、`value` 读当前类名属性，重复词元存首位。支持多词元 `add`、`remove`、`contains` 及可授强制参数之 `toggle`，更新径施于 `class`。空词元及含空白者于修改前告错。下标、迭代器及全品牌之检留待后版。

`parentElement` 还元素父节点，`previousElementSibling`、`nextElementSibling` 越文字及注释而取相邻元素；`firstElementChild`、`lastElementChild` 及 `childElementCount` 取当前直接子元素。无所系则还 `null`，树改后诸只读属性即更新。

`matches` 以既有层叠选择器匹配当前节点，`closest` 自当前节点沿父链寻首个匹配者。所还包装复用身份，未得则还 `null`；离文档树之节点亦可匹配自身。全选择器错误及范围伪类之规留待后版。

`nodeType` 还文档对象之节点类型号。`documentElement` 取文档首个直接子元素，`head`、`body` 自根元素直接子节点取其结构，`body` 亦识框架集。缺则还 `null`，所得节点共包装身份。命名空间及节点品牌之全限定留待后版。

`innerHTML` 实时序列化当前子节点，赋则复用片段解析而易其子。标记实体及注释循既有解析与序列化之法，移出节点存包装身份。模板内容及全转换之规留待后版。

`insertAdjacentHTML` 于 body 之境解标记之文，依 `beforebegin`、`afterbegin`、`beforeend`、`afterend` 而插；`children` 还实时元素之集；`lang`、`dir` 映同名之属性。全局 `navigator` 供 `language`、`languages`（先简体中文）及 `userAgent`。依系统区域之设取语言，留待后版。

`parentNode`、`previousSibling`、`nextSibling`、`firstChild` 及 `lastChild` 每读皆取当前文档树，还共身份之节点包装，无所系则还 `null`。诸属性唯供读，节点插、移、除后即见新关系。

`id` 与 `className` 实时映节点之 `id`、`class` 属性，缺则读为空串。赋属性与 `setAttribute`、`removeAttribute` 共用原文档之态，标识及选择器查询取更新后之属性。

节点 `textContent` 用宿主读写访问器。读则取当前文档之文字，赋则调用文档对象更新文本；后续树改即见于再读。节点种类之空值规及全文字转换留待后版。

`createDocumentFragment` 造文档片段，附于父节点则依次移其子；`createComment` 造注释。`normalize` 递归除空文字，合相邻文字于首节点，复用文档对象之树更新及脏标。

节点方法支持 `hasAttribute`、`contains`、`isSameNode`、`cloneNode`、`insertBefore` 及 `replaceChild`。克隆依实参定是否复制后代，得独立节点身份；插入复用文档父子之检，替换还原节点。包含及身份之检遇空节点还阴。

`querySelectorAll` 依文档之序存静态群籍，具只读下标、长度、取项、逐项回调及迭代，节点包装与单节点查询共身份。`removeChild` 验直接父子之系，还所移节点；`remove` 自原文档移当前节点。全原型及群籍品牌之制留待后续。

浏览器接口系豫言文档对象于捷思页面境，依网页标准文档方法之名供调用。节点包装依文档节点身份缓存，脚本改属性及树，径施于原文档。

`新网览篇系` 立包装缓存，`封装网览节` 包节点，`系网览篇` 于指定捷思境系 `document`。支持元素查询、选择器查询、元素及文字之造、属性之读与设、属性之除及节点之附。

`dialog` 元素之包装供 `open`（与 `open` 内容属性相反映）、`returnValue`、`show()`、`showModal()` 及 `close(还值?)`。`show()` 开非模态之对话，已开而非模态者告 `InvalidStateError`，已开而模态者改为非模态；`showModal()` 开模态之对话，已开者告 `InvalidStateError`；`close()` 唯开时动，还值缺省则守其旧，`close` 之事由文档对象异步派之。`onclose`、`oncancel` 与既有事件处理器之属共其槽。`::backdrop` 及全品牌之检留待后续。

依 DOM 现行标准之节点、元素及文档方法。属性访问器、事件、窗口之能、节点集合全行为、品牌之检及安全策略留待后续。

「网页流」具可读、可写、变换之三流：可读有读取者、取消、分茶（tee）、管道（pipeTo、pipeThrough）、锁定、异步之迭代与「自源」之引；可写有写入者与背压；变换以可写之一侧转于可读。控制器有入块、闭、置误与实时之腔量；排队之策有计数与字节二者。期约依作业之队而兑，腔量有余则呼底层之源之 pull；读尽、误、撤各依规范而决关闭之期约。字节流以「字列」出入；BYOB 之读俟后。

「文编流」与「文解流」承文帛编码之器与增量之态，跨块残字留于解器。「压缩流」与「解压流」承括囊之素收缩（DEFLATE）、泽缩库（zlib）、吉缩（gzip），gzip、deflate、deflate-raw 皆通，闭时一次压或解。抓取之回应有 body 之取值，初读则以全篇为一枚一次读完之可读流；请求之 body 受可读流。

「事件源」以页面之抓取取 text/event-stream，析 data、event、id、retry 与注释之行，向听者派 open、message、自定义之事与 error；连接既毕，依重试之毫秒以页面之定时器复连，close 之后不复。全篇一次读尽，按块增量而读俟后。

画布之节，供 `width`、`height`、`getContext('2d')`、`toDataURL('image/png')` 与 `toBlob`。宽高映其内容之性，缺省三百乘一百五十，易尺寸则清位图；一节还一二维上下，余名则空；`toBlob` 俟帛囊有 `Blob` 而后接，今以空值回调。位图书于篇象之「画布态」而依节之身份藏之，设色据以绘；每绘毕增篇章之变数，浏览器于主循计时后重排重画。

`CanvasRenderingContext2D` 供状栈、平移旋转缩放与矩阵之变、`getTransform` 六数之阵、径之全构（兼 `arcTo`、`ellipse` 与 `roundRect`）、非零奇偶之填、描边与虚列、裁剪、中之测、纯色与线径锥形之渐、图像图案、透明与常用合成、线帽线接斜接、阴影、文字（`fillText`、`strokeText`、`measureText`，字体依页之宿主字样源选之）、`drawImage`（画布、图元与三式之参）、`createImageData`、`getImageData`、`putImageData` 与 `setLineDash`。位图之绘，用绘事之径、摊、栅、描、虚、料、合、影。`Path2D` 兼径术与 SVG 径串之构（弧令暂以直线处之），`ImageData` 供宽高与钳制八位之数组；像素之数组依页境 `Uint8ClampedArray` 之原型而立。`OffscreenCanvas`、`webgl` 与 `ImageBitmap` 留待后续。

`structuredClone`（结构化克隆）依 HTML 结构克隆之算法摹脚本之值：基础之质与包裹之器、日期、正则、映射、集合、数组与常物（含环与共引）、诸误、`Blob` 与 `File`；`ArrayBuffer` 与诸观可摹，`{transfer}` 中之牍摹后旧牍之幅为零。术、记与文档之节则告 `DataCloneError`。模块「结构化克隆」兼供包内诸器复用。

`MessageChannel` 之 `port1`、`port2` 经任务之队依发之序投 `message` 事，事之物带 `data`、`origin`、`source`、`ports`；端口具 `postMessage`、`start`、`close`、`addEventListener`、`removeEventListener`、`dispatchEvent`，书 `onmessage` 或 `onmessageerror` 之时自启。`BroadcastChannel` 于同名之信道相投，发者自身不受。`window.postMessage` 与 `window.addEventListener('message', …)` 于一窗之内异步相投。`postMessage` 之 `{transfer}` 可移其牍，移后旧牍之幅为零。

模块「索引库键」供索引库之键序与键界：数、日期、文字、二进制、数组，其序如是；二进制较其字节，数组逐项而较短者先。键界有唯一、下界、上界、两界四式，又含包含之询、两键之比与相等之判。键界与比较之脚本物为索引库本体所用；索引库之库、对象仓、事务、请与游标俟后。

模块「索引库」供内存之索引数据库，合 Indexed Database API 3.0：工场有 `open`、`deleteDatabase`、`databases` 与 `cmp`；开库之请带 `upgradeneeded`、`success` 与 `error`；连接可建删仓、开事、`close`、读 `objectStoreNames` 与 `version`；仓有 `add`、`put`、`get`、`getAll`、`getKey`、`getAllKeys`、`delete`、`clear`、`count`、`openCursor`、`createIndex`、`deleteIndex` 与 `index`，兼 `keyPath` 与 `autoIncrement`；索引具 `name`、`keyPath`、`unique` 与 `multiEntry`；游标有 `continue`、`advance`、`continuePrimaryKey`、`update` 与 `delete`；事有只读、读写、版变三模，请毕则于零毫之役自毕，可 `abort`、可 `commit`，派 `complete` 与 `abort` 之事；请之 `success` 与 `error` 冒泡至事与库。存储于内存，值过结构化克隆；按源而分与持久化俟后。
