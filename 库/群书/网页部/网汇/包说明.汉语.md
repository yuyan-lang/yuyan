# 网页汇编引擎

版本：0.1.0。

本包是提案 00009 里程碑三的网页汇编（WebAssembly，网汇）引擎，以纯豫言写成，供网页榫卯的捷思接口调用。它把网页汇编二进制读成模块结构，按规范检查段序、索引、块结构与栈的浅深，再用栈式解释器执行函数体。

支持的版本是网页汇编核心规范二点零的常规范畴：三十二位与六十四位整数、单精度与双精度浮点、内存与内存增长、表与间接调用、全局、导入与导出、起始函数、元素段与数据段。后续特性已接通符号扩展与非陷阱浮点转整；批量内存、多值与引用类型的起步留待后续版本；网页汇编回收、异常处理与尾调用同样留待后续。

## 模块

| 模块 | 职责 |
| --- | --- |
| 字节 | 有界字节读取器、七位变长整数、名字与子段 |
| 值型 | 值类型码、运行期值、函数类型、指令、函数体、模块与实例记录，单精度换算 |
| 解码 | 魔数与版本、各段的读取、指令与块结构的解析 |
| 验形 | 段内索引与块结构的检查、跳转目标与栈浅深的预定 |
| 执机 | 装配实例、初始化全局与段、调用函数、陷阱 |

## 用法

公开入口为 `网汇解码`、`网汇验形`、`网汇装配`、`网汇召`、`网汇寻导`。出错时以 `CompileError：`、`LinkError：` 或 `RuntimeError：` 开头的消息告祸，网页榫卯的捷思接口据此造出对应的脚本错误对象。

## 限制

- 类型栈检查按块的出入与栈的浅深进行，逐条指令的操作数类型只在执行时核对。
- 单精度运算在双精度上算出后再按单精度舍入。
- 调用深度与内存容量有实现上限，超过时报告陷阱。
- 表、内存与全局的按名导出暂只接通函数导出；内存复制与填充、表复制与初始化留待后续。
- 网页榫卯的捷思接口把字节、导入、导出函数与内存缓冲接上；流式编译与实例化留待后续。
