# 网页汇编引擎

版：零点一零点零。

此包为提案零零零零九里程碑三之网页汇编（网汇）引擎，以豫言成之，供网页榫卯之捷思接口调用。其职有三：读网汇之帛为篇，验其段序、索引、块构与栈之浅深，以栈式之机行其令。

所据者为网汇核心规范二点零之常法：三十二位、六十四位之整，单精、双精之浮，内存与内存之涨，表与间接之召，通、导入与导出、起始、元素段与数据段。其后已接符号扩展与非陷之浮转整；批量内存、多值与引用之始，以及网汇洒扫、异常与尾调，俟之后版。

## 篇目

| 篇 | 职 |
| --- | --- |
| 字节 | 有界之读、七位变长之数、名字与子段 |
| 值型 | 值类之码、行时之值、函数之型、令、术、篇与例之记，单精换算 |
| 解码 | 魔数与版、诸段之读、令与块构之析 |
| 验形 | 段内索引与块构之检、跳标与栈深之预定 |
| 执机 | 装配例、初通与段、召术、陷 |

## 用法

公开之入为 `网汇解码`、`网汇验形`、`网汇装配`、`网汇召`、`网汇寻导`。有误则以 `CompileError：`、`LinkError：` 或 `RuntimeError：` 起其辞而告祸，网页榫卯之捷思接口依之造脚本错误之物。

## 限

- 类型之栈按块之出入与栈之浅深而检，逐令之操作数之类，行时乃核。
- 单精之算，先以双精算之，再依单精而舍。
- 召之深与内存之量皆有实现之上限，逾则报陷。
- 表、内存与通之按名出，今唯术之出已通；内存之抄填、表之抄与初，俟之后版。
- 网页榫卯之捷思接口已接字节、导入、导出之术与内存之牍；流式编译与实例化，俟之后版。
