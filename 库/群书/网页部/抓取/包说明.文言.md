# 抓取

采资统一请应之制，应用授其交换，网页安全核资源之访，超文本传输备缓存与小饼诸旧能。

「执行抓取」合请求元牒、内置协议、转向、逐站安全之策、跨源预检之藏、应答许可、正文解码及完整性之验，乃依可见之界滤其应。内容之策禁其一驿，则主法依网页安全之违录书记令名、见阻之址与原约，而付违规之桥；只报不拦之策亦于此处核之，记为只报之违而不禁其请。目的为 `report` 之报请不受策约，免报牒自触其报。「依策略执行抓取」受内容安全之策；浏览器内资循「执行内用抓取」与「依策略内用抓取」，共其安全之检而存绘制之文。

「模型」具方法、网址、字段、主体与模式诸请属，应则存地址、状态、字段、正文、种类与诊断。「内置协议」理数据网址及内置空白、内嵌之篇，文件之访听调用者所授权。「媒体解码」循既有解码与文件之类，依状态理空文；「过滤」分基本、跨源、不透明及转向之应。

「缓存」依来源与网址分藏，复用超文本响应之藏，备条件复验、重载与禁存。「小饼」循旧藏而依凭据之式定收发。「取消」前后核中止而存首故。「请求元数据」编来源及抓取之牒。「重定向」逐站改方法，涤正文之牒及跨源之凭。

后续之事：全事件流与请求先后之列、缓存依源分区、不透明资源之籍、流式请应、中止信号之页面绑定及官方试集之验。

## 必缄

「必缄」以网页安全之严格传输库接入采书。带必缄之入口受动态之库与取时之术：每驿未发，先稽预载与动态之项；中则易明文为缄道，成种类 internalredirect、状态三零七之内部转向。转向层见其种类即内随，惟易其址，法与文、凭皆守，亦不受转向之式与跨源去凭之扰。缄道回书带必缄首部者，付「登记网页严格传输」，彼惟认缄道、惟录合法之策。

常入口以空升址、空记应代之，其行如故。调用者可依「执行抓取带必缄」「依策略内用抓取带必缄」之式自装配其策。

## 久存缓存

「久存缓存」为网络之交换加一层磁盘之藏（提案〇〇〇五二第一期“记得住”）：「久存交换」依请而处：非 GET 者径付底层；GET 先依址寻于「浏览久存」之缓存册，新鲜（到期之秒在将来）则径以册中之体作答，不涉于网；不新鲜则带 If-None-Match 或 If-Modified-Since 而复验，回三零四则以旧体作答。每中则印一行“磁盘缓存命中：地址”，`久存命中数` 给本程中次之数。

可存之应须二百、有 Cache-Control 之 max-age 或 ETag 或 Last-Modified 之一、且无 no-store：体书于资目之 `缓存体/`，册其记于簿，总量五吉字依最近之用而汰。不可存者去其同址之旧记并其体。Expires 之日期、Vary 之变与范围之请留待后版。
