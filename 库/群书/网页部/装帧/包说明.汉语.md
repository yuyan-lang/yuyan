# 层叠样式

`contain-intrinsic-size` 将单值或双值展开为占位宽高，`auto` 前缀取随后长度；`scroll-padding` 与 `scroll-margin` 按上右下左展开。`text-wrap` 分别识别 `wrap`、`nowrap` 模式和 `auto`、`balance`、`stable`、`pretty` 样式，省略项复原初值。支持查询对常用纯关键字长写逐项核验，并保留通用关键字及含变量声明。

分词入口将回车换行、单独回车及换页归为换行，将零字符换为替代字符；常见输入复用原串。声明解析递归核对坏字符串、坏网址和闭括号，带块艾特规则后继续恢复声明。嵌套中的属性方括号保留 `&` 原文，分组规则名忽略大小写。导入层名称按点分标识符核对。

`animation` 与 `transition` 简写分别展开八项和五项长写，逗号列表逐项保留，首个时间为持续时间、次个时间为延迟；缓动函数、重复次数、方向、填充和运行状态按分组辨认，省略项采用初值。两组简写均接入变量延迟展开。`columns` 展开栏宽与栏数，接受任意次序和 `auto`；`place-items` 展开两轴对齐，接受安全对齐、首末基线与 `legacy`。

数学常数支持 `pi`、`e`、`infinity`、`-infinity`、`NaN`。角度统一为弧度，时间统一为秒，频率统一为赫兹，分辨率统一为每像素点数，与无量纲及长度分别计维。`color(srgb-linear ...)` 依标准曲线编码为红绿蓝颜色并保留透明度。

媒体布尔查询按数值判零，用户偏好的 `no-preference` 判阴，颜色能力按数值比较。支持查询核验简单伪类、伪元素及非空函数参数，并登记 `lang()`、`dir()`。语言选择器接受扩展子标签范围及 `xml:lang` 继承，关系选择器跳过空分支和残缺组合器。`var()` 首参按单个非空自定义属性名核对。级联回退依来源与重要层关系选择较低声明，行内回层保留样式表声明。

颜色计算支持空格分隔的现代 `rgb()`、`rgba()` 和 `color(srgb ...)`。`color-mix(in srgb, ...)` 支持两端百分比、缺省权重与补足权重，按预乘透明度混合；两端权重之和小于百分之一百时，最终透明度同比降低。其他混色空间留待后续版本。

数学值计算支持 `abs()`、`sign()`、`sqrt()`、`mod()`、`rem()`、`round()` 与任意参数 `hypot()`，保持长度维度并核对参数数量；`hypot()` 按最大绝对值缩放后计算平方和。`round()` 支持 `nearest`、`up`、`down`、`to-zero`，默认取最近倍数，中点取较大倍数，单参数采用步长一。

`:dir()` 沿祖先读取方向，`:focus-within` 检查自身与后代焦点；类型选择器支持通配及空命名空间。特异性忽略命名空间前缀，并按大小写无关的伪类名称计算。媒体长度计算补视口单位与 `pc`、`q`。`述样声明`、`述样声明列`、`述样规则`、`述样式表` 提供语法对象的成文入口，篇终缺分号的艾特规则保留为规则对象。

变量依赖图覆盖备用值中的引用，环上成员采用保证无效值；有效空串按已定义变量替换，计算失败与自定义 `initial` 以保证无效的 `var()` 传递。字体简写同步重置十二项字体长写，含变量时一并延迟展开。弹性简写核对负因子、基准位置及重复方向；背景简写核对空层、未知词、重复分组、尺寸和斜线组合、末层颜色。导入核对层与支持条件的修饰次序，并追踪源表地址阻断循环。

媒体范围查询保留完整比例操作数，可计算 `16/9 < aspect-ratio < 2/1`。`:lang()` 沿最近祖先寻找语言并匹配逗号分隔的语言范围，忽略大小写。一般兄弟组合器逐个回溯候选兄弟及其前链；类与属性词包含匹配按全部样式空白分词，结构伪类按完整名称识别。

`outline` 简写沿用边框分量分类，展开轮廓宽度、样式和颜色，重要标志、全局关键字及变量延迟展开传至三个长写。轮廓偏移与盒阴影登记为非继承属性。

`border-radius` 简写支持一至四个横半径及斜线后的一至四个纵半径，依左上、右上、右下、左下展开；省略纵半径时沿用横半径。四角长写初值为零，重要标志与全局关键字传至各角，变量沿用延迟展开。

`background` 简写逐层展开图像、位置、斜线后的尺寸、重复、附件、原点与裁剪，并采用末层背景颜色。单个盒域同时设置原点和裁剪，两个盒域分别设置二者；省略分量恢复初值。多层值保持逗号分隔，重要标志与全局关键字同步到全部长写，含变量声明沿用级联后的延迟展开。完整排列和非法值校验继续完善。

网格放置简写按斜线划分起止值，`grid-column`、`grid-row` 展开为对应起止长写，`grid-area` 按行起、列起、行止、列止展开。缺省端在首值为单个自定义标识时沿用该标识，其余取 `auto`；通用关键字作用于全部长写，重要标志保持。含变量简写复用延迟展开。网格线整数、跨度和标识组合的完整值校验继续完善。

`flex` 简写展开增长因子、收缩因子与基准尺寸，支持单值、双值、三值以及 `auto`、`none` 和通用关键字；省略的收缩因子为1，省略的基准为0%。`flex-flow` 接受方向与换行关键字任意顺序，省略项采用 `row`、`nowrap`。变量简写复用延迟展开路径。

含变量的已登记简写将原始值保留到各目标长写参加级联之后；变量替换完成后再展开，并按目标属性取值。整体边框的默认分量和图像重置同样参与此路径，后续长写声明按原有级联顺序覆盖。

边框简写接受颜色、线型、宽度的任意顺序，展开整体及单边声明；省略项恢复初值，整体声明同时重置边框图像长写。四边宽度、线型及颜色简写沿上右下左展开，保留重要标志和全局关键字。支持查询对展开后的长写核对登记表。含变量简写的延迟展开和完整值校验随后补齐。边框规则参考[背景与边框三级，2024-03-11](https://www.w3.org/TR/2024/CRD-css-backgrounds-3-20240311/#border-shorthands)。

「颜色」默认导入。「样式颜色」复用图像处理的四分量浮点色值，顺序为红、绿、蓝、透明度。「析样式色」接受当前颜色与值字符串，处理十六进制、传统 RGB、全部148项命名颜色、透明色、`currentColor`、HSL、HWB、`lab()`、`lch()`、`oklab()`、`oklch()` 和 `light-dark()`；色相接受数值及角度、弧度、百分度、周单位，分量支持百分比及透明度。「样式取色」先计算前景色，再将当前颜色用于所求属性；`color-scheme` 仅含 `dark` 时选择第二个明暗颜色，嵌套混色沿用同一方案。

命名颜色查层叠属性数据表，十六进制和 RGB 复用矢量图颜色解析器，其八位分量转换为归一浮点值；HSL 与 HWB 复用图像处理的色相算法。`color()` 按预定义色域解码：`srgb`、`srgb-linear`、`xyz`、`xyz-d65`、`xyz-d50`、`display-p3`、`display-p3-linear`、`a98-rgb`、`prophoto-rgb` 与 `rec2020` 各自经转移曲线与矩阵变换到线性红绿蓝，再做白点适应与显示编码；亮甲乙按 D50 三刺激值换算，优亮甲乙按中间视锥响应换算。相对颜色写法 `rgb(from …)`、`hsl(from …)`、`hwb(from …)` 把通道关键词换成源色在目标空间的数值后再按原语法解析，`lab(from …)`、`lch(from …)`、`oklab(from …)`、`oklch(from …)` 与 `color(from … <色域> …)` 接受与源色同号的通道；通道里的 `calc()` 运算留待后续版本。`color-mix()` 在 `srgb` 空间混合，其余混色空间的插值、分量计算函数及完整语法校验留待后续版本。颜色标准锁定为[颜色4，2026-10-09候选推荐草案](https://www.w3.org/TR/2026/CRD-css-color-4-20261009/)。

「数值」默认导入。「样式数值」保存数值与维度，零表示无量纲，一表示长度。「析样式数」计算数字、长度、以指定基准换算的百分比、括号、四则运算及 `calc()`、`min()`、`max()`、`clamp()`；加减和极值比较核对维度，乘除处理无量纲因子及同维度比值。无效组合返回空结果。「析样式长度」取像素长度或无量纲零；「样式取长度」从已级联并替换变量的样式表取属性值后计算。

「样式数值环境」是小数字典，提供字号、根字号、行高、字形度量、视口、容器及「百分基」；缺字段采用「数值常境」。支持绝对、字号、视口与容器长度单位。「竖排」「容竖排」控制逻辑轴；「小视宽」「小视高」「大视宽」「大视高」「动视宽」「动视高」提供分立视口；根字体度量用于 `rex`、`rch`、`rcap`、`ric`，缺省回退既有环境。其余数学函数与完整类型推导随后补齐。标准锁定为[值与单位4，2024-03-12工作草案](https://www.w3.org/TR/2024/WD-css-values-4-20240312/)。

「导入」默认导入。「样式读取器」接收当前样式基址与请求地址，返回可选的「样式资源」；资源保存解析、重定向后的最终地址和正文。调用者负责地址解析、获取与缓存，可用已经载入的资源字典提供读取器。

「展样式引」在当前位置递归展开 `@import`，处理字符串及 `url()` 地址、媒体与支持条件、具名或匿名层。循环按最终地址检查；缺失资源跳过，普通规则之后的导入跳过。展开结果再交给嵌套、条件、层和级联计算。导入修饰的完整语法诊断、失败记录与增量资源更新随后补齐。

「嵌套」默认导入。「展样式嵌套」将规则内的声明与子规则按源码顺序展开；子选择器省略 `&` 时接在父选择器之后，显式 `&` 用 `:is()` 包装父选择器列表，保留列表的最大特异性。嵌套的媒体、支持、层、容器和起始样式块继续带着父选择器展开，交由条件及层装配计算。自定义属性中的花括号保留为声明值。伪元素嵌套和完整错误恢复随后补齐。

嵌套标准锁定为[样式嵌套1，2026-01-22工作草案](https://www.w3.org/TR/2026/WD-css-nesting-1-20260122/)。文档对象在规则装配时调用展开入口，使用者也可单独处理规则列表。

「条件」默认导入。「样式条件环境」用字符串字典提供媒体类型、视口、分辨率、初始字号及设备和用户偏好；「常样式条件」提供屏幕起始值，加载器可替换字段。媒体查询处理列表、否定、布尔组合、上下限、链式范围、宽高比例与方向，以及常用长度和分辨率单位。支持查询处理布尔组合、登记属性的非空声明、自定义属性和选择器函数能力。完整属性值验证、选择器语法验证及媒体非法值诊断随后补齐。

媒体标准锁定为[媒体查询4，2026-02-19候选推荐草案](https://www.w3.org/TR/2026/CRD-mediaqueries-4-20260219/)。条件规则采用[条件规则3，2024-08-15候选推荐草案](https://www.w3.org/TR/2024/CRD-css-conditional-3-20240815/)与[条件规则4，2025-09-04候选推荐草案](https://www.w3.org/TR/2025/CRD-css-conditional-4-20250904/)。文档对象在装配时递归筛选条件规则，环境改变后重新计算即可更新结果。

本包以纯豫言实现层叠样式语法。默认导入「词法」「语法」。词元保存种类、解码值和原文；标识符与字符串处理转义，数值支持指数、维度与百分比，注释从词元流移除。扫描器的位置是全文里的字节位置，总落在通字符的起点上；取字符、前进与切片都是常数时间，整段分词因此是线性的。名字与引号字符串先按字节扫出连续区间再一次切片；字符串里没有大写 ASCII 字母时，小写转换原样返回。

默认导入「散列表」。「串整散表」「串串散表」按键的字节散列到固定数量的桶，查找近似常数时间，同键有多项时得最晚插入的一项；文档对象的样式引擎用它们给规则建索引并缓存值的规范化结果。

组件将括号、方括号、花括号及函数递归分组；规则保存艾特名称、前奏和可选块。声明保存属性名、组件值和重要标志；自定义属性名保留大小写。无效声明跳到下一分号恢复。

「树观」「择器」默认导入。抽象树视图提供父子、前元素兄弟、名称、命名空间、属性与状态查询，零表示空句柄。选择器从右向左匹配类型、通用、类、标识、属性与四种组合符；属性支持存在、六种比较及大小写标志。支持选择器列表、`:scope`、结构伪类、`:is()`、`:where()`、`:not()`、`:has()` 和带 `of` 筛选的序号公式。交互与控件状态由使用者提供。

选择器标准锁定为[选择器4，2026-01-22工作草案](https://www.w3.org/TR/2026/WD-selectors-4-20260122/)。后续补命名空间前缀绑定、自动文字方向与完整解析错误。文档对象实现树视图，并提供匹配、最近祖先和单个或全部查询入口。

「择器伪件名」拆出选择器分支末尾的伪元素（`::before`、`::after`、`::marker`、`::first-line`、`::first-letter`、`::selection`、`::placeholder` 等，旧式单冒号的 `:before`、`:after`、`:first-line`、`:first-letter` 也算），返回（伪元素名, 去掉伪元素的分支）；没有伪元素时返回（可无, 原分支）。带伪元素的分支在普通元素匹配里不匹配，由文档对象按伪元素另行匹配；特异性把伪元素计为类型。

「特异性」「简写」「级联」「变量」默认导入。特异性采用标识、类属、类型三项比较；逻辑伪类取参数的最大值，`where` 取零，序号伪类加上筛选参数的特异性。级联按重要标志、来源、行内、层、特异性与源码顺序择胜；重要声明反转来源和层顺序。来源零为用户代理，一为作者；层零表示无层，其余按声明先后编号。

「装帧谱」提供初值、继承与简写映射。支持 `initial`、`inherit`、`unset`、`revert`、`revert-layer`，以及外边距、内边距、定位边界、溢出和间隙的简写。变量按大小写敏感的名称递归替换，支持后备值和循环检测，嵌套函数与块一同处理。计算结果保存属性值字符串，长度、颜色与使用值换算继续实施。计算样式按稀疏表存：只存与初值不同的项，每个属性一项，末尾放一个空键作标记；「样式取值」先查这张短表，碰到标记还没找到就从全局初值散表（第一次用到时由属性表建成）取初值，手工拼的样式没有标记，查不到得空串。继承从父样式取可继承的项，同名只取最新的一项；「属继承」查全局继承散表。父元素声明的颜色、字体、字号等沿子树继承。

`list-style` 简写按词分开位置（`inside`、`outside`）、图像（`url(...)`）与类型，缺省的长写取初值，单个 `none` 令类型与图像都为 `none`。`font` 简写：字号之前是样式、变体、字重、字宽（任意次序，缺省为 `normal`），字号可后接 `/行高`，其后全部是字体族；七项直接分量与十二项重置属性共同接受全局关键字，含变量时随变量替换后再展开。有效简写含字号与字体族；系统字体关键字留待后续。
