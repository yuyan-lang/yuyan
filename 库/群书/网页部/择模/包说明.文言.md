# 字体选取

「网页选字定」并还字体、字形号及字体来源键。其键取集合内注册字面之身份或本地字体族，供网页排版合字体链、定码点之择；集合复注册，则复立排版之果。

版：0.1.0。标准定为[字体4，二零二六年九月十三日工作草案](https://www.w3.org/TR/2026/WD-css-fonts-4-20260913/)。

此包供字体族列、通用族映射、字宽字形字重之匹配、字体描述注册、码域筛选、按需载入、逐字回退及字体之度。

「收网页字面」读样式规则之 `@font-face`，存族、字重字宽之域、字形、码域、`src` 本地或远程来源、格式技术之提示及显示描述。「新网模集」受本地数据源、远程字节之读取器；「登网页字面」更注册表而清其藏。「网页选字」依所求之族链择码，按需读取、解析而藏字体，还字体及字形号；链末加无衬线、表情、符号之回退。表情之字（统一码扩展象形、区域指示符与肤色修饰符 U+1F3FB 至 U+1F3FF），先以彩色表情之体列于族链之前，依「Noto Color Emoji」「Apple Color Emoji」与通名「emoji」三族为识，次循所求之族链；`font-variant-emoji` 之 `text` 与 `unicode` 二向，列于后续之事。远程地址之基址解析、安全之察及抓取，由所授读取器司之。

「网页寓字样源」复用操作系统字体接口，分段读系统字体。「样式字样索」自计算样式取族、字重、字宽、字形。「网模取度量」依字号缩上升、下降、行距，读小字大字之高、零字水字之宽；「字样度量数境」接于样式长度单位之算。

「特性」默认导入。「样式字样特性」化字距、连字、大写、上下标、数字及东亚变体为特性之开关，低层 `font-feature-settings` 覆高层属性。「析字样标签设」存四字标签及其数；「启字样特性」列今整形器所用之启用签。「样式字样轴设」以字重、字宽、斜体、斜角、光学字号映为轴值，`font-variation-settings` 最后覆之。「网模轴坐标」循字体轴表之序成十六点十六定标，缺者取轴常值，约于字体轴之域。「网页样式整形」以样式特性、轴标授文字整形库；字号用像素，光学字号轴乘四分之三以为点。

粗体之面：「网页字体定位」带「粗体」之志，示所选之面本身已粗，绘不复仿粗。所求字重六百以上，本地字体（含通用族所映之名）先试宿主「族名加粗体」之面（接口规范之 `无衬线粗体`、`衬线粗体`、`等宽粗体`），得之且兼所需之码点则用之（键为「本地粗:族」，志为阳）；宿主无此面或无此码点，则返常规之面（志为阴），由绘错廓重描以仿粗。所录之面（`@font-face`）依字重之域上限是否在六百以上而标粗体；字重之域依旧则匹配，可变字体之字重轴由样式之轴设驱之。

「字体源可读」于索源之前审其格式、技术。格式受 `truetype`、`opentype`、`collection`、`woff`、`woff2`；技术受 `features-opentype`、`variations`，诸技皆合乃读。题签空者委字体解析而断。源有所未能，遂循后源；远程读取器惟受相合之请。

后续之事：精确斜体之匹配及字宽小数、通用族依语言之设、系统同族多面之列、字簇回退、显示时序、字面描述特性优级、特性替代序号、命名变体、度量覆盖、合成及调色板。集合藏解析之果及读败；字之请求果藏，续接之。

表情选字之口核扩图形与肤色修饰皆先取表情族列、非表情之码仍先取所求族列；选字之验须由发行绑系统字体接口；常无绑定客体由全树测试验类。本机以既有诺驿发行适配实跑本地字体。字面「身份」于同集内独一；一次收样式表则自分之。

| 标准成员 | 豫言成员 |
| --- | --- |
| font-family、font-weight、font-stretch、font-style | 网页字体请求之族列、字重、字宽、字形 |
| @font-face、src、unicode-range、font-display | 网页字面之来源、码域、显示及匹配描述 |
| ascent、descent、line-gap、x-height、cap-height | 网页字体度量之上升、下降、行距、小字高、大字高 |

「收特性值」循文而收 @font-feature-values 之名录，族、类、名皆裁两端之白，藏于「特值录」；一文档之内累加，同名后登者掩先登者，跨文档之清由载者于装配字体集时为之。「字样变体函数设」以变体函数之数或名易为 salt、ss0n、cv0n、swsh、cswh、ornm、nalt 之标：一函数可带逗号分隔之数名，swash 兼启 swsh 与 cswh，逾一之序随签授整形，依值取对应之替。「启字样特性」列启用之签，并以签值之对授替序之录。
