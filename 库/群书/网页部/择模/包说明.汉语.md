# 字体选取

「网页选字定位」在选字结果中同时返回字体、字形号和字体来源键。来源键采用集合内的注册字面身份或本地字体族，供网页排版合并字体链并固定码点选择；集合重新注册后重新建立排版结果。

版本：0.1.0。标准锁定为[字体4，2026-09-13工作草案](https://www.w3.org/TR/2026/WD-css-fonts-4-20260913/)。

本包提供字体族列表与通用族映射、字宽/字形/字重匹配、字体描述符注册、码域筛选、按需加载、逐字符回退及字体度量。

「收网页字面」读取样式规则中的 `@font-face`，保存族、字重与字宽范围、字形、码域、`src` 的本地或远程来源、格式与技术提示、显示描述符。「新网页字体集合」接受本地数据源和远程字节读取器；「注册网页字面」替换注册表并清空缓存。「网页选字」按请求的族链选取码点，按需读取、解析并缓存字体，返回字体与字形号；末尾追加无衬线、表情和符号回退。远程地址的基址解析、安全检查及抓取由传入的读取器处理。

「网页系统字体源」直接复用操作系统字体接口，按段读取系统字体。「样式字体请求」从计算样式提取族、字重、字宽和字形。「网页字体取度量」按字号缩放上升、下降、行距，读取字体小字高与大字高、零字和水字的宽度；「字体度量数值环境」接到样式长度单位计算。

「特性」默认导入。「样式字体特性」把字距、连字、大写、上下标、数字与东亚变体转换为特性开关，低层 `font-feature-settings` 覆盖高层属性。「解析字体标签设置」保存四字符标签和数值；「启用字体特性」给出现有整形器使用的启用标签。「样式字体轴设置」把字重、字宽、斜体、斜角和光学字号映射为轴值，`font-variation-settings` 最后覆盖。「网页字体轴坐标」按字体轴表顺序生成十六点十六定点坐标，缺省用轴默认值，并限制到字体轴范围。「网页样式整形」把样式特性和轴坐标传入文字整形库；字号以像素计，光学字号轴按四分之三换算为点。

粗体字面：「网页字体定位」带「粗体」标志，说明选中的字面本身已是粗体，绘制不再仿粗。请求字重在 600 以上时，本地字体（含通用族映射后的族名）先试宿主的「族名+粗体」字面（接口规范里的 `无衬线粗体`、`衬线粗体`、`等宽粗体`），取得且含所需码点就用它（键为「本地粗:族」，标志为阳）；宿主没有这个字面或没有这个码点时回到常规字面（标志为阴），由绘制把轮廓错开重描来仿粗。注册字面（`@font-face`）按字重范围的上限是否在 600 以上标记粗体；字重范围按原有规则匹配，可变字体的字重轴由样式轴设置驱动。

「字体源可读」在读取来源前筛选格式与技术提示。格式支持 `truetype`、`opentype`、`collection`、`woff`、`woff2`；技术支持 `features-opentype` 与 `variations`，多项技术全部满足后读取。空提示交给字体解析器判断。能力未匹配的来源直接继续下一来源，远程读取器只接收能力匹配的请求。

后续事项：精确斜体匹配及字宽小数、通用族的语言配置、系统字体同族多字面枚举、字符簇回退、显示时间线、字面描述符特性优先级、特性替代序号、命名变体、度量覆盖、合成与调色板。字体集合缓存解析结果与读取失败；字符请求结果缓存随后接通。

选字冒烟需要发行流程绑定系统字体接口；普通无绑定客体由全树测试检查类型。本机通过现有诺驿发行适配实跑本地字体。字面「身份」在同一集合内唯一；一次收集样式表时自动分配。

| 标准成员 | 豫言成员 |
| --- | --- |
| font-family、font-weight、font-stretch、font-style | 网页字体请求的族列、字重、字宽、字形 |
| @font-face、src、unicode-range、font-display | 网页字面的来源、码域、显示及匹配描述符 |
| ascent、descent、line-gap、x-height、cap-height | 网页字体度量的上升、下降、行距、小字高、大字高 |
