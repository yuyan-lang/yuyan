# 页面几何源

这是网页榫卯几何源的排版实现，供浏览器应用与网平测脚本测试共用。

- 布局境记下资源读取器、基址与字体集合；视口尺寸每次从网页榫卯的「网页视口尺寸」现读。
- 同步时按「篇变更计数」与滚动变更计数判断缓存是否可用；不然求样式（「篇求样式」）、造盒树、排版，并把盒树记进缓存。
- 查询：元素外框、各片段矩形、偏移与偏移父、内容尺、滚动位、设卷（按可滚范围夹取，写「网页舒卷位表」）、可滚内容尺、滚入视野。
- 滚动位变了记下待派滚动，浏览器在下一帧派发「scroll」事件。

浏览器应用在启动时用「页几何装」登记；网平测脚本测试在载页前登记，载页时脚本读几何即可得到真实排版。

后续版本的事项：点命中与多点命中（elementFromPoint、elementsFromPoint，循显示列表、与点击命中同一条路）；GeometryUtils（getBoxQuads、convertPointFromNode）。
