# 网页转设计

把网页静态页面和已稳定的网页文档编成设计作品。作品保存当前视口的路径、图层、遮罩与图像素材，可用设计树码保存、验证和播放。

`网页页面图作品` 接收网页绘制结果，纯色填充直接写原始路径命令（保留二次、三次曲线，坐标六位小数，见「曲线保存」），不透明、源上混合、无过滤无蒙版的绘制组直接展开，其余情形沿用显示元转换；`编译静态网页作品` 复用网页载入的资源、字体、样式与布局，`编译网页文档快照` 接收调用方已稳定的文档树。视口尺寸决定画幅。图像元（蒙版与非纯色颜料填成的图像）保存成图像节点，仿射的平移成为节点变换的位置，所以只取包围盒那么大的图像经设计树码往返后仍回到原位置。

`网页页面图动画作品` 按指定时长和步长采样合成动画，保存自带图像素材的设计视频，保持信号决定各帧出现的时刻。动画作品可以经设计树码往返保存并重放。

`编译网页节点动画` 把层叠样式动画自动绑定到各网页节点：布局按动画底样排一次，每个带动画的节点编成设计「合成节点」，变换六分量、透明度、模糊与颜色矩阵作为信号原样保存，播放时逐帧求值；没有动画的节点保留静态变换。

动画逗号列表逐属性合成，同一属性由列表后项覆盖；较短的长写参数列表循环对应各条动画。延迟、有限与无限迭代、分数次数、正放、倒放、交替、反向交替、四种填充与初始暂停都保存为可序列化的属性信号。父子节点沿用各自的页面时刻。

动画名称在长写、短写与关键帧声明中支持引号字符串，并按词法解码后的名称匹配；引号内的缓动、方向与填充关键字也可作动画名称。

零时长动画在延迟结束时进入结束阶段，依方向及迭代次数确定结束状态，并按前向或双向填充保留；延迟期间按后向或双向填充显示起始状态。简写中首个时间值为时长，零时长同样保留此位置。

关键帧同刻声明逐属性级联，同名动画以后定义者为准；缓动支持标准关键字、贝塞尔曲线及阶跃，并按起帧声明选择逐段缓动。二维变换分解为平移、旋转、伸缩和剪切，旋转沿短弧，每段采样六十四点后保存矩阵信号。连续高斯模糊按半径平方和开方合并。

节点动画的 `transform-origin` 按自身关键帧建立横纵原点轨，独立补齐首尾并采用各段缓动；逐时以原点位移修正变换平移分量，支持原点和变换采用不同关键帧时刻。跨动画列表的原点与变换逐属性组合留待后续版本。

图像节点保存完整六分量仿射及透明度。中心圆弧转换为标准端点圆弧，整圆及多圈按半圈切段后直接保存路径。开发工具包「网页设计」提供本地网页及关联资源导出设计作品的命令入口。

`animation-composition` 支持循环长写列表。`add` 将透明度相加，仿射矩阵和颜色矩阵按底层到动画的顺序复合，高斯模糊按半径平方和开方合并。`accumulate` 将透明与模糊相加，矩阵逐项相加并扣除单位阵，适用于平移与轴向伸缩的累积。合成结果保存为设计表达式，并沿用每条动画的填充与时序。

`linear()` 支持带百分比位置的折点，并以四千零九十七点采样保存；等距裸数列保留原值。全局 `steps()` 的 `jump-none` 与 `jump-both` 已接透明度和滤镜原始轨。图层保存色阵、模糊及阴影的顺序，父溢出裁剪保持在子节点动画之外。

变换与变换原点的采样轨支持全局 `steps()` 的 `jump-none` 与 `jump-both`，各属性按自身原关键帧区间计算阶跃时刻，再读取分解矩阵轨。
