# 网页载入

载页受页面接口之主录（采书之交换、本地与会话之簿、持久之诺），设共享脚本之境时，先绑 `document`，次装窗位、页面诸器与网页剪拖，页脚本由是得 `DataTransfer`、`ClipboardItem` 与 `navigator.clipboard`。试与无壳之场，用「网页榫卯」之 `无壳交换`、`新储籍簿` 及 `页面空持久` 以充主录。

外部常篇与模块本篇循 `integrity` 之属验原始资源字节，验合乃依脚本之类解之；完整性不合则循旧载败之路记而越之。

模块本篇及所依皆用八位统一码。常外篇与样式之资，先取字节序标，次循资源编码标签及媒体牒之参数，终用八位统一码；传输编码之空值可越而求后。承自应用之远程字体，仍归原集之读取器；页面新字则循页面之源。

资源之藏去请求之片段，以请求与应答终址共其主体，还资则存本次之片段；读败者容后复求。应用与页面之字面合而序其身份，藏字据此辨源。

传输编码受标签及全媒体之牒；依次析其参数，引内分号与反斜线之引皆存，首见 `charset` 则用之。模块之载受绝对网址与 `/`、`./`、`../` 之径，裸名留待后续；以应答终址为模块之识及后引之基，页面常篇与模块所依共用资源之藏。

普通页面脚本成或异而终，行微任务检查点（「网页微役察点」：捷思期约之作业与文档之微任务），使脚本所排之微任务先于后续脚本毕；回调之异循文档任务诊断。

外篇存应答之终址，模块相对之引依转向后之址而解；执行诊断亦以终址告之。脚本未承之异按籍取真而述其文：误物则名与消息，余值则其字面；主自抛之文仍其旧。

`行网页脚本资` 依调用者所授之序于共享捷思境行脚本，还诸脚本之地址、可选结果及诊断；载入之败及脚本之异各记之，后续脚本续行。常脚本全段而行；模块脚本以脚本之址为规范键，经「网页篇载器」（说明符依引用者之址而析、源码经页面资源之读取器取之而解码、皆严格）载其所依而后行。「行网页篇脚本」先行不延后之常脚本，乃依文档之序行延后之常脚本与模块脚本，终于文档派 DOMContentLoaded 与 load。导入之映射、裸说明符、页面解析之阻及安全之检，留待后续之版。

`载网页脚本` 依文档之序收内嵌及外部脚本，解相对地址，复用资源缓存及文本解码。诸项存地址、可选正文、外部、异步、延后及模块之标；载入之败以空正文记之。捷思媒体之名通大小写，兼收旧牒；无类型则取 `language` 之属，明定类型则涤首尾之白，`module` 守本字。模块既具，带 `nomodule` 之常篇不采。内嵌常篇守其常序，外篇 `async` 先于 `defer`，异步模块列于先行之队。解析之阻、依就绪之异步调度及安全之检，留待后续。

静态载入受应用所授资源读取器，读取器依绝对地址还最终地址、原始主体及编码之名。载入器析文档与首基址，依视口条件载内联及外链之样，装配计算样式与图像读取器，图像读取器依视窗宽高及像素之比自 srcset、sizes 与 picture 之 source 择当前图源，成布局及绘制。资源依地址藏之，图像及矢量图诸资源同由读取器取之。页面结果存地址、基址、文档及页面图。

接口之行依网超组超文本标记之文档载入与网址解析算法渐接之。网络及文件之访由应用授，纯算之路诸后端共之。

外链样式依响应之最终地址递归改写 `url()`，含嵌套规则、变量之值及字体来源。内联及文档样式之计算值依文档基址改之，节点原始之属存焉。背景图遂循所属样式表之地址，重定向后之样式表依最终地址读相对资源。

展有效媒体、支持条件及层规则而集 `@font-face`，合应用已有字面，成独立页面字体之集。远程来源网址依所属样式之址析之，字体字节循页面资源之藏按需读之；本地字体循应用本地之源取之。页面结果存字体之集，供后续布局及绘制复用。

「嗅探网页码」先字节序标记，次所支持之传输编码，次元声明，终缺省编码，以择文档之编码。元声明预扫首千二十四字节（超文本标记包之「预扫码」，行于字节，循规之预扫之算），受 `charset` 及有 `content-type` 令之 `content`；十六位统一码元声明取八位统一码，用户自定编码取轩窗西文编码。缺省用八位统一码。「解网页篇」依所择编码解之；样式诸资源仍依各自传输编码。依据：[超文本标记规范13.2.3.2](https://html.spec.whatwg.org/multipage/parsing.html#determining-the-character-encoding)。

`image-set()` 及 `-webkit-image-set()` 之字符串候选，循所属样式表之终址，展为绝对 `url()`；候选之分辨率、类型与嵌套图像函数皆存。所成网址之串，饰双引、反斜及换行。

后续事项：父文档编码继承、迟至声明复启、字体载入之态及异步复排、脚本调度、安全策略、导航历史及异步资源失效。
# 文档脚本之境

「行网页篇脚本」为既成文档设页面脚本之境，以 `document` 绑定此文档，依文档基址收资源，于共享之境行普通脚本。其返者为环境、文档绑定及诸项执行之果；脚本改节点，则原文档随之。「载网页」于文档既解、读样式与渲染之前，行页中之常脚本（内嵌及外部，依文档之序），脚本所改入于渲染，诸故逐印而照常渲染；「载静态网页」不行脚本，二者共用「载网页带篇理」。每脚本之步数上限取「网页脚本步限」（默认十亿），事件之听与定时器之回调亦取之。定时器由库「网页榫卯」之定时器模块录之，宿主依页面之时钟行之。解析时之调及安全之策，留待后版。

页面接口之主带「媒体」一项：接引以主者原样交「安装网页接口」，由榫卯媒体之接线书于篇象媒体主之匣；无壳之试用「无媒体宿主」充此一项。
