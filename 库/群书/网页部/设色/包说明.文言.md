# 网页绘制

设计之显示元，依过滤之序，存晕与影为层，录其标差、移与色；既存为作品，由设计之渲染器求之。余色效逐项施于像，效影相承之序如故。

`mix-blend-mode: plus-lighter` 合源与底之乘色及显度，各限于一。组之隐显先施于源；设计之出存全树实合之象。

显示项藏文字与字族，以待后用。后续事项：文字之义入设计之作。

`析网页合成关键帧` 读样式表之 `@keyframes`，以百分比、from、to 及声明编为定时样式帧；`造网页合成动画` 以变之六分、不透明、糊及色滤之阵编为设计信号。`网页合成动画映元` 依所予之时求值，径授引擎之仿射、图层色阵及糊。布局之属由网页复算处之。动画之帧依时而序。变之分解、投影连续轨及诸糊之序留待后续之版。

网页显示表经 `网页映列匠心元` 出设计引擎之填充元、图元及图层之遮；绘制组经 `网页绘组匠心元` 出设计图层，其不透明与已具之混法由引擎合之。旧栅格、页面及脏区之入口复用此出。网页节点、径及命中之资存于网页显示表。繁颜料、过滤及引擎后续所接之混法，以图元存当前参考之果。奇偶则之蒙版（外影、边框环之裁）填为图元时，图唯取径包围（外扩二素）之大，以整数平移之仿射置回于布，包围中之素与整幅渲者同；包围不可得，则退回整幅渲。非纯色之料填径所得之图元（`网页颜料径图像匠心元`）亦唯取径包围之大之图，遮与着色皆于小图为之，取色之位加包围之偏，故与整幅着色之果同。外影（`box-shadow`）以裁域左上为原点，唯于影之包围处之：源形之径界外扩二素，与其依偏而平、依糊径而外扩之域相并，夹于布外扩“移加糊”之域（布外而影偏入之源亦计之），影不入布则不画；源形之渲、偏移与高斯糊皆于此小图为之，复以平移之图案料填同大之矩，包围之外源与影皆全透明，其果与于宽布整幅而处者同，影项终乃整移还于裁域之位。内影则整幅而处。

交设计引擎之填依 0.05 素平展（`网页匠心容差`）；字形与显项之移变存其曲（`矢量字形曲线径`、`保曲变换径`），至此乃依素平之。裁框覆全画布之显项、不透而源上混之绘组，不复裹图层，全页渲染之离屏与内存因以减。直角之蒙版（圆角为零之溢出裁剪）包项之域，亦不开图层；纯色之料随变换仍为纯色，不裹为变换之料。

多选控件逐项存换行，活动行循控件自显之路；路径与行片同移，点击仍依可见之位择其项。基本之饰予多选控件四行之高。

文本控件依插入符或今选区之末而自显内容，横纵溢出则移文字之径及行片；选区与插入符读已移之矩，内容框持其裁。反向选区之活动端、旧偏位之持、手滚及缘边拖动之自滚续施之。

文本域保空白而自动断行，依段落之行录文及矩，换行之字计入控件原偏。选区及插入符读诸行之录，空值存一行定位之矩。逐字形之推进、换行字之精细宽、双向范围及内部滚动续施之。

文本控件共用文字选区之饰：即时值定其范围之长，字体排版录行宽与行高，内容框裁背景、选中字色及插入符。插入符宽一素，依其颜色之样式；选区复用蒙版染色。字符之位依全行宽按比例计；逐字形之推进、多行范围之映射、插入符之闪及控件内滚动，续为之。

表单控件展示之文读即时值，空输入显占位之文，密码依字数显遮蔽点，选择控件显所选项之文。复选及单选之勾态绘为内标，文字、标、边框与底色共用滚动、裁剪及变换之径。光标、组字、选区及精细之饰续施之。

图像读取器于普通图像解码败后试解矢量字节，受 SVG 根元素，依根尺寸栅格，共用地址之藏。内联 SVG 序列为矢量文档，诸子由矢量图库一并绘之；图像盒树清其替代盒之布局子盒。替代之节各依其源取图：`img` 依 srcset 与 src 择源，`video` 取 poster，`embed` 取 src，`object` 取 data；svg 之节由外标记栅格，画布之节取「画布态」所藏之位图。图之址受 `data:` 之网：依逗分其 MIME 与数据，MIME 空或以 `image/` 始者受之，带 `;base64` 者以卦文解，余以百分号解；`img`、样式之 `url()`、背景图与遮罩图共此一处。四道之果与自然宽高书于盒树，`video` 之海报尺寸亦记为自然尺寸，供对象适配与布局取之。宽高缺省取三百乘一百五十，外部嵌图循应用资源回调读之。无固有之寸而唯有比例之矢图（根为 svg 而宽高之性俱缺），于读图之处记为「无固有之寸」，盒树书样式 `网页资源无固寸`，供对象适配之 scale-down 取 none 一侧。栅格之尺依矢图固有之则：宽高俱为绝对值者取原值；一边为绝对值、另一边缺或为百分比而根有 `viewBox` 者，另一边依视框之比例算；两边皆不可定者用三百乘一百五十，宽为百分比而高为绝对值者宽取三百。读图之时又依址记 EXIF 之向；`image-orientation: none` 者，「网页正图」以向之反旋其已正之图，「网页纳宽」「网页纳高」以未转之寸改书盒树自然宽高；背景图像层经「网页正图址」与「网页址纳宽」「网页址纳高」同之。`content` 为 `url()` 或字符串之元素盒依替代之容布局：盒之图读器（「网页盒图读」）造暂 img 节取图，「网页标内容」书自然宽高于样式；伪元素之盒（节名以「::」始）暂不接入，仍依宿主之节取图。画布位图裹为四色八位之图，依盒尺寸绘之而依对象适配裁之。图像及背景图仍用既有对象适配、裁剪及采样。地之图层遇无固有之寸又无固有之比例的矢图者，依地尺寸复栅，矢中百分比随绘寸而解。内联文档继承之样、字体接线、内联结果之藏及自然比例全推，后续接之。

「重绘网页区域」受旧图、新绘制组及脏矩形之列，区界向外取整，裁于旧图之界。组无过滤则移至区内之坐标，唯栅格其区；有过滤则栅格全图以取邻域，而后截其区。新像素径易旧者，透明之像素可除旧内容，区外存旧图。「重绘网页盒页」复用调用者已更布局之盒树，复成绘制组，乃摊之为显示列表（「网页绘组映列」，盒树唯遍一次），返更新之页面结果。「舒卷重绘网页盒页」于页唯纵滚整数之素时移旧图，唯重画所露之条、右侧十六素宽之一列（视口滚条）及向上滚时底边十六素高之一行（「网页页块重画」依块生绘制组，距块甚远之盒不生显项），显示列表留空，命中时由「网页页整幅映列」依全幅补之。自集脏区及中间图层之缓存，后续接之。

「设网页文字选区」依文字节点存字符之域，域重合则显插入符，「清网页文字选区」除其态。选区依视觉行序列文字片段，依片内字符之数分宽，生背景及白色文字前景；插入符用 `caret-color` 或当前文字之色，换行之界取次片段。「设网页绘焦点」择焦点节点，焦点环循圆角边框向外扩之。交互之饰与所属内容同滚动、变换、裁剪及合成。实字形之推进、双向之域、空白偏移之映、跨节点之控、闪烁及状态回收，后续接之。

后代之内容依容器滚动之位平移，而后施容器溢出之裁；每盒所受之裁域先易于其自身之坐标（变换与滚动之前，「网页逆变换裁剪」），显项之矩与裁随项变回；盒之边框外扩百素犹不与裁域相交，则不生其自项；显示列表及绘制组共用其移，命中取已移之径及版。背景、边框及轮廓存于容器之位。自动溢出、显式滚动及视口绘覆盖式滚动条，滑块之长与位依内容之比计之；`scrollbar-width` 受默认、细及隐藏。滚动条之拖、固定定位后代、局部背景附件及颜色样式，后续接之。

图像及背景图依实绘之尺寸预缩之，默认施兰索三重采样；透明色先预乘，采而后还原。`image-rendering` 可继，`pixelated` 及 `crisp-edges` 以原图最近邻映之，余值施平滑采样。对象适配、背景尺寸及图案坐标，循同一目标矩形。分数尺寸、变换后采样之迹、缩放之藏及像素化整数倍过渡，后续详之。

「新网页字形读者」藏字体单位之原轮廓，以字体文长、所选字面表目录及字形号辨其项。文字绘读者于诸片段、显示列表及绘制组间共用此藏；读轮廓而后同变字号、纵轴之向及位置。复立读取器，即可释整批之藏。可变字体实例之身份及布局整形结果之藏，后续接之。

`text-shadow` 受多层颜色、横纵偏移及模糊半径，省色则用当前文字之色。影取字形及装饰线透明之形而生，前宣之层覆后者，继绘正文及装饰。文字之影继其样式，与所属盒同参与变换、裁剪、过滤及合成。分数偏移及视口外源图扩展，后续详之。

文字之饰受下划线、上划线及删除线，施实线、双线、点线、虚线或波浪线。`text-decoration` 简写展线种、样式、颜色及粗细；粗细及下划线之偏移，受长度及字号百分比；`text-decoration-inset` 之起止内缩受长度与百分比（百分以片段之宽为基，单值兼两端），负者外延。诸文字片段各生装饰路径，与正文同参与裁剪、变换、过滤及合成。祖先之饰依盒树而传、补画之（越原子行内、浮动及绝对定位之后代），字体度量、避字形、跳空格及竖排，后续接之。

`clip-path` 受圆、椭圆、多边形、内缩矩形、四边坐标矩形及位置尺寸矩形，矩形受圆角。长度、百分比及位置，依边框盒、内边盒或内容盒计之。裁施于全子树过滤之果，显示列表及命中查询共用其形，形随盒而变。旧式 `clip` 惟绝对与固定之盒受之，`rect(上, 右, 下, 左)` 之四边可为 `auto`（取边框盒之边），余以长短或百分（上下依高，左右依宽）。形版皆以一律填径算其边覆，圆角与裁形之边不复两相乘。路径字符串、矢量图之引及专用参考盒，后续接之。

`mask-image` 借地资层片之尺寸、位置、重复与参考盒之制，读为一张掩图：`mask-size`、`mask-position`、`mask-repeat`、`mask-origin` 与 `mask-clip` 逐层相当，掩图之布取 `mask-clip` 之盒；`mask-mode` 为 `alpha` 或 `match-source` 者取透明，为 `luminance` 者以明度乘透明而为白图。多层之掩自下而上依 `mask-composite` 合之：`add` 者上透加下透乘一减上透，`subtract` 者下透乘一减上透，`intersect` 者两透相乘，`exclude` 者两透相加减两倍乘积。掩依组乘入画面：掩外之素全虚，掩内逐素乘其透明。带掩之绘组全组合于画布，掩依组变前之坐标置之。`mask-image` 为 `url(#号)` 者依文档中 SVG `mask` 之元素而渲：取其子节为同盒宽高之矢量图，`mask-mode` 为 `match-source` 者依 `mask-type` 取明度或透明，既成乃乘入画面。`mask` 之简写由装帧依层展为八项长写，`maskUnits` 为 `userSpaceOnUse` 者依掩区像素给 `viewBox` 对齐。`maskContentUnits` 为 `objectBoundingBox` 者依零至一之 `viewBox` 解内容坐标；`mask-origin`、`mask-clip` 之 `fill-box`、`stroke-box`、`view-box` 依内容之盒或边框之盒归约，行内之盒多片者逐片取层片。滤镜区域之裁切，后续接之。

边框及轮廓受实线、虚线、圆点线、双线、凹槽、凸脊、内凹及外凸。虚线及点线循圆角中线分段描边，而以内外圆角之环裁之；双线以三分之宽成两环。凹凸之线依四边之向分明暗，凹槽及凸脊于半宽易色。同色实线合绘之，余边分侧绘之。轮廓绘于后代内容之后，继参与全子树之过滤、不透明度及混合。诸边虚线之均分及异色交界之抗锯齿，后续详之。

`box-shadow` 受多层颜色、横纵偏移、模糊半径、扩张及内影，省色则用当前文字之色。影之形循椭圆圆角，外影除边框之内，内影裁于内边盒；前宣之影覆后者。`outline` 简写展宽度、样式及颜色，轮廓偏移于边框外成圆角之环，`inset` 取负宽度入于边框之内；实线之廓分上下左右四矩形带而绘（内外之缘皆直角，不受圆角蒙版之制），虚、点、双则依边框四侧之梯形而裁、共带一圈角之环蒙版（点距圆帽随圈，与边框之参照相合）；表列与列组不生轮廓（二者不生盒）。行内逐片之饰、分数阴影偏移及视口外影源，后续详之。

`filter` 依宣之序施于全绘制子树，受模糊、投影、亮度、对比度、反色、灰度、棕褐色、饱和度、色相旋转及透明度。色之分量于红绿蓝透明图像中换之，模糊复用预乘透明度之高斯法，投影取子树透明之形，合于原图之后。祖先溢裁之版施于过滤之后，继施组不透明度及混合。过滤之局部变换坐标、分数投影偏移及视口外源图扩展，后续接之。

二维 `transform` 受六数矩阵、横纵平移、缩放、旋转及斜切，依宣之序合之。平移百分比以参考盒之宽高为基，`transform-origin` 受位置之名、长度及百分比；`transform-box` 为 `content-box` 或 `fill-box` 者，参考盒取内容盒，余取边框盒。`scale()` 受数及百分比，诸长度单位依本盒字号折之。全盒及后代之路径、圆角蒙版、命中之域俱变，颜料以逆阵取色；视口之裁存于输出坐标，祖先溢裁之版随其盒而变。奇异之阵除子树之绘及命中。

三维之变，铺四四之阵：`matrix3d`、`translate3d`、`translateZ`、`scale3d`、`scaleZ`、`rotate3d`、`rotateX`/`rotateY`/`rotateZ` 及 `perspective()` 各成其阵，二维诸名仍用六数而铺为四行；`transform-origin` 之三分作深，`translate`、`rotate`、`scale` 三独立之属依“先移、次转、后缩”居 `transform` 之前。`perspective` 与 `perspective-origin` 于盒取视距及视原，以其子盒之透视阵施于子盒；视距不足一像素者，依规范夹而为一。阵以父盒之透与本盒之变相乘；得仿射者仍循二维之途，带透者其全枝先依本盒之坐标栅格为一层，再以投阵反求其源而定色，轴齐之投取最近之素，余则双线，画于父层之画布。`transform-style` 为 preserve-3d 而两轴之溢皆见者，子盒依变后之深而班，深者先画；有裁有滚则退为平。背向之 preserve-3d 盒以自身为一深零之平，与子盒同列而班。`backface-visibility` 为 hidden 者，以累积之阵法线深分判其背，背向观者则全枝不画。诸盒之 em 依本盒字号折之，三维之变与透亦立包含块。命中循未投之显项而近之。四四之阵的分解与插值、相交平面之分、逐层深之缓冲及三维之变的层叠上下文，后续接之。

「网页圆角径」取四角横纵之径，百分比以边框宽高为基，诸边两径之和逾其长则同缩之；内轮廓扣其边距。背景、图像、边框、后代溢裁（各轴用有效之值：根可见则取体盒之值授视口，体盒自身作可见；`overflow: clip` 之轴依 `overflow-clip-margin` 外扩（可带 `content-box`、`padding-box`、`border-box` 之词，圆角随扩后之矩））及命中，共用路径蒙版。实线边框以四侧多边形分色，以内外圆角路径之奇偶环裁之。单轴溢裁及行内连续背景之形，后续详之。

「网页地资片」依原宣之序，取各层尺寸、位置、重复、原点、裁剪及附件之设，返自下至上之背景片。图像背景以暂设图像盒复用已有读器及地址之藏；渐变与图像共铺砖之形。背景尺寸受自然尺寸、明定长度百分比、自动轴及包含覆盖；图无固有之寸又无固有之比例（根为 svg 而宽高之性俱缺、亦无视框可用之比例）者，地以定位之区为其自然之寸，`auto` 之轴亦取定位区相当之边长。位置循对象位置之解。重复可横纵各定，亦可间隔铺排及整砖铺排。图层依砖矩与见裁之交取源之一块，重采至见寸而铺之，覆屏之巨砖不复整块采为素；尺寸近零而两轴俱复者，依裁域铺其一，免逐砖而举数十万片。位置循对象位置之解，一分至四分边移皆可。原点及裁剪受边框盒、内边盒、内容盒、边框之区及文字：边框之区以外框与内边二圆径取奇偶之规成环，文字以盒内字径为蒙。固定附件取视口之域，局部附件取滚动之区而依滚位平移；传于画布之根背景不施裁剪。背景色用末层之裁，全盒命中之域别存之。裁盒即边盒者，地色与地图不复各叠一度圆角之版，留待盒之自项统一叠一，边覆不相乘而暗边不生；裁盒在里者仍依内圆之角。行内连续背景及取整后自动轴之比，续接之。

背景图层可绘径向、锥形渐变及其重复之式。径向受圆、椭圆、明定半径、最近最远边角之名及 `at` 之心位；椭圆以颜料坐标之变取色。锥形受 `from` 始角及 `at` 心位，角度色标循样式之解，百分比为全周之比。重复之式依首末色标之实区取模。边移之位、偏心椭圆之精确角径及复杂插值，续接之。

背景图层可绘线性渐变及重复线性渐变。方向受角度或 `to` 边角之名，颜色循层叠样式之解及当前色；色标之位受百分比及长度，省其位者分于相邻定标之间。重复渐变依首末色标之区展开。背景色在诸层之下，先宣之图层后绘，背景先于边框。双位色标、插值之示及色域，续接之。

「渲染网页页」受字体集合、节点图像读器、样式读器、数值环境、语言、文档及视口尺寸，生图像盒树，成文字测量、布局、显示列表、绘制分组及栅格输出，返盒树、显示列表、绘制组及图像。「渲染网页篇」用文档计算样式、默认数值环境及中文语言之设。视口尺寸录于数值环境，以求视口单位之值。外链字体之录、异步资源复排及局部重绘，续接之。

绘制子盒分负定位层、普通块、浮动、行内、零定位层及正定位层；定位层依层号次之，同层存树序。`transform` 为成列之函数、`translate`、`rotate`、`scale` 任一有值、`perspective` 非 `none`、`transform-style` 为 preserve-3d 或 `backface-visibility` 为 hidden 者，依定位盒之阶入班，文字与非原子行内者不与；无效之 `transform` 不立层叠。立层叠上下文之判，又含定位而 `z-index` 为整数（小数与带单位者作 auto）、`position` 为 fixed 或 sticky、不透明度小于一、`filter` 或 `backdrop-filter`、`isolation` 为 isolate、`mix-blend-mode` 非 normal、`clip-path` 非 none。定位之盒成为层叠单元，升于近层叠上下文：负 `z-index` 者居该上下文背景、边框之后，块级内容之前；零与 auto 及正层居其后。常盒若为层叠上下文，则收子单元与升者，依阶与层而班；不然则还其升者于上。三维上下文之平展子盒自收其升，其中不定位之层叠者仍留子列随深而班，以免乱其深序；表内部之显者仍守本组。无自项、无背景、无边框与分组效果之静块作为空壳展平，其子盒（并定位后代）与空壳之兄弟同列，依绘序再班；画布、图像、矢量及视频之类带图像项者不展。既展之盒不出绘项，而宽高不零、可见且纳指针者仍守其故席，占一透明之项以候命中（矩取边框，见「网页展平命中项」「网页盒项」），绘时不见，点之则归其节。显示列表及命中之检皆循此序。「生网页绘组」存自身显示项、排序子组、不透明度及混合法；「栅格网页绘组」先合全子树，而后统一施不透明度。混合法映于二维绘图之分量及综合色合成。背景贯通、图层复用及全层叠上下文，续接之。

「新网页图像读者」受地址至字节串之读器，用图像编解码而依地址藏成败之果，返节点图像读器。「生网页图像盒树」录已解图像自然宽高于盒样式，供布局；宽高属性循已有之序。

「网页图像选源」还 img 之当前图源：srcset 有宽述则依 sizes 之媒问算源长、乘像素之比择宽候，有密述则依像素之比择密候；父为 picture 则先依 source 之类型、媒问与 srcset 次第而择，皆不中乃退 img 自身与 src。「择图像集」自 `image-set()` 之候依像素之比择优：址取字符串或 `url()`，分辨受 `x`、`dppx`、`dpi`、`dpcm` 与 `calc()`，`type()` 依可解之媒类而滤，先取不小于比之最小分辨，皆不足则取最大。「新网页图像读者带境」依数值之境视窗宽高与像素之比择源而后解码，依址藏之；「新网页图像读者」用常境。`loading="lazy"` 暂依即载。srcset 之址含逗、sizes 之繁长式，后续接之。

「收网页资映列」受文字路径及盒图像之读器，图像依实像素尺寸适配定位，裁于内容盒及祖先之域。「收网模资映列」合字体集合及节点图像读器。栅格输出用颜料路径，图像逆映坐标而取最近邻之色；高质采样、矢量图资源、动图及异步载入失效，续接之。

显示项携绘径。文字绘读者还文字绘制之果：素色字形之径与彩色字形之项（`网页彩字项`）。`文字绘` 为每形取彩色之形：COLR 零版之层，逐层取其廓，同以一变换缩放平移，颜料取 CPAL 调色之颜色，索六五五三五之层用文字之色；无层之形取 CBDT 或 sbix 之位图，依字号与组之尺双线缩放，依小字形之度（横承、纵承）定位，颜料为图像之案。彩项于`映列`配为显项，矩裁取裁域，字义虚而不参命中。`收网页径映列` 受文字绘读者，依文字盒之树序入径，取文字色而共祖先之裁。`收网模映列` 受字体集合、数值环境及语言，逐布局文字片段复整形，化定位字形及字体轮廓为像素之径；字号依字体单位缩放，纵轴反向以合画布。布局存每片之文与矩形，定位平移亦移片位。布局整形之果及字形路径缓存，续接之。

「收网页映列」由已布局之盒树生成背景及四边之显示项，存节点、矩形、祖先之裁及颜色。背景取片段矩形，边框取盒边之尺寸与计算样式；可见性定自身之绘，横纵溢出各裁其后。列表依树序存之，后续层叠之法据此而扩。

「栅格网页映列」用二维绘图成矩形之栅及源上之合，返紧列红绿蓝透明八位图像。「网页命中节」逆序求命中项，用同裁域，读指针事件之设。

`list-item` 盒之列表标记，依盒自身之文字片段而绘，色取 `::marker` 之 `color`（无 `::marker` 之规则则取盒之 `color`）。`font-weight` 六百以上之文，先由字体选取择粗面；所择之面为粗（果之「粗序们」记粗面于字形库之序）则依原而描，择不得则文字之径（「网页储文字果径」之仿粗参）于非粗面之字形，复向右错字号三十分之一而再描之以仿粗，故文字项中之径已含仿粗，显示列表不复另加一项。文之测与绘同用行内排版之测量样式，`pre` 类之空白模式存其空格。

画布之背景：视口盒之式载所传之背景，则「收网页映列」先为视口盒生背景之项，铺视口盒及诸子盒之并（视口及文档）。背景图仍以视口盒定位，以根元素盒定位者，续施之。

脱流子盒之溢出裁剪：固定定位之盒不受祖先溢出之裁剪与滚动所约，绝对定位之盒其父盒无定位（`position:static`）者，父盒非其包含块，父盒之溢出裁剪与滚动亦不施于之（「为网页逃逸裁剪」，显示列表与绘制组同用）。文字项之矩取当下之裁剪域而不取行盒：字形可画于行盒之外（`line-height` 小于字高，则行盒甚矮乃至为零），以行盒为界，则整形之字被当作空项而滤去。图载入时统为红绿蓝透明8（JPEG 解码得三通道，绘制依四通道取样），滚动条之有无与形用未吸附之内距矩判之。

整像素吸附：盒之边框盒、内距盒、内容盒及行内片段矩形，于绘时吸附于整像素（「网页吸附矩形」：左上与右下之隅各自四舍五入，宽高取二隅之差，邻盒共用之边吸附后仍共边），背景、边框、轮廓、图、影及溢出之裁皆用吸附后之矩形（「网页盒绘边框矩形」「网页盒绘内边矩形」「网页盒绘内容矩形」），纯色方块之缘落于整像素，与参照页逐像素相同；布局及命中仍用未吸附之矩形。文字每字形基线之纵坐标四舍五入至整像素，横坐标存其小数。

背景之滤：`backdrop-filter` 复用诸滤之析，循绘序采祖与先行诸兄之积画，滤而裁入本盒边框之圆界。`isolation:isolate` 为裔别立后景；变换兼施于采景之界。组含背滤，则全组成栅而出设计图像。

顶层盒：节点名 `dialog` 而处模态者，于绘序为第六阶，居定位、浮动及随行盒之后，全页最后绘之；同父之多个顶层盒仍守原子盒之次。依入顶之先后重排班次，留待后版。

后续事项：全层叠上下文及定位之序、边框线型、阴影、滚动及脏矩形之重绘。

声影之节：`video` 之节图读器取 `poster` 之性，依址读图解码，以为替换之容；节之背通，海报未得则见页底。`audio` 与 `video` 有 `controls` 之性，则于内容盒之下绘二十四像素之控条：半黑之底、左端播停之象、进度之轨与已播之段、今时与总时之文；音频无控条，则用户代理之式令其不显。

边图（border-image）之解析在「边框图」一篇：源、切（含 fill 与百分比）、宽（数乘边框、长度、百分比、auto）、扩、复（伸、复、圆、空）皆依规范取值；九宫之显项铺排亦在此篇与「映列」。边图之实绘留待后版：九宫与切片缩放之几何尚有偏，绘之入口暂关，边框仍以常边画之。
