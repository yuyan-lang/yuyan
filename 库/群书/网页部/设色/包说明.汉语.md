# 网页绘制

`mix-blend-mode: plus-lighter` 将源图与背景的预乘颜色及透明度相加并截到一。组不透明度先作用于源图；设计输出保留整树的实际合成结果。

显示项保存文字内容与字体族供后续使用。后续事项：将文字语义接入设计作品保存。

`析网页合成关键帧` 读取样式表的 `@keyframes`，把百分比、from、to 和声明编成定时样式帧；`造网页合成动画` 把变换六分量、不透明度、模糊及颜色滤镜矩阵编成设计信号。`网页合成动画映元` 按给定时刻求值，直接交给引擎的仿射、图层颜色矩阵和模糊。布局属性由网页重算处理。动画帧按时刻排序。变换分解、投影连续轨与多重模糊次序留待后续版本。

网页显示列表通过 `网页映列匠心元` 输出设计引擎的填充元、图像元与图层遮罩；绘制组通过 `网页绘组匠心元` 输出设计图层，不透明度及已具备的混合方式由引擎合成。现有栅格、页面与脏区入口复用这条出口。网页节点、路径与命中资料保存在网页显示列表里。复杂颜料、过滤和引擎后续接入的混合方式以图像元保存当前参考结果。奇偶规则的蒙版（外阴影、边框环的裁剪）填成图像元时，图像只取路径包围盒（外扩两像素）那么大，用整数平移的仿射放回画布，包围盒里的像素与整幅渲染的相同；包围盒取不出时退回整幅渲染。非纯色颜料填路径得到的图像元（`网页颜料径图像匠心元`）同样只取路径包围盒那么大的图像，遮罩与着色都在小图上做，取色位置加上包围盒的偏移，所以与整幅着色的结果相同。外阴影（`box-shadow`）以裁剪区左上为原点、只在阴影包围盒里处理：源形状的路径边界外扩两像素，与它按偏移平移再按模糊半径外扩的范围取并，夹到画布外扩“偏移加模糊”的范围（画布外而阴影偏进来的源也算上），阴影落不进画布时不画；源形状的渲染、偏移加高斯模糊都在这个小图上做，再用平移后的图案颜料填同样大小的矩形，包围盒之外源与阴影都是全透明，结果与在放宽画布上整幅处理相同，阴影项最后整体平移回裁剪区的位置。内阴影按整幅处理。

交给设计引擎的填充按 0.05 像素展平（`网页匠心容差`）；文字字形与显示项的位移变换保留曲线（`矢量字形曲线径`、`保曲变换径`），到这一步才按像素展平。裁剪框盖住整个画布的显示项、不透明且源上混合的绘制组不再包图层，整页渲染的离屏与内存随之减少。直角蒙版（圆角为零的溢出裁剪）包住项的范围时也不开图层；纯色颜料随变换保持纯色，不包成变换颜料。

多选控件逐项保留换行，活动行复用控件自动显露通路；路径与行片段同时移动，点击继续按可见位置选取对应选项。基本主题给多选控件四行高度。

文本控件按插入符或当前选区末端自动显露内容，水平和纵向溢出时平移文字路径与行片段；选区和插入符读取移动后的矩形，内容框保持裁剪。反向选区的活动端、历史偏移保持、手动滚动与边缘拖动自动滚动继续实施。

文本域采用保留空白的自动换行排版，按段落行记录文字和矩形，换行字符计入原始控件偏移。选区和插入符读取各行记录，空值保留一行定位矩形。逐字形推进、换行字符的精细宽度、双向范围与内部滚动继续实施。

文本控件共用文字选区装饰：即时值决定范围长度，字体排版记录行宽与行高，内容框裁剪背景、选中字色和插入符。插入符采用单像素宽及 `caret-color`，选区复用蒙版着色。字符位置按整行宽度比例计算；逐字形推进、多行范围映射、插入符闪烁与控件内部滚动继续实施。

表单控件展示文字读取即时值，空输入显示占位文字，密码按字符数显示遮蔽点，选择控件显示所选项文字。复选与单选的勾选状态绘成内部标记，文本、标记、边框与背景共用滚动、裁剪和变换路径。光标、组字、选区与精细主题继续实施。

图像读取器在普通图像解码失败后尝试矢量图字节解码，接受 SVG 根元素，按根尺寸栅格并共享地址缓存。内联 SVG 序列化为矢量文档，子元素交给矢量图库统一绘制；图像盒树清空该替代盒的布局子盒。替代元素按各自来源取图：`img` 按 srcset 与 src 选源，`video` 取 poster，`embed` 取 src，`object` 取 data；svg 元素由外标记栅格，画布元素取「画布态」保存的位图。图像地址支持 `data:` 网址：按逗号分出 MIME 与数据，MIME 为空或以 `image/` 开头时接受，带 `;base64` 的用卦文（Base64）解码，其余按百分号解码；`img`、CSS 的 `url()`、背景图与遮罩图共用这一处。位图统一的四通道结果与自然宽高写入盒树，`video` 的海报尺寸同样记为自然尺寸，供对象适配与布局取用。宽高缺省采用三百乘一百五十，外部嵌图沿应用资源回调读取。没有固有尺寸、只有比例的矢量图（根元素为 svg 而 width 与 height 都缺）在读图处记为「没有固有尺寸」，盒树写入样式 `网页资源无固寸`，供对象适配的 scale-down 取 none 一侧。栅格尺寸按 SVG 固有尺寸规则定：width、height 都是绝对值时取原值；一边是绝对值、另一边缺失或为百分比而根元素有 `viewBox` 时，另一边按视框比例算；两边都定不出时用三百乘一百五十，宽度为百分比而高度为绝对值时宽按三百。读图时另按地址记下 EXIF 朝向；`image-orientation: none` 时「网页正图」按朝向的反向把已经摆正的位图转回去，「网页纳宽」「网页纳高」把盒树自然宽高按未转尺寸改写；背景图像层经「网页正图址」与「网页址纳宽」「网页址纳高」同样处理。`content` 为 `url()` 或字符串的元素盒按替代内容参与布局：盒的图像读取器（「网页盒图读」）造临时 img 节点取图，「网页标内容」把自然宽高写进样式；伪元素盒（节点名以「::」开头）暂不接入，按宿主节点取图。画布位图包成红绿蓝透明八的图像，按盒尺寸绘制并按对象适配裁剪。图像和背景图继续使用现有对象适配、裁剪与采样。背景图层遇到既无固有尺寸又无固有比例的矢量图时按背景尺寸重新栅格，矢量里的百分比随绘制尺寸解析。内联文档继承样式、字体接线、内联结果缓存与完整自然比例推导留待后续接入。

「重绘网页区域」接收原图、新绘制组与脏矩形列表，将区域向外取整并裁到原图边界。无过滤的组平移到区域坐标，只栅格化该区域；含过滤的组保留完整栅格以取得邻域，随后提取区域。新像素直接替换旧像素，透明像素可以清除旧内容，区域外保持原图。「重绘网页盒页」复用调用方已更新布局的盒树，重建绘制组，再把绘制组摊平成显示列表（「网页绘组映列」，盒树只遍历一次），返回更新后的页面结果。「舒卷重绘网页盒页」在页面只纵向滚动了整数像素时平移旧图，只重画露出的条带、右侧十六像素宽的一列（视口滚动条）和向上滚时底边十六像素高的一行（「网页页块重画」按块生成绘制组，离块很远的盒不生成显示项），显示列表留空，命中时由「网页页整幅映列」按整幅补上。自动脏区收集与中间图层缓存留待后续接入。

「设网页文字选区」按文字节点保存字符范围，范围重合时显示插入符，「清网页文字选区」清除状态。选区按视觉行序排列文字片段，并按片段内字符数分配宽度，生成背景与白色文字前景；插入符采用 `caret-color` 或当前文字颜色，换行边界选择下一片段。「设网页绘焦点」选择焦点节点，焦点环按圆角边框向外扩张。交互装饰与所属内容共同滚动、变换、裁剪和合成。真实字形推进、双向范围、空白偏移映射、跨节点控制、闪烁与状态回收留待后续接入。

后代内容按容器滚动位置平移，随后施加容器的溢出裁剪；每个盒收到的裁剪区先换到它自己的坐标（变换与滚动之前，「网页逆变换裁剪」），显示项的矩与裁随项一起变换回去；盒的边框外扩一百像素仍与裁剪区不相交时，不生成它自身的显示项；显示列表与绘制组采用同一偏移，命中使用移动后的路径和蒙版。背景、边框与轮廓保持在容器位置。自动溢出、显式滚动和视口绘制覆盖式滚动条，滑块长度和位置按内容比例计算；`scrollbar-width` 支持默认、细与隐藏。滚动条拖动、固定定位后代、局部背景附件和颜色样式留待后续接入。

图像和背景图按实际绘制尺寸预缩放，默认采用兰索三重采样；透明颜色先预乘，采样后还原。`image-rendering` 继承，`pixelated` 和 `crisp-edges` 使用原图的最近邻映射，其余值采用平滑采样。对象适配、背景尺寸与图案坐标沿用同一目标矩形。分数尺寸、变换后的采样足迹、缩放缓存与像素化整数倍过渡留待后续细化。

「新网页字形读者」缓存字体单位下的原始轮廓，以字体文件长度、所选字面表目录与字形号区分条目。文字绘读者在各片段、显示列表和绘制组之间复用同一缓存；字号、纵轴翻转和位置在读取轮廓后统一变换。重新创建读取器即可释放整批缓存。可变字体实例身份与布局整形结果缓存留待后续接入。

`text-shadow` 支持多层颜色、横纵偏移和模糊半径，颜色省略时采用当前文字颜色。阴影从字形与装饰线的透明轮廓生成，声明在前的层覆盖后面的层，随后绘制正文和装饰。文字阴影继承样式，与所属盒共同参与变换、裁剪、过滤及合成。分数偏移和视口外源图扩展留待后续细化。

文字装饰支持下划线、上划线和删除线，采用实线、双线、点线、虚线或波浪线。`text-decoration` 简写展开线种、样式、颜色和粗细；粗细与下划线偏移接受长度及字号百分比；`text-decoration-inset` 的起、止内缩接受长度与百分比（百分比以该片段宽为基，单值兼作两端），负值向外延伸。每个文字片段生成装饰路径，与正文共同参与裁剪、变换、过滤和合成。祖先装饰按盒树传播并补画（跳过原子行内、浮动与绝对定位后代），字体度量、跳过字形、跳过空格与竖排留待后续接入。

`clip-path` 支持圆、椭圆、多边形、内缩矩形、四边坐标矩形和位置尺寸矩形，矩形接受圆角。长度、百分比和位置按边框盒、内边盒或内容盒计算。裁剪施于整个子树的过滤结果，显示列表与命中查询使用同一形状，形状随盒变换。旧式 `clip` 只对绝对定位与固定定位的盒生效，`rect(上, 右, 下, 左)` 的四边可为 `auto`（取边框盒对应的边），其余按长度或百分比解析（上下按高、左右按宽）。形状蒙版统一用同一路径填充算出边沿的覆盖，圆角与裁剪形状的边缘不再两次相乘。路径字符串、矢量图引用与专用参考盒留待后续接入。

`mask-image` 借背景层片的尺寸、位置、重复与参考盒机制读成一张遮罩图：`mask-size`、`mask-position`、`mask-repeat`、`mask-origin` 与 `mask-clip` 逐层对应，遮罩图的画布取 `mask-clip` 的盒；`mask-mode` 为 `alpha` 或 `match-source` 时取透明，为 `luminance` 时按明度乘透明取白图。多层遮罩自下而上按 `mask-composite` 合成：`add` 为上透明加下透明乘一减上透明，`subtract` 为下透明乘一减上透明，`intersect` 为两透明相乘，`exclude` 为两透明相加再减两倍乘积。遮罩按组乘进画面：遮罩图外的像素全透明，图内逐像素乘遮罩透明。带遮罩的绘制组整组合成于画布，遮罩按组变换之前的坐标放置。`mask-image` 为 `url(#号)` 时按文档里的 SVG `mask` 元素渲染：取该元素的子节点写成同盒宽高的矢量图，`mask-mode` 为 `match-source` 时依 `mask-type` 取明度或透明，写完再乘进画面。`mask` 简写由装帧按层展开成八项长写（图像、位置、尺寸、重复、原点、裁剪、合成、模式），`maskUnits` 为 `userSpaceOnUse` 时按掩区像素给 `viewBox` 对齐。`maskContentUnits` 为 `objectBoundingBox` 时按零到一的 `viewBox` 解释内容坐标；`mask-origin`、`mask-clip` 的 `fill-box`、`stroke-box`、`view-box` 按内容盒或边框盒归约，行内盒多片段时逐片段取层片。滤镜区域的裁切留待后续接入。

边框与轮廓支持实线、虚线、圆点线、双线、凹槽、凸脊、内凹和外凸。虚线及点线沿圆角中线分段描边，再按内外圆角环裁剪；双线以三分宽度形成两个环。凹凸线型按四边方向分配明暗，凹槽和凸脊在半宽位置切换颜色。同色实线合并绘制，其他边框分侧绘制。轮廓在后代内容之后绘制，随后参与整个子树的过滤、不透明度及混合。各边虚线的均衡分配与异色交界的抗锯齿留待后续细化。

`box-shadow` 支持多层颜色、横纵偏移、模糊半径、扩张和内影，省略颜色时使用当前文字颜色。阴影轮廓沿用椭圆圆角，外影排除边框内部，内影裁在内边盒中；声明在前的阴影覆盖后面的阴影。`outline` 简写展开宽度、样式与颜色，轮廓偏移在边框外生成圆角环，`inset` 取负宽度把环画进边框里；实线轮廓分上、下、左、右四条矩形带绘制（外缘与内缘都是直角，不受圆角蒙版影响），虚线、点线与双线按边框的四侧梯形裁剪、各带同一条圆角环蒙版（点距与圆帽随圈走，与边框参照一致）；表列与列组不生成轮廓（它们不生成盒）。行内逐片装饰、分数阴影偏移与视口外阴影源留待后续细化。

`filter` 按声明顺序处理整个绘制子树，支持模糊、投影、亮度、对比度、反色、灰度、棕褐色、饱和度、色相旋转和透明度。颜色分量在红绿蓝透明图像上转换，模糊复用预乘透明度的高斯处理，投影读取子树透明轮廓并在原图后合成。祖先溢出蒙版在过滤之后裁剪，组不透明度与混合随后执行。过滤的局部变换坐标、分数投影偏移和视口外源图扩展留待后续接入。

二维 `transform` 支持六参数矩阵、横纵平移、缩放、旋转及斜切，列表按声明次序复合。平移百分比以参考盒宽高为基准，`transform-origin` 支持位置关键字、长度与百分比；`transform-box` 为 `content-box` 或 `fill-box` 时参考盒取内容盒，其余取边框盒。`scale()` 接受数与百分比，各长度单位按元素自身字号折算。整个盒子及后代的路径、圆角蒙版与命中区域共同变换，颜料用逆矩阵取色；视口裁剪保持在输出坐标中，祖先溢出蒙版随所属盒变换。奇异矩阵排除子树的绘制与命中。

三维变换把变换函数铺成四乘四矩阵：`matrix3d`、`translate3d`、`translateZ`、`scale3d`、`scaleZ`、`rotate3d`、`rotateX`/`rotateY`/`rotateZ` 与 `perspective()` 各自成阵，二维诸名沿用六参数矩阵再铺成四行；`transform-origin` 的第三分量作深度，`translate`、`rotate`、`scale` 三个独立属性按“先移、次转、后缩”的顺序排在 `transform` 之前。`perspective` 与 `perspective-origin` 在盒上取视距与视原点，以其子盒的透视阵作用于子盒；视距小于一像素时按规范夹到一像素。矩阵按父盒的透视与自身变换相成；成阵为仿射时仍走二维通路，带透视时该盒的整个子树先按自己的坐标栅格成一层，再按投影阵反算源坐标取色，轴对齐的投影取最近像素，其余双线取色，画到父层的画布上。`transform-style: preserve-3d` 且两轴溢出都可见时子盒按变换后的深度排序，深处者先画（溢出隐藏、自动或滚动令其退为平）；背向观者的 preserve-3d 盒把自身平面当作一张深度为零的平面，与子盒同列排班。`backface-visibility: hidden` 时以累积矩阵法线的深度分量判背面，背向观者的盒整棵不画。各盒的 em 按自身字号折算，三维变换与透视照常建立包含块。命中查询按未投影的显示项近似。四乘四矩阵的分解与插值、相交平面的分割、逐层深度缓冲与三维变换的层叠上下文留待后续版本。

「网页圆角径」读取四角的横纵半径，百分比以边框宽高为基准，四边半径总和超出尺寸时统一缩放；内侧轮廓扣除对应边距。背景、图像、边框、后代溢出裁剪和命中查询共用路径蒙版。实线边框按四侧多边形划分颜色，以内外圆角路径的奇偶环裁剪。单轴溢出与行内连续背景的轮廓留待后续细化。

「网页地资片」按原声明序号读取每层的背景尺寸、位置、重复、原点、裁剪和附件设置，返回从底至顶的背景片。图像背景经临时图像盒复用已有读取回调与地址缓存；渐变和图像共用铺砖几何。「背景尺寸」支持自然尺寸、显式长度百分比、自动轴及包含和覆盖；图像既无固有尺寸又无固有比例（根元素为 svg 而 width 与 height 都缺、也没有可用的 viewBox 比例）时，背景以定位区的大小作为自然尺寸，`auto` 轴也取定位区对应的边长。位置沿用对象位置解析。重复支持横纵独立、间隔铺排和整砖铺排。图像层按铺砖矩形与可见裁剪区之交取源图一块，重采样到可见尺寸后平铺，覆盖整屏的巨砖不再整块采成像素；尺寸近零且两轴重复时按裁剪区铺一张，避免逐砖列举数十万片。位置沿用对象位置解析，支持一至四个分量的边偏移。原点与裁剪支持边框盒、内边盒、内容盒、边框区域与文字：边框区域以边框盒和内边盒两条圆角路径取奇偶规则成环，文字以盒内字形路径为蒙版。固定附件采用视口区域，局部附件采用滚动区并按滚动位置平移；传播到画布的根背景不着裁剪。背景颜色采用最后一层的裁剪，整个盒子的命中区域独立保留。裁剪盒就是边框盒时，背景色与背景图不再各自叠一次圆角蒙版，留给盒的自身项统一叠一次，边沿覆盖便不会相乘出暗边；裁剪盒在里时仍按内圆角裁。内联连续背景和取整后的自动轴比例继续接入。

背景图层支持径向与锥形渐变及其重复形式。径向渐变接收圆形、椭圆、显式半径、最近与最远边角关键字和 `at` 中心位置；椭圆通过颜料坐标变换采样。锥形渐变接收 `from` 起始角与 `at` 中心，角度色标沿用样式角度解析，百分比表示整周比例。重复形式按首末色标的实际区间取模。边偏移位置、偏心椭圆的精确角半径和复杂插值继续接入。

背景图层支持线性渐变与重复线性渐变。方向接受角度或 `to` 边角关键字，颜色沿用层叠样式解析和当前颜色；色标位置接受百分比和长度，省略位置在相邻确定色标之间分配。重复渐变按首末色标的区间展开。背景颜色位于所有图层之下，声明在前的背景图层绘制在后，背景位于边框之前。双位置色标、插值提示和颜色空间继续接入。

「渲染网页页」接收字体集合、节点图像读取器、样式读取器、数值环境、语言、文档和视口尺寸，生成图像盒树并完成文字测量、布局、显示列表、绘制分组和栅格输出，返回盒树、显示列表、绘制组与图像。「渲染网页篇」使用文档计算样式、默认数值环境和中文语言设置。视口尺寸写入数值环境，供视口单位求值。外链字体注册、异步资源重排与局部重绘继续接入。

绘制子盒分为负定位层、普通块、浮动、行内、零定位层和正定位层；定位层按层号排序，同层保持树序。`transform` 为成立的函数列、`translate`、`rotate`、`scale` 任一有值、`perspective` 不为 `none`、`transform-style: preserve-3d` 或 `backface-visibility: hidden` 的盒按定位盒的阶段入班，文字盒与非原子行内盒除外；无效的 `transform` 值不建层叠。盒立层叠上下文的判据另含定位且 `z-index` 为合法整数（小数与带单位的值按 `auto`）、`position: fixed`/`sticky`、不透明度小于一、`filter`/`backdrop-filter`、`isolation: isolate`、非 `normal` 的 `mix-blend-mode` 与非 `none` 的 `clip-path`。定位盒成为层叠单元，提升到最近的层叠上下文：负 `z-index` 的单元排在该上下文的背景与边框之后、块级内容之前，零与 `auto` 层及正层排在其后；普通盒若是层叠上下文，把子单元与提升单元按阶段与层号收下，否则把提升单元交还上层。三维上下文里的平展子盒自己收下提升单元，三维上下文里不定位的层叠盒留在子盒列中随深度排，免得打乱深度序；表内部显示的盒照旧留在原组。没有自身显示项、背景、边框与分组效果的静态块当作透明外壳展平，其子盒（连同定位后代）与外壳的兄弟同列按绘序重排；画布、图像、矢量图与视频这类带图像项的盒不展平。被展平的盒不出绘制项，宽或高不为零、可见且收指针的仍留在它原来那一席，占一条只供命中的透明项（矩取边框矩形），绘制时看不见，点击却落回它身上（「网页展平命中项」「网页盒项」）。显示列表与命中查询采用这一顺序。「生网页绘组」保存自身显示项、排序子组、不透明度和混合模式；「栅格网页绘组」先合成整个子树，再统一应用不透明度。混合模式映射到二维绘图的分量及综合色合成。背景穿透、图层复用与完整的层叠上下文继续接入。

「新网页图像读者」接受地址到字节串的读取函数，调用图像编解码并按地址缓存成功与失败结果，返回节点图像读取器。「生网页图像盒树」把已解码图像的自然宽高写入盒样式，供布局使用；宽高属性沿用已有优先级。

「网页图像选源」返回 img 的当前图源：srcset 有宽度描述时按 sizes 的媒体条件算出源尺寸、乘设备像素比选宽度候选，有密度描述时按像素比选密度候选；父节点为 picture 时先按 source 的 type、media 与 srcset 依次择源，都不中再退回 img 自身与 src。「择图像集」从 `image-set()` 的候选里按设备像素比择优：地址取字符串或 `url()`，分辨支持 `x`、`dppx`、`dpi`、`dpcm` 与 `calc()`，`type()` 按可解码媒体类型过滤，先取不小于像素比的最小分辨，皆不足时取最大分辨。「新网页图像读者带境」按数值环境的视口宽高与像素比选源后解码，并按地址缓存；「新网页图像读者」用缺省数值环境。`loading="lazy"` 暂按立即载入处理。srcset 地址内含逗号的写法与 sizes 的复杂长度表达式留待后续版本。

「收网页资映列」接受文字路径和盒图像读取器，图像按实际像素尺寸进行对象适配与定位，并在内容盒和祖先区域中裁剪。「收网模资映列」装配字体集合与节点图像读取器。栅格输出使用颜料路径，图像通过坐标逆映射进行最近邻采样；高质量采样、矢量图资源、动态图像和异步载入失效继续接入。

显示项携带绘制路径。文字绘读者返回文字绘制果：素色字形的路径与彩色字形的项（`网页彩字项`）。`文字绘` 为每个字形取彩色字形：COLR 零版的图层逐层取该层轮廓、按同一变换缩放平移，颜料取 CPAL 调色板颜色，调色板索引 65535 的层用文字颜色；没有图层的字形取 CBDT 或 sbix 的位图，按字号与像素组的尺双线性缩放，按小字形度量（横承、纵承）定位，颜料为图像图案。彩字项在`映列`里配成显示项，矩与裁取裁剪矩形，字义缺省、不参与命中。`收网页径映列` 接受文字绘读者，在文字盒所在树序插入路径，采用文字颜色并共享祖先裁剪。`收网模映列` 接收字体集合、数值环境和语言，逐个布局文字片段重新整形，将定位字形和字体轮廓转换成像素路径；字号按字体单位缩放，纵轴翻转到画布方向。布局保存每片正文和矩形，定位平移同步更新片段位置。布局整形结果与字形路径缓存继续接入。

「收网页映列」从已布局盒树生成背景和四边边框显示项，保留节点、矩形、祖先裁剪与颜色。背景使用片段矩形，边框使用盒边框尺寸和计算样式；可见性决定自身绘制，横纵溢出用有效溢出值分别裁剪后代，`overflow: clip` 的轴按 `overflow-clip-margin` 外扩裁剪边（可带 `content-box`、`padding-box`、`border-box` 关键字，圆角随之落在扩后的矩上）：根元素可见时取 body 的值给视口、body 自身按可见，滚动条按同一值决定画与不画。列表按树序保存，后续层叠规则在此基础上扩展。

「栅格网页映列」调用二维绘图完成矩形栅格和源上合成，返回紧密排列的红绿蓝透明8图像。「网页命中节」逆序查询命中项，使用同一裁剪区域，读取指针事件设置。

`list-item` 盒的列表标记按盒自己的文字片段绘制，颜色取 `::marker` 的 `color`（没有 `::marker` 规则时取盒的 `color`）。`font-weight` 为 600 以上的文字先由字体选取选粗体字面；选到的字面是粗体（结果的「粗序们」记着粗体字面在字形库里的序号）就按原样描，选不到时文字路径（「网页储文字果径」的仿粗参数）对不是粗体面的字形再向右错开字号三十分之一描一遍作为仿粗，所以文字项里的路径已含仿粗，显示列表不再另加一项。文字的测量与绘制共用行内排版的测量样式，`pre` 类空白模式保留空格。

画布背景：视口盒的样式里带着传播来的背景时，「收网页映列」先给视口盒生成背景项，铺满视口盒与全部子盒的并集（视口加文档）。背景图仍按视口盒定位，按根元素盒定位继续实施。

脱流子盒的溢出裁剪：固定定位盒不受任何祖先溢出裁剪与滚动的约束，绝对定位盒的父盒没有定位（`position:static`）时，父盒不是它的包含块，父盒的溢出裁剪与滚动也不作用于它（「为网页逃逸裁剪」，显示列表与绘制组共用）。文字项的矩取当前裁剪区域，不取行盒：字形可以画在行盒之外（`line-height` 小于字高时行盒很矮甚至为零），以行盒为界会把整形的文字当成空项滤掉。图像载入时统一转成红绿蓝透明8（JPEG 解码结果是三通道，绘制按四通道取样），滚动条的有无与几何用未吸附的内边矩形判定。

整数像素吸附：盒的边框盒、内边距盒、内容盒与行内片段矩形在绘制时吸附到整数像素（「网页吸附矩形」：左上角与右下角各自四舍五入，宽高取两角之差，相邻盒共用的边吸附后仍共边），背景、边框、轮廓、图像、阴影与溢出裁剪都用吸附后的矩形（「网页盒绘边框矩形」「网页盒绘内边矩形」「网页盒绘内容矩形」），纯色方块的边缘落在整像素上，与参照页逐像素相同；布局与命中测试仍用未吸附的矩形。文字的每个字形基线的纵坐标四舍五入到整数像素，横坐标保留小数。

设计显示元按过滤器顺序保存模糊与投影图层，保留模糊标准差、投影偏移和颜色；保存为设计作品后由设计渲染器求值。其余颜色过滤逐项应用到图像，过滤与投影的先后次序保持一致。

背景滤镜：`backdrop-filter` 复用过滤器解析，按绘制顺序采样祖先与先行兄弟的累计画面，过滤结果裁入本盒的边框圆角。`isolation:isolate` 为后代建立独立后景；变换同时作用于后景采样边界。含背景滤镜的绘制组经完整栅格合成后输出设计图像。

顶层盒：节点名为 `dialog` 且处于模态的盒在绘制顺序里属阶段六，排在定位、浮动与随行盒之后，整页最后绘制；同一父盒内多个顶层盒保持原来的子盒次序。顶层层序按进入顶层的先后重新排班留待后续版本。

后续事项：完整层叠上下文与定位顺序、边框线型、阴影、滚动和脏矩形重绘。

媒体元素：`video` 的节点图像读取器取 `poster` 属性按地址读图解码，作为替换内容绘出；元素背景透明，海报未取到时露出页面底色。`audio` 与 `video` 有 `controls` 属性时在内容盒底部绘二十四像素高的控制条：半黑底、左端播放或暂停图标、进度轨与已播段、当前时与总时长文字；音频无控制条时用户代理样式表令其不显示。

边框图像（border-image）的解析写在「边框图」（border images）一篇：source、slice（含 fill 与百分比）、width（数字乘边框宽、长度、百分比、auto）、outset、repeat（stretch、repeat、round、space）都按规范取值；九宫格按边框图像区、宽度的分割线与切片的源矩形逐段成像：四角独立缩放，四边先按目标边厚等比缩放再按铺法沿长边铺，fill 时画中格；边框成像时不画普通边框。显示项在「映列」里生成。
