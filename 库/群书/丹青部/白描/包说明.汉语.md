# 矢量图

这是纯豫言的SVG静态文档、路径读写与RGBA渲染库。`渲染白描` 接收SVG字符串和输出宽高，经可扩展标记与二维绘图返回图像。`渲染白描字样` 再接收调用者提供的解析字体，以单字体轮廓绘制基本text与tspan。

`析径` 与 `写出径` 处理M、L、H、V、C、S、Q、T、A、Z的绝对、相对、重复参数、指数与圆弧标记；非法路径返回空值。`作绘图径` 计算相对坐标、简写控制点，并把端点椭圆弧转成中心式圆弧命令（曲线留待绘事的容差平展）。`析长度` 接收百分比基准与字高，使用px、%、in、cm、mm、pt、pc、em、ex，每英寸96像素，ex取半字高。`析变换` 使用matrix、translate、scale、rotate、skewX、skewY，参数带角度与长度单位，translate 的百分比按参照框宽高折，矩阵按SVG顺序组合；matrix 只收纯数，逗号错位或空参数（如 `translate(5,)`）整串作废。同一个元素有多份 transform（行内计算样式、样式表规则与呈现属性）时，依次试解，取第一个解得开的，都解不开则不施变换；行内样式与样式表规则按 CSS 语法收单位，呈现属性的那一条（列在最后）按 SVG 语法只收纯数，带 px、deg、% 等单位者整串作废，于是 `transform="skewX(45deg)"`、`transform="translate(10px 10px)"` 都不施变换；`url()` 的引用号带不带引号都认。变换按 transform-box 取参照框：view-box 取最近视口的视框，fill-box 取元素（容器取子元素并集）的几何边界，stroke-box 再按描边宽度向外扩一半，vector-effect 为 non-scaling-stroke 时按 fill-box；transform-origin 的百分比与长度按参照框折并加框的左、上偏移，未写时取参照框左上。translate、rotate、scale 三个个别变换属性按平移、旋转、缩放的次序合成，与 transform 相乘时也依这个次序；display 为 none 的元素整棵跳过，visibility 为 hidden 的元素自身不画、子元素各按自己的计算样式。

静态入口接入svg、g、defs、use、symbol、path、rect、circle、ellipse、line、polyline、polygon、text、image、linearGradient、radialGradient、clipPath、style、tspan、mask、pattern、marker及五种常用滤镜。内部引用、简单标签/类/身份选择器、行内样式（含调用者写进 style 的计算样式，优先于展示属性）、展示属性继承、嵌套视口、长度百分比、viewBox、preserveAspectRatio与SVG名称空间进入同一绘图链。

SVG 根元素的 `background` 与 `background-color` 取纯色时画在内容之下，供外部 SVG 图像自带底色；背景图与渐变留待后续版本。

填描使用非零/奇偶规则、线宽、线帽、连接、斜接上限、虚线与透明度。渐变使用色标透明度、焦点径向、延展、单位、变换及模板引用。pattern使用瓦片、内容单位、视框和变换；marker使用首中末节点、参考点、线宽单位、朝向和默认溢出裁剪。tspan使用单值x/y/dx/dy、字号、锚和连续空白流。字体选择由调用者负责。

image的data URI接收六十四进制或百分号字节，经统一PNG/JPEG解码、图像处理转紧密RGBA8、图案采样及矩形视框绘制。外部资源由调用者预处理为data URI。mask接收亮度/alpha与颜色空间，内容单位及区域按元素矩阵解释。filter链执行SourceGraphic、SourceAlpha、命名result、feGaussianBlur、feOffset、feBlend、feColorMatrix、feComposite；逐原语输入、颜色空间、filterUnits、primitiveUnits及子区域进入同一处理链，裁后结果用于后继原语。输出图像为紧密RGBA8。

`写出径件` 转义属性；`写出白描` 输出名称空间、尺寸与viewBox。图表已真实消费SVG写出并通过坐标与Unicode回归。PNG、灰度128 JPEG与红RGB444 JPEG已实际渲染并写出PNG产物。

本阶段在pit-mac以5d59d481完整工具链独缓存执行全部库模块类型检查与23模块综合构建运行，均退出0；26条输出覆盖甲乙基础像素、滤镜链与区域、图案、标记、嵌套视口、文字及tspan位置。具体日志见实施记录。甲乙级完整验收继续实施。

结构与算法按仓库许可发布。手工字体向量来自字体测试包。渐变、路径弧与滤镜公式依SVG及Filter Effects规范，代码保留规范地址。独立参考实验保留resvg-test-suite的MIT许可与来源提交；官方resvg 0.48.1只在仓外产生对照。当前官方默认500像素圆对照的最大透明差为52灰级，固定验收阈为32，覆盖模型对照继续。

根text与tspan的单值dx/dy按当前文字起点偏移，根text偏移覆盖其全部连续片段。路径数字按ASCII扫描范围直接截取，长文字轮廓的数字读取使用字节边界。

根text与tspan的x/y/dx/dy坐标列表按整个子树的字符序消耗，内层列表覆盖同位置外层值。rotate逐字围绕基线起点旋转，列表末值继续作用于后继字符。坐标列表中的百分比逐项按视口横纵基准转换。

x/y绝对重设划分文字块；每块跨tspan汇集字号、相对位移和前进宽，按块首text-anchor执行一次居中或终点平移，逐字旋转随块平移保留。

高斯原语在非零协方差时保留元素矩阵变换后的两条标准差方向，依次按画布像素距离做预乘双线性方向卷积；透明扩边保留中间画布外贡献，最终裁回原尺寸。一轴标准差为零时使用剩余方向，覆盖旋转后的奇异协方差。

「渲染白描资」「渲染白描字样资」接收应用提供的URI资源解析器。回调返回原始PNG/JPEG字节或失败原因，进入既有图像解码与渲染通路；新入口返回结构化渲染成功或失败。接口见[资源规范](规范.汉语.md)。
