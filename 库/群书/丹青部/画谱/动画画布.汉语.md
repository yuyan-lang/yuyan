# 动画画布

动画画布是图像编解码包内部共用的合成模块。它直接依赖标准库与同包图像数据，沿用图像编解码在图像与图形基础库中的登记。

调用者分配每像素32字节的零初始化字节缓冲，保存四个双精度直通红、绿、蓝、透明度分量。输入图像为红绿蓝透明8或红绿蓝透明16，16位输入为小端；行距从图像数据读取。调用者核对输入格式、画布尺寸与帧矩形边界。

`动画画布合像` 接收输入图像、画布缓冲、画布宽、左偏移、上偏移、替换爻与起始像素序。替换为阳时按来源写入，阴时执行透明覆盖。`动画画布填区` 接收画布、画布宽、矩形位置与尺寸、打包RGBA8颜色和起始像素序，填充矩形背景。上述起始像素序使用零。

`动画画布出图` 接收画布、宽、高与十六位爻，输出紧密排列的红绿蓝透明8或红绿蓝透明16。内部连续合成保持双精度，在输出时将分量限制到零至一并四舍五入量化。透明覆盖的零透明度结果颜色归零；来源替换保存输入的透明隐藏颜色。

此源码随网图联合构建和实际运行通过：透明混合与处置的固定向量，以及透明度1的百次覆盖末值83。验证日志位于受信任开发机的 `/tmp/yy网图联合构建.log` 与 `/tmp/yy网图联合运行.log`。16位动画使用者的独立运行核验列入后续队列。
