# 图像编解码

公开三参 `编算术捷图` 受图像、品质及采样之式，生顺序算术 JPEG；定例 CI 及独据见[捷图算术编码](捷图算术编码.文言.md)。

此包径依标准库、校验、压缩、图像量化及开媒影。便图块循字节区间召公共循环校验三二，压流用压缩包，动图量化用图像量化包。

图之记含宽、高、像素之制、行距、像素字节。行距以字节计，行自上而下。造图像受此五者；图像宽、图像高、图像格式、图像行距、图像像素取其项。

像素之制立为 `像素格式` 变体：灰度、灰度透明、红绿蓝、红绿蓝透明、蓝绿红透明，各有八位、十六位、单精三等，如 `灰度八`、`灰度透明一六`、`红绿蓝透明浮三二`。透明度直存。图记与内道之参皆受此式；造图像之宽、高、行距，各以同名为签。

`取像素格式实`（格式属性查询）鉴十五格而尽之，外名、式序、分量、字宽、蓝首，咸出一表；分量乘字宽，得每素之字数。`述像素格式`（格式名称输出）取其名，`析像素格式`（外部格式名称解析）于边界核名，返 `成否`（结果类型），未知则携 `未知像素格式名` 之误。解文件头时，据色类与位深一次定其式，逐素之内道径用其属性。

下列诸格式已有实编解、固定回归与公开试图之验。图像处理、矢量图形、图表及字体库用同制图像数据。各格式之提案甲乙全验继续。

PBM、PGM、PPM之读入口由网便图模块供之，读三制之六种文字、二进制，含注、逐行位填、八位与十六位大端之值。解码出八位灰度或红绿蓝。编码出二制，依行距抄像素。十六位保真，列后续。

尚可图解六类数据块，编三、四通道八位图；编码径出颜色块。

十六位与单精度分量皆用小端字节序。

轩窗位图读 BMP、DIB 之一、四、八、十六、二十四、三十二位、位域、RLE4/RLE8；出三十二位图。图标读 ICO/CUR 之 DIB 帧、透明遮罩、热点，出单帧三十二位图标或光标。图标之 PNG 载荷由便图解之；接口详《轩窗位图》。

动图具全局局部色盘、透明、隔行、动画之延时与处置二三；解码动图取首帧，解码动图动画出合成图像与毫秒之帧列。编码直依共用图像量化包，用中位切分色盘，透明度不及百二十八者共透明索引，存不透明黑色，出单帧。循环数、纯文扩展之绘、多帧编码列后续。

任意像素映射图读写 PAM 之灰度、灰透明、彩色、彩透明，皆有八位及十六位。PAM极值二五六至六五五三五者，读为 `灰度一六`、`灰度透明一六`、`红绿蓝一六` 或 `红绿蓝透明一六`；文件大端转图之小端，存分量原数。十六位编码循图之行距取小端，以大端紧排列出P7，极值六五五三五；八位编码极值二五五，读之仍依旧八位缩放之法。位像素映射图以百二十八为界，将灰度出为 PBM。

便图解 PNG 之诸色制、合法位深、色盘、透明、阿达姆七隔行，存十六位分量，出小端 RGBA16 或 RGBA8。解码便图附块还图及附块原字节，诸附块随出。编码便图受图与零至九压缩级，具灰度、灰透明、RGB、RGBA 之八位十六位，逐行依残差择五滤，召纯豫言泽压库。解时读图数之前之向：eXIf 之块依 TIFF 方向之标正其图，ImageMagick 式「Raw profile type exif」之 zTXt 块解压后依十六进之文读出 TIFF 再正之；图数之后之向块不计。

解码图像依魔数选便图、尚可图、PBM/PGM/PPM/PAM、轩窗位图、轩窗图标或光标、动图、捷图、网图及标签图，开媒图以文件类型之盒与 avif、avis 之牌辨之，余以塔加图头验之，同还解成或败。网图核RIFF及WEBP标，标签图辨II/MM字序。动画取首帧。捷图读基线、渐进之霍夫曼及顺序、渐进之算术编码。

动便图之源具帧控、默认图排除、透明合成、处置、八位十六位帧之读与全画布帧之编，总入口取动画首帧，动画读取败则还静态便图。详见[动便图](动便图.文言.md)。最新同配5384链之整体类型、固定回归及七组官方独立末帧参验皆过；官方色盘透明图依规范，色盘可先于动画控块。各入口百万隔离及诸后端全验继续。

标签图读标准四十二号格式之首目录，具原始、打包游程、字典与收缩压缩，条带分块、交错独立平面、水平预测、灰度、真彩、色表、四色与透明像素，依八向摆正。详见[标签图](标签图.文言.md)。整体类型、固定向量与一千二百九十六次变异、十份官方原件及三份标准转换图、十三组独立全像素差分皆过。新增统一识图固定回归待实运；大标签图、浮点、传真与捷图压缩列后续。

网图具无损编解、有损关键帧之解、透明层与动画合成。`解网图` 还图像解码结果，动画取合成首帧；`解网图动画` 还全帧列。详见[网图](网图.文言.md)与包内[动画画布](动画画布.文言.md)。无损双向像素比对与有损独立参验皆过，仓外六真网图之尺寸与像素核过；动画外部全参、百万变异与性能之验列后续。

塔加图读原始、游程之色盘、灰阶、真彩，依横纵原点及二行、四行交错列之，出红绿蓝透明8；编码出左上原点三十二位透明真彩图。扩展区、色校元数据及游程编码待后续。详见《塔加图》。

公开试图出[libpng官方PngSuite目录](https://github.com/pnggroup/libpng/tree/libpng16/contrib/pngsuite)，定版`d76d5106f041b97b3462d15bce738f2a4412de47`，作者Willem van Schaik、Glenn Randers-Pehrson。作者许无费使用、抄、改、分发其图。试图藏仓外，豫言「便图样本核验」读所授目录，逐字比基础隔行图与原图。此番五十一图皆过。

捷图基线多扫增 SOF0 分离、部分交错、跨分离异次及非交错灰度块读，外签如故。同一 SOS 次依 T.81 验之。内部别面共用旧整数逆变、颜色与 EXIF。公共类验、固例运行、六合法固图之 djpeg 独比及同客体原生固例皆过。二倍色度用[精细采样](捷图精细采样.文言.md)，官方二百二十七乘一百四十九品质九十之三采样，默认 djpeg 独比与同客体原生皆足四十五点一二分贝，余品质分段核之。详[捷图基线多扫描](捷图基线多扫描.文言.md)。
