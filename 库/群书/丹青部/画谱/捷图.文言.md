# 捷图基图之解

`捷图` 篇设 `解码捷图`，受 JPEG 字节串，还共用图像解码结果。成则携灰阶八位或红绿蓝八位之图，依行次藏之。

标记之析读量化表、霍夫曼表、八位基帧、重启之距及扫描之首，验段长与分量。旧单扫成者守之。新基线多扫依 SOS 标识映帧分量，别藏像面，具分离、部分交错及跨分离扫之异次分量。同一扫依 T.81 循帧次。单分量扫每单元惟编一块，采因参与面布局。量化表循文件锯齿之次，授扫描篇。

四色之帧以 CMYK 解之，Adobe APP14 标记择倒置 CMYK 或 YCCK。解成则循 EXIF 方位易像素与尺寸。

多扫公共类验、固例运行、六合法图之独器 djpeg 差分与同客体原生固例已过；真实彩色诸扫继续分段核之。固例与参数详《捷图基线多扫描》。渐进与算术，由一统入口选其篇。
