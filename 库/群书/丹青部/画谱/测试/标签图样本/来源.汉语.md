# 标签图样本来源

样本取自 [LibTIFF 官方测试图片集](https://libtiff.gitlab.io/libtiff/images.html) 所列的 [图片归档](https://download.osgeo.org/libtiff/pics-3.8.0.tar.gz)。归档 SHA-256 为 `e0e34732b61e1ce49eff2c7a079994c856d2a5f772f5228c84678272bc6829a9`。文件保留原始字节，以中文名登记。

| 仓内文件 | 归档原名 | 覆盖 |
| --- | --- | --- |
| 灰度打包条带.tif | cramps.tif | PackBits 灰度条带 |
| 灰度原始分块.tif | cramps-tile.tif | 未压缩灰度分块 |
| 真彩字典条带.tif | quad-lzw.tif | LZW 真彩条带 |
| 真彩字典分块.tif | quad-tile.tif | LZW 真彩分块 |
| 灰度16收缩.tif | ladoga.tif | 十六位 Deflate |
| 真彩字典平面.tif | oxford.tif | 独立平面 |
| 色表打包.tif | jello.tif | 色表与 PackBits |
| 透明字典.tif | strike.tif | 关联透明与 LZW |
| 花纹灰度16.tif | depth/flower-minisblack-16.tif | 十六位灰度 |
| 花纹真彩交错.tif | depth/flower-rgb-contig-08.tif | 交错真彩 |
| 花纹真彩平面.tif | depth/flower-rgb-planar-08.tif | 独立平面真彩 |
| 花纹四色交错.tif | depth/flower-separated-contig-08.tif | 交错 CMYK |
| 花纹四色平面.tif | depth/flower-separated-planar-08.tif | 独立平面 CMYK |

花纹图片由鲍勃·弗里森汉用 GraphicsMagick 开发版生成，原归档 `depth/README.txt` 声明其为公有领域。其他图片的来源说明保存在原归档 `README` 中。

样本核验入口读取十个原件与三个标准转换图，并比较灰度条带与分块、真彩条带与分块、花纹 RGB 两种平面及花纹 CMYK 两种平面。三个旧原件保留供来源追踪。标准转换由已安装 LibTIFF 的 `tiffcp` 独立读取原件生成，参数及 SHA256 如下。

| 转换文件 | 原件 | 参数 | SHA256 |
| --- | --- | --- | --- |
| 标准灰度分块.tif | 灰度原始分块.tif | `-c none -t -w 256 -l 256` | `d1e67cbcaddaf3cfd8f00b4621bef8f68d3f56a76ee2fda7d1447edac48bd1c6` |
| 标准字典分块.tif | 真彩字典分块.tif | `-c lzw -t -w 128 -l 128` | `dd58536f19af0731febf622e3f0adf10246cfcffde9a0614a4e520fc05d0a26f` |
| 标准字典条带.tif | 真彩字典条带.tif | `-c lzw -s -r 5` | `ee5048879b796d3de9f0a7121295bd24ec5fb1e2d907f14678864c4a6e569bec` |
