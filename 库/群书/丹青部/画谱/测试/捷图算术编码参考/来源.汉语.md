# 单像素算术编码独立参考

本任务独立构造五个标准ASCII PGM，宽高均为1，最大值255，像素为0、64、128、192、255。现成官方LibJPEG-turbo 3.2.0（build 20260630）通过 `/opt/homebrew/opt/jpeg-turbo/bin/cjpeg -arithmetic -quality 75 -outfile 输出.jpg 输入.pgm` 生成五个顺序算术JPEG，分别以 `djpeg -dct int -pnm -outfile 回读.pgm 输出.jpg` 回读，五命令均退出零且回读像素与输入相同。

品质75的DC量化为8，常量块DCT直流为 `(像素−128)×8`，量化系数因此为像素减128，交流系数全零。熵段从偏移120起，到EOI前止；固定测试直接比较独立熵字节，覆盖255补零、正负直流和省末零。

输入为本任务构造数据，参考为标准工具独立编码结果，随仓库测试资料保存。工具算法及使用条件见官方[LibJPEG-turbo](https://github.com/libjpeg-turbo/libjpeg-turbo)与[README.ijg](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/README.ijg)。本库实现采用纯豫言及既有T.81概率表，测试数据生成期间调用现成工具。
