# 单像素算术编码独立参照

本任务独造五标准ASCII PGM，宽高皆1，最大值255，像素为0、64、128、192、255。既有官方LibJPEG-turbo 3.2.0（build 20260630），以 `/opt/homebrew/opt/jpeg-turbo/bin/cjpeg -arithmetic -quality 75 -outfile 输出.jpg 输入.pgm` 生顺序算术JPEG五，复以 `djpeg -dct int -pnm -outfile 回读.pgm 输出.jpg` 读之，五令皆零退，所复读像素皆同输入。

品质75之DC量化为8，常块DCT直流为 `(像素−128)×8`，量化系数即像素减128，交流皆零。熵段自偏移120至EOI前。固定试术直校独立熵字，以验255补零、正负直流及省末零。

输入由本任务造，参照由标准工具独立编码，随仓库测试资料藏之。工具算法与用之条件见官方[LibJPEG-turbo](https://github.com/libjpeg-turbo/libjpeg-turbo)及[README.ijg](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/README.ijg)。库术用纯豫言及既有T.81概率表；造测试数据时用既有工具。
