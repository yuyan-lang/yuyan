# 捷图精细色度采样

内部 `捷图精细采样` 模块用纯豫言整数运算还原二倍色度。横向二倍、纵向二倍及双向二倍采用三比一中心权重；双向组合权为九、三、三、一，总权十六。偶奇像素用不同整数偏置舍入，分量边界按实际像素宽高延拓。横向二倍的实际分量宽度超过二时采用精细模式；小宽度循参考器的直接重复行为。其他采样比例沿原直接取样。

采样平面包含相邻 MCU 的色度行列。基线二倍色度转入完整分量平面后采样；渐进及算术共用同一平面取样。灰度与全尺寸分量直接读取，公开函数签名保持原状。生产只依赖豫言库。

整数权重、边界与舍入行为按 [libjpeg-turbo 3.2.0 官方 jdsample.c](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/3.2.0/src/jdsample.c) 的 h2v1、h1v2、h2v2 规则独立编写。

实际验证：完整5384同配新guest构建和固定回归通过。227×149官方原始彩像经 cjpeg 品质90、合法跨分离扫描重排编码，4:4:4、4:2:2、4:2:0 对默认 `djpeg -dct int -rgb -pnm` 的平方差总和分别为3439、4006、3307，颜色样本数101469，均满足至少45.12 dB门槛。同guest原生预编二实际固定回归及三种差分全部通过，平方差与诺节相同。

品质25和100进一步使用标准部分交错扫描与逐MCU重启，三采样诺节及同guest原生六项全部通过；平方差依444、422、420为品质25的9180、7086、5542，以及品质100的2935、3269、3215，颜色样本数均101469。新采样后的旧渐进、算术和往返固定回归构建及运行全部通过。

旧最近邻的真实默认参考失败及单独 `-nosmooth` 定位记录完整保留。验收使用默认参考与原门槛。真实CMYK/YCCK、全部EXIF方向及渐进算术独立公开图的完整验收另列范围；本记录证明当前三品质三采样矩阵。
