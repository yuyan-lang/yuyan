# 网影容器

版本：0.1.0。

「影匣」按 RFC 9559 读网影（WebM）与 Matroska 的容器，只碰字节与格，不碰解码。规格依据：RFC 9559（Matroska 容器）、RFC 8794（可扩展二进制标记语言，EBML）。

## 入口

- `影匣解卷`：把整份字节解成一卷（`影匣卷`）。先验文件头与文档类型（`webm`、`matroska`），再找段（Segment），读段信息（TimestampScale）、轨表（TrackEntry 的轨号、类别、编码、私有数据、画面宽高、采样率、声道、帧期、编码延迟）、簇（Timestamp、SimpleBlock、BlockGroup 与 ReferenceBlock）与提示（Cues 的 CueTime 与 CueClusterPosition）。
- `影匣首视`、`影匣首声`：卷里第一条画面轨、声音轨。
- `影匣卷宽`、`影匣卷高`：第一条画面轨的宽高。
- `影匣轨帧`：卷里属于某一轨的帧。
- `影匣关键序`、`影匣寻关键`、`影匣寻时刻`：关键帧下标、按时刻找最近的关键帧、按时刻找第一帧。

## 记录

`影匣卷` 有尺度（纳秒）、时长（毫秒）、轨列、帧列与提示列。`影匣轨` 有轨号、类别（一画面、二声音）、编码名、私有数据、画面宽高、采样率、声道、帧期与编码延迟。`影匣帧` 有轨号、毫秒时刻、是否关键帧与编码字节。`影匣提示` 有毫秒时刻与簇位置。

## 块与花边

简单块（SimpleBlock）的关键帧看标志字节最高位；块组（BlockGroup）的关键帧看有没有参考块（ReferenceBlock）。花边（lacing）照 RFC 9559 第三节拆帧：Xiph 法逐字节累加、满二百五十五继续；定长法按帧数均分；EBML 法先读第一帧长，其余读有号差值。花边里各帧共用块头的时刻。

## 位流

`位流` 模块读可扩展二进制标记语言的变长标识与长度、大端无号与有号整数、单精度与双精度小数（符号、指数、尾数按位还原）、ASCII 文字，并把一段字节切成 `影匣元素` 记录。

## 限制

已知长度的段与簇照常读；长度未知的流式段与簇按父界收尾，紧邻的下一元素可能读不进来，留待后续版本。多段文件只读第一段。加密的轨道、字幕轨与章节不读。
