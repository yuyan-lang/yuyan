# 网影容器

版本：0.1.0。

「影匣」按 RFC 9559 读网影（WebM）与 Matroska 的容器，按 ISO/IEC 14496-12 与 14496-14 读动专四（MP4）容器；只碰字节与格，不碰解码。规格依据：RFC 9559（Matroska 容器）、RFC 8794（可扩展二进制标记语言，EBML）、ISO/IEC 14496-12（ISO 基本媒体文件格式）与 14496-14（MP4 文件格式）。

## 入口

- `影匣解卷`：把整份字节解成一卷（`影匣卷`）。先验文件头与文档类型（`webm`、`matroska`），再找段（Segment），读段信息（TimestampScale）、轨表（TrackEntry 的轨号、类别、编码、私有数据、画面宽高、采样率、声道、帧期、编码延迟）、簇（Timestamp、SimpleBlock、BlockGroup 与 ReferenceBlock）与提示（Cues 的 CueTime 与 CueClusterPosition）。
- `影匣首视`、`影匣首声`：卷里第一条画面轨、声音轨。
- `影匣卷宽`、`影匣卷高`：第一条画面轨的宽高。
- `影匣轨帧`：卷里属于某一轨的帧。
- `影匣关键序`、`影匣寻关键`、`影匣寻时刻`：关键帧下标、按时刻找最近的关键帧、按时刻找第一帧。

## 记录

`影匣卷` 有尺度（纳秒）、时长（毫秒）、轨列、帧列与提示列。`影匣轨` 有轨号、类别（一画面、二声音）、编码名、私有数据、画面宽高、采样率、声道、帧期与编码延迟。`影匣帧` 有轨号、毫秒时刻、是否关键帧与编码字节。`影匣提示` 有毫秒时刻与簇位置。

## 块与花边

简单块（SimpleBlock）的关键帧看标志字节最高位；块组（BlockGroup）的关键帧看有没有参考块（ReferenceBlock）。花边（lacing）照 RFC 9559 第三节拆帧：Xiph 法逐字节累加、满二百五十五继续；定长法按帧数均分；EBML 法先读第一帧长，其余读有号差值。花边里各帧共用块头的时刻。

## 位流

`位流` 模块读可扩展二进制标记语言的变长标识与长度、大端无号与有号整数、单精度与双精度小数（符号、指数、尾数按位还原）、ASCII 文字，并把一段字节切成 `影匣元素` 记录。

## 动专四

`动专四` 模块按 ISO 基础媒体文件格式读 MP4：文件类型盒（`ftyp`）、影片盒（`moov`）里的轨盒（`trak`）、媒体盒（`mdia`，含媒体头 `mdhd` 与处理器 `hdlr`）、媒体信息盒（`minf`）与样本表（`stbl` 的样本描述 `stsd`、时间到样本 `stts`、样本尺寸 `stsz`、样本到块 `stsc`、块偏移 `stco`/`co64`、同步样本 `stss`）。样本按块与样本表从文件里截出，摆成与网影相同的 `影匣卷`、`影匣轨`、`影匣帧` 记录：轨号取轨道头、时间尺度与时长取媒体头、类别看处理器四字、编码四字与宽高、采样率、声道取样本描述首项，编码配置盒（`av1C`、`esds` 等）的内容作私有数据，帧时刻由时间到样本表累加并换成毫秒。`动专四解卷` 的入参是整份字节，返回可无的 `影匣卷`；不是 MP4 时得可无。

## 限制

已知长度的段与簇照常读；长度未知的流式段与簇按父界收尾，紧邻的下一元素可能读不进来，留待后续版本。多段文件只读第一段。加密的轨道、字幕轨与章节不读。动专四分片格式的影片片段盒（`moof`、`traf`）留待后续版本；MP4 的编辑表、片段与多描述只取首项。
