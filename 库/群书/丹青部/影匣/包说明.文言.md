# 网影之匣

版本：0.1.0。

影匣依 RFC 九五五九读网影（WebM）与 Matroska 之容，依 ISO/IEC 一四四九六之十二与十四读动专四（MP4）之容；但接字节与格，不接解码。所据：RFC 九五五九（Matroska 之容）、RFC 八七九四（可展二进制之标，EBML）、ISO/IEC 一四四九六之十二（ISO 基本媒体文件之式）与十四（MP4 之式）。

## 门户

- `影匣解卷`：以整份之帛解为一卷（`影匣卷`）。先验文头与文档之类（`webm`、`matroska`），乃寻段、读段息（TimestampScale）、轨表（轨号、类、码、私据、画面宽高、采样、声道、帧期、编码之延）、簇（Timestamp、SimpleBlock、BlockGroup 与 ReferenceBlock）与提示（CueTime 与 CueClusterPosition）。
- `影匣首视`、`影匣首声`：卷中第一画面轨、第一声音轨。
- `影匣卷宽`、`影匣卷高`：第一画面轨之宽高。
- `影匣轨帧`：卷中属于一轨之帧。
- `影匣关键序`、`影匣寻关键`、`影匣寻时刻`：键帧下标、依时寻最近之键、依时寻第一帧。

## 记录

`影匣卷` 有尺度（纳秒）、时长（毫秒）、轨列、帧列与提示列。`影匣轨` 有轨号、类（一画面、二声音）、码名、私据、画面宽高、采样、声道、帧期与编码之延。`影匣帧` 有轨号、毫秒之时、键否与编码之帛。`影匣提示` 有毫秒之时与簇位。

## 块与花边

简单块之键看标志最高位；块组之键看有无参考之块。花边依 RFC 九五五九第三节拆帧：Xiph 法逐字节累加、满二五五则续；定长法依帧数均分；EBML 法先读首帧之长，余读有号之差。花边诸帧共块头之时。

## 位流

`位流` 读变长之识与量、大端无号有号之数、单双精度之小数（号、指、尾按位而还）、ASCII 之文，又以一段之帛析为 `影匣元素` 之记。

## 动专四

`动专四` 之模依 ISO 基本媒体文件之式读 MP4：文件类型盒（`ftyp`）、影片盒（`moov`）中之轨盒（`trak`）、媒体盒（`mdia`，含媒体头 `mdhd` 与处理器 `hdlr`）、媒体信息盒（`minf`）与样本之表（`stbl` 之样本描述 `stsd`、时到样 `stts`、样之尺寸 `stsz`、样到块 `stsc`、块之偏 `stco`/`co64`、同步之样 `stss`）。样本依块与样表自文中截出，摆为与网影同式之 `影匣卷`、`影匣轨`、`影匣帧`：号取轨头，时标与时长取媒体头，类看处理器四字，编码四字与宽高、采率声道取描述首项，编码配置盒（`av1C`、`esds` 等）之体为私据，帧之时依时到样之表累加而化为毫秒。`动专四解卷` 受整份之帛，还可无之 `影匣卷`；非 MP4 则无可。

## 限

量已知之段与簇照常读；量未知之流式段与簇以父界为终，紧邻之次素或不能读，待后续之版。多段之文但读首段。加密之轨、字幕与章节不读。动专四分片之影片片段盒（`moof`、`traf`）待后续之版；MP4 之编辑表、片段与多描述但取首项。
