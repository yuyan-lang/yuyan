# 抄本

读抄本（DXF 之文，二零零七版以后八位同文之书），得豫言之数据结构：抄首（HEADER）、表（TABLES）、抄块（BLOCKS）、抄元（ENTITIES）；亦以抄本之值书为二零一三版之文。

## 一节：行与组

抄本每组二行：一组码，一值。`读组` 自读位（游）读一组，还组与新读位；组为「码」与「值」二项，值存原字。`组值` 依组码之域，解值为文、整数、小数、句柄或爻。

## 一节：段与表

`读抄本` 依次读诸段。抄首收 `$ACADVER`、`$INSUNITS`、`$EXTMIN`、`$EXTMAX`、`$DWGCODEPAGE` 诸变。表收抄层（LAYER）、抄线型（LTYPE）、抄字样（STYLE）、标注样式（DIMSTYLE）与图块记录（BLOCK_RECORD）：抄层有名、色、线型、线宽与启闭，线型有名与虚线之纹，文字样式有名、字体之卷、大字之卷、宽比与倾角，标注样式留名与全组码，图块记录留名。表集之「原表」别存每表每项之全组码，视口（VPORT）、视图（VIEW）、坐标系（UCS）、应用标识（APPID）与余表亦在其中；写出时原样还之，非惟存名。

## 一节：图块与图元

图块有名、基点与其中图元。图元各带公共之属：图层、色（索引之色与真彩组码 420）、线型、线宽（组码 370）、线型之比、句柄与随层之开关。随层为阳则不书线型与线宽两码（六与三百七十），色依层色书六十二码二百五十六；读入之元随层皆阴。识 LINE、POINT、CIRCLE、ARC、ELLIPSE、LWPOLYLINE、POLYLINE 及其 VERTEX、SEQEND、SPLINE、SOLID、TEXT、MTEXT、ATTDEF、ATTRIB、INSERT、DIMENSION、LEADER、HATCH、VIEWPORT、OLE2FRAME；不识者记其类名与原始组码，不报过。

## 一节：文字

`解文字` 先依代码页解旧文，乃解 `\U+XXXX` 之转为通字（Unicode），易控制之码 `%%c`、`%%d`、`%%p`、`%%%` 为 φ、°、±、%。`剥格式` 剥多行文字（MTEXT）之格式码为纯文：`\P` 为换行，`\f`、`\H`、`\W`、`\A`、`\C`、`\T` 之属连其参尽去，花括之组去之，`\S` 堆叠之文去其叠标。原串别存。

二零零七版以前之抄本，文字依 `$DWGCODEPAGE` 所记之代码页而编。代码页为 ANSI_936（GBK）者，`解旧文` 先试八位同文，不成则以易码（编码转换之库）之 `国标解` 解为统一之码；其他代码页报不支持。

## 一节：计数

`段计` 与每段所读之组数，`元类计` 与 ENTITIES 段诸类之件数，`块类计` 与各图块内诸类之件数，`抄元数` 与 ENTITIES 段之件数。

## 一节：写抄本

`抄写` 以抄本之值书为二零一三版（AC1027）之文：卷首（`$ACADVER`、`$HANDSEED`、`$INSUNITS`、`$MEASUREMENT`、`$EXTMIN`、`$EXTMAX`、`$LTSCALE` 诸变）、空类段、表册、图块（`*Model_Space`、`*Paper_Space` 与诸块）、图元与对象（根字典、组字典、布局字典与 Model、Layout1 二布局）。表册以所读之诸表原样还之：句柄依写卷之配重排，所属易为表柄，块录之布局柄换新布局，标注样式引文字样式之三四零码换新字样柄；一零二码之外典段与余句柄引码去之，余码如原值而书。新增之层、线型与字样缀后；无视口、应用标识或标注者补 `*Active`、`ACAD` 与 `Standard` 一条。文字依八位同文直书，中文直书；行尾为回车换行；句柄一统，所属前后相承。

`抄写文件` 著抄本于卷。块参之后属性段终、旧段之后折点段终，皆归前一元。读入之抄本原样写回，不识之元与 OLE 外框不书。坐标、半径、角度与比例用宿主十七位有效之数，读之不失。

直、点、圆、弧、椭、轻多段（含凸）、样条、面、单行、多行、属定、属、引块、尺寸、引线、剖面（实心与界环）皆书。

LibreDWG 读入所需者数端：剖面之多段界书九十二码为末位一（多段）加派生，闭合之记恒一，每界环之末书九十七码零（界所引之物数）；边段界中之直线先转为多段环。界环依九十二末位判多段或边段；属定补 `280` 版号二处。属标记依抄本之值原样而书（带点者不动），欲付 LibreDWG 则由「规矩」出抄之设净化。

未决：多行只书方向向量 1/0/0，带转角者暂不存；布局定为 Model 与 Layout1 各一，图纸空间之元取旧 `*Paper_Space` 块。
