# 便携文档

生成 PDF 1.7 子集。对象从 1 连续编号；对象列表、根目录对象号交给 `生成便携文档`，返回二进制字节串。交叉引用表按真实字节偏移写出，流长度保留内部零字节。

提供页面树、页面、字体、图像、链接和书签对象构造器。字体程序由调用者提供 TrueType 或原始 CID CFF 字节；CID 编码与 Unicode 映射由调用者提供。`抽取紧凑字体` 从 OpenType 文件取出原始 CFF 表。

`真型字体子集` 接单个 TrueType sfnt 字节串与所用字形号列表，保留字形号、度量和复合字形依赖，移除未用轮廓并重算校验。字形零自动保留。PDF 字体名使用六个大写字母与加号前缀，如 `YYAAAA+YYSubset`。文字字码为大端双字节，TrueType 用 GID，CID CFF 用字体 charset 里的 CID；Unicode 映射的目标为 UTF-16BE 字节。

`紧凑字体子集` 接单字体 CFF 1 CID 字体与所用字形索引列表，保留字形零、全部子程序、charset 和所有原始绝对偏移。CharStrings INDEX 内未用字形改为单字节 endchar；INDEX 后的未引用间隙填零。原始字节串长度保持相同。`便携压缩字体程序` 复用公共压缩库的三级固定霍夫曼 Flate 编码，连续零间隙按回引用压缩。

`便携路径` 接二维绘图路径与涂法（`S` 描线、`f` 非零填充、`f*` 奇偶填充）。曲线和椭圆弧以 64 份平展写出。坐标保留六位小数。位图接连续 RGB 八位像素，复用公共 zlib 压缩嵌入；JPEG 接原始 RGB JPEG 字节。书签标题接 UTF-16BE 字节，构造器添加字节序标记。

`便携层级书签` 依次接标题、父项、目的页、前项、后项、首子项、末子项与子树可见计数。正数计数展开子树，负数计数折叠子树；叶项使用 `便携书签`。调用者为同级项填写前后链接，为子项填写父链接。

`紧凑字体子集结果`、`真型字体子集结果`、`抽取紧凑字体结果` 返回状态码与字节串：0 成功，1 输入损坏，2 版本留待后续。CFF 读取、INDEX、字形程序及 sfnt 表目录、loca、复合部件范围逐次检查，损坏输入可恢复处理。TrueType 数据入口使用 `0x00010000` sfnt 版本，CFF 抽取入口使用 `OTTO` 版本。百万变异与性能测量入口放在 `测试/全量/`。

测试数据：仓内 `豫言操作系统/裸机/字模生成/字体/原始字体.ttf` 为 LXGW/Klee 字体，使用 SIL OFL 1.1，许可证在同目录 `许可证.txt`；`思源黑体.otf` 为 Adobe Source Han Sans，使用 SIL OFL 1.1，许可证在同目录 `思源许可证.txt`。RGB JPEG 固定样本由豫言图像编解码器生成，sfnt 与 CFF 变异结构种子由测试构造。

性能实测（2026-10-08，pit-mac、Apple M2 Max、Darwin 27）：首应用相同中文与数字 GID 集合重复 100 次 TrueType 子集，Node 裁剪区间 2.365071 秒，原生预编二裁剪区间 2.565603 秒；同机 HarfBuzz 12.3.2 C 工具 100 次墙钟 0.38 秒，包含启动及文件读写。豫言输出 1,147,060 字节，C 工具输出 162,376 字节，两者保持各自元数据策略；真实样张消费两种字体的 Poppler 渲染逐字节相同。此参考的原生时间比约 6.75 倍，五倍目标的差距交原生工具链后续优化。字体性能入口在首应用的 `测试/全量/字体性能。测试。豫`；千页序列化源码在本包 `测试/全量/序列化性能。测试。豫`，运行测量继续补充。

后续版本事项：CFF2 子集、CFF 完整重排和子程序裁剪、字体集抽取、透明图像蒙版、曲线自适应精度、字体度量与文字码点自动转换。

`紧凑字符集位` 从原始 CFF 的 Top DICT 读取 charset 位置；`紧凑字形字码` 依次接原始 CFF、charset 位置和 GID，返回 CID。支持 charset 格式 0、1、2，字形零映为字码零。调用者先用字体库的 cmap 查询 GID，再用此入口生成 PDF 的双字节 CID 与 Unicode 映射。

`紧凑名称字体子集` 接原始名称型 CFF 1 与所用 GID，读取实际 endchar 的 seac 参数，通过 StandardEncoding 字符标识和 charset 查找底字、附加字 GID，再保留组件闭包。参数查询复用字体库的局部及全局子程序共享栈。组件按 Type 2 规范采用简单字形；缺失组件或嵌套复合返回事故。输出保留原始偏移、charset、全部子程序。
