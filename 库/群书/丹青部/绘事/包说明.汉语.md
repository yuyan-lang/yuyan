# 二维绘图

渐变颜料的延展方法「色标重复」按首末色标之间的实际区间取模，零宽区间取末色。线性、径向、焦点径向与锥形渐变共用「查延展渐变色」；其他延展方法沿用零到一的区间。

路径栅格先把已平展的路径切成纵坐标单调的扫描链，逐像素行维护活动链；行内只在链的端点与链的交点处分带，各带内链序固定，按填充规则求出填充区的边界，再把边界线段在各列的精确面积累加到差分数组，前缀求和得到每个像素的覆盖面积与八位透明度。每行代价与该行的链数、折点数和带数成正比。非零与奇偶填充沿用原有规则。

公开路径模型由路径指令列表组成，供 SVG 渲染与 PDF 输出共用。M 与 L 接收横纵坐标，Q 接收控制点与终点，C 接收两个控制点与终点，A 接收中心横纵、半径横纵、起角与扫角（弧度），Z 闭合当前子路径。

`矩形路径` 按横、纵、宽、高创建闭合路径。
`路径边界 路径` 返回左、上、右、下四个小数，以绘制所用的平展求取几何范围；空路径返回全零边界。

`平展路径 路径 份数` 用 de Casteljau 插值与椭圆弧采样把每段曲线按给定份数转为 M、L、Z 命令。`容差平展路径 路径 容差` 按容差自适应细分：二次、三次曲线按二阶差分、圆弧按半径与扫角取份数，使折线与曲线的距离不超过容差，每段曲线至多1024份；只含 M、L、Z 的路径原样返回。`绘制容差` 是设备像素下的0.0025，渲染、描边、虚线与路径边界都按它平展；半径2的四分之一圆弧分16段，半径6分28段。非数与无穷坐标产生可恢复的参数异常。`变换路径` 先按绘制容差除以 `变换伸缩`（矩阵线性部分的最大奇异值）平展，再逐点应用六参数仿射变换。`椭圆路径` 接收中心横纵与半径横纵，生成四个四分之一圆弧。

`造颜色 红 绿 蓝 透明` 构造 0 至 255 的 RGBA 颜色。`渲染路径 宽 高 路径 颜色 填充规则` 返回紧密排列的红绿蓝透明8图像。填充规则可用“非零”与“奇偶”。曲线按绘制容差平展，再由扫描链求每个像素的精确覆盖面积，量化到八位透明通道，恰为半值的面积向上舍入。`解析覆盖数` 与 `解析边覆盖数` 保留逐像素按边端、像素边界交点与自交点分区积分的算法，作为独立参照。

`合成颜色` 与 `合成图像` 接收源、底、算子与源图层不透明度。算子为“清除、源、底、源上、底上、源内、底内、源外、底外、源顶、底顶、异或、相加”。“源上”对应 source-over。源与底按非预乘 RGBA 输入，在合成时按透明通道预乘，输出再还原为非预乘 RGBA。分量按最近整数写入八位通道，半值向上舍入，相加结果钳制至 255。

`混合颜色` 与 `混合图像` 提供“正片叠底、滤色、变暗、变亮、差值、排除、颜色减淡、颜色加深、强光、叠加、柔光”，以及不可分离的“色相、饱和度、颜色、明度”，以源上方式合成。`路径裁剪图像 图像 路径 规则` 把路径覆盖度作用于图像透明通道。图像合成与混合接收等尺寸、紧密排列的红绿蓝透明8图像。

`描边路径 路径 线宽 连接 线帽 斜接上限` 返回可填充的描边轮廓；连接为“斜接、圆、斜切”，线帽为“平、圆、方”。轮廓由按绘制容差平展的中线生成：开放子路径是一个闭合多边形（右侧向前、末端线帽、左侧向后、起端线帽），闭合子路径是左右两个环。外侧连接取斜接点、斜切两点或圆弧点，圆连接夹角小于圆弧单步时取斜接点；内侧在两段偏移线交点退入各段不超过一半时取交点，否则经连接点绕行。各片段同向，按非零规则填充的结果与逐段矩形、连接与线帽的并集相同；重复点与零长闭合段跳过，两侧线段照常连接。`容差描边路径` 另接平展容差（与路径同一单位），先描边后变换的调用者按变换伸缩换算。`渲染描边 宽 高 路径 颜色 线宽 连接 线帽 斜接上限` 输出RGBA图像。`虚线路径 路径 节长列表 相位` 对完整子路径按弧长分段，节长须为正，奇数节列重复一次。分段时每一步至少前进百万分之一像素，节长极短（如点线的实节）因浮点误差退化为零时也不会原地不动。

`渐变色标` 由位置与颜色组成，色标列表按位置递增。颜料为纯色、线性渐变、径向渐变、锥形渐变与图像图案；延展为“钳制、重复、反射”。`颜料取色 颜料 点` 返回采样颜色，`渲染颜料路径 宽 高 路径 颜料 规则` 输出填色图像。`变换颜料 原颜料 画布到颜料矩阵` 先逆映射采样坐标，再查询原颜料，可表示非均匀缩放与剪切后的渐变。图案接收RGBA图像与从画布坐标到图案坐标的仿射变换，并重复铺排。

`字形轮廓路径` 把字体库整数坐标与隐含二次控制点转为路径，字体纵轴向上。`矢量字形路径 字体 字形号 仿射变换` 定位字形；`渲染矢量字形 宽 高 字体 字形号 仿射变换 颜色` 输出字形图像。排版者可逐字形调用，并用图层合成组合。

`模糊绘图图像 图像 半径 标准差` 在预乘RGBA浮点数据上调用图像处理高斯模糊，再输出非预乘RGBA8。`生成图像阴影 图像 颜色 横偏移 纵偏移 半径 标准差` 输出阴影；`带阴影图像` 把源图叠在阴影之上；`路径阴影` 接收画布宽高与路径生成阴影。显示控件画布的圆角、边框与圆角阴影共用这些入口。

`焦点径向渐变 外心 外半径 内心 内半径 色标 延展` 以两圆的线性插值族求采样位置，支持偏移焦点与内圆半径。二次方程取较大实根；线性退化直接求根，重合圆与无实根返回首位置。曲线覆盖按绘制容差平展后的折线求精确面积，曲线几何误差不超过绘制容差，面积量化为八位透明度。

`紧凑轮廓路径 段列表` 保留CFF原始三次控制点，移动前及段列末尾隐式闭合旧轮廓。`矢量字形路径` 优先读取紧凑轮廓段，空段列表沿用字体点轮廓入口。

`保曲变换路径 路径 阵` 逐个控制点做仿射变换，保留二次与三次曲线、不先平展（含圆弧时退回 `变换路径`）；`矢量字形曲线路径` 用它取字形，供按像素再平展的调用者（网页绘制）使用。
