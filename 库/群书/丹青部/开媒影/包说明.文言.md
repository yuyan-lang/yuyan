# 开媒影（AV1 之解与开媒图）

开媒影者，AV1 之解库也，兼析开媒图（AVIF）之盒。开媒影（AV1）出自开放媒体联盟，开媒图（AVIF）乃 AV1 之图像格式。

## 所治

- 开媒图之盒：文件类型、元数据、处理器、主项、项位、项息、项性（图像空间、编码配置、像素信息、色彩描述）、项附与项引；主图项与透明之辅项。
- AV1 之位流：开放比特单元之读、时序头与元数据之越、简化静图之序列头、帧头（尺寸、超分、瓦片、量化、分段、量差、环路滤波、约束方向增强、环路恢复、变换之模与简化之集）。
- 算术之解：多符区间之解、概率自适应、等概之位（依规范先零后一）与定长之数；默认概率表（六十张，一万八千四百三十项）、扫描之表、量化之查与块、变换、帧内模式之常数表。
- 块之重建：块划（兼横竖甲乙与横四竖四）、帧内之模（直流、方向、平滑、Paeth、色由亮出、滤波内、调色之语）、变换之尺（择模之深与矩形之块）、系数之基、枝、号与哥隆之解；去量与二至六十四点之反变换（余弦、正弦、翻转、恒等、沃什）；依翻转以残差加回平面。
- 色度：单色、四二〇、四二二与四四四之块起、子采与平面之尺；色由亮出（CFL）之号与幅，子采合之、左移与越界夹边皆依规范。
- 环路之滤：7.14 去块（先竖边而后横边、逐面；块边与变换边之判、四六八十之抽、级与限、滤掩、高边变与平判），与 libaom 之去块出逐字节同。
- 样本之出：八位与十位降八之中和、有限与全范、依帧矩阵之 BT.六〇一、BT.七〇九与 BT.二〇二〇（矩阵九）之转；透明辅项解后与主图合为红绿蓝透明八位。
- 画谱之接已成：识图之口以文件类型之盒与 avif、avis 之牌辨之，而后交开媒影解之，透明辅项并合。

```yuyan
　或有「开媒源败」于「错」则 …
```

## 名

开媒图者，AVIF 之现行译名（见《翻译列表》）。开媒影由开媒而衍，取影戏、影像之义，谓 AV1 视频之码。
