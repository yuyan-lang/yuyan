# 开媒影（AV1 之解与开媒图）

开媒影者，AV1 之解库也，兼析开媒图（AVIF）之盒。开媒影（AV1）出自开放媒体联盟，开媒图（AVIF）乃 AV1 之图像格式。

## 所治

- 开媒图之盒：文件类型、元数据、处理器、主项、项位、项息、项性（图像空间、编码配置、像素信息、色彩描述）、项附与项引；主图项与透明之辅项。
- AV1 之位流：开放比特单元之读、时序头与元数据之越、简化静图之序列头、帧头（尺寸、超分、瓦片、量化、分段、量差、环路滤波、约束方向增强、环路恢复、变换之模与简化之集）。
- 算术之解：多符区间之解、概率自适应、等概之位（依规范先零后一）与定长之数；默认概率之表（八十九张，一万九千二百五十七项）、扫描之表、量化之查与块、变换、帧内模式之常数表。
- 块之重建：块划（兼横竖甲乙与横四竖四）、帧内之模（直流、方向、平滑、Paeth、色由亮出、滤波内）、调色之板（尺、色缓与增、索引之图之波前与色序与境之哈希、依图取色，色度纵面兼增之编）、变换之尺（择模之深与矩形之块）、系数之基、枝、号与哥隆之解；去量与二至六十四点之反变换（余弦、正弦、翻转、恒等、沃什）；依翻转以残差加回平面。
- 帧内块之复：`allow_intrabc` 之帧逐块之标、位移候选之栈（上邻、左邻、右上之点、远行远列，权依规范而排而夹）、默认之位移、位移之合类与分量（号、类、零类之位与各类之位）、跳与不跳之两路（不跳者用变换之划树、帧间之变集与残差），整像素之拷，色度半像素之双线。全跳与有残之差二种内块之样已与 `aomdec` 逐字节同。
- 色度：单色、四二〇、四二二与四四四之块起、子采与平面之尺；色由亮出（CFL）之号与幅，子采合之、左移与越界夹边皆依规范。
- 多瓦之帧：瓦之息（匀间之列行对数、`context_update_tile_id`、`TileSizeBytes`）、瓦组之首（起止之标、`tg_start`／`tg_end`、字节之齐）、逐瓦各造算术之解与概率之副、瓦内依本瓦起止而行、瓦界之可得与上下文依瓦而取、跨瓦照常去块与约束方向增强与环路恢复。多瓦之样已与全 `aomdec` 之出逐字节同（二列二行、四列、四行、二五六乘一二八诸样；其最小者已入开媒小样）。
- 环路之滤：7.14 去块（先竖边而后横边、逐面；块边与变换边之判、四六八十之抽、级与限、滤掩、高边变与平判）；7.15 约束方向增强（六十四方之索引与预设强弱、八乘八之向与方差、方差调强、主次之抽与约束、色度方向之映射、越界之样不用）；7.17 环路恢复（帧首复原之参与逐单元之读、条带上下各三行、条内取约束方向增强后之样而条外取去块后之样、维纳七抽两遍、自导两遍盒滤与合成）。三者皆与 libaom 之对出逐字节同。
- 样本之出：八位与十位降八之中和、有限与全范、依帧矩阵之 BT.六〇一、BT.七〇九与 BT.二〇二〇（矩阵九）之转；透明辅项解后与主图合为红绿蓝透明八位。
- 画谱之接已成：识图之口以文件类型之盒与 avif、avis 之牌辨之，而后交开媒影解之，透明辅项并合。


## 名

开媒图者，AVIF 之现行译名（见《翻译列表》）。开媒影由开媒而衍，取影戏、影像之义，谓 AV1 视频之码。
