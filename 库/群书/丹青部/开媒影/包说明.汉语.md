# 开媒影（AV1 解码与开媒图图像）

开媒影是 AV1 解码库，并提供开媒图（AVIF）容器的解析。开媒影（AV1）出自开放媒体联盟（Alliance for Open Media），开媒图（AVIF）是 AV1 图像格式。

## 范围

- 开媒图（AVIF）容器：文件类型盒、元数据盒、处理器盒、主项盒、项位置盒、项信息盒、项属性盒（图像空间、编码配置、像素信息、色彩描述）、项关联盒与项引用盒；主图项与透明辅助图项。
- AV1 位流：开放比特单元（OBU）的读取、时序头与元数据的跳过、简化静图序列头、帧头（尺寸、超分、瓦片、量化、分段、量化差、环路滤波、约束方向增强、环路恢复、变换模式与简化变换集）。
- 算术解码：多符号区间解码、概率自适应、等概率位（按规范取先零后一）与定长数；默认概率表（六十张，一万八千四百三十项）、扫描表、量化查表与块、变换、帧内模式常数表。
- 块重建：块划分（含横竖甲乙与横四竖四）、帧内模式（直流、方向、平滑、Paeth、亮度导出色度、滤波内）、调色板（尺寸、颜色缓存与增量、颜色索引图的波前与颜色次序与上下文哈希、按图取色，色度纵面含增量编码）、变换尺寸（选择模式下的变换深度与矩形变换块）、系数的基、枝、符号与哥隆解码；去量与二至六十四点的反变换（离散余弦、离散正弦、翻转、恒等、沃什）；按翻转把残差加回平面。
- 色度：单色、四二〇、四二二与四四四的块起点、子采样与平面尺寸；色度由亮度（CFL）的符号与幅值，子采合计、左移与越界夹边按规范。
- 多瓦片帧：瓦片信息（均匀间距的列行对数、`context_update_tile_id`、`TileSizeBytes`）、瓦组头（起止标记、`tg_start`／`tg_end`、字节对齐）、逐瓦片各建算术解码与概率副本、瓦内按本瓦起止走、瓦界处的可得性与上下文按瓦取、跨瓦片照常做去块与约束方向增强与环路恢复。多瓦片样已与完整 `aomdec` 输出逐字节一致（二列二行、四列、四行、二五六乘一二八诸样；其中最小的一样已收进开媒小样）。
- 环路滤波：7.14 去块（竖边整帧后横边整帧、逐面；块边与变换边判定、四／六／八／十六抽头、滤波级与限、滤波掩、高边变与平判）；7.15 约束方向增强（六十四见方块索引与预设强弱、八乘八方向与方差搜索、方差调强、主次抽头与约束、色度方向映射、越界样不可用）；7.17 环路恢复（帧头复原参数与逐单元之读、条带上下各三行、条带内取约束方向增强后之样而条带外取去块后之样、维纳七抽头两遍、自导两遍盒滤与合成）。三者皆与 libaom 的对应输出逐字节一致。
- 样本输出：八位与十位到八位的色度中和、有限范围与全范围、按帧矩阵的 BT.六〇一、BT.七〇九与 BT.二〇二〇（矩阵九）转换；透明辅助图项解码后与主图合成为红绿蓝透明八位。
- 画谱（图像编解码库）的识图入口已接入开媒图：按文件类型盒与 avif、avis 品牌识别后交开媒影解码，透明辅助图项一并合成。

## 用法

```yuyan
寻观「开媒影」之「图式」之书。
鉴（「开媒解图源」于「文件字节」）而
　或有（「开媒源成」于「源」）则 …
　或有「开媒源败」于「错」则 …
```

## 命名

开媒图是 AVIF 的现行译名（见《翻译列表》）。开媒影由开媒衍生，取影戏、影像之义，指 AV1 视频编码。
