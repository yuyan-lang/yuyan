# 便携文档阅读

依 ISO 三千二百之一（PDF 一点七）读便携之刻，以供「展卷」阅读之程序。分解析、渲染二层：

| 模块 | 所司 |
| --- | --- |
| `物` | 物之型：空、爻、数、名、串、列、典、引与流；典之寻、按名取数取列取名取串、四隅 |
| `语法` | 记与析：白与注、数、名（井号之逸）、圆括之串（逸与八进）、十六进之串、列、典、真假空与引；逐记而读，流之原字依长取出 |
| `漉法` | 漉流之器：弗拉特（含 PNG、TIFF 之预测）、艾尔兹威、十六进、八五、连程、捷图 |
| `卷` | 卷：尾、交叉之表与流、物之流、增益之更、页树与承、加密之察 |
| `字样` | 字：嵌真型者付字模，标准十四以系统之字代之，码、宽与同文之映 |
| `渲染` | 内容之流与页之栅：绘况、径之填描与裁、灰三色四色、图之物、文（依字模栅格而记字位） |
| `纲目` | 大纲之读与目标页之算 |

渲为红绿蓝透明八位之图，由应用合于窗；字由呼者按族名而供，嵌者自析。加密之刻报“不支持加密文档”。

表单与内联之图已能画：Do 指 /Subtype /Form 则依其 Matrix 与 Resources 递归而释，BBox 与于裁；内联之像读 BI…ID…EI 之略键，画于今阵之单位方；gs 取 LW、LC、LJ 与 ca、CA。着色之样、阴影与虚线留待后版。

试以刻书现造单页之刻，核开卷、页宽高、页文与矩填之素；又核四漉之定矢。手写最小之刻（交叉引用之流与物之流）待后版。
