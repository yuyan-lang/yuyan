# 便携文档阅读

按 ISO 32000-1（PDF 1.7）读便携文档的库，供「展卷」文档阅读程序使用。分解析与渲染两层：

| 模块 | 内容 |
| --- | --- |
| `物` | 对象模型：空、布尔、数、名、串、列、典、间接引用与流；典的查找与按名取数、取列、取名、取串、取四隅 |
| `语法` | 记号与解析：空白与注释、数、名（井号转义）、圆括号串（转义与八进制）、十六进制串、列、典、真假空与间接引用；逐记读取，流传的原始字节按长度取出 |
| `漉法` | 流过滤器：弗拉特（FlateDecode，含 PNG 与 TIFF 预测器）、艾尔兹威（LZWDecode）、十六进（ASCIIHexDecode）、八五（ASCII85Decode）、连程（RunLengthDecode）与捷图（DCTDecode） |
| `卷` | 文档：文件尾、交叉引用表与交叉引用流、对象流、增量更新、页树与继承属性、加密检测 |
| `字样` | 字体：嵌入的真型字样交给字模，标准十四字体用系统字体顶替，编码、宽度与同文映射 |
| `渲染` | 内容流解释与页面栅格：图形状态、路径填描与裁剪、灰/三色/四色、图像对象、文字（按字模栅格化并记下字位） |
| `纲目` | 大纲（书签）读取与目标页换算 |

渲染输出红绿蓝透明八位图像，由应用合成到窗口；字体由调用者按族名提供，嵌入字体自行解析。加密文件报“不支持加密文档”。

表单对象、内联图像、着色图案、图案与透明组留待后续版本。

测试用刻书现造单页刻本，核对开卷、页宽高、页内容与矩形填色的像素；另核对四条过滤器的固定向量。手写最小刻本（交叉引用流与对象流）的用例留待后续版本。
