# 实时三维光栅化

界画（实时三维光栅化，real-time software rasterizer）在中央处理器上把带顶点色的三角网格按相机逐帧画进红绿蓝透明八位像素缓冲，供游戏与交互程序使用。坐标、深度与颜色插值一律用整数定点，热循环不分配对象；依赖豫章（标准库）与画谱（图像编解码库，编便图时用到），各后端共用同一份实现。

单段导入 `寻观「界画」之书。` 打开景块、割圆、取景、画幅、天光、经营六篇；编便图另写 `寻观「界画」之「模写」之书。`。

## 用法

```
寻观「豫章」之书。
寻观「界画」之书。
寻观「界画」之「模写」之书。

「帧」者「置景帧」于「宽」曰「六四零」于「高」曰「三六零」也。
「镜」者「造景镜」于「东」曰「零」于「北」曰「零」于「高」曰「一七零」于「偏」曰「零」于「仰」曰「零」于「视角」曰（「度作角」于「六零」）于「近面」曰「一零」也。
「计」者「绘景」于「帧」曰「帧」于「镜」曰「镜」于「天」曰（「默认天色」于「元」）于「块们」曰「块们」也。
「书」于（「著景帧」于「帧」曰「帧」于「路径」曰『/tmp/景.png』）。
```

画好的颜色缓冲（「帧」中「色牍」）是宽乘高乘四字节的红绿蓝透明八位像素，可以直接交给显示接口（豫寓映）的「呈像素画面」。

## 景块

`景块` 篇定义所画的基本单位「景块」：一块带顶点色的有索引三角网格，连同包围盒与远近显示范围。

- 坐标是世界平面坐标，单位厘米：东为横轴，北为纵轴，高为竖轴，右手系，竖轴朝上。
- 「位们」每顶点三个整数，依次为东、北、高；「色们」每顶点一个整数，按 0xRRGGBB 存标准色空间的红绿蓝，光照由生成方烘进去。
- 「索引们」每个三角形三个顶点序，从零起；从外面看逆时针为正面，背面剔除。
- 「界」是包围盒「景界」（东、北、高各取最小与最大）。「算景界」按顶点求包围盒，「造景块」由顶点、颜色与索引造景块并算好包围盒。
- 「近限」「远限」是相机到包围盒的水平距离范围（厘米）：距离不小于近限且小于远限时才画；远限为零表示不限远。同一片地方可以给几块精细度不同的景块，用远近范围分段，即层次细节。

## 割圆（整数三角函数）

- 角以「周角」（六万五千五百三十六）为一周；「度作角」把度数换成这种角。
- 「整正弦」「整余弦」返回正弦、余弦乘「弦率」（二的二十次方）后的整数。首次取用时用三十位定点的泰勒级数算出四分之一周的表，此后查表，各后端结果逐位相同。

## 取景（相机）

「景镜」记相机位置（东、北、高，厘米）、偏航（从正北起顺时针，偏为四分之一周时朝东）、俯仰（向上为正）、竖直视角（都以周角为一周）与近裁剪面距离（厘米）。「造景镜」按这七个数造相机。

## 画幅（帧缓冲）

「置景帧」按宽、高新建「景帧」：颜色缓冲「色牍」（每像素四字节，红在最低地址）、深度缓冲「深牍」（每像素一个小端四字节无符号整数，越大越近），以及行界、顶点暂存与裁剪工作区。暂存区随帧复用。

「置倍帧」另带放大倍数：宽、高是光栅化的分辨率，颜色缓冲的宽高各乘倍数，每个光栅像素写成倍数乘倍数的一块（横向在光栅化时写满，最后整行向下复制）。高分屏上按逻辑分辨率画、按物理分辨率呈现时用它，不必另做放大。便图也按颜色缓冲的大小编。

## 天光（天空与雾）

「天色」记天顶色、地平色（0xRRGGBB）与雾起、雾尽距离（厘米）。「默认天色」是晴天：天顶 0x4F86C6，地平 0xC9D6E3，雾从三百米起、一千二百米尽。清屏时按相机俯仰逐行算视线仰角：仰角零度以下为地平色，三十度以上为天顶色，其间渐变。雾色就是地平色：雾在起止之间按深度的倒数线性加浓（近似指数雾），雾尽以外的景块与三角形不画，远处的景物融进地平线。雾尽不大于雾起时不加雾。

## 经营（绘制流程）

「绘景」于帧、相机、天色与景块列画一帧，返回「绘计」（入选的景块数、画出的三角形数）：

1. 清屏为天空，深度清零。
2. 逐景块按近限、远限挑选；包围盒对画面四边、近面与雾尽处剔除。
3. 入选景块的全部顶点变到相机空间（整数定点，十六分之一厘米），记下近面、护边（两倍画面）与画面四边的出界标记；不出护边的顶点投影成十六分之一像素的屏幕坐标与深度键（二的若干次方除以深度）。
4. 逐三角形：三顶点同在近面之后或同在画面某边之外的剔除；都在护边之内的直接光栅化；其余在相机空间对近面与护边逐面裁剪成多边形，投影后按扇形分成三角形光栅化。
5. 光栅化（用笔篇）：屏幕上顺时针为正面；三条整数边函数逐行求覆盖区间（左上填充规则，端点整除求得，相邻三角形无缝也不重画）；深度按平面方程插值（十六位小数），颜色把红绿蓝三个通道装进一个整数一起插值；三顶点同色且不受雾的三角形平涂。像素值按有号三十二位传给四字节写入，深度键不超过二的二十九次方，读写都不分配对象。

## 模写（便图）

「编景帧」把颜色缓冲编成便图（PNG），返回（错误文字，字节）；「著景帧」写成文件，返回错误文字（成功为空）。编码用画谱的「编完璧图」，一级压缩。
