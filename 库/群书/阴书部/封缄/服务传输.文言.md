# 服务传输

`服务传输。豫` 系已受之 TCP 连与 TLS 1.3 服务会话。用者以 `始主` 作会话，设 DER 证书列、签名算法及真签名术，乃召 `接入主传`。

`推进主传` 先刷待发密文，乃读密文一次。成与候皆载 `元`；候则以 TCP `候言` 待可读而复试（套多可写，候隙即还）。用者以 `主握手已成`、`主握手曾成`、`主误`、`主已阖` 及 `取主明文` 察会话；「主握手曾成」于客之完成既验则阳，彼紧闭亦阳。

`写主传` 排应用明文；`刷新主传` 发队，存未尽之累计序。读进所生之密文，次刷发之。一连由一用者循次操作。

`终主传` 排闭告。用者刷成而闭 TCP。TCP 先闭，用者以截断治之。签名私钥藏于签名术；交换私钥与随机数，用者以安全随机字节授之。

`测试/服务传输。测试。豫` 为全树测试自见，验连之系及空队之刷；`测试/服务握手。测试。豫` 取 OpenSSL 真发之客问（录版七六九）授于服务之会，而校服务问候之式。本土司阍已与 OpenSSL 4.0.3 之 s_client -tls1_3 及 curl 互通。
