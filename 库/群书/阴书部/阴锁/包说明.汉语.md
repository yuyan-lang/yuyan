# 数据区加密

版本：0.1.0。

本包以「阴书」的阴符（AES）块与沙二五六、口令衍二为底，提供豫言操作系统的数据区加密所需的原语与 LUKS2 盘上封缄头：

- `阴锁` 模块：IEEE 1619 的 XTS 段加密与解密、LUKS2 钥槽的反取证拆分与合回、卦文（Base64）编解码、小端与大端读写。
- `钥匣` 模块：LUKS2 二进制头与 JSON 元数据区的编解码、钥槽的建立与开启、口令的更换。

段加密以段号作扭：六十四字节钥的前三十二字节加密、后三十二字节生扭，段号为小端八字节补零，十六字节一块，每块之后扭态乘二于伽罗瓦域。钥槽区以五百一十二字节为段，数据区以四千零九十六字节为段。

盘上格式依据 cryptsetup 项目公开的 LUKS2 盘上格式：二进制头四千零九十六字节（魔数、版本、头长、序号、标签、校验算法、盐、UUID、子系统、头偏移、校验和），其后为十二千二百八十八字节的 JSON 元数据区（`config`、`segments`、`keyslots`、`digests`、`tokens`），两个头各一份，合计三十二千字节，其后为钥槽区，数据区自十六兆字节起。封缄头的校验和是二进制头（校验和处写零）与整个 JSON 元数据区的沙二五六。

密钥派生用口令衍二（PBKDF2-HMAC-SHA256），盐三十二字节，迭代次数按本机速度定下且不少于十万次。Argon2id 钥槽留待后续版本。

本包只做算法与格式，不碰盘面与内核。
