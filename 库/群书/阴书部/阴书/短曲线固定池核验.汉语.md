# 短曲线固定签名池静核

本篇记录固定池源码静核。后续在正式依赖独立树完成类型、标准向量 Node 与原生短验，证据见《短曲线核验结果.汉语.md》；机器恒时核验仍待专项。

内部签名核返回 `(有效位, r||s)`；私钥及随机数范围形成零一位，非法标量以掩码换为一，随后完整执行公开位数点乘、固定宽模逆及签名计算。首数、次数是约减后的十六位肢，零检测以公开肢序累计，返回零一有效位。内部核全部秘密路径输出相同结构。

确定池每轮生成候选，调用完整签名核，计算 `选择=有效&(1-已有)`，以固定字节序掩码选择输出，然后计算 `已有|有效`。有效位、选择与已有均为零或一；掩码为零或负一，字节为零至255，按位结果保持 i31。秘密值没有用于池内条件分支或数组下标；递归终止仅由公开的三十二次计数决定。结果分支只位于最终公开接口边界。

每轮签核结束后均更新 `K=HMAC(K,V||00)`、`V=HMAC(K,V)`。先前候选已有效时仍完整执行后续候选；`r=0` 或 `s=0` 候选的有效位为零，后续候选可以被选。固定池全部无效时返回可无；无界连续重试留待后续版本。

P521 候选取得66字节并截左521位；SHA512摘要为512位，摘要数保持原位长。域约减一次使用输入小于二倍阶的前提，三条曲线域横坐标及截位候选均满足此条件。RFC6979 A.2.5、A.2.6、A.2.7 的 sample 固定随机数、r、s 已直接写入测试，同时保留默认签名、公钥及拒绝边界测试：[官方向量](https://www.rfc-editor.org/rfc/rfc6979.html)。

正式依赖取 yybs 2068413db 的 `定宽RSA。豫` 与散列模块；候选仅增加十个短曲线文件。包检查、整体类型与测试入口构建通过，现有三族官方及拒绝硬断言在 Node 和同客体硬浮原生运行通过。散列全秘密值表示与机器恒时仍待专项。每次默认签名完成32次完整内核，实际性能待测。
