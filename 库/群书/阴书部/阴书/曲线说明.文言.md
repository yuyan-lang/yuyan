# 曲线之术

`曲线` 篇供 `交换二五五一九` 与 `交换二五五一九公钥`。参及所得皆整数数组，长三十二，各项一字节。私钥先录而依 RFC 7748 钳之，原数组仍存。公钥最高位依其法清零，所得以小端正编码出之。

今小肢源码用三十二肢，各八位；蒙哥马利梯凡二百五十五轮。互易以掩码遍诸肢，密位唯入掩码之算。源码中域乘、逆元与编码，其轮数及访存之序皆由公开定轮决之。用者验输入之长，得共享之密则定遍比其全零，乃付派生。今小肢阶段以最新 8171 配套器完成型验与构建，于 pit-mac 实行 RFC 7748、RFC 8032 公钥、共享密、签名、验签及拒绝诸回归，皆过。

今回收运行时依整数之值择 i31 与完整 i64 装箱，小肢改写依逐中值之界证存 i31。机器恒时之验，俟所生码之审及计时之核；提案甲乙恒时之门，俟此验成。

验取 RFC 7748 第六点一节 Alice、Bob 之公钥及两向共享之密。法与向量本于 RFC 7748；此篇以豫言作，许可从仓中 LICENSE。

`爱德曲线` 篇供 `爱德二五五一九公钥`，种子三十二字节，生公钥亦三十二字节。用既有定宽域术，取扩展坐标完整加点与定二百五十六轮掩码梯；种子经 SHA-512，乃依 RFC 8032 钳之。公钥验取 RFC 8032 第七点一节首向量，于 pit-mac 节点宿主行之皆过。

`爱德签` 篇供 `爱德二五五一九签`，受种子数组、消息数组及字节数，得六十四字节之签。`爱德验签` 篇供 `爱德二五五一九验签`，受三十二字节公钥、六十四字节之签、消息数组及字节数，返爻。标量规约定五百一十二轮移、模减、掩码之择；签名乘加定三十二方字节卷积。验签察正点编码、非单位主群点及小于群阶之标，乃校直接签名方程。

签验取 RFC 8032 空消息及一字节消息两向量，并验篡改、非正纵坐标、单位公钥与等于群阶之标。最新配套器于 pit-mac 完成类型之验、构建及实运行。机器恒时、Wycheproof 相关全验、P-256、P-384、P-521、差分之验、原生裸机之验及性能之量，俟后续核之。

`短曲线` 之试又取 RFC 5903 第三节素域二五六之两私两公与共密 Z，双向各算而核其等于 Z；又取定标一与二为两私，点乘得乙公，双向核其共密之横。机器之恒时、Wycheproof 诸向量、差分、原生与裸机之验及性能之量，留后续核。
