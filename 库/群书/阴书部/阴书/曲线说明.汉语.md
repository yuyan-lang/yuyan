# 曲线算法

`曲线` 模块提供 `交换二五五一九` 和 `交换二五五一九公钥`，参数与结果为整数数组，长度为 32，每个元素为一个字节。私钥会复制后按 RFC 7748 钳制，输入数组保持原值。公钥的最高位依 RFC 7748 清零，输出采用小端规范编码。

当前小肢源码采用 32 个 8 位肢和 255 轮蒙哥马利梯子。交换按掩码遍历全部肢，秘密位仅参与掩码计算。源码中域乘法、逆元与编码的循环次数和访存下标由公开的固定轮次决定。调用者检查输入长度，收到共享秘密后用固定遍历比较检查全零，再交给密钥派生。当前小肢阶段使用最新 8171 配套工具链完成类型检查和构建，在 pit-mac 实际运行通过 RFC 7748 与 RFC 8032 的公钥、共享秘密、签名、验签及拒绝回归。

当前回收运行时依整数值选择 i31 与完整 i64 装箱，小肢改写按逐中间范围证明保持 i31。机器级常数时间验收留待生成代码审查与计时核验；提案甲级与乙级的恒时门槛留待完成此项核验。

测试采用 RFC 7748 第 6.1 节 Alice 与 Bob 的公钥及双向共享秘密向量。参考算法和向量来源为 RFC 7748；本文件为豫言实现，许可遵循仓库 LICENSE。

`爱德曲线` 模块提供 `爱德二五五一九公钥`，以 32 字节种子生成 32 字节公钥。它复用定宽域运算，采用扩展坐标的完整点加法及固定 256 轮掩码梯子；种子经过 SHA-512 后按 RFC 8032 钳制。公钥测试采用 RFC 8032 第 7.1 节首项标准向量，并在 pit-mac 的节点宿主上执行通过。

`爱德签` 模块提供 `爱德二五五一九签`（种子数组、消息数组、消息字节数），返回 64 字节签名。`爱德验签` 模块提供 `爱德二五五一九验签`（32 字节公钥、64 字节签名、消息数组、消息字节数），返回布尔结果。标量规约使用固定 512 轮移位、模减与掩码选择；签名乘加采用固定 32×32 字节卷积。验签检查规范点编码、非单位主群点与小于群阶的签名标量，再核对直接签名方程。

签验测试采用 RFC 8032 的空消息与单字节消息两项标准向量，并检查篡改、非规范纵坐标、单位公钥与等于群阶的签名标量。最新配套工具链在 pit-mac 完成类型检查、构建与实际运行。`短曲线` 测试另取 RFC 5903 第三节 P-256 的双方私钥、公钥与共享秘密 Z，双向各算一次并核对等于 Z；又取固定标量一与二作两方私钥，以点乘得第二方公钥，双向核对共享横坐标。机器级恒时、Wycheproof 全部相关向量、差分测试、原生和裸机验收及性能测量留待后续核验。

`曲线二六` 模块提供 `交换二五五一九` 与 `交换二五五一九公钥`，是 X25519 的第二套实现：十条二十六位与二十五位交替的定宽肢，加、减、乘、平方都在调用者给的匣列里原地运算，平方有专用做法，求逆走标准加链。测试取 RFC 7748 第五点二节两组向量与一千次迭代（首轮与千轮），全部通过。同一时段交替测量，单次标量乘中位约三点四毫秒，原有的三十二字节肢实现约二一点五毫秒。梯轮的七条临时匣列与一条常数匣列改由交换入口一次置备、逐级传用，不在级内分配。封缄（TLS）一三的客端与服务端已改用本模块。
