# 通用名称身份比较

`签发者名称` 的 `通用名称相等` 接收两个 GeneralName 编码节点，返回同类身份是否相等。`通名列交合` 核对两列中是否存在相等身份。

DNS 名称先转小写再核对合法域名与相等性。邮箱保留本地部分，域部分按小写比较。URI 的方案与主机按小写比较，用户信息、端口及路径查询片段保留精确值。目录名复用目录名称规范比较，IP 地址比较四字节或十六字节网络序载荷，注册标识比较解码后的对象标识。otherName、x400Address 与 ediPartyName 以构造节点完整 DER 身份比较。

此模块供发行者身份选择及吊销范围核对复用。名称子树约束由名称约束模块按其规范执行。

依据：[RFC 5280 的 GeneralName 与名称比较规则](https://www.rfc-editor.org/rfc/rfc5280.html)。
