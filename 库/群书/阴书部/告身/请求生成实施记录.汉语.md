# 请求与自签生成实施

本批基于 yybs `98ec53f558`，接已合入请求结构与空扩展修补，专属工作树为基础库-证书请求生成。新增请求生成和私核模块、默认发现的请求生成基本测试及双语规范，同步总集和双语包说明；容器、名称、策略、CRL、OCSP与根数据由其他任务维护。

ECDSA调用正式确定签名接口，按位数配消息散列，并将定宽r、s转换为规范正整数DER。PSS消息及MGF1散列分别取正式参数查表，盐由调用者安全随机函数提供，生成参数省略默认盐长20与尾号一，私运算复用正式定宽RSA。CSR和自签完成签名后用嵌入SPKI和完整声明算法核验，核验成功再包装；旧RSA第一版及Ed工厂由总集公开。

四个豫言文件通过格式化120，差异空白检查通过；最新86整配工具链的`豫构 检查 证书`退出零，正确发现37个证书源码及正式依赖。工具复制时发现误夹缓存，停止本人复制PID64830，清掉本人临时缓存副本，仅保留编译器、豫构和完整宿主；未修改源工具及活缓存。

基本测试源码涵盖PSS参数异散列往返、编码核接收与错MGF拒绝、真实Ed请求及自签解析验签和错签拒绝。该新入口的类型与运行实证由CI及后续基本验证补充，当前未标实际通过。用户已延期所有耗时验证，本批未启动完整类型、互操作、原生、长批或性能；机级恒时保留独审事项。
