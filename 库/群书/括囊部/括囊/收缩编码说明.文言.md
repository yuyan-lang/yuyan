# 缩流编码

`压缩原始收缩` 先受字节串，次受零至九之压缩级，还状数与压缩串。零为成。级逾域则告参数事故。

零级依标准造存储块，每块至六万五千五百三十五字。一至三级造定霍夫曼块，四至九级造变霍夫曼块。变块载完整之文字符号及距离码树，匹配至二百五十八字，距离至三万二千七百六十八字。以三字散列之链求匹配，级定搜之深；后位之匹配更长，则先出今字，再治后位。空串与诸二进制字节皆可用。

算法与码表据 RFC 1951。以标准库之客内字节缓冲、数组引用、位算行之。出缓冲取入长之倍，加一千零二十四字；码树之长分配皆定而全。依频率择码树与流式之态，俟后续之作。

核验入口 `收缩编码。测试。豫` 验零至九级、存储块之界、定码变码之类、重复之压、空串及匹配诸字。核验造 `yy编码级0.gz` 至 `yy编码级9.gz`，系统 `gzip -tv yy编码级*.gz` 可验诸出。三万二千七百六十八字之窗界、杂二进制与系统反向互解之增验，别录其事。

二〇二六年十月七日，于受信开发机 pit-mac 成十级编码往返及系统 gzip 之验。十万字、七字一复之样：零级十万零十字，一至三级六百八十八字，四至九级八百二十二字。杂二进制、窗界、系统反向互解之增验，待统一核验队列。
