# 真实流窗口参考记录

本记录补充私验候选。公开流接口仍待用户确认，发布与等级登记随确认处理。

`泽压窗口。测试。豫` 覆盖 CINFO 零至七的合法头、CINFO 八的损坏头，以及声明窗口二百五十六、距离二百五十六的合法回溯。Node 与原生使用同一 `yy真实流声明窗口测试.wasm`；原生由 E44/E801 既定两器生成，两端退出零，打印“泽压窗口CINFO零至七及距离256合法边界通过”。

`泽压窗口实验。脚本。豫` 导出的独立素材声明窗口二百五十六、实际距离二百五十七。一次与增量解码状态均为零。上游 zlib v1.3.1 原样 `examples/zpipe.c` 链接系统 libz1.2.12，执行 `-d` 后与独立预期全文 `cmp` 退出零。实验保留参考配置差异，无损坏预置断言。

RFC1950 第2.2节给出 CINFO 对窗口大小的编码；第2.3节要求检查 CMF、FLG 与 ADLER32。上游 zlib 的距离超过声明窗口检查由 INFLATE_STRICT 条件控制。当前实现保持默认参考行为，此阶段没有增加严格窗口拒绝条件。依据为 RFC1950（https://www.rfc-editor.org/rfc/rfc1950）和 zlib 的 inflate.c、inffast.c。

另有 `字典窗口边界。测试。豫` 覆盖 RFC1951 最远距离32768、长度三与固定结束码。独立原始素材为 `03deff0f00`；32768字节字典的 ADLER32 为 `8ad202e3`，增加前导字节后32769字节完整字典的身份为 `0dcf033c`。两组原始及泽压素材共44个全部切点，Node 与同客体原生均退出零，打印“字典距离32768与完整身份全切点通过”。相同末32768字节而完整身份不同的字典返回损坏状态二；缺字典返回三；输出上限返回一。字典历史保留与完整身份校验分别受这些向量检验。

空字典补充向量为 `782000000001030000000001`：FDICT已置，完整空字典身份与空正文ADLER32均为一，固定空块为0300。已提供空字典返回零与空正文，缺字典返回三，错误字典身份返回二。全部十三切点同客体Node与原生退出零，打印“空字典身份与十三切点通过”，客体SHA256为9bb44684a0e80c8892c133a16d819b6639df0f5d66cd801d012f6b4fe71b14e5。本项只增加既有接口的独立测试素材。
