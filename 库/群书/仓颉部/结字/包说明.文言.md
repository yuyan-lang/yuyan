# 文字整形

本包行 OpenType 字形替换、定位及文字整形。出字形号、横纵前进、横纵偏移与初入码点之簇序。以六十四分像素之一为度，横右纵上为正。簇序自零起；右行之段出视觉之序。

`整形文字` 受字体、像素字号、码点列与方向签，签为 `ltr`、`rtl`、`ttb`。`整形文字参数` 又受文字、语言、特性签。默认整形器理拉丁、中日韩；阿拉伯依连属属性择孤、始、间、末之形；希伯来析字正标而存簇。文字排版依字体回退分段，实召 `整形文字`。

GSUB 行单、多、候选、连字、上下文、链上下文、扩展、反向链之八查。GPOS 行单、对、草书、标记附基、附连字、附标记、上下文、链上下文、扩展之九查。上下文三式循每易后之今活序；嵌套各依己 LookupFlag 与 GDEF 类而滤。实查历阶传初源及连字组件，右行易序前依簇内前进正偏移。

文字、语言、必需特性由 ScriptList、LangSys、FeatureList 择之。默认启 ccmp、locl、rlig、liga、calt、kern、mark、mkmk，阿拉伯又择 init、medi、fina、isol；竖排启 vert、vrt2，以 vkrn 易 kern。私条件选择取字体默认 fvar/avar 归一坐标，依实轴数求 GSUB/GPOS FeatureVariations 条件及首合之替代表。默认坐标存实 GDEF 项目变体之增量。

定位值、三式锚读二、四、八位 Device 像素之增；诸查存整数分子，终乃一取整而为六十四分像素。竖排读 vmtx 本进，由 VORG 或字形界求纵原点，表阙则用字体高。旧字体由 kern 得字距。

USE 依九类音节、官属性及附加分类行字体诸阶，每节记首实 rphf、pref 事件。基本组既毕，依字体实形补圆点于破损节。默认忽略字取统一码官二元属性，出透明零进形；透明形阙则略其项。

旧九印度文字存节之逻辑入序，以今用户轴标择字体查找。杀符、辅音之二序，实探 blwf、vatu、pstf、pref 二元替换；据形源自节末择基，以基源限 half、下形及后形诸阶。基本特性逐行既毕，前元依基及显杀符定其位；实雷法依天城、孟加拉、古木基、古吉拉特、奥里亚、泰米尔、泰卢固、卡纳达、马拉雅拉姆之位置级易序，组件、源及簇俱存。泰卢固以显式 ZWJ 候雷法，马拉雅拉姆用编码雷法。正式文字排版仍循初整形之口而用此径。

本包直依标准库、字体、统一码，列于文字基础库；独立测试包亦列其下。甲之逐项实现、两端及首用之证，见《甲级审核记录》；源与修正之史，见《后续实施记录》。

## 后版之事

真字体广校、百万隔离变异及资源峰值、性能之量、裸机浏览器之消费，续行之。

`整形连接上下文` 由默认导入之 `连接上下文` 模块出，理实行异字体之阿拉伯连属，源平前去虚标；参数与簇之约见[接口规范](规范.文言.md)。

`整形文字参数轴` 公受用户轴，复用字体fvar/avar、HVAR及项目变体求值；轴标历条件特性及定位，见接口规范。
