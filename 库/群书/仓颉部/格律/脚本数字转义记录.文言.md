# 脚本数逸之源

基线取正式 yybs 之 ac6cb9f8aa。此改最新共析之脚本支；传统之数、属及统一码逸法仍循旧径。

脚本预数全式获括，略逸字与字类，故可前向数引。全十进号有实组者为反引；无 u/v 之余数循旧八进法，首零至三者至多三位，四至七者至多两位，八九存字面。类内用字逸法；u/v 之非零数须于类外引实组，零后接十进数则告事故。既生数引，复按终实组数验之。十进号过大者存超组之态，仍尽取诸数。

脚本无 u/v 者，p/P 存身份字面；u{…} 存字面 u，后付已有花括复数之析。cA 之控逸已有；此补无 u/v 类内 c 接数或下划线之法，并补坏控逸存斜线字面、退至 c 之法。

所据为 [ECMAScript 正则早错与获数](https://tc39.es/ecma262/multipage/text-processing.html#sec-patterns-static-semantics-early-errors) 及 [Annex B 正则旧法](https://tc39.es/ecma262/multipage/additional-ecmascript-features-for-web-browsers.html#sec-regular-expressions-patterns)。此次唯备常例、误例二小试之源；未行型验、构建、匹配及宿主参照。
