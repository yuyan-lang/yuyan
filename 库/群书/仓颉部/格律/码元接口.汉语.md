# 正则码元接口

`格律/码元` 提供 UTF16 码元数组的脚本正则编译与查找。每个输入整数处于 0 至 65535，孤立代理项保留原值，非法码元在解码时报告事故。

`编译码元正则(模式码元列, 标志)` 返回正则式，模式直接进入共享整数解析器。`查找码元正则(正则式, 文本码元列, 起点)` 返回可有匹配结果，起点、整体与全部捕获区间都按原码元计数。未参与捕获保持 `(-1, -1)`，具名捕获编号保留原编译结果。

含 `u` 或 `v` 时，有效高低代理对合成一个执行码点，孤立代理项仍为一个执行整数；不含两旗时，每个码元为一个执行整数。Unicode 模式起点在代理对中间时，使用代理对首码元边界。捕获通过执行边界表映射回原码元区间。

`格律码元解`、`格律码元边界`、`格律码元起点`、`格律码元捕获` 是同模块的复用辅助函数。查找复用现有整数执行入口，大小写、断言与词字符规则由脚本编译和执行器统一决定。

`备考码元(正则式, 文本码元列)` 把同一串上的解码资料与执行器匣列一次备好，返回 `(码料, 码器, 码长, 码原, 码平)`；`依程寻码元格律备(正则式, 正则程序, 备考, 起点)` 与 `寻码元格律备(正则式, 备考, 起点)` 用备考反复查找，`起位` 与 `回果` 在原码元位置与执行位置之间换算；码长与原码等长时没有代理对，两处换算都原样返回。批量匹配与分割先把整串备一次，再逐步查找。`寻码元格律备` 对扩展正则仍走回溯执行，线性程序只由 `依程寻码元格律备` 使用。
