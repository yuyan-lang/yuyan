# PCRE x 旗适配调查

固定官方原件为 PCRE2 提交 `5ebb40cc9e32132d829487c3a5fa945090de6a13`。样本记录输入物理行，输出同一原模式与主题回显：输入 313 对应输出 576，输入 446 对应输出 854，输入 3957 对应输出 6245，输入 3960 对应输出 6249，输入 3964 对应输出 6254，输入 6247 对应输出 9866。源：[testinput1](https://github.com/PCRE2Project/pcre2/blob/5ebb40cc9e32132d829487c3a5fa945090de6a13/testdata/testinput1)、[testoutput1](https://github.com/PCRE2Project/pcre2/blob/5ebb40cc9e32132d829487c3a5fa945090de6a13/testdata/testoutput1)。样本中零行号为人工最小例，另外保存官方实际向量。

[官方 pcre2pattern](https://www.pcre.org/current/doc/html/pcre2pattern.html) 的字符与元字符章节规定 x 忽略类外空白及类外 `#` 到换行的注释；逃逸空白仍可匹配，普通类内空白保留。当前解析器层一连项入口已有空白和注释跳过，字符类及逃逸路径独立，输入 313 可核这两个保持规则。固定默认 LF 换行的 ASCII 范围先适配，其他换行约定与非 ASCII 字节另行按块记录。

静读确认层二原子后量词入口原先直接查看下一字符，遇到空白或注释时没有先略过。因此固定三个块 `a*b *\w`、`a*b#comment` 加 LF 后 `*\w`、`a* b *\w` 会把分离的星号读成缺少前项。官方输出均匹配 `a`。最小例 `^a *$` 配 x 对 `aaa` 应命中。此次已实现共用词法略过 helper，在连项入口、原子后量词前、量词后偏好标记前调用，读取当前作用旗；保持类内与逃逸路径独立。可执行回归覆盖官方样本、非贪婪标记、局部旗及 ix 组合。

私适配器放行单 x 前，词法守卫应保存类内、反斜线逃逸、类外注释状态。类外未逃逸 `#` 之后直到 LF 或文件末尾的原文属于注释，注内未知反斜线和控制项应忽略，不据此判待适配；例 `^a#\q(*UNKNOWN)` 加 LF 后 `b$` 配 x 对 `ab` 命中。模式原字节与来源行仍原样保存，实际忽略位置由词法状态决定。单 x、ims 任意组合与现已识别 ASCII 模式可先纳入；真正有效的未知语法仍保留明确待适配理由。

外修饰 xx 对应 PCRE EXTENDED_MORE，其类内空格和水平 Tab 也忽略。官方 6247 的局部 `(?x:...)` 会恢复单 x 类内空格，而 6250 普通组保持 xx，结果分别命中和不命中 `< >`。现通用外旗拒重复 x，不能把 xx 当成单 x 放行。extra 修饰、局部旗、引用区段及其他 PCRE 特设由适配器逐块单列，继续按既定范围推进。

花括号内部的空格与水平 Tab 是现代 PCRE 本身的量词语法，单 x 关闭时官方原件 6676、6679 也会按量词匹配；这部分与共享 ECMA/RE2 字面回退合同分开处理。样本备源完成格式化检查，执行与类型核验由统筹统一进行。
