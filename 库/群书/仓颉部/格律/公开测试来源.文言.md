# 公开测试来源

公开例之测试取八对式文，出于 [RE2 官方搜式之表](https://github.com/google/re2/blob/main/re2/testing/search_test.cc)，彼用 BSD 之许可。获位循左先、贪取之义核定，皆以码点为界。

四坏式出于 [Rust regex 官方回归之表](https://github.com/rust-lang/regex/blob/master/testdata/regression.toml) 无崩溃诸例；彼用 MIT 或 Apache 2.0 之许可。诸例编时须告异常。

上八对搜式之例与四坏式，首阶段构建及运行皆毕，退出皆零。

`官方线性数据。豫` 增 PCRE2 十四例、Rust regex 四例、RE2 四例。PCRE2 之期取官方输出之文，获文于入文之码点位由人核之；Rust 存原 UTF-8 字节界而易为码点界；RE2 之期据式与入人工推衍。诸行存其源及适配之说，此二十二例俟运行核验。全表导入与随机对勘仍续行之。

第三方许可原文见 [PCRE 测试许可](PCRE测试许可.txt)、[Rust 测试许可](Rust测试许可.txt)、[RE2 测试许可](RE2测试许可.txt)。PCRE2 试材依公共领域之声明；Rust 存 MIT 许可；RE2 存 BSD 三条款许可及源篇版权声明。
