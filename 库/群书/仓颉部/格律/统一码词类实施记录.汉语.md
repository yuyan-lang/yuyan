# POSIX 统一码域纠正

此前源码允许 `u` 编译十四种 POSIX 类，但实际仍查 ASCII 范围；先前“已齐”范围说明由本记录纠正。本批在编译正文内新增局部 Unicode 判定，复用已正式二元属性与一般类别，没有新增数据表或公开辅助函数。

依据 [Perl 官方类文档](https://perldoc.perl.org/perlrecharclass)和[官方 mktables 生成公式](https://github.com/Perl/perl5/blob/blead/lib/unicore/mktables)，`u` 的十四类采用 XPosix 全域定义，图形为 White_Space、Cc、Cs、Cn 的补集，打印为图形与水平空白之并再去 Cc；水平空白为 Zs 与制表符。`lower`、`upper` 在 `i` 时采用 Cased，其他属性固定域；类中字面与范围逐项折叠，避免 POSIX ASCII 类被额外折入 Kelvin 字符。无 `u` 的范围表保留。

新增正常 Unicode 组合与错误 ASCII 越域两项自动发现冒烟。按用户要求只源码格式化、差异检查，未新增类型、构建、运行或复杂验证；验收状态继续依据历史真实记录。
