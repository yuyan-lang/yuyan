# 脚本字符

`模式词码` 按标志选择传统统一码词字符或脚本 ASCII 字母、数字与下划线，脚本 `iu`、`iv` 同时接收简单折叠到 ASCII 的字符。`模式空白` 为脚本加入 FEFF、排除 NEL，使用 ECMAScript 空白与换行集合。

`脚本规范码` 使用单码点大写映射，展开多码点及非 ASCII 映至 ASCII 时保留原值。`模式折判` 在脚本非 Unicode 模式筛选同规范值的候选，在 Unicode 模式使用简单折叠等价类。回溯反向引用使用同一规范值；两个执行器的脚本末锚在无 `m` 时要求输入末尾。

整数模式解析入口把该模块接至字符类谓词。线性程序的锚点保存局部多行与忽略大小写选择，词界按各锚点选择判定；增量锚点同步解码多行选择。完整脚本数字转义判定列为后续事项。
