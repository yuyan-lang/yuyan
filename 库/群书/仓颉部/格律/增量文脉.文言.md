# 增量文脉

`增量文脉。豫` 据线性指令程、前后码及有效旗，求增量闭包与可达表。模块直依核心及脚本字符，供增量态与区间问共用。

前文脉有六：零为输入始，一为 ASCII 词字，二为简单折叠至 ASCII 词字之非 ASCII 字，三为余通用 Unicode 词字，四为换行，五为余字。所代表码次为始哨、a、ſ、汉、LF、叹号。词界用 `模式词码`，局部锚码还 i、m 有效之状。

程有 N 指令，则编码号为守卫乘 N 加真指令号。卫零为常态，卫一为尚须消费末换行，卫二为末换行已耗而后文脉须 EOF。空迁袭其卫，卫一消费则为卫二。闭包以后字为换行存卫一，以 EOF 存卫二。

传统非多行 `$` 与 `\Z`，后码为换行则入卫一，EOF 则常通；脚本非多行 `$` 于 EOF 通，多行 `$` 后码换行则常通。`\z` 于 EOF 通。前后词字及输入始之判，皆在同闭包。

`文脉前类` 受前码而返六类号。`文脉指令号` 返真指令号；`文脉指令接` 求消费后之编码目标；`文脉表位` 为编码号乘六加前类。`文脉闭包` 受程、旗、编码号列、前后码，返去重之消费与完成前沿。

`文脉可达表` 返可进、到终二爻数组，各长 N 乘十八。始以 EOF 闭包之完成指令为到终种。诸消费谓词枚举 Unicode 标量域，以后文脉类记可满足之证；始类零属前脉，消费证用一至五。继以前后类代表求空迁及消费边，反复传到终之关系，至固定而止。可进者，至少耗一字后得至终；到终亦含当下 EOF 即可受之态。

未来字证之域为 Unicode 标量，自零至 10FFFF，除 D800 至 DFFF。冷态造表须全谓词枚举及固定点闭包，后可用缓存、谓词位图速之。此次源已格式化、验差异；执行之试，由统筹增量批安排。
