# 区间转移

`正则状态区间转移(状态, 低, 高)` 返回覆盖合法 Unicode 标量的连续闭区间段。范围裁剪至零至 10FFFF，排除代理码点，包含空后继集合的陷阱状态。

每个候选码点先传入 `增量闭包(状态, 实际后字)`，再筛选消费指令。闭包中的程序计数器保留末换行与消费后必须 EOF 的守卫编码；读取指令通过 `增量指令号` 得原编号，后继通过 `增量指令接` 保留守卫演进。已消费而必须 EOF 的路径不继续消费。

连续区间的合并键同时包含排序去重后的编码后继集合与 `增量前类(实际后字)`。上下文区分起点、ASCII 词字符、非 ASCII 折叠至 ASCII 词字符、其余 Unicode 词字符、换行和其余字符六类。空集合陷阱态也保留上下文分段。

七元状态结构保持原样，第三下标字段保存段低码点作为实际前字代表。相同上下文类与后继集合允许共用这个代表；结束成立由增量模块按前文上下文及编码编号判定。区间查询直接计算迁移，逐码点缓存保持原状态。

冷查询全域成本为 O(1112064*k)，k 表示一个候选码点的闭包、消费筛选和后继排序成本。多个模式的产品状态数可呈指数增长。新增两个基础 CI 测试源码覆盖同后继跨词字符边界及空集合陷阱态跨边界；本批只完成格式化和差异检查，未类型检查、构建或运行。
