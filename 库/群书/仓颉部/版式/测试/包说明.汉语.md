# 文字排版测试

测试自动断行、行间坐标、制表进位、竖排、两端对齐与强制换行后的空行。字体链测试覆盖字体回退、方向层级分段和继承字符的基字字体。

混排样例覆盖中日韩括号禁则、拉丁与希伯来混排、阿拉伯右向顺序、括号、显式嵌入和隔离、行尾空白复位、回车换行、图片占位与竖排。

全量目录的隔离入口采用基础库测试设施的变异批次协议，输入种子路径、起点、次数和进度路径。每个字节映射固定Unicode码表，再调用真实字体段落排版并核对行宽非负、字形簇位于原输入码点区间。父程序可以按精确输入编号重放异常。百万输入、逐输入分配峰值、裸机和浏览器核验另行记录实际结果。
# 性能入口

全量目录的性能入口接受每轮次数，预先解析固定字体，真实执行中英、希伯来和阿拉伯混排。三轮预热后报告九轮整纳秒中位数，原生为主体，同客体Node作对照。实际耗时与运行产物另行登记。
# 字体回退连接冒烟

断后重整入口保留两个基本情形：定字体A你B在宽1024下返回1024、576两行，后行簇序仍为原文2；空输入返回空行。测试由全树测试自动发现。

连接回退入口保留两个基本情形：beh与teh由1000、2000单位em的两个字体真实回退，初末形分别为2、3并保留字体序与原簇；空段落输出空字形行。固定字体GSUB与cmap由测试源码独立构造。
