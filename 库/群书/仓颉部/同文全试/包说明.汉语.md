# 统一码全量测试

版本：0.1.0。父包：文字基础库。直接依赖标准库、统一码、基础库测试设施。

本包以六个模式串行验收八位码、规整、切分、双向、大小写与列宽的确定性变异。复用统一码的模糊样本与性质模块，纯核验函数副本位于模糊核心；生产接口保持既定签名。

隔离入口在每条操作前同步写出序号及三十二位同余种子，记录为两个十进制字段的 TSV。父程序启动每批前写入序号 -1。批起点通过仿射快速幂推进，等同原三十二位线性同余逐条迭代；成功批次核对末序与末种子。每批通过限时隔离运行向量启动，时限含启动成本，超时终止并收取，返回保留码 124。

失败保存原进度及退出码至进度路径加 `.失败.txt`，重放序号及种子至 `.失败.tsv`，原输入字节至 `.失败.bin`。父程序按该序种在新限时子进程单条重放，原批失败保持失败。子进程尚未写进度时，以该批首条重放；残缺进度的原文仍保存。

构建入口：豫构构建统一码全量测试的脚本 `隔离入口。脚本`、`隔离验收。脚本`；输出建议 yy统一码隔离入口.wasm、yy统一码隔离验收.wasm，并发度 24。验收参数依次为子程序、模式、数量、批量、毫秒、初种、进度路径；模式可为全部。例：全部 1000 257 60000 20261007 yy统一码进度.tsv。超时负控参数为：超时负控 子程序 毫秒 进度路径。

核心。测试验证快速推进与原逐条迭代相合及双字段记录。百万全量由独立验收运行，普通 CI 跳过两个 CLI 入口；核心短测进入 CI。

后续验收：操作系统提供强分配上限后接入硬分配控制。当前保证为限时、强制终止、收取、精确进度及失败重放；耗时与峰值内存另作测量。百万各模式的正式结果在独立实施记录中登记。
