# 超文本传输

请求之址先验控制之字而后正之，析败则还空。范围续传依所报全长验下载已毕，续接分段核原表示之编码。网页收缩之握手校客户窗口守所议之限。简单获取循公开安全请求之门，终文皆守长度之界，零期限之请直成失败之务。

默认请求议现有四种正文之压缩，范围请求取原表示，首部方法与无正文之态皆存原应。内容编码合重复之牒，容空列之项，兼旧收缩之名及裸收缩之退路。转向保获取及首部方法之正文；改取获取，兼除正文之元牒；安全传输下行，除其来源之址。

上传之解受前言及界行末白，完整闭界乃终其文；多段字段之元牒核其控制字节。正文之流容首部值两端之白，尾牒守分帧之界，上传涤旧尾牒之声明。实体之签依引号而分，数字地址之饼域须全同，饼寿严格读十进之数，超长则饱和而存。

安全方法之后，响应之藏保其获取旧录；非安全方法得成功或转向之应，乃撤对应之藏，交换或应答败则仍存旧录。主机小饼与域之匹配皆归小写；`__Host-` 之饼原属须无 `Domain`，且明定 `Path` 为 `/`。宽松同站之饼随顶层导航，兼核实际请求为安全方法。

## 获取网址

HTTPS 用 `获取网址` 与 `获取网址字节`（模块 `简单获取`，在默认导入之列）；标准库之明文客户惟司 HTTP。

```
「获取网址」乃化「网址」为「字符串」而化「超时」为「整数」而「客户端响应」也。
「获取网址字节」乃化「网址」为「字符串」而化「超时」为「整数」而「字节串」也。
```

呼之如 `「获取网址字节」于「网址」为『https://yuyan-lang.org/』于「超时」为「六零零零零」`。

- `获取网址` 以 GET 取 http 或 https 之址，返终应（状态码、字段、正文）。
- 转向至多十跳，Location 依今址解之，查询串原样存之。
- 超时为全转向链共守之总毫秒，负则不限。
- https 用默认安全之配：Mozilla 根证（`根证书数据`）、今 Unix 之时（`豫言操作系统时间` 之「读取当前纪元毫秒」）及标准库之「获取安全随机字节串」，行安全传输之 TLS 1.3 客户。
- 正文依 Content-Length、分块或读至连闭而收全，乃依 Content-Encoding 解之（gzip、deflate、br、zstd），解后之限一 GiB。
- 每请附 `User-Agent: yuyan` 与 `Accept: */*`；欲收发小饼则用 `请求默认网址`。
- `获取网址字节` 终状在二百至二百九十九则返正文，他状报事故，其文如 `网址获取失败：状态 404：<网址>`。网络、安全传输、证书之误亦报事故，书其由与网址，如 `证书验证失败：证书路径未通至可信根`、`证书验证失败：主机名与备用名称不匹配`、`证书验证失败：叶证书超出有效期`、`对方安全传输警报 40（握手失败，对方可能只支持 TLS 1.2）`、`异步任务超时`。

联网之验在 `测试/公开安全获取。测试。豫`，全树测试惟验其类；互通之果与所费之时见《公开获取实施记录》。惟支 TLS 1.2 之站留待后版。

`请求网址详情经传输` 与 `请求默认网址详情` 还最终网址及客户端之应。最终之址存片段，默认之请解压而存地址；旧请求入口取详情之应。转向之验兼核最终地址、方法之易及跨源凭据之去，浏览器资源读取用详情入口。

私藏客户之应，以 `新响应缓存` 始之。`缓存请求网址` 受实交换之术，`缓存网址经传输` 径接既有明文、安全传输。GET 藏其 ETag、Last-Modified，次交换复验，304 合首而存旧体。Vary、凭据、小饼各隔其变体；no-store、范围、自设条件者径交换。藏限十万项、一吉字节正文，今每用必复验。

`读取静态文件响应` 实取卷及修改秒，复用日历 HTTP 日期、媒体型及范围核；`读取静态文件响应经媒体` 受应用辨类之术。`编制静态响应字节` 存 HEAD、304 表示之长而发实体。简易网页服务器之文件及首页循此口，存其网页用境及 GBK 宣类。常规藏应、读卷之试由全树试发现。

私有 `静态文件` 受应用所得文件字节，依同源 SHA256 生强 ETag，借文件类型库识媒体类型，编 GET/HEAD、条件304及单范围206/416之应。`条件缓存` 制 ETag 与 Last-Modified 请求条件，304沿旧正文而更元数据，日期之析由明定代术供之。定例 `测试/静态缓存。测试。豫` 验二进制范围、HEAD、条件304及沿旧正文。此批交协议源，文件权限读取之应用装配、多范围应、默认日期及型验互通之验续行。

私有 `网址客户端` 析绝对及相对转向之址，循301、302、303、307、308治方法与正文，跨来源则去 Authorization、Proxy-Authorization 及显式 Cookie。`小饼交换` 每目标依域路径及安全同站策略重择小饼，逐项受独立 Set-Cookie。调用者供明文及安全交换、时钟、日期与公共后缀策略；今超时各计一跳。定例 `测试/网址转向。测试。豫` 验相对之址、方法之易及跨源凭据之去。全转向期限、默认策略之合及正式应用消费列后事。

私有 `多段表单` 编 multipart/form-data 字节正文及内容类型，部分存字段名、可有文件名、媒体类型与原字节；元信息转义引号及反斜线，各部分及终界用CRLF。边界可依既有安全随机接口生成。定例 `测试/多段表单。测试。豫` 验空表终界、文件名转义、二进制正文及内容类型。此批交编码源，上传交换之系、服务端之析及型验互通之验续行。

私有 `内容编码` 循 Content-Encoding 之逆次，调用压缩库既有 gzip、zlib封装deflate、br、zstd 解码术，各层依调用者所定出限，败之状态化为结构异常。解应答后更 Content-Length、去 Content-Encoding。定例 `测试/内容编码。测试。豫` 验多层次序、二进制正文、字段之易及出限之传。此批交源之系，型验及互通之验续行。

私有 `事件流` 编多行数据、事件名、识符及重试毫秒为 SSE 字节消息；`流式服务` 自已受 TCP 连接发响应首部、分块正文及尾部，成终或异则一次闭连，空片仍可续流。`写服务事件` 径发消息于响应流。定例 `测试/事件流。测试。豫` 验多行事件及首部未发终结块之界。此批交服务端源及测试之系，事件接收之析、监听消费、型验及真互通之验续行。

私有 `会话小饼` 源解属性，依域、路径、期限、Secure 及 SameSite 策略筛请求字段，日期与公共后缀由明定代术供之。`范围` 源制 Range 及 If-Range，验206之始位及片长而缀二进制正文，200之答则易旧文。定例 `测试/会话小饼。测试。豫`、`测试/范围。测试。豫` 为全树自得。此批交源；默认日期与公共后缀配置、交换之系、型验及互通之验续行。

私有 `二版传输` 源依公共 TCP 接口驱先验明文请求，循窗口分发正文、读设置及应答，成或异则一次闭连。`网页消息压缩` 合压缩之记、消息片及控制帧为独立接收态，终片解压而验文本，存跨消息字典。`测试/压缩分片。测试。豫` 为全树自得之定例，验压缩片间 PING 及后消息引字典。此批交源及 CI 之系，型验及真互通之验续行。

私有超文本传输2核具帧编解、设置、独立流、首部续帧及窗口之制。网页套接字核具客及服务端握手、掩码、分片、控制帧与文本之验，网页压缩核依同源 DEFLATE 解码器藏有界字典。定例在 `测试/超文本传输2。测试。豫`、`测试/网页套接字。测试。豫`、`测试/网页压缩。测试。豫`，全树测试自得之。此阶段交源及 CI 测试之系，型验、双端互通、压缩之议及消息之合列后事，甲乙之验续行。

首部整数未读首字，先验其位之界；字面量缺名或值长者，以可承之结构异常拒之。定例含 `41`、`00`、`10`、`0000` 截断之文。

私有首部压缩核具 RFC7541 静表、动表、前缀整数、字面量、永不索引之记及全霍夫曼解码。动表计名值字节加三十二，块首改限则裁旧项。定例 `测试/首部压缩。测试。豫` 验 RFC 请求块、动态引用、霍夫曼主机、整数一千三百三十七，及清表、改限越界、坏索引、截断与补位之拒；官方向量之字及预期皆沿原。此例以完整25a843诸器构建，于诺驿及 E44/E801 原生预编二执行器皆过。公开之出及超文本传输2连接互通列后阶段。

接收态积诸字节片，解文后返报文与余态。报文藏起始行、字段、二进制正文、尾字段及留连之记。块长容附辞，零块后解尾字段；正文长依字节裁取，无长之应待连闭而成。

编解可序列化分块，验重长及字段名。明文客端借公共传输控制协议发字节，循长与块终收应，越信息之应；遇异则闭连。

`异步发送请求` 次受方法、主机、端口、请求目标、字段列、字节正文与毫秒之限，归 `异步任务于客户端响应`。客端藏启连、验连、发、收四状，诸候付公共协作调度，期起于编码之前；负限则无期。成、异或到期，统闭连一次，再候沿取终态。明文请求应答之正文皆用字节串；HTTP 字段名无关大小写而易，IPv6 主机入字段则括以方括号，入 TCP 地址则去之。

`安全客户端` 为私有接线候稿，受 TLS 客户配置及两明定终态查询代术，复用请求之状与期及善后。每会话依公共保密随机接口各取三十二字节随机数及私钥，主机配置须同请求主机，协议候选定为 http/1.1。公开入口 `获取网址` 经此与真 HTTPS 之站互通。

`测试/异步客户端截止。测试。豫` 以系统暂配之口启纯豫言静默 TCP 服务，受明文请求或 TLS ClientHello 而察客到期之闭，验复候及一次善后；同消费者于诺驿与 16c 原生预编二执行器皆过。`测试/安全驱动。测试。豫` 于诺驿验固定终态错误之传、复候、零期及主机之限。诸类型及构建以 20261008T023627Z-5384a0b1 全 Wasm 诸器验之，构建时闭旧发行日志编码之途。

转向、Cookie、内容编码、multipart、服务端、网页套接字、代理、缓存与超文本传输2续行。甲乙之验俟全能及互通毕；CPU 连续运行之抢占留后。

“请求安全响应”受 TLS 客户配置、方法、主机、端口、目标、字段、正文与超时，返异步响应任务。此入口径用安全传输客户之错与闭态之察，共用既有请求驱动与闭连善后。调用者供证书核验之配置；`获取网址` 以默认之配呼之。后台回归验零期与复候。
“解析请求地址”用网址解析库，得 HTTP/HTTPS 之来源、主机、端口、请求目标与安全之标。请求目标存查询、去片段；默认端口归一于来源之文。“请求来源获准”依规范化来源列精确求合，协议与端口皆别之。址内凭证可由请求标头供之。宿主授权表之接与实传输续作。

`解析默认小饼` 合默认日期及公共后缀策略，应用供主机、路径、安全来源与真纪元秒。日期循 Cookie 词序取时、日、月、年，再依日历验而换算，两位年以七十为界。存储以名称、域、host-only之记及路径为键，更旧者存创建次序；发送循路径长及创建次序，明文来源欲覆同名重叠安全小饼则留旧值。空 Domain 依默认主机，公共后缀恰同今主机则为仅主机属性。

`请求默认网址` 径候正式明文及安全异步客户，逐跳收发小饼，合默认日期、官方公共后缀与默认证书配置；转向全链共守毫秒之期。调用者供真 Unix 纪元秒时钟、同站上下文、顶层安全导航之记及解压上限。范围之请用 identity 内容编码，终应依正式内容编码模块而解。默认导入含公共后缀、小饼日期、默认小饼及默认网址请求四模块；常规 CI 默认网址之例验零期限于连前终止。
