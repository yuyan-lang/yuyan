# 超文本传输

请求地址在规范化前检查控制字符，解析失败返回空。范围续传以服务器报告的完整长度确认已完成下载，分段续接核对原始表示编码。网页收缩握手校验客户端窗口选择符合提议上限。简单获取调用公开安全请求入口，最终正文统一受长度限制，零期限请求直接形成失败任务。

默认请求协商四种现有正文压缩编码，范围请求采用原始表示，首部和无正文状态直接保留响应。内容编码支持重复首部、空列表项、旧式收缩别名及裸收缩回退。重定向保持获取与首部方法的正文，改为获取时同步清除正文元数据，安全传输降级时清除来源地址。

上传解析支持前言和界行尾部空白，完整关闭界才终止正文；多段字段元数据检查控制字节。正文流接受首部值两端空白，尾字段遵守正文分帧限制，上传时清除旧尾字段声明。实体标签按引号边界拆分，数字地址小饼域采用精确匹配，小饼寿命严格解析十进制并饱和处理超长数值。

响应缓存保留安全方法后的获取记录，非安全方法取得成功或重定向响应后撤销对应缓存，交换失败与失败响应保留已有记录。主机小饼及域匹配统一小写；`__Host-` 小饼要求原始属性中无 `Domain`，且显式 `Path` 为 `/`。宽松同站小饼的顶层导航同时核对实际安全请求方法。

## 获取网址

HTTPS 用 `取驿址` 与 `取驿址字节`（模块 `简取`，在默认导入里）；标准库的明文客户端只管 HTTP。

```
「取驿址」乃化「网址」曰「文」又化「超时」曰「数」为「客户端响应」者也。
「取驿址字节」乃化「网址」曰「文」又化「超时」曰「数」为「帛」者也。
「取驿址抬头」乃化「网址」曰「文」又化「超时」曰「数」为（「列」于「字段」）者也。
```

调用写成 `「取驿址字节」于「网址」曰『https://yuyan-lang.org/』于「超时」曰「六零零零零」`。

- `取驿址` 以 GET 取 http 或 https 网址，返回最终响应（状态码、字段、正文）。
- 转向至多十跳，Location 按当前网址解析，查询串原样保留。
- 超时是整条转向链共用的总毫秒数，负数不限时。
- https 用默认安全配置：Mozilla 根证书（`印谱`）、当前 Unix 时刻（`豫寓时辰` 的「读今纪元毫秒」）与标准库的「密抽帛」，走安全传输的 TLS 1.3 客户端。
- 正文按 Content-Length、分块或读到连接关闭收全，再按 Content-Encoding 解码（gzip、deflate、br、zstd），解码后的上限是 1 GiB。
- 每次请求带 `User-Agent: yuyan` 与 `Accept: */*`；要收发小饼时用 `索常驿址`。
- `取驿址抬头` 以 HEAD 取最终应答的首部（不取正文），状态不在 200–299 时报事故；联网更新用它取 Content-Length，在下载前算要多少空间。
- `取驿址字节` 在最终状态为 200–299 时返回正文，其余状态报事故，消息形如 `网址获取失败：状态 404：<网址>`。网络、安全传输与证书的错误也报事故，消息写出原因与网址，例如 `证书验证失败：证书路径未通至可信根`、`证书验证失败：主机名与备用名称不匹配`、`证书验证失败：叶证书超出有效期`、`对方安全传输警报 40（握手失败，对方可能只支持 TLS 1.2）`、`异步任务超时`。

联网验收在 `测试/公开安全获取。测试。豫`，全树测试只检查它的类型；互通结果与耗时见《公开获取实施记录》。只支持 TLS 1.2 的站点留待后续版本。

`索驿址详情由传` 与 `索常驿址详情` 返回最终网址和客户端响应。最终网址保留片段，默认请求在解压后保留地址信息；原有请求入口取出详情中的响应。转向测试同时核对最终地址、方法变化及跨源凭据清除，浏览器资源读取消费详情入口。
