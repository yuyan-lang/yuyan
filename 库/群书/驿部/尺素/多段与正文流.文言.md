# 多段表单及请求体流

`超文本传输/表单解析` 有 `解析多段表单`，受边界之串及体之原字节，还 `表单部分` 之列。重名与其次皆存，文件守原字节。字段名、文件名、媒体类用 UTF-8 首部之文。引号参数受反斜转义及分号。

`超文本传输/表单上传` 有 `上传安全表单`，依次受安全传输客户之制、主机、端口、请求目标、首部、部分列及毫秒之候限。以公安全随机生界，自设 Content-Type 与 Content-Length，复用既有 POST 安全请求之驱，还客户响应之异步任务。

`超文本传输/请求正文流` 有 `新请求正文流(元)`、`喂请求正文(态, 新字节, 受体术)`、`请求正文已终(态)` 及 `结束请求正文(态)`。受者可径以体片写文件、增量解器或应用之缓冲。可治 Content-Length 及分块之编，读块扩展后之长及尾字段。态之一为阶段，二为未决及后请之余字节，三为今待收之体长，四于首部后存请求字段、于有尾字段之终态存尾字段，五存请求始行。终态之二可授后请之新态。

常验之口为 `测试/表单解析。测试。豫` 及 `测试/请求正文流。测试。豫`。前验重名、中文元信息、引号、分号及零与255字节；后遍验定长与分块之文各二段切处及后请之余。
