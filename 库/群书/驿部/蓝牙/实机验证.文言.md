# 实机验证之序

一、于豫言之机插 USB 蓝牙控车（口类二百二十四、子类一、约一）。开机，核心之通用串行（USB）识其口，驱号三十六之通用串行蓝牙接三端，服务百一七至百二零乃见。

二、入壳，书 `「蓝牙态」`，当报「有器」，并出收发包之数；无控车则报「无器」。

三、书 `「蓝牙寻」`，待十秒许，列近器之址与类；再书可复询。

四、令目标之器入可配之态，书 `「蓝牙配」于「址」曰『址』`（址用十六进之文，如 `001122334455`）。控车行简单之配：示能、确认、口令皆依器之能自应；成则配对之录书于 `/系统/蓝牙/配对。数据。豫`。

五、书 `「蓝牙断」于「址」曰『址』` 以断；书 `「蓝牙忘」于「址」曰『址』` 以去其录。

六、重启，开机之脚本中 `「蓝牙回连」` 逐连已配之器；亦可于壳中手书。

七、若控车不认（厂商私有之初始化），`「蓝牙态」` 恒为无器；此之类不为。

限：建连之后惟发认证；查人机之服、开控制中断之道、设引导之约、以 HID 之报入键鼠之环，皆待接线（见包说明之后续）。
