# 津梁（网页套接字与 TCP 中继）

津梁取通津架梁之意。库以原始目标与已核验目标两个抽象类型分开连接前、连接后的目标状态。目标主机由驿址（网址库）规整，端口限定为一至六万五千五百三十五并剔除二十五。

连接前校验字面地址，连接后通过问连址（套接字地址查询）核验实际对端。已核验目标保存对应连接，转发入口接收已核验目标。公网范围校验覆盖四版地址与六版全局单播地址，专用、环回、链路本地、运营商级 NAT、组播、保留及文档地址列入禁区。

协议见底层网络规范的“浏览器”平台注记。

津请合（中继升级请求判定）在百分号解码后核对路径，并核对升级标头。浏览器发送的编码路径与直接发送的汉字路径共用此入口。

`凭验`模块提供令印（令牌摘要）的抽象类型、配置摘要校验、令牌摘要计算与定长比较。鉴权函数接收客户端令牌，成功时返回令印。`承客`模块的置津设（中继设置构造）接收鉴权函数、Origin 白名单和日志函数；同一设置共用每个令印三十二条连接的配额。

理中继（中继会话处理）接收客户端连接、升级报文、后续余字节与中继设置，返回可等待任务。客户端先发文字`凭 <令牌>`，中继完成鉴权、来源检查与目标连接后回文字`连上`。转传（双向字节转发）只接收验目（已核验目标），用二进制消息承载原始字节流；客户端文字`缄口`关闭目标的写方向，目标余下字节继续向客户端发送。目标有序关闭时发送关闭码一千。

候继（任务完成接续）以承候（完成回调任务构造）串接首帧、目标连接与转发阶段。遣验目（异步连接与核验）按最终结果调用回调；连验目（同步等待连接与核验）供逐项执行的调用方取用。同一设置中的各连接分别推进输入输出事件，空闲客户端保留自己的等待记录。

每条连接结束时，日志函数收到一行文字，依次含令印前八字符、目标、往向字节数、还向字节数和毫秒时长。配额在终止记账时归还。
