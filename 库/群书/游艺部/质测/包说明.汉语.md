# 质测（碰撞与物理）

碰撞、射线与角色控制库，游戏引擎第一期的第三项（[提案 00018](../../../../提案/00018-设计语言与引擎.汉语.md) 与 `库/群书/游艺部`）。质测取徐光启“质测之学”的意思，即格物实测：先在形体上量出相触与穿透，再让角色与载具在实测里走动。供游戏运行时使用，只依赖豫章。

## 模块

| 模块 | 内容 |
|---|---|
| `向量` | 本库自己的「质向」（横、纵、深三个小数）、小数四则、长度、距离、取分量、造轴方向、近似比较与横纵深三个方向常值。另立一名，与匠心的「三维向量」形状相同，免得两库同时导入时重名 |
| `形状` | 形体：球体、轴对齐盒、有向盒（斜盒）、胶囊与三角网格。两两相触的判定，给出穿透深度、单位法线与接触点。法线从甲指向乙，沿法线把乙推开「深」即分开 |
| `盒树` | 中位切分的层次包围盒（自匠心溯光抄出，改成静态三角形）、射线最近命中、球与胶囊沿线扫掠的首次碰撞 |
| `世` | 碰撞世界（球、轴盒、斜盒、胶囊的列与三角网格树列）、胶囊对世界的接触收集与射线查询 |
| `角色` | 胶囊角色：贴地行走、上台阶、坡度限制、沿墙滑动、跳跃与重力 |
| `载具` | 简版轮胎贴地与转向：车轮沿射线找地面，车身随地面高低，按轴距与舵角转向 |

## 约定

- 长度用世界单位（米），角度在内部用弧度，构造器上的角度用度；纵轴向上。
- 接触法线从甲指向乙，深度是沿法线把乙推开多少就能分开；接触点是两者表面点的中点。
- 角色以脚点为位置：胶囊下端在脚点加上半径，上端在脚点加高减半径。
- 三角网格先当三角形列；对网格的接触暂时逐个三角形测，盒树的碰撞剪枝与扫掠剪枝留待后续版本。
- 射线查询覆盖球、轴盒、斜盒与三角网格，胶囊留待后续版本。
- 热循环的整数定点留待后续版本。

## 测试

`测试/形状。测试。豫` 测各形状相交的已知例、穿透深度与法线方向；`测试/射线。测试。豫` 测射线命中三角网格的距离与球、胶囊扫掠的首次碰撞；`测试/角色。测试。豫` 让胶囊角色在台阶与墙的世界里走一百二十步，核对不穿地、不穿墙、上得台阶，并测跳跃与斜坡；`测试/载具。测试。豫` 测车轮贴地与转向。
