# 质测（碰撞与物理）

碰撞、射线与角色控制库，游戏引擎第一期的第三项（[提案 00018](../../../../提案/00018-设计语言与引擎.汉语.md) 与 `库/群书/游艺部`）。质测取徐光启“质测之学”的意思，即格物实测：先在形体上量出相触与穿透，再让角色与载具在实测里走动。供游戏运行时使用，只依赖豫章。

## 数制与约定

九州的硬条件：每帧路径只用整数。长度（位置、半径、距离、深度）用厘米整数；方向与法线是单位向量乘「定率」（六五五三六）；比值（坡度、正切、时间秒）也乘定率；角用「周角」（六五五三六为一周），与游场、界画一致。只用整数散列与整数开方，不读时间，同一场景两次推进逐位相同。

- 纵轴向上；角色以脚点为位置：胶囊下端在脚点加上半径，上端在脚点加高减半径。
- 接触法线从甲指向乙，深度是沿法线把乙推开多少就能分开（厘米）；接触点是两者表面点的中点。
- 实体：球体、轴对齐盒、有向盒（斜盒）、胶囊与三角网。
- 接触：球、轴盒、斜盒、胶囊、三角网两两相触（网与网留待后续版本），另有轴盒与网、斜盒与网的求交。
- 射线：覆盖球、轴盒、斜盒、胶囊与三角网。
- 三角网先当三角形列再用中位切分的层次包围盒：网接触与球/胶囊扫掠都按包围盒剪树。
- 网与网的整数求交留待后续版本。

## 模块

| 模块 | 内容 |
|---|---|
| `定向` | 质向（横、纵、深三整数）、定乘与定除、整数开方、叉定、长度与距离、单位化、取轴与造轴、夹取与近似比较、横纵深三方向常值 |
| `定形` | 球、轴对齐盒、有向盒（斜盒）、胶囊、三角网与两两接触；盒网、斜网；深度厘米、法线定点 |
| `定盒树` | 中位切分的层次包围盒、射线最近命中、球与胶囊沿线扫掠；网接触与扫掠按包围盒剪树 |
| `定世` | 碰撞世界（球、轴盒、斜盒、胶囊的列与网树列）、胶囊对世界的接触与射线（含斜盒与胶囊） |
| `定角色` | 胶囊角色：重力、贴地、沿墙滑、上台阶（抬步高、前挪、向下射线找地）、跳跃 |
| `定载具` | 四轮各有弹簧阻尼悬挂，按向下射线找地算压缩与支承力，车身竖直速度由四轮平均支承力与重力推进；水平速度分纵向与横向，横向速度按轮胎侧向摩擦（简单线性模型）衰减；按轴距与舵角转向 |
