# 质测（碰撞与物理）

碰撞、射线与角色控制之库，游戏引擎第一期之第三项（[提案 00018](../../../../提案/00018-设计语言与引擎.汉语.md) 与 `库/群书/游艺部`）。质测取徐光启「质测之学」之义，格物实测：先量形之相触与穿透，乃令角色与载具行于实测之中。供游戏运行之用，依豫章与界画「线景」（惟取线景之通型）。

## 数制与约定

九州之硬条件：每帧之路惟用整数。长短（位、半径、距、深）以厘米为整；方向法线，单位之向乘「定率」（六五五三六）；比值（坡、切、秒）亦乘定率；角用「周角」（六五五三六为一周），与游场、界画同。惟用整数散列与整数开方，不读时，同景再推逐位同。

- 纵轴向上；角色以足点为位：胶囊下端在足点加半径，上端在足点加高减半径。
- 触法自甲指乙，深者沿法推乙多少而分之（厘米）；触点为二面点之中。
- 形：球、轴盒、斜盒、胶囊与三角网。
- 触：球、轴盒、斜盒、胶囊、三角网两两相触（网与网依三角对之最近点取深，宽相以二盒树互剪），又有轴盒与网、斜盒与网之交。
- 射线：及球、轴盒、斜盒、胶囊与三角网。
- 三角网依质心之莫顿序排为一编，八片一叶，自下而上并为块树（扁平整数节表）：建树逐位定，网触与球/胶囊扫掠依节盒与三角盒剪树。
- 连续之碰撞：胶囊与球可循移扫过三角网取初触；角色之移逾半径则分小步而进，疾者不一步穿墙。

## 篇目

| 篇 | 所载 |
|---|---|
| `定向` | 质向（三整数）、定乘定除、整开方、叉定、长短、单位化、取轴造轴、夹取近校、三方向之常 |
| `定形` | 球、轴盒、斜盒、胶囊、三角网与两两之触；盒网、斜网；深为厘米、法为定点 |
| `定盒树` | 莫顿序分块自下而上之层盒（八片一叶、扁平整数节表）、射线近击（先近后远）、球与胶囊扫掠；网触与扫掠依节盒与三角盒剪树 |
| `定世` | 碰撞之世（球、轴盒、斜盒、胶囊之列与网树列）、胶囊触世之集与射线（含斜盒与胶囊）、世与网树之互剪、世网扫与世球扫 |
| `定角色` | 胶囊角色：重力、贴地、缘墙滑、上阶（抬步高、前挪、向下投线求地）、跳跃 |
| `定载具` | 四轮各有弹簧阻尼之悬，依向下射线求地算压缩与支承，车身竖速以四轮平均支承与重力推之；水平分纵与横，横速依轮胎侧摩（简线性之型）渐衰；依轴距与舵转 |
| `定造` | 由界画线景造静世：竖直遮面循法拉出成棱柱之三角网，入盒树；地别与轴盒 |
| `定舆` | 刚体四轮车：质量、各向同性之惯量、三单位轴与角速；四轮射线悬挂之弹簧阻尼着于触点之推挽与转矩，轮胎侧摩与前轮之转，驱与制；半步长整数积分 |
| `定宽` | 整数均格宽相：依体心之格散列，惟出同格或二十七邻格之对 |
| `定应` | 整数碰撞之应：撞墙、撞体之恢复与摩擦，质可设；载具之推接撞墙之应 |
