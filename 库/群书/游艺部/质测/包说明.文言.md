# 质测（碰撞与物理）

碰撞、射线与角色控制之库，游戏引擎第一期之第三项。质测者，格物实测之学也，取徐光启之说。先量形体之相触与穿透，次令角色、载具依实测而行。资豫章，供游戏运行时之用。

## 篇目

| 篇 | 所载 |
|---|---|
| `向量` | 本库自作之「质向」（横纵深三小数）、小数四则、其长、其距、取分、造轴、近校与三方向之常。别立一名，与匠心「三维向量」同形，免二库并导而同名 |
| `形状` | 形体五：球体、轴盒、斜盒、胶囊、三角之网。两两相触，出其穿透之深、单位之法与接触之点。法自甲指乙，沿法推乙「深」而分 |
| `盒树` | 中位剖分之层盒（自匠心溯光抄出，改为静三角）、射线之近击、球与胶囊循线扫掠之初触 |
| `世` | 碰撞之世（球、轴盒、斜盒、胶囊之列与网树之列）、胶囊触世之集与射线之求 |
| `角色` | 胶囊之角色：贴地而行、上阶、限坡、缘墙而滑、能跃而受重力 |
| `载具` | 简版车轮贴地与转向：轮循射线求地，身随高低，依轴距与舵角而转 |

## 约定

- 长度以世界之尺（米），角在内部以弧，造器之角以度；纵轴向上。
- 接触之法自甲指乙，深者沿法推乙几何而可分；接触之点为二面点之中。
- 角色以足点为位：胶囊下端在足点加半径，上端在足点加高减半径。
- 三角之网先作三角之列；触网者暂逐三角而测，盒树之碰剪与扫掠之剪俟后。
- 射线之求及球、轴盒、斜盒与三角之网，胶囊俟后。
- 热环之整数定点俟后。

## 测试

`测试/形状。测试。豫` 试诸形相交之已知例、穿透之深与法线之向；`测试/射线。测试。豫` 试射线击网格之距与球、胶囊扫掠之初触；`测试/角色。测试。豫` 令胶囊角色行于阶与墙之世一百二十步，核其不穿地、不穿墙、上得阶，并试跳跃与斜坡；`测试/载具。测试。豫` 试车轮贴地与转向。
