# 屏上界面叠映

「屏题」以匠心之「映元」（二维显示之表）写游戏屏上之界面，绘为画布，乃叠于界画之景帧。界面惟一表，与浏览器、系统界面同途，游戏不复别写二维之绘。

- 文字：`题字` 以匠心之 `排字` 取字形之廓，编为 `文字元`，依字号与位置于设备之素。
- 色块：`色块` 以矩形为 `填充元`，供血条、底板与准星。
- 血条：`血条` 出底条与填条二色块，依百分比定填宽。
- 准星：`准星` 出横竖四臂。
- 最小 HUD：`造屏版` 以帧数、东北、血量、字路、画面宽高与色编为一表：左上之文、血条、幅心之准星。
- 合成：`绘屏版` 以匠心之 `分块绘显示表` 绘为画布，乃依源素之透明叠画布于景帧之色牍；帧倍为一则一素对一素，倍大于一则一界面之素铺满其物理之块。
- 图形处理器一路留待后续：今走中央处理器，林纳无窗拍照亦能出图。
- 热路惟整数与匠心之整数光栅，不读时漏；同入再绘，逐字节相同。

测试 `测试/屏题。测试。豫`：于已知底色之帧上绘一最小 HUD，核文字区有字、血条底与填之位色、准星心与四臂之位，并核再绘逐字节相同。
