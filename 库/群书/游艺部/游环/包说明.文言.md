# 游环

游戏之环：定步而进、按帧收事、插值系数、停与一步、变速、录编与重演。

## 缘起与名

游环之「环」，取《庄子·齐物论》「枢始得其环中，以应无穷」：枢居环中，应物而不穷，正游戏循环之状——时来不已，步定而前；「游」取《论语·述而》「游于艺」，与父包游艺部同族。暂名游环，由此而来。

## 所为

- 定步而进：缺省每步六十分之一秒（一六六六六六六七纳秒），可以「置环设」自定；每推受上次以来之纳秒（器物环具之「漏毫」乘「毫为纳」），折为整步。落后则一推至多补「最多补」步（缺省八），余时弃之，免追之无已。
- 插值：进果携「系数」，为不足一步之残时与步长之比乘六五五三六（自零至六五五三六）。画时以「间插」于前态与今态之整数分间插之，所插者由客自择。
- 事泵：器物所交「交互事」以「收输入」裹为「输入」置于本帧之队，显示面之尺易以「收窗改」置于队；推进之时，本帧之事尽归首步，逐步授更新。零步则事留于队，不弃亦不先交。
- 停、一步、变速：「设停」为阳则停（推进不行），停中「行一步」进一定步；「设速」以六五五三六为一倍易其时倍。
- 录编与重演：「设录」为阳，则每定步所收之事（空步亦记）添于志；「取日志」取之，「重放全」依志自首以每步之事授步函而积其态，不读真钟；同编、同初、同函，两演必逐位而同。

## 与器物主循之关系

不别起窗环：显示面、计时、绘事与提交皆交器物之「主循环」「环具」。通常之接法：

- 客态之中置一「环态」。
- 器物之「更新」回调受一「交互事」，以「收输入」置于队，还客态。
- 器物之「计时更新」回调先以「漏毫」取今毫，与上次之数相减、经「毫为纳」授「推进」；次以进果之「每步事」逐批授游戏更新之函，存新环态。还新客态则器物自画。
- 器物之「视图」回调用进果之「系数」与「间插」，画前态与今态之间；观境之尺与上次不同，则随手「收窗改」交一尺寸之事。
- 停则「设停」为阳；单帧步进则「行一步」。

## 模块

- `环中`：全部内容：`窗幅`、`环事`（输入、窗改）、`环态`、`进果`，与造环、收事、设停设速设录、行一步、清日志取日志、推进、重放全、间插、毫为纳。

## 使用

```yuyan
「环」者「置环」于「元」也。
「果」者「推进」于「环」于（「毫为纳」于「一六」）也。
「新环」者「果」中「新环」也。
「系数」者「果」中「系数」也。
```
