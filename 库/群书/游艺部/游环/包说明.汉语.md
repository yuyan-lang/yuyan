# 游环

游戏环：固定步长推进、按帧收拢输入与窗口事件、插值系数、暂停与单步、变速、输入日志与重放。

## 缘起与名字

游环的「环」取《庄子·齐物论》「枢始得其环中，以应无穷」：枢在环中，应物而不穷，正是游戏循环的样子——时间不停地来，固定的步一步步地走；「游」取《论语·述而》「游于艺」，与父包游艺部（游戏引擎诸库）同族。暂名「游环」即由此而来。

## 做什么

- 固定步长更新：缺省每步六十分之一秒（一六六六六六六七纳秒），可用「置环设」自定；每次推进接收自上次以来的纳秒数（器物「环具」的「漏毫」乘「毫为纳」），折成整步。跑慢时一次推进最多补「最多补」步（缺省八），多余的时数丢掉，免得追赶不休。
- 插值：推进结果带「系数」，是不足一步的余时与步长之比乘六五五三六（零至六五五三六）。渲染时用「间插」在上一状态与当前状态的整数分量之间插值，由使用者自己选要插值的状态分量。
- 事件泵：器物交来的「交互事」用「收输入」包成「输入」放进本帧队列，显示面尺寸变化用「收窗改」放进队列；推进时本帧队列里的事件全算在第一步，逐步交给更新。零步时事件留队，不丢也不提前交。
- 暂停、单步、变速：「设停」为阳即暂停（推进不走步），暂停中「行一步」前进一个固定步；「设速」以六五五三六为一倍改时间倍率。
- 输入日志与重放：「设录」为阳时，每个固定步收到的事件（空步也记）添进日志；「取日志」取出，「重放全」按日志从头把每步事件交给步函数累积状态，不读真时钟，同一日志、同一初态、同一函数两次重放逐位相同。

## 与器物主循环的关系

不另起窗口循环：显示面、计时、绘制与提交都交器物的「主循环」「环具」。一个典型接法：

- 应用状态里放一个「环态」。
- 器物的「更新」回调收到一个「交互事」，调「收输入」把它放进队列，返回应用状态。
- 器物的「计时更新」回调先用「漏毫」取当前毫秒，与上次的读数相减、经「毫为纳」交给「推进」；再把推进结果的「每步事」逐批交给游戏更新函数，存回新环态。返回新应用状态后器物自动重画。
- 器物的「视图」回调用推进结果的「系数」与「间插」显示上一状态与当前状态之间的画面；观境尺寸与上次不同时顺手「收窗改」交一个尺寸事件。
- 暂停只要「设停」为阳；单帧步进用「行一步」。

界面示例见 `示例/`（待办事项）。

## 模块

- `环中`：全部内容：`窗幅`、`环事`（输入、窗改）、`环态`、`进果`，以及造环、收事、设停设速设录、行一步、清日志取日志、推进、重放全、间插与毫为纳。

## 使用

```yuyan
「环」者「置环」于「元」也。
「果」者「推进」于「环」于（「毫为纳」于「一六」）也。
「新环」者「果」中「新环」也。
「系数」者「果」中「系数」也。
```
