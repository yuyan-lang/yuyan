# 按辔（暂停菜单）

「按辔」是游戏引擎 1.0 的暂停菜单库。菜单用系统的界面框架「门面」搭：继续、设置、退出三个按钮，设置页一个音量滑条。焦点、悬停与按下态都用门面与器物现成的做法，不另写一套控件。菜单每帧求样式、排版、生成显示树，再转成匠心的「映元」（二维显示表），经「屏题」叠到界画的景帧上，与浏览器、系统界面同一张显示表。

## 名字

「按辔」取执辔而御、将止先按之意：辔是马缰，《说文》「辔，马缰也」；《周礼·保氏》教国子以六艺，御居其一。执辔而御，迟速在手；将停则按辔而止，止而择其所往，正是暂停菜单。与父包游艺部及同族的御术、游环同用御马之喻。

## 做什么

- **状态**：「置菜单」按景帧宽高与请求文件路径造一份菜单状态。状态里有器物的控件状态、当前页、音量、是否已请求退出，以及最近一次造出的元素树、显示树与交互项。
- **开合**：「游戏暂停」打开菜单（游戏应暂停）；「游戏继续」关闭菜单；「游戏退出」关闭并记下退出请求；「设游戏音量」把音量夹在零至一百。「菜单开否」「菜单已退」「菜单页」「菜单音量」「菜单选中」查询状态；「菜单按下」查当前按下的控件标识，「菜单有色」「树有色」查显示树里有没有某底色的方框（测试与排错用）；窗口尺寸变了用「设菜单宽高」换逻辑宽高并重造版，开合、页与音量照旧。
- **输入**：「菜单推进」用「御术」把键盘方向键、回车、空格、退出键与手柄十字键、甲钮、乙钮、启钮映成动作；方向的下、上换成器物的制表、上档加制表，确认换成回车，左右换成左右键，交器物现成的焦点轮换、按下与点击处理。退出键与启钮开合菜单，乙钮关闭菜单。「菜单指针」把鼠标指针事件（阶段与逻辑六四坐标）交器物的指针处理，按下、拖动与抬起都走门面现成的悬停与按下态。
- **绘制**：「菜单映元」把显示树转成匠心的显示表：方框的背景与四边成实心矩形，文字节点的段落排版按片段取字形、按字号与颜色成文字显示元；热区只画子节点，悬停显节点只在悬停时画。圆角按方角画。「菜单绘屏」把显示表交屏题的「绘屏版」叠到景帧。
- **壳命令**：同包「令」模块把「游戏暂停」「游戏继续」「游戏退出」「设游戏音量」「游戏态」的做法登记进「诏令」的实现。命令把请求写进状态文件（停号、续号、退号、音量、讯，一行五栏，制表分隔），游戏每帧用「取按辔请」读一次并办理，再把状态文字写回讯栏；菜单上的同名动作直接调库函数，效果与壳命令相同。请求文件的类型与读写（「按辔请」「按辔请径」「读按辔请」「写按辔请」）也在「令」模块，壳命令与游戏共用；「令」模块只依赖豫章、御术与诏令，不牵连菜单的界面与渲染诸库，壳会话装「游戏」部时不必载入整棵游戏引擎。
- **热路径**：只用整数定点，不读时钟；同一状态两次绘制逐字节相同。

## 用法

```yuyan
寻观「按辔」之「按辔」之书。

「态」者「置菜单」于「宽」曰「一二八零」于「高」曰「七二零」于「请径」曰（「按辔请径」于「元」）也。

「入口」乃化「有」为「有」者也。
「入口」者得「无」而
　令「无甲」为（「游戏暂停」于「态」）而
　令「无乙」为（「菜单推进」于「态」曰「态」于「键们」曰「键们」于「钮们」曰「钮们」于「枢们」曰「枢们」）而
　令「无丙」为（「取按辔请」于「态」）而
　令「无丁」为（若（「菜单开否」于「态」）则（「菜单绘屏」于「态」于「景帧」）否则「元」）而
　令「环」为（「设停」于「环」于（「菜单开否」于「态」））而
　「元」
也。
```

壳命令：

```text
壳> 「游戏暂停」
壳> 「游戏继续」
壳> 「游戏退出」
壳> 「设游戏音量」于「音量」曰「六零」
壳> 「游戏态」
```

## 待办事项

- 圆角按方角画；圆角裁剪与阴影留待后续版本。
- 菜单只处理按钮、文字与可点的横排（音量滑条）；文本框、复选框、滚动区、像素图等显示节点跳过，留待后续版本。
- 滑条用指针横坐标与左右键改音量，没有拖动滑块的手感与键盘连续加速。
- 请求文件只有一份，多个壳命令同时写时后写的留下。

## 验证

```sh
./豫构。林纳。豫行 类型检查 按辔
./豫构。林纳。豫行 构建 按辔 测试 按辔。测试 --输出 按辔测试。林纳。豫行
./按辔测试。林纳。豫行
```

测试开菜单，核默认选中「继续」；画一帧核面板、按钮、标题文字、焦点环与四周变暗的像素，另起一份状态重画并核两帧逐字节相同。按两下方向键（下、上）再回车，核选中项随焦点走、回车后菜单关闭；把菜单开否接到游环的暂停上，核菜单开着时游环不推进、关后继续推进。鼠标在「继续」上按下时核按下态像素，抬起即关菜单。设置页核滑条自动聚焦、右键加音量、下键到返回、回车回主页。请求文件核暂停、继续两条壳命令的写法与游戏写回的讯。
