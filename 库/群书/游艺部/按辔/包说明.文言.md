# 按辔（暂停菜单）

「按辔」者，游戏引擎一点零之暂停菜单也。以系统之界面框架「门面」为骨：继续、设置、退出三钮，设置页一音量滑条。焦点、悬停与按下之态皆用门面与器物之旧法，不别写一套控件。每帧求样式、排班、生显示之树，转匠人之「映元」（二维显示之表），经「屏题」叠于界画之景帧，与浏览器、系统界面同一表。

## 名

按辔，取执辔而御、将止先按之意。辔，马缰也（《说文》）；《周礼·保氏》教国子以六艺，御居其一。执辔而御，迟速在手；将停则按辔而止，止而择其所往，是暂停菜单之象。与父包游艺部及同族御术、游环同用御马之喻。

## 所为

- **态**：「置菜单」依景帧之宽高与请文之径造菜单之态。态中有器物之控件态、今页、量、已请退否，及近造之元素树、显示树与交互之项。
- **开阖**：「游戏暂停」开菜单（戏当暂停）；「游戏继续」闭之；「游戏退出」闭而记退请；「设游戏音量」夹量于零百。「菜单开否」「菜单已退」「菜单页」「菜单音量」「菜单选中」问其态；「菜单按下」问今按之标，「菜单有色」「树有色」问显示树中有无某底之框（试与排错用之）。
- **入**：「菜单推进」以「御术」映键盘方向、回车、空格、退出之键与手柄十字、甲、乙、启之钮为动作；下、上易为器物之制表、上档加制表，确认易为回车，左右易为左右键，交器物现成之焦点轮、按下与点击。退出与启开阖菜单，乙闭之。「菜单指针」以鼠标之事（阶段与逻辑六四之位）交器物之指针处理；按下、拖动、抬起皆循门面旧法。
- **画**：「菜单映元」以显示树为匠心之表：方框之底与四边为实心之矩，文字节点之段排依片取形、依号与色为文字之元；热区惟画其子，悬显之节惟悬时画。圆角以方角画。「菜单绘屏」以表交屏题之「绘屏版」叠于景帧。
- **壳命**：同包之「令」以「游戏暂停」「游戏继续」「游戏退出」「设游戏音量」「游戏态」之法登于「诏令」之实。命书请于状文（停续退之号、量与讯，一行五栏，制表分之），戏每帧以「取按辔请」一读而办，乃书态之文回讯栏；菜单之间名动作径调库函，其效与壳命同。请之类型与读写（「按辔请」「按辔请径」「读按辔请」「写按辔请」）亦在「令」，壳命与戏共之；「令」惟依豫章、御术与诏令，不牵菜单之界面与渲染诸库，壳会话装游戏部时不必载全树游戏之器。
- **热路**：惟整数定点，不读时漏；同态再绘，逐字节同。

## 用法

```yuyan
寻观「按辔」之「按辔」之书。

「态」者「置菜单」于「宽」曰「一二八零」于「高」曰「七二零」于「请径」曰（「按辔请径」于「元」）也。

「入口」乃化「有」为「有」者也。
「入口」者得「无」而
　令「无甲」为（「游戏暂停」于「态」）而
　令「无乙」为（「菜单推进」于「态」曰「态」于「键们」曰「键们」于「钮们」曰「钮们」于「枢们」曰「枢们」）而
　令「无丙」为（「取按辔请」于「态」）而
　令「无丁」为（若（「菜单开否」于「态」）则（「菜单绘屏」于「态」于「景帧」）否则「元」）而
　令「环」为（「设停」于「环」于（「菜单开否」于「态」））而
　「元」
也。
```

壳命：

```text
壳> 「游戏暂停」
壳> 「游戏继续」
壳> 「游戏退出」
壳> 「设游戏音量」于「音量」曰「六零」
壳> 「游戏态」
```

## 待办

- 圆角以方角画；圆裁与影留后。
- 菜单惟处钮、文与可点之横排（音量滑条）；文框、复选框、滚区、像素图诸显示之节跳过，留后。
- 滑条以指横与左右键改量，无拖块之实与连续加速。
- 请文惟一，诸壳命同书则后书者留。

## 验

```sh
./豫构。林纳。豫行 类型检查 按辔
./豫构。林纳。豫行 构建 按辔 测试 按辔。测试 --输出 按辔测试。林纳。豫行
./按辔测试。林纳。豫行
```

试开菜单，核默认选「继续」；绘一帧核板、钮、题文、焦环与四旁之暗，别起一态重绘而核二帧逐字节同。两按方向（下、上）而回车，核选随焦、回车后菜单闭；以开否接游环之停，核开着环不进、闭后环进。鼠标按「继续」核按下之素，抬即闭。设置页核滑条自焦、右键加量、下键至返回、回车归主。状文核暂停继续二命之书与戏所回之讯。
