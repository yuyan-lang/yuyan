# 线偶

线偶者，以匠心动作用之骨姿画为界画线景之线人，供写实城市之行人惟画线者。

## 模块

| 模块 | 内容 |
| --- | --- |
| `群步批` | 群偶远级成批出笔：近中二级逐偶出笔，远级依五百厘米批格而合，一格一簇竖线（取该格诸偶平均位），空簇不出；供图形处理器线景前之省法。 |
| `群偶` | 「造群偶」依数排为方阵，每偶自带其位、其相、其步类（站/走/跑）、相率与行速；造群偶或配状时以动段预采为帧表：细帧表六十四帧供近者全骨逐偶取，粗帧表十六帧供中者六骨共之，远者一笔竖线；帧表连骨姿与六整厘米点并藏，热环惟依下标取。「群级」数各级之偶。相、位与耗皆以整数刻算，不读墙钟，同入再算逐位相同；走跑二动状皆配则依速于走速跑速之间精混。 |
| `群行` | 行人导航：「造路网横」受折线路（每点东北整数厘米）、避让半径、格边、灯与横道（停止线至路口之距），且以节点折为扁点表、段长表与每节点灯号；「造路网」同之而横道取零；「造行态」依群偶排路序、段序与初速；「群行」依所授时刻循路而进、至端转或掉头，红灯则停于横道前以待、绿灯续行、已在横道内则续行而过，惟清上帧所过之格、依格分桶求邻，逐对以半径内之偶沿东北各推五厘米，出「群位」；群偶之「群步在」依群位出笔。整数算、不读墙钟，同入再算逐位相同；路端多出边则依序号与帧号定选下一路，不复折返；同路同向前车小于车距则减速，不穿车。 |
| `借骨` | 传景重定向：「借姿」以传景（glTF）某秒之骨架依骨名配为线偶十二骨之姿，「借骨段」依秒采为动段，「借骨状」包为循环动状交动作篇之状态机；「常名表」为常见骨名之缺省配，缺骨以恒姿补位。 |
| `线偶` | 「骨线」以骨姿列画为线笔列：一骨一笔，起为骨姿之世界平移，向为局部纵轴经旋之后，长为该序之骨长，东北高折为整数厘米；画法「偶画」给样号、厘米之倍、游场方阵、画关节否、头序与两半径，关节与头画为八折小圈（东西高之面，朝北）；「摆线」「摆笔」以既有之线依方阵整体摆之。又有程序之步态：「站段」「走段」「跑段」依步频步幅以正弦摆腿臂、二倍频起伏、一频侧摆前倾而成动段，走跑一周期采十六帧而补末帧使首尾逐位相同，可直付动作篇之状态机与一维混空；「贴地段」逐帧用牵骨之「贴足」「调髋」与双骨解析调髋、重建两腿而定脚掌，地高由回调给，「平地」为处处零之缺省。所出皆整数厘米，同入再算，逐位相同。 |

## 写法

```豫言
寻观「线偶」之书。

「画」者「平画」于「样号」曰「一」也。
「姿们」者「动段采」于（「走段」于「频率」曰「二点零」于「步幅」曰「零点七」）于「时刻」曰「零」也。
「线们」者「骨线」于「姿们」曰「姿们」于「画」曰「画」也。
```

骨姿循动作篇之约：平移为世界之起，旋以局部纵轴（向上）转于骨之实向；长依「骨长们」之次取之。关节与头之小圈在东西高之面，镜朝北则为正圆。贴地之地高回调受东、北（米），还高（米）。

## 九州接法

```豫言
寻观「线偶」之「群偶」之书。
寻观「线偶」之「群行」之书。

「群」者「造群偶」于「个」曰「一零零零」也。
「网」者「造路网」于「路们」曰「路们」于「半径」曰「六零」于「格」曰「六零」于「界东」曰「负六零」于「界北」曰「负六零」于「横格」曰「一六零」于「纵格」曰「一六零」于「灯们」曰（「罄」以「灯」）于「红灯」曰「零」于「周期」曰「一」于「车距」曰「零」也。
「行」者「造行态」于「群」曰「群」于「网」曰「网」也。
「位」者「群行」于「行」曰「行」于「网」曰「网」于「群」曰「群」于「刻」曰「刻」也。
「线」者「群步在」于「群」曰「群」于「位」曰「位」于「刻」曰「刻」于「目东」曰「目东」于「目北」曰「目北」于「目高」曰「目高」也。
```

动状配法：「配状」于「群」曰「群」于「类」曰「零/一/二」于「状」曰「动状」；不配仍用程序化站走跑。群姿一于「群」于「序」于「刻」可独取姿。诸位、半径、格边、速皆以厘米与整数刻计，时刻由调用者传。
