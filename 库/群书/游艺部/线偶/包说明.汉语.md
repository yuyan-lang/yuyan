# 线偶

线偶（wire puppet）把匠心动作用骨骼姿态画成界画线景里的线人，供写实城市只画线的行人。

## 模块

| 模块 | 内容 |
| --- | --- |
| `群偶` | 「造群偶」按个数排成方阵，每偶带自己的位置、相位、步类（站/走/跑）、相位速率与移动速度；「群步」按相机远近分三级：近处全骨每帧采样，中处选六根骨隔帧采样并缓存，最远一笔竖线；「群级」数各级偶数。相位、位置与耗时都按整数刻算，不读墙钟，同入两次逐位相同；走、跑两动状都配时按速度在走速与跑速之间混合。 |
| `群行` | 行人导航：「造路网」收折线路（每点东、北整数厘米）、避让半径与格边长；「造行态」按群偶排路序、段序与初速；「群行」按传入时刻沿路前进、到端转向或掉头，逐对把半径内的偶沿东北各推开一厘米，出「群位」；群偶的「群步在」按群位出笔。整数算、不读墙钟，同入两次逐位相同；路网可带信号灯（节点东、北与相位），红灯时行人在节点前停走，绿灯续行。 |
| `借骨` | 传景重定向：「借姿」把传景（glTF）某一秒的骨架按骨名映射成线偶十二根骨姿，「借骨段」按秒采成动作片段，「借骨状」包成循环动状交给动作篇的状态机；「常名表」是常见骨名的缺省映射，缺骨以恒姿补位。 |
| `线偶` | 「骨线」把骨姿列画成线笔列：一根骨一笔，起点为骨姿世界平移、方向为局部纵轴经旋转后的方向、长度为该序骨长，东北高折成整数厘米；画法「偶画」给样号、厘米倍数、游场方阵、是否画关节、头序与半径，关节与头画成八段折线小圈（东西高平面，朝北）；「摆线」「摆笔」把既有的线按方阵整体摆放。另有程序化步态：「站段」「走段」「跑段」按步频与步幅用正弦摆腿摆臂、二倍频起伏、一频侧摆与前倾生成动作片段，走跑一周期采十六帧并补末帧使首尾逐位相同，可直接交给动作篇的状态机与一维混合空间；「贴地段」逐帧用牵骨的「贴足」「调髋」与双骨解析解调髋、重建两腿并定脚掌，地面高度由回调给出，「平地」是处处为零的缺省回调。输出一律整数厘米，同输入两次逐位相同。 |

## 写法

```豫言
寻观「线偶」之书。

「画」者「平画」于「样号」曰「一」也。
「姿们」者「动段采」于（「走段」于「频率」曰「二点零」于「步幅」曰「零点七」）于「时刻」曰「零」也。
「线们」者「骨线」于「姿们」曰「姿们」于「画」曰「画」也。
```

骨姿沿用动作篇的约定：平移是世界起点，旋转把局部纵轴（向上）转到骨的实际方向；长度按「骨长们」的次序取。关节与头的小圈画在东西高平面，镜头朝北时是正圆。贴地的地面高度回调收东、北（米），返回高度（米）。

## 九州接法

```豫言
寻观「线偶」之「群偶」之书。
寻观「线偶」之「群行」之书。

「群」者「造群偶」于「个」曰「一零零零」也。
「网」者「造路网」于「路们」曰「路们」于「半径」曰「六零」于「格」曰「六零」于「界东」曰「负六零」于「界北」曰「负六零」于「横格」曰「一六零」于「纵格」曰「一六零」于「灯们」曰（「罄」以「灯」）于「红灯」曰「零」于「周期」曰「一」也。
「行」者「造行态」于「群」曰「群」于「网」曰「网」也。
「位」者「群行」于「行」曰「行」于「网」曰「网」于「群」曰「群」于「刻」曰「刻」也。
「线」者「群步在」于「群」曰「群」于「位」曰「位」于「刻」曰「刻」于「目东」曰「目东」于「目北」曰「目北」于「目高」曰「目高」也。
```

动状配法：「配状」于「群」曰「群」于「类」曰「零/一/二」于「状」曰「动状」；不配仍用程序化站走跑。群姿一于「群」于「序」于「刻」可单独取出姿。所有位置、半径、格边、速度都以厘米与整数刻计，时刻由调用者传。
