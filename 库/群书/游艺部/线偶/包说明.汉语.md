# 线偶

线偶（wire puppet）把匠心动作用骨骼姿态画成界画线景里的线人，供写实城市只画线的行人。

## 模块

| 模块 | 内容 |
| --- | --- |
| `线偶` | 「骨线」把骨姿列画成线笔列：一根骨一笔，起点为骨姿世界平移、方向为局部纵轴经旋转后的方向、长度为该序骨长，东北高折成整数厘米；画法「偶画」给样号、厘米倍数、游场方阵、是否画关节、头序与半径，关节与头画成八段折线小圈（东西高平面，朝北）；「摆线」「摆笔」把既有的线按方阵整体摆放。另有程序化步态：「站段」「走段」「跑段」按步频与步幅用正弦摆腿摆臂、二倍频起伏、一频侧摆与前倾生成动作片段，走跑一周期采十六帧并补末帧使首尾逐位相同，可直接交给动作篇的状态机与一维混合空间；「贴地段」逐帧用牵骨的「贴足」「调髋」与双骨解析解调髋、重建两腿并定脚掌，地面高度由回调给出，「平地」是处处为零的缺省回调。输出一律整数厘米，同输入两次逐位相同。 |

## 写法

```豫言
寻观「线偶」之书。

「画」者「平画」于「样号」曰「一」也。
「姿们」者「动段采」于（「走段」于「频率」曰「二点零」于「步幅」曰「零点七」）于「时刻」曰「零」也。
「线们」者「骨线」于「姿们」曰「姿们」于「画」曰「画」也。
```

骨姿沿用动作篇的约定：平移是世界起点，旋转把局部纵轴（向上）转到骨的实际方向；长度按「骨长们」的次序取。关节与头的小圈画在东西高平面，镜头朝北时是正圆。贴地的地面高度回调收东、北（米），返回高度（米）。
