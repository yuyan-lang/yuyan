# 文件类型数据生成

行 `yy文件类型数据生成 输入 输出。豫`，以 shared-mime-info 成豫言规则之数。原数置仓外 `~/repos/yuyan-worktrees/豫言数据`。

输入之径终于 `.xml` 或 `.in` 者，逐行取官方 `freedesktop.org.xml.in` 之 `mime-type type` 及诸 `glob` 之 `pattern`、`weight`、`case-sensitive` 属性。权重未记则五十，大小写未记则阴，`true` 为阳。余径读 globs2，存模式、媒体类型、权重及 `cs` 之记。

源码以一「官方扩展数据」串存 TSV：模式、媒体类型、权重、大小写四栏，以实制表字节隔之，行以换行隔之。始时唯析一次，成内部「官方匹配规则」四元之列，次为字符串、字符串、整数、爻。诸规则存原序。

「官方扩展表」仍为扩展名与媒体类型之偶列，自全规则取简式 `*.扩展`，去名首之点，存复合扩展；首项为空名与默认媒体类型。含星号、问号、方括号之式，存于全规则。

官方 XML 循一行一宣、双引属性之发布式。XML 实体之还原及他排版之式，俟后版。全籍生成循 `node --max-old-space-size=16384 yy稳定节点宿主/宿主.cjs yy文件类型数据生成.wasm 输入 输出。豫`，使全 XML 切分之堆有余。
# IANA 登记数据

输入为 IANA 媒体之类 XML，则自同级 `IANA模板/` 取诸 `<file type="template">` 所指之模板，录 `File extension(s)` 字段及续文，成通配之规。任一模板有阙，即止生成。

官方登记 XML：`https://www.iana.org/assignments/media-types/media-types.xml`。模板径以 `https://www.iana.org/assignments/media-types/` 接 XML 所录媒体径。登记数据以 CC0 1.0 许可，条款见 `https://www.iana.org/help/licensing-terms`。

此轮已核 XML 及模板全籍之下录，实再生成 shared-mime-info 千二百二十五规。IANA 模板定向量，及裸末名列表、说明中点首之末名、同行他字段、括号说明、回车换行、空值及字段止处。自由文意之全析，俟后版；诸规存原序及重复项。

输入 shared-mime-info，则同级 `IANA媒体类型.xml` 及 `IANA模板/` 并入，以补所阙；IANA 末名赋权零，shared-mime-info 存其原权。输入 IANA XML，则唯治登记所自。

此轮定 IANA XML 更新之值 `2026-10-07`；模板引用二千三百六十四项，项皆异；官方 rsync 所下文件二千三百七十三项，引用无阙、下载无败，逐卷校验试行无异。仓外 `IANA模板引用清单.tsv` 存引用原值，`IANA模板文件校验.tsv` 存逐卷 SHA256，`IANA许可原页.html` 存官方许可之原页。

IANA XML SHA256：`dc2b988ac7e91eb719545c2c6391d42c8a7b813312d29031c9800d366ec07eab`；引用清单 SHA256：`806b48789c0722dadc80edea3b8f5dd40620045cca799a5b06d4b0dd295c389d`；文件校验清单 SHA256：`81ba6fa2bf097c92dc314dff68f528a371f12689c4ed33f6415903f5d6cff7b0`。shared-mime-info 2.4 XML SHA256：`d8deef937f79334f99e3131740105fca4bb99db9ffbb43ab5068ff862f9e5431`；原 GNU GPL 第二版或后版许可全文仍入籍。

核验先构数据生成器，再生官方扩展表，次验文件类型库，而后行独立向量。扩展查询之签名如故，内循全文件名规则而匹配。

IANA 模板独立向量，已于 Node 及同源硬浮点原生生成器、执行器运行皆过。向量取实 JPEG、SVG、JPX、Koan、Lotus、linkset、troff、veryant 模板之末名列表及说明止处；验成之文为“IANA注册模板独立向量通过”。

此轮正式合表实生成三千一百零三项，其中 shared-mime-info 全规则千二百二十五项，IANA 字段所取之规则千八百七十八项。IANA 诸规赋权零，重复项存原序。
