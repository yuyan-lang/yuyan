# 文件落盘与百万次性能验收

## 真实发布镜像

`镜像打包。脚本。豫` 载入系统 `newfs_msdos` 格式化的完整 1440 KiB FAT12 镜像，写入 `发布内容😀.txt`，载荷 631 字节跨两个簇，保存输出，再从文件重开目录和簇链、逐字节核对。Node 和 pit-mac 原生预编二均通过。独立系统 `fsck_msdos -n` 的三个检查阶段通过，记录为一个文件、2845 个空闲簇。

Node/native 被验客体 SHA256 同为 `fb4b489c9ab3a5eaea8a39e55f8e294449f26da261aaf94a1ee512cc98363e9b`；两端输出完整镜像 SHA256 同为 `e79c259c8283db1b2478068f16c6be1da3d42530ec3f694149d463105ec5e0c5`。Node 日志在 `/tmp/yy磁盘发布Node.log`；pit-mac 日志在 `/private/tmp/yy磁盘验证/yy磁盘发布Native.log` 和 `yy磁盘发布系统检查.log`。

## 百万次性能

同一客体在 pit-mac 上顺序运行一次，独立期望均通过。百万次分配位图查询应得 500000 已用位；一 MiB 零输入 CRC32 应为 2805525020，期望来自系统 gzip 尾部。

| 入口 | Node 秒数 | 原生预编二秒数 | 原生 / Node |
|---|---:|---:|---:|
| 位图百万次 | 0.012894 | 0.033696 | 2.61 |
| CRC32 一 MiB | 0.051071 | 0.044202 | 0.87 |

位图查询的原生耗时较 Node 高，作为原生热点记录；该结果来自单次同机运行。独立系统 C 实现的长期对照留待后续测量。两端日志在 pit-mac `/private/tmp/yy磁盘验证/yy磁盘Node性能.log` 与 `yy磁盘原生性能.log`。
