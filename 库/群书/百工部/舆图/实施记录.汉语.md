# 磁盘格式实施记录

本轮实现提案 00004 第十二组磁盘格式的可组合基础构件。甲级与乙级仍处于实施中。

## 已实现

- MBR 四个主分区字段读写与签名验证；GPT 头、分区表 CRC32 验证与更新、分区范围与属性读写。
- FAT12/16/32 启动布局、簇链、目录读取、表项写入、簇分配释放、短目录项更新、文件覆盖与新文件落盘、多副本同步；VFAT 长名校验、UTF16 代理对编解码与综合目录读取。
- exFAT 启动布局、目录组名称及流信息、连续与链式文件读取。
- ISO 9660 主卷、目录记录与文件片段读取；Joliet 名称解码与 Rock Ridge NM 名称。
- ext2/3/4 超级块、节点表、节点文件长度、目录记录与直接块；ext4 区段树索引和叶节点块映射。
- 偏移块回调、可修改内存镜像、整文件镜像载入保存与镜像检查首用者。

## 验证

包描述检查已通过。使用最新发布的配套 Wasm 工具链进行全包类型检查与四组测试。类型检查中定位并修复字节串操作与文件操作漏导入、长名目录模式名称冲突，总集已构建通过。CRC与偏移块测试、FAT表项与长名测试、新文件跨两簇及两副本同步测试均运行通过。

## 待完成

- FAT32 根目录后续簇扫描、目录扩展与活动表模式。
- exFAT 目录组校验和、有效长度以外补零及分配位图。
- Rock Ridge CE 续区与特殊名称。
- ext 间接块、哈希目录树、64 位组描述符与 meta_bg 特征。
- 系统工具生成真实镜像的对照验收、模糊测试、性能测量与裸机验证。

现文件适配以整镜像载入内存后整写方式运行，按偏移随机文件接口列为后续平台事项。

## 本轮结果

包检查通过，总集构建与镜像检查首用者类型检查通过。四组测试均完成构建并运行通过：CRC32 与块设备、FAT 表与长名、FAT 新文件跨两簇与两副本同步、ext 超级块与区段映射。新增源码均经 `yy格式化 120` 排版。系统生成真实镜像的对照、裸机与乙级全验仍待实施。
