# 终端参考向量

序列测试之期望值，据 [ECMA-48 第五版](https://ecma-international.org/publications-and-standards/standards/ecma-48/)及 [xterm 控制序列之说](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)手录。以定文及 ESC 字节书之，自立于库之颜色、式样及光标编码术。

ECMA-48 所对应者，CUU、CUD、CUF、CUB、CUP、EL、ED 与 SGR 也。xterm 所对应者，十六色亮色、索引色、真彩色、DECSC、DECRC 与 SGR 鼠标也。鼠标按下以 M，释放以 m，诸项次为原钮码、列与行。

TERM、COLORTERM、NO_COLOR 之向量，验本包色能之规；进度与旋标之向量，验本包显示之式。
