# 差异比较性能测试

此包为差异比较独立效测之程，直赖标准库、差异比较、基础库测试设施，隶系统工具基础库。

入口为 `测试/全量/性能。脚本。豫`，参先任务之名，后行数；无参行迈尔斯，取二百五十六行。可择迈尔斯、耐心、直方、按行、字素、统一输出、补丁应用、三方合并。先热二轮，再量九轮，书中位纳秒及核值。重建之验亦入计时；序列先分行，按行、字素兼切分，施补丁用预成者。造输入、初造参照属启程之备。

编号诸行各异，兼组合附标、ZWJ表情、区域旗帜、肤色。左右变三十一除余七、十九之行，供疏变、独行定锚及不交之合。重行、全易、密冲突俟后测之。

以 `导出 行数` 书载荷于今目录五个 `yy差异` 文件，供GNU diff、Git独立参照。实跑之况见性能测量方案。

`测试/全量/外部基准。脚本。豫` 收 GNU 与 Git 全出而逐字验之，具外部差异、版本迈尔斯、版本耐心、版本直方、外部合并五务。GNU diff3 明择同版 GNU diff。诸外器居今目录 `yy差异外参/`，供独立参照；包之实作所依为标准库与豫言诸库。

二百五十六行同载荷之八内务与五外务，于诺节及原生皆实测而通，先热二次，九量取中，时长与限界载差异比较《乙级实施记录.汉语.md》。内量兼重建之验，外量兼启子程、收出及全文之验，各循其口径记差。
