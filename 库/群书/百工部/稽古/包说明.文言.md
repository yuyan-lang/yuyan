# 版本库

版本库析 Git 对象、树、提交与标签，遍历提交之史，读引用、idx v2、普通包对象及二增量。SHA-1 用密码包，zlib 用压缩包。

`读版物` 访松散对象及包名列，据 idx 裁压缩流。存对象、提交须授建目录术。检出写普通文件与子树；树差异以差异比较生按行变化。

首消费者 `示例/历史合并。脚本。豫` 读系统 Git 之三版 blob 与二版树，行树差异，用 `校勘/合并` 之公共 `逐段三方并`。四独立更改之期望以系统 diff3 造；断言有失则抛异常，进程非零而出。

`接收包/展开接收包` 验 pack 尾之 SHA-1，据压缩流实耗之长，逐轮还原普通对象、OFS 增量与 REF 增量。REF 之基居增量之后，则以候解之轮恢复。目录由调用者之术建之。`示例/前向核验。脚本。豫` 用系统 Git 所受之独立前向包，验所复之对象。

`克隆` 行协议 v2 之访引用、还原包物、更新引用；`联网接线` 以既有 HTTP 客户承明文之传。`示例/联网克隆。脚本。豫` 实行 HTTP 克隆拉取，以系统 Git 核所复之对象与史。建目录由调用者之术司之。

## 工作树文件之枚举

`枚举工作树卷` 受工作树或子目录，还相对此目录已录与未受忽略之新文件。径读二版、三版 Git 索引，识 `.git` 目录与 `gitdir` 指针，循 `commondir` 读共用配置、排除之文。忽略先取全局 `core.excludesFile` 或 XDG 默认文，次取 `info/exclude`，次循各级 `.gitignore`；后条覆前条。受否定、根锚、目录、星、双星、问号、字符组及范围。已录之文虽于盘删除，仍列其名，受者循所用验其存。

批量发布以此收源码。径存原文，汉字、引号、换行之名径以串传。后版之事：四版索引、拆分索引、稀疏索引、配置 include/includeIf 与繁 POSIX 字符类。

`安全联网接线/安全版本传输` 受实今 Unix 秒，用安全传输之默认客户配置、仓中信任根及超文本传输之公共安全请求。`授权目录接线/授权建目录` 以公共文件目录权，逐层造克隆、对象、引用之目录。`示例/安全克隆。脚本。豫` 自公共时间接口取时，于已授“版本库”目录行 HTTPS 连接、克隆、验对象而拉取。持续集成之二接线入口验正式依赖与接口之类。

## 吉特之命

命令行之程「吉特」（`应用/百工坊/吉特`）与系统之壳召同一组带标签之命函。每函所印之文人与代理皆可读，返退出之码（零为成）；有误则抛事故而明其故。仓之式与 git 同，一仓可迭用 git 与此诸函。

- `命令`：`稽态`、`稽校勘`、`稽暂存`、`稽撤销暂存`、`稽提交`、`稽史`、`稽观`、`并基令`、`稽列分支`、`稽置分支`、`稽删分支`。
- `切换并令`：`稽切换`、`稽并`（快进、三方之合、冲突后提交或弃之）、`稽变基`（始、继、跳、弃）、`工作树新增`、`工作树删`、`工作树列出`。
- `远端令`：`稽摹`、`稽拉取`、`稽推送`。令牌取环境变量 `吉特令牌`，次取凭据之文（缺则 `/系统/吉特/凭据`，每行“令牌”或“主机 令牌”），以 HTTP 基本认证发之，诸出皆不含令牌。核心之函 `摹于`、`拉取于`、`推送于` 受一远端之调，试时可易为本机之进程。

诸命立于下列模块：

- `沙一`：可分段续入之沙一摘要，对象标识与包尾之校共用之。
- `物库`：读散对象与包中之物（含偏移增量与引用增量），二版包索引依扇出表二分而查；书散对象。
- `目卷`：二、三版索引之读书，每项记其改时与大小。
- `工作区`：HEAD、暂存区、工作区三方之态，扫未跟踪之文循 `.gitignore`、`info/exclude` 与全局排除之文；改时同且先于索引书时者，径用索引所记之散列，余则重算而更索引。
- `树表`、`提交录`、`引库`、`章程`：树与提交之编解、作者之签与时区，散引用、打包引用与符号引用，链接工作树之元目录与公共目录，INI 之书之配置。
- `历史`：解修订之名（分支、远端分支、标签、全或缩之标识、`~n` 与 `^n`）、依提交之时行史、合并之基与祖先之判。
- `校勘出`：统一式之差，带三行上下文。
- `合并`：两树之换与三方之合，将覆本地之改则拒之；冲突则书第一至三阶与冲突之记。
- `收包`：所收之包逐一解物、展增量、算标识，生二版包索引，与 `git index-pack` 所生者同。
- `远端协议`、`联网`：智能 HTTP 第二版之 upload-pack（ls-refs、fetch、边带）与 receive-pack（引用更新之令、非增量之包、report-status），HTTPS 以仓中信任根验证书。
- `杂凑表`、`文字具`：整数键与字符串键之开址散列表，依字节之文字之术。

`测试/吉特核心。测试。豫` 核沙一之向量、对象标识、索引往返、树往返与统一差块。`示例/本地协议核验。脚本。豫` 付克隆、拉取、推送之请体于本机之 `git upload-pack`、`git receive-pack --stateless-rpc`，于本机核远端之约。

## 后续事项
