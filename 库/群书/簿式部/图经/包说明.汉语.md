# 开放街图读取

图经（开放街图读取库，OpenStreetMap reader）把开放街图 0.6 版文件（可扩展标记文本）读成「图经卷」：外框、全部节点的位置、带标签的节点、路径与关系。经纬度按字面数字逐位读成千万分之一度的整数，不经小数解析；元数据（版本、时间、用户）略去；键值里的实体引用（五个预定义实体与十进、十六进字符引用）还原成字符。读取按字节逐元素前进，不建文档树。

`图经` 取自古时州郡编绘本地图经、汇于朝廷的旧制（译名由来见《翻译列表》）；使用开放街图数据须署名“© OpenStreetMap 贡献者”，数据以开放数据库许可（ODbL）发布。

## 读取

- `读图经文`：开放街图文本（字符串）到「图经卷」。
- `读图经文件`：文件路径到「图经卷」，等于先读文件为字符串再读取。

文件里的 `bounds` 作外框；没有 `bounds` 时按全部节点的位置算外框。缺 `id`、`lat`、`lon` 的节点与缺 `id` 的路径、关系跳过（如历史文件里已删除的节点）；`osm` 根元素之外的未知元素只越过元素头。文件在元素中途截断时告祸。

## 数据结构

| 名字 | 内容 |
| --- | --- |
| 「经纬点」 | 纬、经（千万分之一度，北纬东经为正） |
| 「图界」 | 南、西、北、东四界（千万分之一度） |
| 「图点」 | 带标签的节点：号、纬、经、标签们 |
| 「图径」 | 路径：号、点号们（节点号序列，首尾同号即闭合）、标签们 |
| 「图员」 | 关系成员：种（点员、径员、系员）、号、角色 |
| 「图系」 | 关系：号、成员们、标签们 |
| 「图经卷」 | 读取结果：界、点表（全部节点的位置）、带标点们、径们、系们（文件次序）、径序与径组（路径索引） |
| 「标签列」 | 键值对列表，按文件里的次序 |

没有标签的节点只存在点表里（路径靠节点号引用它们）。

## 号表

「号表」是整数散列表：键是元素号（百亿以上也可，负号也可），每键存两个整数值；开放寻址、线性探测，装载过半倍增。点表用它存纬与经，径序用它存路径在径组里的下标。函数：`造号表`、`入号表`（返回新表，旧表不再使用）、`寻号表`、`号表槽位`与`号表甲值`、`号表乙值`（读值不分配对象）、`号表个数`、`号表号们`。

## 查卷

- `寻图点`：按节点号取经纬点；`寻图径`：按路径号取图径。
- `号们点们`、`图径点们`：节点号列、路径的节点列换成经纬点列（不在文件里的节点跳过）。
- `径闭合`：路径是否闭合（至少四个号且首尾同号）。
- `寻标签`：在标签列里按键取值；`造经纬点`造经纬点。

## 投影

局部等距投影把经纬度换成以厘米计的平面坐标：东 = Δ经 × 每度经长，北 = Δ纬 × 每度纬长。`造投影法` 按 WGS84 椭球在原点纬度算出子午圈与卯酉圈曲率半径（小数运算只做一次，正弦、余弦用泰勒级数），换成每单位（千万分之一度）的厘米数乘二的二十八次方的定点系数；`投影东`、`投影北` 逐点只做整数乘法与移位，四舍五入。城市尺度（几十公里）的误差在厘米级。

## 多边形

- `装环`：把一组节点号序列（路径）拼成闭合环。端点相同的路径接在一起，方向不一致就反转；本身闭合的路径直接成环；拼不成闭环的列为余段；节点不足两个的路径丢弃。返回「装环果」（环们、余段们）。
- `关系环们`：取多边形关系的外环（角色 outer 或空）与内环（角色 inner）成员，分别装环，换成经纬点环，返回「关系环」（外环们、内环们）。不在文件里的成员路径与点、关系成员跳过；不足四点的环丢弃。
- `系为多边形`：关系的 type 标签是否为 multipolygon。

## 性能

扬州古城（6.9 兆字节，27878 个节点、4603 条路径、130 个关系）在 pit-pc-ubuntu-wired 的原生后端上，读文件约 0.01 秒，解析约 0.13 秒（负载较高时约 0.16 秒），峰值内存约 64 兆字节。
