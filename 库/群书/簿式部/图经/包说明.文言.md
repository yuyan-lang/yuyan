# 开放街图读取

图经者，开放街图之读器也。取开放街图零点六版之文（可扩展标记之文），读而成「图经卷」：外框、诸点之位、有标之点、径与系。经纬度依字面之数逐位而读，成千万分之一度之整数，不假小数；版本、时日、编者之名略而不取；键值中之实体引用，还其本字。按格逐物而前，不立文档之树。

「图经」之名，取古者州郡各编本地图经、汇于朝廷之制（由来见《翻译列表》）。用开放街图之数据者，须署“© OpenStreetMap 贡献者”；数据以开放数据库许可（ODbL）颁行。

## 读取

- `读图经文`：以开放街图之文（字符串）成「图经卷」。
- `读图经文件`：以文件之径成「图经卷」，犹先阅其文而后读之。

文中有 `bounds` 则以为外框，无则依诸点之位而算。缺 `id`、`lat`、`lon` 之点与缺 `id` 之径、系越之（如旧史之文中已删之点）；`osm` 根之外不识之物，惟越其头。文断于物中则告祸。

## 数据结构

| 名 | 义 |
| --- | --- |
| 「经纬点」 | 纬、经（千万分之一度，北纬东经为正） |
| 「图界」 | 南、西、北、东四界 |
| 「图点」 | 有标之点：号、纬、经、标签们 |
| 「图径」 | 径：号、点号们（点号之序，首尾同号则合）、标签们 |
| 「图员」 | 系之员：种（点员、径员、系员）、号、角色 |
| 「图系」 | 系：号、成员们、标签们 |
| 「图经卷」 | 读之所得：界、点表（诸点之位）、带标点们、径们、系们（依文之次）、径序与径组（径之索） |
| 「标签列」 | 键值之对，依文之次 |

无标之点，惟存于点表（径以点号引之）。

## 号表

「号表」者，整数散列之表也：以元素号为键（百亿以上可，负号亦可），一键存二整数；开址线探，满半则倍。点表以存纬经，径序以存径在径组中之下标。其术：`造号表`、`入号表`（还新表，旧表勿复用）、`寻号表`、`号表槽位`与`号表甲值`、`号表乙值`（读值不造新物）、`号表个数`、`号表号们`。

## 查卷

- `寻图点`：依点号取经纬点；`寻图径`：依径号取图径。
- `号们点们`、`图径点们`：点号之列、径之点列，换为经纬点之列（不在文者越之）。
- `径闭合`：径合否（至少四号而首尾同号）。
- `寻标签`：于标签列依键取值；`造经纬点`造经纬点。

## 投影

局部等距投影者，换经纬为厘米之平面坐标：东 = Δ经 × 每度经长，北 = Δ纬 × 每度纬长。`造投影法` 依 WGS84 椭球，于原点之纬算子午、卯酉二曲率半径（小数之算止于一次，正弦余弦用泰勒级数），换为每单位（千万分之一度）之厘数乘二之二十八次方之定点系数；`投影东`、`投影北` 逐点惟用整数之乘与移位，四舍五入。城邑之域（数十里之内），所差在厘米。

## 多边形

- `装环`：合一组点号之序（径）为闭环。端点相同者连之，方向不一则倒之；本合者径成环；不成闭环者列为余段；不足二点之径弃之。还「装环果」（环们、余段们）。
- `关系环们`：取多边形系之外环（职曰 outer 或空）与内环（职曰 inner）之员，各装其环，换为经纬点之环，还「关系环」（外环们、内环们）。不在文之员径与点、系之员越之；不足四点之环弃之。
- `系为多边形`：系之 type 标是否为 multipolygon。

## 性能

扬州古城（六点九兆字节，二万七千八百七十八点、四千六百零三径、一百三十系）于 pit-pc-ubuntu-wired 原生之后端，读文件约百分之一秒，解析约十分之一秒余（负载高时约十分之一点六秒），峰值内存约六十四兆字节。
