# DTD 内容之模型

`内容模型解析` 受 XML 1.0 元素内容声明之正文，还模型树。受 `EMPTY`、`ANY`、`(#PCDATA)`、`(#PCDATA|名称…)*`，及元素名、顺序、选择、层叠分组、`?`、`*`、`+`。同组之逗号、竖线毋杂，混合内容之元素名各唯一。

`内容匹配` 受模型与尽子元素名之列，还匹配之果。以正则导数逐项消之，列尽则验余模可空。重复之模虽含可空项，亦唯随输入元素进。造导数时简失败、空串与复选择项。`模型许文字` 于 `ANY` 与混合内容还阳，`模型为空` 于 `EMPTY` 还阳。文本、空白文本、注释、处理指令由树之校验层各治之。

正文与层数至多百万，展开模型树至多百万节，匹配访问之积至多亿次。元素之名循声明限定名逐字比之。DTD 声明之集、属性类型、ID 与引用、确定性之约束，由全体校验层治之。

所据：[XML 1.0 第五版](https://www.w3.org/TR/2008/REC-xml-20081126/)，3.2.1、3.2.2 章。今唯编辑、轻排版已竟，类型与运行之验待统一调度。
