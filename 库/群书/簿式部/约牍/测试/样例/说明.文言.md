# 协议缓冲对照样例

三篇 `官方…tfevents` 复用训练记录包所存 TensorFlow 官方教程之 [HParams 预生成日志](https://storage.googleapis.com/download.tensorflow.org/tensorboard/hparams_demo_logs.zip)，[教程出处](https://www.tensorflow.org/tensorboard/hyperparameter_tuning_with_hparams)。实验三百零四字节（SHA-256 `488f783b32b89983adb3071e00428e240ef4c45a2ddd49151598a923fe73b109`）、会话三百八十七字节（`7ab0c2c6e32ed056514ee0ad90f60e869087d3c139900a078c28faec105a9e30`）、指标二十一万七千四百五十三字节（`df4f63ab39fec43681d7edaf9b28653fc19f642501b6646cf17c40939cdd5195`），皆存下载原字节。包内试按 TFRecord 长度分帧，解诸 Event、Summary.Value 及其 TensorProto 载，验帧数二、四、十三；二〇二六年十月八日于 pit-mac 用成套 25a 诸器行之，成而退。TFRecord CRC 之验由训练记录包之官方样本试毕。样例出于二〇一九年二月，原包未记造器精确之版；教程文字从 CC BY 4.0，示例之源从 Apache-2.0。

六篇 `特殊…模式.proto` 存官方 protoc 36.2 发布包 `include/google/protobuf/` 中 wrappers、struct、any、timestamp、duration、field_mask 之原文与许可，以验九包装型、Struct/Value/ListValue、Any、Timestamp、Duration、FieldMask 及嵌套映射。特殊时间编码由官方 protoc 36.2 编 `seconds: 0 nanos: 123456789`，SHA-256 为 `6e9df4755cdcaef9184e465f394002ed839fd4386efa61888a279635c3d1ddf0`；特殊时长编码由同器编 `seconds: -1 nanos: -1000`，SHA-256 为 `19d4c53c909a20463dac1b29319f9f406a8e7fe4aa12a166850cb10e9bd75bbf`。二〇二六年十月八日，于 pit-mac 以成套 25a 诸器导六模式，验十七项 JSON 往返及二官方原编码，皆成而退。

样例由官方协议编译器 36.2 所造，以验模式解析、线格式、文本与结森映射。器出于[协议缓冲 36.2 发布](https://github.com/protocolbuffers/protobuf/releases/tag/v36.2)。模式存上游之原文及许可。

`算图模式.proto` 取二〇二六年十月七日之 [ONNX 模式](https://github.com/onnx/onnx/blob/main/onnx/onnx.proto)，从 Apache-2.0 许可，SHA-256 为 `795fcd38a3267a6c085190e90bd71c799a98bbba35c6a23f19c8bc672b62ed92`。`算图文本.txt` 载一 Relu 节点与一浮点初始化器；`算图模型.onnx` 为其编码，SHA-256 为 `614d3fc5d82b84edb5c768414dedd47252439a4693d2ad8f42304cf828d777cc`。

`句片模式.proto` 取同日之 [SentencePiece 模式](https://github.com/google/sentencepiece/blob/master/src/sentencepiece_model.proto)，从 Apache-2.0 许可，SHA-256 为 `ac92a7ba0b743e76fe6fb4caadafef4f7f69aa8d4074f8b1ef48cf6d1c5be8c9`。`句片文本.txt` 载六词片及训练、规范化之基本选项；`句片模型.model` 为其编码，SHA-256 为 `ac2ad08af56501deba417724b0b095f52dbf47a68271480d90407becece6e7b6`。

对照模式、文本皆本仓所作，涵变长整数、之字形、定长整数、小数、文字、字节、紧凑重复字段、枚举、嵌套、单选、旧组及映射。`对照编码.bin` 之 SHA-256 为 `dc6721fb96cf328fbc1703733dc242ed51bba3f5fec94a4e11b281d8181acafd`；`对照结森.json` 存所期之结森树。

二模型皆据官方模式所造之微型序列化样例。外器运行、训练模型对照及百万输入之验，列为后续之事。

`真实算图模型.onnx` 取 [ONNX 官方 PyTorch 导出 Linear 测试](https://github.com/onnx/onnx/blob/main/onnx/backend/test/data/pytorch-converted/test_Linear/model.onnx)，凡 585 字节，官方 git blob 为 `cb2d07eb66559c9bb450903b19ef5190f43f419f`，SHA-256 为 `60a3546925d832686c788d3ea22732feaef5bc527e04691c32ec9f677c81f612`。文件载 PyTorch 0.3 导出、IR 3、Gemm 节点及形为 8×10、8 之二浮点初始化器。`真实算图文本.txt` 由官方 protoc 36.2 解之。样例随 ONNX 仓从 Apache-2.0 许可。

`真实句片模型.model` 取 [SentencePiece 官方英文 Unigram 千词片模型](https://github.com/google/sentencepiece/blob/master/data/botchan_en_unigram_1000.model)，凡 253152 字节，官方 git blob 为 `8286458480b8cdb12681ce63769d48a477778347`，SHA-256 为 `f8c7e5e0fa9e948783d20ea9dccf0e2611f567bc1a4e468a658becd5015f458e`，从上游 Apache-2.0 许可。二真实文件既取，皆以 `git hash-object` 核官方文件树之 blob；protoc 已解之，豫言解码之验待资源之时。
