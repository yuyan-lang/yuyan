# 安全外壳密码

「求已知主机HMACSHA1」以二十字盐算主机名 HMAC-SHA1，惟供 OpenSSH `known_hosts` 隐名核对；不施于 SSH 会话密报或报文验真。

包名「豫言/安全外壳密码」，版「0.1.0」。为安全外壳协议备 SHA-256、X25519、Ed25519 原生密码术。赖系统 OpenSSL `libcrypto`；于 macOS、Linux 编之，须得其头与库。豫构今未能声明系统头路；若头不在编译器常路，须于构建环境设 `CPATH`。本机 Homebrew 可用 `CPATH=/opt/homebrew/opt/openssl@3/include`。

「原语。豫」皆受还原字节串。X25519、Ed25519 私钥以三十二字节种子为参；新种子当取标准库之安全随机。X25519 共密三十二字节，全零则拒。Ed25519 验伪签返阴，参长不合则报事故。AES-256-GCM 用三十二字节钥、十二字节 IV，密文后缀十六字节签；验成乃还明文。一请正文与附加文各不得逾一兆字节。同钥之 IV 绝不可复用。

今私钥及共密寄普通豫言字节串。欲设服务于公网，尚须密钥护藏与清除之法，亦须验协议互通。
