# 图标

界面之图库。图书为设计之文 `图形。设计。豫`（[提案〇〇〇一八](../../提案/00018-设计语言与引擎.汉语.md)第十六节）：每图为能为“图标”之设计作品，二十四格视框中之 SVG 之径，墨朱描线，纸色填底。画时由设计之引擎求值，以整数扫描线栅之（去锯齿、圆头圆角），易墨、朱、纸为画法之墨、朱、底，线宽亦取画法。

## 模块

| 模块 | 内容 |
| --- | --- |
| `图形`（`图形。设计。豫`） | 诸图（值为名与设计作品）：夹、终端、任务、设备（芯片）、设置、搜索、刷新、返回、右移、左右拆、上下拆、全屏、还原、闭、收展之箭、合开之夹、豫言之源、文档、图、配置、可执行、会话与他文之页 |
| `画图标` | 「徽识」之类（名与设计作品）、「图标画法」（墨、朱、底色与线宽）、「常图标画法」、「画图标到缓冲」、「渲染图标」（依名、物理边长与画法存之，还 RGBA8 之字与版号） |
| `图标件` | 「设图标像素比」、「图标件」与「定位图标」：依今之像素比而渲，交界面之「混合像素图」示之，透处露底 |

平铺桌面之外壳之视每帧依所受之像素比调「设图标像素比」；活动栏、签栏与工作台资源树皆用此图。

## 预览

`豫构 构建 图标 预览。脚本 --输出 图标预览。林檎。豫行` 后行 `./图标预览。林檎。豫行 图标预览.png`，依一倍、二倍与放大之尺画诸图于纸色之底，书为 PNG，并印独渲之时。

## 后续版本事项

- 像素比今为全局之态；当易为显示树之矢量图之节，由自绘后端依像素比栅之。
- 矢量图库之通渲于曲与描加速之后，图可径交之渲。
