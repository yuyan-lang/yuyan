# 图标

界面图标库。图标写成设计文件 `图形。设计。豫`（[提案 00018](../../提案/00018-设计语言与引擎.汉语.md) 第十六节）：每个图标是能力为“图标”的设计作品，二十四格视框里的 SVG 路径，墨色、朱色描线，纸色填底。画图标时由设计引擎求值、用整数扫描线栅格化（抗锯齿、圆头圆角），把墨色、朱色、纸色换成画法的墨色、朱色、底色，线宽也取画法的。

## 模块

| 模块 | 内容 |
| --- | --- |
| `图形`（`图形。设计。豫`） | 全部图标（值是名与设计作品）：文件夹、终端、任务、设备（芯片）、设置、搜索、刷新、返回、右移、左右拆分、上下拆分、全屏、还原、关闭、收起与展开箭头、合上与打开的文件夹、豫言源码、文档、图片、配置、可执行、会话与其他文件页 |
| `画图标` | 「图标」类型（名与设计作品）、「图标画法」（墨色、朱色、底色、线宽）、「常图标画法」、「画图标到缓冲」、「渲染图标」（按名、物理边长与画法缓存，返回 RGBA8 字节与版本号） |
| `图标件` | 「设图标像素比」、「图标件」与「定位图标」：按当前像素比渲染，交界面的「混合像素图」显示，透明处露出背景 |

平铺桌面的外壳视图每帧按收到的像素比调「设图标像素比」；活动栏、标签栏与工作台资源树都用这里的图标。

## 预览

`豫构 构建 图标 预览。脚本 --输出 yy图标预览.exe` 后运行 `./yy图标预览.exe yy图标预览.png` 把全部图标按一倍、两倍与放大尺寸画在纸色底上，写成 PNG，并打印单独渲染的耗时。

## 后续版本事项

- 像素比现在是全局状态；改成显示树里的矢量图标节点，由自绘后端按像素比栅格化。
- 矢量图库的通用渲染在曲线与描边上加速以后，图标可以直接交它渲染。
