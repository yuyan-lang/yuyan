# 源码排版规则

独立工具包 `源码格式化` 使用本库。修改排版算法时，应同步更新规则和测试。

参数标签写作 `「标签」为 …`。排版保留括号与参数位置；标签名及紧随的“为”保持同一行，右侧复杂表达式沿用普通表达式排版。带标签的 `会`、`遇`、`化`、调用和构造器模式均须通过带注释的语法解析后写回。

## 行宽与缩进

- 每层缩进一个全角空格（U+3000），占两列，默认行宽为 160 列，即八十个汉字。
- ASCII 字符计一列，其他字符保守计两列。
- 排版只取决于词法和注释的位置：源码原有的空格、换行、空行和缩进都不影响结果。只有紧挨注释的换行保留，它决定注释附在前面还是后面。
- 能放在一行的就放在一行。所有断行判断都按整行宽，没有更早断行的阈值。
- 不拆开标识符、字符串和注释；必要时允许这些单元超过行宽。
- 限制深层表达式的缩进，避免正文不断右移。

## 括号与调用

- 左括号与首项放在同一行；独立注释除外。
- `于（` 可以同行。需要拆分时，在 `于` 前换行，不拆开它与左括号。
- 调用放不下一行时，每个 `于` 参数各占一行，比调用头所在的行深一层；一次调用的参数一旦分行，其余参数也各占一行。缩进按括号层次定：括号里的调用比左括号所在的行深一层，括号收尾后，外层调用的参数回到外层。
- 分行的括号，内容比左括号所在的行深一层。以名称开头的调用括号，右括号紧跟最后一行；其余右括号单独一行，与左括号所在的行对齐。括号内容按行宽减去紧跟其后的右括号、句号、分号排，收尾的括号不会超宽。
- 括号里的匿名函数，正文在当前行放不下时，在 `会…而` 之后换行，正文比这一行深一层。
- `附` 连成的长串放不下时在 `附` 前换行，续行以 `附` 开头，彼此对齐。

## 方括号列表

- 列表末尾的逗号一律删去；排版前后比较词法时，紧挨右方括号的逗号不计。
- 放得下的列表排在一行。
- 放不下的列表在左方括号前换行：序列头独占行首时，左方括号与序列头同列；其余情形，左方括号比所在行的内容起点多缩进一层。所在行以外层列表的左方括号或逗号开头时，内容起点在它之后，所以紧跟其后的序列头（嵌在外层列表里），左方括号比序列头多缩进一层；序列头前面另有内容（如作调用参数）时，左方括号比所在行多缩进一层。第一项紧跟左方括号，其余各项另起一行，行首是逗号；右方括号单独一行。左方括号、各项前的逗号与右方括号在同一列：

```yuyan
「长列」者
　「列」
　【『第一个比较长的元素』
　，『第二个比较长的元素』
　，『第三个元素』
　】
也。

「长列长度」者
　「长度」授以「字符串」于（「列」
　　【『第一个比较长的元素』
　　，『第二个比较长的元素』
　　】）
也。
```

- 列表顶层有注释时沿用逗号在行末的旧排法。

## 分支、条件和绑定

- 同一 `鉴` 的 `有`、`或有` 对齐，分支体缩进一层；短分支可以同行。
- 括号分支体若放不下，但下一行能完整放下，就整体移到下一层；仍放不下时，按内部结构换行，不额外增加无用缩进。
- 条件链（`若…则…否则若…则…否则…`）整条放得下就排在一行。放不下时每支各占一行：`则` 留在条件行尾，正文另起一行缩进一层；`否则`、`否则若` 另起一行，与 `若` 对齐。条件本身跨行时，`则` 后的正文比条件的续行再深一层。`否则` 后紧跟的 `若` 与 `否则` 合成 `否则若`，按同一条链排。
- 局部绑定整条连同 `而` 放得下一行时排成一行：值紧接 `者` 平铺，`而` 接在行尾。能这样平铺的值由原子、括号、方括号、`于`、`授以`、`中`、`附`、`与`、`合`、`之`、`为` 与各层至多一个条件组成；含注释、跨行字符串、匿名函数、`鉴` 或嵌套绑定的值按多行绑定排。
- 值移到下一行且只占一行时，`而` 接在值的行尾；值占多行时，`而` 单独一行，与 `虑` 对齐。
- `而` 之后总换行，下一条绑定或正文与 `虑` 对齐；含 `虑` 或 `鉴` 的式子不会压成一行。`递归虑` 不拆开，必要时在整个关键字之前换行。
- 顶层函数定义的正文总在 `会…而` 之后另起一行，`也。` 独占一行。

## 类型、注释和稳定性

- 类型链尽量在同列延续，换行的 `化` 缩进一层。连续构造器保持一致缩进。
- 可省参数的 `可化` 与 `化` 同样排；签名里有 `可化` 时，`乃` 之后换行，每个参数单独一行。定义里的 `会「标签」为「局部名」默认 值 而` 与 `会` 同排。
- 分号连接的同级表达式对齐。
- 前置注释跟随后面的表达式或声明，后置注释跟随前面的表达式。
- 空行由排版器决定：`者…也。` 定义之后、导入之后、新数据类型（`立「元类型」`）之前各空一行；下一条声明带前置注释时，空行放在注释之前。其余空行（包括函数体里的空行）都去掉，紧挨注释的除外。
- 先完成全部文件的带注释语法解析；任一文件有误，就不写回任何文件。
- 排版必须幂等：再次排版不会改变文件字节。

## 双语注释

- 注释去掉开头空白后以语种标记（`汉语：`、`文言：`、`赋曰：`）开头，并且至少含两个标记时，按双语注释排版；其余注释原样保留。
- 标记只在注释开头、换行之后或句末标点（`。`、`！`、`？`、`；`）之后生效，中间可以隔着空白；内层注释里的标记按正文处理。
- 先去掉原有版式：每段去掉首尾空白，段内换行连同前后空白删去，断行两侧都是 ASCII 可见字符时补一个空格；行内空白原样保留。
- 各段按汉语、文言、赋曰排序，同一种标记出现多次时保持原来的相对次序。第一段紧跟注释开头，其余各段另起一行，注释结尾紧贴最后一段：

```yuyan
「：汉语：返回一。
　　文言：返一。：」
「一值」者「一」也。
```

- 续行先用注释开头的缩进，再加两个全角空格（U+3000），与注释开头的两个全角字同宽，使文言、赋曰与汉语对齐；代码行尾的注释，开头与第一段留在代码之后，续行用该代码行的缩进再加两个全角空格。再排时，标记前的全角空格与普通空白一样去掉。
- 一段即使超出行宽也保持一行。
- 排版前后比较词法时，双语注释按上述规范形式比较，其余注释比较原文。
