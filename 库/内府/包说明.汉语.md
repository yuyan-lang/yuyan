# 内府（自己的对象存储）

通称内府（own object storage）。这是提案 00064《内府》第一步的库：跑在自己机器上的对象存储的协议、服务核心与客户端。

## 范围

- 协议（券）：请求是一个籍册记录，栏为号、术、桶、键、键们、约束、读限、正文；术有六：元（取元数据）、读（读正文）、写、列（按前缀列举）、删、息（停服务）。应答是号与果；果有四变：成（元数据、正文、有无正文）、无物、条件不合、器误。编号由客户端给，服务端原样带回。
- 服务核心（受藏）：收请求、交给本机落盘的库「金匮」办、回话。读在收到时即办；写与删排成一列依次办，每批写办完先把这些写碰过的卷册同步到盘，才回应答。一条连接上一建立就先合符（虎符凭证）：服务端先送一个随机数，客户端用虎符对它算沙二五六作证，服务端拿文件里的虎符重算核对。
- 客户端（客）：一条连接复用，断了重连一次；一条连接上一次等一个答复，按请求号核对；超时可设。
- 落盘（落盘）：按宿主授予的目录权，用豫寓榫卯「文件」的「同步卷」把刚写过的卷册刷到盘上。没有授目录时起不了内府台（写入要落盘才回话），错误消息里写明授权办法。
- 台署（台署）：读内府台的配置 `内府台。数据。豫`（数据目录、地址、端口、虎符、桶名单、授权目录名、可选的盟署），缺项取缺省。
- 台行（台行）：按配置起一台并走主循环：没有「盟」一节时起单机内府台（受藏、落盘），有「盟」一节时起三副本的盟台。
- 盟署（盟署）：三副本的配置——本员号与全部员的员号、地址、端口。
- 盟文（盟文）：三副本的编码与落盘格式——信编成籍帛过网，命令（写或删的请加盟主定下的上传时刻）编成籍帛入载书；盘上分盟态（任期、所投、已执行到的序号）与载书两卷，都用籍帛写、原子换名、写完同步。
- 盟台（盟台）：三副本的驱动。持着盟府的一员，把收到的信、钟的滴答、客户端的献令与请读交给「步」；每一步先落盘后发信（存单写进盟态与载书两卷并同步，凭持证启封才发信、才交付）；交付的条按序号执行，空令跳过、实令交本机金匮办，已执行到的序号写回盟态；员间用合符认人、用封与籍帛收发，连接复用、断了重连；开连只投刺、不在原地等回答，合符由每一拍的「理出一」推进，认成之前的信先记在去连接的待发列里，认成后一齐冲出；客户端与盟员共用一个端口，认后按第一封的顶层名分辨；不是盟主时答非主并附所知盟主的地址。
- 随主（随主）：客户端侧的多台选址——按地址列逐台试，得到非主就改连所附盟主，连不上就轮下一个，退避重试有上限；随主只择地址与重试，请求仍由客发。

## 三副本

配置里加一节「盟」就是三副本，不写这一节照旧是单机模式：

```yuyan
「盟」者 「典」
　【「本员号」者『甲』也
　，「员们」者「列」【
　　　「典」【「员号」者『甲』也，「地址」者『127.0.0.1』也，「端口」者「二一零零一」也】，
　　　「典」【「员号」者『乙』也，「地址」者『127.0.0.1』也，「端口」者「二一零零二」也】，
　　　「典」【「员号」者『丙』也，「地址」者『127.0.0.1』也，「端口」者「二一零零三」也】
　　】
　】
也。
```

- 本员按本员址的地址与端口听客与盟员；别的员按名单里的地址与端口连过去。
- 客户端与盟员共用一个端口：认过之后按第一封的顶层名分辨（「请」是客户端，「信」是盟员）。这样配置里每员只写一个端口，一台上只有一门。
- 写的次序：盟主把客户端的写或删编成一条实令、带上盟主定下的上传时刻（元数据里的 `uploaded` 取它，各员执行时不再各取各的钟），献进盟书；等这条交付、在本机执行完，才按执行结果回客户端。
- 条件在交付执行时按本机状态判：各员按同一序号执行，结论一致。执行幂等靠两件事：盟态里记已执行到的序号，重起只执行其后的条；条件写重放时条件已不成立、无条件的写重写同一份正文，效果相同。
- 读与列举先向盟府要读确认，得到许读的序号后等本机执行到那里再从金匮读。不是盟主答「非主」并附所知盟主的地址。
- 重起时从数据目录下的 `盟态` 与 `载书` 两卷恢复：先读载书，再按盟态里的任期、所投与已行开府；起台前先核已行不超过载书条数。
- 发不出的信丢掉（盟府容丢、容重、容乱序）；连接断了下次发信再连。

## 与别处的关系

内府台的存储直接用接口适配「豫寓府库金匮榫」的五术：根设在内府台的数据目录下。三副本的共识用库「盟府」（纯状态机，不碰网、盘、钟，网、盘、钟由盟台接）。服务程序「内府台」在 `应用/百工坊/内府台`；客户端适配「豫寓府库内府榫」在 `豫言操作系统/适配/对象存储内府`。

## 限额

- 单次读写正文至多 16 MiB（与对象存储接口的写入上限相同）。
- 列举一页至多 1000 项。
- 删物一批至多 1000 个键。
- 读请求的字节上限须在 1 至 16777216 之间。

## 待办事项

- 快照与截断还没做：载书一卷整份重写，条数多了写一步就贵；载书一直长。
- 成员增减还没做（三副本的成员写死在配置里）。
- 三副本连互联网时由封缄（TLS）加密，留待第三步。
- 落盘同步要宿主按名授予数据目录：宿主上以 `--授权目录写 内府=<数据目录>` 启动内府台，豫言操作系统上在常役的参数里写同一对选项；未授目录时内府台起不来并报中文错误。浏览器之类的宿主没有同步能力。
- 直通出站响应、入站正文写入、分段写物在客户端适配里答「暂不支持」，第三步补上。
