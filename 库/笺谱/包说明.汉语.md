# 笺谱

便笺的存储与壳命令做法库，供图形程序「便笺」（包名「花笺」）与壳命令共用。

## 存放

- 每条便笺的正文存成 `/数据/花笺/<编号>。文本`，编号逐位写成汉字数字（如一、一二、一零三）；正文是普通文本，标题取首行。
- 元数据存 `/数据/花笺/目录。数据。豫`，按数据子语言写：

```yuyan
「笺目」者
　「列」
　【「笺」【「号」者「一」也，「置顶」者「阴」也，「色」者「零」也】
　，「笺」【「号」者「二」也，「置顶」者「阳」也，「色」者「三」也】
　】
也。
```

- 号：正整数，新建时取现有最大号加一。
- 置顶：阳为置顶。置顶的排在列表前面。
- 色：零至四，对应五种浅色底；零是纸白，其余依次为浅黄、浅绿、浅蓝、浅粉。
- 目录文件不存在时，按目录里的 `。文本` 文件扫出编号，元数据取不置顶、色零。
- 正文与目录都先写草稿再改名，读到的是整篇旧文或整篇新文。

## 纯函数

- 「笺标题」：取正文首行，去掉首尾空白；空文得“无题”。
- 「笺排序」：置顶的在前；同置顶时修改时刻大的在前；都相同时编号大的在前。
- 「笺筛」：搜索词为空时原样返回，否则保留标题或正文含该子串的条目。
- 「笺时刻文」：纪元秒写成“月-日 时:分”，协调世界时。
- 「笺目们文」「笺目们自文」：笺目列与数据文件文字互相转换，往返不丢项。
- 「笺汉数文」「笺读汉数」：编号的汉字数字写法与读法。

## 壳命令

| 命令 | 参数 | 说明 |
| --- | --- | --- |
| `「记笺」于「文」曰『…』` | 正文 | 新建一条，印出新编号 |
| `「笺列」` | 无 | 逐条印编号、标题、时刻；置顶条多标“置顶” |
| `「读笺」于「号」曰「三」` | 编号 | 印出正文 |
| `「删笺」于「号」曰「三」` | 编号 | 删去正文与目录项 |
| `「改笺」于「号」曰「三」于「文」曰『…』` | 编号、正文 | 整篇换掉正文 |
| `「置笺」于「号」曰「三」` | 编号 | 置顶状态取反 |
| `「色笺」于「号」曰「三」于「色」曰「二」` | 编号、颜色号 | 改颜色号，限制在零至四 |

编号不存在时印“错误：没有这张便笺。”。「记笺」遇到目录不存在时借执行器的写文件创建祖先目录。

## 文件

- `笺籍。豫`：类型、纯函数与文件读写。
- `笺令。豫`：七条壳命令的做法与登记函数。
- `测试/笺籍。测试。豫`：标题、排序、搜索、目录往返与汉字数字的断言。
