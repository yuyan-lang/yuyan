# 笺谱

便笺存储与壳命做法之库，供图形之程「便笺」（包名「花笺」）与壳命共之。

## 所存

- 一笺之正文书为 `/数据/花笺/<号>。文本`，号以逐位汉字之数书之（如一、一二、一零三）；正文为常文，题取首行。
- 其目书于 `/数据/花笺/目录。数据。豫`，依数据子语言书之：

```yuyan
「笺目」者
　「列」
　【「笺」【「号」者「一」也，「置顶」者「阴」也，「色」者「零」也】
　，「笺」【「号」者「二」也，「置顶」者「阳」也，「色」者「三」也】
　】
也。
```

- 号：正数，新记取今最大之号加一。
- 置顶：阳为置顶。置顶者列于前。
- 色：零至四，应五浅色之底；零为纸白，余为浅黄、浅绿、浅蓝、浅粉。
- 目文不在时，依目中 `。文本` 之文扫其号，目取不置顶、色零。
- 正文与目皆先书于草而后易名，所读为全旧或全新。

## 纯函

- 「笺标题」：取正文首行，去其首尾之白；空则“无题”。
- 「笺排序」：置顶者先；同顶则改时大者先；皆同则号大者先。
- 「笺筛」：词空则如故，否则留题或文含其子串者。
- 「笺时刻文」：纪元之秒书为“月-日 时:分”，依协调世界时。
- 「笺目们文」「笺目们自文」：目列与数据文相转，往还不失。
- 「笺汉数文」「笺读汉数」：号之汉字写法与读法。

## 壳命

| 命 | 参 | 说 |
| --- | --- | --- |
| `「记笺」于「文」曰『…』` | 正文 | 新记一条，印新号 |
| `「笺列」` | 无 | 逐条印号、题、时；置顶者多标“置顶” |
| `「读笺」于「号」曰「三」` | 号 | 印正文 |
| `「删笺」于「号」曰「三」` | 号 | 去正文与目项 |
| `「改笺」于「号」曰「三」于「文」曰『…』` | 号、正文 | 全篇易其正文 |
| `「置笺」于「号」曰「三」` | 号 | 置顶之状反之 |
| `「色笺」于「号」曰「三」于「色」曰「二」` | 号、色号 | 易色号，束于零至四 |

号不在则印“错误：没有这张便笺。”。「记笺」遇目不在则借执行器之写文以造祖先之目。

## 文

- `笺籍。豫`：类型、纯函与文之读写。
- `笺令。豫`：七命之法与登函。
- `测试/笺籍。测试。豫`：题、排、搜、目之往还与汉字数之断。
