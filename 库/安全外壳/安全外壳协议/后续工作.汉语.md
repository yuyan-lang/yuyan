# SSH 与 SSHD 后续工作

## 当前停点

豫言已实现 SSH 传输、Ed25519 公钥认证、单个 session 通道、无 PTY 命令标准流和 PTY 双向字节转发。客户端与一次性服务端探针已和 OpenSSH 完成密钥交换、认证、命令会话、数据回传及重换钥互通。密码学原语目前调用 OpenSSL `libcrypto`。现有探针固定监听本机回环地址和测试端口，并依赖 `/tmp/yyssh...` 测试文件；它们用于验证基础库，尚不是可直接部署的通用 SSH/SSHD。

## 恢复工作时优先完成

1. 将测试探针整理为可配置的豫言客户端和服务端入口：主机与端口、私钥与可信主机文件、授权公钥、远程命令及本地输入输出路径由参数或配置指定。先保留单用户、公钥认证和一个会话通道。
2. 把服务端单连接处理从探针主程序抽成可复用函数；同一监听端口连续处理连接，随后支持并发连接，并保证每条连接的密钥、IV、窗口、子进程与清理互不混用。
3. 提供明确的基础文件传输用法。可先以 `exec` 加标准流传输文件并核对长度或摘要；若要求兼容现有 `sftp` 或 `scp` 客户端，再实现对应子系统或协议。
4. 用真实 OpenSSH 对端回归上传、下载、大文件、小窗口、半包、断连和重换钥；同时检查未授权密钥、主机密钥不匹配与错误报文均被拒绝。

## 后期完善

- 完整的多用户授权、账户权限边界、会话资源限额与服务日志。
- 更多密钥交换、主机密钥、对称加密和用户认证算法；扩展前先保持现有算法协商的严格拒绝行为。
- 多通道、端口转发、SFTP、复杂终端模式，以及更完整的关闭、超时和重连处理。
- 将 OpenSSL 依赖封装成稳定接口；若未来要求纯豫言密码学实现，单独做安全审查与互通验证。
