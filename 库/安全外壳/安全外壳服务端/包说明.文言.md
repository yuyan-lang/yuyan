# 安全外壳服务端

纯豫言之安全外壳（SSH）服务端之库，整理自 `测试/安全外壳服务端互通` 之探针，豫言操作系统之远程登录程序（`豫言操作系统/应用/远程登录`，装为 `/工具/yy远程登录`）用之。

## 服务端

`运行安全外壳服务` 守所予之址与端口，以三十二字之 Ed25519 主机私种，逐一服诸连：

- 换钥：交版本、KEXINIT、curve25519-sha256、ssh-ed25519 主机钥、二向皆 aes256-gcm@openssh.com，合 OpenSSH 客户之默法。
- 认证：ssh-userauth 之 publickey（Ed25519，试探回 PK_OK）与 password；准否由呼者之回调判之，用户名不限。败回 USERAUTH_FAILURE（可用 publickey 与 password），口令一误约候一秒，二十败则断。
- 会话：一 session 通道，办 pty-req（记终端之模）、shell、exec、subsystem（名付呼者之 `开子系统` 判之，SFTP 用之）、env（不办）、窗之调与数；全局之请皆回败；闲约五分发 keepalive@openssh.com 一次，再约一分无应则断。

会话之容付呼者之 `服务端处理` 回调：`开会话` 予开场之出，`开子系统`（子系统之名，返受否；受则此通道之数亦付 `会话输入` 与 `会话轮询`，呼者自记所办何子系统，SFTP 见 `库/安全外壳/安全外壳文件传输`），`会话输入` 受客之入（空字节串为彼已发 EOF），`会话轮询` 每轮取新出，`会话执行` 办 exec；回调返 `会话反应`（出、已终否、退码），终则服务端发 exit-status、EOF 与 CLOSE。`会话收尾` 于连终时呼之一次，`记事` 受日志之行。本轮得报或回调予新出，则服务端即复一轮；待发之出逾八兆，则暂不向回调取新出，待客增窗而复取。

后续版本之事：并服多连与多通道、重换钥（彼发 KEXINIT 今则断）、端口转发。

## 登录设置

豫言操作系统数据盘 `/系统/远程登录/` 之三文：

- `主机私种`：三十二字之 Ed25519 种，`取得主机私种` 初取乃以安全随机生之。`主机公钥行` 予可置于 known_hosts 之公钥行，`主机钥指纹` 予 `SHA256:…` 之纹（同 `ssh-keygen -l`）。
- `口令`：一行 `pbkdf2-sha256$次数$盐$散列`（PBKDF2-HMAC-SHA256，十六字随机之盐，十六进制），`写入登录口令` 书之（空口令则删其文），`核对登录口令` 依文中之盐与次复算而比。
- `授权公钥`：OpenSSH authorized_keys 之式，`公钥已授权` 查其中之 ssh-ed25519 公钥。
