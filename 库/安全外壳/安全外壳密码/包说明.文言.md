# 安全外壳密码

「求已知主机HMACSHA1」以二十字盐算主机名 HMAC-SHA1，供 OpenSSH `known_hosts` 隐名核对，主机名之长以字节串明记之。

包名「豫言/安全外壳密码」，版「0.1.0」。为安全外壳协议备 SHA-256、X25519、Ed25519 与 AES-256-GCM 密码术。「原语。豫」依共用「密码」基础库，以明长字节数组行之，存既有字节串入口及归果之式。「解密AES256GCM结果」仍以首字节一为成、零为败。「原语宿主。接口。豫」存旧宿主直呼之声，其清理待后续迁移。

「原语。豫」皆受还原字节串。X25519、Ed25519 私钥以三十二字节种子为参；新种子当取标准库之安全随机。X25519 共密三十二字节，全零则拒。Ed25519 验伪签返阴，参长不合则报事故。AES-256-GCM 用三十二字节钥、十二字节 IV，密文后缀十六字节签；验成乃还明文。同钥之 IV 绝不可复用。

今私钥及共密寄普通豫言字节串。密钥护藏与清除、迁后协议互通及诸后端核验，皆待续行。
