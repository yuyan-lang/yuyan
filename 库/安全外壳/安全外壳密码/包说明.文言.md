# 安全外壳密码

「求已知主机HMACSHA1」以二十字盐算主机名 HMAC-SHA1，惟供 OpenSSH `known_hosts` 隐名核对；不施于 SSH 会话密报或报文验真。

包名「豫言/安全外壳密码」，版「0.1.0」。为安全外壳协议备 SHA-256、X25519、Ed25519 与 AES-256-GCM 密码术。其实由宿主供之：Node 宿主用 `node:crypto`（见 `豫言操作系统/宿主/节点/宿主.cjs`）；旧赖 OpenSSL 之包内 C，随编译器改为唯一 Wasm 后端而删。

「原语。豫」皆受还原字节串。X25519、Ed25519 私钥以三十二字节种子为参；新种子当取标准库之安全随机。X25519 共密三十二字节，全零则拒。Ed25519 验伪签返阴，参长不合则报事故。AES-256-GCM 用三十二字节钥、十二字节 IV，密文后缀十六字节签；验成乃还明文。同钥之 IV 绝不可复用。

今私钥及共密寄普通豫言字节串。欲设服务于公网，尚须密钥护藏与清除之法，亦须验协议互通。
