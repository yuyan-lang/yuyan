# 安全外壳密码

`求已知主机HMACSHA1` 使用 20 字节盐计算主机名 HMAC-SHA1，仅用于 OpenSSH `known_hosts` 哈希主机名校验；不用于 SSH 会话加密或消息认证。

包身份为 `豫言/安全外壳密码`，版本 `0.1.0`。本包提供 SSH 所需的 SHA-256、X25519 和 Ed25519 原生密码学原语，依赖系统 OpenSSL `libcrypto`。在 macOS 和 Linux 上，构建时须能找到 OpenSSL 头文件与库。当前豫构不能声明系统头文件路径；若 OpenSSL 不在编译器默认搜索路径，须在构建环境中设置 `CPATH`。本机 Homebrew 路径可用 `CPATH=/opt/homebrew/opt/openssl@3/include`。

`原语。豫` 接受和返回原始字节串。X25519 与 Ed25519 私钥参数为 32 字节种子；调用者应从标准库的安全随机接口生成新种子。X25519 共享秘密为 32 字节，并拒绝全零结果。Ed25519 验签对错误签名返回阴，参数长度错误时报错。AES-256-GCM 使用 32 字节密钥、12 字节 IV，返回密文与完整 16 字节标签；解密只有在认证成功后才返回明文。一次最多处理 1 MiB 正文与 1 MiB 附加数据。调用者必须保证同一密钥下 IV 不重复。

私钥与共享秘密目前以普通豫言字节串保存。部署服务端前仍需补充受保护的密钥存储及清除策略，并完成协议层互通测试。
