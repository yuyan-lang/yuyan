# 安全外壳密码

`求已知主机HMACSHA1` 使用 20 字节盐计算主机名 HMAC-SHA1，仅用于 OpenSSH `known_hosts` 哈希主机名校验；不用于 SSH 会话加密或消息认证。

包身份为 `豫言/安全外壳密码`，版本 `0.1.0`。本包提供 SSH 所需的 SHA-256、X25519、Ed25519 与 AES-256-GCM 密码学原语。实现由宿主提供：`原语宿主。接口。豫` 里的九个无体声明编成导入模块「安全外壳密码」的带类型导入，Node 工具宿主用 `node:crypto` 实现全部九个（见 `豫言操作系统/宿主/节点/宿主.cjs`），Node 应用宿主只实现「求SHA256」；`原语。豫` 寻诵转出它们，并用其中的「解密AES256GCM结果」写成「解密AES256GCM」。原先依赖 OpenSSL 的包内 C 实现已随编译器改为单一 Wasm 后端而删除。

`原语。豫` 接受和返回原始字节串。X25519 与 Ed25519 私钥参数为 32 字节种子；调用者应从标准库的安全随机接口生成新种子。X25519 共享秘密为 32 字节，并拒绝全零结果。Ed25519 验签对错误签名返回阴，参数长度错误时报错。AES-256-GCM 使用 32 字节密钥、12 字节 IV，返回密文与完整 16 字节标签；解密只有在认证成功后才返回明文。调用者必须保证同一密钥下 IV 不重复。

私钥与共享秘密目前以普通豫言字节串保存。部署服务端前仍需补充受保护的密钥存储及清除策略，并完成协议层互通测试。
