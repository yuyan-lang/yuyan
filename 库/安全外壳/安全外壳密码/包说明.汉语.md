# 安全外壳密码

`求已知主机HMACSHA1` 使用 20 字节盐计算主机名 HMAC-SHA1，用于 OpenSSH `known_hosts` 哈希主机名校验，主机名长度由字节串显式记录。

包身份为 `豫言/安全外壳密码`，版本 `0.1.0`。本包提供 SSH 所需的 SHA-256、X25519、Ed25519 与 AES-256-GCM 密码学原语。`原语。豫` 依赖共用「密码」基础库，以显式长度字节数组调用算法，并保留既有字节串入口和返回格式。`解密AES256GCM结果` 仍以首字节一表示成功、零表示失败。`原语宿主。接口。豫` 保存旧宿主直接调用声明，旧声明的清理留待后续迁移。

`原语。豫` 接受和返回原始字节串。X25519 与 Ed25519 私钥参数为 32 字节种子；调用者应从标准库的安全随机接口生成新种子。X25519 共享秘密为 32 字节，并拒绝全零结果。Ed25519 验签对错误签名返回阴，参数长度错误时报错。AES-256-GCM 使用 32 字节密钥、12 字节 IV，返回密文与完整 16 字节标签；解密只有在认证成功后才返回明文。调用者必须保证同一密钥下 IV 不重复。

私钥与共享秘密以普通豫言字节串保存。受保护的密钥存储及清除策略、迁移后的协议层互通和各后端验证留待后续实施。
