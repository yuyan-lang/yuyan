# 安全外壳文件传输

纯豫言之安全外壳文件传输（SFTP 第三版，draft-ietf-secsh-filexfer-02，OpenSSH 所用）服务端之库。豫言操作系统之远程登录（`豫言操作系统/应用/远程登录`）于 `subsystem sftp` 之通道用之以办诸请；标准之 `sftp` 与 `scp`（OpenSSH 九版起默循 SFTP）得以上下文件。

## 用法

- `新传文态`（已授目权、起始之目）造一会话之态；客所见之径，皆此目权中以 `/` 起之绝径，起始之目乃 REALPATH 问 `.` 之答。
- `传文输入`（态、通道之数）受客所发之字节：攒为完整之包，逐一办之，返（当回之出，会话已终否）；空字节串者，彼已发 EOF，收尾而终会话。
- `传文轮询`（态）每轮一呼，续办入缓中未办之包（一批之出至二百五十六 KiB 则止，余者下轮再办），所返同上。
- `传文收尾`（态）连终时呼之，闭诸未闭之柄。

## 所支之操作

- INIT 回 VERSION 三，不宣扩展。
- OPEN：惟读（READ）；书（WRITE）可兼 CREAT、TRUNC、APPEND、EXCL。
- CLOSE、READ（依偏读一块，至多二百五十六 KiB）、WRITE（顺序书一块；写柄攒所受之块至一 MiB 乃真书一次，CLOSE 则书其余；裸机大文转流之后每书为一事务，攒大块乃速；书败则于刷写或 CLOSE 时报之）。
- LSTAT、STAT、FSTAT：回大小、权（目 0755、文 0644）与时（零）。
- SETSTAT、FSETSTAT：回成，属不理。
- OPENDIR、READDIR（一次至多六十四项，长名如 ls -l）、REMOVE（普通文）、MKDIR、RMDIR（空目）。
- REALPATH：规范其径，不必存在，行 `.`、`..` 与重 `/`。
- RENAME：普通文，目标不存则流式抄之而后删原文以成。
- READLINK、SYMLINK 与扩展之请，回“未支”（SSH_FX_OP_UNSUPPORTED）；式不合之包，回 SSH_FX_BAD_MESSAGE。

## 文之操

本库惟依豫言操作系统文件之接口：目权加相对之径、文件柄、`定位读取文件`、`打开覆盖文件`、`打开追加文件`、`写入文件`、`列出目录`、`查询文件信息`、`创建目录`、`删除路径`。读写皆流式：一 READ 当一次定位读，一 WRITE 当一次顺序书，存中唯有今之一块，故可传数百 MiB 之系统镜像。径以 UTF-8 字节论，可有中文之名。

## 验证

于宿主（苹果臂原生）以 OpenSSH 十版之 `sftp` 与 `scp`（默 SFTP 模式）核之：mkdir、put、get、`ls -l`、rename、rm、rmdir、中文之名、`scp -r` 递归上下，皆正。百 MiB 随机文之 `sftp put` 十二点三秒、`sftp get` 十三点一秒、`scp` 上十三点八秒、下十三点一秒（约每秒七至八 MiB），沙256 与原文合。所耗多在 AES-256-GCM（见安全外壳密码之快实）。

## 后续版本之事

- 定位书：今要求每 WRITE 之偏等于该柄已书之字节数（续模式不观偏），足以服 `sftp put` 与 `scp`；续传（`reput`）与多路并行之上传，留待后续。
- 读写同开。
- 目录改名：文件接口增“改名路径”之后，易复制再删之法，并支持目录。
- 符号链接、真实之权与时、六十四位偏移之高位。
- 一程至多约十万次开文（文件接口之资源表不复用表序），久行之远程登录须时时重启。
