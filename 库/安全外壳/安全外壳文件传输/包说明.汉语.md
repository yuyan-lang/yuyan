# 安全外壳文件传输

纯豫言的安全外壳文件传输（SFTP 第 3 版，draft-ietf-secsh-filexfer-02，OpenSSH 使用的版本）服务端库。豫言操作系统的远程登录程序（`豫言操作系统/应用/远程登录`）在 `subsystem sftp` 通道上用它办请求，标准的 `sftp` 与 `scp`（OpenSSH 9 起默认走 SFTP）可以上传、下载文件。

## 用法

- `新传文态`（已授目录权、起始目录）建立一个会话状态；客户端看到的路径都是这个目录权里以 `/` 起头的绝对路径，起始目录是 REALPATH 对 `.` 的回答。
- `传文输入`（状态、通道数据）收一段客户端发来的字节：攒成完整的包，逐个办理，返回（要发回的输出，会话是否已结束）；空字节串表示对端发了 EOF，收尾并结束会话。
- `传文轮询`（状态）每一轮调用一次，继续办输入缓冲里还没办的包（一批的输出攒到 256 KiB 就停，剩下的下一轮再办），返回值同上。
- `传文收尾`（状态）在连接结束时调用，关掉所有还开着的句柄。

## 支持的操作

- INIT 回 VERSION 3，不宣告任何扩展。
- OPEN：只读（READ）；写（WRITE）可带创建（CREAT）、截断（TRUNC）、追加（APPEND）、独占（EXCL）。
- CLOSE、READ（按偏移读一块，至多 256 KiB）、WRITE（顺序写一块；写柄把收到的块攒到 1 MiB 才真写一次文件，CLOSE 时写完剩下的；裸机上大文件转成流式之后每次写是一个事务，攒成大块才快；写失败在刷写时或 CLOSE 时报告）。
- LSTAT、STAT、FSTAT：回大小、权限（目录 0755、普通文件 0644）与时间（0）。
- SETSTAT、FSETSTAT：回成功，属性忽略。
- OPENDIR、READDIR（一次至多 64 项，长名是 ls -l 的样子）、REMOVE（普通文件）、MKDIR、RMDIR（空目录）。
- REALPATH：规范化路径，不要求存在，支持 `.`、`..` 与重复的 `/`。
- RENAME：普通文件，目标不存在时用流式复制再删除原文件完成。
- READLINK、SYMLINK 与扩展请求回“不支持”（SSH_FX_OP_UNSUPPORTED）；格式不对的包回 SSH_FX_BAD_MESSAGE。

## 文件操作

库只依赖豫言操作系统文件接口：目录权加相对路径、文件柄、`定位读取文件`、`打开覆盖文件`、`打开追加文件`、`写入文件`、`列出目录`、`查询文件信息`、`创建目录`、`删除路径`。读写都是流式的：一个 READ 对应一次定位读取，一个 WRITE 对应一次顺序写入，内存里只有当前一块，因此可以传输几百 MiB 的系统镜像。路径按 UTF-8 字节处理，可以有中文名。

## 验证

宿主（macOS arm64 原生）上用 OpenSSH 10 的 `sftp` 与 `scp`（默认 SFTP 模式）核对：mkdir、put、get、`ls -l`、rename、rm、rmdir、中文文件名、`scp -r` 递归上传与下载都正确。100 MiB 随机文件的 `sftp put` 12.3 秒、`sftp get` 13.1 秒、`scp` 上传 13.8 秒、下载 13.1 秒（约 7–8 MiB/s），沙256 与源文件一致。时间主要花在 AES-256-GCM（见 安全外壳密码 的快速实现）。

## 后续版本的事项

- 定位写：现在要求每个 WRITE 的偏移等于该句柄已写的字节数（追加模式不看偏移），这足以服务 `sftp put`、`scp`；续传（`reput`）与多路并行上传留待后续版本。
- 读写同时打开。
- 目录改名：文件接口增加“改名路径”之后换掉复制再删除的做法，并支持目录。
- 符号链接、真实的权限与时间、64 位偏移的高位。
- 一个程序进程最多约十万次打开（文件接口的资源表不复用表序），长期运行的远程登录需要定期重启。
