# 安全外壳终端验证

标准流测试使用真实 `/bin/cat` 验证 stdin 到 stdout 的原始字节和 EOF，使用 `/bin/sh` 验证 stderr 与 stdout 分离，再用 `/usr/bin/true` 验证子进程退出后向已关闭输入写入只返回错误而不会触发 SIGPIPE。另用 `/bin/sleep` 验证 SIGTERM、信号退出、重复回收拒绝，并检查绝对路径约束。

分配原生伪终端，设置并读取字符与像素尺寸，通过从端向主端传送原始字节，检查非阻塞空读、可写等待和越界尺寸。另设原始模式，验证无换行字节可直接送达从端；单独关闭回显后，验证规范行输入仍可到达从端而主端不收到回显。随后启动 `/usr/bin/tty`，确认子进程取得控制终端并被回收；再启动 `/bin/sleep`，验证进程组终止、信号退出及重复收取时的拒绝。相对路径程序不得启动。该验证只在原生 macOS/Linux 运行。
