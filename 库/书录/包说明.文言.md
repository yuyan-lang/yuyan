# 包页渲染

此主站包管理页与 docs 站包页共用之渲染，模块与验证自云仓包管理服务之包引擎迁入。一结绳之数入，一页之文出：包说明、包制、所赖与修订之记，皆以常文转义而陈，外辞不为网文；说明中相对之链，惟既见于包内文件之目者乃生。

`页面渲染。豫` 出概览与文件二页：页首有概览、文档二签；文件页之文档与源码二视同在一页，目录居右，另附隐藏之阅读数据供客器定位。`站制。豫` 定站内之链：主站之包在 `/release/<修订>/`，语在 `?lang=`；docs 之包在 `/包/<主>/<名>/`，语在 `/文言` 之冠，逐篇之文档页在包根下 `/文档/<去 source/ 之径>/`，包制文档之根页为 `/文档/`。渲染依制出一种，主站之一种与原出一同。

docs 文件页之数由「网站资料生成」之 `包文件页。豫` 拼之：`documentation.names` 以「阅读逻辑」之「声明」自源抽之，`references` 与 `qualifiedReferences` 以「阅读逻辑」之「引用」算之；跨包之引于生成之时算为址——目标为社区包者指其站内文件页，目标为语言仓之包者指引言仓本轮提交于 GitHub 之源，声明行号书为 `#L` 之锚。

`安全文档。豫` 以说明之 Markdown 为受文之 HTML，惟生定式之签，原文尽转。`页面附录。豫` 出所赖、包制与上传之记；旧修订无摘要者，以包制静态解析补之。`包定义文档。豫` 以包制为结构之说。

本包依标准库、结绳工具、网页客户端、笺注与包配置。试居 `测试/`，测试包登于共用库。
