# 书录

这是主站包管理页与 docs 站包页共用的一份渲染，模块与验证从云仓包管理服务的包引擎迁入。一份结绳（JSON）页数据进，整页 HTML 出：包说明、包配置、依赖与上传历史都按文字安全渲染，上传内容不作为 HTML 执行；包说明里的相对链接只在包内文件清单验证过的目标上生成。

`页面渲染。豫` 出概览页与文件页：页头有概览与文档两个页签，文件页把文档视图与源码视图放在同一页，文件目录是右侧栏，并附隐藏的阅读数据供浏览器应用定位。`站制。豫` 定站内链接：主站的包页在 `/release/<修订>/`、语言写在 `?lang=`；docs 站的包页在 `/包/<所有者>/<包名>/`、语言写在 `/文言` 前缀，逐文件的文档页在包根下 `/文档/<去掉开头 source/ 的文件路径>/`，包配置文件的文档根页是 `/文档/`。渲染按站制出一种页面，主站那一种与原输出相同。

docs 站的文件页数据由「网站资料生成」的 `包文件页。豫` 拼好：`documentation.names` 用「阅读逻辑」的「声明」从源码抽，`references` 与 `qualifiedReferences` 用「阅读逻辑」的「引用」算；跨包引用在生成时就算成网址——目标是社区包的指它的站内文件页，目标是语言仓的包指引言仓本轮提交在 GitHub 上的源码，声明行号写成 `#L` 锚点。

`安全文档。豫` 把包说明的 Markdown 渲染成受控的 HTML，只生成固定标签，原文一律转义。`页面附录。豫` 出依赖、包配置与上传历史，旧修订没有依赖摘要时用包配置静态解析补上。`包定义文档。豫` 把包配置渲染成结构化说明。

本包依赖标准库、结绳工具、网页客户端、笺注与包配置。测试在 `测试/`，测试包登记在共用库。
