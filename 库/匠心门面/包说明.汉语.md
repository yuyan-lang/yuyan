# 设计界面

「控件」构造生成自己的「控件树」，用带标签参数表达界面的所有元素种类、键、样式、属性、命令事件声明、行内片、文字、选中状态与子项。构造写法 `「控件」【…】` 里「种类」「属性」「行内」必写，键、样式、事件、文字、选中可省，子项可省、子控件直接作尾随项，命名项次序不拘；函数调用写法必写「种类」「属性」「行内」「子项」，子项写 `于「子项」曰…`，具名项照签名次序：种类、键、样式、属性、事件、文字、选中、行内、子项。样式和源码属性沿用界面库的完整类型，源码期的消息函数交给既有更新模型；「作门面」把控件树转给现有后端。「令点击」「令提交」「令入」可以生成字符串命令消息。

「门面作品」按指定宽高生成当前界面状态的设计快照。作品保留控件声明树，每个控件保存种类、键、事件目标、当前超文本与全部状态样式；快照图像是当前状态的展开画面，可以经过设计树码编码、还原和引擎渲染。源码期消息处理函数保存在源程序，纯命令事件文字保存在声明树。

## 写真

「写真」把界面视图离屏画成便图（PNG）字节，全程不须显示面：按逻辑宽、高与像素比求样式、排版、生成显示树，画到画绢，再经画谱编成便图。像素比是正整数，一倍得逻辑宽高的像素数，二倍得宽高各两倍（640×480 在二倍下是 1280×960）。

图形程序的视图用设计语言写成控件树，经「作门面」换成门面元素后交给「写真」：

```yuyan
寻观「豫章」之书。
寻观「豫章」之「寓所」之「藏书」之书。
寻观「门面待办例」之「待办」之书。
寻观「匠心待办」之「待办设计」之书。
寻观「匠心门面」之「控件构造」之书。
寻观「匠心门面」之「写真」之书。

「：汉语：把待办的设计视图画成两倍便图，写到文件。：」
「入口」乃化「有」为「有」者也。
「入口」者得「无」而
　令「字体帛」为「阅帛」于『豫言操作系统/裸机/字模生成/字体/原始字体.ttf』而
　令「图」为
　　「写真」
　　　于「视图」曰
　　　　（「作门面」
　　　　　以（「待办」之「待办消息」）
　　　　　于（「待办设计视图」于（「待办」之「初始模型」）））
　　　于「宽」曰「六四零」
　　　于「高」曰「四八零」
　　　于「像素比」曰「二」
　　　于「字体」曰「字体帛」而
　「著帛」于『/tmp/待办.png』于「图」
也。
```

字体参数是 TrueType 字体文件的字节，由调用方读入（如「阅帛」）；函数把它登记为「无衬线」，此后量字、画字都用它。视图样式里的字体族照旧，缺字回退到「无衬线」。返回的字节可以直接写文件，也可以交画谱的「解完璧图」解码。

测试见 `测试/写真。测试。豫`：把待办的设计视图经「作门面」后在 640×480 下按一倍、二倍各画一张，核对便图头八个字节与宽高。

后续步骤：可序列化的动态控件状态机、完整声明式事件参数、组件定义去重与实例实参；写真按字体文件里的族名登记，供视图用别的族名时直接取用。
