# 设计界面

「控件」之构生己之「控件树」，以有名之参表界面诸种、键、式、属、命令事辞、行内之片、文、选态与子项。构造之书 `「控件」【…】` 中，种、属、行内必书，键、式、事、文、选可阙，子可阙而子控件径为尾随之项，命名之项次序不拘；调用之书必书种、属、行内、子，其子项书 `于「子项」曰…`，具名之项依签名之次：种、键、式、属、事、文、选、行内、子。式与源属沿用界面之全类，源码时消息之函交旧更新之模；「作门面」以控件树交旧后端。「令点击」「令提交」「令入」可生串之命令消息。

## 锦囊

凡可操之项必带等价之壳命（AGENTS.md「图形程序」）。控件树之「属性」列挂「锦囊」于（得「无」而 策们）：副击（右键单击）此控件，自绘之后端于指处出诸策，择一则以其「信」交客之更新，与壳中行其「令」同成一事。下拉之择用「囊钮」，主键单击则出诸策于其下。策依包「门面」之「策府」书之：「良策」为常项，「勾策」带勾（今值），「策囊」为子囊，「策隔」为界线；每策之「令」书等价之壳命，惟易本窗之视者书空文。

```yuyan
「控件」
【「种类」者「横排种类」也
，「属性」者「列」【「锦囊」于（得「无」而「待办」之「待办策们」于「项」）】也
，「行内」者「列」【】也
，「键」者（「述数」于「号」）也
，「样式」者「列」【「待办」之「条目行」】也
】
```

例见「匠心待办」之「设计条目视图」（`示例/待办/待办设计。豫`）：「待办策们」出完成与否（勾策，勾即「已完成」）与删除，令为等价之壳命 `「待办毕」于「序号」曰「7」`、`「待办删」于「序号」曰「7」`。囊之出、指与键之事见包「门面自绘」之说明。

「门面作品」依所定宽高生今态之设计快照。作存控件声明树，每控件存种、键、事之目标、今超文本与全态之式；照图为今态之展画，可编设计树码、还原而以引擎渲之。处事之函存于源，纯命令事文存于声明树。

## 写真

「写真」以界面之视图离屏画为便图之字，全程不须显示之面：依逻辑之宽高与像素之比求式、排版、生显示之树，画于画绢，复经画谱编为便图。比者正整数，一倍得逻辑宽高之像素数，二倍则宽高各倍之（六百四十乘四百八十于二倍为千二百八十乘九百六十）。

图形之程，其视图以设计之语书为控件之树，经「作门面」易为门面之元，乃交「写真」：

```yuyan
寻观「豫章」之书。
寻观「豫章」之「寓所」之「藏书」之书。
寻观「门面待办例」之「待办」之书。
寻观「匠心待办」之「待办设计」之书。
寻观「匠心门面」之「控件构造」之书。
寻观「匠心门面」之「写真」之书。

「：汉语：把待办的设计视图画成两倍便图，写到文件。：」
「入口」乃化「有」为「有」者也。
「入口」者得「无」而
　令「字体帛」为「阅帛」于『豫言操作系统/裸机/字模生成/字体/原始字体.ttf』而
　令「图」为
　　「写真」
　　　于「视图」曰
　　　　（「作门面」
　　　　　以（「待办」之「待办消息」）
　　　　　于（「待办设计视图」于（「待办」之「初始模型」）））
　　　于「宽」曰「六四零」
　　　于「高」曰「四八零」
　　　于「像素比」曰「二」
　　　于「字体」曰「字体帛」而
　「著帛」于『/tmp/待办.png』于「图」
也。
```

字体之参为真型字体之字，客自读之（如「阅帛」）；函登之为「无衬线」，自是量画皆用之。视图之族仍旧，缺字退于无衬。所还之字可径书于卷，亦可交画谱「解完璧图」解之。

试见 `测试/写真。测试。豫`：以待办之设计视图经「作门面」，于六百四十乘四百八十按一倍二倍各画一图，核便图首八字与宽高。

后步之事：可藏之动态控件状态机、全声明事参、组件定义之去重与实例之实参；写真依字体文内之族名登记，供视图用他族名时径取。
