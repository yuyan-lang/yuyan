# 设计界面待办

待办设计视图复用原示例的模型、消息、更新与全部样式，元素写成设计语言的带标签控件构造。测试以八步元素事件日志分别推动两份模型，每步核对超文本和样式，最后核对实际的添加、完成、删除、清除结果，并生成当前状态的设计快照。

`待办。设计。豫` 是设计编译入口样例。`运行。脚本。豫` 在现有自绘后端显示控件树，视图每帧读取当前模型，更新和壳命令共用「执行待办消息」。壳提供「待办草稿」「待办增」「待办毕」「待办删」「待办清除」「待办态」，用户态桌面的统一壳登记同一做法。状态在当前会话的引用中保存。

每个条目挂锦囊（右键菜单，[提案 00048](../../../../提案/00048-锦囊.汉语.md)）：「完成」（勾策，勾为已完成，令是 `「待办毕」于「序号」曰「7」`）与「删除」（令是 `「待办删」于「序号」曰「7」`），信与复选框、删除钮相同。

保存的设计作品包含当前状态快照与纯控件、事件声明。`声明重放` 的「待办重放作品」保存统一壳命令事件日志；「重放待办作品」从初始模型逐句经现有壳快路执行，再由同一控件视图重绘。测试保存八步事件、读取设计文件后重放，核对最终状态、控件声明、图像和完整设计编码一致。消息闭包继续供源码期使用；参数内换行列为后续版本事项。
