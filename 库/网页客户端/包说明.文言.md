# 网页客户端

纯函数之网页前端组件核心：虚文档之节点不系宿主，组件即常函数，状态组件显受其态；兼有文档之组件与构建期之源码高亮。旧属拓展库，二〇二六年九月二十六日别立为包。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包为库，可供他包所依；依标准库，其试另用单元测试。

独书 `寻观「网页客户端」之书。` 则取总集（核心、文档组件、源码高亮）。

高亮逐辞之验，载于 `源码高亮测试数据。豫`；三十行采自标准库之整数操作与字符串术。每行列原文与色类，类空则无色。`源码高亮。测试。豫` 逐行校其超文本全文，色类应使用方 CSS 之 `tok-*` 类。

变接口则修说明，变身份、版本与所依则修包籍。
