# 网页客户端

纯函数式的网页前端组件核心：宿主无关的虚拟文档节点、用普通函数写的组件、显式接收状态的状态组件；另含文档级组件与构建期源码高亮。原属拓展库，2026-09-26 起独立成包。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，可被其他包依赖；依赖标准库与编译器核心（源码高亮用它的语法分析器），测试另用单元测试。

## 使用

单段导入 `寻观「网页客户端」之书。` 取总集（核心、文档组件、源码高亮）。

源码高亮：`高亮源码` 给豫言源码着色时，先调用编译器核心的 `解析源码语义标记`（只做词法、切句与操作符规约），按语法分析器给出的语义标记着色，颜色与编译器的理解一致：类型签名里的「化」「而」同为类型，结束声明的「也」与「乃」「者」同为结构，「「三」」这类数字名称是数值。源码解析失败时退回逐字的词法着色。十三种语义标记映射到既有的 `tok-structure`、`tok-type`、`tok-keyword`、`tok-identifier`、`tok-number`、`tok-string`、`tok-comment`、`tok-builtin`、`tok-punctuation` 类，使用方 CSS 照旧可用。

源码高亮的逐词测试数据在 `源码高亮测试数据。豫`，其中三十行取自标准库的整数操作与字符串术。每行保存源码及按顺序排列的「原文、颜色类别」；空类别表示未着色文本。完整语句的类别以语法分析器为准，残句用来验证词法着色这条退路。`源码高亮。测试。豫` 对整行 HTML 作精确比较，颜色类别对应使用方 CSS 的 `tok-*` 类。
