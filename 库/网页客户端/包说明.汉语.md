# 网页客户端

纯函数式的网页前端组件核心：宿主无关的虚拟文档节点、用普通函数写的组件、显式接收状态的状态组件；另含文档级组件与构建期源码高亮。原属拓展库，2026-09-26 起独立成包。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，可被其他包依赖；依赖标准库，测试另用单元测试。

## 使用

单段导入 `寻观「网页客户端」之书。` 取总集（核心、文档组件、源码高亮）。

源码高亮的逐词测试数据在 `源码高亮测试数据。豫`，其中三十行取自标准库的整数操作与字符串术。每行保存源码及按顺序排列的「原文、颜色类别」；空类别表示未着色文本。`源码高亮。测试。豫` 对整行 HTML 作精确比较，颜色类别对应使用方 CSS 的 `tok-*` 类。

## 维护

修改接口时更新本说明；修改包身份、版本或依赖时同步更新包配置。
