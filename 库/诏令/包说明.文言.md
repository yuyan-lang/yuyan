# 壳命令

设计播放器得以「设渲染后端」于「后端」曰『自动』择自动、中央处理器或图形处理器，以「渲染后端」问其配；动复用已登之播放控制之法，于壳呼之与径呼同。

待办设计示例之动作具「待办草稿」于串、「待办增」、「待办毕」于「序号」为整数、「待办删」于「序号」为整数、「待办清除」与「待办态」。设计界面待办登法，壳与桌面共用其更新之函。

交互之作之「设入」「指」「按键」「清入」「交互态」「烘焙交互」亦于壳中呼之，签依各命之约。

交互之会话与壳中以豫言句径呼之命（提案〇〇〇〇三第五步）。会话之首如已书 `寻观「诏令」之书。寻「诏令」之「案牍」之书。`：

```text
壳> 「案牍」之「列目」于『/数据』
壳> 「行」于『/程序/统计.wasm』于「列」【『/数据/文本.txt』】
壳> 「设」于『语言』于『中文』
```

- 「壳命令」模块：「问津」「日期」「纪元秒」「水土」「寓版」「图形」「辞」「拂屏」（无参，交互时可不书 `于「元」`；「纪元秒」有返值，为墙钟之整秒，同 `date +%s`），「复述」于『文』，「设」于『名』于『值』，「罢」于『名』，「行」于『程序之径』于参之列，「脚本」于『径』。「拂屏」（十月廿一日，提案〇〇〇四八戊路）清屏，同 clear：印 ESC [ H、ESC [ 2 J、ESC [ 3 J 三控制之序，终端摹写见 2 J 与 3 J 则尽去出行、光标归首，宿主之真终端亦随之清；诸处皆可用，不必入部居。「寓版」（十月廿一日）印系统之版一行：豫言操作系统中读盘上之 `/系统/版本。数据。豫`，印“豫言操作系统 1.0.0（提交 号之前九位，兼容六十四）”，不得则印“版本不明”；宿主（林檎、林纳）则印宿主工具链之提交与“行在”，式如“豫言工具链（提交 4ae56f219，行在）”，提交取会话豫构（「豫构径格」）目下之 `源/.提交`，无则印“提交 不明”。「葺寓」远程更新、易试启而成之新版时，亦以新镜之版录书回 `/系统/版本。数据。豫`，故更后「寓版」报新之号（议四百二十七）。
- 字体之命（十月廿一日）：`「装字体」于「路径」曰『字.ttf』` 以字体之文复制于用者字体之目（林檎 `~/Library/Fonts`、林纳 `~/.local/share/fonts`、豫言系统 `/系统/字体`，所缺之目由执行器书文时建之），字体之口即得之；`「卸字体」于「名」曰『字.ttf』` 依文件名自系统字体目删之；`「字体列」` 一径一行列其文。法在同包「字册」之模，字谱装卸之钮呼同一之诸函。
- 浏览资料之命（十月二十四日，提案〇〇〇五二第一期）：`「历史」` 印浏览器最近五十条之史（时、题、址，新者居前），`「清历史」` 空其史；`「加书签」于「地址」曰『https://…』于「标题」曰『…』`（题可省，省则以址）与 `「删书签」于「地址」曰『…』` 增删其签，`「书签列」` 列其全；`「清缓存」` 清浏览器磁盘缓存之册与体。法皆在库「浏览久存」，命径读浏览器之资目（豫言 `/系统/浏览器`，宿主 `~/.豫言/浏览器`），不必经浏览器之程；开者次读其表即见。
- 显示之设之命（AGENTS.md「图形程序」）：`「设分辨率」于「宽」曰「一九二零」于「高」曰「一零八零」`，`「设缩放」于「百分比」曰「一五零」`（「零」为自动，可择百、百二十五、百五十、百七十五、二百、二百五十、三百），`「设字样」于「名称」曰『等宽』`（文楷、无衬线、衬线、等宽），`「映设」` 印今之字体、缩放、分辨率与可选之值。与图形界面「系统设置」所改同一设，桌面开则随之更。
- 任务之命（十月十二日）：`「列出役」`（犹 ps）印系统之任务表：首行为任务之数与统计之界，次行为系统之总览（处理器之总用与核数、内存之已用与总），其下为表头与每任务一行（任务号、处理器、常驻内存、已用堆、名），任务管理器每秒所示即此表；`「辍役」于「号」曰「一二」` 断此任务及其子孙，同 Ctrl-C，任务旋以退码百三十终；`「辍宿主役」于「号」曰「一二」`（十月二十三日，议题四百四十）于宿上按程号止程：先 SIGTERM，三百毫秒不退则 SIGKILL，印“已结束宿主进程 12”，无此程则报误；豫言之土无宿役，改由务表（同「辍役」）；`「辍」于「号」曰「一二」`（十月十四日）惟断其方行之一句：惟终其所起之程（并其子孙），壳会话存而定义皆在，无程可断（于己之进程中算）乃断其身。桌面终端与远程登录按 Ctrl+C，即于本终端之壳会话行「辍」（图形之界径呼同一库函）。默之法告本境不能列或断任务；豫言操作系统之开机壳与桌面命令行登询任务监测、呼子程序接口之法。
- 宿主之观（十月二十日，议题百四十四；十月二十二日，议题三百一十一）：`「寻宿役」于「模式」曰『…』`（十月二十四日，议五百四十四）按令之子串筛宿役（同 `pgrep -fl`），一行一个“号  令”，有返值之「筛宿役」给「宿役」（「号」「令」二田）之列（会话中先寻诏令之宿主之书，乃用「宿主」之「筛宿役」，类名书「宿主」之「宿役」），惟取号者「筛宿役号」给数之列，可径以「第」取一交辍宿役；`「列宿役」` 印宿主之诸进程（号、已行之久与令），林纳读 `/proc`（读不出则行系统 `ps`），林檎行系统 `ps -axo pid,etime,command`；`「列端口」于「号」曰「一二」` 印宿主某进程所开之网络与本地套接字，林纳行 `ss -tunaxp` 而惟留其号之行，林檎行 `lsof -nP -a -p 号 -i -U`（待办：林纳改读 `/proc/<号>/fd` 与 `/proc/net/tcp*`，须先有读影之原语）；`「负载」` 印一、五、十五分平均负载、在线核数，又印一行“已开机 2 天 11 小时 25 分（2026-10-19 23:13 开机）”：林纳读 `/proc/loadavg`、`/proc/uptime` 而行 `uptime -s`，林檎行 `sysctl -n vm.loadavg`、`sysctl -n kern.boottime` 与 `date -r`；`「开机时长」` 还开机以来之秒数（不得则「可无」），以供他句之组合。`「印书」于「网址」曰『https://…』` 印状行、抬头与正文，`「索抬头」于「网址」曰『https://…』` 惟取抬头，皆行系统 `curl`、不落盘。宿主上行在之会话亦照此观宿主；豫言操作系统中「列宿役」如故列任务之表，「列端口」「印书」「索抬头」言其不能（「致书」改由尺素，两处同途），「负载」惟印开机之久（无 `/proc/loadavg`），「开机时长」取内核自开机以来之单调钟。
- 请之命（十月二十一日，议题二百六十七）：`「致书」于「网址」曰『https://…』` 发一带法与抬头之请（法不授则 POST），印状行、抬头与正文；抬头以 `于「标头」曰「列」【『content-type: application/json』】` 予列，体以 `于「正文」曰『…』` 予其文，秘者可藏于卷：`于「标头文件」曰『头.txt』` 每行一条读之，`于「正文文件」曰『体.json』` 原样送其卷之字节，皆不入命令行与壳之史。请经尺素之「索常驿址」而发，宿主与豫言操作系统同一途；回书内容之编由尺素解而后印。
- 封之命（提案〇〇〇三八第三步）：`「分封」于「字节数」曰「六四」` 请执行器于一器之内别立收堆（封），印其号与大小；`「列封」` 列诸封之大小、已分与存活之字节；`「削封」于「号」曰「一」` 还其堆而置为空闲，印所还之字节。唯原生六十四位址之构有之，余则印不支。

- 窗之命（十月十三日；提案〇〇〇四七加工区；议四四六加参与当径）：`「辟窗」于「种类」曰『设备管理器』` 于桌面新开一窗，与活动栏之钮等；种为终端、文件浏览、任务管理器、设备管理器、设置、搜索之一（文件浏览、搜索、启台既开则焦之），亦可为启台（『程序』）。可复予 `于「宫」曰「二」`，开于其宫；省之则开于发窗之宫。预装或已装之图形软件可复携 `于「参数」曰「列」【『图。png』】` 与 `于「目录」曰『/桌面』`，以为其命令行之参与当径（当径缺为程序所在之 `/工具` 或 `/软件`），如 `「辟窗」于「种类」曰『揽辔台』于「参数」曰「列」【『/数据/揽辔/会话。会话。豫』】` 径观一篇。`「徙窗」于「号」曰「三」于「宫」曰「二」` 移窗入宫（省「宫」新开一宫，省「号」为发窗之窗；皆省则书 `于「号」曰「零」`）；`「归窗」于「号」曰「三」` 送窗还其原宫（予宫则尽归其宫之窗）；`「入宫」于「宫」曰「二」` 主屏易而示其宫；`「窗列」` 印宫窗之表。提案〇〇〇四八复加「关窗」（闭其窗，桌面之程先送“请关闭”）、「拆窗」（拆其窗所在之组，新组中开一同种之窗；向『横』左右、『纵』上下）、「全窗」（单格全屏，再行则还）、「移窗」（移于邻组，向左、右、上、下）、「凝窗」（得其焦，在他宫则先入其宫）与问命「囊目」（印诸窗之选单与等价之命，号零或省则尽印）。自关至凝循「徙窗」之路，各书一窗请；囊目读同文快照之「窗囊」。桌面终端登此诸法（书窗请为 `/系统` 下一窗请之文，桌面每轮依名排次取办；「窗列」读 `/系统/桌面窗列。数据。豫`）；默之法报“桌面没有运行”。

## 会话与快路

豫言操作系统之壳（开机壳、桌面终端、远程登录）与宿主之 `豫构 交互` 皆豫构交互之会话，每句（壳命令亦然）皆编为组单元而行之（十月十四日用户定：一切动态装载，不设快路）。会话装前导之单元即登「实现」之「登会话做法」（会话之首不编，惟用户所入者编之）：「脚本」于『…。脚本。豫』付编译器之「行」子命，余之命令脚本书其径于请求之文，会话逐行行之；「辞」印“壳已退出”而终会话之进程。豫言操作系统中壳命之法分部按需而装：每编一句之前装句所用之部之预编单元（见用户态桌面之 `部居`）。

「快路」模块（提案〇〇〇〇三第八步）析一句壳命令为命之呼：形如 `「名」于参…` 或 `「名」之「名」于参…`，参唯字符串之字面 `『…』`、参之列 `「列」【『…』，…】`、`「元」`、十进之整数 `「一九二零」`（亦可书 `「一九二零」`）或带签之此诸参 `「宽」为「一九二零」`，名为上列之命、参之数、种与签合其签者，「快路动作」予所当为之动。其用有三：补全时析句（壳核心之命令登记）、设计示例「待办」之动作重放，及无编译器之宿主上之旧开机壳（-kernel 之验与网页之原壳）——「行壳令句」能析为壳命令则呼之，他句则告当于开机壳行之。网页之原壳编行他豫言句待后续之版。

## 实现

设计文档之命：`「出刻本」于「文件」为路径于「输出」为路径` 用设计引擎之分页与矢量显示表出便携文档；`「引为匠心」` 所入 `.md` 与 `.tex` 直成设计文档。二命于同一系统壳循带签之快路，设计库登其法。

开发之命（二〇二六年十月十四日）：「寻」「寻文字」「寻详」「寻文字详」「寻得」「寻卷」「读行」「读行宽」「计行」「读字节」「易」「全易」「依律易」「取栏」「依隔取栏」「筛行取栏」「校勘」「卷讯」「沙二五六」「索书」「解档」「打包」行「开发」之程（豫言操作系统中为 `/工具/开发。豫行`）；后台作业「后台行」「作业列」「作业出」「待作业」「限时待作业」「罢作业」亦行之，作业由远程登录之程起，宿主之上入行在之会话则由行在起（十月二十三日，议题四百四十五）；「稽」于「参数」曰「列」【…】行「稽」之程（`/工具/吉特。豫行`）。正则、差异、解压、版本库诸大库皆留于程中，不入会话之前导。「寻卷」可依大小（「至多」「至少」字节）与改时（「改于后」「改于前」）筛，四者并用。「卷讯」「沙二五六」惟印其果；「卷情」「摘要」为其有返值之版：卷情还与「卷情录」（大小、改时、类别），摘要还与沙256 之六四字小写十六进文（十月二十三日，议题四八一：摘于本程问构建宿主之「取卷沙二五六」，不复逐卷起开发之器）。「寻详」亦惟印其果；「寻得」为其有返值之版，还与（径、号、行）之列。「寻卷得」为有返值之寻卷，还径之列，内假开发之器之「找文件」而滤其“（没有找到）”一行。

行而收之（十月二十四日，议题五四一、五四三）：「行得」于「程序」曰『./程序』于「参数」曰「列」【『参数』】于「境」曰「列」【『名=值』】于「目录」曰『…』于「限秒」曰「六零」以私俗、迁其居、限其时而行之，收常出、误出与退码，还限时之果四事（超时、退码、常出、误出），自身无所印；境者一时之盖，叠于所设之上（后者胜），不改会话；参数、境、目录、限秒皆可省，限秒零则无期，超时退码百二十四（同限时待作业）。「会话俗」还所设之环境块（以本程之俗为底、叠会话水土，每项零终），未设则空文；脚本中欲使使者之趣使于境或将使之于境带所设之俗者，即以此为环境之参。「后台行」于「程序」曰『…』于「参数」曰「列」【…】以行得起开发之器之后台运行，带所设之俗，以其出付壳出示之，还作业之号；「待作业得」于「号」曰「一」（可加于「秒」曰「六零零」）为等待作业之有返者，还限时之果，超时为退码百二十四而误出含“还在运行”。「罢作业」请止而后候其终，至多十秒，印退码。

其中「依律易」依正则尽易合式之处为新文，模中 `$1`、`$&`、`$<名>` 引其捕获，全篇为一段，点不越行，欲越行则书 `[\s\S]`，印所易之数，无合不为误；「取栏」依制表取栏，「依隔取栏」以所授之分隔（书『』为制表），「筛行取栏」复以一栏同于某文筛行，栏号自一数、可多。会话中复有还列之「析行」（依换行分为行）与「析栏」（依分隔分为栏），可与「遍」「第」「择」合，如取首栏：`「复述」于（「间合」于『「：换行：」』于（「遍」以「文」又以「文」于（「析行」于（「藏书」之「阅」于『表.txt』））于（得「行」而「第」于「零」于（「析栏」于『「：制表：」』于「行」））））`。

搜索之选（二〇二六年十月二十日，议题 #139、#164、#149、#146；前、后 于二〇二六年十月二十一日依议题 #268 加）：「寻详」于「模式」曰『正则』于「路径」曰『.』于「限」曰「列」【『*。豫』】于「宽」曰「二六零」于「式」曰『计数』与「寻文字详」（签同「寻详」，惟依字面之文而搜）多带数签：`限` 为卷名通配之列（可多，空列不限，同 `grep --include`），`宽` 大于零则每行截其前若干字（依字数不依字节，同 `cut -c`），`式` 为出式：`行`（默，印“径:行号:行”）、`只列`（惟印含配之卷名，同 `grep -l`）、`计数`（依卷印“次数<TAB>径”，多者先，同 `grep -c` 而复排之）、`反向`（印不配之行，同 `grep -v`）、`只取`（每配印“径:行号:配”，同 `grep -o`）、`当文`（并二进制之卷当文搜之，命中行如 `行` 式，控制字节书为 `\xNN`，同 `grep -a`），`前`、`后` 为每处前后各印几行（可省，缺则零，同 `grep -B`、`-A`，惟于 `行`、`反向` 二式有用）：命中书“径:行号:行”，上下文书“径-行号-行”，段与段之间（含二卷之间）印“--”一行。二进制之卷（首八千字节有零字节）不用 `当文` 者，有配则惟印“二进制文件 径 有匹配”一行（同 `grep`），无配乃为未得；`计数` 如常计数、`只列` 如常列名。「寻」亦有同样之 `前`、`后` 二签。「寻得」于「模式」曰『正则』于「路径」曰『.』于「限」曰「列」【『*。豫』】为有返值之搜索，还（径、号、行）之列，可付「择」再筛、复以「遍」缀为文；上下惟于印上下文时出，命中列中不含上下文行。「读行宽」于「文件」曰『卷.txt』于「起」曰「一」于「止」曰「八零」于「宽」曰「二六零」为带截宽之读行；无选之时仍用「寻」「寻文字」「读行」。

结绳读取之命（二〇二六年十月二十二日，议题三百八）：「解结」于「文件」曰『卡.json「：』：」于「径」曰『.a.b[0「：』：」读结绳之卷，取径所指之值，串印原文，余印结绳之文（同 jq -r）；径依 jq 之式，点取栏，方括取下标（自零数，负者自末），首点可省。「遍解」于「文件」曰「列」【『甲.json「：』：」，『卡录「：』：」】于「径」曰『.a「：』：」逐卷印“文件<TAB>值”，文件之列可为卷或目，目依可省之「限」通配展之（缺省 *，假开发之器之找文件，与寻卷同一通配之法）。「列栏」于「文件」曰『卡.json「：』：」一行一个印其物之栏（同 jq keys）。「择结」于「文件」曰「列」【『卡录「：』：」】于「径」曰『.isArchived「：』：」于「等」曰『阴「：』：」留其栏之值等于等者，一行一个印卷名，予可省之「取」则改印其栏之值（同 jq 之 select）；等书阳阴以较真假，余先依结绳之文析之（如 `true`、`"文字"`、`3`），析不得则为常串。卷无此栏者不选；卷不得读、文非结绳、径取不得则印“错误：…”而使此句败。

每命之法存于一可易之引（如「行实现」「列目实现」「壳出实现」），默依标准库：径相对进程之当径，环境为本会话之一表（「设」书之、「罢」去之），「行」用「使者」之「亲行」，有会话水土则并其俗、于林檎、林纳经 /usr/bin/env 而付子程（豫言操作系统与轩窗暂不传，待办：豫言未有带境且承三流同步起子程之能），建目用「东道」之「置箧」，删目用「东道」之「删箧」，递归删用「藏书」之「删树」。豫言操作系统中易以库 用户态桌面 之实现（诸命之模之登函，豫构交互之会话依 `部居` 分部按需而登），显示之设书于已授“桌面”根之设置库；脚本、图形与退出由壳登之。显示之设之默实现告本境无桌面之设；系统中由 豫构 所行之 `。脚本。豫` 亦得此告，接设置库待后续之版。「辑壳出」于一段动作之时集其出为文，供桌面命令行书于窗。
