# 壳核心

这是控制台壳与图形命令行共用的普通豫言库，只依赖标准库。现有裸机壳的命令位置、命令登记、命令补全、智能候选、拼音输入及字库移入本包，使用同一份实现。

命令位置解析保留引号内的连接词，登记定义正式成员与参数，候选先匹配当前上下文的已知名称，没有匹配时回退普通全拼字词。拼音输入仍使用原有会话引用状态，后续将编辑与组字状态整理为显式会话，不在此次迁移改变行为。

本包不执行文件或进程操作，不取得显示面，不直接调用内核或设备。编辑行的控制台重画、文件及进程服务仍留在调用方；旧拼音模块仍含候选和模式切换的控制台提示，后续须与组字状态处理分开供 GUI 使用。拼音、智能候选按模块导入，总集导出命令登记与位置解析。

测试在 `测试/`，由原壳的三个测试移入，覆盖位置解析、命令登记与上下文候选。原壳的交互编辑及上下文输入测试继续覆盖控制台接入；迁移后须重新构建运行。
