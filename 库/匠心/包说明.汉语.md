# 设计

三维材质的「透明阈值」支持透明遮罩：负值关闭，其他值按基色贴图透明通道比较，达到阈值的像素参与着色和深度写入。透明采样遵守贴图的横纵延展和近采配置，采用最近像素或双线性插值。无贴图时透明度取一；导入方可以将基色透明因子折入阈值。「混色」启用逐三角形远近排序与线性光源覆盖混合，「显度」乘基色贴图透明度，混合时保留原深度并累计输出透明度。阴影遮罩留待后续版本。

传景导入支持 `COLOR_0` 顶点颜色的红绿蓝分量，沿用访问器的浮点与规范化整数解码。三维渲染在近平面裁剪后进行透视校正颜色插值，并在线性光空间乘入材质基色；缺省顶色为白色。透明分量随透明材质路径留待后续版本。

骨骼蒙皮、传景动画、面板与空间声音已补测（2026-10-20）。测试 `骨骼` 拼两节骨骼的条带与绕横轴九十度的四元数动画，核对静止姿势等于原网格、零点五秒下两顶绕第二节转四十五度、法线随逆转置变换、一秒转满九十，并核批量蒙皮；`变形目标` 拼单三角加位置变形目标与权重线性动画，核对权重一半与满值的顶点位置及节点权重写回；`传景动画` 拼九个节点通道，覆盖平移、缩放、旋转三类与阶梯、线性、三次样条三种插值，核对取样值、写回姿态与越界空列；`面板` 把左朱右蓝的二维插画经快照面板贴到立起的三维平面上，在三维视口里核对颜色与投影位置；`空间声音` 核对右侧响应的右耳电平与到达先后、两次卷积一致，以及对象音频右声道有声、左声道为零、两次渲染一致。官方样例 RiggedSimple、RiggedFigure、CesiumMan、Fox、AnimatedMorphCube、BoxAnimated、MorphPrimitivesTest、SimpleSkin 与 Box、Duck 等的渲染图见远端副本 `样例图/`。

设计命令支持「设渲染后端」与「渲染后端」查询，配置供播放器逐帧读取。播放器公布声音设备时钟快照，播放状态查询和暂停采用同一时刻；快照状态键或时间戳失效时采用原有状态墙钟。

设计语言的引擎库（[提案 00018](../../提案/00018-设计语言与引擎.汉语.md)）。设计源文件 `名。设计。豫` 写 `寻观「匠心」之书。`，用构造写法（`「头」【项，…】`，提案 00018 议十九）写作品；作品是普通豫言值，由这个库求值、渲染。

设计树码的字节布局、签表、验证规则、能力与代价、确定性规则与还原约定，见[《设计树码格式》](文档/设计树码格式.汉语.md)。

## 声明结构

编译器在普通用户组件函数体内记录组件定义和实例，普通调用与构造调用共用此处理。当前参数保存整数、小数、字符串、爻、小数信号和字符串信号的实际值；局部变量和简单算式在求值后保存。反编译输出普通函数签名、函数体和调用，常量信号与关键帧信号可以再次编译得到相同设计文件。`组件值源` 提供与设计还原一致的值和信号表示。泛型、闭包参数与同名跨模块组件列为后续版本事项。

文档源的顶层「作品」保存完整模块规范源码，文章和论文作品用已有「文档源码」声明携带文档构造、版式和编号上下文。反编译恢复完整普通文档源码，再编译重新运行组件与分页。文档组件保存入口依赖文档模型的「文档组件保存」。

「声明」构造保存种类、名称、源码与展开画面；「组件」「挂样式」分别保存组件与挂载样式的声明。设计树码的节点标签八存储这些字段，求值、声音和文字查询沿展开画面运行，还原输出对应声明构造。测试 `测试/声明。测试。豫` 核对声明保留与二进制往返。

「组件定义」保存名称与定义源码，「组件例」保存定义、实参文字列和编译期已求出的展开缓存；「组件实参」构造实参列。「组件」构造生成无实参的组件实例。树码标签九首次写入定义，标签十引用当前文件已写的定义序号，同一名称与源码只写一份。读写器各有独立定义表，读取越界引用会报错。还原输出「组件定义」「组件例」「组件实参」，再编码保留原定义引用关系；渲染、素材、声音和能力沿展开缓存计算。测试 `测试/组件。测试。豫` 核对两种实参共用一份定义、往返、还原、展开画面和非法引用。
## 文档与排版

论文版面照泰赫（ctexart，十一点字）稿排：竖向位置用泰赫的基线距与块间距，每块给出行距、前距、后距与栏首第一条基线的偏移，相邻两块的间隔取前距与后距中较大者；正文基线距二十二点零六（`常论文版式` 的「行距」二点零零五五，即泰赫稿写的十七点零五乘 ctex 的一点三行距），标题十四点字、基线距二十五点九、前距十二点、后距六点（版式的「标题字号」「标题行距」「标题前距」「标题后距」，对应 `\ctexset` 的 section 设置）。页眉下带线，页脚居中；脚注九点字、上方带短线、号用上标，正文里的脚注号同样上标。摘要后的“关键词：”标签加粗；定理写成“定理 1.1 (名称).”加粗，后接斜体正文（版式的「强调字体」给了楷体就用楷体，没给就把默认字体错切合成斜体）；证明的“证明.”用斜体，末行右端画空心方框。公式里单个拉丁字母与小写希腊字母斜排，数字、运算符与大写希腊字母直立，关系符号两侧空千分之二百七十八，二元运算符两侧空千分之二百二十二。三线表按内容取自然宽度（列内最宽的格加两侧各六点）在版心居中，表题在表上居中，写成“表 1: 题注”。目录顶层条目加粗、编号占一点五字宽、页码右对齐（同泰赫 ctex 没有引导点，版式的「目录引导点」设阳可加上）；二级以下条目不加粗并缩进，标题后用引导点连到右对齐的页码；索引条目词在左（首行缩进）、页码右对齐、中间用引导点。标题与其后至少两行正文同页。样例 `样例/论文。设计。豫` 与同内容泰赫稿 `样例/论文对照.tex` 并排比较，各行基线相差不到一点。

版式的「栏数」默认一，「栏距」默认二十点，正文依次流入各栏；「孤行」「寡行」默认两行，普通正文按阈值选择转栏或转页。陈列公式以真实公式盒升降占高，插图下方预留题注升距。文档组件保存定义、实参及展开块，编号与分页沿展开块进行，各页场景保留组件实例。

`篇位图` 把图像显示项写为便携文档内联真色像素，保持显示仿射的位置、尺寸与旋转。常用泰赫插图可与文字轮廓一起导出；透明像素按论文纸白合成，软遮罩属于后续版本事项。

泰赫常用图表导入支持 `table` 内的 `tabular`、`l/c/r` 列对齐、`&` 单元格与 `\\` 行尾；读取 `caption`、`label`，第一行为表头。`figure` 内的 `includegraphics` 从当前目录读取图像，按原比例适配三百点方框，写进设计作品的素材。`$…$` 生成行内公式。

`篇随行` 将含强调、加粗、行内公式的段按字元实际宽度流排。强调使用版式的强调字体并倾斜，加粗叠绘轮廓；行内公式复用公式排版的上下标、分数与根号字形，按组件缩放与普通文字共排行。

`「书籍」【…】` 复用论文的分页、章节、目录与索引组件，版式可给出纸张与页边。`篇表格` 按单元格内容分配列宽，整表适应栏宽；长格换行后行高与表线同步延伸，按「对齐」的左、中、右逐列排字；表题与表体同页。

`文献格式` 按参考文献组件的格式选择输出。默认国标基本格式覆盖顺序编号、作者、题名、文献类型代码、出处、年、卷期页与网址；中文类别映射为标准代码，条目按首次引用编号排序。脚注随正文标记所在行登记，在当前栏底排放；长注拆行续栏或续页，后续栏先接续注，文末排尽余注。图表与题注成组；当前页空间不足时排到下一页页首，后续正文继续利用当前页。

`篇模型` 提供文档、版式、段、节、摘要、强调、列表、公式、定理、证明、插图、表格、脚注、参照、引用、目录、索引与参考文献构造。`篇号` 按结构顺序填编号、标签及引用次序。文档组件写法可导入 `「匠心」之「篇模型」` 与 `「匠心」之「篇排版」`；`「论文」【…】` 直接得到设计作品。

`「排成分页」于稿` 得到排版文档；`「作连续」于排` 重新流排同一原稿；`「篇作品」于排` 得到设计作品。分页复用精排最优断行、禁则及字形轮廓，正文逐行转页，图形和陈列公式按块转页。版式决定纸张、页边、字号、行距、正文首行缩进及字体。题名居中、章节分层、公式居中右编序，脚注在页底，页眉页脚保留页序。目录与索引页码按页面定位求不动点。

`篇网` 把文档值导出成静态网页与共用样式表，供 docs 站使用：`「篇作网标」于稿于头` 出整页（文档类型、语言、题名、描述、规范网址、`zh-Hans` 与 `lzh` 两条 hreflang、共用样式表链接与正文），`「篇作网标身」于稿` 出主体片段。节按级别出 `h1` 至 `h6`（编号在题前，有号者带锚），段出 `p`，列出 `ul` 与 `ol`，三线表出 `table` 与表头 `th`（按内容取宽，窄屏在横向滚动的框里），插图出 `figure` 与内联可缩放矢量（在零时刻求值，把图形与文字轮廓写成 `polygon`，图像元编成便图、缩成卦文放进内联 `image` 的数据网址），陈列公式按正文字体排成字形轮廓、写成内联可缩放矢量（每个字形一条 `path`，按版式字号缩放），脚注集中到文末并带回链，参照、引用与链接出 `a`，目录按层级嵌成嵌套的 `ol`、索引带锚，参考文献按引用号排。一切文字与属性都经网页转义，产物只有文字、标签与样式。`「常篇装帧」于「元」` 出共用样式表 `共用/装帧.css`：纸墨朱三色、题字码三体，浅色与深色随系统（`prefers-color-scheme`），窄屏与打印各有样式。`「查网标」于「文件」曰…于「其文」曰…` 逐行核对脚本元素、内联事件属性、`javascript:` 网址、内嵌框架、内嵌对象、内嵌内容与 `meta` 刷新，报出文件、行与列；`「查目录树」于文件们` 报出 `.js`、`.mjs` 与 `.wasm` 文件；`「述网标犯」` 把一处违规写成一行文字。测试在 `测试/网标导出。测试。豫`。

`篇站` 把一列站页写成 docs 站的整棵目录：站页记录原路径、标题、描述、文档与是否文言页，`「写整站」于「根」曰…于「页们」曰…` 写前清空目标目录，每页写成 `径/index.html`（根径写 `index.html`，文言页在 `/文言/` 下），另写 `共用/装帧.css`、`sitemap.xml`、`robots.txt` 与 `404.html`，最后巡一遍整棵树并返回违规列。每页的规范网址是它自己的路径（文言页指 `/文言/` 下那一页），`hreflang` 两条互指；站点地图每页一条 `url`，`loc` 是该语言版的规范网址，另带 `xhtml:link` 的 `zh-Hans` 与 `lzh` 两条互指，汉字路径不做百分号编码；`robots.txt` 放行全部并写站点地图地址；`404.html` 带题、共用装帧与回首页的链接。`「站验」于「根」曰…` 对已写好的整棵树跑网页与目录树两个守卫，`「站须净」于违列` 在违列为空时印一行、否则报错中止，生成程序据此以非零退出拦下发布。文件读写走豫章的文件接口（`东道` 之「置箧」「著」「焚」「阅」与「列目」），不起宿主命令。测试在 `测试/整站导出。测试。豫`，写到 `/tmp/钩篇出网-站/`。

`篇引` 的 `「标记文作品」于「标题」为题于「源」为文` 直接生成连续设计作品；标记文标题、列表、引用、围栏与正文复用标记文库分类。`「引梓篇」于文` 支持文档类、题名作者、章节、公式环境、定理证明、摘要、参考文献、行内参照、引用、强调与脚注。`「引为匠心」于「文件」为路径于「输出」为源路径` 支持 `.md` 与 `.tex`，生成设计源码。

`篇出` 的 `「篇便携数据」于排` 与 `「匠心作品便携数据」于作` 复用显示表输出便携文档页面树，纯色图形与图像照旧成为矢量与位图，文字按所用字体的子集写成真正的文字：字体程序、CID 字体、宽度与 ToUnicode 映射（同文映射）一并嵌入，刻本里的文字能选中、搜索与复制。字体文件缺失，或排法与字形不符（加粗叠绘、斜体错切、中西文间距等），该处退回字形轮廓，画面不变。`「篇便携数据尺」于排于「宽点」曰…于「高点」曰…` 按点尺寸出页面，设计单位是点；`「篇便携数据实尺」于排于「宽毫米」曰…于「高毫米」曰…` 按毫米幅面出页面（一毫米等于 72/25.4 点），页面 mediabox 保留小数，供「规矩」按幅面的毫米尺寸直接调用。`「篇便携数据多页」于「幅们」` 接收一列多页幅面（作品、毫米宽高与书签题），各页按自己的毫米出页面、各页大小可以不同，书签题平铺成一层，供「规矩」的多页刻本调用。`「匠心图样便携数据」于作` 见作品里的实尺页：每页按页宽页高出一页，多张实尺页成多页刻本；没有实尺页时照旧按画幅出一页。「出刻本」命令走这一条。`「实尺页映表」于页于「每毫米像素数」曰…` 按给定每毫米像素数把一页画成显示表，`「实尺页像素」` 给出像素宽高，供推演与渲染帧；`「去实尺」于页于「每毫米设计单位」曰…` 把实尺页按比例换成普通组节点，能力里的实尺降为无，供图样嵌进文档、幻灯或界面。字形段按字体路径与字形号缓存（`「排段」`），同一字形只排一次。统一壳命令 `「出刻本」于「文件」曰『论文。设计』于「输出」曰『论文.pdf』` 输出设计文件各页（有实尺页时按页的毫米出）；宿主命令是 `豫构 设计 便携文档 文件 输出`。论文样例与文档测试位于 `样例/论文内容。豫`、`样例/论文。设计。豫` 与 `测试/文档。测试。豫`，刻本测试位于 `测试/刻本。测试。豫`。

段落正文与给定宽度的字幕共用中文标点半字身挤压、中西文四分之一字号间距及禁则。起首标点同步调整轮廓位置；断行宽度与最终字形位置计算使用相同间距，换行处保持两边独立。

数学串支持矩阵、圆方花括、单双竖界、分段、对齐、聚集与小矩阵环境；嵌套环境各自保持行列边界，尾随公式继续排放。根式支持根指数，正体、上下划线、常用函数名和显式间距复用公式盒；上下标按数学字体的斜体修正及两侧隅隙定位。定界依内部高度选择字体成形变体，超过最大成形变体时同比放大，字形部件组装留待后续版本。

便携文档将编号表中能够定位的标题按文档顺序导出为中文书签，书签指向标题所在页面。

后续版本事项：字体子集与文字检索、便携文档链接与图层效果；跨页浮动体优化、带行内样式段落的孤寡行控制、分栏平衡；首行与后续行分别使用完整宽度；复杂泰赫宏、跨行命令与复杂图表导入。

标记文正文、列表与引用支持强调、加粗、链接和行内公式，反引号保留代码字面，反斜杠还原转义标点。西文整词与中文相属片段整体断行；软连字符平时零宽，开启英语断词时在实际断行处绘制连字符。

寻观 `「匠心」之「泰赫导出」` 后，`「泰赫文稿」于稿` 生成完整泰赫源码字符串，`「著泰赫文稿」于稿于路径` 写出文稿与伴随插图便携文档。导出递归处理现有文档块和行内节点，转义正文字符，统一编码标签与引用，保留公式、目录、索引、文献与图表结构。字符串入口使用插图文件名，文件入口将实际插图写到文稿旁并引用绝对路径。

标记文导入略过前置元数据，网页块复用超文本标记词法抽取标题和正文，样式与脚本单独略过。官网以网页布局静态编译通路保存其原生超文本块的完整布局；文档通路适合连续阅读正文。

颜色关键帧与信号混合的红绿蓝通道按标准传递曲线解码到线性光空间，插值后编码回八位色阶；透明通道直接线性插值。标准传递曲线的小数次幂用整数乘法与固定轮数二分开方实现，各后端共用同一份算法。

## 帧图像输出

渲染帧按输出文件的小写后缀写出 PNG、QOI、BMP、TGA、PAM、PPM、WebP。帧序列的前缀也可以包含这些后缀，例如前缀 `画面.webp` 生成 `画面0001.webp`；普通前缀生成 `前缀0001.png`。PPM 使用三色像素，其余格式由各自编码器处理透明度。

## 三维传景扩展

传景模型的材质导入、部件保存与求值统一传递自发光因子及贴图、金粗贴图、遮蔽贴图与强度、法线贴图与强度。金粗图的绿道乘粗糙度，蓝道乘金属度；遮蔽图的红道只衰减环境光；自发光在线性光中叠加。法线贴图按世界三角边和纹理坐标构造切线基，支持镜像纹理坐标。双面材质生成反序、反法线的背面三角；透明遮罩在着色和深度写入前按材质阈值裁弃。

基础颜色贴图的采样器支持重复、镜像重复与夹边，并支持最近邻和双线性过滤。每物体预建渐远层链，按投影三角与纹理面积选择细节层。文本传景支持多个外部文件或数据网址缓冲的四字节对齐归并，外图文件名支持百分号转义。二进传景按块头寻找二进缓冲并跳过扩展块；缺少场景表时寻找根节点，缺少节点表时逐网格读取。

骨骼支持两套关节编号及权重，合并后统一归一化。传景动画支持阶梯、线性与三次样条，覆盖平移、缩放、旋转和变形权重；旋转采样归一化四元数。模块「传景相机」的「渲染传景画面」直接读取透视相机与模型并生成像素，负节点编号沿默认场景深度优先选择首个相机，透传材质采样配置、混色与显度；模块「传景灯光」的「渲染传景灯景」把节点灯光扩展接入现有画面渲染。自发光因子乘自发光强度扩展，缺省强度为一。快照面板的源码还原入口自动导出内嵌图像或模型素材，同内容文件复用，异内容文件递增命名。

## 粒子与布料

粒子模块（第五期第五步）用 `造粒子系统` 造初始系统，发射器由 `粒子发射器` 记录给出位置、形状（`点形`、`圆盘形`、`盒形`、`球形`）、每秒速率与一次喷发；力由 `粒子力` 记录给出重力、风、阻力、涡旋中心与轴与强度、旋度噪声的强度频率种子；碰撞平面由 `粒子平面` 记录给出单位法线、到原点的有符号距离与反弹系数。`推进粒子系统` 按一千二百分之一秒的整数步推进，`粒子快照列` 每隔给定步数存一份快照，`画粒子图` 把粒子列画成红绿蓝透明八位像素的圆点图。画图时把粒子的横与纵当作像素坐标，纵向上，翻到画布纵向下。

布料模块（第五期第五步）用 `造布` 造一块宽乘高的方格布：结构约束连右邻与下邻，剪切约束连两对角，弯曲约束连隔一个的邻点，各带静止长度与刚度；`固定们` 给出不动的质点序号。`布世界` 记录给出重力、风、阻尼、每步约束迭代数与平面、球碰撞列。`推进布` 按同样的整数步推进，`布快照列` 定期存快照，`布网` 输出 `三维三角` 的列，位置、法线与纹理坐标齐备，直接作 `三维物体` 的三角形们交给「渲染三维画面」。

两个模块的发射随机量与积分只用整数步与匠心自己的确定性数学，同参同种两次模拟逐位相同，任一时刻的状态等于从零推进到该时刻。测试见 `测试/粒子。测试。豫` 与 `测试/布料。测试。豫`。设计语言的「粒子」「布料」构造、设计树码、还原与能力登记留待下一轮统一接。

`藏光` 首次用到时造一张六万五千五百三十六字节的速查表，以光强乘六五五三五取整作下标，与原来的界表二分逐位相同，省去每像素八次小数比较；越界光强仍依公式算。
