# 设计树码格式

设计树码（设计作品之二进格式）者，库「匠心」（设计引擎库）之公开交换格式也。设计之源 `名。设计。豫` 经 `豫构`（构建工具）之 `设计 编译` 之命编为 `名。设计`；播放之器、渲染之机、检查之具与独立之实现，皆依本篇以书读此格式。

本篇以今之代码为准，逐段书其字节之序、签表、书读之法、验者之规与诸上限，并注其所据之源与函数。末节「一致之验」列独立实现可逐条核者。

## 一、总则

### 外框

设计树码沿树码（提案 00001 之统一二进表示）之魔数、版本与种类三事为外框：

- 魔数为原字节 `树码`，六字节，其前不书长度。
- 树码版本为自然之数，今为二。
- 种类为文 `设计`。

其后书三十二字节之结构摘要与设计格式之版，乃书设计之头、段表与诸段。

| 事 | 容 |
| --- | --- |
| 源卷 | `名。设计。豫` |
| 二进卷 | `名。设计` |

### 版与相容

| 事 | 今值 | 不合之时 |
| --- | --- | --- |
| 树码版本 | 二 | 拒放：`设计树码验证不过：树码版本不认识` |
| 种类 | `设计` | 拒放：`设计树码验证不过：树码种类不是设计：…` |
| 结构摘要 | 三十二字节，见「结构摘要」一节 | 拒放：`设计树码验证不过：结构摘要` |
| 设计格式之版 | 三 | 拒放：`设计树码验证不过：设计格式版本不认识` |

相容之规：

- 结构摘要取结构之说之沙二五六，该说括节点之种、域之序与其义。结构一易，则易其摘并易其版。
- 新于设计格式之版者，其域唯见于新版；旧读器依本版之定序而读，遇不识之版即拒放。
- 本版之读器兼识格式三与格式二：格式二之三维视口止于三维项之列，读为光栅与十六；结构之摘亦兼识结构十五与结构十四。摘与版各自独立核之。
- 播放器之能低于作品之能时，依 `「诸超出之轴」` 之果拒放，并报所超之轴与其级。
- 新事入新之能级、新之可选段或新之格式版；本版之可选段，其长恒为零。
- 本版以拒放处不识之版与逾出之能，并于讯中报其故；降格之映，俟后之版。

### 结构摘要

结构摘要取结构说之文之 SHA-256，凡三十二字节，原样书之。今之说曰：

> 设计树码结构十五：组件定义表与实例缓存；合成节点：六仿射信号、透明信号、模糊信号、二十色阵信号、子节点；含结构十四；三维视口末尾加渲染器与采样数。

说中之十五与十四，皆结构修之序；修一易，则摘随之而易。

摘要与设计格式之版相配而更：摘易则版亦易，版易则摘亦易。摘与版皆书于读器之中，读时逐项比之。本版之读器兼识结构十五与结构十四二摘，亦兼识格式三与格式二；摘与版各自独立核之。

### 轨表

轨表者，使播放之器未读结构段而先知作品之轨。其第一项定为画面之轨：

| 轨 | 种号 | 语 |
| --- | --- | --- |
| 画面之轨 | 零 | 空文 |
| 声轨 | 一 | 空文 |
| 文字之轨 | 二加文字轨之种号（二至五） | 轨之语，如 `汉语` |
| 事轨 | 六 | 空文 |

文字轨之种号：零字幕、一说明字幕、二章节、三口述影像。轨表之项由 `「附轨表项」` 成；读器以轨表原样藏于文件头，供 `设计 信息` 书之。

段之名以文，其长以自然之数，长计该段之全字节，含段内自具之长度或个数前缀。本版书四段，其序有定：

| 段名 | 容 |
| --- | --- |
| `结构段` | 作品之骨、节点、信号与轨 |
| `素材块` | 图像、声音、字形与传景（glTF 场景）模型之原字节 |
| `跳转索引` | 时刻与素材块内之偏 |

## 四、基本之书

### 整数

无号之变长整数（自然之数），每字七位，其高位示后尚有字。书时取最短之码：小于一二八者书一字，否则先书其低七位而置高位为一，次书其余之高。

有号之整数（数），先以之字形映之，乃书为自然之数：

- 非负之数 `n` 映为 `2n`。
- 负之数 `n` 映为 `2(−n) − 1`。

读器依反方而复之。变长之整数至多十字（七十位）；第十字仍求续读时，报 `设计树码损坏：变长整数过长`。读器容非最短之码；书者一律用最短之码。

### 小数

小数依八字之 IEEE 754 双精度位形书之，其字节之次为小端：先书最低之八位，终书最高之八位。负零、次正规之数、无穷与非数，皆依位形原样书读。

### 文与帛

- 文：先书 UTF-8 之字节数（自然），次书其字节。读器察 UTF-8 首字与续字之形，形不合则报 `设计树码损坏：字符串不是合法的 UTF-8`；其察之所及，限于首字与续字之形。
- 帛：先书字节之数（自然），次书原始之字节，其容不释。
- 原字节：径书所予之字节，其长由上下文而定；唯魔数、结构摘要与已由段长所限之收缩之文用之。

### 爻、坐标、色与仿射

| 类 | 书 |
| --- | --- |
| 爻 | 一字：零为阴，一为阳；他值报 `设计树码损坏：爻值不认识` |
| 坐标 | 横、纵二小数 |
| 色 | 红、绿、蓝、透明四字节，各取低八位 |
| 仿射 | 甲、乙、丙、丁、戊、己六小数 |

### 列与其数

列者，先书其项数（自然），次第书之。读器须项数不逾所余之字节数（每项至少一字），否则报 `设计树码损坏：个数超过剩余字节`。零项之列，唯书一零字。

### 签与签之误

和类（节点、信号、颜料、缓动等）先书一字之签，次书该签之诸域。读器遇未定之签，即报：

```
设计树码损坏：<种类>标签不认识：<签号>
```

种之名，读器所予之定文，如 `节点`、`信号`、`颜料`、`缓动`、`几何`、`线帽`、`混合模式`、`渐变形`、`渐变延展`、`振荡波形`、`文字轨种类`、`声源`、`附轨`、`交互条件`、`三维项`、`三维网格`、`渲染器`、`文字对齐`、`排列对齐`、`作品种类`。

## 七、信号、关键帧与式之码

### 信号之签

| 签 | 信号 | 域 |
| --- | --- | --- |
| 零 | 常量之信号 | 值（依其类而书） |
| 一 | 关键帧之信号 | 全条之缓动、帧（列〈帧值〉） |
| 二 | 式之信号 | 原文（文，式之中间表示） |
| 三 | 叠加之信号 | 信们（列〈信号〉） |
| 四 | 混合之信号 | 分（列〈权（小数）、子（信号）〉） |
| 五 | 驱动之信号 | 源（小数之信号）、原文（文） |
| 六 | 噪声之信号 | 种（数）、频（小数）、下界（值）、上界（值） |

帧值（`「帧值」`）之序：时（数，刻）、值（依其类而书）、帧之缓动。帧依时刻之先后书之。

诸值之类，共用一套信号之签：小数之信号书小数，坐标之信号书坐标，颜料之信号书颜料，文之信号书文。关键帧、叠加、混合、驱动与沿径，依其值之类逐层书之。

### 关键帧之求

- 首帧之前，取首帧之值；末帧之后，取末帧之值。
- 二帧之间，依前帧之缓动而插；前帧之缓动为「沿用」者，依全条信号之缓动。
- 保持之缓动，于段末之前取前帧之值，至段末乃跃至后帧。
- 色于标准传递之曲解后之线性光中插之，透明之道则直插。
- 曲之缓动（贝塞尔、弹簧）以定法求之，诸端如一；详见第十二节。

### 式之码

式之信号与驱动之信号，唯藏中间表示之原文；其类由编时豫言之类型之系以保。原文为以空格分之词流：

```
表达式码一 <函数个数>
<参数个数> <体>      每函数依次一
...
```

体依先序书一式，词流中每式如下：

| 式 | 词流 | 说 |
| --- | --- | --- |
| 整数之字 | `整 <整数>` | 十进，可带负号 |
| 小数之字 | `小 <位形>` | 六十四位之位形，读入后易为小数 |
| 爻之字 | `爻 <零或一>` | 一为阳 |
| 变 | `变 <序>` | de Bruijn 之序，末绑者为零 |
| 基本之算 | `算 <名> <参数数> <参数…>` | 名与参数数须合于算表 |
| 条件 | `若 <判> <是> <否>` | 三项 |
| 局部之绑 | `虑 <值> <体>` | 体中变零绑于值 |
| 函数之调 | `调 <函数序> <参数数> <实参…>` | 唯调前之函数 |
| 元组 | `组 <项数> <项…>` | 诸值并列 |
| 取元组之项 | `取 <序> <组式>` | 序自零起 |

算名与参数之数：

| 类 | 算 |
| --- | --- |
| 小数二元 | 小加、小减、小乘、小除、小等、小不等、小小于、小大于、小小等、小大等、小最小、小最大（各二） |
| 小数一元 | 小开方、小绝对、小负、小向上、小向下、小截断、小就近（各一） |
| 整数二元 | 整加、整减、整乘、整除、整余、整等、整不等、整大于、整小于、整小等、整大等、整最大、整最小、整位与、整位或、整位异或、整左移、整右移、整无右移（各二） |
| 整数一元 | 整绝对（一） |
| 数之易 | 整转小、小转整、小饱和转整（各一） |
| 逻辑 | 且（二）、或（二）、非（一） |

式之验规：

- 首必为 `表达式码一`，词流恰于诸函数体之后而终。
- 函数之数在一至一万之间。
- 变之序小于今之变数。
- 算名在算表之内，其参数数与表相合。
- 所调之函数序小于今之函数序，实参之数取自词流。

违其一，报 `表达式中间表示不合法：…`；读设计树码时亦行此验。读器所核者为函数之序与变之序；实参之数径取于词流，依 de Bruijn 之序入所调函数之境。

### 式之费

每算依权计费：开方十六；除、整除与整余八；小数乘与整数乘三；三数之易二；余之基本算一；字面与变各计一。条件之计，一加判之费加二支之较大者；局部之绑计一加值与体；调计一加所调函数体之费加诸实参；元组计一加诸项；取元组之项计一加组式。函数表中，所调者在先，入者居末，其费取入者之费。

### 字形之二进廓

字形素材之廓，每令一字：

| 字 | 令 | 其后 |
| --- | --- | --- |
| 零 | M（移） | 横差（数）、纵差（数） |
| 一 | L（连） | 横差（数）、纵差（数） |
| 二 | Z（合） | 无 |

横差与纵差，为对前点之整数差，以之字形之变长整数书之；起点为横零、纵零；坐标以千分之一字号为单位。读回时逐字还为 `M<x> <y> L<x> <y> … Z` 之文，与编前之廓文逐字相同。

### 收与去重

素材于编前收之：

- 图像节点：卷之字节，时刻取其所在片段实例链上起点之偏之和。
- 文字节点：每字形之廓字节，依字形出现之先后收之。
- 声轨之采样声源：卷之字节，时刻为轨之偏加采样之起；片段实例自带之声轨，依实例之起而偏。
- 三维视口之物体贴图与模：图像之字节与二进传景之字节，时刻同所在之节。

收之序：先画面树之深先之次，次顶层附轨之声源；图层于子节之前先收其遮；片段实例于子节之前先收自带之附轨；交互节点依诸态子节之次；三维视口依子项之次。同一之字节（逐字相同者）唯留一块，其时取最早者。

### 排

素材依初用之时，以升序排之；时相同者，守其收时之先后，以插入之排成之。排在「收与去重」一节去重之后；素材块之次、结构段中素材之序与跳转之索之次，皆以排定之次为准。

### 跳转之索与边下边播

跳转之索与素材块一一相应：第 `i` 项书第 `i` 块素材之初用之时与其于素材块内之偏。

- 结构段以起与长示之；素材块紧随其后；跳转之索紧随素材块。
- 始播（首帧）所需之字节：结构段之起加其长，再加第一块时刻大于零之素材之偏；诸素材之时皆不大于零时，加素材块之全长。
- 前缀读器所读之字节，可止于结构段之末；素材块中已至之块照常解之，未至者记为缺失之素材：空图留白、空声归静、空字形按无廓处之。

## 十二、定之规

### 时间

时间（`「时间」`）为六十四位之整数，以刻为单位；一秒为七亿零五百六十万刻，能为常用之帧率（二十四、二十五、三十、四十八、五十、六十、九十、一百、一百二十）与采样之率（八、十六、二十二点零五、二十四、三十二、四十四点一、四十八、八十八点二、九十六、一百九十二千赫）所整除。

卷中诸时刻之域，皆书刻之整数（数）。秒换刻者，四舍五入而取整；帧号换刻者，帧号乘每秒之刻数而除以帧率。片段实例之起、时长与定格，事与文字段之起止，关键帧之时，跳转之索之时，皆用此一单位。

### 数

- 整数与定点，全定。
- 小数唯用 IEEE 754 之加、减、乘、除与开方，就近舍入于偶数；禁融合之乘加与重排之合；存次正规之数。
- 非数之号与载荷，于比与书之前一律正之，观之无别。
- 小数转整数，一律饱和而取定果；整数转小数，就近舍入。
- 超越之函数（正弦、余弦、指数等），由库「数学」自为之，诸端共用一术。
- 式、噪声与弹簧之算，唯依所传之时、种与参。

### 关键帧与缓动

- 首帧之前取首帧，末帧之后取末帧。
- 二帧之间，依前帧之缓动而插；前帧之缓动为沿用时，依全条信号之缓动。
- 三次贝塞尔以定二十四次二分求横坐标之参，乃取其纵；诸端之位如一。
- 弹簧之缓动，于进度 `p` 处取 `1 − e^(−阻尼·p)·cos(2π·圈数·p)`，段末取一。
- 阶跃依步数分级，每级于始或末而跃；分段线性以诸值等距列于零至一之间。
- 色于线性光中插之，透明之道直插。

### 噪声与排

- 一维值噪声之整点之值，由种与序混成：唯用整数之乘与取余，中间之值不逾二之五十三次方；整点之间以 `3s² − 2s³` 平滑而插。
- 素材之排，用插入之排，时相同者守其收之次；同一作品于同一源码之下，其素材之次、其序与跳转之索全定。
- 组件之定义表，依书之先后而立，同名同源者唯居一项；读时依同一之规而复。

### 还原之定

还原（见第十三节）依定规择数、时与颜料之写法，同一作品二度还原得同一之源；素材之卷名，依今居已有之卷之字节比之，以中文之序递之，同一居之状得同一组之名。

- `库/匠心/信号。豫`：`「求信号」`、`「贝塞尔」`、`「弹簧」`、`「一维噪声」`、`「整点散列」`。

## 十三、还原之约

### 所出之形

`「还原作品源」于作品` 还 `名。设计。豫` 之源文。其顶层之构：

```
寻观「豫章」之书。
寻「豫章」之「本原」之「本术」之书。
寻观「匠心」之书。
（自动捕获组件之定义）
「作品」者
　（作品之构）
也。
```

构造之书写以全角之空格为缩，每层一全角之空格；名、属与子项，依构造调用之约而还之。

### 数、时与颜料

- 整数书为中文之数，负数前加 `负`。
- 小数书为中文之数而恒带 `点`；用十七位有效之数之精书，可原样读回。宿主予指数之书时，退为六位小数之定点之书；指数之书之还原，俟后之版。
- 时：零书 `「零秒」`；能整除一秒者书 `（「秒」于…）`；能整除一毫秒者书 `（「毫秒」于…）`；余者书 `（「刻」于…）`。
- 坐标书 `（「坐标」于…于…）`。
- 纯色书 `（「色码」于『#RRGGBB』）`，透明之分为二五五者书六位，余书八位。
- 渐变之颜料与图案之色，今书 `「透明色」`；渐变与图案之还原，俟后之版。
- 爻书 `「阳」` 或 `「阴」`。

### 常值之省

与常值同者省之，其余依构而还。常用之常值：

| 属 | 常值 |
| --- | --- |
| 位、偏 | 原点 |
| 旋、模糊、背景之糊、绕横、绕纵 | 零点零 |
| 缩、不透明度 | 一点零 |
| 填充 | 透明色 |
| 描边 | 线形为墨色，余形为透明色 |
| 线宽 | 负一点零（沿作品之线宽） |
| 字号 | 三十二点零 |
| 对齐 | 靠左 |
| 阴影之色 | 透明色 |
| 字体 | 空文（常字体） |
| 排列之间距 | 零点零 |
| 图层之色阵 | 空列 |
| 图层之透视 | 零点零 |
| 混合 | 正常 |
| 片段实例之起 | 零 |
| 实例之速 | 一点零 |
| 实例之循环 | 一 |
| 实例之往返、前保 | 阴 |
| 实例之定格 | 负一 |
| 实例之后保 | 阳 |
| 三维之位、旋 | 三维之原点 |
| 三维之缩 | 一点零 |
| 渲染器 | 光栅 |
| 采样数 | 十六 |
| 平行光之投影 | 阳 |

### 组件、声明与文档

- 自动捕获之组件定义，置于作品之前，依定义表之次而书；同名同源者唯书一份。
- 组件之实例，其定义之源码含 `自动捕获组件` 者，书为调 `（「名」实参…）`；余者书 `「组件实例」` 之构，内嵌 `「组件定义」`（名、源码）与 `「组件实参」`（实参之文之列），次书展开之子节。
- 声明节点书 `「声明」` 之构（种、名、源码与子节）。若作品之画面恰为一 `文档源码` 种之声明节点，`「还原作品源」` 径还其源文。

### 素材

- 图像节点之来源存之，源码书其原径。
- 三维物体之贴图与模之项，其来源为空者，书其字节于今居之 `还原素材<中文序号>.<后缀>`（图用 `.png`，模用 `.glb`），并于源码书其全径。
- 同字节之素材，复用同名之卷；同名而字节不同者，递其中文之序。
- 所出唯书磁盘之卷，作品之字节保持原样。

### 往返

一致之试，核「源 → 二进 → 源 → 二进」二度之进逐字节相同，并核还原之源含作品与实例之构。往返之成，以所用之特性皆在本节还原之域为断；渐变之颜料、图案之色、含 `』` 或换行之文与指数之小数，为后版之事。

## 十四、一致之验

独立之播放器或渲染机，可按下列逐条而核。每条皆举可直验之字节、值或行。

### 外框与段

1. 卷首六字节，为 `树码` 之 UTF-8 字节。
2. 魔数之后第一变长之整为二（树码之版）。
3. 次之文为 `设计`。
4. 次之三十二字节，与「结构摘要」一节之摘逐字相同；读器亦识旧之结构十四之摘。
5. 次之变长之整为三（设计格式之版）；读器亦识二。
6. 次恰有十变长之整，其序为时间、空间、声音、文字轨、输入、计算、素材、分页、精排、文档结构。
7. 次三变长之整，为每帧计算、每秒采样计算与内存之预算。
8. 次之有号变长之整为时长；二小数为画幅之宽高。
9. 轨表首项之种号为零、语为空文；文字轨之种号为二至五；声轨为一；事轨为六。
10. 段表恰四项，其名依次为 `结构段`、`素材块`、`跳转索引`、`可选段`；其长之和等于卷之余字节。
11. 结构段先书原长，次书原始收缩之流；解后之长等于原长。
12. 素材块先书块数，次逐块书长与字节。
13. 跳转之索项数等于素材块数，每项为时（有号）与素材块内之偏；其偏等于该块于素材块中之实起。
14. 可选段之长零。

### 结构与节点

15. 作品之骨依次为种、目标、画幅之宽、画幅之高、时长、背景、线宽、画面之列、附轨之列。
16. 每节点之签与域之序，合于第六节之表；节点之签在一二之内，未用之签拒之。
17. 组件之初见用签九书名与源码，引用用签一零书序；序小于已见之定义数；同名同源者唯居一项。
18. 文字节点之字形项，依次为素材之序、横、纵；排法之种为零至二；对齐为零至二。
19. 图层之域序为模糊、阴影、色阵、背景之糊、混合、绕横、绕纵、透视、遮、子节。
20. 交互节点之域序为名、初始、输入、过渡、态、日志；交互条件之签为零至五。
21. 三维视口之域序为名、变换、宽、高、相机、三维项、渲染器、采样数；三维项之签为零至五；网之签为零至二；渲染器之签为零至一。
22. 声源之签为零至二；附轨之签为零至二；波形之号为零至四。
23. 信号之签为零至八；关键帧之帧值为时、值、帧缓之序。
24. 缓动之签为零至九；颜料之签为零至二；渐变形之签为零至二；延展之签为零至三。
25. 所引之素材序小于素材块数，且其种与所引之处相合。

### 数与限

26. 变长之整至多十字；书者用最短之码。
27. 列之数不逾所余之字节；帛与文之长不逾所余之字节。
28. 变长之整中有号之数，用之字形之映；负之数 `n` 书为 `2(−n)−1`。
29. 小数为八字小端 IEEE 754 双精度之位形；负零与次正规之数依位而存。
30. 结构段之原长不逾二十亿字节；节点之总不逾一千万。
31. 球之细分在零至一千零二十四之间；合成节点之仿射六项、色阵二十项；三维视口之采样数在一至六五五三六之间。
32. 图层色阵之长零或二十，诸元与透视皆有限之小数，透视不小于零。
33. 画幅之宽高为有限之正数；时长为不小于负一之刻数；线宽为有限之小数。
34. 关键帧之帧时不减且至少一帧；混合之权、噪声之频与输入之缺省为有限之小数。
35. 式之函数数在一至一万之间；变之序小于变数；唯调前之函数；算名与参数数合于算表；无余之词；实参之数依词流而读。
36. 文件头之能覆作品之实能；预算三项不逾宿主之常限（每帧与每秒各一千亿，内存一万亿）。

### 能与费

37. 能之十轴，其序与级之名合于「能之轴与级」一节；能集之并为逐轴取大。
38. 节点之能合于「节点之能」一节；组、文字与图层依名与属而增其能；三维视口之渲染器为路径追踪者，增计算三。
39. 作品之能为画面与顶层附轨之并；时长大于零者加时间二。
40. 编时作品之能不逾目标之限（「目标之限」一节），逾则报误而列其轴与级。
41. 信号、节点、几何、样式、三维项与声源之费，合于「费之式」一节。
42. 每帧计算等于画面诸节点之费和；每秒采样计算等于四万八千乘附轨与节点声费之和；内存等于每帧计算乘二百五十六。

### 定与还原

43. 诸时刻之域皆以刻之整数书，一秒为七亿零五百六十万刻。
44. 关键帧之求，循首帧、末帧、前帧之缓动与沿用之规；贝塞尔定二十四次二分；弹簧依「关键帧与缓动」一节之式。
45. 噪声依种与整数之散列而求，其插为 `3s² − 2s³`。
46. 素材依初用之时升序而排，时相同者守其收之次；同一之字节唯存一块。
47. 还原之数、时、坐标与纯色之书，合于「数、时与颜料」一节；常值之省，合于「常值之省」一节；渲染器为光栅、采样数为十六者，省而不书。
48. 还原之组件、声明与文档源码，合于「组件、声明与文档」一节；内嵌素材之出与名，合于「素材」一节。
49. 「源 → 二进 → 源 → 二进」二度之进逐字节相同（所用之特性在「往返」一节之域内）。
50. 前缀读器能唯凭文件头与结构段而始播，未至之素材按缺失处之，首帧所需之字节等于「跳转之索与边下边播」一节之式。
