# 设计树码格式

设计树码（设计作品的二进制格式）是库「匠心」（设计引擎库）的公开交换格式。设计源文件 `名。设计。豫` 经 `豫构`（构建工具）的 `设计 编译` 命令编成 `名。设计`；播放器、渲染机、检查工具与独立实现都按本篇读写这一格式。

本篇以当前代码为准，逐段写出字节布局、标签表、编码规则、验证规则与全部上限，并注明依据的源文件与函数。篇末「一致性检查要点」列出独立实现可以逐条核对的条目。

## 一、总则

### 外框

设计树码沿用树码（提案 00001 的统一二进制表示）的魔数、版本与种类三段外框：

- 魔数是原始字节 `树码`（六个字节，不带长度）。
- 树码版本是自然数，当前为二。
- 种类是文字 `设计`。

随后写三十二字节结构摘要与设计格式版本，再写设计头、段表与各段。

### 文件

| 项 | 内容 |
| --- | --- |
| 源文件 | `名。设计。豫` |
| 二进制 | `名。设计` |
| 编码入口 | `「编匠心作品」于作品`、`「写匠心卷」于路径于作品` |
| 解码入口 | `「解匠心卷」于字节`、`「读匠心卷」于路径`、`「解匠心卷前缀」于前段字节` |
| 信息查询 | `「匠心讯文字」于路径于档`，即壳命令 `设计 信息` 的文字输出 |

### 字节与类型记号

本篇以下列记号写字段类型：

| 记号 | 编码 |
| --- | --- |
| 原〈甲〉 | 甲原样写出，不带长度 |
| 自然 | 无符号变长整数（见第四节） |
| 数 | 有符号变长整数，之字形（见第四节） |
| 小数 | 八字节 IEEE 754 双精度位型，小端 |
| 爻（布尔值） | 一字节，零为阴、一为阳 |
| 文 | 长度加 UTF-8 字节 |
| 帛 | 长度加原始字节 |
| 列〈甲〉 | 个数加甲项，逐项依次写出 |
| 列〈甲、乙〉 | 个数加各项；每项先甲后乙 |
| 坐标 | 横、纵两个小数 |
| 色 | 红、绿、蓝、透明四个字节 |
| 仿射（仿射变换） | 甲、乙、丙、丁、戊、己六个小数 |
| 信号〈甲〉 | 一字节签加该信号的各域 |
| 节点 | 一字节签加该节点的各域与子项 |

信号的值按值类型写出：小数信号写小数，坐标信号写坐标，颜料信号写颜料，文字信号写文。

### 版本与兼容

| 项 | 当前值 | 不符时 |
| --- | --- | --- |
| 树码版本 | 二 | 拒放：`设计树码验证不过：树码版本不认识` |
| 种类 | `设计` | 拒放：`设计树码验证不过：树码种类不是设计：…` |
| 结构摘要 | 三十二字节，见「结构摘要」一节 | 拒收：`设计树码损坏：结构摘要不符` |
| 设计格式版本 | 二 | 拒放：`设计树码验证不过：设计格式版本不认识` |

兼容规则：

- 结构摘要覆盖节点种类、字段次序与语义。结构一改，就换摘要并同时换设计格式版本。
- 设计格式版本之外的字段只出现在新版本；旧读器按本版本的固定布局读取，遇到版本号不认识即拒放。
- 播放器能力低于作品能力时，按 `「诸超出之轴」` 的结果拒放并报出超出的轴与等级。
- 新特性走新的能力等级、新的可选段或新的格式版本；本版本的可选段长度为零。
- 本版本以拒放处理不认识的版本与超出的能力，并在消息里报明原因；降格映射留待后续版本。

## 二、文件头与魔数、版本与兼容规则

### 文件头布局

文件头按下列次序连写，字段宽度由编码自身决定：

| 序 | 字段 | 类型 | 内容 |
| --- | --- | --- | --- |
| 一 | 魔数 | 原〈六字节〉 | `树码` 的 UTF-8 字节 |
| 二 | 树码版本 | 自然 | 二 |
| 三 | 种类 | 文 | `设计` |
| 四 | 结构摘要 | 原〈三十二字节〉 | 见「结构摘要」一节 |
| 五 | 设计格式版本 | 自然 | 二 |
| 六 | 能力等级 | 十个自然 | 次序：时间、空间、声音、文字轨、输入、计算、素材、分页、精排、文档结构 |
| 七 | 预算 | 三个自然 | 每帧计算、每秒采样计算、内存（字节） |
| 八 | 时长 | 数 | 作品的时长，单位刻；负一表示时长不限 |
| 九 | 画幅宽 | 小数 | 设计单位 |
| 十 | 画幅高 | 小数 | 设计单位 |
| 十一 | 轨表 | 列〈自然、文〉 | 每项为轨道种类号与语言 |
| 十二 | 段表 | 列〈文、自然〉 | 每项为段名与该段字节数 |

文件头之后紧接第一段。

### 结构摘要

结构摘要取结构说明文字的 SHA-256，共三十二字节，原样写出。当前说明文字是：

> 设计树码结构十四：组件定义表与实例缓存；合成节点：六仿射信号、透明信号、模糊信号、二十色阵信号、子节点；含结构十二。

说明文字里的十四与十二是结构修订的序号；结构修订一改，摘要随之更换。

摘要与设计格式版本成对更换：摘要变了，版本也换；版本变了，摘要也换。摘要与格式版本写在读器里，读时逐项比较。

### 轨表

轨表供播放器在解析结构段之前得知作品的轨。第一项固定为画面轨：

| 轨道 | 种类号 | 语言 |
| --- | --- | --- |
| 画面轨 | 零 | 空文 |
| 声轨 | 一 | 空文 |
| 文字轨 | 二加文字轨种类号（二至五） | 语言文字，如 `汉语` |
| 事件轨 | 六 | 空文 |

文字轨种类号：零字幕、一说明字幕、二章节、三口述影像。轨表项由 `「附轨表项」` 生成；读器把轨表原样存进文件头，供 `设计 信息` 打印。

### 段表

段名用文字，长度用自然数，长度计该段的全部字节（含段内自身的长度或个数前缀）。本版本写四段，次序固定：

| 段名 | 内容 |
| --- | --- |
| `结构段` | 作品骨架、节点、信号与轨 |
| `素材块` | 图像、声音、字形与传景（glTF 场景）模型的原始字节 |
| `跳转索引` | 时刻与素材块内偏移 |
| `可选段` | 本版本长度为零 |

完整读器要求段长之和等于文件头之后的剩余字节数；前缀读器允许剩余字节少于段长之和。首段必须是结构段。各段偏移由文件头长度与前面各段长度累加得到，文件头只存段名与段长。

## 三、各段的布局与顺序

### 总布局

```
文件头
结构段      （段表第一项）
素材块      （段表按名查找）
跳转索引    （段表按名查找）
可选段      （段表按名查找，本版本长度零）
```

段与段之间紧邻，总长等于文件头、结构段、素材块、跳转索引与可选段之和；完整性由文件头、段表与各段结构自身承担。

### 结构段

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| 原长 | 自然 | 压缩前的字节数 |
| 压缩数据 | 原〈段长减原长字段的字节数〉 | 原始收缩（原始 deflate，RFC 1951）流，压缩级别六 |

读器以原长为解压输出上限，要求解压状态成功且输出长度恰等于原长；不足或超出都报 `设计树码验证不过：结构段解压失败`。

### 素材块

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| 个数 | 自然 | 素材块数 |
| 各块 | 帛，重复个数次 | 每块的长度与原始字节 |

块的先后按首次用到的时刻排列（见第八节）。块内字节保持原文件字节：图像是图像文件原文，声音是声音文件原文，传景模型是二进传景原文；字形是 `字形` 二字加二进制轮廓。

### 跳转索引

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| 个数 | 自然 | 索引项数，与素材块数相同 |
| 各项 | 数、自然，重复个数次 | 首次用到的时刻（刻）；该块在素材块内的偏移（字节，自素材块首字节算，含个数前缀） |

写出时索引项数与素材块数相同；读器按项数读入。

偏移与素材块内的实际位置一一对应；读器用偏移与块长算出某时刻之前需要的字节，供边下边播使用。

### 可选段

本版本可选段长度恒为零，内容为空。读器按段表长度跳过可选段，不解释其中字节。可选段的内容、名字与长度规则留待后续版本。

## 四、基本编码

### 整数

无符号变长整数（自然数）每字节七位，最高位表示后面还有字节。写出时取最短编码：小于一二八的数写一个字节，否则先写低七位并把最高位置一，再写余下的高位部分。

有符号整数（数）先之字形映射再写自然数：

- 非负数 `n` 映射为 `2n`。
- 负数 `n` 映射为 `2(−n) − 1`。

读器按相反方向还原。变长整数最多十个字节（七十位）；第十个字节仍要求续读时报 `设计树码损坏：变长整数过长`。读器接受非最短编码；写出方一律用最短编码。

### 小数

小数按八字节 IEEE 754 双精度位型写出，字节次序为小端：先写最低八位，最后写最高八位。负零、次正规数、无穷与非数都按位型原样读写。

### 文字与字节串

- 文字（文）：先写 UTF-8 字节数（自然数），再写这些字节。读器检查 UTF-8 的首字节与续字节形状，形状不合报 `设计树码损坏：字符串不是合法的 UTF-8`；形状检查的范围限于首字节与续字节。
- 字节串（帛）：先写字节数（自然数），再写原始字节，内容不解释。
- 原字节：直接写给定字节，长度由上下文给定；仅用于魔数、结构摘要与已由段长限定的压缩数据。

### 爻、坐标、色与仿射

| 类型 | 编码 |
| --- | --- |
| 爻 | 一字节：零为阴，一为阳；其他值报 `设计树码损坏：爻值不认识` |
| 坐标 | 横、纵两个小数 |
| 色 | 红、绿、蓝、透明四个字节，各取低八位 |
| 仿射 | 甲、乙、丙、丁、戊、己六个小数 |

### 列表与个数

列表（列）先写项数（自然数），再逐项写。读器要求项数不超过剩余字节数（每项至少一字节），否则报 `设计树码损坏：个数超过剩余字节`。零项列表只写一个零字节。

### 签与标签错

和类型（节点、信号、颜料、缓动等）先写一字节签，再写该签的各域。读器遇到未定义的签即报：

```
设计树码损坏：<种类>标签不认识：<签号>
```

种类名是读器给出的固定文字，如 `节点`、`信号`、`颜料`、`缓动`、`几何`、`线帽`、`混合模式`、`渐变形`、`渐变延展`、`振荡波形`、`文字轨种类`、`声源`、`附轨`、`交互条件`、`三维项`、`三维网格`、`文字对齐`、`排列对齐`、`作品种类`。

### 信号签号

| 签 | 信号 | 字段 |

| 零 | 常量信号 | 值（按值类型写） |

帧值（`「帧值」`）的次序：时（数，刻）、值（按值类型写）、帧缓动（缓动）。帧按时刻先后写。

各值类型共用同一套信号签：小数信号的值写小数，坐标信号写坐标，颜料信号写颜料，文字信号写文。关键帧、叠加、混合、驱动与沿路径按值的类型逐层写出。

### 关键帧的求值

- 第一帧之前取第一帧的值，最后一帧之后取最后一帧的值。
- 两帧之间按前一帧的缓动插值；前一帧的缓动为「沿用」时，按整条信号的缓动插值。
- 保持缓动在段末之前取前帧的值，段末跳到后帧。
- 颜色在标准传递曲线解码后的线性光空间插值，透明通道直接线性插值。
- 曲线缓动（贝塞尔、弹簧）以固定算法求值，各端一致；详见第十二节。

### 表达式码

表达式信号与驱动信号只存中间表示的原文，类型由编译期的豫言类型系统保证。原文是一段以空格分隔的词流：

```
表达式码一 <函数个数>
<参数个数> <体>      每个函数依序一个
...
```

体按先序写一个式子，词流中的每种式子如下：

| 式子 | 词流 | 说明 |
| --- | --- | --- |
| 整数字面量 | `整 <整数>` | 十进制，可带负号 |
| 小数字面量 | `小 <位型>` | 六十四位位型，读入后换成小数 |
| 爻字面量 | `爻 <零或一>` | 一为阳 |
| 变量 | `变 <序号>` | de Bruijn 序号，最后绑定的是零 |
| 基本运算 | `算 <名> <参数个数> <参数…>` | 名与参数个数须符合运算表 |
| 条件 | `若 <判别式> <成立> <不成立>` | 三项 |
| 局部绑定 | `虑 <值> <体>` | 体中变量零绑定到值 |
| 函数调用 | `调 <函数序号> <参数个数> <实参…>` | 只能调前面的函数 |
| 元组 | `组 <项数> <项…>` | 各值并列 |
| 取元组项 | `取 <序号> <组式>` | 序号从零起 |

运算名与参数个数：

| 类别 | 运算 |
| --- | --- |
| 小数二元 | 小加、小减、小乘、小除、小等、小不等、小小于、小大于、小小等、小大等、小最小、小最大（各二） |
| 小数一元 | 小开方、小绝对、小负、小向上、小向下、小截断、小就近（各一） |
| 整数二元 | 整加、整减、整乘、整除、整余、整等、整不等、整大于、整小于、整小等、整大等、整最大、整最小、整位与、整位或、整位异或、整左移、整右移、整无右移（各二） |
| 整数一元 | 整绝对（一） |
| 数值转换 | 整转小、小转整、小饱和转整（各一） |
| 逻辑 | 且（二）、或（二）、非（一） |

表达式的校验规则：

- 开头必须是 `表达式码一`，词流恰在各函数体之后结束。
- 函数个数在一到一万之间。
- 变量序号小于当前变量个数。
- 运算名在运算表内，参数个数与表中一致。
- 调用的函数序号小于当前函数序号，实参个数由词流给出。

违反任一条报 `表达式中间表示不合法：…`；读设计树码时同样走这套校验。读器的核对范围是函数序号与变量序号；实参个数直接取自词流，按 de Bruijn 次序进入被调函数的环境。

### 表达式代价

每个运算按权重计费：开方十六；除法、整除与整余八；小数乘与整数乘三；三种数值转换二；其余基本运算一；字面量与变量各计一。条件式计一加判别式加两个分支的较大者；局部绑定计一加值加体；调用计一加被调函数体代价加各实参；元组计一加各项；取元组项计一加组式。函数表里被调用的函数在前，入口函数在最后，代价取入口函数的代价。

| 二进传景模型 | 前四字节是 glTF 魔数 | 二进传景原文 | 模型部件（读入时解析） |
| 图像 | 其余字节 | 图像文件原文 | RGBA8 像素与尺寸 |

图像按图像编解码库认得的格式解码。声音按 `「解声素材」` 的六种格式解码。

### 字形的二进制轮廓

字形素材的轮廓二进制每条指令一字节：

| 字节 | 指令 | 后续 |
| --- | --- | --- |
| 零 | M（移到） | 横差（数）、纵差（数） |
| 一 | L（连线） | 横差（数）、纵差（数） |
| 二 | Z（闭合） | 无 |

横差与纵差是相对前一点的整数差，用之字形变长整数写出；起点是横零、纵零；坐标单位是千分之一字号。读回时逐字还原成 `M<x> <y> L<x> <y> … Z` 的文字，与编码前的轮廓文字逐字相同。

### 收集与去重

素材在编码前收集：

- 图像节点：文件字节，时刻取所在片段实例链上的起点偏移之和。
- 文字节点：每个字形的轮廓字节，按字形出现的先后收集。
- 声轨的采样声源：文件字节，时刻是轨道偏移加采样的起点；片段实例自带的声轨按实例起点偏移。
- 三维视口的物体贴图与模型：图像字节与二进传景字节，时刻同所在节点。

收集顺序：先画面树的深度优先次序，再顶层附轨的声源；图层在子节点之前先收集遮罩；片段实例在子节点之前先收集自带附轨；交互节点按各状态的子节点次序；三维视口按子项次序。同一份字节（逐字节相同）只留一块，时刻取最早的一个。

### 排序

素材按首次用到的时刻升序排列；时刻相同的保持收集时的先后，用插入排序实现。排序在「收集与去重」一节的去重之后进行，素材块的次序、结构段里的素材序号与跳转索引的次序都以排好的次序为准。

### 跳转索引与边下边播

跳转索引与素材块一一对应：第 `i` 项写第 `i` 块素材的首次用到时刻与它在素材块内的偏移。

- 结构段以起点与长度给出；素材块紧随其后；跳转索引紧随素材块。
- 首帧所需字节为：结构段起点加结构段长度，再加第一个时刻大于零的素材的偏移；所有素材的时刻都不大于零时加整个素材块的长度。
- 前缀读器读入的字节可以只到结构段末尾；素材块里已到的块照常解码，未到的记为缺失素材：空图像留白、空声音静音、空字形按无轮廓处理。
- 完整读器读入全部字节，素材块必须完整；块长超过剩余字节报 `设计树码损坏：个数超过剩余字节`，跳转索引在段长超出文件时为空。

声源每样本代价：采样十六加增益加声像；振荡六十四加频率加增益加声像；乐谱一百二十八乘音符数。附轨代价为各声源每样本代价之和，事件轨与文字轨计零；节点声代价递归合计片段实例自带的声轨。

预算三项：

| 项 | 公式 |
| --- | --- |
| 每帧计算 | 画面各节点代价之和 |
| 每秒采样计算 | 四万八千乘（顶层附轨代价加节点声代价） |
| 内存 | 每帧计算乘二百五十六 |

编码器把这三项写进文件头；读器把三项与宿主上限比较（文件头的检查一节）。

## 十二、确定性规则

### 时间

时间（`「时间」`）是六十四位整数，单位是刻；一秒为七亿零五百六十万刻，能被常用帧率（二十四、二十五、三十、四十八、五十、六十、九十、一百、一百二十）与采样率（八、十六、二十二点零五、二十四、三十二、四十四点一、四十八、八十八点二、九十六、一百九十二千赫）整除。

文件里的所有时刻字段都写刻的整数（数）。秒换刻按四舍五入取整；帧号换刻为帧号乘每秒刻数除以帧率。片段实例的起点、时长与定格，事件与文字段的起止，关键帧的时刻，跳转索引的时刻都用同一单位。

### 数值

- 整数与定点完全确定。
- 小数只用 IEEE 754 的加、减、乘、除与开方，就近舍入到偶数；禁用融合乘加与重排结合；保留次正规数。
- 非数的符号与载荷在比较与输出前一律规范化，观察不到差别。
- 小数转整数一律饱和并取确定结果；整数转小数就近舍入。
- 超越函数（正弦、余弦、指数等）由库「数学」自行实现，各端共用同一份代码。
- 表达式、噪声与弹簧的计算只依赖传入的时刻、种子与参数。

### 关键帧与缓动

- 第一帧之前取第一帧，最后一帧之后取最后一帧。
- 两帧之间按前一帧的缓动插值；前帧缓动为沿用时按整条信号的缓动。
- 三次贝塞尔以固定二十四次二分求横坐标的参数，再取纵坐标；各端位数一致。
- 弹簧缓动在进度 `p` 处取 `1 − e^(−阻尼·p)·cos(2π·圈数·p)`，段末取一。
- 阶跃按步数分级，每级在起点或终点跳；分段线性把各值等距排在零到一之间。
- 颜色插值在线性光空间进行，透明通道线性插值。

### 噪声与排序

- 一维值噪声的整点值由种子与序号混成：只用整数乘法与取余，中间值不超过二的五十三次方；整点之间用 `3s² − 2s³` 平滑插值。
- 素材排序用插入排序，时刻相同的保持收集次序；同一作品在同一源码下的素材次序、序号与跳转索引完全确定。
- 组件的定义表按写入先后建立，同一名称与源码只占一项；读取时按同一规则重建。

### 还原的确定性

还原（见第十三节）按固定规则选择数字、时刻与颜料的写法，同一作品两次还原得到同一份源码；素材文件名按当前目录里已有文件的字节比较与中文序号递增，同一目录状态给出同一组名字。

- `库/匠心/信号。豫`：`「求信号」`、`「贝塞尔」`、`「弹簧」`、`「一维噪声」`、`「整点散列」`。
- `库/匠心/数学。豫`：自实现的正弦、余弦、指数与开方。

## 十三、还原的约定

### 输出形态

`「还原作品源」于作品` 返回 `名。设计。豫` 的源码文字。顶层结构：

```
寻观「豫章」之书。
寻「豫章」之「本原」之「本术」之书。
寻观「匠心」之书。
（自动捕获组件的定义）
「作品」者
　（作品构造）
也。
```

构造写法用全角空格缩进，每层一个全角空格；名字、属性与子项按构造调用约定写回。

### 数字、时刻与颜料

- 整数写成中文数字，负数前加 `负`。
- 小数写成中文数字并总带 `点`；用十七位有效数字的精确表示，能原样读回。宿主给出指数写法时退回六位小数定点写法，指数写法的还原留待后续版本。
- 时刻：零写 `「零秒」`；能整除一秒写 `（「秒」于…）`；能整除一毫秒写 `（「毫秒」于…）`；其余写 `（「刻」于…）`。
- 坐标写 `（「坐标」于…于…）`。
- 纯色写 `（「色码」于『#RRGGBB』）`，透明分量为二五五时写六位，其余写八位。
- 渐变颜料与图案色目前写 `「透明色」`，渐变与图案的还原留待后续版本。
- 爻写 `「阳」` 或 `「阴」`。

### 默认值的省略

与默认值相同的属性省略，其余按构造写回。常用的默认值：

| 属性 | 默认 |
| --- | --- |
| 位置、偏移 | 原点 |
| 旋转、模糊、背景模糊、绕横、绕纵 | 零点零 |
| 缩放、不透明度 | 一点零 |
| 填充 | 透明色 |
| 描边 | 线形状为墨色，其余形状为透明色 |
| 线宽 | 负一点零（沿用作品线宽） |
| 字号 | 三十二点零 |
| 对齐 | 靠左 |
| 阴影颜色 | 透明色 |
| 字体 | 空文（默认字体） |
| 排列间距 | 零点零 |
| 图层颜色矩阵 | 空列 |
| 图层透视 | 零点零 |
| 混合 | 正常 |
| 片段实例起 | 零 |
| 实例速度 | 一点零 |
| 实例循环 | 一 |
| 实例往返、之前保持 | 阴 |
| 实例定格 | 负一 |
| 实例之后保持 | 阳 |
| 三维位置、旋转 | 三维原点 |
| 三维缩放 | 一点零 |
| 平行光投影 | 阳 |

### 组件、声明与文档

- 自动捕获的组件定义放在作品之前，按定义表次序写出；同一名称与源码只写一份。
- 组件实例在定义源码含 `自动捕获组件` 时写成调用 `（「名」实参…）`；其余情况写 `「组件实例」` 构造，内嵌 `「组件定义」`（名称、源码）与 `「组件实参」`（实参文字列），再写展开子节点。
- 声明节点写 `「声明」` 构造（种类、名称、源码与子节点）。若作品画面恰为单个种类 `文档源码` 的声明节点，`「还原作品源」` 直接返回它的源文。

### 素材

- 图像节点的来源保留，源码写原路径。
- 三维物体的贴图与模型项的来源为空时，把字节写到当前目录的 `还原素材<中文序号>.<后缀>`（图像为 `.png`，模型为 `.glb`），并在源码里写绝对路径。
- 同字节的素材复用同名文件；同名而字节不同时递增中文序号。
- 导出只写磁盘文件，作品字节保持原样。

### 往返

一致性测试检查「源码 → 二进制 → 源码 → 二进制」两次二进制逐字节相同，并检查还原源码含作品与实例构造。往返成立的条件是所用特性都在本节的还原范围内；渐变颜料、图案色、含 `』` 或换行的文字与指数写法的小数是后续版本的事项。

## 十四、一致性检查要点

独立实现的播放器或渲染机可以按下列条目逐条核对。每条都给出可直接检查的字节、值或行为。

### 外框与段

1. 文件开头六个字节为 `树码` 的 UTF-8 字节。
2. 魔数之后第一个变长整数为二（树码版本）。
3. 随后文字为 `设计`。
4. 随后三十二字节与「结构摘要」一节的摘要逐字节相同。
5. 随后变长整数为二（设计格式版本）。
6. 随后恰有十个变长整数，次序为时间、空间、声音、文字轨、输入、计算、素材、分页、精排、文档结构。
7. 随后三个变长整数为每帧计算、每秒采样计算与内存预算。
8. 随后有符号变长整数为时长；两个小数为画幅宽高。
9. 轨表第一项种类号为零、语言为空文；文字轨种类号为二至五；声轨为一；事件轨为六。
10. 段表恰有四项且名字依次为 `结构段`、`素材块`、`跳转索引`、`可选段`；长度之和等于文件剩余字节。
11. 结构段先写原长，再写原始收缩流；解压后长度等于原长。
12. 素材块先写块数，再逐块写长度与字节。
13. 跳转索引项数等于素材块数，每项为时刻（有符号）与素材块内偏移；偏移等于该块在素材块里的实际起点。
14. 可选段长度为零。

### 结构与节点

15. 作品骨架依次为种类、目标、画幅宽、画幅高、时长、背景、线宽、画面列、附轨列。
16. 每个节点的签号与字段次序符合第六节的表；节点签号在一二以内，未用签号拒收。
17. 组件的首见定义用签九写名称与源码，引用用签一零写序号；序号小于已见定义数；同一名称与源码只占一项。
18. 文字节点的字形项依次为素材序号、横、纵；排法种类为零至二；对齐为零至二。
19. 图层字段次序为模糊、阴影、颜色矩阵、背景模糊、混合、绕横、绕纵、透视、遮罩、子节点。
20. 交互节点字段次序为名、初始、输入、过渡、状态、日志；交互条件签号为零至五。
21. 三维视口字段次序为名、变换、宽、高、相机、三维项；三维项签号为零至五；网格签号为零至二。
22. 声源签号为零至二；附轨签号为零至二；波形号为零至四。
23. 信号签号为零至八；关键帧帧值为时、值、帧缓的次序。
24. 缓动签号为零至九；颜料签号为零至二；渐变形签号为零至二；延展签号为零至三。
25. 引用的素材序号小于素材块数，且种类与引用处相符。

### 数值与限制

26. 变长整数最多十字节；写出方用最短编码。
27. 列表个数不超过剩余字节数；字节串与文字长度不超过剩余字节数。
28. 变长整数中的有符号数用之字形映射；负数 `n` 写成 `2(−n)−1`。
29. 小数为八字节小端 IEEE 754 双精度位型；负零与次正规数按位保留。
30. 结构段的原长不超过二十亿字节；节点总数不超过一千万。
31. 球体细分在零到一千零二十四之间；合成节点仿射六项、色阵二十项。
32. 图层颜色矩阵长度为零或二十，元素与透视都是有限小数，透视不小于零。
33. 画幅宽高为有限正数；时长为不小于负一的刻数；线宽为有限小数。
34. 关键帧帧时刻不减且至少一帧；混合权、噪声频率与输入缺省为有限小数。
35. 表达式函数个数在一到一万之间；变量序号小于变量个数；只能调前面的函数；运算名与参数个数符合运算表；无多余词；调用实参个数按词流读入。
36. 文件头能力覆盖作品实际能力；预算三项不超过宿主默认上限（每帧与每秒各一千亿，内存一万亿）。

### 能力与代价

37. 能力十轴的次序与等级名符合「能力轴与等级」一节；能力集合的并为逐轴取大。
38. 节点能力符合「节点能力」一节；组、文字与图层按名字与属性增加对应能力。
39. 作品能力为画面与顶层附轨的并；时长大于零时加时间二。
40. 编码时作品能力不超过目标点的上限（「目标上限」一节），超出即报错并列出轴与等级。
41. 信号、节点、几何、样式、三维项与声源的代价符合「代价模型」一节。
42. 每帧计算等于画面节点代价之和；每秒采样计算等于四万八千乘附轨与节点声代价之和；内存等于每帧计算乘二百五十六。

### 确定性与还原

43. 所有时刻字段以刻的整数写出，一秒为七亿零五百六十万刻。
44. 关键帧求值遵循第一帧、最后一帧、前帧缓动与沿用规则；贝塞尔固定二十四次二分；弹簧按「关键帧与缓动」一节的公式。
45. 噪声按种子与整数散列求值，插值为 `3s² − 2s³`。
46. 素材按首次用到时刻升序排列，时刻相同保持收集次序；同一字节只存一块。
47. 还原的数字、时刻、坐标与纯色写法符合「数字、时刻与颜料」一节；默认值省略符合「默认值的省略」一节。

49. 「源码 → 二进制 → 源码 → 二进制」两次二进制逐字节相同（所用特性在「往返」一节的范围内）。
50. 前缀读器能只凭文件头与结构段开始播放，未到的素材按缺失处理，首帧所需字节等于「跳转索引与边下边播」一节的公式。
