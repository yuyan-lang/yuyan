# 揽辔

通称揽辔观测协议（agent observation protocol）。捉刀（编程智能体）在后台跑一场会话时，另外写一串事件小文件；揽辔（观测台）按序号读，实时看见模型流、思考、命令、回执、错误与用量，并用三个标记文件送嘱咐、打断与停止，再每秒写一次柝（心跳）文件报自己还在。名字取《后汉书·范滂传》“登车揽辔，慨然有澄清天下之志”：执辔的人不替马走，只看它走到哪里、该停时停。

本库只管文字与文件，不碰界面、不碰模型。路径与解析只有这一份，捉刀、工作台与揽辔共用。

## 文件

会话篇 `会话。会话。豫` 旁边有四类文件：

| 文件 | 谁写 | 内容 |
| --- | --- | --- |
| `会话。会话。豫。观。<运行号>。<序号>。会话。豫` | 捉刀 | 一批事件，沿用会话篇的块与「｜」行格式 |
| `会话。会话。豫。观。今` | 捉刀 | 当前运行号，指针文件 |
| `会话。会话。豫。令。嘱咐` | 观测台 | 一条用户的话，原样文字 |
| `会话。会话。豫。令。打断` | 观测台 | 空文件；捉刀见到就打断当前这一句或这次输出 |
| `会话。会话。豫。令。停止` | 观测台 | 空文件；捉刀见到就结束这一轮并退出 |
| `会话。会话。豫。令。柝` | 观测台 | 一行单调时钟纳秒；观测台窗口开着时约每秒重写一次 |

事件文件用原子写（先写同目录临时文件再改名），观测台只会读到完整的一批。运行号是三个密码学安全随机字节合成的十进数，用来分开同一篇的多次运行；序号从一数，按运行号与序号读，不排序。

柝是观测台的心跳（取打更的木梆：梆声不断，人就在岗）：观测台窗口开着时约每秒重写一次 `令。柝`，内容是当时的单调时钟纳秒。捉刀把「台察断」装进「察断格」，流片与等回执时都会查；查的时候隔约一秒才读一次文件，见到柝的时刻已过去四秒以上，就知道观测台已经没了，自己停下退出。窗口直接关掉（进程结束）也行，不必等窗口主循环返回时写停止标记。同一篇又起了别的后台时，`观。今` 换成新运行号，旧后台见到指针换了也自己退出，免得同篇两个后台一起写事件。后台起来时先删掉上次留下的柝：手动起的后台没有观测台，不会被旧柝误判。

## 事件

一块一个事件：

```text
「：事件：模型片：」
｜你好
```

块头是 `「：事件：种：」`，内容是各行的原文，每行以「｜」起头。正文行按 `｜` 之后照录，换行保留；空文字写一个空的「｜」行。字段行写在正文之前，形如 `名=值`，条数按种类固定。

| 种 | 字段 | 正文 | 何时写 |
| --- | --- | --- | --- |
| `就绪` | `篇`、`运行`、`模型` | 空 | 一次运行开始时，旧篇历史补完之后 |
| `块` | `头` | 块的内容 | 旧篇历史里的每个块；模型这次输出析出的每个块 |
| `模型片` | 无 | 这一片模型写的字（增量） | 流式收到一片时 |
| `思考片` | 无 | 这一片思考的字（增量） | 流式收到一片思考时 |
| `句始` | 无 | 整句壳句 | 交给子会话执行之前 |
| `句终` | `状` | 空 | 子会话回报之后（成或败） |
| `句出` | 无 | 回执全文 | 子会话回报之后 |
| `用量` | `命中`、`未中`、`所出`、`纳`、`累纳` | 空 | 每次请求之后 |
| `错误` | `段` | 说明 | 请求失败、篇式错误、轮次停下 |
| `轮始` | 无 | 空 | 一轮开始时 |
| `轮终` | `因` | 说明 | 一轮停下时（完成、打断、未竟、步数满等） |
| `打断` | 无 | 空 | 见到打断标记时 |
| `停止` | 无 | 空 | 见到停止标记或运行结束时 |

重要事件一到就写；`模型片`、`思考片` 先攒着，八片或四千零九十六字节写一批，免得一篇长回答写出几千个小文件。补旧篇历史时整批攒，最后与 `就绪` 一起写出。

## 使用

捉刀一侧：

```yuyan
「台开」于「篇径」于「模型名」于「篇文」。
「报块」于『模型』于「正文」。
「报量」于「一零零」于「二零零」于「三零」于「九零」于「九零」。
「台关」于「篇径」。
```

观测台一侧：

```yuyan
令「件们」为「析观文」于（「阅」于「事件径」）而
令「状」为（「观栏」于（「件们」中「零」）于『篇』）而
「书令」于「篇径」于『嘱咐』于『接着改』。
「击柝」于「篇径」。
```

捉刀把「台察断」装进「察断格」，流片与等回执时都会查标记，也查观测台还在不在；观测台窗口开着时约每秒「击柝」一次。「台取嘱」在轮与轮之间取一条嘱咐；「台止否」看有没有要求停止。

## 限额

- 事件每批至多四千零九十六字节左右，流片攒八片；写失败时留在缓冲里下次再写。
- 观测台只读自己需要的运行号，不扫全部文件；旧运行的事件留着作证据，暂不自动清理。
- 停止标记见过一次就不再删，由 `台关` 收尾时删掉；打断标记见到即删，免得下一轮误断；柝在 `台开` 与 `台关` 时删掉。观测台每秒击一次柝，捉刀隔一秒查一次、超过四秒没响就自己退，窗口重画或重析大篇耽搁几秒也不会误停。

## 测试

事件收取与三个控制标记由 `应用/机智坊/揽辔台/测试/状态。测试。豫` 核对：在临时目录里读出就绪、模型片、用量、篇改事件，控制标记的写取删，以及旧篇的块与句。

## 使用者

- `应用/机智坊/捉刀`：`--台` 模式写事件、查标记。
- `库/九宫` 的揽辔格：读事件、写标记、显示台账。
