# 揽辔

通称揽辔观测协议。捉刀（编程智能体）居后而行，别书事件之小卷；揽辔（观测台）依序而读，得见其流、其思、其令、其报、其误与其费，并以三标之卷致嘱、止与断。名字取《后汉书·范滂传》“登车揽辔，慨然有澄清天下之志”：执辔者不代马走，观其步而知其力。

此库惟理文字与文件，不涉界面，不涉模型。路径与解析止此一份，捉刀、书斋与揽辔共之。

## 文件

会话篇 `会话。会话。豫` 之旁有三类文件：

| 文件 | 谁书 | 内容 |
| --- | --- | --- |
| `会话。会话。豫。观。<行号>。<序号>。会话。豫` | 捉刀 | 一批事件，循会话篇之块与竖行 |
| `会话。会话。豫。观。今` | 捉刀 | 今行之号，针卷 |
| `会话。会话。豫。令。嘱咐` | 观测台 | 用户之一言，原样之文 |
| `会话。会话。豫。令。打断` | 观测台 | 空卷；捉刀见之则断此一句或此书 |
| `会话。会话。豫。令。停止` | 观测台 | 空卷；捉刀见之则终此轮而退 |

事件卷以原子书写（先书同目之草，书毕改名），观测台惟见全批。行号为三密随机之节合为一十进之数，以别同篇之诸行；序号自一数，依行号与序号而读，不待排序。

## 事件

一块一事：

```text
「：事件：模型片：」
｜你好
```

块头为 `「：事件：种：」`，内容诸行以「｜」起，照录原文；空文则书一空「｜」行。字段行在正文之前，形如 `名=值`，其数依种而定。

| 种 | 字段 | 正文 | 何时书 |
| --- | --- | --- | --- |
| `就绪` | `篇`、`运行`、`模型` | 空 | 一行之始，旧史补毕之后 |
| `块` | `头` | 块之内容 | 旧史之每块；新书析出之每块 |
| `模型片` | 无 | 此片所书（增益） | 流收一片时 |
| `思考片` | 无 | 此片所思（增益） | 流收一片时 |
| `句始` | 无 | 全句壳句 | 付子会话之前 |
| `句终` | `状` | 空 | 子会话回报之后 |
| `句出` | 无 | 回执全文 | 子会话回报之后 |
| `用量` | `命中`、`未中`、`所出`、`纳`、`累纳` | 空 | 每请之后 |
| `错误` | `段` | 说 | 请败、篇式之误、轮止 |
| `轮始` | 无 | 空 | 一轮之始 |
| `轮终` | `因` | 说 | 一轮止时 |
| `打断` | 无 | 空 | 见断标时 |
| `停止` | 无 | 空 | 见止标或行终时 |

要事至即书；流片先积，八片或四千零九十六字节乃书一批，免长答书出数千小卷。补旧史时整批积之，终与 `就绪` 俱出。

## 使用

捉刀一侧：

```yuyan
「台开」于「篇径」于「模型名」于「篇文」。
「报块」于『模型』于「正文」。
「台关」于「篇径」。
```

观测台一侧：

```yuyan
令「件们」为「析观文」于（「阅」于「事件径」）而
令「状」为（「观栏」于（「件们」中「零」）于『篇』）而
「书令」于「篇径」于『嘱咐』于『接着改』。
```

捉刀以「台察断」装于「察断格」，流片与候报时皆查标；「台取嘱」于轮间取一嘱；「台止否」察有命止否。

## 限额

- 事批至四千零九十六字节左右，流片积八片；书败则留于积以待下次。
- 观测台惟读所需之行号，不扫诸卷；旧行之事留为证，暂不自治。
- 止标一见则不复焚，待 `台关` 收尾而焚；断标一见即焚，免下轮误断。

## 测试

`库/揽辔/测试/揽辔。测试。豫` 于暂目核：书一批、针卷、依序读回、字段与正文、制标之写取焚、旧史之块与句、止与断。
