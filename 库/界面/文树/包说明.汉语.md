# 界面文树

[界面库](../包说明.汉语.md)的浏览器文树后端：把界面树译成 HTML 与 CSS 交给浏览器，排版、字体、绘制、输入法与无障碍都由浏览器做。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md` 九·二。

## 用法

```yuyan
寻观「界面文树」之书。
「运行界面」于『待办容器』于「初始模型」于「视图」于「更新」。
```

页面里放一个该 ID 的容器元素（大小由页面定，通常撑满视口），并用浏览器宿主的 `自动启动.mjs` 启动应用；应用用 `yy双宿主构建 --自动 浏览器` 构建。

## 做什么

- 启动：容器加类名 `界根`；用网页文树 0.4.0 的 `添加页面样式规则` 装基础样式表与界面用到的样式规则；界面树译成 HTML 放进容器；第一个带「自动聚焦」的元素取得焦点；在容器上委托订阅 `click`（阻止默认，所以链接不跳转、复选框由模型决定勾选）、`input`、`keydown`、`focusin`、`focusout`。
- 事件：按事件载荷的「操作键」（最近的 `data-yy`，即元素标识）换成元素事件，交界面库的「事件转消息」；文本框里按回车（不在组字中）算提交；浏览器键名换成显示接口的中文键名（Enter→回车 等）。
- 更新：调应用的更新与视图，与上一棵界面树差分（界面库的「比较界面」），按 `data-yy` 查到节点后逐项改；新出现的样式规则按类名去重后补装。文本框的值只在模型给的文字与浏览器里的现值不同时才写回，免得打断输入法组字；写回时临时给节点一个 ID，用网页界面的「设置节点值」。
