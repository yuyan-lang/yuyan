# 界面文树

[界面之库](../包说明.文言.md)之浏览器文树后端：译界面之树为 HTML 与 CSS 以授浏览器，排版、字体、绘、输入法与无障碍皆浏览器为之。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md` 九·二。

## 用法

```yuyan
寻观「界面文树」之书。
「运行界面」于『待办容器』于「初始模型」于「视图」于「更新」。
```

页中置一此 ID 之容器（其大由页定之，常满视口），以浏览器宿主之 `自动启动.mjs` 启客；客以 `yy双宿主构建 --自动 浏览器` 构之。

## 所为

- 始：容器加类名 `界根`；以网页文树零点四点零之 `添加页面样式规则` 装基础样式表与界面所用之规；译界面之树为 HTML 而置于容器；首带自动聚焦之元素得焦；于容器委订 `click`（阻其默认，故链不跳、复选之勾由模型定之）、`input`、`keydown`、`focusin`、`focusout`。
- 事：依事之操作键（最近之 `data-yy`，即元素之标识）易为元素之事，授界面库之「事件转消息」；文本框中按回车（非组字中）为提交；浏览器之键名易为显示之约之中文键名（Enter→回车 等）。
- 更：呼客之更新与视图，与前树相较（界面库之「比较界面」），依 `data-yy` 得节而逐项改之；新见之样式规则依类名去重而补装。文本框之值，惟模型之文异于浏览器今值乃写回，免断输入法之组字；写回时暂予节点一 ID，用网页界面之「设置节点值」。

## 待办

首屏之接管（服务端或构建时所生之 HTML 直接管之，不重画）；自动聚焦惟于始时为之；子元素依键移节，不整段重画；闭时撤订。
