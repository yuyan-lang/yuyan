# 界面文树

[界面之库](../包说明.文言.md)之浏览器文树后端：译界面之树为 HTML 与 CSS 以授浏览器，排版、字体、绘、输入法与无障碍皆浏览器为之。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md` 九·二。

## 用法

```yuyan
寻观「界面文树」之书。
「运行界面」于『待办容器』于「初始模型」于「视图」于「更新」。
```

页中置一此 ID 之容器（其大由页定之，常满视口），以浏览器宿主之 `自动启动.mjs` 启客；客以 `yy双宿主构建 --自动 浏览器` 构之。样式由此后端装于页，页惟定容器之大。

## 所为

- 始：容器加类名 `界根`；以网页文树零点四点零之 `添加页面样式规则` 装基础样式表与界面所用之规；译界面之树为 HTML 而置于容器；首带自动聚焦之元素得焦（文本框与多行文框依 ID `yy输入-标识` 聚之）；于容器委订 `click`（阻其默认，故链不跳、复选之勾由模型定之）、`input`、`select`、`keydown`（命令或控制加 S，宿主即阻浏览器存网页之默认，事仍付客）、`focusin`、`focusout`，记诸订之号。
- 首屏之接：服务端或构建时可以界面库之「首屏容器超文本」生首屏容器，其带 `data-yyhash`（首帧 HTML 之散列）。始时所算首帧之散列与之同，则径接容器既有之节，不重画；散列异或无此属，则如常置首帧。
- 事：依事之操作键（最近之 `data-yy`，即元素之标识）易为元素之事，授界面库之「事件转消息」；文本框中按回车（非组字中）为提交；浏览器之键名易为显示之约之中文键名（Enter→回车 等）。
- 更：呼客之更新与视图，与前树相较（界面库之「比较界面」），依 `data-yy` 得节而逐项改之；新见之样式规则依类名去重而补装。文本框之值，惟模型之文异于浏览器今值乃写回，免断输入法之组字；写回时依 ID `yy输入-标识` 用网页界面之「设置节点值」。
- 依键重排：容器诸子皆带键、键各不重，则差分给「重排子节点」；此后端沿用页中同标识之旧节（先就地改之），新见之子以 HTML 建于一暂节而取之，乃以 `替换页面子节点` 依新序全换之，故增删、移列项惟动有变者。
- 文本着色：带「文本着色」属之多行文框书为三层。外框 `div` 带元素之类名、标识与可易之属，为滚动之器；内一网格，着色层（依着色之域生带色类名之 `span`）与 `textarea` 叠于一格。`textarea` 之文透明（`-webkit-text-fill-color: transparent`），光标、选区与输入法如常；两层同字体、同字号、同行高、同字距，皆不自换行。网格随着色层之文增高增宽，`textarea` 满网格而不自滚，滚动由外框统为之，故两层恒齐；输入时差分改 `textarea` 之值而重画着色层。色书为惟含字色之样式类，页无须 `style` 属。
- 闭：宿主闭事列，则消始时所记界面之订，释容器之柄而止。

## 待办

- 自动聚焦惟于始时为之。
- 带着色之多行文框，`placeholder` 与 `disabled` 之易落于外框，`textarea` 存首帧之值。
- 着色层待更新后乃显新输之字，每输皆历更新、视图与差分；大文逐键输入之迟，留待后续版本优化之。
- 拼写之检：属性白册加入 `spellcheck` 后，乃为源码框闭之。
- `设置页面节点超文本` 一次至多 2 MiB、深至多三十二，着色层（正文加着色之签）与 `textarea` 各存正文一份，数百 KB 以上之源码则逾限。

文树后端订文本框 `select` 之事，复用网页界面读输入光标之接口，依码点始止生元素选区事件。文本框生 `yy输入-` 前缀之节点标识以供读。

文本框声明“编辑时”，则浏览器输入之事传全文及当前码点光标；余输入循“输入时”。编辑之事兼更现值表，相较时存浏览器已入之值。
