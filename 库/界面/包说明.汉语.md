# 界面

显示控件已从实际输入生成按下、移动、抬起消息，并经自绘转换交给 `指针时`；按下标识保持到抬起，指针离开热区仍可回传。窗口拖动状态和 HTML 后端仍待接入，后文“显示输入尚待产生”的早期记录已过时。

`指针时` 处理三个整数：阶段（0 按下、1 移动、2 抬起）、绝对横坐标和纵坐标（逻辑像素乘64）。`元素指针` 沿祖先冒泡，禁用元素遵循既有消息拒绝规则。当前仅完成事件模型与自绘转换；显示输入产生事件、窗口捕获拖动及 HTML 后端尚待接入。

自绘文本框可用 `编辑时` 回调接收全文及码点光标位置，包含文字编辑与光标移动；旧 `输入时` 仍接收改文，两者可各自使用，避免在同一模型重复处理改文。HTML 后端尚未接此编辑回调。

文本框可带 `光标定位 于 请求序号 于 码点位置` 属性。自绘后端每个控件只应用新的非负序号，随后鼠标及编辑键的移动保留；应用需再次定位时递增序号。此属性用于候选确认、历史恢复等程序改文。当前 HTML 生成仅保留普通文本框输出，定位行为由自绘后端实现。

高层界面布局语言：HTML 与 CSS 在豫言里的对应，写成普通豫言库（嵌入式，不改编译器）。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md`。

应用用元素函数写界面树（相当于 HTML），用类型为「样式」的值写样式（相当于 CSS），界面树按应用的消息类型参数化，事件处理直接产出应用的消息。界面描述可以译成 HTML 与 CSS 交给浏览器，也可以交给自绘后端排版、绘制。

## 模块

- `元素`：界面、行内、属性的类型；元素函数 竖排、横排、层叠、滚动区、文字块、段落、按钮、文本框、复选框、可点、分隔线、留白、空元素、带键；行内的 纯文、文片、链接、断行；属性与事件 点击时、输入时、提交时、切换时、按键时、聚焦时、失焦时、占位、禁用、自动聚焦、悬停提示；取元素各字段的函数。
- `样式`：样式与对齐方式的构造器（尺寸、盒、弹性、定位、文字、组合与四种状态变体）。长度以逻辑像素为单位。
- `颜色`：颜色是整数 0xRRGGBBAA；色码（#rgb、#rrggbb、#rrggbbaa）、三原色、加透明、透明色，以及转成 CSS 文字与整数。
- `标识`：元素标识（树路径加键）与祖先判断。
- `默认样式`：根与各种元素的默认样式，两个后端共用。
- `生成样式表`：样式转 CSS 声明与规则（类名取声明文字的散列），基础样式表（结构样式与默认样式）。
- `生成超文本`：界面树转 HTML 与所需的样式规则（每个元素带 `data-yy`＝元素标识）；元素的可变属性；子元素或行内片的 HTML 片段；整棵树用到的（类名，规则）对；整页 HTML（静态页用）。
- `处理`：元素事件（点击、输入、提交、聚焦、失焦、按键，带元素标识）换成应用消息：按标识找到元素或段落里的链接，取它的事件处理；点击与按键沿祖先冒泡；禁用的元素不产生消息。两个后端共用。
- `差分`：新旧界面树差分，得文树改动（改类名、改属性、删属性、改文字、重画内容、改输入值、改选中），文树后端据此改页面。
- `文字工具`：库内部用的取余数、十六进制、散列与超文本转义，不从总集转出。

## 用法

```yuyan
寻观「界面」之书。

「页面」乃「样式」也。
「页面」者「样式组」于「列」【「内距」于「24」，「间距」于「16」】也。

「首页」乃（「界面」于「有」）也。
「首页」者「竖排」于「列」【「页面」】于「列」【「文字块」于「列」【「粗体」】于『你好』】也。

「页面文字」者「整页超文本」于『示例』于「首页」也。
```

公开名一律取两字以上的专名：库导出的名字会劫持应用「鉴」里同名的模式变量。

## 多行文本框

`多行文本框` 接收样式、属性与全文，使用与单行文本框相同的输入和按键回调。自绘后端按逻辑行绘制并处理跨行光标、选区和粘贴；浏览器文树后端生成原生 `textarea` 并更新其当前值。回车插入换行，控制或命令加回车触发提交。撤销重做由应用按文件保存历史。

元素键中的 `%` 和 `/` 在内部标识中分别编码为 `%25` 与 `%2F`，文件路径键保持单个层级。事件查找与祖先冒泡共用此编码，避免子文件事件被同名目录截获。
