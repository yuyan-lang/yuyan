# 界面

高层界面布局语言：HTML 与 CSS 在豫言里的对应，写成普通豫言库（嵌入式，不改编译器）。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md`。

应用用元素函数写界面树（相当于 HTML），用类型为「样式」的值写样式（相当于 CSS），界面树按应用的消息类型参数化，事件处理直接产出应用的消息。界面描述可以译成 HTML 与 CSS 交给浏览器，也可以交给自绘后端排版、绘制。

## 模块

- `元素`：界面、行内、属性的类型；元素函数 竖排、横排、层叠、滚动区、文字块、段落、按钮、文本框、复选框、可点、分隔线、留白、空元素、带键；行内的 纯文、文片、链接、断行；属性与事件 点击时、输入时、提交时、切换时、按键时、聚焦时、失焦时、占位、禁用、自动聚焦、悬停提示；取元素各字段的函数。
- `样式`：样式与对齐方式的构造器（尺寸、盒、弹性、定位、文字、组合与四种状态变体）。长度以逻辑像素为单位。
- `颜色`：颜色是整数 0xRRGGBBAA；色码（#rgb、#rrggbb、#rrggbbaa）、三原色、加透明、透明色，以及转成 CSS 文字与整数。
- `标识`：元素标识（树路径加键）与祖先判断。
- `默认样式`：根与各种元素的默认样式，两个后端共用。
- `生成样式表`：样式转 CSS 声明与规则（类名取声明文字的散列），基础样式表（结构样式与默认样式）。
- `生成超文本`：界面树转 HTML 与所需的样式规则；整页 HTML（静态页用）。
- `文字工具`：库内部用的取余数、十六进制、散列与超文本转义，不从总集转出。

## 用法

```yuyan
寻观「界面」之书。

「页面」乃「样式」也。
「页面」者「样式组」于「列」【「内距」于「24」，「间距」于「16」】也。

「首页」乃（「界面」于「有」）也。
「首页」者「竖排」于「列」【「页面」】于「列」【「文字块」于「列」【「粗体」】于『你好』】也。

「页面文字」者「整页超文本」于『示例』于「首页」也。
```

公开名一律取两字以上的专名：库导出的名字会劫持应用「鉴」里同名的模式变量。
