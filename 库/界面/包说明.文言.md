# 界面

高层界面布局之言：HTML 与 CSS 于豫言之对应，书为常豫言之库（嵌入之式，不易编译器）。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md`。

客以元素之术书界面之树（犹 HTML），以「样式」之值书样式（犹 CSS）；界面之树依客之消息为参，事之处置直出客之消息。界面之述可译为 HTML 与 CSS 以授浏览器，亦可授自绘之后端排而画之。

## 诸模

- `元素`：界面、行内、属性之类；元素之术 竖排、横排、层叠、滚动区、文字块、段落、按钮、文本框、复选框、可点、分隔线、留白、空元素、带键；行内之 纯文、文片、链接、断行；属性与事 点击时、输入时、提交时、切换时、按键时、聚焦时、失焦时、占位、禁用、自动聚焦、悬停提示；取元素诸项之术。
- `样式`：样式与对齐之构造（尺寸、盒、弹性、定位、文、合与四态之变）。长短以逻辑之素计。
- `颜色`：色为整数 0xRRGGBBAA；色码（#rgb、#rrggbb、#rrggbbaa）、三原色、加透明、透明色，及译为 CSS 之文与整数。
- `标识`：元素之标识（树之径加键）与判祖。
- `默认样式`：根与诸元素之默认，二后端共之。
- `生成样式表`：样式译为 CSS 之声明与规（类名取声明之文之散列），基础样式表（结构之式与默认之式）。
- `生成超文本`：界面之树译为 HTML 与所需之样式规则；全页之 HTML（静页用之）。
- `文字工具`：库内用之取余、十六进、散列与超文本转义，不由总集出。

## 用法

```yuyan
寻观「界面」之书。

「页面」乃「样式」也。
「页面」者「样式组」于「列」【「内距」于「24」，「间距」于「16」】也。

「首页」乃（「界面」于「有」）也。
「首页」者「竖排」于「列」【「页面」】于「列」【「文字块」于「列」【「粗体」】于『你好』】也。

「页面文字」者「整页超文本」于『示例』于「首页」也。
```

公名皆二字以上之专名：库所出之名，夺客「鉴」中同名之模式变量。

## 待办

样式之求（自绘用之）、文树后端与自绘后端别包为之；态变之内复套态变者惟记内态；键含斜者依首判祖或误；超文本转义逐通字符而易，长文稍迟。
