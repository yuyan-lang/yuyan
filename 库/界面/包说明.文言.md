# 界面

显示控件已循实输入生按下、移动及抬起之事，经自绘转而交 `指针时`；按下之标存至抬，指离热区犹可回传。窗拖之态与 HTML 后端犹待接，后文显示输入待生之早录已旧。

`指针时` 处置三整数：阶段（零按下、一移动、二抬起）、绝对横纵坐标（逻辑像素乘六十四）。`元素指针` 循祖冒泡，禁用元素循旧拒消息之法。今惟成事模与自绘之转；显示输入生事、窗口捕获拖移及 HTML 后端犹待接。

自绘文框可用 `编辑时` 回调受全文与码点光标之位，含改文与移标；旧 `输入时` 犹受改文，两者可各用，免同模重处改文。HTML 后端尚未接此回调。

文框可带 `光标定位 于 请求序号 于 码点位置` 之属。自绘后端每控件惟施新非负之序，随后鼠标与编辑键之移存之；客欲复定位则增序。此属供定候选、复历史诸程序改文。今 HTML 之生惟存普通文框之出，定位由自绘后端行之。

高层界面布局之言：HTML 与 CSS 于豫言之对应，书为常豫言之库（嵌入之式，不易编译器）。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md`。

客以元素之术书界面之树（犹 HTML），以「样式」之值书样式（犹 CSS）；界面之树依客之消息为参，事之处置直出客之消息。界面之述可译为 HTML 与 CSS 以授浏览器，亦可授自绘之后端排而画之。

## 诸模

- `元素`：界面、行内、属性之类；元素之术 竖排、横排、层叠、滚动区、文字块、段落、按钮、文本框、复选框、可点、分隔线、留白、空元素、带键；行内之 纯文、文片、链接、断行；属性与事 点击时、输入时、提交时、切换时、按键时、聚焦时、失焦时、占位、禁用、自动聚焦、悬停提示；取元素诸项之术。
- `样式`：样式与对齐之构造（尺寸、盒、弹性、定位、文、合与四态之变）。长短以逻辑之素计。
- `颜色`：色为整数 0xRRGGBBAA；色码（#rgb、#rrggbb、#rrggbbaa）、三原色、加透明、透明色，及译为 CSS 之文与整数。
- `标识`：元素之标识（树之径加键）与判祖。
- `默认样式`：根与诸元素之默认，二后端共之。
- `生成样式表`：样式译为 CSS 之声明与规（类名取声明之文之散列），基础样式表（结构之式与默认之式）。
- `生成超文本`：界面之树译为 HTML 与所需之样式规则（每元素带 `data-yy`＝元素之标识）；元素可易之属性；子元素或行内之片之 HTML 片；全树所用之（类名，规）对；全页之 HTML（静页用之）。
- `处理`：易元素之事（点击、输入、提交、聚焦、失焦、按键，带元素之标识）为客之消息：依标识寻其元素或段中之链，取其事之处置；点击、按键循祖而冒；禁者不生消息。二后端共之。
- `差分`：新旧界面之树相较，得文树之改（改类名、改属性、删属性、改文、重画其内、改输入之值、改选），文树后端依之改页。
- `文字工具`：库内用之取余、十六进、散列与超文本转义，不由总集出。

## 用法

```yuyan
寻观「界面」之书。

「页面」乃「样式」也。
「页面」者「样式组」于「列」【「内距」于「24」，「间距」于「16」】也。

「首页」乃（「界面」于「有」）也。
「首页」者「竖排」于「列」【「页面」】于「列」【「文字块」于「列」【「粗体」】于『你好』】也。

「页面文字」者「整页超文本」于『示例』于「首页」也。
```

公名皆二字以上之专名：库所出之名，夺客「鉴」中同名之模式变量。

## 待办

样式之求（自绘用之）与自绘后端别包为之，文树后端在 `文树/`（包「界面文树」）；子元素依键移节、不整段重画；态变之内复套态变者惟记内态；键含斜者依首判祖或误；超文本转义逐通字符而易，长文稍迟。

## 多行文本框

`多行文本框` 受样式、属性与全文，输入按键之回调同单行文框。自绘后端依逻辑行而绘，治跨行之光标、选区与粘贴；浏览器文树后端生原生 `textarea` 而更其今值。回车入换行，控制或命令加回车则提交。撤销重做由客依文存其史。

元素键之 `%` 与 `/` 于内部标识各书为 `%25` 与 `%2F`，文件路径之键仍为一级。事之寻与循祖冒泡共此编码，免子文件之事为同名目所截。

`选区时` 受起位与止位而生客之消息，`元素选区` 依元素标识付此回调。位用编辑控件之码点序。控件与浏览器实选区之事件输出续接。

`元素有编辑回调` 依界面树及元素标识，验其有无编辑回调之声明，以供后端择事件之路。
