# 界面测试

界面库（`库/界面`）之单元测试：色（色码、三原色、加透明、译为 CSS 之文）、样式译为 CSS（单项之声明、样式组与条件样式之展、态变之伪类规则、类名之恒）、元素之标识、界面之树译为 HTML、事转消息（冒、禁、段中之链）、消息之映（映后诸事皆得包内消息之外消息，HTML 同于映前）与新旧界面之树相较；自绘后端之样式求值（相承、态变）、布局（竖排、横排之伸缩、对齐、换行排、文之换行、滚动区、绝对定位、百分、层叠、弹性之长之解）与显示树之热区，文用假量具；渲染之节（提案 00011 议二）：同一串界面之树，各以全排与比对沿用为之，盒树逐项皆同、所画逐素皆同（复以增量之画重画一份，亦逐素皆同），未变之帧不复量文，惟改一处则惟复量其处（此项以测试字体画文，故本包复依字体与字体测试）。须单元测试之框架，故别立为包。诸 `X。测试。豫` 由全树测试自寻而行之。
