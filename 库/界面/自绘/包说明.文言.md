# 界面自绘

[界面库](../包说明.文言.md)之自绘后端：于[显示控件库](../../显示控件/包说明.文言.md)之主循环行模型—视图—更新，自求样式、自排之，生显示之树而交显示控件库画之。可行于诺节之窗（SDL）与浏览器之 canvas，他日接豫言系统之原生窗口。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md` 九·一。

## 用法

```yuyan
寻观「界面自绘」之书。
「运行界面」于『主窗口』于「初始模型」于「视图」于「更新」。
```

首参为显示面之名，由运行之境授之：诺节以 `--授权显示面 主窗口=800x600`，浏览器以 `<canvas data-yy-显示面="主窗口">`。应用以 `yy双宿主构建 --自动 节点|浏览器` 构之，其步见[界面自绘示例](../示例/自绘/包说明.文言.md)。同一应用易为文树后端，惟改所导之包与首参。

## 诸模

- `计算样式。豫`：每元素之计式为一整数之数组（每式一槽）加字体族。文之属性承于父，余取默认；次第施种之默认、元素之样式列（样式组就地展之，条件样式依条件取舍），复依交互之态叠悬停、焦点、按下、禁用之变。
- `样式树。豫`：界面树之每元素配其标识与计式；文类之元素备其文片，段中之链依己之悬停、按下之态上式，并记其片序与标识。悬停、按下依标识之首及于其祖，焦点惟视其身。
- `布局。豫`：布局之擎，长短以六十四分之一逻辑之素计。竖排、滚动区依纵之弹性排之，横排依横之弹性排之（可换行排），层叠叠诸子于内容盒，绝对定位依父之内距盒；伸缩依 CSS 弹性盒九点七节之冻循环解之；自动之最小尺取内容之最小尺，滚动区、裁剪与省略号之元素为零；百分依容块。
- `显示。豫`：以布局盒生显示之树。底与边画为方框（四边宽或色异，则于底框之中画四细边）；文类之元素画文字之节；文本框、滚动区用显示控件之文本框节与滚动节；复选框自画其方。钮、复选框与可点之元素外包可聚焦之钮热区，余元素外包区域热区，悬停、按下与点击之冒皆赖之；段中之链依排之片段各置一链热区；聚焦之控件外画焦点之环。
- `运行。豫`：「运行界面」。每帧之视图回调次第求样式树（根之标识为 0）、依视口排之、生显示之树；控件库所交之交互之事，依元素标识易为元素之事（焦点改变析为旧焦之失焦与新焦之聚焦，无焦点之按键落于根元素），复由界面库之「事件转消息」依最近一帧之界面树易为客之消息而授更新。

## 与文树后端之异

布局之规取 CSS 之定义，同一界面于二后端所排之矩当同，其异出于字形与断行。已知之例外：层叠之主轴对齐为居中或靠末，其宽犹满容器（CSS 网格缩其轨至内容之宽）；换行排之多行依起而叠，不依 align-content 拉伸；钮为鼠所点，亦画焦点之环。

## 待办事项

悬停提示；链之焦点之环；复选框画真勾；换行排之行拉伸与层叠依网格之轨对齐；全帧重算尚无缓存（长列惟排视口中之行、段排之缓存）；与无头 Chrome 之布局对照之测。
