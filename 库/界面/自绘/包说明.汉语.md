# 界面自绘

`运行界面计时会话` 在会话参数后接模型计时间隔及模型更新函数，直接交给显示控件计时循环。计时更新不合成键鼠事件，也不重建焦点状态。旧会话入口不启用计时。

`运行界面会话` 在停止判定后接“结束归还”标记，传给控件主循环。用户态桌面传真，返回调用方前归还本次显示会话；原界面入口传假，保持宿主管理显示面的行为。

主循环的 `编辑改变` 转为 `元素编辑`，通过 `编辑时` 回调把全文及码点位置交给模型。它独立于原输入事件，应用选择一个改文回调使用；模型尚未接此属性时保持原行为。

文本框的 `光标定位` 属性生成 `光标定位节点`，委托显示控件应用一次性光标请求。无定位属性的文本框保持原编辑行为；相同请求序号不覆盖后续鼠标及键盘移动。当前只控制光标位置，尚未向模型报告每次光标移动。

[界面库](../包说明.汉语.md)的自绘后端：在[显示控件库](../../显示控件/包说明.汉语.md)的主循环上运行模型—视图—更新，自己求样式、排版，生成显示树交显示控件库绘制。能在诺节窗口（SDL）与浏览器 canvas 上运行，以后接豫言系统的原生窗口。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md` 九·一。

## 用法

```yuyan
寻观「界面自绘」之书。
「运行界面」于『主窗口』于「初始模型」于「视图」于「更新」。
```

第一个参数是显示面的名字，由运行环境授予：诺节用 `--授权显示面 主窗口=800x600`，浏览器用 `<canvas data-yy-显示面="主窗口">`。应用用 `yy双宿主构建 --自动 节点|浏览器` 构建，步骤见[界面自绘示例](../示例/自绘/包说明.汉语.md)。同一应用换到文树后端时，只改导入的包与第一个参数。

## 模块

- `计算样式。豫`：每个元素的计算样式是一个整数数组（每项样式一个槽）加字体族。文字属性继承父元素，其余取默认；依次施加种类默认样式、元素的样式列（样式组就地展开，条件样式按条件取舍），再按交互状态叠加悬停、焦点、按下、禁用变体。
- `样式树。豫`：界面树的每个元素配上标识与计算样式；文字类元素备好文字片，段落里的链接按自己的悬停、按下状态上样式，并记下片序与标识。悬停、按下按标识前缀作用到祖先，焦点只看元素自身。
- `布局。豫`：布局引擎，长度用 1/64 逻辑像素。竖排、滚动区按纵向弹性排，横排按横向弹性排（可换行排），层叠把子元素叠在内容盒里，绝对定位相对父元素的内边距盒；伸缩按 CSS 弹性盒 9.7 节的冻结循环求解；自动最小尺寸取内容最小尺寸，滚动区、裁剪与省略号的元素为零；百分比相对包含块。
- `显示。豫`：由布局盒生成显示树。背景与边框画成方框（四边宽度或颜色不同时，在背景方框里画四条细边）；文字类元素画文字节点；文本框、滚动区用显示控件的文本框节点与滚动节点；复选框自画方块。按钮、复选框与可点元素包一层可聚焦的按钮热区，其余元素包一层区域热区，悬停、按下与点击冒泡都靠它；段落里的链接按排版片段各放一个链接热区；聚焦的控件外画焦点环。
- `运行。豫`：「运行界面」。每帧视图回调依次求样式树（根标识为 0）、按视口排版、生成显示树；控件库交回的交互事件按元素标识换成元素事件（焦点改变拆成旧焦点的失焦与新焦点的聚焦，没有焦点时的按键落在根元素上），再由界面库的「事件转消息」按最近一帧的界面树换成应用消息交给更新。

## 与文树后端的差异

布局规则取 CSS 的定义，同一界面在两个后端排出的矩形应当相同，差异来自字形与断行。已知的例外：层叠在主轴对齐为居中或靠末时宽度仍撑满容器（CSS 网格会把轨道缩到内容宽）；换行排的多行按起点堆叠，不按 align-content 拉伸；按钮被鼠标点中后也画焦点环。

## 待办事项

悬停提示；链接的焦点环；复选框画真正的勾；换行排的行拉伸与层叠按网格轨道对齐；整帧重算还没有缓存（长列表只排视口内的行、段落排版缓存）；与无头 Chrome 的布局对照测试。

## 验证

单元测试在 `../测试/自绘布局。测试。豫`：样式求值、布局与显示树，文字用假的文字量具（每个码点等宽）。示例在诺节与浏览器上运行的步骤见[界面自绘示例](../示例/自绘/包说明.汉语.md)。

## 应用主动结束

`运行界面可停止` 在原入口的参数后接一个“模型 → 爻”停止条件，交给显示控件的可停止主循环。初态已结束时不生成界面、不取得显示面；应用更新到结束模型后主循环返回。原 `运行界面` 保持原行为。

测试见 `../测试/主动结束。测试。豫`：结束初态不会调用视图或更新，也不要求显示面授权；已构建运行通过。
