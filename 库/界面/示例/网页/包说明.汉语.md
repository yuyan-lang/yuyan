# 界面网页示例

待办清单（包「界面待办示例」）经[界面文树](../../文树/包说明.汉语.md)后端在浏览器里运行。

## 构建与运行

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 库/界面/示例/网页 dist/界面网页示例 --包根 库/界面
cp 库/界面/示例/网页/页面.html dist/界面网页示例/index.html
```

再用任一静态文件服务伺服 `dist/界面网页示例`（如 `wrangler dev --assets dist/界面网页示例`），用支持 WasmGC 与 JSPI 的浏览器打开。页面里 ID 为 `待办容器` 的元素撑满视口。
