# 界面网页示例

待办之清单（包「界面待办示例」）经[界面文树](../../文树/包说明.文言.md)之后端行于浏览器。

## 构与行

于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 库/界面/示例/网页 dist/界面网页示例 --包根 库/界面
cp 库/界面/示例/网页/页面.html dist/界面网页示例/index.html
```

乃以静文之服伺 `dist/界面网页示例`（如 `wrangler dev --assets dist/界面网页示例`），以备 WasmGC 与 JSPI 之浏览器启之。页中 ID 为 `待办容器` 之元素满视口。
