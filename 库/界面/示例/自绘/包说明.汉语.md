# 界面自绘示例

待办清单（包「界面待办示例」）经[界面自绘](../../自绘/包说明.汉语.md)后端运行，显示面名为“主窗口”。同一份应用在浏览器文树后端的版本见[界面网页示例](../网页/包说明.汉语.md)。

## 诺节

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 库/界面/示例/自绘 dist/界面自绘示例 --包根 库/界面 --包根 库/显示控件 --包根 库/字体
node dist/界面自绘示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 是装了 `@kmamal/sdl` 的目录（含 `node_modules` 的那一层），见诺节宿主说明。自动验收时加 `--显示面后台`，窗口不抢前台。

## 浏览器

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 库/界面/示例/自绘 dist/界面自绘示例网页 --包根 库/界面 --包根 库/显示控件 --包根 库/字体
cp 库/界面/示例/自绘/页面.html dist/界面自绘示例网页/index.html
```

页面里的 canvas 撑满视口，`字体/无衬线.ttf` 须自行放一个含中文的字体文件（如 macOS 的 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`；用 `wrangler dev --assets` 伺服时单个文件不能超过 25 MiB）。再用任一静态文件服务伺服产物目录，用支持 WasmGC 与 JSPI 的浏览器打开。

## macOS 原生（arm64）

不绑适配直接构建，显示与字体两个接口由执行器实现，见[原生窗口方案](../../../../豫言操作系统/文档/原生窗口方案.汉语.md)；`yy客体二号.wasm`、`yy原生生成.wasm` 的构建命令见[客体二号](../../../../豫言操作系统/裸机/客体二号/说明.汉语.md)。在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 界面自绘示例 --输出 yy界面自绘示例.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=512 node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm 苹果 臂六十四 yy客体二号.wasm yy界面自绘示例原生 yy界面自绘示例.wasm --预编二
chmod +x yy界面自绘示例原生
./yy界面自绘示例原生 --授权显示面 主窗口=800x600
```

自动验收时加 `--显示面后台`，窗口不激活、放在其他窗口之后。
