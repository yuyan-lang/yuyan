# 界面自绘示例

待办之单（包「界面待办示例」）经[界面自绘](../../自绘/包说明.文言.md)之后端行之，显示面名“主窗口”。同一应用于浏览器文树后端之版，见[界面网页示例](../网页/包说明.文言.md)。

## 诺节

于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 库/界面/示例/自绘 dist/界面自绘示例 --包根 库/界面 --包根 库/显示控件 --包根 库/字体
node dist/界面自绘示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 为已装 `@kmamal/sdl` 之目（含 `node_modules` 之层），见诺节宿主之说明。自动验收则加 `--显示面后台`，窗不夺前。

## 浏览器

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 库/界面/示例/自绘 dist/界面自绘示例网页 --包根 库/界面 --包根 库/显示控件 --包根 库/字体
cp 库/界面/示例/自绘/页面.html dist/界面自绘示例网页/index.html
```

页中之 canvas 满视口，`字体/无衬线.ttf` 须自置一含中文之字体文件（如 macOS 之 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`；以 `wrangler dev --assets` 伺之，则单文不得逾 25 MiB）。乃以静文之服伺其产物之目，以备 WasmGC 与 JSPI 之浏览器启之。

## macOS 原生（arm64）

不绑适配而径构之，显示与字体二接口由执行器实之，见[原生窗口方案](../../../../豫言操作系统/文档/原生窗口方案.文言.md)；`yy客体二号.wasm`、`yy原生生成.wasm` 之构建之令见[客体二号](../../../../豫言操作系统/裸机/客体二号/说明.文言.md)。于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 界面自绘示例 --输出 yy界面自绘示例.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=512 node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm 苹果 臂六十四 yy客体二号.wasm yy界面自绘示例原生 yy界面自绘示例.wasm --预编
chmod +x yy界面自绘示例原生
./yy界面自绘示例原生 --授权显示面 主窗口=800x600
```

自动之验加 `--显示面后台`，窗不激活，置于他窗之后。
