# 界面测试

界面库（`库/门面`）的单元测试：颜色（色码、三原色、加透明、转 CSS 文字）、样式转 CSS（单条声明、样式组与条件样式的展开、状态变体的伪类规则、类名稳定）、元素标识、界面树转 HTML、事件转消息（冒泡、禁用、段落里的链接）、消息映射（映射后各种事件得到包着内消息的外消息，HTML 与映射前相同）与新旧界面树差分；像素图与原样输入（提案 00014，`像素图。测试。豫`：元素原样只交给元素自己、映射后照样得到，自绘把原样交互换成元素原样，文树写成可聚焦的 canvas，差分只在版本号变了或 canvas 新建时画像素，自绘显示树在内容盒放原样热区与像素图节点；为造显示接口的输入事件，本包另依赖显示接口包）；自绘后端的样式求值（继承、状态变体）、布局（竖排、横排的伸展与收缩、对齐、换行排、文字换行、滚动区、绝对定位、百分比、层叠、弹性长度求解）与显示树的热区，文字用假量具；渲染节点（提案 00011 议二）：同一串界面树分别整棵重排与比对沿用，布局盒树逐项相同、画布逐像素相同（另用增量绘制重画一份，也逐像素相同），没变的帧不再量文字，只改一处时只重量那一处（这项用测试字体画字，所以本包另依赖字体与字体测试）。需要单元测试框架，所以独立成包。各 `X。测试。豫` 由全树测试自动发现运行。
