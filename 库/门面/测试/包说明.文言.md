# 界面测试

界面库（`库/门面`）之单元测试：色（色码、三原色、加透明、译为 CSS 之文）、样式译为 CSS（单项之声明、样式组与条件样式之展、态变之伪类规则、类名之恒）、元素之标识、界面之树译为 HTML、事转消息（冒、禁、段中之链）、消息之映（映后诸事皆得包内消息之外消息，HTML 同于映前）与新旧界面之树相较；像素图与原样之入（提案 00014，`像素图。测试。豫`：元素原样惟交其元素、映后亦得之，自绘易原样交互为元素原样，文树书为可得焦之 canvas，差分惟于版号易或 canvas 新建时画素，自绘显示树于内容盒置原样热区与像素图之节；为造显示之约之输入，此包另依显示之约之包）；自绘后端之样式求值（相承、态变）、布局（竖排、横排之伸缩、对齐、换行排、文之换行、滚动区、绝对定位、百分、层叠、弹性之长之解）与显示树之热区，文用假量具；渲染之节（提案 00011 议二）：同一串界面之树，各以全排与比对沿用为之，盒树逐项皆同、所画逐素皆同（复以增量之画重画一份，亦逐素皆同），未变之帧不复量文，惟改一处则惟复量其处（此项以测试字体画文，故本包复依字体与字体测试）；锦囊（提案〇〇〇四八，`锦囊。测试。豫`：副击处上求锦囊与囊钮、内建编辑之单、开囊与囊述、键与指、贴边之翻、并映树；程序出囊之路 `开囊于标` 依元素之框定锚、子囊滚之偏与可见之区、数面会话之 `囊座` 换面闭旧囊）。须单元测试之框架，故别立为包。诸 `X。测试。豫` 由全树测试自寻而行之。

文树锦囊（提案〇〇〇四八第四条，`文树锦囊。测试。豫`）：副击处之元素有锦囊则「诸策述」与自绘同一份策，无则可无；囊钮之策、开囊后之囊标与囊述（含方向下之键换选）、囊图转超文（名、键示皆在，元素之标易为 data-锦）逐项核之。
