# 界面文树

[界面库](../包说明.汉语.md)的浏览器文树后端：把界面树译成 HTML 与 CSS 交给浏览器，排版、字体、绘制、输入法与无障碍都由浏览器做。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md` 九·二。

## 用法

```yuyan
寻观「门面篇」之书。
「行门面」于『待办容器』于「初始模型」于「视图」于「更新」。
```

页面里放一个该 ID 的容器元素（大小由页面定，通常撑满视口），并用浏览器宿主的 `自动启动.mjs` 启动应用；应用用 `豫构 发行 浏览器` 构建。样式由本后端装进页面，页面只需给容器定大小。

要处理不是界面事件的网页事件（如浏览器编译的进度与结果、定时、请求进度）时用 `「行门面带外事」于 容器 于 初始模型 于 视图 于 更新 于 外事`：外事是 `化「结绳」又化「模」为（「或可有」于「模」）`，收到不是界面事件的网页事件（结森）与当前模型，给出新模型就照常重画，给出可无就略过。`行门面` 等于外事一律给可无。

## 做什么

- 启动：容器加类名 `界根`；用网页文树 0.4.0 的 `增页样式规则` 装基础样式表与界面用到的样式规则；界面树译成 HTML 放进容器；第一个带「自动聚焦」的元素取得焦点（文本框与多行文本框按 ID `输入-标识` 聚焦）；在容器上委托订阅 `click`（阻止默认，所以链接不跳转、复选框由模型决定勾选）、`input`、`select`、`keydown`（命令或控制加 S 由宿主当场阻止浏览器存网页的默认动作，事件照常交给应用）、`focusin`、`focusout`，记下各订阅号。
- 首屏接管：服务端或构建时可以用界面库的「首屏容器超文」生成首屏容器，它带 `data-yyhash`（首帧 HTML 的散列）。启动时算出的首帧散列与之相同，就直接接管容器里已有的节点，不重画；散列不同或没有这个属性时照常放入首帧。
- 事件：按事件载荷的「操作键」（最近的 `data-yy`，即元素标识）换成元素事件，交界面库的「事作信」；文本框里按回车（不在组字中）算提交；浏览器键名换成显示接口的中文键名（Enter→回车 等）。
- 更新：调应用的更新与视图，与上一棵界面树差分（界面库的「较门面」），按 `data-yy` 查到节点后逐项改；新出现的样式规则按类名去重后补装。文本框的值只在模型给的文字与浏览器里的现值不同时才写回，免得打断输入法组字；写回时按 ID `输入-标识` 用网页界面的「设节值」。
- 按键重排：容器的子元素都带键、键各不重复时，差分给出「重排子节点」；本后端沿用页面里同标识的旧节点（先原地改好），新出现的子元素用 HTML 建在一个临时节点里取出，再用 `易页子节` 按新次序整体换上，所以增删、移动列表项只动有变化的项。
- 文本着色：带「文本着色」属性的多行文本框写成三层。外框 `div` 带元素的类名、标识与可变属性，是滚动容器；里面一个网格，着色层（按着色区间生成带颜色类名的 `span`）与 `textarea` 叠在同一格。`textarea` 文字透明（`-webkit-text-fill-color: transparent`），光标、选区与输入法照常；两层同字体、同字号、同行高、同字距，都不自动换行。网格随着色层的文字长高长宽，`textarea` 撑满网格而不自己滚动，滚动由外框统一做，所以两层始终对齐；输入时差分改 `textarea` 的值并重画着色层。颜色写成只含字色的样式类，页面不需要 `style` 属性。
- 像素图（提案 00014）：写成 `canvas`（类名 `界像`，带「原样输入时」时 `tabindex="0"` 可聚焦）。首帧放好之后、差分给出「画像素」时（版本号或尺寸变了，或 canvas 随重画内容、重排新建），用网页文树 0.6.0 的「画页画绢像素」把整块像素写进 canvas，宽高与 canvas 属性不同时宿主先改属性；版本号不变时不重画。有焦点的原样像素图上的按键按下换成「元素原样」交给它的「原样输入时」。
- 锦囊（提案 00048）：容器上再叠一层透明的整容器幕（类名 `界根 锦幕`，不挡指针）；副击（右键）与囊钮点击按元素的「锦囊」「囊钮」属性取策，用门面自绘的同一套「寻囊」「寻钮」「开囊」「囊视图」「理囊入事」：菜单树转成超文放进幕里，元素标识从 `data-yy` 换成 `data-jin`，免得与应用元素相撞；样式照主站主题（纸色、墨色与朱色）。囊开着时在容器上临时订阅 `mousemove`，指针移动、主键点击与按键先交「理囊入事」，选中的一项把「信」交应用的更新，与自绘同一条路。副击订阅排除 `input`、`textarea`，文本框仍用浏览器自带的编辑菜单。
- 关闭：宿主关闭事件队列时，取消启动时记下的界面事件订阅与指针移动订阅，去掉锦囊幕，释放容器句柄，然后结束。

## 待办事项

- 自动聚焦只在启动时做。
- 像素图：原样输入只交按键按下，按键抬起、文字输入、组字与指针留待后续版本（浏览器里没有外部程序）；这时祖先元素的「按键时」收不到该键。canvas 按 CSS 像素一比一显示，像素比不为一时与自绘的物理像素一比一不同。
- 带着色的多行文本框，`placeholder` 与 `disabled` 的变化落在外框上，`textarea` 保持首帧的值。
- 着色层在更新之后才显示新输入的字，每次输入都要走一遍更新、视图与差分；大文件逐键输入的延迟留待后续版本优化。
- 拼写检查：属性白册里加入 `spellcheck` 之后再给源码框关掉。
- `设页节超文` 一次至多 2 MiB、深度至多 32，着色层（正文加着色标签）与 `textarea` 各存一份正文，几百 KB 以上的源码文件会超限。
- 锦囊：滚轮（子囊滚动与根面板滚动）留待后续版本；容器尺寸变化后菜单不重排，关掉再开才按新尺寸排；开着时的方向键、空格不阻止浏览器默认动作（工作台容器通常不滚，其他页面可能滚）。
- 锦囊：文本框没有「锦囊」时给浏览器自带的编辑菜单，内建编辑菜单（剪切、复制、粘贴、删除、全选）留待后续版本。

文树后端订阅文本框 `select` 事件，复用网页界面的读取输入光标接口，按码点起止位置产生元素选区事件。文本框生成 `输入-` 前缀节点标识供接口读取。

文本框声明“编辑时”时，浏览器输入事件传入全文及当前码点光标；其余输入沿用“输入时”。编辑事件同步更新现值表，差分时保留浏览器已输入的值。
