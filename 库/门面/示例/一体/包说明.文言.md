# 一体引擎之示例

待办之单在[门面宿](../../../群书/网页部/门面宿/包说明.文言.md)（三约落于篇象、章法、设色、匠心）上之离屏示例：`一体启` 设视口与页范，界面文树后端（门面篇）建树、排版、出图，`一体存图` 以一帧存为塔加图（TGA），并印帧数与帧耗；次以门面自绘之端，同树排一帧、画入画绢、亦存一图，以照字体、间距与颜色。

构而行之（仓根；常构依包图自绑三约于 `豫言操作系统/适配/` 下 `网页文树原生`、`网页界面原生`、`网页事件原生` 三适）：

```sh
./豫构。林纳。豫行 构建 界面一体示例 --输出 界面一体示例。林纳。豫行 -j 12
./界面一体示例。林纳。豫行
```

产物在 `草稿/`：`一体待办。塔图` 与 `自绘待办。塔图`。塔加图可由图像之具转为网便之图而观。
