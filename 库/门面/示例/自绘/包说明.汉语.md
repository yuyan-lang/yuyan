# 界面自绘示例

待办清单（包「门面待办例」）经[界面自绘](../../自绘/包说明.汉语.md)后端运行，显示面名为“主窗口”。同一份应用在浏览器文树后端的版本见[界面网页示例](../网页/包说明.汉语.md)。

## 诺驿

在仓库根目录：

```sh
./豫构。林檎。豫行 发行 节点 库/门面/示例/自绘 dist/界面自绘示例 --包根 库/门面 --包根 库/器物 --包根 库/字模
node dist/界面自绘示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 是装了 `@kmamal/sdl` 的目录（含 `node_modules` 的那一层），见诺驿宿主说明。自动验收时加 `--显示面后台`，窗口不抢前台。

## 浏览器

```sh
./豫构。林檎。豫行 发行 浏览器 库/门面/示例/自绘 dist/界面自绘示例网页 --包根 库/门面 --包根 库/器物 --包根 库/字模
cp 库/门面/示例/自绘/页面.html dist/界面自绘示例网页/index.html
```

页面里的 canvas 撑满视口，`字体/无衬线.ttf` 须自行放一个含中文的字体文件（如 macOS 的 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`；用 `wrangler dev --assets` 伺服时单个文件不能超过 25 MiB）。再用任一静态文件服务伺服产物目录，用支持 WasmGC 与 JSPI 的浏览器打开。

## macOS 原生（arm64）

不绑适配直接构建，显示与字体两个接口由执行器实现，见[原生窗口方案](../../../../豫言操作系统/文档/原生窗口方案.汉语.md)；豫构默认由编译器连同执行器 `执行器。树码`（仓库目标「全部」生成，见[客体二号](../../../../豫言操作系统/裸机/客体二号/说明.汉语.md)）直出原生程序。在仓库根目录：

```sh
./豫构。林檎。豫行 构建 界面自绘示例 --输出 界面自绘示例原生 -j 24
./界面自绘示例原生 --授权显示面 主窗口=800x600
```

自动验收时加 `--显示面后台`，窗口不激活、放在其他窗口之后。
