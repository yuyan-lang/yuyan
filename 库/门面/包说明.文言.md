# 界面

像素图可带「原样输入区域」，其参为可选之左、上、宽、高四元，以内容左上为原点，度为逻辑六四。自绘授此矩于显示控件；得焦则报宿主以定输入法候选窗。区易则增像素图版号，可无则清其示。

显示控件已循实输入生按下、移动及抬起之事，经自绘转而交 `指针时`；按下之标存至抬，指离热区犹可回传。窗拖之态与 HTML 后端犹待接，后文显示输入待生之早录已旧。

`指针时` 处置三整数：阶段（零按下、一移动、二抬起）、绝对横纵坐标（逻辑像素乘六十四）。`元素指针` 循祖冒泡，禁用元素循旧拒消息之法。今惟成事模与自绘之转；显示输入生事、窗口捕获拖移及 HTML 后端犹待接。

自绘文框可用 `编辑时` 回调受全文与码点光标之位，含改文与移标；旧 `输入时` 犹受改文，两者可各用，免同模重处改文。HTML 后端尚未接此回调。

文框可带 `光标定位 于 请求序号 于 码点位置` 之属。自绘后端每控件惟施新非负之序，随后鼠标与编辑键之移存之；客欲复定位则增序。此属供定候选、复历史诸程序改文。今 HTML 之生惟存普通文框之出，定位由自绘后端行之。

高层界面布局之言：HTML 与 CSS 于豫言之对应，书为常豫言之库（嵌入之式，不易编译器）。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md`。

客以元素之术书界面之树（犹 HTML），以「样式」之值书样式（犹 CSS）；界面之树依客之消息为参，事之处置直出客之消息。界面之述可译为 HTML 与 CSS 以授浏览器，亦可授自绘之后端排而画之。

## 诸模

- `元素`：界面、行内、属性之类；元素之术 竖排、横排、层叠、滚动区、文字块、段落、按钮、文本框、复选框、像素图、整块像素图、混合像素图、可点、分隔线、留白、空元素、带键；行内之 纯文、文片、链接、断行；属性与事 点击时、输入时、提交时、切换时、按键时、聚焦时、失焦时、原样输入时、占位、禁用、自动聚焦、悬停提示；原样之入与像素图之资之类；取元素诸项之术，「种类像素图」「属有原样入」。
- `样式`：样式与对齐之构造（尺寸、盒、弹性、定位、文、合与四态之变）。长短以逻辑之素计。
- `颜色`：色为整数 0xRRGGBBAA；色码（#rgb、#rrggbb、#rrggbbaa）、三原色、加透明、透明色，及译为 CSS 之文与整数。
- `标识`：元素之标识（树之径加键）与判祖。
- `常样式`：根与诸元素之默认，二后端共之。
- `生样式表`：样式译为 CSS 之声明与规（类名取声明之文之散列），基础样式表（结构之式与默认之式）。
- `生超文`：界面之树译为 HTML 与所需之样式规则（每元素带 `data-yy`＝元素之标识）；元素可易之属性；子元素或行内之片之 HTML 片；全树所用之（类名，规）对；全页之 HTML（静页用之）；首屏之散列与首屏容器之 HTML（服务端或构建时生首帧，文树后端依之而接）。带「文本着色」之多行文框书为外框、着色层与透明文之 textarea 三层，着色层依域生带色类名之 span。
- `处理`：易元素之事（点击、输入、提交、聚焦、失焦、按键、原样之入，带元素之标识）为客之消息：依标识寻其元素或段中之链，取其事之处置；点击、按键循祖而冒，原样之入惟交其元素；禁者不生消息。二后端共之。
- `差分`：新旧界面之树相较，得文树之改（改类名、改属性、删属性、改文、重画其内、改输入之值、改选、重排子节点、画素），文树后端依之改页。诸子皆带键、键各不重，则依键重排，同形之旧节移而就地相较；带着色之多行文框，文或着色有变则重画着色层；像素图之版号或尺寸易，或其 canvas 方新建（首帧、重画其内、重排新建），则加一画素之改，列于建 canvas 之改之后（「置像素图画改动」）。
- `映射`：`映射消息 于 换消息为 函 于 元素为 树` 易出旧消息之界面树为出新消息者：诸元素之属与段中行内之片，其事之处置（点击时、输入时、编辑时、选区时、提交时、切换时、按键时、聚焦时、失焦时、指针时、原样输入时）皆接以易消息之函，按键之处置得可无者仍可无；种、键、样式、文、选与非事之属皆如故，故标识、HTML 与样式之规皆同于映前。上层之界面以之包子视图之消息于己之消息类，平铺桌面以之接工作台之视图于外壳。
- `文字具`：库内用之取余、十六进、散列与超文本转义，由库内诸模径导之。

## 用法

```yuyan
寻观「豫章」之书。
寻观「门面」之书。

「页面」乃「样式」也。
「页面」者「样式组」于「列」【「内距」于「24」，「间距」于「16」】也。

「首页」乃（「门面」于「有」）也。
「首页」者「竖排」于「列」【「页面」】于「列」【「文字块」于「列」【「粗体」】于『你好』】也。

「页面文字」者「整页超文」于『示例』于「首页」也。
```

包子视图之消息于外层之消息：

```yuyan
「外壳信」立「类」也。
　「工作台来信」立化「书斋信」为「外壳信」者也。

「外壳观」乃化「外壳状态」为（「门面」于「外壳信」）者也。
「外壳观」者得「态」而
　「映射信」于「换消息」曰「工作台来信」于「元素」曰（「书斋观」于（「态」中「工作台」））
也。
```

公名皆二字以上之专名：库所出之名，夺客「鉴」中同名之模式变量。

## 像素图与原样之入（提案 00014）

`像素图 于 样式们为 … 于 属性们为 … 于 像素宽为 宽 于 像素高为 高 于 像素为 字节串 于 版本号为 版 于 变化左为 左 于 变化上为 上 于 变化宽为 宽 于 变化高为 高` 显一块 RGBA8 之素（透未预乘，每素四字，红居低址，行距为宽乘四）；`整块像素图` 省所变之区，取全图。`混合像素图`（参同 `整块像素图`）依透明度而混：自绘后端以源上之法叠之于已画之底，透处露底，图标库用之。其大小由样式定之，同于他元素。画易则调用者加版号，并示自前版以来所变之区（依像素图之物理之素）。

- 自绘后端自元素内容盒之左上依物理之素一比一逐行全抄而贴之，逾内容盒者裁之，不足者露其底。版号恰加一则惟重画、惟交所变之区；跳号或位置、尺寸易则全块重画。缩放待后。
- 文树后端书为 `canvas`（类名 `界像`），以网页文树零点六之「画页画绢像素」全块书其素：首帧、canvas 新建与版号或尺寸易时各书一次，版号未易不重画。canvas 依 CSS 之素一比一自左上显之，逾元素盒者裁之。
- 属性 `原样输入时 于 处置之函` 使像素图可得焦。其得焦，则键之按抬（键名同显示之约，修饰之键亦交）、文字之入、组字之更皆原样交其函；指在其上，则指之移（不按亦交）、按、抬（诸钮，零为主键）与滚轮亦交其函，坐标与滚量为以像素图左上为原点之物理之素。其函受「原样入」而还客之消息。「原样入」之构与显示之约之「输入事件」一一相当：原样按键按下、原样按键抬起、原样文字输入、原样组字更新、原样指针移动、原样指针按下、原样指针抬起、原样滚轮；指类之构带「横」「纵」「按钮」「横量」「纵量」之标；欲还为显示之约之输入（以转于外部程序），用界面自绘之「原样入作入事」。元素之事「元素原样」惟交其元素，不冒。
- 自绘后端中，原样之入不经控件库之制表轮焦、键滚、剪贴之键与回车之点；非修饰之键另交一按键之事，祖元素之「按键时」犹得之（平铺桌面外壳之快捷键赖之）。主键之按、移、抬仍交祖之「指针时」；按主键之时，移与抬为所按之像素图所捕；滚轮不复滚外之滚动区。
- 文树后端中，交得焦像素图上之键按（浏览器无外部程序）；键抬、文字之入、组字与指皆待后。

```yuyan

　「像素图」
```

## 待办

样式之求（自绘用之）与自绘后端别包为之，文树后端在 `文树/`（包「门面篇」）；诸子半带键者仍整段重画；态变之内复套态变者惟记内态；键含斜者依首判祖或误；超文本转义逐通字符而易，长文稍迟。

## 多行文本框

`多行文框` 受样式、属性与全文，输入按键之回调同单行文框。自绘后端依逻辑行而绘，治跨行之光标、选区与粘贴；浏览器文树后端生原生 `textarea` 而更其今值；带「文本着色」者，文树后端于 `textarea` 下叠一同字体同排版之着色层，`textarea` 之文透明，两层由同一外框滚动。回车入换行，控制或命令加回车则提交。撤销重做由客依文存其史。

元素键之 `%` 与 `/` 于内部标识各书为 `%25` 与 `%2F`，文件路径之键仍为一级。事之寻与循祖冒泡共此编码，免子文件之事为同名目所截。

`选区时` 受起位与止位而生客之消息，`元素选区` 依元素标识付此回调。位用编辑控件之码点序。控件与浏览器实选区之事件输出续接。

`件有编辑回音` 依界面树及元素标识，验其有无编辑回调之声明，以供后端择事件之路。

多行文框之 `行号栏` 属性定逻辑像素栏宽，自绘后端显始于一之行号。
`文本着色` 属性受全文字符始止之位及合 RGBA 色之三元组列，自绘多行文框逐行绘之。
