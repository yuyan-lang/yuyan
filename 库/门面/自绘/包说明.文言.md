# 界面自绘

像素图之「原样输入区域」易为依定标而存之矩，其位依内容之左上。显示控件绘时加窗之布局偏位、滚动平移及素比，循文框之路以设候选窗。

`行门面…` 一族入口（自 `行门面尺寸比计时保位缩放会话` 始）诸参皆系标签，标签之名同族相一：面名、初态、视图、更新、应停、结束归还、计时间隔、计时更新、保位、缩放、提前醒计时；多面之版另有「诸面」与「面报」二标签。视图之回调另受宽、高、素比，此三参亦系标签。`行门面尺寸比计时保位缩放会话` 以应用之态之缩放函授显示控件，视图受有效素比。旧尺寸比会话取自动缩放。

`行门面尺寸计时保位会话` 于尺寸计时会话诸参末增保位之开关，接显示控件之窗会话滚动缓存。应用以恒定元素键别文件与视图；旧尺寸计时入口常闭保位。

显示控件已生指针输入之事，自绘之转与父元素之冒皆可承；窗拖之态犹待接，后文未生显示输入之早录已旧。

自绘运行全转 `指针交互` 为 `元素指针`，交界面之 `指针时` 处置，共父元素冒泡。此阶段未生显示输入指针事，窗拖犹待接。

`行门面计时会话` 于会话之参后接模型计时之距与更新之术，直授显示控件之计时循环。计时更新不造键鼠之事，亦不重造焦点之态。旧会话不启计时。

`行门面会话` 于停止之判后受“结束归还”之标，授控件主循环。用户态桌面授阳，归调用者前归此显示之会；旧界面入口授阴，存宿主掌面之行。

主循环之 `编辑改变` 化为 `元素编辑`，以 `编辑时` 回调授全文与码点之位于模型。此独于旧输入之事，客择一改文回调用之；模型未接此属则循旧行。

文框之 `光标定位` 属生 `光标定位节点`，授显示控件施一次之光标请。无定位属者循旧编辑之行；同序不覆随后鼠标与键盘之移。今惟控光标之位，尚未逐移报于模型。

[界面库](../包说明.文言.md)之自绘后端：于[显示控件库](../../显示控件/包说明.文言.md)之主循环行模型—视图—更新，自求样式、自排之，生显示之树而交显示控件库画之。可行于诺驿之窗（SDL）与浏览器之 canvas，他日接豫言系统之原生窗口。方案见 `豫言操作系统/文档/界面布局语言方案.文言.md` 九·一。

## 用法

```yuyan
寻观「门面自绘」之书。
「行门面」于「面名」曰『主窗口』于「初态」曰「初始模型」于「视图」曰「视图」于「更新」曰「更新」。
```

首参为显示面之名，由运行之境授之：诺驿以 `--授权显示面 主窗口=800x600`，浏览器以 `<canvas data-yy-显示面="主窗口">`。应用以 `豫构 发行 节点|浏览器` 构之，其步见[界面自绘示例](../示例/自绘/包说明.文言.md)。同一应用易为文树后端，惟改所导之包与首参。

## 诸模

- `计算样式。豫`：每元素之计式为一整数之数组（每式一槽）加字体族。文之属性承于父，余取默认；次第施种之默认、元素之样式列（样式组就地展之，条件样式依条件取舍），复依交互之态叠悬停、焦点、按下、禁用之变。
- `样式树。豫`：界面树之每元素配其标识与计式；文类之元素备其文片，段中之链依己之悬停、按下之态上式，并记其片序与标识。悬停、按下依标识之首及于其祖，焦点惟视其身。「求样式树比对」复较前帧同标识之节（提案 00011 议二）：子之标识之序同则依位相配，全子树关排、关显之入（种、像素图之版号与素之宽高、计式、文、文片、链、选、禁、可点、自聚焦、有无原样之入、占位之文、行号栏、文本着色、光标定位）皆同则标「未变」；事之处置不较，依标识寻之。像素图易画（版号易）则不为未变，免沿前帧之盒而画旧图。
- `布局。豫`：布局之擎，长短以六十四分之一逻辑之素计。竖排、滚动区依纵之弹性排之，横排依横之弹性排之（可换行排），层叠叠诸子于内容盒，绝对定位依父之内距盒；伸缩依 CSS 弹性盒九点七节之冻循环解之；自动之最小尺取内容之最小尺，滚动区、裁剪与省略号之元素为零；百分依容块。
- `显示。豫`：以布局盒生显示之树。底与边画为方框（四边宽或色异，则于底框之中画四细边）；文类之元素画文字之节；文本框、滚动区用显示控件之文本框节与滚动节；复选框自画其方。钮、复选框与可点之元素外包可聚焦之钮热区，余元素外包区域热区，悬停、按下与点击之冒皆赖之；段中之链依排之片段各置一链热区；聚焦之控件外画焦点之环。像素图（提案 00014）于内容盒置一热区（带「原样输入时」则为可聚焦之原样热区，可点则为钮热区，否则为区域热区），中为画框即内容盒之像素图之节，不另包外层之热区；聚焦则外画焦点之环。
- `渲染节点。豫`（不在默认导入）：渲染之节（提案 00011 议二）。依标识跨帧记诸约束（定宽、定高）下之布局盒；排前清已变之节之记，排时同标识、同约束者径用前帧之盒，不复下排。每标识至多存八约束，标识至六万五千五百三十六则尽清之；像素比变则运行易新表。内在宽之记留待后版。
- `运行具。豫`：「修饰有位」「原样入自」「原样入作入事」「交互作件事」「并映树」「开锦囊」——单面与多面二会话共用之具：修饰之位、显示之约之入与界面原样之入之两易、交互之事易为元素之事、以锦囊之树接于客树之后而加摄事之节、依副击或囊钮之标开囊。本在「运行」篇，既拆而出，犹在默认导入。
- `运行。豫`：单面之会话之入（「行门面」等一族）：惟予一面局，转调「诸面运行」之「行门面诸面会话」；视略面名而受广高与素比，面报不易模，签名与标如旧。窗闭则还，有误则印「界面自绘：…」，还面之败则附其说于果后。入口诸参皆系标签（见前）。故此包径依显示之约之包。
- `诸面运行。豫`（不在默认导入）：「行门面诸面会话」（提案 00047 议六），多面之模型—视图—更新，行于显示控件库之多面主循环（「诸面循环」）。诸参系标签，与「行门面尺寸比计时保位缩放会话」同名，另有「诸面」（面名与题，首为主面）与「面报」（「映面未得」「映面已闭」）二带标签之参；视多携面名。每面初用则各立其元素之树、焦点、样式之树与排版之存。每帧之视图回调次第求样式树而较前帧（根之标识为 0）、清已变之节之排记、依视口排之（未变之子树沿用前帧之盒）、生显示之树；控件库所交之交互之事，依元素标识易为元素之事（焦点改变析为旧焦之失焦与新焦之聚焦，无焦点之按键落于根元素；原样交互中显示之约之输入经「原样入自」易为界面之原样之入，成「元素原样」），复由界面库之「事作信」依彼面之界面树易为客之消息而授更新。「原样入作入事」反之，易界面之原样之入还为显示之约之输入，平铺桌面以之转像素图所受之入于外部程序。单面之「行门面尺寸比计时保位缩放会话」以一面局调之，即其特例。

## 与文树后端之异

布局之规取 CSS 之定义，同一界面于二后端所排之矩当同，其异出于字形与断行。已知之例外：层叠之主轴对齐为居中或靠末，其宽犹满容器（CSS 网格缩其轨至内容之宽）；换行排之多行依起而叠，不依 align-content 拉伸；钮为鼠所点，亦画焦点之环。

## 待办事项

悬停提示；链之焦点之环；复选框画真勾；换行排之行拉伸与层叠依网格之轨对齐；长列惟排视口中之行；与无头 Chrome 之布局对照之测。

## 验证

单元测试在 `../测试/自绘布局。测试。豫`：样式求值、布局与显示之树，文用假量具（每码等宽）。例行于诺驿与浏览器之步，见[界面自绘示例](../示例/自绘/包说明.文言.md)。

## 客之主动结束

`行门面可止` 于旧入口诸参之后接“模型 → 爻”之止条件，授显示控件之可止主循环。初模已终则不造界面、不取显示面；更新至终模则循环还。旧 `行门面` 循旧行。

试见 `../测试/主动结束。测试。豫`：终初模不调视图与更新，亦不须显示面之授权；已构建而行，皆过。

控件之 `选区改变` 化为 `元素选区`，客由 `选区时` 受真实码点之域。

多行文框之 `行号栏` 化为显示节点末尾之逻辑六四栏宽，正文区域同步避让。

`行门面尺寸计时会话` 于每帧视图回调传逻辑六四窗口宽高及模型，应用可依窗口之尺调布局。首树以零尺初建，绘时用显示面实尺。
`行门面尺寸比计时保位会话` 同 `行门面尺寸计时保位会话`，视图回调别受像素比（乘六十四之整数，Retina 为百二十八，首树取六十四），平铺桌面之外程序格依之以物理之素定子程序显示面之尺（提案 00014）。
多行文框之 `文本着色` 属性传入多行着色显示节点，焦点行及余行共全文字符之域。
「排版根」为量文之具别建惟属此次根布局之段落测量之存，键含正文、片界、文字全式、段参及宽。运行改用「排版根带存」，段排赖显示控件之全局排存（提案 00011 议一），不复包此层。

# 锦囊（提案 00048）

`锦囊` 者，门面自绘之弹出单也：以元素之 `锦囊` 属性所授之策画为单，或为文框画内建编辑之单（剪切、复制、粘贴、删除、隔线、全选）。`寻囊` 自副击处的标而上求首带 `锦囊` 之元素（含行内之片），`寻钮` 取 `囊钮` 元素自具之策，`寻文框` 判文框之禁；`编辑项们` 依有选、禁、林檎三事造内建编辑之单之键示与可否。`囊视图` 以 `囊态` 排为门面之树与 `囊盘`（诸层面之框、行框及整高），`囊述`、`盘述` 书为文以资试核。指与键由 `理囊入事` 处之：移惟易所选而行、过策囊则展，主键择一或闭，轮滚根面，上下逾策隔与不可用，左右展开收层，起首、末至两端，退出闭囊，面之尺寸变则闭。`囊定`、`囊移`、`囊展`、`出囊` 主择、移、展与交信；内建编辑之单之项交其命之名，由 `运行`、`诸面运行` 授 `行编辑令`。

`运行`、`诸面运行` 每面各存锦囊之态、版面及前帧之视口；开囊以 `副击` 之坐标或 `囊钮` 元素之框为锚，副击落于文框而无囊则予内建编辑之单。锦囊之显示树求样、排版而后接于客树之后，客元素之标与子序不易；开囊时其树带 `摄事节点`，显示控件还原始之入，本会话先授 `理囊入事`，未用者复循原路为客之事。所择之项以其 `信` 交更新，内建编辑之单之项易为 `行编辑令` 之交互事，仍循更新之路。副击处无囊又不落文框则惟闭囊。
