# 界面自绘

像素图的「原样输入区域」转换成按稳定标识保存的矩形，位置相对内容左上角。显示控件绘制时加入窗口布局偏移、滚动平移和像素比，沿用文本框的候选窗设置通路。

`行门面…` 一族入口（自 `行门面尺寸比计时保位缩放会话` 起）的每个参数都带标签，标签名在同族各入口之间统一：面名、初态、视图、更新、应停、结束归还、计时间隔、计时更新、保位、缩放、提前醒计时；多面版另有「诸面」与「面报」两个标签。视图回调另收宽、高、像素比，这三个参数也带标签。`行门面尺寸比计时保位缩放会话` 把应用状态的缩放回调交给显示控件，视图收到有效像素比。既有尺寸比会话采用自动缩放。

`行门面尺寸计时保位会话` 在尺寸计时会话参数末尾增加保位开关，接入显示控件的窗口会话滚动缓存。应用以稳定元素键区分文件与视图；原尺寸计时入口默认关闭保位。

显示控件已产生指针输入消息，自绘转换和父元素冒泡已可承接；窗口拖动状态尚待接入，后文“尚不产生显示输入”的早期记录已过时。

自绘运行将 `指针交互` 完整转换为 `元素指针`，由界面的 `指针时` 回调处理，并复用父元素冒泡。此阶段尚不产生显示输入指针事件，窗口拖动待接入。

`行门面计时会话` 在会话参数后接模型计时间隔及模型更新函数，直接交给显示控件计时循环。计时更新不合成键鼠事件，也不重建焦点状态。旧会话入口不启用计时。

`行门面会话` 在停止判定后接“结束归还”标记，传给控件主循环。用户态桌面传真，返回调用方前归还本次显示会话；原界面入口传假，保持宿主管理显示面的行为。

主循环的 `编辑改变` 转为 `元素编辑`，通过 `编辑时` 回调把全文及码点位置交给模型。它独立于原输入事件，应用选择一个改文回调使用；模型尚未接此属性时保持原行为。

文本框的 `光标定位` 属性生成 `光标定位节点`，委托显示控件应用一次性光标请求。无定位属性的文本框保持原编辑行为；相同请求序号不覆盖后续鼠标及键盘移动。当前只控制光标位置，尚未向模型报告每次光标移动。

[界面库](../包说明.汉语.md)的自绘后端：在[显示控件库](../../器物/包说明.汉语.md)的主循环上运行模型—视图—更新，自己求样式、排版，生成显示树交显示控件库绘制。能在诺驿窗口（SDL）与浏览器 canvas 上运行，以后接豫言系统的原生窗口。方案见 `豫言操作系统/文档/界面布局语言方案.汉语.md` 九·一。

## 跟随末尾

滚动容器套「随末」（跟随末尾）装饰器后，`显示。豫` 在滚动节点的子节点末尾加 `随末节点`。显示控件收交互项时见到它，就把该滚动区的纵向偏移放到末尾；用户往上滚后暂停，滚回末尾又恢复跟随，详见显示控件包的 `交互项` 与 `事理`。文树后端的跟随末尾留待后续版本。

## 用法

```yuyan
寻观「门面自绘」之书。
「行门面」于「面名」曰『主窗口』于「初态」曰「初始模型」于「视图」曰「视图」于「更新」曰「更新」。
```

第一个参数是显示面的名字，由运行环境授予：诺驿用 `--授权显示面 主窗口=800x600`，浏览器用 `<canvas data-yy-显示面="主窗口">`。应用用 `豫构 发行 节点|浏览器` 构建，步骤见[界面自绘示例](../示例/自绘/包说明.汉语.md)。同一应用换到文树后端时，只改导入的包与第一个参数。

## 模块

- `计算样式。豫`：每个元素的计算样式是一个整数数组（每项样式一个槽）加字体族。文字属性继承父元素，其余取默认；依次施加种类默认样式、元素的样式列（样式组就地展开，条件样式按条件取舍），再按交互状态叠加悬停、焦点、按下、禁用变体。
- `样式树。豫`：界面树的每个元素配上标识与计算样式；文字类元素备好文字片，段落里的链接按自己的悬停、按下状态上样式，并记下片序与标识。悬停、按下按标识前缀作用到祖先，焦点只看元素自身。「求样式树比对」另与上一帧同标识的节点比（提案 00011 议二）：子节点标识序列相同就按位置配对，整棵子树影响排版与显示的输入（种类、像素图的版本号与像素宽高、计算样式、文字、文字片、链接、选中、禁用、可点、自动聚焦、有无原样输入、占位文字、行号栏、文本着色、光标定位）都相同时标「未变」；事件处理函数不比，按标识去找。像素图换了画面（版本号变了）就不算未变，免得沿用上一帧的布局盒画出旧画面。
- `布局。豫`：布局引擎，长度用 1/64 逻辑像素。竖排、滚动区按纵向弹性排，横排按横向弹性排（可换行排），层叠把子元素叠在内容盒里，绝对定位相对父元素的内边距盒；伸缩按 CSS 弹性盒 9.7 节的冻结循环求解；自动最小尺寸取内容最小尺寸，滚动区、裁剪与省略号的元素为零；百分比相对包含块。
- `显示。豫`：由布局盒生成显示树。背景与边框画成方框（四边宽度或颜色不同时，在背景方框里画四条细边）；文字类元素画文字节点；文本框、滚动区用显示控件的文本框节点与滚动节点，带「随末」的滚动区另在子节点末尾加「随末节点」；复选框自画方块。按钮、复选框与可点元素包一层可聚焦的按钮热区，其余元素包一层区域热区，悬停、按下与点击冒泡都靠它；段落里的链接按排版片段各放一个链接热区；聚焦的控件外画焦点环。像素图（提案 00014）在内容盒放一个热区（带「原样输入时」时是可聚焦的原样热区，可点时是按钮热区，否则是区域热区），里面是画框为内容盒的像素图节点，不另包外层热区；聚焦时外画焦点环。
- `渲染节点。豫`（不在默认导入里）：渲染节点（提案 00011 议二）。按标识跨帧记下各约束（定宽、定高）下的布局盒；排版前清掉变了的节点的记录，排版时同标识、同约束的直接沿用上一帧的布局盒，不再往下排。每个标识最多留 8 个约束，标识数到 65536 整表清空；像素比变了由运行换新表。内在宽的记录留待后续版本。
- `运行具。豫`：「修饰有位」「原样入自」「原样入作入事」「交互作件事」「并映树」「开锦囊」「开囊于标」——单面与多面两个会话共用的工具：修饰键位掩码里某一位是否置位，显示接口输入事件与界面原样输入的双向换算，交互事件换成元素事件，把锦囊的显示树接在应用显示树之后并加摄事节点，按副击或囊钮的标识开锦囊，按元素标识开它的锦囊（程序请它弹出时用：锚取这个元素在上一帧交互项里的框，落在文本框上给内建编辑菜单）。原在「运行」篇，拆出后仍列在默认导入里。
- `运行。豫`：单面的会话入口（「行门面」等一族）：只给一块面局，转调「诸面运行」的「行门面诸面会话」；视图忽略面名、收宽高与像素比，面报不动模型，签名与标签照旧。窗口关闭时返回，出错时打印「界面自绘：…」，归还显示面失败时说明附在结果之后。入口的每个参数都带标签（见前文）。本包因此直接依赖显示接口包。
- `诸面运行。豫`（不在默认导入里）：「行门面诸面会话」（提案 00047 议六），多面的模型—视图—更新，跑在显示控件库的多面主循环（「诸面循环」）上。参数带标签，与「行门面尺寸比计时保位缩放会话」同名，另有「诸面」（面名与标题，第一项是主面）与「面报」（「映面未得」「映面已闭」）两个带标签的参数；视图多带面名。每块面第一次用到时各建一份元素树、焦点、样式树与排版存。每帧视图回调依次求样式树并与上一帧比对（根标识为 0）、清掉变了的节点的排版记录、按视口排版（未变的子树沿用上一帧的布局盒）、生成显示树；控件库交回的交互事件按元素标识换成元素事件（焦点改变拆成旧焦点的失焦与新焦点的聚焦，没有焦点时的按键落在根元素上；原样交互里显示接口的输入事件经「原样入自」换成界面的原样输入，成为「元素原样」），再由界面库的「事作信」按那块面的界面树换成应用消息交给更新。「原样入作入事」反过来把界面的原样输入换回显示接口的输入事件，平铺桌面用它把像素图收到的输入转给外部程序。单面的「行门面尺寸比计时保位缩放会话」以一块面局调它，是它的特例。

## 与文树后端的差异

布局规则取 CSS 的定义，同一界面在两个后端排出的矩形应当相同，差异来自字形与断行。已知的例外：层叠在主轴对齐为居中或靠末时宽度仍撑满容器（CSS 网格会把轨道缩到内容宽）；换行排的多行按起点堆叠，不按 align-content 拉伸；按钮被鼠标点中后也画焦点环。

## 待办事项

悬停提示；链接的焦点环；复选框画真正的勾；换行排的行拉伸与层叠按网格轨道对齐；长列表只排视口内的行；与无头 Chrome 的布局对照测试。

## 应用主动结束

`行门面可止` 在原入口的参数后接一个“模型 → 爻”停止条件，交给显示控件的可停止主循环。初态已结束时不生成界面、不取得显示面；应用更新到结束模型后主循环返回。原 `行门面` 保持原行为。

测试见 `../测试/主动结束。测试。豫`：结束初态不会调用视图或更新，也不要求显示面授权；已构建运行通过。

控件的 `选区改变` 转为 `元素选区`，应用通过 `选区时` 接收真实码点范围。

多行文本框的 `行号栏` 转为显示节点末尾的逻辑六四栏宽，正文区域同步避让。

`行门面尺寸计时会话` 在每帧视图回调中传入逻辑六四窗口宽高与模型，应用可以随窗口尺寸调整布局。首个界面树使用零尺寸初始化，绘制时使用显示面实际尺寸。
`行门面尺寸比计时保位会话` 与 `行门面尺寸计时保位会话` 相同，视图回调另收像素比（乘 64 的整数，Retina 为 128，首个界面树取 64），平铺桌面的外部程序格据此按物理像素给子程序定显示面尺寸（提案 00014）。
多行文本框的 `文本着色` 属性传入多行着色显示节点，焦点行和非焦点行共用全文字符范围。
「排版根」为文字量具建立只属于本次根布局的段落测量缓存，键包含正文、分片边界、完整文字样式、段落参数和宽度。运行改用「排版根带存」，段落排版靠显示控件的全局排版缓存（提案 00011 议一），不再包这一层。

# 锦囊（提案 00048）

`锦囊` 是门面自绘的弹出菜单：把元素属性 `锦囊` 给的策画成菜单，或给文本框画内建的编辑菜单（剪切、复制、粘贴、删除、分割线、全选）。`寻囊` 从副击处的标识往上找第一个带 `锦囊` 的元素（含行内片），`寻钮` 取 `囊钮` 元素自己的策，`寻文框` 判文本框的禁用；`编辑项们` 按有选区、禁用、是否林檎生成内建编辑菜单的键示与可用否。`囊视图` 把一份 `囊态` 排成门面树与 `囊盘`（各层面板的框、行框与整高），`囊述`、`盘述` 把它写成文字供测试核对，`盘首行框` 取第一层第一行的框（注入点击的测试用它核对命中与画出的行一致）。指针与键盘走 `理囊入事`：移动只改选中行并展开策囊，主键选一项或关囊，滚轮滚指针下的那一层（根与各层子囊各自能滚），上下跳过策隔与不可用，左右展开与收层，起首、末尾到两端，退出关囊，显示面尺寸变化关囊。`囊定`、`囊移`、`囊展`、`出囊` 管选中、移选、展开与交信；内建编辑菜单的项交出命令名，由 `运行` 与 `诸面运行` 交给 `行编辑令`。

多面会话在整个会话里只开一座 `囊座`：最多一份锦囊态，记着它挂在哪块面上（座主）；哪块面开着囊，那块面才画得出来，别的面一有输入（`座让他`）就把它关掉，面关掉时它的囊也关掉。开囊用 `副击` 的坐标或 `囊钮` 元素的框作锚，副击落在文本框上且没有锦囊时给内建编辑菜单；程序请它弹出时（如交替加空格）用 `开囊于标` 在指针下的元素处弹它的锦囊，指在窗口标签上就是那个窗口的窗口菜单，等价壳命令是 `「击键」于「键」曰『交替+空格』`。锦囊的显示树求样式、排版后接在应用显示树之后，应用元素的标识与子节点次序不变；开囊时菜单树带 `摄事节点`，显示控件把原始输入交回，本会话先给 `理囊入事`，未用掉的再按原路作应用事件。选中的一项把 `信` 交应用更新，内建编辑菜单的项换成 `行编辑令` 的交互事件照常走应用更新。副击处没有锦囊也不在文本框上时只关囊。
