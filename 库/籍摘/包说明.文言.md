# 籍摘（内容摘要实现·文言）

籍摘者，登记之籍而摘其要也，接口「豫寓籍摘」之实。原生之东道与豫言之土共此纯豫言之一术：卷之内容算稽古物号，可成批一请而办；目录之摘要依暂存区建树而得树物号；索引以（径、大小、时）为签，签同则径答旧摘；又立单调之版本号，册书于盘，跨程与重启而存。

## 诸篇

| 篇 | 所司 |
| --- | --- |
| 摘要 | 内容之摘、成批之摘、稽古树物之摘、摘要详情、版本之号、索引之状与自版本之变。 |
| 索引 | 条之类型、册之读写、寻条与易条、较签、号之加减、索引状与详情之构造。 |

## 索引与版本

册依东道书于盘，跨程与重启而存。阙在宿主常居之基目下 `豫言籍摘/索引。数据。豫`；境有 `豫言籍摘索引` 则从之。册为数据子语言之文，顶记版本、命中、未中与条目之表；每行记径、大、时（纪元纳秒）、号与摘。书册先书同目之暂文，乃以更名易之。

版本之号自零起，有进而无退。索引核算见所记之径签异或径亡，每处加一；壳命之书、续、焚、更名既成，呼「记写入」，凡经壳之写入亦加一。外人之写入以签核兜底，下次问摘或问号之时计入。

## 目录之摘

目录之摘用稽古由暂存区建树之法：仓中取暂存区所跟踪之常文，工作区已改者依今文重算物号，逐层编为树物而以沙一磨之；空目录得吉特空树号，仓外之目录递归扫常文，深至多六十四层。

## 限

索引之并发写以末书者胜，不设锁；读者或得上一版。构建索引循稽古暂存区之式（与 Git index 同），改之必守零点二版之接口之行。浏览器无可久存之真文件系统，此版于浏览器还空文与零号。变更之表依（版本、径）记于全局缓存之目，惟留近四千零九十六条；「自版本之变」答此后所改之径，录短而所问之版太旧则答「须全量重扫」。
