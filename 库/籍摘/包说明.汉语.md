# 籍摘（内容摘要实现）

籍摘（内容摘要实现，content digest implementation）是接口「豫寓籍摘」的实现库，给原生宿主与豫言操作系统提供同一份纯豫言摘要服务：文件内容的稽古对象号（SHA-1，四十位十六进制）、成批摘要、稽古树对象号、按（路径、大小、修改时间）签名缓存的构建索引、单调递增的文件系统版本号，以及索引状态与变更查询。

## 模块

| 模块 | 内容 |
| --- | --- |
| 摘要 | 内容摘要、成批摘要、稽古树对象号、摘要详情、版本号、索引状态与自版本变更。 |
| 索引 | 索引条目的类型、索引文件的读写、查找与替换、签名比较、版本号加减、索引状态与详情记录的构造。 |

## 索引与版本

索引按宿主存盘，跨进程与重启保留。默认路径是宿主常居基目录下的 `豫言籍摘/索引。数据。豫`；环境变量 `豫言籍摘索引` 有值时用它。索引是一份数据子语言文件，顶层记版本号、命中次数、未中次数与条目表；条目表每行记路径、大小、修改时间（纪元纳秒）、文件号与摘要。写索引先写同目录下的临时文件，再用「更名」原子换上。

版本号从零起，只增不减。索引核算发现已记录路径的签名变化或路径消失时，每处加一；壳命令的文件写入、续写、删除、改名在成功后调用「记写入」，使经壳的写入也加一。外部写入由签名核对兜底，下一次摘要或版本查询时计入。

## 目录摘要

目录摘要用稽古由暂存区建树的办法：仓里取暂存区跟踪的普通文件，工作区改过的按现内容重算对象号，逐层编码成树对象并计算 SHA-1；空目录得 Git 空树号，仓外目录递归扫普通文件，深度至多六十四层。

## 限制

索引的并发写按最后写入者胜，不设锁；读索引的进程可能读到上一版。构建索引沿用稽古的暂存区格式（与 Git index 相同），改动时保持 0.2.0 的接口行为。浏览器宿主没有可持久保存的真实文件系统，本版在浏览器上答空文与零版本。变更表按（版本号、路径）记在全局缓存目录，只留最近四千零九十六条；「自版本变更」答这以后改过的路径，日志截短且所问版本太旧时答「须全量重扫」。
