# 浏览器宿主模拟

下载之模拟可合文片为 Blob，读正文、八位编码字节之长及媒体类型，以对象网址定位字节之物。二进制之片及撤网址后之失效校验，留待后版。

字串全局之柄可行 `String.fromCharCode`，以十六位码元复其文，结森析器合代理之对，下载之器可据此成字节序标。

日期全局之柄可行 `Date.now` 与 `Date.parse`，共用模拟之钟及日期之析器，以定用量报表之初日与筛。

浏览器宿主库（`库/网览东道`）之纯豫言替身。`豫构 发行 模拟` 构之时，抄此包于构建之临目、易其名为“浏览器宿主”，以代真浏览器宿主库；径依浏览器宿主库之应用（用 `网览全局柄`、`网览召法`、`待网览事` 诸柄之反照原语）故原样行于模拟宿主。

## 包之身份

所有者：豫言。版本：0.1.0。库也，依标准库、结森工具、网址解析与模拟宿主。惟一模「原语」，即此包之默认导入。

## 柄与编码

- 文树之节，其柄为模拟宿主之节号（文档为 `0`），窗口曰 `窗口`；全局之单者曰 `全局:location`、`全局:history`、`全局:localStorage`、`全局:sessionStorage`、`全局:navigator`、`全局:clipboard`、`全局:console`、`全局:crypto`；元素之 classList、style、dataset 曰 `类表:号`、`样式:号`、`数据集:号`；余物（答、头、日、事、网址、查询参、字串、集合）登于模拟宿主之物表，柄曰 `物号`。
- 参与果之结森编码同浏览器宿主：物书 `{"$句柄":"…"}`，undefined 书 `{"$未定义":true}`。

## 已成

- 元素与文档：常用属性之读写；常用之术（getElementById、querySelector(All)、createElement、append、replaceChildren、remove、insertBefore、closest、matches、setAttribute、getAttribute、focus、click、dispatchEvent、cloneNode 等）。无文树之应之属性（如以 JavaScript 属性设之 `data-status`）记为扩属性，读还原值。

- 几何：模拟之宿主自无排版，矩形、片段、偏移之属、卷顶卷左与卷法，皆问一可登记之几何源（`沙盘设几何源`）；源出其节其性之整数，书卷位则源受之。未登记之时，卷顶取节上所记，卷左无处可存而略之，余者皆零。浏览器应用与网页之试可接真排于斯。
- 窗口、location、history、localStorage、sessionStorage、navigator、clipboard、console、crypto.randomUUID。
- 全局之术 fetch（经虚网）、encodeURIComponent 等；构造 Date、Event、CustomEvent、URL、URLSearchParams、String。
- 事：订、阻默认之订、选项之订、多听之订、撤订、`待网览事`（列空则行剧本）。
- 网：`网览索文字` 及其安全者、`浏览器请求JSON安全`、`网览同源资文字`；导航与饼、元素属性小具、`网览篇选全`。

## 未成

文树之观（MutationObserver、TreeWalker）、可读之流、字节之柄、正则、DOMParser、Blob 等，呼之则发“模拟宿主未实现：…”；浏览器宿主库有而此包未定之术，编时报“未找到”。需时补于「原语」，留待后版。

技术文档之模拟验以 `DOMParser.parseFromString` 析独立正文片段，所析之 `body` 存于独立文树之节，主页面存其旧文。`RegExp` 造物记模式及标志，字串 `replace` 之全局正则替换用纯豫言正则库。

后续之版补非全局正则替换及全文头部之析。

字串 `split` 受正则之物则用正则分割，技术文档得循空白正则拆多词之问。

`WeakMap` 之模拟循句柄之身支持 `has`、`get`、`set`，共界据此存各文字节之原文与译文。未登之键，以 `get` 取则返未定义；同文异节，各存其记。弱键自收及余弱映射之术留待后版。

文树游标依节之种类滤后代，循深先之序还节，根自居遍历之范围外。共界以文字节之游标遍正文而译之。新建时记当前后代之序，跨文树变动之位调留待后版。

文树观察支持 `childList`、`characterData` 与 `subtree`，节之附、插、离及文字之改依观察范围投“文树变动”之事，附观察器之身与可读之记录柄。止观察而复改树，则事列静。记录批合、旧值、增删节点列及属性之观留后版。

窗口之 `decodeURIComponent` 用网址解析库严格解码成分。网址之 `searchParams` 存所属网址之身，参之改同步于 `href`，存路径及锚点。

工作台所依文件、显示、字体之原语已有模块：目录缺省未授，显示与字体缺省暂不可用；闭文即成。网页代码之文经项目之服读写，界面由文树载之。已授目录、显示面及字体文件之仿俟后版。

正则之物，其 `test` 术用豫言正则之器；省标志则取空文。全局、粘连之游标，俟后版。

表单数据之物取具名可提交之文字控件，`get` 依名取值；勾选、单选之框取已勾之值，省值则取 `on`。文件、多选下拉之框及禁用字段集，俟后版。

抓取之答具可读流，可逐读文块而释放读器；文字解码器读完整八位码之块。验收以 `沙盘设下次回应块` 定次答之块界，登答即取而清其设。半字跨块、异码与流之锁定，俟后版。

试写编桥以模拟编译可用格定其态，启则录源码，止则复用模拟编译之止；进与果以含字串详情之文树事投之。TextEncoder造含正文与八位码字节长度之字节物；文本框setRangeText易所授之选区，置光标于末，余选区之式俟后版。
