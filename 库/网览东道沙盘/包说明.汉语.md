# 浏览器宿主模拟

下载模拟支持文本片段构造 Blob，读取正文、八位编码字节长度及媒体类型，并用对象网址定位字节物。二进制片段和对象网址撤销后的失效检查留待后续版本。

字符串全局句柄支持 `String.fromCharCode`，按十六位码元重建文字，结绳解析器合并代理对，下载应用可据此生成字节序标。

日期全局句柄支持 `Date.now` 与 `Date.parse`，共用模拟时钟及实例日期解析器，用于用量报表的默认日期与筛选。

浏览器宿主库（`库/网览东道`）的纯豫言替身。`豫构 发行 模拟` 构建时，把本包复制到构建临时目录、包名改成“浏览器宿主”，顶替真正的浏览器宿主库；直接依赖浏览器宿主库的应用（用 `网览全局柄`、`网览召法`、`待网览事` 等句柄反射原语）因此原样就能在模拟宿主上运行。

## 包身份

所有者：豫言。包版本：0.1.0。库类型，依赖标准库、结绳工具、网址解析与模拟宿主。只有一个模块「原语」，即本包的默认导入。

## 句柄与编码

- 文树节点的句柄是模拟宿主的节点号（文档为 `0`），窗口为 `窗口`；全局单例为 `全局:location`、`全局:history`、`全局:localStorage`、`全局:sessionStorage`、`全局:navigator`、`全局:clipboard`、`全局:console`、`全局:crypto`；元素的 classList、style、dataset 为 `类表:号`、`样式:号`、`数据集:号`；其余对象（回应、标头、日期、事件、网址、查询参数、字符串、集合）登记在模拟宿主的对象表里，句柄为 `物号`。
- 参数与结果的结绳编码同浏览器宿主：对象写成 `{"$句柄":"…"}`，undefined 写成 `{"$未定义":true}`。

## 已实现

- 元素与文档：常用属性（id、className、textContent、innerHTML、value、checked、disabled、hidden、href、children、childElementCount、parentElement、classList、dataset、style 等）的读写；方法 getElementById、querySelector(All)、createElement、append、appendChild、prepend、before、after、replaceWith、replaceChildren、remove、insertBefore、contains、closest、matches、setAttribute、getAttribute、removeAttribute、toggleAttribute、focus、blur、click、showModal、close、dispatchEvent、cloneNode、insertAdjacentHTML 等。不对应文树的属性（如 `data-status` 作为 JavaScript 属性）记为扩展属性，读回原值。

- 几何：模拟宿主自己没有排版，`getBoundingClientRect`、`getClientRects`、`offsetTop` 一类几何属性、`scrollTop`、`scrollLeft` 与 `scrollTo`、`scrollBy` 都问一张可登记的几何源（`沙盘设几何源`）；源给出某节点某属性的整数，写滚动位时由源接收。没有登记时 `scrollTop` 取节点上记的滚动顶、`scrollLeft` 无处可存而忽略、其余几何属性为零。浏览器应用与网页测试可以把真的排版接进来。
- 窗口、location、history、localStorage、sessionStorage、navigator、clipboard、console、crypto.randomUUID。
- 全局函数 fetch（经虚拟网络）、encodeURIComponent 等；构造器 Date、Event、CustomEvent、URL、URLSearchParams、String。
- 事件：`网览订阅事`、`网览订阅并阻止常`、`网览事订阅选`、`网览事订阅多`、取消订阅、`待网览事`（队列空时执行剧本）。
- 网络：`网览索文字`、`网览索文字安全`、`浏览器请求JSON安全`、`网览同源资文字`；导航与饼、元素属性小工具、`网览篇选全`。

## 尚未实现

文树观察（MutationObserver、TreeWalker）、可读流、字节句柄、正则、DOMParser、Blob 等调用时抛出“模拟宿主未实现：…”；浏览器宿主库里本包没有定义的函数在编译时报“未找到”。需要时在「原语」里补上，留待后续版本。

技术文档模拟验收使用 `DOMParser.parseFromString` 解析独立正文片段，解析结果的 `body` 保存在独立文树节点中，主页面保持原有内容。`RegExp` 构造器记录模式与标志，字符串 `replace` 的全局正则替换复用纯豫言正则库。

后续版本补齐非全局正则替换与完整文档的头部解析。

字符串 `split` 接收正则对象时复用正则分割，技术文档可以按空白正则拆分多词查询。

`WeakMap` 模拟按句柄身份支持 `has`、`get`、`set`，共用界面据此保存每个文本节点的原文与译文。未登记的键由 `get` 返回未定义，相同文字的不同节点各有自己的记录。弱键自动回收及其他弱映射方法留待后续版本。

文树游标支持按节点种类过滤后代，以深度优先顺序返回节点，根自身保持在遍历范围外。共用界面使用文字节点游标遍历并翻译正文。新建游标时记录当前后代顺序，跨文树变动的位置调整留待后续版本。

文树观察支持 `childList`、`characterData` 与 `subtree`，节点追加、插入、脱离及文本修改按观察范围投递“文树变动”事件，事件附观察器身份和可读取的记录句柄。停止观察后继续修改文树，事件队列保持安静。记录批合、旧值、增删节点列和属性观察留待后续版本。

窗口的 `decodeURIComponent` 复用网址解析库的严格成分解码。网址对象的 `searchParams` 保留所属网址身份，参数修改同步回 `href` 并保留路径与锚点。

工作台依赖的文件、显示、字体原语模块已提供：目录能力缺省未获授权，显示与字体缺省暂不可用；文件关闭立即完成。网页代码应用的文件通过其项目服务读写，界面由文树后端承载。获授权目录、显示面与字体文件的模拟留待后续版本。

正则对象的 `test` 方法复用豫言正则执行器，省略标志时取空字符串。全局与粘连标志的游标行为留待后续版本。

表单数据对象采集具名且可提交的文字控件，`get` 按名称读取值；勾选框与单选框采集已勾选的值，省略值时取 `on`。文件控件、多选下拉框及禁用字段集留待后续版本。

抓取回应提供可读流，可依次读取文字块并释放读取器；文字解码器读取完整八位编码块。验收可用 `沙盘设下次回应块` 指定下一次抓取回应的块边界，登记该回应时即取走并清空设置。半个统一码字符跨块、其它编码与流锁定留待后续版本。

试写编译桥使用模拟编译可用格控制状态，启动记录源码，停止复用模拟编译停止；进度与完成用带字符串详情的文树事件投递。TextEncoder生成含正文及八位编码字节长度的字节对象；文本框setRangeText替换指定选区并将光标放在末尾，其他选区模式留待后续版本。
