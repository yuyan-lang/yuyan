# 工作台网页

豫言工作台之浏览器运行之口：以[界面文树](../../界面/文树/包说明.文言.md)后端于页之容器行[平铺桌面](../../平铺桌面/包说明.文言.md)（提案 00014 第八步），格中为[工作台](../包说明.文言.md)库之文件浏览、编辑、搜索与构建之出。文之读写经呼者所授之服，云端代码页与示例之客共此一口。

## 函

```yuyan
「行网页书斋」乃
　化「容器」曰「文」
　又化「服务」曰「浏览服务」
　又化「写文本」曰（化「文」又化「文」为「浏览文本结果」）
　又化「改名」曰（化「文」又化「文」为「浏览文本结果」）
　又化「删除」曰（化「文」为「浏览文本结果」）
　又化「初始路径」曰「文」
　又化「只读」曰「爻」
　为「有」者也。
「行网页书斋带外事」乃
　化「容器」曰「文」
　又化「服务」曰「浏览服务」
　又化「写文本」曰（化「文」又化「文」为「浏览文本结果」）
　又化「改名」曰（化「文」又化「文」为「浏览文本结果」）
　又化「删除」曰（化「文」为「浏览文本结果」）
　又化「初始路径」曰「文」
　又化「只读」曰「爻」
　又化「外事」曰（化「结绳」又化「工作台状态」为（「或可有」于「工作台状态」））
　又化「更新包装」曰（化（化「书斋信」又化「工作台状态」为「工作台状态」）又化「书斋信」又化「工作台状态」为「工作台状态」）
　为「有」者也。
「网页书斋初态」乃化「浏览服务」又化「初始路径」曰「文」为「工作台状态」者也。
```

呼之之式：

```yuyan
「行网页书斋」
　于「容器」曰『工作台容器』
　于「服务」曰（「组值」【「列目录」者「我的列目录」也，「读文本」者「我的读文本」也】属「浏览服务」）
　于「写文本」曰「我的写文本」
　于「改名」曰「我的改名」
　于「删除」曰「我的删除」
　于「初始路径」曰『示例/入口。豫』
　于「只读」曰「阴」。
```

- 容器：页中既有元素之 ID；其大由页定之，常满视口。
- 服务：用户态桌面「文件浏览」模之「浏览服务」。`列目录`（径）得「浏览目录已得」目录项之列（名、为目录否）或「浏览目录失败」；`读文本`（径）得「浏览文本已得」正文或「浏览文本失败」。径以正斜线分，空文为根。此诸函中可呼浏览器宿主之异步之能（如网页请求），程序于 JSPI 下悬而待其果。
- 写文（径，正文）、更名（源径，目径）、删除（径）：皆还「浏览文本结果」，成得「浏览文本已得」（其文不用），败得「浏览文本失败」带中文之因；败则工作台存缓冲与改标，示其因于状态栏。存之以 命令（或控制）加 S，或于源码框按 命令（或控制）加回车。
- 初始之径：始后于编辑组所开之文；空文则惟载根目。读败则示其因于状态栏。
- 只读：阳则三写函不见呼，存、更名、删除与会话之发惟示之。
- 外事（「行网页书斋带外事」）：处非界面之网页事（如编译之进），施于外壳共有之工作台之态；予新态则易之而重绘，有构建之出则于编辑组下拆出构建输出之格；予可无则略之。
- 更新之包（「行网页书斋带外事」）：受基本之更新（只读则「更新书斋」，否则「更新可写书斋带操作」）、消息与态三参，其果为编辑格之工作台更新。呼者于此先接检查、构建、类型检查等消息，余付基本之更新。「行网页书斋」不处外事，更新不包。

页为平铺桌面之浏览器布局：左活动之栏惟文件浏览与文件搜索，开场左为文件浏览、右为编辑之组，单格之时与旧工作台同貌；签栏之“左右”“上下”“全屏”“关闭”、编辑格之“右侧打开”与文档、原码之易、状态栏之光标行列与文之术皆可用，签组依分割之树以弹性之排列之。检查、构建、类型检查与模型之请经更新之包接之，未接则惟示之。浏览器中无终端、任务管理器、设置与外程序；平铺桌面之终端经「终端程序」接之，浏览器之包不链命令行与拼音之表，示例之客之程约一点五兆。

## 页

页置一容器与浏览器宿主之启脚；基础样式表与界面所用之样式规则由界面文树装于页。

```html
<div id="工作台容器"></div>
<script type="module" src="./自动启动.mjs?标识=工作台容器"></script>
```

页定容器之大，如 `html,body{margin:0;height:100%;}#工作台容器{height:100%;}`。

## 构建

```sh
./豫构。林檎。豫行 发行 浏览器 <应用目录> <输出目录> --包根 库
```

依赖之闭与程序之大见[工作台](../包说明.文言.md)“依赖之闭”。示例之客见 `应用/百工坊/豫言工作台/网页示例`。
