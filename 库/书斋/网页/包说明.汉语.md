# 工作台网页

豫言工作台的浏览器运行入口：用[界面文树](../../界面/文树/包说明.汉语.md)后端在页面容器里跑[平铺桌面](../../平铺桌面/包说明.汉语.md)（提案 00014 第八步），格子里是[工作台](../包说明.汉语.md)库的文件浏览、编辑、搜索与构建输出。文件读写经调用者传入的服务，云端代码页与示例应用共用这一个入口。

调用写法：

```yuyan
「运行网页工作台」
  于「容器」为『工作台容器』
  于「服务」为（「浏览服务」也「组值」【「列目录」者「我的列目录」也，「读文本」者「我的读文本」也】）
  于「写文本」为「我的写文本」
  于「改名」为「我的改名」
  于「删除」为「我的删除」
  于「初始路径」为『示例/入口。豫』
  于「只读」为「阴」
```

- 容器：页面里已有元素的 ID；大小由页面决定，通常撑满视口。
- 服务：用户态桌面「文件浏览」模块的「浏览服务」。`列目录`（路径）得「浏览目录已得」目录项列（名称、是否目录）或「浏览目录失败」；`读文本`（路径）得「浏览文本已得」正文或「浏览文本失败」。路径是以正斜线分隔的相对路径，空文字为根。这些函数里可以调浏览器宿主的异步能力（如网页请求），程序在 JSPI 下挂起等待结果。
- 写文本（路径，正文）、改名（源路径，目标路径）、删除（路径）：都返回「浏览文本结果」，成功得「浏览文本已得」（内容不用），失败得「浏览文本失败」带中文原因；失败时工作台保留缓冲与修改标记，在状态栏显示原因。保存用 命令（或控制）加 S，或在源码框里按 命令（或控制）加回车。
- 初始路径：启动后在编辑组里打开的文件；空文字只载入根目录。读取失败时在状态栏显示原因。
- 只读：为阳时三个写函数不会被调用，保存、改名、删除与会话发送只给提示。
- 外事（「运行网页工作台带外事」）：处理不是界面事件的网页事件（如编译进度），作用在外壳共享的工作台状态上；给出新状态就换上重画，有构建输出时在编辑组下方拆出构建输出格；给出可无就略过。
- 更新包装（「运行网页工作台带外事」）：收基础更新（只读时「更新工作台」，否则「更新可写工作台带操作」）、消息与状态三个参数，结果作编辑格的工作台更新。调用者在这里先接管检查、构建、类型检查等消息，其余交给基础更新。「运行网页工作台」不处理外事，更新不包装。

页面是平铺桌面的浏览器布局：左侧活动栏只有文件浏览与文件搜索，开场左边文件浏览、右边编辑组，单格时与原来的工作台外观一致；标签栏的“左右”“上下”“全屏”“关闭”、编辑格的“右侧打开”与文档、原始代码切换、状态栏的光标行列与文件操作都可用，标签组按分割树用弹性布局排开。检查、构建、类型检查与模型请求经更新包装接管，没有接管时只给提示。浏览器里没有终端、任务管理器、设置与外部程序；平铺桌面的终端经「终端程序」接入，浏览器包不链接命令行与拼音表，示例应用的程序约 1.5 MB。

## 页面

页面放一个容器元素和浏览器宿主的启动脚本；基础样式表与界面用到的样式规则由界面文树装进页面。

```html
<div id="工作台容器"></div>
<script type="module" src="./自动启动.mjs?标识=工作台容器"></script>
```

页面给容器定大小，例如 `html,body{margin:0;height:100%;}#工作台容器{height:100%;}`。

## 构建

```sh
./yy豫构.exe 发行 浏览器 <应用目录> <输出目录> --包根 库
```

依赖闭包与程序大小见[工作台](../包说明.汉语.md)“依赖闭包”。示例应用见 `应用/百工坊/豫言工作台/网页示例`。
