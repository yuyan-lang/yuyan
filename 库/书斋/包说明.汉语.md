# 工作台

豫言工作台与平台无关的部分，从可执行包「豫言工作台」（`应用/百工坊/豫言工作台`）抽出。原生工作台与浏览器工作台（[工作台网页](网页/包说明.汉语.md)、云端代码页）共用同一份状态、视图与更新逻辑。产品设计见云仓 `提案/豫言工作台设计.汉语.md`，改版计划见云仓 `提案/C0002-豫言云控制台改版.汉语.md` 第五节第 4 步。

## 模块

| 模块 | 内容 |
| --- | --- |
| `模型` | 工作台状态（资源树、标签与文件页、搜索、包视图、构建输出、改名与删除确认、卷夹）与改状态的纯函数；卷夹记复制或剪切的文件路径与是否剪切，各文件浏览格共用；双编辑组的副组已删去（提案 00014 第九步），编辑组由平铺桌面的标签组承担，「工作台副栏」消息（“右侧打开”）由平铺桌面接管 |
| `视图` | 工作台消息、界面视图（「书斋观」「书斋宽观带役」等；平铺桌面的格子用「书斋资侧栏带样式」「书斋寻观带样式」「书斋正文观」等单块视图）、配色与源码着色；资源侧栏的文件行、目录行与空处的锦囊（右键菜单，提案 00048 丁路），显示名、快捷键提示与等价壳命令照当时的对象填好 |
| `更新` | 更新逻辑：「更新书斋」（只读）与「更新可写书斋带操作」，以及载入根目录、打开资源、刷新忽略规则、阅读链接、应用差异、改名、删除的辅助函数；只读更新还办复制、剪切、按路径开始改名、在编辑器中打开文件与复制路径（换算成真实绝对路径写入系统剪贴板）；新建文件与目录、粘贴、按路径改名与删除由文件浏览格经授权根办（提案 00048 丁路） |
| `会话卷` | `.会话` 文件的中文结森格式 |
| `修改校勘` | 修改快照与逐行差异展示 |
| `包浏览` | 包树：发现包描述（经包配置解析）、层级与所属包；包视图按包们缓存包树，包们没变就不重排 |
| `营诊断` | 从编译器输出提取诊断位置；工作根内的相对路径与绝对路径互转（「书斋诊断相对径」「书斋全径」） |
| `忽略规则` | `.gitignore` 规则；分层判断的结果按（路径、是否目录）缓存，规则变了才清空 |
| `卷寻` | 递归文件搜索 |
| `模型协议` | 模型聊天正文、回复解析与模型连接配置（2026-10-10 从应用「豫言工作台」移入，纯逻辑） |
| `模型后台协议` | 模型后台子程序的输入输出协议（同上移入） |

默认导入是前九个模块，`寻观「书斋」之书。` 一次打开它们；模型协议与模型后台协议按模块路径导入。平铺桌面（`库/九宫`）把工作台的这些视图做成格子程序（编辑、会话、差异、搜索、构建输出、文件浏览），见其包说明。

## 服务注入

读写都经运行环境注入。读用用户态桌面「文件浏览」模块的「浏览服务」：`列目录` 与 `读文本`，路径是以正斜线分隔的相对路径，空文字为根。写用调用者传入的写文本、改名、删除三个函数，都返回「浏览文本结果」，失败时工作台保留缓冲与修改标记并在状态栏显示原因。

```yuyan
「更新书斋」乃化「浏览服务」又化「书斋信」又化「工作台状态」为「工作台状态」者也。
「更新可写书斋带操作」乃
　化「浏览服务」
　又化「写文本」曰（化「文」又化「文」为「浏览文本结果」）
　又化「改名」曰（化「文」又化「文」为「浏览文本结果」）
　又化「删除」曰（化「文」为「浏览文本结果」）
　又化「书斋信」
　又化「工作台状态」
　为「工作台状态」者也。
```

「更新书斋」对保存、改名、删除与会话发送只给提示；检查、构建、类型检查给出“需要运行环境提供构建服务”的提示；侧栏拖动与停止构建原样返回状态。运行环境要接构建、模型请求与侧栏拖动时，在调用这两个函数之前先接管这些消息，原生工作台的「后台构建」模块就是这样做的。

## 使用者

- 原生工作台 `应用/百工坊/豫言工作台`：它的「更新可写书斋」把授权目录的写文本、改名、删除传给「更新可写书斋带操作」；后台构建、模型请求、原生窗口与授权文件读写留在原生包里。
- 浏览器：[工作台网页](网页/包说明.汉语.md) 的「行网页书斋」，示例见 `应用/百工坊/豫言工作台/网页示例`。

## 依赖闭包

本库依赖用户态桌面，用到其中的文件浏览与标记文预览两个模块。浏览器应用经豫构发行时，依赖闭包会带上用户态桌面所依赖的包与八个系统接口（任务监测、剪贴板、基础、子程序、字体、文件、时间、显示，浏览器都有适配），多出的只是接口绑定与接口清单：程序只编入实际导入的模块，导入表里只有标准库、构建基础与浏览器宿主三组。包浏览经包配置用编译器核心的语法分析，源码文档与源码着色也用它，所以浏览器程序约 1.2 MB。
