# 工作台

豫言工作台与平台无涉之部，自可执行包「豫言工作台」（`应用/百工坊/豫言工作台`）抽出。原生工作台与浏览器工作台（[工作台网页](网页/包说明.文言.md)、云端代码页）共此一份之态、视图与更新。产品之设见云仓 `提案/豫言工作台设计.汉语.md`，改版之计见云仓 `提案/C0002-豫言云控制台改版.汉语.md` 第五节第四步。

## 诸模

| 模 | 所含 |
| --- | --- |
| `模型` | 工作台之态（资源树、签与文页、搜索、包视、构建之出、更名与删除之确）与易态之纯函；双编辑组之副组已删（提案 00014 第九步），编辑之组由平铺桌面之签组承之，「工作台副栏」之消息（“右侧打开”）由平铺桌面接之 |
| `视图` | 工作台之消息、界面之视图（「工作台视图」「工作台宽度视图带任务」等；平铺桌面之格用「工作台资源侧栏带样式」「工作台搜索视图带样式」「工作台正文视图」等单块之视）、配色与源码着色 |
| `更新` | 更新之理：「更新工作台」（惟读）与「更新可写工作台带操作」，及载根目、开资源、刷忽略之规、阅读之链、施差异、更名、删除诸辅函 |

| `构建诊断` | 自编译器之出取诊断之位 |

| `模型协议` | 模型聊天之正文、答之析与模型之连之设（二〇二六年十月十日自客「豫言工作台」移入，纯逻辑） |

## 服务之授

读写皆经运行之境所授。读用用户态桌面「文件浏览」模之「浏览服务」：`列目录` 与 `读文本`，径以正斜线分，空文为根。写用呼者所授写文、更名、删除三函，皆还「浏览文本结果」，败则工作台存缓冲与改标，而示其因于状态栏。

```yuyan
「更新工作台」乃化「浏览服务」又化「工作台消息」又化「工作台状态」为「工作台状态」者也。
「更新可写工作台带操作」乃
　化「浏览服务」
　又化「写文本」曰（化「字符串」又化「字符串」为「浏览文本结果」）
　又化「改名」曰（化「字符串」又化「字符串」为「浏览文本结果」）
　又化「删除」曰（化「字符串」为「浏览文本结果」）
　又化「工作台消息」
　又化「工作台状态」
　为「工作台状态」者也。
```

「更新工作台」于存、更名、删除与会话之发惟示之；检查、构建、类型检查示以“须运行之境供构建之服”；侧栏之拖与止构建，原样还其态。运行之境欲接构建、模型之请与侧栏之拖，则于呼此二函之前先接其消息，原生工作台之「后台构建」模即如是。

## 用者

- 原生工作台 `应用/百工坊/豫言工作台`：其「更新可写工作台」以已授目录之写文、更名、删除授「更新可写工作台带操作」；后台构建、模型之请、原生之窗与授权文件之读写留于原生包。
- 浏览器：[工作台网页](网页/包说明.文言.md) 之「运行网页工作台」，示例见 `应用/百工坊/豫言工作台/网页示例`。

## 依赖之闭

此库依用户态桌面，所用者其文件浏览、标记文预览二模。浏览器之客经豫构发行，依赖之闭兼带用户态桌面所依之包与八系统接口（任务监测、剪贴板、基础、子程序、字体、文件、时间、显示，浏览器皆有其适配），所增惟接口之绑与接口清单：程序惟编实所导之模，导入之表惟标准库、构建基础与浏览器宿主三组。包浏览经包配置用编译器核心之语法分析，源码文档与源码着色亦用之，故浏览器程序约 1.2 MB。
