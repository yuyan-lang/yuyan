# 败报与长文编译

式无可解，先告文件与词文，不尽倾内部之树。词取三十二以内，名与串各取六十四字以内。败句有裸元、阳、阴，则劝察是否当书「元」、「阳」、「阴」。串中之文、已引之名，不作裸值论。此但报错，不改语法，不代改文。今简报言其所至最远之位与其所望之辞：卷后次“位置：第几行第几列处遇到某词”“期望：某辞”。诸位取于词上之源码域（提案〇〇〇二六第六步）：编译之词法（句读标域）裹名与字以域；词尽而语未竟者，取栈上末位之止；不在一词而败者，取栈上首未竟之符，因其已纳之素，定其次当出之辞。括号不配者，别书其未闭之左括。词法之败（未闭之标识、串、注）则补其发端之位。词无域者（句读顶层）惟给片段，明言省略空白。雅言解析平居用不标域之词法，败则改以标域者再析一遍，报误亦带行列。`-vv` 调试仍存败支全栈。

长文之编，遇线性递归而栈溢。今以尾递修「生列」、「起讫」、「遍」、「计」及「接列」；施术与成列之序皆因旧，后列亦共享如故。不增配额，不裁文，不匿败。所改为标准库「多态列。豫」与「多态列工具。豫」。

验三裸值之败、引值之成、串不误报与短报有界；又验三万二千项之表、射、数、区间、附加、施术次序与空列。全程探针先热同版标准库，编万甲之文，得合法器，实运行而逐字验万甲及换行。默认 Node 栈下皆成。极小栈尚受标准库树解码深度所限，生产当以真 Worker 另验。

构建须用独立种子，运行未毕勿覆其径。依有效包上下文生 `.wasm.wat`，因平台现有 Binaryen 优化为 `完整长文编译器优化.wasm`，长 1,780,893 字节。发布须同更两标准库文件，清诸派生缓存而重热之；别模块或已内联旧术，不可但除同名缓存。更新资源摘要，复验云端。本仓不发布用户应用。
