# 败报与长文编译

式无可解，先告文件与词文，不尽倾内部之树。词取三十二以内，名与串各取六十四字以内。败句有裸元、阳、阴，则劝察是否当书「元」、「阳」、「阴」。串中之文、已引之名，不作裸值论。此但报错，不改语法，不代改文。语法之析之门「依表解析及语义标记」还「析果」：成裹具体语法之树与语义之标，误载「析误」。析误二支：析误诊具源位、说辞与片段，民之误也；析内误载辞，编译自生之失也。无解、未定先后与多解三支民误皆归析误诊，不复掷，呼者以鉴尽分之；惟真为不变量之失归析内误。诊之首行依编译统一之出口书“卷:行:列：顶层语句:辞”，行列自一数，位取所至最远之处（编译之词法句读标域裹名与字以域；词尽而语未竟者，取栈上末位之止）；不在一词而败者，取栈上首未竟之符，因其已纳之素，定其次当出之辞。望空则不书“望”。片段次书未闭之左括、句之片段（明言省略空白）、裸值之示与跨行串近因。未定先后与多解二支亦归析误诊：前者源位书后一符之位（无位则退就栈首之符），述两符不能定先后而示之加括，复合实参之支复示须括；后者源位书句首记之起（歧义起处），述有多解而示之加括以明其分。下阶犹为告祸之门者（「雅言具体解析语句」「析」「解式常算符及语义标记」「解式编译及语义标记」）以「析须」还其误于告祸之路，定讯仍冠“编译错误：”：编译一侧由承诊剥冠而报为常诊，格式化之门冠以“格式化失败：”而拒书；内误仍冠“内部错误：”。词法之败于诊首书卷与行列：未闭之串、块文与名号指其开引，块文缩不足者指其行首，不识之避讳指其转之端；辞中不复载位，亦不冠内误。词无域者（句读顶层）以首记之位或零行零列补之，仍具 `卷:行:列` 之形。雅言解析以标域之词法（句读标域）析之，败则同遍之域自具行列，不复别析。`-vv` 调试仍存败支全栈。

长文之编，遇线性递归而栈溢。今以尾递修「生列」、「起讫」、「遍」、「计」及「接列」；施术与成列之序皆因旧，后列亦共享如故。不增配额，不裁文，不匿败。所改为标准库「多态列。豫」与「多态列工具。豫」。

验三裸值之败、引值之成、串不误报与短报有界；又验三万二千项之表、射、数、区间、附加、施术次序与空列。全程探针先热同版标准库，编万甲之文，得合法器，实运行而逐字验万甲及换行。默认 Node 栈下皆成。极小栈尚受标准库树解码深度所限，生产当以真 Worker 另验。
