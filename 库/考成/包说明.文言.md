# 验收驱动

验收驱动者，工具宿主（`node 豫言操作系统/宿主/节点/宿主.cjs 程序.wasm` 或原生执行器）上黑盒验收之库也，以“起一服、经 HTTP 与事件流验之、乃止之”之测书为豫言。所供：具名之用例与断言、HTTP/1.1 之客（含事件流逐帧之读与中途之止）、长驻子进程之编排、本机 wrangler dev（真 workerd）之一贯运行，及本机假服务。

单段之导入 `寻观「验收驱动」之书。` 启六模：`异步定时`、`用例`、`超文本`、`进程编排`、`本机云工`、`假服务`。测之文常复导标准库之 `数据结构/字节串`（空正文、字节串）、`数据结构/特殊字符`（`新行`）与结森工具之 `结森访问`（`结森取整数` 诸术）。

## 并行之法

标准库之协作调度，单线程也：`派生` 之任务惟有候者乃进，嵌套之 `等待` 占调用之栈。此库之网事皆书为定时状态机（`派生定时步进`）：每步或毕，或登“候描述符之事”“候至某时”而让，不占调用之栈。故：

- 主流程（测之顺序之码）径呼不带“异步”之术，如 `请求`、`交换`、`下一帧`、`睡眠毫秒`；
- 欲并行，先连呼带“异步”之术生数机（如 `异步交换`、`异步发起请求`），复以 `等候全部` 或 `等候任务` 取其果，真并行也；
- 假服务之受连与每连亦状态机，主流程候任一任务，皆推行之；
- 一边行事一边候他事者（如一边回传分片一边读长连），于主流程交替行之：每轮行一步，复以 `尝试下一帧` 带短限读一次。

纯定时借一永不就绪之本机听套（哑描述符）为之，标准库之调度有纯定时之器则改用之。

## 用例与断言（`用例`）

- `用例 于「名称」为 文 于「操作」曰（得「无」而 …）`：默认时限二分；`限时用例` 别给 `「限时毫秒」为`。
- `运行验收用例们 于「套件」为 名 于「用例们」为 列`：逐一行之，承其异而记为败，书“通过/失败 名称（毫秒）”与总计，返败数；`结束验收 于「失败数」为 n` 有败则以退码一终。
- 每例之时限书于 `用例截止格`，库中诸候皆不逾之，逾则抛“用例超时”；久算不见断。
- 断言（不成则抛其说）：`断言为真`（条件、说明）、`断言串相等`、`断言整数相等`、`断言爻相等`、`断言含子串`、`断言串列相等`（告首异之项）、`断言结森相等`（对象不计键序，告首异之径，如 `$.body.messages[0].content`）。同类之二参皆系标签：`于「实得」为 … 于「期望」为 …`。
- `验收失败`（自败）、`观察`（书“[观察] …”）、`等到`（每隔若干毫秒验其条件，逾时抛“等待超时：说明”）、`等到条件`（十五秒、五十毫秒）、`逐一`（带序而遍）、`逐次`（半开之区）。

## HTTP 与事件流（`超文本`）

- 每请新开一连而带 `Connection: close`，正文读毕或止即闭之；`Host`、`Content-Length` 自加之。
- `请求`（方法、网址、标头、正文之字节）候至响应头即返 `超文本响应`（`状态`、`标头`（名小写）、正文之读者）；`交换` 尽读其正文返 `完整响应`（`状态`、`标头`、`正文`）；`取文` 者 GET 而取正文之文。
- 正文渐读：`下一块`（一块字节、已毕、有误或逾时，不抛异）、`下一帧`（依事件流之空行分帧，毕则可无，逾时或有误则抛）、`尝试下一帧`（不抛异）、`读完帧们`、`读完全文`；`取消响应` 闭其连（对端将察其断）。正文有定长、分块、读至闭三法。
- 异步之版：`异步发起请求`、`异步交换`、`异步读正文块`、`异步下一帧`、`异步读完全文`，皆带 `「限时毫秒」为`。
- 诸器：`拼网址`（基址、路径逐段百分号编码、查询名值之对）、`查询串`、`百分号编码`、`标头值`、`标头取值`、`正文文字`、`正文结森`、`结森取值`（循键之径）、`正文帧们`（剖全段事件流为帧）、`切分文字`、`重复文字`、`十六进制文字`、`字节变文`、`文变字节`。
- 小饼罐：`新小饼罐`、`收存小饼`（收响应之 Set-Cookie）、`小饼标头`、`附小饼`（附 Cookie 于请之标头）。

## 进程之编排（`进程编排`）

- `选空闲端口`、`建临时目录`（`mktemp -d`，前缀宜惟用 ASCII）、`删临时目录`（惟删名以 yy 始者）、`复制目录内容`、`复制文件到目录`、`运行命令`、`必须运行`、`环境变量或`。
- `起长驻进程`（名、程序、参、标记、日志之径）起异步子进程；`进程已退出吗` 既退则收其退码与所出而书日志之文；`等候就绪`（屡 GET，得任一 HTTP 之应即就绪，进程先退或逾时则抛而附日志之尾）；`日志尾部`。
- `停止长驻进程`：依命令行中之独记（如暂存目录之径）于 `ps -A -ww -o pid=,ppid=,command=` 求其进程之树，发 TERM 于其根，至多候十五秒，否则强止之；复核诸后代（如 workerd）皆已退，残者依确号 KILL 之。返说明之文。

## 本机云工（`本机云工`）

`本机云工复验` 一令毕之：求 wrangler → 确保 Worker 之产物 → 起本机云工 → 逐一行用例 → 止 wrangler → 有败则以退码一终（存工作目录与 `wrangler.log`）。

- 求 wrangler 次第察：环境变量 `云工命令行路径`、仓旁云仓之 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`、作者机上之定径；皆无则书“跳过：缺 wrangler（…）”而以零退。
- 产物目录无 `入口.mjs`，或环境变量 `重建云工应用=1`，则以 `豫构 发行 云工 <应用目录> <产物目录>` 构之：发行与接口清单之核由仓根之 `yy豫构.wasm` 为之，编译付 `yy豫构.exe`（有则用之）。
- `起本机云工` 置产物、配置之文与附加之文于暂存之工作目录，依（绑定之名，SQL 之文）逐一行 `wrangler d1 execute --local`，乃于空端口起 `wrangler dev --local --ip 127.0.0.1`（检查器之端口别择，持久之态置于工作目录之 `.state`），候其 HTTP 就绪；`云工基址` 予其基址。`停本机云工` 止其进程，随需删工作目录。

**本机之探查与观测**（wrangler 4.129 本机开发之服自带，不必止服而读其出）：

- `云工探查网址 于「路径」为 …`：探查之口 `/cdn-cgi/local/explorer/api` 下之网址，可列 D1、R2、KV 与已发之邮（`/local/email/sending`）等，诸路见其址之 OpenAPI。
- `云工观测查询 于「结构化查询」为 …`：于 `/local/observability/query` 行只读之 SQL（SELECT 或 WITH），返诸行（结森数组）。表 `logs` 记 Worker 之控制台日志（`level` 为 log、info、warn、error、debug，`message` 为诸参数组之结森文）与每事之请求行（`message` 为结森串，如“POST 网址”），同事之诸行 `trace_id` 同、`seq` 依所生之次而增；表 `spans` 记诸事。`结构化查询文字` 书文为 SQL 串之字面。
- `控制台日志项`（`级别`、`参数们`、`追踪号`）；`查控制台日志 于「含文」为 …`（`message` 含某段结森之文者）；`请求控制台日志 于「网址含」为 …`（请求行之网址含某段 ASCII 之文之事之记，请求行不与焉）；`候请求控制台日志`（复带 `「限时毫秒」为`）先候请求行书入观测之库乃取之，日志之断言常用之。请中置一独有之查询参数（如 `yymark=7z`）为记。
- `触发定时事件 于「定时表达式」为 cron 于「计划毫秒」为 毫秒`：经 `/cdn-cgi/local/scheduled` 发一定时之事（零则今时），返全应（成则状态二百、正文 `ok`）。

## 本机假服务（`假服务`）

- `起假服务 于 路由列` 于 127.0.0.1 空端口监听，即返；`假服务基址`、`假服务请求数`、`假服务断开们`（答未毕而客已断之请径，已解而不含查询，依先后；迟答与流答候时察之，书败亦记之）、`停假服务`。
- 路由：`路由 于「方法」为 文（“*”合诸方法）于「前缀」为 已解之径之前缀 于「处理」为 术`，依次取首合者，皆不合答四零四，理术抛异答五百。
- 理术受 `假请求`（方法、原标、已解之径、已解之查询对、标头、正文），以 `查询参数` 取参；返 `整段回应`、`文字回应`、`结森回应`，或流之答：`事件流回应 于 步列`（`事件帧`、`流等`、`流写`、`流断`，列尽则正终），`流式回应` 则予“取次步”之术，可依他请所易之态动生其事。`迟回应 于「毫秒」为 n 于「回应」为 答` 先候 n 毫秒（其间不书一字节）乃依内答应之，n 甚大即“久不答”。理术宜速返。

## 改写之方（workerd 黑盒之 JS 测 → 豫言）

一、于所验之目录下立测包之目录（如 `一致性验证/云端复验/`）：包描述（库类、空默认导入，依标准库、结森工具、验收驱动，「包含在」父包）、双语包说明，并登于父包之「包含包」；旧 `wrangler.jsonc` 与 Worker 外壳（如 `rig.mjs`）置于此；外壳转有正文之请前先尽读其正文（见首批之 `rig.mjs`），不然应用未读正文而先答，wrangler dev 或以“答后复读请流”而退。
二、书 `名。测试。豫`：每 `test(...)` 易为顶层 `「例某」乃「验收用例」也。` 与 `用例`；`fetch` 易为 `请求`（惟取响应头）或 `交换`（尽读全段），`Promise.all` 易为先生 `异步交换`／`异步发起请求` 复 `等候全部`；`读.下一帧(t)` 易为 `下一帧 于 读 于「限时毫秒」为 t`，`读.读完()` 易为 `读完帧们`，`读.全文()` 易为 `读完全文`，`AbortController.abort()` 易为 `取消响应`；`assert.deepEqual` 易为 `断言结森相等` 或 `断言串列相等`，`等到` 与 `睡` 易为 `等到`／`等到条件` 与 `睡眠毫秒`；JS 之 `.length` 乃 UTF-16 之长，依字节较者以 `字节长度` 计其非 ASCII 之尾。
三、文末书一 `本机云工复验`，予套件之名、应用目录、产物目录、配置之文、附加之文与建表之列。“须一边发一边读”之并行，易为主流程中交替之循环，毋生相候之顺序流程。旧代 `console` 以收其出之断言，易为 `候请求控制台日志`；旧读 wrangler 之出者，改用本机探查与观测之口。
四、于 `应用/百工坊/全树测试/测试规则.tsv` 登其目录为“只检查”（CI 无 wrangler），删旧 JS 与其“跳过”之登，更所在目录之双语说明。
五、于仓根构而行之：`./yy豫构.exe 文件 <测之径> --输出 yy名.wasm -j 24`，复 `node 豫言操作系统/宿主/节点/宿主.cjs yy名.wasm`。

首批改写：`豫言操作系统/适配/持久频道/一致性验/云端复验`（持久频道九例、组合范例一例）与 `豫言操作系统/适配/网页事件流/一致性验/云端复验`（九例）。以观测之口断日志之范例：`豫言操作系统/适配/日志/一致性验/云端复验`（十一例）。
