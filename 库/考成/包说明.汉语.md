# 验收驱动

验收驱动是工具宿主（`node 豫言操作系统/宿主/节点/宿主.cjs 程序.wasm` 或原生执行器）上的黑盒验收库，用来把“起一个服务、经 HTTP 与事件流检查它、再停掉”的测试写成豫言。它提供具名用例与断言、HTTP/1.1 客户端（含事件流逐帧读取与中途取消）、长驻子进程编排、本机 wrangler dev（真 workerd）的一条龙运行，以及本机假服务。

单段导入 `寻观「考成」之书。` 打开全部六个模块：`异步定时`、`用例`、`超文`、`使编排`、`本机云工`、`假务`。测试文件通常还要导入标准库的 `数据结构/字节串`（空正文、字节串）、`数据结构/特殊字符`（`新行`）与结森工具的 `结森访问`（`结绳取数` 等）。

## 并发模型

标准库的协作调度是单线程的：`派生` 出来的任务只在有人等候时推进，嵌套的 `等待` 会占住调用栈。本库的网络操作都写成定时状态机（`派生定时步进`）：每一步要么完成，要么登记“等描述符的事件”或“等到某一时刻”后让出，不占调用栈。所以：

- 主流程（测试的顺序代码）直接调用不带“异步”的函数，如 `索`、`交换`、`次帧`、`小憩毫秒`；
- 要并发时，先连续调用带“异步”的函数派生多个状态机（如 `异步交换`、`异步发起索`），再用 `等候全` 或 `等候役` 取结果，它们真正并发；
- 假服务的接受与每条连接也是状态机，主流程等候任何任务时它都在推进；
- 需要一边做事一边等另一件事时（如一边回传分片一边读长连接），在主流程里交替进行：每轮做一步，再用 `姑次帧` 带短限时读一次。

纯定时器借一个永不就绪的本机监听套接字（哑描述符）实现，标准库调度器加入纯定时器后改用它。

## 用例与断言（`用例`）

- `用例 于「名称」为 文 于「操作」曰（得「无」而 …）`：默认限时两分钟；`限时用例` 另给 `「限时毫秒」为`。
- `运行验收用例们 于「套件」为 名 于「用例们」为 列`：逐个运行，接住异常记为失败，打印“通过/失败 名称（毫秒）”与汇总，返回失败数；`结束验收 于「失败数」为 n` 在有失败时以退出码 1 结束。
- 每例的限时写进 `用例截止格`，库里的各种等待都不越过它，越过即抛“用例超时”；长时间的纯计算不会被打断。
- 断言（不成立即抛出说明）：`断为真`（条件、说明）、`断文同`、`断数同`、`断爻同`、`断含子串`、`断串列同`（报告第一个不同的项）、`断结绳同`（对象不计键序，报告首个差异的路径，如 `$.body.messages[0].content`）。相同类型的两个参数都带标签：`于「实得」为 … 于「期望」为 …`。
- `验收败`（主动失败）、`观察`（打印“[观察] …”）、`等到`（每隔若干毫秒检查条件，超时抛“等待超时：说明”）、`等到条件`（十五秒、五十毫秒）、`逐一`（带序号遍历）、`逐次`（半开区间）。

## HTTP 与事件流（`超文`）

- 每次请求新开一条连接并带 `Connection: close`，正文读完或取消即关闭；`Host`、`Content-Length` 自动添加。
- `索`（方法、网址、标头、正文字节）等到响应头就返回 `超文本响应`（`状态`、`标头`（名字小写）、正文读者）；`交换` 读完整段正文返回 `完整响应`（`状态`、`标头`、`正文`）；`取文` 是 GET 后取正文文字。
- 正文增量读取：`次块`（一块字节、结束、出错或超时，不抛异常）、`次帧`（按事件流的空行分帧，结束得可无，超时或出错抛出）、`姑次帧`（不抛异常）、`读诸完帧`、`读完全文`；`罢回书` 关掉连接（对端会察觉断开）。正文支持定长、分块与读到关闭三种。
- 异步版本：`异步发起索`、`异步交换`、`异步读正文块`、`异步次帧`、`异步读完全文`，都带 `「限时毫秒」为`。
- 工具：`拼驿址`（基址、路径按段百分号编码、查询名值对）、`问串`、`百分码`、`抬头值`、`抬头取值`、`正文文字`、`正文结绳`、`结绳取值`（按键路径）、`诸正文帧`（把整段事件流切成帧）、`切分文字`、`重复文字`、`十六进制文字`、`字节变文`、`文变字节`。
- 小饼罐：`新小饼罐`、`收存小饼`（收下响应的 Set-Cookie）、`小饼抬头`、`附小饼`（给请求标头附上 Cookie）。

## 进程编排（`使编排`）

- `选空闲端口`、`置暂箧`（`mktemp -d`，前缀请只用 ASCII）、`删暂箧`（只删名字以 yy 开头的目录）、`摹箧内容`、`摹卷到箧`、`行令`、`必须行`、`水土或`。
- `起长驻使`（名称、程序、参数、标记、日志路径）起异步子进程；`使已辞` 退出后收下退出码与输出并写进日志文件；`等候就绪`（反复 GET，任何 HTTP 响应都算就绪，进程先退出或超时则抛出并附日志尾部）；`录尾部`。
- `止长驻使`：按命令行里的唯一标记（如临时目录路径）在 `ps -A -ww -o pid=,ppid=,command=` 里找到进程树，向根发 TERM，最多等十五秒，否则强制终止；再核对后代（如 workerd）都已退出，残留的按确切进程号 KILL。返回说明文字。

## 本机云工（`本机云工`）

`本机云工复验` 一条命令完成：找 wrangler → 确保 Worker 产物 → 起本机云工 → 逐个运行用例 → 停 wrangler → 有失败则以退出码 1 结束（保留工作目录与 `wrangler.log`）。

- 找 wrangler 依次看：环境变量 `云工命令行路径`、仓库旁云仓的 `../yuyan-cloud/应用/包管理服务/node_modules/.bin/wrangler`、作者机器上的固定路径；都没有就打印“跳过：缺 wrangler（…）”并以零退出。
- 产物目录里没有 `入口.mjs`，或环境变量 `重建云工应用=1` 时，用 `豫构 发行 云工 <应用目录> <产物目录>` 构建：发行与接口清单核对由仓库根的 `豫构.wasm` 做，编译交给 `豫构。林檎。豫行`（有则用）。
- `起本机云工` 在临时工作目录里放入产物、配置文件与附加文件，按（绑定名，SQL 文件）逐个执行 `wrangler d1 execute --local`，再在空闲端口上起 `wrangler dev --local --ip 127.0.0.1`（检查器端口另选，持久状态放工作目录的 `.state`），等到 HTTP 就绪；`云工基址` 给出基址。`停本机云工` 停进程并按需删工作目录。

**本机探查与观测**（wrangler 4.129 的本机开发服务自带，不必停服读输出）：

- `云工探查网址 于「路径」为 …`：探查接口 `/cdn-cgi/local/explorer/api` 下的网址，可列 D1、R2、KV 与已发邮件（`/local/email/sending`）等，全部路由见该地址的 OpenAPI。
- `云工观测查询 于「结构化查询」为 …`：对 `/local/observability/query` 运行只读 SQL（SELECT 或 WITH），返回各行（结森数组）。表 `logs` 记着 Worker 的控制台日志（`level` 为 log、info、warn、error、debug，`message` 是参数数组的结森文字）与每个事件的请求行（`message` 是结森字符串，如“POST 网址”），同一事件的各行 `trace_id` 相同、`seq` 按产生次序递增；表 `spans` 记着各事件。`问簿文字` 把文字写成 SQL 字符串字面。
- `控制台日志项`（`级别`、`参数们`、`追踪号`）；`查控制台日志 于「含文」为 …`（`message` 含某段结森文字的日志）；`请求控制台日志 于「网址含」为 …`（请求行网址含某段 ASCII 文字的那个事件的日志，请求行本身不算）；`候索案头录`（再带 `「限时毫秒」为`）先等请求行写进观测库再取，日志断言一般用它。请求里放一个独有的查询参数（如 `yymark=7z`）作记号。
- `触发定时事件 于「定时表达式」为 cron 于「计划毫秒」为 毫秒`：经 `/cdn-cgi/local/scheduled` 触发一次定时事件（零表示当前时刻），返回完整响应（成功时状态 200、正文 `ok`）。

## 本机假服务（`假务`）

- `起假服务 于 路由列` 在 127.0.0.1 的空闲端口上监听，立即返回；`假务基址`、`假务索数`、`诸假务断开`（回应未完就被客户端断开的请求路径，解码后不含查询，按先后；迟回应与流式回应等待时察觉，写失败也记入）、`停假务`。
- 路由：`路由 于「方法」为 文（“*”匹配任何方法）于「前缀」为 解码后路径的前缀 于「处理」为 函数`，按次序取第一条匹配的，都不匹配答 404，处理函数抛出异常答 500。
- 处理函数收到 `假请求`（方法、目标、解码后的路径、解码后的查询对、标头、正文），用 `问参` 取参数；返回 `整段回应`、`文字回应`、`结绳回应`，或流式回应：`事件流回应 于 步列`（`事帧`、`流等`、`流写`、`流断`，走完正常结束），`流式回应` 则给出“取下一步”的函数，可以按其他请求改变的状态动态产生事件。`迟回应 于「毫秒」为 n 于「回应」为 回应` 先等 n 毫秒（其间不写任何字节）再按内层回应作答，n 取得很大即“迟迟不答”。处理函数应当很快返回。

## 改写配方（workerd 黑盒 JS 测试 → 豫言）

1. 在被测目录下建测试包目录（如 `一致性验证/云端复验/`）：包描述（库类型、空默认导入，依赖标准库、结森工具、验收驱动，「包含在」父包）、双语包说明，并在父包「包含包」登记；原来的 `wrangler.jsonc` 与 Worker 外壳（如 `rig.mjs`）放在这里；外壳转发带正文的请求前先读完正文（见首批的 `rig.mjs`），否则应用没读正文就作答时 wrangler dev 可能因“响应之后再读请求流”而退出。
2. 写 `名。测试。豫`：每个 `test(...)` 改成一个顶层 `「例某」乃「验收用例」也。` 与 `用例`；`fetch` 改成 `索`（只要响应头）或 `交换`（读完整段），`Promise.all` 改成先派生 `异步交换`／`异步发起索` 再 `等候全`；`读.下一帧(t)` 改成 `下一帧 于 读 于「限时毫秒」为 t`，`读.读完()` 改成 `读诸完帧`，`读.全文()` 改成 `读完全文`，`AbortController.abort()` 改成 `罢回书`；`assert.deepEqual` 改成 `断结绳同` 或 `断串列同`，`等到` 与 `睡` 改成 `等到`／`等到条件` 与 `小憩毫秒`；JS 的 `.length` 是 UTF-16 长度，按字节比时把非 ASCII 尾巴换成 `计文字节`。
3. 文件末尾写一条 `本机云工复验`，给出套件名、应用目录、产物目录、配置文件、附加文件与建表列表。“需要一边发一边读”的并发改成主流程里的交替循环，不要派生会互相等待的顺序流程。原来替换 `console` 捕获输出的断言改成 `候索案头录`，原来读 wrangler 输出的改用本机探查与观测接口。
4. 在 `应用/百工坊/全树测试/测试规则.tsv` 把该目录登记为“只检查”（CI 没有 wrangler），删掉旧 JS 与它的“跳过”登记，更新所在目录的双语说明。
5. 在仓库根目录构建并运行：`./豫构。林檎。豫行 文件 <测试路径> --输出 名.wasm -j 24`，再 `node 豫言操作系统/宿主/节点/宿主.cjs 名.wasm`。

首批改写：`豫言操作系统/适配/持久频道/一致性验/云端复验`（持久频道九例、组合范例一例）与 `豫言操作系统/适配/网页事件流/一致性验/云端复验`（九例）。用观测接口断言日志的范例：`豫言操作系统/适配/日志/一致性验/云端复验`（十一例）。

## 自测

`测试/往返。测试。豫` 由全树测试自动运行：本机假服务与客户端往返（整段、查询与正文、分块事件流、取消、十路并发、大正文、小饼、超时、处理异常与 404、迟回应与断开记录）、断言信息、用例限时、临时目录与空闲端口、长驻进程按标记停止、SQL 字符串字面。

## 后续版本的事项

- 长驻进程的输出在进程结束后写进日志文件；运行中增量读取输出、向子进程传标准输入与环境变量（现经 `env K=V 程序`）留待工具宿主补原语。
- 建目录、递归删除、按信号终止与子进程树现借 mktemp、rm、cp、ps、kill；Windows 留待后续版本。
- https、IPv6 字面地址、保持连接、分块的请求正文留待后续版本。
- 测试进程被外部强杀时，wrangler 的子进程可能残留；按信号终止的原语补上后改为随父进程退出。
