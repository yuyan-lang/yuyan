# 中文处理

提供词组最长匹配、ASCII 可见字符与空格的全角半角转换、中文整数与大写金额。未知字符保留原样，词典多候选取原顺序首项。每次转换使用首字哈希索引的命中桶，公开的索引接口可以让使用者复用同一索引。

接口包括转全角、转半角、读转换词典、建立转换索引、索引转换、词典转换、整数转中文、中文转整数和金额大写。转换词典是字符串键值对列表，最长键优先，相同长度保留首次出现的值。整数转中文的第一个参数控制金额大写；金额大写接收整数分，避免浮点舍入。

完整数据接口包括简繁及台湾香港地区双向转换、汉字转拼音（调号、数字调、无调）、拼音排序键、笔画排序键与排序、中文小数双向转换、大写金额转分、词典 DAG 与四态 HMM 分词、完整全拼词频候选。数据来自 OpenCC 1.1.9、单字拼音 0.15.0、词组拼音 0.19.0、Unihan 18.0.0 和 jieba 0.42.1，来源与许可见独立「中文处理数据」包。词典、拼音、笔画、分词与输入在初始化时建索引，连续调用查询命中桶。

最新官方 d25 同配工具链构建并真实运行完整数据测试的十五项断言，包含地区词汇、多音词组、调号、笔画、DAG/HMM 与负零小数金额，初始化及运行合计 15.18 秒，峰值常驻内存 1240432640 字节。完整全拼输入三项首候选断言运行 7.96 秒，峰值常驻内存 636534784 字节。两次测量均含首次数据解压及索引初始化，使用节点宿主。
