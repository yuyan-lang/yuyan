# 中文处理

提供词组最长匹配、ASCII 可见字符与空格的全角半角转换、中文整数与大写金额。未知字符保留原样，词典多候选取原顺序首项。每次转换使用首字哈希索引的命中桶，公开的索引接口可以让使用者复用同一索引。

接口包括转全角、转半角、读转换词典、建立转换索引、索引转换、词典转换、整数转中文、中文转整数和金额大写。转换词典是字符串键值对列表，最长键优先，相同长度保留首次出现的值。整数转中文的第一个参数控制金额大写；金额大写接收整数分，避免浮点舍入。

完整数据接口包括简繁及台湾香港地区双向转换、汉字转拼音（调号、数字调、无调）、拼音排序键、笔画排序键与排序、中文小数双向转换、大写金额转分、词典 DAG 与四态 HMM 分词、完整全拼词频候选。数据来自 OpenCC 1.1.9、单字拼音 0.15.0、词组拼音 0.19.0、Unihan 18.0.0 和 jieba 0.42.1，来源与许可见独立「中文处理数据」包。词典、笔画与分词在初始化时建索引，连续调用查询命中桶。汉字转拼音与全拼字词候选查中文处理数据包里预先生成的拼音转换表和全拼候选表：表按键的字节序排列，由「行表」模块二分查找，程序启动时不读词库、不建索引，结果与按旧索引现算相同。

最新官方 d25 同配工具链构建并真实运行完整数据测试的十五项断言，包含地区词汇、多音词组、调号、笔画、DAG/HMM 与负零小数金额，初始化及运行合计 15.18 秒，峰值常驻内存 1240432640 字节。完整全拼输入三项首候选断言运行 7.96 秒，峰值常驻内存 636534784 字节。两次测量均含首次数据解压及索引初始化，使用节点宿主。改为查预算表后，全拼输入三项首候选断言运行 0.13 秒。

台湾转换按 OpenCC 配置分字形和地区词汇：简转台湾与台湾转简包含地区词汇；简转台湾字形、台湾字形转简、繁转台湾与台湾转繁使用字形表。其他模式为简转繁、繁转简、简转香港、繁转香港、香港转繁和香港转简。全角半角转换覆盖 ASCII 可见字符和空格；整数数词采用万、亿、兆递归分组，小数保留逐位精度，金额使用整数分。输入字节上限为十亿，超出平台整数范围的数字继续接大数库。

甲级逐项审核已完成：十一份 OpenCC 官方完整输入与答案、十二个中文适用配置、三调与多音拼音抽样、排序实列表、宽度数词金额和全拼输入均有对应测试；四个正式客体在诺节与同源原生上全部运行通过。壳核心的已知名字和拼音候选已使用本库，既有分页回归通过。详细哈希、退出结果、计时和许可核对见《甲级审核记录》。本轮诺节四客体合计 61.29 秒，中文处理完整数据测试的单包预算为 120 秒。

百万变异、连续查询性能对照、浏览器及裸机验收列为乙级后续实施事项。

输入词条与输入索引的解析实现置于内部输入读入模块，输入模块以原名称和签名委托该实现。全拼数据及完整索引在输入模块初始化时建立，独立解析测试复用同一内部实现。

分词对照已采用 jieba 0.42.1 官方说明的精确模式与未登录词输出，完整词典的「C语言」「B超」保持为整词，未登录英文数字保持整段。词典 DAG 接收中英混合块，HMM 在未知块内按汉字与非汉字分组；五项对照在诺节与同源原生上通过。官方来源：https://github.com/fxsjy/jieba/tree/v0.42.1 ，许可 MIT，原始许可由中文处理数据包保存。
