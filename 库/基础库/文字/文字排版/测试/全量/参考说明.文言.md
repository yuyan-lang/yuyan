# 真段落之别立参考

`参考段落.json` 乃本机Pango一五七一以AאבB为入而成。用Verdana十像素，止提示及度量取整，启子像素之位，边距零；序列化之果取Verdana、Lucida Grande回退。字体依试验之参就机读之，参考之入与数值从本仓AGPL第三版之许可，Pango、系统字体从各自所发之许可。

视觉形次三十六、六百九、六百八、三十七，字体次零一一零，原码点簇零二一三。前进七千、五千七百六十五、六千六百五、七千二十；横位零、七千、一万二千七百六十五、一万九千三百七十；总宽二万六千三百九十，皆每像素千二十四单位。库之出以每像素六十四整数单位，各形容一六四单位量化之差，积位依前形之数累其界。

字体之版：Verdana.ttf之SHA为0da8c12f3e15d95585434d2cf294b3113a3e3fc84bf9ba9d64f2ef834ef4bd98；LucidaGrande.ttc第零面之SHA为c481b239979bf0a4912949494e00568fba253fd6265a9770c8721e7989e111ca。入口置全量之目录，明授字体之径而行；寻常一分钟快试以自造字体定向量。

复成参考之命：

```text
pango-view --no-display --pixels --font="Verdana 10" --hinting=none --hint-metrics=off --subpixel-positions --margin=0 --text="AאבB" --serialize-to=yy段落参考.json --output=yy段落参考.png
```

纯豫言入口：`豫构 构建 文字排版测试 全量 真实段落 --输出 yy真实段落.wasm -j 24`；行之参先拉丁字体径，后希伯来字体径。
