# 文字排版测试

试自断、行间之位、制表进位、竖排、两端齐与必断之后之空行。字体链之试，兼回退、方向级分段与继承字符袭基字之体。

相杂之文之例，试中日韩括之禁则、拉丁希伯来相杂、阿拉伯右向之序、括、明嵌与隔离、行末空白复位、回车换行、图占与竖排。
# 全量隔离

全量目录之隔离入口遵基础库测试设施变异批次之约，受种路径、始序、次数及进度路径。每字节映定通码表，复行实字体段落排版，核行宽非负、形簇在原输入码序之内。父程得依精确序复行异常。百万输入、逐输入分配峰值、裸机及浏览器之验，别录其实。
# 性能入口

全量目录之性能入口受每轮次数，先析定字体，实行中英、希伯来及阿拉伯混排。预热三轮后录九轮整纳秒中位，原生为主，同客体诺节为参。实耗时及运行之物别录之。
