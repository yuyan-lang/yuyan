# 文字排版

文字排版受已整形之段，以六十四分像素之一出诸形之位与行宽。入形存字体序、形号、原码点簇序、前进与偏移，可断之处由统一码行断之层供之。

`排版字形段落` 依可断之处纳行，存不可断之整形簇；`定位一行` 可两端齐与竖排。图之形号为负一，前进记其宽；制表负二，依所设宽定位；必断负三。

`码点断行区间` 受二整数数组引用（码、前进）、个数、最大宽、换行开关与相邻码之可断术，返原索引始止区间，止不含。宽度之单位由用者同之，可用终端列数；负宽为无限。零进续位从前簇，急断惟在次正进簇前。BK、CR、LF、NL成硬行，CRLF一断而二制码皆除于行文。空可出行宽，终端定格可用字素槽、非空哨码配之，存原文之映。

`回退文字分段` 受字体链、码点列、双向层级列与统一码文字属性之术，依体、文与级分之。诸段存原起簇与码点，继承字符从基字之体。

`排版文字段落` 受字形库、整数像素字号、字符串与段选，循全统一码行断、中日韩禁则、双向之术、字体回退与整形，出定位诸形。断行存连字簇，逐行L1复位、L2重排，显式嵌入、隔离参与定级；奇级码点由全四百三十八镜表换之而整形。右为横正，下为纵正；整形器之纵进、偏移化为屏下之向。记录、真参考见《衔接准备记录》《真实段落核验记录》。

段落字形之字段依次体序、形号、簇序、前进、横偏移、纵偏移、断后。`默认段落选项` 受最大前进、行高，造四倍行高之等距制表宽；字形段落最大前进为零或负则用无限宽。过长不可断段独占一行。出段行存行序、行前进、定位形列；定位形存原形、横位、纵位。

显示控件以诸式片统解双向之境，依实全行范围复级，取原片体、色、距画定位形。断后复整，宽增则复择断处，宽缩则试合邻软行，省号每去全簇复量之。实分色帧、行中式尾空、正距收敛皆有别立双端之验。

回车换行相连则必断一次，制表依其宽而进，字符 U+FFFC 留一字号为图之位。用者可径成「段落字形」以定图之前进，并依图之尺度定段之行高。

寻常试验核中英、中日韩括号，阿拉伯、希伯来之向，嵌入、隔离、末空、回车换行、两端齐、继承回退、制表、图位、竖排。全量目录存Pango一五七一之定布局及真体二十二项回退、形、簇、几何参考；体文件依径就机读之。

后续验收之事：尽核甲之必需入口终源，验上游USE殊文、跨体连字之境、百万隔离、资源败断，量性能，验浏览器、裸机而尽迁用者。

此包乃纯豫言原创，从本仓AGPL第三版之许可。统一码行断、双向、文字属性、镜像数据取依赖库官方统一码第十八版生成表，出处、许可见其包说明。字体解、开放字体GSUB、GPOS、GDEF由字体、文字整形依赖供之。Pango用于别立参考之数。
# 性能短基线

于macOS ARM64以定测试字体混排，每轮百次，预热三轮后取九轮中位：原生六亿九千九百一十八万二千纳秒，同客体诺节五亿一千二百三十二万二千纳秒。今原生约为诺节一点三六五倍；实快照、客体散列及输入见[短批与性能记录](短批与性能记录.汉语.md)。同机系统排版库及实字体之速，续别量之。
