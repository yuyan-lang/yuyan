# 正则全量测试

本包提供纯豫言正则和通配符变异入口。每个编号生成一个字节变异，依次调用模式解析、字符串执行、字节执行和通配入口。通配入口同时读取文件名选项与花括号展开。

变异模式按编号轮换空、`u`、`v`、`ims`、`x`、`imsxu` 标志。每个成功编译的变异模式另行查找短确定文本与其字节串，并读取第零捕获。固定模式继续对任意变异文本及字节执行，以覆盖解码边界。编译拒绝与变异模式执行拒绝分别统计；变异模式串与字节执行次数均为实际编译接纳数。

无参数时以起号 0、总量 1000000、批量 10000 运行限时隔离批次。`统筹 起号 总量 批量` 可指定范围与小批数量；`子 起号 次数` 可直接重放单批。例如 `子 100 20` 执行编号 100 至 119。

每个隔离批次限时 600000 毫秒。批次运行前逐例记录 `/tmp/yy正则模糊-<批起号>.进度`，可用于定位陷阱或超时编号。可捕获事故计入对应入口拒绝数量。操作系统陷阱、子进程非零退出及超时使统筹失败。子批输出真实完成数与各入口拒绝数，父程序只累加成功完成的子批。

子批完成后把计数写入 `/tmp/yy正则批统计-<起号>-<次数>.json`。父程序在子批零退出后读取完整 JSON，核对起号、次数、各计数范围以及编译接纳数与变式执行数的守恒，再输出该批记录。旁车记录编译、固定串、固定字节、通配拒绝数，以及合法变式执行次数与两种执行拒绝数。

原版驱动使用完整 25a84347 同配链完成四固定入口各百万次尝试，统筹正常退出；系统测量实时间 2667.22 秒、统筹观测最大常驻 135888896 字节。新增旁车计数版已完成二十五项隔离短批和逐批 JSON 回收。逐子程序生命周期峰值与新增计数版全量运行继续验收。
