# 编码转换

此包以豫言编解 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE、UTF-32BE，惟依标准库。

`UTF8解码` 受字节串及严验之爻，还可有之码点列；`UTF16解码`、`UTF32解码` 又受小端之爻。严验拒坏列，宽验代以 U+FFFD。首记定端而去之。编码受码点列，出字节串而不置首记；非法标量代以 U+FFFD。

`字符串UTF16长度` 计串之双八位码元。包配置之语言服务以此换算列数。

试验之口为 `测试/统一编码。测试。豫`，验平面字、域外字、极标量、零字节、两端、首记及坏列。

规取 WHATWG Encoding Standard（https://encoding.spec.whatwg.org/）及 Unicode Standard。实现从仓库之许可，试数于本仓独作。

后事：旧编码、诸标签、流式转换、探测、官索引及 WPT 对照、百万变异之试、性能之量、原生及裸机之验。
