# 编码转换

本包以纯豫言实现 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE 和 UTF-32BE 的编码与解码，只依赖标准库。

`UTF8解码` 接受字节串与严格开关，返回可选码点列表；`UTF16解码` 与 `UTF32解码` 另接受小端开关。严格解码拒绝非法序列，替换解码输出 U+FFFD。首 BOM 决定端序并移除。编码函数接收码点列表，输出无 BOM 的字节串，非法标量替换为 U+FFFD。

`字符串UTF16长度` 计算字符串的 UTF-16 码元数。包配置的语言服务使用此函数换算列号。

测试入口为 `测试/统一编码。测试。豫`，包含基本平面、补充平面、最大标量、零字节、两种端序、BOM 与非法序列。

规则出处为 WHATWG Encoding Standard（https://encoding.spec.whatwg.org/）及 Unicode Standard。实现遵循仓库许可，测试向量在本仓独立编写。

后续事项：WHATWG 全部旧式编码及标签、流式转换、编码探测、官方索引与 WPT 对照、百万输入模糊测试、性能测量、原生及裸机验收。
