# 编码转换

固定短字符串编解性能已在Node与同源原生测量八组各七轮，每轮10000次、预热1000次，校验和一致。UTF-8往返中位数为Node 0.025912秒、原生0.015722秒；GBK为2.787710秒、1.937451秒。完整八组及112轮数据见相邻编码转换全量测试包的《七轮编解性能记录.汉语.md》。后台百万任务参与本次测量环境。

本包以纯豫言实现 UTF-8、UTF-16LE、UTF-16BE、UTF-32LE 和 UTF-32BE 的编码与解码，只依赖标准库。

国标编码支持 WHATWG GBK 与 gb18030，共用解码器，含四字节区及 GB18030-2005 的十八项非对称编码映射。`国标解码` 接收字节串与严格开关；`国标编码` 接收码点列表与 GBK 限制开关，无法表示的码点返回空结果。西文编码支持 windows-1252。

`解码文本` 接收编码名、字节串与严格开关，返回可选字符串；`编码文本` 接收编码名与字符串，返回可选字节串。网页接口依 WHATWG 将 ISO-8859-1 与 US-ASCII 标签映射到 windows-1252。`解码传统文本` 与 `编码传统文本` 供邮件等 IANA 协议使用，ISO-8859-1 逐字节直映，US-ASCII 严格解码拒绝高位字节。

`UTF8解码` 接受字节串与严格开关，返回可选码点列表；`UTF16解码` 与 `UTF32解码` 另接受小端开关。严格解码拒绝非法序列，替换解码输出 U+FFFD。首 BOM 决定端序并移除。编码函数接收码点列表，输出无 BOM 的字节串，非法标量替换为 U+FFFD。

`字符串UTF16长度` 计算字符串的 UTF-16 码元数。包配置的语言服务使用此函数换算列号。

测试入口为 `测试/统一编码。测试。豫`，包含基本平面、补充平面、最大标量、零字节、两种端序、BOM 与非法序列。

规则出处为 WHATWG Encoding Standard（https://encoding.spec.whatwg.org/）及 Unicode Standard。实现遵循仓库许可，测试向量在本仓独立编写。

国标索引源为官方 `index-gb18030.txt`（2024-09-18，SHA-256 `746b3c55f1a8ec4b90b451f384437a17fd37cd51cd668456a28071a758d10784`）与 `index-gb18030-ranges.txt`（SHA-256 `874c6b6f6f74cf7d427ad228d5b41ddd9354fffd92a2259bf429f86e6baa7a1e`）。原始数据下载于仓外，`工具/索引生成。豫` 生成紧凑十进制文本，初始化时转数组。WHATWG 版权所有者为 Apple、Google、Mozilla、Microsoft；嵌入源码的数据按 BSD 3-Clause 使用，原许可留存于 `数据许可.txt`。

本阶段在 pit-mac 用最新配套工具链构建并运行统一编码测试，UTF、BOM、非法序列、西文、国标双字节、四字节首末边界、特殊指针 7457 与表情往返通过。传统文本模块类型检查通过。

本包现含全部 WHATWG 编码与 228 个官方标签，增加 Big5、EUC-JP、Shift_JIS、EUC-KR、ISO-2022-JP、单字节编码、replacement 与 x-user-defined。UTF-32 两种端序也可使用。标签按 ASCII 大小写及首尾空白归一。

`新文本解码态` 接收编码名与严格开关；`解码文本块` 接收状态与字节块，返回可选的状态和文本；`终结文本解码` 输出余留文本。状态保留未足字节及 ISO-2022-JP 模式。`新文本编码态`、`编码文本块`、`终结文本编码` 提供分块编码，日文转义编码终结时返回 ASCII 模式。统一文本入口按标签固定 UTF 端序，首 U+FEFF 移除，后续 U+FEFF 保留。

`工具/全部索引生成。豫` 顺序调用索引生成器，生成全部 34 张官方表，共 76981 项映射及范围记录。`工具/标签生成。豫` 读取官方 encodings.json。完整来源 SHA-256 留存于 `官方来源SHA256.txt`；官方测试许可留存于 `官方测试许可.txt`。

2026-10-08 本机 ec25 完整同配工具链验证通过：包检查、60 个包源码的整体类型检查、38 条 WPT 一次与逐字节流式向量、官方多字节索引逐项、单字节全部字节及标签、统一编码与传统协议、旧式多字节与 ISO 状态往返。测试入口分别为 `官方向量。测试`、`全索引。测试`、`单字节标签。测试`、`统一编码。测试`、`多字节。测试`。

同一组五个已验 ec25 客体现已用 16cffa740 配套原生生成器及执行器在本机运行通过。新增小批在 Node 与原生各运行 42 编码各 25 条，校验和一致；记录见 `原生与小批验收记录.汉语.md`。正式百万、性能与裸机验收留待后续。
