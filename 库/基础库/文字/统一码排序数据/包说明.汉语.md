# 统一码排序数据

纯豫言读取 Unicode 默认排序元素，构造三层排序键。

数据来自 Unicode 18.0.0 的 [DUCET](https://www.unicode.org/Public/UCA/latest/allkeys.txt)，遵循 [Unicode 数据许可](https://www.unicode.org/license.txt)。生成工具接收仓外下载的 allkeys.txt 与输出文件两个参数。

调用者先作规范分解；排序以默认非忽略可变元素模式逐级比较，支持连续收缩、展开与汉字和特殊文字的隐式权重。非连续收缩、地区裁剪与隐式范围内的未分配码点区分留待后续版本。
