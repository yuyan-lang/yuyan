# 统一码排序压紧与默认排序全集验证

日期：2026-10-08。独立工作树：`基础库-统一码排序`。

## 实现

- Unicode 18.0.0 DUCET 从 2,360,138 字节的源码文本表压紧到 415,615 字节，比例约 17.6%。
- 编码采用桶内首码有向差与五位变长整数；各高位桶按需解析，用低八位索引候选行。
- 统一码字符串包装先进行 NFD，并传入规范组合类，实现非连续收缩；跳过较低组合类的字符，保留其后续权重，同类、较高类和起始字符形成阻塞。
- 按 Unicode 18 属性与已分配区间精确计算统一表意文字、女真字符及部首、西夏、契丹、女书与小篆的隐式权重，未分配空洞使用默认隐式权重。
- 官方驱动附加相同级，令 FFFE 使用唯一最低权重。
