# 中文处理性能验证

固定语料测量词典 DAG 与 HMM 分词、全拼词频查询。预热两轮后测量七轮，以基础库测试设施的纳秒中位数报告热点时间。每轮核对输出字节长度校验和，次数由命令行指定。当前全拼入口查主线预算候选表，输出保持词频顺序；热点时间包含查询与输出构造。测量记录保留原索引实现的客体摘要与实际结果，整合后的预算表入口留待后续测量。

入口为性能测量，参数为每轮重复次数。固定中文样本与中英混合样本包含官方 jieba 0.42.1 说明的精确模式及新词识别例子。

2026-10-08，同客体诺节与原生每轮1000次、七轮中位：分词分别269652458和795018000纳秒，全拼排序分别162918250和708759000纳秒。两端九轮字节校验通过且退出零；Chrome抽样退出零。复现、产物摘要、整体冷进程资源及待测事项见[测量记录](测量记录.汉语.md)。

入口 `简转繁冷测` 接收输入文件与输出文件，运行既有简转繁接口一次。870字节官方样本在 OpenCC 1.4.2 CLI、诺节和同源原生中逐字节一致，冷进程整体实耗分别0.05、3.19和5.58秒；原生相对 CLI 约111.6倍，优化留待后续原生工具链与数据初始化工作。范围、峰值资源与复现见[简转繁参考记录](简转繁参考记录.汉语.md)。
