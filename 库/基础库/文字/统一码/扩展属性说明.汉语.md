# 扩展字符属性

`码点字母性` 查询 Unicode 18.0.0 的 `Alphabetic` 属性。数据来自 `DerivedCoreProperties.txt`。

`文字扩展类别` 返回 `Script_Extensions` 的文字全名列表。数据来自 `ScriptExtensions.txt`。码点采用缺省值时，列表含 `文字类别` 的一个结果。

`统一码文字别名` 与 `文字类别别名` 将官方文字短名、全名及旧别名转换成文字全名。`文字类别名称有效` 查询名称是否在官方文字别名表中。`统一码属性别名` 返回属性全名；`统一码类别别名` 返回一般类别短名。别名均按官方原文精确比较；未知名称的查询结果为空串。

文字与一般类别别名来自 `PropertyValueAliases.txt` 的 `sc`、`gc` 记录；属性别名来自 `PropertyAliases.txt`。源文件位于仓库外 `~/repos/yuyan-worktrees/豫言数据/统一码/18.0.0/`。

生成字母性表时，向 `属性生成。豫` 传入 `DerivedCoreProperties.txt`、表名 `字母表`、字段号 `1`、筛选 `Alphabetic`、模式 `0`，输出数据包的 `字母。豫`。生成文字扩展表时，传入 `ScriptExtensions.txt`、表名 `文字扩展表`、字段号 `1`、空筛选、模式 `0`，输出 `文字扩展。豫`。

`别名生成。豫` 接受输入文件、筛选属性、表名、输出路径。文字别名使用 `PropertyValueAliases.txt`、`sc`、`文字别名表`；类别别名使用该文件、`gc`、`类别别名表`；属性别名使用 `PropertyAliases.txt`、空筛选、`属性别名表`。各输出文件分别为数据包的 `文字别名。豫`、`类别别名。豫`、`属性别名。豫`。

`简单折叠码点` 采用 `CaseFolding.txt` 的 C 与 S 记录，C 复用现有 `折叠表`，S 生成 `简单折叠表`。缺省映射为原码点。`简单折叠等价码点` 查询相同简单折叠目标的所有码点，包括该目标自身；C 与 S 的逆表分别为 `折叠逆表`、`简单折叠逆表`。三张新表均取字段 `2`，正表采用模式 `0`，逆表采用新增模式 `3`，筛选分别为 S、C、S。
