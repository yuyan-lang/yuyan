# 字符串属性

`统一码字符串属性` 接收官方属性全名，返回有限的码点序列列表。`统一码字符串属性有效` 查询该名称是否受支持。支持 Basic_Emoji、Emoji_Keycap_Sequence、RGI_Emoji_Modifier_Sequence、RGI_Emoji_Flag_Sequence、RGI_Emoji_Tag_Sequence、RGI_Emoji_ZWJ_Sequence、RGI_Emoji。

数据取自 Emoji 18.0 的 [emoji-sequences.txt](https://www.unicode.org/Public/emoji/latest/emoji-sequences.txt) 与 [emoji-zwj-sequences.txt](https://www.unicode.org/Public/emoji/latest/emoji-zwj-sequences.txt)。官方范围记录展开成单码点序列，多码点记录保留顺序。RGI_Emoji 为其余六种集合的联合。

原始文件存于仓库外 `~/repos/yuyan-worktrees/豫言数据/统一码/18.0.0/emoji/`。用 `别名生成。豫` 分别读取两篇，筛选为空，表名分别为 `表情序列表`、`表情连接序列表`，输出数据包的 `表情序列。豫`、`表情连接序列。豫`。生成沿用现有别名工具，两张表留待独立生成窗口。
