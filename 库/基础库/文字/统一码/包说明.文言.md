# 统一码

`工具/官方映射核验。豫` 可径读官定 BidiMirroring 及 CaseFolding C/S 诸录，遍比一百一十一万四千一百一十二码及缺省还码。实得核验之果与 CPU、存储之测见[属性官方全域核验记录](属性官方核验记录.汉语.md)。

`工具/官方二元核验。豫` 为五十三字性各作官定应值之阵，遍比五千九百零四万七千九百三十六码之真与假，异者零；亦可据字性全名复核。

官定脚本核验遍察 Script_Extensions 全码及 Scripts 缺省之值；官定别名核验遍察字性、脚本、类别七百四十八官名，异者皆零。

官定表情核验遍察七集诸员及其数；官定逆折叠核验遍察全码 C/S 同类之员。同一客体、同一官源，于 Node 与苹果臂六十四原生执行器各行之；每端比码六千三百五十万四千三百八十四次、别名七百四十八、表情诸员七千九百四十四次，异者皆零。耗用与复行之命见[属性官方核验记录](属性官方核验记录.汉语.md)。

以豫言为文字计算之术，供字符之性、四种规整、大小写与折叠、字素词句之分、东亚列宽、双向段及域名码。排序之数，别置统一码排序数据包。

规范合成随问析官桶为首码所统之整数索引，后问复用次码与成码，除录于初藏时滤之。官定规整及全桶复核之果、Node 与原生三轮千次之测，见[合成缓存性能记录](合成缓存性能记录.汉语.md)。

规范组合类与分解之对，随问展官桶，后直取整数或码列。三术全码精核、双端官定规整及千次三轮之测，见[规整属性缓存性能记录](规整属性缓存性能记录.汉语.md)。

标题之转，循词界取各词有大小写之首字，条件小写仍察原篇前后之境；大小写可忽略之性，参于西格玛词尾之判。大小写映射以尾递归积其展开之码，复循原序出之。

`统一码/镜像` 中 `码点镜像` 之型为 `整数→整数`，据十八版统一码官篇 `BidiMirroring.txt` 全四百三十八录求其对码，无对则还原码。诸对兼括号、比较及数学诸符，含 ≤↔≥；统一码总集导出此术，数由统一码数据包供之。全表生成、原篇与表各四百三十八录之核、最新 d8 全套于本机之型核与链接、七例 Node 运行皆过；命令、配套 SHA 及实得退出码见[镜像准备记录](镜像准备记录.汉语.md)，构建之程见[本机日志](/tmp/yy镜像七向量构建.txt)，接口之义见[码点镜像](镜像说明.文言.md)。

字符之性取 [Unicode 18.0.0](https://www.unicode.org/versions/Unicode18.0.0/) 官方之数，循 [Unicode 数据许可](https://www.unicode.org/license.txt)。生成器受仓外原料，成两级桶区间表；邻桶同者合为界，问字则先取其高八位，而察桶内之界。

## 主要接口

| 模块 | 接口 | 型与义 |
| --- | --- | --- |
| 属性 | 一般类别、文字类别、东亚宽度、字素断类、词断类、句断类、行断类 | 整数→字符串；还官定类名 |
| 属性 | 双向类别 | 整数→整数；还双向算法所约之类号 |
| 属性 | 规范组合类 | 整数→整数；还标准组合之类 |
| 属性 | 规范分解、兼容分解 | 整数→整数列；还直接分解之码 |
| 文字规整 | 规范合成文字、规范分解文字、兼容合成文字、兼容分解文字 | 字符串→字符串；各行 NFC、NFD、NFKC、NFKD，谚文以算法拆合 |
| 大小写 | 转小写、转大写、转标题大小写、大小写折叠 | 字符串→字符串；循默认全映射与西格玛前后之境，映射可展为多码 |
| 切分 | 字素切分、词切分、句切分 | 字符串→字符串列；循 UAX 29 还原篇之片 |
| 切分 | 字素码点边界、词码点边界、句码点边界、行断码点边界 | 整数列→整数列；界以码点之位计，空篇惟还零界 |
| 列宽 | 码点列宽、文字列宽 | 整数→整数、字符串→整数；W/F 二列，疑宽一列，Mn/Me/Cf/Cc 零列；篇按字素取宽之大者相积，地区旗帜之对二列；含 VS16 而合官定基本表情或键帽序之前缀者，字素至少二列 |
| 码点 | 字符串码点、码点字符串 | 字符串→整数列、整数列→字符串；严格八位码与标量相往返 |
| 二元属性 | 统一码二元属性、统一码二元属性有效 | 字符串→整数→爻、字符串→爻；问全官二元之性及官名 |

导入冠包及模块之名，如 `寻观「统一码」之「文字规整」之书`。规整、切分受合法八位码，坏字节由严格读码报错。码点问表受整数，出其域则还各性之缺省。大小写循统一码默认之规，地区专用之择留待后版。列宽约面向定列终端；字形实际前进之量，由整形、排版诸库计之。

首用者为行编辑之字素移动与列宽：编辑径召统一码切分，展示径召统一码列宽；官定字素移动八百五十三例于诺节、同源原生皆过。`豫言操作系统文字规整共用适配` 以本库供去首尾空白、全小写、UTF-16长及字母数字之判，供原生、裸机接线。

完整乙级之性能、强资源界、诸后端及迁移之验，继载实施记；级依逐项实核而录。
