# 域名编码

`域名码编码` 纳统一码标量之列，出 RFC 3492 Punycode。`域名码解码` 纳其码，出标量之列。此术纳无 `xn--` 之载荷，基本 ASCII 字循旧序而存，编码所出数字字母皆小写。

算法本于 [RFC 3492](https://www.rfc-editor.org/rfc/rfc3492)。

`国际化域名` 具 `域名转基本`、`域名转统一`，纳文，返所转之文与失验之爻；爻阳则失。默行非过渡之术，验双向与连接，供 WHATWG 网址主机之用。

`域名按选项转换` 纳选项数、基本输出之爻及文。诸位可相加：三规 1，连字符 2，双向 4，连接符 8，过渡 16，域长 32，容坏码 64。统一码输出存所可转者而告失。`国际化域名核心` 可授属性与规整之术。

`码点` 具 `字符串码点` 与 `码点字符串`，皆以豫言读写通码八，验残码、冗码、代理与标量之界。

`域名状态表`、`域名映射表` 取 Unicode 18.0.0 [域名映表](https://www.unicode.org/Public/idna/latest/IdnaMappingTable.txt)，于 2026-10-07 下载，遵 [统一码数据许可](https://www.unicode.org/license.txt)。以本包 `属性生成` 生之，状态取字段一，映码取字段二，模式皆零；原数据藏仓外。

协议诸例验大小写、过渡、ACE、连接上下文、双向、连字符、域长及标量边界。官方一致性之验另行之。
