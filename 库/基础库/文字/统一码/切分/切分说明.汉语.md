# 统一码切分

本组模块提供 Unicode 18 的属性驱动码点边界算法。字素、词、句依据 UAX29，行断依据 UAX14。

| 模块 | 入口 | 参数 |
|---|---|---|
| 字素切分 | 字素码点边界按属性 | 字素断类回调、印度连接断类回调、扩展图形回调、码点列 |
| 词切分 | 词码点边界按属性 | 词断类回调、扩展图形回调、码点列 |
| 句切分 | 句码点边界按属性 | 句断类回调、码点列 |
| 行断 | 行断码点边界按属性 | 行断类回调、码点列 |
| 完整行断 | 行断码点边界按完整属性 | 行断类回调、一般类别回调、东亚宽度回调、扩展图形回调、码点列 |

类别回调接收整数码点，返回 UCD 原始属性值字符串；扩展图形回调返回爻。每个入口返回升序整数边界列，偏移以码点为单位，含零与输入长度。空输入返回仅含零的列。边界之间保留所有输入码点，词界包含标点、空白等片段。

字素实现扩展字素簇规则，包含谚文、组合标记、表情连接、地区指示符配对，以及 Unicode 18 的印度连接规则。词界包含字母、希伯来引号、数字中缀、片假名、连接标点和忽略类上下文。句界包含缩略、数字、小写前探、闭标点、空白、段隔与忽略类上下文。

完整行断实现 LB1 至 LB31，包含组合类继承、数字、引号及其上下文、东亚宽度、韩文、印度音节、地区指示符配对与表情修饰符。只授行断类的入口采用 `Lo`、`N`、阴作为其余属性的默认值，并委托完整规则。统一码属性表调用完整入口。

规则测试用人工属性输入隔离算法和数据表；失败抛出事故。统一入口为 `测试/切分。测试。豫`。

官方核验工具为 `工具/官方切分核验。豫`，接收数据目录及可选模式 `全部`、`字素`、`词`、`句`、`行断`。目录包含官方四个 `*BreakTest.txt` 文件。测试驱动读取十六码点与边界标记，报告例数、失败数及前二十个失败行，失败时抛出事故。官方行断验证排除返回值中的零位标记。

Unicode 18 官方全量核验结果：GraphemeBreakTest 853 例、WordBreakTest 1,944 例、SentenceBreakTest 512 例、LineBreakTest 19,346 例，共 22,655 例全部通过。数据存于仓外统一码数据目录，核验时以目录参数传入。

后续事项：主包接入字符串包装；词与句的长上下文扫描优化留待性能测量；语种定制、模糊测试与裸机验证另行推进。

规范来源：[UAX29 修订 49](https://www.unicode.org/reports/tr29/tr29-49.html)、[UAX14 修订 57](https://www.unicode.org/reports/tr14/tr14-57.html)；向量来源：[Unicode 18 官方辅助数据](https://www.unicode.org/Public/18.0.0/ucd/auxiliary/)。
