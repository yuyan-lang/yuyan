# 统一码切分

本组模块提供 Unicode 18 的属性驱动码点边界算法。字素、词、句依据 UAX29，行断提供基本换行机会和中日韩标点禁则。

| 模块 | 入口 | 参数 |
|---|---|---|
| 字素切分 | 字素码点边界按属性 | 字素断类回调、印度连接断类回调、扩展图形回调、码点列 |
| 词切分 | 词码点边界按属性 | 词断类回调、扩展图形回调、码点列 |
| 句切分 | 句码点边界按属性 | 句断类回调、码点列 |
| 行断 | 行断码点边界按属性 | 行断类回调、码点列 |

类别回调接收整数码点，返回 UCD 原始属性值字符串；扩展图形回调返回爻。每个入口返回升序整数边界列，偏移以码点为单位，含零与输入长度。空输入返回仅含零的列。边界之间保留所有输入码点，词界包含标点、空白等片段。

字素实现扩展字素簇规则，包含谚文、组合标记、表情连接、地区指示符配对，以及 Unicode 18 的印度连接规则。词界包含字母、希伯来引号、数字中缀、片假名、连接标点和忽略类上下文。句界包含缩略、数字、小写前探、闭标点、空白、段隔与忽略类上下文。

规则测试用人工属性输入隔离算法和数据表；失败抛出事故。统一入口为 `测试/切分。测试。豫`。

后续事项：接入统一码生成属性表与字符串包装，运行官方 GraphemeBreakTest、WordBreakTest、SentenceBreakTest、LineBreakTest；行断补齐数字、引号、韩文、地区指示符与组合类继承；词与句的长上下文扫描优化留待性能测量。

规范来源：[UAX29 修订 49](https://www.unicode.org/reports/tr29/tr29-49.html)、[UAX14](https://www.unicode.org/reports/tr14/)。
