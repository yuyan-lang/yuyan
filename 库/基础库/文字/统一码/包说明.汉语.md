# 统一码

`工具/官方映射核验。豫` 可直接读取官方 BidiMirroring 与 CaseFolding C/S 记录，对照全部 1,114,112 个码点及缺省回退。已完成的真实结果与 CPU、内存测量见[属性官方全域核验记录](属性官方核验记录.汉语.md)。

`工具/官方二元核验。豫` 对 53 属性逐一建立官方期望数组，完成全部 59,047,936 次码点真值与假值对照，差异为零；该工具支持按属性全名复验。

官方脚本驱动完成 Script_Extensions 的全部码点与 Scripts 回退对照；官方别名驱动完成属性、脚本、类别的全部 748 个官方名称对照，差异均为零。

官方表情驱动核验七个 Emoji 集合的全部成员和数量；官方逆折叠驱动遍查全部码点的完整 C/S 等价类。同一客体与官方输入在 Node、苹果臂六十四原生执行器运行，每端共 63,504,384 次码点判断、748 个别名和 7,944 次表情成员判断，差异均为零。资源与复现命令见[属性官方核验记录](属性官方核验记录.汉语.md)。

提供纯豫言文字计算模块：字符属性、四种规范化、大小写转换与折叠、字素词句切分、东亚列宽、双向段落与域名码。排序数据由独立的统一码排序数据包提供。

标题转换按词界选取每词首个有大小写字符，并按整篇原码点保留条件小写的前后上下文；大小写忽略属性参与西格玛词尾判定。大小写映射以尾递归累计展开码点，再按原序输出。

`统一码/镜像` 的 `码点镜像` 接口为 `整数→整数`，查询 Unicode 18.0.0 官方 `BidiMirroring.txt` 的完整 438 条映射，无映射时返回原码点。映射覆盖括号、比较及数学符号，包括 ≤↔≥；统一码总集导出该接口，数据由统一码数据包提供。完整表生成、438 条源记录与表记录核对、最新 d8 完整配套的本机类型检查与链接、七项 Node 向量运行均通过；生成命令、配套 SHA 与真实退出码见[镜像准备记录](镜像准备记录.汉语.md)，构建过程见[本机日志](/tmp/yy镜像七向量构建.txt)，接口说明见[码点镜像](镜像说明.汉语.md)。

属性采用 [Unicode 18.0.0](https://www.unicode.org/versions/Unicode18.0.0/) 官方字符数据库，依据 [Unicode 数据许可](https://www.unicode.org/license.txt)。生成器输入仓外原始资料，输出两级桶区间表；相同邻桶合并为范围，查询先按码点高八位定位，再读取桶内区间。

完整统一码官方一致性测试、全部平台验证、百万变异输入与性能测量列入后续实施记录，验收等级以官方核验结果为准。
