# 正则

正则提供纯豫言的模式编译、搜索、捕获、替换、分割和路径通配。

脚本数字转义按完整模式的捕获组数选择十进制反引，支持前向反引。非 `u`/`v` 模式的无效反引编号使用旧式八进制或 `8`、`9` 身份字面；八进制首位 `0` 至 `3` 最多三位，`4` 至 `7` 最多两位。`u`/`v` 模式按实际捕获组数校验数字反引，并检查零转义后续数字。脚本非 `u`/`v` 模式的 `p`、`P` 为身份字面，`u{…}` 的花括号交量词规则解析；字符类中的旧式控制转义支持数字和下划线。

`编译正则`接收模式和标志，`查找正则`接收已编译模式、文本和起始码点，返回可选匹配结果。`匹配起点`、`匹配终点`和`匹配捕获`使用左闭右开码点范围；捕获编号零表示整项。`全部查找正则`依次返回互不重叠的结果，遇到空匹配后前进一个码点，保留末尾空匹配一次。

字符串编译入口 `编译正则` 与 `编译脚本正则` 接收字符串模式；它们的结果经字符串查找入口 `查找正则` 执行时，起点和捕获范围仍以码点计数。`编译脚本正则`选择脚本语法与捕获规则。

UTF16 码元语义使用 `编译码元正则` 与 `查找码元正则`。前者接收模式码元整数列和标志，后者接收编译结果、输入码元整数列和码元起点。每个整数处于 0 至 65535，孤立高低代理项保持原整数；切取半个代理项的捕获可直接按结果范围切取输入整数列。非 `u`/`v` 模式的模式与输入均逐码元处理；`u`/`v` 模式合并有效代理对为一个执行码点，并保留孤立代理项。Unicode 模式的起点处于有效代理对中间时，从该对首码元边界开始执行。

`查找码元正则`沿用 `匹配结果` 类型。由此接口所得结果的 `匹配起点`、`匹配终点`、`匹配捕获` 全部使用左闭右开的码元区间，未参与捕获保持 `(-1, -1)`；`匹配命名编号`沿用编译时的组编号。码元接口的编译与执行由共享整数解析器及正则执行器完成。

`正则替换`替换全部结果，模板支持`$&`、`$1`至`$99`、`$<名>`与`$$`。`正则分割`返回分隔符之间的字符串列。`完整匹配正则`为模式增加首尾锚点，核对整个文本并保留备选分支语义。

互斥备选分支可以共用捕获名称。`匹配命名编号`选择实际参与的组，命名反向引用和替换模板使用同一选择；全部未参与时捕获为空。

捕获组名按统一码 `ID_Start` 与 `ID_Continue` 属性检查，支持组名中的 Unicode 转义。`u` 与 `v` 模式的固定四位配对代理项转义合为一个码点；花括号转义接收零至 `10FFFF` 的非空十六进制数字序列，并逐位检查上界。

`v` 字符集合支持并集、交集、差集与 `\q{…}` 有限字符串。运算组合用嵌套集合表达，保留符号按转义规则书写；可能含字符串的集合补集在编译时检查。

`文件名匹配`依次接收模式、文本、路径保护、禁止转义、隐藏保护。`通配匹配`开启路径及隐藏保护，支持双星跨目录。`花括号展开`展开嵌套逗号分支。

普通字符类中的左方括号按字面字符解析，范围首尾的字面与转义字符使用同一范围检查。`v` 集合中的左方括号开启嵌套集合。

公开编译使用 Perl／RE2 传统语法，`u` 表示统一码。普通字符类首项的 `]` 是字面字符，POSIX 命名类提供十四种传统类别。花括号支持省略下界与内部水平空白，未完成量词语法按字面字符解析。完整计数范围验证上下界顺序，十进制数值在乘加前验证整数范围；任意数量的前导零可以使用。

传统重复保留先前参与的子组，成功的空迭代写入捕获；未参与组的反向引用使该分支失败。`\\Q…\\E` 按字符引用字面文本，后续量词绑定引用文本的末字。

`编译脚本正则` 接收模式和标志，选择脚本语法及重复捕获规则；总集显式导出此入口。`编译正则内部` 接收模式、标志和脚本选择布尔值，两种入口共享同一解析正文。脚本旗使用 `d g i m s u v y`，`u` 与 `v` 互斥。完整 UTF-16 码元结果与孤立代理执行由后续码元接口承接。

传统转义支持 `\\a` 铃声、`\\e` 退出控制符及 `\\x{…}` 码点；花括十六进制数逐位检查至 `10FFFF`。单字属性 `\\pL` 与 `\\PL` 表示字母类及其补集，`(?#…)` 提供组内注释。

字符属性与大小写来自统一码库。源码与测试保持宿主无关，模式解析与执行使用豫言自己的实现。

`x` 在字符类外跳过空白和至换行或输入末尾的 `#` 注释；原子与量词之间、量词与非贪婪标记之间使用同一规则。字符类内的空白、转义空格与转义 `#` 保留字面意义。

`\w` 与 `\b` 使用同一统一码词字符集合：字母属性、标记、十进数字、连接标点和连接控制符。词界位于词字符与其他字符的交界；统一码默认词切分由统一码库的切分接口提供。

扩展模式的回溯在单次搜索中共享一亿步预算，包含所有尝试的起点。耗尽时抛出异常。全部查找中的每次搜索分别使用这一预算。

线性程序的指令规模估算在现有一百万预算加一处饱和。合法整数极值和嵌套重复先截幅再乘加，超过预算的模式抛出指令上限异常。

字节接口把每个原始字节映射为同值码点，捕获范围按原始字节计数，可以处理零字节及无效 UTF-8。`查找字节正则`、`全部查找字节正则`、`字节正则捕获`、`正则替换字节`与`正则分割字节`提供相应操作，替换模板也是原始字节串。

浏览器验收页为 `豫言操作系统/宿主/浏览器/正则。测试页.html`，复用既有张量测试服务与浏览器值桥，顺序装载同编译器生成的核心、字节、六百三十例差分三个 Wasm 客体。页内胶水读取客体输出并核对预期通过文本；模式解析、执行与断言均由豫言客体完成。已实际在 Chrome 完成这三个客体，页面完成计数为三。

传统数字逃逸采用 Perl 反引消歧规则：`\0` 后读取最多两个八进数字；类内八进字符总计最多三位，`\8`、`\9` 表示对应字面数字。类外单数字、首位 8／9 以及已有捕获组号作为数字反引，其他多数字按最多三位八进读取，余数字保持字面。真正反引在全式解析后校验最终组号，因此前向组号也经最终检查。`\113` 在组数不足时表示 K，`\0113` 表示 Tab 后接 3。

此分支使用 Perl 的数字反引合同；[RE2 官方语法表](https://github.com/google/re2/wiki/Syntax) 提供八进字符码规则，并将反引列入其未支持清单。两类语法的数字消歧范围由各自合同说明。脚本数字逃逸由脚本模式另行处理。
