# 公开测试来源

`测试/公开例。测试。豫` 选取八对模式和文本，来源为 [RE2 官方搜索测试表](https://github.com/google/re2/blob/main/re2/testing/search_test.cc)，原项目采用 BSD 风格许可。断言位置按左先、贪婪语义人工核定，并统一为码点区间。

四个非法模式来自 [Rust regex 官方回归测试表](https://github.com/rust-lang/regex/blob/master/testdata/regression.toml) 的无崩溃回归项，原项目采用 MIT 或 Apache 2.0 许可。这些例要求编译报告异常。

以上八对搜索选例与四个非法模式已经完成首阶段构建和运行，退出零。

`官方线性数据。豫` 新增 PCRE2 十四例、Rust regex 四例与 RE2 四例。PCRE2 预期来自官方输出文本，捕获文本在输入中的码点位置人工核定；Rust 保留原 UTF-8 字节范围并转换为码点范围；RE2 预期按模式和输入人工推导。每行保存具体来源与适配说明，这二十二例等待运行验证。完整测试表导入与随机差分对照继续实施。

第三方许可原文见 [PCRE 测试许可](PCRE测试许可.txt)、[Rust 测试许可](Rust测试许可.txt) 与 [RE2 测试许可](RE2测试许可.txt)。PCRE2 测试数据采用公共领域声明；Rust 保存 MIT 许可；RE2 保存 BSD 三条款许可及源文件版权声明。
