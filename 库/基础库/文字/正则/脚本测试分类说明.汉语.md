# 官方脚本分类准备

私有 `脚本测试分类。豫` 只依赖标准库。输入为路径、原文、摘录标记；结果保留原路径、原文、原头、旗串列表、语义标签、类别与理由。

零类为已登记向量对应摘录，要求路径与全部原文逐字相同且输入明确标为摘录。一类为待适配：修改或追加正文、完整源标记、未知记录均进入此类。二类为原头中独立负向 parse/SyntaxError 元数据块的坏式预期，实际执行留待验证窗口。路径用于精确查询，完整原文亦是资格依据。

头部保留原样，`flags:` 起的整个原段保留多行旗字段；正文 RegExp 旗只有精确登记摘录的人工核值。未知正文完整保留，完整 JavaScript 词法分析归后续适配。对象协议、非 u/v 的 UTF-16 单位、ASCII 词类差异均归后续适配。

夹具包含十二已阅官方文件的头字段与短断言摘录，删选在源码中明示。两旧版坏式属于运行期断言摘录，登记为零类向量摘录；独立草稿元数据例核对二类。夹具检查追加正文降类、完整源降类、原头与头旗保留，以及输入记录数量守恒：总数等于零类、一类、二类之和。结果逐件保留，完整官方目录及正文尚待取得、分类与适配。

以上记录为原分类准备与阶段摘录夹具；完整读取的新增证据如下。
