# test262 正则目录清单与后续适配

本调查只读取官方目录条目和十二个选定小文件。当前十四向量是阶段子集，已准备数据与执行入口，验证结果待统筹窗口补录。

上游入口为 [test/built-ins/RegExp](https://github.com/tc39/test262/tree/main/test/built-ins/RegExp)。检视日期为 2026-10-07，分支为 `main`。目录清单用来选择下一批具体测试；每批以官方文件 URL、版权归属、断言预期及人工接口转换分别登记。

| 官方目录 | 已见内容 | 适配路径 |
| --- | --- | --- |
| 根目录旧版编号测试 | 字符、重复、锚点、语法错误 | 先接 ASCII 匹配与编译异常，再逐项归类其他语义 |
| `CharacterClassEscapes/` | 数字、空白、词字及其负类正负案例 | 数字与官方空白可接；词类差异单独列边界 |
| `named-groups/` | 基本命名、反引、重复名、未参与组、替换与对象属性 | 文本与捕获可接；对象原型、枚举顺序与 JS 方法协议单独归类 |
| `lookBehind/` | 定长、变长、负后顾、捕获、贪婪循环、反引、嵌套探查 | 先接纯匹配与捕获；切片、sticky、词界依相关语义边界分类 |
| `regexp-modifiers/` | 添加删除 i/m/s、作用域、捕获反引、嵌套；另有 `syntax/` | 先接模式内标志与坏式；RegExp 对象属性断言列对象协议事项 |
| `property-escapes/` | 非法属性、范围端点、别名、隐式扩展及 `generated/` | 严格 ECMAScript 属性语法与通用 Perl 扩展需分开归类；生成数据按 Unicode 版本登记 |
| `unicodeSets/generated/` | 字符、类、类转义、属性、字符串及其交差并集 | 小文件逐项译为当前纯豫向量；扩大正负输入与有限字符串捕获覆盖 |
| `dotall/` | dotAll 的匹配与相关对象行为 | 点号匹配可接；对象访问器断言列协议事项 |
| `match-indices/` | 捕获位置及索引对象 | 先登记与码点区间相同的 ASCII 案例；UTF-16 单位及对象结构另列事项 |
| `prototype/`、`Symbol.species/`、`escape/` | 构造器、原型、JS 方法与 RegExp.escape | 列入 JavaScript 对象协议适配工作 |

## 相容边界

1. 非 `u/v` 的 UTF-16 码元匹配、半个代理项捕获、公开 UTF-16 区间与孤立代理项输入表示，归入后续接口工作；公共 ABI 保持当前签名。
2. JavaScript 对象原型、访问器副作用、枚举次序、`lastIndex`、`exec` 自定义覆盖、`Symbol` 方法及构造器协议，归入浏览器脚本运行时适配。
3. 通用库的 Unicode 词字与词界、官方 UCD White_Space 和 ECMAScript ASCII 词字及空白规则，分别登记其模式与来源，按当前通用接口的约定选择相容向量。
4. 官方属性语法、Unicode 版本和上游生成文件的版本，随每批来源登记。旧版源文件与本仓 Unicode 18 数据共同使用时，应保留版本信息。
5. 捕获字符串、未参与组与本库区间表示逐项人工转换；所选 ASCII 输入可直接换算。坏式以官方 SyntaxError 断言为预期，本库编译字符串异常为承接方式。

## 下一批顺序

先扩展 `regexp-modifiers/` 的 i/m/s 作用域、`lookBehind/` 的捕获与变长探查，再接 `property-escapes/` 的严格坏式与 `unicodeSets/generated/` 的交差组合。每批准备具体官方文件、正负输入、组捕获及来源元数据，统一进入独立纯豫数据表与执行入口。目录逐项清单和验证计数在授权验证窗口后补录；完整 test262 RegExp 全验留待全部分类与接口适配完成。
