# 脚本数字转义源码

基线为正式 yybs 的 ac6cb9f8aa。此次直接修改最新共享解析器的脚本分支，传统模式保持既有数字、属性和 Unicode 转义路径。

脚本模式预数完整模式的捕获括号，跳过转义和字符类，支持前向数字反引。完整十进制编号对应实际捕获组时生成反引；非 u/v 模式其余数字按旧式八进制解析，首位 0 至 3 最多三位，4 至 7 最多两位，8 与 9 保持身份字面。字符类内使用字符转义；u/v 模式的非零数字须在类外引用实际组，零转义后接十进制数字时报告事故。生成的数字反引还按最终实际组数检查。扫描过大十进制编号时保持超出组数的状态，继续消费数字。

脚本非 u/v 模式的 p/P 为身份字面；u{…} 保留字面 u 后交已有花括量词解析。控制转义 cA 已有；本次补入非 u/v 字符类中的 c 加数字或下划线，以及无效控制转义保留反斜线字面并回退至 c 的规则。

依据为 [ECMAScript 正则早期错误及捕获计数](https://tc39.es/ecma262/multipage/text-processing.html#sec-patterns-static-semantics-early-errors) 与 [Annex B 正则旧式语法](https://tc39.es/ecma262/multipage/additional-ecmascript-features-for-web-browsers.html#sec-regular-expressions-patterns)。本次只备正常和错误两个轻量测试源码；未运行类型检查、构建、匹配或参照宿主。
