# 区间之迁

`正则状态区间转移(状态, 低, 高)` 得覆盖合法 Unicode 标量之连续闭界段。裁界自零至 10FFFF，去代理码，存空后继之陷态。

逐候选码先付 `增量闭包(状态, 实际后字)`，而后筛消费令。闭包之程序号存末换行及消费后须 EOF 之守卫编码；以 `增量指令号` 取原令号，以 `增量指令接` 存守卫之迁。已消费而须 EOF 之径，毋复消费。

连续界之合键，兼存有序无重之编码后继集与 `增量前类(实际后字)`。境分始、ASCII 词字、非 ASCII 折至 ASCII 词字、余 Unicode 词字、换行、余字六类。空集陷态亦依境分段。

七元态之制仍存，下标三之域以段低码点为实前字之代表。同境类与后继集者可共此代表；可终之判，由增量模依前境与编码号定之。区间径算其迁，逐字之缓存存其旧态。

冷察全域费 O(1112064*k)，k 为一候选码之闭包、筛耗及后继排序之费。诸式积态之数或指数增。新增二基础 CI 试源，验同后继跨词字之界及空陷跨界；此批唯排版察异，未型验、构建及运行。
