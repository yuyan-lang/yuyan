# 增量文脉

`增量文脉。豫` 根据线性指令程序、前后码点和有效标志计算增量闭包与可达表。模块直接依赖核心和脚本字符模块，供增量状态及区间查询共用。

前文脉分为六类：0 是输入起点，1 是 ASCII 词字，2 是简单折叠到 ASCII 词字的非 ASCII 字，3 是其他通用 Unicode 词字，4 是换行，5 是其他字符。代表码依次为起点哨值、a、ſ、汉、LF、感叹号。词界使用 `模式词码`，局部锚编码恢复 i 和 m 的有效状态。

若程序指令数为 N，编码指令号由守卫乘 N 加真实指令号组成。守卫 0 表示普通状态；1 表示尚须消费末换行；2 表示末换行已消费，下一文脉须为 EOF。空迁继承守卫，守卫 1 的消费转到守卫 2。闭包在后字为换行时保留守卫 1，在 EOF 时保留守卫 2。

传统非多行 `$` 与 `\Z` 在后码为换行时进入守卫 1，在 EOF 时普通通过；脚本非多行 `$` 在 EOF 通过，多行 `$` 在后码为换行时普通通过。`\z` 在 EOF 通过。前后词字和输入起点的判断保存在同一闭包中。

`文脉前类` 接收前码点，返回六类编号。`文脉指令号` 返回真实指令号；`文脉指令接` 计算消费后的编码目标；`文脉表位` 使用编码号乘 6 加前类编号。`文脉闭包` 接收程序、标志、编码指令列、前码和后码，返回去重后的消费／完成前沿。

`文脉可达表` 返回可进和到终两个爻数组，各长 N×18。初始化以 EOF 闭包中的完成指令作为到终种子。每个消费谓词枚举 Unicode 标量域，按后文脉类别记录可满足证据；起点类 0 属于前文脉，消费证据使用类别 1 至 5。随后使用前后类代表计算空迁与消费边，反复传播到终关系直到固定点。可进表示至少消费一个字符后可以到终，到终也包含当前 EOF 即可接受的状态。

未来字符证据域为 Unicode 标量，范围为 0 至 10FFFF 并排除 D800 至 DFFF。冷态建表包含完整谓词枚举和固定点闭包，耗时可由后续缓存与谓词位图优化。此次源码完成格式化及差异检查，执行测试由统筹的增量批次安排。
