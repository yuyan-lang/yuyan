# 传统数字转义实施记录

此批基于整数模式解析与按旗折叠源码，只修改脚本爻为阴的传统数字分支。脚本的原数字处理继续单独保存。

`\0` 后最多读取两个八进数字，类内非零八进数字最多合计读取三位；类内 `\8`、`\9` 为字面数字。类外先看完整十进数字是否代表已开捕获组，单数字及首位 8／9 按数字反引处理；其余已知号按反引，未知多数字回退最多三位八进，剩余数字作为字面。例如无足够组时 `\113` 表示 K，`\0113` 表示 Tab 后接 3。副索引比较将累积值饱和于已知组数，以便超长未知数字仍按八进处理；真正选定的反引使用现有十进溢出检查。

真正数字反引号在解析末尾依据最终捕获总数校验，因此前向号可先解析，最终不存在的号编译报错。引用未参与捕获时的运行行为沿用传统执行器合同。

依据为官方 [Perl 数字消歧说明](https://perldoc.perl.org/perlrebackslash#Disambiguation-rules-between-old-style-octal-escapes-and-backreferences) 与 [PCRE2 Perl 数字规则](https://www.pcre.org/current/doc/html/pcre2pattern.html#SEC11)。RE2 的数字逃逸与反引支持范围单独见 [官方 Syntax](https://github.com/google/re2/wiki/Syntax)：RE2 支持八进字符码，反引列为未支持。本库此分支采用传统 Perl 数字反引合同，字符类和八进字符保留对应传统规则。

仅新增正常与错误两项源码冒烟，分别覆盖已知数字反引及八进字符组合、最终不存在组号。完成格式化和源码差异检查；未构建或运行。脚本 Annex B 数字逃逸以及无 Unicode 旗的属性／Unicode 身份逃逸继续作为后续源码事项，未混入此批。
