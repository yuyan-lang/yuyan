# 编码转换全量测试

`资源隔离验收。测试` 用正式资源隔离之器，逐批分录采得常驻最大与系统峰，正数常驻限为门槛，未得资源则败；败犹存样而复之。命令及今源码之阶见《资源隔离接线.汉语.md》。持续集成寻此受参之口而惟查，全二十五小批、百万及资源反例续实试。

`探测验收` 具十九定例，核五种字节序标、UTF-8优先及GBK启发、空入、残尾与非法字节。Node与同源原生实试皆过，见《探测固定向量验收.汉语.md》。

`覆盖隔离入口` 补严跨块解码及单编、跨编之果同，循批模糊之参数。四十二码各二十五条精确隔离小批已过，记见《入口覆盖小批.汉语.md》；全百万及原生俟后实试。

七轮编解效测已于Node及同源原生运行皆过：八组各七轮，每轮万次，一百一十二轮校验和皆同，详数见《七轮编解性能记录.汉语.md》及性能原始.tsv。

此包别依编码转换及基础库测试设施，供限时隔离之批。子程循序录进度，正常解码还零，严拒还二，断言败与陷皆为败。

`隔离入口` 受批模糊、码名、种径、始、次数、进度径；`隔离验收` 受目标程、码名、种径、总次数、批量、毫秒、进度径。先二十五条，分十、十、五三批，而后诸码各百万；每批核末序。四十二码名由模糊核心供之。数据许可及规见编码转换之说明。
