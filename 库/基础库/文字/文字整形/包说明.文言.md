# 文字整形

解开放字型之替换、定位，整繁杂之文。出字形号、横纵前进、横纵偏移及所入码点之簇序。位置以六十四分像素之一为度，横向右、纵向上为正。簇序自零起，应所入码点之序；右向左之段，出视觉之序。

`整形文字` 受字体、像素字号、码点列与方向签，方向为 `ltr`、`rtl`、`ttb`。`整形文字参数` 又受文字、语言与特性签。排版之库依字体回退分段而召之。

排版表循 [Microsoft OpenType 排版表之规](https://learn.microsoft.com/en-us/typography/opentype/spec/chapter2) 及 [字距表之规](https://learn.microsoft.com/en-us/typography/opentype/spec/kern) 而解。诸数据由所入字体载之。竖排读 vmtx 本进，依 VORG 或字形之界求纵原点；表阙则用字体之高。

查找之行含 GSUB 八类、GPOS 九类及上下文三式。阿拉伯连属依簇择起、间、末、孤立之特性。预理文字存原簇，含印度前置元音、分裂元音、雷法，缅甸金齐、高棉前置辅音。旧体依 kern 表得字距。

GPOS 查找依字体 GDEF 之类与 LookupFlag 而滤，含所忽略之类、标记所附之类与标记筛选之集，嵌套之查找各用其旗。显式组件之口，可择标记所附之连字节。

今码取「统一码」包官定之属性及扩展字素之界，由「字体取表」得今字面之排版表。GSUB 依 GDEF 而滤，传组件之源；右行易序前换簇内横偏。Arial 四项 HarfBuzz 参照皆过，核验之界见[后续实施记录](后续实施记录.汉语.md)。

后版之事：繁杂上下文之组件来源覆盖、设备与变体之修、完备 USE 属性之状态机。

后续候码于实 GSUB 查找记多易之出身及连字所耗之分，并传历阶初预理之源。私设备读器解二、四、八位像素增，定位值、三式锚点皆接其正。变体候码读实GDEF项目变体之藏，复用字体求值之术及默认fvar/avar坐标。USE 阶段之接及候码核验之进，见实施记录。

USE 候码循九类音节之语法行字体驱动诸阶，取官定 Microsoft 附加音节、位置之覆表。基本特性既行、未重排时，字体有其圆点之形则补破损节。逐节之连仍存其源；默认忽略字依官二元属性出透明零进之形，字体阙透明形则略其项。候码编译、运行之核，见实施记录。

后验含真字体 HarfBuzz 对照、百万变异、原生裸机之试及性能之量。今录为实施之阶段，甲乙之验尚俟诸事。
