# 文字整形

解开放字型之替换、定位，整繁杂之文。出字形号、横纵前进、横纵偏移及所入码点之簇序。位置以六十四分像素之一为度，横向右、纵向上为正。簇序自零起，应所入码点之序；右向左之段，出视觉之序。

`整形文字` 受字体、像素字号、码点列与方向签，方向为 `ltr`、`rtl`、`ttb`。`整形文字参数` 又受文字、语言与特性签。排版之库依字体回退分段而召之。

排版表循 [Microsoft OpenType 排版表之规](https://learn.microsoft.com/en-us/typography/opentype/spec/chapter2) 及 [字距表之规](https://learn.microsoft.com/en-us/typography/opentype/spec/kern) 而解。诸数据由所入字体载之。竖排今依字身之高取纵向本进；vmtx 度量之接，俟后版。

查找之行含 GSUB 八类、GPOS 九类及上下文三式。阿拉伯连属依簇择起、间、末、孤立之特性。预理文字存原簇，含印度前置元音、分裂元音、雷法，缅甸金齐、高棉前置辅音。旧体依 kern 表得字距。

GPOS 查找依字体 GDEF 之类与 LookupFlag 而滤，含所忽略之类、标记所附之类与标记筛选之集，嵌套之查找各用其旗。显式组件之口，可择标记所附之连字节。

后版之事：GSUB 依 GDEF 滤字形、多重替换及连字组件之来源映射、设备与变体之修、完备 USE 属性之状态机。

后验含真字体 HarfBuzz 对照、百万变异、原生裸机之试及性能之量。今录为实施之阶段，甲乙之验尚俟诸事。
