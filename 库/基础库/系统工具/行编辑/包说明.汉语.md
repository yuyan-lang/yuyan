# 行编辑

本包用纯豫言提供 UTF-8 字符边界上的插入、删除和光标移动、多行行首行尾、历史浏览、子串增量搜索、补全回调和高亮回调。状态机与终端输入输出分离，使用者将按键交给 `按键编辑`，从 `编辑文本` 取得内容。

`新编辑(文本)` 创建编辑状态；`插入文字(状态,文本)` 插入；`移左`、`移右`、`删左`、`删右`、`行首`、`行尾` 接受状态并返回新状态。`光标字符数` 返回光标前字符数。`设历史(状态,字符串列)` 和 `历史文本` 导入导出历史，应用可将历史列存文件。`记录历史` 将当前文本加入最近历史；`取历史` 按从零起的最新优先位置取历史；`增量搜索(状态,搜索词)` 取最新包含词的历史。

按键名称包括左、右、退格、换行、提交、Ctrl-A/B/D/E/F/H/N/P/R。其余字符串作为输入文字。`应用补全(状态,回调)` 把回调返回的后缀插入光标；回调参数是完整文本和光标字符数。`高亮文本(状态,回调)` 将全文交给高亮器返回展示字符串，编辑内容保持原值。多行内容包含换行字符。

首个使用者是本包 `按键示例`，从按键序列构造交互输入，可供命令壳接入。源码与测试为自行编写，许可沿仓库许可。

`保存历史(状态,路径)` 与 `读取历史(状态,路径)` 以结森字符串数组存取文件，支持历史项中的换行；`历史结森` 和 `载入历史结森` 可独立序列化。Ctrl-K/U 剪下本行后部/前部，Ctrl-Y 插回，Ctrl-T 交换光标前两字。依赖标准库、结森工具和单元测试。

`新会话`、`设会话历史` 与 `会话按键` 提供 Ctrl-R 搜索模式：输入逐步扩展搜索词，退格缩短搜索词，重复 Ctrl-R 查找更早的匹配，Ctrl-G 恢复原输入与光标，提交键接受匹配。`会话状态` 取编辑内容，`会话搜索词` 取搜索词。`控制键名` 把控制字节转换为按键名称。

`光标行列(状态,字宽回调)` 返回从一开始的终端行列；换行重置列数。`刷新编辑(旧状态,新状态,字宽回调)` 调用终端界面的屏幕差量刷新和光标定位，返回终端输出序列。字宽回调可接统一码，展示模块直接依赖终端界面。
