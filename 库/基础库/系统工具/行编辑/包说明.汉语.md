# 行编辑

本包用纯豫言提供 UTF-8 扩展字素边界上的插入、删除和光标移动、多行行首行尾、历史浏览、子串增量搜索、补全回调和高亮回调。状态机与终端输入输出分离，使用者将按键交给 `按键编辑`，从 `编辑文本` 取得内容。

`新编辑(文本)` 创建编辑状态；`插入文字(状态,文本)` 插入；`移左`、`移右`、`删左`、`删右`、`行首`、`行尾` 接受状态并返回新状态。`光标字符数` 返回光标前字符数。`设历史(状态,字符串列)` 和 `历史文本` 导入导出历史，应用可将历史列存文件。`记录历史` 将当前文本加入最近历史；`取历史` 按从零起的最新优先位置取历史；`增量搜索(状态,搜索词)` 取最新包含词的历史。

按键名称包括左、右、退格、换行、提交、Ctrl-A/B/D/E/F/H/N/P/R。其余字符串作为输入文字。`应用补全(状态,回调)` 把回调返回的后缀插入光标；回调参数是完整文本和光标字符数。`高亮文本(状态,回调)` 将全文交给高亮器返回展示字符串，编辑内容保持原值。多行内容包含换行字符。

首个使用者是「豫言终端」交互输入中的末尾退格，调用行编辑删除完整字素。本包 `按键示例` 从按键序列构造交互输入。源码与测试为自行编写，许可沿仓库许可。字素切分及东亚列宽采用「统一码」包的官方数据，数据出处与许可见该包说明。

`保存历史(状态,路径)` 与 `读取历史(状态,路径)` 以结森字符串数组存取文件，支持历史项中的换行；`历史结森` 和 `载入历史结森` 可独立序列化。Ctrl-K/U 剪下本行后部/前部，Ctrl-Y 插回，Ctrl-T 交换光标两侧字素并向右移一字素，在文末交换末尾两字素。依赖标准库、结森工具、单元测试、统一码与终端界面。

`新会话`、`设会话历史` 与 `会话按键` 提供 Ctrl-R 搜索模式：输入逐步扩展搜索词，退格缩短搜索词，重复 Ctrl-R 查找更早的匹配，Ctrl-G 恢复原输入与光标，提交键接受匹配。`会话状态` 取编辑内容，`会话搜索词` 取搜索词。`控制键名` 把控制字节转换为按键名称。

`光标行列(状态,字宽回调)` 返回从一开始的终端行列；换行重置列数。`刷新编辑(旧状态,新状态,字宽回调)` 调用终端界面的屏幕差量刷新和光标定位，返回终端输出序列。字宽回调可接统一码，展示模块直接依赖终端界面。

`终端光标行列(状态)` 与 `刷新终端编辑(旧状态,新状态)` 直接调用统一码文字列宽，支持东亚宽字、组合字符和表情字素。插入后重新切分全文，逐次输入组合标记也形成完整字素。`光标字符数` 与补全回调的位置按字素计数。

Ctrl-W 剪下光标前的词及其尾随空白。`会话按键` 接收控制字节和终端方向键序列。

会话用 Ctrl-P/N 浏览历史，回到最新历史之后恢复浏览前的草稿。`官方字素编辑` 接受仓外 `GraphemeBreakTest.txt` 路径，以官方期望边界核对编辑器逐次左移所得边界。

源码与测试按仓库 GNU AGPL 第三版许可。Unicode 18.0.0 字素与列宽数据依据 Unicode 数据许可，由统一码包提供。

已取得的运行证明：Node 与同源原生均通过 36 条状态断言、豫言终端退格函数 4 例、官方字素移动边界 853 例；细节见《实施记录.汉语.md》。甲级仍需完成实际终端主循环接线、屏幕折行与东亚光标定位验收，进度由统筹登记。乙级继续完成百万变异输入、裸机与浏览器验证、性能测量及完整多行展示。
