# 行编辑

此包以豫言为之，插删与移标皆循 UTF-8 扩展字素之界。可录多行，求行首尾，阅史，以词寻史，受补全与着色之回调。状态与终端出入各立，使用者以键授 `按键编辑`，以 `编辑文本` 取其文。

`新编辑` 建状态；`插入文字` 插文；`移左`、`移右`、`删左`、`删右`、`行首`、`行尾` 受状态而返新状态。`光标字符数` 计标前之字。`设历史` 与 `历史文本` 入出史列，应用可藏于文件。`记录历史` 录今文；`取历史` 自零索引，以新为先；`增量搜索` 取最近含词之史。

键名有左、右、退格、换行、提交与 Ctrl-A/B/D/E/F/H/N/P/R，余串皆插文。`应用补全` 以全文及标前字数授回调，将所得后缀插于标。`高亮文本` 以全文授回调，取其展示之文，原文仍存。多行以换行字相隔。

首用者为「豫言终端」之末端退格，取此包删全字素。包中 `按键示例` 按键列造输入。源码与测试皆自作，许可从仓库。字素及东亚列宽取「统一码」官方数据，其出处与许可见彼包说明。

`保存历史` 与 `读取历史` 以结森串数组存取文件，史项含换行亦可录；`历史结森` 与 `载入历史结森` 可独用。Ctrl-K/U 剪本行标后与标前，Ctrl-Y 复插，Ctrl-T 易标两侧字素而右移一簇，文末则易末尾二簇。所依为标准库、结森工具、单元测试、统一码与终端界面。

`新会话`、`设会话历史` 与 `会话按键` 立 Ctrl-R 寻史之态：录字增词，退格减词，复按 Ctrl-R 寻更早之文，Ctrl-G 复原文与标，提交则纳所得。`会话状态` 取文，`会话搜索词` 取词。`控制键名` 化控制字节为键名。

`光标行列` 受状态及字宽回调，还自一起之行列，换行复列。`刷新编辑` 受旧新状态与宽度回调，调用终端界面之差刷与移标，还输出序列。字宽可接统一码，展示所依为终端界面。

`终端光标行列` 与 `刷新终端编辑` 径取统一码文字列宽，兼容东亚宽字、组合字与表情之簇。插文后复分全文，逐录组合之记亦成全字素。`光标字符数` 与补全回调之位置皆计字素。

Ctrl-W 剪标前之词及随后的空白。`会话按键` 受控制字节与终端方向键之序。

会话以 Ctrl-P/N 阅史，越最新史则复阅前之草稿。`官方字素编辑` 受仓外 `GraphemeBreakTest.txt` 之径，以官方应界核逐次左移之实界。

源码与测试从仓库 GNU AGPL 第三版之许可。Unicode 18.0.0 字素与列宽之数据从 Unicode 数据许可，由统一码包供之。

所得运行之证：Node 与同源原生皆过状态断言四十四、豫言终端退格函数四例、官方字素移标边界八百五十三例，又过终端会话接线十六例与实列输入私有布局六例。详见《实施记录.汉语.md》。终端主循环已接阅史、Ctrl-R、存右文补全、逻辑行东亚定位、Ctrl-O 开行与循列宽纵移。屏实宽、屏幕折行与实终端交互续验，进度由统筹录之。

`百万状态。测试` 定种行百万杂编，逐步校全字素之分栏。同一客体于所信 pit-mac 之 Node 与同源原生两端实验退出零。Node 历三百六十点三九秒，最大常驻内存一亿四千四百二十四万四千七百三十六字节；原生历三百一十四点七二秒，最大常驻内存十一亿二千二百一十五万六千五百四十四字节。所量兼每步全文字素切分之核，运行机之负载共用。裸机、浏览器与多行全展示续验之。
