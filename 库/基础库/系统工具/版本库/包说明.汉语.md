# 版本库

版本库提供 Git 对象、树、提交与标签解析，提交历史遍历，引用、idx v2、普通包对象及两种增量读取。SHA-1 使用密码包，zlib 使用压缩包。

`读取版本对象` 按松散对象及包名列表查找，按 idx 边界裁切压缩流。保存对象与提交接收建目录回调。检出写出普通文件与子树，树差异经差异比较生成按行变化。

首消费者 `示例/历史合并。豫` 读取系统 Git 的真实三版 blob 与两版树，执行树差异，调用 `差异比较/合并` 公共 `逐段三方合并`。四处独立修改的期望由系统 diff3 生成；断言失败抛出异常，进程非零退出。

`接收包/展开接收包` 校验 pack 尾部 SHA-1，读取压缩流实际消费长度，逐轮还原普通对象、OFS 增量与 REF 增量。REF 基对象位于增量之后时，经候解轮次恢复。目录由调用方回调创建。`示例/前向核验。豫` 以系统 Git 接受的独立前向包验证恢复对象。
