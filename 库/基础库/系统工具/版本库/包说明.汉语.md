# 版本库

版本库提供 Git 对象、树、提交与标签解析，提交历史遍历，引用、idx v2、普通包对象及两种增量读取。SHA-1 使用密码包，zlib 使用压缩包。

`读取版本对象` 按松散对象及包名列表查找，按 idx 边界裁切压缩流。保存对象与提交接收建目录回调。检出写出普通文件与子树，树差异经差异比较生成按行变化。

首消费者 `示例/历史合并。脚本。豫` 读取系统 Git 的真实三版 blob 与两版树，执行树差异，调用 `差异比较/合并` 公共 `逐段三方合并`。四处独立修改的期望由系统 diff3 生成；断言失败抛出异常，进程非零退出。

`接收包/展开接收包` 校验 pack 尾部 SHA-1，读取压缩流实际消费长度，逐轮还原普通对象、OFS 增量与 REF 增量。REF 基对象位于增量之后时，经候解轮次恢复。目录由调用方回调创建。`示例/前向核验。脚本。豫` 以系统 Git 接受的独立前向包验证恢复对象。

`克隆` 模块提供协议 v2 的引用发现、pack 内容恢复与引用更新；`联网接线` 经现有 HTTP 客户端承接明文传输。`示例/联网克隆。脚本。豫` 完成实际 HTTP 克隆和拉取，系统 Git 核对恢复对象与历史。目录创建由调用方回调承担。

## 工作树文件枚举

`枚举工作树文件` 接收工作树目录或子目录，返回相对此目录的已跟踪文件及未被忽略的新文件。实现直接读取版本二、版本三 Git 索引，识别 `.git` 目录与 `gitdir` 工作树指针，读取 `commondir` 的公共配置与排除文件。忽略来源依次为全局 `core.excludesFile` 或 XDG 默认文件、`info/exclude`、逐级 `.gitignore`；后级规则覆盖前级规则。规则支持否定、根锚定、目录限定、星号、双星号、问号、字符组与范围。已跟踪文件在磁盘上删除后仍列入结果，调用者按用途检查存在性。

批量发布通过此入口收集源码。路径保持原文，中文、引号与换行文件名直接作为字符串传递。后续版本事项：Git 索引版本四、拆分索引、稀疏索引、配置 include/includeIf 与复杂 POSIX 字符类。

`安全联网接线/安全版本传输` 接受真实当前 Unix 秒，使用安全传输的默认客户配置、仓内信任根和超文本传输的公开安全请求。`授权目录接线/授权建目录` 使用公共文件目录权，逐层创建克隆、对象与引用目录。`示例/安全克隆。脚本。豫` 从公共时间接口取得时刻，在“版本库”已授目录内连接 HTTPS、克隆、核对对象并拉取。CI 的两个接线入口检查正式依赖及接口类型。

## 吉特命令

命令行程序「吉特」（`应用/开发工具/吉特`）与系统壳调用同一组带标签的命令函数。每个函数打印人与代理都读得懂的文字，返回退出码（零为成功）；出错时抛出事故，说明原因。仓库格式与 git 一致，同一个仓库可以交替使用 git 与这些函数。

- `命令`：`吉特状态`、`吉特差异`、`吉特暂存`、`吉特撤销暂存`、`吉特提交`、`吉特历史`、`吉特查看`、`合并基命令`、`吉特列分支`、`吉特新建分支`、`吉特删除分支`。
- `切换合并命令`：`吉特切换`、`吉特合并`（快进、三方合并、冲突后提交或放弃）、`吉特变基`（开始、继续、跳过、放弃）、`工作树新增`、`工作树删除`、`工作树列出`。
- `远端命令`：`吉特克隆`、`吉特拉取`、`吉特推送`。令牌取环境变量 `吉特令牌`，其次取凭据文件（缺省 `/系统/吉特/凭据`，每行“令牌”或“主机 令牌”），经 HTTP 基本认证发送，任何输出都不含令牌。核心函数 `克隆于`、`拉取于`、`推送于` 接收一个远端调用函数，测试时可以换成本机进程。

这些命令建立在以下模块上：

- `沙一`：分段追加的沙一摘要，对象标识与包文件尾部校验共用。
- `对象库`：松散对象与包文件中的对象（含偏移增量与引用增量）的读取，第二版包索引按扇出表二分查找；松散对象写入。
- `索引文件`：第二、三版索引的读写，每项记下修改时间与大小。
- `工作区`：HEAD、暂存区、工作区三方状态，未跟踪文件扫描遵守 `.gitignore`、`info/exclude` 与全局排除文件；修改时间相同且早于索引写入时刻的文件沿用索引里的散列，其余重新计算并刷新索引。
- `树表`、`提交记录`、`引用库`、`配置`：树与提交对象的编解码、作者签名与时区，松散引用、打包引用与符号引用，链接工作树的元目录与公共目录，INI 写法的配置文件。
- `历史`：修订名解析（分支、远端分支、标签、完整或缩写标识、`~n` 与 `^n`）、按提交时间的历史行走、合并基与祖先判断。
- `差异输出`：统一格式差异，带三行上下文。
- `合并`：两树切换与三方合并，会覆盖本地改动时拒绝；冲突写入第一至三阶段与冲突标记。
- `收包`：收下的包逐个解压对象、展开增量、计算标识，生成第二版包索引，内容与 `git index-pack` 相同。
- `远端协议`、`联网`：智能 HTTP 第二版 upload-pack（ls-refs、fetch、边带）与 receive-pack（引用更新命令、非增量包、report-status），HTTPS 用仓内信任根核验证书。
- `散列表`、`文字工具`：整数键与字符串键的开放寻址散列表，按字节的文字处理。

`测试/吉特核心。测试。豫` 核对沙一向量、对象标识、索引往返、树往返与统一差异块。`示例/本地协议核验。脚本。豫` 把克隆、拉取、推送的请求体交给本机的 `git upload-pack`、`git receive-pack --stateless-rpc`，在本机核对远端协议。
