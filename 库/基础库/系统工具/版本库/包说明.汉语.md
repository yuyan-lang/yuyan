# 版本库

版本库提供 Git 对象原文、树、提交的解析和编码，标签字段解析，提交历史遍历，idx v2 的对象标识及大小偏移读取，pack 对象头和两种增量对象的读取，松散与打包引用的解析与读盘，以及协议 v2 的 ls-refs 和 fetch 请求编码。pack 读取接收解压和引用对象查找回调。

首用者为代码浏览和批量发布。调用者提供提交读取函数，历史遍历去重访问合并提交的父链。树项保留模式、文件名和二十字节标识，文件与标签载荷通过对象内容保存。

## 后续版本事项

压缩和 SHA-1 依赖接入、树差异、目录检出、落盘写对象和提交、HTTP 克隆与拉取、完整系统 Git 互验留待后续版本。当前原文解析入口要求有效 Git 数据。

`测试/对象。测试。豫` 验证对象编码、增量复制与插入、提交往返。`示例/包索引查看。豫` 接收 idx 路径，输出对象总数、首对象标识及偏移，供系统 Git 互验。
