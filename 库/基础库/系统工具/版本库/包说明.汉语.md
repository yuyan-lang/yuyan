# 版本库

版本库提供 Git 对象、树、提交与标签解析，提交历史遍历，引用、idx v2、普通包对象及两种增量读取。SHA-1 使用密码包，zlib 使用压缩包。

`读取版本对象` 按松散对象及包名列表查找，按 idx 边界裁切压缩流。保存对象与提交接收建目录回调。检出写出普通文件与子树，树差异经差异比较生成按行变化。

首消费者 `示例/历史合并。豫` 读取系统 Git 的真实三版 blob 与两版树，执行树差异，调用 `差异比较/合并` 公共 `逐段三方合并`。四处独立修改的期望由系统 diff3 生成；断言失败抛出异常，进程非零退出。

`接收包/展开接收包` 校验 pack 尾部 SHA-1，读取压缩流实际消费长度，逐轮还原普通对象、OFS 增量与 REF 增量。REF 基对象位于增量之后时，经候解轮次恢复。目录由调用方回调创建。`示例/前向核验。豫` 以系统 Git 接受的独立前向包验证恢复对象。

`克隆` 模块提供协议 v2 的引用发现、pack 内容恢复与引用更新；`联网接线` 经现有 HTTP 客户端承接明文传输。`示例/联网克隆。豫` 完成实际 HTTP 克隆和拉取，系统 Git 核对恢复对象与历史。目录创建由调用方回调承担。

## 工作树文件枚举

`枚举工作树文件` 接收工作树目录或子目录，返回相对此目录的已跟踪文件及未被忽略的新文件。实现直接读取版本二、版本三 Git 索引，识别 `.git` 目录与 `gitdir` 工作树指针，读取 `commondir` 的公共配置与排除文件。忽略来源依次为全局 `core.excludesFile` 或 XDG 默认文件、`info/exclude`、逐级 `.gitignore`；后级规则覆盖前级规则。规则支持否定、根锚定、目录限定、星号、双星号、问号、字符组与范围。已跟踪文件在磁盘上删除后仍列入结果，调用者按用途检查存在性。

批量发布通过此入口收集源码。路径保持原文，中文、引号与换行文件名直接作为字符串传递。后续版本事项：Git 索引版本四、拆分索引、稀疏索引、配置 include/includeIf 与复杂 POSIX 字符类。

`安全联网接线/安全版本传输` 接受真实当前 Unix 秒，使用安全传输的默认客户配置、仓内信任根和超文本传输的公开安全请求。`授权目录接线/授权建目录` 使用公共文件目录权，逐层创建克隆、对象与引用目录。`示例/安全克隆。豫` 从公共时间接口取得时刻，在“版本库”已授目录内连接 HTTPS、克隆、核对对象并拉取。CI 的两个接线入口检查正式依赖及接口类型。
