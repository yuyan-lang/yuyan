# 版本库

版本库析而编码 Git 对象原文、树与提交，析标签字段，遍历提交之史，读 idx v2 之对象标识与大小偏移，读 pack 对象首及偏移、引用二增量，析松散、打包引用而读盘，并编码协议 v2 之 ls-refs 与 fetch 请求。读 pack 须授解压、引用对象查找二术。

首用者为代码浏览、批量发布。调用者授提交读取之术，史之遍历去重而访合并提交诸父。树项存模式、文件名及二十字节标识；文件、标签之载荷以对象内容存之。
