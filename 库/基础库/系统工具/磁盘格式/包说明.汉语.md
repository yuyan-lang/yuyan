# 磁盘格式

磁盘格式提供纯豫言的分区与文件系统镜像构件。公开数据接口使用字节串，设备接口使用按字节偏移与长度的读写回调。

## 使用

导入 `磁盘格式` 总集可使用主引导记录、全局分区表、文件分配表、光盘及扩展文件系统的构件。分配表启动信息的八个槽位依次为位宽、扇区字节数、每簇扇区数、表起始扇区、数据起始扇区、簇数、根目录簇、固定根目录起始扇区。目录解析返回名称、属性、首簇与文件字节长度。

`内存块设备` 接收存放镜像字节串的单元素数组引用；写入后引用保存新的镜像。`载入文件镜像` 与 `保存文件镜像` 提供整文件适配。文件适配整读镜像、修改后整写，适合内存可容纳的镜像。`镜像检查。豫` 是首个真实文件使用者。

## 验证

`基础。测试。豫` 核对 CRC32 标准向量与偏移写入。`分配表。测试。豫` 核对 FAT12 半字节共享、簇链释放与 FAT32 高位保留。`分配表文件。测试。豫` 核对新文件跨两簇落盘与多副本同步，`镜像。测试。豫` 核对超级块及区段映射。
