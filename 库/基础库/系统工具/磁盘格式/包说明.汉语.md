# 磁盘格式

磁盘格式提供纯豫言的分区与文件系统镜像构件。公开数据接口使用字节串，设备接口使用按字节偏移与长度的读写回调。

## 使用

导入 `磁盘格式` 总集可使用主引导记录、全局分区表、文件分配表、光盘及扩展文件系统的构件。分配表启动信息的八个槽位依次为位宽、扇区字节数、每簇扇区数、表起始扇区、数据起始扇区、簇数、根目录簇、固定根目录起始扇区。目录解析返回名称、属性、首簇与文件字节长度。

`内存块设备` 接收存放镜像字节串的单元素数组引用；写入后引用保存新的镜像。`载入文件镜像` 与 `保存文件镜像` 提供整文件适配。文件适配整读镜像、修改后整写，适合内存可容纳的镜像。`镜像检查。豫` 是首个真实文件使用者。

## 验证

`基础。测试。豫` 核对 CRC32 标准向量与偏移写入。`分配表。测试。豫` 核对 FAT12 半字节共享、簇链释放与 FAT32 高位保留。`分配表文件。测试。豫` 核对新文件跨两簇落盘与多副本同步，`镜像。测试。豫` 核对超级块及区段映射。

## 文件系统读取与长名写入

`新建分配表完整根长名文件` 可在 FAT12/16/32 写入中文及代理对名称，目录不足时扩充簇链，FAT32 根据活动表标志写回。调用者给出十一字节唯一短别名。`扩展读取文件` 统一处理 ext 三级间接块、区段和稀疏区域；`扩展读取目录` 线性枚举哈希目录叶条目。`光盘完整根目录` 可选择 Joliet 名称或 Rock Ridge NM/CE 名称。exFAT 补全入口可核验目录组、启动校验及有效长度零填充，并读取活动分配位图位置。

新增长名目录读写与独立 FAT/ISO/ext 镜像消费者已经在 Node 和原生预编二运行。GPT 与 exFAT 独立向量已经在 Node 运行。源与镜像来源详见实施记录和参考镜像来源调查。

## 发布镜像与性能入口

`镜像打包。豫` 接收完整 FAT 输入镜像与输出镜像路径，示范中文发布文件写入、保存与重开核对。`磁盘性能。豫` 核对百万次位图查询及一 MiB CRC32 扫描，并打印秒数。Node 与原生预编二运行证据、输出镜像散列及测量见 `文件与性能验收.汉语.md`。
