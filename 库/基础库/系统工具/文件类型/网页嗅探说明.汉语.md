# 网页媒体嗅探

私有模块 `网页嗅探。豫` 实现 [WHATWG MIME Sniffing Standard](https://mimesniff.spec.whatwg.org/) 的字节模式、未知媒体、文本二进制区分与上下文分派。规范读取日期为 2026-10-08。

`网页上下文嗅探` 接收声明字符串、资源首部字节、禁嗅标记、旧服务器检查标记、上下文字符串和支持声明标记。上下文使用「浏览」「图像」「影音」「字体」「插件」「样式」「脚本」「字幕」「缓存清单」。返回空字符串代表未定义类型；原声明的参数由调用者保有，有效声明得到保留时返回原声明字符串。声明本质解析校验 HTTP token，按 ASCII 小写比较类型与子类型。

浏览上下文先保留 XML 与 HTML 声明，再处理未知声明、禁嗅、旧服务器文本检查以及支持的图像和影音声明。未知声明为缺省、`unknown/unknown`、`application/unknown`、`*/*`。`application/octet-stream` 属于有效声明。未知类型的脚本嗅探受禁嗅标记控制；图像、影音和归档模式使用规范中的独立表。文本二进制区分使用规范定义的控制字节集合，高位字节得到文本结果。

图像模式包含图标与光标、BMP、GIF、完整 WebP 前缀、PNG、JPEG。影音模式包含 AIFF、ID3、Ogg、MIDI、AVI、WAVE，以及 MP4 品牌盒、WebM 文档类型和相邻 MP3 帧。字体上下文含嵌入字体、TTF、OTF、字体集合、WOFF、WOFF2。归档模式含 GZIP、ZIP 本地文件头和 RAR 4 签名；返回值沿用规范媒体名称。HTML 标签需以空格或 `>` 终止，包含注释前缀；XML 签名采用精确小写。

HTTP 调用者可以通过 `网页旧服务器标记` 检查最后一个 Content-Type 头的原始值；它识别规范列出的四个精确字符串。来源、重复 HTTP 头选择、资源读取超时、浏览器支持的媒体集合由调用者提供。资源首部读取可以在文件末尾、取得 1445 字节或调用者规定的等待时间到达时结束。

`网页默认嗅探` 接收旧二参入口的输入，使用允许嗅探的浏览上下文、支持图像与影音声明、非 HTTP 来源。集成时，`文本嗅探。豫` 增加同包导入 `寻观「文件类型」之「网页嗅探」之书。`，将 `网页媒体嗅探` 的函数体替换为 `「网页默认嗅探」于「声明」于「数据」`，类型签名保留原值。`总集。豫` 的导出保持现状。

后续集成事项：公开上下文入口需要任务统筹确定 API 授权；当前二参入口的输入表达能力涵盖默认浏览语义，完整上下文通过私有核心及固定向量表达。样式和脚本上下文的无声明分支在活规范第 8.5、8.6 节以省略号表示，本实现返回未定义类型。

活规范第 6.2.3 节的 MP3 帧界限写为 `skipped-bytes > s - length`，在初始位置零会拒绝全部正长度帧。本实现采用剩余字节数界限，并逐项采用该节其余头匹配、码率表、版本位与频率计算。WebM 变长整数从调用偏移开始读取，文档类型长度限定填零匹配区间，并拒绝截断输入。相关偏移、截断、位掩码和两帧向量在 `测试/网页嗅探。测试。豫`。

本阶段完成源码排版与静态审阅；类型检查、Node 与原生运行、百万输入及性能证据由统筹安排验证窗口。
