# 文件类型

按文件头魔数识别常见图像、音频、视频、压缩、归档、PDF、字体、可执行文件与 BOM 文本。提供常见扩展名媒体类型、严格 UTF-8 判断、网页嗅探及 freedesktop 图标名称。字节输入采用整数列表，未知魔数返回空串，未知扩展返回 application/octet-stream。

官方扩展表由文件类型数据生成包从 shared-mime-info 2.4 官方 XML 生成，包含 1185 条简单扩展规则。出处 https://gitlab.freedesktop.org/xdg/shared-mime-info/-/raw/2.4/data/freedesktop.org.xml.in ，许可 GNU GPL 第 2 版或以后版本，许可全文见 数据许可.txt；原始下载文件保存于仓外的豫言数据/文件类型。

ZIP 内容识别从末目录记录定位中央目录，并检查条目边界及精确名称，支持 OOXML 文档、表格、演示与 JAR。EPUB 使用首个无压缩 mimetype 条目的内容识别。统一入口为文件媒体类型。

生成命令：`yy文件类型数据生成 shared-mime-info-2.4.xml.in 官方扩展表。豫`。数据采用制表符分隔的扩展名与媒体类型、换行分隔的记录，嵌入源码字符串；模块初始化时一次转换为扩展表。

后续事项：IANA 全量登记、复合扩展与复杂通配及权重规则；经归档库接续 ZIP64、多卷及 OOXML 内容类型 XML；经编码转换判断其他编码；补足 WHATWG 上下文算法与跨库回归样例。
