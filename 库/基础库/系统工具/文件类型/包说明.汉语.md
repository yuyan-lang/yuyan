# 文件类型

按文件头魔数识别常见图像、音频、视频、压缩、归档、PDF、字体、可执行文件与 BOM 文本。提供常见扩展名媒体类型、严格 UTF-8 判断、网页嗅探及 freedesktop 图标名称。字节输入采用整数列表，未知魔数返回空串，未知扩展返回 application/octet-stream。

官方规则表由文件类型数据生成包从 shared-mime-info 2.4 官方 XML 生成，包含全部 1225 条文件名规则，并合入 IANA 注册模板中的扩展字段。shared-mime-info 出处 https://gitlab.freedesktop.org/xdg/shared-mime-info/-/raw/2.4/data/freedesktop.org.xml.in ，许可 GNU GPL 第 2 版或以后版本，许可全文见 数据许可.txt；IANA 登记数据采用 CC0 1.0，出处与冻结清单见数据生成包说明。原始下载文件保存于仓外的豫言数据/文件类型。

ZIP 内容识别复用归档库，读取 ZIP64、存储与 DEFLATE 条目并校验 CRC。OOXML 经 XML 字节解析、命名空间与 Override 声明核对档内主部件，识别文档、表格与演示。EPUB 根据 mimetype 完整内容识别，JAR 根据精确清单路径识别。统一入口为文件媒体类型，解压总额度十亿字节。

归档内容测试由豫言归档库生成存储、DEFLATE、ZIP64、OOXML、EPUB 与 JAR 样本，附缺主部件、非法 XML、错命名空间与截断回退向量。本次归档内容候选已完成格式检查，构建与双端运行待统筹验证窗口执行。

生成命令：`node --max-old-space-size=16384 yy稳定节点宿主/宿主.cjs yy文件类型数据生成.wasm shared-mime-info-2.4.xml.in 官方扩展表。豫`。同级保存 `IANA媒体类型.xml` 与 `IANA模板/`。数据采用制表符分隔的模式、媒体类型、权重、大小写标志四列，记录以换行分隔，嵌入源码字符串；模块初始化时一次转换为规则表。

无 BOM 编码判断复用编码转换库的严格探测与解码，依次尝试 UTF-8 与 GBK。解码文本中的零字节及其他控制字符按二进制处理，制表与常用换行保留。BOM 输入保持 UTF-8、UTF-16 与 UTF-32 名称。探测顺序决定可被多种编码解释的字节输入所返回的名称。

新增“中文”的标准 GBK 字节及混合 ASCII、控制字符、孤尾、坏字节、UTF-8、五种 BOM 与越界整数固定向量。最新 25a 完整工具链的显式总集类型检查通过，编码、网页嗅探与 ZIP 内容生成向量已在 Node 与同源原生运行通过；百万、性能与裸机验证待运行。

归档测试通过豫言归档库生成存储与 DEFLATE 条目；已有 ZIP64 档案重建末记录时读取真实 64 位目录值，避免将传统尾记录哨兵值作为实际目录值。生成的 ZIP64 办公档通过系统 unzip 检验；合法内容声明与真实部件联合识别 OOXML，错误域、破碎 XML、缺主部件与截断档保持通用 ZIP 类型。

简易网页服务器的 txt 与 Markdown 响应调用严格编码判断。原始 GBK“中文”文件通过 Node 与原生真实 HTTP 请求返回 `text/plain; charset=GBK`，四字节正文与源文件及两端响应一致。

后续事项：继续核对 IANA 注册模板自由说明的扩展字段；经归档库接续多卷及加密；补齐 OOXML 模板、宏与部件关系验证；扩充编码探测库支持的探测策略；补足 WHATWG 上下文算法。

完整文件名规则包含固定名称、复合后缀、星号与问号、字符组及范围、转义和大小写标志。优先固定名称，再比较权重和模式长度；同级不同媒体类型返回通用二进制类型，提供内容时由魔数入口识别。文件名匹配固定向量在 Node 与原生运行通过。

跨库样例向量读取归档库已入库的系统 ar、cpio、ZIP 样本，调用文件媒体类型核对实际文件字节。向量在仓库根目录运行，已在 Node 与原生运行通过。

甲级魔数测试逐一核对现有 50 个前缀签名及各自截断输入，涵盖图像、音频、视频、归档、压缩、PDF、字体、ELF、Mach-O、PE、Wasm 与 BOM 文本。独立向量另核 RIFF 的第八字节、ftyp 的第四字节及品牌位置、TAR 的第 257 字节，包含截短与错偏移输入。魔数识别采用前缀与指定偏移；文件完整结构解析留待后续版本。

公开扩展查询向量核对 IANA 的 u8msg 与 ivs、裸后缀 png、复合后缀 svg.gz，以及官方同权 pot 歧义回到通用二进制类型。构建命令为 `豫构 构建 文件类型 测试 甲级魔数。测试 --输出 yy甲级魔数测试.wasm -j 24`。

甲级魔数与官方查询固定向量已在 Node 及同源硬浮点原生生成器、执行器上运行通过，输出“甲级魔数与官方查询固定向量通过”。

首消费者为简易网页服务器。测试目录预置甲补证消息.u8msg 与真实甲补证图像.png，以此目录作服务根，分别对 Node 与同源原生服务器发送 HTTP GET。响应 Content-Type 为 message/global 与 image/png；响应正文与源文件及两端响应逐字节一致。图像复用图像编解码测试中的动便图绿色参考样本。

乙阶段私有网页嗅探模块与固定向量已形成源码候选，提供浏览及八种专用上下文分派、禁嗅与旧服务器标记、规范字节表、MP4 品牌盒、WebM 文档类型与 MP3 两帧检查。接入方案、规范笔误处理、来源许可及待验事项见 [网页嗅探说明](网页嗅探说明.汉语.md)。运行验证留待统筹安排。
