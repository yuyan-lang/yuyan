# 文件类型

依卷首魔数识常见图像、音声、影像、压缩、归档、PDF、字体、可执行卷与 BOM 之文。供常用末名媒体之类、严验 UTF-8、网页嗅探及 freedesktop 图标之名。字节以整数列入，魔数未识还空串，末名未识还 application/octet-stream。

官方末名表由文件类型数据生成包取 shared-mime-info 2.4 官方 XML 而成，凡简单末名规则 1185 条。所自 https://gitlab.freedesktop.org/xdg/shared-mime-info/-/raw/2.4/data/freedesktop.org.xml.in ，许可为 GNU GPL 第二版或后版，全文见数据许可.txt；原卷存仓外豫言数据/文件类型。

识 ZIP 内容，自末目录记录定中央目录，验条目之界及全名，识 OOXML 文档、表格、演示与 JAR。EPUB 取首个无压缩 mimetype 条目之文而识之。总入口为文件媒体类型。

生成之命：`yy文件类型数据生成 shared-mime-info-2.4.xml.in 官方扩展表。豫`。数据以制表符隔末名与媒体之类，以换行隔记录，纳于源码串；模块初载，一次化为末名表。

后续之事：纳 IANA 全籍，备复合末名、杂通配与权重之规；经归档库续 ZIP64、多卷及 OOXML 内容类型 XML；经编码转换判余编码；备 WHATWG 上下文之法及跨库回归诸例。
