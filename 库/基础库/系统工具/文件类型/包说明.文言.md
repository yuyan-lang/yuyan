# 文件类型

依卷首魔数识常见图像、音声、影像、压缩、归档、PDF、字体、可执行卷与 BOM 之文。供常用末名媒体之类、严验 UTF-8、网页嗅探及 freedesktop 图标之名。字节以整数列入，魔数未识还空串，末名未识还 application/octet-stream。

官方规则表由文件类型数据生成包取 shared-mime-info 2.4 官方 XML 而成，凡文件名之规则千二百二十五条，悉录之，并纳 IANA 登记模板之末名字段。shared-mime-info 所自 https://gitlab.freedesktop.org/xdg/shared-mime-info/-/raw/2.4/data/freedesktop.org.xml.in ，许可为 GNU GPL 第二版或后版，全文见数据许可.txt；IANA 登记数据以 CC0 1.0 许可，所自及定值之籍见数据生成包说明。原卷存仓外豫言数据/文件类型。

识 ZIP 内容，自末目录记录定中央目录，验条目之界及全名，识 OOXML 文档、表格、演示与 JAR。EPUB 取首个无压缩 mimetype 条目之文而识之。总入口为文件媒体类型。

生成之命：`node --max-old-space-size=16384 yy稳定节点宿主/宿主.cjs yy文件类型数据生成.wasm shared-mime-info-2.4.xml.in 官方扩展表。豫`。同级存 `IANA媒体类型.xml` 及 `IANA模板/`。数据以制表符隔模式、媒体类型、权重、大小写四栏，以换行隔记录，纳于源码串；模块初载，一次化为规则表。

后续之事：续核 IANA 登记模板自由说明之末名字段；经归档库续 ZIP64、多卷及 OOXML 内容类型 XML；经编码转换判余编码；备 WHATWG 上下文之法。

全文件名之规，及定名、复合末名、星号、问号、字组、范围、转义及大小写标记。先定名，次权，次规长；同级异类，还通用二进制之类，有内容则以魔数之口识之。文件名匹配定向量于 Node 及原生运行皆过。

跨库向量取归档库已入籍之系统 ar、cpio、ZIP 实卷，召文件媒体类型以验其字节。向量于仓库根行，已于 Node 及原生运行皆过。

甲级魔数之验，逐核现有五十前缀之记及各记之截短，及图像、音声、影像、归档、压缩、PDF、字体、ELF、Mach-O、PE、Wasm 与 BOM 之文。又独核 RIFF 第八字节、ftyp 第四字节及品牌之位、TAR 第二百五十七字节，兼验截短与错位。魔数依前缀及定位而识；全卷结构之析，俟后版。

公开末名查询，验 IANA 之 u8msg、ivs，裸末名 png，复合末名 svg.gz，及官方同权 pot 歧义还通用二进制之类。构建之命为 `豫构 构建 文件类型 测试 甲级魔数。测试 --输出 yy甲级魔数测试.wasm -j 24`。

甲级魔数及官方查询定向量，已于 Node 及同源硬浮点原生生成器、执行器运行皆过，出文“甲级魔数与官方查询固定向量通过”。

首用之器为简易网页服务器。测试目录先存甲补证消息.u8msg 与所自有据之实甲补证图像.png，以此目录为服务之根，分别向 Node 及同源原生服务器发 HTTP GET。响应 Content-Type 为 message/global 及 image/png；响应之文与原卷及两端之文逐字节相同。图像复取图像编解码测试中动便图绿色参考之样。
