# 文件类型数据生成

所成源码以一「官方扩展数据」串存 TSV 之数，始时依换行、制表分之而成「官方扩展表」。每条列扩展名、实制表字节、媒体类型及换行。

输入之径终于 `.xml` 或 `.in` 者，读官方 `freedesktop.org.xml.in`，逐行取 `mime-type` 之 `type` 属性及其 `glob` 之 `pattern` 属性。官方之文循一行一宣、双引属性之发布式。XML 实体之还原及他排版之式，俟后版。

行 `yy文件类型数据生成 globs2 输出。豫`，以 shared-mime-info 之 globs2 成豫言扩展表。原始之数置仓外 `~/repos/yuyan-worktrees/豫言数据`。其「官方扩展表」列扩展名与媒体类型之偶，去名首之点，存原序及复合扩展。首项为空名与默认媒体类型。

读权重、媒体类型、模式三栏，取 `*.扩展` 之简式。繁通配式、权重排序及大小写之记，俟后版。官方全数之取与成表之记，由维护者行之。
