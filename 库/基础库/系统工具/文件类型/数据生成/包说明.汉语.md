# 文件类型数据生成

运行 `yy文件类型数据生成 输入 输出。豫`，从 shared-mime-info 生成豫言规则数据。原始数据放在仓外 `~/repos/yuyan-worktrees/豫言数据`。

输入路径以 `.xml` 或 `.in` 结尾时，逐行提取官方 `freedesktop.org.xml.in` 的 `mime-type type` 及全部 `glob` 的 `pattern`、`weight`、`case-sensitive` 属性。缺省权重为 50，缺省大小写标志为阴，`true` 表示阳。其他路径读取 globs2，保留模式、媒体类型、权重与 `cs` 标志。

生成源码以单个「官方扩展数据」字符串保存 TSV：模式、媒体类型、权重、大小写标志四列以实际制表字节分隔，各行以换行分隔。初始化只解析一次，得到内部「官方匹配规则」四元组列表，依次包含字符串、字符串、整数、爻。规则保持输入顺序。

「官方扩展表」保持扩展名与媒体类型二元组列表接口，由完整规则抽取简单 `*.扩展` 模式派生，去掉开头的点，保留复合扩展名；首项为空扩展与默认媒体类型。包含星号、问号、方括号的扩展模式保存在完整规则中。

官方 XML 输入采用每行一条声明、双引号属性的发布格式。XML 实体还原与其他排版形式留待后续版本。本次源码仅作静态核对，构建、生成及运行验证留待恢复验证时执行。
# IANA 注册数据

输入为 IANA 媒体类型 XML 时，从同级 `IANA模板/` 目录读取各 `<file type="template">` 对应的注册模板，提取 `File extension(s)` 字段及续行，输出通配规则。缺少任一登记模板即停止生成。

官方注册 XML：`https://www.iana.org/assignments/media-types/media-types.xml`。模板对应 `https://www.iana.org/assignments/media-types/` 后接 XML 中的媒体类型路径。注册数据采用 CC0 1.0，条款见 `https://www.iana.org/help/licensing-terms`。

本轮待验：XML 与模板全量下载核对、1225 条 shared-mime-info 规则重新生成、独立文件名及 IANA 模板向量的类型检查与 Node/native 运行。

输入 shared-mime-info 数据时，同级 `IANA媒体类型.xml` 与 `IANA模板/` 自动作为补充来源合入；IANA 扩展赋权零，shared-mime-info 保留原权重，补充来源用于已有规则以外的扩展。输入 IANA XML 时只处理登记来源。

本轮冻结 IANA XML 内的更新值 `2026-10-07`，登记模板引用 2364 项且互异；官方 rsync 下载文件 2373 项，引用缺项零、下载失败零，逐文件 checksum dry-run 差异零。仓外 `IANA模板引用清单.tsv` 保留引用原值，`IANA模板文件校验.tsv` 保留逐文件 SHA256，`IANA许可原页.html` 保留官方许可原页。
