# 网页媒类嗅探

私卷 `网页嗅探。豫` 依 [WHATWG MIME Sniffing Standard](https://mimesniff.spec.whatwg.org/) 为字节模式、未知媒类、文本二进制之辨及用境分派。读准之日为 2026-10-08。

`网页上下文嗅探` 受宣类之串、资源首字节之列、禁嗅之爻、旧服务器检验之爻、用境之串、支持宣类之爻。用境有「浏览」「图像」「影音」「字体」「插件」「样式」「脚本」「字幕」「缓存清单」。返空串者，媒类未定也；参数由调用者守之，宣类有效而当存者，返其原串。宣类本质须合 HTTP token，以 ASCII 小写校主类与副类。

浏览之境先存 XML、HTML 宣类，继辨未知宣类、禁嗅、旧服务器之文本检验、所支持图像影音之宣类。未知宣类有未定、`unknown/unknown`、`application/unknown`、`*/*`；`application/octet-stream` 为有效宣类。未知者之脚本嗅探受禁嗅之爻制；图像、影音、归档各用准中之表。辨文本与二进制用所定控制字节之集；高位字节得文本之类。

图像之式有图标、光标、BMP、GIF、全 WebP 首记、PNG、JPEG。影音之式有 AIFF、ID3、Ogg、MIDI、AVI、WAVE，及 MP4 品牌盒、WebM 文档类型、相邻 MP3 帧。字体之境有嵌入字体、TTF、OTF、字体集、WOFF、WOFF2。归档之式有 GZIP、ZIP 本地头、RAR 四版之记；返媒类之名从准。HTML 标签末须空格或 `>`，注释首记亦从此；XML 首记须小写相同。

HTTP 调用者可用 `网页旧服务器标记` 校末一 Content-Type 头之原串，四串须全同。所来之源、重头之末取、读取之时限、浏览器所支持媒类之集，皆受于调用者。读资源首部，可至卷末、得 1445 字节，或所定等待之时至而止。

`网页默认嗅探` 受旧入口二物，用许嗅之浏览境，支持图像影音之宣类，谓非 HTTP 所得。合卷时，`文本嗅探。豫` 添同包之入 `寻观「文件类型」之「网页嗅探」之书。`，以 `「网页默认嗅探」于「声明」于「数据」` 易 `网页媒体嗅探` 之体，类签仍旧。`总集。豫` 所出仍旧。

后续合卷之事：公开用境入口俟统筹定 API 之授权；二参之物足表达默认浏览之义，全用境由私核与定例表达。样式、脚本之境无宣类者，活准第八章第五、第六节以省文示之；此返未定之类。

活准第六章第二第三节，MP3 帧界写 `skipped-bytes > s - length`，首位零则诸正长帧皆拒。此依余字节数为界，其余头匹配、码率表、版本位、频率计算逐从其节。WebM 变长整数自所传之位读之，以文档类型之长限填零匹配之域，短而未全者拒之。偏移、截断、掩码、两帧之例在 `测试/网页嗅探。测试。豫`。

此阶段既排源码，验总集之类，定例于 Node 与苹果臂六十四原生皆成。百万输入与性能之测，俟后验之。
