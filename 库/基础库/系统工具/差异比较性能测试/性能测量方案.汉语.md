# 差异比较性能测量方案

当前为静态源码候选，构建、运行、中位数、原生与系统性能比值均待执行。

先串行包检查、类型检查、构建 `差异比较性能测试 测试 全量 性能`，输出 `yy差异性能.wasm`，并行数24。八任务各32行做短验，再用同源生成器与执行器验证原生八任务。

正式规模依次256、1024、4096行。程序每项预热两次、测量九次，取第五个排序值。独占同机窗口，保留客体摘要、提交、工具链、系统CPU、负载、每项输出和退出码。初始参考生成属于启动准备；库内计时含重建校验。

由程序 `导出 规模` 生成五个文件，记录SHA256。GNU来源用 `diff --version` 核对；统一输出命令为 `diff --label 旧 --label 新 --unified=规模 yy差异旧文.txt yy差异新文.txt`，标签以库输出实际头部为准。差异预期退出1，正文逐字核对。

Git命令为 `git diff --no-index --no-prefix --diff-algorithm=myers --unified=规模 yy差异旧文.txt yy差异新文.txt`，另换patience、histogram。预期退出1，文件头与index路径作为元数据保留，正文比较；歧义脚本核对重建与编辑数。

三方命令为 `git merge-file --diff3 -L 左 -L 基 -L 右 -p yy差异新文.txt yy差异旧文.txt yy差异右文.txt`，不相交载荷预期退出0，逐字比较 `yy差异合文.txt`。

外部计时用已有豫言进程能力或系统计时器，每项预热二次、测九次，取排序第五项；输出统一重定向临时文件。保留九个原始时间、命令、退出码。外部包含进程启动与文件I/O，库内包含结果校验；报告同时列出口径。按算法规模报告原生与同机系统实现五倍目标差距。字素与补丁应用的库内时间单独记录，直接同语义外部性能对照留待后续测量。

本方案使用单次原生命令或现有豫言设施串行执行。实际数值和日志路径在运行后补录。
