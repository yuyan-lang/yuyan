# 差异比较性能测试

本包是差异比较独立性能程序，直接依赖标准库、差异比较和基础库测试设施，属于系统工具基础库。

入口为 `测试/全量/性能。脚本。豫`，参数依次为任务名、行数；默认迈尔斯、256行。任务支持迈尔斯、耐心、直方、按行、字素、统一输出、补丁应用、三方合并。每项预热两轮、测量九轮，输出中位纳秒与核值。结果重建校验包含在计时内；序列算法预先分行，按行与字素包含切分，应用使用预先生成的补丁。输入与初始参考生成属于启动准备时间。

编号行各异，含组合附标、ZWJ表情、区域旗帜、肤色。左右修改模三十一余七与十九的行，代表疏散修改、唯一行定锚和不相交合并。重复行、全替换、密集冲突留待后续测量。

`导出 行数` 将载荷写入当前目录五个 `yy差异` 文件，供GNU diff、Git独立对照。正式运行状态见性能测量方案。

`测试/全量/外部基准。脚本。豫` 捕获 GNU 与 Git 的完整输出并逐字核验：外部差异、版本迈尔斯、版本耐心、版本直方、外部合并五个任务。GNU diff3 显式使用同版 GNU diff。外部工具位于当前目录的 `yy差异外参/`，作为独立对照；包的实现依赖标准库与豫言库。

256行同载荷的八内部任务与五外部任务均已在 Node 和原生执行完成，预热2次、测量9次、中位数及限制见差异比较《乙级实施记录.汉语.md》。内部计时含重建校验；外部计时含子程启动、捕获及完整输出校验。性能差距按这两种口径记录。
