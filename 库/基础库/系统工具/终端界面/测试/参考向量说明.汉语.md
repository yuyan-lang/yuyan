# 终端参考向量

`序列。测试。豫` 的转义序列期望值据 [ECMA-48 第五版](https://ecma-international.org/publications-and-standards/standards/ecma-48/)及 [xterm 控制序列说明](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)手录。期望值使用固定文字与 ESC 字节，独立于本库颜色、样式及光标编码函数。

ECMA-48 对应项为 CUU、CUD、CUF、CUB、CUP、EL、ED 与 SGR。xterm 对应项为十六色亮色、索引色、真彩色、DECSC/DECRC 与 SGR 鼠标。鼠标按下用 M，释放用 m，字段依次为原始按钮码、列与行。

TERM、COLORTERM、NO_COLOR 的向量测试本包颜色能力规则；进度条和转圈的向量测试本包显示格式。
