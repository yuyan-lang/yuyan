# 终端界面

此包出 ANSI、VT 诸序，具十六色、索引色、真彩色、式样、光标、清屏、鼠标与备用屏。召者取串而输于终端。

色能受 TERM、COLORTERM 与 NO_COLOR 有无，还零、十六、二百五十六或一千六百七十七万七千二百一十六。进度与旋标受数与帧。屏以行串列存之，差刷唯出异行，亡行则清之。

具列表、表格、文本输入与对话框之文字。窗变受旧新宽高。鼠析受 SGR 报，次还钮码、列、行及释放之记。豫构之构建监视用本包进度条，行编辑可取光标定位与清行。

源码皆豫言，依仓库之许可。诸序据 ECMA-48 及 xterm 鼠标协议。环境之读、输出之送、输入之集、窗度之报与控件之态，皆由召者主之。鼠报须具三项非空十进制数，以 M 或 m 终之；不合法则还空列。统一码宽度、逾平台之坐标数值及原生裸机核验，俟后续。

2026-10-07，于本地 macOS 诺节变鼠报百万，钮与坐标随序号而变，每串易一可印 ASCII 字，皆毕；样本最长二十三字。测一次，用户 CPU 1.34 秒，系统 CPU 0.05 秒，墙钟 26.21 秒。墙钟含宿主之启，测时仓库并行构建。序验兼察按下、释放、非法 ESC 与 CSI 首序、空项、缺项及尾文。
