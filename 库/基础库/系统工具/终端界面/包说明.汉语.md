# 终端界面

本包提供 ANSI/VT 十六色、索引色、真彩色与样式序列、光标定位、上下左右移动、保存恢复、清屏、鼠标模式与备用屏幕。调用者把返回字符串写入终端。

颜色能力接收 TERM、COLORTERM 与 NO_COLOR 是否存在，返回 0、16、256 或 16777216。进度条与转圈按调用者给出的数值和帧号生成。屏幕以字符串行列表保存，屏幕差刷仅输出改变的行并清除消失的行。

列表、表格、文本输入与对话框提供文字渲染。窗口变化接收前后宽高。解析鼠标读取 SGR 报文，返回按钮码、列、行、释放标记列表。豫构的构建监视面板使用本包进度条，行编辑可直接使用光标定位与清行。

本包源码由豫言编写，采用仓库许可。序列依据 ECMA-48 与 xterm SGR 鼠标协议。调用者负责读取环境、发送输出、收集输入、通知窗口尺寸与维护控件状态。鼠标报文具有三个非空十进制字段，以 M 或 m 结尾，非法报文返回空列。统一码宽度接入、超平台坐标数值处理与原生及裸机验收留待后续。

2026-10-07 在本地 macOS 诺节执行一百万条鼠标报文变异，按钮与坐标随序号变化，每串替换一个可打印 ASCII 字符，全部完成；样本最大 23 字符。单次测量用户 CPU 1.34 秒、系统 CPU 0.05 秒、墙钟 26.21 秒。墙钟包含宿主启动，测量时仓库有并行构建。序列回归另覆盖合法按下与释放、非法 ESC/CSI 前缀、空字段、缺字段和尾随文本。
