# 终端界面

本包提供 ANSI/VT 十六色、索引色、真彩色与样式序列、光标定位、清屏、鼠标模式与备用屏幕。调用者把返回字符串写入终端。

颜色能力接收 TERM、COLORTERM 与 NO_COLOR 是否存在，返回 0、16、256 或 16777216。进度条与转圈按调用者给出的数值和帧号生成。屏幕以字符串行列表保存，屏幕差刷仅输出改变的行并清除消失的行。

列表、表格、文本输入与对话框提供文字渲染。窗口变化接收前后宽高。解析鼠标读取 SGR 报文，返回按钮码、列、行、释放标记列表。豫构的构建监视面板使用本包进度条，行编辑可直接使用光标定位与清行。

本包源码由豫言编写，采用仓库许可。序列依据 ECMA-48 与 xterm SGR 鼠标协议。调用者负责读取环境、发送输出、收集输入、通知窗口尺寸与维护控件状态。统一码宽度接入、鼠标畸形报文严格校验、运行性能与原生及裸机验收留待后续。
