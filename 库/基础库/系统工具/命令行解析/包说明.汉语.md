# 命令行解析

本包用声明式命令与选项描述解析参数。直接依赖标准库与数值格式，包含在系统工具基础库。

命令壳动态补全使用既有环境登记协议：键为 `命令补全：<程序路径>`，值为以空白分隔的声明词表。生成命令壳补全脚本后执行正式设置命令，可为该程序登记候选；再次设置同键覆盖词表，取消该键移除登记。控制台与图形命令行共享壳核心的运行补全规则。正式输入 `「运行」于「工具」于「--」` 的程序参数位置使用「工具」的登记词表，程序路径位置使用原有路径候选。按当前参数上下文筛选声明词表留待后续版本。

`声明选项` 依次接收长名、短名、类型、默认值、必填标记、互斥组、枚举值和说明；`声明命令` 接收名称、说明、选项列和子命令列。

`解析命令行` 接收命令声明与参数列，返回诊断文字、选中命令名、选项键值列及位置参数列组成的四元组。诊断为空表示成功；`--帮助` 返回帮助文字。`读取选项` 按长名读值。

当前支持长短选项、默认值、必填检查、子命令、位置参数与 `--` 终止选项。类型字段可用字符串、整数、小数、枚举与列表；整数、小数和枚举在解析时校验，小数接受带正负号的十进制定点表示。互斥组按显式输入检查。`读取整数选项` 返回整数，`读取列表选项` 收集重复选项的非空值。

祖先命令的选项可以在进入子命令之前填写。解析完成后逐层保留默认值并核对必填约束，根命令、子命令与孙命令的约束共同生效。

`命令帮助` 生成用法与选项说明；`补全词` 收集声明中的选项、枚举值及子命令；`生成补全` 支持 bash、zsh；传入「命令壳」生成正式「设」命令脚本，把声明词表登记到命令环境，其他壳名返回词表。运行参数候选按当前文字精确前缀过滤；声明类型与参数上下文的进一步筛选以及乙级验收留待后续版本。

`示例。豫` 是第一个使用者，读取真实进程参数，解析构建输出选项与入口路径；六条进程参数参考见 `测试/示例参考.tsv`；`测试/解析。测试。豫` 用表格覆盖基础解析、类型检查和错误输入，并检查帮助、列表与补全。

`数字串合法`、`读取整数选项` 与 `读取小数选项` 复用数值格式的正式解析接口。整数采用有符号六十四位十进制范围；小数接受定点、科学计数及数值格式规定的特殊值，按 IEEE 754 双精度舍入。读取缺省空值返回零。路径和文字保留输入，列表用重复选项表示。`测试/整数参考。测试。豫` 覆盖四组独立整数位型与七组非法或越界输入；`测试/小数参考。测试。豫` 覆盖八组独立 IEEE 位型及九组非法输入，两项由全树测试自动发现。

实现与测试用例由本项目编写，采用仓库的 GNU AGPL 第三版许可。包内无外部数据表。原生性能比较、扩大模糊输入范围及原生、裸机验收留待后续版本。
