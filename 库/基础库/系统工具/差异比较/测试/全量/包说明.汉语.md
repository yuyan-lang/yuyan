# 差异比较全量测试

这是差异补丁三个公开输入入口的隔离变异测试包，登记在系统工具基础库之下。入口0调用解析统一补丁，入口1调用解析补丁块，入口2调用模糊应用补丁。

每个入口百万运行包含100批，每批10000个确定性变异输入。编号0至999999，种子由编号整除10000再对6取余确定，翻位、删除、插入与替换由基础库测试设施执行。语料覆盖普通修改、多块、零长度插入、末行无换行、过长数字与空输入。原始字节包含零字节及无效UTF-8，直接送入真实文本入口。

`烟测` 每入口5次；`百测` 每入口100次；`百万` 每入口1000000次。`入口批 入口 起点 次数 进度路径` 执行一批；`重放 入口 编号` 重建单样本，返回0为成功、2为输入拒绝。父程序按一批一子程隔离，时限1200000毫秒，任何非零退出或末编号不符均失败；失败保存进度与字节样本。父程运行期间须保留当前工作目录可写。

峰值常驻资源测量由运行者以系统工具记录。公共设施的资源强上限接口接入留待后续版本，本包使用真实隔离时限及非零失败判定。

当前源码构建与类型检查通过；三入口的烟测、百测、六种子短批及各入口1000000编号变异已在 Node 和同源原生两端运行退出零。两端使用同一 `90ca1126…` 客体，300子批末编号各到999999；实际时间、RSS与文件摘要见差异比较《乙级实施记录.汉语.md》。
