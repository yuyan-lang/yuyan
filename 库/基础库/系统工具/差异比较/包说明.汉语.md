# 差异比较

本包提供按行的最短插入删除差异。`序列比较` 接收两份字符串列表，返回 `保持`、`删除`、`插入` 三种差异项。`按行比较` 保留每行的换行符与末行状态。`按词比较` 以连续非空白非标点字符为词，独立保留空白与标点。`按字素比较` 接收统一码字素切分器和两侧文本。`差异旧文` 与 `差异新文` 重建两侧文本，`应用差异` 检查原文并返回新文。`文本相似度` 是公共行数两倍占两侧总行数的整数百分比，空文相似度为 100。

默认序列比较采用 Myers 双向波前和中间蛇分治，只保存线性大小的对角线数组。`耐心比较` 采用双方唯一项和最长递增锚链，空隙调用 Myers；`直方比较` 采用出现次数最低的共同项定锚。另保留 Hirschberg 公共子序列用于对照。

导入 `差异比较/字素` 后，`默认字素比较` 直接接收两侧文本，使用统一码库的扩展字素簇切分；`按统一码词比较` 使用官方词边界。总集的 `按字素比较` 保留自选切分器接口。字素模块单独导入，可以按使用场景选择文字处理入口。

导入 `差异比较/补丁` 可调用 `统一补丁`、`解析统一补丁`、`模糊应用补丁`。输出采用完整上下文的单个统一补丁块，保存末行换行状态。解析与应用支持同一文件的多个块、省略数量的单行范围与零行插入范围。

`差异比较/补丁块` 的 `解析补丁块` 保存各块的新旧行号、行数与差异项，并核对正文行数。`解析统一补丁` 顺序汇总各块的差异项。`模糊应用补丁` 按行号与先前块的偏移，在已施块末尾之后寻找最近匹配；纯插入检查指定位置，越界时返回可无。完整上下文失败后，逐级略去两端最多两行保持项，原文对应上下文仍予保留。由此可以应用行号漂移与上下文发生编辑的补丁。

导入 `差异比较/合并` 可调用 `逐段三方合并`，按基文位置聚合变更，不相交的变更自动合并，重叠的变更以 diff3 冲突标记保存双方与基文。冲突段按文本末行状态补必要换行，保持标记位于独立行。总集的 `三方合并` 提供整篇相同或一侧未改的快捷处理。

默认统一码字素、多块上下文模糊应用、三算法独立参考与 Git 多块补丁及逐段合并向量已在 Node 与原生执行器通过固定测试。

后续实现事项：多文件补丁的文件名路由与严格无效头诊断；完成全规格验收。
