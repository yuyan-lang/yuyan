# 差异比较独立参考调查

固定向量位于 `测试/参考/多块原文.txt`、`测试/参考/多块新文.txt`、`测试/参考/多块参考.补丁`。

补丁来源为本机系统 `git version 2.50.1 (Apple Git-155)`。生成命令为：

```
git -c core.quotepath=false diff --no-index --no-prefix -U1 -- 库/基础库/系统工具/差异比较/测试/参考/多块原文.txt 库/基础库/系统工具/差异比较/测试/参考/多块新文.txt
```

Git 输出两个块：`@@ -1,3 +1,4 @@` 和 `@@ -8,3 +9,3 @@`。第一块替换第二行并增加一行；第二块替换原第九行，应用时累计偏移为一。`测试/外部参考。测试。豫` 直接读取三个固定文件，检查块坐标、块数与应用后的完整原始期望文本。运行目录为仓库根。

`测试/参考。测试。豫` 另列独立手工脚本，覆盖空输入、中间插删、Myers／patience／histogram 三算法及经典 `ABCABBA → CBABAC` 的五次最短编辑。行相似度三行与两行共享两行，独立期望为百分之八十。

交叉锚点固定向量为 `abc → bac`，独立最短编辑数为二，三种算法均核原文与新文重建；允许选择不同公共子序列。

三方合并固定向量另由 `git merge-file --diff3 -L 左 -L 基 -L 右 -p` 从 `合并左文.txt`、`合并基文.txt`、`合并右文.txt` 生成 `合并期望.txt`。该向量要求冲突文本与标记之间恰有必要的换行。静态对照发现原实现对已经带换行的冲突文本重复增加换行，本轮改为按各侧末行状态排布标记。外部参考测试直接逐字比较 Git 期望文件。

多段自动合并另以十二行 `多块原文.txt` 为基，左侧替换第二行，右侧替换第九行，用同一 `git merge-file --diff3` 命令生成 `分段期望.txt`，Git 返回零并保留双方变更。外部参考同时核逐段合并输出与这个独立完整期望。

静态复核另补两项保护：后块寻找匹配以先前已施块末尾为下界；纯插入检查指定位置范围。固定失败用例包含后块旧文本只出现于前块刚生成的内容、纯插入超出实际文件行数。两项修订保持应用入口签名。
