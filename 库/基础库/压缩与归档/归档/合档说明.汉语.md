# 合档

合档模块提供 tar 字节串读取与写入，保存普通文件、目录、符号链接、权限与链接目标。

`合档条目` 的五个字段依次为路径字符串、内容字节串、权限整数、链接目标字符串、类型字节整数。类型 48 表示普通文件，53 表示目录，50 表示符号链接。目录和链接使用空内容字节串。

`合档读取` 接收字节串，返回条目列表的可选值，读取 ustar 前缀、pax 路径和链接路径记录、GNU 长名和长链接记录。`合档写入` 接收条目列表，短路径写入 ustar 首块，长路径与长链接使用 pax 记录；`合档GNU写入` 使用 GNU 长名记录。写入时间、用户与组为零，以得到可复现字节。

`合档路径安全` 验证相对路径。读取与写入均验证路径及非空链接目标；空路径、绝对路径、父目录段、盘符、反斜杠、零字节返回失败。首块校验和错误、截断数据、无效八进制字段与未识别的条目类型返回可无。文件系统解包由调用者执行，调用者应逐级检查父目录并防止符号链接穿越。

后续事项：GNU 基数二数值字段、pax 全局路径记录的跨条目继承、硬链接和特殊设备条目、用户与时间元数据留待后续版本。

验证覆盖普通文件、目录、权限、符号链接、中文 pax 长名及长链接、GNU 长名及长链接往返、恶意路径与截断输入。独立工具链编译后运行 `合档。测试`。
