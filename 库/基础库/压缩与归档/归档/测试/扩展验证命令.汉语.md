# 扩展归档短验命令

候选依赖为编码转换已验 `41ee0a067`；泽标压 `d6f2cef8b`、`d28d2cb87`；叉泽存储 `373256aeb`；归档桥接 `1cddbf8f6`。编码链前三提交为 `66fd72a97`、`2d8cd7fde`、`4abe740ad`。待根集成依赖后，在独立验证树使用最新同包工具链执行。

仅一次构建覆盖国标扩展整档文件名、方法93泽标压档、泽标合档、叉泽合档、空串与跨 65536 字节叉泽子块、内容字节及权限。测试输出四份系统互读材料。

```text
/opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 归档 测试 扩展格式。测试 --编译器 ./yy_bs_stable.wasm --输出 yy归档扩展测试.wasm -j 24
/opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy归档扩展测试.wasm
/usr/bin/tar -tvf yy扩展合档.tar.xz
/usr/bin/tar -tvf yy扩展合档.tar.zst
/usr/bin/tar -tvf yy扩展压档.zip
```

若系统 tar 所带格式支持不足，使用已安装的官方工具作直接校验：

```text
/opt/homebrew/bin/xz -t yy扩展合档.tar.xz
/opt/homebrew/bin/zstd -t yy扩展合档.tar.zst
```

系统 unzip 的旧版可能尚无方法93；优先用系统 tar/libarchive 读取压档。国标压档的系统名称显示受工具编码配置影响，整档解码名称由测试断言为「中文.txt」。
