# 布罗压元块解码

`布罗解块` 解码压缩元块的编码头与数据。参数依次为输入、起位、元块解压长度、窗口大小、已有输出、输出上限、距离环；返回状态码、完整输出、新位偏移。状态零为成功，一为超限，二为损坏。

距离环槽零至三保存最近、次近、第三近、第四近距离。流入口建立 `[4,11,15,16]`，后续元块共用此环。模块读取三类块切换与码树，按上下文解字面量，执行长度与距离命令，支持重叠回拷和静态字典变换。输出长度到达元块目标时结束。

验证：格式化与联合类型检查通过，十组官方编码器压缩向量及其全部截断前缀、超限测试通过。

省略变换产生空字典词时，命令可以继续读取后续编码。位流与输出同时停滞时返回损坏。此项修复及 `布罗跨块。测试。豫` 的十个调用已通过 Node 与同客体苹果臂六十四原生核验。

块类别声明用于范围与树阵，元块结束按解压目标长度判定，未使用类别保留合法输入预期。新增源码格式化、差异检查及压缩包完整类型检查通过。完整证据见《布罗短固定实施记录》。

回拷按历史末距的周期段指数倍扩展，再一次追加历史。距离一、距离二、短于距离、跨周期、零长度与最高复制长度固定强核在两个后端通过；修后官方八对全文在 Node 与同客体原生逐字对照通过，详见《布罗回拷性能实施记录》。

字面插入段使用局部缓冲，前两字从段内已写字与旧历史连续取得，段末一次追加。十六个四模式、跨段、空及单字历史固定用例、官方八对全文在两个后端通过，详见《布罗字面缓冲实施记录》。
