# 压缩

提供纯豫言字节串压缩与解压。原始收缩解压读取存储块、固定哈夫曼码与动态哈夫曼码；压缩输出标准存储块。泽压库封装检查头部及阿德勒32校验，输出标准泽压库流。

`解压原始收缩`、`解压泽压库` 依次接收输入字节串和最大输出字节数；`压缩原始收缩`、`压缩泽压库` 接收输入字节串和压缩级别。结果为状态整数与输出字节串。状态 0 表示成功，1 表示超过输出上限，2 表示损坏，3 表示尚待实现的预设字典；失败结果为空字节串。原始流末尾附带多余字节返回损坏。

测试采用公开固定码的hello向量、标准泽压库hello向量、阿德勒32的123456789校验值、存储块与泽压库往返、输出超限、尾随字节与坏块。实现依照收缩和泽压库公开格式规范；源码与测试随本仓库许可。

动态编码、惰性匹配、压缩级别优化、吉压封装、预设字典与流式状态留待后续实现。原生、百万变异输入、性能量测与裸机验收留待后续。本包当前为部分实现。
