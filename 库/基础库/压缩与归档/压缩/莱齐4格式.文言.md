# 莱齐4格式

`快速压缩`有`莱齐块压缩`、`莱齐块解压`、`莱齐帧压缩`、`莱齐帧解压`。压者受字节串，解者兼受解压量之限。果为状态与字串：零成，一越限，二损或参数未受。

块读字面、延长、十六位距离及叠取。块书以四字散列求匹配，末留五字面，末匹配之始距终至少十二字。块读先核长度、距离及终界，乃依实长造藏；限唯约出文之长。

帧书六万五千五百三十六字之独立压块或存块。帧读压块、存块、相依块、实长、联帧及十六种可略帧。以共用校验库之XXH32核帧首、块及全帧出文；所宣实长须等所出。块限随首为六万五千五百三十六、二十六万二千一百四十四、一百零四万八千五百七十六或四百一十九万四千三百零四字。各帧更始其块史。

`莱齐块字典解压 输入 上限 字典`以典末六万五千五百三十五字为回溯窗。`莱齐帧字典解压 输入 上限 字典 字典号`核首所宣之典号；号由召者约之。独立块各始于典，相依块承前出之窗。旧`莱齐帧解压`读常帧，有典号者由字典之口读之。

`莱齐块字典压缩 输入 字典`书用典之块。`莱齐帧字典压缩 输入 字典 字典号`书有典号之独立块帧，块限六万五千五百三十六字。典号取零至四十二亿九千四百九十六万七千二百九十五。

后版之事：帧压之可择校验参数、增量流之口、分块出文之速。

格式据：[LZ4帧规范](https://github.com/lz4/lz4/blob/dev/doc/lz4_Frame_format.md)、[LZ4块规范](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md)。
