# 缩流编码

`压缩原始收缩` 依次接收输入字节串和零至九级压缩级别，返回状态整数与压缩字节串。成功状态为 0。越界级别抛出参数异常。

零级输出标准存储块，每块至多 65535 字节。一至三级输出固定霍夫曼块；四至九级输出动态霍夫曼块。动态块携带完整的文字符号和距离码树，支持最长 258 字节匹配及最大 32768 字节距离。三字节哈希链寻找匹配，级别控制搜索深度；下一位置存在更长匹配时，编码器先输出当前字节，再处理下一位置。空串和任意二进制字节可用。

算法和码表依据 RFC 1951。实现使用标准库的客体字节缓冲、数组引用和位运算。输出缓冲按输入的两倍加 1024 字节分配；码树采用确定的完整长度分配。按频率优化码树与流式状态留待后续版本。

验证入口 `收缩编码。测试。豫` 覆盖零至九级、存储块边界、固定与动态块类型、重复数据压缩、空串与匹配内容。测试输出 `yy编码级0.gz` 至 `yy编码级9.gz`，系统 `gzip -tv yy编码级*.gz` 可核验每个输出。32768 字节窗口边界、混合二进制与系统反向互解的扩展核验另行登记。

2026-10-07 在受信任开发机 pit-mac 完成十级编码往返与系统 gzip 校验。100000 字节七字节周期样本：零级 100010 字节，一至三级 688 字节，四至九级 822 字节。扩展的混合二进制、窗口边界与系统反向互解等待统一验证队列。
