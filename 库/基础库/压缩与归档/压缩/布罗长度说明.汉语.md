# 布罗长度

本模块依据 RFC 7932 第 4、5、6 节，将命令号映射到插入与复制长度编码号，提供长度基数、额外位数、块长度表及距离译码。

命令号范围为 0 至 703；插入与复制编码号范围为 0 至 23；块长度编码号范围为 0 至 25。调用方验证编码号范围，并将读取的额外位值加到基数上。

`布罗距离` 按顺序接收距离号、后缀位数、直接距离数、额外位值及最近的四个距离。初始最近距离依次为 4、11、15、16。调用方验证译出的距离为正，并维护历史距离队列。距离号为零及静态词典引用沿用原有队列。

`布罗长度。测试。豫` 覆盖命令区段边界、最长长度、块长、短距离和含后缀的距离。
