# 泽标压混合样本排查

## 已有运行证据

压缩统筹在统一核验时段使用系统 zstd 1.5.7 生成对照。泽标压自测先通过，周期大样本的一级、九级、十九级标准压缩帧通过。混合中文样本的九级压缩帧首次失败，测试仅输出 `yy泽标混参考.zst` 文件名。训练字典对照已生成，尚未执行到该项。

本次在原独立工作树同步最新 yybs 后进行静态排查，没有构建或测试。

## 静态确认的概率表缺陷

`熵概率读` 原先使用 `bitLength(剩余量 - 1)` 选择位数。FSE 规范与参考实现只在剩余量严格小于阈值时降低阈值；剩余量等于二的幂时应保留上一档。因此应使用 `bitLength(剩余量)`。

独立回归表精度为五，概率为 `[1, 16, 15]`，序列化字节为 `20 e2 07`：

1. 首符号读取概率一后，剩余量为三十二。
2. 正确阈值保持三十二，以短字段读取第二符号概率十六。
3. 剩余量为十六时，正确阈值保持十六，读取末符号概率十五。
4. 原实现提前降低阈值，第二符号被读成十七，末符号被读成十四。

两张表消费长度均为三字节，概率总和均为三十二，普通边界检查可以通过，生成的状态转移已经不同。正确表的状态七符号为二，状态一基值为零；新增测试分别核对这两项。

混合样本首个压缩块使用四流霍夫曼字面量，字面量恢复长度为五百零九，压缩区长度为四百三十七，权重表使用五十七字节的 FSE 数据。其概率描述也经过二的幂边界。本次修正是该失败的候选根因；复验仍需统一时段确认。

## 已准备的修正与诊断

- 保留二的幂边界上的 FSE 阈值。
- 增加三字节概率表的独立状态断言。
- 对照失败时输出状态、预期和实际长度、首异位置及存在的两侧字节。
- 生产解压接口与错误结果形状保持现行约定。
