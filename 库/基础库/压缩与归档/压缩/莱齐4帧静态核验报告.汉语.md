# 莱齐4帧静态核验报告

日期：2026-10-08。此报告记录源码与测试候选，运行验收尚待统筹分配单队列窗口。

## 候选与合入状态

原候选为 `eb22afffd`，工作树为 `基础库-莱齐4完善`。本轮核对 `yybs` 与 `基础库-压缩` 的快速压缩模块提交历史，两树目前沿用 `ce738d3ce`，原候选仍在独立分支。本轮沿原候选补充测试与核验记录，产品入口及参数次序保持原候选定义。

压缩统筹树已另行补充对校验包的直接依赖；本树保持包描述与总集交由统筹修改。

## 逐项对应

| 项目 | 源码处理 | 测试候选 |
| --- | --- | --- |
| 帧头校验 | 描述区自FLG起，覆盖BD、可选内容长度与字典号；XXH32零种子的第八至十五位为HC | 校帧头损坏、有效HC下的非法FLG/BD |
| 块校验 | 对实际编码块字节计算XXH32，压缩与存储块走同一核验分支 | 存储块损坏、压缩块校验组合、零长存储块仍含块校验 |
| 内容校验 | 仅核对当前帧实际解码输出 | 内容摘要损坏、四种校验组合 |
| 字典号 | 可选字段按无符号32位读取，与调用者给出的编号比较 | 正确与错误编号、普通入口处理带编号帧、零与4294967295 |
| 内容长度 | 八字节小端，先与总输出上限比较，帧结束再与真实长度核对 | 正确与错误内容长度、巨大上限的小输出 |
| 独立窗口 | 每个独立块从字典窗口重新开始 | 首块存储、次块回溯在独立帧中报损坏 |

| 块标 | 接受64、80、96、112，其余保留位须零 | 四种块标均解码压缩块；无效版本、保留位与块号报损坏 |
| 块限 | 编码块与解码块均受帧声明大小限制 | 64 KiB声明下的70000字节存储块及压缩块报损坏 |

| 截断 | 读取字段前核对源长度 | 校验帧每一截断长度均有测试候选 |

## 官方依据及后续实验

规则依据为 [LZ4帧格式1.6.4](https://github.com/lz4/lz4/blob/dev/doc/lz4_Frame_format.md) 与 [LZ4块格式](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md)。测试类别对照 [官方frametest.c](https://github.com/lz4/lz4/blob/dev/tests/frametest.c) 的块大小、块与内容校验、空存储块、原始字典及随机输入输出分段场景。这里按类别补写豫言测试，官方C测试尚待由统筹安排外部互解实验。

当前只完成源码静读、测试候选编写、格式化与差异检查。类型检查、单元测试、官方工具双向互解、原始字典互解、四种块大小的真实大块样本、百万变异与原生执行均待实验。

增量输入输出及分段调用场景留待既定ABI的后续实现与验收。当前完整字节串入口累计拼接已输出内容，性能测量及增量输出优化仍待执行；此报告保留其待验状态。

## 空块与历史复制修复候选

继续静读确认，先前路径对每个空存储块执行了累计输出拼接，并对满窗历史先截尾、拼接字典、再截尾。新候选在块校验之后直接续读空存储块，保留原输出及历史；满窗时直接取已有输出的窗口；首个实际块、首个实际帧及空拼接帧复用既有字节串。公开入口与参数次序保持不变。

多块实际输出拼接仍会复制累计前缀，保留后续性能工作。当前修改去掉上述确定可省的复制，耗时及分配量仍待测量。

新增独立向量直接固定普通帧头字节及零长终记，覆盖空帧和单字节存储帧；它们按格式常量手工构造，来源类别为规范独立向量，官方工具实际互解仍待实验。最大距离65535的手工块覆盖长字典与70000字节已有历史，并在两个空存储块之后继续回溯；空帧夹在普通拼接帧前后也有回归候选。
