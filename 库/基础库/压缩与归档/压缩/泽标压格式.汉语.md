# 泽标压

`泽标压。豫` 实现 Zstandard 帧格式，依据官方[压缩格式 0.4.5](https://github.com/facebook/zstd/blob/dev/doc/zstd_compression_format.md)。所有编解码在豫言客体内完成。

## 调用

- `泽标压压缩 输入 级别`：级别取一至三。
- `泽标压解压 输入 输出上限`：解码一个或多个帧。
- `泽标压字典解压 输入 字典 输出上限`：字典为原始内容或标准训练字典。

结果为整数状态与字节串。零表示成功，一表示输出或实现缓冲上限，二表示输入损坏或字典不匹配，三表示压缩级别超出一至三。错误结果返回空字节串。

输出缓冲按需增长，默认初始容量至多 1 KiB。调用者以字节为单位指定输出上限。

## 帧与解码

帧描述符决定窗口、字典标识、内容长度与校验字段；支持拼接帧和可跳过帧。解码验证保留位、区段边界、块大小、内容长度和可选内容校验。校验取零种子 XXH64 的低三十二位。

原始块直接复制，游程块填充重复字节，压缩块解码字面量与序列。字面量支持原始、游程、带霍夫曼表和复用霍夫曼表四种模式；霍夫曼权重支持直接和有限状态熵编码，数据支持单流及四流。序列支持预定义、单符号、有限状态熵编码及复用表四种模式，按规范维护三个近期距离。序列匹配按字节向前复制，允许源目标重叠。

标准训练字典读取字典标识、霍夫曼表、距离表、匹配长度表、字面长度表、近期距离与字典内容。帧提供非零字典标识时与传入字典核对。

## 压缩

压缩器优先检测周期，随后用散列链寻找匹配。一、二、三级分别探查一、八、六十四个候选，周期搜索长度分别为三十二、一百二十八、五百一十二字节。每个块最多生成一条序列，字面量保留匹配前缀与尾部；序列使用三个单符号熵表。单字节游程写成游程块，缺少有利匹配时写成原始块。输出采用单段帧、显式内容长度和至多 128 KiB 的块。

## 验证

`泽标压。测试。豫` 包含空帧、游程块、单序列块、多块、拼接帧、输出限额、逐前缀截断与官方 XXH64 空串向量。测试写出 `yy泽标自压1.zst` 至 `yy泽标自压3.zst` 和对应原样，供系统 `zstd -d` 双向对照。若准备了 `yy泽标参考1.zst` 至 `yy泽标参考3.zst`，测试读取并核对其内容。

默认 FSE 表与直接霍夫曼表有独立标准向量；另收录[官方解码勘误](https://github.com/facebook/zstd/blob/dev/doc/decompressor_errata.md)的空压缩块、首块游程与小熵表三个帧。测试生成六十四份训练样本，供系统工具训练字典后对照。`泽标压模糊。豫` 默认实际调用一百万次，按固定种子执行十类变异；小规模诊断可在仓外产物 `yy泽标模糊次数` 中指定次数。外层负责监督超时、进程陷阱及驻留内存。模糊程序仅在全部调用结束后报告实际次数和状态计数。
