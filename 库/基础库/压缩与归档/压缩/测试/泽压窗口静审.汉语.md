# 泽压库声明窗口静审

当前一次与增量包装验 CM 为 8、CINFO 至多 7、FCHECK 和输出阿德勒。解码正文采用 32768 字节历史；封装状态没有传入 CINFO 对应的逐距离上限。

[RFC 1950 第 2.2 节](https://www.rfc-editor.org/rfc/rfc1950) 定义 CINFO 为 LZ77 窗口的二进制对数减八，对应 256 至 32768，并规定 CINFO 超过 7 非法。第 2.3 节要求解码器验 CMF、FLG 和 ADLER32。逐次距离超过声明窗口的拒绝行为还需对照参照配置，规范没有在该节单列这项距离检查的 MUST。

本轮读取的 zlib `develop` [inflate.c](https://github.com/madler/zlib/blob/develop/inflate.c) 设置 `dmax = 1U << len`，距离超过 `dmax` 的判定受 `INFLATE_STRICT` 条件控制；[inffast.c](https://github.com/madler/zlib/blob/develop/inffast.c) 的快速路径采用同一条件。默认源码与严格配置有行为差异，具体系统构件的编译配置及结果留待运行核验。本轮据此保留现有距离行为，增加材料供参照比较，公开 ABI 保持。

## 独立材料

`泽压窗口。测试。豫` 覆盖 CINFO 0 至 7 的固定 `hello` 向量，以及 CINFO 8 的头错误。还加入 CINFO 0、历史 257 字节、距离恰好 256 的合法边界，一次与逐字节流式都比对固定预期输出。

`泽压窗口向量。豫` 的历史字节为 0 至 255 后接一个零；后续固定码输出长度三，分别回看 256 或 257。合法距离 256 输出历史后接 1、2、3，阿德勒按原字节独立求和为 `AC227F87`；距离 257 输出历史后接 0、1、2，求和为 `AC1C7F84`。两者均声明 256 字节窗口。

`泽压窗口实验。脚本。豫` 为显式实验入口，默认显示用法。参数 `导出` 保存 `yy泽压超声明窗口.bin` 和 `yy泽压超声明窗口预期.bin`，观察本实现一次与流式状态；超窗材料没有预置接受或拒绝断言，系统默认及严格参照留待队列运行。它与自动短测试候选分开。

## 全量候选补充

保留全量工具原编号 0 至 18，补编号 19「解压泽压库前缀」，每入口百万主测安排总数更新为二千万。两个前缀入口在成功时验消费长度介于零与输入长度之间；基线额外尾随一字节，前缀成功且消费恰为原种子长度，同输入的完整入口返回 2。独立测试包的父登记使用逻辑名「收缩全量测试」，由根聚合。
