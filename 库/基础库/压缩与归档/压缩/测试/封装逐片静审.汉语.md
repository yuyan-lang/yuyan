# 封装逐片边界候选与静审

新短测试位于 `测试/封装逐片边界。测试。豫`，采用已有增量及流式入口，结束结果按 0 成功、1 超限、2 损坏、3 未支持或缺字典核对。错字典、CRC、ISIZE 与 FHCRC 不符均为 2。内部推进状态只用于驱动暂停后继续读取。

## 独立预期与覆盖

泽压库固定向量 `789ccb48cdc9c90700062c0215` 与吉压固定向量 `1f8b0800000000000003cb48cdc9c9070086a6103605000000` 的预期均为固定字节 `hello`。输出逐字节比较；所有输入切点分别配一与三字节输出块，以空输入恢复暂停。

吉压可选头按 [RFC 1952](https://www.rfc-editor.org/rfc/rfc1952) 构造 FEXTRA、FNAME、FCOMMENT、FHCRC 共存的头，以及零长度扩展和空名称／注释的头。FHCRC 由既有一次吉压校验参考实现生成，正文 CRC32 与 ISIZE 保留固定常量。枚举头字段切点、头校验损坏、每个头部截断及尾部少一至八字节；加入 CRC32、ISIZE 和泽压库阿德勒损坏向量。

双成员由带可选头成员与普通成员串联，预期 `hellohello`。累计限额十成功，九产生前九字节并以 1 结束。吉压与泽压库各加独立尾随字节，以 2 结束。FDICT 使用原有独立字典回溯向量，分别核对正确字典、错误字典和缺字典。

现有流式消费者逐字节追加并立即读取，覆盖普通泽压库、吉压、可选头、多成员、CRC 损坏和字典三种身份结果。消费者可先读到正文，结束状态用于确认包装校验。

## 暂停交接静审

原始解码器在输出块用尽时保留位游标、回溯窗口和复制余量。封装层每次只对该调用实际返回的新输出块续算 CRC32、阿德勒及成员长度。原始流完成后，尾部移交到封装输入余片，再用空输入解析头尾；这一步返回空输出，正文校验不会重复累计。多成员创建新原始解码器时，总限额取最大值减累计输出，同时复位成员校验及长度。

本轮未确认需要修改的实现缺陷。上述是源码静审结论与待执行候选，逐文件格式化与差异检查完成；类型、实际暂停行为、固定向量及系统互解留待根队列核验，未登记甲乙达标。
