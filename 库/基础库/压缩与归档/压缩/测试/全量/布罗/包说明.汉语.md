# 布罗全量测试

本包挂在「压缩与归档基础库」，依赖「压缩」「基础库测试设施」「密码」与标准库。父包登记由聚合任务集中完成，生产压缩包保留原依赖。

`性能。豫` 接受压缩文件、原文件两个路径，计时外读取，两轮预热、九轮测量取解码中位纳秒，最后输出与原文逐字校验。此入口已在 Node 与同客体苹果臂六十四原生执行通过，当前并发测量及资源采样见《布罗回拷性能实施记录》。

`布罗百万变异。豫` 沿用基础库验证的批模糊五参数协议：`批模糊 种子路径 起点 次数 进度路径`；单参数模式重放指定样本。内部调用现有 `执行变异批次`，每次解码一次，核查状态、输出上限与失败时空输出。合法拒绝输入及解压量超限映射到设施状态二，性质失败返回三。设施在每次操作前写入准确进度编号；父工具 `yy基础库验证` 使用既有 `限时隔离运行向量` 处理陷阱、非零退出、强制超时与失败重放。

正式百万验收选八个压缩种子，每种十二万五千次，总量一百万；每批一万次，最后批五千次。执行命令使用现有「基础库验证」的 `批模糊 目标程序 语料目录 样本路径 每种次数 批量 毫秒`。百万工具源码已经迁入本目录；旧十类自定义变异矩阵保留为 `旧变异矩阵。豫`，正式隔离路径使用设施的四类变异。

语料目录取固定版本根下的 `压缩种子/`，其中只放下述八个 `.compressed` 文件。仓外本机目录已据固定清单复制这些文件；pit-mac 准备同样目录后由队列执行。每批进度与失败样本使用执行树的临时路径。

`官方重放。豫` 受固定版本语料根路径，核验 LICENSE 与八组原/压文件的 SHA256，逐文件解压、核对输出长度，再逐字节对照原文件。清单内的文件名及十六进制摘要均是外部来源数据。输出上限取对应原文件实长。所有原/压 SHA256 明写在此源码的「语料清单」。

固定来源为 [Google Brotli v1.2.0](https://github.com/google/brotli/tree/028fb5a23661f123017c060daa546b55cf4bde29)，提交 `028fb5a23661f123017c060daa546b55cf4bde29`。仓外输入目录为 `~/repos/yuyan-worktrees/豫言数据/布罗压/1.2.0`。源码归档 SHA256 为 `0afe09a53c8bad9861c8dd1fc1284308d54f19d2979ba3541cfdcc9b05fe360f`；[官方补充语料构件](https://github.com/google/brotli/releases/download/v1.2.0/testdata.txz) SHA256 为 `e8624d888f13067e7635353397cf42956bf4ca1382da67f9cec8d43e800deecb`。固定源码附 MIT 许可，LICENSE SHA256 为 `3d180008e36922a4e8daec11c34c7af264fed5962d07924aea928c38e8663c94`，仓外保留原文。

八组语料包括 `10x10y`、`backward65536`、`alice29.txt`、`asyoulik.txt`、`cp1251-utf16le`、`cp852-utf8`、`mapsdatazrh`、`monkey` 及各自 `.compressed`。这些是长距离、大文本、非 ASCII 与混合数据的候选覆盖，具体块类别数、树数与非平凡树覆盖待获准运行时记录。

完整包类型检查、官方重放与正式隔离入口构建通过。固定八对官方语料已在 Node 与同客体苹果臂六十四原生上逐字对照通过，证据见《布罗官方全文实施记录》。正式百万隔离及性能、裸机验收继续执行并另记结果。既有短向量保持原位置与命令。
