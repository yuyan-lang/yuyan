# 迅压全量测试

本包具编号结构复验、精计隔离目标、各口独批统筹、官方语料互解及文件效测五器，依标准库、压缩及基础库测试设施，属压缩与归档基础库。

`迅压官方互解` 受 `全部 参考工具 官方语料目录 输出前缀`，以十一官定合式语料各行 raw、framing2 双向逐字之核；`单样 参考工具 样本 输出前缀` 可增边例。参考器经既有子程之口召，二进制循文件之口传。

`迅压文件与性能` 受 `样本 路径 长度 类别`、`核对 两路径`、`文件 方式 输入 输出 限额` 或 `性能 方式 输入 限额`。零类重字，一类251字周期，二类定种随机；方式为原始压缩、原始解压、分帧压缩或分帧解压。效测用共器三预热、九轮中位，取实出长。

隔离父器逐批核器所记末序，须等本批终点；存 `.完成` 末序及 `.退出` 实子批码。全事存 `.成功`、`.拒绝`、`.总数` 及 `.状态`，状态为执行中、失败或完成。`记录退出 退出文件 程序 参数…` 以既有子程之口，书目标实退码，乃以同码退，可存百万父终态。

原始与分帧之新同客体原生隔验，各百万次已过，二父实退码皆零，各具百批末序及子批零码。原始成482206、常拒517794；分帧成1363、常拒998637。999999号同客体双端复验分类同。旧诺节百万实计保留，旧父柄终退码之缺别列；详见《迅压百万验收记录.汉语.md》。

`迅压隔离统筹` 受 `隔离客体 原始或分帧 种子路径 结果前缀 精确次数`。一批至多万次，以既有器限时行隔离子程；父器读成数与常拒数，核其和如本批数，乃计此口总数。败则存今序之变入。子程之数别存进度径 `.成功`、`.拒绝`，终数书 `.总数`。原始与分帧别起，各以百万为目标。

候选树始于 `7b5187295`，合列须先具已授之测试设施。二器各导直依之包，生产压缩之依赖如故。

批器受回调零、二而续：零为成，二为常拒坏入。未知解状、出逾界、坏出非空还三；逐字比较及 CRC 预期断言败则发异常。编号复验之基线召次别记，一项两解原块；百万之数唯计百万循环。

`迅压百万变异核验` 受 `百万` 或 `重放 编号`。百万模式每轮两解原块，至少两解分帧，实召之数各记之；复算 CRC 合帧与受控坏 CRC 帧，另计帧数。其源尚未行验。

结构序零至四验长直写之界，五验2047字距之一字节复制，六验65535字距之二字节复制，七至九验65537字距之四字节复制。各验合块与末字之截，出限依实宣长。十号独造16777216长之三字节附加量最大直写及长距复制，唯全量复验行之。

`迅压隔离核验` 用既有 `执行变异批次` 之法。命令为 `原始或分帧 样本路径`，或 `原始或分帧 批模糊 种路径 起点 次数 进度路径`。一批唯验一口，原始、分帧各百万次可成独立之数。父器记进度之变序，隔而复陷阱样。坏入还二，出逾限或坏出非空还三。构建、接器及行验之果待统筹队列。
