# 迅压全量测试

本包提供编号结构重放、精统计隔离目标、每入口独立批次统筹、官方语料互解与文件性能五个工具入口，依赖标准库、压缩与基础库测试设施，包含在压缩与归档基础库。

`迅压官方互解` 接受 `全部 参考工具 官方语料目录 输出前缀`，对十一份官方有效语料分别执行 raw 和 framing2 的双向逐字节核对；`单样 参考工具 样本 输出前缀` 用于追加边界样本。参考工具通过现有子进程接口调用，二进制数据走文件接口。

`迅压文件与性能` 接受 `样本 路径 长度 类别`、`核对 两路径`、`文件 方式 输入 输出 限额` 或 `性能 方式 输入 限额`。类别 0 为重复字节、1 为 251 字节周期、2 为固定种子随机；方式为原始压缩、原始解压、分帧压缩或分帧解压。性能工具采用共用设施的两次预热、九轮中位，并读取实际输出长度。

`迅压隔离统筹` 接受 `隔离客体 原始或分帧 种子路径 结果前缀 精确次数`。每批至多 10000 次，通过既有设施启动限时隔离子程序；父程序读取成功和正常拒绝数，核对其和等于本批次数，再计入该入口总数。失败保存当前编号对应的变异输入。子程序的统计分别保存在进度路径的 `.成功`、`.拒绝` 文件，最终完成数写 `.总数`。原始与分帧分开启动，各自目标一百万。

候选工作树起点为 `7b5187295`，合并队列须先包含已提供的基础库测试设施实现。两工具各自导入直接依赖，生产压缩包保持自身依赖。

批设施接受回调 0 和 2 后继续：0 表示成功，2 表示正常拒绝输入。未知解码状态、超过限额及错误时非空输出返回 3；逐字节比较和 CRC 预期断言失败直接触发异常。编号重放的基线调用单独记录，每项两次原始解码，百万计数仅覆盖百万循环。

`迅压百万变异核验` 接受 `百万` 或 `重放 编号`。百万模式每轮调用两次原始解码、至少两次分帧解码，并按实际调用分别输出计数；重算 CRC 的成功结构帧和受控坏 CRC 帧另计入分帧次数。源码尚未运行。

结构编号 0 至 4 覆盖长直写长度分界，5 覆盖 2047 字节距离的一字节复制，6 覆盖 65535 字节距离的二字节复制，7 至 9 覆盖 65537 字节距离的四字节复制。每项同时核对合法块和末字节截断，限额依真实声明长度设置。编号 10 单独构造长度 16777216 的三字节附加量最大直写及长距复制，仅在全量重放运行。

`迅压隔离核验` 使用现有设施的 `执行变异批次` 协议。命令格式为 `原始或分帧 样本路径`，或 `原始或分帧 批模糊 种路径 起点 次数 进度路径`。一次批次只访问一个入口，原始与分帧各自运行一百万次可形成独立计数。父设施按进度记录变异编号并隔离重放陷阱样本。输入错误返回 2，结果超过限额或错误输出非空返回 3。构建、设施接入和执行结果待统一队列。
