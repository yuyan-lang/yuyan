# 收缩全量测试

纯豫言之手行全量候选器。构建入口为 `变异`，出器宜名 `yy收缩全量.wasm`。父包「压缩与归档基础库」由根聚登。径依标准库、压缩、基础库测试设施。

## 入口与计数

序零至二为原始、泽压库、吉压一次解压；三为原始前缀；四五为原始及泽压带典解压；六至八为三式流解；九十为原始及泽压带典流解；十一至十三为三式一次压缩；十四至十六为三式流压；十七十八为原始及泽压带典流压。

十九为泽压前缀解压，旧序零至十八恒存。前缀成则核其耗长介于零与入长；另基线附一尾随字，前缀成而恰耗种长，全解同文则还二。基线与参照召数别计。

`全量 1000000 yy收缩变异` 使各入口各受百万主测变异，总二千万。每批至多万次，各口别计，诸口次行。每批另召主口一次以验合法基线，出与定 `hello` 逐字比；解码诸口另以保留码、验不符或典不符之例验还二及空果；编码诸口每变异另以解码术回验。基线及参照召数别计。

共用设施于召术前录总序。此器分录生产状零、一、二、三之数、主测变异召数及出字节总长；父程核末序、实召数及四状之和，相符乃积批数。回调还零为核验过，超限、坏流、乏典各依法验，成功别录。原始与吉压许零一二，默认泽压许乏典三，编码须零。完整误果须空，流式先读之前缀别验总长，终误之尾须空。

## 定种与复行

十四定种含定码、多块、保留码、十六首坏码、泽压、FDICT、吉压、双成员、全可选首、截尾、空入、原始典回溯及 zlib 官方 `pull 17` 变码块。种号与总序授 `变异字节向量` 以定成其文。百万序计召数，独异文之数待量；种与序同，字节可复成。

`入口 7 1000000 yy泽压变异` 唯调第七口。`重放 7 6 120003 yy重放` 复第七口、第六种、总序一二零零零三，原字藏于 `yy重放输入`。流之切点由序与入长定，压级取序模十。败则父录口、种、序，隔离复一例；基线败者录变异未召，归其口基线。

实用签名为 `执行变异批次(字节串, 起点, 次数, 进度路径, 字节串→整数)→整数` 及 `限时隔离运行向量(程序, 字符串列, 毫秒)→整数`。批与复行限三十万毫秒，百二十四为逾时止而收其退果。出限一六七七七二一六字节。RSS、峰值内存及异分配之判，待设施有资源接口乃验；常退码验其控制流，资源峰值待后量而定。

## 候选之状

此器以完备配套链构成，二十口各百次隔离变异及精计皆过。诸口各百万续验，单例复行及资源峰值续量。显命全量乃行，默认唯示用法。

## 全文互解

入口 `互解` 有 `造样 样本 长度 输出`、`比较 甲 乙`、`编码 格式 级别 输入 输出 片长`、`解码 格式 输入 输出 片长`。带典则用 `字典编码 格式 级别 输入 输出 片长 字典`、`字典解码 格式 输入 输出 片长 字典`。式零原始，一泽压，二吉压；片长须正。样零以七字为周，样一以二〇二六一〇〇八为种而生伪随机字。

压解皆逐片附入，即读所出，终合未读之尾；状零乃存文。比较逐字验全文。解压出限一吉字节。可成系统参照互解之材，同一客体可供节点与原生对照。

`原始提取 单成员吉压 输入原始文件` 依吉压首长取其DEFLATE之材。`原始封装 原始文件 正文 吉压输出` 以正文CRC与长加吉压首尾，授系统gzip而验全文。二术合为原始式之系统参照桥。

## 计数汇总与中位采样

入口「计数汇总」具「全量 次数 前缀」及「入口 编号 次数 前缀」二令，逐批验末序、实调用数、四态计数之和，乃出入口、字段、值三列。字段零至三记生产之态，四记变异主测次数，五记成功出文字节。全量汇总俟二十入口俱终；单入口汇总验已终者。毁计数之反例退一。

「互解」之「采样 格式 级别 输入 片长 次数」，读正文而先验一轮，复用基础库测试设施热三批、量五批，报压解之中位纳秒。每批调用数从参数；所报正文字节总数为一批正文长乘次数。每算法实调用为八倍参数加一。时内量构造、附片、读取、合文与终；读文件及末次全文核对在时外。负载中之量作为观测，性能门槛及目标进程资源采样另验。

## 资源观察

手动入口「资源观察」复用五参资源隔离。「采样 目标 格式 级 输入 片长 次数 时限毫秒 常驻上限字节」启冻结互解采样目标；「运行 目标 时限毫秒 常驻上限字节」启无参目标。二十毫秒一采，分报终因、实退码、采最大与系统峰。常终零退乃报成；逾限、逾时及资源未得皆败。正限验采样，零限惟察。Node 用完整资源宿主及 --experimental-ffi；采最大与系统峰分录。

二十入口各百万主测，俱常终零退；纯豫汇总验二千批及百二十项而成。详见《真实流百万与资源记录》。异输入实数、百万目标资源峰及性能门槛另验。

「批次 目标 编号 种号 起点 次数 前缀 时限 上限」直隔变异客体之子批。「全量 目标 次数 前缀 时限 上限」次行二十入口，每批至多万次；种号为批序除十四之余，同既有百万编排。逐批报资源；目标存进度及六计数，别以计数汇总器精验。直察目标与察其子孙树各录。
