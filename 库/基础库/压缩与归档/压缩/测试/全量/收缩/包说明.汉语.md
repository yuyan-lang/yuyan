# 收缩全量测试

纯豫言的手动全量候选工具。构建入口为 `变异`，建议输出 `yy收缩全量.wasm`。父包「压缩与归档基础库」登记由根聚合。本包直接依赖标准库、压缩与基础库测试设施。

## 入口与调用计数

| 编号 | 主测入口 |
| --- | --- |
| 0 | 解压原始收缩 |
| 1 | 解压泽压库 |
| 2 | 解压吉压 |
| 3 | 解压原始收缩前缀 |
| 4 | 解压原始收缩带字典 |
| 5 | 解压泽压库带字典 |
| 6、7、8 | 原始／泽压库／吉压流式解压 |
| 9、10 | 原始／泽压库带字典流式解压 |
| 11、12、13 | 原始／泽压库／吉压一次压缩 |
| 14、15、16 | 原始／泽压库／吉压流式压缩 |
| 17、18 | 原始／泽压库带字典流式压缩 |
| 19 | 解压泽压库前缀 |

`全量 1000000 yy收缩变异` 为每个入口安排一百万次主测变异调用，共二千万次。每批至多一万次，每个入口独立累计，二十个入口依次执行。每批额外调用一次主测入口验证合法基线，并比对固定 `hello` 输出；解码类另用保留码、错校验或错字典基线断言状态 2 与空结果，编码类每个变异结果额外由解码器逐字节回验。这些基线与参照调用另计。

基础库设施在调用前记录全局变异序号；本工具记录生产状态 0／1／2／3 的独立计数、主测变异调用计数及输出字节数。父程序核对末序、实际调用数与四类状态总和，全部相符后累计批次数。设施回调返回 0 表示本次核验通过；生产超限、损坏和缺字典按允许规则核对，成功状态保留独立计数。原始与吉压解码允许 0／1／2，默认泽压库解码允许缺字典 3；编码入口要求 0。完整错误结果要求空输出，流式提前读出的前缀另验总长度，结束错误尾部要求为空。

## 固定种与单例重放

前缀入口成功时核对消费长度介于零和输入长度之间。额外基线添加一个尾随字节，前缀解码成功并恰好消费原种子长度，同一数据的完整解码返回 2。基线与参照调用另计，原编号零至十八保持，泽压前缀新增为十九。

十四种固定结构种包含独立固定码、多块串联、保留码、16 首符号坏码、普通泽压库、FDICT、吉压、双成员、带全部可选字段的吉压、截断尾、空输入、原始字典回溯，以及 zlib 官方 `pull 17` 动态块。种号与全局序号通过 `变异字节向量` 确定性生成输入。百万编号用于调用计数，唯一输入数量留待统计；同一种子与编号总能重建相同字节。

`入口 7 1000000 yy泽压变异` 单独调度编号 7。`重放 7 6 120003 yy重放` 重建入口 7、种号 6、序号 120003，并保存 `yy重放输入` 的原始字节。流式切点由序号和输入长度确定，编码级别为序号模十。父程序遇失败时记录入口／种号／序号，隔离重放单例。基线失败记录为尚未调用变异，归于该入口基线。

复用的真实签名为 `执行变异批次(字节串, 起点, 次数, 进度路径, 字节串→整数)→整数` 与 `限时隔离运行向量(程序, 字符串列, 毫秒)→整数`。每批及重放时限为三十万毫秒，124 表示超时终止并收取后的结果。输出总限额为 16777216 字节。RSS、峰值内存与异常分配判定留待已有设施增加资源接口后核验；正常退码属于控制流核验，资源峰值结论由后续资源测量提供。

## 候选状态

工具已用完整配套链构建，二十个入口各一百次隔离变异与精确计数通过。各入口百万变异正在核验；单例重放与资源峰值测量继续进行。工具采用显式全量命令，默认只显示用法。

## 全文互解

入口 `互解` 提供 `造样 样本 长度 输出`、`比较 甲 乙`、`编码 格式 级别 输入 输出 片长`、`解码 格式 输入 输出 片长`。带字典命令为 `字典编码 格式 级别 输入 输出 片长 字典` 与 `字典解码 格式 输入 输出 片长 字典`。格式零为原始、一为泽压、二为吉压；片长取正整数。样本零为七字节周期，样本一为固定种二〇二六一〇〇八的伪随机字节。

编码与解码逐片追加并立即读取输出，结束后合并未读尾部；状态零时保存文件。比较命令逐字节核对全文。解码输出限额为一吉字节。此入口可以生成系统参考互解素材，并将同一客体用于节点及原生对照。

`原始提取 单成员吉压 输入原始文件` 根据吉压头长取出原始DEFLATE素材。`原始封装 原始文件 正文 吉压输出` 使用正文CRC与长度给原始素材加吉压头尾，可交给系统gzip全文核对。这两项组成原始格式的系统参考桥。

## 计数汇总与中位采样

入口 `计数汇总` 提供 `全量 次数 前缀` 与 `入口 编号 次数 前缀`，逐批核对末序、实际调用数、四种状态计数之和，再输出入口、字段、值三列。字段零至三为生产状态计数，四为变异主测调用数，五为成功输出字节数。全量汇总用于二十个入口全部结束后的记录；单入口汇总用于已结束的入口。计数破坏的负控退出一。

`互解` 的 `采样 格式 级别 输入 片长 次数` 在正文读入后执行单次正确性核对，再复用基础库测试设施热身三批、计量五批，报告编码与解码中位纳秒。每批调用次数为参数次数，打印的正文字节总数为每批正文长度乘次数；每种算法实际调用八倍参数次数加一次。计时包含构造、追加、读取、拼接与结束，文件读取及最终全文核对置于计时之外。负载中的测量值作为观测记录，性能门槛与目标进程资源采样继续独立核验。

## 资源观察

手动入口 `资源观察` 复用现有五参数资源隔离设施。`采样 目标 格式 级 输入 片长 次数 时限毫秒 常驻上限字节` 启动冻结的互解采样目标；`运行 目标 时限毫秒 常驻上限字节` 启动无参数目标。采样间隔二十毫秒，分别打印结束原因、真实退出码、采样最大字节与操作系统峰值。正常结束并零退出时打印成功标志；超限、超时与资源未知作为失败。正数常驻门槛用于采样核验，零门槛用于观测。Node 使用完整资源宿主与 `--experimental-ffi`；采样最大值与系统峰值分别报告。

二十个入口各一百万主测调用已自然零退出，纯豫全量计数工具核对二千个批次与一百二十项汇总通过。完整计数记录见《真实流百万与资源记录》。唯一变异输入数量、百万目标资源峰值和性能门槛继续独立核验。

`批次 目标 编号 种号 起点 次数 前缀 时限 上限` 直接隔离变异客体的子批。`全量 目标 次数 前缀 时限 上限` 依次编排二十入口，每批至多一万次，种号为批次序号模十四，与既有百万编排相同。资源结果逐批打印；进度和六项计数仍由变异目标保存，独立计数汇总工具负责最终精核。直接目标采样独立于子孙进程树观测。
