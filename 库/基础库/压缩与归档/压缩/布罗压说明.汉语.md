# 布罗压

`布罗压解压 输入 上限` 返回状态与字节串。状态零表示成功，一表示解压量超限，二表示数据损坏。失败时输出为空。

流头按 RFC 7932 解析窗口编码，支持空末块、元数据、未压缩与压缩元块。压缩解码包含简单及复杂霍夫曼树、连续重复码长、三类块切换、四种字面上下文、上下文映射及逆移前、距离环与重叠回拷。输出历史与距离环跨元块共用。填充位、截断与输出长度经过检查。

静态字典完整保存 122784 字节及全部 121 种变换。`布罗字典词 词长 词索引 变换索引` 返回状态与字节串；`布罗字典词数 词长` 返回词数。数据来自 Google Brotli 官方仓库，许可见 `布罗字典许可.txt`。

验证：发布工具链联合类型检查与构建通过；十组 Google Brotli 1.2.0 编码器质量十一、窗口二十二的真实向量解压结果一致，覆盖字面量、字典词、重复文本、中文与 JSON；所有向量的每一个截断前缀均返回失败，非空输出的解压量上限测试通过。RFC 7932 第十一节原块样本另验元数据、非法窗口与尾填充。

后续验收：官方完整测试集、模糊测试、性能测量与裸机验证。乙级验收在这些事项完成后记录。

依据：[RFC 7932](https://www.rfc-editor.org/rfc/rfc7932.html)。
