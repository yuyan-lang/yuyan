# 布罗压百万变异验收计划

## 当前记录

正式入口已迁入 `测试/全量/布罗/布罗百万变异。豫`，复用现有基础库测试设施的批模糊、限时隔离与失败重放。原十类矩阵迁为同目录 `旧变异矩阵。豫`，作为追加覆盖源码保留。八对官方全文在 Node 与同客体苹果臂六十四原生上均通过 SHA256 核验及逐字节比较，见《布罗官方全文实施记录》。正式设施烟测八种子各一百次退出零；百万实际执行已启动，终态另记。具体协议、来源与清单见该目录包说明及 `官方重放。豫`。

## 正式隔离方案

解码入口为 `布罗压解压`，输出上限 65536 字节。种子目录只放八个固定官方 `.compressed` 文件，每种编号区间 `[0,125000)`，合计一百万次实际解码调用。每批一千、外层硬期限六十万毫秒；每种一百二十五个批，共一千批。烟测八百次单独记录。每批父进度初始化为起序减一，成功时精确末序须为起序加数量减一，各种最后末序须为 124999。失败时保留当前范围内编号的确定样本；越界进度回退起序，登记退出码与重放编号。

正式父命令为 `node yy布罗25a链/yy稳定节点宿主/宿主.cjs yy布罗隔离父.wasm 批模糊 ./yy布罗百万变异.wasm yy布罗官方语料/压缩种子 yy布罗百万失败.bin 125000 1000 600000`，完整日志位于 pit-mac 布罗独树 `yy布罗正式百万.log`。次数以成功批实际数量之和计算，须为一百万；终态、异常与超时由隔离父及实际退出结果记录。

该原客体轮已实际完成一千个成功批、每种一百二十五批，共一百万次，外层退出零，末序 124999，见《布罗原源百万实施记录》。优化后最终源码两后端的正式百万继续分列记录。

## 旧矩阵源码准备记录

以下保留初始自定义矩阵的编号、参数与待执行记录，正式验收采用上一节现有设施协议。

解码入口为 `布罗压解压`。验收编号区间为 `[0,1000000)`，共一百万次变异调用。编号决定种子、变异及输出上限，可逐编号重放。计数表示实际调用数，同一字节输入可能重复出现。

## 工具与结果

构建产物名为 `yy布罗百万变异.wasm`。工具参数依次为起始编号、数量、单次返回耗时上限毫秒。无参数时打印用法。建议先检查编号零至九百九十九，再顺序执行一百个分片，每片一万次，起始编号依次为零、一万至九十九万。冒烟调用另记，百万验收区间按完整分片计数。

工具每一百二十八次记录检查点，分片完成后输出实际调用数量、成功、超限与损坏次数及耗时。合格条件为全部分片退出零、完成数量之和恰为一百万、三类状态计数之和等于调用数量、失败报告零条。保留工具链版本、源码提交、运行后端、命令、完整输出、进程退出码及外层限时记录。发生进程陷阱时，用最后检查点所在区间逐编号重放。

每次检查状态码在零至二之间，输出长度不大于传入上限，失败时输出为空；字符串异常使工具报失败。调用返回后核验单次耗时。外层执行器为每个分片设置硬期限，超时终止并保存检查点；随后以单编号进程重放定位。标准库现有进程接口提供启动与收取，强制终止由外层执行器负责。只有外层监督记录齐备，才登记无崩溃与无超时。

初次执行建议单次返回阈值五千毫秒，分片硬期限根据冒烟实测确定并写入报告。阈值用于发现异常耗时，正常解码性能另行测量。

## 变异矩阵

已有十个种子来自 Google Brotli 1.2.0 官方编码器，参数质量十一、窗口二十二，内容包括空流、短字面量、字典词、英文句、三类重复、中文与 JSON。种子模块为 `测试/布罗向量。豫`，既有向量验证记录见 `布罗压说明.汉语.md`。

编号末位选十个种子，十位选十类变异，百位及其以上轮换五个输出上限。每个种子与每类变异各获一万次调用，总计一百万次。

| 方式 | 操作 | 主要覆盖 |
| --- | --- | --- |
| 零 | 单位翻转 | 窗口、块头、树与命令编码 |
| 一 | 单字节替换 | 字面量及长度、距离数据 |
| 二 | 截断到选定位置 | 各层输入耗尽 |
| 三 | 删除一字节 | 编码错位与缺失 |
| 四 | 插入一字节 | 编码错位 |
| 五 | 追加一至十六随机字节 | 流尾与填充 |
| 六 | 连续区间置零 | 零码、空树及重复长度 |
| 七 | 连续区间置二百五十五 | 高位字段及最大码 |
| 八 | 复制尾内片段追加 | 重复与额外数据 |
| 九 | 一至二百五十六随机字节 | 未知结构输入 |

输出上限轮换零、一、三十一、一千零二十四、六万五千五百三十六。随机混数使用确定的三十二位位运算；输入构造的截取范围均由当前种子长度限定。

## 真实向量补齐计划

依据 [Google Brotli 官方测试数据目录](https://github.com/google/brotli/tree/master/tests/testdata)，在获准执行时段获取固定提交的数据至仓外 `~/repos/yuyan-worktrees/豫言数据/布罗压/`，记录提交号、文件哈希与许可。官方压缩文件逐字节对照对应原文件；成功结果以原文件为准。

| 数据 | 验收目的 |
| --- | --- |
| `empty.compressed` 与 `.00` 至 `.18`，`x.compressed` 与其变体 | 空流与短流不同表示 |
| `10x10y`、`64x`、`quickfox`、`quickfox_repeated` | 短命令、字典与重复 |
| `backward65536`、`compressed_repeated`、`zeros`、`zerosukkanooa` | 长距离及长重复 |
| `alice29.txt`、`asyoulik.txt`、`lcet10.txt`、`plrabn12.txt` | 多树、块切换与大文本 |
| `cp1251-utf16le`、`cp852-utf8`、`ukkonooa` | 非 ASCII 上下文 |
| `random_org_10k.bin`、`mapsdatazrh`、`monkey` | 二进制与混合数据 |

另以官方编码器质量零至十一、窗口十至二十四生成同一真实输入的不同编码；重点记录跨元块历史、元数据与窗口边界。把新增压缩种子固定保存后，再扩充百万矩阵种子池并重跑全部编号区间。上述文件与质量/窗口矩阵当前待获取、待执行。
