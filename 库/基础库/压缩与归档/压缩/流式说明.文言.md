# 流入流出

式号零为原始收缩，一为泽压库，二为吉压。

`新建压缩流` 受式与级，`压缩流追加` 进编码，`压缩流读取` 取已成之块，`压缩流结束` 还其状与未读之尾。次联诸读与终出，即得全流。

`新建解压流` 受式与总出之限，`解压流追加` 进解析，`解压流读取` 取已出之文，`解压流结束` 验其完而还未读之出。解者存三万二千七百六十八字节之回溯窗，隔片存其析状。封装验渐积之校与吉压诸成员之界。

旧用唯附而终读者，终仍得全果。每附即读，可制调用者所积之出。

## 预设字典

`新建压缩流带字典(格式, 级别, 字典)` 与 `新建解压流带字典(格式, 最大输出, 字典)` 起原始收缩或泽压库之流。底层之口为 `新建增量收缩带字典`、`新建增量解收缩带字典` 及 `新建增量解封装带字典`。典尾至多三二七六八字节供回溯匹配；实出之长、限及验皆自新文计。

泽压库编码置 FDICT，以全典之共用阿德勒32大端录 DICTID。解者俟四字节尽至，验身乃入窗。泽压库流未置 FDICT 者，依空典析之。`解压泽压库带字典(输入, 最大输出, 字典)` 与 `解压原始收缩带字典(输入, 最大输出, 字典)` 为全入之口。

附口还「有」，录推进之果；终及全入之状为零成功、一超限、二坏、三未支持或乏典。DICTID与所供典不符则还二，需典而未供则还三。私进存暂停、终成及需典之状，流口据之续读。空典可明供，其身为阿德勒初值一。吉压带典构造，终时还三。

据 [RFC 1950](https://www.rfc-editor.org/rfc/rfc1950) 之FDICT、DICTID及出验，并依[RFC 1951](https://www.rfc-editor.org/rfc/rfc1951)定码造例`7820062c0215031300062c0215`：典与出皆hello，正文唯长五、距五与终码。此独立据规范所造之测试源码。
