# 莱齐4格式

`快速压缩`提供`莱齐块压缩`、`莱齐块解压`、`莱齐帧压缩`、`莱齐帧解压`。压缩函数接收字节串；解压函数另接收解压字节上限。结果是状态码与字节串，零为成功，一为超限，二为损坏或不支持的格式参数。

块解码支持字面量、长度扩展、16位距离与重叠复制。块编码以四字节哈希搜索通用匹配，保留末尾五个字面字节及末次匹配的十二字节间隔。块解码先检查长度、距离与结束边界，再按真实解码长度分配缓冲。上限只限制输出长度。

帧编码生成64 KiB独立压缩或存储块；帧解码支持压缩块、存储块、依赖块、内容长度、拼接帧及十六种可跳过帧。解码器使用共用校验库的XXH32实现，核对帧头、压缩或存储块、整个帧输出的校验和；声明内容长度与实际输出长度须相等。块大小依帧头限制为64 KiB、256 KiB、1 MiB或4 MiB，各帧重置块历史。

帧与拼接帧的累计输出使用按实际需求倍增的字节缓冲，扩容只复制已写区段，容量受输出上限约束。帧结束后将真实输出一次复制成字节串，内容校验使用这份结果；依赖块回溯窗口只取此前输出的末尾65535字节。单帧入口直接返回该帧结果。

`莱齐块字典解压 输入 上限 字典`使用字典的末尾65535字节作为回溯窗口。`莱齐帧字典解压 输入 上限 字典 字典号`核对帧头声明的字典号；编号由调用者约定。独立块每次从字典开始，依赖块沿用此前输出的窗口。原有`莱齐帧解压`入口处理普通帧，带字典编号的帧通过字典入口处理。

`莱齐块字典压缩 输入 字典`生成使用字典的块。`莱齐帧字典压缩 输入 字典 字典号`生成带字典编号的64 KiB独立块帧。字典号取零至4294967295。

后续版本事项：帧压缩可选校验参数、增量流接口及块内复制性能优化。

格式依据：[LZ4帧规范](https://github.com/lz4/lz4/blob/dev/doc/lz4_Frame_format.md)、[LZ4块规范](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md)。
