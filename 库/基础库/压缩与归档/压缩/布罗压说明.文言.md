# 布罗压

`布罗压解压 输入 上限` 还状态及字节串。零为成，一为越限，二为损。失则还空串。

据 RFC 7932 读窗之码，解空末块、附录、原块及压块。压块之解具简繁霍夫曼树、连复码长、三类块之易、四类字面上下文、映射及逆移前、距环及重叠回抄。旧字与距环跨块共之。验余位、缺帙及出量。

定典具十二万二千七百八十四字节及百二十一变换。`布罗字典词 词长 词索引 变换索引` 还态及字节；`布罗字典词数 词长` 还词数。数据出 Google Brotli 官库，许可见 `布罗字典许可.txt`。

发布诸器之合验、构成皆过；取 Google Brotli 1.2.0 以品十一、窗二十二所成十例，皆得原字，兼字面、典词、重复、汉字及 JSON。诸例逐截皆报失，非空出量之限皆验过。又取 RFC 7932 十一章原块，验附录、误窗及余位。

后验：官定全例、模糊之试、速量及裸机之验。诸验毕而录乙级。

所据：[RFC 7932](https://www.rfc-editor.org/rfc/rfc7932.html)。
