# 分词器

共用 BPE 分词库。提供千问正则预分词、字节词表、合并名次、添加词元、解码与流式解码。深度学习的 GGUF 装载器构造本库的分词器。

通过 `寻观「分词器」之书。` 导入。`分词` 返回词元号列表，`解码` 将词元号列表还原为文本。`新流式解码器` 与 `流式解码` 在完整 UTF-8 字符到齐时输出文本。

`由词表建分词器` 接收按词元号排列的文字、类型及合并对。`读取结森分词器` 接收 tokenizer.json 文本，读取 BPE 词表、字符串或二元组形式的合并表及添加词元，执行时采用千问预分词。`词元文字` 返回词表中的映射文字，`词元字节们` 返回原始字节列表。

`读取分词配置` 读取 tokenizer.json 的完整组件配置，返回「分词配置已读」或「分词配置有误」。`按配置分词(配置,文本,添加特殊词元)` 和 `按配置成对分词(配置,甲文本,乙文本,添加特殊词元)` 返回词元号列表与逐词元类型号列表组成的对。`按配置解码(配置,词元号列表,去掉特殊词元)` 返回文本。

规范化器包含 NFC、NFKC、NFD、NFKD、Lowercase、Strip、Prepend、Replace、Sequence。预分词器包含 ByteLevel、Split、Whitespace、WhitespaceSplit、Digits、Punctuation、Metaspace、Sequence。后处理器包含 TemplateProcessing 与 ByteLevel。解码器包含 ByteLevel、Metaspace、ByteFallback、Fuse、Strip、Replace、Sequence。BPE 支持续接前缀、词尾后缀、字节回退、未知词元融合及忽略合并的整词查找。添加词元记录规范化、单词边界、左右空白及特殊词元属性。

`读取刻词器(tiktoken词表文本,正则模式)` 构造排名词表分词器。`刻词分词(刻词器,文本)` 返回词元号，`刻词解码(刻词器,词元号列表)` 返回文本。词表的每行使用六十四进制字节与十进制名次。构造时登记全部可拆的合并对，执行时复用优先队列 BPE。

BPE 使用双向索引链与左偏堆，按合并名次及原始左位置选择候选，每次合并更新相邻两对。词长为 n 时，合并阶段耗时为 O(n log n)，空间为 O(n)。

配置模型包含WordPiece的最长词片匹配、WordLevel的整词查表与Unigram的评分最优路径。Unigram读取数组词表及评分，读取时缓存评分数组，执行时支持未知片段融合与字节回退。BertNormalizer支持控制字清理、汉字分隔、小写及去重音；StripAccents执行规范分解后去非间距标记；BertPreTokenizer按空白与标点分段。BertProcessing与RobertaProcessing生成单句和句对的特殊词元及类型号；WordPiece解码器连接词片并按配置清理空白。私有句片模块读取官方模型并执行其预编译规整表，Precompiled规范化器复用该表执行器。

配置截断按左右方向和LongestFirst、OnlyFirst、OnlySecond策略裁切正文，预留后处理特殊词元的长度。配置填充支持Fixed、单次编码的BatchLongest、左右方向和pad_to_multiple_of，返回补齐的词元号及类型号。

私有句片执行链读取SentencePiece一元、字对、整词与字符模型，保留词元号、类型与评分，执行官方预编规整表及用户词保护。共用解码链处理控制词元、未知表面、连续字节的UTF8替换解码及首空白标记。
