# 分词器

`按配置编码`、`按配置成对编码` 还主窗及stride溢出窗，具原UTF8字节之位、序号、特殊词及注意力之掩码。结构及区间之义见[编码规范](规范.文言.md)。

`读取GGUF分词配置(张量格式模型头)` 还分词配置读取结果，读gpt2字节BPE、llama句片BPE、bert词片与t5一元之模。词号、类、分、首尾特殊之词与解码之设，皆存于配置。配置以核心、结森诸件、原添词、规整添词、特殊词号及可有一元评分之态为六元；各配置明持其分。

`新配置流式解码器(元)` 建配置流解之态。`按配置流式解码(配置,状态,词元号,去特殊词元)` 还新增之文；字节BPE待完UTF8字齐乃出。`结束配置流式解码(配置,状态,去特殊词元)` 于生成终尽出未出之尾文，清其态；词片清理、多字替换可改前文者，终乃出文。原提示之`按配置分词`添特殊参数可为阳，已渲染聊天范本者为阴。

GGUF之白转换，循`add_space_prefix`、`escape_whitespaces`及`remove_extra_whitespaces`之元数据；词片小写循`do_lower_case`，一元规整行兼容合成；句片字对之正负单精度分，循数递减以定并之次。

共用 BPE 分词之库。具千问正则预分、字之词表、合并名次、添词、全解与流解之法。深度学习之 GGUF 载器构本库之器。

以 `寻观「分词器」之书。` 观之。`分词` 还词号之列，`解码` 以词号之列复为文。`新流式解码器` 与 `流式解码` 待 UTF-8 全字齐乃出文。

`由词表建分词器` 受按词号之文、类及并对。`读取结森分词器` 受 tokenizer.json 之文，读 BPE 词表、文式或二元式并表及所添之词，行则依千问预分。`词元文字` 还词表所映之文，`词元字节们` 还原字之列。

`读取分词配置` 读 tokenizer.json 诸件之设，还「分词配置已读」或「分词配置有误」。`按配置分词(配置,文本,添加特殊词元)`、`按配置成对分词(配置,甲文本,乙文本,添加特殊词元)`，还词号之列及逐词类号之列相合之对。`按配置解码(配置,词元号列表,去掉特殊词元)` 还文。

规整器具 NFC、NFKC、NFD、NFKD、Lowercase、Strip、Prepend、Replace、Sequence。预分具 ByteLevel、Split、Whitespace、WhitespaceSplit、Digits、Punctuation、Metaspace、Sequence。后处具 TemplateProcessing 与 ByteLevel。解码具 ByteLevel、Metaspace、ByteFallback、Fuse、Strip、Replace、Sequence。BPE具续接之首、词尾之后、字节回退、未知之融及整词径寻之法。添词录规整、词界、左右之白与特殊之性。

`读取刻词器(tiktoken词表文本,正则模式)` 构名次词表之器。`刻词分词(刻词器,文本)` 还词号，`刻词解码(刻词器,词元号列表)` 还文。表之每行，以六十四进字节及十进名次为之。构时登诸可析之并对，行时复用优先队列BPE。

BPE 用双向序链及左偏堆，以并次及原左位择候，既并则更邻二对。词长 n，则并词之时为 O(n log n)，所用之藏为 O(n)。

配置之模具WordPiece先长之词片匹配、WordLevel全词索表与Unigram评分择最优之径。Unigram读列式词表与评分，读时藏评分之列，行时融未知之片而具字节回退。BertNormalizer具控制字之清、汉字之分、小写及去音；StripAccents行规范分解而去非间距标记；BertPreTokenizer依白及标点分段。BertProcessing、RobertaProcessing生单句、句对之特殊词号与类号；WordPiece解码连词片而循设清白。私有句片之模读官本而行其预编规整表，Precompiled规整器复用其行表之法。

配置截词循左右之向与LongestFirst、OnlyFirst、OnlySecond之法，先留后处特殊词之额。配置补词具Fixed、单次编码之BatchLongest、左右之向及pad_to_multiple_of，还补齐之词号与类号。

私有句片之径读SentencePiece一元、字对、整词及字符之模，存词号、类与分，行官本预编规整表而护用户词。共解之径处控制词、未知表面、连字节之UTF8替换解码及首白之标。

后版之事：SentencePiece词元之模全类之义及denormalizer、批量补词与stride溢出之窗、全位映；实分词器之批量对验、性能及裸机之验，见实施记录。
