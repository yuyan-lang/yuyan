# 带坐标编码

`按配置编码(分词配置,字符串,添加特殊词元)` 与 `按配置成对编码(分词配置,甲字符串,乙字符串,添加特殊词元)` 返回 `编码结果`。

`文字坐标` 为 `(起点,终点)`，表示原始输入的UTF8字节半开区间。两段输入各自从零计数。规范化展开的多个字节可以指向同一个原字符区间；合成和重排的输出字节指向参与的原字符并集。添加词元的左右空白属性扩展其原文区间。

`编码窗口` 是六元组：词元号列、类型号列、文字坐标列、序列号列、特殊词元掩码列、注意力掩码列。序列号零表示甲输入，一表示乙输入，负一表示后处理特殊词元或填充。后处理特殊词元和填充的坐标是 `(0,0)`；其特殊掩码为阳。正文与特殊词元的注意力掩码为阳，填充为阴。

`编码结果` 是 `(主窗口,溢出窗口列)`。主窗口沿用配置的截断方向与正文预算，各溢出窗口依 `stride` 保留相邻窗口的重叠词元，并各自执行后处理和填充。成对输入的两列窗口作笛卡尔组合，首组作为主窗口。`stride` 小于被切序列的正文预算；预算为零且正文需切片时返回事故。

普通分词接口继续返回词元号和类型号组成的对。带坐标编码在需要原文定位或溢出窗口时调用。

后续版本事项：前缀规整坐标建立的长文本性能优化、任意自定义规范化器的官方偏移差分核对。
