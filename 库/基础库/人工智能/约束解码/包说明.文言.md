# 约束解码

版为 0.1.0。包属人工智能基础库，依标准库、结森工具、分词器、正则。

`编译有限文法` 以候选诸串为字节前树。`约束活态` 起其态，`约束步进` 受词元原字节，`允许词元掩码` 还真假之列，与词表同序。统一码之字可跨词元。`约束可结束` 察此前缀可终。空词元之掩码为阴；调用者以可终之态治终止词元。

`校验结森模式` 察 type、properties、required、items、enum、const、anyOf、oneOf、pattern、minimum、maximum；正则验函由调用者授。`编译有限结森模式` 受独用之 const、enum、boolean、null，还编成之树或明示其误。词表受字节串之列，可接分词器原字节。

`编译约束模式` 受结森模式与正则译函；`内置约束正则编译` 接统一码正则之态。`新建通用约束状态`、`通用约束步进`、`通用约束可结束`、`通用约束可继续` 操通用预测之态。故初态可存，以复核所还之文。

数值文法出六十四位整数字面、含点之十进表示及指数表示。浮数前缀以精确舍入单元与离散浮值之域相交，整数模式亦受值为整数之小数、指数表示。泛结森之数同用精确词法。const、enum 小数常量用精确往返表示；对象与数组中之常量，递归同其法。指数私核之独验得双端及逐字同出之证，调用者整合与新通用回归付 CI 验之。

`建字节词表前缀树` 受依模型词元之序排列之原字节串；`建分词器词表前缀树` 径受基础库分词器。`通用允许词元掩码` 遍历词表前树，同前缀者共其字节之行；`通用允许字节词元掩码` 以字节串之列为便门。呼者以可终之态置终止词元；限额与停止串终生成，则复核所还之文。

`编译约束文法` 读 GBNF，以 root 为首则；`编译约束文法以规则` 指定首则之名。文法含定文、统一码字类、连接、选择、递归、可选与计数重复。`编译正则约束` 建全串正则文法。模式搜索之简首尾锚，各定串之始终。

`工具约束说明` 存工具名与参数模式。`编译工具调用约束` 出含 name、arguments 之工具对象；`编译工具调用列表约束` 出其数组。`编译带标签工具调用约束` 依次受工具列、正则译函、前标签、后标签，标签外容结森空白。

通用回归察窄整数之域、整数 oneOf 相叠、对象与数组互斥、递归文法、空字类、计数、正则首尾之锚及词表掩码之前缀对照。入口所引闭包构建已过，同一客体行于节点与原生执行器皆过，两端之出逐字相同。独验数值、容器与全包类型收尾续行。

anyOf、oneOf 内析取之正规化，与对象字段、数组项失败之证，同接其文法。对象字段子集之态容诸字段任序；数组见证子集之态容一项合诸证。已知与未知之键，各用精确串词法。

内用容器交补文法已接负 const 与 enum：对象以字段存亡、字段异值及余键辨所禁之值，数组以长短及位值之异辨之。其通用之试随主入口得双端运行之验，禁值之独验续行。

字符串模式交补之私有乘积已接。乘积以统一码区间求诸式共同之后缀，存负式之空汇态，并合有限串之排除。独立有限语言逐字节前缀对照行于节点已过，原生之验续行。

后事：已知键之重复、繁搜索锚、模糊之验、基准、裸机之验。后续之途以明示编译之误告之。今为甲级设施之一部。
