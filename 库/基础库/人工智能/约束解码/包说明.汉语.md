# 约束解码

版本：0.1.0。包位于人工智能基础库组，直接依赖标准库、结森工具、分词器与正则。

`编译有限文法` 将候选字符串编成字节前缀树。`约束活态` 建立初始状态，`约束步进` 接受原始词元字节，`允许词元掩码` 返回与词表顺序一致的布尔列表。字节拆开的统一码字符可跨词元前进。`约束可结束` 判断当前前缀属于语言。空词元的掩码为阴；结束词元由调用方根据可结束状态处理。

`校验结森模式` 支持 type、properties、required、items、enum、const、anyOf、oneOf、pattern、minimum、maximum。调用方提供正则匹配函数。`编译有限结森模式` 支持单独使用 const、enum、boolean、null，返回编译结果或明确错误。词表接口接受字节串列表，便于从分词器获取原始字节。

`编译约束模式` 接受结森模式与正则编译回调。`内置约束正则编译` 接入统一码正则状态。`新建通用约束状态`、`通用约束步进`、`通用约束可结束`、`通用约束可继续` 操作通用预测状态。旧初态可以保留，用于复核最终返回文本。

内置模式搜索与字符串交补使用带 `u` 标志的 ECMA 脚本正则编译入口。全串正则约束使用通用 Perl／RE2 正则入口。脚本语法错误作为模式编译错误返回。

数值文法生成六十四位整数字面、含小数点的十进制表示与指数表示。浮数前缀采用精确舍入单元与离散浮值区间相交，整数模式同时接受具有整数值的小数和指数表示。泛结森数值复用同一精确词法。const、enum 的小数常量采用精确往返表示，对象与数组内的常量递归使用同一表示。指数私内核的独立测试已取得双端与逐字输出一致结果，调用者整合与新增通用回归交由 CI 验证。

`建字节词表前缀树` 接受按模型词元序号排列的原始字节串，`建分词器词表前缀树` 直接接受基础库分词器。`通用允许词元掩码` 遍历词表前缀树共享公共字节前缀。`通用允许字节词元掩码` 提供字节串列表的便利入口。调用方根据可结束状态设置结束词元；生成上限与停止串结束时复核返回文本。

`编译约束文法` 读取 GBNF 文法，以 root 规则为入口；`编译约束文法以规则` 指定入口名。文法包含固定文字、统一码字符类、连接、选择、递归、可选项与计数重复。`编译正则约束` 建立全串正则文法。模式搜索中的简单首尾锚分别限定字符串起点与终点。

`工具约束说明` 保存工具名及参数模式。`编译工具调用约束` 输出含 name、arguments 的工具对象；`编译工具调用列表约束` 输出工具对象数组。`编译带标签工具调用约束` 按工具列表、正则回调、前标签、后标签的顺序接受参数，标签外容许结森空白。

通用回归涵盖窄整数区间、整数 oneOf 重叠、对象与数组互斥、递归文法、空字符类、计数、正则首尾锚及词表掩码前缀对照。入口的引用闭包构建通过，同一客体在节点与原生执行器上运行通过，两端输出逐字一致。独立数值与容器对照、全包类型检查收尾继续实施。

anyOf、oneOf 的内部析取正规化与对象字段、数组项失败见证接入同一文法。对象字段子集状态支持任意字段顺序，数组见证子集状态允许同一项满足多项见证。已知键与未知键分别采用精确字符串词法。

内部容器交补文法已接入负 const 与 enum：对象通过字段存在、字段异值和额外键区分禁值，数组通过长度和索引异值区分禁值。相关通用用例随主入口取得双端运行结果，完整独立禁值对照继续实施。

字符串模式交补的私有乘积已接入。乘积按统一码区间求各模式的共同后缀，保留负模式的空汇态，并联合排除有限字符串。独立有限语言逐字节前缀对照在节点端运行通过，原生对照继续实施。

后续事项：重复已知键、复杂搜索锚、模糊测试、基准与裸机验收。后续路径通过明确编译错误报告。当前实现为甲级设施的一部分。
