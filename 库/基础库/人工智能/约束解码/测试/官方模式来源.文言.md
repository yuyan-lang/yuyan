# 官方模式试项出处

`官方模式。测试。豫` 收 JSON Schema Test Suite 之 Draft 2020-12 数据五十项，逐项据官方 `valid` 之真值验 `校验结森模式`。上游定本为 `5b0ee1613e45fcc2bddac00e07c19cd49b00d8a8`，采于 2026-10-08。

[官方试集目录](https://github.com/json-schema-org/JSON-Schema-Test-Suite/tree/5b0ee1613e45fcc2bddac00e07c19cd49b00d8a8/tests/draft2020-12)载其原式、输入及真值。源码以文件名加 JSON Pointer 定其处；如 `type.json#/0/tests/1`，即此文件零组之一项。汉语名供本地诊断，模式、输入存官方判义字段及数据。方言统一定为 Draft 2020-12，源码模式略重复之 `$schema` 宣。

正则试项用内置搜索回调，验简锚及子串搜索。有限掩码之验，以枚举 `[1,2,3]` 明生三规范文本及七词元，逐项穷验前缀可达，并验成值合官方枚举模式。其穷尽之域为有限文法所定之文本集。

后版之事：平台整数域外之纯整数试项，随大整数之表而接；余 JSON Schema 关键词及全 ECMA 正则之约，各扩出处向量。诸事别计。今五十项唯录所择子集，验果由 CI 报之。
