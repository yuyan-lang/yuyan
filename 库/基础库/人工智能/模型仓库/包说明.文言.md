# 模型仓库

此包备拥抱面、镜像、魔搭及 OCI 注册表之文件目与下载计算核心。网络之行委于传输回调，核心造范围、续传及鉴权头，治转址，跨站则去令牌。果存已得字节，断网复起可续。摘要以纯豫言 SHA-256 及 Git blob SHA-1 验之。

缓存径循拥抱面 models--、blobs、snapshots、refs 及奥拉玛 manifests、blobs 之制。离线取已有字节，完备且摘要合则即成。

今所施为仓目及下载状态计算。后续当接超文本真实客户端、文件缓存、并行调度、终端进度、yy模型及本地推理。甲乙之验尚行。

据：[拥抱面缓存布局](https://huggingface.co/docs/huggingface_hub/en/guides/manage-cache)、[魔搭官方客户端](https://github.com/modelscope/modelscope/blob/master/modelscope/hub/file_download.py)、[OCI分发规范](https://github.com/opencontainers/distribution-spec/blob/main/spec.md)。
