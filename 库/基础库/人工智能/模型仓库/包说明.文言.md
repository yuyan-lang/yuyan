# 模型仓库

此包备抱抱脸、镜像、魔搭及 OCI 注册表之文件目与下载计算核心。网络之行委于传输回调，核心造范围、续传及鉴权头，治转址，跨站则去令牌。果存已得字节，断网复起可续。摘要以纯豫言 SHA-256 及 Git blob SHA-1 验之。

缓存径循抱抱脸 models--、blobs、snapshots、refs 及奥拉玛 manifests、blobs 之制。离线取已有字节，完备且摘要合则即成。

仓目及下载状态计算核心已过二十八验。文件缓存、仓库会话、明文客户端及分块异步调度已过类型之验。原生文件缓存过九验，核目录之授、中文径、零字节、越界之拒、抱抱脸离线快照、奥拉玛层之存及删。yy模型命令行续验。后续当接安全超文本、并行网络及本地推理。甲乙之验尚行。

据：[抱抱脸缓存布局](https://huggingface.co/docs/huggingface_hub/en/guides/manage-cache)、[魔搭官方客户端](https://github.com/modelscope/modelscope/blob/master/modelscope/hub/file_download.py)、[OCI分发规范](https://github.com/opencontainers/distribution-spec/blob/main/spec.md)。
