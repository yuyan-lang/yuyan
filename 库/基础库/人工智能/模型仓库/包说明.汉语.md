# 模型仓库

`模型网址请求` 的 HTTPS 分支调用正式安全 HTTP 请求，按请求主机和当前 Unix 秒建立默认客户配置，使用仓内信任根、证书链和握手签名核验。异步入口 `模型异步网址请求` 可供分块调度使用。HTTP 驱动负责每连接的安全随机数、期限与连接关闭。

`解析模型卡(文件名, 文本)` 返回状态、配置树和正文。独立 `.toml`、`.yaml`、`.yml` 文件及 README 的 `---` 雅码前言、`+++` 通明前言复用配置格式包，保留嵌套表、序列与正文。状态零表示成功，四表示配置错误。

公网 HTTPS 端点与分块网络实测继续验收；TLS 套件、群组与签名能力遵循安全传输包。

本包提供 Hugging Face、镜像端点、魔搭社区与 OCI 注册表的文件清单和下载计算核心。网络请求由传输回调执行；下载逻辑生成 Range、If-Range 和鉴权头，处理重定向，跨站重定向清除令牌。下载结果保留已下载字节，供断网后继续。文件摘要使用纯豫言 SHA-256 与 Git blob SHA-1 验证。

缓存路径计算遵循 Hugging Face 的 models--、blobs、snapshots、refs 与 Ollama 的 manifests、blobs 目录布局。离线模式从现有字节恢复，完整且摘要正确时直接成功。

仓库元数据与下载状态计算核心已通过二十八项断言。文件缓存、仓库会话、明文客户端接入与分块异步调度已通过类型检查。原生文件缓存实测通过九项断言，核对目录授权、中文路径、零字节、越界拒绝、抱抱脸离线快照、奥拉玛层保存与删除。yy模型命令行继续验收。后续接入事项：安全超文本客户端、并行网络任务与本地推理使用者。甲乙验收仍在进行。

依据：[Hugging Face缓存布局](https://huggingface.co/docs/huggingface_hub/en/guides/manage-cache)、[魔搭官方客户端](https://github.com/modelscope/modelscope/blob/master/modelscope/hub/file_download.py)、[OCI分发规范](https://github.com/opencontainers/distribution-spec/blob/main/spec.md)。

正式快照入口见《快照》：向本地推理提供提交号、授权相对快照根与完整原文件清单，网络回调留在库内。`yy模型` 下载失败返回退出码一，成功时输出缓存就绪。新基本 CI 烟测覆盖快照目录与文件查询，运行结果由 CI 后续核验。
