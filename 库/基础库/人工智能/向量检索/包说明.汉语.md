# 向量检索

本包提供向量内积、欧氏距离、平方距离、余弦距离与精确近邻检索。向量以小数列表表示；调用方提供相同维度。近邻结果按平方距离升序排列，包含记录编号与平方距离。零向量的余弦距离取一。

`新向量索引` 创建可变索引，`插入向量` 按编号更新，`删除向量` 移除编号，`检索向量` 返回指定数量的近邻。精确检索保持至多 k 项结果，逐项遍历记录。

后续事项：分块检索；HNSW 与 IVF；索引存取；元数据过滤；图形处理器检索；公开数据集召回率对照。当前为实施中的核心，甲级与乙级验收待全部规格覆盖。

## 向量存储

「存储向量」保存单精度、半精度或有符号八位整数的原始字节。`打包单精度向量` 与 `打包半精度向量` 将小数列表按小端位型打包；`量化八位整数向量` 按最大绝对值确定比例，使用就近取整、范围负127至127的对称量化，零向量比例取一。量化拒绝非数与无穷输入，调用方可以捕捉异常。八位整数向量同时记录比例与零码，解码公式为 `(有符号码−零码)×比例`。

`存储向量取值` 解码为小数列表，`存储向量平方距离` 返回两向量的平方 L2 距离。浮点字节长度按类型对齐，高维解码使用打表，编码与最大绝对值使用尾累计。`测试/存储向量。测试。豫` 覆盖三种表示往返、距离、零向量与非有限量化输入。
