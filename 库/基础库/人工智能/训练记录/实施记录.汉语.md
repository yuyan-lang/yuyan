# 训练记录实施记录

实现 TensorBoard TFRecord 分帧及掩码 CRC-32C 校验，Event 与 Summary 的标量、图像、直方图编码和字段读取，hparams 实验及会话元数据，以及 CSV 和 JSON Lines 指标记录。训练循环示例写出事件与指标文件。

本机最新稳定工具链的包检查、类型检查、往返测试、训练循环示例通过。往返测试同时在 pit-mac 的诺节宿主通过。初版曾通过临时协议缓冲外部包联调；协议缓冲现已正式合入 `yybs`（`a6e9210c7`），训练记录分支与远端验证树均已同步包含该提交的基点，后续使用仓内正式依赖。

三个解析入口（TFRecord 解帧、Event 字段读取、Summary 标量读取）在 pit-mac 各完成一百万次单字节变异测试，合计 3.435891 秒；本次小样本测试没有崩溃或超时。位置和值来自确定性序列，可以复现。该耗时包括全部变异输入的构造与解析，作为小输入测量记录。

CRC-32C 已替换为公共「校验/循环校验」的「循环校验32C(字节串)→整数」，本包重复逐位循环已删除。协议缓冲与公共校验均取正式仓内依赖，适配后的往返测试已通过。

官方样本与百万变异入口集中在 `测试/全量/`，由全树测试规则跳过。此前单进程百万测试为冒烟与小输入测量；公共乙级所需子进程隔离、超时、崩溃和超限判定尚待接公共测试设施，尚未宣称完整乙级。

后续已静态接入手写数字训练的 `--记录文件` 选项，每轮收集训练损失、训练及测试正确率、训练及评估秒数，在训练结束时保存事件文件。该应用的时钟接口提供单调微秒，事件暂取默认纪元时间零，轮数用于步数轴。

已取官方教程的预生成 hparams 样例，保留实验、会话零与其指标文件的原始字节；来源、SHA-256 与预期值见测试/全量/样例双语来源说明。官方会话中的标量使用 TensorProto.float_val，读取接口据此扩展。hparams 空张量形状修正为 `[0]`，并补离散候选域及数值区间域。

2026-10-08 官方样本对照在最新发布工具链的诺节宿主与同源原生生成器、原生执行器上通过。三个原始文件分别含实验两帧、会话四帧、指标十三帧，共二十一帧。全部帧通过公共 CRC-32C、公共协议缓冲 Event/Summary/TensorProto 解析与重分帧逐字节一致检查；官方 0.94 标量、hparams 空张量形状、离散候选与数值区间亦通过。日志分别为 yy训练记录官方样本运行.log 与 yy训练记录官方样本原生运行.log。
