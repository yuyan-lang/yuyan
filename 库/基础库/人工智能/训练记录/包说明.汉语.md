# 训练记录

训练记录以纯豫言构造和读取 TensorBoard 事件文件。TFRecord 帧依次保存八字节小端长度、长度的掩码 CRC-32C、Event 载荷与载荷的掩码 CRC-32C。损坏或截断的帧返回 `可无`。

## 接口

- `训练标量(标签, 小数)`、`训练图像(标签, 高, 宽, 通道, 已编码图像字节串)`、`训练直方图(标签, 最小, 最大, 数目, 和, 平方和, 边界列, 计数列)` 构造 Summary.Value。
- `训练事件(时间, 步数, 摘要列)` 构造 Event。时间单位为 Unix 秒。
- `训练文件编码(事件列)` 添加版本事件并分帧；`训练文件解码(字节串)` 校验全部帧，返回可选 Event 字节串列。
- `写训练文件(路径, 事件列)` 与 `读训练文件(路径)` 操作文件。
- `读取训练事件` 返回协议缓冲的解析状态及字段列；`训练事件时间`、`训练事件步数`、`训练事件摘要` 读取常用字段。
- `训练摘要标签`、`训练摘要标量`、`训练摘要载荷(摘要, 字段号)` 读取 Summary.Value；图像载荷字段号为 4，直方图为 5，张量为 8，元数据为 9。嵌套载荷由协议缓冲包解析。
- `超参数数值`、`超参数文字`、`超参数爻` 构造会话参数；`超参数开始`、`超参数结束` 构造 hparams 元数据摘要。
- `超参数说明(名称, 类型号)` 与 `超参数指标说明(组, 标签)` 构造实验描述，类型号 1 为字符串、2 为爻、3 为小数；`超参数实验` 构造实验摘要。
- `指标逗隔标题`、`指标逗隔行`、`指标结森行` 构造 CSV 与 JSON Lines；`写指标记录` 按顺序写出字符串行列。CSV 指标名双引号包裹并转义；JSON Lines 转义引号、反斜线、换行、回车、制表符。

## 使用

训练循环每次取时间、步数和损失，调用 `训练标量` 与 `训练事件`，结束时以 `写训练文件` 保存。图像接口接收图像编解码包产出的 PNG 或 JPEG 字节串。hparams 的实验摘要存入根运行目录，会话摘要与标量指标存入各会话目录。

`训练循环示例。豫` 运行十步示例并写出 `yy训练示例.tfevents` 与 `yy训练示例.jsonl`。构建入口为 `豫构 构建 训练记录 训练循环示例 --输出 yy训练循环示例.wasm -j 24`。

## 限制与后续事项

文件写入采用整文件覆盖。流式追加留待后续版本。指标小数采用标准库的小数表示精度。JSON 的其他控制字符转义与非有限数指标策略留待后续版本。图像字节由调用者编码。乙级的百万变异输入、原生运行、浏览器抽样、裸机与性能测量按仓库验收流程另行记录。

## 数据出处与许可

字段号依据 TensorFlow 的 `tensorflow/core/util/event.proto`、`tensorflow/core/framework/summary.proto` 与 TensorBoard 的 `tensorboard/plugins/hparams/plugin_data.proto`、`api.proto`；上游协议使用 Apache-2.0。实现为依据公开格式独立编写的豫言代码。CRC-32C 检查串 `123456789` 的值为 `0xe3069283`。

协议来源：[Event](https://github.com/tensorflow/tensorflow/blob/master/tensorflow/core/util/event.proto)、[Summary](https://github.com/tensorflow/tensorflow/blob/master/tensorflow/core/framework/summary.proto)、[hparams](https://github.com/tensorflow/tensorboard/blob/master/tensorboard/plugins/hparams/plugin_data.proto)。

测试覆盖校验检查值、标量与时间往返、单精度次正规数舍入、Unicode 标签、图像与直方图字段、hparams、CSV 引号、完整帧与损坏帧。

pit-mac 上三个解析入口各一百万次单字节变异测试共用 3.435891 秒，包含输入构造与解析。此为小输入测量；代表性大事件性能留待后续验收。
