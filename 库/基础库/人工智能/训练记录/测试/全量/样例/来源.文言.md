# 官方 TensorBoard 样例

三事件之文取自 TensorFlow 官方《Hyperparameter Tuning with the HParams Dashboard》之[预造日志](https://storage.googleapis.com/download.tensorflow.org/tensorboard/hparams_demo_logs.zip)。[教程](https://www.tensorflow.org/tensorboard/hyperparameter_tuning_with_hparams)之辞用 CC BY 4.0，示例之码用 Apache-2.0；数据取其公开下载。

于 2026-10-07 取之，唯存根目录实验、会话零及其 keras_metrics 文件，诸字节原样存之。原径、字数及 SHA-256 详配对汉语稿之表。

会话四帧，依次版本、开始、accuracy 标量、结束。accuracy 单精位为 `0x3f70a3d7`，约 0.94，以 TensorProto float_val 存之。对照之验读原帧，核诸 CRC 及 Event 消息，察实验、开始、结束之标签及此标量。
