# 向量检索加速

`加速精确检索(上下文, 编号向量记录, 查询, 数量, 距离种类)` 使用公共张量上下文与正式「线性代数加速」的直接加速矩阵乘，计算全部候选与查询的内积，再形成前 k 个近邻。距离种类零为平方 L2，一为负内积，二为余弦距离。调用者取得与释放上下文，并提供一致维度的向量。

输入以单精度上传，矩阵乘的左、右、积三个临时张量由「线性代数加速」释放。L2 用向量平方模及内积合成，小幅负距离截为零；小数舍入按张量后端精度体现。GPU 实验入口要求「必须加速」，核对上下文加速标记并打印真实后端名称。2026年10月8日在 pit-mac 经正式公共 Node 绑定实际运行 Metal，四条二维向量的三种距离、近邻编号及排序与 CPU 精确参考一致，运行退出零；距离误差界为0.0001。证据见基础包的「向量检索乙级测量.汉语.md」。原生设备运行留待后续测量。
