# 向量检索之加速

「加速精确检索」受公共境、号量诸记录、所问量、所求数及距类，以正式「线性代数加速」之直接加速矩阵乘，计诸候选与问量之内积，后成前 k 邻。距类零取平方距，壹取内积之负，贰取余弦距。调用者取境而释之，诸量维数同。

输入以单精度上送，左、右、积三暂量由「线性代数加速」释之。平方距以量之平方模及内积合成，微负者取零；舍入从张量后端之精度。图算之验须「必须加速」，校境之加速记，印实用后端之名。2026年10月8日于 pit-mac 经公共 Node 绑定实用 Metal，四条二维量之三距、邻号及次序皆合 CPU 精确参考，退出零，距误之界0.0001。证据在基础包「向量检索乙级测量.汉语.md」。原生设备之行，后续测之。
