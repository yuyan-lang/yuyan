# 推理服务

此包具模型目录、交谈及文本补全之结森应答、Bearer 鉴权与错误之辞，亦具奥拉玛交谈、生成及模型目录之应答。流式引擎受全请及词片回调，片至即书 SSE 或结森行，终书终结之记。千问 `<tool_call>` 可转成 OpenAI 与奥拉玛之工具调用对象。

`服务分派` 受模型名、密钥、授权首、路径、请求与引擎，还状态、媒类及正文。`推理引擎` 还所生之辞及出入词数。

引擎受全请，可取采样诸参与消息。`服务分派` 以引擎所还全辞编为 SSE 或结森行；网络服务之流式引擎由词片回调逐片书出。
OpenAI 内容、工具及完成之流片皆具整数 `created`，与全辞应答同为零。系统创建之时留待后版记之。

`运行推理服务` 受址、端口、模型名、密钥与引擎。以纯豫言超文本传输及传输控制协议监听，次第受请，监听队十万，候时六十万毫秒。应答具跨域首与 OPTIONS 预检。`服务连接` 处一已受之连。

`运行完整推理服务` 又受可选嵌入提供者，以 `/v1/embeddings` 还带号之向量列与词数。`新连续批队列`、`批请求入队` 及 `推进连续批` 存活动之请，每步纳新而去已毕者；实批前向由批模型提供者行之。

`批后端` 供步进、积果之查询与会话之释放。`取消批请求` 去活动及待办之请。`推进批接收` 每轮试读一度而存超文本解析之态；`推进批发送` 每轮试写一度而存部分已写之字节序。调度可交处连之读写与模型之步进。

`运行批推理服务` 受址、端口、模型名、密钥、批容量、批后端及可选嵌入引擎。每轮纳新连，进分片之请与模型批步，乃试书诸客户之积。书出有失则罢而释其请；应答尽乃闭连。工具流于毕时转对象；常词片至即入发送之积。

验证：全协议入口二十项、批状态及错误流十一项与双客户实 TCP 互通，于诺节及原生预编二皆过，包检查及全库源码类型检查皆过。系统 curl 与原生服务之 OpenAI SSE、奥拉玛 NDJSON 混合请求亦过。工具请求之流果于生成毕后转为工具增量对象。引擎有失则书明白之结森或流式错误记录，释其会而空其批位。待办事项：约束解码接入之全验、实模型之嵌入前向与批前向、裸机之验、诺节 fetch 之对照、全模糊测试、性能及甲乙级核验。

数据以手书测试生之；许可从仓。
