# 推理服务

本包提供 OpenAI 模型清单与聊天、文本补全的结森响应格式、Bearer 鉴权和错误响应，以及奥拉玛聊天、生成与模型列表的响应。流式引擎接收完整请求与词片回调；每次回调即时写出 SSE 或结森行，结束时写终结记录。千问 `<tool_call>` 内容可以转换成 OpenAI 与奥拉玛工具调用对象。

`服务分派` 接收模型名、密钥、授权头、路径、请求与引擎；返回状态码、媒体类型与正文。`推理引擎` 返回生成文本与输入、输出词元数。

引擎回调接收完整请求，可以读取采样参数与消息。`服务分派` 将整段引擎结果编码成 SSE 或结森行；网络服务的流式引擎通过词片回调逐片写出。
OpenAI 内容、工具及完成流片都包含整数 `created` 字段，与整段应答保持相同的零值。系统创建时间记录留待后续版本。

`运行推理服务` 接收地址、端口、模型名、密钥与引擎。服务通过纯豫言超文本传输与传输控制协议监听，顺序处理请求，监听队列为 100000，等待时间为 600000 毫秒。响应提供跨域头与 OPTIONS 预检。`服务连接` 处理一个已接受的连接。

`运行完整推理服务` 额外接收可选嵌入提供者，把 `/v1/embeddings` 映射为有编号的向量列表与词元用量。`新连续批队列`、`批请求入队` 与 `推进连续批` 保留活动请求，每步纳入新请求并移除已完成请求；批模型提供者执行真实批前向。

`批后端` 提供步进、累计结果查询与会话释放。`取消批请求` 同时移除活动与待办请求。`推进批接收` 每轮尝试读取一次并保留超文本解析状态；`推进批发送` 每轮尝试写出一次并保留部分写入的字节偏移。调度循环可以交替处理连接读写与模型步进。

`运行批推理服务` 接收地址、端口、模型名、密钥、批容量、批后端与可选嵌入引擎。每轮纳入新连接，推进分片请求和模型批步，再尝试写出全部客户的缓冲。发送失败时取消并释放对应请求；完成响应排空后关闭连接。工具流在完成时转换对象；普通词片即时加入发送缓冲。

验证：完整协议入口二十项、批状态七项断言及双客户真实 TCP 互通均通过诺节与原生预编二运行，包检查与完整库源码类型检查通过。系统 curl 与原生服务的 OpenAI SSE、奥拉玛 NDJSON 混合请求通过。工具请求的流式结果在生成完成后转换成工具增量对象。引擎失败时写明确的结森或流式错误记录。待办事项：约束解码接入的完整核验、实际模型的嵌入前向与批前向、裸机核验、诺节 fetch 对照、完整模糊测试、性能与甲乙级验收。

数据由手写接口测试生成；许可随仓库。
