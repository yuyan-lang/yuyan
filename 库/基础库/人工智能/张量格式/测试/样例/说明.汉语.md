# 官方线性模型样本

`线性模型.onnx` 来自 ONNX 官方仓库的 PyTorch 导出 Linear 测试模型，采用 Apache-2.0 许可。

来源：[官方文件](https://github.com/onnx/onnx/blob/main/onnx/backend/test/data/pytorch-converted/test_Linear/model.onnx)。取得日期为 2026-10-08，长度 585 字节，Git blob 为 `cb2d07eb66559c9bb450903b19ef5190f43f419f`，SHA256 为 `60a3546925d832686c788d3ea22732feaef5bc527e04691c32ec9f677c81f612`。

模型包含一个 Gemm 节点、名字为 `1` 的 8×10 单精度权重和名字为 `2` 的八元素单精度偏置。扩展格式测试核对节点、初始化器排列和 320 字节权重载荷。当前真实样本的豫言运行验证等待统一构建时段。
