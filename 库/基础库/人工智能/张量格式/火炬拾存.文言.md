# 火炬拾存

`解析火炬拾存` 受 PyTorch ZIP 所藏 `data.pkl` 之字节，還 `火炬张量说明` 之列。调用者取 ZIP 之 `data/<存储键>`，据说明成其张量。

说明循序藏张量名、存储键、安量类、元素偏、形、元素之跨、存储总数。根可为权重字典，亦可为有 `state_dict` 之检查点字典。字段之序即所得之序；memo 所记字典、列表、张量之别名共其藏。

受第二至五协议之常用数据指令：PROTO、FRAME、MARK、整数、Unicode 文、旧字节文、None、真假、元组、列表、字典、memo、REDUCE、BINPERSID、BUILD、POP、DUP。终则验 STOP、栈与末位。字段之长、存储之形皆验其界。空张量、零维量、非零偏、疏跨可用。

GLOBAL、STACK_GLOBAL 所许者：`collections.OrderedDict`、`torch._utils._rebuild_tensor_v2`，及 torch 之 DoubleStorage、FloatStorage、HalfStorage、BFloat16Storage、LongStorage、IntStorage、ShortStorage、CharStorage、ByteStorage、BoolStorage。安量之类依次为 F64、F32、F16、BF16、I64、I32、I16、I8、U8、BOOL。

REDUCE 以本模数据之法释 OrderedDict 与张量复建之名。持久标识取 storage 之类、键、总数；设备验其为文。BUILD 受字典附属之典，弃旁记 metadata。余名与余码以字符串告异，可用 `尝试运行` 承之。

测试以纯豫言拼第二、四协议之定例，验权重、外包 state_dict、OrderedDict 附属、memo 共名、偏与疏跨、恶 GLOBAL/STACK_GLOBAL、缺 memo、越存储与断字。源码已排，型验及运行待统筹授时。

后事：第零、一协议之文本整数、浮数旁记、非空 OrderedDict 构造参数、新式无类存储与 `_rebuild_tensor_v3`、Parameter 复建、FRAME 指令之界严验、真 PyTorch 所生对照例。

协议据：[CPython pickletools 操作码文档](https://github.com/python/cpython/blob/main/Lib/pickletools.py)。张量字段据：[PyTorch 重建函数](https://github.com/pytorch/pytorch/blob/main/torch/_utils.py)。
