# 模板

这是纯豫言模板解释库，版本为 0.1.0。`渲染模板` 接收模板字符串与结森对象上下文，返回渲染文字。变量可以取对象公开属性与数组下标，内部属性访问会抛出异常。

当前实现变量输出、字符串与整数、布尔值、空值、括号、相等与不等、逻辑且或非、整数相加、字符串相加与 `~` 拼接，支持 `if/else`、`for/else`、`set`、注释与标签两端的 `-` 空白控制。循环提供 `loop.index`、`index0`、`first`、`last`、`length`。

过滤器支持 length、trim、upper、lower、string、safe、list、tojson、abs、first、last、join、default。ASCII 大小写转换适用于模型模板中的角色名。tojson 当前采用结森工具的紧凑表示，Jinja2 的分隔空格与 HTML 字符转义留待后续。模板未知过滤器与未知指令会报告带“待办事项”的异常。

后续版本事项：其余 Jinja2 表达式、过滤器、测试、elif、namespace、字符串与容器方法、切片、Hugging Face 扩展、macro、call、include、继承、自动转义；三十个模型的 Jinja2 对照向量与裸机验收。提案00004的甲级和乙级仍待完整验收。
