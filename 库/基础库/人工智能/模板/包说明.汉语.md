# 模板

这是纯豫言模板解释与聊天模板渲染库，版本为 0.1.0。

`渲染模板` 接收模板文字与结森对象上下文，返回渲染文字。`渲染聊天模板` 使用聊天模板的块裁白设置，归整换行并移除模板源末尾的一个换行。`渲染分词器配置` 接收分词器配置与上下文，选择 `chat_template` 并补充配置中的 BOS、EOS 特殊词元；上下文中显式传入的特殊词元优先。

配置中的聊天模板可以采用文字、名字到文字的对象，以及含 `name`、`template` 的数组。含工具的上下文优先选择 `tool_use`，其余选择 `default`；单一模板可以直接选取。

表达式处理结森对象、数组、字符串、整数、小数、爻、空值，以及模板元组。变量可以取公开属性、下标与切片；内部属性访问会报告异常。算术、比较链、包含、逻辑、条件表达式、字符串拼接、常用字符串与容器方法均在豫言中求值。幂链采用 Jinja 的左结合次序。大小写转换使用统一码库；小数文字使用数值格式库的最短往返结果，并采用 Python 的指数阈值与浮点文字样式。

过滤器包括 length、upper、lower、trim、join、tojson、default、items、list、string、replace、first、last、selectattr、rejectattr、map、indent、capitalize、round、abs、int、float、safe、escape。测试包括 defined、undefined、none、string、mapping、iterable、sequence、number、equalto、in。tojson 对键排序，使用分隔空格、ASCII 转义与 HTML 特殊字符转义。

语句包括 if、elif、else、for、循环 else、set、namespace、macro、call、autoescape，以及注释和标签的空白控制。循环提供 index、index0、first、last、length、revindex、revindex0、previtem、nextitem、depth、depth0 与 cycle。宏支持位置参数、具名参数与默认参数，call 的正文可以通过 caller 调用。自动转义块保存并恢复作用域中的转义设置；safe、tojson 与宏输出携带内部安全文字身份。上下文中以“模板内部”开头的键名用于内部值表示。

`raise_exception` 报告模板异常；`strftime_now` 使用当前日期时间格式化入口。

库内字典加载器用于包含与继承验证。模板集以名字到文字的对象提供源，include可以选择候选模板与上下文；extends逐级覆盖block，super读取父块，self调用模板中的块。scoped块携带调用位置的局部变量。

三个测试入口在Node及原生上均已构建并运行通过：表达式与聊天配置115项、原模板回归37项、内部模板集10项，各端共162项成功、0项失败。两端使用同一批Wasm客体。

后续版本事项：模板集公共入口、完整递归循环及其余 Jinja 宏语义；约三十个模型的固定对话对照、模糊测试、性能及裸机验收。提案00004甲级、乙级的完整验收继续进行。
