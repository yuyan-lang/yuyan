# 模板

此纯豫言之模板解释与聊天渲染库也，版为 0.1.0。

`渲染模板` 受模之文与结森之典为境，还其成文。`渲染聊天模板` 用聊天之块裁白，齐其换行，去源末一换行。`渲染分词器配置` 受分词之配置与境，择 `chat_template`，补配置之 BOS、EOS 特殊词元；境中明授之词优先。

聊天之模可为文，或名与文之典，或含 `name`、`template` 之列。境有工具则先择 `tool_use`，余择 `default`；独一之模可径取。

式具结森之典、列、串、整数、小数、爻、空与模板元组。变数可取公开之键、下标与切片；取内部之键则告异。算、比较之链、包含、且或非、条件之式、串相附及串与容器常用之术，皆以豫言求之。幂之链依 Jinja，自左而合。大小写用统一码；小数用数值格式之最短往返文，复依 Python 指数之界与浮点之式书之。

滤术具 length、upper、lower、trim、join、tojson、default、items、list、string、replace、first、last、selectattr、rejectattr、map、indent、capitalize、round、abs、int、float、safe、escape。试具 defined、undefined、none、string、mapping、iterable、sequence、number、equalto、in。tojson 序诸键，以空白分之，且转阿斯基与 HTML 特殊之字。

令具 if、elif、else、for、环之 else、set、namespace、macro、call、autoescape，及注与标签裁白。环具 index、index0、first、last、length、revindex、revindex0、previtem、nextitem、depth、depth0、cycle与changed。环有recursive之识，则可由loop呼子层可迭代之值；各层更新其深、滤后之列与环之状态。宏受位置、具名与默认之参；call 之正文可由 caller 呼之。自动转义之块存其旧设，事毕复之；safe、tojson 与宏之成文携内部安全文字之识。境中以“模板内部”起名之键，用于内部值之表。

`raise_exception` 告模板之异；`strftime_now` 由当前日期时间之格式入口书之。

`渲染模板集`为公开典之装载，受名与模板文之结森典、入口名及境，还其成文。include可择候选之模与其境；extends逐级覆block，super取父块，self呼模中之块。scoped块携呼处局部之变。源值之核及域之复，见[渲染之约](规范.文言.md)。总集公开之口十二基本试，于Node皆成。

Node与原生之三试入口皆成而行之：式与聊天配置115试、原模板回验37试、库内模板集10试，各端合162成，败者零。两端用同批Wasm客体。

递归环新增五试，于Node及同客体原生皆成；原162试于Node回验皆成。

宏依正文之引用，捕kwargs、varargs与caller，并具name、arguments、catch_kwargs、catch_varargs及caller诸属性。明授未定义之值仍存为参；余参依宏之捕获而纳之或告异。宏新增十四试，于Node及同客体原生皆成。

call正文具匿名宏之name、arguments及捕获诸属性；宏默认参数与明授caller之声明，于定义时验之，且纳参末之逗。今宏回验三十一试于Node皆成。not依统一码标识符之界辨之，可紧接括号、容器、引文与正负之符；式回验一百一十八试于Node皆成。截断模糊之入口试五类模板之诸前缀，异常后复其域，四百零三试于Node皆成。

`测试/全量/`具渲染、聊天与分词配置三批模糊之口，受既有设施五参之约及单例之径；各变试先验UTF-8，乃行对应公开渲染之术。基础库验证父程核诸批末序；三口各成而行有效之种，各二十五隔离变试之末序九、十九、二十四皆核成，合七十五次。全量之口于CI略之，百万变试与资源限额之验，别期而行。

热点效测用既有设施，三次预热，九次取中位，各样百次且核定成文。pit-mac之Node实测：渲染127.282583毫秒、聊天128.776毫秒、配置136.40875毫秒。源码之口在`测试/全量/基准。测试。豫`；此批之时含内部成文之核。
