# 模板

此纯豫言之模板库也，版为 0.1.0。`渲染模板` 受模之串与结森之典为境，还其成文。变数可取公开之键与列之下标；取内部之键者告异。

今具变数输出、串、整数、爻、空值、括号、等与不等、且或非、整数相加、串相加与 `~` 相附，及 `if/else`、`for/else`、`set`、注与标签两端 `-` 之裁白。环有 `loop.index`、`index0`、`first`、`last`、`length`。

滤术具 length、trim、upper、lower、string、safe、list、tojson、abs、first、last、join、default。阿斯基大小写可用于角色之名。tojson 今用结森工具之紧凑表示，Jinja2 分隔之白与 HTML 之转义待后版。滤与令未具者，以“待办事项”告异。

后版所期：余 Jinja2 之式、滤、试、elif、namespace、串与容器之术、切片、Hugging Face 扩展、macro、call、include、继承、自动转义；三十模型之 Jinja2 对照与裸机验之。提案00004甲乙二级待全验。
