# 名称之规与约束

目录相校，以「目录名称相等」受两 DER 名序列，循序校相对名，各名之属性无序相校，标识与规整之文皆与焉。

通码八串、可印串、IA5 串、双字节串、四字节串皆化通码。映控白，折大小，合兼容，压空白；坏码、代理、私用、非字符与替代之码，皆还拒果。码表循仓中之版。

域名、邮箱、URI 主机、四版与六版地址及目录约束，循旧术而验。同类所许，组内合之；历颁者而取其交；所禁有中，则拒之。

属性之白循 RFC 4518 二点六点一：白后有组合标者，与文本相校；余白之段，首尾各一格，内化二格，全白亦二格。

otherName、ediPartyName、registeredID 之约义，RFC 5280 四点二点一点十留他篇定之；x400Address 无明校义，遇约束亦拒。子树最小距非零或有最大距，则拒，循该节之拒支。

字符之年，以 RFC 3454 附录 A.1 之静界，定于三点二版；豫术自官文取界，原码与规整后之码皆核未赋之域。

大小折叠，以豫术自 RFC 3454 附录 B.2 取全旧映。旧兼容合成，存三点二版五项于四版所改之映；余已赋之码循稳定规整之法。据统一码勘误四。

简验含历史界邻、多码折叠、格鲁吉亚旧大小行为、旧合成及组合白之断言。全量、繁向量与原生核验，续列验收之阶段。

据 RFC 5280 四点二点一点十、七点一及 RFC 4518。简验添中文、全折叠、全角合成之断言；全量及原生之验别记。
