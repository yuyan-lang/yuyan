# 证书

版本 0.1.0。纯豫言实现，输入使用标准库字节串。

`外壳口令` 的 `口令解析外壳私钥` 接收 OpenSSH 二进制封套和口令字节串，使用正式 bcrypt 派生及 AES256CTR 解密，核对校验数、条目与顺序填充。`口令编码外壳私钥` 接收条目列、校验数、口令、盐与轮数，生成 bcrypt/AES256CTR 封套。调用者为生成提供安全随机的盐和校验数。库内 `外壳口令。测试` 自动发现 CI 入口使用专门生成的公开测试钥和公开口令，覆盖 ssh-keygen 封套解码、错误口令拒绝及编码回读。

`请求生成` 接入正式确定性ECDSA与双散列RSA-PSS生成、算法参数DER和生成后公钥核验的CSR及自签入口；RSA第一版与Ed25519签名工厂由总集公开。参数、盐来源与基本测试见《请求生成规范》，实际验证分阶段记录。

`曲线验签` 将 ECDSA DER 正整数签名转换为定宽 r 与 s，调用正式密码短曲线验签。生产完整证书签名核验接入 P-256、P-384、P-521 与 SHA256、SHA384、SHA512；现有握手入口接入对应三种 TLS ECDSA 方案。`测试/曲线验签。测试` 提供 OpenSSL P-256 证书真实签名、篡改签名及错误 DER 拒绝的自动发现 CI 入口。此批新增接口行为的实际运行验收列入后续核验。

既有 `测试/编码。测试` 在正式源 `465d3bde8` 通过 Node 与苹果臂六十四原生同客体核验，两端输出“证书编码与名称测试通过”。工具身份、命令与日志见《固定DER核验记录》。完整证书链与甲乙验收按后续事项逐项核验。

现有接口包括严格确定长度 DER 节点编解码、对象标识编解码、证书时间解码、X.509 主体与扩展封套解析、域名通配符与二进制 IP 地址核对、密钥容器解析和证书路径构建。

`编码` 模块的 `解码完整节点` 返回 `解码成功` 或 `解码失败`。`证书解析` 的 `解析证书` 返回 `证书解析成功` 或 `证书解析失败`。证书有效期转换为自 1970 年起的协调世界时秒数。`扩展` 模块提供基本约束、路径上限、密钥用途、扩展用途与备用名称查询。

`路径` 的 `验证证书链` 接收证书 DER 列表、主机名、Unix 秒、可信根 DER 列表和强制验签函数，返回成功链或错误。验签函数接收签名算法 OID、待签主体 DER、签发者 SPKI 和签名，生产调用需接密码库。当前路径对名称约束采取拒绝策略；`名称约束` 模块正在实现 DNS 与 IP 子树的检查。

`密钥格式` 支持 SPKI、PKCS#1 双素数及多素数私钥与公钥、PKCS#8、SEC1 的解码与重编码。多素数 RSA 按版本1解析非空其它素数三元组，逐项检查规范正整数。SEC1 核对版本、命名曲线、定宽私钥范围、可选字段次序及公私钥一致性，支持 P-256、P-384、P-521 的压缩与非压缩公钥。PKCS#8 内部曲线参数继承外层命名曲线并检查一致性。

`加密密钥` 的 `加密PKCS8(容器,口令字节串,盐字节串,迭代次数,AES位数,初向量字节串)` 返回 `密钥封套成功` 的 DER 字节串或 `密钥封套失败`。编码使用 PBES2、PBKDF2 HMAC-SHA256、AES-128/192/256 CBC 与整块填充。调用者提供独立安全随机的至少8字节盐和16字节初向量，迭代次数由调用者安全策略决定。`解密PKCS8(加密DER,口令字节串)` 返回既有密钥格式结果，接受默认 HMAC-SHA1 及显式 SHA224/256/384/512 PRF，并核对派生密钥长度、算法参数和填充。接口拒绝错误口令及畸形封套。基本回归由 `测试/密钥容器。测试` 自动接入 CI；完整互操作及性能验证列入用户延期事项。

多素数RSA的素性、乘积及CRT关系数学审计列为后续事项；PKCS8旧式PBES1、额外口令算法及显式曲线参数列为后续事项。`安全外壳密钥` 解码 OpenSSH RSA、Ed25519、P-256、P-384 公钥的二进制字段。

`文本封套` 提供 PEM 标签与严格 Base64 的解析、编码。`地址` 提供文本 IPv4 与 IPv6 解析。`验签` 接入密码库的 RSA SHA256、SHA384、SHA512 签名核验，并提供 TLS RSA-PSS 握手核验桥；这批接口正在进行编译与互操作验收。`吊销列表`、`在线状态`、`签名请求` 分别提供 CRL、OCSP 响应及 PKCS#10 的结构接口，完整策略验收列入后续事项。

独立包 `根证书数据` 保存 2026-10-07 的 Mozilla NSS 根快照，共 172 个 DER、121 个安全传输信任位及四个失信日期。全部 DER 已通过解析测试。生产调用可按叶证书签发时刻筛选可信根。

实施进度保持为未达甲级。后续事项包括完整名称约束、OpenSSH 私钥、OCSP 真实签名互操作验收、完整签名算法参数核验、真实签名与生成对照、模糊测试及跨平台验收。

`在线状态` 的基本政策覆盖身份算法空值与缺省参数等价、重复身份和目标条目拒绝、请求随机数匹配、报告及更新时序，以及委托响应者在签署时与核验时的授权。使用约定见《在线政策.汉语.md》，基本测试入口为 `测试/在线政策。测试。豫`。完整互操作验收列入后续事项。

代码依照 ASN.1 DER、RFC 5280、RFC 9525 编写，版权与仓库许可一致。当前代码包含自主编写的测试向量。

路径验证接入策略交集、策略映射、显式策略与任意策略计数，以及规范化颁发者名称与 AKI/SKI 筛选。接口与后续核验事项见[路径策略规范](路径策略规范.汉语.md)。
