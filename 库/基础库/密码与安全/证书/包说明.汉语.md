# 证书

版本 0.1.0。纯豫言实现，输入使用标准库字节串。

`曲线验签` 将 ECDSA DER 正整数签名转换为定宽 r 与 s，调用正式密码短曲线验签。生产完整证书签名核验接入 P-256、P-384、P-521 与 SHA256、SHA384、SHA512；现有握手入口接入对应三种 TLS ECDSA 方案。`测试/曲线验签。测试` 提供 OpenSSL P-256 证书真实签名、篡改签名及错误 DER 拒绝的自动发现 CI 入口。此批新增接口行为的实际运行验收列入后续核验。

既有 `测试/编码。测试` 在正式源 `465d3bde8` 通过 Node 与苹果臂六十四原生同客体核验，两端输出“证书编码与名称测试通过”。工具身份、命令与日志见《固定DER核验记录》。完整证书链与甲乙验收按后续事项逐项核验。

现有接口包括严格确定长度 DER 节点编解码、对象标识编解码、证书时间解码、X.509 主体与扩展封套解析、域名通配符与二进制 IP 地址核对、密钥容器解析和证书路径构建。

`编码` 模块的 `解码完整节点` 返回 `解码成功` 或 `解码失败`。`证书解析` 的 `解析证书` 返回 `证书解析成功` 或 `证书解析失败`。证书有效期转换为自 1970 年起的协调世界时秒数。`扩展` 模块提供基本约束、路径上限、密钥用途、扩展用途与备用名称查询。

`路径` 的 `验证证书链` 接收证书 DER 列表、主机名、Unix 秒、可信根 DER 列表和强制验签函数，返回成功链或错误。验签函数接收签名算法 OID、待签主体 DER、签发者 SPKI 和签名，生产调用需接密码库。当前路径对名称约束采取拒绝策略；`名称约束` 模块正在实现 DNS 与 IP 子树的检查。

`密钥格式` 支持 SPKI、PKCS#1 双素数私钥与公钥、PKCS#8、SEC1 的结构解码与重编码。`安全外壳密钥` 解码 OpenSSH RSA、Ed25519、P-256、P-384 公钥的二进制字段。

`文本封套` 提供 PEM 标签与严格 Base64 的解析、编码。`地址` 提供文本 IPv4 与 IPv6 解析。`验签` 接入密码库的 RSA SHA256、SHA384、SHA512 签名核验，并提供 TLS RSA-PSS 握手核验桥；这批接口正在进行编译与互操作验收。`吊销列表`、`在线状态`、`签名请求` 分别提供 CRL、OCSP 响应及 PKCS#10 的结构接口，完整策略验收列入后续事项。

独立包 `根证书数据` 保存 2026-10-07 的 Mozilla NSS 根快照，共 172 个 DER、121 个安全传输信任位及四个失信日期。全部 DER 已通过解析测试。生产调用可按叶证书签发时刻筛选可信根。

实施进度保持为未达甲级。后续事项包括完整名称约束、OpenSSH 私钥、OCSP 授权与新鲜度策略、完整签名算法参数核验、真实签名与生成对照、模糊测试及跨平台验收。

代码依照 ASN.1 DER、RFC 5280、RFC 9525 编写，版权与仓库许可一致。当前代码包含自主编写的测试向量。
