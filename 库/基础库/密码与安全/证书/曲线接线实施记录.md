# ECDSA 证书接线实施记录

本批完成现行生产证书与握手 API 的 ECDSA 内部接线，直接依赖正式 `密码/短曲线签名`，保持现有公开入口签名。SPKI 仅接受具名 P-256、P-384、P-521；SEC1 公钥长度为 65、97、133；DER 签名要求两项规范非负整数，去符号前零后左填至 32、48、66 字节，实际密码核继续检查标量范围与曲线点。

新 CI 入口为 `证书 测试 曲线验签。测试`，全树工具按库内测试自动发现。公开 OpenSSL P-256/SHA256 自签 DER 样本在 `测试/向量/曲线根.der`，私钥保留仓外。测试含实际自签验签、末字节签名篡改拒绝、畸形 DER 拒绝。格式化、差异空白检查、包元数据检查通过；新增类型与实际语义由后续核验及 CI 记录。DNS 公共 ECC 链互操作、三曲线签名固定向量、性能与甲乙门槛继续推进。
