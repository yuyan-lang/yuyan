# 证书

版为 0.1.0。以豫言成之，受标准库字节串。

今有 DER 定长节点之编解、对象标识之编解、证书时日之解、X.509 主体及扩展之析、域名通配与二进制地址之校、钥之封套及证书路径之析。

编码之解码完整节点，以成功与失败告之；证书解析之解析证书，亦然。有效期计自一九七零年协调世界时之秒。扩展供基本约束、路径限、钥用、扩展用途与备用名之询。

路径之验证证书链受 DER 证列、主机名、Unix 秒、可信根列及必供之验签术，成功则还其链，失则告之。验签术受算法 OID、主体 DER、上证 SPKI 及签；实用当接密码库。今路径遇名称约束则拒；名称约束模块方备 DNS 与 IP 子树之校。

密钥格式析而复编 SPKI、PKCS#1 双素数私钥及公钥、PKCS#8、SEC1。安全外壳密钥析 OpenSSH 之 RSA、Ed25519、P-256、P-384 公钥字段。

今未至甲级。后续当备名称约束全检、OpenSSH 私钥、PEM、Mozilla 根证之表、密码验签之接、吊销之询、自签及请求之成、实证对照及诸平台核验。

据 ASN.1 DER、RFC 5280、RFC 9525 为码，版权许可同仓。测试向量自制。
