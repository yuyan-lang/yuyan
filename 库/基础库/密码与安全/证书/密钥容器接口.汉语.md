# 密钥容器接口

模块为 `证书/密钥格式` 与 `证书/加密密钥`。二进制输入输出使用标准库字节串。

`解析密钥(格式,DER)` 返回既有 `密钥格式成功(密钥容器)` 或 `密钥格式失败(说明)`。PKCS#1私钥格式接受版本0的九项双素数结构、版本1的十项多素数结构。其它素数信息为非空序列，每项含规范正整数的素数、指数、系数；`写出密钥` 保存这些信息。素性、模数乘积和CRT关系的数学核查列为后续事项。

SEC1接受版本1、定宽私钥字节串、可选显式标签0命名曲线及显式标签1公钥比特串，参数先于公钥，各最多一次。支持P-256、P-384、P-521，私钥满足1≤d<n。公钥支持SEC1压缩及非压缩编码并须与私钥派生点相合。独立SEC1携命名曲线；PKCS8内SEC1可以继承外层命名曲线，内外同时出现时须相合。

`加密PKCS8(容器,口令,盐,次数,AES位数,初向量)` 返回 `密钥封套成功(DER)` 或 `密钥封套失败(说明)`。容器为已解析的PKCS8，次数为正整数，AES位数为128/192/256，盐至少8字节，初向量16字节。编码PBES2、PBKDF2 HMAC-SHA256、显式派生密钥长度、AES CBC及PKCS7整块填充。调用者从安全随机接口取得独立新盐与初向量，并依安全策略设置迭代次数。

`解密PKCS8(加密DER,口令)` 返回既有密钥格式结果。PBKDF2盐使用字节串；省略PRF按HMAC-SHA1处理，显式PRF支持SHA1/224/256/384/512，参数可以省略或为NULL。省略密钥长度按AES算法决定，显式长度须一致。CBC末块固定检查16个填充字节，去填充后交严格DER与内部RSA/SEC1语义解析。

规范依据：[RFC8018](https://www.rfc-editor.org/rfc/rfc8018)、[RFC8017](https://www.rfc-editor.org/rfc/rfc8017)、[RFC5915](https://www.rfc-editor.org/rfc/rfc5915)。PBES1、显式曲线参数及额外口令算法列为后续事项。基本测试自动接入CI；完整互操作、性能及机器恒时审计按用户要求延期。
