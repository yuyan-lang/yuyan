# OpenSSH 口令封套实施记录

本批完成常见 bcrypt/AES256CTR 加密封套解析与编码，直接使用正式 `密码/封套派生` 输出 48 字节，前 32 为 AES256 密钥、后 16 为大端计数器。KDF 参数严格读取盐字段与四字节轮数，拒绝尾随参数及非 16 字节对齐密文。解密后复用既有私钥条目、双校验数和顺序填充检查；编码以 16 字节块补齐。

普通 API `口令解析外壳私钥`、`口令编码外壳私钥` 在总集导出。CI 入口 `证书 测试 外壳口令。测试` 使用系统 ssh-keygen 生成的专用 Ed25519 测试钥，口令为“公开测试口令”，此钥仅作为公开测试数据。测试包含正确口令解析、错误口令拒绝及重编回读。源码格式、包元数据和差异检查后立即提交；新增类型与实际运行由 CI 及后验记录，完整甲乙继续逐项核验。
