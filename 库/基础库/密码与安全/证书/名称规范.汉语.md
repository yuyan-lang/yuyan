# 名称规范与约束

目录名称比较通过 `目录名称相等` 接收两个 DER Name 序列节点，按顺序比较 RDN，并在每个 RDN 内无序比较属性。属性标识与规范文本一并参加比较。

UTF8String、PrintableString、IA5String、BMPString 与 UniversalString 转为统一码文本。文本经过控制与空白映射、完整大小写折叠、兼容合成与空白压缩；非法 UTF-8、代理码点、私用码点、非字符与替代字符产生拒绝结果。统一码表沿用仓库版本。

DNS、邮箱、URI 主机、IPv4、IPv6 与 directoryName 约束沿用现有检查；同型允许组内取并集，跨颁发者逐层检查取交集，排除组命中即拒绝。

属性空白处理按 RFC 4518 §2.6.1：后随组合标记的空格参加文本匹配，其余空白段在首尾各规范为一格、内部规范为两格，全空白属性规范为两格。

otherName、ediPartyName 与 registeredID 的名称约束语义由 RFC 5280 §4.2.1.10 留给其他文档定义；x400Address 沿用未定义匹配语义的拒绝处理。这些约束当前产生拒绝结果。GeneralSubtree 的 minimum 非零或 maximum 出现时产生拒绝结果，符合该节要求的处理分支。

历史字符年龄通过 RFC 3454 附录 A.1 静态范围冻结为 Unicode 3.2；纯豫生成器从官方文本提取范围，原始字符和规范化后字符均检查未分配范围。

后续源码事项：大小写折叠目前复用仓库统一码表；RFC 3454 附录 B.2 的历史折叠映射与历史规范化修订继续单独冻结。

依据：[RFC 5280 §4.2.1.10 与 §7.1](https://www.rfc-editor.org/rfc/rfc5280)、[RFC 4518](https://www.rfc-editor.org/rfc/rfc4518)。基本测试补中文、完整折叠与全角兼容合成断言；全量与原生验证单独登记。
