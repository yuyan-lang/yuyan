# 通用名称身份比较

签发者名称之通用名称相等，受二通名编码节点，还其同类身份等否。通名列交合，验二列有相等身份否。

DNS 先小写，乃验域名与等值。邮箱留本地部分，域部以小写比。URI 方案及主机小写，用户、端口、路径、查询、片段皆存其值。目录名循目录规范；IP 比四或十六字节网络序之载；注册标识比所解对象之号。otherName、x400Address、ediPartyName 以构造节点全 DER 比其身份。

此术供发行者选择及吊销范围核对共用。子树约束循名称约束之规。

所据：[RFC 5280 通名及名称比较之规](https://www.rfc-editor.org/rfc/rfc5280.html)。
