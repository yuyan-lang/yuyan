# 对称算法之装箱值域

豫言回收运行时以 `[-2^30, 2^30-1]` 内之整数为 i31，余整则装于含 i64 之回收结构。秘密运算诸中值，须恒居其一域，乃得同一装箱之路。下文据源码及今运行时之规，推其值域。

## ChaCha20

内藏三十二位之词，恒带识 M=2^32，其域 `[M,2M-1]`。入字节在 `[0,255]`。高字先与二五六合而左移二十四位，得恒巨整，乃合低二十四位；以此装配代秘密原三十二位词之装箱。

- 加先得 `[2M,4M-2]`，掩存第三十三位及低三十二位，所得在 `[2M,3M-1]`，再以公掩移识还第三十二位。
- 异或先移乙词之识于第三十三位；二词异或，第三十二、三十三位皆一；存第三十二位及低三十二位，即复内词。
- 左旋之左移，存公移后之识，先掩低三十二位及其识，乃还 M。右移之中值在 `[2^(32-q),2^(33-q)-1]`；q=1、2恒巨整，q≥3恒i31。继而还 M。
- 出字依公位右移，掩二五五，恒归i31。

计数、流号、长与循环之位皆公。正文与密钥循定轮、定位之整算。认证解密之终歧路，依公开认证之果。

## Poly1305

内用十三肢，各十位。因子之肢至多一零二三；入消息后，积肢小于四零九六。各乘、乘五及部分和皆非负，全乘加之守界为 `13×4095×1023×5 < 2^29`。合所传进位，仍在i31之域。

末肢卷积用普通因子，全和与所传进位小于2^26，故终进位小于六五五三六。折还低肢后，第二肢小于一三四四；次消息块入后，小于二三六七，归纳得积肢恒小于四零九六。终约减之候选末肢、择掩与所得字节，亦恒居i31。
