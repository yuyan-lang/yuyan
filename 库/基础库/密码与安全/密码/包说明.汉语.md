# 密码

本包提供纯豫言密码算法。所有字节数组元素为零至二百五十五的整数，长度由调用者显式提供，输出长度由算法或调用参数确定。

`字节` 模块提供复制、拼接和常数时间比较。比较依次扫描公开长度的每个位置，累积全部异或差异，最后返回相等结果。调用者保证数组实际长度足够。

`派生` 模块提供 HMAC-SHA256、HKDF-SHA256 与 PBKDF2-HMAC-SHA256。密钥垫逐位置异或常数，循环和访存由公开长度决定。HKDF 的输出长度遵从 RFC 5869 的 8160 字节上界。安全参数、长度与迭代次数为公开数据。PBKDF2 要求迭代次数为正整数。

`通用派生` 的 `HMAC` 接收散列函数、块长、摘要长、密钥数组、密钥长、消息数组、消息长。`HKDF提取` 接收散列函数、块长、摘要长、盐数组、盐长、材料数组、材料长。`HKDF展开` 接收散列函数、块长、摘要长、提取密钥数组、信息数组、信息长、输出长。散列函数接收字节数组与长度，返回定长摘要；调用者提供与算法一致的块长和摘要长。SHA-256 使用 64、32，SHA-384 使用 128、48。展开输出最多为摘要长度的 255 倍。

散列模块提供 SHA-1、SHA-224、SHA-256 与 MD5；宽字散列提供 SHA-384、SHA-512、SHA-512/224 与 SHA-512/256；海绵散列提供四种 SHA-3 与两种 SHAKE；BLAKE散列提供 BLAKE2b、BLAKE2s、BLAKE3 与扩展输出。MD5 与 SHA-1 可用于旧格式校验，安全签名选择后续安全散列。MD5 的碰撞安全性已失效。各散列按公开长度遍历输入、按公开轮号取常数，秘密字值经固定整数算术变换。

`定宽RSA` 提供定宽蒙哥马利模幂，`公钥` 提供 PKCS#1 v1.5 与 PSS 签名及验签、OAEP 加密及解密。秘密指数的每个位执行相同的乘法次数，以掩码选择结果，循环与访存仅依公开位宽。详情和验证见《公钥算法》。`口令内存` 提供 scrypt，完整扫描记忆块以保持公开访存，详情见《口令内存》。密码库验收等级仍在实施中，高级密码算法随后补齐。

`对称`、`认证` 提供 ChaCha20、XChaCha20、Poly1305 与两种认证加密，以及系统安全随机播种的随机源。`AES` 提供三档密钥块加解密、CTR、CBC 与 GCM。`曲线` 提供 X25519，爱德模块提供 Ed25519 公钥、签名及严格验签。总集导出各模块已实现的常用入口；具体参数与向量见《对称算法》《曲线说明》。秘密中间值的装箱区间证明与生成代码恒时核验逐项实施，详见《恒时值域》。

实现依据 RFC 2104、RFC 5869、RFC 8018。测试包含 RFC 4231 的首组 HMAC 向量、RFC 5869 的首组 HKDF 向量与 PBKDF2 两组标准向量。文档中的算法名称沿用标准。源码由本项目编写，遵从仓库许可。完整算法清单、原生验证、裸机验证、迁移与性能记录留待后续实现与验收。
