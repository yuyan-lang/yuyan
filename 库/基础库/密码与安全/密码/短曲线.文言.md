# 短曲线

此以纯豫言行 P256、P384、P521 之 ECDH 与 ECDSA。参数依 [SEC 2 二版](https://www.secg.org/sec2-v2.pdf)，定签之态与候选依 [RFC6979](https://www.rfc-editor.org/rfc/rfc6979.html)。

`密码/短曲线` 有 `ECDH公钥(曲线位数, 私钥数组)` 与 `ECDH(曲线位数, 私钥数组, 对方公钥数组)`，还或可有之字节数组。`密码/短曲线签名` 有 `ECDSA验签(曲线位数, 公钥数组, 摘要数组, 摘要长, 签名数组)`，还爻。`密码/短曲线确定签名` 有常用 `ECDSA签名(曲线位数, 私钥数组, 摘要数组, 摘要长)`，还或可有之签名数组。

曲线公位数取 256、384、521。私钥、共享横坐标与签中各数，依次占三十二、四十八、六十六字节，皆大端。公钥用 SEC1 非压缩之形，长六十五、九十七、一百三十三字节。签用定宽 r 合 s；协议可化之为 ASN.1 DER。入数组须具所约之容量，诸项为零至二百五十五之字节，有效长由协议之召者核之。摘要自最高位截至阶位数；常签之 HMAC 依曲线用 SHA256、SHA384、SHA512。

解公钥验其形首、规范坐标与曲线之式，所用标准曲线余因子皆一。私钥出范围、无穷点、形误、签数零或逾阶，皆还败。验私钥之范围成零一掩；非法私钥以一替之，尽行定宽点算，终还败。受拒之果皆公开输出。

点算用 Jacobian 坐标，倍点用 a 为负三之术。合点并算常合、倍点与无穷，以掩治同点、互负与无穷。标量之诸公位皆行倍、合与掩择。域逆以公模减二为指数，循公肢宽定行平方、乘与掩择。

常定签定算三十二候选，各尽行 HMAC、点乘、逆与签算。内签核还零一有效位与定宽签字节，并验私钥、候选范围及 r、s 非零；以掩取首全有效之签。各依 RFC6979 拒后之 K、V 术逐进，r、s 为零亦进次项。池中秘值惟制掩；循数及访序皆由公宽定。三十二项皆无效，终于公果之界还可无。后续之事：广定池以容更多连拒。显式随机数惟内签核受之；常公口行定签。

域算复用密码定宽RSA之带标十六位积与 Montgomery 乘。诸肢零至六五五三五；加减、倍、借与掩之中数皆在 i31 之域。乘前两数各增六五五三六，乃定偿而还二之三十二次方与原积之和；积与偿之诸中数皆行大数装箱。乘累之数在二之三十二次方至二之三十三次方减一间，析进位而去定标。秘密数组之序皆由公肢序定，秘值惟制掩。

此验依正式 yybs 2068413db 之 RSA 与散列，独树惟取短曲线十篇。包审、密码全类检与试入口之构皆过；三族 RFC6979 公钥、定随机数签核、三十二定候选常签、ECDH 单位标量、零倍与阶倍基点、阶减一倍互负、非法私钥、零随机数签核、无穷形、零签、r 或 s 等于阶及摘要改动之断言，皆于同客体 Node 与硬浮原生实过。全日志、工具及产物之散列，见《短曲线核验结果.汉语.md》。全散列秘密之表示、所生机器码、机器恒时与效量，仍待专核。
