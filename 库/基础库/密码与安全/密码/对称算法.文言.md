# 流密码与认证

`对称` 有 ChaCha20、HChaCha20、XChaCha20 及明授种之 ChaCha20 随机源。字节以整数数组引载之，调用者明授入长，密钥定三十二字节，ChaCha20 随机数定十二，XChaCha20 定二十四。

`夏夏二十块` 受密钥、公块数与随机数，归六十四字节之块。`夏夏二十`、`扩展夏夏二十` 受密钥、块数、随机数、输入及长，归等长所得。`创建夏夏随机源` 受三十二字种、十二字公流号；`夏夏随机块` 归次块而增三十二位计数。调用者须在计数尽前再播其种，系统安全随机播种之裹与计数扩展待续。

`认证` 之 `Poly1305` 受三十二字一次之钥、消息数组及长，归十六字认证之签。密钥以标准掩之，内用五个二十六位肢，乘、进位与终约减皆以定次数整算行之。秘密之值参与位算与整算，数组之位及循环之界依公长、公位。一次之钥每消息用一次。

核验有 RFC 8439 ChaCha20 块向量、Poly1305 消息及空消息向量，已于 pit-mac 诺节实跑而过。源码本于 RFC 8439 算法之规范，自编而成，许可从仓库。认证加密、原生及裸机核验、性能测量待续。
