# 流密码与认证

`对称` 有 ChaCha20、HChaCha20、XChaCha20 及明授种之 ChaCha20 随机源。字节以整数数组引载之，调用者明授入长，密钥定三十二字节，ChaCha20 随机数定十二，XChaCha20 定二十四。

`夏夏二十块` 受密钥、公块数与随机数，归六十四字节之块。`夏夏二十`、`扩展夏夏二十` 受密钥、块数、随机数、输入及长，归等长所得。`创建夏夏随机源` 受三十二字种、十二字公流号；`夏夏随机块` 归次块而增三十二位计数，溢则进于九十六位流号。`创建密码随机源` 取系统安全随机三十二字为种；`密码随机字节` 受源及长，归所需字节。

`认证` 之 `Poly1305` 受三十二字一次之钥、消息数组及长，归十六字认证之签。密钥以标准掩之，内用十三个十位肢，乘、进位与终约减皆以定次数整算行之。秘密之值参与位算与整算，数组之位及循环之界依公长、公位。一次之钥每消息用一次。ChaCha20 三十二位秘密词皆附定高位标，其间值装箱之界见《恒时值域》。

`ChaCha20Poly1305加密`、`XChaCha20Poly1305加密` 依次受钥、随机数、附加数据及长、明文及长，归密文与十六字之签。其解密依次受钥、随机数、附加数据及长、密文及长、签，验成则归明文，验败则归空值。

核验有 RFC 8439 ChaCha20 块、Poly1305 消息及空消息、ChaCha20Poly1305 向量、XChaCha20Poly1305 草案向量、坏签与坏附加数据之拒、计数扩展及安全播种，已于 pit-mac 诺节实跑而过。源码本于算法之规范，自编而成，许可从仓库。生成码恒时核验、原生及裸机核验、性能测量待续。
