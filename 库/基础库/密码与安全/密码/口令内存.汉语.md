# 内存口令派生

`口令内存` 模块提供 RFC 7914 的 scrypt。接口参数依次为口令数组、口令长度、盐数组、盐长度、容量 N、块数 r、并列数 p、输出字节数。N 为大于一的二次幂，r、p 为正整数。数组长度与输出长度为非负公开数据。

实现包含 PBKDF2-HMAC-SHA256、Salsa20/8、BlockMix 和 ROMix。ROMix 选择秘密位置时，完整扫描所有记忆块，以算术掩码合并所选块；各分支与访存地址只由公开参数及循环位置决定。此法保留标准输出，记忆读取次数随 N 的平方增长。调用者按机器内存和可接受耗时选择公开参数。

测试采用 RFC 7914 的空口令、空盐、N=16、r=1、p=1、输出64字节向量，以及系统 OpenSSL 4.0.3 对照的 N=16、r=2、p=2、输出32字节向量。源码由本项目编写，遵从仓库许可。更大参数的性能测量和裸机验收留待后续实施。Argon2id 留待后续版本实现。
