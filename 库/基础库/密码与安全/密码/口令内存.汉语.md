# 内存口令派生

`口令内存` 模块提供 RFC 7914 的 scrypt。接口参数依次为口令数组、口令长度、盐数组、盐长度、容量 N、块数 r、并列数 p、输出字节数。N 为大于一的二次幂，r、p 为正整数。数组长度与输出长度为非负公开数据。

实现包含 PBKDF2-HMAC-SHA256、Salsa20/8、BlockMix 和 ROMix。ROMix 选择秘密位置时，完整扫描所有记忆块，以算术掩码合并所选块；各分支与访存地址只由公开参数及循环位置决定。此法保留标准输出，记忆读取次数随 N 的平方增长。调用者按机器内存和可接受耗时选择公开参数。

Salsa20/8 的秘密32位词携带第32位标记，入词、模加、异或、旋转和 ROMix 合并都保持定域表示，出字节时取低八位。模加与旋转沿用《恒时值域》的逐中间界；Salsa 旋转位数为7、9、13、18，左移范围固定落入大整数路径，右移范围固定落入小整数路径。选择掩码为零或负一，先加三倍标记，再异或二倍标记，所得为标记减一或标记，两者均落大整数路径；再或标记，形成带标记的零或全一低词。源词与其相与、同选择词相或均保留标记。可执行的单数组容量使 N 小于二的三十二次方，整数化用低词取公开 N 的掩码，位置及差值保持小整数范围。超单数组容量的分段实现留待后续版本保留高词。

单数组采用32位元素数量，每个记忆块占32r个词且r至少为一，成功分配的N个记忆块满足N×32r小于二的三十二次方，因此N小于二的二十七次方。秘密位置、同位比较的异或差及其负值均落i31范围；前述低词整数化和掩码比较据此成立。

此定域改写已完成排版与差异静查，最新25a843完整配套链的包检查与整包类型检查通过。RFC7914最短与N16r2p2两组向量已在Node和同客体原生运行通过，固定SHA依赖参与联验。生成代码装箱路径、机器时序恒时及大参数性能另行核验，正式证据见《口令固定整合记录》。

测试采用 RFC 7914 的空口令、空盐、N=16、r=1、p=1、输出64字节向量，以及系统 OpenSSL 4.0.3 对照的 N=16、r=2、p=2、输出32字节向量。源码由本项目编写，遵从仓库许可。更大参数的性能测量和裸机验收留待后续实施。Argon2id 留待后续版本实现。
