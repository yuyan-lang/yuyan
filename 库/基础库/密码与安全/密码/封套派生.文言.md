# OpenSSH 封套口令派生

此为 OpenSSH 私钥封套内部 bcrypt_pbkdf 之辅术。模块密码封套派生之 `封套口令派生(口令数组,口令长,盐数组,盐长,轮数,输出长)`，还或可有之字节数组。诸长与轮数皆公整数，诸入项为零至二百五十五字节；口令盐之有效长皆正，轮数正，所出一至一零四八五七六字节。召者备足数组容量。总集存既有公算法之口。

口令先行 SHA512。所出诸列，以大端四字节之计数附盐而行 SHA512；散列块用 Blowfish 初态，先合盐口令而扩一次，又六十四次更用盐口令而扩，乃密固定三十二字节正文六十四次。诸轮所出依三十二位词之小端写之。外轮以 SHA512 散前出而复算块，累异其果；所出依公 stride 交织。内零字节依有效长而受之。

Blowfish 十八P词与四组二百五十六S词，皆用带第三十二位标之三十二位词。秘S盒之序，逐盒定扫二百五十六项，诸项拆为二肢、各十六位，在i31之域以掩累之；终先为高肢添第十六位而左移十六，乃合低肢，径成定大整数词。Feistel诸轮、扩展、字节载出与秘中数之类，详于《封套派生核验》。

一手法据为 OpenBSD 之 [bcrypt_pbkdf.c](https://raw.githubusercontent.com/openbsd/src/master/lib/libutil/bcrypt_pbkdf.c) 与 [blowfish.c](https://raw.githubusercontent.com/openbsd/src/master/lib/libc/crypt/blowfish.c)。Pi常量为公数学数据。纯豫草稿之器，自初态结构取S千二十四词、P十八词，核总数与首S、首P、末P；生产初态乃排P而后S。参考与生成器存本树草稿之 `yy吹鱼参考.txt`、`yy封套常量生成。豫`，皆临时之材。

作者向量取 [OpenBSD bcrypt_pbkdf_test.c](https://raw.githubusercontent.com/openbsd/src/master/regress/lib/libutil/bcrypt_pbkdf/bcrypt_pbkdf_test.c)。先核Pi之位、S首末扫描、参数拒绝及[作者站Blowfish ECB向量](https://www.schneier.com/wp-content/uploads/2015/12/vectors-2.txt)全零全一二例；八字节复钥展为六十四字节同周期之流，惟试内扩态之术。参“底核”则惟行此较廉之核。常试乃行口令password、盐salt、四轮、三十二字节之向量。参“完整”则加零字节、截长、六十四字节交织与二进制口令盐，共八派生向量。

今算法、测试与草稿之器皆轻排过，Pi初态常量之模块待生成器构建运行之期。类检、常与完整向量、机器码及实效皆待统筹。定S扫描较径表之效差，将以实行为录。
试参“封套”，行底核及OpenSSH所须四十八字节之派生验。定期值取作者六十四字节、八轮之先四十八字节；二长之步幅皆二，诸列所受与轮数同，前二十四行之交织位同。此验覆三十二字节AES钥与十六字节IV之相接长。
