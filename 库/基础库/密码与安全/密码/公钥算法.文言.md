# RSA 公钥制码

`公钥` 具 PKCS#1 v1.5 签名制码与审码、PSS 签名制码与审码、MGF1 掩码及 OAEP 加密制码。

字节以整数数组引用载之，各数自零至二百五十五，其长明授。RSA 第一版之摘要序为全 ASN.1 DigestInfo；审码须有八 FF 字节以上，依定位审其分隔与摘要序。PSS 受消息摘要、散列术、散列长与定盐长；码位数取模位数减一。散列术受字节数组及其长，还定长摘要。MGF1 计数以四字节大端载之。盐及 OAEP 种皆取安全随机，种长同散列长。

此诸术为 RSA 制码之层。公钥模幂既接，验签先作公钥运算，而后审码。私钥运算、造钥、OAEP 解码、ML-KEM 与 ML-DSA 俟后成之。

所审者为公开签名代表元，公数之较可先止。MGF1 与制码之复制、异或循公开之长访数组。私钥运算须定宽常时，大数包唯供公钥运算。

测试审第一版最短合法填充与坏填充、MGF1 零计数及末块截断、PSS 定盐长与坏尾字节。样本散列唯验码之序；正散列与外来 RSA 向量之互通俟后验之。
