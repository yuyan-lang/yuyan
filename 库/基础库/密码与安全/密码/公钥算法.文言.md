# RSA 公钥诸术

`公钥` 具 PKCS#1 v1.5 与 PSS 签名、验签，MGF1 掩码及 OAEP 加解密。`定宽RSA` 具十六位肢体蒙哥马利模幂。

字节以整数数组引用载之，各数自零至二百五十五，其长明授。模数以大端载之，无前零，为奇而过一。公指数亦大端。秘指数依模字节长左补零，签名、解密所受指数长须同模长。钥数用者自授。

RSA 第一版之摘要序为全 ASN.1 DigestInfo；审码须有八 FF 字节以上，依定位审其分隔与摘要序。PSS 受消息摘要、散列术、散列长与定盐长；码位数取模位数减一。散列术受字节数组及其长，还定长摘要。MGF1 计数以四字节大端载之。盐及 OAEP 种皆取安全随机，种长同散列长。

公钥验签先审签名长、模之表示及代表元之域，乃行公钥模幂而审码。签名、OAEP 加密还模长数组，公参长有失则还空数组。OAEP 解密还消息数组与其长，复与成败爻相合为嵌套二元组。

定宽模幂每指数位皆平方且乘，以位掩码择其果。蒙氏乘、减与复制之循皆依公宽访数组，秘指数位唯参位运算。秘钥运算之循数由模长定。OAEP 先循定长审标签与填充，末乃一判成败；成后依已释消息长复制而还。公签名代表元之较可先止。

测试审第一版最短合法填充与坏填充、MGF1 零计数及末块截断、PSS 定盐长与坏尾字节、复模之签验与 OAEP 加解密、坏标签之拒、二百组独立整数模幂参照及满肢进位之界。复以 OpenSSL 所制 RSA2048/SHA256 第一版与 PSS 签名验互通，审坏盐长及篡改签名之拒。

造钥、ML-KEM 与 ML-DSA 俟后成之；性能测量与优化俟后录之。
