# 曲线之术

`曲线` 篇供 X25519 与 X25519公钥。参及所得皆整数数组，长三十二，各项一字节。私钥先录而依 RFC 7748 钳之，原数组仍存。公钥最高位依其法清零，所得以小端正编码出之。

治密源码用十六肢，各十六位；蒙哥马利梯凡二百五十五轮。互易以掩码遍诸肢，密位唯入掩码之算。源码中域乘、逆元与编码，其轮数及访存之序皆由公开定轮决之。用者验输入之长，得共享之密则定遍比其全零，乃付派生。

今回收运行时依整数之值择 i31 与完整 i64 装箱，域乘中值入其途。机器恒时之验，俟固定整数之实现、所生码之审及计时之核；提案甲乙恒时之门，俟此验成。

验取 RFC 7748 第六点一节 Alice、Bob 之公钥及两向共享之密。法与向量本于 RFC 7748；此篇以豫言作，许可从仓中 LICENSE。

`爱德曲线` 篇供 Ed25519公钥，种子三十二字节，生公钥亦三十二字节。用既有定宽域术，取扩展坐标完整加点与定二百五十六轮掩码梯；种子经 SHA-512，乃依 RFC 8032 钳之。公钥验取 RFC 8032 第七点一节首向量，于 pit-mac 节点宿主行之皆过。

后续之事：Ed25519 签名与验签、P-256、P-384、P-521，Wycheproof 相关全验及差分之验，原生与裸机之验、性能之量。
