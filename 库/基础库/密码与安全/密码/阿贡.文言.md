# Argon2id

`Argon2id` 行 RFC 9106 十九版之法。受口令、盐与其有效字节之长，次受 KiB 记忆、轮数、逻辑并列数、所出字节之数。

`Argon2id完整` 于口令、盐后受秘密与其长、附材与其长，次受四项资用。并列数一至三三五五四四三二，记忆其八倍至二六八四三五四五六 KiB（二百五十六 GiB），轮数正，所出至少四字节。资用皆公值，可分配之量由平台定之。

记忆分四片，诸片循逻辑并列之序填之。初二块、独立地址之段、依材取址之段、复轮旧块之异或、终块之合，皆循标准。秘密所引，尽察记忆，以定序与整数掩码取之。

秘六十四位词用两带定标之三十二位肢。BlaMka之低三十二位乘，以四带标十六位积与定进位合之；宽加、异、转与扫描之择，皆保定装箱之类。秘引用号之余，定三十二步二进而求。J1之平方与引用面积之积常带标，高三十二位既证少于公面积，乃化为i31小数。索引与掩皆在定i31之域。BLAKE2b与H′依定标散列之术。诸中数之域见《阿贡恒时核验》。

定形之术已由25a843全套诸器核包并尽检其类。RFC9106第五章三节之全向量，用三十二KiB、三轮、四并列，具秘密及附材；此向量与带标词边界皆于Node及同客体原生核过，输出皆同。轻排与差异之核已过。机器码、运行时之路与实际效量，留后核之，证见《阿贡恒时核验》。

BLAKE2b 以所定摘要之长入初参。长摘要循 H′ 连锁而展之。

法据：[RFC 9106](https://www.rfc-editor.org/rfc/rfc9106.html)。
