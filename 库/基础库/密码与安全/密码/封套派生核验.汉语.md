# 封套 bcrypt_pbkdf 源码核验

记录当前待执行验证的实现。算法来源是 OpenBSD 官方一手实现，密码与盐的输入有效长度、迭代轮数、输出长度、块数及查表遍扫序均为公开值。

## 初态与数据顺序

公开参考初始化数据顺序为四S盒共1024词，随后P18词。纯豫生成器仅取 `static const blf_ctx initstate` 至 `*c = initstate;` 的结构区间，逐项检验八位小写十六进制、精确1042项及首S d1310ba6、首P243f6a88、末P8979fb1b。生产状态顺序取P0..17，再S0..1023。初始化解析处理公开常量，秘密扩展前附固定标记。

## 装箱类别

所有秘密三十二位词代表2^32加uint32，始终处于Big区间。秘密字节在[0,255]，载入最高字节先位或256得[256,511]，再左移24位得[2^32,2^33−2^24]，随后合低三字节仍为Big。加法、异或及移位复用定标32原语的逐中间量证明。公开初态解析与公开计数属于公开路径。

S盒固定扫256项，秘密目标字节与公开位置异或差为[0,255]，负差为[−255,0]，非零与0/−1掩码均i31。带标S词与65535相与后[0,65535]；带标S词右移16位为[65536,131071]，再与65535相与为[0,65535]。两肢与秘密掩码相与仍在[0,65535]，两个累积肢位或亦在此域。扫描结束高肢位或65536得到[65536,131071]，左移16位直接落入[2^32,2^33−2^16]，再与低肢相或得到完整带标Big词。每一步装箱类别固定，全部访存下标是公开盒号与扫描位置。

Feistel 每轮使用四S盒固定扫，十六轮按公开轮号运行。轮结果先加两带标词，再带标异或，再加末词，全部用定标原语。P键混合的字节下标和P位置由公开轮次决定。状态扩展每次处理18个P与1024个S，连续盐字节序保持跨P、S区间推进，所有写入下标公开。

## 派生与输出

口令作一次SHA512。首盐为盐加大端32位列计数，后轮盐为前轮32字节输出；盐与口令预散列都为64字节。每个散列块先带盐扩态一次，依盐、口令次序作64对无盐扩态，再把OxychromaticBlowfishSwatDynamite的八个大端词加密64次。最终八词按小端写32字节。外层轮异或按字节执行，输出索引i×stride+count−1均公开。

## 固定工作量

每次扩态处理1042词，成对更新，执行521个密块。一个散列块执行一次有盐扩态和128次无盐扩态，随后对四个正文密块执行64轮，共129×521+64×4=67465个密块。每个密块16轮，每轮四盒各扫描256词，故一个散列块固定读取1105346560项S词。32字节、四轮的基础派生共有4个散列块，读取4421386240项；48字节、八轮的封套向量 stride 为二，共16个散列块，读取17685544960项。这里计算源码的公开固定循环工作量，运行耗时与机器实际访存仍待测。

单项ECB检查包含一次无盐扩态与一次密块，共522个密块，读取8552448项S词。先跑两项ECB可以定位Pi初始化、Feistel方向和扩钥，随后再单独执行派生模式。

## 验证阶段

纯豫算法、测试与临时生成器均轻量格式化通过。生产Pi常量模块尚待窗口运行生成器；当前源码依赖该待生成模块。先写作者站全零/全一两项Blowfish ECB向量：测试将八字节重复钥铺为六十四字节同周期流，直接调用内部expand0，一次只需521次密块计算与约8.5百万项读取。传“底核”只执行Pi、扫描、拒绝及这两项底核。默认再执行基础32字节四轮派生向量，完整参数增加其余派生向量，共八项。类型检查、执行、机器码及性能待统筹窗口，当前仅提供源码区间证明。固定S扫描每个bcrypt散列块约需十亿项读取，实际耗时与参考实现倍率必须据执行记录。
