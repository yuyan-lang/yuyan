# 密码

此包以豫言行密码之术。字节数组之元素皆零至二五五，调用者明授其长，所得之长依术或所授参数而定。

`阿贡` 有Argon2id十九版之口令派生，全口具秘密与附材。记忆引用循定序全扫，秘六十四位词用双标三十二位肢，引用之余定三十二轮而求。完整RFC9106向量与积、进位、余、扫之边界，皆于Node及同客体原生核过；参数与证见《阿贡》《阿贡恒时核验》。生成码及机器时序之恒时审，留后验之。

散列、宽字散列与BLAKE散列之秘密三十二位词，皆具第三十二位定标；六十四位词用双标肢。正式海绵之口用私有定形核。已有三十四官方散列向量及定标移位、进位之试，皆以25a843配套链于Node及同客体原生核过；证见《散列固定表示整合记录》。值域之证述源中诸间数；生成码与机器时序之恒时审，留后验之。
`封套派生` 为 OpenSSH 私钥封套内部 bcrypt_pbkdf 之辅术，复用正式私有定形词算与 SHA512。Pi公常数以纯豫之器依定原件生之，审千四十二项。作者 Blowfish ECB四例、Pi之位、定扫及拒参底核，皆于 Node 与同客体硬浮原生实过；全派生官例、封套首用与效量续验，见《封套派生核验结果》。总集存既有术之口。

`字节` 有复制、合接与恒时比较。比较循公长之诸位，积其异或之差，终还相等之值。调用者须使数组实长足用。

`派生` 有 HMAC-SHA256、HKDF-SHA256、PBKDF2-HMAC-SHA256。密钥垫逐位与常数异或，循环与取址皆依公长。HKDF 所得之长依 RFC 5869，以八一六零字节为界。安全参数、长度与迭代之数皆公。PBKDF2 迭代之数须正。

`通用派生` 之 `HMAC` 受散列之函数、块长、摘要长、密钥数组及长、消息数组及长。`HKDF提取` 受散列之函数、块长、摘要长、盐数组及长、材料数组及长。`HKDF展开` 受散列之函数、块长、摘要长、提取密钥数组、信息数组及长、所得之长。散列函数受字节数组及长，归定长摘要；调用者所授块长、摘要长须合其术。SHA-256 用六四、三二，SHA-384 用一二八、四八。展开之长至多为摘要长之二五五倍。

散列有 SHA-1、SHA-224、SHA-256、MD5；宽字散列有 SHA-384、SHA-512、SHA-512/224、SHA-512/256；海绵散列有四种 SHA-3、二种 SHAKE；BLAKE散列有 BLAKE2b、BLAKE2s、BLAKE3 及扩展所得。MD5、SHA-1 可核旧制，安全签名择后续安全散列。MD5 抗碰撞之性已失。诸散列循公长遍输入，按公轮取常数，秘密之字以定整算变之。

`定宽RSA` 有定宽蒙哥马利模幂，`公钥` 有 PKCS#1 v1.5、PSS 之签验与 OAEP 加解密。秘密指数之诸位，乘法次数皆同，以掩择所得，循环与取址惟依公宽。其详与核验见《公钥算法》。`口令内存` 有 scrypt，遍扫记忆以守公开之取址，其详见《口令内存》。密码库之验收级尚在实施，高级密码之术待续。

`对称`、`认证` 有 ChaCha20、XChaCha20、Poly1305 及二种认证加密，亦有系统安全随机播种之源。`AES` 有三档密钥块之加解密、CTR、CBC、GCM。`曲线` 有 X25519，爱德诸模块有 Ed25519 公钥、签名及严验。总集出诸模块已成之常用入口；参数与向量见《对称算法》《曲线说明》。秘密间值之装箱界证明与生成码恒时核验逐项行之，详见《恒时值域》。

此术本于 RFC 2104、RFC 5869、RFC 8018。测试用 RFC 4231 首组 HMAC 向量、RFC 5869 首组 HKDF 向量与 PBKDF2 标准向量二组。术名从标准。源码为本项目所作，许可从仓库。全术之目、原生及裸机核验、迁移与性能之录，待后续具之。

`格封装` 有 ML-KEM-768。解封之公长及秘钥公钥摘要校验误，以定公辞之异告之，呼者用标准库 `尝试运行` 而处；成乃读全三十二字，合法全零亦受为常果。合长密文之隐拒仍还三十二字共享钥。封装呼者先读真有效爻，乃消费全共享钥与密文，其详见《封装算法》。

AES-GCM生产认证恒行一百二十八轮，以十六八位肢行之；子密钥、任意长随机数之初计数与标签，秘密数据皆存字节数组。合积、移位、进位与归约之秘密间值恒守i31，详域见《认证定肢之说》。所生码与机器时序之恒时审，续行之。
