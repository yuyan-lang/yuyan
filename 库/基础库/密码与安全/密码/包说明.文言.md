# 密码

此包以豫言行密码之术。字节数组之元素皆零至二五五，调用者明授其长，所得之长依术或所授参数而定。

`字节` 有复制、合接与恒时比较。比较循公长之诸位，积其异或之差，终还相等之值。调用者须使数组实长足用。

`派生` 有 HMAC-SHA256、HKDF-SHA256、PBKDF2-HMAC-SHA256。密钥垫逐位与常数异或，循环与取址皆依公长。HKDF 所得之长依 RFC 5869，以八一六零字节为界。安全参数、长度与迭代之数皆公。PBKDF2 迭代之数须正。

`通用派生` 之 `HMAC` 受散列之函数、块长、摘要长、密钥数组及长、消息数组及长。`HKDF提取` 受散列之函数、块长、摘要长、盐数组及长、材料数组及长。`HKDF展开` 受散列之函数、块长、摘要长、提取密钥数组、信息数组及长、所得之长。散列函数受字节数组及长，归定长摘要；调用者所授块长、摘要长须合其术。SHA-256 用六四、三二，SHA-384 用一二八、四八。展开之长至多为摘要长之二五五倍。

散列有 SHA-1、SHA-224、SHA-256、MD5；宽字散列有 SHA-384、SHA-512、SHA-512/224、SHA-512/256；海绵散列有四种 SHA-3、二种 SHAKE；BLAKE散列有 BLAKE2b、BLAKE2s、BLAKE3 及扩展所得。MD5、SHA-1 可核旧制，安全签名择后续安全散列。MD5 抗碰撞之性已失。诸散列循公长遍输入，按公轮取常数，秘密之字以定整算变之。

`定宽RSA` 有定宽蒙哥马利模幂、PKCS#1 v1.5、PSS 之签验与 OAEP 加解密。秘密指数之诸位，乘法次数皆同，以掩择所得，循环与取址惟依公宽。其详与核验见《公钥算法》。`口令内存` 有 scrypt，遍扫记忆以守公开之取址，其详见《口令内存》。密码库之验收级尚在实施，密钥生成、认证加密与高级密码之术待续。

此术本于 RFC 2104、RFC 5869、RFC 8018。测试用 RFC 4231 首组 HMAC 向量、RFC 5869 首组 HKDF 向量与 PBKDF2 标准向量二组。术名从标准。源码为本项目所作，许可从仓库。全术之目、原生及裸机核验、迁移与性能之录，待后续具之。
