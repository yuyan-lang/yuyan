# 海绵固定表示衔接记录

本轮将候稿563d42259的双32位定标海绵算法收敛为私有实现，接入正式海绵散列的六个SHA3/SHAKE入口。原输入输出签名、字节数组别名、算法速率、域分隔与输出长度保持；旧内部海绵函数、其他散列及包/总集/宿主接口保持。本记录是源码与范围推导，类型、Node/native向量、生成码与机器恒时验证继续等待窗口。

私有文件为《海绵定标。豫》《海绵核。豫》，来源563d42259的定标与海绵候稿，内部名称分别加海绵/定形前缀。正式《海绵散列。豫》仅增加私有核导入，将六个入口的摘要调用接至定形海绵摘要；旧内部函数保留供现有调用及公开数据回归。没有带入BLAKE、宽字散列或原公钥树的临时散列副本。

## 表示及逐中间箱类

令M=2^32。每个秘密32位肢表示为M+x，0≤x<M；64位词为两个这样的整数元组，低肢在前。每肢恒处[M,2M−1]，在WasmGC中恒为大整结构，元组字段的表示与分配形状固定。吸收入口字节满足0至255，先与M置标，随后按公开字节位置移动双肢；秘密状态始终保留标记。公开Keccak轮常数允许通过宽公值转换，秘密输入使用宽字节入口。

| 运算 | 每个中间值及箱类 |
| --- | --- |
| 异或 | 将乙与3M异或，得[2M,3M−1]；与甲异或得[3M,4M−1]；与2M−1掩位还[M,2M−1]，三者恒大整 |
| 与、或 | 两个标记位均为一，结果[M,2M−1]，恒大整 |
| 非 | 原反值[-2M,−M−1]恒大整；与3M−1后[2M,3M−1]恒大整；与3M异或还[M,2M−1] |
| 左移1至30 | 移值保公开第32+s位，正数至少2^33；保标掩位仍带该公开位，去旧标添M后还[M,2M−1]，均大整 |
| 左移31 | 原移值以第63位为一，signed值至多−2^31，恒大整；保标后的值含固定符号位，最后换标还[M,2M−1] |
| 右移1、2 | 移值分别在[2^31,2^32−1]、[2^30,2^31−1]，均恒大整；换公开移标后还[M,2M−1] |
| 右移3至31 | 移值在[2^(32−s),2^(33−s)−1]，整个区间在i31内；该公开s对应固定小整路径，换标后还[M,2M−1] |
| 挤出取字 | 公开字号决定肢与移数0/8/16/24；未掩字的右移值分别恒大整/恒i31/恒i31/恒i31，最后与255为i31 |

零移、至少32位的短肢移位及宽肢32/64边界分支只依公开移数。双肢旋转使用公开Keccak旋转表，按公开半字选择、移动、或合；秘密值不选择肢或地址。相关加法辅助中的低和、高和始终至少2M，进位由公开位32右移后低一位提取为0/1，不剥离裸32位秘密肢。

私有置换固定24轮，行、列、轮常数下标和交换位置都由公开计数决定；吸收填充及挤出块数由公开输入、输出长度与速率决定。所有整数除余的输入是上述公开计数，秘密状态使用异或、与、非和固定公开移位。规范字节路径没有先剥裸64位秘密状态的步骤。

## 候窗测试及剩余证据

《海绵定形边界。测试》从563候稿保留独立公开整数参考，覆盖七个32位端点的全部0至31移位/旋转与六个64位端点的全部0至63移位/旋转，以及取反、异或、跨肢加法进位。参考裸整数均为公开测试常量，功能对照与机器恒时证据分别记录。

《海绵接线。测试》用旧正式内部海绵核作为公开确定样本的独立表示回归参照，覆盖两种速率前一字节、恰一块、多一字节及多块吸收，输出覆盖0、1、32及跨挤出块边界。此回归只查表示和接线；官方输出预期继续使用NIST固定原件的格封装/格签全字段向量，以及原正式散列测试的已存在SHA3/SHAKE向量。

下一窗口应先类型检查海绵入口闭包，再串行构建运行海绵定形边界、海绵接线、散列测试及格封装官方测试，接着格签官方测试。此轮没有执行这些命令。机器码、GC分配行为、目标机运算时序及整体密码安全验收仍待核实；静态箱类推导属于待验证证据。
