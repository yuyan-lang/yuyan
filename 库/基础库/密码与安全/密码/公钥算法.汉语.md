# RSA 公钥算法

`公钥` 模块提供 PKCS#1 v1.5 与 PSS 签名、验签，MGF1 掩码生成，OAEP 加密与解密。`定宽RSA` 模块提供十六位肢体的蒙哥马利模幂。

字节表示采用整数数组引用，元素范围为 0 至 255，数组长度显式传入。模数采用无前导零的大端表示，模数是大于一的奇数。公钥指数采用大端表示。私钥指数按模数字节长度左补零，签名与解密入口要求指数长度等于模长。密钥参数由调用者提供。

RSA 第一版接口的摘要序是完整的 ASN.1 DigestInfo；校验要求至少八个 FF 填充字节，按固定位置逐字节核对分隔符与摘要序。PSS 接口接收消息摘要、散列函数、散列长度与固定盐长度，编码位数取 RSA 模数位数减一。散列函数的签名是“字节数组、输入长度 → 定长摘要数组”。MGF1 的计数器采用四字节大端表示。签名和 OAEP 编码所需的盐与种子由安全随机接口产生，OAEP 种子长度等于散列长度。

公开验签入口依次核对签名字节长度、模数表示与签名代表元范围，执行公钥模幂，再严格核对编码。签名和 OAEP 加密返回模长字节的数组；公开参数长度无效时返回空数组。OAEP 解密返回“消息数组与消息长度”及成功标志组成的嵌套二元组。

定宽模幂的平方与乘法每个指数位都执行，用位掩码选择结果。蒙哥马利乘法、减法与复制循环按公开肢体宽度访问数组；秘密指数位参与位运算。私钥运算的循环次数由模长决定。OAEP 解码先按固定长度扫描标签与填充，最后一次性返回成功或失败；成功后按已释放的消息长度复制输出。公开签名代表元的比较可以提前结束。

测试覆盖 v1.5 最短合法填充与填充损坏、MGF1 零计数器与末块截断、PSS 固定盐长度及尾字节拒绝、复合模数的签验与 OAEP 加解密往返、OAEP 错标签拒绝、两百组独立整数参考模幂及满肢进位边界。另以 OpenSSL 产生的 RSA2048/SHA256 v1.5 与 PSS 签名向量验证互操作，覆盖错盐长度与篡改签名拒绝。
