# RSA 公钥编码

`公钥` 模块提供 PKCS#1 v1.5 的签名编码与严格编码校验、PSS 的签名编码与严格编码校验、MGF1 掩码生成，以及 OAEP 加密编码。

字节表示采用整数数组引用，元素范围为 0 至 255，数组长度显式传入。RSA 第一版接口的摘要序是完整的 ASN.1 DigestInfo；校验要求至少八个 FF 填充字节，按固定位置逐字节核对分隔符与摘要序。PSS 接口接收消息摘要、散列函数、散列长度与固定盐长度，编码位数取 RSA 模数位数减一。散列函数的签名是“字节数组、输入长度 → 定长摘要数组”。MGF1 的计数器采用四字节大端表示。签名和 OAEP 编码所需的盐与种子由安全随机接口产生，OAEP 种子长度等于散列长度。

这些编码函数属于 RSA 的编码层。公开模幂接入后，验签入口先执行 RSA 公钥运算，再调用编码校验。私钥运算、密钥生成、OAEP 解码与 ML-KEM、ML-DSA 留待后续实现。

编码校验的输入是公开的签名代表元，公开字节比较可以提前结束。MGF1 与编码的复制和异或循环按公开长度访问数组。私钥运算使用定宽常数时间实现；大数包仅供公钥运算。

测试覆盖 v1.5 最短合法填充与填充损坏、MGF1 零计数器与末块截断、PSS 固定盐长度、PSS 尾字节拒绝。测试中的样本散列用来检查编码结构。正式散列与外部 RSA 向量的互操作核验留待后续验证。
