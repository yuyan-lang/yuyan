# 内存口令派生

`口令内存` 有 RFC 7914 之 scrypt。所授依次为口令数组及长、盐数组及长、容量 N、块数 r、并列数 p、所得字节数。N 须为大于一之二次幂，r、p 须正。数组长与所得长皆非负之公数。

此术备 PBKDF2-HMAC-SHA256、Salsa20/8、BlockMix、ROMix。ROMix 择秘密之位，必遍扫所记诸块，以算筹之掩合所选；歧路与取址皆惟依公参数及循环之位。所得合标准，记忆读取之数随 N 之平方而长。调用者度机器之藏与可受之时，以择公参数。

Salsa20/8 秘密三十二位词常附第三十二位之识，入词、模加、异或、旋转及 ROMix 合并皆守定域，出字节取低八位。模加及旋转之界从《恒时值域》；Salsa 移位为七、九、十三、十八，左移恒循巨整，右移恒循小整。择掩为零或负一，先加三倍识，再异或二倍识，得识减一或识，皆循巨整；复或识，成带识之零或全一低词。源词与之相与，择词与之相或，皆存其识。可行之一数组容使 N 小于二之三十二乘方，整数化取低词与公 N 之掩，位置及差恒在小整之界。逾一数组容者，分段之术存高词待续。

一数组以三十二位数其元素，每记忆块占三十二r词，r至少为一；N块既配成，则N乘三十二r小于二之三十二乘方，故N小于二之二十七乘方。秘密位置、同位比之异或差及其负值皆在i31界，故低词整数化及掩比之证成。

此定域之改，排版及差异静查已毕，最新25a843全套诸器之核包及整类检皆过。RFC7914最短与N16r2p2两向量，皆于Node及同客体原生核过，定形SHA亦与联验。生成码装箱路径、机器时序之恒时及大参性能，别验之，证见《口令固定整合记录》。

测试用 RFC 7914 空口令、空盐、N=16、r=1、p=1、所得六十四字节之向量，亦用系统 OpenSSL 4.0.3 对照之 N=16、r=2、p=2、所得三十二字节之向量。源码为本项目所作，许可从仓库。大参数之测时与裸机验收待续。Argon2id 待后续版本具之。
