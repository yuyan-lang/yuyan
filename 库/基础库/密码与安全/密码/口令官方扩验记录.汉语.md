# scrypt 官方扩集与小样本实测

独立工作树基础库-密码口令官方扩验以净生产4ae921a6a为基，生产代码保持。测试源码3dc97fd4b、93916294a、997271d69提供RFC7914 Salsa20/8、BlockMix、ROMix、PBKDF2一轮固定原件，以及三个大参数的显式模式。默认仅运行廉价子核及原有两短向量；官方期望来自[RFC7914第8至12节](https://www.rfc-editor.org/rfc/rfc7914.html)。测试公开模式曾误用不存在的布尔函数「或」，PBKDF2期望也曾把0b误抄为b0，均修正并格式化复核；生产代码未修改。

失败后先查询官方最新发布并下载完整86ff2dcf配套包，独立目录`yy链86`与缓存；官方digest与下载实值均为1f68d32f854239aa0982efa4f274c87b942c2bc94829dbbee4723e90afde3710，六host齐备，三个核摘要实际与此前25a相同。最终测试构建parent52534退出0，包含全部测试闭包类型。Node默认六组全部通过；指定只读完整host、E44/E801原器生成同guest，parent56428退出0，原生六组也全部通过，stdout一致。

## 实跑官方1024

显式模式 `官方1024` 使用password、NaCl、N1024、r8、p16、64字节。Node parent41736最终exit0，官方结果通过；其后原生parent96930最终exit0，结果通过，stdout一致。当前N16384、N1048576两模式保存精确公开期望，均尚未执行。后续N16384将在另一独树实跑；百万容量等待根按长期资源排期。

## 实测性能与待验量级

受信pit-mac为Apple M2 Max，测后负载54.01、66.38、78.25。用系统time工具串行执行，各进程还包含启动、默认六组核验及输出，单位为秒。两个小性能模式使用password、salt、r1、p1、32字节；Node/native输出分别一致。每组是一轮样本，资源干扰使wall值波动。

| 参数 | Node实耗／用户CPU | 原生实耗／用户CPU |
| --- | --- | --- |
| N1024 r1 p1 | 0.34／0.30 | 0.27／0.24 |
| N2048 r1 p1 | 1.22／0.61 | 1.79／1.06 |
| 官方N1024 r8 p16 | 20.70／14.40 | 41.86／35.39 |

官方1024的原生CPU耗时约为Node的2.46倍；原生性能差距已上报统筹，原器保持只读。ROMix扫描读取次数为p×N²×32r词：官方1024约4.295十亿词；N16384r8p1约68.72十亿词，为前者16倍；N1048576r8p1约281.475万亿词，为前者65536倍。按当前官方1024用户CPU作工作量外推，N16384约Node230秒、原生566秒，百万容量约Node11天、原生27天CPU；按wall约16天、32天。此为待实测量级估计，GC、缓存、内存规模与系统负载会改变耗时。

源码仍完整扫描秘密引用，不替换为秘密直索引。完整算法兼容、源码中间值区间和机器实际恒时分别登记；本轮没有按秘密分组比较时序，也没有完成生成代码及GC路径的机器恒时审计。正式输出、计时原件及完整链/guest/native摘要见 `测试/口令扩验证据/`，完整构建日志留远端本树及`.yy构建日志`。
