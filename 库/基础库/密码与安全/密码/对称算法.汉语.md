# 流密码与认证

`对称` 模块提供 ChaCha20、HChaCha20、XChaCha20 与显式种子的 ChaCha20 随机源。字节采用整数数组引用表示，调用者显式提供输入长度，密钥固定32字节，ChaCha20 的随机数固定12字节，XChaCha20 固定24字节。

`夏夏二十块` 接收密钥、公开块计数与随机数，返回64字节块。`夏夏二十` 和 `扩展夏夏二十` 接收密钥、计数、随机数、输入与长度，返回等长输出。`创建夏夏随机源` 接收32字节种子和12字节公开流号；`夏夏随机块` 返回下一个64字节块并递增32位计数，计数溢出时向96位流号进位。`创建密码随机源` 从系统安全随机取得32字节种子；`密码随机字节` 接收源与长度并返回所需字节。

`认证` 模块的 `Poly1305` 接收32字节一次性密钥、消息数组与消息长度，返回16字节认证标签。密钥取标准掩码，内部采用十三个10位肢体，乘法、进位和最终约减使用固定次数整数运算。秘密值参与位运算和算术，数组下标和循环界由公开长度及位置决定。一次性密钥每个消息使用一次。ChaCha20 的32位秘密词携带固定高位标记，逐中间值的装箱区间见《恒时值域》。

`ChaCha20Poly1305加密` 与 `XChaCha20Poly1305加密` 依次接收密钥、随机数、附加数据、附加数据长度、明文与明文长度，返回密文与16字节标签。相应解密函数依次接收密钥、随机数、附加数据、附加数据长度、密文、密文长度与标签，认证成功时返回明文，认证失败时返回空值。

验证包括 RFC 8439 的 ChaCha20 块、Poly1305 消息及空消息、ChaCha20Poly1305 向量、XChaCha20Poly1305 草案向量、坏标签和坏附加数据拒绝、计数扩展与安全播种，已在 pit-mac 的诺节上实跑通过。源码依据算法规范自行编写，遵从仓库许可。生成代码恒时核验、原生与裸机验证、性能测量留待后续实施。
