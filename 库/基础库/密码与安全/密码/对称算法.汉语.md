# 流密码与认证

`对称` 模块提供 ChaCha20、HChaCha20、XChaCha20 与显式种子的 ChaCha20 随机源。字节采用整数数组引用表示，调用者显式提供输入长度，密钥固定32字节，ChaCha20 的随机数固定12字节，XChaCha20 固定24字节。

`夏夏二十块` 接收密钥、公开块计数与随机数，返回64字节块。`夏夏二十` 和 `扩展夏夏二十` 接收密钥、计数、随机数、输入与长度，返回等长输出。`创建夏夏随机源` 接收32字节种子和12字节公开流号；`夏夏随机块` 返回下一个64字节块并递增32位计数。调用者在计数用尽前重新播种，系统安全随机播种包装与计数扩展留待后续实现。

`认证` 模块的 `Poly1305` 接收32字节一次性密钥、消息数组与消息长度，返回16字节认证标签。密钥取标准掩码，内部采用五个26位肢体，乘法、进位和最终约减使用固定次数整数运算。秘密值参与位运算和算术，数组下标和循环界由公开长度及位置决定。一次性密钥每个消息使用一次。

验证包括 RFC 8439 的 ChaCha20 块向量、Poly1305 消息向量与空消息向量，已在 pit-mac 的诺节上实跑通过。源码依据 RFC 8439 算法规范自行编写，遵从仓库许可。认证加密、原生与裸机验证、性能测量留待后续实施。
