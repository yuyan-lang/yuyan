## 模65537恒等式

令t=a·65536+b，其中0≤a≤65536、0≤b≤65535。d=b−a在[-65536,65535]，借位位k为d符号位的低一位。商q=a−k，余r=d+k·65537；若d非负，q=a且r=d；若d负，q=a−1且r=d+65537。两种情形均满足t=q·65537+r，0≤q≤65535、0≤r≤65536。实现仅使用固定移位、掩码和小整数加减乘，分支及地址继续只依公开循环位置。

拼肢先返回v=2^33+t，值域[2^33,2^33+2^32+65535]，始终使用GC大整数表示。v&65535得b，v右移16的结果在[131072,196608]，整个移位结果已经恒为i31；随后与131071得a。标记在提取高肢时由低17位掩码消去。全部差、借位、商及余的中间值均处于i31。

小域乘的甲乙各在[0,65536]，带标积为w=2^34+甲乙，值域[2^34,2^34+2^32]，恒为GC大整数。w右移16在[262144,327680]，移位结果恒为i31；低17位得到积的高肢a≤65536，低16位得到b。复用上述余数恒等式，直接得到甲乙模65537的结果，保持标记的原大整数也保持固定表示。甲乙同时为65536时a=65536、b=0，r=1，覆盖积达到2^32的边界。

带标十六积自身逐步界如下，令M=2^32。甲加65536、乙加65536各为[65536,131072]的i31；它们的积P在[M,4M]，恒为大整。甲乙之和加131072在[131072,262144]的i31；左移16得到偿数C∈[2M,4M]，恒为大整。P+8M在[9M,12M]，减C后恰为7M+甲乙∈[7M,8M]，再减6M得到M+甲乙∈[M,2M]。造钥小域再加3M得到w∈[4M,5M]。这些加减中间全部固定采用大整表示。

小域逆返回u∈[0,65536]。负模因子用 `非零(u)·(65537−u)`。非零位由 `(u or −u)>>63 &1` 得出；u、−u、位或、移位结果、65537−u及最终乘积全部在i31范围。u=0返回0，其余u返回65537−u。

## 造钥控制流与下标逐项审核

| 函数及路径 | 控制流、地址和迭代界限 |
| --- | --- |
| 造钥乘行、乘续 | 行与位置由两个公开肢宽决定；固定行列全乘，即使因子为零也扫描全部肢；进位作为数据传递 |
| 造钥取余、除公指数 | 自公开总宽降至负一；读写位置恒为公开位置，余数和商只作为数值 |
| 造钥小域逆 | 入口累计1、固定16轮；每轮平方和乘余数均执行，唯一终止条件是公开轮数为零 |
| 造钥密钥位 | 仅公开字节长无效时提前返回；其余分配、乘法、φ计算、逆、除法与编码均固定完成，φ余数为零由返回有效位表达 |
| 右移一位、字节加二 | 扫描全部公开字节长；字节进位零时也继续，地址与移位数公开 |
| 字节相等位 | 扫描全部公开长度，将差按位或累计，末尾产生0/1位，保持全程无秘密早停 |
| 候选位 | 强制首两位1与末两位11；候选为奇数且减一恰含一个因子2，半数直接右移一次，避免秘密因子2计数循环 |
| 素性逐轮 | 固定128轮；每轮固定随机调用、一次定宽模幂及两次全长比较，无合数早停；累计通过位仅传入下一轮的位与 |
| 候选批次 | 完整扫描公开候选数，每个候选都核素性与同甲比较；取甲、取乙及已见位只作掩码数据，无成功早停 |
| RSA生成密钥 | 参数长度及候选数检查公开；批次结束后无条件构造密钥，成功位只控制最后两次全长掩码取舍及已公开的返回爻 |

候选批次读取本轮开始时的甲已见位：取甲=通过且甲未见，取乙=通过且甲已见且乙未见且不同甲，因此同一候选只进入一侧。见位经位或更新，两个见位单调且始终为0/1；不同甲位经全字节固定比较产生。零个、一个或两个合格候选的迭代次数与地址相同。未选中的数组保持零；批次失败仍构造后按成功位归零。

调用链的RSA定宽模幂对公开长度进行检查，并检查模数低位是否为奇数。造钥候选强制奇数，因此每次筛素调用都进入同一路径。指数长度固定为素数字节长，执行8倍该长度的指数位；每位平方和乘法都执行，指数位只作取舍掩码。Montgomery的低肢逆固定4次Newton步骤，所有乘减和循环地址依公开肢宽；减法借位和最终选取都作为数据处理。调用者直接调用定宽模幂时，奇偶输入检查属于其输入边界。

## 模逆与筛素的独立算例

小域逆第j轮的幂指数E满足E0=0、E(j+1)=2Ej+1，故16轮后E=65535。65537为素数；非零r的r^65535是其乘法逆，r为零时首轮变零并继续全部轮数。独立预期为0逆得到0、1逆得到1、2逆得到32769、65536逆得到65536；后两个预期分别由2·32769=65537+1与(65537−1)平方模65537=1直接推出，新测试写常量而非调用被测减移算法生成预期。

当φ模65537非零时，k=−φ^-1模65537，65537·d=kφ+1，构造出的d满足公指数的逆关系。已保留p=61、q=53、n=3233、d=2753的独立小向量：φ=3120，65537模3120为17，17·2753=15·3120+1。

素性算法对应 [FIPS 186-5 附录B.3.1](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.186-5.pdf) 的Miller-Rabin判据；本实现的候选限制使候选减一的2次幂分解次数恒为1。当前受限候选域、固定批次和失败规则属于本库接口约定。完整FIPS造钥合规性与机器恒时证据列为后续核验事项。
