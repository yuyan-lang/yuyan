# 曲线算法

`曲线` 模块提供 X25519 和 X25519公钥，参数与结果为整数数组，长度为 32，每个元素为一个字节。私钥会复制后按 RFC 7748 钳制，输入数组保持原值。公钥的最高位依 RFC 7748 清零，输出采用小端规范编码。

秘密运算源码采用 16 个 16 位肢和 255 轮蒙哥马利梯子。交换按掩码遍历全部肢，秘密位仅参与掩码计算。源码中域乘法、逆元与编码的循环次数和访存下标由公开的固定轮次决定。调用者检查输入长度，收到共享秘密后用固定遍历比较检查全零，再交给密钥派生。

当前回收运行时依整数值选择 i31 与完整 i64 装箱，域乘法的中间值会进入此路径。机器级常数时间验收留待固定整数实现、生成代码审查与计时核验；提案甲级与乙级的恒时门槛留待完成此项核验。

测试采用 RFC 7748 第 6.1 节 Alice 与 Bob 的公钥及双向共享秘密向量。参考算法和向量来源为 RFC 7748；本文件为豫言实现，许可遵循仓库 LICENSE。

`爱德曲线` 模块提供 Ed25519公钥，以 32 字节种子生成 32 字节公钥。它复用定宽域运算，采用扩展坐标的完整点加法及固定 256 轮掩码梯子；种子经过 SHA-512 后按 RFC 8032 钳制。公钥测试采用 RFC 8032 第 7.1 节首项标准向量，并在 pit-mac 的节点宿主上执行通过。

后续事项：Ed25519 签名与验签、P-256、P-384、P-521，Wycheproof 全部相关向量与差分测试，原生和裸机验收及性能测量。
