# X25519MLKEM768 合交换

`混合` 依 [RFC 10024](https://www.rfc-editor.org/rfc/rfc10024.html) 行TLS 1.3合交换，群号4588。客户传份先1184字节格公钥，后32字节曲线公钥；服务传份先1088字节格密文，后32字节曲线公钥；合密先32字节格秘密，后32字节曲线秘密，径入TLS密钥日程。

`生成混合客户份额` 受32字节曲线私钥与安全随机术，还客户传份及2400字节格解封私钥。调用者独取曲线私钥于安全随机源；随机术每召依所请长还新数组，格之二种各独取32字节。每次握手及重试皆新造诸材。

`完成混合客户交换` 受曲线私钥、格解封私钥与服务传份，还合交换之果。传份长失及曲线合密尽零，还`混合交换非法参数`，告TLS警报47；本地解封之参失，还`混合交换内部失败`，告80。格密文遭改，循FIPS 203隐拒，TLS Finished之验察握手之失。

`测试/混合。测试` 由全树测试自取，验传份次序、双方合密、非法长与曲线尽零。
