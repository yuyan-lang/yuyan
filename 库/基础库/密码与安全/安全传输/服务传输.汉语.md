# 服务传输

`服务传输。豫` 将已经接受的 TCP 连接与 TLS 1.3 服务会话绑定。调用者使用 `开始服务` 创建会话，配置 DER 证书链、签名算法和真实签名回调，然后调用 `接入服务传输`。

`推进服务传输` 先刷新待发密文，再读取一次密文。成功和等待结果携带 `元`；等待时使用 TCP `关注可读写` 等待后重试。调用者通过 `服务握手已成`、`服务错误`、`服务已关闭` 和 `取服务明文` 查询会话。

`写入服务传输` 排入应用明文；`刷新服务传输` 发送队列并保留部分写入的累计偏移。读取推进产生的密文在下一次刷新时发送。连接由一个调用者串行操作。

`结束服务传输` 排入关闭通知。调用者刷新成功后关闭 TCP 连接。TCP 提前关闭由调用者作为截断处理。证书签名私钥由签名回调持有；交换私钥与随机数由调用者提供安全随机字节。

`测试/服务传输。测试。豫` 由全树测试自动发现，检查连接绑定与空队列刷新。真实网络与证书互通验证留待后续版本。
