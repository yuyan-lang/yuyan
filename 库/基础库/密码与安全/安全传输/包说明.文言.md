# 安全传输

以字节串析传输之记录及握手之文，未全者存其余。编码者作网络字节序之首。握手篇作第三版客户问候，书三套件及服务名、协议、版本、群、签名、密钥份额；用者授三十二字节之随机数及公开份额。

密钥日程篇联字节串与密码之列，具标签展开、秘密衍生、握手及主秘密、完成证明与流量秘密更新；授散列术、块长、摘要长以择 SHA-256 或 SHA-384。握手篇析服务问候之套件、随机数及扩展。

依 RFC 8448 第三节校早期秘密、衍生盐、握手秘密、主秘密、服务流量秘密、密钥及初始向量。

加密记录篇以序号异或初始向量作随机数，书网络序之附加认证文及内部明文；辨内容之类与零填充，验败则还误。对称记录篇用密码库之 AES-GCM 及 ChaCha20-Poly1305。

客户今具第三版 AES-128-GCM、X25519 之路。客户配置藏主机名、协议候选、证书链与握手签名之核验术；链之核验接证书库，签名之术得叶证书与待签之文。开始客户受配置及各三十二字节之随机数、私钥而作独立会话；喂入客户受网络字节，取客户待发、取客户明文取其出物，客户握手已成问其成否，写入客户分片发应用之文。请求客户密钥更新、关闭客户发更新与闭告。

传输薄层发送密文还累计序，候则存之；读取传输记录先授缓冲已有之全记录。

客户完成证明既成，衍恢复主秘密；认证后新票据严校长度与重复扩展，存其最近者，寿命零则除之。取客户票据受会话及接收Unix毫秒，还系主机协议套件寿命之票据。开始恢复客户受配置、随机数、私钥、票据及今Unix毫秒，编末项预共享扩展及绑定证明，辨单身份之择、全握手回退、重试合成之首与恢复协议。票据失效或主机变则始全握手。

客户受闭告，先列己之应答于待发，再示闭态；传输者取其待发而后止连接。

依 RFC 8448 重放完成之密文，逐字节校之，验开封与拒篡改。纯豫言客户于 pit-mac 通 OpenSSL，成 X25519、AES-128-GCM、RSA-PSS-SHA256、协议协商及 HTTP 200 往返；测试证书明列为信任之锚，私钥与随机数藏于库外。

互通之客户以 localhost 服务器证书原文为唯一测试之锚，取其起效后一秒验路径；路径校主机名与期限，CertificateVerify 回调实核其公钥之 RSA-PSS-SHA256 签。客户配置两验签回调皆由用者授之，随机数与 X25519 私钥亦然。通用发行链签名、Mozilla 根数据之默认相接、实时与安全随机之默认装配及其互通之验，列后续之事。

客户会话供“客户错误”与“客户已关闭”之察。错误正文存至闭后，察而存会话之文；闭态含主动之闭与所收 close_notify。传输驱动可依此传败而终接收。
“默认客户配置”受主机名与明定 Unix 秒，协议限于 http/1.1。证书链调用证书库之“验证服务器证书”，用根证书数据与全证书验签；握手签名调用“核对握手签名”。调用者每请供今时。回归验空链、坏证与无效握手签名之拒，真 HTTPS 互通续验。
客户又具 AES-256-GCM/SHA384、ChaCha20-Poly1305/SHA256 及重问候所择 P-256 之路。重问候校其惟一、群之变、套件之同、令牌及合成消息散列；服务问候校会话标识、扩展长、类与重复。客户错误、客户已关闭问其终态。

三套件及 P-256 重问候于 pit-mac 通强制配置之 OpenSSL@3，成证书认证及 HTTP 200 往返。测试时取证书始时加一秒以重放其样；实用者授今时与信任之策。

旧版客户具 TLS 1.2 之 X25519 ECDHE、AES-128-GCM/SHA256 与 ChaCha20-Poly1305/SHA256，列 RSA、ECDSA 之套件。服务问候必协扩展主密钥；主秘由含客户换钥之握手摘要生。服务换钥之随机与群参数授既有签名验，证书链依既有配置核之。双方完成证明取 SHA256 PRF 十二字节。记录生 GCM 显式随机、ChaCha 异或随机及含序、类、版、明文长之附加数据。

开始旧版客户、喂入旧版客户、写入旧版客户与关闭旧版客户行独立旧版之机；输出、错误、终态沿客户之问。旧版客户测试由全树 CI 自取，验两类 AEAD 全握手、分片、应用数据及缺主密钥之拒。试之回调为协议夹具，实用者依配置核证书之真。

ECDSA、Ed25519、票据复用、混合交换与服务端诸路及全出错之验待续。提案甲乙之验尚待毕。
