# 弗拉克完整解码覆盖核对

本轮以 `276cf5614` 为基线，遵调度只静态开发与格式化，保持现有函数 ABI。此前未知总数、多帧编码及 RFC9639 D.1–D.3 已由协调代理确认双端 134 项通过，本轮没有重做这些结果。

依据 [官方 subset 清单](https://github.com/ietf-wg-cellar/flac-test-files/blob/main/subset/README.txt)、[uncommon 清单](https://github.com/ietf-wg-cellar/flac-test-files/blob/main/uncommon/README.txt) 与 [faulty 清单](https://github.com/ietf-wg-cellar/flac-test-files/blob/main/faulty/README.txt)，逐组核对源码路径：

| 官方编号 | 所需解码路径 | 本轮证据与待验范围 |
|---|---|---|
| subset 01–10、24–27、29–30 | 各块长、可变块、连续帧 | 帧头与容器按每帧块长推进；65536 非法块本轮明确拒绝；这些官方文件未运行 |
| subset 11–18、31–32、34、44 | 高阶/高精度 LPC、分区、固定阶、逃逸及废位 | 64 位预测累加及通用分区源码已有；本轮补分区整除、首区长度、保留精度及负移位拒绝；已有 D.3 独立 LPC/逃逸向量 |
| subset 19–23、28、33、35–37 | 采样率与 8/12/20/24 位样本 | 通用帧头及有符号位读已有；本轮手算 12/20/24 位极值字节向量，尚未运行 |
| subset 38–44 | 三至八声道 | 独立声道按交错下标输出，相关声道重建另有既有数学向量；官方声道文件未运行 |
| subset 45–59 | 未知总数、未知帧大小、多种大型元数据 | 未知总数实计已验；元数据按二十四位长度跳过，不依据预告帧大小分配；新增合法 APPLICATION 与 PADDING 移帧测试 |
| subset 60–64 | 单声道、预测溢出、零宽逃逸 | 64 位运算已有；本轮新增非零固定一阶零宽逃逸字节向量，登记官方 subset64 全文件与独立 PCM MD5，尚未运行 |
| uncommon 05–09 | 32 位、超高采率、15 位、大块、高分区阶 | 本轮登记官方 32 位文件及全部 PCM 摘要，手算 15 位及 33 位侧声道边界，尚未运行；最大分区阶依通用循环读取 |
| uncommon 01–04 | 中途改变采样率、声道数及位深 | 单配置入口逐帧核对采率、声道与位深，显式拒绝配置变化；此为 RFC9639 允许的停止策略。分段输出继续核定，公开签名保持原样 |
| uncommon 10–11 | 裸帧、任意前导字节 | 现有容器入口从 fLaC 与 STREAMINFO 起步；裸流恢复入口继续核定，保持现 ABI |
| faulty 01–11 | 错误流信息、长度、块大小及元数据内容 | 按实际帧分配可避免依赖错误上限；已有样本数、声道、首元数据与长度拒绝；本轮补子帧、LPC、分区与非法块拒绝；元数据内部标签内容解析仍按音频解码范围跳过 |

新增独立错误向量分别翻转 RFC D.1 的 CRC8、CRC16 与 MD5；新增必为零的子帧头位、废位耗尽、阶数越界、分区不整除、首分区过短、LPC 保留精度及负移位拒绝测试。新增帧尾填充位零校验。新增 Rice2 手算向量的采样为 `[1,-1,2,-2]`；新宽位向量包含有符号最小/最大值及三十三位侧声道常量 `4294967295`。

官方样例授权、文件 SHA-256、固定 PCM MD5 及样本数见双语样例来源文件。全部本轮源码与测试仅完成格式化及差异检查，类型检查、构建和运行交由 pit-mac 的统一验证窗口；这些登记均为待运行证据。

随后补分配前的实际帧核对：非零声明样本数也先实计，声明须与实际数量吻合，最终数组依据实际数量分配。独立向量将极短 RFC D.1 的三十六位声明改为 68719476735，预期在分配前拒绝；另有空流声明一帧、空流采样率零及位深一至三的拒绝向量，位深四的合法空流保留。按 RFC9639 §8.2，位深下限为四；采样率零可以描述非音频，本包音频入口要求正采样率。此补丁仍未编译或运行。
