# 奥普斯声道历史迁移实施记录

SILK 私核 `丝路迁声道历史` 接受单声跟踪态、同采样率双声跟踪态及新声道数。仅在内部声道变化时调用；转双声逐字段复制中声预测、线谱、参数、延迟和 PLC，初始化侧声预测与 PLC，清中侧预测及侧声历史，中声末二样从真实 PCM 环取回。左重采样历史复制至独立左右状态。转单声复制中声预测、PLC 及左重采样历史。

依据官方 Opus v1.1 [silk/dec_API.c](https://github.com/xiph/opus/blob/v1.1/silk/dec_API.c) 的单声转双声初始化、中侧预测复位与右重采样器复制规则。当前公开输出随 TOC 声道变化；固定双声 API 下的单声流输出恢复另由上层策略接入。

基本向量覆盖 8、12、16 千赫，每档检查中声 PLC 双向保存、侧声初始化、左右重采样状态的独立性，共 27 项通过，0 项失败。使用完整 25a843 发布工具链在 pit-mac 独立声道核验树编译运行。源码及测试均已排版 120。

主调度接线、CELT 固定双路合成历史与动态声道下逐 PCM 数值验收继续实施。本批为真实历史迁移私核及独立标记向量。
