# 奥普斯声道历史迁移实施记录

SILK 私核 `丝路迁声道历史` 接受单声跟踪态、同采样率双声跟踪态及新声道数。仅在内部声道变化时调用；转双声逐字段复制中声预测、线谱、参数、延迟和 PLC，初始化侧声预测与 PLC，清中侧预测及侧声历史，中声末二样从真实 PCM 环取回。左重采样历史复制至独立左右状态。转单声复制中声预测、PLC 及左重采样历史。

依据官方 Opus v1.1 [silk/dec_API.c](https://github.com/xiph/opus/blob/v1.1/silk/dec_API.c) 的单声转双声初始化、中侧预测复位与右重采样器复制规则。当前公开输出随 TOC 声道变化；固定双声 API 下的单声流输出恢复另由上层策略接入。

基本向量覆盖 8、12、16 千赫，每档检查中声 PLC 双向保存、侧声初始化、左右重采样状态的独立性，共 27 项通过，0 项失败。使用完整 25a843 发布工具链在 pit-mac 独立声道核验树编译运行。源码及测试均已排版 120。

主调度接线、CELT 固定双路合成历史与动态声道下逐 PCM 数值验收继续实施。本批为真实历史迁移私核及独立标记向量。

CELT 新私核 `赛尔特解双路单流帧` 在固定双声状态中读取单声码流帧。读取前把共享左右当前带能量取最大值，左右使用相同熵码、种子和单声抗塌陷频谱历史，分别运行既有完整单声解码与各自合成、去加重、后滤历史。读取后右前两帧能量按右路原历史与实际瞬态标恢复，当前能量同步写入共享两侧，输出真实左右交错 PCM。上层可以选择输出声道；本私核保持双路内部历史。

依据官方 [celt/celt_decoder.c](https://github.com/xiph/opus/blob/v1.1/celt/celt_decoder.c) 的 `C` 流声道与 `CC` 输出声道分离、单声能量压合和单流双路频谱恢复规则。当前实现以两次豫言熵码读取复用既有完整合成链。

四种帧长的真实 `ff ff` 静音码流小向量给右去加重历史赋值 100、左路零；首右样独立期望为 `100 × 0.850006103515625 ÷ 32768`，左首样零，后续帧右路继续衰减。28 项通过、0 项失败，证明两路沿各自历史合成。长码流逐 PCM 精度继续验收。

混合正式跟踪高声在单声码流读取粗能量之前应用左右当前能量最大值。PVQ 与抗塌陷完成后，把实际单声频谱复制到右谱数组，把已解当前能量同步至右侧，随后执行双路去规整、真实合成和背景维护。左右各自时间、后滤、去加重和前两帧能量历史继续保存，公开单声输出取左路。

混合十、二十毫秒高流基本向量读取实际 255 字节零码流。独立预置左右能量验证 max 与同步规则；左右从相同初态合成，2048 项真实后滤历史逐项相同且均含非零样本，共 4106 项通过、0 项失败。关联正常、双次丢包及恢复基本链回归 88 项通过、0 项失败。尚待统一调度在 CELT 单流帧上接入固定双路私核，以及在同模式声道变化时调用 SILK 迁移。
