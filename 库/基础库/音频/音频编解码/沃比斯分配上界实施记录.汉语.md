# 沃比斯分配前样本上界

原实现根据末 granule 减正时间偏移计算输出帧数，直接分配交错样本数组，随后才用实际解码帧数复核。多音频页的末粒位增大时，第一音频页推导出的正时间偏移保持正常，输出数组可能先增大。

修复先复用 `沃比斯包时长` 对全部有效音频包的模式及窗口头做轻读，得到名义可恢复帧数，叠加负首偏作为真实输出上界。分配之前检查输出限帧是否超过该上界，超过时报告 `沃比斯末粒位超过音包可恢复上界`。名义计数按相邻有效块长之和的四分之一累计，首包用于预备叠帧；过程包含已约定的残头丢包行为，保持前块状态。

公式为 `限帧 = 末粒位 - max(起粒位, 0)`，`上界 = 全部有效包名义帧 + min(起粒位, 0)`。正起点的时间偏移先从限帧扣除，负起点的裁前量先从上界扣除；合法尾裁对应限帧小于上界。本次没有添加固定样本上限，名义计数调用只读包头，执行发生在 FFT、窗重建和输出数组分配之前。

独立载体保留既有 ffmpeg 非零样例的所有码字，重新分页为两头页和两音频页。第一音频页含首两包，粒位1024；第二音频页含余包，正常粒位4800。配置轻读的手列名义时长为5120帧。异常载体只把末粒位改为5121或1000000000000，并重算页CRC，单流组包和页位置检查必须先通过，再核对分配前的特定拒绝消息。

原19200链样本、9600非零样本及默认首流参考保留。新入口为 `测试/沃比斯分配上界。测试。豫`。本次只静态实现与格式化，未构建、未运行，异常载体测试验收为待测。

继续静态核对发现轻计与实际串包一致：两者调用同一音包头可用函数，丢包均保留前块长度与已帧，有效包都按相邻块长和的四分之一累计。追加四类独立边界：首两有效包间插空包与保留类型包时名义5120帧及全部9600参考样本保持；首末粒位同加一万亿正时间偏移时全部9600参考样本保持；首粒位1000裁前24帧、终粒位4776时逐样本期望取外部参考第24至4799帧，共9552样本；只有三头包且终粒位零的流返回采样率48000、双声道、零样本。

这些追加向量包含真实重建与逐样本比较，未来执行会调用逆变换；本次静态准备没有运行计数或重建，没有改原参考或增加公共 ABI。
