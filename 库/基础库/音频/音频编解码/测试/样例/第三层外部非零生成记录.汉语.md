# 第三层外部非零参考生成记录

2026-10-08 使用本机已安装 FFmpeg 9.0.2（libavcodec 63.1.102、libavformat 63.1.102、libmp3lame 编码器）独立生成三种 MPEG Layer III 整流，并由 FFmpeg 独立解码为小端 IEEE binary64 交错 PCM。输入为数学合成的双声道正弦与脉冲，无外部录音版权。保留全部输出帧、编码器延迟与尾帧。

左声道表达式为 `0.2*sin(2*PI*997*t)+0.35*lt(mod(t,0.04),0.002)`，右声道为 `0.17*sin(2*PI*541*t)-0.28*lt(mod(t,0.03),0.001)`。每份输入持续 0.15 秒；码率依次为 128k、64k、32k。生成命令如下，第二版将 `44100`、`128k` 与名称分别换成 `22050`、`64k`、`外部非零第二版`，扩展版换成 `11025`、`32k`、`外部非零扩展版`。

```text
ffmpeg -v error -f lavfi -i 'aevalsrc=0.2*sin(2*PI*997*t)+0.35*lt(mod(t\,0.04)\,0.002)|0.17*sin(2*PI*541*t)-0.28*lt(mod(t\,0.03)\,0.001):s=44100:d=0.15' -c:a libmp3lame -b:a 128k -write_xing 0 -id3v2_version 0 -y 外部非零第一版.mp3
ffmpeg -v error -i 外部非零第一版.mp3 -map 0:a:0 -c:a pcm_f64le -f f64le -y 外部非零第一版参考.pcm
ffprobe -v error -select_streams a:0 -count_frames -show_entries stream=sample_rate,channels,nb_read_frames -of compact 外部非零第一版.mp3
```

`write_xing=0`、`id3v2_version=0` 禁止写入 Xing 和 ID3v2 元数据。首四字节分别为 `ff fb 90 44`、`ff f3 80 64`、`ff e3 40 64`，版本头分别为 MPEG1、MPEG2、MPEG2.5。独立 ffprobe 实测全部为双声道，帧数为 7、8、5；参考字节数与整帧的交错样本总数一致。
