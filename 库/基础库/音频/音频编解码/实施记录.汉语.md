# 音频编解码实施记录

2026-10-07 开始实现提案 00004 音频编解码。甲级、乙级均处于进行中；本记录按真实算法范围更新。

| 模块 | 已落地范围 | 后续事项 |
|---|---|---|
| 波形 | PCM 八、十六、二十四、三十二位；单精度与双精度；扩展格式；编码与解码 | 完成边界与格式测试 |
| 流无损 | 原始子帧编码；通用元数据、多帧、常量/原始/固定/线性预测/Rice 子帧、声道重建及 CRC 解码 | MD5 校验与未知总样本数 |
| 流无损预测 | Rice 折叠、固定预测、线性预测恢复、声道重建，已接入容器 | 公开测试集对照 |
| 页式容器 | 页校验、单流页序与分段组包；沃比斯标识及注释包 | 沃比斯设置包与完整 PCM 解码 |
| 第三层音频 | 帧头、位读取、侧信息长度、主数据回溯、位储备拼接 | 颗粒侧信息、霍夫曼、反量化、逆变换、合成滤波 |
| 奥普斯 | 四种数据包布局拆帧、变长帧与填充；范围解码原语、逆累计和均匀整数 | 丝绸与凯尔特音频解码 |
| 音频交换 | AIFF/AIFC 八至三十二位整数采样解析，NONE/twos/sowt；十六位编码 | 类型检查与往返验证 |

第一个使用者为 `示例/波形摘要。豫`：读取文件并显示采样率、声道数及交错样本数，供语音模型输入预处理检查使用。

测试由本包 `测试/` 下的独立入口执行。所有构建按工作树串行运行，避免共享缓存并发。遇到旧工具链与当前标准库不兼容后，取得仓库 CI 指向的 2026-10-06 发布工具链，并核对其 SHA256，使用配套稳定节点宿主继续验证。

11 个测试入口共 500 项核对通过：

| 测试 | 通过数 |
|---|---:|
| 波形六种位宽、扩展格式及截断 | 32 |
| 音频交换往返与字节序 | 11 |
| 流无损容器往返 | 6 |
| 页式容器 | 5 |
| 第三层音频帧与位储备 | 13 |
| 奥普斯数据包 | 12 |
| 奥普斯范围解码 | 10 |
| 流无损预测 | 7 |
| 流无损子帧 | 5 |
| 流无损帧头 | 9 |
| ffmpeg 独立生成的 WAV/FLAC 样例逐样本核对 | 390 |

参考样例为原生双声道 0.5 恒值。首轮单声道转双声道样例受 ffmpeg 默认混音增益影响，逐样本核对发现差异后改为原生双声道生成，并以原始十六位采样值 16384 另行核对。

包检查与总集类型检查均通过。类型检查以总集覆盖全部库模块，测试与示例均以实际构建覆盖。第一个使用者已构建运行，读取参考波形返回采样率 48000、声道数 2、交错样本数 192。
