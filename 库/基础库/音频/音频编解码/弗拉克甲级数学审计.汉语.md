# 弗拉克甲级数学审计

基线为 yybs `e0f34bc6c`，包含已合的 `76f5ab617` 弗拉克修复。协调代理确认此前边界44项、官方完整文件38项均在 Node 与原生终止码零；本轮只静态阅读及格式化，新增向量仍待运行。

本轮没有发现单配置原生 FLAC 合法输入的新增解码或 MD5 算法缺口。结论以 RFC9639 的原生 fLaC/STREAMINFO 映射为界；帧间配置变化采用规范允许的显式停止策略。官方 uncommon 10–11 的无元数据裸帧和前导垃圾接收属于裸流恢复入口，仍按已记录的范围核定。

## 可复核的数值范围

| 路径 | 源码依据 | 合法数值范围 |
|---|---|---|
| 原样、常量、废位 | 流无损子帧的有符号位读取、废位末尾左移 | 音频位深4–32，相关声道的侧信号增加一位；最大33位值可由64位整数完整保存 |
| 固定预测0–4阶 | 流无损预测的固定系数及整数累加 | 四阶绝对系数和为16，33位侧信号累加界低于2的37次方 |
| LPC1–32阶 | 系数按最近样本优先，整数累加后算术右移 | 15位有符号系数、最多32项、33位侧信号，绝对累加界不超过2的51次方，处于64位整数范围 |
| Rice/Rice2及逃逸 | 分区整除及首区约束、米码展开、零宽原样读取 | 参数宽4或5，分区阶0–15；逃逸宽0正确输出零残差，0–31位符号余数由64位整数保存 |
| 声道重建 | 独立、左侧、侧右、中侧路径 | 中侧奇偶修复与算术右移均在64位整数内，废位在解耦前恢复 |
| MD5 | 流无损摘要按交错PCM逐字节写小端并符号扩展 | 4–32位整数转归一化小数的分母为二的幂；小数53位有效精度可以完整保留所有32位PCM，反归一化也精确 |
| 帧/元数据/计数 | CRC8、CRC16、填充零检查、实际长度跳过、分配前实计 | 帧大小来自实际位游标；最终数组只在声明与实际数吻合后按实际数分配，合法大流保留 |

这些边界覆盖官方 subset 高阶、高精度、预测溢出与 uncommon 高分区阶需要的算术范围；覆盖结论是源代码静态核对，官方全部文件族的完整运行仍待逐项登记。

## 新增独立最小向量

`测试/流无损极限数学。测试。豫` 增加三组证据：

1. 非整字节位深4、12、15、20、28与整位32的最小/最大采样。小端符号扩展预像字节在测试处逐项手列，再用已验证密码MD5作为共同散列工具，与采样到摘要结果比较。这里独立验证的是PCM字节预像与符号扩展规则。
2. 三十二阶LPC、十五位系数512、移位14与三十二个最大32位热身值。独立整数和为35184372072448，移位后为2147483647，残差负一后为2147483646。
3. 最大分区阶15、块长32768、零阶固定预测。每区七位手列为 `0000001`，表示参数零及残差一；全部32768项应为一，最终游标应为229390位。此向量使用28674字节，不依赖被测编码器。

测试源码已格式化，差异检查通过；本轮没有类型检查、构建或运行，新增结果没有计入此前通过数。
