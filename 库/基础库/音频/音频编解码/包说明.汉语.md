# 音频编解码

`示例/波形摘要。豫` 读取 WAV、AIFF、FLAC、Vorbis 与 MP3 文件，显示语音预处理使用的采样率、声道数、交错样本数与实际非零样本数。`测试/音频交换参考。测试。豫` 按 AIFF 格式手工列出八千赫兹单声道的三个非零 PCM 样本，独立核对解码结果，Node 与原生各六项通过。正式摘要接线验收见首轮完整链验收。

本包以纯豫言读取音频文件，输出交错排列的归一化小数样本。公共音频数据依次保存采样率、声道数、交错样本数与样本数组。

波形文件接口为 `解码波形`，输入字节串，返回可选音频数据。`示例/波形摘要。豫` 读取本机波形文件并显示采样参数，作为语音模型预处理的输入检查工具。

`编码波形` 接收音频数据、位数及浮点标志，返回可选字节串。整数 PCM 支持八、十六、二十四、三十二位，浮点支持三十二、六十四位。编码统一写出四十字节的 WAVE_FORMAT_EXTENSIBLE 格式块，有效位数等于容器位数，声道掩码为零表示未指定扬声器位置；样本保持输入的交错顺序。浮点编码另写 `fact` 块中的每声道样本数。解码校验完整十六字节 PCM/IEEE_FLOAT GUID、扩展长度、有效位宽及声道掩码。整数有效位按高位对齐恢复，包含二十位存于二十四位容器；非零声道掩码按位数对应声道数，文件中的声道次序沿用原交错次序。上述续作的运行验收列后续事项。

`解码音频交换` 读取 AIFF/AIFC 的整数 PCM，包含 NONE、twos、sowt 字节序变体；`编码音频交换` 写出十六位 AIFF。`读取奥格包` 提供校验后的容器包列。第三层音频模块提供帧头和位储备处理，奥普斯模块提供数据包拆帧与范围解码。

MP3 侧信息模块解析三版本的颗粒字段。混合变换模块提供长短窗逆修正余弦、去混叠、重叠相加和频率反转，复用傅里叶库的余弦计算。第二阶段的验证状态见实施记录。

谱恢复模块提供符号幅值的反量化。霍夫曼模块提供有界码字、延长位和四元码表读取，多相合成模块提供状态延迟、矩阵与合成窗累加内核。其码表与标准窗数据的登记范围见实施记录。

沃比斯码本模块读取有序、无序及稀疏长度，提供标量与向量查找。沃比斯重建模块提供混合窗、逆变换、逆耦合与异长帧叠加。完整数据包解码的接入范围见实施记录。

`解码流无损容器` 读取弗拉克的元数据与连续帧，支持常量、原始、固定预测、线性预测、Rice 残差以及独立和相关声道，输出交错样本。解码后用密码库的 MD5 校验流信息中的非零摘要，摘要按交错小端有符号采样计算。解码先逐帧实计采样数，非零声明数与实计数核对吻合后，按实计数分配最终样本数组；未知总数使用同一流程。音频入口要求采样率大于零、位深为四至三十二位。`编码流无损` 写出十六位单帧独立声道原始子帧；`编码多帧流无损` 写出按 65535 个声道内样本分块的完整十六位音频，摘要覆盖截断量化后的全部采样。RFC 9639 附录 D 的三个标准解码向量及逐样本期望值已在 Node 与原生各通过134项核对，编码续作运行验收列后续事项。

实施与验收范围持续记录于本包实施记录。甲级验收包含 WAV、FLAC、MP3、Ogg/Vorbis 全部规格；乙级另含 FLAC 编码、AIFF 与 Opus 解码。

沃比斯流程提供 Floor0/Floor1、三类残差、设置、映射、模式、逆耦合、重建、跨包叠帧与首末采样裁剪。真实非零双声道样例与独立9600样本参考提供完整解码对照。MP3连续文件入口处理尺度因子、频带、立体声、规范霍夫曼表与合成窗，保留跨帧状态并读取可变码率与ID3包裹。各阶段双后端运行证据见首轮完整链验收。

MP3自由码率连续帧按固定未填充槽长与逐帧填充位定位，候选帧界经过完整头链核对。单帧自由文件按已跳标签的码流终界扣除填充位推断基长；残破候选链及无效帧界明确报错。保护帧以8005多项式及FFFF初值校验头低十六位和侧信息，核验完成后更新解码状态。新增三版本非零完整帧、独立CRC余数、假同步载荷、混合短带与强度整帧向量，静态实现记录见《第三层完整规格实施记录》。

沃比斯标识与注释头按最低位读取 framing。注释头截断后继续音频解码，签名与已读取的结束位接受规范检查。Floor1 设置按照官方上限检查至多65个唯一横点。完整包向量实施记录列出奇偶阶 Floor0、含主子码本的 Floor1，以及双声道两阶段的三类残差独立期望；本阶段的新向量状态为待运行。

沃比斯位读取保存持续 EOP 状态；音频类型、模式或长窗标志未完成的包依规范丢弃，后续包继续使用既有叠帧状态。
