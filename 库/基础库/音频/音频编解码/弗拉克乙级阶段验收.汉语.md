# 弗拉克乙级阶段验收

本轮基点为 `c74939f850`，运行机为用户信任的 pit-mac，官方原始语料提交为 `aa7b0c6cf32994c106ae517a08134c28a96ff5b2`。语料保留全部原文件与全部采样。

多帧十六位编码增加逐声道常量子帧选择，重算帧 CRC，继续以量化后的全部 PCM 核算 MD5。65536 个常量样本输出两个帧、共 68 字节；普通编码测试 Node 与原生各 65545 项通过。包检查与整包类型检查通过。

`测试/全量/流无损官方全集。测试。豫` 读取官方 64 个 subset、11 个 uncommon、11 个 faulty，共 86 文件。Node 全批退出零，subset 全部完整解码并通过流内 MD5。uncommon05–09 接受，01–04 按单配置音频接口停止配置变化，10–11 拒绝缺失原生流标记。faulty01、02、09、10 解码接受，其余七项拒绝。错误块长上限、帧长上限或注释格式的接受情况单独保留，供规格验收复核。

原生完整语料运行到 subset44 时退出 120，报预编陷阱。该文件为八声道、192kHz、24 位、32 阶预测，独立进程重现。Node 对其完整 23169256 个交错样本校验通过。同规模小数数组分配与逐槽不同小数填充的独立豫言探针，Node 与原生均通过。原生全集验收尚待此陷阱修复。

`测试/全量/流无损百万变异。豫` 使用基础库测试设施的批模糊流程，种子为 RFC 9639 D.1 完整 57 字节流。Node 与原生分别执行 100 批，每批 10000，末序 999999，各一百万次，正式验收器均退出零。成功结果核对采样率、声道数及样本计数性质。当前设施的逐子进程内存峰值约束留待后续验收。

`测试/全量/流无损性能。豫` 在同机对一 MiB 非零 PCM 运行二次预热、九次中位数。原生库 391761000 纳秒，Node 库 288124625 纳秒，系统 flac 1.4.3 为 30778917 纳秒。原生与 C 比约 12.73 倍；原生与 Node 比约 1.36 倍。库测量包括读 WAV、编码及写文件，C 测量包括子进程启动。库对这组非恒信号写原始子帧，C 使用默认预测压缩。库流 1048678 字节，C 流 110768 字节，完整源 WAV 1048644 字节。系统 flac 对库输出独立 `--test` 退出零。

`测试/全量/流无损裸机。测试。豫` 准备无文件访问、无子进程的纯计算客体，核对 64 个非零交错采样、常量与原始混合子帧、CRC 与 MD5，Node 与原生均通过。QEMU 运行列后续验收。
