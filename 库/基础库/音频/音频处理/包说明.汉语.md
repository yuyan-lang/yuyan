# 音频处理

纯豫言交错样本处理与语音特征计算。依赖标准库、傅里叶变换与音频编解码，版本 0.1.0，属于音频基础库。

音频块是四元组，依次为整数采样率、整数声道数、交错样本数、`数组引用类 于 小数`；结构与音频编解码的音频数据一致。计算保留双精度小数，整数格式转换覆盖八位无符号和十六、二十四、三十二位有符号样本。整数写出先钳位，再舍偶；解码和文件封装由音频编解码提供。

| 接口 | 参数与结果 |
| --- | --- |
| 整数样本转小数、小数样本转整数 | 值、位数；归一化或钳位舍偶转换 |
| 单精度样本转换 | 音频块；各样本舍偶到二进制三十二位，载体保持标准库小数 |
| 声道转换 | 音频块、目标声道；单声道均值，多声道按道号分组均值或循环复制 |
| 混音 | 两个同率同声道块、两个增益；长度取较长者，短输入尾部按零处理 |
| 增益、限幅器 | 音频块、倍数或非负峰值；返回新块，限幅采用硬钳位 |
| 重采样 | 音频块、目标采样率、质量零至二；半径八、十六、三十二，一千零二十四相汉宁加窗 sinc，截止频率随降采样率降低，边缘延拓最近样本 |
| 定点重采样 | 单声道整数数组、样本数、源率、目标率、质量；二十位定点滤波系数，六十四位累加，样本使用有号二十四位范围 |
| 音频短时变换 | 单声道数组、样本数、窗长、步长、居中；周期汉宁窗，居中反射填充，返回各帧复数半谱列表 |
| 音频逆短时变换 | 半谱帧列表、窗长、步长、输出样本数、居中；逆实数变换，重叠相加并除以窗平方和 |
| 梅尔滤波器组 | 采样率、窗长、带数、最低最高赫兹、约定；行优先的三角权重数组 |
| 对数梅尔频谱 | 半谱帧、权重数组、带数、半谱长度、约定；功率加权，最小能量为 1e-10 |
| 梅尔倒谱系数 | 对数梅尔帧、带数、系数数；正交归一余弦二型变换 |
| 语音活动检测 | 音频块、交错样本帧长、均方能量阈值；逐帧活动布尔列表，末帧按实际长度计算 |
| 语音识别预处理 | 音频块；单声道、十六千赫、四百点窗、一百六十点步长、八十带 Whisper 特征 |

梅尔约定零为 HTK，赫兹转换采用 `2595 log10(1+f/700)`，三角滤波器峰值为一；约定一为 Slaney，千赫以下线性梅尔，千赫以上对数梅尔，滤波器按面积归一；约定二采用 Whisper 的 Slaney 滤波器、以十为底的对数、全谱峰值以下八个数量级截断以及 `(值+4)/4`。语音识别预处理去掉居中谱的最后一帧。示例 `示例/语音特征。豫` 是语音识别前处理的首个调用程序，将静音写为十六位 WAV 后解码，演示八十带输出。

采样率与声道数必须为正，声道数上限一千零二十四，交错样本数上限十亿；参数违规抛豫言异常。数组长度由调用者与样本数保持一致。定点系数由纯豫言小数计算一次生成，样本卷积使用整数运算。重采样输出长度取源帧数乘采样率比的上取整。窗平方和为零的位置输出零。

测试包含声道均值、增益混音、整数边界、限幅、活动检测、浮点与定点常量重采样、居中短时往返、HTK/Slaney 解析向量、滤波器三角权重、常量梅尔倒谱。解析参考来自上述公式，代码与测试采用仓库许可，外部数据表尚未引入。

梅尔参数与公式参照 [librosa 滤波器实现](https://github.com/librosa/librosa/blob/main/librosa/filters.py)；Whisper 窗参数、末帧处理与对数归一参照 [Whisper 音频前处理](https://github.com/openai/whisper/blob/main/whisper/audio.py)。以上算法由本库用豫言实现。
