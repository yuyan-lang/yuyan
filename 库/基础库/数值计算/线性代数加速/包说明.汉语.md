# 线性代数加速

此可选包把矩阵乘交给既有的 `豫言操作系统张量计算` 公共接口。核心线性代数保持只依赖标准库。调用者持有并管理张量上下文；本包释放每次乘法创建的三个临时张量。

`加速矩阵乘` 接上下文、左矩阵、右矩阵，按单精度上传，返回核心的矩阵。张量接口的右侧形状为列、深，本包上传转置视图的数据以匹配这一约定。`自动矩阵乘` 在乘积数达到一百万且上下文已加速时委托，较小矩阵使用纯豫言分块乘法。

后续事项：实际金属与统算后端的跨设备性能及精度对照；导入失败后的临时资源回收。

设备验收入口使用公共接口的「必须加速」，核对上下文已加速并输出后端名。矩形小阵核对上传、转置约定与读出；101×99×103 的输入覆盖自动委托阈值，以 99×行号×列号核对全部 10403 个结果，右侧采用共享转置视图。该入口由公共应用宿主绑定运行，设备与平台证据见核心包的《乙级实施记录》。

2026-10-08，Apple M5 Pro 的公共节点金属设备发行实际通过矩形桥接和大矩阵自动委托测试，输出后端「金属」，进程退出 0。两次上下文均要求必须加速并核对加速状态；大矩阵全部 10403 个已知值通过。产物身份与日志见《乙级实施记录》；原生张量设备共享和其他设备对照继续验收。
