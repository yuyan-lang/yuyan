# 数学函数

纯豫言 binary64 计算核心，依赖标准库。指数、指数减一、自然对数、对数加一、二底对数、十底对数、幂、正弦、余弦、正切、双曲正弦、双曲余弦、双曲正切、立方根、斜边、误差函数、互补误差函数、正参数伽马、对数伽马与贝塔已提供。统计与傅里叶变换可作为首批使用者。

指数使用二幂归约与泰勒级数，对数使用二幂归约与反双曲正切级数。三角函数使用周期归约与泰勒级数，伽马使用递推与斯特林展开。误差函数使用五项多项式近似，绝对误差目标 1.5e-7。其余函数的全定义域误差界留待高精度差分测量；当前实现属于开发核心，甲级与乙级验收留待测量完成。

后续事项：负底数幂、巨大三角参数的精确归约、反三角、反双曲、单精度接口、软件融合乘加、拆分指数、下一浮点值、逆误差函数、双伽马、不完全伽马、不完全贝塔、贝塞尔函数与正确舍入。核心函数一个最后位单位的门槛留待高精度测量和算法调整。

本次扩充提供反三角、反双曲、双伽马、逆误差函数、拆分指数（frexp）、二幂缩放（ldexp）、下一浮点值（nextafter）、正则下不完全伽马与补偿乘加。下一浮点值按 binary64 位型移动。拆分指数返回尾数与二幂指数。正则下不完全伽马使用级数，适用于中等参数；大参数稳定算法与上尾连分式列入后续事项。补偿乘加使用 Dekker 拆分，严格单次舍入、溢出与下溢处理列入后续事项。逆误差函数通过二分反求当前误差函数近似；尾部精度列入后续事项。

`核心。测试。豫` 核对指数、对数、微小 log1p、三角、伽马、erf 与斜边的公开数学常数，属于独立的首个调用者。

`单精度。豫` 以小数承载 binary32，`舍入` 用二幂缩放与就近取偶量化；已提供指数、指数减一、自然对数、对数加一、正弦、余弦、双曲正切、误差函数与幂。其余单精度入口列入后续事项。

## 扩充算法与误差登记

正则不完全贝塔使用对称变换和修改连分式；不完全伽马使用下尾级数与上尾连分式。贝塞尔第一类零阶与一阶、第二类零阶与一阶使用小参数幂级数及大参数渐近展开，公式参照 [NIST DLMF 10.8](https://dlmf.nist.gov/10.8) 与 [10.17](https://dlmf.nist.gov/10.17)。

软件融合乘加将binary64有效数分解为整数位阵，先算精确乘积与精确和，再按保护位、粘滞位和奇偶位执行一次就近取偶舍入。数组覆盖全部有限指数范围，支持次正规、溢出抵消及符号相反的完全抵消。无效运算与非数输入返回固定的安静非数位型。`补偿乘加`保留为较快的Dekker计算入口。
