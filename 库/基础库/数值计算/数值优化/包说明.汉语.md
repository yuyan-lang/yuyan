# 数值优化

提供带括区间的布伦特及割线与二分求根、黄金分割极小、中心微分、自适应辛普森与十五点高斯克朗罗积分、线性与双线性插值、自然三次样条、保形分段三次插值。只依赖标准库，输入函数及双精度小数，返回小数。区间和步长违规抛出异常。

求根与极小最多迭代一万次。积分递归深度三十，达到深度后返回当前修正估计。调用者应保证函数在区间内连续且值有限；黄金分割应选择单峰区间。插值可以外推。

`准备自然样条` 与 `准备保形插值` 接收横坐标数组、纵坐标数组与点数，返回插值表；分别交给 `自然样条插值` 与 `保形插值` 求值。坐标严格递增，点数至少为二；调用者提供至少指定点数的数组并保持其内容。自然样条的端点二阶导数为零；保形插值通过加权调和斜率保持单调。`拟合示例。豫` 演示共同均值的最小二乘拟合。

算法为独立实现，代码采用仓库许可，测试使用多项式的解析结果。后续实现布伦特极小、多元优化、非线性最小二乘、线性规划及自适应常微分方程。甲乙级验收随全部规格完成后登记。
