# 统计

提供韦尔福德在线累积、均值、指定自由度扣除的方差与标准差、中位数与第七种线性分位数、中心矩、偏度、超额峰度与加权均值。样本使用小数列表，分位数接受非空样本与零到一的概率。方差的有效样本量须大于自由度扣除值。加权样本各项为数值与权重。偏度与峰度采用总体中心矩。

`在线统计` 的三个字段按顺序为样本数（整数）、均值（小数）、离差平方和（小数）。`新在线统计` 给出零样本初态；`在线添` 接受旧状态与一个小数，返回更新状态；`汇总样本` 接受样本列表，返回该状态。`均值` 读取均值字段，`方差` 用离差平方和除以样本数减自由度扣除，`标准差` 返回同约定方差的平方根。`加权标准差` 返回加权总体方差的平方根。

测试样本为一、二、三、四，均值与中位数为 2.5，总体方差为 1.25。构建性能工具用在线统计累计各阶段均时，作为实际使用者。

新增接口：`分位定义` 接受一至九的定义号；众数同频时选择较小数；加权方差为总体方差；皮尔逊、斯皮尔曼及肯德尔相关分别采用积矩、平均秩与 tau-b；协方差矩阵输入各变量的观测列。分箱提供斯特奇斯规则与弗里德曼–迪亚科尼斯规则，直方图末箱包含最大值。

概率分布使用构造函数建立参数，统一调用 `分布密度`、`分布累计`、`分布生存`、`分布分位`。覆盖正态、学生、卡方、费舍尔、伽马、贝塔、二项、泊松、指数、均匀与对数正态。连续分布参数采用常见形状、尺度或标准差；指数分布参数为率。分位采用解析反函数或扩展上界后的二分。

十一种构造均返回 `概率分布`；构造参数依下表次序传入。除二项次数为整数，其余参数为小数。

| 构造函数 | 参数次序与约定 |
| --- | --- |
| 正态分布 | 均值、标准差；标准差正 |
| 学生分布 | 自由度；自由度正 |
| 卡方分布 | 自由度；自由度正 |
| 费舍尔分布 | 分子自由度、分母自由度；两者正 |
| 伽马分布 | 形状、尺度；两者正，均值为形状乘尺度 |
| 贝塔分布 | 甲形状、乙形状；两者正，支持区间零至一 |
| 二项分布 | 非负整数次数、零至一的成功概率 |
| 泊松分布 | 非负率，亦为均值 |
| 指数分布 | 正率，均值为率的倒数 |
| 均匀分布 | 下界、上界；下界小于上界 |
| 对数正态分布 | 对数后的均值、对数后的标准差；标准差正 |

四个统一函数均先接受分布；密度、累计、生存再接受位置小数，分位再接受零至一概率，均返回小数。二项与泊松的密度表示整数位置的概率质量，非整数位置的质量为零。累计表示不大于位置的概率，生存表示大于位置的概率，分位为达到目标累计概率的最小支持位置。

检验结果为统计量、p 值与自由度或标准化量。提供单样本学生检验、双样本韦尔奇检验、拟合优度卡方检验、曼–惠特尼渐近检验及单双样本柯尔莫戈罗夫检验。曼–惠特尼采用同值修正与连续性修正，柯尔莫戈罗夫采用渐近尾级数。线性回归输入横纵样本，返回斜率、截距、决定系数、斜率标准误及残差方差。自助置信区间接受统计函数、置信度、重复次数与种子，采用百分位法。

`多元最小二乘回归` 接受线性代数库的设计矩阵与响应样本。每行是一项观测，每列是一项解释变量，截距由调用者提供全一列。观测数大于变量数、设计矩阵满列秩。返回系数列、系数协方差、残差方差、决定系数与残差自由度；另提供系数标准误、学生统计量与双侧概率。系数通过正交分解求得，协方差为残差方差乘设计矩阵格拉姆阵的逆。

贝塔累计使用数学函数库的正则不完全贝塔连分式，学生与费舍尔累计共享这一实现。卡方与伽马采用正则不完全伽马，二项累计采用不完全贝塔，泊松累计采用不完全伽马。十一种分布的生存函数均有直接上尾路径。连续分位采用解析反函数或扩界二分，离散分位采用整数二分。零一概率按各分布支持范围返回有限端点或无穷。

参数要求：加权样本的权重非负、总权为正；相关样本等长且至少两项；分箱数与自助重复数为正，自助置信度居零一之间。分布的标准差、形状、尺度、自由度及指数率为正，泊松率非负，均匀区间递增。违规参数抛豫言异常，异常样例位于 `测试/参数。测试。豫`。

源码沿用[仓库许可](../../../../LICENSE)。独立期望值由解析公式、R 与 SciPy 的公开短向量及 NIST 的不等式构成，出处和推导见[参考值核对](参考值核对.汉语.md)。

在线约定与本包实现对应韦尔福德算法，分位定义对应R的九种分位；十一分布的参数和支持约定采用该参考值核对中列出的R分布文档及独立密度积分公式。外部参考链接用于公式与短向量核对，包源码许可沿用仓库AGPL第3版；新增平方根参考由既有独立方差5/4、3/4解析推出，常量分别为1.118033988749895、0.8660254037844386。

自助抽样复用随机数库，以整数种子新建随机源；每次抽样推进同一随机源，使用均匀整数选择样本位置，同种子与同输入可重放结果。

正态分位在正负六十四标准差内以累计或生存函数二分，高分位二分直接比较生存概率。此范围覆盖双精度的全部可表示严格零一间概率，依据见参考值核对。

测试目录备有一百七十一项独立快测参考及反函数回代补验。全量性能入口直接使用基础库测试设施的基准，十万样本预热二次，计九轮纳秒中位，并校验均值与总体方差。

整包类型检查与一百七十一项独立参考运行通过，详见[统计验证记录](测试/统计验证记录.汉语.md)。
