# 统计

具在线累积、均值、方差、标准差、中位、第七种线性分位、中心矩、偏度、超额峰度及加权均值。样本用小数列；求分位者，列须有物，概率居零一之间。求方差者，样本数须过所扣自由度。加权之项，值与权相合。

在线之术为韦尔福德。在线统计三字段依次为样本数（整数）、均值（小数）、离差平方和（小数）。新在线统计立零样本之初态；在线添受旧态与一小数，还新态；汇总样本受样本列，还此态。均值取均值字段；方差以离差平方和除样本数减所扣自由度；标准差还其方差之根。加权标准差还加权总体方差之根。

验样本一二三四，其均与中位皆二点五，总体方差一点二五。构建性能之器以在线统计计各段均时，实用之。

又具九种分位、众数、加权方差、三种相关、协方差矩阵及二法分箱。众数同频取小；加权方差用总体之法。矩阵受诸变量之观测列。

分布具正态、学生、卡方、费舍尔、伽马、贝塔、二项、泊松、指数、均匀及对数正态，皆可求密度、累计、生存及分位。指数之参为率。分位用反术或扩界后二分。

十一构造皆还概率分布，诸参依表之序。二项之次数为整数，余参皆小数。

| 构造术 | 诸参之序与约定 |
| --- | --- |
| 正态分布 | 均值、标准差；标准差正 |
| 学生分布 | 自由度；自由度正 |
| 卡方分布 | 自由度；自由度正 |
| 费舍尔分布 | 分子自由度、分母自由度；皆正 |
| 伽马分布 | 形状、尺度；皆正，均值为形乘尺度 |
| 贝塔分布 | 甲形、乙形；皆正，支持域零至一 |
| 二项分布 | 非负整数次数、零一间成功概率 |
| 泊松分布 | 非负率，亦其均值 |
| 指数分布 | 正率，均值为率之倒数 |
| 均匀分布 | 下界、上界；下界小于上界 |
| 对数正态分布 | 取对数后之均值、标准差；标准差正 |

四通术皆先受分布；密度、累计、生存继受位置小数，分位继受零一概率，皆还小数。二项、泊松之密度表整数位之概率质量，非整数位质量为零。累计表不大于其位之概率，生存表大于其位之概率；分位为累计达所定概率之最小支持位。

具单样本学生、双样本韦尔奇、卡方拟合、曼惠特尼及单双样本柯尔莫戈罗夫检验。曼惠特尼校同值与连续，柯尔莫戈罗夫用渐近尾级数。线性回归受横纵二列，还斜率、截距、决定系数、斜率标准误及残差方差。自助区间用百分位法，受统计术、置信度、重试数与种。

多元最小二乘受设计阵与响应列。阵每行一观测，每列一解释量；截距者，调用者具全一列。观测数须过变量数，阵须满列秩。还系数列、系数协方差、残差方差、决定系数及自由度，又具系数标准误、学生量及双侧概率。系数以正交分解求之，协方差以残差方差乘格拉姆阵之逆。

贝塔累计用正则不完全贝塔之连分式，学生与费舍尔共用之。卡方、伽马与泊松用不完全伽马，二项用不完全贝塔。十一分布之生存函数皆径求其尾。连续分位用反术或扩界二分，离散分位用整数二分；零一概率依支持范围还端点或无穷。

加权之权须非负、总权为正；相关诸列等长且至少二项。箱数与自助重复数为正，置信度居零一之间。分布之标准差、形、尺度、自由度及指数率为正，泊松率非负，均匀之界递增。违规者抛豫言异常，试例在测试目录。

源码从[仓库许可](../../../../LICENSE)。独立期望值由解析公式、R 与 SciPy 公开短向量及 NIST 不等式而成，出处与推导见[参考值核对](参考值核对.汉语.md)。

在线约定从韦尔福德之术，分位从R之九定义；十一分布诸参及支持域，从参考值核对所列R文及独立密度积分式。外部参照用于公式及短向量之核；本包源文从仓库AGPL第三版。新增根数参考自别定方差五除四、三除四而推，常数为1.118033988749895、0.8660254037844386。

自助抽样用随机数库，以整数之种新立随机源；诸抽样共进其源，以均匀整数取样本之位。种与输入同，则可复其果。

正态分位于正负六十四标准差内，以累计或生存术二分；高分位径比生存概率。此域包双精度可表之严格零一间概率，其据见参考值核对。

测试目备独立速验参考一百七十三项，兼反术回代补验。全量性能之验径用基础库测试设施之基准，十万样本先预热二次，计九轮纳秒中位，兼验均值与总体方差。

整包类检与一百七十一独立参考之运行皆过，详见[统计验证记录](测试/统计验证记录.汉语.md)。
