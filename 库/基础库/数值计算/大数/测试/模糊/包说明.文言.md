# 大数模糊测试

同字段性能口用公开署名向量，先行写公开二进制，以造DER公钥、署名及所期编码，继行公开同字段性能。循既有标准库之时与子进程接口，各暖一遍而量九遍取中位；系统用OpenSSL公开恢复之令，每遍验其全编码。物料皆RFC7515公开之数，造料计时皆豫言。

用基础库测试设施既有批变异之法，别验大数十进整数及任意精度十进解析。两目标受`批模糊 种子路径 起点 次数 进度路径`，每输入之序由设施录之；单例受文件路径。

解析成还零，拒还二。成功之后，表示、再解析及精确相等之验皆在处异之外，败则留其实态。字节串依标准库同文之藏视为字符串，兼验零与任意字节；两口皆用十进定点文本域。

语料取仓内所造之数、号、长数、截文，许可从仓库。正式次数及原生之果录于验收记录。此包属数值计算基础库。

公开署名向量取 RFC7515 附录 A.2 之 RSA2048 公钥、幂与署名。署名之入文由豫言精确写之，SHA256 定数由系统 OpenSSL 别算；所期整数依 PKCS1 v1.5 之 SHA256 编码成之。此口验公开模幂所得整数，其官书在 https://www.rfc-editor.org/rfc/rfc7515 。
