# 大数

同字段系统性能：RFC7515同一RSA2048公钥、指数和署名，原生九轮单次中位数1349.613毫秒；系统LibreSSL公开运算含启动、文件读写与结果核对为20.807毫秒，约64.86倍。两侧逐次核对同一完整编码块，详见《同字段系统性能记录》。三倍目标的优化列为后续事项。

三路插值已采用既有小除数商余运算，每层核对三个余数为零，保留负号。M2 Max同2048位样本优化后三路乘法20次的九轮中位数为73.403毫秒，每次3.67015毫秒；前次为每次54.2854毫秒。黄金覆盖768/1024/2048位独立平方、四种符号、负插值及Karatsuba对照，详见《三路优化记录》。

性能测量：M2 Max同机2048位样本，一次预热、九轮中位数，原生Karatsuba乘法每次2.1389毫秒、三路乘法54.2854毫秒、乘后精确除116.5638毫秒、公开指数65537模幂1133.393毫秒。对应诺节为1.3912、53.64179375、156.6540166、1913.601毫秒。样本、计次、系统C粗背景和差距见《性能测量记录》。同字段系统性能对照列为后续验收事项。

纯豫言任意精度整数，数字采用低位在前的二百五十六进制，零为非负空位列。

公开接口由总集导出：

| 接口 | 参数与结果 |
| --- | --- |
| 整数转大数、大数转整数 | 本机整数与大整数互转，转回时由调用者保证可表示 |
| 大数加、减、乘、除、余、模 | 两个大整数，返回大整数 |
| 大数除余 | 两个大整数，返回商与余数对子 |
| 大数比较 | 两个大整数，返回负一、零或一 |
| 大数绝对值、取负、开方、位非 | 一个大整数，返回大整数；开方取整数下界 |
| 大数幂 | 底数与非负大整数指数 |
| 大数模幂 | 底数、非负指数、非零模数 |
| 大数最大公约数 | 两个大整数，返回非负最大公约数 |
| 大数左移、右移 | 大整数与非负本机整数位数，右移补符号位 |
| 大数位与、位或、位异或 | 两个大整数，按无限二进制补码解释 |
| 大数解析、大数表示 | 文本与大整数互转，显式指定二至三十六进制 |
| 大端转大数、大数转大端 | 无符号大端字节串与大整数互转 |

| 造有理数 | 分子与非零分母，约分并令分母为正 |
| 有理数加、减、乘、除、比较、取负 | 精确有理运算，比较返回负一、零或一 |
| 造十进制 | 大整数系数与非负小数位数 |

| 十进制加、减、乘、比较 | 精确十进制运算 |
| 十进制除 | 两个十进制与结果小数位数，向零截断 |

普通乘法以三十二字节为阈值切换 Karatsuba；三路乘法以九十六字节为阈值，其小量回退到普通乘法。除法按二进制权重逐级试减，模幂采用平方乘。使用者数值格式库直接依赖本包。

除法向零截断，余数随被除数，模运算产生非负值。除数零与负指数抛出异常。十进制文本的正负号仅在开头，数字为零至九，小数点至多一个。无符号大端编码零输出空字节串，负数抛出异常。转本机整数由使用者保证范围。

实现只用于公开数据。密码库的秘密数据使用定宽常数时间运算。

验证：原整数、千组本机整数范围参考、精确数入口在诺节与同客体硬浮点原生均通过。128/256位固定常量、2048位独立数学恒等式、RFC7515官方RSA2048公开模幂参考均在两端通过。整数与任意精度十进制解析各正式百万变异在诺节与原生均通过；详细覆盖、客体哈希与剩余验收项目见完整验收记录。大整数随机 BigInt 差分、裸机、性能与生命周期峰值资源核验列为后续验收事项。
