# 大数

纯豫言任意精度整数，数字采用低位在前的二百五十六进制，零为非负空位列。

公开接口由总集导出：

| 接口 | 参数与结果 |
| --- | --- |
| 整数转大数、大数转整数 | 本机整数与大整数互转，转回时由调用者保证可表示 |
| 大数加、减、乘、除、余、模 | 两个大整数，返回大整数 |
| 大数除余 | 两个大整数，返回商与余数对子 |
| 大数比较 | 两个大整数，返回负一、零或一 |
| 大数绝对值、取负、开方、位非 | 一个大整数，返回大整数；开方取整数下界 |
| 大数幂 | 底数与非负大整数指数 |
| 大数模幂 | 底数、非负指数、非零模数 |
| 大数最大公约数 | 两个大整数，返回非负最大公约数 |
| 大数左移、右移 | 大整数与非负本机整数位数，右移补符号位 |
| 大数位与、位或、位异或 | 两个大整数，按无限二进制补码解释 |
| 大数解析、大数表示 | 文本与大整数互转，显式指定二至三十六进制 |
| 大端转大数、大数转大端 | 无符号大端字节串与大整数互转 |
| 大端数组转大数 | 整数数组引用、长度，返回大整数 |
| 大数转定长大端数组 | 大整数、长度，返回左补零的整数数组引用；不足以容纳时报异常 |
| 大数三路乘 | 两个大整数，使用 Toom-Cook 三路乘法 |
| 造有理数 | 分子与非零分母，约分并令分母为正 |
| 有理数加、减、乘、除、比较、取负 | 精确有理运算，比较返回负一、零或一 |
| 造十进制 | 大整数系数与非负小数位数 |
| 十进制解析、表示 | 普通定点文本与任意精度十进制互转，保留小数位数 |
| 十进制加、减、乘、比较 | 精确十进制运算 |
| 十进制除 | 两个十进制与结果小数位数，向零截断 |

普通乘法以三十二字节为阈值切换 Karatsuba；三路乘法以九十六字节为阈值，其小量回退到普通乘法。除法按二进制权重逐级试减，模幂采用平方乘。使用者数值格式库直接依赖本包。

除法向零截断，余数随被除数，模运算产生非负值。除数零与负指数抛出异常。无符号大端编码零输出空字节串，负数抛出异常。转本机整数由使用者保证范围。

实现只用于公开数据。密码库的秘密数据使用定宽常数时间运算。

验证：诺节整数向量与千组本机整数范围内的正负算术、补码位运算差分通过；五百二十一位 Karatsuba 与朴素乘法对照、千零二十四位 Toom-Cook 与 Karatsuba 对照、有理数约分相加、三十位十进制除法通过。大整数随机 BigInt 差分、原生与裸机、解析器百万变异、性能测量列为后续验收事项。
