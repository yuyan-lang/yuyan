# 大数

官定长幂：RFC3526群十四之二千零四十八位素数、生成元二及二千零四十七位指数，于诺节及同客体原生循独立欧拉判据验其所期皆过。长验置全量而明行，常CI用RFC5054公开标准短口、RFC7515公开署名短口及既有算术之验。出处、源码与客体摘要及真实退出，详官方长指数记录。

同字段系统性能：取RFC7515同一RSA2048公钥、幂及署名，原生九轮单次之中位为1349.613毫秒；系统LibreSSL公开运算兼计启程、读写及核果，为20.807毫秒，约六十四点八六倍。两术逐次验同一全编码块，详同字段系统性能记录。三倍目标之优化留后续。

三路插值用既有小除数商余之术，逐层验三余皆零而存原号。M2 Max同二千零四十八位样本，优化后三路乘法二十次九轮之中位为73.403毫秒，每次3.67015毫秒；前次每次54.2854毫秒。黄金兼验七百六十八、千零二十四、二千零四十八位独立平方、四号、负插值及Karatsuba对照，详三路优化记录。

性能已量：M2 Max同机二千零四十八位样本，暖一遍，量九遍取中位。原生Karatsuba乘法每次2.1389毫秒、三路乘法54.2854毫秒、乘后精确除116.5638毫秒、公开指数65537模幂1133.393毫秒。诺节各为1.3912、53.64179375、156.6540166、1913.601毫秒。样本、次数、系统C粗参及差距，详性能测量记录。同字段系统性能对照待后验。

纯豫言任意精度之整数，以二百五十六为率，低位在前，零为非负空列。

总集出诸术：整数与大数互转；大数加、减、乘、除、余、模、除余、比较、绝对值、取负、幂、模幂、最大公约数、整数开方、左右移、位与、位或、位异或、位非；二至三十六进制之解析与表示；无符号大端字节串与大数互转；大端数组转大数、定长大端数组输出。右移补号位，诸位术以无穷二进补码释数。定长大端左补零，幅不足则报事故。

普通乘法以三十二字节为界用 Karatsuba；大数三路乘以九十六字节为界用 Toom-Cook，小量用普通乘。除法循二进权重试减，模幂用平方乘。数值格式库依此包。

有理数以分子、分母构造，约而令分母正，备加减乘除、比较、取负。任意精度十进制以大整数系数及非负小数位数构造，备定点文本解析表示及加减乘除、比较；除法受结果小数位数，向零截之。

除向零截，余随被除者，模所得非负。除数为零、指数负则报事故。十进文之正负号唯在首，数字为零至九，小数点至多一。无符号大端之零出空字节串，负数报事故。转本机整数，调用者保其范围。

本实现唯用于公开之数。密码之秘密数，用定宽常数时间之术。

原整数、千组本机整数范围参考、精确数诸口，于诺节及同客体硬浮点原生皆过。百二十八与二百五十六位定数、二千零四十八位独立数理恒等式、RFC7515官书RSA2048公开模幂参考，两端皆过。整数及任意精度十进解析各百万正式变异，于诺节及原生皆过。所验之域、客体摘要与余项，详完整验收记录。后续验大数随机 BigInt 差分、裸机、性能及全程峰值资源。

RFC 5054两组千零二十四位公开模幂及十二例十进符号位置回归，于诺节及同客体硬浮点原生程序皆过，详窄验记录。向量出RFC Editor公开原文，唯取数值参考。
