# 线性代数系统对照

这是辅助性能可执行包，依赖标准库、线性代数和既有系统库调用，登记在数值计算基础库之下。生产核心保持标准库唯一依赖。

工具读取苹果系统自带 Accelerate 的 `cblas_dgemm` 符号，按官方 SDK `cblas.h` 的十四参数签名调用。输入是正式性能入口的六十四阶固定矩阵，结果逐元素与纯豫言分块乘比较。预热一次、五次取中位数；计量包含现有外部调用桥的开销，数据写入、读出与逐元素核对在计量区间之外。

本工具只运行系统自带库，参考接口声明来自本机官方 SDK。原生性能、诺节对照和系统内核测量分别记录，具体环境与数据见核心包《乙级实施记录》。其他系统的同等参考留作后续平台事项。
