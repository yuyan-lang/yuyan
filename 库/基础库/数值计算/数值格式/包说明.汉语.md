# 数值格式

整数进制输出和整数进制解析支持二至三十六进制，解析严格校验完整文字和六十四位有符号范围。无符号进制输出解释完整六十四位位型。

小数解析先扫描无符号六十四位短系数，以艾瑟尔—勒迈尔高低乘积守卫决定是否补乘缓存幂低字；舍入歧义与长系数转成大数有理数，二分定位二进指数后以商余就近舍偶。单精度解析直接舍入到二十四位有效二进位。小数最短和单精度最短采用龙式往返区间、定宽幂表乘移与整数除十删位，以中心余位就近舍偶。幂表按需以豫言生成，缓存取整歧义由精确大数求解。定点、科学计数和通用格式使用精确十进制系数舍入。十六进制格式按完整位型输出和解析。全流程采用豫言运算。

| 接口 | 参数 | 结果 |
| --- | --- | --- |
| 小数解析、单精度解析 | 十进制文字 | 小数 |
| 小数最短、单精度最短 | 小数 | 最短往返文字 |
| 小数定点 | 小数、小数位数 | 定点文字 |
| 小数科学 | 小数、小数位数 | 科学计数文字 |
| 小数通用 | 小数、有效位数 | 通用文字 |
| 小数十六进输出、解析 | 小数或十六进文字 | 文字或小数 |
| 解析十进数、十进数输出 | 文字或十进数 | 十进数或文字 |
| 十进加、减、乘、比较 | 两个十进数 | 十进数或比较整数 |
| 十进除 | 两个十进数、结果小数位数 | 就近舍偶的十进数 |

十进数保存任意长度有符号大整数系数和十进尺度，金额计算可以保持精确。无效文字和整数越界以豫言事故报告，调用方可以用尝试运行捕捉。

格式位数与除法结果小数位数取零至一百万。十进制文字的尺度在六十四位有符号整数范围内校验；超界以事故报告。通用格式的零值分别写作 `0` 与 `-0`。

测试包含最小次正规数、最小正规数、最大有限数、溢出、舍入中点、负零、任意精度金额和随机位型的十进与十六进往返。

测试向量来源：[Ryu d2s 官方测试](https://github.com/ulfjack/ryu/blob/master/ryu/tests/d2s_test.cc)，数据依据 2026-10-07 读取的版本，项目许可为 Apache-2.0 或 BSL-1.0。随机差分调用标准库参考解析，在诺节执行时以诺节内置数值解析为参考。

短边界测试以「测试/定宽边界。测试。豫」进入全树测试。官方双单精度龙式向量与逐指数解析差分放在「测试/全量」，可独立构建运行。静态算法实施与验收记录见「实施记录.汉语.md」。

官方双单精度龙式固定向量、逐指数解析边界与常规随机差分已经在诺节运行通过；短参数、定宽与官方固定向量的同一客体也在原生运行通过。常规测试本机当次耗时 1.76 秒，测量条件与客体校验值见实施记录。
