# 数值格式系统核验

这是独立验收包，通过既有系统库调用读取 `strtod` 与固定参数的 `gcvt`。生产数值格式的依赖保持标准库与大数。系统库函数直接从进程主映像取出，macOS 对应系统 libSystem。

短测试比较有限十进输入的完整 binary64 位型，十七位 `gcvt` 输出按往返位型核对。`gcvt` 采用指定有效位输出，最短输出采用最少往返位数；布局与文字分别记录。`snprintf` 的可变参数调用留待系统库调用支持后的测量。

性能入口将原生字符串、函数、参数列和输出缓冲提前准备，分别报告豫言解析、系统解析及十七位有效位输出的墙钟时间与消费校验值。系统测量含既有 FFI 边界费用，可用于同一调用路径的重复比较。原生热点吞吐与直接 C 循环倍率留待配套原生系统库调用路径验收。
