# 数值格式系统核验

此独立验收之包也，以既有系统库调用取 `strtod` 及定参之 `gcvt`。生产数值格式仍依标准库与大数。系统函径取进程主象，macOS 则为系统 libSystem。

短验以有限十进文校 binary64 全位型；`gcvt` 十七位之文，以往返位型校之。`gcvt` 循所授有效位而书，最短书法循最少往返位而书；布局与文字各录。`snprintf` 之变参调用，俟系统库支持而测之。

性能入口先备原生文字、函数、参列及输出缓冲，各录豫言解析、系统解析及十七有效位书法之墙钟时与消费校验值。系统之测含既有 FFI 边界之费，可供同调用路之复较。原生热路吞吐与径用 C 循环之倍率，俟配套原生系统库调用之验。
