# 数值格式静态算法稿实施记录

日期：2026-10-08。正式核心由根集成于 `2f261eb80`。本记录描述后续算法稿。全部新增算法与向量已按一百二十列格式化；编译与运行验证交 CI 及后续资源窗口。

## 龙式最短输出

从 IEEE 尾数构造四倍中心及上下舍入边界，偶数尾数允许端点。双精度和单精度各自还原有效尾数与二进指数。首次十进尺度采用龙式的整数对数近似，之后以归一化 128 位十幂缓存和定宽乘移取得中心、两倍中心及上下边界的整数部分。

缓存记录 `floor(10^q × 2^(127−floor(log2(10^q))))` 和相应二进权。下界与误差上界取整一致时得到精确商；格点恰为整数时用整除条件校正；剩余歧义交给大整数精确商。

合法系数区间统一表示为闭整数区间。每轮将下界向上除十、上界向下除十，区间仍有整数时继续删位；中心的末位与此前非零余位决定就近舍偶。首次乘移后，删位循环只做整数除十。此稿采用合法闭区间表达龙式端点与末尾零的条件。

## 艾瑟尔—勒迈尔解析

短文字扫描直接累积无符号 64 位系数，超界转精确大数扫描。先以精确小整数十幂路径处理适用的双精度输入。其余系数左移至最高位为一，先乘缓存幂的高 64 位，得到高低双字积。

守卫检查高积在目标精度加二位之外的位是否全为一。成立时补乘幂低字，并把该乘积高字加入首次乘积低字，按无符号比较传递进位。此条件对应官方 `compute_product_approximation` 的精度守卫。

设缓存值为 `C=floor(T)`，归一化系数为 `w<2^64`。真实乘积与 `wC` 的差小于 `w`。未补低乘积时，缩去低 64 位后的总误差小于一个高字单位；补乘后，低 64 位截断误差与缓存误差之和小于两个低字单位。两端舍入结果一致即返回；歧义交精确大数回退。热乘积只用两个 64 位字，调用既有定宽舍入时以数位视图装入数组。

来源：[fast_float 官方十进转二进实现](https://github.com/fastfloat/fast_float/blob/main/include/fast_float/decimal_to_binary.h)、[Ryu 官方双精度实现](https://github.com/ulfjack/ryu/blob/master/ryu/d2s.c)、[单精度实现](https://github.com/ulfjack/ryu/blob/master/ryu/f2s.c)。数学流程以豫言独立实现。

## 验证入口

在工作树使用匹配稳定宿主与编译器，入口以 `测试 定宽边界。测试`、`测试 全量 龙式官方向量`、`测试 全量 解析边界` 分别构建。例如：

```text
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 数值格式 测试 定宽边界。测试 --编译器 ./yy_bs_stable.wasm --输出 yy定宽边界.wasm -j 24
node yy稳定节点宿主/宿主.cjs yy定宽边界.wasm
```

定宽边界覆盖无符号满字乘积与进位、次正规半中点、守位粘滞位、最大有限值与溢出中点。龙式官方向量覆盖双精度与单精度的有限值类别、输出长度、回归位型与幂移位边界。解析边界逐指数 −343 至 308，比较五类系数在双单精度上的定宽解析与独立精确路径；另验十六进极指数与中点。常规入口仍为 `测试 格式。测试`，保持原随机样例数量。
