# 傅里叶变换

以豫言求复数、实数之傅里叶变换。正变换指数为负；逆变换以长除之；实数谱存自零频至奈奎斯特频。复数以实部、虚部之小数对表之；诸数以列传之。

混基取二、三、四、五、七，以库利图基分解；余长用蓝斯坦卷积。余弦变换、窗术、短时变换供音频之谱。测试程兼为初用之谱析者。

## 接口与约定

| 术 | 所受与所还 |
| --- | --- |
| 快速傅里叶变换、逆快速傅里叶变换 | 复数列；正术不缩，逆术除以长 |
| 实数傅里叶变换 | 实数列；还长除二取下整加一之复数半谱 |
| 逆实数傅里叶变换 | 受半谱及原长，还实数列，奇偶依所受长 |
| 多维傅里叶变换 | 受展平复数列、形状及逆否；行优先，末轴相续 |
| 二维傅里叶变换、逆二维傅里叶变换 | 受展平复数列、行数、列数 |
| 傅里叶卷积 | 受二实数列，还线性卷积 |
| 余弦二型变换、余弦三型变换 | 受实数列；二型直和，三型为其归一逆术 |
| 余弦四型变换 | 直和；再施之，乘二除以长，复其原 |
| 修正余弦变换、逆修正余弦变换 | 双长入则半谱出，逆还双长帧，乘二除以谱长；音频用者施窗、重叠而加 |
| 汉宁窗、汉明窗、布莱克曼窗、凯泽窗 | 受长，凯泽并受贝塔；对称窗以长减一为母，独点得一 |
| 短时傅里叶变换 | 受实数列、窗及正步；自零取全帧，还半谱之列 |
| 单精度傅里叶变换、逆单精度傅里叶变换 | 受复数列；每算舍偶至二进三十二位，以标准库小数对载之 |

余弦及修正余弦径求其和。单精度专径以混基蝶形、素数直合成之。双精度先验长之因子二三五七，择混基或蓝斯坦卷积。空列还空；形状之积须合元素之数。窗长非负，短时窗与步皆正。

## 测试与数据

频谱测试兼示四点实数谱析。依离散傅里叶定义，一二三四之谱为十、负二加二虚、负二、负二减二虚。验空、诸基、混基、十一质数及含十一因子之长，以朴素术逐项校之；验能量、复数实数往返、余弦二三型四型往返、二维往返、卷积、窗及帧数。数据由数学定义推得，代码循仓库许可。
