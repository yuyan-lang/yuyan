# 傅里叶变换

纯豫言复数与实数傅里叶变换。正变换采用负指数，逆变换按长度归一化；实数变换保存零频至奈奎斯特频率。复数表示为实部与虚部的小数对，数组接口采用列表。

混合基采用二、三、四、五、七的库利图基分解；其他长度采用蓝斯坦卷积。余弦变换、窗函数与短时傅里叶变换用于音频频谱。测试程序也是第一个谱分析使用者。

## 接口与约定

| 接口 | 输入与输出 |
| --- | --- |
| 快速傅里叶变换、逆快速傅里叶变换 | 复数列表；正变换无缩放，逆变换除以长度 |
| 实数傅里叶变换 | 实数列表，返回长度除二向下取整加一的复数半谱 |
| 逆实数傅里叶变换 | 半谱与原始长度，恢复实数列表；奇偶长度由调用者提供 |
| 多维傅里叶变换 | 展平复数列表、形状列表、逆否；行优先存储，末轴连续 |
| 二维傅里叶变换、逆二维傅里叶变换 | 展平复数列表与行数、列数 |
| 傅里叶卷积 | 两个实数列表，返回线性卷积 |
| 余弦二型变换、余弦三型变换 | 实数列表；二型为无系数余弦和，三型按二型的逆变换归一化 |
| 余弦四型变换 | 无系数余弦和；两次变换乘以二除以长度恢复输入 |
| 修正余弦变换、逆修正余弦变换 | 两倍长度输入变为半长谱；逆变换得双长帧，系数为二除以谱长；音频调用者施窗并重叠相加 |
| 汉宁窗、汉明窗、布莱克曼窗、凯泽窗 | 窗长；凯泽窗另收贝塔；对称窗以长度减一作分母，单点窗为一 |
| 短时傅里叶变换 | 实数列表、窗列表与正步长；从零开始取完整窗帧，返回半谱列表 |
| 单精度傅里叶变换、逆单精度傅里叶变换 | 复数列表；逐次四则采用二进制三十二位舍偶，复数载体为标准库小数对 |

余弦、修正余弦直接求和。单精度专用路径采用混合基蝶形与直接素数合并。双精度任意长度路径先识别二三五七平滑长度，再选择混合基或蓝斯坦卷积。空序列保持为空；多维形状与元素数量须一致。窗长须非负，短时变换的窗和步长须为正。

## 测试与数据

`测试/频谱。测试。豫` 同时演示四点实数信号的谱分析。解析向量取自离散傅里叶定义：[1,2,3,4] 的谱为 [10,-2+2i,-2,-2-2i]。测试覆盖零长度、二三四五七基、混合基、十一质数及含十一因子的长度，与朴素变换逐项比较；验证帕塞瓦尔恒等式、复数与实数往返、余弦二三型与四型往返、二维往返、解析卷积、窗函数和短时帧数。数据由数学定义直接导出；代码采用仓库许可。
