# 数值类型

三十三字节串解码入口于诺节各行百万定种变异，共三千三百万入数；万项一子程，限六十万毫秒，退码与确序皆核，长程出零。三十三项同客体双端基准已测，时值与所行之况，见解码基准记录.汉语.md。进程生命周期之资源、同机C性能对校及余裸机入口，别续验之。

冻结浮点试客体于QEMU 11.1.2之ARM裸机实过：半精六万五千五百三十六位型循环、脑浮16、浮点边界、单精串转半精群化及尾截、Q8_0零块断言皆竟，印“数值类型浮点测试通过”，子程与QEMU皆自然出零。客体及复用内核之身份，见实施记录。

IQ2_S私编码用官单位重要性权sqrt(σ²+x²)，终公共半精尺度乘0.9875；子尺度依微调前尺度藏之。五百一十二项正负三十一周期之官载荷，一百六十四字节皆同，完整固定载荷已接全树CI试。

IQ3_XXS私编码用单位重要性参权sqrt(σ²+x²)，σ²取块平方和之二倍除二百五十六。正负三十一周期五百一十二项之官量化载荷，一百九十六字节皆同，独立固定载荷已接全树CI试。IQ3_S循无外授重要性之官参径。

Q2_K拟合依官ARM64量化器融合乘加之舍序；私快径遇单精中点，则用数学函数包精确融合核。数学函数为此径直接所依。固定中点、次正规、负零、溢出、非有限及五百一十二组三元乱位，校精确核皆过。

供半精度、脑浮16、单精度位形、八位浮点五二、八位浮点四三有限式、四位浮点二一与双精度小数相化。以整数藏低精度之位形，取近而舍偶。半精度、脑浮16、单精度、八位浮点五二存有符号零、非数、无穷。八位浮点四三之中点四百六十四取四百四十八，逾者为非数；四位浮点限于正负六，非数化有符号零。

字节串群化用小端位形，供单精度、双精度与半精度、脑浮16八术相化。通术受源宽、解术、目的宽、编术；尾不足一项则告事故。四位整数先藏低位、次藏高位；解术受项数与有符号之标。

Q8_0编解受字节串，三十二单精度为块，编成三十四字节：小端半精度尺度在先，三十二有符号八位数在后。参考术见 [GGML 量化实现](https://github.com/ggml-org/ggml/blob/master/src/ggml-quants.c)。浮点试穷举半精度位形，验舍偶、有符号零、溢出、次正规、群化截断。

Q4_0、Q4_1、Q5_0、Q5_1编解之名，为量化四零、四一、五零、五一之编码与解码。块受三十二项，长依次十八、二十、二十二、二十四字节。尺度用小端半精度；一系兼存最小值，五位系兼藏第五位之表。MXFP4之微四编码、解码，每块三十二项、十七字节，共指数而藏四位浮点，等距取先见之形。量化试核常量向量之尺度位形、块长、全还原，并验五零高位表与正负相杂向量。

Q2_K、Q3_K、Q4_K、Q5_K、Q6_K、Q8_K之量化超二、超三、超四、超五、超六、超八编码与解码，皆受小端单精度字节串；块有二百五十六项，长各八十四、一百一十、一百四十四、一百七十六、二百一十、二百九十二字节。仿射式拟子尺度与最小值，对称式拟带符子尺度；Q8_K藏单精度尺度、八位码及十六项分组和。IQ4_NL、IQ4_XS之量化非线性四、量化非线性超四编解，各三十二项十八字节、二百五十六项一百三十六字节，编以十六非线性格与加权候选尺度拟之。

算法格值据[定版GGML参术](https://github.com/ggml-org/ggml/blob/ffa4e8b80930029a35991f94e7c8a93cd67730ab/src/ggml-quants.c)，外来数据之许藏于数据许可.txt。最新25a843全配链之全库型检，与六K循环向量、六K全固定字节位型、IQ4非线性固定格向量，皆于诺节实行为过。固定位型逐字节核独立推导之向量；Q6循环样本之差限，以半全幅量步16/31、子尺度舍差32/256、半精度尺度余量0.02合之。官可行参术之差分、原生之行，别验之。

总集公出IQ1_S、IQ1_M、IQ2_XXS、IQ2_XS、IQ2_S、IQ3_XXS、IQ3_S十四编解入口，及FP8、FP4与单双精十二群化入口；名与全签见[公接口规范](规范.文言.md)。IQ1以加权平方差穷举三码之界与八分之一偏，IQ2/IQ3循分组候选尺度、整数邻格级与加权相关量搜；IQ1、IQ2及IQ3极小用单位重要性，IQ3常循无外授重要性之官参径。官六格原文SHA-256为0061131b615c5721fc88a78feeb22c1f8c450f1c2646a317d80796a653bf595c，源定版GGML之ffa4e8b80930029a35991f94e7c8a93cd67730ab。旧七式载荷解码、零块、非零分组归一平方差、IQ1解析及十二微浮点规格向量皆过。全树CI由总集入公IQ零块基本试与十二微浮点固定短试。

浮点、量化、六K循环、六K全固定位型、IQ4、IQ1解析、七IQ固定载荷与零块、七IQ非零、十二微浮点群化，共九组短试，皆用同一Wasm客体造预编二原生而实行为过，其stdout与诺节逐字节同。原生二器之配及日志，见实施记录.汉语.md。

IQ4_NL依官quantize_iq4_nl之ntry七式，搜十五尺度而复取终码；quantize_row_iq4_nl_ref之ntry负一式存初码与最小二乘尺度，私拟存之。既有llama-quantize 0.5.0及GGML 0.25.3所出恒一、正负三十一周期两类五百一十二项载荷，IQ4_NL、IQ4_XS逐字节皆合。旧固定格期望如故，25a843诺节与同客体预编二原生皆过，stdout逐字节同。
