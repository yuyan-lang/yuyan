# 随机数

本包提供 SplitMix64 播种、Xoshiro256** 可复现随机源、53 位精度的 `[0,1)` 均匀小数与拒绝法无偏均匀整数。只依赖标准库。

`新随机源(种子)` 创建 Xoshiro256**；`下一随机整数(源)` 输出六十四位位型；`均匀小数(源)`、`均匀整数(源,上界)` 提供抽样。上界须为正整数。`新分混源` 与 `分混下一整数` 提供 SplitMix64。

算法依据公开的 SplitMix64 与 Xoshiro256** 参考实现公式，代码由豫言独立实现。后续事项：PCG64 DXSM、Philox、MT19937、Lemire、Ziggurat、其他分布、别名法、抽样工具、多维正态、Sobol、统计检验与平台性能验收。
