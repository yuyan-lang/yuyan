# 随机数

本包提供 SplitMix64 播种、Xoshiro256** 可复现随机源、53 位精度的 `[0,1)` 均匀小数与 Lemire 宽乘拒绝法无偏均匀整数。只依赖标准库。

`随机数/梅森` 提供 MT19937：`新梅森源(种子)`、`梅森下一整数(源)` 输出三十二位无符号整数。种子 5489 的首个输出为 3499211612，第一万个为 4123659995，测试均已通过。

`随机数/费洛克斯` 提供 Philox4x32-10：`费洛克斯十轮(四个三十二位计数器,键甲,键乙)` 返回四个三十二位整数。计数器与键全零的 Random123 已知答案测试通过。调用者显式指定计数器与键，可以复现各框架采用的计数器映射。

`新随机源(种子)` 创建 Xoshiro256**；`下一随机整数(源)` 输出六十四位位型；`均匀小数(源)`、`均匀整数(源,上界)` 提供抽样。上界须为正整数。`新分混源` 与 `分混下一整数` 提供 SplitMix64。

`随机数/抽样` 提供 `洗牌`（Fisher–Yates，泛型数组、显式长度）、`无放回抽样`（从零起的索引列）、`蓄水池抽样`（Algorithm R，泛型列表输入、数组输出）。取数与容量须介于零与输入长度之间。排列唯一性与蓄水池范围测试通过。

`随机数/分布` 提供极坐标法标准正态、指数（率）、伽马（形、尺度）、贝塔（两形）、狄利克雷（形状列）、二项（次数、概率）、泊松（率）、几何（概率，结果为首次成功前失败次数）与冈贝尔。形、尺度、率为正，概率属于 `(0,1]`。九类分布各一万次均值检验通过。

`随机数/别名` 提供 Walker–Vose 别名法：`建立别名表(权重数组,长度)` 预处理非负权重（总权重为正），`类别分布(源,表)` 常数时间取类别索引，`多项分布(源,表,次数)` 返回每类命中次数。1:2:7 权重的一万次频次测试通过。

`随机数/置换同余` 提供 PCG64 DXSM，`新置换同余源(状态低,状态高,增量低,增量高)` 按明确的 128 位状态与奇增量建源，`置换同余下一整数` 输出六十四位整数。公式核对 [NumPy 参考源码](https://github.com/numpy/numpy/blob/main/numpy/random/src/pcg64/pcg64.h)。状态转移、128位宽乘边界、Lemire最大正上界与单位上界一万次测试通过。

算法依据公开的 SplitMix64 与 Xoshiro256** 参考实现公式，代码由豫言独立实现。后续事项：Ziggurat、多维正态、Sobol、PCG参考输出向量、卡方与 KS 检验、原生与裸机测试、平台性能验收。
