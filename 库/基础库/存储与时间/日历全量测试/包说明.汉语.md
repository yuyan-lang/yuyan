# 日历全量测试

本包测试 RFC3339、ISO8601、HTTP、RFC5322、中文与 strftime 模式六个解析入口。每入口一百万个确定性变异，分一百个万次隔离批。每次调用前写当前编号，崩溃或超时保存精确样本，附重放参数。合法拒绝返回二，接受返回零。

执行工具的「批 入口 起点 次数 进度路径」命令运行一批；「重放 入口 编号」运行一个样本；「全量」依次隔离全部六百万；「烟测」每入口二十五次。批次截止时间为二十分钟。正式计数、资源及平台结果在运行后登记。

默认无参数执行烟测，便于全树测试发现。独立入口「时区变异。测试」读取随包的真实纽约 TZif 数据，使用相同编号变异与隔离方法运行一百万个二进制输入；失败样本的精确编号 386 已暴露转换类型索引越界，修复后重放为合法拒绝。六日期与修复后的 TZif 在 Node、硬原生分别完整完成七百万次，共十四百万次，全部批末序核对通过；详见 `正式百万验录.汉语.md`。峰值资源、其余入口及平台继续验收。

TZif 修复后完整一百万在 Node 和硬原生均通过，100 个隔离批逐批核对末序，最终为 999999。独立入口「官方农历核验」读取仓外香港天文台 1901—2100 年原表，在两端均完成全部 73049 日对照，每年断言 365 或 366 日，并断言总数。官方原表依据官网使用条件保留仓外，来源为 `https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T<年份>c.txt`。

独立入口「尾规则变异。测试」在未来 2128 年时刻直接解释 POSIX 尾规则，Node 与硬原生各完整一百万，末序 999999；详见 `尾规则百万验录.汉语.md`。本包目前已验八个入口每后端各百万，合计十六百万。峰值资源、其余入口及平台继续验收。
