# 日历全量测试

此包验 RFC3339、ISO8601、HTTP、RFC5322、汉语及 strftime 模式六解析入口。各生百万确定变异，分百隔离批，各万次。每召术先记序，崩或逾时则存确样并附复行之参。拒还二，纳还零。

器受「批 入口 起点 次数 进度路径」而行一批；受「重放 入口 编号」而行一样；「全量」次隔行六百万；「烟测」诸口各二十五次。批限二十分钟。正式数、资源及平台之果，行后录之。

无参则烟验，以便全树求验。别入「时区变异。测试」，取随包纽约真 TZif，以同法行百万二进输入。确序三百八十六显转换类序逾界，修后复行则依法拒之。六日期与修后 TZif 于 Node、硬原生各成七百万，合千四百万，诸批末序皆验；详 `正式百万验录.汉语.md`。峰值资源、余入口及平台续验。

修后 TZif 百万于 Node 与硬原生皆过，百隔离批逐核末序，终为九十九万九千九百九十九。别入「官方农历核验」，读仓外香港天文台一九零一至二一零零年原表，两端皆验七万三千四十九日；逐岁核三百六十五或三百六十六日，并核总数。官方原表依其用约留仓外，源为 `https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T<年份>c.txt`。
