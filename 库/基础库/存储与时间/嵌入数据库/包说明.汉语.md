# 嵌入数据库

键值存储以字节串为键和值，按字节序排列。只读事务持有不可变页树快照，叶页与分支页各容纳 32 项。写事务在同一数据库实例中独占写锁，提交后发布新快照；回滚释放写锁。

日志包含长魔数、负载长度、校验值及完整键值快照。负载使用十六进位数码编码，值中的帧内容与外层帧边界保持区分。恢复扫描完整帧，跳过截断或校验失败的帧，返回最后完整快照；残尾后可以继续追加。范围遍历使用左闭右开边界；前缀遍历保留按键排序。

`文件持久` 模块通过目录权文件接口打开、追加、读取及关闭日志。部分写入继续写完，失败时内存保持旧快照。完整帧写成后关闭失败的磁盘提交结果可能不确定，重开可能恢复该帧。页树按首次查询解码叶页，重复查询使用缓存，「淘汰页树缓存」释放解码条目。`分页持久` 提供独立主数据文件与保留 WAL 的检查点，先提交日志，再写主数据页；主图像损坏时重放完整日志。文件落盘同步、按偏移定位读取、增量脏页与日志回收列为后续事项；断电耐久验收随同步完成。

用户态桌面的字体设置是第一个使用者。桌面在已授“桌面”目录中打开 `yy桌面设置.数据库`，启动时恢复字体，选择字体时提交事务；只读会话保留会话内设置。包索引迁移列为后续事项。

设置持久测试已核对默认值、提交、重开恢复与未授权回退；真实图形回归列为后续事项。当前整包类型检查及主数据页的 Node、硬原生测试通过，内嵌帧全截断与真实目录权故障验收继续执行。甲乙级保持实施状态。

关系查询入口在 `关系查询/引擎`、`关系查询/文本` 与 `关系查询/接口适配`。后者提供授权内存会话的四个 JSON 关系函数，依赖结森工具；参数按词元绑定，结果按列声明保持整数、布尔与空值。关系查询测试位于 `测试/关系查询/`。文件页树与关系会话接入列入后续事项。

SQL 文本支持 INSERT 指定列名，并按表列顺序补齐行；ORDER BY 支持投影列的正整数序号。`测试/关系查询/逻辑子集。测试。豫` 固定 SQLite 官方 sqllogictest `select1.test` 的首个建表、三十条插入以及 e、b、d 三列的排序查询，用于与系统 SQLite 逐行核对。
