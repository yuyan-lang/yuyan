# 嵌入数据库

SQLite 唯读表名之查，循编码转换篇，依档编码取八位、十六位小端或大端。记录字段存序列之型及原字节。

键与值皆字节串，循字节序。读事务执不变页树之本，叶与枝各容三十二项。写事务独执一库之锁，录成则布新本，弃则释锁。

日志有长魔数、载长、校验及键值全本。载荷以十六进之码录，值内之帧与外帧之界各辨。复原循成帧，越残帧与验失者，取末成帧；残尾后可续录。范围取左闭右开，前缀取同首之键，皆循键序。

文件持久循目录权开文、追加、读取、关闭。未尽则续写，败则内存留旧本。全帧既录而闭文失，磁盘提交之果或未定，再开或复此帧。初查解叶，再查循缓存，「淘汰页树缓存」释解码之项。分页持久设独立主数据文与保留日志之检查点，先录日志，继录主数据页；主象毁则重放全日志。落盘同步、按偏移读、增量脏页与日志回收留后补；同步成而后验断电。

用户态桌面之字体设置首用此库。桌面于已授目录开 yy桌面设置.数据库，启动复字体，选择则录事务；惟读之会存会内设置。包索引迁移列于后补。

设置持久之验已核默认、提交、复启与未授之退；实图形复验列于后补。今全包类型之核、主数据页诺节与硬原生之验皆过，嵌帧尽截断与实目录权故障之验续行。甲乙尚在施作。

关系查询之门在 `关系查询/引擎`、`关系查询/文本` 及 `关系查询/接口适配`。后者依结森工具，供所授内存会话四 JSON 关系术；参数缚于词元，结果依列类存整数、爻及空值。测试在 `测试/关系查询/`。接文件页树于关系会话，列入后续之事。

SQL 文本可于 INSERT 指列名，循表列次补行；ORDER BY 可取投影列之正整数次。`测试/关系查询/逻辑子集。测试。豫` 取 SQLite 官方 sqllogictest `select1.test` 首建表、三十插句及 e、b、d 三列排序之查，以与系统 SQLite 逐行相验。

`关系查询/快照` 以有版本之 JSON 存单一所授会话之表、列型与插入号；复原先尽解而验，乃以调用者所定授名布之。`关系查询/持久` 纳快照于所定键值键，复用事务提交与日志复原。共用关系适配以「登记关系存储」系保存之处，语句与批行成则存已提交之态，SQL 事务待结束而存。持久提交败时内存已改；闭文败或令提交未定，调用者可重开验日志。落盘同步与断电耐久之验，列入后续之事。

主数据页循偏移惰读之口，见《惰读页.文言.md》。「打开惰读主数据页树」用于使用时守内容之文件；缓存未中，则以正定位读术取其页，逾容淘汰而释解码条目。

测试依基础库测试设施，日志批变异之口备录序、单例复行及百万隔离驱动；全树默认行千二十四次小验。召法见 `测试/日志批变异.文言.md`。
