# 内存关系查询

`引擎。豫` 以豫言治内存之关系表。行藏串列，表藏名、列名及诸行。`关系建表` 立表，`关系插入` 验列数，`关系查询` 受行谓词，`关系更新`、`关系删除` 还所及行数。

`关系排序` 受行比较之术，`关系分页` 受偏移与限额，`关系连接` 依谓词合诸行，`关系分组` 依列号聚行，`关系聚合` 取整数而求其和。组中行序因其旧。

`关系建索引` 依列名成键与诸行之快照，`关系索引查询` 依键取行。表既改，用者复建其索引。`关系列号` 依名求号，`关系改列` 易一字段而成新行。

`关系开始事务` 还全库不可变之快照，`关系回滚` 复其旧，`关系提交` 成内存之事。事务供一用者循序而行。久存之事由数据库存储模块主之。

`文本。豫` 析 SQL 文而行建表、插入、查询、更新、删除及 BEGIN/COMMIT/ROLLBACK。查询可投影字段、依 WHERE 等值及数值比较筛行、接同类 AND/OR 条件、以整数 ORDER BY 排序、用 LIMIT 限数、等值合两表、依 GROUP BY 分组，并求 COUNT/SUM/MIN/MAX/AVG 整数聚合。关键字兼受大小写，串用单引号。列类留存，以供 JSON 适配转整数、爻及空值。COUNT 字段略空，全空 SUM/MIN/MAX/AVG 还空值，AVG 取整数商。

后续事项：AND/OR 杂式之先后与括号、浮点均值、多用者事务隔离、SQL 文本索引登记。

测试之门在 `../测试/关系查询/`。`引擎。测试。豫` 验建表、增删改查、连接、分页、分组聚合、排序及事务回滚。

`文本。测试。豫` 验 SQL 文、连接、分组聚合及事务回滚。于 pit-mac 构建而行，皆成。SUM/MIN/MAX 与 GROUP BY 所得为 `70|10|40`、`甲|2|10`，与系统 SQLite 以同数据所查者同。

`接口适配。测试。豫` 于 Node 与 Mach-O arm64 预编二硬原生之程皆成，所书逐字节同。验整数、爻、空值、败批回滚、参数数组、恶意形似之文、问号字面、关键字缚参及全空聚合。此验召内存接口之实现；正式系统宿主装载及文件久存之接，列入后续验收。

语句批败则复批前之表、列型、插入号与活动事务快照。批中 BEGIN 而后败，复无事务之态；外事务既开，批中 COMMIT 而后败，复外事务，调用者仍得弃改而还其起点。CI 自寻接口适配测试，验其回归。

「关系建维护索引」持源库、表名、列名与缓存；「关系维护索引查询」验共用写版，关系写术或弃改之后惰性重建，再以键取行。既有「关系建索引」仍供独立快照。共用写版于他库写入时亦失效，索引属其源库对象；版本之验取常数步，键组之寻仍循列表。

事务已开而复 BEGIN，则陈明误而存旧快照，调用者仍得弃改而还首次 BEGIN 之起点。
