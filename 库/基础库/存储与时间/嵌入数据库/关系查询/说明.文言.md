# 内存关系查询

`引擎。豫` 以豫言治内存之关系表。行藏串列，表藏名、列名及诸行。`关系建表` 立表，`关系插入` 验列数，`关系查询` 受行谓词，`关系更新`、`关系删除` 还所及行数。

`关系排序` 受行比较之术，`关系分页` 受偏移与限额，`关系连接` 依谓词合诸行，`关系分组` 依列号聚行，`关系聚合` 取整数而求其和。组中行序因其旧。

`关系建索引` 依列名成键与诸行之快照，`关系索引查询` 依键取行。表既改，用者复建其索引。`关系列号` 依名求号，`关系改列` 易一字段而成新行。

`关系开始事务` 还全库不可变之快照，`关系回滚` 复其旧，`关系提交` 成内存之事。事务供一用者循序而行。久存之事由数据库存储模块主之。

后续事项：析 SQL 文本而行之、列类与空值、多用者事务隔离、自动养护索引。

`引擎。测试。豫` 验建表、增删改查、连接、分页、分组聚合、排序及事务回滚。
