# SQL按列声明排序

此前SQL ORDER BY把每个字段强制读为整数，中文文本会失败，数字文本的次序也不遵TEXT声明。SQL执行路径现在通过局部选择闭包携带当前会话列声明，排序调用私有排序值模块：整数按数值、文本按UTF-8字节，升序空值在首、降序空值在末；限定字段匹配其来源表与列。

保留原公开查询选择签名及实现路径，SQL执行词内的新闭包负责声明类型排序。私模块仅依赖标准库，文本仅命名导入私模块，无全局动态上下文、无依赖环、无总集变更。

CI覆盖数字TEXT 10在2之前、中文甲、NULL升降序、INTEGER值2/7/10以及JOIN限定文本字段。120列格式化和差异检查通过，新增行为交CI运行，不以本地长验阻塞合入。
