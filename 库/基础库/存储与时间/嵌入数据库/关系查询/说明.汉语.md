# 内存关系查询

`引擎。豫` 提供纯豫言的内存关系表。每行保存字符串列表；表保存名称、列名和行集合。`关系建表` 创建表，`关系插入` 校验列数，`关系查询` 接收行谓词，`关系更新` 和 `关系删除` 返回受影响行数。

`关系排序` 接收行比较函数，`关系分页` 接收偏移及限额，`关系连接` 执行带谓词的内连接，`关系分组` 按列号生成分组，`关系聚合` 对取值函数求整数和。分组的行顺序与输入一致。

`关系建索引` 生成指定列的键到行集合快照，`关系索引查询` 按键取行。修改表后调用者重建索引。`关系列号` 按名称定位列，`关系改列` 生成替换一个字段的新行。

`关系开始事务` 返回整个库的不可变快照，`关系回滚` 恢复快照，`关系提交` 完成当前内存事务。事务用于单一调用者的串行操作。持久化由数据库存储模块提供。

`文本。豫` 提供 SQL 文本分词、建表、插入、查询、更新、删除与 BEGIN/COMMIT/ROLLBACK。查询支持字段投影、WHERE 等值、整数 ORDER BY、LIMIT、两表等值内连接、GROUP BY 和 COUNT/SUM/MIN/MAX/AVG 整数聚合。SQL 关键字使用大写；字符串使用单引号。列声明记录类型，供 JSON 适配转换整数、布尔与空值。AVG 结果取整数商。

后续事项：更多 WHERE 运算、浮点平均值、多调用者事务隔离及自动维护索引。

测试入口为 `引擎。测试。豫`，覆盖建表、增删改查、连接、分页、分组聚合、排序及事务回滚。

`文本。测试。豫` 覆盖 SQL 文本执行、连接、分组聚合与事务回滚。在 pit-mac 构建运行通过；SUM/MIN/MAX 和 GROUP BY 的输出分别为 `70|10|40`、`甲|2|10`，与系统 SQLite 的同一数据查询结果一致。
