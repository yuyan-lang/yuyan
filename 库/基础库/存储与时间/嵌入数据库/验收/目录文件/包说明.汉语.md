# 目录文件验收

这个程序通过现有目录权文件接口验收数据库追加日志、二进制值重开、所有字节截断点及内嵌帧恢复，以及主文件检查点、损坏主图像和检查点失败后的 WAL 重放。启动器授予本次新建空目录，名称为“数据库验收”；程序在该目录操作 `yy真实文件恢复.数据库`、`yy分页主数据.数据库` 与 `yy分页事务.日志`，以缺失父目录触发主文件写入失败。

包描述使用 `。包。豫.txt` 模板，交给已有双宿主构建器自动模式复制为实际验收包，复用已有文件适配与宿主支持清单。源码为纯豫言。

目录中另预置测试样本「关系库官方工具样本.数据库」，程序通过正式只读目录权入口查询其80行、负整数及溢出链。日志、分页故障及只读样本验收已经 Node 和硬原生实际运行通过，记录见《双端验收记录》。落盘同步与实机断电验收列为后续事项。

入口另含独立快照文件与增量 WAL 的正式目录验收源码。快照用两个路径保存前后版本，缓存淘汰后核对旧值，路径冲突拒绝覆盖。增量日志核对两次提交后的真实文件重开与删除重放。新增路径的运行证据由定位读取后端接线后补充。
