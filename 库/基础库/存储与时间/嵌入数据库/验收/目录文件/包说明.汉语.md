# 目录文件验收

这个程序通过现有目录权文件接口验收数据库追加日志、二进制值重开、所有字节截断点及内嵌帧恢复，以及主文件检查点、损坏主图像和检查点失败后的 WAL 重放。启动器授予本次新建空目录，名称为“数据库验收”；程序在该目录操作 `yy真实文件恢复.数据库`、`yy分页主数据.数据库` 与 `yy分页事务.日志`，以缺失父目录触发主文件写入失败。

包描述使用 `。包。豫.txt` 模板，交给已有双宿主构建器自动模式复制为实际验收包，复用已有文件适配与宿主支持清单。源码为纯豫言。

日志真实文件验收已经 Node 和硬原生实际运行通过。分页故障验收已经 Node 运行通过，硬原生运行结果记入《双端验收记录》。落盘同步与实机断电验收列为后续事项。
