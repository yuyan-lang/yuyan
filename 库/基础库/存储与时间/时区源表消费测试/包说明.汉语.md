# 时区源表消费测试

这是独立可执行测试包。私有读取器 `解析时区源表` 读取 `时区数据/源生成。豫` 已有的 YTZ1 文本表，产出日历紧凑时区四元记录列表。本包直接依赖标准库、时区数据与日历，登记在存储与时间基础库下。

首行五字段为 YTZ1、数据版、时区名、起年与终年。数据版与时区数据版本一致，年份窗口有效。记录行采用标准制表符分隔四字段：协调世界秒、总偏移秒、缩写、夏令标记。数字按有符号64位十进制严格读取，夏令标记为0或1。首记录位于窗口首日，其余记录位于窗口内，秒数按非递减顺序保存；同秒的后一条记录由日历消费时生效。每行字段数受检，记录行数实际统计；尾部允许一个空行。

年份范围取正负一亿年，偏移范围取正负八百六十四万秒。此范围给日历换算的整数加减留足余量。缩写字段逐字节检查控制字符。

入口 `消费。测试。豫` 默认执行固定期待向量。附加参数为“源表路径 协调世界秒”时，查询秒在源表年份窗口内时，工具读取落盘文件、调用日历紧凑时区接口并打印记录数、偏移、夏令标记与当地秒。后续验证可先执行原有源生成入口，再把它写出的路径交给本工具。

独立向量覆盖固定协调世界时、纽约2024年两次切换的前一秒与切换秒、进钟缺口、退钟双候选、同秒记录顺序及非法字段。期待 Unix 秒由系统 `date -j -u -f` 查询取得，时差与夏令标记由限定年份的 `zdump -v -c 2024,2025 America/New_York` 取得。期待值保存为常量。
