# 系统消息扩展

`读取系统消息` 接受 MO 原始字节串与系统段替换字典，返回错误文及原译字节串对列表。错误文为空表示成功；字典项为段名称与替换字节串。结果保留内部零字节，去掉每个展开字符串的最终零，供消息层统一按目录字符集解码。

高 16 位为主版本，低 16 位为次版本。主版本 0、1 的次版本 0 返回空扩展列表；次版本至少 1 按 48 字节扩展头读取。0.1 的版本数为 1，1.1 为 65537。大小端按 MO 魔数识别。扩展头、散列表、名称表、原译索引表、描述符与静态段均按文件边界检查。

普通描述表由消息层读取，再与这里返回的扩展对合并。系统段替换由调用方提供，例如 `PRId64` 对应 `ld`；引用未知系统段的整对原译消息略过，符合 GNU 加载行为。段序号越界、名称或末段缺少结尾零返回错误。字典值由调用方保存为无结尾零的替换内容。

格式出处为 GNU gettext 官方仓库的 [gmo.h](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-runtime/intl/gmo.h) 与 [loadmsgcat.c](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-runtime/intl/loadmsgcat.c)。上游文件由 Free Software Foundation 以 LGPL 2.1 或后续版本发布；本模块根据公开格式独立用豫言实现，静态用例为自行构造的真实 MO 字节布局。

测试源码覆盖小端 0.1、大端 0.1、1.1、有效替换、未知替换与截断。当前按任务调度仅作静态交付，构建与运行验证留待整合。
