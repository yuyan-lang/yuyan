# 固定关系的末元素补正

固定CLDR48中文规则的多元素重置采用[release-48官方关系规范](https://github.com/unicode-org/cldr/blob/release-48/docs/ldml/tr35-collation.md#orderings)：关系选择最后具足该强度的元素，保留此前元素，删除其后较弱元素，再调整该级并恢复较弱级公共值。完全忽略的锚归为单个零元素。官方原规范读取SHA-256为 `2cf9209cdcc7bfdc0dfb01e774027ac5358d0ebfca4ba28cf8f69509dd6855e7`；文件保留Unicode来源及许可引用。

私有 `地区调整关系` 保持现有参数、增量与返回类型，使用反向剔弱选择末元素。固定XML的 `&令和<<<㋿`、`&株式会社<<<㍿` 原样保留前面的令、株式会元素，仅提高末元素三级权重。公开总集、包父登记与ABI保持原样。

新增 `测试/固定关系末元。测试。豫` 共19项：七个独立三元元素向量覆盖三级选择、截尾、完全忽略、before 2及前元保留；拼音和笔画分别对两个官方多码重置验证前元、末主次与末三级，共十二项。

先对冻结650旧算法构建同一入口并实际运行，退出1：`主级关系截次级与三级尾`。输入 `[(10,32,2),(0,7,2),(0,0,5)]`，规范预期仅 `[(999910,32000000000,2000000000)]`，旧算法保留后两个元素。旧guest SHA-256为 `fceabbfcd725f75ba9809eb9b3284a4b371e01e2ee940f7a8c317261e3d85483`。

随后仅替换私有算法，保持19向量及两表原样，在同一25a843完整工具链、同一缓存上构建运行。Node及E44/E801同guest硬原生均退出0，输出 `固定关系末元十九项通过`，错误输出均为空，标准输出 `cmp` 相同。新guest SHA-256为 `403ae39e038e2a4b76d7042540029218b3141e88d0ec58902f87fbb140e10d4e`，自有exe为 `e58b0ba8dbf95a698bc084276bedb3d8ac0e7111bc88ba6704fba456604e763e`。硬原生直接运行exe。

核验树为 pit-mac `基础库-本地化排序固定关系验证`，真实基线f0f122be0ee及叶依赖c67823884，冻结650自身源码。日志 `yy固定关系旧算法运行日志.txt`、`yy固定关系新算法节点输出.txt`、`yy固定关系新算法原生输出.txt` 与对应构建、错误日志均保留。最短构建为 `豫构 构建 本地化 测试 固定关系末元。测试 --输出 yy固定关系末元测试.wasm -j 24`。
