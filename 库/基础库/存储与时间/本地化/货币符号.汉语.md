# 普通货币符号

`格式地区货币` 与 `地区货币符号` 保持原签名，采用 CLDR 48.0.0 五地区 `currencies.symbol` 的普通符号。补充私表包含 AUD、BRL、CAD、HKD、ILR、ILS、INR、MXN、NZD、PHP、TWD、VND、XAF、XCD、XCG、XOF、XPF、XXX，配合原有六币种完整覆盖快照中与币码不同的普通符号。繁体 TWD 为 `$`，其余为 `NT$`；日文与英文 AUD 为 `A$`，其余为 `AU$`；日文 XCG 为 `Cg`，其余为 `Cg.`。PHP 的 `₱` 用于英文，XXX 的 `¤` 用于英文与韩文，历史 ILR 的 `ILS` 用于简体中文。

FCFA、CFPF、F CFA、Cg、Cg.、ILS 与数字间依官方 currencySpacing 使用 U+00A0。F CFA 内部保留 U+202F。私表通过限定模块导入，公开总集保持原有接口。普通符号缺项时使用币码与不换行空格；`symbol-alt-narrow` 保留为官方数据，RUB、THB 等窄符号扩展留待后续选项。

来源为数据包保存的 [Unicode CLDR JSON 48.0.0](https://github.com/unicode-org/cldr-json/tree/48.0.0/cldr-json/cldr-numbers-full/main) 官方五份 currencies.json，采用 Unicode License V3，完整许可位于本地化数据包 `数据/Unicode许可.txt`。本次读取的原始文件 SHA-256：
