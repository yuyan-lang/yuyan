# 地区数字与货币

`格式定点 地区 值 小数位` 以十之位次幂缩带符号整数而成定点之数。如值 `123405`、位 `2`，得 `1,234.05`。小数位当为非负整数。

`格式地区货币 地区 币种 分值` 可用 USD、CNY、EUR、JPY、KRW、GBP。日圆韩元以元计，示零位小数；余币以分计，示二位小数。输入既以币之最小单位计，存其真值。

`格式比率 地区 百万分率` 示整数百分数；`255000` 得 `26%`。取最近整数，中点则远零取整。

地区可书 `zh`、`zh-Hans`、`zh-Hant`、`en`、`ja`、`ko`，亦可附地区之号。分组、币符、间隔与常用小数位，皆据 Unicode CLDR JSON 48.0.0 官定五语及货币补充数据。日语人民币用 `元`，继以不换行之空格；繁体中文韩元用 `￦`。出处与许可见本地化数据包之双语篇。

后续之事：极多小数位、整数相加之界；可设之精度与现金取整。
