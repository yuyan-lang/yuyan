# 固定包裹引号重置

官方CLDR48 `zh.xml` 的Pinyin LONG与Stroke LONG各含36个圆括号、9个方括号的整串包裹引号重置，共90条。例为 `&'(一)'<<<㈠`、`&'〔三〕'<<<🉁`。包裹单引号属于[固定官方规则语法](https://github.com/unicode-org/cldr/blob/release-48/docs/ldml/tr35-collation.md)，锚码点为 `(一)`、`〔三〕`。规范读取SHA-256为 `2cf9209cdcc7bfdc0dfb01e774027ac5358d0ebfca4ba28cf8f69509dd6855e7`，XML来源及许可沿根模型所录固定快照。

私有规范码列函数解包整串首尾ASCII39，随后作十七版NFD；内部引号及转义另列更广范围。公开参数、类字段、父包及默认导入保持原样。现有纯豫言生成器已真实重生成中文表，主序仍拼音44,470、笔画102,037，规则977。格式化表逐行差异为90替换，恰去两个锚引号；根表保持原样。新中文表最终SHA-256为 `08bf3f06eecd2ef3206f6fef3526d9627a3dd7b6ca51f57117e0a512f18175f9`，前阶段中文表SHA为 `c4404d333bb896596938dba69e636f83319df715466a60fb49adc18888fef394`。
