# 地区数字与货币

`格式定点 地区 值 小数位` 将按十的小数位次方缩放的带符号整数显示为定点数字。例如 `123405` 配小数位 `2` 得 `1,234.05`。小数位应为非负整数。

`格式地区货币 地区 币种 分值` 支持 USD、CNY、EUR、JPY、KRW、GBP。JPY、KRW 的输入按元计并显示零位小数，其余币种按分计并显示两位小数。金额输入已使用币种最小单位，保留其精确值。

`格式比率 地区 百万分率` 显示整数百分数；`255000` 得 `26%`。舍入取最接近整数，中点远离零。

地区接受 `zh`、`zh-Hans`、`zh-Hant`、`en`、`ja`、`ko` 及其带地区后缀的写法。数字分组、币种符号、货币间隔与默认小数位依据 Unicode CLDR JSON 48.0.0 的官方五语数据及货币补充数据。日语 CNY 使用 `元` 与不换行空格，繁体中文 KRW 使用 `￦`。详见本地化数据包的双语数据来源与 Unicode 许可。

后续版本事项：极端小数位与整数加法边界；可配置的精度和现金舍入。
