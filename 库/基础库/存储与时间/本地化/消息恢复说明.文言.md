# 消息私语法及恢复

今 `读取便携消息` 口收全 `msgid_plural` 引文及续行，从目录字符集严解而采译形。八、十六进制字节可跨引文并为合法字。复数声明继单数声明，缺单数者还原文；复数引文坏则其项还原文，后续合法声明仍读。

引内物理换行止其行扫描，引未闭之项略之，后续合法项复析。未知语法行存前已成之项而废未成者，常注及旧项之注存今合法声明之态。裸 `msgstr` 须继有效声明而入目录。

今 `读取编译消息` 口验普通表诸原译字段长后之实终零；先验终位尚在档内，继读其值。内零仍循旧复数之式。其式据 [GNU PO 语法器](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-tools/src/read-po-gram.y) 及 [GNU MO 文件规格](https://www.gnu.org/s/gettext/manual/html_node/MO-Files.html)，出处许可循旧消息说明。

源文仅归CRLF为LF，引中单CR存为字段字节。引外空格及字节九至十三循词法空白归一，fuzzy旗词首尾亦从此集；目录头CRLF字段之字符集赋值去尾CR。其序据GNU词法器827、1099、1182行。所取源码SHA256 `a34b9110bd7ba907d145ff1c365592f2a7af3f9173304f1ac9c5fc13379fce14`，许可循GNU GPL v3及后版；源文供核语义，算法自书豫言。

CRLF归一讫，词法归一器于解码字符副本单次消反斜杠接物理LF，容引文、关键字及注释之续。引导字符副本先并ASCII目录头跨行charset，原源字节存全；既得字符集，严解而后治正文之续，GBK尾字节5C存为全字。此据GNU词法器851行lex_getc之循环。尚存之反斜杠与物理换行循旧误后恢复之法。

模板charset=CHARSET循旧未知码还空目录之约；POT文件角色俟统筹定接口。未知控制序循旧严略坏项之约，GNU诊断之流由官方器供之。

引号前声明头唯循四旧字段词或全msgstr十进数字壳，独续引以空头为之。余NAME、壳后之字、空序及中文数词序使其项循旧恢复还原文。序用ASCII零至九，数字内空白存之供严析，外空白归一；`msgstr [ 0 ]`可读，`msgstr[1 0]`为两数字标记之坏式，略之。

合法声明词或ASCII数壳后，首引文可在后续物理行；间有常注，则循词法为空白。数壳开括号、全数与闭括号之间亦可换行，归行者察合法未成壳之首，存一空格为词标之界。归行者察当前逻辑行犹候首引文，已成引文之换行与旧误式恢复存焉。ASCII目录头引导及正式源解码同循此法，跨行声明之实Latin1目录可读。数壳内空白仍交常数读者严察，`1`换行`0`犹为两数标。

私六字段之态及旧公口存焉。domain、明书空上下文复数消歧由统筹定之；Intl 对照俟用户授权。增量公口之验为 `测试/消息恢复。测试。豫`，有PO恢复三十五项及MO合法、坏终止四项；`测试/消息声明布局。测试。豫`另有合法布局与误式恢复十五验。实验之状见消息恢复验证记录。
