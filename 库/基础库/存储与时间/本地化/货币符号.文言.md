# 普通货币符号

`格式地区货币`、`地区货币符号` 守旧签，以 CLDR 四十八版五地区 currencies.symbol 之普通币符为据。私表补 AUD、BRL、CAD、HKD、ILR、ILS、INR、MXN、NZD、PHP、TWD、VND、XAF、XCD、XCG、XOF、XPF、XXX，合旧六币，尽纳快照中异于币码之普通符。繁体 TWD 为 `$`，余为 `NT$`；日英 AUD 为 `A$`，余为 `AU$`；日文 XCG 为 `Cg`，余为 `Cg.`。PHP 之 `₱` 用于英文，XXX 之 `¤` 用于英韩，旧 ILR 之 `ILS` 用于简体中文。

FCFA、CFPF、F CFA、Cg、Cg.、ILS 与数之间，依 currencySpacing 置 U+00A0；F CFA 中存 U+202F。私表限定篇名以导入，总集诸签如旧。普通币符缺则用币码及不换行空格。窄符存官数，RUB、THB 等窄符之选，俟后版。

数据出 [Unicode CLDR JSON 48.0.0](https://github.com/unicode-org/cldr-json/tree/48.0.0/cldr-json/cldr-numbers-full/main) 五份 currencies.json，从 Unicode License V3，许可全文藏本地化数据包之 `数据/Unicode许可.txt`。原文件 SHA-256 如下。
