# 本地化

此包为简繁英日韩地区书整数、定点小数、百分、货币、复数、日期时刻、列表及相对时间。整数三位一组；百分受整数百分值，比率受百万分率而取整百分；货币受最小单位整数，位从 CLDR 四十八之货币补充全表。列表之序不易。

公开诸术在默认导入诸篇。货币用五地区官定普通币符及最小单位位数，尽纳快照中异于币码之符；普通符缺则用币码，文字符依 currencySpacing 分隔，详见《货币符号》。日期时刻具 CLDR 四式，星期由调用者授周一至周日之一至七，时区之名亦由调用者授之；相对时间具年月季周日时分秒；英文复数分 one、other，中日韩皆 other。数据定于 CLDR 48.0.0，所出及许可见本地化数据包。

gettext PO/MO 读取在消息篇，具字集解码、上下文、复数诸形及 GNU 无符复数式之求值；系统消息表受调用者所授宏之字节。查消息，缺则返原文。默认导入兼含地区排序之篇；汉文拼音、笔画之剪裁，用 CLDR 四十八之 Unicode 十七根排序、组合类及规范分解数据。地区格式命令器、中文姓名排序之例已用此库。

四项格式之修，已于 pit-mac 过包检、类检及五十短验：基础格式十八、数字货币二十一、日期十一；诺节与同客体硬原生皆以零退，三组标准输出逐字相同。日期之数据源码，标准输出曰“日期格式测试通过”。消息百五十六、排序七十一短断言，皆过同客体双后端；官方根全档验至原末行 206309。定姓名之性能入口，实求四万完整排序键、比较两万次。消息二口，各于诺节父、原生父成百万隔离变异，每批万次；原生父以公共运行术启 Wasm 子程，子程行于诺节。详见《格式修正双后端验录》《消息验证记录》及本地化数据《根模型》。后验之事：五地区全功能矩阵、Intl 对照、裸机运行、逐入分配与公共峰值观测、消息 domain 及空上下文复数查询之接口约定。
