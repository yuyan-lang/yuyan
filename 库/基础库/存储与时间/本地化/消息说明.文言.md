# gettext 消息目录

`读取便携消息 文本` 读 PO 字串，`读取编译消息 字节串` 读 MO 二进制，皆得消息目录。`查消息 目录 标识` 求常译，未译则返原识。

`查上下文消息 目录 上下文 标识` 求 msgctxt 之项。`查复数形消息 目录 上下文 单数 复数 形下标` 求 msgstr[n] 之译，序自零始。调用者据地区之复数法求序。缺译则零序返单数，余序返复数。

`查数量复数消息 目录 地区 上下文 单数 复数 数量` 据目录头 `Plural-Forms` 之 `nplurals` 与 `plural` 求序，验其在零至形数减一之间。`消息头字段` 读目录头，`消息目录字符集` 读 charset，常取 UTF-8。复数头失效则据 CLDR 之则：英语 one 取零，余取一；简繁中文与日韩文皆取零。缺译则数量一返单数，余返复数。

依数量查询，先验 nplurals，再验实有连续译形之数；高位序存无符号位模式，越界则返原文。英语缺头惟数量位模式等于一为 one，UINT64_MAX 之负载体为 other。

式容 n、十进常数、括号、一元 `!`、`+`、`-`，乘除余、加减、比较、`&&`、`||`、`?:`。目录头循 GNU gettext 六十四位 unsigned long 之法：豫言整数载其无符号位模式，加减乘以模 `2^64` 回绕，比与除余皆无符。载体为负，示高位之无符数；`复数无符表示` 书其十进之值。常数止 `18446744073709551615`。惟所择之支求值，未择者亦验其式；所择除零则退用 CLDR。nplurals 与序以无符域校之。式止百万字节、百万步、万层。法据 [GNU gettext 官方复数求值源码](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-runtime/intl/eval-plural.h)。

PO 可读上下文、复数项、续引、多行标识与译文，及 `\n`、`\t`、`\r`、`\b`、`\f`、`\v`、`\a`、引号、反斜线、八进与十六进之转义。`\t` 成字节九。fuzzy 之项存为待译，查询返其原文。MO 可读大小端、主修订零与一之常表；次修订一及后，由系统消息模块展其系统相关表。常表与展开之原译字节对，同付编码转换包严解，而后分上下文及复数形；系统宏未识则略其整对。UTF-8 及 UTF-16/32 之 BOM、头初零字排列，引其头之解码；ASCII 可读头以 Latin1 引字段，再据 charset 严解。表坏、码未识及字段坏者返空。

PO 输入之串载原文件字节。先据目录头 charset 严解源文，守 GBK 等码之字符界；常引文字编回源码集，八进、十六进转义径书字节。邻引与续行并成全字段，乃据目录码集严解，而成上下文及复数形键。UTF-8 之 `\303\251` 得 `é`，Latin1 之 `\351` 亦得 `é`。同声明邻引与行尾注释，循转义辨引界。控制序坏、字段码坏、零字与 EOT 字段，略其项。八进止三位，十六进扫描限存亿位。法据 [GNU PO 官方词法器](https://raw.githubusercontent.com/autotools-mirror/gettext/master/gettext-tools/src/read-po-lex.c)。

明书空 msgctxt 与无上下文别存。`查上下文消息` 之空参数求明书之空上下文，`查消息` 求无上下文。复数查询之空上下文参数仍谓无上下文；明书空上下文复数查询之消歧，列后续接口之事。

PO 词法归一容同列诸声明及名紧接引号，引文注释存原字。查询据项存否与译空否择回退；译与全键同者仍还其译。系统字节对同循字符集解码、上下文构键与复数拆形而入目录。复数方括号序间空格制表循词法归一，引内空白存原文。

`读取编译消息带系统替换 数据 替换字典` 还错误文与目录；字典为系统段名与原始字节串之列。错文空则读成。原 `读取编译消息` 用空字典。展开之对存内零，去终零，继从目录头 charset。

其式据 [GNU gettext PO 文件](https://www.gnu.org/software/gettext/manual/html_node/PO-Files.html) 与 [MO 文件](https://www.gnu.org/software/gettext/manual/html_node/MO-Files.html)。
