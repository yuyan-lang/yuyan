# 时区数据

段界同刻之律事取一次，其保存值为后续墙时律之初态。新律首事远后于段界，取默认零保存。自动测试校同刻换律及远后首律二者。

段易而律异，首墙时之事承前段保存秒；同刻之事依前段标准偏移定世界时，新段之总偏取新标准及当下保存。自动测试含换律前后二定验。

源之编译，邻段同律则承段界当时之夏令保存；标偏改而律同时起者，取含其时之态。秋季墙时重叠，止时取最早有效世界时。`源编译。测试。豫` 自动验六定段界。全官方源之差分器，在「日历全量测试」之 `全区域源核验`，逐 Zone 与 Link 生一九〇〇至二一〇〇全岁，存而复读，与独立 TZif 校转前后之态。

源编译之库，真实源与人工诸例，皆已构建而运行。源生成之命令入口、核心区域之源表落盘及紧表展开独验，排次待行。试验缺仓外全源，则明示其由，人工向量仍行。新设路径守卫，已排版而静察；改后之运行验，留俟其时。

此包供 IANA 2026d 紧表、豫言源编译器与生成诸器，惟依标准库。输入取用户所信本地开发机 `/usr/share/zoneinfo`，TZif 版为 2026d，源律为 2026d-rearguard，皆留仓外 `/tmp/yy时区源`。版记见 `数据/+VERSION`，授权见 `数据/许可`，上游发行见 https://www.iana.org/time-zones/releases/2026d 。数据属公有领域。

`数据/` 藏生成紧表，及诸洲诸洋、南极洲、Etc 与常用别名。`生成紧凑时区表` 去第二、三、四版重之三十二位段，存后段全首、六十四位转时、型、缩名及 POSIX 尾律。第一版循单段而存。`展开紧凑时区表` 补空三十二位段于前，供双段读器取之。`读取时区数据` 受根径与 IANA 名，还展开之字节。

`生成。豫` 受输入径与输出径，`批量生成。豫` 受输入输出之根，输出目录树须先具。数据随包行，用时循径取之。

`编译时区源` 受源文、区名、始年、终年，还转记之列。每记为世界时秒、总偏秒、缩名、夏令爻；首记即始年正月朔之状态。Zone、Rule、Link、续行、紧缩诸令、月份星期缩名、年限、固定保存秒、数日、月末星期、星期前后界、逾二十四时及诸时基皆可析。命名律自一八〇〇年展之，状态存至所选年限。

`源生成。豫` 受源径、名、始年、终年、输出径，生 YTZ1 文本表。首记版、名、年限，余以制表隔秒、偏秒、缩名、夏令。所生之列可授日历包紧凑时区诸术。

验用实有之纽约、伦敦、上海、悉尼与别名，并人工验固定保存秒、世界与标准时终点、多年保存状态、月末与前界星期。

今以 25a843 全链于 pit-mac 行源生成入口，纽约、伦敦、上海、悉尼及 US/Eastern 二零二四全年表皆实存，独立验器以硬原生取之。纽约源生成之 Node 与硬原生所出，逐字节皆同。实源、固定保存、历史继承、终点时基诸验，两端皆过。仓外全源具，则新路径守卫后之实向量已行；源缺则告其由，人工期列续行。
