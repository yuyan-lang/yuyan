# 本地化官方数据

`时段规则.json` 保存同版官方 `cldr-core/supplemental/dayPeriods.json` 原文，依 Unicode License V3，复用 `数据/Unicode许可.txt` 完整许可。SHA-256 为 `6ed3b0e88ea0b8b2a045da6880951812f0ffb256d38156432b10f583c06a28b8`。中文午夜及弹性时段读取 dayPeriodRuleSet.zh；繁体沿用中文规则。

这些 JSON 文件来自 Unicode CLDR JSON 48.0.0 官方版本，保存原始数据内容。上游仓库为 [Unicode CLDR JSON](https://github.com/unicode-org/cldr-json/tree/48.0.0)，数据根目录为 `cldr-json/`。

语言与中文文件名前缀对应为：`zh-Hans` 简体中文、`zh-Hant` 繁体中文、`en` 英语、`ja` 日语、`ko` 韩语。
