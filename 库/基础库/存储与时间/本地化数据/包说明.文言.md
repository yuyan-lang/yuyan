# 本地化数据

此包取共同地区数据之简繁汉文、英文、日文、韩文，以供本地化。地区以 zh、zh-Hant、zh-TW、en、ja、ko 为识。

可辨地区，得列表隔文、基数复类、四式日期时刻、八种相对时间单位及货币常用小数位。英文整数一而无小数位者为 one，余为 other；汉日韩文皆为 other。货币位数逐项取补充表 fractions._digits，常数为二。数据目存 CLDR 48.0.0 五地区之数字、货币、公历、列表、日期字段全貌，兼存补充复数及货币之则。

数据出 Unicode CLDR，用 Unicode License v3：[数据仓库](https://github.com/unicode-org/cldr-json)、[许可](https://www.unicode.org/license.txt)。今用拉丁数及三位分组；余编号之制，俟后版。
