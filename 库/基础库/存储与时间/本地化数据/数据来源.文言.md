# 本地化官定数据

`时段规则.json` 存同版官数 `cldr-core/supplemental/dayPeriods.json` 原文，从 Unicode License V3，全文许可仍见 `数据/Unicode许可.txt`。SHA-256 为 `6ed3b0e88ea0b8b2a045da6880951812f0ffb256d38156432b10f583c06a28b8`。中文午夜及弹性时段取 dayPeriodRuleSet.zh；繁体从中文之则。

诸 JSON 取自 Unicode CLDR JSON 48.0.0 官定本，悉存其原文。其仓见 [Unicode CLDR JSON](https://github.com/unicode-org/cldr-json/tree/48.0.0)，数据之根曰 `cldr-json/`。

语言与篇名前缀相应：`zh-Hans` 为简体中文，`zh-Hant` 为繁体中文，`en` 为英语，`ja` 为日语，`ko` 为韩语。

| 篇名后缀 | 官仓之径 |
| --- | --- |
| 数字.json | cldr-numbers-full/main/语言/numbers.json |
| 货币.json | cldr-numbers-full/main/语言/currencies.json |
| 公历.json | cldr-dates-full/main/语言/ca-gregorian.json |
| 日期字段.json | cldr-dates-full/main/语言/dateFields.json |
| 列表模式.json | cldr-misc-full/main/语言/listPatterns.json |

`复数规则.json` 取于 `cldr-core/supplemental/plurals.json`，`货币补充.json` 取于 `cldr-core/supplemental/currencyData.json`，诸语言之规则与货币沿革皆存焉。

诸数据从 Unicode License V3。许可全文存于 `数据/Unicode许可.txt`，取于同版仓根之 `LICENSE`。散布当附此许可。取数之日为二〇二六年十月七日。JSON 之英文键、地区之号、币种之码，皆循官定之式。
