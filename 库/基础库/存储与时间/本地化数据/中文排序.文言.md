# 中文排序之数据

数据取诸 Unicode CLDR release-48 中文排序规则，官址为 https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/collation/zh.xml 。快照存于 `数据/中文排序.xml`，SHA-256 为 `55890bb4b1f8779b9868f8afb805a1db3af0da8f9d6456f756cc25de85e3bb1e`。版权及许可之文存于 XML 首，遵 Unicode 数据许可。

`排序生成。豫` 读官定快照，取两种 LONG 段之 `<*` 主序行，成 `中文排序表。豫`。主序行若含额外 ASCII 规则字则止而告，俾察数据式之变。输出依码点高位分桶，各行记十进码及主序号。

今生成器源码调用排序规则生成篇，析私拼音及两长式之重置行，兼收篇末重庆、沈阳、藏文诸则。生成物增两种规则桶，记 NFD 目标、强度、before 二之志、定义之序、NFD 锚及所扩。私拼音之录同入两体，短式及注音各留后版。

中文生成器以码点及 NFD 操作处所定规则既赋之锚及声调，运行默认根已接四十八版官根、十七版桶及组合类、隐式闭包。根生成惟复用不系版之文本解析，径读十七版字符表，先成根表再成中文表而闭其依赖。

重生成时，先以豫构构建本地化数据之排序生成入口，再以节点宿主行之，传快照路径及排序表输出路径。

今为静态补实现之候稿，中文排序表俟生成，所收之数俟行而载。生成源码增 FDD0 索引直接主序之位，规则查询增组合类非连续匹配，解释器存跨度及越点。旧三十三向量及新十五向量俟行；同版提供器接入、前缀上下文、大小写位、通用分重及全层一致性付后版。
