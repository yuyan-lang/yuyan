# 日历

历以推步公历，互易年月日与协调世界时之秒。纪元始于一九七零年正月一日零时。周一为一，周日为七。比较时间，以整数大小为之。日期时间凡六整数，次为年、月、日、时、分、秒；易算之前可验其正。

入口曰 `日历`，公历别入 `日历/公历`。`公历转协调世界秒` 受六整数，`协调世界秒转公历` 得 `日期时间类`。惟依标准库。时区、格式、农历，各有其篇。

时区读 TZif，互易协调世界时与当地时，察夏令之缺与重，依月周及年日之律。`时区数据` 别为包，存 IANA 之数，用者取而授历。格式有国际日期、邮件、HTTP、汉语及模式之写读。农历自一九零零至二一零零，具闰月、干支、生肖；其日数起于一九零零年正月三十一日。

节气存一九零零至二一零零年 JPL Horizons 时刻缓存，凡四千八百二十四项，原毫秒全录十进文字，以豫言解之。数取 MIT 所许 `solar_terms_24` 之定本，许可见 `农历/节气数据许可.txt`，生成者为 `农历/时刻表生成。豫`。Horizons 于一九六二年前用 UT1，其后用 UTC；毫秒乃存数之分度。日视黄经近算之法亦存。

今于 Node 宿主验全表四千八百二十四项之序与日期，别验七日期、三毫秒定值、三十八周序向量及十时长向量。HKO 二百年四千八百日期皆已比之，四千七百九十三同，七近夜半而异；原值、古时制及官方预测之界，详 `农历/节气差分根因记录.汉语.md`。农历逐日官方比对凡七万三千四十九日。

Intl 与 Date 随机比对、原生执行器、QEMU 与诸平台效能，留俟后验。时区数据源命令入口及 YTZ1 落盘取用之全验，续排待行。甲乙之级，以提案进度表为据。
