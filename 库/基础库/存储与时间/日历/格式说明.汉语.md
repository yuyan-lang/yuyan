# 日历格式

模式解析在读取百分号后的说明符前核对剩余字节；末尾孤立百分号返回 `可无`。模式参数变异编号 29 的固定字节 `25 46 20 25 54 20 25` 已保存为独立回归。

日历格式模块以协调世界 Unix 整数秒表示时刻。`格式化国际日期`、`格式化ISO8601` 与 `格式化RFC3339` 输出 `YYYY-MM-DDTHH:mm:ssZ`。对应解析函数读取 ISO 基本与扩展日期、仅日期、小时、时分及秒，接受小数秒、`Z`、`+HH:mm`、`-HH:mm` 和基本偏移。小数秒按整数秒接口取其整秒部分。

`格式化HTTP日期` 输出 IMF-fixdate，`格式化RFC5322日期` 输出带 `+0000` 的邮件日期。解析支持 IMF-fixdate、RFC850 与 asctime 三种 HTTP 日期，以及邮件日期的可省星期、单数字日、可省秒、折叠空白、注释与数字偏移和常用北美时区缩写。

`格式化模式` 支持 `%Y %y %C %m %d %e %H %I %M %S %p %j %u %w %V %G %g %U %W %a %A %b %B %h %z %Z %s %n %t %F %R %T %X %D %x %%`。星期、序日与 ISO 周字段按前推公历计算；百分号转义逐项处理。`格式化中文日期` 与 `解析中文日期` 使用 `2026年10月6日 星期二 下午3点` 格式，并按需输出分钟与秒钟；解析也接受旧的数字年月日时分秒格式。

`尝试解析RFC3339` 返回 `或可有` 整数秒，校验分隔、数字、日期、时刻及偏移范围。`尝试解析ISO8601` 将基本与省略时刻规范化后执行同一校验。`尝试解析HTTP日期` 与 `尝试解析RFC5322日期` 校验有效公历日期及时刻；调用者可匹配 `可无` 处理非法日期。对应整数解析入口在无效日期时报告日期范围错误。

`解析模式` 与 `尝试解析模式` 接收模式和日期文本，支持年月日、英文月名、十二小时与上午下午、时分秒、数字偏移、年内序日和 ISO 周日期，以及 `%F %T %R %D %r %X` 复合模式。`尝试解析模式` 检查输入长度、分隔文本及日期时刻范围。

`尝试解析ISO8601` 的候检增量接受直接周日期 `2020-W01-1`、`2020W011`，以及序日日期 `2020-060`、`2020060`；时刻与偏移沿用现有解析。周日期省略星期时取星期一。周年第一周包含 1 月 4 日；元旦为星期四，或闰年元旦为星期三时，该周年有 53 周。序日范围按平年 365 日和闰年 366 日校验。候检向量固定记录 UTC Unix 秒，包含跨年和世纪闰年。
