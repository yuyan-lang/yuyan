# 日历格式

日历格式模块以协调世界 Unix 秒表示时刻。`格式化国际日期`、`格式化ISO8601` 与 `格式化RFC3339` 输出 `YYYY-MM-DDTHH:mm:ssZ`。对应解析函数读取秒精度日期及 `Z`、`+HH:mm`、`-HH:mm` 偏移。

`格式化HTTP日期` 输出 IMF-fixdate，`格式化RFC5322日期` 输出带 `+0000` 的邮件日期。对应解析函数读取固定宽度日期。

`格式化模式` 支持 `%Y %m %d %H %M %S %z %Z %%`。`格式化中文日期` 与 `解析中文日期` 使用 `2026年10月06日 15点00分00秒` 格式。

待办事项：非固定宽度输入、闰秒、小数秒、旧 HTTP 日期、模式解析和中文星期及上午下午表达留待后续补齐。
