# 日历格式

此模块以协调世界 Unix 整数秒纪时。国际日期、ISO8601 与 RFC3339 诸格式之术书 `YYYY-MM-DDTHH:mm:ssZ`；诸解析之术受基本、扩展、唯日期及小时、时分、时分秒之文，兼受小数秒与正负偏移。小数秒从整数秒之约，取其整秒。

HTTP 日期之术书 IMF-fixdate，RFC5322 日期之术书偏移 `+0000`。解析受 IMF-fixdate、RFC850 及 asctime，亦受邮件之省星期、独位日、省秒、折叠空白、注释、数值偏移及北美常见区名。

模式之术受 `%Y %y %C %m %d %e %H %I %M %S %p %j %u %w %V %G %g %U %W %a %A %b %B %h %z %Z %s %n %t %F %R %T %X %D %x %%`；星期、年内序日、ISO 周从前推公历，百分号循序释之。中文格式及解析用 `2026年10月6日 星期二 下午3点`，有分秒则书之，解析亦受旧数字年月日时分秒之文。

尝试解析 RFC3339 之术还可有可无之秒，验隔符、数字、日期、时刻及偏移。尝试解析 ISO8601 之术先规范基本与省略时刻，再以同法验之。尝试解析 HTTP 与 RFC5322 之术验公历及时刻，非法者还可无。诸整数解析之口遇非法日期则报范围之失。

模式解析诸术受模式及日期之文，读年月日、英文月名、十二时与午前午后、时分秒、数值偏移、序日及 ISO 周；亦受 `%F %T %R %D %r %X`。尝试之术验文长、分隔及日期时刻之域。

待办事项：闰秒之表、模式地区修饰、ISO 周与序日之直接文、地区语言全习，俟后续补之。
