# 日历时区

纯豫言读取 TZif 第一版与第二至第四版的 64 位转换块。时间值为 Unix 秒。`时区状态` 返回 协调世界秒 偏移秒与夏令时标记；`协调世界秒转当地` 返回当地 Unix 秒；`当地转协调世界秒` 返回全部互异的 协调世界秒 候选，夏令时缺口为空，回拨重叠有两项。

转换表首项之前采用类型零。第二版及后续版本的表末状态采用 POSIX 尾部规则，支持固定偏移、M月份.周数.星期规则、J日序与数字日序、显式夏令偏移、转换时刻及墙钟/标准时/协调世界时后缀，以及南半球跨年夏令时。规则文本以 TZif 中的换行边界读取。转换时刻以切换前的当地偏移换算为 协调世界秒。

`解析TZif` 返回可选时区表，短输入与无类型记录返回可无。`时区尾部状态` 可独立接受 POSIX 规则文本。

后续版本事项：闰秒应用、缩写文本、损坏文件的全部字段校验。规则暂未识别时采用转换表末状态。

测试覆盖合成转换表的切换前后、当地时间缺口与重叠、空输入以及大于 32 位的转换时刻。

紧凑时区模块直接消费源生成工具的转换记录列表：协调世界秒、总偏移秒、缩写、夏令标记四元组，按转换秒递增。首记录表示起始范围状态。`紧凑时区状态`、`紧凑协调世界秒转当地`、`紧凑当地转协调世界秒` 提供同样的查询、转换与缺口重叠候选计算。
