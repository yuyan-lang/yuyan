# 网址解析

此包以豫言载网址诸部，序列化其址，计特种址之源，治径之点段。今备协议扫描、双斜线后之权威部件、用户及密码、十进端口与常端之去、询片之分、相对径及询之承、不透明径。字节接口循 UTF-8 入析，书址亦出字节。

主机备 IPv4 十六进、八进、省点段、整数字法，IPv6 零段压缩、内嵌 IPv4 及规整。诸部之百分编码、表单编码及 data 载荷解码，皆用共字节编码库。data 载荷零及八位皆存。询参备析书、添删（许择值）、设取（首及全）、有无（许择值）、计数、键值项遍历、循 UTF-16 码元之稳排。

后续施统一码域名、file 与特种方案全状态、设属、公开一致性数据之全验。今例验主机、端、径、询、片、相对所承、百分编码、data 任意字节及表单诸参。

验其全备，以 WHATWG URL 之规与 web-platform-tests 之 urltestdata.json、setters 为据。今未达甲级。
