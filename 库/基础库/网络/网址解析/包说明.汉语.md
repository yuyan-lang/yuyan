# 网址解析

本包用纯豫言表示网址部件、序列化网址、计算特种网址的来源，并处理路径点段。当前实现协议扫描、带双斜线的权威部件、用户名与密码、十进制端口及默认端口移除、查询与片段拆分、相对路径与查询继承、不透明路径。公开字节接口以 UTF-8 文字进入计算算法，序列化输出字节串。

主机实现 IPv4 十六进制、八进制、省略点段与整数写法，IPv6 压缩零段、内嵌 IPv4 与规范化。部件百分号编码、表单编码与 data 载荷解码复用字节编码库；data 载荷保留零与任意八位字节。查询参数提供解析、序列化、追加、删除（可选值筛选）、设置、获取首值与全部值、存在判断（可选值筛选）、项数、键值项遍历及 UTF-16 码元稳定排序。

后续实施统一码 IDNA、完整 file 与特种方案状态机、属性设置，以及公开一致性数据的全面测试。当前实施向量覆盖主机、端口、路径、查询、片段、相对继承、百分号编码、data 任意字节与表单参数。

完整验收使用 WHATWG URL 标准与 web-platform-tests 的 urltestdata.json、setters 数据；当前实施状态为未达甲级。
