# 邮件格式

此纯豫言邮件格式之库也，版为 0.1.0，许可从仓库。

`解析邮件` 受任意八位字节串，还 `邮件成功` 或 `邮件错误`。`邮件正文` 存有序首部及字节串正文；重名皆存，续行展开。`查邮件头` 校名忽 ASCII 字母之大小，尽还同名字段。`生成邮件` 还字节串，验字段名、值中控制字节及单行 998 字节之限，循 78 字节软折行，以回车换行成文。生成参数非法则告豫言异常。

`解析邮件部件` 还 `部件成功` 或 `部件错误`，析 MIME 媒体之参、引号及反斜线之转义、嵌套多部、前言与后言。`单邮件部件` 存首及原字节串之载荷；`多邮件部件` 存首、前言、子部及后言。`查媒体参数` 还可选之参。`生成邮件部件` 受边界及部件之树，还字节串。

测试皆自作，据 RFC 5322、RFC 2046 之报文法，验折首、重名、畸形、多部、中文之首及含 NUL、255、128 字节之正文往返。初用者为开发工具「邮件查看」。

今首、MIME 多部及 SMTP 字节通道之篇已成，甲乙之验续行。传输编码、RFC 2047 编码字、字符集转换及 SMTP STARTTLS 认证适配续作。原生之验、模糊之测及性能之量，留后续之验。

## 简单邮件传输

`建立邮件字节通道` 受写、读及安全升级之回调，成存响应缓冲之字节通道。`发送简单邮件` 受通道、主机、招呼域名、信封发件人、收件人之列、报文字节串及要求安全之标；还已受收件人、被拒收件人及响应码，或败因。其治分片与多行响应、EHLO/HELO、MAIL FROM、RCPT TO、DATA 点转义及 QUIT。报文用七位字节、回车换行，行长至多998字节。

`连接邮件服务器` 启真实 TCP 之连，`邮件连接通道` 裹既有之连，呼者终闭之。求安全者，验 STARTTLS，召升级回调，复行 EHLO；升级回调受连中已读之后续字节。真实安全传输库之认证握手适配，续作。

协议据：[RFC 5321](https://www.rfc-editor.org/rfc/rfc5321.html)、[RFC 3207](https://www.rfc-editor.org/rfc/rfc3207.html)。测试以自构 SMTP 服务响应，验分片、多行、拒收、点转义、安全升级回调及参数注入。真实 TLS 及诸平台之验续行，甲乙皆未验收。
