# 邮件格式

这是纯豫言邮件格式库，版本为 0.1.0，代码遵循仓库许可。

`解析邮件` 接收任意八位字节串，返回 `邮件成功` 或 `邮件错误`。`邮件正文` 保存有序头部字段与字节串正文；重复字段保留，续行展开。`查邮件头` 按 ASCII 大小写无关规则返回全部同名字段。`生成邮件` 返回字节串，校验字段名、值中的控制字节与单行 998 字节上限，按 78 字节软折行，使用回车换行。非法生成参数抛出豫言异常。

`解析邮件部件` 返回 `部件成功` 或 `部件错误`，解析 MIME 媒体参数、带引号及反斜线转义的参数、嵌套多部分、前言与后言。`单邮件部件` 保存头部与原始字节串载荷；`多邮件部件` 保存头部、前言、子部件和后言。`查媒体参数` 返回可选参数值。`生成邮件部件` 接收边界及部件树，返回字节串。

测试自行编写，依据 RFC 5322 与 RFC 2046 的报文规则，覆盖折叠头部、重复字段、畸形输入、多部分、中文头部及含 NUL、255、128 字节的二进制正文往返。第一个使用者是开发工具「邮件查看」。

当前状态是头部与 MIME 多部分模块已实现，甲级与乙级验收继续实施。传输编码、RFC 2047 编码字、字符集转换与 SMTP STARTTLS 客户端在后续实现。原生验收、模糊测试与性能测量在后续验收。
