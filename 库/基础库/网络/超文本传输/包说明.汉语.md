# 超文本传输

私有 `网址客户端` 解析绝对与相对转向位置，按301、302、303、307、308处理方法及正文，跨来源转向清除 Authorization、Proxy-Authorization 与显式 Cookie。`小饼交换` 按每个目标的域路径与安全同站策略重新选择小饼，并逐项收取独立 Set-Cookie。调用方提供明文及安全交换、时钟、日期和公共后缀策略；当前超时按每跳请求计算。全树定向入口 `测试/网址转向。测试。豫` 覆盖相对位置、方法变化与跨源凭据清除。整体转向期限、默认策略装配及正式应用消费列为后续事项。

私有 `内容编码` 按 Content-Encoding 的逆序调用压缩库现有 gzip、zlib封装deflate、br、zstd 解码器，每层使用调用者指定的输出上限，失败状态转为结构异常。响应解码后更新 Content-Length 并移除 Content-Encoding。定向 CI 入口 `测试/内容编码。测试。豫` 核对多层编码顺序、二进制正文、字段调整及上限传播。本批为源码接线，类型与互通验收继续推进。

私有 `事件流` 将多行数据、事件名、标识符与重试毫秒编为 SSE 字节消息；`流式服务` 从已接受 TCP 连接写响应首部、分块正文与尾部，成功结束或异常后一次关闭连接，空片段保持流可继续。`写服务事件` 将事件消息直接写入响应流。定向 CI 入口 `测试/事件流。测试。豫` 核对多行事件和首部发送前的终结块边界。本批交付服务端源与测试接线，事件接收解析、监听消费、类型与真实互通验收继续推进。

私有 `会话小饼` 源解析属性并按域、路径、期限、Secure 和 SameSite 策略筛选请求字段，日期解析与公共后缀由显式策略回调提供。`范围` 源生成 Range 与 If-Range，核对206响应的起点及片长后拼接二进制正文，200响应替换旧正文。定向 CI 入口 `测试/会话小饼。测试。豫`、`测试/范围。测试。豫` 由全树测试自动发现。本批为源码交付；默认日期与公共后缀配置、交换接线、类型与互通验收继续推进。

私有 `二版传输` 源通过公共 TCP 接口驱动先验明文请求，按窗口分批发送正文、读取设置与响应，并在成功或异常后一次关闭连接。`网页消息压缩` 把压缩位、消息分片及控制帧整合为独立接收态，在终片解压并校验文本，保留跨消息字典。`测试/压缩分片。测试。豫` 是全树自动发现的固定入口，覆盖压缩片间 PING 与后续字典引用。本批交付源码与 CI 接线，类型及真实互通验收继续推进。

私有超文本传输2核提供帧编解、设置、独立流、首部续帧与窗口控制。网页套接字核提供客户端与服务端握手、掩码、分片、控制帧及文本校验，网页压缩核通过同源 DEFLATE 解码器保存有界字典。定向入口为 `测试/超文本传输2。测试。豫`、`测试/网页套接字。测试。豫`、`测试/网页压缩。测试。豫`，由全树测试自动发现。此阶段为源码与 CI 测试接线交付，类型与双端互通验收、压缩协商及消息整合列为后续事项，甲乙等级验收继续推进。

首部整数在读取首字节前核对位置范围；缺少名字或值长度的字面量以可捕获结构异常拒绝。固定向量包含 `41`、`00`、`10` 和 `0000` 截断输入。

私有首部压缩核提供 RFC7541 静态表、动态表、前缀整数、字面量、永不索引属性及完整霍夫曼解码。动态表按名字和值的字节数加32计量，块首大小更新裁切旧项。固定入口 `测试/首部压缩。测试。豫` 核对 RFC 请求块、动态引用、霍夫曼主机、整数1337，以及表清空、更新越界、无效索引、截断和填充拒绝；官方向量字节与预期保持原样。该入口以完整25a843工具链构建，在诺节和 E44/E801 原生预编二执行器运行通过。公开导出及超文本传输2连接互通列为后续阶段。

字节报文接收态按输入片段累积数据，解析后返回报文与剩余接收态。报文保存起始行、字段、二进制正文、尾部字段与保持连接标记。分块大小支持扩展，零块结束后读取尾部字段，内容长度按字节裁取，连接关闭结束无长度响应。

报文编解提供分块序列化、重复内容长度校验及字段名记号校验。明文客户端薄层经公共传输控制协议发送字节串，按内容长度与分块结束收取响应，跳过信息响应；异常路径关闭连接。

`异步发送请求` 依次接收方法、主机、端口、请求目标、字段列、字节正文与毫秒超时，返回 `异步任务于客户端响应`。客户端分别保存建立、确认、发送及接收状态，每次等待交公共协作调度器处理，期限从请求编码前开始；负超时表示无限等待。任务成功、异常或到期后统一关闭连接一次，重复等待返回同一终态。明文请求和响应的正文使用字节串；HTTP 字段名称按大小写无关方式替换，IPv6 主机在请求字段中加方括号，在 TCP 地址中去方括号。

`安全客户端` 是私有接线候稿，接受 TLS 客户配置与两个明确的终态查询回调，复用上述请求阶段和截止善后。每个会话从公共密码随机接口分别获取 32 字节随机数与私钥，主机配置须匹配请求主机，协议候选限定为 http/1.1。公开错误及认证关闭查询接入、证书默认配置装配和真实 HTTPS 握手互通列为下一实施阶段。

`测试/异步客户端截止。测试。豫` 以系统临时端口启动纯豫言静默 TCP 服务，接收明文请求或 TLS ClientHello 后观察客户端到期关闭，核对重复等待与一次善后；同一消费者已在诺节和 16c 原生预编二执行器运行通过。`测试/安全驱动。测试。豫` 在诺节核对固定终态错误传播、重复等待、零期限及主机约束。以上类型与构建使用 20261008T023627Z-5384a0b1 完整 Wasm 工具链验证，构建时关闭旧发行构建日志编码路径。

重定向、Cookie、内容编码、multipart、公开 HTTPS 客户端、服务端、网页套接字、代理、缓存与超文本传输2继续实施。甲级与乙级验收留待完整能力与互通测试完成；CPU 连续执行的抢占列为后续事项。

协议依据：[RFC 9112](https://www.rfc-editor.org/rfc/rfc9112.html)。测试覆盖标准分块样例、全部单次切分位置、二进制正文、流水线消费位置、长度冲突与溢出。

明文互通用例在 `测试/客户端互通。豫`，先以仓内简易网页服务器在本树根目录监听本机端口 8127，再构建并运行该文件。此用例已用配套 Wasm 工具链及诺节公共传输接口验证。
“请求安全响应”接收 TLS 客户配置、方法、主机、端口、目标、字段、正文和超时，返回异步响应任务。此入口直接使用安全传输客户的错误与关闭查询，共用现有请求驱动及连接善后。调用方提供证书核验配置；默认配置装配与真实 HTTPS 互通继续实施。后台回归覆盖零期限与重复等待。
“解析请求地址”复用网址解析库，得到 HTTP/HTTPS 的来源、主机、端口、请求目标及安全标记。请求目标保留查询、移除片段；默认端口归一到来源文字。“请求来源获准”按规范化来源列精确匹配，协议与端口参与区分。网址内凭证可通过请求标头提供。宿主授权表接入及实际传输继续实施。
