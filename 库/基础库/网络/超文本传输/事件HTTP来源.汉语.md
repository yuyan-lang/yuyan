# 事件HTTP来源

`开事件HTTP来源`接收可选TLS客户配置、主机、端口、目标、首部及超时，实际建立TCP并发送HTTP/1.1 GET。提供TLS配置时使用安全随机、完整证书与握手签名验证回调，ALPN候选为http/1.1。请求声明Accept-Encoding为identity；响应首部提前返回，正文随网络字节增量消费。

`包装事件HTTP正文`复用请求正文状态机的定长与分块处理，去除块长度、块行末及尾字段；无长度响应按连接结束消费。读取包含首部后的首批余字节，分片保留待决边界，定长与分块截断产生错误。204来源直接结束。

`消费HTTP服务器事件`把真实HTTP来源接入现有事件接收与重连器，按retry等待并携Last-Event-ID重新GET，接收事件由调用回调处理。返回阴结束消费，正常和错误路径关闭来源；关闭状态保持幂等，TLS待发关闭通知刷新后释放TCP。超时按建立及读取片段的调用计，重连上限由调用者提供。

基本CI入口`测试/事件HTTP来源。测试。豫`核对分块边界、定长正文及事件内容。源码经格式化及差异检查后先合入；实际TCP/TLS互通与双端运行证据继续补充。
