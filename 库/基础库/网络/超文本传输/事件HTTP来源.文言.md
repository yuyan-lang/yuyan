# 事件HTTP来源

「开事件HTTP来源」受可选TLS客户配置、主机、埠、目标、首部、超时，实建TCP而发HTTP/1.1 GET。有TLS配置则用安全随机及全证书、握手签名之验，ALPN所候为http/1.1。请求宣Accept-Encoding为identity；响应首部先还，正文随网字节增受。

「包装事件HTTP正文」因请求正文之态而治定长及分块，去块长、块行末、尾字段；无长之应随连接终而受。读取存首部后之初余字，分片留待决边界，定长及分块中断则告错。二零四之源径止。

「消费HTTP服务器事件」以真HTTP之源系事件接收及重连器，循retry而待，携Last-Event-ID复GET，以所授术处事件。还阴则止，成与错之路皆闭源；重闭同果，TLS闭通知发毕乃释TCP。超时各计于建立及读片之调用，重连之限由调用者授。

常CI入口「测试/事件HTTP来源。测试。豫」核块界、定长体及事件之文。源经排版及差异之察先合；真TCP及TLS互通、双端运行之证续补。
