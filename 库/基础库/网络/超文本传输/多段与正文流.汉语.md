# 多段表单与请求正文流

`超文本传输/表单解析` 提供 `解析多段表单`，接收边界字符串与正文原始字节串，返回 `表单部分` 列表。列表保留重复字段和原顺序，文件内容保留原始字节。字段名、文件名与媒体类型使用 UTF-8 首部文字。带引号的参数支持反斜杠转义与分号。

`超文本传输/表单上传` 提供 `上传安全表单`，依次接收安全传输客户配置、主机、端口、请求目标、首部、部分列表及超时毫秒。它生成公共安全随机边界，设置 Content-Type 与 Content-Length，复用既有 POST 安全请求驱动，返回客户端响应的异步任务。

`超文本传输/请求正文流` 提供 `新请求正文流(元)`、`喂请求正文(状态, 新字节, 正文消费回调)`、`请求正文已终(状态)` 与 `结束请求正文(状态)`。消费者可以把正文片段直接写入文件、增量解码器或应用缓冲区。它支持 Content-Length 与分块编码，解析块扩展后的长度和尾字段。状态的第一项是阶段，第二项是待定或流水线剩余字节，第三项是当前待收正文长度，第四项在首部阶段之后保存请求字段、在有尾字段的完成状态保存尾字段，第五项保存请求起始行。完成后的第二项可以交给下条请求的新状态。

常规测试入口为 `测试/表单解析。测试。豫` 与 `测试/请求正文流。测试。豫`。前者验证重复字段、中文元信息、引号与分号及零与255字节；后者逐一验证定长和分块报文的每个二段切分位置以及流水线剩余。
