# 域名解析

纯豫言 DNS 报文编解组件。压缩域名解码以报文字节串为输入，返回域名与原始报文后继位置；截断、越界、压缩循环与过长域名返回明确错误。

实现按 RFC 1035 第四节处理标签和压缩指针。

后续事项：记录的语义取值接口、TCP、DoH、配置文件与 TTL 缓存。当前尚未达到提案甲级或乙级。

`写域名` 将点分域名与根域名编码成标签序列；`造查询` 生成递归的单问题 IN 查询，类型号由调用者指定。`读双字节` 和 `写双字节` 供报文组件复用。

`报文。测试。豫` 覆盖空输入、畸形标签、半截指针、循环指针、截断标签与正常往返，六项断言通过。库结构检查、类型检查与测试构建通过。

`解报文` 返回报文编号、标志、问题、答案、权威与附加记录；`编报文` 写出这些字段。记录包含名称、类型、类别、存活秒数与字节串载荷。A、AAAA 校验地址长度，CNAME、MX、SRV 将压缩域名规整为独立标签，TXT 校验逐段长度，HTTPS 与 SVCB 校验参数边界、唯一键与递增次序。未知记录按原载荷保存。`造扩展记录` 生成 EDNS0 OPT 记录。

`整文。测试。豫` 构造上述八类记录，核对解码后重编码逐字节相同，并检查截断记录明确失败，三项断言通过。最新配套工具链构建与包检查退出为零。实现依据 [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html) 与 [RFC 9460](https://www.rfc-editor.org/rfc/rfc9460.html)，代码遵循仓库许可。
