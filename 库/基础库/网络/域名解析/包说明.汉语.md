# 域名解析

这是纯豫言 DNS 报文与存根解析库。报文编号、标志、问题、答案、权威与附加记录采用公开元组，资源记录包含名称、类型、类别、存活秒数与独立字节串载荷。

当前验收状态：实施中。甲乙完整验收与共享默认墙钟的配套运行列入后续事项。

`写域名` 编码点分名称和根域名，`读域名` 解码标签与压缩指针并返回原报文后继位置。截断、越界、非法标签、循环指针与过长名称返回显式 `域名失败`。`造查询` 生成递归的单问题 IN 查询；`解报文` 与 `编报文` 读写完整四段报文。

名称表示采用 DNS 主文件式转义：单字符转义恢复原字节，三位十进制转义覆盖零至二百五十五。解码时点、反斜线、控制字节与非 ASCII 字节按三位转义显示，编码时恢复标签原字节；名称长度按还原后最多二百五十五字节、每标签最多六十三字节校验。缓存键统一转义表示后折叠 ASCII 大小写。

A、AAAA 校验地址长度；CNAME、MX、SRV 将压缩域名规整成独立标签；TXT 保存逐段长度；HTTPS 与 SVCB 保存优先级、目标与递增且唯一的参数键。`解记录语义` 以具名构造器公开八类记录字段，`地址记录表示` 显示四版点分地址与六版十六进制地址。未知记录及服务参数按原字节保存。

`造扩展记录` 构造 EDNS0 OPT 记录；选项按代码、长度与原始字节校验；`报文返回码` 合并头部低四位与 OPT 高八位。

`经传输查询` 经公共传输控制协议接口完成连接、双字节长度定界、部分读写与关闭。查询回答核验编号、回答位、操作码、截断位、问题名、类型与类别。`经通道查询` 提供同样核验，便于接入其它字节通道。

`经数据报通道查询` 接受保持报文边界且核对服务器来源的数据报交换通道与传输交换通道。正常回答完成编号、回答位、操作码和问题核验；带截断标志的回答先核验完整问题，再沿传输通道重发原查询。截断回答中的部分资源记录由传输回答替代。

`经数据报查询` 将标准库已连接数据报交换与公共 TCP 交换装配为存根查询，参数依次为服务器数值地址、端口、超时毫秒数、问题名、类型和编号。数据报截断回答沿同服务器与端口回退到 TCP。

`解析主机文件` 展开 hosts 同址名称与别名，`解析解析器配置` 保存 resolv.conf 的服务器、搜索域、选项与其它指令；两者支持空白、行注释与行顺序。文件读写由调用者承担。

`存域名缓存` 与 `取域名缓存` 以规范化问题名、类型与类别为键，调用者传入单调秒数。命中时递减记录存活秒数，取答案组最短存活秒数为到期时间；零秒及高位 TTL 即刻失效。OPT 从缓存记录中剔除，错误返回码保持原缓存。

`经安全网页查询` 实现 RFC 8484 的 POST 与 `application/dns-message` 封装，核验 HTTP 状态、媒体类型、DNS 问题，并按 Age 减去记录存活秒数。调用者以 `已验证安全网页通道` 明确传入完成 TLS 与证书主机名验证的通道；该模块依赖超文本传输的公开字段与响应类型。

首个使用者是开发工具包「域名查询」，命令为 `yy域名查询 example.com --服务器 1.1.1.1 --类型 1`。

## 安全网页传输接口

`创建安全网页通道` 将公共 TCP、纯豫言安全传输客户与 HTTP 字节报文接收器接成安全网页通道。调用者传入服务器地址、端口、超时、证书链及主机名核验、握手签名核验与每连接种子供应。`安全网页默认种子` 从标准库安全随机接口取得六十四字节，分别供客户随机数与 X25519 私钥使用。

传输驱动发送待发密文、喂入收到的密文，握手完成后发送请求并接收完整网页回答，处理部分读写、等待、告警与关闭。该接口消费严格默认生产配置并通过真实公共服务短连接；共享默认墙钟与原生消费者的配套运行继续验收。

安全网页传输接口当前为私有驱动候稿，错误查询与关闭查询通过显式回调参数传入。正式消费者复用已公开错误与关闭查询、默认生产证书配置；同模块回调驱动保留，单段总集出口维持既有范围。
