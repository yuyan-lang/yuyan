# 域名解析

此以豫言成域名报文及存根之库。号、标、问、答、权、附以公开元组存之；资源录载名、型、类、存秒与独立字节串。

今验收之事在施行。甲乙全验、真实 HTTPS 之道接入列后事。

`写域名` 编点分名及根名，`读域名` 解标签、压针而返原文后位。缺、越、异标签、环针与过长名皆返 `域名失败`。`造查询` 成递归单问 IN 之文；`解报文`、`编报文` 读写四段全文。

名称循域名主文件之转义：单字转义复原字节，三位十进制转义纳零至二百五十五。解则点、反斜线、控制字节及非 ASCII 字节皆作三位转义，编则复原标签字节；名之还原长至多二百五十五，单标签至多六十三。缓存键统转义之表示，折叠 ASCII 字母大小。

A、AAAA 验址长；CNAME、MX、SRV 化压名为独立标签；TXT 存段长；HTTPS、SVCB 存优先、目标及递增唯一之键。`解记录语义` 以具名构造器明八类之字段，`地址记录表示` 示四版点分址、六版十六进制址。未知录及服务参数存其原字节。

`造扩展记录` 成 EDNS0 OPT；选项循代码、长与原字节验之；`报文返回码` 合首之低四位、OPT 高八位。

`经传输查询` 由公共传输控制协议之口连接，以双字节长定界，续未尽读写，终则闭连。答验号、回答位、操作码、截断位、问名、型与类。`经通道查询` 同验之，供余字节道接入。

`解析主机文件` 展 hosts 同址诸名、别名，`解析解析器配置` 存 resolv.conf 服务器、寻域、选项及余令；皆解空白、行注、行序。文之读写由用者司之。

`存域名缓存`、`取域名缓存` 以规整问名、型、类为键，用者授单调秒。命中减录存秒，以答组最短存秒定期；零秒、高位 TTL 即失。缓存剔 OPT；返码有误，旧缓存仍存。

`经安全网页查询` 循 RFC 8484，以 POST 与 `application/dns-message` 封之；验网页状态、媒体型、域名问题，并依 Age 减录存秒。用者以 `已验证安全网页通道` 明授已验 TLS、书证及主机名之道；此模依超文本传输公开字段、响应之类。

首用之器为开发工具包「域名查询」，命令 `yy域名查询 example.com --服务器 1.1.1.1 --类型 1`。

## 核验

既有标签六验、八类全文三验皆成。配置缓存、问答核验、记录语义、安全网页协议、实传成对诸验，循其入口行之。实施与验收记于别篇。

## 后版之事

接公共 HTTPS 客户端，以自有安全网页道互通公共服务；公共数据报之口既具，乃接 UDP 查询。

依据 [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html)、[RFC 6891](https://www.rfc-editor.org/rfc/rfc6891.html)、[RFC 2181](https://www.rfc-editor.org/rfc/rfc2181.html)、[RFC 9460](https://www.rfc-editor.org/rfc/rfc9460.html)、[RFC 8484](https://datatracker.ietf.org/doc/html/rfc8484)。源码循仓库许可。

## 安全网页传输之口

`创建安全网页通道` 合公共 TCP、纯豫言安全传输客户及 HTTP 字节报文接收器为安全网页之道。用者授服务器址、端口、时限、书证链及主机名核验、握手署验与每连种子之供。`安全网页默认种子` 由标准库安全随机之口取六十四字节，分供客户随机数、X25519 私钥。

驱动发待发密文、纳所收密文，握手既成则发请求、收网页全答，续未尽读写，司等待、告警与关闭。此口源码入配套类型检查、真实互通之验；生产默认书证核验之装配、真实 Unix 时之接入列后事。

安全网页传输之口今为私有驱动候稿，错误、关闭之查询由明示回调参数授之。总集之出、生产通道之接及运行之验，随安全传输公共查询之口核准而行。

二〇二六年十月八日配套之验：九组八十断言、动态端口真实 TCP 互通，Node 及同客体原生皆成；私有安全网页驱动类型检查、域名查询构建皆成。甲乙全审、公共安全网页服务互通、百万采样入后验。

名称解码、全文解码各成正式隔离百万变异，父程核诸批末序，零退。官方 RFC 1035 四名压缩图八断言，Node、同客体原生皆成。记录载荷、配置诸余解析入口百万采样，生命周期峰值资源与性能对照列后验。
