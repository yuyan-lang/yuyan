# 字节编码

版本 0.1.0，生产包只依赖标准库，测试独立登记为「字节编码测试」包。输入和输出均为标准库字节串。每次输入限十亿字节。

## 基码

`十六进制编码(输入)`；`十六进制解码(输入,宽松)`。
`三十二进制编码(输入,填充)`；`三十二进制解码(输入,宽松)`。
`六十四进制编码(输入,网址安全,填充)`；`六十四进制解码(输入,网址安全,宽松)`。
解码返回或可有字节串。严格方式校验字母表、填充位置、填充数量及末尾未使用位；宽松方式接受 ASCII 空白及省填充。

流式接口为 `新建基码编码流(类别,网址安全,填充)`、`更新基码编码流(状态,输入)`、`结束基码编码流(状态)`；解码接口将“编码”替换为“解码”，第三参数为宽松。类别为 16、32、64。更新返回新状态与输出，解码更新返回或可有；结束输出剩余部分。基码和百分号分段为纯函数，调用者负责累计输入总量和结束后调用的生命周期约束。

## 验证与出处

可打印引用提供 `可打印引用编码(输入)` 与 `可打印引用解码(输入,宽松)`；编码按 75 列折入软换行，空白与换行使用十六进制引用。流式接口为 `新可打印引用编码流(元)`、`可打印引用编码流加入(状态,输入)`，以及 `新可打印引用解码流(宽松)`、`可打印引用解码流加入(状态,输入,结束)`。

严格解码检验原行至多76字节、CRLF配对及行尾空白；流式状态跨片保存列宽与待换行标记。

八十五进制提供 `八十五进制编码(输入)`、`八十五进制解码(输入,宽松)`，接受零组缩写与 Adobe 包装。编码默认输出原始字节。编码流更新接收残段与新输入，返回输出与残段；解码流逐块接收残段、新输入、宽松，返回或可有的输出与残段。结束接口解出末组。Adobe 包装可使用逐块接口，在完整组与终标处即时输出；原有收集式更新接口继续可用。八十五进制流累计输入限十亿字节，终标后的非空输入被拒绝。可打印引用解码流在结束后拒绝再次加入，流累计输入亦限十亿字节。流状态应原样传回接口。

百分号提供 `百分号编码(输入,编码集)`、`百分号解码(输入,宽松)`。编码集常量依次为通用 0、控制 1、片段 2、查询 3、特殊查询 4、路径 5、用户信息 6、组件 7、表单 8；各常量以「百分号」开头、「编码集」结尾。通用集按 [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986)，其余按 [WHATWG 网址标准](https://url.spec.whatwg.org/#percent-encoded-bytes) 2026-10-07 版本。表单编码把空格写成加号；百分号解码保留加号，表单解析者先把加号转为空格。分段解码接收输入、宽松、结束，返回已解字节与待续尾段。

早期合入稿的 `测试/全量/变异。豫` 曾生成一百万条长度 0 至 32 的确定性随机 ASCII 输入，每个严格与宽松解码入口各运行一百万次。该稿诺节运行完成，累计解码长度 46271750；共享开发机计时为 real 46.33 秒、user 2.58 秒、sys 0.07 秒。此数为早期随机验证耗时；当前增补稿的正式隔离模糊、原生吞吐量与系统工具对照留待乙级测量。

当前甲级短测在诺节与同源原生各自实跑通过：基码 161 项、可打印引用 174 项、百分号 624 项、随机二进制往返 8000 项，失败数均为零；八十五进制的向量、全字节与跨块测试输出通过。基码包含 RFC 4648 第十节向量，字母表覆盖标准与网址安全六十四进制，填充可选。出处为 RFC 4648、RFC 2045 第 6.7 节、Adobe Ascii85 公开格式及上述百分号标准；算法按公开规格独立实现，源码许可沿用仓库许可。全部字母表为格式常量。数据表均为自有测试向量与确定性随机生成值。详细提交、工具哈希、平台与日志见《验收记录.汉语.md》。原生性能、正式种子隔离模糊测试与裸机验证留待乙级。

首个使用者为「安全外壳协议」：公钥文本与私钥文本的六十四进制解码已改用本包；迁移提交为 `92bd3b535`。对应既有验证产物实际运行通过，调用位置与真实日志路径记录在验收记录。网址解析的百分号部件和数据网址也直接使用本包。
