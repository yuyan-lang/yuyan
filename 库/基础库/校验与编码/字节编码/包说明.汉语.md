# 字节编码

版本 0.1.0，只依赖标准库，测试使用单元测试包。输入和输出均为标准库字节串。

## 基码

`十六进制编码(输入)`；`十六进制解码(输入,宽松)`。
`三十二进制编码(输入,填充)`；`三十二进制解码(输入,宽松)`。
`六十四进制编码(输入,网址安全,填充)`；`六十四进制解码(输入,网址安全,宽松)`。
解码返回或可有字节串。严格方式校验字母表、填充位置、填充数量及末尾未使用位；宽松方式接受 ASCII 空白及省填充。

流式接口为 `新建基码编码流(类别,网址安全,填充)`、`更新基码编码流(状态,输入)`、`结束基码编码流(状态)`；解码接口将“编码”替换为“解码”，第三参数为宽松。类别为 16、32、64。更新返回新状态与输出，解码更新返回或可有；结束输出剩余部分。

## 验证与出处

RFC 4648 第十节测试向量、二进制往返与所有两段切分边界共 111 项通过。算法按公开标准实现，源码许可沿用仓库许可。完整验收的百万变异、原生性能与裸机验证留待后续实施记录。
