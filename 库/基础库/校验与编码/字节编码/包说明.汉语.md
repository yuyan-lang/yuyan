# 字节编码

版本 0.1.0，只依赖标准库，测试使用单元测试包。输入和输出均为标准库字节串。

## 基码

`十六进制编码(输入)`；`十六进制解码(输入,宽松)`。
`三十二进制编码(输入,填充)`；`三十二进制解码(输入,宽松)`。
`六十四进制编码(输入,网址安全,填充)`；`六十四进制解码(输入,网址安全,宽松)`。
解码返回或可有字节串。严格方式校验字母表、填充位置、填充数量及末尾未使用位；宽松方式接受 ASCII 空白及省填充。

流式接口为 `新建基码编码流(类别,网址安全,填充)`、`更新基码编码流(状态,输入)`、`结束基码编码流(状态)`；解码接口将“编码”替换为“解码”，第三参数为宽松。类别为 16、32、64。更新返回新状态与输出，解码更新返回或可有；结束输出剩余部分。

## 验证与出处

可打印引用提供 `可打印引用编码(输入)` 与 `可打印引用解码(输入,宽松)`；编码按 75 列折入软换行，空白与换行使用十六进制引用。流式接口为 `新可打印引用编码流(元)`、`可打印引用编码流加入(状态,输入)`，以及 `新可打印引用解码流(宽松)`、`可打印引用解码流加入(状态,输入,结束)`。

八十五进制提供 `八十五进制编码(输入)`、`八十五进制解码(输入,宽松)`，接受零组缩写与 Adobe 包装。编码默认输出原始字节。编码流更新接收残段与新输入，返回输出与残段；解码流逐块接收残段、新输入、宽松，返回或可有的输出与残段。结束接口解出末组。Adobe 包装的流使用收集式更新接口。

百分号提供 `百分号编码(输入,编码集)`、`百分号解码(输入,宽松)`。编码集常量依次为通用 0、控制 1、片段 2、查询 3、特殊查询 4、路径 5、用户信息 6、组件 7、表单 8；各常量以「百分号」开头、「编码集」结尾。通用集按 [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986)，其余按 [WHATWG 网址标准](https://url.spec.whatwg.org/#percent-encoded-bytes) 2026-10-07 版本。表单编码把空格写成加号；百分号解码保留加号，表单解析者先把加号转为空格。分段解码接收输入、宽松、结束，返回已解字节与待续尾段。

全量工具 `测试/全量/变异。豫` 生成一百万条长度 0 至 32 的确定性随机 ASCII 输入，每个严格与宽松解码入口各运行一百万次。诺节运行完成，累计解码长度 46271750；共享开发机计时为 real 46.33 秒、user 2.58 秒、sys 0.07 秒。此数为变异验证耗时；原生吞吐量与系统工具对照留待后续测量。

RFC 4648 第十节测试向量、二进制往返与所有两段切分边界共 111 项通过；百分号编码集测试 526 项通过；八十五进制和可打印引用的向量与跨块测试通过。算法按公开标准实现，源码许可沿用仓库许可。原生性能、种子语料隔离模糊测试与裸机验证留待后续实施记录。
