# 校验

本包以字节串计算循环校验与非密码散列，输出整数位模式。六十四位值按豫言有符号整数表示，一百二十八位值按低位、高位整数对表示。

算法包括循环校验32（IEEE）、循环校验32C、循环校验64（XZ）、阿德勒32、极速散列32/64及极速散列3的64/128位、低语散列3的32与x64 128位、固定乘异或散列32/64、短输入散列2-4。各模块提供一次与流式接口；流式续算次序为旧状态、输入字节串。

| 模块 | 一次接口 | 流式接口 |
| --- | --- | --- |
| 循环校验 | 循环校验32、循环校验32C、循环校验64 | 相应函数名加「续」 |
| 阿德勒 | 阿德勒32 | 阿德勒32续 |
| 极速 | 极速三二、极速六四；加「带种子」则另接整数种子 | 极速流创建、极速流更新、极速流三二收尾、极速流六四收尾 |
| 极速三、极速三宽、极速三流 | 极速三六四、极速三一二八；加「带种子」另接种子 | 新极速三流、更新极速三流、完成极速三六四、完成极速三一二八 |
| 低语散列、低语流 | 低语三十二、低语百二十八（另接整数种子） | 新低语流、更新低语流、完成低语三十二、完成低语百二十八 |
| 固定乘异或散列 | 固定乘异或三十二、固定乘异或六十四 | 相应名称加「初态」取初值，加「更新」续算 |
| 短输入散列 | 短输入散列24（输入、密钥甲、密钥乙） | 新短输入散列24、更新短输入散列24、完成短输入散列24 |

导入如 `寻观「校验」之「循环校验」之书。`；单段 `寻观「校验」之书。` 经手写总集汇出全部模块。种子流式创建接受整数种子，更新接受旧态与字节串，完成接受状态。

循环校验每次处理八字节，使用反射多项式生成的八张查表。循环校验的续算初态为零，阿德勒续算初态为一。短输入散列使用两个六十四位密钥整数，保留轮态与至多七个尾字节。极速散列与低语散列的流式接口暂存输入，完成时计算摘要；长流固定缓冲留待后续版本。

实现依据公开算法规格手写，运行时依赖标准库。测试包含标准字符串123456789、xxHash官方固定输入与摘要、SipHash官方64条附录向量与全部两段切分。参考：xxHash（BSD-2-Clause，https://github.com/Cyan4973/xxHash）、SipHash（CC0，https://github.com/veorq/SipHash）、MurmurHash3（公有领域，https://github.com/aappleby/smhasher）、FNV（https://www.ietf.org/archive/id/draft-eastlake-fnv-25.html）、CRC目录（https://reveng.sourceforge.io/crc-catalogue/）、RFC1950阿德勒校验。

实现进度：六组既有测试已在诺节与苹果臂六十四原生直接运行通过。新增标准串测试独立核对全部算法的一次结果和十种两段切分，共165条断言，两个后端均通过；标准串为九个ASCII字节，散列种子零，SipHash使用附录密钥000102030405060708090a0b0c0d0e0f，2轮压缩、4轮收尾与8字节结果。xxHash期望来自官方xxhsum0.8.3，SipHash期望来自OpenSSL3.6.4，MurmurHash3与FNV期望来自只导标准库的独立固定串参考计算，源码、命令、字节序与结果见《甲级验收记录.汉语.md》。FNV参考规范补充为RFC9923。

生产包只依赖标准库，六组测试及新增标准串测试归独立「校验测试」包。构建示例：`豫构 构建 校验测试 标准串。测试 --输出 yy校验标准串.wasm -j 24`。首个使用者为归档的默认压档桥，实际调用本包循环校验32完成写入与读取；默认桥短测与系统互读已有真实通过证据。甲级逐项证据见验收记录，由提案进度登记达级。乙级的系统性能对照、裸机验收与迁移继续按队列执行。

本包源码按公开算法独立实现，自有代码遵循仓库许可，外部算法规格与向量许可依上述出处记录。
