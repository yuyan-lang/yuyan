# 紧凑二进制公共规范

本包直接依赖标准库。`寻观「紧凑二进制」之书。` 导入公开值类型、读取、编码与字段访问。

## 起位、终位与错误

读取入口接收字节串与从零起算的字节位置，成功返回值及下一字节位置。调用者可以依据终位继续读取后续值。尝试读取入口要求起位处于零至字节串长度之间；起位等于长度时返回数据读取失败，越界起位抛参数异常。

`消息包尝试读取`、`简象尝试读取` 返回 `二进制读取成功 值 终位` 或 `二进制读取失败 错误文字`。`节俭紧凑尝试读取`、`节俭二进尝试读取` 返回 `节俭读取成功 值 终位` 或 `节俭读取失败 错误文字`。消息头尝试入口返回 `节俭消息读取成功 头` 或 `节俭消息读取失败 错误文字`。

输入字节访问先核验范围；递归读取的深度限额为10000。数据错误通过读取失败结果表达。宿主陷阱与资源耗尽通过隔离执行的失败结果验收。

## 消息包与简象值

通用类型为 `二进制值`，其构造项包括空、布尔、整数、小数、文字字节、原始字节、数组、键值映射、标签、扩展、无符号整数、负大整数与简单值。

`二进制无符号整数 位型` 保存高位为一的64位无符号数，位型由普通整数容纳。`二进制负大整数 位型` 保存简象负整数的无符号参数n，其数学值为−1−n。文字与字节构造项各保存字节串。映射保存键值对的列，数组保存值的列。

`消息包读取 数据 起位` 返回值与终位；`消息包编码 值` 返回字节串。消息包文字保存原始字节，扩展保存有符号8位类型号与原字节。整数编码选择最短宽度，浮点编码使用双精度，扩展统一使用带长度的格式。

`简象读取 数据 起位` 返回值与终位；`简象编码 值` 返回字节串。简象读写核验文字UTF-8。确定性编码选择最短整数、长度和精确浮点宽度，保留负零，统一NaN为半精度 `f97e00`，输出定长容器，按键的编码字节字典序排列映射并拒绝重复编码键。

简象标签0核验并保存RFC3339日期文字，标签1保存完整正负整数域及有限小数，标签2、3保存大端绝对值字节。大数编码移除前导零，64位内的值使用普通整数主类型。其余标签保存标签号与嵌套值。

## 节俭值、类型与字段

`节俭值` 包括 `节俭整数`、`节俭字节`、`节俭序列`、`节俭映射`、`节俭结构` 和编码时使用的 `节俭指定类型 类型码 值`。结构保存“字段号与值”的列。

`节俭紧凑读取 数据 起位` 与 `节俭二进制读取 数据 起位` 读取结构值和终位。`节俭字段 结构 字段号` 返回 `节俭有项 值` 或 `节俭缺项`。`节俭紧凑编码 值` 与 `节俭二进制编码 值` 返回字节串。

指定类型使用紧凑协议类型码：1、2为布尔，3为有符号8位整数，4、5、6为有符号16、32、64位整数，7为双精度，8为字节串，9为列表，10为集合，11为映射，12为结构，13为唯一标识。整数默认类型6，字节默认类型8，序列默认类型9。集合以类型10指定序列。容器中的布尔类型头统一为1，紧凑布尔元素载荷1为真、2为假，二进布尔载荷1为真、0为假。

双精度值使用 `节俭字节` 保存8字节小端位型，编码时以类型7指定；唯一标识保存16字节并以类型13指定。窄整数、字段号和载荷宽度按所选协议类型核验。

## 节俭消息头

`节俭紧凑消息编码 名称字节 种类 序号` 与 `节俭二进消息编码 名称字节 种类 序号` 编码消息头。种类1、2、3、4分别表示调用、应答、异常与单向消息。序号为有符号32位整数。

`节俭紧凑消息读取 数据 起位`、`节俭二进消息读取 数据 起位` 返回 `节俭消息头`，依次包含名称字节、种类、序号和终位。二进消息读取支持版本头及旧式名称长度头。对应尝试入口为 `节俭紧凑消息尝试读取` 与 `节俭二进消息尝试读取`。
