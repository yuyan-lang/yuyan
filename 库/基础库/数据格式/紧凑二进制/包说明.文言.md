# 紧凑二进制

以豫言读节俭紧凑之整数、字节、序列、映射及结构。入口曰节俭紧凑读取，还值树与终位；节俭字段以号取结构之项。

据 [Apache Thrift 紧凑协议规格](https://github.com/apache/thrift/blob/master/doc/specs/thrift-compact-protocol.md)。变整数以七位小端组读之，负数以曲折编码转之；结构之布尔寓于字段头，序列之布尔各占一字节；双精度藏八字节之原位。

试结构之一号为整数一，二号为字节串 abc，核取项及终位。

消息包读取与消息包编码可读写空、布尔、整数、单精与双精小数、文字、字节、数组、映射及扩展。无符号六十四位整数藏其位型于二进制无符号整数，文字存原字节。据 [MessagePack 公开规格](https://github.com/msgpack/msgpack/blob/master/spec.md)，试固定数组、单精格式及整数与扩展往返。

简象读取与简象编码据 [RFC 8949](https://www.rfc-editor.org/rfc/rfc8949.html) 治诸主类型。读无定长之字节、文字、数组及映射，核文字 UTF-8；以最短整数、长度及浮点编码，映射循键之编码字节排之，拒同编码之键。零号日期标签核格式、年月日、时分秒及时区而藏其文，一号时间戳藏有限数字；二、三号大数标签藏大端绝对值字节，编码去首零，六十四位内者化寻常整数。

节俭紧凑编码、节俭二进制编码及节俭二进制读取治标量、列表、集合、映射、结构及唯一标识。节俭指定类型裹值而定协议之型；整数默认六十四位，四、五、六号各为十六、三十二、六十四位，七号为小端双精度八字节，十三号为唯一标识十六字节。结构列字段号及值，集合以十号定序列。消息头治紧凑与有版二进消息，亦读旧版二进消息。

外入之文可用消息包尝试读取、简象尝试读取、节俭紧凑尝试读取及节俭二进尝试读取，还成功之值或失败之辞。先核字节界，嵌套之深限万层。
