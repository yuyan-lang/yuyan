# 协议缓冲对照样例

六个 `特殊…模式.proto` 保留官方 protoc 36.2 发布包 `include/google/protobuf/` 中 wrappers、struct、any、timestamp、duration、field_mask 的原文和许可；用于九种包装类型、Struct/Value/ListValue、Any、Timestamp、Duration、FieldMask 与嵌套映射。特殊时间编码由官方 protoc 36.2 编码 `seconds: 0 nanos: 123456789`，SHA-256 为 `6e9df4755cdcaef9184e465f394002ed839fd4386efa61888a279635c3d1ddf0`；特殊时长编码由同一工具编码 `seconds: -1 nanos: -1000`，SHA-256 为 `19d4c53c909a20463dac1b29319f9f406a8e7fe4aa12a166850cb10e9bd75bbf`。2026 年 10 月 8 日，六模式导入、十七项 JSON 往返与两项官方原编码对照均在 pit-mac 的配套 25a 工具链上正常退出。

样例由官方协议编译器 36.2 生成，用于模式解析、线格式及文本与结森映射的对照测试。编译器来源：[协议缓冲 36.2 发布](https://github.com/protocolbuffers/protobuf/releases/tag/v36.2)。模式文件保留上游原文与许可声明。

`算图模式.proto` 取自 2026 年 10 月 7 日的 [ONNX 模式](https://github.com/onnx/onnx/blob/main/onnx/onnx.proto)，采用 Apache-2.0 许可，SHA-256 为 `795fcd38a3267a6c085190e90bd71c799a98bbba35c6a23f19c8bc672b62ed92`。`算图文本.txt` 描述单个 Relu 节点及一个浮点初始化器，`算图模型.onnx` 是其编码，SHA-256 为 `614d3fc5d82b84edb5c768414dedd47252439a4693d2ad8f42304cf828d777cc`。

`句片模式.proto` 取自同日的 [SentencePiece 模式](https://github.com/google/sentencepiece/blob/master/src/sentencepiece_model.proto)，采用 Apache-2.0 许可，SHA-256 为 `ac92a7ba0b743e76fe6fb4caadafef4f7f69aa8d4074f8b1ef48cf6d1c5be8c9`。`句片文本.txt` 描述六个词片及基本训练、规范化选项，`句片模型.model` 是其编码，SHA-256 为 `ac2ad08af56501deba417724b0b095f52dbf47a68271480d90407becece6e7b6`。

对照模式与文本由本仓编写，覆盖变长整数、之字形、固定整数、小数、文字、字节、紧凑重复字段、枚举、嵌套、单选、旧式分组及映射。`对照编码.bin` 的 SHA-256 为 `dc6721fb96cf328fbc1703733dc242ed51bba3f5fec94a4e11b281d8181acafd`，`对照结森.json` 保存期望的结森树。

两个模型属于依官方模式生成的微型序列化样本。外部运行器执行、训练模型对照及百万输入验收列入后续验证。

`真实算图模型.onnx` 取自 [ONNX 官方 PyTorch 导出 Linear 测试](https://github.com/onnx/onnx/blob/main/onnx/backend/test/data/pytorch-converted/test_Linear/model.onnx)，共 585 字节，官方 git blob 为 `cb2d07eb66559c9bb450903b19ef5190f43f419f`，SHA-256 为 `60a3546925d832686c788d3ea22732feaef5bc527e04691c32ec9f677c81f612`。文件记载 PyTorch 0.3 导出、IR 3、Gemm 节点及形状为 8×10 和 8 的两个浮点初始化器。`真实算图文本.txt` 由官方 protoc 36.2 解码得到。样例随 ONNX 仓库的 Apache-2.0 许可发布。

`真实句片模型.model` 取自 [SentencePiece 官方英文 Unigram 1000 词片模型](https://github.com/google/sentencepiece/blob/master/data/botchan_en_unigram_1000.model)，共 253152 字节，官方 git blob 为 `8286458480b8cdb12681ce63769d48a477778347`，SHA-256 为 `f8c7e5e0fa9e948783d20ea9dccf0e2611f567bc1a4e468a658becd5015f458e`，采用上游 Apache-2.0 许可。两个真实文件的下载结果均以 `git hash-object` 核对官方文件树的 blob 值；protoc 已成功解码，豫言解码的验收等待资源时段。
