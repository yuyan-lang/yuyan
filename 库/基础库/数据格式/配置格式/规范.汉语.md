# 配置格式公共门面

单段导入「配置格式」提供以下入口。

| 名称 | 签名 | 行为 |
| --- | --- | --- |
| 解析通明配置 | 字符串 → 配置结果 | 读取 TOML 1.0；错误结果带行、列和说明。日期时间保存原文。 |
| 写通明配置 | 配置值 → 字符串 | 将配置表写为 TOML 文档。 |
| 解析雅码 | 字符串 → 雅码结果 | 读取 YAML 1.2 核心模式多文档节点图，核验映射键唯一性，保存标签、锚点及别名身份。 |
| 写雅码 | 列于雅码文档 → 爻 → 字符串 | 写出多文档节点图；阳选择块式，阴选择流式。 |
| 雅码转配置 | 雅码文档 → 配置结果 | 投影为配置树；整数使用有符号64位，键使用字符串，循环及超出表示范围以结构错误返回。 |

「雅码节点」包括空、字符串、大整数、小数、爻、序列、任意节点键映射、锚点、别名及标签构造子。「雅码文档」由根节点与整数身份到节点的锚表组成。「雅码结果」使用「雅码成功」携带文档列，「雅码失败」携带配置错误。标签以数据保存。

总集精准公开上述五入口、三类型及其构造子。内部解析状态与词法设施由模块自身使用。测试/公共门面。测试。豫提供一个正常输入与一个错误输入的基本 CI 冒烟。
