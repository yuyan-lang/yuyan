# 配置格式

配置格式以纯豫言保存配置树，提供分节配置（INI）与环境配置（.env）读写；静态站前言与平铺映射列表共用本库。

`配置值` 保存空值、字符串、有符号64位整数、小数、布尔值、日期时间原文、数组和有序表。解析结果保存成功值或从一开始的错误行、列与说明。INI 支持根键、节、空行、注释与同名键覆盖；环境配置支持 `export `、空值、值内等号与单双引号。

## 私有候稿

通明是 TOML 的提案译名。私有模块 `通明配置` 与 `通明写出` 提供配置树解析和写出；日期时间保存精确原文，数值格式负责小数读写，日历负责公历日期校验。

雅码是 YAML 的提案译名。私有雅码模块保存文档流、任意节点键、序列、映射、锚点身份、别名与标签。整数节点使用正式大数库保存任意精度整数。转换到配置树时，对超出64位的整数、复杂键、循环图与标签返回明确失败说明。写出支持流式、块式与文档边界。

正式总集保持配置数据和键值配置两项导出。通明和雅码候稿通过库内短测试直接导入。
