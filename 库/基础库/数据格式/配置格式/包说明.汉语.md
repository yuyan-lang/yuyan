# 配置格式

配置格式以纯豫言保存配置树，提供分节配置（INI）与环境配置（.env）读写；静态站的前言与平铺映射列表解析迁入本库。

`配置值` 包含空值、字符串、整数、小数、布尔值、日期时间原文、数组和有序表。`配置取` 按键取表项。`解析分节配置` 与 `解析环境配置` 返回 `配置成功` 或 `配置失败`；错误包含从一开始的行、列与说明。`写分节配置` 与 `写环境配置` 写出配置文本。

INI 支持根级键、节、空行、注释与同名键覆盖；.env 支持 `export ` 前缀、空值、值内等号、单引号值与双引号转义。键值保持出现顺序。两种格式的值保存为字符串。双引号转义共用结森工具的解析。

前言模块提供 `前言取`、`解析前言`、`分离前言` 与 `解析数据列`，保持静态站原有接口；支持平铺键值、单双引号与平铺映射列表。

## 验证

`测试/键值配置。测试。豫` 验证覆盖、空值、等号、读写往返、分节与错误行号。静态站既有测试核对迁移前言行为。
