# 配置格式公门

单段寻「配置格式」，得以下诸术。

| 名 | 型 | 行为 |
| --- | --- | --- |
| 解析通明配置 | 字符串 → 配置结果 | 读 TOML 1.0；误载行、列及言。日期时刻存原文。 |
| 写通明配置 | 配置值 → 字符串 | 以配置表写 TOML 文。 |
| 解析雅码 | 字符串 → 雅码结果 | 读 YAML 1.2 核心之多文档图，验映射键独一，存标签、锚及别名身份。 |
| 写雅码 | 列于雅码文档 → 爻 → 字符串 | 写多文档图；阳用块式，阴用流式。 |
| 雅码转配置 | 雅码文档 → 配置结果 | 投为配置树；整数取有符号六十四位，键取字符串；遇环及越表示之域，以结构误返。 |

「雅码节点」有空、字符串、大整数、小数、爻、序列、任意节点键映射、锚点、别名及标签诸构造。「雅码文档」合根节点与整数身份所系之锚表。「雅码结果」以「雅码成功」载文档列，以「雅码失败」载配置误。标签存为数据。

总集明列五术、三型及其构造；雅码节点全篇转诵，构造可径用于式，其节点转换之辅术亦随之可见。词法与解析状态循其私模块。测试/公共门面。测试。豫以一正一误之输入供 CI 起验。
