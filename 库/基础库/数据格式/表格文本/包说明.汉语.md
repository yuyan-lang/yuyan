# 表格文本

提供 CSV、TSV 与自定分隔符、引号及转义字符的分块读写。读态跨块保留引号、转义和回车，字段及记录按输入顺序返回。表头选项把首行保存在读态，`表格表头` 取出它。裁白选项裁去字段两端的空格与制表符。

`新表格读态` 创建状态，`读表格块` 返回状态与已成行，输入结束调用 `终结读表格`；一次读取使用 `读表格`。写出使用 `写表格行` 或 `写表格块`，记录以回车换行结束。空输入产生零行；空记录产生一个空字段。缺失闭引号与闭引号后的杂字符抛出事故。

实现依赖标准库与编码转换。数据集导入器可逐块送入文本，逐批消费记录。`读编码表格` 接收方言、编码名、字节串及严格开关；`写编码表格` 接收方言、编码名及记录。编码名称与错误处理沿用编码转换接口。一次字节接口覆盖 UTF-8、UTF-16 与 UTF-32 等编码。

`新表格字节读态` 接收方言、编码名及严格开关，复用编码转换的流式解码态。`读表格字节块` 返回可有的状态与已成行，`终结表格字节读取` 收取尾部，`表格字节表头` 取出表头。`新表格字节写态` 接收方言与编码名，`写表格字节块` 返回可有的状态与字节串，`终结表格字节写出` 收取编码尾部。重复终结返回空输出，已终结状态继续送块抛出参数事故。非法编码及表格数据错误返回可无，每个输入字节块上限为1 GiB。测试包含中文字符跨字节块往返与严格非法编码拒绝两个基本冒烟。

`推断字段类型` 和 `推断表格列类型` 推断空、真假、整数、小数与文本类型。空值保持已知类型，整数与小数合成小数类型，其他混合类型合成文本类型。`推断表格列类型从` 可把前块的推断结果传给后块，实现大文件增量推断。读取块的大小由调用者决定，读态只保留未完成字段及记录。

`尝试读表格`、`尝试读表格块`、`尝试终结读表格` 把可恢复的数据错误转成 `可无`，其他异常继续抛出。编码字节读取入口采用此处理。每个输入块上限为 1 GiB，每条记录默认上限为 1 GiB；记录计数跨块累计，包含分隔符与引号，引号外的记录终止符重置计数，字段长度共同受记录上限约束。`新有界表格读态` 接收方言及正数上限，可为使用者设置记录限制。超限报数据错误。

首个使用者为 `示例/查看表格。脚本。豫`：读取实际表格文件，调用编码字节入口，以列分隔线打印内容。构建命令为 `豫构 构建 表格文本 示例 查看表格。脚本 --输出 yy查看表格.wasm -j 24`，运行时传文件路径和可选编码名。

2026-10-08 同机性能测量使用十万、二十万汉字单字段，预热两次、测七次取中位数。苹果臂六十四预编二硬原生分别为 11.886 ms、31.709 ms，字段长度加倍时耗时约为 2.67 倍。诺节分别为 9.615 ms、120.636 ms；测量时机器负载较高，保留原始结果。系统 C 工具对照及后续性能优化另记实施记录。

同机系统 C 工具粗对照使用系统 SQLite 的 CSV 导入，输入为纯豫言生成的相同十万、二十万汉字单字段文件，导入后长度查询分别为100000、200000。系统进程总耗时分别约80 ms、20 ms，计入进程与数据库初始化；此记录保存完整范围与计时分辨率，精确解析阶段对照留待后续测量。

测试数据采用 csv-spectrum 固定提交 `d30e80f8b99d2eecb3778f1d7b9ed1cb425502ec` 的十二样例，许可为 BSD-2-Clause，原始字节保存在测试目录。[样例出处](测试/样例/出处.汉语.md)记录版本、许可与地理坐标样例的期望差异证据。普通测试与官方全集均采用抛错断言，完成时打印“失败0”。
