# 列存数据

此库以豫言为箭列内存与拼花页之编码。其类有整数、小数、爻、文本、字节、列、结构、字典、时间戳。数组藏类、长、空数、偏移、缓冲、子列。截片共其不变之藏，复数空值。

拼花之码有小端整数、变长无符号整数、游程与位合编码、字典序、原样整数及字节。读者以可有告其成，以可无告其缺损。

箭列元数据可读平缓冲之根、虚表字段、标量、间接对象及字节向量。消息之读可识旧式长度与连续标记，还类、元数据、体及后始。

首用者为示例之箭列流查看，读 IPC 流档，逐书消息之类与体长。以豫构建示例之入口，可行之。

拼花文件之读，验首尾 PAR1，析尾部节俭元数据，还版、行数、模式、行组。页之读，存页头与压字节，以待压缩库解之而读列值。

全类型原样之向量取自 [Apache parquet-testing](https://github.com/apache/parquet-testing/blob/master/data/alltypes_plain.parquet)，依 Apache 2.0 之许可，全文存于同目。上游之试，验八行及元数据尽读。

基本类型箭列流取自 [Apache arrow-testing 之 C++ 21.0.0 流](https://github.com/apache/arrow-testing/blob/master/data/arrow-ipc-stream/integration/cpp-21.0.0/generated_primitive.stream)，亦依 Apache 2.0 之许可。

拼花层级可读初版、二版数据页之重复级、定义级及列值之始，以游程与位合解其流。

嵌套模式树循标准前序，复列与结构；叶列尽存重复、定义诸级。列之偏移别父空、空列、空元素及重复元素。拼花之写，按批成行组，以PLAIN列值、RLE层级及节俭紧凑之页脚。秒时间写为毫秒，逻辑时间之注记存毫秒、微秒、纳秒之度。字段据[Apache官方Thrift定义](https://github.com/apache/parquet-format/blob/master/src/main/thrift/parquet.thrift)。

## 后续之事

IPC字典增量合其值缓冲。文件会诸批字典，移其索引，每号惟书一统一字典；原域不足，则广至三十二位。大端数据转为列存小端，位图、字节之序仍旧。批次察行数及节点、缓冲向量之尽读；字典索引察其符号与界。列表三层之写，用`list`、`element`协议之名；读法据[Apache官方列表规范](https://github.com/apache/parquet-format/blob/master/LogicalTypes.md#lists)。

输入及单块解压，限四GiB；递归限四千九十六层，列值限十亿，解压倍率限百万。逾限之读，还可无。核物理缓冲，察空值数、缓冲之长、偏移之序及结构子列之长。全量独立之包，用正式批模糊之器，录实变序号及接受拒绝之类。

箭列流与文件之读写、拼花全档读写及嵌套之义，续核其全。泽标压之接、限量之果、原生、全量变异及上游之验，皆续为之。诸能与核验皆成，乃定甲乙之级。
