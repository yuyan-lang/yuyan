# 列存数据

这是箭列列式内存与拼花页编码的纯豫言基础库。列存类型包含整数、小数、布尔、UTF-8、二进制、列表、结构、字典与时间戳。列存数组保存类型、长度、空值数、逻辑偏移、缓冲列表与子列列表。切片共享不可变缓冲，重新计算空值数。

拼花编码提供小端整数、无符号变长整数、RLE 与位打包混合编码、字典索引和 PLAIN 整数及二进制编码。读取函数通过可选值报告截断或非法输入。

箭列元数据提供 FlatBuffers 根地址、虚表字段、标量、间接对象和字节向量读取。箭列读取消息识别旧式长度前缀与连续标记前缀，返回消息类型、元数据、消息体及下一条起点。

首个使用者是 `示例/箭列流查看。豫`。它读取真实 IPC 流文件，逐条打印消息类型与体长。用豫构构建列存数据的示例入口即可运行。

拼花文件信息读取核验文件的 PAR1 首尾标记，解析尾部节俭紧凑元数据，返回版本、行数、模式及行组。页读取保留页头与压缩字节，供压缩库解码后读取列值。

测试向量 `测试/向量/全类型原样.parquet` 来源于 [Apache parquet-testing 的 alltypes_plain.parquet](https://github.com/apache/parquet-testing/blob/master/data/alltypes_plain.parquet)，适用 Apache 2.0 许可，许可全文保存在同目录。上游测试核验其八行及元数据完整消费。

箭列流向量 `测试/向量/基本类型箭列流.bin` 来源于 [Apache arrow-testing 的 C++ 21.0.0 基本类型流](https://github.com/apache/arrow-testing/blob/master/data/arrow-ipc-stream/integration/cpp-21.0.0/generated_primitive.stream)，同样适用 Apache 2.0 许可。

拼花层级模块读出 v1 与 v2 数据页中的重复级、定义级及列值起点，级别流使用 RLE 与位打包混合解码。

嵌套模式树依标准前序模式恢复列表及结构，叶列保留全部重复级和定义级。列表偏移区分空父值、空列表、空元素及重复元素。拼花写出入口按批次写行组，采用PLAIN列值、RLE层级及标准紧凑页脚。秒时间写出时转换为毫秒，逻辑时间注记保存毫秒、微秒和纳秒单位。格式字段依据[Apache官方Thrift定义](https://github.com/apache/parquet-format/blob/master/src/main/thrift/parquet.thrift)。

## 后续实现

IPC字典增量合并值缓冲。文件写出汇集各批字典并重定位索引，同一编号写一次统一字典，原索引范围不足时扩至32位。大端数据缓冲转换为列存小端形式，位图与字节数据保持原序。批次核验行数以及节点、缓冲向量完整消费；字典索引核验符号和边界。列表三层写出采用`list`与`element`协议名，读取规则依据[Apache官方列表规范](https://github.com/apache/parquet-format/blob/master/LogicalTypes.md#lists)。

输入与单块解压上限为四GiB，递归上限4096层，列值上限十亿，解压倍率上限百万。读取超限返回可无。物理缓冲核验检查空值数、缓冲尺寸、偏移单调性和结构子列长度。独立全量测试包使用正式批模糊设施，记录真实变异编号与接受拒绝类别。

箭列 IPC 流与文件读写、拼花完整读写及嵌套语义的整体核验继续实施。泽标压接入、限制结果、原生及全量变异与上游测试集验收继续实施。甲级与乙级门槛待这些能力及验证全部完成后核定。

## 嵌套字典与泽标压续作

续作将Schema和Footer中的字典编号映射到物理节点序，记录批次递归装入列表及结构里的字典；字典值批次使用独立节点序并引用先到的子字典。流状态保存模式侧表，文件先按Footer顺序装入全部字典后读取记录块。公开完整流、文件读取签名保持一致。拼花codec6和IPC缓冲codec1调用正式压缩库泽标压解压，复用原长及倍率核验。此续作完成格式解析，类型和运行核验待窗口。

`测试/嵌套字典上游。测试。豫`使用[Apache Arrow C++21官方嵌套字典样例](https://github.com/apache/arrow-testing/tree/master/data/arrow-ipc-stream/integration/cpp-21.0.0)，流2544字节、文件3266字节，Apache2.0许可沿用同目录许可全文。官方JSON独立预期为两个批次十行和十三行、两个顶层列、列表和结构字典各三十项、共享字符串字典十项；短测试逐层核验这些数据，失败抛出事故。
