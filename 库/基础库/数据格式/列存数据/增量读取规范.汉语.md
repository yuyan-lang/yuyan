# Arrow IPC增量读取规范

默认导入的 `箭列增量读取` 模块导出「箭列字节读取器」「箭列批次消费者」与「箭列增量读取流」。

「箭列字节读取器」接收整数绝对字节位置和整数请求长度，返回「或可有 字节串」。读取器返回至多请求长度的非空片段，支持短片段；解析器按实际长度推进位置，补齐当前消息所需字节。缺项、提前返回空片段、超出请求长度的片段均使当前读取返回缺项。零长度消息体由解析器直接处理。

「箭列批次消费者」接收一个「列存批次」，返回爻。阳表示继续，阴表示正常结束；已调用的当前批次计入交付批数。调用方可以立即处理批次，也可以自行保存所需批次。

「箭列增量读取流」接收读取器与消费者，返回「或可有 整数」。成功值是已经交付的记录批数，包括消费者要求停止的当前批次；缺项表示截断、元数据、类型、字典或记录解码错误。读取器和消费者抛出的异常按现有异常规则传播。

解析器逐帧读取IPC长度头、FlatBuffers元数据和消息体，支持传统长度头与continuation长度头。模式与大端标记跨帧保存；字典替换和增量消息通过正式字典模式、合并和记录实现解码。替换后删除同编号的旧字典引用。记录解码后即调用消费者，状态保存模式与当前字典；处理下一消息时释放解析器对旧记录消息体的引用。调用方保存的批次及当前字典继续拥有其所需缓冲。

解析器的输入驻留范围为当前消息的元数据、消息体和补齐短片的临时片段，状态另保存模式与当前字典。每一元数据段、消息体沿用列存最大输入字节限额；整条流可以逐帧处理。读取器可以连接已有按位文件读取或网络缓存。

测试入口「测试 增量读取。测试」包含两个基本烟测：官方嵌套字典10/13行两批以三字节短片读取，以及六字节截断长度头返回缺项。本轮源码交付时本机构建仍在运行，完整测试交CI。文件尾部索引与Parquet按行组增量输入列为后续实现事项。
