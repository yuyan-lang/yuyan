# 可扩展标记

此包备 XML 文树、预定实体转义、属与节之书出及递归之析口。树存元之限定名、属之序、文、CDATA 之文、注及处理令。

`解析` 受串而还根元，失则告截断、属与终签之故。`写出` 还紧凑之文。`文本转义`、`属性转义` 可助有式之文生成。

析者循 XML 1.0 第五版之名域察统一码之码点，严验 UTF-8、XML 字符及十进十六进之引，归一行尾及属之空白。命名之验及其宣、承、限定名、保留之址、无所承之前缀与同展之属。首声明、外围注与处理令，皆可析。

文树与拉取之口，共察文之处理令、实体及记法之无冒号名；逐文相校之验，及官方实体所处与预定实体之例。

名之察兼及展后正文、参数实体所生之宣、未用 DTD 元与属及内容模型之限定名、NDATA 记法之引与 NOTATION 候选之本名。内 DTD 处理令存于辅录，以察其名；常枚举之值循 NMTOKEN 词法。十三补验及官方今界之复验皆过。

十三补验随综合短例，于诺节、同源硬浮原生及实 Chrome 各过之；浏览器新客体之毕验记与零错误之录皆存。

库验依正式共验之器，以五参父程隔其变异之批。字节解码、原字节文树与拉取，首轮各行百万编号之召，皆常终而相校合；今单点翻位、删、插、易之法有定周期，验文之字节可重。受文方核书出往返，召数循实支录之；诸子程 RSS 之限续验。

六组综合短验及上述官方之界，皆于诺节与同源硬浮原生过之；官方两端皆一千七百一十八过、零失、八百六十七别录。

变异之驱已备字节解析两口，用合法内 DTD 与 ID 之种而先核原种；字节解码、串析、串拉取、字节析及字节拉取，各行百万编号之召皆过。五口逐文受拒之较与受后书出往返皆核。

名称之检增强后，五口百万于同源原生皆毕，末序 999999，正式母子隔离之验无陷阱、差分失合及批次逾时。静态站迁移之验，于诺节与同源原生各成功二十四、失者零；甲级逐项之据见《甲级验收审核》。

六组综合验例，已于实 Chrome 抽验皆过；纯豫薄应用俟诸初置断言毕，乃书毕验之记于页，错误与警告之录皆空。浏览器验应用及静态页在 `测试/浏览器`。

查询与 DTD 之模糊口，各先核合法原种，乃以正式批隔离行百万编号之文。查询之普通及明命名域两口，诸编号皆召之，受后复核身份、去重、计数及串值之确定；DTD 诸编号皆校，受后核书出往返。三口初召各至百万，皆常终。

性能之验用内置小文，先温三轮，九轮取中位，每轮千次而核其果。名称之检增强后，原生毫秒：解码 7.849，DOM 88.018，拉取 93.594，书出往返 37.951，DTD 139.511，查询 6.887。同机系统 libxml 2.9.13 解析与 DTD 校验之中位各为 29、31 毫秒，原生小文之比约为 3.04、4.50。历次复测、诸轮原数及资源之数见《性能记录》，其量兼运行时、读文及核验之界；广验诸载及百万子批分配之限续验。

内 DTD 与实体展限、编码转换、流式拉取、缩进书出、XPath 子集及 DTD 校验皆具实现与独立验例，默认名域之六组综合短验已过。W3C xmlconf 20130923 全目录之驱，已核默认名域之界：一千七百一十八项皆过，失者零；八百六十七项依外实体之法、原名之式及版本之界别录。诸子程 RSS 之限与裸机实运列后验之事，甲乙之果依实验之录而更。

此实现据 W3C XML 1.0 第五版、Namespaces in XML 1.0 第三版及 XPath 1.0 之规，独以纯豫言为之。代码循仓根 `LICENSE` 之 GNU AGPL 第三版许可。官方 xmlconf 原验集存于仓外，取自 W3C XML 验页，发行之文循其原版权告而存；仓内验例皆本库自编。
