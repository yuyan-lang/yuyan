# XML 1.0 原名之口

`原名解析 文本` 还既有 `标记节点`；`原名开始拉取 文本` 还既有 `标记拉取器`，以 `拉取下一` 逐事推进。总集兼出诸口。

原名之口循 XML 1.0 第五版 Name 词法，存名中冒号，以原名核始终之标。`xmlns` 及含冒号之属，皆循常 XML 属性而存。字符、行尾、声明、内 DTD、实体展限及默认禁外实体之法，共用原实现。字节之入可先以 `解码标记输入` 化为文本。

`解析`、`解析带声明`、`开始拉取` 续循现名域之义。拉取事件之类与旧 `拉取状态` 诸项仍旧，原名之式以 `原名状态` 包之，逐进后存其式。

`测试/原名入口。测试。豫` 含二基本之文：多冒号空根可析而拉取至终，始终原名失配则拒之。常 CI 自得此口。原名官全例、百万及诸后端长验，依用户之命缓之。
