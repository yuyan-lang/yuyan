# 路径查询子集

`查询` 模块实现 XPath 1.0 的位置路径子集。`查询路径` 接收根元素与表达式，返回路径节点列表；`查询路径带命名空间` 再接收查询前缀与命名空间地址的成对列表。路径节点分为文档、树节点和属性节点，并携带身份路径与在域命名空间。`路径计数`、`路径布尔`、`路径结果串值` 提供节点集合的常用转换；`路径串值` 读取单个节点的字符串值。

位置路径支持绝对与相对路径、`/`、`//`、`.`，以及 `child`、`descendant`、`descendant-or-self`、`self`、`attribute` 轴。`@` 是属性轴缩写。节点测试支持限定名称、`*`、`前缀:*`、`node()`、`text()`、`comment()` 和 `processing-instruction()`。

名称和通配符测试按轴的主节点类型选择：属性轴选择属性，其余已支持轴选择元素；`node()` 等类型测试按实际节点类型选择。属性、文本、注释和处理指令各保存自身字符串值，元素与文档的字符串值按文档顺序拼接后代文本。

谓词支持正整数位置、`last()`、`position()=整数`、`position()=last()`、属性或子节点存在、属性或子节点字符串等值、`text()` 与当前节点 `.` 字符串等值。等值右侧使用单引号或双引号字面量。多个谓词按出现顺序作用，位置在每个谓词后重新计算。`//项[1]` 在每个父节点的子轴中取第一项，`/descendant::项[1]` 在全部后代中取第一项。

未带前缀的名称测试匹配空命名空间。查询前缀依显式查询表解析，节点名称依树中继承的声明解析。属性轴排除命名空间声明。相邻文本与 CDATA 文本合并为一个路径文本节点，空文本移除，注释与处理指令划分文本节点。

表达式长度上限为一百万字符，路径节点层数上限为一百万层，每次后代遍历上限为一亿节点。身份路径用于去重并恢复文档顺序，同一元素的属性保持实现所定顺序。位置谓词逐父节点执行，再合并结果。

后续版本事项：父轴与祖先轴、兄弟轴、命名空间轴、集合并集、变量、通用布尔与算术表达式、通用函数库、嵌套谓词、带目标的处理指令测试。

规格来源：[W3C XPath 1.0](https://www.w3.org/TR/1999/REC-xpath-19991116/)，第二节的位置路径与第五节的数据模型。查询入口与本地向量已通过综合构建和真实运行。
