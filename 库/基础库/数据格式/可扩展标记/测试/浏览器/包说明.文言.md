# 标记浏览器验收

此应用于实浏览器行可扩展标记六组综合初置之断言。诸验皆毕，页面“结果”之元乃显“可扩展标记六组浏览器验收通过”。测试应用录于数据格式基础库。

于仓根用完整同配诸器，行 `yy双宿主构建.wasm --自动 浏览器 库/基础库/数据格式/可扩展标记/测试/浏览器 yy标记浏览器产物 --包根 库 --编译器 编译器路径`。抄本目录验收页入产物之目录，名 `yy验收页.html`，用自有简易网页服务器 `--本机 端口` 供此目录，复于实浏览器核其毕验之记与错误之录。

二〇二六年十月八日，完整 25a 与同配四器实构皆成，包检亦过。实 Chrome 页显上述毕验之文，错误与警告之录皆空；服务收百三十而退，验页亦闭。客体与诸器之确摘要，见所验库《实施记录》。
