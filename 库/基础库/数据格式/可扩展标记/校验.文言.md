# 内文档类型之校

`校验文档` 受 XML 字符串，读其内文档类型之宣，返校过之根。校所据者，实体既展、默认属既置、属中空白既整之节点树也。

内容模具 EMPTY、ANY、杂文、元素次序、选择及 `?`、`*`、`+`。属之校具宣名、必需值、定值、列举、名称词法、标识唯一与标识所引。ENTITY 属引未析实体，NOTATION 属引已宣记法。

内容模之确定以位置自动机校之：诸名各见之位皆独号，初集与诸位后继集皆校原名之争。默认名域之本地校例皆过综合构建与运行。EMPTY 原文词法之校具注、处理令、实体引及空 CDATA；元素内容模别直接字符引与实体替代之文。完整 W3C 有效全约之验，列后验之事。
