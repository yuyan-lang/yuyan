# 路径查询之子集

`查询` 篇行 XPath 1.0 位置路径之子集。`查询路径` 受根元素与式，还路径节点之列；`查询路径带命名空间` 兼受查询前缀与命名地址之成对列。路径节点别文档、树节、属性，携身份之径与在域命名表。`路径计数`、`路径布尔`、`路径结果串值` 化节点之集；`路径串值` 取一节之串值。

路径受绝对、相对之式、`/`、`//`、`.`，及 `child`、`descendant`、`descendant-or-self`、`self`、`attribute` 诸轴。`@` 为属性轴之略。节点测试受限定名、`*`、`前缀:*`、`node()`、`text()`、`comment()`、`processing-instruction()`。

名测、通配测循轴之主类：属性轴择属性，余已受诸轴择元素；`node()` 等类测循实节之类。属性、文本、注释、处理指令各存己之串值，元素与文档之串值依文档之次合后代文本。

谓词受正整数之位、`last()`、`position()=整数`、`position()=last()`、属性或子节之存在、属性或子节串值之等、`text()` 与今节 `.` 串值之等。等号右辞以单引或双引括之。诸谓词循次施行，每施则复计位置。`//项[1]` 于诸父之子轴各取首项，`/descendant::项[1]` 于众后代取首项。

无前缀之名测匹配空命名空间。查询前缀循所授之表，树节之名循承继之宣。属性轴去命名声明。相邻文本、CDATA 文本合为一路径文本节，空者去，注释与处理指令断之。

表达式至多百万字，路径树节至多百万层，每次后代遍历至多亿节。以身份之径去重、复文档之次，同元之属性循实现所定之次。位置谓词各父施之，乃合其果。

后版待办：父轴、祖先轴、兄弟轴、命名空间轴、集合并集、变量、通用布尔与算术式、通用函数库、嵌套谓词、具目标之处理指令测试。

所据：[W3C XPath 1.0](https://www.w3.org/TR/1999/REC-xpath-19991116/)，第二章位置路径、第五章数据模型。查询之口与本地验例皆过综合构建及运行之验。
