# XML 1.0 原名入口

`原名解析 文本` 返回既有 `标记节点`；`原名开始拉取 文本` 返回既有 `标记拉取器`，由 `拉取下一` 逐事件推进。默认导入的 `解析` 与 `拉取` 模块同时导出这些入口。

原名入口采用 XML 1.0 第五版的 Name 词法，保留名称中的冒号，按原始名称核开始和结束标签。`xmlns` 及带冒号的属性按普通 XML 属性保存。字符、行尾、声明、内部 DTD、实体展开限额与默认禁用外部实体规则共用原实现。字节输入可以先经 `解码标记输入` 转为文本。

`解析`、`解析带声明`、`开始拉取` 继续采用现有命名空间语义。拉取事件类型与旧 `拉取状态` 字段保持原样，原名模式由 `原名状态` 包装并在每次推进后保存。

`测试/原名入口。测试。豫` 包含两个基本输入：多冒号空根可解析并拉取至结束，开始和结束原名失配会拒绝。默认 CI 自动发现该入口。原名完整官方、百万及各后端长验按用户要求延期。
