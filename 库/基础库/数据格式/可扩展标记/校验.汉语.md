# 内部文档类型校验

`校验文档` 接受 XML 字符串，读取内部文档类型声明并返回通过校验的根节点。校验使用展开实体、默认属性和属性空白规整后的节点树。

内容模型支持 EMPTY、ANY、混合内容、元素顺序、选择以及 `?`、`*`、`+`。属性校验包含声明、必需值、固定值、枚举、名称词法、标识唯一性与标识引用。ENTITY 属性引用未解析实体，NOTATION 属性引用声明记法。

内容模型确定性通过位置自动机检查：每次名称出现都有独立位置，起始集合与各位置后继集合按原名称检查冲突。默认命名空间模式的本地校验向量已通过综合构建和运行。EMPTY 的原始词法检查覆盖注释、处理指令、实体引用与空 CDATA；元素内容模型区分直接字符引用与实体替代文字。完整 W3C 有效性约束核验列为后续验收事项。
