# DTD 内容模型

`内容模型解析` 接收 XML 1.0 的元素内容声明正文，返回内容模型 AST。支持 `EMPTY`、`ANY`、`(#PCDATA)`、`(#PCDATA|名称…)*`，以及元素名、顺序、选择、嵌套分组和 `?`、`*`、`+`。同一分组的逗号与竖线分隔符保持一致，混合内容的元素名保持唯一。

`内容匹配` 接收模型和全部子元素名称序列，返回匹配结果。匹配采用正则导数，消费完序列后判断剩余模型可空。重复模型即使包含可空项，也由输入元素驱动推进。构造导数时简化失败、空串和重复选择项。`模型许文字` 对 `ANY` 和混合内容返回真；`模型为空` 对 `EMPTY` 返回真。文本、空白文本、注释与处理指令由树校验层分别处理。

模型正文和层数上限为一百万，展开 AST 上限为一百万节点，匹配累计模型访问预算为一亿。元素名按声明中的限定名字面匹配。DTD 的声明收集、属性类型、ID/引用和确定性约束由整体校验层处理。

依据：[XML 1.0 第五版](https://www.w3.org/TR/2008/REC-xml-20081126/)，3.2.1 与 3.2.2 节。当前只完成编辑与轻格式化，类型和运行验证等待统一调度。
