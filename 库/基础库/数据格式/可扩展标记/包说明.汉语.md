# 可扩展标记

包提供 XML 文档树、预定义实体转义、属性与节点写出，以及递归解析入口。树保留元素限定名称、属性次序、文本、CDATA 文本、注释与处理指令。

`解析` 接收字符串，返回根元素；解析事故标明截断、属性与结束标签问题。`写出` 返回紧凑 XML。`文本转义`、`属性转义` 可用于直接生成格式化文档。

解析器按 XML 1.0 第五版的名字范围检查统一码码点，严格校验 UTF-8、合法 XML 字符与十进制或十六进制字符引用，规范化行尾和属性空白。命名空间校验覆盖声明、继承、限定名、保留地址、未绑定前缀与重复扩展属性名。文档首部声明、外围注释和处理指令可以解析。

内部 DTD 与实体展开限额、编码转换、流式拉取、缩进写出、XPath 子集及 DTD 校验具有实现与独立向量，已通过默认命名空间模式的六组综合短测。W3C xmlconf 一致性、百万变异及 RSS 为后续验收事项，甲乙级结果由真实验证记录更新。

`测试/综合。测试。豫` 合并标记、字节、查询、内容模型、校验和差分六组短测。版本声明语义见双语《版本声明》，实际验证状态见《实施记录》。
