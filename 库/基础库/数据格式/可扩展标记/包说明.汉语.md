# 可扩展标记

包提供 XML 文档树、预定义实体转义、属性与节点写出，以及递归解析入口。树保留元素限定名称、属性次序、文本、CDATA 文本、注释与处理指令。

`解析` 接收字符串，返回根元素；解析事故标明截断、属性与结束标签问题。`写出` 返回紧凑 XML。`文本转义`、`属性转义` 可用于直接生成格式化文档。

解析器按 XML 1.0 第五版的名字范围检查统一码码点，严格校验 UTF-8、合法 XML 字符与十进制或十六进制字符引用，规范化行尾和属性空白。命名空间校验覆盖声明、继承、限定名、保留地址、未绑定前缀与重复扩展属性名。文档首部声明、外围注释和处理指令可以解析。

文档树与拉取入口共享文档处理指令、实体和记法的无冒号名字检查，逐输入差分回归覆盖官方实体位置与预定义实体样本。

名字检查同时覆盖展开正文、参数实体生成声明、未使用的 DTD 元素/属性与内容模型限定名、NDATA 记法引用及 NOTATION 候选本名。内部 DTD 处理指令保存在辅助资料中用于名称检查；普通枚举值继续采用 NMTOKEN 词法。十三项补强向量及官方当前范围复跑通过。

库测试依赖正式基础库测试设施，以五参数父程序隔离变异批次。字节解码、原字节文档树与拉取已各执行一百万编号调用，正常完成且差分一致；当前单点翻位、删除、插入与替换策略具有有限周期，样本字节内容可以重复。写出只在接受分支核往返，调用数按实际分支记录；RSS、其余入口与原生模糊验收持续实施。

六组综合短测和上述官方适用范围已在诺节与同源硬浮原生通过，官方双端计数同为 1718 通过、零失败、867 另列。

变异驱动已补齐字节解析两个入口，使用合法内部 DTD 与 ID 种子并先核原种；字节解码、字符串解析、字符串拉取、字节解析及字节拉取各一百万编号调用通过。五入口逐输入接受差分和接受后的写出往返已核。

六组综合向量已通过真实 Chrome 抽样，纯豫薄应用在全部初始化断言后写入页面完成标记，错误与警告日志为空。浏览器测试应用及静态页面位于 `测试/浏览器`。

独立查询与 DTD 模糊入口各先核合法原种，再用正式批隔离执行百万编号输入。查询普通与显式命名空间两个入口每编号均调用，接受后核结果身份、去重、计数与串值的重复确定性；DTD 每编号调用校验，接受后核写出往返。三入口首次调用数各达百万，正常结束。
