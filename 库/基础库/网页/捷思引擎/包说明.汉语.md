# 捷思引擎

版本：0.1.0。

纯豫言捷思引擎属于网页基础库。当前词法入口覆盖统一码标识符及转义、私有名、整数与小数、进制前缀、数字分隔符、大整数、字符串、注释、散列行、模板分段、正则与操作符。

`捷思新扫描器` 接受源码字符串，`捷思下一词` 接受扫描器和是否容许正则的词法目标。解析器在表达式首采用容正则目标，在除法位置采用普通目标。模板头消费 `${`，解析器读完插值的 `}` 后调用 `捷思续模板`，返回模板中段或尾段。

词元保存种类、原文、文字码元列、起止位置和前置换行。位置按豫言字符计数，区间左闭右开；文字以十六位码元保存，统一码转义保留孤立代理项。原文可供数值转换、关键字及转义早期错误检查。

`捷思解析表达式` 接受完整表达式源码，返回递归语法树。`捷思新解析器` 与 `捷思读表达式` 提供增量解析入口，后者接受最低运算级。语法节点保存种类、来源词元和子节点，查询由 `捷思语法种类`、`捷思语法词` 与 `捷思语法子` 提供。

表达式支持字面量、名称、括号、前后置运算、二元优先级、右结合赋值与乘方、条件、调用与成员访问、可选链、数组孔位与展开、对象简写与计算键、模板插值和标签模板。正则目标在表达式首启用，除法采用普通目标。

`捷思解析脚本` 返回脚本语法树，`捷思读语句` 提供增量语句入口。声明、块、分支、普通循环及属性和值遍历、后验循环、跳转、标签、选择、对象环境、调试和异常捕获终结接通；函数及生成器声明保存名称、参数与句体，参数支持默认值和剩余参数。换行、块尾及文件尾参与自动分号。

普通、生成器、异步及异步生成器函数支持声明和表达式，箭头支持单参数、括号参数、默认值和剩余参数；等待、生成、委托生成及异步值遍历保留语法节点。增量表达式解析可用 `捷思设置读句` 设置句体读取回调，完整表达式和脚本入口自动接通句体。

类声明和类表达式保存名称、父类与成员。成员支持普通及计算键、私有键、字段初值、静态成员与静态块、构造器、取值器和设值器、普通及生成器与异步方法；方法保存参数与句体。

`捷思解析模块` 返回模块树，保存副作用、默认、具名与命名空间导入，以及默认、声明、具名与全体导出；转导出保存来源，导入属性保存键值。动态导入、模块元信息访问与顶层等待沿用表达式树。

对象字面量支持方法、访问器、生成器、异步及异步生成方法，成员键与句体和类共用读取入口。对象模式支持简写默认值；嵌套数组与对象、孔位及剩余项可用于声明、参数与赋值。

脚本基础值包含未定义、空值、布尔、双精度数值和字符串，提供真值转换与严格相等。脚本文字以十六位码元计数，拉丁一和宽叶分别保存一字节与两字节码元；拼接保存绳节点，展开码元时缓存结果。宿主字符串转换为码元，补充平面字符占两项，孤立代理项原样保存。

普通对象具有独立身份、有序自有属性、原型与可扩展状态；属性保存键、值及可写、可枚举、可配置标志。入口提供创建、定义、自有查询、原型链读取、删除和阻止扩展，对象参与真值与严格身份比较。

`捷思编表达` 把基础字面量、括号、一元正负与逻辑非、四则与关系和严格比较、条件及逻辑短路编成栈指令。数值字面量经数值格式解析。`捷思新帧` 保存剩余指令、值栈、步数与宿主指定步限，`捷思步进` 推进一步，`捷思运行帧` 恢复并运行至末尾；`捷思执行表达式` 采用十亿默认步限。

模块链接执行、完整语句与函数执行、词法环境、异常表、完整对象内部方法及标准内建对象继续实施。完整值转换、进制与分隔符数值、解构目标与上下文及绑定早期错误、附录乙八进制转义、标签模板无效转义、严格模式及正则字符类目标细分继续实施。
