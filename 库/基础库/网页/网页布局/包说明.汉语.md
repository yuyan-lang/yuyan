# 网页布局

单元格的指定高度转换为最低高度，最终自动高度填满行或跨行区域。`vertical-align` 的顶部、居中和底部接入内容几何：排布后测流内子盒的底端，按剩余内容高度平移子树，格边框位置保持所在行。基线、长度值、逻辑方向与完整盒尺寸换算继续实施。

表格标题按 `caption-side` 分别排在表体上方与下方，高度计入外层表格。列与列组宽度、`span` 属性接入列宽约束，列的自动宽度采用所在列组的宽度；固定布局优先使用列宽，自动布局与单元格内在约束合并。自动宽度表格用列内在尺寸、间距和标题求收缩包裹宽度，单元格最终填满分配区域。标题外边距、列组背景几何与完整宽度约束继续实施。

`table` 与 `inline-table` 接通表格排布，递归收集表头、表体和表尾行组，单元格按跨行占用选择空列。`colspan`、`rowspan` 转换为二维区域，零行跨度延伸到已收集行的末端。固定布局读取首行指定宽度，未定列分配余量；自动布局按单元格内在最小最大宽度分配列宽，跨列贡献按列数分摊。分离边框间距进入轨间和外侧几何，合并边框采用零间距。行与行组更新包围矩形。标题、列组、匿名盒、合并边框冲突、垂直对齐、自动表宽与完整尺寸约束继续实施。

列向自动流接通 `column` 与 `column dense`。放置规划交换两轴复用占用算法，再把项目区域转换回正常坐标；项目先填满行轴，再扩展下一列。规划后的列数决定隐式列轨数量，行线的负序号先按原显式行数固定，区域行数计入网格范围。逻辑方向、起点之前的隐式轨道与完整放置阶段继续实施。

逐行自动流接通 `dense` 回填，每个自动项目从首格重新寻找连续空区域。超出显式列的数字起止线、项目跨度及区域列范围扩展列轨，新增列按 `grid-auto-columns` 序列循环取轨，比例轨参与统一余量分配；负列线先按原显式列数固定位置。列向流、网格起点之前的隐式轨、定行自动列增长和完整放置优先序继续实施。

命名放置接通 `grid-template-areas`：字符串行划分区域单元，同名区域累计行列边界，区域名称及派生的 `-start`、`-end` 线转换为数字起止线。显式轨道的方括号命名线支持同线多名、重复出现、正负序号和整数重复中的线名。解析后的项目复用二维占用、跨格对齐及拉伸。区域有效性、命名跨度、自动重复和隐式命名线继续实施。

数字行线与行跨度接入二维放置。具有显式行的项目先登记占用，自动项目查找连续的空格区域，跨行占用覆盖全部行列范围；完全显式的项目允许共享区域。最终跨行高度合计所覆盖行轨与内部间隙，内容超过轨道总高时按跨行数分配增量。命名线和区域、完整放置顺序、密集回填、隐式列扩展及轨道增长约束继续实施。

数字列起止线与 `span` 列跨度接入几何排布，负线号从显式网格末端计数。稀疏逐行放置检查已有项目占用，自动项目选择连续空列；跨列区域宽度包含各轨尺寸与内部间隙，项目对齐和拉伸使用整个区域。显式行、行跨度、命名线和区域、密集回填、隐式列扩展与完整放置顺序继续实施。

隐式行采用 `grid-auto-rows` 的尺寸序列，超出显式行后循环读取各项，固定下限参与行高与自动高度计算。显式列为空时，首条隐式列采用 `grid-auto-columns`，默认自动轨继续分配容器宽度。隐式列扩展与尺寸循环、隐式比例轨的统一分配继续实施。

重复轨道接通 `auto-fill` 和 `auto-fit`。自动重复按可用轴长、重复轨道的固定下限与间隙计算可容纳的组数，零下限按1像素计数；比例份继续分配余量。自动适配按流内项目数缩减末尾空重复组，让有内容的轨道填满区域；未定高度的行轴采用一组。自动重复与其他轨道组合、空网格全部折叠和跨度占用判定继续完善。

网格整体接通 `justify-content` 和 `align-content` 的起点、末端、居中及三种空间分配。固定轨道与间隙占用之外的剩余空间用于偏移轨道组或扩大轨道间隔，最终格区域重新排布项目。显式行数超过已放置的行数时补空行，其轨道高度与间隙计入自然总高度；自动高度容器采用自然总高度。自动轨道的内容拉伸与完整内在尺寸分配继续实施。

网格项目接通两轴的 `justify-items`、`align-items` 和单项覆盖，支持起点、末端、居中与自动尺寸拉伸。每行先测自然高度，再按最终行高重新布局项目，自动高度项目填满格高。自动外边距优先分配正剩余空间，具有自动边的轴保留自然尺寸；非拉伸自动宽度使用内在最大宽度。对齐位移同步盒和子树片段矩形。基线、安全对齐、逻辑方向、替代项目的拉伸例外及边框盒换算继续完善。

「网格」默认导入。`grid` 与 `inline-grid` 接通网格排布，显式列轨接受长度、百分比、比例份、整数 `repeat()` 与基础 `minmax()`；方括号命名线在轨道计数时略过。轨道扣除固定尺寸和间隙后按份分配空间，自动列采用等份。项目按稳定次序逐行放置，宽度自动的项目填满格宽并计入固定外边距；每行由项目自然高度和指定行轨决定高度，行间隙计入父盒自动高度。脱流盒由定位遍历排布。内在轨道约束、有限最大轨、自动重复、显式放置和跨度、命名线与区域、隐式轨道属性、列向和密集流、对齐与高度拉伸继续实施。

绝对定位的包含区域采用定位祖先的内边距边界。「网页盒内边矩形」从边框矩形扣除四边边框，返回包含内容和内边距的区域；边框厚度计算与块流共用。定位布局将完整包含宽高传给块布局，百分比尺寸和内外边距使用此基准，自动宽度继续使用扣除左右偏移后的可用区域。固定定位沿用视口区域。行内定位祖先的分片包含块与字体相对边框厚度继续完善。

绝对与固定定位的自动宽度在左右偏移有自动边时采用收缩包裹计算，`inline-block` 自动宽度复用同一入口。内容宽取最小内容宽与可用宽的较大值，再以最大内容宽为上限；边框和内边距随后计入边框矩形。左右偏移均指定的定位盒保持剩余空间拉伸。「测网页内容内在宽度」测量盒自身内容，并排除其脱流子盒；「测网页内在宽度」还排除脱流盒自身。文字盒按流内内容处理，定位由所属元素盒统一承担。计算参考[层叠样式2.2的绝对定位宽度](https://www.w3.org/TR/CSS22/visudet.html#abs-non-replaced-width)。内在测量的完整规则继续实施。

「内在」默认导入。「测网页内在宽度」返回最小与最大内容宽度，文字复用测量器和统一码断行片段，行内内容累计宽度，块内容取最大宽度，并计入已指定宽度与水平内边距。横向弹性自动宽度项目采用最大内容宽度作为自动基准，分行沿用同一测量入口。跨片不可断序列、硬换行、内在百分比、边框与替代元素内在尺寸继续完善。

弹性交叉轴固定外边距计入项目外部尺寸、自然行高与行间分配；拉伸先扣除两侧固定边，对齐和自动边分配剩余空间后再加入前侧边。临时块样式清除外边距，由弹性布局统一放置项目。

弹性项目主轴固定外边距计入空间分配、前后游标及换行判断，百分比外边距按容器宽度计算。项目的临时块样式清除主轴外边距，由弹性游标统一放置；交叉轴固定外边距继续完善。

弹性主轴分配接入最小、最大尺寸冻结：约束改变项目尺寸后固定该项目，将剩余空间重新分配给其他项目。最终剩余空间用于自动外边距与内容对齐。约束的内容盒与边框盒换算、混合上下约束违例的精确冻结顺序继续完善。

弹性交叉轴自动外边距优先于项目对齐：前侧自动边取得全部正剩余空间，两侧自动边均分空间，后侧自动边保留起点。具有交叉轴自动边的项目保留自身尺寸，停止自动拉伸。

弹性主轴自动外边距在增长与收缩之后均分正剩余空间，优先于主轴内容对齐。项目排布采用方向对应的前后边，自动边在块布局的临时样式中置零，几何仍记录到原盒引用。

多行弹性接入 `align-content` 的起点、末端、居中、三种空间分配及拉伸。指定交叉区域的剩余空间分配到行间或各行尺寸，项目按各行的新区域重新对齐，随后处理反向换行。

`wrap-reverse` 将行和项目映射到反向交叉轴，并同步子树片段矩形。横向自动高度容器采用各行累计高度，指定高度容器采用内容高度作为映射区域。

弹性换行先按排序后的项目基准尺寸与主轴间隙分行，每行独立分配增长、收缩和主轴对齐空间。行间采用交叉轴间隙，横向多行高度累计到父盒自动高度。行间对齐和纵向多列的交叉尺寸继续完善。

单行弹性交叉轴接入 `align-items` 与 `align-self`，支持起点、末端、居中及自动交叉尺寸拉伸。单项值覆盖容器值，位移同步项目子树的片段矩形；横向自动高度容器从各项目最大高度确定交叉区域。基线、安全对齐和自动外边距继续实施。

单行弹性主轴支持 `justify-content` 的起点、末端、居中、两端、环绕与均匀空间分配，分配间隔叠加指定的主轴间隙。反向主轴采用同一对齐游标；增长或收缩已经用尽的空间取零剩余对齐空间。

「弹性」默认导入。`flex` 与 `inline-flex` 接入单行弹性排布，支持行列方向、反向、稳定的 `order` 排序、主轴间隙、基准尺寸、按增长因子分配剩余空间和按基准尺寸加权收缩。各项目复用块布局处理内容与尺寸约束；父盒从排布结果取得自动高度。多行、对齐、自动外边距、内在尺寸与约束冻结继续实施。

绝对与固定定位的自动高度在上下偏移同时指定时填满剩余空间，并计入垂直外边距、边框、内边距及最小最大高度约束。

「定位」默认导入。布局先排普通流，再处理定位盒；相对定位平移盒与子树并保留流内占位，绝对定位采用最近定位祖先的包含区域，固定定位采用视口区域。左右、上下偏移支持长度与百分比，右边和下边可以锚定指定尺寸的盒。脱流盒单独排布，节点片段矩形同步平移。后续完善自动高度双边拉伸、收缩包裹宽度、静态位置、内边距包含块、粘滞定位及变换包含块。

「行内」默认导入。「布局网页行内」将相邻文字和嵌套行内元素放在连续横向游标上，按统一码断行机会分片测量并换行，处理换行元素与原子行内盒。文字和祖先行内盒登记每行片段矩形；块流在行内组与块盒之间切换，并将行内高度计入自动高度。真实系统字体冒烟核验相邻元素连续排布和跨行客户矩形。跨片整形、共同基线、垂直对齐、行首尾空白、文字硬换行及行内边框内边距继续实施。

「文字」默认导入。「排版网页文字」接受字体集合、数值环境、计算样式、正文、整形语言标签与可用宽度，返回字形库、规范文字、字号、行高、基线、定位字形行和行矩形。文字先按空白模式折叠或保留，再经统一码段落断行、双向处理及逐行整形；字体特性和可变轴由计算样式传入，连接上下文保持。行高接受无量纲倍数、长度与百分比，`normal` 使用字体度量。左右、居中、起止方向及两端对齐映射到行位置。字形坐标以六十四分之一像素计，已经加入基线与对齐偏移，行矩形采用像素。

「网页字体测量器」把该结果的尺寸接入「布局网页」。字体选择保存稳定来源键并按来源合并字体链，码点缓存固定每个码点的选字结果。加载器提供所需字体后，可重新排版。真实系统字体经现有发行适配实跑，原布局集成入口继续通过。

文字规则参考[文字模块三级，2026-08-14](https://www.w3.org/TR/2026/CRD-css-text-3-20260814/)。完整混合样式行内排版、首尾空白裁剪、字距词距、异步字体重排、竖排与分数字号继续实施。

「网页边框宽」计算指定边的布局厚度：线型为 `none` 或 `hidden` 时取零，`thin`、`medium`、`thick` 依次取1、3、5像素，其余长度按数值环境计算。块流将四边厚度与内边距一起计入内容偏移、自动宽度、尺寸约束及 `box-sizing` 换算。

版本：0.1.0。

盒生成参考[显示模块三级](https://www.w3.org/TR/css-display-3/#box-generation)，块宽计算参考[层叠样式2.2的宽度与外边距](https://www.w3.org/TR/CSS22/visudet.html#blockwidth)。这些入口现提供基础块流；各布局模块的完整规则按提案继续接入。

「生成网页盒树」接受样式读取器和文档根，构造引用保存的子盒与几何数据。元素采用计算样式的显示值，隐藏子树在构造时裁剪，`display:contents` 将子盒接入上一层。文字保存原节点与父样式。文档与片段生成块包装，视口盒保存布局范围。

「布局网页」接文字测量器、数值环境、盒树和视口宽高。基础块流计算自动宽度、左右自动外边距、内边距、内容盒与边框盒尺寸、最小与最大宽高、相邻块外边距折叠，以及子流决定的自动高度。百分比外边距与内边距使用包含块宽度。文字测量器返回给定可用宽度下的文字尺寸，调用者将其连接到文字排版。

「网页盒边框矩形」「网页盒内容矩形」返回单盒几何。「网页节点诸盒」按稳定节点身份查找盒；「网页节点客户矩形」返回片段矩形，「网页节点包围矩形」合并这些矩形。布局写入引用，并清除已排盒的脏位。文档变更后可重新生成盒树并布局。

后续实施：真实行内行盒、父子与空块外边距折叠、浮动与清除、定位、弹性、网格、表格、替代元素、伪元素、逻辑轴、滚动尺寸与增量约束缓存。自动高度包含块的百分比判定、继承字号换算和视口坐标变换继续完善。一个布局集成冒烟检查盒树裁剪与展平、自动居中、边框盒及内容盒尺寸、尺寸约束和相邻块外边距。
