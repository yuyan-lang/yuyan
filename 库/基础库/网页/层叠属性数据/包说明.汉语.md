# 层叠属性数据

登记动画八项、过渡五项长写及对应简写目标；登记 `columns`、`place-items` 展开目标和分栏初值。`text-align-last` 初值为 `auto`，沿父元素继承；计数器三属性初值为 `none`，`user-select` 初值为 `auto`，均采用非继承行为。

字体简写登记十九个长写目标，包含字距、字号调整、特性与变体等十二项重置属性，供含变量的字体简写延迟展开。`font-size-adjust` 初值为 `none`，`font-language-override` 初值为 `normal`，均沿父元素继承。

登记背景附件、原点与裁剪，初值分别为 `scroll`、`padding-box`、`border-box`，采用非继承行为；简写表登记 `background` 的八个长写目标，供变量延迟展开与级联重置使用。

登记非继承属性 `mix-blend-mode`，初值为 `normal`，供绘制组选择混合算法。

登记继承属性 `pointer-events`，初值为 `auto`，供网页命中测试读取。

登记 `aspect-ratio`、`object-fit`、`object-position`，初值分别为 `auto`、`fill`、`50% 50%`，均采用非继承行为。

登记表格布局、边框合并与间距、标题侧和垂直对齐的初值及继承行为，供级联和布局使用。

登记网格行列起止长写和 `grid-template-areas`，初值分别采用 `auto` 与 `none`；简写表登记 `grid-column`、`grid-row`、`grid-area` 的展开目标。

登记 `grid-auto-columns` 与 `grid-auto-rows`，初值为 `auto`，均取非继承属性，供隐式网格轨道尺寸使用。

登记 `justify-items` 与 `justify-self`，初值分别为 `normal` 和 `auto`，均取非继承属性，供网格项目横向对齐使用。

登记四边边框宽度、线型、颜色及边框图像各长写的初值和继承标志；简写表列出整体、单边和四边分量的展开目标。

版本：0.1.0。

「层叠颜色表」返回全部148项不透明命名颜色及六位十六进制值，名称采用小写；另有14项浅色方案的系统颜色（`canvas`、`canvastext`、`linktext`、`visitedtext`、`activetext`、`buttonface`、`buttontext`、`field`、`fieldtext`、`highlight`、`highlighttext`、`graytext`、`mark`、`marktext`），`canvastext` 即初始文字色黑色。数据依据[颜色4命名颜色表，2026-10-09](https://www.w3.org/TR/2026/CRD-css-color-4-20261009/#named-colors)。

「层叠属性表」返回属性名、初值和继承标志；「层叠简写表」返回简写及展开的长写名称。数据由层叠样式库用于级联与默认值计算。

本版登记静态文档常用的文字、盒、背景、定位、弹性盒与网格属性。数值与颜色验证、其余属性及完整简写留待后续。取值依据万维网联盟的层叠样式各模块，数据以豫言项目许可提供。
