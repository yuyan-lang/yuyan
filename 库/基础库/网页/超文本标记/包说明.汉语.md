# 超文本标记

版本：0.1.0。

本包提供独立于文档树表示的词元类型、词法分析器与树建造器接口。树接口导出「树建造器」「构树」，整页构树在「文档构树」模块。使用者提供节点创建、插入、父子查询、名称、命名空间与属性操作，节点以正整数句柄表示，零表示空位置。「新构树」与「构树词元」接收词元；「新文档构树」「文档构树词元」补出全文、头与身的基本结构。现有构树处理空元素、常见段落与列表项的隐式闭合、外来命名空间。

表格构树补出隐式表身、行和列组；新增行、单元、表头与表尾会收拢相应开放元素。表容器中的非空白文字和普通元素寄养到表前。描述列表项、标题、选项和选项组支持省略闭合。

词法分析按[网超组超文本标记现行标准](https://html.spec.whatwg.org/multipage/parsing.html)“分词”一节的七十九个状态逐态实现，直接在八位统一码字节上工作，停表整段扫过各状态的“其他字符”，支持增量输入与挂起。默认导入「词元」「串建」「字符引用」「词法」「词法驱动」。词元包括文字、空字、开始标签、结束标签、注释、文档类型与输入结束；开始标签的属性保持源码次序、重名只留第一个；文档类型词元带名称与两个标识，并区分“缺失”和“空串”。

「新词法器」按整段源码创建词法器，「新增量词法器」创建尚无输入的词法器；「追加词法输入」提交一块，「结束词法输入」标记输入结束，「取词元们」取出已经完整的词元，输入全部处理完后得到空列表，最后一个词元是输入结束。树构造按标准切换词法状态时使用「切到可替换数据」「切到原始文本」「切到脚本数据」「切到纯文本」「设最后开始标签名」与「设允许外来」。「拆词元」把整段源码一次拆成词元列表，相邻的文字合并成一个文字词元，空字符换成替换字符；它供只看词元的使用者（如文档导入）。

脚本、样式及其他原始文本标签保留其中的尖括号和字符引用；标题与文本框解码字符引用。命名引用使用最长匹配，属性中的历史无分号引用按后继字符判断。数字引用支持十进制和十六进制，代理、空码、越界码替换，旧西文控制引用按标准映射。

命名引用表含 2,231 项，由[网超组官方数据](https://html.spec.whatwg.org/entities.json)生成。锁定下载日期为 2026-10-11，原表沙256为 `d741d877ac77c4194c4ad526b5b4a19aef8dfe411ab840a466891cdbb9f362e6`。数据版权属于网超组（苹果、谷歌、谋智、微软），并遵循[网超组出版许可](https://whatwg.org/ipr-policy#copyright-license-for-whatwg-publications)；标准内容纳入源码时采用三条款伯克利许可。生成命令：`网页一致性 字符引用 原始结森路径 命名引用表。豫`。

词法分析对照超文本5库测试的词法数据（`网页一致性 超文本词法 测试文件或目录`），词元通过 7016/7044；未通过的 28 项是已过时的旧式处理指令用例。树建造器、编码嗅探与官方测试版本锁定列入本任务后续实施，之后进行甲级与乙级验收。
