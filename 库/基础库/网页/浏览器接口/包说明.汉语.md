# 浏览器接口

`nodeType` 返回文档对象的节点类型编号。`documentElement` 取得文档的首个直接子元素，`head`、`body` 从根元素的直接子节点取得对应结构，`body` 同时识别框架集。缺失结构返回 `null`，所得节点共用包装身份。命名空间与节点品牌的完整限定留待后续版本。

`innerHTML` 实时序列化当前子节点，赋值复用文档片段解析并替换子节点。标记实体与注释沿已有解析和序列化处理，移出的节点保留包装身份。上下文片段解析、模板内容与完整转换规则留待后续版本。

`parentNode`、`previousSibling`、`nextSibling`、`firstChild` 与 `lastChild` 每次读取当前文档树，返回共用身份的节点包装，空关系返回 `null`。这些只读属性在节点插入、移动与移除后立即反映新关系。

`id` 与 `className` 实时映射节点的 `id`、`class` 属性，缺失属性读为空字符串。属性赋值与 `setAttribute`、`removeAttribute` 共用原文档状态，标识查询和选择器读取更新后的属性。

节点 `textContent` 使用宿主读写访问器。读取取得当前文档的文字内容，赋值调用文档对象的文本更新；后续树操作即时反映到下一次读取。节点种类对应的空值规则与完整文字转换留待后续版本。

`createDocumentFragment` 创建文档片段，片段追加到父节点时依次移动其子节点；`createComment` 创建注释。`normalize` 递归移除空文字，并将相邻文字合并到首个节点，复用文档对象的树更新与脏标记。

节点方法支持 `hasAttribute`、`contains`、`isSameNode`、`cloneNode`、`insertBefore` 和 `replaceChild`。克隆按实参决定是否复制后代并取得独立节点身份；插入复用文档的父子关系检查，替换返回原节点。包含与身份检查对空节点返回假。

`querySelectorAll` 返回按文档顺序保存的节点快照，当前用捷思数组提供下标、长度与值遍历，节点包装与单节点查询共用身份。`removeChild` 校验直接父子关系并返回被移除节点；`remove` 从原文档移除当前节点。完整节点列表对象与只读集合规则留待后续实施。

浏览器接口将豫言文档对象绑定到捷思页面环境，按网页标准的文档方法名称提供调用。节点包装按文档节点身份缓存，脚本对属性和树的修改直接作用于原文档。

`新浏览器文档绑定` 建立包装缓存，`封装浏览器节点` 包装节点，`绑定浏览器文档` 在指定捷思环境绑定 `document`。支持元素查询、选择器查询、元素与文字创建、属性读取与设置、属性移除和节点追加。

跟随 DOM Living Standard 的节点、元素和文档方法。属性访问器、事件、窗口能力、节点集合完整行为、品牌检查与安全策略留待后续实施。
