# 字体选取

版：0.1.0。标准定为[字体4，二零二六年九月十三日工作草案](https://www.w3.org/TR/2026/WD-css-fonts-4-20260913/)。

此包供字体族列、通用族映射、字宽字形字重之匹配、字体描述注册、码域筛选、按需载入、逐字回退及字体之度。

「收网页字面」读样式规则之 `@font-face`，存族、字重字宽之域、字形、码域、`src` 本地或远程来源、格式技术之提示及显示描述。「新网页字体集合」受本地数据源、远程字节之读取器；「注册网页字面」更注册表而清其藏。「网页选字」依所求之族链择码，按需读取、解析而藏字体，还字体及字形号；链末加无衬线、表情、符号之回退。远程地址之基址解析、安全之察及抓取，由所授读取器司之。

「网页系统字体源」复用操作系统字体接口，分段读系统字体。「样式字体请求」自计算样式取族、字重、字宽、字形。「网页字体取度量」依字号缩上升、下降、行距，读小字大字之高、零字水字之宽；「字体度量数值环境」接于样式长度单位之算。

后续之事：精确斜角及字宽小数、通用族依语言之设、系统同族多面之列、字簇回退、格式技术能力之筛、显示时序、特性变体之接、可变轴、度量覆盖、合成及调色板。集合藏解析之果及读败；字之请求果藏，续接之。

选字之验须由发行绑系统字体接口；常无绑定客体由全树测试验类。本机以既有诺节发行适配实跑本地字体。字面「身份」于同集内独一；一次收样式表则自分之。

| 标准成员 | 豫言成员 |
| --- | --- |
| font-family、font-weight、font-stretch、font-style | 网页字体请求之族列、字重、字宽、字形 |
| @font-face、src、unicode-range、font-display | 网页字面之来源、码域、显示及匹配描述 |
| ascent、descent、line-gap、x-height、cap-height | 网页字体度量之上升、下降、行距、小字高、大字高 |
