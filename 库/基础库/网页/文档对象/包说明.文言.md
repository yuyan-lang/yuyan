# 文档对象

版：0.1.0。

此包立可变文档节点，其身份恒存。文、属性、父子之属及脏志皆藏于豫言引用。用者持其节点，得见后改。

默认导入「样式接线」。「节点行内样式」析 `style` 属性，「文档样式规则」循前序取样式元素诸则，「文档外链样式」取样式链之址，授加载器取而析之。

默认导入「选择器接线」。「文档样式树视图」以节点身份供抽象查询；「节点匹配选择器」「最近选择器」「查询选择器」「查询选择器全部」对应 `matches`、`closest`、`querySelector`、`querySelectorAll`。查询循前序还恒定节点，范围根参与 `:scope` 之配。控件初态取诸属性，交互状态之接留于页面事件循环。

类序循网页文档对象。元素、文本、注、属性、处理之令、字符数据段、文档及片段皆有造术。虽移改再插，其身份恒存。

默认导入「节点」「树操作」「节点操作」「标记解析」「序列化」「遍历」。父子之改同步易引，片段之插依序移其子；插者察祖先之属，以存树之理。属性、树之改皆标祖先为脏。规范文字则去空文，邻文合于首。

「解析文档」补全文、头、身，合显式诸元之属性；「解析片段」立片段。二者皆循抽象建树器，以正整数为柄，零示空位。「外部标记」「内部标记」序列化、转义，原文径书之。查询循文档前序，深克隆则新立身份及引用。

| 网页之口 | 豫言之口 |
| --- | --- |
| parentNode、childNodes | 父节点、子节点 |
| previousSibling、nextSibling | 上一兄弟、下一兄弟 |
| append、prepend、insertBefore | 追加节点、前置节点、插入节点 |
| before、after、replaceWith | 节点前插、节点后插、节点替身 |
| replaceChild、removeChild、remove | 替换节点、移除子节点、移除节点 |
| contains、getRootNode、isSameNode | 含节点吗、根节点、同节点吗 |
| textContent、normalize | 文本内容、设文本内容、规范节点 |
| getAttribute、setAttribute、removeAttribute | 取属性、设属性、移除属性 |
| getElementById、getElementsByTagName | 按标识查询、按标签查询 |
| cloneNode | 克隆节点 |
| innerHTML、outerHTML | 内部标记、设内部标记、外部标记 |

「事件」「中止」「微任务」「观察」亦默认导入。事件循定父链，依序捕获、至目标、冒泡；监听可捕获、一次、被动，亦可系中止信号，以回调身份去重、移除。自定义事件存任意豫言值为详情。回调有异，录于任务诊断；微任务检查点循入队之序行。

中止控制器存首个理由，同步告善后；诸信号合者取先中止之信。事件循环以「推进中止时刻」供毫秒之刻，推超时信号。变更观察器察子节点、属性、文字、子树，可筛属性、存旧值；于微任务检查点成批投递，亦可径取记录、断开。

| 网页之口 | 豫言之口 |
| --- | --- |
| Event、CustomEvent | 新事件、新自定义事件 |
| addEventListener、removeEventListener、dispatchEvent | 添加事件监听、移除事件监听、派发事件 |
| stopPropagation、stopImmediatePropagation、preventDefault | 停止传播、立即停止传播、阻止默认动作 |
| AbortController、AbortSignal.any、AbortSignal.timeout | 新中止控制器、任一中止信号、超时中止信号 |
| queueMicrotask | 排微任务 |
| MutationObserver、observe、takeRecords、disconnect | 新变更观察器、观察节点、取变更记录、断开观察 |

后续有全树插入诸态、依上下文析片段、节点所属文档、范围及动集合、选择器、影子树、自定义元素及元素属性反射。事件之影子树重定向、界面事件专有之项，及观察记录之兄弟、移除子树之临时订阅，留于后续。接官测运行器时，锁标准及测试之版。

核验惟存一文档集成之口，兼核隐式全文之形、片段解析、恒定身份、移动、片段插入、深克隆及序列化。甲乙两级之验随提案进度录之。
