# 文档对象

版本：0.1.0。

本包提供带稳定身份的可变文档节点。节点的内容、属性、父子关系及脏位用豫言引用保存。使用者持有节点后，可观察后续修改。

节点种类采用网页文档对象的编号。元素、文本、注释、属性、处理指令、字符数据段、文档与片段由相应构造函数创建。节点身份在移动、修改和重新插入后保持。

默认导入「节点」「树操作」「节点操作」「标记解析」「序列化」「遍历」。父子操作同步更新引用，片段插入依次移动其子节点；插入检查祖先关系以维持树结构。属性修改与树修改把祖先链标为脏。文字规范化移除空文字，并将相邻文字合入首节点。

「解析文档」补出全文、头与身元素，合并显式元素属性；「解析片段」创建片段。两者都经抽象树建造器，以正整数句柄表示节点，零表示空位置。「外部标记」「内部标记」进行标记序列化与转义；原始文本直接写出。查询按文档前序遍历，深克隆创建新的身份与可变引用。

| 网页接口 | 豫言入口 |
| --- | --- |
| parentNode、childNodes | 父节点、子节点 |
| previousSibling、nextSibling | 上一兄弟、下一兄弟 |
| append、prepend、insertBefore | 追加节点、前置节点、插入节点 |
| before、after、replaceWith | 节点前插、节点后插、节点替身 |
| replaceChild、removeChild、remove | 替换节点、移除子节点、移除节点 |
| contains、getRootNode、isSameNode | 含节点吗、根节点、同节点吗 |
| textContent、normalize | 文本内容、设文本内容、规范节点 |
| getAttribute、setAttribute、removeAttribute | 取属性、设属性、移除属性 |
| getElementById、getElementsByTagName | 按标识查询、按标签查询 |
| cloneNode | 克隆节点 |
| innerHTML、outerHTML | 内部标记、设内部标记、外部标记 |

后续实施包括完整树插入模式、上下文片段解析、节点所属文档、范围与动态集合、选择器、事件、观察、影子树、自定义元素及元素属性反射。标准与官方测试版本在一致性运行器接入时锁定。

验证保留一个文档集成冒烟入口，覆盖隐式全文结构、片段解析、稳定身份、移动、片段插入、深克隆与序列化。甲级与乙级验收随提案进度登记。
