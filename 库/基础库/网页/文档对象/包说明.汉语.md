# 文档对象

选择器状态接通字段集禁用继承和首图例子树豁免，选项沿选项组承接禁用。只读与可写状态结合文本控件、只读属性、禁用和可编辑继承；占位提示读取即时空值，默认态读取选项及勾选控件的默认属性，未定态识别缺值的进度元素。空节点判定计入字符数据段。

「表单控件活动序」与「设表单控件活动序」保存选择控件的活动项序号，复原回到零。多选控件逐项显示活动标记、勾选标记与文字，即时选态继续供提交使用。

复原与文档清理删除同一节点的全部即时记录，恢复默认属性及默认文本内容。

「设控件预编辑」保存可选的显示覆盖，「表单控件编辑显示值」读取覆盖或实时值；提交仍读取「表单控件值」。复原清理显示覆盖，密码遮蔽在显示值上进行。

表单控件实时值与选中状态按节点身份保存，输入默认属性和文本域默认内容保留。`表单控件值`、`设表单控件值`、`表单控件已选`、`设表单控件已选` 供显示、交互与提交共同读取；复原与文档清理删除即时覆盖，`:checked` 消费即时选态。用户代理样式提供输入、文本域、选择及按钮的基本尺寸、边框和背景，隐藏输入按显示规则处理。类型专用规整、完整脏标记、精细控件主题及自定义表单元素继续实施。

「文档用户代理样式」提供默认块元素（含 `details`、`address`、`legend` 等）、隐藏元数据（含 `noscript`，按已启用脚本的浏览器处理）、标题、列表及表格显示规则。「文档求样式」与「载入文档节点样式」先加入该来源，再加入页面来源，页面声明按级联覆盖默认值。显式来源计算入口由调用者选择是否加入该来源。`a[href]` 取蓝色并加下划线，`summary` 是内标记的列表项（`details[open]` 里为向下箭头，否则为向右箭头）。输入框与下拉框只指定宽度，高度取自然高度。控件主题、链接状态、替代元素尺寸和其余默认样式随后补齐。

版本：0.1.0。

「样式载入」默认导入。「载入样式来源」接读取器、条件环境、样式基址与正文，展开外部导入。「载入文档样式」按文档顺序读取样式元素及样式链接，筛选节点的媒体条件，跳过禁用链接，并以外部资源最终地址作为嵌套导入基址。「载入文档节点样式」将这些来源接入节点的级联和继承计算。替代样式表选择、链接关系的完整空白分词、内容类型及加载状态事件随后补齐。

「样式引擎」默认导入。「文档样式读取器」接条件环境、文档根节点与样式来源，一次建好这份文档的样式表，返回读取记录；记录里的「读取」按节点给出计算样式。「文档默认样式读取器」使用与「文档求样式」同一套来源（用户代理样式加页面里的样式元素）。建表时来源只装配一次，每条规则的选择器分支预先拆好段、算好特异性，再按最右复合选择器的标识、类、标签建索引，树视图建一次；读取节点样式时只检验索引命中的分支，元素的计算样式按文档序缓存，子元素直接取缓存里的父样式。每个元素的结果与「带条件计算节点样式」逐属性相同；表外的节点（非元素或不在建表子树里）转交「带条件计算节点样式」。文档变动后由调用者重新建表。「渲染网页文档」与「载入静态网页」使用这个读取器。「文档样式树视图」一次遍历把整棵树登记进数组（下标是节点身份减最小身份），父、子、前元素兄弟、种类、名称、命名空间在登记时算好，之后每次查询是常数时间；「前序节点」用显式的待访栈，线性时间。

样式装配先展开嵌套规则，再筛选条件和登记层顺序。嵌套规则前后的声明保持源码次序，媒体与支持块里的声明继续匹配其父选择器。

「带条件计算节点样式」接受条件环境、节点与样式来源。在装配层块时递归筛选 `@media` 和 `@supports`；「文档计算节点样式」采用默认屏幕环境。调用者在视口或用户偏好改变后传入新环境重新计算，取得更新的样式。

本包提供带稳定身份的可变文档节点。节点的内容、属性、父子关系及脏位用豫言引用保存。使用者持有节点后，可观察后续修改。

默认导入「样式接线」。「节点行内样式」解析 `style` 属性，「文档样式规则」按前序收集样式元素的规则，「文档外链样式」收集样式链接地址，交由加载器获取后解析。

默认导入「选择器接线」。「文档样式树视图」以节点身份提供抽象查询；「节点匹配选择器」「最近选择器」「查询选择器」「查询选择器全部」对应 `matches`、`closest`、`querySelector`、`querySelectorAll`。查询按前序返回稳定节点，范围根参与 `:scope` 匹配。初始控件状态取自属性，交互状态接线留待页面事件循环。

默认导入「计算样式」。「新样式来源」登记来源、层与规则；「文档计算节点样式」将匹配规则与行内声明级联，递归继承父样式并替换变量。「文档求样式」使用本页样式元素。「装配样式诸源」接受环境并展开条件、层声明与层块，同名层共享首次登记的顺序，嵌套层按限定名称登记。当前计算入口返回指定值字符串，后续接单位、颜色换算及缓存；层组的完整树序优先级与匿名层独立身份随后补齐。

「节点伪元素候选」对每条规则里以伪元素结尾的选择器分支，去掉伪元素后匹配这个元素，匹配上就产生带伪元素名的层叠候选。计算元素样式时（祖先只作继承，不算伪元素），对 `before`、`after`、`marker` 各自把胜出的声明连成「名:值;」，以「::名」为键并进元素的计算样式；它不是继承属性，子元素不带。盒树生成时再解析回来，对元素样式层叠出伪元素的样式。

节点种类采用网页文档对象的编号。元素、文本、注释、属性、处理指令、字符数据段、文档与片段由相应构造函数创建。节点身份在移动、修改和重新插入后保持。

默认导入「节点」「树操作」「节点操作」「标记解析」「序列化」「遍历」。父子操作同步更新引用，片段插入依次移动其子节点；插入检查祖先关系以维持树结构。属性修改与树修改把祖先链标为脏。文字规范化移除空文字，并将相邻文字合入首节点。

「解析文档」「解析片段」调用超文本标记的标准树构造（经「构树接线」把树建造器接到本包的节点，句柄是登记表里的序号，零表示空位置）：整页补出全文、头与身元素，片段按 body 元素的上下文解析；「设内部标记」以节点自身为上下文元素解析。模板元素的内容就是它的子节点。「外部标记」「内部标记」进行标记序列化与转义；原始文本直接写出。查询按文档前序遍历，深克隆创建新的身份与可变引用。

「事件」「中止」「微任务」「观察」一并默认导入。事件沿固定父链依次捕获、到达目标、冒泡；监听支持捕获、一次、被动和中止信号，回调对象的身份用于去重与移除。自定义事件保存任意豫言值的详情。回调异常写入任务诊断；微任务检查点按入队顺序执行。

中止控制器保存首个理由，同步通知善后；组合信号采用首先中止的信号。事件循环用「推进中止时刻」提供毫秒时间，驱动超时信号。变更观察器支持子节点、属性、文字、子树、属性筛选和旧值；记录在微任务检查点批量投递，也可主动取走或断开。每记一条变更「文档变更计数」加一，浏览器据此判断脚本改没改文档。

后续实施包括节点所属文档、范围与动态集合、选择器、影子树、自定义元素及元素属性反射。事件的影子树重定向、界面事件专有字段，以及观察记录的兄弟字段与移除子树的临时订阅留待后续。标准与官方测试版本在一致性运行器接入时锁定。

验证保留一个文档集成冒烟入口，覆盖隐式全文结构、片段解析、稳定身份、移动、片段插入、深克隆与序列化。甲级与乙级验收随提案进度登记。
# 选择控件实时映射

单行单选控件首次读取时，已有选态保留；没有选项选中时选择首个可用项，跳过禁用选项与禁用组中的选项。多选与多行保持原选态。显式值和下标赋值登记已初始化状态，清空后保持空选择。复原选择控件同时复原其选项并重置初始化状态。

「选择控件下标」「选择控件值」读取首个已选项，「设选择控件下标」按位置更新各项选态，「设选择控件值」选中首个值匹配项。未匹配值和越界下标清除选择，默认属性保留；显示与提交沿已有选项状态读取。默认首项选择和选项增删修复留待后续版本。
