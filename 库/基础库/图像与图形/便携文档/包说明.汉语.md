# 便携文档

生成 PDF 1.7 子集。对象从 1 连续编号；对象列表、根目录对象号交给 `生成便携文档`，返回二进制字节串。交叉引用表按真实字节偏移写出，流长度保留内部零字节。

提供页面树、页面、字体、图像、链接和书签对象构造器。字体程序由调用者提供 TrueType 或原始 CID CFF 字节；CID 编码与 Unicode 映射由调用者提供。`抽取紧凑字体` 从 OpenType 文件取出原始 CFF 表。

`真型字体子集` 接单个 TrueType sfnt 字节串与所用字形号列表，保留字形号、度量和复合字形依赖，移除未用轮廓并重算校验。字形零自动保留。PDF 字体名使用六个大写字母与加号前缀，如 `YYAAAA+YYSubset`。文字字码为大端双字节 GID；Unicode 映射的目标为 UTF-16BE 字节。

`便携路径` 接二维绘图路径与涂法（`S` 描线、`f` 非零填充、`f*` 奇偶填充）。曲线和椭圆弧以 64 份平展写出。坐标保留六位小数。位图接连续 RGB 八位像素，以 zlib 存储块嵌入；JPEG 接原始 RGB JPEG 字节。书签标题接 UTF-16BE 字节，构造器添加字节序标记。

后续版本事项：CFF 字体自动子集、字体集抽取、透明图像蒙版、曲线自适应精度、字体度量与文字码点自动转换。提案甲级验收尚待 CFF 子集。
