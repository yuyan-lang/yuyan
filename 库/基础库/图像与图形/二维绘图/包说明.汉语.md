# 二维绘图

公开路径模型由路径指令列表组成，供 SVG 渲染与 PDF 输出共用。M 与 L 接收横纵坐标，Q 接收控制点与终点，C 接收两个控制点与终点，A 接收中心横纵、半径横纵、起角与扫角（弧度），Z 闭合当前子路径。

`矩形路径` 按横、纵、宽、高创建闭合路径。

`平展路径 路径 份数` 用 de Casteljau 插值与椭圆弧采样把曲线转为 M、L、Z 命令。`变换路径` 对平展后的路径应用六参数仿射变换。`椭圆路径` 接收中心横纵与半径横纵。

`造颜色 红 绿 蓝 透明` 构造 0 至 255 的 RGBA 颜色。`渲染路径 宽 高 路径 颜色 填充规则` 返回紧密排列的红绿蓝透明8图像。填充规则可用“非零”与“奇偶”。当前每段曲线平展为 64 份，每像素采用 8×8 子像素采样计算覆盖度。

`合成颜色` 与 `合成图像` 接收源、底、算子与源图层不透明度。算子为“清除、源、底、源上、底上、源内、底内、源外、底外、源顶、底顶、异或、相加”。“源上”对应 source-over。源与底按非预乘 RGBA 输入，在合成时按透明通道预乘，输出再还原为非预乘 RGBA。分量按最近整数写入八位通道，半值向上舍入，相加结果钳制至 255。

`混合颜色` 与 `混合图像` 提供“正片叠底、滤色、变暗、变亮、差值、排除、颜色减淡、颜色加深、强光、叠加、柔光”，以源上方式合成。`路径裁剪图像 图像 路径 规则` 把路径覆盖度作用于图像透明通道。图像合成与混合接收等尺寸、紧密排列的红绿蓝透明8图像。
