## 甲级缺项

2026-10-08 使用完整 5384 工具链，在 pit-mac 独立树、独立缓存串行构建运行「枕头独立参考」「几何」「合成」三个测试目标，均退出 0。「枕头独立参考」严格逐像素比对 Pillow 11.0.0 官方四种缩小固定向量，同时检查透明污色和 torchvision 中心裁剪规则，参考来源见 `测试/独立参考来源.md`。同三份 Wasm 经已验硬浮点同源生成器与执行器预编二生成独立原生程序，直接运行均退出 0，与 Node 输出一致。

本次按官方参考修正整数重采样逐轴取整、透明预乘处理及中心裁剪半整数取偶规则。实际日志为 pit-mac `/tmp/yy枕头5384运行.log`、`/tmp/yy枕头原生运行.log`、`/tmp/yy枕头几何运行.log`、`/tmp/yy枕头几何原生运行.log`、`/tmp/yy枕头预处理运行.log`、`/tmp/yy枕头预处理原生运行.log`。该轮覆盖四种滤镜的固定缩小样例、透明污色、几何及既有视觉归一，完整预设外部运行数据仍为下列缺项。

净整合复验从最新 yybs `5d64ddc64` 新建「基础库-图像处理已验」，仅拣取已验叶提交为 `4e64390cd`，原阶段树保留。导出该净树完整源码后，用原 pit-mac 独缓存与完整 5384 链执行正式依赖包检查、关键参考重建及 Node 运行，均退出 0，构建实际 PID 为 675。重建客体 SHA256 为 `3367e75b650097bc56fc7fe8999994f2a37cde80412851fc601d66dfcf8da03b`，与此前双端已验客体逐字节哈希一致。复跑该客体的现成原生程序退出 0，输出与净树 Node 输出经 `cmp` 核对相同。日志为 `/tmp/yy枕头净树检查.log`、`/tmp/yy枕头净树构建.log`、`/tmp/yy枕头净树节点.log`、`/tmp/yy枕头净树原生.log`。净整合分支只含叶功能与本段复验证明两提交。

Pillow/torchvision 的 ImageNet 与 CLIP 预设外部对照数据尚待取得。对照应包含非方形 RGB 图、放大与缩小、奇偶中心裁剪、灰度转 RGB、透明输入，记录软件版本、插值、抗锯齿选项、均值标准差、CHW/HWC 与 F32 字节序。当前已有 ImageMagick 三滤镜缩小向量及真实 CHW 归一断言。固定对照数据取得后提交数据，豫言测试负责读取与比对。

- 更广的 ImageMagick 颜色、透明合成、任意角仿射、模糊和量化容差对照。
- 已有 128 种子恒等、对称与格式往返性质；更大尺寸、异常输入及长期模糊测试待追加。
- 同一客体的原生性能与正确性、裸机解释执行/预编二、浏览器与云工客体运行待验。
- 共用「图像量化」已登记合入 `ec25b243d`。本包改为直接依赖并转出原 API，旧重复模块已删除；导入迁移与 GIF 使用者回归待统一窗口运行。

## 裸机与浏览器准备

裸机使用既有「豫言系统」预置目录机制，把本包已构建的测试 Wasm 放到私有 `yy图像裸机目录`，沿系统说明运行。启动后由壳运行预置的测试文件并记录输出；解释执行与预编二、ARM64 与 AMD64 分开记录。

```sh
./yy豫构.exe 文件 豫言操作系统/裸机/豫言系统。豫 --输出 yy豫言系统.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=1024 node 豫言操作系统/宿主/节点/宿主.cjs yy豫言系统.wasm 运行 --架构 兼容六十四 --预置 yy图像裸机目录
```

浏览器正式入口读取 `程序.wasm`、`值桥.wasm`、`接口要求组.json` 与 `宿主提供组.json`。本包浏览器回归资源组尚待准备，后续沿现有双宿主构建与装载机制生成该资源组，再用现有浏览器测试页启动。资源组与许可路径确定后补上可直接复跑的构建、装载、服务命令；目前只完成纯算法源码与节点/原生入口准备。
