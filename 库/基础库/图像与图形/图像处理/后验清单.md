## 甲级缺项

Pillow/torchvision 的 ImageNet 与 CLIP 预设外部对照数据尚待取得。对照应包含非方形 RGB 图、放大与缩小、奇偶中心裁剪、灰度转 RGB、透明输入，记录软件版本、插值、抗锯齿选项、均值标准差、CHW/HWC 与 F32 字节序。当前已有 ImageMagick 三滤镜缩小向量及真实 CHW 归一断言。固定对照数据取得后提交数据，豫言测试负责读取与比对。

当前仓库具有图像处理自己的 ImageNet/CLIP 参数预设，外部预设数据的读取回归入口待随数据一并添加。Pillow/torchvision 的生成环境与参考文件尚待确定，因此本清单不把内部向量运行视作外部对齐验收。

## 乙级缺项

- ICC 参数曲线类型 0–3 与曲线表的独立外部向量、复杂配置和标签长度内的字段边界核验。
- 更广的 ImageMagick 颜色、透明合成、任意角仿射、模糊和量化容差对照。
- 已有 128 种子恒等、对称与格式往返性质；更大尺寸、异常输入及长期模糊测试待追加。
- 同一客体的原生性能与正确性、裸机解释执行/预编二、浏览器与云工客体运行待验。
- 共用「图像量化」已登记合入 `ec25b243d`。本包改为直接依赖并转出原 API，旧重复模块已删除；导入迁移与 GIF 使用者回归待统一窗口运行。

## 裸机与浏览器准备

裸机使用既有「豫言系统」预置目录机制，把本包已构建的测试 Wasm 放到私有 `yy图像裸机目录`，沿系统说明运行。启动后由壳运行预置的测试文件并记录输出；解释执行与预编二、ARM64 与 AMD64 分开记录。

```sh
./yy豫构.exe 文件 豫言操作系统/裸机/豫言系统。豫 --输出 yy豫言系统.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=1024 node 豫言操作系统/宿主/节点/宿主.cjs yy豫言系统.wasm 运行 --架构 兼容六十四 --预置 yy图像裸机目录
```

浏览器正式入口读取 `程序.wasm`、`值桥.wasm`、`接口要求组.json` 与 `宿主提供组.json`。本包浏览器回归资源组尚待准备，后续沿现有双宿主构建与装载机制生成该资源组，再用现有浏览器测试页启动。资源组与许可路径确定后补上可直接复跑的构建、装载、服务命令；目前只完成纯算法源码与节点/原生入口准备。
