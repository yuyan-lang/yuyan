# 图像处理

图像处理使用图像编解码包的统一图像类型。几何模块提供裁剪、中心裁剪、水平与垂直翻转、顺时针直角旋转、EXIF 八种方向校正和最近邻缩放。中心裁剪的半像素起点按最邻近偶数取整。变换读取源行距并输出紧密排列的图像。

像素格式有灰度、灰度透明、红绿蓝、红绿蓝透明、蓝绿红透明；每种格式具有 8、16、浮32 三种分量精度。十六位与单精度分量使用小端存储。几何变换保留完整像素字节。

像素模块提供以上十五种格式互转、预乘透明与解除预乘透明。色值按归一化红、绿、蓝、透明四分量表示；灰度采用 BT.601 权重。像素格式互转的整数输出夹在有效区间并取最邻近偶数。单精度转换处理符号、次正规数、无穷和非数。

颜色模块提供 sRGB 与线性传递函数以及 BT.601、BT.709 全范围亮色差互转。最近邻与重采样采用半像素中心坐标；重采样模块提供双线性、Catmull–Rom 双三次、Lanczos3 和面积平均。整数重采样按横轴、纵轴分离执行，每轴结果以半上取整写回像素。透明格式使用预乘颜色采样并还原直通颜色，同尺寸保留原像素。缩小时采样核按缩放比例展开，边界截断采样核并按剩余权重归一。缩略图保持宽高比并限制在指定矩形内。

构造模块提供常色与复制边缘填边。合成模块按直通透明颜色提供 Porter–Duff 的清除、源、底、源覆盖、底覆盖、源内、底内、源外、底外、源置顶、底置顶、异或以及相加。图像合成使用相同尺寸。

视觉预处理提供短边缩放、中心裁剪、按通道均值与标准差归一和 CHW/HWC 单精度小端数据输出。图像网预设采用短边 256、裁剪 224、双线性采样及标准均值标准差；对比视觉预设采用所给边长、双三次采样及 CLIP 均值标准差。

定点模块提供八位像素的 16.16 双线性缩放。色相模块提供 HSV/HSL 互转，色相一周表示为一。仿射模块提供前向六系数矩阵的逆向双线性采样和按角度顺时针旋转；旋转扩展输出边框。滤镜模块提供自定义卷积、盒式模糊、可指定半径与标准差的高斯模糊、锐化和 Sobel。卷积延续边缘并逐分量计算颜色与透明度；Sobel 保留中心透明度。

颜色配置模块读取 ICC v2/v4 的 RGB–XYZ 矩阵配置，支持曲线表与参数曲线 0–4，按目标矩阵反解和反曲线转换颜色。每个矩阵与曲线标签先按其声明长度核对完整字段，截断矩阵、曲线表与参数曲线会报告字符串异常。色阶模块提供按通道的 256 桶直方图、黑白位调整和实数伽马。

本包直接依赖共用「图像量化」，图像编解码与本包共用同一实现；使用者需要它的量化 API 时，直接依赖并导入「图像量化」。「量化图像」接受统一图像类型，转换为紧密 RGBA8 后调用共用量化。紧密 RGBA8 字节可用中位切分或八叉树生成最多 256 色的调色板，并选择 Floyd–Steinberg 抖动，输出 RGBA8 调色板与逐像素索引。「图像量化」的公开入口「量化红绿蓝透明」依次传入像素、宽、色数、八叉树开关和抖动开关。

## 已测性能

2026-10-08，pit-mac Apple M2 Max、12核；复用公共二次预热九次中位，算法在进程内计时，每次核对输出。32×32 RGBA8确定性颜色缩放至96×64的四方法每个测量操作重复八次；两种量化处理1024像素、64色和Floyd–Steinberg抖动。同guest Node与原生六项校验依次为336、255、193、336、29、37。原生为硬浮点同源预编二执行。
