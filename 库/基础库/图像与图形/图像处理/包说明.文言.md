# 图像处理

图像处理用图像编解码之同一图类。几何之书可裁、居中裁、横纵翻、顺时直角转、正 EXIF 八向及近邻缩。读源行距，出图则密列。

像素有灰度、灰度透明、红绿蓝、红绿蓝透明、蓝绿红透明；分量之精度有八位、十六位、单精度。十六位与单精度皆小端藏。几何之变，像素诸字悉存。

像素之书可互化上列十五制，亦可预乘透明及解之。色值以归一之红绿蓝透明四分量示；灰度依 BT.601 之权。整数之出，夹于其域，就近取偶。单精度之化，受符号、微数、无穷与非数。

颜色之书可互化 sRGB 与线性，亦可互化 BT.601、BT.709 全域之明色差。采样之书，以半素心为坐标，具双线性、Catmull–Rom 双三次、Lanczos3 与面积平均。缩小则依其比广核，边外续边素。缩略图存宽高之比，限于所定矩。

构造之书可常色填边，亦可续边。合成之书以直通透明之色，具 Porter–Duff 清除、源、底、源覆盖、底覆盖、源内、底内、源外、底外、源置顶、底置顶、异或及相加。合图用同尺寸。

视觉预处理可缩短边、居中裁，以通道均值与标准差归一，出 CHW/HWC 单精度小端之字。图像网之设，短边二百五十六，裁二百二十四，双线性采，以标准均值标准差。对比视觉之设，以所授边长、双三次采与 CLIP 均值标准差行之。

定点之书，以 16.16 双线性缩八位像素。色相之书互化 HSV/HSL，一相之周以一示。仿射之书，以前向六系数矩阵逆向双线性采之，亦可按度顺时转；转则广其边框。滤镜之书具自定卷积、盒式模糊、可授半径标准差之高斯模糊、锐化与 Sobel。卷积续边，透明存中心之值。

ICC 与调色板量化，依提案 00004 续成。Pillow、torchvision 逐素外校，留待后验。
