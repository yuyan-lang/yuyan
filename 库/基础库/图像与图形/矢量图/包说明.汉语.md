# 矢量图

这是纯豫言实现的 SVG 路径数据读写库。

`解析路径` 将字符串解析成可选的路径数据；每项由 `路径指令` 保存命令字和小数参数列表。命令字保存绝对与相对形式，移动命令的后续坐标转成直线命令。`写出路径` 输出可再次解析的字符串。

路径命令包括 M、L、H、V、C、S、Q、T、A、Z，支持大小写、重复参数、指数数值和圆弧标记。非法命令、缺少参数和非法圆弧标记返回空值。

数据结构与算法为本项目原创，按仓库许可发布。测试包含全命令读写和非法输入。目前处于实现中；静态 SVG 文档、样式、图像、文字、二维渲染与滤镜留待后续实现。甲乙级验收尚待完成。

`解析长度` 接收长度字符串、百分比基准与字高，支持 px、%、in、cm、mm、pt、pc、em、ex；绝对单位按每英寸 96 像素换算，ex 暂取半字高。`合成变换` 计算两个六参数仿射矩阵的乘积；`变换坐标` 将横纵坐标映射到新坐标。

`写出路径元素` 接收路径数据和填色，输出 path 元素并转义属性。`写出矢量图` 接收整数宽高与元素内容，输出包含命名空间、尺寸与 viewBox 的 svg 文档。
