# 矢量图

此库以豫言读写 SVG 之路径。

`解析路径` 受字符串，得或可有之路径数据。`路径指令` 存令字及小数参数之列，存绝对、相对之式；移令之续坐标化为线令。`写出路径` 成可复读之串。

令有 M、L、H、V、C、S、Q、T、A、Z；大小写、重参数、指数及弧标皆可用。令误、参缺、弧标误，则还可无。

结构与算法皆本项目所作，循仓库之许可。试验含诸令读写及误入。今方实施；文档、式样、图像、文字、二维绘制与滤镜，俟后继之。甲乙之验尚待成。

`解析长度` 受长度之串、百分之基及字高，可用 px、%、in、cm、mm、pt、pc、em、ex；绝对单位以每英寸九十六像素为率，ex 暂取半字高。`合成变换` 乘两组六参仿射矩阵；`变换坐标` 映横纵为新坐标。

`写出路径元素` 受路径数据与填色，出 path 之项，转其属性之义。`写出矢量图` 受整数宽高与诸项，出含名称空间、尺寸及 viewBox 之 svg 文。
