# 矢量图

此库以豫言读写 SVG 之路径。

`解析路径` 受字符串，得或可有之路径数据。`路径指令` 存令字及小数参数之列，存绝对、相对之式；移令之续坐标化为线令。`写出路径` 成可复读之串。

令有 M、L、H、V、C、S、Q、T、A、Z；大小写、重参数、指数及弧标皆可用。令误、参缺、弧标误，则还可无。

结构与算法皆本项目所作，循仓库之许可。试验含诸令读写及误入。静态文、式样、图像、文字与二维绘制皆已联于源码；完整滤镜及甲乙之验续行。

`解析长度` 受长度之串、百分之基及字高，可用 px、%、in、cm、mm、pt、pc、em、ex；绝对单位以每英寸九十六像素为率，ex 暂取半字高。`合成变换` 乘两组六参仿射矩阵；`变换坐标` 映横纵为新坐标。

`写出路径元素` 受路径数据与填色，出 path 之项，转其属性之义。`写出矢量图` 受整数宽高与诸项，出含名称空间、尺寸及 viewBox 之 svg 文。

`转换绘图路径` 化路径相对坐标、横纵线、二三次曲线、省写控点及端点椭圆弧，为二维绘图之绝对路径。`渲染路径数据` 受宽、高、路径、绘色及填充之法，得或可有之 RGBA 图。试验校相对矩形之像素覆盖、平滑曲线之控点反射。

`渲染矢量图` 以可扩展标记析 SVG 之树，受 SVG 文与宽高，得 RGBA 图。今可绘 svg、g、path、rect、circle、ellipse，继填色、用非零或奇偶之法、含组不透明度及源上叠层。defs 与 symbol 之定义留于树。填色可用短长十六进制、黑白红绿蓝及透明。实试校组之继色、矩形叠层及组透明度。

`解析变换` 可用 matrix、translate、scale、rotate、skewX、skewY，并循序合之；旋可授其中心。元素之 transform、svg 之 viewBox 与 preserveAspectRatio，已用于文之绘制。视框可用 none、meet、slice，横纵皆可最小、居中、最大之齐。pit-mac 数试校变换之序、旋之中心、斜切及视框之齐；文试校组平移、居中视框之像素。

待验之篇，已将内部 use 之引、symbol 之展、标签与类与身份之择及行内样式、polyline 与 polygon、横纵异径之圆角矩形、line 与描边之廓、虚线、透明度及展示属性之继承接于主入。data URI 之 image 已联整体变换与视框之齐。线性与中心径向之渐变，已联色标、透明度、延展、单位、变换及引之继承；clipPath 已联各形蒙版之合、单位及裁剪之则。诸篇已排，型检与像素之试列于统一验次。径向焦点、嵌套视口及逻辑视口百分比之准，皆列续事。

`渲染矢量图字体` 受 SVG 之串、输出宽高及调用者所授之字体，以一字体之字形轮廓绘基本 text；文字之尺寸与基线，取诸 SVG 属性。此入与字体之试，皆候统一验次。

今之阶段，诸库模块之型检皆过。image 之PNG、灰度一百二十八JPEG与红色RGB444 JPEG，经data URI、统一解码、图像处理化RGBA8、图案取样及矩形视框之绘，其试已构行而过，成三份PNG画布之物。余新联之像素试及固定resvg参考之校，续验之。
