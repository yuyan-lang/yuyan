生成种子的来源为本树纯豫正规编码器。PNG、GIF、BMP、ICO/CUR、PBM/PGM/PPM/PAM、QOI、VP8L、APNG、TGA 使用原生产编码入口。P1/P2/P3 与 16 位 P5 按 Netpbm 标准文本或二字节大端数据构造。GIF 双帧在正规编码的全局色盘和图像块外加入标准 GCE，处置值二、三；WebP 双帧在正规 VP8L 帧块外加入标准 VP8X、ANIM、ANMF，动画与透明标志俱全。小 TIFF 是 TIFF 6.0 十二项基线灰度条带目录，X/Y 分辨率各有独立有理数；目录后继零、像素偏移、条带量及文件长度逐项一致。

TIFF 标签静态核对依据 [TIFF 6.0 原规格](https://www.itu.int/itudoc/itu-t/com16/tiff-fx/docs/tiff6.pdf) 第四节 Required Fields for Grayscale Images：宽、高、位深、压缩、光度、条带偏移、每条带行数、条带字节量、X/Y 分辨率与分辨率单位俱全，另登记 SamplesPerPixel=1。独立 TIFF 消费者核验等待实际生成文件。

## 每口最短百万命令

本树先接最新完整同批工具链到独立缓存路径，父确认错峰窗口后按下列命令串行构建。当前命令是执行准备，执行结果由实际 PID、日志与返回码另行登记。

```text
node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 图像模糊测试 种子生成 --输出 yy图像种子.wasm --编译器 ./yy_bs_stable.wasm -j 24
node yy稳定节点宿主/宿主.cjs yy图像种子.wasm
```

每个入口使用同一条正式百万命令，分别把上表的实际入口名与完整种路径代入；批量 10000，时限 60000 毫秒，每个入口独立一百万编号：

```text
node yy稳定节点宿主/宿主.cjs yy图像模糊.wasm 全量 入口名 完整种路径 1000000 10000 60000
```

例如标准小 TIFF 的两个入口分别执行：

```text
node yy稳定节点宿主/宿主.cjs yy图像模糊.wasm 全量 标签图 库/基础库/图像与图形/图像模糊测试/种子/标准灰度条带.tif 1000000 10000 60000
node yy稳定节点宿主/宿主.cjs yy图像模糊.wasm 全量 统一标签图 库/基础库/图像与图形/图像模糊测试/种子/标准灰度条带.tif 1000000 10000 60000
```

每口先把次数改为 10、批量改为 5，确认原种与隔离设施；百万期间保持单活构建与既有隔离子批调度。运行登记至少包括工具 SHA、种子 SHA、实际 handle/PID、入口、种路径、起止号、成功/拒绝数、限时、退出码与日志。当前没有任何百万完成声明。
