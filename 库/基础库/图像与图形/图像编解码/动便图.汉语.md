# 动便图

动便图对应 APNG，采用 W3C《PNG 第三版》的帧控制、序号与画布合成规则。`解码动便图` 接收字节串，返回 `动便图成功` 携带的文档或 `动便图失败` 携带的错误字符串。文档字段为宽、高、循环次数与帧列表。每帧由完整画布图像和整数毫秒延时组成；循环次数零表示持续循环。

读取过程复用便图的块校验、颜色、滤波、隔行与解压。默认静态图可以作为动画首帧，也可以留在动画之外。帧控制块可以位于动画控制块之前；动画控制块位于首个图像数据块之前。色盘与透明块可以先于动画控制块。帧控制与帧数据共享从零递增的序号。帧数、矩形边界、处置与混合值均在读取时核对。

画布采用双精度直通颜色保存中间结果。来源替换、透明覆盖、清背景和恢复前画布在逐帧合成时执行。公开帧输出为红绿蓝透明8或红绿蓝透明16，16位分量采用小端字节序。每次输出帧才将内部数值量化，连续微透明覆盖可以积累颜色变化。

`编码动便图` 依次接收帧列表、循环次数和便图压缩级，返回错误字符串与字节串的二元组。空错误表示成功。编码帧使用相同尺寸与像素格式，各帧覆盖完整画布，以来源替换和保持画布方式写出。延时按毫秒约分为秒分数，分子与分母遵守格式的16位字段。循环次数遵守32位字段。

固定向量覆盖延时、循环、透明混合、清背景、恢复画布、16位分量、微透明百次覆盖、默认图排除、序号损坏与帧控先行。`测试/动便图样本核验。脚本。豫` 无参数时比较仓内七组官方动画末帧，带两个路径时比较指定动画和静态参考。参考比较将十六位完整分量按除以257并四舍五入归一为八位，再比较全部像素字节。官方样本采用 Web Platform Tests 提交 `b550114b660ac9473078674ae8726ce760697904` 的 `png/apng/support` 数据，包含基本帧、默认图排除、拆分帧数据、帧控先行、16位、灰透明与一位色盘透明。具体对应与摘要见[样本来源](测试/动便图样本/来源.汉语.md)。规则参见 [W3C PNG 第三版](https://www.w3.org/TR/png-3/)。

当前源码在最新同配5384链通过整体类型、固定向量和七组官方样本末帧比较。区域帧编码优化、跨颜色空间合成与完整甲乙性能及逐入口百万变异验收列为后续事项。
