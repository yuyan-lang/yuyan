# 视窗位图、设备位图与图标

BMP 与 DIB 支持十二字节核心头和信息头系列。核心头的三字节色表在解码前转换为四字节色表。

`解码视窗位图` 读取 BMP 文件，`解码设备位图` 读取 DIB 数据。结果为统一的 `图像解码结果`，像素采用自上而下、红绿蓝透明度顺序的 `红绿蓝透明8`。未压缩图像可用 1、4、8、16、24、32 位像素；16 位默认采用 RGB555，位域图像使用头部的 RGB 与透明度掩码。RLE4 与 RLE8 解码处理重复段、字面段、行结束、数据结束与位移。

`编码视窗位图` 与 `编码设备位图` 接受 `红绿蓝透明8` 图像，生成保留透明度的 32 位未压缩像素，行序按文件格式从底部向上写入。输入行距应足以容纳一行四字节像素。

`解码图标帧` 按零起帧序读取 ICO 或 CUR 目录，`解码图标` 与 `解码光标` 读取首帧。DIB 图标同时处理彩色像素与一位 AND 遮罩。32 位图标保留原透明度，全零透明度图标按遮罩生成透明度。`图标帧数` 查询目录帧数，`图标热点横`、`图标热点纵` 查询 CUR 帧热点。

`编码图标` 与 `编码光标` 生成单帧 32 位 DIB 容器；光标编码额外接受热点横纵坐标。透明度小于 128 的像素在 AND 遮罩中记为透明。

## 后续版本事项

- 其他内嵌图像格式。
- 多帧图标编码、色表位深编码、游程编码。
- 色彩空间与内嵌色彩配置转换。
- 超出 ICO 目录一字节尺寸字段的图像处理。

ICO/CUR 中的便图载荷由「解码便图」读取，支持全部合法颜色与位深、透明和Adam7。
