# 动便图

动便图即 APNG，依 W3C《PNG 第三版》之帧控、序号与画布合成之则。`解码动便图` 受字节串，成则以 `动便图成功` 载文档，败则以 `动便图失败` 载错辞。文档有宽、高、循环数与帧列。每帧合全画布图与毫秒延时；循环数零者，循环无尽。

读取用便图之块验、颜色、滤波、隔行与解压。默认静图可为首动帧，亦可置于动画之外。帧控块可先于动画控块；动画控块先于首图像数据块。色盘及透明块可先于动画控块。帧控与帧数据共用序号，自零递增。帧数、矩形之界、处置与混合值皆核之。

画布以双精度直通色存中间之值。逐帧施来源替换、透明覆盖、清背景与复前画布。所出之帧为红绿蓝透明8或红绿蓝透明16，十六位分量以小端存之。出帧乃量化，故微透明屡覆盖者，其色可积。

`编码动便图` 依次受帧列、循环数与便图压级，返错辞合字节串。错辞空则成。诸帧尺寸与像素格式同，皆覆全画布，以来源替换且保持画布写之。毫秒延时约为秒之分数，分子分母遵十六位字段；循环数遵三十二位字段。

固定向量核延时、循环、透明混合、清背景、复画布、十六位分量、微透明百次覆盖、默认图排除、坏序与帧控先行。`测试/动便图样本核验。脚本。豫` 无参则比仓内七组官方动图末帧，有两径则比指定动静图。十六位全分量除二百五十七而四舍五入归八位，乃比全像素字节。官方样本取 Web Platform Tests 提交 `b550114b660ac9473078674ae8726ce760697904` 之 `png/apng/support`，有基础帧、默认图排除、拆分帧数据、帧控先行、十六位、灰透明及一位色盘透明。对应及摘要见[样本来源](测试/动便图样本/来源.文言.md)。规则见 [W3C PNG 第三版](https://www.w3.org/TR/png-3/)。

此源以最新同配5384链核整体类型、固定向量及七组官方末帧皆过。区域帧编码优化、异色空间合成、甲乙性能及逐入口百万变异全验，列为后事。
