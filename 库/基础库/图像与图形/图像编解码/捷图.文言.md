# 捷图基图之解

`捷图` 篇设 `解码捷图`，受 JPEG 字节串，还共用图像解码结果。成则携灰阶八位或红绿蓝八位之图，依行次藏之。

标记之析读量化表、霍夫曼表、八位基帧、重启之距及扫描之首，验段长与分量。旧单扫成者守之。新基线多扫之源，依 SOS 标识映帧分量，别藏像面，具分离、部分交错及异次分量。单分量扫每单元惟编一块，采因参与面布局。量化表循文件锯齿之次，授扫描篇。

四色之帧以 CMYK 解之，Adobe APP14 标记择倒置 CMYK 或 YCCK。解成则循 EXIF 方位易像素与尺寸。

新多扫之源排版已过，类验、运行及独器对照待根授窗。固例与参数详《捷图基线多扫描》。渐进与算术，由一统入口选其篇。
