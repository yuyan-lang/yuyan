# 捷图基线解码

`捷图` 模块提供 `解码捷图`，接收 JPEG 字节串，返回公共图像解码结果。成功结果携带按行排列的灰度八位或红绿蓝八位图像。

标记解析读取量化表、霍夫曼表、八位基线帧、重启间隔和扫描头，检查段长度与分量参数。既有单扫描成功路径保留。新增基线多扫描源码按 SOS 分量标识映射帧分量，保存独立平面，支持非交错分离、部分交错及重排分量次序。单分量扫描每个 MCU 编码一个块，采样因子参与平面布局。量化表以文件中的锯齿顺序交给扫描模块。

四色帧采用 CMYK 解码，Adobe APP14 标记选择倒置 CMYK 或 YCCK。成功解码后按 EXIF 方向调整像素与尺寸。

新增多扫描源码轻格式化通过，类型、运行与独立参考验收待根授窗。回归入口和扫描参数见《捷图基线多扫描》。渐进与算术通过统一图像入口选择对应模块。
