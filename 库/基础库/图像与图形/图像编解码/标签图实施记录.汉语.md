# 标签图实施记录

本任务从正式 `yybs` 的 `825ba9c62` 建立专属工作树，分支为 `codex/基础库-标签图`。

已落盘目录、安全读取、条带与分块重组、交错与独立平面、水平预测器、未压缩/PackBits/LZW/Deflate 四种块解压，以及灰度、RGB、色表、CMYK、透明和方向处理。公开入口为 `解码标签图`，沿用统一图像与解码结果。

固定小向量与十三个官方样本核验源码已落盘，十三个原始 TIFF 样本已保存。样本来源与归档摘要见双语《来源》。源码完成轻格式化与静态复核。

在 pit-mac 独立验证树 `基础库-标签图-d25验证`，以正式 `2da121aa0` 及完整 d25 同配工具链验证。整体图像编解码包类型检查退出零，固定向量和 1296 次单比特变异退出零。十个官方原件、三个由官方旧图转换成 TIFF6 的新向量通过核验，十三组完整像素存储差分与独立 LibTIFF 参照一致。由图像编解码统筹接入 `II/MM` 魔数入口和总集。

原 `cramps-tile.tif` 与 `quad-tile.tif` 用 322/323 描述块而用 273/279 存块位置；原 `quad-lzw.tif` 用旧低位 LZW，LibTIFF 明示需转换。这三份原件保留用于来源追踪，读取兼容草稿独立留在临时目录，未纳入标准实现。固定样本采用三份独立规范转码文件，准确统计为十份原件和三份转换图。

未压缩参照参数为 `tiffcp -c none -p contig -s -r 1000000000`。标准灰度块参数为 `-c none -t -w 256 -l 256`；标准字典块为 `-c lzw -t -w 128 -l 128`；标准字典带为 `-c lzw -s -r 5`。参照转换与规范转换分别读取官方原件，压缩、布局还原以全像素逐字节差分检验；色彩归一和关联透明另由手工固定向量验证。

完整工具链归档 SHA256 为 `52f0c19ee01197e27cce49495e676587ffafdcb27338b064be0ad645b13c0ec0`。真实验证日志在 pit `/tmp/yy标签图-d25类型.log`、`yy标签图-d25固定运行.log`、`yy标签图-d25规范转换运行.log`、`yy标签图-d25规范差分运行.log`，临时参照目录为 `/tmp/yy标签图独立参照`。独立差分入口会话 72610 构建、运行均退出零，最后的现代分块与字典带重编码复验亦退出零。
