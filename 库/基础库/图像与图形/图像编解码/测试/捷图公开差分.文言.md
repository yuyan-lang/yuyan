# 捷图公开参考差分

此入口以纯豫言一统解图之果，比独器 `djpeg` 所出八爻 PPM。基线、渐进霍夫曼、算术诸流皆由一统入口解之。图用灰度8、红绿蓝8或红绿蓝透明8，依行距取像，灰度充三同道。

`捷图公开差分。测试` 受捷图路径、参考 PPM 路径，及可选 `方向二` 至 `方向八`。EXIF 方向以试中独定之逆坐标索参考图，`djpeg` 所出守文件行次。出颜色样本数与平方差之和；均方差以二为上，峰值信噪比至少四十五点一二分贝，足提案四十五之限。

今公开固图已取，SHA256 已校；二〇二六年十月八日于 pit-mac 专树，包察、类验、合构皆过。十五固图与独器默认所出相比，诺节及同客体硬浮点原生各十五项皆过四十五点一二分贝之限，平方差逐项相同。诸器身份与实果，见《捷图公开差分验收.汉语.md》。

libjpeg-turbo 3.2.0 之标签定于 `c85e6b905bf237038faa936dab160ebfc5da0344`，取其[官方测试图](https://github.com/libjpeg-turbo/libjpeg-turbo/tree/c85e6b905bf237038faa936dab160ebfc5da0344/testimages)。其原图、整数与算术图遵 IJG 许可，原始 PPM 为二百二十七乘一百四十九。原文许可与样本说明藏于样本目录。

Go go1.24.0 之[官方测试图](https://github.com/golang/go/tree/go1.24.0/src/image/testdata)，具三种彩色采样、三种渐进、灰度及渐进灰度、四色直通与重启。四色直通之 Adobe APP14 变换值为零，已静察之。原文 BSD 许可藏于样本目录。

Pillow 12.0.0 固定提交 `693df7b42c666f88c719f9973be0ad71607328e0` 之[官方测试图](https://github.com/python-pillow/Pillow/tree/693df7b42c666f88c719f9973be0ad71607328e0/Tests/images)，取 `pil_sample_cmyk.jpg` 与 `hopper_orientation_6.jpg`。前者百乘百，四色，Adobe 变换值二，为 YCCK；后者百二十八之方图，方向字段为六。原文 MIT-CMU 许可藏于样本目录。

每图源名与 SHA256，详汉语稿之表。其表亦载本机与 pit-mac 两器之实哈希；两机均报 libjpeg-turbo 3.2.0，构建号 20260630。

复验时，以完整同配工具链、二十四并行度构此一入口；再逐图以 `djpeg -dct int -rgb -pnm` 出参考 PPM，运行此入口。CMYK 与 YCCK 两图用 `djpeg -dct int -pnm` 默认转换；方向六图须附 `方向六`。实对照具 4:4:4、4:2:2、4:2:0、灰度、CMYK、YCCK、EXIF 方向六、渐进、重启与顺序算术。

品质矩阵以后窗用 `cjpeg` 之品质二十五、九十、百与三采样，各出文件；复具渐进、算术、渐进算术与灰度。每项出后，以独器解之，此入口比之；实哈希与实运行之果，当时录之。

公开诸器供试图与对照；生产诸篇惟依豫言库。
