# 标签图样本来源

诸图取 [LibTIFF 官方试图集](https://libtiff.gitlab.io/libtiff/images.html) 所列 [图归档](https://download.osgeo.org/libtiff/pics-3.8.0.tar.gz)。归档 SHA-256 为 `e0e34732b61e1ce49eff2c7a079994c856d2a5f772f5228c84678272bc6829a9`。诸篇存其原字，以中文名录之。

| 仓内文件 | 归档原名 | 所验 |
| --- | --- | --- |
| 灰度打包条带.tif | cramps.tif | PackBits 灰带 |
| 灰度原始分块.tif | cramps-tile.tif | 未压灰块 |
| 真彩字典条带.tif | quad-lzw.tif | LZW 彩带 |
| 真彩字典分块.tif | quad-tile.tif | LZW 彩块 |
| 灰度16收缩.tif | ladoga.tif | 十六位 Deflate |
| 真彩字典平面.tif | oxford.tif | 独立平面 |
| 色表打包.tif | jello.tif | 色表 PackBits |
| 透明字典.tif | strike.tif | 关联透明 LZW |
| 花纹灰度16.tif | depth/flower-minisblack-16.tif | 十六位灰 |
| 花纹真彩交错.tif | depth/flower-rgb-contig-08.tif | 交错真彩 |

花纹诸图，鲍勃·弗里森汉以 GraphicsMagick 开发版造之，原档 `depth/README.txt` 声明为公有领域。余图之源，见原档 `README`。

核验术读原图十与标准转图三，校灰带块、彩带块及花纹 RGB、CMYK 二种平面之同图。旧原图三存之以溯源；转图由既有 LibTIFF 之 `tiffcp` 独立读原图而生。
