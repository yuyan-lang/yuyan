# 位图与动图公开参考差分

`图像公开差分。测试` 以原作者所供 PNG 为独立像素之参。静图受位图及 PNG 二路径；动图受 `动图`、GIF 路径及完整诸帧 PNG，依次给之。试尺寸、帧数与各道；八爻灰度、灰透、红绿蓝、红绿蓝透明，皆依行距规整。双方透度皆零，则循 GNOME 之例，略此像 RGB；透度与可见色逐道同。

二〇二六年十月八日，包察、全包类验、公开差分合构皆过。十BMP及五组GIF于诺节、同客体硬浮点原生皆实验：BMP循原PNG逐道同；GIF三静帧循原参，处置二明叠于所宣黑底，处置三先全核零时初帧而后循展示之时比四参。条件及原败之证见《图像公开差分验收.汉语.md》。

此手授参考入口之单篇精确跳过法，录于 `应用/开发工具/全树测试/测试规则.tsv`。常CI以全包类验察源码；实公开像素之验，以诺节及同客体原生逐项之录证之。

[BMP Suite](https://entropymine.com/jason/bmpsuite/) 为 Jason Summers 所作，版本二点八，2023-11-28。固定发行包 SHA256 为 `f1b1f18c4f310b76bf317378e64f25b84f875a3d0976fab33ff10befdb35d13f`。十 BMP 与六 PNG 皆与其发行包原图校同。生成器未行。作者 README 言生成图像为公有领域，嵌入 ICC 者别论；此选常色诸图。作者说明原文随数据存。

[官方图录](https://entropymine.com/jason/bmpsuite/bmpsuite/html/bmpsuite.html) 明各图对应之 PNG。此选一、四、八位调色板，RLE4、RLE8，十六位默认五五五及五六五位域，二十四位真彩，三十二位默认及位域。源名、本地名与逐项对应，详汉语稿之表。

GNOME gdk-pixbuf 标签二点四四点四，注解对象 `5aa7e738075b710ba6e3921c4411b0113b6436b4`，实提交 `c9e6d11cbfa085d7b59dd6ad3b1cbfa26348ce13`。[官方测试图录](https://github.com/GNOME/gdk-pixbuf/tree/c9e6d11cbfa085d7b59dd6ad3b1cbfa26348ce13/tests/test-images/gif-test-suite) 具 GIF、帧 RGBA、同名 PNG 与配置。原始配置及测试清单皆存。项目 COPYING 为 LGPL 二点一，其原文亦存；上游试程序另标 GPL 二及后版、2018 Canonical Ltd. 著作权，此惟读其语义而以豫言别作入口。GIF 此存项目之许可，逐图别定之许可，待上游复核。

此取透明、隔行、局部色盘三静帧，处置二四原帧，处置三零时初帧及四展示帧。处置二用 `animation-erase.0.png` 至第三帧，明合透明参考于文件所宣黑底，逐道核之，延时各五百毫秒；处置三用 `animation.0.png` 至第三帧，先核零时初帧之全黑不透明画布，而后比四展示帧。两动图皆二乘二，处置三在上游默认 TESTS 中注释，今两端皆实核。五GIF有十二原合成帧，十一有官定PNG参考，零时初帧循规范及原帧之断别核。生产GIF守所宣之底及全原帧；循环、余展示延时别期核之。

复验用完整同配器、二十四并行度构此一入口；静图受两路径，三静GIF受 `动图`，处置二受 `动图黑底`，处置三受 `动图零时初帧`，各与输入、全参考帧同授。最短实命与对应详汉语稿。诸文件实SHA256载 `样本指纹.原文.txt`。

试篇居编解码包内，惟用同包图像、解器与便图参考。生产诸篇依赖如故。
