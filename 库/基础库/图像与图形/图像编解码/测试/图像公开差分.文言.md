# 位图与动图公开参考差分

`图像公开差分。测试` 以原作者所供 PNG 为独立像素之参。静图受位图及 PNG 二路径；动图受 `动图`、GIF 路径及完整诸帧 PNG，依次给之。试尺寸、帧数与各道；八爻灰度、灰透、红绿蓝、红绿蓝透明，皆依行距规整。双方透度皆零，则循 GNOME 之例，略此像 RGB；透度与可见色逐道同。

今实图已取，固定版本、许可与原义已读，归档中诸图已逐一校同，SHA256 已录。豫言试源排版、静差与包述之验已过。类验、合构、运行差分，待根授窗。

[BMP Suite](https://entropymine.com/jason/bmpsuite/) 为 Jason Summers 所作，版本二点八，2023-11-28。固定发行包 SHA256 为 `f1b1f18c4f310b76bf317378e64f25b84f875a3d0976fab33ff10befdb35d13f`。十 BMP 与六 PNG 皆与其发行包原图校同。生成器未行。作者 README 言生成图像为公有领域，嵌入 ICC 者别论；此选常色诸图。作者说明原文随数据存。

[官方图录](https://entropymine.com/jason/bmpsuite/bmpsuite/html/bmpsuite.html) 明各图对应之 PNG。此选一、四、八位调色板，RLE4、RLE8，十六位默认五五五及五六五位域，二十四位真彩，三十二位默认及位域。源名、本地名与逐项对应，详汉语稿之表。
