# 位图与动图公开参考差分

`图像公开差分。测试` 以原作者提供的 PNG 为独立像素参考。静图入口接收位图路径和 PNG 路径。动画入口接收 `动图`、GIF 路径及依次排列的完整帧 PNG 路径，检查画布尺寸、帧数与每个颜色/透明分量。八位灰度、灰透明、红绿蓝与红绿蓝透明均在测试内按实际行距规整。双方透明度为零时沿用 GNOME 官方比较规则，忽略该像素 RGB；透明分量与可见颜色逐分量完全相等。

当前状态：2026-10-08 完成包检查、完整类型检查、一个公开差分入口构建，以及十张 BMP 和五组 GIF 的 Node 与同客体硬浮点原生验证。BMP 使用原 PNG 逐分量相等参考。GIF 三静帧使用原参考；处置二使用明确声明黑底条件，处置三先完整断言零延迟初帧再按展示时间对应四张参考，条件与原失败证据见《图像公开差分验收.汉语.md》。

本手工参考入口的精确单文件跳过规则登记于 `应用/开发工具/全树测试/测试规则.tsv`。默认 CI 由整包类型检查覆盖本入口源码；实际公开像素验收由逐项 Node 与同客体原生日志证明。

参数 `灰透明回归` 运行合成3×2、行距8的 `灰透明8` 图像，核灰色扩三通道、半透明、不透明与透明分量，以及PNG级零往返。Node与同客体原生实际通过。此参数用于测试规整分支回归，独立公开参考矩阵使用前述十五项记录。

## 动图来源与语义

GNOME gdk-pixbuf 固定标签 2.44.4，注解标签对象 `5aa7e738075b710ba6e3921c4411b0113b6436b4`，实际提交 `c9e6d11cbfa085d7b59dd6ad3b1cbfa26348ce13`。[官方测试数据目录](https://github.com/GNOME/gdk-pixbuf/tree/c9e6d11cbfa085d7b59dd6ad3b1cbfa26348ce13/tests/test-images/gif-test-suite)包含 GIF、逐帧 RGBA 数据、同名 PNG 及配置。配置中的 `.rgba` 文件与下表同名 PNG 为上游像素参考。原始配置及测试清单保存为数据，本文的帧对应以这些配置为准。

项目 `COPYING` 是 LGPL 2.1，完整原文已随测试数据保存。[上游测试程序](https://github.com/GNOME/gdk-pixbuf/blob/c9e6d11cbfa085d7b59dd6ad3b1cbfa26348ce13/tests/pixbuf-gif.c)另标 GPL 2 或后续版本、Copyright 2018 Canonical Ltd.；本任务读取其透明像素比较与配置语义，并用豫言独立编写入口。GIF 数据本轮保存项目整体许可；逐图单独许可声明留待上游补核。

处置三在原始 `TESTS` 默认清单中被注释，四张展示帧参考由上游提供，本轮两端实际核验。`动图黑底` 将处置二的二元透明参考合成到文件声明的黑色背景，再核尺寸、四帧、RGBA与500毫秒延时；`动图零时初帧` 完整核验处置三的零延迟2×2不透明黑色原帧，再核四展示帧与参考逐分量相同。五个GIF合计十二个原始合成帧，其中十一个有官方PNG参考；零时初帧由标准背景与原帧断言另核。生产GIF保持声明背景与全部原帧。循环字段与其余展示延时留待专项验收。数据目录 `样本指纹.原文.txt` 列出全部文件的实际 SHA256。

## 复验最短串行命令

在专属树根、完整同配工具链下构建一个入口：

```text
YY_BUILD_LOG=0 /opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 图像编解码 测试 图像公开差分。测试 --编译器 ./yy_bs_stable.wasm --输出 yy图像公开差分.wasm -j 24
```

静图示例，随后按表替换另外九对路径串行运行：

```text
/opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy图像公开差分.wasm 库/基础库/图像与图形/图像编解码/测试/公开样本/位图/四位游长.bmp 库/基础库/图像与图形/图像编解码/测试/公开样本/位图/四位参考.png
```

GIF 示例；其余静态 GIF 用 `动图` 给一张参考，处置三用 `动图零时初帧` 依次给四张处置三参考：

```text
/opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy图像公开差分.wasm 动图黑底 库/基础库/图像与图形/图像编解码/测试/公开样本/动图/处置二.gif 库/基础库/图像与图形/图像编解码/测试/公开样本/动图/处置二帧0.png 库/基础库/图像与图形/图像编解码/测试/公开样本/动图/处置二帧1.png 库/基础库/图像与图形/图像编解码/测试/公开样本/动图/处置二帧2.png 库/基础库/图像与图形/图像编解码/测试/公开样本/动图/处置二帧3.png
```

测试位于编解码包内，直接使用同包图像、解码器与参考便图模块；生产模块依赖关系保持原状。
