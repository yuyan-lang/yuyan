# 捷图公开参考差分

本入口把纯豫言统一解码结果与独立 `djpeg` 的八位 PPM 输出相比。解码类型为基线、渐进霍夫曼与算术，像素类型为灰度8、红绿蓝8、红绿蓝透明8。比较逐行使用图像行距，灰度扩为三相同通道。

`捷图公开差分。测试` 接收捷图路径、独立 PPM 参考路径，以及可选的 `方向二` 至 `方向八`。方向参数按 EXIF 的逆坐标在测试内独立索引参考图。`djpeg` 输出保持文件行序。比较输出颜色样本数和平方差总和，要求平均平方差不大于二，即峰值信噪比至少 45.12 dB，满足提案的 45 dB 门槛。

当前状态：真实公开样本已下载并校验 SHA256，差分源码轻格式化通过。类型检查、构建、`djpeg` 参考生成与差分运行等待根授予重窗口。文中命令是待验命令。

## 待窗最短命令

在专属验证树根，使用完整同配工具链，串行构建：

```text
YY_BUILD_LOG=0 /opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy豫构_stable.wasm 构建 图像编解码 测试 捷图公开差分。测试 --编译器 ./yy_bs_stable.wasm --输出 yy捷图公开差分.wasm -j 24
```

每张固定图分别运行参考器及纯豫言入口；以下展示 libjpeg-turbo 原图：

```text
/opt/homebrew/bin/djpeg -dct int -rgb -pnm -outfile /tmp/yy捷图公开参考.ppm 库/基础库/图像与图形/图像编解码/测试/捷图公开样本/彩像.jpg
/opt/homebrew/bin/node yy稳定节点宿主/宿主.cjs yy捷图公开差分.wasm 库/基础库/图像与图形/图像编解码/测试/捷图公开样本/彩像.jpg /tmp/yy捷图公开参考.ppm
```

表内其余十四张捷图依次替换路径；方向六公开在入口末尾加 `方向六`。PPM 原始彩像用于新质量矩阵的编码输入。静态样本已经覆盖 4:4:4、4:2:2、4:2:0、灰度、CMYK、YCCK、EXIF、霍夫曼渐进、重启与顺序算术。

质量矩阵待窗用 `cjpeg -quality 25/90/100 -sample 1x1/2x1/2x2` 分别生成彩像；再以 `-progressive`、`-arithmetic`、`-progressive -arithmetic`、`-grayscale` 补各分支，随后使用同一 `djpeg` 命令与差分入口。生成结果的实际 SHA256 与运行结果由验收窗口记录。

公开参考器参与测试数据生成与对照。生产模块仅依赖豫言库。
