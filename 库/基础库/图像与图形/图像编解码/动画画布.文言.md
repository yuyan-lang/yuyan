# 动画画布

动画画布为图像编解码包内共用之合成模块，依标准库及同包图像数据，沿用图像编解码在图像与图形基础库之登记。

调用者分配每像素三十二字节之零初字节缓冲，存双精度直通红绿蓝与透明度四分量。输入为红绿蓝透明8或红绿蓝透明16，十六位以小端存之；行距取诸图像。调用者核格式、画布尺寸与帧矩形之界。

`动画画布合像` 受输入图像、画布缓冲、画布宽、左上偏移、替换爻与起始像素序。替换阳则写来源，阴则透明覆盖。`动画画布填区` 受画布、画布宽、矩形位置尺寸、打包RGBA8色与起始像素序，以色填背景。起始像素序皆用零。

`动画画布出图` 受画布、宽、高与十六位爻，出紧排红绿蓝透明8或红绿蓝透明16。合成内值存双精度，出帧乃限于零至一而四舍五入量之。覆盖结果透明度零者，色归零；来源替换则存输入之透明隐色。

此源随网图联合构建及实运皆过，核透明混合处置及透明度一百次覆盖末值八十三。其日志存于受信开发机 `/tmp/yy网图联合构建.log` 与 `/tmp/yy网图联合运行.log`。十六位动画调用者之独验列后续之队。
