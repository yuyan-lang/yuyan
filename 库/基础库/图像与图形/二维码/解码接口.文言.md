# 解码接口

既有字节接口之回归、独立条码对照及实拍图识别，皆于诺节及原生校之而过。新增结构控制段接口过包验、类型验及诺节基本冒烟，常规测试接CI。全量之核列后续验收。

字节解码之口还 `二维码解码结果`：`二维码解码成功` 携字节串，`二维码解码失败` 携中文告辞。数字及字母数字段还 ASCII 字节，字节段存原内容；汉字段还 Shift JIS 双字节码。UTF-8 之 ECI 26 与 ISO-8859-1 之 ECI 3 可随字节段而用。

`解码二维码矩阵` 受 `二维码矩阵`，校版号、边长、模块之数，取两份格式字段，以 BCH 校之；继取码字、解交织、行里德所罗门解码，复其数据段。纠错用有限域综合、伯莱坎普—梅西误位多项式、钱氏搜根及有限域方程求误幅。

`识别二维码` 受统一图像，入式为灰度8、红绿蓝8、红绿蓝透明8。以整数灰度及全局阈值二值化，横扫定位图形而纵校之；三定位中心定方向及版号。第二版以上取右下校准图形为第四点，第一版取定位外环角点推第四中心；四点单应之变定模块中心，而矩阵解码终其校验。

`解码商品条码` 受九十五二值模块，校 EAN-13 首尾及中护条、左侧奇偶之式与校验位，还十三 ASCII 数字。`解码一二八条码` 受二值模块，校起符、终符及模103校验和，行 Code 128 之 A、B、C 集及临时移位，还零至二五五之原载荷字节。FNC4可暂变一字，亦可用双符出入扩态；临移及代码集之变皆从制式。FNC1、FNC2、FNC3以结构控制段接口还原。

`识别商品条码` 及 `识别一二八条码` 受统一图像。于画面高之二分之一、三分之一、三分之二处横扫，除两端留白，以最细条空估模块之宽，就近归一，依次校顺向、逆向模块。

后续待验及增广之事：不均匀照明之局部阈值；甚斜及定位外环破损；一维条码斜向扫线；其他 ECI 指派、二维码分段追加、二维码FNC1。

定向量取 Thonky 原创码字及成图、ZXing 原创 EAN-13 及 Code 128 之试。真实拍摄图用 ZXing `qrcode-1/1.png`，原文件藏仓外豫言数据之处。所出、版本与许可见包说明。
# 功能控制段

「一二八数据段」有「一二八字节段」、「一二八功能一」、「一二八功能二」、「一二八功能三」。「编码一二八条码段」受段列而出二值模块；「解码一二八条码段」成则以「一二八段解码成功」载段列，败则以「一二八段解码失败」载汉语诊断。相邻字节合段，诸控制之位皆存，空字节段解时归并。

FNC1表GS1识别及分隔；FNC2表消息附加，读器合此消息于次条码；FNC3表读器初始化。用者察段，依读器之约而处之。二四一至二四四于字节段皆为数据；FNC4为扩字节之变，存于编码之内。旧字节解码遇FNC1、FNC2、FNC3，则出专用接口之诊断。段编码用A/B集，段解码受A/B/C集之制式控制。

常规CI入口「测试/功能控制段。测试。豫」校定符列及独算校验五十，复校公开段接口往返。控制义参[JIS X0504:2014第四点三点四节](https://kikakurui.com/x0/X0504-2014-01.html)，采用ISO15417:2007。
