# 解码接口

此接口已过类型之验，相关回归、独立条码对照与实拍图之识别，皆于诺节及原生校之而过。全量之核列后续验收。

诸解码之口皆还 `二维码解码结果`：`二维码解码成功` 携字节串，`二维码解码失败` 携中文告辞。数字及字母数字段还 ASCII 字节，字节段存原内容；汉字段还 Shift JIS 双字节码。UTF-8 之 ECI 26 与 ISO-8859-1 之 ECI 3 可随字节段而用。

`解码二维码矩阵` 受 `二维码矩阵`，校版号、边长、模块之数，取两份格式字段，以 BCH 校之；继取码字、解交织、行里德所罗门解码，复其数据段。纠错用有限域综合、伯莱坎普—梅西误位多项式、钱氏搜根及有限域方程求误幅。

`识别二维码` 受统一图像，入式为灰度8、红绿蓝8、红绿蓝透明8。以整数灰度及全局阈值二值化，横扫定位图形而纵校之；三定位中心定方向及版号。第二版以上取右下校准图形为第四点，第一版取定位外环角点推第四中心；四点单应之变定模块中心，而矩阵解码终其校验。

`解码商品条码` 受九十五二值模块，校 EAN-13 首尾及中护条、左侧奇偶之式与校验位，还十三 ASCII 数字。`解码一二八条码` 受二值模块，校起符、终符及模103校验和，行 Code 128 之 A、B、C 集及临时移位，还 ASCII 及控制字节。

`识别商品条码` 及 `识别一二八条码` 受统一图像。于画面高之二分之一、三分之一、三分之二处横扫，除两端留白，以最细条空估模块之宽，就近归一，依次校顺向、逆向模块。

后续待验及增广之事：不均匀照明之局部阈值；甚斜及定位外环破损；一维条码斜向扫线；Code 128 之 FNC 及扩展字节；其他 ECI 指派、二维码分段追加、FNC1。

定向量取 Thonky 原创码字及成图、ZXing 原创 EAN-13 及 Code 128 之试。真实拍摄图用 ZXing `qrcode-1/1.png`，原文件藏仓外豫言数据之处。所出、版本与许可见包说明。
