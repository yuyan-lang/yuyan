# 解码接口

本接口已通过类型检查，相关回归、独立条码参照和真实照片识别已在诺节与原生通过。全量核验列入后续验收。

所有解码入口返回 `二维码解码结果`：`二维码解码成功` 携带字节串，`二维码解码失败` 携带中文诊断。数字与字母数字段还原 ASCII 字节，字节段保留原始内容；汉字段还原 Shift JIS 双字节码。UTF-8 的 ECI 26 与 ISO-8859-1 的 ECI 3 可以随字节段使用。

`解码二维码矩阵` 接受 `二维码矩阵`，核对版号、边长、模块长度，读取两份格式字段并按 BCH 校正，提取码字、去交织、执行里德所罗门解码，再还原数据段。纠错采用有限域综合、伯莱坎普—梅西误位多项式、钱氏搜根与有限域方程求误幅。

`识别二维码` 接受统一图像，输入格式为灰度8、红绿蓝8、红绿蓝透明8。二值化采用整数灰度与全局阈值，横向扫描定位图形并做纵向核对；三个定位中心确定方向与版号。版本二以上以右下校准图形确定第四点，版本一以定位外环角点推估第四中心；四点单应变换确定模块中心，矩阵解码完成校验。

`解码商品条码` 接受 95 个二值模块，核对 EAN-13 的首尾与中心护条、左侧奇偶模式和校验位，返回十三个 ASCII 数字。`解码一二八条码` 接受二值模块，核对起始符、终止符和模103校验和，支持 Code 128 的 A、B、C 集及临时移位，返回 ASCII 与控制字节。

`识别商品条码` 与 `识别一二八条码` 接受统一图像。它们在画面高度的二分之一、三分之一、三分之二处取水平扫线，去掉两端留白，用最细条空估计模块宽并就近归一，依次核验正向与反向模块。

待后续核验与扩充：不均匀照明的局部阈值；严重倾斜与定位外环破损；一维条码斜向扫线；Code 128 的 FNC 与扩展字节；其他 ECI 指派、二维码分段追加、FNC1。

固定向量采用 Thonky 原创码字与成图、ZXing 原创 EAN-13 与 Code 128 测试。真实拍摄图使用 ZXing `qrcode-1/1.png`，原始文件保存在仓外豫言数据目录。来源版本与许可见包说明。
