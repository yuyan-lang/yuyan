# 二维码

二零二六年十月八日实量性能：同一客体于本机Apple M5 Pro、十八核、Node26.3.0及同源原生行之，以定网址、高纠错，解矩阵十万次、识图千次。公共基准器预热三次、复试九次，含启程及构造之全程序中位，原生为58.213617秒，诺节为46.270458秒。单轮热点，原生各为38.296322秒、18.406359秒，诺节各为52.422532秒、9.974274秒。其时别有开发之事并行，机负载、客体摘要及全日志见《性能核验记录》；同机C实现之对照，列后续测量。

图像定位以七模块原宽之加权均值推其版，至算边长之末乃作整数除法。独立Nayuki第七版、高纠错、掩模零之二零二五模块及公开图像识别，已于诺节及同客体原生校之而过；其图经公共线代LU造四角透视之变，两端皆准采第七版而识ABCDEF。来源及全摘要见《高版参照核验记录》与《高版透视核验记录》。

以豫言成 QR Model 2 之编码。版自一至四十，纠错四等，受数字、字母数字、字节、汉字四式与统一码 ECI，出模块矩阵及灰度图。

汉字式受 Shift JIS 双字节码。统一码之文以 UTF-8 字节段及 ECI 二六入码。

`编码二维码段` 受段列、纠错等、最小版、最大版及掩模。纠错等依 L、M、Q、H 为零、一、二、三；掩模为零至七，负一则按四项罚分择之。成则 `二维码编码成功` 携矩阵，败则 `二维码编码失败` 携告。矩阵之 `模块` 按行藏字节，黑为一，白为零；`二维码矩阵模块` 以横纵之坐标取色。

`编码二维码文字` 择足容 UTF-8 之文之最小版。`二维码转图像` 受矩阵、整数倍率及留白模块数，出 `灰度8` 图。分享之图留白四模块。

网址分享之例，以 `豫构 构建 二维码 分享示例 --输出 yy二维码分享.wasm -j 24` 造之，复以节点宿主行 `yy二维码分享.wasm 网址 yy分享二维码.pgm`。出 PGM 灰度图。

已验原创教程 HELLO WORLD 1-M 之数据及纠错码字、1-Q 成图之四四一模块、汉字及 ECI 位流、格式与版号校验位、四十版四等之功能区容量，及图之倍率留白。网址分享之应用入口已于诺节构建运行。同客体已于诺节及原生运行校验。

矩阵解码、里德所罗门纠错、图像定位、四点透视采样、EAN-13 及 Code 128 编解码与灰度扫线识别皆已成。六版四等八掩模凡192组、五误码之校、独立条码模块及 ZXing 原始拍摄图，皆于诺节及原生校之而过。详见解码接口。

后续验收事项：百万变异、性能之比及裸机之验。独立首版透视图由公共线代LU造之，识别已于诺节及原生校之而过。

后续校验向量取 ZXing `EncoderTestCase.testEncode` 之 ABCDEF 1-H、掩模0成矩阵（2026-10-08快照，Apache 2.0）。源码存全441模块，并直以原创条码模块向量校解码及扫线；此441模块已于诺节及原生逐项校之而过。

制式参数据 [QR Code generator](https://www.nayuki.io/page/qr-code-generator-library)、ISO/IEC 18004 校之；码字据 [Thonky 原创教程](https://www.thonky.com/qr-code-tutorial/error-correction-coding) 校之。

对照数据之记：Nayuki 之 QR 制式参表取二零二六年十月七日所见主分支，原代码许可以 MIT 为则。Thonky 码字教程更新于二零二一年十一月九日，成图教程更新于二零二三年二月二十日，网站许可以 CC BY-NC 4.0 为则；测试表藏 QR 之制式定值。Code 128 之条空参及 EAN-13、Code 128 之对照模式，取二零二六年十月七日所见 ZXing 主分支，原代码与测试许可以 Apache 2.0 为则。外图之原本藏于仓外豫言数据之目录，采样校验之器以豫言造之。

ISO/IEC18004:2015附录I.2数字01234567之十六码字、十纠错码字及四四一成图模块皆已校。全模块取[JIS X0510:2018采用稿](https://kikakurui.com/x0/X0510-2018-01.html)原书成图之独立像素，以公开编码入口依第一版M等及所给第二掩模造矩阵，于诺节及原生逐项校之而过。原标准版权归其发布者，原页藏仓外，仓内惟藏制式定值及豫言采样器。

Code128字节串接口存零至二五五全数据值，FNC4之一字扩变、双符扩态及暂还低字节皆已成。旧接口以诸入字节为数据，二四一至二四四诸值亦皆存之。独立ZXing testEncodeWithFunc4之七九模块、全二五六字节往返、双扩态、FNC4后临移及非法控制阶段之严拒，已于诺节及原生校之而过。FNC1、FNC2、FNC3控制段接口，列后续事项。参据ZXing定提交33dfdefcb35576612841e614d44ba9edc9aee2b5之Code128Reader及Code128WriterTestCase，许可以Apache2.0为则；控制态规范见JIS X0504:2014采用ISO15417:2007第4.3.4节。
