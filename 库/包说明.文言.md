# 共用库

「豫言基础库」录提案零零零零四之十二组基础库，居 `库/基础库/`。

此 `库/` 之父包也，唯有包述与此说，无模。以「包含包」登 `库/` 下众用之高级库、安全外壳之组（父包「安全外壳」），及诸库 `测试/` 下之试包。

- 应用与库径依所需之库；依此包者，并依其下诸库类之包。
- `底层库` 为底层之模；父与库子其模必同，故自成一根，登于此包之外。依底层库之底层库 `中央张量内核` 亦自成一根；其试「中央张量内核测试」与供网页宿主之「中央张量内核模块」皆为可执行之包，登于此包之下。
- 试包依所试之库，登于其下则成环，故登于此包。
- 于 `库/` 增众用之库或试包者，必登于此包之「包含包」，新包书「包含在」。

欲览诸包之层级：`node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 发现 --树`。
