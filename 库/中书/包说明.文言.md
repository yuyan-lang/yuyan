# 壳核心

## 壳命令之豫言句（二〇二六年十月十一日，提案〇〇〇〇三第八步）

壳之输入易为壳命令之豫言句，正式句式退：字符串之参书于 `『』`，「行」之参书参之列（`「行」于『/程序/你好.wasm』于「列」【『甲』】`），列出须书径（`「案牍」之「列目」于『.』`），演示之「加」去之（即标准库之加，当于豫构交互行之）。十月十二日起全系统惟一壳：命之行在系统壳（豫构交互之会话，十月十四日起每句皆编而行；无编译器之宿主上之旧开机壳用库 壳命令 之「行壳令句」），本包旧之「解析登记命令」「执行登记行」「基础命令输出」与帮助之文删之，命令登记之表惟供输入之候选与补全。编辑时「验自由参」裹自由之参以 `『』`（纯数裹以 `「」`）；于参之位（于之后）按 `{` `}` 入 `『』`，所择参之候选亦填为 `『…』`；「正式令位」识 `『』` 与参之列，参之列中查询之文为游标所在之一项（「行」之参补仍可用）。本包故依壳命令。

`运行补全。豫` 存所同步之环境快照。`同步而行补全水土` 受 `环境条目们`；`行补全参名` 受正式命令输入，归所登程序之候选列；`运行补全位置索引` 接候选于已有位置索引。键 `命令补全：<程序路径>` 之空白词表用于正式 `运行` 参数序一及其后。设同键则易候选，取消则复旧候选之规，诸程序依全路径各登；参数序零仍取程序路径候选。`测试/运行补全。测试。豫` 验设置、覆盖、取消、异程序及路径位。

拼音候选复用「中文处理/输入」全拼词频索引，存旧首项及九项分页；二〇二六年十月二十二日起拼音惟给此段之字词，不复混已知之名于候选（独打 `?` 展全选时仍用已知名之索引）。已知名索引复用「中文处理/拼音」多音词组之映射。

此迁以官方 5cfa 同包诸器核之，原包 SHA-256 为 `ce0116000f43f4840aa9da23e93a771dd1dc385ae1fec6908b426bc28d9815a2`。全壳核心之类型皆过。智能候选二十三调用断言实试而过，及重庆银行多音全拼与首字母、豫言语言之序；初置并运行十七点九八秒，峰值常驻内存七九六八六八六〇八字节。旧用户态桌面图形命令行二十五回归皆过，及分页、翻回、回绕、第十候选与翻页之示；初置并运行十七点八六秒，峰值常驻内存七九九五〇六四三二字节。两测以节点宿主行之，含全籍初解与立索引。

原生之行、官方全对照及提案甲乙之验，续行于后。

旧 `拼音字库。豫` 今供裸机字模生成器循源文件读之，其迁界待后续。壳运行候选与已知名索引，皆已接中文处理之术。

`命令环境。豫` 供别于宿主与储存之环境态法：设同名则易旧值，取消所名，循序成环境正文。久存之行惟以首等号分，存值中等号与空值。图形命令行以会话引用存诸项，行子程序则传公接口；原壳设与取消亦用此法，犹存于 `/.环境`。原壳旧宿主文件与子进程之调犹未迁。

正式命增 `「图形」`，无参，经平台处理回调启桌面；帮助与当位候选共一登记。控制台调共用用户态桌面库，桌面止则归旧命令之循环。图形命令行内复启桌面尚未接，今服务明报不可用。

`组字确认。豫` 收自控制台析出之候选确认纯法，受标左右文、位置、候选果与序，还新左右文。既有外引之内，紧承 `「` 之词自补 `」`，既有文字后之续词就位入之而存右文。壳之逐键编辑之器（`交互输入`，开机壳、豫构交互与桌面终端中之会话共之）用此以处独打 `?` 所展之已知名；常拼音之字词不补外引，原样插于标处，惟去标前之拼音。

此控制台壳与图形命令行共用之普通豫言库也，惟依标准库。旧裸机壳之命令位置、命令登记、命令补全、智能候选、拼音输入及字库徙于此包，共用一实。

命令位置析文而存引内之连接词，登记定正式成员与参。二〇二六年十月二十二日起常拼音惟给此段之字词，不复先列当位已知之名；独打 `?` 与 Tab 补全仍列已知之名。开机壳组字之态（组字拼音、候选页号）犹为会话之引，桌面命令行置同态于终端之态。

此包不行文件与进程之术，不取显示面，不直调内核与设备。编辑行之控制台重画、文件与进程服务仍在调用者；拼音篇惟置两端共用之法与开机壳组字之态，控制台之示由调用者印之。拼音与智能候选各寻其篇，默认导入含 `令籍`、`令位` 二模，出命令登记与位置解析。

试在 `测试/`，徙旧壳三试，验位置解析、命令登记与当位候选。旧壳之交互编辑与上下文输入诸试仍验控制台之接；徙后当重构而行。

## 逐键编辑（十月十六日）

`交互输入。豫` 为壳之逐键行编（拼音组字、候选、补全、旧行、移标），自用户态桌面徙来：全系统唯一壳，宿主原生之豫构交互、豫行启动器中之豫构交互与豫言操作系统之开机壳皆用此一份。「闻言」于提示读一行：印其提示，读行之时终端入原始之模（键逐字而至），读毕复其旧模；得可有此行，空行按 Ctrl+D 或标准入已闭得可无，Ctrl+C 弃此行而得空行；不能入原始之模（标准入为管）则仍逐字而读。豫构交互之组字之入（`豫构 交互 --组字`，标准入为终端之默）用之。读行之前先办「候键余事」一次；「候键不止」为阳（豫言操作系统之开机壳：控台无尽）则不得键不为入尽，办「候键余事」毕而复候。「候键中止」为阳（「候键余事」所设，十月十七日）则「闻言」「直闻」办毕余事不复候键、得可无；「读行被中断」记此行以 Ctrl+C 终否：壳行子程之时，子程终或入原始之模则令读行跃出，以 Ctrl+C 终之行用以断子程（见「几席」之「伴行循环」）。「纯文组字」为阳则组字以入行为常文，Tab 不补；二〇二六年十月二十二日起拼音惟给字词本为默法，此格惟存子程之入之意。「直闻」为直读之入于开机之控台之读行（十月十六日）：逐键原样收字，不经拼音组字、候选与补全，回显、退格，回车得此行，Ctrl+C 弃此行；读键之原语候键时兼办子任务之信，开机自启之远程登录不止。「读取中文交互行」为旧壳（`豫言操作系统/裸机/壳`）之读行：不得键则呼「候键余事」而复候。「待读行」藏壳伴子程时所读、子程适已毕之一行（十月二十三日，议四百零六），「闻言」次读先出之，以为壳之次句（见「几席」之「伴行循环」）；读半而子程毕，则「续读行」藏其半行，次读续之。径参之候选取进程今目之下之名（系统壳之「案牍」之「迁」同进程之今目）；运行补词之环境之文取「水土来处」，默为空，开机壳登为读已授“桌面”根之 .环境。编辑之器读终端之键、易终端之模、列今目。

入行重绘，先书回首、提示、全文，乃补空以擦旧尾，复回首、提示、左文，标停左文之后。补空之数取宽差与字差之大者：真终端与浏览器之终端依宽定位（全角二格），桌面之终端仿依码点定位，取大者两边皆净。二〇二六年十月二十二日起，重绘毕与印提示毕皆呼 `画光标`：豫言操作系统之开机壳设为书一 NUL 之字，帧缓控台见之则绘竖线；真终端与桌面终端之仿自示光标，默则无为。

## 共用命令之行

`命令执行。豫` 今唯存诸处所共之二小函：「去脚本注」（脚本之注同豫言之源）与「基行尾」，唯依标准库。旧受壳命、依登记析参、帮助与回显之术，随正式之句退役而删；十月十六日复去无用之 `令籍`、`令位` 之导：系统中诸部之法几皆导此篇，带之则并装拼音输入、智能候选与中文处理之拼音表（约二十兆字节之单元）于每部。

共用执行之试含引内空格与连接词、加法、平台参之授、退出与参误，已构建而行，皆过；旧控制台壳构建亦过。

## 共用引号之入

`引号输入。豫` 收旧控制台之引栈与快捷键法，两端共用一实。左花括号循标左未闭之层择「或『（外层在参之位则出『），右花括号闭当层。图形文框以编辑前后全文辨单字之入；整段粘贴与替换存原文，已有当闭之引则不重入。

共用法之试与旧控制台上下文输入之验皆过，图形桌面类型之查亦过。

## 通配之 ? 与展全部之选

二〇二六年十月十一日起，`?` 作常 ASCII 之入：如字母书于输入之行，计于标前之拼音（拼音之串以字母与 `?` 成之）。以拼音解之，`?` 为通配，合任一段（可空）。已知之名（名之文、全拼、首字母）依通配前缀较之（`拼音输入。豫` 之 `百搭前缀`），故拼音惟一 `?` 即展光标处诸已知之选，同网页工作台；字词依整键通配查全拼候选表（中文处理 `输入` 之 `全拼百搭候选`：依首 `?` 前之字面前缀二分求其一片键，收整键相合之行，先短后长，至多三百）。二〇二六年十月二十二日起带字母之拼音（如 `tu?`）惟查字词，不复先给“图形”“退出”诸已知之名；`h?o` 仍给“好”。按 Esc 则此串（含 `?`）亦作英文留于行，故欲入 `?` 本字，打 `?` 而按 Esc。`拼字候选行` 生两端同一之候选行，拼音惟 `?` 则书“当前位置全部选项：…”，常书“拼音：… 候选：…”；方打之 `?` 令拼音惟余一 `?` 而当位无已知之选，则示一行 `无全选提示`，`?` 如常留于行。以 `?` 起之模不查拼音之表，留待后版。开机壳上下文输入之试与桌面命令行之试，覆展开、择定、翻页、成员之位、退格删 `?`、`tu?` 通配、`?` 后 Esc 与无选之示。

## 行内拼音

二〇二六年十月十日起，开机壳与桌面命令行恒以中文组字，无中英之易（F2 与 Ctrl-R 不复易之）。拼音即输入之行中标前相续之 ASCII 字母：字母径书于行，候选依此串即时给之；退格如常删行中之字，拼音随短；有候选则一至九、空格、回车择字，以所择之字词代此串字母，翻页之键如故；无候选则空格、数字如常入之，回车行此行。二〇二六年十月二十二日起拼音惟列此段之字词，不复列已知之名，所择之字词原样插于标处，惟易标前之拼音，标后之文一字不易。择字惟填入，再回车乃行。

两端各记拼音起点（码点之位），惟标前、起点之后相续之字母与 `?` 乃为拼音。Esc 移起点于标处，此串（含 `?`）遂作英文留于行，不复出候选，后打之字母别起一段拼音；移标、取史、补全与择字亦移起点于标处；退格越起点，则起点随退于标处。`拼音输入。豫` 之 `为拼音字`、`行内拼音长`、`去尾字`、`取尾字`、`百搭前缀` 为两端共用之纯法；`智能候选。豫` 之 `行内拼音候选` 依标左之文与拼音长给候选：常惟给此段拼音之字词，拼音惟一 `?` 乃同 `今位候选` 展已知之名。开机壳上下文输入之试与桌面命令行之试，覆字母入行、退格、Esc 留英文与别起拼音、移标、无候选则回车行之、择字原样插入与右文不动。

`{ }` 仍依层入角引或双引；方入之括后紧按 Esc，则易回 ASCII 之 `{` 或 `}`（`}` 越既有之闭引，则于原处书 `}`）。两端各记引号撤回一条（入前之文与当易回之字），他键皆清之；独按修饰之键得零者不清。逐字而至之方向键以 ESC 起，紧于 `{ }` 后按方向键则作 Esc，留待后版。
