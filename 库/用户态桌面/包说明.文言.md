# 用户态桌面

此开机命令壳与[平铺桌面](../平铺桌面/包说明.文言.md)所共之常豫言库也：命令之会、图形命令行、文件浏览与文件之服、标记文预览、任务管理器、系统设置与设置之久存、环境之文。库经系统接口取宿主之能，不径涉内核之存与设备。二〇二六年十月十日起桌面为平铺桌面（提案 00014）：旧之浮窗（窗形之表、题栏之拖、右下之伸缩、置顶与轮换）与「运行用户态桌面」皆删之，此之图形命令行、文件浏览、任务管理器与系统设置皆为平铺桌面之格程。

## 诸模

| 模 | 所司 |
| --- | --- |
| `命令壳` | 开机命令壳与桌面终端共之命令之会：当前路径、环境（已授“桌面”根之 `.环境`）、命令登记诸正式命之行、用法与误示；桌面终端之异步「运行」与询（未成行之余文依子程序之柄分之） |
| `命令服务` | 文件之命：目录、列、读、写、追加、复制、移动、建、删、切换 |
| `子程序服务` | 桌面终端之台「桌面命令平台」：命付 `命令壳`，「运行」异步启之，「脚本」逐行行之 |
| `终端类型` | 终端之型与轻部：终端之态、终端之消息、终端之台、输出之续、开场、终端之视与「终端程序」（更新、视、询、行之函组）；不引壳核心之组字与拼音之表，浏览器中之平铺桌面惟链之 |
| `图形命令行` | 终端之更新（拼音组字、候选、历史、行与询）；「终端程序于平台」以平台组终端之程 |
| `文件浏览`、`文件服务` | 浏览之服（列目录、读文）及授权目录之文读写；工作台亦用之 |
| `标记文预览` | 共用之 Markdown 预览 |
| `任务管理器` | 任务采样之视 |
| `系统设置`、`设置持久` | 字体之设及其于授权目录 `yy桌面设置.数据库` 之久存 |
| `环境文件` | `.环境` 之读写 |

包之默认导入为 `命令壳`。

## 终端同开机命令壳（二〇二六年十月九日）

终端之格与开机命令壳共一命之处（`命令壳。豫`）：同一当径，同一环境，命令登记之诸正式命、用法与误示皆同，含「运行」「设」「取消」「环境」「日期」「脚本」。二者惟「运行」有别：开机壳同步行之，子程序径书控制台；终端经公共子程序接口〇点六异步启之，依时以「取子程序输出」取新出（连询无新出则其间逐次倍之，自二百五十毫秒至多二秒；有新出即复二百五十毫秒），造盘之类久行之程随时示其进。程序行时输入之框停用。裸机之上，出见捕之程以“承出”复起之子程序，其出随其程之出，不书屏之控制台。「脚本」逐行行之，遇「运行」则候其毕乃行次行；脚本之注同豫言之源，书于「：与：」之间，可跨行、可嵌套。终端中「图形」示已在桌面，「退出」闭此终端之格。

输入同开机壳：行命时回显 `壳> 命`，脚本之行回显 `+ 行`；中文之模，字母入拼音之缓，候选行示“拼音：… 候选：…”，? 或 ？ 展光标处诸已知之选（候选行示“当前位置全部选项：…”，无已知之选则于输出示之），空格或回车择当页之首，一至九择字，= 、- 翻页，退格删拼音，Esc 罢组字，F2 易中英而于输出示之；径参之位之候选取壳之当径；回车先补自由参为角引之文，再回车乃行。输出区存最新三百行，排最新百行，每行至多示千字。裸机与原生执行器随时交新出；诺节与浏览器于程毕时一并示之。设或取消环境后，同步壳核心之运行补全登记。

## 文件浏览与预览

浏览之服之径为授权目录内以正斜线分之相对径，空文为根。`文件浏览` 之浏览之态与视（径框、条目、Markdown 与豫言源码文档之预览）存以供验与后之格；平铺桌面之文件浏览格用工作台之资源侧栏。`标记文预览` 共用于工作台与预览：标题、列表、引用、围栏代码、行内代码、粗体、链、表格与转义标点。

## 设置

启时自授权目录之 `yy桌面设置.数据库` 复其字体，择字体则经嵌入数据库之写事务交之；惟读或未授则存此会之设。默认字体为随发行之文楷，又有无衬线、衬线、等宽三标准族名。

## 验证

`测试/` 中之模型之验（图形命令行、命令服务、文件浏览、系统设置、设置持久）可以诺节径行之；文件服务、环境文件、继承输入须绑实宿主（全树测试惟检之）。诸平台之记见 `原生接入.汉语.md` 与诸宿主之说。
