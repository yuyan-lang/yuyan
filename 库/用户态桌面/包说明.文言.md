# 用户态桌面

此独立桌面客与控制台共用之普通豫言库也。旧窗口态、文件浏览、文件服务、图形命令行、命令服务与桌面视图自图形桌面可执行包徙此，存同一实；诸篇依包名寻之，总集惟出同步运行入口。

`运行用户态桌面` 以旧显示、字体与文件接口取能力，行可止主循环；返回之钮止此桌面而归调用者。库直依界面、自绘与壳核心，用标准库，不直取内核内存与裸机设备。平台未供能力，则接口还误；为库未证诸平台皆已供之。

旧桌面诸试随实徙于 `测试/`，直试此库。文件服务之试须绑实宿主与所授验收目录；余模型之试可用普通工具宿主。徙后构建、态与实图形诸验须重行。

徙后库类型之查、窗口、浏览、命令服务、桌面退出与图形命令行诸验皆过；原壳入口构建与图形命登记之试亦过。实 Node 发行调此库，后台文件读取与历史复行出中文正文，返回之钮常止，绘录为 `yy共用桌面库后台.png`。

今用显示零点三版之归还，正常止则闭此节点窗，存授权以供复启。宿主之试验旧号失效、积事清除、等待之止、他面之存与新号之授；真SDL后台验中，同一Wasm程序连调两次桌面，皆归调用者前销此窗，并行归后中文之标。入口在 `测试/会话启停。测试。豫`，以临时发行绑实宿主而行，全树试录为只检查。原壳全输入会话、浏览器实界面、他系统与语言异常之收犹待验。
