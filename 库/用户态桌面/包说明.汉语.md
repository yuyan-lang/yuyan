# 用户态桌面

这是独立桌面应用与控制台共用的普通豫言库。现有窗口状态、文件浏览、文件服务、图形命令行、命令服务和桌面视图从图形桌面可执行包移入，保留同一份实现；各模块按包名导入，总集只导出同步运行入口。

`运行用户态桌面` 通过既有显示、字体与文件接口取得能力，运行可停止主循环；返回按钮结束本次桌面并回到调用方。库直接依赖界面、自绘与壳核心，使用标准库，不直接访问内核内存或裸机设备。平台尚未提供相应能力时由接口返回错误；库化不证明所有平台已经提供这些能力。

现有桌面测试随实现移入 `测试/`，直接测试本库。文件服务测试需绑定实际宿主与授权验收目录；其余模型测试可由普通工具宿主运行。迁移后的构建、状态与实际图形验收须重跑。

迁移后的库类型检查、窗口、浏览、命令服务、桌面退出和图形命令行回归通过；原壳入口构建与图形指令登记测试通过。实际 Node 发行调用本库，后台文件读取与历史重放输出中文正文，返回按钮正常结束，绘制记录为 `yy共用桌面库后台.png`。此验为独立应用；原壳同进程运行仍待实测，当前公共显示接口没有归还能力，停止循环后宿主面仍被保留，须补归还后验证反复启停。
