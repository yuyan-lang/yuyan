# 用户态桌面

这是开机命令壳与[平铺桌面](../平铺桌面/包说明.汉语.md)共用的普通豫言库：命令会话、图形命令行、文件浏览与文件服务、标记文预览、任务管理器、系统设置与设置持久、环境文件。库通过系统接口取得宿主能力，不直接访问内核内存或设备。2026-10-10 起桌面是平铺桌面（提案 00014）：原来的浮动窗口（窗口形表、标题栏拖动、右下角缩放、置顶与轮换）与「运行用户态桌面」已删去，这里的图形命令行、文件浏览、任务管理器与系统设置都作为平铺桌面的格子程序使用。

## 模块

| 模块 | 内容 |
| --- | --- |
| `命令壳` | 开机命令壳与桌面终端共用的命令会话：当前路径、环境（已授“桌面”根的 `.环境`）、命令登记里全部正式命令的执行、用法与出错提示；桌面终端的异步「运行」与轮询（未成行的输出余文按子程序句柄分开） |
| `命令服务` | 文件命令：目录、列、读、写、追加、复制、移动、建、删、切换 |
| `子程序服务` | 桌面终端的平台「桌面命令平台」：命令交给 `命令壳`，「运行」异步启动，「脚本」逐行执行 |
| `图形命令行` | 终端的状态、更新与视图（拼音组字、候选、历史、输出） |
| `文件浏览`、`文件服务` | 浏览服务（列目录、读文本）及授权目录上的文件读写；工作台也用它们 |
| `标记文预览` | 共用 Markdown 预览 |
| `任务管理器` | 任务采样的视图 |
| `系统设置`、`设置持久` | 字体设置与它在授权目录 `yy桌面设置.数据库` 里的持久化 |
| `环境文件` | `.环境` 的读写 |

包的默认导入是 `命令壳`。

## 终端与开机命令壳一致（2026-10-09）

终端格与开机命令壳用同一套命令处理（`命令壳。豫`）：同一个当前路径，同一份环境，命令登记里的全部正式命令、用法与出错提示都相同，包括「运行」「设」「取消」「环境」「日期」「脚本」。两处只在「运行」上分开：开机壳同步运行，子程序直接写控制台；终端经公共子程序接口 0.6.0 异步启动，按计时用「取子程序输出」取回新输出（连续没有新输出时间隔逐次加倍，从 250 毫秒至多 2 秒；有新输出即回到 250 毫秒），造盘这类长时间运行的程序随时显示进度行。程序运行期间输入框停用。裸机上被捕获输出的程序以“继承输出”再起的子程序，输出跟着该程序的输出走，不写屏幕控制台。「脚本」逐行执行，遇到「运行」等它结束再执行下一行；脚本注释与豫言源码相同，写在「：与：」之间，可以跨行、可以嵌套。终端里「图形」提示已在桌面，「退出」关闭这个终端格。

输入与开机壳一致：执行时回显 `壳> 命令`，脚本行回显 `+ 行`；中文模式下字母进拼音缓冲，候选行显示“拼音：… 候选：…”，空格或回车选当前页首项，1-9 选字，= 、- 翻页，退格删拼音，Esc 取消组字，F2 切换中英文并在输出里提示；路径参数位置的候选取壳的当前路径；回车先把自由参数补成角引文本，再回车才执行。输出区保留最新 300 行，排版最新 100 行，每行显示至多 1000 字。裸机与原生执行器随时交出新输出；诺节与浏览器在程序结束时一次显示。设置与取消环境后同步壳核心的运行补全登记。

## 文件浏览与预览

浏览服务的路径是授权目录内以正斜线分隔的相对路径，空串表示根。`文件浏览` 的浏览状态与视图（路径框、条目、Markdown 与豫言源码文档预览）保留供测试与以后的格子使用；平铺桌面的文件浏览格用工作台的资源侧栏。`标记文预览` 共用于工作台与预览：标题、列表、引用、围栏代码、行内代码、粗体、链接、表格与转义标点。

## 设置

启动时从授权目录的 `yy桌面设置.数据库` 恢复字体，字体选择经嵌入数据库写事务提交；只读或未授权时保留会话内设置。默认字体是随发行的文楷，另有无衬线、衬线、等宽三个标准族名。
