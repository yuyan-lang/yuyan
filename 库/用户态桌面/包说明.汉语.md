# 用户态桌面

这是开机命令壳与[平铺桌面](../平铺桌面/包说明.汉语.md)共用的普通豫言库：命令会话、图形命令行、文件浏览与文件服务、标记文预览、任务管理器、系统设置与设置持久、环境文件。库通过系统接口取得宿主能力，不直接访问内核内存或设备。2026-10-10 起桌面是平铺桌面（提案 00014）：原来的浮动窗口（窗口形表、标题栏拖动、右下角缩放、置顶与轮换）与「运行用户态桌面」已删去，这里的图形命令行、文件浏览、任务管理器与系统设置都作为平铺桌面的格子程序使用。

## 模块

| 模块 | 内容 |
| --- | --- |
| `命令壳` | 系统壳在豫言操作系统里的会话与做法：开机壳、桌面终端与旧开机壳共用的当前路径与环境（已授“桌面”根的 `.环境`）；命令一律由[壳命令](../壳命令/包说明.汉语.md)的快路解析与派发，这里把文件、设、取消、环境、显示设置等在系统里的做法登记成壳命令的实现（提案 00003 第 5 步）；同步与异步运行子程序、轮询（未成行的输出余文按子程序句柄分开） |
| `命令服务` | 文件命令：目录、列、读、写、追加、复制、移动、建、删、切换 |
| `子程序服务` | 桌面终端的平台「桌面命令平台」：每句经「桌面执行壳句」交给系统壳（壳命令的「执行壳命令句」），执行期间「运行」「构建启动盘」「安装系统」异步启动，「脚本」交给终端逐行执行，「图形」提示已在桌面，「退出」关闭终端格 |
| `终端类型` | 终端的类型与轻量部分：终端状态、终端消息、终端平台、输出追加、开场、终端视图与「终端程序」（更新、视图、轮询、执行的函数组）；不引用壳核心的组字与拼音表，浏览器里的平铺桌面只链接它 |
| `图形命令行` | 终端的更新（拼音组字、候选、历史、执行与轮询）；「终端程序于平台」用平台组出终端程序。程序运行时输入框照常可用，回车把这一行连同换行交给程序（平台「送输入」，子程序 0.8.0 的交互子程序），Ctrl+C 打断程序 |
| `文件浏览`、`文件服务` | 浏览服务（列目录、读文本）及授权目录上的文件读写；工作台也用它们 |
| `标记文预览` | 共用 Markdown 预览 |
| `任务管理器` | 任务表「任务表文字」（壳命令「列出任务」与任务管理器共用，像 ps：首行写任务数、统计范围与采样时间，其下是表头与每个任务一行，列为任务号、处理器、常驻内存、已用堆、名称，数字列靠右、按双宽字体对齐）；任务管理器的视图「任务管理视图」整屏就是这张表，格子每秒重查一次。「桌面程序」是平铺桌面的窗口列表项（标题、种类、组序、任务号），任务管理器据此把桌面窗口的名称写成“窗口标题 · 程序名”（「任务显示名」） |
| `系统设置`、`设置持久` | 字体、缩放、分辨率设置与它们在授权目录 `yy桌面设置.数据库` 里的持久化 |
| `设置命令` | 壳命令「设置分辨率」「设置缩放」「设置字体」「显示设置」在豫言操作系统里的做法：与「系统设置」共用更新与保存，存成后「桌面设置版本」加一，开着的平铺桌面随之重读 |
| `任务命令` | 壳命令「列出任务」「打断任务」在豫言操作系统里的做法（2026-10-12）：列出任务查任务监测接口，印出「任务表文字」的表格；打断任务调子程序接口的「打断任务」。桌面终端运行程序时按 Ctrl+C，终端取运行中子程序的任务号，显示 `^C` 与 `壳> 「打断任务」于「号」为「N」`，再把这句交给系统壳执行；脚本在运行时另清掉余下的行 |
| `设备命令` | 壳命令「设备列表」在豫言操作系统里的做法（2026-10-13）：查设备接口，首行写设备数，其下每个设备一行（总线、位置、厂商号:产品号、类码、驱动名、状态）；驱动名按驱动号查「驱动名」，各驱动加自己的编号。 |
| `环境文件` | `.环境` 的读写 |
| `交互输入` | 控制台的逐键行编辑（拼音组字、候选、补全、历史、光标移动；2026-10-11 从开机壳移来，提案 00003 第 8 步）：「读取中文交互行」读一行，提示符在「输入提示文」里（开机壳为“壳> ”），开机壳与豫言操作系统里的豫构交互共用 |

包的默认导入是 `命令壳`。

文件服务在收齐文件字节后，以 UTF-8 替换方式解码文本。残缺与非法编码片段显示为 `�`，文件浏览和工作台编辑共用这一行为。`测试/文件文本解码。测试。豫` 覆盖完整中文、补充平面字符、空文、截断与非法字节。

## 终端与开机命令壳一致（2026-10-09）

终端格与开机命令壳是同一个系统壳（2026-10-12 起每句交给壳命令的快路，`子程序服务。豫` 的「桌面执行壳句」；桌面里编译运行别的豫言句留待后续版本）：同一个当前路径，同一份环境，命令登记里的全部壳命令（豫言句，字符串写『』）、用法与出错提示都相同，包括「运行」「设」「取消」「环境」「日期」「脚本」。两处只在「运行」上分开：开机壳同步运行，子程序直接写控制台；终端经公共子程序接口 0.6.0 异步启动，按计时用「取子程序输出」取回新输出（连续没有新输出时间隔逐次加倍，从 250 毫秒至多 2 秒；有新输出即回到 250 毫秒），造盘这类长时间运行的程序随时显示进度行。程序运行期间输入框停用。裸机上被捕获输出的程序以“继承输出”再起的子程序，输出跟着该程序的输出走，不写屏幕控制台。「脚本」逐行执行，遇到「运行」等它结束再执行下一行；脚本注释与豫言源码相同，写在「：与：」之间，可以跨行、可以嵌套。终端里「图形」提示已在桌面，「退出」关闭这个终端格。

输入与开机壳一致：执行时回显 `壳> 命令`，脚本行回显 `+ 行`；永远中文组字（10-10 起没有中英文切换）：字母直接写进输入框，光标前那串字母就是拼音，候选行显示“拼音：… 候选：…”；? 和字母一样进输入框、算进拼音，是通配符（匹配任意一段，可为空）：单打 ? 展开光标处全部已知选项（候选行显示“当前位置全部选项：…”，没有已知选项时在输出里提示），tu? 按通配给候选；有候选时空格或回车选当前页首项，1-9 选字，= 、- 翻页；退格照常删字，拼音随之变短；Esc 把这串拼音（含 ?）当英文留在框里，之后打的字母另起一段拼音（要输入 ? 本身就打 ? 再按 Esc）；{ } 输入角引号，紧接着按 Esc 换回 ASCII 的 { }；没有候选时回车执行；路径参数位置的候选取壳的当前路径；回车先把自由参数补成角引文本，再回车才执行。输出区保留最新 300 行，排版最新 100 行，每行显示至多 1000 字。裸机与原生执行器随时交出新输出；诺节与浏览器在程序结束时一次显示。设置与取消环境后同步壳核心的运行补全登记。

## 文件浏览与预览

浏览服务的路径是授权目录内以正斜线分隔的相对路径，空串表示根。`文件浏览` 的浏览状态与视图（路径框、条目、Markdown 与豫言源码文档预览）保留供测试与以后的格子使用；平铺桌面的文件浏览格用工作台的资源侧栏。`标记文预览` 共用于工作台与预览：标题、列表、引用、围栏代码、行内代码、粗体、链接、表格与转义标点。

## 设置

启动时从授权目录的 `yy桌面设置.数据库` 恢复字体，字体选择经嵌入数据库写事务提交；只读或未授权时保留会话内设置。默认字体是随发行的文楷，另有无衬线、衬线、等宽三个标准族名。

显示设置提供自动、100%、125%、150%、175%、200%、250%、300%缩放，自动项注明宿主自动值。分辨率按显示接口的模式列表列按钮，只有一项时显示当前尺寸。数据库键为桌面/字体、桌面/缩放、桌面/分辨率；缩放存比六四（0为自动），分辨率存宽×65536＋高（0为沿用当前）。设置立即生效，启动恢复保存的值。后续版本事项：分辨率确认倒计时。
