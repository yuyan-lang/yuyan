# 用户态桌面

活动窗口的主输入框启用自动聚焦，切换到文件窗口时恢复路径框，切换到命令窗口时恢复命令框；稳定窗口键保留已有光标。待办事项：记忆其他内部控件的焦点，以及再次点击当前窗口标题后的输入焦点恢复。此行为使用自绘控件，文树运行器尚未支持动态自动聚焦。

背景文件窗口的路径框获得焦点时立即激活文件窗口，不读取目录或文件，并保留命令行草稿。`测试/窗口聚焦。测试。豫` 覆盖视图事件路由与状态保留；切换窗口后自动恢复内部焦点仍待实现。

这是独立桌面应用与控制台共用的普通豫言库。现有窗口状态、文件浏览、文件服务、图形命令行、命令服务和桌面视图从图形桌面可执行包移入，保留同一份实现；各模块按包名导入，总集只导出同步运行入口。

`运行用户态桌面` 通过既有显示、字体与文件接口取得能力，运行可停止主循环；返回按钮结束本次桌面并回到调用方。库直接依赖界面、自绘与壳核心，使用标准库，不直接访问内核内存或裸机设备。平台尚未提供相应能力时由接口返回错误；库化不证明所有平台已经提供这些能力。

现有桌面测试随实现移入 `测试/`，直接测试本库。文件服务测试需绑定实际宿主与授权验收目录；其余模型测试可由普通工具宿主运行。迁移后的构建、状态与实际图形验收须重跑。

迁移后的库类型检查、窗口、浏览、命令服务、桌面退出和图形命令行回归通过；原壳入口构建与图形指令登记测试通过。实际 Node 发行调用本库，后台文件读取与历史重放输出中文正文，返回按钮正常结束，绘制记录为 `yy共用桌面库后台.png`。

现使用显示0.3.0的归还能力，正常停止后关闭本次节点窗口，保留授权供再次启动。宿主测试覆盖旧号失效、积压事件清除、等待结束、另一个显示面保留及新面号分配；真实SDL后台验收中，同一Wasm程序连续调用两次桌面，两次均在返回调用方前销毁本次窗口，并执行返回后的中文标记。入口为 `测试/会话启停。测试。豫`，通过临时发行绑定实际宿主运行，全树测试登记只检查。原壳完整输入会话、浏览器实际界面、其他系统与语言异常收尾仍待验收。
