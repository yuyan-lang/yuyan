# 标准库

子进程模块提供 `终止异步子进程(句柄)`，按本实例登记的异步句柄请求强制终止，随后由收取服务读取退出结果。结果码为 0 成功、8 句柄无效、29 宿主失败、58 当前平台暂不支持。工具节点与原生执行器已有实现；裸机动态任务与应用宿主异步能力列为后续事项。

提供豫言语言核心、数据结构及操作系统接口。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 使用

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 标准库
```

依赖及说明路径以 [包配置](标准库。包。豫) 为准。

`操作系统/路径` 按当前平台取路径分隔符；Windows 的 `D:\子项` 以 `D:\` 为父目录，`D:\` 自身没有父目录。绝对路径判断接受盘符后接正斜线或反斜线。

`数据结构/字节缓冲` 提供可就地改写的定长字节存储：新建、读写单字节与小端四字节、填充、复制、转字节串，用于逐字节构造画面、位图等大块数据。它与字节串同为 WasmGC 的 i8 数组，操作都在客体内完成，转字节串时复制一份；字节缓冲不可交给宿主。

`语言核心/原语`（文件 `原语。内建。豫`）声明编译器提供的语言原语：引用与数组、不安全转换、整数与小数运算，以及字符串、字节串与字节缓冲的操作，都由编译器就地生成指令或调用客体内的运行时函数。`宿主`（`宿主。接口。豫`）与 `宿主带列`（`宿主带列。接口。豫`）声明标准库要宿主提供的服务（标准流、文件、进程、时间、随机、网络等），编成导入模块“标准库”的带类型导入，共六十五个函数；用到列的八个函数单独成文，免得模块成环。标准库的公开函数都改调这三个模块；它们不经总集导出，一般程序不必直接导入。

`数据结构/整数操作` 除加减乘除与比较外，还有取余（截断余数，符号随被除数）、非负余、位与、位或、位异或、位非、左移、右移（补符号位）、无符号右移、循环左移、循环右移、前导零数、末尾零数、置位数、小等、大等、无符号小于、无符号大于、无符号除、无符号余、整数最小值与整数绝对值。`数据结构/小数术` 提供小数等、小数不等、小数小于、小数大于、小数小等、小数大等、小数是非数、小数最小、小数最大、小数绝对值、小数取负、小数复号、小数向上取整、小数向下取整、小数截断、小数就近取整与小数开方，名字都带“小数”前缀，与整数操作一样经标准内核无限定导出；小数四则仍在 `数据结构/小数操作`，写限定名。`数学运算/转换` 另有小数饱和转整数（非数得零，越界取极值，不陷阱）、无符号整数转小数、小数位与位转小数。这些都由编译器就地生成指令，语义见《执行与编译》编四。
