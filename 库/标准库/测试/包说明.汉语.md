# 标准库测试

标准库的单元测试（`X。测试。豫`）与回归样例（`名-N。豫` 配 `名。成功`／`名。失败`）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，不被其他包依赖。

测试要用单元测试框架（包「单元测试」），而标准库不能依赖它，所以测试单独成包，放在被测库之下：包目录是 `库/标准库/测试/`，依赖标准库与单元测试。它没有登记为标准库的子包，因为子包不能依赖祖先。

## 使用

在仓库根目录构建并运行单个测试，入口段相对本包根、不带扩展名：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 标准库测试 数据结构 可选值。测试 --输出 yy可选值测试.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy可选值测试.wasm
```

本包含两个预期失败的回归样例（`。失败`），不能把全部源码一律当作应能构建成功的目标。

## 维护

新增测试放在对应的子目录；修改包身份或依赖时同步更新包配置。
