# 包配置

以 parser 解析静态包配置并验证依赖图。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 使用

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 包配置
```

依赖及说明路径以 [包配置](包配置。包。豫) 为准。

包描述的字段与校验见[豫构包系统](../../应用/豫构/包系统.汉语.md)。可选字段「平台」的解析结果用「包平台们」（按书写顺序的各项）与「包平台依赖」（包在某平台上的诺节库与系统库，不能用于该平台时为「可无」）读取。

## 维护

包描述的跳转与悬停资料写入 `.yybuild/豫构语言服务/<包描述基名>.语言服务.树码`。它与编译器语言服务缓存共用第二版树码，由豫言 `yy树码 读取编辑器资料` 解码后交给编辑器。

语言服务的 UTF-16 列号使用「编码转换」的「字符串UTF16长度」计算，补充平面字符占两个码元。

修改接口时更新本说明；修改包身份、版本或构建组成时同步更新包配置。说明文件不参与模块导入。
