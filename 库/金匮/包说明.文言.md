# 金匮（本地盘存储底座）

诸适配落于本机之盘者，共此最小之底座。数据居于文件系统，重启而在；惟依标准库与结绳，不假宿主之口，亦不起东道之令。

## 包之身

所有者：豫言。包之版：零点一。此包为库，依标准库与结绳。单段导入 `寻观「金匮」之书。` 不展其模；用何篇则显导之：`寻观「金匮」之「路」之书。`、`寻观「金匮」之「键值」之书。`

## 诸模

| 模 | 所收 |
| --- | --- |
| 路 | 金匮之根（`匮根`、`设匮根`，缺省 `.豫言金匮`）、合径（`存径`、`存目`）、补目（`备目`）、卷册（`卷在`、`读卷文`、`写卷文`、`附卷文`、`删卷`）、列目（`列目名`）、转写怪名（`遁名`）、依字节之序相较（`文先`） |
| 键值 | 键值之表（`键表` 与 `键表空`）、读、写、删（`键读`、`键写`、`键删`）、依选项而列（`键列举`）、表与 JSON 互转（`表述`、`表析`）、以卷存表（`读表卷`、`写表卷`） |

## 约

- **根**：诸适配启时一次 `设匮根`，后之诸径皆附其下。试者以 `临时箧` 造暂根，用毕 `删树`。
- **书**：`写卷文` 先书草名而后更名，观者惟见旧稿或新篇之全；`附卷文` 依字节而续。
- **键值之表**：值存 JSON 之文（卷中为 JSON 之物，值为再编之串）。列举依字节之序，选项循持久事务之规。
- **怪名**：径中不便为目名者（空名、`.`、`..`）与以 `%` 起首者，由 `遁名` 转写。

后续之事项：整表重写之费与大小俱增，大库宜改为追加之记（芥子同此患）；`遁名` 不复其原；单名与总径之长限；多程同书一表之锁。
