# 金匮（本地盘存储底座）

给落在本机盘上的平台适配共用的最小存储底座。数据放在文件系统里，重启后仍在；只依赖标准库与结绳工具，不依赖任何宿主接口，也不起宿主命令。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库与结绳工具。单段导入 `寻观「金匮」之书。` 不展开任何模块，用哪个模块就显式导入哪个：`寻观「金匮」之「路」之书。`、`寻观「金匮」之「键值」之书。`

## 模块

| 模块 | 内容 |
| --- | --- |
| 路 | 金匮根（`匮根`、`设匮根`，缺省 `.豫言金匮`）、拼径（`存径`、`存目`）、补建目录（`备目`）、卷册（`卷在`、`读卷文`、`写卷文`、`附卷文`、`删卷`）、列目（`列目名`）、转写怪名（`遁名`）、按字节序比较（`文先`） |
| 键值 | 键值表（`键表` 与 `键表空`）、读写删（`键读`、`键写`、`键删`）、按选项列举（`键列举`）、表与 JSON 文字互转（`表述`、`表析`）、以卷存表（`读表卷`、`写表卷`） |

## 约定

- **根**：各适配在启动时 `设匮根` 一次，之后所有路径都拼在它下面。测试用 `临时箧` 造一个临时根，用完 `删树`。
- **写**：`写卷文` 先写同目录的草名再改名，同时读的人只见旧稿或新稿之全；`附卷文` 按字节追加。
- **键值表**：值按 JSON 文字原样存放（文件里是 JSON 对象，值是再编码一次的字符串）。列举按键的 UTF-8 字节序排好，选项照持久事务规范：`prefix`、`start`、`startAfter`、`end`、`limit`、`reverse`。
- **怪名**：路径段里不能作目录名的（空名、`.`、`..`）与以 `%` 起首的名字由 `遁名` 转写。

后续版本的事项：键值表整个重写的代价与大小成正比，大库要改成追加式日志（芥子同此问题）；`遁名` 不还原原名；单段长名与路径总长的上限；多进程同写一张表时的锁。
