# 深度学习框架测试

此「深度学习框架」之试，为一诺节之应用（实启动之接口），行于实张量计算接口之宿主。其入口次行梯之核、卷积之核、循环之网与变换之器之核及训之核，每项书“核对 名：通过”或“失败”及其详，终书成败之数，退出之码为败数。

- `梯度核对`：数前向之已知值（矩阵乘、软最大每行之和、按轴求和、对数求和指数、换轴、修正线性）；以数值微分核诸算之梯：随取出之权 w，令 L = Σ(f(x) × w)，反传得解析之梯，复于每入之元行中心差分（步 0.01）得数值之梯，二者之差须在 0.02 + 0.02 × |数值之梯| 之内。所核者：逐元四则（含广播）、数加数乘数除数减、整数幂与小数幂、取负、矩阵乘（含批与广播）、按轴求和、均值、广播到、改形、交换轴、转置、换轴、指数、对数、平方根、修正线性、双曲正切、反曲、对数求和指数、软最大、对数软最大、查表、软最大交叉熵、均方误差、层归一化与批归一化。入值离零至少 0.05，以避修正线性之折。
- `梯度核对` 中卷积之核（`运行卷积核对`）：卷积前向之已知值；步一补一、步二补一（边长六，出不整除）、核二步二无补三卷积于入与核之梯；NHWC 四维批归一于入之梯。
- `梯度核对` 中循环之网与变换之器之核（`运行循环核对`）：切片、取项与堆叠、按号查表（行号重）、简单循环与长短期记忆之单元（于入与态）、二层长短期记忆之序列前向（于入序）、多头注意（因果，于问、键、值）与注意之层（于入）之数值之梯。
- `训练核对`：不记梯、分离与梯之累；载器之分批与乱序；随机张量之均、方差与可复；MNIST 之读（原与 gzip 二小样之文件，须授只读目录“样例”，否则略之）；线性回归（随机梯度下降加动量，三百步后均方之误下于 1e-4）；异或（亚当，五百步后四者皆对）；三类高斯之团上含残差、层归一、批归一与丢弃之多层感知机（载器分批而乱之，二十轮后正率不下于 95%，且暂存张量无漏）；CIFAR-10 之读（小样，核标签、形与 NHWC 下数处像素）；横竖之纹（8×8 单通道六十四张）上之小卷积网十五轮后正率不下九成；ResNet9 出形 [2, 10]，于八随机之图训三十步损减其半；梯之裁（范五裁至一）；小语料之读与语言之批；二层长短期记忆与变换之语言模于周期之序八轮后均损下于 0.3。

`样例/` 中为读所用小文件：MNIST 之 `小图.idx`（二图各 2×3）、其 gzip 原件 `小图.idx.gz`（头载文件名）与 `小标签.idx`（二标签）；已分词之文 `小语料.txt`（三行 a b c、b c d、c d a）；CIFAR-10 之式之 `小十类.bin`（二条，标签三、四，第 r 条通道 c、行 y、列 x 之像素为 (50r + 80c + 3y + x) mod 256）。

## 包之身份

主：豫言。版：0.1.0。可执行文件之包（入口 `入口`，产物名 `yy深度学习框架测试`），依标准库、单元测试、深度学习、深度学习框架、启动、基础与文件之接口。试包依所试之库，故登于「共用库」之下。

## 行之

于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 库/深度学习/框架/测试 dist/框架测试 --包根 库/深度学习
node dist/框架测试/启动.mjs --授权只读目录 样例=库/深度学习/框架/测试/样例
```

2026-09-30 于 macOS arm64（诺节 26.3.0，接口 0.4.0）六十八项皆过：中央处理器之后端约三秒；加宿主之选项 `--张量后端 金属 --允许系统库调用` 于金属之后端约十三秒。以反曲之反乘二为变异之试，“核对 反曲”报败（最大相对之误约 8.9），退出之码为一。
