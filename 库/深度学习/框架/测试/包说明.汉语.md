# 深度学习框架测试

这是「深度学习框架」的测试，一个诺节应用（实现启动接口），在实现张量计算接口的宿主上运行。入口依次运行两组核对，每项打印“核对 名：通过”或“失败”及详情，最后打印成功与失败数，退出码为失败数。

- `梯度核对`：几个前向的已知值（矩阵乘、软最大每行和、按轴求和、对数求和指数、换轴、修正线性）；数值微分核对各算子的梯度：随机取输出权重 w，令 L = Σ(f(x) × w)，反向传播得解析梯度，再对每个输入元素做中心差分（步长 0.01）得数值梯度，两者之差须在 0.02 + 0.02 × |数值梯度| 之内。覆盖逐元四则（含广播）、数加数乘数除数减、整数幂与小数幂、取负、矩阵乘（含批与广播）、按轴求和、均值、广播到、改形、交换轴、转置、换轴、指数、对数、平方根、修正线性、双曲正切、反曲、对数求和指数、软最大、对数软最大、查表、软最大交叉熵、均方误差、层归一化与批归一化。输入离 0 至少 0.05，避开修正线性的折点。
- `训练核对`：不记梯度、分离与梯度累加；数据加载器的分批与打乱；随机张量的均值、方差与可复现；MNIST 读取（原始与 gzip 两种小样例文件，须授予只读目录“样例”，否则跳过）；线性回归（随机梯度下降加动量，300 步后均方误差低于 1e-4）；异或（亚当，500 步后四个全对）；三类高斯团上带残差、层归一、批归一与丢弃的多层感知机（数据加载器分批打乱，二十轮后正确率不低于 95%，且没有临时张量泄漏）。

`样例/` 里是 MNIST 读取用的小文件：`小图.idx`（2 张 2×3 的图）、它的 gzip 原件 `小图.idx.gz`（文件头带文件名）与 `小标签.idx`（2 个标签）。

## 运行

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 库/深度学习/框架/测试 dist/框架测试 --包根 库/深度学习
node dist/框架测试/启动.mjs --授权只读目录 样例=库/深度学习/框架/测试/样例
```

2026-09-30 在 macOS arm64（诺节 26.3.0，接口 0.3.0，中央处理器后端）上 48 项全部通过，用时约 4 秒。把反曲的反向乘以 2 做变异试验，“核对 反曲”报失败（最大相对误差约 8.9），退出码为 1。
