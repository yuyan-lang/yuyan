# 深度学习框架

这是豫言的通用深度学习框架，定位与 PyTorch、CMU 10-714 的 needle 相同：任何神经网络都在它上面搭。它提供框架张量与自动微分、神经网络模块与损失、二维卷积、常用模型（多层感知机、ResNet9）、循环网络（简单循环、长短期记忆）与变换器、语言模型、优化器（含梯度裁剪）、数据集与数据加载器，以及 MNIST（IDX 格式）、CIFAR-10（二进制版）与 Penn Treebank 语料读取。计算全部经[张量计算接口](../../../豫言操作系统接口/张量计算/规范.汉语.md)（0.4.0）交给宿主，框架本身是普通的带垃圾回收的豫言库；现在能在路一诺节宿主上运行：后端缺省为中央处理器，宿主选项 `--张量后端 金属 --允许系统库调用` 时在苹果设备的 GPU 上算。

## 包身份

MNIST、CIFAR-10 与文本语料的文件开启、顺序读取与关闭使用「数据集」包的文件流模块。

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、深度学习（伪随机源）、豫言操作系统基础、文件、压缩、张量计算与张量文件。它依赖「深度学习」，所以与「深度学习推理」一样登记在「共用库」之下。

## 张量与内存

框架张量（类型「框架张量」）包住一个后端张量，并记下它由哪些输入经什么运算得来。后端张量是宿主的资源，垃圾回收不会释放它们，所以框架把张量分成两种：

- **临时张量**：经后端新建的张量（运算结果、批数据、梯度）一律登记为临时。训练每一步结束时调用 `「释放临时张量」于「元」` 一并释放；此后再用这些张量属于非法资源使用，宿主终止运行。`「逐批折叠」` 每批之后自动释放，所以它的状态里只能放数、列表等豫言值。`「在临时作用域中」` 执行一个函数后只释放其间新建的临时张量，适合把结果写进常驻张量的计算。`「临时张量数」` 用来查泄漏。
- **常驻张量**：参数（`「转为参数」`）、常驻缓冲（`「转为常驻」`）、优化器状态、数据集各复制一份不登记的存储，由持有者释放（`「释放常驻」`、`「释放模块」`、`「释放数据集」`）。参数的梯度也常驻，可以跨批累加，由优化器的 `「清零梯度」` 释放。

## 自动微分

- 叶子张量：`「张量自小数」「张量自整数」「全零张量」「全一张量」「常数张量」`（不需要梯度）；`「需要梯度」` 得到同一数据、需要梯度的叶子；`「分离」` 得到不记计算图的张量。
- 运算结果在“记梯度”且有输入需要梯度时记下输入与反传函数。`「不记梯度地」授以 类型 于（会「无」而 …）` 在执行期间不记计算图。
- `「反向传播」于 损失` 以全 1 为输出梯度（`「反向传播于」` 可给定），按拓扑序从输出往回传，梯度在各张量的梯度格里累加；`「取梯度」` 读出。
- 带梯度的算子：`逐元加、逐元减、逐元乘、逐元除`（按 NumPy 规则广播，反向把梯度求和回原形状）、`数加、数减、数乘、数除`、`幂`（整数次）、`小数幂`、`取负`、`矩阵乘`（[…, m, k] 乘 […, k, n]，批维广播）、`按轴求和、全部求和、均值、全部均值`（轴号可为负）、`广播到`、`改形`（可有一项为负一）、`交换轴、转置`（末两轴）、`换轴`（任意排列）、`指数、对数、平方根、修正线性、双曲正切、反曲`、`对数求和指数`（任意轴，先减最大值）、`软最大、对数软最大`（末维）、`查表` 与 `按号查表`（嵌入，反向按行累加）、`切片`（跨步视图，反向写回全零张量的那一段）、`取项`（第一维的一项）、`堆叠`（沿新的第一维）、`卷积`（见下）。

## 卷积

`「卷积」于 输入 于 核 于 步长 于 补零` 是二维互相关，数据用 NHWC 布局：输入 [N, H, W, Ci]，核 [K, K, Ci, Co]，结果 [N, (H+2p−K)÷s+1, (W+2p−K)÷s+1, Co]。照 needle 的做法：前向先补零，再用跨步视图取出每个输出位置的 K×K×Ci 图块（im2col），复制成 [N×Ho×Wo, K×K×Ci] 后乘以改形成 [K×K×Ci, Co] 的核。反向：对核的梯度是图块列的转置乘输出梯度；对输入的梯度是把输出梯度按步长扩张（放进边长为 H+2p−K+1 的全零张量，输出不整除时末端补零）后，与空间翻转、通道对调的核（负步长视图）做步长 1、补零 K−1−p 的卷积。

`「卷积层」于 入通道 于 出通道 于 核长 于 步长 于 源`：核按何恺明均匀初始化（扇入 K×K×入通道），偏置 [出通道] 取 U(−1/√扇入, 1/√扇入)，补零为 K÷2。

## 模块与损失

模块（类型「模块」）有名称、本层参数、子模块、训练标记与前向函数。`「模块前向」于 模块 于 输入`；`「模块参数」` 递归收集参数；`「训练模式」「评估模式」` 递归设置标记。

| 模块 | 说明 |
| --- | --- |
| `线性层 入数 出数 源` | y = x·W + b；W [入数, 出数] 取何恺明均匀初始化，b [1, 出数] 取 U(−1/√入数, 1/√入数)；`无偏线性层` 没有 b |
| `修正线性层`、`双曲正切层`、`反曲层` | 无参数的激活 |
| `顺序组合 模块们`、`残差连接 模块` | 依次经过；y = f(x) + x |
| `丢弃层 概率 源` | 训练时以给定概率置零、其余除以 (1 − 概率)；评估时原样通过 |
| `层归一化 维数 小量` | 沿最后一维归一，w 初始 1、b 初始 0 |
| `批归一化 维数 小量 动量` | 输入 [..., 维数]：最后一维是特征，前面各维都当作样本，所以 NHWC 的四维输入即二维批归一；训练时用本批均值与有偏方差并更新滑动统计，评估时用滑动统计 |
| `卷积层` | 见上 |
| `嵌入层 词数 维数 源` | 表 [词数, 维数] 取标准正态；输入是行号张量 |
| `展平层` | [批, …] 变为 [批, 其余元素数] |

损失：`「软最大交叉熵」于 对数几率 于 标签`（对数几率 [批, 类别数]，标签 [批] 或 [批, 1]，元素为类别号，返回批内平均，形状 [1]）；`「均方误差」于 预测 于 目标`。`「预测类别」于 对数几率` 得每行最大值的类别号 [..., 1]；`「正确个数」于 对数几率 于 标签` 数出预测类别等于标签的样本数（并列取序号小者）；两者都不记梯度。

## 常用模型

- `「多层感知机」于 宽度们 于 源`：宽度列表 [d₀, …, dₙ]，相邻两层之间是线性层，除最后一层外都接修正线性。
- `「残差网络九」于 源`：needle 作业四的 ResNet9，输入 NHWC 的 [N, 32, 32, 3]：卷积批归一(3→16, 核 7, 步长 4)、(16→32, 3, 2)、残差块(32)、(32→64, 3, 2)、(64→128, 3, 2)、残差块(128)、展平、线性(128→128)、修正线性、线性(128→10)；卷积批归一是卷积层、批归一化（小量 1e-5、动量 0.1）、修正线性，残差块是两个 3×3 卷积批归一加残差连接。`「卷积批归一」「残差块」` 也可单独用。

## 循环网络与语言模型

needle 作业四后半的写法。序列模型（类型「序列模型」）有参数模块、前向函数与零隐状态：`「序列前向」于 模型 于 输入 于 隐状态` 把输入序列 [T, B, 入维] 变成（输出序列 [T, B, 出维]，新隐状态）；隐状态是每层一个张量列表（简单循环为 [h]，长短期记忆为 [h, c]），`「零隐状态」于 模型 于 批大小` 得全零的初值。

- `「循环单元」于 入维 于 隐维 于 用双曲正切 于 源`：h′ = 激活(x·Wᵢ + bᵢ + h·Wₕ + bₕ)，激活为双曲正切或修正线性。
- `「长短期记忆单元」于 入维 于 隐维 于 源`：门 = x·Wᵢ + bᵢ + h·Wₕ + bₕ（[B, 4×隐维]），依次切成输入门、遗忘门、候选、输出门；c′ = σ(f)·c + σ(i)·tanh(g)，h′ = σ(o)·tanh(c′)。两种单元的权重与偏置都取 U(−1/√隐维, 1/√隐维)。
- 单元（类型「单元」）是（参数模块，输入投影，一步函数）：输入投影把 [N, 入维] 变成 [N, 门维] 并加上两个偏置，一步函数由投影后的一个时刻 [B, 门维] 与这一层的状态得新状态；`「单元一步」于 单元 于 输入 于 状态` 对单个时刻先投影再走一步。
- `「循环序列模型」于 入维 于 隐维 于 层数 于 用长短期记忆 于 源`：多层网络，逐层处理：先把这一层整段输入 [T, B, 入维] 用一次矩阵乘投影好，再逐时刻用 `取项` 取出投影、只算隐状态那一半并走一步，最后把各时刻的输出 `堆叠` 成 [T, B, 隐维] 作为下一层的输入。
- 截断反向传播：每批之后 `「隐状态常驻化」`（分离并复制成常驻张量），跨批保留隐状态而不回传，旧的用 `「释放隐状态」` 释放。
- `「新语言模型」于 词数 于 嵌入维 于 出维 于 序列模型 于 丢弃率 于 源`：嵌入（U(−0.1, 0.1)）→ 丢弃 → 序列模型 → 丢弃 → 线性（权重 U(−0.1, 0.1)、偏置 0），与 PyTorch 词语言模型例子相同。`「语言模型前向」于 模型 于 词号们 于 T 于 B 于 隐状态` 的词号是行优先 [T, B] 的整数列表，返回（对数几率 [T×B, 词数]，新隐状态）。
- `「语言模型一轮」`（needle 的 epoch_general_ptb）：按批大小把词号数组排成列，每 T 行一批；训练时清零梯度、前向、反向、按上限裁剪梯度、更新，评估时不记梯度；每批之后常驻化隐状态、释放临时张量并调用报告函数；返回（损失乘词元数之和，词元数），困惑度为 e^(平均损失)（`「小数指数」`）。

## 变换器

needle 作业四的 Transformer。`「多头注意力」于 问 于 键 于 值 于 因果 于 丢弃层`：三者形状 [B, H, T, D]，分数 = 问·键ᵀ ÷ √D，因果时加上 `「因果掩码」`（j > i 处为 −10⁹），软最大后经丢弃层再乘值。接口的「注意力」原语只有前向、没有批维，训练用不上，所以用矩阵乘与软最大拼。`「注意力层」于 特征 于 头数 于 头维 于 丢弃率 于 因果 于 源`：问、键、值各先层归一，经无偏线性投影成多头，注意力后合并并投影回特征维。`「变换器层」` 是注意力与前馈（线性、修正线性、丢弃、线性）两个残差块，各带丢弃；`「变换器序列模型」于 嵌入维 于 前馈维 于 层数 于 头数 于 头维 于 丢弃率 于 最长序列 于 源` 加上学习的位置嵌入（标准正态初始化），输入输出都是序列在前的 [T, B, 嵌入维]，隐状态为空列表，可直接放进语言模型。

## 优化器

`「随机梯度下降」于 参数们 于 学习率 于 动量 于 权重衰减`、`「亚当」于 参数们 于 学习率 于 β₁ 于 β₂ 于 小量 于 权重衰减`，更新规则与 needle 相同：

- 随机梯度下降：g = 梯度 + 衰减 × 参数；u ← 动量 × u + (1 − 动量) × g；参数 ← 参数 − 学习率 × u。用接口的就地线性组合实现（两至三次调用，不改梯度）。
- 亚当：g = 梯度 + 衰减 × 参数；m ← β₁m + (1 − β₁)g；v ← β₂v + (1 − β₂)g²；参数 ← 参数 − 学习率 × m̂ ÷ (√v̂ + 小量)，m̂、v̂ 为偏差修正后的矩。每个参数一次调用接口的亚当更新。

每步先 `「清零梯度」`，再前向、`「反向传播」`，然后 `「优化一步」`。参数与状态常驻，就地更新；没有梯度的参数跳过。`「梯度裁剪」于 参数们 于 上限` 在全部梯度的总二范数超过上限时按比例就地缩小，返回裁剪前的总范数。

## 数据

- `「张量数据集」于 输入 于 目标`：第一维是样本，各复制一份常驻数据；`「取批」于 数据集 于 序号们` 返回（输入，目标）两个临时张量。
- `「新数据加载器」于 数据集 于 批大小 于 打乱 于 种子`；`「一轮批次」` 得到一轮的样本序号批（打乱用费舍尔–耶茨洗牌，每轮不同）；`「逐批折叠」于 加载器 于 初值 于（会「状」而会「输入」而会「目标」而 …）` 逐批更新状态，每批之后释放临时张量。
- `「读取手写数字」于 目录名 于 图像文件 于 标签文件`：读已授目录里的 MNIST（IDX 格式、无符号字节），图像缩放到 [0, 1]、形状 [样本数, 784]，标签形状 [样本数, 1]。文件以 gzip 魔数开头时先经压缩接口解压（文件头的附加段、文件名、注释与头校验都跳过），否则按偏移用张量文件接口直接载入宿主张量；都分段载入，每段 4 MiB。`「读取手写数字文件」` 读单个 IDX 文件。
- `「读取十类小图」于 目录名 于 批文件们 于 最多`：读 CIFAR-10 二进制版（每条 1 字节标签加 3072 字节像素，R、G、B 各 32×32），按每个文件 10000 条依次读，至多读 最多 条（0 为全读）；每段 1000 条经张量文件接口载入，用跨步视图把通道优先的像素换成 NHWC，图像 [样本数, 32, 32, 3] 缩放到 [0, 1]，标签 [样本数, 1]。
- `「读取语料」于 目录名 于 训练文件 于 验证文件 于 测试文件 于 最多行数`：读 PTB 那样空格分词的文本（needle 的 Corpus），三个文件共用一张词表（用「深度学习」的字节键表，按出现先后编号，每行末加 `<eos>`），每个文件至多读 最多行数 行（0 为全读）；`「语料词数」`、`「语料一份」`（0 训练、1 验证、2 测试）取出（词号数组，长度）。`「语言批」于 词号数组 于 长度 于 批大小 于 起 于 T`（needle 的 batchify 与 get_batch）返回行优先 [T, B] 的输入与目标词号，`「语言批数」` 算一轮的批数。

## 后端与张量计算接口

## 已知限制

代码里以“待办事项”注明：

- 宿主张量须显式释放：临时张量在每步末尾统一释放，跨步留用的临时张量会失效。
- `「后端读出」` 一次读出全部元素，逾两百万个元素时超过宿主单次交换上限。
- 丢弃概率为 1 时除以零。
- gzip 只支持单成员、解压后不超过 128 MiB 的文件；CIFAR-10 读取假定每个批文件恰有 10000 条。
- 卷积的 im2col 复制出 [N×Ho×Wo, K×K×Ci] 的图块列并留到反向，批大、特征图大时占内存多。
- 循环网络逐时刻计算，每个时刻前向十来次、反向二三十次小算子，每次都是一次宿主调用；金属后端上耗时几乎全是调用开销（见 `循环` 的待办事项）。
- 软最大交叉熵先把标签变成独热 [批, 类别数]，词表大时多算一整块（见 `模块` 的待办事项）。
- 速度（诺节宿主，苹果 M5 Pro，本机常有别的会话占用，负载平均 20 至 130）：中央处理器后端上 MNIST 多层感知机（784→256→10，亚当，批大小 100）每步约 12 毫秒（前向约 5、反向约 6、更新约 0.7 毫秒），ResNet9 批大小 32 每批约 0.2 秒，两层 200 维长短期记忆语言模型（批大小 20，序长 35）每批约 0.7 秒；金属后端上 ResNet9 批大小 32、128 每批都约 40 毫秒（负载重时 100 毫秒上下），CIFAR-10 全量一轮约 70、17 秒起，长短期记忆语言模型每批约 0.4 至 0.5 秒，同尺寸的两层变换器每批约 0.12 至 0.23 秒。
