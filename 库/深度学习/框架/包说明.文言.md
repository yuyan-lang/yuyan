# 深度学习框架

此豫言通用之深度学习框架也，其位同 PyTorch 与 CMU 10-714 之 needle：凡神经之网皆可建于其上。所备者：框架张量与自动微分、神经网络之模与损、二维卷积、常用之模型（多层感知机、ResNet9）、优化之器、数据之集与载器，及 MNIST（IDX 之式）与 CIFAR-10（二进制版）之读。诸算皆由[张量计算之接口](../../../豫言操作系统接口/张量计算/规范.文言.md)（0.4.0）付诸宿主，框架自身为寻常带垃圾回收之豫言库；今可行于路一诺节之宿主（后端为中央处理器）。

## 包之身份

主：豫言。版：0.1.0。库类之包，依标准库、深度学习（伪随机源）、豫言操作系统基础、文件、压缩、张量计算与张量文件。以其依「深度学习」，故与「深度学习推理」同登于「共用库」之下。

## 张量与存

框架张量（类「框架张量」）裹一后端张量，且记其由何入、经何算而得。后端张量为宿主之资，垃圾回收不释之，故框架分张量为二：

- **暂存张量**：凡经后端所建之张量（算果、批之据、梯）皆登为暂。每步训毕召 `「释放临时张量」于「元」` 尽释之；其后复用者为非法，宿主止其行。`「逐批折叠」` 每批之后自释，故其状惟容数、列等豫言之值。`「在临时作用域中」` 行一函毕，惟释其间新建之暂存，宜施于以果书于常驻张量之算。`「临时张量数」` 以察其漏。
- **常驻张量**：参数（`「转为参数」`）、常驻之缓（`「转为常驻」`）、优化之状、数据之集，各复一不登之存，其主释之（`「释放常驻」`、`「释放模块」`、`「释放数据集」`）。参数之梯亦常驻，可跨批而累，优化器之 `「清零梯度」` 释之。

## 自动微分

- 叶张量：`「张量自小数」「张量自整数」「全零张量」「全一张量」「常数张量」`（不需梯）；`「需要梯度」` 得同据而需梯之叶；`「分离」` 得不记算图之张量。
- 算果于“记梯”之时、入有需梯者，乃记其入与反传之函。`「不记梯度地」授以 类 于（会「无」而 …）` 行时不记算图。
- `「反向传播」于 损` 以全一为出之梯（`「反向传播于」` 可自给之），依拓扑之序自出而返，梯累于诸张量之梯格；`「取梯度」` 读之。
- 带梯之算：`逐元加、逐元减、逐元乘、逐元除`（依 NumPy 之法广播，其反求和归于原形）、`数加、数减、数乘、数除`、`幂`（整数次）、`小数幂`、`取负`、`矩阵乘`（[…, m, k] 乘 […, k, n]，批维广播）、`按轴求和、全部求和、均值、全部均值`（轴号可负）、`广播到`、`改形`（可有一项为负一）、`交换轴、转置`（末二轴）、`换轴`（任意之排）、`指数、对数、平方根、修正线性、双曲正切、反曲`、`对数求和指数`（任意之轴，先减其最大）、`软最大、对数软最大`（末维）、`查表`（嵌入，其反按行累加）、`卷积`（见下）。

## 卷积

`「卷积」于 入 于 核 于 步 于 补零` 为二维之互相关，据用 NHWC 之布：入 [N, H, W, Ci]，核 [K, K, Ci, Co]，果 [N, (H+2p−K)÷s+1, (W+2p−K)÷s+1, Co]。依 needle 之法：前向先补零，以跨步之视取每出位之 K×K×Ci 图块（im2col），抄为 [N×Ho×Wo, K×K×Ci]，乘以改为 [K×K×Ci, Co] 之核。其反：于核之梯为图块列之转置乘出之梯；于入之梯，以出之梯依步扩之（置于边长 H+2p−K+1 之全零张量，出不整除则末端补零），与空间翻转、通道互易之核（负步之视）行步一、补零 K−1−p 之卷积。

`「卷积层」于 入通道 于 出通道 于 核长 于 步 于 源`：核以何恺明均匀初之（扇入 K×K×入通道），偏 [出通道] 取 U(−1/√扇入, 1/√扇入)，补零为 K÷2。

## 模与损

模（类「模块」）有名、本层之参、子模、训练之标与前向之函。`「模块前向」于 模 于 入`；`「模块参数」` 递收诸参；`「训练模式」「评估模式」` 递设其标。

| 模 | 说 |
| --- | --- |
| `线性层 入数 出数 源` | y = x·W + b；W [入数, 出数] 以何恺明均匀初之，b [1, 出数] 取 U(−1/√入数, 1/√入数)；`无偏线性层` 无 b |
| `修正线性层`、`双曲正切层`、`反曲层` | 无参之激 |
| `顺序组合 诸模`、`残差连接 模` | 依次过之；y = f(x) + x |
| `丢弃层 率 源` | 训练时以所给之率置零、余者除以 (1 − 率)；评估时原样过之 |
| `层归一化 维数 小量` | 于末维归一，w 初为一、b 初为零 |
| `批归一化 维数 小量 动量` | 入 [..., 维数]：末维为特征，前诸维皆为样本，故 NHWC 之四维入即二维之批归一；训练时用本批之均与有偏之方差，且更滑动之统；评估时用滑动之统 |
| `卷积层` | 见上 |
| `嵌入层 词数 维数 源` | 表 [词数, 维数] 取标准正态；入为行号之张量 |
| `展平层` | [批, …] 化为 [批, 余元之数] |

损：`「软最大交叉熵」于 对数几率 于 标签`（对数几率 [批, 类数]，标签 [批] 或 [批, 1]，元为类号，还批内之均，形 [1]）；`「均方误差」于 预测 于 目标`。`「预测类别」于 对数几率` 得每行最大者之类号 [..., 1]；`「正确个数」于 对数几率 于 标签` 数所测之类等于标签者（同者取其前）；二者皆不记梯。

## 常用之模型

- `「多层感知机」于 诸宽 于 源`：宽之列 [d₀, …, dₙ]，相邻二层间为线性层，末层之外皆接修正线性。
- `「残差网络九」于 源`：needle 作业四之 ResNet9，入为 NHWC 之 [N, 32, 32, 3]：卷积批归一(3→16, 核七, 步四)、(16→32, 3, 2)、残差块(32)、(32→64, 3, 2)、(64→128, 3, 2)、残差块(128)、展平、线性(128→128)、修正线性、线性(128→10)；卷积批归一为卷积层、批归一化（小量 1e-5、动量 0.1）、修正线性，残差块为二 3×3 卷积批归一加残差之连。`「卷积批归一」「残差块」` 亦可独用。

## 优化之器

`「随机梯度下降」于 诸参 于 学率 于 动量 于 权衰`、`「亚当」于 诸参 于 学率 于 β₁ 于 β₂ 于 小量 于 权衰`，其更新之法同 needle：

- 随机梯度下降：g = 梯 + 衰减 × 参；u ← 动量 × u + (1 − 动量) × g；参 ← 参 − 学率 × u。以接口之就地线性组合为之（二至三召，不易其梯）。
- 亚当：g = 梯 + 衰减 × 参；m ← β₁m + (1 − β₁)g；v ← β₂v + (1 − β₂)g²；参 ← 参 − 学率 × m̂ ÷ (√v̂ + 小量)，m̂、v̂ 为修偏之矩。每参一召接口之亚当之更。

每步先 `「清零梯度」`，次前向、`「反向传播」`，乃 `「优化一步」`。参与状皆常驻，就地更之；无梯之参则略之。

## 数据

- `「张量数据集」于 入 于 目标`：首维为样本，各复一常驻之据；`「取批」于 数据集 于 诸序` 还（入，目标）二暂存张量。
- `「新数据加载器」于 数据集 于 批大 于 乱否 于 种`；`「一轮批次」` 得一轮样本序号之诸批（乱之以费舍尔–耶茨之洗，每轮各异）；`「逐批折叠」于 载器 于 初值 于（会「状」而会「入」而会「目标」而 …）` 逐批更其状，每批之后释暂存张量。
- `「读取手写数字」于 目名 于 图像之文件 于 标签之文件`：读已授之目中之 MNIST（IDX 之式、无符之字），图像缩至 [0, 1]、形 [样数, 784]，标签形 [样数, 1]。文首为 gzip 之魔数则先由压缩之接口解之（头之附段、文件名、注与头校皆越之），否则依偏由张量文件之接口径载于宿主张量；皆分段而载，每段 4 MiB。`「读取手写数字文件」` 读一 IDX 文件。
- `「读取十类小图」于 目名 于 诸批文件 于 最多`：读 CIFAR-10 二进制版（每条一字标签加 3072 字像素，R、G、B 各 32×32），以每文件万条次读之，至多 最多 条（零则尽读）；每段千条由张量文件之接口载之，以跨步之视易通道为先之像素为 NHWC，图像 [样数, 32, 32, 3] 缩至 [0, 1]，标签 [样数, 1]。

## 已知之限

码中以“待办事项”注之：

- 宿主张量须明释：暂存张量每步之末统释，跨步留用者失效。
- `「后端读出」` 一次尽读诸元，元逾二百万则逾宿主一交换之限。
- 丢弃之率为一则除以零。
- gzip 惟支单成员、解后不逾 128 MiB 之文件；CIFAR-10 之读以每批文件恰万条为设。
- 卷积之 im2col 抄出 [N×Ho×Wo, K×K×Ci] 之图块列而留至其反，批大、特征图大则耗存多。
- 速：诺节宿主之中央处理器后端。MNIST 多层感知机（784→256→10，亚当，批大 100）每步约十二毫秒（前向约五、反向约六、更约 0.7 毫秒，主机之负约五十五）；ResNet9 批大 32 每批约 0.2 秒。CIFAR-10 全量之训，俟图形处理器之后端成乃行之。
