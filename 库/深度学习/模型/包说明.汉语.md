# 深度学习模型

这是模型库：各大语言模型架构的权重载入与前向，全部算子经[张量计算接口](../../../豫言操作系统接口/张量计算/规范.汉语.md)交给宿主。模型文件的打开与载入、通用的逐词元生成与采样在「深度学习推理」，分词器与文件头解析在「深度学习」。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，登记在「共用库」下，依赖标准库、深度学习、深度学习推理、豫言操作系统基础与豫言操作系统张量计算。

## 用法

`「载入语言模型」于 上下文 于 模型文件` 按文件头的 `general.architecture` 选架构，返回语言模型（架构、模型名、层数、词表大小、新建会话）。`（模型 中「新建会话」）于 上下文长` 得到推理会话（前向、释放、上下文长），交给「深度学习推理」的 `「生成」`。每层在载入时就读好权重，给上下文长时才建这层的缓存与状态。

## 模块

| 模块 | 内容 |
| --- | --- |
| `层件` | 各架构共用：须得张量、释放全部、读单个小数、倒平方根（1/√n，按单精度求，同 llama.cpp 的 `1.0f/sqrtf(n)`）、按层载入权重、零张量与键值缓存（半精度 [上下文长, 键值头数, 头维]）、SwiGLU 前馈块、千问式注意力块、输出几率；层会话（前向、释放）、千问式层、把各层串成推理会话的 `「串成会话」`，以及语言模型的类型 |
| `千问三` | `「载入千问三」`（qwen3）；`「载入千问式」` 读千问式超参数与注意力权重，每层的前馈块由调用者给出，千问三混合专家也用它 |
| `千问三混合专家` | `「载入千问三混合专家」`（qwen3moe，如 Qwen3-Coder-30B-A3B）与混合专家块 |
| `千问三点五` | `「载入千问三点五」`（qwen35）：门控 DeltaNet 线性注意力块、门控全注意力块及两种层 |
| `语言模型` | `「载入语言模型」`：按架构分派 |

## 前向

千问三（每层，x 形状 [n, 嵌入维]，p 为起位）：h = 均方根归一(x, attn_norm)；问、键投影后按头均方根归一（attn_q_norm、attn_k_norm）并做旋转位置编码（前后半成对，基数 rope.freq_base）；键值写进缓存；分组查询因果注意力，缩放 1/√头维；x += 输出投影。然后 x += SwiGLU(均方根归一(x, ffn_norm))。全部层之后取最后一行，均方根归一（output_norm）再乘 output（缺失时用 token_embd）得对数几率。

千问三混合专家：注意力同千问三；前馈换成混合专家：取 h × ffn_gate_inp 的前 k 个（qwen3moe.expert_used_count），对这 k 个分数做软最大作权重（等于 llama.cpp 先软最大、取前 k、再除以它们的和，即 norm_w；少三次派发），每个选中专家算 SwiGLU（ffn_gate_exps、ffn_up_exps、ffn_down_exps 用「按专家矩阵乘」），按权重加总；没有共享专家。

千问三点五：第 i 层当 (i + 1) 是 full_attention_interval 的倍数时为门控全注意力，其余为线性注意力，之后都接 SwiGLU（前置归一 post_attention_norm）。主干层数为 block_count − nextn_predict_layers，多词元预测层不载入。

- 线性注意力：混 = h × attn_qkv，卷 = SiLU(因果卷积(混, ssm_conv1d, 卷积状态))，从卷取问 [n, 键头数, 键维]、键、值 [n, 值头数, 值维] 三个视图（键头数 = ssm.group_count，键维 = ssm.state_size，值头数 = ssm.time_step_rank，值维 = ssm.inner_size ÷ 值头数）；问、键二范数归一；β = 反曲(h × ssm_beta)，g = 软加(h × ssm_alpha + ssm_dt.bias) × ssm_a；o = 门控递推(问, 键, 值, g, β, 递推状态, 1/√键维)；o 按头均方根归一（ssm_norm）再乘 SiLU(h × attn_gate)，x += o × ssm_out。
- 门控全注意力：h × attn_q 的每头是（问，门）两段；问、键按头均方根归一后在前 rope.dimension_count 维做旋转位置编码；因果注意力的输出乘反曲(门)，x += 结果 × attn_output。纯文字输入时 rope.dimension_sections 各段的位置相同，等同普通旋转位置编码。

数学照 llama.cpp 的 qwen3、qwen3moe、qwen35 实现（2026-09 的 master）。

前向用张量计算接口 0.5.0 的融合算子（宿主有融合内核时一次派发算完，否则退回小算子的组合，结果与逐个调用小算子相同）：问、键、值三个投影（千问三点五的线性层是 qkv、门、β、α 四个投影）合成一次 `归一矩阵乘`（含前置均方根归一）；问、键按头归一、旋转位置编码与写键值缓存是一次 `问键旋转写缓存`；输出投影、降投影与混合专家的加权和都用 `矩阵乘加` 接上残差；SwiGLU 的门、升、激活与相乘是一次 `归一门控矩阵乘`，混合专家的门、升是一次 `按专家门控矩阵乘`；末层归一与输出投影是一次 `归一矩阵乘`。千问三一层解码约为 6 次派发（注意力分段时 7 次）。

## 已知限制

- 缓存按调用者给的上下文长一次建好，不会增长；门控递推的预填充逐词元计算。
- 千问三点五的分词预处理（tokenizer.ggml.pre = qwen35）比 qwen2 多把组合附加符（\p{M}）算作字母，「深度学习」现仍按 qwen2 处理（待办事项），不含这类字符的文字结果相同。
- 大模型的权重整个读进宿主内存（张量文件接口），Qwen3-Coder-30B-A3B（Q4_K_M 约 18.6 GB）与 Qwen3.8-27B（约 16.8 GB）需要同样多的空闲内存。
