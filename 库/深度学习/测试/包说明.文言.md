# 深度学习测试

深度学习库之单元之试（`X。测试。豫`），用合成之小数据，不须真之模型文件：

- `散列表。测试`：字键之表之登、查、覆与缺；整数键之表登万键而尽查得之。
- `模型格式。测试`：字之小具（小端整数、单精度之位、UTF-8）；合成 GGUF 文件头之元数据、数据段之对齐、张量之形之倒序；头字截断则报不足，魔数与版不合则报误。
- `分词。测试`：Qwen2 预分词之诸支（缩写、字、数、标点、连白与换行、中文标点、表情、全角之字）；小词表（二百五十六字词、八合并之词、四特殊之词）之 BPE 合并之序、特殊之词之切（长者先）、解码与流式之解；伪随机可复现。

`合成。豫` 依 GGUF 第三版之式，拼试用之文件头之字与小词表。

## 籍

所有者曰豫言，版本 0.1.0。此包为库，惟供试，依标准库、单元测试与深度学习。试包依所试之库，故登于「共用库」之下，不登为深度学习之子包。

## 用法

于仓根构而行之（以分词之试为例）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 深度学习测试 分词。测试 --输出 yy深度学习分词测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy深度学习分词测试.wasm
```

所出末行之“当前失败数”当为 0。全树之试自能寻之：`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/深度学习`。
