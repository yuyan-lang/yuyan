# 深度学习测试

深度学习库的单元测试（`X。测试。豫`），用合成的小数据，不需要真实模型文件：

- `散列表。测试`：字节键表的登记、查找、覆盖与缺失；整数键表登记一万个键后全部查回。
- `模型格式。测试`：字节工具（小端整数、单精度位型、UTF-8）；合成 GGUF 文件头的元数据、数据段对齐、张量信息的形状倒序；头部截断时报不足，魔数与版本不对时报错。
- `分词。测试`：Qwen2 预分词各分支（缩写、字母、数字、标点、连续空白与换行、中文标点、表情、全角字符）；小词表（256 个字节词元、8 个合并词、4 个特殊词元）的 BPE 合并次序、特殊词元切分（长者优先）、解码与流式解码；伪随机数可复现。

`合成。豫` 按 GGUF 版本三的布局拼出测试用的文件头字节与小词表。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试与深度学习。测试包依赖被测库，所以登记在「共用库」之下，没有登记为深度学习的子包。

## 使用

在仓库根目录构建并运行（以分词测试为例）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 深度学习测试 分词。测试 --输出 yy深度学习分词测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy深度学习分词测试.wasm
```

输出末行的“当前失败数”应为 0。全树测试会自动发现这些测试：`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/深度学习`。
