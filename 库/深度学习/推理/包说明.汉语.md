# 深度学习推理

这是经[张量计算接口](../../../豫言操作系统接口/张量计算/规范.汉语.md)在宿主上做大语言模型推理的公共部分：从 GGUF 文件载入权重，以及各架构通用的逐词元生成与采样。各架构的前向在同目录 `模型/` 下的「深度学习模型」；文件头解析、分词器与伪随机数来自「深度学习」。它依赖文件、张量计算、[张量文件](../../../豫言操作系统接口/张量文件/规范.汉语.md)三个操作系统接口，只能在同时实现这三个接口的宿主上运行（现为路一 Node 宿主）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、深度学习、豫言操作系统基础、豫言操作系统文件、豫言操作系统张量计算与豫言操作系统张量文件。

## 模块

| 模块 | 内容 |
| --- | --- |
| `模型文件` | `「打开模型文件」于 目录名 于 路径`：取已授目录、只读打开、顺序读出文件头（每次至多 16 MiB，解析报不足时目标加倍续读）并解析。`「载入张量」于 上下文 于 模型文件 于 名`：按数据段起点加偏移，经「由文件载入张量」直接载入宿主张量，数据不经豫言字节串。GGML 类型 0、1、30、8、12、14、24、26 依次对应单精度、半精度、脑浮点、块量化八位、超块量化四位、超块量化六位、八位整数、三十二位整数。另有 `「打开授权文件」`、`「读完文件」`（读小文件）与 `「系统错误文字」` |
| `生成` | `「推理会话」`：前向（词元号们、起位 → 最后一个词元的对数几率 [1, 词表大小]，并更新会话的缓存与状态）、释放、上下文长，由各架构给出。`「生成」于 会话 于 提示 于 最多 于 温度 于 种子 于 停止号们 于 回调`：先整段预填充，再逐词元解码；温度为零时取最大下标，否则「按概率抽样」（前 20 个、累积概率 0.8，Qwen3 非思考模式的推荐值；随机整数来自可设种子的伪随机源）；遇停止词元或达到上限即止，每个非停止词元调用一次回调（给词元号与产生它的对数几率，几率在回调返回后释放）；返回提示词元数、预填充用时、解码步数、解码用时（微秒）与生成的词元号 |

## 已知限制

- 矩阵乘的激活以单精度参与，llama.cpp 在 CPU 上会先把激活量化成 Q8_0 或半精度，所以对数几率与 llama.cpp 有小差异；贪心生成在前两名概率很接近时可能分歧。
- 权重整个读进宿主内存，模型多大就要多少空闲内存。
