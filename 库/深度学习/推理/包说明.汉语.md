# 深度学习推理

这是经[张量计算接口](../../../豫言操作系统接口/张量计算/规范.汉语.md)在宿主上做大语言模型推理的公共部分：从 GGUF 文件载入权重，以及各架构通用的逐词元生成与采样。各架构的前向在同目录 `模型/` 下的「深度学习模型」；文件头解析、分词器与伪随机数来自「深度学习」。它依赖文件、张量计算、[张量文件](../../../豫言操作系统接口/张量文件/规范.汉语.md)三个操作系统接口，只能在同时实现这三个接口的宿主上运行（现为路一 Node 宿主）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、深度学习、豫言操作系统基础、豫言操作系统文件、豫言操作系统张量计算与豫言操作系统张量文件。

## 模块

`推理会话` 的 `隐藏前向` 接受词元号列表与起位，返回末层 RMS 归一后的全部隐藏状态 `[词元数，隐藏维]`，并更新该会话状态。返回量由调用者释放；每段独立嵌入输入新建会话。

`隐藏池化` 提供 `隐藏均值池化`、`隐藏末词池化` 与 `嵌入单位归一`，三者都是张量到张量，保留输入，返回量由调用者释放。单位归一使用 L2 范数，零向量保持零。

`批前向项` 为推理会话、词元号列表与起位三项；`批前向` 接受其列表，依输入顺序返回各会话的 logits 张量列表。同轮先派发各会话的真实算子，再由消费者读取与采样；各会话独立维护缓存。每个返回量由采样者释放，会话由请求管理者在请求结束时释放。同会话每轮只提交一项。跨会话算子融合留待后续版本。

| 模块 | 内容 |
| --- | --- |
| `模型文件` | `「打开模型文件」于 目录名 于 路径`：取已授目录、只读打开、顺序读出文件头（每次至多 16 MiB，解析报不足时目标加倍续读）并解析。`「载入张量」于 上下文 于 模型文件 于 名`：按数据段起点加偏移，经「由文件载入张量」直接载入宿主张量，数据不经豫言字节串。GGML 类型 0、1、30、8、12、14、24、26 依次对应单精度、半精度、脑浮点、块量化八位、超块量化四位、超块量化六位、八位整数、三十二位整数。另有 `「打开授权文件」`、`「读完文件」`（读小文件）与 `「系统错误文字」` |
| `生成` | `「推理会话」`：前向（词元号们、起位 → 最后一个词元的对数几率 [1, 词表大小]，并更新会话的缓存与状态）、按下标前向（同前向，词元号是宿主上的三十二位整数张量）、释放、上下文长、可录制（一步解码只有注意力、问键旋转写缓存、旋转位置编码与位置有关时为阳，千问三为阳，千问三点五为阴），由各架构给出。`「生成」于 会话 于 提示 于 最多 于 温度 于 种子 于 停止号们 于 回调`：先整段预填充，再逐词元解码；温度为零时流水解码：按行求最大下标留在宿主上，先用它记下下一步的按下标前向，再读出这一步的词元（宿主只等到这一步算完，下一步的计算与回调、记录重叠；遇停止词元时下一步白算一次）；会话可录制时改用录制重放：录下第二个词元的那一步（按下标前向，再按行最大下标），之后各步「重放录制」（位移为与录制那步的位置差），下标与几率各用两块轮流，同样先记下下一步再读出这一步的词元，重放得阴时转回流水解码；否则「按概率抽样」（前 20 个、累积概率 0.8，Qwen3 非思考模式的推荐值；随机整数来自可设种子的伪随机源）；遇停止词元或达到上限即止，每个非停止词元调用一次回调（给词元号与产生它的对数几率，几率在回调返回后释放）；返回提示词元数、预填充用时、解码步数、解码用时（微秒）与生成的词元号 |

## 已知限制

- 矩阵乘的激活以单精度参与，llama.cpp 在 CPU 上会先把激活量化成 Q8_0 或半精度，所以对数几率与 llama.cpp 有小差异；贪心生成在前两名概率很接近时可能分歧。
- 权重整个读进宿主内存，模型多大就要多少空闲内存。

## 安量权重直接载入

`载入安量模型参数` 接收张量上下文、授权目录名和 HF 安量权重文件相对路径，只读取文件头并解析目录，再经已有张量文件接口按绝对偏移直接取得宿主张量。返回原 HF 参数名与张量句柄，保持 F32、F16、BF16 等已支持类型和形状。调用者负责张量句柄释放。基本 CI 烟测覆盖原 HF 参数名保留。

HF config、分词器配置、架构权重名映射和本地完整生成接线列为后续事项；实际文件与宿主加载核验等待配套宿主。
