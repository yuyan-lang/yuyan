# 深度学习推理

此由[张量计算之接口](../../../豫言操作系统接口/张量计算/规范.文言.md)于宿主行大语言模型之推之公共之部：自 GGUF 文件载权，及诸架构通用之逐词而生与抽样。诸架构之前向在同目 `模型/` 下之「深度学习模型」；文件头之解、分词器与伪随机出于「深度学习」。又依文件、张量计算、[张量文件](../../../豫言操作系统接口/张量文件/规范.文言.md)三操作系统之接口，惟兼行此三者之宿主可行之（今为路一 Node 之宿主）。

## 籍

所有者曰豫言，版本 0.1.0。此包为库，依标准库、深度学习、豫言操作系统基础、豫言操作系统文件、豫言操作系统张量计算与豫言操作系统张量文件。

## 诸模

| 模 | 所含 |
| --- | --- |
| `模型文件` | `「打开模型文件」于 目录名 于 路径`：取已授之目，只读启之，顺读其头（每次至多 16 MiB，解之报不足则倍其所期而续读）而解之。`「载入张量」于 境 于 模型文件 于 名`：依数据段之始加其偏，由「由文件载入张量」径入宿主之张量，数据不经豫言之字节串。GGML 类号零、一、三十、八、十二、十四、二十四、二十六，依次对单精度、半精度、脑浮点、块量化八位、超块量化四位、超块量化六位、八位整数、三十二位整数。又有 `「打开授权文件」`、`「读完文件」`（读小文件）与 `「系统错误文字」` |
| `生成` | `「推理会话」`：前向（词号、起位 → 末词之对数几率，且更会之缓存与状态）、按下标前向（同前向，词号为宿主上之三十二位整数张量）、释、上下文长，诸架构予之。`「生成」于 会 于 提示 于 所生之极 于 温度 于 种 于 止词 于 回调`：先以全提示预填，后逐词解码；温度为零则流水解码：依行求最大之序留于宿主，先以之记次步之按下标前向，乃读此步之词（宿主惟候此步毕，次步之算与回调、记录相叠；遇止词则次步徒算一回），否则「按概率抽样」（前二十、累积概率 0.8；随机之数出于可设种之伪随机）；遇止词或满其限则止，每生一非止之词即调回调一次（予词号与生之之对数几率，回调返后释之）；还提示之词数、预填之时、解码之步、解码之时（微秒）与所生之词号 |
