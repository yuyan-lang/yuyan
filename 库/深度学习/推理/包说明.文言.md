# 深度学习推理

此库由[张量计算之接口](../../../豫言操作系统接口/张量计算/规范.文言.md)于宿主行大语言模型之推：自 GGUF 文件载权、Qwen3 之前向与逐词而生。文件头之解、分词器与伪随机出于「深度学习」；又依文件、张量计算、[张量文件](../../../豫言操作系统接口/张量文件/规范.文言.md)三操作系统之接口，惟兼行此三者之宿主可行之（今为路一 Node 之宿主）。

## 籍

所有者曰豫言，版本 0.1.0。此包为库，依标准库、深度学习、豫言操作系统基础、豫言操作系统文件、豫言操作系统张量计算与豫言操作系统张量文件。

## 前向

每层（x 形为 [n, 嵌入维]，p 为起位）：

1. h = 均方根归一(x, attn_norm)。
2. q = 旋转位置编码(均方根归一(改形(矩阵乘(h, attn_q), [n, 问头数, 头维]), attn_q_norm), p)；k 亦然（键值头数，attn_k_norm）；v = 改形(矩阵乘(h, attn_v), [n, 键值头数, 头维])。旋转位置编码前后半成对（NEOX），其基取 rope.freq_base。
3. k、v 以「写入行」书于此层缓存自第 p 行始。
4. a = 注意力(q, 键缓存, 值缓存, p + n, p, 1/√头维)，改形为 [n, 问头数 × 头维]；x = x + 矩阵乘(a, attn_output)。
5. h2 = 均方根归一(x, ffn_norm)；x = x + 矩阵乘(反曲加权(矩阵乘(h2, ffn_gate)) × 矩阵乘(h2, ffn_up), ffn_down)。

诸层既毕，取末行，均方根归一（output_norm）而乘 output，得对数几率。每层中间之张量用毕即释。注意之缩以单精度之张量算之，同 llama.cpp 之 `1.0f/sqrtf(头维)`。
