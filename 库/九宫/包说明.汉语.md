# 平铺桌面

2026-10-11显示设置：启动取得显示面后应用保存的分辨率，再按保存的缩放运行会话。改缩放立即重排，外部程序格在尺寸或有效像素比变化时重设子程序显示面，把父桌面的比六四传给子程序；文字、指针与脏区共用同一有效比。缩放0使用宿主自动值，分辨率0沿用当前尺寸；保存的模式设置失败时保留设置。

2026-10-12 每个窗口独立成任务（[提案 00015](../../提案/00015-桌面程序独立成任务.汉语.md)）：豫言操作系统上有 `/工具/桌面程序。豫行`（包「桌面程序」）时，终端、文件浏览、任务管理器、设备管理器、设置、搜索与编辑器都以外部程序格起成这个程序的一个任务，任务管理器（「列出役」）里各占一行。窗口要外壳办的事（打开文件、右侧打开、运行程序或脚本、设标签标题、重读设置、要窗口列表、按种类名打开窗口）经「子程序显示」0.2.0 的外壳请求交给桌面，桌面经来信叫窗口跳到某行或关闭；关窗口时先送“请关闭”，程序自己收尾退出，再关一次就直接结束它。终端窗口里运行的程序照样收键盘输入（子程序 0.8.0，经初始任务转交）。宿主上行在起的桌面（提案 00039 第三步，环境变量 `豫言桌面程序` 给出本机的桌面程序）同样把这些格子起成桌面程序的进程，各自登进行在的任务表；浏览器、诺驿与不经行在的原生桌面照旧在本进程里显示这些格子（嵌入）。后续版本的事项：画面直接映射、只读段共享、构建输出与差异另成窗口、别的窗口改了设置时其余窗口随之更新。

2026-10-20 行在停止时桌面自行退出（议题 #136）：行在起的桌面带着 `豫言行在屏`，值是行在的进程号。行在收场时在私有根的系统目录写下“请退桌面”并等桌面退出，逾时结束它；行在被杀或崩掉时，桌面每秒起一次 `ps -p 行在进程号` 看行在还在不在，不在了就退。标记的路径按 HOME 或 `豫言行在目录` 算（「行在桌标」），不另传。桌面程序的环境是执行器给的授权几项加 HOME、PATH 与附庸，看不到 `豫言行在屏`；它们在父桌面的显示面关闭时读到管道尽头，随即结束。不经行在的桌面（豫言工作台、裸机、浏览器）没有 `豫言行在屏`，行为不变。

平铺桌面是豫言的窗口系统（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一棵分割树把屏幕划成不重叠的矩形，叶子是标签组，标签里是格子程序。终端、文件浏览、任务管理器、设备管理器、设置与外部程序都是格子程序，同一种可以开多个。外壳只管布局与分派，格子程序各自更新；外部程序各在自己的任务里运行。

## 入口

```yuyan
寻观「九宫」之书。

「行平铺桌面」于「授权根」曰『桌面』于「布局」曰「题壁布局」。
```

「行平铺桌面」在显示面 `主窗口` 上用自绘后端运行，点活动栏最下面的“返”（返回命令行）时结束并归还显示面，调用方接着运行。「授权根」是文件浏览、编辑保存、终端环境（`.环境`）与设置数据库（`桌面设置.数据库`）所用的授权目录名；「布局」是开场的默认布局：「题壁布局」（开场整块是一个空组，只画题壁；文件浏览、终端等从活动栏打开，开在这一组里，全关掉后题壁又露出来；裸机开机壳的「图形」、行在桌面与 `豫言操作系统/应用/图形桌面` 用它，授权根“桌面”）、「浏览编辑布局」（左文件浏览、右空编辑组；`应用/百工坊/豫言工作台` 用它，授权根“工作台”）与「浏览终端布局」（左文件浏览、右终端，焦点在终端；外壳测试用它）。没有标签的组整组画题壁（桌面壁纸）：纸色底上正中一行墨色大字欢迎语“欢迎使用豫言系统”，看去是桌面的底，组上方的标签栏与按钮一并让给壁纸。

浏览器入口在模块 `网页`（不在默认导入里）：「行网页平铺桌面」于「容器」为 页面容器 ID 于「服务」为 浏览服务 于「台更新」为 编辑格的工作台更新 于「外事」为 外事处理 于「初始路径」为 路径，用界面文树后端跑外壳，开场左文件浏览、右编辑组，用流式视图排版；浏览器里只开文件浏览、编辑、搜索与构建输出格。[工作台网页](../工作台/网页/包说明.汉语.md)的「行网页书斋」与「行网页书斋带外事」经它运行。

## 界面与操作

左边 36 逻辑像素的活动栏是一列线条图标（出自[图标库](../图标/包说明.汉语.md)，按像素比抗锯齿渲染，悬停显示中文提示）：文件浏览（文件夹，已开则聚焦第一个）、终端（带提示符的屏幕，新开）、任务管理器（脉搏折线，新开）、设备管理器（芯片，新开）、设置（齿轮，新开）、文件搜索（放大镜，已开则聚焦）、程序（九宫格，已开则聚焦）、软件（店铺），最下面是返回命令行（从门框出去的箭头）。这些按钮都有等价的壳命令 `「辟窗」于「种类」曰『设备管理器』`（种类是终端、文件浏览、任务管理器、设备管理器、设置、搜索、市肆与已装图形软件的名称）：“程序”等价于 `「辟窗」于「种类」曰『程序』`，开启动台格；“软件”等价于 `「辟窗」于「种类」曰『市肆』`，开 `/工具/市肆。豫行`，还没有这个程序时在状态栏提示“市肆尚未安装”。在桌面终端里执行时，终端记下种类名，桌面在这一轮更新后照活动栏的做法打开（独立格经外壳请求「请打开窗口」交给父外壳）；开机壳与宿主上报“桌面没有运行”。中间按分割树排布各标签组，每组上方是 28 逻辑像素的标签栏：标签（点击切换，× 关闭，按住可以拖到别处），右边是同样画法的小图标按钮：移到右边（向右的箭头：右边有组就移进去，没有就拆出一组）、左右拆分、上下拆分（拆分本组，新组里开一个同种格子）、单格全屏（再点还原）、关闭当前标签；文件浏览格选中可运行的文件时前面多一个“运行”；当前格是编辑格时，前面还有它的视图切换钮；是有画面的外部程序格时，前面有“文字”“画面”切换钮；桌面程序格（终端、文件浏览等桌面自己的窗口）只显示画面。焦点组的当前标签有朱红下划线。组之间的分割条可以拖动调比例。底部 20 逻辑像素的状态栏显示焦点格的标题、工作台的错误提示与运行中的外部程序数。

在组里任何地方按下指针即聚焦该组；格子里的任何操作也会聚焦它所在的组。

拖标签（照 VS Code 的手感，只认主键）：按下标签即选中它，按住移动 5 逻辑像素以上算拖动，松开时按指针位置放下。落在另一组的标签栏上或内容区中间，标签移进那一组（加在末尾）；落在某组内容区的左、右、上、下边缘（各占四分之一，角上取最近的一边），就在那一边拆出新组放这个标签，自己所在的组也可以这样拆；组里只剩这一个标签时，拖到自己身上保持原样。拖动中将要放下的区域以半透明朱色高亮（放进组时是整组，拆分时是那一半）。按下后移动不到 5 逻辑像素算点击。

快捷键的修饰键是交替（Alt、Option）：交替加回车新开终端，加 E 新开文件浏览，加方向键移焦点，再加上档把当前标签移到那一边（那边没有组就拆出一组），加 \ 左右拆分，加 - 上下拆分，加 W 关标签，加 F 单格全屏，加 1–9 切标签，加 [ 与 ] 调焦点组所在分支的比例。每个操作都有鼠标入口（移标签用拖标签或“移到右边”钮）。裸机的 PS/2 与 USB 键盘 2026-10-11 起交修饰键与按键抬起，快捷键在裸机上同样可用；焦点在终端文本框里时交替组合键照样到达外壳（显示控件按住交替时不编辑文本框）。Ctrl+C（2026-10-12）交给焦点终端：终端的壳会话正在运行一句时只打断这一句（2026-10-14，等价的壳命令是「辍」，见用户态桌面的「役令」），停在提示符上时只清掉输入框；有选区时由文本框复制选区（2026-10-21 起控制加上档加 C 复制选区、加 V 粘贴、加 A 全选，终端锦囊里也有这几项）。会话里「辞」（退出码零）之后，外壳在这一轮计时更新之后关掉这个终端（「关诸告退终端」），独立格的任务随之结束。

锦囊（2026-10-21，[提案 00048](../../提案/00048-锦囊.汉语.md)）：每个可操作处副击（右键单击；林檎上控制加主键单击）弹出菜单，每项都带等价的壳命令，图形界面与壳命令做同一件事。在标签上副击或点标签栏右端的“≡”钮，弹出这个窗口的窗口菜单：关闭（交替加 W）、左右拆分（交替加 \）、上下拆分（交替加 -）、单格全屏（交替加 F，勾记这座宫是否正单格全屏）、移到（左组、右组、上组、下组，交替加上档加方向）、移进宫（新宫，交替加 O；以及它所在宫之外的各宫）、归回原宫（交替加上档加 O，没有原处时不可用）。在空组的题壁、活动栏空处与状态栏空处副击，弹出桌面菜单：新终端（交替加回车）、文件浏览（交替加 E）、程序、软件、任务管理器、设备管理器、设置、搜索，宫（各宫，今宫为勾）、显示（缩放：自动、一百、一二五、一五零、二百；字样：文楷、无衬线、衬线、等宽）、电源（返回命令行、重启、关机，后两项只在豫言操作系统上可用）。在状态栏的宫名上副击弹出宫菜单（入宫、全部归回）；在活动栏的窗口图标上副击弹出栏菜单（新开、在新宫打开）。菜单由外壳状态生成（模块 `宫策`），桌面每轮把各窗口与桌面的菜单写进 `/系统/桌面窗列。数据。豫` 的顶层「窗囊」（「诸窗囊述」），供壳命令「囊目」读。

## 宫（工作区）

九宫里可以有好几座宫（工作区，[提案 00047](../../提案/00047-窗口工作区.汉语.md)）：一座宫是一棵分割树连同焦点组与单格全屏，宫一是主宫，总在。格子表全桌面一份，窗口在宫之间移动只改它挂在哪棵树上，程序不重起。标签栏的“出”钮（交替加 O）把当前窗口徙进一座新宫（宫号取二起最小的空号），主屏跟过去显示它；窗口第一次徙出时记下原宫与原组，“归”钮（交替加上档加 O）把它送回去（原组没了放进原宫的焦点组，原宫没了放进宫一）。交替加控制加宫号入宫（主屏换成显示那座宫），交替加上档加宫号把当前窗口徙进那座宫（主屏不跟）。不止一座宫时状态栏最左列出各宫，今宫是朱色字，别的宫点了入宫。宫一之外的宫空了即撤。桌面程序的请求、程序结束关窗这类不经界面的事在发起窗口所在的宫里办，新窗口开在那座宫。「诸宫窗述」给出壳命令「窗列」印的宫窗表，「徙格」「归格」「归宫诸格」「临宫」供壳命令调用。壳命令「徙窗」「归窗」「入宫」「关窗」「拆窗」「全窗」「移窗」「凝窗」与加了「宫」的「辟窗」照「辟窗」的路走：几席的壳请求把一条窗请（种类、参数与发起窗号）写成 `/系统` 下的一个窗请文件（名字以 `请求打开窗口-` 起头），桌面每轮按名排次取走、逐条办；终端起壳会话时环境里有 `豫言窗号`，所以省了「号」就是发起者自己的窗口。剖、旁开格与右侧打开在建格之前先把它设成新窗口将要得到的格号，那几种窗口起的终端同样拿到自己的格号。查询命令「窗列」读桌面写下的 `/系统/桌面窗列。数据。豫`（桌面每轮在宫或窗口变了时重写）；同一个文件里的「窗囊」是各窗口的窗口菜单快照（提案 00048 4.4），「囊目」读它，给了号只印那个窗口的一段。

宫可以有自己的显示面（宿主窗口）：桌面在多面会话（门面「诸面运行」）里跑时开场「许独面」，此后新开的宫各取一块显示面（面名就是宫名，如“宫二”；行在授权 `宫*=960x640`），那块面上只画这座宫的标签栏与各组，没有活动栏与状态栏，看去接近原生窗口；主屏不跟过去，状态栏里它是浅色字。「诸宫面」给出多面会话要的面（主窗口与每座有自己显示面的宫，标题是宫名加焦点窗口的标题）；「宫面观」是宫面的视图，它发来的消息包成「宫内信」在那座宫里办（「于宫办」），主屏不跳（「定屏」「归屏」：主屏总显示共用主屏的宫）。每块面的尺寸各记各的（「记面尺」「补视尺」），临到哪座宫视图尺寸就换成显示它的面的，外部程序格按它定显示面尺寸。宿主给不了显示面（裸机、诺驿、浏览器小窗被拦）交来「映面未得」时，那座宫改为共用主屏、主屏跟过去（「宫面未得」）；用户关掉宫的宿主窗口交来「映面已闭」时等于「归窗」于那座宫，窗口各回原处，宫随之撤销（「宫面已闭」）。宫空了即撤，它的显示面随之归还、宿主窗口关闭。

## 格子程序

- **终端**：`几席` 的终端仿真（2026-10-16 起：按键原样交给壳会话，屏上摹写壳的输出，与开机壳是同一个逐键编辑器），命令处理与开机壳相同（「桌面令平台」）。格子经格子环境里的「终端程序」（更新、视图、轮询、运行程序）调用它（文件浏览的“运行”钮与“终端 路径”开窗经「运行程序」直接启动程序或 。脚本。豫，不拼成句子交给壳编译，2026-10-14），原生入口给「终端程序于平台」，浏览器给「暂不可用终端程序」，所以浏览器包不链接壳的编辑器与拼音表。有焦点的终端格里，光标处收原样输入的像素图自动聚焦（「加自动凝神」；输出行的文本框不自动聚焦，点它只是去选字）。每个终端各有自己的状态、运行中的子程序与空轮询退避（250 毫秒起，至多 2 秒）；子程序未成行的输出余文按句柄分开。当前路径与开机壳共用一个。「辞」命令关掉这个终端格。终端挂在「终端观带囊」上（2026-10-21，提案 00048 戊路）：输出行的每一行是一个单行文本框，指针拖选、双击选词、上档加点击扩选，控制加上档加 C 复制选区、加 V 粘贴（换行即回车，多行逐行执行）、加 A 全选；在输出行里打出的字只把新打进的一段交给壳，换号加一让焦点回到光标像素；终端挂「锦囊」（复制、粘贴、全选、清屏、打断、新终端、左右与上下拆分、关闭，每项带等价的壳命令，拆分与关闭写窗请交给桌面，桌面没在运行时不可用）。
- **文件浏览**：工作台的资源侧栏（文件与包两种视图、资源树、包树；豫言操作系统桌面即授权根“桌面”上只有文件视图，侧栏上方只留新建会话钮），经「映射信」接进外壳。每个文件浏览格有自己的资源树（展开状态各自分开），文件缓冲等共享状态放在外壳的工作台状态里。点文件行即选中它：以 .wasm 结尾或没有扩展名的文件读文件头认出可执行文件（豫行文件或网页汇编），名字以 `。脚本。豫` 结尾的是脚本；不是可执行文件的点一下：有已装图形软件认得这个后缀（名帖的“所开”）就开一个外部程序格运行它、把这个文件作第一个参数（与壳命令「开卷」同），没有对应的程序就在编辑格里打开。选中后按回车或点标签栏的“运行”即运行：可执行文件开一个外部程序格，脚本开一个新终端格执行「脚本」；可执行文件也可以双击（半秒内再点同一行）运行。包视图、新建会话打开的文件同样进编辑格。新格子放进上一个焦点组（文件浏览格所在的组以外）；只有一组时往右拆出一组。文件行、目录行与侧栏空处各有锦囊（右键菜单，提案 00048 丁路）：文件行是打开、运行、在编辑器中打开、重命名、删除、复制、剪切、复制路径与详情，目录行是展开或收起、新建文件、新建目录、在此开终端、粘贴、复制、剪切、重命名、删除、复制路径与详情，空处是新建文件、新建目录、粘贴与刷新。每一项都带等价的壳命令（如 `「案牍」之「焚」于『路径』`、`「纳袋」于『路径』`）。复制、剪切记在共享工作台状态的卷夹里（路径与是否剪切），粘贴时复制或移动进来、同名加“副本”；新建文件与目录先取暂名、选中它并打开改名输入以取名字；删除第一次只提示确认，第二次才删，目录连同内容删去。
- **任务管理器**：`几席` 的任务管理器，相当于每秒运行一次壳命令「列出役」（ps）：每秒重查任务监测接口，整屏换成同一张任务表（任务数、统计范围与采样时间，表头，每个任务一行），桌面窗口的名称写“窗口标题 · 程序名”。每个任务行挂锦囊（提案 00048）：打断（`「辍」于「号」曰「七」`）、结束任务（`「辍役」于「号」曰「七」`，先点一次换成“确认结束任务”）与桌面窗口的转到窗口（`「凝窗」于「号」曰「三」`）；动作的结果显示在表前一行。嵌入运行时终端、文件浏览等格子程序与桌面同在一个任务里，表里算作那一个任务。裸机「图形」、图形桌面与豫言工作台共用这个外壳，三处都这样显示。
- **设备管理器**（2026-10-13）：`几席` 的设备管理器，整屏是壳命令「器列」的同一张设备表（设备数与已驱动、无驱动、失败的个数，表头，每个设备一行：总线、位置、类别、驱动、状态、厂商号:产品号、类码），没有驱动的行灰色、驱动失败的行朱色；每两秒重查设备接口，插拔 USB 设备后随之更新。格子只作显示；在豫言操作系统以外的宿主上，整屏是一行错误提示。
- **设置**：`几席` 的系统设置；设置全局一份，改了存进设置数据库。字样、缩放、分辨率各是一个「囊钮」下拉（提案 00048），钮上写当前值，菜单里勾着当前那一项。
- **程序**（启动台，2026-10-20）：模块 `博古`。图标格子：每格是 96 逻辑像素见方的可点方块，图标在上、显示名在下；内建六种窗口（终端、文件浏览、任务管理器、设备管理器、设置、搜索）用图标库现成的图标，已装图形软件用 `/软件/名称。图标.png`（画谱解码、缩成方形），没有图标时用九宫格图标。点一格与 `「辟窗」于「种类」曰『名称』` 等价（独立格经外壳请求交给父外壳）。每个图标挂锦囊（提案 00048）：打开（同上）；已装的图形软件另有卸载（`「卸软件」于「名称」曰『名称』`，宿主上没有 `/软件` 时不可用）与详情（`「软件讯」于「名」曰『名称』`，在格子下方一行显示版本与简介，简介来自安装时记下的目录介绍）。格子每两秒重读一次 `/软件/已装软件。数据。豫`，装了新软件随之出现；视图照设计语言写成控件树，经匠心门面的「作门面」交自绘后端。
- **外部程序**：以「遣使附映面」异步启动（不带参数；当前目录设为程序所在目录，环境取自 `.环境`），把显示面 `主窗口` 转授给它，尺寸是格子内容区的物理像素，像素比取显示面的（视图经「行门面尺寸比计时保位会话」收到像素比）。有显示面时每 50 毫秒「取使者画面」，新画面以像素图显示（版本号加一，带变化区域）；格子尺寸变了就「设使者映面尺寸」，程序按新尺寸重画。格子有焦点时，按键、文字、指针与滚轮经「原样输入时」原样收下，换成显示接口的输入事件，以「送使者入事」转给程序；交替按着时按键与文字留给外壳快捷键。程序还没交画面时格子显示文字输出（完整的行才显示）；有画面时标签栏多一个“文字”“画面”切换钮。平台返回资源暂不可用时只取文字输出。结束后标签与内容标出退出码；关掉标签即终止子程序并收取，没收完的句柄由计时继续收取。裸机上子程序显示要求外壳在初始任务里（开机壳的「图形」即是）；原生上子程序以 `--授权子程序 名=绝对路径` 授权，名字是以斜线开头的授权根内路径；名字也可以是一个目录（如 `/软件`），目录里的程序都能起；余段里的 `..` 段、`.` 段与空段一律拒绝，出不了授权目录（2026-10-21，议题 258）。
- **编辑**（第六步）：工作台的正文视图，文件的文档或原始代码视图、`.会话` 会话（上方一排引用按钮）、“差异：”页都是编辑格，格子只记路径；画之前把共享工作台状态的当前路径投影成本格路径，同一文件在两个编辑格里共用光标与视图选择。标签栏右侧是“右侧打开”（往右拆出一组开同一文件）与文档、原始代码切换；焦点在编辑格时状态栏右边是光标行列、构建运行时的停止钮与文件操作（包说明、检查、构建、类型检查、改名、删除）。保存、改名、删除落在授权根；改了没存的文件关不掉。点链接、看差异、改名时当前路径变了，本格跟着换路径。
- **搜索**（第六步）：工作台的文件搜索视图（活动栏“搜”，已开则聚焦）；点结果在编辑组打开，“返回文件”关掉搜索格。
- **构建输出**（第六步）：检查、构建、类型检查经后台任务（具名子程序“豫构”）运行，有构建输出就在编辑组下方拆出一格（占三成）显示，点诊断打开文件并定位，“收起构建结果”或关掉标签就收起。请求回复（会话）经具名子程序“模型请求”。

## 计时

外壳的计时间隔取各格子需求的最小值：终端有子程序在运行时按退避间隔，任务管理器 1 秒，设备管理器 2 秒，启动台 2 秒（重读已装软件），外部程序在运行时有显示面的每 50 毫秒（豫言操作系统上每半秒，子任务交了新画面或外壳请求时外壳提前醒来取画面、办请求）、只取文字输出的按退避间隔，后台构建或模型请求在运行时 100 毫秒；有等着收取的句柄时至少每半秒一次；设了 `豫言桌面程序`（行在桌面）时也至少每半秒一次，好取「辟窗」「开卷」等壳命令写下的请求。豫言系统上的主桌面（裸机「图形」即是）没有格子要计时时也至少每半秒一次（「桌面计时隔」），好取 ssh 等别的会话写下的请求（议题 #254）。计时到时对所有格子做计时更新。桌面程序（独立格）只靠外壳来信叫醒取信，后备计时每 2 秒一次。
