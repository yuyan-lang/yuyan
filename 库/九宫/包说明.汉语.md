# 平铺桌面

2026-10-11显示设置：启动取得显示面后应用保存的分辨率，再按保存的缩放运行会话。改缩放立即重排，外部程序格在尺寸或有效像素比变化时重设子程序显示面，把父桌面的比六四传给子程序；文字、指针与脏区共用同一有效比。缩放0使用宿主自动值，分辨率0沿用当前尺寸；保存的模式设置失败时保留设置。

2026-10-12 每个窗口独立成任务（[提案 00015](../../提案/00015-桌面程序独立成任务.汉语.md)）：豫言操作系统上有 `/工具/桌面程序。豫行`（包「桌面程序」）时，终端、文件浏览、任务管理器、设备管理器、设置、搜索与编辑器都以外部程序格起成这个程序的一个任务，任务管理器（「列出役」）里各占一行。窗口要外壳办的事（打开文件、右侧打开、运行程序或脚本、设标签标题、重读设置、要窗口列表、按种类名打开窗口）经「子程序显示」0.2.0 的外壳请求交给桌面，桌面经来信叫窗口跳到某行或关闭；关窗口时先送“请关闭”，程序自己收尾退出，再关一次就直接结束它。终端窗口里运行的程序照样收键盘输入（子程序 0.8.0，经初始任务转交）。宿主上行在起的桌面（提案 00039 第三步，环境变量 `豫言桌面程序` 给出本机的桌面程序）同样把这些格子起成桌面程序的进程，各自登进行在的任务表；浏览器、诺驿与不经行在的原生桌面照旧在本进程里显示这些格子（嵌入）。后续版本的事项：画面直接映射、只读段共享、构建输出与差异另成窗口、别的窗口改了设置时其余窗口随之更新。

平铺桌面是豫言的窗口系统（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一棵分割树把屏幕划成不重叠的矩形，叶子是标签组，标签里是格子程序。终端、文件浏览、任务管理器、设备管理器、设置与外部程序都是格子程序，同一种可以开多个。外壳只管布局与分派，格子程序各自更新；外部程序各在自己的任务里运行。

## 入口

```yuyan
寻观「九宫」之书。

「行平铺桌面」于「授权根」曰『桌面』于「布局」曰「浏览题壁布局」。
```

「行平铺桌面」在显示面 `主窗口` 上用自绘后端运行，点活动栏最下面的“返”（返回命令行）时结束并归还显示面，调用方接着运行。「授权根」是文件浏览、编辑保存、终端环境（`.环境`）与设置数据库（`桌面设置.数据库`）所用的授权目录名；「布局」是开场的默认布局：「浏览题壁布局」（左文件浏览、右题壁：右边是空组，焦点在它，活动栏新开的终端等窗口放进去；裸机开机壳的「图形」、行在桌面与 `豫言操作系统/应用/图形桌面` 用它，授权根“桌面”）、「浏览编辑布局」（左文件浏览、右空编辑组；`应用/百工坊/豫言工作台` 用它，授权根“工作台”）与「浏览终端布局」（左文件浏览、右终端，焦点在终端；外壳测试用它）。没有标签的组画题壁（桌面壁纸）：正中一行墨色大字欢迎语“欢迎使用豫言系统”。

浏览器入口在模块 `网页`（不在默认导入里）：「行网页平铺桌面」于「容器」为 页面容器 ID 于「服务」为 浏览服务 于「台更新」为 编辑格的工作台更新 于「外事」为 外事处理 于「初始路径」为 路径，用界面文树后端跑外壳，开场左文件浏览、右编辑组，用流式视图排版；浏览器里只开文件浏览、编辑、搜索与构建输出格。[工作台网页](../工作台/网页/包说明.汉语.md)的「行网页书斋」与「行网页书斋带外事」经它运行。

## 界面与操作

左边 36 逻辑像素的活动栏是一列线条图标（出自[图标库](../图标/包说明.汉语.md)，按像素比抗锯齿渲染，悬停显示中文提示）：文件浏览（文件夹，已开则聚焦第一个）、终端（带提示符的屏幕，新开）、任务管理器（脉搏折线，新开）、设备管理器（芯片，新开）、设置（齿轮，新开）、文件搜索（放大镜，已开则聚焦），最下面是返回命令行（从门框出去的箭头）。这些按钮都有等价的壳命令 `「辟窗」于「种类」曰『设备管理器』`（种类是终端、文件浏览、任务管理器、设备管理器、设置、搜索之一）：在桌面终端里执行时，终端记下种类名，桌面在这一轮更新后照活动栏的做法打开（独立格经外壳请求「请打开窗口」交给父外壳）；开机壳与宿主上报“桌面没有运行”。中间按分割树排布各标签组，每组上方是 28 逻辑像素的标签栏：标签（点击切换，× 关闭，按住可以拖到别处），右边是同样画法的小图标按钮：移到右边（向右的箭头：右边有组就移进去，没有就拆出一组）、左右拆分、上下拆分（拆分本组，新组里开一个同种格子）、单格全屏（再点还原）、关闭当前标签；文件浏览格选中可运行的文件时前面多一个“运行”；当前格是编辑格时，前面还有它的视图切换钮；是有画面的外部程序格时，前面有“文字”“画面”切换钮；桌面程序格（终端、文件浏览等桌面自己的窗口）只显示画面。焦点组的当前标签有朱红下划线。组之间的分割条可以拖动调比例。底部 20 逻辑像素的状态栏显示焦点格的标题、工作台的错误提示与运行中的外部程序数。

在组里任何地方按下指针即聚焦该组；格子里的任何操作也会聚焦它所在的组。

拖标签（照 VS Code 的手感，只认主键）：按下标签即选中它，按住移动 5 逻辑像素以上算拖动，松开时按指针位置放下。落在另一组的标签栏上或内容区中间，标签移进那一组（加在末尾）；落在某组内容区的左、右、上、下边缘（各占四分之一，角上取最近的一边），就在那一边拆出新组放这个标签，自己所在的组也可以这样拆；组里只剩这一个标签时，拖到自己身上保持原样。拖动中将要放下的区域以半透明朱色高亮（放进组时是整组，拆分时是那一半）。按下后移动不到 5 逻辑像素算点击。

快捷键的修饰键是交替（Alt、Option）：交替加回车新开终端，加 E 新开文件浏览，加方向键移焦点，再加上档把当前标签移到那一边（那边没有组就拆出一组），加 \ 左右拆分，加 - 上下拆分，加 W 关标签，加 F 单格全屏，加 1–9 切标签，加 [ 与 ] 调焦点组所在分支的比例。每个操作都有鼠标入口（移标签用拖标签或“移到右边”钮）。裸机的 PS/2 与 USB 键盘 2026-10-11 起交修饰键与按键抬起，快捷键在裸机上同样可用；焦点在终端文本框里时交替组合键照样到达外壳（显示控件按住交替时不编辑文本框）。Ctrl+C（2026-10-12）交给焦点终端：终端的壳会话正在运行一句时只打断这一句（2026-10-14，等价的壳命令是「辍」，见用户态桌面的「役令」），停在提示符上时只清掉输入框；有选区时由文本框复制选区。会话里「辞」（退出码零）之后，外壳在这一轮计时更新之后关掉这个终端（「关诸告退终端」），独立格的任务随之结束。

## 格子程序

- **终端**：`几席` 的终端仿真（2026-10-16 起：按键原样交给壳会话，屏上摹写壳的输出，与开机壳是同一个逐键编辑器），命令处理与开机壳相同（「桌面令平台」）。格子经格子环境里的「终端程序」（更新、视图、轮询、运行程序）调用它（文件浏览的“运行”钮与“终端 路径”开窗经「运行程序」直接启动程序或 。脚本。豫，不拼成句子交给壳编译，2026-10-14），原生入口给「终端程序于平台」，浏览器给「暂不可用终端程序」，所以浏览器包不链接壳的编辑器与拼音表。有焦点的终端格里，光标处收原样输入的像素图自动聚焦（「加自动凝神」）。每个终端各有自己的状态、运行中的子程序与空轮询退避（250 毫秒起，至多 2 秒）；子程序未成行的输出余文按句柄分开。当前路径与开机壳共用一个。「辞」命令关掉这个终端格。
- **文件浏览**：工作台的资源侧栏（文件与包两种视图、资源树、包树；豫言操作系统桌面即授权根“桌面”上只有文件视图，侧栏上方只留新建会话钮），经「映射信」接进外壳。每个文件浏览格有自己的资源树（展开状态各自分开），文件缓冲等共享状态放在外壳的工作台状态里。点文件行即选中它：以 .wasm 结尾或没有扩展名的文件读文件头认出可执行文件（豫行文件或网页汇编），名字以 `。脚本。豫` 结尾的是脚本；不是可执行文件的点一下就在编辑格里打开。选中后按回车或点标签栏的“运行”即运行：可执行文件开一个外部程序格，脚本开一个新终端格执行「脚本」；可执行文件也可以双击（半秒内再点同一行）运行。包视图、新建会话打开的文件同样进编辑格。新格子放进上一个焦点组（文件浏览格所在的组以外）；只有一组时往右拆出一组。
- **任务管理器**：`几席` 的任务管理器，相当于每秒运行一次壳命令「列出役」（ps）：每秒重查任务监测接口，整屏换成同一张任务表（任务数、统计范围与采样时间，表头，每个任务一行），桌面窗口的名称写“窗口标题 · 程序名”。嵌入运行时终端、文件浏览等格子程序与桌面同在一个任务里，表里算作那一个任务。裸机「图形」、图形桌面与豫言工作台共用这个外壳，三处都这样显示。
- **设备管理器**（2026-10-13）：`几席` 的设备管理器，整屏是壳命令「器列」的同一张设备表（设备数与已驱动、无驱动、失败的个数，表头，每个设备一行：总线、位置、类别、驱动、状态、厂商号:产品号、类码），没有驱动的行灰色、驱动失败的行朱色；每两秒重查设备接口，插拔 USB 设备后随之更新。格子只作显示；在豫言操作系统以外的宿主上，整屏是一行错误提示。
- **设置**：`几席` 的系统设置；设置全局一份，改了存进设置数据库。
- **外部程序**：以「遣使附映面」异步启动（不带参数；当前目录设为程序所在目录，环境取自 `.环境`），把显示面 `主窗口` 转授给它，尺寸是格子内容区的物理像素，像素比取显示面的（视图经「行门面尺寸比计时保位会话」收到像素比）。有显示面时每 50 毫秒「取使者画面」，新画面以像素图显示（版本号加一，带变化区域）；格子尺寸变了就「设使者映面尺寸」，程序按新尺寸重画。格子有焦点时，按键、文字、指针与滚轮经「原样输入时」原样收下，换成显示接口的输入事件，以「送使者入事」转给程序；交替按着时按键与文字留给外壳快捷键。程序还没交画面时格子显示文字输出（完整的行才显示）；有画面时标签栏多一个“文字”“画面”切换钮。平台返回资源暂不可用时只取文字输出。结束后标签与内容标出退出码；关掉标签即终止子程序并收取，没收完的句柄由计时继续收取。裸机上子程序显示要求外壳在初始任务里（开机壳的「图形」即是）；原生上子程序以 `--授权子程序 名=绝对路径` 授权，名字是以斜线开头的授权根内路径。
- **编辑**（第六步）：工作台的正文视图，文件的文档或原始代码视图、`.会话` 会话（上方一排引用按钮）、“差异：”页都是编辑格，格子只记路径；画之前把共享工作台状态的当前路径投影成本格路径，同一文件在两个编辑格里共用光标与视图选择。标签栏右侧是“右侧打开”（往右拆出一组开同一文件）与文档、原始代码切换；焦点在编辑格时状态栏右边是光标行列、构建运行时的停止钮与文件操作（包说明、检查、构建、类型检查、改名、删除）。保存、改名、删除落在授权根；改了没存的文件关不掉。点链接、看差异、改名时当前路径变了，本格跟着换路径。
- **搜索**（第六步）：工作台的文件搜索视图（活动栏“搜”，已开则聚焦）；点结果在编辑组打开，“返回文件”关掉搜索格。
- **构建输出**（第六步）：检查、构建、类型检查经后台任务（具名子程序“豫构”）运行，有构建输出就在编辑组下方拆出一格（占三成）显示，点诊断打开文件并定位，“收起构建结果”或关掉标签就收起。请求回复（会话）经具名子程序“模型请求”。

## 计时

外壳的计时间隔取各格子需求的最小值：终端有子程序在运行时按退避间隔，任务管理器 1 秒，设备管理器 2 秒，外部程序在运行时有显示面的每 50 毫秒（豫言操作系统上每半秒，子任务交了新画面或外壳请求时外壳提前醒来取画面、办请求）、只取文字输出的按退避间隔，后台构建或模型请求在运行时 100 毫秒；有等着收取的句柄时至少每半秒一次；设了 `豫言桌面程序`（行在桌面）时也至少每半秒一次，好取「辟窗」等壳命令写下的请求。计时到时对所有格子做计时更新。桌面程序（独立格）只靠外壳来信叫醒取信，后备计时每 2 秒一次。

## 验证
