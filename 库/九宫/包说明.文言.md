# 平铺桌面

2026-10-11显示之设：始得显示面则施所存分辨率，乃依所存缩放行会话。改缩放即重排，外程格于尺或有效像素比变时并设子程显示面，授父桌面之比六四；字、指位、脏区共用一有效比。缩放0用宿主自动值，分辨率0沿今尺；所存模式设未成则留其设。

2026-10-12 每窗独立为任务（[提案 00015](../../提案/00015-桌面程序独立成任务.汉语.md)）：豫言操作系统上有 `/工具/桌面程序。豫行`（包「桌面程序」）则终端、文件浏览、任务管理器、设备管理器、设置、搜索与编辑器皆以外程序之格起为此程之一任务，任务管理器（「列出役」）中各占一行。窗须外壳为之事（开文、右侧开之、行程序或脚本、设签题、复读设置、求窗列、依种名开窗）经「子程序显示」〇点二之外壳之请付桌面，桌面经来信令窗跳行或闭；闭窗先送“请关闭”，程自收而退，再闭则径止之。终端窗中所行之程亦受键入（子程序〇点八，经初始任务转交）。宿主之上行在所起之桌面（提案〇〇〇三九第三步，环境 `豫言桌面程序` 予本机之桌面程序）亦起此诸格为桌面程序之进程，各登于行在之籍；浏览器、诺驿与不经行在之原生桌面如故于本进程示此诸格（嵌入）。后续之事：画面直接映射、只读段共享、构建输出与差异别为窗、他窗改设则余窗随之更新。

2026-10-20 行在停则桌面自退（议题百三十六）：行在所起之桌面带 `豫言行在屏`，其值即行在之程号。行在收场则书私根系统目中之“请退桌面”而候桌面之退，逾则止之；行在被杀或崩，桌面每秒一起 `ps -p 行在程号` 视其存否，亡则自终。标之径依 HOME 或 `豫言行在目录` 而算（「行在桌标」），不别传。桌面程序之俗为执行器所授数项加 HOME、PATH 与附庸，不见 `豫言行在屏`；父桌面之面闭则读管之尽，随即自终。不经行在之桌面（豫言工作台、裸机、浏览器）无 `豫言行在屏`，其行如故。

平铺桌面，豫言之窗系也（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一分割之树划其屏为不相叠之矩，叶为签组，签中为格程。终端、文件浏览、任务管理器、设备管理器、设置与外程序皆格程也，同种可开数个。外壳惟司布局与分派，格程各自更新；外程序各行于其任务。

## 入口

```yuyan
寻观「九宫」之书。

「行平铺桌面」于「授权根」曰『桌面』于「布局」曰「题壁布局」。
```

「行平铺桌面」于显示面 `主窗口` 以自绘之后端行之；点活动栏最下之“返”（返命令行）则终而归其面，调用者续行。桌面方行则每帧（空桌面半秒之计亦与焉）呼几席 远程令 之「远程登录看护」一次（议题三百一十五）：桌面常开则开机壳在桌面中，看护须自桌面一侧而行。桌面这处每五秒至多一次（「问行役」汇总诸务之用，每秒一次则老桌面前台一顿），其外裹「姑试」，看护有误惟书一行屏记而吞之，不累桌面（十月二十三日，审查之议）。「授权根」者，文件浏览、编辑之存、终端之环境（`.环境`）与设置之库（`桌面设置.数据库`）所用授权目录之名也；「布局」者，开场之默认布局：「题壁布局」（始则全区为一空组，惟画题壁；文件浏览、终端诸窗自活动栏开之，入此一组，尽闭则壁复见；裸机开机壳之「图形」、行在之桌面与 `豫言操作系统/应用/图形桌面` 用之，授根“桌面”）、「浏览编辑布局」（左文件浏览、右空编辑之组；`应用/百工坊/豫言工作台` 用之，授根“工作台”）与「浏览终端布局」（左文件浏览、右终端，焦在终端；外壳之试用之）。无签之组全组画题壁（桌面之壁纸）：纸色之底，正中墨书大字一行，曰“欢迎使用豫言系统”，望之若桌面之底，组上之签栏与钮并让于壁。

浏览器之入口在模 `网页`（不在默认导入）：「行网页平铺桌面」于「容器」为 页容器之 ID 于「服务」为 浏览之服 于「台更新」为 编辑格之工作台更新 于「外事」为 外事之处 于「初始路径」为 径，以界面文树之后端行外壳，开场左为文件浏览、右为编辑之组，以流式之视排之；浏览器中惟开文件浏览、编辑、搜索与构建输出之格。[工作台网页](../工作台/网页/包说明.文言.md)之「行网页书斋」与「行网页书斋带外事」经之而行。

## 界面与操作

左为三十六逻辑像素之活动栏，一列线条之图（出[图标库](../图标/包说明.文言.md)，依像素比去锯齿而渲，悬停示中文之提示）：文件浏览（夹，既开则焦其首）、终端（带提示之屏，新开）、任务管理器（脉搏之折线，新开）、设备管理器（芯片，新开）、设置（齿轮，新开）、文件搜索（放大之镜，既开则焦之）、程序（九宫之格，既开则焦之）、软件（店铺），最下为返命令行（出门框之箭）。诸钮皆有等之壳命 `「辟窗」于「种类」曰『设备管理器』`（种为终端、文件浏览、任务管理器、设备管理器、设置、搜索、市肆与已装图形软件之名）：“程序”等 `「辟窗」于「种类」曰『程序』`，开启台之格；“软件”等 `「辟窗」于「种类」曰『市肆』`，开 `/工具/市肆。豫行`，尚无此程则示“市肆尚未安装”于状态栏。于桌面终端行之，终端记其种名，桌面于此轮更后依活动栏之法开之（独立格经外壳之请「请打开窗口」付父外壳）；开机壳与宿主报“桌面没有运行”。中依分割之树排诸签组，每组上有二十八逻辑像素之签栏：诸签（点则易之，× 则闭之，按而可曳之他所），右有同法之小图钮：移到右边（向右之箭：右有组则移入之，无则拆出一组）、左右拆、上下拆（拆本组，新组中开同种之格）、单格全屏（再点则复）、闭当签；文件浏览格选可行之文，则前多一“运行”；当格为编辑格时，前又有其视之易钮；为有画之外程序格时，前有“文字”“画面”之易钮；桌面程序之格（终端、文件浏览之类桌面自有之窗）惟示其画。焦组之当签有朱下划。组间之分割条可拖以调比。下为二十逻辑像素之状态栏，示焦格之题、工作台之误示与方行之外程序数。

于组中任处按指，即焦其组；于格中有所操作，亦焦其所在之组。

曳签（循 VS Code 之感，惟主键）：按签即择之，按而移五逻辑像素以上为曳，举时依指之所而置之。落他组之签栏或内容区之中，则签移入彼组（附于末）；落某组内容区之左、右、上、下之缘（各占四分之一，角则取最近之边），则于彼边拆出新组以容此签，己所在之组亦可如是拆之；组惟此一签而曳于己身，则如故。曳时将置之域以半透之朱显之（入组则全组，拆则彼半）。按后移不及五逻辑像素为点。

快捷之键以交替（Alt、Option）为修饰：交替加回车新开终端，加 E 新开文件浏览，加方向移焦，复加上档则移当签于彼侧（彼无组则拆出一组），加 \ 左右拆，加 - 上下拆，加 W 闭签，加 F 单格全屏，加一至九易签，加 [ 与 ] 调焦组所在枝之比。每术皆有鼠之入口（移签以曳签或“移到右边”之钮）。裸机之 PS/2 与 USB 键盘，十月十一日起交修饰之键与按键之抬，快捷之键于裸机亦行；焦在终端之文本框，交替之组合仍达外壳（显示控件按交替则不编文本框）。Ctrl+C（十月十二日）付焦点之终端：终端之壳会话方行一句则惟断此句（十月十四日，等价之壳命为「辍」，见用户态桌面之「役令」），停于提示则惟清入框；有所选则由文本框复制之（十月廿一日起控制加上档加 C 复制选区、加 V 粘贴、加 A 全选，终端锦囊中亦有此数项）。会话中「辞」（退码零）之后，外壳于此轮计时更新之后闭此终端（「关诸告退终端」），独立格之任务随终。

锦囊（二〇二六年十月二十一日，[提案〇〇〇四八](../../提案/00048-锦囊.汉语.md)）：凡可操作之处副击（右键单击；林檎上控制加主键单击）则出囊，每策皆携等价之壳命，图形之界与壳命同成一事。副击签、或点签栏右端之“≡”钮，则出此窗之窗囊：闭（交替加 W）、左右拆（交替加 \）、上下拆（交替加 -）、单格全屏（交替加 F，勾记此宫单格全屏否）、移于（左右上下四组，交替加上档加向）、移宫（新宫，交替加 O；及所在宫之外诸宫）、归原（交替加上档加 O，无原处则不可）。副击空组之题壁、活动栏之虚处与状态栏之虚处，则出桌囊：新终端（交替加回车）、文件浏览（交替加 E）、程序、软件、任务管理器、设备管理器、设置、搜索，宫（诸宫，今宫为勾）、显示（缩放的自动、百、百二五、百五、二百；字样的文楷三族）、电源（返命令行、重启、关机，后二者惟豫言系统中可用）。副击状态栏之宫名则出宫囊（入宫、尽归）；副击活动栏之窗图则出栏囊（新开、新宫开）。囊由外壳之态而生（模 `宫策`），桌面每轮以诸窗与桌面之囊书于 `/系统/桌面窗列。数据。豫` 之顶「窗囊」（「诸窗囊述」），供壳命「囊目」读。

## 宫

九宫可有数宫（工作区，[提案〇〇〇四七](../../提案/00047-窗口工作区.汉语.md)）：一宫者一分树及其焦组与单格全屏，宫一为主宫，恒在。格表全桌一份，窗徙于诸宫惟易其所挂之树，程不复起。签栏之“出”钮（交替加 O）徙今窗入新宫（号取自二起最小之空号），主屏随而示之；窗初徙出则记其原宫原组，“归”钮（交替加上档加 O）送之还（原组不存则入原宫之焦组，原宫不存则入宫一）。交替加控制加宫号则入宫（主屏易而示之），交替加上档加宫号则徙今窗入彼宫（主屏不随）。宫不止一，则状态栏最左列诸宫，今宫书以朱字，他宫点之则入。宫一而外，宫空即撤。桌面程序之请、程终闭窗之类不经界面之事，于发起之窗所在之宫办之，新窗开于彼宫。「诸宫窗述」予壳命「窗列」所印之表，「徙格」「归格」「归宫诸格」「临宫」供壳命呼之。壳命「徙窗」「归窗」「入宫」「关窗」「拆窗」「全窗」「移窗」「凝窗」与加「宫」之「辟窗」循「辟窗」之路：几席之壳请书一窗请（种、参与发窗之号）为 `/系统` 下一窗请之文（名以 `请求打开窗口-` 起头），桌面每轮依名排次取之、逐条办之；终端起壳会时环境有 `豫言窗号`，故省「号」即发窗之窗。剖、旁开、右开者未立格之前先置之为新窗将得之号，此数种之窗所起之终端亦得己之号。问命「窗列」读桌面所书之 `/系统/桌面窗列。数据。豫`（桌面每轮于宫或窗变时重书）；同文之「窗囊」为诸窗窗口选单之快照（提案〇〇〇四八第四节之四），「囊目」读之，予号则惟印其窗之段。

宫可有己之显示面（东道之窗）：桌面行于多面会话（门面「诸面运行」）则开场「许独面」，此后新宫各取一面（面名即宫名，如“宫二”；行在授 `宫*=960x640`），其面惟画此宫之签栏与诸组，无活动之栏与状态之栏，望之近原生之窗；主屏不随之，状态栏中书以浅色。「诸宫面」予多面会话所欲之面（主窗与每有己面之宫，题为宫名加焦窗之题）；「宫面观」为宫面之视，所发之信包为「宫内信」而于彼宫办之（「于宫办」），主屏不跳（「定屏」「归屏」：主屏恒示共主屏之宫）。诸面之尺各记其尺（「记面尺」「补视尺」），临于何宫则视之尺易为示之之面者，外程序格依之定其面之尺。东道不能予面（裸机、诺驿、浏览器小窗被拦）而交「映面未得」，则此宫改共主屏，主屏随之（「宫面未得」）；人闭宫之东道之窗而交「映面已闭」，犹「归窗」于此宫，诸窗各还原处，宫随撤（「宫面已闭」）。宫空即撤，其面随还，东道之窗随闭。

## 格程

- **终端**：`几席` 之终端之仿（十月十六日起：键原样付壳会话，屏上摹壳之出，与开机壳同一逐键编辑之器），命令之处同开机壳（「桌面令平台」）。格经格之境中之「终端程序」（更新、视、询、行程序）调之（文件浏览之“运行”钮与“终端 径”开窗经「运行程序」径启程序或 。脚本。豫，不拼句付壳而编，十月十四日），原生之入口予「终端程序于平台」，浏览器予「暂不可用终端程序」，故浏览器之包不链壳之编辑与拼音之表。有焦之终端格，标处受原样之入之像素图自焦（「加自动凝神」）。每终端各有其态、方行之子程序与空询之退避（自二百五十毫秒，至多二秒）；子程序未成行之余文依柄分之。当前路径与开机壳共一。「辞」之命闭此终端之格（十月廿一日，提案〇〇〇四八戊路）终端挂于「终端观带囊」：出行每行皆为一单行文框，指拖而择、双击择词、上档加按而扩，控制加上档加 C 则复制选区、加 V 则粘贴（换行即回车，多行逐行）、加 A 则全选；于出行中打字，惟以新入一段付壳，换号加一令焦归光标像素；终端挂「锦囊」（复制、粘贴、全选、清屏、打断、新终端、左右与上下拆分、关闭，每项皆带等价之壳命，拆分与关闭书窗请以付桌面，桌面未行则不可用）。
- **文件浏览**：工作台之资源侧栏（文件与包二视、资源之树、包之树；豫言操作系统之桌面即授根“桌面”惟有文件之视，侧栏之上惟留新建会话之钮），以「映射信」接于外壳。每文件浏览格自有资源之树（展否各别），文之缓冲等共态存于外壳之工作台之态。点文行即选之：以 .wasm 终或无扩展名之文，读文首以认可执之文（豫行或网页汇编），名以 `。脚本。豫` 终者为脚本；非可执之文点之：有已装图形软件识其扩展名（名帖之“所开”）则开一外程序之格行之、以此文为首参（同壳命「开卷」），无相应之程则于编辑格开之。既选，按回车或点签栏之“运行”即行之：可执之文开一外程序之格，脚本开一新终端之格以行「脚本」；可执之文亦可双击（半秒内再点同行）行之。包之视、新建会话所开之文亦入编辑之格。新格置于前焦组（文件浏览格所在组之外）；惟一组则右拆一组。文行、目行与侧栏空处各有锦囊（副击之菜单，提案 00048 丁路）：文行为开、行、于编辑开、更名、删、复、剪、复径与详情，目行为展收、新文、新箧、此处终端、贴、复、剪、更名、删、复径与详情，空处为新文、新箧、贴与刷新。每项皆带等价之壳命（如 `「案牍」之「焚」于『径』`、`「纳袋」于『径』`）。复制、剪记者于共台态之卷夹（径与剪否），贴时摹或移入之、同名加“副本”，多层之箧依树递摹；新文与新箧先取暂名、选之而启更名之框以取其名；更名之框回车或点确认，则由格经授根更名，惟须授根，不须可写之工作台，故行在惟授“桌面”亦能更名；删之初点惟示其确，再点乃删，多层之箧依树递焚。「复径」入夹袋者为换算后之真全径（根接箧内之相径），锦囊所书之等价壳命亦书此全径。「此处终端」于嵌入之桌面先移当径而后开终端之格，独立之格以目随外壳之请「请此处终端」付父外壳，父外壳移而之乃开，终端之壳会自此目始。
- **任务管理器**：`几席` 之任务管理器，犹每秒行壳命令「列出役」（ps）一次：每秒复询任务监测之接口，全屏易为同一任务之表（任务之数、统计之界与采样之时，表头，每任务一行），桌面之窗名书“窗题 · 程名”。每任务之行挂锦囊（提案〇〇〇四八）：打断（`「辍」于「号」曰「七」`）、结束（`「辍役」于「号」曰「七」`，先点一次易为“确认结束任务”）与桌面之窗之转到窗口（`「凝窗」于「号」曰「三」`）；动作之果示于表前一行。嵌入而行，则终端、文件浏览诸格程与桌面同居一任务，表中计为彼一任务。裸机「图形」、图形桌面与豫言工作台共此外壳，三处皆如是示之。
- **设备管理器**（十月十三日）：`几席` 之设备管理器，全屏为壳命「器列」之同一设备之表（设备之数与已驱、无驱、败者之数，表头，每设备一行：总线、位置、类别、驱动、态、厂商:产品、类码），无驱动之行灰、驱动败之行朱；每二秒复询设备之接口，插拔 USB 设备则随之更。格惟示之；于豫言操作系统以外之宿主，全屏为一行之误示。
- **设置**：`几席` 之系统设置；设置全局一份，改则存于设置之库。
- **程序**（启台，二〇二六年十月二十日）：模 `博古`。图之格：每格为九十六逻辑像素见方之可点之块，图在上、显示名在下；内建六窗（终端、文件浏览、任务管理器、设备管理器、设置、搜索）用徽识之成图，已装图形软件用 `/软件/名称。图标.png`（画谱解之，缩为方），无图则用九宫之图。点一格与 `「辟窗」于「种类」曰『名称』` 等（独立格经外壳之请付父外壳）。每图挂锦囊（提案〇〇〇四八）：打开（同上）；已装之图形软件别有卸载（`「卸软件」于「名称」曰『名称』`，宿主无 `/软件` 则不可用）与详情（`「软件讯」于「名」曰『名称』`，于格下书版与简介，简介取装时所记之目录介绍）。格每二秒复读 `/软件/已装软件。数据。豫` 一次，新装之软件随见；视图依设计语言书为控件之树，经匠心门面之「作门面」付自绘之后端。
- **外程序**：以「遣使附映面」异步启之（不携参；当前目录设为程序所在之目，环境取诸 `.环境`），转授显示面 `主窗口`，尺为格内容之区之物理之素，像素比取显示面之（视以「行门面尺寸比计时保位会话」受像素比）。有面则每五十毫秒「取使者画面」，新画以像素图示之（版号加一，携所变之区）；格尺易则「设使者映面尺寸」，程依新尺重画。格得焦时，按键、文字、指针与滚轮以「原样输入时」原样受之，易为显示之约之输入，以「送使者入事」转于程；交替按时，键与文留与外壳之快捷。程未交画，则格示其文出（成行乃示）；有画则签栏多一“文字”“画面”之易钮。平台返资源暂不可用，则惟取文出。毕则签与内容标其退码；闭签即止其子程序而收之，未收毕之柄由计时续收。裸机之子程序显示，须外壳在初始任务（开机壳之「图形」即是）；原生之子程序以 `--授权子程序 名=绝径` 授之，名为以斜线始之授根内径；名亦可以为目（如 `/软件`），目中诸程皆得起；余段之 `..` 段、`.` 段与空段皆拒，不出授目（十月二十一日，议题二百五十八）。
- **编辑**（第六步）：工作台之正文之视，文之文档或原码之视、`.会话` 会话（上置一排引用之钮）、“差异：”之页皆编辑之格，格惟记其径；画前投共工作台之态之当径为本格之径，同文在二编辑格共光标与视之择。签栏右为“右侧打开”（右拆一组以开同文）与文档、原码之易；焦在编辑格时，状态栏右为光标之行列、构建方行之止钮与文之术（包说明、检查、构建、类型检查、更名、删除）。存、更名、删除落于授根；改而未存之文不可闭。点链、观差、更名而当径易，则本格随易其径。
- **搜索**（第六步）：工作台文件搜索之视（活动栏“搜”，既开则焦之）；点果则于编辑之组开之，“返回文件”则闭搜索之格。
- **构建输出**（第六步）：检查、构建、类型检查经后台之事（具名子程序“豫构”）行之，有构建之出则于编辑组下拆出一格（占三成）示之，点诊则开文而定位，“收起构建结果”或闭其签则收之。请答（会话）经具名子程序“模型请求”。

## 计时

外壳之计时取诸格所需之最小：终端有子程序方行则依退避之间，任务管理器一秒，设备管理器二秒，启台二秒（复读已装软件），外程序方行，有面者每五十毫秒（豫言操作系统上每半秒，子任务交新画或外壳之请则外壳早醒而取画、办请）、惟取文出者依退避之间，后台构建或模型之请方行则百毫秒；有待收之柄则至少每半秒一次；设 `豫言桌面程序`（行在之桌面）亦至少每半秒一次，以取「辟窗」「开卷」诸壳命所书之请。豫言之系统上主桌面（裸机之「图形」即是）无格需计亦至少每半秒一次（「桌面计时隔」），以取 ssh 诸他会所书之请（议二五四）。时至则遍诸格行计时之更新。桌面程序（独立格）惟待外壳来信醒之而取信，后备之计时每二秒一次。
