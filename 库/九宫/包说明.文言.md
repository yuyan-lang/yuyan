# 平铺桌面

2026-10-11显示之设：始得显示面则施所存分辨率，乃依所存缩放行会话。改缩放即重排，外程格于尺或有效像素比变时并设子程显示面，授父桌面之比六四；字、指位、脏区共用一有效比。缩放0用宿主自动值，分辨率0沿今尺；所存模式设未成则留其设。

2026-10-12 每窗独立为任务（[提案 00015](../../提案/00015-桌面程序独立成任务.汉语.md)）：豫言操作系统上有 `/工具/桌面程序。豫行`（包「桌面程序」）则终端、文件浏览、任务管理器、设备管理器、设置、搜索与编辑器皆以外程序之格起为此程之一任务，任务管理器（「列出役」）中各占一行。窗须外壳为之事（开文、右侧开之、行程序或脚本、设签题、复读设置、求窗列、依种名开窗）经「子程序显示」〇点二之外壳之请付桌面，桌面经来信令窗跳行或闭；闭窗先送“请关闭”，程自收而退，再闭则径止之。终端窗中所行之程亦受键入（子程序〇点八，经初始任务转交）。宿主之上行在所起之桌面（提案〇〇〇三九第三步，环境 `豫言桌面程序` 予本机之桌面程序）亦起此诸格为桌面程序之进程，各登于行在之籍；浏览器、诺驿与不经行在之原生桌面如故于本进程示此诸格（嵌入）。后续之事：画面直接映射、只读段共享、构建输出与差异别为窗、他窗改设则余窗随之更新。

平铺桌面，豫言之窗系也（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一分割之树划其屏为不相叠之矩，叶为签组，签中为格程。终端、文件浏览、任务管理器、设备管理器、设置与外程序皆格程也，同种可开数个。外壳惟司布局与分派，格程各自更新；外程序各行于其任务。

## 入口

```yuyan
寻观「九宫」之书。

「行平铺桌面」于「授权根」曰『桌面』于「布局」曰「浏览终端布局」。
```

「行平铺桌面」于显示面 `主窗口` 以自绘之后端行之；点活动栏最下之“返”（返命令行）则终而归其面，调用者续行。「授权根」者，文件浏览、编辑之存、终端之环境（`.环境`）与设置之库（`桌面设置.数据库`）所用授权目录之名也；「布局」者，开场之默认布局：「浏览终端布局」（左文件浏览、右终端，焦在终端；裸机开机壳之「图形」与 `豫言操作系统/应用/图形桌面` 用之，授根“桌面”）与「浏览编辑布局」（左文件浏览、右空编辑之组；`应用/百工坊/豫言工作台` 用之，授根“工作台”）。

浏览器之入口在模 `网页`（不在默认导入）：「行网页平铺桌面」于「容器」为 页容器之 ID 于「服务」为 浏览之服 于「台更新」为 编辑格之工作台更新 于「外事」为 外事之处 于「初始路径」为 径，以界面文树之后端行外壳，开场左为文件浏览、右为编辑之组，以流式之视排之；浏览器中惟开文件浏览、编辑、搜索与构建输出之格。[工作台网页](../工作台/网页/包说明.文言.md)之「行网页书斋」与「行网页书斋带外事」经之而行。

## 界面与操作

左为三十六逻辑像素之活动栏，一列线条之图（出[图标库](../图标/包说明.文言.md)，依像素比去锯齿而渲，悬停示中文之提示）：文件浏览（夹，既开则焦其首）、终端（带提示之屏，新开）、任务管理器（脉搏之折线，新开）、设备管理器（芯片，新开）、设置（齿轮，新开）、文件搜索（放大之镜，既开则焦之），最下为返命令行（出门框之箭）。诸钮皆有等之壳命 `「辟窗」于「种类」曰『设备管理器』`（种为终端、文件浏览、任务管理器、设备管理器、设置、搜索之一）：于桌面终端行之，终端记其种名，桌面于此轮更后依活动栏之法开之（独立格经外壳之请「请打开窗口」付父外壳）；开机壳与宿主报“桌面没有运行”。中依分割之树排诸签组，每组上有二十八逻辑像素之签栏：诸签（点则易之，× 则闭之，按而可曳之他所），右有同法之小图钮：移到右边（向右之箭：右有组则移入之，无则拆出一组）、左右拆、上下拆（拆本组，新组中开同种之格）、单格全屏（再点则复）、闭当签；文件浏览格选可行之文，则前多一“运行”；当格为编辑格时，前又有其视之易钮；为有画之外程序格时，前有“文字”“画面”之易钮。焦组之当签有朱下划。组间之分割条可拖以调比。下为二十逻辑像素之状态栏，示焦格之题、工作台之误示与方行之外程序数。

于组中任处按指，即焦其组；于格中有所操作，亦焦其所在之组。

曳签（循 VS Code 之感，惟主键）：按签即择之，按而移五逻辑像素以上为曳，举时依指之所而置之。落他组之签栏或内容区之中，则签移入彼组（附于末）；落某组内容区之左、右、上、下之缘（各占四分之一，角则取最近之边），则于彼边拆出新组以容此签，己所在之组亦可如是拆之；组惟此一签而曳于己身，则如故。曳时将置之域以半透之朱显之（入组则全组，拆则彼半）。按后移不及五逻辑像素为点。

快捷之键以交替（Alt、Option）为修饰：交替加回车新开终端，加 E 新开文件浏览，加方向移焦，复加上档则移当签于彼侧（彼无组则拆出一组），加 \ 左右拆，加 - 上下拆，加 W 闭签，加 F 单格全屏，加一至九易签，加 [ 与 ] 调焦组所在枝之比。每术皆有鼠之入口（移签以曳签或“移到右边”之钮）。裸机之 PS/2 与 USB 键盘，十月十一日起交修饰之键与按键之抬，快捷之键于裸机亦行；焦在终端之文本框，交替之组合仍达外壳（显示控件按交替则不编文本框）。Ctrl+C（十月十二日）付焦点之终端：终端之壳会话方行一句则惟断此句（十月十四日，等价之壳命为「辍」，见用户态桌面之「役令」），停于提示则惟清入框；有所选则由文本框复制之。会话中「辞」（退码零）之后，外壳于此轮计时更新之后闭此终端（「关诸告退终端」），独立格之任务随终。

## 格程

- **终端**：`几席` 之终端之仿（十月十六日起：键原样付壳会话，屏上摹壳之出，与开机壳同一逐键编辑之器），命令之处同开机壳（「桌面令平台」）。格经格之境中之「终端程序」（更新、视、询、行程序）调之（文件浏览之“运行”钮与“终端 径”开窗经「运行程序」径启程序或 。脚本。豫，不拼句付壳而编，十月十四日），原生之入口予「终端程序于平台」，浏览器予「暂不可用终端程序」，故浏览器之包不链壳之编辑与拼音之表。有焦之终端格，标处受原样之入之像素图自焦（「加自动凝神」）。每终端各有其态、方行之子程序与空询之退避（自二百五十毫秒，至多二秒）；子程序未成行之余文依柄分之。当前路径与开机壳共一。「辞」之命闭此终端之格。
- **文件浏览**：工作台之资源侧栏（文件与包二视、资源之树、包之树），以「映射信」接于外壳。每文件浏览格自有资源之树（展否各别），文之缓冲等共态存于外壳之工作台之态。点文行即选之：以 .wasm 终或无扩展名之文，读文首以认可执之文（豫行或网页汇编），名以 `。脚本。豫` 终者为脚本；非可执之文点之即于编辑格开之。既选，按回车或点签栏之“运行”即行之：可执之文开一外程序之格，脚本开一新终端之格以行「脚本」；可执之文亦可双击（半秒内再点同行）行之。包之视、新建会话所开之文亦入编辑之格。新格置于前焦组（文件浏览格所在组之外）；惟一组则右拆一组。
- **任务管理器**：`几席` 之任务管理器，犹每秒行壳命令「列出役」（ps）一次：每秒复询任务监测之接口，全屏易为同一任务之表（任务之数、统计之界与采样之时，表头，每任务一行），桌面之窗名书“窗题 · 程名”。嵌入而行，则终端、文件浏览诸格程与桌面同居一任务，表中计为彼一任务。裸机「图形」、图形桌面与豫言工作台共此外壳，三处皆如是示之。
- **设备管理器**（十月十三日）：`几席` 之设备管理器，全屏为壳命「器列」之同一设备之表（设备之数与已驱、无驱、败者之数，表头，每设备一行：总线、位置、类别、驱动、态、厂商:产品、类码），无驱动之行灰、驱动败之行朱；每二秒复询设备之接口，插拔 USB 设备则随之更。格惟示之；于豫言操作系统以外之宿主，全屏为一行之误示。
- **设置**：`几席` 之系统设置；设置全局一份，改则存于设置之库。
- **外程序**：以「遣使附映面」异步启之（不携参；当前目录设为程序所在之目，环境取诸 `.环境`），转授显示面 `主窗口`，尺为格内容之区之物理之素，像素比取显示面之（视以「行门面尺寸比计时保位会话」受像素比）。有面则每五十毫秒「取使者画面」，新画以像素图示之（版号加一，携所变之区）；格尺易则「设使者映面尺寸」，程依新尺重画。格得焦时，按键、文字、指针与滚轮以「原样输入时」原样受之，易为显示之约之输入，以「送使者入事」转于程；交替按时，键与文留与外壳之快捷。程未交画，则格示其文出（成行乃示）；有画则签栏多一“文字”“画面”之易钮。平台返资源暂不可用，则惟取文出。毕则签与内容标其退码；闭签即止其子程序而收之，未收毕之柄由计时续收。裸机之子程序显示，须外壳在初始任务（开机壳之「图形」即是）；原生之子程序以 `--授权子程序 名=绝径` 授之，名为以斜线始之授根内径。
- **编辑**（第六步）：工作台之正文之视，文之文档或原码之视、`.会话` 会话（上置一排引用之钮）、“差异：”之页皆编辑之格，格惟记其径；画前投共工作台之态之当径为本格之径，同文在二编辑格共光标与视之择。签栏右为“右侧打开”（右拆一组以开同文）与文档、原码之易；焦在编辑格时，状态栏右为光标之行列、构建方行之止钮与文之术（包说明、检查、构建、类型检查、更名、删除）。存、更名、删除落于授根；改而未存之文不可闭。点链、观差、更名而当径易，则本格随易其径。
- **搜索**（第六步）：工作台文件搜索之视（活动栏“搜”，既开则焦之）；点果则于编辑之组开之，“返回文件”则闭搜索之格。
- **构建输出**（第六步）：检查、构建、类型检查经后台之事（具名子程序“豫构”）行之，有构建之出则于编辑组下拆出一格（占三成）示之，点诊则开文而定位，“收起构建结果”或闭其签则收之。请答（会话）经具名子程序“模型请求”。

## 计时

外壳之计时取诸格所需之最小：终端有子程序方行则依退避之间，任务管理器一秒，设备管理器二秒，外程序方行，有面者每五十毫秒（豫言操作系统上每半秒，子任务交新画或外壳之请则外壳早醒而取画、办请）、惟取文出者依退避之间，后台构建或模型之请方行则百毫秒；有待收之柄则至少每半秒一次；设 `豫言桌面程序`（行在之桌面）亦至少每半秒一次，以取「辟窗」诸壳命所书之请。时至则遍诸格行计时之更新。桌面程序（独立格）惟待外壳来信醒之而取信，后备之计时每二秒一次。

## 验证

- `测试/分割树。测试。豫`：拆、闭而收、移焦、移签、调比、求矩；曳签之置所（签栏、内容区之中、四边、分割条）、置之预示之矩与置之（入他组、拆于他组与己组之边、独签之组曳于己身、搬空之组删之）（`豫构 构建 平铺桌面 测试 分割树。测试 --输出 分割树测试.wasm`，以诺驿行之）。
- `测试/外壳。测试。豫`：于假浏览之服与假终端之台，验开场之布、拆与闭、多开终端各有其入、移焦、改设不清他格、拖分割条、单格全屏、文件浏览格展目录、运行之动作与退出。工作台之布下，自文件浏览开编辑格、再点惟焦之、改而未存不许闭、右侧开之、构建输出之格之开与收。曳签之假指之事之序（按即择之、移时置之预示、入他组之签栏、拆于他组之右、移不及阈为点、独签之组曳于己边则如故）与“移到右边”之钮（右有组则移入而删空组、最右独签之组如故）；任务管理器示任务之表（工具宿主不绑任务监测，验者易一格为携假系统任务之任务管理器格，核窗列，复画全外壳之视，核任务之数与界、表头与对齐之任务行，并核「列出役」所印之表与之同）。
- 原生 macOS 后台（曳签）：图形桌面以 `--显示面后台` 行之，以后台之曳移签：曳至他组下缘（拆出新组）、曳入他组签栏与内容区之中（移入之，空组删之）、曳至己组左缘（拆出之），点签惟易之，“移到右边”之钮右无组则拆出一组、有组则移入；置之预示以半透之朱画之（拆则彼半，入组则全组）。
- `测试/会话启停。测试。豫`：同一程序连行两次平铺桌面，须绑实显示之宿主（全树测试惟检之）。
- 裸机 QEMU（兼容六十四，第七步）：造盘时置示例图形之程（界面自绘示例、显示控件示例之 .wasm）于预置之树，开机入「图形」，自文件浏览行之，画入于格，点与键皆效；左右拆分而二程并行，变窄之格依新尺重画；闭签即止其程。
- 原生 macOS 后台（第七步）：图形桌面以 `--授权子程序 /程序/待办.wasm=<原生待办>` 等授二示例之程，文件浏览中同名之文惟为选与行之口；行之则子程序以管代办画入于格，Retina 上依像素比二画之，点与键皆效，二程左右并列。
- 浏览器（第八步）：工作台网页示例经「行网页书斋」开之，单格之时与旧工作台同貌，展目录、开文成签、编辑出改标、左右拆分、文件搜索、构建之示皆可用；程约一点五兆（改前一点二五兆）。
