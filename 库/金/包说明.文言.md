# 金属

共享八位四色二维纹理由「置金纹理」建之，得「写金纹理」「读金纹理」「释金纹理」。区域结构依林檎臂六十四之调用约传副本之址，原生与诺驿同用豫言之实。图形处理器原生之适配与图形显示原生之适配复用诸函。

林檎原生执行器与诺驿，共用本包之器、缓、Objective-C 消息与派之实现；原生之径由纯豫言系统库桥调用系统框架。张量计算原生复用此包，通单精矩阵之必需链；基本 CI 依器可用而试之，实机之果待记。

此乃林檎金属（Metal）之算之豫言封装，以供他日张量之金属后端。金属之口皆 Objective-C 之消息：此库由 `库/借道` 调 Objective-C 运行时（libobjc 之 `objc_getClass`、`sel_registerName`、`objc_msgSend`），诸理皆书于豫言，诺驿宿主惟供通用之系统库调用原语。

此库无核之源。金属着色语言（MSL）属 C++ 之系，手书之 MSL 不入库；他日之核由着色语言译为 MSL，乃付 `「译金源」`。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，依标准库与系统库调用，登于「百家」之下。

## 用法

```yuyan
寻观「金」之书。
```

- 器：`「金可用」`、`「取常金器」`（MTLCreateSystemDefaultDevice，惟取一次）、`「金器名」`、`「金器统一存」`。
- 编：`「译金源」于 器 于 源` 得「金属已编译」或「金属编译失败」（附编者之误述）；`「置金管线」于 器 于 函库 于 函名` 得「金属管线已建」或「金属管线失败」；`「管线每组最多缕」`、`「管线行宽」`。
- 缓：`「置金缓冲」于 器 于 字数`（共享之存，CPU 与 GPU 共一存，`「金缓冲址」` 可以系统库调用之存函径读写）；`「包裹本土存为金缓冲」于 器 于 址 于 字数` 零抄而裹页齐之原生之存（址不齐则可无），缓未释，其存不可释。张量之存（诺驿宿主之 SharedArrayBuffer）页齐，可零抄。
- 器之家族：`「金器支持家族」于 器 于 家族之号` 问器属某 GPU 家族否（supportsFamily:），若一零一零为 MTLGPUFamilyApple10（M5、A19 以后，其 GPU 带行张量之算之神经加速器）。
- 常驻之集：`「置金常驻集」于 器` 新建空之常驻集（MTLResidencySet，macOS 十五以来），得其物号，无其类或金属拒之则零；`「常驻集入」于 集 于 物` 纳一分配（若缓之物）于集，交而请其常驻；`「序加常驻集」于 队 于 集` 系集于命令之队。集中之分配既请常驻，恒钉于内存，系统不换出亦不压之。常驻集不释（待办事项）。
- 命令：`「置金序」`；`「置金令」`、`「置无保留金令」`（commandBufferWithUnretainedReferences：不留所系之缓，召者须保其存至令毕）、`「置算编器」`、`「匠心算管线」`、`「设金缓冲」`、`「设金字节」`（不逾四千零九十六字）、`「设三十二位数参」`、`「设单精参」`、`「依缕组派发」`、`「依缕派发」`、`「终编」`、`「提交金令」`、`「待金令」`、`「金令态」`（四为已毕）、`「金令误」`。
- 绘（`绘事` 篇）：`「置金绘管线」` 依器、函库、二入口之名、顶点之布、色格、混法、深格立绘管，得「金绘管线已建」（物号）或「金绘管线失败」；顶点之布第 i 系于槽三十减 i（「金顶点槽」）。`「置金深度态」` 依比法与写否立深规；`「置金深度纹理」` 铺私存之深绢。每道：`「置金绘道述」`、`「设金色附」`（绢、先清否、清色四数）、`「设金深附」`（绢、先清否、清深），`「置金绘编器」` 开绘编之器，乃 `「设金绘管线」`、`「设金深度态」`、`「设金逆时针为正」`、`「设金剔除」`（零不剔、一剔正、二剔背）、`「设金顶点缓冲」`、`「设金片元缓冲」`、`「金绘顶点」`、`「金绘索引」` 或 `「金绘索引段」`（首索乘四为字偏、基顶传入），终以 `「终绘编」`。清色、清深为双精，经 `「发信带双」`（消息篇）入浮点之寄。
- 命令之缓、编码器与误物皆自动释放：每派裹于 `「在自动释池中」以 类 于（得「无」而 …）` 之中，否则恒泄。`新建`、`编译` 所得之物归用者，用毕调所当之 `「释放金属…」`。

## 实测（二〇二六年九月三十日，Apple M5 Pro，诺驿 26.3.0，工具宿主）

于草稿之目以手书之 MSL 小核验全链：加倍之核、零抄之缓上之加倍、64×64 单精之矩阵乘（四千零九十六元皆对）。往返之时（交而同步候之，二百次之均；时本机负甚重，数偏大而有动）：

| 项 | 往返 |
| --- | --- |
| 空命令之缓 | 六十六至八十九微秒 |
| 一线之空派 | 二百四十四至三百一十四微秒 |
| 64×64 矩阵乘 | 二百九十至三百五十四微秒 |
| 一 Objective-C 之消息（宿主调之费） | 约二微秒 |

径以诺驿书同派，空派约二百六十五至三百三十五微秒，故时多耗于 GPU 之侧，豫言与宿主之费（一派约二十越宿主）仅居其小。

## 限

待办事项：惟支 arm64（MTLSize 等逾十六字之结构传指副本之址，x86-64 按值压栈，未支）；毕事之回调未支，一以同步候之；核之试俟着色语言能译 MSL 乃补。

### 深度学习并发计算

为深度学习推理之速，予「置并发算编器」与「算缓冲屏障」。前者依MTLDispatchTypeConcurrent造编码器，后者以MTLBarrierScopeBuffers序障前后之存缓访问。召者须核存储读写之所待，有所待则设障；交、候与对象存亡仍依原命令之法。
