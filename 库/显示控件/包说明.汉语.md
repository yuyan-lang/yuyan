# 显示控件

显示 0.7.0 与剪贴板 0.2.0：指针移动后按悬停的项设指针形状（未禁用的文本框为文字指针，按钮与链接热区为手形，其余默认；与上次设给宿主的相同就不再调用）。收到“组字更新”时把预编辑文字与光标码点位置记进控件状态，焦点文本框把预编辑文字插在光标处一起排版、画下划线，不写进文本，也不画选区；空文字表示组字结束。焦点在未禁用的文本框上时，命令或控制加 c、x、v 复制、剪切、粘贴（粘贴按文字输入插入，换行去掉）；写剪贴板失败（如浏览器拒绝权限）用「尝试运行」接住，剪切也就不删文字，应用不退出；读剪贴板失败不改文本。本包因此依赖剪贴板接口包，跑显示控件的宿主都要提供剪贴板读写。

文本框有焦点时光标闪烁：亮、灭各 530 毫秒。主循环把下次翻转的时点与应用计时取较早者，用显示 0.5.0 的限时等待；到期只翻转光标并重画，不调用计时更新。按键、文字输入与指针按下让光标重新亮起并从头计时；焦点离开文本框就停止闪烁。熄灭时照常报告输入区域，输入法候选框不跟着跳。

主循环接入显示0.6.0的 `显示尺寸变化`。收到通知后保留应用状态、交互项和计时到期时点，直接按当前尺寸与像素比重绘；不触发计时更新，也不假造键鼠输入。浏览器布局及节点窗口变化均走同一主循环。

显示输入现已产生指针交互：主键按下后读取按下标识，移动及抬起回传同一标识，抬起后清除捕获。坐标复用物理像素到逻辑六四的换算，保留旧焦点、点击和滚动结果。滚动条仍由旧处理器优先处理；窗口标题栏拖动的应用状态尚待接入。

交互事件增加 `指针交互(标识,阶段,横,纵)`，阶段0按下、1移动、2抬起，坐标使用逻辑像素乘64。此阶段只定义消息载体，显示输入尚未产生该事件，现有点击与滚动行为沿用原路径。

`运行显示控件计时会话` 在会话参数后增加“状态 → 毫秒”间隔与“状态 → 状态”计时更新。正间隔使用显示0.5.0限时等待及公共时间接口保留到期时点，输入后只等待剩余时间，到期更新模型并重画；输入及焦点仍循原路径。非正间隔无限等待，旧会话入口传零间隔。真实 SDL 每50毫秒持续鼠标输入、闲置刷新及关窗停止验收通过。墙钟跳变处理仍待完成。

自动聚焦优先保留明确光标定位请求。新文本框没有定位请求时仍默认置末；应用恢复中间光标后再显示控件，聚焦不会覆盖它。定位回归覆盖控件消失、重新定位、重新聚焦；既有71项交互断言通过。

自绘控件的自动聚焦在标记由关闭转为开启时也生效。新控件的光标置末，已有控件保留光标；标记持续开启时不重复抢焦点。交互测试覆盖重新激活与中间光标保留。

`运行显示控件会话` 在可停止主循环参数后接“结束归还”标记；为真时，正常停止或错误结果返回前调用显示0.3.0的 `归还显示面`。显示面已经关闭时不重复报错，其他归还失败保留错误说明。原 `运行显示控件可停止` 与 `运行显示控件` 传假，继续由宿主管理面。待办事项：语言异常越过主循环时的归还另补。

主循环在原改文事件后附加 `编辑改变（标识、全文、码点位置）`；焦点文本框的光标或焦点改变时，也回传其当前文字与位置。原低层事件处理函数保留原事件结果，附加工作由 `编辑事件。豫` 完成；提交且光标未变时不重新报告旧文字。完整编辑事件与光标回传测试通过。

`光标定位节点` 包含控件标识、非负请求序号、码点位置及子节点；收集交互项时应用新的序号并递归子节点，绘制时只递归子节点。相同序号保留用户后来移动的光标，控件消失时清理序号。负位置取零，文字范围由现有文本框编辑及绘制夹取。一次性定位、重复请求保留、新序号和消失清理测试通过；图形桌面类型检查通过。

图形界面的底层显示控件库（纯豫言）。上层（高层布局语言，眼下由应用手写）每帧给出一棵显示树，节点带好矩形；本库负责把它画到显示面上、实现控件行为（光标、滚动、悬停、按下、焦点）、做命中测试，并把输入变成交互事件交回上层。盒子布局（块、行内、弹性）归高层。方案见 `豫言操作系统/文档/图形界面方案.汉语.md`。

## 模块

- `显示树`：显示树、文字样式、段落排版、交互状态、交互事件、文字量具与视图环境等类型。坐标、尺寸、字号都是 1/64 逻辑像素的整数（逻辑六四）；颜色是一个整数 0xRRGGBBAA（直通透明度）。
- `画布`：物理像素的 RGBA 帧缓冲（标准库「字节缓冲」）：填充与描边矩形、圆角矩形（4×4 超采样的抗锯齿）、按覆盖度与颜色混合字形，都带裁剪框；整帧转成字节串交给显示接口。
- `文字字体`：族名第一次用到时经字体接口取字体文件并解析，结果记在登记表里；每种族列建一个字形库（缺字回退到无衬线）。逻辑六四与物理像素的换算。「登记字体」直接登记一个字体，供测试与自带字体的应用使用。
- `文字排版`：文字量具的实现。按码点量宽，在空格后与中日文字之间断行（禁则由字体库判断），行尾空格悬挂，支持对齐、固定行高、最多行数与省略号，并给出最小、最大内容宽。「造文字量具」按像素比造一个量具。
- `文字绘制`：按段落排版逐字画字形覆盖度；粗体为错开一个物理像素重画，另画下划线与删除线。
- `控件状态`：两帧之间保存的交互状态：悬停、按下、焦点、修饰键、指针位置、拖动滚动条，以及按标识保存的文本框光标、文本框横向滚动与滚动区偏移。
- `交互项`：每帧从显示树按绘制次序收集热区、文本框与滚动区，带屏幕上的框与裁剪框；命中测试、焦点次序与滚动条几何。
- `绘制树`：把显示树画进画布（按边取整到物理像素，裁剪、滚动平移、滚动条、文本框光标与横向滚动），返回焦点文本框的光标矩形，供输入法候选框定位。
- `事件处理`：把显示面的输入事件换成控件状态的更新与交互事件：点击（主键在同一热区按下并抬起，或焦点在按钮上时回车、空格）、文字改变（文字输入、退格、删除）、提交（文本框里回车）、焦点改变（点击、制表键轮换、上档加制表反向）、按键（其余按键，带焦点与修饰键）。滚轮、拖动滚动条、点轨道翻页，以及上下、翻页、起首、末尾键滚动。
- `主循环`：「运行显示控件」取得显示面后反复“视图 → 收交互项 → 绘制 → 提交 → 等输入事件 → 处理 → 更新应用状态”，只在交互状态、应用状态、尺寸或像素比变化时重画。

## 使用

```yuyan
「结果」者「运行显示控件」授以「我的状态」于『主窗口』于「初态」于「视图」于「更新」也。
```

「视图」由视图环境（文字量具、交互状态、视口宽高与像素比）和应用状态造显示树；「更新」把一个交互事件并入应用状态。显示面关闭时返回空文字，出错时返回错误说明。完整例子见 `示例/`（包「显示控件示例」，待办清单）。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 显示控件
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 类型检查 显示控件 -j 24
```

测试在 `测试/`（包「显示控件测试」）。公开名一律用两字以上的专名，免得劫持应用「鉴」里的同名模式变量。

## 应用主动结束

`运行显示控件可停止` 在原入口的参数后接一个“状态 → 爻”停止条件。初态已结束时直接返回空文字；主循环在绘制或等待下一事件前检查条件。应用更新产生结束状态后返回，不关闭宿主拥有的显示面。原 `运行显示控件` 入口保持等待显示面关闭的行为。

初态提前结束的实际调用测试在 `库/界面/测试/主动结束。测试。豫`，已构建运行通过；真实窗口事件后的退出还须图形验收。

## 多行文本编辑

`多行文本框节点` 在普通文本框参数后接逻辑六四行高。它保存全文码点光标与选区，用逻辑行定位鼠标和上下方向键，行首末尾键定位当前行，回车与制表键插入文字。粘贴保留换行。绘制复用字形、组字与输入法候选框定位，光标移动时让当前行滚入视口。

`测试/多行编辑。测试。豫` 覆盖空行、末尾换行、中文码点位置、回车、多行粘贴、上下移动、行首、跨行删除、鼠标行定位和第二行光标绘制。超长行的统一横向滚动留待后续改进。
