# 显示控件测试

普通文字入口在任意失败断言后抛出异常，CI与子程序执行按退出结果识别失败。实际位置、跨样式分色、行中尾白、行收敛和完整像素参考使用独立强失败向量；测试自动发现规则按现有文件名运行。

`原生文楷字形探针。脚本。豫`经共享显示控件加载程序目录文楷，使用现有字体库解析及栅格化“中”字，核对非零字形编号、位图尺寸及非空覆盖度。独立macOS程序实测退出0；此结果覆盖共享字形生成，真实窗口中的像素绘制仍待验。

[显示控件](../包说明.汉语.md)库的单元测试，不需要显示面与宿主接口，全树测试会自动运行。

另有手动原生探针，需宿主授予“主窗口”显示面，不列入全树单元测试。`原生显示会话探针。脚本。豫`检查首次取面及尺寸；`原生显示归还探针。脚本。豫`重复归还与同名重取，核对旧资源不会复活及重复归还的“资源已失效”，因此直接依赖公共基础错误类型。`原生显示计时探针。脚本。豫`先建窗，核对三次100毫秒限时等待在80–500毫秒内返回计时，并检查归还后零、负数及正数等待均报失效。macOS实际通过记录见[原生接入复核](../../用户态桌面/原生接入.汉语.md)；其他宿主仍须各自运行，编译通过不代表接口已接入。

另有 `原生公共时间探针。脚本。豫`，直接依赖公共时间包，检查64位纪元毫秒数量级及与显示计时的联动；它同样需要手动原生宿主验收。

`原生文楷资源探针。脚本。豫`直接依赖公共字体包，检查随程序文楷的长度、单字体集序号及实际文件头；运行时应使用不同工作目录。`原生文楷拒绝探针。脚本。豫`用于程序目录缺少字体或末级字体为符号链接的情形，工作目录中的同名字体不能替代程序资源。这两项须手动运行独立原生程序；资源读取通过仍须继续验证字体解析与桌面绘制。

`原生显示换算探针。脚本。豫`以320×240逻辑尺寸授面，核对实际物理尺寸等于逻辑尺寸乘公共像素比。`原生显示尺寸探针。脚本。豫`须从外部真实调整窗口，检查公共尺寸通知及新尺寸，最长候60次；界面控制服务不可用时须记录未验，不以模拟通知替代。

- `画布。测试。豫`：画布的清屏、裁剪、不透明与半透明填充（半透明按直通透明度混合的精确值）、描边、圆角矩形的覆盖与字形覆盖度混合。
- `全量/圆角参考。脚本。豫`：直接依赖二维绘图与图像编解码，比较半径2、8、32、64的解析面积与独立四乘四子样本覆盖，输出最大差、平方差和及像素数。
- `文字。测试。豫`：把字体测试包手造的小字体登记成“无衬线”，核对字体度量、单片与多片排版、按空格与汉字断行、最小与最大内容宽、居中、省略号、强制换行、单行排版与字形绘制。
- `排版缓存。测试。豫`：排版缓存同键第二次不再排版，只改颜色或装饰线仍命中，文字、字号、最大宽、像素比、段落参数、分片任一变化都重排，经缓存与不经缓存的结果相同，清空后重排。
- `增量绘制。测试。豫`：手搭桌面显示树，同一串状态（开窗、聚焦、打字、光标闪烁、命令行追加输出、滚动、拖窗、悬停、关窗、不变）分别整帧重画与增量重画，每一步两块画布逐像素相同；没变的帧一块也不画，光标闪烁只画光标一小块，悬停只画按钮一块。
- `交互。测试。豫`：手搭一棵显示树，把输入事件逐个交给事件处理，核对交互项的收集次序与屏上位置、悬停与点击（含移开后抬起、右键、禁用、区域热区失焦）、制表键轮换焦点与滚到可见、文本框的输入与编辑键、点文本框放光标、焦点按钮的回车与空格、滚轮、拖动滚动条与点轨道翻页、键盘滚动、自动聚焦与消失控件的清理，以及显示树绘制与光标矩形。
# 控件强断区间

回车区间测试直接调用控件内部整形断行入口，核对CRLF同时从行内容排除，下一行起点保持原码点序。全文上下文测量另以128单位非零字距核对CRLF的两个原码点宽度均为零。强断字形的宽度累计保留零前进量。
# 跨色连字

跨色连字测试用独立构造的GSUB liga表核对红A与蓝B合为576单位连字、簇首归红片、蓝片零字形和实际控件行宽；截为单独A后恢复384单位。实际控件绘制的6144字节帧与独立红色字形2参考逐字节相等。另以独立cmap与arab init/fina表核对跨颜色两个beh的初形2、末形3，断后独形1。固定字节表与hmtx期望独立于排版输出。
# 连接边界

连接边界测试核对真实Unicode连接类别：透明fatha继续连接，ZWNJ截断，调用者ZWJ保留原码点并参与连接。实际行边界和不同双向层级截断上下文。跨字体虚上下文的精确来源过滤与生产整形接线另行推进。
