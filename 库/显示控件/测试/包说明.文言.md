# 显示控件测试

寻常文字入口遇败断言则抛异常，CI与子程依退出之果识败。实位、跨式分色、行中尾空、行收敛、全像参考皆用别立强败向量；循既有文件名自发现而试之。

`原生文楷字形探针。豫`由共用显示控件载程序目录文楷，以旧字体库析而栅“中”字，核非零形号、图尺与非空覆度。独立苹果程序实验退出零；此果核共用字形之成，实窗像素之绘仍待验。

[显示控件](../包说明.文言.md)库之单元测试，不须显示之面与宿主之接口，全树测试自行之。

另有手行之原生探针，须宿主授“主窗口”显示面，不入全树单元之试。`原生显示会话探针。豫`核初取面与尺；`原生显示归还探针。豫`反复归与同名复取，核旧资不复生及重复归还之“资源已失效”，故径依公基础错误之类。`原生显示计时探针。豫`先建窗，核三次百毫秒限时之候于八十至五百毫秒内返计时，并核归后零、负与正之候皆报失效。苹果实行之录见[原生接入复核](../../用户态桌面/原生接入.文言.md)；他宿主仍须各自行之，编译之过不谓接口已接。

另有 `原生公共时间探针。豫`，径依公时间包，核六十四位纪元毫秒数阶与显示计时相用；亦须手行原生宿主之验。

`原生文楷资源探针。豫`径依公字体包，核随程序文楷之长、单字体集序与实文之首；运行当异工作目录。`原生文楷拒绝探针。豫`用于程序目录无字体或末级字体为符链之境，今目录同名字体不得代程序之资。二者须手行独立原生程序；读资虽过，仍须续验字体之析与桌面之画。

`原生显示换算探针。豫`以三百二十乘二百四十逻辑尺授面，核实物理尺等于逻辑尺乘公素比。`原生显示尺寸探针。豫`须从外实改窗，核公尺告与新尺，至多候六十次；界面控制服务不可用者，须录未验，毋以模拟之告代之。

- `画布。测试。豫`：核画布之清屏、裁剪、不透与半透之填（半透依直通透明混之，核其确值）、描边、圆角之覆与字形覆盖之混。
- `全量/圆角参考。豫`：径依二维绘图、图像编解码，较半径二、八、三十二、六十四之解析面积与别立十六子样之覆，出最大差、平方差和及素数。
- `文字。测试。豫`：以字体测试包手造之小字体登记为“无衬线”，核字体之度、单片与多片之排、依空格与汉字断行、最小最大内容之宽、居中、省略号、必断、单行之排与字形之画。
- `交互。测试。豫`：手搭一显示树，逐授输入之事于事之处置，核交互项所收之序与屏上之位、悬停与点击（兼移去乃抬、右键、禁用、区域热区失焦）、制表轮换焦点而滚令可见、文本框之输入与编辑之键、点文本框置光标、焦在钮之回车与空格、滚轮、拖滚条与点轨翻页、键之滚、自动聚焦与已逝控件之清，及画显示树与光标之矩。
# 控件强断区间

回车区间之验直召控件内整形断行，核CRLF俱除于行文，次行之始存原码序。全文之境别以百二十八单位字距，核CRLF二原码宽俱零。强断之形积宽存零进量。
# 跨色连字

跨色连字之验，以别造GSUB liga表核红A、蓝B合为五百七十六单位连字、簇首属红片、蓝片无形及实控件行宽；独A复为三百八十四单位。实控件之帧六千一百四十四字节，与别立红色形二之参逐字节相等。别以cmap、arab init/fina表核跨色二beh初形二、末形三、断后独形一。定字节表及hmtx之期，别立于排版所出。
# 连接边界

连接之界验实通码连接类：透明fatha续连，ZWNJ断连，调用者ZWJ存原码而参与连接。实行之界及异双向级截其境。跨字体虚境之精来源滤取及生产整形之接，别续行之。
