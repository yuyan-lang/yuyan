# 显示控件

图形界面底层之显示控件库（纯豫言）。上层（高层布局之言，今由应用手书）每帧授一显示之树，诸节皆定其矩；此库画之于显示之面，行控件之为（光标、滚动、悬停、按下、焦点），测其所中，化输入为交互之事以还上层。盒之布归高层。方案见 `豫言操作系统/文档/图形界面方案.文言.md`。

## 模

- `显示树`：显示之树、文式、段排、交互之态、交互之事、文字量具与视图之境诸类。坐标、尺寸、字号皆以六十四分之一逻辑像素之整数计（逻辑六四）；色以一整数 0xRRGGBBAA（透未预乘）。
- `画布`：物理之素之 RGBA 帧（标准库「字节缓冲」）：填矩与描边、圆角之矩（四乘四超采样之抗锯齿）、依覆与色混字形，皆带裁框；全帧转为字节串以交显示之接口。
- `文字字体`：族名初用，经字体接口取文件而解之，录于登记之表；每一族列造一字形库（缺字退于无衬线）。逻辑六四与物理之素相换。「登记字体」径登记一字体，供试与自带字体之应用。
- `文字排版`：文字量具之实。依码量宽，断于空格之后与中日文字之间（禁则由字体库断之），行尾之空悬之；可对齐、定行高、限行数而加省略号，并出最小、最大内容之宽。「造文字量具」依像素比造之。
- `文字绘制`：依段排逐字画字形之覆；粗体错一物理之素而重画之，并画下划线与删除线。
- `控件状态`：两帧之间所存交互之态：悬停、按下、焦点、修饰之键、指之位、拖滚条，及依标识所存文本框之光标、横滚与滚动区之偏移。
- `交互项`：每帧依画序自显示树收热区、文本框、滚动区，带其屏上之框与裁框；测中、焦点之序与滚条之形。
- `绘制树`：画显示树于画布（依边取整于物理之素，裁、滚移、滚条、文本框之光标与横滚），还焦点文本框光标之矩，以定输入法候选之位。
- `事件处理`：化显示面之输入为控件之态之更与交互之事：点击（主键按抬于同一热区，或焦点在钮而回车、空格）、文字改变（文字输入、退格、删除）、提交（文本框中回车）、焦点改变（点、制表轮换、上档加制表则逆）、按键（余键，带焦点与修饰）。滚轮、拖滚条、点轨翻页，及上下、翻页、起首、末尾之键皆滚。
- `主循环`：「运行显示控件」得显示面，乃反复“视图、收项、画、交、候事、处之、更应用之态”，惟交互之态、应用之态、尺寸或像素比变乃重画。

## 用

```yuyan
「结果」者「运行显示控件」授以「我的状态」于『主窗口』于「初态」于「视图」于「更新」也。
```

「视图」以视图之境（文字量具、交互之态、视口之宽高与像素比）与应用之态造显示之树；「更新」以一交互之事并入应用之态。面闭则还空文，有误则还其说。全例见 `示例/`（包「显示控件示例」，待办之单）。于仓根行 `检查 显示控件` 与 `类型检查 显示控件`。

试在 `测试/`（包「显示控件测试」）。公名皆二字以上，免夺客「鉴」中同名之模式变量。

## 待办事项

每变则全帧重画（无脏矩）；惟 CPU 画之；文本框惟单行，无选区、剪贴板与输入法预编之显；无指针之形；显示接口无尺寸变更之事，窗缩放后须候下一输入之事乃重画。
