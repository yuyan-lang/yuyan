# 显示控件

候选文字接线用包内「字形片段」，共整形簇之量与定位字形之画，循全统一码之界断行。候选有别立之位向量，待专窗验型与运行；跨式双向之境及断后度量之调，留待后续段级接线。

显示零点七版与剪贴零点二版：指移之后依所悬之项设指之形（未禁之文本框为文字，钮与链之热区为手形，余为常箭；同于前设则不复呼宿主）。得“组字更新”则记预编之文与光标之码位于控件之态，焦点文本框以预编之文插于光标处而同排之，画下划线，不入正文，亦不画选区；空文为组字毕。焦点在未禁之文本框，命令或控制加 c、x、v 则复制、剪切、粘贴（粘贴以文字之入插之，去其换行）；书剪贴败（如浏览器拒其权）以「尝试运行」承之，剪切亦不删文，应用不退；读剪贴败则不易其文。故此包依剪贴之接口包，凡行显示控件之宿主皆须供剪贴之读写。

文本框得焦则光标闪烁：明、灭各五百三十毫秒。主循环以下次翻转之时与应用计时取其早者，用显示零点五版之限时以候；期至惟翻光标而重画，不行计时更新。按键、文字之入与指之按，令光标复明而重计；焦离文本框则止其闪。灭时仍告输入之区，输入法之候选不随之跃。

主循环接显示零点六版之 `显示尺寸变化`。得告则存客态、交互项与计时之期，径循今尺与像素比重绘；不行计时更新，亦不冒键鼠输入。浏览器布局与节点窗变皆行同一主循环。

显示输入今生指针交互：主键按下后取按下之标，移动与抬起回同标，抬后清捕。坐标共物理像素至逻辑六十四之换，存旧焦点、点击与滚动之果。滚条犹由旧处置优先；窗标题拖移之客态犹待接。

交互事增 `指针交互(标识,阶段,横,纵)`，阶段零按下、一移动、二抬起，坐标用逻辑像素乘六十四。此阶段惟定消息之载，显示输入未生此事，旧点击与滚动循旧路。

`运行显示控件计时会话` 于会话之参后增“状态 → 毫秒”之距与“状态 → 状态”之更新。距正则用显示零点五版限时之候与公时间接口，存到期之时，输入后惟候余时，到期更新模型而重画；输入与焦点循旧路。非正则无期，旧会话传零距。实 SDL 每五十毫秒续注鼠事、闲置刷新及闭窗止采之验皆过。墙钟跃变之治犹待成。

自焦先存明光标定位之请。新文框无定位之请则默认置末；客复文中之标而再显控件，聚焦不覆之。定位之试验控件亡、复定位与复聚焦；旧七十一项交互断言皆过。

自绘控件之自焦，标由闭而启亦行之。新控件之光标置末，旧者存其标；恒启则不复夺焦。交互之试验复启与文中光标之存。

`运行显示控件会话` 于可止主循环之参后受“结束归还”之标；阳则正常止或误果归前调显示零点三版之 `归还显示面`。面既闭则不复报误，余归还之败存其说。旧 `运行显示控件可停止` 与 `运行显示控件` 授阴，犹由宿主掌面。待办事项：语言异常越主循环时之归还待补。

主循环于旧改文之事后附 `编辑改变（标识、全文、码点位置）`；焦文框之标或焦有变，亦报其今文与位。旧低层事处理之函存旧果，所附由 `编辑事件。豫` 行之；提交而标未变，则不复报旧文。全编辑之事与光标回传诸试皆过。

`光标定位节点` 含控件标识、非负请序、码点位及子节；收交互项时施新序而递行子节，绘时惟递行子节。同序存用户后移之光标，控件亡则清其序。负位取零，文界由旧文框编辑与绘夹取。一次定位、同序存位、新序与亡后清理诸试皆过；图形桌面类型之查亦过。

图形界面底层之显示控件库（纯豫言）。上层（高层布局之言，今由应用手书）每帧授一显示之树，诸节皆定其矩；此库画之于显示之面，行控件之为（光标、滚动、悬停、按下、焦点），测其所中，化输入为交互之事以还上层。盒之布归高层。方案见 `豫言操作系统/文档/图形界面方案.文言.md`。

## 模

- `显示树`：显示之树、文式、段排、交互之态、交互之事、文字量具与视图之境诸类。坐标、尺寸、字号皆以六十四分之一逻辑像素之整数计（逻辑六四）；色以一整数 0xRRGGBBAA（透未预乘）。
- `画布`：物理像素之 RGBA 帧（标准库「字节缓冲」）：填矩与描边、由二维绘图解析覆所绘之圆角矩及其边、依覆与色混字形，皆带裁框；全帧转为字节串以交显示之口。
- 画圆角阴影受画布、裁框、矩左上右下、圆角之径、横纵之移、模糊之径、标差与色；共用二维绘图之影及图像处理之高斯模糊。
- `文字字体`：族名初用，经字体接口取文件而解之，录于登记之表；每一族列造一字形库（缺字退于无衬线）。逻辑六四与物理之素相换。「登记字体」径登记一字体，供试与自带字体之应用。
- `文字排版`：文字量具之实。依码量宽，由共用「文字排版」库断行，可断于空格之后与中日文字之间（禁则由字体库断之），行尾之空悬之；可对齐、定行高、限行数而加省略号，并出最小、最大内容之宽。「造文字量具」依像素比造之。
- `文字绘制`：依段排逐字画字形之覆；粗体错一物理之素而重画之，并画下划线与删除线。
- `控件状态`：两帧之间所存交互之态：悬停、按下、焦点、修饰之键、指之位、拖滚条，及依标识所存文本框之光标、横滚与滚动区之偏移。
- `交互项`：每帧依画序自显示树收热区、文本框、滚动区，带其屏上之框与裁框；测中、焦点之序与滚条之形。
- `绘制树`：画显示树于画布（依边取整于物理之素，裁、滚移、滚条、文本框之光标与横滚），还焦点文本框光标之矩，以定输入法候选之位。
- `事件处理`：化显示面之输入为控件之态之更与交互之事：点击（主键按抬于同一热区，或焦点在钮而回车、空格）、文字改变（文字输入、退格、删除）、提交（文本框中回车）、焦点改变（点、制表轮换、上档加制表则逆）、按键（余键，带焦点与修饰）。滚轮、拖滚条、点轨翻页，及上下、翻页、起首、末尾之键皆滚。
- `主循环`：「运行显示控件」得显示面，乃反复“视图、收项、画、交、候事、处之、更应用之态”，惟交互之态、应用之态、尺寸或像素比变乃重画。

## 用

```yuyan
「结果」者「运行显示控件」授以「我的状态」于『主窗口』于「初态」于「视图」于「更新」也。
```

「视图」以视图之境（文字量具、交互之态、视口之宽高与像素比）与应用之态造显示之树；「更新」以一交互之事并入应用之态。面闭则还空文，有误则还其说。全例见 `示例/`（包「显示控件示例」，待办之单）。于仓根行 `检查 显示控件` 与 `类型检查 显示控件`。

试在 `测试/`（包「显示控件测试」）。公名皆二字以上，免夺客「鉴」中同名之模式变量。

## 客之主动结束

`运行显示控件可停止` 于旧入口诸参之后接“状态 → 爻”之止条件。初态已终则径还空文；主循环于绘或候下一事前察之。更新生终态则还，不闭宿主所持之面。旧 `运行显示控件` 仍候面闭。

初态早终之实调试在 `库/界面/测试/主动结束。测试。豫`，已构建而行，皆过；实窗之事后退出尚须图形之验。

## 多行文本编辑

文字之节以诸式片为一段，统解双向之级。量与断后复整取全文相应之级；各行循L1复位、L2视觉重排，分同式同级之区间，绘取原片之色、体、字距。跨式试以א、בA二片核前进一千六百六十四、片号一一零之视觉次，并较实分色帧与别定坐标之参考帧；诺节三核皆过。跨式换体后阿拉伯连接之境，待更验。

文行既定断处，各行同式之文复整其形，行宽与片之横位取此前进。内容之最小、最大宽存断前之度。自动换行时，复整而过宽者，循全UCD之界与有效簇首复分之，新行复量，独簇过宽则全存。宽缩后合邻行，俟后版。实量与绘之模经全包验型；旧十一项位置皆过，新四项复断码位与续簇、实像三项别立参考之核，于诺节、同客体原生皆过。

`多行文本框节点` 于寻常文框诸参后接逻辑六四行高。存全文码位之光标与选区，以逻辑行定位鼠标与上下方向键，首末之键至当行首末，回车制表则入文。粘贴存换行。绘用既有字形、组字与候选框定位，光标移则使当行入视口。

`测试/多行编辑。测试。豫` 验空行、末换行、中文码位、回车、多行粘贴、上下移、行首、跨行删除、鼠标择行与次行光标之绘。超长行同一横滚留待后改。

主循环处输入后报焦点文本框之 `选区改变`，传码点始止。范围取光标与选区锚点，反向之选归为始不大于止；惟锚变亦报。无选区则两端皆光标。

多行文字供始于一之行号文字及栏宽之算。栏宽用逻辑六四，依末行号位数、调用者所给数字实宽及两侧边距计之。空文存首行，末换行增一行。

`多行文本框节点` 末增逻辑六四行号栏宽，零表示普通文框。行号随正文纵向偏移，横位固定。正文之绘、指针命中与输入法候选之位共用避让行号栏之后区域。
行号之绘兼受栏域及外层裁剪之约，滚动之半行存于编辑视口内。
多行编辑之试以测试字体逐像素验半行滚动：栏内有行号墨迹，栏外存背景色。此证及离屏之绘与裁剪。
空正文多行之景，增正文横偏二十逻辑像素，比前后画布全二万四千字节，验行号之位固定。

`文本行内着色` 切全文字符之域于所定逻辑行，还行内始止之位及合色。换行存于全文坐标，跨行之域各截于其行正文，空交集则略，色与原域之序皆存。

`文本着色片` 依行内之域成既有文字片，补未着色之原文，存字体、字号、字重、饰与字距。域越界或相叠则报错。编辑控件绘制之接续作。
`着色单行排版` 以同一行之诸片付既有段落排版器，共排为单行。测试字体之中文样本验着色前后宽高相同。
`画着色文本框` 受行内着色之域，共文框之选区、光标、横滚及输入法候选框之绘。组字时用常色，组毕复用着色之域。工作台义标之域传入续作。
