# 显示控件示例

[显示控件](../包说明.汉语.md)的示例应用：待办清单。顶上是标题、输入框与“添加”按钮（回车也能添加），中间是可滚动的待办列表（点方块勾选，点“删除”删去，完成的项加删除线并变灰，太长的以省略号结尾），底下是统计与“清除已完成”。制表键在输入框与各按钮间轮换焦点，按钮有焦点时回车或空格即点击；滚轮、拖动滚动条、上下键与翻页键滚动列表。

高层布局语言还没有，视图函数里手算矩形（逻辑像素乘 64）；文字用字体接口的“无衬线”。

## 运行

诺节（需要显示与字体两个接口的诺节实现，以及放 SDL 的原生依赖目录）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 显示控件示例 --输出 yy显示控件示例.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录> yy显示控件示例.wasm
```

自动验收时加 `--显示面后台`，窗口不抢前台。浏览器上用 `yy双宿主构建 --自动 浏览器` 构建，页面放一个 `data-yy-显示面="主窗口"` 的 canvas，并用 `link[data-yy-字体]` 给出“无衬线”字体文件。
