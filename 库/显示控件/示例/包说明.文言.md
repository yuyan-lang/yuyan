# 显示控件示例

[显示控件](../包说明.文言.md)之示例：待办之单。上为题、输入之框与“添加”之钮（回车亦添），中为可滚之单（点方块以勾之，点“删除”以去之，已成者加删除之线而灰，长者以省略号终），下为计与“清除已完成”。制表之键轮换焦点于框与诸钮，钮得焦点则回车、空格即点；滚轮、拖滚条、上下与翻页之键皆可滚其单。

高层布局之言未成，视图之函手算其矩（逻辑之素乘六十四）；文用字体接口之“无衬线”。

## 行之

诺节（须显示、字体二接口之诺节实现，及置 SDL 之原生依赖目录）。于仓之根，以双宿主构建之节点模式构其发行包，乃以包中之 `启动.mjs` 行之：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 节点 库/显示控件/示例 dist/显示控件示例 --包根 库/显示控件 --包根 库/字体
node dist/显示控件示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 为已装 `@kmamal/sdl` 之目（含 `node_modules` 之层），见[诺节宿主之说](../../../豫言操作系统/宿主/节点/说明.文言.md)。显示之原语惟在发行包之应用宿主；工具链宿主 `宿主.cjs` 惟以行构建之具。自动之验加 `--显示面后台`，窗不夺前台。浏览器以 `yy双宿主构建 --自动 浏览器` 构之，页置 `data-yy-显示面="主窗口"` 之 canvas，并以 `link[data-yy-字体]` 给“无衬线”之字体文件。
