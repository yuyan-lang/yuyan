# 司电（ACPI）控制方法库

司电（ACPI）控制方法库，依 ACPI 6.5（UEFI 论坛公开）第 19、20 章与附录 B 写成，供豫言操作系统的初始任务在裸机上读取司电表、装命名空间、执行方法。

## 收什么

- 表：从根指针（RSDP）经根表（XSDT 或 RSDT）取固定描述表（FADT）、区分描述表（DSDT）与各辅助描述表（SSDT），并解出 FADT 的电源寄存器、GPE 块与 DSDT 地址。
- AML：装 DSDT 与各 SSDT 的命名空间（名字、作用域、设备、方法、操作区、字段、索引字段、银行字段、互斥、事件），解释常用操作码执行方法：参数与局部、返回、整数、文字、帛、包、算术、比较、位运算、条件与循环、取反与解引用、取大小与对象类型、索引、Store、Notify、Sleep 与 Stall。
- 用：在命名空间里按 `_HID` 找设备，取电池 `_BIF`／`_BIX`／`_BST`、交流电 `_PSR`、合盖 `_LID`、背光 `_BCL`／`_BCM`／`_BQC`。

## 怎么访硬件

解释器不碰端口与内存，经「司电钩」的四个函数访硬件：读操作区、写操作区、通知与等待。裸机上的钩在初始任务里经内核服务实现（系统内存、系统 I/O、PCI 配置与嵌入式控制器四种地址空间）；测试里的钩在内存里模拟。

## 报错

不认的操作码抛出一条说明，解释器在方法边界接住、记下错误并交回零，不让开机失败；调用方可用「司电误」取最近一次错误。
