# 编译器入口

命参 `--原生参数输出` 所载之径，于界上付营造（构建基础）草牍（构建临时文件）之「析临时文」，验而还其抽象之类，乃以可有、可无存交接之引。构号、职尾与组序，共识此构之暂卷（议一三〇〇）。

链参之交接与前炉之制签，循编参籍（编译器选项表）所定之段而取。选后之值各全，双画之后运言悉存；末链持前签，阶储有阙则并陈两制。

常译未分并役、未用旧储，先稽入卷所属之包，其宿主之实是否具全（提案〇〇〇五八）。所查源目随第七式包境而传，远行逐卷取之。底层实包别备常底合篇，引诸实现及分派所需之基础；接口类依于依析时补足，签之核与派之生于正名时施行。其则及导出之约，见编译器核心包说明与规范「类型与模块」类六。

编译器之主函「译场主」：读命令行之参，依 `stage`、`debug`、`--原生产物子进程`、`--mode=worker` 与常编而分之，并挂原生之产书出之钩（`--目标 本机` 则终链经裸机后端径出本机原生可执行之文）。

豫言编译器之入口呼之；豫构（提案 00007 合一）于首参为源文、`stage`、`debug`、`--mode=…` 或 `--原生产物子进程` 者亦呼之，故 `豫构` 自为编译器，并行编译之工作进程用同一程文。

编译以定讯（“编译错误：…”或底层之“底层编译错误…”）而败者，主函原书其讯于标准误，以退出码一终；余异仍告，其不承者由顶层未捕之术书之。工作之程亦由此，全构之路与独程之路所报同此数行。

所依及说明之径，以[包配置](编译器入口。包。豫)为准。
