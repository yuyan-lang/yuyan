# 安全外壳客户与服务者后续工作

## 今之所止

豫言已备 SSH 传输、Ed25519 公钥认证、单 session 通道、无 PTY 命令常流及 PTY 双向转字。客户与一次性服务探针，已同 OpenSSH 验换钥、认证、命令、回文与再议。密码原术今借 OpenSSL `libcrypto`。探针惟听本机回环试埠，取 `/tmp/yyssh...` 诸试文；此为验库之器，未可径充通用 SSH/SSHD。

## 复工宜先行

1. 整探针为可配置之豫言客户与服务入口；主机、埠、私钥、可信主钥簿、授权公钥、彼命令及本地出入文，皆由参或配置定之。初惟单用户、公钥认证、单会话通道。
2. 抽服务者一连接之治法为可复用术；一监听可续治多连接，继乃并行。各连之钥、IV、窗、子进程及清理，不得相杂。
3. 明定基础传文件之法：先可凭 `exec` 与常流转文，核字数或摘要；若须与既有 `sftp`、`scp` 客互通，再备其子系统或协议。
4. 以真 OpenSSH 对端复验上下载、大文、微窗、半报、断连与再议；非获准钥、主钥不符及坏报皆须拒。

## 后期宜备

- 多用户授权、账户权限之界、会话资源之限及服务日志。
- 更多换钥、主钥、对称密法与用户认证之术；扩展前仍严拒无共同算法。
- 多通道、端口转发、SFTP、繁终端模式，及更全之关闭、逾时、重连处置。
- 封 OpenSSL 所借之术为稳固接口；若后欲纯豫言密码术，当别行安全审查与互通验。
