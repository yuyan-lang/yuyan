# 数据文件

读写数据子语言 `名。数据。豫`（[提案 00028](../../提案/00028-数据子语言.汉语.md)）。数据文件的顶层只放 `「名」者 值 也。`，值是字面量（字符串、整数、小数、爻）、`「列」【…】`、`「典」【…】`、组值 `「组值」【「字段」者 值 也，…】` 与构造写法 `「头」【「字段」者 值 也，…】`。

记录的字段可以取列：`「头」【「字段」者「列」【…】也】`。列里的元素可以是构造写法的记录或组值，列还可以是列之列（议四一八）。组值读成头名为「组值」的记录，字段按名取值，写出时仍写回 `「组值」【…】` 的构造写法。

## 读取

节点类别复用章句（语法与排版）的式类（表达式类别），只显示固定类别名；完整节点内容进入至多一百五十字的源文或打印摘要。

- 「析数据文」于「文件名」为…于「内容」为…：只做词法与语法分析（编译器核心），得到「数据根」——顶层的（名，值）列，依书写次序。导入与签名跳过。
- 「读籍册」于 路径：读文件后解析。解析报错带文件、行、列：`文件:行:列：` 接原因与一小段说明（节点类别加一两百字源文），全串不超过五百字；找不到源码位置时给原因与截短的节点打印，并注明“无源文”。
- 「数据值」：数据空、数据爻、数据整数、数据小数、数据字符串、数据符号、数据列、数据记录（头名与字段列）、数据帛（字节串，只在籍帛里用）。`「典」【…】` 读成头名为「典」的记录；`「组值」【…】` 读成头名为「组值」的记录。
- 「数据取」于 根 于 名：按名取值，记录的字段也用它取。「数据诸列项」「数据录诸栏」「数据值文字」取列项、字段与值的文字。
- 「数据表诸行」于「根」为…于「表名」为…于「字段名们」为…：把顶层名下的记录列读成行（每行按字段名取文字，缺的字段为空串）。

## 写出

- 「写数据文」于 根：顶层每个定义之间空一行；标量写在一行，列与记录每项占一行，按全角空格缩进。小数写成小数字面（如「零点八五」「一点零」「负二点五」）：先按六位定点写、去掉末尾的零（至少留一位小数），读回与原值相差不超过万亿分之一就用这个短写法，否则用十七位有效数字的精确写法。
- 「述数据值」于 值：把一个值写成一行数据子语言的文字，列与记录也在同一行，项与字段之间用逗号；供清单与日志逐行印出，用「析数据文」读回。整篇书写仍用「写数据文」。
- 「写籍册」于 路径 于 根。
- 「数据表」于「头名」为…于「字段名们」为…于「整数字段们」为…于「行们」为…：把行写成记录列，「整数字段们」里的字段写成整数。

字符串里的 `』`、`「：`、换行与制表符写成转义 `「：』：」`、`「：「：：」`、`「：换行：」`、`「：制表：」`。整数逐位写成汉字，负数首字写「负」，如「九三六三四五六」「负二」。

## 籍帛：二进制编码

程序之间传消息、传文件用二进制：一条消息的正文是数据根的籍帛编码（[提案 00051](../../提案/00051-程序间二进制通信.汉语.md)）。「编籍帛」于 根：把数据根编成「帛」；「解籍帛」于 帛：把帛解回数据根，返回「籍帛解果」：「解成」带数据根，「解误」带一句缘由。截断、类别号不认、长度越界、变长整数超过十字节都返回解误。

每个值以一个字节的类别号起头：

| 类别号 | 值 | 后接 |
| --- | --- | --- |
| 0 | 数据空 | 无 |
| 1 | 数据爻，阴 | 无 |
| 2 | 数据爻，阳 | 无 |
| 3 | 数据整数 | 之字形变长整数：非负 n 写 2n，负 n 写 −2n−1；七位一组、低位在前，除末组外最高位置一，最多十字节 |
| 4 | 数据小数 | 八字节，「小数作位」所得位型，低字节在前 |
| 5 | 数据字符串 | 变长整数写 UTF-8 字节数，再接字节 |
| 6 | 数据符号 | 同数据字符串 |
| 7 | 数据列 | 变长整数写项数，再接各项 |
| 8 | 数据记录 | 记录名（变长整数字节数加 UTF-8）、变长整数写栏数，再接各栏（栏名加值） |
| 9 | 数据帛 | 变长整数写字节数，再接原样字节 |

数据根写成：变长整数写栏数，再接各栏（栏名加值）。

「编籍帛」先一遍算出总字节数，「置牍」一次，再一遍按下标写入，末以「牍作帛」抄成帛；「解籍帛」按下标读，不复制整块。

## 数据帛

「数据帛」是第九种数据值，装一条「帛」，只在籍帛里出现，用来原样传文件与二进制内容。「写数据文」遇到它只写占位 `「帛」于「字节数」`（如 `「帛」于「三零零零」`，表示三千字节），供日志看；「析数据文」不读回它。

## 封

- 「封刺」于「元」：八字节的刺，取『籍帛』两字的八位同文，接版次一与零一。连接一建立，双方先各投一次；收方头八字节对不上就关门。
- 一封的格式：八字节小端无符号长度（低字节在前），后接这么多字节的帛。长度大于「封长上限」（一太字节）的按坏封处理。「封长帛」于 长：把长度写成那八字节。
- 「置封积」于「元」：每条连接一份的收方状态，是个「匣」装的「封积录」：待刺（还在等刺）、零散（上次读多出来的帛）、知长、封长、体（按长度置的牍）、已填。
- 「拆封」于「连」于「积」：非阻塞取一封，返回「拆封果」：整封（带帛）、未整、门绝。先凑封积里的字节，够一封就直接返回、不读连接；凑不出才读一次：收体时至多读还差的字节数与十六兆中小的那个，未收体时读六五五三六字节。多读的字节留在封积里，下一次先取。
- 「投刺」于「连」：把刺写完。
- 「投封」于「连」为…于「片」为…于「余次」为…：先写八字节长度，再写帛，分两次写；写不完等可写续写（每次至多一秒，次数用完为阴），返回爻。
- 「候封」于「连」为…于「积」为…于「毫秒」为…：阻塞等一封，至多等给定毫秒，返回拆封果（超时为未整）。
- 「成封帛」于「片」为…：把一段帛连同刺与长度接成一条帛（八字节刺、八字节长度、帛），与连接上先投刺再投封的字节逐一相同；存卷用，一卷存一封。
- 「帛作封积」于 帛：拿已有的整段帛作零散造一份等刺的封积，交「凑封」逐封取出、不读连接；读回的卷这样拆。「置封积」就是零散为空帛的这一份。
- 封里装的是帛：发送方先把数据编成籍帛（数据值的二进制编码）再投封，接收方拆封得帛后再解籍帛；封只管字节的切分与拼合，帛里装什么由收方另解。

## 迁封

任务迁移（提案 00073 第四期 4-3）在程序之间收发的消息，同一虚机的两个任务、两台虚机、两台机器之间都用它；一条消息是一封，封里是数据根的籍帛。

- 迁封（发端交收端）：栏「种」（符号“迁块”）、「版」（「迁封版次」，现为二）、「身」（发端程序的码身纹，字符串）、「块」（数据帛，豫章「迁块」的帛原样）。「编迁封」于「块」为…于「身」为…编，「解迁封」于「体」为…于「本身」为…解，答「成否」：成带迁块（先核身栏与本身相同，再核块栏的帛经「帛作迁块」是完整的迁移块），误带「迁封误」。连接与存卷上的身都取豫章「迁移」的「本码身纹」（东道原语 422 码身纹：服务 413 答的共用代码摘要写成六十四个小写十六进制字；执行器与程序合编成同一份共用代码，链不同、程序不同码身都不同；虚机外答六十四个“0”）。
- 迁执（收端回发端）：栏「种」（符号“迁执”）、「版」、「果」（符号：迁入成、拒入、入败、漏段、拒收），迁入成另带「号」（收端的新协程号），拒入另带「答」（「拒迁答」，同出磐石迁移约），拒收另带「述」（收端没收成迁封的缘由）。编解的单位是「迁执果」：「执入」带豫章的「迁入果」，「执拒」带述。「编迁执」于「果」为…编，「解迁执」于「体」为…解回；「迁执果名」「迁执果述」给名与一句话。
- 走连接：发端连上以后「投刺」、「投迁封」、「候迁执」，收到迁执才关连接；收端迎进连接以后「投刺」、「候迁封」，收成了就「协程迁入」、「投迁执」回执入，没收成先回一封执拒再报错。「候迁封」「候迁执」于「连」为…于「积」为…于「毫秒」为…阻塞等一封并解开。
- 存卷：「迁封成卷」于「块」为…把一封迁封（刺、长度、籍帛）接成一段帛写进卷；「卷作迁封」于「卷帛」为…从读出的整段帛取回迁块。卷没有回执，写完卷由发端自己弃源。
- 源端回退：发端用豫章「迁移」的「协程迁出扣」先扣下源协程再导出，源的去留由迁执定。「迁源判」于「执」为…把「候迁执」的结果穷尽地鉴成「迁源定」：执入迁入成「定弃」（带新号），执入拒入、入败、漏段与执拒「定放」（带「迁回因」：对端拒入、对端入败、对端漏段、对端拒收），收不到或解不开「定悬」（带迁封误：对端收没收不知道，源留着扣，免得两头各跑一份或一份也没有）。「迁源收」于「源号」为…于「执」为…照判定调差遣「迁源弃」或「迁源放」，答「迁源果」（源已弃、源已放、源悬、源态误）；「迁回因述」「迁源定述」「迁源果述」给一句话。
- 「迁封误」：封绝（连接关闭，或刺、长度不合）、封迟（等满毫秒）、封残（卷里不足一封）、籍坏、种异、版异、身异（带来身、本身）、栏误（带栏名）、块坏（不是完整的迁移块）；「迁封误述」写成一句话，执拒的述就是它。

后续版本事项：要用指数才写得下的小数（绝对值极大或极小）与非数、无穷的写出；写出结果经源码排版排成 160 列。
