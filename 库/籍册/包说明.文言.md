# 数据文件

读书数据子语言 `名。数据。豫`（[提案〇〇〇二八](../../提案/00028-数据子语言.汉语.md)）。数据之文，其顶惟置 `「名」者 值 也。`；值为字面（串、整数、小数、爻）、`「列」【…】`、`「典」【…】`、组值 `「组值」【「字段」者 值 也，…】` 与构造之书 `「头」【「字段」者 值 也，…】`。

记之字段可取列：`「头」【「字段」者「列」【…】也】`。列中之物可为构造之书之记或组值，列又可为列之列（议四一八）。组值读为首名「组值」之记，字段依名取，书时仍归 `「组值」【…】` 之构造之书。

## 读

节点之类取章句（语法与排版）之式类（表达式类别），惟予定名；节之内容皆入百五十字内之源文或述摘。

- 「析数据文」于「文件名」为…于「内容」为…：惟析其词与语法（编译器核心），得「数据根」——顶之（名，值）列，依书之序。导入与签名略之。
- 「读籍册」于 径：读其文而析之。析之误书卷、行、列：`卷:行:列：` 接其故与短述（其类及百许字之原文），全串不逾五百字；不得源位则书其故与截短之节述（题“无源文”）。
- 「数据值」：数据空、数据爻、数据整数、数据小数、数据字符串、数据符号、数据列、数据记录（首名与字段之列）、数据帛（帛也，惟籍帛用之）。`「典」【…】` 读为首名「典」之记；`「组值」【…】` 读为首名「组值」之记。
- 「数据取」于 根 于 名：依名取值，记之字段亦以之取。「数据诸列项」「数据录诸栏」「数据值文字」取列项、字段与值之文。
- 「数据表诸行」于「根」为…于「表名」为…于「字段名们」为…：读顶名下之记列为行（每行依字段名取其文，阙者为空串）。

## 书

- 「写数据文」于 根：顶之诸定义间空一行；标量书于一行，列与记每项占一行，以全角之空缩进。小数书为小数字面（若「零点八五」「一点零」「负二点五」）：先依六位定点书之，去末之零（至少留一位），读回与原数之差不逾万亿分之一则用此短书，否则用十七位有效之精书。
- 「述数据值」于 值：以一值书为一行数据子语言之文，列与记亦在同一行，项与栏之间用逗；供清单与日志逐行而书，以「析数据文」读还。整篇书之仍用「写数据文」。
- 「写籍册」于 径 于 根。
- 「数据表」于「头名」为…于「字段名们」为…于「整数字段们」为…于「行们」为…：书行为记列，「整数字段们」中之字段书为整数。

串中之 `』`、`「：`、换行与制表，书为转义 `「：』：」`、`「：「：：」`、`「：换行：」`、`「：制表：」`。整数逐位书为汉字，负者首字书「负」，如「九三六三四五六」「负二」。

## 籍帛：二进制之编

程序相遗以二进制：一消息之正，为数据根之籍帛（[提案〇〇〇五一](../../提案/00051-程序间二进制通信.汉语.md)）。「编籍帛」于 根，以数据根为帛；「解籍帛」于 帛，以帛还数据根，还为「籍帛解果」：「解成」载根，「解误」载辞。截断、类号不认、长越其幅、变长之数逾十字者，皆还解误。

每值先标一字节之类号：

| 类号 | 值 | 后接 |
| --- | --- | --- |
| 0 | 数据空 | 无 |
| 1 | 数据爻，阴 | 无 |
| 2 | 数据爻，阳 | 无 |
| 3 | 数据整数 | 之字形变长之数：非负 n 书 2n，负 n 书 −2n−1；七位一组、低者居前，末组之外最高位置一，多不过十格 |
| 4 | 数据小数 | 八字节，「小数作位」所得之位型，低者居前 |
| 5 | 数据字符串 | 变长整数书 UTF-8 字节数，次接其字节 |
| 6 | 数据符号 | 同数据字符串 |
| 7 | 数据列 | 变长整数书项数，次接诸项 |
| 8 | 数据记录 | 记名（变长整数之字节数加 UTF-8）、变长整数书栏数，次接诸栏（栏名加值） |
| 9 | 数据帛 | 变长整数书字节数，次接原样字节 |

数据根书为：变长整数书栏数，次接诸栏（栏名加值）。

「编籍帛」先量总字节数，「置牍」一次，再巡而按下标书之，终以「牍作帛」誊为帛；「解籍帛」按位而读，不复制整幅。

## 数据帛

「数据帛」者，第九种数据值也，藏一「帛」，惟见于籍帛，以原样传文件与二进制之物。「写数据文」遇之，惟书占位 `「帛」于「字节数」`（如 `「帛」于「三零零零」`，谓三千字节），供日志之观；「析数据文」不读还之。

## 封

- 「封刺」于「元」：八字节之刺，取籍帛两字之八位同文，加版次一、零一。门初启，两方各投一次；收者头八字节不合则掩门。
- 一封之式：八字节小端无号之长（低端居首），后接其帛。长逾「封长上限」（一太字节）者作坏封。「封长帛」于 长：书其长为八字节。
- 「置封积」于「元」：一条连接一份之收方状，匣盛「封积录」：待刺（犹候彼刺）、零散（前读之余帛）、知长、封长、体（依长所置之牍）、已填。
- 「拆封」于「连」于「积」：不候而取一封，还「拆封果」：整封（携帛）、未整、门绝。先凑积中之字节，足则径还，不读连接；不足乃听一次：收体时至多读尚欠之数与十六兆取小者，未收体则读六五五三六字节。余字节留积，下次先取。
- 「投刺」于「连」：尽书其刺。
- 「投封」于「连」为…于「片」为…于「余次」为…：先书八字节之长，次书其帛，二者分书；未尽则候隙而续（每次至一秒，数尽则阴），还爻。
- 「候封」于「连」为…于「积」为…于「毫秒」为…：候一封，至整封、门绝或满所限之毫秒；满则未整，还拆封果。
- 「成封帛」于「片」为…：以一段帛并刺与长缀为一帛（八字之刺、八字之长、帛），与连接上先投刺后投封之字一一相同；存卷用之，一卷存一封。
- 「帛作封积」于 帛：以既有之全帛为零散，置一待刺之封积，授凑封以次取封而不读连接；卷之读还者如是拆之。「置封积」即零散为空帛者。
- 封中装帛：送者先编为籍帛（数据之二进制编码）而后投封，收者拆封得帛而后解籍帛；封惟司其短长，帛中之物解者之事。

## 迁封

役迁（提案 00073 第四期四之三）于程间往来之书，同虚机之二役、二虚机、二机之间皆用之；一书一封，封中为数据根之籍帛。

- 迁封（发者致收者）：栏种（符号迁块）、版（「迁封版次」，今为二）、身（发者程之码身纹，字串）、块（数据帛，豫章迁块之帛原样）。「编迁封」于「块」为…于「身」为…编之，「解迁封」于「体」为…于「本身」为…解之，答「成否」：成携迁块（先核身栏与本身同，乃核块栏之帛经「帛作迁块」为全迁块），误携「迁封误」。连接与存卷之身皆取豫章迁移之「本码身纹」（东道原语四百二十二码身纹：务四百一十三所答共码之摘书为六十四小写十六进之字；执行器与程合编为一份共码，链异、程异则码身皆异；机外答六十四“0”）。
- 迁执（收者复发者）：栏种（符号迁执）、版、果（符号：迁入成、拒入、入败、漏段、拒收），迁入成并携号（收端新协程之号），拒入并携答（「拒迁答」，同出磐石迁约），拒收并携述（收者未得迁封之由）。编解之单位为「迁执果」：「执入」携豫章之「迁入果」，「执拒」携述。「编迁执」于「果」为…编之，「解迁执」于「体」为…解还之；「迁执果名」「迁执果述」予其名与一言。
- 行于连接：发者既连，「投刺」、「投迁封」、「候迁执」，得迁执乃闭连；收者迎连，「投刺」、「候迁封」，得之则「协程迁入」、「投迁执」复执入，不得则先复一执拒乃告误。「候迁封」「候迁执」于「连」为…于「积」为…于「毫秒」为…候一封而解之。
- 存于卷：「迁封成卷」于「块」为…缀一封迁封（刺、长、籍帛）为一段帛以书卷；「卷作迁封」于「卷帛」为…自所读之全帛取还迁块。卷无复书，卷书毕则发者自弃其源。
- 源端可回：发者以豫章迁移之「协程迁出扣」先扣源协程乃出之，源之去留由迁执定。「迁源判」于「执」为…以「候迁执」之果尽鉴为「迁源定」：执入迁入成则「定弃」（携新号），执入拒入、入败、漏段与执拒则「定放」（携「迁回因」：对端拒入、对端入败、对端漏段、对端拒收），不得或不可解则「定悬」（携迁封误：彼收否不可知，源仍扣之，免两端各行一份或一份亦无）。「迁源收」于「源号」为…于「执」为…依判呼差遣「迁源弃」或「迁源放」，答「迁源果」（源已弃、源已放、源悬、源态误）；「迁回因述」「迁源定述」「迁源果述」予一言。
- 「迁封误」：封绝（连闭，或刺、长不合）、封迟（候满毫秒）、封残（卷中不足一封）、籍坏、种异、版异、身异（携来身、本身）、栏误（携栏名）、块坏（非全迁块）；「迁封误述」书为一言，执拒之述即此。

后续之事：须以指数方书之小数（极大极小者）与非数、无穷之书；书之所得经源码排版排为百六十列。
