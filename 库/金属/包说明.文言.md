# 金属

此乃苹果金属（Metal）之算之豫言封装，以供他日张量之金属后端。金属之口皆 Objective-C 之消息：此库由 `库/系统库调用` 调 Objective-C 运行时（libobjc 之 `objc_getClass`、`sel_registerName`、`objc_msgSend`），诸理皆书于豫言，诺节宿主惟供通用之系统库调用原语。

此库无核之源。金属着色语言（MSL）属 C++ 之系，手书之 MSL 不入库；他日之核由着色语言译为 MSL，乃付 `「编译金属源码」`。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，依标准库与系统库调用，登于「共用库」之下。

## 所须

苹果之系统、arm64，宿主能调系统库（工具宿主自开；应用宿主须予 `--允许系统库调用`，见 `豫言操作系统/宿主/节点/说明.文言.md`）。`「金属可用」` 为阴，则勿调余函。

## 模

| 模 | 所含 |
| --- | --- |
| `消息` | Objective-C 运行时：取类、取选择子（`「惰取选择子」` 以顶层之引格存之）、依参数之数发消息、自动释放之池、留释对象、文与 NSString 相转 |
| `金属` | 默认之器、命令之队、以 MSL 源编函库、算之管线、共享之缓与零抄之缓、命令之缓、算之编码器、设缓设字、派、交与候 |

## 用法

```yuyan
寻观「金属」之书。
```

- 器：`「金属可用」`、`「取默认金属设备」`（MTLCreateSystemDefaultDevice，惟取一次）、`「金属设备名」`、`「金属设备统一内存」`。
- 编：`「编译金属源码」于 器 于 源` 得「金属已编译」或「金属编译失败」（附编者之误述）；`「新建金属管线」于 器 于 函库 于 函名` 得「金属管线已建」或「金属管线失败」；`「管线每组最多线程」`、`「管线执行宽度」`。
- 缓：`「新建金属缓冲」于 器 于 字数`（共享之存，CPU 与 GPU 共一存，`「金属缓冲地址」` 可以系统库调用之存函径读写）；`「包裹原生内存为金属缓冲」于 器 于 址 于 字数` 零抄而裹页齐之原生之存（址不齐则可无），缓未释，其存不可释。张量之存（诺节宿主之 SharedArrayBuffer）页齐，可零抄。
- 器之家族：`「金属设备支持家族」于 器 于 家族之号` 问器属某 GPU 家族否（supportsFamily:），若一零一零为 MTLGPUFamilyApple10（M5、A19 以后，其 GPU 带行张量之算之神经加速器）。
- 常驻之集：`「新建金属常驻集」于 器` 新建空之常驻集（MTLResidencySet，macOS 十五以来），得其物号，无其类或金属拒之则零；`「常驻集加入」于 集 于 物` 纳一分配（若缓之物）于集，交而请其常驻；`「队列加常驻集」于 队 于 集` 系集于命令之队。集中之分配既请常驻，恒钉于内存，系统不换出亦不压之。常驻集不释（待办事项）。
- 命令：`「新建金属队列」`；`「新建金属命令」`、`「新建无保留金属命令」`（commandBufferWithUnretainedReferences：不留所系之缓，召者须保其存至令毕）、`「新建计算编码器」`、`「设计算管线」`、`「设金属缓冲」`、`「设金属字节」`（不逾四千零九十六字）、`「设三十二位整数参」`、`「设单精度参」`、`「按线程组派发」`、`「按线程派发」`、`「结束编码」`、`「提交金属命令」`、`「等待金属命令」`、`「金属命令状态」`（四为已毕）、`「金属命令错误」`。
- 命令之缓、编码器与误物皆自动释放：每派裹于 `「在自动释放池中」授以 类 于（会「无」而 …）` 之中，否则恒泄。`新建`、`编译` 所得之物归用者，用毕调所当之 `「释放金属…」`。

## 实测（二〇二六年九月三十日，Apple M5 Pro，诺节 26.3.0，工具宿主）

于草稿之目以手书之 MSL 小核验全链：加倍之核、零抄之缓上之加倍、64×64 单精之矩阵乘（四千零九十六元皆对）。往返之时（交而同步候之，二百次之均；时本机负甚重，数偏大而有动）：

| 项 | 往返 |
| --- | --- |
| 空命令之缓 | 六十六至八十九微秒 |
| 一线之空派 | 二百四十四至三百一十四微秒 |
| 64×64 矩阵乘 | 二百九十至三百五十四微秒 |
| 一 Objective-C 之消息（宿主调之费） | 约二微秒 |

径以诺节书同派，空派约二百六十五至三百三十五微秒，故时多耗于 GPU 之侧，豫言与宿主之费（一派约二十越宿主）仅居其小。

## 限

待办事项：惟支 arm64（MTLSize 等逾十六字之结构传指副本之址，x86-64 按值压栈，未支）；毕事之回调未支，一以同步候之；核之试俟着色语言能译 MSL 乃补。

### 深度学习并发计算

为深度学习推理之速，予「新建并发计算编码器」与「计算缓冲屏障」。前者依MTLDispatchTypeConcurrent造编码器，后者以MTLBarrierScopeBuffers序障前后之存缓访问。召者须核存储读写之所待，有所待则设障；交、候与对象存亡仍依原命令之法。
