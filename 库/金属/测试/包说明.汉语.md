# 金属测试

金属库的单元测试（`X。测试。豫`），不含内核源码：

- `设备。测试`：默认设备与名字、命令队列；共享缓冲的内容地址可直接读写；页对齐的原生内存零拷贝包成缓冲，缓冲地址即原地址，未对齐的地址得可无；空命令缓冲与只含空计算编码器的命令缓冲提交、等待后状态为已完成且没有错误；非法源码编译失败并带错误描述。没有金属（在苹果以外的系统上，或宿主不能调用系统库）时只打印“跳过”。

待办事项：着色语言能翻译成 MSL 后，补内核测试（编译、建管线、派发、读回数值、矩阵乘）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试、系统库调用与金属。测试包依赖被测库，所以登记在「共用库」之下。

## 使用

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属测试 设备。测试 --输出 yy金属设备测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属设备测试.wasm
```

输出末行的“当前失败数”应为 0。
