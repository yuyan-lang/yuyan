# 金属测试

金属库之单元之试（`X。测试。豫`），无核之源：

- `设备。测试`：默认之器与其名、命令之队；共享之缓所容之址可径读写；页齐之原生之存零抄裹为缓，缓址即原址，不齐之址则可无；空命令之缓与惟含空编码器之缓，交而候之，态为已毕而无误；非法之源编之而败，附误述。无金属（苹果以外之系统，或宿主不能调系统库）则惟书“跳过”。

待办事项：着色语言能译 MSL 之后，补核之试（编、建管线、派、读回数值、矩阵乘）。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟供试，依标准库、单元测试、系统库调用与金属。试包依所试之库，故登于「共用库」之下。

## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属测试 设备。测试 --输出 yy金属设备测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属设备测试.wasm
```

出之末行“当前失败数”当为零。
