# 琴谱

琴谱是音乐播放的曲单、播放状态与壳命令做法库，供图形程序「知音」与壳命令共用。

## 曲单

- 所开后缀：mp3、flac、wav、aiff、aif、ogg、opus，大写小写都认。
- 给文件：曲单只有这一首。给目录：收目录下所开后缀的普通文件，去掉 `.` 与 `..`，按文件名排序。
- 「奏」遇到已在当前曲单中的文件时只改当前序号，不重建曲单。

## 播放状态

状态文件是用户主目录下的 `豫言乐曲播放状态。数据。豫`，按数据子语言写：

```yuyan
「乐曲播放状态」者
　「乐曲播放状态」
　【「曲单」者「列」
　　【『/桌面/乐/甲.flac』
　　，『/桌面/乐/乙.mp3』
　　】也
　，「当前」者「一」也
　，「播放中」者「阳」也
　，「起秒」者「四二」也
　，「起播时刻」者「一七六零九七六零零零」也
　，「音量」者「八零」也
　】
也。
```

- 曲单：路径列。
- 当前：当前序号，从零起。
- 播放中：阳为播放，阴为暂停。
- 起秒：从第几秒起。
- 起播时刻：开始播放的墙钟时刻，纪元秒。
- 音量：零到一百。

状态文件先写草稿再改名；读不成时取初始状态（空曲单、暂停、音量八十）。

## 纯状态变换

「歇态」「续态」「次态」「前态」「移态」「量态」「选态」只由旧状态得新状态，不读写文件、不看墙钟，时间由调用方传入；「规整状态」把序号、起秒与音量收进合法范围。测试只测这些。

## 壳命令

| 命令 | 参数 | 做法 |
|---|---|---|
| `「奏」于「曲」曰…` | 文件或目录 | 收曲单，从零秒开始播放 |
| `「歇奏」` | 无 | 暂停，记下当前整秒 |
| `「续奏」` | 无 | 从记下的秒数接着播 |
| `「次曲」` | 无 | 下一首；末首不动 |
| `「前曲」` | 无 | 上一首；首曲不动 |
| `「移奏」于「秒」曰…` | 整数秒 | 跳到该秒，不小于零 |
| `「奏量」于「量」曰…` | 零到一百 | 改音量 |
| `「奏态」` | 无 | 印曲名、进度、状态与音量 |

「奏」写好状态后，桌面在运行且知音没开时，经 `库/几席/壳索。豫` 的「索辟窗」请桌面打开知音。知音开着时在用户主目录写 `豫言知音。行` 标记，「奏」据此不重复开窗。

## 知音

图形程序「知音」（`豫言操作系统/应用/知音`）每轮读状态，用声律把当前曲解成十六位交错样本，经声音输出接口写出；进度以已播帧数为准，曲终自动下一首，整单放完停在末尾。界面的每个按钮直接调用本包的同一批函数。

## 待办事项

- 同一首曲在两个知音窗口同时打开时的互斥。
- 音量以新块生效，已排进队列的旧块保持原音量。
- 曲目时长不在状态里，壳命令「奏态」只印当前进度。
