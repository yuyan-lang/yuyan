# 琴谱

琴谱者，鼓琴之谱也。曲有先后，声有起止；此包收曲单、播放之状与壳命之法，供知音与壳共用。

## 曲单

- 所开之尾：mp3、flac、wav、aiff、aif、ogg、opus，大小写皆认。
- 与文则曲单惟此一首。与目则收目下所开之尾之常卷，去 `.` 与 `..`，依文名而排。
- 「奏」遇已在今曲单之文，惟改今序，不复造曲单。

## 播放之状

状文在家主之 `豫言乐曲播放状态。数据。豫`，依数据子语言书之：

```yuyan
「乐曲播放状态」者
　「乐曲播放状态」
　【「曲单」者「列」
　　【『/桌面/乐/甲.flac』
　　，『/桌面/乐/乙.mp3』
　　】也
　，「当前」者「一」也
　，「播放中」者「阳」也
　，「起秒」者「四二」也
　，「起播时刻」者「一七六零九七六零零零」也
　，「音量」者「八零」也
　】
也。
```

- 曲单：径之列。
- 当前：今序，自零起。
- 播放中：阳为播，阴为停。
- 起秒：起于第几秒。
- 起播时刻：起播之墙钟，纪元之秒。
- 音量：零至百。

状文先草后名；读不成则取初状（空曲单、暂停、音量八十）。

## 纯状之变

「歇态」「续态」「次态」「前态」「移态」「量态」「选态」惟由旧状得新状，不读写文、不问墙钟，时由客传；「规整状态」收序、起秒与音量于正。试惟测此。

## 壳命

| 命 | 参 | 法 |
|---|---|---|
| `「奏」于「曲」曰…` | 文或目 | 收曲单，自零秒始播 |
| `「歇奏」` | 无 | 暂停，记今之整秒 |
| `「续奏」` | 无 | 自所记之秒接播 |
| `「次曲」` | 无 | 次曲；末曲不动 |
| `「前曲」` | 无 | 前曲；首曲不动 |
| `「移奏」于「秒」曰…` | 整秒 | 跳至该秒，不小于零 |
| `「奏量」于「量」曰…` | 零至百 | 改音量 |
| `「奏态」` | 无 | 印曲名、进度、状与音量 |

「奏」书状之后，桌面行而知音未开，经 `库/几席/壳索。豫` 之「索辟窗」请桌面开知音。知音开时于家主书 `豫言知音。行` 之标，「奏」据此不复开窗。

## 知音

图形程序「知音」（`豫言操作系统/应用/知音`）每轮读状，以声律解今曲为十六位交错之样，经声音输出接口书之；进度以已播之帧为准，曲终自次，整单毕则止于末。界面诸钮径呼此包同批之函。

## 待办

- 二知音同开一曲时之互斥。
- 音量以新块生效，已入列之旧块守旧量。
- 曲之长短不在状中，壳命「奏态」惟印今之进度。
