# 双语注释样本

这是双语注释排版的输入与期望输出。每组样本由两份同名文件组成：`输入/名.文本` 是待排源码，`标准/名。豫` 是按 100 显示格排版后的逐字节期望输出。输入用 `.文本` 扩展名，包构建不把它当作模块，排乱的写法得以保存。

[双语注释样本测试](../双语注释样本。测试。豫)逐一排版输入，结果须与同名标准文件相同；标准文件再次排版也须保持不变。测试从仓库根目录运行，先用 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 文件 库/源码排版/测试/双语注释样本。测试。豫 --输出 /tmp/yy双语注释样本测试.wasm` 构建，再用同一宿主运行产物。

## 规则

### 识别

- 语种标记有三种：`汉语：`、`文言：`、`赋曰：`，冒号为全角。
- 标记只在分界处生效：注释开头，换行之后，或句末标点 `。`、`！`、`？`、`；` 之后；中间可以隔着空白。句中出现的同样文字（如“现代汉语：”“所谓汉语：”）按正文处理。
- 内层注释 `「：…：」` 里的标记按正文处理。
- 注释去掉开头空白后以标记开头，并且至少含两个标记，才按双语注释排版。其余注释原样保留，包括单语注释、只有一个标记的注释，以及标记之前另有前言的注释。

### 去格式

- 每段从标记开始，到下一个标记或注释结尾为止。
- 删去段首段尾的空白（空格、制表符、换行）。段内每处换行连同其前后的空白一并删去，空行也删去；断行两侧都是 ASCII 字符时补一个空格。
- 行内空白原样保留，包括连续空格。内层注释的文字原样保留，其中的换行按同一规则合并。

### 排序

- 各段按汉语、文言、赋曰的次序排列；同一种标记出现多次时保持原来的相对次序。

### 版式

- 每段一行：`「：` 后面直接接第一段，其余各段另起一行，`：」` 紧贴在最后一段之后。两种语言占两行，带赋曰占三行。
- 独立成行的注释：续行都用注释开头的缩进。
- 代码行尾的注释：`「：` 与第一段留在代码之后，与代码隔一个空格；续行用该代码行的缩进。
- 一段即使超出行宽也保持一行，排版器只按语种分行。

## 样本一览

| 样本 | 覆盖 |
| --- | --- |
| [单行拆分](标准/单行拆分。豫) | 单行的两语、三语注释；`；`、`？`、`！` 后的标记；句号与标记之间的空格 |
| [语序归一](标准/语序归一。豫) | 文言在前、汉语在后、赋曰在前三种次序归为汉语、文言、赋曰 |
| [旧排版去格式](标准/旧排版去格式。豫) | `「：`、`：」` 各占一行的旧式；注释开头缩进而正文顶格；段间空行与行尾空白；标记行缩进与冒号后空格；注释开头之后与结尾之前的空白 |
| [段内续行合并](标准/段内续行合并。豫) | 中文续行直接相接，ASCII 与 ASCII 之间补空格，中西之间直接相接，赋曰两联合并 |
| [缩进随代码](标准/缩进随代码。豫) | 构造器后缩进四格的注释、函数体内、分支括号内、分支正文前的注释 |
| [行尾双语注释](标准/行尾双语注释。豫) | 顶层声明行尾与类型续行行尾的双语注释 |
| [非双语注释不变](标准/非双语注释不变。豫) | 单语多行注释、只有一个标记、带前言、“现代汉语：”、句中的“汉语：”、行尾单语注释，输入与标准相同 |
| [内层注释](标准/内层注释。豫) | 内层注释中的标记、跨行的内层注释 |
| [超宽不折行](标准/超宽不折行。豫) | 超过 100 显示格的一段保持一行 |

[规范样本](../规范样本/测试说明.汉语.md)中的双语注释也已写成上述版式，由规范样本测试核对幂等及空白扰动。
