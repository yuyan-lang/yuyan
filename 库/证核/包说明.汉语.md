# 证核（证明内核）

核形（核心项定义）模块在 `核形。豫` 统一声明「核项」类型，证明项与实际定义共用它。模块名与类型名分别命名。绑定变量采用从零起的德氏下标；全局名保存模块身份与名称。标签、类型参数、零次证据和可选类型标注分别保存。

默认导入核形、读卷（证明项解析器）、述项（项打印器）与证核（证明核验入口）。`读证明项` 接收实际定义声明列、含文件名与模块身份的源码、依赖证明声明列，返回声明列的成否。`读实际定义` 为测试把实现层源码读成相同的声明列。`述核项` 与 `述核卷` 分别打印闭合项与声明列。

`读证明文` 供证场（证明细化器）读取表层证明，参数与 `读证明项` 相同。本定义的自引保存为本模块的同名全局项，交证场译成归纳；证明项读取入口继续检查自引限制。底层「卷读全」入口另接自引位置回调，证场据此保存诊断源位。未知名字在表层模式中附互递归暂待的诊断。勘验、归纳与运项现有公开函数供证场复用，推断函数的导出保持现状。

模式绑定按先序进入环境，最后绑定的变量占零号。源位置的行列从一开始，列按字符计数。打印器按绑定深度生成「束零」等名字，保留全局模块身份，以括号确定复合项的分组。

共享项的绑定约定如下，供译场（编译器核心）前端直接构造实际定义：

- 「核函」的可选标注与「核箭」的定义域在外层解释，体在增加一个绑定的环境里解释。
- 「核令」的值在外层解释，体增加一个绑定。
- 「核复令」的签名在外层解释，值与体都增加递归绑定；值须为函数。
- 「核鉴」的各支分别按模式先序增加绑定，子模式从左到右进入环境，最后绑定的变量下标为零。
- 「核类施」与「核施」分别保留类型施用和值施用。类型标注、绑定提示名和次数分别存放。
- 「核立名」逐条保存类型及构造器的完整签名，类型参数由「核箭」表示；抽象标志由调用方给出，文本读法置为阴。
- 「核全名」的模块字段是调用方给定的稳定身份，名称字段是篇内名字。两栏共同决定身份。

名字依次查本卷先前定义、证核内建、实际定义境、依赖证明。同层的歧义报告全部候选。限定名同样核对环境；本术（编译器原语）限定名统一记为 `豫章/本原/本术` 的身份。本期读法登记本加、本乘、本除、本取余，内建函数的完整名称按豫章源码保留；告祸（抛出异常）的包装与本告祸定义照源码一起读入。

读入的绑定和施用保存「核未定次」，供第二段勘验（类型检查器）依类型核定为零次或多次。求值与擦除的入口须先拒绝未定次。显式子集型引入写成 `「择证」于 目标类型 于 值 于 证据`，核心构造「核择证」依次保存这三项，最后一项为零次位置。

| 读法 | 保存方式 |
| --- | --- |
| `「名」乃 类型 者也。` | 签名声明 |
| `「名」者 项 也。`、`「名」即 项 也。` | 定义、类型别名 |
| `「名」立 T 者也。` | 类型与构造器的立声明，签名仍为核心项 |
| `设…而`、`得…而`、`又得`、`得「签」曰「名」` | 类型绑定、值绑定、标签与可选标注 |
| `凡…而`、`化…又化…为…`、`化「名」属 A 为 B` | 任意定义域的依值函数类型 |
| `于`、`于「签」曰`、`以`、`又以` | 值施用、标签实参、类型施用 |
| `令…为…而…`、`复令…属…即…而…` | 普通与递归局部绑定；递归值须为函数字面 |
| `鉴…而 或有…则…` | 嵌套构造器、`得「名」`、通配、字面和组模式 |
| `若…则…否则…`、`且`、`或` | 条件项；且比或紧，两者右结合 |
| 加、减、乘、大于、小于、等于、不等于、除以、取余 | 算较中缀；彼此及与施用混写时加括号 |
| `「零」`、`「负一」`、`「二五六」`、`『串』` | 六十四位数字字面、四种转义的字符串 |
| `「组值」【…】`、`「组类」【…】`、`中「零」` | 非依值组、组类与静态下标投影 |
| `「列」【…】`、`「帛」【「零」，「二五五」】` | 列展开为罄与缀；帛逐字节存放 |
| `「：…：」` | 跳过注释，来源摘要留给后续核对 |

算符关系据雅言（源语言文法）的 `雅言符集。豫` 在本包单独实现。待办事项：与编译器共用同一份算符声明。

读写测试在 `测试/读写。测试。豫`，从仓库根按相对路径读取列算实际定义文、次第归纳规则与列算完整证明项，核对再次解析后的规范打印文本。运行冒烟待验。

## 核验入口与计算

`核证明` 依次接收标签「实定」的核心声明列、含文件及模块身份的「核卷文」、标签「依证」的已核「核报告」列，返回报告或文字错误的成否。依赖直接携带先前成功报告，可信基随依赖传递；含待证定义的报告须先补齐证明。报告保存定义状态、可信基、已核声明与可引用的证明名字。定义状态分别为已证、待证与假设；任一子项里的「假」都归入可信基。

精化签名按名字配到实际定义，且本卷同名定义为显式「假」或仅给签名时，由实际全名推出「名之隶」。显式假设同时给出对应成员规则。成员证明的显式签名与推出的目标换名核对，缺失成员证明带名报错。

运项（核心项操作）集中处理带绑定的映射、德氏下标移动、同时替换与擦除。模式的多个绑定同时替换时，实参先提升到剩余绑定层数，逐个消去绑定。核形的公开类型与绑定约定沿用第一段。

原术（原语表）以完整身份识别本术和编译器内建，保存参数、结果与全性。加减乘用六十四位补码回绕；除余向零截断；除零和极小整数除负一中止；极小整数余负一得零。文长按八位同文字节计，帛按从零起的下标读取并检查边界。爻运算依源码的函数定义与条件项展开。

推演（符号求值器）的结果为值、中性、抛出、中止与步数超限，定义展开、绑定消去、分支选择和原语计算共用一千万步预算。`推演` 的第三个参数可指定预算。变量代表闭合值；线性求值语境另查恰用一次、求值位置与全的前缀。条件事实随新增绑定提升，在爻分的两支分别固定条件。

勘验（双向类型检查器）依目标检查函数，依函数类型检查施用；命题与幽参数标为零次，计算位置逐次核对局部变量的次数。隐式类型实参从紧接的实参类型作局部一阶匹配，补不出时要求用「以」写明。证据用显式「于」给出，代入与归纳的所证写全。全性采用保守检查，未知调用按可抛处理。

归纳（归纳规则生成器）检查函数域、可变容器和抽象参数的负位置，并检查嵌套类型自己的参数。内建列的签名和计算规则独立生成；普通立类型按构造器与递归字段同时生成签名、分支和计算体。照抄的两种规则逐字核对，绑定名归一后比较。鉴分支检查完整覆盖；当前嵌套分割可用完整构造器支或通配支覆盖。

`测试/核验。测试。豫` 读取列算、安读和次第全证三组必收样例；次第全证将原来的递归证法改为列归纳，并写全变化累积参数的所证与代入。必拒样例逐条检查关键字，另核整数边界与循环预算。全部测试运行待验。
