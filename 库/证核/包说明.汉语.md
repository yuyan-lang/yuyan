# 证核（证明内核）

核形（核心项定义）模块在 `核形。豫` 统一声明「核项」类型，证明项与实际定义共用它。模块名与类型名分别命名。绑定变量采用从零起的德氏下标；全局名保存模块身份与名称。标签、类型参数、零次证据和可选类型标注分别保存。

默认导入核形、读卷（证明项解析器）、述项（项打印器）。`读证明项` 接收实际定义声明列、含文件名与模块身份的源码、依赖证明声明列，返回声明列的成否。`读实际定义` 为测试把实现层源码读成相同的声明列。`述核项` 与 `述核卷` 分别打印闭合项与声明列。

模式绑定按先序进入环境，最后绑定的变量占零号。源位置的行列从一开始，列按字符计数。打印器按绑定深度生成「束零」等名字，保留全局模块身份，以括号确定复合项的分组。

共享项的绑定约定如下，供译场（编译器核心）前端直接构造实际定义：

- 「核函」的可选标注与「核箭」的定义域在外层解释，体在增加一个绑定的环境里解释。
- 「核令」的值在外层解释，体增加一个绑定。
- 「核复令」的签名在外层解释，值与体都增加递归绑定；值须为函数。
- 「核鉴」的各支分别按模式先序增加绑定，子模式从左到右进入环境，最后绑定的变量下标为零。
- 「核类施」与「核施」分别保留类型施用和值施用。类型标注、绑定提示名和次数分别存放。
- 「核立名」逐条保存类型及构造器的完整签名，类型参数由「核箭」表示；抽象标志由调用方给出，文本读法置为阴。
- 「核全名」的模块字段是调用方给定的稳定身份，名称字段是篇内名字。两栏共同决定身份。

名字依次查本卷先前定义、证核内建、实际定义境、依赖证明。同层的歧义报告全部候选。限定名同样核对环境；本术（编译器原语）限定名统一记为 `豫章/本原/本术` 的身份。本期读法登记本加、本乘、本除、本取余，内建函数的完整名称按豫章源码保留；告祸（抛出异常）的包装与本告祸定义照源码一起读入。

读入的绑定和施用保存「核未定次」，供第二段勘验（类型检查器）依类型核定为零次或多次。求值与擦除的入口须先拒绝未定次。显式子集型引入写成 `「择证」于 目标类型 于 值 于 证据`，核心构造「核择证」依次保存这三项，最后一项为零次位置。

| 读法 | 保存方式 |
| --- | --- |
| `「名」乃 类型 者也。` | 签名声明 |
| `「名」者 项 也。`、`「名」即 项 也。` | 定义、类型别名 |
| `「名」立 T 者也。` | 类型与构造器的立声明，签名仍为核心项 |
| `设…而`、`得…而`、`又得`、`得「签」曰「名」` | 类型绑定、值绑定、标签与可选标注 |
| `凡…而`、`化…又化…为…`、`化「名」属 A 为 B` | 任意定义域的依值函数类型 |
| `于`、`于「签」曰`、`以`、`又以` | 值施用、标签实参、类型施用 |
| `令…为…而…`、`复令…属…即…而…` | 普通与递归局部绑定；递归值须为函数字面 |
| `鉴…而 或有…则…` | 嵌套构造器、`得「名」`、通配、字面和组模式 |
| `若…则…否则…`、`且`、`或` | 条件项；且比或紧，两者右结合 |
| 加、减、乘、大于、小于、等于、不等于、除以、取余 | 算较中缀；彼此及与施用混写时加括号 |
| `「零」`、`「负一」`、`「二五六」`、`『串』` | 六十四位数字字面、四种转义的字符串 |
| `「组值」【…】`、`「组类」【…】`、`中「零」` | 非依值组、组类与静态下标投影 |
| `「列」【…】`、`「帛」【「零」，「二五五」】` | 列展开为罄与缀；帛逐字节存放 |
| `「：…：」` | 跳过注释，来源摘要留给后续核对 |

算符关系据雅言（源语言文法）的 `雅言符集。豫` 在本包单独实现。待办事项：与编译器共用同一份算符声明。

读写测试在 `测试/读写。测试。豫`，从仓库根按相对路径读取列算实际定义文、次第归纳规则与列算完整证明项，核对再次解析后的规范打印文本。运行冒烟待验。
