# 证核（证明内核）

「读证明文」为证场（证明细化器）读表层之门，参同「读证明项」；本定义之自引存为本模块同名全局项，俟证场化为归纳。「读证明项」仍守自引之禁。「卷读全」另受自引源位之回调，证场存之以告失。表层未知名附互递暂待之辞。勘验、归纳、运项之旧有公术供证场复用，推断导出循旧。

核形（核心项定义）之制，统于 `核形。豫`，其中立核项之类；模、类各名，证明与实定同其形。束名以从零之次，全称以篇籍与名字。标签、类参、零次之据、可有之类注，各录其位。

先导核形、读卷（证明项解析器）、述项（项打印器）、证核（证明核验入口）。读证明项，受实定、卷文、依证而归声明之成否；读实际定义，以实文供试；述核项、述核卷，各成闭项、声明之辞。

鉴式束名，依先序入境，末束者居零。源位之行列皆始于一，列以字计。述项随境深而生束零诸名，全称保篇籍，复项皆加括。

译场（编译器核心）前端造实定，依此束制：

- 核函之可有类注、核箭之域，皆在外境；其体增一束。
- 核令之值在外，其体增束。
- 核复令之签在外，其值、其体同入递归之束；值须为函。
- 核鉴之诸支各束其式，子式从左至右，末束居零。
- 核类施、核施分录类参、值参；类注、提示名、次数各存其位。
- 核立名逐条录类与构造之全签，类参以核箭述之；抽象之志由调用者授，读文则置阴。
- 核全名之篇籍由调用者定其恒称，与篇内名字共辨其物。

解名先旧定，次内建，次实境，次依证；歧义尽列候称，限定亦察其籍。本术（编译器原语）归 `豫章/本原/本术`，今录本加、本乘、本除、本取余；内建全称依豫章录之，告祸（抛出异常）之包函与本告祸之定同读其源。

初读之次数记未定，俟勘验（类型检查器）判其零与众；未定者先拒而后求值、擦除。子集之入，显书 `「择证」于 目标类型 于 值 于 证据`；核中先类、次值、次据，末为零次之位。

| 读法 | 所录 |
| --- | --- |
| 乃签、者定、即别、立名 | 各归声明，立之签亦为核项 |
| 设、得、又得、得签曰名 | 束类、束值、标签与可有之注 |
| 凡、化名属域、又化、为 | 任域之依值箭 |
| 于、于签曰、以、又以 | 值参、签参、类参 |
| 令、复令 | 承值与自续，复令之值须为函 |
| 鉴、或有、得名、通配、诸字面与组 | 嵌套之式及支体 |
| 若、且、或 | 阴阳之路；且紧于或，皆右约 |
| 加减乘、大小等较、除余 | 算较之符相混须括，与施用亦然 |
| 汉字逐位之数、负数、书括之串 | 定宽之筹与四种转义 |
| 组值、组类、中零 | 非依值之组及静序投影 |
| 列之方括、帛之字节方括 | 罄缀之列、零至二百五十五之帛 |
| 注释 | 过之，来源摘要俟后核 |

算符之系，依雅言（源语言文法）符集而别立于此。待办事项：与编译器同出一声明。

读写之验在 `测试/读写。测试。豫`，循仓根相对之径，读实卷、归规、全证，述而复析，比较规范之辞。运行之验待行。

## 核验之门与计算之制

核证明之门，先受标签实定之核心声明列，次受核卷文，后受标签依证之已核报告列，归报告或祸辞之成否。依凭承旧报，可信基随之；待证之篇，须补而后依。报告列定义之记、可信之籍、已核之辞与可引之证名。已证、待证、假设各有其栏，子项有假亦录于可信。

精签按名归实；卷中惟签或明书假者，以实定全名称其成员之辞，名加之隶。明假亦生其成员规则。成员有签，则与所推者换名而稽；缺证则明报其名。

运项（核心项操作）总束感之遍历、德氏下标之迁、同时之代与幽据之除。鉴式多束，各值先举至余束之深，而后逐束消之；核形之公类与束制仍旧。

原术（原语表）凭全称而认本术、内建，录参、果与全性。加减乘循六十四位之周；商余向零；法空、极小除负一则止，极小余负一则零。文量八位同文字节，帛循零起之格而察界。爻术依其源函及条件而展。

推演（符号求值器）有值、中性、抛出、中止、筹尽五归。展名、消束、择支、算术共限千万步，入口第三参可别授其筹。变量为闭值；线性语境察其一用、所居与全之前缀。入束则举其事实，爻分两支各定阴阳。

勘验（双向类型检查器）依目标核函，按函签核施。辞、幽之参皆零次，算位逐变量察其用次。隐类惟于近参之类作一阶合一，疑则请以字明书；据显授于字，代入、归纳皆陈其所证。全性从严，未知之呼列于可抛。

归纳（归纳规则生成器）察函域、可变器与抽参之负位，亦察所嵌之型自身之参。内建列之签、体核中自生；普通立型依构列支，递域授假，签体俱铸。卷抄之规，换名后逐字稽同。鉴支须尽，嵌套之分可加全构支或通配以尽其界。

核验之试在 `测试/核验。测试。豫`，收列算、安读、次第全证三卷。次第之递证改以列归纳，变化之积皆纳所证，代入各陈其辞。拒例逐条稽其关键，筹界、环算别察之。诸试运行皆待验。
