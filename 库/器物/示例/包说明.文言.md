# 显示控件示例

[显示控件](../包说明.文言.md)之示例：待办之单。上为题、输入之框与“添加”之钮（回车亦添），中为可滚之单（点方块以勾之，点“删除”以去之，已成者加删除之线而灰，长者以省略号终），下为计与“清除已完成”。制表之键轮换焦点于框与诸钮，钮得焦点则回车、空格即点；滚轮、拖滚条、上下与翻页之键皆可滚其单。

高层布局之言未成，视图之函手算其矩（逻辑之素乘六十四）；文用字体接口之“无衬线”。

## 行之

诺驿（须显示、字体二接口之诺驿实现，及置 SDL 之原生依赖目录）。于仓之根，以豫构发行之节点模式构其发行包，乃以包中之 `启动.mjs` 行之：

```sh
./豫构。林檎。豫行 发行 节点 库/器物/示例 dist/显示控件示例 --包根 库/显示控件 --包根 库/字体
node dist/显示控件示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 为已装 `@kmamal/sdl` 之目（含 `node_modules` 之层），见[诺驿宿主之说](../../../豫言操作系统/宿主/节点/说明.文言.md)。显示之原语惟在发行包之应用宿主；工具链宿主 `宿主.cjs` 惟以行构建之具。自动之验加 `--显示面后台`，窗不夺前台。浏览器以 `豫构 发行 浏览器` 构之，页置 `data-yy-显示面="主窗口"` 之 canvas，并以 `link[data-yy-字体]` 给“无衬线”之字体文件。

macOS 原生（arm64）：不绑适配而径构之，豫构默由编译器并执行器 `执行器。树码` 径出原生之程，见[原生窗口方案](../../../豫言操作系统/文档/原生窗口方案.文言.md)：

```sh
./豫构。林檎。豫行 构建 显示控件示例 --输出 显示控件示例原生 -j 24
./显示控件示例原生 --授权显示面 主窗口=800x600
```
