# 显示控件示例

[显示控件](../包说明.汉语.md)的示例应用：待办清单。顶上是标题、输入框与“添加”按钮（回车也能添加），中间是可滚动的待办列表（点方块勾选，点“删除”删去，完成的项加删除线并变灰，太长的以省略号结尾），底下是统计与“清除已完成”。制表键在输入框与各按钮间轮换焦点，按钮有焦点时回车或空格即点击；滚轮、拖动滚动条、上下键与翻页键滚动列表。

高层布局语言还没有，视图函数里手算矩形（逻辑像素乘 64）；文字用字体接口的“无衬线”。

## 运行

诺驿（需要显示与字体两个接口的诺驿实现，以及放 SDL 的原生依赖目录）。在仓库根目录用豫构发行的节点模式构建发行包，再用发行包里的 `启动.mjs` 运行：

```sh
./yy豫构.exe 发行 节点 库/器物/示例 dist/显示控件示例 --包根 库/显示控件 --包根 库/字体
node dist/显示控件示例/启动.mjs --授权显示面 主窗口=800x600 --原生依赖目录 <目录>
```

`<目录>` 是装了 `@kmamal/sdl` 的目录（含 `node_modules` 的那一层），见[诺驿宿主说明](../../../豫言操作系统/宿主/节点/说明.汉语.md)。显示原语只在发行包的应用宿主里；工具链宿主 `宿主.cjs` 只用来运行构建工具。自动验收时加 `--显示面后台`，窗口不抢前台。浏览器上用 `豫构 发行 浏览器` 构建，页面放一个 `data-yy-显示面="主窗口"` 的 canvas，并用 `link[data-yy-字体]` 给出“无衬线”字体文件。

macOS 原生（arm64）：不绑适配直接构建，豫构默认由编译器连同执行器 `yy执行器。树码` 直出原生程序，见[原生窗口方案](../../../豫言操作系统/文档/原生窗口方案.汉语.md)：

```sh
./yy豫构.exe 构建 显示控件示例 --输出 yy显示控件示例原生 -j 24
./yy显示控件示例原生 --授权显示面 主窗口=800x600
```
