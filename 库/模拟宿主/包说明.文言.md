# 模拟宿主

有 `download` 属性之链，点击则存文件之名及对象网址，可由「模拟下载记录」核之；「模拟重置」清其记。

模拟宿主者，纯豫言所书之“假浏览器并假平台”也：内存之文档物树、事之剧本、虚时钟、可定之随机与虚网。`豫构 发行 模拟` 绑应用所用之豫言操作系统诸接口于 `XXX模拟` 适配，适配与测试共此库之态，故应用之验收全以豫言书之，行于工具宿主（诺节或原生），惟用豫言自有之库。

## 包之身份

所有者：豫言。版本：0.1.0。库也，依标准库、结森工具与网址解析。单段导入 `寻观「模拟宿主」之书。` 展为诸模；公名皆以“模拟”或“结”起，免与应用、测试之名相撞。

## 诸模

| 模 | 所含 |
| --- | --- |
| 文字工具 | 分、去白、大小写、寻；结森造值取值之简书 |
| 断言 | `模拟用例`、`模拟断言`、`模拟断言相等`、`模拟断言等数`、`模拟断言包含`、`模拟断言不含`、`模拟断言依次包含`（犹正则 `/甲.*乙/s`）、`模拟汇报`（有败则退出码一）。断败则记数书因，试续行 |
| 时钟 | 虚墙钟（默 2026-01-01T00:00:00Z，`模拟设置时钟`）、单调之钟、时区之偏（默四百八十分）、期表；Unix 毫秒与 ISO、UTC 日、中文本地时文之换算 |
| 随机 | splitmix64 伪随机，种默 20261010（`模拟设置随机种子`）；十六进制、通用标识 |
| 文树 | 内存文档：节依号存，零号为文档；元素、属性、子、文、控件之值与勾（未改则依属性推之）、类名、扩属性；页址、可见、联机、窄屏、焦点 |
| 超文本 | 简易超文本之析（开闭签、属性、注、实体、空元素、script/style 原文、常见隐闭）与书；`模拟载入页面`、`模拟载入页面文件`（读真页之模）、`模拟设超文本` |
| 选择器 | CSS 选择器之子集；`模拟查询`、`模拟查询全部`、`模拟最近`、`模拟匹配选择器` |

| 剧本 | 测试所书之剧本与行者（见下），及事源（服务器推）之联 |

## 剧本与行

测试先书剧本，后行应用：

```yuyan
「模拟重置」于「元」。
「模拟载入页面文件」于「文件」为『应用/…/首页.html』于「网址」为『https://yuyan-lang.org/…』。
「模拟登记结森」于「方法」为『GET』于「路径」为『/api/甲』于「状态」为「200」于「正文」为『{"ok":true}』。
「模拟点击」于『按钮标识』。
「模拟检查」于（会「无」而「模拟断言相等」于「说明」为『…』于「期望」为『…』于「实际」为（…））。
「模拟运行」于（会「无」而「入口」之「入口」于「元」）。
「模拟汇报」于「元」。
```

剧本之步：`模拟点击`（禁者无应；可聚焦者先得焦点；勾框、单选易勾而派 input、change；提交之钮提交所属表单；链接未见止则记一导航）、`模拟点击选择`、`模拟输入`、`模拟变更`、`模拟组字`、`模拟按键`（单字之键附文于输入框，回车提交表单）、`模拟提交`、`模拟聚焦`、`模拟派发事件`、`模拟发出消息`、`模拟设可见`、`模拟设联机`、`模拟历史移动`、`模拟推进时间`（虚时钟进，途中到期之期依次发，每发令应用先处之）、`模拟推送事件流`、`模拟断开事件流`、`模拟检查`（行断或易页态，如 `模拟设剪贴板拒绝`）、`模拟关闭宿主`。

应用每阻候一事（`等待界面事件`、`等待网页事件`、`等待网页消息`、浏览器宿主之 `等待浏览器事件`），列中无所欲者，行者则依次行剧本之次步；故检步恒在应用处尽前事之后乃行，不须轮候。剧本尽而应用犹候，则抛可捕之事故“模拟结束”，`模拟运行` 视为常终；应用先返则补行余检。网页请求、事源、fetch 皆经虚网同步而成，期惟于 `模拟推进时间` 时至。

一程可有数用例：每例先 `模拟重置`（文树、时钟、随种、网、储、物表、事、剧本皆清，断数存之）。应用自有之模态不在模拟宿主，例间不重置。

## 限

不排版（矩与尺恒零）、不算样式表（`读取节点可见` 惟视 hidden）、事不仿止传与捕获之先后、不并高频之事、不依上限弃事、导航不卸页。此诸情于码中以“待办事项”注之，留待后版。

## 试

`./yy豫构.exe 构建 模拟宿主 测试 模拟宿主。测试 --输出 yy模拟宿主测试.wasm`，复以同宿主行其产物。

受限之页可设 `模拟饼拒绝格`、`模拟历史拒绝格` 为真，饼之读写及浏览器历史之改发权限之误；`模拟重置` 复许之。共界据此验受限文档之辞易。

节之扩 `矩形` 可预置左、上、右、下四项之结森文；`模拟节点矩形` 于未置及非元素之目标取零矩。网页界面模拟之矩读，与界面事之 `带矩形` 载共用其值，可定验气泡之摆与阅读之位。

网页文树模拟依描述造树，以结森爻值设白册之布尔属性。节之扩 `滚动度量` 可预置 `总高` 与 `可视高`，网页界面模拟读之，兼取当前滚动顶值；未置之高为零。阅读应用之显赋气泡与目录滚动之验，共用此能。
