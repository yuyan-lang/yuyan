# 可分（可微增量计算）

「可分」者，分而可导之谓也。凡以本库组合子所成之算，皆守一约：

```
f(a 施变 da) = f(a) 施变 f′(a)(da)
```

## 一、变化结构

凡受支持之值类，各配一「变构」，凡三术：

- 「施变」：以值加增而得新值；
- 「作差」：取两值之差；
- 「无变」：未改之增。

增者，「变」于「甲」也，按值形而分门。「数」之增为数，加减之量也；「文」之增为编辑项之列，于某字位删若干字、插一段也；「列」之增为定位之删、插、改；「簿」之增为键之置与删；「对」之增为两半各进；「自编」者，任意类之补丁一束，兼其规模与说，以待记录与自定之类。

所供者：数、文、列、簿、对、记录（「组变构二」）、集合（以「簿」于「有」表之）之变构，及「自变构」（任意类以补丁表之）。复合之类由部分而合：对用「对变构」，记录用「组变构二」，按字段之变构与读写之术拼成。

## 二、核心类型

「可分结果」于（入，果）者，签名所封之抽象类也：内含当值、推进之术与重算之术。推进受输入之增，改其身而答结果之增；重算按子节点之当值从头算己值，供初建与接续改构之用。

惟经组合子而合：程序不得取节点中之值以为不可导之算；「取值」惟读当值，不复授可再裹之物。

输入经「入源」而共：同一入源之诸节点共读一处当值，「取入」惟读之，推进由「推进」一处统施，免同一增施之再。

## 三、组合子

- 「常值」：常量，输入虽变而不动；
- 「取入」：果即输入，出增即入增；
- 「映导」：再射子节之果；改时客授之导受子节旧果与其果增、答映射之增，缓存以增而更，不重算其射；
- 「映重」：再射子节之果；改则按子节新果尽算，出增由新旧之差而得，正而不省；
- 「并联」：二同入之果合为二元组；
- 「接续」：后一步依前一步之值；前值既变则改建后节，出增取新旧之差；
- 「映列」：列上之增量映射，逐项各有子节点，列有增删改则惟动相关之项；
- 「择列」：按谓词筛列，列改则惟增删谓词有变之项；
- 「映簿」：簿上之增量映射，按键各有子节点；
- 「键连」：按名连二簿，键之增删改惟动相关之项；
- 「归约增」：可交换可结合之归约，每项先以贡得一份，乃以合自左叠之；叶值改则惟算沿路，列有插删则重建全树。
- 「归约重」：同此折叠，每推皆从头算，以为对照与兜底。

## 四、测试

测试在包之 `测试/` 下，凡二篇：

- `可分性质。测试。豫`：以豫章之随机数生随机值与随机增，变构验“作差而施之即还原”，组合子验“出增施于旧果即新果”与“新果等于以新入尽算之所得”，凡十六组。
- `可分辨例。测试。豫`：给一列行，增量守其字数之和与最长行，二途各推同一串增，书其果与账，并与尽算者相较。

## 五、可观测

「账」按组合子之种而记：每推进则记一增与其所理之规模，每重算则记一算；末以「可分账文」按种印之，另于「诏令」有壳命令「析可分」。

## 六、待办事项

- 「归约」之增量路径，叶值改则惟重算沿路诸级；列之插删则改建全树，费与列长相当。
- 「接续」改建后节时以「作差」出出增，其规模或大于实改。
- 记账为进程内之全局表，壳命令惟见本进程所记之账。
