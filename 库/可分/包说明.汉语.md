# 可分（可微增量计算）

「可分」把一段计算包成节点：给输入的增量，答结果的增量，中间状态由节点自带。凡是经本库组合子搭起来的计算都满足

```
f(a 施变 da) = f(a) 施变 f′(a)(da)
```

## 一、变化结构

每个受支持的值类型配一份「变构」（变化结构），三术：

- 「施变」：值加增量得新值；
- 「作差」：两值之差；
- 「无变」：没改动的增量。

增量本身是「变」于「甲」：一个按值形分门的变体。「数」的增量是数（加减量），「文」的增量是编辑项列（在某字位删若干字、插一段），「列」的增量是编辑项列（定位删、插、改），「簿」的增量是键的置与删，「对」（二元组）的增量是两半各进，「自编」是任意类型的一组补丁函数连同规模与说明，供记录与自定类型使用。

各处提供：数、文、列、簿、对、记录（「组变构二」）、集合（以「簿」于「有」表之）的变构，以及「自变构」（任意类型以补丁表之）。组合类型由各部分组合：对用「对变构」，记录用「组变构二」按字段的变构与读写函数拼成。

## 二、核心类型

「可分结果」于（入，果）是签名文件封住的抽象类型：内含当前值、推进函数与重算函数。推进函数收输入的增量，更新自身，答结果的增量；重算函数按子节点的当前值从头算出自己的值，供初建与接续改构时用。

只能经组合子组合：程序拿不到节点里的值去做不可导的计算；「取值」只读当前值，不返回能再包回去的东西。

输入经「入源」共享：同一入源的各节点共读一处当前输入，「取入」只读它，推进由「推进」一处统一施加，免得同一增量施两遍。

## 三、组合子

- 「常值」：常量，输入怎么变都不动；
- 「取入」：结果就是输入本身，输出增量即输入增量；
- 「映导」：把子节点的结果再映射一次；改时调用方给的导函数收子节点的旧结果与它的结果增量、答映射后的增量，缓存按增量更新，不重算函数；
- 「映重」：把子节点的结果再映射一次；改了就按子节点的新结果整体重算，输出增量由新旧的差得出，正确而不省；
- 「并联」：两个同输入的结果合成二元组；
- 「接续」：后一步依赖前一步的值；前一步的值变了就改建后一步的节点，输出增量取新旧之差；
- 「映列」：列上的增量映射，逐项各有子节点，列增删改时只动相关项；
- 「择列」：按谓词筛列，列改时只增删谓词变化的那几项；
- 「映簿」：簿上的增量映射，按键各有子节点；
- 「键连」：按名连接两个簿，键的增删改只动相关项；
- 「归约增」：可交换可结合的归约，每项先经贡献函数得一份，再以结合函数自左叠之；叶值改动只重算沿路各级，列的插删则重建整棵树。
- 「归约重」：同样的折叠，每次推进都从头算，作对照与兜底。

## 四、测试

测试在包的 `测试/` 下，两份：

- `可分性质。测试。豫`：用豫章的随机数生成随机值与随机增量，变构验“作差再施变即还原”，组合子验“结果增量施于旧结果即新结果”与“新结果等于把新输入整体重算所得”，共十六组。
- `可分辨例。测试。豫`：给一列源码行，增量地维护每行字数总和与最长行，两条路（归约增、归约重）各推同一串增量，印出结果与账，并与整体重算对照。

## 五、可观测

「账」按组合子种类记账：每次推进记一次增量推进与所处理的增量规模，每次重算记一次重算，末给「可分账文」把这份账按种类印成文字，另在「诏令」有壳命令「析可分」。

## 六、用法举例

```
令「源」为（「立源」以「数」于「数变构」于「三」）而
令「和计」为（「并联」于「取入」于「映重」…）而
令「出」为（「推进」于「源」于「和计」于（「数差」于「二」））而
…
```

## 七、待办事项

- 「归约」的增量路径对叶值改动只重算沿路各级；列的插删会改建整棵树，代价与列长成正比。
- 「接续」改建后一步时用「作差」出输出增量，规模可能大于真实改动。
- 记账是进程内的全局表，壳命令只看得见本进程记过的账。
