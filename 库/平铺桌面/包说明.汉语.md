# 平铺桌面

平铺桌面是豫言的窗口系统（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一棵分割树把屏幕划成不重叠的矩形，叶子是标签组，标签里是格子程序。终端、文件浏览、任务管理器、设置与外部程序都是格子程序，同一种可以开多个。外壳只管布局与分派，格子程序各自更新；外部程序各在自己的任务里运行。

## 入口

```yuyan
寻观「平铺桌面」之书。
「运行平铺桌面」于「授权根」为『桌面』于「布局」为「浏览终端布局」。
```

「运行平铺桌面」在显示面 `主窗口` 上用自绘后端运行，点活动栏最下面的“返”（返回命令行）时结束并归还显示面，调用方接着运行。「授权根」是文件浏览、编辑保存、终端环境（`.环境`）与设置数据库（`yy桌面设置.数据库`）所用的授权目录名；「布局」是开场的默认布局：「浏览终端布局」（左文件浏览、右终端，焦点在终端；裸机开机壳的「图形」与 `豫言操作系统/应用/图形桌面` 用它，授权根“桌面”）与「浏览编辑布局」（左文件浏览、右空编辑组；`应用/开发工具/豫言工作台` 用它，授权根“工作台”）。

## 模块

| 模块 | 内容 |
| --- | --- |
| `分割树` | 纯逻辑：分割树（分支记方向与甲边千分比，叶子是标签组）、拆分、关标签（组空了删组并收拢父分支）、移焦点、移标签、调比例、求各组与各分割条的矩形；分割条宽 4 逻辑像素，格子最小 120×80 |
| `格子` | 格子程序：格子与格子消息的和类型，各格子的新建、更新、视图、标题、计时需求；文件浏览格的投影 |
| `外壳` | 外壳状态（分割树、焦点组、格子表、共享工作台状态、桌面设置等）、外壳消息与更新、快捷键、计时 |
| `外壳视图` | 活动栏、标签栏、分割条、状态栏与焦点标记 |
| `工作台格` | 编辑、搜索、构建输出格的视图：把共享工作台状态的当前路径投影成本格路径，再用工作台的视图；没有焦点的格子去掉自动聚焦 |
| `工作台后台` | 工作台的后台任务（构建与模型请求）与授权根上的写文件、删文件；「授权根后台更新」「授权根收取后台任务」 |
| `构建执行` | 豫构命令参数与同步执行（后台检查等命令行用） |
| `文件改名` | 授权根上的改名（完整复制到目标后删源） |
| `开场布局` | 入口用的默认布局 |
| `运行` | 入口「运行平铺桌面」 |

## 界面与操作

左边 36 逻辑像素的活动栏：文（文件浏览，已开则聚焦第一个）、终（新开终端）、任（新开任务管理器）、设（新开设置）、搜（文件搜索，已开则聚焦），最下面是“返”。中间按分割树排布各标签组，每组上方是 28 逻辑像素的标签栏：标签（点击切换，× 关闭），右边是“左右”“上下”（拆分本组，新组里开一个同种格子）、“全屏”（单格全屏，再点还原）、“关闭”（关当前标签）；文件浏览格选中可运行的文件时多一个“运行”；当前格是编辑格时，前面还有它的视图切换钮。焦点组的当前标签有朱红下划线。组之间的分割条可以拖动调比例。底部 20 逻辑像素的状态栏显示焦点格的标题、工作台的错误提示与运行中的外部程序数。

在组里任何地方按下指针即聚焦该组；格子里的任何操作也会聚焦它所在的组。

快捷键的修饰键是交替（Alt、Option）：交替加回车新开终端，加 E 新开文件浏览，加方向键移焦点，再加上档把当前标签移到那一边（那边没有组就拆出一组），加 \ 左右拆分，加 - 上下拆分，加 W 关标签，加 F 单格全屏，加 1–9 切标签，加 [ 与 ] 调焦点组所在分支的比例。每个操作都有鼠标入口，裸机上全部可以用鼠标操作。

## 格子程序

- **终端**：`用户态桌面` 的图形命令行，命令处理与开机壳相同（「桌面命令平台」）。每个终端各有自己的状态、运行中的子程序与空轮询退避（250 毫秒起，至多 2 秒）；子程序未成行的输出余文按句柄分开。当前路径与开机壳共用一个。「退出」命令关掉这个终端格。
- **文件浏览**：工作台的资源侧栏（文件与包两种视图、资源树、包树），经「映射消息」接进外壳。每个文件浏览格有自己的资源树（展开状态各自分开），文件缓冲等共享状态放在外壳的工作台状态里。点文件行即选中它：以 .wasm 结尾或没有扩展名的文件读文件头认出可执行文件（豫行文件或网页汇编），名字以 `。脚本。豫` 结尾的是脚本；不是可执行文件的点一下就在编辑格里打开。选中后按回车或点标签栏的“运行”即运行：可执行文件开一个外部程序格，脚本开一个新终端格执行「脚本」；可执行文件也可以双击（半秒内再点同一行）运行。包视图、新建会话打开的文件同样进编辑格。新格子放进上一个焦点组（文件浏览格所在的组以外）；只有一组时往右拆出一组。
- **任务管理器**：`用户态桌面` 的任务管理器，每秒采样一次。
- **设置**：`用户态桌面` 的系统设置；设置全局一份，改了存进设置数据库。
- **外部程序**：以「启动子程序」异步启动（不带参数；当前目录设为程序所在目录，环境取自 `.环境`），计时取输出（完整的行才显示），结束后标签与内容标出退出码；关掉标签即终止子程序并收取，没收完的句柄由计时继续收取。
- **编辑**（第六步）：工作台的正文视图，文件的文档或原始代码视图、`.会话` 会话（上方一排引用按钮）、“差异：”页都是编辑格，格子只记路径；画之前把共享工作台状态的当前路径投影成本格路径，同一文件在两个编辑格里共用光标与视图选择。标签栏右侧是“右侧打开”（往右拆出一组开同一文件）与文档、原始代码切换；焦点在编辑格时状态栏右边是光标行列、构建运行时的停止钮与文件操作（包说明、检查、构建、类型检查、改名、删除）。保存、改名、删除落在授权根；改了没存的文件关不掉。点链接、看差异、改名时当前路径变了，本格跟着换路径。
- **搜索**（第六步）：工作台的文件搜索视图（活动栏“搜”，已开则聚焦）；点结果在编辑组打开，“返回文件”关掉搜索格。
- **构建输出**（第六步）：检查、构建、类型检查经后台任务（具名子程序“豫构”）运行，有构建输出就在编辑组下方拆出一格（占三成）显示，点诊断打开文件并定位，“收起构建结果”或关掉标签就收起。请求回复（会话）经具名子程序“模型请求”。

## 计时

外壳的计时间隔取各格子需求的最小值：终端有子程序在运行时按退避间隔，任务管理器 1 秒，外部程序在运行时按退避间隔，后台构建或模型请求在运行时 100 毫秒；有等着收取的句柄时至少每半秒一次。计时到时对所有格子做计时更新。

## 验证

- `测试/分割树。测试。豫`：拆分、关闭收拢、移焦点、移标签、调比例、求矩形（`豫构 构建 平铺桌面 测试 分割树。测试 --输出 yy分割树测试.wasm`，诺节运行）。
- `测试/外壳。测试。豫`：假浏览服务与假终端平台上的开场布局、拆分与关闭、多开终端各有输入、移焦点、设置不清别的格子、拖分割条、单格全屏、文件浏览格展开目录、运行动作与退出；工作台布局下从文件浏览打开编辑格、再点只聚焦、改了没存不许关、右侧打开、构建输出格的开与收起。
- `测试/会话启停。测试。豫`：同一程序连续运行两次平铺桌面，须绑定实际显示宿主（全树测试只检查）。

## 后续版本

- 外部程序格接子程序显示：画面、输入与尺寸（第七步）。
- 浏览器里的文树入口（第八步）。
- 布局存成文件、开机恢复；拖标签到别的组；外壳级输入法；每个终端各有当前目录。
- 光标闪烁时整窗重排：打开大文件或有文本框聚焦时，原生程序几乎一直占满一个核（工作台改用平铺桌面之前同样如此）；格子级的视图缓存留待后续版本。
