# 平铺桌面

平铺桌面，豫言之窗系也（[提案 00014](../../提案/00014-平铺桌面.汉语.md)）：一分割之树划其屏为不相叠之矩，叶为签组，签中为格程。终端、文件浏览、任务管理器、设置与外程序皆格程也，同种可开数个。外壳惟司布局与分派，格程各自更新；外程序各行于其任务。

## 入口

```yuyan
寻观「平铺桌面」之书。
「运行平铺桌面」于「授权根」为『桌面』于「布局」为「浏览终端布局」。
```

「运行平铺桌面」于显示面 `主窗口` 以自绘之后端行之；点活动栏最下之“返”（返命令行）则终而归其面，调用者续行。「授权根」者，文件浏览、编辑之存、终端之环境（`.环境`）与设置之库（`yy桌面设置.数据库`）所用授权目录之名也；「布局」者，开场之默认布局：「浏览终端布局」（左文件浏览、右终端，焦在终端；裸机开机壳之「图形」与 `豫言操作系统/应用/图形桌面` 用之，授根“桌面”）与「浏览编辑布局」（左文件浏览、右空编辑之组；`应用/开发工具/豫言工作台` 用之，授根“工作台”）。

## 诸模

| 模 | 所司 |
| --- | --- |
| `分割树` | 纯为逻辑：分割之树（枝记其向与甲边之千分，叶为签组）、拆、闭签（组空则删而收其父枝）、移焦、移签、调比，求诸组与诸分割条之矩；分割条宽四逻辑像素，格最小百二十乘八十 |
| `格子` | 格程：格与格消息之和类，诸格之新建、更新、视、题、计时之需；文件浏览格之投 |
| `外壳` | 外壳之态（分割之树、焦组、格表、共工作台之态、桌面之设等）、外壳之消息与更新、快捷之键、计时 |
| `外壳视图` | 活动之栏、签栏、分割之条、状态之栏与焦之标 |
| `工作台格` | 编辑、搜索、构建输出之格之视：投共工作台之态之当径为本格之径，乃用工作台之视；无焦之格去其自焦 |
| `工作台后台` | 工作台之后台之事（构建与模型之请）与授根上之书文、删文；「授权根后台更新」「授权根收取后台任务」 |
| `构建执行` | 豫构之命参与同步之行（后台检查等命令行用之） |
| `文件改名` | 授根上之更名（尽复制于目标乃删源） |
| `开场布局` | 入口所用之默认布局 |
| `运行` | 入口「运行平铺桌面」 |

## 界面与操作

左为三十六逻辑像素之活动栏：文（文件浏览，既开则焦其首）、终（新开终端）、任（新开任务管理器）、设（新开设置）、搜（文件搜索，既开则焦之），最下为“返”。中依分割之树排诸签组，每组上有二十八逻辑像素之签栏：诸签（点则易之，× 则闭之），右有“左右”“上下”（拆本组，新组中开同种之格）、“全屏”（单格全屏，再点则复）、“关闭”（闭当签）；文件浏览格选可行之文，则多一“运行”；当格为编辑格时，前又有其视之易钮。焦组之当签有朱下划。组间之分割条可拖以调比。下为二十逻辑像素之状态栏，示焦格之题、工作台之误示与方行之外程序数。

于组中任处按指，即焦其组；于格中有所操作，亦焦其所在之组。

快捷之键以交替（Alt、Option）为修饰：交替加回车新开终端，加 E 新开文件浏览，加方向移焦，复加上档则移当签于彼侧（彼无组则拆出一组），加 \ 左右拆，加 - 上下拆，加 W 闭签，加 F 单格全屏，加一至九易签，加 [ 与 ] 调焦组所在枝之比。每术皆有鼠之入口，裸机上尽可以鼠操之。

## 格程

- **终端**：`用户态桌面` 之图形命令行，命令之处同开机壳（「桌面命令平台」）。每终端各有其态、方行之子程序与空询之退避（自二百五十毫秒，至多二秒）；子程序未成行之余文依柄分之。当前路径与开机壳共一。「退出」之命闭此终端之格。
- **文件浏览**：工作台之资源侧栏（文件与包二视、资源之树、包之树），以「映射消息」接于外壳。每文件浏览格自有资源之树（展否各别），文之缓冲等共态存于外壳之工作台之态。点文行即选之：以 .wasm 终或无扩展名之文，读文首以认可执之文（豫行或网页汇编），名以 `。脚本。豫` 终者为脚本；非可执之文点之即于编辑格开之。既选，按回车或点签栏之“运行”即行之：可执之文开一外程序之格，脚本开一新终端之格以行「脚本」；可执之文亦可双击（半秒内再点同行）行之。包之视、新建会话所开之文亦入编辑之格。新格置于前焦组（文件浏览格所在组之外）；惟一组则右拆一组。
- **任务管理器**：`用户态桌面` 之任务管理器，每秒一采。
- **设置**：`用户态桌面` 之系统设置；设置全局一份，改则存于设置之库。
- **外程序**：以「启动子程序」异步启之（不携参；当前目录设为程序所在之目，环境取诸 `.环境`），依时取其出（成行乃示），毕则签与内容标其退码；闭签即止其子程序而收之，未收毕之柄由计时续收。
- **编辑**（第六步）：工作台之正文之视，文之文档或原码之视、`.会话` 会话（上置一排引用之钮）、“差异：”之页皆编辑之格，格惟记其径；画前投共工作台之态之当径为本格之径，同文在二编辑格共光标与视之择。签栏右为“右侧打开”（右拆一组以开同文）与文档、原码之易；焦在编辑格时，状态栏右为光标之行列、构建方行之止钮与文之术（包说明、检查、构建、类型检查、更名、删除）。存、更名、删除落于授根；改而未存之文不可闭。点链、观差、更名而当径易，则本格随易其径。
- **搜索**（第六步）：工作台文件搜索之视（活动栏“搜”，既开则焦之）；点果则于编辑之组开之，“返回文件”则闭搜索之格。
- **构建输出**（第六步）：检查、构建、类型检查经后台之事（具名子程序“豫构”）行之，有构建之出则于编辑组下拆出一格（占三成）示之，点诊则开文而定位，“收起构建结果”或闭其签则收之。请答（会话）经具名子程序“模型请求”。

## 计时

外壳之计时取诸格所需之最小：终端有子程序方行则依退避之间，任务管理器一秒，外程序方行则依退避之间，后台构建或模型之请方行则百毫秒；有待收之柄则至少每半秒一次。时至则遍诸格行计时之更新。

## 验证

- `测试/分割树。测试。豫`：拆、闭而收、移焦、移签、调比、求矩（`豫构 构建 平铺桌面 测试 分割树。测试 --输出 yy分割树测试.wasm`，以诺节行之）。
- `测试/外壳。测试。豫`：于假浏览之服与假终端之台，验开场之布、拆与闭、多开终端各有其入、移焦、改设不清他格、拖分割条、单格全屏、文件浏览格展目录、运行之动作与退出。工作台之布下，自文件浏览开编辑格、再点惟焦之、改而未存不许闭、右侧开之、构建输出之格之开与收。
- `测试/会话启停。测试。豫`：同一程序连行两次平铺桌面，须绑实显示之宿主（全树测试惟检之）。

## 后续版本

- 外程序之格接子程序显示：画面、输入与尺寸（第七步）。
- 浏览器之文树入口（第八步）。
- 布局存为文、开机复之；拖签至他组；外壳级之输入法；每终端各有当前目录。
- 光标闪而全窗重排：开大文或有文本框得焦，原生之程几恒占一核（工作台改用平铺桌面前亦然）；格级之视之缓存留待后版。
