# 结森工具

结森（JSON）之数据结构、严格解析、访问、转义、逐行读写及分块事件解析。旧属拓展库，二〇二六年九月二十六日别立为包。转义之则见[结森转义](结森转义.文言.md)。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包为库，可供他包所依；依标准库，其试另用单元测试。

独书 `寻观「结森工具」之书。` 则取总集；亦可按书观之，如 `寻观「结森工具」之「结森访问」之书。`。

变接口则修说明，变身份、版本与所依则修包籍。

## 解析与接口

式依 [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.html)。全篇可为任一结森值；空白为字节三十二、九、十、十三；数可有负号、小数与正负指数。容器以明栈验之，数组与对象循原序，重键亦循原序存之。字符串先验八位编码与转义之式，继付标准库客运行时解之；孤代理项转义循旧约化为替换字符。

| 接口 | 所受与所还 |
| --- | --- |
| `结森解析` | 受串还结森，式失告可承之异 |
| `结森尝试解析` | 受串还可选结森，式失还 `可无` |
| `结森字节尝试解析` | 受八位编码字节串还可选结森 |
| `结森表示`、`结森写字节` | 受结森还紧凑串、八位编码字节串 |
| `结森文合法吗` | 验式及八位编码，还爻 |
| `结森行读取`、`结森行表示` | 一行一值；末行可无行隔，所书各行具行隔；空行告异 |
| `结森流创建`、`结森流送入`、`结森流结束` | 造态、授字节块而回调事件、验篇终 |

事件有数组及对象之始终、成员名及原子值。授块皆还新态，下授以其新态行之。多字节之字、转义及数字，其间皆可分块；事件循原序授回调。态唯存容器栈及今词元，长篇可边读边治。后文有失以前，回调或已受事件，应用循己之事务界存其果。

全篇及流之单词元限十亿字节，容器限十万层。常整数仍整数，指数及较长之整数以双精度存；小数之书循标准库之六位小数，非数及无穷书为空值。

## 对照与核验

公开测试集出自 [JSONTestSuite](https://github.com/nst/JSONTestSuite)，定提交 `1ef36fa01286573e846ac449e8683f8833c5b26a`，许可 MIT。原篇置仓外 `豫言数据/结森测试集`，本包录纯豫言验器，集文与来源目录俱存。全篇之式已过 `test_parsing` 三百一十八篇，三十五篇自定者各记纳拒，纳拒之类皆无败。

`测试/结森一致性。测试。豫` 验严格之式、结森行、指数、回车及一字节、七字节之事件分块，诺节三十九项皆过。`测试/全量/结森测试集。测试。豫` 所比全篇与事件流，三百一十八篇皆过。`测试/全量/结森模糊。测试。豫` 以百子程验语法、全篇解析、结森行、事件流四入口，各百万变文皆成，全篇与事件流之果相合；今次用时 385.917269 秒。`测试/全量/结森性能。测试。豫` 温后七量，取其中位。

二〇二六年十月七日，于 pit-mac 之真实 Chrome 154.0.8037.98，以同源重造之双宿主构建、装载包两具封装同一三十九验。暂置之纯豫言应用验成三十九、败零，乃书于页，DOM 实显“结森一致性三十九项通过”。复行之径、令与证见[实施记录](实施记录.汉语.md)。

## 后续核验

二〇二六年十月七日，于诺节温一次、七量取中：四十四字节之对象，全篇析为 0.023292 毫秒，事件流为 0.030750 毫秒；四十五万零一字节之万项对象数组，分别为 392.946583 毫秒、367.086750 毫秒。同机方并行诸基础库之事，录此以记今实现。

二〇二六年十月七日，于 pit-mac，以同源提交 `16cffa740` 之原生生成器、执行器造苹果臂六十四预编二程序而直行之：一致性三十九项、数据结构复验六十二项、公开集三百一十八篇皆过，三程序退码皆零。

裸机之验，原生性能及系统实现之对照，皆列提案 00004 之验事。小数精确往返之书留待后版。
