# 结森工具

结森（JSON）的数据结构、严格解析、访问、转义、结森行读写与分块事件解析。原属拓展库，2026-09-26 起独立成包。转义规则见[结森转义](结森转义.汉语.md)。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，可被其他包依赖；依赖标准库，测试另用单元测试。

## 使用

单段导入 `寻观「结森工具」之书。` 取总集；也可按模块导入，如 `寻观「结森工具」之「结森访问」之书。`。

## 维护

修改接口时更新本说明；修改包身份、版本或依赖时同步更新包配置。

## 解析与接口

语法依据 [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.html)。完整文档可以是任意一个结森值；空白为字节 32、9、10、13；数字支持负号、小数与正负指数。容器用显式栈核验，数组和对象按原顺序保存，重复对象键按原顺序保存。字符串先核验八位编码及转义语法，再由标准库客体运行时解码；孤立代理项转义按既有规则转换为替换字符。

| 接口 | 输入与结果 |
| --- | --- |
| `结森解析` | 字符串到结森，语法错误抛出可捕获异常 |
| `结森尝试解析` | 字符串到可选结森，语法错误返回 `可无` |
| `结森字节尝试解析` | 八位编码字节串到可选结森 |
| `结森表示`、`结森写字节` | 结森到紧凑字符串、八位编码字节串 |
| `结森文合法吗` | 核验语法和八位编码，返回爻 |
| `结森行读取`、`结森行表示` | 每行一个完整值，读取末行可省换行，写入各行带换行；空行报错 |
| `结森流创建`、`结森流送入`、`结森流结束` | 创建状态、送入字节块并回调事件、核验输入结束 |

事件包括数组和对象的开始、结束、成员名及原子值。每次送入返回新状态，下次送入使用该状态。字节块可以在多字节字符、转义与数字内部切开；容器和原子事件按输入顺序交给回调。状态只保存容器栈和当前词元，大文件可边读边处理。回调已处理的事件可以在后续输入出错前出现，应用按自己的事务边界保存结果。

整文输入及单个流词元上限十亿字节，容器嵌套上限十万层。常用整数保留整数类型，指数与较长整数采用双精度；小数输出沿用标准库六位小数形式，非数与无穷输出空值。

## 对照与验证

公开结森测试集来源：[JSONTestSuite](https://github.com/nst/JSONTestSuite)，固定提交 `1ef36fa01286573e846ac449e8683f8833c5b26a`，MIT 许可。原始文件放仓外 `豫言数据/结森测试集`；本包提交纯豫言运行工具，测试集内容随来源目录保存。整文校验已通过 `test_parsing` 全部 318 个文件；35 个实现自定文件逐项报告接受或拒绝，接受及拒绝类失败为零。

`测试/结森一致性。测试。豫` 覆盖严格语法、结森行、指数、回车及事件流的单字节和七字节切块，诺节 39 项通过。`测试/全量/结森测试集。测试。豫` 的整文与事件流差分也通过全部 318 个文件。`测试/全量/结森模糊。测试。豫` 以一百个子进程完成语法核验、整文解析、结森行读取、事件流四个入口各百万次变异检查，全部成功，整文与事件流差分一致；本次总耗时 385.917269 秒。`测试/全量/结森性能。测试。豫` 预热后取七次中位数。

2026-10-07 在 pit-mac 的真实 Chrome 154.0.8037.98 中，用同源重建的双宿主构建和装载包工具打包同一组 39 项用例。临时纯豫言应用核对成功数 39、失败数零后写入页面，DOM 实际显示“结森一致性三十九项通过”。复现路径、命令与证据见[实施记录](实施记录.汉语.md)。
