# 盟府（共识库）

通用的共识库，照 Raft（桴，Ongaro 与 Ousterhout，二零零一四年）做，提案 00064《内府》第二步的地基。只有纯状态机：不碰网、不碰盘、不碰钟，网、盘、钟都由上层接。带载书截断与快照追赶（Raft 论文第七节），快照的字节由上层传，本库只报送给谁、送到哪一号。另带一个确定性推演器与一套情景测试。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只有一个直接依赖：标准库（列、可选值、帛与文之术）。单段导入 `寻观「盟府」之书。` 不展开任何模块，用哪个模块就显式导入哪个。

## 模块

| 模块 | 内容 |

| 载记 | 载书的取用：末标、条期、在条、首同期末、取段、合条数、条同、帛同、序排、序插；认快照点的各一份带照（`末标带照`、`条期带照`、`在条带照`、`首同期末带照`、`取段带照`、`合条数带照`），旧名留给没有快照的整书 |

## 用法

一步的次序是**先落盘、后发信**：

```yuyan
令「果」为（「步」于「态」于「入」）而
令「无」为（「落盘」于「盘」于（「果」中「须存」））而
令「证」为（「持证」于（「果」中「须存」））而
令「后」为（「启封」于「果」于「证」）而
「后」中「态」
```

- `步` 的结果分两段：`须存` 是必须写进稳定存储的存单（任期、所投、截到几条、接上几条），`后` 是落盘之后才可取的发件（新态、要发的信、要交的条、给上层的议答与读答）。`启封` 要一张 `存证`，它是「已经按这张单落过盘」的回执；本库以此表达「先落盘后发信」的规矩。
- 入是记录：`时`（单调毫秒）、`随`（调用方随机源给的一个整数，用来错开选举）、`事由`（刻至、信至、献令、请读）。时钟与随机都由外授，同一状态与同一入必得同一果。
- 消息只有四种：求票、答票、附载（空的就是心跳）、答载。信带自、至、内三项。
- 读确认（ReadIndex）：盟主收下读请求时，若本任期还没有载书盟成，请求就挂着（`读候` 的轮记零），等本任期首条盟成之后自动开一轮心跳去数过半；答复的序号取「挂起时记的盟成点」与「答复时的盟成点」的较大者，故必不早于此前任何已盟之条。
- 让位（见到更高任期、降为从员）时，挂着的读候一律答 `读非主` 并附所知的主（附载里就记发信的那位），不丢下请求。
- 载书的序号就是条在列里的位置，条不另存序号。
- 载条的令有两种（`命令`）：`实令` 是上层献上的命令帛，`空令` 是盟主当选后自己补的一条。补空令是为了让本任期有一条载书得以盟成：Raft 只在「本任期的条已过半」之后才许读、才许推进盟成点。空令照样按序交付给上层（`交条` 带的是 `命令`），由上层 `鉴` 出 `空令` 跳过。
- 从员、候盟、盟主三种身份、两种议答、两种读答、四种消息、四种事由，`鉴` 时都须列全。
- 快照（Raft 论文第七节）：上层把已交付到第 k 条的状态存成快照之后调 `立快照`，本库把 k 及以前的载书丢掉、记下快照点（k 与那一条的任期），并在存单的 `快照` 项里报"截到 k 之前"与新的快照点；上层照单落盘（`落盘带照`）再继续。载书的序号仍是绝对号，`书长` 是末一条的绝对号，载书里只剩快照点之后的条。
- 附载跨快照：前标落在快照点及以前就当对得上（那些条已在快照里），只接快照点之后的部分；前标恰是快照点时按快照点的任期比；末标、任期、取条、取段、合条数都认快照点。
- 送快照：盟主发现某位远员的下号已落在快照点及以前（要的条已截掉），就不再给它发附载的条文，改在发件的 `送照们` 里报一项"给某员送快照（至号、任期）"，同时仍给它发一封心跳（前标报快照点），好让它的选举期限照常续上。快照的字节由上层传。对方的上层传完、装好之后调 `装快照`（员态、至号、任期、主号）：从员把自己的载书换成从快照点起（照点之后的旧条一律丢掉；本库的照不带链印，留着无从核对，盟主随后按载成从照后重发），快照点记成至号与该任期，盟成点与已交付点至少推到至号（只进不退），随后答盟主一封载成；盟主凭它把该员的下号与同号推到快照点之后。至号不大于现有快照点或已交付点时是旧照，原样不动，也答一封载成。
- 装快照只给从员装：盟主与候盟的书不因别处的快照而截短。
- 上层要另存一份快照点的记录：存单的 `快照` 项与落盘之后的照书（`照书`：快照点加盘书）给出新的持久态，重起时照它造照书调 `开府带照`（没有快照的旧调用方仍用 `开府`）。
- 成员增减留待后续版本；这一步的盟规（选举三百至六百毫秒、心跳一百毫秒）由 `常规` 给出，也可另造 `府规`。

## 推演

`寻观「盟府」之「推演」之书。` 之后：

- `「演一种」于「种子」` 跑一副剧本：种子逢双三员、逢单五员，各员钟速九百五十至一千零五十，期限四千毫秒，随机注崩溃与重起、一次分区与愈合、丢包、重复、迟延，并随机献令、请读。
- `「随机剧本」于「种子」` 只摊剧本，不跑。
- 每走一步核十一条：同一任期至多一个盟主；同号同期的载书此前全同（日志匹配）；盟成的载书在之后各任期盟主的载书里都在（领袖完整）；各员交付的序列互为前缀，装了快照的员以快照点那一号的状态摘为界，摘须与别员在同一序号的状态一致（状态机安全）；装快照不会让已交付点后退，且盟成点不小于已交付点；截掉的载书不再被附载用到（附载的前标不落到快照点之前），送照的标正是快照点；盟成点不超过书长；已答收录且盟成的提议不会丢；全好一段时间内能选出盟主并继续盟成（活性，宽松地核）；读确认只出于盟主、且该员本任期已有载书盟成；读确认答出的序号不小于当时已盟成、已交付的每一条。
- 违例时看 `演果` 的 `违例们` 与 `录们`，凭种子可复现；`述员们` 给出各员处境的文字。

## 测试

- `测试/推演。测试。豫`：默认六十个种子，带一个参数跑别的种数。
- `测试/推演万种。测试。豫`：默认一万个种子（三员与五员各半），本机约十一秒；带参数跑别的种数，第二个参数是起点种子。
- `测试/情景。测试。豫`：八副手写情景——三员选主（空令先盟成）、献令、盟成、交付、读确认许在新盟成点；盟主孤立在少数派一侧，愈合后旧主退位、旧书被截；从员带着未盟的条被新主截掉；盟主被分区隔开时读确认不答、愈合后才答；让位时挂着的读确认答「非主」并附所知的主；从员掉线期间盟主立快照截掉载书、从员回来后经送快照追上；装快照与普通附载交错；快照点之后的冲突条照样被截。

构建与运行：

```sh
豫构 构建 盟府 测试 推演万种。测试 --输出 推演万种测试。林檎。豫行
./推演万种测试。林檎。豫行
```
