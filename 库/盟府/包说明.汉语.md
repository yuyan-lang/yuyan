# 盟府（共识库）

通用的共识库，照 Raft（桴，Ongaro 与 Ousterhout，二零零一四年）做，提案 00064《内府》第二步的地基。只有纯状态机：不碰网、不碰盘、不碰钟，网、盘、钟都由上层接。另带一个确定性推演器与一套情景测试。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只有一个直接依赖：标准库（列、可选值、帛与文之术）。单段导入 `寻观「盟府」之书。` 不展开任何模块，用哪个模块就显式导入哪个。

## 模块

| 模块 | 内容 |
| --- | --- |
| 府制 | 型与器：任期、序号、条标、载条、府规、遥记、身份（从员、候盟、盟主）、读候、消息（求票、答票、附载、答载）、信、交条、议答、读答、事、入、存单、盘书、存证、发件、步果；开局（`开府`）、落盘（`落盘`）、持证（`持证`）、启封（`启封`）、择限（`择限`）、过半（`过半`） |
| 载记 | 载书的取用：末标、条期、在条、首同期末、取段、合条数、条同、帛同、序排、序插 |
| 盟约 | 共识状态机：`步` 收一个员态与一个入，交出步果；内部有选举（举、收票、收答票、成盟）、附载（发载、收载、受载、续载、前校）、盟成（进成、交付进）、读确认（收读、发读请、读候进）、献令（受献）与刻（候刻、主刻） |
| 推演 | 确定性模拟：剧本、员、事件列、假网（迟延、丢包、重复、分区）、假钟（各员钟速）、假盘（崩溃只留已落盘的），六条不变式的逐步核对；违例时印种子、各员处境与事件序列 |

## 用法

一步的次序是**先落盘、后发信**：

```yuyan
令「果」为（「步」于「态」于「入」）而
令「无」为（「落盘」于「盘」于（「果」中「须存」））而
令「证」为（「持证」于（「果」中「须存」））而
令「后」为（「启封」于「果」于「证」）而
「后」中「态」
```

- `步` 的结果分两段：`须存` 是必须写进稳定存储的存单（任期、所投、截到几条、接上几条），`后` 是落盘之后才可取的发件（新态、要发的信、要交的条、给上层的议答与读答）。`启封` 要一张 `存证`，它是「已经按这张单落过盘」的回执；本库以此表达「先落盘后发信」的规矩。
- 入是记录：`时`（单调毫秒）、`随`（调用方随机源给的一个整数，用来错开选举）、`事由`（刻至、信至、献令、请读）。时钟与随机都由外授，同一状态与同一入必得同一果。
- 消息只有四种：求票、答票、附载（空的就是心跳）、答载。信带自、至、内三项。
- 读确认（ReadIndex）：盟主收下读请求时，若本任期还没有载书盟成，请求就挂着（`读候` 的轮记零），等本任期首条盟成之后自动开一轮心跳去数过半；答复的序号取「挂起时记的盟成点」与「答复时的盟成点」的较大者，故必不早于此前任何已盟之条。
- 让位（见到更高任期、降为从员）时，挂着的读候一律答 `读非主` 并附所知的主（附载里就记发信的那位），不丢下请求。
- 载书的序号就是条在列里的位置，条不另存序号。
- 载条的令有两种（`命令`）：`实令` 是上层献上的命令帛，`空令` 是盟主当选后自己补的一条。补空令是为了让本任期有一条载书得以盟成：Raft 只在「本任期的条已过半」之后才许读、才许推进盟成点。空令照样按序交付给上层（`交条` 带的是 `命令`），由上层 `鉴` 出 `空令` 跳过。
- 从员、候盟、盟主三种身份、两种议答、两种读答、四种消息、四种事由，`鉴` 时都须列全。
- 快照与截断、成员增减留待后续版本；这一步的盟规（选举三百至六百毫秒、心跳一百毫秒）由 `常规` 给出，也可另造 `府规`。

## 推演

`寻观「盟府」之「推演」之书。` 之后：

- `「演一种」于「种子」` 跑一副剧本：种子逢双三员、逢单五员，各员钟速九百五十至一千零五十，期限四千毫秒，随机注崩溃与重起、一次分区与愈合、丢包、重复、迟延，并随机献令、请读。
- `「随机剧本」于「种子」` 只摊剧本，不跑。
- 每走一步核八条：同一任期至多一个盟主；同号同期的载书此前全同；盟成的载书在之后各任期盟主的载书里都在；各员交付的序列互为前缀；已答收录且盟成的提议不会丢；全好一段时间内能选出盟主并继续盟成（活性，宽松地核）；读确认只出于盟主、且该员本任期已有载书盟成；读确认答出的序号不小于当时已盟成、已交付的每一条。
- 违例时看 `演果` 的 `违例们` 与 `录们`，凭种子可复现；`述员们` 给出各员处境的文字。

## 测试

- `测试/推演。测试。豫`：默认六十个种子，带一个参数跑别的种数。
- `测试/推演万种。测试。豫`：默认一万个种子（三员与五员各半），本机约十一秒；带参数跑别的种数，第二个参数是起点种子。
- `测试/情景。测试。豫`：五副手写情景——三员选主（空令先盟成）、献令、盟成、交付、读确认许在新盟成点；盟主孤立在少数派一侧，愈合后旧主退位、旧书被截；从员带着未盟的条被新主截掉；盟主被分区隔开时读确认不答、愈合后才答；让位时挂着的读确认答「非主」并附所知的主。

构建与运行：

```sh
豫构 构建 盟府 测试 推演万种。测试 --输出 推演万种测试。林檎。豫行
./推演万种测试。林檎。豫行
```
