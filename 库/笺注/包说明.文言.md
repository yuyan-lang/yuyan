# 源码文档

此工作台、系统文件预览与云仓包阅读页共用之源码文档数据。`资料。豫` 与 `定义片段。豫` 自云仓包引擎迁入，循编译器语法解析、注释之取、明确导入与原始定义片段。

`源码声明资料` 供名称之本地说明与明确来源；`定义片段们` 存原代码及行号；`定义片段资料` 合同名声明与实施，位置取首声明。源码以文字静态解析。
`定义片段们` 之原片各供“起位”与“止位”，依通字符计，范围含左而不含右。全片含前空及注，可据源码之位联其声明名。
`源码位置声明名称` 依源码及字符之位返所属声明名，同名签与实施归同名，域外返空串。

本包依标准库、结森工具、编译器核心、包配置与网页客户端。系统之访由调用者行之。试居 `测试/`，测试包登于共用库。
