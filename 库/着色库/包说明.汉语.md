# 着色库

深度学习推理新增「载入矩阵片累前八行」：从单精度共享数组读取8×16区域，返回16×16累加片，下八行填零。起点和行步长以单精度元素计，均须为8的倍数，所读区域在界内，全子组一致调用。当前只支持Metal，辅助源码仅在使用该接口时生成；八行注意力原型将据此继续缩减共享累加存储，性能尚待验证。

着色语言的内建声明：WGSL 的标量、向量、矩阵、资源、入口与内建函数的豫言签名。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，不依赖任何包，登记在「共用库」之下。

## 使用

唯一的模块是 `着色内建。着色器。接口。豫`（着色内建声明）。着色源（`名。着色器。豫`）写 `寻观「着色库」之「着色内建」之书。`，所在的包须声明依赖「着色库」。其中的函数由着色目标（WGSL、MSL 或 PTX）提供：翻译器把调用换成目标语言的运算符、内建函数或指令，运行时不存在这些调用；类型、别名与签名只供类型检查与翻译。标量的宽度与有无符号由名义类型区分（「定长长度」「定长小数」「定长整数」「定长无符号」，「浮三二」等是它们的别名），字面量经「新浮三二」「新无三二」等构造器取得类型；定长数组是「定长数组」于 元素类型 于 定长长度。完整的名字表、翻译规则与限制见[着色语言](../../应用/豫言编译器/文档/语言技术规范/着色语言.汉语.md)。

构建探针或应用时，`yy双宿主构建` 须加 `--包根 库/着色库` 才能找到本包。

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 着色库
```

测试在 `测试/`（包「着色库测试」）。依赖及说明路径以 [包配置](着色库。包。豫) 为准。

## 维护

「存矩阵片累到存储」将16×16单精度累加块直接写入读写存储缓冲，布局同「存矩阵片累」。起和步须为8的倍数，整个子组在一致控制流里调用，调用方保证完整16×16区域在界内。Metal使用设备指针的`simdgroup_store`，PTX使用全局向量存储；网页目标不支持。

「载矩阵片甲自存储」「载矩阵片乙自存储」是深度学习半精度缓存直读接口：从「存储缓冲」的「无三二」数组直接读取16×16半精度矩阵片，每字存两个半精度位型，低半字在前。起和步以半精度元素计，须为8的倍数；整片在界内，全子组一致调用。甲片布局与共享载入相同，乙片载入时转置，乘加仍计算甲乘乙转置。当前Metal直接使用设备指针的`simdgroup_load`；网页与统算明确报不支持。对应能力见[苹果Metal语言规范第6.8节](https://developer.apple.com/metal/Metal-Shading-Language-Specification.pdf)。乙片直读与前八行载入、写回用于Metal双头单词元注意力的128维半精度键、至少1024个可见键路径。

翻译回归48项通过，旧黄金输出保持一致。pit-mac设备运行31项通过，数值断言核对两组不同正负半精度输入、起点8/16、行间距24的256个矩阵结果及144个输出保护元素，并核对前八行的128个结果及共享、设备输出保护区。

增删内建时同步修改翻译器（`库/编译器核心/编译步骤/着色翻译/` 里的类型表与内建规则表）与着色语言规范。

「载矩阵片甲前八行」「存矩阵片累前八行」供少行注意力使用：载入甲的前8×16元素，后八行置零；存回累的前8×16元素，其余目标元素保持原值。起、步须为8的倍数，八行区域在界内，全子组一致调用。当前仅支持Metal。
预填充在线注意力实验新增「载入矩阵片累」与「载矩阵片乙自转置存储」。前者从单精度共享数组读16×16累加片，起、步以单精度元素计；后者从无三二存储缓冲的半精度位型读乙的转置布局，乙[行][列] = 缓冲[起 + 列×步 + 行]，起、步以半精度元素计。起、步为8的倍数，完整区域在界内，全子组一致调用。当前仅支持Metal，数值验证及预填充性能仍待完成。
预填充实验的初步金属运行34项通过：新增样本核对256个带非零单精度初累的结果及144个输出保护元素，甲、乙采用不同正负半精度布局，起点8/16、步24，乙按转置存储读取。实验编译器为`yy预填矩片编译器.wasm`，设备日志`yy预填矩片内建测试.log`。八查询分块注意力及模型性能尚待实现、验证，当前默认模型构件保持上一轮已采用版本。
