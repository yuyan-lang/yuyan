# 着色库

着色语言的内建声明：WGSL 的标量、向量、矩阵、资源、入口与内建函数的豫言签名。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，不依赖任何包，登记在「共用库」之下。

## 使用

唯一的模块是 `着色内建。着色器。接口。豫`（着色内建声明）。着色源（`名。着色器。豫`）写 `寻观「着色库」之「着色内建」之书。`，所在的包须声明依赖「着色库」。其中的函数由着色目标（WGSL）提供：翻译器把调用换成 WGSL 运算符与内建函数，运行时不存在这些调用；类型、别名与签名只供类型检查与翻译。标量的宽度与有无符号由名义类型区分（「定长长度」「定长小数」「定长整数」「定长无符号」，「浮三二」等是它们的别名），字面量经「新浮三二」「新无三二」等构造器取得类型；定长数组是「定长数组」于 元素类型 于 定长长度。完整的名字表、翻译规则与限制见[着色语言](../../应用/豫言编译器/文档/语言技术规范/着色语言.汉语.md)。

构建探针或应用时，`yy双宿主构建` 须加 `--包根 库/着色库` 才能找到本包。

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 着色库
```

测试在 `测试/`（包「着色库测试」）。依赖及说明路径以 [包配置](着色库。包。豫) 为准。

## 维护

增删内建时同步修改翻译器（`库/编译器核心/编译步骤/着色翻译/` 里的类型表与内建规则表）与着色语言规范。
