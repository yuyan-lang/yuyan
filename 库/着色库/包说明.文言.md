# 着色库

深学推理新置「载入矩阵片累前八行」：自单精共享列读八乘十六域，还十六乘十六累片，下八行填零。起步以单精元计，皆八之倍，读域在界，全子组一致召之。今惟Metal，惟用此口乃生辅源；八行注意原型将以之再减共享累存，其速未验。

着色语言之内建之声：WGSL 之标量、向量、矩阵、资源、入口与内建之函之豫言签名。

## 籍

所有者曰豫言，版本 0.1.0，种类曰库，无所依，登于「共用库」之下。

## 用

惟一模曰 `着色内建。着色器。接口。豫`（着色内建之声）。着色之源（`名。着色器。豫`）书 `寻观「着色库」之「着色内建」之书。`，其所在之包须依「着色库」。其函由着色之的（WGSL、MSL 或 PTX）具之：译器以的语之算符、内建之函或令代其召，运行之时无此召；类、别名与签惟供检类与译。标量之宽与符之有无以类别之（「定长小数」「定长整数」「定长无符号」于整数之宽，如「定长小数」于「三二」；「浮三二」等为其别名），字面经「新浮三二」「新无三二」等构造而得其类；定长数组为「定长数组」于 元之类 于 整数之长，如「定长数组」于「浮三二」于「八一九二」。名之全表、译规与所限见[着色语言](../../应用/豫言编译器/文档/语言技术规范/着色语言.文言.md)。

构探针或应用，`yy双宿主构建` 须加 `--包根 库/着色库` 乃得此包。

于仓之根行 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 着色库` 以验其籍。试在 `测试/`（「着色库测试」包）。所依与说明之径以[包籍](着色库。包。豫)为准。

## 维护

「存矩阵片累到存储」直书十六乘十六单精累块于读写存储缓冲，布局同「存矩阵片累」。起与步须为八之倍，全子组于一致控流召之，召者保全十六乘十六域在界内。Metal用设备指针之`simdgroup_store`，PTX用全局向量存储；网页之的不支。

「载矩阵片甲自存储」「载矩阵片乙自存储」为深度学习半精缓存直读之口：自「存储缓冲」之「无三二」列径读十六乘十六半精矩阵片，一字二半精位型，低半字在先。起与步以半精元计，须为八之倍；全片在界，全子组一致召之。甲片布局同共享之载，乙片载时转之，乘加犹算甲乘乙转置。今Metal径用设备指针之`simdgroup_load`；网页与统算皆明报不支。此能见[苹果Metal语言规范第6.8节](https://developer.apple.com/metal/Metal-Shading-Language-Specification.pdf)。乙片直读与前八行载书用于Metal双头一词注意之百二十八维半精键、至少一千零二十四可见键之径。

翻译回归四十八项皆过，旧金样之出犹同。pit-mac设备运行三十一项皆过，数值断言验二组异布正负半精之入、起八及十六、行距二十四之二百五十六阵出及一百四十四护元，复验前八行百二十八出及共享、设备出之护域。

增删内建，须同修译器（`库/编译器核心/编译步骤/着色翻译/` 之类表与内建之规表）及着色语言之规。
「载矩阵片甲前八行」「存矩阵片累前八行」以用于少行注意：载甲前八乘十六元，后八行置零；书累前八乘十六元，余目元保旧值。起、步须为八之倍，八行在界，全子组一致召之。今惟支金属。
预填在线注意之试新置「载入矩阵片累」与「载矩阵片乙自转置存储」。前者自单精共享列读十六乘十六累片，起、步以单精元计；后者自无三二存储缓之半精位型读乙之转置布，乙[行][列] = 缓冲[起 + 列×步 + 行]，起、步以半精元计。起、步为八之倍，全域在界，全子组一致召之。今惟支Metal，数值与预填之速尚待验。
预填之试初步金属运行三十四验皆过：新例验二百五十六有非零单精初累之出及一百四十四护元，甲乙用异布正负半精，起八与十六、步二十四，乙依转置存读取。实验编译器`yy预填矩片编译器.wasm`，设备之录`yy预填矩片内建测试.log`。八问分块注意及模型之速尚待制验，今默认模型构件犹为上轮所用之版。
