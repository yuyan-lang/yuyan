# 着色库测试

着色语言之试：着色之源译为 WGSL、MSL 与 PTX 之金样、报误之样、高级之代导着色之源之构建之合之样，及所生之 MSL 于金属、PTX 于统算编而行之。

## 籍

所有者曰豫言，版本 0.1.0，种类曰库；依标准库、单元测试、构建基础、编译器核心（译器）、包配置、着色库、系统库调用、金属与统算。此包依所试之着色库，故登于上一级之父「共用库」之下。

## 所载

- `样例/`：每着色之源 `名。着色器。豫` 配一所期之文：`名.wgsl` 为所期之 WGSL（逐字相较），`名.错误` 为误辞所当含之文；`名.金属` 为所期之 MSL（逐字相较）；`名.统算` 为所期之 PTX（逐字相较，加倍、求和、缩放、杂项、子组、子组非满六样例有之）；`名.生成` 为高级之代导之时构建所得之模之豫言源。样例及数组倍之计算、三角之顶点与片元（结构与自编之位次）、局部尾递归之环、格、二种「若」（select 与 if）、数组之读写、内建之入、均匀缓冲、纹理、采样器、原子、工作组变量与定长数组、带类之字面、内建之入所成之入口之参之结构与辅函所用之资源（缩放，重金属之的）、子组之算（求和、最大、最小、广播、洗牌与子组内序号、子组大小，三的各有所期之文；子组非满同之而工作组四十八线，线束不满），及类型之误、混用标量之宽、非尾递归、着色之文导标准库四种报误。
- `着色翻译。测试。豫`：逐一译样例之目而核之，须于仓之根行之（行时于今目录索诸包，为样例启包之上下文）。
- `着色导入-1。豫` 与 `着色导入。成功`：构建之合之金样，导 `样例/加倍。着色器。豫`，书入口之函名与 WGSL、MSL 之文、PTX 之入口名与 PTX 之文。
- `金属运行。测试。豫`：导加倍、求和、缩放、子组四样例，经「金属」之库编构时所生之 MSL、派发而核其读回之数；无金属（非苹果之系，或宿主不能调系统之库）则书“跳过”。
- `统算运行。测试。豫`：导加倍、求和、缩放、子组、子组非满五样例（子组为二满员之三十二线之线束，所期同金属运行之试；子组非满之第二线束惟十六线，核子组之算惟计活线），经「统算」之库载构时所生之 PTX、发射（每块之线等工作组之大，缓依全块之线留足）而核其读回之数；无统算之器（系统无英伟达驱动 `libcuda.so.1`，或宿主不能调系统之库）则书“跳过”。

## 行

全树之试自索而行之（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/着色库/`）。独行单元之试：先 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色库测试 着色翻译。测试 --输出 yy着色翻译测试.wasm -j 24`，后 `node 豫言操作系统/宿主/节点/宿主.cjs yy着色翻译测试.wasm`。金属之试同法：构 `金属运行。测试` 为 `yy金属运行测试.wasm` 而行之；统算之试亦然：构 `统算运行。测试` 为 `yy统算运行测试.wasm` 而行之。

所期之 WGSL、MSL、PTX 可以 `yy着色器 译`、`yy着色器 金属`、`yy着色器 统算` 复生之，更之前须逐行复核。
