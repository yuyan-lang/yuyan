# 着色库测试

着色语言的测试：着色源译成 WGSL 的黄金样例、报错样例，以及高级代码导入着色源的构建集成样例。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、单元测试、构建基础、编译器核心（翻译器）、包配置与着色库。它依赖被测的着色库，所以登记在上一级父包「共用库」之下。

## 内容

- `样例/`：每个着色源 `名。着色器。豫` 配一个期待文件：`名.wgsl` 是期望的 WGSL（逐字比较），`名.错误` 是报错里应含的文字；`名.生成` 是高级代码导入它时构建所得模块的豫言源码。样例覆盖数组加倍计算、三角形顶点与片元（结构与自动位置号）、局部尾递归循环、格、两种「若」（select 与 if）、数组读写、内建输入、均匀缓冲、纹理、采样器、原子、工作组变量与定长数组、带类型的字面量，以及类型错误、混用标量宽度、非尾递归、在着色文件里导入标准库四种报错。
- `着色翻译。测试。豫`：对样例目录逐个翻译并核对，须在仓库根目录运行（运行时在当前目录发现包并为样例启用包上下文）。
- `着色导入-1。豫` 与 `着色导入。成功`：构建集成的黄金样例，导入 `样例/加倍。着色器。豫`，打印入口函数名与 WGSL 文字。

## 运行

全树测试自动发现并运行以上测试（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/着色库/`）。单独运行单元测试：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色库测试 着色翻译。测试 --输出 yy着色翻译测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy着色翻译测试.wasm
```

期望的 WGSL 可用 `yy着色器 译` 重新生成，更新前须逐行复核。
