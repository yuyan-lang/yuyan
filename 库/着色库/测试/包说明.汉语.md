# 着色库测试

着色语言的测试：着色源译成 WGSL、MSL 与 PTX 的黄金样例、报错样例、高级代码导入着色源的构建集成样例，以及生成的 MSL 在金属上、PTX 在统算上编译运行。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、单元测试、构建基础、编译器核心（翻译器）、包配置、着色库、系统库调用、金属与统算。它依赖被测的着色库，所以登记在上一级父包「共用库」之下。

## 内容

- `样例/`：每个着色源 `名。着色器。豫` 配一个期待文件：`名.wgsl` 是期望的 WGSL（逐字比较），`名.错误` 是报错里应含的文字；`名.金属` 是期望的 MSL（逐字比较）；`名.统算` 是期望的 PTX（逐字比较，加倍、求和、缩放、杂项、子组、子组非满、矩阵片、读四八个样例有）；`名.生成` 是高级代码导入它时构建所得模块的豫言源码。样例覆盖数组加倍计算、三角形顶点与片元（结构与自动位置号）、局部尾递归循环、格、两种「若」（select 与 if）、数组读写、内建输入、均匀缓冲、纹理、采样器、原子、工作组变量与定长数组、带类型的字面量、由内建输入组成的入口参数结构与辅助函数用到的资源（缩放，着重金属目标）、子组运算（求和、最大、最小、广播、洗牌与子组内序号、子组大小，三种目标各有期待文件；子组非满同上而工作组 48 个线程，线程束不满）、子组矩阵片（矩阵片：WGSL 期待报错，MSL 与 PTX 各有期待文件）、四个一组的读（读四：「读四浮」「读四无」），以及类型错误、混用标量宽度、非尾递归、在着色文件里导入标准库四种报错。
- `着色翻译。测试。豫`：对样例目录逐个翻译并核对，须在仓库根目录运行（运行时在当前目录发现包并为样例启用包上下文）。
- `着色导入-1。豫` 与 `着色导入。成功`：构建集成的黄金样例，导入 `样例/加倍。着色器。豫`，打印入口函数名、WGSL 与 MSL 文字、PTX 入口名与 PTX 文字。
- `金属运行。测试。豫`：导入加倍、求和、缩放、子组、子组非满、矩阵片、读四七个样例（矩阵片由一个子组算 16 × 32 乘 32 × 16，读回后按整数核对），经「金属」库把构建时生成的 MSL 编译、派发并核对读回的数值；没有金属（不是苹果系统，或宿主不能调用系统库）时打印“跳过”。
- `统算运行。测试。豫`：导入加倍、求和、缩放、子组、子组非满、矩阵片、读四七个样例（子组为两个满员的 32 线程线程束，期望值同金属运行测试；子组非满的第二个线程束只有 16 个线程，核对子组运算只算活跃线程；矩阵片同金属运行测试），经「统算」库把构建时生成的 PTX 载入、发射（每块线程数等于工作组大小，缓冲按整块线程数留足）并核对读回的数值；没有统算设备（系统上没有英伟达驱动 `libcuda.so.1`，或宿主不能调用系统库）时打印“跳过”。

## 运行

矩阵片直接存储翻译检查验证Metal设备指针调用、PTX全局向量写出和WGSL拒绝。非零矩阵数值测试在张量内核的「矩阵与位置」中，包含完整瓦片、完整与边缘混合、Q8权重及既有奇数尺寸；新增Metal辅助函数的样例期望须同步。

全树测试自动发现并运行以上测试（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/着色库/`）。单独运行单元测试：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色库测试 着色翻译。测试 --输出 yy着色翻译测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy着色翻译测试.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色库测试 金属运行。测试 --输出 yy金属运行测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属运行测试.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 着色库测试 统算运行。测试 --输出 yy统算运行测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy统算运行测试.wasm
```

期望的 WGSL、MSL、PTX 可用 `yy着色器 译`、`yy着色器 金属`、`yy着色器 统算` 重新生成，更新前须逐行复核。
