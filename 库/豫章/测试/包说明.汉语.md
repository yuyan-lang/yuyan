# 标准库测试

标准库的单元测试（`X。测试。豫`）与回归样例（`名其一。豫`、`名其二。豫`……配 `名。成功`／`名。失败`）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，不被其他包依赖。

测试要用单元测试框架（包「考课」），而标准库不能依赖它，所以测试单独成包，放在被测库之下：包目录是 `库/豫章/测试`，依赖标准库与单元测试。它没有登记为标准库的子包，因为子包不能依赖祖先。

## 使用

在仓库根目录构建并运行单个测试，入口段相对本包根、不带扩展名：

```sh
./豫构。林檎。豫行 构建 标准库测试 数据结构 可选值。测试 --输出 可选值测试.wasm
node 豫言操作系统/宿主/节点/宿主.cjs 可选值测试.wasm
```

本包有若干预期失败的回归样例（同组带 `。失败` 期望的源文），不能把全部源码一律当作应能构建成功的目标。

## 维护

新增测试放在对应的子目录；修改包身份或依赖时同步更新包配置。

`寓所/附庸真径。测试。豫` 用家目录的符号链接别名与合成的附庸（挂载表）核对路径查询和迁（切换工作目录）的表外错误。行在（运行环境）采用当前共用实例，目录与端口配置原样保留。参数“旧程 程序路径”让相同环境运行改前程序，便于核对改前失败、改后通过。挂载表的合成分支集中在客体二号（执行器）的 `附庸表外。底层。测试。豫`，探有（探查路径是否存在）测试核对实有之卷、目录与缺失候选。
