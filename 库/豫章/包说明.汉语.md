# 标准库

`形制/文章` 的删首（前缀删除）与删尾（后缀删除）核对指定的前后缀：`「删首」于「首文」曰『底』于「其文」曰『底任』` 返回包着『任』的可有；失配返回可无，由调用方用鉴处理。删尾的标签为「尾文」「其文」。空前后缀匹配任意字符串，匹配只删除一次。去首（按字数删头）与去尾（按字数删尾）继续按首参的字符数截取，供明确需要按数量删除的调用使用。

异步调度每十六次调度入口以零超时检查已登记的输入输出等待，事件就绪的任务进入先入先出队尾。队列持续满载时，前面的任务数有限且每件返回即可保证等待任务最终运行；队列排空时按最早期限阻塞等待。公平规则详见 `御/异步使用说明.汉语.md`。

网络模块的 `数据报协议/交换数据报` 提供一次已连接 UDP 报文交换：服务器为数值地址，端口为一至六万五千五百三十五，等待时限以毫秒计。套接字由实现创建并在成功、超时或失败后关闭；回答来源由已连接套接字核对。操作成功返回完整字节报文，操作失败携带底层错误码。平台实际传输上限按系统错误反馈。

`寓所/使者` 的 `问使` 按当前实例的异步句柄查询资源，返回状态、当前常驻字节的可用爻与数值、操作系统峰值常驻字节的可用爻与数值。单位字节，可用爻为阳时读取对应数值，查询保留句柄供最终收取。采样最大值由等待者单独累计，超时和观测超限由调用方分别归因。macOS 查询复用纯豫言底层核心；其他平台资源后端列为后续事项。

`寓所/使者` 的 `趣使` 限时运行子进程：限秒与宽限以秒计，到期先召回请其退出，宽限过后仍不退再召回强制终止；返回是否超时、退出码、标准输出与错误输出，超时退出码记为一百二十四。

`寓所/使者` 的 `趣使于境` 是 `趣使` 的带目录与环境版本：工作目录为空文时承本进程的当前目录，环境为空文时承本进程的环境，否则是若干以零结尾的“名=值”连成的环境块、整块替换子进程的环境；两项都为空文时用普通启动，其余照 `趣使`。

异步模块提供单调毫秒截止时间：`遣可待截至`设置绝对期限，`遣可待限时`设置从创建时起算的相对期限。`遣可待截至善后`在成功、异常和到期后调用一次同步清理。协作调度在步骤与输入输出观察点检查到期状态，多路等待采用最早期限；到期任务保存`异步任务超时`失败并移出等待集合。连续计算步骤的抢占列为后续事项。完整规则见`控制/异步使用说明.汉语.md`。

子进程模块提供 `终止异步子进程(句柄)`，按本实例登记的异步句柄请求强制终止，随后由收取服务读取退出结果。结果码为 0 成功、8 句柄无效、29 宿主失败、58 当前平台暂不支持。工具节点与原生执行器已有实现；裸机动态任务与应用宿主异步能力列为后续事项。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 使用

在仓库根目录运行：

```sh
./豫构。林檎。豫行 检查 标准库
```

依赖及说明路径以 [包配置](标准库。包。豫) 为准。

标准库的默认导入是 14 个前置模块：语言核心的 `本类`、`然诺`、`匣椟`、`祸福`；数据结构的 `次第`、`文章`、`爻术`、`筹算`、`小数术`、`有无`、`簿录`、`对偶`；控制的 `缓算`；输入输出的 `笔`。`寻观「豫章」之书。` 把这些模块的名字纳入未限定名称查找，`寻「豫章」之书。` 把命名空间 `豫章` 绑定到它们，`标准库之f` 在这些模块里逐个查找。其他标准库模块显式导入，如 `寻观「豫章」之「形制」之「帛书」之书。`。使用模块命名空间的写法（如 `字典术之f`）时，显式写 `寻「豫章」之「形制」之「簿录」之书。`；命名空间取路径末段的名字，直接写 `字典术之f`。

`寓所/阡陌` 拼接路径时一律用正斜线，轩窗上也一样（执行器的内部路径写作 `/C:/a/b`，宿主写文件补建上级目录时也只认正斜线，而 Windows 的文件接口两种斜线都收）；取父目录、取末段名把正斜线与反斜线都当分隔符，所以外部给的 `D:\子项` 照样能拆，父目录是 `D:\`，`D:\` 自身没有父目录。绝对路径判断接受盘符后接正斜线或反斜线。宿主写法与执行器写法由 `归径`、`示径` 互转：`归径` 把宿主写法归成执行器写法（轩窗上反斜线改正斜线、盘符前补前导正斜线），`示径` 把执行器写法示成宿主写法（轩窗上去掉盘符前的正斜线、正斜线改反斜线），别的宿主都原样返回；程序收到用户给的路径先归径，再判绝对路径、拼接，印给用户看、写进报告的路径先示径（2026-10-26，议题 813）。`名号避讳` 把路径转成标识符或缓存目录名（`-`、`。`、`.`、`/`、`\`、`:`、`*`、`%`、`+` 都换成下划线），供模块全局名、工作树号与共享缓存根里的目录取名；实现在 `寓所/阡陌`，译场 `译程具` 的同名函数转调它，营造与豫构也直接用它。

`寓所/水土` 除 `问俗`、`风俗` 外，另给出宿主的两处目录与宿主用户名，都收参数、不读环境的核心各有一个纯函数，测试在任何宿主上都核得到各分支（2026-10-27）。`暂居` 返回宿主临时目录，给一次性的东西用（林檎、林纳与豫言操作系统上取环境变量 `TMPDIR`，轩窗上依次取 `TEMP`、`TMP`，都没有时是 `USERPROFILE` 下的 `AppData/Local/Temp`，再都没有是 `/tmp`），算法在 `暂居视`。`宿根` 返回一个机器上稳定、按用户分开的基目录，给要跨进程、跨工作树共用的东西用：林檎、林纳与豫言操作系统上是 `/tmp`（与旧法逐字相同，换链不冷编），轩窗上是 `LOCALAPPDATA`（没有则由 `USERPROFILE` 接 `AppData/Local`，再都没有是 `/tmp`）；不取 `TMPDIR`、`TEMP` 是有意的：它们随进程的起法而异（ssh、launchd、screen 里起的各不相同，林檎上 ssh 会话常没有 `TMPDIR`），将作与客、各工作树会算出不同的根，缓存就分家，且 macOS 会定期清 `/var/folders` 下的旧文件；算法在 `宿根视`。`户名` 返回宿主用户名（`USER`，再 `LOGNAME`，Windows 上再 `USERNAME`，都没有是空串，由调用方定缺省），算法在 `户名视`。`宿根分目` 把这两项拼成 `<宿主常居基目录>/<名>-<宿主用户名>`（用户名为空用“默认”，有值先经 `名号避讳`），共享缓存根的缺省就是它取 `豫构缓存`，算法在 `宿根分目视`。临时目录与常居基目录的值都经 `归径视` 化成执行器写法、去掉末尾斜线。`俗径` 按名读一个给路径的环境变量并归径，读 `豫言缓存目录`、`豫言根目录`、`豫言行在目录`、`豫言附` 这类变量都用它：轩窗上用户多半把环境里的路径写成宿主写法（`D:\目录`），不归径会被当成相对路径接到当前目录后面。`问数俗` 按名读数值环境变量：没设或设为空串得 `可无`，设了整数得 `可有` 其值，设了而不是整数就告祸（消息写明变量名、原值与单位），读 `豫言行在内存上限`、`豫言将作槽数` 这类变量一律用它，写错的数不再悄悄当成零；严格解析在 `形制/文章` 的 `析整数`：去掉两端空白后整串须是十进制整数，以六十四位为界，与只读开头数字的 `识数` 分开（2026-10-28，议题 1271）。

`寓所/附庸` 判断绝对路径在附庸表（挂载表，环境变量 `豫言附庸`）之外，并给出报错文字，供开发命令与壳的文件命令把“路径不存在”改说成“不在附庸表里”，提示 `豫言附`、`豫言全宿主`（2026-10-20，议题 150；2026-10-22，议题 305 起壳的文件命令也用它）。判表外的规矩与执行器「附庸根径」「附庸外记」同法：最长前缀相配的一行是“/”、宿主一头又正是私有根（豫言行在目录 有值时是它接 `/根`，否则 HOME 接 `/.豫言/行在/根`；都没有为没有私有根）时才算影子根，路径比“/”长则为表外；没有私有根时“/”行不算影子根，所以造盘预编前导的虚根表（只有“/”映到虚根目录）里一切路径都不算表外（2026-10-27，议题 1033：原先只看宿主一头不是“/”，虚根里每次「探有」都答没有，迁移名单找不到，预编前导报缺标签）。判断本身在不读环境的 `附庸表外视` 里，`附庸表外` 只从环境取表与私有根。原生程序读、写文件失败而错误码为 44（不存在）、路径又落在附庸表外时，执行器在这句报错（2026-10-26 起读失败抛出可接的豫言异常，议题 723）末尾另加一句“（不在行在附庸表内：可设 豫言附=<所在目录>，或 豫言行在=关）”，与这里的判断相同（2026-10-23，议题 363）。

`形制/次第` 的 `排` 是稳定归并排序，收一个“甲应先于乙”的比较函数与一个列；`排文` 是按字节序排字符串的简写；`计重` 按相等比较函数数出每个不同元素各出现几次，返回（元素，次数）列，次序按首次出现。`寓所/藏书` 的 `大小` 返回文件的字节数（目录为零），只问文件状态，不读正文（2026-10-23，议题 468）。`迁` 切换进程的当前工作目录，返回 `成否`（成功载荷为元，失败载荷是 `迁误`：无此径、非目录、表外、无权、他故，他故带错误码与宿主说明）；先核附庸表与 `实有`、`为箧`，路径落在附庸表（挂载表）外时答 `迁表外`、不问东道，与列目等文件操作同一句，提示 `豫言附`、`豫言全宿主`（2026-10-28，议题 1247、1262）。`迁误文` 把它写成给人看的报错文字；`迁须` 供把切换失败当作致命错误的调用方使用（失败时抛出可接的豫言异常）。结果是 `成否`，要鉴开成败或往上传，不能丢。`探有` 在绝对路径落在附庸表外时径答“没有”、不去问宿主，供往上找仓根、找配置文件这类探找用，免得执行器把每次越过附庸边界的试探都印成“路径不在行在附庸表内”（2026-10-26，议题 812）。

`形制/往复` 收三个循环组合子：`复` 倒数，给次数、每步与初值，自次数减到零，每减一次以当前值施一步，次数为零或负时一步不做；`候至` 反复做，直到条件成立，条件先按初值问一遍，一开始就成立则一步不做；`迭` 带初值的一般循环，先问是否继续，继续则以每步的结果再问，返回不再继续时的值。三者都尾递归，调用栈不随次数增长；停的次数与“是否继续”的比较写在库里，调用方只写每一步做什么，写不出方向比较，也不会漏掉入口调用（议题 702、1113、1046）。用时显式导入：`寻观「豫章」之「形制」之「往复」之书。`

`形制/成亏` 收结果类型 `成否`：`成` 带成功的值，`误` 带失败的缘由，缘由由各库立成自己的枚举类型，不用整数、空串或哨兵值；`既成` 把几步可失败的操作串起来，成了接着做，误了原样传出，后一步不跑。可失败的原语、库接口与壳命令逐步改为返回它（提案 00057）。用时显式导入：`寻观「豫章」之「形制」之「成亏」之书。`

`形制/量` 提供带单位的量 `量` 与刻 `刻`：二者都以一个「数」加一个单位类型参数构成，是带参数的抽象类型；单位是空类型，如 `逻辑素`，由各领域的库自己立，本模块只立量与刻。`量` 表示一段有单位的多少，同单位的两个量用 `量加`、`量减`、`量小于`、`量等于` 相合、相减、比大小；`量倍` 把量乘以数，`量析` 把量除以数，都得同单位的量。`刻` 表示一个点：`刻差` 把两个刻相减，得二者相距的量；`刻进` 把量加到刻上、`刻退` 把量从刻上减去，都得新的刻；两个刻之间只有 `刻差` 这一种组合。`作量`、`作刻` 造值，`量值`、`刻值` 取值，只换类型，不做换算；跨单位的换算由调用方明写的一处换算函数完成。量与刻的构造器只在模块内可见（提案 00060）。用时显式导入：`寻观「豫章」之「形制」之「量」之书。` 开销现状：在“单构造器单字段不装箱”合入之前，每个量、每个刻都装箱一次，同单位的简单运算比直接对「数」用「加」多一次拆箱与一次装箱。

`形制/同生` 把一段工作包进一个作用域：`同生` 接收一个以主为参的函数，先造一个主，在其中用 `托` 把一项资源连同它的关法（一个收 `元` 的函数，资源由关法自己裹住）登记到主名下，登记时给一个名字；出作用域时按登记的逆序把没交出的资源一并关掉，正常返回与抛出事故两条出路都收尾，事故先收尾再把原消息照原样抛出。要长期留用的资源用 `交出` 明着交给别的主：原作用域收尾时跳过它，由新主在它自己的作用域结束时关掉。`托` 返回一张券：交出以后再用报“已交出”，同一张券还两次报“已还过”，消息都带上登记时的名字；`还` 当场归还一项资源。`主` 与 `券` 由签名文件封成抽象类型，模块外造不出、鉴不开（提案 00060）。同一张券可以抄成多份、主也可以作为结果交出来：这两种情形由运行时核对，前者按券里共执的态匣报“已交出”“已还过”，后者在主收尾后再 `托`、再 `交出` 时报“已收主”。用时显式导入。例（关法把次数记进一个匣，出作用域后数一；把 `托` 换成 `交出` 并把主换成外层的，则要等外层收尾才关）：

`形制/简牍` 提供可就地改写的定长字节存储：新建、读写单字节与小端四字节、填充、复制、转字节串，用于逐字节构造画面、位图等大块数据。它与字节串同为 WasmGC 的 i8 数组，操作都在客体内完成，转字节串时复制一份；字节缓冲不可交给宿主。
