# 标准库

网络模块的 `数据报协议/交换数据报` 提供一次已连接 UDP 报文交换：服务器为数值地址，端口为一至六万五千五百三十五，等待时限以毫秒计。套接字由实现创建并在成功、超时或失败后关闭；回答来源由已连接套接字核对。操作成功返回完整字节报文，操作失败携带底层错误码。平台实际传输上限按系统错误反馈。

`寓所/使者` 的 `问使` 按当前实例的异步句柄查询资源，返回状态、当前常驻字节的可用爻与数值、操作系统峰值常驻字节的可用爻与数值。单位字节，可用爻为阳时读取对应数值，查询保留句柄供最终收取。采样最大值由等待者单独累计，超时和观测超限由调用方分别归因。macOS 查询复用纯豫言底层核心；其他平台资源后端列为后续事项。

`寓所/使者` 的 `趣使` 限时运行子进程：限秒与宽限以秒计，到期先召回请其退出，宽限过后仍不退再召回强制终止；返回是否超时、退出码、标准输出与错误输出，超时退出码记为一百二十四。

`寓所/使者` 的 `趣使于境` 是 `趣使` 的带目录与环境版本：工作目录为空文时承本进程的当前目录，环境为空文时承本进程的环境，否则是若干以零结尾的“名=值”连成的环境块、整块替换子进程的环境；两项都为空文时用普通启动，其余照 `趣使`。

异步模块提供单调毫秒截止时间：`遣可待截至`设置绝对期限，`遣可待限时`设置从创建时起算的相对期限。`遣可待截至善后`在成功、异常和到期后调用一次同步清理。协作调度在步骤与输入输出观察点检查到期状态，多路等待采用最早期限；到期任务保存`异步任务超时`失败并移出等待集合。连续计算步骤的抢占列为后续事项。完整规则见`控制/异步使用说明.汉语.md`。

子进程模块提供 `终止异步子进程(句柄)`，按本实例登记的异步句柄请求强制终止，随后由收取服务读取退出结果。结果码为 0 成功、8 句柄无效、29 宿主失败、58 当前平台暂不支持。工具节点与原生执行器已有实现；裸机动态任务与应用宿主异步能力列为后续事项。

提供豫言语言核心、数据结构及操作系统接口。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 使用

在仓库根目录运行：

```sh
./豫构。林檎。豫行 检查 标准库
```

依赖及说明路径以 [包配置](标准库。包。豫) 为准。

标准库的默认导入是 15 个前置模块：语言核心的 `本类`、`然诺`、`匣椟`、`祸福`；数据结构的 `次第`、`次第`、`文章`、`爻术`、`筹算`、`小数术`、`有无`、`簿录`、`对偶`；控制的 `缓算`；输入输出的 `笔`。`寻观「豫章」之书。` 把这些模块的名字纳入未限定名称查找，`寻「豫章」之书。` 把命名空间 `豫章` 绑定到它们，`标准库之f` 在这些模块里逐个查找。其他标准库模块显式导入，如 `寻观「豫章」之「形制」之「帛书」之书。`。使用模块命名空间的写法（如 `字典术之f`）时，显式写 `寻「豫章」之「形制」之「簿录」之书。`；命名空间取路径末段的名字，直接写 `字典术之f`。

`寓所/阡陌` 拼接路径时一律用正斜线，轩窗上也一样（执行器的内部路径写作 `/C:/a/b`，宿主写文件补建上级目录时也只认正斜线，而 Windows 的文件接口两种斜线都收）；取父目录、取末段名把正斜线与反斜线都当分隔符，所以外部给的 `D:\子项` 照样能拆，父目录是 `D:\`，`D:\` 自身没有父目录。绝对路径判断接受盘符后接正斜线或反斜线。

`寓所/附庸` 判断绝对路径在附庸表（挂载表，环境变量 `豫言附庸`）之外，并给出报错文字，供开发命令与壳的文件命令把“路径不存在”改说成“不在附庸表里”，提示 `豫言附`、`豫言全宿主`（2026-10-20，议题 150；2026-10-22，议题 305 起壳的文件命令也用它）。原生程序读、写文件失败而错误码为 44（不存在）、路径又落在附庸表外时，执行器在这句报错末尾另加一句“（不在行在附庸表内：可设 豫言附=<所在目录>，或 豫言行在=关）”，与这里的判断相同（2026-10-23，议题 363）。

`形制/次第` 的 `排` 是稳定归并排序，收一个“甲应先于乙”的比较函数与一个列；`排文` 是按字节序排字符串的简写；`计重` 按相等比较函数数出每个不同元素各出现几次，返回（元素，次数）列，次序按首次出现。`寓所/藏书` 的 `大小` 返回文件的字节数（目录为零），只问文件状态，不读正文（2026-10-23，议题 468）。

`形制/简牍` 提供可就地改写的定长字节存储：新建、读写单字节与小端四字节、填充、复制、转字节串，用于逐字节构造画面、位图等大块数据。它与字节串同为 WasmGC 的 i8 数组，操作都在客体内完成，转字节串时复制一份；字节缓冲不可交给宿主。

`本原/本术`（文件 `原语。内建。豫`）声明编译器提供的语言原语：引用与数组、不安全转换、整数与小数运算，以及字符串、字节串与字节缓冲的操作，都由编译器就地生成指令或调用客体内的运行时函数。`东道`（`宿主。接口。豫`）与 `东道带列`（`宿主带列。接口。豫`）声明标准库要宿主提供的服务（标准流、文件、进程、时间、随机、网络等），编成导入模块“标准库”的带类型导入，共九十七个函数（2026-10-21 加「读墙钟秒毫」「设墙钟偏移」「注起居」供网络对时用，2026-10-22 加「读墙钟偏移」供对时在当前偏移上累加，2026-10-23 加「提句柄上限」供长挂程序提高句柄上限、「辞行在」供构建类程序留在宿主命名空间里而不必另起子进程、「置箧」建目录（缺的上级一并建）「删箧」删空目录与「改权」改权限位，让程序不必起 mkdir、rmdir、chmod 宿主命令，「问负载」「问开机秒」与「问主机名」取一、五、十五分钟的平均负载、开机以来的秒数与主机名，让程序不必起 sysctl、uptime、hostname 宿主命令或自己读 /proc，「问使众」按子程序句柄量它连同全部子孙进程的常驻内存之和，供构建服务按自家代役进程树的实测常驻折算占槽，2026-10-24 加「卷大小长」按状态块里 st_size 的八个字节取六十四位卷长，供 4 GiB 以上的大文件，同日的第二段让「藏书」之「卷大小」改走它；「问权」读状态块里的 st_mode 低十二位，让「详目」印出权限而不必起 stat 或 ls 宿主命令，2026-10-24 加「遣离使」在新会话中异步启动子进程，供构建服务「将作」与行在在后台起自己，不再循 PATH 找宿主的 setsid 程序（#479、#545））；用到列的九个函数单独成文，免得模块成环。标准库的公开函数都改调这三个模块；一般程序通过这些公开函数使用宿主服务，需要直接调用时显式导入。

`本原/匣椟` 提供可变引用与可变数组的新建、读写与计长：`置匣列` 先接初值后接长度，`读匣列` 与 `写匣列` 按下标存取，`计匣列` 取数组的格数，空数组得零，与 `计帛`、`计牍` 成套。数组建成后长度不再改变，写改各格也不改变它。

`形制/筹算` 除加减乘除与比较外，还有取余（截断余数，符号随被除数）、正余、位与、位或、位异或、位非、左移、右移（补符号位）、无符号右移、循环左移、循环右移、前导零数、末尾零数、置位数、不大于、不小于、无符号小于、无符号大于、无符号除、无符号余、小者与绝对值。`形制/小数术` 提供小数等、小数不等、小数小于、小数大于、小数小等、小数大等、小数是非数、小数最小、小数最大、小数绝对值、小数取负、小数复号、小数向上取整、小数向下取整、小数截断、小数就近取整与小数开方，名字都带“小数”前缀，与整数操作一样由默认导入无限定提供；小数四则仍在 `形制/分厘`，显式写 `寻「豫章」之「形制」之「分厘」之书。` 后用限定名（如 `小数操作之f`）。`算术/变通` 另有小数饱和转整数（非数得零，越界取极值，不陷阱）、无符号整数转小数、小数位与位转小数。这些都由编译器就地生成指令，语义见《执行与编译》编四。
