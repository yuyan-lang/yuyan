# 标准库

`形制/文章` 之删首（前缀删除）、删尾（后缀删除），先校首尾之文：`「删首」于「首文」曰『底』于「其文」曰『底任』`，还可有而裹『任』；异则还可无，呼者鉴而处之。删尾之签曰「尾文」「其文」。首尾文空，则诸篇皆合；合则惟删一次。去首（按字数删头）、去尾（按字数删尾），仍循前篇字数而裁，供按量去字者用之。

网络之「数据报协议/交换数据报」行一次已连 UDP 报文交换：服务器用数值址，端口一至六万五千五百三十五，候期以毫秒计。实现造柄，成败与期尽皆闭之；连柄验答之来源。成则还全字节报文，败载底码；平台实限依系统之误而告。

`寓所/使者` 之 `问使` 循今实例异步柄询资源，返状态、今常驻字节之可用爻与数、系统峰常驻字节之可用爻与数。单位字节，爻阳乃取其数，询犹存柄以待终收。采样最大由候者别计，逾时与实见逾限各归其因。林檎之询复用纯豫言底层核；余平台资源后端留后。

`寓所/使者` 之 `趣使` 限时行子程：限秒与宽限以秒计，期届先召回以请其退，宽限过后未退则再召回而强止之；还超时与否、退码、常出与误出，超时退码记一百二十四。

`寓所/使者` 之 `趣使于境` 乃 `趣使` 之带居与俗者：所居空则承本程之今居，环境空则承本程之俗，否则零终“名=值”之块尽易子程之俗；二者皆空则以常法起，余同 `趣使`。

异步模块供单调毫秒截止时：`遣可待截至`定绝对期，`遣可待限时`自生时计相对期。`遣可待截至善后`于成、异、到期后施同步清理一次。协作调度于步骤及输入输出之观察处验到期，众路候取最早之限；到期任务藏`异步任务超时`之败而去其候项。连续计算步骤之抢占列为后续。全则见`控制/异步使用说明.文言.md`。

子进程模块供 `终止异步子进程(句柄)`，循今实例所录之异步柄请强止，继由收取之服读退果。码零成、八柄无效、二十九宿主败、五十八今平台未支持。工具节点与原生执行器已有实作；裸机动态任务与客宿主异步之能列为后续。

提供豫言语言核心、数据结构及操作系统接口。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包可供他包所依，观书须先书包名，继书包内路径。无默认程序入口，试例须明指其书。

在仓库之根行 `./豫构。林檎。豫行 检查 标准库` 以验其籍。

标准库之默认导入，凡十四前置之模：语言核心之 `本类`、`然诺`、`匣椟`、`祸福`；数据结构之 `次第`、`文章`、`爻术`、`筹算`、`小数术`、`有无`、`簿录`、`对偶`；控制之 `缓算`；输入输出之 `笔`。书 `寻观「豫章」之书。`，则纳此诸模之名于无限定之名查找；书 `寻「豫章」之书。`，则以名空间 `豫章` 统之，`标准库之f` 于诸模逐一求之。余标准库之模显导入之，若 `寻观「豫章」之「形制」之「帛书」之书。`。用模块名空间之法（若 `字典术之f`），显书 `寻「豫章」之「形制」之「簿录」之书。`；名空间取径末之名，直书 `字典术之f`。

`寓所/阡陌` 合径皆用正斜，轩窗亦然（径内作 `/C:/a/b`，补建上级亦惟正斜是认，而轩窗之文书两斜皆受）；父径、末名兼认二斜，故外入之 `D:\子项` 犹可拆，父径为 `D:\`，盘根自身无父。验绝对径，盘符后之正反斜线皆受之。宿主之写法与执行器之写法由 `归径`、`示径` 互转：`归径` 纳宿主之写法于执行器（轩窗上反斜尽改正斜，盘符之前补一前斜），`示径` 还执行器之写法于宿主（轩窗上去盘符之前斜，正斜尽改反斜），余土皆原样而还；程序受人之径先归之，而后辨其全、合其径，印以示人、书于报者先示之（十月二十六日，议题八一三）。`名号避讳` 以径为名，不宜入名之字（`-`、`。`、`.`、`/`、`\`、`:`、`*`、`%`、`+`）皆代以下划线，供模之通名、树号与共储根中之目名；实在 `寓所/阡陌`，译场译程具之同名者转调之，营造与豫构亦径用之。

`寓所/水土` 于 `问俗`、`风俗` 之外，另予暂目、基目与户名，三者之核皆受参而不读环境，故试者于诸土皆核其支（十月二十七日）。`暂居` 还宿主之暂目，供一时之用（林檎、林纳与豫言之土取环境 `TMPDIR`，轩窗依次取 `TEMP`、`TMP`，皆无则为 `USERPROFILE` 下之 `AppData/Local/Temp`，再无则 `/tmp`），法在 `暂居视`。`宿根` 还一机之上稳定、依户而分之基目，供跨程、跨工作树共用者：林檎、林纳与豫言之土为 `/tmp`（与旧法逐字同，易链不冷编），轩窗为 `LOCALAPPDATA`（无则由 `USERPROFILE` 接 `AppData/Local`，再无则 `/tmp`）；不取 `TMPDIR`、`TEMP` 者有意也：二者随程之起法而异（ssh、launchd、screen 中所起各不同，林檎 ssh 之会常无 `TMPDIR`），将作与客、诸工作树所算各异，缓遂分家，且林檎按期涤 `/var/folders` 之旧文；法在 `宿根视`。`户名` 还宿主之用户名（`USER`，次 `LOGNAME`，轩窗再现 `USERNAME`，皆无则空文，由呼者定其缺），法在 `户名视`。`宿根分目` 缀为 `<宿根>/<名>-<户名>`（户空则“默认”，有则先经 `名号避讳`），共储之根之缺即取其 `豫构缓存`，法在 `宿根分目视`。暂目与基目之值皆经 `归径视` 化为执行器之写法、去其末斜。`俗径` 依名取予径之环境项而归之，凡 `豫言缓存目录`、`豫言根目录`、`豫言行在目录`、`豫言附` 之类皆用之：轩窗之上人书径多作宿主之式（`D:\目录`），不归则以为相对而缀于今目之后。`问数俗` 依名问数值之俗：未设或设为空文则 `可无`，设而为数则 `可有` 其值，设而非数则告祸（辞书其名、原值与单位），凡读 `豫言行在内存上限`、`豫言将作槽数` 之类皆用之，写错之数不复潜为零；严析在 `形制/文章` 之 `析整数`：去两端空白后全篇须为十进之数，以六十四位为界，与惟读首数之 `识数` 分（十月二十八日，议一二七一）。

`寓所/附庸` 辨绝径在附庸之表（挂表，环境 `豫言附庸`）之外，并出其误文，以供开发之命与壳之文件命改其辞、示附入之二俗（十月二十日，议题百五十；十月二十二日，议题三百五起壳之文件命亦用之）。判表外之法与执行器「附庸根径」「附庸外记」同：最长前缀之行为“/”而宿端正为私根（设 豫言行在目录 则其目接 `/根`，否则家目接 `/.豫言/行在/根`；皆无则无私根）乃为影根，径长于“/”则为表外；无私根则“/”行不为影根，故造盘预编前导之虚根表（惟“/”映虚根之目）中一切径皆不算表外（十月二十七日，议千三十三：旧惟视宿端非“/”，虚根之中每探皆答无，迁移之单不得，预编之前导报缺签）。判之本在不读境之 `附庸表外视`，`附庸表外` 惟取今俗之表与私根。原生之程读书而败、误码为四十四（不存在）而径在表外者，执行者于此误辞之末另加一句“（不在行在附庸表内：可设 豫言附=<所在目录>，或 豫言行在=关）”，与斯判同（十月二十三日，议题三百六十三）。

`形制/往复` 收循环之合三：`复` 者倒计而施，受次数、每步与初值，自次数减一而步一，至零而止，数零若负则一步不施；`候至` 者待其成，先以初值问之，阳则径还，否则施每回而复问；`迭` 者缘初值而递进，先问续，阳则施每步而复问，阴则还其今值。三者皆尾递，栈不随数长；止之数、续之校皆在库，呼者惟书一步之事，无由书其向，亦无由漏其入口（议题七百零二、一千一百一十三、一千零四十六）。用之则显导：`寻观「豫章」之「形制」之「往复」之书。`

`形制/成亏` 收成否之类：`成` 裹所获，`误` 题其由；由者，各库自以其枚举当之，不以整数、空文、哨兵充数。`既成` 缀诸步：成则付之后术，误则原样而传，后术不施。可败之原语、库之接口与壳之命渐改而还之（提案〇〇〇五七）。用之则显导：`寻观「豫章」之「形制」之「成亏」之书。`

`形制/量` 供带单位之量与刻：二者皆以一「数」加单位之类参而成，为带参之抽象类；单位为虚类，若 `逻辑素`，各库自立之，此篇惟立量与刻。`量` 表一段有单位之多少，同单位之二量以 `量加`、`量减`、`量小于`、`量等于` 相合、相减、相较；`量倍` 以数倍量，`量析` 以数析量，皆还同单位之量。`刻` 表一点：`刻差` 减二刻而得相距之量；`刻进` 加量于刻、`刻退` 减量于刻，皆得新刻；二刻之间惟 `刻差` 一合。`作量`、`作刻` 造之，`量值`、`刻值` 取之，惟易其类，不为换算；易单位者由调用之处书一换算之函而成。量与刻之构惟篇内可见（提案〇〇〇六〇）。用时显导：`寻观「豫章」之「形制」之「量」之书。` 开销之状：于“单构单田不装箱”合入之前，每一量、每一刻皆装匣一次，同单位之简算较径以「数」用「加」多一拆一装。

`形制/简牍` 供定长可改之字节藏：造、一字与小端四字之读写、填、抄、转字节串，以逐字造画面、位图诸大块。与字节串同为 i8 之数组，诸术行于客内，转字节串则抄之；勿交宿主。

`本原/本术`（文 `原语。内建。豫`）声编译器所供之原语：引与数组、不安全转换、整数小数之算，及字符串、字节串、字节缓冲之操，编译器就地生令，或调客内运行时之术。`东道`（`宿主。接口。豫`）与 `东道带列`（`宿主带列。接口。豫`）声标准库所求于宿主之务（标准流、文件、进程、时、随机、网络等），编为导入模块“标准库”之带型导入，凡一百一十三函（十月二十一日加「读墙钟秒毫」「设墙钟偏移」「注起居」为网络对时之用，十月二十二日加「读墙钟偏移」供对时于今偏之上累加，十月二十三日加「提句柄上限」供长挂之程广其纳物之数、「辞行在」使构建之程留于宿主之域而无须别起子程、「置箧」立目（缺之上级并立）「删箧」去其空目与「改权」易其权位，使程无须起 mkdir、rmdir、chmod 宿主之命，「问负载」「问开机秒」与「问主机名」取一、五、十五分均负、开机以来之秒数与主机之名，使程无须起 sysctl、uptime、hostname 宿主之命或自读 /proc，十月二十四日加「卷大小长」依状块 st_size 之八字取六十四位卷长，供二之三十二次方字节以上之大卷，同日之次段令藏书之「卷大小」改行之；同日加「卷占」一问兼示类与实占，供量箧按实占遍历时每条只问一次；「问权」读状块 st_mode 之低十二位，使「详目」印其权而无须起 stat 或 ls 之宿主命，十月二十四日加「遣离使」于新会之中异步启子程，供将作与行在之后台自立，不复循 PATH 求宿主之 setsid 程（议四七九、五四五）；十月二十六日加「遣离使于卷」，同其起法而二出尽续于卷末（缺之上级并建），供将作与行在之后台自立时以误报（含执行器硬中止之报）存于会所下之 `将作.输出`、`行在.输出`（议六五九）；十月二十五日加「问号实占」「问号父」二术，依号问实占与父号，令行在依号量本机诸豫言之程而无须起 ps，又加「辞附庸」撤附庸而犹居行在，供构建之命登记而不附庸，再加「定缺存」使程自择缺存之法（窖、候、止），供执行器依块向行在领存时用（提案〇〇〇五六）；十月二十六日加「遣使于境离」「散组」二函：前者在东道带列，使将作以新会起代役；后者使代役退前朝己群发一信，收常驻之工、原生之产子程与其分片之工而尽召之（议题六五四）；十月二十七日加「遣信」一函：依异步子程之柄发十五 SIGTERM 或九 SIGKILL、交回程号，供将作收逾截止不退之代役（议题一千零二十四）；十月二十八日加「退额」「领额」二函：尽以所领之整份行在仓额还之、将用内存则依实跨复领，供构建前端候译器子程、整客远行之客候彼做完之时不占仓（议一千二百零八））；用列之十二函别为一文，免模成环。标准库之公函皆改调此三模；常程由公函用宿主之务，欲径调则显导入之。

`本原/匣椟` 供可变引用与可变数组之造、读写与计长：`置匣列` 先受初值后受长，`读匣列` 与 `写匣列` 按序存取，`计匣列` 取列之格数，空列得零，与 `计帛`、`计牍` 成套。列成而后长不易，写易诸格亦不改其长。

`形制/筹算` 加减乘除与较之外，又有取余（截断之余，号随被除数）、正余、位与、位或、位异或、位非、左移、右移（补号位）、无符号右移、循环左移、循环右移、前导零数、末尾零数、置位数、不大于、不小于、无符号小于、无符号大于、无符号除、无符号余、小者与绝对值。`形制/小数术` 供小数等、小数不等、小数小于、小数大于、小数不大于、小数不小于、小数是非数、小数最小、小数最大、小数绝对值、小数取负、小数复号、小数向上取整、小数向下取整、小数截断、小数就近取整与小数开方，名皆冠以“小数”，与整数操作同由默认导入无限定而供；小数四则仍在 `形制/分厘`，显书 `寻「豫章」之「形制」之「分厘」之书。` 而后用限定之名（若 `小数操作之f`）。`算术/变通` 又有小数饱和转整数（非数得零，越界取其极，不陷）、无符号整数转小数、小数位与位转小数。皆编译器就地生令，其义见《执行与编译》编四。

`形制/次第` 之 `排` 为稳之归并排序，受“甲当先于乙”之较术与一列；`排文` 乃依字节排串之简；`计重` 依相等之术数诸异者各现几次，还（物，次）之列，次依初见。`寓所/藏书` 之 `大小` 还文之字节数（目则零），惟问其状，不读其文（十月二十三日，议四百六十八）。`迁` 易进程之今目，还 `成否`（成则裹元，败则裹 `迁误`：无此径、非目录、表外、无权、他故，他故载误码与宿辞）；先核附庸之表与 `实有`、`为箧`，径在附庸表外则答 `迁表外`、不问东道，与列目等文件之命同一句，示 `豫言附`、`豫言全宿主`（十月二十八日，议一二四七、一二六二）。`迁误文` 书之为示人之误辞；`迁须` 供以败为致命之呼者（败则告可承之祸）。果为 `成否`，须鉴之或上传，不可弃。`探有` 于绝径在附庸表外者径答“无”而不问东道，供上寻仓根、觅配置文件之探找用之，免执行者每越附庸之疆而书表外之告（十月二十六日，议八百一十二）。
