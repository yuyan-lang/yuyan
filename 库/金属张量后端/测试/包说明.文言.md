# 金属张量后端测试

金属张量后端与张量后端之单元之试（`X。测试。豫`）：

- `设备。测试`：以本目之着色源 `仿射。着色器。豫`（依张量内核之绑定之约：绑零为只读参数之区，绑一为数据；构时译为 MSL）验单精之位（1.5、−2.0）；存缓与管线依址、依入口之名而存；二派合一批，未同则数不变，同后数合；参数之区逾四千九十六字则用临时之缓；组数零则不派亦无待交；释存后复取、尽释。无金属则惟书“跳过”。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟供试，依标准库、单元测试、系统库调用、金属、着色库、张量后端与金属张量后端，登于「共用库」之下；唯用于诺节之苹果。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属张量后端测试 设备。测试 --输出 yy金属张量后端测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属张量后端测试.wasm
```
