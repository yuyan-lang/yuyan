# 金属张量后端测试

金属张量后端与张量后端之单元之试（`X。测试。豫`）：

- `设备。测试`：以本目之着色源 `仿射。着色器。豫`（依张量内核之绑定之约：绑零为只读参数之区，绑一为数据；构时译为 MSL）验单精之位（1.5、−2.0）；存缓与管线依址、依入口之名而存；二派合一批，未同则数不变，同后数合；参数之区逾四千九十六字亦合（全段书入派发之环）；组数零则不派亦无待交；又验 Q8_0、Q4_K 惟金属启子组且常规未分块乃择各自双行核，余后端与路仍择旧核，及 M=1、M 奇、N 有尾之双行组数；释存后复取、尽释。无金属则惟书“跳过”。
- `设备。测试` 又核归一多重、归一门控、矩阵乘加、按专家门控四族之金属 Q8_0/Q4_K 双行入口，Q6_K 与网页图算之故入口、中央处理器融合之退路，并验组数之 M=1、M 奇与 N=9 之尾。
- `派发计时。测试`：同一管线、三缓、十六字之参，连记四千派，取每派编之线程 CPU 之时；又测一交候、一派加同之往返、一消息、一书原生、一单精之位。惟书之，不断。
- `开销剖析。测试`：以本线之 CPU 之时逐项量豫言诸语言之操作（空循环、整与小数之算、列与闭包、串较、记录取域、数组引用、字节缓冲、宿主原语、系统库之调）与张量后端诸层（核表之参、参数之字、取管线（依源与入口之名取、依键取）、取存缓、记派，及全逐元二元、解码之形之矩阵乘、均方根归一）之单价。分配之函径予预建之原生之存，不经宿主之张量。惟书之，不断。

## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属张量后端测试 设备。测试 --输出 yy金属张量后端测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属张量后端测试.wasm
```

出之末行“当前失败数”当为零。二计时易入口之段为 `派发计时。测试` 或 `开销剖析。测试` 而构之行之即可。
