# 金属张量后端测试

金属张量后端与张量后端的单元测试（`X。测试。豫`）：

- `设备。测试`：用本目录的着色源 `仿射。着色器。豫`（按张量内核的绑定约定：绑定 0 是只读参数区，绑定 1 是数据；构建时译成 MSL）检验单精位型（1.5、−2.0）；存储缓冲与管线按地址、按入口名缓存；两次派发合进一批，同步前数据不变、同步后数值正确；参数区超过 4 KiB 时走临时数据缓冲；组数为零时不派发也不留待提交；释放存储后重取、释放全部。没有金属时只打印“跳过”。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试、系统库调用、金属、着色库、张量后端与金属张量后端，登记在「共用库」之下；只用于诺节之苹果。

## 使用

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属张量后端测试 设备。测试 --输出 yy金属张量后端测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属张量后端测试.wasm
```

输出末行的“当前失败数”应为 0。
