# 金属张量后端测试

金属张量后端与张量后端的单元测试（`X。测试。豫`）：

- `设备。测试`：用本目录的着色源 `仿射。着色器。豫`（按张量内核的绑定约定：绑定 0 是只读参数区，绑定 1 是数据；构建时译成 MSL）检验单精位型（1.5、−2.0）；存储缓冲与管线按地址、按入口名缓存；两次派发合进一批，同步前数据不变、同步后数值正确；参数区超过 4 KiB 时也正确（整段写进派发环）；组数为零时不派发也不留待提交；并核对 Q8_0、Q4_K 仅在金属启用子组且普通未分块时选各自双行核、其他后端与路径仍选原核，以及 M=1、奇数 M、N 尾列的双行组数；释放存储后重取、释放全部。没有金属时只打印“跳过”。
- `设备。测试` 还核对归一多重、归一门控、矩阵乘加、按专家门控四族的金属 Q8_0/Q4_K 双行入口、Q6_K/网页图算原入口与中央处理器融合回退，并覆盖双行组数的 M=1、奇数 M、N=9 尾列。
- `设备。测试` 还核对半精度与脑浮点普通矩阵向量乘的金属双行 selector；`矩阵与位置。测试` 直接派发该入口，验证 N=5/9、K=35/67 与输出哨兵。
- `派发计时。测试`：同一管线、三个缓冲、16 字节参数区，连记 4000 次派发，取每次编码的线程 CPU 时间；另测一次提交并等待、一次派发加同步的往返、一次消息发送、一次写原生内存与一次单精位型。只打印，不断言。
- `开销剖析。测试`：用本线程的 CPU 时间逐项量出豫言各种语言操作（空循环、整数与小数运算、列表与闭包、字符串比较、记录取字段、数组引用、字节缓冲、宿主原语、系统库调用）与张量后端各层（内核表参数、参数字节、取管线（按源码与入口名取、按键取）、取存储缓冲、记派发，以及整个逐元二元、解码形状的矩阵乘、均方根归一）的单价。分配函数直接给预先建好的原生内存，不经宿主张量。只打印，不断言。

## 包身份

`管线资源。测试` 只创建管线，打印普通块八、双行块八及三族融合内核的静态共享内存字节、最大工作组线程数和线程执行宽度，用于核实资源占用；不派发计算。

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试、系统库调用、金属、着色库、张量内核、张量后端与金属张量后端，登记在「共用库」之下；只用于诺节之苹果。

## 使用

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属张量后端测试 设备。测试 --输出 yy金属张量后端测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属张量后端测试.wasm
```

输出末行的“当前失败数”应为 0。两项计时把入口段换成 `派发计时。测试` 或 `开销剖析。测试` 构建运行即可。
