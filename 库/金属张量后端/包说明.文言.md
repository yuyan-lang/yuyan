# 金属张量后端

此乃张量计算之金属之器：以「金属」之库实「张量后端」之器表（`库/张量后端`）。苹果之芯存统一，宿主张量之存（共享之缓）并其所在之整页零抄裹为金属之缓，CPU 与 GPU 共一存，不上下传。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，依标准库、系统库调用、金属与张量后端，登于「共用库」之下；唯用于诺节之苹果。

## 用法

```yuyan
寻观「金属张量后端」之书。
```

`「取金属张量设备」于「元」` 得「或可有」于「张量设备」：一进程惟建一金属之器与命令之队，诸境共之；无金属（苹果以外之系统、宿主不能调系统库或无器）则可无。得器乃以 `「新建张量后端」于 器` 为每境建后端。

## 实

每十六派终今编码器而先交一段，使 GPU 之行与次段宿主之编相并。诸段犹同一命令之队；参环已用之区、暂缓与自动释放之池，皆留至全批同毕。同步先交余段，候末段，验诸段之态，乃逆次弹池、复用参环而释暂缓。参环满则犹先候全批毕，使旧参不先被覆。

二〇二六年十月三日，pit-mac 之 Qwen3 0.6B Q8_0 短提示解码，由归一独派版之约六十七增至百十一至百十二词元每秒，长提示由五十四点八增至八十二点二；六十四生成之词号逐号同。一千一百次依赖之派跨诸段与二次参环回绕，终果合；设备之试八十六项皆过。详见[本地推理测速](../../应用/人工智能/本地推理/测速.文言.md)。

- 取存之缓：`newBufferWithBytesNoCopy` 裹存 [址, 址 + 字数（补至四之倍）) 所在之整页，惟发此一消息（不取其容之址）；存不在页首者（小共享缓常然）系时带页内之偏。缓号为金属对象之号加页内之偏乘 2⁴⁸（页首齐者即对象之号），后端惟视为不透之号。裹而释之一次约五至十微秒，百二十八 MiB 约四十微秒。
- 记派发：每段用一不留其引之命令缓（commandBufferWithUnretainedReferences：所系之缓由今批暂缓之表与后端之延释保其存至同毕之后，拆时亦不逐释）、算编码器与自动释放之池（串行而派，诸缓依默认之法迹其读写之依），十六派后先交之。每派以二 MTLSize、缓址表、偏表与参区拼为一段，一书入派发之环（四 MiB 共享金属缓）之空处；系零为环中参区，系一、二……为诸张量，一 `setBuffers:offsets:withRange:` 设全；管线同于今段之前者不复设，终 `dispatchThreadgroups:threadsPerThreadgroup:`。环不容则先交候全批，乃自首复用；一派之段逾四 MiB 则事故。
- 交而候之：交余段，以 `waitUntilCompleted` 候同队末段；逐段验误，逆次弹自动释放之池，释全批暂缓，参环自首复用。
- 单精之位：以八字原生暂存书单精，复以三十二位整读之。
- 交回宿主与宿主已改：存统一，无为。

## 解码及拼装缓复测（二〇二六年十月四日）

于 pit-mac，以Qwen3 0.6B Q8_0、短提示“Write a short poem about the sea.”，提示二十词元、贪心生六十四词元：今留版本解码每秒118.11词元；Ollama 0.34.4同模、原始模板、提示二十词元、无提示缓存，六十四评估词元耗300.661毫秒，约每秒212.86词元，犹差约一点八倍。豫言计预填后六十三次前向，录其计数之异。

试复用CPU派发拼装字节缓，初容六十四KiB，不足依需扩；抄入原生派发环即复用，短参首字清零，GPU提交之频及绑不易。候选首轮解码125.26，较先测原版118.11速；交替暖轮原、新为120.09、120.34，反序新、原为121.79、121.66，差不足百分之零点三，初益未复见。三组六十四所生词元皆与原版逐号同。候选源已撤，惟测其速及词元，未谓别数皆验或恒速有增。

今器用串行计算编码器；上层「后端派发」已受所书存址，设备「记派发」回调犹未受之。并发之策须传读写之依赖于器，冲突之资源加屏障，不可径易编码器。新增API之仓库授权犹待答，未实此策。Apple官文言并发编码时共享资源之同步由应用任之：[并发派发](https://developer.apple.com/documentation/metal/mtldispatchtype/concurrent)，[资源屏障](https://developer.apple.com/documentation/metal/mtlcomputecommandencoder/memorybarrier(resources:))。

### 推理并发与所待之障

算编码器以并发派之。同段累可读可写之缓号；今读遇旧写，或今写遇旧读旧写，则设存缓之障，清旧迹而记今派。写缓号零则其信未明，视为相冲。新段清迹。旧器派发入口以诸绑定皆为可写，仍从严序之。十六派先交，全批候毕乃复用参环及暂存，其存亡之约如故。
