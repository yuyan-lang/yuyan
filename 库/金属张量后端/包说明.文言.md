# 金属张量后端

此乃张量计算之金属之器：以「金属」之库实「张量后端」之器表（`库/张量后端`）。苹果之芯存统一，宿主张量之存（共享之缓）并其所在之整页零抄裹为金属之缓，CPU 与 GPU 共一存，不上下传。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，依标准库、系统库调用、金属与张量后端，登于「共用库」之下；唯用于诺节之苹果。

## 用法

```yuyan
寻观「金属张量后端」之书。
```

`「取金属张量设备」于「元」` 得「或可有」于「张量设备」：一进程惟建一金属之器与命令之队，诸境共之；无金属（苹果以外之系统、宿主不能调系统库或无器）则可无。得器乃以 `「新建张量后端」于 器` 为每境建后端。

## 实

- 取存之缓：`newBufferWithBytesNoCopy` 裹存 [址, 址 + 字数（补至四之倍）) 所在之整页；存不在页首者（小共享缓常然）系时以 `setBuffer:offset:atIndex:` 带页内之偏。缓号为金属对象之号加页内之偏乘 2⁴⁸（页首齐者即对象之号），后端惟视为不透之号。裹而释之一次约五至十微秒，百二十八 MiB 约四十微秒。
- 记派发：同批之派皆记于一命令缓之一算编码器（串行而派，诸缓依默认之法迹其读写之依），每批裹于一自动释放之池。参数之区不逾四千九十六字用 `setBytes`，逾则建临时数据之缓；`dispatchThreadgroups` 之二 MTLSize 拼于字节缓冲而一书之。
- 交而候之：终编、交、`waitUntilCompleted`；命令缓有误则事故（附金属之误述）；乃弹池、释今批之临时之缓。
- 单精之位：以八字原生暂存书单精，复以三十二位整读之。
- 交回宿主与宿主已改：存统一，无为。

## 试

`测试/` 下之「金属张量后端测试」包：以本包试目之着色源「仿射」（构时译为 MSL）验单精之位、存缓与管线之存、二派合一批（未同则不行，同后数合）、参数之区逾四千九十六字则用临时之缓、组数零则不派、释存后复取与尽释。无金属则书“跳过”。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 金属张量后端测试 设备。测试 --输出 yy金属张量后端测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy金属张量后端测试.wasm
```
