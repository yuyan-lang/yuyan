# 构建编排

以寻常豫言书构建之目标、所依与诸步，本库并行调度之，据输入跳过已最新者。语言仓之构建目标书于 `应用/豫构/仓库目标。豫`，豫构召本库而行之：于仓根行 `./豫构。林檎。豫行 自举|测试|打包|清理|全部`，或以 `… 豫构.wasm 目标 名…` 行任一目标。他仓则书一构建程序（可执行之包，如云仓之“云仓构建”），列其诸目标，于入口之函「入口」中召 `营程序主术`。仓中不复留 shell 之本。

## 用法

```text
寻观「豫章」之书。
寻观「法式」之书。

「目标们」乃「列」于「营鹄」也。
「目标们」者
　「列」
　【（「目标」
　　　于『甲』 「：名：」
　　　于『构建 甲.wasm』 「：注（--列出 时显之）：」
　　　于（「罄」以「文」） 「：所依目标之名：」
　　　于（「列」【（「令步」于『./豫构.wasm』于（「列」【『文件』，『甲。豫』，『--输出』，『甲.wasm』】））】）
　　　于（「列」【（「文件输入」于『甲。豫』）】）
　　　于（「列」【『甲.wasm』】））
　】
也。

「入口」乃化「有」为「有」者也。
「入口」者得「无」而
　「营程序主术」于「目标们」
也。
```

构建程序之命令行：`程序 [目标…] [-j 并发] [--强制] [--不连带] [--列出]`。不举目标则行名“全部”者；`--强制` 不用缓存；`--不连带` 但行所举之目标（所举之间所依仍守其序）；`--列出` 书诸目标及其注。

## 目标与步

`「目标」于 名 于 注 于 所依 于 诸步 于 输入 于 输出`。同目标之步相继而行；异目标所依既成则并行，其上限依 `-j`（默以在线处理器之数）。命步同步而行，行令之际不复派他步。一步败则止派新步，以非零之码终。

诸步：

- `命令步 程序 参数们`：行外令，参数原样相传，不经 shell；命步同步而行，子程承本程之三流，所言所诉实时可见。
- `目录内命令步 目录 程序 参数们`：于所定之目行之（启时迁目录，启毕即还）。
- `限时命令步 秒数 程序 参数们`：限时而行，逾时先请其退，宽限十秒仍未退则强止之；以「豫章」之 `趣使` 行之，成则二出于步毕而转书，败则随败报而书。
- `函数 注 函数体`：于构建程序中径行一豫言之术；其注入缓存之键。`写文件步 径 文` 本之。
- `摹卷步`、`同步`、`置箧步`、`删步`：常用卷事之函数步，分别以豫章「藏书」（文件系统）中之「拷卷」「同卷」「删树」与豫章「东道」（宿主接口）中之「置箧」行之，不起宿主之令。
- `独占 组名 步`：同组之步依目标之拓扑序逐一而行，不并发。实相冲突之步入同组，如改同一共享之目录、占同一定端口者。编译缓存原子而书，共一编译缓存之豫构可并行；每召已依 `-j` 自并行者，亦可入同组逐一而行，免争处理器。

## 缓存

输入为 `文件输入 径` 或 `目录输入 目录 后缀们 所除片段们`（遍而入之，略点起首之名与 `_v0` 之目；后缀空则皆取）。输入输出俱非空者可缓存：键合诸步之述、诸输入之径与修改之时（整秒）、诸输出之径，书于 `.豫构缓存/构建编排/<目标名>.印`，首行记算键之时。键不变而输出俱在，则报“已最新”而略之；所依之目标重造，其出之时变，下游之键随改。无输入或无输出者，每次皆行。

改时止于整秒：输入于算键之同秒复改，则时不变而键亦不易。故印之首行记算键之整秒，判新旧时改时不早于此者不可信，改以内容之沙二五六重判（键中此行书为“径 摘 沙二五六”）：文同则续用而刷新印之时，异乃须重做。旧格之印无首行，作过期而重做一次。

## 约束

- 本库唯依标准库与构建基础（用其调度器）；非限时之命步同步而行，子程承本程之三流，不张二管：管满而无人排，则子程死等（议三六四）。限时之步以趣使收其二出，由宿主排管；成则步毕而转书，败则随败报而书。
- 标准库无同步设环境而启子程之术（「将使」（异步子进程）之「将咨于境」乃异步者）：须环境变量，则以 `env 名=值 程序 …` 为令。待办事项：同步带境而启子程之术既备，乃改从之。
- 入口启构建之志（见构建基础之构建日志；语言仓由豫构启之），则行目标时录每目标算键之时与跳否、每步之令，及每调度之务入备启毕之刻；启 `.wasm` 之程则裹以 `env 豫言构建日志运行=… 豫言构建日志父项=…`，使子程入同一运行。未启（如云仓之构建程序）则一无所录。
- 修改之时唯精于秒：输入于算键之同秒复改，则时不变，判新旧时此诸入改以内容之沙二五六重判，文异乃重做；印记不可读（旧格）者作过期论。
