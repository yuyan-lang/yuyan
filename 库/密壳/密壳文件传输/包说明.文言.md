# 安全外壳文件传输

纯豫言之安全外壳文件传输（SFTP 第三版，draft-ietf-secsh-filexfer-02，OpenSSH 所用）服务端之库。豫言操作系统之远程登录（`豫言操作系统/应用/远程登录`）于 `subsystem sftp` 之通道用之以办诸请；标准之 `sftp` 与 `scp`（OpenSSH 九版起默循 SFTP）得以上下、续传、改名其文与目录。

## 用法

- `新传文态`（已授目权、起始之目）造一会话之态；客所见之径，皆此目权中以 `/` 起之绝径，起始之目乃 REALPATH 问 `.` 之答。
- `传文入`（态、通道之数）受客所发之字节：攒为完整之包，逐一办之，返（当回之出，会话已终否）；空字节串者，彼已发 EOF，收尾而终会话。
- `传文巡`（态）每轮一呼，续办入缓中未办之包（一批之出至二百五十六 KiB 则止，余者下轮再办），所返同上。
- `传文收尾`（态）连终时呼之，闭诸未闭之柄。

## 所支之操作

- INIT 回 VERSION 三，宣扩展 `posix-rename@openssh.com`（版一）。
- OPEN：惟读（READ）为读柄；书（WRITE）为写柄，可兼 CREAT、TRUNC、APPEND、EXCL；READ 与 WRITE 并给则用 `辟读写卷`，一柄可读可书（带 TRUNC 则开后截为零长）。
- CLOSE、READ（依偏读一块，至多二百五十六 KiB；读书之柄先刷所攒）。
- WRITE：书于所请之偏。偏正接所攒之末则惟攒之，攒足一 MiB 乃真书一次（裸机之大文每书为一 ext4 之事务，攒大块乃速）；不接则先刷所攒，乃自新偏重攒。刷时块起正当文件柄之顺位则顺书（`写卷`），否则定位书（`指写卷`，逾末者补零）。故 `reput` 续传、乱序与多路并传皆书其位。续柄不观其偏。书败则于刷写时报之。
- LSTAT、STAT、FSTAT：经 `问卷详情` 回真长与修改之时（访之时亦填修改之时），权依类取 0755 与 0644；写柄之 FSTAT 先刷。
- SETSTAT、FSETSTAT：属带 SIZE 则设文之长（截之或补零以长之；SETSTAT 可书而开乃设，FSETSTAT 用写柄，读柄回成）；余属回成。
- OPENDIR、READDIR（一次至多六十四项；长名如 ls -l，带真长与修改之时，时以协调世界时书为“年-月-日 时:分”）、REMOVE（普通文）、MKDIR、RMDIR（空目）。
- REALPATH：规范其径，不必存在，行 `.`、`..` 与重 `/`。
- RENAME：经 `更名径` 易名，文与目录皆可，可跨目录；新径已存则依 SFTP 第三版之规回败。扩展 `posix-rename@openssh.com` 亦易名，新径已存则原子代之（OpenSSH 之 `sftp` 见之则用之，故 `rename` 可代已有之文）。
- READLINK、SYMLINK 与他扩展之请，回“未支”（SSH_FX_OP_UNSUPPORTED）；式不合之包，回 SSH_FX_BAD_MESSAGE。

## 文之操

本库惟依豫言操作系统文件之接口（零点七）：目权加相对之径、文件柄、`指读卷`、`指写卷`、`辟覆盖卷`、`辟增卷`、`辟可写卷`、`辟读写卷`、`写卷`、`设卷长度`、`更名径`、`列出箧`、`问卷讯`、`问卷详情`、`置箧`、`删径`。读写皆流式：一 READ 当一次定位读，WRITE 攒为至多一 MiB 之块乃书，存中唯有今之一块，故可传数百 MiB 之系统镜像。径以 UTF-8 字节论，可有中文之名。文件柄之表复用已闭之项，久行之远程登录可无穷开闭其文。

## 验证

于宿主（林檎臂原生）以 OpenSSH 十版之 `sftp` 与 `scp`（默 SFTP 模式）核之：mkdir、put、get、`reput` 续传（先传前二 MiB 乃续传五 MiB 之文，取回而沙256 与原文合）、`rename` 代已有之文（posix-rename）、`rename -l` 遇已有之目则败、目录改名、`ls -l` 示真长与时、中文之名、`scp -r` 递归上下，皆正。协议级之探针 `测试/乱序写入探针。脚本。豫`（宿主上以 `--授权目录写 桌面=目录` 行之）径以请包授 `传文入`，核乱序 WRITE、STAT 之长、读回之容、FSETSTAT 截短、读书同开、posix-rename 之代、旧式 RENAME 之败与目录改名。百 MiB 随机文于十月二十四日之量：`chacha20-poly1305@openssh.com` 下 `sftp get` 二点五至三点二秒（约每秒三十三至四十二兆）、`scp` 下二点九秒、续传之上（`put -a`，远端先置小文）二点五至三点五秒；`aes256-gcm@openssh.com` 下 `sftp get` 十点五秒、续传上十点五秒（约每秒十兆）。取回之沙256 与原文合；续传之上依续传之义核之（远端为小文加源文自其长起之余段），亦合。加密之法依客所陈两皆能之首而议，本机 OpenSSH 十版首列 AES-GCM 而非恰恰封。宿主原生之覆盖新建（不续传之 `put`、`scp` 之上）犹缺宿主原语百二十六（辟覆盖卷），乃本轮前已有之阙，待补。
