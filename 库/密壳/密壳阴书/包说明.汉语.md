# 安全外壳密码

`求已知主机密钥杂凑码沙一` 使用 20 字节盐计算主机名 HMAC-SHA1，用于 OpenSSH `known_hosts` 哈希主机名校验，主机名长度由字节串显式记录。

包身份为 `豫言/安全外壳密码`，版本 `0.1.0`。本包提供 SSH 所需的 SHA-256、X25519、Ed25519、AES-128-GCM、AES-256-GCM 与 chacha20-poly1305@openssh.com（恰恰封）密码学原语。`本术。豫` 依赖共用「密码」基础库，以显式长度字节数组调用算法，并保留既有字节串入口和返回格式。`解密阴符二五六伽氏计数果` 与 `解密阴符一二八伽氏计数果` 仍以首字节一表示成功、零表示失败。`本术东道。接口。豫` 保存旧宿主直接调用声明，旧声明的清理留待后续迁移。

`本术。豫` 接受和返回原始字节串。X25519 与 Ed25519 私钥参数为 32 字节种子；调用者应从标准库的安全随机接口生成新种子。X25519 共享秘密为 32 字节，并拒绝全零结果。Ed25519 验签对错误签名返回阴，参数长度错误时报错。AES-128-GCM 使用 16 字节密钥，AES-256-GCM 使用 32 字节密钥，两者都用 12 字节 IV，返回密文与完整 16 字节标签；解密只有在认证成功后才返回明文。调用者必须保证同一密钥下 IV 不重复。

AES-GCM 默认用 `快速伽氏计数。豫` 的快速实现：T 表 AES（四张 256 项的 32 位字表，首次使用时由密码库的 S 盒算出），AES-128 十轮、AES-256 十四轮；GHASH 用八位表（每字节四次查表），加密与认证合在同一个块循环里，输入输出按四字节读写。宿主（macOS arm64 原生）上一兆字节的吞吐：AES-128-GCM 约 16 MiB/s，AES-256-GCM 约 12 MiB/s；密码库的慢速实现约 0.1 MB/s。时间主要花在纯豫言的按字 T 表 AES 上。`加密阴符二五六伽氏计数`、`解密阴符二五六伽氏计数`、`加密阴符一二八伽氏计数` 与 `解密阴符一二八伽氏计数` 的输入输出格式相同；密码库的逐字节实现保留为 `加密阴符二五六伽氏计数慢` 与 `解密阴符二五六伽氏计数慢`，供对拍与需要恒时的场合使用，对拍与 NIST 向量见 `测试/安全外壳密码`。快速实现按输入查表，恒时的快速实现留待后续版本。

`恰恰封。豫` 实现 OpenSSH 默认首选的 `chacha20-poly1305@openssh.com`：六十四字节密钥分两半，后半 K_1 加密四字节包长，前半 K_2 自块计数一起加密载荷，Poly1305 钥取 K_2 第零块前三十二字节，标签算在加密后的包长与载荷上；序号为八字节大端，换钥后从三起算（握手三报，且本端不宣告 kex-strict）。ChaCha20 按十六字整块、十次双轮全在局部名中算，Poly1305 用二十六位五肢、一次吃十六字节。已知答案见 `测试/安全外壳恰恰封验证`，OpenSSH 互通见 `测试/安全外壳服务端互通`。

私钥与共享秘密以普通豫言字节串保存。受保护的密钥存储及清除策略、迁移后的协议层互通和各后端验证留待后续实施。
