# 安全外壳密码

「求已知主机密钥杂凑码沙一」以二十字盐算主机名 HMAC-SHA1，供 OpenSSH `known_hosts` 隐名核对，主机名之长以字节串明记之。

包名「豫言/安全外壳密码」，版「0.1.0」。为安全外壳协议备 SHA-256、X25519、Ed25519、AES-128-GCM、AES-256-GCM 与恰恰封（chacha20-poly1305@openssh.com）密码术。「本术。豫」依共用「密码」基础库，以明长字节数组行之，存既有字节串入口及归果之式。「解密阴符二五六伽氏计数果」与「解密阴符一二八伽氏计数果」仍以首字节一为成、零为败。「本术东道。接口。豫」存旧宿主直呼之声，其清理待后续迁移。

「本术。豫」皆受还原字节串。X25519、Ed25519 私钥以三十二字节种子为参；新种子当取标准库之安全随机。X25519 共密三十二字节，全零则拒。Ed25519 验伪签返阴，参长不合则报事故。AES-128-GCM 用十六字节钥，AES-256-GCM 用三十二字节钥，皆以十二字节 IV，密文后缀十六字节签；验成乃还明文。同钥之 IV 绝不可复用。

AES-GCM 默用 `快速伽氏计数。豫` 之快实：T 表 AES（四表各二百五十六项之字，初用时由密码库之 S 盒算出），一二八十轮、二五六十四轮；GHASH 用八位之表（每字节四查），加密与认证同环而行，出入按四字读。于宿主（林檎臂原生）一兆之吞吐：AES-128-GCM 约每秒十六兆，AES-256-GCM 约每秒十二兆；密码库之缓实约每秒十分之一兆。所耗多在纯豫言之按字 T 表 AES。`加密阴符二五六伽氏计数`、`解密阴符二五六伽氏计数`、`加密阴符一二八伽氏计数` 与 `解密阴符一二八伽氏计数` 之入出式同；密码库之逐字节实存为 `加密阴符二五六伽氏计数慢` 与 `解密阴符二五六伽氏计数慢`，以供对勘及须恒时者，对勘与 NIST 之向见 `测试/安全外壳密码`。快实依所入而查表，恒时之快实待后续。

今私钥及共密寄普通豫言字节串。密钥护藏与清除、迁后协议互通及诸后端核验，皆待续行。
