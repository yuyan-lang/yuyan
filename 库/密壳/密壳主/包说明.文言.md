# 安全外壳服务端

纯豫言之安全外壳（SSH）服务端之库，整理自 `测试/安全外壳服务端互通` 之探针，豫言操作系统之远程登录程序（`豫言操作系统/应用/远程登录`，装为 `/工具/远程登录。豫行`）用之。

## 服务端

`行密壳务` 守所予之址与端口，以三十二字之 Ed25519 主机私种，逐一服诸连：

- 换钥：交版本、KEXINIT、curve25519-sha256、ssh-ed25519 主机钥、二向皆 aes256-gcm@openssh.com，合 OpenSSH 客户之默法。依 RFC 4253 第七节之一于客之名称列取两皆能之首法，客多陈者不碍；两无交会，则先陈明文之断（因三，书所由）乃闭。
- 认证：ssh-userauth 之 publickey（Ed25519，试探回 PK_OK）与 password；准否由呼者之回调判之，用户名不限。败回 USERAUTH_FAILURE（可用 publickey 与 password），口令一误约候一秒，二十败则断。
- 会话：一 session 通道，办 pty-req（记终端之模）、shell、exec、subsystem（名付呼者之 `开子系统` 判之，SFTP 用之）、env（不办）、窗之调与数；全局之请皆回败；闲约五分发 keepalive@openssh.com 一次，再约一分无应则断。

会话之容付呼者之 `服务端处理` 回调：`开会话` 予开场之出，`开子系统`（子系统之名，返受否；受则此通道之数亦付 `会话输入` 与 `会话轮询`，呼者自记所办何子系统，SFTP 见 `库/密壳/密壳文件传输`），`会话输入` 受客之入（空字节串为彼已发 EOF），`会话轮询` 每轮取新出，`会话执行` 办 exec；回调返 `会话反应`（出、已终否、退码），终则服务端发 exit-status、EOF 与 CLOSE。`会话收尾` 于连终时呼之一次，`记事` 受日志之行。本轮得报或回调予新出，则服务端即复一轮；待发之出逾八兆，则暂不向回调取新出，待客增窗而复取。

## 多连与多通道（二〇二六年十月十四日）

`行多连接密壳务`（址、端口、主种、新处理、每轮）并服至多六十四之连（握手认证中者亦计其一），每连至多六十四会话通道。OpenSSH 之 ControlMaster 于一连开多通道，惟握手一次，其后每命惟开一新通道（宿主实测首命约零点三二秒，其后每命约零点零五秒）。

- 主环令每活连各行一步：不塞而读一回（收缓已攒六十四千则此步不读，免其日积）、取一报办之、诸通道向其回调取新出一次而依窗发之；有进则即复一轮，皆闲则依退避而候（自二十毫秒起每轮倍之，至多二百毫秒，其后恒候二百毫秒；无连则至多一秒）。有活连则候于最近有进之连，客之字至则醒，守口惟不塞而一视；一连皆无乃候于守口。子程方行而无新出者，不计为进。
- 新连之版本交换、换钥与认证亦分步而行：连自记所至之步与已收之字，主环每轮于每连惟行一步，与已立之连同轮；默客自滞于其身，握手逾六十秒、认证逾五分则惟断此连。
- `新处理` 于每新连（认证与记事用之）与每新通道各呼一次，诸通道之会话之态不相干；通道之报依收方通道号分之，通道两端皆闭则呼其 `会话收尾` 而去之，连犹开。
- 闲依单调毫秒计：五分无进则发 keepalive.com 一次，彼应则为进；六分无进则断。
- `每轮` 于主环每轮呼一次（远程登录以之管后台作业），返阳则此轮不候。
- 旧之 `行密壳务` 犹一时服一连。

后续版本之事：重换钥（彼发 KEXINIT 今则断）、端口转发、标准误走扩展之数。

## 登录设置

豫言操作系统数据盘 `/系统/远程登录/` 之诸文：

- `主机私种`：三十二字之 Ed25519 种，`取主机私种` 初取乃以安全随机生之。`主机公钥行` 予可置于 known_hosts 之公钥行，`主机钥指纹` 予 `SHA256:…` 之纹（同 `ssh-keygen -l`）。
- `口令`：一行 `pbkdf2-sha256$次数$盐$散列`（PBKDF2-HMAC-SHA256，十六字随机之盐，十六进制），`写登录口令` 书之（空口令则删其文），`核对登录口令` 依文中之盐与次复算而比。
- `授权公钥`：OpenSSH authorized_keys 之式，`公钥已授权` 查其中之 ssh-ed25519 公钥。
- `启动诊断`（2026-10-23，议题三百八十五）：服务书主机之种为已有、现生，及启之误由于是文（`记启动诊断`）；开机壳之看护每秒一读（`取启动诊断`），得则以「远屏记」印于串口而删之（`清启动诊断`）。子之「书」入其出管，不至串口；开机无人触串口，此行乃主机钥新生之证。
