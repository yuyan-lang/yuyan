# 安全外壳恰恰封验证

本可执行包核 `chacha20-poly1305@openssh.com`（通称恰恰封）的已知答案：固定六十四字节密钥、八字节包序号三、四字节包长二十四与二十四字节明文，加密结果须与独立计算一致——ChaCha20 密钥流由 OpenSSL 3 按同一密钥、序号与块计数算出，Poly1305 标签由 Python `cryptography` 库按同一一次性密钥算出；再核解密还原出相同的四字节包长与明文。

另验序号递增：序号三进一得四；八字节全 `ff` 时进一返回可无。

构建与运行（在仓根）：

```
豫构 构建 安全外壳恰恰封验证 --输出 安全外壳恰恰封验证。林檎。豫行
./安全外壳恰恰封验证。林檎。豫行
```

成功时印 `恰恰封向量通过`，不符时报错中止。
