# 安全外壳测速

本可执行包（通称密壳测速）量安全外壳（SSH）传输加解密所用诸算法的吞吐：密码库（阴书）的 AES-256-GCM（数组接口，逐字节递归）、快速伽罗瓦计数（快速伽氏计数，字节串接口，T 表 AES 与四位 GHASH）、ChaCha20（夏夏二十）、Poly1305（多式一三零五）与 ChaCha20-Poly1305（恰恰二零多式一三零五）。各项以同一份一兆字节输入跑一次热身、再计时若干次，印每秒兆字节数与用时毫秒。

构建与运行（在仓根）：

```
豫构 构建 密壳 测试 安全外壳测速 --输出 安全外壳测速。林檎。豫行
./安全外壳测速。林檎。豫行
```

输出每行一项，如 `快速伽氏计数加密：8 MiB/s，用时毫秒 500`。测速只作改前改后的相对比较，绝对数随机器与负载变动。
