# 网页服务内核（文言）

网页服务之共库：传输、收请、回写、封缄证、役助。本土之榫导入之；绑定之包以常依而至，不烦复记适包。

## 传输

以宾主为途，素封二式共一读缓，先收者留、后至者不弃。封缄之握，候暂则惟待可读三〇秒（套多可写，候隙即还，六十四轮俄顷而尽，客未通问而门已闭）。判握之成以「主握手曾成」：客之完成既验则阳，后虽彼闭亦阳；不以今阶判，以客常于完成后即发闭告，同读则阶入于闭。「连接已关闭」与「操作失败」二路于推进、握手与封缄读回皆备，客中道而断，止闭此连。

## 封缄证

读 PEM 之链与 P-256 之私，造封缄之配置；签以告身之椭签，算法一零二七。私按 PEM 之标择其式（EC PRIVATE KEY 为椭圆标准一，PRIVATE KEY 为公钥典八），付告身析之，校其算法与宽；告身识 OpenSSL 命名与显式二种写法。RSA 之私未备，读则明告。

## 验证

- pit-mac 原生跑司阍：openssl s_client -tls1_3 成握手（TLS 1.3、TLS_AES_128_GCM_SHA256）；curl -sk 得二百与正文；同连再请皆二百。命名、显式参数与 EC PRIVATE KEY 三种私钥各验一遍。
- 封缄包之服务握手测试以 OpenSSL 真发之客问授于服务之会，校服务问候之式；记录测试校录版七六九至七七一之纳与他人之拒。
