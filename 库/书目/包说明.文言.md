# 软件目录

软件目录之记之类（[提案〇〇〇二八](../../提案/00028-数据子语言.汉语.md) 例二）。包仓库之软件目录 `/豫/<所有者>/软件/<目标>。数据。豫` 与汇总之目 `/豫/社区/软件/<目标>。数据。豫`，其顶「软件们」为「软件」之记之列。

- 「软件条」：记之类。
- 「软件」：值之构造器，十五参皆带签：「名称」「版本」「网址」「沙二五六」（串）、「字节数」（整数）、「简介」「包名」「所有者」「提交」「界面」「显示名」「类别」「提要」「图标」「所开」（串），皆必填。「界面」书“图形”或“终端”；「显示名」与「类别」供启台与市肆示人；「提要」三十字以内；「图标」为便图之址，空串则无；「所开」为能开之文之后缀，小写、去点、以空格间之，空串则不开文（提案〇〇〇四六第三节）。

数据之文导此库，以构造之书书其记；类检依「软件」之签，核字段之名、类与必填：

```yuyan
寻观「书目」之书。

「软件们」者
　「列」
　【「软件」
　　【「名称」者『源码格式化』也
　　，「版本」者『0.1.0+ae7b54c4f』也
　　，…
　　】
　】
也。
```

高级之文导此等数据之文，得类为「列」于「软件条」之「软件们」。试 `测试/导入。测试。豫` 导样 `测试/样例。数据。豫`；字段误书诸报错之例在 `应用/豫言编译器/校场/语法/数据文件`。
