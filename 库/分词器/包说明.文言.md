# 分词器

共用字节级 BPE 分词之库。具千问预分、字之词表、合并名次、特殊词先取、全解与流解之法。深度学习之 GGUF 载器构本库之器。

以 `寻观「分词器」之书。` 观之。`分词` 还词号之列，`解码` 以词号之列复为文。`新流式解码器` 与 `流式解码` 待 UTF-8 全字齐乃出文。

`由词表建分词器` 受按词号之文、类及并对。`读取结森分词器` 受 tokenizer.json 之文，读 BPE 词表、文式或二元式并表及所添之词，行则依千问预分。`词元文字` 还词表所映之文，`词元字节们` 还原字之列。

BPE 用双向序链及左偏堆，以并次及原左位择候，既并则更邻二对。词长 n，则并词之时为 O(n log n)，所用之藏为 O(n)。

后版之事：tokenizer.json 诸件、tiktoken、统一码全分类、WordPiece、Unigram、WordLevel、SentencePiece、截补及位映。
