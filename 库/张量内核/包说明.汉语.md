# 张量内核

这是张量计算接口（`豫言操作系统接口/张量计算`）的 GPU 算子内核库。内核用着色语言写成（`名。着色器。豫`），构建时译成 WGSL（网页图算）与 MSL（金属），网页图算、金属两种后端共用同一份内核；统算（CUDA）的 PTX 目标另行接入。本库不含后端：后端按下面的绑定约定编译源码、建管线、放缓冲、派发。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库与着色库，登记在「共用库」之下。测试在 `测试/`（包「张量内核测试」）。

| `逐元。着色器。豫` | 逐元二元、逐元标量、逐元一元 |
| `复制。着色器。豫` | 填充常数、跨步复制、取行、按行累加 |

| `矩阵乘。着色器。豫` | 矩阵乘分块、矩阵乘向量 |

高级代码写 `寻观「张量内核」之「内核表」之书。`，用 `「逐元二元内核」` 等描述取源码与入口名（`「内核网页源」`、`「内核金属源」`、`「内核入口」`、`「内核组大小」`），用 `「逐元二元参数」` 等函数得到参数区的字（`「参数字」`：`「整字」` 按 32 位字写，负数按二补码；`「单精字」` 舍入到 binary32 后写其位型），用 `「派发尺寸」` 把组数拆成 (gx, gy)。`「全部内核」` 列出全部描述，供后端预先编译。

## 绑定约定

1. 每个内核是某个着色源里的一个计算入口；同一着色源的内核共用一份源码，后端每份源码只编译一次（金属 `newLibraryWithSource`，网页图算 `createShaderModule`），每个入口建一条计算管线。入口函数名在两种目标里相同。
2. 只用组 0。绑定 0 恒为参数区：只读存储缓冲，32 位无符号字的数组（WGSL `var<storage, read> 参数: array<u32>`，MSL `const device uint* 参数 [[buffer(0)]]`）。整数（个数、形状、起点、行号）按 u32 存，步长按 i32 的位型存（可为负），小数按 binary32 的位型存。参数区可变长：定长头之后可接可变长的整数列（行号、批偏移）。
3. 绑定 1 起依次是张量缓冲，输入在前、输出在后，次序见下表。每个绑定是张量存储的整块缓冲（不绑子区间）；张量起点写在参数区里，以该绑定的元素为单位（单精度、三十二位整数按元素，块量化按字节）。金属的缓冲序号就是绑定号（`[[buffer(n)]]`，n＝组号×16＋绑定号）。缓冲长度向上取整到 4 字节的倍数。
4. 同一次派发里，可写的绑定不得与其他绑定指向同一存储的重叠区域；就地内核（填充常数、按行累加、跨步复制的目标）只绑目标一次。源与目标共享存储时（如写入视图），后端先把源紧致化到临时缓冲。
5. 工作组大小 N 由内核固定。派发一律按组：先按下表求组数 G，派发 (gx, gy, 1)，gx = min(G, 65535)，gy = ⌈G/65535⌉。网页图算 `dispatchWorkgroups(gx, gy, 1)`；金属 `dispatchThreadgroups((gx, gy, 1), threadsPerThreadgroup: (N, 1, 1))`，每组线程数必须恰为 N（MSL 里写明 `[[max_total_threads_per_threadgroup(N)]]`）。内核按 g = 工作组号.y × 工作组数.x + 工作组号.x 编号，g ≥ G 的多余组什么也不做。
6. 个数、起点、下标都是 32 位无符号；元素数与存储字节数须小于 2³²。
7. NaN 按规范传播：比较、取较大/较小、修正线性、末维最大与按轴最大都按位判断 NaN，所以金属默认的快速数学下也合规；后端关掉快速数学时，无穷的处理更稳妥。
8. 跨步头（逐元二元、逐元标量、逐元一元、填充常数、跨步复制）：字 0..5 为头，字 6..13 为形状（最外维在前，维数 ≤ 8，不用的维填 1），字 14..21 为第一个张量的步长，字 22..29 为第二个张量的步长（各 8 字，i32 位型，不用的填 0）。广播维步长为 0；视图直接给自己的步长与起点；连续张量可折成一维（形状 [总数]、步长 1）。结果都连续，从「出起」按行优先存放。

- 运算码与路一宿主、适配相同。二元：0 相加、1 相减、2 相乘、3 相除、4 取较大、5 取较小、6 乘方（同 C 的 pow）、7 是否相等、8 是否大于、9 是否大于等于。一元：0 取指数、1 取对数、2 取平方根、3 取倒数、4 取负值、5 取绝对值、6 双曲正切、7 反曲、8 反曲加权、9 高斯误差线性、10 修正线性、11 软加。数乘、数加即逐元标量的相乘、相加。
- 旋转位置编码的方式：0 相邻成对 (2t, 2t+1)，1 前后半成对 (t, t + r/2)。角表由后端以双精度求好再舍入到单精度：第 i 个词元第 t 对的角 θ = (起位 + i) × 基数^(−2t/r)，表[(i×r/2 + t)×2] = cos θ、其后一项为 sin θ（`「旋转角表」` 按此生成，三角函数与乘方由调用者给出）。在 GPU 上以单精度求角，位置上万时误差超出容差；同一次前向各层可共用一张表。
- 矩阵乘：结果 = 甲 · 乙ᵀ，第 b 批的结果在 出起 + b×M×N；甲、乙的每个矩阵须行连续（行步为 K），不连续的先紧致化；批维广播由后端把每批的偏移列进参数区。M 小（解码）时用矩阵乘向量，其余用矩阵乘分块。块八矩阵向量乘在 M 大时（预填充）按行重复读权重，暂作过渡。
- 填充常数的值由后端按类型转换规则换成目标类型的位型（单精度或三十二位整数）；跨步复制按 32 位字搬运，所以同样适用于三十二位整数。

## 测试与实测

`测试/` 下的「张量内核测试」包在金属上编译、派发各内核的 MSL，与双精度参照（C 数学库经系统库调用求得）按规范容差 |结果 − 参照| ≤ 1e-5 + 1e-3 × s 比较（逐元运算 s 为 |参照|，归约与矩阵乘为各被加项绝对值之和）；没有金属时打印“跳过”。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 张量内核测试 逐元。测试 --输出 yy逐元测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy逐元测试.wasm
```

`复制与归约。测试`、`矩阵与位置。测试` 同法；`计时。测试` 打印各内核的平均耗时（数据全为零）。

2026-09-30 在 Apple M5 Pro 上的实测（本机同时有多个构建在跑，数值有波动；每次为一个命令缓冲内连派取平均）：

| 内核 | 尺寸 | 每次 |
| --- | --- | --- |
| 矩阵乘分块 | 1024³ | 0.7 至 1.2 毫秒（约 1.7 至 3.0 TFLOPS） |
| 矩阵乘分块 | 512³ | 0.2 至 0.26 毫秒 |
| 矩阵乘向量（单精度） | 1 × 3072 × 1024 | 64 至 115 微秒 |
| 块八矩阵向量乘 | 1 × 151936 × 1024（词表投影） | 0.78 至 0.9 毫秒（约 180 至 210 GB/s） |
| 块八矩阵向量乘 | 1 × 3072 × 1024、1 × 1024 × 3072 | 46 至 60 微秒 |
| 逐元二元（相乘） | 1048576 | 200 至 245 微秒（约 50 至 60 GB/s） |
| 软最大 | 512 × 1024 | 45 至 130 微秒 |

## 限制与待办

- 待办事项：第二批——Q4_K、Q6_K、半精度与脑浮点（取行、均方根归一的权、写入行）、注意力（因果、分组查询、带 KV 缓存）、层归一、随机填充（Philox，与宿主逐位相同）、取最大下标，以及 0.4.0 的新算子。
- 待办事项：一行很长时（软最大 1 × 151936）只用一个工作组，应拆成多组两遍归约；逐元内核每个线程只算一个元素，参数字按线程重复读取；块八矩阵向量乘在 M 大时按行重复读权重，应补分块的量化矩阵乘；没有子组运算。
- 待办事项：元素数、字节数不小于 2³² 时不支持；超大存储应按段绑定（网页图算的单个存储绑定有上限）。
