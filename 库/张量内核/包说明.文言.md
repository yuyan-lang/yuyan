# 张量内核

此张量计算之接口（`豫言操作系统接口/张量计算`）之 GPU 算核之库也。核以着色语言书之（`名。着色器。豫`），构时译为 WGSL（网页图算）与 MSL（金属），网页图算、金属二后端共一核；统算（CUDA）之 PTX 之的另接之。此库无后端：后端依下之绑定之约编其源、建管线、置缓冲、派之。

## 籍

所有者曰豫言，版本 0.1.0，种类曰库；依标准库与着色库，登于「共用库」之下。试在 `测试/`（「张量内核测试」包）。

## 绑定之约

1. 每核为某着色之源之一算之入口；同源之核共一源，后端每源惟编一次（金属 `newLibraryWithSource`，网页图算 `createShaderModule`），每入口建一算之管线。入口之函名于二的同。
2. 惟用组零。绑定零恒为参数之区：只读之存储之缓，三十二位无号之字之列（WGSL `var<storage, read> 参数: array<u32>`，MSL `const device uint* 参数 [[buffer(0)]]`）。整（数、形、起、行号）以 u32 存，步以 i32 之位型存（可负），小数以 binary32 之位型存。参数之区可变长：定长之头后可接变长之整列（行号、批偏）。
3. 绑定一起依次为张量之缓，入者先、出者后，其序见下表。每绑定为张量之存之全缓（不绑其子区）；张量之起书于参数之区，以其绑定之元为单位（单精、三十二位整数依元，块量化依字）。金属之缓序即绑定号（`[[buffer(n)]]`，n＝组号×16＋绑号）。缓之长上取为四字之倍。
4. 同一派之中，可写之绑定不得与他绑定指同存之叠区；就地之核（填常、按行累加、跨步复制之目）惟绑其目一次。源与目共存者（如写入视图），后端先紧致其源于暂缓。
5. 工作组之大 N 由核定之。派发一依组：先依下表求组数 G，派 (gx, gy, 1)，gx = min(G, 65535)，gy = ⌈G/65535⌉。网页图算 `dispatchWorkgroups(gx, gy, 1)`；金属 `dispatchThreadgroups((gx, gy, 1), threadsPerThreadgroup: (N, 1, 1))`，每组之线必恰为 N（MSL 书明 `[[max_total_threads_per_threadgroup(N)]]`）。核依 g = 工作组号之 y × 工作组数之 x + 工作组号之 x 编之，g ≥ G 之余组无所为。
6. 数、起、下标皆三十二位无号；元数与存之字数须小于 2³²。
7. 非数依规而传：比较、取大取小、修正线性、末维最大与按轴最大皆依位判非数，故金属默认之速算亦合；后端去速算，则无穷之处更稳。
8. 跨步之头（逐元二元、逐元标量、逐元一元、填充常数、跨步复制）：字零至五为头，字六至十三为形（最外之维先，维数 ≤ 8，不用之维填一），字十四至二十一为首张量之步，字二十二至二十九为次张量之步（各八字，i32 位型，不用者填零）。广播之维步零；视图径予其步与起；连续者可折为一维（形 [总数]、步一）。果皆连续，自「出起」依行优先而存。

- 算码同路一之宿主与适配。二元：零相加、一相减、二相乘、三相除、四取较大、五取较小、六乘方（同 C 之 pow）、七是否相等、八是否大于、九是否大于等于。一元：零取指数、一取对数、二取平方根、三取倒数、四取负值、五取绝对值、六双曲正切、七反曲、八反曲加权、九高斯误差线性、十修正线性、十一软加。数乘、数加即逐元标量之相乘、相加。
- 旋转位置编码之方式：零相邻成对 (2t, 2t+1)，一前后半成对 (t, t + r/2)。角表由后端以双精求之而舍为单精：第 i 词元第 t 对之角 θ = (起位 + i) × 基数^(−2t/r)，表[(i×r/2 + t)×2] = cos θ、其次为 sin θ（`「旋转角表」` 依此生之，三角与乘方之函由召者予之）。于 GPU 以单精求角，位置逾万则误逾容差；同一前向，诸层可共一表。
- 矩阵乘：果 = 甲 · 乙ᵀ，第 b 批之果在 出起 + b×M×N；甲、乙每阵须行连续（行步为 K），不连续者先紧致之；批维之广播由后端列每批之偏于参数之区。M 小（解码）则用矩阵乘向量，余用矩阵乘分块。块八矩阵向量乘于 M 大（预填）则逐行复读其权，暂以过渡。
- 填常之值由后端依类型转换之规化为目之类之位型（单精或三十二位整数）；跨步复制依三十二位之字搬之，故亦用于三十二位整数。

## 试与实测

`测试/` 之「张量内核测试」包于金属编而派诸核之 MSL，与双精之参（以系统库之调借 C 数学之库求之）依规范之容差 |果 − 参| ≤ 1e-5 + 1e-3 × s 较之（逐元之算 s 为 |参|，归约与矩阵乘为诸加项绝对值之和）；无金属则书“跳过”。于仓之根先 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 张量内核测试 逐元。测试 --输出 yy逐元测试.wasm -j 24`，后 `node 豫言操作系统/宿主/节点/宿主.cjs yy逐元测试.wasm`；`复制与归约。测试`、`矩阵与位置。测试` 同法；`计时。测试` 书诸核之均费（数据皆零）。

二〇二六年九月三十日于 Apple M5 Pro 之实测（其时本机并行诸构，数有起伏；每次为一命令之缓内连派而均之）：

## 所限与待办

- 待办事项：第二批——Q4_K、Q6_K、半精与脑浮点（取行、均方根归一之权、写入行）、注意（因果、分组之问、带 KV 之缓）、层归一、随机之填（Philox，与宿主逐位同）、取最大下标，及 0.4.0 之新算。
- 待办事项：一行甚长（软最大 1 × 151936）惟用一工作组，宜析为多组二遍而归；逐元之核每线惟算一元，参数之字依线复读；块八矩阵向量乘于 M 大则逐行复读其权，宜补分块之量化矩阵乘；无子组之算。
- 待办事项：元数、字数不小于 2³² 者不支；甚大之存宜分段而绑（网页图算单存储之绑有其上限）。
