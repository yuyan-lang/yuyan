# 张量内核测试

这是张量内核的测试包：在金属上编译、派发各内核的 MSL，在统算（CUDA）上载入、发射各内核的 PTX，结果与双精度参照按张量计算规范的容差比较；没有相应设备时打印“跳过”（金属须在苹果系统上，统算须在装有英伟达驱动 `libcuda.so.1` 的林纳克斯上，两者都要宿主能调用系统库）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，依赖标准库、单元测试、系统库调用、金属、统算与张量内核。它依赖被测的张量内核，所以登记在上一级父包「共用库」之下。

## 内容

- `金属派发。豫`：测试用的金属执行——设备与队列、按源码缓存函数库、按入口缓存管线、由参数字或小数建共享缓冲、读回单精度，按绑定约定派发（组数拆成 gx、gy，每组恰为工作组大小个线程）；`「计时派发」` 在一个命令缓冲里连派多次取平均；`「造十六位缓冲」` 用写入十六位内核把单精度值写成半精度或脑浮点的缓冲。
- `参照。豫`：双精度参照——从进程主映像取 C 数学库函数（exp、log、sqrt、tanh、pow、cos、sin、fabs、fdim、fmax、fmin），按位判 NaN 与大小（标准库的小数没有比较），以及容差判定 |结果 − 参照| ≤ 1e-5 + 1e-3 × s。
- `逐元。测试。豫`：逐元二元十种运算（广播、起点偏移、转置视图，含 NaN、无穷、除以零与负底乘方），逐元一元十二种运算，逐元标量几种运算。
- `复制与归约。测试。豫`：填充常数（跨步视图，单精度与三十二位整数）、跨步复制（转置、广播、负步长、目标为视图）、取行（单精度与块量化八位）、按行累加（行号重复）、末维求和与末维最大（含 NaN 的行）、软最大、组数超过 65535 的派发（末维求和 70000 行，派发 (65535, 2, 1)，多出的组不得写入）、均方根归一、按轴求和与按轴最大。
- `矩阵与位置。测试。豫`：矩阵乘分块与矩阵乘向量（尺寸不是瓦片的整数倍、两批且乙沿批广播）、旋转位置编码（两种配对方式）、块八矩阵向量乘与块八矩阵乘分块（每行块数为奇数，对齐交替出现；分块版 70 × 67）。
- `十六位。测试。豫`：写入十六位（就近取偶的边界、溢出、次正规、NaN、负零，以及目标首尾不满一字时保留另一半；NaN 输入先去符号位，因为 x86 上 0.0/0.0 的默认 NaN 带符号位）、转单精度（半精度、脑浮点、八位整数、三十二位整数），以及以半精度、脑浮点存放的取行表、均方根归一的权与矩阵乘的乙。
- `训练与随机。测试。豫`：层归一、二范数归一、按行最大下标（并列、NaN、全为 NaN）、就地线性组合、亚当更新一步；填充随机的 32 位数与路一宿主 Philox4x32-10 的已知答案逐位比较（种子 0、12345、−1 各前三块），正态与伯努利按同一组数求参照。
- `量化与注意。测试。豫`：Q4_K、Q6_K 的取行、矩阵向量乘与分块矩阵乘（Q6_K 的块首不按 4 对齐；分块版 70 × 67）；注意力（分组查询、因果与有效长同时起作用、键长超过一段 256、键值为单精度或半精度且起点为奇数），单组与分段（段长 256、96、512，段长 96 时第 0 个词元的末段没有可见键）两种做法。
- `序列与专家。测试。豫`：取前 k（大量并列、含 NaN、k 等于行长的整行排序）、分段取前 k 加合并（行长 5000、段长 512、k = 40，以及段长 64 小于 k = 70）、按专家矩阵向量乘（专家为单精度、半精度、Q8_0、Q4_K，甲共用与各用）、因果卷积与门控递推（一次调用与分两次调用经状态衔接）。
- `计时。测试。豫`、`第二批计时。测试。豫`：打印各内核的平均耗时与折算的带宽或算力（数据全为零）。
- `性能计时。测试。豫`：性能改进的前后对比（同一尺寸下旧做法与新做法的平均耗时）。
- `统算派发。豫`：测试用的统算执行，与 `金属派发。豫` 同名同用法——设备的主上下文、按 PTX 源缓存模块、按入口缓存函数、由参数字、小数或字节建显存、读回单精度与 32 位字，按绑定约定发射（网格 (gx, gy, 1)，每块恰为工作组大小个线程）；`「计时派发」` 连续发射调用者所给次数的十倍后同步一次取平均（显卡常与别的进程分时，次数少时平均值被等待时间片主导）；`「造十六位缓冲」` 同金属版。
- `统算逐元。测试。豫`、`统算复制与归约。测试。豫`、`统算矩阵与位置。测试。豫`、`统算十六位。测试。豫`、`统算训练与随机。测试。豫`、`统算量化与注意。测试。豫`、`统算序列与专家。测试。豫`、`统算计时。测试。豫`、`统算第二批计时。测试。豫`、`统算性能计时。测试。豫`：金属各测试的统算版，用例与参照相同，共 145 项（`统算量化与注意` 含分段注意力三种段长，其中有末段无可见键、走 −∞ 分支的情形）；`统算性能计时` 另测块量化矩阵向量乘与分块矩阵乘在 M = 1 至 512 上的交叉点。`统算十六位` 里 NaN 输入先经 fabs 去掉符号位：x86 上 0.0/0.0 得到的默认 NaN 带符号位（苹果芯片上不带），内核保留 NaN 的符号，所以按位比较的期望值只对正 NaN 成立。

## 运行

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 张量内核测试 逐元。测试 --输出 yy逐元测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy逐元测试.wasm
```

其余测试同法，统算版在装有英伟达驱动的林纳克斯上运行（诺节须支持 `node:ffi`，见 `豫言操作系统/宿主/节点/说明.汉语.md`；设 `CUDA_CACHE_DISABLE=1` 则每次都重新 JIT 编译 PTX）；全树测试自动发现并运行它们（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/张量内核/`）。
