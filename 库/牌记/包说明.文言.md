# 包配置

以 parser 解析静态包配置并验证依赖图。

## 籍与用

所有者曰豫言，版本暂定 0.1.0。此包之版本，非编译器命令所报之版本。

此包可供他包所依，观书须先书包名，继书包内路径。无默认程序入口，试例须明指其书。

在仓库之根行 `./豫构。林檎。豫行 检查 包配置` 以验其籍。

所依与说明之径皆见[包籍](包配置。包。豫)。变接口则修说明，变身份与组成则修包籍。说明不作模块。

包籍之字段与其验，见[豫构包制](../../应用/豫构/包系统.文言.md)。可选之「平台」所解之果，以「包诸平台」（依书之序之诸项）与「包平台依」（包于某平台之诺驿库与系统库，不可用于其平台则「可无」）读之；包图既析，以「验包图平台」核依闭之台交（鹄台不在某包所列之台及其子中则报「平台不合」为首之误，构建之时呼之）；析包图时以「验包图试包」核生产之包不依试包（包目在 `测试/` 之下者为试包，库包与可执行之包依之则告“生产包依赖测试包：”，书其二包）；可选之「许可」（SPDX 许可式）以「包许可」读之，不书则空串；可选之「实现接口」以「包实现接口」读之：所实现接口包名之列，依所书之序，每名须为合式之短名，包图中须有同名之包，其包须有 `。接口。豫`、`。应用接口。豫` 或 `。底层接口。豫` 之文（包之存否与是否为接口包，待析包图时验之）；所列之包不必在「依赖」之中，不书则空列；可选之「文体」（提案〇〇〇二六）以「包声明文体」读之：名须为译场所登记之文体（文体榫卯之「文体已知」验之，今惟雅言），不书则为『雅言』，包记之「文体」项由是而填。

器之可书字段「界面」解为「界面类」（「图形界面」「终端界面」，不书则终端），以别图形之器与独对终端之器；以「包界面」「包为图形」读之，「述界面」复书为“图形”“终端”（提案〇〇〇四六）。

包籍之跳转、悬停资料，书于 `.豫构缓存/豫构语言服务/<包描述基名>。语言服务。树码`。与编译器语言服务缓存共用第二版树码，以豫言 `树码 读取编辑器资料` 解而授编辑器。

语言服务之双八位码列数，以「易码」之「文十六位同文长度」计之，域外之字占二码元。

补全包图，并填实约与缺签唯警之位。后者按诸包近单而定，随第七式包境授译器；本程之「为卷启包境」亦由此途。
