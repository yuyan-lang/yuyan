# 篇式

通称会话篇格式（transcript format）。这是捉刀（编程智能体）记一场会话的格式与读写，提案 00036。一场会话记成一篇文章 `名。会话。豫`：块头单独一行，块的内容每行以「｜」起头，「｜」之后照原样写、永不转义。模型要做事就写一句豫言壳句，交给壳执行，回执紧接着记进篇里。

本篇只认文字，不碰文件与网络。捉刀应用用它读写会话，揽辔（观测台）用它解析事件块；两边共用这一份，不各写一份。

## 块头

| 块头 | 谁写 | 内容 |
| --- | --- | --- |
| `「：用户：」` | 捉刀 | 用户的一条话 |
| `「：模型思考：」` | 模型 | 思考 |
| `「：模型：」` | 模型 | 对用户说的话 |
| `「：稿：名：」` | 模型 | 一段原样文字，去掉「｜」后定义成会话里的字符串「名」 |
| `「：结果：」` | 捉刀 | 上一句办成了：它印出的文字 |
| `「：错误：」` | 捉刀 | 上一句没办成：印出的文字与诊断 |

块头单独占一行，本身是一条完整的注释；块到第一行不以「｜」起头的行为止。句是一句壳句，以「。」结尾，不以「｜」起头；每句之后必有一块回执。

## 模块

| 模块 | 内容 |
| --- | --- |
| `篇式` | 按行切分（「分行」）、加去「｜」（「加竖」「去竖」）、成块（「成块」）、认块头（「块名」「稿名」）、析出模型的一次输出（「析应」「析应半」）、析整篇（「析篇」）、按角色切分（「分问答」）、截长（「截长」）、清理回执（「涤文」）、压成一行（「束句」）、签名句与定义句的判断（「为定句」）、系统提示里的篇式说明与示例 |

## 写法

```yuyan
「：用户：」
｜把 甲。豫 里的“你好”改成“您好”。
「：模型思考：」
｜先看文件。
「案牍」之「阅」于『甲。豫』。
「：结果：」
｜「：汉语：问候语。：」
｜「问候」乃「文」也。
｜「问候」者『你好』也。
「易」于「文件」曰『甲。豫』于「旧」曰『你好』于「新」曰『您好』。
「：结果：」
｜已改 甲。豫 一处
「：模型：」
｜已把 甲。豫 里的“你好”改成“您好”。
```

## 测试

`测试/篇式。测试。豫` 用考课核对切行、加去「｜」、认块头与稿名、析应（含篇式错误）、析篇、按角色切分、截长、清理回执、压成一行与定义句判断。

## 使用者

- `应用/机智坊/捉刀`：读写会话篇、拼请求、起壳执行、记回执。
- `库/揽辔`：观测台读事件块、重建会话视图。
