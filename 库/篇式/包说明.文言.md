# 篇式

通称会话篇格式。此库定捉刀（编程智能体）录谈成篇之体例，见提案 00036。一场之谈录为一文 `名。会话。豫`：块头独居一行，块之内容每行以「｜」起，照录原文，永不转义。模型欲有为，则书一句豫言壳句，付壳而行之，回执随录于篇。

此库惟理文字，不涉文件与网络。捉刀用之以读写会话，揽辔（观测台）用之以析事件块；二者共此一份，不二其式。

## 块头

| 块头 | 谁书 | 内容 |
| --- | --- | --- |
| `「：系统：」` | 捉刀 | 系统之示：篇式之说与例、今目与日、仓根之 LOCALAGENTS.md、上寻所得之 AGENTS.md |
| `「：用户：」` | 捉刀 | 用户之一言 |
| `「：模型思考：」` | 模型 | 思考 |
| `「：模型：」` | 模型 | 对用户之言 |
| `「：稿：名：」` | 模型 | 原样之文，去「｜」而定为会话中之字符串「名」 |
| `「：结果：」` | 捉刀 | 上一句办成，录其所印 |
| `「：错误：」` | 捉刀 | 上一句未成，录其所印与诊 |

块头独居一行，本身为一全注；块至首行不以「｜」起者而止。句为一句壳句，以「。」终，不以「｜」起；每句之后必有一块回执。系统之块，捉刀每开篇、始事之前书之：篇中无之，或末一系统块之内容与今次之示不同，则以全示为一块追于篇末；模型书之则为篇式之误。

## 模块

| 模块 | 内容 |
| --- | --- |
| `篇式` | 析行、加去竖、成块、识块头、析应、析应半、析篇、分问答、截长、涤文、束句、定句之判、系统块之识别与剔除、篇式说明与示例 |

## 写法

```yuyan
「：系统：」
｜（全示在此，从略）
「：用户：」
｜把 甲。豫 里的“你好”改成“您好”。
「：模型：」
｜已把 甲。豫 里的“你好”改成“您好”。
```

## 测试

`测试/篇式。测试。豫` 以考课核切行、加去竖、识块头与稿名、析应（含篇式之误）、析篇、系统之块（识别与剔除、模型书之为误）、分问答、截长、涤文、束句与定句之判。

## 使用者

- `应用/机智坊/捉刀`：读写会话篇、拼请求、起壳执行、录回执。
- `库/揽辔`：观测台读事件块、重建会话视图。
