# 图标

界面之图库。图画于零至二十四之方格，每笔为一 SVG 路径之数：墨描、朱描为线（取墨色、朱色），墨实、朱实为实形，底填以底色填之。其径由矢量图库解之、二维绘图平为折线，乃依物理边长以距离场栅之：线取至诸段之最近距，圆头圆角自得；实形依非零绕数判内外，依至边之距去锯齿。逐素之算皆用整数，原生与诺节同速，一图数毫秒。

## 模块

| 模块 | 内容 |
| --- | --- |
| `图形` | 「图标」「笔」与诸图：夹、终端、任务、设置、搜索、刷新、返回、右移、左右拆、上下拆、全屏、还原、闭、收展之箭、合开之夹、豫言之源、文档、图、配置、可执行、会话与他文之页 |
| `画图标` | 「图标画法」（墨、朱、底色与线宽）、「默认图标画法」、「画图标到缓冲」、「渲染图标」（依名、物理边长与画法存之，还 RGBA8 之字与版号） |
| `图标元素` | 「设图标像素比」、「图标元素」与「定位图标」：依今之像素比而渲，交界面之「混合像素图」示之，透处露底 |

平铺桌面之外壳之视每帧依所受之像素比调「设图标像素比」；活动栏、签栏与工作台资源树皆用此图。

## 预览

`豫构 运行 库/图标/预览。脚本。豫 yy图标预览.png` 依一倍、二倍与放大之尺画诸图于纸色之底，书为 PNG，并印独渲之时。

## 后续版本事项

- 像素比今为全局之态；当易为显示树之矢量图之节，由自绘后端依像素比栅之。
- 矢量图库之通渲于曲与描加速之后，图可径交之渲。
