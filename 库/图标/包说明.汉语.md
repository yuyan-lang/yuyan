# 图标

界面图标库。图标画在 0 到 24 的方格里，每一笔是一条 SVG 路径数据：墨描、朱描是线条（取墨色、朱色），墨实、朱实是实心形状，底填用底色填满。路径由矢量图库解析、二维绘图平展成折线，再按物理边长用距离场栅格化：线条取到各线段的最近距离，圆头圆角自然得出；实心形状按非零环绕数判内外，按到边的距离抗锯齿。逐像素的计算全用整数，原生与诺节一样快，一个图标几毫秒。

## 模块

| 模块 | 内容 |
| --- | --- |
| `图形` | 「图标」「笔」与全部图标：文件夹、终端、任务、设置、搜索、刷新、返回、右移、左右拆分、上下拆分、全屏、还原、关闭、收起与展开箭头、合上与打开的文件夹、豫言源码、文档、图片、配置、可执行、会话与其他文件页 |
| `画图标` | 「图标画法」（墨色、朱色、底色、线宽）、「默认图标画法」、「画图标到缓冲」、「渲染图标」（按名、物理边长与画法缓存，返回 RGBA8 字节与版本号） |
| `图标元素` | 「设图标像素比」、「图标元素」与「定位图标」：按当前像素比渲染，交界面的「混合像素图」显示，透明处露出背景 |

平铺桌面的外壳视图每帧按收到的像素比调「设图标像素比」；活动栏、标签栏与工作台资源树都用这里的图标。

## 预览

`豫构 运行 库/图标/预览。脚本。豫 yy图标预览.png` 把全部图标按一倍、两倍与放大尺寸画在纸色底上，写成 PNG，并打印单独渲染的耗时。
