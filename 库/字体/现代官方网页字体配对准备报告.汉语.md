# 现代官方网页字体配对准备报告

2026-10-08 已取得 Adobe 官方 Source Serif 发布仓中预存的四组原始字体与 WOFF2 配对，涵盖静态 CFF、静态 TrueType、可变 CFF2、可变 TrueType。八个字体文件与完整许可保存在仓外目录 `/private/tmp/yy字体现代官方配对/`。

本轮完成来源、提交、文件长度、原文件头、Git blob 身份与 SHA-256 静态核对。解压、类型检查、字体解析、几何比较和栅格验证留待后续验证窗口。

## 固定来源

仓库：[adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4)。分支为 `release`，固定提交为 `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`。官方 [README](https://github.com/adobe-fonts/source-serif/blob/80d3f8894c09c937bebfa9011247d2e1c79fd6f4/README.md) 将字体发布文件与 `main` 分支的源文件及构建说明分开。

下面每组两端都是这一提交已有的二进制文件，原始字体路径与 WOFF2 路径同时见于官方发布树。独立原件来自上游 OTF、TTF 或 VAR 目录；预压件来自上游 WOFF2 对应目录。配对依据为官方同一发布提交、目录类别和完整文件名，语义一致性将在后续实测核对。

| 轮廓类型 | 原始字体仓库路径 | 预压 WOFF2 仓库路径 | 原件／压件字节数 |
| --- | --- | --- | --- |
| 静态 CFF | `OTF/SourceSerif4-Regular.otf` | `WOFF2/OTF/SourceSerif4-Regular.otf.woff2` | 241392／107408 |
| 静态 TrueType | `TTF/SourceSerif4-Regular.ttf` | `WOFF2/TTF/SourceSerif4-Regular.ttf.woff2` | 261868／76260 |

可变 OTF 原件文件头为 `OTTO`，目录包含 `CFF2`、`HVAR`、`MVAR`；可变 TTF 目录包含 `avar`、`fvar`。这些结论来自读取原件表目录。可变 OTF 文件经固定提交的官方 raw 地址下载，其 Git blob SHA-1 为 `7f3fc506816bdb8f0cb447679c7badb3c98df695`，与官方树记录一致。其余七件经 GitHub 连接器取得上游 Base64 表示并恢复原字节。

## 后续验证建议

既有 W3C 历史样本及其 240 个横度量差异保留在独立历史验证记录中。本轮新增八件作为新的独立配对，后续测试记录单独列出结果。
