# 系统覆度及二型曲修之录

二〇二六年十月八日，于同一 macOS，以本机字体首面、预定百分十之容差，核 CoreText 三十组，百二十断皆成，无败，行出为零。样本及阈皆存初值。

初行有十败，皆在 Hiragino Sans GB 之 CFF 曲；Menlo 十五组真型皆成。察二型交替曲有二失：九参、十三参者先耗末余参；纵首末曲之余纵增又入首控横。今每段耗四参，惟末剩五参者耗余参；纵首控横增恒零。

## 器与状态

用 ec25b243 完整配套链、本树专缓存，构参 `-j 24`。系统末构会话 76693 全出零；曲试末构会话 43037 全出零。诸行皆终。

macOS 框架居 dyld 共缓存，故以框架目察平台。实行用仓内既有全工具宿主及最新值桥，由 Node v26.3.0 既有 FFI 调系统框架。发行工具宿主未附系统调用之文者，明书跳过。

日志 `yy字体系统覆盖运行.log` 存诸组系统覆和、自研覆和、实差；`yy字体紧凑运行.log` 存五十四定试之断。二者居字体独树根。官方二十原样之旧配宽差二百四十断，别存诊断、严败之出；全树以其精确入口录已知败。生产曲修，依本录实系统对照及定列验之。
