# PDF CFF 标准编码与旧复合参数静态闭包

新授权普通公共helper任务，独树字体标准编码复合字，基已审55adffa94。原0f25与55队列树保持冻结。只新增标准表、SID到GID及真实endchar参数查询，现代字体既有甲乙验收分类沿用原记录。

直接官方来源：Adobe5176的charset格式0/1/2、TopDICT字段15、ROS12/30、附录B StandardEncoding代码SID表和附录C predefined ISOAdobe、Expert、ExpertSubset；后两完整表分别166、87项，ISOAdobe为SID0..228。Adobe5177附录C印刷35–36说明旧PDF endchar四参数及可选宽度，bchar/achar依据StandardEncoding字名，禁止复合嵌套。

高层公开签名已提前交PDF：标准编码字符标识 整数→整数；紧凑字符标识字形 紧凑字体→整数→整数；紧凑字形复合参数 紧凑字体→整数→列整数。另低层紧凑程序复合参数 字节缓冲→局部紧凑索引→全局紧凑索引→列整数。所有接口由字体总集导出，无宿主接口或外部库。

共享解释器增加实际endchar回调入口，旧普通执行器保持签名并传空回调。查询回调只在实际endchar且栈数4/5时取尾4项，随后设置既有全查询停止标志；局、全subr仍共栈，普通return不触发收尾，子程endchar终止查询并向父传播。EOF残栈不判复合。组件映射和保留由PDF调用方以三个高层helper办理，CID字符集与禁止嵌套检查归调用方。

仅一正常与一错误基础断言：正常局部子程序真实endchar提取四参并阻止父后续移动，基字与音标代码映射为A/acute的SID；错误四参EOF查询为空。失败或数量非二强退出。源码格式化和差异检查通过，未构建运行，无长验、million或性能任务。
