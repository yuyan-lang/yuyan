# 字体测试

`系统覆盖黄金。测试` 以 pit-mac 已取得的 CoreText 30 项覆盖值为独立黄金，固定两份字体的 SHA-256，在 16、32、64 字号逐项完成四个断言，共 120 个断言，采用固定 10% 相对容差。入口只使用字体库与纯豫言 SHA256；测试包直接依赖「密码」以核对输入。它可以供纯原生执行器与诺节分别验收相同输入与黄金。

这是字体库的单元测试（`X。测试。豫`）。测试字体在测试代码里用字节缓冲手工拼出，不需要外部字体文件：

- `解析。测试`：字面数；head、hhea、maxp 与 OS/2 排版度量；cmap 格式 4（差值段与范围偏移段）与格式 12；前进宽度（含超出横度量数的字形）；简单字形、全是控制点的字形、复合字形（一字节与两字节偏移、缩放、复合的复合、引用自己的复合字形到限深为止）的轮廓；字体集取第二个字面（长 loca）；CFF、坏数据与越界序号报失败。
- `栅格化。测试`：整像素对齐的方块全为 255；半像素错位的边为 128；空心框的洞与复合字形部件之间为 0；三角形与两种曲线字形的覆盖总和约等于面积；嵌套复合字形的位置、空格、每 em 2000 的字面、100 像素与非整数坐标。
- `排版。测试`：整数键散列表扩容；字体回退、行度量与位图缓存；测量宽度；断行覆盖中文、英文、中英混排、行首行尾禁则、超长词、强制换行与空文字，并核对各字形的码点、字体序、字形号与横坐标；UTF-8 解码。
- `真字体。测试`：本机有 `/System/Library/Fonts/Menlo.ttc` 与 `/System/Library/Fonts/STHeiti Light.ttc` 时，渲染“永”“国”“A”“g”，核对尺寸、前进宽度与覆盖比例，印出字符画；缺文件时打印“跳过”，不算失败。

`造字体。豫` 拼出测试字体：字面甲（每 em 1000、短 loca、cmap 格式 4、带 OS/2）有九个字形——空心框、方块、三角形、全由控制点组成的圆角方、复合字形、空格、在线点与控制点相间的小圆、复合的复合、引用自己的复合字形；字面乙把坐标与度量放大一倍（每 em 2000），用长 loca，cmap 另有格式 12；两者可拼成字体集。

## 包身份

扩充样本包括 `彩色字体。测试`、`彩色字形。测试`、`紧凑轮廓。测试`、`可变字体。测试`、`可变字形。测试`、`网页字体。测试` 与 `网页字体变换。测试`，分别覆盖图层与调色板、位图索引、完整紧凑表与二型指令、轴与变体插值、使用者入口、网页封装及逆变换。`真实扩充字体。测试` 使用本机的中日韩紧凑字体、可变字体与彩色表情字体；缺文件时跳过该项。

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试与字体。测试包依赖被测库，所以登记在「共用库」之下。

## 使用

`真实彩色消费。测试` 使用官方Noto CBDT/CBLC位图及Mozilla COLR零版/CPAL字体；前者交正式PNG解码，后者按原层序交二维绘图与合成，产出图像像素。二维绘图直接依赖仅用于该真实测试。数据固定来源与许可见甲审验收记录。

`官方网页字体。测试` 保留 20 个官方原样及严格失败出口，历史横度量差异见《官方网页字体诊断报告》。`系统覆盖。测试` 通过测试专用的「系统覆盖对照」模块与直接依赖「系统库调用」，读取 macOS 系统框架栅格化相同首面字形；30 组固定容差实测见《系统覆盖验收记录》。
`彩色便图消费。测试` 使用真实 Apple Color Emoji 的生产载荷到正式 PNG 解码的闭环，核 IHDR 尺寸并保留像素；测试直接依赖「图像编解码」。本轮节点与同客体原生各七个断言通过，产物为20×20 RGBA8；旧载荷定位测试的成功数单独记录。

`官方网页字体。测试` 的固定配对入口接收原文件名、预压文件名及可选样本目录；默认目录与完整 20 原样清单保持原值。新增 Adobe 官方四组独立配对见《现代官方网页字体配对准备报告》，新配对尚待实测。


在仓库根目录构建并运行（以解析测试为例）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 文件 库/字体/测试/解析。测试。豫 --输出 yy字体解析测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy字体解析测试.wasm
```

输出末行的“当前失败数”应为 0。全树测试会自动发现这些测试：`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/字体`。
# 系统变量黄金对照

「系统变量度量黄金。测试」固定真实 CoreText 八组度量值，使用纯豫言密码散列先核官方字体 SHA-256，再按用户轴值归一化并读取可变前进宽度。绝对容差为一字体单位，失败或断言数不足八项时发生事故。
