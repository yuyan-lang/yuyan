# 字体全量入口扩充静态报告

增加测试内扩充模块，复用生产 API，生产接口与实现保持原样。新增网页一、网页二、网页逆字形、位图索引、位图数据五个模式，总模式十七。批隔离、精确编号、失败样本重建沿用已有驱动，修改范围为两处种子提取、一处解析调用和同包导入。新增直接依赖压缩，用于调用生产布罗解压。

网页逆字形种子使用真实单字体 WOFF2，生产 API 解析目录及共享压缩流，选择带变换标记的 glyf 原载荷。每次变异直接进入 `网页字形逆变换`，避免整字体目录拒绝掩盖逆变换覆盖。头截断、缺变换表或解压长度不符在预备阶段失败。WOFF2 字体集共享变换流提取留待后续版本；整文件及网页解封装模式支持指定 TTC 面。

位图种子从真实字体选取 CBDT、CBLC，像素组固定零、gid 由参数指定。预备实际调用 `查彩色位图位置` 与 `读彩色位图载荷`，检查非空 PNG 载荷并写出 yy字体位图种子.png。运行位图索引时变异 CBLC、固定原 CBDT；运行位图数据时变异 CBDT、固定原 CBLC。每例均真实定位和取载荷，定位无项或空载荷计拒绝。原字体缺表或指定 gid 缺图强失败。真实 CBDT/CBLC 种子尚需主执行者从有对应表的官方字体目录指定；当前 Adobe Source Serif 与 Apple sbix 来源各用于其已有入口，不能代充 CBDT 计数。

指定面号现用于整文件变异后字体解析以及各表原上下文。坐标数量依据原字体实际 fvar 轴列表，用既有编号的 F2Dot14 全域扫描值映射每一轴；轴数不固定为二。各轴不同值的组合扫描与全部面自动调度为后续事项。

格式化与差异核对完成；本轮未构建、未运行，实际扩充计数零。公共生命周期峰值 RSS 与分配峰值仍缺，未填写资源通过记录。主执行者先分别以真实种子小批验证精确编号，再运行两端正式百万。
