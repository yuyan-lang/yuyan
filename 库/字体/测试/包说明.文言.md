# 字体测试

此字体库之单元之试也（`X。测试。豫`）。试用之字体，于试码中以字节缓冲手拼之，不须外来之字体文：

- `解析。测试`：面数；head、hhea、maxp 与 OS/2 排版之度；cmap 格式四（差之段与范围偏移之段）与十二；前进之宽（兼逾横度量数之形）；简形、皆控点之形、复形（一字与二字之偏、缩、复之复、自引之复形至深限而止）之廓；字体集取第二面（长 loca）；CFF、坏数据与越界之序皆报败。
- `栅格化。测试`：整像素相齐之方块皆二百五十五；错半像素之边为百二十八；空心之洞与复形诸件之间为零；三角与二曲形之覆之和约等其积；嵌复形之位、空格、每 em 二千之面、百像素与非整之坐标。
- `排版。测试`：整数键散列表之扩；体之回退、行之度与图之存；量宽；断行兼中文、英文、中英相杂、行首行尾之禁、长词、必断与空文，并核诸形之码点、体序、形号与横坐标；UTF-8 之解。
- `真字体。测试`：本机有 `/System/Library/Fonts/Menlo.ttc` 与 `/System/Library/Fonts/STHeiti Light.ttc`，则绘“永”“国”“A”“g”，验其尺寸、前进之宽与覆之比，印其字画；文阙则书“跳过”，不计为败。

`造字体。豫` 拼试用之字体：面甲（每 em 千、短 loca、cmap 格式四、带 OS/2）有九形——空心之框、方块、三角、皆控点之圆角方、复形、空格、在线与控点相间之小圆、复之复、自引之复形；面乙倍其坐标与诸度（每 em 二千），用长 loca，cmap 兼有格式十二；二者可拼为字体集。

## 籍

扩充之例有「彩色字体。测试」「彩色字形。测试」「紧凑轮廓。测试」「可变字体。测试」「可变字形。测试」「网页字体。测试」「网页字体变换。测试」，各验层及色表、位图索、全紧凑表与二型令、轴与变体插值、用者之口、网页封与逆变。「真实扩充字体。测试」用本机中日韩紧凑体、可变体、彩色表情之体；文缺则略其项。

所有者曰豫言，版本 0.1.0。此包为库，惟供试，依标准库、单元测试与字体。试包依所试之库，故登于「共用库」之下。

## 用法

于仓根构而行之（以解之试为例）：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 文件 库/字体/测试/解析。测试。豫 --输出 yy字体解析测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy字体解析测试.wasm
```

所出末行之“当前失败数”当为 0。全树之试自能寻之：`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/字体`。
