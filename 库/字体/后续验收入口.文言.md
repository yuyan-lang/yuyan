# 后续验收之入口

今惟备源码、官方文及许可。新增诸入口待察型及实行；构建由统筹授时。

## 官方独立对

Adobe 定发布提交及八文哈希见《现代官方网页字体配对准备报告》。四对原文与预压文皆出上游发布树，原文别为逻辑廓、度量及栅格之参。

构 `字体测试 官方网页字体。测试` 后，先核静真型之最窄定对：

```text
node 豫言操作系统/宿主/节点/宿主.cjs yy字体官方测试.wasm SourceSerif4-Regular.ttf SourceSerif4-Regular.ttf.woff2 /private/tmp/yy字体现代官方配对/
```

而后循同入口各核静 OTF、可变 TTF、可变 OTF 同名预压文。第三参惟择试目；缺则仍用旧目，全二十原样之列及严败之出存初值。旧原宽度列、压缩原流、自研与系统独解之同，见《官方网页字体诊断报告》。

## 实非默认轴

构 `字体测试 真实非默认轴。测试` 后，常用 SFNS；参传 Adobe 官方可变原文，可各及 gvar/HVAR 与 CFF2 blend/HVAR。惟取 `wght` 最大值，余轴常值；A、g 常值及变值之廓，须有坐标之变。用户16.16、归一F2Dot14、前进宽度悉书，败数大则异常而出。

```text
node 豫言操作系统/宿主/节点/宿主.cjs yy字体真实轴测试.wasm /private/tmp/yy字体现代官方配对/SourceSerif4Variable-Italic.otf
```

初轮惟需一原文二字形；余轴取常值，便察轴映、blend区域、形增之失。

## 彩色 PNG 消费

构 `字体测试 彩色便图消费。测试` 后，由既有 `字体彩色位图载荷` 读实 Apple Color Emoji，交正式 `解码便图`。试核独立 IHDR 宽高及全像素之长，书宽高、格式、行距、像素字节数；行后存 `/private/tmp/yy字体彩色原载荷.png` 及 `/private/tmp/yy字体彩色解码像素.bin`。

此为待验之源；旧彩色试惟验数之定位，PNG解码及像素之证待实行而录。字体生产包循旧口，图像编解码之依惟加试包。

## 原生及速度

既有 `字体性能` 同源驱动，备十六、三十二、六十四像素之号、同文及校量。后时先以一轮核原生与节点之实产，次依《验收驱动》五轮中数之法收诸平台之数。诸格式原生之证及跨平台速数待行后录，甲乙之成以全证定之。
