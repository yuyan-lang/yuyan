# 用户态桌面

文件之服收全诸字节，乃以八位通码宽解其文。残坏之码以 `�` 显之，文件浏览与工作台编辑共此法。`测试/文件文本解码。测试。豫` 验全中文、域外字、空文、残码与坏字节。

此开机命令壳与[平铺桌面](../平铺桌面/包说明.文言.md)所共之常豫言库也：命令之会、图形命令行、文件浏览与文件之服、标记文预览、任务管理器、设备管理器、系统设置与设置之久存、环境之文。库经系统接口取宿主之能，不径涉内核之存与设备。二〇二六年十月十日起桌面为平铺桌面（提案 00014）：旧之浮窗（窗形之表、题栏之拖、右下之伸缩、置顶与轮换）与「运行用户态桌面」皆删之，此之图形命令行、文件浏览、任务管理器与系统设置皆为平铺桌面之格程。

## 终端同开机命令壳（二〇二六年十月九日）

终端之格与开机命令壳、远程登录同为一壳（十月十四日起每终端之格起一豫构交互子会话，每句皆编而行；十月十六日起终端之格为终端之仿，会话用 `--组字`，与开机壳同一逐键编辑之器，见 `子程序服务。豫` 之「桌面起壳会话」；十月廿三日起终端之格既立则起会话、印其提示，不复待初按键）：同一当径，同一环境，同一套壳命令（豫言句，字符串书『』）、用法与误示。子会话之出经公共子程序接口〇点六依时以「取使者出」取之（连询无新出则其间逐次倍之，自二百五十毫秒至多二秒；有新出即复二百五十毫秒），造盘之类久行之程随时示其进；会话中同步「行」之子程序于裸机以“承出”起之，其出随子会话之出，行时依行模所入之行亦付之。「脚本」由子会话逐行行之；脚本之注同豫言之源，书于「：与：」之间，可跨行、可嵌套。终端中「图形」告桌面已行，「辞」或空行按 Ctrl+D 则终子会话而闭终端之格；Ctrl+C 惟断会话方行之一句，会话停于提示则弃方入之行（十月十四日）。

输入同开机壳（十月十六日起由会话中壳核心之逐键编辑之器处之，见壳核心之「闻言」）：恒以中文组字，字母径组拼音，候选行示“拼音：… 候选：…”，? 为通配，有候选则空格或回车择首、一至九择字、= 、- 翻页，Esc 留此拼音为英文，{ } 入角引，↑ ↓ 取旧行，Tab 补全；回车先补自由参为角引之文，再回车乃行。屏上存最新三百行，排最新百行，每逻辑行至多示千字；示时复依终端格所量之列数折行，长行依窗宽而折、不见截断。裸机与原生执行器随时交新出；诺驿与浏览器于程毕时一并示之。

## 文件浏览与预览

浏览之服（定于 `簿录`）之径为授权目录内以正斜线分之相对径，空文为根。`卷浏览` 之浏览之态与视（径框、条目、Markdown 与豫言源码文档之预览）存以供验与后之格；平铺桌面之文件浏览格用工作台之资源侧栏。`标记文预览` 共用于工作台与预览：标题、列表、引用、围栏代码、行内代码、粗体、链、表格与转义标点。

## 设置

启时自授权目录之 `桌面设置.数据库` 复其字体，择字体则经嵌入数据库之写事务交之；惟读或未授则存此会之设。默认字体为随发行之文楷，又有无衬线、衬线、等宽三标准族名。

显示之设具自动、100%、125%、150%、175%、200%、250%、300%缩放，自动项注宿主之自动值。分辨率依显示接口模式之列设钮，惟一项则示今尺。库键为桌面/字体、桌面/缩放、桌面/分辨率；缩放存比六四（0为自动），分辨率存宽乘65536加高（0为沿今尺）。设即生效，始则复所存。后续之事：分辨率确认倒计时。
