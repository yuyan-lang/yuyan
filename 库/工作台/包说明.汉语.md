# 工作台

豫言工作台与平台无关的部分，从可执行包「豫言工作台」（`应用/开发工具/豫言工作台`）抽出。原生工作台与浏览器工作台（[工作台网页](网页/包说明.汉语.md)、云端代码页）共用同一份状态、视图与更新逻辑。产品设计见云仓 `提案/豫言工作台设计.汉语.md`，改版计划见云仓 `提案/C0002-豫言云控制台改版.汉语.md` 第五节第 4 步。

## 模块

| 模块 | 内容 |
| --- | --- |
| `模型` | 工作台状态（资源树、标签与文件页、主副编辑组、搜索、包视图、构建输出、改名与删除确认）与改状态的纯函数 |
| `视图` | 工作台消息、界面视图（「工作台视图」「工作台宽度视图带任务」等）、配色与源码着色 |
| `更新` | 更新逻辑：「更新工作台」（只读）与「更新可写工作台带操作」，以及载入根目录、打开资源、刷新忽略规则、阅读链接、应用差异、改名、删除的辅助函数 |
| `会话文件` | `.会话` 文件的中文结森格式 |
| `修改差异` | 修改快照与逐行差异展示 |
| `包浏览` | 包树：发现包描述（经包配置解析）、层级与所属包 |
| `构建诊断` | 从编译器输出提取诊断位置 |
| `忽略规则` | `.gitignore` 规则 |
| `文件搜索` | 递归文件搜索 |

默认导入是这九个模块，`寻观「工作台」之书。` 一次打开全部。

## 服务注入

读写都经运行环境注入。读用用户态桌面「文件浏览」模块的「浏览服务」：`列目录` 与 `读文本`，路径是以正斜线分隔的相对路径，空文字为根。写用调用者传入的写文本、改名、删除三个函数，都返回「浏览文本结果」，失败时工作台保留缓冲与修改标记并在状态栏显示原因。

```yuyan
「更新工作台」乃化「浏览服务」而化「工作台消息」而化「工作台状态」而「工作台状态」也。

「更新可写工作台带操作」乃
  化「浏览服务」而
  化「写文本」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「改名」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「删除」为（化「字符串」而「浏览文本结果」）而
  化「工作台消息」而
  化「工作台状态」而
  「工作台状态」
也。
```

「更新工作台」对保存、改名、删除与会话发送只给提示；检查、构建、类型检查给出“需要运行环境提供构建服务”的提示；侧栏拖动与停止构建原样返回状态。运行环境要接构建、模型请求与侧栏拖动时，在调用这两个函数之前先接管这些消息，原生工作台的「后台构建」模块就是这样做的。

## 使用者

- 原生工作台 `应用/开发工具/豫言工作台`：它的「更新可写工作台」把授权目录的写文本、改名、删除传给「更新可写工作台带操作」；后台构建、模型请求、原生窗口与授权文件读写留在原生包里。
- 浏览器：[工作台网页](网页/包说明.汉语.md) 的「运行网页工作台」，示例见 `应用/开发工具/豫言工作台/网页示例`。

## 依赖闭包

本库依赖用户态桌面，用到其中的文件浏览与标记文预览两个模块。浏览器应用经双宿主构建时，依赖闭包会带上用户态桌面所依赖的包与八个系统接口（任务监测、剪贴板、基础、子程序、字体、文件、时间、显示，浏览器都有适配），多出的只是接口绑定与接口清单：程序只编入实际导入的模块，导入表里只有标准库、构建基础与浏览器宿主三组。包浏览经包配置用编译器核心的语法分析，源码文档与源码着色也用它，所以浏览器程序约 1.2 MB。
