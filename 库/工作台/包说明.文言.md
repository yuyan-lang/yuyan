# 工作台

豫言工作台与平台无涉之部，自可执行包「豫言工作台」（`应用/开发工具/豫言工作台`）抽出。原生工作台与浏览器工作台（[工作台网页](网页/包说明.文言.md)、云端代码页）共此一份之态、视图与更新。产品之设见云仓 `提案/豫言工作台设计.汉语.md`，改版之计见云仓 `提案/C0002-豫言云控制台改版.汉语.md` 第五节第四步。

## 诸模

| 模 | 所含 |
| --- | --- |
| `模型` | 工作台之态（资源树、签与文页、主副编辑组、搜索、包视、构建之出、更名与删除之确）与易态之纯函 |
| `视图` | 工作台之消息、界面之视图（「工作台视图」「工作台宽度视图带任务」等）、配色与源码着色 |
| `更新` | 更新之理：「更新工作台」（惟读）与「更新可写工作台带操作」，及载根目、开资源、刷忽略之规、阅读之链、施差异、更名、删除诸辅函 |
| `会话文件` | `.会话` 文之中文结森格式 |
| `修改差异` | 修改之快照与逐行差异之示 |
| `包浏览` | 包树：寻包之述（经包配置析之）、层级与所属之包 |
| `构建诊断` | 自编译器之出取诊断之位 |
| `忽略规则` | `.gitignore` 之规 |
| `文件搜索` | 递归之文搜 |

默认导入即此九模，`寻观「工作台」之书。` 一举尽开之。

## 服务之授

读写皆经运行之境所授。读用用户态桌面「文件浏览」模之「浏览服务」：`列目录` 与 `读文本`，径以正斜线分，空文为根。写用呼者所授写文、更名、删除三函，皆还「浏览文本结果」，败则工作台存缓冲与改标，而示其因于状态栏。

```yuyan
「更新工作台」乃化「浏览服务」而化「工作台消息」而化「工作台状态」而「工作台状态」也。

「更新可写工作台带操作」乃
  化「浏览服务」而
  化「写文本」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「改名」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「删除」为（化「字符串」而「浏览文本结果」）而
  化「工作台消息」而
  化「工作台状态」而
  「工作台状态」
也。
```

「更新工作台」于存、更名、删除与会话之发惟示之；检查、构建、类型检查示以“须运行之境供构建之服”；侧栏之拖与止构建，原样还其态。运行之境欲接构建、模型之请与侧栏之拖，则于呼此二函之前先接其消息，原生工作台之「后台构建」模即如是。

## 用者

- 原生工作台 `应用/开发工具/豫言工作台`：其「更新可写工作台」以已授目录之写文、更名、删除授「更新可写工作台带操作」；后台构建、模型之请、原生之窗与授权文件之读写留于原生包。
- 浏览器：[工作台网页](网页/包说明.文言.md) 之「运行网页工作台」，示例见 `应用/开发工具/豫言工作台/网页示例`。

## 依赖之闭

此库依用户态桌面，所用者其文件浏览、标记文预览二模。浏览器之客经双宿主构建，依赖之闭兼带用户态桌面所依之包与八系统接口（任务监测、剪贴板、基础、子程序、字体、文件、时间、显示，浏览器皆有其适配），所增惟接口之绑与接口清单：程序惟编实所导之模，导入之表惟标准库、构建基础与浏览器宿主三组。包浏览经包配置用编译器核心之语法分析，源码文档与源码着色亦用之，故浏览器程序约 1.2 MB。
