# 工作台网页

豫言工作台之浏览器运行之口：以[界面文树](../../界面/文树/包说明.文言.md)后端于页之容器行[工作台](../包说明.文言.md)库之初态、视图与更新。文之读写经呼者所授之服，云端代码页与示例之客共此一口。

## 函

```yuyan
「运行网页工作台」乃
  化「容器」为「字符串」而
  化「服务」为「浏览服务」而
  化「写文本」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「改名」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「删除」为（化「字符串」而「浏览文本结果」）而
  化「初始路径」为「字符串」而
  化「只读」为「爻」而
  「有」
也。

「网页工作台初态」乃化「浏览服务」而化「初始路径」为「字符串」而「工作台状态」也。
```

呼之之式：

```yuyan
「运行网页工作台」
  于「容器」为『工作台容器』
  于「服务」为（「浏览服务」也「组值」【「列目录」者「我的列目录」也，「读文本」者「我的读文本」也】）
  于「写文本」为「我的写文本」
  于「改名」为「我的改名」
  于「删除」为「我的删除」
  于「初始路径」为『示例/入口。豫』
  于「只读」为「阴」
```

- 容器：页中既有元素之 ID；其大由页定之，常满视口。
- 服务：用户态桌面「文件浏览」模之「浏览服务」。`列目录`（径）得「浏览目录已得」目录项之列（名、为目录否）或「浏览目录失败」；`读文本`（径）得「浏览文本已得」正文或「浏览文本失败」。径以正斜线分，空文为根。此诸函中可呼浏览器宿主之异步之能（如网页请求），程序于 JSPI 下悬而待其果。
- 写文（径，正文）、更名（源径，目径）、删除（径）：皆还「浏览文本结果」，成得「浏览文本已得」（其文不用），败得「浏览文本失败」带中文之因；败则工作台存缓冲与改标，示其因于状态栏。存之以 命令（或控制）加 S，或于源码框按 命令（或控制）加回车。
- 初始之径：始后所开之文；空文则惟载根目。读败则示其因于状态栏。
- 只读：阳则三写函不见呼，存、更名、删除与会话之发惟示之。

视图为工作台库之「工作台视图」：资源侧栏宽二百二十逻辑之素，副编辑组恒依态而显，排版付浏览器。检查、构建、类型检查与模型之请，于此惟示之。欲接构建服务之运行之境，以「网页工作台初态」「工作台视图」与工作台库之「更新可写工作台带操作」自组更新之函（先接检查、构建、类型检查诸消息，余付之），乃付界面文树之「运行界面」。

## 页

页置一容器与浏览器宿主之启脚；基础样式表与界面所用之样式规则由界面文树装于页。

```html
<div id="工作台容器"></div>
<script type="module" src="./自动启动.mjs?标识=工作台容器"></script>
```

页定容器之大，如 `html,body{margin:0;height:100%;}#工作台容器{height:100%;}`。服务端或构建时可以界面库之「首屏容器超文本」，以「工作台视图」于（「网页工作台初态」于 服务 于「初始路径」为 径）生首屏容器而置于页；首帧同则界面文树径接之，不重画。

