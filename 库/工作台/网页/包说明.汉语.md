# 工作台网页

豫言工作台的浏览器运行入口：用[界面文树](../../界面/文树/包说明.汉语.md)后端在页面容器里跑[工作台](../包说明.汉语.md)库的初始状态、视图与更新逻辑。文件读写经调用者传入的服务，云端代码页与示例应用共用这一个入口。

## 函数

```yuyan
「运行网页工作台」乃
  化「容器」为「字符串」而
  化「服务」为「浏览服务」而
  化「写文本」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「改名」为（化「字符串」而化「字符串」而「浏览文本结果」）而
  化「删除」为（化「字符串」而「浏览文本结果」）而
  化「初始路径」为「字符串」而
  化「只读」为「爻」而
  「有」
也。

「网页工作台初态」乃化「浏览服务」而化「初始路径」为「字符串」而「工作台状态」也。
```

调用写法：

```yuyan
「运行网页工作台」
  于「容器」为『工作台容器』
  于「服务」为（「浏览服务」也「组值」【「列目录」者「我的列目录」也，「读文本」者「我的读文本」也】）
  于「写文本」为「我的写文本」
  于「改名」为「我的改名」
  于「删除」为「我的删除」
  于「初始路径」为『示例/入口。豫』
  于「只读」为「阴」
```

- 容器：页面里已有元素的 ID；大小由页面决定，通常撑满视口。
- 服务：用户态桌面「文件浏览」模块的「浏览服务」。`列目录`（路径）得「浏览目录已得」目录项列（名称、是否目录）或「浏览目录失败」；`读文本`（路径）得「浏览文本已得」正文或「浏览文本失败」。路径是以正斜线分隔的相对路径，空文字为根。这些函数里可以调浏览器宿主的异步能力（如网页请求），程序在 JSPI 下挂起等待结果。
- 写文本（路径，正文）、改名（源路径，目标路径）、删除（路径）：都返回「浏览文本结果」，成功得「浏览文本已得」（内容不用），失败得「浏览文本失败」带中文原因；失败时工作台保留缓冲与修改标记，在状态栏显示原因。保存用 命令（或控制）加 S，或在源码框里按 命令（或控制）加回车。
- 初始路径：启动后打开的文件；空文字只载入根目录。读取失败时在状态栏显示原因。
- 只读：为阳时三个写函数不会被调用，保存、改名、删除与会话发送只给提示。

视图是工作台库的「工作台视图」：资源侧栏宽 220 逻辑像素，副编辑组一直按状态显示，排版交给浏览器。检查、构建、类型检查与模型请求在这里只给提示。要接构建服务的运行环境，用「网页工作台初态」「工作台视图」与工作台库的「更新可写工作台带操作」自己组一个更新函数（先接管检查、构建、类型检查等消息，其余交给它），再交界面文树的「运行界面」。

## 页面

页面放一个容器元素和浏览器宿主的启动脚本；基础样式表与界面用到的样式规则由界面文树装进页面。

```html
<div id="工作台容器"></div>
<script type="module" src="./自动启动.mjs?标识=工作台容器"></script>
```

页面给容器定大小，例如 `html,body{margin:0;height:100%;}#工作台容器{height:100%;}`。服务端或构建时可以用界面库的「首屏容器超文本」，以「工作台视图」于（「网页工作台初态」于 服务 于「初始路径」为 路径）生成首屏容器放进页面；首帧相同时界面文树直接接管，不重画。

## 构建

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy双宿主构建.wasm --自动 浏览器 <应用目录> <输出目录> --包根 库
```

依赖闭包与程序大小见[工作台](../包说明.汉语.md)“依赖闭包”。示例应用见 `应用/开发工具/豫言工作台/网页示例`。
