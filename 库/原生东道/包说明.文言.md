# 原生东道

原生执行器所供之手柄宿主之函也。其无体之声明在 `手柄东道。接口。豫`，编为导入模块「原生东道」之带型导入，实于客体之 `豫言操作系统/裸机/客体二号/手柄原语。底层。豫`。

## 诸函

| 函 | 参 | 还 |
| --- | --- | --- |
| `手原数` | 无 | 已接之柄数；无权读输入之器则负一 |
| `手原名` | 枚举之序 | 器之名；越界则空文 |
| `手原钮` | 序、钮之下标 | 千分之整（零至一千）；柄不在或越界则负一 |
| `手原枢` | 序、枢之下标 | 千分之整（负一千至一千）；柄不在或越界则负二千 |
| `手原候` | 毫秒之数 | （种、序、名）：种零无变、一接、二拔、三无其能 |
| `手原振` | 序、强、毫 | 零已发、二无其能、三柄不在；零点一版一律答二 |

## 宿主之行

林纳读 `/dev/input/event0` 至 `event31`，以器之能（事类、按键、绝对之轴）认常式之手柄，读键位之图与诸轴之今值，依规范归一为十七钮四枢。接拔之变，每二十毫秒重扫输入之目而校其号。

林檎与轩窗暂答暂不可用。裸机之通用串行 HID 手柄驱留待后版。

原生之适配 `辔原生` 惟依本包之手柄东道，不径依执行器内之原语号。
