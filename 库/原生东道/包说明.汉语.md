# 原生手柄东道

原生执行器提供的手柄宿主函数。无体声明在 `手柄东道。接口。豫` 里，编成导入模块「原生东道」的带类型导入，实现在客体的 `豫言操作系统/裸机/客体二号/手柄原语。底层。豫`。

## 函数

| 函数 | 参数 | 返回 |
| --- | --- | --- |
| `手原数` | 无 | 已接的手柄数；没有权限读输入设备时为负一 |
| `手原名` | 枚举次序 | 器名；越界为空串 |
| `手原钮` | 枚举次序、按钮下标 | 千分整数（零至一千）；柄不在或越界为负一 |
| `手原枢` | 枚举次序、轴下标 | 千分整数（负一千至一千）；柄不在或越界为负二千 |
| `手原候` | 毫秒数 | （种, 序, 名）：种零无变、一接、二拔、三无能力 |
| `手原振` | 枚举次序、强度、毫秒 | 零已发、二无振动能力、三柄不在；0.1.0 一律答二 |

## 宿主行为

林纳读 `/dev/input/event0` 至 `event31`，用设备能力（事件类、按键、绝对轴）认出标准布局的手柄，读按键位图与各轴的当前值，按规范归一成十七个按钮与四个摇杆。热插拔靠每二十毫秒重扫输入设备并比较设备号。

林檎与轩窗暂答资源暂不可用。裸机的通用串行 HID 手柄驱动留待后续版本。

原生适配 `辔原生` 只依赖本包的手柄东道，不直接依赖执行器内部的原语号。
