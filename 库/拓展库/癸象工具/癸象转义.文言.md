# 癸象 JSON 串转义

此篇述 `癸象解析` 与 `癸象表示` 如何处 JSON 串中之转义。

- 解者，运行时内建之术 `豫言_字符串获取JSON字符串` 也。网页汇编之目标（凡以 `豫言操作系统/宿主/网页汇编/运行时.wat` 组成之程序，含云工与浏览器）行于其 `$json_string`；原生之目标行于 `豫言操作系统/宿主/原生/运行时/字符串.c`。二处之行相同。
- 编者，本目录 `癸象数据结构。豫` 之 `癸象字符串转义` 也（键名与串值皆经之）。

## 解

| 书法 | 所得 |
| --- | --- |
| `\"` `\\` `\/` | 双引、反斜、斜 |
| `\b` `\f` `\n` `\r` `\t` | 退格（八）、换页（十二）、换行（十）、回车（十三）、制表（九） |
| `\uXXXX`（四位十六进，大小写不拘） | 其码点之 UTF-8。例：`中` 得「中」，`\u001b` 得字节二十七，`é` 得二字节 |
| 高代理项 `\uD800`至`\uDBFF` 之后紧随低代理项 `\uDC00`至`\uDFFF` | 合为一码点，书为四字节 UTF-8。例：`😀` 得 U+1F600 |
| 孤高代理项或孤低代理项 | 代以 U+FFFD（EF BF BD），与 `TextEncoder` 处 JS 串中孤代理项同 |
| `\u0000` | 得字节零（详下） |
| 余反斜书法：`\u` 后不足四位或杂非十六进之字、`\x41`、`\0`、`\a`、末端孤反斜 | 畸形。运行时即止：网页汇编为 `unreachable` 之陷阱，原生为报错而退。豫言之 `尝试运行` 不能捕；云工应用中，则本事失败，见壳界之 `RuntimeError` |

- 串中未转义之原字节（含原控制字符与任意 UTF-8）仍宽容，原样存之，不验 UTF-8 是否合法；此旧行也，未改。
- 宿主 JS 之 `JSON.stringify` 于控制字符书 `\u00xx`，于孤代理项书 `\udXXX`（良构之 JSON.stringify）。故自句柄桥还豫言之 JSON（查询参数、标头值、`request.json()` 之果……）可含 `\u001b` 之类，今皆能正解。
- 应用若以**不可信之原 JSON 文**径授 `癸象解析`，则畸形转义将止全事而不复报四百。宜如 `读取入站癸象正文文`：使宿主先以 `JSON.parse` 验之，复以 `JSON.stringify` 授豫言。

## 编

`癸象表示` 所出之串，与 ECMAScript 之 `JSON.stringify` 逐字节相同：

| 字 | 出 |
| --- | --- |
| `"` `\` | `\"` `\\` |
| 退格、制表、换行、换页、回车 | `\b` `\t` `\n` `\f` `\r` |
| U+0000 至 U+001F 余下之控制字 | `\u00xx`，四位、十六进**小写**（如 `\u001b`） |
| `/`、U+007F（DEL）、U+2028、U+2029 及余一切字 | 原样而出，不转义 |

快径 `癸象字符串无需转义` 以小于 0x20 之字节、双引、反斜为须转义；余字节之串，原样而还。无控制字之串，所出与旧版逐字节同，编译缓存 JSON 不受其扰；含 `\n` `\t` `\r` `\b` `\f` 者亦同旧版；唯昔日原样而书之他控制字（如 ESC），今书为 `\u00xx`，遂成宿主 `JSON.parse` 所受之合法 JSON。

## 取舍与界

1. `\u0000` 解为字节零。豫言之串乃带长之字节列（网页汇编为 `$bytes` 数组，原生为「长度加隐藏末零」之缓冲），字节零不为串终；`癸象表示` 复书之为 `\u0000`，往还无损。其代价：若以此串授诸按 C 串行事之宿主原语（如文件路径、进程参数），则或于零处截断，用者自审。
2. 孤代理项有损：UTF-8 不能表之，唯代以 U+FFFD。不取「即止」（公开接口将为一条畸形之数所拒），亦不取径书三字节（其为非法 UTF-8，`TextDecoder` 与 `JSON.parse` 皆将改写或拒之）。
3. 畸形转义仍止，与旧行同；本库不设「容错解析」。
4. 编码器不转义 U+2028、U+2029 与 DEL，与 `JSON.stringify` 同；合法 JSON 许其在串中。
5. JS「逐 UTF-16 码元」之视角与本库无涉：豫言之串以 UTF-8 字节存之，`串长度` 以码点计；非 BMP 之字，于本库为一字（四字节），非二码元也。

## 验

- `癸象数据结构。测试。豫`：验编码器（三十一控制字皆验、DEL、U+2028/2029、`/`、键名、数组）与不涉宿主之解析；原生与网页汇编皆可行。（其中小数三例，即 `1.2`、`12.12` 与含小数之数组，因 `小数表示` 出 `1.200000` 而败，与转义无涉，改前已然。）
- `癸象转义。测试。豫`：验 `\u` 之解（大小写、代理对、孤代理项、`\u0000`、DEL、U+2028/2029、往还）；须网页汇编运行时，或重建原生运行时库（`make 运行时`）后原生而行。
- `豫言操作系统/宿主/网页汇编/一致性验证/`：`$json_string` 之穷举低层对拍（六万五千五百三十六个 `\uXXXX`、一百零四万八千五百七十六个代理对、畸形必陷）与端到端云工应用对拍，详其中 `说明.文言.md`。
