# 云仓现用能力验收

核查日期：2026-09-24。依据当前 `yuyan-cloud` 的官网入口、云工作台与包管理服务源码和 Wrangler 配置；这里只记录宿主库迁移所需能力，不修改云仓业务代码。“已验证”均指本地浏览器或 workerd，尚不代表生产部署完成。

| 现用场景 | 宿主能力 | 当前验收 |
|---|---|---|
| 官网 `网站/入口/平台.mjs` 的产品页、性能页及其他静态路径 | `ASSETS.fetch`、原请求转送、`Request(url, request)` 改址 | 豫言接口与构建产物已在 Wrangler 4.129.0 本地 workerd 用真实静态文件验证；完整路径判断、URL 解码、查询串与重定向尚待豫言实现及验收 |
| 官网向 CLOUD、REGISTRY 分流；云工作台向 REGISTRY、BROWSER_COMPILER 转送 | Service binding 原生 Request/Response | 两份豫言 Wasm Worker 经本地 workerd Service binding 相连，POST 得 HTTP 201 且 `00 FF 41` 无损；各业务路由、鉴权标头策略及取消待验 |
| 云工作台项目、任务、站点状态 | Durable Object 内部 SQLite、事务、alarm | 本地 workerd 已验豫言对象 fetch、字符串存储、参数化 SQLite SQL 与 alarm，且重启后仍可读；预先列出的同步 SQL 事务与 JSON 兼容对象已本地验收，且失败事务回滚；交互式事务、其他结构化克隆值和完整对象生命周期待补 |
| 包管理服务后台页面与归档 | Queue `send`、`sendBatch`、消费事件 | 生产者单条、批量接口经真实 Wasm 验证；本地 workerd 已验证生产→消费→KV 状态跨事件往返；现有业务消息模式、批量失败与重试时序待验 |
| 包管理服务账户邮件 | Send Email 绑定 `send` | 文字 EmailMessageBuilder 经真实 Wasm 与模拟绑定验证；实际发送与错误语义待验 |
| 云工作台隔离运行 | Worker Loader `load`、`get`、模块装载及限额 | 豫言 Wasm 通过本地 Wrangler 4.129.0 的真实 Loader `load` 与重复 `get` 装载隔离子 Worker，均返回 HTTP 200 与子程序响应；子 Worker 只含宿主 JS 与豫言 Wasm，父 Worker 不向其授予环境绑定或外发网络；生产隔离、限额触发、缓存换码与任务协议仍待验 |
| 包管理服务的 PROVIDER_CONNECTIONS 与 CLOUD_SITES | Durable Object 桩及 Service binding | Service 原生请求路径已验证；对象标识、桩生命周期及长连接待验 |
| 云工作台和包管理服务的 D1、R2、KV | 数据库及对象、键值绑定 | 基础文字路径已有；查询、事务、字节、分页与条件操作待逐项补验 |
| 浏览器工作台 | DOM、事件、Fetch、Streams、Cache | 浏览器宿主已有局部能力及真实浏览器样例；页面完整业务逻辑仍需按 Web IDL 逐项封装 |

官网 Worker 路由最早可用的宿主原语是 `云工请求句柄`、`云工请求改址`、`云工资产请求句柄`、`云工服务请求句柄`、`云工设置响应句柄`。构建器生成 `入口.mjs`、`程序.wasm` 与 `值桥.wasm`；许可文件至少按实际绑定列出 `ASSETS` 和 `SERVICE` 名称。业务路由应在豫言中编写。现有验证足以开始编写和本地联调，尚不足以声称官网全部路径可迁移上线。
