# 浏览器宿主覆盖清单

BroadcastChannel 子书以真 Chrome 验：页内二豫言频道互传癸象可容之值，单向传 `00 FF 41` 原字；页与 Dedicated Worker 之豫言 Wasm 又借同名频道通。`messageerror`、繁复克隆及跨页签诸境待验，详 `广播频道接口.清单.tsv`；其义据 [HTML 广播频道规范](https://html.spec.whatwg.org/multipage/web-messaging.html#broadcasting-to-other-browsing-contexts)。

TextEncoderStream、TextDecoderStream 今有豫言门。真 Chrome 验两段文字成六字节 UTF-8、汉字三字分两块而完读、BOM 跨块而默认略之，并察 `encoding`、`fatal`、`ignoreBOM`；坏 UTF-8 严解归 TypeError，宽解出替换字符。背压待验，详 `流式编码接口.清单.tsv`；其义据 [Encoding 标准](https://encoding.spec.whatwg.org/#interface-textdecoderstream)。

可断 fetch 以真 Chrome 验：客先取在途求柄，继断 AbortSignal，安全候则归 AbortError；未断者得 Response 柄、二百状态及正文。预断之自定理由与无效待柄亦验，详 `网络中断接口.清单.tsv`；其义据 [Fetch 标准](https://fetch.spec.whatwg.org/#dom-global-fetch)。

AbortController、AbortSignal 子书以真 Chrome 验控制器断、对象与文字理由、重断、`abort()`、`any()`、`timeout()` 静法、`throwIfAborted()` 安全察及 `abort` 事候。`timeout(-1)` 归 RangeError，详 `中断接口.清单.tsv`；其义据 [DOM 中断标准](https://dom.spec.whatwg.org/#aborting-ongoing-activities)。

URI 及其成分之编解码四术，以真 Chrome 验；坏 `%` 与非法 UTF-8 归阴及 `URIError` 文。`浏览器调用全局安全` 亦验同步错及 Promise 拒绝皆归显式结果，详 `网址编解码接口.清单.tsv`；错义据 [ECMAScript URI 诸法](https://tc39.es/ecma262/multipage/global-object.html#sec-decodeuricomponent-encodeduricomponent)。

Event、EventTarget 今有具名豫言诸门。真 Chrome 验捕获与目标之序、`once`、AbortSignal 撤听、同目标同名多听独撤、`passive` 不止默认、同步止传播及同处后听、`dispatchEvent()` 归值，且于回调当刻存 target、currentTarget、composedPath、eventPhase。默认被动之策及旧属性诸界尚待验，详 `事件接口.清单.tsv`；其义据 [DOM 标准](https://dom.spec.whatwg.org/#events)。

FormData 子书以真 Chrome 验空造、表格并提交钮之造、重名序、文字与文件之添置、删取、键值遍历及 Request、Response multipart 往返；原字 `00 FF 41` 无损。诸表格控件尚待验，详 `表单数据接口.清单.tsv`；其义据 [XMLHttpRequest 标准](https://xhr.spec.whatwg.org/#interface-formdata)。

FormDataEvent 之造、列中取事及原生 `formdata` 投事，真 Chrome 皆验。事同步发而客后取列，故不得以后取改已成之原生提交；可先止 `submit`，由客取 `SubmitEvent.submitter`，自行造、改、送表单。此径已验 `requestSubmit` 与 multipart 往返，详 `表单数据接口.清单.tsv`；时序据 [HTML 表单提交标准](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#form-submission-algorithm)。

Blob、File 子书今以真 Chrome 验原字 `00 FF 41`、诸部件合物、负索引截取、原生 `bytes()`、字流与 `textStream()`，及文件名、类别、修改时。FileReader 四读法、诸终事与 FileList 亦验；文件由程序置于输入框，真人择件之途及错事尚待验。详 `物字文件接口.清单.tsv`、`文件读取接口.清单.tsv`；其义据 [W3C File API](https://w3c.github.io/FileAPI/)。

可写流写器今以真 Chrome 验：客先发两块及闭流之待柄，读压字后逐候其成，解回 `00 FF 41`；锁、初就、已闭、释柄及中断皆过。满载背压尚待验，详 `可写流接口.清单.tsv` 及 [Streams 标准](https://streams.spec.whatwg.org/)。

压缩流今有豫言门，真 Chrome 验 gzip、deflate、deflate-raw 三式之原字 `00 FF 41` 往还；客复以两块入流，经压解双管而原字复得。坏 gzip 与无效格式归阴。满载背压与诸引擎异同尚待验，详 `压缩流接口.清单.tsv`；接口据 [Compression 标准](https://compression.spec.whatwg.org/)。

定时子书今以一次、重复之期投豫言事列。真 Chrome 三收周期事，撤后得真，复撤得假，终收一次事；客得号、标、类及时刻，自裁更新。后台节流与久行尚待验，详 `定时接口.清单.tsv` 及 [HTML 定时器规范](https://html.spec.whatwg.org/multipage/timers-and-user-prompts.html)。

事件源子书已于真 Chrome 跨源接本地 SSE，得自定 `notice`、文「甲」与号 `7`，豫言继而断联。常信、错事、重联及含凭据之界尚待验，详 `事件源接口.清单.tsv`；据 [HTML EventSource 规范](https://html.spec.whatwg.org/multipage/server-sent-events.html)。

消息通道子书以真 Chrome 之豫言 Wasm 验：两端传象文，移字缓冲而读 `00 FF 41`；又以甲通道移乙通道之端，转入后犹能通。复杂克隆、跨工转端及错事尚待验，详 `消息通道接口.清单.tsv`。[HTML 消息端口规范](https://html.spec.whatwg.org/multipage/web-messaging.html)载转移与事义。

长联子库今与云工 WebSocketPair 双端相验：真 Chrome 之豫言 Wasm 收开事，送「豫言」而得回文，复送 `00 FF 41` 并逐字验返；断联事至，释其柄。子协议、错事、非常断联、Blob 形与缓冲边界尚待验，详 `套接字接口.清单.tsv`；浏览器诸术据 [WebSocket API](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket)。

`浏览器请求文字安全` 今遇 fetch 或读正文之败，归阴与事故文；HTTP 虽为错码而有答，仍归阳与状态正文。真 Chrome 验连接拒得阴、`TypeError`，本地 HTTP 404 得阳、状态 404，豫言犹可更页。重试、取消与超时尚待补，详 `网络请求接口.清单.tsv`；义据 [Fetch 标准](https://fetch.spec.whatwg.org/)。

索引库又有原生 `IDBKeyRange` 柄与游标快照。真 Chrome 已验 only、bound、lowerBound、upperBound、includes，bound 可为 getAll 之参；对象仓逆游与索引唯键游皆还键、主键与值。宿主于同一事务之请事回调续游，客定来源、界、向与限数。临时推进、游中写及非文字键尚待补，详 `索引库接口.清单.tsv`。

索引库今有豫言初门：升级之 stores/indexes 由客定，同事务诸术亦由客预列；宿主于活期一并排请，提交后归逐请之果。真 Chrome 已验建仓、建索引、批写、计数、读值、列键、索引寻值、无值标、闭而复开、列库及删库；重键之 `add` 使先前 `put` 同退，安全门归 `ConstraintError`。无头 Chrome 虚拟时刻之快照于原生索引库探针亦未候毕，故终验据真 Chrome 实页。游标、键界、跨事动态事务、非癸象克隆及跨标签页之界尚待补，详 `索引库接口.清单.tsv`。义据 [Indexed Database API 3.0](https://www.w3.org/TR/IndexedDB/)。

受限文档之饼与史遇 `SecurityError`，今有明辨之门；新豫言术归许否，旧术逢此拒仍续行，诸余 JS 事故不掩。旧已编豫言界面 Wasm 于 JSDOM 沙箱验：饼之取写与史之 `replaceState` 皆抛拒，犹可易语言；新术亦验其阴。重构正常页于真 Chrome 示「导航与饼通过」，详 `导航接口.清单.tsv`。

网页二域之储存今有豫言具名门：取、写、删、清、按序取键与计数，空文与无值不混。真 Chrome 以豫言父子二器验之：子器在同源 iframe 写本地仓，父器收真 `storage` 事，辨区域、键与新值。异标签、会话域之事、异常及诸文档并发尚待验，详 `储存接口.清单.tsv`。义据 [HTML Standard Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html)。

页呼豫言之公开操作通约已验于真 Chrome：注册空间、事列传参、按号异步成拒、双请逆序还果及客毕清名，皆通；自启之就绪 Promise 与条件启动亦通。同步返值尚缺豫言 Wasm 另出入口，详 `公开操作接口.清单.tsv`。

通用 `浏览器调用方法原始` 行 `Node.appendChild`，真 Chrome 已验节点入树且得同一 Node 柄；先立 MutationObserver 而后调用，亦得之。先前增强观察样例之 `illegal cast` 未于此最小路复现，其触发之由尚待核。

Cookie Store 之异步读、枚举、设、删与变事，今以真 Chrome、豫言 Wasm 验之；History 回进之 `popstate`，及 MutationRecord 之类、目标、新增节点柄，亦已验。分区、过期、跨文档史遍历与变动记录余字段，尚待逐术核之。

官网共用界面之饼读写、Location 取址、History 推替、MutationObserver 回调及 TreeWalker 文本遍历，今有豫言门且真 Chrome 已验。跨页导航、History.go、变动记录诸属性与游标过滤器尚待补验，详 `导航接口.清单.tsv` 与 `文树观察接口.清单.tsv`。

真 Chrome 又验 AES-GCM 可导钥之生成、出入，及 PBKDF2、HKDF 以 SHA-256 衍生二百五十六位字节与不可导钥，二者可互解。诸余钥式、用途、算法及事故之界尚待补。

Web Crypto 之随机识别、随机字节、SHA-256、AES-GCM 原钥与 HMAC 原钥已有具名豫言门，真 Chrome 验摘要之长与首字节、密往返及签之真伪；其余钥式、算法与派生诸术尚待补，详 `密码接口.清单.tsv`。

以二〇二六年九月二十四日为基。接口之形取 [W3C Webref](https://github.com/w3c/webref) 所校 Web IDL；浏览器实具与否，验 [MDN 兼容资料](https://github.com/mdn/browser-compat-data) 之 `api`。仓中今有 MDN 8.1.2 原始路径及 Chrome、Firefox、Safari 支持撮要一万零二百六十五项，来源、哈希、断法见 `接口路径来源.json`。一位唯谓 BCD 有无旗未移之支持记录；未核浏览器今版、部分实现、试验或废弃之状。诸径与 Webref IDL 今唯同名初配；不得以其数冒称待作之数或已成之率。

又录 `@webref/idl` 3.84.0 原始规范成员：规范三百三十四、上层定义三千六百四十八、成员一万一千五百一十九，别有无成员定义九百九十九，合一万二千五百一十八行。来源、解器及哈希见 `规范成员来源.json`。册中有字典之域、常数及不可直呼之定义，非谓同数之浏览器 JS 术；部分、混入、继承及 BCD 特径尚待合校。

`规范兼容对齐.清单.tsv` 今以同名 interface、callback interface、namespace 与 BCD `api` 初配，直得五千三百三十六行；余类及哈希见 `规范兼容对齐来源.json`。得径唯证 BCD 有记，不谓豫言已封；无同名径亦不谓浏览器无术。混入、包含、继承、别名、特性之径及 BCD 独有者，皆待后合。

`Headers` 之 BCD 十五径，今于 `工具/宿主接口清单/标头覆盖.清单.tsv` 逐记两端所验及未竟；一径未必即一独立之法。

`Cache`、`CacheStorage` 之 BCD 十七径，今于 `工具/宿主接口清单/缓存覆盖.清单.tsv` 逐记。浏览器 Cache 子库已有规范所名诸法之基门：`Cache.add/addAll/put/match/matchAll/delete/keys` 与 `CacheStorage.open/has/delete/keys/match`。本地真浏览器载豫言 Wasm，三静态资源由 add、addAll 入藏，句柄列、跨仓匹配及删除皆验，页示「缓存往返通过」。[Service Workers 规范](https://w3c.github.io/ServiceWorker/#cache-interface)之查询选项、批量败时之原子性、异常及 Worker 暴露，尚待逐验。

`URL` 与 `URLSearchParams` 之 BCD 四十径，今于 `网址接口.清单.tsv` 逐录。浏览器子库已有构造、相对解析、属性读改、活动查询参数、增删排序与化列、静析及 Blob 物址之门。真 Chrome 载豫言 Wasm，页示「网址操作通过」；查询参数改而网址随之、重名项、记录与有序双项之造、静析及游列，皆有验。原生 `forEach` 回呼、符号游历及部分属性之边尚阙。诸义据 [WHATWG URL 标准](https://url.spec.whatwg.org/)。

今验豫言 WasmGC 借 JSPI 候网答，按名改文树；点击、输入、变更、提交诸事件及本地储存亦有声明。句柄桥已验豫言呼异步对象方法，亦有构造、属性、方法与订阅之门。诸门未依 Web IDL 逐验，不可谓已尽 Fetch、DOM、Storage 之全。

`Headers` 之构造、成对初值、get、getSetCookie、has、set、append、delete、entries/keys/values 化列及原生 entries 游标启取终释，已以 Node/V8 豫言 Wasm 经浏览器桥验之；本地真浏览器载构建物，亦显 `one, two|a=1|b=2|set-cookie|set-cookie|a=1|set-cookie|b=2`。`forEach` 今以豫言快照回呼；遍历中改标头之实时义、保护状态与诸浏览器之异同，尚未逐验。接口之形见 [Fetch 规范](https://fetch.spec.whatwg.org/#headers-class)。

字节桥已以真 Wasm 验之：豫言字节串经 `Uint8Array` 柄入 Blob，又由 `arrayBuffer()` 取回；零与高位皆不失。一次传值今限十六 MiB，大文与长流尚待验。

流桥又以真 Wasm 验三块 `00`、`FF`、`41` 经 `ReadableStream` 入 `Response.arrayBuffer()`；本地浏览器试页明示「浏览器流式往返通过」。事件订阅亦以 Node/V8 之 `EventTarget` 验回呼。长流、取消与诸浏览器异同，尚待逐验。

成事之验：逐接口记规范、运行处、浏览器支持、豫言声明、JS 桥、行为试验及未具之由。各能力之构造、属性、方法、事件、异步果、异常及客柄寿命皆须有据。新规范与新浏览器另记增量；空有声明不算已成。

浏览器构建物今含 `自动启动.mjs`：页唯以 module script 载之，可借 `标识` 查询参择启否。真 Chrome 已验标识在则示「网址操作通过」，不在则仍示「未启动」；静态服务之记又证后者未取 Wasm。此物唯载器与起其寿，页事仍归豫言。

文树子库今有 Document、Element、Node 之豫言门：按标识及选择符求节点、造元素与文本、附删、读改文字属性，并化 NodeList 为节点柄列。`文树接口.清单.tsv` 逐录此批 BCD 径之所验、唯封与待补。真 Chrome 载豫言 Wasm，页示「文树往返通过」，已验造、属性、查询、枚举及移除；带选项之 `createElement`、Trusted Types、事件之全义与其余诸术尚待逐补。诸义据 [WHATWG DOM 标准](https://dom.spec.whatwg.org/)。

《类名与样式。豫》今有活动 `classList` 与元素行内 `style` 之豫言门。`类名样式接口.清单.tsv` 逐配 BCD 中 DOMTokenList、CSSStyleDeclaration 三十二径。真 Chrome 载豫言 Wasm，页示「类名样式通过」；类名之增删切换替换、CSS 属性、优先级、删除及 `cssText` 往返皆验。游历、回呼、旧式 CSSOM 及诸浏览器异同尚待补。诸义据 [WHATWG DOM](https://dom.spec.whatwg.org/#interface-domtokenlist) 与 [CSSOM](https://drafts.csswg.org/cssom/#the-cssstyledeclaration-interface)。

事件子库今增豫言先记之默认动作止策，亦可明撤订阅。`事件接口.清单.tsv` 逐标 Event、EventTarget、SubmitEvent 之 BCD 三十八径。真 Chrome 中，豫言订阅 submit 后，普通 GET 表单点击不转址，Wasm 所收 `已阻止默认` 为真。原生监听诸选项、逐事同步由豫言裁断、传播控制及事件诸域尚待补。[WHATWG DOM 标准](https://dom.spec.whatwg.org/#events)明 `preventDefault()` 须于适用之监听时行之。
