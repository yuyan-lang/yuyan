# 浏览器宿主库

`广播频道。豫` 备 BroadcastChannel 之造、察名、发象与原字、候事及闭。宿主投 `message`、`messageerror` 入客事列，客自裁得信之行。真 Chrome 已验页内二频道往还、`00 FF 41` 原字无失，及页与 Dedicated Worker 各运行豫言 Wasm 而通。繁复克隆、跨页签与 `messageerror` 尚待验，详 `广播频道接口.清单.tsv` 与 [HTML 广播频道规范](https://html.spec.whatwg.org/multipage/web-messaging.html#broadcasting-to-other-browsing-contexts)。

`空闲回调。豫` 接页之 `requestIdleCallback`、`cancelIdleCallback` 于豫言事列。客可请无期之闲，亦可定 `timeout` 毫秒；宿主于原生回调当刻取 `IdleDeadline.didTimeout` 与 `timeRemaining()`，投 `{名称:"空闲",空闲号,标记,已超时,剩余毫秒}`。真 Chrome 已验二请及撤。闲时由浏览器裁，限期之请亦可先至；Safari 若无此能，宿主明报其阙。详 `定时接口.清单.tsv` 与 [W3C 后台任务规范](https://w3c.github.io/requestidlecallback/)。

`动画帧。豫` 以原生 `requestAnimationFrame`、`cancelAnimationFrame` 接页与有页为主之 Dedicated Worker。宿主唯投帧号、客标及原生时刻于事列，绘制与续请皆由豫言裁之；宿主终则撤余帧。真 Chrome 已别验页与工之请、撤及得事；工内豫言 Wasm 亦验一次时之撤、重复二事及另一次时事。详 `定时接口.清单.tsv` 与 [HTML 动画帧标准](https://html.spec.whatwg.org/multipage/imagebitmap-and-animations.html#animation-frames)。

`工作线程。豫` 今可由客造 module 或 classic 工，发癸象可容之值与可移物列，亦可止工。宿主造工即听 message、messageerror、error，诸信同入客事列，故工速报 ready 而不失。相对址据应用构建目录解之。`工作线程自动启动.mjs` 为构建器所抄定壳，可于 Dedicated Worker 内载另一豫言 Wasm；工内客取自身柄听主信，以 `浏览器工作线程向主线程发值` 答之。真 Chrome 已验页与工皆运行豫言 Wasm，初信、回信、止工悉通；繁复克隆与转移待验。两客若用异源，可分构于页目录与工子目录，而页造工时指其壳，详 `工作线程接口.清单.tsv`。

`事件。豫` 订阅之策可先列 `键盘阻止默认`：每律必有 `key`，可别定 `ctrlKey`、`metaKey`、`altKey`、`shiftKey` 之阴阳；未定者不拘。宿主于原生键事当刻辨律而禁默认，继投键、码、辅键、重复与组字之状于客列。真 Chrome 已验无 Ctrl/Meta 之 Tab 默认被禁，输入框焦点犹在；余组合待验。编译与运行两期之限，可由豫言用既有定时器各定之。

真 Chrome 又验工之端与字缓冲同信转移：页客发 `00 FF 41`，发后原缓冲之 `byteLength` 为零；工客得三字如故，借转入之端答之。页所命工名，工客读而核之；回信后工自 `close()`。同源工脚本阙，`error` 事亦至页客。`messageerror`、逆向转移与闭工竞态尚待验。工信对象柄可由 `浏览器工作线程事件数据字段句柄` 循事文取之。接口据 [HTML 工标准](https://html.spec.whatwg.org/multipage/workers.html)。

`流式编码。豫` 备 TextEncoderStream、TextDecoderStream 之造、察性及读写端柄；`流。豫` 今有文字写器与安全读文门。真 Chrome 已验「甲」「乙」两段写成六字节 UTF-8，断开之汉字与 BOM 亦合之；坏 UTF-8 严解归 TypeError，宽解出替换字符。详 `流式编码接口.清单.tsv`、[Encoding 标准](https://encoding.spec.whatwg.org/#interface-textdecoderstream)。

`网络。豫` 之可断求先还在途待柄，客可断其 AbortSignal，继以 `浏览器请求候回应安全` 取 Response 柄或错文；`浏览器回应文字安全` 取正文。真 Chrome 已验同源二百、在途 AbortError、预断自定理由及无效待柄。详 `网络中断接口.清单.tsv`、[Fetch 标准](https://fetch.spec.whatwg.org/#dom-global-fetch)。

`中断。豫` 使客造 AbortController、取信号、授文字或对象理由、察 `throwIfAborted()`，并用 `AbortSignal.abort()`、`any()`、`timeout()` 与异步候 `abort` 事。真 Chrome 诸术已验；`timeout(-1)` 安全归 RangeError。详 `中断接口.清单.tsv`、[DOM 中断标准](https://dom.spec.whatwg.org/#aborting-ongoing-activities)。

`网址。豫` 备 URI 与成分之四编解码术，归成败爻及文；`句柄。豫` 之 `浏览器调用全局安全` 使同步错与 Promise 拒绝皆为错象文。真 Chrome 已验坏 `%`、非法 UTF-8 与无效网址，详 `网址编解码接口.清单.tsv`、[ECMAScript URI 诸法](https://tc39.es/ecma262/multipage/global-object.html#sec-decodeuricomponent-encodeduricomponent)。

`事件。豫` 可造 EventTarget、Event，发事，先立 capture、once、passive、AbortSignal 等听策，并察事状。同目标同名可由 `浏览器事件订阅多` 立多听，各持号以独撤。客先裁止默认或止传播，宿主于原生回调同步行之，且存 target、currentTarget、composedPath、eventPhase 诸状以待客后取。真 Chrome 已验捕获序、一次听、信号撤听、多听、被动不止默认及同步止同处；余界尚待验，详 `事件接口.清单.tsv`、[DOM 标准](https://dom.spec.whatwg.org/#events)。

`表单数据。豫` 使客造空表、由表格与提交钮造表、添置删取文字与文件诸项，并循原序枚举；文件原字留柄。真 Chrome 已验 `00 FF 41` 经 Request multipart 往返，详 `表单数据接口.清单.tsv` 与 [XMLHttpRequest 标准](https://xhr.spec.whatwg.org/#interface-formdata)。

`formdata` 事可预订而后自客列取，FormDataEvent 亦可由客造。然原生事同步，列中后取不得追改已成之提交。欲以客裁正文，当先以 `浏览器表单拦截提交` 止默认，取 `SubmitEvent.submitter`，再以客造表、改项、发求。真 Chrome 已验此径及 multipart 解析；事序据 [HTML 表单提交标准](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#form-submission-algorithm)。

`物字与文件。豫` 备 Blob/File 原字与合件之造、察元、截取、原生 `arrayBuffer()`/`bytes()`、`text()`、`stream()` 与安全 `textStream()`；`流。豫` 可逐块读文字。真 Chrome 已验 `00 FF 41` 无损、Blob 合 UTF-8 文、负索引截取及 File 名、类、修改时；文字流读回「甲」。`文件读取。豫` 备 FileReader 四读法、察态、候事与 FileList 序取；真 Chrome 已验原字无损、诸终事、程序置件及越界。真人择件与错事待验，详 `物字文件接口.清单.tsv`、`文件读取接口.清单.tsv` 及 [W3C File API](https://w3c.github.io/FileAPI/)。

`流。豫` 今有通用可写流写器：取柄、察锁与容量、候 ready/closed、先发写与闭之待柄，客可先读下游再候诸果。真 Chrome 以 gzip 验两块在途写、闭、读及 `00 FF 41` 解还；有效写器中断后锁释，无效柄安全归误，皆验。满载背压与读端错事尚待验，详 `可写流接口.清单.tsv` 及 [Streams 标准](https://streams.spec.whatwg.org/)。

`压缩流。豫` 有 CompressionStream、DecompressionStream 造流、读写端柄及短字安全转换。真 Chrome 三式 gzip、deflate、deflate-raw 以原字 `00 FF 41` 往还；客又主动写两块，经压解双管而原字复得。坏 gzip 与无效格式归阴及 UTF-8 误字。一次转换于宿主聚全出字，大流宜执端柄；满载背压与取消尚待验。Brotli 可否用依浏览器本能，详 `压缩流接口.清单.tsv` 及 [Compression 标准](https://compression.spec.whatwg.org/)。

`定时。豫` 有一次、重复、取消三门。期至，宿主但投 `{名称:"定时",定时号,种类,标记,时刻}` 入客事列；同号未交之事仅留一，撤则去未交之事，宿主终亦清诸期。真 Chrome 已验三期、撤与一期。业务可订六万毫秒而于 `等待浏览器事件` 中自决取数。后台页之期可迟，不可作精时；详 `定时接口.清单.tsv` 及 [HTML 定时器规范](https://html.spec.whatwg.org/multipage/timers-and-user-prompts.html)。
