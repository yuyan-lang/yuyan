# 诺节宿主

此乃诺节（Node.js）应用宿主之平台接口之包。诸模皆 `。接口。豫` 之文，惟无体之 `乃` 声；编时成导入模块「诺节宿主」之带型 Wasm 导入，字段名即函名，边界之签见《网页汇编接口》网五。实于 `豫言操作系统/宿主/节点/`（`应用宿主.mjs`、`张量.mjs`、`图形.mjs`），由共用胶水 `网页汇编/边界.mjs` 接之；他宿主不供此诸函，载时给桩，调则报“接口函数未绑定”。

此包惟供诺节上之适配（张量计算节点、张量文件节点、文件节点、网络节点、显示节点、图形处理器节点、字体诺节），不入公共之接口；应用当由接口与适配用宿主之能。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟依标准库，平台限诺节，登于「共用库」之下。

## 模

| 模 | 所含 |
| --- | --- |
| `张量原语` | 张量计算与张量文件之五十九原语（函名冠“诺节张量”）：取释上下文、立与读写张量、诸算、跨步视图、自文件载入 |
| `文件原语` | 取所授之目录、开、读、写、闭文件；果之首项为状码 |
| `网络原语` | 出站之求（异步）与正文之限 |
| `显示原语` | 显示面之术，依操作名分派 |
| `图形原语` | 图形处理器之术，依操作名分派，参为结森之文 |
| `字体原语` | 字体之术，依操作名分派 |

模名带“原语”二字，免与适配中之类名（张量、文件、字体等）同名。此步柄仍为字符串；网络发送为异步，宿主惟为之套 JSPI。
