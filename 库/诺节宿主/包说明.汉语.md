# 诺节宿主

这是诺节（Node.js）应用宿主的平台接口包。各模块都是 `。接口。豫` 文件，只有无函数体的 `乃` 声明；编译时编成导入模块「诺节宿主」的带类型 Wasm 导入，字段名就是函数名，边界签名见《网页汇编接口》网五。实现在 `豫言操作系统/宿主/节点/`（`应用宿主.mjs`、`张量.mjs`、`图形.mjs`），经共用胶水 `网页汇编/边界.mjs` 接上；其他宿主不提供这些函数，装载时给桩，调用时报“接口函数未绑定”。

本包只供诺节上的适配使用（张量计算节点、张量文件节点、文件节点、网络节点、显示节点、图形处理器节点、字体诺节），不进公共接口；应用应当经由接口与适配使用宿主能力。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只依赖标准库，平台限诺节，登记在「共用库」之下。

## 模块

| 模块 | 内容 |
| --- | --- |
| `张量原语` | 张量计算与张量文件的五十九个原语（函数名以“诺节张量”开头）：取得与释放上下文、建立与读写张量、各算子、跨步视图、由文件载入 |
| `文件原语` | 取得授权目录、打开、读取、写入、关闭文件；结果首项是状态码 |
| `网络原语` | 出站请求（异步）与正文上限 |
| `显示原语` | 显示面操作，按操作名分派 |
| `图形原语` | 图形处理器操作，按操作名分派，参数为结森文字 |
| `字体原语` | 字体操作，按操作名分派 |

模块名带“原语”二字，免得与适配里的类型名（张量、文件、字体等）同名。句柄这一步仍是字符串；网络发送是异步的，宿主只给它套 JSPI。

## 测试

由节点一致性验证覆盖（`豫言操作系统/宿主/节点/一致性验证/`）。

文件原语增加 `诺节文件列目录`、`诺节文件查询信息`，供文件接口 0.2.0 适配使用，沿用具名目录授权及相对路径边界。

`诺节文件创建目录` 供文件接口 0.3.0 使用，须可写授权，父目录存在且真实路径在授权根内，成功返回零码与空消息。

`子程序原语。接口。豫` 提供 `诺节运行子程序`，供公共子程序节点适配使用。程序名称与环境名称由宿主预授，输入及环境随调用传入，返回状态、退出码、两路输出字节及错误消息；详见节点宿主的双语子程序说明。
