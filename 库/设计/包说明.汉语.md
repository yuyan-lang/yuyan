# 设计

设计语言的引擎库（[提案 00018](../../提案/00018-设计语言与引擎.汉语.md)）。设计源文件 `名。设计。豫` 写 `寻观「设计」之书。`，用构造写法（`「头」【项，…】`，提案 00018 议十九）写作品；作品是普通豫言值，由这个库求值、渲染。

## 模块

| 模块 | 内容 |
| --- | --- |
| `时间` | 「时间」（整数刻，一秒 705600000 刻）、「秒」「毫秒」「分」「帧时」「秒数」「时间表示」「解析时刻」 |
| `设计值` | 「坐标」「原点」「尺寸」「度」、「颜色值」「颜料」（纯色、线性渐变）、「色码」与纸墨朱色板，各类插值 |
| `信号` | 「信号」（常量、关键帧、表达式、叠加、混合、驱动、种子噪声、沿路径）；构造「关键帧」「帧」「随时」「叠加」「混合」「分量」「驱动」「噪声」「沿路径」；「缓动」（线性、缓入、缓出、缓入缓出、贝塞尔、阶跃、分段线性、保持、弹簧）；「求信号」 |
| `场景` | 场景节点与构造：「组」「矩形」「圆」「椭圆」「线」「路径」「文字」「图像」（嵌入素材块）「横排」「竖排」（排列容器）「图层」（模糊、投影「阴影」、颜色矩阵、背景模糊、混合模式、遮罩、绕横绕纵与透视的二维半）「节点们」「数列」与常用颜色矩阵（灰度、亮度、饱和度、反相、色相旋转）；时间线：「片段」「实例」（偏移、变速、循环、往返、定格、保持、时间映射信号）「顺序」「并行」「停留」「事件轨」；作品：「视频」「插画」「图标」与「画面」轨 |
| `数学` | 只用四则的小数工具、自实现的正弦余弦与指数、二维仿射 |
| `折线` | 几何平展成折线、SVG 路径数据、描边化成多边形、按长度比例取点 |
| `设计文字` | 编译时按字体把「文字」排成字形轮廓（平展后简化成 M、L、Z 路径数据，单位千分之一字号）；默认字体是仓库里的思源黑体，作品里同时留着原文 |
| `设计图像` | 图像素材：编译时读入图片文件，留着文件字节（写进素材块）并解码成 RGBA8 像素；「载入图像素材」「解码图像素材」 |
| `求值` | 作品在时刻 t 的二维显示表（「显示元」：填充项、图像或带效果的图层，二维半投影，排列容器按包围盒排开） |
| `设计表达式` | 表达式层的受限中间表示：解析与验证（函数只调前面的、变量序号在范围内、运算名与个数对得上）、代价、求值；「表达式码」「文本表达式」 |
| `渲染` | 中央处理器参考渲染器：显示表画到 RGBA8 画布（整数扫描线、四条子扫描线、非零环绕）；图层合成（W3C 混合模式）、盒式三遍模糊、颜色矩阵、遮罩、投影与背景模糊，编成便图（PNG） |
| `能力` | 能力格：「能力集合」（时间、空间、声音、文字轨、输入、计算、素材、分页、精排、文档结构十条轴）、作品能力推断、常用点的上限、静态预算 |
| `设计树码` | 设计树码 v0：「编码设计作品」「解码设计文件」（外框同树码，设计头、段表、结构段、素材块；读时处处查边界，验证器拒绝截断、改坏、超预算与能力不符的文件）、「读设计文件」「写设计文件」 |
| `还原` | 「还原作品源码」：设计作品写回构造写法的源码，省略默认属性 |
| `设计命令` | 壳命令的做法：渲染帧、导出帧序列、设计信息、还原设计、播放与播放控制，「登记设计命令」写进库「壳命令」；「编译设计作品」 |

## 写法

```
寻观「设计」之书。

「作品」者
　「视频」
　【「画幅」者（「尺寸」于「三二零」于「一八零」）也
　，「时长」者（「秒」于「二」）也
　，「背景」者「纸色」也
　，「画面」
　　【「圆」
　　　【「圆心」者（「坐标」于「一六零」于「九零」）也
　　　，「半径」者「关键帧」【「帧」【「在」者「零秒」也，「值」者「一零」也】，「帧」【「在」者（「秒」于「一」）也，「值」者「六零」也】】也
　　　，「填充」者「朱色」也
　　　】
　　】
　】
也。
```

属性类型是 `「信号」于 甲` 时写常量即可，构造写法自动提升为常量信号；整数字面量在小数处当小数。「点」在豫言里是数字（零点零），坐标的构造函数叫「坐标」。

## 命令

- 编译：`豫构 设计 编译 源。设计。豫 --输出 名。设计`（源文件所在的包要依赖「设计」）。
- 宿主上：`豫构 设计 渲染帧 文件 时刻 输出`、`豫构 设计 信息 文件`、`豫构 设计 导出帧序列 文件 起 止 帧率 前缀`、`豫构 设计 还原 文件 输出`（转给 `设计工具。脚本。豫`）。
- 壳里：「渲染帧」「导出帧序列」「设计信息」「还原设计」「播放」「暂停」「继续」「跳到」「设音量」「选字幕」「播放状态」（库「壳命令」；豫言操作系统桌面的命令壳登记做法）。
- 播放状态：播放类命令把状态写进用户主目录下的 `.豫言设计播放状态`，图形播放器 `yy设计播放器`（`豫言操作系统/应用/设计播放器`）每帧读它显示当前帧，只当监视器。

## 后续版本事项

- 表达式信号、弹簧、叠加与混合、驱动；文字、图像、布局容器、效果与样式表。
- 播放器窗口；组件定义与实例、缺省标记、素材块与跳转索引。
- 颜色在线性光空间插值与混合；组的不透明度先合成再整体透明。
