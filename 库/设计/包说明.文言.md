# 设计

设计之言之引擎之库（[提案〇〇〇一八](../../提案/00018-设计语言与引擎.汉语.md)）。设计之源 `名。设计。豫` 书 `寻观「设计」之书。`，以构造之书（`「首」【项，…】`，提案〇〇〇一八议十九）书作品；作品为常豫言之值，由此库求值而渲之。

## 诸模

| 模 | 所载 |
| --- | --- |
| `时间` | 「时间」（整刻，一秒七亿五百六十万刻）、「秒」「毫秒」「分」「帧时」「秒数」「时间表示」「解析时刻」 |
| `设计值` | 「坐标」「原点」「尺寸」「度」、「颜色值」「颜料」（纯色、线性渐变）、「色码」与纸墨朱之色板，诸类之插 |
| `信号` | 「信号」（常量信号、关键帧信号）、「关键帧」「帧」之构造、「缓动」、「求信号」 |
| `场景` | 场景之节与构造：「组」「矩形」「圆」「椭圆」「线」「路径」；时线：「片段」「实例」「顺序」「并行」「停留」「事件轨」；作品：「视频」「插画」「图标」与「画面」之轨 |
| `数学` | 唯用四则之小数之具、自为之正弦余弦、二维仿射 |
| `折线` | 几何平为折线、SVG 之径、描化为多边 |
| `求值` | 作品于时 t 之二维显示表 |
| `渲染` | 中央处理器之参考渲染器：画显示表于 RGBA8 之布（整数扫描线、四子扫描线、非零绕数），编为便图 |

## 书法

属类为 `「信号」于 甲` 者书常量即可，构造之书自升为常量信号；整数之字面于小数之处作小数。「点」于豫言为数（零点零），故坐标之造函名「坐标」。示例见汉语稿。

## 后续版本之事

- 式之信号、弹簧、叠加混合、驱动；文字、图像、布局之器、效果与样式。
- 设计树码（二进制 `名。设计`）、能力之推与静预算、反编、播放器与壳之令。
- 颜色于线性光之空插混；组之不透明先合而后整透。
