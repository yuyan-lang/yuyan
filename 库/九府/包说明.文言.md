《汉书·食货志下》曰：“太公为周立九府圜法。”九府者，周之官守，掌货贿之出入、圜法之轻重。此包取诸府之名以立骨，所据者提案 00054 之第三步：与机器、网络无涉之一层。天府司名册与领袖之租，大府司派单与改派，三司者其外接之途也——府库以藏，漏刻以时，邮传以告。骨既立，乃以推演试之。真器未接，法度先具；后接豫寓榫卯之府库与系统之钟，易其皮而不易其骨。

## 三约

府库四术：

- 读以键取一物，得其录——键、正文、摘要；无物则得空，后端不通则得错。
- 写受一求：凭、键与正文。凭有三：无凭、唯无、符同。写成得新本之摘要；条件不合得冲突而物如故；后端之败得出错。
- 列举以前缀陈其下诸物之录。
- 删以键去其一物。

漏刻二术：今时予本节点单调之毫秒；定时预约本节点之一醒。

邮传二术：告发一信，收取已受之信。本步惟留其位，天府、大府皆未用之。

三约皆书为命名之组，其字段为函数；取用时经「读物」「写物」「列物」「删物」「取时」「设时」「告信」「收信」八术转调，状态机之内不以字段之投影径当函数之呼。

## 天府

名册：节点每一心跳之隔，书其号于 `九府/名册/` 之下，正文记地址、能力与序号；每书必易其正文（序号加一），摘要亦随而变。读方依列举所陈，逐条记其摘要与初见之刻；同一摘要不再易其初见；初见去今逾名册之过期，则谓其去。所计者惟读方自己之单调钟所过之短长，不比两机之墙钟。

领袖之租：`九府/领袖` 之正文为 `<任期>|<节点号>`。

- 抢：非领袖见租约无物，则以唯无之凭书之；见同一本已历租期加租缓之久的（以己钟计），则以符同之凭书己、任期加一。条件之写成，乃为领袖。本步取租期三十秒、续约五秒、租缓五秒。
- 续：领袖每一续约之隔，以符同之凭重书同期；写成则新其租期之始。
- 丢：续约不成（条件不合或后端不通）则立弃其位；此后若后端不通，己之租期一至亦弃；读到期大于己所见之最大者，亦弃。
- 任期之单调：节点记其所见之最大任期，所读小于此者不认；抢时所书之期必大于此。

## 大府

派单之正文为 `<任期>|<序>|<节点们>|<队列们>|<役们>`，三者各以逗号别之。领袖依名册之活者造单：一千零二十四个分片依号轮授诸节点，队列与役各依名次轮授。

- 节点每读一单，记其摘要与初见之刻；期小于己所见之最大者，则整单不认。
- 受新单则相较：不复属己之职入于待交，交出而后放手（先调交出之回调以存盘，成而后放）；新属己之职入于待接，待交接之宽而后调接手之回调以载入，载入成而后开工。职守者一段之文：`片|<号>`、`队|<名>`、`役|<名>`。
- 领期：自初见今本之刻起算，逾派单之领期而未见他本，则尽放在执之职（先一试交出，成否皆放）。
- 交接之宽兼覆旧主之领期与两机钟速之差：旧主最迟于领期满时放手，新主最早于初见新单加宽时开工，两不相犯。

## 推演

一进程之内，多节点与一假府库，其态皆在己身。剧本记节点之号与其钟速、期限、所注之事与三种故障之率。

所注之故障：

- 节点之崩与重起：内存之态尽失，重起则单调钟自零起；
- 网络之分：某节点读不到后端，诸术皆以错答，心跳、续约、读单、读名册一概不通；
- 后端之慢：一术费数秒，推演以其实时加此；
- 后端之误：一术径答以错；
- 条件写之冲突：本合之条件亦答以冲突；
- 钟之迟疾：诸节点之单调钟行于千分之九百五十至千分之一千零五十之间，计时与定时皆依己钟折算。

不变者，每行一事则核其一：

- 同一任期至多一领袖：一节点报「升」时，同期已有他节点报过，则违；
- 任一时刻每片至多一片主在执：接手成而报「起」时，其片已有人在执，则违；
- 派单惟出于当时之领袖：假府库受派单之写时，租约所书之期与号须与写者相合；
- 领袖去后，租期加余量之内必有新领袖：连续无「有效领袖」（报过升、且末次续约之成在租期之内）逾租期加租余量（三十秒加六十秒），则违；无一台生而通后端者，此段不算其空。

违则印其种子与种下之事序，凭种可复。

## 真三司、节点之符与运行

第三步之余，接三司于真器，别立节点之符与运行：

| 篇 | 所司 |
| --- | --- |
| 守藏 | 真府库：以豫寓府库之五术，结为三司府库之四术。读还正文与摘要（摘要取物之加引校值），写以无凭、唯无、符同译为无条件、ifNoneMatch、ifMatch，列举依前缀循续标而尽取、复逐个读其正文，删去一物。后端由呼者依构时所择之适而授。 |
| 金匮库、邸阁库、内府库 | 以落盘、邸阁与内府三适之五术，原样结为守藏所须之库术。 |
| 择库 | 依府署之库类择后端，先设金匮之根于数据之目；别给择术，以便壳命读物之元。 |
| 符节 | 节点之符：三十二字节爱德种子，初取安全随机而生、书于数据目之 `节点私钥`，后则读之；公钥由种导出，节点号取公钥沙二五六前八字节之十六位小写十六进。 |
| 府署 | 读 `九府配置。数据。豫`：库类、桶、凭据之径、对外之址、听之端口与数据之目；阙者取缺。 |
| 铜壶 | 真漏刻：今时取单调微秒千而一之；定时以到点之刻与其名书于本节点之表，同名惟留其一；近候还最近之期，到期取去已至之名。不用墙钟。 |
| 置邮 | 真邮传：传输控制协议上长题分帧（八字节之刺与小端之长），体为籍帛所编六栏之记。告信依名册之址，连以号复用、断则复连、发不得则弃、至多一次；收信取其所已受。另有问态一往还：问其号、期与职，答态还之。候用多路等待。 |
| 九府令 | 壳命「九府态」之法与「登九府命令」（部居九府部以之登）。 |
| 治所 | 节点之运行：一步行天府、记主变、主写单、行大府、记职开合；又一步办网上来信。接手交出此时惟记一行。 |

服务之程为 `应用/百工坊/九府台`（包「九府台」）：读配置、备钥、择库、开门、结治态，循府制之数行主环，记为人读之文。SIGTERM 由宿主径终其程（执行器不接此信），而府库之写皆整份原子，故不留半写之状；「息」以节点间之来信行之，受则收场。

壳命「九府态」（篇九府令；部名「九府」，所依九府）：豫言系统之壳与宿主行在之会皆装，网页行在姑不装（九府所依于网页之构，留俟后版）；径读配置之府库与数据目之符，印本机之号、主与期、名册诸节点之址与几秒前之心、单之序与期、本机之职守；后端不通则照实言之。
