# 树码实施

此提案00001之实施记也。结构表与编解之器在 `编译数据/抽象绑定树结构/抽象语法树/序列化/`，缓存之接在 `编译步骤/总体过程/树码缓存支持。豫` 与 `编译文件缓存工具。豫`，转换、核对之器在 `应用/开发工具/树码/`。下文度量存第一版之验。

今第二版文件定义列惟名与式，去无实导出之用的公开性爻；卷首版本改二，定义编码依次为名串号、体字节长与体。旧版树码失命中则重构。编译器惟书树码，去结森缓存、附加豫文之书及其命令选项；`yy树码 转换` 常以树码成同名豫文，其标头版本为三。

语言服务、语义标记及包籍语言服务亦用树码。资料对象循旧节点，字段名与内容共串表；VS Code 调豫言 Wasm 器读资料、显阶段之文。二类实二进制样本之跨语言互通，插件 lint、编及诸回验皆过。「全部」构建皆过，历一千五百八十五秒；三级、四级逐字节同，SHA-256 为 `3996951b9665942245537d551c520a23140f33c1e1158b97a91b26ce090552fa`。末次类型检查及包配置、豫构七验皆过。此编译器缓存已核树码一万零九百四十七卷，结森与豫文缓存皆无；二进制成文再成二进制，字节悉同。

节点名称九十三种，参数形式五种，内建常量十六种，结构名称操作七种，定义透明性、注释方向各二种。规范之文依此序，各行间一换行，末无换行；SHA-256 曰 `d0e190951b1aee7a253106686ad73097c9f1bedda1e92d727684e64f700a809f`。原提案所记内建常量十七者，以源码实有十六为准。

六十四位 LEB128、小数位型、名示拆号、散列串表、包径表、诸构造器载荷、树组、串列俱成。表达式先序积片，终乃层合，不逐层抄子树；定义体共游标而各守终。第一版拒共享签四，NaN 归一，负零仍存。编码之果可附本机有关之记，供构建清单书之；未知包径仍存本机之径。

`--中间格式 结森|树码` 择缓存之书，以树码为常；中间豫文常不书，以 `--导出中间文本` 开之。读先树码，后结森，以魔数辨之。版本、结构摘要不合则重建；复书结森，去同产旧树码。依赖与其快照用树码串列，补豫文依同一基径。独立阶段明授树码输入，仍禁从卷上缓存暗取所缺。

模块之名依主、包、包内径而成，诸段各冠其长，继循标识符转义；不在包上下文者仍用本机之名。顶层直调、局部直调、满参递归与提升之函亦依此身份；缺支之异辞先依最长包目录代为包身份，乃截其诊文。
