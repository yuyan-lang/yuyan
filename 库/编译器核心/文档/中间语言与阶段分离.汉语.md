# 中间语言与阶段分离

编译器在每个已命名的中间边界只保存同名 `.树码` 阶段产物。树码版本或结构表摘要不符时按缓存未命中重建。需要看文本时用 `yy树码 转换` 生成 `。豫`；文本是可重新解析的中间程序，读取过程不执行文本中的函数。

## 共同语法

所有中间语言共用现有豫言词法和表达式解析器。定义使用 `者／即／乃`，函数使用 `会／受／遇`，调用、局部绑定、分支、顺序执行、元组与函数类型保留源码语法。只有缺少普通源码写法的阶段操作使用扩展列：`「《《扩展名》》」【参数…】`。序列头仍是自由变量，不新增词法规则。

例如正文可以是：

```text
「恒等」者
  （会「参数」而 「参数」）也。

「引用」者
  （「《《文件定义引用》》」【『文件。豫』，『参数』，「2」】）也。
```

词法阶段的文本直接保存原始源码正文，前置一行阶段注释。读取时只去掉这一行，再调用共同词法器恢复令牌，保留原有空白、注释和位置。词法阶段约定源码与令牌一致；独立树码输入会校验这一点，普通编译的缓存读取不重做词法。

其余阶段文件开头的 `「《《阶段源码》》」【…】` 标头保存版本“三”、阶段名及按定义顺序排列的声明类别。正文使用源码定义，声明类别用于区分前端类型声明、类型值和已降级的普通定义。可以编辑正文再交给 `stage` 命令重解析。

绑定变量通常打印为作用域内的名字。匿名绑定、名字无法直接引用、自由变量与绑定重名，以及被遮蔽的外层引用使用专门扩展，避免变量捕获；其中显式索引从一开始。位置、注释、节点专属参数和小数原始精度也有专门扩展，保证重解析无损。扩展参数直接来自有类型的 IR 字段，不先构造 JSON，也没有通用的“中间节点／中间字段”包装。

打印器使用显式任务栈和片段合并，避免深树的递归字符串拼接。字符串转义和标识符检查直接扫描字节，避免逐字符分配列表。底层写文件先直接打开，只有目录缺失时才创建父目录，避免双导出重复逐层 mkdir/stat。扩展表达式和调用参数带必要括号，满足既有操作符优先级规则。重解析使用共同语法解析器，然后按阶段静态解释扩展；不会执行中间程序，也不会重新运行源码类型推导。

文件定义列与表达式树组的每项为“名称、表达式”二元组。树码第二版的定义正文依次写名串号、体字节长与体；公开性字段已移除。第一版树码和旧 JSON 缓存均由编译器重建。小数节点保存原始字面量和六十四位浮点位型。

## 边界及顺序

| 顺序 | 阶段 | 载荷或附属输出 |
| --- | --- | --- |
| 1 | 词法形式 | 原始源码和完整令牌，包括词法注释 |
| 2 | 抽象语法 | 文件定义列；另有语义标记 |
| 3 | 名称解析后形式 | 解析后的引用和源码标注；另存名称解析资料 |
| 4 | 检查后定义 | 同时保存检查后对象、语言服务资料和各定义的签名元数（`签名元数`） |
| 5 | 模式展开形式 | 检查后对象的模式变换结果 |
| 6 | 类型擦除形式 | 类型擦除结果 |
| 7 | 续延调用展开形式 | 当前续延调用转换结果 |
| 8 | 擦除后形式 | 隐式参数擦除结果 |
| 9 | 优化后形式 | 跨模块优化结果；另存供下游内联的候选（`原语内联`）和顶层工函数的元数表（`顶层元数`） |
| 10 | 闭包前优化形式 | 局部闭包前优化结果 |
| 11 | 递归转换形式 | 递归节点变换结果 |
| 12 | 闭包环境形式 | 显式闭包转换结果 |
| 13 | 全局存储形式 | 单项“全局初始化”表达式 |
| 14 | 闭包形式 | 函数提升后的树组 |
| 15 | 纯求值正则形式 | ANF 变换结果 |
| 16 | 正则消冗形式 | 按配置消除未使用表达式后的结果 |
| 17 | 求值正则形式 | 续延传递变换后的结果，沿用旧缓存名称 |
| 18 | 代码生成前形式 | 代码生成准备变换后的树组 |

依赖信息及其阶段快照使用树码串列，主程序初始化表达式也只写树码。语义标记和编辑器语言服务资料也写树码，使用现有标量、元组和表达式树组节点表示资料对象，由豫言 Wasm 工具解码后交给编辑器。名称解析资料另有可往返的阶段快照。优化器内部递归调用和单轮局部重写不另立文件边界。

## 独立执行

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy2_bs.wasm stage 输入阶段 输出阶段 输入文件 输出前缀 源文件身份 \
  [依赖源身份 依赖阶段 依赖文件]… [-- 编译器选项…]
```

`源文件身份` 是原模块路径，用于模块引用和生成符号；它不要求在磁盘上仍有源码。每项额外依赖明确给出模块身份、阶段及产物文件。源码快照使用阶段名“源码”，文件内容按原始源码读取；“词法形式”产物已携带本模块源码。涉及名称解析、类型检查、模式展开和类型擦除时，应提供实际需要的依赖检查后定义与源码快照。原始导入语法仍需相应包上下文，可通过 `-- --package-context 路径` 传入。

例如，从闭包形式的文本执行一次 ANF：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy2_bs.wasm stage 闭包形式 纯求值正则形式 \
  /tmp/例.闭包形式。豫 /tmp/下一步 /原工程/例。豫
```

结果为 `/tmp/下一步.纯求值正则形式.树码`，输入接受树码或阶段中间文本。输入阶段与输出阶段相同时，只转换表示，不执行变换。类型检查同时输出检查后定义和检查后对象；名称解析同时输出名称解析后形式和名称解析资料。

独立命令将显式输入装入进程内依赖表；缺失依赖时报告其模块和阶段，不回退到原编译器缓存。每次命令只执行一个目标阶段，不自动补跑前面的步骤。对输入进行绑定范围、闭合性、重复定义、部分节点参数数量和前端暂存节点检查；具体变换仍会检查其所要求的结构。

## 性能测量

阶段缓存的有效性只由树码决定；编译过程不写中间文本，不读取 JSON 缓存。需要文本时，用转换工具从树码生成，不重跑编译阶段，也不改树码时间戳。

`yy树码` 提供转换、统计和完整往返核对，见 [工具说明](../../../应用/开发工具/树码/包说明.汉语.md)。树码编码器按首次引用登记散列串表、按包上下文登记路径表，绑定名字提示拆末尾序号；源码范围及定义顺序保留。NaN 编码统一，负零保留。

统计工具使用豫言编写：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 树码 --输出 yy树码.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy树码.wasm 统计 缓存目录 --包上下文 上下文文件
```

按阶段列出文件数、树码字节、读取还原、编码、解码耗时与本机相关文件数。完整构建测量区分冷缓存、热缓存，并报告磁盘占用。

## 验证

往返测试覆盖特殊字符串、绑定遮蔽、匿名绑定、自由变量、次序、位置和注释。阶段负例覆盖缺失绑定、自由变量、节点形状和错误阶段标头。完整验证还包括独立进程重放、连续编译比较、类型检查及三次自举；以 `yy3_bs` 和 `yy4_bs` 的逐字节比较验证固定点。

## 回归入口

持久回归入口位于 `编译器核心/编译步骤/总体过程`：

- `中间语言。测试`：往返、特殊字符串、小数精度，以及自然源码与扩展列。
- `中间阶段。测试`：阶段非法输入、版本／阶段不符，以及五万项列表反转。
- `阶段文件写入。测试`：新建多层目录、覆盖、截断为空和含零字节的二进制写入。
- `中间阶段集成。测试`：对 `阶段样例。测试` 逐阶段启动新进程，比较两种输入格式直到后端。

集成测试参数依次为编译器绝对路径、样例绝对路径、已存在的输出目录。验证时，旧稳定编译器和新编译器连续编译该样例得到同一输出。原有注释语法和语义标记回归同样通过。

性能实测见 [中间阶段性能](中间阶段性能.汉语.md)。旧 AST 包装文本的数据属于旧实现，不能代表重做后的源码格式。
