# 中间诸言与编译分阶

编译每至一阶，惟书同名树码；版本、结构摘要不合则重构。欲观豫文，以 `yy树码 转换` 成之；文可复解，不待执行。诸言共词法、括号、引号与序列。定义以者、即、乃，函数以会、受、遇；调用、虑、分支、元组与函数类型，皆循源码。其降级之义无旧文可书者，以 `「《《扩展名》》」【参数…】` 申之；列头仍自由名，不改词法。语法同，而各阶所许之式有别。

常用绑定以名书之；名有遮蔽、无名或不可直书者，乃用扩展，索引自一始。词法之文直存原书，首加阶段之注；读则去此注而复词，原空白与源域不易。词与源须相符，独立树码输入验之；常读缓存不再词法。余阶篇首记版本三、阶段与声明类别，正文可改而复解。诸参直取于树，不先造结森，不复以“中间节点”包万物。树组之项惟名与式，树码第二版诸定义记名串号、体字节长与体，已去公开性；第一版树码与旧结森缓存皆重构。小数存原十进字面及六十四位位型。源域与注释俱可复得。

诸阶之次：词法、抽象语法、名称解析、类型检查、模式展开、类型擦除、续延调用展开、隐参擦除、跨模块优化、闭包前优化、递归转换、闭包环境、全局存储、函数提升、求值正则、消冗、续延传递、代码生成准备。全局存储暂汇为一初始化式，提升后复为函数组。检查后定义与对象并存，并书诸定义之签名数（`签名元数`）；名称解析所得跳转资料亦存。跨模块优化另书下游内联之候选（`原语内联`）与顶层工函数之数表（`顶层元数`）。优化内部之递归重写，不各立文件。

独行一阶，命曰：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy2_bs.wasm stage 输入阶段 输出阶段 输入文件 输出前缀 源文件身份 \
  [依赖源身份 依赖阶段 依赖文件]… [-- 编译器选项…]
```

源文件身份定其模块，未必尚存原书。所依模块、阶段、产物须明授；若须源文，以“源码”阶段授其快照。词法产物本含源文。输入许树码、阶段豫文，输出惟树码。依赖不备则告缺，不暗取旧缓存。输入输出同阶，则但换其表示。依赖及其快照以树码串列存之，主程序初始化亦惟书树码。语义标记与编辑器资料亦书树码，以旧标量、元组、树组节点载其对象，豫言 Wasm 器解之而授编辑器。

验之，以复解后同于原式为本，以独行诸阶同于连行为继。以 `yy树码 统计` 分阶段计篇数、字节、读、编、解之时。冷暖缓存与磁盘之量，须各记之，不先断其快慢。

书文以显栈积片，终乃合之；串之转义与名之辨直扫字节，毋逐字造列。书文件先直开之，缺父径乃建，不逐阶反复建同径。扩展与调用之参，加括号以明其界。缓存之效惟依树码，编译不书中间豫文、不读结森缓存；欲观其文，以别器转之，不重行其阶，不易树码之时。

`yy树码` 供转换、统计与完整往返核对，见 [工具说明](../../../应用/开发工具/树码/包说明.文言.md)。串入散表，号依首用；径依包上下文；绑定名示拆末尾之序。源域与定义次序皆存，NaN 归一，负零不易。

代码既成，当验类型，继以三举，比较 `yy3_bs` 与 `yy4_bs`，同乃成其固定点。

匹配覆盖之名取本模“抽象语法”，独立类检阶须明供此原声明产物；模式展开又须供“类型检查资料”。无待验匹配及警告止，覆盖之用径还，免读原声明缓存。检后定义、对象，许匹配支存一源码范围之包，以供展开诊断；展开去其包，后阶仍拒源注。寻常式之范围包、源码绑定标注、待定节点及包内未闭合变量，皆循旧验之约。

回归兼验：中间语言往返，阶段非法输入与长列反转，逐阶新进程至后端之集成，暨建径、覆写、空文与零字节。以“阶段样例。测试”验捕获及打印，新旧编译器连行所出皆同。旧注释与语义标记之试亦过。性能实测另载同名性能篇。
