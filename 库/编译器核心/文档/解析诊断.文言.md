# 败报与长文编译

式无可解，先告文件与词文，不尽倾内部之树。词取三十二以内，名与串各取六十四字以内。败句有裸元、阳、阴，则劝察是否当书「元」、「阳」、「阴」。串中之文、已引之名，不作裸值论。此但报错，不改语法，不代改文。今词法已去空白，式未存源位，故明言无精确行列；`-vv` 调试仍存败支全栈。

长文之编，遇线性递归而栈溢。今以尾递修「打表」、「整数范围」、「态射」、「长度」及「附加」；施术与成列之序皆因旧，后列亦共享如故。不增配额，不裁文，不匿败。所改为标准库「多态列。豫」与「多态列工具。豫」。

验三裸值之败、引值之成、串不误报与短报有界；又验三万二千项之表、射、数、区间、附加、施术次序与空列。全程探针先热同版标准库，编万甲之文，得合法器，实运行而逐字验万甲及换行。默认 Node 栈下皆成。极小栈尚受总集树解码深度所限，生产当以真 Worker 另验。

构建须用独立种子，运行未毕勿覆其径。依有效包上下文生 `.wasm.wat`，因平台现有 Binaryen 优化为 `yy完整长文编译器优化.wasm`，长 1,780,893 字节。发布须同更两标准库文件，清诸派生缓存而重热之；别模块或已内联旧术，不可但除同名缓存。更新资源摘要，复验云端。本仓不发布用户应用。

终验三段自举与类型检查皆成，三、四代字节尽同。平台复报真 workerd 七验皆成，万甲源码之编为其一，余验多文件、运行、隔离、流式与简报。
