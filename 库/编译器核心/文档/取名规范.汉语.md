# 取名规范

本篇汇总豫言给名字取名的做法，供人与 AI 写代码时起新名字参考：函数、类型、构造器、标签、模块、文件、包都适用。这些做法是在提案 00025（关键词的文学性）、00027（关键词换字）、00029（标准库命名）、00031（译名雅化）里与用户逐条议定的，细节与来历以各提案为准。外来术语的译名另见《翻译列表》《英文字母翻译》（同目录）。本篇只写现代汉语（用户 2026-10-14 定）。

## 一、名字要放进句子里读

豫言的代码读来是一句句文言，名字是句子的一部分：

| 写法 | 读作 |
| --- | --- |
| 调用 `「遍」于「数列」于（……）` | 遍于数列 |
| 判断 `若「有一」于（……）于「数列」则……` | 若有一于数列，则…… |
| 带标签的调用 `「截取」于「起」曰「零」` | 截取于起曰零（标签读在“曰”前） |
| 签名 `「平方和」乃化「数」又化「数」为「数」者也` | 平方和，乃化数，又化数为数者也 |
| 限定名与导入 `「分厘」之「加」`、`寻观「豫章」之「形制」之「次第」之书` | 分厘之加；寻观豫章之形制之次第之书 |

所以函数名要在“于”前读得通（`「迁」于『/tmp』` 读作“迁于 /tmp”，`「咨」于『git』` 读作“咨于 git”），谓词要在“若”后读得通，模块名要在“之”前读得通。起好名字后，放进一两句真实的调用里读一遍，再定。

## 二、四条原则

用户 2026-10-14 定：

1. **常用函数以一个古字动词为名**，读作“动词于宾语”。态射→「遍」，滤→「择」（《论语》“择其善者而从之”），取／放→「取」「舍」（“取舍”成对），反转→「倒」，折叠→「叠」。
2. **谓词以判断之词为名，去掉“吗”“乎”“否”。** 字符串相等吗→「文同」，存在吗→「有一」，完成了吗→「毕」，是文件夹→「为箧」。
3. **去掉今语套词**：获取、取得、新建、创建、转、搜索、查找、已经。
4. **同义只留一名，并与中缀同名。** 等／等于只留「等于」，小等／大等→「不大于」「不小于」，或者→「或」（与「且」成对）。

## 三、办法：先看做什么，再找现成的古雅说法

起名先写清它做什么（输入、输出、有无副作用），再想古书里怎么说这件事：一个动词、一个成语、一个典故。不要机械删字：只删“获取”、只换一字，得出的「命令参数」「称当前日期时间格式」反比原名更拙。照这个办法重拟的例子：

| 原名 | 雅名 | 读来 |
| --- | --- | --- |
| 获取参数 | 受命 | 程序受命而行 |
| 获取输出（运行一个程序取其输出） | 咨 | 咨于 git |
| 获取当前路径 | 所居 | 今之所居 |
| 切换当前路径 | 迁 | 迁于 /tmp |
| 用时秒数表示 | 历时 | 历时几何 |
| 头一个／最后一个 | 冠／殿 | 冠军、殿军 |
| 拉链合并 | 偶 | 偶于甲于乙 |
| 新引用 | 置匣 | 置一匣 |

## 四、一事一字

同一件事全库只用一个字，变体加固定的字：

| 事 | 字 | 例 |
| --- | --- | --- |
| 新建 | 置 | 置匣、置牍 |
| 转换 | 作 | `「作小数」于「甲」`、作帛 |
| 表示（成文） | 述（列则“列举”） | 述数、述小数；《论语》“述而不作”：述是照样说出，作是另造一物 |
| 相等 | 同（数的相等用中缀“等于”） | 文同、列同、爻同 |
| 读、写 | 读、写 | 读匣、写匣 |
| 查找（得或无） | 寻 | 文寻、寻序 |
| 删除 | 删 | 簿删 |
| 长度 | 计 | 计（列）、计字（文的字数）、计帛、计牍；读作“计于数列” |
| 带序号的变体 | 加“序” | 遍序、叠序 |
| 作用于两列的变体 | 加“二” | 遍二、皆二 |
| 从右往左的变体 | 加“逆” | 逆叠、文逆寻 |
| 异步 | “将”字起头 | 将咨、将听；“将”是古文表将来的字 |
| 编译器原语 | “本”字起头，后接库里的名字 | 本加、本置匣 |

类型名照提案 00027、00029：整数→「数」，字符串→「文」，元类型→「类」，引用→「匣」，字节缓冲→「牍」（写错可刮去重写的木板），字节串→「帛」（帛书一写即定，与牍相对），异步返回→「诺」（《史记》“得黄金百，不如得季布一诺”）。整数是默认数型，名字不加前缀（「绝对值」「大者」）；小数加“小数”前缀（「小数绝对值」）。

## 五、术语成套取喻

一族术语取一个比喻，族内用字相应，读者认出一个就猜得到其余（详表见提案 00029 第三节第八条）：

- **以爻喻位**：位与、位或、位异或、位非→「交爻」「兼爻」「变爻」「错卦」；左移、右移→「升位」「降位」。
- **以宾主往来喻连接**：监听、接受→「开门」「迎」；读取、写入→「听」「告」；关闭→「别」。
- **以书信喻请求**：获取、提交→「索书」「致书」；响应→「回书」；标头→「抬头」。
- **以使者喻子进程**：启动、终止→「遣使」「召回」；结果→「使报」。
- **以役喻异步任务**：任务→「役」，派生→「遣」，等待→「待」，阻塞等待→「坐待」。
- **以书卷喻文件**：读、写、删、改名→「阅」「著」「焚」「更名」；原子写→「定稿」。
- **终端**：标准输入→「闻」，标准错误→「诉」。

新起一族接口时，先看已有的族能不能容下；容不下再取一个新比喻，并在该族的说明里写明。

## 六、模块名、目录名与包名

模块名出现在每句导入与每个限定名里，照古书篇名取：多为两字，说出篇中所收，像一部书的篇目。如整数→「筹算」（古人以算筹计数），小数→「分厘」，列→「次第」，文→「文章」，路径→「阡陌」（《桃花源记》“阡陌交通”），环境变量→「水土」，数据报→「鸿雁」（鸿雁传书），不安全→「行险」（《中庸》“小人行险以徼幸”）。一族比喻的总名照用（使者、宾主、书札、然诺），目录取总名（形制、本原、出纳）。

模块名作“之”的底，会被同名的局部名、类名遮住，所以模块名与类名分开取（帛→帛书、牍→简牍、匣→匣椟），也避开常作局部名的字。包名同此，如标准库→「豫章」：豫章是良材，“章”又是篇章、典章。

## 七、标签名

标签写在“曰”前，读作“起曰零，止曰三”，与《尚书·洪范》“一曰水，二曰火”同一句式（提案 00027）。标签取短，成对的取成对的字：起／止、宽／高、题／副题。标签与局部名同名时会出现“圆心曰圆心”的叠字，简写待定。

## 八、外来术语

外来术语的译名照《翻译列表》，按“短、能猜、像专名”起，并照提案 00031 再求两条：

- **雅**：名字本身是比喻或有来历的，直译本义（Python→蟒、Perl→珠玑、Blink→瞬）；音义兼译时字取雅义（git→稽，《尚书·尧典》“曰若稽古”）。
- **成套**：与豫言的库名同用一套比喻（书札、索书、诺、出纳）。

厂商与产品的官方中文名、学界通行的人名音译、已成通语的词照旧。列表没有的，先按该篇开头的原则补进列表再用（提案 00013）。

## 九、要避开的坑

1. **常作局部名的字。** 类型与值共用一个名字空间，局部名会遮住同名的函数与模块。「首」作局部名与模式变量约两千处，「末」约六百，「积」约一千三百，「累」约六百，「逆」「续」「存」「配」「分」各一百余，「径」一千二百余，「符」约二百五十，「今」「问」也常用；起名前先统计。
2. **现有顶层名。** 「项数」「区间」「范围」「生」「字码」「诸参」等在仓里已有同名定义，换一个。
3. **与“于”连读成词的收尾字。** “长于”“始于”“至于”“终于”“同于”“易于”“先于”都会误读，所以长度叫「计」不叫“列长”，范围叫「起讫」不叫“自至”。中缀本名（大于、等于……）照用。
4. **一字多义、易生歧解的字。** 「称数」易读作“称量数目”，所以表示取「述」；“对称”会读成今语的对称，所以二对子的表示写作「述对」。
5. **今语口吻与生僻字。** “任意”带今语口吻；冷僻字读者不识，选常见而有来历的字。
6. **类名作参数与局部名。** 参数与局部名避开类名，连提案 00027、00029 将改出的「数」「文」「类」「匣」「牍」「帛」也避开。
7. **默认导入的模块之间重名。** 编译器会报错；随作用域走的同名（如「分厘」里的「加」「大于」）只放在不进默认导入的模块里。
8. **意思随上下文变的字。** 一个字在一族里只作一种用法。提案 00027 撤去“及”、改用“又化”“又得”，就是因为“及”的意思要看上下文才知道，而“又X”各接本类构造。
9. **要看内部才能定的规则。** 定规则只看外形：如“者也”只看类型开头一字（提案 00027），名字的前缀、后缀规则同此。

## 十、古例与出处

取字要引古语时，到殆知阁语料（`豫言数据/文学性研究/殆知阁/`）里核原文与篇章，不凭记忆；合成词（如告祸、姑试）注明“古书无成例”。提案 00027 第十一节列出了每个关键词的出处，可作样子。

## 十一、起名的步骤

1. 写清它做什么。
2. 查第四、五节：同族已有的字照用。
3. 想古书里怎么说，拟两三个候选。
4. 放进真实的调用里读，看会不会误读（第一节、第九节第三、四条）。
5. 查撞名：局部名、模式变量、顶层名、类名、模块名。
6. 要引古语的，核出处。
7. 标准库的名字照提案 00029 的改名表；拿不准的公开接口列出候选，交用户挑。

## 十二、过渡

提案 00027（关键词）与 00029（标准库改名）尚未实施：调用已有的名字照旧写现名，代码照现行关键字写；新起的名字照本篇。两提案实施后，本篇的示例随之核对；与提案有出入时以提案为准。
