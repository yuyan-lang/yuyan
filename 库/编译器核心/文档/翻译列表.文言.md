# 翻译列表

此篇录英文术语之汉译。字母之书法，见[英文字母翻译](英文字母翻译.文言.md)与[希腊字母音译表](希腊字母音译表.文言.md)。立名之则与诺节、结森之所由，见官网[译名](https://yuyan-lang.org/译名/文言.html)；豫言基础库所用格式与协议之译，见[提案 00004](../../../提案/00004-共用基础库.汉语.md)“译名”一节。

格式之名，以定字殿之，以明其类：图（图像格式）、档（归档）、压（压缩）、码（文本记法）、象（对象表示）、列（列式数据）、量（张量）、浮（浮点）。

| 英文 | 译名 | 由来 |
| --- | --- | --- |
| Token | 符记 | |
| Lexer | 词法分析器 | |
| JSON | 结森 | 音译，读若“杰森”：结与 J 之音译“杰”同音，森取 son 之音；结有“结构”之义，森喻层层相嵌如林。旧译“癸象”，二〇二六年九月三十日改 |
| Node.js | 诺节 | 诺取 Node 之音；节当 JS 之 J（与音译之“杰”同音），亦存“节点”之义 |
| npm package | 诺节库 | 诺节所用之库，与“系统库”相对 |
| CPU | 中央处理器 | 通行之译 |
| WebGPU | 网页图算 | 网页（Web）加图算（算于图形处理器） |
| Metal | 金属 | 直译 |
| CUDA | 统算 | 取 Compute Unified（统一计算）之义 |

| Apache Arrow | 箭列 | 直译加语素：箭即 arrow，列谓列式数据 |
