# 翻译列表

本篇记录英文术语的中文译名，按类别分节。字母的写法见[英文字母翻译](英文字母翻译.汉语.md)与[希腊字母音译表](希腊字母音译表.汉语.md)。起名的原则与诺节、结森、捷思、沙、李萨阿的由来见官网[译名](https://yuyan-lang.org/译名/)。豫言基础库（提案 00004）与网页基础库（提案 00009）用到的格式、协议与库名的译名也收在本篇；增删时同步官网译名页（云仓 `应用/网站/译名.汉语.md` 与 `译名.文言.md`）。

按提案 00013，外来的缩写、专名与接口名一律起中文名；英文原名只留在字符串、下载的数据与规范原文里。

专有名称优先音义兼译，通用概念优先意译：结森、沙二五六、李萨阿是专名；散列、签名、张量、汇编是通用概念。数字逐位写成汉字零至九，与豫言的数字字面量同法：标准编号、版本号、位数都这样写，如 RFC 3339 译征求意见三三三九、ext4 译扩展文件系统四；十六进制、三十二位统一码这类已成词的照旧；两段数字相连会读混的，把位数写在前面加“位”，如 SHA3-256 译二五六位沙三。人名缩写取各人姓氏译名的首字，如 LZ 译莱齐、RSA 译李萨阿、Diffie–Hellman 译迪赫。

格式名用固定的字收尾，表明类别：图（图像格式）、景（三维场景格式）、档（归档）、压（压缩）、码（文本记法）、象（对象表示）、列（列式数据）、量（张量）、阵（多维数组）、浮（浮点）。

### 网页接口成员的译法

网页接口成员（方法、属性、事件名）、层叠样式的属性与关键字、超文本标记的元素与属性、超文本传输首部数以千计，照下列规则命名：

1. 网页内容看到的名字照规范原文存成字符串数据，运行时按它匹配；序列化与测试数据也保留规范原名。
2. 实现它们的豫言函数、类型与常量用中文名，按词直译。同一语义统一译名；同一英文词语义不同就分别登记（见下表）。
3. 各库在包说明里列本库的可逆对照表：规范原名、所属规范与版本、中文名，一一对应。规范原名加所属规范是条目的固定键，中文名改动时据此全树替换。概念级的新术语进翻译列表与官网译名页，代码符号只进各库的对照表。
4. 测试报告与诊断同时给出中文名与规范原名，便于对照网平测、测试二六二与上游问题。

### 系统符号

`。底层接口。豫` 声明的系统调用与系统库函数用下表的中文名（规则与由来见提案 00013 附录）；系统原名只留在 `豫言操作系统/裸机/库/裸机后端/降级目标。豫` 的导入对照表里。

- 动词在前；同一符号在各平台同名；带版本号的数字逐位写，如 accept4 译接受连接四。
- `…at` 系列冠“相对”，表示操作以目录文件描述符为参照，如 openat 译相对打开。
- 视窗接口的 W（以十六位统一码宽字符传递字符串的版本）缀“宽”，Ex（扩展版）缀“扩”，如 MoveFileExW 译移文件扩宽；CF（Core Foundation）译“核心”，如 CFRelease 译释放核心对象。

平台：林＝林纳克斯，苹＝苹果，视＝视窗。
