# 翻译列表

本篇记录英文术语的中文译名，按类别分节。字母的写法见[英文字母翻译](英文字母翻译.汉语.md)与[希腊字母音译表](希腊字母音译表.汉语.md)。起名的原则与诺节、结森、捷思的由来见官网[译名](https://yuyan-lang.org/译名/)。豫言基础库（提案 00004）与网页基础库（提案 00009）用到的格式、协议与库名的译名也收在本篇；增删时同步官网译名页（云仓 `应用/网站/译名.汉语.md` 与 `译名.文言.md`）。

格式名用固定的字收尾，表明类别：图（图像格式）、档（归档）、压（压缩）、码（文本记法）、象（对象表示）、列（列式数据）、量（张量）、浮（浮点）。
