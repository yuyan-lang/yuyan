# 翻译列表

本篇记录英文术语的中文译名。字母的写法见[英文字母翻译](英文字母翻译.汉语.md)与[希腊字母音译表](希腊字母音译表.汉语.md)。

| 英文 | 译名 | 由来 |
| --- | --- | --- |
| Token | 符记 | |
| Lexer | 词法分析器 | |
| JSON | 结森 | 音译，读如“杰森”：结与 J 的音译“杰”同音，森取 son 的音；结有“结构”的意思，森比喻层层嵌套如林。旧译“癸象”，2026-09-30 改 |
| Node.js | 诺节 | 诺取 Node 的音；节代表 JS 的 J（与音译的“杰”同音），也保留“节点”的意思 |
| npm package | 诺节库 | 诺节使用的库，与“系统库”对称 |
| CPU | 中央处理器 | 通行译名 |
| WebGPU | 网页图算 | 网页（Web）加图算（在图形处理器上计算） |
| Metal | 金属 | 直译 |
| CUDA | 统算 | 取 Compute Unified（统一计算）的意思 |
