# 系统库调用

这是在诺节宿主上调用系统动态库的豫言封装：打开动态库、取符号地址、按签名调用其中的函数，以及分配、读写、复制原生内存。底下是诺节宿主的系统库调用原语：`调用宿主`、`内存宿主` 两个 `。接口。豫` 模块里的十八个无体声明，编成导入模块「系统库调用」的带类型导入（实现在 `豫言操作系统/宿主/节点/外部库.mjs`，基于诺节的 `node:ffi`；Node 工具宿主与应用宿主都提供）。

本包只供适配与系统库（如 `库/金属`）使用，不进公共接口；应用应当经由接口与适配使用宿主能力。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只依赖标准库，登记在「共用库」之下。

## 宿主要求

- 诺节须支持 `node:ffi`，并以 `--experimental-ffi` 启动。工具宿主 `宿主.cjs` 自动给客体工作线程带上此旗。应用宿主（`应用宿主.mjs` 与发行包的 `启动.mjs`）须给宿主选项 `--允许系统库调用`：系统库调用能执行任意原生代码，绕过目录、网络等授权，所以缺省不开；给了此选项而诺节没带此旗时，宿主带旗重启自身。
- `「系统库调用可用」` 为阴时，其余函数都会使宿主报错终止；调用者应先判断，不可用时退回别的实现。

## 模块

| 模块 | 内容 |
| --- | --- |
| `调用` | 类型「外部类型」「外部值」「外部库」「外部函数」；打开库、取符号地址、定外部函数、按签名调用 |
| `内存` | 分配与释放原生内存、按类型读写一个值、与字节串互相复制、原生内存之间搬移、C 字符串、张量存储的原生地址 |
| `调用宿主` | 「外部值」类型与调用模块用到的六个宿主原语（`。接口。豫`）；调用模块寻诵转出它们 |
| `内存宿主` | 内存模块用到的十二个宿主原语（`。接口。豫`）；内存模块寻诵转出它们 |

## 用法

```yuyan
寻观「系统库调用」之书。
```

- `「打开外部库」于 路径`：返回「外部库已打开」或「外部库未打开」（附 dlopen 的错误）。路径为空串时打开进程主映像，能见到已载入的全部全局符号。
- `「定外部函数」于 库 于 名字 于 返回类型 于 参数类型列`：得「或可有」于「外部函数」；符号不存在时为可无。`「按址定外部函数」` 由已取得的符号地址直接定函数，同一符号可以定多种签名（如 `objc_msgSend`）。
- `「调用外部函数」于 函数 于 参数列`：参数是「整数值」或「小数值」，个数与类型须合签名；参数列直接交给宿主（过边界时是“变〔整｜小｜〕”的列），有「无值」时宿主报错。结果按返回类型包成「整数值」「小数值」或「无值」。参数全是整数时可用 `「调用整数外部函数」`，直接得整数。
- 类型：外无（无返回，只用于返回）、外爻（布尔）、外字（八位无符号）、外整（三十二位有符号）、外长（六十四位有符号）、外址（指针）、外单（单精度）、外双（双精度）。指针按六十四位有符号整数保存，高位为一时是负数，零是空指针。
- 内存：`「分配原生内存」于 字节数 于 对齐`（清零，失败得零）、`「释放原生内存」`、`「读原生整数」「写原生整数」`（外字、外整、外长、外址）、`「读原生小数」「写原生小数」`（外单、外双）、`「读原生字节」「写原生字节」`（单次不超过 16 MiB）、`「复制原生内存」`、`「读原生文字」`、`「原生文字」`（复制成以零结尾的 C 字符串，用完须释放）。
- `「张量存储原生地址」于 句柄号`：张量适配用它取张量存储（SharedArrayBuffer）的地址与字节数，只有应用宿主有张量。地址只在张量存活期间有效：须先让原生一方放手，再释放张量。张量是存储上的跨步视图，这里给的是整块存储的起址，视图的起点、形状与步长用 `「张量存储视图」于 句柄号` 取：得「张量视图」（元素类型号、起点、形状、步长，起点与步长以元素计），另有 `「张量视图起点字节」`、`「张量视图连续」`、`「张量元素字节」`；视图信息只读，不需要允许系统库调用。

## 限制

待办事项：结构体按值传递（arm64 上大于 16 字节的结构体由调用者传指向副本的指针，写作外址即可；小结构体、x86-64 上的结构体未支持）；回调（`node:ffi` 的回调只能在创建它的线程上被调用）；可变参数函数；只能调用经取符号登记过的地址（运行时得到的任意函数指针未支持）；视窗未适配。

## 测试

`测试/` 下的「系统库调用测试」包：打开 C 库、取符号、调用 `strlen`、`labs`、`abs`、`sqrt`、`sqrtf`、`toupper`，分配、读写与复制原生内存，C 字符串往返；张量视图的纯函数部分（逗号数列解析、元素字节、连续判断、起点字节）总是运行。宿主不能调用系统库时其余部分打印“跳过”。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 系统库调用测试 调用。测试 --输出 yy系统库调用测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy系统库调用测试.wasm
```
