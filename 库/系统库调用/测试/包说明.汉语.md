# 系统库调用测试

系统库调用库的单元测试（`X。测试。豫`）：

- `调用。测试`：从进程主映像取 C 库函数并调用——`strlen`（指针参数；同一符号定六十四位与三十二位两种返回签名）、`labs`、`abs`、`toupper`、`isalpha`（布尔返回）、`sqrt`、`sqrtf`；分配清零的原生内存，按字、整、长、址、单、双读写，字节串往返与原生内存搬移；C 字符串往返；工具宿主取张量存储得可无。张量视图的纯函数部分（逗号数列解析、元素字节、连续与否、起点字节）与工具宿主取视图得可无总是运行；宿主不能调用系统库（诺节不支持 `node:ffi`）时其余部分只打印“跳过”。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试与系统库调用。测试包依赖被测库，所以登记在「共用库」之下。

## 使用

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 系统库调用测试 调用。测试 --输出 yy系统库调用测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy系统库调用测试.wasm
```

输出末行的“当前失败数”应为 0。
