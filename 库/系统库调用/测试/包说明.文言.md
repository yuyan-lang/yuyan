# 系统库调用测试

系统库之调之单元之试（`X。测试。豫`）：

- `调用。测试`：自进程主象取 C 库之函而调之——`strlen`（指针之参；一符号定六十四位与三十二位二返之签名）、`labs`、`abs`、`toupper`、`isalpha`（布尔之返）、`sqrt`、`sqrtf`；分已清零之原生之存，依字、整、长、址、单、双读写之，字节串往返与存间搬移；C 文往返；工具宿主取张量之存得可无。宿主不能调系统库（诺节不具 `node:ffi`）则惟书“跳过”。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟供试，依标准库、单元测试与系统库调用。试包依所试之库，故登于「共用库」之下。

## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 系统库调用测试 调用。测试 --输出 yy系统库调用测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy系统库调用测试.wasm
```

出之末行“当前失败数”当为零。
