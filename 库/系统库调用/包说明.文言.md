# 系统库调用

此乃于诺节宿主调系统动态库之豫言封装：开动态之库、取符号之址、依签名调其函，及分、读写、抄原生之存。其下为诺节宿主之系统库调用原语（外调名冠 `豫言_节点_外部库`，实于 `豫言操作系统/宿主/节点/外部库.mjs`，本于诺节之 `node:ffi`）。

此包惟供适配与系统库（若 `库/金属`）之用，不入公共之接口；应用当由接口与适配用宿主之能。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟依标准库，登于「共用库」之下。

## 宿主之求

- 诺节须具 `node:ffi`，以 `--experimental-ffi` 起。工具宿主 `宿主.cjs` 自为客之工作线程加此旗。应用宿主（`应用宿主.mjs` 与发行包之 `启动.mjs`）须予宿主之选 `--允许系统库调用`：系统库之调能行任意原生之码，越目录、网络诸授，故默不开；予此选而诺节未带此旗，宿主带旗自重启。
- `「系统库调用可用」` 为阴，则余函皆令宿主报误而终；用者当先辨之，不可用则退就他法。

## 模

| 模 | 所含 |
| --- | --- |
| `调用` | 类「外部类型」「外部值」「外部库」「外部函数」；开库、取符号之址、定外函、依签名而调 |
| `内存` | 分释原生之存、依类读写一值、与字节串相抄、存间搬移、C 文、张量之存之原生址 |

## 用法

```yuyan
寻观「系统库调用」之书。
```

- `「打开外部库」于 径`：返「外部库已打开」或「外部库未打开」（附 dlopen 之误）。径空则开进程之主象，已载之全局符号皆可见。
- `「定外部函数」于 库 于 名 于 返类 于 参类之列`：得「或可有」于「外部函数」；无其符号则可无。`「按址定外部函数」` 以既取之符号址径定函，一符号可定数签名（若 `objc_msgSend`）。
- `「调用外部函数」于 函 于 参列`：参为「整数值」或「小数值」，数与类须合签名；果依返类裹为「整数值」「小数值」或「无值」。参皆整数者可用 `「调用整数外部函数」`，径得整数。
- 类：外无（无返，惟用于返）、外爻（布尔）、外字（八位无号）、外整（三十二位有号）、外长（六十四位有号）、外址（指针）、外单（单精）、外双（双精）。指针存为六十四位有号之整数，首位为一则负，零为空。
- 存：`「分配原生内存」于 字数 于 齐`（清零，败则零）、`「释放原生内存」`、`「读原生整数」「写原生整数」`（外字、外整、外长、外址）、`「读原生小数」「写原生小数」`（外单、外双）、`「读原生字节」「写原生字节」`（一次不逾 16 MiB）、`「复制原生内存」`、`「读原生文字」`、`「原生文字」`（抄为以零终之 C 文，用毕须释）。
- `「张量存储原生地址」于 号`：张量适配以之取张量之存（SharedArrayBuffer）之址与字数，惟应用宿主有张量。址惟张量存时有效：须先令原生之方释之，乃释张量。

## 限

待办事项：结构体按值而传（arm64 上逾十六字之结构，调者传指副本之址，书为外址即可；小结构与 x86-64 之结构未支）；回调（`node:ffi` 之回调惟可于造之之线程调之）；可变参之函；惟可调经取符号所登之址（运行时所得任意函指未支）；视窗未适。

## 试

`测试/` 下之「系统库调用测试」包：开 C 库、取符号、调 `strlen`、`labs`、`abs`、`sqrt`、`sqrtf`、`toupper`，分、读写、抄原生之存，C 文往返。宿主不能调系统库则书“跳过”。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 系统库调用测试 调用。测试 --输出 yy系统库调用测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy系统库调用测试.wasm
```
