# dotsection 兼容静态补充

静读 Adobe 官方 #5177《The Type 2 Charstring Format》2000-03-16 版，附录C印刷页35（PDF第35页），确认旧PDF CFF中的 dotsection 应由 Type2 处理器支持。其编码12、0，操作数栈保持，Adobe ATM按空操作执行。原文链接：https://adobe-type-tools.github.io/font-tech-notes/pdfs/5177.Type2.pdf。

最小源码补充：转义零命令归零参数，并在实际执行前返回空操作，保持现栈数与各操作数。既有未知保留命令测试改用转义一；其他已支持命令的合法清单保持原样。末尾单独12仍由前一补丁按程序边界正常终止。

新增两条精确回归：直接转义零在栈含七时保持一项与值七；完整程序139、12、0、139、139、21、149、159、5、14继续输出移动段与终点10、20的直线段。回归总断言由21增为23，失败或数量异常强退出。

仅静态源码、格式化与差异核对，尚未构建运行。此补丁与转义参数保护由主合阶段后串行验证。
