# 底层扩充示例

底层模式（不用垃圾回收）扩充数值类型的回归示例：小数（f64）、单精度（f32，含指数、对数、双曲正切等超越函数）、长整数（i64）、向量（v128 SIMD，含 relaxed SIMD）、原子操作与共享内存。只依赖 `底层库`，用 `寻观「底层库」之「数值」之书。` 导入扩充部分。

每项校验不符时陷阱；导出的 `_start` 依次运行全部校验。用 `应用/开发工具/底层测试` 的诺节模式运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 底层扩充示例 --输出 yy底层扩充示例.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy底层测试.wasm --诺节 yy底层扩充示例.wasm
```

另有四个入口：`六四。豫` 校验六十四位地址内存（memory64）；`补充。豫` 逐个覆盖主入口没用到的原语，核对每个原语映射到的 Wasm 指令；`导入。豫` 含带类型的导入（参数与结果写类型字），诺节宿主不提供这些导入，只经编译与验证；`内存导入。豫` 从宿主导入一块共享内存并以“内存”导出，导出「工作线程」，诺节宿主据此起若干工作线程（环境变量 `YY_底层线程数`），各把自己的序号原子地加到和上，主线等完成数到齐后核对。构建时在包名后写入口名，如 `构建 底层扩充示例 六四 --输出 yy底层六四示例.wasm`。
