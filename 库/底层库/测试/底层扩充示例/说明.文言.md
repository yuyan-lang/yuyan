# 底层扩充示例

底层模式（不用垃圾回收）扩充数值之回归示例：小数（f64）、单精度（f32，并指数、对数、双曲正切诸超越函数）、长整数（i64）、向量（v128，并宽松之集）、原子之令与共享内存。唯依 `底层库`，以 `寻观「底层库」之「数值」之书。` 引其扩充。

诸校不合则陷；所出之 `_start` 依次行诸校。以 `应用/开发工具/底层测试` 之诺节之式行之：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 底层扩充示例 --输出 yy底层扩充示例.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy底层测试.wasm --诺节 yy底层扩充示例.wasm
```

别有入口三：`六四。豫` 校六十四位址之内存（memory64）；`补充。豫` 逐一覆主入口未用之原语，校其所映之 Wasm 令；`导入。豫` 含带型之导入（参与果书以型字），诺节宿主不供之，唯编而验之。构之则于包名后书入口之名，如 `构建 底层扩充示例 六四 --输出 yy底层六四示例.wasm`。
