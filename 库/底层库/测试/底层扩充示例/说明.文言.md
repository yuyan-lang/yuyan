# 底层扩充示例

底层模式（不用垃圾回收）扩充数值之回归示例：小数（f64）、单精度（f32，并指数、对数、双曲正切诸超越函数）、长整数（i64）、向量（v128，并宽松之集）、原子之令与共享内存。唯依 `磐石`，按模引其扩充（`数值类型`、`小数算`、`单精算`、`长数算`、`向量算`、`一气算`、`广仓`、`数格`、`单精术`，一模一行，书 `寻观「磐石」之「模」之书。`）。

诸校不合则陷；所出之 `_start` 依次行诸校。编为本机之程而径行之：

```sh
./豫构。林檎。豫行 构建 底层扩充示例 --输出 底层扩充示例 -j 24
./底层扩充示例
```

别有入口四：`六四。底层。豫` 校六十四位址之内存（memory64）；`补充。底层。豫` 逐一覆主入口未用之原语，校其所映之 Wasm 令；`导入。底层。豫` 调接口文件 `宿主。底层接口。豫`、`数学。底层接口。豫` 所声之带型导入（参果遍诸数值之类），诺驿宿主不供“宿主”之模之导入，唯编而验之；`内存导入。底层。豫` 自宿主导一共享之内存而以“内存”出之，又出「工作线程」，诺驿之宿依此起数工作线程（环境变量 `YY_底层线程数`），各以其序原子加于和，主线候其毕而校之。构之则于包名后书入口之名，如 `构建 底层扩充示例 六四 --输出 底层六四示例`。
