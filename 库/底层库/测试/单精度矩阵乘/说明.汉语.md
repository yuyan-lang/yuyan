# 单精度矩阵乘

底层模式的单精度（f32）矩阵乘样例：256×256 的方阵 丙 = 甲 × 乙，四种内核：

- 标量：按 行、中间维、列 三重循环，逐元素乘加；
- 向量：同样的循环次序，最内层每次处理四列（f32x4 广播乘加）；
- 分块：每行每次算十六列，四个向量累加量留在局部变量里走完中间维，最后一次写回；
- 融合：分块内核改用 relaxed SIMD 的单精度四融合乘加。

矩阵元素取 -8 到 8 的小整数，乘积之和在单精度里是精确的，因此各内核的结果逐位相同。入口 `入口。豫` 各算一遍并核对；`标量。豫`、`向量。豫`、`分块。豫`、`融合。豫` 各把一种内核重复二十遍，用来计时：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 单精度矩阵乘 --输出 yy单精度矩阵乘.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy底层测试.wasm --诺节 yy单精度矩阵乘.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 单精度矩阵乘 标量 --输出 yy矩阵乘标量.wasm
YY_NODE_STATS=1 node 豫言操作系统/宿主/节点/宿主.cjs yy矩阵乘标量.wasm
```

`YY_NODE_STATS=1` 让宿主在标准错误印出 `执行毫秒`（不含模块编译）。
