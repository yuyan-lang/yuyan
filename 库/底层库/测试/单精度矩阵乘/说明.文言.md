# 单精度矩阵乘

底层模式单精度（f32）矩阵乘之样例：二百五十六阶方阵，丙 = 甲 × 乙，内核四：

- 标量：行、中维、列三重之环，逐元乘加；
- 向量：环序同前，最内每次理四列（f32x4 广播乘加）；
- 分块：每行每次算十六列，四向量之累留于局部变量，走尽中维，末乃一书；
- 融合：分块之内核改用宽松之集之融合乘加。

矩阵之元取负八至八之小整数，乘积之和于单精度无失，故诸内核之果逐位相同。入口 `入口。豫` 各算一遍而相校；`标量。豫`、`向量。豫`、`分块。豫`、`融合。豫` 各复其内核二十遍，以计其时：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 单精度矩阵乘 --输出 yy单精度矩阵乘.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy底层测试.wasm --诺节 yy单精度矩阵乘.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 单精度矩阵乘 标量 --输出 yy矩阵乘标量.wasm
YY_NODE_STATS=1 node 豫言操作系统/宿主/节点/宿主.cjs yy矩阵乘标量.wasm
```

`YY_NODE_STATS=1` 令宿主于标准错误印 `执行毫秒`（不计模块之编译）。
