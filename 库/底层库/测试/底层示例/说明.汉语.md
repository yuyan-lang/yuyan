# 底层示例

底层模式（无垃圾回收）的回归示例：用普通豫言写成，声明 `「编译模式」者『底层』也。`，只依赖 `底层库`。构建产物是 Wasm 模块：

常量导出通过带重复标签的整数函数计算，验证底层模式的标签类型检查、逐位传参与擦除。

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 底层示例 --输出 /tmp/yy底层示例.wasm
```

再用 `应用/开发工具/底层测试` 在宿主侧的整数执行器里逐项校验导出函数（尾递归、递归、分派、内联循环、可变格、位运算、多参数、导出签名后缀）。含内存与静态数据的导出只做模块验证，由客体执行器等系统代码在裸机上实测。
