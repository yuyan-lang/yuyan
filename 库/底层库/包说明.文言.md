# 底层库

役录约（任务记录协议）统服务四十六之百二十八字小端布局，宽、量、阙符皆出一编。普通篇为源，豫构（构建工具）之役录约生成脚本生底层之副，司阍（准入控制）之试较二篇无差；改约则于仓根重生。行在（运行环境管理器）、任务簿（任务表记账）与执行器共守之。号存非负全印，态之第八位别机役；牒中以二之三十一次方为机域之基。

核块栏约（核块栏之类，十一月六日，提案〇〇〇七三、议千六百三十三）以「核块某栏之偏」为一种抽象之类，公开之表藏于同名之底层签名之后。其值惟二：`核块栏偷来`、`核块栏被偷`，各以核块约之常造之；签不登通用之构造，故外不能造任意之偏。依核块偏读核块之接口（硬件接口机核块和，及其行机、内核机约二分）惟受此类型；以役录、差遣录或他整数之偏授之则编时即报——十一月六日之前，任务簿之写任务记录正以役录之偏百二十八、百三十六授机核块和，读为核块之差遣役与停世次数。核块内之算仍用整数，实者入而用核块栏作偏解一次。负例见客体二号之测试核块栏误交其一。

启块约（启动块之约，十一月九日，议千六百九十七）定父起子时所授启块之局：首八兆为参区，次六万五千五百三十六字为名区，名区中程名、显代之名、所居之目、输入之径与环区之偏与限皆惟定于此篇；全块连存之启块，其名区之址以启块名区求之。系统所读于子役环区之数项列于小变体境键（将作优先、内存软额、协程核验），其名之字惟书于境键码位一处，诸处不复以静串较键；境项（值距名区之偏）、境数、境优先（仓档：壳与交互零、后台二、余一）、境软额千（兆乘千零二十四）依名区与块长读之，逾块逾区之字不读，不得或书误则答其常。址为呼者己域之长整，由广仓长址读之：裸核读父役之用户虚址（装载与按段入环时取优先与软额），虚机启动器读己之线址（登籍、协程核验）；执行器布局之同名之常皆转引此篇，林兼容启块诸栏之偏、内核名区所居之块亦取此名。试在测试启块约。

服号约（核务之号，十一月九日，议千六百九十七）自冶铸裸机服务约之名号二列生之，一项一常，名同约名，值为核务之号；核之动务分派（入口、装载、任务之篇与行在核任务簿之句柄服务）皆书服号约之名，号惟定于服务约。勿手改：改约则于仓根跑服号约生成之脚本重生之，带型核对逐字校其与约同否。

核块约（每核状态块之约，提案〇〇〇七三）定诸核各守之块：块长万六千三百八十四字，诸栏之偏、零号之址与块数之限皆出一编。核指之寄（臂 x29，兼 r15）藏本核块之绝址，所生之码以核指加常偏读书之；零号之块居线性之址五十万七千九百零四，余块执行者以取区域连列，首址与块数书于全实例之格。普通篇为源，豫构之核块约生成脚本生底层之副，冶铸之核块约之试较二篇无差；执行器、冶铸、虚机与内核皆取偏于此。

续客帧约（臂六四服务场帧之约，十一月九日，提案〇〇〇七三第四期）声服务之呼于客栈所遗之续客帧：门公共之跳板减栈十六字（臂续客门压长）压服务号与 x17，服务入口之桩复减二百八十八字（臂续客现场长）藏 x1 至 x15、x19 至 x30 与 d8 至 d15，帧长三百零四（臂续客帧长），帧首加帧长为呼务前之客栈针。诸寄之偏、号位、x17 位与帧长皆由约中之名而算，不书裸数。普通篇为源，豫构之续客帧约生成脚本生底层之副；冶铸之桩、门公共与续客段，客体二号开工作核之伪帧（务三百二十一）、协程首切（三百三十一）与续行（三百九十八）皆取于此，带型核对核二篇无差、诸篇皆引此约、不复见旧之手书之数。兼六四之续客帧今犹在客体二号工作核约与冶铸兼豫行务入口桩二处，后当收入此篇。

陷阱记录约（核陷阱账录之局，十一月二日）定务三百零九每核一录之百零四字小端：核号四字，其后抢占、续行、客陷之合、依信号六项（含坏调）、最近客陷之任务号、信号号与出事之码偏各八字。虚机之启动器依之填录，执行器之公共任务原语依之读录，壳命析陷阱所印之表亦以诸栏为准；诸端惟引此篇之字段与单位。核区中同账之始与诸栏之偏别见客体二号之陷阱账篇，与本篇之账块同序（核区之偏等录之偏加一八四）。

图籍约（栈图与侧表之式，十一月九日，议千六百九十九之静防）定冶铸所书、执行器所读之二籍：栈图之首（三十二字：魔数、版、总长、函项之数、表码偏、呼处之数、运行之表址）、函项（三十二字：码偏、旗、帧大、存数、十二所保之寄号、函号）、四旗与呼处之项（八字，自二版始有），及侧表之首（百四十四字，三十六栏）之魔数、版、首长、诸栏之偏、扩展之标，与名段之段名长、函名子段之种。普通篇为源，豫构之图籍约生成脚本摹出底层之入口，冶铸之试较二篇无差、诸栏首尾相接、三魔数合于“YYZT”“YYCB”“YYST”之小端；冶铸与执行器皆依名取之，不别抄数。侧首百四十之迁录偏仍归迁址约。

小变体之试（议一千二百八十四、一千二百九十三），验整数、爻与三十二爻之卦，依值造之、传之、还之，鉴诸支而尽。缺支、广载与入布局之栏，各作编时告误之例。小变体循既有类块与造器之文，其形其界，见编译器《底层模式》。

底层（不用垃圾回收）编译模式之基础库：整数之算、内存之读写、可变之格、静态串与声明；数值之扩充有小数（f64）、单精度（f32）、长整数（i64）、向量（v128）、原子之令与六十四位址之内存。编译之模以文名定之，此库之文皆底层之文（名含「。底层」），故唯底层之文得导之，而此库不依任何包（尤不依标准库）。

## 用法

于底层包之 `依赖` 列 `『磐石』`，源文首行书 `寻观「磐石」之书。`（包之默认导入：`基`、`仓廪`、`格`、`址算`），则得整数之诸原语：

- `基`：`整数`、`爻`、`有` 等类型别名；`加`、`减`、`乘`、有符无符之除与余、位运算、移位、比较、`非`、`且`、`或`、`择`、`坎`。
- `仓廪`：`读四`、`读二`、`读一` 及其有符者；`写四`、`写二`、`写一`；`存页数`、`存增长`、`存摹`、`存填`；`声明存`、`声明共享存`、`声明存六四`、`声明共享存六四`、`声明存引`（改自宿主导内存）、`声明存出`、`声明数据区`、`静态文`。
- `格`：`置格`、`读格`、`写格`（可变之局部变量）。
- `址算`：址宽之整数（址）：`址加`、`址减`、`址乘`、`址无号除`、`址无号余`、位之算与移、较、`数作址`、`有号数作址`、`址作数`、`读址`、`写址`、`址宽`。前端之型书整数，其宽随内存之声（常内存三十二位，六十四位址之内存六十四位），同源可编二宽。此旧法也；新文用下 `数值类型` 之 `址` 与 `址度` 之原语，宽书于型上。
- `址度`：收「址」之址之原语（用时书 `寻「磐石」之「址度」之书。`，依模名别于规度、本术之同名旧版）：`数作址`、`有号数作址`、`址作数`、`指作址`、`址作指`、`进址`（址加整数之偏，偏依无号扩），及唯六十四位址之内存乃立之 `长数作址`、`址作长数`。址之算、读写与较，仍用 `址算` 与 `本术` 中「甲」多态之 `址加`、`址减`、`址等于`、`读址`、`写址` 等，`址` 可径入。

数值之扩充，按模逐一导之，一模一行，若 `寻观「磐石」之「小数算」之书。`（与默认导入分立，唯用整数之旧程序其依赖不变，旧编译器犹能编之）：

- `数值类型`：`小数`、`单精度`、`长整数`、`向量`、`址`（址宽之整数，宽随仓制：三十二位或六十四位；前端由型知其宽，生码依此出 i32 或 i64）。
- `小数算`、`单精算`、`长数算`：四则、取整、开方、较、互转、位型互转与内存之读写。
- `向量算`：单精度四、整数四、短整数八、字节十六诸形之算，广播、车道、洗牌、读而扩之、点积与宽松之集。
- `一气算`：原子之读写、读改写、较换、候与唤（须声共享内存）。
- `广仓`：六十四位址内存之 `长址…` 诸函：四、二、一字节与小数、单精度、长整数、向量之读写，页数与增长，成批之复制与填充，原子之操作；址皆长整数。
- `数格`：小数、单精度、长整数、向量之格。
- `单精术`：指数、对数、双曲正切、逻辑斯谛、正弦、余弦、幂（多项式逼近）。

诸函皆本术（基础内建原语）之模（`本术。底层内建。豫`）内建之声之包装，类型检查依底层原语表校之，易为 `底层_加` 等内名，编译器内联之而映于 Wasm 指令；语言之约与限见 `应用/豫言编译器/文档/底层模式.文言.md`。

## 维护

规度（布局内建原语，`规度。底层内建。豫`）供卦（定宽无号整数）、指向（带类型地址）、依类择宽之「读」「写」、长整数与卦之「卦作长数」「长数作卦」、三十二位整数与卦之「卦作数」「数作卦」及有号解读「卦作有号长数」，并供址与指向之「址作指」「指作址」。址度（址宽整数之原语，`址度。底层内建。豫`）供收「址」之「指作址」「址作指」「数作址」「有号数作址」「址作数」及唯六十四位址之内存乃立之「长数作址」「址作长数」，用时 `寻「磐石」之「址度」之书。` 依模名别于规度、本术之同名旧版。长整数址与指向之「长址作指」「指作长址」在广规度（`广规度。底层内建。豫`），六十四位址内存之代码别导之。列度（定长列内建原语，`列度。底层内建。豫`）供「定长列」、取数组元素址之「第址」与运行期验下标之「验下标」（其疆取类中隐列长）；`（「定长列」于 n 于 T）` 为布局之栏时，其广等 T 之广乘 n，其齐取 T 之齐。列下标（`列下标。底层。豫`）供「下标」之类。元组之类声内存之局，栏依自然之齐紧列；「中」得栏之址。用则明导 `寻观「磐石」之「规度」之书。`、`寻观「磐石」之「列度」之书。` 与 `寻观「磐石」之「列下标」之书。`，数值之类仍依旧模导之。默认所引存旧器所识之声，列度、列下标、规度、址度与广规度由通布局之新器检之。则见底层模式第二、五、六节。

客值（宿主边界客体类别标记，`客值。底层。豫`）供客参、客果、客串、客列、客组、客资、客变七标，与「指向」相合，以别参列、果值、串、列、组、资及有构造之物。实方自定其局，译器循约声生成取参、直召与还果之派，见规范「类型与模块」类六。实约（生成分派调用接口，`实约。底层。豫`）供程内计声、依双名求号、按号入派三术，用者明引；底层总装直连实约机（分派内部链接协议）之引于生成之术。

增原语则同更底层后端之原语表（`库/译场/分职/笔受/底/底定型。豫`；特殊之原语另于 `底层生成。豫` 处之，并登于同篇之殊名之单）。新声别置底层内建之篇，用者明引；新器自举既验、连续版既更，乃依所需接入默认所引之闭包。
