# 中央张量内核

此为张量计算接口（`豫言操作系统接口/张量计算`）之中央处理器算子内核之库，以底层豫言（无回收之底层之模，见 `应用/豫言编译器/文档/底层模式.文言.md`）书之，一份之码行于诸台：编为 Wasm 则径行于诺节、浏览器与云工；原生三台（路二）与豫言系统，则由裸机后端降同一 Wasm 为 ARM64、x86-64 之机器码。入口、参数之区之布与组之分，皆依 GPU 内核之库 `库/张量内核`，故其「内核表」之模之包参之函与组数之式可径复用。

## 包之身

主：豫言。版：0.1.0。底层之模之库，唯依 `底层库`。既依底层库，不得登为其子（父包之库子为隐依，将成环），故自为一根。试在 `测试/`（包「中央张量内核测试」，可执行之类，登于共用库之下）。

## 入口之约

1. 每入口为底层之函 `（参数区之址, 绑定表之址, 组起, 组止）→ 有`，司工作组 [组起, 组止)。工作组同 GPU 之核：组数 G 之式、每组之工（组之大 N 线）皆依 `库/张量内核` 之内核表；组内 N 份之工以环成之，可向量化者用单精四（f32x4）。
2. 参数之区为三十二位字之列，与 GPU 之核之绑定零逐字同（整依无号，步依 i32 二补码，小数依 binary32 之位型，可变之行号、批偏接于定长之头后）。
3. 绑定之表为三十二位字之列，第 k 项为绑定 k 之首字节之址（第零项不用）；绑定之号与次同 GPU 之核。张量之起仍书于参数之区，依各绑定之元计之：单精、三十二位整数依四字，半精、脑浮点依二字，块量化依字。
4. 址为三十二位（线性内存至多 4 GiB）。可书之绑定不得与他绑定相叠（同 GPU 之约）。
5. 每出唯由一组依定序求之，组区如何分于诸线皆不易其果：多线与单线逐位同。

## 多线：役板

`派发。豫` 之役板为共享内存中之二百五十六字（齐于八字）：代号、退出、入口号、参数区之址、绑定表之址、组数、每领之组数、已毕之组数、六十四位之领字（高三十二位为代号，低三十二位为次组之号），其后为每线所行组数之计。

- 主线调 `「板派发」于 板 于 入口号 于 参数区 于 绑定表 于 组数 于 块`：先易领字为新代号，乃书余字，终加代号而唤诸工作线程，己亦依块领而行之，候已毕之数至乃返。`「板派发选」` 可令主线惟候不算（试用之以验工作线程之果）。
- 工作线程调 `「板工作线程」于 板 于 序号`：代号未易则先旋而后以原子候之；易则以较换依块领组区 [起, 止) 而调「运行入口」；退出之字非零则返（`「板退出」` 告之）。
- 领时较全领字，故后至之工持旧代号不得领新组，亦不读方改之字；无工作线程则主线独算之，亦正。
- 诺节之宿（`豫言操作系统/宿主/节点/底层宿主.cjs`）见模出「工作线程」，乃起数工作线程，各以同模、同共享之内存实例化而调 `工作线程(序号)`；其数取环境变量 `YY_底层线程数`（缺则可用处理器之数减一）。

## 数值

- 矩阵乘、矩阵向量乘与 Q8_0 之点积用单精四之融合乘加（宽松之集，诸台真融合否或异，皆在规范之容差内）；向量之累终横而和之，K 之余逐一加之。和之序异于 GPU 之核，依规范之容差较之。
- 指数：阶夹于 [−126, 127] 而以六次泰勒多项式逼之，大于 88.7228 得正无穷，小于 −87.3365 得零；对数：析尾与阶而以级数求之，次正规者先放大 2²³，零得负无穷，负得非数，正无穷得正无穷；双曲正切先夹于 ±15（同 GPU）；反曲依号取稳之式；乘方逐道依 C 之 pow 处诸特例，余者为 e^(指 × ln|底|)。常用之域相对误差约千万分之一至百万分之一。
- 非数依规而传：取大、取小与诸最大之归用 Wasm 之 max/min（遇非数得非数），较遇非数不成，修正线性存其非数。

## 所限与待办

- 待办事项：第二批之入口（就地线性组合、亚当更新、层归一、二范数归一、按行最大下标、取前 k、按专家矩阵向量乘、超四与超六矩阵向量乘、按专家量化矩阵向量乘、块八矩阵乘分块、注意力与分段注意力、写入十六位、转单精度、填充随机、因果卷积、门控递推）未备。
- 待办事项：六十四位址（memory64）之版，线性内存逾 4 GiB 则需之；块量化之字节之起近 2³¹ 时，较依有号为之。
- 待办事项：半精、脑浮点乙之矩阵乘逐出求点积，未为微块；逐元之算每四元一判算码与步，连续之张量可专之；旋转位置编码逐元而算；软最大一行唯一组算之，长行不得分于诸线；每领之块数由调者予之。
- 待办事项：x86-64 原生之路浮点寄存器唯十二，矩阵乘分块之十六累逾操作数栈深之限，须改为 2×4 之微块或俟降级器能溢于帧；今唯验于 ARM64（二十四）。
- 待办事项：原生与豫言系统之候与唤今为单线之实（见 `豫言操作系统/裸机/文档/数值降级.文言.md`），役板于彼唯可单线用之。
