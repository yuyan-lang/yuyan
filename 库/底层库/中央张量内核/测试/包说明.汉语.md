# 中央张量内核测试

这是中央张量内核的测试包（底层模式，可执行文件类型，默认入口是 `逐元。测试`）。测试在诺节上运行：诺节宿主（`豫言操作系统/宿主/节点/底层宿主.cjs`）按各入口的导入建共享内存、提供「数学」「诺节」两个导入模块的函数，并因为导出了「工作线程」而起若干工作线程（环境变量 `YY_底层线程数`，缺省为可用处理器数减一），都共用同一块共享内存。结果与双精度参照（宿主的 JS Math 函数与双精度四则）按张量计算规范的容差 |结果 − 参照| ≤ 1e-5 + 1e-3 × s 比较（逐元运算 s 为 |参照|，归约与矩阵乘为各被加项绝对值之和）；打印“当前失败数：N”，有失败时陷阱，进程以非零状态退出。

## 包身份

所有者：豫言。包版本：0.1.0。依赖底层库与中央张量内核；它依赖被测库，所以登记在上一级父包「共用库」之下（可执行文件类型的子包只作归类）。

## 内容

- `测试公用。豫`：内存布局（数据区、工作板、参数区、绑定表、按块分配）、诺节宿主的导入（声明在 `诺节。接口。豫`、`数学。接口。豫`：写出字节与数、毫秒、工作线程数、双精度的指数、对数、双曲正切、乘方、正弦、余弦）、参数区与绑定表的填写、按类型（单精度、半精度、脑浮点）写值、容差核对与整数核对、「跑」（有工作线程时经工作板派发，否则单线程调用）、「分段跑」（单线程把组区间拆成几段），以及导出的「工作线程」。
- `量化数据。豫`：块量化测试数据（造法同 GPU 测试）：伪随机字节，Q8_0、Q4_K、Q6_K 块的字节与按 GGML 格式解出的元素值。
- `逐元。测试。豫`：逐元二元十种运算（广播、起点偏移、转置视图，含 NaN、无穷、除以零与负底乘方），逐元一元十二种运算，逐元标量几种运算——用例同 GPU 测试。
- `复制与归约。测试。豫`：填充常数（单精度与三十二位整数视图）、跨步复制（转置、广播、负步长、目标为视图）、取行（单精度与块量化八位）、按行累加（行号重复）、末维求和与末维最大（含 NaN 的行）、软最大、70000 行的末维求和（结果之后的哨兵不得改写）、均方根归一（权为单精度、半精度、脑浮点）、按轴求和与按轴最大。
- `矩阵与位置。测试。豫`：矩阵乘分块与矩阵乘向量（尺寸不是瓦片的整数倍、两批且乙沿批广播、起点偏移；乙为单精度、半精度、脑浮点）、旋转位置编码（两种配对方式）、块八矩阵向量乘（每行块数为奇数，对齐交替出现）。
- `多线程。测试。豫`：组数较多的入口（逐元一元、软最大、均方根归一、按轴求和、矩阵乘分块、矩阵乘向量、块八矩阵向量乘）各算四遍——单线程一次调用、单线程分七段、经工作板（主线参与）、经工作板（主线不参与，只由工作线程算）——结果须逐位相同，并打印干了活的工作线程数。
- `训练与随机。测试。豫`：层归一与二范数归一、按行最大下标（并列、NaN、全为 NaN 的行）、就地线性组合与亚当更新、填充随机（三个种子，目标为视图；均匀与宿主的 Philox 结果逐位比较，另测正态与伯努利）。
- `十六位。测试。豫`：写入十六位（八分值逐位比较，就近取偶的边界、溢出、次正规、NaN 与负零，从奇数位置起写时前后的半字不变）、转单精度（半精度、脑浮点、八位整数、三十二位整数）、以半精度与脑浮点存放的取行表。
- `量化与注意。测试。豫`：Q4_K 与 Q6_K 的取行、矩阵向量乘与矩阵乘分块（乙前空一块，Q6_K 的块首不按四字节对齐）；注意力（键值为单精度或半精度，起点为奇数）与分段注意力加注意力合并（段长 256、96、512；段长 96 时有一段没有可见的键）。
- `序列与专家。测试。豫`：取前 k（大量并列、含 NaN 的行、几乎全是 NaN 的行，以及 k 等于行长的整行排序）、按专家矩阵向量乘（乙为单精度、半精度、Q8_0、Q4_K，甲共用或各用）、因果卷积与门控递推（一次算完与借状态分两次调用，结果与末状态都与参照相同）。
- `计时。豫`（不是测试）：打印各入口的平均耗时，尺寸同 GPU 的实测表（矩阵乘分块 1024³ 等）；设 `YY_底层线程数=0` 即单线程。
- `第二批计时。豫`（不是测试）：第二批入口的平均耗时，尺寸同 GPU 的第二批计时（注意力、超块量化矩阵向量乘、取前 k、按专家量化矩阵向量乘、因果卷积、门控递推、层归一、亚当更新、写入十六位、转单精度、填充随机）。
- `原生。豫`（不是测试）：原生路径（路二，macOS arm64）的检查：自带内存，经 libSystem 的 write、exit 输出与退出，参照只用双精度四则与开方。

## 运行

在仓库根目录：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 逐元。测试 --输出 yy中央逐元测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy中央逐元测试.wasm
env YY_底层线程数=4 node 豫言操作系统/宿主/节点/宿主.cjs yy中央逐元测试.wasm
```

其余测试同法；全树测试自动发现并运行它们（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/底层库/中央张量内核/`）。计时与原生：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 计时 --输出 yy中央计时.wasm -j 24
env YY_底层线程数=0 node 豫言操作系统/宿主/节点/宿主.cjs yy中央计时.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 第二批计时 --输出 yy中央第二批计时.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy中央第二批计时.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 原生 --输出 yy中央原生.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 豫言裸机 原生生成 --输出 yy原生生成.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=512 node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm 苹果 臂六十四 yy中央原生.wasm yy中央原生
./yy中央原生
```

原生程序全部合规时以 0 退出，打印“原生中央张量内核：共不合 0”。
