# 中央张量内核测试

此为中央张量内核之试之包（底层之模，可执行之类，默认之入口为 `逐元。测试`）。试行于诺节：诺节之宿（`豫言操作系统/宿主/节点/底层宿主.cjs`）依诸入口之导入建共享之内存，供「数学」「诺节」二导入之模之函，又因其出「工作线程」而起数工作线程（环境变量 `YY_底层线程数`，缺则可用处理器之数减一），共一共享之内存。其果与双精之参（宿主 JS 之 Math 函数与双精之四则）依张量计算规范之容差 |果 − 参| ≤ 1e-5 + 1e-3 × s 较之（逐元之算 s 为 |参|，归约与矩阵乘为诸加项绝对值之和）；书“当前失败数：N”，有败则陷，进程以非零之状退。

## 包之身

主：豫言。版：0.1.0。依底层库与中央张量内核；既依所试之库，故登于上一级之父「共用库」之下（可执行之子惟以归类）。

## 所含

- `测试公用。豫`：内存之布（数据区、役板、参数之区、绑定之表、依块之分配）、诺节之宿之导入（书字节与数、毫秒、工作线程之数、双精之指数、对数、双曲正切、乘方、正弦、余弦）、参数之区与绑定之表之填、容差之核与整数之核、「跑」（有工作线程则经役板而派，否则单线一调）、「分段跑」（单线析组区为数段），及所出之「工作线程」。
- `逐元。测试。豫`：逐元二元之十算（广播、起之偏、转置之视，含非数、无穷、除以零与负底之乘方），逐元一元之十二算，逐元标量之数算——其例同 GPU 之试。
- `复制与归约。测试。豫`：填常（单精与三十二位整数之视）、跨步之抄（转置、广播、负步、目为视）、取行（单精与块量化八位）、按行累加（行号重）、末维求和与末维最大（含非数之行）、软最大、七万行之末维求和（果后之哨不得易）、均方根归一（权为单精、半精、脑浮点）、按轴求和与按轴最大。
- `矩阵与位置。测试。豫`：矩阵乘分块与矩阵乘向量（尺非瓦之整倍、二批而乙沿批广播、起有偏；乙为单精、半精、脑浮点）、旋转位置编码（二种配对）、块八矩阵向量乘（每行块数为奇，齐迭见）。
- `多线程。测试。豫`：诸组多之入口（逐元一元、软最大、均方根归一、按轴求和、矩阵乘分块、矩阵乘向量、块八矩阵向量乘）各算四遍——单线一调、单线分七段、经役板（主线与之）、经役板（主线不与，唯工作线程算之）——果须逐位同，并书有役之工作线程之数。
- `计时。豫`（非试）：书诸入口之均时，尺同 GPU 之实测之表（矩阵乘分块 1024³ 等）；设 `YY_底层线程数=0` 即单线。
- `原生。豫`（非试）：原生之路（路二，macOS arm64）之验：自带内存，经 libSystem 之 write、exit 书出而退，参唯用双精之四则与开方。

## 行之

于仓之根：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 逐元。测试 --输出 yy中央逐元测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy中央逐元测试.wasm
env YY_底层线程数=4 node 豫言操作系统/宿主/节点/宿主.cjs yy中央逐元测试.wasm
```

余试同法；全树之试自寻而行之（`node 豫言操作系统/宿主/节点/宿主.cjs yy全树测试.wasm --只 库/底层库/中央张量内核/`）。计时与原生：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 计时 --输出 yy中央计时.wasm -j 24
env YY_底层线程数=0 node 豫言操作系统/宿主/节点/宿主.cjs yy中央计时.wasm
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 中央张量内核测试 原生 --输出 yy中央原生.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 豫言裸机 原生生成 --输出 yy原生生成.wasm -j 24
YY_GC_INITIAL_HEAP_SIZE_MB=512 node 豫言操作系统/宿主/节点/宿主.cjs yy原生生成.wasm 苹果 臂六十四 yy中央原生.wasm yy中央原生
./yy中央原生
```

原生之程皆合则以零退，书“原生中央张量内核：共不合 0”。
