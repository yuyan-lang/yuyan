# 构建基础

提供包定位、上下文与异步构建调度。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 模块

- 包定位、包上下文：发现包与写包上下文。包上下文一律写第五版；读到旧日带“文体”一列的第六版时略去这一列。存放目录（`.豫构缓存/豫构上下文`）里的上下文头一次启用时，旁边另写一份境检（包上下文二进制索引，`号.上下文。境检`）：记着上下文原文、仓库根前缀和每个包的目录、身份与预先算好的缓存号，目录按散列分桶。此后每个编译任务启用这份上下文时只读境检，按目录查所属包与缓存号，整份文本到真要用（如导入解析）时才解析；境检缺了、坏了或记的原文与上下文不符时照旧解析文本。
- 调度器：构建任务图的并行调度；每个任务记录加入、就绪、开始、结束四个时刻与开始时的在途数。调度开销与任务数成线性：任务完成只唤醒等它的下游，就绪任务进按（优先级，加入次序）排的最小堆，每轮只看在途任务与新加入的任务；运行中任务图匣当收件箱用，每轮取空，结束时按加入次序写回全部任务。无面板调度在队列空时至多每 200 毫秒复查一次子进程完成状态，即使子进程没有输出。
- 并行编译、构建监视：编译器的阶段任务图与终端监视面板；完成进度条由终端界面库生成。
- 交役（`交役。豫`，提案 00035）：构建服务客户端。并行编译开头「探将作」找本机构建服务「将作」（没有就在后台起一个），此后「将交役」把每个任务交服务：新连接先登门（令牌、客号、工作目录、全部环境变量），每个任务一行交役，服务交该工具链的代役执行，答一行役毕（退出码与两路输出）；服务答自行时它已给本任务留出一个槽，客在本机执行，执行完在同一连接上答自毕还槽。服务起得慢时等至多三十秒（三秒后印一行提示）；连接出错先重交一次（服务不在就重起它），确实连不上才直接在本机执行并印一行提示。消息都是一行数据子语言（籍册，「将作成牒」「将作析牒」），服务与代役共用这里的读行、写尽、令牌等函数。CI 环境、`.wasm` 编译器不用服务；`豫言将作=关` 时只借槽：交役带“借”栏，服务只排槽、不派代役，任务都在本机执行（将作不在也不起它）。用服务时并行编译同时交出的任务放宽到 `-j` 的两倍加八，多交的在服务里排队，本机槽满时便有任务可托给同僚。工作任务一侧另有两件（提案 00035 第四、五步）：「将作取键」在共享缓存未命中时，若本机将作有在线同僚（会合点下有“同僚在”标记）且本任务是托出办成后的重放（环境变量 `豫言将作邻取`），请服务向同僚要这一键与产物，再不然按 `豫言将作远作` 向云端缓存要；「将作取引」在替同僚执行任务（环境变量 `豫言将作借场` 有值，即借场）时，缺的阶段缓存文件与源文件向托主要，取来写到镜像根下的原位，访包的「实径」与包境的「启包境」借它补源文件。
- 构建日志：把构建事件写进半永久的日志目录（依赖结森工具写 JSON），格式见[构建日志格式](../../应用/度量/构建性能/日志格式.汉语.md)。
- 构建宿主（`构建宿主。接口。豫`）：宿主服务包括存放包上下文、可绘监视面板、绘监视面板、获取当前程序 SHA-256 和获取文件 SHA-256，以及装载单元用的单元现况、单元存、单元并入、单元带型码、单元装代码与单元运行（提案 00003，原生执行器原语 186–191，豫构的「运行」经 裸机后端 的 单元装入 调用；诺驿与浏览器宿主没有这些函数）。获取当前程序 SHA-256 返回程序内容的身份：Node 上是 Wasm 文件内容的 SHA-256，编译器直出的原生程序与由汇编树码造的豫行文件是程序汇编树码的 SHA-256（提案 00007 收尾），所以原生编译器与 Node 上的 .wasm 编译器各用各的编译缓存目录；获取文件 SHA-256 返回指定文件内容的 SHA-256。它们编成导入模块“构建基础”的带类型导入；模块名不叫“宿主”，免得与标准库的“宿主”模块同名而互相遮蔽。

## 使用

并行编译完成前端任务并写出任务耗时与依赖记录后，清空已完成的调度任务图，释放回调与异步结果；最终链接使用文件依赖图，阶段总量由已知文件计算。

并行编译支持最终链接参数交接。调用方通过编译器参数 `--链接参数输出 文件` 指定结森文件，前端完成后写出工作模式的链接参数并退出；豫构在裸机宿主上读取此文件，再启动最终链接，使前端进程的整份堆先归还。豫构起最终链接时再加 `--原生参数输出 文件`：大客体要另起原生生成时，最终链接只写出客体文件与原生生成参数就退出，豫构接着起原生生成（同一编译器加 `--原生产物子进程`），完后删掉客体与参数文件，最终链接进程的整份堆也先归还。宿主继续沿用编译器的子进程链接。

在仓库根目录运行：

```sh
./豫构。林檎。豫行 检查 构建基础
```

## 程序标识

`程序标识。豫` 给出本程序的摘要「本程序沙二五六」：编译缓存目录名、装载单元缓存键与单元目录印记都用它。缺省是构建宿主的「取今程序沙二五六」；豫言操作系统的开机程序（提案 00003 第 8 步）开机时把「程序沙二五六覆盖」设成盘上 /工具/豫构。豫行 的摘要（造盘时写在 /工具/豫构。豫行。摘要），与它共用编译缓存。

依赖及说明路径以 [包配置](构建基础。包。豫) 为准。
