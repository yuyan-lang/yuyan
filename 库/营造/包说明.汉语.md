# 构建基础

提供包定位、上下文与异步构建调度。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 模块

- 包定位、包上下文：发现包与写包上下文。包记录的第七项是包的文体名（提案 00026，包描述的「文体」，缺省为「常文体名」即雅言，现在只登记雅言）；没有包写非缺省文体时包上下文仍是第五版，有包写了非缺省文体时写第六版（在“默认导入”与依赖之间多一列“文体”）。「取卷所属包文体」按文件取所在包的文体名，编译器据此选解析器。
- 调度器：构建任务图的并行调度；每个任务记录加入、就绪、开始、结束四个时刻与开始时的在途数。无面板调度在队列空时至多每 200 毫秒复查一次子进程完成状态，即使子进程没有输出。
- 并行编译、构建监视：编译器的阶段任务图与终端监视面板；完成进度条由终端界面库生成。
- 构建日志：把构建事件写进半永久的日志目录（依赖结森工具写 JSON），格式见[构建日志格式](../../应用/度量/构建性能/日志格式.汉语.md)。
- 构建宿主（`构建宿主。接口。豫`）：宿主服务包括存放包上下文、可绘监视面板、绘监视面板、获取当前程序 SHA-256 和获取文件 SHA-256，以及装载单元用的单元现况、单元存、单元并入、单元带型码、单元装代码与单元运行（提案 00003，原生执行器原语 186–191，豫构的「运行」经 裸机后端 的 单元装入 调用；诺驿与浏览器宿主没有这些函数）。获取当前程序 SHA-256 返回程序内容的身份：Node 上是 Wasm 文件内容的 SHA-256，编译器直出的原生程序与由汇编树码造的豫行文件是程序汇编树码的 SHA-256（提案 00007 收尾），所以原生编译器与 Node 上的 .wasm 编译器各用各的编译缓存目录；获取文件 SHA-256 返回指定文件内容的 SHA-256。它们编成导入模块“构建基础”的带类型导入；模块名不叫“宿主”，免得与标准库的“宿主”模块同名而互相遮蔽。

## 使用

并行编译完成前端任务并写出任务耗时与依赖记录后，清空已完成的调度任务图，释放回调与异步结果；最终链接使用文件依赖图，阶段总量由已知文件计算。

并行编译支持最终链接参数交接。调用方通过编译器参数 `--链接参数输出 文件` 指定结森文件，前端完成后写出工作模式的链接参数并退出；豫构在裸机宿主上读取此文件，再启动最终链接，使前端进程的整份堆先归还。豫构起最终链接时再加 `--原生参数输出 文件`：大客体要另起原生生成时，最终链接只写出客体文件与原生生成参数就退出，豫构接着起原生生成（同一编译器加 `--原生产物子进程`），完后删掉客体与参数文件，最终链接进程的整份堆也先归还。宿主继续沿用编译器的子进程链接。

在仓库根目录运行：

```sh
./豫构。林檎。豫行 检查 构建基础
```

## 程序标识

`程序标识。豫` 给出本程序的摘要「本程序沙二五六」：编译缓存目录名、装载单元缓存键与单元目录印记都用它。缺省是构建宿主的「取今程序沙二五六」；豫言操作系统的开机程序（提案 00003 第 8 步）开机时把「程序沙二五六覆盖」设成盘上 /工具/豫构。豫行 的摘要（造盘时写在 /工具/豫构。豫行。摘要），与它共用编译缓存。

依赖及说明路径以 [包配置](构建基础。包。豫) 为准。
