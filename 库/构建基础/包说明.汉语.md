# 构建基础

提供包定位、上下文与异步构建调度。

## 包身份

所有者：豫言。包版本：0.1.0（本轮初始包版本，不代表编译器命令行版本）。

本包为库类型，可被其他包依赖；模块按包名和包内路径访问。本包没有程序入口和文件名；默认构建编译库模块而不链接程序，测试或示例须显式指定模块。

## 模块

- 包定位、包上下文：发现包与写包上下文。
- 调度器：构建任务图的并行调度；每个任务记录加入、就绪、开始、结束四个时刻与开始时的在途数。无面板调度在队列空时至多每 200 毫秒复查一次子进程完成状态，即使子进程没有输出。
- 并行编译、构建监视：编译器的阶段任务图与终端监视面板。
- 构建日志：把构建事件写进半永久的日志目录（依赖结森工具写 JSON），格式见[构建日志格式](../../应用/性能研究/构建性能/日志格式.汉语.md)。
- 构建宿主（`构建宿主。接口。豫`）：宿主服务包括存放包上下文、可绘监视面板、绘监视面板、获取当前程序 SHA-256 和获取文件 SHA-256；摘要函数返回 Wasm 文件内容身份。它们编成导入模块“构建基础”的带类型导入；模块名不叫“宿主”，免得与标准库的“宿主”模块同名而互相遮蔽。

## 使用

在仓库根目录运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 检查 构建基础
```

依赖及说明路径以 [包配置](构建基础。包。豫) 为准。

## 维护

修改接口时更新本说明；修改包身份、版本或构建组成时同步更新包配置。说明文件不参与模块导入。
