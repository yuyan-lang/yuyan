# 静态站

静态站者，以豫言成静态网站之库也，以代 Jekyll。一站即一豫言之程序：以此库读源目录，以豫言之函为诸页套版，终书全站。页中之 Markdown 由「标记文」库转之。

## 籍

所有者曰豫言，版本 0.1.0。此包为库，依标准库与标记文。

## 站之所成

源目录之文分为二：

- 页：首行 `---`，至次一行 `---` 止，有前言（front matter）者。Markdown 之页（`.md`、`.markdown`）读时即转为网页之片，他页存其原文。
- 静文：余者，依字节原样复制。

名以 `.` 或 `_` 起之文与目录，默略之；在排除之列者亦略之；在包含之列者，虽以 `_` 起亦处之（如 Cloudflare 之 `_redirects`、`_headers`）。二列皆书相对源目录之径。

页之网址：前言有 `permalink` 则从之；否则为“/”加相对之径，Markdown 之文易其尾为 `.html`。网址以“/”终者，书于其目录之 `index.html`。网址皆直书中文，不作百分号之编码。

## 前言

每行书“键: 值”，值可加单引或双引；以 `#` 起之行为注。`「前言取」于 前言 于『键』` 取其值，无此键则得空串。`「解析数据列」` 析平铺映射之列（YAML 之“- 键: 值”），以读站之数据文件。

## 用法

```yuyan
寻观「标准库」之书。
寻观「静态站」之书。

「文件们」乃「列」于「站点文件」也。
「文件们」者「读取站点」于『源目录』于（「列」【『测试』】）于（「列」【『_redirects』】）也。

「套版」乃化「站点文件」而「字符串」也。
「套版」者会「件」而
  鉴「件」而
    有（「页面」于「相对」于「网址」于「页前言」于「页内容」）则
      『<!doctype html><title>』附（「前言取」于「页前言」于『title』）附『</title>』附「页内容」
    或有「其他」则『』
也。

「生成站点」于『源目录』于『输出目录』于『https://example.org』于「套版」于「文件们」。
```

`「生成站点」` 复制静文，以套版之函得诸页之全网文而书之，继书 `sitemap.xml`；源目录无 `robots.txt` 则亦书一篇，指站图之所在。站图收以 `.html` 或“/”终之网址，末之 `index.html` 省为目录。

他所出：`「页面网址」`、`「网址文件」`、`「站点地图」`、`「机器人说明」`、`「复制静态文件」`、`「写出页面」`。

## 所未及

前言唯识平铺之键值，不识嵌套、多行之值与流式之书。出之目录，其父目录由 Node 宿主之写文件自建，他宿主未必然。码中以“待办事项”注之。
