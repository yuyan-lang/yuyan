# 静态站测试

静态站的单元测试（`X。测试。豫`）：前言解析、页面网址与输出文件、站点地图、数据列表解析。读写文件的完整流程由使用它的站点构建验证。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试、标记文与静态站。它放在被测库之下，没有登记为静态站的子包。

## 使用

在仓库根目录构建并运行：

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 静态站测试 静态站。测试 --输出 yy静态站测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy静态站测试.wasm
```

输出末行的“当前失败数”应为 0。
