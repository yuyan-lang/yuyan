# 云工宿主

本库是豫言程序与 Cloudflare Workers 之间的通用桥。宿主只做名字翻译：豫言用资源「云工物」直接持有 JS 对象，经十七个通用原语读写属性、调用方法、构造对象、等待 Promise；平台语义（D1、R2、持久对象、队列、网页请求与响应等）都写在豫言操作系统的云工适配里。宿主实现在 `豫言操作系统/宿主/云工/`（`物桥.mjs` 与 `宿主.mjs`），Node 应用宿主用同一份 `物桥.mjs`。

## 模块

- `物宿主。接口。豫`：资源「云工物」、跨边界的值「云工值」、结果「云工果」，以及宿主原语：云工全局、云工绑定、云工取、云工设、云工调、云工调候、云工呼、云工呼候、云工造、云工候、云工类型、云工是实例、云工新数组、云工新对象、云工数组项们、云工对象项们、云工造回调。可能失败的原语都返回「云工果」，宿主不向 Wasm 抛异常；带“候”的原语等待 Promise（JSPI 挂起），结果用「同步等待」取出。
- `物。豫`：豫言写成的便利函数：「成或抛」把失败转成豫言异常，「取文」「取整」「取物」等从云工值取出豫言值，「物取」「物调」「物调候」「全局造」等是常用组合。
- `回调。豫` 与 `回调入口。应用接口。豫`：「登记云工回调」登记一个闭包，得到一个 JS 函数；平台调用这个函数时，宿主以应用接口导出 `云工宿主/执行云工回调` 进入 Wasm 执行闭包。ReadableStream 的拉取、Promise 的后续、持久对象事务等回调都走这里。回调入口由本库提供，应用不用写。

## 执行约定

- 每个程序在一个隔离体里只有一个 Wasm 实例（持久对象每个对象一个），多个事件在 JSPI 挂起点交错执行。顶层可变格只放跨请求共享的缓存与计数；本次请求的状态放参数或局部变量。
- 宿主不保存按事件的状态：请求、事件上下文作为类型化入口的参数传入，JS 对象的生命周期交给引擎的垃圾回收。
- 「云工全局」只能取得宿主白名单里的全局对象，以及宿主对象 豫言公网取、豫言子工、豫言平台资料、豫言应用导出；「云工绑定」按程序的许可清单核对绑定名。

`物。测试。豫` 是冒烟测试，须在实现了物宿主的宿主（云工宿主或 Node 应用宿主）里运行。
