# 云工宿主覆盖清单

TextEncoderStream、TextDecoderStream 今有豫言门。本地 workerd 验两段文字成六字节 UTF-8、汉字三字分两块而完读、BOM 跨块而默认略之，并察 `encoding`、`fatal`、`ignoreBOM`；坏 UTF-8 严解归 TypeError，宽解出替换字符。背压及云端部署待验，详 `流式编码接口.清单.tsv`；其义据 [Encoding 标准](https://encoding.spec.whatwg.org/#interface-textdecoderstream)、[Cloudflare Web 标准接口](https://developers.cloudflare.com/workers/runtime-apis/web-standards/)。

可断 fetch 以本地 workerd 验：客先取在途求柄，继断 AbortSignal，安全候则归 AbortError；未断之本机 HTTP 求得 Response 柄、二百状态及正文。预断之自定理由与无效待柄亦验，云端尚待，详 `网络中断接口.清单.tsv`；[Cloudflare Request 文档](https://developers.cloudflare.com/workers/runtime-apis/request/)载 `signal` 选项。

AbortController、AbortSignal 子书以本地 workerd 验控制器断、对象与文字理由、重断、`abort()`、`any()`、`timeout()` 静法、`throwIfAborted()` 安全察及 `abort` 事候。本地 `timeout(-1)` 可造信号而后断，真 Chrome 则归 RangeError；库存原生差异，云端尚待验。详 `中断接口.清单.tsv`；[Cloudflare Web 标准接口](https://developers.cloudflare.com/workers/runtime-apis/web-standards/)载其能。

URI 及其成分之编解码四术，以本地 workerd 验；坏 `%` 与非法 UTF-8 归阴及 `URIError` 文。`云工调用全局安全` 亦验同步错及 Promise 拒绝皆归显式结果，详 `网址编解码接口.清单.tsv`；错义据 [ECMAScript URI 诸法](https://tc39.es/ecma262/multipage/global-object.html#sec-decodeuricomponent-encodeduricomponent)。

`云工调用方法安全` 以 Node 宿主真器验：句柄之法成，则归阳与果 JSON；同步错（如 `JSON.parse` 之 SyntaxError）与无此法，则归阴及含名与辞之错象文。关系数据库适配以之读 D1 语句之误及批内约束之冲原文。workerd 与 Promise 拒绝之径待验，详 `句柄接口.清单.tsv`。

FormData 子书以 Wrangler 4.129.0 本地 workerd 验重名序、文字与文件之添置、删取、键值遍历及 Request、Response multipart 往返；原字 `00 FF 41` 无损。云端部署尚待验，详 `表单数据接口.清单.tsv`；[Cloudflare Request 文档](https://developers.cloudflare.com/workers/runtime-apis/request/)载请求正文与表单读取之法。

Blob、File 今有豫言造用诸门。本地 workerd 验原字 `00 FF 41`、诸部件合物、截取、文读、字流、文件名与修改时；原生 `Blob.bytes()` 亦逐字合。`Blob.textStream()` 于此版本无术，安全门归阴。FileReader、FileList 尚待补，详 `物字文件接口.清单.tsv`。

可写流今有豫言写器门：本地 workerd 先发两块及闭流之待柄，读压字后逐候其成，解回 `00 FF 41`；初就、已闭、释柄及中断亦验。平台闭流、中断后释柄犹报已锁，异于 Chrome；满载背压及败写尚待验，详 `可写流接口.清单.tsv`。

压缩流三式 gzip、deflate、deflate-raw 今以本地 workerd 验原字 `00 FF 41` 往还；gzip 又以按需流两次复入豫言，供「甲」及原字，经双管而六字复得。坏 gzip 与无效格式归阴；满载背压与久流尚待验，详 `压缩流接口.清单.tsv`。

事件源今由豫言可依址接本地 SSE，亦可以按需流为源；本地 workerd 两路皆得自定 `notice`、文「甲」及号 `7`。复以双豫言云工，经所授 SERVICE 绑定之 fetcher 得同信。重联与错事尚待验，详 `事件源接口.清单.tsv`。

消息通道今可由豫言造二端，同次云工事中候消息；本地 workerd 已验象文、原字 `00 FF 41` 与闭端之事。平台不许转移列，复杂克隆与败信尚待验，详 `消息通道接口.清单.tsv`。

Console 五等志今有豫言门，本地 workerd 皆见其出；多参数 `log` 亦存数与物。诸余标准法由通门可调，然平台有仅部行者及无为者，生产志路尚待验，详 `控制台接口.清单.tsv`。

TCP 外联今由豫言执柄而行：本地 workerd 连本地回声，以原字 `00 FF 41` 往还，开、读、写、闭诸路皆过。升密、失联与久联尚待验，详 `传输控制接口.清单.tsv`。

工作流回滚今以别立之 `workflow-rollback` 事复入豫言 Wasm。本地 workerd 中，前向步既成而候，`terminate({rollback:true})` 使豫言回滚分支取前果、写 KV；终止前仓空，终止后得「豫言回滚已行」。多步逆序、回滚败而复试及云上义尚待验，详 `工作流接口.清单.tsv`。

工作流批量与绝对时刻之眠今有豫言门。本地 workerd 一呼造二实例，批删得二成功、一无号之逐项事故；豫言以 `Date.now()` 求一秒后之期，CLI 录一秒 `Sleeping` 步骤。复呼批造未重行旧实例，然本地仍返旧二号，与官方之述不合，待云上或新模拟器再核；往昔时刻则报错。时钟诸界详 `时钟接口.清单.tsv`，工作流诸界详 `工作流接口.清单.tsv`。

编码与调度今有豫言门。Wrangler 4.129.0 本地 workerd 以真豫言 Wasm 验 UTF-8 汉字往返、三字节分块解码、定容量入字、`scheduler.wait` 成候及以信号中断得 `AbortError`。错字、计时精度、云上时钟与柄释放之界尚待验，详 `编码调度接口.清单.tsv`。
