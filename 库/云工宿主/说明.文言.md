# 云工宿主

此库为豫言程序与 Cloudflare Workers 之通桥。宿主惟译其名：豫言以资「云工物」径执 JS 之物，以十八通用原语读写属性、呼法、造物、候 Promise；平台之义（D1、R2、持久之物、队列、网页之请与答等）皆书于豫言操作系统之云工适配。宿主之实在 `豫言操作系统/宿主/云工/`（`物桥.mjs` 与 `宿主.mjs`），Node 应用宿主共用 `物桥.mjs`。

## 诸模

- `物宿主。接口。豫`：资「云工物」、过界之值「云工值」、果「云工果」，及宿主原语：云工全局、云工绑定、云工取、云工设、云工调、云工调候、云工呼、云工呼候、云工造、云工候、云工类型、云工是实例、云工新数组、云工新对象、云工数组项们、云工对象项们、云工造回调、云工中止。或败之原语皆归「云工果」，宿主不抛于 Wasm（部署之误与「云工中止」除外：未授之绑、主动之止，宿主径止此事）；带“候”者候 Promise（JSPI 挂起），其果以「同步等待」取之。
- `物。豫`：以豫言书之便函：「成或抛」化败为豫言之异，「取文」「取整」「取物」之属自云工值取豫言之值，「物取」「物调」「物调候」「全局造」之属为常用之合。
- `回调。豫` 与 `回调入口。应用接口。豫`：「登记云工回调」登一闭包而得 JS 之函；平台呼此函，宿主以应用接口之出 `云工宿主/执行云工回调` 入 Wasm 而行闭包。ReadableStream 之取、Promise 之续、持久之物之事务诸回调皆由此。回调入口本库供之，应用毋书。

## 行之约

- 每程序于一隔离体惟一 Wasm 实例（持久之物每物一），诸事交错于 JSPI 挂起之点。顶层可变之格惟藏跨请共用之缓存与计数；此请之态置于参或局部。
- 宿主不存按事之态：请与事之上下文皆以类型化入口之参授之，JS 之物之存亡付引擎之回收。
- 「云工全局」惟得宿主所许之全局，及宿主之物 豫言公网取、豫言子工、豫言平台资料、豫言应用导出；「云工绑定」依程序之许可清单核其绑名。

`物。测试。豫` 为烟试，须行于实物宿主之宿主（云工宿主或 Node 应用宿主）。
