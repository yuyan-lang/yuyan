# 云仓现用能力验收

以二〇二六年九月二十四日核 `yuyan-cloud` 官网、云工作台、包管理服务之源码与 Wrangler 配置。此册唯记迁移所需宿主之能，不改云仓业务。所谓已验，皆本地浏览器或 workerd 之验，未谓云上已成。

官网产品、性能及静态诸径需 `ASSETS.fetch`、原请转送与 `Request(url, request)` 改址；豫言之门及构建物已于 Wrangler 4.129.0 本地 workerd 取真静态物。径之决断、URL 解码、查询串与转址，尚须豫言作而验之。官网至 CLOUD、REGISTRY，工作台至 REGISTRY、BROWSER_COMPILER，皆需 Service binding 原生请答；两豫言 Wasm Worker 于本地 workerd 相接，POST 得 HTTP 201，`00 FF 41` 不失；各业务之路与鉴权、取消尚待验。

工作台之项目、任务、站点，需持久对象内部 SQLite、事务与 alarm；今以本地 workerd 验对象 fetch、文字存储、参数化 SQLite SQL 与 alarm，重启后仍可读；预列之同步 SQL 事务与可化癸象对象已于本地验，败时回滚；交互式事务、诸余克隆值及对象之全寿尚待补。包管理后台所需 Queue `send`、`sendBatch` 与消费事件，今有豫言基门，且本地 workerd 已验投递、消费、KV 跨事记态；实务消息之形、批败与重试尚待验。账户所需 Send Email `send`，今以真 Wasm 及模拟绑定验文字构造物，未寄真信。隔离运行之 Worker Loader `load`、`get`、客器入口与限额，今由豫言门调用；本地 workerd 真载豫言子工，两路皆得 HTTP 200，`get` 复请亦然。客器之 JS 唯宿主外壳，不授环境绑定及外发网络；云上隔离、限额事故、同号换码与任务协议尚待验。包管理之 PROVIDER_CONNECTIONS、CLOUD_SITES 又需对象标识、桩寿命与 Service 传请。D1、R2、KV 今有文字基路，查询、事务、字节、分页与条件诸事未周。浏览器工作台所需文树、事件、网求、流与缓存，亦唯部分有验。

官网路由今可先用 `云工请求句柄`、`云工请求改址`、`云工资产请求句柄`、`云工服务请求句柄`、`云工设置响应句柄` 诸原语；构建器出 `入口.mjs`、`程序.wasm`、`值桥.wasm`，许可书须按实列 ASSETS、SERVICE 之名。业务路由当由豫言书之。今可始本地编路与联调，未可称官网诸径悉可迁上线。
