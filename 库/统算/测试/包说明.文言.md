# 统算测试

统算库之单元之试（`X。测试。豫`），无 PTX 之源：

- `驱动。测试`：器数、名、显存总量、算力、多处理器数、每块至多之线与驱动之版；留主上下文，显存之余不逾其总，空上下文可同步；已识之码之名与述，不识之码曰“未知错误码 N”而述空；字节串书于显存而读回同，原生之存上传、显存相抄、下载之后诸值同；全块依字置值，复改其首十六字，读回而核；于新建之阻塞之流与传统默认之流记事、同步，事之间隔在零与一秒之间；非法之文（`this is not PTX`）载模而败，误文具误名与 JIT 之误志。无统算之器（系统无英伟达驱动 `libcuda.so.1`，或宿主不能调系统库）则惟书“跳过”。

核之载、取函、发与读回数值，由「着色库测试」之 `统算运行。测试` 以着色语言所译之 PTX 覆之；待办事项：矩阵乘等较大之核之试，俟张量内核之库成乃补。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，惟供试，依标准库、单元测试、系统库调用与统算。试包依所试之库，故登于「共用库」之下。

## 用法

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 统算测试 驱动。测试 --输出 yy统算驱动测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy统算驱动测试.wasm
```

出之末行“当前失败数”当为零。
