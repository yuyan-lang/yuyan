# 统算测试

统算库的单元测试（`X。测试。豫`），不含 PTX 源码：

- `驱动。测试`：设备个数、名字、显存总量、计算能力、多处理器数、每块最多线程与驱动版本；保留主上下文，显存空闲量不超过总量，空上下文可以同步；已知错误码的名字与说明，未知码得“未知错误码 N”与空说明；字节串写入显存再读回相同，原生内存上传、显存间复制、下载后各值相同；整块按字节置值再改写开头 16 字节，读回核对；在新建的阻塞流与传统默认流上记录事件、同步，事件间隔在零到一秒之间；非法文字（`this is not PTX`）载入模块失败，错误文字带错误名与 JIT 错误日志。没有统算设备（系统上没有英伟达驱动 `libcuda.so.1`，或宿主不能调用系统库）时只打印“跳过”。

待办事项：着色语言能翻译成 PTX 后，补内核测试（载入、取函数、发射、读回数值、矩阵乘）。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只供测试，依赖标准库、单元测试、系统库调用与统算。测试包依赖被测库，所以登记在「共用库」之下。

## 使用

```sh
node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 统算测试 驱动。测试 --输出 yy统算驱动测试.wasm -j 24
node 豫言操作系统/宿主/节点/宿主.cjs yy统算驱动测试.wasm
```

输出末行的“当前失败数”应为 0。
