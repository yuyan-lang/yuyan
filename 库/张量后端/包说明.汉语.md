# 张量后端

这是张量计算的 GPU 后端公共层，与设备无关。它规定设备要提供的一张操作表（「张量设备」），并为每个张量上下文维护后端状态（「张量后端」）：存储缓冲缓存、管线与模块缓存、命令合批。金属、网页图算、统算各自实现设备表（金属见 `库/金属张量后端`），张量计算适配只经本层使用 GPU。

## 包身份

所有者：豫言。包版本：0.1.0。本包为库类型，只依赖标准库，登记在「共用库」之下。

## 设备表（`设备` 模块）

「造张量设备」依次接十三项，后端只经这张表用设备：

| 项 | 类型 | 含义 |
| --- | --- | --- |
| 名称 | 字符串 | 如 `金属` |
| 源种 | 字符串 | 取内核源码的哪一种：`金属` 取 MSL，`网页图算` 取 WGSL，`统算` 取 PTX |
| 统一内存 | 爻 | 阳：设备直接读写宿主存储（金属零拷贝）；阴：设备有自己的显存，要上传下载（统算） |
| 取存储缓冲 | （存储地址，字节数）→ 缓冲号 | 统一内存的设备包裹宿主存储；其余设备分配显存，显存副本过期时上传；零表示失败 |
| 释放缓冲 | 缓冲号 → 元 | |
| 新建数据缓冲 | 字节串 → 缓冲号 | 设备自有、按给定字节初始化（如旋转位置编码的角表），下次提交并等待后自动释放 |
| 编模块 | 源码 → 模块号 | 编译失败时抛出事故，附编译器的消息 |
| 取管线 | （模块号，入口名）→ 管线号 | |
| 记派发 | （管线号，缓冲号列，参数区字节，gx，gy，每组线程数）→ 元 | 缓冲依次绑到 1、2……，参数区绑到 0；只记进当前批 |
| 提交并等待 | 元 → 元 | 把已记的派发交给设备并等到全部完成 |
| 交回主机 | 存储地址 → 元 | 设备写过的存储在宿主读之前交回（统一内存的设备不做事） |
| 主机已改 | 存储地址 → 元 | 宿主就地改了存储之后，令设备副本作废（统一内存的设备不做事） |
| 单精位型 | 小数 → 整数 | 舍入到 binary32 后的 32 位位型，打包参数区用；豫言的小数运算经宿主，由设备所在的宿主求最直接 |

后两项与“交回主机”“主机已改”是给没有统一内存的设备（统算）准备的：张量常驻显存，只在宿主要读、宿主改过时上传下载。

## 后端状态（`后端` 模块）

- `「新建张量后端」于 设备`：每个张量上下文一个后端，设备可由多个上下文共用。
- `「后端存储缓冲」于 端 于 存储地址 于 字节数`：按存储地址缓存缓冲号；同一存储的多个视图共用一个缓冲。
- `「后端取管线」于 端 于 源码 于 入口名`：按入口名缓存管线，同一源码只编译一次。
- `「后端派发」于 端 于 管线 于 缓冲们 于 参数区字节 于 组数 G 于 每组线程数 于 写址们`：组数拆成 (gx, gy)，gx = min(G, 65535)，gy = ⌈G/65535⌉；G 为零时不派发。写址们是这次派发会写的存储，非统一内存的设备据此在同步时交回主机。
- 命令合批：派发只记进当前批。`「后端同步」` 在有待提交的派发时提交并等待（非统一内存的设备再把写过的存储交回主机）；宿主要读、改或释放这个上下文的张量之前都要先同步。`「后端有待提交吗」` 查询是否有未提交的派发。
- `「后端主机已改」于 端 于 存储地址`：宿主就地改了存储之后调用。
- `「后端释放存储」`：宿主释放张量之前调用，先同步再放掉这块存储的缓冲（零拷贝的缓冲必须先于宿主存储释放）；同一存储另有张量共用时，下次用到再取。`「后端释放全部」`：上下文释放之前调用。
- `「字们转字节」`：把整数列按小端 32 位字写成参数区字节串（负数即二补码）；`「后端单精位型」` 求小数的 binary32 位型。
