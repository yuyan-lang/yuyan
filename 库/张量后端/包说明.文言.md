# 张量后端

此乃张量计算之 GPU 后端公共之层，与器无涉。定器所当供之操作之表（「张量设备」），为每张量之境守后端之态（「张量后端」：存缓之存、管线与模之存、命令合批、延释），又依「张量内核」之核表实诸算（「算子」之模）。金属、网页图算、统算各实其器表（金属见 `库/金属张量后端`，统算见 `库/统算张量后端`），张量计算之适配（`豫言操作系统/适配/张量计算节点`）惟经此层用 GPU。

## 包之身

所有者：豫言。包之版：0.1.0。此包为库，依标准库与张量内核，登于「共用库」之下。

## 器表（`设备` 之模）

「造张量设备」依次受十三项，后端惟经此表用器：

| 项 | 类 | 义 |
| --- | --- | --- |
| 名称 | 字符串 | 若 `金属` |
| 源种 | 字符串 | 取核源之何种：`金属` 取 MSL，`网页图算` 取 WGSL，`统算` 取 PTX |
| 统一内存 | 爻 | 阳：器径读写宿主之存（金属零抄）；阴：器有自之显存，须上下传（统算） |
| 取存储缓冲 | （存址，字数）→ 缓号 | 统一之器裹宿主之存；余器分显存，其副过期则上传；零为败 |
| 释放缓冲 | 缓号 → 元 | |
| 新建数据缓冲 | 字节串 → 缓号 | 器自有，以所予之字初之（若旋转位置编码之角表），下次交候之后自释 |
| 编模块 | 源 → 模号 | 编败则事故，附编者之辞 |
| 取管线 | （模号，入口之名）→ 管线号 | |
| 记派发 | （管线号，缓号之列，参数之字，gx，gy，每组之线数）→ 元 | 诸缓依次系于一、二……，参数之区系于零；惟记于今批 |
| 提交并等待 | 元 → 元 | 以所记之派付器而候其尽毕 |
| 交回主机 | 存址 → 元 | 器所写之存，宿主读之前交回（统一之器无为） |
| 主机已改 | 存址 → 元 | 宿主就地改存之后，废器之副（统一之器无为） |
| 单精位型 | 小数 → 整数 | 舍为 binary32 之三十二位之位，包参数之区用之；豫言之小数运算经宿主，由器所在之宿主求之最径 |

交回主机、主机已改二项，为无统一之存之器（统算）而设：张量常居显存，惟宿主将读、宿主已改乃上下传。

缓号、模号、管线号于后端皆为不透之正整数（零为败），器可自定其编（金属张量器于缓号中带页内之偏）；缓可为 GPU 之物，亦可为宿主之存段（址加长），若他日之中央处理器之器。记派可惟记于今批，亦可当场同步行毕（此时交候无为）；后端惟求交候返时，所记之派皆已毕。

## 后端之态（`后端` 之模）

- `「新建张量后端」于 器`：每张量之境一后端，器可数境共之。
- `「后端存储缓冲」于 端 于 存址 于 字数`：依存址存缓号；同存之诸视图共一缓。
- `「后端取管线」于 端 于 源 于 入口之名`：依入口之名存管线，一源惟编一次。
- `「后端派发」于 端 于 管线 于 诸缓 于 参数之字 于 组数 G 于 每组之线数 于 写址们`：组数析为 (gx, gy)，gx = min(G, 65535)，gy = ⌈G/65535⌉；G 零则不派。写址们为此派所写之存，非统一之器据之于同时交回宿主。
- 命令合批：派惟记于今批。`「后端同步」` 有待交之派则交而候之（非统一之器又交回所写之存），终行延释；宿主读、改此境之张量之前，皆先同之。`「后端有待提交吗」` 问有无未交之派。
- 延释：`「后端延后释放」于 端 于 存址 于 释之函` 记一项，俟下次同（所记之派皆毕）乃先释其存之缓，而后调其函；用于派犹用之临时张量（若矩阵乘前所紧致者）与宿主将释之张量。`「后端存储已用吗」` 问此存今有缓否。
- `「后端主机已改」于 端 于 存址`：宿主就地改存之后调之。
- `「后端释放存储」`：宿主释张量之前调之，先同而后释此存之缓（零抄之缓必先于宿主之存而释）；同存他张量共之者，后用再取。`「后端释放全部」`：境释之前调之。
- `「字们转字节」`：以整数之列书为小端三十二位之字，为参数之区（负者即二补码）；`「后端单精位型」` 求小数之 binary32 之位。

## 算子之层（`算子` 之模）

「后端张量」述一张量之视：宿主之号、存址、存之字数、元类之号（同张量适配：零单精、四三十二位整数、五块量化八位……）、起与步（以元计）、形。召者予「后端分配」（元类之号，形）→ 新建之连续张量，每算验其类与布、依核表包参（单精字经器之单精之位）、取管线（依器之源种取 WGSL、MSL 或 PTX 与入口之名）、依张量取存缓（依次系于一、二……）、求组数而派之，返其果；不能（类、布、参不合）则返可无或阴，召者退就中央处理器。

| 函 | 条 | 核 |
| --- | --- | --- |
| 后端逐元二元、后端逐元标量、后端逐元一元 | 单精，可为视图，二元依广播 | 逐元二元、逐元标量、逐元一元 |
| 后端填充常数（就地） | 单精，目可为视图 | 填充常数 |
| 后端紧致化、后端切片、后端转置 | 三十二位之类 | 跨步复制 |
| 后端写入视图（就地）、后端拼接 | 三十二位同类，写视之二边不共存 | 跨步复制 |
| 后端取行 | 表 [R, d] 为单精、半精、脑浮点、Q8_0、Q4_K 或 Q6_K，连续 | 取行 |
| 后端按行累加（就地） | 单精、连续，二边不共存 | 按行累加 |
| 后端末维求和、后端末维最大、后端软最大 | 单精、连续 | 末维求和、末维最大、软最大 |
| 后端均方根归一 | 甲单精连续，权为单精、半精或脑浮点 | 均方根归一 |
| 后端按轴求和、后端按轴最大 | 单精、连续 | 按轴求和、按轴最大 |
| 后端旋转位置编码 | 单精、连续 [n, h, d]，r 偶 | 旋转位置编码；角表由「后端旋转角表字节」求之（三角之函召者予之） |
| 后端矩阵乘 | 甲单精，乙为单精、半精、脑浮点、Q8_0、Q4_K 或 Q6_K，批维广播；单精之边行不连续则先紧致之，临时者经延释还之（召者又予「后端释放」）；半精、脑浮点之乙须行连续 | 浮点之乙：m ≤ 4 用矩阵乘向量，否则矩阵乘分块；块量化之乙：依「量化宜分块」择块八/超四/超六矩阵向量乘或其分块矩阵乘 |
| 后端写入行（就地） | 目单精或半精、连续，源单精，行在界，不共存 | 单精之目用跨步之抄，半精之目用写入十六位（源须连续） |
| 后端注意力 | 问单精，键、值单精或半精，皆连续 [·, 头, 维]，d、dv 不逾二百五十六 | 「注意力宜分段」为真则分段注意加注意力合并（暂存由召者所予之函供之，诸层共之），否则注意力 |
| 后端层归一、后端二范数归一 | 甲单精连续；层归一之权、偏为浮点 | 层归一、二范数归一 |
| 后端就地线性组合、后端亚当更新（就地） | 单精、连续、同形，存两两相异；亚当之 1 − βᵗ 召者以双精求之 | 就地线性组合、亚当更新 |
| 后端取前k、后端按行最大下标 | 甲单精连续 | 取前k（值与三十二位整之下标）、按行最大下标 |
| 后端类型转换 | 源连续；转单精则源为单精、半精、脑浮点、八位或三十二位整，转半精、脑浮点则源为单精 | 转单精度、写入十六位 |

又有「后端视图」「后端改形视图」「换句柄」「造连续后端张量」，供召者由已知之视推新视之信。段长、分段之阈与量化分块之阈依「后端种类值」（由器之源种得之：统算、网页图算，余为金属）取于核表。
