# 统算张量后端

此张量计算之统算（CUDA）之器也：以「统算」之库（`库/统算`）实「张量后端」之器表（`库/张量后端`）。显卡自有显存，张量常驻显存，惟需时上下传；核为「张量内核」诸着色之源所译之 PTX，驱动即以 JIT 编之。

## 籍

所有者曰豫言，版本 0.1.0，种类曰库；依标准库、系统库调用、统算与张量后端，登于「共用库」之下；唯用于诺节之林纳克斯（由系统库之调开 libcuda.so.1）。

## 用

```yuyan
寻观「统算张量后端」之书。
```

`「取统算张量设备」于「元」` 得「或可有」于「张量设备」：一进程惟建一次（第零卡之主上下文，设为当前），诸境共之；无统算（宿主不能调系统库、无 libcuda.so.1 或无卡）则可无。得器乃以 `「新建张量后端」于 器` 为每境建后端。

## 实

- 统一之存为阴。缓号即显存之址；器又记宿主之址、字数与过期之标。
- 取存之缓：依尺寸之档（不及二百五十六字作二百五十六，不及一兆字取二之幂，逾之依六十四千字取整）取一块于显存之池，无则申之（败则清池复试），乃整块异步上传宿主之存。释缓则还显存于池；池逾二百五十六兆字则径释。
- 上传一以默认之流之异步之抄（cuMemcpyHtoDAsync）：可分页之宿主之存即抄入驱动之暂区而返，不候显卡，列于先发者之后。显卡为他程所占，同步之上传每候八十至百一十微秒，异步者惟约六微秒。
- 宿主已改：标显存之副为过期；次记派用此缓，先重传之。交回宿主：整块同步下显存于宿主之址（每块约十微秒）。
- 记派：以参数之字续于今批之暂存（依十六字对齐），记发射之项（函柄、网格、每块之线、参数之偏、缓号之列）；每满十六则先发一段（不候），使显卡随记而行：此段之参区并发射之记拼入原生之暂区，参区异步上传至显存参区中今批不复覆之块（区不足则另分更大之新区，旧区俟同后乃释），乃逐一 cuLaunchKernel（网格 (gx, gy, 1)，每块 (N, 1, 1)，默认之流）。
- 交而候之：余下之派依上法发一段；今批曾有发则同其上下文，有误则事故（附驱动之误名）。乃释今批之临时之数据之缓。每发惟余一系统库之调。
- 编模：以 cuModuleLoadDataEx 载 PTX，败则事故，附 JIT 之误志；取管线：依改书为 ASCII 之入口之名取函。
- 单精之位：书单精于八字原生之暂存，复以三十二位整读之。

## 费

二〇二六年九月三十日于 NVIDIA GeForce RTX 5090（其时显卡为他程所占约九成）以暂设之计时之程测之：一派于后端与器中记之约二至三微秒；交时每发约二十微秒，多为由系统库之调之一 cuLaunchKernel（十一参经宿主值桥而转）；同步下载每块约十微秒，空同约二微秒；显卡为他程所占，有待行之派之同须候显卡之时片（约二毫秒）。千问三 0.6B 解码每词元约五百派，统算每词元约五十一至五十六毫秒，其中器之层（发射、上传新果、下载所写之存）约十余毫秒，余在适配与后端之层。

## 试

`测试/` 之「统算张量后端测试」包：以试目之着色源「仿射」（构时译为 PTX）验单精之位、存缓与管线之存、二派合一批（未同则宿主之存不变，同后下回之数合）、较大之参数之区、组数零则不派、宿主改之而调宿主已改则次派用新值、释存复取与尽释。无统算之器则书“跳过”。于仓之根先 `node 豫言操作系统/宿主/节点/宿主.cjs yy豫构.wasm 构建 统算张量后端测试 设备。测试 --输出 yy统算张量后端测试.wasm -j 24`，后 `node 豫言操作系统/宿主/节点/宿主.cjs yy统算张量后端测试.wasm`。

## 所限

待办事项：惟用第零卡；下传为同步之常抄（大块可改锁页之存与异步之抄）；新建之果张量亦先上传宿主之全零；每发犹一系统库之调——宿主若加“依原生之存之参表连调一函 N 次”之批调之原语，可降至一二微秒；统算之图（CUDA Graph）须每步缓址与参不变，解码时中间张量之址与位置之参每词元皆变，暂不值；模与函不卸；显存之池依尺寸之档精合。
