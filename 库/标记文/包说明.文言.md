# 标记文

标记文者，以豫言书之 Markdown 转换之库也：受 Markdown 之文，出网页之片。所出之式仿 kramdown 之 GFM 法（Jekyll 默用之 Markdown 引擎），以便代昔以 Jekyll 所成之站。

## 籍

所有者曰豫言，版本 0.1.0。此包为库，唯依标准库。

## 用法

```yuyan
寻观「标记文」之书。

「打印行」于（「标记文转网页」于『# 标题「：换行：」「：换行：」正文 **粗体**』）。
```

总集所出：

- `「标记文转网页」`：转 Markdown 之文为网页之片；块间空一行，篇末有换行。
- `「网页正文转义」`：转 `&`、`<`、`>` 三字。
- `「网页属性转义」`：兼转双引、单引，与 Liquid 之 `escape` 同。
- `「文分行」`、`「去空白」` 等文字之辅。

## 所识之式

块：

- ATX 之题（一至六 `#`，继以空白）。题之标识循 kramdown GFM 之法：小写之，去标点符号，空格为连字符；一篇之中重者续以 `-1`、`-2`。
- 围栏之码（三以上反引号或波浪号）。有语言之名则出 `<pre><code class="language-语言">`。
- GFM 之表：以竖线始之连行；次行为对齐之分隔者，首行为表头；冒号示左、右、中之齐。
- 无序之列（`-`、`*`、`+`）与有序之列（`数字.`），一项可跨数行。
- 引（`>`）、分隔之线（三以上 `-`、`*` 或 `_`）。
- 网文之块：以块级标签始之行，收至同名标签启闭相抵之行乃止，其中空行不断之；块内原样出之。注释收至 `-->` 乃止。
- 段：余行皆是。

行内：

- 代码之段（`` `代码` ``，反引号多者去首尾各一空格）、`**粗**`、`*斜*`。
- 链 `[文](址 "题")`、图 `![替文](址)`、自动之链 `<https://…>`。
- 行内网文之标签原样出之；字符实体（`&amp;`、`&#39;` 等）原样出之；反斜杠转义 ASCII 之标点。

## 所未及

下列之式未之识，码中以“待办事项”注之：缩进之码块、Setext 之题、嵌套之列、疏列（项间有空行则分为二列）、下划线之强调、引用式之链、脚注、定义之列、`{: }` 属性、硬换行，及 kramdown 之智能引号与 `--`、`...` 诸排版之替。寻强调与链之闭，不越其中之代码段。题之标识辨“词字”，用近似之码段表。
